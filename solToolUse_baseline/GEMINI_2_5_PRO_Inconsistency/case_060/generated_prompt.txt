Create a file named axiplane.inp in the working directory with the provided input deck content.
The simulation will use the CAX8 and CPS8 element types as specified in the axiplane.inp file.
The simulation will use the distributed pressure load as defined in the axiplane.inp file.
Run the CalculiX simulation using either the `ccx -i axiplane` or `ccx axiplane` command.
Determine if the simulation succeeded by checking for a successful termination message in the `axiplane.sta` file.
The stress and strain results do not need to be validated against the provided reference text.
Create a file named results.json in the working directory.
The results.json file will contain a JSON object with "solver" set to "calculix" and "case_id" set to "axiplane".
The "status" field in results.json will be "success" if the run completed successfully, and "error" otherwise.
The "ccx_version" field in results.json will contain the version string from the `ccx -v` command.
The "artifacts" field in results.json will be an empty list.
The "notes" field in results.json will record the exact CalculiX command used.
If the simulation fails, the "notes" field will also include the error message and the name of the file that indicated the failure.
