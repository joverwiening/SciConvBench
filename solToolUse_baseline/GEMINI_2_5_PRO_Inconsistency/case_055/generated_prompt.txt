Create a file named uprofile.inp with the exact content provided in the "Input deck" section.
The element type used in the simulation will be B32R.
The beam section parameters will be 25.0, 50.0, 0.0001, 3.00, 3.00, 3.00.
The load in the second step will be a moment of 1000.0 about the z-axis applied to node 11.
The load in the third step will be a force of -100.0 in the y-direction applied to node 11.
Run the CalculiX solver on the uprofile.inp file using either `ccx -i uprofile` or `ccx uprofile`.
Determine the success or failure of the run by checking the uprofile.sta file for a successful termination message.
The numerical results do not need to be validated against the 'Reference text'.
Create a JSON file named results.json.
The `solver` field in results.json will be "calculix".
The `case_id` field in results.json will be "uprofile".
The `status` field in results.json will be "success" or "error".
The `ccx_version` field in results.json will be the version string from `ccx -v`.
The `artifacts` field in results.json will be an empty list.
The `notes` field in results.json will record the exact ccx command used.
If the run fails, the `notes` field will also include the error message and the file that indicated the failure.
