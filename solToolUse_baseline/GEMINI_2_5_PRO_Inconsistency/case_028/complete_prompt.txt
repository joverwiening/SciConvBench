Case ID: case_028
Use FEniCS legacy (dolfin).
Solver: small-strain linear elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with a vector-valued displacement space and a direct linear solver.
Task:
Analyze stress distribution in an L-shaped structure with combined gravity loading and shear traction on top-right edge. Implement linear elasticity model with Young's modulus E=70e9 Pa, Poisson ratio ν=0.33, density ρ=2700 kg/m^3. Fix left boundary (x=0), apply horizontal shear traction on y=1 (x>0.5), and visualize displacement/stress patterns.
Case details:
Material: E=70e9, ν=0.33, ρ=2700, g=9.81. Geometry: L-shape (1x1 outer minus 0.5x0.5 inner). Boundaries: x=0 fixed, y=1 (x>0.5) has σ_xy=2.65e4 Pa. Mesh: 64 elements/edge.
Implementation notes:
Treat the 2D domain as plane stress with unit thickness and use the reduced plane-stress constitutive law.
Compute von Mises from the in-plane Cauchy stress field.
Apply the shear traction only on the top-right segment y = 1 with x > 0.5; the remaining outer edges are natural except for the clamped left edge.
