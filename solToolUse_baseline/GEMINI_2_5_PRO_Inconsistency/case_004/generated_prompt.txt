Simulate stress in a 2D L-shaped structure using the FEniCS legacy library (dolfin).
The simulation will solve a small-strain linear elasticity problem.
The problem is formulated under the plane-stress assumption with unit thickness.
The geometry is an L-shaped domain created by removing the square [0.5, 1] x [0.5, 1] from the unit square [0, 1] x [0, 1].
The mesh will have a resolution of exactly 64 elements per unit length on the outer boundary.
The material has a Young's modulus of 70e9 Pa and a Poisson's ratio of 0.33.
A body force representing gravity is applied, with density ρ=2700 kg/m^3 and gravitational acceleration g=9.81 m/s^2 acting in the negative y-direction.
The left boundary of the domain (x=0) is fixed, with zero displacement.
A linearly varying vertical traction is applied to the outer right boundary (x=1, for y from 0 to 1).
The traction's vertical component is defined by the expression σ_yy(y) = -2.65e4 * y.
All other boundaries, including the inner re-entrant boundaries, are traction-free.
The displacement field is discretized using second-degree Lagrange elements in a vector-valued function space.
The linear system of equations is solved using a direct solver.
The simulation will compute the displacement field, the in-plane Cauchy stress tensor, and the von Mises stress.
The computed displacement, stress, and von Mises stress fields will be saved in XDMF format.
