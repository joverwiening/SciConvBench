Use the FEniCS legacy (dolfin) library.
Solve a 2D small-strain linear elasticity problem.
The simulation domain is an L-shaped polygon defined by the vertices (0,0), (1,0), (1,0.5), (0.5,0.5), (0.5,1), and (0,1).
The material has a Young's modulus of 70e9 Pa, a Poisson's ratio of 0.33, and a density of 2700 kg/m^3.
Model the domain under plane stress conditions with a unit thickness.
The mesh resolution should be 64 elements along any edge of length 1.0.
Use a vector-valued function space for the displacement field.
The displacement function space should use second-degree (P2) Lagrange elements.
Apply a body force due to gravity, with g=9.81 m/s^2, acting in the negative y-direction.
Apply a traction of (2.65e4, 0) Pa on the right boundary, defined by x=1 and 0 <= y <= 0.5.
Clamp the outer left boundary (x=0, 0 <= y <= 1) by setting displacement to zero.
Clamp the outer bottom boundary (y=0, 0 <= x <= 1) by setting displacement to zero.
Clamp the inner vertical boundary (x=0.5, 0.5 <= y <= 1) by setting displacement to zero.
Clamp the inner horizontal boundary (y=0.5, 0.5 <= x <= 1) by setting displacement to zero.
Solve the linear system using a direct solver.
After solving for the displacement, compute the von Mises stress from the in-plane Cauchy stress components.
The final outputs should be the displacement field and the von Mises stress field.
