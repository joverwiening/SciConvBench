Create the file leifer1.inp in the working directory with the provided content.
The simulation will use S8 elements as specified in the input deck.
The simulation will be a dynamic analysis as specified in the input deck.
Run the CalculiX simulation using either `ccx -i leifer1` or `ccx leifer1`.
Determine if the run was successful by checking for a successful termination message in the `leifer1.sta` file.
Get the CalculiX version string by running `ccx -v` or an equivalent command.
Create a JSON file named `results.json` in the working directory.
The `results.json` file must conform to the specified schema.
The `solver` field in `results.json` will be "calculix".
The `case_id` field in `results.json` will be "leifer1".
The `status` field in `results.json` will be "success" if the run completed successfully, otherwise "error".
The `ccx_version` field in `results.json` will contain the version string.
The `artifacts` field in `results.json` will be an empty list.
The `notes` field in `results.json` will contain the exact CalculiX command used.
If the run fails, the `notes` field will also include the error message and the file that indicated the failure.
