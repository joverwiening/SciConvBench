Create the file `beampfix.inp` in the working directory using the provided input deck.
The simulation will use the C3D20R element type as specified in the input deck.
The simulation will be a two-step analysis as defined in the input deck.
The `*BOUNDARY,FIXED` card will be used in the second step as specified in the input deck.
Run the CalculiX analysis using either `ccx -i beampfix` or `ccx beampfix`.
Determine if the run succeeded by checking the `beampfix.sta` file for a successful termination message.
Write a `results.json` file in the working directory.
The `results.json` file must conform to the specified schema.
The `solver` field in `results.json` will be "calculix".
The `case_id` field in `results.json` will be "beampfix".
The `status` field in `results.json` will be "success" or "error" based on the run's outcome.
The `ccx_version` field in `results.json` will be the version string from `ccx -v`.
The `artifacts` field in `results.json` will be an empty list.
The `notes` field in `results.json` will record the exact ccx command used.
If the run fails, the `notes` field will also include the error message and the file that indicated the failure.
