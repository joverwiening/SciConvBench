Create a file named `pendel.inp` in the working directory.
The content of `pendel.inp` is the provided input deck.
The simulation uses B32 elements as specified in the input deck.
The simulation applies a gravity load as specified in the input deck.
The total time for the dynamic simulation step is 1.0, as specified in the input deck.
Run the CalculiX simulation for the `pendel.inp` file.
The command to run the simulation should be either `ccx -i pendel` or `ccx pendel`.
Determine if the simulation run was successful by checking for a successful termination message in the `pendel.sta` file.
Create a JSON file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with specific key-value pairs.
The `solver` key should have the string value "calculix".
The `case_id` key should have the string value "pendel".
The `status` key should have the string value "success" if the run succeeded, or "error" if it failed.
The `ccx_version` key should contain the version string obtained by running `ccx -v` or an equivalent command.
The `artifacts` key should have an empty list as its value.
The `notes` key should contain a string with the exact CalculiX command used to run the simulation.
If the simulation failed, the `notes` string should also include the error message and the name of the file that indicated the failure.
