Create a file named zerovel.inp in the working directory with the provided input deck content.
The input deck defines a dynamic simulation for a beam structure using B31 elements.
The material has an elastic modulus of 10,000,000,000 and a density of 1000.
The beam has a rectangular cross-section of 0.01 by 0.01.
The simulation is a dynamic step running from a time of 0.01 to 0.1.
A concentrated load of 0.01 is applied to node 1 in the positive x-direction.
The simulation will output both the displacement (U) and velocity (V) vectors.
Run the CalculiX analysis on the zerovel.inp file using either `ccx -i zerovel` or `ccx zerovel`.
Determine if the simulation succeeded by checking the `zerovel.sta` file for a successful completion message.
Create a file named `results.json` in the working directory.
The `solver` field in `results.json` will be "calculix".
The `case_id` field in `results.json` will be "zerovel".
The `status` field will be "success" if the run completed successfully, otherwise "error".
The `ccx_version` field will contain the version string from the `ccx -v` command.
The `artifacts` field will be an empty list.
The `notes` field will contain the exact CalculiX command used for the run.
If the simulation fails, the `notes` field will also include the error message and the file that indicated the failure.
