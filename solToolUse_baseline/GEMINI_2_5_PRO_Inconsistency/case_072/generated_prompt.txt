Create a file named `testmortar.inp` in the working directory.
The content of `testmortar.inp` must be the exact text provided in the input deck block.
Run the CalculiX analysis on the `testmortar.inp` file.
Use either the `ccx -i testmortar` or `ccx testmortar` command, whichever is functional on the system.
Determine if the simulation run was successful by checking for a successful termination message, such as 'JOB COMPLETED', in the `testmortar.sta` file.
Create a `results.json` file in the working directory.
The `results.json` file must contain a JSON object with specific key-value pairs.
The `solver` key must have the string value "calculix".
The `case_id` key must have the string value "testmortar".
The `status` key must have the string value "success" if the run completed successfully, or "error" otherwise.
The `ccx_version` key must have a string value corresponding to the output of the `ccx -v` command or its equivalent.
The `artifacts` key must have an empty list as its value.
The `notes` key must contain a string with the exact CalculiX command used for the run.
If the run fails, the `notes` string must also include the error message and the name of the file where the error was found.
