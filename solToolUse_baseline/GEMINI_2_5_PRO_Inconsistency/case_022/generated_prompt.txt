Use the FEniCS legacy library (dolfin).
Solve a 2D small-strain linear elasticity problem for a rectangular plate.
The model is for plane stress.
The geometry is a rectangle defined by the domain (0, 1.0) x (0, 0.20) meters.
Use a uniform structured mesh with 20 subdivisions in the x-direction and 4 subdivisions in the y-direction.
The material has a Young's modulus of 200 GPa and a Poisson's ratio of 0.30.
Use the reduced plane-stress constitutive law.
The function space for the displacement field is a vector-valued space using Lagrange elements of polynomial degree 2.
The left edge of the plate (x = 0) is fixed with a displacement of (0, 0).
The right edge of the plate (x = 1) has a prescribed displacement of (0.001, 0) meters.
The top (y = 0.20) and bottom (y = 0) edges are traction-free.
Solve the linear variational problem using a direct solver.
Save a color map of the x-component of displacement (u_x) to a file named q1_ux.png.
Save the resulting displacement field to an XDMF file named displacement.xdmf.
