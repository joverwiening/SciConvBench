Solve a 2D small-strain linear elasticity problem using the FEniCS legacy (dolfin) library.
The problem domain is a semi-circle with a radius of 1 meter, defined by y >= 0.
The analysis will use a plane stress formulation.
The material has a Young's modulus of 70e9 Pa, a Poisson's ratio of 0.33, and a density of 2700 kg/m^3.
A body force due to gravity (g = 9.81 m/s^2) acts in the negative y-direction.
The straight base of the semi-circle (where y=0) is fixed, meaning displacement is zero.
A uniform vertical traction of (0, -20000 Pa) is applied to the circular arc of the semi-circle.
The mesh for the domain must contain exactly 64 elements.
The mesh will be generated using `mshr` by iteratively adjusting the resolution parameter until the element count is exactly 64.
A reasonable number of segments will be used to discretize the circular arc during mesh generation.
The displacement will be solved for using a vector-valued function space with a reasonable polynomial degree.
A direct linear solver will be used to solve the system of equations.
After solving for the displacement, compute the von Mises stress distribution from the in-plane Cauchy stress field.
The computed displacement and von Mises stress distributions should be saved in a standard format suitable for visualization, such as XDMF.
