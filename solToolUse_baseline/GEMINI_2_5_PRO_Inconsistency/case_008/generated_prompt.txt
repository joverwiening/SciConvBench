Use FEniCS legacy (dolfin) to solve a 2D small-strain linear elasticity problem.
The simulation uses the plane-stress formulation with unit thickness.
The geometry is a right triangle with vertices at (0,0), (1,0), and (0,0.5).
The material has a Young's modulus of 70e9 Pa and a Poisson's ratio of 0.33.
A structured mesh of exactly 64 triangular elements will be used.
The left edge (x=0) is constrained with the boundary condition u_x = 0.
The bottom edge (y=0) is constrained with the boundary condition u_y = 0.
A vertical point load of -5000 N is applied at the coordinate (0.5, 0.25).
The point load is to be implemented using the `PointSource` class.
The vector-valued displacement function space will use second-order Lagrange elements (P2).
The linear system will be solved using a direct solver.
Compute the displacement field.
Compute the von Mises stress field from the in-plane Cauchy stress components.
Save the computed displacement and von Mises stress fields to XDMF files for visualization.
