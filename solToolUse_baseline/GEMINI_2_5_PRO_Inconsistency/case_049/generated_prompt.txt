The job name is `planestrain2`.
The input file must be named `planestrain2.inp`.
Create the file `planestrain2.inp` in the working directory using the provided input deck content.
The simulation will use CPE8 elements as specified in the input deck.
The nodal loads will be applied in the y-direction as specified in the input deck.
Run the CalculiX analysis using either `ccx -i planestrain2` or `ccx planestrain2`.
Determine if the run succeeded by checking the `planestrain2.sta` file for a successful completion message.
Create a `results.json` file in the working directory.
The `results.json` file must contain a "solver" key with the value "calculix".
The `results.json` file must contain a "case_id" key with the value "planestrain2".
The `results.json` file must contain a "status" key with the value "success" or "error".
The `results.json` file must contain a "ccx_version" key with the version string from `ccx -v`.
The `results.json` file must contain an "artifacts" key with an empty array as its value.
The `results.json` file must contain a "notes" key that records the exact ccx command used.
If the run fails, the "notes" key must also include the error message and the file that indicated the failure.
