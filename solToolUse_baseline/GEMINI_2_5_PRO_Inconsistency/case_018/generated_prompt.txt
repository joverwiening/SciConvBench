The simulation will be performed using the FEniCS legacy library (dolfin).
The problem to be solved is 2D small-strain linear elasticity under a plane-stress assumption.
The domain has a unit thickness of 1.0 m.
The geometry is an L-shaped domain, formed by a 1.0x1.0 square with a 0.5x0.5 square removed from the top-right corner.
The mesh will be generated with 64 elements along each of the outer 1.0-length edges.
The material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, and density ρ = 2700 kg/m^3.
The left boundary, where x=0, is fixed with a zero-displacement Dirichlet boundary condition.
All other boundaries are traction-free.
A body force due to gravity is included, with g = 9.81 m/s^2 acting in the negative y-direction.
A concentrated vertical point load of -2.65e4 N is applied at the re-entrant corner, point (0.5, 0.5).
The concentrated load is to be implemented using a `PointSource` on the y-component of the displacement vector.
The displacement field will be discretized using continuous, second-degree (quadratic) Lagrange elements.
The linear system will be solved using a direct solver.
The von Mises stress will be computed from the in-plane Cauchy stress components.
A plot of the displacement magnitude will be generated as an output.
A plot of the von Mises stress distribution will be generated as an output.
