Solve a 2D plane-stress linear elasticity problem using the FEniCS legacy library (dolfin).
The geometry is a rectangle of size 1.0m by 0.5m.
A circular hole with a radius of 0.1m is centered at (0.5, 0.25).
The material has a Young's modulus E = 70e9 Pa and a Poisson's ratio ν = 0.33.
The material has a density ρ = 2700 kg/m^3.
A body force representing gravity, f = (0, -ρ*g) with g = 9.81 m/s^2, is applied to the domain.
The left edge of the plate (x=0) is clamped.
A point load of (+3000, 0) N is applied at the coordinate (1.0, 0.3).
A point load of (-3000, 0) N is applied at the coordinate (1.0, 0.2).
Implement the point loads using the `PointSource` class.
The boundary of the circular hole is traction-free.
Model the problem under the plane-stress assumption with unit thickness.
Generate a mesh with a resolution corresponding to approximately 64 elements along the outer boundary edges.
Use second-order Lagrange elements for the vector-valued displacement function space.
Solve the linear system using a direct solver.
Compute the displacement field.
Compute the von Mises stress field from the in-plane Cauchy stress.
Provide the results as plot images showing the displacement magnitude and the von Mises stress distribution.
