Case ID: case_027
Use FEniCS legacy (dolfin).
Solver: small-strain linear elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with a vector-valued displacement space and a direct linear solver.
Task:
Analyze stress in a right triangular domain with clamped base (y=0) and horizontal shear traction along sloping edge (x+2y=1). Implement linear elasticity with E=70e9 Pa, ν=0.33 under gravity loading. Compute displacement magnitude and von Mises stress distributions.
Case details:
Material: E=70e9, ν=0.33, ρ=2700 kg/m^3, g=9.81 m/s^2. Geometry: Right triangle (0,0)-(1,0)-(0,0.5). Loads: τ_x=2000 Pa (slope). Boundaries: y=0 fixed. Mesh: 64 elements.
Implementation notes:
Treat the 2D domain as plane stress with unit thickness and use the reduced plane-stress constitutive law.
Compute von Mises from the in-plane Cauchy stress field.
The horizontal shear traction acts along the sloping boundary but remains a global x-directed traction, not a normal pressure.
