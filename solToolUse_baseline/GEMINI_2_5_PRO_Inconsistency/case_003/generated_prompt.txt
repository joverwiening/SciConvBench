Use the FEniCS legacy library (dolfin).
Solve a 2D small-strain linear elasticity problem for a plate with two circular holes.
The model is based on a plane-stress assumption.
Use the reduced plane-stress constitutive law.
The geometry is a rectangular plate defined by the domain (0, 1.0) x (0, 0.20) meters.
The plate contains two circular holes, each with a radius of 0.04 m.
The first hole is centered at (0.33, 0.10) m.
The second hole is centered at (0.67, 0.10) m.
The material's Young's modulus is E = 200 GPa.
The material's Poisson's ratio is ν = 0.30.
The left boundary (x = 0) is clamped, with displacement u = (0, 0).
The right boundary (x = 1.0) has an applied line traction of t = (2e6, 0) N/m.
The top, bottom, and hole boundaries are traction-free.
Use a direct linear solver.
The mesh should be composed of triangular elements.
The mesh should be refined near the boundaries of the circular holes.
Use a vector-valued function space for the displacement field.
The displacement function space should use Lagrange elements of polynomial degree 2.
Compute the von Mises stress field.
Save the von Mises stress field as a PNG file named q4_vm.png.
Save the displacement field in XDMF format to a file named q4_displacement.xdmf.
Report the maximum von Mises stress value found on the boundaries of the holes.
Calculate and report the stress concentration factor Kt, defined as the maximum von Mises stress divided by 2 MPa.
