Create a file named segststate.inp in the working directory.
The content of segststate.inp must be the exact text provided in the "Input deck (`segststate.inp`)" section.
The finite element model will use C3D20 elements.
The simulation will apply P6 pressure loads of 100.0 as defined in the input file.
The simulation will have one `*NODE PRINT` command at the end of the second step.
Run the CalculiX analysis using a command such as `ccx -i segststate` or `ccx segststate`.
Determine if the run was successful by checking for a successful termination message (e.g., 'JOB COMPLETED') in the `segststate.sta` file.
Create a `results.json` file in the working directory.
The `results.json` file must conform to the specified schema.
The `solver` field in `results.json` should be "calculix".
The `case_id` field in `results.json` should be "segststate".
The `status` field should be "success" if the run completed successfully, and "error" otherwise.
The `ccx_version` field should contain the version string from the `ccx -v` command.
The `artifacts` field should be an empty list.
The `notes` field should contain the exact CalculiX command used.
If the run fails, the `notes` field must also include the error message and the name of the file that indicated the failure.
