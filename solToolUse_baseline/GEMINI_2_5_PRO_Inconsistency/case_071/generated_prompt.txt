The job name is `beampt`.
The input file must be named `beampt.inp`.
Create the file `beampt.inp` in the working directory with the exact content provided in the prompt.
The thermal expansion definition must be included in the `beampt.inp` file as specified.
Run the CalculiX analysis using either the `ccx -i beampt` or `ccx beampt` command.
Check the `beampt.sta` file for a successful termination message like 'JOB COMPLETED' to determine the run status.
Create a `results.json` file in the working directory.
The `results.json` file will contain the solver name "calculix" and the case ID "beampt".
The `status` field in the JSON will be "success" for a successful run or "error" for a failed run.
The `ccx_version` field will contain the output of the `ccx -v` command.
The `artifacts` field in the JSON will be an empty list.
The `notes` field will record the exact command used for the simulation.
If the simulation fails, the `notes` field will also include the error message and the file indicating the failure.
