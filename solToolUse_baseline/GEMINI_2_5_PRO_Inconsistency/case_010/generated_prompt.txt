Case ID is case_010.
Use the FEniCS legacy (dolfin) library.
Solve a 2D small-strain orthotropic plane-stress elasticity problem.
The geometry is a rectangle defined by (0, 1.0) x (0, 0.20) meters.
Use a structured mesh of 50 by 25 triangular elements.
Use second-order Lagrange elements for the displacement field.
The material's local axes are rotated 30 degrees anticlockwise relative to the global axes.
The local orthotropic material properties are E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
The orthotropic stiffness matrix should be formulated in the local material frame and then rotated by +30 degrees into the global frame for the analysis.
The bottom edge (y=0) is fixed with zero displacement.
The top edge (y=0.20) has a uniform downward line traction of (0, -10 MPa*m).
The vertical sides (x=0 and x=1) are traction-free.
Use a direct linear solver.
Save a color map of the x-component of displacement (u_x) to a file named q8_ux.png.
Save a color map of the von Mises stress to a file named q8_vm.png.
Project the stress field onto a piecewise constant function space (DG0) for visualization and output.
Write the displacement and stress fields to an XDMF file named q8_solution.xdmf.
