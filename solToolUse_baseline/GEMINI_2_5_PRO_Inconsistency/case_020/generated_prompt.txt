Case ID is case_020.
Use the FEniCS legacy (dolfin) library.
Solve a 2D small-strain linear elasticity problem for a rectangular plate.
The model is for a plane-stress condition with unit thickness.
The geometry is a rectangle defined by the domain (0, 1.0) x (0, 0.20) meters.
Use a uniform structured mesh with 40 subdivisions in the x-direction and 8 in the y-direction.
The material has a Young's modulus of 200 GPa and a Poisson's ratio of 0.30.
The left edge (x = 0) is fixed, with displacement u = (0, 0).
The top edge (y = 0.20) has a uniform downward traction of 2000 N/m applied.
The right edge (x = 1.0) and bottom edge (y = 0) are traction-free.
The displacement function space is a vector-valued space using first-degree Lagrange elements.
Solve the linear system using a direct solver.
Save a color map of the vertical displacement component (u_y) to a file named q2_uy.png.
The title for the color map plot will be "Vertical Displacement (u_y)".
Save the resulting displacement vector field to XDMF files with the base name q2_displacement.
