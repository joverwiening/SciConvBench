Use the FEniCS legacy library (dolfin).
The task is to solve a 2D plane-strain, nearly incompressible, small-strain elasticity problem.
The geometry is a rectangular strip defined by the domain (0, 1.0) x (0, 0.20) meters.
Create a structured mesh of the domain with 100 elements in the x-direction and 20 in the y-direction.
The mesh elements will be triangles.
The material model is linear elasticity with Young's modulus E = 5 MPa and Poisson's ratio ν = 0.49.
Use a mixed displacement-pressure formulation.
The finite element for displacement is a continuous piecewise quadratic (P2) vector element.
The finite element for pressure is a continuous piecewise linear (P1) scalar element.
The left edge of the strip (x=0) is fixed, with u_x = 0 and u_y = 0.
The right edge of the strip (x=1.0) has a prescribed displacement of u_x = 0.03 m and u_y = 0.
The top and bottom edges of the strip are traction-free.
Solve the linear system using a direct saddle-point solver.
Save a color map of the displacement magnitude |u| to a file named q10_disp.png.
Save the displacement field in XDMF format to a file named q10_displacement.xdmf.
Do not save the pressure field.
