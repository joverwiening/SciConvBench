The job name is axial.
The input file must be named axial.inp.
Create the file axial.inp in the working directory using the provided content.
The analysis will use CAX8R elements as specified in the input file.
The analysis will apply the centrifugal load as specified in the input file.
Run the CalculiX analysis using either `ccx -i axial` or `ccx axial`.
Determine if the run succeeded by checking for a successful termination message in the `axial.sta` file.
Write a `results.json` file in the working directory.
The `results.json` file must contain a "solver" field set to "calculix".
The `results.json` file must contain a "case_id" field set to "axial".
The `results.json` file must contain a "status" field set to "success" or "error" based on the run outcome.
The `results.json` file must contain a "ccx_version" field with the version string from the `ccx -v` command.
The `results.json` file must contain an "artifacts" array listing the paths to `axial.inp`, `axial.sta`, and `axial.dat`.
The `results.json` file must contain a "notes" field with the exact CalculiX command used.
If the run fails, the "notes" field must also include the error message and the file that indicated the failure.
