Q: **What you are trying to do**

You want a *distance* multi‑point constraint (MPC) that keeps the distance
between node 129 and node 10 equal to a prescribed value.  
In Abaqus a distance constraint is entered with the keyword **\*MPC** and
the type **DIST**.  

The syntax of the **DIST** constraint is

```
*MPC
DIST, mpc_id, node_a, node_b, node_c, node_d
```

* `mpc_id` – an integer that uniquely identifies the constraint.  
* `node_a – node_b` – the first pair of nodes that defines the “reference”
  distance.  
* `node_c – node_d` – the second pair of nodes that defines the “controlled”
  distance.  

During the analysis Abaqus enforces  

```
|r(node_a) – r(node_b)|  =  |r(node_c) – r(node_d)|
```

where **r(·)** is the current position vector of a node.

---

### Why the line you wrote is wrong

```
*MPC
DIST,129,129,129,10,10,10,262
```

* You have **seven** numbers after the type name, while the **DIST**
  constraint needs **exactly five** (mpc‑id + four node numbers).  
* The node numbers are repeated (129,129,129 …) which makes no sense for a
  distance constraint.  
* The last entry (262) is interpreted as a *sixth* node, which is not allowed
  for the **DIST** type.

Because of the wrong syntax Abaqus reports the generic error *“the user
subroutine *MPC is not supported”* (the parser cannot recognise the line as a
valid MPC definition).

---

## Correct way to write the distance constraint

Assume you want the distance between node 129 and node 10 to stay **exactly the
same** as the distance between node 262 and a second reference node
(e.g. node 263).  If you want the distance to be *zero* (i.e. nodes 129 and 10
must stay coincident) you can use node 262 twice – the distance between a node
and itself is zero.

### Example 1 – keep nodes 129 and 10 coincident (zero distance)

```abaqus
*NODE, NSET=REFPOINT
262, 7.200000, 0., 0.          ! reference point (fixed in X later)

*MPC
DIST, 1, 129, 10, 262, 262    ! distance(129‑10) = distance(262‑262) = 0
```

*`1`* is the MPC identifier (any positive integer that is not used elsewhere).

### Example 2 – keep the distance equal to a prescribed non‑zero value

If you want the distance to be, say, **0.5 mm**, create a second reference node
(at a known location) that is 0.5 mm away from node 262:

```abaqus
*NODE, NSET=REFPOINT
262, 7.200000, 0., 0.
263, 7.200500, 0., 0.          ! 0.5 mm away from node 262 in X

*MPC
DIST, 2, 129, 10, 262, 263    ! distance(129‑10) = distance(262‑263) = 0.5 mm
```

Now the distance between nodes 129 and 10 will be forced to stay 0.5 mm
throughout the analysis.

You are running a **static analysis** (or a series of static load steps) and you want to apply a series of displacement‑type boundary conditions on node 262.

## 2. Why the error occurs  

| Problem | Why it is illegal | What Abaqus reports |
|---------|-------------------|---------------------|
| Missing `*END STEP` | Every step has to be closed before the next keyword can be read. | “The *STEP keyword must be terminated by *END STEP.” |
| Use of `*END` alone | `*END` is not a keyword in the Abaqus input language. | “*END is not a valid keyword.” |

3. 若需要在同一步内施加多种载荷，只要它们都在 `*END STEP` 之前即可，顺序不受限制。

1. 打开文件（推荐使用 **Notepad++ / VS Code / Sublime Text**）。  
2. 正则搜索并删除：  

   - `^\*END\s*$` （仅 `*END` 行）  
   - `^\*$` （仅一个星号的行）  

3. 再次搜索确认已无匹配项。  

> 合法的结束关键字只有 `*END STEP`（以及可选的 `*END INPUT`，后者可以省略）。

### 2.3 合并/去除冗余的约束/载荷卡  

| 场景 | 正确做法 |
|------|----------|
| 同一步内 **同一节点‑自由度** 多次出现 | **保留一次**，若数值需要变化则在 **后续 STEP** 中重新写该卡片。 |


## 3️⃣ 编辑后 **快速自检 Checklist**  

| 检查项 | 操作方法 | 合格标准 |
|--------|----------|----------|
| **① `*STEP` 与 `*END STEP` 数目匹配** | 搜索 `*STEP` 与 `*END STEP`，分别计数 | 两者数量相同，且每个 `*END STEP` 位于对应 `*STEP` 之后 |

| **③ 每个 `*STEP` 内至少有一种分析指令** | 检查 `*STEP` 块内部是否出现 `*STATIC`、`*HEAT TRANSFER`、`*DYNAMIC` 等 | 每个 STEP 至少有一条 |

| **⑤ 同一步内不出现重复约束/载荷** | 手动或脚本检查同一节点‑自由度或同一单元‑方向是否出现多次 | 只出现一次（若数值需要变化则在后续 STEP 中重新写） |
| **⑥ 参数完整且符合格式** | 逐卡片检查列数、数据类型 | 所有卡片均满足官方手册规定的列数和顺序 |

## 4️⃣ TL;DR（最关键的三点）  

1. **每个 `*STEP` 必须以 `*END STEP` 结束，且内部必须至少包含一条分析指令（如 `*STATIC`）。**  
2. **`*END`（或单独的 `*`）不是合法关键字，全部删除。** 合法的结束关键字只有 `*END STEP`（可选 `*END INPUT`）。  
3. **相同的约束/载荷卡（如 `*BOUNDARY`）只能写一次，若数值需要变化则在后续 STEP 中重新写。**  

把文件整理成 **“STEP → 分析指令 → 约束/载荷 → END STEP”** 的完整结构后，作业应能顺利进入求解阶段。若还有其他报错，请把完整的错误日志贴出来，我们再进一步排查。祝您顺利求解！
