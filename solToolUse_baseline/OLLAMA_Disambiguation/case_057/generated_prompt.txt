Create the file `case_057.inp` in the working directory containing the provided input deck.  
Run CalculiX with the command `ccx -i case_057`.  
Check the file `case_057.sta` for a successful termination message such as “JOB COMPLETED”.  
Obtain the CalculiX version string by executing `ccx -v`.  
Write a `results.json` file in the working directory with the following fields:  
- `"solver"` set to `"calculix"`.  
- `"case_id"` set to `"case_057"`.  
- `"status"` set to `"success"` if the run completed successfully, otherwise `"error"`.  
- `"ccx_version"` set to the version string obtained from `ccx -v`.  
- `"artifacts"` set to an empty array.  
- `"notes"` containing the exact command used (`ccx -i case_057`) and, if the run failed, the error message and the file that indicated the failure.
