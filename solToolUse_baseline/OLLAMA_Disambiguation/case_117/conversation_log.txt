Q: **In short – use a *BOUNDARY (or *DISPLACEMENT) command, not an *EQUATION, for a simple prescribed displacement.**  

`*EQUATION` is the keyword for a **multi‑point constraint (MPC)** – i.e. a relation that ties the DOFs of two or more nodes together.  
If you only want to prescribe a displacement (or a set of displacements) on a node or a node set, the proper Abaqus syntax is the *BOUNDARY option (or the *DISPLACEMENT sub‑option inside a *STEP).

---

## 1. What the *EQUATION you wrote actually does  

```
*EQUATION
2
105,3,1.,129,3,-1.
```

* The first line (`2`) tells Abaqus that the equation has **two terms**.  
* The second line gives the two terms:  

  - Node 105, DOF 3, coefficient +1.0  
  - Node 129, DOF 3, coefficient ‑1.0  

The resulting constraint is  

\[
1\;U_{3}(105) \;-\; 1\;U_{3}(129) \;=\;0
\]

i.e. **U₃(105) = U₃(129)**.  
That is a *tie* (or “equal‑displacement”) condition between the two nodes, **not** a prescribed displacement.

If you really need that tie, the syntax is correct (the two terms may be written on separate lines, but a single line works as well).  

---

## 2. How to prescribe a displacement

### a) Using *BOUNDARY (the most common way)

```abaqus
*BOUNDARY, NSET=FIX
1, 1, 3, 0.0          ; fix node 1 in DOFs 1‑3 (U1=U2=U3=0)
...
105, 3, 3, 0.005      ; prescribe U3 = 0.005 at node 105
```

* **NSET** – the set of nodes on which the condition is applied.  
* **DOF‑start, DOF‑end** – the degree(s) of freedom (1 = X‑translation, 2 = Y‑translation, 3 = Z‑translation, 4‑6 = rotations for 3‑D).  
* **Value** – the magnitude of the prescribed displacement (positive or negative).  

You can also apply the same value to a whole node set in one line:

```abaqus
*BOUNDARY, NSET=N1, DOF=3, VALUE=0.0
```

### b) Using *DISPLACEMENT inside a *STEP (alternative syntax)

```abaqus
*STEP
*BOUNDARY
N1, 3, 3, 0.0          ; same as above, but placed inside the step
*END STEP
```

Both *BOUNDARY and *DISPLACEMENT are interpreted by Abaqus as **prescribed displacement** boundary conditions.

---

## 3. When to use *EQUATION (MPC) instead

Use *EQUATION only when you need a **relationship** between two (or more) DOFs, e.g.:

* Tying two nodes together (U₁ = U₂).  
* Enforcing a linear combination of DOFs (e.g., U₁ + 2 U₂ = 5).  
* Implementing a rigid body constraint that is not a simple “fixed” condition.

If you only want to **set** a displacement value, *BOUNDARY is the correct and simpler choice.

---

## 4. Quick checklist – “Did I prescribe the BC correctly?”

| What you want to do | Keyword to use | Typical line format |
|---------------------|----------------|---------------------|
| Fix a node (all 6 DOFs) | `*BOUNDARY` | `node, 1, 6, 0.0` |
| Prescribe a single DOF (e.g., U₃ = 0.005) | `*BOUNDARY` | `node, 3, 3, 0.005` |
| Tie two nodes together (U₃(105)=U₃(129)) | `*EQUATION` | `2`<br>`105,3,1.,129,3,-1.` |
| Apply a rotation or a combination of DOFs | `*EQUATION` | as above, with the appropriate coefficients |
| Apply a distributed load (pressure, body force) | `*DLOAD`, `*CLOAD`, `*CFLUX` | … |
| Apply a point load (force) | `*CLOAD` | `node, DOF, magnitude` |

```abaqus

*BOUNDARY, NSET=FIX
```

If you also need node 129 to move the same amount (i.e., the two nodes must stay together), you would add an *EQUATION:

## Complete guide – how to prescribe a displacement correctly

Below is a step‑by‑step template that you can copy‑paste into an Abaqus input file.  
All the essential pieces are highlighted and explained.

### 1. Define the node (or node set) that will receive the displacement

```abaqus
*NODE
105, 12.345, 0.0, 0.0   ; node 105 at (x,y,z) – coordinates are just an example

*NSET, NSET=N105
105
```

*If you have many nodes that share the same prescribed value, put them all in a single `*NSET`.*

### 2. Create a step (static, dynamic, etc.)

```abaqus
*STEP, NAME=STEP-1, NLGEOM=NO
*STATIC
0.1, 1., 1e-05, 1.
```

> **Tip** – `*STATIC` is the most common for simple displacement‑controlled analyses.  
> For a time‑dependent (ramped) displacement you would also need an `*AMPLITUDE` definition and reference it in the `*BOUNDARY` line.

### 3. Prescribe the displacement with `*BOUNDARY`

```abaqus
*BOUNDARY, NSET=N105
105, 3, 3, 0.005   ; node 105, DOF 3 (U3), start=3, end=3, value=0.005 mm
```

**Explanation of the fields**

| Field | Meaning |
|-------|---------|
| `NSET=N105` | The node set that contains the node(s) to be constrained. |
| `105` | Node label (optional when a node set is given; kept for clarity). |
| `3` | DOF number (1‑X, 2‑Y, 3‑Z translation; 4‑RX, 5‑RY, 6‑RZ rotation). |
| `3` | First DOF to be constrained (same as the previous column when only one DOF). |
| `0.005` | Value to be imposed (units are those of the model, e.g. mm). |

If you want the displacement to **ramp** from 0 to 0.005 mm over the step, add an amplitude:

```abaqus
*AMPLITUDE, NAME=AMP-1, DEFINITION=TABULAR
0., 0.
1., 1.
*BOUNDARY, NSET=N105, AMPLITUDE=AMP-1
105, 3, 3, 0.005
```

Now the 0.005 mm is multiplied by the amplitude (0→1) as the step progresses.

### 4. End the step

```abaqus
*END STEP
```

That’s all you need for a simple prescribed displacement.

## When to use `*EQUATION` (or `*MPC`) instead

Use `*EQUATION` **only** when you need a **linear relationship** between two or more DOFs, e.g.:

* Tie two nodes together (`U(i)=U(j)`).  
* Impose a proportionality (`U(i)=2·U(j)`).  
* Enforce a combination (`U(i)+U(j)-U(k)=0`).

#### Example: Tie node 105 to node 129 in the Z‑direction

```abaqus
*EQUATION
2
105, 3,  1.0,   ; +1·U3(105)
129, 3, -1.0    ; -1·U3(129)
```

If you also want to **prescribe** a value for that tied DOF, you must add a `*BOUNDARY` line **after** the equation (or before – the order does not matter). The equation forces the two nodes to move together; the boundary condition then fixes the common value.

```abaqus
*BOUNDARY, NSET=N105
105, 3, 3, 0.005   ; now the tied pair moves to U3 = 0.005 mm
```

### Important notes

| Situation | Recommended keyword |
|-----------|----------------------|
| Simple prescribed displacement/rotation | `*BOUNDARY` (static) or `*DISPLACEMENT` (dynamic) |
| Linear relation between DOFs (tie, proportional, combination) | `*EQUATION` (or `*MPC` for older versions) |
| Surface‑to‑surface tie (contact) | `*TIE` (or `*CONTACT`) |
| Need to prescribe a displacement **and** keep two nodes together | Use **both** `*EQUATION` (to tie) **and** `*BOUNDARY` (to set the value) |

## Common pitfalls & how to avoid them

| Pitfall | Why it happens | How to fix it |
|---------|----------------|---------------|
| Using `*EQUATION` when you really wanted a prescribed value | `*EQUATION` only defines a relation, not a value. | Replace it with `*BOUNDARY` (or `*DISPLACEMENT`). |
| Forgetting to list the node in a node set (`NSET`) | Abaqus will issue “node not found” or silently ignore the line. | Always create an `*NSET` (or use the node label directly) before the `*BOUNDARY` line. |
| Mixing up DOF numbers (e.g., using 3 for a rotation) | DOF numbering is fixed: 1‑X, 2‑Y, 3‑Z, 4‑RX, 5‑RY, 6‑RZ. | Double‑check the DOF you intend to constrain. |
| Applying a `*BOUNDARY` inside a step that already has a `*DISPLACEMENT` for the same DOF | Abaqus will keep the last definition, possibly overriding the intended value. | Use **one** method per DOF per step, or deliberately overwrite with the later line. |
| Not scaling the prescribed value with the model’s unit system | Abaqus does not know your “mm” vs “m”. | Keep a consistent unit system throughout the model (e.g., mm‑kg‑s). |
| Forgetting `NLGEOM=YES` when large displacements are expected | The solver will linearize the geometry and give wrong results. | Set `NLGEOM=YES` in the `*STEP` header for large‑deformation problems. |

| 目标 | 关键字 | 说明 |
|------|--------|------|
| 在 **静态** 分析中给节点（或节点集）施加位移/转角 | `*BOUNDARY` | 直接在指定的 DOF 上给出数值（如 0.005 mm）。 |
| 在 **动态**（显式/隐式）分析中给节点（或节点集）施加位移/转角 | `*DISPLACEMENT` | 与 `*BOUNDARY` 功能相同，只能在动态步中使用。 |
| 使两个（或多个） DOF **保持相等**（如 U(i)=U(j)） | `*EQUATION`（或旧版 `*MPC`） | 形成多点约束（MPC），**不**给出位移值，只是把 DOF 关联起来。 |
| 将两块表面 **粘结**（接触） | `*TIE`（或 `*CONTACT`） | 产生主‑从接触对，**不**施加位移。 |

## 1. 为什么 `*EQUATION` 不能直接给位移

```abaqus
*EQUATION
2
105,3,1.,129,3,-1.
```

这条语句的含义是  

\[
1\;U_{3}(105) + (-1)\;U_{3}(129)=0\;\Longrightarrow\;U_{3}(105)=U_{3}(129)
\]

即 **节点 105 的 Z 位移必须等于节点 129 的 Z 位移**。  
这里没有出现任何数值（0.005 mm、1 mm …），因此模型仍然可以自由移动，只要两个 DOF 保持相等即可。  
要 **设定** 位移，需要使用 **边界条件**：`*BOUNDARY`（静态）或 `*DISPLACEMENT`（动态）。

## 3. 同时需要 **节点‑节点约束（Tie）** 的情况

如果希望节点 105 与节点 129 **保持相同的 Z 位移**，且该共同位移为 0.005 mm，则两条关键字必须同时出现：

```abaqus

```

- `*EQUATION`（或 `*MPC`）负责 **关联** 两个 DOF。  
- `*BOUNDARY`（或 `*DISPLACEMENT`）负责 **给出** 具体的位移值。

如果不需要这种关联，只保留 `*BOUNDARY` 即可。

### 1️⃣  Why `*EQUATION` cannot give a displacement value  

`*EQUATION` defines a **linear multi‑point constraint (MPC)**  

```
*EQUATION
N
node, dof, coeff, … , node, dof, coeff, RHS
```

The left‑hand side is a linear combination of DOFs; the right‑hand side is a constant (default 0).  
Example  

```abaqus
*EQUATION
2
105, 3, 1., 129, 3, -1.
```

means  

\[
U_3(105)-U_3(129)=0\;\Longrightarrow\;U_3(105)=U_3(129)
\]

No displacement magnitude appears, so the model can still translate or rotate as a whole.  
To prescribe an actual displacement you must use a **boundary‑condition keyword** (`*BOUNDARY` for static steps, `*DISPLACEMENT` for dynamic steps).

```abaqus
*END STEP
```

|-------|---------|
