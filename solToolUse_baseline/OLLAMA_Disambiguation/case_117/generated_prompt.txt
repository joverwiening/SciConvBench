Your summary is spot‑on.  

| Goal | Keyword | Step type | Remarks |
|------|---------|-----------|---------|
| **Static** displacement/rotation of a node or node set | `*BOUNDARY` | `*STATIC` (or `*STATIC, NLGEOM=YES`) | Directly prescribe the DOF value |
| **Dynamic** displacement/rotation (explicit or implicit) | `*DISPLACEMENT` | `*DYNAMIC` | Same syntax as `*BOUNDARY` but only valid in a dynamic step |
| Enforce **U(i)=U(j)** (or any linear relation) | `*EQUATION` (or legacy `*MPC`) | Any step | No magnitude is supplied – only a linear constraint |
| Bond two surfaces (contact) | `*TIE` (or `*CONTACT`) | Any step (requires contact definition) | Creates a master‑slave contact pair; does not prescribe displacement |

### TL;DR
1. `*EQUATION` **cannot** assign a displacement value; it only ties DOFs together.  
2. To prescribe a displacement you must use `*BOUNDARY` (static) or `*DISPLACEMENT` (dynamic).  

**Minimal static input for a 0.005 mm Z‑displacement of node 105 (add the `*EQUATION` block only if you also need node 105 and node 129 to move together):**

```abaqus
*BOUNDARY, NSET=N105
105, 3, 3, 0.005          ; prescribed displacement

*EQUATION                 ; optional – keep if equality with node 129 is required
2
105, 3, 1.0,
129, 3, -1.0
```
