Use FEniCS legacy (dolfin) to solve a small‑strain linear elasticity problem in 2D plane‑stress.  
Create an L‑shaped domain consisting of a unit square with a 0.5 × 0.5 cutout at the lower‑left corner (0 ≤ x ≤ 0.5, 0 ≤ y ≤ 0.5).  
Generate a mesh with 64 elements per edge using FEniCS built‑in geometry utilities (e.g., mshr).  
Use a first‑order vector‑valued finite element space (P1) for the displacement field.  
Apply material properties E = 70e9 Pa, ν = 0.33, density ρ = 2700 kg/m³ and gravity body force (0, ‑ρ g).  
Impose zero displacement (u = (0, 0)) on the left boundary (x = 0).  
Apply a linearly varying vertical traction on the right edge (x = 1) given by σ_yy(y) = ‑2.65×10⁴ y Pa, with σ_yy = 0 Pa at y = 0 and σ_yy = ‑2.65×10⁴ Pa at y = 1.  
Leave the top, bottom, and inner cut edges traction‑free.  
Use the reduced plane‑stress constitutive law for unit thickness.  
Solve the variational problem with a direct linear solver MUMPS.  
Compute the in‑plane Cauchy stress tensor and evaluate the von Mises stress from it.  
Export the nodal displacement field, stress tensor components, and von Mises stress to VTK/VTU files (displacement.vtu, stress.vtu, von_mises.vtu), to XDMF/HDF5 files (displacement.xdmf, stress.xdmf, von_mises.xdmf) and to CSV files (displacement.csv, stress.csv, von_mises.csv) for post‑processing.
