Use FEniCS legacy (dolfin) to solve a 2D plane‑stress linear elasticity problem on the rectangular domain Ω = (0, 1.0) m × (0, 0.20) m.  
Create a structured mesh with 100 elements in the x‑direction and 20 elements in the y‑direction.  
Set Poisson’s ratio ν = 0.30.  
Define the spatially varying Young’s modulus as E(y) = 100 GPa + 100 GPa · (y / 0.20) for 0 ≤ y ≤ 0.20 m.  
Treat the problem as plane stress with unit thickness using the reduced plane‑stress constitutive law.  
Apply displacement boundary conditions u_x = 0, u_y = 0 on the left edge (x = 0).  
Apply a uniform traction t = (2e6 Pa·m, 0) on the right edge (x = 1).  
Leave the top and bottom edges traction‑free.  
Solve the linear system with a direct linear solver, using PETSc LU (MUMPS).  
Save a colour map of the displacement magnitude |u| as q9_disp.png using the viridis colormap.  
Save the full displacement field in XDMF format as q9_disp.xdmf.
