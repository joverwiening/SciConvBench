Create a file named `case_083.inp` in the working directory containing the provided input deck.  
Run CalculiX using the command `ccx -i case_083` (or `ccx case_083` if the former fails).  
Check the file `case_083.sta` for a line indicating successful termination such as “JOB COMPLETED”.  
Create a file `results.json` in the working directory with the following fields:
- `"solver"` set to `"calculix"`.  
- `"case_id"` set to `"case_083"`.  
- `"status"` set to `"success"` if the job completed successfully, otherwise `"error"`.  
- `"ccx_version"` containing the version string obtained from `ccx -v` (or the closest equivalent output).  
- `"artifacts"` set to the list of extensions `[".dat", ".frd", ".log", ".sta"]`.  
- `"notes"` containing the exact command used to run CalculiX and, if the run failed, the error message and the file that indicated the failure.
