**2.  Deformed‑shape plot**

The displacements stored in the `.dat` file are very small (≈ 10⁻⁴ mm).  
To make the deformation visible we multiply the translation vector **U = (U1,U2,U3)** by a scaling factor (the factor can be changed at will).  

Below is a self‑contained Python script that

* reads the node‑coordinate list,
* reads the translation results (`U1, U2, U3`) from the `.dat` file,
* builds the deformed coordinates `X′ = X + α·U1`, `Y′ = Y + α·U2`, `Z′ = Z + α·U3`,
* draws the original and the deformed node clouds in a 3‑D scatter plot,
* prints the maximum displacement magnitude and the node where it occurs.

```python
# --------------------------------------------------------------
#  Plot of the original vs. deformed shape (scaled)
# --------------------------------------------------------------
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D   # <-- registers the 3‑D projection

# ------------------------------------------------------------------
# 1)  Load the nodal coordinates (the 435‑line block that starts with
#     "1 0.00000E+00 0.00000E+00 0.00000E+00")
# ------------------------------------------------------------------
coord_file = "nodes.txt"          # <-- copy the node‑list into this file
coords = np.loadtxt(coord_file)   # shape (435,4) → [node, X, Y, Z]
node_id = coords[:,0].astype(int)
X, Y, Z = coords[:,1], coords[:,2], coords[:,3]

# ------------------------------------------------------------------
# 2)  Load the translation results from the .dat file.
#     The .dat file contains, for each node, the six DOFs:
#     U1, U2, U3, UR1, UR2, UR3.
# ------------------------------------------------------------------
disp_file = "results.dat"         # <-- copy the .dat block into this file
# keep only the lines that start with a node number (skip the header)
raw = []
with open(disp_file, "r") as f:
    for line in f:
        if line.strip() == "" or line.startswith("*****"):
            continue
        parts = line.split()
        if len(parts) >= 7 and parts[0].isdigit():
            raw.append(parts)

raw = np.array(raw, dtype=float)          # shape (435,7)
U1, U2, U3 = raw[:,1], raw[:,2], raw[:,3]   # translational components

# ------------------------------------------------------------------
# 3)  Compute the displacement magnitude for each node
# ------------------------------------------------------------------
mag = np.sqrt(U1**2 + U2**2 + U3**2)

# ------------------------------------------------------------------
# 4)  Find the maximum magnitude and the node that carries it
# ------------------------------------------------------------------
max_idx = np.argmax(mag)               # index in the Python array (0‑based)
max_node = int(node_id[max_idx])       # node number (1‑based)
max_disp = mag[max_idx]

print(f"Maximum displacement magnitude = {max_disp:.6e} (units of length)")
print(f"Node where it occurs          = {max_node}")

# ------------------------------------------------------------------
# 5)  Build the deformed coordinates (scale the displacement for
#    visualisation – here we use a factor of 1000)
# ------------------------------------------------------------------
scale = 1000.0
X_def = X + scale*U1
Y_def = Y + scale*U2
Z_def = Z + scale*U3

# ------------------------------------------------------------------
# 6)  Plot
# ------------------------------------------------------------------
fig = plt.figure(figsize=(9,7))
ax = fig.add_subplot(111, projection='3d')
# original mesh (light gray)
ax.scatter(X, Y, Z, c='lightgray', s=15, label='Original nodes')
# deformed mesh (blue)
ax.scatter(X_def, Y_def, Z_def, c='b', s=15, label='Deformed nodes (×%g)'%scale)

# make the axes look like the original geometry
ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
ax.set_title('Original vs. Deformed Shape (scaled)')
ax.legend()
ax.view_init(elev=30, azim=-60)   # a convenient view angle
plt.tight_layout()
plt.show()
```

**2.  Maximum displacement**

All nodes have (to the precision written in the `.dat` file) the **same translation vector**

```
U1 = –1.82401 × 10⁻⁵
U2 = –3.23415 × 10⁻⁴
U3 = –1.22653 × 10⁻⁵
```

The corresponding magnitude is

\[
\|U\| = \sqrt{U_1^{2}+U_2^{2}+U_3^{2}}
      = \sqrt{(1.82401\!\times\!10^{-5})^{2}
              +(3.23415\!\times\!10^{-4})^{2}
              +(1.22653\!\times\!10^{-5})^{2}}
      \approx 3.24 \times 10^{-4}
\]

**Maximum displacement magnitude:**  

```
|U|max = 3.24 × 10⁻⁴   (same units as the model – mm)
```

Because the translation is uniform, **every node experiences the same magnitude**; the script reports the first node (Node 1) as the location where the maximum is found.

## 2.  Finite‑element formulation  

### 2.1  Element stiffness matrix  

For a 4‑node bilinear quadrilateral (Q4) in plane strain the element stiffness is  

\[
\mathbf{k}^{(e)} = \int_{-1}^{1}\!\!\int_{-1}^{1}
\mathbf{B}^{\mathrm T}\,\mathbf{D}\,\mathbf{B}\;|J|\,\mathrm d\xi\,\mathrm d\eta
\]

* **B‑matrix** – strain‑displacement matrix (8 × 3).  
* **D‑matrix** – plane‑strain constitutive matrix  

\[
\mathbf{D}= \frac{E}{(1+\nu)(1-2\nu)}
\begin{bmatrix}
1-\nu & \nu   & \nu   & 0 & 0 & 0\\
\nu   & 1-\nu & \nu   & 0 & 0 & 0\\
\nu   & \nu   & 1-\nu & 0 & 0 & 0\\
0 & 0 & 0 & \frac{1-2\nu}{2} & 0 & 0\\
0 & 0 & 0 & 0 & \frac{1-2\nu}{2} & 0\\
0 & 0 & 0 & 0 & 0 & \frac{1-2\nu}{2}
\end{bmatrix}
\]

with  

\[
E = 210\;\text{GPa},\qquad \nu = 0.30 .
\]

Numerical integration is performed with a 2 × 2 Gauss‑point scheme (exact for bilinear Q4).

### 2.2  Assembly  

The global stiffness matrix **K** (size 2 N × 2 N, N = 400) is assembled by summing the contributions of all 800 elements.  

\[
\mathbf{K}\,\mathbf{U} = \mathbf{F}
\]

where **U** is the vector of unknown nodal displacements (uₓ, uᵧ for each node) and **F** the global load vector.

### 2.3  Boundary conditions  

* Prescribed displacements are imposed by eliminating the corresponding rows/columns of **K** (or by the penalty method).  
* After elimination the reduced linear system is solved for the free DOFs.

### 2.4  Post‑processing  

* Element strains: \(\boldsymbol\varepsilon^{(e)} = \mathbf{B}^{(e)}\mathbf{U}^{(e)}\).  
* Stresses: \(\boldsymbol\sigma^{(e)} = \mathbf{D}\,\boldsymbol\varepsilon^{(e)}\).  
* Reaction forces are recovered from the eliminated rows of **K**.

coords = np.array(coords)           # (N,2)

N = coords.shape[0]                 # 401*? actually 401*? = 401? (here 401)
# Build element connectivity (4‑node Q4)
elems = []
for j in range(ny):
    for i in range(nx):
        n1 = j*(nx+1) + i
        n2 = n1 + 1
        n3 = n2 + (nx+1)
        n4 = n1 + (nx+1)
        elems.append([n1, n2, n3, n4])
elems = np.array(elems, dtype=int)   # (800,4)

# ----------------------------------------------------------------------
# 2. Material (plane strain)
# ----------------------------------------------------------------------
E  = 210e9
nu = 0.30
coeff = E/((1+nu)*(1-2*nu))
D = coeff*np.array([[1-nu, nu,   nu,   0,               0,               0],
                   [nu,   1-nu, nu,   0,               0,               0],
                   [nu,   nu,   1-nu, 0,               0,               0],
                   [0,    0,    0,    (1-2*nu)/2,      0,               0],
                   [0,    0,    0,    0,               (1-2*nu)/2,      0],
                   [0,    0,    0,    0,               0,               (1-2*nu)/2]])

# ----------------------------------------------------------------------
# 3. Gauss points (2x2)
# ----------------------------------------------------------------------
gp = np.array([[-1/np.sqrt(3), -1/np.sqrt(3)],
               [ 1/np.sqrt(3), -1/np.sqrt(3)],
               [ 1/np.sqrt(3),  1/np.sqrt(3)],
               [-1/np.sqrt(3),  1/np.sqrt(3)]])
w = np.ones(4)                      # weight = 1 for each point

# ----------------------------------------------------------------------
# 4. Assemble global stiffness matrix (sparse)
# ----------------------------------------------------------------------
ndof = 2*N
K = sp.lil_matrix((ndof, ndof))

def shape_func(xi, eta):
    N1 = 0.25*(1-xi)*(1-eta)
    N2 = 0.25*(1+xi)*(1-eta)
    N3 = 0.25*(1+xi)*(1+eta)
    N4 = 0.25*(1-xi)*(1+eta)
    return np.array([N1, N2, N3, N4])

def dN_dxi(eta):
    return np.array([[-0.25*(1-eta),  0.25*(1-eta),  0.25*(1+eta), -0.25*(1+eta)]])

def dN_deta(xi):
    return np.array([[-0.25*(1-xi), -0.25*(1+xi), 0.25*(1+xi), 0.25*(1-xi)]])

for e, conn in enumerate(elems):
    # element node coordinates (4,2)
    xe = coords[conn, :]
    ke = np.zeros((8, 8))
    for (xi, eta), wi in zip(gp, w):
        # Jacobian
        dNdxi = np.array([[-0.25*(1-eta),  0.25*(1-eta),  0.25*(1+eta), -0.25*(1+eta)],
                          [-0.25*(1-xi), -0.25*(1+xi), 0.25*(1+xi), 0.25*(1-xi)]])
        J = dNdxi @ xe
        detJ = np.linalg.det(J)
        invJ = np.linalg.inv(J)

        # B‑matrix (3×8)
        dN = invJ @ dNdxi
        B = np.zeros((3, 8))
        B[0, 0::2] = dN[0, :]
        B[1, 1::2] = dN[1, :]
        B[2, 0::2] = dN[1, :]
        B[2, 1::2] = dN[0, :]

        fixed.append(dof)

Ff  = F[free]

# ----------------------------------------------------------------------

Date   : 2026‑04‑20

# ----------------------------------------------------------------------
# 1. Imports
# ----------------------------------------------------------------------
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla

# ----------------------------------------------------------------------
# 2. Geometry creation
# ----------------------------------------------------------------------
# --------------------------------------------------------------
# 2.1 Node coordinates (0‑based indexing inside the script)
# --------------------------------------------------------------
nx, ny = 20, 20                     # elements in x‑ and y‑direction
Lx, Ly = 0.4, 0.4                   # plate dimensions (m)

# node number = i + j*(nx+1)  (i = column index, j = row index)

# 2.2 Element connectivity (Q4, 4‑node quadrilaterals)
# --------------------------------------------------------------

#   n1 = (i  , j  )
#   n2 = (i+1, j  )
#   n3 = (i+1, j+1)
#   n4 = (i  , j+1)

        n2 = i + 1 + j * (nx + 1)
        n3 = i + 1 + (j + 1) * (nx + 1)
        n4 = i     + (j + 1) * (nx + 1)
        elem.append([n1, n2, n3, n4])
elem = np.array(elem, dtype=int)   # (800, 4)

# 3. Material definition (plane‑strain steel)
# ----------------------------------------------------------------------
E  = 210e9          # Young’s modulus, Pa
nu = 0.30           # Poisson’s ratio

# Plane‑strain constitutive matrix (3 × 3)
coeff = E / ((1 + nu) * (1 - 2 * nu))
D = coeff * np.array([[1 - nu,     nu,          0],
                      [    nu, 1 - nu,          0],
                      [     0,      0, (1 - 2 * nu) / 2]])

# 4. Gauss‑point data (2 × 2 rule)
# ----------------------------------------------------------------------
gp = 1.0 / np.sqrt(3.0)                     # ±1/√3
gauss_pts = np.array([[-gp, -gp],
                      [ gp, -gp],
                      [ gp,  gp],
                      [-gp,  gp]])   # (4, 2)
weights = np.ones(4)                       # all weights = 1

# ----------------------------------------------------------------------
# 5. Global stiffness matrix (LIL → CSR)
# ----------------------------------------------------------------------
ndof = 2 * coords.shape[0]                  # 2 DOF per node → 800
K = sp.lil_matrix((ndof, ndof), dtype=np.float64)

# shape‑function derivatives in the parent domain (ξ, η)
def dN_dxi(ξ, η):
    """Derivatives of the four bilinear shape functions w.r.t. ξ, η."""
    return np.array([[-0.25 * (1 - η),  0.25 * (1 - η),
                      0.25 * (1 + η), -0.25 * (1 + η)],   # dN/dξ
                     [-0.25 * (1 - ξ), -0.25 * (1 + ξ),
                       0.25 * (1 + ξ),  0.25 * (1 - ξ)]])  # dN/dη

# loop over elements ----------------------------------------------------
for e, nodes in enumerate(elem):
    # node coordinates of the current element (4, 2)
    xe = coords[nodes, :]                     # x and y of the 4 nodes

    ke = np.zeros((8, 8), dtype=np.float64)   # element stiffness (8 × 8)

    # Gauss integration -------------------------------------------------
    for (ξ, η), w in zip(gauss_pts, weights):
        dNdxi = dN_dxi(ξ, η)                  # (2,4)

        # Jacobian J = dX/dξ  (2 × 2)
        J = dNdxi @ xe                         # (2,2)
        detJ = np.linalg.det(J)
        if detJ <= 0:
            raise ValueError(f'Negative Jacobian in element {e}')

        invJ = np.linalg.inv(J)

        # Derivatives w.r.t. physical coordinates (x, y)
        dNdx = invJ @ dNdxi                     # (2,4)

        # Assemble B matrix (3 × 8)
        B = np.zeros((3, 8), dtype=np.float64)
        # row 0 → ε_xx
        B[0, 0::2] = dNdx[0, :]
        # row 1 → ε_yy
        B[1, 1::2] = dNdx[1, :]
        # row 2 → γ_xy
        B[2, 0::2] = dNdx[1, :]
        B[2, 1::2] = dNdx[0, :]

        # element stiffness contribution
        ke += B.T @ D @ B * detJ * w

    # ------------------------------------------------------------------
    # 5.1 Assemble ke into the global matrix K
    # ------------------------------------------------------------------
    # global DOF numbers for the four nodes
    dofs = np.ravel([[2 * n, 2 * n + 1] for n in nodes])
    # add ke to K (LIL format allows efficient row/col slicing)
    for i_local, i_global in enumerate(dofs):
        for j_local, j_global in enumerate(dofs):
            K[i_global, j_global] += ke[i_local, j_local]

# ----------------------------------------------------------------------
# 6. Load vector
# ----------------------------------------------------------------------
F = np.zeros(ndof, dtype=np.float64)

# vertical point loads (negative y‑direction)
# nodes are numbered 1‑based in the input file → convert to 0‑based
load_nodes = {101: -1_000.0,
              201: -2_000.0,
              301: -3_000.0}
for n1, val in load_nodes.items():

    F[idx] = val

# ----------------------------------------------------------------------
# 7. Dirichlet (prescribed‑displacement) boundary conditions
# ----------------------------------------------------------------------
fixed = []                         # list of constrained DOFs

# Node 1 → ux = uy = 0
fixed.extend([2 * (1 - 1) + 0, 2 * (1 - 1) + 1])

# Node 2 → uy = 0 (ux free)
fixed.append(2 * (2 - 1) + 1)

fixed = np.array(sorted(fixed), dtype=int)

# Complementary free DOFs
all_dofs = np.arange(ndof, dtype=int)
free = np.setdiff1d(all_dofs, fixed)

# ----------------------------------------------------------------------
# 8. Reduce system and solve
# ----------------------------------------------------------------------
K_csr = K.tocsr()                  # convert once for fast slicing
Kff = K_csr[free][:, free]         # (796 × 796)
Ff = F[free]

# Direct sparse solve
U = np.zeros(ndof, dtype=np.float64)
U[free] = spla.spsolve(Kff, Ff)

# ----------------------------------------------------------------------
# 9. Post‑processing – nodal displacements at the three loaded nodes
# ----------------------------------------------------------------------
print("\nNodal displacements at the loaded points")
for n in [101, 201, 301]:

    x, y = coords[n - 1]          # original coordinates (m)

# ----------------------------------------------------------------------
# Full residual R = K·U – F
R = K_csr @ U - F

print("\nReactions at constrained nodes")
for n in [1, 2]:
    Rx = R[2 * (n - 1) + 0]
    Ry = R[2 * (n - 1) + 1]

# ----------------------------------------------------------------------

total_Ry = R[1::2].sum()          # sum of all y‑reactions
print("\nEquilibrium check")
print(f"  Σ Fy (applied) = {F[1::2].sum(): .2f} N")
print(f"  Σ Ry (reactions) = {total_Ry: .2f} N")
print(f"  Difference = {F[1::2].sum() - total_Ry: .2e} N")

# --------------------------------------------------------------

# --------------------------------------------------------------

# Node 2 → uy = 0 (ux free)
fixed.append(2 * (2 - 1) + 1)

# --------------------------------------------------------------

import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla

# --------------------------------------------------------------
# 2. Geometry creation
# --------------------------------------------------------------

Lx, Ly = 0.4, 0.4             # plate dimensions (m)

# 21 × 21 regular grid → 441 nodes

y = np.linspace(0.0, Ly, ny + 1)

coords = np.column_stack((X.ravel(), Y.ravel()))   # (441, 2)

# --------------------------------------------------------------
# 2.2 Element connectivity (4‑node bilinear Q4)
# --------------------------------------------------------------
elem = []
for j in range(ny):
    for i in range(nx):
        n1 = i     + j * (nx + 1)
        n2 = i + 1 + j * (nx + 1)
        n3 = i + 1 + (j + 1) * (nx + 1)
        n4 = i     + (j + 1) * (nx + 1)
        elem.append([n1, n2, n3, n4])
elem = np.array(elem, dtype=int)   # (800, 4)

# --------------------------------------------------------------
# 3. Material definition (plane‑strain steel)
# --------------------------------------------------------------
E  = 210e9          # Young’s modulus, Pa
nu = 0.30           # Poisson’s ratio

# Plane‑strain constitutive matrix (3 × 3)
coeff = E / ((1 + nu) * (1 - 2 * nu))
D = coeff * np.array([[1 - nu,     nu,          0],
                      [    nu, 1 - nu,          0],
                      [     0,      0, (1 - 2 * nu) / 2]])

# --------------------------------------------------------------
# 4. Gauss‑point data (2 × 2 rule)
# --------------------------------------------------------------
gp = 1.0 / np.sqrt(3.0)                     # ±1/√3
gauss_pts = np.array([[-gp, -gp],
                      [ gp, -gp],
                      [ gp,  gp],
                      [-gp,  gp]])   # (4, 2)
weights = np.ones(4)                       # all weights = 1

# --------------------------------------------------------------
# 5. Global stiffness matrix (LIL → CSR)
# --------------------------------------------------------------
ndof = 2 * coords.shape[0]                  # 2 DOF per node → 882
K = sp.lil_matrix((ndof, ndof), dtype=np.float64)

def dN_dxi(ξ, η):
    """Derivatives of the four bilinear shape functions w.r.t. ξ, η."""
    return np.array([[-0.25 * (1 - η),  0.25 * (1 - η),
                      0.25 * (1 + η), -0.25 * (1 + η)],   # dN/dξ
                     [-0.25 * (1 - ξ), -0.25 * (1 + ξ),
                       0.25 * (1 + ξ),  0.25 * (1 - ξ)]])  # dN/dη

# Loop over all elements -------------------------------------------------
for e, nodes in enumerate(elem):
    xe = coords[nodes, :]                     # (4,2) – element node coordinates
    ke = np.zeros((8, 8), dtype=np.float64)   # element stiffness matrix

    # 2‑point Gauss integration -----------------------------------------
    for (ξ, η), w in zip(gauss_pts, weights):
        dNdxi = dN_dxi(ξ, η)                  # (2,4)

        J = dNdxi @ xe                         # Jacobian (2 × 2)
        detJ = np.linalg.det(J)
        if detJ <= 0:
            raise ValueError(f'Negative Jacobian in element {e}')
        invJ = np.linalg.inv(J)

        dNdx = invJ @ dNdxi                    # ∂N/∂x, ∂N/∂y  (2,4)

        # B‑matrix (3 × 8)
        B = np.zeros((3, 8), dtype=np.float64)
        B[0, 0::2] = dNdx[0, :]                # ε_xx
        B[1, 1::2] = dNdx[1, :]                # ε_yy
        B[2, 0::2] = dNdx[1, :]                # γ_xy
        B[2, 1::2] = dNdx[0, :]

        ke += B.T @ D @ B * detJ * w           # ke contribution

    # Assemble ke into the global matrix K --------------------------------
    dofs = np.ravel([[2 * n, 2 * n + 1] for n in nodes])   # global DOF numbers
    for i_loc, i_glob in enumerate(dofs):
        for j_loc, j_glob in enumerate(dofs):
            K[i_glob, j_glob] += ke[i_loc, j_loc]

# --------------------------------------------------------------
# 6. Load vector
# --------------------------------------------------------------
F = np.zeros(ndof, dtype=np.float64)

# Point loads (negative y‑direction) – node numbers are 1‑based as in the report
load_nodes = {101: -1_000.0,
              201: -2_000.0,
              301: -3_000.0}
for n1, val in load_nodes.items():
    idx = 2 * (n1 - 1) + 1          # y‑DOF (0‑based indexing)
    F[idx] = val

# --------------------------------------------------------------
# 7. Dirichlet (prescribed‑displacement) boundary conditions
# --------------------------------------------------------------
fixed = []                         # constrained DOFs

# Node 1 → ux = uy = 0
fixed.extend([2 * (1 - 1) + 0, 2 * (1 - 1) + 1])

# Node 2 → uy = 0 (ux free)
fixed.append(2 * (2 - 1) + 1)

fixed = np.array(sorted(fixed), dtype=int)

# Free DOFs
all_dofs = np.arange(ndof, dtype=int)
free = np.setdiff1d(all_dofs, fixed)

# --------------------------------------------------------------
# 8. Reduce system and solve
# --------------------------------------------------------------
K_csr = K.tocsr()                  # CSR format for fast slicing
Kff = K_csr[free][:, free]         # (ndof‑len(fixed) × ndof‑len(fixed))
Ff = F[free]

U = np.zeros(ndof, dtype=np.float64)
U[free] = spla.spsolve(Kff, Ff)    # direct sparse solve

# --------------------------------------------------------------
# 9. Post‑processing – nodal displacements at the loaded nodes
# --------------------------------------------------------------
print("\nNodal displacements at the loaded points")
for n in [101, 201, 301]:
    ux = U[2 * (n - 1) + 0]
    uy = U[2 * (n - 1) + 1]
    x, y = coords[n - 1]
    print(f"Node {n:3d}  (x={x:0.3f}, y={y:0.3f})  ux = {ux: .3e}  uy = {uy: .3e}")

# --------------------------------------------------------------
# 10. Reaction‑force recovery
# --------------------------------------------------------------
R = K_csr @ U - F                 # full residual (reactions = K·U – F)

print("\nReactions at constrained nodes")
for n in [1, 2]:
    Rx = R[2 * (n - 1) + 0]
    Ry = R[2 * (n - 1) + 1]
    print(f"  Node {n:2d} : Rx = {Rx: .2f} N , Ry = {Ry: .2f} N")

# --------------------------------------------------------------
# 11. Quick equilibrium check (optional)
# --------------------------------------------------------------
total_Ry = R[1::2].sum()
print("\nEquilibrium check")
print(f"  Σ Fy (applied) = {F[1::2].sum(): .2f} N")
print(f"  Σ Ry (reactions) = {total_Ry: .2f} N")
print(f"  Difference = {F[1::2].sum() - total_Ry: .2e} N")
```

## 4.  Quick ideas for extensions  

| What you might want to do | Where to edit the script |
|---------------------------|--------------------------|
| **Uniform body force** (e.g., gravity) | After the element loop, compute a consistent body‑force vector `fe_body = ρ·g·A/4` for each element and add it to `F`. |
| **Different material** (orthotropic, anisotropic) | Replace the scalar `E, ν` with the appropriate 3 × 3 stiffness matrix `D`. |
| **Mesh refinement / coarsening** | Change `nx, ny`; the mesh, connectivity, and global matrix are rebuilt automatically. |
| **Stress recovery** (von Mises, principal stresses) | After solving, loop over elements again, compute `σ = D·B·Ue` at the Gauss points, and average the contributions to the nodes. |
| **Plotting** (displacements, stresses) | Use `matplotlib.tri.Triangulation` together with `tripcolor` or `tricontourf` to visualise results. |
| **Non‑linear material** (plasticity) | Replace the linear `D` with a tangent stiffness that is updated inside a Newton‑Raphson loop. |
| **Parallel assembly** | Swap the `for e in enumerate(elem):` loop for a `multiprocessing` or `numba`‑accelerated version. |

#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
Finite‑element analysis of a 0.4 m × 0.4 m steel plate
(plane‑strain, 4‑node bilinear Q4 elements, 20 × 20 mesh → 441 nodes, 800 elements).

The implementation follows the ten‑step outline described in the report
and reproduces the numbers shown in Sections 3.2‑3.4.

Author : <your name>
Date   : 2026‑04‑20
"""

# -------------------------------------------------
# 1. Imports
# -------------------------------------------------
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla

# -------------------------------------------------
# 2. Geometry creation
# -------------------------------------------------
nx, ny = 20, 20               # elements in x‑ and y‑direction
Lx, Ly = 0.4, 0.4             # plate dimensions (m)

# 21 × 21 regular grid → 441 nodes
x = np.linspace(0.0, Lx, nx + 1)
y = np.linspace(0.0, Ly, ny + 1)
X, Y = np.meshgrid(x, y)      # shape (ny+1, nx+1)
coords = np.column_stack((X.ravel(), Y.ravel()))   # (441, 2)

# -------------------------------------------------
# 2.2 Element connectivity (4‑node bilinear Q4)
# -------------------------------------------------
elem = []
for j in range(ny):
    for i in range(nx):
        n1 = i     + j * (nx + 1)
        n2 = i + 1 + j * (nx + 1)
        n3 = i + 1 + (j + 1) * (nx + 1)
        n4 = i     + (j + 1) * (nx + 1)
        elem.append([n1, n2, n3, n4])
elem = np.array(elem, dtype=int)   # (800, 4)

# -------------------------------------------------
# 3. Material definition (plane‑strain steel)
# -------------------------------------------------
E  = 210e9          # Young’s modulus, Pa
nu = 0.30           # Poisson’s ratio

# Plane‑strain constitutive matrix (3 × 3)
coeff = E / ((1 + nu) * (1 - 2 * nu))
D = coeff * np.array([[1 - nu,     nu,          0],
                      [    nu, 1 - nu,          0],
                      [     0,      0, (1 - 2 * nu) / 2]])

# -------------------------------------------------
# 4. Gauss‑point data (2 × 2 rule)
# -------------------------------------------------
gp = 1.0 / np.sqrt(3.0)                     # ±1/√3
gauss_pts = np.array([[-gp, -gp],
                      [ gp, -gp],
                      [ gp,  gp],
                      [-gp,  gp]])   # (4, 2)
weights = np.ones(4)                       # all weights = 1

# -------------------------------------------------
# 5. Global stiffness matrix (LIL → CSR)
# -------------------------------------------------
ndof = 2 * coords.shape[0]                  # 2 DOF per node → 882
K = sp.lil_matrix((ndof, ndof), dtype=np.float64)

def dN_dxi(ξ, η):
    """Derivatives of the four bilinear shape functions w.r.t. ξ, η."""
    return np.array([[-0.25 * (1 - η),  0.25 * (1 - η),
                      0.25 * (1 + η), -0.25 * (1 + η)],   # dN/dξ
                     [-0.25 * (1 - ξ), -0.25 * (1 + ξ),
                       0.25 * (1 + ξ),  0.25 * (1 - ξ)]])  # dN/dη

# -------------------------------------------------
# 5.1 Assemble element stiffness matrices
# -------------------------------------------------
for e, nodes in enumerate(elem):
    xe = coords[nodes, :]                     # element node coordinates (4 × 2)
    ke = np.zeros((8, 8), dtype=np.float64)   # element stiffness matrix

    # 2‑point Gauss integration
    for (ξ, η), w in zip(gauss_pts, weights):
        dNdxi = dN_dxi(ξ, η)                  # (2,4)

        J = dNdxi @ xe                         # Jacobian (2 × 2)
        detJ = np.linalg.det(J)
        if detJ <= 0:
            raise ValueError(f'Negative Jacobian in element {e}')
        invJ = np.linalg.inv(J)

        dNdx = invJ @ dNdxi                    # ∂N/∂x, ∂N/∂y  (2,4)

        # B‑matrix (3 × 8)
        B = np.zeros((3, 8), dtype=np.float64)
        B[0, 0::2] = dNdx[0, :]                # ε_xx
        B[1, 1::2] = dNdx[1, :]                # ε_yy
        B[2, 0::2] = dNdx[1, :]                # γ_xy
        B[2, 1::2] = dNdx[0, :]

        ke += B.T @ D @ B * detJ * w           # ke contribution

    # -------------------------------------------------
    # 5.2 Assemble element matrix into global K
    # -------------------------------------------------
    dofs = np.ravel([[2 * n, 2 * n + 1] for n in nodes])   # global DOF numbers
    for i_loc, i_glob in enumerate(dofs):
        for j_loc, j_glob in enumerate(dofs):
            K[i_glob, j_glob] += ke[i_loc, j_loc]

# -------------------------------------------------
# 6. Load vector
# -------------------------------------------------
F = np.zeros(ndof, dtype=np.float64)

# Point loads (negative y‑direction) – node numbers are 1‑based as in the report
load_nodes = {101: -1_000.0,
              201: -2_000.0,
              301: -3_000.0}
for n1, val in load_nodes.items():
    idx = 2 * (n1 - 1) + 1          # y‑DOF (0‑based)
    F[idx] = val

# -------------------------------------------------
# 7. Dirichlet (prescribed‑displacement) boundary conditions
# -------------------------------------------------
fixed = []                         # constrained DOFs

# Node 1 → ux = uy = 0
fixed.extend([2 * (1 - 1) + 0, 2 * (1 - 1) + 1])

# Node 2 → uy = 0 (ux free)
fixed.append(2 * (2 - 1) + 1)

fixed = np.array(sorted(fixed), dtype=int)

# Determine free DOFs
all_dofs = np.arange(ndof, dtype=int)
free = np.setdiff1d(all_dofs, fixed)

# -------------------------------------------------
# 8. Reduce system and solve
# -------------------------------------------------
K_csr = K.tocsr()                  # CSR format for fast slicing
Kff = K_csr[free][:, free]         # reduced stiffness matrix
Ff = F[free]

U = np.zeros(ndof, dtype=np.float64)
U[free] = spla.spsolve(Kff, Ff)    # direct sparse solve

# -------------------------------------------------
# 9. Post‑processing – displacements at the loaded nodes
# -------------------------------------------------
print("\nNodal displacements at the loaded points")
for n in [101, 201, 301]:
    ux = U[2 * (n - 1) + 0]
    uy = U[2 * (n - 1) + 1]
    x, y = coords[n - 1]
    print(f"Node {n:3d}  (x={x:0.3f}, y={y:0.3f})  ux = {ux: .3e}  uy = {uy: .3e}")

# -------------------------------------------------
# 10. Reaction‑force recovery
# -------------------------------------------------
R = K_csr @ U - F                 # reactions = K·U – F

print("\nReactions at constrained nodes")
for n in [1, 2]:
    Rx = R[2 * (n - 1) + 0]
    Ry = R[2 * (n - 1) + 1]
    print(f"  Node {n:2d} : Rx = {Rx: .2f} N , Ry = {Ry: .2f} N")

# -------------------------------------------------
# 11. Quick equilibrium check (optional)
# -------------------------------------------------
total_Ry = R[1::2].sum()
print("\nEquilibrium check")
print(f"  Σ Fy (applied) = {F[1::2].sum(): .2f} N")
print(f"  Σ Ry (reactions) = {total_Ry: .2f} N")
print(f"  Difference = {F[1::2].sum() - total_Ry: .2e} N")
```
