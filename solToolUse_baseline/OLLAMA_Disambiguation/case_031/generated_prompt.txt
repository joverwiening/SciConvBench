Use FEniCS legacy (dolfin) to solve a 2D plane‑stress linear elasticity problem on a parallelogram domain with vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3).  
Generate a conforming mesh of 72 triangular elements by creating a RectangleMesh (8 × 9 cells) on the unit square and applying an affine transformation that maps the unit square to the given parallelogram.  
Define material properties: Young’s modulus E = 70e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s², and assume unit thickness for plane‑stress formulation.  
Use the reduced plane‑stress constitutive law to compute the stress tensor.  
Impose a clamped (zero displacement) boundary condition on the left inclined edge defined by the line y = 1.5 x connecting (0,0) and (0.2,0.3).  
Apply gravity as a body force ρ g in the negative‑y direction.  
Apply a horizontal point load of magnitude 5 kN acting in the negative‑x direction at the point (1.1 m, 0.15 m) using a PointSource on the x‑displacement component.  
Solve the resulting linear system with the default direct LU solver provided by FEniCS (PETSc LU or MUMPS).  
Compute the von Mises stress from the in‑plane Cauchy stress field.  
Save the displacement field to the file displacement.xdmf and the von Mises stress field to the file von_mises.xdmf in XDMF format.
