Create a file named case_135.inp in the working directory containing the provided input deck.  
Run CalculiX using the command `ccx -i case_135` (or `ccx case_135` if the former fails) in the working directory.  
After execution, check the file case_135.sta for a line indicating successful termination such as "JOB COMPLETED".  
Record the version string obtained from `ccx -v` (or equivalent) as ccx_version.  
Write a JSON file named results.json in the working directory with the schema:  
{  
  "solver": "calculix",  
  "case_id": "case_135",  
  "status": "success" or "error",  
  "ccx_version": "<version string>",  
  "artifacts": [],  
  "notes": "<exact ccx command used; if error, include error message and the file that indicated the failure>"  
}  
Set status to "success" if the .sta file shows successful termination, otherwise set to "error".  
Do not include any entries in the artifacts array.  
The notes field must contain only the exact ccx command executed, and if the run fails, also include the error message and the name of the file that indicated the failure.
