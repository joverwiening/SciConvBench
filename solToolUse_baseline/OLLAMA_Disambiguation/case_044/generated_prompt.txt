Use FEniCS legacy (dolfin) to solve a small‑strain linear elasticity problem in 2D plane‑stress for a rectangular plate Ω = (0, 1.0) m × (0, 0.20) m with unit thickness.  
Create a structured mesh of 80 cells in the x‑direction and 16 cells in the y‑direction over Ω.  
Define two bonded subdomains split at y = 0.10 m: assign Steel (E = 200 GPa, ν = 0.30) to the lower subdomain (0 ≤ y < 0.10 m) and Aluminium (E = 70 GPa, ν = 0.30) to the upper subdomain (0.10 m < y ≤ 0.20 m).  
Enforce perfect bonding at the interface y = 0.10 m by requiring continuity of displacement and traction.  
Apply displacement boundary conditions u_x = 0, u_y = 0 on the left edge (x = 0).  
Apply a uniform downward line traction t = (0, −5000) N/m on the right edge (x = 1).  
Leave the top (y = 0.20 m) and bottom (y = 0 m) edges traction‑free.  
Use the reduced plane‑stress constitutive law for both materials.  
Assemble and solve the variational problem using the direct linear solver “mumps”.  
Save the displacement field to an XDMF file named q7_disp.xdmf.
