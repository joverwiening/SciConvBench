Use FEniCS legacy (dolfin) to solve a 2D plane‑stress linear elasticity problem.  
Model an L‑shaped domain formed by a 1 m × 1 m outer square with a 0.5 m × 0.5 m inner square removed from the lower‑left corner.  
Generate a mesh with 64 elements along each outer edge.  
Assign material properties: Young’s modulus E = 70 e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³.  
Treat the domain as plane stress with unit thickness and use the reduced plane‑stress constitutive law.  
Apply a body force representing gravity: ρ g acting in the negative y‑direction (g = 9.81 m/s²).  
Impose a fixed displacement (zero) on the left boundary where x = 0.  
Apply a vertical point load of magnitude 2.65 × 10⁴ N downward at the point (0.5 m, 0.5 m).  
Solve the variational problem using a direct linear solver.  
Compute the in‑plane Cauchy stress tensor and evaluate the von Mises stress from it.  
Write the displacement field to the XDMF file “displacement.xdmf”.  
Write the stress tensor field to the XDMF file “stress.xdmf”.  
Write the von Mises stress field to the XDMF file “von_mises.xdmf”.
