**What you are seeing is not a “mystery bug” – it is Abaqus telling you that the model has been changed after the step was defined and therefore the step has to be rebuilt.  
Those messages are only **warnings**. The real reason the job aborts is that the model is **unstable** – there are no constraints (no *BOUNDARY* or *EQUATION* cards) and there is no load applied.  

A static analysis of a 3‑D solid must have at least six independent constraints (three translations + three rotations) to prevent rigid‑body motion. If the model is completely free, the global stiffness matrix is singular and the solver stops with an error such as

```
*** ERROR:  The model is unstable.  The analysis cannot continue.
```

## 1️⃣ Checklist – what a static job really needs

| Item | Why it is required | Typical Abaqus card |
|------|-------------------|---------------------|
| **Geometric constraints** (fix the model) | Prevents the whole part from translating/rotating as a rigid body. | `*BOUNDARY`, `*EQUATION`, `*MPC`, `*ENCASTRE`, … |
| **At least one load** (or a prescribed displacement) | A static step with zero load does nothing – Abaqus will still try to solve, but the result is meaningless. | `*CLOAD`, `*DLOAD`, `*CFLUX`, `*DSLOAD`, `*DISPLACEMENT`, … |
| **Amplitude (optional)** | If you define an amplitude you must reference it from a load card. | `*AMPLITUDE` + `AMPLITUDE=A1` on the load line |
| **Damping** | Damping is only used for dynamic (implicit/explicit) steps. In a static step it is ignored, but an extremely large α‑damping (500 000) can cause convergence problems if you later switch to a dynamic step. | Remove `*DAMPING` for a pure static analysis. |
| **Step definition** (optional but good practice) | Gives the step a name, tells Abaqus whether to consider geometric non‑linearity, etc. | `*STEP, NAME=STEP-1, NLGEOM=NO, INC=10000` |

## 3️⃣ Why the “model‑database‑has‑been‑modified” messages appear

When you edit the input file **after** a `*STEP` card has been written, Abaqus stores a checksum of the model at the moment the step was created.  
If the model is later changed (e.g., you add a *BOUNDARY* card, change a node set, etc.) the checksum no longer matches and Abaqus prints

```
*** WARNING: The model database has been modified since the step was last analyzed.
***          The step will be re‑analyzed from the start.
```

These warnings are harmless – they simply tell the solver to rebuild the step with the new data.  
If you run the job from the command line you will see them in the `.msg` file; they do **not** stop the analysis.

## 4️⃣ Quick sanity‑check before you run again

1. **Count constraints** – for a 3‑D solid you need at least six independent constraints.  
   - Fixing a single node in all six DOFs (`*Boundary, 100, 1, 6, 0.`) is the simplest way.  
   - If you prefer to fix a face, you can use a node set (e.g. `*Nset, nset=FIXED, generate 1, 8, 1`) and then `*Boundary, FIXED, 1, 6, 0.`

2. **Apply a load** – even a tiny pressure or a point force will make the step non‑trivial.  
   - For a pressure: `*Dsload, amplitude=A1` → `LAST, P, -1.0` (negative sign = compressive).  
   - For a point load: `*Cload` → `100, 3, -1.0, A1` (force in the Z‑direction on node 100).

3. **Run a short test** – keep the total step time very small (e.g. `1e-5 s`) and the initial increment `1e-6 s`. If the job finishes without “singular matrix” errors, you know the constraints are sufficient.

## 2️⃣ What makes a static step “unstable”

A static analysis solves  

\[
\mathbf K \, \mathbf u = \mathbf f
\]

where  

* **\(\mathbf K\)** – global stiffness matrix (size = 6 × (number of nodes))  
* **\(\mathbf u\)** – nodal displacement vector  
* **\(\mathbf f\)** – external load vector  

If the model can move as a rigid body, \(\mathbf K\) has six zero‑energy modes → it is singular → the solver stops with the *unstable model* error.

**Therefore a static step must contain:**

1. **Six independent constraints** (any combination of fixed nodes, encastre faces, equations, MPCs, etc.) that lock the six rigid‑body DOFs.  
2. **At least one non‑zero load or prescribed displacement/strain** so that the right‑hand side \(\mathbf f\) is not identically zero.

## Full explanation and step‑by‑step solution

### 1. What the warning really means
```
*** WARNING: The model database has been modified since the step was last analyzed.
***          The step will be re‑analyzed from the start.
```
- **When it appears:** You add or change a boundary condition, load, material, etc. **after** Abaqus has already read the `*STEP` definition.
- **Effect:** Abaqus discards the partially‑built step, re‑reads the whole step, and continues.  
- **Result:** The analysis **does not stop** because of this message; it is merely informational.

### 2. Why the job aborts
```
*** ERROR:  The model is unstable.  The analysis cannot continue.
```
A static analysis requires a **well‑posed** problem:

| Requirement | What it provides |
|-------------|-------------------|
| **Six independent constraints** (e.g., fixing three translational and three rotational DOFs) | Removes the six rigid‑body modes of a 3‑D solid. |
| **At least one non‑zero load** (force, pressure, temperature change, initial strain, etc.) | Gives the system a driving term; otherwise the equilibrium equations are `K·u = 0` with a singular `K`. |

If either of these is missing, the global stiffness matrix `K` is singular and the solver stops with the “model is unstable” error.

### 3. How to fix the model

#### 3.1 Add constraints (boundary conditions)

Pick a node (or a set of nodes) that will serve as the reference point and fix it in all six DOFs.  
Example (Abaqus input file syntax):

```abaqus
*Node
100, 0.0, 0.0, 0.0   ; node 100 at the origin (choose any node that belongs to the part)

*Boundary
100, 1, 6, 0.0       ; fix DOFs 1‑6 (U1, U2, U3, ROT1, ROT2, ROT3) at node 100
```

If you prefer to constrain only translational DOFs (common for solid parts) you can also add a *Coupling* constraint to tie a set of nodes together and then fix the reference node.

#### 3.2 Apply a non‑zero load in the same step

Any load that produces a non‑zero right‑hand side will work. Typical choices:

- **Pressure on a surface**

  ```abaqus
  *Dsload
  surf-1, P, 1.0      ; 1.0 MPa pressure on surface “surf-1”
  ```

- **Concentrated force**

  ```abaqus
  *Cload
  200, 1, -1000.0     ; -1000 N in X‑direction on node 200
  ```

- **Thermal load** (if you have a temperature field)

  ```abaqus
  *Temperature
  100, 50.0           ; raise node 100 to 50 °C
  ```

- **Initial strain** (e.g., for a pre‑stress analysis)

  ```abaqus
  *Initial Conditions, type=STRESS
  1, 1, 1e6           ; 1 MPa initial stress in direction 1
  ```

#### 3.3 Remove unnecessary damping for a static step

A static analysis does not need a `*Damping` card. If you have one, delete it or move it to a dynamic step.

```abaqus
*Damping, alpha=0.0   ; <-- delete this line for a pure static analysis
```

Abaqus therefore rebuilds the step and starts the solution again from the beginning – it does **not** abort the analysis.

The real problem is the error that follows  

```
*** ERROR:  The model is unstable.  The analysis cannot continue.
```  

A static analysis is *unstable* when the global stiffness matrix is singular. For a 3‑D solid this happens when the problem is not **well‑posed**, i.e. when one (or both) of the following is missing  

1. **Six independent constraints** – the six rigid‑body motions (3 translations + 3 rotations) must be restrained somewhere in the model.  
2. **At least one non‑zero load** – a force, pressure, temperature change, initial strain, etc. must be applied in the same step.

If either the constraints or the load are absent, the stiffness matrix has a zero eigenvalue, Abaqus declares the model *unstable* and aborts the job.  
A `*Damping` card in a pure static step is also unnecessary and can trigger the same check, so it should be removed (or moved to a dynamic step).

### 1. Provide six independent constraints  

Pick any combination that fully restrains the part, for example

```abaqus

```

```abaqus

### 2. Apply a non‑zero load in the same step

```

*Part …

## 关键问题：`*Boundary` 中的 DOF 编号

- 对于 **实体（solid）单元**（如 C3D8R），每个节点只有 **3 个自由度**：X、Y、Z 位移（DOF 1‑3）。  
- **没有旋转自由度**（DOF 4‑6）可以直接在节点上施加。  
- 因此下面这行  

```abaqus
*Boundary
1, 1, 6, 0.0          ! 固定 X、Y、Z 以及三个转动
```  

是 **非法的**。Abaqus 会把 **4‑6 号 DOF** 当作不存在的自由度忽略掉，结果只约束了 **1‑3 号 DOF**，模型仍然是 **未约束的**，刚度矩阵奇异，于是出现 *model is unstable* 错误。

---

## 解决办法

1. **只约束实体节点的 1‑3 号 DOF**（即三维位移），或者在其它节点再加约束以消除剩余的刚体运动。  
2. **在 STEP 之前定义约束和载荷**，这样可以消除 “model database has been modified” 警告。  
3. **确保在同一静力步中至少有一个非零外载荷**（你的 *Pressure* 已经满足）。  
4. **如果文件中出现 `*Damping`，请删除或放到动力步中**（本例中没有）。  
5. **检查约束是否冗余**（Tools → Constraint Check），但对单元模型只需要 3 条独立约束即可。
