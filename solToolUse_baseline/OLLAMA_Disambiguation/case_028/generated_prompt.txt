Use FEniCS legacy (dolfin) to solve a small‑strain linear elasticity problem in 2D plane‑stress with unit thickness.  
Create an L‑shaped domain defined as a 1 × 1 outer square with a 0.5 × 0.5 inner cut‑out, and generate a mesh with 64 elements per edge.  
Set material properties: Young’s modulus E = 70e9 Pa, Poisson ratio ν = 0.33, density ρ = 2700 kg/m³, and gravitational acceleration g = 9.81 m/s².  
Apply a uniform body force f = (0, −ρ g) throughout the domain.  
Impose Dirichlet boundary conditions on the left boundary x = 0 fixing both displacement components (uₓ = 0, u_y = 0).  
Apply a horizontal shear traction σ_xy = 2.65e4 Pa on the portion of the top edge y = 1 where 0.5 < x ≤ 1.  
Treat all remaining outer edges and the inner cut‑out boundaries as traction‑free (natural) with no external loads.  
Formulate the variational problem using the reduced plane‑stress constitutive law and solve with a direct linear solver.  
Compute the von Mises stress from the in‑plane Cauchy stress field.  
Save the displacement field to the XDMF file named displacement.xdmf and the von Mises stress field to the XDMF file named von_mises.xdmf.
