Use FEniCS legacy (dolfin) 2019.1.0 to solve a 2D small-strain linear elasticity problem in plane stress with unit thickness on an L-shaped domain.
Use material properties E = 70e9 Pa, ν = 0.33, density ρ = 2700 kg/m^3, and gravity g = 9.81 m/s^2.
Use the reduced plane-stress constitutive law to compute the in-plane Cauchy stress from the displacement field.
Use a vector-valued continuous Lagrange P2 displacement space (VectorFunctionSpace(mesh, "Lagrange", 2)).
Use a direct linear solver available in dolfin 2019.1.0 such as MUMPS.
Generate the mesh programmatically inside the script for the L-shape defined as the outer square [0,1]×[0,1] minus the inner square [0,0.5]×[0.5,1] (top-left cut-out).
Target a mesh resolution corresponding to 64 elements per outer edge.
Apply a fully clamped Dirichlet boundary condition u = (0,0) on the entire left boundary x = 0.
Apply gravity as a body force f = (0, -ρ g) over the domain.
Apply a horizontal shear traction t = ( +2.65e4, 0 ) Pa on the top-right segment of the top boundary defined by y = 1 with x > 0.5.
Leave all other outer boundaries traction-free (natural boundary conditions).
Compute the von Mises stress from the in-plane Cauchy stress field.
Write results to ParaView-readable XDMF files for displacement and stress, including von Mises, using the dolfin 2019.1.0 XDMFFile API.
