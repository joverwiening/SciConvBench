Implement a legacy FEniCS (dolfin) script targeting FEniCS 2019.1.0.
Solve 2D small-strain linear elasticity on a 1.0 m by 0.5 m rectangular plate with a central circular hole of radius 0.1 m centered at (0.5, 0.25).
Use plane-stress formulation with unit thickness and the reduced plane-stress constitutive law.
Use material parameters E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3 and gravity g = 9.81 m/s^2.
Apply gravity as a body force per unit volume f = (0, -ρ g) with no extra thickness factor.
Apply a -5 kN downward point load at (1.0, 0.25) using a PointSource on the vertical displacement component.
Clamp the left edge x = 0 by enforcing u_x = 0 and u_y = 0 on that boundary.
Leave the hole boundary traction-free.
Leave all other exterior edges traction-free except for the stated point load.
Use a vector-valued displacement function space with CG1/P1 elements.
Generate the mesh internally using mshr.
Interpret “Mesh: 72 elements” as approximately 72 total 2D triangular cells as a reasonable best-practice assumption for the rectangle-with-hole geometry.
Formulate and solve the variational problem with a direct linear solver.
Compute the in-plane Cauchy stress field from the displacement solution.
Compute von Mises stress from the in-plane Cauchy stress field.
Output displacement and von Mises stress fields to XDMF for ParaView (optionally also PVD).
