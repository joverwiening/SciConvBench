Simulate deformation of an L-shaped 2D plane-stress linear-elastic body in legacy FEniCS (dolfin) using a vector-valued displacement function space and a direct linear solver.
Target legacy FEniCS/dolfin version 2019.1.0.
Use an L-shaped geometry defined as an outer 1×1 square minus an inner 0.5×0.5 square cutout.
Use mesh resolution of 64 elements per outer edge.
Use material parameters E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2 as provided in the case details.
Treat the problem as 2D plane stress with unit thickness using the reduced plane-stress constitutive law.
Apply clamped (u = 0) boundary conditions on the outer left edge x = 0 and the outer bottom edge y = 0.
Also apply u = 0 on the two cutout faces adjacent to the re-entrant corner to regularize the singular field.
Apply a horizontal traction on the right outer edge x = 1 corresponding to σ_xx = 2.65e4 Pa.
Solve the resulting linear variational problem with a direct solver using MUMPS by default.
Post-process to compute the in-plane Cauchy stress field.
Compute von Mises stress from the in-plane Cauchy stress field.
Output displacement and von Mises stress fields for visualization using XDMF/HDF5 files suitable for ParaView.
