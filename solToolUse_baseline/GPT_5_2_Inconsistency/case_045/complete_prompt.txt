Case ID: case_045
Use FEniCS legacy (dolfin).
Solver: small-strain linear elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with piecewise material data on bonded subdomains and a direct linear solver.
Task:
Solve Solid Mechanics Problem 7 from the paper: a two-material bonded strip in plane stress.
Case details:
Geometry:
Let Ω = (0, 1.0) x (0, 0.20) m be a rectangular plate in 2D plane stress.
Subdomains:
Top half Ω_Al = (0, 1.0) x (0.10, 0.20) m is aluminium.
Bottom half Ω_Steel = (0, 1.0) x (0.00, 0.10) m is steel.
Mesh:
Structured mesh 80 x 16 over Ω.
Model:
Small-strain linear elasticity for displacement u = (u_x, u_y).
Material:
Ω_Al: E = 70 GPa, ν = 0.30.
Ω_Steel: E = 200 GPa, ν = 0.30.
Interface:
Perfect bond at y = 0.10 m; enforce continuity of displacement and traction.
Boundary conditions:
Left edge (x = 0): fixed, u_x = 0, u_y = 0.
Right edge (x = 1): uniform downward line traction t = (0, -5000) N/m.
Top and bottom edges: traction-free.
Outputs:
Save a colour map of |u| as q7_disp.png.
Save the displacement field in XDMF format.
Implementation notes:
Use cell markers or a DG0 material field so the top half and bottom half use different elastic moduli in one conforming displacement space.
Treat the 2D strip as plane stress with unit thickness and use the reduced plane-stress constitutive law.
