Use legacy FEniCS (dolfin), reasonably targeting FEniCS 2019.1.0.
Solve a 2D small-strain linear elasticity problem on a semi-circular (half-disk) domain of radius 1 m.
Treat the 2D domain as plane stress with unit thickness using the reduced plane-stress constitutive law.
Use material parameters E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2 with gravity acting in the negative y direction.
Generate the half-disk mesh using mshr, interpreting “64 elements” as a mesh resolution chosen to yield roughly that density.
Use a vector-valued continuous Lagrange P2 (quadratic) displacement function space.
Apply two concentrated vertical downward point loads of -3 kN each at (0.707, 0.707) and (-0.707, 0.707).
Represent the point loads using PointSource applied to the y-displacement component.
Fix only the two base points (-1, 0) and (1, 0) with pointwise DirichletBC (method="pointwise") enforcing u_x = 0 and u_y = 0 at both points.
Use a direct linear solver, reasonably choosing MUMPS via solver parameters.
Compute the in-plane Cauchy stress field from the displacement solution.
Compute the von Mises stress from the in-plane Cauchy stress field.
Save the displacement field to an XDMF file named displacement.xdmf.
Save the von Mises stress field to an XDMF file named von_mises.xdmf.
Print min/max values for displacement and von Mises stress to the console.
Implement everything in a single self-contained Python script including mesh generation, solve, and output.
