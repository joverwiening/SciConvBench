Create a CalculiX input file named pendel.inp in the current working directory (the directory returned by pwd).
Use the exact contents provided in the reference input deck, keeping the B32 beam elements and all other lines unchanged.
Ignore the instruction to use C3D20R elements.
Run CalculiX for job name pendel by trying the command ccx pendel first.
If ccx pendel does not work, run ccx -i pendel instead.
Determine whether the run succeeded by checking pendel.sta for JOB COMPLETED or any other clear successful-termination message.
If pendel.sta is missing, treat the run status as error.
If pendel.sta does not clearly indicate successful termination, treat the run status as error.
Create results.json in the working directory with fields solver="calculix", case_id="pendel", status="success" or "error", ccx_version set to the version string from ccx -v (or closest equivalent), artifacts as an empty array [], and notes containing the exact ccx command used.
If the run succeeds, notes may also briefly state that success was confirmed via pendel.sta.
If the run fails, notes must include the error message and identify the file indicating failure, or state that pendel.sta was missing.
