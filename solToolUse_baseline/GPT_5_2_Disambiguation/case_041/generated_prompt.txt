Implement a legacy FEniCS (dolfin) 2019.1.0 script that solves 2D small-strain linear elasticity on the square domain [-1,1]^2 with a slit from (0,0) to (1,0).

Generate the mesh using mshr CSG with a baseline resolution around 30.
Apply a reasonable local refinement strategy near the crack tip at (0,0) to better resolve the singularity.
Use vector-valued Lagrange finite elements of degree 1 (CG1).
Use plane strain constitutive law with σ(u)=2μ ε(u)+λ tr(ε(u)) I.
Set λ=0.5444837367825 and μ=1.0.
Solve the PDE -div(σ(u))=0 with zero body force f=(0,0).
Define the exact displacement field u0 using polar coordinates about the origin with r=sqrt(x^2+y^2) and θ=atan2(y,x).
Treat the slit along (x,0) for 0<x≤1 as a branch cut for θ with θ in (-π,π] and θ→0+ on the upper face and θ→0- on the lower face.
Set u0x=r^q( cos(qθ) - λ cos((q-2)θ) ) and u0y=r^q( sin(qθ) + λ sin((q-2)θ) ) with q=0.5430755788367.
Impose Dirichlet boundary conditions u=u0 only on the outer square boundary.
Leave the slit faces traction-free as natural Neumann boundaries with σ(u)n=0 and apply no surface loads there.
Formulate and solve the vector-valued variational problem using an iterative linear solver GMRES with ILU preconditioning.
Compute and print the displacement error norms versus u0: ||u-u0||_{L2(Ω)} and ||∇(u-u0)||_{L2(Ω)} (H1-seminorm).
