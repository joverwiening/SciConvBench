Implement a nonlinear finite-strain hyperelasticity solver in legacy FEniCS (dolfin) targeting FEniCS 2019.1.0 (e.g., quay.io/fenicsproject/stable:2019.1.0).
Solve the equilibrium equation div(sigma) + f0 = 0 on the UnitCube domain.
Use a UnitCube mesh with 8x8x8 cells.
Use the Saint-Venant–Kirchhoff material model with strain energy density Psi = 0.5*lambda*(tr(E))^2 + mu*tr(E^2).
Define the Green-Lagrange strain E = 0.5*(F^T*F - I).
Define the deformation gradient F = I + grad(u).
Define the stress as sigma = dPsi/dE (second Piola-Kirchhoff stress) and use the consistent finite-strain formulation in the weak form.
Use a manufactured exact displacement field u_ex(x,y,z) = 0.1*sin(pi*x)*sin(pi*y)*sin(pi*z)*(1,1,1).
Apply Dirichlet boundary conditions u = u_ex on the entire boundary of the UnitCube.
Use a vector Lagrange P2 (quadratic) finite element space for displacement.
Assume Young’s modulus E = 1.0 and Poisson’s ratio nu = 0.3, and derive Lamé parameters lambda and mu from these.
Use Newton’s method to solve the nonlinear problem.
Use Newton stopping criteria: relative residual tolerance 1e-8, absolute residual tolerance 1e-10, maximum iterations 25.
Verify the numerical solution against the manufactured solution using the relative L2 norm ||u - u_ex||_L2 / ||u_ex||_L2.
Optionally also report the absolute L2 norm ||u - u_ex||_L2.
Derive the body force term f0 from the manufactured solution so that u_ex satisfies div(sigma) + f0 = 0 exactly.
