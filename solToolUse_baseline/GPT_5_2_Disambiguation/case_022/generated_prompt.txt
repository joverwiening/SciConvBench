Solve a 2D small-strain linear elasticity plane-stress problem in legacy FEniCS (dolfin) 2019.1.0 with Python 3.
Use the rectangular domain Ω = (0, 1.0) × (0, 0.20) meters.
Use a uniform structured mesh with 20 × 4 subdivisions in (x, y).
Use a vector-valued first-order Lagrange (P1) displacement space for u = (u_x, u_y).
Use plane-stress linear elastic constitutive law with unit thickness.
Use material parameters Young’s modulus E = 200 GPa and Poisson’s ratio ν = 0.30.
Apply boundary conditions: left edge x = 0 fixed with u_x = 0 and u_y = 0.
Apply boundary conditions: right edge x = 1 prescribed displacement with u_x = 0.001 m and u_y = 0.
Leave top y = 0.20 and bottom y = 0 traction-free (natural boundary conditions).
Formulate and solve the variational problem for plane-stress linear elasticity.
Use a direct LU solve via PETSc with solver_parameters={"linear_solver": "lu"} and optionally reuse factorization.
Write the resulting displacement field u as a single vector field to XDMF file named q1_displacement.xdmf.
Generate a color map PNG of u_x directly from FEniCS using Matplotlib, plotting on the undeformed mesh.
Save the PNG as q1_ux.png.
Use Matplotlib default colormap or explicitly use cmap="viridis" for the u_x plot.
