Q: Which node(s) should receive the point load, and what magnitude and direction should that load have?
A: **Answer**

- **Which node(s) get the load?**  
  Apply the point load to the model node that coincides with the physical location where the load is acting. In most textbook‐type problems this is the node that lies at the point of interest (e.g., the free‑end node of a cantilever, the mid‑span node of a simply‑supported beam, the joint where a vertical force is applied to a truss, etc.).  
  *If the geometry is discretised so that the load location falls between two nodes, split the load equally (or proportionally to the distance) between the two nearest nodes.*

- **What magnitude?**  
  Use the exact value given in the problem statement.  
  - Example: If the problem says “a vertical load of **10 kN** is applied,” the load magnitude to be entered is **10 kN** (or 10 000 N in SI units).  
  - If the load is a reaction that must be balanced, use the calculated reaction value (e.g., 5 kN upward).

- **What direction?**  
  Follow the global coordinate system used in the model:  

  | Global axis | Positive direction | Typical load direction for the problem |
  |-------------|--------------------|----------------------------------------|
  | **X** (horizontal) | Rightward | Positive X for a right‑ward pull, negative X for a left‑ward pull |
  | **Y** (vertical)   | Upward   | Positive Y for an upward force, **negative Y for a downward force** |
  | **Z** (out‑of‑plane) | Out of the page (or upward if 3‑D) | Same sign convention as X/Y |

  So, for a conventional “downward” load on a 2‑D model, enter the load as **‑10 kN in the Y‑direction** (or **‑10 000 N**).  
  For a horizontal “rightward” load, enter **+10 kN in the X‑direction**.

| Step | What to do | Why it matters |

| **O** – **Orient the load** | Determine the sign (+/–) based on the global coordinate system (down = –Y, up = +Y, right = +X, left = –X). | Ensures the load acts in the intended direction. |
| **M** – **Magnitude** | Enter the exact numerical value from the problem (convert to model units if needed). | The structure’s response scales directly with the load magnitude. |
| **P** – **Placement verification** | Run a quick sanity check (e.g., free‑body diagram) to confirm the load location and direction are correct. | Prevents modeling errors that can invalidate results. |
| **L** – **Load distribution (if needed)** | If the load falls between nodes, distribute it proportionally (e.g., 60 % to node A, 40 % to node B). | Maintains equilibrium and accurate stress/deflection results. |
| **E** – **Enter into the solver** | Input the load into the analysis software (point load, vector components). | The solver needs the data in the correct format to compute. |
| **T** – **Test the model** | Perform a preliminary run and check reaction forces/displacements against expectations. | Confirms the load was applied correctly before final analysis. |
| **E** – **Export/Report** | Document which node(s) received the load, its magnitude, and direction in your results report. | Provides traceability and satisfies reporting requirements. |
