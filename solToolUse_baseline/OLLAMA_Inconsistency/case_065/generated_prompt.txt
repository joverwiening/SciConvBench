**What the “point‑load’’ has to be (global X‑Y‑Z system)**  

| Item                | Value (CalculiX syntax) |
|---------------------|--------------------------|
| **Node that carries the load** | **21**  *(any node 21‑40 of the second cube works – node 21 is the simplest choice)* |
| **Direction code**  | **3** → Z‑direction (the minus sign makes it “‑Z”) |
| **Force magnitude** | **‑66.7 N** (downward) |
| **CalculiX card**   | `*CLOAD` |
| **Exact line to add** | `21, 3, -66.7   ; node 21, Z‑direction, 66.7 N downward` |

---

### 1. Remove the body‑force card you already have  

```inp
*DLOAD
Eall,NEWTON
```  

Delete (or comment) those two lines – they are not needed when a point load is used.

---

### 2. Insert the point‑load card in the step where the load must act  

You can keep the step type you already use (`*STATIC` or `*DYNAMIC`).  
Only the load line changes.

#### Example – keeping your existing dynamic step

```inp
*STEP
*DYNAMIC                ; keep the step type you already use (static works as well)
1., 1.                  ; (time increment, total time – keep your original values)
*CLOAD
21, 3, -66.7            ; node 21, direction 3 = Z, magnitude = –66.7 N
*NODE PRINT,NSET=Nall,FREQUENCY=5
U
*EL FILE,NSET=Nall
ENER
*END STEP
```

*If you prefer a static analysis, replace `*DYNAMIC` with `*STATIC`; the `*CLOAD` line stays exactly the same.*

---

### 3. Save & run

```bash
ccx model_name          # or whatever command you normally use
```  

The solver will now apply a **single vertical downward force of 66.7 N at node 21**, which satisfies the required point‑load definition.

---

### QUICK “COMPLETE” checklist

| ✔ | Requirement |
|---|--------------|
| ✅ Correct node – node 21 (any node 21‑40 works) |
| ✅ Only one load – point load (`*CLOAD`), no `*DLOAD` left |
| ✅ Magnitude – 66.7 N (negative for –Z) |
| ✅ Proper direction – Z‑direction, negative (`3`) |
| ✅ Syntax – `21, 3, -66.7` correctly formatted for CalculiX |
| ✅ Placement – inside the desired `*STEP` block (static or dynamic) |

Copy the `*CLOAD` line (or the whole step block shown above) into your `.inp` file, run the analysis, and the required point‑load will be applied.
