Use FEniCS legacy (dolfin) to solve a small-strain linear elasticity plane‑stress variational problem in 2D.  
Define the rectangular domain Ω = (0, 1.0) × (0, 0.20) m.  
Create a uniform structured mesh with 40 subdivisions in the x‑direction and 8 subdivisions in the y‑direction.  
Use a vector‑valued displacement function space for u = (u_x, u_y).  
Set material properties: Young’s modulus E = 200 GPa and Poisson’s ratio ν = 0.30.  
Apply plane‑stress constitutive law with unit thickness.  
Impose boundary conditions: on the left edge (x = 0) fix u_x = 0 and u_y = 0; on the top edge (y = 0.20) apply a uniform traction t = (0, –2000) N/m interpreted as a 3D pressure of 2000 Pa on the top face; the right edge (x = 1.0) and bottom edge (y = 0) are traction‑free.  
Solve the linear system using a direct linear solver.  
Save a colour map of the vertical displacement component u_y as the image file results/q2_uy.png.  
Save the full displacement field in XDMF format as results/q2_displacement.xdmf.  
If the subdirectory results/ does not exist, create it before writing the output files.
