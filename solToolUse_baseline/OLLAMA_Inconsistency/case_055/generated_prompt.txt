Create a file named `uprofile.inp` in the working directory containing exactly the input deck provided, including the `*element, type=B32R` specification.  
Run CalculiX with the command `ccx -i uprofile`.  
Check the file `uprofile.sta` for a successful termination message such as “JOB COMPLETED”.  
Create a file `results.json` in the working directory with the following fields:  
`"solver"` set to `"calculix"`.  
`"case_id"` set to `"uprofile"`.  
`"status"` set to `"success"` if the job completed successfully, otherwise `"error"`.  
`"ccx_version"` set to the version string obtained from `ccx -v` (or the closest equivalent).  
`"artifacts"` set to an empty array.  
`"notes"` set to the exact text `ccx -i uprofile`.
