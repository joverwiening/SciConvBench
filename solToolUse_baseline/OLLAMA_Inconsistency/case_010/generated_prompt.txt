Use FEniCS legacy (dolfin) to solve a small‑strain orthotropic plane‑stress elasticity problem in 2D.  
The domain Ω is the rectangle (0 m ≤ x ≤ 1.0 m, 0 m ≤ y ≤ 0.20 m).  
Generate a structured mesh with 50 elements in the x‑direction and 25 elements in the y‑direction.  
Define the displacement field u = (uₓ, u_y) in a first‑order (linear) Lagrange finite element space.  
Local orthotropic material properties are E₁ = 40 GPa, E₂ = 10 GPa, G₁₂ = 5 GPa, ν₁₂ = 0.25, and compute the transverse Poisson’s ratio ν₂₁ = (E₂/E₁)·ν₁₂.  
Construct the plane‑stress reduced stiffness matrix [Q] in the material axes (1‑2) and rotate it to the global x‑y axes by –30° (the material axes are rotated 30° anticlockwise relative to the global axes).  
Apply the following boundary conditions:  
- Bottom edge (y = 0): uₓ = 0 and u_y = 0 (fixed).  
- Top edge (y = 0.20 m): uniform downward line traction t = (0, –10 MPa·m) interpreted as a traction per unit thickness.  
- Left and right edges (x = 0 and x = 1 m): traction‑free.  
Assemble the variational problem using the rotated orthotropic stiffness and solve it with a direct linear solver.  
Post‑process the solution:  
- Compute the von Mises stress field.  
- Save a colour map of the displacement component uₓ as q8_ux.png.  
- Save a colour map of the von Mises stress as q8_vm.png.  
- Write the displacement field and stress field to q8_solution.xdmf.
