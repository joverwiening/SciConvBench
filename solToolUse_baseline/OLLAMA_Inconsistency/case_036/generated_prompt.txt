Use FEniCS legacy (dolfin) to solve a 2D plane‑stress linear elasticity problem with a vector‑valued displacement space and the default LU direct solver.  
Set material properties to Young’s modulus E = 70e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³, and assume unit thickness.  
Define the domain as a parallelogram with vertices (0,0), (1,0), (1.2,0.3), and (0.2,0.3).  
Generate internally a triangular mesh consisting of 72 elements covering the given vertices.  
Apply a body‑force term f = (0, −ρ g) with g = 9.81 m/s² acting in the negative‑y direction.  
Impose a horizontal traction of 6000 Pa on the left inclined edge, acting in the positive‑x direction, which provides the appropriate tangential shear traction with an upward component along that edge.  
Fully clamp the right inclined edge by setting both displacement components to zero on that boundary.  
Use the reduced plane‑stress constitutive law to compute the in‑plane Cauchy stress tensor.  
Solve the variational problem for the displacement field.  
Compute the von Mises stress from the obtained Cauchy stress field.  
Save the displacement field and the von Mises stress field to VTK XML files named `case_036_results.vtu` and to an XDMF/HDF5 pair named `case_036_results.xdmf` (with accompanying HDF5 data).  
Optionally also write a CSV file containing node coordinates together with the displacement and von Mises stress values.
