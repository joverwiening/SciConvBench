Use FEniCS legacy (dolfin) to solve a small‑strain linear elasticity problem in 2D plane‑stress for a rectangular plate with a rectangular notch.  
Define the domain Ω = (0, 1.0) × (0, 0.20) m and remove the notch region (0, 0.06) × (0.08, 0.12).  
Generate a uniform triangular mesh with a characteristic element size of 0.005 m, giving roughly 200 elements along the length and 40 elements across the height.  
Set material properties to Young’s modulus E = 200 GPa and Poisson’s ratio ν = 0.30, using the reduced plane‑stress constitutive law with unit thickness.  
Apply displacement boundary conditions uₓ = 0, u_y = 0 on the left outer boundary (x = 0) only; all notch faces are traction‑free.  
Apply a line traction t = (2 MPa·m, 0) on the right edge (x = 1.0).  
Treat the top and bottom edges as traction‑free.  
Solve the variational problem with a direct linear solver.  
Compute the plane‑stress von Mises stress field and save it as an image file named q5_vm.png.
