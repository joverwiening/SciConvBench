Use a mixed displacement–pressure formulation with Taylor‑Hood elements (quadratic P2 for displacement and linear P1 for pressure).  
Generate a conforming triangular mesh of the rectangular strip (0 ≤ x ≤ 1.0, 0 ≤ y ≤ 0.20) with a circular hole of radius 0.04 m centred at (0.50, 0.10).  
Set a global target element size of approximately 0.005 m and apply local refinement near the hole to achieve an element size of about 0.002 m on the hole boundary.  
The resulting mesh should contain roughly 8 000–10 000 triangular elements, with a higher density around the hole.  
Apply Dirichlet boundary conditions u_x = 0 and u_y = 0 on the left edge (x = 0).  
Apply a uniform follower pressure of 0.10 MPa on the hole boundary as a traction sigma·n = ‑P_hole n in the deformed configuration.  
Leave the right, top, and bottom edges traction‑free.  
Solve the incompressible finite‑strain neo‑Hookean problem using Newton’s method with appropriate convergence tolerances.  
After convergence, compute the Cauchy stress tensor and evaluate the von Mises stress field.
