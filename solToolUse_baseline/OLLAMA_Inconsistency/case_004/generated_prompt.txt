Use legacy FEniCS (dolfin) to solve a static 2D plane‑stress linear elasticity problem on an L‑shaped domain (outer square 1 × 1 m, inner cutout 0.5 × 0.5 m) with a mesh of 64 elements per edge.  
Material properties: Young’s modulus E = 70 × 10⁹ Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³, plane‑stress reduced constitutive law, unit thickness.  
Apply a uniform body force equal to ρ · g acting in the negative y‑direction (g = 9.81 m/s²) throughout the domain.  
Boundary conditions: fix the left boundary (x = 0) with zero displacement; apply a vertical surface traction on the outer right edge (x = 1) with components tₓ = 0 and t_y = −2.65 × 10⁴ · y (negative y‑direction) varying linearly with the y‑coordinate; all other boundaries, including the inner vertical face of the cutout, are traction‑free.  
Solve the variational problem using a direct linear solver.  
Compute the in‑plane Cauchy stress tensor and the von Mises stress from the solution.  
Export results:  
- Write the displacement vector field to a VTK/ParaView file named `displacement.pvd` and to a CSV file named `displacement.csv`. The CSV must contain one row per node with columns: node ID, x‑coordinate, y‑coordinate, uₓ, u_y.  
- Write the stress components σₓₓ, σ_yy, σ_xy and the von Mises scalar σ_vM to a VTK/ParaView file named `stress.pvd` and to a CSV file named `stress.csv`. The CSV must contain one row per node with columns: node ID, x‑coordinate, y‑coordinate, σₓₓ, σ_yy, σ_xy, σ_vM.
