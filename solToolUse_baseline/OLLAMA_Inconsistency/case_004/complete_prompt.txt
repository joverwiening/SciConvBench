Case ID: case_004
Use FEniCS legacy (dolfin).
Solver: small-strain linear elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with a vector-valued displacement space and a direct linear solver.
Task:
Simulate stress in an L-shaped structure under gravity loading and vertically increasing traction on right edge (x=1). Implement linear elasticity with Young's modulus E=70e9 Pa, Poisson ratio ν=0.33. Traction magnitude grows linearly from σ_yy=0 at y=0 to σ_yy=-2.65e4 Pa at y=1. Fix left boundary and compute displacement/stress distributions.
Case details:
Material: E=70e9, ν=0.33, ρ=2700 kg/m^3, g=9.81 m/s^2. Geometry: L-shape (1x1 outer - 0.5x0.5 inner). Boundaries: x = 0 fixed. Traction profile: σ_yy(y) = -2.65e4*y applied on the outer right edge x = 1. Mesh: 64 elements/edge.
Implementation notes:
Treat the 2D domain as plane stress with unit thickness and use the reduced plane-stress constitutive law.
Compute von Mises from the in-plane Cauchy stress field.
Apply the varying traction only on the outer right edge x = 1; the re-entrant inner boundaries are traction-free.
