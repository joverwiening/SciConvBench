Create a file named `case_075.inp` in the working directory with the provided input deck.
Run the CalculiX analysis using either `ccx -i case_075` or `ccx case_075`.
Determine the success of the run by checking for a message like 'JOB COMPLETED' in the `case_075.sta` file.
Create a `results.json` file in the working directory.
The `results.json` file must have a "solver" field set to "calculix".
The `results.json` file must have a "case_id" field set to "case_075".
The `results.json` file must have a "status" field set to "success" or "error" based on the run's outcome.
The `results.json` file must have a "ccx_version" field containing the output of `ccx -v`.
The `results.json` file must have an "artifacts" field which is an empty list.
The `results.json` file must have a "notes" field containing the exact ccx command used.
If the run fails, the "notes" field must also include the error message and the name of the file that indicated the failure.
