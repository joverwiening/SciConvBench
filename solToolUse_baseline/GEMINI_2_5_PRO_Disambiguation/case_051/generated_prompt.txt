Run the CalculiX analysis using a command like `ccx -i case_051` or `ccx case_051`.
The exact command used to run the analysis must be recorded.
After the run, determine the status by checking for the string 'JOB COMPLETED' in the file `case_051.sta`.
If the string 'JOB COMPLETED' is present, the status is 'success'.
If the string 'JOB COMPLETED' is not present, the status is 'error'.
Obtain the CalculiX version string by executing `ccx -v`.
Create a JSON file named `results.json` in the working directory.
The `results.json` file will contain an object with keys: "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
The value for "solver" is the string "calculix".
The value for "case_id" is the string "case_051".
The value for "status" is the determined run status, either "success" or "error".
The value for "ccx_version" is the version string obtained from the `ccx -v` command.
The value for "artifacts" is an empty list.
The value for "notes" is a string that includes the exact command used to run CalculiX.
If the run status is "error", the "notes" string must also include an error message captured from the standard error stream of the process and state that the failure was indicated by the `case_051.sta` file.
