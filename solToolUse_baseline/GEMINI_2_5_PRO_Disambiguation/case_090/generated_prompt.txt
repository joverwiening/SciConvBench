Create a file named `case_090.inp` in the working directory with the provided input deck content.
Execute the `ccx -v` command and capture the output as the version string.
Run the CalculiX analysis using either the `ccx -i case_090` or `ccx case_090` command.
Determine if the run was successful by checking for the string 'JOB COMPLETED' in the `case_090.sta` file.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with specific fields.
The `solver` field in the JSON object must be the string "calculix".
The `case_id` field must be the string "case_090".
The `status` field must be "success" if the run was successful, otherwise it must be "error".
The `ccx_version` field must be the version string captured from the `ccx -v` command.
The `artifacts` field must be an empty list.
The `notes` field must contain a string with the exact command used to run the analysis.
If the run status is "error", the `notes` field must also contain the error message and the name of the file or stream from which the error was identified.
