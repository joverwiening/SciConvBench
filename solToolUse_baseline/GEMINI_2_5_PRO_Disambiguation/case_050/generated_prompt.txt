Create a file named `case_050.inp` in the working directory.
The content of `case_050.inp` will be the provided input deck.
The `*STEP` block in the input deck will contain a `*STATIC` analysis step.
The step will include a centrifugal `*DLOAD` on element set Eall.
The step will request `U` output for node set Nall.
The step will request `S` output for element set Eall.
The physics of the input deck must not be changed.
Run the CalculiX analysis using the `case_050.inp` file.
The command to run the analysis should be either `ccx -i case_050` or `ccx case_050`.
Determine if the run succeeded by checking for a successful termination message in the `case_050.sta` file.
Create a JSON file named `results.json` in the working directory.
The `solver` field in `results.json` will be "calculix".
The `case_id` field in `results.json` will be "case_050".
The `status` field will be "success" if the run completed successfully, and "error" otherwise.
The `ccx_version` field will contain the full version string from the `ccx -v` command.
The `artifacts` field will be an empty list.
The `notes` field will contain the exact CalculiX command used to run the simulation.
If the simulation fails, the `notes` field will also contain the error message and the name of the file from which the error message was retrieved.
