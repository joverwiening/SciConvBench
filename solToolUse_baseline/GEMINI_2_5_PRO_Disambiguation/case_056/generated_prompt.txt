Create a file named `case_056.inp` in the working directory.
The content of `case_056.inp` will be the input deck provided by the user, with specific additions and modifications.
The `*MATERIAL,NAME=EL` block must be followed by an `*ELASTIC` card.
The line following the `*ELASTIC` card must be `210000.0, .3`.
Before the `*STEP` block, add three `*BOUNDARY` blocks.
The first `*BOUNDARY` block will have the data line `CN7, 1`.
The second `*BOUNDARY` block will have the data line `CN7, 2`.
The third `*BOUNDARY` block will have the data line `CN7, 3`.
The `*STEP` block must contain a `*BUCKLE` card followed by the data line `10,1.e-2`.
The `*STEP` block must also contain a `*CLOAD` card followed by the data line `LAST,3,-1.`.
Run the CalculiX analysis on the `case_056.inp` file.
Use either the command `ccx -i case_056` or `ccx case_056`.
Determine if the simulation succeeded by checking the `case_056.sta` file for a successful termination message.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object with the solver, case_id, status, ccx_version, artifacts, and notes.
The `solver` key will have the value "calculix".
The `case_id` key will have the value "case_056".
The `status` key will be "success" if the run completed successfully, otherwise "error".
The `ccx_version` key will contain the version string obtained from the `ccx -v` command.
The `artifacts` key will be an empty list.
The `notes` key will contain the exact CalculiX command used to run the simulation.
If the run failed, the `notes` key will also include the error message and the file that indicated the failure.
