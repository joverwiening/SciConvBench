Create a file named `case_103.inp` in the working directory with the provided input deck.
The `*STEP` block in the `case_103.inp` file must contain a `*STATIC` card, a `*CLOAD` card with the value `LAST,3,1.`, a `*NODE PRINT` card for NSET=NALL with the `U` field, and an `*EL PRINT` card for ELSET=EALL with the `S` field.
Run the CalculiX analysis using the `case_103.inp` file.
Execute the analysis by running either `ccx -i case_103` or `ccx case_103`.
Check the `case_103.sta` file to determine if the run succeeded.
Create a `results.json` file in the working directory.
The `solver` field in `results.json` shall be "calculix".
The `case_id` field in `results.json` shall be "case_103".
The `status` field shall be "success" for a successful run and "error" for a failed run.
The `ccx_version` field shall contain the version string from the `ccx -v` command.
The `artifacts` field shall be an empty list.
The `notes` field shall record the exact `ccx` command used.
If the run fails, the `notes` field shall also include the error message and the file that indicated the failure.
