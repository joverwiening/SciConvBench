Solve a 2D small-strain linear elasticity problem using FEniCS legacy (dolfin).
The analysis will be for a plane-stress condition.

The material's Young's modulus is 70e9 Pa and its Poisson's ratio is 0.33.

A body force due to gravity (g=9.81 m/s^2) must be included in the analysis.
The bottom boundary, where y=0, is to be fixed.
A linearly varying vertical traction is applied to the top boundary segment from x=0.3 to x=0.5.
The vertical traction value is -2400 Pa at x=0.3.
The vertical traction value is -4000 Pa at x=0.5.
All other boundaries not specified as fixed or under traction are to be treated as traction-free.
The mesh should contain approximately 72 elements.
Use a vector-valued function space for the displacement.
Solve the system using a direct linear solver.
The final outputs required are the displacement distribution and the von Mises stress distribution.
The implementation should use the reduced plane-stress constitutive law with an assumed unit thickness.
Calculate the von Mises stress from the in-plane Cauchy stress field.
