Use the FEniCS legacy library (dolfin).
Solve a static, nonlinear finite-strain elasticity problem for a hyperelastic cube.
The geometry is a UnitCube meshed with 8x8x8 cells.
Use a Saint-Venant-Kirchhoff material model.
The shear modulus, μ, is a constant value of 3.8461.
The first Lamé parameter, λ, varies spatially according to the expression λ = 5.8*x1 + 5.7*(1 - x1), where x1 is the first spatial coordinate.
Discretize the displacement field using second-order Lagrange elements.
Apply a fixed boundary condition (zero displacement) on the face where x1 = 0.
Apply a rotational displacement of 60 degrees on the face where x1 = 1.
The axis of rotation is the cube's centerline, parallel to the x1-axis.
Apply the total rotation incrementally over 10 equal steps.
Solve the nonlinear system at each step using Newton's method.
Save the final displacement field to a file for visualization.
Calculate and save the final von Mises stress field to a file for visualization.
