Solve a 2D plane-stress linear elasticity problem using FEniCS legacy (dolfin).
The domain is a rectangle defined by the corners (0, 0) and (1.0, 0.20) meters.
Create a uniform structured mesh with 40 cells in the x-direction and 8 cells in the y-direction.
The material has a Young's modulus of 200 GPa and a Poisson's ratio of 0.30.
Model the problem using plane-stress constitutive relations assuming unit thickness.
Discretize the vector displacement field using continuous Lagrange finite elements of polynomial degree 2.
Apply a fixed boundary condition (u_x = 0, u_y = 0) on the left edge (x = 0).
Apply a uniform downward traction with a vector value of (0, -2000) N/m on the top edge (y = 0.20).
The right edge (x = 1.0) and bottom edge (y = 0) are traction-free.
Solve the linear system using a direct solver.
Save a color plot of the vertical displacement component (u_y) as q2_uy.png.
Save the resulting displacement vector field to an XDMF file named displacement.xdmf.
