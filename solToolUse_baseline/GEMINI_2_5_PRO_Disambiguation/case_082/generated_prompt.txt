Create a file named `case_082.inp` in the working directory.
The content of this file will be the complete CalculiX input deck formed by combining the initial deck with the provided additions for the `*BOUNDARY`, `*MATERIAL`, and `*STEP` cards.
Run the CalculiX analysis on the `case_082.inp` file.
Use either the command `ccx -i case_082` or `ccx case_082`.
Determine if the simulation was successful by checking the `case_082.sta` file for a successful termination message such as 'JOB COMPLETED'.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with a specific schema.
The `solver` key should have the value "calculix".
The `case_id` key should have the value "case_082".
The `status` key should have the value "success" if the run completed successfully, and "error" otherwise.
The `ccx_version` key should contain the version string obtained from running `ccx -v`.
The `artifacts` key should have an empty list `[]` as its value.
The `notes` key should contain a string with the exact CalculiX command used to run the simulation.
If the simulation failed, the `notes` string must also include the error message and the name of the file that indicated the failure.
