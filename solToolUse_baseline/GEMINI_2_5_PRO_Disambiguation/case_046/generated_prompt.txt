Create the file `case_046.inp` in the working directory with the provided input deck.
Run the CalculiX analysis using either `ccx -i case_046` or `ccx case_046`.
Determine the CalculiX version by running a command like `ccx -v`.
Check the `case_046.sta` file to determine if the run succeeded.
A successful run is indicated by a message such as 'JOB COMPLETED'.
Create a JSON file named `results.json` in the working directory.
The JSON file will have a "solver" key with the value "calculix".
The JSON file will have a "case_id" key with the value "case_046".
The JSON file will have a "status" key with the value "success" or "error" depending on the outcome.
The JSON file will have a "ccx_version" key with the captured version string.
The JSON file will have an "artifacts" key containing a list of generated file names.
The artifacts list will include the primary output files generated by the solver, such as `case_046.sta`, `case_046.dat`, and `case_046.frd`.
The JSON file will have a "notes" key containing the exact ccx command used for the run.
If the run fails, the "notes" key will also include the error message and the name of the file that indicated the failure.
