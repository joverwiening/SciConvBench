Create a file named `case_092.inp` in the working directory.
The file `case_092.inp` will contain a CalculiX input deck.
The input deck defines five nodes in a node set named Nall.
The input deck defines two B32 elements in an element set named Eall.
The input deck defines a material named EL with an elastic modulus of 210000 and a Poisson's ratio of 0.3.
The input deck assigns a rectangular beam section of size 0.05 by 0.08 to the element set Eall.
The analysis consists of a single static step with non-linear geometric effects enabled.
A boundary condition fixes node 1 in all degrees of freedom, from 1 through 6.
A concentrated load applies a torque of magnitude 0.005 to node 4 in the rotational degree of freedom about the x-axis.
Request nodal displacement (U) output for the node set Nall.
Request element stress (S) output for the element set Eall.
Execute the CalculiX solver on the input file `case_092.inp`.
The command to execute the solver is either `ccx -i case_092` or `ccx case_092`.
Determine the success of the run by checking for a successful termination message in the `case_092.sta` file.
Create a JSON file named `results.json` in the working directory.
The `solver` key in `results.json` will have the value "calculix".
The `case_id` key in `results.json` will have the value "case_092".
The `status` key in `results.json` will be "success" for a successful run and "error" for a failed run.
The `ccx_version` key in `results.json` will contain the version string from the `ccx -v` command.
The `artifacts` key in `results.json` will be an empty list.
The `notes` key in `results.json` will record the exact command used to run CalculiX.
If the run fails, the `notes` key will also include the error message and the name of the file that indicated the failure.
