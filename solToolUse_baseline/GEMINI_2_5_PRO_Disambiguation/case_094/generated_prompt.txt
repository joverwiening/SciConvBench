Create a file named case_094.inp in the working directory with the provided input deck.
Run the CalculiX analysis on the case_094.inp file.
Use either the command `ccx -i case_094` or `ccx case_094` to execute the analysis.
Determine the success of the run by checking for a successful termination message in the case_094.sta file.
Create a JSON file named results.json in the working directory.
The solver field in results.json must be "calculix".
The case_id field in results.json must be "case_094".
The status field in results.json must be "success" for a successful run or "error" for a failed run.
The ccx_version field in results.json must contain the version string from the `ccx -v` command.
The artifacts field in results.json must be an empty list.
The notes field in results.json must record the exact ccx command that was used.
If the run fails, the notes field must also include the error message and the file that indicated the failure.
