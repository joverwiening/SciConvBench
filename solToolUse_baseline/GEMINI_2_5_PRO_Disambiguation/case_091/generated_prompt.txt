Create the file case_091.inp in the working directory.
The input deck for case_091.inp will contain the provided geometry, including nodes and B32 elements.
Define a material named 'EL' with a Young's modulus of 210000 and a Poisson's ratio of 0.3.
Use the provided RECT and CIRC beam sections for element sets SET1 and SET2 respectively, referencing the material 'EL'.
Apply a boundary condition to fully fix nodes 1 and 4 for all degrees of freedom (1 through 6).
Apply a concentrated load of 0.0025 to node 2 in the 3rd degree of freedom.
The analysis step will have the NLGEOM parameter activated.
Request nodal displacement (U) output for the node set Nall.
Request element stress (S) output for the element set Eall.
Run the CalculiX analysis using either `ccx -i case_091` or `ccx case_091`.
Determine the run's success by checking for a successful termination message in `case_091.sta`.
Write a `results.json` file in the working directory.
The `results.json` file must conform to the specified schema.
The `solver` field in the JSON will be "calculix".
The `case_id` field in the JSON will be "case_091".
The `status` field will be "success" or "error" based on the run outcome.
The `ccx_version` field will contain the version string from the `ccx -v` command.
The `artifacts` field will be an empty list.
