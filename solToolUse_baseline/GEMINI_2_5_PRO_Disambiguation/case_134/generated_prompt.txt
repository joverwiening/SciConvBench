Create a file named `beamp.inp` with the content provided in the "Global model input deck" section.
Execute the CalculiX solver for the global model using the command `ccx -i beamp`.
Check the `beamp.sta` file for the text 'JOB COMPLETED' to verify successful completion of the global model run.
If the global model run fails, do not attempt the submodel run.
If the global model run succeeds, check for the existence of the results file `beamp.frd`.
If the `beamp.frd` file does not exist, treat this as a failure and do not proceed with the submodel run.
If the `beamp.frd` file exists, copy it to `beamp.frd.ref`.
Create a file named `case_134.inp` with the content provided in the "Submodel input deck" section.
Execute the CalculiX solver for the submodel using the command `ccx -i case_134`.
Check the `case_134.sta` file for the text 'JOB COMPLETED' to verify successful completion of the submodel run.
Get the CalculiX version string by running `ccx -v`.
Create a JSON file named `results.json`.
The `results.json` file will contain an object with specific key-value pairs.
The value for the `solver` key will be the string "calculix".
The value for the `case_id` key will be the string "case_134".
The value for the `status` key will be "success" if both the global and submodel runs complete successfully, and "error" otherwise.
The value for the `ccx_version` key will be the version string obtained from the solver.
The value for the `artifacts` key will be an empty list.
The value for the `notes` key will be a string containing all shell commands executed and any failure messages encountered.
