Create a file named `case_067.inp` in the working directory with the provided input deck content.
Run the CalculiX analysis for the job `case_067`.
Use either the command `ccx -i case_067` or `ccx case_067`.
The physics defined in the input deck must not be changed.
Check the `case_067.sta` file to determine if the run succeeded.
A successful run is indicated by a message such as 'JOB COMPLETED'.
Create a file named `results.json` in the working directory.
The `results.json` file must have a `solver` field with the value "calculix".
The `results.json` file must have a `case_id` field with the value "case_067".
The `results.json` file must have a `status` field set to "success" or "error" based on the run outcome.
The `results.json` file must have a `ccx_version` field containing the version string from the `ccx -v` command.
The `results.json` file must have an `artifacts` field set to an empty list.
The `results.json` file must have a `notes` field that records the exact ccx command used.
If the run failed, the `notes` field must also include the error message and the file that indicated the failure.
