Create a file named `case_055.inp` in the working directory with the provided input deck content.
Run the CalculiX simulation using either `ccx -i case_055` or `ccx case_055`.
Determine the CalculiX version by running `ccx -v`.
Check the `case_055.sta` file for a successful termination message, such as 'JOB COMPLETED', to determine the run status.
Create a `results.json` file in the working directory.
The `results.json` file must conform to the specified schema.
The `solver` field in the JSON will be "calculix".
The `case_id` field in the JSON will be "case_055".
The `status` field will be "success" or "error" based on the run's outcome.
The `ccx_version` field will contain the version string from the `ccx -v` command.
The `artifacts` array in the JSON will be an empty list.
The `notes` field will record the exact ccx command used.
If the run fails, the `notes` field will also include the error message and the file that indicated the failure.
