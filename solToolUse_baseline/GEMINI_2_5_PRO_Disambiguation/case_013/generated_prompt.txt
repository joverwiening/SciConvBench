Use the FEniCS legacy library (dolfin).
Solve a 2D plane-stress linear elasticity problem for a notched plate.
The geometry is a rectangle defined by the corners (0,0) and (1.0, 0.2) in meters.
A semicircular notch of radius 0.05 m is removed from the top edge, with its center at (0.5, 0.2).
Generate the mesh for this geometry using the FEniCS `mshr` tool.
Refine the mesh near the notch tip to accurately capture stress concentrations.
The material model is linear elasticity with Young's modulus E = 200 GPa and Poisson's ratio ν = 0.30.
Use the reduced plane-stress constitutive law, assuming unit thickness.
The bottom edge of the plate (y = 0) is fixed with zero displacement in all directions.
Apply a downward line traction t = (0, -10 MPa*m) to the top edge (y = 0.2) on the segments outside the notch opening.
The vertical sides (x = 0 and x = 1) and the notch arc surface are traction-free.
Use a vector-valued function space with second-degree Lagrange elements for the displacement field.
Solve the resulting linear system with a direct solver.
Compute the von Mises stress field from the resulting displacement solution.
Project the von Mises stress into a first-degree Discontinuous Galerkin function space before plotting.
Save a contour plot of the von Mises stress field to the file q6_vm.png.
Save the final displacement field to an XDMF file named q6_displacement.xdmf.
