Use the FEniCS legacy (dolfin) library to solve the small-strain linear elasticity equations.
The computational domain is a square defined by `[-1,1] x [-1,1]`.
A horizontal slit exists within the domain from `(0,0)` to `(1,0)`.
Generate a mesh of the domain with a refinement resolution of approximately 30 elements near the crack tip at `(0,0)`.
Assume plane strain conditions for the simulation.
The first Lamé parameter is `lambda = 0.5444837367825`.
The second Lamé parameter is `mu = 0.84`.
There is no body force term.
Use continuous vector Lagrange elements of polynomial degree 2.
The exact displacement field `u0` is used to enforce Dirichlet boundary conditions on the outer boundary of the square.
The components of the exact displacement field `u0 = (u0_x, u0_y)` are defined in terms of polar coordinates `(r, theta)` where `r = sqrt(x^2 + y^2)` and `theta = atan2(y, x)`.
The exponent for the radial term is `q = 0.5430755788367`.
The `kappa` parameter is defined by the plane strain assumption: `kappa = 3 - 4*nu`, where `nu = lambda / (2 * (lambda + mu))`.
The x-component of the exact displacement is `u0_x = r^q * ( (kappa - cos(2*theta)) * cos(q*theta) - (1-q) * cos((2-q)*theta) )`.
The y-component of the exact displacement is `u0_y = r^q * ( (kappa - cos(2*theta)) * sin(q*theta) + (1-q) * sin((2-q)*theta) )`.
Solve the resulting linear system using the GMRES iterative solver.
Precondition the GMRES solver with an Incomplete LU (ILU) preconditioner.
