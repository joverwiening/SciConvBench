Create a file named `case_111.inp` in the working directory with the provided input deck content.
Execute the CalculiX solver on the input file.
The command to run the solver should be either `ccx -i case_111` or `ccx case_111`.
Determine if the simulation run was successful by checking the `case_111.sta` file.
A successful run is indicated by a successful termination message, such as 'JOB COMPLETED', within the `case_111.sta` file.
Obtain the CalculiX version string by running a command like `ccx -v`.
Create a JSON file named `results.json` in the working directory.
The `results.json` file must contain a "solver" key with the value "calculix".
The `results.json` file must contain a "case_id" key with the value "case_111".
The `results.json` file must contain a "status" key with the value "success" if the run succeeded or "error" if it failed.
The `results.json` file must contain a "ccx_version" key with the version string obtained from the solver.
The `results.json` file must contain an "artifacts" key with an empty list as its value.
The `results.json` file must contain a "notes" key.
The value for the "notes" key must be a string containing the exact command used to run the solver.
If the run failed, the "notes" string must also include the error message from the solver's standard error output and identify the file that indicated the failure.
