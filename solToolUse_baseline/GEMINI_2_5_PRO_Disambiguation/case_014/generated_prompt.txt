Implement a nonlinear hyperelasticity problem in FEniCS legacy (dolfin).
The material model is Saint-Venant-Kirchhoff.
The strain energy function is Ψ = 0.5λ(trε)^2 + μtr(ε^2).
Use a first Lamé parameter λ of 125.0.
Use a second Lamé parameter μ of 80.0.
The problem is defined on a UnitCube mesh with 8x8x8 cells.
The exact manufactured solution for displacement is u_ex = (0.1*sin(πx)sin(πy)sin(πz), 0.1*sin(πx)sin(πy)sin(πz), 0.1*sin(πx)sin(πy)sin(πz)).
Derive the body force f0 required to satisfy the governing equation ∇*σ + f0 = 0 for the given manufactured solution.
Apply the manufactured solution as a Dirichlet boundary condition on the entire boundary of the domain.
Solve the resulting nonlinear variational problem using Newton's method.
Verify the implementation by comparing the computed numerical solution to the exact manufactured solution.
A convergence study is not required.
