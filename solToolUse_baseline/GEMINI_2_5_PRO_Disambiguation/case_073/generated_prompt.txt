Create a CalculiX input file named `case_073.inp`.
The input file will contain the mesh data, material properties, and step definitions.
The material named `EL` has a density of 7.8E-9.
The material `EL` has a Young's modulus of 210000.0.
The material `EL` has a Poisson's ratio of 0.3.
The material `EL` has a structural damping factor of 0.03.
The first analysis step is a frequency analysis defined by `*FREQUENCY, STORAGE=YES`.
The frequency analysis will calculate 10 eigenvalues.
Nodes in the node set `CN7` are constrained in degrees of freedom 1, 2, and 3.
The second analysis step is a steady-state dynamics analysis.
The steady-state dynamics analysis runs from 13000 to 13200 cycles/time.
A reasonable number of increments should be assumed for the steady-state dynamics analysis.
A concentrated load of 100.0 is applied to node 100 in the first degree of freedom during the second step.
Run the CalculiX analysis on the `case_073.inp` file.
Use either `ccx -i case_073` or `ccx case_073` to execute the analysis.
Determine the success of the run by checking the `case_073.sta` file.
Create a JSON file named `results.json` in the working directory.
The `results.json` file will have a "solver" key with the value "calculix".
The `results.json` file will have a "case_id" key with the value "case_073".
The `results.json` file will have a "status" key with the value "success" or "error".
The `results.json` file will have a "ccx_version" key containing the output of `ccx -v`.
The `results.json` file will have an "artifacts" key with an empty list as its value.
The `results.json` file will have a "notes" key containing the exact command used to run the simulation.
If the simulation fails, the "notes" field will also include the error message and the file that indicated the failure.
