The results.json file must contain a JSON object with six specific key-value pairs.
The value for the "solver" key must be the string "calculix".
The value for the "case_id" key must be the string "case_124".
The value for the "status" key must be "success" if the run completed successfully, and "error" otherwise.
The value for the "ccx_version" key must be the version string obtained by running `ccx -v` or an equivalent command.
The value for the "artifacts" key must be an empty list.
The value for the "notes" key must be a string containing the exact ccx command that was used to run the simulation.
If the run failed, the "notes" string must also include the error message and the name of the file that indicated the failure.
