Create a file named `case_080.inp` in the working directory with the provided input deck content.
Run the CalculiX analysis using either `ccx -i case_080` or `ccx case_080`.
Determine the success of the run by checking for a successful termination message like 'JOB COMPLETED' in the `case_080.sta` file.
Create a `results.json` file in the working directory.
The `results.json` file must have a `solver` field set to "calculix".
The `results.json` file must have a `case_id` field set to "case_080".
The `results.json` file must have a `status` field set to "success" or "error" based on the run's outcome.
The `results.json` file must have a `ccx_version` field containing the version string from the `ccx -v` command.
The `results.json` file must have an `artifacts` field which is an empty list.
The `results.json` file must have a `notes` field that records the exact ccx command used.
If the run fails, the `notes` field must also include the error message and the file that indicated the failure.
