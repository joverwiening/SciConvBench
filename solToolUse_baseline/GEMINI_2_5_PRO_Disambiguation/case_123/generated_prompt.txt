Create a file named `case_123.inp` in the working directory with the provided input deck content.
Run the CalculiX analysis on the `case_123.inp` file.
Use either the `ccx -i case_123` or `ccx case_123` command to execute the analysis.
Determine if the run was successful by checking for the string 'JOB COMPLETED' in the `case_123.sta` file.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with specific key-value pairs.
The `solver` field shall be "calculix".
The `case_id` field shall be "case_123".
The `status` field shall be "success" if the run succeeded, and "error" otherwise.
The `ccx_version` field shall be the version string obtained from running `ccx -v`.
The `artifacts` field shall be an empty list.
The `notes` field shall contain the exact CalculiX command that was used.
If the run failed, the `notes` field shall also include the error message and the name of the file that indicated the failure.
The physics defined in the input deck must not be changed.
