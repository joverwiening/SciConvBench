Run the CalculiX analysis using either the `ccx -i case_049` or `ccx case_049` command.
Determine if the run succeeded by checking the `case_049.sta` file for a successful termination message.
Create a `results.json` file in the working directory.
The `results.json` file must follow the specified schema.
The `solver` field will be "calculix".
The `case_id` field will be "case_049".
The `status` field will be "success" or "error" based on the run's outcome.
The `ccx_version` field will contain the version string from the `ccx -v` command.
The `artifacts` field will be an empty list.
The `notes` field will record the exact ccx command used.
If the run fails, the `notes` field will also include the error message and the name of the file that indicated the failure.
The `results.json` file should not contain any numerical data from the simulation.
