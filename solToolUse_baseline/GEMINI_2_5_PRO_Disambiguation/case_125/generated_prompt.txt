Create a file named `case_125.inp` in the working directory.
The content of `case_125.inp` is the provided CalculiX input deck.
The physics defined in the input deck must not be changed.
Execute the CalculiX solver on the `case_125.inp` file.
The command to execute the solver should be `ccx -i case_125` or `ccx case_125`.
Determine the version of the CalculiX solver by running `ccx -v`.
Determine if the simulation run was successful by checking for the phrase 'JOB COMPLETED' in the `case_125.sta` file.
Create a file named `results.json` in the working directory.
The `results.json` file must conform to the specified JSON schema.
The `solver` field in `results.json` shall be "calculix".
The `case_id` field in `results.json` shall be "case_125".
The `status` field in `results.json` shall be "success" if the run completed successfully, and "error" otherwise.
The `ccx_version` field in `results.json` shall contain the version string obtained from the solver.
The `artifacts` field in `results.json` shall be an empty list.
The `notes` field in `results.json` shall contain the exact command used to run the solver.
If the run status is "error", the `notes` field shall also include the error message and an indication of its source.
The source for the error message should be determined based on standard practices, such as checking standard error or output log files.
