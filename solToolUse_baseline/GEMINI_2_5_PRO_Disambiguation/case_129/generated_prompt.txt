Create a file named `case_129.inp` in the working directory with the provided input deck content.
Run the CalculiX solver for the `case_129.inp` file using either the `ccx -i case_129` or `ccx case_129` command.
Determine if the solver run was successful by checking the `case_129.sta` file for a successful termination message like 'JOB COMPLETED'.
Create a JSON file named `results.json` in the working directory.
The `solver` field in `results.json` will be "calculix".
The `case_id` field in `results.json` will be "case_129".
The `status` field in `results.json` will be "success" for a successful run or "error" for a failed run.
The `ccx_version` field in `results.json` will be the version string obtained from the `ccx -v` command.
The `artifacts` field in `results.json` will be an empty list.
The `notes` field in `results.json` will record the exact ccx command that was used.
If the run fails, the `notes` field will also include the error message and the file that indicated the failure.
The physics defined in the input deck must not be changed.
