Use the FEniCS legacy library (dolfin).
Solve a 2D plane-stress small-strain orthotropic elasticity problem.
The geometry is a rectangle defined by (0, 1.0) x (0, 0.20) meters.
Use a 50x25 structured mesh on the rectangle.
The displacement finite element function space should use second-degree Lagrange elements.
The local material axes are rotated 30 degrees anticlockwise with respect to the global x-y axes.
The local orthotropic material properties are E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
The bottom edge (y=0) is fixed, with u_x = 0 and u_y = 0.
The top edge (y=0.20) has a uniform downward traction of (0, -10 MPa).
The vertical sides (x=0 and x=1) are traction-free.
Use a direct linear solver for the system of equations.
Save a color map of the x-component of displacement (u_x) to a file named q8_ux.png.
Save a color map of the von Mises stress to a file named q8_vm.png.
Save the displacement and stress fields to a file named q8_solution.xdmf.
