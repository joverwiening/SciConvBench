Create a file named `case_118.inp` in the working directory with the provided input deck content.
Run the CalculiX simulation for the `case_118.inp` file.
Use either `ccx -i case_118` or `ccx case_118` to run the simulation.
Determine the version of CalculiX by running `ccx -v` or an equivalent command.
Check for the string 'JOB COMPLETED' in the output file `case_118.sta` to determine if the run was successful.
Create a JSON file named `results.json` in the working directory.
The `results.json` file must conform to the specified schema.
The `solver` field in the JSON will be "calculix".
The `case_id` field in the JSON will be "case_118".
The `status` field in the JSON will be "success" if the run completed successfully, otherwise "error".
The `ccx_version` field in the JSON will contain the version string obtained from the version command.
The `artifacts` field in the JSON will be an empty list.
The `notes` field in the JSON will contain the exact CalculiX command used.
If the run fails, the `notes` field will also include the error message and the name of the file that indicated the failure.
The error message for a failed run will be taken from the standard error output of the `ccx` command.
