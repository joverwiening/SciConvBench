Use a recent stable release of OpenFOAM (OpenFOAM‑10 or later).  
Start from the standard buoyantCavity tutorial case.  
Replace the laminar turbulence model with the k‑omega SST turbulence model.  
Assume the working fluid is air with standard properties at room temperature.  
Set the Rayleigh number to 1 × 10⁶ by using a temperature difference of approximately 10 K across the cavity.  
Run the case as a transient simulation.  
Set the simulation end time to 100 seconds.  
Choose an initial time step of about 1 × 10⁻³ seconds and adjust as needed to keep the Courant number ≤ 0.5.  
Configure all other case settings (boundary conditions, mesh, solver settings, etc.) as in the original buoyantCavity tutorial, adapting them as necessary for the turbulent k‑omega SST model.
