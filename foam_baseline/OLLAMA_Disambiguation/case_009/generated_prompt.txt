The cavity geometry is a square domain 1 unit by 1 unit in the x‑y plane with a thickness of 0.1 units in the z‑direction, treated as a 2‑D case using empty boundary conditions on the front and back faces.  
The simulation runs from time 0 to 10 s with a time step of 0.005 s and writes results every 100 time steps.  
The fluid kinematic viscosity is constant ν = 1e‑05 m²/s.  
Use the realizable k‑ε turbulence model with standard coefficients: Cμ = 0.09, σ_k = 1.0, σ_ε = 1.3, C1_ε = 1.44, C2_ε = 1.92.  
Initialize turbulence fields uniformly: k = 1.5e‑4 m²/s² with kqRWallFunction on all walls, ε = 1.4e‑4 m²/s³ with epsilonWallFunction on all walls, and nut = 0 m²/s with nutkWallFunction on all walls.  
Use the pisoFoam solver.  
Set the convection schemes as follows: div(phi,U) Gauss limitedLinearV 1, div(phi,k) Gauss limitedLinear 1, div(phi,epsilon) Gauss limitedLinear 1, and the viscous term as div((nuEff*dev2(T(grad(U))))) Gauss linear.  
Velocity boundary conditions: the top wall (named movingWall) is a no‑slip wall with U = (1 0 0) m/s; all other walls (named fixedWalls) are no‑slip with U = (0 0 0); front and back faces are empty.  
Pressure boundary condition: zeroGradient on all walls and on the empty faces.  
Initial fields: U = (0 0 0) everywhere at time 0; p = 0 Pa everywhere at time 0.  
pisoFoam solver settings: 2 pressure‑velocity correctors, 0 non‑orthogonal correctors; momentum equation solved with smoothSolver, tolerance 1e‑06, relTol 0.1; pressure equation solved with GAMG, tolerance 1e‑06, relTol 0.1; relaxation factors: p = 0.3, U = 0.7.
