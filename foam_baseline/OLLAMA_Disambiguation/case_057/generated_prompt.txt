Simulate turbulent flow in a 2D channel using pisoFoam with the k‑epsilon turbulence model.  
The channel dimensions are length 2 m, height 0.1 m, and width (depth) 0.01 m.  
At the inlet apply a uniform velocity U = (1 0 0) m s⁻¹ as a fixedValue condition.  
Set the inlet turbulence quantities to k = 3.75 × 10⁻³ m² s⁻² and ε = 0.017 m² s⁻³, both as fixedValue.  
At the outlet set the pressure p to a fixedValue of 0 (zero gauge pressure).  
For the topWall and bottomWall patches apply: U = noSlip, p = zeroGradient, k = kqRWallFunction, ε = epsilonWallFunction, nut = nutkWallFunction.  
Initialize the fields at startTime = 0 s with U = (0 0 0), p = 0, k = 3.75 × 10⁻³ m² s⁻², and ε = 0.017 m² s⁻³.  
Run the simulation from startTime = 0 s to endTime = 5 s with a time step deltaT = 0.001 s, resulting in 5 000 time steps.  
Write the solution fields every 0.5 s of simulated time (every 500 time steps) using writeControl = runTime and writeInterval = 0.5 in system/controlDict.  
The mesh resolution (number of cells in the streamwise, vertical, and depth directions) is to be defined by the user.
