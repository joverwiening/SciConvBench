Simulate a 2D transient, laminar, incompressible lid-driven cavity flow using the icoFoam solver.
Geometry: The domain is a square cavity of size 0.1m x 0.1m. The simulation is 2D, represented by a single cell depth of 0.01m with 'empty' boundary conditions on the front and back faces.
Mesh: Use blockMesh to create a uniform Cartesian mesh of 20x20x1 cells.
Physical Properties: The fluid has a constant kinematic viscosity nu = 0.01 m^2/s.
Boundary Conditions:
- U (velocity): The top wall ('movingWall') has a fixedValue uniform velocity of (1 0 0) m/s. The 'fixedWalls' (left, bottom, right) have a noSlip condition (fixedValue uniform (0 0 0)).
- p (pressure): All walls have a zeroGradient boundary condition.
Initial Conditions: The entire domain is initialized with zero velocity and zero pressure.
Time Controls: Run the simulation from t=0 to endTime = 0.5 s, with a fixed time step deltaT = 0.005 s. Write results every 0.1 s.
