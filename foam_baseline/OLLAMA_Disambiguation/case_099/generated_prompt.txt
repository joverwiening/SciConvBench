Model steady buoyant flow through a porous medium using buoyantBoussinesqSimpleFoam with an explicit Darcy‑Forchheimer resistance source defined in fvOptions.  
The porous block is a 2‑D rectangle with length 0.20 m, height 0.40 m, and thickness 0.01 m.  
Assume a porosity of 0.9 for the porous medium.  
Use water with Boussinesq reference properties.  
Apply a fixed temperature of 303 K on the left (heated) wall and a fixed temperature of 293 K on the right (cooled) wall; top and bottom walls have zeroGradient temperature; front and back are empty.  
Set velocity boundary condition to noSlip on all walls (leftWall, rightWall, topWall, bottomWall, frontAndBack).  
Set pressure boundary condition to fixedFluxPressure on all walls.  
Use a Darcy resistance coefficient d = 1e8 1/m, corresponding to an isotropic permeability k ≈ 1e-14 m².  
Set the Forchheimer resistance coefficient f = (0 0 0).  
Use gravity vector (0 -9.81 0) m s⁻².  
No separate inlet or outlet patches; the domain is closed with solid walls.
