Create a 3‑D channel geometry with length 2.0 m in the x‑direction, height 0.10 m in the y‑direction, and width 0.10 m in the z‑direction.  
Generate the mesh with blockMesh using 100 cells in x, 50 cells in y, and 50 cells in z, refining near the walls if desired.  
Set fluid properties: kinematic viscosity ν = 1.5 × 10⁻⁵ m² s⁻¹ and density ρ = 1.225 kg m⁻³ in constant/transportProperties.  
Use pimpleFoam as the solver.  
Apply a mean‑velocity forcing (meanVelocityForce) to achieve a bulk velocity of (1 0 0) m s⁻¹; compute the corresponding pressure gradient automatically.  
Employ the k‑omega SST RAS turbulence model with wall functions: kqRWallFunction for k, omegaWallFunction for ω, and nutkWallFunction for nut.  
Set the inlet and outlet patches as cyclic boundaries for both velocity (type cyclic) and pressure (type cyclic).  
On the lowerWall and upperWall patches set velocity U = fixedValue (0 0 0) (no‑slip), pressure p = zeroGradient, turbulent kinetic energy k = kqRWallFunction, specific dissipation rate ω = omegaWallFunction, and turbulent viscosity nut = nutkWallFunction.  
Initialise the fields at startTime = 0 s with uniform values: U = (1 0 0) m s⁻¹, p = 0 Pa, k = 0.001 m² s⁻² (or based on a turbulence intensity of 5 %), and ω = 1.0 s⁻¹ (or computed from k and SST parameters).  
Run the simulation from time 0 s to 5 s.  
Use a fixed initial time step Δt = 0.001 s, enable adjustTimeStep, and limit the Courant number to a maximum of 1.0 (maxCo 1.0).
