Q: What specific discretization schemes would you like to use for the convective and diffusive terms in the fvSchemes file?
A: **Convective (divSchemes)**  
- `divSchemes` – use a second‑order upwind scheme, e.g.  
  ```foam
  divSchemes
  {
      div(phi,U)        Gauss linearUpwind grad(U);
      div(phi,k)        Gauss linearUpwind;
      div(phi,epsilon) Gauss linearUpwind;
      div(phi,T)        Gauss linearUpwind;
      div(phi,nuTilda)  Gauss linearUpwind;
  }
  ```

**Diffusive (laplacianSchemes)**  
- `laplacianSchemes` – use a second‑order central differencing scheme with correction, e.g.  
  ```foam
  laplacianSchemes
  {
      laplacian(nu,U)        Gauss linear corrected;
      laplacian(alphaEff,T)  Gauss linear corrected;
      laplacian(nuEff,k)     Gauss linear corrected;
      laplacian(nuEff,epsilon) Gauss linear corrected;
  }
  ```
