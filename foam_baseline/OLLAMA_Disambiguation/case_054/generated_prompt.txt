Use a perfect‑gas model with constant transport properties, specific‑heat ratio γ = 1.4, free‑stream static temperature T = 300 K and pressure p = 101 325 Pa.  
Run the case with the density‑based solver rhoCentralFoam as a laminar (inviscid) simulation with no turbulence model.  
Create a rectangular computational domain 1.0 m long in the x‑direction and 0.5 m high in the y‑direction.  
Generate a uniform structured mesh of 200 cells in the x‑direction and 100 cells in the y‑direction (200 × 100 cells) using blockMeshDict.  
Apply an inlet boundary condition with velocity components Uₓ = 694.5 m s⁻¹ and Uᵧ = 0 m s⁻¹.  
Place a 10‑degree wedge defined by the line segment from the tip at (0.20 m, 0 m) to the outlet intersection at (1.00 m, 0.141 m).  
Set the bottom wall to a slip condition, the top wall to a slip (far‑field) condition, and the outlet to zeroGradient for all variables (supersonic outflow).  
Run the simulation from time 0 to endTime = 0.005 s with a fixed time‑step size deltaT = 5 × 10⁻⁷ s (or a Courant number ≈ 0.5 if adaptive).  
Write output files every writeInterval = 0.001 s.  
Record the full field data for velocity vector U (x‑ and y‑components), static pressure p, static temperature T (or internal energy), and density rho at each write interval for post‑processing of Mach‑number distribution and shock‑angle location.
