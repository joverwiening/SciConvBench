Simulate pulverized coal combustion in a 2D furnace using the coalChemistryFoam solver.
SOLVER: coalChemistryFoam, which handles reacting Lagrangian particles with devolatilization, char combustion, and radiation.
GEOMETRY: A 2D rectangular furnace, 2 m high and 0.5 m wide. The primary air/coal inlet is at the bottom center, and the outlet is at the top.
 MESH: Use blockMesh to create a 50x200 (width x height) mesh, refined near the inlet.
GAS PHASE BCs: Primary Inlet (air+coal): U=(0 20 0) m/s, T=400 K, O2=0.233, N2=0.767. Outlet: totalPressure p0=101325 Pa. Walls: noSlip, fixed temperature T=1200 K.
COAL PROPERTIES (constant/coalCloudProperties): Inject a high-volatile bituminous coal. Define its composition (ultimate/proximate analysis). Use a Rosin-Rammler particle size distribution with a mean diameter of 100 microns. Injection mass flow rate: 0.1 kg/s.
COMBUSTION SUBMODELS (constant/combustionProperties): Devolatilization: Use the 'singleKinetic' model with specified rate constants. Char Combustion: Use the 'diffusionLimited' rate model. Gas-phase reactions: Use a simple two-step mechanism for volatile matter (represented as CH4) and CO combustion.
RADIATION MODEL (constant/radiationProperties): Use the P1 radiation model. Set absorption/emission properties for the gas mixture using a 'wsggm' (weighted-sum-of-gray-gases) model. Particles are assumed to have an emissivity of 0.9.
TURBULENCE: Use the standard k-epsilon RAS model with appropriate wall functions and inlet conditions.
TIME CONTROLS: This is a steady-state problem. Use the PIMPLE algorithm in steady-state mode (nOuterCorrectors > 1). Run for 2000 iterations. Set deltaT to 1 and use relaxation factors in fvSolution for stability.
