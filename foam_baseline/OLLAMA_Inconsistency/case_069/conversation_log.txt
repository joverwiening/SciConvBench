Q: What turbulence intensity or inlet values for k and ε should be used at the tangential inlet?
A: Make a reasonable assumption based on best practice.  
A common choice is a turbulence intensity of about 5 % at the inlet.  
With the inlet velocity taken as 10 m s⁻¹ (as suggested earlier), the corresponding turbulence quantities are:

* **k** ≈ 1.5 · (U · I)² = 1.5 · (10 · 0.05)² ≈ 0.38 m² s⁻²  
* **ε** ≈ Cμ³⁄⁴ · k³⁄² / l, with Cμ = 0.09 and a length scale l ≈ 0.07 · D (≈ 0.003 – 0.005 m for a typical cyclone inlet). This gives ε on the order of 10 – 20 m² s⁻³.

So you can set, for example:

```
inlet
{
    type            turbulentIntensityKineticEnergyInlet;
    intensity       uniform 0.05;          // 5 % turbulence intensity
    value           uniform 0.38;          // k (m2/s2)
    epsilon         uniform 15;            // ε (m2/s3) – adjust to match chosen length scale
}
```

If you prefer to specify k and ε directly, values of **k ≈ 0.3–0.5 m² s⁻²** and **ε ≈ 10–20 m² s⁻³** are reasonable starting points. Adjust as needed based on convergence or experimental data.
