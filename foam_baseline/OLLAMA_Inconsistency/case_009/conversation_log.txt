Q: What should be the contents of the `fvSchemes` file, including the reconstruction schemes for density, velocity, and temperature, as well as the time discretization settings?
A: **fvSchemes**

```foam
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      fvSchemes;
}

//--- time discretisation -------------------------------------------------
ddtSchemes
{
    default         Euler;          // inviscid, explicit
}

//--- gradient schemes ----------------------------------------------------
gradSchemes
{
    default         Gauss linear;   // as required
}

//--- divergence (convection) schemes ------------------------------------
divSchemes
{
    default         none;
    // rhoCentralFoam uses the fluxScheme entry (see below)
}

//--- interpolation (reconstruction) schemes -----------------------------
reconstructionSchemes
{
    rho             vanLeer;
    U               vanLeer;
    T               vanLeer;
}

//--- flux scheme for rhoCentralFoam --------------------------------------
fluxScheme       Kurganov;

//--- Laplacian (diffusion) schemes ---------------------------------------
laplacianSchemes
{
    default         Gauss linear corrected;
}

//--- interpolation schemes (for other fields) ---------------------------
interpolationSchemes
{
    default         linear;
}

//--- surface normal gradient schemes ------------------------------------
snGradSchemes
{
    default         limited;
}
```

Q: What should be the contents of the `transportProperties` file to enable the Sutherland viscosity model with μRef = 1.7894e‑5 Pa·s at TRef = 300 K?
A: According to the complete requirement you should **not** enable the Sutherland viscosity model. For an inviscid simulation set the viscosity to zero (or a negligible constant) in `transportProperties`, e.g.:

```foam
transportModel  const;
mu              0;   // inviscid flow – zero (or negligible) viscosity
```

FoamFile

adjustTimeStep  no;
maxCo           0.5;   // optional, can be omitted

purgeWrite      0;

Q: What should be the contents of the fvSolution file, including the solver settings and tolerances for the simulation?
A: **fvSolution**

```foam
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      fvSolution;
}

//--- linear solvers -------------------------------------------------
solvers
{
    rho
    {
        solver          smoothSolver;
        smoother        GaussSeidel;
        tolerance       1e-6;
        relTol          0.1;
    }

    U
    {
        solver          smoothSolver;
        smoother        GaussSeidel;
        tolerance       1e-6;
        relTol          0.1;
    }

    T
    {
        solver          smoothSolver;
        smoother        GaussSeidel;
        tolerance       1e-6;
        relTol          0.1;
    }

    p
    {
        solver          PCG;
        preconditioner  DIC;
        tolerance       1e-6;
        relTol          0.1;
    }
}

//--- PIMPLE algorithm (transient) ------------------------------------
PIMPLE
{
    nOuterCorrectors          1;
    nCorrectors               2;
    nNonOrthogonalCorrectors  0;
    momentumPredictor         yes;

    residualControl
    {
        rho 1e-6;
        U   1e-6;
        T   1e-6;
        p   1e-6;
    }
}

//--- relaxation (optional for explicit schemes) ----------------------
relaxationFactors
{
    fields
    {
        p 0.7;
    }
    equations
    {
        rho 0.7;
        U   0.7;
        T   0.7;
    }
}
```
