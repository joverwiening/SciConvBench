Simulate the transient start‑up flow of a Bingham plastic fluid in a 2‑D pipe using the icoFoam solver.  
The computational domain is a rectangle 1.0 m long and 0.1 m high.  
Create the mesh with blockMesh using 100 cells in the axial (x) direction and 20 cells in the radial (y) direction; set the front and back patches to type empty.  
Apply a fixed inlet velocity of (0.1 0 0) m s‑1, a zeroGradient outlet for velocity with a fixed pressure of 0, and noSlip wall conditions on the remaining boundaries.  
Run the simulation from t = 0 s to t = 5 s with a constant time step of 0.005 s, targeting a maximum Courant number of 0.5.  
In constant/transportProperties define the fluid as a Bingham plastic with:  
transportModel  BinghamPlastic;  
rho             1000;  
tau0            10;  
mu0             0.1;  
muInf           0.01.  
Use the default numerical schemes and solvers appropriate for icoFoam.
