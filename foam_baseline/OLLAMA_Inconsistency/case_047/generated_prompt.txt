Use simpleFoam for a steady-state turbulent pipe flow simulation with the k‑epsilon RANS model.  
Set the fluid to water with a kinematic viscosity of 1e‑6 m²/s.  
Model a pipe of diameter 0.1 m and length 1 m (approximately 10 × diameter).  
Specify an inlet velocity of 1 m/s in the x‑direction.  
In the 0/U file set the internalField to uniform (1 0 0).  
Apply a fixedValue boundary condition with value uniform (1 0 0) at the inlet patch for U.  
Apply a fixedValue boundary condition with value uniform (0 0 0) at the pipe wall for U.  
Apply a zeroGradient boundary condition for U at the outlet patch.  
In the 0/p file set the internalField to uniform 0.  
Apply a fixedValue boundary condition with value uniform 0 at the inlet patch for p.  
Apply a zeroGradient boundary condition for p at the outlet patch.  
Apply a zeroGradient boundary condition for p at the pipe wall.  
In the 0/k file set the internalField to uniform 0.  
Apply a fixedValue boundary condition with value 0.00375 at the inlet patch for k.  
Apply a kqRWallFunction boundary condition for k at the pipe wall.  
Apply a zeroGradient boundary condition for k at the outlet patch.  
In the 0/epsilon file set the internalField to uniform 0.  
Apply a fixedValue boundary condition with value 0.001 at the inlet patch for epsilon.  
Apply an epsilonWallFunction boundary condition for epsilon at the pipe wall.  
Apply a zeroGradient boundary condition for epsilon at the outlet patch.  
In constant/transportProperties set nu to 1e‑6.  
In constant/turbulenceProperties set simulationType to RAS and RASModel to kEpsilon.
