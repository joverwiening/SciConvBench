Create a case directory named bubbleColumn2D.  
Set up a 2D gas–liquid bubble column simulation using multiphaseEulerFoam (Euler–Euler) in a rectangular domain with x ranging from 0 to 0.15 m, y ranging from 0 to 1.00 m, and z ranging from 0 to 0.10 m, with the height oriented along the +y direction and the domain thin in the z direction.  
Generate a structured hexahedral mesh with 25 cells in the x direction, 75 cells in the y direction, and 1 cell in the z direction, using simpleGrading (1 1 1).  
Define inlet, outlet, and wall patches in blockMeshDict and treat the domain as 2‑D by using empty faces in the z direction.  
Use water as the continuous liquid phase modeled with heRhoThermo and an rPolynomial equation of state with coefficients 0.001278, -2.1055e-06, 3.9689e-09, 4.3772e-13, -2.0225e-16; molecular weight 18; specific heat capacity Cv = 4195 J/(kg·K); dynamic viscosity 3.645e-4 Pa·s; and Prandtl number 2.289.  
Use air as the dispersed gas phase modeled with heRhoThermo and a perfectGas equation of state; molecular weight 28.9; specific heat capacity Cp = 1007 J/(kg·K); dynamic viscosity 1.84e-05 Pa·s; and Prandtl number 0.7.  
Set gravity to act vertically along the –y direction with vector (0 0 -9.81) m/s².  
Apply bubble size models: isothermal diameter d0 = 3e-3 m for air and constant diameter d = 1e-4 m for water.  
Configure momentum transport as laminar for both phases by setting simulationType to laminar in the respective momentumTransport files.  
Define multiphase interaction in phaseProperties with phases (air water), water as the reference phase, and residualAlpha = 1e-6 for both phases.  
Use a linear blending scheme with minFullyContinuousAlpha = 0.7 and minPartlyContinuousAlpha = 0.3 for default models, and 0.5 for drag.  
Set surface tension between air and water to a constant sigma = 0.07 N/m.  
Select the Schiller‑Naumann drag model for air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water configurations.  
Use a constant virtual mass coefficient Cvm = 0.5 for both directions.  
Employ the Ranz‑Marshall heat transfer model for both phases with residualAlpha = 1e-4.  
Initialize at t = 0 with water velocity uniform (0 0 0), air velocity uniform (0 0.1 0), water volume fraction uniform 1, pressure p_rgh uniform 1e5 Pa, air temperature uniform 300 K, and water temperature uniform 350 K.  
Set the initial phase distribution so that the volume fraction of air is 1 and water is 0 everywhere except in the box region from (0 0 0) to (0.15 0.701 0.1) where the volume fraction of air is 0 and water is 1.  
At the inlet, apply fixedValue boundary conditions: air velocity (0 0.1 0), water velocity (0 0 0), air volume fraction 0.5, water volume fraction 0.5, air temperature 300 K, and water temperature 350 K.  
At wall boundaries, apply fixedValue for velocities (0 0 0) for both phases, zeroGradient for volume fractions of both phases, fixedFluxPressure for p_rgh, and zeroGradient for temperatures of both phases.  
Configure time controls with startTime = 0 s, endTime = 20 s, deltaT = 0.005 s, adjustTimeStep = no, maxCo = 0.5, maxDeltaT = 1 s, and writeInterval = 1 s.
