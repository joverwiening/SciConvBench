Set up a 2D, incompressible, steady-state airflow simulation over a symmetric NACA0012 airfoil using the simpleFoam solver.  
Create a C‑grid topology around the airfoil with the mesh one cell thick in the z‑direction.  
Define the frontAndBack patch as a wall in system/blockMeshDict with the specified faces.  
Name the inlet patch “inlet” and the outlet patch “outlet” in system/blockMeshDict.  
Name the airfoil surface patch “airfoil” in system/blockMeshDict and in all boundary‑condition files.  
Place the inlet boundary 5 chord lengths upstream of the airfoil, the outlet boundary 15 chord lengths downstream, and the top and bottom boundaries 10 chord lengths away from the airfoil surface.  
Provide the NACA0012 airfoil coordinates in a separate file called airfoil.dat and reference this file when generating the mesh.  
In 0/U, set a uniform inlet velocity of (10 0 0) m/s on the inlet patch, a zeroGradient condition on the outlet and airfoil patches, and noSlip on the frontAndBack patches.  
In 0/p, apply zeroGradient on the inlet and airfoil patches, fixedValue uniform 0 on the outlet patch, and zeroGradient on the frontAndBack patches.
