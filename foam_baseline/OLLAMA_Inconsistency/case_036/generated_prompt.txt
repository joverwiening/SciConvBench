Simulate the quasi‑static deflection of a 3D steel cantilever beam using linear elasticity.  
The beam is 1 m long, 0.1 m high, and 0.1 m wide.  
Create a structured mesh with 100 cells along the length and 20 cells in each of the height and width directions (100 × 20 × 20 cells total).  
In constant/mechanicalProperties set the steel properties: Young’s modulus E = 200e9 Pa and Poisson ratio ν = 0.3.  
In 0/D apply the following boundary conditions: the fixed end uses fixedValue uniform (0 0 0); the loaded end uses tractionDisplacement with traction uniform (0 -1000 0) and pressure uniform 0; all other faces use zeroGradient.  
In system/controlDict set application pimpleFoam, endTime 1, and use a uniform time step Δt = 0.01 s.  
Set the initial displacement field to uniform (0 0 0) everywhere.  
Use a convergence tolerance of 1 e‑6 for the solver residuals.
