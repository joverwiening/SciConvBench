Set up a steady-state incompressible turbulent flow simulation of the 2‑D Pitz and Daily combustor using the simpleFoam solver.  
Generate a uniform mesh with a cell size of approximately 0.001 m in both directions, yielding about 10 000 cells along the length and 10 cells through the height (≈1 × 10⁵ cells total).  
Apply velocity boundary conditions: fixedValue (10 0 0) m/s at the inlet patch, zeroGradient at the outlet patch, and noSlip at the upperWall and lowerWall patches; set the front and back patches to type empty.  
Apply pressure boundary conditions: zeroGradient at the inlet and wall patches, and fixedValue 0 at the outlet patch.  
Define turbulence properties in constant/turbulenceProperties with simulationType RAS and use the kEpsilon model (RASModel kEpsilon, turbulence on, printCoeffs on).  
Set inlet turbulence quantities using typical best‑practice values: turbulence intensity 5 % and turbulent length scale 0.01 m, which correspond to k ≈ 0.375 m²/s² and ε ≈ 3.9 m²/s³ at the inlet.  
Use under‑relaxation factors of 0.3 for pressure, 0.7 for velocity, and 0.7 for both k and ε in the simpleFoam simulation.  
Specify residual convergence criteria with target residuals of 1e‑5 for p, U, k, and ε.  
Run the simulation for 500 iterations.  
Configure fvSolution linear solvers as follows:  
- Pressure (p): solver GAMG, tolerance 1e‑6, relTol 0.1, smoother DIC, nPreSweeps 0, nPostSweeps 2, nFinestSweeps 2, cacheAgglomeration true, nCellsInCoarsestLevel 10, agglomerator faceAreaPair, mergeLevels 1.  
- Velocity (U): solver smoothSolver, smoother GaussSeidel, tolerance 1e‑5, relTol 0.  
- Turbulence quantities (k|epsilon): solver smoothSolver, smoother GaussSeidel, tolerance 1e‑5, relTol 0.  
Do not use a hybrid RANS‑LES model; the simulation employs only the RANS k‑Epsilon model as defined.
