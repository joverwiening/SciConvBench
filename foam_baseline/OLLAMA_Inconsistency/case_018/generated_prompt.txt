Set up a laminar counter-flow diffusion flame using reactingFoam in a 2-D opposed-jet configuration. Define the computational domain with x ranging from 0 to 0.02 m, y from –0.01 to 0.01 m, and z from –0.01 to 0.01 m. Create a mesh with 100 cells in the x‑direction, 40 cells in the y‑direction, and 1 cell in the z‑direction, leaving the front and back boundaries empty. Apply four patches: a left fuel inlet at x = 0, a right air inlet at x = 0.02, a top outlet, and a bottom outlet. Set the fuel inlet temperature to 293 K, velocity to +0.1 m s⁻¹ in the +x direction, and mass fraction of methane Y_CH4 to 1.0 (pure methane). Set the air inlet temperature to 293 K, velocity to +0.1 m s⁻¹ in the +x direction, and mass fractions Y_O2 = 0.23 and Y_N2 = 0.77 (balance N2). Initialise the entire domain temperature to 2000 K and mass fractions to Y_CH4 = 0, Y_O2 = 0.23, Y_N2 = 0.77, with all other species set to zero. Use the EulerImplicit chemistry model with the Rosenbrock43 ODE solver. Enable laminar combustion and momentum transport. Use hePsiThermo for thermodynamics, coefficientWilkeMultiComponentMixture for transport properties, Sutherland model for viscosity, and JANAF thermodynamic data. Set the simulation pressure to 101325 Pa. Use a time step of 1e‑4 s, run the simulation to an end time of 0.5 s, and write results every 0.05 s.
