Set up the classic 2D dam‑break problem with a tank 2 m long, 1 m high and 0.01 m wide (spanwise). Use a 2D mesh extruded one cell in the spanwise direction with frontAndBack set to empty. Generate a uniform mesh with 200 cells along the length, 100 cells along the height and a single cell in the spanwise direction. Initialise the VOF field alpha.water to 1 inside the initial water column and 0 elsewhere using setFields. The initial water column occupies the left half of the tank and half the tank height (1 m × 0.5 m region). Apply gravity (0 -9.81 0). Use the following boundary conditions: tank walls – noSlip for U, zeroGradient for p_rgh and zeroGradient for alpha.water; open top – pressureInletOutletVelocity for U, totalPressure/fixedValue 0 for p_rgh, inletOutlet for alpha.water with inletValue uniform 0. In system/controlDict set application solidDisplacementFoam.
