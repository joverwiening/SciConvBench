Set up a 2D dam break simulation using the pimpleFoam solver.  
Define a rectangular domain with a length of 2 m, a height of 1 m, and a depth of 0.1 m.  
Place an initial water column on the left side of the domain extending from x = 0 m to x = 1 m and spanning the full height of the domain.  
Initialize the volume fraction field using setFields so that alpha.water = 1 inside the water column region and alpha.water = 0 elsewhere (air).  
Set the gravity vector to (0 -9.81 0).  
In controlDict, set endTime to 5 s.  
Create a transportProperties dictionary containing two phases, “water” and “air”, with the following properties:  
- water: density = 1000 kg m⁻³, dynamic viscosity = 1 × 10⁻³ Pa·s.  
- air: density = 1.225 kg m⁻³, dynamic viscosity = 1.8 × 10⁻⁵ Pa·s.
