Set up a 2D dam break simulation using the interFoam solver.  
The domain is 1 m long and 1 m high.  
Use a uniform mesh with 100 cells in the x‑direction and 100 cells in the y‑direction.  
Initialize the water column in the region 0 < x < 0.2 and 0 < y < 0.5 with alpha.water = 1, and set alpha.water = 0 elsewhere using setFieldsDict.  
Define gravity in constant/g as g (0 0 -9.81).  
Apply a pressureInletOutletVelocity condition on the top boundary and a noSlip condition on all other boundaries.  
Set the simulation end time to 1 s.  
Use a maximum Courant number of 0.5 to control the time step.  
Write solution files every 0.01 s.
