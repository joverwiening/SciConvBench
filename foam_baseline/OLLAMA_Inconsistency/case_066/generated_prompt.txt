Simulate steady-state, incompressible, turbulent flow and heat transfer in a 2D pipe using the simpleFoam solver.  
The pipe has a diameter of 0.1 m and a length of 2 m; the simulation is 2D, so the front and back patches are of type “empty”.  
Use the standard k‑ε turbulence model with wall functions.  
The fluid is air with standard properties.  
Set the inlet velocity to a uniform 1 m/s in the x‑direction.  
Set the inlet temperature to a fixed value of 300 K.  
Set the outlet to a fixed gauge pressure of 0 Pa (zeroGradient for velocity).  
Make the pipe wall adiabatic by applying a zeroGradient temperature condition (no heat flux).  
Assume a turbulence intensity of 5 % at the inlet and a turbulence length scale of 0.07 × diameter = 0.007 m.  
Compute the inlet turbulent kinetic energy k as 0.00375 m²/s² and set it as a fixedValue uniform condition.  
Compute the inlet turbulent dissipation ε as approximately 0.0054 m²/s³ and set it as a fixedValue uniform condition.  
Apply zeroGradient for k and ε at the outlet.  
Apply nutkWallFunction for k and epsilonWallFunction for ε on the wall (or zeroGradient if wall functions are not used).  
Set the front and back patches to type “empty” for all fields.
