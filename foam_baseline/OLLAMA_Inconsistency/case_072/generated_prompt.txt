Set up a Rayleigh‑Bénard convection case using the buoyantBoussinesqPimpleFoam solver.  
Create a 3‑D rectangular domain 1 m × 1 m × 0.1 m with the height aligned with the Z‑axis.  
Use a mesh with 100 cells in the X‑direction, 100 cells in the Y‑direction, and an appropriate number of cells in the Z‑direction to resolve the thin vertical layer (to be chosen based on best practice).  
Define the fluid properties in constant/transportProperties with Boussinesq approximation: beta = 0.00341, T0 = 300 K, nu = 1.5e‑5 m²/s, Pr = 0.71.  
Set the gravity vector in constant/g as g (-9.81 0 0).  
Apply fixedValue temperature boundary conditions: bottom wall (z = 0) T = 310 K, top wall (z = 0.1 m) T = 300 K.  
Apply periodic boundary conditions on the side walls for all fields.  
Apply noSlip velocity boundary condition on the top and bottom walls; side walls inherit periodicity.  
Initialise the temperature field with a linear profile T = 310 − 100 *z (K, z in metres), giving 310 K at the bottom and 300 K at the top.  
Initialise the velocity field as quiescent: U = (0 0 0) everywhere.  
Run the case as a transient simulation to capture the development of convection cells.
