Use the case directory `~/OpenFOAM/<user-name>/run/settlingTankCase/`.  
In the `0/` folder of this case, edit the files `alpha.sediment`, `alpha.water`, and `alpha.oil`.  
Set the `internalField` in each of these files to `uniform 0.5;`.  
Leave all other entries in the files unchanged.  
These initial uniform volume fractions will later be modified by `setFieldsDict` to create stratified layers.
