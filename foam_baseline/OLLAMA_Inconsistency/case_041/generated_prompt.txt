Create a case directory named cylinderRe100.  
Generate a 2‑D mesh with approximately 200 cells in the streamwise (x) direction, 80 cells in the vertical (y) direction, and a single cell in the spanwise (z) direction.  
Place a cylinder of diameter 0.1 m centered at (0.2 m, 0.2 m) inside a rectangular channel that is 2.2 m long and 0.41 m high.  
Set the fluid kinematic viscosity to 1e‑3 m²/s and the inlet velocity to a uniform (1 0 0) m/s.  
Use simpleFoam as the solver with startTime 0, endTime 200, deltaT 1, and writeInterval 10.  
For the velocity field U, apply the following boundary conditions: inlet fixedValue uniform (1 0 0), outlet zeroGradient, cylinderWall noSlip, topAndBottom noSlip, and frontAndBack empty.  
For the pressure field p, apply the following boundary conditions: inlet zeroGradient, cylinderWall zeroGradient, outlet fixedValue uniform 0, topAndBottom zeroGradient, and frontAndBack empty.  
Run the simulation until the final time to obtain the steady‑state flow field.
