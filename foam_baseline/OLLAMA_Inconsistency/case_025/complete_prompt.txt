Simulate the 3D, incompressible, turbulent flow around a cube mounted on the floor of a channel using `simpleFoam` with a RANS `kEpsilon` turbulence model. Use a fully 3D mesh (more than one cell in the spanwise direction). To emulate an infinitely wide channel, treat the two spanwise side patches (`left` and `right`) as symmetry boundaries.

In `system/blockMeshDict`, define the side patches as:
```foam
left
{
    type    symmetryPlane;
    faces
    (
        // ... faces for left patch
    );
}
right
{
    type    symmetryPlane;
    faces
    (
        // ... faces for right patch
    );
}
```

Use `noSlip` on all solid walls (floor, cube, top wall), a fixed inlet velocity on `inlet`, and a fixed outlet pressure on `outlet`.
