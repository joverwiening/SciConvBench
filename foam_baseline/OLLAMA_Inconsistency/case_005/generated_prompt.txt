Use OpenFOAM 10 or a comparable recent stable release.  
Create a case for the twoPhaseEulerFoam (Euler‑Euler) solver to simulate a 2‑D gas–liquid bubble column.  
The computational domain is a rectangular box with x ranging from 0 to 0.15 m, y from 0 to 1.00 m, and z from 0 to 0.10 m, with the height aligned with the +y direction and the domain thin in the z direction.  
Generate a structured hexahedral mesh with 25 cells in the x direction, 75 cells in the y direction, and 1 cell in the z direction, using simpleGrading (1 1 1).  
In blockMeshDict define four patch groups: inlet, outlet, walls (a single patch that combines all solid walls), and empty (the two faces normal to the z direction).  
Assign the standard patch name “empty” to the two z‑direction faces.  
Set the inlet patch to apply the following fixedValue conditions: air velocity (0 0.1 0), water velocity (0 0 0), alpha.air = 0.5, alpha.water = 0.5, T.air = 300 K, T.water = 350 K.  
Set the outlet patch to use zeroGradient for all transported fields and fixedFluxPressure for p_rgh.  
On the walls patch set air and water velocities to fixedValue (0 0 0), alpha.air and alpha.water to zeroGradient, p_rgh to fixedFluxPressure, and T.air and T.water to zeroGradient; also designate walls as the pressure reference for the p_rgh field.  
On the empty patches apply zeroGradient for all fields.  
Initialize at t = 0 with U.water = (0 0 0), U.air = (0 0.1 0), p_rgh = 1e5 Pa, T.air = 300 K, T.water = 350 K, alpha.water = 0, alpha.air = 1 everywhere, then overwrite the box region from (0 0 0) to (0.15 0.701 0.1) so that alpha.water = 1 and alpha.air = 0.  
Define phaseProperties with phases (air water), set water as the referencePhase, and use residualAlpha = 1e-6 for both phases.  
Use heRhoThermo for water with an rPolynomial equation of state having coefficients 0.001278 -2.1055e-06 3.9689e-09 4.3772e-13 -2.0225e-16, molecular weight 18, Cv = 4195 J kg⁻¹ K⁻¹, dynamic viscosity 3.645e-4 Pa·s, and Prandtl number 2.289.  
Use heRhoThermo for air with a perfectGas equation of state, molecular weight 28.9, Cp = 1007 J kg⁻¹ K⁻¹, dynamic viscosity 1.84e-5 Pa·s, and Prandtl number 0.7.  
Set the bubble size models: isothermal diameter d0 = 3e-3 m for air and constant diameter d = 1e-4 m for water.  
Configure momentum transport as laminar for both phases with simulationType laminar.  
Select the Schiller‑Naumann drag model for the configurations air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water.  
Use a constantCoefficient virtual mass model with Cvm = 0.5 for both directions.  
Apply the Ranz‑Marshall heat transfer model for both phase pairs with residualAlpha = 1e-4.  
Set surface tension between air and water to a constant sigma = 0.07 N m⁻¹.  
Use a linear blending scheme with minFullyContinuousAlpha = 0.7, minPartlyContinuousAlpha = 0.3 for default blending and 0.5 for drag blending.  
Set the time control parameters: startTime = 0 s, endTime = 20 s, deltaT = 0.005 s, adjustTimeStep = no, maxCo = 0.5, maxDeltaT = 1 s, writeInterval = 1 s.  
Use the field names alpha.air, alpha.water, U.air, U.water, T.air, T.water, and p_rgh throughout the case.  
Run the simulation with the twoPhaseEulerFoam solver.
