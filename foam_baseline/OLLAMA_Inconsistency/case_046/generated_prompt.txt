Set up a transient simulation of turbulent flow over a 2D cylinder in a channel using pimpleFoam.  
Specify the simulation type as LES in constant/turbulenceProperties and include a RAS sub‑dictionary with the kOmegaSST model.  
Use standard air properties for an incompressible fluid (density 1.225 kg m⁻³, kinematic viscosity 1.5 × 10⁻⁵ m² s⁻¹).  
Apply a uniform inlet velocity of 10 m s⁻¹.  
Set noSlip boundary conditions on the cylinder surface and on the channel walls.  
Assume a cylinder diameter of 0.1 m.  
Set the channel height to 0.4 m (four times the cylinder diameter).  
Set the channel length to 2.0 m (twenty times the cylinder diameter).  
Create a mesh with approximately 25 cells across the cylinder diameter.  
Run the transient simulation for a total time of 1.0 s, which corresponds to five flow‑through times (L/U = 0.2 s).  
Choose a time step that keeps the Courant number below 0.5 throughout the simulation.  
Use the Smagorinsky LES model with delta set to cubeRootVol.  
Enable the kOmegaSST RAS model for the sub‑grid scale turbulence.  
Write results at appropriate intervals for post‑processing.
