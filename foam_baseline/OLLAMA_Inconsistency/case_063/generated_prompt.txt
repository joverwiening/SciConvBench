Simulate the transient von Kármán vortex street behind a cylinder in a 2‑D channel using a 2‑D mesh extruded one cell in the z‑direction with `frontAndBack` set to `empty`.  
Set the kinematic viscosity to `nu = 1e-3 m^2/s`.  
Define the channel length as 20 times the cylinder diameter and the channel height as 10 times the cylinder diameter.  
Use a cylinder diameter of 1 m.  
Place the cylinder centre 5 diameters downstream from the inlet and centred vertically in the channel.  
Apply the following boundary conditions:  
- For `0/U`: inlet `fixedValue uniform (0.1 0 0)`, outlet `zeroGradient`, cylinder `noSlip`, top and bottom walls `slip`, `frontAndBack` `empty`.  
- For `0/p`: inlet `zeroGradient`, outlet `fixedValue uniform 0`, cylinder, top and bottom walls `zeroGradient`, `frontAndBack` `empty`.  
Set the simulation to run for a total physical time of 10 s with a time‑step size of 1 × 10⁻³ s.  
Generate the mesh with approximately 20 cells across the cylinder diameter (cell size ≈ 0.05 m).  
Use the `pimpleFoam` solver for the transient simulation.  
Assume laminar flow and do not include any turbulence model.  
In `system/controlDict`, set `application` to `pimpleFoam`.
