Model a de Laval nozzle with the following specifications:
Use air as the working fluid.
Use a perfect gas model with constant transport properties.
Set the specific heat ratio (gamma) to 1.4.
Set inlet total pressure to 5e5 Pa.
Set inlet total temperature to 600 K.
Use zeroGradient condition for inlet velocity.
Target Mach number range between 1.5 and 3.
Set outlet back pressure to 3.5e5 Pa to induce a normal shock in the diverging section.
