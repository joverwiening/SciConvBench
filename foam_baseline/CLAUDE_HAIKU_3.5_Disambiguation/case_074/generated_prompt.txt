Simulate flow over a 2D cylinder with the following specifications:
Solver is pimpleFoam.
Cylinder diameter is 0.1 m.
Computational domain extends from -10D to +25D in x-direction.
Use blockMesh with O-grid around cylinder, refining mesh in wake region.
Boundary conditions:
Inlet: U = fixedValue uniform (1.5 0 0); p = zeroGradient
Outlet: U = zeroGradient; p = fixedValue uniform 0
Cylinder wall: U = noSlip
Top and bottom: type slip
Reynolds number is 150.
Simulation is transient to observe vortex shedding.
