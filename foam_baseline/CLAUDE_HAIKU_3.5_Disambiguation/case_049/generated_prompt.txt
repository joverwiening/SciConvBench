Set up a dam break case with a water column collapsing under gravity in a tank of air.
The water column is located in the bottom-left corner of the tank.
Water column dimensions are 0.146m wide and 0.292m high.
Tank dimensions are 0.584m in length and 0.584m in height.
Initial velocity is uniform (0 0 0).
Initial reduced pressure (p_rgh) is uniform 0.
Water phase fraction (alpha.water) will be set using setFields utility.
Water will be defined in a box from (0 0 -1) to (0.146 0.292 1) with fieldValue 1.
Default field value for water will be 0.
Initial temperature will be set to 293.15K (20°C), which is a standard room temperature.
