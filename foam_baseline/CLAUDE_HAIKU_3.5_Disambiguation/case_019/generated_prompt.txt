Simulate a 2D flow past a circular cylinder using OpenFOAM Foundation v2206.
Use pimpleFoam solver for laminar flow simulation.
Set computational domain from x = -5 m to x = 5 m.
Set computational domain from y = -1.5 m to y = 2.5 m.
Set computational domain from z = -1 m to z = 1 m.
Place cylinder with 2 m diameter at origin (x = 0 m, y = 0 m).
Apply inlet boundary condition: U = (1 0 0) m/s.
Apply outlet boundary condition: U zeroGradient, p = 0.
Apply top and bottom wall boundary conditions: U noSlip, p zeroGradient.
Apply cylinder wall boundary conditions: U noSlip, p zeroGradient.
Set default back/front faces as empty (2-D).
Initialize fluid field with U = (0 0 0), p = 0.
Use generalisedNewtonian model with crosspowerlaw viscosity.
Set nuinf = 10, m = 0.4, n = 3.
Set viscosity to 0.01 m^2/s.
