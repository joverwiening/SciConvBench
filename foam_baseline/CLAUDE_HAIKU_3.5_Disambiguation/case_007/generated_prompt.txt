Use OpenFOAM v2206 (latest stable version at time of simulation).
Use standard desktop/workstation computational resources (8 CPU cores, 32GB RAM).
Use double precision floating point calculations.
Use standard PISO solver convergence tolerances:
- Velocity residual: 1e-6
- Pressure residual: 1e-5
- Turbulence field residuals: 1e-5

Simulation specifications:
Perform an incompressible lid driven cavity flow simulation.
Use a 20x20x1 grid in x, y, and z directions.
Set top wall ('movingWall') velocity to 1 m/s in x-direction.
Apply no-slip boundary condition on fixed walls.
Designate front and back faces as 'empty'.
Run simulation from time 0 to 10 with 0.005 time step.
Output results every 100 time steps.
Set viscosity (nu) to 1e-05 m^2/s.
Use k-epsilon turbulence model.
Initialize turbulence fields:
- k = 1.5e-4 uniformly
- epsilon = 1.4e-4 uniformly
- nut = 0 uniformly
Use pisoFoam solver.
Initialize domain with zero velocity.
Set convection schemes:
- div(phi,U) Gauss limitedLinearV 1
- div(phi,k) Gauss limitedLinear 1
- div(phi,epsilon) Gauss limitedLinear 1
Set viscous term as div((nuEff*dev2(T(grad(U))))) Gauss linear.
Apply wall function boundary conditions:
- kqRWallFunction for k
- epsilonWallFunction for epsilon
- nutkWallFunction for nut
