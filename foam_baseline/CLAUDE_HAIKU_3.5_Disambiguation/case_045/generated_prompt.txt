Set up a buoyant flow simulation in OpenFOAM using the buoyantBoussinesqPimpleFoam solver.
Create a computational domain of 1x1 meter with a 50x50 cell grid.
Set bottom boundary temperature to 300K.
Set top boundary temperature to 290K.
Apply noSlip boundary condition for velocity (U) on side walls.
Apply zeroGradient boundary condition for temperature (T) on side walls.
Apply fixedFluxPressure boundary condition for p_rgh on side walls.
Use fluid properties:
Reference density (rho0) = 1.0 kg/m^3.
Thermal expansion coefficient (beta) = 3.4e-3 1/K.
Kinematic viscosity (nu) = 1e-5 m^2/s.
Prandtl number (Pr) = 0.71.
Reference temperature (T0) = 295 K.
