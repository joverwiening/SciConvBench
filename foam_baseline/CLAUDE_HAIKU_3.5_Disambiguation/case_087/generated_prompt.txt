Set up a supersonic flow simulation over a forward-facing step.
Use a computational domain of 3 m (x) x 1 m (y).
Place a step height of 0.2 m starting at x=0.6 m.
Use grid resolution of approximately 150 cells in x and 50 cells in y.
Implement grid refinement near the step corner and along expected shock paths.
Set inlet boundary condition as supersonicFreestream with U=(1020.6 0 0), p=101325, T=300.
Set outlet boundary condition as waveTransmissive for pressure with pInf 101325.
Set outlet velocity and temperature as zeroGradient.
Use slip boundary conditions for bottom wall (including step faces) and top wall.
Set frontAndBack boundaries as empty.
Use Kurganov-Tadmor central scheme (upwind-biased) for spatial discretization.
Simulate as laminar flow with extremely low dynamic viscosity (mu = 1e-12).
Inlet Mach number is 3.
Flow is approximated as inviscid.
