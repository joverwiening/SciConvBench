Run a transient laminar two-phase dam-break simulation using interFoam in OpenFOAM.
Use a computational domain of (1,1,1) meters, discretized with a 32 x 32 x 32 uniform grid.
Set gravity vector as g = (0 0 -9.81) m/s^2.
Apply wall boundary conditions with no-slip (zero velocity) for x=0, x=1, y=0, y=1 faces.
Set the top (z=1) face as an open atmosphere patch.
Model two phases using Volume of Fluid (VOF) method:
Water phase: density = 1000 kg/m^3, viscosity = 1.0e-6 m^2/s
Air phase: density = 1 kg/m^3, viscosity = 1.48e-5 m^2/s
Include surface tension = 0.07 N/m between phases.
Initialize water column as a rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75) with alpha.water = 1 inside and 0 elsewhere.
Add a stationary obstacle from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) with no-slip boundary conditions.
Set simulation parameters:
Time step (deltaT) = 1e-3 s
End time = 0.1 s
Write interval = 0.02 s
