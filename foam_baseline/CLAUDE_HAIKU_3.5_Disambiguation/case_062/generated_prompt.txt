Simulate 2D turbulent flow over a circular cylinder.
Set Reynolds number to 3900.
Use cylinder diameter D=1m.
Set computational domain from (-10D, -10D) to (30D, 10D).
Center cylinder at (0,0).
Set third dimension thickness to 0.1D with one cell.
Use transient incompressible solver pimpleFoam.
Use k-omega SST RAS turbulence model.
Set inlet velocity U=(3.9 0 0) m/s.
Set inlet turbulence k=5.7e-3.
Set inlet turbulence omega=3.6.
