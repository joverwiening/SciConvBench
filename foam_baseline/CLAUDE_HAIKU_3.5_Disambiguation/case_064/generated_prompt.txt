Perform a Large Eddy Simulation (LES) of flow over periodic hills with the following specifications:
Reynolds number is Re_H = 10595.
Target grid resolution of approximately 1.5 million cells.
Near-wall resolution of y+ ~ 1-2 on the hill surface.
Mesh generation using snappyHexMesh from an STL of the periodic hill surface and base blockMesh.
Use WALE (Wall-Adapting Local Eddy-viscosity) LES model.
Delta calculation using cubeRootVol with appropriate model coefficients.
Domain is fully periodic in x-direction with cyclic boundary conditions.
Use OpenFOAM-v2206 or OpenFOAM-v2212.
Solver will be standard pimpleFoam.
