Set up a counter-flow diffusion flame simulation using reactingFoam.
Use pure methane (CH4) as the fuel.
Fuel inlet conditions: velocity U = (0 -0.5 0) m/s, temperature T = 300 K, mass fraction Y.CH4 = 1.0.
Oxidizer (air) inlet conditions: velocity U = (0 0.5 0) m/s, temperature T = 300 K.
Use GRI-Mech 3.0 reaction mechanism.
Convert GRI-Mech 3.0 mechanism files to OpenFOAM format using 'chemkinToFoam' utility.
Place converted mechanism files in the constant directory.
