Use OpenFOAM v2306 for the simulation.
Perform a 2D incompressible lid-driven cavity flow simulation.
Create a computational grid of 20x20 cells in x and y directions.
Use 1 cell in the z-direction to represent 2D flow characteristics.
Set the top wall ('movingWall') velocity to 1 m/s in the x-direction.
Apply no-slip boundary condition (zero velocity) to fixed walls.
Designate front and back faces as 'empty'.
Set constant viscosity (nu) to 1e-05 m^2/s.
Use pisoFoam solver.
Apply convection schemes:
div(phi,U) Gauss limitedLinearV 1
div(phi,k) Gauss limitedLinear 1
div(phi,epsilon) Gauss limitedLinear 1
Use div((nuEff*dev2(T(grad(U))))) Gauss linear for viscous term.
Simulate from time 0 to 10 seconds.
Use time step of 0.005 seconds.
Output results every 100 time steps.
Set convergence tolerance for velocity and pressure residuals to 1e-6.
Initialize entire domain with zero velocity at simulation start.
