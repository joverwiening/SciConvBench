Run a transient laminar two-phase dam-break with obstacles using interFoam.
Use a computational domain as a cube spanning from (0,0,0) to (1,1,1) meters.
Discretize the domain uniformly at 32 x 32 x 32 grid points.
Place an obstacle in the domain from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) meters.
Set gravity vector g = (0, 0, -9.81) m/s².
Initialize water volume fraction (alpha.water) as 1 inside the box from (0, 0, 0) to (0.6, 0.1875, 0.75).
Set water volume fraction to 0 elsewhere in the domain.
Use time step (deltaT) of 1e-3 seconds.
Set simulation end time to 0.1 seconds.
Set write interval to 0.02 seconds.
Use "noSlip" wall boundary conditions for five domain faces.
Set top face (z=1) as an open atmosphere patch.
Initialize velocity for both water and air phases to (0, 0, 0) m/s.
Solve using interFoam solver in a laminar flow regime.
