Simulate a 2D cavity flow using pisoFoam solver with the following specifications:

Geometry:
- Square cavity with dimensions 1x1 unit in x and y
- Very thin in z-direction (0.1 units)
- Grid resolution: 20x20x1 cells

Boundary Conditions:
- Top wall ('movingWall'): Uniform velocity 1 m/s in x-direction
- Side walls ('fixedWalls'): No-slip boundary condition (zero velocity)
- Front and back faces: 'empty' boundary type

Simulation Parameters:
- Time range: 0 to 10 seconds
- Time step: 0.005 seconds
- Output frequency: Every 100 time steps
- Viscosity (nu): 1e-05 m^2/s

Turbulence Model:
- k-epsilon model
- Initial k: 1.5e-4 uniformly, with kqRWallFunction
- Initial epsilon: 1.4e-4 uniformly, with epsilonWallFunction
- Initial nut: 0 uniformly, with nutkWallFunction

Numerical Schemes:
- Convection: 
  div(phi,U) Gauss limitedLinearV 1
  div(phi,k) Gauss limitedLinear 1
  div(phi,epsilon) Gauss limitedLinear 1
- Viscous term: div((nuEff*dev2(T(grad(U))))) Gauss linear

Initial Condition:
- Zero velocity throughout the domain
