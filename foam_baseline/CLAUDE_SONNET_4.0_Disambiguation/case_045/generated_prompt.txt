Set up a buoyant flow case in a 1x1 box with 50x50 cells.
The bottom wall is hot at 300K and the top wall is cold at 290K.
Use kinematic viscosity of 1e-5 m²/s, Prandtl number of 0.71, thermal expansion coefficient of 3.4e-3 1/K, reference temperature of 295 K, and reference density of 1.0 kg/m³ in the constant/physicalProperties file for the Boussinesq approximation.
Apply no-slip boundary conditions for velocity on all walls: bottomWall, topWall, and sideWalls.
Set initial conditions with uniform zero velocity (0 0 0) and uniform temperature of 295 K.
Add a symmetry-breaking perturbation using setFields to create a small warm spot from (0.45 0.00 -1) to (0.55 0.05 1) with temperature 295.1 K.
Use the buoyantBoussinesqPimpleFoam solver.
Run the simulation for 200 seconds with a time step of 0.05 seconds.
Enable adaptive time stepping with maxCo = 0.8.
Write results every 5 seconds.
