Simulate turbulent flow in a 2D channel using pisoFoam and the k-epsilon model.
The channel dimensions are 2m long and 0.1m high.
The inlet velocity is 1 m/s in the x-direction (1 0 0).
The kinematic viscosity 'nu' should be set to 1e-5 m^2/s in the 'constant/transportProperties' file.
At the inlet, apply fixedValue boundary conditions with U=(1 0 0), p=zeroGradient, k=3.75e-3, and epsilon=0.017.
At the outlet, apply zeroGradient for U, k, and epsilon, and fixedValue 0 for p.
At the walls (topWall & bottomWall), apply noSlip for U, zeroGradient for p, kqRWallFunction for k, epsilonWallFunction for epsilon, and nutkWallFunction for nut.
For frontAndBack patches, set all fields to type 'empty'.
The mesh should be 200x20x1 cells using blockMesh with 200 cells in x-direction, 20 cells in y-direction, and 1 cell in z-direction.
