Simulate a 2D flow past a circular cylinder.
The domain is rectangular extending from x = -5 m to x = 5 m in the streamwise direction and y = -1.5 m to y = 2.5 m in the cross-stream direction and z = -1 to 1 m.
The cylinder has diameter 2 m and is centered at the origin (x = 0 m, y = 0 m).
Apply inlet boundary condition at left boundary with U = (1 0 0) m/s.
Apply outlet boundary condition at right boundary with U zeroGradient and p = 0 (reference).
Apply top and bottom wall boundary conditions with U noSlip and p zeroGradient.
Apply cylinder wall boundary condition with U noSlip and p zeroGradient.
Set default back/front faces as empty for 2D simulation.
Initialize the flow field with quiescent fluid conditions: U = (0 0 0) and p = 0.
Use laminar flow model.
Use generalisedNewtonian laminar model with crosspowerlaw viscosity model.
Set crosspowerlaw parameters: nuinf = 10, m = 0.4, and n = 3.
Set viscosity to 0.01 m^2/s.
Use reasonable mesh resolution based on best practices.
Set deltaT = 0.0025 s.
Set startTime = 0 s.
Set endTime = 0.5 s.
Write results every 0.05 s.
