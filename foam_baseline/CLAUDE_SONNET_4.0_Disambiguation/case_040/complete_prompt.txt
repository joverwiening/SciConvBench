Problem: Transient 2D dam-break style flow (water-air VOF) through a porous dam section using interFoam with an explicit porosity momentum source.

Solver: interFoam

Geometry: 2D domain 5 m (x) x 2 m (y) x 0.1 m (z-thickness); front/back are empty.
A porous dam zone occupies x=2 m to x=3 m over the full height.

Mesh: blockMesh (250 100 1). Patches: leftWall, rightWall, bottomWall, atmosphere (top), frontAndBack.

Porous dam (system/fvOptions): apply explicit porosity to a cellZone 'porousDam' (created via topoSet from the x-range 2-3 m).
- type explicitPorositySource; selectionMode cellZone; cellZone porousDam;
- explicitPorositySourceCoeffs { type DarcyForchheimer; d (1e6 1e6 0); f (100 100 0); }

Multiphase properties (constant/transportProperties):
- phases: water and air
- water: nu=1e-6, rho=1000
- air: nu=1.48e-5, rho=1
- sigma = 0.07 N/m
Gravity (constant/g): (0 -9.81 0)

Initial conditions (system/setFieldsDict):
- default alpha.water = 0 (air everywhere)
- set a water column at the left: box (0 0 -1) to (1 1.5 1) with alpha.water = 1
- initialize U = (0 0 0), p_rgh = 0

Boundary conditions:
- leftWall/rightWall/bottomWall (solid walls):
  - U noSlip
  - p_rgh fixedFluxPressure
  - alpha.water zeroGradient
- atmosphere (top open boundary):
  - U pressureInletOutletVelocity (inletValue (0 0 0))
  - p_rgh totalPressure with p0 uniform 0
  - alpha.water inletOutlet (inletValue 0; value 0)
- frontAndBack: empty

Time controls (system/controlDict): endTime 10; deltaT 0.001; adjustTimeStep yes; maxCo 0.5; writeInterval 0.1.
