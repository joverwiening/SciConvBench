Perform an incompressible lid driven cavity flow simulation using pisoFoam solver.
Set up a computational grid with 20x20 cells in x and y directions and 1 cell in z-direction.
The cavity dimensions are 1 unit × 1 unit × 0.1 units (length × width × height).
The top wall boundary is named 'movingWall' and moves in the x-direction with uniform velocity of 1 m/s.
The remaining walls are named 'fixedWalls' and have no-slip boundary condition with velocity equal to zero.
The front and back faces are designated as 'empty' boundary type.
Set the kinematic viscosity (nu) as constant with value of 1e-05 m^2/s.
Initialize the velocity field to zero throughout the domain at time t=0.
Run the simulation from time 0 to 10 with time step size of 0.005 units.
Use convection schemes: div(phi,U) Gauss limitedLinearV 1, div(phi,k) Gauss limitedLinear 1, and div(phi,epsilon) Gauss limitedLinear 1.
Use viscous term scheme: div((nuEff*dev2(T(grad(U))))) Gauss linear.
