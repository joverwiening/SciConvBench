Set up a steady-state developing pipe flow case with simpleFoam.
The pipe is 1 meter long.
The pipe diameter is 0.02 m with radius 0.01 m.
The inlet velocity is 0.1 m/s in the x-direction with uniform (0.1 0 0).
The kinematic viscosity is 1e-6 m^2/s.
The pipe wall should have a no-slip boundary condition.
