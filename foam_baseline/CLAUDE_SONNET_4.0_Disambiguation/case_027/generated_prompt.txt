Run a transient laminar two-phase dam-break simulation with obstacles using interFoam.
Set up a cubic computational domain spanning from (0,0,0) to (1,1,1).
Discretize the domain uniformly with a 32 x 32 x 32 mesh.
Assign the top face (z=1) as an open atmosphere patch.
Assign the remaining five faces as wall boundary conditions.
Include one rectangular obstacle positioned from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Model two phases using VOF method: water with density 1000 kg/m³ and viscosity 1.0e-6 m²/s, and air with density 1 kg/m³ and viscosity 1.48e-5 m²/s.
Set surface tension coefficient to 0.07 N/m.
Initialize the water column as a rectangular prism where alpha.water = 1 inside the region from (0, 0, 0) to (0.6, 0.1875, 0.75) and alpha.water = 0 elsewhere.
Use time step deltaT = 1e-3 s.
Set simulation end time to 0.1 s.
Set write interval to 0.02 s for output frequency.
