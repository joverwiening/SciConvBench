Simulate heat transfer in a porous block with natural convection using air as the fluid.
The porous block dimensions are 0.10 m x 0.10 m x 0.01 m configured as a 2D square cavity.
Set the hot bottom boundary (hotWall) temperature to 310 K.
Set the cold top boundary (coldWall) temperature to 290 K.
Apply noSlip boundary condition for velocity U on left and right walls (sideWalls).
Apply zeroGradient boundary condition for temperature T on left and right walls (sideWalls).
Apply fixedFluxPressure boundary condition for pressure p_rgh on left and right walls (sideWalls).
Configure the porous medium using a Darcy-Forchheimer resistance model.
Set the Darcy coefficient d to (1e7 1e7 1e7).
Set the Forchheimer coefficient f to (0 0 0).
Implement the porous medium as an explicitPorositySource in fvOptions with type DarcyForchheimer.
Initialize velocity U to (0 0 0) m/s throughout the domain.
Initialize temperature T to 300 K throughout the domain.
Initialize pressure p_rgh to 0 Pa throughout the domain.
