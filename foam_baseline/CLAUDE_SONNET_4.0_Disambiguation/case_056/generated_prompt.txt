Simulate a lid-driven cavity flow using OpenFOAM's icoFoam solver.
The cavity dimensions are 0.1m x 0.1m x 0.01m (a square cavity).
The top wall moves at 1 m/s.
Set the kinematic viscosity 'nu' to 0.01 m^2/s in the 'constant/transportProperties' file.
Apply no-slip boundary conditions to the left, bottom, and right walls with velocity U as fixedValue uniform (0 0 0) and pressure p as zeroGradient.
Create a uniform Cartesian mesh with 20x20x1 cells using blockMesh.
Initialize the pressure 'p' field to uniform 0 and the velocity 'U' field to uniform (0 0 0).
Set the time step (deltaT) to 0.0005 and the total simulation time (endTime) to 0.5 seconds.
