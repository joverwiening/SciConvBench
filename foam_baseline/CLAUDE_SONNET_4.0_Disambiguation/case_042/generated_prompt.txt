Model Rayleigh-Benard convection in a rectangular domain.
The domain is 2m wide by 1m high with aspect ratio 2:1.
The domain is heated from below and cooled from above.
The Rayleigh number should be around 2500.
Use periodic boundary conditions (type cyclic) for the left and right walls for all fields (U, T, p_rgh).
Set the bottom wall (heated) temperature to 300 K.
Set the top wall (cooled) temperature to 299 K.
Use kinematic viscosity nu = 0.00928 m²/s.
Use thermal diffusivity alpha = 0.01307 m²/s.
Use coefficient of thermal expansion beta = 0.0034 1/K.
Initialize the fluid at rest with velocity U = (0 0 0) m/s.
Initialize the temperature field to T(x,y) = (300 - y) + 0.1*sin(pi*x).
The temperature initialization includes a linear profile T(y) = 300 - y plus a small sinusoidal perturbation 0.1*sin(pi*x) to trigger convection.
