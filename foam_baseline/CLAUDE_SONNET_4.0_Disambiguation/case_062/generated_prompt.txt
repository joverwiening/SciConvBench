Simulate flow over a cylinder to visualize vortex shedding using water as the fluid.
Set Reynolds number to 3900.
Use a cylinder diameter of 1 meter (D = 1m).
Create a rectangular computational domain from (-10D, -10D) to (30D, 10D) where D=1m.
Center the cylinder at (0,0).
Set domain thickness to 0.1D with one cell in the third dimension.
Apply inlet boundary condition with uniform velocity U=(3.9 0 0) m/s and turbulence values k=5.7e-3 and omega=3.6.
Apply outlet boundary condition with zeroGradient for U, k, omega and fixedValue p=0.
Apply noSlip boundary condition for U on cylinder surface with kqRWallFunction for k and omegaWallFunction for omega.
Apply symmetry boundary conditions on top and bottom edges.
Apply empty boundary conditions on front and back faces.
Use k-omega SST RAS turbulence model.
Use adjustable time stepping with maxCo=1 and maxDeltaT=0.01.
Set total simulation time to 100 seconds starting from time 0.
Create mesh using blockMesh with C-grid topology around cylinder.
Target y+ value between 30 and 100 on cylinder surface.
Generate approximately 40,000 cells with higher resolution near cylinder surface and in wake region.
Write results every 0.5 seconds.
