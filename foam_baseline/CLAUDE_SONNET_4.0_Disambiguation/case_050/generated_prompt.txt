Run a transient simulation using pimpleFoam on a 1m x 1m square domain with a 40x40 mesh.
The top wall moves at 1 m/s in the x-direction.
The left, right, and bottom walls use noSlip boundary conditions for velocity (U) and fixedFluxPressure with value uniform 0 for pressure (p).
The kinematic viscosity is 1e-4 m^2/s.
Initialize velocity U to uniform (0 0 0) at t=0.
Initialize kinematic pressure p to uniform 0 at t=0.
Run the simulation until t=5s.
