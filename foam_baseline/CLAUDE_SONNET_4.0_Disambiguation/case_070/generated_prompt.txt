Model a flow through a thin porous screen in a channel where the screen causes a pressure drop and the flow is incompressible and turbulent.
The domain is a 2D channel that is 1.0 m long and 0.1 m high.
The porous baffle is a zero-thickness screen located at x=0.5 m exactly in the middle of the channel.
The inlet boundary condition has velocity fixed at (5 0 0) m/s and pressure set to zeroGradient.
The outlet boundary condition has velocity set to zeroGradient and pressure fixed at 0 Pa.
The porous baffle uses a pressure drop model with Darcy coefficient D = 1e7 and Inertial/Forchheimer coefficient I = 0.
The baffle is implemented as a boundary condition of type 'porousBafflePressure' rather than as a traditional porous zone with porosity and permeability.
Use the standard k-omega SST RAS turbulence model.
Set 'simulationType RAS' in 'constant/turbulenceProperties' and 'model kOmegaSST' in 'constant/RASProperties'.
The kinematic viscosity nu = 1e-5 m^2/s is specified in 'constant/transportProperties'.
Since this is an incompressible flow simulation only the kinematic viscosity is needed as density cancels out in the governing equations for simpleFoam.
