Simulate a compressible flow over a NACA 0012 airfoil to see the shock waves using OpenFOAM with the rhoPimpleFoam solver.
Set the Mach number to 0.85 with 0 degrees angle of attack.
Use the k-omega SST turbulence model for the turbulent flow simulation.
Create a structured C-grid mesh with approximately 256 cells around the airfoil and 64 cells in the normal direction.
Target y+ values around 30-100 for near-wall resolution since RANS wall functions will be used.
Apply boundary-layer grading for proper resolution near the wall.
Set freestream conditions with pressure at 101325 Pa and temperature at 288 K.
Calculate density from the perfect gas law using these pressure and temperature values.
Apply freestreamVelocity boundary condition at far-field boundaries with freestreamValue corresponding to Ma=0.85 in direction (1 0 0).
Apply freestreamPressure boundary condition with freestreamValue 101325 Pa at far-field boundaries.
Apply freestreamTemperature boundary condition with freestreamValue 288 K at far-field boundaries.
Set turbulence boundary conditions at far-field with freestream values from turbulence intensity 1% and viscosity ratio around 10.
Apply noSlip boundary condition for velocity at the airfoil wall.
Apply zeroGradient boundary condition for pressure at the airfoil wall.
Apply zeroGradient boundary condition for temperature at the airfoil wall for adiabatic conditions.
Use compressible wall functions for turbulence at the airfoil wall (compressible::kqRWallFunction, compressible::omegaWallFunction).
Set front and back faces as empty for 2D simulation.
Use a 2D C-grid domain around the NACA 0012 airfoil with chord length c = 1 m.
Position the far-field boundary at 20 chord lengths from the airfoil.
