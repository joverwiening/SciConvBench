Simulate turbulent flow over a backward-facing step using pimpleFoam.
The step height is 0.01m.
The inlet velocity is 10 m/s in the x-direction (10 0 0).
The total domain length is 0.55m, with 0.05m inlet section and 0.5m downstream of the step.
The total domain height is 0.02m.
The simulation will be 2D with empty frontAndBack patches.
Use the k-epsilon RAS turbulence model.
The width of the domain should be set to a single cell with empty boundary conditions.
The Reynolds number will be determined by the specified geometry and inlet conditions.
