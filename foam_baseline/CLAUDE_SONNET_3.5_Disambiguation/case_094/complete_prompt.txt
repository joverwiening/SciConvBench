Problem: Modify the standard OpenFOAM buoyantCavity tutorial to simulate turbulent natural convection at Ra = 1e6 using the k-omega SST model.
Base Case: tutorials/heatTransfer/buoyantPimpleFoam/buoyantCavity
Solver: buoyantPimpleFoam
Modifications:
1. Physical Properties: To achieve Ra = 1e6 (from the tutorial's Ra ~ 1e5), modify constant/transportProperties. Increase the thermal expansion coefficient 'beta' by a factor of 10, from 2.9e-3 to 2.9e-2 1/K. Keep other properties (nu, Pr) the same.
2. Turbulence Model: In constant/momentumTransport, change 'simulationType' from 'laminar' to 'RAS'. Add the entry 'RASModel kOmegaSST;'.
3. Initial/Boundary Condition Fields: Create new files in the 0/ directory for k, omega, and nut.
   - 0/k: internalField uniform 1e-6. Boundary conditions: 'kqRWallFunction' with value uniform 1e-6 on all walls; 'empty' on frontAndBack.
   - 0/omega: internalField uniform 1. Boundary conditions: 'omegaWallFunction' with value uniform 1 on all walls; 'empty' on frontAndBack.
   - 0/nut: internalField uniform 0. Boundary conditions: 'nutkWallFunction' with value uniform 0 on all walls; 'empty' on frontAndBack.
4. Solver Settings: In system/fvSolution, add solver entries for k and omega. For example:
   k { solver PBiCGStab; preconditioner DILU; tolerance 1e-08; relTol 0.1; }
   omega { solver PBiCGStab; preconditioner DILU; tolerance 1e-08; relTol 0.1; }
5. Discretization Schemes: In system/fvSchemes, add 'divSchemes' for turbulence fields, e.g., 'div(phi,k) Gauss linearUpwindV grad(k);' and 'div(phi,omega) Gauss linearUpwindV grad(omega);'.
6. Time Controls: The flow will be faster and more complex. In system/controlDict, reduce maxCo from 0.9 to 0.5 to ensure stability. Reduce endTime to 100s and writeInterval to 10s to capture the turbulent evolution.
