Simulate Rayleigh-Benard convection in a 2D square cavity.
The domain is 0.1 m x 0.1 m with empty front/back faces for 2D simulation.
The bottom wall temperature is fixed at 294.0 K.
The top wall temperature is fixed at 293.0 K.
The fluid properties are: nu = 1.5e-5, Pr = 0.71, beta = 3.33e-3, rho0 = 1.0.
Initial temperature is uniform 293.5 K throughout the domain.
A perturbation region from (0.045 0.00 -1) to (0.055 0.01 1) has initial T = 293.52 K.
Side walls use zeroGradient for temperature, noSlip for velocity, and fixedFluxPressure for p_rgh.
Simulation end time is 5000 seconds.
Time step (deltaT) is 1 second.
Write interval is 500 seconds.
Simulation stops based on residualControl settings in fvSolution.
