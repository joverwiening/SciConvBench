Run a transient laminar two-phase dam-break with obstacles using interFoam.
The domain is a cube spanning (0,0,0) to (1,1,1) discretized uniformly at (32 x 32 x 32). 
There is an obstacle in the domain from (0.375 0.375 0) to (0.625 0.625 0.25).
Set gravity g = (0 0 -9.81).
Assign the top (z=1) face as the open atmosphere patch and the remaining five faces as walls. 
Model phases via VOF as water (density = 1000 kg/m^3, viscosity = 1.0e-6 m^2/s) and air (density = 1 kg/m^3, viscosity = 1.48e-5 m^2/s) with surface tension = 0.07 N/m.
Initialize water column as a rectangular prism where alpha.water = 1 inside the box (0, 0, 0) to (0.6, 0.1875, 0.75) and 0 elsewhere. 
Use deltaT = 1e-3 s, endTime = 0.1 s, writeInterval = 0.02 s.
