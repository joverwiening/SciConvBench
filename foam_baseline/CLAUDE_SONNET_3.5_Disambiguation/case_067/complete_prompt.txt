Simulate steady-state, incompressible, turbulent flow in a porous pipe using the porousSimpleFoam solver.
GEOMETRY: The domain is a 3D pipe with a length of 2 m and a radius of 0.05 m.
MESH: Use blockMesh to create a cylindrical mesh with 100 cells axially, 20 cells radially, and 16 cells circumferentially.
TURBULENCE: Use the standard k-epsilon RAS model. Set 'simulationType RAS' in 'constant/turbulenceProperties'.
PHYSICAL PROPERTIES: The fluid is air with kinematic viscosity nu = 1.5e-5 m^2/s, defined in 'constant/transportProperties'.
POROUS MEDIA: The entire domain is a porous zone. Define this in 'constant/fvOptions' with a 'DarcyForchheimer' model, d = (5e7 5e7 5e7) and f = (0 0 0).
INITIAL & BOUNDARY CONDITIONS (in '0/' directory):
- U: inlet has a fixedValue uniform (10 0 0); outlet is inletOutlet with inletValue uniform (0 0 0); pipeWall is noSlip.
- p: inlet is zeroGradient; outlet is fixedValue uniform 0; pipeWall is zeroGradient.
- k: inlet is fixedValue based on 5% turbulence intensity (I=0.05), k = 1.5*(U*I)^2 = 0.375; outlet is inletOutlet with inletValue uniform 0.0375; pipeWall uses kqRWallFunction.
- epsilon: inlet is calculated from turbulent length scale (L=0.07*Radius), epsilon = Cmu^0.75 * k^1.5 / L = 0.23; outlet is inletOutlet with inletValue uniform 0.023; pipeWall uses epsilonWallFunction.
- nut: pipeWall uses nutkWallFunction.
TIME CONTROLS: In 'system/controlDict', set application = porousSimpleFoam, stopAt = endTime, endTime = 1000, deltaT = 1.
