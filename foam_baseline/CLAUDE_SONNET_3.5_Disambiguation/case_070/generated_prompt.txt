Model a flow through a thin porous screen in a 2D channel.
The channel is 1.0 m long and 0.1 m high.
The inlet velocity is uniform at (5 0 0) m/s.
The flow is incompressible and turbulent.
The porous screen is located at x=0.5 m with zero thickness.
Use a Darcy coefficient D = 1e7 and Inertial coefficient I = 0 for the porous screen pressure drop model.
The porosity should be set based on best practices for similar applications.
The pressure drop will be determined by the specified Darcy-Inertial coefficients.
