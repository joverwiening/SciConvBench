Simulate incompressible water flow through a porous channel with the following specifications:
The channel dimensions are 1.0m length x 0.2m height x 0.01m width.
The porous block extends from x=0.4m to x=0.6m across the entire channel height.
The inlet has a uniform velocity of 0.1 m/s in the x-direction.
The outlet has a uniform pressure of 0 Pa.
The porous zone uses the Darcy-Forchheimer model with d = (1e8 1e8 1e8) and f = (0 0 0).
The simulation should be run until steady-state conditions are achieved.
The flow is incompressible.
Water should be used as the working fluid.
