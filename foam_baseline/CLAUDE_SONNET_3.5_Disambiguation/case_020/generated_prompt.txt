The simulation uses pimpleFoam solver for incompressible unsteady flow.
The simulation runs from 0 to 0.5 seconds.
The time step size (deltaT) is 0.0025 seconds.
Results are written every 0.05 seconds.
The flow is laminar using generalisednewtonian model.
The viscosity model is crosspowerlaw with parameters: nuinf = 10 m^2/s, m = 0.4 s, n = 3, and nu0 = 0.01 m^2/s.
Initial conditions are quiescent with U = (0 0 0) m/s and p = 0.
Inlet boundary condition: U = (1 0 0) m/s.
Outlet boundary conditions: U zeroGradient, p = 0.
Top and bottom walls: U noSlip, p zeroGradient.
Cylinder wall: U noSlip, p zeroGradient.
Front and back faces: empty (2-D simulation).
