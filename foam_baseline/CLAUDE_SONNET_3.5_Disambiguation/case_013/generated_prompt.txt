Set up a laminar counter-flow diffusion flame simulation in OpenFOAM using reactingFoam solver.
The domain is rectangular spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Use 100 grid points in x direction, 40 in y direction, and 1 cell in z direction.
Left boundary (x=0) is named fuel inlet.
Right boundary (x=0.02) is named air inlet.
Top and bottom boundaries are named outlet.
FrontAndBack faces are empty type.
Fuel inlet injects CH4 at 293 K with velocity of 0.1 m/s.
Air inlet supplies oxidizer (Y_O2=0.23, balance N2) at 293 K with velocity of -0.1 m/s.
Initialize domain temperature at 2000 K at time 0.
Use EulerImplicit chemistry type with Rosenbrock43 ODE solver.
Set combustion model and momentum transport as laminar.
Use compressible finite-rate chemistry with hePsiThermo thermodynamics model.
Use coefficientWilkeMultiComponentMixture for mixing.
Use Sutherland transport model.
Use JANAF thermodynamics.
Set simulation end time to 0.5 seconds.
Set time step size (deltaT) to 1e-4 seconds.
Set write interval to 0.05 seconds.
