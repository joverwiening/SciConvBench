The simulation is for a 2D lid-driven cavity case with the following specifications:
The cavity is a square with dimensions 1x1x0.1 units.
The mesh consists of 20x20x1 cells.
The simulation runs from t=0 to t=10 with a time step of 0.005 units.
Results are output every 100 time steps.
The kinematic viscosity (nu) is constant at 1e-05 m^2/s.
Use k-epsilon turbulence model.
Initialize k = 1.5e-4 uniformly with kqRWallFunction on all walls.
Initialize epsilon = 1.4e-4 uniformly with epsilonWallFunction on all walls.
Initialize nut = 0 uniformly with nutkWallFunction on all walls.
Initialize velocity U = 0 everywhere in the domain.
Top wall has moving wall condition with U = (1 0 0) m/s.
Other walls have no-slip condition with U = (0 0 0) m/s.
Front and back patches are set to empty.
Use pisoFoam solver.
Use Gauss limitedLinearV 1 scheme for div(phi,U).
Use Gauss limitedLinear 1 scheme for div(phi,k).
Use Gauss limitedLinear 1 scheme for div(phi,epsilon).
Use Gauss linear scheme for div((nuEff*dev2(T(grad(U))))).
Pressure boundary conditions should follow best practices.
Initial pressure should follow best practices.
