Perform a steady-state external aerodynamics simulation of an Ahmed body (25 deg slant) to compute drag.

Solver: simpleFoam (steady incompressible)

Geometry: Standard Ahmed body, length L = 1.044 m. Place in a wind-tunnel domain extending:
- 4L upstream, 10L downstream, 3L to each side, and 3L above.
Include a ground plane.

Target Reynolds number: Re_L = 7.68e5 based on body length L and free-stream speed U.
Assume air kinematic viscosity nu = 1.5e-5 m^2/s (constant/transportProperties).
Compute U = Re_L * nu / L ~ 7.68e5 * 1.5e-5 / 1.044 ~ 11.0 m/s.
Use inlet velocity U = (11 0 0) m/s and moving ground speed 11 m/s.

Mesh: snappyHexMesh with ~5 million cells. Add 10-15 prism layers on the Ahmed body and ground. Target y+ ~ 30-100 (wall functions) on the body and ground.
Refine in the near wake and along the shear layer.

Turbulence: RAS kOmegaSST (constant/momentumTransport). Use wall functions for k/omega/nut.

Boundary conditions:
- inlet: U fixedValue (11 0 0); p zeroGradient; turbulence from I=1% and viscosity ratio ~10.
- outlet: p fixedValue 0; U zeroGradient; turbulence zeroGradient.
- ground: movingWallVelocity (11 0 0); appropriate wall-function turbulence BCs.
- topAndSides: symmetryPlane (or slip) for U; p zeroGradient.
- ahmedBody: noSlip for U; wall-function turbulence BCs; p zeroGradient.

Post-processing: add forces/forceCoeffs function objects in controlDict to report drag and lift on patch 'ahmedBody' using reference area and length.
