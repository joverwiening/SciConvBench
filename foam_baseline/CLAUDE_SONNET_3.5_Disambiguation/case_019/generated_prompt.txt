Simulate a 2D flow past a circular cylinder from t = 0 s to t = 0.5 s.
Use pimpleFoam solver for this incompressible unsteady flow simulation.
Set the rectangular domain from x = -5 m to x = 5 m, y = -1.5 m to y = 2.5 m, and z = -1 to 1 m.
Place a cylinder of diameter 2 m centered at origin (0, 0, 0).
Set inlet boundary condition (left) to uniform velocity U = (1 0 0) m/s.
Set outlet boundary condition (right) to zeroGradient for velocity and p = 0.
Apply noSlip condition for velocity and zeroGradient for pressure on top and bottom walls.
Apply noSlip condition for velocity and zeroGradient for pressure on cylinder wall.
Set back and front faces as empty for 2D simulation.
Initialize the field with quiescent fluid (U = (0 0 0), p = 0).
Use laminar flow model with generalisedNewtonian and crosspowerlaw viscosity model.
Set viscosity model parameters: nuinf = 10, m = 0.4, n = 3.
Set base viscosity to 0.01 m^2/s.
Set deltaT = 0.0025 s with writeInterval = 0.05 s.
Use standard mesh resolution with refinement near cylinder following best practices.
