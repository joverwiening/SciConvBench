Model compressible air flow through a porous filter in a rectangular duct.
The duct dimensions are 0.5m length x 0.1m height x 0.01m width (2D case).
The inlet flow is supersonic at Mach 2.
Use k-omega SST turbulence model.
The porous filter zone is located from x=0.2m to x=0.25m (0.05m thickness).
Inlet conditions are: pressure = 101325 Pa, temperature = 300 K, velocity = (700 0 0) m/s.
A shock wave is expected due to supersonic inlet conditions.
Use industry best practices to determine an appropriate porosity value for the filter material.
The simulation should capture the shock-porous media interaction.
