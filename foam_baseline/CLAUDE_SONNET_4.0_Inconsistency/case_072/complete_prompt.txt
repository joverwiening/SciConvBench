Set up a Rayleigh-Bénard convection case using the buoyantBoussinesqPimpleFoam solver. The domain is a 3D box with dimensions 1m x 1m x 0.1m, with the height oriented along the Z-axis. The fluid has a Prandtl number of 0.71. In constant/transportProperties, the Boussinesq approximation is used with beta=0.00341, T0=300, nu=1.5e-5, and Pr=0.71. The gravity vector in constant/g is defined as `g (0 0 -9.81);`. For boundary conditions in the 0/ directory: the bottom wall (z=0) has a fixed temperature T=310K (`fixedValue`), and the top wall (z=0.1) has T=300K (`fixedValue`). The side walls are periodic. The velocity U is `noSlip` on the top and bottom walls. The simulation is transient and aims to capture the formation of convection cells.
