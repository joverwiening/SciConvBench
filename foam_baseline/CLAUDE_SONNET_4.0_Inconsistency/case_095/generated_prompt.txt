Set up a 2D, steady-state, incompressible, turbulent simulation of airflow over a NACA0012 airfoil at a 5-degree angle of attack.
Use the simpleFoam solver with the k-omega SST turbulence model.
The domain should be a C-grid type, one cell thick in the z-direction.
The mesh is defined in constant/polyMesh.
The boundary patches are inlet, outlet, airfoil, and frontAndBack.
Set inlet velocity U to fixedValue uniform (10 0 0).
Calculate inlet k and omega from turbulence intensity 1% and viscosity ratio 10.
Set inlet pressure p to zeroGradient.
Set outlet velocity U to inletOutlet.
Set outlet k and omega to inletOutlet.
Set outlet pressure p to fixedValue uniform 0.
Set airfoil velocity U to noSlip.
Set airfoil k to kqRWallFunction.
Set airfoil omega to omegaWallFunction.
Set airfoil pressure p to zeroGradient.
Set frontAndBack patches type to wall in constant/polyMesh/boundary.
Set frontAndBack velocity U to noSlip.
Set frontAndBack pressure p, k, and omega to zeroGradient.
Use reasonable kinematic viscosity value based on best practices.
Use reasonable Reynolds number based on best practices for NACA0012 airfoil at these flow conditions.
