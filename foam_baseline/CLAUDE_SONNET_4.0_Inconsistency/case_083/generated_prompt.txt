Set up the initial conditions for a three-phase settling tank containing sediment, water, and oil using the multiphaseEulerFoam solver.
The initial field files are located in the 0/ directory.
Use reasonable assumptions for tank dimensions and geometry based on best practices.
For the default field condition before setFields is applied, set the volume fraction internalField for all three files (alpha.sediment, alpha.water, alpha.oil) as: internalField uniform 0.5;
This will be later modified by setFieldsDict to create stratified layers.
Set the initial velocity field to zero for all phases: internalField uniform (0 0 0);
Set the initial pressure field to zero: internalField uniform 0;
Apply reasonable boundary conditions based on best practices to each face of the settling tank for velocity, pressure, and volume fraction fields.
