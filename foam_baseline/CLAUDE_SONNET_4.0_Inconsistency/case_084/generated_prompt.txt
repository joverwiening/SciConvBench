Set up a transient two-phase Euler–Euler gas–solid riser simulation with phases (air catalyst) using twoPhaseEulerFoam.
Use a cylindrical riser geometry with diameter 0.1 m and height 2.0 m based on typical laboratory-scale CFB risers.
At the inlet, prescribe a dilute solids loading with alpha.catalyst = 0.01 and set the gas volume fraction to alpha.air = 0.99 so that phase fractions sum to 1.
Use inlet gas velocity of 5 m/s which is typical for circulating fluidized bed operations.
Use catalyst particles with diameter 75 microns and density 1500 kg/m3 representing typical FCC catalyst.
Apply zero gradient boundary conditions at the outlet for both phases.
Run the simulation for 10 seconds total time with initial time step of 0.001 seconds.
In 0/alpha.catalyst, set inlet boundary condition as fixedValue with uniform 0.01.
In 0/alpha.air, set inlet boundary condition as fixedValue with uniform 0.99.
