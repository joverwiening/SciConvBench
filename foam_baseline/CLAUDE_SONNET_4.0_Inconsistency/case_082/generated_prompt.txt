Configure a simulation for the separation of three immiscible fluids (oil, water, and gas) in a horizontal gravity separator using the VOF method.
The solver specified in controlDict should be interFoam.
The phases are defined in transportProperties with their respective densities and viscosities.
Use reasonable assumptions for typical oil, water, and gas properties for density and viscosity values.
The initial state is a stratified mixture, which can be set using setFieldsDict.
Use reasonable assumptions for typical gravity separator initial conditions for the volume fractions of each phase.
The alpha.water field represents the volume fraction of water.
The simulation should track the interface between the three fluids over time as they separate under gravity.
Gravity is set to (0 -9.81 0).
Use reasonable assumptions for typical gravity separator geometries for the domain dimensions.
Use reasonable assumptions for multiphase separation simulations for the simulation time duration and time step size.
