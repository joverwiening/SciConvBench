I want to model a steady-state buoyant flow in a solar chimney. The solver should be `buoyantSimpleFoam`. The air is heated at the bottom and rises due to density changes. Gravity is defined in the `constant/g` file. To model the buoyancy, I will use a compressible perfect gas model, which is required by this solver. My `constant/thermophysicalProperties` file should look like this:

FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      thermophysicalProperties;
}

thermoType      hePsiThermo;
mixture         perfectGas;
transport       const;
thermo          hConst;
equationOfState perfectGas;
specie          specie;
energy          sensibleEnthalpy;

mixture
{
    specie
    {
        molWeight   28.9;
    }
    thermodynamics
    {
        Cp          1005;
        Hf          0;
    }
    transport
    {
        mu          1.8e-05;
        Pr          0.7;
    }
}
