Set up a 2D, incompressible, steady-state simulation of airflow over a symmetric airfoil using the simpleFoam solver.
Use a NACA 0012 airfoil profile with 1 meter chord length.
Design the simulation for a Reynolds number of 1,000,000 based on chord length.
Set the airfoil at 5 degrees angle of attack.
Create a C-grid topology around the airfoil with domain extending 10 chord lengths upstream, 20 chord lengths downstream, and 15 chord lengths to the far-field boundaries.
Make the mesh one cell thick in the z-direction.
In the system/blockMeshDict file, define the front and back patches for this 2D simulation as walls using the specified boundary entry format with frontAndBack patch type wall and the given face definitions.
For boundary conditions in the 0/U file, apply a uniform inlet velocity of (10 0 0) m/s, a zero-gradient outlet, a noSlip condition on the airfoil surface, and noSlip on the frontAndBack patches.
For pressure in 0/p, use zeroGradient for the inlet and airfoil, fixedValue uniform 0 at the outlet, and zeroGradient on the frontAndBack patches.
