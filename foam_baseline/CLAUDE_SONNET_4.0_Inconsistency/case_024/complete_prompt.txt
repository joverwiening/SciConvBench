Set up an axisymmetric simulation of swirling flow inside a pipe using `simpleFoam`. The mesh should be a 2D wedge geometry, with a small angle (e.g., 5 degrees) in the tangential direction, and one cell thick. The `system/blockMeshDict` should define the axial patches as `axis`, the pipe surface as `wall`, and the inlet/outlet. The front and back planes of the wedge must be defined with the `wedge` type for an axisymmetric calculation:

```
    front
    {
        type            wedge;
        faces
        (
            (0 3 2 1)
        );
    }
    back
    {
        type            wedge;
        faces
        (
            (4 5 6 7)
        );
    }
```
