Set up an axisymmetric simulation of swirling flow inside a pipe using simpleFoam.
The mesh should be a 2D wedge geometry with a 5-degree angle in the tangential direction and one cell thick.
Use a pipe length of 10 times the diameter (L/D = 10) for the axial direction.
Use a pipe radius of 0.05 meters (diameter of 0.1 meters).
Apply a uniform velocity profile at the inlet for the axial component.
Apply a uniform swirl velocity component at the inlet.
Set the inlet axial velocity magnitude to 1 m/s.
Set the outlet pressure boundary condition to zero gradient.
The system/blockMeshDict should define the axial patches as axis, the pipe surface as wall, and the inlet/outlet.
The front and back planes of the wedge are defined as empty boundary conditions.
The front face uses vertices (0 3 2 1) and the back face uses vertices (4 5 6 7).
