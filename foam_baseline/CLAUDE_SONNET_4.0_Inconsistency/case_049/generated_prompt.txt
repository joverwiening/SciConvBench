Set up a 2D simulation of incompressible, laminar flow over an airfoil using simpleFoam.
The mesh is extruded one cell in the z-direction.
Use the patch name frontAndBack for the out-of-plane faces.
In constant/polyMesh/boundary, set frontAndBack type to wall.
In 0/U, set frontAndBack type to slip.
Use a NACA 0012 airfoil geometry as it is a standard symmetric airfoil commonly used for validation studies.
Set the Reynolds number to 1000 based on chord length, which ensures laminar flow conditions.
Set the angle of attack to 5 degrees to generate meaningful lift while remaining in the linear regime.
Set the computational domain dimensions with 10 chord lengths upstream, 20 chord lengths downstream, and 10 chord lengths above and below the airfoil to minimize boundary effects.
