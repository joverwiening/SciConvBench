Configure a 2D simulation of flow past a cylinder using pimpleFoam for a transient, incompressible, laminar case.
The mesh is one cell thick.
The 'frontAndBack' patches in 'constant/polyMesh/boundary' are defined with 'type symmetryPlane'.
In the '0/U' file, the boundary condition for 'frontAndBack' is specified as 'type wall; value uniform (0 0 0);'.
All other boundary conditions (inlet, outlet, cylinderWall) are set appropriately for a flow-past-cylinder case.
Use a Reynolds number based on best practices for laminar flow past a cylinder.
Use an inlet velocity magnitude based on best practices.
Use a cylinder diameter based on best practices.
Use computational domain dimensions (length and height) based on best practices.
Use time step size and total simulation time based on best practices for transient simulation.
