Set up a transient simulation of turbulent flow over a 2D cylinder in a channel using pimpleFoam.
The simulation should be configured to use both Large Eddy Simulation (LES) and a Reynolds-Averaged Navier-Stokes (RANS) model simultaneously to capture both large and small scale turbulence.
In the constant/turbulenceProperties dictionary, specify the simulation type as LES and also include a RAS sub-dictionary.
The turbulenceProperties file should contain simulationType LES, LES sub-dictionary with Smagorinsky model and cubeRootVol delta, and RAS sub-dictionary with kOmegaSST model with turbulence on and printCoeffs on.
Use standard air properties for an incompressible fluid.
The inlet velocity is 10 m/s.
The cylinder and channel walls should have noSlip boundary conditions.
Make reasonable assumptions for cylinder diameter based on best practices.
Make reasonable assumptions for channel dimensions (length and height) based on best practices.
Make reasonable assumptions for Reynolds number based on best practices.
Make reasonable assumptions for time step size based on best practices.
Make reasonable assumptions for total simulation time or number of time steps based on best practices.
