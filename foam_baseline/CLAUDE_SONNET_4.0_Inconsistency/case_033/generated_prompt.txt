Perform a 2D simulation of heat conduction through a square solid plate using laplacianFoam.
The domain is 1m x 1m and one cell thick.
The goal is to find the steady-state temperature distribution.
In blockMeshDict, define four side patches (left, right, top, bottom) and the 'frontAndBack' patches.
Set the 'frontAndBack' patches to 'type wall'.
In the '0/T' file, set the left wall to a fixedValue of 400 K.
Set the right wall to a fixedValue of 300 K.
Set the top and bottom walls to 'zeroGradient'.
For the 'frontAndBack' patches, also apply a 'zeroGradient' boundary condition to simulate an insulated plate.
Use a reasonable mesh resolution based on best practices.
Use a reasonable thermal diffusivity value based on best practices.
