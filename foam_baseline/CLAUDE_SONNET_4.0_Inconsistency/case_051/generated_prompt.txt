Simulate the transient start-up flow of a Bingham plastic fluid in a 2D pipe.
Use the solver icoFoam.
The domain is a rectangle of 1.0m length and 0.1m diameter.
Use blockMesh to create a mesh with 100 cells in the axial (x) direction and 20 cells in the radial (y) direction.
The front and back patches should be of type empty.
Set an inlet boundary condition with a fixed velocity of (0.1 0 0) m/s.
Set an outlet boundary condition with zeroGradient for velocity and a fixed pressure of 0.
Set noSlip boundary conditions on the walls.
Run the simulation from t=0 to t=5s.
In constant/transportProperties, define the fluid as a Bingham plastic with transportModel BinghamPlastic, rho 1000, tau0 10, mu0 0.1, and muInf 0.01.
Use a reasonable initial condition for the velocity field at t=0 based on best practices.
Use a reasonable initial condition for the pressure field at t=0 based on best practices.
