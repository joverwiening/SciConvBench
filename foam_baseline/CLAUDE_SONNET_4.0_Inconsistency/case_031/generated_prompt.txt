Set up a 2D incompressible laminar flow simulation in a rectangular channel using the icoFoam solver.
The channel is 0.5 m long (x-direction) and 0.1 m high (y-direction).
The mesh should be one cell thick in the z-direction.
Use a reasonable mesh resolution based on best practices for the x-direction and y-direction.
In blockMeshDict, define the geometry and patches: inlet, outlet, topWall, bottomWall, and frontAndBack.
For the frontAndBack patches, specify 'type wall;'.
The simulation should model Poiseuille flow.
Use reasonable fluid properties (kinematic viscosity) based on best practices for the target Reynolds number.
In the '0/U' file, set a parabolic inlet velocity profile with a maximum of 1 m/s.
Apply zeroGradient outlet boundary condition for velocity.
Apply noSlip conditions on topWall and bottomWall for velocity.
For the frontAndBack patches, also apply the 'noSlip' boundary condition for velocity.
In '0/p', use fixedValue 0 at the outlet.
Apply zeroGradient pressure boundary condition on all other patches, including frontAndBack.
