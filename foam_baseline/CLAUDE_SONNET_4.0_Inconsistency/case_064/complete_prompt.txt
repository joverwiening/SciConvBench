Model a flexible flap in a channel where the fluid loading deforms the flap (fluid–structure interaction). Geometry (2D, extruded one cell in z with `frontAndBack` empty): channel length 1.0 m, height 0.2 m; flap length 0.05 m, thickness 0.005 m, attached to the bottom wall at x = 0.4 m.

Fluid (incompressible water):
- `nu = 1e-6 m^2/s`
- inlet: `U = (1 0 0)` (fixedValue)
- outlet: `p = 0` (fixedValue)
- channel walls: `noSlip`

Solid flap (linear elastic):
- `E = 1e6 Pa`, `nu = 0.45`, `rho = 1200 kg/m^3`
- flap base: fixed displacement
- flap surface: coupled interface boundary

Solution approach:
- fluid solver: `pimpleFoam`
- solid solver: `solidDisplacementFoam` (separate solid region)
- interface coupling: two-way FSI coupling each time step exchanging displacement and traction (e.g., via solids4foam or preCICE)
