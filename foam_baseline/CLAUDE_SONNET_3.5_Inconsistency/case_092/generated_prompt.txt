Simulate the compressible, supersonic flow of air over a 10-degree wedge to form an oblique shock.
Use rhoPimpleFoam solver for the simulation.
The freestream Mach number is 2.0.
Set inlet conditions to U = (686 0 0) m/s, T = 293 K, p = 101325 Pa.
Treat air as a perfect gas using hePsiThermo model with perfectGas equation of state and sutherland transport model.
Set inlet boundary conditions to fixed values for U, p, and T.
Set outlet boundary conditions to waveTransmissive for p and T, and zeroGradient for U.
Configure wedge surface and top boundary as slip walls.
Set frontAndBack patches to empty type.
Use a 2D mesh extruded one cell in z direction.
The mesh size and endTime should follow best practices for this type of simulation.
