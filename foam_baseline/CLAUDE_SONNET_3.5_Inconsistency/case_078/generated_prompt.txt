Set up a simulation of airflow in a ventilated room with a heater using buoyantSimpleFoam.
The room dimensions should follow typical room dimensions (e.g., 5m x 4m x 3m).
Create an inlet vent on one wall (e.g., 0.3m x 0.3m).
Create an outlet vent on the opposite wall (matching inlet dimensions).
Place a heater on one wall (e.g., 1m x 0.5m).
Set inlet air temperature to 293 K.
Set heater wall patch temperature to 320 K using fixedValue boundary condition.
Use inlet velocity appropriate for room ventilation (e.g., 0.5 m/s).
Configure thermophysicalProperties with thermoType heRhoThermo.
Set equationOfState to Boussinesq with T0 293, beta 0.00341, and rho0 1.2.
Use const transport model with mu 1.8e-5 and Pr 0.71.
Model the natural convection driven by the heater.
Use steady-state solver buoyantSimpleFoam.
