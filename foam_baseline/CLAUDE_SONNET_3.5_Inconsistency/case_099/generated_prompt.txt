Simulate 2D laminar, transient flow past a square cylinder in a channel using icoFoam.
The domain dimensions are 2.2m long, 0.41m high, and 0.01m thick (one cell).
A square cylinder of dimensions 0.1m x 0.1m is placed in the flow path.
The kinematic viscosity (nu) is 0.001 m^2/s.
The inlet boundary condition for U is a parabolic profile with maxValue (1.5 0 0).
The outlet boundary condition for U is zeroGradient.
The topAndBottomWalls boundary condition for U is noSlip.
The cylinder boundary condition for U is noSlip.
The frontAndBack boundary condition for U is noSlip.
The inlet boundary condition for p is zeroGradient.
The outlet boundary condition for p is fixedValue uniform 0.
The topAndBottomWalls boundary condition for p is zeroGradient.
The cylinder boundary condition for p is zeroGradient.
The frontAndBack boundary condition for p is zeroGradient.
The frontAndBack patches are defined with type wall in constant/polyMesh/boundary.
The square cylinder location, simulation end time, time step size, and write interval should follow best practices for this type of simulation.
