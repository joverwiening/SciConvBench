Perform a transient simulation of a Rayleigh-Bénard convection cell using buoyantPimpleFoam.
The domain is a 2D rectangle with dimensions 0.1 m width × 0.05 m height.
Use a uniform mesh with 100 cells in x-direction and 50 cells in y-direction.
The bottom wall is heated to 305 K and the top wall is cooled to 295 K.
The fluid is water.
Apply the Boussinesq approximation for buoyancy effects.
Set thermoType to hePsiThermo in constant/thermophysicalProperties.
Set equationOfState to Boussinesq with appropriate coefficients for water.
Use Gauss linear scheme for temperature divergence (div(phi,T)).
Use Gauss upwind scheme for velocity divergence (div(rhoPhi,U)).
Run the simulation for 300 seconds of physical time.
Use adjustableRunTime with maxCo = 0.5 for time step control.
