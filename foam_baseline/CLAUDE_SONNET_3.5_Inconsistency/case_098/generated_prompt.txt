Set up a 2D axisymmetric simulation of swirling flow in a pipe using OpenFOAM.
The pipe diameter is 0.1 meters.
The pipe length is 1.0 meters.
Create a 5-degree wedge mesh using blockMeshDict.
Use the simpleFoam solver.
Define patches: inlet (type patch), outlet (type patch), wall (type wall), front (type symmetryPlane), back (type symmetryPlane).
Set inlet velocity with axial component of 1 m/s and swirl component of 0.5 m/s.
Apply noSlip condition on wall.
Apply zeroGradient condition on outlet.
Apply symmetryPlane condition on front and back patches.
The mesh should follow best practices for pipe flow simulation with proper cell aspect ratios.
