Set up a 2D lid-driven cavity flow in a 1 m × 1 m square domain, extruded one cell in z.
Create a uniform mesh of 40 × 40 × 1 cells.
Use an incompressible Newtonian fluid with kinematic viscosity nu = 0.01 m^2/s.
Use icoFoam solver for the simulation.
Set endTime to a reasonable value for steady-state convergence.
Set deltaT to a reasonable value that ensures numerical stability.
Apply boundary condition movingLid (top): 0/U is fixedValue uniform (1 0 0).
Apply boundary condition fixedWalls (left, right, bottom): 0/U is noSlip.
Apply boundary condition 0/p: zeroGradient on all walls.
Set pressure reference using pRefCell and pRefValue in system/fvSolution.
Set frontAndBack patches as empty type.
Run simulation until steady state is reached.
