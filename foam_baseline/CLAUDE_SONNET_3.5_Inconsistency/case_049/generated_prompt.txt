Set up a 2D incompressible laminar flow simulation over a NACA 0012 airfoil using simpleFoam.
The Reynolds number is set to 1000 for laminar flow conditions.
The airfoil has a chord length of 1 meter.
The angle of attack is set to 5 degrees.
The mesh is extruded one cell in the z-direction.
Use patch name 'frontAndBack' for the out-of-plane faces.
In constant/polyMesh/boundary, set frontAndBack type to wall.
In 0/U, set frontAndBack type to slip.
The simulation uses standard sea-level air properties.
