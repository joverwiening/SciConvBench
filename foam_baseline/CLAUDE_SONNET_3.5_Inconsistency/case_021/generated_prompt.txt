Set up a 2D incompressible steady-state simulation of airflow over a NACA 0012 airfoil.
Use the simpleFoam solver for the simulation.
Set the angle of attack to 5 degrees.
Create a C-grid topology extending 15 chord lengths upstream, 20 chord lengths downstream, and 15 chord lengths in the vertical direction.
Generate a mesh with approximately 100,000 cells.
Set the domain to be one cell thick in the z-direction.
Define front and back patches as walls in system/blockMeshDict using the provided boundary entry.
Apply inlet velocity of (10 0 0) m/s uniform.
Set zero-gradient outlet condition.
Apply noSlip condition on the airfoil surface.
Apply noSlip condition on the frontAndBack patches.
Set zeroGradient for pressure at inlet and airfoil.
Set fixedValue uniform 0 for pressure at outlet.
Set zeroGradient for pressure on frontAndBack patches.
