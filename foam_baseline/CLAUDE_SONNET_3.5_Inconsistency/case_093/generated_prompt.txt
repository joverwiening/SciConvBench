Set up a 2D dam break simulation in OpenFOAM with the following specifications:
Create a rectangular domain of 4m length x 2m height.
Initialize a water column of 1m length x 1m height on the left side of the domain.
Use a uniform mesh resolution of 100 cells per meter (0.01m cell size).
Set the time step (deltaT) to 0.001 seconds.
Use the pimpleFoam solver for multiphase flow.
Set endTime to 5 seconds in controlDict.
Use setFields to initialize alpha.water = 1 for the water column and alpha.water = 0 for the air region.
Set gravity vector to (0 -9.81 0) m/s².
Include transportProperties dictionary with two phases: water (density = 998 kg/m³, kinematic viscosity = 1e-6 m²/s) and air (density = 1.2 kg/m³, kinematic viscosity = 1.48e-5 m²/s).
Create the domain with empty front and back patches for 2D simulation.
The simulation will track the collapse of the water column under gravity.
