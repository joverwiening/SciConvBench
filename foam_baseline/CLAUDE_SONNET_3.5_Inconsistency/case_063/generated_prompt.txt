Simulate a 2D von Kármán vortex street behind a cylinder with the following specifications:
The cylinder diameter is 0.1 meters.
The channel height is 0.8 meters (8D).
The channel length is 2.5 meters (25D), with the cylinder placed at x = 0.5m.
Use pimpleFoam as the solver.
Set kinematic viscosity to nu = 1e-3 m^2/s.
The simulation runs for 10 seconds.
Use deltaT = 0.001 seconds.
Write results every 0.1 seconds (writeInterval = 0.1).
The mesh is extruded one cell in z-direction with frontAndBack type empty.
Inlet boundary uses fixedValue uniform (0.1 0 0) for U.
Outlet boundary uses zeroGradient for U.
Cylinder uses noSlip condition for U.
Top and bottom boundaries use slip condition for U.
Inlet uses zeroGradient for p.
Outlet uses fixedValue uniform 0 for p.
Cylinder, top, and bottom boundaries use zeroGradient for p.
All frontAndBack boundaries use empty type.
