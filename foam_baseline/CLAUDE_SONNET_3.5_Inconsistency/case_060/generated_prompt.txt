Set up a 2D dam break simulation with the following specifications:
The initial water column has dimensions of 0.146m width by 0.292m height.
The computational domain size is 0.584m width by 0.584m height.
The mesh resolution is 200 cells per meter, resulting in a uniform grid.
The simulation will run for 1 second of physical time.
The domain is extruded one cell in z-direction with frontAndBack patches set to empty.
Use setFields to initialize alpha.water as 1 in the water column region and 0 elsewhere.
The solver is set to twoPhaseEulerFoam in system/controlDict.
The case represents a sharp interface between water and air phases.
