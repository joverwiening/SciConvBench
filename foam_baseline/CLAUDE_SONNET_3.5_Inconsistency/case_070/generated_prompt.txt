Set up a 2D natural convection simulation in a sealed cavity with dimensions 0.1m width × 0.3m height.
The left wall is maintained at 350K and the right wall at 300K.
The top and bottom walls are adiabatic.
Use buoyantBoussinesqSimpleFoam solver in OpenFOAM.
Create a structured mesh with 50 cells in the x-direction and 150 cells in the y-direction.
Set gravity to act in the negative y-direction (-9.81 m/s²).
Use air as the working fluid with standard properties at room temperature.
Run the simulation for 1000 seconds of physical time.
Set the pressure field convergence tolerance to 1e-6.
Apply fixedValue boundary conditions for temperature as specified in the input.
Correct the boundary conditions for top and bottom walls to zeroGradient type to properly represent adiabatic conditions.
Initialize the temperature field with a linear gradient between the hot and cold walls.
