Perform a steady-state, incompressible simulation of airflow over a NACA 0012 airfoil.
The simulation is 2D with a single layer of cells in the z-direction.
The domain extends 20 chord lengths upstream, 30 chord lengths downstream, and 20 chord lengths to each side.
Set the freestream velocity to 50 m/s.
Use an angle of attack of 2 degrees.
Target a y+ value of approximately 1 for wall-resolved simulation.
Use the simpleFoam solver.
Implement the k-omega SST turbulence model.
The patches for the thin dimension are named frontAndBack and defined with type wall.
Set the frontAndBack boundary condition to noSlip in 0/U.
Set the frontAndBack boundary condition to zeroGradient in 0/p.
The Reynolds number will be approximately 3.4 million based on standard air properties and a 1-meter chord length.
