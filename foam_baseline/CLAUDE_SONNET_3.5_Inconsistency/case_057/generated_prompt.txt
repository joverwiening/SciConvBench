Simulate a 2D bubble column using twoPhaseEulerFoam with the following specifications:
The column dimensions are 0.5m wide and 2m high.
The continuous phase is water, and the dispersed phase is air.
Use a structured mesh with 50 cells in horizontal direction and 200 cells in vertical direction.
Set the air inlet velocity at the bottom to 0.1 m/s.
Run the simulation for 30 seconds to achieve quasi-steady state.
Use the k-epsilon turbulence model for both phases.
Initialize the domain using setFieldsDict with the provided configuration.
The bottom 1.5m of the column should have alpha.air = 0.4 and alpha.water = 0.7.
The top 0.5m of the column should have alpha.air = 0.9 and alpha.water = 0.1.
Apply standard atmospheric pressure (101325 Pa) at the outlet.
Use standard gravitational acceleration (9.81 m/s²) in the negative y-direction.
