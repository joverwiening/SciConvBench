Set up a 2D dam break simulation using the interFoam solver.
The domain dimensions are 1m long and 1m high.
Initialize a water column in the region 0 < x < 0.2 and 0 < y < 0.5.
Use a mesh resolution of 100 cells in both x and y directions (standard practice for this scale).
Set the simulation end time to 2 seconds (typical for observing complete dam break dynamics).
Set acceleration due to gravity as g (0 0 -9.81) in the constant/g file.
Use setFieldsDict to initialize alpha.water field to 1 in water column region and 0 elsewhere.
Set the top boundary as pressureInletOutletVelocity (open atmosphere).
Set all other boundaries as noSlip walls.
The rest of the domain is initially filled with air.
