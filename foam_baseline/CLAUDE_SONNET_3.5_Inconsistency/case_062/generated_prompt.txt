Simulate the static deflection of a 2D cantilever beam under downward traction load using linear elasticity.
The beam dimensions are 1.0 m long and 0.1 m high.
Use a structured mesh of 100 × 10 cells.
Use solidDisplacementFoam solver for the simulation.
Set up the case for 2D simulation mode.
Use aluminum as the material with Young's modulus E = 70e9 Pa and Poisson's ratio nu = 0.33.
Apply fixedValue uniform (0 0 0) boundary condition at the fixed end (x=0).
Apply tractionDisplacement with traction uniform (0 -10000 0) and pressure uniform 0 at the load end (x=1).
Apply zeroGradient boundary conditions at the top and bottom surfaces.
Configure boundary conditions in the 0/D directory.
