Set up a 2D incompressible laminar flow simulation in a rectangular channel using the icoFoam solver.
The channel dimensions are 0.5 m long (x-direction) and 0.1 m high (y-direction).
Create a mesh with 100 cells in x-direction and 20 cells in y-direction.
Make the mesh one cell thick in the z-direction.
Use a kinematic viscosity (nu) value of 1e-6 m²/s.
In blockMeshDict, define patches: inlet, outlet, topWall, bottomWall, and frontAndBack.
Set frontAndBack patches type as wall.
Model Poiseuille flow with a parabolic inlet velocity profile with maximum velocity of 1 m/s.
In 0/U file, set zeroGradient outlet condition.
Apply noSlip conditions on topWall and bottomWall.
Apply noSlip conditions on frontAndBack patches.
In 0/p file, set fixedValue 0 at the outlet.
Apply zeroGradient boundary condition for pressure on all other patches, including frontAndBack.
