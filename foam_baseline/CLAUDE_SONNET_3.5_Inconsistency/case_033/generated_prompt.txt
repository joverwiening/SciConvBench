Perform a 2D heat conduction simulation through a square solid plate using laplacianFoam.
The domain dimensions are 1m x 1m x 1cell.
Use a mesh resolution of 50x50 cells in the x and y directions.
Set the thermal conductivity to 1 W/(m·K) as a standard reference value.
Run the simulation for 1000 seconds to ensure steady state is reached.
Use a time step size of 0.1 seconds.
Create four side patches (left, right, top, bottom) and frontAndBack patches in blockMeshDict.
Set frontAndBack patches to type wall.
Apply temperature boundary conditions in 0/T:
Left wall: fixedValue 400 K
Right wall: fixedValue 300 K
Top wall: zeroGradient
