Perform a conjugate heat transfer simulation of an electronics component with the following specifications:
Use chtMultiRegionSimpleFoam solver for the simulation.
The setup consists of a solid silicon chip region and a fluid air region.
The chip dimensions should follow industry standard dimensions for typical electronics components.
The heat generation in the chip should be specified via fvOptions using typical values for electronics components.
The housing enclosure dimensions should be sized appropriately relative to the chip dimensions.
The outer surface of the housing (outerCasing) is perfectly insulated.
Air enters at 293 K with an appropriate velocity for electronics cooling.
Air exits at an outlet boundary.
In the 0/air/T file, set the inlet to a fixed temperature of 293 K.
In the 0/solid/T file, set the outerCasing boundary condition to fixedValue with uniform value 293.
