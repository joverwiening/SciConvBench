Set up initial conditions for a three-phase settling tank simulation using multiphaseEulerFoam solver.
The simulation uses three phases: sediment, water, and oil.
Create field files in the 0/ directory for each phase (alpha.sediment, alpha.water, alpha.oil).
Set the internalField value to uniform 0.5 in all three alpha files as the default condition.
The stratified layers will be created later using setFieldsDict.
The exact dimensions and layer heights can be determined based on best practices during implementation.
