Configure a 2D simulation of flow past a cylinder using pimpleFoam for a transient, incompressible, laminar case.
Use a cylinder diameter of 1 meter.
Set inlet velocity to 0.1 m/s uniform in x-direction.
Use kinematic viscosity of 1e-5 m²/s (corresponding to water at room temperature).
Run simulation for 100 seconds to ensure development of von Karman vortex street.
The mesh is one cell thick in z-direction.
Set frontAndBack patches in constant/polyMesh/boundary as type symmetryPlane.
In 0/U file, set frontAndBack boundary condition as type wall with value uniform (0 0 0).
Configure inlet with fixed velocity boundary condition.
Configure outlet with zero gradient pressure boundary condition.
Set cylinderWall with no-slip boundary condition.
This configuration yields a Reynolds number of 10000, ensuring laminar vortex shedding regime.
