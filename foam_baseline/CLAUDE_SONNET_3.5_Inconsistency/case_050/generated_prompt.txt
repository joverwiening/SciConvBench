Simulate a high-speed, compressible supersonic jet with inlet Mach number 2.0 discharging into a larger domain.
The computational domain extends 20 inlet diameters downstream and 10 inlet diameters in the radial direction.
Use a 2D mesh extruded one cell in z with frontAndBack set to empty.
Set inlet conditions to U = (686 0 0) m/s, T = 300 K, p = 101325 Pa.
Configure constant/thermophysicalProperties with hePsiThermo, perfectGas equation of state, and sutherland transport model.
Apply fixed value boundary conditions for U, p, and T at the nozzle inlet (supersonic inflow).
Use waveTransmissive boundary conditions for p and T, and zeroGradient for U at the far-field/outlet.
Apply no-slip boundary conditions on solid walls to capture viscous effects.
Set application to pimpleFoam in system/controlDict.
Run simulation until t = 0.1 seconds to allow flow development and steady state convergence.
