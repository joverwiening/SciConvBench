Set up a laminar counter-flow diffusion flame simulation in OpenFOAM using reactingFoam solver.
The domain dimensions are x = 0 to 0.02 m, y = -0.01 to 0.01 m, z = -0.01 to 0.01 m.
Use mesh with 100 points in x, 40 in y, and 1 cell in z direction.
The left boundary (x = 0) is named fuel, right boundary (x = 0.02) is named air.
Top and bottom boundaries are named outlet.
FrontAndBack faces are empty type.
Fuel inlet supplies CH4 at 293 K with velocity 0.1 m/s.
Air inlet supplies oxidizer at 293 K with Y_O2 = 0.23, balance N2, and velocity -0.1 m/s.
Initialize domain temperature to 2000 K at t = 0.
Use GRI-Mech 3.0 mechanism for chemical kinetics (standard for methane combustion).
Set maximum Courant number to 0.5 for stability.
Initialize pressure to 1 atm (101325 Pa).
Set zeroGradient pressure boundary condition at fuel and air inlets.
Set totalPressure boundary condition at outlets.
Use chemistry type EulerImplicit with Rosenbrock43 ODE solver.
Use laminar combustion and momentum transport models.
Implement compressible finite-rate chemistry with hePsiThermo.
Use coefficientWilkeMultiComponentMixture for mixing.
Use Sutherland transport model.
Use JANAF thermodynamics.
Set viscosity to 0 everywhere for inviscid flame.
Set timestep to 1e-4 s.
Set endTime to 0.5 s.
Write results every 0.05 s.
