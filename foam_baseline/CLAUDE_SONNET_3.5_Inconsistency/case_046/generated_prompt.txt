Set up a transient simulation of turbulent flow over a 2D cylinder in a channel using pimpleFoam.
The cylinder diameter should be 1 meter.
The channel dimensions should be 50 meters long and 10 meters high.
The cylinder should be placed at 10 meters from the inlet.
The simulation should run for 10 seconds of flow time.
Use a time step size of 0.001 seconds.
Configure both LES and RANS models as specified in the turbulenceProperties dictionary.
Use LES with Smagorinsky model and cubeRootVol delta.
Use kOmegaSST for the RAS model with turbulence and printCoeffs enabled.
Set inlet velocity to 10 m/s.
Apply noSlip boundary conditions to cylinder and channel walls.
Use standard air properties for incompressible fluid (density = 1.225 kg/m³, kinematic viscosity = 1.5e-5 m²/s).
Create a 2D mesh with appropriate refinement near the cylinder and walls.
