Set up an axisymmetric simulation of swirling flow inside a pipe using simpleFoam.
Create a 2D wedge geometry with a 5-degree angle in the tangential direction.
Use a pipe length of 1 meter.
Use a pipe diameter of 0.1 meters.
Set inlet axial velocity to 1 m/s.
Set inlet swirl ratio (tangential/axial velocity) to 0.5.
Create one cell thick mesh in the tangential direction.
Define axial patches as 'axis' in system/blockMeshDict.
Define pipe surface as 'wall' in system/blockMeshDict.
Define inlet and outlet patches in system/blockMeshDict.
Define front and back planes of the wedge as 'empty' type.
Use the provided face definitions for front and back patches.
