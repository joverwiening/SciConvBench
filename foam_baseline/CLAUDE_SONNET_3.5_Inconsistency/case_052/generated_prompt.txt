Set up a 2D lid-driven cavity simulation for a non-Newtonian, shear-thinning fluid.
Use the nonNewtonianIcoFoam solver.
The cavity dimensions are 1m x 1m square.
The top wall (lid) moves with a velocity of (1 0 0) m/s.
All other walls have noSlip boundary conditions.
The simulation is transient with a total simulation time of 10 seconds.
Use a uniform mesh with 100x100 cells.
Set the time step size to 0.001 seconds.
Save simulation results every 0.1 seconds.
Use the Power Law non-Newtonian model with parameters: k=0.1, n=0.5, nuMax=1, nuMin=1e-6.
Set initial transportProperties with transportModel Newtonian and nu [0 2 -1 0 0 0 0] 1e-3.
