Set up a 2D dam break simulation with the following specifications:
The tank dimensions are 0.584 m wide by 0.438 m high.
The initial water column dimensions are 0.146 m wide by 0.292 m high, positioned at the left side of the tank.
The simulation should run for 1 second of physical time.
Use a 2D mesh extruded one cell in the spanwise direction with frontAndBack set to empty.
Track the interface using VOF field alpha.water.
Initialize the water column using setFields with alpha.water = 1 inside the initial column and 0 elsewhere.
Set gravity to (0 -9.81 0).
Apply noSlip for U, zeroGradient for p_rgh, and zeroGradient for alpha.water on tank walls.
Apply pressureInletOutletVelocity for U, totalPressure/fixedValue (0) for p_rgh, and inletOutlet for alpha.water with inletValue uniform 0 on the open top.
Use solidDisplacementFoam as the application in system/controlDict.
