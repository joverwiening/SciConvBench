Simulate incompressible water flow in a channel with a prescribed moving wall (simplified peristaltic pumping) using a dynamic mesh.
The channel dimensions are 0.1 m length x 0.02 m height.
The inlet velocity is set to 0.01 m/s uniform in x-direction.
The moving wall oscillates with amplitude 0.005 m and frequency 1 Hz.
The simulation runs for 10 seconds with adjustable time step targeting Courant number below 1.
Use a 2D mesh extruded one cell in the spanwise direction with frontAndBack as empty.
Water kinematic viscosity is 1e-6 m^2/s.
Use dynamicMotionSolverFvMesh with displacementLaplacian in constant/dynamicMeshDict.
Prescribe motion on the movingWall via 0/pointDisplacement using oscillatingDisplacement.
All non-moving boundaries have fixedValue uniform (0 0 0) for pointDisplacement.
For 0/U: set inlet as fixedValue, outlet as zeroGradient, stationary walls as noSlip, movingWall uses movingWallVelocity.
For 0/p: set outlet as fixedValue uniform 0, inlet and walls as zeroGradient.
Use solidDisplacementFoam as the solver application in system/controlDict.
