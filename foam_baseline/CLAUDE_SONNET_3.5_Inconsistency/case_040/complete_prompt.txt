Simulate incompressible water flow in a channel with a prescribed moving wall (simplified peristaltic pumping) using a dynamic mesh. Use a 2D mesh extruded one cell in the spanwise direction with `frontAndBack` as `empty`. Water properties: `nu = 1e-6 m^2/s`.

Mesh motion:
- Use `dynamicMotionSolverFvMesh` with `displacementLaplacian` (or similar) in `constant/dynamicMeshDict`.
- Prescribe motion on the `movingWall` via `0/pointDisplacement` (e.g., `oscillatingDisplacement`); all other boundaries `fixedValue uniform (0 0 0)`.

Flow boundary conditions:
- `0/U`: inlet `fixedValue`, outlet `zeroGradient`, stationary walls `noSlip`, `movingWall` uses `movingWallVelocity`
- `0/p`: outlet `fixedValue uniform 0`, inlet/walls `zeroGradient`

In `system/controlDict`, set:
```foam
application     pimpleFoam;
```
