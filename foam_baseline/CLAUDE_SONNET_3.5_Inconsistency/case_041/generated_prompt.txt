Set up a simulation of 2D laminar, incompressible flow past a cylinder at a Reynolds number of 100 to observe the von Kármán vortex street.
The domain is a rectangular channel 2.2m long and 0.41m high, with a cylinder of diameter 0.1m centered at (0.2, 0.2).
Use blockMesh for the base rectangular domain and snappyHexMesh for the cylinder geometry.
Use a kinematic viscosity of 1e-3 m²/s and a uniform inlet velocity of U = (1 0 0) m/s.
The mesh is one cell thick in the z-direction.
In system/controlDict, use simpleFoam as the solver.
Set startTime to 0, endTime to 200, deltaT to 1, and writeInterval to 10.
For U boundary conditions, set inlet to fixedValue uniform (1 0 0), outlet to zeroGradient, cylinderWall to noSlip, topAndBottom to noSlip, and frontAndBack to empty.
For p boundary conditions, set inlet and cylinderWall to zeroGradient, outlet to fixedValue uniform 0, topAndBottom to zeroGradient, and frontAndBack to empty.
Run the simulation until reaching the specified endTime of 200 seconds.
