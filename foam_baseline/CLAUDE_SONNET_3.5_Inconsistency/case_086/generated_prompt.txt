The simulation requires setting up a 2D compressible flow case with buoyantPimpleFoam solver.
The domain is a 5 m × 3 m room, extruded one cell in z-direction with frontAndBack empty boundary condition.
Place a 0.5 m × 0.5 m hot block at the center of the room (coordinates (2.25, 1.25) for bottom-left corner).
Set initial temperature of the block to 400 K.
Set initial temperature of surrounding air to 300 K.
Apply adiabatic walls (zeroGradient for T) and noSlip condition for velocity on all walls.
Set gravity as (0 -9.81 0).
Use Boussinesq equation of state in thermophysicalProperties with specified configuration.
Use base mesh size of 0.05 m with local refinement around the hot block to 0.025 m.
Run simulation for 300 seconds to observe full cooling process.
Create mesh using blockMesh and snappyHexMesh utilities.
Monitor temperature and velocity fields during the simulation.
