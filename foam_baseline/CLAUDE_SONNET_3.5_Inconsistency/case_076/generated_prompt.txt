Set up a steady-state 2D natural convection simulation in a square cavity with dimensions 1m x 1m.
The left wall is hot (310 K) and the right wall is cold (290 K), while the top and bottom walls are adiabatic.
Use the buoyantBoussinesqSimpleFoam solver.
Gravity acts in the -y direction, g = (0 -9.81 0).
The fluid is air.
Use thermoType heRhoThermo in constant/thermophysicalProperties.
Set mixture to pureMixture.
Set transport to const.
Set thermo to hConst.
Set equationOfState to perfectGas.
Set specie to hConst.
Set energy to sensibleEnthalpy.
Set molecular weight to 28.9 g/mol.
In constant/transportProperties, set mu to 1.8e-5.
In constant/transportProperties, set Pr to 0.7.
Create a uniform mesh with 50x50 cells.
In 0/T, set the left wall to fixedValue uniform 310.
In 0/T, set the right wall to fixedValue uniform 290.
In 0/T, set top and bottom walls to zeroGradient.
In 0/U, use noSlip on all walls.
In 0/p_rgh, use fixedFluxPressure on all walls.
Initialize the temperature field to a linear gradient between hot and cold walls.
Initialize the velocity field to (0 0 0) everywhere.
