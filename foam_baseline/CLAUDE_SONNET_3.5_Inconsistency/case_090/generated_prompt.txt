Set up a 2D vortex shedding simulation behind a cylinder at Reynolds number 100.
The domain is a rectangular channel 40m long by 20m high.
Place the cylinder center at (8m, 10m) from the inlet.
The cylinder diameter is 1m.
Use incompressible fluid with kinematic viscosity nu = 0.01 m^2/s.
Set inlet velocity to U = (1 0 0) m/s.
Use simpleFoam solver for the simulation.
Create mesh with 120 cells around cylinder circumference.
Set maximum far-field cell size to 0.5m.
Apply boundary conditions: inlet (fixedValue U), outlet (zeroGradient U, fixedValue p=0), topAndBottom (slip), cylinder (noSlip), frontAndBack (empty).
Run simulation from t=0 to t=200s with deltaT = 0.1s.
Monitor flow field to observe von Kármán vortex street formation.
Calculate Strouhal number from vortex shedding frequency.
