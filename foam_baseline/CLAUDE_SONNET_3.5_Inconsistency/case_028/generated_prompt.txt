Create a 2D laminar incompressible flow simulation in a channel with the following specifications:
The channel geometry is 1m long, 0.1m high, and 0.01m deep.
Use blockMesh to generate the mesh with 100 cells in x-direction and 50 cells in y-direction.
The mesh should be one cell thick in the z-direction.
Define boundary patches as inlet, outlet, topWall, bottomWall, and frontAndBack.
Set frontAndBack patches as wall type with faces (0 4 7 3) and (1 2 6 5).
Apply no-slip condition (0 0 0) at all walls including frontAndBack.
Use inlet velocity of 1 m/s in x-direction.
Set kinematic viscosity to 1e-6 m²/s (water-like fluid).
Run simulation for 5 seconds to reach steady state.
Use icoFoam solver for the simulation.
