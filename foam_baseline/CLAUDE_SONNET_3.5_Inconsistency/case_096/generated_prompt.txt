Simulate a 2D dam break problem using the interFoam solver for water and air.
Create a rectangular tank domain of 0.5m x 0.5m x 0.01m (length x height x depth).
Use a structured mesh with 100 cells in x-direction and 100 cells in y-direction, with a single cell layer in z-direction.
Set gravity as (0 -9.81 0) m/s².
Initialize water column (alpha.water=1) in region x < 0.15m using setFieldsDict.
Set remaining domain as air (alpha.water=0).
Set boundary leftWall, rightWall, lowerWall as type wall.
Set boundary atmosphere as type patch.
Set boundary frontAndBack as type symmetry.
Apply noSlip condition for U on walls.
Apply pressureInletOutletVelocity for U on atmosphere.
Apply symmetry condition for U on frontAndBack.
Apply fixedFluxPressure for p_rgh on walls and frontAndBack.
Apply totalPressure for p_rgh on atmosphere.
Apply zeroGradient for alpha.water on walls and frontAndBack.
Apply inletOutlet for alpha.water on atmosphere.
Run simulation until endTime = 2.0 seconds.
Use adjustable timeStep with maxCo = 0.5 for time step control.
