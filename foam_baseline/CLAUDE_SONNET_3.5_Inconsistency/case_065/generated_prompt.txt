Simulate transient elastic wave propagation in a solid aluminum block.
The domain is 1.0 m × 0.1 m × 0.1 m.
Material properties are E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3.
Use a mesh resolution of dx = 0.005 m (approximately 20 elements across the width/height).
Set the total simulation time to 0.001 seconds to observe wave propagation.
Use a time step of dt = 1e-6 seconds to ensure numerical stability.
Initialize displacement field D with (1e-6 0 0) m near x = 0 and (0 0 0) elsewhere using setFields.
Apply traction-free boundary conditions on all external faces using tractionDisplacement with zero traction and pressure.
Use pimpleFoam as the solver application.
Write simulation results every 1e-5 seconds (every 10 time steps).
