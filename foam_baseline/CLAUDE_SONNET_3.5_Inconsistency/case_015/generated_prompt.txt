Run a 2D inviscid laminar oblique-shock simulation in a rectangular channel.
The domain extends from (0, 0, 0) to (4.1, 1, 0.1).
Use 60 cells in x-direction, 30 cells in y-direction, and 1 cell in z-direction.
Set frontAndBack patches to empty type.
Define boundaries as inlet (left), outlet (right), top (wall), and bottom (symmetryPlane).
Use simpleFoam solver with laminar momentumTransport.
Use ideal gas with molecular weight 11640.3.
Set thermophysical properties: Cp=2.5, Pr=1, viscosity=0, Hf=0.
Set operating pressure (p_ref) to 100000 Pa.
Initialize fields with U=(2.9 0 0), p=1, T=1.
Set inlet boundary conditions: U=(2.9 0 0), p=zeroGradient, T=1.
Set outlet boundary conditions: U=zeroGradient, p=fixedValue 1, T=zeroGradient.
Set top wall boundary conditions: U=(2.61933 -0.50632 0), p=zeroGradient, T=1.25853.
Set bottom symmetryPlane boundary conditions: U=symmetryPlane, p=symmetryPlane, T=symmetryPlane.
Set convergence criteria to 1e-6 for all residuals.
Set deltaT=0.0025, endTime=10, writeInterval=1.
