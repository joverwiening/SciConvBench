Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity.
The beam dimensions are 1 m long, 0.1 m high, and 0.1 m wide.
Use a mesh with approximately 10,000 hexahedral elements for good accuracy while maintaining reasonable computational cost.
Set the simulation to run for a maximum of 30 minutes.
The beam has one end clamped (fixed) and a downward traction load at the free end.
Use steel properties with Young's modulus E = 200e9 Pa and Poisson ratio nu = 0.3.
Apply fixedValue uniform (0 0 0) boundary condition at the fixed end.
Apply tractionDisplacement with traction uniform (0 -1000 0) and pressure uniform 0 at the loaded end.
Use zeroGradient boundary condition for all other faces.
Set application to pimpleFoam in system/controlDict.
Set endTime to 1 in system/controlDict.
