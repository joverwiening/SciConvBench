Perform a 2D transient heat conduction simulation on a 1 m × 1 m plate using laplacianFoam.
Create a uniform mesh with 50x50 cells in the x-y plane.
Extrude the mesh one cell in the z-direction with thickness 0.01 m.
Set thermal diffusivity (DT) to 1e-5 m^2/s.
Set initial temperature (T) to uniform 300 K.
Set simulation time to 1000 seconds to allow for sufficient heat diffusion.
Apply fixed temperature of 350 K on the left wall.
Apply fixed temperature of 300 K on the right wall.
Apply zeroGradient boundary condition on top and bottom walls.
Set frontAndBack patch type as wall in constant/polyMesh/boundary.
Set frontAndBack boundary condition as zeroGradient in 0/T.
