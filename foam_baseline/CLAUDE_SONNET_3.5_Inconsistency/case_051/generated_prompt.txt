The simulation requires a 2D pipe flow setup with the following specifications:
Create a rectangular domain of 1.0m length and 0.1m diameter using blockMesh.
Use 100 cells in the axial (x) direction and 20 cells in the radial (y) direction.
Set front and back patches as empty type.
Set inlet boundary condition with fixed velocity (0.1 0 0) m/s.
Set outlet boundary with zeroGradient velocity and fixed pressure of 0.
Apply noSlip condition at the walls.
Run simulation from t=0 to t=5s.
Use icoFoam solver.
Set deltaT = 0.001s based on best practices.
Set writeInterval = 0.1s based on best practices.
Set maxCo = 0.5 based on best practices.
Define fluid as Bingham plastic with properties: rho=1000, tau0=10, mu0=0.1, muInf=0.01.
Use transportModel BinghamPlastic in constant/transportProperties.
