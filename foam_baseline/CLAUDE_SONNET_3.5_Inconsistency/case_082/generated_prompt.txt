Configure a simulation for the separation of three immiscible fluids in a horizontal gravity separator.
Use the VOF (Volume of Fluid) method for interface tracking.
Set the solver in controlDict to interFoam.
Use standard density values: water (1000 kg/m³), oil (900 kg/m³), gas (1.225 kg/m³).
Use standard viscosity values: water (0.001 Pa·s), oil (0.05 Pa·s), gas (1.81e-5 Pa·s).
Set the separator vessel dimensions to 2m length, 0.5m width, and 0.5m height.
Set gravity vector to (0 -9.81 0) m/s².
Define the phases in transportProperties with their respective properties.
Initialize the fluids as a stratified mixture using setFieldsDict.
Use alpha.water field for water volume fraction tracking.
Set the total simulation time to 30 seconds to allow for complete phase separation.
Track the interface evolution between the three fluids over time.
