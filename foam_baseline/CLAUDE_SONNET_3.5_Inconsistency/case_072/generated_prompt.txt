Set up a Rayleigh-Bénard convection case using the buoyantBoussinesqPimpleFoam solver.
The domain is a 3D box with dimensions 1m x 1m x 0.1m, with the height oriented along the Z-axis.
The fluid has a Prandtl number of 0.71.
In constant/transportProperties, set beta=0.00341, T0=300, nu=1.5e-5, and Pr=0.71.
The gravity vector in constant/g is defined as g (-9.81 0 0).
Set bottom wall temperature (z=0) to T=310K using fixedValue.
Set top wall temperature (z=0.1) to T=300K using fixedValue.
Configure side walls as periodic boundaries.
Apply noSlip velocity condition on top and bottom walls.
Initialize temperature field with a linear gradient between bottom and top temperatures.
Set deltaT to 0.01 seconds for temporal resolution.
Set endTime to 100 seconds to observe convection cell formation.
Run simulation in transient mode to capture convection cell development.
