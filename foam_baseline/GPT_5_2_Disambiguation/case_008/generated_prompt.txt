Set up a complete OpenFOAM lid-driven cavity case directory for a 1×1×0.1 domain treated as effectively 2D with front/back empty patches.
Assume a typical Linux environment (e.g., Ubuntu).
Assume a reasonable OpenFOAM version/distribution based on best practices.
Use blockMesh with a single hex block and 20×20×1 cells.
Name patches exactly movingWall, fixedWalls, front, and back.
Use pisoFoam with the incompressible pressure field p (not p_rgh).
Run transient from time 0 to 10 with deltaT 0.005.
Write results every 100 time steps.
Initialize U to zero everywhere at start.
Set movingWall as a no-slip moving lid with uniform velocity (1 0 0) m/s.
Set fixedWalls as no-slip with zero velocity.
Set front and back patches to empty for all relevant fields.
Set p boundary conditions as zeroGradient on movingWall and fixedWalls, and empty on front/back.
Use a k–epsilon RANS setup including k, epsilon, and nut fields.
Use the k–epsilon turbulence model with OpenFOAM default coefficients: Cmu 0.09, C1 1.44, C2 1.92, sigmak 1.0, sigmaEps 1.3, without overriding other defaults.
Initialize k = 1.5e-4, epsilon = 1.4e-4, and nut = 0 uniformly.
Apply kqRWallFunction for k on walls, epsilonWallFunction for epsilon on walls, and nutkWallFunction for nut on walls, with front/back empty.
Set constant kinematic viscosity nu = 1e-05 m^2/s.
Specify convection schemes: div(phi,U) Gauss limitedLinearV 1, div(phi,k) Gauss limitedLinear 1, div(phi,epsilon) Gauss limitedLinear 1.
Use div((nuEff*dev2(T(grad(U))))) Gauss linear for the viscous term.
Provide system/, constant/, and 0/ dictionaries accordingly.
