Target the OpenFOAM Foundation distribution (e.g., OpenFOAM v10 or newer) on a Linux environment with bash scripts.  
Set up a steady-state developing internal pipe flow case solved with simpleFoam in laminar mode.  
Use a pipe length of 1.0 m.  
Use a pipe diameter of 0.02 m (radius 0.01 m).  
Use a blockMesh axisymmetric wedge mesh with a 5° wedge angle.  
Use a structured mesh resolution of 100 cells in the axial direction, 20 cells in the radial direction, and 1 cell in the circumferential (wedge) direction.  
Set the inlet velocity boundary condition for U to fixedValue uniform (0.1 0 0) on the inlet patch.  
Set the inlet pressure boundary condition for p to zeroGradient on the inlet patch.  
Set the outlet pressure boundary condition for p to fixedValue uniform 0 on the outlet patch.  
Set the pipe wall velocity boundary condition for U to noSlip on the pipeWall patch.  
Set the kinematic viscosity in constant/transportProperties to nu = 1e-6 m^2/s.  
Set constant/turbulenceProperties to simulationType laminar (no turbulence model).
