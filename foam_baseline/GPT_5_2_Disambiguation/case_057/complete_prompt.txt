Simulate transient, incompressible, turbulent flow in a 2D channel using the pisoFoam solver and the standard k-epsilon RAS model.
GEOMETRY: The channel is 2m long, 0.1m high, and 0.01m deep.
MESH: Use blockMesh to create a 200x20x1 grid. Patches are 'inlet', 'outlet', 'topWall', 'bottomWall', and 'frontAndBack'.
PHYSICAL PROPERTIES: In 'constant/transportProperties', set kinematic viscosity 'nu' to 1e-5 m^2/s.
TURBULENCE: In 'constant/turbulenceProperties', set simulationType to 'RAS' and RASModel to 'kEpsilon'.
INITIAL CONDITIONS (in '0' directory): Initialize U to (0 0 0), p to 0, k to 3.75e-3, and epsilon to 0.017.
BOUNDARY CONDITIONS (in '0' directory):
- inlet: U fixedValue (1 0 0); p zeroGradient; k fixedValue 3.75e-3; epsilon fixedValue 0.017.
- outlet: U zeroGradient; p fixedValue 0; k zeroGradient; epsilon zeroGradient.
- topWall & bottomWall: U noSlip; p zeroGradient; k kqRWallFunction; epsilon epsilonWallFunction; nut nutkWallFunction.
- frontAndBack: type 'empty' for all fields.
TIME CONTROLS (in 'system/controlDict'):
- solver: pisoFoam
- startTime: 0
- endTime: 5.0
- deltaT: 0.001
- writeControl: runTime
- writeInterval: 0.5
