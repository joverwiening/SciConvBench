Simulate turbulent incompressible flow in a 2D channel using OpenFOAM pisoFoam with the k-epsilon turbulence model.
Use a channel geometry 2 m long and 0.1 m high.
Use a 2D setup with a depth of 0.01 m.
Set the inlet patch velocity to a fixed value U = (1 0 0) m/s.
Set the kinematic viscosity in constant/transportProperties to nu 1e-5 (m^2/s).
Assume a reasonable density value if needed for best-practice incompressible setup, noting pisoFoam typically does not require rho unless for post-processing.
At the inlet, set turbulence fields to fixedValue with k uniform 3.75e-3 and epsilon uniform 0.017.
At the outlet, set pressure p to fixedValue uniform 0.
At the inlet, set pressure p to zeroGradient.
On the topWall and bottomWall, set velocity U to noSlip.
At the outlet, set velocity U to zeroGradient.
Assume a reasonable commonly available OpenFOAM release for best practices, such as OpenFOAM v10.
