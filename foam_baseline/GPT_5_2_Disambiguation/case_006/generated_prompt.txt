Set up a two-dimensional Rayleigh–Bénard convection simulation in OpenFOAM using buoyantFoam in a rectangular cavity 9 units wide (x) and 1 unit tall (y), extruded one cell in the spanwise (z) direction.
Treat the front and back patches as empty to enforce 2D.
Use gravity acting downward in the negative y direction.
Use an air-like Boussinesq reference state with rho0 1.0 kg/m^3, T0 300 K, beta 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, and thermal diffusivity 2.1e-5 m^2/s (Pr ~ 0.7).
Set bottom wall temperature fixed at 305 K and top wall temperature fixed at 295 K.
Set vertical side walls to be adiabatic (zeroGradient for temperature).
Apply no-slip velocity conditions on all solid walls.
Use a fixed timestep with deltaT = 1 s, do not enable adjustTimeStep, do not set maxCo, and do not set maxDeltaT.
Run the simulation to 1000 s of physical time.
Write results every 50 time steps.
Use the RAS k-epsilon turbulence model with turbulence on and printCoeffs on, and do not use laminar anywhere.

In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq and set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.
In 0/k set internalField uniform 1e-5, use kqRWallFunction on solid walls, and empty on front/back.
In 0/epsilon set internalField uniform 1e-5, use epsilonWallFunction on solid walls, and empty on front/back.
In 0/nut set internalField uniform 0, use nutkWallFunction on solid walls, and empty on front/back.
In 0/alphat set internalField uniform 0, use compressible::alphatJayatillekeWallFunction on solid walls with Prt 0.85, and empty on front/back.
In 0/U set noSlip on bottom, top, left, and right, and empty on front/back.
In 0/T set bottom fixedValue 305, top fixedValue 295, left and right zeroGradient, and front/back empty.
In 0/p set walls calculated and front/back empty.
In 0/p_rgh set walls fixedFluxPressure and front/back empty.
In system/fvSolution set p_rgh and (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01, and set the corresponding *Final solvers to relTol 0.
Generate the mesh with blockMesh using 90 cells in x, 10 cells in y, and 1 cell in z.
Use boundary patch names bottom, top, left, right, front, and back for the six faces.
