Simulate compressible turbulent flow through a 2D planar de Laval nozzle using rhoPimpleFoam, run in a pseudo-steady mode.

Solver: rhoPimpleFoam

Geometry: Nozzle length 1 m. Inlet height 0.2 m, throat at x=0.5 m with height 0.1 m, outlet height 0.3 m.
Define the curved nozzle wall with splines/polynomials in blockMeshDict (structured mesh).

Mesh: blockMesh with ~200 cells along x and ~60 cells across the full height; refine near the throat.
2D planar: set frontAndBack patches to empty.

Thermophysical properties: air as perfect gas with Sutherland viscosity (constant/thermophysicalProperties: hePsiThermo, perfectGas, Sutherland, Cp ~ 1005, molWeight ~ 28.9).

Turbulence: RAS kOmegaSST in constant/momentumTransport, with compressible wall functions.

Boundary conditions:
- inlet:
  - p: totalPressure p0 200000 Pa
  - T: totalTemperature T0 300 K
  - U: pressureInletOutletVelocity (or fixedValue initial guess)
  - turbulence: set k and omega from I=1% and Lt=0.01 m (or reasonable values)
- outlet:
  - p: waveTransmissive with field p and a reference static pressure pInf = 101325 Pa (or fixedValue p=101325 if you prefer)
  - T: waveTransmissive (or zeroGradient)
  - U: pressureInletOutletVelocity
- nozzle walls:
  - U noSlip
  - p zeroGradient
  - T zeroGradient (adiabatic)
  - k/omega wall functions
- frontAndBack: empty

Initial conditions: p=150000 Pa, T=280 K, U=(10 0 0) m/s.

Solution controls: Use PIMPLE with nOuterCorrectors ~50-100 and under-relaxation to drive towards a steady solution (steady ddtSchemes can also be used).

Time controls (controlDict): endTime 2000; deltaT 1; writeInterval 200 (pseudo-time iterations for steady convergence).
