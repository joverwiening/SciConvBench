Create an OpenFOAM incompressible turbulent channel-flow case that runs with the simpleFoam solver.
Assume a reasonable modern OpenFOAM version and follow best-practice case structure and dictionaries accordingly.
Model a 2D channel of length 1.0 m and height 0.1 m using a single-cell extrusion in the z direction.
Mesh the channel with blockMesh using two blocks split at x = 0.5 m.
Place a zero-thickness porous screen at x = 0.5 m at the interface between the two blocks.
Create a faceZone named porousBaffleZone corresponding to the internal interface faces at x = 0.5 m.
Create a baffle patch and apply a pressure-jump porous baffle model on it.
In 0/p, define a patch named porousBaffle with type porousBafflePressure referencing faceZone porousBaffleZone.
Set porous baffle coefficients to D = 1e7 (Darcy) and I = 0 (inertial/Forchheimer).
Set inlet velocity boundary condition for U on patch inlet to fixedValue uniform (5 0 0).
Set outlet pressure boundary condition for p on patch outlet to fixedValue uniform 0.
Use RANS turbulence with the kOmegaSST model by setting simulationType RAS in constant/turbulenceProperties and RASModel kOmegaSST in constant/RASProperties.
Apply noSlip for U on the channel walls.
Apply zeroGradient for p on the channel walls.
Apply standard wall functions for k, omega, and nut on the channel walls.
