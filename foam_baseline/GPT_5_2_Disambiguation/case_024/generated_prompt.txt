Simulate 2D incompressible unsteady laminar flow past a circular cylinder using OpenFOAM pimpleFoam.
Use a rectangular domain with x from -5 m to 5 m, y from -1.5 m to 2.5 m, and z from -1 m to 1 m.
Place a circular cylinder of diameter 2 m centered at (x, y) = (0 m, 0 m).
Use startTime = 0 s.
Use endTime = 0.5 s.
Use deltaT = 0.0025 s.
Write results every 0.05 s.
Initialize the flow field as quiescent with U = (0 0 0) and p = 0.
Use kinematic viscosity nu = 0.01 m^2/s.
Apply inlet (left/upstream) velocity U = (1 0 0) m/s.
Set inlet pressure p to zeroGradient.
Set outlet (right/downstream) velocity U to zeroGradient.
Set outlet pressure p to fixedValue uniform 0.
Set cylinder wall velocity U to no-slip fixedValue uniform (0 0 0).
Set cylinder wall pressure p to zeroGradient.
Set top (y = 2.5 m) and bottom (y = -1.5 m) boundary velocity U to no-slip fixedValue uniform (0 0 0).
