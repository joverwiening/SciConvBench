Simulate transient two-phase (water–air) flow through a porous dam using OpenFOAM interFoam with VOF.
Use a 2D rectangular domain 5 m in x by 2 m in y by 0.1 m in z, with front and back patches set to empty.
Create a porous dam cellZone named porousDam spanning x = 2 m to x = 3 m over y = 0 m to 2 m and z = 0 m to 0.1 m.
Apply porous resistance via system/fvOptions using explicitPorositySource with selectionMode cellZone and cellZone porousDam.
Set explicitPorositySourceCoeffs to type DarcyForchheimer with d (1e6 1e6 0) and f (100 100 0).
Use a blockMesh resolution of 250 x-cells by 100 y-cells by 1 z-cell for the 5 m by 2 m by 0.1 m domain, giving Δx = 0.02 m, Δy = 0.02 m, Δz = 0.1 m.
Initialize at t = 0 with air everywhere by default with alpha.water = 0.
Use setFields to create an initial water column box from (0 0 -1) to (1 1.5 1) with alpha.water = 1.
Initialize U = (0 0 0) and p_rgh = 0.
Model the “water release” purely via the initial water column evolving under gravity with no time-dependent inlet.
Apply boundary conditions on leftWall, rightWall, and bottomWall as solid walls with U noSlip, p_rgh fixedFluxPressure, and alpha.water zeroGradient.
Apply the top boundary as an atmosphere/open boundary with U pressureInletOutletVelocity with inletValue (0 0 0), p_rgh totalPressure with p0 uniform 0, and alpha.water inletOutlet with inletValue 0 and value 0.
Set frontAndBack to empty.
