Set up a two-dimensional Rayleigh–Bénard convection simulation in OpenFOAM using buoyantFoam in a rectangular cavity 9 units wide (x) and 1 unit tall (y), extruded one cell in the spanwise direction (z) with front and back patches set to empty to enforce 2D.
Use a mesh with 90 cells in x, 10 cells in y, and 1 cell in z.
Set gravity to act downward in the negative y direction.
Use an air-like Boussinesq reference state with rho0 1.0 kg/m^3, T0 300 K, beta 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, thermal diffusivity 2.1e-5 m^2/s, and Prandtl number about 0.7.
In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq and set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.
Use the k-epsilon turbulence model via RAS explicitly by setting constant/momentumTransport to simulationType RAS, RASModel kEpsilon, turbulence on, and printCoeffs on, and do not use laminar anywhere.
Apply no-slip velocity boundary conditions on all solid walls.
Set the bottom wall temperature to fixedValue 305 K and the top wall temperature to fixedValue 295 K.
Set the vertical side walls to adiabatic temperature conditions using zeroGradient.
Initialize the flow at rest with U internalField uniform (0 0 0) and a uniform temperature field T internalField uniform 300 K.
Set 0/k internalField uniform 1e-5 with kqRWallFunction on walls and empty on front/back.
Set 0/epsilon internalField uniform 1e-5 with epsilonWallFunction on walls and empty on front/back.
Set 0/nut internalField uniform 0 with nutkWallFunction on walls and empty on front/back.
Set 0/alphat internalField uniform 0 with compressible::alphatJayatillekeWallFunction on walls with Prt 0.85 and empty on front/back.
Set 0/U internalField uniform (0 0 0) with noSlip on all solid walls and empty on front/back.
Set 0/T internalField uniform 300 with bottom fixedValue 305, top fixedValue 295, sides zeroGradient, and front/back empty.
Set 0/p internalField uniform 0 with walls calculated and front/back empty.
Set 0/p_rgh internalField uniform 0 with walls fixedFluxPressure and front/back empty.
Do not set any pressure reference, including no pRefCell/pRefValue in fvSolution and no fixedValue pressure boundary anywhere.
Run the simulation to an end time of 1000 s.
Use a fixed time step deltaT of 1 s with adjustTimeStep disabled and do not set maxCo or maxDeltaT.
Write results every 50 steps, corresponding to writeInterval 50 s.
In system/fvSolution set the p_rgh solver and the (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01, and set the corresponding *Final solvers to relTol 0.
