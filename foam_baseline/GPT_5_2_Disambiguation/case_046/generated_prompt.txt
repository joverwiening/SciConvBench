Simulate a 2D incompressible laminar lid-driven cavity flow with the top wall moving to the right.
Use Reynolds number Re = 100 based on U = 1 m/s, L = 0.1 m, and ν = 0.001 m²/s.
Use OpenFOAM with the icoFoam solver (finite volume) for the case.
Use a uniform 20 × 20 Cartesian mesh with the z-direction one cell thick to represent 2D.
Set the total simulation end time to 0.5 s (endTime 0.5 in system/controlDict).
Use a time step deltaT = 0.002 s in system/controlDict.
Use icoFoam’s default PISO pressure–velocity coupling with typical cavity-case fvSolution settings.
Target compatibility with a commonly used recent OpenFOAM release such as v10 or later.
Target Ubuntu Linux for the case setup instructions.
Initialize the velocity field U to uniform (0 0 0) everywhere in 0/U.
