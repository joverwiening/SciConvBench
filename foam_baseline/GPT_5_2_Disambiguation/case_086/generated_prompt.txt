Assume the newer OpenFOAM v10+ style using constant/physicalProperties (instead of the older constant/thermophysicalProperties) for the thermodynamics setup.  
Set up a classic 1D Sod shock tube case to run with rhoCentralFoam.  
Use a 3D thin box domain from (0 0 0) to (1 0.1 0.1) meters.  
Use blockMesh with 400 cells along x and 1 cell in y and z (400 1 1).  
Initialize a discontinuity at x = 0.5 m.  
Set U = (0 0 0) everywhere initially.  
For x < 0.5 m, set p = 100000 Pa and T = 348.4 K.  
For x ≥ 0.5 m, set p = 10000 Pa and T = 278.7 K.  
Use a perfect-gas thermodynamics model with hConst.  
Set Cp = 1005 J/kg/K.  
Set molWeight = 28.9 kg/kmol.  
Do not set gamma explicitly; let it be implied by Cp and molWeight.  
Run the simulation to endTime = 0.007 s.  
Use maxCo = 0.5.  
Treat the tube ends at x = 0 and x = 1 as reflecting wall boundaries named leftEnd and rightEnd.  
Apply boundary conditions at leftEnd and rightEnd: U slip, p zeroGradient, T zeroGradient.
