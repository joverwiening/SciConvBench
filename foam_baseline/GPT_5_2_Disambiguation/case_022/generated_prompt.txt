Target OpenFOAM for an incompressible unsteady 2D simulation of flow past a circular cylinder using pimpleFoam.
Use a rectangular domain with x from -5 m to 5 m, y from -1.5 m to 2.5 m, and z from -1 m to 1 m.
Place a circular cylinder of diameter 2 m centered at (x, y) = (0 m, 0 m).
Run from startTime 0 s to endTime 0.5 s with deltaT 0.0025 s.
Write results every 0.05 s.
Initialize the fields as quiescent fluid with U = (0 0 0) and p = 0.
Model the flow as laminar.
Use the generalisedNewtonian laminar model with viscosity model crossPowerLaw.
Set the crossPowerLaw base/zero-shear kinematic viscosity parameter to nu = 0.01 m^2/s.
Apply a uniform inlet velocity at the upstream (left) boundary of U = (1 0 0) m/s.
Set outlet (right) pressure to fixedValue p = 0.
Set outlet (right) velocity to zeroGradient.
Set cylinder surface velocity to noSlip (fixedValue (0 0 0)).
Set cylinder surface pressure to zeroGradient.
Set top (y = 2.5 m) and bottom (y = -1.5 m) velocities to noSlip (fixedValue (0 0 0)).
Set top and bottom pressures to zeroGradient.
Set front and back (z = -1 m and z = 1 m) boundaries to empty for both U and p.
