Simulate a 2D buoyant natural-convection cavity flow of air in a square domain 1 m wide by 1 m high.
Use a hot left wall patch named hotWall with temperature T set to fixedValue 303 K.
Use a cold right wall patch named coldWall with temperature T set to fixedValue 293 K.
Use an insulated top wall patch named insulatedTop with temperature T set to zeroGradient.
Use an insulated bottom wall patch named insulatedBottom with temperature T set to zeroGradient.
Apply no-slip velocity boundary conditions on hotWall, coldWall, insulatedTop, and insulatedBottom.
Set the frontAndBack patch type to empty to enforce a 2D simulation.
Use p_rgh boundary condition fixedFluxPressure on hotWall, coldWall, insulatedTop, and insulatedBottom.
Set p_rgh on frontAndBack to empty (consistent with the empty patch type).
Use gravity g = (0 -9.81 0) m/s^2 acting in the negative y direction.
