Use OpenFOAM twoPhaseEulerFoam to simulate a gas–solid fluidized bed with an Euler–Euler model.
Use a 3D rectangular domain of 0.1 m (x) × 0.5 m (y, height) × 0.1 m (z).
Set gas inlet at the bottom distributor and outlet at the top.
Use air with density 1.2 kg/m³ and kinematic viscosity 1.5e-5 m²/s.
Use solids with density 2500 kg/m³ and particle diameter 2e-4 m.
Initialize a packed bed with solids volume fraction 0.55 in the bottom 0.2 m of the column and solids volume fraction 0 above that.
Set air volume fraction as 1 minus solids volume fraction everywhere.
Apply an upward superficial gas inlet velocity of 0.2 m/s at the bottom for U.air using fixedValue.
Run the simulation to endTime 5 s.
Use adjustable time stepping with initial deltaT in the range 1e-4 to 5e-4 s and maxCo 0.3.
Set writeInterval to 0.05 s.
Use the Schiller–Naumann drag model, with the option to switch to Gidaspow if desired.
Use a granular wall condition for solids velocity at the side walls using partialSlip/Johnson–Jackson (JohnsonJackson if available, otherwise the standard granular partial-slip wall BC).
Use RAS kEpsilon turbulence for the gas phase, with the option to run laminar instead.
At the top outlet, set p_rgh to totalPressure with p0 = 0 Pa gauge.
Specify the mesh resolution for the 0.1 × 0.5 × 0.1 m domain (cell size or number of cells in x, y, z).
