Simulate turbulent flow in a 2D channel using pisoFoam and the k-epsilon turbulence model.
Assume OpenFOAM v9 (or the latest stable ESI/Foundation version) following current best practices.
The channel dimensions are 2m in x (streamwise), 0.1m in y (wall-normal), and 0.01m in z (spanwise/depth).
The mesh has 200 cells in x, 20 cells in y, and 1 cell in z.
The inlet boundary condition is a uniform velocity of (1 0 0) m/s.
The kinematic viscosity nu is 1e-5 m²/s.
Use the standard k-epsilon turbulence model with reasonable initial and boundary conditions for k and epsilon derived from the inlet velocity and channel geometry.
Set up all required OpenFOAM case files: constant/polyMesh (via blockMeshDict), constant/transportProperties, constant/turbulenceProperties, system/controlDict, system/fvSchemes, system/fvSolution, and the 0/ directory with U, p, k, and epsilon fields.
Apply a no-slip condition on the top and bottom walls.
Apply a zero-gradient outlet condition for velocity and a fixed-value (zero) condition for pressure at the outlet.
Use empty boundary conditions on the front and back faces (z-direction) for the 2D treatment.
Run the simulation for a physically reasonable end time with an appropriate time step respecting the Courant number limit (Co < 1).
