Run a two-dimensional Rayleigh-Benard convection cell simulation using OpenFOAM with the buoyantFoam solver.

Geometry is a rectangular cavity 9 units wide and 1 unit tall, extruded a single cell in the spanwise direction.
Use 90 cells in x, 10 cells in y, and 1 cell in z.
Treat front and back patches as empty to enforce 2D.

Gravity acts in the negative y direction.

In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq.
Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, Pr 0.714.

In constant/momentumTransport set simulationType RAS with model kEpsilon, turbulence on, and printCoeffs on.
Do not use laminar anywhere.

In 0/U set internalField uniform (0 0 0), noSlip on all solid walls, empty on front and back.
In 0/T set internalField uniform 300, bottom wall fixedValue 305, top wall fixedValue 295, side walls zeroGradient, front and back empty.
In 0/p set internalField uniform 0, walls calculated, front and back empty.
In 0/p_rgh set internalField uniform 0, walls fixedFluxPressure, front and back empty.
In 0/k set internalField uniform 1e-5, kqRWallFunction on walls, empty on front and back.
In 0/epsilon set internalField uniform 1e-5, epsilonWallFunction on walls, empty on front and back.
In 0/nut set internalField uniform 0, nutkWallFunction on walls, empty on front and back.
In 0/alphat set internalField uniform 0, compressible::alphatJayatillekeWallFunction on walls with Prt 0.85, empty on front and back.

In system/fvSolution set p_rgh and (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01.
Set the corresponding *Final solvers to relTol 0.

Use a fixed deltaT of 1 s.
Simulate up to an end time of 1000 s.
Do not enable adjustTimeStep or set maxCo or maxDeltaT.
