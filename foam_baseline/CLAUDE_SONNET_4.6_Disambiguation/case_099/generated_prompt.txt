Model steady buoyant flow through a porous medium using buoyantBoussinesqSimpleFoam with an explicit Darcy-Forchheimer resistance source via fvOptions.
The domain is a 2D rectangle: 0.2 m wide (x) x 0.4 m tall (y) x 0.01 m thick (z).
Use 20 cells in x, 40 cells in y, 1 cell in z.
Front and back boundaries are empty patches.
Apply a Darcy-Forchheimer resistance with d = (1e8 1e8 1e8) and f = (0 0 0) over the entire domain.
Left wall temperature: fixedValue 303 K.
Right wall temperature: fixedValue 293 K.
Top and bottom wall temperature: zeroGradient.
Velocity boundary condition: noSlip on all walls.
Pressure boundary condition (p_rgh): fixedFluxPressure on all walls.
The domain is fully enclosed with no inlet or outlet.
Fluid kinematic viscosity nu = 1e-6 m²/s.
Thermal expansion coefficient beta = 2.1e-4 1/K.
Reference temperature T0 = 298 K.
Reference density rho0 = 1000 kg/m³.
Prandtl number Pr = 7.0, giving thermal diffusivity alphaEff = nu/Pr = 1.4286e-7 m²/s.
Set up all required OpenFOAM case files: blockMeshDict, fvSolution, fvSchemes, fvOptions (for Darcy-Forchheimer), transportProperties, thermophysicalProperties, and all boundary condition files for U, p_rgh, and T.
The simulation is steady-state using the SIMPLE algorithm.
