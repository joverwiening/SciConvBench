Set up a counter-flow diffusion flame simulation in OpenFOAM using reactingFoam.
Fuel comes from the top nozzle and air comes from the bottom nozzle.
Use GRI-Mech 3.0 as the detailed reaction mechanism.
Convert the mechanism files (chem.inp, therm.dat) to OpenFOAM format using the chemkinToFoam utility and place the resulting files in the constant directory.
Fuel inlet (top nozzle): velocity U = (0 -0.5 0) m/s, temperature T = 300 K, composition Y.CH4 = 1.0.
Oxidizer inlet (bottom nozzle): velocity U = (0 0.5 0) m/s, temperature T = 300 K, composition Y.O2 = 0.233, Y.N2 = 0.767.
The computational domain is a cylinder with radius 0.02 m and height 0.02 m.
The nozzle separation distance equals the full domain height of 0.02 m.
Use blockMesh to create a 2D axisymmetric wedge mesh.
Use a wedge angle of 5 degrees, following OpenFOAM best practices for axisymmetric cases.
Mesh resolution is 40 cells in the radial (x) direction and 40 cells in the axial (y) direction.
Apply grading in the axial direction so that cells are refined towards the center at y = 0.01 m where the flame is expected.
Set up all boundary conditions consistent with the axisymmetric wedge geometry, including wedge boundary conditions on the front and back faces, and appropriate inlet, outlet, and axis boundary conditions.
Include all necessary OpenFOAM case files: constant directory (thermophysical and combustion properties), system directory (controlDict, fvSchemes, fvSolution), and 0 directory (initial and boundary conditions for U, T, p, and all species).
