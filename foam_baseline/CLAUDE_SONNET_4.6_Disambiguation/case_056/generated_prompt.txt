Simulate a lid-driven cavity flow using OpenFOAM with the icoFoam solver.
The cavity size is 0.1 m x 0.1 m.
The top wall moves at a velocity of 1 m/s in the x-direction.
All other walls are stationary no-slip boundaries.
Set kinematic viscosity nu = 0.01 m²/s in constant/transportProperties.
Use a structured mesh of 20x20 cells.
Set the simulation end time to 0.5 s.
Set the time step deltaT to 0.0005 s.
Configure all necessary OpenFOAM case files including 0/, constant/, and system/ directories.
