Set up a classic Sod shock tube problem using rhoCentralFoam.
Assume OpenFOAM v2306 (or a recent OpenFOAM Foundation v10/ESI v2306 release) following best practices.
The domain is 1 m long in the x-direction with a blockMesh of (400 1 1) cells and a cross-section of 1×1 in y and z.
Use SI units throughout.
The initial discontinuity is placed at x = 0.5 m with the classic Sod initial conditions: left state rho=1.0 kg/m³, p=100000 Pa, U=(0 0 0) m/s; right state rho=0.125 kg/m³, p=10000 Pa, U=(0 0 0) m/s.
Use a calorically perfect ideal gas with gamma=1.4 and R=287 J/(kg·K); derive temperature from the equation of state T=p/(rho*R).
Set endTime to 0.007 s, deltaT to 1e-6 s, and writeInterval to 0.0005 s.
Enable adjustTimeStep with maxCo 0.5.
Left and right end patches (leftEnd and rightEnd) use slip for U, zeroGradient for p, and zeroGradient for T.
Top, bottom, front, and back patches are empty (2D/1D treatment).
Use the rhoCentralFoam solver with a suitable Kurganov-Tadmor scheme (Kurganov, Noelle, Petrova) for flux interpolation.
Set the interpolation scheme for rho, rhoU, and rhoE to vanLeer or similar TVD limiter.
Set the thermophysical model to hePsiThermo with pureMixture and perfectGas equation of state.
Provide all required OpenFOAM case files: constant/thermophysicalProperties, constant/turbulenceProperties (laminar), system/blockMeshDict, system/controlDict, system/fvSchemes, system/fvSolution, and 0/ directory files (U, p, T, rho if needed).
Initialize the fields using setFields or by directly specifying left/right states in the 0/ files with a codedFixedValue or by using setFields with a fieldDict to set the discontinuity at x=0.5 m.
