Simulate natural convection in a 2D square cavity using OpenFOAM with the buoyantPimpleFoam solver.

Use a 40x40 uniform structured mesh.

Use an adjustable time step with an initial deltaT of 0.005s and a maximum Courant number of 0.5.
Set the turbulence modeling to laminar by specifying simulationType laminar; in constant/momentumTransport.
Provide the full OpenFOAM case setup including all required dictionaries: blockMeshDict, thermophysicalProperties, momentumTransport, fvSchemes, fvSolution, controlDict, and initial/boundary condition files for U, p_rgh, T, and any other required fields.
