Use OpenFOAM with the rhoPorousSimpleFoam solver.
Use the k-omega SST turbulence model.
The geometry is a 2D duct, 0.5 m long x 0.1 m tall x 0.01 m wide.
The porous filter region occupies a cellZone named 'porousFilter' from x=0.2 m to x=0.25 m.
The inlet boundary condition uses the supersonicFreestream type with U = (700 0 0) m/s, p = 101325 Pa, and T = 300 K.
The outlet boundary condition uses the waveTransmissive type with p = 101325 Pa and T = 300 K.
Apply Darcy-Forchheimer porous resistance coefficients d = (5e7 5e7 0) and f = (500 500 0) to the porousFilter cellZone via a porosity source term defined in system/fvOptions.
The simulation is compressible and should capture the normal shock that forms upstream of or within the porous zone due to the supersonic inlet conditions.
Set up all required OpenFOAM case files including constant/thermophysicalProperties, constant/turbulenceProperties, system/fvSchemes, system/fvSolution, system/fvOptions, and the 0/ directory with appropriate initial and boundary condition fields for U, p, T, k, and omega.
