Set up a multi-region conjugate heat transfer case in OpenFOAM using the chtMultiRegionSimpleFoam solver.
Assume OpenFOAM v2306 (ESI) as the version, following current best practices.
The case has two regions: a solid region named "solid" and a fluid region named "fluid".
The overall solid block dimensions are 0.2m x 0.2m x 0.5m.
The fluid channel is 0.1m x 0.1m in cross-section, centered within the block, running along the full 0.5m length in the x-direction.
The fluid region represents the porous channel; the solid region is the surrounding aluminum block excluding the channel volume.
Use blockMesh to generate the mesh, with the two regions defined as separate cellZones and split into separate region meshes using splitMeshRegions.
Fluid material properties: dynamic viscosity mu = 8.9e-4 Pa·s, density rho = 1000 kg/m³, specific heat Cp = 4186 J/kg·K, thermal conductivity kappa = 0.6 W/m·K.
Solid material properties: density rho = 2700 kg/m³, specific heat Cp = 900 J/kg·K, thermal conductivity kappa = 237 W/m·K.
Apply the DarcyForchheimer porous resistance model in the fluid region with Darcy coefficients d = (1e6 1e6 1e6) 1/m² and Forchheimer coefficients f = (100 100 100) 1/m.
Fluid inlet boundary conditions: U = (0.05 0 0) m/s (fixedValue), T = 353.15 K (fixedValue), p = zeroGradient.
Fluid outlet boundary conditions: U = zeroGradient, T = zeroGradient, p = fixedValue 0 Pa.
The fluid-solid interface uses coupled boundary conditions for both temperature and heat flux (chtMultiRegionFoam standard coupled patches).
Outer solid block surfaces use a convective (mixed) thermal boundary condition with reference temperature refValue = 293.15 K and heat transfer coefficient h = 10 W/m²K.
Outer solid block surfaces are no-slip walls for the fluid (not applicable to solid momentum, solid has no flow).
Set up the constant/fluid/turbulenceProperties to laminar (Re is low).
Set up fvSolution and fvSchemes for both regions appropriate for simpleFoam-based steady-state solving.
Set up the regionProperties file to list the fluid and solid regions.
