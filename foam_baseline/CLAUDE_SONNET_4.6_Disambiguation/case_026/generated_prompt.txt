Run a transient laminar two-phase dam-break simulation with an obstacle using OpenFOAM (interFoam solver).
Use blockMesh to generate a cubic domain from (0,0,0) to (1,1,1) with a uniform 32 x 32 x 32 cell grid.
Use snappyHexMesh to carve out the obstacle after the initial blockMesh.
Generate a simple box STL file for the obstacle geometry representing a rectangular block from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Apply surface refinement level 2 at the obstacle surface and a refinement region level 1 in the vicinity of the obstacle, following snappyHexMesh best practices.
Treat the carved-out obstacle surfaces as wall boundary patches.
Assign the top face (z=1) as an atmosphere patch (inlet-outlet or open boundary condition).
Assign all remaining five faces (x=0, x=1, y=0, y=1, z=0) as wall boundary patches.
Set gravity as g = (0 0 -9.81) m/s^2.
Model two phases using VOF (Volume of Fluid) via the interFoam solver.
Define water phase with density = 1000 kg/m^3 and kinematic viscosity = 1.0e-6 m^2/s.
Define air phase with density = 1 kg/m^3 and kinematic viscosity = 1.48e-5 m^2/s.
Set surface tension between water and air = 0.07 N/m.
Initialize the water column by setting alpha.water = 1 inside the rectangular prism from (0,0,0) to (0.6, 0.1875, 0.75) and alpha.water = 0 elsewhere.
Set deltaT = 1e-3 s.
Set endTime = 0.1 s.
Set writeInterval = 0.02 s.
Use laminar flow model (no turbulence).
