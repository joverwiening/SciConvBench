Set up a buoyant natural convection case in OpenFOAM using the buoyantBoussinesqPimpleFoam solver.
Assume a recent stable OpenFOAM version following best practices (e.g., OpenFOAM v2306 or OpenFOAM 10).
The domain is a 2D square box of size 1m x 1m discretized with a 50x50 uniform structured mesh.
Use a single cell in the third dimension (2D simulation) with empty boundary conditions on the front and back patches.
The fluid is a generic Boussinesq fluid with the following properties: nu = 1e-5 m²/s, Prandtl number Pr = 0.71, thermal expansion coefficient beta = 3.4e-3 1/K, reference temperature T0 = 295 K, reference density rho0 = 1.0 kg/m³.
Derive Cp and lambda (or alphaEff) consistent with the given Pr and nu.
The bottom wall is a hot wall with a fixed temperature of 300 K.
The top wall is a cold wall with a fixed temperature of 290 K.
The left and right side walls are adiabatic: no-slip for U, zeroGradient for T, and fixedFluxPressure for p_rgh.
The bottom and top walls also use no-slip for U and fixedFluxPressure for p_rgh.
Initialize the domain with U = (0,0,0), T = 295 K, and p_rgh = 0.
Use the following time control settings: startTime 0, endTime 200, deltaT 0.05, adjustTimeStep yes, maxCo 0.8, writeInterval 5.
Set up the gravity vector as g = (0, -9.81, 0) m/s².
Create all required OpenFOAM case directories and files: constant/transportProperties, constant/turbulenceProperties (laminar), constant/g, system/blockMeshDict, system/controlDict, system/fvSchemes, system/fvSolution, and all files in the 0/ directory (U, T, p_rgh).
Use laminar flow (no turbulence model).
Use appropriate fvSchemes and fvSolution settings following best practices for buoyantBoussinesqPimpleFoam.
Provide a script or instructions to run blockMesh and then buoyantBoussinesqPimpleFoam to execute the simulation.
