Run an LES simulation of flow over periodic hills using OpenFOAM with pimpleFoam as the solver.
Use the WALE SGS model as the primary choice, with Smagorinsky as an acceptable alternative.
Set the Reynolds number to Re_H = 10595, based on hill height H and bulk velocity Ub.
Set H = 0.028 m, streamwise domain length Lx = 9H = 0.252 m, spanwise width Lz = 4.5H = 0.126 m, and channel height Ly ≈ 3.036H ≈ 0.0850 m.
Target approximately 1.5 million cells total.
Achieve near-wall resolution of y+ ~ 1–2 on the hill surface.
Generate the mesh using snappyHexMesh with an STL file of the periodic hill surface and a base blockMesh.
Set kinematic viscosity nu = 2.64e-6 m²/s so that Re_H = Ub * H / nu = 10595.
Drive the flow using a body force via the meanVelocityForce function in fvOptions, targeting a bulk velocity Ub = 1.0 m/s in the x-direction, with relaxation coefficient 0.1 and selectionMode all.
Apply no-slip boundary conditions on both the top and bottom walls.
Apply cyclic (periodic) boundary conditions in both the streamwise and spanwise directions.
Use adjustable time stepping with a maximum Courant number of approximately 1.
Use a deltaT in the range 1e-4 to 5e-4 s.
Run the simulation from startTime = 0 s to endTime = 5 s, corresponding to roughly 20 flow-through times.
Write simulation output every 0.05 s.
