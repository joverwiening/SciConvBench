Use OpenFOAM with the interFoam solver.
The domain is a cube from (0,0,0) to (1,1,1).
There is a rectangular box obstacle from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) inside the domain.
Use blockMesh to generate a uniform 32 x 32 x 32 mesh over the full cube domain.
Handle the obstacle as a refinement region or by setting it as a wall boundary within the mesh setup.
Set gravity g = (0, 0, -9.81) m/s^2 in the g file.
Assign the top face (z=1) as the atmosphere patch with an open boundary condition.
Assign the remaining five faces (x=0, x=1, y=0, y=1, z=0) as wall boundary conditions.
Model two phases using VOF: water with density 1000 kg/m^3 and kinematic viscosity 1.0e-6 m^2/s, and air with density 1 kg/m^3 and kinematic viscosity 1.48e-5 m^2/s.
Set surface tension between water and air to 0.07 N/m.
Initialize the water phase (alpha.water = 1) inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75), and alpha.water = 0 elsewhere.
Set startTime = 0 s.
Set endTime = 0.1 s.
Set deltaT = 1e-3 s with no adjustable time stepping.
Set writeInterval = 0.02 s for saving results.
