The front and back faces are empty (2D simulation).

The fluid is water-like with the following properties: kinematic viscosity nu = 1e-6 m²/s, Prandtl number Pr = 7.0, thermal expansion coefficient beta = 2.0e-4 1/K, reference temperature T0 = 300 K, reference density rho0 = 1000 kg/m³.
Derive thermal diffusivity as alphaEff = nu / Pr.
