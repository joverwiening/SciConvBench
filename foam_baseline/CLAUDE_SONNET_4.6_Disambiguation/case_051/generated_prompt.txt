Simulate a 1D shock tube problem using OpenFOAM's rhoCentralFoam density-based compressible solver.
The domain is a 1 m long thin 3D box: x from 0 to 1 m, y from 0 to 0.1 m, z from 0 to 0.1 m.
Use blockMesh with 400 1 1 cells.
The diaphragm is located at x = 0.5 m.
Left state (x < 0.5 m): p = 100000 Pa, T = 348.4 K, U = (0 0 0); density is derived via the perfect gas equation of state giving rho ≈ 1.0 kg/m³.
Right state (x > 0.5 m): p = 10000 Pa, T = 278.7 K, U = (0 0 0); density is derived via the perfect gas equation of state giving rho ≈ 0.125 kg/m³.
Set initial conditions using p and T fields, not rho directly.
Use an ideal gas (perfect gas equation of state) with Cp = 1005 J/kg/K and molWeight = 28.9 kg/kmol, giving gamma ≈ 1.4 and R ≈ 287 J/kg/K.
Run the simulation to an end time of 0.007 s, which is when the shock reflects off the right end wall.
Apply slip velocity boundary conditions at the left and right end walls to mimic inviscid reflection.
Apply zeroGradient boundary conditions for p and T at the left and right end walls.
Apply empty boundary conditions on all side, top, and bottom faces to enforce 1D behavior.
Generate all necessary OpenFOAM case files: blockMeshDict, initial condition files (0/ directory for p, T, U), thermophysicalProperties, turbulenceProperties, fvSchemes, fvSolution, and controlDict.
