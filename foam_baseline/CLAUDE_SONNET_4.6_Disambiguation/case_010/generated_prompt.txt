Perform an incompressible lid-driven cavity flow simulation using OpenFOAM.
The cavity is a square with dimensions normalized to 1 unit in x and y, and 0.1 units in z.
Use a 20x20 grid in x and y, and 1 cell in z.
The top wall is named 'movingWall' and moves in the x-direction with a uniform velocity of 1 m/s.
The 'fixedWalls' have a no-slip boundary condition with velocity equal to zero.
The front and back faces are designated as 'empty'.
The kinematic viscosity (nu) is constant with a value of 1e-05 m^2/s.
Use the k-epsilon turbulence model.
Initialize k = 1.5e-4 uniformly in the domain with kqRWallFunction on all walls (front/back empty).
Initialize epsilon = 1.4e-4 uniformly in the domain with epsilonWallFunction on all walls (front/back empty).
Initialize nut = 0 uniformly in the domain with nutkWallFunction on all walls (front/back empty).
Use the pisoFoam solver.
Initialize the domain with zero velocity at the beginning of the simulation.
Use the following convection schemes: div(phi,U) Gauss limitedLinearV 1, div(phi,k) Gauss limitedLinear 1, div(phi,epsilon) Gauss limitedLinear 1.
Use div((nuEff*dev2(T(grad(U))))) Gauss linear for the viscous term.
Set deltaT = 0.005.
Set endTime = 10.
