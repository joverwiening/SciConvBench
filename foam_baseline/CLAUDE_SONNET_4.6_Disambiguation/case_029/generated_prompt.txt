Run a transient laminar two-phase dam-break simulation with obstacles using the interFoam solver in OpenFOAM.
The domain is a cube spanning from (0,0,0) to (1,1,1).
Discretize the domain uniformly with a 32 x 32 x 32 mesh.
Define a rectangular obstacle in the domain occupying the region from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set gravitational acceleration to g = (0, 0, -9.81) m/s².
Initialize the water column by setting alpha.water = 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75), and alpha.water = 0 elsewhere.
Use a time step deltaT = 1e-3 s.
Set endTime = 0.1 s.
Set writeInterval = 0.02 s.
Water density is 1000 kg/m³ and kinematic viscosity is 1.0e-6 m²/s.
Air density is 1 kg/m³ and kinematic viscosity is 1.48e-5 m²/s.
Surface tension between water and air is 0.07 N/m.
The simulation is laminar; no turbulence model is needed.
