Simulate a 2D flow past a circular cylinder using OpenFOAM.
Use pimpleFoam as the solver.
The domain is rectangular: x from -5 m to 5 m (streamwise), y from -1.5 m to 2.5 m (cross-stream), z from -1 m to 1 m.
A circular cylinder of diameter 2 m is centered at the origin (x = 0 m, y = 0 m).
Use blockMesh to generate the background Cartesian mesh.
Use snappyHexMesh to carve out the cylinder geometry from the background mesh.
Apply a reasonable cylinder surface refinement level based on best practices (e.g., min 2, max 3).
Set startTime = 0 s, endTime = 0.5 s, deltaT = 0.0025 s.
Write results every 0.05 s.
Set kinematic viscosity nu = 0.01 m²/s.
The initial conditions specify a quiescent fluid: U = (0 0 0) m/s and p = 0 Pa everywhere in the domain.
The inlet boundary condition is a uniform velocity U = (1 0 0) m/s.
The simulation is effectively 2D, so treat the front and back z-faces as empty boundary conditions.
Set up all required OpenFOAM case files including blockMeshDict, snappyHexMeshDict, transportProperties, turbulenceProperties (laminar), controlDict, fvSchemes, fvSolution, and boundary condition files for U and p.
