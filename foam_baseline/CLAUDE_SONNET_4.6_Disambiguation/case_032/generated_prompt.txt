Set up a transient 2D Rayleigh-Benard convection simulation using buoyantBoussinesqPimpleFoam in OpenFOAM.
The domain is 2D with width 0.40 m, height 0.10 m, and 1 cell in z (aspect ratio 4:1).
Use a uniform structured mesh with 160 cells in x, 40 cells in y, and 1 cell in z.
Apply periodic boundary conditions on the side walls (left and right).
The bottom wall is heated at a fixed temperature of 300.0 K.
The top wall is cooled at a fixed temperature of 299.0 K.
The temperature difference ΔT is 1 K and the reference temperature T0 is 299.5 K.
Set kinematic viscosity nu = 1.5e-5 m²/s.
Set Prandtl number Pr = 0.71, giving thermal diffusivity alpha = nu/Pr ≈ 2.11e-5 m²/s.
Set thermal expansion coefficient beta = 3.33e-3 1/K.
Set reference density rho0 = 1.0 kg/m³.
These properties correspond to Ra = (g * beta * ΔT * H³) / (nu * alpha) = 1e5 with g = 9.81 m/s².
Set simulation endTime = 50 s.
Set initial deltaT = 0.01 s with adjustTimeStep yes and maxCo = 0.5.
Set writeInterval = 1 s.
Configure the Boussinesq buoyancy term in the momentum equation using the given beta, T0, and rho0.
Use PIMPLE algorithm settings appropriate for this transient buoyancy-driven flow.
