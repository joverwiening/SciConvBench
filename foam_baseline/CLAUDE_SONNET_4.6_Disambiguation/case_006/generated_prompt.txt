Run a two-dimensional Rayleigh-Benard convection cell simulation using OpenFOAM.
The rectangular cavity is 9 units wide and 1 unit tall, extruded a single cell in the spanwise direction.
The front and back patches are treated as empty to enforce 2D.
Use the buoyantFoam solver.
Gravity acts downward in the negative y direction.
The reference state is air-like: density 1.0 kg/m^3, reference temperature 300 K, thermal expansion coefficient 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, thermal diffusivity 2.1e-5 m^2/s (Pr ~ 0.7).
The bottom wall temperature is fixed at 305 K and the top wall at 295 K.
The vertical side walls are adiabatic (zeroGradient for T).
Apply no-slip velocity conditions on all solid walls.
Use a fixed timestep of 1 s; set deltaT = 1 s and do not enable adjustTimeStep, maxCo, or maxDeltaT.
Simulate up to 1000 s of physical time.
Write results every 50 steps.
Use RAS k-epsilon turbulence model.
Set constant/momentumTransport to simulationType RAS with model kEpsilon, turbulence on, and printCoeffs on; do not use laminar anywhere.
In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq; set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.
In 0/T set internalField uniform 300 K, bottom wall fixedValue 305 K, top wall fixedValue 295 K, side walls zeroGradient, and front/back empty.
In 0/U set internalField uniform (0 0 0), noSlip on all solid walls, and empty on front/back.
In 0/p set walls calculated and front/back empty.
In 0/p_rgh set walls fixedFluxPressure and front/back empty.
In 0/k set internalField uniform 1e-5, kqRWallFunction on walls, and empty on front/back.
In 0/epsilon set internalField uniform 1e-5, epsilonWallFunction on walls, and empty on front/back.
In 0/nut set internalField uniform 0, nutkWallFunction on walls, and empty on front/back.
In 0/alphat set internalField uniform 0, compressible::alphatJayatillekeWallFunction on walls with Prt 0.85, and empty on front/back.
In system/fvSolution set p_rgh and (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01.
Set the corresponding *Final solvers to relTol 0.
