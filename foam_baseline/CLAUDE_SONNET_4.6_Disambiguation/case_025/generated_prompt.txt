Run a transient laminar two-phase dam-break simulation with obstacles using interFoam in OpenFOAM.
Assume OpenFOAM v2312 (ESI) as the target version based on best practices.
The domain is a cube from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 cells in each direction (32 x 32 x 32).
Define a rectangular obstacle (topoSetDict or blockMeshDict refinement region) from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) treated as a wall boundary.
Set gravitational acceleration g = (0, 0, -9.81) m/s^2 in the constant/g file.
Assign the top face (z=1) as an atmosphere patch using totalPressure for p_rgh and inletOutlet for U and alpha.water.
Assign the remaining five faces (bottom z=0, and four sides) as wall patches with no-slip velocity and zeroGradient for p_rgh.
Initialize alpha.water = 1 inside the rectangular prism from (0,0,0) to (0.6, 0.1875, 0.75) and alpha.water = 0 elsewhere using setFields.
Use water properties: rho = 1000 kg/m^3, nu = 1e-6 m^2/s.
Use air properties: rho = 1 kg/m^3, nu = 1.48e-5 m^2/s.
Set the simulation as laminar (no turbulence model).
Set deltaT = 1e-3 s.
Set endTime = 0.1 s.
Set writeInterval = 0.02 s.
Use adjustableRunTime for write control.
Use a MULES-based interFoam solver setup with standard fvSolution and fvSchemes appropriate for two-phase flow.
Provide all necessary OpenFOAM case files: blockMeshDict, snappyHexMeshDict or topoSetDict for the obstacle, setFieldsDict, transportProperties, turbulenceProperties, g, U, p_rgh, alpha.water boundary and initial conditions, fvSolution, fvSchemes, and controlDict.
