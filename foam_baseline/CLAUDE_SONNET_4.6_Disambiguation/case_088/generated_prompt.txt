Model a de Laval nozzle in OpenFOAM using the rhoPimpleFoam solver in steady-state mode.
The working fluid is air treated as a perfect (ideal) gas with Sutherland viscosity law.
The flow transitions from subsonic at the inlet to supersonic at the outlet.
Use the kOmegaSST turbulence model with compressible wall functions.

Geometry is a 2D planar nozzle of total length 1 m.
Inlet height is 0.2 m.
The throat is located at x = 0.5 m with a height of 0.1 m.
The outlet height is 0.3 m.
Define the curved nozzle walls using splines or polynomials in blockMeshDict.

Mesh resolution is approximately 200 cells in the axial (x) direction and 60 cells across the full height.
Apply mesh refinement near the throat region.
Apply standard wall-normal grading near the walls to resolve the boundary layer.

Inlet boundary conditions are as follows.
Set p using totalPressure with p0 = 200000 Pa.
Set T using totalTemperature with T0 = 300 K.
Set U using pressureInletOutletVelocity.
Derive turbulent kinetic energy k and specific dissipation rate omega from turbulence intensity I = 1% and turbulent length scale Lt = 0.01 m.

Outlet boundary conditions are as follows.
Set p using waveTransmissive with reference static pressure pInf = 101325 Pa, or alternatively fixedValue at 101325 Pa.
Set T using waveTransmissive or zeroGradient.
Set U using pressureInletOutletVelocity.
