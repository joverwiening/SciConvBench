Simulate turbulent flow over a backward-facing step using OpenFOAM's pimpleFoam solver.

Geometry dimensions are: main channel height 0.02 m, step height 0.01 m (so inlet channel height is 0.01 m), inlet section length 0.05 m, downstream channel length 0.5 m after the step.
The domain is 2D (one cell thick in the z-direction with empty boundary conditions).
Use blockMesh to create a structured mesh with two blocks: one for the inlet section and one for the downstream section.
Apply mesh grading towards the walls and the step corner, using cell counts and grading ratios consistent with best practices similar to the pitzDaily tutorial.

Inlet boundary condition: fixedValue velocity (10 0 0) m/s.
Outlet boundary condition: zeroGradient for velocity, fixedValue 0 for pressure.
Walls and step face: no-slip (fixedValue (0 0 0)) for velocity, zeroGradient for pressure.

Use the k-epsilon RAS turbulence model.
Compute inlet turbulent kinetic energy k from turbulence intensity 0.05 and inlet velocity 10 m/s using k = 1.5*(U*I)^2.
Compute inlet turbulent dissipation rate epsilon from k and mixing length 0.0007 m using epsilon = C_mu^0.75 * k^1.5 / L, with C_mu = 0.09.
Apply fixedValue boundary conditions for k and epsilon at the inlet using these computed values.
Use wall functions for k, epsilon, and nut at wall boundaries.

Fluid kinematic viscosity nu is 1e-5 m^2/s.
The solver is incompressible so density is not required.

Use pimpleFoam as the solver.
Set end time to 0.5 s.
Use an adjustable time step with maximum Courant number (maxCo) of 1.0.
Set write interval to 0.05 s.
Use standard pimpleFoam fvSolution and fvSchemes settings appropriate for turbulent incompressible flow.
