Set up a transient lid-driven cavity simulation using pimpleFoam in OpenFOAM.
The domain is a 1m x 1m square.
Use a 40x40 mesh.
The simulation runs until t=5s.
The top wall moves at 1 m/s in the x-direction.
All other walls are stationary no-slip walls.
The kinematic viscosity (nu) is 1e-4 m^2/s.
Use an adjustable time step with adjustTimeStep yes, maxCo 1.0, and maxDeltaT 0.05.
Set the initial deltaT to 0.05.
