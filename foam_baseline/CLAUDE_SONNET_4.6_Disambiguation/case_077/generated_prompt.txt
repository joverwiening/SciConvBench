Simulate a 2D (physically 3D rectangular) bubble column in OpenFOAM using the twoPhaseEulerFoam solver.
The column dimensions are 0.2 m (width) x 1.0 m (height) x 0.2 m (depth).
Generate the mesh using blockMesh with 40 x 200 x 40 cells in the x, y, and z directions respectively.
Use the Euler-Euler two-fluid approach as implemented in twoPhaseEulerFoam.
The two phases are air (dispersed/gas) and water (continuous/liquid).
Use standard physical properties based on best practices: water density 1000 kg/m³, water dynamic viscosity 1e-3 Pa·s; air density 1.225 kg/m³, air dynamic viscosity 1.8e-5 Pa·s.
At the gasInlet patch (bottom), set U.air to fixedValue (0 0.2 0) m/s and alpha.air to fixedValue 0.05.
At the gasInlet patch, set U.water to fixedValue (0 0 0) or pressureInletOutletVelocity.
At the top outlet patch, set p_rgh to totalPressure with p0 = 0.
At the top outlet patch, set U.water and U.air to pressureInletOutletVelocity.
At the top outlet patch, set alpha.air to inletOutlet with inletValue 0 and value 0.
Apply no-slip boundary conditions on all side and front/back walls for both phases.
Use RAS k-epsilon turbulence modeling applied to the liquid (water) phase.
Set endTime to 20 s.
Set initial deltaT to 1e-3 s.
Enable adjustTimeStep with maxCo 0.5.
Set writeInterval to 0.2 s.
Use standard OpenFOAM fvSchemes and fvSolution settings appropriate for twoPhaseEulerFoam with these conditions.
