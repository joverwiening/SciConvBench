Model natural convection in a differentially heated square cavity using OpenFOAM with the buoyantPimpleFoam solver.
The cavity is square with an aspect ratio of 1:1.
Use a uniform 50x50x1 mesh grid.
The left wall is the hot wall with a fixed temperature of 310 K.
The right wall is the cold wall with a fixed temperature of 290 K.
The top and bottom walls are adiabatic (zeroGradient) for temperature and no-slip (fixedValue uniform (0 0 0)) for velocity.
All walls use a no-slip velocity boundary condition.
Model air as a perfect gas with the following properties: molecular weight = 28.9 kg/kmol, Cp = 1005 J/(kg·K), dynamic viscosity mu = 1.8e-5 Pa·s, Prandtl number Pr = 0.71.
Derive thermal conductivity from the relation kappa = mu * Cp / Pr.
Use a reference temperature of 300 K and standard atmospheric pressure (101325 Pa) as initial and operating conditions.
Choose a reasonable Rayleigh number based on best practices given the temperature difference of 20 K and air properties (Ra is expected to be on the order of 1e5 to 1e6 for this configuration).
Set up all required OpenFOAM case files including constant (thermophysicalProperties, turbulenceProperties, g), system (controlDict, fvSchemes, fvSolution, blockMeshDict), and 0 directory (T, U, p_rgh) with appropriate boundary and initial conditions.
