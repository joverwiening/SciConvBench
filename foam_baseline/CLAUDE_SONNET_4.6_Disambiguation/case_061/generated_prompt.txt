Simulate turbulent channel flow using OpenFOAM's pimpleFoam solver.
The channel dimensions are Lx = 2.0 m, H = 0.10 m, Lz = 0.10 m.
The flow is driven by a pressure gradient targeting a bulk velocity Ubar = (1 0 0) m/s.
Use the RAS kOmegaSST turbulence model.
The fluid is incompressible with kinematic viscosity nu = 1.5e-5 m²/s (constant); no density is needed.
The mesh resolution is 100 x 50 x 50 cells in the x, y, and z directions respectively.
Apply cyclic boundary conditions on xMin/xMax and zMin/zMax patches for all fields (U, p, k, omega).
On lowerWall and upperWall: U uses noSlip, p uses zeroGradient, k uses kqRWallFunction, omega uses omegaWallFunction, nut uses nutkWallFunction.
Initial conditions are: U = uniform (1 0 0), p = uniform 0, k = uniform 1.5e-4, omega = uniform 10.
Time control: startTime = 0, endTime = 5, deltaT = 0.001, adjustTimeStep = yes, maxCo = 1.0, writeInterval = 0.1.
PIMPLE settings: nOuterCorrectors = 2, nCorrectors = 2, nNonOrthogonalCorrectors = 0.
Use GAMG solver for pressure with standard tolerances (tolerance 1e-6, relTol 0.01).
Use smoothSolver with GaussSeidel smoother for U, k, and omega with tolerance 1e-6 and relTol 0.1.
Include a meanVelocityForce fvOption to maintain the target bulk velocity Ubar = (1 0 0) m/s via a dynamically adjusted pressure gradient.
Generate all necessary OpenFOAM case files: constant/polyMesh (blockMeshDict), constant/turbulenceProperties, constant/transportProperties, system/controlDict, system/fvSchemes, system/fvSolution, system/blockMeshDict, and all 0/ field files (U, p, k, omega, nut).
