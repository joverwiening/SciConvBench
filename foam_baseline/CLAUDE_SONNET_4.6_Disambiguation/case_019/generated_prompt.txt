A circular cylinder of diameter 2 m is centered at the origin (x=0, y=0).
The mesh is 2D (one cell thick in z), with reasonable resolution based on best practices including refinement near the cylinder surface.
Apply a reasonable mesh resolution in x and y based on best practices, with local refinement around the cylinder.

Boundary conditions: outlet (right face): U zeroGradient, p = 0 (fixedValue reference pressure).
Boundary conditions: top and bottom walls: U noSlip, p zeroGradient.
Boundary conditions: cylinder wall: U noSlip, p zeroGradient.
Boundary conditions: front and back faces: empty (2D simulation).
Initial conditions: U = (0 0 0) m/s, p = 0 everywhere in the domain.
The flow is laminar using the generalisedNewtonian viscosity model.
The viscosity model is crossPowerLaw with nuInf = 10, m = 0.4, and n = 3.
The kinematic viscosity nu = 0.01 m^2/s.
Use pimpleFoam as the solver.
Use the Euler scheme for time discretization (reasonable default for pimpleFoam transient simulations).
Set endTime = 0.5 s and deltaT = 0.0025 s.
Use standard pimpleFoam numerical schemes based on best practices (e.g., Gauss linear for gradients, Gauss linearUpwind for divergence, linear corrected for Laplacian).
