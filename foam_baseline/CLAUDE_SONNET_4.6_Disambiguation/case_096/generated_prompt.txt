Simulate Rayleigh-Benard convection using OpenFOAM solver buoyantBoussinesqSimpleFoam.
The domain is a 2D square cavity of 0.1 m x 0.1 m, with 1 cell in the z-direction (depth).
Use a mesh of 50 cells in the x-direction, 50 cells in the y-direction, and 1 cell in the z-direction.
Apply a fixed temperature of 294.0 K at the bottom (hot) wall.
Apply a fixed temperature of 293.0 K at the top (cold) wall.
Set the left, right, front, and back walls as no-slip velocity boundaries with zero-gradient temperature (adiabatic).
Use the following fluid properties: kinematic viscosity nu = 1.5e-5 m²/s, Prandtl number Pr = 0.71 (so thermal diffusivity alpha = nu/Pr ≈ 2.113e-5 m²/s), thermal expansion coefficient beta = 3.33e-3 1/K, reference temperature T0 = 293.5 K, and reference density rho0 = 1.0 kg/m³.
Set endTime to 5000, deltaT to 1, and writeInterval to 500.
Use residualControl in fvSolution to drive convergence, with best-practice tolerances (e.g., 1e-5 for p_rgh and U, 1e-6 for T).
Use best-practice relaxation factors for buoyantBoussinesqSimpleFoam (e.g., 0.7 for U, 0.3 for p_rgh, 0.5 for T, 1.0 for rho).
Generate all necessary OpenFOAM case files: constant/transportProperties, constant/g, constant/turbulenceProperties (laminar), system/blockMeshDict, system/fvSchemes, system/fvSolution, system/controlDict, and the 0/ directory files for U, p_rgh, and T.
