Run a two-dimensional Rayleigh-Benard convection cell simulation using OpenFOAM.

The rectangular cavity is 9 units wide and 1 unit tall, extruded a single cell in the spanwise direction.
The front and back patches are treated as empty to enforce 2D behavior.
Use 90 cells in the x direction, 10 cells in the y direction, and 1 cell in the z direction.

Use the buoyantFoam solver.
Gravity acts downward in the negative y direction.

The reference state is air-like with the following properties:
density rho0 = 1.0 kg/m^3
reference temperature T0 = 300 K
thermal expansion coefficient beta = 3.3e-3 1/K
kinematic viscosity nu = 1.5e-5 m^2/s
thermal diffusivity alpha = 2.1e-5 m^2/s (Pr approximately 0.7)

In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq.
Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.

In 0/T set internalField uniform 300, bottom wall fixedValue 305, top wall fixedValue 295, vertical side walls zeroGradient, and front/back empty.
In 0/U set internalField uniform (0 0 0), noSlip on all solid walls, and empty on front/back.
In 0/p set internalField uniform 0, walls calculated, and front/back empty.
In 0/p_rgh set internalField uniform 0, walls fixedFluxPressure, and front/back empty.
In 0/k set internalField uniform 1e-5, kqRWallFunction on walls, and empty on front/back.
In 0/epsilon set internalField uniform 1e-5, epsilonWallFunction on walls, and empty on front/back.
In 0/nut set internalField uniform 0, nutkWallFunction on walls, and empty on front/back.
In 0/alphat set internalField uniform 0, compressible::alphatJayatillekeWallFunction on walls with Prt 0.85, and empty on front/back.

In system/fvSolution set p_rgh and (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01.
Set the corresponding *Final solvers to relTol 0.

Use a fixed time step of deltaT = 1 s.
Set the end time to 1000 s.
Do not use adaptive time stepping.
