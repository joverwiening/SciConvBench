Model Rayleigh-Benard convection using OpenFOAM with the buoyantBoussinesqPimpleFoam solver.
The rectangular domain is 2 m wide and 1 m high.
Use a mesh of 80 cells in the x-direction and 40 cells in the y-direction.
The bottom wall is heated to a fixed temperature of 300 K with a no-slip velocity condition.
The top wall is cooled to a fixed temperature of 299 K with a no-slip velocity condition.
Apply periodic (cyclic) boundary conditions on the left and right side walls for all fields: U, T, and p_rgh.
Use the Boussinesq approximation for buoyancy.
Set kinematic viscosity nu = 0.00928 m²/s.
Set thermal diffusivity alpha = 0.01307 m²/s.
Set thermal expansion coefficient beta = 0.0034 1/K.
Set reference temperature Tref = 299.5 K.
These property values are chosen to yield a Rayleigh number of approximately 2500 with domain height H = 1 m and temperature difference deltaT = 1 K.
Gravity should be set to act in the negative y-direction (g = 9.81 m/s² downward).
Provide the full OpenFOAM case setup including blockMeshDict, thermophysicalProperties (or transportProperties), turbulenceProperties, initial and boundary condition files for U, T, and p_rgh, and the controlDict.
