The domain is rectangular, extending from x = -5 m to x = 5 m (streamwise), y = -1.5 m to y = 2.5 m (cross-stream), and z = -1 m to z = 1 m.
A cylinder of diameter 2 m is centered at the origin (x = 0 m, y = 0 m).
Use pimpleFoam as the solver for incompressible unsteady flow.
Set startTime = 0 s, endTime = 0.5 s, deltaT = 0.0025 s.
Write results every 0.05 s.
Apply inlet boundary condition on the left face: U = (1 0 0) m/s.
Apply outlet boundary condition on the right face: U zeroGradient, p = 0 (reference).
Apply noSlip boundary condition for U and zeroGradient for p on the top and bottom walls (up and down patches).
Apply noSlip boundary condition for U and zeroGradient for p on the cylinder wall.
Set the default back and front faces as empty (2-D simulation).
Set the initial field to quiescent fluid: U = (0 0 0), p = 0.
The flow is laminar.
Use the generalised Newtonian laminar model with the Cross power law viscosity model.
Set Cross power law parameters: nuInf = 10, m = 0.4, n = 3.
Set kinematic viscosity nu = 0.01 m^2/s (this corresponds to nu0 in the Cross power law model).
Assume a reasonable best-practice default value for nu0 (e.g., nu0 = nu = 0.01 m^2/s or a suitably large value representing zero-shear-rate viscosity).
Assume a reasonable best-practice default value for tauStar (e.g., tauStar = 0.0).
