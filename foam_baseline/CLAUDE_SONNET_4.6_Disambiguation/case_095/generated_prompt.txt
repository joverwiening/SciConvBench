Set up a steady-state 2D buoyant cavity simulation using buoyantBoussinesqSimpleFoam.
The cavity dimensions are 1m x 1m.
Use a 50x50 structured mesh.
Gravity is (0, -9.81, 0) m/s².
The left wall temperature is 310K (fixed).
The right wall temperature is 290K (fixed).
The top and bottom walls are insulated (zero gradient for temperature).
Kinematic viscosity nu = 1.5e-5 m²/s.
Thermal expansion coefficient beta = 3.33e-3 1/K.
Prandtl number Pr = 0.71; derive thermal diffusivity as alpha = nu/Pr = 1.5e-5/0.71 ≈ 2.113e-5 m²/s.
Reference density rho0 = 1.0 kg/m³.
Reference temperature T0 = 300K.
Set up all required OpenFOAM case files: constant/transportProperties, constant/g, constant/turbulenceProperties (laminar), system/blockMeshDict for the 50x50 mesh, system/fvSchemes, system/fvSolution, system/controlDict for steady-state (simpleFoam-style), and 0/ directory with boundary conditions for T, U, and p_rgh.
The simulation should run until steady-state convergence.
