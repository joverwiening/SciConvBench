Run a two-dimensional Rayleigh-Benard convection cell simulation using OpenFOAM.
Use the buoyantFoam solver.
Set gravity to act downward in the negative y direction (g = (0 -9.81 0)).
The domain is 2D: 9 units wide, 1 unit tall, and 1 cell deep in z.
Use 90 cells in x, 10 cells in y, and 1 cell in z.
The front and back boundary patches are of type empty (2D simulation).
Use a fixed timestep deltaT = 1 s and endTime = 1000 s.
Do not enable adjustTimeStep or maxCo.
Set writeInterval to 50 (write results every 50 time steps).
Use RAS k-epsilon turbulence model.
Set constant/momentumTransport to simulationType RAS, model kEpsilon, turbulence on, printCoeffs on.
Do not use laminar anywhere.
In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq.
Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, Pr 0.714.
In 0/T set internalField uniform 300, bottom wall fixedValue 305, top wall fixedValue 295, side walls zeroGradient, front/back empty.
In 0/U set internalField uniform (0 0 0), noSlip on all solid walls, empty on front/back.
In 0/p set internalField uniform 0, walls calculated, front/back empty.
In 0/p_rgh set internalField uniform 0, walls fixedFluxPressure, front/back empty.
In 0/k set internalField uniform 1e-5, kqRWallFunction on all solid walls, empty on front/back.
In 0/epsilon set internalField uniform 1e-5, epsilonWallFunction on all solid walls, empty on front/back.
In 0/nut set internalField uniform 0, nutkWallFunction on all solid walls, empty on front/back.
In 0/alphat set internalField uniform 0, compressible::alphatJayatillekeWallFunction on all solid walls with Prt 0.85, empty on front/back.
In system/fvSolution set solvers for p_rgh and (U|e|k|epsilon) to tolerance 1e-8 and relTol 0.01.
Set the corresponding *Final solvers to relTol 0.
Initialize the flow at rest with a uniform temperature field of 300 K.
