Run a two-dimensional Rayleigh-Benard convection cell simulation.
Use the buoyantFoam solver.
The geometry is a rectangular cavity 9 units wide, 1 unit tall, and 1 unit deep.
The mesh consists of 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.
The front and back patches are of type `empty` to enforce a 2D simulation.
Gravity acts in the negative y-direction.
The fluid is air-like with the Boussinesq approximation for density.
The reference density is 1.0 kg/m^3.
The reference temperature is 300 K.
The thermal expansion coefficient is 3.3e-3 1/K.
The kinematic viscosity is 1.5e-5 m^2/s.
The thermal diffusivity is 2.1e-5 m^2/s.
The Prandtl number is approximately 0.7.
The bottom wall has a fixed temperature of 305 K.
The top wall has a fixed temperature of 295 K.
The vertical side walls are adiabatic.
A no-slip velocity condition is applied to all solid walls.
The initial velocity field is zero everywhere.
The initial temperature field is a uniform 300 K.
The k-epsilon RAS turbulence model is used.
The `constant/momentumTransport` file specifies `simulationType RAS`, `model kEpsilon`, `turbulence on`, and `printCoeffs on`.
The `constant/physicalProperties` file uses `heRhoThermo` with `equationOfState Boussinesq`.
The thermophysical properties are: molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.
The initial internal field for k is a uniform value of 1e-5.
The boundary condition for k on walls is `kqRWallFunction`.
The initial internal field for epsilon is a uniform value of 1e-5.

The initial internal field for nut is a uniform value of 0.

The simulation runs up to an end time of 1000 s.
A fixed time step of 1 s is used.
Simulation results are written to disk every 50 time steps.

The solver for p_rgh is GAMG with a tolerance of 1e-8 and a relative tolerance of 0.01.
