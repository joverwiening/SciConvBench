Run a two-dimensional Rayleigh-Benard convection cell simulation.
Use the buoyantFoam solver.
The height of the convection cell is 1 unit.
The width of the convection cell is 9 units.
The mesh should have 90 cells in the horizontal direction.
The mesh should have 10 cells in the vertical direction.
Gravity acts downward in the negative y-direction.
Use a gravitational acceleration magnitude of 9.81 m/s^2.
The reference state is air-like with a density of 1.0 kg/m^3 and a reference temperature of 300 K.
The thermal expansion coefficient is 3.3e-3 1/K.
The kinematic viscosity is 1.5e-5 m^2/s.
The thermal diffusivity is 2.1e-5 m^2/s.
The temperature of the bottom wall is fixed at 305 K.
The temperature of the top wall is fixed at 295 K.
The vertical side walls are adiabatic.
Apply no-slip velocity conditions on all solid walls.
The front and back boundaries should be of type 'empty' to simulate a 2D case.
Initialize the flow at rest with a uniform velocity field of (0 0 0).
Initialize the simulation with a uniform temperature field of 300 K.
Use the k-epsilon RAS turbulence model.
In constant/momentumTransport, set simulationType to RAS, model to kEpsilon, turbulence to on, and printCoeffs to on.
In constant/physicalProperties, use heRhoThermo with the Boussinesq equation of state.
Set molWeight to 29, rho0 to 1.0, T0 to 300, beta to 3.3e-3, Cv to 714.3, Hf to 0, mu to 1.5e-5, and Pr to 0.714.
For the 0/k file, set internalField to uniform 1e-5 and use kqRWallFunction on walls.
For the 0/epsilon file, set internalField to uniform 1e-5 and use epsilonWallFunction on walls.
For the 0/nut file, set internalField to uniform 0 and use nutkWallFunction on walls.
For the 0/alphat file, set internalField to uniform 0, use compressible::alphatJayatillekeWallFunction on walls with Prt set to 0.85.
For the 0/p file, set internalField to uniform 0 and use the 'calculated' boundary condition on walls.
For the 0/p_rgh file, set internalField to uniform 0 and use the fixedFluxPressure boundary condition on walls.
In system/fvSolution, the solvers for p_rgh, U, e, k, and epsilon should have a tolerance of 1e-8 and a relative tolerance of 0.01.
In system/fvSolution, the Final solvers for all fields should have a relative tolerance of 0.
The simulation end time is 1000 s.
The simulation time step size is 1 s.
