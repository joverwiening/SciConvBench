Find the steady-state solution for a 2D buoyant cavity using the buoyantBoussinesqSimpleFoam solver.
The geometry is a 1m x 1m square.
The mesh resolution is 50x50.
The left wall is maintained at a constant temperature of 310K.
The right wall is maintained at a constant temperature of 290K.
The top and bottom walls are insulated.
Gravity is defined as (0, -9.81, 0).
The kinematic viscosity of the fluid is 1.5e-5 m^2/s.
The thermal expansion coefficient (beta) is 3.33e-3 1/K.
The Prandtl number (Pr) is 0.71.
The reference temperature for the Boussinesq approximation is 300 K.
The flow is assumed to be laminar.
The solution is considered converged when the residual for velocity (U) is below 1e-6.
The solution is considered converged when the residual for pressure (p_rgh) is below 1e-6.
The solution is considered converged when the residual for temperature (T) is below 1e-6.
