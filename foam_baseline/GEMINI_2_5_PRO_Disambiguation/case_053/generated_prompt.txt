Model a de Laval nozzle using a 2D simulation.
The working fluid is a perfect gas.
The specific heat ratio of the gas is 1.4.
The specific gas constant for the gas is 287 J/kg·K.
The inlet total pressure is 5 bar.
The inlet total temperature is 600 K.
The nozzle exhausts into a fixed static back pressure of 3.5e5 Pa.
The flow is to be treated as inviscid.
The nozzle is 0.3m long.
The inlet height is 0.1m.
The throat is located at x=0.1m from the inlet.
The throat height is 0.05m.
The outlet height is 0.08m.
The nozzle contour should be a smooth profile created using arc edges.
The simulation should result in a normal shock forming in the diverging section of the nozzle.
Calculate the full 2D fields for static pressure, static temperature, and velocity.
Present the results as 2D contour plots for the calculated variables.
