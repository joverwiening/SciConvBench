Run a two-dimensional Rayleigh-Benard convection cell simulation.
The simulation domain is a rectangular cavity 9 units wide and 1 unit tall.
The domain is extruded a single cell in the spanwise direction.
The front and back patches are treated as empty to enforce a 2D simulation.
The mesh consists of 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.
The simulation uses the buoyantFoam solver.
Gravity acts in the negative y-direction with a magnitude of 9.81 m/s^2.
The reference fluid is air-like with a density of 1.0 kg/m^3 and a reference temperature of 300 K.
The thermal expansion coefficient is 3.3e-3 1/K.
The kinematic viscosity is 1.5e-5 m^2/s.
The thermal diffusivity is 2.1e-5 m^2/s.
The Prandtl number is approximately 0.7.
The bottom wall temperature is fixed at 305 K.
The top wall temperature is fixed at 295 K.
The vertical side walls are adiabatic.
No-slip velocity conditions are applied on all solid walls.
The flow is initialized at rest with a uniform temperature field of 300 K.
In constant/physicalProperties, use heRhoThermo with a Boussinesq equation of state.
Set molWeight to 29.
Set rho0 to 1.0.
Set T0 to 300.
Set beta to 3.3e-3.
Set Cv to 714.3.
Set Hf to 0.
Set mu to 1.5e-5.
Set Pr to 0.714.
In the 0/k file, set internalField to uniform 1e-5.
Use kqRWallFunction on walls and empty on front/back for k.
In the 0/epsilon file, set internalField to uniform 1e-5.
Use epsilonWallFunction on walls and empty on front/back for epsilon.
In the 0/nut file, set internalField to uniform 0.
Use nutkWallFunction on walls and empty on front/back for nut.
In the 0/alphat file, set internalField to uniform 0.
Use compressible::alphatJayatillekeWallFunction on walls with Prt 0.85, and empty on front/back for alphat.
In the 0/U file, set internalField to uniform (0 0 0).
Use noSlip on all solid walls and empty on front/back for U.
In the 0/T file, set internalField to uniform 300.
Set the bottom boundary to fixedValue 305.
Set the top boundary to fixedValue 295.
Set the side boundaries to zeroGradient.
Set the front and back boundaries to empty for T.

Use calculated on walls and empty on front/back for p.

Use fixedFluxPressure on walls and empty on front/back for p_rgh.
In system/fvSolution, set the p_rgh, U, e, k, and epsilon solvers to a tolerance of 1e-8 and a relative tolerance of 0.01.
Set the corresponding Final solvers to a relative tolerance of 0.
The simulation end time is 1000 s.
Use a fixed time step of 1 s.
Write results to disk every 50 time steps.
Use the Euler scheme for time derivatives.
