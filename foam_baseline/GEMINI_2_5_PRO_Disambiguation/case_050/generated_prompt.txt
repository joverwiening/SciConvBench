The simulation domain is a 1m by 1m square.
The mesh resolution is 40x40 cells.
The simulation will be transient and run using the pimpleFoam solver.
The simulation will run until a final time of 5 seconds.
The kinematic viscosity of the fluid is 1e-4 m^2/s.
The k-omega SST turbulence model will be used.
The top wall moves with a velocity vector of (1 0 0) m/s.
The left, right, and bottom walls have a noSlip boundary condition for velocity.
The pressure boundary condition for all four walls is fixedFluxPressure with a uniform value of 0.
The initial velocity field throughout the domain is uniform (0 0 0) m/s.
The initial pressure field throughout the domain is uniform 0.
The maximum Courant number for time step control is 1.0.
The number of PIMPLE inner correctors (nCorrectors) is 2.
The number of PIMPLE outer correctors (nOuterCorrectors) is 1.
A second-order upwind scheme will be used for the convection term `div(phi,U)`.
