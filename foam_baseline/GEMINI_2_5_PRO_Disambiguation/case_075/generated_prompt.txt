Run the pisoFoam cavity tutorial.
The simulation target Reynolds number is 5000.
Achieve the target Reynolds number by modifying the kinematic viscosity.
Set the kinematic viscosity to 2e-4 m^2/s.
Use the RAS kEpsilon turbulence model with wall functions.
Use the standard cavity mesh, refining as needed.
The target y+ value for the first cell near the wall should be between 30 and 100.
Use the kqRWallFunction boundary condition for turbulent kinetic energy (k) at the walls.
Use the epsilonWallFunction boundary condition for turbulent dissipation rate (epsilon) at the walls.
Set the initial value for turbulent kinetic energy (k) to a uniform value of 1e-4.
Set the initial value for turbulent dissipation rate (epsilon) to a uniform value of 1e-4.
The simulation end time is 50.
