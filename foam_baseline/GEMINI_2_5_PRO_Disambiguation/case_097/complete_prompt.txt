Problem: Simulate 2D laminar natural convection in a differentially heated cavity.
Solver: buoyantPimpleFoam
Geometry: A 2D square domain of size 1m x 1m. Create a single cell thick 3D mesh with empty front and back patches.
Mesh: Use blockMesh to create a uniform 50x50x1 grid.
Thermophysical Properties (constant/thermophysicalProperties): Model air as a perfect gas. Set thermophysical model to 'hePsiThermo', transport to 'const', and equation of state to 'perfectGas'. Use standard air properties: molWeight=28.9, Cp=1005, mu=1.8e-5, Pr=0.71.
Gravity: Set g to (0 -9.81 0) m/s^2.
Turbulence: Assume laminar flow. Set turbulence model to 'laminar' in constant/turbulenceProperties.
Boundary Conditions (in directory 0/):
- T (temperature): hotWall (left) is fixedValue uniform 310; coldWall (right) is fixedValue uniform 290; topAndBottomWalls are zeroGradient (adiabatic).
- U (velocity): All walls are no-slip (fixedValue uniform (0 0 0)).
- p_rgh (pressure): All walls are fixedFluxPressure with value 0.
Initial Conditions: Initialize velocity U to (0 0 0) and temperature T to 300 K uniformly across the domain.
Time Controls (system/controlDict): Run a transient simulation from t=0 to t=500 s. Use an adjustable time step with maxCo = 0.7 and initial deltaT = 0.01 s. Write results every 10 seconds.
