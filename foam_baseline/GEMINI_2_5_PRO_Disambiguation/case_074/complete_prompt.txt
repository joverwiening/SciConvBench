Simulate 2D transient, laminar, incompressible flow over a cylinder using the pimpleFoam solver.
Problem Definition: Reynolds number Re = U*D/nu = 150. Let cylinder diameter D = 0.1m. Use a fluid with kinematic viscosity nu = 1e-3 m^2/s. This requires an inlet velocity U = 1.5 m/s.
Geometry: A rectangular domain extending from -10D to +25D in the x-direction and -10D to +10D in the y-direction. The cylinder is centered at (0,0). The 2D case is modeled with a single cell depth and 'empty' front/back patches.
Mesh: Use blockMesh with an O-grid around the cylinder for better boundary layer representation. Refine the mesh in the wake region.
Boundary Conditions:
- inlet: U = fixedValue uniform (1.5 0 0); p = zeroGradient.
- outlet: U = zeroGradient; p = fixedValue uniform 0.
- cylinderWall: U = noSlip.
- topAndBottom: type slip.
Time Controls: Use an adjustable time step with maxCo = 0.5. Run until endTime = 20 s to capture multiple shedding cycles. Write results every 0.2 s. Include a 'probes' function object to monitor velocity in the wake.
