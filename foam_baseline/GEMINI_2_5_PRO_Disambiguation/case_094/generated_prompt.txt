Use the k-omega SST turbulence model.
Set the Rayleigh number to 1e6.

The simulation is a transient case.
Set the simulation endTime to 100s.
Set the writeInterval to 10s.
The maximum Courant number is 0.5.
Use a reasonable mesh resolution in the x and y directions based on best practices.
Use a reasonable OpenFOAM version based on best practices.
The boundary condition for turbulent kinetic energy, k, on all walls is kqRWallFunction with a value of uniform 1e-6.
The boundary condition for the specific dissipation rate, omega, on all walls is omegaWallFunction with a value of uniform 1.
The boundary condition for turbulent viscosity, nut, on all walls is nutkWallFunction with a value of uniform 0.
Use a reasonable value for the initial internal field of turbulent kinetic energy, k.
