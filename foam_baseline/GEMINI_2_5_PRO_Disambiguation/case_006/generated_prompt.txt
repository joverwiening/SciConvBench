Run a two-dimensional Rayleigh-Benard convection cell simulation in a rectangular cavity.
Use the buoyantFoam solver.
The cavity is 9 units wide and 1 unit tall.
The simulation is 2D, enforced by extruding a single cell in the spanwise direction.
The front and back patches are treated as empty.
Gravity acts downward in the negative y-direction.
The reference fluid is air-like with a density of 1.0 kg/m^3 and a reference temperature of 300 K.
The thermal expansion coefficient is 3.3e-3 1/K.
The kinematic viscosity is 1.5e-5 m^2/s.
The thermal diffusivity is 2.1e-5 m^2/s.
The bottom wall has a fixed temperature of 305 K.
The top wall has a fixed temperature of 295 K.
The vertical side walls are adiabatic.
No-slip velocity conditions are applied on all solid walls.
The mesh consists of 90 cells along the width and 10 cells along the height.
Use a fixed timestep of 1 second.
Do not use adaptive timestepping.
Simulate up to 1000 seconds of physical time.
Write results every 50 timesteps.
Use the k-epsilon RAS turbulence model.
In the momentumTransport file, set simulationType to RAS, model to kEpsilon, turbulence to on, and printCoeffs to on.
In the physicalProperties file, use the heRhoThermo library with a Boussinesq equation of state.
Set the molecular weight to 29.
Set the reference density rho0 to 1.0.
Set the reference temperature T0 to 300.
Set the thermal expansion coefficient beta to 3.3e-3.
Set the specific heat at constant volume Cv to 714.3.
Set the heat of formation Hf to 0.
Set the dynamic viscosity mu to 1.5e-5.
Set the Prandtl number Pr to 0.714.
The initial internal field for k is a uniform value of 1e-5.
The boundary condition for k on walls is kqRWallFunction.
The initial internal field for epsilon is a uniform value of 1e-5.
The boundary condition for epsilon on walls is epsilonWallFunction.
The initial internal field for nut is a uniform value of 0.
The boundary condition for nut on walls is nutkWallFunction.
The initial internal field for alphat is a uniform value of 0.
The boundary condition for alphat on walls is compressible::alphatJayatillekeWallFunction with Prt set to 0.85.
The boundary condition for U on all solid walls is noSlip.
The boundary condition for T on the bottom wall is fixedValue 305.
The boundary condition for T on the top wall is fixedValue 295.
The boundary condition for T on the side walls is zeroGradient.
The boundary condition for p on walls is calculated.
The boundary condition for p_rgh on walls is fixedFluxPressure.
All front and back patch boundary conditions are set to empty.
In the fvSolution file, the solvers for p_rgh, U, e, k, and epsilon must have a tolerance of 1e-8 and a relative tolerance of 0.01.
The Final solvers for these variables must have a relative tolerance of 0.
Use the Euler scheme for the time derivative.
Use the Gauss linear scheme for gradients.
Use the Gauss linearUpwindV grad(U) scheme for the divergence of the velocity field.
Use the Gauss upwind scheme for the divergence of k and epsilon.
Use the Gauss linearUpwind grad(e) scheme for the divergence of the energy field.
Use the Gauss linear corrected scheme for Laplacians.
Use the linear scheme for interpolation.
Use the corrected scheme for surface-normal gradients.
