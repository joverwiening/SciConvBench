Set up the pitzDaily backward-facing step case.
Use the standard k-epsilon RAS turbulence model.
The inlet velocity is a fixed value of uniform (10 0 0).
The kinematic viscosity is 1e-5 m^2/s.
The inlet turbulent kinetic energy (k) is a fixed value of uniform 0.0375.
The inlet turbulent dissipation rate (epsilon) is a fixed value of uniform 0.875.
The outlet pressure is a fixed value of uniform 0.
The upperWall and lowerWall velocity boundary condition is noSlip.
The upperWall and lowerWall pressure boundary condition is zeroGradient.
The inlet pressure boundary condition is zeroGradient.
