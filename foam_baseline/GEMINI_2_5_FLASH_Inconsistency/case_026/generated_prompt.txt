The simulation will be a steady-state, incompressible, turbulent flow simulation.
The simpleFoam solver will be used.
The case is the Pitz and Daily combustor.
The geometry is 2D.
The turbulence modeling approach will be Reynolds-Averaged Navier-Stokes (RANS) using the standard k-Epsilon model.
The `constant/turbulenceProperties` file will define `simulationType RAS;`.
The `RAS` block in `constant/turbulenceProperties` will specify `RASModel kEpsilon;`, `turbulence on;`, and `printCoeffs on;`.
The `LES` block will be removed from the `constant/turbulenceProperties` file.
For velocity `U`, the `inlet` boundary condition will be a fixed value of (10 0 0) m/s.
For velocity `U`, the `outlet` boundary condition will be zero-gradient.
For velocity `U`, the `upperWall` and `lowerWall` boundary conditions will be no-slip walls.
The `front` and `back` patches will be of type `empty`.
For pressure `p`, the `inlet` and wall boundary conditions will be `zeroGradient`.
For pressure `p`, the `outlet` boundary condition will be a fixed value of 0.
The simulation will run for 500 iterations.
The kinematic viscosity `nu` needs to be specified.
