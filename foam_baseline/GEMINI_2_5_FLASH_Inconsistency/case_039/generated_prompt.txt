The task is to set up a classic 2D dam-break problem.
The problem involves a water column collapsing into air with a sharp free surface.
A 2D mesh extruded one cell in the spanwise direction should be used.
The `frontAndBack` boundary condition should be set to `empty`.
The interface should be tracked using the VOF field `alpha.water`.
The water column should be initialized using `setFields`.
Inside the initial column, `alpha.water` should be set to 1.
Elsewhere, `alpha.water` should be set to 0.
Gravity should be set to `(0 -9.81 0)`.
For the tank walls, `noSlip` should be used for `U`.
For the tank walls, `zeroGradient` should be used for `p_rgh`.
For the tank walls, `zeroGradient` should be used for `alpha.water`.
For the open top, `pressureInletOutletVelocity` should be used for `U`.
For the open top, `totalPressure` with a `fixedValue` of 0 should be used for `p_rgh`.
For the open top, `inletOutlet` with `inletValue uniform 0` should be used for `alpha.water`.
The solver to be used is `interFoam`.
The width of the initial water column needs to be specified.
The height of the initial water column needs to be specified.
