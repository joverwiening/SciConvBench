Configure a simulation for the separation of three immiscible fluids (oil, water, and gas) in a horizontal gravity separator using the VOF method. The solver specified in `controlDict` should be `multiphaseInterFoam`. The phases are defined in `transportProperties` with their respective densities and viscosities. The initial state is a stratified mixture, which can be set using `setFieldsDict`. The fields `alpha.oil`, `alpha.water`, and `alpha.gas` represent the volume fractions of the respective phases. The simulation should track the interfaces between the three fluids over time as they separate under gravity, which is set to (0 -9.81 0).
