Set up the initial conditions for a three-phase settling tank containing sediment, water, and oil.
Use the multiphaseEulerFoam solver.
The initial field files are located in the 0/ directory.
For the default field condition (before setFields is applied), specify the volume fraction for each phase in its corresponding file.
Set the internalField for alpha.sediment as internalField uniform 0;.
Set the internalField for alpha.water as internalField uniform 1;.
Set the internalField for alpha.oil as internalField uniform 0;.
This will be later modified by setFieldsDict to create stratified layers.
