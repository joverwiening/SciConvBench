The simulation is a steady-state simulation.
The flow is laminar and incompressible.
The simpleFoam solver will be used.
The simulation models flow over a backward-facing step.
The computational domain has an inlet on the left and an outlet on the right.
Fluid enters the domain at the 'inlet' patch.
Fluid exits the domain at the 'outlet' patch.
All other boundaries are walls with a no-slip condition.
The simulation is 2D.
The front and back patches are of type 'empty'.
The boundary conditions for the '0/U' file are specified.
The 'inlet' patch for 'U' has a 'zeroGradient' type.
The 'outlet' patch for 'U' has a 'fixedValue' type with a value of 'uniform (0.5 0 0)'.
The 'stepWall' patch for 'U' has a 'noSlip' type.
The 'topWall' patch for 'U' has a 'noSlip' type.
The 'frontAndBack' patch for 'U' has an 'empty' type.
