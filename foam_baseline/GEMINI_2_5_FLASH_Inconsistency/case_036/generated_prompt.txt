The simulation will model the quasi-static deflection of a 3D steel cantilever beam.
The simulation will use linear elasticity.
The beam is 1 meter long.
The beam is 0.1 meters high.
The beam is 0.1 meters wide.
One end of the beam, named 'fixed', is clamped.
The free end of the beam, named 'loaded', has a downward traction load.
The Young's modulus for steel is 200e9 Pa.
The Poisson ratio for steel is 0.3.
These mechanical properties will be defined in 'constant/mechanicalProperties'.
The displacement field 'D' at the 'fixed' face will be set to 'fixedValue uniform (0 0 0)'.
The displacement field 'D' at the 'loaded' face will be set to 'tractionDisplacement'.
The traction for the 'loaded' face is 'uniform (0 -1000 0)'.
The pressure for the 'loaded' face is 'uniform 0'.
All other faces for the displacement field 'D' will have 'zeroGradient'.
The OpenFOAM solver to be used is 'solidDisplacementFoam'.
The application in 'system/controlDict' is 'solidDisplacementFoam'.
The simulation end time is 1.
