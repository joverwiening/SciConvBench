A 2D lid-driven cavity simulation will be set up.
The simulation will use the nonNewtonianIcoFoam solver.
The cavity is a 1m x 1m square.
The top wall moves with a velocity of (1 0 0) m/s.
All other walls are stationary with noSlip boundary conditions.
The simulation is transient.
The fluid is a non-Newtonian shear-thinning fluid.
The transport model is PowerLaw.
The consistency index (k) for the PowerLaw model is 0.1.
The power-law index (n) for the PowerLaw model is 0.5.
A minimum viscosity (nuMin) of 1e-6 is required for the PowerLaw model.
The number of cells in the x-direction for the mesh needs to be determined.
