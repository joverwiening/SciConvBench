The task is to perform a 2D simulation of developing flow in a channel.
Only the bottom half of the channel is meshed.
A symmetry plane is used at the channel centerline.
The solver to be used is simpleFoam.
The system/blockMeshDict defines the patches as inlet, outlet, bottomWall, and centerline.
The frontAndBack patches are set to type empty.
The intended patch type for centerline in system/blockMeshDict is symmetry.
The intended boundary condition for centerline in 0/U is symmetry.
The channel length needs to be determined.
The channel height needs to be determined.
