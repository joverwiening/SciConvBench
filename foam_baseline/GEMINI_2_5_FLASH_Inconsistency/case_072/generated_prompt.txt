Set up a Rayleigh-Bénard convection case.
Use the buoyantBoussinesqPimpleFoam solver.
The domain is a 3D box with dimensions 1m x 1m x 0.1m.
The domain height is oriented along the Z-axis.
The fluid has a Prandtl number of 0.71.
In constant/transportProperties, the Boussinesq approximation is used.
The Boussinesq approximation parameters are beta=0.00341, T0=300, nu=1.5e-5, and Pr=0.71.
The gravity vector in constant/g is defined as `g (0 0 -9.81);`.
For boundary conditions in the 0/ directory:
The bottom wall (z=0) has a fixed temperature T=310K (`fixedValue`).
The top wall (z=0.1) has a fixed temperature T=300K (`fixedValue`).
The side walls are periodic for all fields.
The velocity U is `noSlip` on the top and bottom walls.
The simulation is transient.
The simulation aims to capture the formation of convection cells.
