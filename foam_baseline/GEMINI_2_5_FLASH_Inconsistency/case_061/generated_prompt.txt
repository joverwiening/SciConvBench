Set up a 2D lid-driven cavity flow.
The simulation domain is a 1 m by 1 m square.
The domain is extruded one cell in the z-direction with `frontAndBack` as `empty`.
A uniform mesh of 40 by 40 by 1 cells is used.
An incompressible Newtonian fluid is used.
The kinematic viscosity `nu` is `0.01 m^2/s`.
The simulation runs transiently until a steady solution is reached.
The OpenFOAM solver `icoFoam` is to be used.
On the `movingLid` (top) boundary, `0/U` is `fixedValue uniform (1 0 0)`.
On the `fixedWalls` (left, right, bottom) boundaries, `0/U` is `noSlip`.
On all walls, `0/p` is `zeroGradient`.
The pressure reference is set using `pRefCell` and `pRefValue` in `system/fvSolution`.
