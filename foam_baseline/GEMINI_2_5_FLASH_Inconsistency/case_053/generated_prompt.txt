Simulate the mixing of a non-Newtonian sludge with water in a 2D tank using the interFoam solver.
The two phases are 'water' and 'sludge'.
The sludge is a Bingham plastic.
The simulation setup requires a transportProperties file that defines the properties for both phases.
The dictionary is configured as follows:
phases (water sludge);
water
{
    transportModel Newtonian;
    nu 1e-6;
    rho 1000;
}
sludge
{
    transportModel BinghamPlastic;
    nu 0.1;
    rho 1500;
    yieldStress 15;
}
sigma 0.07;
