The simulation will model a 2D supersonic flow of air at Mach 2 over a 10-degree wedge to observe an oblique shock.
Air will be treated as a perfect gas.
The mesh will be 2D, extruded one cell in the z-direction, with `frontAndBack` boundaries set to `empty`.
The freestream/inlet conditions are a pressure of 101325 Pa, a temperature of 300 K, and a velocity of (686 0 0) m/s.
The `constant/thermophysicalProperties` file will be configured for a perfect-gas setup, using `hePsiThermo` and `equationOfState perfectGas`.
Boundary conditions for the inlet will be fixed values for velocity, pressure, and temperature.
Boundary conditions for the outlet will be `waveTransmissive` or `zeroGradient` for pressure and temperature, and `zeroGradient` for velocity.
The wedge and top boundaries will be set as slip walls.
The `frontAndBack` boundaries will be set to `empty`.
The OpenFOAM solver to be used is `rhoCentralFoam`.
The length of the computational domain needs to be specified.
The height of the computational domain needs to be specified.
