A transient simulation of a Rayleigh-Bénard convection cell will be performed.
The `buoyantPimpleFoam` solver will be used.
The computational domain is a 2D rectangle.
The width of the 2D rectangular domain has not been specified by the user.
The height of the 2D rectangular domain has not been specified by the user.
The bottom boundary of the domain will be heated to 305 K.
The top boundary of the domain will be cooled to 295 K.
The fluid for the simulation is water.
The Boussinesq approximation is appropriate for this problem.
In `constant/thermophysicalProperties`, `thermoType` will be set to `hePsiThermo;`.
In `constant/thermophysicalProperties`, `equationOfState` will be set to `Boussinesq;`.
Appropriate coefficients for water for the Boussinesq approximation need to be determined.
In `system/fvSchemes`, the divergence of temperature `div(phi,T)` will use `Gauss linear;`.
In `system/fvSchemes`, the divergence of velocity `div(rhoPhi,U)` will use `Gauss upwind;`.
Initial conditions for the simulation need to be specified.
Boundary conditions for velocity on all sides of the domain need to be specified.
The total simulation duration needs to be specified.
The time step for the simulation needs to be specified.
The mesh resolution or cell count for the domain needs to be specified.
