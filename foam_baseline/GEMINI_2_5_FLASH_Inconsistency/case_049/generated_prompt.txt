A 2D simulation of incompressible, laminar flow over an airfoil will be set up using simpleFoam.
The mesh will be extruded one cell in the z-direction.
The patch name frontAndBack will be used for the out-of-plane faces.
In constant/polyMesh/boundary, the frontAndBack patch will have type wall.
In 0/U, the frontAndBack patch will have type slip.
The airfoil profile will be a NACA 0012.
The inlet flow velocity magnitude will be 10 m/s.
The fluid density will be 1.225 kg/m^3.
The fluid kinematic viscosity will be 1.5e-5 m^2/s.
The chord length of the NACA 0012 airfoil needs to be determined.
