Set up a simulation of airflow in a ventilated room with a heater.
Use the steady-state solver buoyantSimpleFoam.
The room has an inlet and an outlet.
The heater is a wall patch with a fixedValue temperature of 320 K.
The inlet air is at 293 K.
The goal is to model the natural convection driven by the heater.
In constant/thermophysicalProperties, specify the thermodynamics using thermoType heRhoThermo.
The equation of state is Boussinesq.
The reference temperature T0 is 293.
The thermal expansion coefficient beta is 0.00341.
The reference density rho0 is 1.2.
The transport model is const.
The dynamic viscosity mu is 1.8e-5.
The Prandtl number Pr is 0.71.
The dimensions of the room are not yet specified.
