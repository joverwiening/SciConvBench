The task is to simulate compressible air flow through a 2D converging–diverging nozzle.
The air will be modeled as a perfect gas.
A nozzle mesh will be created with boundary patches named inlet, outlet, and nozzleWall.
The frontAndBack boundary patch will be set as empty for 2D simulation.
The constant/thermophysicalProperties dictionary will use equationOfState perfectGas.
A temperature-dependent transport model, such as Sutherland, will be used.
The inlet boundary condition will specify a stagnation state using totalPressure and totalTemperature, or fixed supersonic inlet values for U, p, and T.
The outlet boundary condition will set the back pressure, for example p = 101325 Pa, and allow supersonic outflow if it develops.
The nozzle wall boundary condition will be an adiabatic no-slip wall, or a slip wall for inviscid-like behavior.
The system/controlDict will set application nonNewtonianIcoFoam.
The specific numerical value for the inlet height of the converging-diverging nozzle is not specified.
