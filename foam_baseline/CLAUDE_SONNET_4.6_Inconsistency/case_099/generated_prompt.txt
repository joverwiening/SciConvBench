Simulate 2D laminar, transient flow past a square cylinder in a channel using icoFoam.
The domain is 2.2m long, 0.41m high, and one cell (0.01m) thick.
A 0.1m x 0.1m square cylinder is placed in the flow path.
Place the square cylinder center at x = 0.2m from the inlet and y = 0.2m from the bottom wall (slightly offset from the channel centerline at y = 0.205m, following DFG benchmark best practices for vortex shedding).
The kinematic viscosity nu is 0.001 m^2/s.
Use icoFoam as the solver.
In 0/U, set the inlet boundary condition to a parabolic inflow profile with maxValue (1.5 0 0) using groovyBC or codedFixedValue.
In 0/U, set the outlet to zeroGradient.
In 0/U, set topAndBottomWalls to noSlip.
In 0/U, set cylinder to noSlip.
In 0/U, set frontAndBack to noSlip.
In 0/p, set inlet to zeroGradient.
In 0/p, set outlet to fixedValue uniform 0.
In 0/p, set topAndBottomWalls to zeroGradient.
In 0/p, set cylinder to zeroGradient.
In 0/p, set frontAndBack to zeroGradient.
In constant/polyMesh/boundary, define the frontAndBack patches with type wall.
Provide the full OpenFOAM case structure including blockMeshDict, 0/U, 0/p, constant/transportProperties, and system/controlDict, system/fvSchemes, and system/fvSolution files.
Use blockMesh to generate the mesh, with the square cylinder represented by removing cells or using multiple blocks to carve out the cylinder geometry.
