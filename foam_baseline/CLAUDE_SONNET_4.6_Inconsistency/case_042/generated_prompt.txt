Simulate a 2D supersonic flow of air at Mach 2 over a 10-degree wedge (oblique shock).
Treat air as a perfect gas.
Use rhoCentralFoam as the solver.
Set application to rhoCentralFoam in system/controlDict (overriding the simpleFoam example given).
Use a 2D mesh extruded one cell in the z-direction with frontAndBack patches set to empty.
Freestream/inlet conditions: p = 101325 Pa, T = 300 K, U = (686 0 0) m/s.
In constant/thermophysicalProperties, configure a perfect-gas thermophysical model using hePsiThermo and equationOfState perfectGas.
Boundary conditions: inlet uses fixed values for U, p, and T; outlet uses waveTransmissive (or zeroGradient) for p and T, and zeroGradient for U; wedge and top boundary use slip wall condition; frontAndBack patches use empty.
Provide all necessary OpenFOAM case files: constant/thermophysicalProperties, constant/turbulenceProperties (or RASProperties), system/controlDict, system/fvSchemes, system/fvSolution, and the 0/ directory files for U, p, T, and any other required fields.
Use appropriate fvSchemes for supersonic compressible flow with rhoCentralFoam (e.g., Kurganov-Tadmor flux scheme settings).
