Set up a 2D axisymmetric simulation of swirling flow in a pipe using OpenFOAM.
Create a wedge mesh of 5 degrees using blockMeshDict.
Use the simpleFoam solver.
Assume a pipe diameter of 0.1 m and a pipe length of 1.0 m based on best practices.
Define the wedge geometry so the mesh spans 2.5 degrees on each side of the x-axis (total 5 degrees).
The patches are inlet, outlet, wall, front, and back.
In constant/polyMesh/boundary, define inlet and outlet as type patch, wall as type wall, and front and back as type symmetryPlane.
Assume turbulent flow at a moderate Reynolds number of approximately 10000.
Use the k-epsilon turbulence model as a best-practice choice for pipe swirl flow.
For the velocity field U, apply a swirling inlet condition with axial velocity 1.0 m/s, radial velocity 0.0 m/s, and tangential (swirl) velocity 0.5 m/s at the inlet, based on a swirl number of approximately 0.5 as a reasonable best-practice value.
Apply noSlip boundary condition on the wall patch for U.
Apply zeroGradient boundary condition on the outlet patch for U.
Apply symmetryPlane boundary condition on the front and back patches for U.
Set up the pressure field p with zeroGradient at the inlet, fixedValue of 0 at the outlet, zeroGradient at the wall, and symmetryPlane at front and back.
Set up turbulence fields k and epsilon with reasonable inlet turbulence intensity of 5% and turbulent length scale based on pipe diameter.
Apply wall functions on the wall patch for k and epsilon.
Apply zeroGradient on the outlet for k and epsilon.
Apply symmetryPlane on front and back for k and epsilon.
Use fvSchemes and fvSolution settings appropriate for simpleFoam with steady-state swirling flow.
Include a transportProperties file with kinematic viscosity nu set to give a Reynolds number of 10000 based on the pipe diameter and axial inlet velocity (nu = U*D/Re = 1.0*0.1/10000 = 1e-5 m^2/s).
