Simulate transient cooling of a hot block in a 2D sealed room using the compressible solver buoyantPimpleFoam.
Assume OpenFOAM v2212 (or a recent ESI OpenFOAM release circa 2022) as the target version, following best practices.
The room domain is 5 m wide by 3 m tall, extruded one cell in z (depth 0.1 m) to make it 2D.
The front and back patches are set to the empty boundary condition type.
A 0.5 m × 0.5 m block region is initialized at 400 K and is located somewhere reasonable inside the room (e.g., centered horizontally, resting on or near the floor).
The surrounding air is initialized at 300 K.
All solid walls (top, bottom, left, right) are adiabatic: zeroGradient for T.
All solid walls use noSlip for U.
Gravity is set to (0 -9.81 0) in constant/g.
In constant/thermophysicalProperties, use hePsiThermo with pureMixture, sutherland transport, janaf thermo, Boussinesq equationOfState, specie specie, and sensibleEnthalpy energy.
Provide JANAF coefficients and Sutherland transport coefficients appropriate for air.
Provide Boussinesq equationOfState parameters appropriate for air (rho0, T0, beta).
Set up the blockMeshDict to create the room geometry with the appropriate patches.
Use setFields or an equivalent approach to initialize the block region at 400 K.
Provide a complete case directory structure including: constant/thermophysicalProperties, constant/turbulenceProperties (laminar), constant/g, system/blockMeshDict, system/setFieldsDict, system/controlDict, system/fvSchemes, system/fvSolution, and the 0/ directory with initial and boundary conditions for T, U, p, p_rgh, and any other required fields.
Set the simulation to run transiently for a reasonable duration (e.g., 200 s) with an adaptive or fixed time step appropriate for buoyancy-driven flow.
Use PIMPLE settings appropriate for a compressible buoyancy-driven transient simulation.
