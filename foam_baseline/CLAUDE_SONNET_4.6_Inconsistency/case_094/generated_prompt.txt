Simulate steady-state, compressible flow of natural gas through a pipe with a porous baffle using the solver rhoPorousSimpleFoam.
The inlet boundary condition is a total pressure of 2e5 Pa.
The outlet boundary condition is a static pressure of 1e5 Pa.
The gas is modeled as a perfect gas using the perfectGas equation of state.
Define gas thermophysical properties in the thermophysicalProperties dictionary.
Use the sutherland transport model with reasonable best-practice coefficients for natural gas (e.g., As ≈ 1.458e-6 kg/(m·s·K^0.5) and Ts ≈ 110.4 K, or values appropriate for methane).
Use reasonable best-practice thermodynamic properties for natural gas (e.g., Cp ≈ 2220 J/(kg·K), molecular weight ≈ 16.04 g/mol).
Define the porous baffle zone using Darcy-Forchheimer coefficients in the fvOptions dictionary.
Use reasonable best-practice values for the Darcy coefficient d and Forchheimer coefficient f (e.g., d ~ 1e6 m^-2 and f ~ 0 or a small value, applied in all three coordinate directions).
There is no transportProperties dictionary; all transport and thermodynamic properties are in thermophysicalProperties.
Set up the case with standard OpenFOAM directory structure: constant, system, and 0 directories.
Use the SIMPLE algorithm as appropriate for rhoPorousSimpleFoam.
