Simulate incompressible water flow in a channel with a prescribed moving wall (simplified peristaltic pumping) using a dynamic mesh.
Use a 2D mesh extruded one cell in the spanwise direction with `frontAndBack` as `empty`.
Water properties: `nu = 1e-6 m^2/s`.
Use `dynamicMotionSolverFvMesh` with `displacementLaplacian` (or similar) in `constant/dynamicMeshDict`.
Prescribe motion on the `movingWall` boundary via `0/pointDisplacement` (e.g., `oscillatingDisplacement`).
Set all other boundaries in `0/pointDisplacement` to `fixedValue uniform (0 0 0)`.
In `0/U`: inlet uses `fixedValue`, outlet uses `zeroGradient`, stationary walls use `noSlip`, and `movingWall` uses `movingWallVelocity`.
In `0/p`: outlet uses `fixedValue uniform 0`, and inlet/walls use `zeroGradient`.
In `system/controlDict`, set `application` to `pimpleFoam`.
