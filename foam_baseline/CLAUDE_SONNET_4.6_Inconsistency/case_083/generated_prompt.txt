Set up the initial conditions for a three-phase settling tank using the `multiphaseEulerFoam` solver.
The initial field files are located in the `0/` directory.
Create three files: `alpha.sediment`, `alpha.water`, and `alpha.oil`.
Set the `internalField` in all three files to `internalField uniform 0.5;`.
These values will later be modified by `setFieldsDict` to create stratified layers.
Each file corresponds to the volume fraction of its respective phase.
