Set up a steady-state 2D natural convection simulation in a square cavity using the buoyantBoussinesqSimpleFoam solver.
The cavity is square; choose a side length of 1 m as a reasonable best-practice assumption.
The left wall is hot at 310 K and the right wall is cold at 290 K.
The top and bottom walls are adiabatic.
Gravity acts in the -y direction: g = (0 -9.81 0).
The fluid is air.
Choose a mesh resolution of 40x40 cells (or similar best-practice resolution) for the 2D square cavity.
The cavity is 2D, so use a single cell in the z-direction with empty boundary conditions on the front and back faces.
In constant/thermophysicalProperties, use thermoType heRhoThermo with the following sub-settings: mixture pureMixture; transport const; thermo hConst; equationOfState perfectGas; specie hConst; energy sensibleEnthalpy.
Set molecular weight to 28.9 g/mol in the specie sub-dictionary.
In constant/transportProperties, set mu to 1.8e-5 and Pr to 0.7.
In 0/T, set the left wall to fixedValue uniform 310, the right wall to fixedValue uniform 290, and the top and bottom walls to zeroGradient.
Set the internal field initial temperature to a reasonable uniform value (e.g., 300 K).
In 0/U, apply noSlip boundary condition on all walls.
Set the internal field initial velocity to uniform (0 0 0).
In 0/p_rgh, apply fixedFluxPressure on all walls.
Set the internal field initial p_rgh to uniform 0.
Provide all necessary OpenFOAM case files: constant/thermophysicalProperties, constant/transportProperties, constant/g, constant/turbulenceProperties (laminar), system/blockMeshDict, system/fvSchemes, system/fvSolution, system/controlDict, and all 0/ field files.
Use laminar flow (no turbulence model).
Use steady-state settings in controlDict with simpleFoam-compatible controls (e.g., sufficient number of iterations for convergence).
