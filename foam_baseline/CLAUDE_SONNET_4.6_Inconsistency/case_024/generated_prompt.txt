Set up an axisymmetric simulation of swirling flow inside a pipe using simpleFoam.
The mesh is a 2D wedge geometry with a wedge angle of 5 degrees in the tangential direction and one cell thick.
Use reasonable best-practice assumptions for pipe geometry: radius of 0.05 m and axial length of 0.5 m (length-to-diameter ratio of 5).
Define the blockMeshDict in system/blockMeshDict with the axial patch named axis, the pipe surface patch named wall, and inlet and outlet patches.
The front and back wedge planes are defined as type empty, with front using faces (0 3 2 1) and back using faces (4 5 6 7).
Use a solid-body rotation swirl profile at the inlet as a best-practice assumption, where tangential velocity is proportional to radius.
Use reasonable best-practice inlet conditions: a moderate axial velocity (e.g., 1 m/s) and a swirl number of approximately 0.5.
Configure all required OpenFOAM case directories and files: constant/polyMesh (via blockMeshDict), constant/transportProperties, constant/turbulenceProperties, system/controlDict, system/fvSchemes, system/fvSolution, and 0/ directory with initial and boundary conditions for U, p, k, epsilon (or omega).
Use a steady-state incompressible solver (simpleFoam) with a suitable turbulence model (e.g., k-epsilon or k-omega SST).
Apply no-slip boundary condition on the wall patch.
Apply a zero-gradient pressure condition at the inlet and a fixed value (zero gauge) at the outlet.
Ensure the wedge boundary condition is applied correctly to the front and back patches in the 0/ field files.
Apply the axis boundary condition to the axial centerline patch in all relevant field files.
