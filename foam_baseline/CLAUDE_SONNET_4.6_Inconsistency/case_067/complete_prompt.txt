Set up a steady-state simulation for laminar, incompressible flow over a backward-facing step using the simpleFoam solver. The domain has an inlet on the left and an outlet on the right. The fluid enters the domain at the 'inlet' patch and exits at the 'outlet' patch. All other boundaries are walls with a no-slip condition. The simulation is 2D, so front and back patches are of type 'empty'.

Specify the following boundary conditions in the '0/U' file:

inlet
{
    type            fixedValue;
    value           uniform (0.5 0 0);
}
outlet
{
    type            zeroGradient;
}
stepWall
{
    type            noSlip;
}
topWall
{
    type            noSlip;
}
frontAndBack
{
    type            empty;
}
