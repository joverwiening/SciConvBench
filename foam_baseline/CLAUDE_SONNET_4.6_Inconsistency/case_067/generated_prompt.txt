Set up a steady-state simulation for laminar, incompressible flow over a backward-facing step using the simpleFoam solver.
The domain is 2D with an inlet on the left and an outlet on the right.
The fluid enters at the 'inlet' patch and exits at the 'outlet' patch.
All other boundaries are walls with a no-slip condition.
Front and back patches are of type 'empty' for the 2D treatment.
Create the '0/U' file with the following boundary conditions:
inlet uses type fixedValue with value uniform (0.5 0 0).
outlet uses type zeroGradient.
stepWall uses type noSlip.
topWall uses type noSlip.
frontAndBack uses type empty.
