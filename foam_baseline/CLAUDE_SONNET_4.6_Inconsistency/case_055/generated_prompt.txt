Simulate compressible air flow through a 2D converging-diverging nozzle assuming a perfect gas.
Use rhoCentralFoam as the OpenFOAM application in system/controlDict.
Create a 2D nozzle mesh with boundary patches named inlet, outlet, nozzleWall, and frontAndBack.
Set frontAndBack as empty type for 2D simulation.
Use reasonable best-practice nozzle geometry: inlet height 0.1 m, throat height 0.05 m, outlet height 0.1 m, converging section length 0.15 m, diverging section length 0.25 m.
Use reasonable best-practice inlet stagnation conditions: total pressure p0 = 300000 Pa and total temperature T0 = 300 K.
Set outlet back pressure to p = 101325 Pa and allow supersonic outflow if it develops.
Configure constant/thermophysicalProperties with equationOfState perfectGas for air.
Use a Sutherland temperature-dependent transport model in thermophysicalProperties.
At the inlet, specify stagnation state using totalPressure and totalTemperature boundary conditions.
At the outlet, set fixed back pressure p = 101325 Pa and use zeroGradient or inletOutlet conditions for other fields to allow supersonic outflow.
Apply an adiabatic no-slip wall condition on nozzleWall.
Set up system/fvSchemes and system/fvSolution appropriate for rhoCentralFoam (e.g., Kurganov-Tadmor scheme for flux, suitable Courant number control).
Set a reasonable end time and Courant number (e.g., maxCo = 0.5) in system/controlDict.
Provide all relevant OpenFOAM case files: constant/thermophysicalProperties, constant/turbulenceProperties (laminar), system/controlDict, system/fvSchemes, system/fvSolution, system/blockMeshDict, and 0/ directory files for U, p, T, and rho.
