Simulate compressible air flow through a 2D converging–diverging nozzle (perfect gas). Create a nozzle mesh with boundary patches `inlet`, `outlet`, and `nozzleWall` (and `frontAndBack` as `empty` for 2D). Use `constant/thermophysicalProperties` with `equationOfState perfectGas` and a temperature-dependent transport model (e.g., Sutherland).

Example boundary conditions:
- `inlet`: specify a stagnation state using `totalPressure`/`totalTemperature` (or specify fixed supersonic inlet values for `U`, `p`, `T`)
- `outlet`: set the back pressure (e.g., `p = 101325 Pa`) and allow supersonic outflow if it develops
- `nozzleWall`: adiabatic no-slip wall (or slip if you want inviscid-like behavior)

In `system/controlDict`, set:
```foam
application     rhoCentralFoam;
```
