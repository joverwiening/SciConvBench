Simulate the transient von Kármán vortex street behind a cylinder in a 2D channel using OpenFOAM.
Use a 2D mesh extruded one cell in the z-direction with `frontAndBack` patches set to type `empty`.
Set the kinematic viscosity to nu = 1e-3 m^2/s.
For `0/U`, set the inlet to `fixedValue uniform (0.1 0 0)`, outlet to `zeroGradient`, cylinder to `noSlip`, top and bottom to `slip`, and frontAndBack to `empty`.
For `0/p`, set the inlet to `zeroGradient`, outlet to `fixedValue uniform 0`, cylinder/top/bottom to `zeroGradient`, and frontAndBack to `empty`.
In `system/controlDict`, set `application` to `pimpleFoam`.
