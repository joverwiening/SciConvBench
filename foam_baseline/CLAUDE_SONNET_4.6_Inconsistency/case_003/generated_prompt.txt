Run a two-dimensional Rayleigh-Benard convection cell simulation using OpenFOAM with the following full specification.

Geometry and mesh:
Rectangular cavity 9 units wide (x), 1 unit tall (y), extruded 1 cell in the spanwise (z) direction with a thin depth (e.g. 0.1 units).
Use 90 cells in x, 10 cells in y, 1 cell in z.
Front and back patches are treated as walls to enforce 2D behavior.

Solver:
Use buoyantFoam.
Gravity acts in the negative y direction: g = (0 -9.81 0) m/s^2.

Turbulence model:
Use RAS k-epsilon explicitly.
Set constant/momentumTransport to simulationType RAS, model kEpsilon, turbulence on, printCoeffs on.
Do not use laminar anywhere.

Physical properties (constant/physicalProperties):
Use heRhoThermo with equationOfState Boussinesq.
Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, Pr 0.714.

Time control (system/controlDict):
Use a fixed timestep deltaT = 1 s.
Do not enable adjustTimeStep, maxCo, or maxDeltaT.
Simulate up to endTime 1000 s.
Write results every writeInterval 50 steps (writeControl timeStep).

Initial and boundary conditions:

0/U: internalField uniform (0 0 0); noSlip on all solid walls and front/back.

0/T: internalField uniform 300; bottom wall fixedValue 305; top wall fixedValue 295; vertical side walls zeroGradient; front/back noSlip.

0/p: internalField uniform 0; walls calculated; front/back noSlip.

0/p_rgh: internalField uniform 0; walls fixedFluxPressure; front/back noSlip.

0/k: internalField uniform 1e-5; kqRWallFunction on solid walls; noSlip on front/back.

0/epsilon: internalField uniform 1e-5; epsilonWallFunction on solid walls; noSlip on front/back.

0/nut: internalField uniform 0; nutkWallFunction on solid walls; noSlip on front/back.

0/alphat: internalField uniform 0; compressible::alphatJayatillekeWallFunction on solid walls with Prt 0.85; noSlip on front/back.

system/fvSolution solvers:
p_rgh solver: tolerance 1e-8, relTol 0.01.
p_rghFinal solver: tolerance 1e-8, relTol 0.
(U|e|k|epsilon) solvers: tolerance 1e-8, relTol 0.01.
(U|e|k|epsilon)Final solvers: tolerance 1e-8, relTol 0.
