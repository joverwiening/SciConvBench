Set up the classic 2D dam-break problem in OpenFOAM using interFoam.
Use a 2D mesh extruded one cell in the spanwise direction with frontAndBack patches set to empty.
Track the free surface using the VOF field alpha.water.
Initialize the water column using setFields, setting alpha.water = 1 inside the initial water column and 0 elsewhere.
Set gravity to (0 -9.81 0).
Apply the following boundary conditions for tank walls: noSlip for U, zeroGradient for p_rgh, zeroGradient for alpha.water.
Apply the following boundary conditions for the open top: pressureInletOutletVelocity for U, totalPressure or fixedValue of 0 for p_rgh, and inletOutlet for alpha.water with inletValue uniform 0.
In system/controlDict, set application to interFoam.
