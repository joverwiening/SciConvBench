Set up a 2D steady-state simulation of Rayleigh-Bénard convection in a square cavity of 1m x 1m.
The fluid is air.
Use the buoyantBoussinesqSimpleFoam solver.
The domain is a unit square (1m x 1m) in 2D (one cell thick in the z-direction).
Use a mesh resolution of 40 x 40 cells in the x and y directions, with 1 cell in the z-direction, as a reasonable best-practice starting resolution for this Ra number range.
The bottom wall is heated to 310 K using a fixedValue boundary condition.
The top wall is cooled to 290 K using a fixedValue boundary condition.
The side walls use zeroGradient for temperature (adiabatic).
All walls use noSlip boundary condition for velocity.
All boundaries use fixedFluxPressure for p_rgh.
Gravity acts in the negative y-direction with g = 9.81 m/s^2.
In constant/thermophysicalProperties, use the following thermoType block: type hePsiThermo, mixture perfectGas, transport const, thermo hConst, equationOfState perfectGas, specie specie, energy sensibleEnthalpy.
In the mixture block, set molWeight to 28.9, Cp to 1005, Hf to 0, mu to 1.8e-05, and Pr to 0.7.
Use the Boussinesq approximation for buoyancy with a reference temperature of 300 K (mean of 310 K and 290 K).
Set up all required OpenFOAM case directories and files: constant/, system/, and 0/ directories with appropriate field initialization files (T, U, p_rgh), transportProperties or thermophysicalProperties, turbulenceProperties (laminar), blockMeshDict, controlDict, fvSchemes, and fvSolution.
Run the simulation as a steady-state case using the SIMPLE algorithm.
Use laminar flow model (no turbulence), as Rayleigh-Bénard convection at this scale and temperature difference is expected to be in the laminar regime.
