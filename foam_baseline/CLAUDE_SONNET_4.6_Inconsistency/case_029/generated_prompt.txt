Simulate the transient von Kármán vortex street for 2D flow past a circular cylinder at Reynolds number Re = 150 using OpenFOAM.
Use `pimpleFoam` as the solver (transient, incompressible).
Set up a 2D mesh of flow past a circular cylinder appropriate for Re = 150.
In `system/controlDict`, set the following:
application to pimpleFoam
startFrom to startTime
startTime to 0
stopAt to endTime
endTime to 200
deltaT to 0.005
adjustTimeStep to yes
maxCo to 0.9
writeControl to runTime
writeInterval to 1
Use a transient time-stepping approach (not steady-state iterations).
Write results at every 1 unit of run time to ensure the vortex shedding is temporally resolved.
The simulation should capture the periodic vortex shedding behavior characteristic of Re = 150 flow past a cylinder.
