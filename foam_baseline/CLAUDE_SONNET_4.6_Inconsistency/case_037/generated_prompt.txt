Simulate steady, incompressible, laminar flow of water through a 2D channel containing a rigid, stationary obstacle using OpenFOAM.
Use a 2D mesh extruded one cell in the spanwise direction with `frontAndBack` set to `empty`.
Use `simpleFoam` as the solver in the `application` field of `system/controlDict`.
Water kinematic viscosity: `nu = 1e-6 m^2/s`.
Assume a rectangular channel of length 2.2 m and height 0.41 m based on best practices (e.g., inspired by the DFG 2D-2 benchmark).
Place a square obstacle of side 0.1 m centered at (0.2, 0.2) from the channel inlet bottom-left corner.
Extrude the mesh one cell in the spanwise (z) direction with a depth of 0.1 m.
Boundary conditions for `0/U`: inlet `fixedValue uniform (0.1 0 0)`, outlet `zeroGradient`, walls and obstacle `noSlip`, frontAndBack `empty`.
Boundary conditions for `0/p`: inlet `zeroGradient`, outlet `fixedValue uniform 0`, walls and obstacle `zeroGradient`, frontAndBack `empty`.
In `system/controlDict`, set `startTime 0`, `endTime 500`, `deltaT 1`, and `writeInterval 50` as reasonable steady-state settings for `simpleFoam`.
Set `stopAt endTime` and use `latestTime` for `startFrom`.
Use `system/fvSchemes` with steady-state schemes: `ddtSchemes default steadyState`, `gradSchemes default Gauss linear`, `divSchemes div(phi,U) Gauss linearUpwind grad(U)`, `laplacianSchemes default Gauss linear corrected`.
Use `system/fvSolution` with `SIMPLE` algorithm, appropriate relaxation factors (e.g., `U 0.7`, `p 0.3`), and convergence tolerances (e.g., `1e-6` for U and p).
Generate the `constant/transportProperties` file with `nu [0 2 -1 0 0 0 0] 1e-6`.
Set `constant/turbulenceProperties` to `simulationType laminar`.
Create the `blockMeshDict` to produce the channel geometry with the obstacle represented as a hole or using `topoSet`/`snappyHexMesh` as appropriate for the square obstacle.
