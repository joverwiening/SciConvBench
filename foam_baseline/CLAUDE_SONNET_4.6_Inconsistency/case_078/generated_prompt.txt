Set up a steady-state OpenFOAM simulation of airflow in a ventilated room with a heater using the solver buoyantSimpleFoam.
The room geometry has one inlet patch and one outlet patch.
The heater is modelled as a wall patch with a fixedValue temperature boundary condition of 320 K.
The inlet air temperature is 293 K.
The goal is to model natural convection driven by the heater using the Boussinesq approximation.
In constant/thermophysicalProperties, set thermoType to heRhoThermo.
Set the equation of state to Boussinesq with T0 293, beta 0.00341, and rho0 1.2.
Set the transport model to const with mu 1.8e-5 and Pr 0.71.
Use the k-epsilon RANS turbulence model as a reasonable best-practice choice for buoyancy-driven indoor airflow simulations.
Configure constant/turbulenceProperties to use RAS with the kEpsilon model.
Set up the 0/ directory with appropriate boundary conditions for U, p_rgh, T, k, and epsilon.
For the inlet, use fixedValue for U (a low inlet velocity consistent with ventilation), fixedValue 293 K for T, and reasonable turbulence inlet values for k and epsilon.
For the outlet, use zeroGradient for T and inletOutlet or zeroGradient for U, with a fixedValue or zeroGradient for p_rgh.
For the heater wall, use fixedValue 320 K for T, noSlip for U, and kqRWallFunction and epsilonWallFunction for turbulence quantities.
For all other walls, use zeroGradient for T, noSlip for U, and wall functions for k and epsilon.
Set up system/fvSchemes with steady-state (Gauss linear) schemes appropriate for buoyantSimpleFoam.
Set up system/fvSolution with SIMPLE algorithm settings, including appropriate relaxation factors for U, p_rgh, T, k, and epsilon.
Include gravitational acceleration in constant/g pointing in the negative z-direction (0 0 -9.81).
