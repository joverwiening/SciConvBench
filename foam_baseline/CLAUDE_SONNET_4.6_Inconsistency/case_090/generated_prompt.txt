Set up a transient 2D vortex shedding simulation behind a cylinder at Reynolds number 100 using OpenFOAM.
Use the pimpleFoam solver.
The domain is a rectangular channel with a circular cylinder offset from the center.
The fluid is incompressible with kinematic viscosity nu = 0.01 m^2/s.
The inlet velocity is U = (1 0 0) m/s.
The cylinder diameter is 1 m.
The boundary conditions are as follows: 'inlet' uses fixedValue for U, 'outlet' uses zeroGradient for U and fixedValue p = 0, 'topAndBottom' uses slip, 'cylinder' uses noSlip, and 'frontAndBack' uses empty (2D).
Run the simulation from t = 0 to t = 200 s with a time step deltaT of 0.1 s.
The goal is to observe the von Kármán vortex street and calculate the Strouhal number.
