Simulate the transient start-up flow of a Bingham plastic fluid in a 2D pipe using OpenFOAM.
Use the solver `nonNewtonianIcoFoam`.
The domain is a 2D rectangle of 1.0m length and 0.1m height (diameter).
Use `blockMesh` to create the mesh with 100 cells in the axial (x) direction and 20 cells in the radial (y) direction.
The front and back patches must be of type `empty` to enforce 2D simulation.
In `constant/transportProperties`, define the transport model as `BinghamPlastic` with the following properties: rho 1000, tau0 10, mu0 0.1, muInf 0.01.
The boundary conditions are: inlet with fixed velocity `(0.1 0 0)` m/s, outlet with `zeroGradient` for velocity and fixed pressure of 0, and `noSlip` on the wall patches.
The simulation runs from t=0 to t=5s.
Choose a reasonable time step `deltaT` based on best practices (e.g., deltaT=0.001s to satisfy CFL stability with the given mesh and velocity).
Set `writeInterval` to a reasonable value (e.g., 0.1s or 0.5s) to capture transient development.
Set `maxCo` to 0.5 or similar if adjustable time-stepping is used, otherwise use fixed time-stepping.
Provide all necessary OpenFOAM case files: `blockMeshDict`, `controlDict`, `fvSchemes`, `fvSolution`, `transportProperties`, and the initial condition files `0/U` and `0/p`.
