Set up a steady-state, incompressible, turbulent flow simulation for the Pitz and Daily combustor case using the simpleFoam solver.
The geometry is 2D.
Use RANS turbulence modeling with the kEpsilon model.
The constant/turbulenceProperties file should contain only the RAS block with simulationType set to RAS, RASModel set to kEpsilon, turbulence set to on, and printCoeffs set to on. No LES block should be present.
The boundary condition for velocity U at the inlet is a fixed value of (10 0 0) m/s.
The boundary condition for velocity U at the outlet is zeroGradient.
The boundary condition for velocity U at upperWall and lowerWall is no-slip (fixedValue of (0 0 0)).
The front and back patches are of type empty.
The boundary condition for pressure p at the inlet is zeroGradient.
The boundary condition for pressure p at upperWall and lowerWall is zeroGradient.
The boundary condition for pressure p at the outlet is fixedValue of 0.
The simulation should run for 500 iterations.
