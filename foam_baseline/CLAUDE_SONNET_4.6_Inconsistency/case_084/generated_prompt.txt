Set up a transient two-phase Euler–Euler gas–solid riser simulation using twoPhaseEulerFoam.
The two phases are air (gas) and catalyst (solid).
At the inlet, prescribe a dilute solids loading with alpha.catalyst = 0.01.
In 0/alpha.catalyst, set the inlet boundary condition to type fixedValue with value uniform 0.01.
In 0/alpha.air, set the inlet boundary condition to type fixedValue with value uniform 0.99.
The phase fractions alpha.air and alpha.catalyst must sum to 1 everywhere, including at the inlet.
