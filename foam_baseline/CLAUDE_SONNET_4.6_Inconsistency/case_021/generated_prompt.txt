Set up a 2D, incompressible, steady-state simulation of airflow over a symmetric airfoil using the simpleFoam solver in OpenFOAM.
Use a NACA 0012 airfoil profile as a reasonable best-practice choice for a symmetric airfoil.
Set the angle of attack to 5 degrees as a reasonable best-practice value.
Use the k-ω SST turbulence model as a best-practice RANS model for external aerodynamic flows.
The domain uses a C-grid topology around the airfoil.
The mesh is one cell thick in the z-direction (2D simulation).
In the system/blockMeshDict file, define the frontAndBack patches as walls in the boundary entry, using the face definitions as specified by the user, including (0 4 7 3) and (1 2 6 5) and any other relevant faces for that patch.
In the 0/U file, apply a uniform inlet velocity of (10 0 0) m/s at the inlet.
In the 0/U file, apply a zeroGradient condition at the outlet.
In the 0/U file, apply a noSlip condition on the airfoil surface.
In the 0/U file, apply a noSlip condition on the frontAndBack patches.
In the 0/p file, apply zeroGradient at the inlet.
In the 0/p file, apply zeroGradient on the airfoil surface.
In the 0/p file, apply fixedValue uniform 0 at the outlet.
In the 0/p file, apply zeroGradient on the frontAndBack patches.
Create 0/k and 0/omega files with reasonable freestream turbulence boundary conditions appropriate for k-ω SST and an inlet velocity of 10 m/s.
Set turbulence intensity to approximately 1% and a turbulent length scale appropriate for external aerodynamic flow as best-practice initial and boundary conditions for k and omega.
Include a constant/turbulenceProperties file specifying the k-ω SST model.
Include a constant/transportProperties file with air properties (kinematic viscosity approximately 1.5e-5 m²/s).
Include a system/fvSolution and system/fvSchemes file configured appropriately for simpleFoam with k-ω SST.
Include a system/controlDict configured for a steady-state simpleFoam run with a reasonable number of iterations (e.g., 500).
