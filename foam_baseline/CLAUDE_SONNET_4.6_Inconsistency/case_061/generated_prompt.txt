Set up a 2D lid-driven cavity flow simulation using OpenFOAM.
The domain is a 1 m × 1 m square extruded one cell in the z-direction.
Use the `frontAndBack` patch type as `empty` for the z-faces.
Use a uniform mesh of 40 × 40 × 1 cells.
The fluid is incompressible and Newtonian with kinematic viscosity `nu = 0.01 m^2/s`.
Run the simulation transiently using `icoFoam` until a steady solution is reached.
Set `application icoFoam;` in `system/controlDict`.
The `movingLid` patch (top wall) has boundary condition `0/U` set to `fixedValue uniform (1 0 0)`.
The `fixedWalls` patch (left, right, and bottom walls) has boundary condition `0/U` set to `noSlip`.
The `0/p` field uses `zeroGradient` on all wall patches.
Set the pressure reference using `pRefCell` and `pRefValue` in `system/fvSolution`.
The `frontAndBack` patch uses type `empty` for both `0/U` and `0/p`.
