Set up a laminar counter-flow diffusion flame simulation using the reactingFoam solver in OpenFOAM.

The domain is a 3-D rectangular region: x from 0 to 0.02 m, y from -0.01 to 0.01 m, z from -0.01 to 0.01 m.
Use 100 cells in x, 40 cells in y, and 1 cell in z.
The left boundary (x = 0) is named "fuel".
The right boundary (x = 0.02 m) is named "air".
The top and bottom boundaries are named "outlet".
The front and back faces are named "frontAndBack" and are set to empty (2-D simulation).

At the fuel inlet, inject pure methane (CH4) at 293 K with velocity 0.1 m/s in the +x direction.
At the air inlet, supply oxidizer at 293 K with Y_O2 = 0.23 and Y_N2 = 0.77, with velocity 0.1 m/s in the -x direction (i.e., -0.1 m/s).
The outlet boundaries use a zero-gradient or inletOutlet condition appropriate for reactingFoam.

Initialize the entire domain temperature to 2000 K at time 0 to ignite the flame.
Initialize species fields consistently with a mixing layer or uniform fields appropriate for ignition.

Use the GRI-Mech 3.0 reduced mechanism (or a well-established small reduced methane mechanism such as the 2-step or 4-step Jones-Lindstedt, or a skeletal GRI mechanism) as the chemical mechanism, following best practices for laminar methane diffusion flames.
Use finite-rate chemistry with EulerImplicit chemistry type and Rosenbrock43 ODE solver.

The combustion model is laminar (no turbulence-chemistry interaction).
Momentum transport is laminar.

Use heRhoThermo for thermophysical modeling.
Use coefficientWilkeMultiComponentMixture for the mixture model.
Use Sutherland transport model.
Use JANAF thermodynamics.

Use a timestep of 1e-4 s.
Set the end time to 0.5 s.
Write results every 0.05 s.

Generate all necessary OpenFOAM case files including: blockMeshDict, chemistryProperties, combustionProperties, thermophysicalProperties, controlDict, fvSchemes, fvSolution, initial and boundary condition files (0/ directory) for U, T, p, p_rgh, and all species, and the reactions/chemistry file consistent with the chosen mechanism.
