Simulate the static deflection of a 2D cantilever beam under a downward traction load using linear elasticity in OpenFOAM with solidDisplacementFoam.
The beam is 1.0 m long and 0.1 m high.
Use a structured mesh of 100 × 10 cells.
Material is aluminum with E = 70e9 Pa and nu = 0.33.
In 0/D, set the fixedEnd patch (x=0) to fixedValue uniform (0 0 0).
In 0/D, set the loadEnd patch (x=1) to tractionDisplacement with traction uniform (0 -10000 0) and pressure uniform 0.
In 0/D, set the top and bottom patches to zeroGradient.
In system/controlDict, set the application field to pimpleFoam (as specified by the user).
Generate all necessary OpenFOAM case files including constant/mechanicalProperties, constant/polyMesh (or blockMeshDict), 0/D, and system/controlDict.
