Set up a 2D laminar incompressible flow simulation past a cylinder to observe the von Kármán vortex street.
The Reynolds number is 100.
The domain is a rectangular channel 2.2m long and 0.41m high.
The cylinder has a diameter of 0.1m and is centered at (0.2, 0.2).
Use a kinematic viscosity of 1e-3 m²/s.
Use a uniform inlet velocity of U = (1 0 0) m/s.
The mesh is one cell thick in the z-direction (2D simulation).
In system/controlDict, specify the solver as pimpleFoam.
Set startTime to 0, endTime to 200, deltaT to 1, and writeInterval to 10.
For boundary conditions in the 0/ directory, set U at inlet to fixedValue uniform (1 0 0).
Set U at outlet to zeroGradient.
Set U on cylinderWall to noSlip.
Set U on topAndBottom walls to noSlip.
Set U on frontAndBack patches to empty.
For p, set inlet to zeroGradient.
Set p on cylinderWall to zeroGradient.
Set p at outlet to fixedValue uniform 0.
Set p on topAndBottom to zeroGradient.
Set p on frontAndBack to empty.
Run the simulation to obtain the final time-dependent flow field showing vortex shedding.
