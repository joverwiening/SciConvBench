Perform a 2D transient heat conduction simulation on a 1 m × 1 m plate using laplacianFoam.
Extrude the mesh one cell in the z-direction with a thickness of 0.01 m.
Treat the out-of-plane faces as a patch named frontAndBack.
In constant/polyMesh/boundary, set frontAndBack to type wall.
In 0/T, set frontAndBack to type zeroGradient.
Set thermal diffusivity DT = 1e-5 m^2/s in constant/transportProperties.
Set the initial temperature T to a uniform 300 K throughout the domain.
For the four side patches (left, right, top, bottom), apply a fixed temperature (Dirichlet) boundary condition as a best-practice assumption for a well-posed transient problem.
Set the left patch to a fixed temperature of 400 K to drive heat conduction across the plate.
Set the right, top, and bottom patches to a fixed temperature of 300 K.
Choose a mesh resolution of 100 × 100 cells in the x-y plane (one cell in z) as a reasonable best-practice discretization.
Choose a time step deltaT = 1 s based on the diffusive stability criterion (Fourier number well below 1 for the given DT and cell size).
Set the total simulation end time to 50000 s, which is on the order of the diffusive time scale L^2/DT = 1e5 s, allowing the solution to approach steady state.
Use Euler implicit time integration (Euler scheme in fvSchemes) for unconditional stability.
Use a Gauss linear corrected scheme for the Laplacian term in fvSchemes.
Use a PCG solver with DIC preconditioner for the temperature equation in fvSolution.
Write output every 5000 s (writeInterval 5000) so that the transient evolution is captured at roughly 10 snapshots.
Use writeFormat ascii and writePrecision 6.
