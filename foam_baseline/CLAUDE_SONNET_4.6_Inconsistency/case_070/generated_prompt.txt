Set up a 2D simulation of natural convection in a tall, sealed cavity using OpenFOAM.
Use the buoyantBoussinesqSimpleFoam solver.
The fluid is air.
Gravity acts in the negative y-direction.
The left wall is hot and the right wall is cold.
The top and bottom walls are adiabatic.
Use the following boundary conditions for temperature T:
leftWall: type fixedValue, value uniform 350 K.
rightWall: type fixedValue, value uniform 300 K.
topWall: type zeroGradient (adiabatic).
bottomWall: type zeroGradient (adiabatic).
