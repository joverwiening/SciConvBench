Simulate a high-speed, compressible supersonic jet in OpenFOAM with inlet Mach number 2.0 discharging into a larger domain.
Treat air as a perfect gas using hePsiThermo, equationOfState perfectGas, and transport sutherland in constant/thermophysicalProperties.
Use a 2D mesh extruded one cell in z with frontAndBack set to empty.
Inlet conditions: U = (686 0 0) m/s, T = 300 K, p = 101325 Pa.
Apply fixed value boundary conditions for U, p, and T at the nozzle inlet (supersonic inflow).
Apply waveTransmissive boundary conditions for p and T at the far-field/outlet, and zeroGradient for U.
Apply noSlip boundary conditions on solid walls.
Use rhoPimpleFoam (or rhoSimpleFoam for steady-state) as the solver — note that pimpleFoam is incompressible and not appropriate; use a compressible solver instead.
Use RANS turbulence modeling with k-omega SST as the turbulence model, as this is best practice for high-speed compressible jet flows.
Set the domain length to 30 nozzle diameters in x and 10 nozzle diameters in y as a reasonable domain size.
Use approximately 300 cells in x and 100 cells in y, with refinement near the nozzle exit and shear layers.
Assume a nozzle exit diameter (or height for 2D) of 0.01 m as a reference length scale.
Set the domain height to be large enough to avoid far-field reflections (at least 10 nozzle diameters).
Configure system/controlDict with appropriate time stepping (e.g., adjustable time step with max Courant number 0.5), write interval, and end time sufficient to reach a statistically steady state.
Configure fvSchemes with second-order schemes appropriate for compressible flow (e.g., Gauss linearUpwind for divergence terms).
Configure fvSolution with appropriate solvers and tolerances for compressible RANS.
Include initial conditions consistent with the inlet values throughout the domain to aid convergence.
