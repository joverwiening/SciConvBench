Perform a 2D steady-state heat conduction simulation using laplacianFoam on a 1m x 1m square plate that is one cell thick.
Use a mesh resolution of 20 cells in the X direction and 20 cells in the Y direction (20x20x1), as a reasonable best-practice assumption.
In blockMeshDict, define four side patches named left, right, top, and bottom, plus a frontAndBack patch.
Set the frontAndBack patch to type wall in blockMeshDict.
In the 0/T file, set the left wall boundary condition to fixedValue with a value of 400 K.
Set the right wall boundary condition to fixedValue with a value of 300 K.
Set the top and bottom wall boundary conditions to zeroGradient.
Set the frontAndBack patch boundary condition to zeroGradient to simulate an insulated plate.
The simulation should run until steady-state temperature distribution is reached.
Use laplacianFoam as the solver.
