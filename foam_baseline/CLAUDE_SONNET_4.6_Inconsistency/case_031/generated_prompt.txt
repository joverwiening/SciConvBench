Set up a 2D incompressible laminar flow simulation in a rectangular channel using the icoFoam solver.
The channel is 0.5 m long in the x-direction and 0.1 m high in the y-direction.
The mesh should be one cell thick in the z-direction.
In blockMeshDict, define the geometry and the following patches: inlet, outlet, topWall, bottomWall, and frontAndBack.
In blockMeshDict, set frontAndBack patches to type empty.
The simulation should model Poiseuille flow.
In 0/U, set a parabolic inlet velocity profile with a maximum velocity of 1 m/s.
In 0/U, set a zeroGradient condition at the outlet.
In 0/U, apply noSlip conditions on topWall and bottomWall.
In 0/U, set frontAndBack patches to type empty.
In 0/p, set fixedValue 0 at the outlet.
In 0/p, set zeroGradient on all other patches except frontAndBack (i.e., inlet, topWall, bottomWall).
In 0/p, set frontAndBack patches to type empty.
