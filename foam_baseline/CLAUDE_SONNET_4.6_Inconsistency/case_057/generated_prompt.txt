Simulate a 2D bubble column using twoPhaseEulerFoam.
The column is 0.5m wide and 2m high.
The continuous phase is water and the dispersed phase is air.
Initialize the domain using setFieldsDict.
The default field values (top 0.5m pure air region) are alpha.air = 0.9 and alpha.water = 0.1.
The bottom 1.5m of the column is filled with a mixture defined by a boxToCell region from (0 0 -0.1) to (0.5 1.5 0.1).
The corrected field values inside the boxToCell region are alpha.air = 0.4 and alpha.water = 0.6.
Use the following corrected setFieldsDict configuration:

FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      setFieldsDict;
}

defaultFieldValues
(
    volScalarFieldValue alpha.air 0.9
    volScalarFieldValue alpha.water 0.1
);

regions
(
    boxToCell
    {
        box (0 0 -0.1) (0.5 1.5 0.1);
        fieldValues
        (
            volScalarFieldValue alpha.air 0.4
            volScalarFieldValue alpha.water 0.6
        );
    }
);
