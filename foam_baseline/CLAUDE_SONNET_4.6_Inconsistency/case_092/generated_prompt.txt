Simulate the compressible, supersonic flow of air over a 10-degree wedge to produce an oblique shock.
The freestream Mach number is 2.0.
Treat air as a perfect gas.
Use a 2D mesh extruded one cell in the z-direction with `frontAndBack` patches set to `empty`.
Freestream/inlet conditions are: U = (686 0 0) m/s, T = 293 K, p = 101325 Pa.
In `constant/thermophysicalProperties`, configure a perfect-gas thermophysical model using `hePsiThermo`, `equationOfState perfectGas`, and `transport sutherland`.
Set the inlet boundary condition to fixed values for U, p, and T.
Set the outlet boundary condition to `waveTransmissive` for p and T, and `zeroGradient` for U.
Set the wedge surface and top boundary to slip wall conditions.
Set frontAndBack patches to `empty`.
In `system/controlDict`, set `application rhoPimpleFoam`.
