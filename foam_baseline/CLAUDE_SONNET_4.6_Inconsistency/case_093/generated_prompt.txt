Set up a 2D dam break simulation in OpenFOAM using the pimpleFoam solver.
The domain is rectangular; use best-practice dimensions (e.g., 3.22 m long x 1.0 m tall x 0.1 m deep as a standard dam break benchmark).
Use a best-practice mesh resolution (e.g., 161 x 50 x 1 cells for a 2D simulation with one cell in the z-direction).
The domain is initially filled with air (alpha.water = 0) everywhere except the water column.

Water properties: kinematic viscosity nu = 1e-6 m^2/s, density rho = 1000 kg/m^3.
Air properties: kinematic viscosity nu = 1.48e-5 m^2/s, density rho = 1 kg/m^3.
In controlDict, set endTime to 5 s.
Use reasonable best-practice settings for deltaT, writeInterval, and other controlDict entries.
The simulation is 2D (one cell thick in the z-direction) with empty boundary conditions on the front and back faces.
