Simulate the mixing of a non-Newtonian sludge with water in a 2D tank using the `interFoam` solver.
The two phases are named 'water' and 'sludge'.
The sludge is a Bingham plastic material.
Produce a `transportProperties` file that defines the properties for both phases.

The water phase uses transportModel Newtonian, nu = 1e-6, rho = 1000.
The sludge phase uses transportModel BinghamPlastic.
The sludge Bingham plastic parameters are: tau0 = 15, mu0 = 0.1, muInf = 0.01.
Choose a reasonable regularization parameter (BinghamCoeff or equivalent) for the BinghamPlastic model based on best practices.
The surface tension sigma = 0.07.
The simulation is 2D.
