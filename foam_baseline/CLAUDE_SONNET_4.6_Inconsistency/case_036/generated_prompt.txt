Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity.
The beam is 1 m long, 0.1 m high, and 0.1 m wide.
One end named `fixed` is clamped, and the free end named `loaded` has a downward traction load.
In `constant/mechanicalProperties`, set Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.3.
In `0/D`, set the `fixed` patch to `fixedValue uniform (0 0 0)`.
In `0/D`, set the `loaded` patch to `tractionDisplacement` with `traction uniform (0 -1000 0)` and `pressure uniform 0`.
In `0/D`, set all other faces to `zeroGradient`.
In `system/controlDict`, set `application` to `solidDisplacementFoam` and `endTime` to 1.
