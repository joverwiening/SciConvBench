Set up a two-dimensional Rayleigh–Bénard convection simulation case in OpenFOAM using buoyantFoam.
Assume an OpenFOAM Foundation line case structure and dictionary syntax as a reasonable best-practices default.
Use a rectangular cavity domain 9 units wide (x) and 1 unit tall (y), extruded one cell in the spanwise (z) direction.
Treat the front and back patches as empty to enforce 2D.
Use a mesh with 90 cells in x, 10 cells in y, and 1 cell in z.
Set gravity to act downward in the negative y direction.
Use an air-like Boussinesq reference state with rho0 1.0 kg/m^3, T0 300 K, beta 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, and thermal diffusivity 2.1e-5 m^2/s (Pr ≈ 0.7).
In constant/physicalProperties, use heRhoThermo with equationOfState Boussinesq and set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.
Apply no-slip velocity conditions on all solid walls.
Set the bottom wall temperature to fixedValue 305 K.
Set the top wall temperature to fixedValue 295 K.
Set the vertical side walls to be adiabatic.
Initialize the flow at rest with uniform temperature 300 K.
Use a fixed timestep with deltaT = 1 s.
Do not enable adjustTimeStep.
Do not set maxCo.
Do not set maxDeltaT.
Run the simulation to 1000 s of physical time.
Write results every 50 time steps.
Use the k-epsilon turbulence model.
Configure constant/momentumTransport with simulationType RAS, model kEpsilon, turbulence on, and printCoeffs on, and do not use laminar anywhere.
In 0/k, set internalField uniform 1e-5, use kqRWallFunction on walls, and empty on front/back.
In 0/epsilon, set internalField uniform 1e-5, use epsilonWallFunction on walls, and empty on front/back.
In 0/nut, set internalField uniform 0, use nutkWallFunction on walls, and empty on front/back.
In 0/alphat, set internalField uniform 0, use compressible::alphatJayatillekeWallFunction on walls with Prt 0.85, and empty on front/back.
In 0/U, set internalField uniform (0 0 0), use noSlip on all solid walls, and empty on front/back.
In 0/T, set internalField uniform 300, set bottom fixedValue 305, set top fixedValue 295, set sides fixedValue 300, and set front/back empty.
In 0/p, set internalField uniform 0, set walls to calculated, and set front/back empty.
In 0/p_rgh, set internalField uniform 0, set walls to fixedFluxPressure, and set front/back empty.
In system/fvSolution, set p_rgh and (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01.
In system/fvSolution, set the corresponding *Final solvers to relTol 0.
