Simulate laminar buoyant air flow and heat transfer in a 2D channel containing a heated block using the OpenFOAM buoyantPimpleFoam solver.  
Assume a reasonable OpenFOAM version and follow best-practice case structure and settings for that version.  
Model a 2D rectangular channel of length 0.5 m and height 0.05 m.  
Enforce 2D by using a mesh that is one cell thick in the z-direction with thickness 0.001 m.  
Set the front and back patches to type empty.  
Place a rectangular heated block inside the channel with size 0.02 m (x) by 0.01 m (y).  
Center the block vertically in the channel.  
Locate the block leading edge at x = 0.20 m so the block spans x = 0.20 to 0.22 m.  
Set the block to span y = 0.02 to 0.03 m.  
Use air properties at 300 K with kinematic viscosity nu ≈ 1.5e-5 m^2/s.  
Target a laminar regime with Reynolds number approximately 100–500 and certainly below 2300.  
Compute inlet mean velocity using U_in = Re * nu / D_h.  
Use hydraulic diameter D_h = 2H for the 2D parallel-plate channel, with H = 0.05 m.  
Set inlet boundary conditions to fixed velocity and temperature 300 K.  
Maintain the block at constant temperature 400 K.  
Set the outlet temperature boundary condition to zeroGradient.  
Set the channel walls to be adiabatic by using zeroGradient for temperature on the walls in 0/T.  
In the 0/T file, set inlet to type fixedValue with value uniform 300.  
In the 0/T file, set outlet to type zeroGradient.  
In the 0/T file, set block to type fixedValue with value uniform 400.  
In the 0/T file, set walls to type zeroGradient.
