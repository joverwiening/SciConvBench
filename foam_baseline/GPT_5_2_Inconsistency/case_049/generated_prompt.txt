Set up a 2D simulation of incompressible, laminar flow over an airfoil using simpleFoam.
Use a mesh extruded one cell in the z-direction.
Use the patch name frontAndBack for the out-of-plane faces.
In constant/polyMesh/boundary, set the frontAndBack patch block to type wall.
In 0/U, set frontAndBack to type slip.
In constant/turbulenceProperties, set simulationType laminar;.
In 0/p, set frontAndBack to type empty.
In 0/nut, set frontAndBack to type empty.
In 0/k, set frontAndBack to type empty.
In 0/epsilon, set frontAndBack to type empty.
In 0/omega, set frontAndBack to type empty.
In 0/nuTilda, if the field exists, set frontAndBack to type empty.
In 0/phi, if the field exists, set frontAndBack to type empty.
