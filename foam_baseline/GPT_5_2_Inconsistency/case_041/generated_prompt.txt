Set up a 2D laminar incompressible flow simulation past a cylinder at Reynolds number 100 to observe a von Kármán vortex street.
Use a rectangular channel domain 2.2 m long and 0.41 m high.
Place a cylinder of diameter 0.1 m centered at (0.2, 0.2).
Use kinematic viscosity nu = 1e-3 m^2/s.
Use a uniform inlet velocity U = (1 0 0) m/s.
Use a mesh that is one cell thick in the z-direction and treat the front and back patches as empty.
Use a transient solver pimpleFoam (not simpleFoam).
In system/controlDict set startTime = 0, endTime = 200, deltaT = 1, and writeInterval = 10.
In 0/U set inlet to fixedValue uniform (1 0 0), outlet to zeroGradient, cylinderWall to noSlip, topAndBottom to noSlip, and frontAndBack to empty.
In 0/p set inlet to zeroGradient, outlet to fixedValue uniform 0, cylinderWall to zeroGradient, topAndBottom to zeroGradient, and frontAndBack to empty.
In constant/turbulenceProperties set simulationType laminar.
In system/fvSchemes use a second-order implicit transient scheme with ddtSchemes default backward.
Run the simulation to obtain the final flow field.
