Set up a 2D lid-driven cavity flow in a 1 m × 1 m square domain extruded one cell in z with frontAndBack set to empty.
Use a uniform mesh of 40 × 40 × 1 cells.
Use an incompressible Newtonian fluid with kinematic viscosity nu = 0.01 m^2/s.
Run a transient simulation with icoFoam until a steady solution is reached, using a fixed endTime chosen to be long enough without any automatic stop criterion.
Set boundary conditions so that movingLid (top) has 0/U fixedValue uniform (1 0 0).
Set boundary conditions so that fixedWalls (left, right, bottom) have 0/U noSlip.
Set 0/p to zeroGradient on all walls.
Set the pressure reference using pRefCell and pRefValue in system/fvSolution.
Set frontAndBack to empty.
In system/controlDict set application to icoFoam.
Choose reasonable best-practice values for endTime, deltaT, maxCo, whether to use adjustTimeStep, the OpenFOAM version, the OpenFOAM distribution, and the residual-based convergence criterion definition (even though the run will not stop automatically based on it).
