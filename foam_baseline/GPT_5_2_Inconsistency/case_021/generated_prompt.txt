Set up a 2D, incompressible, steady-state simulation of airflow over a symmetric airfoil using the simpleFoam solver.  
Use a C-grid topology computational domain around the airfoil.  
Make the mesh one cell thick in the z-direction to represent a 2D case.  
In system/blockMeshDict, define the frontAndBack patch in the boundary entry as type wall with faces including (0 4 7 3) and (1 2 6 5), plus the remaining faces belonging to that patch.  
In 0/U, set a uniform inlet velocity of (10 0 0) m/s.  
In 0/U, set the outlet to zeroGradient.  
In 0/U, set the airfoil surface to noSlip.  
In 0/U, set the frontAndBack patches to noSlip.  
In 0/p, set the inlet to zeroGradient.  
In 0/p, set the airfoil surface to zeroGradient.  
In 0/p, set the outlet to fixedValue uniform 0.  
In 0/p, set the frontAndBack patches to zeroGradient.  
Where unspecified, choose reasonable best-practice assumptions for the airfoil profile and chord length, angle of attack, Reynolds number or kinematic viscosity, turbulence/laminar modeling approach, turbulence model if applicable, farfield domain size, near-wall resolution target, SI units and chord scaling, and OpenFOAM version.
