Create initial condition field files in the 0/ directory for a three-phase settling tank case using multiphaseEulerFoam.
Assume a standard modern OpenFOAM header format consistent with OpenFOAM v10 style.
Use phase names exactly: sediment, water, oil.
Create 0/alpha.sediment as a volScalarField with dimensions [0 0 0 0 0 0 0].
Create 0/alpha.water as a volScalarField with dimensions [0 0 0 0 0 0 0].
Create 0/alpha.oil as a volScalarField with dimensions [0 0 0 0 0 0 0].
In each file’s FoamFile header, set class to volScalarField.
In each file’s FoamFile header, set location to "0".
In each file’s FoamFile header, set object to match the field name (alpha.sediment, alpha.water, alpha.oil).
Set the default (pre-setFields) internalField to represent a tank full of water: alpha.water internalField uniform 1; alpha.sediment internalField uniform 0; alpha.oil internalField uniform 0;.
Apply zeroGradient boundary conditions for alpha.sediment, alpha.water, and alpha.oil on all boundary patches present in constant/polyMesh/boundary (including walls and any inlet/outlet patches if present).
Leave the stratification to be applied later via setFieldsDict modifying these initial fields.
