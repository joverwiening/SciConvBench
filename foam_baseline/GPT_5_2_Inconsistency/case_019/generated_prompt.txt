Set up an OpenFOAM reactingFoam case for a 2-D opposed-jet laminar counter-flow diffusion flame in a rectangular domain with x = 0 to 0.02 m, y = -0.01 to 0.01 m, z = -0.01 to 0.01 m.
Use a mesh with 100 cells in x, 40 cells in y, and 1 cell in z.
Name the left boundary at x = 0 as fuel.
Name the right boundary at x = 0.02 as air.
Name the top and bottom boundaries as outlet.
Set the frontAndBack faces to empty.
Run at 1 atm with initial/internal pressure p = 101325 Pa.
Use reactingFoam with laminar momentum transport and laminar combustion modeling.
Use incompressible finite-rate chemistry with heRhoThermo.
Set mixture = coefficientWilkeMultiComponentMixture.
Set transport = Sutherland.
Set thermodynamics = JANAF.
Use a detailed methane–air mechanism such as GRI-Mech 3.0 with the standard GRI species set for CH4/O2/N2.
Set chemistry type = EulerImplicit.
Set ODE solver = Rosenbrock43.
At the fuel inlet, set U = (0.1 0 0) m/s, inject CH4 at about 293 K, set p to zeroGradient, and set species mass fractions to methane (CH4 = 1, others = 0).
At the air inlet, set U = (-0.1 0 0) m/s, set T = 293 K, set p to zeroGradient, and set species mass fractions to Y_O2 = 0.23 with the balance N2.
Initialize the domain at time 0 with T = 2000 K.
On the outlet patches (top and bottom), set U = zeroGradient.
On the outlet patches (top and bottom), set T = zeroGradient.
On the outlet patches (top and bottom), set p = fixedValue 101325 Pa.
On the outlet patches (top and bottom), set all species mass fractions Y* to zeroGradient.
Use a timestep of 1e-4 s.
Run to an end time of 0.5 s.
Write results every 0.05 s.
