Set up a steady-state 2D natural convection simulation in a square cavity. The left wall is hot (310 K) and the right wall is cold (290 K), while the top and bottom walls are adiabatic. Use the `buoyantBoussinesqSimpleFoam` solver. Gravity acts in the -y direction, g = (0 -9.81 0). The fluid is air. For thermophysical properties in `constant/thermophysicalProperties`, use `thermoType hePsiThermo;` with the following settings: `mixture pureMixture; transport const; thermo hConst; equationOfState Boussinesq; specie hConst; energy sensibleEnthalpy;`. In the `BoussinesqCoeffs` sub-dictionary, set `T0 300; beta 0.00333; rho0 1.176;`. For transport properties in `constant/transportProperties`, set `nu 1.53e-5;` and `Pr 0.7;`. In the `0/T` file, set the left wall to `fixedValue uniform 310;`, the right wall to `fixedValue uniform 290;`, and top/bottom walls to `zeroGradient;`. For velocity `0/U`, use `noSlip` on all walls. For pressure `0/p_rgh`, use `fixedFluxPressure` on all walls.
