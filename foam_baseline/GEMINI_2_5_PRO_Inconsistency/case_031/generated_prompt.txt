Set up a 2D incompressible laminar flow simulation in a rectangular channel using the icoFoam solver.
The channel is 0.5 m long in the x-direction and 0.1 m high in the y-direction.
The mesh is one cell thick in the z-direction.
The mesh has 100 cells in the x-direction and 20 cells in the y-direction.
The kinematic viscosity of the fluid is 0.001 m^2/s.
The simulation end time is 2.0 seconds.
Simulation data is saved every 0.1 seconds.
The maximum Courant number for time step control is 0.5.
The geometry and patches are defined in blockMeshDict.
The patches are named inlet, outlet, topWall, bottomWall, and frontAndBack.
The frontAndBack patches are of type wall.
The simulation models Poiseuille flow.
In the '0/U' file, set a parabolic inlet velocity profile with a maximum of 1 m/s.
In the '0/U' file, set a zeroGradient boundary condition at the outlet.
In the '0/U' file, set noSlip boundary conditions on the topWall and bottomWall patches.
In the '0/U' file, set a noSlip boundary condition on the frontAndBack patches.
In the '0/p' file, set a fixedValue of 0 at the outlet.
In the '0/p' file, set a zeroGradient boundary condition on the inlet, topWall, bottomWall, and frontAndBack patches.
