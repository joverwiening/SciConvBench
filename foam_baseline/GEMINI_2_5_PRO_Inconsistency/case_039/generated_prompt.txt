Set up a 2D dam-break simulation using the interFoam solver.
The computational domain dimensions are 4 meters in length (x-direction) and 2 meters in height (y-direction).
The mesh is 2D, extruded one cell in the spanwise direction.
The mesh resolution is 200 cells in the x-direction and 100 cells in the y-direction.
The front and back boundaries are of type empty.
Set gravity to (0 -9.81 0).
Track the water-air interface using the VOF field alpha.water.
Initialize a water column of 1 meter width and 1 meter height at the origin.
Use the setFields utility to initialize alpha.water to 1 inside the water column and 0 elsewhere.
Use standard physical properties for water and air at atmospheric conditions.
For the tank walls, use a noSlip boundary condition for U.
For the tank walls, use a zeroGradient boundary condition for p_rgh.
For the tank walls, use a zeroGradient boundary condition for alpha.water.
For the open top boundary, use a pressureInletOutletVelocity boundary condition for U.
For the open top boundary, use a totalPressure boundary condition with a fixed value of 0 for p_rgh.
For the open top boundary, use an inletOutlet boundary condition for alpha.water with an inletValue of uniform 0.
The simulation end time is 3 seconds.
