Set up a transient simulation of 2D laminar, incompressible flow past a cylinder.
The goal is to observe the von Kármán vortex street.
The Reynolds number is 100.
The domain is a rectangular channel 2.2m long and 0.41m high.
A cylinder with a diameter of 0.1m is centered at (0.2, 0.2).
The kinematic viscosity is 1e-3 m²/s.
The inlet velocity is a uniform U = (1 0 0) m/s.
The mesh is one cell thick in the z-direction.
Use the `pimpleFoam` solver for the transient simulation.
Set the start time to 0 and the end time to 200.
Set the initial time step `deltaT` to 1.
Set the write interval to 10.
Enable automatic time step adjustment to satisfy a maximum Courant number.
The maximum Courant number is 0.9.
For the `U` field, the inlet boundary condition is `fixedValue uniform (1 0 0)`.
For the `U` field, the outlet boundary condition is `zeroGradient`.
For the `U` field, the cylinderWall and topAndBottom boundary conditions are `noSlip`.
For the `U` field, the frontAndBack boundary condition is `empty`.
For the `p` field, the outlet boundary condition is `fixedValue uniform 0`.
For the `p` field, the inlet, cylinderWall, and topAndBottom boundary conditions are `zeroGradient`.
For the `p` field, the frontAndBack boundary condition is `empty`.
Use the `backward` scheme for the time derivative term `ddt(U)`.
Use the `Gauss linearUpwindV grad(U)` scheme for the convection term `div(phi,U)`.
Use the `Gauss linear` scheme for all gradient terms.
Use the `GAMG` solver for the pressure equation `p`.
Use the `PBiCGStab` solver with a `DILU` preconditioner for the velocity equation `U`.
Generate a suitable mesh using `blockMesh` with refinement around the cylinder and in the wake region.
Run the simulation to obtain the time-dependent flow field.
