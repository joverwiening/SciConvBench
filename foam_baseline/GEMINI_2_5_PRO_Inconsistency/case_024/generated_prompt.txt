Set up an axisymmetric simulation of swirling flow inside a pipe using the simpleFoam solver.
The mesh is a 2D wedge geometry with a 5-degree angle in the tangential direction.
The mesh is one cell thick in the tangential direction.
The pipe has a length of 1.0 meters.
The pipe has a diameter of 0.1 meters.
The mesh contains 200 cells in the axial direction.
The mesh contains 50 cells in the radial direction.
The system/blockMeshDict defines an `axis` patch for the axial centerline.
The system/blockMeshDict defines a `wall` patch for the pipe surface.
The system/blockMeshDict defines `inlet` and `outlet` patches.
The front and back planes of the wedge are defined as `empty` patches.
The simulation uses the k-omega SST turbulence model.
The flow has a Reynolds number of 10,000.
The inlet axial velocity is a uniform 1.0 m/s.
The inlet tangential velocity profile corresponds to solid-body rotation.
