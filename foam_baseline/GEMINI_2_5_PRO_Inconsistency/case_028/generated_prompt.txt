Create a 2D simulation of laminar, incompressible flow in a channel using the icoFoam solver.
The mesh will be generated using blockMesh.
The simulation domain is 1 meter long, 0.1 meters high, and 0.01 meters deep.
The mesh will have 100 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.
The boundaries are named inlet, outlet, topWall, bottomWall, and frontAndBack.
The frontAndBack patches are of type empty.
The fluid's kinematic viscosity is 1e-5 m^2/s.
The inlet velocity is a uniform value of (0.1 0 0) m/s.
The outlet pressure is a fixed uniform value of 0.
The outlet velocity boundary condition is zeroGradient.
The topWall and bottomWall boundaries have a no-slip velocity boundary condition.
The pressure boundary condition for the inlet, topWall, and bottomWall is zeroGradient.
The simulation will run until an end time of 50 seconds.
The time step will be automatically adjusted to maintain a maximum Courant number of 0.5.
Simulation results will be written to disk every 1 second of simulation time.
Use default second-order discretization schemes.
Use default solver settings for the icoFoam solver.
