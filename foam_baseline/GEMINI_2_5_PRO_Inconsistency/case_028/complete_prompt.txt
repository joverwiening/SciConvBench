Create a 2D simulation of laminar, incompressible flow through a simple channel using the `icoFoam` solver. The mesh should be generated with `blockMesh`. The simulation domain is 1m long, 0.1m high, and 0.01m deep. The mesh should be one cell thick in the z-direction to model the 2D case. The `blockMeshDict` defines the boundaries as `inlet`, `outlet`, `topWall`, `bottomWall`, and `frontAndBack`. The `frontAndBack` patches, representing the 2D plane, must be defined with the `empty` type to ensure 2D behavior:

```
boundary
(
    // ... other patches
    frontAndBack
    {
        type            empty;
        faces
        (
            (0 4 7 3)
            (1 2 6 5)
        );
    }
);
```

The velocity at the `topWall` and `bottomWall` is set to no-slip `(0 0 0)`.
