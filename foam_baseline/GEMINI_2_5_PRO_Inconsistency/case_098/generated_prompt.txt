Set up a 2D axisymmetric simulation of swirling flow in a pipe.
Use the simpleFoam solver.
The simulation will be turbulent.
Use the k-epsilon turbulence model.
The fluid has a kinematic viscosity of 1e-6 m^2/s.
The pipe has a radius of 0.05 meters.
The pipe has a length of 1.0 meter.
Create a 5-degree wedge mesh using blockMeshDict.
The mesh should have 100 cells in the axial direction.
The patches are named inlet, outlet, wall, front, and back.
The inlet patch type is patch.
The outlet patch type is patch.
The wall patch type is wall.
The front patch type is symmetryPlane.
The back patch type is symmetryPlane.
For the velocity field U, apply a swirling inlet condition.
The axial component of the inlet velocity is 1 m/s.
The swirl number at the inlet is 0.5.
Apply a noSlip boundary condition for velocity on the wall patch.
Apply a zeroGradient boundary condition for velocity on the outlet patch.
Apply a symmetryPlane boundary condition for velocity on the front and back patches.
Apply a fixedValue boundary condition with a value of 0 for pressure at the outlet.
The turbulence intensity at the inlet is 5%.
