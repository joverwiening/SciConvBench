Set up a 2D axisymmetric simulation of swirling flow in a pipe using a wedge mesh of 5 degrees created with blockMeshDict. Use the simpleFoam solver. The patches are inlet, outlet, wall, front, and back.

In constant/polyMesh/boundary, define the patches as follows:

inlet
{
    type patch;
}

outlet
{
    type patch;
}

wall
{
    type wall;
}

front
{
    type wedge;
}

back
{
    type wedge;
}

For the velocity field U, apply a swirling inlet condition, noSlip on wall, zeroGradient on outlet, and wedge on front and back.
