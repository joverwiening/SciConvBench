Set up a 2D dam break simulation using the interFoam solver.
The simulation is for a two-phase water-air system.
The domain is 2m long and 1m high.
The domain has a single cell in the z-direction.
Gravity is defined as (0 -9.81 0) in the 'constant/g' file.
The front and back patches are named 'frontAndBack' and have the type 'wall'.
The bottom patch is named 'bottomWall'.
The top patch is named 'atmosphere'.
The left patch is named 'leftWall'.
The right patch is named 'rightWall'.
The 'frontAndBack' patches use the 'noSlip' boundary condition for the velocity field (U).
The 'bottomWall', 'leftWall', and 'rightWall' patches use the 'noSlip' boundary condition for the velocity field (U).
The 'atmosphere' patch uses the 'pressureInletOutletVelocity' boundary condition for the velocity field (U).
The 'frontAndBack' patches use the 'zeroGradient' boundary condition for the pressure field (p_rgh).
The 'bottomWall', 'leftWall', and 'rightWall' patches use the 'fixedFluxPressure' boundary condition for the pressure field (p_rgh).
The 'atmosphere' patch uses the 'totalPressure' boundary condition with a value of 0 for the pressure field (p_rgh).
The 'frontAndBack' patches use the 'zeroGradient' boundary condition for the phase fraction field (alpha.water).
The initial water column is defined using the setFieldsDict utility.
