Perform a transient simulation of a Rayleigh-Bénard convection cell.
Use the `buoyantPimpleFoam` solver.
The domain is a 2D rectangle.
The width of the domain is 0.02 meters.
The height of the domain is 0.01 meters.
The fluid is water.
Use the Boussinesq approximation for density.
In `constant/thermophysicalProperties`, set `thermoType` to `hePsiThermo`.
In `constant/thermophysicalProperties`, set `equationOfState` to `Boussinesq`.
Use appropriate thermophysical coefficients for water to achieve a target Rayleigh number of 1e6.
The bottom wall is heated to a constant temperature of 305 K.
The top wall is cooled to a constant temperature of 295 K.
The side walls have an adiabatic (zero gradient) temperature boundary condition.
The top and bottom walls have a no-slip velocity boundary condition.
The side walls have a slip velocity boundary condition.
In `system/fvSchemes`, use `Gauss linear` for the divergence of temperature (`div(phi,T)`).
In `system/fvSchemes`, use `Gauss upwind` for the density-weighted divergence of velocity (`div(rhoPhi,U)`).
The mesh should have 100 cells in the horizontal direction.
The mesh should have 50 cells in the vertical direction.
The simulation end time should be sufficient to observe the development of a stable convection pattern.
The maximum Courant number for time step control should be 0.5.
