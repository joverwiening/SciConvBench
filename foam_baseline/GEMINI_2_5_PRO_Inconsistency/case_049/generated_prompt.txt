Set up a 2D simulation of incompressible, laminar flow over an airfoil using the simpleFoam solver.
The mesh is extruded one cell in the z-direction.
The airfoil profile is a NACA 0012.
The kinematic viscosity of the fluid is 1.5e-5 m^2/s.
The freestream velocity magnitude is 1 m/s.
The airfoil is at a 4-degree angle of attack.
The simulation type in `constant/turbulenceProperties` is set to `laminar`.
The inlet patch is named `inlet`.
The outlet patch is named `outlet`.
The airfoil surface patch is named `airfoil`.
The top and bottom boundaries of the domain are a single patch named `topAndBottom`.
The out-of-plane faces are a single patch named `frontAndBack`.
In `constant/polyMesh/boundary`, the `frontAndBack` patch type is `wall`.
For the velocity field `U`, the inlet boundary condition is a fixed value corresponding to the freestream velocity and angle of attack.
For the velocity field `U`, the outlet boundary condition is `zeroGradient`.
For the velocity field `U`, the airfoil boundary condition is `noSlip`.
For the velocity field `U`, the `topAndBottom` boundary condition is `slip`.
For the velocity field `U`, the `frontAndBack` boundary condition is `slip`.
For the pressure field `p`, the inlet boundary condition is `zeroGradient`.
For the pressure field `p`, the outlet boundary condition is a fixed value of 0.
For the pressure field `p`, the airfoil boundary condition is `zeroGradient`.
For the pressure field `p`, the `topAndBottom` boundary condition is `zeroGradient`.
For the pressure field `p`, the `frontAndBack` boundary condition is `slip`.
Use standard second-order numerical schemes and standard solver settings for `simpleFoam`.
The simulation should run for a sufficient number of iterations to reach a converged steady-state solution.
