Set up a 2D lid-driven cavity flow simulation.
The solver application to use is icoFoam.
The domain is a 1 m by 1 m square.
The domain is extruded by one cell in the z-direction.
The front and back boundaries are of type empty.
The mesh is uniform with a resolution of 40 by 40 by 1 cells.
The fluid is incompressible and Newtonian.
The kinematic viscosity is 0.01 m^2/s.
The simulation is transient.
The simulation should be run until a steady-state solution is reached.
The top boundary is named movingLid.
The velocity on the movingLid boundary is a fixed value of (1 0 0) m/s.
The left, right, and bottom boundaries are grouped as fixedWalls.
The velocity on the fixedWalls boundary has a noSlip condition.
The pressure boundary condition on all walls is zeroGradient.
The pressure reference is set using pRefCell and pRefValue.
The reference pressure cell index, pRefCell, is 0.
The reference pressure value, pRefValue, is 0.
The time step, deltaT, is 0.005 seconds.
The end time of the simulation is 10 seconds.
The divergence scheme for the velocity flux, div(phi,U), is Gauss upwind.
The time derivative scheme is Euler.
The gradient scheme is Gauss linear.
The Laplacian scheme is Gauss linear corrected.
The interpolation scheme is linear.
The surface-normal gradient scheme is corrected.
The PISO algorithm will use 2 correctors.
The pressure equation will be solved with the PCG solver using a DIC preconditioner.
The velocity equation will be solved with the PBiCG solver using a DILU preconditioner.
Simulation results will be written every 0.1 seconds of simulation time.
