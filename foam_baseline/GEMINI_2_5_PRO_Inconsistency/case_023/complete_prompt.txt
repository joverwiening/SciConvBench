Perform a 2D simulation of developing flow in a channel. To reduce computational cost, only the bottom half of the channel is meshed, and a symmetry plane is used at the channel centerline. The solver is `simpleFoam`. The `system/blockMeshDict` defines the patches as `inlet`, `outlet`, `bottomWall`, and `centerline`. The `frontAndBack` patches are correctly set to `type empty;`. The `centerline` patch must be defined as a symmetry plane:

```
    centerline
    {
        type            symmetry;
        faces
        (
            (3 7 6 2)
        );
    }
```

In `0/U`, the boundary condition for `centerline` must also be `symmetry`.
