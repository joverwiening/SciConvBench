Set up a three-dimensional, transient dam break simulation.
Use the multiphaseEulerFoam solver.
The simulation will model three phases: water, air, and a light oil.
The phases are to be named `water`, `air`, and `oil` in the `transportProperties` file.
The simulation domain is a rectangular tank with dimensions 1m (x) by 0.4m (y) by 0.6m (z).
Gravity is applied in the negative y-direction.
Use a standard, physically reasonable value for the density of water.
Use a standard, physically reasonable value for the density of the light oil.
Use a standard, physically reasonable value for the density of air.
Use a standard, physically reasonable value for the kinematic viscosity of water.
Use a standard, physically reasonable value for the kinematic viscosity of the light oil.
Use a standard, physically reasonable value for the kinematic viscosity of air.
Initialize the fields using the `setFieldsDict` utility.
A column of water is initially located in the region defined by the minimum point (0, 0, 0) and the maximum point (0.2, 0.2, 0.6).
A layer of oil is initially located on top of the water, in the region from (0, 0.2, 0) to (0.2, 0.25, 0.6).
The rest of the domain is to be filled with air.
All wall boundaries must have a no-slip condition.
The top boundary of the domain is an atmospheric inlet/outlet.
