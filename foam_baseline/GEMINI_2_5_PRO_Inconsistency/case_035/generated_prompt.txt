Configure a 2D simulation of flow past a cylinder using the pimpleFoam solver.
The simulation is for a transient, incompressible, laminar case.
The mesh is one cell thick.
The 'frontAndBack' patch type is 'empty' in the 'constant/polyMesh/boundary' file.
The boundary condition for the 'frontAndBack' patch in all field files is 'empty'.
The simulation will be based on a Reynolds number of 100.
The cylinder diameter is 1 meter.
The kinematic viscosity of the fluid is 0.01 m^2/s.
The magnitude of the uniform inlet velocity is 1 m/s.
The simulation end time is 60 seconds.
The maximum Courant number for time step control is 0.8.
