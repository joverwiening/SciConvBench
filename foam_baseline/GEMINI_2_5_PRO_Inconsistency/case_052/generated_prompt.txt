Set up a 2D lid-driven cavity simulation using the nonNewtonianIcoFoam solver.
The simulation domain is a 1m x 1m square cavity.
The mesh will be one cell thick in the z-direction with 'empty' boundary conditions on the front and back faces to ensure 2D behavior.
The top wall moves with a velocity of (1 0 0) m/s.
The other three walls are stationary with a no-slip boundary condition.
The simulation is transient.
The fluid is a non-Newtonian, shear-thinning fluid using the Power Law model.
The Power Law properties are nuMax=1, nuMin=1e-6, k=0.1, and n=0.5.
The simulation will run until the flow reaches a quasi-steady state.
A mesh of 40x40 cells will be used.
The mesh will be graded towards the walls to better resolve boundary layers.
The maximum Courant number will be 0.5.
The simulation end time will be sufficient to allow the flow to develop.
Standard second-order discretization schemes will be used.
The initial condition for velocity is (0 0 0) m/s.
The initial condition for pressure is 0.
