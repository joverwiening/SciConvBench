Run a two-dimensional Rayleigh-Benard convection simulation using the buoyantFoam solver.
The simulation domain is a rectangular cavity 9 units wide and 1 unit tall.
The mesh consists of 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.
The front and back boundaries are set to the `empty` patch type to enforce a 2D simulation.
Gravity acts in the negative y-direction.
The simulation uses the Boussinesq approximation for an air-like fluid.
The reference density rho0 is 1.0 kg/m³.
The reference temperature T0 is 300 K.
The thermal expansion coefficient beta is 3.3e-3 1/K.
The dynamic viscosity mu is 1.5e-5 kg/(m*s).
The Prandtl number Pr is 0.714.
The thermophysical properties are defined using `heRhoThermo` with the `Boussinesq` equation of state.
The RAS k-epsilon turbulence model is enabled.
The bottom wall is a fixed temperature boundary at 305 K.
The top wall is a fixed temperature boundary at 295 K.
The vertical side walls are adiabatic, using a `zeroGradient` boundary condition for temperature.
All solid walls use a no-slip boundary condition for velocity.
The initial velocity field is uniform at (0 0 0).
The initial temperature field is uniform at 300 K.
The simulation end time is 1000 seconds.
A fixed time step of 1 second is used.
Simulation results are written to disk every 50 time steps.
The temporal derivative scheme is Euler.
The gradient scheme is Gauss linear.
The divergence scheme for velocity is Gauss linearUpwindV.
The divergence schemes for turbulence and energy fields are Gauss upwind.
The laplacian scheme is Gauss linear corrected.
Solvers for p_rgh, U, e, k, and epsilon are configured with a tolerance of 1e-8 and a relative tolerance of 0.01.
The final solvers for all fields have a relative tolerance of 0.
Initial and boundary conditions for k, epsilon, nut, alphat, p, and p_rgh are set as specified in the detailed user request.
