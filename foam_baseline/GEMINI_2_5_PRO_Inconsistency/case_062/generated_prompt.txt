Simulate the static deflection of a 2D cantilever beam using linear elasticity.
Use the solidDisplacementFoam solver.
The simulation will assume plane stress conditions.
The beam is 1.0 m long and 0.1 m high.
Use a structured mesh of 100 cells in the x-direction and 10 cells in the y-direction.
The material is aluminum with a Young's modulus of 70e9 Pa and a Poisson's ratio of 0.33.
Do not include body forces due to gravity.
The boundary at x=0 is a fixed end with zero displacement.
The boundary at x=1 has a uniform downward traction of -10000 N/m^2 applied.
The top and bottom surfaces of the beam have zero-gradient boundary conditions.
Use the Gauss linear scheme for gradient terms.
Use the Gauss linear scheme for divergence terms.
Solve for the displacement field using the PCG solver.
Use the DIC preconditioner for the displacement solver.
Set the solver tolerance for displacement to 1e-6.
Set the solver relative tolerance for displacement to 0.
Run the simulation for a single static step.
