Set up a CFD simulation of airflow in a ventilated room using OpenFOAM's buoyantSimpleFoam solver.
Room dimensions will be 4m x 5m x 3m (length x width x height).
Use a heater wall patch with a fixed temperature of 320 K.
Inlet air temperature is 293 K.
Model natural convection driven by the heater.
In constant/thermophysicalProperties, use:
- thermoType: heRhoThermo
- Equation of state: Boussinesq
- T0: 293 K
- beta: 0.00341
- rho0: 1.2 kg/m³
Transport model: const
- mu: 1.8e-5 Pa·s
- Pr: 0.71
Mesh resolution: Use a fine grid with approximately 0.05m cell size near heater and boundaries.
Heater wall thickness: 0.01m.
Side wall boundary conditions: No-slip wall conditions.
