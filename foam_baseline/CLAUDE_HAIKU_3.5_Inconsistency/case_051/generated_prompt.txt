Simulate a transient start-up flow of a Bingham plastic fluid in a 2D pipe using OpenFOAM v2206.
Use the `nonNewtonianIcoFoam` solver for the simulation.
Create a rectangular domain with 1.0m length and 0.1m diameter.
Generate a mesh using `blockMesh` with 100 cells in the axial (x) direction and 20 cells in the radial (y) direction.
Set front and back patches as type `empty`.
Define boundary conditions:
Inlet: fixed velocity of `(0.1 0 0)` m/s
Outlet: `zeroGradient` for velocity and fixed pressure of 0
Walls: `noSlip`
Run the simulation from t=0 to t=5s.
In `constant/transportProperties`, define the Bingham plastic fluid with the following properties:
transportModel as BinghamPlastic
Density (rho) = 1000 kg/m³
Yield stress (tau0) = 10 Pa
Minimum viscosity (mu0) = 0.1 Pa·s
Infinite shear viscosity (muInf) = 0.01 Pa·s
