Set up a 2D laminar, incompressible flow simulation of flow past a cylinder using OpenFOAM.
Use `blockMesh` for computational domain generation.
Create a rectangular channel domain 2.2m long and 0.41m high.
Place a cylinder with 0.1m diameter centered at (0.2, 0.2).
Use kinematic viscosity of 1e-3 m²/s.
Set uniform inlet velocity of U = (1 0 0) m/s.
Create a mesh one cell thick in z-direction.
Use approximately 50 cells in x-direction and 30-40 cells in y-direction.
Apply structured mesh refinement near cylinder wall with geometric progression ratio of 1.2.
Target y+ value around 1 for viscous effect resolution.
Use `simpleFoam` solver in `system/controlDict`.
Set `startTime` to 0, `endTime` to 200, `deltaT` to 1, and `writeInterval` to 10.
Configure boundary conditions in `0/` directory as specified in original requirement.
Run simulation to obtain final steady-state flow field.
