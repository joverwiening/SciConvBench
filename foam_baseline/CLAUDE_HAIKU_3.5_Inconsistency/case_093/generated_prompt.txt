Set up a 2D dam break simulation using the following specifications:
Domain dimensions will be 5m long by 1m high (5:1 aspect ratio).
Water column initial height will be 0.5m.
Water column will be positioned at the left side of the domain.
Use pimpleFoam solver for the simulation.
Set endTime in controlDict to 5 seconds.
Use setFields to initialize alpha.water = 1 for water column and alpha.water = 0 for air.
Set gravity as g = (0 -9.81 0).
Configure transportProperties dictionary with water and air phase properties.
Simulate two-phase flow with water and air phases.
Perform 2D simulation using OpenFOAM.
