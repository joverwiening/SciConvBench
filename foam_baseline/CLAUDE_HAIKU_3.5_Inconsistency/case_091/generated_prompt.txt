Simulate natural convection in a 2D square cavity using the de Vahl Davis case.
Use a 100x100 grid resolution.
Set the cavity physical dimensions to 1m x 1m square.
Fill the cavity with air.
Set the left wall temperature to 300 K.
Set the right wall temperature to 290 K.
Set the top and bottom walls to have a temperature of 295 K.
Use adiabatic boundary conditions for the top and bottom walls.
Apply noSlip boundary condition for velocity on all walls.
Use gravity acting downwards in the -y direction, g = (0 -9.81 0).
Apply the Boussinesq approximation for buoyancy.
Use laplacianFoam as the solver.
Set the Prandtl number to 0.71.
Set the Rayleigh number to 10^5.
