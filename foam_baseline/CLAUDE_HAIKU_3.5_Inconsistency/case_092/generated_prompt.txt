Simulate compressible supersonic flow over a 10-degree wedge using OpenFOAM.
Use `rhoPimpleFoam` as the solver.
Use k-ω SST turbulence model for turbulence closure.
Freestream Mach number is 2.0.
Treat air as a perfect gas.
Create a 2D mesh extruded one cell in z-direction with `frontAndBack` set to `empty`.
Freestream conditions: 
- Velocity `U = (686 0 0) m/s`
- Temperature `T = 293 K`
- Pressure `p = 101325 Pa`
Configure perfect-gas model in `constant/thermophysicalProperties`.
Set boundary conditions:
- Inlet: fixed values for `U`, `p`, and `T`
- Outlet: `waveTransmissive` for `p` and `T`, `zeroGradient` for `U`
- Wedge surface and top boundary: slip wall
- Front and back boundaries: `empty`
