Configure a 2D bubble column simulation using twoPhaseEulerFoam.
The column dimensions are 0.5m wide (X-direction) and 2m high (Y-direction).
The initial fluid is water.
Air is injected from a sparger at the bottom center.
Simulation goal is to observe air bubble rise due to buoyancy.
Phases are air (dispersed) and water (continuous).
Gravity vector is set to `g (-9.81 0 0)`.
Bottom boundary is an inlet patch with `alpha.air` set to `fixedValue 1` and `U.air` set to `fixedValue (0 0.1 0)`.
Top boundary is an outlet.
Side walls are `noSlip`.
Front and back patches are `empty`.
Mesh resolution will be approximately 0.01m (1 cm) grid size.
Expected bubble diameter is around 0.005m (5 mm).
Computational resources assumed to be 4 CPU cores with 16 GB RAM.
