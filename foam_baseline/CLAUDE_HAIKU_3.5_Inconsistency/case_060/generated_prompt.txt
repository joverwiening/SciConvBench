Set up the classic 2D dam-break problem using OpenFOAM with the following specifications:

Use a computational domain with the following characteristics:
Total domain length in x-direction: 4.0 meters
Total domain height: 1.0 meters
Initial water column height: 0.5 meters (50% of total domain height)
Initial water column width: 0.5 meters
Domain depth in z-direction: 0.1 meters (single cell extrusion)

Grid resolution:
Number of cells in x-direction: 200 cells
Number of cells in y-direction: 50 cells
Number of cells in z-direction: 1 cell

Simulation setup:
Use `twoPhaseEulerFoam` application
Set `alpha.water = 1` inside the water column
Set `alpha.water = 0` outside the water column
Use `frontAndBack` boundary condition set to `empty`

Initialization method:
Use `setFields` to define water column volume fraction
