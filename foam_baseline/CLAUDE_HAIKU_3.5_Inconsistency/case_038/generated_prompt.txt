Simulate thermo-elastic deformation of an aluminum block with the following specifications:

Geometry is a perfect cube with dimensions 0.1 m x 0.1 m x 0.1 m.
Mesh is a uniform 20x20x20 grid, resulting in cell size of 0.005 m (5 mm).
Material is aluminum with following properties:
Young's modulus E = 69e9 Pa
Poisson's ratio nu = 0.33
Density rho = 2700 kg/m^3
Thermal expansion coefficient alpha = 2.3e-5 1/K
Reference temperature T0 = 300 K

Boundary conditions for displacement (0/D):
Fixed face has uniform zero displacement (0 0 0)
Other faces have zero gradient displacement

Boundary conditions for temperature (0/T):
Heated face is set to 400 K
Fixed face has zero gradient temperature
Other faces have zero gradient temperature

Simulation application will use buoyantPimpleFoam.

Goal is to compute displacement and stress due to thermal expansion.
