Simulate a steady-state, two-phase (oil–water) flow in a horizontal pipe using `twoPhaseEulerFoam`.
Use a standard research-scale horizontal pipe with 50 mm diameter.
Set pipe length to 10 pipe diameters (500 mm) to ensure fully developed flow.
Set inlet mixture velocity to 2 m/s.
Impose a fixed water volume fraction `alpha.water = 0.3` at the inlet.
Use `noSlip` boundary condition on pipe walls.
Set outlet `alpha.water` to a fixed value of 0.3 using `fixedValue` type.
