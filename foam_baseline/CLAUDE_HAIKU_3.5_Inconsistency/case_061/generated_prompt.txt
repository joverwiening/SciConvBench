Set up a 2D lid-driven cavity flow simulation in OpenFOAM using the icoFoam solver.
Use a 1 m × 1 m square domain extruded one cell in z with frontAndBack as empty.
Create a uniform mesh of 40 × 40 × 1 cells.
Use an incompressible Newtonian fluid with kinematic viscosity nu = 0.01 m^2/s.
Simulate at Reynolds number 100.
Set boundary conditions:
Top lid (movingLid): velocity 0/U as fixedValue uniform (1 0 0)
Left, right, and bottom walls (fixedWalls): velocity 0/U as noSlip
Pressure 0/p with zeroGradient on all walls
Use pRefCell and pRefValue in system/fvSolution to set pressure reference
Front and back boundaries set as empty
Use time step of 0.01 seconds
Converge simulation when normalized residuals drop below 10^-4
Stop simulation when maximum velocity changes between iterations are < 10^-5 m/s
