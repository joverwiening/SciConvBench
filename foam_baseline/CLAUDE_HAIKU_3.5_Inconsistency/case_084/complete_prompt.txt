Set up a transient two-phase Euler–Euler gas–solid riser simulation with phases `(air catalyst)` using `twoPhaseEulerFoam`. At the inlet, prescribe a dilute solids loading with `alpha.catalyst = 0.01` and set the gas volume fraction accordingly so that the phase fractions sum to 1.

In `0/alpha.catalyst`, set:
```foam
inlet
{
    type            fixedValue;
    value           uniform 0.01;
}
```

In `0/alpha.air`, set:
```foam
inlet
{
    type            fixedValue;
    value           uniform 0.99;
}
```
