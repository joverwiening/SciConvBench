Set up a 2D, steady-state, incompressible, turbulent simulation of airflow over a NACA0012 airfoil.
Use the simpleFoam solver with the k-omega SST turbulence model.
Create the NACA0012 airfoil geometry using standard coordinates with approximately 100 points for smooth representation.
Use air as the working fluid at standard atmospheric conditions.
Set the freestream Reynolds number to 1,000,000 (typical for aerodynamic studies).
Create a C-grid type domain, one cell thick in the z-direction.
Define mesh in `constant/polyMesh`.
Use boundary patches: `inlet`, `outlet`, `airfoil`, and `frontAndBack`.
Inlet boundary conditions:
- Velocity `U`: `fixedValue` uniform (10 0 0)
- `k` and `omega`: Calculated from 1% turbulence intensity and viscosity ratio 10
- Pressure `p`: `zeroGradient`
Outlet boundary conditions:
- Velocity `U`: `inletOutlet`
- `k` and `omega`: `inletOutlet`
- Pressure `p`: `fixedValue` uniform 0
Airfoil boundary conditions:
- Velocity `U`: `noSlip`
- `k`: `kqRWallFunction`
- `omega`: `omegaWallFunction`
- Pressure `p`: `zeroGradient`
Front and back boundary conditions:
- Treated as solid walls
- Velocity `U`: `noSlip`
- Pressure `p`, `k`, and `omega`: `zeroGradient`
