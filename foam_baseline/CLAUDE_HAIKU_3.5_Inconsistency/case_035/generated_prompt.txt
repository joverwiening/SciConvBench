Simulate flow past a cylinder using pimpleFoam with the following specifications:
Reynolds number is 100.
Cylinder diameter is 1 meter.
Inlet velocity is 0.0015 m/s.
Computational domain length is 15 diameters upstream and 25 diameters downstream.
Computational domain width is 8 diameters.
Near-wall cell size is 0.01 times the cylinder diameter.
Use a structured hexahedral mesh with local refinement near the cylinder surface.
The simulation is transient, incompressible, and laminar.
The mesh is one cell thick.
'frontAndBack' patches are defined with 'symmetryPlane' type.
'0/U' file boundary condition for 'frontAndBack' is 'type wall; value uniform (0 0 0)'.
Other boundary conditions (inlet, outlet, cylinderWall) will be set appropriately for a flow-past-cylinder case.
