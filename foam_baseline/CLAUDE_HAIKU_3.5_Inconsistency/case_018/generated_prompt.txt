Use OpenFOAM v2306 (latest stable release).
Use a standard workstation with 8 CPU cores and 32 GB RAM.
Research goal is fundamental flame structure investigation of a laminar counter-flow diffusion flame.
Use GRI-Mech 3.0 chemical mechanism for methane combustion.
Use uniform mesh as specified: 100 (x) x 40 (y) x 1 (z) without local refinement.
Do not use adaptive mesh refinement (AMR).
Simulate laminar counter-flow diffusion flame with methane/air reactants.
Use computational domain: x in [0, 0.02] m, y in [-0.01, 0.01] m, z in [-0.01, 0.01] m.
Set up mesh with frontAndBack patches as empty.
Define patches: left fuel (x=0), right air (x=0.02), top outlet, bottom outlet.
Set fuel inlet as methane (CH4) at 293 K.
Set air inlet as air (O2/N2) at 293 K with Y_O2 = 0.23, balance N2.
Initialize domain temperature at 2000 K.
Set velocity at fuel inlet to +0.1 m/s in +x direction.
Set velocity at air inlet to +0.1 m/s in +x direction.
Use EulerImplicit chemistry with Rosenbrock43 ODE solver.
Model laminar combustion and momentum transport.
Use hePsiThermo thermodynamics.
Use coefficientWilkeMultiComponentMixture.
Use Sutherland transport model.
Use JANAF thermodynamic coefficients.
Set time parameters: deltaT = 1e-4 s, endTime = 0.5 s, writeInterval = 0.05 s.
