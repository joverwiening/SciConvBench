Model a steady-state buoyant flow in a solar chimney using OpenFOAM.
Use `buoyantSimpleFoam` solver.
Use Boussinesq model for buoyancy simulation.
Gravity is defined in the `constant/g` file.
Use thermophysical properties from the provided `constant/thermophysicalProperties` configuration.
Set bottom wall temperature to 350K (77°C), which is 50°C above the reference temperature of 300K.
Assume a solar chimney height of 12 meters.
Assume a solar chimney cross-sectional area of 1.5 square meters.
Use standard air properties as defined in the thermophysical properties file.
Boundary conditions for temperature will be set in the `0/T` file with 350K at the bottom wall.
