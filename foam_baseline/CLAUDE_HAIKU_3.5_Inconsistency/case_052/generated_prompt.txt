Set up a 2D lid-driven cavity simulation for a non-Newtonian, shear-thinning fluid using OpenFOAM's nonNewtonianIcoFoam solver.
Use a 1m x 1m square cavity domain.
Apply top wall (lid) velocity of (1 0 0) m/s.
Set all other walls to no-slip boundary condition.
Use Power Law non-Newtonian fluid model with following properties:
transportModel set to PowerLaw.
nuMax set to 1.
nuMin set to 1e-6.
Consistency index k set to 0.1.
Power law index n set to 0.5.
Use a 50x50 grid resolution for spatial discretization.
Set simulation time step to 0.01 seconds.
Run simulation for a total of 10 seconds to capture flow development and steady-state behavior.
Simulate at a Reynolds number approximating 1000.
Conduct transient simulation to observe flow characteristics.
