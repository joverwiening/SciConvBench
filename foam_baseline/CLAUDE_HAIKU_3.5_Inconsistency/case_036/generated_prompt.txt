Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity.

Beam geometry:
Length is 1 m.
Height is 0.1 m.
Width is 0.1 m.

Material properties:
Use steel with Young's modulus of 200e9 Pa.
Use Poisson ratio of 0.3.

Boundary conditions:
One end (fixed) is clamped with displacement set to (0 0 0).
Free end (loaded) has a traction load of (0 -1000 0) Pa.
All other faces have zero gradient boundary condition.

Solver configuration:
Use `solidDisplacementFoam` application.
Set simulation end time to 1 second.

Mesh discretization:
Use 30 elements along the beam's length.
Use standard hexahedral mesh elements.
Maintain uniform mesh density across the beam.
