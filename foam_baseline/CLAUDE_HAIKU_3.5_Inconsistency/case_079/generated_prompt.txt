Perform a transient Rayleigh-Bénard convection simulation using buoyantPimpleFoam.
Domain is a 2D rectangular cell with height of 0.1 m and width of 0.1 m (1:1 aspect ratio).
Horizontal resolution set to 0.002 m grid cell size.
Bottom boundary temperature is 305 K.
Top boundary temperature is 295 K.
Fluid is water.
Use Boussinesq approximation.
In constant/thermophysicalProperties, set thermoType to hePsiThermo.
In constant/thermophysicalProperties, set equationOfState to Boussinesq.
In system/fvSchemes, use div(phi,T) Gauss linear for temperature divergence.
In system/fvSchemes, use div(rhoPhi,U) Gauss upwind for velocity divergence.
