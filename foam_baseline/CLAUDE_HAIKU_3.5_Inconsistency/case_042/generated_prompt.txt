Simulate a 2D supersonic flow of air over a 10-degree wedge using OpenFOAM.
Use `rhoCentralFoam` solver for compressible flow simulation.
Treat air as a perfect gas using `hePsiThermo` and `perfectGas` equation of state.
Use Koren flux limiter for handling supersonic flow discontinuities.
Set freestream conditions: p = 101325 Pa, T = 300 K, U = (686 0 0) m/s.
Create a 2D mesh extruded one cell in z-direction with `frontAndBack` set to `empty`.
Set computational domain upstream length to 10 wedge lengths.
Define boundary conditions:
Inlet: fixed values for U, p, and T
Outlet: `waveTransmissive` for p and T, `zeroGradient` for U
Wedge and top boundary: slip wall
