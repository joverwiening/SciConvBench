Set up a 2D, incompressible, steady-state simulation of airflow over a symmetric airfoil.
Use the simpleFoam solver for the simulation.
Use a NACA 0012 symmetric airfoil profile.
Set the angle of attack to 0 degrees.
Use a Reynolds number of 300,000.
Create a C-grid topology domain around the airfoil.
Make the mesh one cell thick in the z-direction.
In `system/blockMeshDict`, define frontAndBack patches as walls.
In `0/U`, apply uniform inlet velocity of (10 0 0) m/s.
In `0/U`, use zero-gradient outlet condition.
In `0/U`, apply `noSlip` condition on airfoil surface.
In `0/U`, apply `noSlip` on frontAndBack patches.
In `0/p`, use `zeroGradient` for inlet and airfoil.
In `0/p`, use `fixedValue uniform 0` at the outlet.
In `0/p`, use `zeroGradient` on frontAndBack patches.
