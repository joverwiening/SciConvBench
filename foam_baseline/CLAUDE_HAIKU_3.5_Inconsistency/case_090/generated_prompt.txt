Set up a transient simulation of 2D vortex shedding behind a cylinder using OpenFOAM v2306.
Use parallel computation with 4 processors.
Simulate at Reynolds number 100.
Use a fine mesh resolution with refined grid near the cylinder.
Use a computational domain of a rectangular channel with a circular cylinder.
Employ the simpleFoam solver for incompressible flow.
Set kinematic viscosity nu = 0.01 m^2/s.
Set inlet velocity U = (1 0 0) m/s.
Set cylinder diameter as 1 m.
Define boundary conditions:
- 'inlet': fixedValue U
- 'outlet': zeroGradient U, fixedValue p=0
- 'topAndBottom': slip
- 'cylinder': noSlip
- 'frontAndBack': empty
Run simulation from t=0 to t=200 s with deltaT of 0.1 s.
Goal is to observe von Kármán vortex street and calculate Strouhal number.
Use a grid spacing of 0.01 m near the cylinder surface to resolve boundary layer and vortex dynamics.
