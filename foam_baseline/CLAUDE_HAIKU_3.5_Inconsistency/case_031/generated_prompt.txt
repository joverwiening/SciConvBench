Set up a 2D incompressible laminar flow simulation in OpenFOAM using icoFoam solver.
Channel geometry is 0.5 m long (x-direction) and 0.1 m high (y-direction).
Mesh will be one cell thick in z-direction.
Use 100 cells in x-direction and 25 cells in y-direction.
Use kinematic viscosity of water at room temperature (1×10^-6 m²/s).
Target Reynolds number between 100-200.
Create blockMeshDict with patches: inlet, outlet, topWall, bottomWall, frontAndBack.
Set frontAndBack patches as type 'wall'.
In '0/U' file, define parabolic inlet velocity profile with maximum 1 m/s.
Apply zeroGradient at outlet.
Apply noSlip conditions on topWall and bottomWall.
Apply noSlip conditions on frontAndBack patches.
In '0/p' file, use fixedValue 0 at outlet.
Use zeroGradient on all other patches, including frontAndBack.
