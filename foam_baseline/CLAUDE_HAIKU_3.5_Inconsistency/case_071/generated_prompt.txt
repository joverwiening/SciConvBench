Simulate a 2D dam break case using the interFoam solver.
The domain is a rectangle with dimensions 0.6m (length) x 0.4m (height), with the height oriented along the Y-axis.
Use blockMesh to create the geometry with a single block.
Use a mesh resolution of 0.01m (10mm) in both x and y directions.
Initial water column occupies the region x < 0.15m and y < 0.3m.
The rest of the domain is air.
Water properties: Density of 1000 kg/m³, Kinematic viscosity of 1e-6 m²/s.
Air properties: Density of 1.225 kg/m³, Kinematic viscosity of 1.5e-5 m²/s.
Gravity vector set to `g (0 0 -9.81)`.
Boundary conditions for U: `noSlip` on walls, `pressureInletOutletVelocity` on top 'atmosphere' patch.
Boundary conditions for p_rgh: `fixedFluxPressure` on walls, `totalPressure` on atmosphere.
Boundary conditions for alpha.water: `zeroGradient` on walls, `inletOutlet` on atmosphere.
Front and back patches are of type `empty` for 2D simulation.
Numerical schemes: Second-order, Gauss linear for gradient/divergence, linear interpolation, Euler time discretization.
PIMPLE settings: 3 correctors, 1 non-orthogonal corrector, tolerance of 1e-7, relative tolerance of 0.01.
Simulation runs for 2 seconds.
