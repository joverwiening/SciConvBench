Set up a 2D dam break simulation using OpenFOAM's interFoam solver.
Use a uniform mesh with cell size of 0.01m.
Domain dimensions are 1m long and 1m high.
Water column initially located at 0 < x < 0.2 and 0 < y < 0.5.
Use standard water (density 1000 kg/m³) and air (density 1.225 kg/m³) properties.
Set gravity as `g (0 0 -9.81)` in `constant/g` file.
Initialize `alpha.water` field to 1 in water column and 0 elsewhere using `setFieldsDict`.
Top boundary is an open atmosphere using `pressureInletOutletVelocity`.
All other boundaries are walls using `noSlip`.
Simulate for 3 seconds of physical time.
Use adaptive time stepping with maximum Courant number of 0.25.
Mesh will have approximately 10,000 cells (100 x 100 grid).
