Specification for Wave Equation Numerical Solution (Task ID: agent_wave_05):

Solve the 1D wave equation u_tt = c^2 * u_xx with the following specifications:

Equation: u_tt = (1.0)^2 * u_xx
Domain: x in [0,1) periodic, t in [0,1.0]
Wave speed (c): 2
Grid: 512 points on [0,1) periodic domain
Spatial Discretization: 2nd-order central difference with periodic wrap-around for u_xx
Time Integration: 2nd-order central difference in time
CFL Condition: c*dt/dx ≤ 0.9
Initialization: Taylor start with periodic Laplacian

Initial Conditions:
- u(x,0) = cos(2*pi*x)
- u_t(x,0) = 0

Boundary Conditions: Periodic on x (u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t))

Computational Details:
- Compute dx = 1/Nx
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Output Requirements:
- Compute u(x, T=1.0) on the grid
- Save solution to "solution_agent_wave_05.npz"
- Include arrays: x, u, and metadata: T, dx, dt
- Create plot "solution_agent_wave_05.png" of u(x,T)
- Print diagnostics:
  * Minimum of u
  * Maximum of u
  * Discrete L2 norm of u
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = cos(2*pi*x)*cos(2*pi*1.0*t)
