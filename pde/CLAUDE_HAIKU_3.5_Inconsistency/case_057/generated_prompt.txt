Solve the 2D Laplace equation (∇²u = 0) on a [0,1] x [0,1] domain using the following specification:

Numerical Method:
Discretize using 5-point stencil on a uniform 100x100 grid (101x101 points).
Use scipy.sparse.linalg.spsolve for linear system solution.
Boundary conditions are Dirichlet using u(x,y) = sin(pi*x)*sinh(pi*y)/sinh(pi).

Grid Details:
Domain is [0,1] x [0,1].
Nx = Ny = 100 intervals.
dx = dy = 1/100.
x_i = i*dx for i=0..100.
y_j = j*dy for j=0..100.

Output Requirements:
Compute steady-state solution u(x,y) on 2D grid.
Save solution to "solution_agent_laplace_01.npz" with:
- x (1D array)
- y (1D array)
- u (2D array, shape (len(y), len(x)))
- dx, dy as metadata scalars

Create visualization "solution_agent_laplace_01.png" (heatmap/contour plot).

Print diagnostics:
- Minimum u value
- Maximum u value
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Maximum absolute error vs reference solution
- L2 error vs reference solution
