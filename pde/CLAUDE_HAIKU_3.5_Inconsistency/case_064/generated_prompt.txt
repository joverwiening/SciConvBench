Solve the 2D Laplace equation (u_xx + u_yy = 0) on a [0,1] x [0,1] domain with the following specifications:

Numerical Method:
Discretize the Laplace equation using the 5-point stencil on a uniform grid.
Use Nx = Ny = 100 intervals (101 x 101 grid points).
Grid spacing: dx = dy = 1/100.
Grid points: x_i = i*dx, y_j = j*dy for i,j = 0..100.

Boundary Conditions:
Apply Dirichlet boundary conditions:
u(x,0) = 0
u(x,1) = sin(2*pi*x)
u(0,y) = 0
u(1,y) = 0

Solution Method:
Use a sparse direct solver (scipy.sparse.linalg.spsolve) to solve the resulting linear system.

Output Requirements:
Compute the steady-state solution u(x,y) on the 2D grid.
Save solution to "solution_agent_laplace_08.npz" with:
- x (1D array of x coordinates)
- y (1D array of y coordinates)
- u (2D array of solution values)
- dx, dy as metadata scalars

Generate a heatmap/contour plot of u(x,y) as "solution_agent_laplace_08.png".

Reporting:
Print the following diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Reference Solution:
u(x,y) = sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi)

Coding Note:
Use '^' for exponentiation in mathematical expressions.
Use '**' for powers when implementing in Python.
