Solve the 1D Reaction-Diffusion PDE with the following specification:

Implement a numerical solver for the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following precise requirements:

Numerical Method:
- Use Strang splitting method with three steps:
  1. Half diffusion step in Fourier space
  2. Full reaction step solved exactly
  3. Half diffusion step in Fourier space

Computational Domain:
- Spatial domain: x in [0, 1) with periodic boundary
- Temporal domain: t in [0, 1.0]
- Spatial grid: Uniform periodic grid with Nx=512 points
- Time grid: Fixed dt=0.001 with Nt=1000 steps

Parameters:
- nu = 10.0
- rho = 10.0

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Diffusion Step Details:
- Use FFT and inverse FFT
- Compute k = 2*pi*fftfreq(Nx, d=dx)
- Update u_hat(k) by multiplying with exp(-nu*k^2*(dt/2))

Reaction Step Details:
- Solve du/dt = rho*u*(1-u) exactly
- Update each grid point using the formula: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1))

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu10_rho10.npz" with arrays: x, u, and scalars: nu, rho, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho10.png"
- Print scalar diagnostics: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx)
