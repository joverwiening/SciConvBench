Numerical Solution Specification for 1D Compressible Navier-Stokes PDE:

Solve the 1D Compressible Navier-Stokes PDE with the following specifications:

Computational Domain:
- Spatial domain x ∈ [-1, 1]
- Temporal domain t ∈ [0, 0.5]
- Grid: Uniform finite-volume grid with Nx=400 cells
- Cell centers x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1
- dx = 2/Nx

Physical Parameters:
- Gamma = 1.6666666666666667
- eta = 0.01
- zeta = 0.01

Initial Conditions:
- rho(x,0) = 1.0 + 0.2*sin(pi*x)
- v(x,0) = 0.1*cos(pi*x)
- p(x,0) = 1.0 + 0.2*cos(pi*x)

Boundary Conditions:
- Periodic on x=-1 and x=1

Numerical Method:
- Conservative variables: U = [rho, m, E]
- Equation of State: p = (Gamma-1) * (E - 0.5*m^2/rho)
- Flux Calculation: Rusanov numerical flux with viscous corrections
- Time Integration: 2-stage SSP-RK2 (Heun's method)
- Time Step: Adaptive dt based on convective and viscous CFL conditions

Output Requirements:
- Compute final state rho(x,T), v(x,T), p(x,T) at t=0.5
- Save solution to "solution_pdebench_cns1d_eta0p01_periodic_smooth.npz"
- Create plot "solution_pdebench_cns1d_eta0p01_periodic_smooth.png"
- Print diagnostics: min/max of rho and p, mean of rho

Specific Implementation Details:
- Enforce positivity for rho and p with floor of 1e-12
- Compute v_x using centered differences
- Calculate viscous stress sigma = (zeta + 4/3*eta)*v_x
- Use interface-averaged values for viscous flux calculations
