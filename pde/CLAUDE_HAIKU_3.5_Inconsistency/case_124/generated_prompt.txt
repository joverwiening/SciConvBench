Solve the 1D nonlinear reaction-diffusion PDE with the following specification:

Partial Differential Equation:
u_t = 0.01*u_xx + 2.0*(u**2)*(1-u)**2

Computational Domain:
Spatial domain x in [0, 1) with periodic boundary
Time domain t in [0, 1.0]

Numerical Method Details:
Use a uniform periodic grid with Nx=512 points
Spatial discretization: 2nd-order central differences for u_xx
Time integration: Explicit 4th-order Runge-Kutta (RK4)
Time step: dt=0.0005 with Nt=2000 steps

Initial Condition:
u(x,0) = 0.2 + 0.1*sin(2*pi*x)

Parameters:
q1 = 0.01
q2 = 2.0

Output Requirements:
Compute u(x,T=1.0) on the periodic grid
Save solution to "solution_molk_023.npz" with arrays:
- x (1D length Nx)
- u (1D length Nx)
- T, dx, Nx
- Parameter scalars
Create line plot of u(x,T) as "solution_molk_023.png"
Print scalar diagnostics:
- min(u)
- max(u)
- mean(u)
- Discrete L2 norm sqrt(sum(u^2)*dx)

Boundary Conditions:
Periodic: u(0,t) = u(1,t) for all t
