Numerical Solution Specification for 1D Convection-Diffusion PDE (Task molk_024):

Solve the 1D convection-diffusion PDE u_t = -q1*∂_x(0.5*u^2) + (q2/pi)*u_xx with the following precise specifications:

Computational Domain:
- Spatial domain: x ∈ [0, 1) with periodic boundary
- Temporal domain: t ∈ [0, 0.5]
- Grid: Uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx

PDE Parameters:
- q1 = 1.0
- q2 = 0.1

Initial Condition:
- u(x,0) = sin(2*pi*x)

Numerical Method:
- Spatial discretization: Conservative finite-volume Rusanov flux for nonlinear term
- Diffusion term: 2nd-order central differences
- Time integration: SSP-RK2 (Heun method)
- Time step calculation:
  * Compute effective diffusion D_eff = q2/pi
  * Calculate dt_conv = 0.4 * dx / max|u0|
  * Calculate dt_diff = 0.4 * dx^2 / D_eff
  * Set dt = min(dt_conv, dt_diff)
  * Adjust Nt to hit T=0.5 exactly

Output Requirements:
- Compute u(x,T=0.5) on periodic grid
- Save solution to "solution_molk_024.npz" with:
  * x array (length Nx)
  * u array (length Nx)

- Print scalar diagnostics:
