Specification for 1D Viscous Burgers PDE Numerical Solution:

Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

Domain and Grid:
- Spatial domain is [0, 1) with periodic boundary
- Use uniform periodic grid with Nx = 512 points
- Grid points x_j = j*dx for j=0,...,Nx-1 with dx = 1/Nx

PDE Parameters:
- Viscosity nu = 0.002
- Time domain t ∈ [0, 1.0]
- Final solution time T = 1.1

Initial Condition:
- u(x,0) = sin(2*pi*x)

Numerical Method:
- Use Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space
  2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
  3. Diffusion half-step in Fourier space

Time Stepping:
- Use CFL = 0.4 with estimated max speed ≈ 1
- Compute dt0 = CFL * dx / 1.0
- Set Nt = ceil(T/dt0)
- Adjust final dt to hit T exactly

Output Requirements:
- Compute u(x,T=1.1) on the periodic grid
- Save solution to "solution_pdebench_burgers_nu2em3.npz"
- Include arrays: x, u, and scalars: nu, T, dx, dt, Nx, Nt
- Create line plot "solution_pdebench_burgers_nu2em3.png"
- Print diagnostics:
  1. Minimum value of u
  2. Maximum value of u
  3. Discrete mean value of u
  4. Discrete L2 norm of u
