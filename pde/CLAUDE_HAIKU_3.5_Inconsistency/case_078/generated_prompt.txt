Solve the 2D Poisson equation with the following specification:

Partial Differential Equation:
Solve u_xx + u_yy = f(x,y), where f(x,y) = -2*pi^2*cos(pi*x)*cos(pi*y)

Domain:
x and y in [0,1] x [0,1]

Numerical Method:
Use a uniform grid with Nx = Ny = 120 intervals
Grid points: (Nx+1) by (Ny+1), including boundary points
Grid spacing: dx = dy = 1/Nx
Grid coordinates: x_i = i*dx (i=0..Nx), y_j = j*dy (j=0..Ny)

Spatial Discretization:
Apply 5-point stencil (2nd-order) finite difference method
Discretize Laplacian ∇²u on interior grid points

Linear Solver:
Use sparse direct solver (scipy.sparse.linalg.spsolve)

Boundary Conditions:
Dirichlet conditions on all four edges
u(x,y) = cos(pi*x)*cos(pi*y) on boundaries

Solution Requirements:
Compute steady-state solution u(x,y) on 2D grid

Output Files:
1. Save solution to "solution_agent_poisson_05.npz"
   - Include arrays: x (1D), y (1D), u (2D)
   - Include metadata: dx, dy
2. Save heatmap/contour plot as "solution_agent_poisson_05.png"

Reporting:
- Print minimum value of u
- Print maximum value of u
- Print discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Compute and print max absolute error vs reference solution
- Compute and print L2 error vs reference solution

Reference Solution:
u(x,y) = cos(pi*x)*cos(pi*y)
