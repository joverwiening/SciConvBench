Specification for Wave Equation Numerical Solution (Task ID: agent_wave_04):

Solve the 1D wave equation u_tt = c^2 * u_xx numerically with the following specifications:

Equation: u_tt = (1.0)^2 * u_xx
Domain: x in [0,1], t in [0,1.0]
Wave speed (c): 2
Grid: 400 intervals (Nx+1 = 401 points)
Spatial discretization: Uniform grid with 2nd-order central differences for u_xx
Time integration: 2nd-order central difference (leapfrog/Störmer–Verlet)

Initial Conditions:
u(x,0) = 0
u_t(x,0) = sin(pi*x)

Boundary Conditions:
Dirichlet at x=0 and x=1: u = 0

Numerical Method Details:
- Compute dx = 1/Nx
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(1.0/dt0)
- Adjust dt to hit final time exactly
- Use Taylor start for second time step
- Enforce Dirichlet boundary conditions at each time step

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_wave_04.npz"
- Include arrays: x, u, with metadata T, dx, dt
- Create plot "solution_agent_wave_04.png"
- Print diagnostics:
  * Minimum u value
  * Maximum u value
  * Discrete L2 norm
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = (1/(1.0*pi))*sin(1.0*pi*t)*sin(pi*x)
