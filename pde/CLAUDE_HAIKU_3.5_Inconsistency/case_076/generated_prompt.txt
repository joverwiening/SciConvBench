Solve the 2D Poisson equation with the following specification:

Partial Differential Equation: u_xx + u_yy = f(x,y)
Where f(x,y) = -2*(y*(1-y) + x*(1-x))

Domain: 
Spatial domain is [0,1] x [0,1]
Grid resolution: Nx = Ny = 120 intervals
Grid spacing: dx = dy = 1/Nx
Grid points: x_i = i*dx (i=0..Nx), y_j = j*dy (j=0..Ny)

Boundary Conditions:
Dirichlet conditions on all four edges
u(x,y) = x*(1-x)*y*(1-y) on boundaries

Numerical Method:
Use 5-point stencil for spatial discretization (2nd-order)
Solve sparse linear system using scipy.sparse.linalg.spsolve

Output Requirements:
Compute steady-state solution u(x,y) on 2D grid
Save solution to "solution_agent_poisson_03.npz"
- Include arrays: x (1D), y (1D), u (2D)
- Include metadata: dx, dy
Create heatmap/contour plot "solution_agent_poisson_03.png"
Print diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Reference Solution: u(x,y) = x*(1-x)*y*(1-y)
