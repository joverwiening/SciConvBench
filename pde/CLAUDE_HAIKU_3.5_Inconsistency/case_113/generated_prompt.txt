Numerical Solution Specification for 1D Diffusion PDE (Task ID: molk_012)

Solve the 1D diffusion equation with the following precise specifications:

Partial Differential Equation: u_t = 0.2 * u_xx
Spatial Domain: [0, 1) with periodic boundary conditions
Temporal Domain: [0, 0.5]

Numerical Method Details:
Spatial Discretization: 2nd-order central differences on periodic grid
Spatial Grid: Uniform grid with Nx = 256 points
Grid Points: x_j = j*dx for j=0,...,255 with dx = 1/256
Time Integration: Crank-Nicolson method
Time Step: dt = 0.001
Number of Time Steps: Nt = 500

Initial Condition: u(x,0) = sin(2*pi*x)
Parameter: c1 = 0.2

Computational Requirements:
- Compute solution u(x,T) at final time T = 0.5
- Save solution to "solution_molk_012.npz" with arrays:
  * x (grid points)

  * dx (grid spacing)
  * Nx (number of grid points)
  * c1 (diffusion parameter)

  * Maximum absolute error vs exact solution
  * L2 error vs exact solution

Exact Solution for Verification:
u(x,t) = exp(-c1*(2*pi)^2*t) * sin(2*pi*x)
