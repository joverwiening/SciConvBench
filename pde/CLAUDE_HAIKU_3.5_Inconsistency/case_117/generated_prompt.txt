Numerical Solution Specification for Task molk_016:

Solve the 1D dispersive beam / nonlinear wave PDE with the following specifications:

PDE: u_tt + (q**2)*u_xxxx + c*∂_x( u * u_x ) = 0

Domain Configuration:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 0.5]
- Spatial grid: Uniform periodic grid with Nx=512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- Grid spacing: dx = 1/Nx

Parameters:
- q = 0.05
- c = 1.0

Initial Conditions:
- u(x,0) = 0.1*cos(2*pi*x)
- u_t(x,0) = 0

Numerical Method:
- Reformulate as first-order system: u_t=v, v_t = -(q**2)*u_xxxx - c*∂_x(u*u_x)
- Spatial derivatives: Fourier spectral derivatives
- Time integration: RK4
- Time step: dt = 0.0001
- Total time steps: Nt = 5000

Output Requirements:
- Compute u(x,T=0.5) on periodic grid
- Save solution to "solution_molk_016.npz" with:
  * x array (1D, length Nx)
  * u array (1D, length Nx)
  * T, dx, Nx, q, c scalar values
- Create plot "solution_molk_016.png" of u(x,T)
- Print scalar diagnostics:
  * Minimum of u
  * Maximum of u
  * Mean of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
