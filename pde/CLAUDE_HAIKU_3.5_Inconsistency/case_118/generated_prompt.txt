Specification for Solving 1D KdV-type PDE (Task ID: molk_017):

Implement a numerical solver for the PDE u_t + (0.1^2)*u_xxx + u*u_x = 0 with the following specifications:

Spatial Domain:
- Periodic domain [0, 1) 
- Uniform grid with Nx = 512 points
- Grid points x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Temporal Domain:
- Time interval [0, 0.2]
- Use Runge-Kutta 4 (RK4) time integration
- Time step dt = 0.0001
- Total time steps Nt = 2000

Initial Condition:
- u(x,0) = cos(2*pi*x)

Numerical Method:
- Spatial derivatives (u_x and u_xxx) computed using Fourier spectral method
- Periodic boundary conditions enforced

Output Requirements:
- Compute u(x,T=0.2) on the periodic grid
- Save solution to "solution_molk_017.npz" with arrays:
  * x (grid points)
  * u (solution at final time)
  * T (final time)
  * dx (grid spacing)
  * Nx (number of grid points)
  * q (parameter value 0.1)
- Create line plot "solution_molk_017.png" of u(x,T)
- Print scalar diagnostics:
  * Minimum of u
  * Maximum of u
  * Mean of u
  * Discrete L2 norm of u
