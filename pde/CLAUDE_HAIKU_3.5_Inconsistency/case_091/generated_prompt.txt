Solve the 1D wave equation u_tt = c^2 * u_xx + sin(pi*x)*sin(2*pi*t) numerically with the following specifications:

Spatial Domain: x in [0,1]
Time Domain: t in [0,1.0]
Wave Speed (c): 2.0
Grid: 400 intervals (401 points)
Spatial Discretization: 2nd-order central differences for u_xx
Time Integration: 2nd-order central difference (leapfrog/Störmer–Verlet)
Boundary Conditions: Dirichlet u=0 at x=0 and x=1
Initial Conditions: u(x,0) = 0, u_t(x,0) = 0
CFL Condition: c*dt/dx ≤ 0.9

Computational Steps:
Compute dx = 1/Nx
Compute dt0 = 0.9*dx/c
Set Nt = ceil(T/dt0)
Adjust dt to hit final time exactly

Output Requirements:
Compute u(x, T=1.0)
Save solution to "solution_agent_wave_10.npz"
