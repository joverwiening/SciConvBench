Specification for Fokker-Planck PDE Numerical Solution:

Solve the Fokker-Planck PDE p_t = ∂/∂x( 1.0*x*p ) + 0.1*p_xx with the following detailed requirements:

Computational Domain:
- Spatial domain x ∈ [-3.0, 3.0]
- Time domain t ∈ [0, 1.0]
- Use Nx = 2000 uniform cells
- Grid type: Cell-centered finite volume
- Grid points: x_i = -L + (i+0.5)*dx for i=0..Nx-1
- dx = 2*L/Nx = 2*3.0/2000
- Time stepping: Forward Euler
- dt = 1e-4
- Total time steps: Nt = 10000

Parameters:
- gamma = 1.0
- D = 0.1
- L = 3.0
- sigma0 = 0.2

Initial Condition:
- Initial distribution: Normalized Gaussian q(x) = exp(-(x-1)^2/(2*sigma0^2))
- Normalize so that total probability mass ∑ q*dx = 1

Numerical Method:
- Use finite-volume conservative update for p_t = -∂x J
- Flux J = -(gamma*x*p + D*p_x)
- Upwind discretization for advective term
- Central difference for diffusive term
- Enforce zero flux at x = ±L boundaries

Output Requirements:
- Compute p(x, T=1.0)
- Save solution to "solution_agent_other_07_fokker_planck.npz"
- Include arrays: x, p, with metadata T, dx, dt
- Create plot "solution_agent_other_07_fokker_planck.png"
- Print diagnostics:
  1. min(p)
  2. max(p)
  3. Discrete L2 norm
  4. Mass at t=0
  5. Mass at t=T
  6. Relative mass change

Coding Note:
- Use '^' for exponentiation
- Use Python '**' for powers in implementation
