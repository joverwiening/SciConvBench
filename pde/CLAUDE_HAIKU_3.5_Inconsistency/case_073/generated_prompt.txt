Solve the Euler-Bernoulli beam equation using a sine-series spectral method with the following specification:

Implement a numerical solution for the PDE u_tt + 0.01*u_xxxx = 0 on the domain x ∈ [0,1], t ∈ [0,1.0].

Numerical Method Details:
Use a sine-series spectral method with discrete sine transform (DST-I).
Use Nx = 800 grid points on the spatial domain.
Use time step dt = 1e-4 with Nt = 10000 steps to reach T = 1.0 exactly.
Implement explicit forward Euler time integration in modal space.

Initial Conditions:
Set u(x,0) = sin(π*x)
Set u_t(x,0) = 0

Boundary Conditions:
Enforce simply-supported conditions:
u(0,t) = 0
u(1,t) = 0
u_xx(0,t) = 0
u_xx(1,t) = 0

Output Requirements:
Compute u(x, T=1.0) on the spatial grid.
Save solution to "solution_agent_other_08_beam.npz" with arrays x, u, and metadata T, dx, dt.
Generate plot of u(x,T) as "solution_agent_other_08_beam.png".
Print min(u), max(u), and discrete L2 norm at T.
Compute and print max absolute error and L2 error compared to reference solution.

Reference Solution:
u(x,t) = cos((π^2)*sqrt(0.01)*t) * sin(π*x)
