Numerical Solution Specification for Advection-Diffusion PDE (Task ID: agent_other_06_advection_diffusion)

Partial Differential Equation:
u_t + (1.0)*u_x + (0.5)*u_y = 0.01*(u_xx + u_yy)

Domain and Grid:
Spatial domain is [0,1) x [0,1) with periodic boundaries
Grid resolution: Nx = Ny = 400
Grid spacing: dx = dy = 1/400
Time domain: t in [0, 0.5]

Numerical Method:
Time integration: Explicit forward Euler with deterministic IMEX (1st order)
Advection discretization: 1st-order upwind differences
Diffusion discretization: 2nd-order central differences
Time step: dt = 0.001
Total time steps: Nt = 500

Parameters:
a = 1.0
b = 0.5
Diffusion coefficient D = 0.01

Initial Condition:
u(x,y,0) = sin(2*pi*x)*cos(2*pi*y)

Exact Solution (for verification):
u(x,y,t) = exp(-0.01*8*pi^2*t)*sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t))
