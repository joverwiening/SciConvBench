Specification for Diffusion-Reaction PDE Numerical Solution:

Spatial Domain: x in [0,1]
Time Domain: t in [0,1.0]
Numerical Grid: 
- Use Nx = 400 grid points
- Uniform grid with zero Neumann boundary conditions via ghost point mirroring
- Spatial discretization using 2nd-order central differences

Time Integration:
- Use IMEX method (1st order)
- Diffusion term: Implicit (backward Euler)
- Reaction term: Explicit (forward Euler)
- Time step: dt = 0.0005 (total 2000 steps)
- Solve (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) at each step

Initial Condition:
u(x,0) = 0.1 + 0.1*sin(2*pi*x)

Parameters:
- Diffusion coefficient D = 0.01
- Reaction rate r = 5.0

Boundary Conditions:
- Neumann at x=0 and x=1: u_x(0,t) = 0, u_x(1,t) = 0
- Dirichlet condition: u = 0 at boundaries
