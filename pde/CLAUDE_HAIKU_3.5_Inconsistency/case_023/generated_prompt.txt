Numerical Solution Specification for Diffusion-Reaction PDE (Task ID: agent_diffusion_reaction_01):

Solve the 1D diffusion-reaction PDE u_t = 0.1*u_xx - u with the following precise specifications:

Computational Domain:
- Spatial domain x ∈ [0,1]
- Time domain t ∈ [0,0.5]
- Grid points: Nx = 200
- Time steps: dt = 0.001 (Total 500 steps)

PDE Parameters:
- Diffusion coefficient D = 0.1
- Reaction rate λ = -1.0

Numerical Method:
- Spatial discretization: 2nd-order central differences for diffusion terms
- Time integration: 1st-order IMEX method
  - Diffusion terms: Implicit (backward Euler)
  - Reaction terms: Explicit (forward Euler)
- Solve linear system (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n)
- Use sparse direct solver for each time step

Boundary Conditions:
- Dirichlet at x=0 and x=1: u(0,t) = 0, u(1,t) = 0

Initial Condition:
- u(x,0) = sin(π*x)

Output Requirements:
- Compute solution u(x, T=0.5)
- Save solution to "solution_agent_diffusion_reaction_01.npz"
- Create plot "solution_agent_diffusion_reaction_01.png"
- Print diagnostics:
  1. Minimum value of u
  2. Maximum value of u
  3. Discrete L2 norm
  4. Maximum absolute error vs reference solution
  5. L2 error vs reference solution

Reference Solution:
u(x,t) = exp((-1.0 - 0.1*π^2)*t) * sin(π*x)
