Specification for 1D Advection PDE Numerical Solution (Task ID: pdebench_advection_beta2):

Solve the 1D advection PDE u_t + beta * u_x = 0 with the following specifications:

Domain Configuration:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 2.0]
- Spatial grid: Uniform grid with Nx = 512 points
- Grid spacing: dx = 1/Nx
- Grid points: x_j = j*dx for j=0,...,Nx-1

Parameters:
- Advection speed beta = 2.0

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Numerical Method:
- Spatial discretization: 1st-order upwind finite difference for u_x
- Time integration: Explicit forward Euler
- Time step calculation: 
  * CFL = 0.5
  * dt = CFL * dx / abs(beta)
  * Nt = ceil(T/dt)
  * Adjust dt to hit final time exactly

Output Requirements:
- Compute solution at T = 2.0
- Save solution to "solution_pdebench_advection_beta2.npz"
  * Include arrays: x, u
  * Include scalars: beta, T, dx, dt, Nx, Nt
- Create line plot "solution_pdebench_advection_beta2.png"
- Print at final time:
  * Minimum of u
  * Maximum of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print:
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution:
- u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition

Coding Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
