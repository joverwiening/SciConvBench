Numerical Solution Specification for 1D Linear Reaction-Diffusion PDE (Task ID: molk_021)

Solve the 1D linear reaction-diffusion PDE with the following specifications:

PDE Equation: u_t = q1*u_xx + q2*u
Domain: x in [0, 1) with periodic boundary, t in [0, 0.5]
Parameters: q1 = 0.01, q2 = -1.0

Numerical Method Details:
Spatial Grid: 256 uniform periodic points on [0,1)
Spatial Discretization: 2nd-order central differences for u_xx
Time Integration: Operator-splitting method
- Step 1: Diffusion Crank-Nicolson step
- Step 2: Reaction exact step using exponential integration
Time Step: dt = 0.001, Nt = 500 steps

Initial Condition: u(x,0) = sin(2*pi*x)
Boundary Condition: Periodic (u(0,t) = u(1,t))

Output Requirements:
