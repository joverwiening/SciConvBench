Grid spacing dx = dy = 1/Nx

Boundary conditions: Dirichlet u = 0 on all four edges
Discretize using 5-point stencil (2nd-order finite difference)
Solve sparse linear system using scipy.sparse.linalg.spsolve
Exact solution: u(x,y) = sin(pi*x)*sin(pi*y)

Output requirements:
Compute steady-state solution u(x,y) on 2D grid
Save solution to "solution_agent_poisson_01.npz" with:
- x (1D array)

- dx, dy as metadata scalars
