Specification for Heat Equation Numerical Solution (Task ID: agent_heat_01):

Solve the 1D heat equation u_t = 0.1 * u_xx numerically with the following specifications:

Equation: u_t = 0.1 * u_xx
Domain: x in [0, 1], t in [0, 0.5]
Diffusion coefficient (alpha): 0.1

Numerical Method Details:
- Spatial discretization: Uniform grid with Nx = 200 intervals
- Spatial grid points: Nx+1 points (including both boundaries)
- Spatial step size: dx = 1/Nx
- Spatial derivative: 2nd-order central differences for u_xx in the interior
- Time integration method: Crank-Nicolson scheme
- Time step size: dt = 0.001
- Total time steps: 600

Initial Condition:
u(x,0) = sin(π*x)

Boundary Conditions:
- Dirichlet conditions at x=0 and x=1 for all t
- u(0,t) = 0
- u(1,t) = 0

Output Requirements:
1. Compute u(x, T=0.5) on the grid
2. Save solution to "solution_agent_heat_01.npz" with:
   - x array (1D)
   - u array (1D)
   - Metadata: T, dx, dt
3. Generate line plot of u(x,T) as "solution_agent_heat_01.png"
4. Print the following diagnostics at T=0.5:
   - Minimum value of u
   - Maximum value of u
   - Discrete L2 norm: sqrt(sum(u^2)*dx)
5. Compute and print error metrics vs reference solution:
   - Maximum absolute error
   - L2 error

Reference Solution for Verification:
u(x,t) = exp(-0.1*π^2*t) * sin(π*x)

Coding Note:
- Use '^' for exponentiation in mathematical expressions
- Use '**' for powers when implementing in Python
