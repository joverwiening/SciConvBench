Specification for Solving Burgers' Equation (Task ID: agent_burgers_04):

Implement a numerical solver for the 1D Burgers' equation with the following specifications:

PDE: u_t + u*u_x = 0.02*u_xx + sin(2*pi*x)*cos(2*pi*t)

Numerical Method Details:
1. Domain: x in [0,1) periodic, t in [0,1.0]
2. Spatial Discretization: Conservative form using Rusanov flux
3. Convection Flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i)
4. Diffusion: 2nd-order central difference
5. Time Integration: 1st-order IMEX (explicit convection, implicit diffusion)
6. Grid Parameters:
   - Nx = 1000 points
   - dx = 1/Nx
   - dt = 1e-4
   - Nt = 10000 steps
7. Boundary Conditions: Periodic wrap-around

Output Requirements:
1. Compute u(x, T=1.0)
2. Save solution to "solution_agent_burgers_04.npz" with:
   - x array
   - u array
   - Metadata: T, dx, dt
3. Create plot "solution_agent_burgers_04.png" of u(x,T)
4. Print diagnostics:
   - Minimum of u
   - Maximum of u
   - Discrete L2 norm: sqrt(sum(u^2)*dx)

Implementation Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math, '**' in Python
- Solve sparse linear system (e.g., scipy.sparse.linalg.spsolve)
- Ensure periodic indexing for fluxes and diffusion stencil
