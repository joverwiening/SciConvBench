Numerical Solution Specification for 1D Inviscid Conservation Law with Sin Flux:

Solve the PDE u_t = -k*∂_x(sin(u)) with the following specifications:

Domain Configuration:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 0.2]
- Grid: Uniform periodic grid with Nx = 1024 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- Grid spacing: dx = 1/Nx

PDE Parameters:
- k = 1.0

Initial Condition:
- u(x,0) = 0.5*sin(2*pi*x)

Numerical Method:
- Spatial Discretization: Conservative finite-volume Rusanov flux
- Flux Function: f(u) = sin(u)
- Wave Speed: alpha = max|cos(u)|
- Time Integration: SSP-RK2
- Time Step: 
  * CFL = 0.2
  * dt0 = CFL*dx/1.0
  * Nt = ceil(T/dt0)
  * dt = T/Nt

Output Requirements:
- Compute u(x,T=0.2) on periodic grid
- Save solution to "solution_molk_030.npz" with arrays:
  * x (1D, length Nx)
  * u (1D, length Nx)
  * T, dx, Nx
  * Parameter scalars
- Create line plot of u(x,T) as "solution_molk_030.png"
- Print scalar diagnostics:
  * min(u)
  * max(u)
  * mean(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
