Solve the 1D Reaction-Diffusion PDE with the following specification:

Implement a numerical solver for the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following exact details:

Spatial Domain:
- Periodic grid on [0, 1) 
- Nx = 512 grid points
- dx = 1/Nx
- x_j = j*dx for j=0,...,Nx-1

Temporal Domain:
- t in [0, 1.0]
- Fixed time step dt = 0.001
- Nt = 1000 steps

Parameters:
- nu = 1.0
- rho = 5.0

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical Method:
- Use Strang splitting with three steps:
  1. Half diffusion step in Fourier space
  2. Full reaction step solved exactly pointwise
  3. Half diffusion step in Fourier space

Output Requirements:
- Compute u(x,T=1.0)
- Save solution to "solution_pdebench_reacdiff_nu1_rho5.npz"
- Save plot to "solution_pdebench_reacdiff_nu1_rho5.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
