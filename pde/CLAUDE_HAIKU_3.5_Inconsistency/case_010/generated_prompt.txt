Specification for Allen-Cahn PDE Numerical Solution:

Solve the Allen-Cahn PDE u_t = (0.01)^2*(u_xx + u_yy) + u - u^3 with the following detailed requirements:

Computational Domain:
- Spatial domain: [0,1) x [0,1) with periodic boundary conditions
- Time domain: [0,0.2]
- Grid: Nx = Ny = 256 uniform grid points
- Spatial step sizes: dx = dy = 1/256
- Time step: dt = 0.0002 (1000 total time steps)

Numerical Method:
- Spatial discretization: 5-point Laplacian for u_xx + u_yy
- Time integration: Semi-implicit scheme
  - Solve (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3 
  - Involves solving a sparse linear system at each time step
- Boundary handling: Periodic wrap-around indexing in x and y dimensions

Initial Condition:
- u(x,y,0) = 0.1 * cos(2*pi*x) * cos(2*pi*y)

Parameters:
- ε (epsilon) = 0.01

Output Requirements:
- Compute final solution u(x,y,T=0.2)
- Save solution to "solution_agent_allen_cahn_04.npz" with:
  * x (1D array of x coordinates)
  * y (1D array of y coordinates)
  * u (2D array of solution values, shape (Ny, Nx))
  * Metadata: T, dx, dy, dt
- Generate heatmap/contour plot "solution_agent_allen_cahn_04.png"
- Print diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx*dy)

Coding Notes:

- Use '^' for exponentiation in math notation
