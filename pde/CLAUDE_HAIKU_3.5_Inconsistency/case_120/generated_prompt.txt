Solve the 1D wave equation with periodic boundary conditions using the following specification:

Partial Differential Equation:
u_tt = q*u_xx, where q = 1.0

Domain:
x in [0, 1) periodic grid
t in [0, 1.0]

Numerical Method Specifications:
Use a uniform periodic grid with Nx = 256 points
Convert to first-order system: u_t = v, v_t = q*u_xx
Spatial discretization: 2nd-order central differences for u_xx
Time integration: RK4 method
Time step: dt = 0.0005 with Nt = 2000 steps

Initial Conditions:
u(x,0) = sin(2*pi*x)
u_t(x,0) = 0

Boundary Conditions:
Periodic boundary conditions for u and u_x

Output Requirements:
Compute u(x,T=1.0) on the periodic grid
Save solution to "solution_molk_019.npz" with arrays:
- x (1D length Nx)
- u (1D length Nx)
- Scalar values: T, dx, Nx, and parameter scalars
Save line plot of u(x,T) as "solution_molk_019.png"
Print at final time T:
- Minimum of u
- Maximum of u
- Mean of u
- Discrete L2 norm: sqrt(sum(u^2)*dx)
