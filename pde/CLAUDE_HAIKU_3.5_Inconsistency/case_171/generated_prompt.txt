Numerical Solution Specification for 2D Darcy Flow (Task ID: pdebench_darcy_beta100):

Solve the 2D elliptic PDE: -∇ · ( a(x,y) ∇u(x,y) ) = 1

Domain Specifications:
- Spatial domain: (x,y) ∈ (0,1) × (0,1)
- Grid: Uniform Cartesian grid with 128 intervals (129 points)
- Grid spacing: dx = dy = 1/128
- Grid points: x_i = i*dx, y_j = j*dy for i,j = 0,...,128

Coefficient Field:
- a(x,y) = 1 + 100 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y))
- Ensures a(x,y) ≥ 1 for all (x,y)

Boundary Conditions:
- Dirichlet: u = 0 on all boundaries

Numerical Method:
- Discretization: 2nd-order finite differences
- Face coefficients: Harmonic mean averaging
- Linear solver: Conjugate Gradient (CG)
- Solver tolerance: 1e-10 relative residual
- Optional: Jacobi preconditioner

Output Requirements:
- Compute u(x,y) on full 129 × 129 grid
- Save solution to "solution_pdebench_darcy_beta100.npz"
- Include arrays: x, y, u
- Include scalars: beta, N, dx
- Generate heatmap plot "solution_pdebench_darcy_beta100.png"
- Print diagnostics: min(u), max(u), discrete residual norm

Coding Notes:
- Use radians for trigonometric functions
- Use '^' or '**' for exponentiation as appropriate
