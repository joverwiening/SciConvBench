Specification for 1D Reaction-Diffusion PDE Numerical Solution:

Solve the 1D reaction-diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) with the following detailed requirements:

Domain and Grid:
- Spatial domain is [0, 1) with periodic boundary
- Use uniform periodic grid with Nx = 512 points
- Grid points x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Parameters:
- nu = 5.0
- rho = 5.0
- Simulation time T = 1.0

Numerical Method:
- Time integration: Explicit forward Euler
- Time step: dt = 0.001
- Total time steps: Nt = 1000
- Method: Strang splitting with three steps:
  1. Diffusion half-step in Fourier space (dt/2)
  2. Reaction full-step using exact pointwise logistic ODE update
  3. Diffusion half-step in Fourier space (dt/2)

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu5_rho5.npz"
- NPZ file must contain: x, u, nu, rho, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) as "solution_pdebench_reacdiff_nu5_rho5.png"
- Print scalar diagnostics:
  1. Minimum of u
  2. Maximum of u
  3. Mean of u
  4. Discrete L2 norm sqrt(sum(u^2)*dx)

Coding Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation
- Use '**' for powers in Python implementation
