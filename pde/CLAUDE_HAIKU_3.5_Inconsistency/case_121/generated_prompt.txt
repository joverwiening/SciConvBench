Numerical Solution Specification for 1D Reaction-Diffusion PDE (Task ID: molk_020)

Solve the 1D reaction-diffusion PDE with the following precise specifications:

PDE Equation: u_t = q1*u_xx + q2*u*(1-u)
Domain: x in [0, 1) periodic, t in [0, 1.0]
Parameters: q1 = 0.01, q2 = 5.0

Numerical Method Details:
Spatial Grid: Uniform periodic grid with Nx = 512 points
Grid Points: x_j = j*dx for j=0,...,Nx-1 with dx = 1/Nx
Spatial Discretization: 2nd-order central differences for u_xx
Time Integration: Explicit forward Euler
Time Step: dt = 0.001 with Nt = 1000 steps

Initial Condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x)
Boundary Condition: Periodic (u(0,t) = u(1,t))

Output Requirements:
1. Compute u(x,T=1.0) on the periodic grid
2. Save solution to "solution_molk_020.npz" with arrays:
   - x (1D length Nx)
   - u (1D length Nx)
   - T, dx, Nx
   - Parameter scalars (q1, q2)
3. Save line plot of u(x,T) as "solution_molk_020.png"
4. Print scalar diagnostics:
   - min(u)
   - max(u)
   - mean(u)
   - Discrete L2 norm: sqrt(sum(u^2)*dx)
