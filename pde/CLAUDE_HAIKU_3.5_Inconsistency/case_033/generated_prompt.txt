Specification for Heat Equation Numerical Solution (Task ID: agent_heat_04):

Solve the 1D heat equation u_t = 0.1 * u_xx numerically with the following specifications:

Partial Differential Equation:
- Equation: u_t = 0.1 * u_xx
- Domain: x in [0, 1], t in [0, 0.4]
- Diffusion coefficient (alpha): 0.1

Numerical Method Details:
- Spatial discretization: Uniform grid with Nx = 200 intervals
- Spatial grid: dx = 1/Nx, x points include both boundaries
- Temporal discretization: Fixed time step dt = 0.001 (480 total time steps)
- Spatial derivative: 2nd-order central differences for u_xx
- Time integration method: Crank-Nicolson scheme

Initial Condition:
- u(x,0) = cos(pi*x)

Boundary Conditions:
- Neumann zero-flux at x=0 and x=1
- Implement using ghost point method: u[-1]=u[1] at x=0, u[Nx+1]=u[Nx-1] at x=1

Output Requirements:
- Compute solution u(x, T=0.4)
- Save solution to "solution_agent_heat_04.npz" with arrays:
  * x (1D spatial grid)
  * u (1D solution at final time)
  * Metadata: T, dx, dt
- Create plot "solution_agent_heat_04.png" of u(x,T)
- Print at final time:
  * Minimum of u
  * Maximum of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print:
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution for Verification:
- u(x,t) = exp(-0.1*pi^2*t) * cos(pi*x)
