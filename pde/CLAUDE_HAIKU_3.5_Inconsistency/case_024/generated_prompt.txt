Numerical Solution Specification for Diffusion-Reaction PDE (agent_diffusion_reaction_02):

Partial Differential Equation:
u_t = 0.05*u_xx + 2.0*u

Domain:
Spatial domain x in [0,1]
Time domain t in [0,0.3]

Numerical Method Parameters:
Use spatial grid with Nx = 250 points
Use time step dt = 0.0005 (total 600 time steps)
Spatial discretization: 2nd-order central differences
Time integration: 1st-order IMEX method (implicit diffusion, explicit reaction)

Boundary Conditions:
Dirichlet conditions at x=0 and x=1: u(0,t)=0, u(1,t)=0

Initial Condition:
u(x,0) = sin(2*pi*x)

Computational Parameters:
Diffusion coefficient D = 0.05
Reaction coefficient lambda = 2.0

Output Requirements:
1. Compute solution u(x,T) at T = 0.3
2. Save solution to "solution_agent_diffusion_reaction_02.npz"
3. Save line plot of u(x,T) as "solution_agent_diffusion_reaction_02.png"

   - Minimum value of u
   - Maximum value of u
   - Discrete L2 norm of u
   - Maximum absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution:
u(x,t) = exp((2.0 - 0.05*(2*pi)^2)*t)*sin(2*pi*x)
