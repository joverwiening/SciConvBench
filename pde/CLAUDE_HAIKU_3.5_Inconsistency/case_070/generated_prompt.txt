Solve the biharmonic PDE ∇^4 u = f(x,y) on a [0,1] x [0,1] square domain using the following specification:

Numerical Method:
Solve by introducing v = Δu through two sequential Poisson solves.
First Poisson solve: Δv = f with Dirichlet BC v=0 on boundaries.
Second Poisson solve: Δu = v with Dirichlet BC u=0 on boundaries.

Discretization Details:
Use 5-point Laplacian stencil on uniform grid.
Grid size: Nx = Ny = 120 intervals.
Grid points: (Nx+1) x (Ny+1) including boundaries.
dx = dy = 1/Nx
x_i = i*dx for i=0..Nx
y_j = j*dy for j=0..Ny

Source Term:
f(x,y) = 4*pi^4 * sin(pi*x) * sin(pi*y)

Boundary Conditions:
Dirichlet BC: u = 0 on all boundaries
Neumann BC: ∂u/∂n = 0 on all boundaries

Linear Solver:
Use sparse direct solver (scipy.sparse.linalg.spsolve)

Output Requirements:
Compute steady-state solution u(x,y) on 2D grid.
Save solution to "solution_agent_other_05_biharmonic.npz" with:
- x (1D array)
- y (1D array)
- u (2D array, shape (len(y), len(x)))
- dx, dy as metadata scalars

Create heatmap/contour plot "solution_agent_other_05_biharmonic.png".

Print diagnostics:
- min(u)
- max(u)
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Max absolute error vs reference solution
- L2 error vs reference solution

Reference Solution:
u(x,y) = sin(pi*x) * sin(pi*y)
