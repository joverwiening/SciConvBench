Solve the 1D Reaction-Diffusion PDE with the following specification:

Implement a numerical solver for the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following exact details:

Spatial Domain:
- Periodic grid on [0, 1) with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Temporal Domain:
- Time interval [0, 1.0]
- Fixed time step dt = 0.001
- Total time steps Nt = 1000

Parameters:
- nu = 1.0
- rho = 2.0

Initial Condition:
- u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical Method:
- Use Strang splitting with three steps per time step:
  1. Half diffusion step in Fourier space (dt/2)
  2. Full reaction step solved exactly pointwise
  3. Half diffusion step in Fourier space (dt/2)

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu1_rho2.npz" with arrays:
  * x (grid points)
  * u (solution at T)
  * Scalar parameters: nu, rho, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_reacdiff_nu1_rho2.png" of u(x,T)
- Print scalar diagnostics:
  * min(u)
  * max(u)
  * mean(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
