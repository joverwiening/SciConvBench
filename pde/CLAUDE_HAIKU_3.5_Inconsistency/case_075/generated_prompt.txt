Solve the 2D Poisson equation with the following specification:

Partial Differential Equation: u_xx + u_yy = f(x,y)
Where f(x,y) = -5*pi^2*sin(2*pi*x)*sin(pi*y)

Domain: 
- x in [0,1]
- y in [0,1]

Boundary Conditions:
- Dirichlet boundary conditions: u = 0 on all four edges

Numerical Method:
- Spatial discretization: 5-point stencil (2nd-order)
- Grid: Uniform grid with Nx = Ny = 120 intervals
- Grid points: (Nx+1) x (Ny+1) including boundaries
- Grid spacing: dx = dy = 1/Nx
- Grid coordinates: 
  x_i = i*dx for i=0..Nx
  y_j = j*dy for j=0..Ny

Solution Method:
- Use sparse direct solver (scipy.sparse.linalg.spsolve)

Output Requirements:
1. Compute steady-state solution u(x,y)
2. Save solution to "solution_agent_poisson_02.npz" with:
   - x (1D array)
   - y (1D array)
   - u (2D array, shape (len(y), len(x)))
   - dx, dy as metadata scalars
3. Save heatmap/contour plot as "solution_agent_poisson_02.png"
4. Print:
   - min(u)
   - max(u)
   - Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
5. Compute and print:
   - Max absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution: u(x,y) = sin(2*pi*x)*sin(pi*y)
