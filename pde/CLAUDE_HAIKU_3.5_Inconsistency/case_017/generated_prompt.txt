- x in [0,1]
- Temporal Domain: t in [0,0.5]
- Grid Points: Nx = 300
- Spatial Step: dx = (1-0)/300
- Time Step: dt = 0.001
- Total Time Steps: 600

- D(x) = 0.1*(1+x)

- u(0,t) = 0
- u(1,t) = 0 (Dirichlet conditions)

- u(x,0) = sin(π*x)

Numerical Method:
- Spatial Discretization: Conservative 2nd-order flux form
- Face Diffusion Coefficient: Arithmetic average D_{i+1/2} = 0.5*(D_i + D_{i+1})
- Time Integration: Implicit Euler method
- Linear System Solver: Sparse matrix solver

- Print diagnostics: min(u), max(u), discrete L2 norm
