Implement a numerical solver for the 1D wave equation with the following precise requirements:

Spatial Domain: x in [0,1]
Time Domain: t in [0,0.8]
Wave Speed (c): 2
Grid Parameters: 
- Use Nx = 600 intervals (Nx+1 points)
- dx = 1/Nx
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(0.8/dt0)
- Adjust dt to hit final time exactly

Numerical Method:
- Spatial Discretization: 2nd-order central differences for u_xx
- Time Integration: 2nd-order central difference (leapfrog/Störmer–Verlet)
- CFL Condition: c*dt/dx ≤ 0.9
- Initialization: Use Taylor start method for first time step
- Boundary Conditions: Dirichlet (u=0) at x=0 and x=1

Initial Conditions:
- u(x,0) = sin(pi*x) + 0.5*sin(3*pi*x)
- u_t(x,0) = 0

Output Requirements:
- Compute u(x, T=0.8)
- Save solution to "solution_agent_wave_03.npz"
- Save plot to "solution_agent_wave_03.png"
- Print:
  1. min(u)
  2. max(u)
  3. Discrete L2 norm
  4. Max absolute error vs reference solution
  5. L2 error vs reference solution

Reference Solution: u(x,t) = cos(pi*t)*sin(pi*x) + 0.5*cos(3*pi*t)*sin(3*pi*x)
