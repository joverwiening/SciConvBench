Specification for Allen-Cahn PDE Numerical Solution:

Solve the Allen-Cahn PDE u_t = (0.015)^2*(u_xx + u_yy) + u - u^3 with the following detailed requirements:

Computational Domain:
- Spatial domain: [0,1] x [0,1]
- Time domain: [0,0.2]
- Grid: Nx = Ny = 200 uniform grid points
- Time step: dt = 0.0002 (1000 total time steps)

Numerical Method:
- Spatial discretization: 5-point Laplacian for u_xx + u_yy
- Time integration: Semi-implicit forward Euler
- Boundary conditions: Zero Neumann via ghost node mirroring
- Equation solved as: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3

Initial Condition:
- u(x,y,0) = sin(π*x) * sin(π*y)

Output Requirements:
- Compute final solution u(x,y,T=0.2)
- Save solution to "solution_agent_allen_cahn_06.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (len(y), len(x)))
  * Metadata: T, dx, dy, dt
