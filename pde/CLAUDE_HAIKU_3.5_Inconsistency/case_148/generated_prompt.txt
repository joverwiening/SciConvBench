Specification for 1D Viscous Burgers Equation Numerical Solution:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

PDE Details:
- Equation: u_t + ∂_x(0.5*u^2) = 0.4 * u_xx
- Domain: x in [0, 1) with periodic boundary, t in [0, 1.0]
- Parameter: nu = 0.4

Numerical Method:
- Use Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space (dt/2)
  2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
  3. Diffusion half-step in Fourier space (dt/2)

Grid Specifications:
- Spatial grid: Uniform periodic grid
- Number of points: Nx = 512
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Initial Condition:
- u(x,0) = sin(2*pi*x)

Time Stepping:
- CFL = 0.4
- dt0 = CFL*dx/1.0
- Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Output Requirements:
- Compute solution at T = 1.0
- Save solution to "solution_pdebench_burgers_nu0p4.npz"
- Include arrays: x, u
- Include scalars: nu, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_burgers_nu0p4.png"
- Print diagnostics:
  1. Minimum of u
  2. Maximum of u
  3. Discrete mean value
  4. Discrete L2 norm
