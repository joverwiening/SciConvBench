Solve the 2D Poisson equation with the following specification:

Partial Differential Equation: u_xx + u_yy = f(x,y)
Where f(x,y) = -((3*pi)^2 + (2*pi)^2)*sin(3*pi*x)*cos(2*pi*y)

Domain: 
- x in [0,1]
- y in [0,1]

Boundary Conditions:
- Dirichlet on all four edges
- u(x,y) = sin(3*pi*x)*cos(2*pi*y) on boundaries

Numerical Method:
- Spatial Discretization: 5-point stencil (2nd-order)
- Grid: Uniform grid with Nx = Ny = 120 intervals
- Grid Points: Nx+1 by Ny+1 grid points
- Grid Spacing: dx = dy = 1/Nx
- Grid Points: x_i = i*dx (i=0..Nx), y_j = j*dy (j=0..Ny)
- Linear Solver: Sparse direct solver (scipy.sparse.linalg.spsolve)

Output Requirements:
- Compute steady-state solution u(x,y)
- Save solution to "solution_agent_poisson_06.npz"
- Include in .npz: x (1D), y (1D), u (2D array), dx, dy
- Create heatmap/contour plot "solution_agent_poisson_06.png"
- Print diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,y) = sin(3*pi*x)*cos(2*pi*y)
