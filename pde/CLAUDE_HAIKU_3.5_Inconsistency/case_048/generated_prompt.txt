Solve the 1D Klein-Gordon PDE numerically with the following specification:

Partial Differential Equation:
u_tt - (1.0)^2*u_xx + (1.0)^2*u = 0

Domain and Parameters:
Spatial domain x in [0,1]
Time domain t in [0,1.0]
Wave speed c = 2
Mass parameter m = 1.0

Numerical Method:
Use a uniform grid with Nx = 400 intervals (Nx+1 points)
Spatial discretization: 2nd-order central differences for u_xx
Time integration: 2nd-order central difference (leapfrog)
Grid spacing dx = 1/Nx
Time step dt calculated to ensure c*dt/dx ≤ 0.9
Total time steps Nt = ceil(T/dt0), with dt adjusted to hit T=1.0 exactly

Boundary Conditions:
Dirichlet conditions at x=0 and x=1: u=0

Initial Conditions:
u(x,0) = sin(pi*x)
u_t(x,0) = 0

Computational Tasks:
1. Compute u(x, T=1.0) on the grid
2. Save solution to "solution_agent_kg_01.npz" with arrays:
   - x (1D grid points)
   - u (1D solution at final time)
   - Metadata: T, dx, dt
3. Generate plot of u(x,T) and save as "solution_agent_kg_01.png"
4. Print scalar diagnostics:
   - Minimum value of u
   - Maximum value of u
   - Discrete L2 norm of u
5. Compute and print error metrics:
   - Maximum absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution for Verification:
u(x,t) = cos(sqrt((1.0*pi)^2 + (1.0)^2)*t)*sin(pi*x)

- Use radians for trigonometric functions
- Interpret '^' as exponentiation
