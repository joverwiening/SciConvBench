Numerical Solution Specification for 2D Wave Equation (Task ID: agent_wave_08)

Solve the 2D wave equation with the following precise specifications:

PDE: u_tt = (0.7)^2 * (u_xx + u_yy)
Domain: (x,y) in [0,1] x [0,1], t in [0,0.8]
Wave speed parameter: c = 1.4

Grid Configuration:
- Use uniform grid with Nx = Ny = 140 intervals
- Grid points: (Nx+1) by (Ny+1) points
- dx = dy = 1/Nx
- Compute dt0 = 0.9 / (c * sqrt(1/dx^2 + 1/dy^2))
- Set Nt = ceil(0.8/dt0)
- Adjust dt to ensure final time is exactly 0.8

Initial Conditions:
- u(x,y,0) = sin(2*pi*x) * sin(pi*y)
- u_t(x,y,0) = 0

Boundary Conditions:
- Dirichlet BC: u = 0 on all boundaries

Numerical Method:
- Spatial discretization: 5-point Laplacian
- Time integration: 2nd-order central difference
- Initialization: Taylor start with initial velocity
- Boundary handling: Set boundary nodes each time step
