Specification for Solving 1D Inviscid Burgers Equation:

Implement a numerical solver for the 1D inviscid Burgers equation with the following specifications:

PDE: u_t = -k*∂_x( 0.5*u^2 )
Domain: x in [0, 1) with periodic boundary, t in [0, 0.2]
Parameters: k = 1.0

Numerical Method Details:
- Use a uniform periodic grid with Nx = 1024 points
- Grid points: x_j = j*dx for j=0,...,Nx-1, with dx = 1/Nx
- Spatial discretization: Conservative finite-volume method with Rusanov (local Lax–Friedrichs) flux
- Time integration: SSP-RK2 (Heun) method
- Time step: Use CFL = 0.2, with dt0 = CFL*dx/max|u|
- Initial condition: u(x,0) = sin(2*pi*x)

Output Requirements:
- Compute u(x,T=0.2) on the periodic grid
- Save solution to "solution_molk_025.npz" with arrays:
  * x (1D length Nx)
  * u (1D length Nx)
  * T, dx, Nx, and parameter scalars
- Create line plot of u(x,T) as "solution_molk_025.png"
- Print scalar diagnostics:
  * Minimum of u
  * Maximum of u
  * Mean of u
  * Discrete L2 norm sqrt(sum(u^2)*dx)
