Numerical Solution Specification for 1D Advection-Diffusion PDE (Task ID: molk_033)

Solve the 1D advection-diffusion PDE with the following specifications:

PDE Equation: u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u )
Domain: x in [0, 1) with periodic boundary, t in [0, 1.0]

Parameters:
- Diffusion coefficient D = 0.01
- Gamma = 1.0
- U(x) = cos(2*pi*x)
- U'(x) = -2*pi*sin(2*pi*x)

Grid Configuration:
- Use uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Initial Condition:
u(x,0) = 1.0 + 0.2*sin(2*pi*x)

Numerical Method:
- Spatial Discretization:
  * Upwind finite-volume flux for ∂_x(F)
  * 2nd-order central differences for u_xx
- Time Integration: Explicit SSP-RK2
- Time Step: 
  * dt = min(0.4*dx/max|b|, 0.2*dx^2/D)
  * b(x) = U'(x)/gamma
  * Nt = ceil(T/dt)
  * Final dt = T/Nt

Output Requirements:
- Compute u(x,T=1.0) on periodic grid
- Save solution to "solution_molk_033.npz" with:
  * x array (length Nx)
  * u array (length Nx)
  * T, dx, Nx
  * Parameter scalars
- Create plot "solution_molk_033.png" of u(x,T)
- Print scalar diagnostics:
  * min(u)
  * max(u)
  * mean(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
