Specification for 1D Viscous Burgers PDE Numerical Solution:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx using the specified numerical method.

Problem Setup:
- PDE: u_t + ∂_x(0.5*u^2) = nu * u_xx
- Domain: x in [0, 1) periodic, t in [0, 1.0]
- Viscosity parameter nu = 2.0
- Initial condition: u(x,0) = sin(2*pi*x)
- Boundary condition: Periodic (u(0,t) = u(1,t))

Numerical Method:
- Spatial discretization: Uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1, with dx = 1/Nx
- Time integration: Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space (dt/2)
  2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
  3. Diffusion half-step in Fourier space (dt/2)
- Time step: CFL = 0.4, dt0 = CFL*dx/1.0
- Total time steps: Nt = ceil(T/dt0), with final dt adjusted to hit T exactly

Output Requirements:
- Compute solution u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_burgers_nu2.npz"
- Save plot to "solution_pdebench_burgers_nu2.png"
- Print diagnostics:
  1. Minimum value of u
  2. Maximum value of u
  3. Discrete mean value of u
  4. Discrete L2 norm of u

Implementation Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math, '**' in Python code
- Perform FFT and IFFT for diffusion substeps
- Use periodic indexing for flux calculations
