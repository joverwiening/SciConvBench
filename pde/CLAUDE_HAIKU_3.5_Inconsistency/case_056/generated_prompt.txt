Solve the 1D Klein-Gordon PDE numerically with the following specification:

Partial Differential Equation: u_tt - (1.2)^2*u_xx + (0.8)^2*u = 0
Spatial Domain: x ∈ [0,1]
Temporal Domain: t ∈ [0,0.7]
Parameters: c = 1.2, m = 0.8

Numerical Method Details:
Spatial Discretization: Uniform grid with 600 intervals (601 points)
Spatial Discretization Method: 2nd-order central differences for u_xx
Time Integration: 2nd-order central difference (leapfrog)
Grid Spacing: dx = 1/Nx
Time Step: Compute dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), adjust dt to hit final time exactly

Boundary Conditions: Dirichlet at x=0 and x=1, u=0

Initial Conditions:
u(x,0) = sin(3*pi*x)
u_t(x,0) = 0

Computational Requirements:
- Compute u(x, T=0.7) on the grid
- Save solution to "solution_agent_kg_09.npz"
- Include x, u arrays and metadata (T, dx, dt)
- Create line plot of u(x,T) as "solution_agent_kg_09.png"

Reporting Requirements:
- Print min(u)
- Print max(u)
- Print discrete L2 norm sqrt(sum(u^2)*dx)
- Compute and print max absolute error vs reference solution
- Compute and print L2 error vs reference solution

Reference Solution: u(x,t) = cos(sqrt((1.2*3*pi)^2 + (0.8)^2)*t)*sin(3*pi*x)
