Solve the 2D heat equation using the following specification:

Partial Differential Equation: u_t = 0.1 * (u_xx + u_yy)
Spatial Domain: [0,1] x [0,1]
Time Domain: [0,0.1]
Diffusion Coefficient (alpha): 0.1

Numerical Method Details:
Spatial Discretization: Uniform grid with Nx=Ny=50
Spatial Grid Spacing: dx=dy=1/50
Temporal Discretization: Implicit Euler method
Time Step: dt=0.001 (Total 120 steps)
Laplacian Discretization: 5-point stencil (2nd-order)

Boundary Conditions: Dirichlet u=0 on all edges
Initial Condition: u(x,y,0) = sin(pi*x)*sin(pi*y)

Computational Tasks:
1. Solve the PDE numerically to time T=0.1
2. Save solution grid as "solution_agent_heat_09.npz"
3. Create heatmap plot "solution_agent_heat_09.png"
4. Compute and print:
   - Minimum value of u
   - Maximum value of u
   - Discrete L2 norm of u
   - Maximum absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution: u(x,y,t) = exp(-2*0.1*pi^2*t) * sin(pi*x)*sin(pi*y)
