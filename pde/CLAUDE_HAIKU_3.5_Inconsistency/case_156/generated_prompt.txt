Specification for 1D Compressible Navier-Stokes PDE Numerical Solution:

Implement a numerical solver for the 1D Compressible Navier-Stokes equations with the following specifications:

Computational Domain:
- Spatial domain x ∈ [-1, 1]
- Temporal domain t ∈ [0, 0.5]
- Grid: Uniform finite-volume grid with Nx = 400 cells
- Cell centers x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1
- dx = 2/Nx

Physical Parameters:
- Gamma = 1.6666666666666667
- eta = 0.1
- zeta = 0.1

Conservative Variables:
- U = [rho, m, E]
- rho: density
- m: momentum (rho*v)
- E: total energy

Initial Conditions:
- rho(x,0) = 1.0 + 0.2*sin(pi*x)
- v(x,0) = 0.1*cos(pi*x)
- p(x,0) = 1.0 + 0.2*cos(pi*x)

Boundary Conditions:
- Periodic on x = -1 and x = 1

Numerical Method:
- Finite volume method with cell-centered grid
- Rusanov (local Lax-Friedrichs) numerical flux for inviscid terms
- Centered difference for viscous terms
- 2-stage SSP-RK2 (Heun's method) time integration
- Adaptive time-stepping with CFL condition
- Equation of state: p = (Gamma-1) * (E - 0.5*m^2/rho)
- Enforce positivity by clipping rho and p to 1e-12 floor if needed

Time-Step Calculation:
- dt_conv = CFL * dx / max_j( |v_j| + c_j )
- dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 )
- dt = min(dt_conv, dt_visc)
- Adjust last step to hit final time exactly

Output Requirements:
- Compute solution at T = 0.5
- Save solution to "solution_pdebench_cns1d_eta0p1_periodic_smooth.npz"
- Include arrays: x, rho, v, p
- Include scalars: Gamma, eta, zeta, T, dx, CFL
- Create plot "solution_pdebench_cns1d_eta0p1_periodic_smooth.png"
- Print diagnostics:
  * Min/max of rho
  * Min/max of p
  * Mean of rho (mass conservation check)
