Numerical Solution Specification for Burgers' Equation (Task ID: agent_burgers_02):

Solve the 1D Burgers' equation u_t + u*u_x = 0.005*u_xx numerically with the following specifications:

Equation Details:
- PDE: u_t + u*u_x = 0.005*u_xx
- Domain: x in [0,1) periodic, t in [0,0.2]
- Viscosity (nu): 0.005

Numerical Method:
- Spatial Discretization: Conservative form using Rusanov (local Lax-Friedrichs) flux
- Convection Term: Finite-volume/conservative finite-difference
- Diffusion Term: 2nd-order central difference
- Time Integration: 1st-order IMEX (explicit convection, implicit diffusion)

Grid Parameters:
- Spatial Grid: Nx = 1200 points on [0,1) with periodic indexing
- Spatial Step: dx = 1/Nx
- Time Step: dt = 5e-5
- Total Time Steps: Nt = 4000

Initial Condition:
u(x,0) = 0.5 + sin(2*pi*x)

Boundary Conditions:
- Periodic on x
- Periodic wrap-around indexing for fluxes and diffusion stencil

Output Requirements:
- Compute u(x, T=0.2)
- Save solution to "solution_agent_burgers_02.npz"
- Save plot to "solution_agent_burgers_02.png"
- Print diagnostics: min(u), max(u), discrete L2 norm
