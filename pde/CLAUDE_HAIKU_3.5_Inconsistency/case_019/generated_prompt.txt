Solve 2D diffusion PDE with the following specification:

Partial Differential Equation:
u_t = 0.1 * u_xx + 0.01 * u_yy

Computational Domain:
x and y in [0,1], time t in [0,0.2]
Grid: 60x60 uniform grid points
Time steps: 240 steps with dt=0.001

Diffusion Parameters:
Dx = 0.1
Dy = 0.01

Boundary Conditions:
Dirichlet zero boundary conditions (u=0) on all edges

Initial Condition:
u(x,y,0) = sin(π*x) * sin(π*y)

Numerical Method:
Spatial discretization: 5-point Laplacian with scaled x and y second derivatives
Time integration: Implicit Euler method

Output Requirements:
Compute solution at T=0.2
Save solution to "solution_agent_diffusion_03.npz"
Save visualization as "solution_agent_diffusion_03.png"
Print diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Reference Solution:
u(x,y,t) = exp(-(0.1+0.01)*π²*t) * sin(π*x) * sin(π*y)
