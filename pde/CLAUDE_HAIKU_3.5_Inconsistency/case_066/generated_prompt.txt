Solve the 2D Helmholtz equation using the following specification:

Partial Differential Equation: u_xx + u_yy + k^2*u = f(x,y)
Where:
- k = 5.0
- f(x,y) = (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y)

Domain:
- x ∈ [0,1]
- y ∈ [0,1]

Numerical Method:
- Use uniform grid with Nx = Ny = 120 intervals
- Grid points: (Nx+1) × (Ny+1) including boundaries
- Grid spacing: dx = dy = 1/Nx
- Discretize using 5-point Laplacian
- Solve sparse linear system with scipy.sparse.linalg.spsolve

Boundary Conditions:
- Dirichlet: u = 0 on all boundaries

Reference Solution:
- u(x,y) = sin(pi*x) * sin(pi*y)

Output Requirements:
- Compute steady-state solution u(x,y)
- Save solution to "solution_agent_other_01_helmholtz.npz"
- Include arrays: x (1D), y (1D), u (2D)
- Save heatmap plot as "solution_agent_other_01_helmholtz.png"
- Print:
  1. min(u)
  2. max(u)
  3. Discrete L2 norm
  4. Max absolute error
  5. L2 error vs reference solution

- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
