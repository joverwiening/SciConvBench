Numerical Solution for 1D Reaction-Diffusion PDE (Logistic Reaction, Periodic)

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following specifications:

Domain is periodic [0, 1) with 512 uniform grid points.
Time domain is [0, 1.0] with 1000 fixed time steps of dt=0.001.
Parameters: nu = 5.0, rho = 2.0.

Numerical Method:
Use Strang splitting with three steps per time step:
1. Half diffusion step in Fourier space (dt/2)
2. Full reaction step solved exactly pointwise
3. Half diffusion step in Fourier space (dt/2)

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Boundary Conditions:
Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
1. Compute u(x,T=1.0) on the periodic grid
2. Save solution to "solution_pdebench_reacdiff_nu5_rho2.npz" with:
   - x array (grid points)
   - u array (solution at T)
   - Scalar parameters: nu, rho, T, dx, dt, Nx, Nt
3. Create line plot "solution_pdebench_reacdiff_nu5_rho2.png"
4. Print scalar diagnostics:
   - Minimum of u
   - Maximum of u
   - Mean of u
   - Discrete L2 norm sqrt(sum(u^2)*dx)
