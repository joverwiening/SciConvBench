Numerical Wave Equation Solver Specification:

Solve the 1D wave equation u_tt = c^2 * u_xx with the following precise requirements:

Equation: u_tt = (1.0)^2 * u_xx
Domain: x in [0,1], t in [0,1.0]
Wave speed (c): 2
Grid: Nx = 400 intervals (Nx+1 points)
Spatial discretization: Uniform grid with 2nd-order central differences for u_xx
Time integration: 2nd-order central difference (leapfrog/Störmer–Verlet)
CFL condition: c*dt/dx ≤ 0.9

Initial conditions:
- u(x,0) = sin(pi*x)
- u_t(x,0) = 0

Boundary conditions:
- Dirichlet at x=0 and x=1: u(0,t)=0, u(1,t)=0

Computational steps:
- Compute dx = 1/Nx
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(1.0/dt0)
- Adjust dt to hit T=1.0 exactly

Output requirements:
- Compute u(x, T=1.0)
- Save "solution_agent_wave_01.npz" with x, u, T, dx, dt
- Save line plot "solution_agent_wave_01.png"
- Print min(u), max(u), discrete L2 norm
- Compute and print max absolute error and L2 error vs reference solution

Reference solution: u(x,t) = cos(1.0*pi*t)*sin(pi*x)
