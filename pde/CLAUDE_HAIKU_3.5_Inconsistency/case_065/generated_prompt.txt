Solve the 2D Laplace equation (∇²u = 0) on a [0,1] x [0,1] domain using the following specification:

Numerical Method:
Discretize the Laplace equation using the 5-point stencil on a uniform grid.
Use Nx = Ny = 100 intervals (101 x 101 grid points).
Grid spacing: dx = dy = 1/100.
Grid points: x_i = i*dx (i=0..100), y_j = j*dy (j=0..100).

Boundary Conditions:
Apply Dirichlet boundary conditions:
u(x,0) = 0
u(x,1) = 1
u(0,y) = 0
u(1,y) = 0

Solution Procedure:
Construct the sparse linear system for interior nodes.
Solve using a sparse direct solver (scipy.sparse.linalg.spsolve).

Output Requirements:
Compute the steady-state solution u(x,y).
Save solution to "solution_agent_laplace_09.npz" with:
- x (1D array of x coordinates)
- y (1D array of y coordinates)
- u (2D array of solution values)
- dx, dy as metadata scalars

Generate a heatmap/contour plot saved as "solution_agent_laplace_09.png".

Print the following diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)

Use radians for trigonometric functions.
Interpret '^' as exponentiation.
