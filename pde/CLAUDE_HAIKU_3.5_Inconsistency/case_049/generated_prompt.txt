Solve the 1D Klein-Gordon PDE numerically with the following specification:

Partial Differential Equation: u_tt - (0.5)^2*u_xx + (2.0)^2*u = 0
Spatial Domain: x ∈ [0,1]
Temporal Domain: t ∈ [0,1.0]
Parameters: c = 1, m = 2.0

Numerical Method Details:
Spatial Discretization: Uniform grid with 600 intervals (601 points)
- Use 2nd-order central differences for u_xx
- Grid spacing dx = 1/Nx
- x points: x_i = 0 + i*dx, i = 0 to Nx

Time Integration:
- Use 2nd-order leapfrog method for time stepping
- Handle +m^2*u term explicitly at time level n
- Compute dt to satisfy c*dt/dx ≤ 0.9
- Compute Nt to exactly hit final time T=1.0

Boundary Conditions:
- Dirichlet at x=0 and x=1: u = 0

Initial Conditions:
- u(x,0) = sin(2*pi*x)
- u_t(x,0) = 0

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_kg_02.npz"
- Save line plot of u(x,T) to "solution_agent_kg_02.png"
- Print diagnostics:
  * min(u)
  * max(u)
  * Discrete L2 norm
  * Max absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = cos(sqrt((0.5*2*pi)^2 + (2.0)^2)*t)*sin(2*pi*x)
