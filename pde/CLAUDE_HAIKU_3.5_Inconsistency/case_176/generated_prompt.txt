Solve the 1D Reaction-Diffusion PDE with the following specification:

Implement a numerical solver for the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following exact details:

Computational Domain:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 1.0]
- Spatial grid: Uniform periodic grid with Nx=512 points
- Time grid: Fixed dt=0.001 with Nt=1000 steps

Parameters:
- nu = 10.0
- rho = 1.0

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical Method:
Use Strang splitting with three steps:
1. Diffusion half-step in Fourier space (dt/2)
2. Reaction full-step solved exactly pointwise
3. Diffusion half-step in Fourier space (dt/2)

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu10_rho1.npz" with arrays: x, u, and scalars: nu, rho, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho1.png"
- Print scalar diagnostics: min(u), max(u), mean(u), and discrete L2 norm

Coding Notes:
- Use radians for trigonometric functions
- Interpret '^' as exponentiation
- Use Python's '**' for powers
