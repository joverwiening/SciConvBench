Specification for Heat Equation Numerical Solution (Task ID: agent_heat_08):

Solve the 1D heat equation u_t = 0.1 * u_xx + sin(pi*x)*cos(2*pi*t) numerically with the following specifications:

Domain: x in [0, 1], t in [0, 1.0]
Diffusion coefficient (alpha): 0.1

Numerical Method Details:
Spatial Discretization: 
- Use uniform grid on [0,1] with Nx = 300 intervals
- Use 2nd-order central differences for u_xx in the interior
- Grid points: Nx+1 points including both boundaries
- Spatial step size: dx = 1/Nx

Time Integration:
- Method: Crank-Nicolson 
- Time step size: dt = 0.001
- Total time steps: 1200
- Include source term at average of current and next time levels

Boundary Conditions:
- Dirichlet at x=0 and x=1
- u(0,t) = 0
- u(1,t) = 0

Initial Condition:
- u(x,0) = 0

Output Requirements:
- Compute u(x, T=1.0) on the specified grid
- Save solution to "solution_agent_heat_08.npz" with:
  * x array (1D grid points)
  * u array (1D solution at final time)
  * Metadata: T, dx, dt
- Create line plot of u(x,T) and save as "solution_agent_heat_08.png"
- Print scalar diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
