Numerical Wave Equation Solver Specification:

Solve the 1D wave equation u_tt = (0.5)^2 * u_xx with the following precise implementation:

Computational Domain:
- Spatial domain x ∈ [0,1]
- Time domain t ∈ [0,1.0]
- Grid: Nx = 400 intervals (Nx+1 points)
- dx = 1/Nx
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Numerical Method:
- Spatial discretization: 2nd-order central differences for u_xx in interior
- Time integration: 2nd-order central difference (leapfrog/Störmer–Verlet)
- CFL condition: c*dt/dx ≤ 0.9
- Initialization: Taylor start method for first time step
- Boundary conditions: Dirichlet (u(0,t)=0, u(1,t)=0) enforced at every time step

Initial Conditions:
- u(x,0) = sin(2*pi*x)
- u_t(x,0) = 0

Outputs:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_wave_02.npz"
- Save plot to "solution_agent_wave_02.png"
- Print:
  * min(u)
  * max(u)
  * Discrete L2 norm
  * Max absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = cos(0.5*2*pi*t)*sin(2*pi*x)
