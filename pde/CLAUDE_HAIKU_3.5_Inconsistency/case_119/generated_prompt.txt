Specification for 1D Linear Advection PDE Numerical Solution (Task ID: molk_018):

Solve the 1D linear advection PDE u_t + q*u_x = 0 with the following detailed specifications:

Computational Domain:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 1.1]
- Spatial grid: Uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1, where dx = 1/Nx

Parameters:
- Advection velocity q = 1.5

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x)

Numerical Method:
- Spatial discretization: 1st-order upwind finite difference for u_x
- Time integration: Forward Euler method
- Time step calculation: 
  * CFL = 0.5
  * dt0 = CFL * dx / |q|
  * Nt = ceil(T / dt0)
  * dt = T / Nt

Output Requirements:
- Compute solution at T = 1.1
- Save solution to "solution_molk_018.npz" with arrays:
  * x (1D, length Nx)
  * u (1D, length Nx)
  * Scalar values: T, dx, Nx, q
- Create line plot of u(x,T) and save as "solution_molk_018.png"
- Print scalar diagnostics:
  * Minimum of u
  * Maximum of u
  * Mean of u
  * Discrete L2 norm: sqrt(sum(u^2) * dx)
- Compute and print error metrics:
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Coding Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
