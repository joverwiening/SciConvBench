Specification for 1D Viscous Burgers PDE Numerical Solution:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

Domain Configuration:
Spatial domain is [0, 1) with periodic boundary conditions
Time domain is [0, 1.0]
Spatial grid: Uniform periodic grid with Nx=512 points
Grid points: x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx
Parameter nu = 4.0

Numerical Method:
Use Strang splitting method with three substeps:
1. Diffusion half-step in Fourier space (duration dt/2)
2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
3. Diffusion half-step in Fourier space (duration dt/2)

Time Stepping:
Use CFL=0.4 with estimated max speed of 1.0
Compute dt0 = CFL*dx/1.0
Determine Nt = ceil(T/dt0)
Adjust final dt to hit T=1.0 exactly

Initial Condition:
u(x,0) = sin(2*pi*x)

Output Requirements:
1. Compute solution u(x,T=1.0) on periodic grid
2. Save "solution_pdebench_burgers_nu4.npz" with:
   - x array (grid points)
   - u array (solution at final time)
   - Scalar parameters: nu, T, dx, dt, Nx, Nt
3. Save line plot "solution_pdebench_burgers_nu4.png"
4. Print diagnostics:
   - Minimum of u
   - Maximum of u
   - Discrete mean value of u
   - Discrete L2 norm sqrt(sum(u^2)*dx)

Coding Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
- Treat all functions exactly as written
