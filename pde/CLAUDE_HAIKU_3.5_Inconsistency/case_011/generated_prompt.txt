Specification for Allen-Cahn PDE Numerical Solution:

Solve the Allen-Cahn PDE u_t = (0.02)^2*(u_xx + u_yy) + u - u^3 numerically with the following specifications:

Computational Domain:
- Spatial domain: [0,1] x [0,1]
- Time domain: [0,0.1]
- Grid: Nx = Ny = 300 uniform grid points
- Time step: dt = 0.0001 (1000 total time steps)

Numerical Method:
- Spatial discretization: 5-point Laplacian for u_xx + u_yy
- Time integration: Semi-implicit forward Euler
- Solve sparse linear system at each time step for u^{n+1}

Boundary Conditions:
- Dirichlet boundary conditions: u = 0 on all boundaries
- Enforce boundary conditions at every time step

Initial Condition:
- r = sqrt((x-0.5)^2 + (y-0.5)^2)
- u(x,y,0) = tanh((0.25 - r)/(sqrt(2)*0.02))

Output Requirements:
- Compute u(x,y,T=0.1) on the 2D grid
- Save solution to "solution_agent_allen_cahn_05.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (Ny, Nx))
  * Metadata: T, dx, dy, dt
- Create heatmap/contour plot "solution_agent_allen_cahn_05.png"
- Print diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
