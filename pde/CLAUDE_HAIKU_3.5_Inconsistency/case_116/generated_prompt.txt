Solve the 1D sine-Gordon equation numerically with the following specification:

Partial Differential Equation: u_tt + q*sin(u) = u_xx
Equation Parameters: q = 1.0

Spatial Domain: [0, 1) with periodic boundary
Temporal Domain: [0, 2.0]

Spatial Discretization:
- Use uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Numerical Method:
- Reformulate as first-order system: u_t = v, v_t = u_xx - q*sin(u)
- Spatial discretization: 2nd-order central differences for u_xx
- Time integration: RK4 method
- Time step: dt = 0.0005
- Total time steps: Nt = 4000

Initial Conditions:
- u(x,0) = 0.1*sin(2*pi*x)
- u_t(x,0) = 0

Output Requirements:
- Compute u(x,T=2.0) on periodic grid
- Save solution to "solution_molk_015.npz" with arrays:
  * x (1D length Nx)
  * u (1D length Nx)
  * T, dx, Nx
  * Parameter scalars
- Create line plot of u(x,T) as "solution_molk_015.png"
- Print at T=2.0:
  * Minimum of u
  * Maximum of u
  * Mean of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
