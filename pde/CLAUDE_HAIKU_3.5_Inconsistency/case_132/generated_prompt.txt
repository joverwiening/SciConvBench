Numerical Solution Specification for 1D Nonlinear Convection-Diffusion PDE (Task ID: molk_031)

Solve the PDE u_t = -q1*∂_x(cos(u)) + (q2/pi)*u_xx with the following specifications:

Domain Configuration:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 0.5]
- Grid: Uniform periodic grid with Nx = 1024 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- Grid spacing: dx = 1/Nx

PDE Parameters:
- q1 = 1.0
- q2 = 0.05

Initial Condition:
- u(x,0) = 0.5*sin(2*pi*x)

Numerical Method:
- Spatial discretization for convection: Conservative finite-volume Rusanov flux with wave speed alpha = max|sin(u)|
- Spatial discretization for diffusion: 2nd-order central differences
- Time integration: SSP-RK2
- Time step calculation:
  * dt_adv = 0.2*dx/1
  * dt_diff = 0.2*dx^2/(q2/pi)
  * dt = min(dt_adv, dt_diff)
  * Nt = ceil(0.5/dt)
  * Final dt = 0.5/Nt

Output Requirements:
- Compute u(x,T=0.5) on the periodic grid
- Save solution to "solution_molk_031.npz" with arrays:
  * x (1D, length Nx)
  * u (1D, length Nx)
  * T, dx, Nx
  * Parameters q1, q2
- Create line plot of u(x,T) as "solution_molk_031.png"
- Print scalar diagnostics:
  * min(u)
  * max(u)
  * mean(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
