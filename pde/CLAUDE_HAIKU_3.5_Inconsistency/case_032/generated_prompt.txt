Specification for Heat Equation Numerical Solution (Task ID: agent_heat_03):

Solve the 1D heat equation u_t = 0.2 * u_xx numerically with the following specifications:

Spatial Domain: x in [0, 1]
Time Domain: t in [0, 0.3]
Diffusion Coefficient (alpha): 0.2

Numerical Method Details:
- Use a uniform grid with Nx = 300 intervals (Nx+1 points)
- Spatial discretization: 2nd-order central differences for u_xx
- Time integration: Crank-Nicolson method
- Grid spacing: dx = 1/Nx
- Time step: dt = 0.0005 (720 total time steps)

Initial Condition:
u(x,0) = sin(pi*x) + 0.5*sin(3*pi*x)

Boundary Conditions:
- Dirichlet at x=0: u(0,t) = 0
- Dirichlet at x=1: u(1,t) = 0

Output Requirements:
- Compute solution at final time T = 0.3
- Save solution data in "solution_agent_heat_03.npz"
  - Include arrays: x, u
  - Include metadata: T, dx, dt
- Create line plot of u(x,T) saved as "solution_agent_heat_03.png"
- Print the following diagnostics at T:
  - Minimum value of u
  - Maximum value of u
  - Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print max absolute error vs reference solution
- Compute and print L2 error vs reference solution

Reference Solution for Verification:
u(x,t) = exp(-0.2*pi^2*t)*sin(pi*x) + 0.5*exp(-0.2*(3*pi)^2*t)*sin(3*pi*x)

Coding Note: Use '^' for exponentiation in math, use '**' for powers in Python implementation.
