Specification for Solving 1D Viscous Burgers Equation:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

PDE Details:
- Equation: u_t + ∂_x(0.5*u^2) = nu * u_xx
- Domain: x in [0, 1) periodic, t in [0, 1.0]
- Viscosity parameter nu = 1.0

Numerical Method:
- Spatial discretization: Uniform periodic grid with Nx=512 points
- Time integration: Strang splitting method
- Advection substep: Finite-volume Rusanov (local Lax-Friedrichs) flux
- Diffusion substeps: Exact solution in Fourier space

Initial Condition:
- u(x,0) = sin(2*pi*x)

Boundary Conditions:
- Periodic: u(0,t) = u(1,t) for all t

Time Stepping:
- CFL = 0.4
- dt0 = CFL*dx/1.0
- Nt = ceil(T/dt0)
- Final dt adjusted to hit T=1.0 exactly

Outputs:
- Compute u(x,T=1.0) on periodic grid
- Save solution to "solution_pdebench_burgers_nu1.npz"
- Save plot to "solution_pdebench_burgers_nu1.png"
- Print diagnostics: min(u), max(u), mean(u), L2 norm
