Specification for Wave Equation Numerical Solution (agent_wave_06):

Solve the 1D wave equation u_tt = c^2 * u_xx with the following detailed requirements:

Equation: u_tt = (1.0)^2 * u_xx
Domain: x in [0,1], t in [0,1.0]
Wave speed (c): 2
Grid: 400 intervals (Nx+1 = 401 points)
Spatial discretization: Uniform grid with 2nd-order central differences for u_xx
Time integration: 2nd-order central difference (leapfrog/Störmer–Verlet)

Initial Conditions:
- u(x,0) = cos(pi*x)
- u_t(x,0) = 0

Boundary Conditions:
- Neumann at x=0 and x=1: u_x(0,t)=0, u_x(1,t)=0
- Implement using ghost point mirroring technique

Time Step Calculation:
- CFL condition: c*dt/dx ≤ 0.9
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(T/dt0)
- Adjust dt to hit T=1.0 exactly

Output Requirements:
1. Compute u(x, T=1.0)
2. Save solution to "solution_agent_wave_06.npz" with:
   - x array
   - u array
   - Metadata: T, dx, dt
3. Create plot "solution_agent_wave_06.png" of u(x,T)
4. Print diagnostics:
   - min(u)
   - max(u)
   - Discrete L2 norm
5. Compute and print error metrics:
   - Max absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution: u(x,t) = cos(pi*x)*cos(1.0*pi*t)
