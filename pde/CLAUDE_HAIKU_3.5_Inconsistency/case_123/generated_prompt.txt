Specification for Solving 1D Nonlinear Reaction-Diffusion PDE (Task ID: molk_022):

Implement a numerical solver for the PDE u_t = q1*u_xx + q2*(u**2)*(1-u) with the following specifications:

Computational Domain:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 1.0]
- Spatial grid: Uniform periodic grid with Nx=512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx

Parameters:
- q1 = 0.01
- q2 = 2.0
- a = 2.0

Numerical Method:
- Spatial discretization: 2nd-order central differences for u_xx
- Time integration: Explicit RK4 method
- Time step: dt = 0.0005
- Total time steps: Nt = 2000

Initial Condition:
- u(x,0) = 0.2 + 0.1*sin(2*pi*x)

Boundary Conditions:
- Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_molk_022.npz" with arrays:
  * x (1D length Nx)
  * u (1D length Nx)
  * T, dx, Nx
  * Parameter scalars
- Create line plot of u(x,T) and save as "solution_molk_022.png"
- Print scalar diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Mean of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)

Coding Notes:
- Use radians for trigonometric functions
- Use '**' for exponentiation in Python
- Ensure numerical stability of RK4 method
