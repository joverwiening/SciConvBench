Numerical Solution for 1D Reaction-Diffusion PDE (Logistic Reaction, Periodic)

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following specifications:

Domain is [0, 1) with periodic boundary conditions.
Spatial discretization uses Nx=512 uniform periodic grid points.
Time domain is [0, 1.0] with Nt=1000 fixed time steps.
Time step dt = 0.001 to reach T=1.0 exactly.

Numerical Method:
Use Strang splitting with three steps per time step:
1. Half diffusion step in Fourier space (dt/2)
2. Full reaction step solved exactly pointwise
3. Half diffusion step in Fourier space (dt/2)

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Parameters:
- nu = 0.5
- rho = 5.0

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu0p5_rho5.npz"
- Create line plot "solution_pdebench_reacdiff_nu0p5_rho5.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm

Coding Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
