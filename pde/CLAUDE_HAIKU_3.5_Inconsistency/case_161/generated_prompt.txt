Numerical Solution Specification for 1D Compressible Navier-Stokes Sod Shock Tube Problem:

Solve the 1D Compressible Navier-Stokes equations on domain x ∈ [-1, 1] from t = 0 to t = 0.2.

Governing Equations:
- Solve conservation equations for rho, m, and E in conservative form
- Use equation of state p = (Gamma-1) * (E - 0.5*m^2/rho)
- Enforce positivity by clipping rho and p to 1e-12 floor if needed

Numerical Method:
- Grid: Uniform finite-volume grid with Nx = 800 cells
- Cell centers: x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1
- Discretization: Conservative variables U = [rho, m, E]
- Convective Flux: Rusanov (local Lax-Friedrichs) numerical flux
- Viscous Terms: Centered difference for v_x, interface-averaged sigma
- Time Integration: 2-stage SSP-RK2 (Heun's method)
- Time Step: Adaptive dt based on CFL and viscous stability conditions

Initial Conditions:
- x < 0: rho_L = 1.0, v_L = 0.0, p_L = 1.0
- x ≥ 0: rho_R = 0.1, v_R = 0.0, p_R = 0.1

Parameters:
- Gamma = 1.6666666666666667
- eta = 1e-08
- zeta = 1e-08

Boundary Conditions:
- Transmissive/outflow (zero-gradient) at x = -1 and x = 1
