Numerical Solution Specification for Burgers' Equation:

Solve the 1D Burgers' equation u_t + u*u_x = 0.01*u_xx with the following precise specifications:

PDE Details:
- Equation: u_t + u*u_x = 0.01*u_xx
- Domain: x ∈ [0,1], t ∈ [0,0.5]
- Viscosity (nu): 0.01

Numerical Method:
- Spatial Discretization: Conservative form using Rusanov flux
- Convection Flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i)
- Diffusion: 2nd-order central difference
- Time Integration: 1st-order IMEX (explicit convection, implicit diffusion)

Grid Parameters:
- Spatial Grid: Nx = 800 intervals (Nx+1 points)
- Spatial Step: dx = 1/Nx
- Time Step: dt = 1e-4
- Total Time Steps: Nt = 5000

Boundary Conditions:
- Dirichlet at x=0 and x=1: u(0,t) = 0, u(1,t) = 0
- Enforce Dirichlet BC each time step

Initial Condition:
- u(x,0) = sin(π*x)
