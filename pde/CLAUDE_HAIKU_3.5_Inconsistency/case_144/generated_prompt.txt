Specification for 1D Viscous Burgers PDE Numerical Solution:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

Equation Details:
- PDE: u_t + ∂_x(0.5*u^2) = nu * u_xx
- Domain: x in [0, 1) periodic, t in [0, 1.0]
- Viscosity parameter nu = 0.02

Numerical Method:
- Use Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space
  2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
  3. Diffusion half-step in Fourier space

Grid Specifications:
- Uniform periodic grid
- Nx = 512 points
- dx = 1/Nx
- Grid points: x_j = j*dx for j=0,...,Nx-1

Time Stepping:
- CFL = 0.4
- Initial dt0 = CFL*dx/1.0
- Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Initial Condition:
- u(x,0) = sin(2*pi*x)

Output Requirements:
- Compute solution at T = 1.0
- Save solution to "solution_pdebench_burgers_nu0p02.npz"
- Include arrays: x, u
- Include scalars: nu, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_burgers_nu0p02.png"
- Print diagnostics:
  1. Minimum u value
  2. Maximum u value
  3. Discrete mean value
  4. Discrete L2 norm
