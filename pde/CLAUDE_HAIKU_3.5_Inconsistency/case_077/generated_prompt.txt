Solve the 2D Poisson equation using the following specification:

Partial Differential Equation: u_xx + u_yy = f(x,y)
Where f(x,y) = (1 - π²) * exp(x) * sin(π*y)

Domain: 
- x ∈ [0,1]
- y ∈ [0,1]

Numerical Method:
- Use a uniform grid with Nx = Ny = 120 intervals
- Grid points: Nx+1 by Ny+1 points including boundaries
- Grid spacing: dx = dy = 1/Nx
- x_i = i*dx (i=0..Nx)
- y_j = j*dy (j=0..Ny)

Discretization:
- Use 5-point stencil (2nd-order) for spatial discretization
- Solve sparse linear system using scipy.sparse.linalg.spsolve

Boundary Conditions:
- Dirichlet conditions on all four edges
- Boundary values: u(x,y) = exp(x) * sin(π*y)

Output Requirements:
- Compute steady-state solution u(x,y)
- Save solution to "solution_agent_poisson_04.npz"
  - Include arrays: x (1D), y (1D), u (2D)
  - Include metadata: dx, dy
- Create heatmap/contour plot "solution_agent_poisson_04.png"
- Print diagnostics:
  - Minimum value of u
  - Maximum value of u
  - Discrete L2 norm: sqrt(sum(u²)*dx*dy)
- Compute and print error metrics:
  - Maximum absolute error vs reference solution
  - L2 error vs reference solution

Reference Solution: u(x,y) = exp(x) * sin(π*y)
