Solve the Korteweg-de Vries (KdV) equation using a Fourier pseudo-spectral method with the following specifications:

Equation: u_t + 6*u*u_x + u_xxx = 0
Domain: x in [0,1) periodic, t in [0,0.1]
Initial condition: u(x,0) = 0.5*cos(2*pi*x)

Numerical Method Details:
Use a Fourier pseudo-spectral method with FFT for spatial derivatives.
Grid: Nx = 1024 points
Time integration: Explicit RK4 method
Time step: dt = 1e-5 (total 12000 steps)
Final time: T = 0.1

Computational Steps:
Compute spatial derivatives u_x and u_xxx using FFT (multiply by ik and (ik)^3).
Compute nonlinear term 6*u*u_x in physical space.

Output Requirements:
Compute u(x, T=0.1) on the grid.
Save solution to "solution_agent_other_03_kdv.npz" with arrays:
- x (1D grid points)
- u (1D solution at final time)
- Metadata: T, dx, dt
Create line plot of u(x,T) as "solution_agent_other_03_kdv.png"
Print diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm (sqrt(sum(u^2)*dx))
