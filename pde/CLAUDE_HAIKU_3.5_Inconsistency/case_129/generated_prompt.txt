Numerical Solution Specification for 1D Inviscid Conservation Law (Task ID: molk_028)

Solve the 1D periodic PDE u_t = -k*∂_x((1/3)*u^3) with the following precise specifications:

Governing Equation:
- PDE: u_t = -k*∂_x((1/3)*u^3)
- Parameter k = 1.0

Domain and Grid:
- Spatial domain: x ∈ [0, 1) with periodic boundary
- Temporal domain: t ∈ [0, 0.2]
- Grid: Uniform periodic grid with Nx = 1024 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- Grid spacing: dx = 1/Nx

Initial Condition:
- u(x,0) = 0.5*sin(2*pi*x)

Numerical Method:
- Spatial discretization: Conservative finite-volume method with Rusanov flux
- Flux function: f(u) = (1/3)u^3
- Time integration: SSP-RK2
- Time step calculation:
  * Estimate max|f'(u)| = max|u^2|
  * CFL = 0.2
  * dt0 = CFL*dx/max|f'|
  * Nt = ceil(T/dt0)
  * dt = T/Nt

Output Requirements:
- Compute u(x,T=0.2) on the periodic grid
- Save solution to "solution_molk_028.npz" with arrays:
  * x (1D, length Nx)
  * u (1D, length Nx)
  * T, dx, Nx, and parameter scalars
