Numerical Solution Specification for 1D Compressible Navier-Stokes PDE:

Solve the 1D Compressible Navier-Stokes PDE with the following specifications:

Computational Domain:
- Spatial domain: x ∈ [-1, 1]
- Temporal domain: t ∈ [0, 0.5]
- Grid: Uniform finite-volume grid with Nx = 400 cells
- Cell centers: x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1
- Grid spacing: dx = 2/Nx

Physical Parameters:
- Gamma = 1.6666666666666667
- eta = 1e-08
- zeta = 1e-08

Conservative Variables:
- U = [rho, m, E]
- rho: density
- m: momentum (rho*v)
- E: total energy

Initial Conditions:
- rho(x,0) = 1.0 + 0.2*sin(pi*x)
- v(x,0) = 0.1*cos(pi*x)
- p(x,0) = 1.0 + 0.2*cos(pi*x)

Boundary Conditions:
- Transmissive/outflow (zero-gradient) at x=-1 and x=1

Numerical Method:
- Equation of State: p = (Gamma-1) * (E - 0.5*m^2/rho)
- Convective Flux: Rusanov (local Lax-Friedrichs) numerical flux
- Viscous Terms: Centered difference for v_x, interface-averaged sigma
- Time Integration: 2-stage SSP-RK2 (Heun's method)
- Time Step: Adaptive dt based on CFL and viscous stability

Time Stepping:
- dt_conv = CFL * dx / max_j( |v_j| + c_j )
- dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 )
- dt = min(dt_conv, dt_visc)

Output Requirements:
- Compute solution at T = 0.5
- Save solution to "solution_pdebench_cns1d_eta1em8_outflow_smooth.npz"
- Create plot "solution_pdebench_cns1d_eta1em8_outflow_smooth.png"
- Print diagnostics:
  * Min/max of rho
  * Min/max of p
  * Mean of rho
