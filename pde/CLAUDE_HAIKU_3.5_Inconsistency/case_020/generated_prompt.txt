Numerical Solution Specification for Diffusion PDE (agent_diffusion_04):

Solve the 2D variable-coefficient diffusion equation with the following specifications:

Partial Differential Equation:
u_t = ∇·( D(x,y) ∇u )
Where D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y))

Domain:
x ∈ [0,1]
y ∈ [0,1]
t ∈ [0,0.1]

Grid Parameters:
Use Nx = Ny = 80 uniform grid points
Use time step dt = 0.0005 (total 240 time steps)

Initial Condition:
u(x,y,0) = sin(pi*x)*sin(pi*y)

Boundary Conditions:
Apply Dirichlet zero boundary conditions (u = 0) on all edges

Numerical Method:
Use conservative 2nd-order flux-form discretization for spatial derivatives
Use arithmetic face averages for diffusion coefficient interpolation
Use implicit Euler time integration, solving the resulting sparse linear system
