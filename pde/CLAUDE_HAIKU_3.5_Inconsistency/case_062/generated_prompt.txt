Solve the 2D Laplace equation (∇²u = 0) on a [0,1] x [0,1] domain with the following specification:

Numerical Method:
Discretize using 5-point stencil on a uniform grid with Nx = Ny = 100 intervals.
Grid points: x_i = i*dx, y_j = j*dy, where dx = dy = 1/Nx.
Use scipy.sparse.linalg.spsolve as the linear solver.

Boundary Conditions:
Apply Dirichlet conditions on all edges with u(x,y) = x^2 - y^2.

Solution Computation:
Solve the sparse linear system for interior grid points.
Compute steady-state solution u(x,y) on the 2D grid.

Output Requirements:
Save solution data in "solution_agent_laplace_06.npz" with:
- x (1D array of x coordinates)
- y (1D array of y coordinates)
- u (2D array of solution values, shape (len(y), len(x)))
- dx and dy as metadata scalars

Generate visualization "solution_agent_laplace_06.png" as a heatmap/contour plot.

Diagnostic Outputs:
Print the following:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Coding Note:
Use '^' for exponentiation in mathematical expressions.
Use '**' for powers when implementing in Python.
