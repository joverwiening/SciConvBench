Solve the 1D Klein-Gordon PDE numerically with the following specification:

Partial Differential Equation: u_tt - (1.0)^2*u_xx + (3.0)^2*u = 0
Spatial Domain: x in [0,1) periodic
Time Domain: t in [0,0.8]
Number of Spatial Points: Nx = 512
Spatial Discretization: Uniform periodic grid with 2nd-order central differences
Time Integration: Leapfrog method with mass term
Parameters: c = 1.0, m = 3.0

Initial Conditions:
u(x,0) = cos(2*pi*x)
u_t(x,0) = 0

Numerical Method Details:
- Use wrap-around for u_xx calculation
- CFL condition: c*dt/dx ≤ 0.9
- Compute initial time step as dt0 = 0.9*dx/c
- Set Nt = ceil(T/dt0) to ensure exact final time
- Taylor start initialization including -m^2*u0

Output Requirements:
- Compute u(x, T=0.9)
- Save solution to "solution_agent_kg_04.npz"
