Solve the Lotka-Volterra predator-prey ODE system with the following specification:

Implement a numerical solver for the ODE system:
dx/dt = alpha*x - beta*x*y
dy/dt = delta*x*y - gamma*y

Time domain parameters:
- Solve from t = 0.0 to t = 30.0
- Use Classical 4th-order Runge-Kutta (RK4) method
- Fixed time step dt = 0.01
- Total number of steps Nt = 3000

System parameters:
- alpha = 1.5
- beta = 2.0
- gamma = 3.0
- delta = 1.0

Initial conditions:
- x(0) = 1.0
- y(0) = 1.0

Numerical solution requirements:
- Compute full state vector at all time points
- Generate time array t with length Nt+1
- Generate solution array Y with shape [Nt+1, 2]

Output requirements:
- Save solution data to "solution_molk_008.npz"
- Include arrays: t, Y, and parameter scalars
- Create line plot "solution_molk_008.png" showing x and y vs t
- Print final state values at T
- Print minimum and maximum values for x and y over time
