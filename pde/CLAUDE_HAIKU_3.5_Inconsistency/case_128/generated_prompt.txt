Numerical Solution Specification for 1D Nonlinear Convection-Diffusion PDE (Task ID: molk_027)

Solve the 1D nonlinear convection-diffusion PDE with the following specifications:

Governing PDE: u_t = -q1*∂_x((1/3)*u^3) + (q2/pi)*u_xx
Domain: x in [0, 1) with periodic boundary, t in [0, 0.5]
Parameters: q1 = 1.0, q2 = 0.05

Numerical Method Details:
Spatial Grid: Uniform periodic grid with Nx = 1024 points
Grid Points: x_j = j*dx for j=0,...,Nx-1, with dx = 1/Nx
Spatial Discretization: 
- Conservative finite-volume flux (Rusanov) for nonlinear convection term
- 2nd-order central differences for diffusion term
Time Integration: SSP-RK2 method
Time Step Calculation:
- Estimate max|f'(u)| = max|u^2|
- Initial |u| <= 0.5
- CFL = 0.2
- dt0 = CFL*dx/max|f'|
- dt_diff = 0.2*dx^2/(q2/pi)
- dt = min(dt0, dt_diff)
- Nt = ceil(T/dt), adjust dt = T/Nt

Initial Condition: u(x,0) = 0.5*sin(2*pi*x)
Boundary Condition: Periodic (u(0,t) = u(1,t))

Output Requirements:
1. Compute u(x,T=0.5) on the periodic grid
2. Save "solution_molk_027.npz" with:
   - x array (1D, length Nx)
   - u array (1D, length Nx)
   - T, dx, Nx
   - Parameter scalars
3. Save line plot "solution_molk_027.png" of u(x,T)
4. Print at T=0.5:
   - min(u)
   - max(u)
   - mean(u)
   - Discrete L2 norm: sqrt(sum(u^2)*dx)
