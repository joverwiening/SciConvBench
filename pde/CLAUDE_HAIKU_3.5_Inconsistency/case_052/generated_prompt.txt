Specification for Klein-Gordon PDE Numerical Solution (Task ID: agent_kg_05):

Implement a numerical solver for the 2D Klein-Gordon equation u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0.

Numerical Method Details:
Solve the PDE on a 2D domain [0,1] x [0,1] from t=0 to t=0.8.
Use a uniform grid with Nx = Ny = 256 intervals (257x257 points).
Compute dx = dy = 1/Nx = 1/256.
Use 5-point Laplacian for spatial discretization.
Apply 2nd-order central difference in time.
Calculate dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) and adjust dt to hit final time exactly.

Initial Conditions:
Set u(x,y,0) = sin(pi*x)*sin(pi*y)
Set u_t(x,y,0) = 0

Boundary Conditions:
Apply Dirichlet boundary conditions u = 0 on all boundaries.

Computational Parameters:
c = 1.0
m = 1.0
Final time T = 0.8

Output Requirements:

Save solution to "solution_agent_kg_05.npz" with:
- x (1D array of x coordinates)

- Metadata: T, dx, dy, dt

Reference Solution:
