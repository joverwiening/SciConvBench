Specification for Solving 1D Inviscid Conservation Law with Cos Flux (Task ID: molk_032):

Solve the Partial Differential Equation (PDE):
u_t = -k*∂_x( cos(u) )

Numerical Solution Specifications:
Solve the PDE using the following precise requirements.

Domain and Grid:
- Spatial domain: x in [0, 1) with periodic boundary
- Temporal domain: t in [0, 0.2]
- Grid type: Uniform periodic grid
- Number of grid points: Nx = 1024
- Grid points: x_j = j*dx for j=0,...,Nx-1
- Grid spacing: dx = 1/Nx

Parameters:
- k = 1.0

Initial Condition:
u(x,0) = 0.5*sin(2*pi*x)

Numerical Method:
- Spatial Discretization: Conservative finite-volume Rusanov flux
- Flux Function: f(u) = cos(u)
- Wave Speed: alpha = max|sin(u)|, bounded by 1
- Time Integration: SSP-RK2 (Strong Stability Preserving Runge-Kutta 2)
- Time Step Calculation:
  * CFL = 0.2
  * dt0 = CFL*dx/1.0
  * Nt = ceil(T/dt0)
  * dt = T/Nt
