Specification for Solving 1D Burgers' Equation Numerically:

Solve the 1D Burgers' equation u_t + u*u_x = 0.01*u_xx numerically with the following specifications:

Equation Details:
- PDE: u_t + u*u_x = 0.01*u_xx
- Domain: x in [0,1) periodic, t in [0,0.5]
- Viscosity (nu): 0.01

Numerical Method:
- Spatial Discretization: Conservative form using Rusanov (local Lax-Friedrichs) flux
- Convection Term: f(u) = 0.5*u^2
- Diffusion: 2nd-order central difference
- Time Integration: 1st-order IMEX (explicit convection, implicit diffusion)
- Grid: 800 points (Nx=800) on [0,1) with periodic indexing
- Time Step: dt = 1e-4, Nt = 5000 steps

Initial Condition:
- u(x,0) = sin(2*pi*x)

Boundary Conditions:
- Periodic wrap-around for both convection fluxes and diffusion stencil

Output Requirements:
- Compute u(x, T=0.5)
- Save solution to "solution_agent_burgers_01.npz"
- Include arrays: x, u, with metadata: T, dx, dt
- Create plot "solution_agent_burgers_01.png"
- Print diagnostics: min(u), max(u), discrete L2 norm

Implementation Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation, '**' in Python
- Solve sparse linear system each time step (e.g., scipy.sparse.linalg.spsolve)
