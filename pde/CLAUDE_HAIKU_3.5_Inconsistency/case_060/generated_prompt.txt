Solve the 2D Laplace equation (∇²u = 0) on a [0,1] x [0,1] domain with the following specification:

Numerical Method:
Discretize the Laplace equation using the 5-point stencil on a uniform grid.
Use Nx = Ny = 100 intervals (101 x 101 grid points).
Grid spacing: dx = dy = 1/100.
Grid points: x_i = i*dx, y_j = j*dy for i,j = 0..100.

Boundary Conditions:
Apply Dirichlet boundary conditions with u(x,y) = y on all four edges.

Solution Process:
Construct the sparse linear system representing the discretized Laplace equation.
Solve the system using a sparse direct solver (scipy.sparse.linalg.spsolve).

Output Requirements:
Compute the steady-state solution u(x,y) on the 2D grid.
Save solution data in "solution_agent_laplace_04.npz" with:
- x (1D array of x coordinates)
- y (1D array of y coordinates)
- u (2D array of solution values, shape (len(y), len(x)))
- dx and dy as metadata scalars

Generate a heatmap/contour plot of u(x,y) and save as "solution_agent_laplace_04.png".

Diagnostics to Print:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Verification:
Reference solution is u(x,y) = y, which is an exact harmonic function.
