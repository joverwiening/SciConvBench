Specification for Diffusion-Reaction PDE Numerical Solution (Task ID: agent_diffusion_reaction_05):

Solve the 2D diffusion-reaction PDE u_t = 0.01*(u_xx + u_yy) + 2.0*u*(1 - u) with the following detailed requirements:

Computational Domain:
- Spatial domain: [0,1] x [0,1]
- Time domain: [0,1.0]
- Grid: Uniform 120x120 intervals (121x121 points)
- Grid spacing: dx = dy = 1/120
- Time step: dt = 0.001 (1000 total time steps)

Parameters:
- Diffusion coefficient D = 0.01
- Reaction rate r = 2.0

Numerical Method:
- Spatial discretization: 5-point Laplacian on uniform grid
- Time integration: First-order IMEX method
  - Diffusion term: Implicit (backward Euler)
  - Reaction term: Explicit (forward Euler)
- Boundary conditions: 
  - Neumann (zero flux) implemented via ghost node mirroring
  - Dirichlet boundary values set to zero

Initial Condition:
u(x,y,0) = 0.2 + 0.05*cos(2*pi*x)*cos(2*pi*y)

Solution Requirements:
- Compute solution at T = 1.0
- Save solution to "solution_agent_diffusion_reaction_05.npz"
