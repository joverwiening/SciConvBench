Numerical Solution Specification for 1D Linear Advection-Diffusion PDE (Task ID: molk_026)

Solve the 1D linear advection-diffusion PDE with the following specifications:

PDE Equation: u_t = -q1*∂_x(u) + (q2/pi)*u_xx
Domain: x in [0, 1) with periodic boundary, t in [0, 0.5]
Parameters: q1 = 1.0, q2 = 0.05

Grid Configuration:
- Use uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Numerical Method:
- Spatial Discretization:
  * 1st-order upwind for ∂_x(u)
  * 2nd-order central differences for u_xx
- Time Integration: IMEX Euler (diffusion implicit, advection explicit)
- Time Step Calculation:
  * dt = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi))
  * Nt = ceil(T/dt)
  * Final dt = T/Nt

Initial Condition:
u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Boundary Conditions:
- Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
- Compute u(x,T=0.5) on the periodic grid
- Save solution to "solution_molk_026.npz" with:
  * x array (1D, length Nx)
  * u array (1D, length Nx)
  * T, dx, Nx, q1, q2 scalars
- Create line plot "solution_molk_026.png" of u(x,T)
- Print scalar diagnostics:
  * min(u)
  * max(u)
  * mean(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- If exact solution available, compute and print:
  * Max absolute error
  * L2 error vs reference solution
