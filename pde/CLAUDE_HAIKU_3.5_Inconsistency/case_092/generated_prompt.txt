Numerical Solution Specification for Wave Equation (Task ID: agent_wave_11)

Implement a 2D wave equation solver with the following precise specifications:

PDE: u_tt = (1.0)^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t)
Domain: x, y in [0,1], t in [0,1.0]
Wave speed (c): 2

Numerical Method Details:
- Spatial discretization: Uniform grid with Nx = Ny = 120 intervals
- Grid points: (Nx+1) by (Ny+1) points
- Spatial step sizes: dx = dy = 1/Nx
- Time step calculation: 
  * dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2))
  * Nt = ceil(T/dt0)
  * dt = T/Nt to hit final time exactly
- Spatial discretization: 5-point Laplacian
- Time integration: 2nd-order central difference
- Initialization: Taylor series start with zero initial velocity

Boundary Conditions:
- Dirichlet BC: u = 0 on all boundaries

Initial Conditions:
- u(x,y,0) = 0
- u_t(x,y,0) = 0

Output Requirements:
1. Compute u(x,y,T=1.0) on the 2D grid
2. Save "solution_agent_wave_11.npz" with:
   - x (1D array)
   - y (1D array)
   - u (2D array, shape (len(y), len(x)))
   - Metadata: T, dx, dy, dt
3. Save heatmap/contour plot "solution_agent_wave_11.png"
4. Print at T=1.0:
   - Minimum of u
   - Maximum of u
   - Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
