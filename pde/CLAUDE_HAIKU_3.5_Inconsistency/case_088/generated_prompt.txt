Numerical Solution Specification for 2D Wave Equation (Task ID: agent_wave_07)

Solve the 2D wave equation with the following precise specifications:

PDE: u_tt = (1.0)^2 * (u_xx + u_yy)
Domain: (x,y) in [0,1] x [0,1], t in [0,1.0]
Wave speed parameter: c = 2

Grid Configuration:
- Use Nx = Ny = 120 intervals
- Grid points: (Nx+1) by (Ny+1) points
- dx = dy = 1/Nx
- Compute dt0 = 0.9 / (c * sqrt(1/dx^2 + 1/dy^2))
- Set Nt = ceil(T/dt0)
- Adjust dt to ensure final time is hit exactly

Numerical Method:
- Spatial discretization: 5-point Laplacian on uniform grid
- Time integration: 2nd-order central difference
- Initialization: Taylor series start with initial velocity
- Boundary handling: Dirichlet (u = 0) on all boundaries

Initial Conditions:
- u(x,y,0) = sin(π*x) * sin(π*y)
- u_t(x,y,0) = 0

Output Requirements:
- Compute u(x,y,T=1.0) on the 2D grid
- Save "solution_agent_wave_07.npz" with:
  * x (1D array)
