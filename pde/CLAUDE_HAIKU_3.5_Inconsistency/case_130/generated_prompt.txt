Numerical Solution Specification for 1D Nonlinear Convection-Diffusion PDE (Task ID: molk_029)

Solve the PDE u_t = -q1*∂_x(sin(u)) + (q2/pi)*u_xx with the following specifications:

Domain Configuration:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 0.5]
- Grid: Uniform periodic grid with Nx = 1024 points
- Grid points: x_j = j*dx for j=0,...,Nx-1, where dx = 1/Nx

PDE Parameters:
- q1 = 1.0
- q2 = 0.05

Numerical Method Details:
- Spatial discretization: Conservative finite-volume Rusanov flux for ∂_x(sin(u))
- Flux wave speed: alpha = max|cos(u)|
- Diffusion discretization: 2nd-order central differences for u_xx
- Time integration: SSP-RK2
- Time step calculation:
  * dt_adv = 0.2*dx/1
  * dt_diff = 0.2*dx^2/(q2/pi)
  * dt = min(dt_adv, dt_diff)
  * Nt = ceil(T/dt)
  * Final dt = T/Nt

Initial Condition:
u(x,0) = 0.5*sin(2*pi*x)

Output Requirements:
- Compute u(x,T=0.5) on the periodic grid
- Save solution to "solution_molk_029.npz" with arrays:
  * x (1D, length Nx)
  * u (1D, length Nx)
  * T, dx, Nx
  * Parameters q1, q2
- Create line plot "solution_molk_029.png" of u(x,T)
- Print scalar diagnostics:
  * min(u)
  * max(u)
  * mean(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
