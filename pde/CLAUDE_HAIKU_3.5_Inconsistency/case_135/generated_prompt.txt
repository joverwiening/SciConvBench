Solve the 1D periodic advection equation with the following specification:

Implement a numerical solver for the PDE u_t + 0.1 * u_x = 0.

Numerical Method Details:
Solve on the domain x in [0, 1) with periodic boundary conditions.
Solve from t = 0 to t = 2.0.
Use a uniform spatial grid with Nx = 512 points.
Use 1st-order upwind finite difference for spatial discretization.
Use explicit forward Euler time integration.
Set time step using CFL = 0.5, with dt = CFL * dx / |beta|.
Adjust final time step to hit T exactly.

Initial Condition:
u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Boundary Conditions:
Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
Compute solution at T = 2.0.
Save solution to "solution_pdebench_advection_beta0p1.npz".
Include arrays: x, u, and scalars: beta, T, dx, dt, Nx, Nt.
Create line plot "solution_pdebench_advection_beta0p1.png".
Print:
- Minimum of u
- Maximum of u
- Discrete L2 norm of u
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Reference Solution:
u(x,t) = u0((x - 0.1*t) mod 1), where u0 is the initial condition.
