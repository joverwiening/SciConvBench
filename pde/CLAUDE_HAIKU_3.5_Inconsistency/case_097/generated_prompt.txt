Numerical Solution Specification for 2D Wave Equation (Task ID: agent_wave_16)

Governing Equation:
u_tt = (1.0)^2 * (u_xx + u_yy)

Domain and Parameters:
- Spatial domain: [0,1] x [0,1]
- Time domain: [0, 0.8]
- Wave speed (c): 2

Grid Specifications:
- Use uniform grid with Nx = Ny = 140 intervals
- Grid points: (Nx+1) by (Ny+1) points
- dx = dy = 1/Nx
- Compute dt0 = 0.9 / (c * sqrt(1/dx^2 + 1/dy^2))

- Adjust dt to hit final time exactly

Initial Conditions:
- u(x,y,0) = cos(π*x) * cos(π*y)
- u_t(x,y,0) = 0

- Neumann (zero gradient) on all boundaries
- Implement using ghost node mirroring technique

- Spatial discretization: 5-point Laplacian
- Time integration: 2nd-order central difference
- Initialization: Taylor series start with initial velocity
- CFL condition: ≤ 0.9
