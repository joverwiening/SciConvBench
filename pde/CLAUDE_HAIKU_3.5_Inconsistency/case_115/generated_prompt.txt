Numerical Solution for 1D Linear Wave/Klein-Gordon PDE

Specification:
Solve the PDE u_tt + (0.5**2)*(1.0**4)*u = (1.0**2)*u_xx on the periodic domain [0, 1).

Detailed Implementation Requirements:
Solve the PDE using the following precise specifications:

Spatial Discretization:
- Use a uniform periodic grid with Nx = 256 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx
- Use either Fourier spectral derivatives (FFT) or 2nd-order central differences for u_xx

Time Integration:
- Reformulate as first-order system: v = u_t
- Solve system: u_t = v, v_t = (1.0**2)*u_xx - (0.5**2)*(1.0**4)*u
- Use RK4 time integration method
- Time step: dt = 0.0005
- Total steps: Nt = 2000
- Final time: T = 1.0

Initial Conditions:
- u(x,0) = sin(2*pi*x)
- u_t(x,0) = 0

Boundary Conditions:
- Periodic: u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t) for all t

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_molk_014.npz" with arrays:
  * x (1D length Nx)
  * u (1D length Nx)
  * T, dx, Nx
  * Parameters q1, q2
- Create line plot of u(x,T) as "solution_molk_014.png"
- Print scalar diagnostics:
  * min(u)
  * max(u)
  * mean(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)

Verification:
- Exact solution: u(x,t) = cos(omega*t) * sin(2*pi*x)
- omega = sqrt(0.5^2 * 1.0^4 + 1.0^2 * (2*pi)^2) = 6.303048278758258
