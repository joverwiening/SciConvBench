Solve the 1D Reaction-Diffusion PDE with the following specification:

Implement a numerical solver for the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following precise requirements:

Domain and Grid:
- Spatial domain is [0, 1) with periodic boundary
- Uniform periodic grid with Nx = 512 points
- x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx
- Time domain [0, 1.0]

Parameters:
- nu = 5.0
- rho = 10.0

Numerical Method:
- Time integration: Explicit forward Euler
- Time step: Fixed dt = 0.001
- Total time steps: Nt = 1000
- Method: Strang splitting with three steps:
  1. Diffusion half-step in Fourier space (dt/2)
  2. Reaction full-step solved exactly pointwise
  3. Diffusion half-step in Fourier space (dt/2)

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu5_rho10.npz"
- Include in .npz: x, u, nu, rho, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_reacdiff_nu5_rho10.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm

Coding Notes:
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
- Use radians for trigonometric functions
