Specification for Heat Equation Numerical Solution (Task ID: agent_heat_16):

Implement a 2D heat equation solver with the following specifications:

Partial Differential Equation:
u_t = 0.05 * (u_xx + u_yy)

Spatial Domain:
x in [0,1] with Dirichlet boundaries
y in [0,1) with periodic boundaries

Temporal Domain:
t in [0,0.3]

Numerical Method Details:
- Spatial discretization: Tensor grid with 2nd-order central differences
- Spatial grid: Nx = 60 (x-direction), Ny = 64 (y-direction)
- Temporal discretization: Implicit Euler method
- Time step: dt = 0.001 (360 total steps)
- Final time: T = 0.3

Initial Condition:
u(x,y,0) = sin(pi*x) * cos(2*pi*y)

Boundary Conditions:
- Dirichlet at x=0 and x=1: u(0,y,t) = 0, u(1,y,t) = 0
- Periodic in y-direction: u(x,0,t) = u(x,1,t)

Output Requirements:
1. Compute 2D solution u(x,y,T=0.3)
2. Save solution to "solution_agent_heat_16.npz" with:
   - x (1D array)
   - y (1D array)
   - u (2D array, shape (Ny, Nx))
   - Metadata: T, dx, dy, dt
3. Generate heatmap/contour plot "solution_agent_heat_16.png"
4. Print scalar diagnostics:
   - Minimum value of u
   - Maximum value of u
   - Discrete L2 norm
5. Compute and print error metrics:
   - Maximum absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution:
u(x,y,t) = exp(-0.05*((pi)^2 + (2*pi)^2)*t) * sin(pi*x) * cos(2*pi*y)
