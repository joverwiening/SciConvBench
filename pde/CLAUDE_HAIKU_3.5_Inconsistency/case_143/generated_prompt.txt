Specification for 1D Viscous Burgers Equation Numerical Solution:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

Problem Domain:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 1.0]
- Viscosity parameter: nu = 0.01

Numerical Method:
- Use Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space
  2. Advection full-step using Rusanov (local Lax-Friedrichs) finite-volume flux
  3. Diffusion half-step in Fourier space

Grid Specifications:
- Uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Initial Condition:
- u(x,0) = sin(2*pi*x)

Time Stepping:
- Use CFL = 0.4 with estimated max speed of 1.0
- Compute dt0 = CFL * dx / 1.0
- Determine Nt = ceil(T/dt0)
- Adjust final dt to hit T exactly

Output Requirements:
- Compute solution at T = 1.0
- Save solution to "solution_pdebench_burgers_nu0p01.npz"
- Include arrays: x, u
- Include scalars: nu, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_burgers_nu0p01.png"
- Print diagnostics:
  1. Minimum value of u
  2. Maximum value of u
  3. Discrete mean value of u
  4. Discrete L2 norm of u
