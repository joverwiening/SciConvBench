Specification for Wave Equation Numerical Solution (Agent Wave 12):

Solve the 1D wave equation u_tt = 4^2 * u_xx numerically with the following specifications:

Computational Domain:
- Spatial domain x ∈ [0,1]
- Time domain t ∈ [0,0.5]
- Wave speed c = 4

Numerical Method:
- Use a uniform grid with Nx = 400 intervals (Nx+1 points)
- Compute dx = 1/Nx
- Calculate dt using CFL condition: dt0 = 0.9*dx/c, with Nt = ceil(0.5/dt0)
- Use 2nd-order central differences for spatial discretization
- Use leapfrog/Störmer-Verlet method for time integration
- Apply Taylor start for initial time step
- Enforce Dirichlet boundary conditions u(0,t) = u(1,t) = 0

Initial Conditions:
- u(x,0) = sin(π*x)
- u_t(x,0) = 0

Output Requirements:
- Compute u(x, T=0.5)
- Save solution to "solution_agent_wave_12.npz"
- Save plot of u(x,T) to "solution_agent_wave_12.png"
- Print:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm of u
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution:
u(x,t) = cos(2π*t) * sin(π*x)
