Specification for Heat Equation Numerical Solution (Task ID: agent_heat_02):

Solve the 1D heat equation u_t = 0.5 * u_xx numerically with the following specifications:

Spatial Domain: x in [0, 1]
Time Domain: t in [0, 0.2]
Numerical Grid: 
- Use Nx = 200 intervals (201 grid points)
- dx = 1/Nx
- Grid points include both domain endpoints

Numerical Method:
- Spatial Discretization: 2nd-order central differences for u_xx in interior
- Time Integration: Crank-Nicolson method for diffusion terms
- Time Step: dt = 0.0005 (480 total time steps)

Initial Condition: u(x,0) = sin(2*pi*x)
Boundary Conditions: Dirichlet 
- u(0,t) = 0
- u(1,t) = 0

Computational Requirements:
- Compute solution u(x, T=0.2)
- Save solution to "solution_agent_heat_02.npz" with:
  * x grid (1D array)
  * u solution (1D array)
  * Metadata: T, dx, dt
- Generate plot "solution_agent_heat_02.png" of u(x,T)
- Print diagnostics:
  * Minimum u value
  * Maximum u value
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print error metrics:
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = exp(-0.5*(2*pi)^2*t) * sin(2*pi*x)
