Solve the 1D wave equation with damping using the following specification:

Partial Differential Equation:
u_tt + 0.5*u_t = (1.0)^2 * u_xx

Spatial Domain: x in [0,1]
Temporal Domain: t in [0,3.0]

Parameters:
c = 1.0
gamma = 0.5

Boundary Conditions:
Dirichlet boundary conditions at x=0 and x=1: u=0 at all times
Enforce u=0 at boundaries during every RK4 substage

Initial Conditions:
u(x,0) = sin(pi*x)
u_t(x,0) = 0

Numerical Method:
Rewrite as first-order system: 
u_t = v
v_t = c^2*u_xx - gamma*v

Discretization Details:
- Spatial grid: Nx = 400 uniform points
- Spatial discretization: 2nd-order central differences for u_xx
- Time integration: Classical RK4 method
- Time step: dt = 0.0005 (6000 total steps)

Output Requirements:
- Compute solution u(x,T=3.0)
- Save solution to "solution_agent_wave_09.npz"
- Include arrays: x, u, with metadata: T, dx, dt
- Create line plot "solution_agent_wave_09.png"
- Print diagnostics: min(u), max(u), discrete L2 norm

Coding Note:
Use '^' for exponentiation in math
Use '**' for powers in Python implementation
