Numerical Solution for 1D Reaction-Diffusion PDE (Logistic Reaction, Periodic)

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following specifications:

Domain is [0, 1) with periodic boundary conditions.
Spatial grid: 512 uniform points (Nx=512), x_j = j*dx for j=0,...,Nx-1.
Time domain: t in [0, 1.0]
Parameters: nu = 2.0, rho = 1.0
Time stepping: Fixed dt = 0.001 with 1000 steps (Nt=1000)

Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical method: Strang splitting with three steps:
1. Half diffusion step in Fourier space (dt/2)
2. Full reaction step solved exactly pointwise
3. Half diffusion step in Fourier space (dt/2)

Solution computation steps:
- Use Fast Fourier Transform (FFT) for diffusion steps
- Use exact pointwise update for reaction step
- Compute solution at T = 1.0

Output requirements:
- Save solution as "solution_pdebench_reacdiff_nu2_rho1.npz"
- Include arrays: x, u, and scalars: nu, rho, T, dx, dt, Nx, Nt
- Create line plot "solution_pdebench_reacdiff_nu2_rho1.png"
- Print scalar diagnostics: min(u), max(u), mean(u), discrete L2 norm
