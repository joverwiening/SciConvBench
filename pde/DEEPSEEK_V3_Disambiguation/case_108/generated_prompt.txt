Solve the Van der Pol oscillator ODE system numerically.
The ODE system is dx/dt = y and dy/dt = mu*(1 - x**2)*y - x.
The time domain is t in [0.0, 20.0].
The parameter mu is 2.0.
The initial condition is x(0.0) = 1.0 and y(0.0) = 0.0.
Use the Classical 4th-order Runge–Kutta (RK4) method with a fixed step size.
Use a time step dt = 0.01 for Nt = 2000 steps.
Compute the full state vector at all time points t_n = 0.0 + n*dt for n=0..Nt.
Save the solution to a file named "solution_molk_007.npz".
The file must contain arrays: t (1D length Nt+1) and Y (2D array shape [Nt+1, 2]) with columns ordered as [x, y].
The file must also contain the parameter scalar mu.
Save a line plot of each state variable versus time as "solution_molk_007.png".
Print the final state values at the final time T.
Print the minimum and maximum values of each state variable over the entire simulation time.
