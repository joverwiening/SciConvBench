Use a CFL number of 0.5.
Use Nx = 800 uniform finite-volume cells on the spatial domain [-1, 1].
The cell centers are defined as x_j = -1 + (j + 0.5) * dx for j = 0,..., Nx-1, with dx = 2.0 / Nx.
Solve the 1D compressible Navier-Stokes equations in conservative form for the fields rho(x,t), v(x,t), and p(x,t).
The total simulation time is T = 0.2.
Use the equation of state p = (Gamma - 1) * (E - 0.5 * m**2 / rho) with Gamma = 1.6666666666666667.
Set the dynamic viscosity eta = 1e-08 and the bulk viscosity zeta = eta.
Initialize the simulation with a Riemann shock-tube condition: for x < 0, set rho_L=1.0, v_L=0.0, p_L=1.0; for x >= 0, set rho_R=0.1, v_R=0.0, p_R=0.01.
Apply transmissive (zero-gradient) outflow boundary conditions at x = -1 and x = 1.
Evolve the cell-averaged conservative variables U = [rho, m, E] on the finite-volume grid.
Compute the convective flux using the Rusanov (local Lax-Friedrichs) numerical flux.
Compute the viscous stress as sigma = (zeta + 4/3 * eta) * v_x, where v_x is approximated with a centered difference on cell-centered velocities.
Average neighboring cell-centered sigma values to obtain interface values for the viscous flux.
Compute the total interface flux as the sum of the convective and viscous flux contributions.
Integrate in time using the 2-stage SSP-RK2 (Heun's) method.
Compute the time step dt each iteration using dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx**2 / max( zeta + 4/3*eta, 1e-30 ), then set dt = min(dt_conv, dt_visc).
Adjust the final time step to hit exactly T = 0.2.
Enforce positivity by clipping computed values of rho and p to a floor of 1e-12 if needed.
At the final time T, compute the primitive variables rho, v, and p on the cell centers.
Save the solution arrays and parameters to the file "solution_pdebench_cns1d_shock_eta1em8_outflow.npz".
The NPZ file must contain the arrays 'x', 'rho', 'v', 'p' and the scalars 'Gamma', 'eta', 'zeta', 'T', 'dx', 'CFL'.
Create and save a line plot of the final rho, v, and p versus x to the file "solution_pdebench_cns1d_shock_eta1em8_outflow.png".
Print the minimum and maximum values of rho and p to the console as a positivity check.
Print the mean value of rho over the domain to the console as a mass conservation check.
