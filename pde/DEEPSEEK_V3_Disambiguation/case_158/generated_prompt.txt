Solve the 1D Compressible Navier-Stokes PDE numerically on the domain x in [-1, 1], t in [0, 0.5].
Use a uniform finite-volume grid with Nx=400 cells.
Define cell centers as x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2.0/Nx.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho), with Gamma = 1.6666666666666667.
Enforce positivity by clipping rho and p to a floor value of 1e-12.
For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
Compute the interface wave speed as a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
Calculate the numerical convective flux as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Set the viscous parameters eta = 1e-08 and zeta = 1e-08.
Compute the viscous stress as sigma = (zeta + 4/3*eta) * v_x, where v_x is computed with a centered difference on cell-centered v values.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Add viscous contributions to the momentum and energy fluxes at interfaces as F_visc = [ 0, -sigma, -v*sigma ].
Calculate the total interface flux as F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Calculate the time step dt each step using dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx**2 / max( zeta + 4/3*eta, 1e-30 ).
Set dt = min(dt_conv, dt_visc) and use a CFL number of 0.5.
Adjust the last time step to hit the final time T=0.5 exactly.
Implement periodic boundary conditions on x=-1 and x=1 by wrapping indices.
Use the initial conditions rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), and p(x,0) = 1.0 + 0.2*cos(pi*x).
Compute the final solution rho(x,T), v(x,T), p(x,T) on the cell centers.
Save the solution to "solution_pdebench_cns1d_eta1em8_periodic_smooth.npz" containing arrays x, rho, v, p, and scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel (or 3 separate) line plot(s) of rho, v, p vs x at T as "solution_pdebench_cns1d_eta1em8_periodic_smooth.png".
Print the minimum and maximum of rho and p for a positivity check.
Print the mean of rho over the domain for a mass conservation check.
