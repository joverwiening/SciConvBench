Use a CFL number of 0.5.
Use Nx = 800 uniform finite-volume cells on the spatial domain [-1, 1].
The cell centers are defined as x_j = -1 + (j + 0.5) * dx for j = 0, ..., Nx-1, with dx = 2.0 / Nx.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Use the equation of state p = (Gamma - 1) * (E - 0.5 * m**2 / rho).
Enforce positivity by clipping rho and p to a floor value of 1e-12 if needed.
For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
Compute the interface wave speed as a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma * p / rho).
Compute the numerical convective flux as F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L).
Compute the velocity gradient v_x using a centered difference on cell-centered v values.
Compute the viscous stress as sigma = (zeta + 4/3 * eta) * v_x.
Approximate sigma at cell interfaces by averaging the sigma values from the two neighboring cells.
Compute the viscous flux contribution as F_visc = [0, -sigma, -v * sigma] using interface-averaged v and sigma.
Compute the total interface flux as F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
Compute the convective time step constraint as dt_conv = CFL * dx / max_j( |v_j| + c_j ).
Compute the viscous time step constraint as dt_visc = 0.5 * dx**2 / max( zeta + 4/3 * eta, 1e-30 ).
Set the time step dt each iteration to min(dt_conv, dt_visc).
Adjust the final time step to exactly reach the final time T = 0.2.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell value.
Compute the final solution fields rho(x,T), v(x,T), p(x,T) on the cell centers.
