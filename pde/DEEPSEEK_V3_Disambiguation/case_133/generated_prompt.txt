Solve the PDE u_t = -k * ∂_x( cos(u) ) for u(x,t) with k=1.0.
Use the spatial domain x in [0, 1) with periodic boundary conditions.
Use the temporal domain t in [0, 0.2].
Set the initial condition as u(x,0) = 0.5 * sin(2 * pi * x).
Use a uniform periodic spatial grid with Nx=1024 points.
Define grid points as x_j = j * dx for j = 0,..., Nx-1, where dx = 1 / Nx.
Discretize the spatial derivative using a conservative finite-volume method with the Rusanov flux for f(u)=cos(u).
Compute the wave speed alpha as the maximum absolute value of sin(u) over the domain, which is bounded by 1.
Set the CFL number to 0.2.
Calculate the initial time step as dt0 = CFL * dx / 1.0.
Calculate the total number of time steps as Nt = ceil(T / dt0), where T=0.2.
Set the final time step size as dt = T / Nt.
Integrate in time using the SSP-RK2 method.
No closed-form reference solution is required for verification.
