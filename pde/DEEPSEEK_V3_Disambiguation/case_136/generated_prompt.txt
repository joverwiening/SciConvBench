The spatial domain is [0, 1) with periodic boundary conditions.
The final time T is 2.0.
Use a uniform spatial grid with Nx = 512 points.
Define the grid points as x_i = i * dx for i = 0 to Nx-1, where dx = 1.0 / Nx.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The PDE is u_t + beta * u_x = 0 with beta = 0.2.
Use a first-order upwind finite difference for the spatial derivative u_x.
The upwind direction is determined by the sign of beta.
Use explicit forward Euler for time integration.
Set the CFL number to 0.5.
Calculate the time step as dt = CFL * dx / abs(beta).
Calculate the number of time steps as Nt = ceil(T / dt).
Recalculate the time step as dt = T / Nt to exactly reach the final time.
Compute the numerical solution u at the final time T on the defined spatial grid.
Compute the reference solution as u_ref(x, T) = u0( (x - beta * T) mod 1 ).
Calculate the min and max of the numerical solution u at time T.
Calculate the discrete L2 norm of the numerical solution as sqrt(sum(u**2) * dx).
Calculate the max absolute error between the numerical and reference solutions.
Calculate the L2 error between the numerical and reference solutions.
Print the min(u), max(u), discrete L2 norm, max absolute error, and L2 error.
