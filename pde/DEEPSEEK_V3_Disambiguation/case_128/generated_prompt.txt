Solve the PDE u_t = -1.0 * ∂_x( (1/3)*u^3 ) + (0.05/pi)*u_xx on the domain x in [0, 1) and t in [0, 0.5].
Use a uniform periodic spatial grid with Nx=1024 points, defined as x_j = j*(1/1024) for j=0,...,1023.
Set the initial condition as u(x,0) = 0.5*sin(2*pi*x).
Apply periodic boundary conditions such that u(0,t)=u(1,t).
Discretize the convective flux term -∂_x( (1/3)*u^3 ) using a conservative finite-volume method with the Rusanov numerical flux.
Discretize the diffusive term (0.05/pi)*u_xx using second-order central differences.
For time integration, use the SSP-RK2 method.
Calculate the time step dt by first estimating max|f'(u)| = max|u^2|, where the initial condition gives max|f'| <= 0.25.
Compute dt0 = 0.2 * (1/1024) / 0.25.
Compute dt_diff = 0.2 * (1/1024)^2 / (0.05/pi).
Set dt = min(dt0, dt_diff).
Calculate Nt = ceil(0.5 / dt) and set the final time step to dt = 0.5 / Nt.
Advance the solution from t=0 to t=0.5 using Nt steps of the SSP-RK2 method.
