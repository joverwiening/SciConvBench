Solve the 1D Viscous Burgers equation on the periodic domain x in [0,1).
Use the initial condition u(x,0) = sin(2*pi*x).
Use the viscosity parameter nu = 0.01.
Use a uniform spatial grid with Nx = 512 points.
Define the grid points as x_i = i * dx for i = 0 to Nx-1, where dx = 1.0 / Nx.
Use a final simulation time of T = 1.0.
Calculate the initial time step dt0 using a CFL number of 0.4 and an estimated maximum speed of 1.0, so dt0 = 0.4 * dx.
Set the number of time steps Nt to the ceiling of T / dt0.
Recalculate the actual time step as dt = T / Nt.
Advance the solution from t=0 to t=T using Strang splitting for each full time step dt.
For each full time step, first perform a diffusion half-step for duration dt/2 exactly in Fourier space.
For each full time step, then perform an advection full-step for duration dt using a finite-volume method with Rusanov flux.
For each full time step, finally perform a second diffusion half-step for duration dt/2 exactly in Fourier space.
After completing all time steps, compute the solution u(x, T) on the spatial grid.
Save the results to a file named "solution_pdebench_burgers_nu0p01.npz".
The NPZ file must contain the 1D array 'x' of length Nx.
The NPZ file must contain the 1D array 'u' of length Nx.
The NPZ file must contain the scalar values 'nu', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Create a line plot of the final solution u(x, T) and save it as "solution_pdebench_burgers_nu0p01.png".
Print the minimum value of u at the final time.
Print the maximum value of u at the final time.
Print the discrete mean value of u at the final time, calculated as sum(u) / Nx.
Print the discrete L2 norm of u at the final time, calculated as sqrt( sum(u**2) * dx ).
