The spatial domain is [0,1) with periodic boundary conditions, using Nx=512 grid points.
The temporal domain is [0,0.5].
The PDE is u_t = -1.0 * ∂_x(0.5*u**2) + (0.1/pi)*u_xx.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with x_j = j*dx for j=0,...,Nx-1, where dx=1/512.
Discretize the nonlinear flux f(u)=0.5*u**2 using the Rusanov (local Lax–Friedrichs) flux.
Discretize the diffusion term u_xx with 2nd-order central differences.
Compute D_eff = 0.1/pi.
Compute dt_conv = 0.4 * dx / 1.
Compute dt_diff = 0.4 * dx**2 / D_eff.
Set dt0 = min(dt_conv, dt_diff).
Set Nt = ceil(0.5 / dt0) and dt = 0.5 / Nt.
Use the SSP-RK2 (Heun) method for time integration with this fixed dt.
