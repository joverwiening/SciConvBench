Solve the 1D linear advection equation u_t + q*u_x = 0 with q = 1.5.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
Use Nx = 512 uniform intervals, resulting in Nx grid points x_i = i*dx for i=0..Nx-1, with dx = 1/Nx.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
Set the CFL number to 0.5.
Calculate the initial time step as dt0 = CFL * dx / abs(q).
Set the number of time steps Nt = ceil(T / dt0) where T=1.0.
Set the final time step dt = T / Nt.
Use a first-order upwind finite difference scheme for the spatial derivative u_x.
Use the Forward Euler method for time integration.
Compute the solution u(x, T=1.0) on the periodic grid.
Save the results to "solution_molk_018.npz" containing arrays x and u, and scalars T, dx, Nx, and q.
Save a line plot of u(x,T) as "solution_molk_018.png".
Print the minimum, maximum, and mean of u at T, and the discrete L2 norm sqrt(sum(u**2)*dx).
Compute the exact solution as u_exact(x, T) = u0( (x - q*T) mod 1 ).
Print the maximum absolute error and the L2 error between the numerical and exact solutions.
