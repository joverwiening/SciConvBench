Solve the 1D nonlinear reaction-diffusion PDE for u(x,t) on the domain x in [0,1) with periodic boundary conditions.
Use a uniform spatial grid with Nx=512 points, where x_i = i*dx for i=0..Nx-1 and dx = 1.0/Nx.
The temporal domain is t in [0, 1.0].
The PDE is u_t = 0.01 * u_xx + 2.0 * (u**2) * (1-u)**2.
The initial condition is u(x,0) = 0.2 + 0.1 * sin(2 * pi * x).
Use a numerical method suitable for solving this PDE (e.g., method of lines with a finite difference discretization for u_xx and an ODE time integrator).
Compute the solution u(x, T=1.0) on the periodic grid.
Save the results to a file named "solution_molk_023.npz".
The saved file must contain the following arrays and scalar values: x (1D, length Nx), u (1D, length Nx), T, dx, Nx, q1, q2.
Create and save a line plot of u(x, T=1.0) as "solution_molk_023.png".
Print the following scalar diagnostics at time T=1.0: the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u**2)*dx).
Do not compute or report an error against a reference solution.
