Solve the PDE u_t = -1.0 * ∂_x( cos(u) ) + (0.05/pi) * u_xx on the domain x in [0, 1) and t in [0, 0.5].
Use a uniform periodic spatial grid with Nx = 1024 points, defined as x_j = j * dx for j = 0,...,Nx-1 with dx = 1/1024.
Set the initial condition as u(x,0) = 0.5 * sin(2 * pi * x).
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Discretize the convective flux term -∂_x( cos(u) ) using a conservative finite-volume method with the Rusanov flux, where the wave speed alpha = max|sin(u)|.
Discretize the diffusion term u_xx using second-order central differences.
For time integration, use the SSP-RK2 method.
Calculate the time step dt using a CFL number of 0.2: dt_adv = 0.2 * dx / 1, and dt_diff = 0.2 * dx**2 / (0.05/pi).
Set dt = min(dt_adv, dt_diff).
Calculate the number of time steps as Nt = ceil(0.5 / dt).
Recalculate the final time step as dt = 0.5 / Nt.
Advance the solution from t=0 to t=0.5 using Nt steps of the SSP-RK2 method.
