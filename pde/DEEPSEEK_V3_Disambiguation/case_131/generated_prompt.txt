Solve the PDE u_t = -k * ∂_x( sin(u) ) for u(x,t) with k=1.0.
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the temporal domain t in [0,0.2].
Set the initial condition u(x,0) = 0.5*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=1024 points.
Define grid points as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a conservative finite-volume method with the Rusanov flux for f(u)=sin(u).
Compute the wave speed alpha as the maximum absolute value of cos(u) over the domain.
Set the initial time step dt0 using CFL=0.2 via dt0 = CFL * dx / 1.0.
Calculate the number of time steps Nt as the ceiling of T / dt0.
Set the final time step dt as T / Nt.
Use the SSP-RK2 method for time integration.
