Solve the 1D reaction-diffusion PDE numerically.
Use the domain x in [0, 1) with periodic boundary conditions.
Use the time domain t in [0, 1.0].
The PDE is u_t = 0.01 * u_xx + 5.0 * u * (1 - u).
Use the initial condition u(x,0) = 0.25 + 0.1 * sin(2 * pi * x).
Use Nx = 512 spatial grid points.
Construct the spatial grid with dx = (1 - 0) / 512.
Define grid points as x_i = 0 + i * dx for i = 0 to Nx-1.
Apply periodic boundary conditions for all computations.
Compute the solution up to time T = 1.0.
Use a stable and accurate time-stepping method.
Save the final solution u(x, T=1.0) to "solution_molk_020.npz".
The NPZ file must contain the 1D array 'x', the 1D array 'u', and the scalars 'T', 'dx', 'Nx', 'q1', and 'q2'.
