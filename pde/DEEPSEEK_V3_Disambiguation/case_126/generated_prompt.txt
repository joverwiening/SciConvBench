Solve the 1D inviscid Burgers equation u_t = -k * ∂_x(0.5 * u^2) on the domain x in [0, 1) and t in [0, 0.2].
Use the parameter k = 1.0.
Apply periodic boundary conditions: u(0, t) = u(1, t) for all t.
Use the initial condition u(x, 0) = sin(2 * π * x).
Use a uniform periodic spatial grid with Nx = 1024 points.
Define the grid points as x_j = j * dx for j = 0, ..., Nx-1, where dx = 1 / Nx.
Discretize the spatial derivative using a conservative finite-volume method.
Compute the numerical flux using the Rusanov (local Lax–Friedrichs) flux for f(u) = 0.5 * u^2.
Integrate in time using the SSP-RK2 (Heun) method.
Calculate the initial time step dt0 using the formula dt0 = CFL * dx / max|u|, with CFL = 0.2 and an estimated max|u| ≈ 1.
Set the total number of time steps Nt = ceil(T / dt0), where T = 0.2.
Use the final time step dt = T / Nt for the simulation.
No closed-form reference solution is required for verification.
