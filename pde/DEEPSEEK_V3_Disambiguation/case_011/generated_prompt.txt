Solve the Allen-Cahn equation for u(x,y,t) on the domain (x,y) in [0,1] x [0,1] and t in [0,0.1].
Use the PDE u_t = (0.02)^2*(u_xx + u_yy) + u - u^3.
Set the parameter epsilon = 0.02.
Use the initial condition u(x,y,0) = tanh((0.25 - r)/(sqrt(2)*0.02)), where r = sqrt((x-0.5)^2 + (y-0.5)^2).
Discretize space using a uniform grid with Nx=300 and Ny=300 intervals, resulting in 301x301 grid points.
Calculate spatial steps dx = (1-0)/300 and dy = (1-0)/300.
Use a time step dt = 0.0001, resulting in 1000 steps to reach T=0.1.
Apply a semi-implicit time integration scheme: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
Compute the 5-point Laplacian (u_xx+u_yy) for the spatial discretization.
Enforce Dirichlet boundary conditions by setting u = 0 at all boundary nodes (x=0, x=1, y=0, y=1) at every time step.
Solve the resulting sparse linear system for u^{n+1} at each time step.
Compute the final solution u(x,y,T=0.1) on the 2D grid.
