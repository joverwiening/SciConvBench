Solve the PDE u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u ) on the domain x in [0, 1) and t in [0, 1.0].
Use the parameters D = 0.01 and gamma = 1.0.
Use the potential function U(x) = cos(2*pi*x) and its derivative U'(x) = -2*pi*sin(2*pi*x).
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition to u(x,0) = 1.0 + 0.2*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points.
Define the grid points as x_j = j*dx for j = 0,...,Nx-1, where dx = 1/Nx.
Discretize the drift term in conservative form, with flux F = (1/gamma)*U'(x)*u.
For the spatial discretization of ∂_x(F), use an upwind finite-volume flux based on the sign of b(x) = U'(x)/gamma.
For the spatial discretization of u_xx, use 2nd-order central differences.
For time integration, use the explicit SSP-RK2 method.
Calculate the local velocity b(x) = U'(x)/gamma.
Calculate the time step dt = min(0.4*dx / max|b(x)|, 0.2*dx**2 / D).
Set the final simulation time T = 1.0.
Calculate the number of time steps Nt = ceil(T / dt).
Set the actual time step used for integration as dt = T / Nt.
Run the simulation from t = 0 to t = T.
