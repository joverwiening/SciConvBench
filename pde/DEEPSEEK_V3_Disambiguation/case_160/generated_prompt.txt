Use Nx = 800 uniform finite-volume cells on the spatial domain [-1, 1].
Set the CFL number to 0.5.
Use a uniform finite-volume grid with cell centers x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Compute pressure from the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.
For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
Compute the interface wave speed a as max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
Compute the convective numerical flux as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x using a centered difference on cell-centered v values.
Compute the viscous stress sigma as (zeta + 4/3*eta)*v_x.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Compute the viscous flux contribution as F_visc = [ 0, -sigma, -v*sigma ] using interface-averaged v and sigma.
Compute the total interface flux as F_total = F_hat + F_visc.
Integrate in time using the 2-stage SSP-RK2 (Heun's) method.
Compute the convective time step constraint dt_conv = CFL * dx / max_j( |v_j| + c_j ).
Compute the viscous time step constraint dt_visc = 0.5 * dx**2 / max( zeta + 4/3*eta, 1e-30 ).
Set the time step dt each step as min(dt_conv, dt_visc).
Adjust the final time step to hit exactly t = 0.2.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell value.
Compute the final solution fields rho(x,T), v(x,T), p(x,T) on the cell centers at time T=0.2.
