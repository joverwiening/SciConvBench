Solve the Lotka-Volterra ODE system numerically.
The ODE system is dx/dt = 1.5*x - 1.0*x*y and dy/dt = 1.0*x*y - 3.0*y.
The time domain is t in [0.0, 30.0].
Use initial conditions x(0.0) = 1.0 and y(0.0) = 1.0.
Use the Classical 4th-order Runge-Kutta (RK4) method with a fixed step size.
Set the time step dt to 0.01.
Take Nt=3000 steps so the final time is exactly 30.0.
Compute the full state vector at all time points t_n = 0.0 + n*dt for n=0..Nt.
Save the results to a file named "solution_molk_008.npz".
The NPZ file must contain a 1D array 't' of length Nt+1.
The NPZ file must contain a 2D array 'Y' of shape [Nt+1, 2].
The columns of 'Y' must be ordered as [x, y].
The NPZ file must also contain the parameter scalars alpha, beta, gamma, and delta.
Save a line plot of each state variable versus time to a file named "solution_molk_008.png".
Print the final state values x(30.0) and y(30.0).
Print the minimum and maximum values of x over the entire simulation time.
Print the minimum and maximum values of y over the entire simulation time.
