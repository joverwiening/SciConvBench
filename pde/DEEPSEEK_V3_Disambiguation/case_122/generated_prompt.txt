Solve the 1D linear reaction-diffusion PDE u_t = 0.01*u_xx - 1.0*u on the periodic spatial domain x in [0,1).
Use the initial condition u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx = 256 points, which are x_i = i*(1/256) for i=0..255.
Use a uniform time step dt = 0.001 and integrate from t=0 to t=0.5, resulting in Nt = 500 steps.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Compute the numerical solution u(x, T=0.5) on the periodic grid.
Save the results to "solution_molk_021.npz" containing the arrays x (1D, length Nx) and u (1D, length Nx), and the scalars T, dx, Nx, q1, and q2.
Save a line plot of u(x,T) as "solution_molk_021.png".
Print the min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.
