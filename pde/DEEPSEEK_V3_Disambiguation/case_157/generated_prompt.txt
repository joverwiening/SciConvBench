Use Nx = 400 cells on the spatial domain [-1, 1].
Use a uniform finite-volume grid with cell centers x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2.0/Nx.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.
Compute the convective flux using the Rusanov (local Lax-Friedrichs) numerical flux.
Compute the sound speed as c = sqrt(Gamma*p/rho).
Use a CFL number of 0.5 for the convective time step constraint.
Compute the viscous stress as sigma = (zeta + 4/3*eta) * v_x, where v_x is computed with a centered difference on cell-centered v values.
Average neighboring cell-centered sigma values to approximate sigma at interfaces.
Compute the viscous flux contribution as F_visc = [ 0, -sigma, -v*sigma ] using interface-averaged v and sigma.
Compute the total interface flux as F_total = F_hat + F_visc.
Integrate in time using the 2-stage SSP-RK2 (Heun's method) scheme.
Compute the convective time step as dt_conv = CFL * dx / max_j( |v_j| + c_j ).
Compute the viscous time step as dt_visc = 0.5 * dx**2 / max( zeta + 4/3*eta, 1e-30 ).
Set the global time step as dt = min(dt_conv, dt_visc).
Adjust the final time step to exactly reach the final time T = 0.5.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell value.
Compute the final solution fields rho(x,T), v(x,T), p(x,T) on the cell centers.
