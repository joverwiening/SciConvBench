Use CFL = 0.5.
Use Nx = 800 cells.
The spatial domain is [-1, 1].
The temporal domain is [0, 0.2].
The PDE is the 1D compressible Navier-Stokes equations in conservative form with viscous stress sigma = (zeta + 4/3*eta) * v_x.
The parameters are Gamma = 1.6666666666666667, eta = 1e-08, and zeta = eta.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, set rho = 1.0, v = -0.75, and p = 1.0.
For x >= 0, set rho = 0.125, v = 0.0, and p = 0.1.
Use a uniform finite-volume grid with Nx cells on the closed interval [-1, 1].
Calculate dx = (1 - (-1)) / Nx.
Define cell centers as x_j = -1 + (j + 0.5) * dx for j = 0,..., Nx-1.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Compute the pressure from the equation of state p = (Gamma-1) * (E - 0.5 * m**2 / rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.
For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
Compute the convective flux function F_conv(U) = [ m, m**2/rho + p, (E+p)*v ] where v = m/rho.
At each interface, compute the wave speed a = max( |v_L| + c_L, |v_R| + c_R ) where c = sqrt(Gamma * p / rho).
Compute the numerical convective flux as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
For the viscous terms, compute v_x at cell centers using a centered difference.
Compute sigma at cell centers as sigma = (zeta + 4/3*eta) * v_x.
Approximate sigma at interfaces by averaging the sigma values from the two neighboring cells.
Compute the viscous flux contribution as F_visc = [ 0, -sigma, -v*sigma ] using interface-averaged v and sigma.
Compute the total interface flux as F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
Compute the convective time step constraint as dt_conv = CFL * dx / max_j( |v_j| + c_j ).
Compute the viscous time step constraint as dt_visc = 0.5 * dx**2 / max( zeta + 4/3*eta, 1e-30 ).
Compute the time step as dt = min(dt_conv, dt_visc).
Adjust the final time step to exactly reach T = 0.2.
Implement outflow boundary conditions at x = -1 and x = 1 by setting ghost cell values equal to the nearest interior cell value.
Compute the final solution fields rho(x,T), v(x,T), and p(x,T) on the cell centers.
