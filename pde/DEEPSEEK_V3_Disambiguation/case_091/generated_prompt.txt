Solve the wave equation u_tt = (1.0)^2 * u_xx + sin(pi*x)*sin(2*pi*t) on the domain x in [0,1], t in [0,1.0].
Use a uniform spatial grid on the closed interval [0,1] with Nx=400 intervals, resulting in 401 grid points.
Set the spatial step size dx = 1.0 / Nx.
Set the wave speed c = 1.0.
Calculate the provisional time step dt0 = 0.9 * dx / c.
Set the final time T = 1.0.
Set the number of time steps Nt = ceil(T / dt0).
Set the actual time step dt = T / Nt.
Apply Dirichlet boundary conditions: u = 0 at x=0 and x=1 at every time step.
Set the initial condition u(x,0) = 0.
Set the initial time derivative condition u_t(x,0) = 0.
Initialize the first time step using the Taylor start: u^1 = u^0 + dt * v0 + 0.5 * dt^2 * (c^2 * u_xx^0 + f^0).
Discretize the spatial derivative u_xx in the interior using 2nd-order central differences.
Integrate in time using the standard 2nd-order central difference (leapfrog) scheme.
Compute the solution u(x, T=1.0) on the spatial grid.
Save the results to a file named "solution_agent_wave_10.npz".
The file must contain the 1D array x, the 1D solution array u, and the scalar values T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_wave_10.png".
