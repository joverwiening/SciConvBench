Solve the 1D compressible Navier-Stokes equations in conservative form on the domain x in [-1, 1] and t in [0, 0.2].
Use a cell-centered finite-volume method with Nx = 800 uniform intervals.
Use piecewise linear reconstruction with the minmod slope limiter.
Compute inviscid fluxes using the Rusanov (local Lax-Friedrichs) numerical flux.
Compute viscous fluxes using a second-order central difference approximation for the velocity gradient.
Use a 2-stage SSP-RK2 (Heun's method) time integrator.
Use a CFL number of 0.5 for time-step stability.
Set the specific heat ratio Gamma to 1.6666666666666667.
Set the dynamic viscosity eta to 1e-08.
Set the bulk viscosity zeta equal to eta (1e-08).
Apply transmissive (zero-gradient) outflow boundary conditions at x = -1 and x = 1.
Set the initial condition as a Riemann problem with a discontinuity at x = 0.
For x < 0, set density rho_L = 1.0, velocity v_L = 0.0, and pressure p_L = 2.0.
For x >= 0, set density rho_R = 0.125, velocity v_R = 0.0, and pressure p_R = 0.2.
Compute the solution at the final time T = 0.2.
Output the solution arrays rho(x,T), v(x,T), p(x,T) on the cell centers.
Save the solution to a file named "solution_pdebench_cns1d_sod5_eta1em8_outflow.npz".
The .npz file must contain the 1D arrays x, rho, v, p, and the scalar values Gamma, eta, zeta, T, dx, CFL.
Save a plot of rho, v, and p versus x at time T to a file named "solution_pdebench_cns1d_sod5_eta1em8_outflow.png".
Print the minimum and maximum values of rho and p to the console as a positivity check.
Print the mean value of rho over the domain to the console as a mass conservation check.
