Solve the 1D linear advection-diffusion equation for the field u(x,t) on the periodic domain x in [0,1) and t in [0, 0.5].
The PDE is u_t = -1.0 * ∂_x(u) + (0.05/pi) * u_xx.
Use a uniform periodic spatial grid with Nx=512 points, where x_j = j * dx for j=0,...,Nx-1 and dx = 1/512.
Use first-order upwind finite differences for the advection term ∂_x(u).
Use second-order central finite differences for the diffusion term u_xx.
Calculate the time step dt as min(0.4*dx/1.0, 0.2*dx**2/(0.05/pi)).
Set the number of time steps Nt to ceil(0.5 / dt).
Recalculate dt as 0.5 / Nt.
Use the IMEX Euler method, treating the advection term explicitly and the diffusion term implicitly.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Apply periodic boundary conditions such that u(0,t) = u(1,t) for all t.
Verify the numerical solution by comparing it to the exact Fourier-mode evolution.
