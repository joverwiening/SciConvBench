Use a CFL number of 0.5.
Use Nx = 400 uniform finite-volume cells on the spatial domain [-1, 1].
The cell width is dx = (1 - (-1)) / 400 = 0.005.
Cell centers are located at x_j = -1 + (j + 0.5) * dx for j = 0, ..., Nx-1.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Use the equation of state p = (Gamma - 1) * (E - 0.5 * m**2 / rho).
Clip rho and p to a floor value of 1e-12 if needed to enforce positivity.
Compute the convective flux F_conv(U) = [m, m**2 / rho + p, (E + p) * v] where v = m / rho.
Use the Rusanov numerical flux at interfaces: F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L).
Compute the interface wave speed a as max(abs(v_L) + c_L, abs(v_R) + c_R), where c = sqrt(Gamma * p / rho).
Compute the velocity gradient v_x using a centered difference on cell-centered v values.
Compute the viscous stress sigma = (zeta + 4/3 * eta) * v_x.
Average neighboring cell-centered sigma values to obtain sigma at interfaces.
Compute the viscous flux F_visc = [0, -sigma, -v * sigma] using interface-averaged v and sigma.
Compute the total interface flux as F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Compute the convective time step constraint dt_conv = CFL * dx / max_j( abs(v_j) + c_j ).
Compute the viscous time step constraint dt_visc = 0.5 * dx**2 / max( zeta + 4/3 * eta, 1e-30 ).
Set the time step dt = min(dt_conv, dt_visc) each step.
Adjust the final time step to exactly reach the final time T = 0.5.
Implement periodic boundary conditions by wrapping indices.
Compute the final solution fields rho(x, T), v(x, T), p(x, T) on the cell centers.
