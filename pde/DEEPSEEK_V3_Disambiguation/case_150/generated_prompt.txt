Solve the 1D Viscous Burgers equation for u(x,t) with nu=0.001.

Set the initial dt0 = CFL * dx / 1.0.
Set Nt = ceil(T / dt0).
Recalculate dt = T / Nt.
Compute the solution u at the final time T=1.0 on the defined spatial grid.
