Solve the 1D Viscous Burgers equation on the periodic domain x in [0, 1).

Recalculate the actual time step as dt = T / Nt.

For each diffusion half-step, compute the exact solution in Fourier space using the FFT.
For the advection full-step, use a finite-volume update with the Rusanov (local Lax-Friedrichs) numerical flux.
