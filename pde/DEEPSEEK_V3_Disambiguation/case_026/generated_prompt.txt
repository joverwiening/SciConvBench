Solve the PDE u_t = 0.01*u_xx + u*(1-u)*(u-0.25) numerically.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.5].
The diffusion coefficient D is 0.01.
The parameter a in the reaction term is 0.25.
The initial condition is u(x,0) = 0.5*(1 - tanh((x-0.5)/0.02)).
Use Dirichlet boundary conditions: u(0,t)=1 and u(1,t)=0.
Use a uniform spatial grid with Nx=600 intervals, resulting in 601 points.
Use a time step of dt=0.0002.
Use a 2nd-order central difference scheme for the spatial diffusion term.
Use a deterministic IMEX time integration scheme: treat the diffusion term implicitly with backward Euler and the reaction term explicitly with forward Euler.
At each time step, solve the linear system (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) using a sparse direct solver.
Compute the solution u(x, T=0.5) on the spatial grid.
Save the arrays x and u, and metadata scalars T, dx, and dt to the file "solution_agent_diffusion_reaction_04.npz".
Create and save a line plot of u(x,T) to the file "solution_agent_diffusion_reaction_04.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time T=0.5.
