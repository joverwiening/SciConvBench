The task is to numerically solve the 1D viscous Burgers equation with periodic boundary conditions using Strang splitting with exact spectral diffusion and Rusanov finite-volume advection.

The spatial domain is [0,1) with periodic boundary conditions, using Nx=512 grid points with dx=1/512.

The initial condition is u(x,0) = sin(2*pi*x).

The final time T is not explicitly specified in the requirements. Use T=1.0 as a standard benchmark time for this problem.

The numerical method uses Strang splitting: (A) exact diffusion half-step in Fourier space with factor exp(-nu*k^2*(dt/2)), (B) advection full-step using Rusanov flux with alpha=max(|u_left|,|u_right|), (C) diffusion half-step again.

The time step uses CFL=0.4 with estimated max speed 1.0, so dt0 = 0.4*dx, then adjusted so Nt=ceil(T/dt0) and dt=T/Nt exactly reaches T.

The wavenumbers for FFT are k = 2*pi*fftfreq(Nx, d=dx).

The advection flux is F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left) where f(u)=0.5*u^2.

The finite-volume update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.

The solution is saved to "solution_pdebench_burgers_nu2em3.npz" containing arrays x, u and scalars nu, T, dx, dt, Nx, Nt.

A line plot is saved to "solution_pdebench_burgers_nu2em3.png".

The report prints min(u), max(u), mean(u), and sqrt(sum(u^2)*dx) at the final time.
