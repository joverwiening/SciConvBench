Use a time step dt satisfying the CFL condition: dt = 0.5*dx/sqrt(q) = 0.0025 for stability.

Initialize the grid with x_i = i*dx for i = 0, 1, ..., Nx-1 (periodic, no duplicate endpoint).

Set initial condition u(x,0) = sin(2*pi*x) at all grid points.

Set initial velocity u_t(x,0) = 0 using a forward Euler step: u^{-1} = u^0 - dt*0 = u^0, or equivalently use the central difference: u^1 = u^0 + 0.5*dt^2*q*u_xx^0.

Evolve from t=0 to t=T=1.0 using Nt = ceil(T/dt) steps, adjusting the final step to hit exactly T=1.0 if needed.

At the final time, compute and print: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
