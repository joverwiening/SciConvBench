The PDE is a 1D inviscid conservation law with cubic flux: u_t = -k * ∂_x((1/3)*u^3) with k=1.0.

The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 0.2].

The initial condition is u(x,0) = 0.5*sin(2*pi*x).

Use a uniform periodic grid with Nx=1024 points on [0,1), with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.

Implement a conservative finite-volume method with Rusanov flux for f(u)=(1/3)*u^3.

Use SSP-RK2 for time integration.

Compute the time step using CFL=0.2: estimate max|f'(u)| = max|u^2|; with |u|<=0.5 initially, max|f'|<=0.25. Set dt0=CFL*dx/max|f'|, Nt=ceil(T/dt0), dt=T/Nt.

Periodic boundary conditions are enforced as u(0,t)=u(1,t) for all t.

No closed-form reference solution is required for verification.
