Solve the 1D inviscid conservation law u_t = -k*∂_x(sin(u)) on the periodic domain x in [0,1) with t in [0,0.2].

Set the parameter k = 1.0.

Apply periodic boundary conditions u(0,t) = u(1,t) for all t.

Use the initial condition u(x,0) = 0.5*sin(2*pi*x).

Construct a uniform periodic spatial grid with Nx = 1024 points on [0,1).

Define dx = 1/Nx and grid points x_j = j*dx for j = 0,...,Nx-1.

Implement conservative finite-volume spatial discretization using Rusanov flux for f(u) = sin(u).

Compute the Rusanov numerical flux as F_{j+1/2} = 0.5*(f(u_j) + f(u_{j+1})) - 0.5*alpha*(u_{j+1} - u_j) where f(u) = sin(u) and alpha = max|cos(u)| over the stencil.

Use alpha = 1.0 as the global maximum wave speed since |cos(u)| <= 1 for all real u.

Compute cell interface fluxes and form the semi-discrete residual R_j = -(F_{j+1/2} - F_{j-1/2})/dx.

Apply time integration using SSP-RK2 (strong stability preserving Runge-Kutta of order 2).

Compute the time step using CFL = 0.2: dt0 = CFL*dx/1.0.

Set Nt = ceil(0.2/dt0) and dt = 0.2/Nt to reach exactly t = 0.2.

Execute the SSP-RK2 stages: u^{(1)} = u^n + dt*R(u^n), then u^{n+1} = 0.5*u^n + 0.5*(u^{(1)} + dt*R(u^{(1)})).

Enforce periodicity by treating indices modulo Nx.

Advance from t=0 to t=0.2 using Nt uniform time steps.

Output the final solution u(x,0.2) at all grid points x_j.
