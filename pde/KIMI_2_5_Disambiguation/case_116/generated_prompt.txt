Solve the 1D sine-Gordon equation u_tt + q*sin(u) = u_xx on the periodic domain x in [0,1) with time t in [0,2.0].

Use q = 1.0.

Apply periodic boundary conditions: u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t).

Set initial conditions: u(x,0) = 0.1*sin(2*pi*x) and u_t(x,0) = 0.

Discretize space with Nx points on [0,1) periodic grid, so dx = 1/Nx and x_i = i*dx for i = 0,...,Nx-1. No endpoint duplication for periodic domain.

Use a time-stepping scheme for second-order wave equation. Store u and u_t (or equivalently u at two time levels). Use a standard finite difference: u_tt ≈ (u^{n+1} - 2u^n + u^{n-1})/dt^2 and u_xx ≈ (u_{i+1} - 2u_i + u_{i-1})/dx^2 with periodic indexing.

For the nonlinear term q*sin(u), evaluate at time level n for explicit scheme, or use iteration for implicit. Use explicit leapfrog or Verlet-style: u^{n+1} = 2u^n - u^{n-1} + dt^2*(u_xx^n - q*sin(u^n)). For first step, use Taylor expansion: u^1 = u^0 + dt*u_t^0 + 0.5*dt^2*(u_xx^0 - q*sin(u^0)) = u^0 + 0.5*dt^2*(u_xx^0 - q*sin(u^0)) since u_t^0 = 0.

Choose Nx and dt to ensure stability. For wave equation, CFL condition requires dt <= dx. Use Nx = 256 or similar, dt = dx/2 for safety.
