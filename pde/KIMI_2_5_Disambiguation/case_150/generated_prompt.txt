The task is to solve the 1D viscous Burgers equation with periodic boundary conditions using Strang splitting with exact Fourier diffusion and Rusanov flux finite-volume advection.

The spatial domain is [0,1) with periodic boundary conditions, interpreted as half-open with Nx=512 grid points and no duplicated endpoint, so dx = 1/512.

The initial condition is u(x,0) = sin(2*pi*x), which has maximum speed approximately 1, so the CFL condition uses max speed ≈ 1.

The time step is determined by CFL=0.4: dt0 = 0.4*dx/1.0, then Nt = ceil(T/dt0) and dt = T/Nt adjusted to hit final time T exactly.

The numerical method uses Strang splitting: (A) diffusion half-step exact in Fourier space, (B) advection full-step with Rusanov flux finite-volume update, (C) diffusion half-step again.

The diffusion substep computes FFT, applies exp(-nu*k^2*(dt/2)) in Fourier space with k = 2*pi*fftfreq(Nx, d=dx), then IFFT taking real part.

The advection substep uses Rusanov flux: for each interface between u_left and u_right, alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left) where f(u)=0.5*u^2, then u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.

The final time T is not specified in the requirements and must be determined.
