Solve the 1D Cahn-Hilliard equation u_t = -epsilon^2 * u_xxxx + d^2/dx^2(u^3 - u) on the periodic domain x in [0,1) with t in [0, 0.05].

Set epsilon = 0.01.

Use initial condition u(x,0) = 0.1*cos(2*pi*x) + 0.01*cos(6*pi*x).

Use a Fourier pseudo-spectral method with Nx = 512 grid points, where x_j = j/Nx for j = 0, 1, ..., 511.

Use time step dt = 1e-5 for 5000 steps to reach T = 0.05.

Compute the wavenumbers k = 2*pi*[0, 1, ..., Nx/2-1, -Nx/2, -Nx/2+1, ..., -1] in the standard FFT ordering.

Define the linear operator L(k) = -epsilon^2 * k^4 + k^2.

At each time step, compute the nonlinear term: (1) compute u^3 in physical space, (2) apply 2/3 dealiasing by zeroing Fourier modes with |k| > (2/3)*k_max where k_max = pi/dx, (3) compute second derivative in Fourier space as -k^2 * FFT(u^3).

Update in Fourier space using the semi-implicit scheme: u_hat^{n+1} = (u_hat^n + dt * (-k^2) * dealias[FFT((u^n)^3)]) / (1 - dt*L(k)).

After each step, transform back to physical space with inverse FFT to obtain real u.

At final time T = 0.05, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx).

Save the solution to "solution_agent_other_02_cahn_hilliard.npz" containing arrays x (1D, length Nx), u (1D, final solution), and scalars T, dx, dt.
