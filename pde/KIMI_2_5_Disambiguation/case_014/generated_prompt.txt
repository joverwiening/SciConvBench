The PDE to solve is the viscous Burgers equation: u_t + u*u_x = nu*u_xx with nu=0.005.

The spatial domain is x in [0,1) with periodic boundary conditions, and time domain is t in [0,0.2].

The initial condition is u(x,0) = 0.5 + sin(2*pi*x).

Use Nx=1200 grid points on [0,1), giving dx=1/1200. Use dt=5e-5 with Nt=4000 time steps to reach T=0.2 exactly.

Discretize in conservative form u_t + (f(u))_x = nu*u_xx where f(u)=0.5*u^2.

For convection, use the Rusanov (local Lax-Friedrichs) flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|). The convection term is (F_{i+1/2}-F_{i-1/2})/dx.

For diffusion, use 2nd-order central difference: u_xx ≈ (u_{i+1}-2*u_i+u_{i-1})/dx^2.

Use 1st-order IMEX time integration: treat convection explicitly and diffusion implicitly. The scheme is (u^{n+1}-u^n)/dt + conv_term^n = nu*diff_term^{n+1}. This gives (I - dt*nu*L)*u^{n+1} = u^n - dt*conv_term^n, where L is the discrete Laplacian with periodic boundary conditions. Solve this sparse linear system each time step using scipy.sparse.linalg.spsolve.

Apply periodic boundary conditions consistently in both the convection flux calculation and the implicit diffusion solve.

Compute u(x,T=0.2) on the grid.
