The PDE is a 1D linear advection-diffusion equation with periodic boundary conditions on the domain [0,1) × [0,0.5].

The equation to solve is: u_t = -q1 * ∂_x(u) + (q2/pi) * u_xx, with q1 = 1.0 and q2 = 0.05.

The spatial domain uses a uniform periodic grid with Nx = 512 points on [0,1), where x_j = j*dx for j = 0,...,Nx-1 and dx = 1/Nx = 1/512.

The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

Boundary conditions are periodic: u(0,t) = u(1,t) for all t.

For spatial discretization, use 1st-order upwind for the advection term ∂_x(u) and 2nd-order central differences for the diffusion term u_xx.

For time integration, use IMEX Euler with diffusion treated implicitly and advection treated explicitly.

Compute the time step as dt = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)), then set Nt = ceil(T/dt) with T = 0.5, and reset dt = T/Nt for the final time step.

The exact solution can be verified using Fourier-mode evolution since the PDE is linear with constant coefficients.
