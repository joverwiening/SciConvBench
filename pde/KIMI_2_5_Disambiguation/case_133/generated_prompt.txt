Solve the 1D inviscid conservation law u_t = -k*∂_x(cos(u)) on the periodic domain x in [0,1) with t in [0,0.2].

Set the parameter k = 1.0.

Apply periodic boundary conditions u(0,t) = u(1,t) for all t.

Use the initial condition u(x,0) = 0.5*sin(2*pi*x).

Construct a uniform periodic spatial grid with Nx = 1024 points on [0,1).

Define dx = 1/Nx and grid points x_j = j*dx for j = 0,...,Nx-1.

Implement spatial discretization using conservative finite-volume Rusanov flux for f(u) = cos(u).

Compute the Rusanov numerical flux as F_{j+1/2} = 0.5*(f(u_j) + f(u_{j+1})) - 0.5*alpha*(u_{j+1} - u_j) where f(u) = cos(u) and alpha = max|sin(u)| <= 1.0.

Use alpha = 1.0 as the global wave speed bound for the Rusanov flux.

Compute the flux divergence as -k*(F_{j+1/2} - F_{j-1/2})/dx for the semi-discrete right-hand side.

Implement time integration using SSP-RK2 (strong stability preserving Runge-Kutta of order 2).

Compute the time step using CFL = 0.2: dt0 = CFL*dx/1.0.

Set Nt = ceil(0.2/dt0) and dt = 0.2/Nt for the final time step.

Advance the solution from t=0 to t=0.2 using Nt steps of SSP-RK2 with the computed dt.

Treat all trigonometric functions using radians.
