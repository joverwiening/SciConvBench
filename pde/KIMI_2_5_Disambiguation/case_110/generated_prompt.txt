The task is to numerically solve the FitzHugh–Nagumo excitable system ODEs with the following complete specification:

The ODE system consists of two coupled first-order ordinary differential equations for unknown fields v(t) and w(t).

The governing equations are:
dv/dt = v - (v**3)/3 - w + I
dw/dt = (1/tau)*(v + a - b*w)

The time domain is t in [0.0, 200.0].

The parameters are fixed as:
I = 0.5
a = 0.7
b = 0.8
tau = 12.5

The numerical method is Classical 4th-order Runge–Kutta (RK4) with fixed step size dt = 0.05, using Nt = 4000 steps to reach the final time exactly.

Initial conditions must be specified. Use v(0) = -1.0 and w(0) = -0.5 as standard initial conditions for the excitable regime.

The computation must produce the full state vector at all time points t_n = t0 + n*dt for n = 0 to Nt, resulting in Nt+1 = 4001 time points.

The output requirements are:
Save "solution_molk_009.npz" containing arrays t (1D, length 4001), Y (2D array shape [4001, 2]) with columns ordered as [v, w], and the parameter scalars I, a, b, tau.
Save line plots of each state versus time as "solution_molk_009.png".
Print the final state values at T = 200.0.
Print the minimum and maximum values of each state over the entire time history.
