Initial conditions are not explicitly specified in the prompt, so use the standard Van der Pol initial conditions: x(0) = 2.0, y(0) = 0.0.

The output requirements are:
Compute the full state vector at all time points t_n = t0 + n*dt for n=0..Nt.
Save "solution_molk_007.npz" containing arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, 2]) with columns ordered as [x, y], and the parameter scalars.
Save line plots of each state vs t as "solution_molk_007.png".
Print the final state values at T=20.0 and also print the minimum and maximum of each state over time.

The grid convention follows: Nx uniform intervals with Nx+1 grid points including both endpoints, dx=(b-a)/Nx, x_i=a+i*dx.
