Solve the 1D linear Klein-Gordon-type PDE u_tt + (q2**2)*(q1**4)*u = (q1**2)*u_xx on the periodic domain x in [0,1) with t in [0,1.0].

Use parameters q1 = 1.0 and q2 = 0.5.

Apply periodic boundary conditions: u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t).

Set initial conditions u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.

Discretize space with Nx = 256 grid points (standard resolution for periodic spectral/FD methods), giving dx = 1/256 and x_i = i*dx for i = 0..255.

Use a second-order central finite difference scheme in space: u_xx(x_i) ≈ (u_{i+1} - 2*u_i + u_{i-1})/dx^2 with periodic indexing.

Use the leapfrog (Verlet) method for time integration: u^{n+1} = 2*u^n - u^{n-1} + dt^2 * [(q1**2)*u_xx^n - (q2**2)*(q1**4)*u^n].

Choose time step dt = 0.4*dx/q1 to satisfy the CFL stability condition (CFL factor 0.4), giving approximately Nt = ceil(T/dt) steps.

Initialize the leapfrog scheme using the initial conditions: set u^0 = sin(2*pi*x) and u^{-1} = u^0 (since u_t=0 at t=0, use u^{-1} = u^0 for the first step).

Evolve from t=0 to t=T=1.0.

At final time T=1.0, compute and print: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx).
