The task is to solve the Klein-Gordon PDE numerically with the following specifications:

The PDE is u_tt - (1.2)^2*u_xx + (0.8)^2*u = 0 on the domain x in [0,1], t in [0,0.7].

The parameters are c = 1.2 and m = 0.8.

The initial conditions are u(x,0) = sin(3*pi*x) and u_t(x,0) = 0.

The exact solution for verification is u(x,t) = cos(sqrt((1.2*3*pi)^2 + (0.8)^2)*t)*sin(3*pi*x).

Use a uniform spatial grid with Nx = 600 intervals, giving Nx+1 = 601 points including both endpoints at x = 0 and x = 1.

Compute dx = 1/Nx = 1/600.

Compute dt0 = 0.9*dx/c = 0.9*dx/1.2 to satisfy the CFL condition c*dt/dx ≤ 0.9.

Set Nt = ceil(T/dt0) with T = 0.7, then set dt = T/Nt so the final time is hit exactly.

Use 2nd-order central differences in space for u_xx: u_xx at point i approximated as (u_{i+1} - 2*u_i + u_{i-1})/dx^2.

Use 2nd-order central difference in time (leapfrog) for u_tt: u_tt at time level n approximated as (u^{n+1} - 2*u^n + u^{n-1})/dt^2.

The time-stepping equation is: (u^{n+1} - 2*u^n + u^{n-1})/dt^2 = c^2*(u_{i+1}^n - 2*u_i^n + u_{i-1}^n)/dx^2 - m^2*u_i^n.

Rearrange to solve for u^{n+1}: u^{n+1} = 2*u^n - u^{n-1} + dt^2*(c^2*(u_{i+1}^n - 2*u_i^n + u_{i-1}^n)/dx^2 - m^2*u_i^n).

Handle the +m^2*u term explicitly at time level n in the update.

For initialization, use Taylor expansion from u0 and v0 (where v0 = u_t(x,0) = 0), including the -m^2*u0 term.

The Taylor start gives: u^1 = u^0 + dt*v0 + (dt^2/2)*u_tt^0, where u_tt^0 = c^2*u_xx^0 - m^2*u^0.

Since v0 = 0, this simplifies to: u^1 = u^0 + (dt^2/2)*(c^2*u_xx^0 - m^2*u^0).

Apply Dirichlet boundary conditions u(0,t) = u(1,t) = 0 for all time, consistent with the initial data.

Compute u(x, T=0.7) on the grid.

Save "solution_agent_kg_09.npz" containing arrays x (1D, length 601), u (1D, same length), and metadata scalars T=0.7, dx, dt.

Save a line plot of u(x,T) as "solution_agent_kg_09.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.7.

Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
