The task is to solve the 1D wave equation numerically with the following specifications:

The PDE is u_tt = (1.0)^2 * u_xx + sin(pi*x)*sin(2*pi*t) on the domain x in [0,1] and t in [0,1.0].

The wave speed c equals 1.0.

The boundary conditions are Dirichlet with u=0 at x=0 and x=1 for all time.

The initial conditions are u(x,0)=0 and u_t(x,0)=0.

Use a uniform spatial grid on [0,1] with Nx=400 intervals, giving Nx+1=401 grid points. The grid spacing is dx=1/400=0.0025. The spatial points are x_i = i*dx for i=0,...,400.

For spatial discretization, use second-order central differences for u_xx at interior points: (u_{i+1} - 2*u_i + u_{i-1})/dx^2.

For time integration, use the standard second-order central difference (leapfrog/Störmer-Verlet): u_i^{n+1} = 2*u_i^n - u_i^{n-1} + dt^2*(c^2*u_xx_i^n + f_i^n).

Compute the initial time step dt0 = 0.9*dx/c = 0.9*0.0025/1.0 = 0.00225. Set Nt = ceil(T/dt0) = ceil(1.0/0.00225) = ceil(444.44...) = 445. Then set dt = T/Nt = 1.0/445 ≈ 0.002247191 to hit the final time exactly.

Initialize with u^0 = 0 everywhere. Compute u^1 using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0). Since u^0=0, v0=0, and u_xx^0=0, this gives u^1 = 0.5*dt^2*f^0 where f^0 = sin(pi*x)*sin(0) = 0, so u^1 = 0.

At each time step, enforce Dirichlet boundary conditions by setting u_0^n = 0 and u_{Nx}^n = 0.

Compute the solution at T=1.0.

Save the results to "solution_agent_wave_10.npz" containing: x (1D array of 401 points), u (1D array of solution values at T), and scalars T=1.0, dx=0.0025, dt=1.0/445.

Save a line plot of u(x,T) to "solution_agent_wave_10.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
