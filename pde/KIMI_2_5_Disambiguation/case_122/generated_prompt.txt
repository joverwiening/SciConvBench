Solve the 1D linear reaction-diffusion PDE u_t = q1*u_xx + q2*u on the periodic domain x in [0,1) with t in [0,0.5].

Use parameters q1 = 0.01 and q2 = -1.0.

Apply periodic boundary conditions u(0,t) = u(1,t) for all t.

Set initial condition u(x,0) = sin(2*pi*x).

Use the method of lines with second-order central finite differences for the spatial derivative and a standard time integrator (e.g., scipy.integrate.solve_ivp with method='RK45' or similar).

Interpret Nx as the number of grid points with no duplicated endpoint for the periodic domain [0,1), so dx = 1/Nx and x_i = i*dx for i = 0,1,...,Nx-1.

Discretize u_xx at interior points using (u_{i+1} - 2*u_i + u_{i-1})/dx^2 with periodic wrapping: index -1 maps to Nx-1 and index Nx maps to 0.

Integrate from t=0 to t=0.5.

After computing u(x,T=0.5), save "solution_molk_021.npz" containing: x (1D array length Nx), u (1D array length Nx), scalars T=0.5, dx, Nx, and parameter scalars q1, q2.

Save a line plot of u(x,T) versus x as "solution_molk_021.png" with appropriate labels.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.

Compute the exact solution u_exact(x,t) = exp(q2*t) * exp(-q1*(2*pi)**2*t) * sin(2*pi*x) evaluated at t=0.5 on the same x grid.

Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2)*dx).
