The PDE is the 1D viscous Burgers equation with periodic boundary conditions on [0,1).

The spatial domain uses a uniform periodic grid with Nx=512 points on [0,1), where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.

The PDE is u_t = -q1 * d/dx(0.5*u^2) + (q2/pi)*u_xx with q1=1.0 and q2=0.1.

The initial condition is u(x,0) = sin(2*pi*x).

The spatial discretization uses a conservative finite-volume approach for the nonlinear flux f(u)=0.5*u^2 with the Rusanov (local Lax-Friedrichs) flux, and second-order central differences for the diffusion term u_xx.

The time integration uses SSP-RK2 (Heun) with a fixed time step.

The time step is computed as follows: D_eff = q2/pi = 0.1/pi, dt_conv = 0.4 * dx / 1.0 = 0.4*dx, dt_diff = 0.4 * dx^2 / D_eff = 0.4 * dx^2 * pi / 0.1 = 4*pi*dx^2, dt0 = min(dt_conv, dt_diff), Nt = ceil(0.5/dt0), and dt = 0.5/Nt.

The boundary conditions are periodic: u(0,t) = u(1,t) for all t, implemented by proper ghost cell handling or index wrapping.

The simulation runs from t=0 to t=0.5.

No reference solution is required for verification.
