The task is to solve a 1D diffusion-reaction PDE numerically with the following specifications:

The PDE is u_t = 0.01*u_xx + u*(1-u)*(u-0.25), where the unknown field u(x,t) represents a scalar concentration or density.

The spatial domain is x in [0,1] and the time domain is t in [0,0.5].

The parameters are D = 0.01 for diffusion and a = 0.25 for the reaction term threshold.

Boundary conditions are Dirichlet: u(0,t) = 1 at the left boundary and u(1,t) = 0 at the right boundary.

The numerical method uses a uniform grid with Nx = 600 intervals, giving 601 grid points including both endpoints. The grid spacing is dx = (1-0)/600 = 1/600. The grid points are x_i = 0 + i*dx for i = 0, 1, ..., 600.

The time step is dt = 0.0002, requiring 2500 steps to reach T = 0.5.

Spatial discretization uses 2nd-order central differences for the diffusion term: u_xx at interior point i is approximated as (u_{i-1} - 2*u_i + u_{i+1})/dx^2.

Time integration uses a deterministic IMEX scheme (1st order): diffusion is treated implicitly with backward Euler, reaction is treated explicitly with forward Euler. At each step, solve (I - dt*D*L)*u^{n+1} = u^n + dt*R(u^n), where L is the discrete Laplacian matrix incorporating Dirichlet boundary conditions, and R(u) = u*(1-u)*(u-0.25) is the reaction term. Use a sparse direct solver for the linear system at each step.

The initial condition is not explicitly stated; use u(x,0) = 1 - x as a linear profile satisfying the boundary conditions u(0,0)=1 and u(1,0)=0.

The discrete Laplacian L is a (Nx-1) x (Nx-1) tridiagonal matrix for the interior points, with entries: main diagonal -2/dx^2, off-diagonals 1/dx^2. The boundary conditions are enforced by modifying the right-hand side: for the first interior point, add D*dt*(1/dx^2)*u(0,t) = D*dt/dx^2 to account for the left Dirichlet condition; for the last interior point, add D*dt*(1/dx^2)*u(1,t) = 0.

Compute u(x, T=0.5) on the grid.
