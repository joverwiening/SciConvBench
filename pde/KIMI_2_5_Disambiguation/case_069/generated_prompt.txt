Use Fourier pseudo-spectral differentiation with Nx = 1024 grid points. The grid points are x_i = i * dx for i = 0, 1, ..., Nx-1 where dx = 2*pi/Nx.

Compute spatial derivatives via FFT: u_x = IFFT(i*k*FFT(u)), u_xx = IFFT(-k^2*FFT(u)), u_xx = IFFT(-k^4*FFT(u)), where k is the wavenumber array [0, 1, ..., Nx/2-1, -Nx/2, ..., -1].

Use time step dt = 1e-4 for 10000 steps to reach T = 1.0.

Use a semi-implicit time integration scheme in Fourier space: treat the nonlinear term u*u_x explicitly and the linear terms u_xx + u_xxxx implicitly. For each Fourier mode with wavenumber k, update as û^{n+1} = (û^n - dt * FFT(u*u_x)) / (1 - dt*(-k^2 + k^4)).

At each time step: compute u*u_x in physical space, transform to Fourier space, apply the semi-implicit update, and transform back to physical space.
