Solve the 1D linear advection equation u_t + q*u_x = 0 with periodic boundary conditions on the domain x in [0, 1) and t in [0, 1.1].

Discretize the spatial domain with Nx = 512 uniform points on [0, 1) using a periodic grid with dx = 1/Nx and x_j = j*dx for j = 0 to Nx-1.  
Compute the time step dt0 = CFL*dx/|q| with CFL = 0.5, then set Nt = ceil(1.1 / dt0) and dt = 1.1 / Nt.  
Use the first-order upwind finite difference scheme for the spatial derivative u_x.  
Use the Forward Euler method for time integration.  
Advance the solution from t = 0 to t = 1.1 using Nt time steps.  
At t = 1.1, compute the numerical solution u(x,1.1) on the grid points x_j.  
Evaluate the exact solution at t = 1.1 on the same grid for error computation.  
Save the results in a .npz file named "solution_molk_018.npz" containing: x (1D array of length Nx), u (1D array of length Nx), T = 1.1, dx, Nx, and q.

Print the minimum value of u, maximum value of u, mean of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at t = 1.1.
