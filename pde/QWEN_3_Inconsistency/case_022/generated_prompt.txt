Solve the PDE \( u_t = 0.05 (u_{xx} + u_{yy}) \) numerically on the spatial domain \( (x,y) \in [0,1] \times [0,1] \) and temporal domain \( t \in [0, 0.5] \).
Use the diffusion coefficient \( D = 0.05 \).
Apply Neumann boundary conditions on all edges: \( \partial u / \partial n = 0 \) (zero-flux).
Set the initial condition: \( u(x,y,0) = \exp(-80((x-0.3)^2 + (y-0.7)^2)) \).
Use a uniform spatial grid with \( Nx = Ny = 80 \) intervals, resulting in 81×81 grid points.
Compute spatial step sizes: \( dx = dy = 1/80 \).
Use the 5-point Laplacian stencil for spatial discretization.
Implement ghost nodes to enforce zero Neumann boundary conditions.
Use implicit Euler time integration with time step \( dt = 0.001 \), taking 500 steps.
Compute the solution \( u(x,y,T) \) at final time \( T = 0.5 \).
Construct 1D coordinate arrays: \( x = [0, dx, 2dx, ..., 1] \), \( y = [0, dy, 2dy, ..., 1] \).
Save the solution in a .npz file named "solution_agent_diffusion_06.npz" containing:
  - x: 1D array of x-coordinates.
  - y: 1D array of y-coordinates.
  - u: 2D array of solution values at \( T = 0.5 \), with shape (len(y), len(x)), such that u[j,i] corresponds to \( u(x[i], y[j]) \).
  - Metadata: scalar values \( T = 0.5 \), \( dx = 0.0125 \), \( dy = 0.0125 \), \( dt = 0.001 \).
Generate a heatmap or contour plot of \( u(x,y,0.5) \) and save it as "solution_agent_diffusion_06.png".
Print the minimum value of \( u \) at \( T = 0.5 \): min(u).
Print the maximum value of \( u \) at \( T = 0.5 \): max(u).
Print the discrete L2 norm: \( \sqrt{\sum u^2 \cdot dx \cdot dy} \).
