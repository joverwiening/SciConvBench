Solve the 2D Darcy flow PDE: -∇ · (a(x,y) ∇u(x,y)) = 1 on the domain (0,1) × (0,1).  
Use the coefficient field a(x,y) = 1 + 2 * (0.5 + 0.5 * sin(2 * π * x) * sin(2 * π * y)).  
Apply Dirichlet boundary conditions: u = 0 on all boundaries ∂((0,1) × (0,1)).  
Discretize the domain using a uniform Cartesian grid with N = 128 intervals in each direction, resulting in N+1 = 129 grid points per dimension.  
Set grid spacing dx = dy = 1/128.  
Define grid points as x_i = i * dx for i = 0,...,128 and y_j = j * dy for j = 0,...,128.  
Use second-order finite differences for spatial discretization with harmonic averaging for face-centered coefficients.  
For interior nodes (i=1..127, j=1..127), compute face coefficients as:  
a(i+1/2,j) = 2 * a(i,j) * a(i+1,j) / (a(i,j) + a(i+1,j)),  
a(i,j+1/2) = 2 * a(i,j) * a(i,j+1) / (a(i,j) + a(i,j+1)),  
and similarly for left and bottom faces.  
Assemble the sparse linear system Au = b for the interior unknowns (u_ij for i=1..127, j=1..127).  
The right-hand side b is constant and equal to 1 at each interior node.  
Solve the linear system using the conjugate gradient (CG) method with a relative residual tolerance of 1e-10.  
Optionally use a Jacobi preconditioner during CG iteration.  
After solving, extend the solution to the full grid by setting boundary values to zero.  
Compute the discrete residual norm ||Au - b||₂ / ||b||₂ for the interior system.  
Save the results in a .npz file named "solution_pdebench_darcy_beta1.npz" containing:  
- x: 1D array of x coordinates (length 129),  
- y: 1D array of y coordinates (length 129),  
- u: 2D array of solution values (shape [129, 129]),  
- beta: scalar value 2,  
- N: scalar value 128,  
- dx: scalar value 1/128.  
Generate and save a heatmap or contour plot of u(x,y) as "solution_pdebench_darcy_beta1.png".  
Print the following scalar diagnostics:  
- Minimum value of u: min(u),  
- Maximum value of u: max(u),  
- Discrete residual norm: ||Au - b||₂ / ||b||₂.
