Solve the PDE \( u_t + 1.0 \cdot u_x + 0.5 \cdot u_y = 0 \) numerically on the domain \( (x, y) \in [0,1) \times [0,1) \) with periodic boundary conditions in both directions and \( t \in [0, 1.0] \).  
Use the initial condition \( u(x, y, 0) = \sin(2\pi x) \cos(2\pi y) \).  
The exact solution is \( u(x, y, t) = \sin(2\pi (x - 1.0 t)) \cos(2\pi (y - 0.5 t)) \).  
Discretize the spatial domain using a uniform periodic grid with \( N_x = N_y = 256 \) points, so \( dx = dy = 1/256 \).  
Apply 1st-order upwind finite differences for spatial derivatives in both x and y directions.  
Use Forward Euler time integration with time step \( dt \) chosen as follows: compute \( dt_0 = 0.9 / (|1.0|/dx + |0.5|/dy) \), then set \( N_t = \lceil 1.0 / dt_0 \rceil \) and \( dt = 1.0 / N_t \) to ensure the final time is exactly \( T = 1.0 \).  
Handle boundary conditions using periodic wrap-around indexing.  
Compute the numerical solution \( u(x, y, T=1.0) \) on the 2D grid.  
Save the results in a file named "solution_agent_advection_04.npz" containing:  
- x: 1D array of grid points in x-direction, \( x_i = i \cdot dx \) for \( i = 0, \dots, 255 \)  
- y: 1D array of grid points in y-direction, \( y_j = j \cdot dy \) for \( j = 0, \dots, 255 \)  
- u: 2D array of solution values at \( T = 1.0 \) with shape (256, 256), where \( u[j,i] = u(x[i], y[j]) \)  
- scalar metadata: T = 1.0, dx = 1/256, dy = 1/256, dt = 1.0 / N_t  
Generate and save a heatmap or contour plot of \( u(x, y, T=1.0) \) as "solution_agent_advection_04.png".  
Print the following scalar diagnostics:  
- Minimum value of u: min(u)  
- Maximum value of u: max(u)  
- Discrete L2 norm: \( \sqrt{\sum_{i,j} u[i,j]^2 \cdot dx \cdot dy} \)  
Evaluate the exact solution on the same grid at \( T = 1.0 \) and compute:  
- Max absolute error: \( \max |u_{\text{numerical}} - u_{\text{exact}}| \)  
- L2 error: \( \sqrt{\sum_{i,j} (u_{\text{numerical}}[i,j] - u_{\text{exact}}[i,j])^2 \cdot dx \cdot dy} \)  
Print both error values.
