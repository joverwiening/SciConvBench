The PDE to solve is u_tt - c^2*u_xx + m^2*u = 0 with c = 2 and m = 1.0.  
The spatial domain is x ∈ [0,1] and the temporal domain is t ∈ [0,1.0].  
The boundary conditions are Dirichlet: u(0,t) = u(1,t) = 0 for all t.  
The initial conditions are u(x,0) = sin(πx) and u_t(x,0) = 0.  
The exact solution for verification is u(x,t) = cos(√((π)^2 + 1)*t) * sin(πx).  
Use a uniform spatial grid with Nx = 400 intervals, resulting in 401 grid points.  
Compute dx = 1.0 / Nx.  
Set c = 2.0 and compute the maximum stable time step dt0 = 0.9 * dx / c.  
Set Nt = ceil(1.0 / dt0), then set dt = 1.0 / Nt to ensure the final time is exactly T = 1.0.  
Discretize u_xx using second-order central differences on the uniform grid.  
Use leapfrog time integration for u_tt with second-order central differences in time.  
Treat the m^2*u term explicitly at the current time level during the time update.  
Initialize the solution using a Taylor expansion: u^1 = u^0 + dt * v^0 + 0.5 * dt^2 * (c^2 * u_xx^0 - m^2 * u^0), where v^0 = u_t(x,0) = 0.  
At each time step, apply Dirichlet boundary conditions by setting u[0] = u[-1] = 0.  
Compute the numerical solution u(x, t=1.0) on the spatial grid.  
Evaluate the exact solution on the same spatial grid at t = 1.0 for error computation.  
Compute the max absolute error as max(|u_numerical - u_exact|).  
Compute the L2 error as sqrt(sum((u_numerical - u_exact)^2) * dx).  
Compute the discrete L2 norm of the numerical solution as sqrt(sum(u_numerical^2) * dx).  
Save the following to "solution_agent_kg_01.npz": x (1D array of grid points), u (numerical solution at t=1.0), and scalars T=1.0, dx, dt.
