Use the following specification to solve the given PDE numerically.  

The PDE is the 1D reaction–diffusion equation: u_t = nu * u_xx + rho * u*(1 - u).  
The spatial domain is x in [0, 1) with periodic boundary conditions.  
The temporal domain is t in [0, 1.0].  
Set nu = 10.0.  
Set rho = 5.0.  
Impose periodic boundary conditions: u(0,t) = u(1,t) for all t.  
Set the initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).  
Use a uniform spatial grid with Nx = 512 points on [0, 1).  
Compute dx = 1 / Nx.  
Define grid points: x_j = j * dx for j = 0 to Nx-1.  
Use a uniform time grid with dt = 0.001.  
Set Nt = 1000 so that T = Nt * dt = 1.0 is reached exactly.  
Use explicit forward Euler time integration within the Strang splitting framework.  
Apply Strang splitting at each full time step dt as follows:  
First, perform a diffusion half-step of duration dt/2 using exact integration in Fourier space:  
Compute u_hat = FFT(u).  
Define wave numbers k = 2 * pi * fftfreq(Nx, d=dx).  
Update u_hat(k) = u_hat(k) * exp(-nu * k^2 * dt/2).  
Compute u = real(IFFT(u_hat)).  
Second, perform a full reaction step of duration dt using the exact solution of the logistic ODE:  
For each grid point j, update u_j = (u_j * exp(rho * dt)) / (1 + u_j * (exp(rho * dt) - 1)).  
Third, perform another diffusion half-step identical to the first.  
After completing all Nt time steps, compute the solution u(x, T=1.0).  
Save the results in a .npz file named "solution_pdebench_reacdiff_nu10_rho5.npz".  
Include in the .npz file: the array x of length Nx, the array u of length Nx, and scalar values nu, rho, T=1.0, dx, dt, Nx=512, Nt=1000.
