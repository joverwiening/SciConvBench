Use the following specification to solve the given PDE numerically.  

The PDE is the 1D reaction–diffusion equation: u_t = nu * u_xx + rho * u*(1 - u).

The temporal domain is t in [0, 1.0].  
Set nu = 0.5.  
Set rho = 5.0.  
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).  
Compute dx = 1 / Nx.  
Define grid points: x_j = j * dx for j = 0 to Nx-1.  
Use a fixed time step dt = 0.001.  
Take Nt = 1000 time steps, so the final time is T = 1.0.  
Use explicit forward Euler time integration within the Strang splitting framework.  
Implement Strang splitting per time step as follows:  
First, perform a diffusion half-step of duration dt/2 using exact solution in Fourier space:  
  Compute u_hat = FFT(u).  
  Define wave numbers k = 2 * pi * fftfreq(Nx, d=dx).  
  Update u_hat(k) = u_hat(k) * exp(-nu * k^2 * (dt/2)).  
  Update u = real(IFFT(u_hat)).  
Second, perform a full reaction step of duration dt using the exact solution of the logistic ODE:  
  For each grid point, update u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).  
Third, perform another diffusion half-step identical to the first.  
After completing all time steps, compute the solution u(x, T=1.0).
