Solve the 1D reaction-diffusion PDE with logistic reaction term on a periodic domain [0, 1) for t in [0, 1.0].  
Use the Strang splitting method with forward Euler time integration.  
Set the diffusion coefficient nu = 0.5 and reaction coefficient rho = 2.0.  
Use a uniform spatial grid with Nx = 512 points on [0, 1) with periodic boundary conditions.  
Compute dx = 1 / Nx and define grid points x_j = j * dx for j = 0 to Nx-1.  
Use a uniform time grid with dt = 0.001 and Nt = 1000 steps, reaching T = 1.0 exactly.  
Initialize the solution as u(x,0) = 0.25 + 0.1 * sin(2 * pi * x).  
For each time step, perform Strang splitting:  
First, apply a half-step of diffusion (duration dt/2) using Fourier spectral methods:  
Compute the FFT of u to get u_hat.  
Define wave numbers k = 2 * pi * fftfreq(Nx, d=dx).  
Update u_hat(k) = u_hat(k) * exp(-nu * k^2 * dt/2).  
Perform inverse FFT and take the real part to get u after diffusion half-step.  
Next, apply a full-step of reaction (duration dt) using the exact solution of the logistic ODE:  
Update each grid point as u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).  
Then, apply a second diffusion half-step identical to the first.  
After completing all time steps, compute the solution u(x, T=1.0).  
Save the solution in a .npz file named "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing:  
x: 1D array of length Nx with grid points.  
u: 1D array of length Nx with solution values at T=1.0.  
Scalars: nu, rho, T=1.0, dx, dt, Nx=512, Nt=1000.  
Save a line plot of u(x, T=1.0) vs x in a file named "solution_pdebench_reacdiff_nu0p5_rho2.png".  
Print the following scalar diagnostics at T=1.0:  
Minimum value of u.

Mean value of u.
