The PDE to solve is u_t = ∂/∂x( D(x) * u_x ), where D(x) = 0.01 + 0.09*x^2.  
The spatial domain is x ∈ [0,1] and the time domain is t ∈ [0,0.2].  
The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0 for all t.  
The initial condition is u(x,0) = x*(1-x).  
The spatial discretization uses Nx = 400 uniform intervals, resulting in 401 grid points.  
The spatial step size is dx = (1 - 0)/400 = 0.0025.  
The time step size is dt = 0.0005, and the total number of time steps is 480 to reach T = 0.2.  
The diffusion coefficient at each grid point is D_i = 0.01 + 0.09*x_i^2.  
Face values of D are computed using arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).  
The spatial discretization of (D(x) u_x)_x is approximated in conservative flux form:  
For interior points i = 1 to 400:  
( (D u_x)_x )_i ≈ (1/dx^2) * [ D_{i+1/2}*(u_{i+1} - u_i) - D_{i-1/2}*(u_i - u_{i-1}) ].  
Time integration is performed using the Implicit Euler method: (I - dt*L) u^{n+1} = u^n, where L is the discrete spatial operator.  
At each time step, the resulting sparse linear system is solved exactly.  
The solution u(x, T=0.2) is computed on the grid x_i = i*dx for i = 0 to 400.  
The output array x contains the 401 grid points from 0 to 1 with spacing dx = 0.0025.  
The output array u contains the numerical solution at t = 0.2, with the same length as x.
