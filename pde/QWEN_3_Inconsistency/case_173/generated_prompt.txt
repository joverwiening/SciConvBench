Solve the 1D reaction-diffusion PDE with logistic reaction term using Strang splitting.
Use the domain x in [0, 1) with periodic boundary conditions and t in [0, 1.0].
Set the parameters: nu = 0.5, rho = 10.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Use the initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points on [0, 1), so dx = 1/512.
Define grid points as x_j = j*dx for j = 0 to 511.
Use a fixed time step dt = 0.001 and perform Nt = 1000 steps to reach T = 1.0 exactly.
Use forward Euler time integration framework with Strang splitting.
For the diffusion half-step (duration dt/2), solve exactly in Fourier space:
  Compute u_hat = FFT(u).
  Define wave numbers k = 2*pi*fftfreq(Nx, d=dx).
  Update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
  Compute u = real(IFFT(u_hat)).
For the reaction full-step (duration dt), solve the logistic ODE exactly at each grid point:
  Update u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).
Structure each full time step as: diffusion (dt/2), reaction (dt), diffusion (dt/2).
At final time T = 1.0, compute the solution u(x, T).

Include in the .npz file: x (1D array of length Nx), u (1D array of length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
