Use the following specification to solve the given PDE.

Solve the 1D reaction-diffusion equation u_t = nu * u_xx + rho * u*(1 - u) on the spatial domain x in [0, 1) with periodic boundary conditions and time domain t in [0, 1.0].
Set the parameters: nu = 2.0, rho = 10.0.
Use the initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points on [0, 1), so dx = 1/Nx and x_j = j*dx for j = 0 to Nx-1.
Use a fixed time step dt = 0.001, with Nt = 1000 steps, so the final time T = 1.0 is reached exactly.
Apply Strang splitting for each full time step:
  First, perform a diffusion half-step of duration dt/2 using exact solution in Fourier space:
    Compute u_hat = FFT(u).
    Define the wave numbers k = 2*pi*fftfreq(Nx, d=dx).
    Update u_hat(k) = u_hat(k) * exp(-nu * k^2 * dt/2).
    Update u = real(IFFT(u_hat)).
  Then, perform a full reaction step of duration dt using the exact solution of the logistic ODE:
    For each grid point, update u = (u * exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
  Finally, perform another diffusion half-step identical to the first.
Enforce periodic boundary conditions via the Fourier method, which naturally respects periodicity.
At final time T = 1.0, compute the solution u(x, T).

  x: 1D array of length Nx with grid points,
  u: 1D array of length Nx with solution values at T,
  scalars: nu, rho, T, dx, dt, Nx, Nt.
Generate a line plot of u(x, T) versus x and save it as "solution_pdebench_reacdiff_nu2_rho10.png".
