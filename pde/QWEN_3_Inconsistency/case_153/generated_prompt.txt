Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 4.0 on the spatial domain x ∈ [0, 1) with periodic boundary conditions and time domain t ∈ [0, 1.0].
Use the initial condition u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points, so dx = 1/512 and x_j = j*dx for j = 0, ..., 511.
Apply Strang splitting for each full time step dt: first a diffusion half-step (dt/2) solved exactly in Fourier space, then a full advection step (dt) using a finite-volume method with Rusanov flux, then another diffusion half-step (dt/2).
For the diffusion step, compute the FFT of u to get u_hat, apply the filter u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then take the real part of the inverse FFT to return to physical space.
For the advection step, solve the inviscid Burgers equation using a finite-volume update with Rusanov flux: for each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing), compute flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left) where f(u) = 0.5*u^2 and alpha = max(|u_left|, |u_right|).
Update each cell j using F_plus = flux between u[j] and u[j+1], F_minus = flux between u[j-1] and u[j], and u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), then set u = u_new after all fluxes are computed.
Set the time step dt0 = CFL*dx / 1.0 with CFL = 0.4, then compute Nt = ceil(1.0 / dt0) and set dt = 1.0 / Nt to ensure the final time is reached exactly.
Compute the solution u(x, T=1.0) on the periodic grid.
Save the file "solution_pdebench_burgers_nu4.npz" containing arrays x (1D, length Nx), u (1D, length Nx), and scalars nu, T=1.0, dx, dt, Nx=512, Nt.
Save a line plot of u(x, T=1.0) as "solution_pdebench_burgers_nu4.png".
