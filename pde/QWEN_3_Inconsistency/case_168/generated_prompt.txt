Solve the 2D Darcy flow elliptic PDE given by -∇ · (a(x,y) ∇u(x,y)) = 1 on the domain (0,1) × (0,1).  
Use the coefficient field a(x,y) = 1 + 0.1 * (0.5 + 0.5 * sin(2 * π * x) * sin(2 * π * y)).  
Apply Dirichlet boundary conditions: u = 0 on all boundaries ∂((0,1) × (0,1)).  
Discretize the domain using a uniform Cartesian grid with N = 128 intervals in each direction, resulting in N+1 = 129 grid points per dimension.  
Set grid spacing dx = dy = 1/128.  
Define grid points as x_i = i * dx for i = 0,...,128 and y_j = j * dy for j = 0,...,128.  
Use second-order finite differences with harmonic averaging for face-centered coefficients.  
For interior nodes (i=1..127, j=1..127), discretize the PDE using the stencil:  
-(1/dx²) * [a(i+1/2,j)*(u(i+1,j)−u(i,j)) − a(i−1/2,j)*(u(i,j)−u(i−1,j)) + a(i,j+1/2)*(u(i,j+1)−u(i,j)) − a(i,j−1/2)*(u(i,j)−u(i,j−1))] = 1.  
Compute face coefficients using harmonic means, e.g., a(i+1/2,j) = 2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)).  
Assemble the sparse linear system Au = b for the interior unknowns (indices i=1..127, j=1..127).  
Solve the system using the conjugate gradient (CG) method with a relative residual tolerance of 1e-10.  
Optionally use a Jacobi preconditioner during CG iteration.  
Compute the solution u on the full (129 × 129) grid, setting boundary values to zero.  
Save the solution in a .npz file named "solution_pdebench_darcy_beta0p1.npz" containing:  
x (1D array of size 129), y (1D array of size 129), u (2D array of shape [129, 129]), beta (scalar 0.1), N (scalar 128), dx (scalar 1/128).  
Generate and save a heatmap or contour plot of u(x,y) as "solution_pdebench_darcy_beta0p1.png".
