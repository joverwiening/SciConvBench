Solve the 1D viscous Burgers equation with periodic boundary conditions using Strang splitting.  
Use the PDE: u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 2.0.  
Set the spatial domain as x ∈ [0, 1) with periodic boundary conditions and use Nx = 512 uniform grid points.  
Define the grid spacing as dx = 1/Nx and grid points x_j = j*dx for j = 0 to Nx-1.  
Set the time domain as t ∈ [0, 1.0].  
Use the initial condition u(x,0) = sin(2*pi*x).  
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.  
Use explicit forward Euler time integration within the Strang splitting framework.  
Perform Strang splitting with three substeps per full time step: diffusion (half-step), advection (full step), diffusion (half-step).  
For the diffusion half-step:  
  Compute the FFT of u to get u_hat.  
  Define the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).  
  Update u_hat(k) = u_hat(k) * exp(-nu * k^2 * (dt/2)).  
  Compute the inverse FFT and take the real part to get the updated u.  
For the advection full-step:  
  Solve the inviscid Burgers equation u_t + ∂_x(0.5*u^2) = 0.  
  Use a finite-volume method with Rusanov (local Lax-Friedrichs) flux.  
  Define the flux function f(u) = 0.5*u^2.  
  For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing):  
    Compute alpha = max(|u_left|, |u_right|).  
    Compute flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).  
  For each cell j:  
    Compute F_plus = flux between u[j] and u[j+1].  
    Compute F_minus = flux between u[j-1] and u[j].  
    Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).  
  Replace u with u_new after completing all flux computations.  
Determine the time step as follows:  
  Use CFL = 0.4 based on an estimated maximum wave speed of 1.0.  
  Compute dt0 = CFL * dx / 1.0.  
  Set Nt = ceil(1.0 / dt0).  
  Set final dt = 1.0 / Nt to ensure exact integration to T = 1.0.  
At final time T = 1.0, compute the solution u(x, T).  
Save the results in a .npz file named "solution_pdebench_burgers_nu2.npz" containing:  
  x (1D array of length Nx),  
  u (1D array of length Nx at final time),  
  scalars nu, T, dx, dt, Nx, Nt.  
Generate a line plot of u(x, T) versus x and save it as "solution_pdebench_burgers_nu2.png".
