Solve the Allen-Cahn equation with the following specifications:

The PDE is u_t = (0.01)^2*u_xx + u - u^3.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,0.5].
Set epsilon = 0.01.
The initial condition is u(x,0) = 0.1*cos(2*pi*x) + 0.05*sin(4*pi*x).
Use Nx=800 grid points with uniform spacing.
Use dt=0.0002 (2500 time steps).
Use 2nd-order central differences for spatial discretization of u_xx.
Implement a semi-implicit time integration scheme: (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
Apply periodic boundary conditions for both u and u_x.
Compute the solution until T=0.5.
Save the solution arrays x and u, along with metadata T, dx, dt in "solution_agent_allen_cahn_01.npz".
Create and save a line plot of u(x,T) as "solution_agent_allen_cahn_01.png".
Print the minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
