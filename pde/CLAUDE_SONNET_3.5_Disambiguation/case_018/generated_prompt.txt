Solve the variable-coefficient diffusion equation with the following specifications:

The PDE is u_t = ∂/∂x(D(x) * u_x) where D(x) = 0.01 + 0.09*x^2.
The spatial domain is x in [0,1].
The time domain is t in [0,0.2].
The initial condition is u(x,0) = x*(1-x).
The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0.
Use Nx=400 uniform intervals for spatial discretization.
Use dt=0.0005 for time stepping (400 steps).
Use conservative 2nd-order spatial discretization in flux form with arithmetic-averaged D at faces.
Use Implicit Euler time integration, solving the sparse linear system each step.
Compute the solution u(x,T) at final time T=0.2.
Save solution data to "solution_agent_diffusion_02.npz" containing arrays x, u and scalars T, dx, dt.
Create and save a line plot of u(x,T) as "solution_agent_diffusion_02.png".
Print the minimum value, maximum value, and discrete L2 norm of u at final time T.
