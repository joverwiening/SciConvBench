Solve the Lotka-Volterra predator-prey ODE system numerically.
The system is dx/dt = alpha*x - beta*x*y and dy/dt = delta*x*y - gamma*y.

The time domain is t in [0.0, 30.0].
Set parameters alpha = 1.5, beta = 1.0, gamma = 3.0, and delta = 1.0.
Use classical 4th-order Runge-Kutta (RK4) time integration with fixed step size dt = 0.01.
Run for exactly Nt = 3000 time steps.
Compute the full state vector at all time points t_n = t0 + n*dt for n=0..Nt.
Save solution_molk_008.npz containing arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns [x, y], and parameter scalars.
Save line plots of each state vs t as solution_molk_008.png.
