The spatial domain is [0,1) with periodic boundary conditions.
The final time is T = 1.0.
Use nu = 0.5 for the diffusion coefficient.
Use rho = 10.0 for the reaction rate.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use Nx = 512 grid points with uniform spacing dx = 1/Nx.
Use Nt = 1000 time steps with fixed dt = 0.001.
Apply Strang splitting for each time step:
First solve diffusion for dt/2 using FFT with k = 2*pi*fftfreq(Nx, d=dx).
Then solve reaction exactly for dt using u = (u*exp(rho*dt))/(1 + u*(exp(rho*dt) - 1)).
Finally solve diffusion again for dt/2.
