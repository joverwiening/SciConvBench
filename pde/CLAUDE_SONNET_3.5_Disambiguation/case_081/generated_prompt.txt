Solve the Poisson equation u_xx + u_yy = sin(pi*x) + cos(2*pi*y) numerically with the following specifications:
The domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions: u=0 on all boundary edges.
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx (i=0..120), y_j=j*dy (j=0..120).
Use the standard 5-point stencil for the Laplacian discretization.
Solve the sparse linear system using a direct solver.
Save solution arrays to solution_agent_poisson_08.npz containing x, y, u, dx, dy.
Save heatmap/contour plot to solution_agent_poisson_08.png.
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy).
