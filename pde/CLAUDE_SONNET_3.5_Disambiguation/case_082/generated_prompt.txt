Solve the wave equation u_tt = u_xx on [0,1] x [0,1.0] with the following specifications:
The wave speed c = 1.0.
Use Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0.
Initial conditions are u(x,0) = sin(pi*x) and u_t(x,0) = 0.
Use Nx=400 intervals (Nx+1 points) with uniform spacing dx = 1/Nx.
Use 2nd-order central differences for spatial discretization of u_xx.
Use leapfrog/Störmer-Verlet scheme for time integration.
Set dt0 = 0.9*dx/c, Nt = ceil(T/dt0), and dt = T/Nt for exact end time.
Initialize using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0.
Compute solution until T = 1.0.
Save solution arrays (x, u) and metadata (T, dx, dt) to solution_agent_wave_01.npz.
Create line plot of u(x,T) and save as solution_agent_wave_01.png.
Print min(u), max(u), and L2 norm at T.
Compute and print max absolute error and L2 error versus exact solution u(x,t)=cos(pi*t)*sin(pi*x).
