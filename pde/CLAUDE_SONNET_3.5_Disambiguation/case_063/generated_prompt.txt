Solve the Laplace equation u_xx + u_yy = 0 on [0,1] x [0,1] with the following specifications:

The domain is discretized using Nx=Ny=100 intervals with dx=dy=1/100.
Grid points are located at x_i=i*dx (i=0..100) and y_j=j*dy (j=0..100).
Use the standard 5-point stencil for the Laplacian operator.
Apply Dirichlet boundary conditions: u(x,0)=0, u(x,1)=sin(pi*x), u(0,y)=0, u(1,y)=0.
Solve the resulting sparse linear system using a direct solver.
The exact solution for verification is u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
Save the solution arrays (x, y, u) and grid spacings (dx, dy) to solution_agent_laplace_07.npz.
Create and save a heatmap/contour plot of the solution as solution_agent_laplace_07.png.
Print the solution minimum, maximum, and discrete L2 norm.
Compute and print the maximum absolute error and L2 error against the exact solution.
