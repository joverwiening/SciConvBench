The numerical solution should be implemented in Python with the following specifications:

Use Python with NumPy and Matplotlib libraries.
Create a uniform periodic grid with Nx=1000 points on [0,1).
Set dx = 1/Nx.
Set dt0 = 0.9*dx/0.5 based on the CFL condition with |a|=0.5.
Set Nt = ceil(1.0/dt0) and then dt = 1.0/Nt to hit T=1.0 exactly.
Initialize u(x,0) = exp(-100*(x-0.3)**2) on the grid points.
Use 1st-order upwind scheme with right-biased stencil due to a=-0.5.
Apply periodic boundary conditions when accessing grid points.
Advance solution using Forward Euler time stepping until T=1.0.
Compute and print min(u), max(u), and sqrt(sum(u^2)*dx) at T=1.0.
Save solution data to 'solution_agent_advection_02.npz' containing arrays x, u, and scalars T, dx, dt.
