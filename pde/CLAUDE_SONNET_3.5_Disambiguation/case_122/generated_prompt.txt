Solve a 1D linear reaction-diffusion PDE with periodic boundary conditions.
The PDE is u_t = 0.01*u_xx - 1.0*u.
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 0.5].
Use Nx = 256 grid points with uniform spacing dx = 1/256.
The initial condition is u(x,0) = sin(2*pi*x).
The exact solution is u(x,t) = exp(-t) * exp(-0.01*(2*pi)^2*t) * sin(2*pi*x).
Compute the solution u(x,T) at T = 0.5.
Save the solution arrays and parameters in "solution_molk_021.npz".
Create a line plot of u(x,T) and save as "solution_molk_021.png".
Print the minimum, maximum, mean, and L2 norm of u at T = 0.5.
Compute and print the maximum absolute error and L2 error compared to the exact solution.
