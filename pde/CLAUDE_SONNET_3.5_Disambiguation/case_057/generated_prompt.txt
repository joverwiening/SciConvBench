Solve the Laplace equation numerically with the following specification:

The PDE is u_xx + u_yy = 0 on the domain [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals (101x101 points).
Set dx=dy=1/100.
Grid points are x_i=i*dx (i=0..100), y_j=j*dy (j=0..100).
Apply Dirichlet boundary conditions on all edges using u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
Use the standard 5-point stencil for spatial discretization of the Laplacian.
Solve the resulting sparse linear system using a direct solver.
Save solution arrays (x, y, u) and metadata (dx, dy) to solution_agent_laplace_01.npz.
Save a heatmap/contour plot of the solution to solution_agent_laplace_01.png.
Print minimum and maximum values of u.
Print the discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compute and print the maximum absolute error versus the exact solution.
Compute and print the L2 error versus the exact solution.
