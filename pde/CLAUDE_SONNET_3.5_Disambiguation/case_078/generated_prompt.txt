Solve the Poisson equation u_xx + u_yy = -2*pi^2*cos(pi*x)*cos(pi*y) numerically.
The domain is [0,1] x [0,1].
Apply Dirichlet boundary conditions u(x,y) = cos(pi*x)*cos(pi*y) on all four edges.
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Set dx=dy=1/120.
Generate grid points as x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.
Use the standard 5-point stencil for spatial discretization of the Laplacian.
Solve the resulting sparse linear system using a direct solver.
The exact solution is u(x,y) = cos(pi*x)*cos(pi*y).
Save the solution arrays in solution_agent_poisson_05.npz.
