Solve the Poisson equation numerically with the following specifications:

The PDE is u_xx + u_yy = -2*pi^2*sin(pi*x)*sin(pi*y).
The domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions: u=0 on all four edges.
The exact solution is u(x,y) = sin(pi*x)*sin(pi*y).
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx (i=0..120), y_j=j*dy (j=0..120).
Discretize using the standard 5-point stencil for the Laplacian.
Solve the sparse linear system using a direct solver.
Save solution arrays to solution_agent_poisson_01.npz containing x, y, u, dx, dy.
Save heatmap/contour plot to solution_agent_poisson_01.png.
Print minimum, maximum, and L2 norm of the solution.
Print maximum absolute error and L2 error versus the exact solution.
