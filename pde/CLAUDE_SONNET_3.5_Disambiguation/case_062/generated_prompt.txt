Solve the Laplace equation u_xx + u_yy = 0 on [0,1] x [0,1] with the following specifications:

The domain is [0,1] x [0,1] with Nx=Ny=100 intervals (101x101 grid points).
Use uniform grid spacing dx=dy=1/100.
Grid points are located at x_i=i*dx (i=0..100), y_j=j*dy (j=0..100).
Apply Dirichlet boundary conditions u(x,y)=x^2 - y^2 on all boundaries.
Use standard 5-point stencil discretization for the Laplacian operator.
Solve the resulting sparse linear system using a direct sparse solver.
Save solution arrays to solution_agent_laplace_06.npz containing x, y, u, dx, dy.
Generate and save a heatmap/contour plot as solution_agent_laplace_06.png.
Print minimum, maximum, and L2 norm of the solution.
Compute and print maximum absolute error and L2 error against exact solution x^2 - y^2.
The 2D solution array u should have shape (Ny+1, Nx+1) with u[j,i] = u(x[i], y[j]).
