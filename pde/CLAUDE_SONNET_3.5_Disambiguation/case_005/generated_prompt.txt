Solve the 2D advection equation with the following specifications:

The PDE is u_t + (-0.7)*u_x + (1.2)*u_y = 0.
The domain is (x,y) in [0,1) x [0,1) with t in [0,0.5].
Use periodic boundary conditions in both x and y directions.
The advection coefficients are a = -0.7 and b = 1.2.
The initial condition is u(x,y,0) = exp(-80*((x-0.2)^2 + (y-0.6)^2)).
Use Nx = Ny = 256 grid points with uniform spacing dx = dy = 1/256.
Use upwind differencing with right-biased stencil in x (since a < 0) and left-biased stencil in y (since b > 0).
Use Forward Euler time integration with dt satisfying CFL condition |a|*dt/dx + |b|*dt/dy ≤ 0.9.
Set dt0 = 0.9 / (|a|/dx + |b|/dy), Nt = ceil(T/dt0), and dt = T/Nt.
Compute the solution u(x,y,T) at final time T = 0.5.
Save solution data to solution_agent_advection_05.npz containing arrays x, y, u and scalars T, dx, dy, dt.
Create and save a heatmap/contour plot of the final solution as solution_agent_advection_05.png.
Print the minimum value, maximum value, and discrete L2 norm of the solution at time T.
