The numerical solution shall be computed with these specifications:
The spatial domain is [-1, 1] with Nx = 400 uniform finite-volume cells.
The cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx = 0.005.
The simulation runs from t = 0 to T = 0.5.
Use CFL = 0.5 for stability with the SSP-RK2 time integration scheme.
Store all numerical values in float64 format for maximum precision.
Initial conditions are rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Use periodic boundary conditions by wrapping array indices.
Evolve the conservative variables U = [rho, m, E] using the Rusanov flux for convection terms.
Compute viscous terms using centered differences and interface averaging.
Use the combined time step restriction from convective and viscous terms.
Save solution arrays (x, rho, v, p) and parameters (Gamma, eta, zeta, T, dx, CFL) to NPZ file.
Generate and save plots of the solution variables versus x at the final time.
Print minimum/maximum density and pressure, and mean density for solution verification.
