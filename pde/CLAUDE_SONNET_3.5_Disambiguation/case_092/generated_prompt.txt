Solve the wave equation PDE numerically with the following specifications:
The PDE is u_tt = (1.0)^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t).
The domain is (x,y) in [0,1] x [0,1] and t in [0,1.0].
Use Dirichlet boundary conditions with u=0 on all boundaries.
Initial conditions are u(x,y,0)=0 and u_t(x,y,0)=0.
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Use the 5-point Laplacian stencil for spatial discretization.
Use 2nd-order central difference in time for u_tt.
Set dx=dy=1/120.
Calculate dt0 = 0.9 / (sqrt(1/dx^2 + 1/dy^2)) using c=1.0.
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit T=1.0 exactly.
Initialize the first timestep using Taylor start with the initial velocity.
Apply Dirichlet boundary conditions at each timestep.
Save solution at T=1.0 to "solution_agent_wave_11.npz" with arrays x, y, u and scalars T, dx, dy, dt.
