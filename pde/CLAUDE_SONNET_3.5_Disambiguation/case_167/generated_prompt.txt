Solve the 2D Darcy flow equation with variable coefficient on unit square domain.
The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 where a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) with beta = 0.01.
Use N=128 intervals (129x129 grid points) with uniform spacing dx = dy = 1/N.
Grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Apply Dirichlet boundary conditions u = 0 on all boundaries.
Use 2nd-order finite differences with harmonic averaging for face coefficients.
Solve the interior system Au=b using conjugate gradient with relative residual tolerance 1e-10.
Use zero initial guess for CG solver.
Save solution arrays to "solution_pdebench_darcy_beta0p01.npz" containing x, y, u, beta, N, dx.
Save solution plot to "solution_pdebench_darcy_beta0p01.png" as heatmap/contour.
Print min(u), max(u), and relative residual norm ||Au-b||_2 / ||b||_2.
