Solve the 1D wave equation numerically with the following specifications:
Use Python with NumPy and Matplotlib for implementation.
The PDE is u_tt = 4*u_xx on domain x in [0,1], t in [0,0.5].
Use Nx=400 intervals giving Nx+1 grid points with dx=1/400.
Use 2nd-order central differences in space for u_xx.
Use leapfrog/Störmer-Verlet time integration.
Set wave speed c=2.0.
Calculate dt0 = 0.9*dx/c, then Nt = ceil(0.5/dt0), then dt = 0.5/Nt.
Apply Dirichlet boundary conditions u(0,t)=u(1,t)=0.
Use initial conditions u(x,0)=sin(pi*x) and u_t(x,0)=0.
Initialize first time step using Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Compute solution until T=0.5.
Save solution arrays (x,u) and metadata (T,dx,dt) to solution_agent_wave_12.npz.
Create and save line plot of u(x,T) to solution_agent_wave_12.png.
