The numerical solution for Klein-Gordon equation should be implemented with these specifications:

Use a uniform grid with Nx=400 intervals (401 points) on x in [0,1].
Set dx = 1/400.
Use c = 1.0 (wave speed coefficient).
Use m = 0.5 (mass term coefficient).
Set dt0 = 0.9*dx/c.
Set Nt = ceil(1.0/dt0) and dt = 1.0/Nt for exact end time.
Use 2nd-order central differences in space for u_xx.
Use leapfrog time integration for u_tt with m^2*u term handled explicitly.
Implement zero Neumann boundary conditions using ghost points with mirrored values.
Initialize using Taylor series start from u(x,0)=cos(pi*x) and u_t(x,0)=0.
Compute solution until T=1.0.
Save x and u arrays plus metadata (T, dx, dt) to solution_agent_kg_03.npz.
Create and save line plot of u(x,T) to solution_agent_kg_03.png.
Print min(u), max(u), and L2 norm at T=1.0.
Compute and print max absolute error and L2 error against exact solution.
