Solve 2D Darcy flow PDE -∇·(a(x,y)∇u) = 1 with the following specifications:
The coefficient function a(x,y) = 1 + 10.0 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The domain is (x,y) in (0,1) x (0,1).
Dirichlet boundary conditions: u = 0 on all boundaries.
Use N=128 intervals (129x129 grid points) with uniform spacing dx = dy = 1/128.
Grid points are x_i = i*dx for i=0,...,128 and y_j = j*dy for j=0,...,128.
Use 2nd-order finite differences with harmonic averaging of face coefficients.
For interior points, discretize: -(1/dx^2)*[a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1))] = 1.
Face coefficients use harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)).
Solve the sparse linear system Au=b using conjugate gradient with zero initial guess.
Use relative residual tolerance of 1e-10.
Jacobi preconditioning may be used.
Save solution arrays to "solution_pdebench_darcy_beta10.npz" containing x, y, u, beta, N, and dx.
Save solution plot to "solution_pdebench_darcy_beta10.png".
Print minimum and maximum values of u and the relative residual norm ||Au-b||_2/||b||_2.
