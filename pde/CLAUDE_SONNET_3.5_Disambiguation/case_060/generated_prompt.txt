Create a Python script that:
Uses numpy for array operations and numerical computations.
Uses scipy.sparse for sparse matrix operations and linear system solving.
Uses matplotlib for plotting.
Initialize a uniform grid with Nx=Ny=100 intervals (101x101 points) on [0,1]x[0,1].
Create 1D arrays x and y with x_i=i*dx and y_j=j*dy where dx=dy=1/100.
Construct the 5-point Laplacian stencil matrix for interior points using scipy.sparse.
Set Dirichlet boundary conditions u=y on all boundaries.
Solve the linear system using scipy.sparse.linalg.spsolve.
Reshape the solution into a 2D array u[j,i] representing u(x[i],y[j]).
Save x, y, u, dx, dy to solution_agent_laplace_04.npz using numpy.savez.
Create a heatmap using matplotlib.pyplot.imshow with proper axes labels and colorbar.
Save the plot as solution_agent_laplace_04.png with 300 DPI.
Print min(u), max(u), and sqrt(sum(u^2)*dx*dy).
Compute and print max(abs(u - y_grid)) and sqrt(sum((u - y_grid)^2)*dx*dy) where y_grid is the exact solution y evaluated on the 2D grid.
