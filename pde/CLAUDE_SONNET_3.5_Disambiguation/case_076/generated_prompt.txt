Solve the Poisson equation numerically with the following specifications:

The PDE is u_xx + u_yy = -2*(y*(1-y) + x*(1-x)) on the domain [0,1] x [0,1].
The boundary conditions are Dirichlet on all edges with u(x,y) = x*(1-x)*y*(1-y).
The exact solution is u(x,y) = x*(1-x)*y*(1-y).
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Discretize using the standard 5-point stencil for the Laplacian.
Solve the sparse linear system using a direct solver.
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.
Save solution data to solution_agent_poisson_03.npz with arrays x, y, u and scalars dx, dy.
Save visualization to solution_agent_poisson_03.png as a heatmap/contour plot.
Print minimum, maximum, and L2 norm of the solution.
Compute and print maximum absolute error and L2 error versus the exact solution.
