The numerical solution specification for the 2D Darcy flow problem is:

Set beta = 1.0.
Define coefficient function a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Use N = 128 intervals in each direction, creating a (129 x 129) grid including boundaries.
Set dx = dy = 1/N = 1/128.
Generate grid points x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Set Dirichlet boundary conditions u = 0 on all boundaries.
Use zero initial guess for the conjugate gradient solver.
Discretize the PDE using 2nd-order finite differences with harmonic averaging of coefficients at faces.
Solve the linear system Au=b using conjugate gradient to relative tolerance 1e-10.
Save solution arrays (x, y, u) and parameters (beta, N, dx) to "solution_pdebench_darcy_beta1.npz".
Create and save a heatmap/contour plot of u(x,y) to "solution_pdebench_darcy_beta1.png".
Print the minimum and maximum values of u.
Print the relative residual norm ||Au-b||_2 / ||b||_2 for the interior system.
