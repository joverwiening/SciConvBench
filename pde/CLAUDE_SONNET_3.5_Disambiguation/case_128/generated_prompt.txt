The numerical solution of the 1D nonlinear convection-diffusion PDE requires:

Initialize a uniform periodic grid with Nx=1024 points on [0,1) with x_j = j*dx for j=0,...,Nx-1 where dx=1/Nx.

Set q1=1.0 and q2=0.05 as given parameters.
Compute time step dt using CFL=0.2: dt0 = 0.2*dx/0.25 and dt_diff=0.2*dx^2/(q2/pi).

Use Rusanov flux for the convective term -q1*∂_x((1/3)u^3).
Use 2nd-order central differences for the diffusive term (q2/pi)*u_xx.
Implement SSP-RK2 time integration to advance the solution.
