Solve the Laplace equation u_xx + u_yy = 0 with the following specifications:

The domain is [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals (101x101 points).
Grid spacing is dx=dy=1/100.
Grid points are x_i=i*dx for i=0..100, y_j=j*dy for j=0..100.
Apply Dirichlet boundary conditions: u(x,0)=0, u(x,1)=sin(2*pi*x), u(0,y)=0, u(1,y)=0.
Use standard 5-point stencil discretization for the Laplacian.
Solve the resulting sparse linear system using a direct solver.
The exact solution is u(x,y)=sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi).
Save solution data to solution_agent_laplace_08.npz containing x, y, u arrays and dx, dy scalars.
Create and save a heatmap/contour plot as solution_agent_laplace_08.png.
Print minimum, maximum, and L2 norm of the solution.
Compute and print maximum absolute error and L2 error against the exact solution.
