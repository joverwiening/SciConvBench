  (C) Diffusion half-step (dt/2) solved exactly in Fourier space
Set time step using CFL = 0.4 with estimated max speed 1.0.
Calculate dt0 = CFL*dx/1.0, then Nt = ceil(T/dt0), then dt = T/Nt.
