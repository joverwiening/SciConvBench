The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,1.0].
Use Nx=512 spatial points with dx=1/512.
Use dt=0.001 with Nt=1000 time steps.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use nu=2.0 for the diffusion coefficient.
Use rho=5.0 for the reaction rate.
Solve using Strang splitting with three substeps per time step:
(A) Diffusion half-step (dt/2) solved in Fourier space using exp(-nu*k^2*(dt/2)).
(B) Reaction full-step (dt) solved using u <- (u*exp(rho*dt))/(1 + u*(exp(rho*dt) - 1)).
(C) Repeat diffusion half-step (dt/2).
Save solution arrays x and u, and parameters nu, rho, T, dx, dt, Nx, Nt in solution_pdebench_reacdiff_nu2_rho5.npz.
