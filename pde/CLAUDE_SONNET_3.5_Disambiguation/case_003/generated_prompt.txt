Create a numerical solver for the advection equation with the following specifications:

The PDE is u_t + a(x)*u_x = 0 where a(x) = 1 + 0.5*sin(2*pi*x).
The domain is x in [0,1) and t in [0,0.5].
Use Nx=1200 grid points with uniform spacing dx=1/Nx.
Use periodic boundary conditions.
Set the initial condition u(x,0) = sin(2*pi*x).
Use upwind spatial discretization with left-biased stencil since a(x)>0.
Use Forward Euler time integration.
Set amax=1.5 and compute dt0 = 0.9*dx/amax.
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit T=0.5 exactly.
Compute the solution u(x,T) at final time T=0.5.
Save solution data to "solution_agent_advection_03.npz" containing arrays x, u and scalars T, dx, dt.
Create and save a line plot of u(x,T) as "solution_agent_advection_03.png".
Print the minimum value of u, maximum value of u, and discrete L2 norm sqrt(sum(u^2)*dx) at time T.
