The spatial domain is [0,1) with periodic boundary conditions.
The final time is T = 1.0.
The PDE is the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 0.2.
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx = 512 uniform grid points with dx = 1.0/Nx.
Use Strang splitting with three substeps per time step: diffusion (dt/2), advection (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space using the given formula.
Solve advection steps using finite-volume with Rusanov flux.
Set initial dt0 = CFL*dx/1.0 with CFL = 0.4.
Set Nt = ceil(T/dt0) and adjust dt = T/Nt.
Compute solution u(x,T) on the grid.
Save arrays x, u and parameters nu, T, dx, dt, Nx, Nt to "solution_pdebench_burgers_nu0p2.npz".
Save line plot of u(x,T) to "solution_pdebench_burgers_nu0p2.png".
