Solve the wave equation u_tt = u_xx on [0,1] x [0,1.0] with the following specifications:
The wave speed c = 1.0.
Initial conditions are u0(x) = 0 and v0(x) = sin(pi*x).
Dirichlet boundary conditions u(0,t) = u(1,t) = 0 for all t.
Use Nx = 400 intervals giving Nx+1 spatial grid points with dx = 1/Nx.
Use 2nd-order central differences for spatial discretization u_xx.
Use leapfrog (2nd-order central differences) for time integration.
Set initial dt0 = 0.9*dx/c, then Nt = ceil(T/dt0), and final dt = T/Nt.
Initialize first time step using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0.
Enforce Dirichlet boundary conditions at every time step.
Compute solution until T = 1.0.
Save solution arrays (x, u) and metadata (T, dx, dt) to "solution_agent_wave_04.npz".
Create and save line plot of u(x,T) as "solution_agent_wave_04.png".
Print min(u), max(u), and L2 norm sqrt(sum(u^2)*dx) at final time.
Compare with exact solution u(x,t) = (1/(pi))*sin(pi*t)*sin(pi*x) using max abs error and L2 error.
