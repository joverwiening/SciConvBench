Solve the diffusion PDE u_t = (D(x)*u_x)_x with D(x) = 0.1*(1+x) on [0,1] x [0,0.5].
The initial condition is u(x,0) = sin(pi*x).
The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0.
Use Nx=300 uniform intervals with dx = 1/300.
Use dt=0.001 for time integration from t=0 to t=0.5 (500 steps).
Use implicit Euler time integration: (I - dt*L)u^{n+1} = u^n.
Use the specified conservative 2nd-order spatial discretization with arithmetic-averaged D at faces.
Compute the solution u(x,T=0.5) on the grid points x_i = i*dx for i=0..Nx.
Save the arrays x and u, plus metadata T, dx, dt in solution_agent_diffusion_01.npz.
Create a line plot of u vs x at T=0.5 with appropriate axis labels and title, saved as solution_agent_diffusion_01.png.
