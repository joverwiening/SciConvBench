Solve the Helmholtz equation numerically with the following specifications:

The PDE is u_xx + u_yy + k^2*u = f(x,y) where k = 5.0 and f(x,y) = (k^2 - 2*pi^2) * sin(pi*x) * sin(pi*y).
The domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions u = 0 on all boundaries.
Use Nx = Ny = 120 intervals for spatial discretization.
Use a uniform grid with dx = dy = 1/Nx.
Grid points are x_i = i*dx for i=0..Nx and y_j = j*dy for j=0..Ny.
Discretize using the 5-point Laplacian stencil.
Solve the resulting sparse linear system using a direct solver.
The exact solution is u(x,y) = sin(pi*x)*sin(pi*y).
Save solution data to solution_agent_other_01_helmholtz.npz containing x, y, u arrays and dx, dy scalars.
Save visualization to solution_agent_other_01_helmholtz.png as a heatmap/contour plot.
Print minimum, maximum, and L2 norm of the solution.
Print maximum absolute error and L2 error compared to the exact solution.
