The spatial domain is [0,1) with periodic boundary conditions.
The final time is T = 1.0.
The PDE is the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx.
The viscosity parameter is nu = 0.01.
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx = 512 grid points with uniform spacing dx = 1/Nx.
Use Strang splitting with three substeps: diffusion (dt/2), advection (dt), diffusion (dt/2).
The diffusion steps are solved exactly in Fourier space using FFT.
The advection step uses finite-volume with Rusanov flux.
Set initial dt0 = CFL*dx/1.0 with CFL = 0.4.
Set Nt = ceil(T/dt0) and adjust dt = T/Nt.
Save solution arrays and parameters to "solution_pdebench_burgers_nu0p01.npz".
Save solution plot to "solution_pdebench_burgers_nu0p01.png".
Print min(u), max(u), mean(u), and L2 norm at final time T.
