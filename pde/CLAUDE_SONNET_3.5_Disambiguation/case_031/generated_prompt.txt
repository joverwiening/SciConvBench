Solve the heat equation u_t = 0.5 * u_xx on [0,1] x [0,0.2] with the following specifications:
The initial condition is u(x,0) = sin(2*pi*x).
The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0.
Use a uniform spatial grid with Nx=200 intervals (201 points including boundaries).
Use time step dt=0.0005 for 400 time steps.
Use 2nd-order central differences for spatial discretization of u_xx.
Use Crank-Nicolson method for time integration.
The exact solution is u(x,t) = exp(-0.5*(2*pi)^2*t) * sin(2*pi*x).
Compute the solution up to T=0.2.
Save the solution arrays (x, u) and metadata (T, dx, dt) in "solution_agent_heat_02.npz".
Create and save a line plot of u(x,T) as "solution_agent_heat_02.png".
Print the minimum, maximum, and discrete L2 norm of the solution at T=0.2.
Compute and print the maximum absolute error and L2 error compared to the exact solution.
