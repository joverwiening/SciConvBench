Solve the biharmonic equation numerically with the following specifications:

The PDE is ∇^4 u = f(x,y) where f(x,y) = 4*pi^4*sin(pi*x)*sin(pi*y).
The domain is (x,y) in [0,1] x [0,1].
Simply-supported boundary conditions: u=0 and Δu=0 on all boundaries.
The exact solution is u(x,y) = sin(pi*x)*sin(pi*y).
Use Nx=Ny=120 intervals giving a (121 x 121) point grid including boundaries.
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx (i=0..120), y_j=j*dy (j=0..120).
Solve using the split method: v = Δu, then solve two Poisson problems sequentially.
Use the standard 5-point Laplacian stencil for both Poisson solves.
Use sparse direct solver for both Poisson problems.
Save solution arrays to solution_agent_other_05_biharmonic.npz containing x, y, u, dx, dy.
Create and save heatmap/contour plot to solution_agent_other_05_biharmonic.png.
Print min(u), max(u), and L2 norm sqrt(sum(u^2)*dx*dy).
Compute and print max absolute error and L2 error versus the exact solution.
