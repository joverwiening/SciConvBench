Use Nx=512 grid points for spatial discretization.

Compute the solution u(x,t) up to T=1.0.
Save the solution arrays x and u, along with scalars T, dx, Nx, q1=0.01, q2=5.0 in "solution_molk_020.npz".
Create and save a line plot of u vs x at T=1.0 as "solution_molk_020.png".
