The spatial domain is [0,1) with periodic boundary conditions.
The final time is T = 1.0.
The PDE is the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 0.4.
Use Nx = 512 grid points with uniform spacing dx = 1.0/Nx.
Initial condition is u(x,0) = sin(2*pi*x).
Use Strang splitting with three substeps per time step: diffusion (dt/2), advection (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space using the given exponential update.
Solve advection step using finite-volume with Rusanov flux.
Set time step using CFL = 0.4 based on max speed 1.0: dt0 = CFL*dx/1.0.
Choose Nt = ceil(T/dt0) and reset dt = T/Nt.
Save solution arrays and parameters to "solution_pdebench_burgers_nu0p4.npz".
Save line plot of final solution to "solution_pdebench_burgers_nu0p4.png".
Print min(u), max(u), mean(u), and L2 norm at final time T.
