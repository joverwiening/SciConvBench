Solve the scalar ODE du/dt = a*sin(2*pi*t)*u with the following specifications:

The time domain is [0.0, 5.0].
The initial condition is u(0.0) = 1.0.
The parameter a = 1.3.
Use classical 4th-order Runge-Kutta (RK4) time integration.
Use fixed time step dt = 0.001 with Nt = 5000 steps.
The exact solution is u(t) = exp(a*(1 - cos(2*pi*t))/(2*pi)) for u(0) = 1.0.
Compute u(t) at all time points t_n = n*dt for n=0..Nt.
Save solution_molk_000.npz containing arrays t, u, and parameter scalars.
Save a line plot of u(t) vs t as solution_molk_000.png.
Print the final value u(T), minimum u, and maximum u over the time grid.
Compute and print the maximum absolute error and L2 error against the exact solution.
