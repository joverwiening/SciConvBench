The numerical solution shall be implemented in Python with the following specifications:

The program shall solve the 2D wave equation u_tt = (1.0)^2 * (u_xx + u_yy) on domain [0,1] x [0,1] for t in [0,0.5].
The program shall use NumPy arrays for efficient numerical computations.
The spatial grid shall use Nx=Ny=160 intervals creating a (161 x 161) point grid.
The spatial discretization shall use the 5-point Laplacian stencil for the spatial derivatives.
The time integration shall use 2nd-order central difference for u_tt.
The time step dt shall be computed as: dt0 = 0.9 / (sqrt(1/dx^2 + 1/dy^2)), Nt = ceil(0.5/dt0), dt = 0.5/Nt.
The initial condition shall be u(x,y,0) = sin(pi*x)*sin(2*pi*y) with u_t(x,y,0) = 0.
The first time step shall use Taylor series initialization with the given initial velocity.
Dirichlet boundary conditions (u=0) shall be enforced on all boundaries at each time step.
The program shall compute the solution until T=0.5.
The program shall save the solution in "solution_agent_wave_15.npz" containing arrays x, y, u and scalars T, dx, dy, dt.
The program shall create a heatmap/contour plot saved as "solution_agent_wave_15.png" using matplotlib.
The program shall compute and print the minimum, maximum, and L2 norm of the solution at T=0.5.
The program shall compute and print the maximum absolute error and L2 error compared to the exact solution u(x,y,t)=cos(pi*sqrt(5)*t)*sin(pi*x)*sin(2*pi*y).
The program shall use standard Python scientific libraries (NumPy for arrays, SciPy if needed, Matplotlib for plotting).
