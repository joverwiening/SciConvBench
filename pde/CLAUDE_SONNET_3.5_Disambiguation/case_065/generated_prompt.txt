Solve the Laplace equation u_xx + u_yy = 0 on [0,1] x [0,1] with the following specifications:

The domain is a unit square [0,1] x [0,1].
Use Nx = Ny = 100 intervals, giving 101x101 grid points.
Grid spacing is dx = dy = 1/100.
Grid points are x_i = i*dx for i=0..100, y_j = j*dy for j=0..100.
Apply Dirichlet boundary conditions: u(x,0) = 0, u(x,1) = 1, u(0,y) = 0, u(1,y) = 0.
Use standard 5-point stencil for spatial discretization of the Laplace operator.
Solve the resulting sparse linear system using a direct sparse solver.
Save solution data in solution_agent_laplace_09.npz containing arrays x, y, u and scalars dx, dy.
Save visualization as solution_agent_laplace_09.png showing a heatmap/contour plot.
Print minimum value, maximum value, and discrete L2 norm of the solution.
The solution array u should have shape (101,101) with u[j,i] = u(x[i], y[j]).
