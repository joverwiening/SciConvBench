Solve the 1D Reaction-Diffusion equation with logistic reaction term using Strang splitting.
The spatial domain is [0, 1) with periodic boundary conditions.
Use Nx=512 grid points with uniform spacing dx=1/512.
The time domain is [0, 1] with Nt=1000 steps and dt=0.001.
Set diffusion coefficient nu=1.0 and reaction rate rho=5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use Strang splitting with three substeps per time step:
  1. Solve diffusion for dt/2 in Fourier space using exp(-nu*k^2*(dt/2)).
  2. Solve reaction ODE for dt using exact solution u = (u*exp(rho*dt))/(1 + u*(exp(rho*dt) - 1)).
  3. Solve diffusion for dt/2 again.
Compute solution until T=1.0.
Save solution arrays (x, u) and parameters (nu, rho, T, dx, dt, Nx, Nt) to solution_pdebench_reacdiff_nu1_rho5.npz.
Create and save line plot of u(x,T) to solution_pdebench_reacdiff_nu1_rho5.png.
Print min(u), max(u), mean(u), and L2 norm sqrt(sum(u^2)*dx) at final time.
