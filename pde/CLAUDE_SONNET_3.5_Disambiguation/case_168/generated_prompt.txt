Solve 2D Darcy flow PDE -∇·(a(x,y)∇u) = 1 with the following specifications:
The domain is (x,y) in (0,1) x (0,1).
The coefficient function a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) with beta = 0.1.
Dirichlet boundary conditions: u = 0 on all boundaries.
Use N=128 intervals (129 points) in each direction with uniform spacing dx = dy = 1/N.
Grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Use 2nd-order finite differences with harmonic averaging of face coefficients.
Face coefficients are computed using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)).
Solve the linear system Au=b using conjugate gradient with relative residual tolerance 1e-10.
Use zero initial guess for CG solver.
Optional Jacobi preconditioner may be used.
Save solution arrays to "solution_pdebench_darcy_beta0p1.npz" containing x, y, u, beta, N, and dx.
Save solution visualization to "solution_pdebench_darcy_beta0p1.png" as a heatmap/contour plot.
Print minimum and maximum values of u and the relative residual norm ||Au-b||_2/||b||_2.
