Solve the Allen-Cahn equation with the following specifications:

The PDE is u_t = (0.02)^2*u_xx + u - u^3 on domain x in [0,1], t in [0,0.2].
The initial condition is u(x,0) = tanh((0.5 - x)/(sqrt(2)*0.02)).
Apply Dirichlet boundary conditions: u(0,t) = 1 and u(1,t) = -1.
Use epsilon = 0.02 as the parameter value.
Use Nx=1200 uniform intervals (1201 points) with second-order central differences for spatial discretization.
Use dt=0.0001 (2000 time steps) with a semi-implicit time integration scheme.
The semi-implicit scheme is (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
Solve the resulting linear system at each time step.
Enforce boundary conditions by setting boundary nodes to prescribed values after each time step.
Compute the solution until final time T=0.2.
Save the solution arrays (x and u) and metadata (T, dx, dt) in solution_agent_allen_cahn_02.npz.
Create and save a line plot of u(x,T) as solution_agent_allen_cahn_02.png.
Print the minimum value of u, maximum value of u, and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
