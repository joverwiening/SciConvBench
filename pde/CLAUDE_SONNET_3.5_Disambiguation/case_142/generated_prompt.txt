The PDE is u_t + 7.0 * u_x = 0.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution is u(x,t) = u0((x - 7.0*t) mod 1).
Use Nx=512 grid points with uniform spacing dx=1.0/Nx.
Use 1st-order upwind finite difference for spatial discretization.

Set CFL=0.5 to determine dt = CFL * dx / abs(beta).
The final time is T=2.0.
Calculate Nt = ceil(T/dt) and reset dt = T/Nt.
Compute solution u(x,T) on the grid points.
Save arrays x, u and scalars beta, T, dx, dt, Nx, Nt to "solution_pdebench_advection_beta7.npz".
