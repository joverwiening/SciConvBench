Solve the scalar ODE du/dt = a*exp(-t) + b with the following specifications:
The time domain is [0.0, 5.0].
The parameters are a = 2.0 and b = -0.5.
The initial condition is u(0.0) = 0.0.
Use classical 4th-order Runge-Kutta (RK4) time integration.
Use fixed time step dt = 0.001 with Nt = 5000 steps.
Compute u(t) at all time points t_n = n*dt for n = 0..Nt.
Save arrays t and u, and parameter scalars to "solution_molk_001.npz".
Save a line plot of u(t) vs t as "solution_molk_001.png".
Print the final value u(T), minimum u, and maximum u over the time grid.
Compute and print the maximum absolute error and L2 error against the exact solution u(t) = a*(1 - exp(-t)) + b*t.
