Implement zero Neumann boundary conditions using ghost points.
Use 2nd-order central differences for spatial derivatives.
Compute solution until T=1.0.
Save solution arrays (x, u) and metadata (T, dx, dt) to solution_agent_wave_06.npz.
Create and save line plot of u(x,T) to solution_agent_wave_06.png.
