Solve the Poisson equation u_xx + u_yy = f(x,y) numerically with the following specifications:
The source term is f(x,y) = 100*exp(-200*((x-0.5)^2 + (y-0.5)^2)).
The domain is [0,1] x [0,1].
Apply Dirichlet boundary conditions u=0 on all four edges.
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.
Discretize using the standard 5-point stencil for the Laplacian.
Solve the sparse linear system using a direct solver.
Save solution data to solution_agent_poisson_07.npz containing x, y, u arrays and dx, dy scalars.
Create and save a heatmap/contour plot as solution_agent_poisson_07.png.
Print the minimum value, maximum value, and discrete L2 norm of the solution.
