Solve the 2D Darcy flow equation with the following specifications:
The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the unit square domain (0,1) x (0,1).
The coefficient function a(x,y) = 1 + 100.0 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Use Dirichlet boundary conditions u = 0 on all boundaries.
Use N=128 intervals (129 points) in each direction with uniform spacing dx = dy = 1/128.
Grid points are x_i = i*dx for i=0,...,128 and y_j = j*dy for j=0,...,128.
Use 2nd-order finite differences with harmonic averaging of face coefficients.
For interior points, discretize using the given stencil with harmonic means for face coefficients.
Solve the linear system Au=b using conjugate gradient with relative residual tolerance 1e-10.
Use zero initial guess for the CG solver.
Use Jacobi preconditioning if desired for better convergence.
Save solution arrays to "solution_pdebench_darcy_beta100.npz" containing x, y, u, beta, N, and dx.
Create and save a heatmap/contour plot as "solution_pdebench_darcy_beta100.png".
Print the minimum and maximum values of u and the relative residual norm ||Au-b||_2 / ||b||_2.
