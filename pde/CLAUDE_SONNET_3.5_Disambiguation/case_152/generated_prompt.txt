The spatial domain is [0,1) with periodic boundary conditions.
The final time is T = 1.0.
The PDE is the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx.
Set nu = 0.002.
Use Nx = 512 grid points with uniform spacing dx = 1.0/Nx.
Set grid points x_i = i*dx for i=0..Nx-1.
Set initial condition u(x,0) = sin(2*pi*x).
Use Strang splitting with three substeps per time step: diffusion (dt/2), advection (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space using the given exponential integration formula.
Solve advection step using finite-volume update with Rusanov flux as specified.
Set time step using CFL = 0.4 with estimated max speed 1.0: dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and adjust dt = T/Nt.
Save solution arrays and parameters to "solution_pdebench_burgers_nu2em3.npz".
Save line plot of final solution to "solution_pdebench_burgers_nu2em3.png".
