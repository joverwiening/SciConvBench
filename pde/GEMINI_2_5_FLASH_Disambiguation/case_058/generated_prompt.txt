The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is a square (x,y) in [0,1] x [0,1].
The numerical method is a 5-point stencil (2nd-order accurate) for spatial discretization on a uniform grid.
The grid uses Nx=Ny=100 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points.
The grid spacing is dx=dy=1/Nx.
Grid points are x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Dirichlet boundary conditions are applied on all four edges of the square.
The boundary values for u(x,y) are set to match the exact harmonic function u(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi).
The resulting sparse linear system for interior nodes is solved using a sparse direct solver.
The steady-state solution u(x,y) is computed on the 2D grid.
The solution is saved to "solution_agent_laplace_02.npz" as a NumPy archive.
The archive contains 1D arrays x, y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx, dy.
A heatmap or contour plot of u(x,y) is saved as "solution_agent_laplace_02.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) are printed to standard output.
The maximum absolute error and L2 error against the reference solution u(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi) (evaluated on the same grid) are computed and printed to standard output.
