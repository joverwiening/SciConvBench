The PDE to solve is u_t = 0.1 * u_xx + sin(pi*x)*cos(2*pi*t).
The spatial domain is x in [0, 1].
The temporal domain is t in [0, 1.0].
The initial condition is u(x,0) = 0.
The Dirichlet boundary conditions are u(0,t)=0 and u(1,t)=0.
The spatial discretization uses a uniform grid on [0,1] with Nx=300 intervals, resulting in Nx+1 grid points.
The spatial step size is dx = 1/Nx.
Second-order central differences are used for u_xx in the interior.
The time integration uses the Crank–Nicolson method for diffusion terms.
The time step size is dt=0.001, resulting in 1000 time steps.
The source term sin(pi*x)*cos(2*pi*t) is included by averaging its values at time levels n and n+1.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step.
The solution u(x, T=1.0) is computed on the specified grid.
The solution is saved to "solution_agent_heat_08.npz" as a NumPy archive containing arrays x (1D), u (1D, same length as x), and scalar metadata T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_heat_08.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0 are printed to the console.
