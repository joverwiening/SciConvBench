The task is to numerically solve the 2D time-dependent diffusion equation u_t = ∇·( D(x,y) ∇u ).
The unknown field is u(x,y,t).
The spatial domain is [0,1] x [0,1].
The temporal domain is [0,0.1].
The diffusion coefficient is D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The initial condition is u(x,y,0) = sin(pi*x)*sin(pi*y).
The boundary conditions are Dirichlet u=0 on all boundary edges.
Use a uniform grid with Nx=80 and Ny=80 intervals, resulting in Nx+1 and Ny+1 grid points including endpoints.
The spatial discretization for ∇·(D∇u) must be a conservative 2nd-order flux form.
For interior nodes (i=1..Nx-1, j=1..Ny-1), the discrete operator is (∇·(D∇u))_{i,j} ≈ (1/dx^2)[ D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}(u_{i,j}-u_{i-1,j}) ] + (1/dy^2)[ D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}(u_{i,j}-u_{i,j-1}) ].
Arithmetic face averages must be used for the diffusion coefficient: D_{i+1/2,j}=0.5*(D_{i,j}+D_{i+1,j}) and D_{i,j+1/2}=0.5*(D_{i,j}+D_{i,j+1}).
The time integration method must be Implicit Euler: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
Solve the sparse linear system at each time step.
Use a time step dt=0.0005, for a total of 200 steps to reach T=0.1.
Compute the solution u(x,y,T=0.1) on the 2D grid.
Save the solution to a file named "solution_agent_diffusion_04.npz".
The .npz file must contain the 1D arrays x and y, and the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T).
The .npz file must also contain the scalar metadata T, dx, dy, and dt.
Save a heatmap or contour plot of u(x,y,T) as "solution_agent_diffusion_04.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
