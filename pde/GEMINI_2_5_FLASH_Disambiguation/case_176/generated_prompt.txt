The task ID is pdebench_reacdiff_nu10_rho1.
The PDE category is 1D Reaction–Diffusion with logistic reaction and periodic boundary conditions.
The unknown field is u(x,t).
The PDE to solve numerically is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 10.0.
The parameter rho is 1.0.
The boundary condition is periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
No closed-form reference solution is required.
The numerical method requires a uniform periodic spatial grid with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx = (1-0)/Nx = 1/512.
The time grid uses a fixed dt=0.001.
The number of time steps Nt is T/dt = 1.0/0.001 = 1000.
The numerical method is Strang splitting for each full time step dt.
Each Strang splitting step consists of three parts:
(A) A diffusion half-step of duration dt/2, solved exactly in Fourier space.
For this, compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) to u_hat(k) * exp(-nu*k^2*(dt/2)).
Then compute u = IFFT(u_hat) and take the real part.
(B) A reaction full-step of duration dt, solved exactly pointwise for the logistic ODE du/dt = rho * u*(1 - u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Another diffusion half-step, identical to part (A).
The output requirement is to compute u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_reacdiff_nu10_rho1.npz".
The .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho1.png".
Report by printing min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
