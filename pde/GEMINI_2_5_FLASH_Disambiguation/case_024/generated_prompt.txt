Solve the one-dimensional Diffusion-Reaction Partial Differential Equation u_t = 0.05*u_xx + 2.0*u.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.3].
The diffusion coefficient D is 0.05 and the reaction coefficient lambda is 2.0.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0 for all t.
The initial condition is u(x,0)=sin(2*pi*x).
The numerical method will use 2nd-order central differences for the spatial discretization of the diffusion term on a uniform grid.
The time integration will be a 1st-order deterministic IMEX scheme, with the diffusion term treated implicitly (Backward Euler) and the reaction term treated explicitly (Forward Euler).
At each time step, solve (I - dt*D*L) u^(n+1) = u^n + dt * R(u^n), where L is the discrete Laplacian and R(u) is the reaction term.
Use a sparse direct solver for the linear system at each time step.
The grid will have Nx=250 spatial intervals, resulting in Nx+1 grid points.
The time step will be dt=0.0005, for a total of 600 time steps.
Compute the numerical solution u(x, T=0.3) on the specified grid.
Save the solution to a file named "solution_agent_diffusion_reaction_02.npz".
This NPZ file must contain the 1D array x, the 1D array u (solution at T=0.3), and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_diffusion_reaction_02.png".
Print the minimum value of u(x,T), the maximum value of u(x,T), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.3.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution u(x,t)=exp((2.0 - 0.05*(2*pi)^2)*t)*sin(2*pi*x) at T=0.3, evaluated on the same spatial grid.
