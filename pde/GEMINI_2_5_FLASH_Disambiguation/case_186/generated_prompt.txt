The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 2.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1.
The spatial step size dx is 1/512.
The time grid uses a fixed dt=0.001.
The total number of time steps Nt is 1000.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
(A) A diffusion half-step of duration dt/2, solved exactly in Fourier space.
For this step, compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Transform back to physical space: u = IFFT(u_hat), taking the real part.
(B) A reaction full-step of duration dt, solved exactly pointwise for the logistic ODE du/dt = rho * u * (1 - u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Another diffusion half-step of duration dt/2, identical to step (A).
Compute u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_reacdiff_nu2_rho2.npz".
The .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu2_rho2.png".
