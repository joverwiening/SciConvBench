The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 1.0].
The parameters are nu = 5.0 and rho = 5.0.
The boundary condition is periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A uniform periodic spatial grid will be used with Nx = 512 points on [0, 1).
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx = (1-0)/Nx = 1/512.
A fixed time step dt = 0.001 will be used.
The total number of time steps is Nt = 1000, calculated as T/dt = 1.0/0.001, to reach T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
First, a diffusion half-step of duration dt/2 is solved exactly in Fourier space.
This involves computing the Fast Fourier Transform (FFT) of u to get u_hat(k).
The wave numbers k are defined as k = 2*pi*fftfreq(Nx, d=dx).
u_hat(k) is then updated using the formula u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, the Inverse Fast Fourier Transform (IFFT) of u_hat is computed to get u, taking only the real part.
Second, a reaction full-step of duration dt is solved exactly pointwise for the logistic ODE du/dt = rho * u*(1 - u).
The exact update for each grid point is u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, another diffusion half-step of duration dt/2 is performed, identical to the first diffusion half-step.
The final solution u(x,T=1.0) on the periodic grid must be computed.
The computed solution will be saved to a file named "solution_pdebench_reacdiff_nu5_rho5.npz".
This NPZ file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) will be saved as "solution_pdebench_reacdiff_nu5_rho5.png".
The minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T will be printed to the console.
