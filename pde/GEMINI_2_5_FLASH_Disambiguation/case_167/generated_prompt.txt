The PDE to solve is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The domain is (x,y) in (0,1) x (0,1).
The boundary conditions are Dirichlet with u = 0 on the entire boundary ∂((0,1) x (0,1)).
The coefficient field is defined as a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)), where beta = 0.01.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 points including boundaries.
The grid spacing is dx = dy = 1/N.
The grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using 2nd-order finite differences with variable coefficients, employing face-centered harmonic averaging.
For interior nodes (i=1..N-1, j=1..N-1), the discretization is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face coefficients are harmonic means, for example, a(i+1/2,j) = 2*a(x_i,y_j)*a(x_{i+1},y_j) / (a(x_i,y_j)+a(x_{i+1},y_j)).
Assemble the sparse linear system Au=b for the interior unknowns.
Solve the linear system using the conjugate gradient (CG) method to a relative residual tolerance of 1e-10.
A simple Jacobi preconditioner may be used.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including boundary points.
Save the solution data to a file named "solution_pdebench_darcy_beta0p01.npz".
This NPZ file must contain the 1D arrays x and y, the 2D array u (with shape [N+1, N+1]), and the scalars beta, N, and dx.
Save a heatmap or contour plot of u(x,y) as "solution_pdebench_darcy_beta0p01.png".
Print the minimum value of u, the maximum value of u, and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system.
