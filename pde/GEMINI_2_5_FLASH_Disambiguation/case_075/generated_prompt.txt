The PDE to be solved is u_xx + u_yy = f(x,y), where f(x,y) = -5*pi^2*sin(2*pi*x)*sin(pi*y).
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied, with u=0 on all four edges of the domain.
The exact solution for verification is u(x,y)=sin(2*pi*x)*sin(pi*y).
The spatial discretization will use a uniform grid over (0,1) x (0,1) with the standard 5-point stencil for a 2nd-order approximation of the Laplacian.
The resulting sparse linear system for interior nodes will be solved using a sparse direct solver.
The grid will use Nx=Ny=120 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points including boundaries.
The grid spacing will be dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The steady-state solution u(x,y) will be computed on the 2D grid.
The solution will be saved to "solution_agent_poisson_02.npz" containing the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) will be saved as "solution_agent_poisson_02.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm (sqrt(sum(u^2)*dx*dy)) will be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, will also be computed and printed.
