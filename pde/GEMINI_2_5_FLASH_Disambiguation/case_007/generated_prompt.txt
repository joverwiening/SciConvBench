The task is to numerically solve the 1D Allen-Cahn partial differential equation u_t = (0.01)^2*u_xx + u - u^3.
The spatial domain is x in [0,1) and the temporal domain is t in [0,0.5].
The parameter epsilon is 0.01.
The initial condition is u(x,0)=0.1*cos(2*pi*x) + 0.05*sin(4*pi*x).
The spatial discretization will use a uniform grid with Nx=800 points.
The grid points are x_i = i*dx for i=0..Nx-1, where dx = (1-0)/Nx.
Periodic boundary conditions are applied in the spatial dimension.
The spatial derivative u_xx will be discretized using 2nd-order central differences.
Time integration will use a semi-implicit scheme with dt=0.0002 for 2500 steps.
The semi-implicit scheme is (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
This scheme requires solving a linear system at each time step.
The final solution u(x, T=0.5) on the computational grid must be computed.
Save the solution to a file named "solution_agent_allen_cahn_01.npz".
The npz file must contain 1D arrays 'x' and 'u', and scalar metadata 'T', 'dx', 'dt'.
Save a line plot of u(x,T) as "solution_agent_allen_cahn_01.png".
Print the minimum value of u(x,T).
Print the maximum value of u(x,T).
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
