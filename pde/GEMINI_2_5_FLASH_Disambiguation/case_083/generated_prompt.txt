The PDE to solve is u_tt = (0.5)^2 * u_xx.
The spatial domain is x in [0,1] and the time domain is t in [0,1.0].
The parameter c is 0.5.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The initial condition for u(x,0) is sin(2*pi*x).
The initial condition for u_t(x,0) is 0.
The reference exact solution is u(x,t)=cos(0.5*2*pi*t)*sin(2*pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx=400 intervals, resulting in Nx+1 points.
The spatial derivative u_xx is approximated using 2nd-order central differences in the interior.
The time integration uses the standard 2nd-order central difference (leapfrog / Störmer–Verlet) for u_tt.
The time step dt is chosen such that CFL = c*dt/dx ≤ 0.9.
Specifically, dx=1/Nx. Let dt0 = 0.9*dx/c. Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time T=1.0 is hit exactly.
The initialization for the first time step u^1 uses the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value at every time step.
