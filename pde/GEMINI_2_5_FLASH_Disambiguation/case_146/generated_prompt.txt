The task is to numerically solve the 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1).
The final simulation time T is 1.0.
The parameter nu is 0.1.
The boundary conditions are periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method uses a uniform spatial grid with Nx=512 points.
The grid spacing dx is (1-0)/Nx.
The grid points x_i are 0 + i*dx for i=0..Nx-1.
The time integration uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), the solution is performed exactly in Fourier space.
The Fourier transform of u, u_hat(k), is computed using FFT.
The wave numbers k are calculated as 2*pi*fftfreq(Nx, d=dx).
u_hat(k) is updated by multiplying with exp(-nu*k^2*(dt/2)).
The updated u is obtained by taking the real part of the IFFT of u_hat.
For the advection full-step (B), a finite-volume update with Rusanov (local Lax-Friedrichs) flux is used for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), alpha is defined as max(abs(u_left), abs(u_right)).
The Rusanov flux F is calculated as 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The new value u_new[j] is computed as u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, u is replaced with u_new.
The time step dt is determined using a CFL condition.
The CFL number is 0.4, based on an estimated maximum speed of 1.0.
The initial time step dt0 is calculated as CFL*dx/1.0.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is reset to T/Nt to ensure the simulation ends exactly at T.
The simulation computes u at the final time T on the grid.
The results are saved to a file named "solution_pdebench_burgers_nu0p1.npz".
This NPZ file contains the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, T, dx, dt, Nx, and Nt.
A line plot of u(x,T) is saved as "solution_pdebench_burgers_nu0p1.png".
The minimum value of u, maximum value of u, the discrete mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed to the console.
