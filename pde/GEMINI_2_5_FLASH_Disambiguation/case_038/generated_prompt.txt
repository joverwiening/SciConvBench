The task is to numerically solve the 2D heat equation u_t = 0.1 * (u_xx + u_yy) on the spatial domain (x,y) in [0,1] x [0,1] and time domain t in [0,0.1].
The initial condition is u(x,y,0) = sin(pi*x)*sin(pi*y).
Dirichlet boundary conditions are applied, fixing boundary nodes to u=0 at all times.
The numerical method uses a uniform grid with Nx=Ny=50 intervals, resulting in (Nx+1) by (Ny+1) grid points.
Spatial discretization employs the 5-point Laplacian for second-order accuracy.
Time integration uses the Implicit Euler (backward Euler) method with a time step dt=0.001, for a total of 100 steps to reach T=0.1.
The exact solution for verification is u(x,y,t) = exp(-2*0.1*pi^2*t) * sin(pi*x)*sin(pi*y).
Compute the numerical solution u(x,y,T=0.1) on the specified grid.
Save the solution to a file named "solution_agent_heat_09.npz".
This NPZ file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_heat_09.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute and print the maximum absolute error and the L2 error against the reference solution evaluated on the same grid at T.
