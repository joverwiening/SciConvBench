The task ID is agent_heat_11.
The PDE category is Heat equation.
The unknown field is u(x,y,t).
The PDE to solve numerically is u_t = 0.05 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1) x [0,1) with periodicity in both x and y.
The temporal domain is t in [0,0.5].
The parameter alpha is 0.05.
The initial condition is u(x,y,0) = cos(2*pi*x) + sin(2*pi*y).
The reference exact solution is u(x,y,t) = exp(-0.05*(2*pi)^2*t)*cos(2*pi*x) + exp(-0.05*(2*pi)^2*t)*sin(2*pi*y).
The spatial discretization uses a uniform periodic grid with Nx x Ny points on [0,1) x [0,1), without duplicating endpoints.
Second-order central differences with periodic wrap-around are used for spatial derivatives.
The time integration method is Crank–Nicolson.
The numerical scheme involves assembling a sparse matrix for the 2D periodic Laplacian and solving (I - 0.5*dt*alpha*L) u^{n+1} = (I + 0.5*dt*alpha*L) u^n at each time step using a sparse direct solver.
The grid resolution is Nx=64 and Ny=64.
The time step size is dt=0.0025, resulting in 200 time steps.
The final solution u(x,y,T=0.5) on the 2D grid must be computed.
The solution data must be saved to "solution_agent_heat_11.npz".
The saved NPZ file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and the scalar metadata T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T) must be saved as "solution_agent_heat_11.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, must be computed and printed.
