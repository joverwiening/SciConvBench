The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 1.0.
The boundary condition is periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx = (1-0)/Nx = 1/512.
The time grid uses a fixed time step dt=0.001.
The number of time steps is Nt = T/dt = 1.0/0.001 = 1000.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps: (A) Diffusion half-step, (B) Reaction full-step, (C) Diffusion half-step.
For the diffusion half-step (A and C), the duration is dt/2.
The diffusion half-step is solved exactly in Fourier space.
The Fourier transform of u is u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The update for u_hat(k) is u_hat(k) * exp(-nu*k^2*(dt/2)).
The inverse Fourier transform is u = IFFT(u_hat), taking the real part.
For the reaction full-step (B), the duration is dt.
The reaction full-step solves du/dt = rho * u*(1 - u) exactly pointwise for the logistic ODE.
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The simulation computes u(x,T=1.0) on the periodic grid.
The solution is saved to "solution_pdebench_reacdiff_nu5_rho1.npz".
The saved NPZ file contains arrays: x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) is saved as "solution_pdebench_reacdiff_nu5_rho1.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T are printed to the console.
