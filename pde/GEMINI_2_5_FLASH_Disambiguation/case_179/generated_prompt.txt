The task ID is pdebench_reacdiff_nu10_rho5.
Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 10.0.
The parameter rho is 5.0.
The boundary condition is periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A closed-form reference solution is not required.
Use a uniform periodic spatial grid with Nx = 512 points on [0,1).
Calculate dx as (1-0)/Nx.
The spatial grid points are x_j = j*dx for j=0,...,Nx-1.
Use a fixed time step dt = 0.001.
Calculate Nt as T/dt, where T = 1.0.
The numerical method is Strang splitting for each full time step dt.
Each Strang splitting step consists of three sub-steps:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space.
Perform a Fast Fourier Transform (FFT) on u to get u_hat(k).
Calculate the wave numbers k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) using u_hat(k) * exp(-nu*k^2*(dt/2)).
Perform an Inverse Fast Fourier Transform (IFFT) on u_hat to get u, taking the real part.
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho * u * (1 - u).
Update u at each grid point using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (duration dt/2), identical to step (A).
Compute the solution u(x,T=1.0) on the periodic grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu10_rho5.npz".
The .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho5.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the mean value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) of u at T.
