The task is to numerically solve the 1D nonlinear convection-diffusion PDE u_t = -q1*∂_x( (1/3)*u^3 ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 0.5].
The parameters are q1 = 1.0 and q2 = 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
A uniform periodic spatial grid with Nx=1024 points on [0,1) must be used, with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
The spatial discretization for the convection term ∂_x((1/3)u^3) must use a conservative finite-volume Rusanov flux.
The spatial discretization for the diffusion term u_xx must use 2nd-order central differences.
Time integration must be performed using SSP-RK2.
The time step dt must be determined using a CFL condition: calculate dt0 = CFL*dx/max|f'| where CFL=0.2 and max|f'| is estimated as max|u^2| <= 0.25 based on the initial condition.
Calculate dt_diff = 0.2*dx^2/(q2/pi).
The time step dt is then set to min(dt0, dt_diff).
The total number of time steps Nt is ceil(T/dt), and the final dt is T/Nt, where T=0.5.
No closed-form reference solution is required for verification.
