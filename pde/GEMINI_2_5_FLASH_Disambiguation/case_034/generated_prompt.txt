The PDE to solve is u_t = 0.05 * u_xx.
The spatial domain is x in [0, 1) with periodicity.
The temporal domain is t in [0, 1.0].
The parameter alpha is 0.05.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*cos(4*pi*x).
The exact solution for verification is u(x,t)=exp(-0.05*(2*pi)^2*t)*sin(2*pi*x) + 0.2*exp(-0.05*(4*pi)^2*t)*cos(4*pi*x).
The spatial discretization uses a uniform periodic grid with Nx=256 points on [0,1).
The spatial step size dx is 1/Nx.
Second-order central differences with periodic wrap-around are used for u_xx.
The time integration method is Crank–Nicolson.
The time step size dt is 0.001.
There are 1000 time steps to reach T=1.0.
The cyclic tridiagonal matrix for (I - 0.5*dt*alpha*L) must be assembled and solved each step using a sparse direct solver.
The numerical solution u(x, T=1.0) must be computed on the grid.
The arrays x (1D) and u (1D, same length as x), along with metadata scalars T, dx, dt, must be saved to "solution_agent_heat_05.npz".
A line plot of u(x,T) must be saved as "solution_agent_heat_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same x grid, must be computed and printed.
