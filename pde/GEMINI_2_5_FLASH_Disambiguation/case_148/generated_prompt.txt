Solve the 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The parameter nu is 0.4.
The spatial domain for x is [0, 1).
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
The final simulation time T is 1.0.
Use a uniform spatial grid with Nx=512 points.
Calculate dx as (1-0)/Nx.
The grid points x_i are a+i*dx for i=0..Nx-1.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space.
For this step, compute u_hat(k) = FFT(u).
The wave numbers k are 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Then compute u = IFFT(u_hat) and take the real part.
(B) Advection full-step (duration dt) for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
Use a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
(C) Diffusion half-step again (duration dt/2), identical to step (A).
For time stepping, use a CFL number of 0.4 based on an estimated maximum speed of 1.0.
Calculate an initial time step dt0 = CFL*dx/1.0.
Determine the number of time steps Nt = ceil(T/dt0).
Reset the actual time step dt = T/Nt to hit the final time T exactly.
Compute the field u at the final time T on the grid.
Save the solution to a NumPy .npz file named "solution_pdebench_burgers_nu0p4.npz".
The .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, T, dx, dt, Nx, and Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p4.png".
Print the minimum value of u, the maximum value of u, the discrete mean value of u (mean(u)), and the discrete L2 norm (sqrt(sum(u^2)*dx)) at time T.
