The PDE to be solved is u_tt = (2.0)^2 * u_xx.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.5].
Dirichlet boundary conditions are applied at x=0 and x=1, where u=0.
The initial condition for u(x,0) is sin(pi*x).
The initial condition for u_t(x,0) is 0.
The numerical method will use a uniform grid on [0,1] with Nx=400 intervals, resulting in Nx+1 grid points.
The spatial discretization for u_xx will use 2nd-order central differences in the interior.
The time integration will use the standard 2nd-order central difference (leapfrog / Störmer–Verlet) for u_tt.
The time step dt will be chosen such that the CFL condition c*dt/dx <= 0.9 is met, where c=2.0.
Specifically, dx = 1/Nx.
A provisional time step dt0 = 0.9*dx/c will be calculated.
The number of time steps Nt will be ceil(T/dt0), where T=0.5.
The final time step dt will be T/Nt to ensure the simulation ends exactly at T=0.5.
The initialization for the first time step u(x,dt) will use the Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Boundary nodes will be set to the prescribed Dirichlet value of 0 at every time step.
The simulation will compute u(x, T=0.5) on the defined grid.
The results will be saved to a file named "solution_agent_wave_12.npz", containing 1D arrays for x and u, and scalar metadata T, dx, and dt.
A line plot of u(x,T) will be saved as "solution_agent_wave_12.png".
The minimum value of u, maximum value of u, and the discrete L2 norm (sqrt(sum(u^2)*dx)) at time T will be printed to the console.
The maximum absolute error and the L2 error between the computed solution u(x,T) and the exact solution u(x,t)=cos(2.0*pi*t)*sin(pi*x) (evaluated on the same x grid at T) will be computed and printed to the console.
