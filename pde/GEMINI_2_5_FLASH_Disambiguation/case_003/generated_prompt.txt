The PDE to solve is u_t + a(x)*u_x = 0, where a(x) = 1 + 0.5*sin(2*pi*x).
The spatial domain is x in [0,1) and the temporal domain is t in [0,0.5].
The initial condition is u(x,0) = sin(2*pi*x).
The numerical method will use a uniform periodic grid with Nx=1200 points on [0,1).
The spatial discretization will use upwind with a left-biased stencil because a(x)>0 for all x.
The time integration will use Forward Euler.
The spatial step size is dx = 1/Nx.
The maximum value of a(x) is amax = 1.5.
An initial time step dt0 is calculated as 0.9*dx/amax.
The number of time steps Nt is calculated as ceil(T/dt0), where T=0.5.
The final time step dt is calculated as T/Nt to ensure the final time is hit exactly.
The solution u(x, T=0.5) must be computed on the grid.
The solution must be saved to "solution_agent_advection_03.npz" as a NumPy archive containing the arrays x and u, and the scalar metadata T, dx, and dt.
A line plot of u(x,T) must be saved as "solution_agent_advection_03.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T must be printed to the console.
