The PDE to be solved is u_t = -(0.01)^2*u_xxxx + ∂^2/∂x^2( u^3 - u ).
The spatial domain is x in [0,1) and the time domain is t in [0,0.05].
The parameter epsilon is 0.01.
The initial condition is u(x,0)=0.1*cos(2*pi*x) + 0.01*cos(6*pi*x).
The numerical method is a Fourier pseudo-spectral method (FFT) on a periodic grid.
The field u(x,t) will be represented on Nx equally spaced points x_j=j/Nx.
The time integration uses a semi-implicit spectral step.
The linear operator L(k)=(-ε^2*k^4 + k^2) is treated implicitly.
The nonlinear term N(u)=∂xx(u^3) is treated explicitly.
The update in Fourier space is û^{n+1} = (û^n + dt * 𝔽[∂xx(u^3)] ) / (1 - dt*L(k)).
2/3 dealiasing is required for the u^3 term.
Fourier modes with |k| > (2/3)*k_max must be zeroed out after computing FFT(u^3).
The grid size is Nx=512.
The time step is dt=1e-5, resulting in 5000 steps.
The solution u(x, T=0.05) must be computed on the grid.
The solution must be saved to "solution_agent_other_02_cahn_hilliard.npz".
The .npz file must contain 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_other_02_cahn_hilliard.png".
