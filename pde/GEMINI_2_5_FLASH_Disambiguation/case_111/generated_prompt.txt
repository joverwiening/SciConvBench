The Brusselator chemical oscillator ODE system is dx/dt = A + x**2 * y - (B + 1) * x and dy/dt = B * x - x**2 * y.
The time domain is t in [0.0, 20.0].
The parameters are A = 1.0 and B = 3.0.
The initial conditions are x(0.0) = 1.0 and y(0.0) = 1.0.
The numerical method is Classical 4th-order Runge–Kutta (RK4) with a fixed time step.
The time step is dt = 0.01, resulting in Nt = 2000 steps.
The full state vector at all time points t_n = t0 + n*dt for n=0..Nt must be computed.
The solution must be saved to "solution_molk_010.npz".
The "solution_molk_010.npz" file must contain arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns ordered as [x, y], and the parameter scalars.
Line plots of each state vs t must be saved as "solution_molk_010.png".
The final state values at T must be printed.
The minimum and maximum of each state over time must be printed.
