The task is to numerically solve the 1D heat equation u_t = 0.2 * u_xx.
The spatial domain is x in [0, 1] and the time domain is t in [0, 0.3].
The initial condition is u(x,0) = sin(pi*x) + 0.5*sin(3*pi*x).
The Dirichlet boundary conditions are u(0,t)=0 and u(1,t)=0 for all t.
The numerical method uses a uniform grid on [0,1] with Nx=300 intervals, resulting in Nx+1 grid points.
Spatial derivatives are discretized using 2nd-order central differences for u_xx in the interior.
Time integration uses the Crank–Nicolson method for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step.
The time step size is dt=0.0005, leading to 600 time steps.
The exact solution for verification is u(x,t) = exp(-0.2*pi^2*t)*sin(pi*x) + 0.5*exp(-0.2*(3*pi)^2*t)*sin(3*pi*x).
Compute the numerical solution u(x, T=0.3) on the specified grid.
Save the solution to a NumPy compressed archive named "solution_agent_heat_03.npz".
The .npz file must contain the 1D arrays x and u, and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_heat_03.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) of the solution at T=0.3.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution evaluated on the same x grid at T=0.3.
