The task is to numerically solve the 2D diffusion PDE u_t = D * (u_xx + u_yy).
The unknown field is u(x,y,t).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.5].
The diffusion coefficient D is 0.05.
The initial condition is u(x,y,0) = exp(-80*((x-0.3)^2 + (y-0.7)^2)).
Boundary conditions are zero-flux Neumann on all boundary edges (∂u/∂n = 0).
The spatial discretization uses a uniform grid with Nx=Ny intervals.
A 5-point Laplacian stencil is used for spatial derivatives.
Ghost-node implementation is used for the zero Neumann boundary conditions.
The time integration method is Implicit Euler.
The grid resolution is Nx=Ny=80.
The time step is dt=0.001, resulting in 500 time steps to reach T=0.5.
The final solution u(x,y,T=0.5) on the 2D grid must be computed.
The solution must be saved to a file named "solution_agent_diffusion_06.npz".
The NPZ file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T) must be saved as "solution_agent_diffusion_06.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm (sqrt(sum(u^2)*dx*dy)) at T must be printed.
The total mass M(t)=∑ u * dx*dy must be computed at t=0 and t=T.
M(0), M(T), and the relative change in mass must be printed.
