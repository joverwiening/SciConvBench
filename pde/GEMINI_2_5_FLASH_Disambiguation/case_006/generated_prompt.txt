The task is to numerically solve the 1D advection Partial Differential Equation u_t + (2.0)*u_x = 0.
The spatial domain is x in [0,1) and the temporal domain is t in [0,0.3].
The parameter 'a' in the advection term is 2.0.
The initial condition is a periodic square pulse: u(x,0)=1 if 0.2 ≤ x < 0.4, and 0 otherwise.
Use a uniform periodic grid with Nx=2000 points on [0,1).
The spatial step dx is 1/Nx.
For spatial discretization, use 1st-order upwind for the spatial derivative u_x.
For time integration, use Forward Euler.
The time step dt must satisfy the CFL condition max|a|*dt/dx ≤ 0.9.
Calculate dt by first setting dt0 = 0.9*dx/|a|, then determine Nt = ceil(T/dt0), and finally set dt = T/Nt to ensure the final time T=0.3 is hit exactly.
Apply boundary indexing consistent with periodic boundary conditions.
Compute the numerical solution u(x, T=0.3) on the specified grid.
Save the solution to a NumPy .npz file named "solution_agent_advection_06.npz".
The .npz file must contain the 1D array x, the 1D array u (same length as x), and scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_advection_06.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time T.
