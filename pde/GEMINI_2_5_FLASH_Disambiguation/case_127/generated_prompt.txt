The task is to numerically solve the 1D linear advection–diffusion PDE for the unknown field u(x,t).
The PDE is u_t = -q1*∂_x( u ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The boundary condition is periodic, u(0,t)=u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization uses 1st-order upwind for the advection term ∂_x(u).
The spatial discretization uses 2nd-order central differences for the diffusion term u_xx.
The time integration method is IMEX Euler, with diffusion treated implicitly and advection treated explicitly.
The initial time step dt is calculated as min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)).
The number of time steps Nt is ceil(T/dt), where T is the total simulation time.
The final time step dt is reset to T/Nt.
