The task is to numerically solve the 1D Advection PDE u_t + beta * u_x = 0 for the unknown field u(x,t).
The spatial domain is x in [0,1) and the time domain is t in [0, 2.0].
The parameter beta is 0.1.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The boundary conditions are periodic, specifically u(0,t) = u(1,t) for all t.
The numerical solution will use a uniform spatial grid with Nx=512 points over the domain [0,1).
The spatial grid points are x_i = i*dx for i=0..Nx-1, where dx = 1/Nx.
The spatial discretization for u_x is a 1st-order upwind finite difference, using the upwind direction determined by the sign of beta.
The time integration method is explicit forward Euler.
The time step dt is determined using a CFL number of 0.5, such that dt = CFL * dx / abs(beta).
The number of time steps Nt is calculated as ceil(T/dt), and then dt is reset to T/Nt to ensure the final time T is hit exactly.
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
The final computed solution u at time T on the grid must be saved.
A file named "solution_pdebench_advection_beta0p1.npz" must be saved, containing the arrays x (1D length Nx) and u (1D length Nx), and the scalars beta, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_advection_beta0p1.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm (sqrt(sum(u^2)*dx)) at time T must be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same x grid, must be computed and printed.
