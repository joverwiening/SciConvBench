The parameter epsilon is 0.02.
The initial condition is u(x,y,0)=tanh((0.25 - r)/(sqrt(2)*0.02)), where r = sqrt((x-0.5)^2 + (y-0.5)^2).
The spatial discretization uses a uniform grid with Nx=300 and Ny=300.
The grid convention for [a,b] intervals means there are Nx+1 grid points in x and Ny+1 grid points in y.
The spatial discretization uses a 5-point Laplacian for u_xx+u_yy.
The time integration uses a semi-implicit scheme: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
A sparse linear system must be solved at each time step.
The time step size is dt=0.0001, resulting in 1000 time steps to reach T=0.1.
Dirichlet boundary conditions are enforced by setting boundary nodes to u=0 at every time step for t > 0.
