The PDE is u_t = ∂/∂x( D(x) * u_x ).
The diffusion coefficient is D(x) = 0.01 + 0.09*x^2.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.2].
The initial condition is u(x,0) = x*(1-x).
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The spatial discretization uses a conservative 2nd-order finite difference scheme in flux form on a uniform grid.
The discrete operator for interior points i=1..Nx-1 is (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ], where D_i = D(x_i) and D_{i+1/2} = 0.5*(D_i + D_{i+1}).
The time integration uses the Implicit Euler method: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
The sparse linear system must be solved at each time step.
The number of spatial intervals is Nx=400.
The time step size is dt=0.0005, resulting in 400 time steps.
The solution u(x, T=0.2) must be computed on the grid.
The solution must be saved to a file named "solution_agent_diffusion_02.npz".
The npz file must contain the 1D arrays x and u, and the scalar metadata T, dx, and dt.
A line plot of u(x,T) must be saved as "solution_agent_diffusion_02.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed to the console.
