The PDE to solve is u_t + u*u_x = 0.01*u_xx.
The spatial domain is x in [0,1) and the temporal domain is t in [0,0.5].
The parameter nu is 0.01.
The initial condition is u(x,0)=sin(2*pi*x).
Periodic boundary conditions are applied for u and u_x on the spatial domain.
The spatial discretization uses a conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
Convection is discretized using finite-volume or conservative finite-difference with the Rusanov (local Lax–Friedrichs) flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
The convection term (f(u))_x is approximated as (F_{i+1/2}-F_{i-1/2})/dx.
Diffusion is discretized using a 2nd-order central difference: u_xx is approximated as (u_{i+1}-2u_i+u_{i-1})/dx^2.
Time integration uses a 1st-order IMEX scheme, treating convection explicitly and diffusion implicitly.
The time integration scheme is (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_{i-1})/dx^2.
The resulting linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term is solved each step.
The grid uses Nx=800 points on [0,1).
The spatial step dx is 1/Nx.
The time step dt is 1e-4.
The total number of time steps Nt is 5000, reaching T=0.5 exactly.
