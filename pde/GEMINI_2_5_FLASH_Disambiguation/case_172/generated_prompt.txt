Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The unknown field is u(x,t).
The spatial domain for x is [0, 1).
The parameters are nu = 0.5 and rho = 1.0.
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points.
The spatial grid points are x_i = i*dx for i=0..Nx-1, where dx = (1-0)/Nx.
Use a fixed time step dt = 0.001 with Nt = 1000 steps.
The final time T is Nt * dt.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space:
  Compute u_hat(k) by taking the Fast Fourier Transform (FFT) of u.
  Define k as 2*pi*fftfreq(Nx, d=dx).
  Update u_hat(k) by multiplying it with exp(-nu*k^2*(dt/2)).
  Compute u by taking the Inverse Fast Fourier Transform (IFFT) of u_hat(k) and taking the real part.
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u):
  Update u at each grid point using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (same as A).
Compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu0p5_rho1.npz".
The .npz file must contain the following arrays: x (1D length Nx), u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho1.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the mean value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
