The task ID is agent_diffusion_reaction_04.
Solve the one-dimensional Diffusion-Reaction Partial Differential Equation numerically.
The PDE is u_t = 0.01*u_xx + u*(1-u)*(u-0.25).
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.5].
The diffusion coefficient D is 0.01.
The reaction parameter a is 0.25.
The boundary condition at x=0 is Dirichlet: u(0,t)=1.
The boundary condition at x=1 is Dirichlet: u(1,t)=0.
The initial condition at t=0 is u(x,0)=0.5*(1 - tanh((x-0.5)/0.02)).
Use a uniform spatial grid with Nx=600 intervals, resulting in Nx+1 grid points.
The spatial discretization for diffusion terms must use 2nd-order central differences.
The time integration method must be a 1st-order deterministic IMEX scheme.
The diffusion term must be treated implicitly using Backward Euler.
The reaction term must be treated explicitly using Forward Euler.
The time integration scheme is (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where L is the discrete Laplacian and R(u) is the reaction term.
Use a sparse direct solver at each time step.
The time step size dt is 0.0002.
The total number of time steps is 2500.
Compute the solution u(x, T=0.5) on the grid used for the simulation.
Save the solution to a file named "solution_agent_diffusion_reaction_04.npz".
The .npz file must contain the 1D array x, the 1D array u (solution at T=0.5), and scalar metadata T, dx, dt.
Save a line plot of u(x,T=0.5) as "solution_agent_diffusion_reaction_04.png".
Report the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
