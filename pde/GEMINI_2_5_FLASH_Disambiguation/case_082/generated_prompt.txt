The PDE to solve is u_tt = c^2 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The parameter c is 1.0.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The initial condition for u is u(x,0) = sin(pi*x).
The initial condition for u_t is u_t(x,0) = 0.
The reference exact solution is u(x,t)=cos(1.0*pi*t)*sin(pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx=400 intervals, resulting in Nx+1 grid points.
The spatial step size dx is 1/Nx.
Second-order central differences are used for u_xx in the interior.
Time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen such that the CFL condition c*dt/dx ≤ 0.9 is met.
Specifically, dt0 = 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt to hit the final time T=1.0 exactly.
The initialization for the first time step u^1 uses the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Boundary handling for Dirichlet conditions involves setting boundary nodes to the prescribed value at every time step.
The numerical solution u(x, T=1.0) must be computed on the grid.
The solution must be saved to "solution_agent_wave_01.npz" as a NumPy compressed archive containing the 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_01.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T must be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same x grid at time T, must be computed and printed.
