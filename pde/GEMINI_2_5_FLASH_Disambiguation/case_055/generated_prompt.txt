The task is to numerically solve the Klein-Gordon equation u_tt - c^2*u_xx + m^2*u + lambda*u^3 = 0.
The spatial domain is x in [0,1) and the temporal domain is t in [0,2.0].
The parameters are c = 1.0, m = 1.0, and lambda = 1.0.
The initial condition is u(x,0) = 0.1*cos(2*pi*x) and u_t(x,0) = 0.
Use a uniform periodic grid with Nx = 512 points on [0,1).
The spatial discretization for u_xx is a 2nd-order central difference with wrap-around.
The time integration method is Leapfrog for u_tt.
The nonlinear term u^3 must be treated explicitly at time level n.
The time step is dt = 0.0005, resulting in 4000 time steps to reach T = 2.0.
The initialization uses a Taylor start including -m^2*u0 - lambda*u0^3.
Compute u(x, T=2.0) on the grid.
Save the solution to "solution_agent_kg_08.npz".
The NPZ file must contain the 1D arrays x and u, and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_kg_08.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
