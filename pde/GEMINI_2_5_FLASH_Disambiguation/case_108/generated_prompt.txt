The task is to numerically solve the Van der Pol oscillator system of ordinary differential equations.
The ODE system is dx/dt = y and dy/dt = mu*(1 - x**2)*y - x.
The unknown fields are x and y, which are functions of time t.
The time domain for the solution is t in [0.0, 20.0].
The parameter mu is set to 2.0.
The initial conditions at t=0.0 are x(0.0) = 1.0 and y(0.0) = 0.0.
The numerical method for time integration is the Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step size dt is 0.01.
The number of time steps Nt is 2000, ensuring the final time is hit exactly.
The full state vector at all time points t_n = t0 + n*dt for n=0..Nt must be computed.
The solution must be saved to a file named "solution_molk_007.npz".
The "solution_molk_007.npz" file must contain the 1D array t of length Nt+1, the 2D array Y of shape [Nt+1, n_state] with columns ordered as [x, y], and the parameter scalars.
Line plots of each state vs t must be saved as "solution_molk_007.png".
The final state values at the final time T must be printed.
The minimum and maximum values of each state over time must be printed.
