The task is to numerically solve the 2D Helmholtz equation u_xx + u_yy + k^2*u = f(x,y) on a square domain.
The unknown field is u(x,y).
The domain is (x,y) in [0,1] x [0,1].
The parameter k is 5.0.
The function f(x,y) is defined as (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y).
Dirichlet boundary conditions are applied on all boundaries, with u=0.
The exact solution for verification is u(x,y)=sin(pi*x)*sin(pi*y).
The spatial discretization will use a uniform grid with Nx=Ny=120 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points including boundaries.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The 5-point Laplacian will be used to discretize the PDE, yielding a sparse linear system for the interior nodes.
The resulting sparse linear system will be solved using a sparse direct solver.
The steady-state solution u(x,y) will be computed on the 2D grid.
The computed solution will be saved to "solution_agent_other_01_helmholtz.npz".
The NPZ file will contain 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]), and scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) will be saved as "solution_agent_other_01_helmholtz.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, will also be computed and printed.
