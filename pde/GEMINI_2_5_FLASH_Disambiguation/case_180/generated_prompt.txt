The task ID is pdebench_reacdiff_nu1_rho1.
The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The unknown field is u(x,t).
The parameter nu is 1.0.
The parameter rho is 1.0.
The spatial domain for x is [0, 1).
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A closed-form reference solution is not required.
The spatial grid is uniform with Nx=512 points.
The spatial grid spacing dx is (1-0)/Nx.
The spatial grid points x_i are defined as x_i = i*dx for i=0..Nx-1.
The time step dt is 0.001.
The number of time steps Nt is 1000.
The final time T is Nt * dt.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps: (A) Diffusion half-step (duration dt/2), (B) Reaction full-step (duration dt), (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), solve exactly in Fourier space.
Compute u_hat(k) by taking the Fast Fourier Transform (FFT) of u.
The Fourier wavenumbers k are defined as k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute u by taking the Inverse Fast Fourier Transform (IFFT) of u_hat, and take the real part.
For the reaction full-step (B), solve the logistic ODE du/dt = rho*u*(1-u) exactly pointwise.
Update u at each grid point using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu1_rho1.npz".
The .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu1_rho1.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the mean value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
