Solve the 1D advection PDE u_t + beta * u_x = 0.
The unknown field is u(x,t).
Set the parameter beta to 2.0.
Apply periodic boundary conditions such that u(0,t) = u(1,t) for all t.
Use the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The simulation runs until a final time T of 2.0.
Use a uniform spatial grid with Nx=512 points over the spatial domain [0,1).
Calculate dx as (1-0)/Nx.
Define grid points x_i = i*dx for i=0..Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme, with the upwind direction determined by the sign of beta.
Integrate in time using the explicit forward Euler method.
Determine the time step dt using a CFL number of 0.5, such that dt = CFL * dx / abs(beta).
Calculate the number of time steps Nt = ceil(T/dt).
Reset dt = T/Nt to ensure the final time T is hit exactly.
Compute the numerical solution u at the final time T on the defined spatial grid.
Save the solution data to a file named "solution_pdebench_advection_beta2.npz".
The .npz file must contain the 1D arrays x and u, and the scalars beta, T, dx, dt, Nx, and Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta2.png".
