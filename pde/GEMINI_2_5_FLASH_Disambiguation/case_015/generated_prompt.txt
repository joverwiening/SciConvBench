The PDE to solve is u_t + u*u_x = 0.01*u_xx.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.5].
The parameter nu is 0.01.
The initial condition is u(x,0)=sin(pi*x).
The spatial discretization will use a conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
Convection will be discretized using finite-volume or conservative finite-difference with the Rusanov (local Lax–Friedrichs) flux.
The Rusanov flux is F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
The spatial derivative of the convection term is approximated as (f(u))_x ≈ (F_{i+1/2}-F_{i-1/2})/dx.
Diffusion will be discretized using a 2nd-order central difference u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Time integration will use a 1st-order IMEX scheme, treating convection explicitly and diffusion implicitly.
The time integration scheme is (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_{i-1})/dx^2.
This results in a linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term, which must be solved each step.
Boundary conditions will be enforced as Dirichlet BC by setting u[0]=0 and u[N]=0 at each time step.
One-sided or ghost treatment consistent with the diffusion stencil will be used.
Convection fluxes will be computed using boundary values or ghosts rather than periodic wrap-around.
The grid will have Nx=800 uniform intervals, resulting in Nx+1 grid points on [0,1] including endpoints.
The spatial step size dx will be 1/Nx.
The time step dt will be 1e-4.
The number of time steps Nt will be 5000, ensuring the final time T=0.5 is hit exactly.
The solution u(x, T=0.5) must be computed on the specified grid.
The solution will be saved to "solution_agent_burgers_03.npz" as a NumPy .npz file.
The .npz file will contain 1D arrays 'x' and 'u' (same length as x), and scalar metadata 'T', 'dx', 'dt'.
A line plot of u(x,T) will be saved as "solution_agent_burgers_03.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T will be printed to standard output.
