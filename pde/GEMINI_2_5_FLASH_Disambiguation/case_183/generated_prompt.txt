The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The unknown field is u(x,t).
The parameters are nu = 1.0 and rho = 5.0.
The spatial domain for x is [0, 1).
The boundary conditions are periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform with Nx=512 points.
The spatial step size dx is (1-0)/Nx.
The spatial grid points are x_i = 0 + i*dx for i=0..Nx-1.
The time grid uses a fixed dt=0.001.
The simulation runs for Nt=1000 steps.
The final time T is Nt * dt.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space.
For step (A), compute u_hat(k) by taking the FFT of u.
The wave numbers k are 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute u by taking the IFFT of u_hat and taking the real part.
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
For step (B), update u at each grid point using the exact solution: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (duration dt/2), identical to step (A).
Compute u at the final time T on the grid.

The npz file must contain the arrays x (1D length Nx) and u (1D length Nx).
The npz file must also contain the scalars nu, rho, T, dx, dt, Nx, Nt.
