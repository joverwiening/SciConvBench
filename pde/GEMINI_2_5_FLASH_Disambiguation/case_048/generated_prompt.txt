The task is to numerically solve the 1D Klein-Gordon equation u_tt - (1.0)^2*u_xx + (1.0)^2*u = 0.
The spatial domain is x in [0,1] and the temporal domain is t in [0,1.0].
Dirichlet boundary conditions u=0 are applied at x=0 and x=1.
The initial condition is u(x,0)=sin(pi*x) and u_t(x,0)=0.
The exact solution for verification is u(x,t)=cos(sqrt((1.0*pi)^2 + (1.0)^2)*t)*sin(pi*x).
A uniform spatial grid will be used on [0,1] with Nx=400 intervals, resulting in Nx+1 grid points.
The spatial step size dx is 1/Nx.
Second-order central differences will be used for the u_xx term.
Time integration will use a second-order central difference scheme (leapfrog) for u_tt.
The +m^2*u term (which is +1.0^2*u) will be handled explicitly at time level n in the update.
The time step dt will be chosen such that c*dt/dx <= 0.9, where c=1.0 from the PDE.
Calculate dt0 = 0.9*dx/c.
The number of time steps Nt will be ceil(T/dt0), and then dt will be set to T/Nt to ensure the final time T=1.0 is hit exactly.
The simulation will be initialized using a Taylor start from u0 and v0, including the -m^2*u0 term.
Compute the numerical solution u(x, T=1.0) on the defined grid.
Save the solution to a NumPy .npz file named "solution_agent_kg_01.npz".
This file must contain the 1D arrays x and u (both of length Nx+1), and scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_kg_01.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution evaluated on the same x grid at time T.
