The PDE to be solved is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The boundary conditions are Dirichlet u=0 at x=0 and x=1.
The initial condition for u is u(x,0)=exp(-200*(x-0.5)^2).
The initial condition for u_t is u_t(x,0)=0.
The spatial discretization uses a uniform grid on [0,1] with Nx=800 intervals, resulting in Nx+1 grid points.
The spatial step size dx is 1/Nx.
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen such that CFL = c*dt/dx <= 0.9, where c=1.0.
Specifically, dt0 = 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt, ensuring the final time T=1.0 is hit exactly.
The initialization for the first time step u^1 uses the Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0).
Given v0=0 and no forcing term f=0, this simplifies to u^1 = u^0 + 0.5*dt^2*c^2*u_xx^0.
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value (u=0) at every time step.
The solution u(x, T=1.0) is computed on the grid.
The solution is saved to "solution_agent_wave_18.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_wave_18.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed to the console.
