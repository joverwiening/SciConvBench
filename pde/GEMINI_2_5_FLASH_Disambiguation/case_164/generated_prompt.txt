Solve the 1D Compressible Navier–Stokes equations without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE in conservative form is: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ( (E+p)*v - v*sigma )_x = 0.
Let m = rho*v.
Let total energy E = p/(Gamma-1) + 0.5*rho*v^2.
Let the viscous stress be sigma = (zeta + 4/3*eta) * v_x.
Assume zeta = eta.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.2].
The parameters are Gamma = 1.6666666666666667, eta = 1e-08, and zeta = 1e-08.
Boundary conditions are transmissive (zero-gradient) at x=-1 and x=1.
The initial condition is a Riemann (shock-tube) discontinuity at x=0.
For x < 0, rho_L = 1.0, v_L = 0.0, p_L = 2.0.
For x ≥ 0, rho_R = 0.125, v_R = 0.0, p_R = 0.2.
Use a uniform finite-volume grid with Nx = 800 cells.
The spatial step size is dx = (1 - (-1)) / Nx.
The cell centers are located at x_j = -1 + (j + 0.5) * dx for j = 0, ..., Nx-1.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Use a CFL number of 0.5.
Compute rho(x,T), v(x,T), and p(x,T) on the cell centers at the final time T = 0.2.
Save the solution to "solution_pdebench_cns1d_sod5_eta1em8_outflow.npz".
The .npz file must contain the 1D arrays x (length Nx), rho (length Nx), v (length Nx), p (length Nx).
The .npz file must also contain the scalars Gamma, eta, zeta, T, dx, and CFL.
Save a 3-panel line plot of rho, v, and p versus x at T as "solution_pdebench_cns1d_sod5_eta1em8_outflow.png".
Report the minimum and maximum values of rho and p.
Report the mean of rho over the domain.
