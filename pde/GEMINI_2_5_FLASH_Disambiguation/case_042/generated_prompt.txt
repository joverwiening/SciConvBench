The PDE to solve is u_t = 0.01 * (u_xx + u_yy) + 10*exp(-50*((x-0.5)^2 + (y-0.5)^2)).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.5].
The initial condition is u(x,y,0) = 0.
The Dirichlet boundary conditions are u=0 on all boundary edges for all t.
The spatial discretization will use a uniform grid on [0,1] x [0,1] with Nx=80 and Ny=80 intervals, resulting in 81x81 grid points.
The 5-point Laplacian (2nd-order) will be used for spatial derivatives.
The time integration will use Implicit Euler (backward Euler) with a time step dt=0.001 for 500 steps.
Dirichlet boundary conditions will be enforced by fixing boundary nodes at each time step.
A sparse linear system will be solved for the interior nodes at each time step.
The final solution u(x,y,T=0.5) on the 2D grid will be computed.
The solution will be saved to "solution_agent_heat_13.npz" containing 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T=0.5) will be saved as "solution_agent_heat_13.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T=0.5 will be printed.
