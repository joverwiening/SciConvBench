The task ID is pdebench_reacdiff_nu5_rho2.
The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 2.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx = (1-0)/Nx = 1/512.
The time grid uses a fixed dt=0.001.
The number of time steps Nt is T/dt = 1.0/0.001 = 1000.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
(A) A diffusion half-step of duration dt/2 is solved exactly in Fourier space.
    The steps are: u_hat(k) <- FFT(u); k = 2*pi*fftfreq(Nx, d=dx); u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)); u <- IFFT(u_hat) (take the real part).
(B) A reaction full-step of duration dt is solved exactly pointwise for the logistic ODE du/dt = rho * u * (1 - u).
    The exact update for each grid point is: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) A second diffusion half-step of duration dt/2 is performed, identical to step (A).
The simulation computes u(x,T=1.0) on the periodic grid.
The solution is saved to "solution_pdebench_reacdiff_nu5_rho2.npz".
The .npz file contains the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) is saved as "solution_pdebench_reacdiff_nu5_rho2.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T are printed to the console.
