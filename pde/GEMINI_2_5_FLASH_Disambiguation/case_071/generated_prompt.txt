The task is to numerically solve the 2D advection-diffusion equation u_t + 1.0*u_x + 0.5*u_y = 0.01*(u_xx + u_yy).
The spatial domain is (x,y) in [0,1) x [0,1) and the time domain is t in [0,0.5].
The initial condition is u(x,y,0)=sin(2*pi*x)*cos(2*pi*y).
The exact solution for verification is u(x,y,t)=exp(-0.01*8*pi^2*t)*sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t)).
Use a uniform periodic grid with Nx=Ny=400 points in each spatial dimension, resulting in dx=dy=1/400.
The grid points are x_i = i*dx and y_j = j*dy for i,j = 0, ..., Nx-1.
Discretize advection terms (1.0*u_x and 0.5*u_y) using 1st-order upwind differences.
Discretize diffusion terms (u_xx and u_yy) using 2nd-order central differences.
Use a 1st-order IMEX time integration scheme where advection is explicit and diffusion is implicit.
The time integration scheme is (I - dt*D*L) u^{n+1} = u^n - dt*(a*D_x^up u^n + b*D_y^up u^n), where a=1.0, b=0.5, D=0.01.
L is the 5-point periodic Laplacian operator.
D_x^up and D_y^up are the 1st-order upwind operators, using backward differences since a and b are positive.
Use a time step dt=0.001 for Nt=500 steps to reach T=0.5 exactly.
Solve the sparse linear system at each time step using a direct sparse solver.
Compute the numerical solution u(x,y,T=0.5) on the specified 2D grid.
Save the solution to a file named "solution_agent_other_06_advection_diffusion.npz".
The .npz file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and the scalar metadata T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_other_06_advection_diffusion.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution, both evaluated on the same grid at T.
