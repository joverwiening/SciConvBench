The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is a unit square (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square.
The boundary values for u are set to match the analytic harmonic function u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
The spatial discretization uses a uniform grid with Nx=Ny=100 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The PDE is discretized using the standard 5-point stencil, which is 2nd-order accurate, for interior nodes.
The resulting sparse linear system for the interior nodes is solved using a sparse direct solver, such as scipy.sparse.linalg.spsolve.
The steady-state solution u(x,y) is computed on the 2D grid.
The reference exact solution for verification is u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
A file named "solution_agent_laplace_01.npz" is saved.
This NPZ file contains the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and the scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) is saved as "solution_agent_laplace_01.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm (sqrt(sum(u^2)*dx*dy)) are printed to the console.
The maximum absolute error and the L2 error, both computed against the reference solution evaluated on the same grid, are also computed and printed.
