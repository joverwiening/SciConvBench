The task is to numerically solve the 1D Klein-Gordon equation u_tt - (1.0)^2*u_xx + (0.5)^2*u = 0.
The spatial domain is x in [0,1] and the temporal domain is t in [0,1.0].
Boundary conditions are Neumann at x=0 and x=1: u_x(0,t)=0 and u_x(1,t)=0.
Initial conditions are u(x,0)=cos(pi*x) and u_t(x,0)=0.
The reference exact solution for verification is u(x,t)=cos(sqrt((1.0*pi)^2 + (0.5)^2)*t)*cos(pi*x).
The spatial discretization will use a uniform grid on [0,1] with Nx=400 intervals, resulting in Nx+1 grid points.
The spatial step size is dx = (1-0)/Nx = 1/400.
Second-order central differences will be used for the u_xx term.
Time integration will use a 2nd-order central difference in time (leapfrog) for u_tt.
The + (0.5)^2*u term will be handled explicitly at time level n in the update.
The time step dt will be chosen such that c*dt/dx <= 0.9, where c=1.0 from the PDE.
Specifically, dt0 = 0.9*dx/1.0.
The number of time steps Nt will be ceil(T/dt0), where T=1.0.
The final time step dt will be T/Nt to ensure the final time is hit exactly.
Initialization will use a Taylor start from u(x,0) and u_t(x,0), including the - (0.5)^2*u(x,0) term.
Boundary conditions will be handled using zero Neumann via ghost points (mirror values).
Compute u(x, T=1.0) on the grid.
Save the solution to "solution_agent_kg_03.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_kg_03.png".
Print the minimum value of u(x,T), the maximum value of u(x,T), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the maximum absolute error and the L2 error between the computed solution and the reference exact solution evaluated on the same x grid at T.
