The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) in [0,1] x [0,1].
The boundary conditions are Dirichlet on all four edges of the square, where u(x,y) is set to match the exact harmonic function u(x,y)=x*y.
Discretize the PDE on a uniform grid over (0,1) x (0,1) using the standard 5-point stencil, which is 2nd-order accurate.
Use Nx=Ny=100 intervals in each direction, resulting in an (Nx+1) by (Ny+1) grid of points including boundaries.
The grid spacing should be dx=dy=1/Nx.
The grid points are x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Solve the resulting sparse linear system for the interior nodes using a sparse direct solver.
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution data to a file named "solution_agent_laplace_05.npz".
The .npz file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and the scalar metadata dx and dy.
Save a heatmap or contour plot of u(x,y) as "solution_agent_laplace_05.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm calculated as sqrt(sum(u^2)*dx*dy).
Compute and print the maximum absolute error and the L2 error of the numerical solution compared to the reference solution u(x,y)=x*y, evaluated on the same grid.
