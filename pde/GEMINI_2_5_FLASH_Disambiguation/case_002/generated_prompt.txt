Solve the advection PDE u_t + a*u_x = 0 numerically.
The unknown field is u(x,t).
The parameter a is -0.5.
The spatial domain is x in [0,1).
The temporal domain is t in [0,1.0].
The initial condition is u(x,0) = exp(-100*(x-0.3)^2).
Use a uniform periodic grid with Nx=1000 points on [0,1).
The spatial step size is dx = 1/Nx.
Use 1st-order upwind spatial discretization.
Since a < 0, use a right-biased stencil for u_x, specifically (u_{i+1} - u_i)/dx.
Use Forward Euler for time integration.
The time step dt is chosen such that max|a|*dt/dx <= 0.9.
Calculate dt0 = 0.9*dx/|a|.
Set Nt = ceil(T/dt0) where T=1.0.
Set dt = T/Nt to ensure the final time is hit exactly.
Apply boundary indexing consistent with periodic boundary conditions.
Compute u(x, T=1.0) on the grid.
Save the solution to "solution_agent_advection_02.npz" containing arrays: x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_advection_02.png".
Report (print) the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
