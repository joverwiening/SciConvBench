Solve the ordinary differential equation du/dt = a*t**2 * cos(u) + b*u numerically.
The unknown field is u(t).
The time domain is t in [0.0, 3.0].
The parameter a is 0.5.
The parameter b is -0.2.
The initial condition is u(0.0) = 0.1.
Use the Classical 4th-order Runge–Kutta (RK4) method for time integration.
The fixed time step size is dt=0.001.
The number of time steps is Nt=3000.
Compute u(t) at all time points t_n = t0 + n*dt for n=0..Nt.
Save the solution to "solution_molk_002.npz".
The "solution_molk_002.npz" file must contain the 1D array t (length Nt+1), the 1D array u (length Nt+1), and the scalar parameters a and b.
Save a line plot of u(t) vs t as "solution_molk_002.png".
Print the value of u(T) where T is the final time.
Print the minimum value of u over the time grid.
Print the maximum value of u over the time grid.
No closed-form reference solution is provided, so error computation is not required.
