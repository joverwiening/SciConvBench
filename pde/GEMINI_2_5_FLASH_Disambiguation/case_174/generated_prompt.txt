Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The unknown field is u(x,t).
The parameters are nu = 0.5 and rho = 2.0.
The spatial domain for x is [0, 1) with periodic boundary conditions u(0,t) = u(1,t).
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx=512 points.
The grid spacing dx is (1-0)/Nx.
The grid points x_i are 0 + i*dx for i=0..Nx-1.
Use a fixed time step dt=0.001 for Nt=1000 steps, resulting in a final time T=1.0.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting steps are:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space:
    Compute u_hat(k) by taking the FFT of u.
    The wave numbers k are 2*pi*fftfreq(Nx, d=dx).
    Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
    Compute u by taking the IFFT of u_hat and taking the real part.
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u):
    Update u for each grid point as (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (same as A).
Compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu0p5_rho2.npz".
This NPZ file must contain the 1D arrays x (length Nx) and u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho2.png".
Report (print to console) the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
