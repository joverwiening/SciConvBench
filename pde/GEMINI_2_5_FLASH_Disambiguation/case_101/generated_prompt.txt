The task is to solve the scalar ordinary differential equation du/dt = a*sin(2*pi*t)*u numerically.
The time domain for the solution is t in [0.0, 5.0].
The parameter 'a' is set to 1.3.
The initial condition is u(0.0) = 1.0.
The numerical method to be used is the Classical 4th-order Runge–Kutta (RK4) with a fixed time step.
The time step size is dt = 0.001, resulting in Nt = 5000 steps to reach the final time exactly.
The exact solution for verification is u(t) = u0 * exp( a*(1 - cos(2*pi*t)) / (2*pi) ), where u0 = u(0).
Compute u(t) at all time points t_n = t0 + n*dt for n=0..Nt.
Save the numerical solution to a file named "solution_molk_000.npz".
This NPZ file must contain the 1D array 't' (length Nt+1), the 1D array 'u' (length Nt+1), and the scalar parameters.
Save a line plot of u(t) vs t as "solution_molk_000.png".
Print the value of u(T), the minimum value of u, and the maximum value of u over the computed time grid.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution evaluated on the same time grid.
