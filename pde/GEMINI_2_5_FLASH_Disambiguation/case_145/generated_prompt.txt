The task is to numerically solve the 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The spatial domain for x is [0, 1).
The final simulation time T is 1.0.
The parameter nu is 0.04.
The boundary conditions are periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
A uniform spatial grid will be used with Nx=512 points.
Given the [0,1) periodic domain and Nx points, dx = (1-0)/Nx = 1/512.
The grid points x_i are defined as x_i = i*dx for i=0..Nx-1.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
(A) A diffusion half-step of duration dt/2. This step is solved exactly in Fourier space.
First, compute the Fast Fourier Transform (FFT) of u to get u_hat(k).
The wave numbers k are calculated as k = 2*pi*fftfreq(Nx, d=dx).
Then, update u_hat(k) by multiplying it with exp(-nu*k^2*(dt/2)).
Finally, compute the Inverse Fast Fourier Transform (IFFT) of the updated u_hat(k) and take the real part to get u.
(B) An advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
This step uses a finite-volume update with the Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is calculated as F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The updated value u_new[j] is calculated as u[j] - (dt/dx)*(F_plus - F_minus).
After calculating all u_new[j], replace u with u_new.
(C) Another diffusion half-step of duration dt/2, identical to step (A).
The time step dt is determined using a CFL condition.
An estimated maximum speed of 1 is used for the initial condition.
The initial time step dt0 is calculated as CFL*dx/1.0, where CFL=0.4.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is then reset to T/Nt to ensure the simulation ends exactly at T.
The simulation will compute u at the final time T on the grid.
The results will be saved to a file named "solution_pdebench_burgers_nu0p04.npz".
This NPZ file will contain the 1D arrays x (length Nx) and u (length Nx), and the scalars nu, T, dx, dt, Nx, and Nt.
A line plot of u(x,T) will be saved as "solution_pdebench_burgers_nu0p04.png".
The report will print the minimum value of u, the maximum value of u, the discrete mean value of u (mean(u)), and the discrete L2 norm (sqrt(sum(u^2)*dx)) at time T.
