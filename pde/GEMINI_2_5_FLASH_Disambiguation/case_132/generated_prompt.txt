The task is to numerically solve the 1D nonlinear convection-diffusion PDE u_t = -q1*∂_x( cos(u) ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 0.5].
The parameters are q1 = 1.0 and q2 = 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=1024 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The convection term ∂_x(cos(u)) is discretized using a conservative finite-volume Rusanov flux.
The Rusanov flux uses a wave speed alpha=max|sin(u)|.
The diffusion term u_xx is discretized using 2nd-order central differences.
Time integration is performed using the SSP-RK2 method.
The time step dt is determined by a CFL number of 0.2.
The advective time step is dt_adv = 0.2*dx/1, noting max|sin(u)|<=1.
The diffusive time step is dt_diff = 0.2*dx^2/(q2/pi).
The time step dt is set to min(dt_adv, dt_diff).
The total number of time steps Nt is calculated as ceil(T/dt), where T=0.5.
The final time step dt is adjusted to T/Nt to ensure the simulation ends exactly at T.
