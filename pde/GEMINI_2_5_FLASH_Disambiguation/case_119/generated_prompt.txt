The task is to numerically solve the 1D linear advection PDE u_t + q*u_x = 0.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 1.0].
The parameter q is 1.5.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The exact solution for verification is u(x,t) = u0( (x - q*t) mod 1 ), where u0 is the initial condition.
The numerical solution will use 1st-order upwind finite difference for the spatial derivative u_x.
Since q = 1.5 > 0, the upwind scheme will use a backward difference for u_x.
The temporal discretization method is Forward Euler.
The number of spatial grid points is Nx = 512.
The spatial step size dx is (1 - 0) / Nx = 1/512.
The grid points are x_i = i * dx for i = 0, ..., Nx-1.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The time step dt is CFL * dx / |q| = 0.5 * (1/512) / 1.5 = 1/1536.
The total number of time steps is Nt = T_final / dt = 1.0 / (1/1536) = 1536.
The simulation will compute u(x,T=1.0) on the periodic grid.
The results will be saved to "solution_molk_018.npz" containing the arrays x (1D length Nx) and u (1D length Nx), and the scalars T, dx, Nx, and q.
A line plot of u(x,T) will be saved as "solution_molk_018.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T=1.0 will be printed.
The maximum absolute error and L2 error against the exact solution, evaluated on the same x grid at T=1.0, will be computed and printed.
