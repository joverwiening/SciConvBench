The task is to numerically solve the 1D Diffusion-Reaction PDE u_t = 0.01*u_xx + 5.0*u*(1 - u) for the unknown field u(x,t).
The spatial domain is x in [0,1] and the temporal domain is t in [0,1.0].
The initial condition is u(x,0) = 0.1 + 0.1*sin(2*pi*x).
The boundary conditions are Neumann at x=0 and x=1, specifically u_x(0,t)=0 and u_x(1,t)=0.
The numerical method will use a uniform spatial grid with Nx=400 intervals, resulting in Nx+1 grid points.
The spatial discretization for the diffusion term will use 2nd-order central differences.
Zero Neumann boundary conditions will be implemented using ghost points (mirror values).
The time integration will use a 1st-order deterministic IMEX scheme, with the diffusion term treated implicitly (Backward Euler) and the reaction term treated explicitly (Forward Euler).
The time integration scheme is (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where D=0.01, L is the discrete Laplacian, and R(u) = 5.0*u*(1 - u) is the reaction term.
A sparse direct solver will be used at each time step.
The time step size is dt=0.0005, leading to 2000 time steps to reach T=1.0.
The final solution u(x, T=1.0) on the computational grid must be computed.
Save the computed solution to a file named "solution_agent_diffusion_reaction_03.npz".
This NPZ file must contain the 1D arrays x and u (both of length Nx+1), and the scalar metadata T, dx, and dt.
Generate and save a line plot of u(x,T) as "solution_agent_diffusion_reaction_03.png".
Print the minimum value of u(x,T), the maximum value of u(x,T), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
