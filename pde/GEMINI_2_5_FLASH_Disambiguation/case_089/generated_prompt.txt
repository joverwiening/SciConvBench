The PDE to be solved is u_tt = (0.7)^2 * (u_xx + u_yy).
The spatial domain is x in [0,1] and y in [0,1].
The temporal domain is t in [0,0.8].
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition is u(x,y,0)=sin(2*pi*x)*sin(pi*y) and u_t(x,y,0)=0.
The reference exact solution is u(x,y,t)=cos(0.7*pi*sqrt(5)*t)*sin(2*pi*x)*sin(pi*y).
A uniform grid is used on [0,1] x [0,1] with Nx=140 and Ny=140 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The spatial step sizes are dx = (1-0)/Nx and dy = (1-0)/Ny.
The 5-point Laplacian is used for spatial discretization of the ∇²u term.
Second-order central difference is used for time integration of u_tt.
The time step dt is chosen such that CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9, where c=0.7.
Specifically, dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
The number of time steps Nt is ceil(T/dt0), where T=0.8.
The final time step dt is T/Nt to ensure the final time T is hit exactly.
u at the first time step is computed using a Taylor start with the initial velocity.
Boundary nodes are set to 0 at each time step to enforce Dirichlet boundary conditions.
The numerical solution u(x,y,T=0.8) on the 2D grid is computed.
The solution is saved to "solution_agent_wave_08.npz" as a NumPy archive.
The .npz file contains 1D arrays x and y, a 2D array u with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T, and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) is saved as "solution_agent_wave_08.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T are printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid at T, are computed and printed.
