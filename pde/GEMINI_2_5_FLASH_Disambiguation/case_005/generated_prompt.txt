Solve the 2D advection PDE u_t + (-0.7)*u_x + (1.2)*u_y = 0 numerically.
The spatial domain is (x,y) in [0,1) x [0,1) and the time domain is t in [0,0.5].
The parameters are a = -0.7 and b = 1.2.
The initial condition is u(x,y,0)=exp(-80*((x-0.2)^2 + (y-0.6)^2)).
Apply periodic boundary conditions in both x and y directions.
Use a uniform grid with Nx=Ny=256 points on [0,1) x [0,1).
Calculate dx and dy as (1-0)/Nx and (1-0)/Ny respectively.
For spatial discretization, use upwind differencing.
For the x-derivative, since a = -0.7 < 0, use a right-biased stencil.
For the y-derivative, since b = 1.2 > 0, use a left-biased stencil.
For time integration, use Forward Euler.
Determine the time step dt such that |a|*dt/dx + |b|*dt/dy <= 0.9.
Specifically, calculate dt0 = 0.9 / (|a|/dx + |b|/dy).
Set Nt = ceil(T/dt0) where T=0.5.
Set dt = T/Nt to ensure the final time T is hit exactly.
Compute the numerical solution u(x,y,T=0.5) on the specified grid.
Save the solution to a file named "solution_agent_advection_05.npz".
The .npz file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and the scalar metadata T, dx, dy, dt.
Generate and save a heatmap or contour plot of u(x,y,T) as "solution_agent_advection_05.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the discrete L2 norm of u at T, calculated as sqrt(sum(u^2)*dx*dy).
