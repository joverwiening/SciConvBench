The task is to numerically solve the 1D wave equation u_tt + 0.5*u_t = (1.0)^2 * u_xx.
The spatial domain is x in [0,1] and the time domain is t in [0,3.0].
The boundary conditions are Dirichlet u=0 at x=0 and x=1.
The initial conditions are u(x,0)=sin(pi*x) and u_t(x,0)=0.
The PDE should be rewritten as a first-order system in time: u_t = v, v_t = c^2*u_xx - gamma*v, where c=1.0 and gamma=0.5.
The spatial discretization for u_xx will use 2nd-order central differences on a uniform grid.
The time integration will use classical RK4 with a fixed time step.
The grid will have Nx=400 spatial intervals, resulting in Nx+1=401 grid points.
The spatial step size dx will be (1-0)/Nx.
The time step dt will be 0.0005.
Dirichlet boundary conditions (u=0 and v=0) must be enforced at x=0 and x=1 at every RK substage.
The simulation will run until T=3.0.
Compute the solution u(x, T=3.0) on the grid.
Save the solution to a file named "solution_agent_wave_09.npz".
The .npz file must contain the 1D arrays x and u, and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_wave_09.png".
Print the minimum value of u(x,T), the maximum value of u(x,T), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=3.0.
