The PDE to be solved is u_t + u*u_x = 0.005*u_xx.
The spatial domain is x in [0,1) and the temporal domain is t in [0,0.2].
The parameter nu is 0.005.
The initial condition is u(x,0) = 0.5 + sin(2*pi*x).
The spatial discretization uses a conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
Convection is discretized using finite-volume or conservative finite-difference with the Rusanov (local Lax–Friedrichs) flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|). The spatial derivative is approximated as (f(u))_x ≈ (F_{i+1/2}-F_{i-1/2})/dx.
Diffusion is discretized using a 2nd-order central difference: u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Time integration uses a 1st-order IMEX scheme, treating convection explicitly and diffusion implicitly: (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_i-1)/dx^2.
This results in a linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term, which must be solved each step.
Boundary conditions are periodic, consistent with the spatial domain [0,1).
The grid uses Nx=1200 points on [0,1), with dx=1/Nx. The grid points are x_i = i*dx for i=0..Nx-1.
The time step is dt=5e-5, and the simulation runs for Nt=4000 steps to reach T=0.2 exactly.
