The task is to numerically solve the 1D heat equation u_t = alpha * u_xx.
The spatial domain is x in [0, 1] and the time domain is t in [0, 0.5].
The parameter alpha is 0.1.
The initial condition is u(x,0) = sin(pi*x).
The boundary conditions are Dirichlet, with u(0,t) = 0 and u(1,t) = 0 for all t in [0, 0.5].
The numerical method uses a uniform grid on [0,1] with Nx=200 intervals, resulting in Nx+1 grid points.
The spatial discretization uses 2nd-order central differences for u_xx in the interior.
The time integration uses the Crank–Nicolson method for diffusion terms.
The time step is dt=0.001, resulting in 500 time steps.
The final solution u(x, T=0.5) on the grid must be computed.
The computed solution, along with the x grid, T, dx, and dt, must be saved to a file named "solution_agent_heat_01.npz".
A line plot of u(x,T) must be saved as "solution_agent_heat_01.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5 must be printed.
The maximum absolute error and L2 error against the provided exact solution u(x,t) = exp(-0.1*pi^2*t) * sin(pi*x) must be computed and printed at T=0.5.
