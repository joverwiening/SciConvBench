The PDE to be solved is u_tt - (0.8)^2*(u_xx + u_yy) + (0.2)^2*u = 0.
The unknown field is u(x,y,t).
The spatial domain is x in [0,1] and y in [0,1].
The temporal domain is t in [0,1.0].
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition for u is u(x,y,0)=sin(2*pi*x)*sin(pi*y).
The initial condition for u_t is u_t(x,y,0)=0.
The reference exact solution is u(x,y,t)=cos(sqrt((0.8)^2*((2*pi)^2 + (pi)^2) + (0.2)^2)*t)*sin(2*pi*x)*sin(pi*y).
The spatial discretization will use a uniform grid with a 5-point Laplacian for u_xx+u_yy.
The time integration will use a 2nd-order central difference scheme for u_tt.
The initialization will use a Taylor start, incorporating the Laplacian and mass terms from the PDE.
The grid will have Nx=160 intervals in x and Ny=160 intervals in y.
This results in Nx+1 by Ny+1 grid points.
The spatial step sizes are dx = (1-0)/Nx and dy = (1-0)/Ny.
The wave speed c for the CFL condition is 0.8.
The initial time step dt0 is calculated as 0.5 * min(dx, dy) / c.
The total number of time steps Nt is ceil(T/dt0), where T=1.0.
The final time step dt is adjusted to T/Nt to ensure the simulation ends exactly at T=1.0.
The simulation will compute u(x,y,T=1.0) on the 2D grid.
The results will be saved to a file named "solution_agent_kg_06.npz".
This NPZ file will contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T) will be saved as "solution_agent_kg_06.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed to the console.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid at T, will also be computed and printed.
