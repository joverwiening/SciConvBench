The PDE to solve is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.8].
The parameter c is 1.0.
The boundary conditions are Dirichlet at x=0 and x=1, with u=0.
The initial condition for u(x,0) is sin(pi*x) + 0.5*sin(3*pi*x).
The initial condition for u_t(x,0) is 0.
The reference exact solution is u(x,t)=cos(1.0*pi*t)*sin(pi*x) + 0.5*cos(1.0*3*pi*t)*sin(3*pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx=600 intervals, resulting in Nx+1 points.
The spatial step dx is 1/Nx.
Second-order central differences are used for u_xx in the interior.
Time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen such that CFL = c*dt/dx ≤ 0.9.
Specifically, dt0 = 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0), and the final dt is T/Nt to hit the final time exactly.
Initialization uses a Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value at every time step.
The task requires computing u(x, T=0.8) on the grid.
The solution must be saved to "solution_agent_wave_03.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_03.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
The maximum absolute error and L2 error against the reference solution evaluated on the same x grid must also be computed and printed.
