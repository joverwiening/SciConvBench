The task is to numerically solve the Duffing oscillator (undriven) ordinary differential equation system.
The ODE system is dx/dt = y and dy/dt = -delta*y - alpha*x - beta*x**3.
The unknown fields are x and y, which are functions of t.
The time domain is t in [0.0, 50.0].
The parameters are alpha = 1.0, beta = 0.1, and delta = 0.2.
The initial conditions at t=0.0 are x(0.0) = 1.0 and y(0.0) = 0.0.
The numerical method for time integration is Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step is dt=0.01, resulting in Nt=5000 steps to reach the final time exactly.
The full state vector at all time points t_n = t0 + n*dt for n=0..Nt must be computed.
The solution must be saved to "solution_molk_011.npz".
The saved file must contain the 1D array t (length Nt+1), the 2D array Y (shape [Nt+1, n_state]) with columns ordered as [x, y], and the parameter scalars.
Line plots of each state vs t must be saved as "solution_molk_011.png".
The final state values at T must be printed.
The minimum and maximum values of each state over time must be printed.
