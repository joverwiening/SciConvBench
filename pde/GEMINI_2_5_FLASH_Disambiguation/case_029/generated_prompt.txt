The PDE is u_t = 0.02*(u_xx + u_yy) + 3.0*u*(1 - u/1.0).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.5].
The diffusion coefficient is D = 0.02.
The reaction rate is r = 3.0.
The carrying capacity is K = 1.0.
The boundary conditions are Dirichlet on all boundary edges with u=0.
The initial condition is u(x,y,0)=0.8*exp(-40*((x-0.5)^2 + (y-0.5)^2)).
The spatial discretization uses a uniform grid with Nx=Ny=120 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The spatial step sizes are dx=dy=1/Nx.
The diffusion term is discretized using a 5-point Laplacian.
The time integration uses a deterministic IMEX (1st order) scheme.
The diffusion term is treated implicitly (backward Euler).
The reaction term is treated explicitly (forward Euler).
The time integration scheme is (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where L is the discrete Laplacian and R(u) is the reaction term.
A sparse direct solver is used at each time step.
The time step size is dt=0.0005, resulting in Nt=1000 steps.
The solution u(x,y,T=0.5) on the 2D grid must be computed.
The solution must be saved to "solution_agent_diffusion_reaction_07.npz".
The NPZ file must contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_diffusion_reaction_07.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
