The task ID is pdebench_reacdiff_nu2_rho5.
The PDE category is 1D Reaction–Diffusion (logistic reaction, periodic).
The unknown field is u(x,t).
The PDE to solve numerically is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 5.0.
The boundary conditions are periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is a uniform periodic grid with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1.
The spatial step size dx is (1-0)/Nx = 1/512.
The time grid uses a fixed dt=0.001.
The number of time steps Nt is T/dt = 1.0/0.001 = 1000, so that T=1.0 is reached exactly.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps:
(A) A diffusion half-step of duration dt/2, solved exactly in Fourier space.
For this step, u_hat(k) is computed by taking the FFT of u.
The wave numbers k are defined as k = 2*pi*fftfreq(Nx, d=dx).
u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)).
u is then obtained by taking the IFFT of u_hat, and the real part is retained.
(B) A reaction full-step of duration dt, solved exactly pointwise for the logistic ODE.
The ODE for this step is du/dt = rho * u * (1 - u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Another diffusion half-step, identical to step (A).
The simulation must compute u(x,T=1.0) on the periodic grid.
The solution must be saved to a file named "solution_pdebench_reacdiff_nu2_rho5.npz".
This .npz file must contain the arrays: x (1D length Nx), u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu2_rho5.png".
The minimum value of u, maximum value of u, mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed to the console.
