The task ID is pdebench_reacdiff_nu0p5_rho5.
The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The unknown field is u(x,t).
The spatial domain is x in [0, 1).
The parameters are nu = 0.5 and rho = 5.0.
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform with Nx = 512 points.
The spatial grid points are x_i = i * dx for i = 0, ..., Nx-1, where dx = (1 - 0) / Nx.
The time grid uses a fixed dt = 0.001 with Nt = 1000 steps.
The final time T is Nt * dt.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
  (A) Diffusion half-step (duration dt/2) solved exactly in Fourier space.
      Compute u_hat(k) by taking the FFT of u.
      The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
      Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
      Compute u by taking the IFFT of u_hat(k) and taking the real part.
  (B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
      Update u at each grid point using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
  (C) Diffusion half-step (duration dt/2) solved exactly in Fourier space, identical to step (A).
Compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu0p5_rho5.npz".
The .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho5.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the mean value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
