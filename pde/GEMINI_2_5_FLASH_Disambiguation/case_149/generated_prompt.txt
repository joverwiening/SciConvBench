The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The spatial domain for x is [0, 1).
The final time T is 1.0.
The parameter nu is 1.0.
The boundary conditions are periodic, meaning u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
The numerical solution will be computed on a uniform spatial grid with Nx=512 points.
Given the domain [0, 1) and periodicity, dx = (1-0)/Nx, and x_i = 0 + i*dx for i=0..Nx-1.
The numerical method uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), the solution is obtained exactly in Fourier space.
First, compute u_hat(k) = FFT(u).
Then, define k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, compute u <- IFFT(u_hat) and take the real part.
For the advection full-step (B), the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 is solved using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is calculated as F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
The updated value for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After computing all u_new[j], replace u <- u_new for the advection substep.
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated max speed is 1.0.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is reset to T/Nt to ensure the simulation ends exactly at T.
The output requirements are to compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_burgers_nu1.npz".
This .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu1.png".
