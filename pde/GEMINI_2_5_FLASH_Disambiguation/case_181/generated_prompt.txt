The task is to numerically solve the 1D Reaction–Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u).
The unknown field is u(x,t).
The spatial domain for x is [0, 1).
The parameters are nu = 1.0 and rho = 10.0.
The boundary conditions are periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method uses a uniform spatial grid with Nx=512 points.
Given the spatial domain [0, 1) and Nx=512, dx = (1 - 0) / Nx = 1/512.
The spatial grid points are x_i = 0 + i*dx for i=0..Nx-1.
The time grid uses a fixed dt=0.001 with Nt=1000 steps, resulting in a final time T = dt * Nt = 1.0.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space:
    Compute u_hat(k) by taking the FFT of u.
    The wave numbers k are calculated as k = 2*pi*fftfreq(Nx, d=dx).
    Update u_hat(k) using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
    Compute u by taking the IFFT of u_hat, retaining only the real part.
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u):
    Update u for each grid point using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (same as A).
The output requirements are to compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu1_rho10.npz".
This NPZ file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu1_rho10.png".
Report (print to console) the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
