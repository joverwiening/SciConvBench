The task is to numerically solve the 1D Advection PDE u_t + beta * u_x = 0.
The unknown field is u(x,t).
The parameter beta is 0.4.
The spatial domain for x is [0, 1).
The boundary condition is periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The final simulation time T is 2.0.
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
The numerical method uses a uniform spatial grid with Nx=512 points.
Since the domain is [0, 1) with periodicity, dx = (1-0)/Nx and x_i = 0 + i*dx for i=0..Nx-1.
The spatial discretization is a 1st-order upwind finite difference for u_x, using the upwind direction determined by the sign of beta.
The time integration method is Explicit forward Euler.
The time step dt is determined using a CFL number of 0.5.
Calculate dt_raw = CFL * dx / abs(beta).
The number of time steps Nt is ceil(T/dt_raw).
The final dt is reset to T/Nt to hit the final time exactly.
Compute the numerical solution u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_advection_beta0p4.npz".
This NPZ file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta0p4.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the discrete L2 norm of u at T, calculated as sqrt(sum(u^2)*dx).
Compute and print the maximum absolute error between the numerical solution and the reference solution at T on the same x grid.
Compute and print the L2 error between the numerical solution and the reference solution at T on the same x grid.
