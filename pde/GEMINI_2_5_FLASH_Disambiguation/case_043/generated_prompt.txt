The task is to numerically solve the one-dimensional heat equation u_t = 0.1 * u_xx + 1.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 0.5].
The initial condition is u(x,0) = 0 for all x in [0, 1].
The boundary conditions are u(0,t) = 0 and u(1,t) = 0 for all t in [0, 0.5].
Use a uniform spatial grid with Nx=200 intervals, resulting in Nx+1 grid points.
Use a time step dt=0.001, for a total of 500 time steps to reach T=0.5.
Discretize the spatial derivative u_xx using 2nd-order central differences.
Integrate in time using the Crank–Nicolson method.
The constant source term of 1 should be included consistently in the Crank-Nicolson scheme.
Enforce the Dirichlet boundary conditions by fixing the boundary nodes at each time step.
Compute the solution u(x, T=0.5) on the grid.
Save the solution data to a file named "solution_agent_heat_14.npz".
The .npz file must contain the 1D arrays x and u, and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T=0.5) as "solution_agent_heat_14.png".
Print the minimum value of u(x,T=0.5), the maximum value of u(x,T=0.5), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
