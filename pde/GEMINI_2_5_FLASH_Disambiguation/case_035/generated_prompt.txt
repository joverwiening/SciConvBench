The task is to numerically solve the one-dimensional heat equation u_t = 0.1 * u_xx.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 0.5].
The initial condition is u(x,0) = 1 - x.
The Dirichlet boundary conditions are u(0,t) = 1 and u(1,t) = 0.
The numerical method uses a uniform grid on [0,1] with Nx=200 intervals, resulting in Nx+1=201 grid points.
The spatial discretization uses 2nd-order central differences for u_xx in the interior.
The time integration uses the Crank–Nicolson method for diffusion terms.
Boundary nodes are fixed according to the Dirichlet boundary conditions at each time step.
The time step is dt=0.001, leading to 500 time steps to reach T=0.5.
The exact solution for verification is u(x,t) = 1 - x.
Compute the numerical solution u(x, T=0.5) on the specified grid.
Save the solution to "solution_agent_heat_06.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_heat_06.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
Compute and print the maximum absolute error and the L2 error against the exact solution evaluated on the same x grid at T=0.5.
