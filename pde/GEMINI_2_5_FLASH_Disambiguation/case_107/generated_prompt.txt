The ODE system dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t) will be solved.
The ODE system dI/dt = delta*E - epsilon*I will be solved.
The ODE system dH/dt = theta*I - phi*H will be solved.
The time domain for the solution is t in [0.0, 50.0].
The parameter alpha is 1.2.
The parameter beta is 1.0.
The parameter gamma is 0.5.
The parameter delta is 0.8.
The parameter epsilon is 0.7.
The parameter theta is 0.9.
The parameter phi is 0.4.
The initial condition for E at t=0.0 is 0.5.
The initial condition for I at t=0.0 is 0.2.
The initial condition for H at t=0.0 is 0.1.
The numerical method for time integration is Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step dt is 0.01.
The number of time steps Nt is 5000.
The full state vector will be computed at all time points t_n = t0 + n*dt for n=0..Nt.
The solution will be saved to "solution_molk_006.npz".
The "solution_molk_006.npz" file will contain a 1D array 't' of length Nt+1.
The "solution_molk_006.npz" file will contain a 2D array 'Y' with shape [Nt+1, n_state].
The columns of the 'Y' array will be ordered as [E, I, H].
The "solution_molk_006.npz" file will contain the parameter scalars.
Line plots of each state vs t will be saved as "solution_molk_006.png".
The final state values at T will be printed.
The minimum and maximum values of each state over time will be printed.
