Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The spatial domain is x in [0, 1).
The unknown field is u(x,t).
The parameter nu is 1.0.
The parameter rho is 2.0.
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx=512 points.
The spatial grid points x_i are defined as x_i = 0 + i*dx for i=0..Nx-1, where dx = (1-0)/Nx.
Use a fixed time step dt=0.001.
Perform Nt=1000 time steps.
The final time T is dt * Nt.
Implement the numerical solution using Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
  (A) Diffusion half-step (duration dt/2):
      Transform u to Fourier space using FFT to get u_hat(k).
      The wave numbers k are 2*pi*fftfreq(Nx, d=dx).
      Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
      Transform u_hat back to real space using IFFT to get u, taking the real part.
  (B) Reaction full-step (duration dt):
      For each grid point, update u using the exact solution for the logistic ODE du/dt = rho*u*(1-u).
      The exact update is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
  (C) Diffusion half-step (duration dt/2):
      Repeat the process described in step (A).
Compute the solution u at the final time T on the grid.
Save the computed solution to a file named "solution_pdebench_reacdiff_nu1_rho2.npz".
The .npz file must contain the 1D arrays x and u, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) to a file named "solution_pdebench_reacdiff_nu1_rho2.png".
Report the minimum value of u at T.
Report the maximum value of u at T.
Report the mean value of u at T.
Report the discrete L2 norm sqrt(sum(u^2)*dx) at T.
