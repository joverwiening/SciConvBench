The task is to numerically solve the 2D Poisson equation u_xx + u_yy = f(x,y) on the domain (x,y) in [0,1] x [0,1].
The source term is f(x,y) = sin(pi*x) + cos(2*pi*y).
Dirichlet boundary conditions u=0 are applied on all four edges of the domain.
The spatial discretization will use a uniform grid with Nx=Ny=120 intervals in each direction.
This results in (Nx+1) by (Ny+1) grid points, including boundary points.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The PDE will be discretized using the standard 5-point stencil, which is 2nd-order accurate.
The resulting sparse linear system for the interior nodes will be solved using a sparse direct solver.
The steady-state solution u(x,y) on the 2D grid must be computed.
The solution data will be saved to a file named "solution_agent_poisson_08.npz".
This NPZ file will contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and the scalar values dx and dy.
A heatmap or contour plot of u(x,y) will be saved as "solution_agent_poisson_08.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed to the console.
