The task is to numerically solve the 1D inviscid conservation law u_t = -k*∂_x( (1/3)*u^3 ).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method will use a uniform periodic spatial grid with Nx=1024 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization is a conservative finite-volume method with Rusanov flux for f(u)=(1/3)u^3.
The time integration method is SSP-RK2.
The time step is determined using a CFL number of 0.2.
The maximum absolute value of the flux derivative, max|f'(u)|, is estimated as max|u^2|.
Given the initial condition, max|u| is 0.5, so max|f'| is estimated as 0.25.
The initial time step dt0 is calculated as CFL*dx/max|f'|.
The number of time steps Nt is ceil(T/dt0), and the final time step dt is T/Nt.
The initial cell averages u_j^0 are set to the value of the initial condition evaluated at the grid point x_j, i.e., u_j^0 = u(x_j, 0).
