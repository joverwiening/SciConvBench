The task ID is agent_diffusion_01.
Solve the one-dimensional diffusion PDE u_t = ∂/∂x( D(x) * u_x ) numerically.
The unknown field is u(x,t).
The diffusion coefficient is D(x) = 0.1*(1 + x).
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.5].
The initial condition is u(x,0) = sin(pi*x).
The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0.
Use a uniform spatial grid with Nx=300 intervals, resulting in Nx+1=301 grid points.
The spatial step size is dx = (1-0)/Nx.
The grid points are x_i = 0 + i*dx for i=0, ..., Nx.
Use a time step dt = 0.001.
The total number of time steps is 500.
For spatial discretization, use a conservative 2nd-order finite difference scheme in flux form.
Define D_i = D(x_i).
Define face values D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior grid points i=1, ..., Nx-1, the discrete diffusion operator is (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
For time integration, use the Implicit Euler method: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
Solve the resulting sparse linear system at each time step.
Compute the solution u(x, T=0.5) on the defined grid.
Save the solution to a NumPy .npz file named "solution_agent_diffusion_01.npz".
The .npz file must contain the 1D arrays x and u, and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_diffusion_01.png".
Print the minimum value of u(x,T), the maximum value of u(x,T), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
