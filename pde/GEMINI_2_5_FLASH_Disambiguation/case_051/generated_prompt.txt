The task is to numerically solve the 1D Klein-Gordon equation u_tt - (1.0)^2*u_xx + (3.0)^2*u = 0.
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0,0.8].
The initial condition is u(x,0)=cos(2*pi*x) and u_t(x,0)=0.
The exact solution for verification is u(x,t)=cos(2*pi*x)*cos(sqrt((1.0*2*pi)^2 + (3.0)^2)*t).
Use a uniform periodic grid with Nx=512 points on [0,1), so dx = 1/Nx.
The wave speed c is 1.0, derived from the u_xx coefficient.
Calculate dt0 = 0.9*dx/c.
Determine Nt = ceil(T/dt0), where T=0.8.
Set dt = T/Nt to ensure the final time is hit exactly.
For spatial discretization, use 2nd-order central differences with wrap-around for u_xx.
For time integration, use the Leapfrog method for u_tt, including the mass term +m^2*u at time n.
Initialize the simulation using a Taylor start, including the -m^2*u0 term.
Compute the numerical solution u(x, T=0.8) on the grid.
Save the solution to "solution_agent_kg_04.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_kg_04.png".
Print the minimum value of u(x,T), the maximum value of u(x,T), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the maximum absolute error and the L2 error against the exact solution evaluated on the same x grid at T.
