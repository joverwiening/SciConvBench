The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The parameter nu is 2.0.
The spatial domain for x is [0, 1).
The final simulation time T is 1.0.
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
A uniform spatial grid with Nx=512 points must be used.
Given the domain [0, 1) and Nx=512, the spatial step dx is (1-0)/512 = 1/512.
The grid points x_i are defined as x_i = i*dx for i=0..Nx-1.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), solve exactly in Fourier space.
First, compute u_hat(k) by taking the FFT of u.
The wave numbers k are defined as k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Then, compute u by taking the IFFT of u_hat and taking the real part.
For the advection full-step (B), solve the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is calculated as F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
Update u_new[j] using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated max speed is 1.0.
Calculate the number of time steps Nt = ceil(T/dt0).
Reset dt = T/Nt to ensure the final time T is hit exactly.
The calculated dt0 is 0.4 * (1/512) / 1.0 = 0.4/512.
The calculated Nt is ceil(1.0 / (0.4/512)) = 1280.
The final dt is 1.0 / 1280.
Compute u at the final time T on the grid.
