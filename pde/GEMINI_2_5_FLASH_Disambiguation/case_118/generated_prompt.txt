Solve the 1D KdV-type equation u_t + (q**2)*u_xxx + u*u_x = 0 numerically.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.2].
The parameter q is 0.1.
The initial condition is u(x,0) = cos(2*pi*x).
The number of spatial grid points is Nx = 512.
The spatial grid points x_i are defined as x_i = i*dx for i=0..Nx-1, where dx = (1-0)/Nx.
Compute the solution u(x,T=0.2) on this periodic grid.
Save the solution data to a file named "solution_molk_017.npz".
The "solution_molk_017.npz" file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values T, dx, Nx, and q.
Save a line plot of u(x,T=0.2) as "solution_molk_017.png".
Print the minimum value of u at T=0.2.
Print the maximum value of u at T=0.2.
Print the mean value of u at T=0.2.
Print the discrete L2 norm of u at T=0.2, calculated as sqrt(sum(u^2)*dx).
