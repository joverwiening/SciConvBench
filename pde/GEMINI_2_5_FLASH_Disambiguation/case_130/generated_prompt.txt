The 1D nonlinear convection-diffusion equation u_t = -q1*∂_x( sin(u) ) + (q2/pi)*u_xx will be solved numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 0.5].
The parameters are q1 = 1.0 and q2 = 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
A uniform periodic spatial grid will be used with Nx=1024 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The convection term -q1*∂_x(sin(u)) will be discretized using a conservative finite-volume Rusanov flux.
The Rusanov flux will use a wave speed alpha=max|cos(u)|.
The diffusion term (q2/pi)*u_xx will be discretized using 2nd-order central differences.
Time integration will be performed using the SSP-RK2 method.
The time step will be determined using a CFL number of 0.2.
The advective time step is dt_adv = 0.2*dx/1.
The diffusive time step is dt_diff = 0.2*dx^2/(q2/pi).
The raw time step dt is min(dt_adv, dt_diff).
The number of time steps Nt is ceil(T/dt), where T=0.5.
The final time step dt is T/Nt to ensure the simulation ends exactly at T.
