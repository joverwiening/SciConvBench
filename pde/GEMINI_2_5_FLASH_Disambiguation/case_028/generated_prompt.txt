The task is to numerically solve a 1D Diffusion-Reaction Partial Differential Equation.
The unknown field is u(x,t).
The PDE is u_t = 0.05*u_xx - 1.0*u + sin(pi*x).
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The diffusion coefficient D is 0.05.
The reaction rate k is 1.0.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0)=0.
The spatial discretization will use 2nd-order central differences for diffusion terms on a uniform grid.
The time integration will use a 1st-order deterministic IMEX scheme.
The diffusion term will be treated implicitly using backward Euler.
The reaction term will be treated explicitly using forward Euler.
At each time step, the equation (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) will be solved, where L is the discrete Laplacian and R(u) is the reaction term.
A sparse direct solver will be used at each time step.
The number of spatial intervals Nx is 300.
The time step dt is 0.001.
The total number of time steps is 1000.
The solution u(x, T=1.0) will be computed on the grid.
The solution will be saved to a file named "solution_agent_diffusion_reaction_06.npz".
The npz file will contain 1D arrays x and u, and scalar metadata T, dx, and dt.
A line plot of u(x,T) will be saved as "solution_agent_diffusion_reaction_06.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T will be printed to the console.
