Numerically solve the Allen-Cahn PDE u_t = (0.01)^2*(u_xx + u_yy) + u - u^3.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions on u for both x and y.
The time domain is t in [0,0.2].
The parameter epsilon is 0.01.
The initial condition is u(x,y,0)=0.1*cos(2*pi*x)*cos(2*pi*y).
Use a uniform grid for spatial discretization with Nx=Ny=256.
The spatial discretization for u_xx+u_yy is a 5-point Laplacian.
The time integration method is semi-implicit: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
Solve a sparse linear system at each time step.
Apply boundary indexing consistent with periodic boundary conditions.
The time step is dt=0.0002, resulting in 1000 steps to reach T=0.2.
Compute u(x,y,T=0.2) on the 2D grid.
Save the solution to "solution_agent_allen_cahn_04.npz".
The .npz file must contain 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T, and scalar metadata T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_allen_cahn_04.png".
