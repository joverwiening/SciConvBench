The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square, setting u on the boundary to match the exact solution u(x,y)=x.
The spatial domain is discretized using a uniform grid with Nx=Ny=100 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points including boundaries.
The grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny, where dx=dy=1/Nx.
The Laplace equation is discretized using the standard 5-point stencil, which is 2nd-order accurate.
The resulting sparse linear system for the interior nodes is solved using a sparse direct solver, such as scipy.sparse.linalg.spsolve.
The steady-state solution u(x,y) is computed on the 2D grid.
The computed solution, along with the x and y grid arrays and metadata dx, dy, is saved to a file named "solution_agent_laplace_03.npz".
The saved u array has shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
A heatmap or contour plot of u(x,y) is saved as "solution_agent_laplace_03.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm (sqrt(sum(u^2)*dx*dy)) are printed to the console.
The maximum absolute error and the L2 error between the computed solution and the reference solution u(x,y)=x, evaluated on the same grid, are computed and printed to the console.
