The task is to numerically solve the 1D inviscid conservation law u_t = -k*∂_x( cos(u) ).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 0.2].
The parameter k is set to 1.0.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
A closed-form reference solution is not required for verification.
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization uses a conservative finite-volume Rusanov flux for the flux function f(u)=cos(u).
The wave speed alpha for the Rusanov flux is max|sin(u)|, which is bounded by 1.
Time integration is performed using the SSP-RK2 method.
The time step is determined using a CFL number of 0.2, such that dt0 = CFL*dx/1.0.
The total number of time steps Nt is calculated as ceil(T/dt0), and the final time step dt is T/Nt.
