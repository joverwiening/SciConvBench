The task is to numerically solve the 2D Darcy flow PDE: -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The unknown field is u(x,y).
The spatial domain is (x,y) in (0,1) x (0,1).
The coefficient function is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The scalar parameter beta is 0.1.
Dirichlet boundary conditions are applied: u = 0 on the entire boundary ∂((0,1) x (0,1)).
A uniform Cartesian grid is used with N=128 intervals in each direction.
The grid spacing is dx = dy = 1/N.
Grid points are defined as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
The PDE is discretized using 2nd-order finite differences with variable coefficients.
Face-centered harmonic averaging is used for the coefficients.
For interior nodes (i=1..N-1, j=1..N-1), the discretization is: -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Face coefficients are harmonic means, for example, a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
The resulting sparse linear system Au=b for the interior unknowns is assembled.
The linear system is solved using the Conjugate Gradient (CG) method.
The CG solver tolerance is 1e-10 (relative residual).
A Jacobi preconditioner may be used.
The solution u(x,y) is computed on the full (N+1) x (N+1) grid, including boundaries.
The solution is saved to "solution_pdebench_darcy_beta0p1.npz".
The .npz file contains the 1D arrays x and y, the 2D array u (shape [N+1, N+1]), and the scalars beta, N, and dx.
A heatmap or contour plot of u(x,y) is saved as "solution_pdebench_darcy_beta0p1.png".
The minimum value of u, the maximum value of u, and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system are printed to standard output.
