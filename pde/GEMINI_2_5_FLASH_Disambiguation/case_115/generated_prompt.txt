The task is to numerically solve a 1D linear wave / Klein–Gordon-type equation for the unknown field u(x,t).
The partial differential equation is u_tt + (q2**2)*(q1**4)*u = (q1**2)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameters are q1 = 1.0 and q2 = 0.5.
The boundary conditions are periodic: u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t) for all t.
The initial condition for u is u(x,0) = sin(2*pi*x).
The initial condition for u_t is u_t(x,0) = 0.
The number of spatial grid points is Nx = 256.
The spatial discretization will use Fourier spectral derivatives (FFT).
The time integration will use the RK4 method.
The time step size is dt = 0.0005.
The number of time steps is Nt = 2000.
The simulation will compute u(x,T=1.0) on the periodic grid.
The results will be saved to "solution_molk_014.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, q1, q2.
A line plot of u(x,T) will be saved as "solution_molk_014.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T will be printed to the console.
