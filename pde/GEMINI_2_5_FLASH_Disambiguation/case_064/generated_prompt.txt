The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is (x,y) in [0,1] x [0,1].
The boundary conditions are Dirichlet: u(x,0)=0, u(x,1)=sin(2*pi*x), u(0,y)=0, u(1,y)=0.
The numerical method involves discretizing the PDE on a uniform grid using the standard 5-point stencil, which is 2nd-order accurate.
The grid will have Nx=Ny=100 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points including boundaries.
The grid spacing will be dx=dy=1/Nx.
The grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The resulting sparse linear system for the interior nodes will be solved using a sparse direct solver.
The exact solution for verification is u(x,y)=sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi).
The steady-state solution u(x,y) on the 2D grid must be computed.
The computed solution and grid data must be saved to "solution_agent_laplace_08.npz".
The "solution_agent_laplace_08.npz" file must contain 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]), and scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) must be saved as "solution_agent_laplace_08.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) must be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, must also be computed and printed.
