The task is to solve the 2D Poisson equation u_xx + u_yy = f(x,y) numerically.
The function f(x,y) is defined as (1 - pi^2)*exp(x)*sin(pi*y).
The spatial domain is a square (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges, setting u on the boundary to match the exact solution u(x,y)=exp(x)*sin(pi*y).
The numerical method involves discretizing the Laplacian operator using the standard 5-point stencil, which is 2nd-order accurate.
The resulting sparse linear system for the interior nodes must be solved using a sparse direct solver.
The grid will use Nx=Ny=120 uniform intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points including boundaries.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0 to Nx and y_j=j*dy for j=0 to Ny.
The steady-state solution u(x,y) must be computed on this 2D grid.
The computed solution, along with grid data, must be saved to "solution_agent_poisson_04.npz".
This NPZ file must contain 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]), and scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) must be saved as "solution_agent_poisson_04.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) must be printed to the console.
The maximum absolute error and the L2 error between the computed solution and the reference exact solution (u(x,y)=exp(x)*sin(pi*y)) evaluated on the same grid must also be computed and printed.
