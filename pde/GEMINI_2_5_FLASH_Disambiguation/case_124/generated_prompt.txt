The task ID is molk_023.
The PDE is u_t = q1*u_xx + q2*(u**2)*(1-u)**2.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 2.0.
The boundary condition is u(0,t)=u(1,t) for all t.
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
The number of spatial grid points Nx is 512.
The spatial grid points are x_i = 0 + i*dx for i=0..Nx-1, where dx = (1-0)/Nx.
The time integration method is Explicit RK4.
The time step size dt is 0.0005.
The simulation should compute u(x,T=1.0) on the periodic grid.
The solution should be saved to "solution_molk_023.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, q1, q2.
A line plot of u(x,T) should be saved as "solution_molk_023.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T should be printed.
No closed-form reference solution is required, so error computation against a reference solution is not needed.
