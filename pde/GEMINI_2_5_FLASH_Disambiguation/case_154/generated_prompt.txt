The task ID is pdebench_burgers_nu4em3.
The PDE is the 1D Viscous Burgers equation: u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The parameter nu is 0.004.
The spatial domain is x in [0, 1).
The boundary conditions are periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
The final simulation time T is 1.0.
A uniform spatial grid will be used with Nx=512 points.
Given the domain [0, 1) and periodicity, dx = (1-0)/Nx = 1/512.
The grid points are x_i = i*dx for i=0, ..., Nx-1.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps:
  (A) Diffusion half-step (duration dt/2):
      Compute the Fourier transform of u: u_hat(k) <- FFT(u).
      The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
      Update u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
      Compute the inverse Fourier transform: u <- IFFT(u_hat), taking the real part.
  (B) Advection full-step (duration dt) for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0:
      Use a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
      Define f(u)=0.5*u^2.
      For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), calculate the flux F:
        alpha = max(abs(u_left), abs(u_right)).
        F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
      For each cell j, calculate F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
      Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
      Replace u with u_new after the advection substep.
  (C) Diffusion half-step (duration dt/2):
      Repeat the same procedure as in substep (A).
The time step dt will be determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated max speed is 1.0.
Calculate the number of time steps Nt = ceil(T/dt0).
Reset dt = T/Nt to ensure the simulation ends exactly at T.
Compute the solution u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_burgers_nu4em3.npz".
The .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu4em3.png".
Print the minimum value of u at T, the maximum value of u at T, the discrete mean value of u at T, and the discrete L2 norm sqrt(sum(u^2)*dx) of u at T.
