The task is to numerically solve the 2D wave equation u_tt = c^2 * (u_xx + u_yy) where c=1.0.
The spatial domain is [0,1) x [0,1) with periodic boundary conditions in both x and y.
The temporal domain is [0, 0.5].
The initial condition is u(x,y,0) = cos(2*pi*x)*cos(2*pi*y) and u_t(x,y,0) = 0.
The reference exact solution is u(x,y,t) = cos(2*pi*x)*cos(2*pi*y)*cos(1.0*2*pi*sqrt(2)*t).
Use a uniform periodic grid with Nx=Ny=128 points on [0,1) x [0,1).
The grid spacing is dx = dy = 1/Nx.
Employ 2nd-order central differences with wrap-around for spatial discretization.
Use 2nd-order central differences in time (leapfrog scheme).
Initialize the time integration using a Taylor start with the periodic Laplacian.
Determine the time step dt by first calculating dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) where T=0.5.
The final time step dt is T/Nt to ensure the simulation ends exactly at T=0.5.
Compute the numerical solution u(x,y,T=0.5) on the defined 2D grid.
Save the solution to a file named "solution_agent_wave_19.npz".
This NPZ file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and the scalar metadata T, dx, dy, dt.
Generate and save a heatmap or contour plot of u(x,y,T) as "solution_agent_wave_19.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at time T.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the reference exact solution evaluated on the same grid at time T.
