The PDE to be solved is u_t = 0.2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The temporal domain is t in [0,0.2].
The initial condition is u(x,y,0) = sin(2*pi*x)*sin(pi*y).
Homogeneous Dirichlet boundary conditions are applied on all boundaries (x=0, x=1, y=0, y=1).
The numerical solution will use a uniform grid with Nx=60 and Ny=60 intervals, resulting in 61x61 grid points.
The spatial discretization will use the 5-point Laplacian for second-order accuracy.
The time integration will use Implicit Euler (backward Euler) with a time step dt=0.001 for 200 steps.
The final solution u(x,y,T=0.2) will be computed on the specified grid.
The exact solution for verification is u(x,y,t) = exp(-0.2*((2*pi)^2 + (pi)^2)*t) * sin(2*pi*x)*sin(pi*y).
The solution will be saved to "solution_agent_heat_10.npz" as a dictionary containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T), and metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) will be saved as "solution_agent_heat_10.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed.
The maximum absolute error and L2 error against the exact solution evaluated on the same grid at T will be computed and printed.
