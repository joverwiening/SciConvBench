The task is to numerically solve the 2D wave equation u_tt = (1.0)^2 * (u_xx + u_yy) for u(x,y,t).
The spatial domain is [0,1] x [0,1] and the time domain is [0,1.0].
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y) and u_t(x,y,0)=0.
The reference exact solution for verification is u(x,y,t)=cos(1.0*sqrt(2)*pi*t)*sin(pi*x)*sin(pi*y).
A uniform spatial grid is used on [0,1] x [0,1] with Nx=120 and Ny=120 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The spatial discretization uses the 5-point Laplacian for ∇²u.
The time integration uses a 2nd-order central difference scheme for u_tt.
The time step dt is chosen such that CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9, where c=1.0.
Specifically, calculate dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)), then set Nt = ceil(T/dt0) and dt = T/Nt to hit the final time T=1.0 exactly.
The first time step for u is computed using a Taylor start with the initial velocity.
Boundary nodes are set to 0 at each time step to enforce Dirichlet boundary conditions.
Compute the numerical solution u(x,y,T=1.0) on the specified 2D grid.
Save the solution to "solution_agent_wave_07.npz" as a dictionary containing 1D arrays x, y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_wave_07.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) of the solution at T.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the reference exact solution evaluated on the same grid at T.
