The task ID is pdebench_reacdiff_nu2_rho10.
The PDE category is 1D Reaction–Diffusion (logistic reaction, periodic).
The unknown field is u(x,t).
The PDE to solve numerically is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 10.0.
The boundary condition is periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A closed-form reference solution is not required.
The spatial grid is a uniform periodic grid with Nx=512 points on [0,1).
The spatial step size dx is (1-0)/Nx = 1/512.
The spatial grid points are x_j = j*dx for j=0,...,Nx-1.
The time grid uses a fixed time step dt=0.001.
The number of time steps Nt is T/dt = 1.0/0.001 = 1000.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space:
    Compute u_hat(k) by taking the Fast Fourier Transform (FFT) of u.
    Compute k as 2*pi*fftfreq(Nx, d=dx).
    Update u_hat(k) by multiplying it with exp(-nu*k^2*(dt/2)).
    Compute u by taking the Inverse Fast Fourier Transform (IFFT) of u_hat, and take the real part.
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho * u * (1 - u):
    Update u at each grid point using the exact solution: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (same as A).
Compute u(x,T=1.0) on the periodic grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu2_rho10.npz".
The .npz file must contain the arrays: x (1D length Nx), u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) to a file named "solution_pdebench_reacdiff_nu2_rho10.png".
Report (print to console) the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
