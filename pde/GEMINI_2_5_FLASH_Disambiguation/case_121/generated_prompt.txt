The PDE to be solved is u_t = q1*u_xx + q2*u*(1-u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The number of spatial grid points is Nx = 512.
The spatial discretization uses uniform intervals with dx = (1-0)/Nx.
The grid points are x_i = 0 + i*dx for i=0..Nx-1.
The time step size is dt = 0.001.
The numerical method for time integration is Strang splitting.
The diffusion term (q1*u_xx) is handled using a spectral method (FFT).
The reaction term (q2*u*(1-u)) is solved exactly.
The final solution u(x,T=1.0) on the periodic grid must be computed.
The solution data must be saved to "solution_molk_020.npz".
The saved npz file must contain the arrays x (1D length Nx) and u (1D length Nx).
The saved npz file must contain the scalars T, dx, Nx, q1, and q2.
A line plot of u(x,T) must be saved as "solution_molk_020.png".
The minimum value of u at T must be printed.
The maximum value of u at T must be printed.
The mean value of u at T must be printed.
The discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
