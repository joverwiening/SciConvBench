The task is to numerically solve the 2D diffusion PDE u_t = 0.1 * u_xx + 0.01 * u_yy.
The spatial domain is [0,1] x [0,1] and the time domain is [0,0.2].
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y).
The boundary conditions are Dirichlet u=0 on all domain boundaries (x=0, x=1, y=0, y=1).
The numerical method uses a uniform grid with Nx=Ny=60 intervals in x and y, meaning 61 grid points in each spatial dimension including endpoints.
The spatial discretization uses a standard 5-point Laplacian, where the x-second derivative term is scaled by Dx=0.1 and the y-second derivative term is scaled by Dy=0.01.
The time integration method is Implicit Euler with a time step dt=0.001, for a total of 200 steps to reach T=0.2.
The exact solution for verification is u(x,y,t)=exp(-( 0.1+0.01 )*pi^2*t)*sin(pi*x)*sin(pi*y).
The final solution u(x,y,T=0.2) on the 2D grid must be computed.
The solution must be saved to "solution_agent_diffusion_03.npz" containing 1D arrays x, y, and a 2D array u (shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T), along with metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_diffusion_03.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The maximum absolute error and L2 error against the exact solution evaluated on the same grid must also be computed and printed.
