The task is to numerically solve the 1D advection PDE u_t + beta * u_x = 0 for the unknown field u(x,t).
The spatial domain for x is [0, 1) with periodic boundary conditions u(0,t) = u(1,t) for all t.
The final time for the simulation is T = 2.0.
The parameter beta is 0.7.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The numerical solution will be computed on a uniform spatial grid with Nx = 512 points.
Given the spatial domain [0, 1) and Nx, the grid points x_i are defined as x_i = 0 + i*dx for i=0..Nx-1, where dx = (1-0)/Nx.
The spatial discretization for u_x will use a 1st-order upwind finite difference, with the upwind direction determined by the sign of beta.
Time integration will use the explicit forward Euler method.
The time step dt will be determined using a CFL number of 0.5, such that dt = CFL * dx / abs(beta).
The number of time steps Nt will be calculated as ceil(T/dt), and then dt will be reset to T/Nt to ensure the final time T is hit exactly.
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
The computed solution u at the final time T on the grid must be saved.
A file named "solution_pdebench_advection_beta0p7.npz" must be saved, containing the arrays x (1D length Nx) and u (1D length Nx), and the scalars beta, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_advection_beta0p7.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T must be printed.
The maximum absolute error and the L2 error between the computed solution and the reference solution (evaluated on the same x grid) at time T must also be computed and printed.
