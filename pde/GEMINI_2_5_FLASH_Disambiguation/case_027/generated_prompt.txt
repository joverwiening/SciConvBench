The PDE to solve is u_t = 0.01*(u_xx + u_yy) + 2.0*u*(1 - u).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,1.0].
The diffusion coefficient D is 0.01.
The reaction rate r is 2.0.
The boundary conditions are zero Neumann on all boundary edges (∂u/∂n = 0).
The initial condition is u(x,y,0)=0.2 + 0.05*cos(2*pi*x)*cos(2*pi*y).
The spatial discretization uses a uniform grid with Nx=Ny=120 intervals, resulting in Nx+1 by Ny+1 grid points.
The spatial step sizes are dx=dy=1/Nx.
The 5-point Laplacian is used for diffusion.
The time integration method is a 1st order deterministic IMEX scheme.
Diffusion is treated implicitly using backward Euler.
Reaction is treated explicitly using forward Euler.
The time integration step is (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where L is the discrete Laplacian and R(u) is the reaction term.
A sparse direct solver is used at each time step.
Zero Neumann boundary conditions are implemented using ghost nodes with mirror values.
The time step size is dt=0.001, leading to Nt=1000 steps.
The simulation computes u(x,y,T=1.0) on the 2D grid.
The solution is saved to "solution_agent_diffusion_reaction_05.npz".
The NPZ file contains 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) is saved as "solution_agent_diffusion_reaction_05.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T are printed to the console.
