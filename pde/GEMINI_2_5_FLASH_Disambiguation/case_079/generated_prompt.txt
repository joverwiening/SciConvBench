The task is to numerically solve the 2D Poisson equation u_xx + u_yy = f(x,y) on a square domain.
The function f(x,y) is -((3*pi)^2 + (2*pi)^2)*sin(3*pi*x)*cos(2*pi*y).
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges, setting u on the boundary to match the exact solution u(x,y)=sin(3*pi*x)*cos(2*pi*y).
The numerical method uses a uniform grid with Nx=Ny=120 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points.
The grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny, where dx=dy=1/Nx.
The spatial discretization uses the standard 5-point stencil (2nd-order accurate) for the Laplacian operator.
The resulting sparse linear system for the interior nodes is solved using a sparse direct solver.
The computed steady-state solution u(x,y) on the 2D grid must be saved.
The solution data must be saved to a file named "solution_agent_poisson_06.npz".
This NPZ file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and the scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) must be saved as "solution_agent_poisson_06.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) must be printed to the console.
The maximum absolute error and the L2 error between the computed solution and the exact solution u(x,y)=sin(3*pi*x)*cos(2*pi*y), evaluated on the same grid, must also be computed and printed.
