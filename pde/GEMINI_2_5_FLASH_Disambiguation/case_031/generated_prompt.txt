The task is to numerically solve the 1D heat equation u_t = 0.5 * u_xx.
The spatial domain is x in [0, 1] and the time domain is t in [0, 0.2].
The initial condition is u(x,0) = sin(2*pi*x).
The numerical method uses a uniform grid on [0,1] with Nx=200 intervals, resulting in Nx+1 grid points.
The spatial discretization uses 2nd-order central differences for u_xx in the interior.
The time integration uses the Crank–Nicolson method for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step using the exact solution u(0,t)=0 and u(1,t)=0.
The time step is dt=0.0005, leading to 400 time steps.
The exact solution for verification is u(x,t) = exp(-0.5*(2*pi)^2*t) * sin(2*pi*x).
Compute the numerical solution u(x, T=0.2) on the grid.
Save the solution to "solution_agent_heat_02.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_heat_02.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.2.
Compute and print the maximum absolute error and the L2 error against the exact solution evaluated on the same x grid at T=0.2.
