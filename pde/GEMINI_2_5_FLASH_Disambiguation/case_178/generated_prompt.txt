The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 10.0.
The parameter rho is 2.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid will be uniform and periodic with Nx = 512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx = (1-0)/Nx.
The time grid will use a fixed time step dt = 0.001.
The total number of time steps Nt will be T/dt = 1.0/0.001 = 1000.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps: (A) Diffusion half-step, (B) Reaction full-step, (C) Diffusion half-step.
For the diffusion half-step (duration dt/2), solve exactly in Fourier space.
Transform u to Fourier space: u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Transform back to real space: u = IFFT(u_hat), taking the real part.
For the reaction full-step (duration dt), solve exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_reacdiff_nu10_rho2.npz".
The .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho2.png".
Report (print) the minimum, maximum, mean, and the discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T.
