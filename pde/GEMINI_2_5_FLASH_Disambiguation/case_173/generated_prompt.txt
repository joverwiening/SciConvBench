The task is to numerically solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) for the unknown field u(x,t).
The spatial domain for x is [0, 1) with periodic boundary conditions u(0,t) = u(1,t).
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The parameters are nu = 0.5 and rho = 10.0.
The numerical solution will use a uniform spatial grid with Nx=512 points.
Given the [0, 1) domain and periodicity, dx = (1-0)/Nx = 1/512, and x_i = i*dx for i=0..Nx-1.
The time integration will use a fixed time step dt=0.001 for Nt=1000 steps, resulting in a final time T = Nt*dt = 1.0.
The numerical method is Strang splitting for each full time step dt:
First, a diffusion half-step of duration dt/2 is solved exactly in Fourier space.
The steps are: compute u_hat(k) = FFT(u); compute k = 2*pi*fftfreq(Nx, d=dx); update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)); compute u = IFFT(u_hat) and take the real part.
Second, a reaction full-step of duration dt is solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, another diffusion half-step of duration dt/2 is performed, identical to the first diffusion half-step.
After completing all time steps, compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz".
This NPZ file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho10.png".
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
