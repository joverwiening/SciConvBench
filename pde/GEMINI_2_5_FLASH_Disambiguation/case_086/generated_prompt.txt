The PDE to be solved is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0,1.0].
The wave speed parameter is c = 1.0.
The exact solution for verification is u(x,t)=cos(2*pi*x)*cos(2*pi*1.0*t).
The spatial discretization will use a uniform periodic grid with Nx=512 points on [0,1).
The spatial step size is dx = 1/Nx.
The second-order central difference with periodic wrap-around will be used for u_xx.
The time integration will use a second-order central difference in time for u_tt.
The initial conditions are derived from the exact solution: u(x,0) = cos(2*pi*x) and u_t(x,0) = 0.
A Taylor start with the periodic Laplacian will be used to compute u(x,dt).
The time step dt will be determined by first calculating dt0 = 0.9*dx/c.
Then, Nt = ceil(T/dt0) will be computed, and the final dt = T/Nt will be used to ensure the final time T=1.0 is hit exactly.
The CFL condition c*dt/dx ≤ 0.9 must be satisfied.
The numerical solution u(x, T=1.0) will be computed on the grid.
The solution will be saved to "solution_agent_wave_05.npz" containing arrays: x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
A line plot of u(x,T) will be saved as "solution_agent_wave_05.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T will be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid, will also be computed and printed.
