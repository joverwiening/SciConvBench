The task is to numerically solve the 1D wave equation u_tt = (1.0)^2 * u_xx + sin(pi*x)*sin(2*pi*t).
The spatial domain is x in [0,1] and the time domain is t in [0,1.0].
Dirichlet boundary conditions are applied at x=0 and x=1, where u=0.
The initial conditions are u(x,0)=0 and u_t(x,0)=0.
A uniform grid is used on [0,1] with Nx=400 intervals, resulting in Nx+1 grid points.
The spatial step size is dx = 1/Nx.
The wave speed c is 1.0.
The time step dt is determined by first calculating dt0 = 0.9*dx/c.
Then, Nt is calculated as ceil(T/dt0), where T=1.0.
The final time step dt is set to T/Nt to ensure the simulation ends exactly at T.
Spatial derivatives (u_xx) are approximated using 2nd-order central differences in the interior.
Time integration uses the standard 2nd-order central difference scheme (leapfrog / Störmer–Verlet).
The simulation is initialized using a Taylor start for u^1: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0).
Boundary nodes are set to the prescribed Dirichlet value of 0 at every time step.
The solution u(x, T=1.0) on the grid is to be computed.
The computed solution is saved to "solution_agent_wave_10.npz", containing 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_wave_10.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T are printed to the console.
