The task is to numerically solve the Lotka–Volterra predator–prey ordinary differential equation system.
The ODE system is dx/dt = alpha*x - beta*x*y and dy/dt = delta*x*y - gamma*y.
The time domain is t in [0.0, 30.0].
The parameters are alpha = 1.5, beta = 1.0, gamma = 3.0, and delta = 1.0.
The initial conditions at t=0.0 are x(0.0) = 1.0 and y(0.0) = 1.0.
The numerical method for time integration is the Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step is dt=0.01, resulting in Nt=3000 steps to reach the final time exactly.
Compute the full state vector at all time points t_n = t0 + n*dt for n=0..Nt.
Save the solution to "solution_molk_008.npz".
The "solution_molk_008.npz" file must contain the 1D array t (length Nt+1), the 2D array Y (shape [Nt+1, n_state]) with columns ordered as [x, y], and the parameter scalars.
Save line plots of each state vs t as "solution_molk_008.png".
Print the final state values at T.
Print the minimum and maximum values of each state over time.
