The task is to numerically solve the biharmonic partial differential equation ∇^4 u = f(x,y) on the domain (x,y) in [0,1] x [0,1].
The function f(x,y) is defined as 4*pi^4*sin(pi*x)*sin(pi*y).
The boundary conditions are simply-supported on all boundaries, meaning u=0 and (Δu)=0 on the boundary.
The numerical method involves introducing an auxiliary field v = Δu, then solving two sequential Poisson problems.
The first Poisson problem is Δv = f with Dirichlet boundary condition v=0 on the boundary.
The second Poisson problem is Δu = v with Dirichlet boundary condition u=0 on the boundary.
Each Poisson problem will be discretized using the standard 5-point Laplacian on a uniform grid.
The linear system resulting from each Poisson problem will be solved using a sparse direct solver.
The grid will have Nx=Ny=120 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points.
The grid spacing will be dx=dy=1/Nx.
The grid points will be x_i=i*dx for i=0 to Nx and y_j=j*dy for j=0 to Ny.
The steady-state solution u(x,y) will be computed on this 2D grid.
The computed solution will be saved to a file named "solution_agent_other_05_biharmonic.npz".
This NPZ file will contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx and dy.
A heatmap/contour plot of u(x,y) will be saved as "solution_agent_other_05_biharmonic.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed to the console.
The maximum absolute error and the L2 error between the computed solution and the exact solution u_exact(x,y)=sin(pi*x)*sin(pi*y) (evaluated on the same grid) will also be computed and printed.
