The task is to numerically solve the 2D heat equation u_t = 0.1 * (u_xx + u_yy) on the spatial domain (x,y) in [0,1] x [0,1] for time t in [0,0.2].
The initial condition is u(x,y,0) = cos(pi*x)*cos(pi*y).
The boundary conditions are zero Neumann (du/dn = 0) on all boundaries, implemented using ghost nodes with mirror values for second-order accuracy.
The numerical method uses a uniform spatial grid with Nx=Ny=60 intervals, resulting in 61 grid points in each spatial direction including endpoints.
The spatial discretization uses a 5-point Laplacian for interior nodes.
The time integration uses the Implicit Euler method with a time step dt=0.001, for a total of 200 steps to reach T=0.2.
The exact solution for verification is u(x,y,t) = exp(-2*0.1*pi^2*t) * cos(pi*x)*cos(pi*y).
The output requirements are to compute the numerical solution u(x,y,T=0.2) on the 2D grid.
Save the solution to a file named "solution_agent_heat_12.npz" containing the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_heat_12.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution evaluated on the same grid at T.
