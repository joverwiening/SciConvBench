The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is [0,1] x [0,1].
The boundary conditions are Dirichlet: u(x,0)=0, u(x,1)=1, u(0,y)=0, and u(1,y)=0.
Discretize the PDE on a uniform grid using the standard 5-point stencil (2nd-order accurate).
Use Nx=100 and Ny=100 intervals in each direction, resulting in (Nx+1)x(Ny+1) grid points.
The grid spacing is dx=dy=1/Nx.
The grid points are x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Solve the resulting sparse linear system for the interior nodes using a sparse direct solver.
Compute the steady-state solution u(x,y) on the entire 2D grid.
Save the solution data to a file named "solution_agent_laplace_09.npz".
The .npz file must contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar values dx and dy.
Save a heatmap or contour plot of u(x,y) as "solution_agent_laplace_09.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm calculated as sqrt(sum(u^2)*dx*dy).
