Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx = 1.0/Nx.
Use a fixed time step dt = 0.001.
The total number of time steps is Nt = 1000, so that T=1.0 is reached exactly.
Employ Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps:
First, perform a diffusion half-step of duration dt/2.
Solve the diffusion half-step exactly in Fourier space.
Transform u to Fourier space: u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Transform back to real space: u <- IFFT(u_hat), taking the real part.
Second, perform a reaction full-step of duration dt.
Solve the reaction term du/dt = rho * u * (1 - u) exactly pointwise for each grid point.
Update u using the exact solution: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, perform another diffusion half-step of duration dt/2, identical to the first diffusion half-step.
Compute the final solution u(x,T=1.0) on the periodic grid.
Save the solution data to a file named "solution_pdebench_reacdiff_nu5_rho10.npz".
The .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu5_rho10.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the mean value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
