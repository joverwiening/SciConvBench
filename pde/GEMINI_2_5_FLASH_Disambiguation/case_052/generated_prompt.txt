The task is to numerically solve the 2D Klein-Gordon equation for u(x,y,t).
The PDE is u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0.
The spatial domain is [0,1] x [0,1] and the time domain is [0,0.8].
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y) and u_t(x,y,0)=0.
The reference exact solution is u(x,y,t)=cos(sqrt((1.0)^2*(2*pi^2) + (1.0)^2)*t)*sin(pi*x)*sin(pi*y).
Use a uniform grid with Nx=Ny=256 intervals, resulting in Nx+1 by Ny+1 grid points.
The spatial discretization uses a 5-point Laplacian for u_xx+u_yy.
Time integration uses a 2nd-order central difference scheme for u_tt.
The time step dt is determined by first calculating dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)), where c=1.0 is derived from the PDE.
Then, Nt = ceil(T/dt0) is calculated, and dt = T/Nt is set to hit the final time T=0.8 exactly.
The initialization uses a Taylor start method, incorporating the Laplacian and mass terms.
Compute u(x,y,T=0.8) on the 2D grid.
Save the solution to "solution_agent_kg_05.npz" as a NumPy archive containing 1D arrays x, y, and a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), along with scalar metadata T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_kg_05.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute and print the maximum absolute error and the L2 error against the reference solution evaluated on the same grid.
