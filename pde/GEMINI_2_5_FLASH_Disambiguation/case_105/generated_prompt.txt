Solve the ordinary differential equation du/dt = a*t*sin(u) numerically.
The unknown field is u(t).
The time domain is t in [0.0, 5.0].
The parameter a is 0.8.
The initial condition is u(0.0) = 0.5.
Use the Classical 4th-order Runge–Kutta (RK4) method for time integration.
Use a fixed time step size dt = 0.001.
The number of time steps is Nt = 5000.
Compute u(t) at all time points t_n = t0 + n*dt for n=0..Nt.
Save the solution to a file named "solution_molk_004.npz".
The "solution_molk_004.npz" file must contain the 1D array t (length Nt+1), the 1D array u (length Nt+1), and the parameter scalars.
Save a line plot of u(t) vs t as "solution_molk_004.png".
Print the value of u(T) where T is the final time.
Print the minimum value of u over the time grid.
Print the maximum value of u over the time grid.
No closed-form reference solution is required.
Do not compute error metrics against an exact solution.
