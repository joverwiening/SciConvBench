The task ID is pdebench_burgers_nu2em3.
The PDE is the 1D Viscous Burgers equation: u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The parameter nu is 0.002.
The spatial domain for x is [0, 1).
The boundary conditions are periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
The final time T is 1.0.
A uniform spatial grid will be used with Nx=512 points.
Given the spatial domain [0, 1) and periodicity, dx = (1-0)/Nx = 1/512.
The grid points x_i are defined as x_i = 0 + i*dx for i=0..Nx-1.
The numerical method uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step, (B) Advection full-step, (C) Diffusion half-step.
For the diffusion half-step (duration dt/2), the solution is obtained exactly in Fourier space.
First, compute u_hat(k) = FFT(u).
The wave numbers k are calculated as k = 2*pi*fftfreq(Nx, d=dx).
Then, update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, compute u = IFFT(u_hat) and take the real part.
For the advection full-step (duration dt), the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 is solved using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is calculated as F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
The updated cell value u_new[j] is calculated as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
The time step dt is determined using a CFL condition.
Set CFL=0.4 based on an estimated maximum speed of 1.0 for the given initial condition.
Calculate an initial time step dt0 = CFL*dx/1.0.
Determine the number of time steps Nt = ceil(T/dt0).
Reset the time step dt = T/Nt to ensure the final time T is hit exactly.
Compute the solution u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_burgers_nu2em3.npz".
This NPZ file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu2em3.png".
Report the minimum value of u, the maximum value of u, the discrete mean value of u (mean(u)), and the discrete L2 norm (sqrt(sum(u^2)*dx)) at time T by printing them to the console.
