The task is to numerically solve a 1D convection-diffusion PDE.
The PDE is u_t = -q1*∂_x( 0.5*u^2 ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.1.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
Grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The nonlinear flux f(u)=0.5*u^2 is discretized using a conservative finite-volume or finite-difference scheme with the Rusanov (local Lax–Friedrichs) flux.
The diffusion term u_xx is discretized using 2nd-order central differences.
Time integration uses the SSP-RK2 (Heun) method.
The time step dt is fixed and calculated based on stability criteria.
First, calculate D_eff = q2/pi.
Then, calculate dt_conv = CFL * dx / max|u0| with CFL=0.4 and max|u0|=1.
Next, calculate dt_diff = 0.4 * dx^2 / D_eff.
Set dt0 = min(dt_conv, dt_diff).
The number of time steps Nt is ceil(T/dt0), where T=0.5.
The final time step dt is T/Nt to ensure the simulation ends exactly at T.
