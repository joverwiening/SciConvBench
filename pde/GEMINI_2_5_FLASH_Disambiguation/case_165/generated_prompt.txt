The task is to numerically solve the 1D Compressible Navier-Stokes equations without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
where m = rho*v, total energy E = p/(Gamma-1) + 0.5*rho*v^2, and viscous stress sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1] and the temporal domain is t in [0, 0.2].
The parameters are Gamma = 1.6666666666666667, eta = 1e-08, and zeta = eta.
The initial condition is a Riemann (shock-tube) problem with a discontinuity at x=0:
For x < 0: rho_L = 0.445, v_L = 0.698, p_L = 3.528.
For x >= 0: rho_R = 0.5, v_R = 0.0, p_R = 0.571.
Boundary conditions are transmissive (zero-gradient) at x=-1 and x=1 for the conservative variables.
The numerical method uses a uniform finite-volume grid with Nx=800 cells.
The spatial discretization uses cell-centered finite volumes, evolving conservative variables U = [rho, m, E].
The grid cell centers are x_j = -1 + (j + 0.5) * dx for j = 0, ..., Nx-1, where dx = (1 - (-1)) / Nx.
The convective flux is computed using the Rusanov (local Lax-Friedrichs) numerical flux.
Viscous terms are computed using centered differences for v_x and interface averaging for sigma.
The temporal discretization uses 2-stage SSP-RK2 (Heun's method).
The time step dt is chosen as dt = min(dt_conv, dt_visc).
dt_conv = CFL * dx / max_j( |v_j| + c_j ), where c_j = sqrt(Gamma * p_j / rho_j) is the speed of sound.
dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The CFL number for dt_conv is 0.5.
The last time step is adjusted to hit the final time T exactly.
The solution rho(x,T), v(x,T), p(x,T) should be computed on the cell centers.
The solution should be saved to "solution_pdebench_cns1d_sod6_eta1em8_outflow.npz" as a NumPy archive containing arrays: x (1D length Nx), rho (1D), v (1D), p (1D), and scalars: Gamma, eta, zeta, T, dx, CFL.
A 3-panel line plot of rho, v, and p versus x at time T should be saved as "solution_pdebench_cns1d_sod6_eta1em8_outflow.png".
The minimum and maximum values of rho and p, and the mean of rho over the domain, should be printed to the console.
