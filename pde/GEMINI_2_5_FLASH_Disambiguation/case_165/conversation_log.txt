Q: What numerical method should be used for the spatial and temporal discretization?
A: For spatial discretization, use a uniform finite-volume grid with Nx=800 cells, evolving conservative variables U = [rho, m, E]. The convective flux should use the Rusanov (local Lax-Friedrichs) numerical flux. Viscous terms should be computed using centered differences for v_x and interface averaging for sigma.

For temporal discretization, use 2-stage SSP-RK2 (Heun's method). The time step dt should be chosen as dt = min(dt_conv, dt_visc), where dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ), adjusting the last step to hit the final time T exactly.
