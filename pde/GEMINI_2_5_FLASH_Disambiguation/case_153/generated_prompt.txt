The task is to numerically solve the 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The parameter nu is 4.0.
The spatial domain for x is [0, 1).
The boundary conditions are periodic, specifically u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
The final simulation time T is 1.0.
The spatial grid is uniform with Nx=512 points.
Given the spatial domain [0, 1) and Nx points, dx = (1-0)/Nx. The grid points are x_i = 0 + i*dx for i=0..Nx-1.
The numerical method uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), solve exactly in Fourier space.
First, compute u_hat(k) = FFT(u).
Then, define k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, compute u = IFFT(u_hat) and take the real part.
For the advection full-step (B), solve the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, calculate F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After computing all u_new[j], replace u with u_new for the advection substep.
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated max speed is 1.0.
Calculate the number of time steps Nt = ceil(T/dt0).
Reset dt = T/Nt to ensure the final time T is hit exactly.
Compute u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_burgers_nu4.npz".
This .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu4.png".
The plot should show u on the y-axis and x on the x-axis.
Report (print to console) the minimum value of u, the maximum value of u, the discrete mean value of u (mean(u)), and the discrete L2 norm (sqrt(sum(u^2)*dx)) at the final time T.
