The task is to numerically solve the 1D wave equation u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1] and the time domain is t in [0,0.25].
Dirichlet boundary conditions u=0 are applied at x=0 and x=1.
The initial condition is u(x,0)=sin(4*pi*x) and u_t(x,0)=0.
The reference exact solution is u(x,t)=cos(1.0*4*pi*t)*sin(4*pi*x).
A uniform grid on [0,1] with Nx=800 intervals (Nx+1 points) must be used for spatial discretization.
The spatial step size dx is 1/Nx.
Second-order central differences must be used for u_xx in the interior.
Time integration must use the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt must be chosen for stability such that CFL = c*dt/dx <= 0.9, where c=1.0.
Specifically, calculate dt0 = 0.9*dx/c, then Nt = ceil(T/dt0), and finally dt = T/Nt to hit the final time exactly.
Initialization must use u(x,0)=u0(x) and compute u(x,dt) via the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, set boundary nodes to the prescribed value at every time step.
Compute u(x, T=0.25) on the grid.
Save "solution_agent_wave_13.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_13.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error and L2 error against the reference solution evaluated on the same x grid.
