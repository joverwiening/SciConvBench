The task is to numerically solve the SIR epidemiology model ODE system.
The ODE system is dS/dt = -beta * S * I, dI/dt = beta * S * I - gamma * I, dR/dt = gamma * I.
The time domain is t in [0.0, 40.0].
The parameters are beta = 0.5 and gamma = 0.1.
The initial conditions at t=0.0 are S(0.0) = 0.99, I(0.0) = 0.01, and R(0.0) = 0.0.
The numerical method is Classical 4th-order Runge–Kutta (RK4) with a fixed time step.
The time step is dt = 0.01, resulting in Nt = 4000 steps to reach the final time exactly.
Compute the full state vector [S, I, R] at all time points t_n = t0 + n*dt for n=0..Nt.
Save the solution to "solution_molk_005.npz".
The NPZ file must contain a 1D array 't' of length Nt+1, a 2D array 'Y' of shape [Nt+1, 3] with columns ordered as [S, I, R], and the scalar parameters beta and gamma.
Save line plots of each state (S, I, R) versus time 't' to "solution_molk_005.png".
Print the final state values of S, I, and R at T=40.0.
Print the minimum and maximum values of S, I, and R over the entire simulation time.
