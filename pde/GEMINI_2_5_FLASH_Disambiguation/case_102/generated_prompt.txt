Solve the ODE numerically.
The ODE is du/dt = a*exp(-t) + b.
The time domain is t in [0.0, 5.0].
The parameter a is 2.0.
The parameter b is -0.5.
The initial condition is u(0.0) = 0.0.
The exact solution for verification is u(t) = u0 + a*(1 - exp(-t)) + b*t, where u0 = u(0).
Use Classical 4th-order Runge–Kutta (RK4) for time integration.
Use a fixed time step size dt=0.001.
The number of time steps is Nt=5000.
Compute u(t) at all time points t_n = t0 + n*dt for n=0..Nt.
Save "solution_molk_001.npz" containing arrays: t (1D length Nt+1), u (1D length Nt+1), and the parameter scalars.
Save a line plot of u(t) vs t as "solution_molk_001.png".
Print the value of u(T), the minimum value of u, and the maximum value of u over the time grid.
Compute and print the maximum absolute error and the L2 error of the numerical solution compared to the exact solution evaluated on the same time grid.
