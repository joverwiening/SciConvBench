The task is to numerically solve the 2D Poisson equation u_xx + u_yy = f(x,y) on the domain (x,y) in [0,1] x [0,1].
The function f(x,y) is -2*pi^2*cos(pi*x)*cos(pi*y).
Dirichlet boundary conditions are applied on all four edges of the domain, setting u on the boundary to match the exact solution u(x,y)=cos(pi*x)*cos(pi*y).
The numerical solution will use a uniform grid with Nx=Ny=120 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points including boundaries.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The spatial discretization of the Laplacian operator will use the standard 5-point stencil, which is 2nd-order accurate.
The resulting sparse linear system for the interior nodes will be solved using a sparse direct solver.
The computed steady-state solution u(x,y) on the 2D grid must be saved.
A file named "solution_agent_poisson_05.npz" must be saved, containing the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and the scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) must be saved as "solution_agent_poisson_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm (calculated as sqrt(sum(u^2)*dx*dy)) must be printed to the console.
The maximum absolute error and the L2 error between the computed numerical solution and the provided exact solution u(x,y)=cos(pi*x)*cos(pi*y) (evaluated on the same grid) must also be computed and printed to the console.
All trigonometric functions should use radians.
Exponentiation should be interpreted as '^' in mathematical expressions and '**' in Python code.
