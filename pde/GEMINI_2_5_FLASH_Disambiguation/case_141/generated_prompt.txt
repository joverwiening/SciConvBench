The task is to numerically solve the 1D Advection PDE u_t + beta * u_x = 0.
The unknown field is u(x,t).
The parameter beta is 4.0.
The spatial domain is [0, 1).
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The final time T for the simulation is 2.0.
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
Use a uniform spatial grid with Nx=512 points.
Calculate dx as (1-0)/Nx.
The grid points x_i are a+i*dx for i=0..Nx-1.
Use 1st-order upwind finite difference for the spatial discretization of u_x, with the upwind direction determined by the sign of beta.
Use Explicit forward Euler for time integration.
Set the CFL number to 0.5.
Calculate the time step dt = CFL * dx / abs(beta).
Calculate the number of time steps Nt = ceil(T/dt).
Reset dt = T/Nt to ensure the final time T is hit exactly.
Compute the numerical solution u at the final time T on the grid.
Save the solution to a file named "solution_pdebench_advection_beta4.npz".
The .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta4.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) of u at T.
Compute the reference solution on the same x grid at time T.
Compute and print the maximum absolute error between the numerical and reference solutions.
Compute and print the L2 error between the numerical and reference solutions.
