Solve the 1D Compressible Navier–Stokes equations numerically.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE is given in conservative form.
Let m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
Let the viscous stress be sigma = (zeta + 4/3*eta) * v_x.
Assume zeta = eta.
The PDE system is: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.2].
The number of spatial intervals Nx is 800.
The number of grid points is Nx+1 = 801.
The spatial step dx = (1 - (-1)) / Nx = 2 / 800 = 0.0025.
The grid points are x_i = -1 + i*dx for i=0..Nx.
The parameter Gamma = 1.6666666666666667.
The parameter eta = 1e-08.
The parameter zeta = 1e-08.
Boundary conditions are transmissive/outflow (zero-gradient) at x=-1 and x=1.
The initial condition is a Riemann (shock-tube) problem with a discontinuity at x=0.
For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 10.0.
For x ≥ 0: rho_R = 1.0, v_R = 0.0, p_R = 0.1.
The Courant-Friedrichs-Lewy (CFL) number for the simulation is 0.5.
Compute rho(x,T), v(x,T), p(x,T) on the cell centers.
Save "solution_pdebench_cns1d_sod7_eta1em8_outflow.npz" containing arrays: x (1D length Nx), rho (1D), v (1D), p (1D), and scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel line plot of rho, v, p vs x at T as "solution_pdebench_cns1d_sod7_eta1em8_outflow.png".
Print the minimum and maximum values of rho and p.
Print the mean of rho over the domain.
