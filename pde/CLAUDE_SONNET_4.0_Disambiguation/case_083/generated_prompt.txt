Solve the wave equation u_tt = (0.5)^2 * u_xx numerically on the domain x in [0,1], t in [0,1.0].
Use the wave speed parameter c = 0.5.
Apply Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0 for all t.
Set initial conditions u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.
Use a uniform spatial grid on [0,1] with Nx = 400 intervals, giving Nx+1 = 401 grid points including both endpoints.
Calculate dx = 1/Nx = 1/400 = 0.0025.
Apply 2nd-order central differences for u_xx in the interior points.
Use 2nd-order central difference in time for u_tt (leapfrog/Störmer-Verlet method).
Choose dt0 = 0.9*dx/c = 0.9*0.0025/0.5 = 0.0045 for stability.
Set Nt = ceil(1.0/dt0) and then dt = 1.0/Nt to hit the final time T = 1.0 exactly.
Initialize u(x,dt) using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0 where v0 = u_t(x,0) = 0.
Set boundary nodes to zero at every time step to enforce Dirichlet conditions.
Compute the solution u(x,T) at the final time T = 1.0.
Save "solution_agent_wave_02.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_02.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
Compare against the exact solution u(x,t) = cos(0.5*2*pi*t)*sin(2*pi*x).
