Solve the 1D compressible Navier-Stokes PDE system numerically using finite volume method.
Use uniform grid with Nx=800 cells on domain [-1,1].
Place cell centers at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1 where dx = 2/Nx.
Apply Rusanov (local Lax-Friedrichs) numerical flux for convective terms.
Apply centered differences for viscous terms.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Use CFL number of 0.4 for time step calculation based on standard stability practices.
Set Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.
Apply transmissive/outflow (zero-gradient) boundary conditions at x=-1 and x=1.
Initialize with Riemann shock-tube condition: discontinuity at x=0 with left state (rho=1.0, v=0.0, p=2.0) and right state (rho=0.125, v=0.0, p=0.2).
Integrate from t=0 to T=0.2.
Compute final solution rho(x,T), v(x,T), p(x,T) on cell centers.
