Solve the wave equation u_tt = u_xx numerically on a periodic domain.
Use the wave equation u_tt = (1.0)^2 * u_xx where c = 1.0.
Set the spatial domain as x in [0,1) with periodic boundary conditions.
Set the time domain as t in [0,1.0].
Apply periodic boundary conditions: u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t).
Use initial conditions u(x,0) = cos(2*pi*x) and u_t(x,0) = 0.
Create a uniform periodic grid with Nx = 512 points on [0,1) with no duplicated endpoint.
Calculate dx = 1/Nx.
Use 2nd-order central difference with periodic wrap-around for spatial discretization of u_xx.
Use 2nd-order central difference in time for temporal discretization of u_tt.
Set dt0 = 0.9*dx/c to satisfy CFL condition c*dt/dx ≤ 0.9.
Calculate Nt = ceil(T/dt0) and then set dt = T/Nt so the final time T = 1.0 is hit exactly.
Initialize the time integration using Taylor start with the periodic Laplacian.
Compute the numerical solution u(x, T=1.0) on the grid.
Compare against the exact solution u(x,t) = cos(2*pi*x)*cos(2*pi*1.0*t).
Save "solution_agent_wave_05.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
