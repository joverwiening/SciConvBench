Solve the 1D inviscid conservation law u_t = -k*∂_x((1/3)*u^3) numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
Set k = 1.0.
Apply periodic boundary conditions where u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.5*sin(2*pi*x).
Create a uniform periodic grid with Nx = 1024 points on [0,1).
Set x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Use conservative finite-volume method with Rusanov flux for f(u) = (1/3)u^3.
Apply SSP-RK2 time integration.
Set CFL = 0.2 and estimate max|f'(u)| = max|u^2|.
With |u| <= 0.5 initially, set max|f'| <= 0.25.
Calculate dt0 = CFL*dx/max|f'|, Nt = ceil(T/dt0), and dt = T/Nt.
Use radians for trigonometric functions.
