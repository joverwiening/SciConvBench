Solve the 2D diffusion PDE u_t = ∇·(D(x,y)∇u) where D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The spatial domain is (x,y) in [0,1] x [0,1] and time domain is t in [0,0.1].
The initial condition is u(x,y,0) = sin(pi*x)*sin(pi*y).
The boundary conditions are Dirichlet u=0 on all four edges of the domain.
Use a uniform grid with Nx=Ny=80 intervals, so there are 81x81 grid points including endpoints.
The grid spacing is dx=dy=1/80=0.0125.
Grid points are x_i = i*dx for i=0,1,...,80 and y_j = j*dy for j=0,1,...,80.
Use conservative 2nd-order spatial discretization in flux form with arithmetic face averages for the diffusion coefficient.
For face averages use D_{i+1/2,j} = 0.5*(D_{i,j} + D_{i+1,j}) and D_{i,j+1/2} = 0.5*(D_{i,j} + D_{i,j+1}).
For interior nodes (i=1 to 79, j=1 to 79), discretize as (∇·(D∇u))_{i,j} ≈ (1/dx^2)[D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}(u_{i,j}-u_{i-1,j})] + (1/dy^2)[D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}(u_{i,j}-u_{i,j-1})].
Use implicit Euler time integration with dt=0.0005 for 200 time steps to reach T=0.1.
At each time step solve the linear system (I - dt*L)u^{n+1} = u^n where L is the discrete diffusion operator.
Compute the solution u(x,y,T=0.1) on the full 2D grid.
Save "solution_agent_diffusion_04.npz" containing 1D arrays x and y, 2D array u with shape (81,81) where u[j,i] = u(x[i],y[j]) at T=0.1, and scalars T=0.1, dx=0.0125, dy=0.0125, dt=0.0005.
Save a heatmap plot of u(x,y,T=0.1) as "solution_agent_diffusion_04.png".
Print the minimum value of u, maximum value of u, and discrete L2 norm sqrt(sum(u^2)*dx*dy) at T=0.1.
