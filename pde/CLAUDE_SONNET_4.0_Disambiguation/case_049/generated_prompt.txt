Solve the Klein-Gordon PDE u_tt - (0.5)²*u_xx + (2.0)²*u = 0 numerically.
The spatial domain is x in [0,1] and temporal domain is t in [0,1.0].
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Use initial conditions u(x,0)=sin(2*pi*x) and u_t(x,0)=0.
The exact solution for verification is u(x,t)=cos(sqrt((0.5*2*pi)^2 + (2.0)^2)*t)*sin(2*pi*x).
Use uniform spatial grid with Nx=600 intervals giving Nx+1=601 grid points including both endpoints.
Set dx=1/Nx and x_i=i*dx for i=0 to Nx.
Apply 2nd-order central differences for spatial derivative u_xx.
Use 2nd-order central difference in time (leapfrog) for u_tt with explicit treatment of +m^2*u term at time level n.
Set wave speed c=0.5 and mass coefficient m=2.0.
Choose dt0 = 0.9*dx/c, then set Nt = ceil(T/dt0) and dt = T/Nt to hit final time T=1.0 exactly.
Initialize using Taylor expansion from u0 and v0 including the -m^2*u0 term.
Compute the solution u(x,T=1.0) on the grid.
Save "solution_agent_kg_02.npz" containing arrays x, u and scalars T, dx, dt.
