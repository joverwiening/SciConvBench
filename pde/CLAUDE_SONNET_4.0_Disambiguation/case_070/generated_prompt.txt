Solve the biharmonic PDE ∇^4 u = f(x,y) where f(x,y) = 4*pi^4*sin(pi*x)*sin(pi*y) on the domain [0,1] x [0,1].
Apply simply-supported boundary conditions: u=0 on all boundaries AND Δu=0 on all boundaries.
Use the method of introducing v = Δu to split into two Poisson problems.
First solve Δv = f with Dirichlet BC v=0 on the boundary.
Then solve Δu = v with Dirichlet BC u=0 on the boundary.
Use the standard 5-point Laplacian discretization for each Poisson solve on a uniform grid.
Use Nx=Ny=120 intervals in each direction creating a (Nx+1) by (Ny+1) grid including boundaries.
Set dx=dy=1/Nx and use x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Solve each Poisson system using a sparse direct solver like scipy.sparse.linalg.spsolve.
Save the solution arrays x (1D), y (1D), u (2D with shape (len(y), len(x))), dx, and dy to "solution_agent_other_05_biharmonic.npz".
Save a heatmap plot of u(x,y) as "solution_agent_other_05_biharmonic.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compute and print the max absolute error and L2 error against the exact solution u(x,y)=sin(pi*x)*sin(pi*y).
