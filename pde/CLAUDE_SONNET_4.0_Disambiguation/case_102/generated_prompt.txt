Solve the scalar ODE du/dt = a*exp(-t) + b numerically using the Classical 4th-order Runge-Kutta method.
The ODE has exponential forcing term a*exp(-t) and constant drift term b.
The time domain is [0.0, 5.0].
Set parameter a = 2.0.
Set parameter b = -0.5.
Set initial condition u(0) = 0.0.
Use fixed time step dt = 0.001 with Nt = 5000 steps to reach final time exactly.
Compute u(t) at all time points t_n = n*dt for n = 0 to Nt.
The exact solution for verification is u(t) = u0 + a*(1 - exp(-t)) + b*t where u0 = u(0).
Save results to "solution_molk_001.npz" containing arrays t (1D length Nt+1), u (1D length Nt+1), and parameter scalars a and b.
Save a line plot of u(t) vs t as "solution_molk_001.png".
Print the final value u(T), minimum value min(u), and maximum value max(u) over the time grid.
Compute and print the maximum absolute error and L2 error compared to the exact solution evaluated on the same time grid.
