Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the spatial domain [0, 1) with periodic boundary conditions.
Use parameters nu = 0.5 and rho = 2.0.
Apply the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points where dx = (1-0)/512 = 1/512 and x_i = 0 + i*dx for i = 0 to 511.
Use a time grid with fixed dt = 0.001 and Nt = 1000 steps so the final time T = 1.0.
Implement Strang splitting for each time step dt with three substeps: diffusion half-step (dt/2), reaction full-step (dt), diffusion half-step (dt/2).
For diffusion substeps, solve exactly in Fourier space by computing u_hat = FFT(u), setting k = 2*pi*fftfreq(Nx, d=dx), updating u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)), and taking u = real(IFFT(u_hat)).
For the reaction substep, solve the logistic ODE du/dt = rho*u*(1-u) exactly at each grid point using u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute the solution u at final time T on the grid.
Save "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing arrays x (1D length 512), u (1D length 512), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho2.png".
Print the final values of min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
