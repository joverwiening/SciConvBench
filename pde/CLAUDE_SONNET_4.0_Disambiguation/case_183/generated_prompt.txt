Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the spatial domain [0, 1) with periodic boundary conditions.
Use nu = 1.0 and rho = 5.0 as parameters.
Apply periodic boundary conditions where u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points where dx = (1-0)/512 = 1/512 and x_i = 0 + i*dx for i = 0 to 511.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so the final time T = 1.0.
Implement Strang splitting for each full time step dt with three substeps.
For diffusion half-steps, solve exactly in Fourier space by computing u_hat = FFT(u), setting k = 2*pi*fftfreq(Nx, d=dx), updating u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)), and taking u = real(IFFT(u_hat)).
For the reaction full-step, solve the logistic ODE du/dt = rho*u*(1-u) exactly pointwise using u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Apply the sequence: diffusion half-step (dt/2), reaction full-step (dt), diffusion half-step (dt/2) for each time step.
Compute the solution u at the final time T = 1.0 on the grid.
