Solve the Allen-Cahn PDE u_t = (0.02)^2*u_xx + u - u^3 on domain x in [0,1], t in [0,1.0].
Use epsilon = 0.02.
Apply initial condition u(x,0) = 0.05*sin(2*pi*x) + 0.02*sin(6*pi*x).
Apply boundary conditions u_x(0,t) = 0 and u_x(1,t) = 0 (zero Neumann at both boundaries).
Use uniform spatial grid with Nx = 800 intervals, so 801 grid points including both endpoints.
Set dx = (1-0)/800 = 1/800 and x_i = 0 + i*dx for i = 0,1,...,800.
Use 2nd-order central differences for u_xx.
Implement zero Neumann boundary conditions via ghost points by mirroring values.
Use semi-implicit time integration: (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
Use dt = 0.0005 for 2000 time steps to reach T = 1.0.
Solve the resulting linear system at each time step.
Compute the final solution u(x, T=1.0) on the grid.
Save "solution_agent_allen_cahn_03.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
