Solve the diffusion PDE u_t = ∂/∂x(D(x) * u_x) where D(x) = 0.1*(1 + x).
The spatial domain is x in [0,1] and temporal domain is t in [0,0.5].
The diffusion coefficient is D(x) = 0.1*(1+x).
The initial condition is u(x,0) = sin(pi*x).
The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0.
Use a uniform spatial grid with Nx=300 intervals, so there are 301 grid points including both endpoints.
The grid spacing is dx = (1-0)/300 = 1/300 and grid points are x_i = 0 + i*dx for i=0,1,...,300.
Use a conservative 2nd-order spatial discretization in flux form for (D(x) u_x)_x.
Define D_i = D(x_i) and face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior points i=1..299: ((D u_x)_x)_i ≈ (1/dx^2) * [D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1})].
Use implicit Euler time integration: (I - dt*L) u^{n+1} = u^n where L is the discrete diffusion operator.
Use dt = 0.001 for 500 time steps to reach T = 0.5.
Solve the sparse linear system at each time step.
Compute the solution u(x, T=0.5) on the grid.
Save "solution_agent_diffusion_01.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_diffusion_01.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
