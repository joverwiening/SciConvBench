Solve the Allen-Cahn PDE numerically using the following specifications.
The PDE is u_t = (0.01)^2*u_xx + u - u^3.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,0.5].
The parameter epsilon = 0.01.
The initial condition is u(x,0) = 0.1*cos(2*pi*x) + 0.05*sin(4*pi*x).
Use a uniform spatial grid with Nx = 800 intervals, so dx = (1-0)/800 = 1/800.
The grid points are x_i = 0 + i*dx for i = 0, 1, ..., 799.
Apply periodic boundary conditions where u and u_x are periodic at the boundaries.
Use 2nd-order central differences for the spatial derivative u_xx.
Use the semi-implicit time integration scheme: (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
Use dt = 0.0002, which gives 2500 time steps to reach T = 0.5.
Solve the resulting linear system at each time step.
Compute the solution u(x, T=0.5) on the spatial grid.
Save "solution_agent_allen_cahn_01.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_allen_cahn_01.png".
Print the minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.5.
