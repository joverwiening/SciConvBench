Solve the 1D linear reaction-diffusion PDE u_t = q1*u_xx + q2*u on domain x in [0,1) with periodic boundary conditions and t in [0,0.5].
Set parameters q1 = 0.01 and q2 = -1.0.
Use initial condition u(x,0) = sin(2*pi*x).
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use Nx = 256 grid points with dx = (1-0)/256 = 1/256 and x_i = 0 + i*dx for i = 0 to 255.
Use deterministic operator-splitting time integration with dt = 0.001 and Nt = 500 steps.
For each time step, first solve the diffusion substep (I - 0.5*dt*q1*L) u_tilde^{n+1} = (I + 0.5*dt*q1*L) u^n using Crank-Nicolson where L is the periodic 2nd-order Laplacian.
Then apply the reaction substep u^{n+1} = exp(q2*dt) * u_tilde^{n+1}.
Compute the solution u(x,T=0.5) on the periodic grid.
Save "solution_molk_021.npz" containing arrays x (1D length 256), u (1D length 256), and scalars T, dx, Nx, q1, q2.
Save a line plot of u(x,T) as "solution_molk_021.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.5.
Compute and print the max absolute error and L2 error versus the exact solution u(x,t) = exp(q2*t) * exp(-q1*(2*pi)^2*t) * sin(2*pi*x) evaluated on the same x grid.
