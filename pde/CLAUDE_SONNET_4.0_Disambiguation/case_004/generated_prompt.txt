Solve the 2D advection PDE u_t + (1.0)*u_x + (0.5)*u_y = 0 on domain [0,1) x [0,1) for t in [0,1.0].
Use parameters a = 1.0 and b = 0.5.
Apply initial condition u(x,y,0) = sin(2*pi*x)*cos(2*pi*y).
Use uniform periodic grid with Nx = Ny = 256 points on [0,1) x [0,1).
Set dx = dy = 1/Nx = 1/256.
Apply 1st-order upwind spatial discretization in both x and y directions.
Use Forward Euler time integration.
Calculate dt0 = 0.9 / (|a|/dx + |b|/dy) = 0.9 / (1.0/(1/256) + 0.5/(1/256)).
Set Nt = ceil(T/dt0) where T = 1.0.
Set dt = T/Nt to hit final time exactly.
Handle boundaries using periodic boundary conditions with appropriate indexing.
Compute solution u(x,y,T=1.0) at final time.
