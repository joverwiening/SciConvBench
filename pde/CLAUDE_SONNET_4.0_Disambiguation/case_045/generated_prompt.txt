Solve the 2D heat equation u_t = 0.05 * (u_xx + u_yy) on the domain x in [0,1] with Dirichlet boundaries and y in [0,1) with periodic boundaries for t in [0,0.3].
Use the initial condition u(x,y,0) = sin(pi*x)*cos(2*pi*y).
Apply Dirichlet boundary conditions u(0,y,t) = 0 and u(1,y,t) = 0.
Apply periodic boundary conditions in the y-direction.
Use a tensor grid with Nx=60 intervals in x (61 grid points including boundaries) and Ny=64 periodic points in y.
Set dx = 1/60 and dy = 1/64.
Use x_i = i*dx for i=0,1,...,60 and y_j = j*dy for j=0,1,...,63.
Apply 2nd-order central differences for spatial discretization.
Use implicit Euler time integration with dt = 0.001 for 300 time steps.
Compute the solution u(x,y,T=0.3) on the 2D grid.
Save "solution_agent_heat_16.npz" containing arrays x (1D), y (1D), u (2D with shape (64,61) where u[j,i] = u(x[i], y[j]) at T=0.3), and scalars T, dx, dy, dt.
Save a heatmap plot of u(x,y,T=0.3) as "solution_agent_heat_16.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T=0.3.
