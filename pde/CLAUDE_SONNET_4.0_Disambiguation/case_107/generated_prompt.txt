Solve the ODE system numerically using Classical 4th-order Runge-Kutta method with fixed step size.
The ODE system consists of three coupled equations for E(t), I(t), and H(t).
dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t)
dI/dt = delta*E - epsilon*I
dH/dt = theta*I - phi*H
The time domain is [0.0, 50.0].
The parameters are alpha = 1.2, beta = 1.0, gamma = 0.5, delta = 0.8, epsilon = 0.7, theta = 0.9, phi = 0.4.
The initial conditions are E(0) = 0.5, I(0) = 0.2, H(0) = 0.1.
Use time step dt = 0.01 with Nt = 5000 steps so the final time is hit exactly.
Compute the full state vector at all time points t_n = t0 + n*dt for n = 0 to Nt.
Save "solution_molk_006.npz" containing arrays t (1D length Nt+1) and Y (2D array shape [Nt+1, 3]) with columns ordered as [E, I, H], and the parameter scalars.
Save line plots of each state vs t as "solution_molk_006.png".
Print the final state values at T and the min/max of each state over time.
