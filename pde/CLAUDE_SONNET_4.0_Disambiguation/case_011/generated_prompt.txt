Solve the Allen-Cahn PDE u_t = (0.02)^2*(u_xx + u_yy) + u - u^3 on the domain (x,y) in [0,1] x [0,1] for t in [0,0.1].
Set epsilon = 0.02.
Use initial condition u(x,y,0) = tanh((0.25 - r)/(sqrt(2)*0.02)) where r = sqrt((x-0.5)^2 + (y-0.5)^2).
Apply Dirichlet boundary conditions u = 0 on all boundaries of the domain [0,1] x [0,1].
Use uniform grid with Nx = Ny = 300 intervals, giving 301 grid points in each direction including endpoints.
Use dx = dy = 1/300 and dt = 0.0001 for 1000 time steps.
Discretize spatially using 5-point Laplacian for u_xx + u_yy.
Use semi-implicit time integration: (u^{n+1} - u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
Solve the resulting sparse linear system at each time step.
Enforce Dirichlet boundary conditions by setting boundary nodes to zero at every time step.
Compute u(x,y,T=0.1) on the 2D grid.
Save "solution_agent_allen_cahn_05.npz" containing arrays x (1D), y (1D), u (2D with shape (len(y), len(x)) so u[j,i] = u(x[i], y[j]) at T), plus scalars T, dx, dy, dt.
Save heatmap plot of u(x,y,T) as "solution_agent_allen_cahn_05.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
