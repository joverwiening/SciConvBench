Solve the 1D advection PDE u_t + beta * u_x = 0 numerically.
Use beta = 4.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use the reference solution u(x,t) = u0((x - beta*t) mod 1) where u0(x) is the initial condition.
Set the spatial domain as [0,1) with periodic boundary conditions.
Use a uniform grid with Nx=512 points where dx=(1-0)/Nx=1/512 and x_i=i*dx for i=0..Nx-1.
Apply 1st-order upwind finite difference for u_x using the upwind direction determined by the sign of beta.
Use explicit forward Euler for time integration.
Set the time step using CFL=0.5 where dt = CFL * dx / abs(beta).
Calculate the number of time steps as Nt = ceil(T/dt) then reset dt = T/Nt to hit the final time T=2.0 exactly.
Compute u at the final time T on the grid.
Save "solution_pdebench_advection_beta4.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta4.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
