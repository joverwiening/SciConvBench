Solve the 1D Compressible Navier-Stokes equations numerically using finite volume method.
Use conservative form with variables rho (density), m (momentum), and E (total energy).
Set m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x with zeta = eta.
The PDE system is rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
Set spatial domain x in [-1, 1] and time domain t in [0, 0.5].
Use parameters Gamma = 1.6666666666666667, eta = 0.1, zeta = 0.1.
Apply periodic boundary conditions at x = -1 and x = 1.
Set initial conditions rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Use uniform finite-volume grid with Nx = 400 cells on [-1,1].
Set cell centers x_j = -1 + (j+0.5)*dx for j=0,...,399 with dx = 2/400 = 0.005.
Evolve conservative variables U = [rho, m, E] as cell averages.
Use equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to floor value 1e-12 if needed.
Compute convective flux F_conv(U) = [m, m^2/rho + p, (E+p)*v] with v = m/rho.
Use Rusanov numerical flux with interface wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Set numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute v_x using centered difference on cell-centered v values.
Calculate sigma = (zeta + 4/3*eta)*v_x at cell centers.
Approximate sigma at interfaces by averaging neighboring cell-centered values.
Add viscous flux F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Set total interface flux F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Choose time step each iteration using dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc) and adjust final step to hit T = 0.5 exactly.
Use CFL = 0.4 based on stability requirements for SSP-RK2 with Rusanov flux.
Implement periodic boundary conditions by wrapping indices.
Compute final solution rho(x,T), v(x,T), p(x,T) on cell centers at T = 0.5.
