Solve the advection PDE u_t + a(x)*u_x = 0 where a(x) = 1 + 0.5*sin(2*pi*x).
The spatial domain is [0,1) with periodic boundary conditions and temporal domain is [0,0.5].
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx = 1200 points where dx = 1/Nx.
Apply upwind spatial discretization with left-biased stencil since a(x) > 0 everywhere.
Use forward Euler time integration with dt chosen so max_x a(x) * dt / dx ≤ 0.9.
Set amax = 1.5, dt0 = 0.9*dx/amax, Nt = ceil(T/dt0), and dt = T/Nt to hit final time T = 0.5 exactly.
Compute the solution u(x,T) at the final time T = 0.5.
Save the results to "solution_agent_advection_03.npz" containing arrays x, u, and scalars T, dx, dt.
Create a line plot of u(x,T) and save as "solution_agent_advection_03.png".
Print the minimum value, maximum value, and discrete L2 norm sqrt(sum(u^2)*dx) of the final solution.
