Solve the 1D nonlinear convection-diffusion PDE: u_t = -q1*∂_x((1/3)*u^3) + (q2/pi)*u_xx.
Use spatial domain x in [0,1) with periodic boundary conditions and temporal domain t in [0,0.5].
Set parameters q1 = 1.0 and q2 = 0.05.
Apply initial condition u(x,0) = 0.5*sin(2*pi*x).
Use uniform periodic grid with Nx = 1024 points where x_j = j*dx for j = 0,...,Nx-1 and dx = 1/Nx.
Discretize the convection term ∂_x((1/3)u^3) using conservative finite-volume flux with Rusanov scheme.
Discretize the diffusion term u_xx using 2nd-order central differences.
Use SSP-RK2 for time integration.
Calculate time step using CFL = 0.2 where dt0 = CFL*dx/max|u^2| and dt_diff = 0.2*dx^2/(q2/pi), then set dt = min(dt0, dt_diff).
Set Nt = ceil(T/dt) and adjust dt = T/Nt.
Save solution to "solution_molk_027.npz" containing arrays x, u and scalars T, dx, Nx, q1, q2.
Save line plot of u(x,T) as "solution_molk_027.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T = 0.5.
