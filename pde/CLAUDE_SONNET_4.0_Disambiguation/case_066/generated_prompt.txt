Solve the Helmholtz equation u_xx + u_yy + k^2*u = f(x,y) numerically on the domain [0,1] x [0,1].
Set k = 5.0.
Set f(x,y) = (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y).
Apply Dirichlet boundary conditions u = 0 on all four boundaries.
Use a uniform grid with Nx = Ny = 120 intervals in each direction, creating (Nx+1) by (Ny+1) = 121 by 121 grid points.
Set dx = dy = 1/Nx = 1/120.
Define grid points as x_i = i*dx for i = 0 to Nx and y_j = j*dy for j = 0 to Ny.
Discretize the PDE using the 5-point Laplacian stencil on interior grid points.
Form a sparse linear system for the interior nodes.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution as "solution_agent_other_01_helmholtz.npz" containing arrays x (1D), y (1D), u (2D with shape (len(y), len(x))), and scalars dx, dy.
Save a heatmap plot of u(x,y) as "solution_agent_other_01_helmholtz.png".
Print the minimum value of u, maximum value of u, and discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compare against the exact solution u(x,y) = sin(pi*x)*sin(pi*y) evaluated on the same grid.
Print the maximum absolute error and L2 error versus the exact solution.
