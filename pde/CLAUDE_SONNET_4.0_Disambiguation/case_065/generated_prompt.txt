Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain [0,1] x [0,1].
Apply boundary conditions: u(x,0) = 0, u(x,1) = 1, u(0,y) = 0, u(1,y) = 0.
Use a uniform grid with Nx=Ny=100 intervals in each direction, creating a 101x101 grid of points.
Set dx=dy=1/100 and define grid points as x_i=i*dx for i=0..100, y_j=j*dy for j=0..100.
Discretize the Laplace equation using the standard 5-point stencil for interior grid points.
Apply the 5-point stencil: (u[i+1,j] + u[i-1,j] + u[i,j+1] + u[i,j-1] - 4*u[i,j])/dx^2 = 0.
Set up a sparse linear system for the interior nodes only.
Solve the resulting sparse linear system using scipy.sparse.linalg.spsolve.
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution to "solution_agent_laplace_09.npz" with arrays x, y, u and scalars dx, dy.
Ensure u is a 2D array with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]).
