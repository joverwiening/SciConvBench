Solve the 1D Cahn-Hilliard PDE numerically using Fourier pseudo-spectral method.
The PDE is u_t = -(0.01)^2*u_xxxx + ∂^2/∂x^2( u^3 - u ) with periodic boundary conditions.
The spatial domain is x in [0,1) and time domain is t in [0,0.05].
Set epsilon = 0.01 so the coefficient -(0.01)^2 = -epsilon^2 = -0.0001.
Use initial condition u(x,0) = 0.1*cos(2*pi*x) + 0.01*cos(6*pi*x).
Use Nx = 512 grid points with x_j = j/Nx for j = 0 to Nx-1.
Use dt = 1e-5 for 5000 time steps to reach T = 0.05.
Implement semi-implicit spectral time stepping with linear operator L(k) = (-epsilon^2*k^4 + k^2) treated implicitly.
Treat nonlinear term N(u) = ∂xx(u^3) explicitly.
Apply the update formula û^{n+1} = (û^n + dt * FFT[∂xx(u^3)]) / (1 - dt*L(k)) in Fourier space.
Apply 2/3 dealiasing by zeroing Fourier modes with |k| > (2/3)*k_max after computing FFT(u^3).
Compute the final solution u(x, T=0.05) on the grid.
Save "solution_agent_other_02_cahn_hilliard.npz" containing arrays x, u, and scalars T, dx, dt.
