Solve the 1D advection PDE u_t + beta * u_x = 0 numerically.
Use beta = 0.1.
Apply periodic boundary conditions where u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use the reference solution u(x,t) = u0((x - beta*t) mod 1) where u0(x) is the initial condition.
Create a uniform spatial grid on domain [0,1) with Nx=512 points and no duplicated endpoint.
Calculate dx = (1-0)/Nx = 1/512.
Set grid points as x_i = 0 + i*dx for i = 0 to Nx-1.
Apply 1st-order upwind finite difference for u_x using upwind direction based on sign of beta.
Use explicit forward Euler for time integration.
Set time step using CFL = 0.5 so dt = CFL * dx / abs(beta) = 0.5 * (1/512) / 0.1.
Calculate number of time steps as Nt = ceil(T/dt) where T = 2.0.
Reset dt = T/Nt to hit final time exactly.
Compute the solution u at final time T = 2.0 on the grid.
Save "solution_pdebench_advection_beta0p1.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta0p1.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at time T.
