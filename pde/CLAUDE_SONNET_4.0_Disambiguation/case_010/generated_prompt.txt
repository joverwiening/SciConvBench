Solve the Allen-Cahn PDE numerically using the following specification:

The PDE is u_t = (0.01)^2*(u_xx + u_yy) + u - u^3.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions in both directions.
The time domain is t in [0,0.2].
The parameter epsilon = 0.01.
The initial condition is u(x,y,0) = 0.1*cos(2*pi*x)*cos(2*pi*y).
Use a uniform grid with Nx = Ny = 256 grid points.
Since the domain is [0,1) with periodicity, interpret Nx as 256 grid points with no duplicated endpoint.
Set dx = (1-0)/256 = 1/256 and dy = 1/256.
Generate grid points as x_i = 0 + i*dx for i = 0 to 255 and y_j = 0 + j*dy for j = 0 to 255.
Use dt = 0.0002 for 1000 time steps to reach T = 0.2.
Apply spatial discretization using a uniform grid with 5-point Laplacian for u_xx + u_yy.
Use semi-implicit time integration: (u^{n+1} - u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
Solve a sparse linear system at each time step.
Apply periodic wrap-around indexing in both x and y directions without duplicating endpoints.
Compute u(x,y,T=0.2) on the 2D grid.
