Solve the 1D advection PDE u_t + beta * u_x = 0 numerically.
Use beta = 1.0.
Apply periodic boundary conditions where u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use the spatial domain [0,1) with Nx=512 grid points.
Calculate dx = (1-0)/Nx = 1/512.
Set grid points as x_i = 0 + i*dx for i = 0, 1, ..., Nx-1.
Apply 1st-order upwind finite difference for u_x using the upwind direction determined by the sign of beta.
Use explicit forward Euler for time integration.
Set CFL = 0.5 and calculate dt = CFL * dx / abs(beta) = 0.5 * (1/512) / 1.0.
Calculate Nt = ceil(T/dt) where T = 2.0.
Reset dt = T/Nt to hit the final time exactly.
Compute the solution u at final time T = 2.0.
Save "solution_pdebench_advection_beta1.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta1.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
