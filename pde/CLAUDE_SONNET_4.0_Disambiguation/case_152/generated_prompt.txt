Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 0.002.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0,1) with Nx=512 uniform grid points.
Calculate dx = (1-0)/Nx = 1/512.
Set grid points as x_i = 0 + i*dx for i = 0 to Nx-1.
Use final time T = 1.0.
Apply Strang splitting with CFL = 0.4 based on estimated max speed = 1.0.
Calculate dt0 = CFL*dx/1.0 = 0.4*dx.
Set Nt = ceil(T/dt0) and reset dt = T/Nt to hit final time exactly.
For each time step, perform diffusion half-step (dt/2) in Fourier space using u_hat(k) *= exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx).
Follow with advection full-step (dt) using finite-volume Rusanov flux: alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left) where f(u) = 0.5*u^2.
Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.
Complete with another diffusion half-step (dt/2).
Take real part after each inverse FFT operation.
Save "solution_pdebench_burgers_nu2em3.npz" containing arrays x, u and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu2em3.png".
Print min(u), max(u), mean(u), and L2 norm sqrt(sum(u^2)*dx) at final time T.
