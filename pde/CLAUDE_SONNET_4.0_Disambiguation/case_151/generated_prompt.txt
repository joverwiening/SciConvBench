Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 2.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0,1) with Nx=512 uniform grid points.
Calculate dx = 1.0/512.
Set grid points as x_i = i*dx for i=0..511.
Use Strang splitting for time integration with three substeps per time step.
For diffusion substeps, solve exactly in Fourier space using FFT.
Transform u_hat(k) = FFT(u), apply k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)) for each half-step.
Transform back u = real(IFFT(u_hat)).
For the advection substep, use finite-volume Rusanov flux with f(u) = 0.5*u^2.
Calculate interface flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Set alpha = max(abs(u_left), abs(u_right)) for each interface.
Update each cell: u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Use periodic indexing for boundary fluxes.
Set time step with CFL = 0.4, dt0 = CFL*dx/1.0.
Calculate Nt = ceil(T/dt0) and reset dt = T/Nt.
Run simulation to final time T = 1.0.
Save results to "solution_pdebench_burgers_nu2.npz" with arrays x, u and scalars nu, T, dx, dt, Nx, Nt.
Create line plot of u(x,T) and save as "solution_pdebench_burgers_nu2.png".
Print min(u), max(u), mean(u), and L2 norm sqrt(sum(u^2)*dx) at final time.
