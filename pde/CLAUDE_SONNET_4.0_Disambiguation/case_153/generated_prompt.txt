Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 4.0 as the viscosity parameter.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Set the initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0,1) with Nx = 512 grid points and dx = 1.0/512.
Set final time T = 1.0.
Use CFL = 0.4 to determine time step with dt0 = CFL*dx/1.0.
Calculate Nt = ceil(T/dt0) and reset dt = T/Nt for exact final time.
Implement Strang splitting with three substeps per time step.
For diffusion half-steps, solve exactly in Fourier space using FFT with k = 2*pi*fftfreq(Nx, d=dx) and multiply by exp(-nu*k^2*(dt/2)).
For advection full-step, use finite-volume Rusanov flux with f(u) = 0.5*u^2.
Calculate Rusanov flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left) where alpha = max(abs(u_left), abs(u_right)).
Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.
Save solution as "solution_pdebench_burgers_nu4.npz" containing arrays x, u and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu4.png".
Print min(u), max(u), mean(u), and L2 norm sqrt(sum(u^2)*dx) at final time T.
