Set parameter k = 1.0.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.

Create uniform periodic grid with Nx = 1024 points on [0,1).
Set grid points as x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Implement conservative finite-volume method with Rusanov flux for f(u) = 0.5*u^2.

Calculate time step using CFL = 0.2: dt0 = CFL*dx/max|u| with max|u| ≈ 1.
Set Nt = ceil(T/dt0), then dt = T/Nt.
Compute solution u(x,T=0.2) on the periodic grid.
