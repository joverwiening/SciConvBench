Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
Use nu = 0.5 and rho = 10.0 as parameters.
Apply periodic boundary conditions where u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use spatial domain [0,1) with Nx=512 grid points and dx=(1-0)/512=1/512.
Use time stepping with dt=0.001 and Nt=1000 steps for total time T=1.0.
Implement Strang splitting for each time step dt with three substeps.
For diffusion half-steps, solve exactly in Fourier space using FFT with k = 2*pi*fftfreq(Nx, d=dx) and update u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
For the reaction full-step, solve the logistic ODE exactly pointwise using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute the solution u at final time T=1.0 on the spatial grid.
Save "solution_pdebench_reacdiff_nu0p5_rho10.npz" containing arrays x, u and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho10.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
