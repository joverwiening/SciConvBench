Solve the 1D nonlinear reaction-diffusion PDE: u_t = q1*u_xx + q2*(u**a)*(1-u) with a=2.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
Set parameters q1 = 0.01, q2 = 2.0, a = 2.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.2 + 0.1*sin(2*pi*x).
Use Nx = 512 grid points for spatial discretization with dx = (1-0)/512 = 1/512.
Grid points are x_i = 0 + i*dx for i = 0, 1, ..., 511.
Use 2nd-order central differences for the u_xx term.
Use explicit RK4 (4th-order Runge-Kutta) time stepping with dt = 0.0005 and Nt = 2000 steps.
Verify that dt*Nt = 0.0005*2000 = 1.0 to reach final time T = 1.0 exactly.
Compute the solution u(x,T=1.0) on the periodic grid.
Save "solution_molk_022.npz" containing arrays x (1D length 512), u (1D length 512), and scalars T, dx, Nx, q1, q2, a.
Save a line plot of u(x,T) as "solution_molk_022.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
