Q: What value should be used for the wave speed c in the CFL condition calculation, since the PDE has coefficient (0.8)^2 but the CFL formula references c*dt/dx?
A: The wave speed c = 0.8. The PDE is u_tt = (0.8)^2 * u_xx, which is in the standard form u_tt = c^2 * u_xx where c = 0.8.
