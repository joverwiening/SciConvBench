Solve the diffusion PDE u_t = ∂/∂x(D(x) * u_x) where D(x) = 0.01 + 0.09*x^2.
Use spatial domain x in [0,1] and temporal domain t in [0,0.2].
Apply initial condition u(x,0) = x*(1-x).
Apply Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0.
Use Nx=400 uniform spatial intervals so there are 401 grid points including both endpoints.
Calculate dx = (1-0)/400 = 0.0025 and x_i = 0 + i*dx for i=0,1,...,400.
Use dt = 0.0005 for 400 time steps to reach T = 0.2.
Discretize spatially using conservative 2nd-order flux form on uniform grid.
Define D_i = D(x_i) = 0.01 + 0.09*x_i^2.
Define face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior points i=1 to Nx-1: ((D u_x)_x)_i ≈ (1/dx^2) * [D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1})].
Use implicit Euler time integration: (I - dt*L) u^{n+1} = u^n where L is the discrete diffusion operator.
Solve the sparse linear system at each time step.
Compute u(x, T=0.2) on the grid.
Save "solution_agent_diffusion_02.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save line plot of u(x,T) as "solution_agent_diffusion_02.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
