Solve the damped wave equation u_tt + 0.5*u_t = (1.0)^2 * u_xx numerically.
The spatial domain is x in [0,1] and the time domain is t in [0,3.0].
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Use initial conditions u(x,0)=sin(pi*x) and u_t(x,0)=0.
Rewrite the PDE as a first-order system: u_t = v and v_t = c^2*u_xx - gamma*v where c=1.0 and gamma=0.5.
Use a uniform spatial grid with Nx=400 intervals, giving 401 grid points including both endpoints.
Calculate dx=(1-0)/400=0.0025 and set x_i=0+i*dx for i=0 to 400.
Discretize u_xx using 2nd-order central differences: u_xx ≈ (u_{i+1} - 2*u_i + u_{i-1})/dx^2.
Integrate the system (u,v) using classical RK4 with fixed time step dt=0.0005.
Run for 6000 time steps to reach final time T=3.0.
At every RK4 substage, enforce boundary conditions by setting u=0 and v=0 at i=0 and i=400.
Compute the final solution u(x,T=3.0) on the grid.
Save "solution_agent_wave_09.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
