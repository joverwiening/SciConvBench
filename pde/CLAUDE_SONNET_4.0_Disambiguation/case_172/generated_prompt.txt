Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the spatial domain [0, 1) with periodic boundary conditions.
Set nu = 0.5 and rho = 1.0.
Use periodic boundary conditions where u(0,t) = u(1,t) for all t.
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points on [0, 1) where dx = 1/Nx and x_i = i*dx for i = 0 to Nx-1.
Use a time grid with fixed dt = 0.001 and Nt = 1000 steps so T = 1.0.
Implement Strang splitting for each time step dt with three substeps.
For substep A (diffusion half-step of duration dt/2), solve exactly in Fourier space by computing u_hat = FFT(u), setting k = 2*pi*fftfreq(Nx, d=dx), updating u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)), and computing u = real(IFFT(u_hat)).
For substep B (reaction full-step of duration dt), solve the logistic ODE du/dt = rho*u*(1-u) exactly pointwise using u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
For substep C, repeat the diffusion half-step from substep A.
Compute the solution u at final time T = 1.0 on the spatial grid.
Save "solution_pdebench_reacdiff_nu0p5_rho1.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho1.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
