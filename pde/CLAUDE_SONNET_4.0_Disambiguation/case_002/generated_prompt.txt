Solve the advection PDE u_t + (-0.5)*u_x = 0 on domain x in [0,1), t in [0,1.0].
Use parameter a = -0.5.
Apply initial condition u(x,0) = exp(-100*(x-0.3)^2).
Apply periodic boundary condition u(0,t) = u(1,t).
Use uniform periodic grid with Nx = 1000 points on [0,1).
Set dx = 1/Nx.
Use 1st-order upwind spatial discretization with right-biased (downwind) stencil since a < 0.
Use Forward Euler time integration.
Set dt0 = 0.9*dx/|a| for CFL condition.
Set Nt = ceil(T/dt0) where T = 1.0.
Set dt = T/Nt to hit final time exactly.
Compute u(x, T=1.0) on the grid.
Save "solution_agent_advection_02.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save line plot of u(x,T) as "solution_agent_advection_02.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
