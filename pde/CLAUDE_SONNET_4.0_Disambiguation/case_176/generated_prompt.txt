Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use temporal domain t in [0, 1.0].
Set parameters nu = 10.0 and rho = 1.0.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Create uniform periodic grid with Nx = 512 points on [0,1).
Set dx = 1.0/512 and x_j = j*dx for j = 0, 1, ..., 511.
Use fixed time step dt = 0.001 with Nt = 1000 steps to reach T = 1.0 exactly.
Implement Strang splitting for each time step dt with three substeps.
For diffusion half-step (duration dt/2), solve exactly in Fourier space by computing u_hat = FFT(u), setting k = 2*pi*fftfreq(Nx, d=dx), updating u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)), and computing u = real(IFFT(u_hat)).
For reaction full-step (duration dt), solve the logistic ODE du/dt = rho * u*(1 - u) exactly pointwise using u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Apply diffusion half-step again (same as first diffusion step).
Compute the final solution u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_reacdiff_nu10_rho1.npz" containing arrays x (1D length 512), u (1D length 512), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho1.png".
