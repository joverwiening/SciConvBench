Solve the wave equation u_tt = u_xx numerically on the domain x in [0,1], t in [0,1.0] with wave speed c = 1.0.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1.

Create a uniform spatial grid on [0,1] with Nx = 800 intervals, giving Nx+1 = 801 grid points including both endpoints.
Set dx = 1/Nx = 1/800.
Use 2nd-order central differences for spatial discretization of u_xx in the interior points.
Use 2nd-order central difference in time (leapfrog/Störmer-Verlet) for time integration of u_tt.

Compute u at t = dt using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0 where v0 = u_t(x,0) = 0.
Apply Dirichlet boundary conditions by setting u = 0 at boundary nodes at every time step.
Compute the solution u(x,T) at final time T = 1.0.
