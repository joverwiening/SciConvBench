Solve the 1D linear advection PDE u_t + q*u_x = 0 using finite difference methods.
Use 1st-order upwind spatial discretization and Forward Euler time integration.
Set the spatial domain as x in [0, 1) with periodic boundary conditions.
Set the time domain as t in [0, 1.0].
Use parameter q = 1.5.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
Set spatial grid points Nx = 512.
Use CFL = 0.5 to determine time step automatically with dt0 = CFL*dx/abs(q).
Set Nt = ceil(T/dt0) and use dt = T/Nt.
Create periodic grid with dx = (1-0)/Nx and x_i = 0 + i*dx for i = 0 to Nx-1.
Compute the numerical solution u(x,T=1.0) on the periodic grid.
Save "solution_molk_018.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter q.
Save a line plot of u(x,T) as "solution_molk_018.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
Compute and print max absolute error and L2 error versus exact solution u(x,t) = u0((x - q*t) mod 1) where u0 is the initial condition.
