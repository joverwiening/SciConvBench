Solve the wave equation u_tt = u_xx + sin(pi*x)*sin(2*pi*t) numerically on the domain x in [0,1], t in [0,1.0].
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Use initial conditions u(x,0)=0 and u_t(x,0)=0.
Create a uniform spatial grid on [0,1] with Nx=400 intervals, giving Nx+1=401 grid points including both endpoints.
Set dx = 1/Nx = 1/400 = 0.0025.
Set x_i = i*dx for i=0,1,...,400.
Use 2nd-order central differences for u_xx in the interior points.
Use the wave speed c = 1.0 for time step calculation.
Calculate dt0 = 0.9*dx/c = 0.9*0.0025/1.0 = 0.00225.
Set Nt = ceil(1.0/dt0) and then dt = 1.0/Nt to hit the final time exactly.
Use 2nd-order central difference in time for u_tt (leapfrog/Störmer-Verlet scheme).
Initialize u(x,dt) using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0) where f^0 = sin(pi*x)*sin(2*pi*0) = 0.
Apply Dirichlet boundary conditions by setting u[0] = 0 and u[Nx] = 0 at every time step.
Compute the solution until T = 1.0.
Save "solution_agent_wave_10.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_10.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time.
