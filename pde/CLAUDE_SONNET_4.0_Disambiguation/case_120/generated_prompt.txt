Solve the 1D wave equation u_tt = q*u_xx numerically using finite difference method.
Use second-order central differences for spatial discretization and RK4 for time integration.
Convert to first-order system: u_t = v, v_t = q*u_xx where v = u_t.
Set q = 1.0.
Use spatial domain x in [0,1) with periodic boundary conditions.
Use temporal domain t in [0,1.0].
Apply periodic boundary conditions: u and u_x are periodic on [0,1).
Set initial conditions: u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.
Use Nx = 256 grid points for spatial discretization.
Use dt = 0.0005 with Nt = 2000 time steps.
Grid convention: dx = (1-0)/Nx = 1/256, x_i = 0 + i*dx for i = 0 to Nx-1.
Compute the solution u(x,T=1.0) on the periodic grid.
Save "solution_molk_019.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter q.
Save a line plot of u(x,T) as "solution_molk_019.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
