Solve the 1D nonlinear convection-diffusion PDE u_t = -q1*∂_x(sin(u)) + (q2/pi)*u_xx numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
Set q1 = 1.0 and q2 = 0.05.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.5*sin(2*pi*x).
Create a uniform periodic grid with Nx = 1024 points on [0,1).
Set x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Use conservative finite-volume flux discretization for ∂_x(sin(u)) with Rusanov flux.
Set the wave speed alpha = max|cos(u)| for the Rusanov flux.
Apply 2nd-order central differences for the diffusion term u_xx.
Use SSP-RK2 for time integration.
Set CFL = 0.2 and note max|cos(u)| <= 1.
Calculate dt_adv = 0.2*dx/1 and dt_diff = 0.2*dx^2/(q2/pi).
Use dt = min(dt_adv, dt_diff).
Set Nt = ceil(T/dt) and dt = T/Nt where T = 0.5.
Treat all trigonometric functions in radians.
Use ** for exponentiation in Python code instead of ^.
