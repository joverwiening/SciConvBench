Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain [0,1] x [0,1].
Use Dirichlet boundary conditions: u(x,0) = 0, u(x,1) = sin(2*pi*x), u(0,y) = 0, u(1,y) = 0.
Discretize on a uniform grid with Nx=Ny=100 intervals, giving 101x101 grid points including boundaries.
Set dx=dy=1/100 and grid points x_i=i*dx for i=0..100, y_j=j*dy for j=0..100.
Use the standard 5-point stencil for the Laplacian at interior points.
Solve the resulting sparse linear system using scipy.sparse.linalg.spsolve.
Save the solution arrays x, y, u (with u[j,i] = u(x[i], y[j])) and scalars dx, dy to "solution_agent_laplace_08.npz".
Save a heatmap plot of the solution as "solution_agent_laplace_08.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compute the exact solution u(x,y) = sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi) on the same grid.
Print the maximum absolute error and L2 error between numerical and exact solutions.
