Solve the 1D Compressible Navier-Stokes equations numerically using finite volume method.
Use conservative form with variables rho (density), m (momentum), and E (total energy).
Set domain as x in [-1, 1] and t in [0, 0.2].
Use parameters Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.
Apply transmissive/outflow boundary conditions with zero-gradient at x = -1 and x = 1.
Initialize with Riemann shock-tube condition: left state (x < 0) has rho_L = 1.0, v_L = -0.75, p_L = 1.0; right state (x >= 0) has rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Use uniform finite-volume grid with Nx = 800 cells on [-1,1].
Set cell centers as x_j = -1 + (j+0.5)*dx for j = 0,...,799 with dx = 2/800 = 0.0025.
Evolve conservative variables U = [rho, m, E] as cell averages.
Apply equation of state p = (Gamma-1) * (E - 0.5*m^2/rho) with positivity enforcement by clipping rho and p to floor value 1e-12.
Use Rusanov numerical flux for convective terms with interface wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Compute viscous stress sigma = (zeta + 4/3*eta) * v_x using centered differences on cell-centered v values.
Average sigma at interfaces and add viscous contributions F_visc = [0, -sigma, -v*sigma] to total flux.
Apply 2-stage SSP-RK2 time integration.
Choose time step as dt = min(dt_conv, dt_visc) where dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Use CFL = 0.4 based on stability requirements for second-order methods.
Adjust final time step to hit T = 0.2 exactly.
Implement outflow boundary conditions by setting ghost cell values equal to nearest interior cell.
Compute final solution rho(x,T), v(x,T), p(x,T) on cell centers.
