Solve the diffusion-reaction PDE u_t = 0.02*(u_xx + u_yy) + 3.0*u*(1 - u/1.0) on the domain (x,y) in [0,1] x [0,1] for t in [0,0.5].
Use the initial condition u(x,y,0) = 0.8*exp(-40*((x-0.5)^2 + (y-0.5)^2)).
Apply Dirichlet boundary conditions u=0 on all boundary edges.
Use parameters D = 0.02, r = 3.0, K = 1.0.
Discretize the spatial domain with Nx=Ny=120 intervals creating a (Nx+1) by (Ny+1) grid with dx=dy=1/Nx.
Use a 5-point Laplacian stencil for the diffusion term.
Apply IMEX time integration with dt=0.0005 for Nt=1000 steps where diffusion is treated implicitly with backward Euler and reaction is treated explicitly with forward Euler.
At each time step solve (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) where L is the discrete Laplacian and R(u) = 3.0*u*(1 - u/1.0) is the reaction term.
Use a sparse direct solver for the linear system at each time step.
Compute the solution u(x,y,T=0.5) at the final time.
Save the solution as "solution_agent_diffusion_reaction_07.npz" containing 1D arrays x and y, 2D array u with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]), and metadata scalars T, dx, dy, dt.
Save a heatmap plot of u(x,y,T) as "solution_agent_diffusion_reaction_07.png".
Print the minimum value, maximum value, and discrete L2 norm sqrt(sum(u^2)*dx*dy) of the final solution.
