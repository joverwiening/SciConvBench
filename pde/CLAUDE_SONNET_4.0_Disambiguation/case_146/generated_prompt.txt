Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 0.1.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0,1) with Nx=512 uniform grid points.
Calculate dx = (1-0)/512 = 1/512.
Set grid points as x_i = 0 + i*dx for i = 0 to 511.
Use final time T = 1.0.
Apply Strang splitting with CFL = 0.4 based on estimated max speed = 1.0.
Calculate dt0 = CFL*dx/1.0 = 0.4*dx.
Set Nt = ceil(T/dt0) and reset dt = T/Nt for exact final time.
For each time step, perform diffusion half-step using exact Fourier space solution.
Calculate k = 2*pi*fftfreq(Nx, d=dx).
Apply u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Perform advection full-step using finite-volume Rusanov flux for inviscid Burgers equation.
Define f(u) = 0.5*u^2.
For each interface, calculate alpha = max(abs(u_left), abs(u_right)).
Calculate flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell: u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Perform second diffusion half-step identical to the first.
