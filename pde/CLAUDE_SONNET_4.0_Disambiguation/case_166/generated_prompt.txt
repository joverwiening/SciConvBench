Solve the 1D compressible Navier-Stokes equations numerically using a finite-volume method.
Use a uniform grid with Nx=800 cells on the domain [-1,1].
Place cell centers at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
The PDE system in conservative form is: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
Define m = rho*v, total energy E = p/(Gamma-1) + 0.5*rho*v^2, and viscous stress sigma = (zeta + 4/3*eta) * v_x.
Set parameters Gamma = 1.6666666666666667, eta = 1e-08, zeta = eta = 1e-08.
Apply transmissive/outflow (zero-gradient) boundary conditions at x=-1 and x=1.
Use Riemann shock-tube initial conditions with discontinuity at x=0: for x < 0 set rho_L = 1.0, v_L = 0.0, p_L = 10.0; for x ≥ 0 set rho_R = 1.0, v_R = 0.0, p_R = 0.1.
Implement Rusanov (local Lax-Friedrichs) numerical flux for the convective terms.
Use centered differences for viscous terms.
Apply 2-stage SSP-RK2 (Heun's method) for time integration.
Use CFL = 0.5 for time step calculation based on stability requirements.
Simulate from t=0 to T=0.2.
Compute the solution rho(x,T), v(x,T), p(x,T) on the cell centers at final time T.
Save "solution_pdebench_cns1d_sod7_eta1em8_outflow.npz" containing arrays x (1D length Nx), rho (1D), v (1D), p (1D), and scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel line plot of rho, v, p vs x at T as "solution_pdebench_cns1d_sod7_eta1em8_outflow.png".
Print min/max of rho and p for positivity check, and mean of rho over the domain for mass conservation check.
