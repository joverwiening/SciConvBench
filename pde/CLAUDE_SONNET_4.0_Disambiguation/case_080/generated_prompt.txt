Solve the 2D Poisson equation u_xx + u_yy = f(x,y) where f(x,y) = 100*exp(-200*((x-0.5)^2 + (y-0.5)^2)).

Apply Dirichlet boundary conditions with u=0 on all four edges.
Use a uniform grid with Nx=Ny=120 intervals in each direction, creating a (Nx+1) by (Ny+1) grid of points including boundaries.
Set dx=dy=1/Nx and define grid points as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Discretize the Laplacian using the standard 5-point stencil with second-order accuracy.
Solve the resulting sparse linear system for interior nodes using a sparse direct solver like scipy.sparse.linalg.spsolve.
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution as "solution_agent_poisson_07.npz" containing arrays x (1D), y (1D), u (2D with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j])), and metadata scalars dx, dy.
Save a heatmap or contour plot of u(x,y) as "solution_agent_poisson_07.png".
