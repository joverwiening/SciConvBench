Solve the 1D advection-diffusion PDE u_t = D*u_xx - (1/gamma)*∂_x(U'(x)*u) numerically.
The PDE has space-dependent drift with U(x) = cos(2*pi*x) and U'(x) = -2*pi*sin(2*pi*x).
Use spatial domain x in [0,1) with periodic boundary conditions and time domain t in [0,1.0].
Set parameters D = 0.01 and gamma = 1.0.
Apply initial condition u(x,0) = 1.0 + 0.2*sin(2*pi*x).
Use uniform periodic grid with Nx = 512 points where x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Treat the drift term in conservative form as flux F = (1/gamma)*U'(x)*u so the PDE becomes u_t = D*u_xx - ∂_x(F).
Discretize ∂_x(F) using upwind finite-volume flux based on the sign of interface velocity b = U'(x)/gamma.
Discretize u_xx using 2nd-order central differences.
Use explicit SSP-RK2 for time integration.
Choose time step dt = min(0.4*dx/max|b|, 0.2*dx^2/D) where b(x) = U'(x)/gamma.
Set Nt = ceil(T/dt) and adjust dt = T/Nt.
Print to console min(u), max(u), mean(u) at T = 1.0.
Print to console the discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
Save "solution_molk_033.npz" containing arrays x, u and scalars T, dx, Nx plus parameter scalars.
