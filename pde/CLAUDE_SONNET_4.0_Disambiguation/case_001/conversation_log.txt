Q: What value should be used for the parameter 'a' in the advection equation u_t + a*u_x = 0, since the PDE shows coefficient 1.0 but the parameters section lists a = 1.0 separately?
A: The parameter a = 1.0 from the parameters section is the same as the coefficient 1.0 shown in the PDE. Use a = 1.0 for the advection velocity.
