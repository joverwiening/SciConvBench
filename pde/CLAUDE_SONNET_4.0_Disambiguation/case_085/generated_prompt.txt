Solve the wave equation u_tt = u_xx numerically on the domain x in [0,1], t in [0,1.0].
Use parameter c = 1.0.
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Set initial conditions u(x,0) = 0 and u_t(x,0) = sin(pi*x).
Use the exact solution u(x,t) = (1/(1.0*pi))*sin(1.0*pi*t)*sin(pi*x) for verification.
Create a uniform spatial grid on [0,1] with Nx=400 intervals giving Nx+1=401 points.
Set dx = 1/Nx = 1/400.
Use 2nd-order central differences for u_xx in the interior points.
Apply 2nd-order central difference time integration (leapfrog/Störmer-Verlet) for u_tt.
Choose dt0 = 0.9*dx/c = 0.9*dx/1.0 for stability with CFL ≤ 0.9.
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit the final time T=1.0 exactly.
Initialize u(x,dt) using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0.
Set boundary nodes to u=0 at every time step.
Compute the solution u(x,T) at the final time T=1.0.
Save "solution_agent_wave_04.npz" containing arrays x, u, and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_04.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time.
Compute and print max absolute error and L2 error versus the exact solution on the same grid.
