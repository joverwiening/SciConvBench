Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 0.04.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0,1) with Nx = 512 grid points.
Calculate dx = (1-0)/Nx = 1/512.
Set grid points as x_i = 0 + i*dx for i = 0 to Nx-1.
Set final time T = 1.0.
Use CFL = 0.4 with estimated max speed = 1.0 to get dt0 = CFL*dx/1.0.
Calculate Nt = ceil(T/dt0) and reset dt = T/Nt for exact final time.
Implement Strang splitting for each time step dt with three substeps.
For diffusion half-step (duration dt/2): transform to Fourier space using FFT, apply exact solution u_hat(k) *= exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then inverse FFT taking real part.
For advection full-step (duration dt): solve inviscid Burgers u_t + ∂_x(0.5*u^2) = 0 using finite-volume with Rusanov flux.
Define flux function f(u) = 0.5*u^2.
For each interface between u_left = u[j] and u_right = u[j+1] with periodic indexing: calculate alpha = max(abs(u_left), abs(u_right)) and flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus is flux between (u[j], u[j+1]) and F_minus is flux between (u[j-1], u[j]).
Apply second diffusion half-step identical to the first.
Compute the solution u at final time T.
Save "solution_pdebench_burgers_nu0p04.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu0p04.png".
