Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 0.004.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0,1) with Nx = 512 grid points.
Calculate dx = (1-0)/Nx = 1/512.
Set grid points as x_i = 0 + i*dx for i = 0 to Nx-1.
Set final time T = 1.0.
Use CFL = 0.4 with estimated max speed = 1.0.
Calculate dt0 = CFL*dx/1.0 = 0.4*dx.
Set Nt = ceil(T/dt0).
Reset dt = T/Nt to hit final time exactly.
Apply Strang splitting for each time step dt.
For diffusion half-step (duration dt/2): transform to Fourier space using FFT, set k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k^2*(dt/2)), transform back using IFFT and take real part.
For advection full-step (duration dt): use finite-volume update with Rusanov flux for inviscid Burgers equation u_t + ∂_x(0.5*u^2) = 0.
Define f(u) = 0.5*u^2.
For each interface between u_left = u[j] and u_right = u[j+1] with periodic indexing: calculate alpha = max(abs(u_left), abs(u_right)), then F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j: calculate F_plus = flux between (u[j], u[j+1]) and F_minus = flux between (u[j-1], u[j]), then u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after advection substep.
Apply diffusion half-step again (same as first diffusion step).
Compute u at final time T on the grid.
Save "solution_pdebench_burgers_nu4em3.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu4em3.png".
