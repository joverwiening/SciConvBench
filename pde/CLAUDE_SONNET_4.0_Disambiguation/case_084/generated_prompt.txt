Solve the wave equation u_tt = (1.0)^2 * u_xx numerically on the domain x in [0,1], t in [0,0.8].
Use the parameter c = 1.0.
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Set initial conditions u(x,0) = sin(pi*x) + 0.5*sin(3*pi*x) and u_t(x,0) = 0.
Use a uniform spatial grid on [0,1] with Nx=600 intervals, giving Nx+1=601 grid points including both endpoints.
Set dx = 1/Nx = 1/600.
Apply 2nd-order central differences for u_xx in the interior points.
Use 2nd-order central difference time integration (leapfrog/Störmer-Verlet) for u_tt.
Choose dt0 = 0.9*dx/c = 0.9*(1/600)/1.0, then set Nt = ceil(0.8/dt0) and dt = 0.8/Nt to hit the final time exactly.
Initialize the first time step using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0 where v0 is u_t(x,0)=0.
Set boundary nodes to u=0 at every time step.
Compute the solution at the final time T=0.8.
Save "solution_agent_wave_03.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_03.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.8.
Compute and print the max absolute error and L2 error versus the exact solution u(x,t)=cos(1.0*pi*t)*sin(pi*x) + 0.5*cos(1.0*3*pi*t)*sin(3*pi*x) evaluated on the same grid.
