Solve the Burgers equation u_t + u*u_x = 0.02*u_xx + sin(2*pi*x)*cos(2*pi*t) numerically.
Use spatial domain [0,1) with periodic boundary conditions u(0,t) = u(1,t).
Use temporal domain [0,1.0].
Set nu = 0.02.
Apply initial condition u(x,0) = 0.
Use Nx = 1000 grid points on [0,1) with dx = 1/Nx.
Use dt = 1e-4 with Nt = 10000 time steps to reach T = 1.0 exactly.
Discretize in conservative form u_t + (f(u))_x = nu*u_xx with f(u) = 0.5*u^2.
Apply Rusanov flux for convection: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i) where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
Compute convection term as (f(u))_x ≈ (F_{i+1/2}-F_{i-1/2})/dx.
Apply 2nd-order central difference for diffusion: u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Use 1st-order IMEX time integration treating convection explicitly and diffusion implicitly.
Solve linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term at each time step.
Handle periodic boundaries consistently in the spatial operators and linear system.
Compute u(x, T=1.0) on the final grid.
