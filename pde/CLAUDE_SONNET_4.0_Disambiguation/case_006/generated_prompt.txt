Solve the advection PDE u_t + 2.0*u_x = 0 numerically.
The spatial domain is [0,1) with periodic boundary conditions and the time domain is [0,0.3].
The parameter a = 2.0.
The initial condition is u(x,0) = 1 if 0.2 ≤ x < 0.4, else 0 (a periodic square pulse).
Use a uniform periodic grid with Nx = 2000 points on [0,1).
Calculate dx = 1/Nx.
Use 1st-order upwind finite difference for the spatial derivative u_x.
Use Forward Euler time integration.
Calculate dt0 = 0.9*dx/|a| for the CFL condition.
Set Nt = ceil(T/dt0) where T = 0.3.
Set dt = T/Nt to hit the final time exactly.
Apply periodic boundary conditions using appropriate indexing.
Compute the solution u(x,T) at T = 0.3.
Save the results to "solution_agent_advection_06.npz" containing arrays x, u, and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_advection_06.png".
Print the minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.3.
