Solve the 1D advection PDE u_t + beta * u_x = 0 with beta = 0.7.
Use periodic boundary conditions where u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use spatial domain [0,1) with Nx=512 grid points and dx=(1-0)/Nx=1/512.
Generate grid points as x_i = 0 + i*dx for i=0 to Nx-1.
Apply 1st-order upwind finite difference for u_x using upwind direction based on sign of beta.
Since beta=0.7 > 0, use backward difference: (u_i - u_{i-1})/dx.
Use explicit forward Euler time integration.
Set CFL=0.5 and compute dt = CFL * dx / abs(beta) = 0.5 * (1/512) / 0.7.
Calculate Nt = ceil(T/dt) where T=2.0, then reset dt = T/Nt for exact final time.
Compute the solution u at final time T=2.0.
Save "solution_pdebench_advection_beta0p7.npz" with arrays x, u and scalars beta, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_advection_beta0p7.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=2.0.
