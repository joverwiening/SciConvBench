Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain [0,1] x [0,1].
Use Dirichlet boundary conditions: u(x,0) = 0, u(x,1) = 1, u(0,y) = y, u(1,y) = y.
Discretize using a uniform grid with Nx = Ny = 100 intervals, giving 101 x 101 grid points.
Set dx = dy = 1/100 and x_i = i*dx for i = 0 to 100, y_j = j*dy for j = 0 to 100.
Apply the standard 5-point stencil for the Laplacian at interior grid points.
Solve the resulting sparse linear system using scipy.sparse.linalg.spsolve.
Save the solution arrays x, y, u and scalars dx, dy to "solution_agent_laplace_04.npz".
Save a heatmap plot of u(x,y) as "solution_agent_laplace_04.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compute and print the max absolute error and L2 error against the exact solution u(x,y) = y.
