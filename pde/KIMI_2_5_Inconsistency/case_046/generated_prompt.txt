Solve the heat equation u_t = 0.1 * u_xx + sin(2*pi*x) on x in [0,1], t in [0,0.5] with Neumann boundary conditions u_x(0,t)=0, u_x(1,t)=0 and initial condition u(x,0)=0.

Use a uniform grid with Nx=200 intervals (201 points) on [0,1], giving dx=0.005.

Discretize the Laplacian using 2nd-order central differences: u_xx at interior point i is (u_{i-1} - 2*u_i + u_{i+1})/dx^2.

Implement zero Neumann boundary conditions via ghost points: set u_{-1} = u_1 and u_{Nx+1} = u_{Nx-1}, which modifies the stencil at boundaries to give (2*u_1 - 2*u_0)/dx^2 at i=0 and (2*u_{Nx-1} - 2*u_{Nx})/dx^2 at i=Nx.

Use Crank-Nicolson time integration with dt=0.001 for 600 steps to reach T=0.5. The scheme is (I - 0.5*dt*alpha*A)u^{n+1} = (I + 0.5*dt*alpha*A)u^n + dt*source, where A is the discrete Laplacian matrix including boundary modifications, and source is sin(2*pi*x) evaluated at grid points.

The source term sin(2*pi*x) is treated explicitly (added to the right-hand side) or with the same Crank-Nicolson averaging as the diffusion term.

Assemble the (Nx+1) x (Nx+1) tridiagonal system for the diffusion operator with: main diagonal entries -2/dx^2 (interior) or -2/dx^2 (boundaries, from ghost point substitution), off-diagonal entries 1/dx^2, with boundary rows modified to have 2/dx^2 in the first off-diagonal position due to ghost points.

Solve the linear system at each time step using a direct solver for the tridiagonal/banded matrix.

At final time T=0.5, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
