Solve the undriven Duffing oscillator ODE system numerically with the following specifications.

The ODE system is defined as:
dx/dt = y
dy/dt = -delta*y - alpha*x - beta*x**3

The time domain is t in [0.0, 50.0].

The parameters are:
alpha = 2
beta = 0.1
delta = 0.2

The initial conditions are:
x(0.0) = 1.0
y(0.0) = 0.0

Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt=0.01 and Nt=5000 steps so that the final time is hit exactly.

Compute the full state vector at all time points t_n = t0 + n*dt for n=0..Nt.

Save "solution_molk_011.npz" containing arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns ordered as [x, y], and the parameter scalars.

Save line plots of each state vs t as "solution_molk_011.png".

Print the final state values at T and also min/max of each state over time.
