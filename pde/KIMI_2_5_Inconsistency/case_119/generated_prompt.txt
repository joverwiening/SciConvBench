The task is to solve the 1D linear advection equation u_t + q*u_x = 0 on a periodic domain [0,1) with q=1.5, using a first-order upwind finite difference scheme with Forward Euler time integration.

The spatial grid uses Nx=512 points with x_j = j*dx for j=0,...,Nx-1 where dx=1/Nx=1/512.

The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).

The time step is determined by CFL=0.5: dt0 = CFL*dx/abs(q) = 0.5*(1/512)/1.5, then Nt=ceil(T/dt0) with T=1.1, and dt=T/Nt.

For the upwind scheme with q>0, the spatial discretization uses backward differences: u_x ≈ (u_j - u_{j-1})/dx with periodic wrapping.

The Forward Euler update is: u_j^{n+1} = u_j^n - dt*q*(u_j^n - u_{j-1}^n)/dx for j=0,...,Nx-1, with u_{-1} = u_{Nx-1}.

The solution at T=1.1 is computed and saved to "solution_molk_018.npz" containing arrays x, u and scalars T, dx, Nx, q.

A line plot is saved to "solution_molk_018.png".

The diagnostics min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) are printed.

The exact solution is u_exact(x,T) = u0((x - q*T) mod 1), and the max absolute error and L2 error against this reference are computed and printed.
