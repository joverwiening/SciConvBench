The PDE is the linear advection equation u_t + a*u_x = 0 with a = -0.5, solved on a periodic domain [0,1) with initial condition u(x,0) = exp(-100*(x-0.3)^2).

The spatial discretization uses a uniform periodic grid with Nx = 1000 points, giving dx = 0.001. Since a < 0, the 1st-order upwind scheme uses a right-biased stencil: u_x ≈ (u_{i+1} - u_i)/dx.

The time step is determined by the CFL condition: dt0 = 0.9*dx/|a| = 0.9*0.001/0.5 = 0.0018. With T = 1.1, Nt = ceil(1.1/0.0018) = 612, and dt = 1.1/612 ≈ 0.001797.

The update formula is: u_i^{n+1} = u_i^n - (a*dt/dx)*(u_{i+1}^n - u_i^n) = u_i^n + 0.5*dt/dx*(u_{i+1}^n - u_i^n).

Periodic boundary handling uses wrap-around indexing: index i maps to i mod Nx.

The solution at T=1.1 is computed, saved to "solution_agent_advection_02.npz" with arrays x, u and scalars T, dx, dt, and plotted to "solution_agent_advection_02.png". The diagnostics min(u), max(u), and discrete L2 norm are printed.
