The task is to solve a 1D reaction-diffusion PDE with logistic reaction using Strang splitting with exact diffusion in Fourier space and exact reaction pointwise, on a periodic domain [0,1) with Nx=512 grid points, time step dt=0.001 for Nt=1000 steps to reach T=1.0, with parameters nu=10.0 and rho=10.0.

The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).

The numerical method uses:
- Step A: Exact diffusion half-step via FFT with factor exp(-nu*k^2*(dt/2))
- Step B: Exact reaction full-step via logistic ODE solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1))
- Step C: Exact diffusion half-step again

The spatial grid uses x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx=1/512, interpreted as Nx points on [0,1) with no duplicated endpoint.

The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).

Output requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save "solution_pdebench_reacdiff_nu10_rho10.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt
- Save a line plot as "solution_pdebench_reacdiff_nu10_rho10.png"
- Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u**2)*dx) at T
