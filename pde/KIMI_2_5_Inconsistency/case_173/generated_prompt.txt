The task is to numerically solve a 1D reaction-diffusion PDE with logistic reaction and periodic boundary conditions using Strang splitting with explicit forward Euler time stepping.

The PDE is u_t = nu * u_xx + rho * u*(1 - u) with nu = 0.5 and rho = 10.0.

The spatial domain is x in [0, 1) with periodic boundary conditions, using a uniform periodic grid with Nx = 512 points where x_j = j*dx for j = 0,...,Nx-1 and dx = 1/Nx = 1/512.

The time domain is t in [0, 1.0] with fixed time step dt = 0.001 and Nt = 1000 steps to reach T = 1.0 exactly.

The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x), using radians for the sine function.

The numerical method uses Strang splitting for each full time step dt:
First, apply a diffusion half-step of duration dt/2 solved exactly in Fourier space by computing the FFT of u, multiplying by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then taking the IFFT and keeping the real part.
Second, apply a reaction full-step of duration dt solved exactly pointwise for the logistic ODE using the exact solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, apply another diffusion half-step identical to the first.

The output requirements are to compute u(x,T=1.0) on the periodic grid, save "solution_pdebench_reacdiff_nu0p5_rho10.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt, save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho10.png", and print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
