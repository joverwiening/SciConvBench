Solve the 1D heat equation u_t = 0.1 * u_xx + 1 on x in [0,1] with t in [0,0.5].

Use a uniform grid with Nx=200 intervals (201 points) where dx = 1/200 = 0.005, with grid points x_i = i*dx for i=0..200.

Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 by fixing the boundary nodes to zero at each time step.

Start with initial condition u(x,0)=0 for all x.

Use Crank-Nicolson time integration with dt=0.001 for 500 steps to reach T=0.5.

For the diffusion term 0.1*u_xx, apply standard second-order central differences: (u_{i+1} - 2*u_i + u_{i-1})/dx^2.

For the constant source term +1, include it in the Crank-Nicolson scheme by averaging: add 0.5*dt*1 to the right-hand side and 0.5*dt*1 to the left-hand side (or equivalently, add dt*1 to the right-hand side with the source treated explicitly, or use the average 0.5*(1+1)=1 effectively since it's constant). The correct CN treatment is: (u^{n+1} - u^n)/dt = 0.5*0.1*(u_xx^{n+1} + u_xx^n) + 1, which gives (I - 0.5*dt*0.1*D2)u^{n+1} = (I + 0.5*dt*0.1*D2)u^n + dt*1, where D2 is the discrete Laplacian matrix.

Build the tridiagonal system for the interior points (indices 1 to Nx-1, i.e., 1 to 199) with:
- Main diagonal: 1 + 0.5*dt*0.1*2/dx^2 = 1 + 0.01/dx^2
- Off-diagonals: -0.5*dt*0.1/dx^2 = -0.005/dx^2

The right-hand side for interior point i is: u_i^n + 0.5*dt*0.1*(u_{i+1}^n - 2*u_i^n + u_{i-1}^n)/dx^2 + dt*1.

After solving the linear system at each step, set u[0]=0 and u[Nx]=0 to enforce Dirichlet BCs.

At final time T=0.5, compute and print:
- min(u)
- max(u)
- discrete L2 norm sqrt(sum(u^2)*dx)

- u: 1D array of solution values at T=0.5 (length 201)
- T: scalar 0.5
- dx: scalar 0.005
- dt: scalar 0.001
