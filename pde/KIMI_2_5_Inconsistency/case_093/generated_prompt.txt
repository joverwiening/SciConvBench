The PDE is the 1D wave equation u_tt = c^2 * u_xx with c = 2.0 (from the PDE specification where (2.0)^2 = 4 = c^2), on domain x in [0,1] and t in [0,0.5].

The spatial discretization uses a uniform grid with Nx = 400 intervals, giving Nx+1 = 401 grid points including both endpoints at x=0 and x=1. The grid spacing is dx = 1/400 = 0.0025. The spatial points are x_i = i*dx for i = 0, 1, ..., 400.

The initial condition is u(x,0) = sin(π*x) and u_t(x,0) = 0. The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0 for all t.

The spatial second derivative u_xx is approximated by second-order central differences: u_xx(x_i) ≈ (u_{i+1} - 2*u_i + u_{i-1})/dx^2 for interior points i = 1, ..., Nx-1.

The temporal discretization uses the leapfrog (Störmer-Verlet) scheme: u^{n+1} = 2*u^n - u^{n-1} + dt^2 * c^2 * u_xx^n for interior points, with boundary values set to 0 at each time step.
