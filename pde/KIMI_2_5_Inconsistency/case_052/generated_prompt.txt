The task is to numerically solve the 2D Klein-Gordon equation with the following complete specification:

The PDE is u_tt - c^2*(u_xx + u_yy) + m^2*u = 0 with c=1.0 and m=1.0.

The spatial domain is (x,y) in [0,1] x [0,1] with Dirichlet boundary conditions u=0 on all boundaries.

The time domain is t in [0,0.8] for the PDE statement, but the output requires computation at T=0.9. Use T=0.9 as the final output time.

Initial conditions are u(x,y,0) = sin(pi*x)*sin(pi*y) and u_t(x,y,0) = 0.

The exact solution is u(x,y,t) = cos(sqrt(c^2*(2*pi^2) + m^2)*t) * sin(pi*x)*sin(pi*y).

Use a uniform grid with Nx=Ny=256 intervals, giving 257x257 grid points including boundaries. Set dx=dy=1/256.

Compute dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)), then Nt = ceil(T/dt0), and dt = T/Nt to hit the final time exactly.

Use 5-point Laplacian for spatial discretization of u_xx+u_yy.

Use 2nd-order central difference in time for u_tt.

Initialize with Taylor expansion: u^0 = u(x,y,0), u^1 = u^0 + dt*u_t(x,y,0) + (dt^2/2)*(c^2*Laplacian(u^0) - m^2*u^0).

Time step using: u^{n+1} = 2*u^n - u^{n-1} + dt^2*(c^2*Laplacian(u^n) - m^2*u^n).

Apply Dirichlet boundary conditions u=0 at all boundaries after each time step.

At final time T=0.9, compute and save:

Save "solution_agent_kg_05.npz" containing: x (1D array of x coordinates), y (1D array of y coordinates), u (2D array with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j])), and scalars T, dx, dy, dt.

Save "solution_agent_kg_05.png" as a heatmap/contour plot of u(x,y,T).

Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy).

Compute the reference solution on the same grid and print max absolute error and L2 error vs reference.
