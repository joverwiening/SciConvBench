The task is to numerically solve the 1D viscous Burgers equation with periodic boundary conditions using Strang splitting.

The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 4.0.

The domain is x in [0,1) periodic and t in [0, 1.0].

The initial condition is u(x,0) = sin(2*pi*x).

Use a uniform periodic grid with Nx=512 points on [0,1), with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.

Use Strang splitting with three substeps per full time step dt: (A) exact diffusion half-step in Fourier space, (B) advection full-step using finite-volume Rusanov flux, (C) exact diffusion half-step in Fourier space.

For the diffusion substep: compute FFT of u, multiply by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then IFFT and take real part.

For the advection substep: use Rusanov flux F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left) where f(u)=0.5*u^2 and alpha=max(abs(u_left),abs(u_right)), with periodic indexing. Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).

Set time step using CFL=0.4 with estimated max speed 1.0: compute dt0 = CFL*dx/1.0, then Nt = ceil(T/dt0), then reset dt = T/Nt to hit final time exactly.

Compute the solution at T=1.0 (note: the output requirement says T=1.1 but the domain specification says t in [0,1.0]; use T=1.0 as specified in the domain).

Save "solution_pdebench_burgers_nu4.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x,T) as "solution_pdebench_burgers_nu4.png".

Print min(u), max(u), mean(u), and sqrt(sum(u^2)*dx) at the final time.
