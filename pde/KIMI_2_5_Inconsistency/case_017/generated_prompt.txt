The PDE is a variable-coefficient diffusion equation: u_t = ∂/∂x( D(x) * u_x ) with D(x) = 0.1*(1+x).

The spatial domain is x in [0,1] and time domain is t in [0,0.5].

The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0 for all t.

The initial condition is u(x,0) = sin(π*x), using radians.

Use a uniform grid with Nx=300 intervals, giving Nx+1=301 grid points including both endpoints.

The grid spacing is dx = (1-0)/300 = 1/300.

The grid points are x_i = 0 + i*dx for i = 0, 1, ..., 300.

Define D_i = D(x_i) = 0.1*(1 + x_i) at each grid point.

Define face-centered diffusion coefficients by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}) for i = 0, ..., 299.

For interior points i = 1, ..., 299, the discrete operator L is: (L*u)_i = (1/dx^2) * [ D_{i+1/2}*(u_{i+1}-u_i) - D_{i-1/2}*(u_i-u_{i-1}) ].

The boundary conditions u_0 = 0 and u_{300} = 0 are enforced by eliminating these variables from the system.

The discrete system for interior unknowns u_1, ..., u_{299} is: (I - dt*L) * u^{n+1} = u^n.

Use time step dt = 0.001.

Perform 600 time steps to reach final time T = 0.5.

At each step, construct the sparse tridiagonal matrix (I - dt*L) and solve the linear system for u^{n+1}.

The matrix has: diagonal entries 1 + (dt/dx^2)*(D_{i+1/2} + D_{i-1/2}), sub-diagonal entries -(dt/dx^2)*D_{i-1/2}, super-diagonal entries -(dt/dx^2)*D_{i+1/2}, for i = 1, ..., 299.

After reaching T=0.5, compute the solution array u of length 301 (including boundary values of zero).

Save "solution_agent_diffusion_01.npz" containing: x (1D array of 301 points), u (1D array of 301 values), T=0.5, dx=1/300, dt=0.001.

Save "solution_agent_diffusion_01.png" as a line plot of u versus x at time T.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
