Solve the 1D wave equation u_tt = c^2 * u_xx with c=1.0 (from the PDE) on the periodic domain x in [0,1), t in [0,1.0].

Use a uniform periodic grid with Nx=512 points on [0,1), so dx = 1/512 and x_i = i*dx for i=0,...,511.

Compute dt0 = 0.9*dx/c where c=1.0, then set Nt = ceil(T/dt0) and dt = T/Nt to hit the final time T=1.0 exactly.

Initialize with u(x,0) = cos(2*pi*x) and u_t(x,0) = 0 using a Taylor start: compute u_tt(x,0) = c^2 * u_xx(x,0) via 2nd-order central difference with periodic wrap-around, then set u(x,dt) = u(x,0) + dt*u_t(x,0) + 0.5*dt^2*u_tt(x,0).

Apply 2nd-order central difference in time: u^{n+1} = 2*u^n - u^{n-1} + c^2*dt^2*D_xx(u^n) where D_xx is the 2nd-order spatial Laplacian with periodic boundary conditions.

Enforce periodicity by wrapping indices: for index i, use i mod Nx.

Evolve for Nt time steps to reach T=1.0.

Compute the reference solution u_exact(x,T) = cos(2*pi*x)*cos(2*pi*1.0*T) on the same grid.
