The task is to numerically solve a 1D reaction-diffusion PDE with logistic reaction and periodic boundary conditions using Strang splitting with exact diffusion in Fourier space and exact reaction pointwise.

The PDE is u_t = nu * u_xx + rho * u*(1 - u) with nu = 0.5 and rho = 2.0.

The spatial domain is x in [0, 1) with periodic boundary conditions, using a uniform periodic grid with Nx = 512 points where x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx = 1/512.

The time domain is t in [0, 1.0], using fixed dt = 0.001 with Nt = 1000 steps to reach T = 1.0 exactly.

The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x), using radians for the sine function.

The numerical method uses Strang splitting each full time step dt: (A) exact diffusion half-step in Fourier space using FFT, multiplying by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then IFFT and taking the real part; (B) exact reaction full-step pointwise using the logistic ODE exact solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)); (C) exact diffusion half-step again identical to step A.

The output requires computing u(x,T=1.0) on the periodic grid, saving "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt, saving a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho2.png", and printing min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
