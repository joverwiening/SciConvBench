The PDE to solve is the 2D wave equation with a source term: u_tt = c^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t), where c = 1.0 (from the PDE specification, note: parameter c=2 in section 3 appears to be a typo or unused since PDE uses 1.0).

The spatial domain is [0,1] x [0,1] with time domain [0,1.0].

Boundary conditions are Dirichlet with u=0 on all boundaries.

Initial conditions are u(x,y,0)=0 and u_t(x,y,0)=0.

Use a uniform grid with Nx=Ny=120 intervals, giving 121x121 grid points. Compute dx=dy=1/120.

Compute dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)) with c=1.0. Then set Nt = ceil(T/dt0) and dt = T/Nt to hit final time exactly.

For spatial discretization, use the 5-point Laplacian: (u_xx + u_yy) ≈ (u[i+1,j] + u[i-1,j] + u[i,j+1] + u[i,j-1] - 4*u[i,j]) / dx^2.

For time integration, use second-order central difference: u^{n+1} = 2*u^n - u^{n-1} + dt^2 * (c^2 * Laplacian(u^n) + source^n).

Initialize using Taylor expansion: since u(x,y,0)=0 and u_t(x,y,0)=0, the first step is u^1 = u^0 + dt*u_t^0 + 0.5*dt^2*u_tt^0 = 0.5*dt^2 * source(x,y,0), since Laplacian(u^0)=0.

At each time step, apply Dirichlet boundary conditions by setting boundary nodes to zero.
