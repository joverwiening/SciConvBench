The task is to numerically solve the 1D viscous Burgers equation with periodic boundary conditions using a specified Strang splitting method and output the solution at T=1.1.

The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx with nu=0.2 on domain x in [0,1), t in [0,1.1].

The initial condition is u(x,0) = sin(2*pi*x).

Use a uniform periodic grid with Nx=512 points on [0,1), with x_j = j*dx for j=0,...,Nx-1 where dx=1/Nx.

Implement Strang splitting for each time step dt:
- First, apply a diffusion half-step (duration dt/2) solved exactly in Fourier space: compute FFT of u, multiply by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then inverse FFT and take real part.
- Second, apply an advection full-step (duration dt) for the inviscid Burgers equation using a finite-volume update with Rusanov flux: for each interface between cells, compute alpha = max(abs(u_left), abs(u_right)), then flux F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left) where f(u)=0.5*u^2, then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.
- Third, apply another diffusion half-step identical to the first.

Set the time step using CFL=0.4 with estimated max speed 1.0, so dt0 = CFL*dx/1.0. Compute Nt = ceil(T/dt0) with T=1.1, then reset dt = T/Nt to hit the final time exactly.

Compute the solution at T=1.1.

Save the results to "solution_pdebench_burgers_nu0p2.npz" containing arrays x (length Nx), u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x,T) to "solution_pdebench_burgers_nu0p2.png".

Print min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time.
