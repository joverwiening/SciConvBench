The task is to numerically solve the Van der Pol oscillator ODE system with the following complete specification:

The ODE system is defined by:
dx/dt = y
dy/dt = mu*(1 - x**2)*y - x

The time domain is t in [0.0, 20.0].

The parameter is mu = 4.

The initial conditions are x(0.0) = 1.0 and y(0.0) = 0.0.

Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt = 0.01 and Nt = 2000 steps so that the final time is hit exactly.

Compute the full state vector at all time points t_n = t0 + n*dt for n = 0 to Nt.

Save "solution_molk_007.npz" containing arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns ordered as [x, y], and the parameter scalars.

Save line plots of each state vs t as "solution_molk_007.png".

Print the final state values at T and also min/max of each state over time.
