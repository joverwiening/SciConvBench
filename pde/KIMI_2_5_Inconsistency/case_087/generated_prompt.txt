The PDE is the 1D wave equation u_tt = c^2 * u_xx with c = 1.0 (from the PDE specification), though the parameters section lists c = 2 which is contradictory. The PDE explicitly states (1.0)^2, so c = 1.0 is used for the wave speed in the equation.

The spatial domain is x in [0,1] with closed interval interpretation: Nx = 400 intervals gives Nx+1 = 401 grid points with x_i = i*dx for i = 0..400, where dx = 1/400 = 0.0025.

The time domain is t in [0,1.0] with T = 1.0.

The boundary conditions are zero Neumann: u_x(0,t) = 0 and u_x(1,t) = 0, implemented using ghost points with mirror symmetry.

The initial conditions are u(x,0) = cos(pi*x) and u_t(x,0) = 0.

The exact solution is u(x,t) = cos(pi*x)*cos(pi*t).

For spatial discretization, use 2nd-order central differences: u_xx at interior point i is (u_{i+1} - 2*u_i + u_{i-1})/dx^2.

For time integration, use the leapfrog scheme: u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (c*dt/dx)^2 * (u^n_{i+1} - 2*u^n_i + u^n_{i-1}).

For stability, compute dt0 = 0.9*dx/c where c = 1.0, giving dt0 = 0.9*0.0025 = 0.00225. Then Nt = ceil(T/dt0) = ceil(1.0/0.00225) = ceil(444.44...) = 445, and dt = T/Nt = 1.0/445 ≈ 0.002247191.

For initialization: u^0_i = cos(pi*x_i). Compute u^1 using Taylor expansion: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0. Since v0 = 0, this becomes u^1_i = u^0_i + 0.5*dt^2*c^2*(u^0_{i+1} - 2*u^0_i + u^0_{i-1})/dx^2.

For Neumann boundaries with ghost points: at i=0, use ghost point u_{-1} = u_1 (mirror), so u_xx at i=0 becomes (u_1 - 2*u_0 + u_1)/dx^2 = 2*(u_1 - u_0)/dx^2. Similarly at i=Nx, use ghost point u_{Nx+1} = u_{Nx-1}.

The CFL number is c*dt/dx = 1.0 * (1.0/445) / (1/400) = 400/445 ≈ 0.8989 ≤ 0.9, satisfying the stability constraint.
