The task is to solve a 1D reaction-diffusion PDE with logistic reaction and periodic boundary conditions using Strang splitting with exact Fourier diffusion and exact pointwise reaction updates.

The PDE is u_t = nu * u_xx + rho * u*(1 - u) with nu = 2.0 and rho = 5.0.

The spatial domain is [0, 1) with periodic boundary conditions, using a uniform grid with Nx = 512 points where x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx = 1/512.

The time domain is [0, 1.0] with fixed time step dt = 0.001 and Nt = 1000 steps.

The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x), using radians for the sine function.

The numerical method uses Strang splitting for each full time step dt: (A) exact diffusion half-step in Fourier space using FFT with wavenumbers k = 2*pi*fftfreq(Nx, d=dx) and update factor exp(-nu*k**2*(dt/2)), (B) exact reaction full-step pointwise using the logistic ODE solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)), (C) exact diffusion half-step again identical to step A.

The diffusion substep uses numpy.fft.fft and numpy.fft.ifft, taking the real part after IFFT.

The output requirements are: compute u(x, T=1.0) on the periodic grid, save "solution_pdebench_reacdiff_nu2_rho5.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt, save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu2_rho5.png", and print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
