Solve the 1D compressible Navier-Stokes equations (without heat conduction) on the domain x in [-1, 1] with t in [0, 0.2].

Use the conservative form with unknowns U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.

Set Gamma = 1.6666666666666667 for the equation of state p = (Gamma-1)*(E - 0.5*m^2/rho).

Set eta = 1e-08 and zeta = eta = 1e-08 for the viscosities.

Define the viscous stress as sigma = (zeta + 4/3*eta) * v_x.

The PDE system is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

Apply transmissive/outflow (zero-gradient) boundary conditions at both x = -1 and x = 1.

Use the Sod shock tube initial condition with discontinuity at x = 0:
For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 1.0
For x >= 0: rho_R = 0.125, v_R = 0.0, p_R = 0.1

Discretize on a uniform finite-volume grid with Nx = 800 cells on [-1, 1].
Compute cell centers as x_j = -1 + (j+0.5)*dx for j = 0,...,Nx-1 with dx = 2/Nx.

Evolve cell-averaged conservative variables U = [rho, m, E].

Compute pressure from the equation of state and enforce positivity by clipping rho and p to a floor of 1e-12 if needed.

For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux:
Compute F_conv(U) = [m, m^2/rho + p, (E+p)*v] with v = m/rho.
At each interface, compute wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Compute numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

For viscous terms, compute v_x using centered differences on cell-centered v values.
Compute sigma = (zeta + 4/3*eta)*v_x at cell centers.
Average sigma to interfaces and average v to interfaces.
Add viscous flux F_visc = [0, -sigma, -v*sigma] using interface-averaged values.
The total interface flux is F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.

Choose the time step as dt = min(dt_conv, dt_visc) where:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30)
Adjust the final step to hit T = 0.2 exactly.

Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell values.

Compute rho(x,T), v(x,T), p(x,T) on the cell centers at final time.

Save "solution_pdebench_cns1d_sod1_eta1em8_outflow.npz" containing arrays x (length Nx), rho, v, p and scalars Gamma, eta, zeta, T, dx, CFL.

Save a 3-panel line plot of rho, v, p versus x at time T as "solution_pdebench_cns1d_sod1_eta1em8_outflow.png".

Print the minimum and maximum values of rho and p for positivity checking.
Print the mean of rho over the domain for mass conservation checking.
