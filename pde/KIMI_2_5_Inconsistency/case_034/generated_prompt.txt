The task is to solve the 1D heat equation u_t = 0.05 * u_xx on a periodic domain [0,1) with initial condition u(x,0) = sin(2*pi*x) + 0.2*cos(4*pi*x), using Crank-Nicolson time integration with 2nd-order central spatial differences on a periodic grid with Nx=256 points, dt=0.001 for 1200 steps to reach T=1.0.

The spatial grid uses Nx=256 points on [0,1) with dx=1/256, so x_i = i*dx for i=0,...,255, with periodic boundary conditions (no duplicate point at x=1).

The Laplacian discretization uses 2nd-order central differences: (u_{i+1} - 2*u_i + u_{i-1})/dx^2, with periodic wrap-around (index i-1 maps to Nx-1 when i=0, and index i+1 maps to 0 when i=Nx-1).

The Crank-Nicolson scheme solves (I - 0.5*dt*alpha*L) u^{n+1} = (I + 0.5*dt*alpha*L) u^n at each step, where L is the discrete Laplacian matrix. The matrix (I - 0.5*dt*alpha*L) is a cyclic tridiagonal matrix assembled using scipy.sparse and solved with scipy.sparse.linalg.spsolve.

The initial condition is u(x,0) = sin(2*pi*x) + 0.2*cos(4*pi*x).

The exact solution for verification is u_exact(x,t) = exp(-0.05*(2*pi)^2*t)*sin(2*pi*x) + 0.2*exp(-0.05*(4*pi)^2*t)*cos(4*pi*x).

The code computes u at T=1.0, saves "solution_agent_heat_05.npz" containing arrays x, u and scalars T, dx, dt, saves a line plot as "solution_agent_heat_05.png", and prints min(u), max(u), discrete L2 norm, max absolute error, and L2 error versus the exact solution.

```python
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla
import matplotlib.pyplot as plt

# Parameters
alpha = 0.05
T_final = 1.0
Nx = 256
dx = 1.0 / Nx
dt = 0.001
n_steps = int(T_final / dt)

# Grid: Nx points on [0, 1), no duplicate at x=1
x = np.linspace(0, 1, Nx, endpoint=False)

# Initial condition
u = np.sin(2 * np.pi * x) + 0.2 * np.cos(4 * np.pi * x)

# Build discrete Laplacian L (periodic, 2nd order central)
# L u = (u_{i+1} - 2*u_i + u_{i-1}) / dx^2
r = 1.0 / (dx * dx)
main_diag = -2.0 * r * np.ones(Nx)
off_diag = r * np.ones(Nx)
L = sp.diags([off_diag, main_diag, off_diag], [-1, 0, 1], shape=(Nx, Nx), format='csr')
# Apply periodic wrap-around
L[0, -1] = r
L[-1, 0] = r

# Crank-Nicolson matrices
A = sp.eye(Nx) - 0.5 * dt * alpha * L
B = sp.eye(Nx) + 0.5 * dt * alpha * L

# Time stepping
for n in range(n_steps):
    rhs = B @ u
    u = spla.spsolve(A, rhs)

# Compute exact solution at T=1.0
t = T_final
u_exact = (np.exp(-0.05 * (2 * np.pi)**2 * t) * np.sin(2 * np.pi * x) +
           0.2 * np.exp(-0.05 * (4 * np.pi)**2 * t) * np.cos(4 * np.pi * x))

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
L2_norm = np.sqrt(np.sum(u**2) * dx)
max_err = np.max(np.abs(u - u_exact))
L2_err = np.sqrt(np.sum((u - u_exact)**2) * dx)

print(f"min(u) = {u_min:.10e}")
print(f"max(u) = {u_max:.10e}")
print(f"L2 norm = {L2_norm:.10e}")
print(f"max absolute error = {max_err:.10e}")
print(f"L2 error = {L2_err:.10e}")

# Save NPZ
np.savez("solution_agent_heat_05.npz", x=x, u=u, T=T_final, dx=dx, dt=dt)

# Save plot
plt.figure(figsize=(8, 5))
plt.plot(x, u, 'b-', label='Numerical')
plt.plot(x, u_exact, 'r--', label='Exact')
plt.xlabel('x')
plt.ylabel('u(x,T)')
plt.title(f'Heat equation solution at T={T_final}')
plt.legend()
plt.tight_layout()
plt.savefig("solution_agent_heat_05.png", dpi=150)
plt.close()
```
