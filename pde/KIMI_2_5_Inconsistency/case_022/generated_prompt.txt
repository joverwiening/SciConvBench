The PDE is the 2D heat/diffusion equation with constant diffusivity D=0.05 on the unit square [0,1]×[0,1] with zero-flux Neumann boundary conditions on all edges.

The spatial discretization uses a uniform grid with Nx=Ny=80 intervals, giving 81×81 grid points including boundaries, with dx=dy=1/80=0.0125. The 5-point Laplacian stencil is applied with ghost-node implementation for Neumann BC: ghost points are set equal to their interior mirror points to enforce zero normal derivative.

The time integration uses implicit Euler with dt=0.001 for 500 steps to reach T=0.5. At each step, solve (I - dt*D*L)u^{n+1} = u^n where L is the discrete Laplacian matrix. The system is solved efficiently using sparse linear algebra.

The initial condition is a Gaussian blob centered at (0.3, 0.7) with amplitude 1 and width parameter 80: u(x,y,0) = exp(-80*((x-0.3)^2 + (y-0.7)^2)).

The solution at T=0.5 is computed and saved to "solution_agent_diffusion_06.npz" containing: x (1D array of 81 points), y (1D array of 81 points), u (2D array with shape (81,81) where u[j,i] = u(x[i], y[j])), plus scalars T=0.5, dx, dy, dt.

A heatmap/contour plot is saved as "solution_agent_diffusion_06.png".

Reported diagnostics at T=0.5: min(u), max(u), discrete L2 norm sqrt(sum(u^2)*dx*dy).

Mass conservation check: compute total mass M(t) = sum(u)*dx*dy at t=0 and t=T, print M(0), M(T), and relative change (M(T)-M(0))/M(0). With pure diffusion and zero-flux BC, the relative change should be small (on order of machine precision or solver tolerance).
