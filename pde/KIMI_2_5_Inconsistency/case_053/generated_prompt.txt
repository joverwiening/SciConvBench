The task is to solve the 2D Klein-Gordon PDE numerically with the following complete specification:

The PDE is u_tt - (0.8)^2*(u_xx + u_yy) + (0.2)^2*u = 0 on the domain (x,y) in [0,1] x [0,1] with t in [0,1.0].

The parameters are c = 0.8 and m = 0.2.

Boundary conditions are Dirichlet with u=0 on all boundaries.

Initial conditions are u(x,y,0) = sin(2*pi*x)*sin(pi*y) and u_t(x,y,0) = 0.

The exact solution for verification is u(x,y,t) = cos(sqrt((0.8)^2*((2*pi)^2 + (pi)^2) + (0.2)^2)*t) * sin(2*pi*x)*sin(pi*y).

Spatial discretization uses a uniform grid with Nx=Ny=160 intervals, giving 161 points in each direction including endpoints. The grid spacing is dx=dy=1/160. The 5-point Laplacian stencil is used for u_xx+u_yy.

Time integration uses 2nd-order central differencing for u_tt. The time step is determined by dt0 = 0.5*min(dx,dy)/c with CFL=0.5. The number of time steps is Nt = ceil(T/dt0) and dt = T/Nt is set so the final time T=1.0 is hit exactly.

Initialization uses a Taylor expansion: u^1 = u^0 + dt*u_t^0 + 0.5*dt^2*(c^2*Laplacian(u^0) - m^2*u^0), where u_t^0=0.

The time stepping scheme is: u^{n+1} = 2*u^n - u^{n-1} + dt^2*(c^2*Laplacian(u^n) - m^2*u^n).

The output requirements are: compute u(x,y,T=1.0) on the 2D grid; save "solution_agent_kg_06.npz" containing arrays x (1D), y (1D), u (2D array with shape (len(y), len(x)) so u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt; save a heatmap/contour plot as "solution_agent_kg_06.png"; print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T; compute and print the max absolute error and L2 error versus the reference solution evaluated on the same grid.

Note: The user specified T=1.1 in the output requirements but T=1.0 in the domain specification. The domain specification takes precedence, so T=1.0 is used for the final time.
