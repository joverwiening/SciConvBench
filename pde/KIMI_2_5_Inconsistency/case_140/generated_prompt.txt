The task is to solve the 1D advection equation u_t + beta * u_x = 0 with beta=2.0 on the periodic domain [0,1) with initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x), using first-order upwind spatial discretization and forward Euler time integration with CFL=0.5, computing the solution at T=2.0 (note: the output requirement says T=2.1 but the domain specification says t in [0,2.0]; I will use T=2.0 as specified in the domain and reference solution description, which is physically consistent).

The numerical method shall be implemented as follows.

Use Nx=512 grid points on the periodic domain [0,1), giving dx=1/512.

Compute the time step as dt = CFL * dx / abs(beta) = 0.5 * dx / 2.0 = 0.25 * dx.

Set Nt = ceil(T/dt) and reset dt = T/Nt to hit the final time exactly.

For spatial discretization, use first-order upwind: since beta=2.0 > 0, the upwind direction is to the left, so approximate u_x at point j as (u_j - u_{j-1}) / dx, with periodic indexing (j-1 wraps to Nx-1 when j=0).

Use forward Euler time integration: u^{n+1}_j = u^n_j - dt * beta * (u^n_j - u^n_{j-1}) / dx.

Initialize u_j = sin(2*pi*x_j) + 0.5*sin(4*pi*x_j) for j=0,...,Nx-1.

Advance Nt steps to reach time T.

After computing the numerical solution at time T, compute the reference solution as u_ref(x_j,T) = u0((x_j - beta*T) mod 1), where u0(x) = sin(2*pi*x) + 0.5*sin(4*pi*x), and the modulo operation returns a value in [0,1).

Compute and print: min(u), max(u), discrete L2 norm sqrt(sum(u^2)*dx), max absolute error vs reference, and L2 error vs reference.
