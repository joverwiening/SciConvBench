The task is to solve a 2D Darcy flow elliptic PDE with variable coefficient using finite differences.

The PDE is -∇ · (a(x,y) ∇u(x,y)) = 1 on the domain (0,1) × (0,1) with Dirichlet boundary conditions u = 0 on all boundaries.

The coefficient field is a(x,y) = 1 + 2 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) = 1 + 1 + sin(2*pi*x)*sin(2*pi*y) = 2 + sin(2*pi*x)*sin(2*pi*y).

Use a uniform Cartesian grid with N = 128 intervals in each direction, giving N+1 = 129 points per dimension including boundaries. The grid spacing is dx = dy = 1/128. Grid points are x_i = i*dx for i = 0,...,128 and y_j = j*dy for j = 0,...,128.

Discretize using 2nd-order finite differences with variable coefficient via face-centered harmonic averaging. For interior nodes (i=1..127, j=1..127), the discrete equation is:
-(1/dx^2) * [ a_{i+1/2,j}*(u_{i+1,j}-u_{i,j}) - a_{i-1/2,j}*(u_{i,j}-u_{i-1,j}) + a_{i,j+1/2}*(u_{i,j+1}-u_{i,j}) - a_{i,j-1/2}*(u_{i,j}-u_{i,j-1}) ] = 1

where face coefficients use harmonic averaging: a_{i+1/2,j} = 2*a_{i,j}*a_{i+1,j} / (a_{i,j} + a_{i+1,j}), and similarly for other faces.

Assemble the sparse linear system Au = b for the interior unknowns (127 × 127 = 16129 unknowns). Solve using conjugate gradient (CG) with tolerance 1e-10 on the relative residual. Use a Jacobi preconditioner (diagonal preconditioning) where the preconditioner is the inverse of the diagonal of A.

Compute the coefficient field a(x,y) on the full (N+1) × (N+1) grid. Compute face-centered harmonic averages for all interior faces in x and y directions.

Apply Dirichlet boundary conditions by setting u = 0 on all boundary points (i=0, i=128, j=0, j=128) and incorporating these into the right-hand side for interior equations.

After solving, reconstruct the full solution array including boundaries.

Save "solution_pdebench_darcy_beta1.npz" containing: x (1D array of shape (129,)), y (1D array of shape (129,)), u (2D array of shape (129, 129)), beta (scalar 2), N (scalar 128), dx (scalar 1/128).

Save a heatmap/contour plot of u(x,y) as "solution_pdebench_darcy_beta1.png" with appropriate color scale and labels.

Print min(u), max(u), and the discrete residual norm ||Au-b||_2 / ||b||_2 computed on the interior system.
