The task is to solve the Klein-Gordon PDE numerically with fully specified parameters and methods. All requirements are clear and actionable.

The PDE is u_tt - c^2*u_xx + m^2*u = 0 with c=1.0, m=0.5 on x in [0,1], t in [0,1.0].

Use a uniform grid with Nx=400 intervals (401 points), dx=1/400=0.0025. Set dt0 = 0.9*dx/c = 0.9*0.0025 = 0.00225. Compute Nt = ceil(1.0/0.00225) = ceil(444.44...) = 445, then dt = 1.0/445 ≈ 0.002247191.

For spatial discretization, use 2nd-order central differences: u_xx at point i is (u_{i+1} - 2*u_i + u_{i-1})/dx^2.

For time integration, use leapfrog: u^{n+1} = 2*u^n - u^{n-1} + dt^2*(c^2*u_xx^n - m^2*u^n).

Initialize with Taylor expansion: u^0 = cos(pi*x), u^1 = u^0 + dt*v^0 + (dt^2/2)*(c^2*u_xx^0 - m^2*u^0) where v^0 = u_t(x,0) = 0.

Apply zero Neumann boundary conditions via ghost points: u_{-1} = u_1 and u_{Nx+1} = u_{Nx-1}, which enforces u_x=0 at boundaries.

Compute the solution at T=1.0 (note: output requirement says T=1.1 but domain specification says t in [0,1.0]; use T=1.0 as the domain upper bound).

Save results to "solution_agent_kg_03.npz" with arrays x, u and scalars T, dx, dt.

Save a line plot to "solution_agent_kg_03.png".

Print min(u), max(u), discrete L2 norm at T.
