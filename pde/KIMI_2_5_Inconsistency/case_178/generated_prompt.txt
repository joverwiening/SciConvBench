The task is to numerically solve a 1D reaction-diffusion PDE with logistic reaction using Strang splitting on a periodic domain.

The PDE is u_t = nu * u_xx + rho * u*(1 - u) with nu=10.0 and rho=2.0.

The spatial domain is [0,1) with periodic boundary conditions, using Nx=512 grid points with dx=1/512, giving x_j = j*dx for j=0,...,511.

The time domain is [0,1.0] with fixed dt=0.001 and Nt=1000 steps.

The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).

The numerical method uses Strang splitting with three substeps per time step: (A) exact diffusion half-step in Fourier space, (B) exact reaction full-step using the logistic ODE analytical solution, (C) exact diffusion half-step in Fourier space.

For the diffusion step, compute FFT of u, apply the factor exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx,d=dx), then take IFFT and use the real part.

For the reaction step, update each point as u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).

After completing all time steps to reach T=1.0, save the solution to "solution_pdebench_reacdiff_nu10_rho2.npz" containing arrays x and u, and scalars nu, rho, T, dx, dt, Nx, Nt.

Save a line plot of u(x,T) to "solution_pdebench_reacdiff_nu10_rho2.png".

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
