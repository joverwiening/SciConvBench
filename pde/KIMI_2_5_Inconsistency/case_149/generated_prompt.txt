The task is to solve the 1D viscous Burgers equation with periodic boundary conditions using a specific numerical method and produce the requested outputs.

The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx with nu=1.0, on domain x in [0,1) periodic, t in [0,1.0].

The initial condition is u(x,0) = sin(2*pi*x).

The numerical method uses Strang splitting with three substeps per time step: (A) exact diffusion half-step in Fourier space, (B) advection full-step using finite-volume Rusanov flux, (C) exact diffusion half-step in Fourier space.

The spatial grid uses Nx=512 points on [0,1) with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.

The time step uses CFL=0.4 with estimated max speed 1.0, computing dt0 = CFL*dx/1.0, then Nt = ceil(T/dt0), and resetting dt = T/Nt to hit final time exactly.

The diffusion substep (A and C) computes: u_hat = FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat = u_hat * exp(-nu*k**2*(dt/2)), u = real(IFFT(u_hat)).

The advection substep (B) uses Rusanov flux: for each interface between u_left and u_right (periodic), alpha = max(abs(u_left), abs(u_right)), F = 0.5*(0.5*u_left**2 + 0.5*u_right**2) - 0.5*alpha*(u_right - u_left). For each cell j: F_plus = flux(j,j+1), F_minus = flux(j-1,j), u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).

The output requires: compute u(x,T=1.0), save "solution_pdebench_burgers_nu1.npz" containing x, u, nu, T, dx, dt, Nx, Nt, save line plot as "solution_pdebench_burgers_nu1.png", and print min(u), max(u), mean(u), and sqrt(sum(u**2)*dx) at T.
