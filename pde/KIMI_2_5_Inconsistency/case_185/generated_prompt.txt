The task is to numerically solve a 1D reaction-diffusion PDE with logistic reaction and periodic boundary conditions using Strang splitting with explicit forward Euler time stepping.

The PDE is u_t = nu * u_xx + rho * u*(1 - u) with nu = 2.0 and rho = 10.0.

The spatial domain is x in [0, 1) with periodic boundary conditions, using a uniform periodic grid with Nx = 512 points where x_j = j*dx for j = 0,...,Nx-1 and dx = 1/Nx.

The time domain is t in [0, 1.0] with fixed time step dt = 0.001 and Nt = 1000 steps.

The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x), with all trigonometric functions evaluated in radians.

The numerical method uses Strang splitting for each full time step dt: first a diffusion half-step solved exactly in Fourier space using FFT, then a reaction full-step solved exactly pointwise for the logistic ODE, then another diffusion half-step. The diffusion step applies the exact Fourier multiplier exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx). The reaction step uses the exact solution u_new = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).

The code must compute u(x, T=1.0) on the periodic grid.

The code must save "solution_pdebench_reacdiff_nu2_rho10.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.

The code must save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu2_rho10.png".

The code must print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
