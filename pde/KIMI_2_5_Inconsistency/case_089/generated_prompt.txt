The task is to solve the 2D wave equation numerically with the following specifications:

The PDE is u_tt = (0.7)^2 * (u_xx + u_yy), which represents a wave equation with wave speed c = 0.7.

The spatial domain is (x,y) in [0,1] x [0,1] with time t in [0,0.8].

The boundary conditions are Dirichlet with u=0 on all boundaries.

The initial conditions are u(x,y,0) = sin(2*pi*x)*sin(pi*y) and u_t(x,y,0) = 0.

The exact solution for verification is u(x,y,t) = cos(0.7*pi*sqrt(5)*t)*sin(2*pi*x)*sin(pi*y).

Use a uniform grid with Nx=Ny=140 intervals, giving 141x141 grid points including boundaries. Set dx=dy=1/140.

Compute dt0 = 0.9 / (0.7*sqrt(1/dx^2 + 1/dy^2)) for CFL stability. Set Nt = ceil(0.8/dt0) and dt = 0.8/Nt to hit the final time exactly.

Use the 5-point Laplacian for spatial discretization: (u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1} - 4*u_{i,j}) / dx^2.

Use 2nd-order central difference in time: (u^{n+1} - 2*u^n + u^{n-1}) / dt^2 = c^2 * Laplacian(u^n).

Initialize using Taylor expansion with zero initial velocity: u^1 = u^0 + 0.5*dt^2*c^2*Laplacian(u^0).

Apply Dirichlet boundary conditions by setting boundary nodes to zero at each time step.

At final time T=0.8, compute and save the solution to "solution_agent_wave_08.npz" containing arrays x (1D, length 141), y (1D, length 141), u (2D with shape (141,141) where u[j,i] = u(x[i], y[j])), and scalars T=0.8, dx, dy, dt.

Save a heatmap plot to "solution_agent_wave_08.png".

Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy) at T=0.8.

Compute and print max absolute error and L2 error against the exact solution evaluated on the same grid.
