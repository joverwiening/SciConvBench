The task is to solve a 1D reaction-diffusion PDE with logistic reaction and periodic boundary conditions using Strang splitting with exact Fourier diffusion and exact pointwise reaction updates.

The PDE is u_t = nu * u_xx + rho * u*(1 - u) with nu = 5.0 and rho = 10.0 on the domain x in [0,1) with periodic boundary conditions and t in [0,1.0].

The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Use a uniform periodic grid with Nx = 512 points on [0,1), so dx = 1/512 and x_j = j*dx for j = 0,...,511.

Use a fixed time step dt = 0.001 with Nt = 1000 steps to reach T = 1.0 exactly.

Implement Strang splitting for each full time step dt: first apply a diffusion half-step of duration dt/2 solved exactly in Fourier space using FFT, then apply a reaction full-step of duration dt solved exactly pointwise using the logistic ODE exact solution u_new = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)), then apply another diffusion half-step of duration dt/2.

For the diffusion half-step in Fourier space: compute u_hat = FFT(u), compute wave numbers k = 2*pi*fftfreq(Nx, d=dx), update u_hat(k) = u_hat(k) * exp(-nu*k**2*(dt/2)), then compute u = real(IFFT(u_hat)).

Compute the solution u(x, T=1.0) on the periodic grid.

Save the file "solution_pdebench_reacdiff_nu5_rho10.npz" containing arrays x (1D length Nx) and u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.

Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu5_rho10.png".

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.
