The task is to numerically solve the Klein-Gordon PDE with the following complete specification:

The PDE is u_tt - (1.0)^2*u_xx + (1.0)^2*u = 0, which simplifies to u_tt - u_xx + u = 0.

The spatial domain is x in [0,1] and time domain is t in [0,1.0].

The parameters are c = 2 and m = 1.0, though note that c does not appear in the PDE itself (the wave speed coefficient in u_xx is fixed at 1.0), and m = 1.0 appears as the coefficient in the mass term m^2*u = 1.0^2*u = u.

Boundary conditions are Dirichlet with u = 0 at x = 0 and x = 1 for all time.

Initial conditions are u(x,0) = sin(pi*x) and u_t(x,0) = 0.

The exact reference solution is u(x,t) = cos(sqrt((1.0*pi)^2 + (1.0)^2)*t) * sin(pi*x) = cos(sqrt(pi^2 + 1)*t) * sin(pi*x).

For spatial discretization, use a uniform grid on [0,1] with Nx = 400 intervals, giving Nx + 1 = 401 grid points including both endpoints. The grid spacing is dx = 1/Nx = 0.0025. Use second-order central differences for u_xx.

For time integration, use second-order central difference in time (leapfrog) for u_tt. Handle the +m^2*u term explicitly at time level n in the update. Compute dt0 = 0.9*dx/c = 0.9*0.0025/2 = 0.001125. Set Nt = ceil(T/dt0) = ceil(1.0/0.001125) = ceil(888.888...) = 889. Then set dt = T/Nt = 1.0/889 ≈ 0.001124859 so that the final time T = 1.0 is hit exactly.

For initialization, use Taylor start from u0 and v0, including the -m^2*u0 term (and forcing if present, though there is none here).

Compute u(x, T=1.0) on the grid.

Save "solution_agent_kg_01.npz" containing arrays x (1D, length 401), u (1D, same length as x), plus metadata scalars T, dx, dt.

Save a line plot of u(x,T) as "solution_agent_kg_01.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.

Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
