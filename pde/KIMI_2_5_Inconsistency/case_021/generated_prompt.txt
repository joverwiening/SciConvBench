The spatial discretization uses Nx=300 uniform intervals, giving Nx+1=301 grid points with dx=1/300. The grid points are x_i = i*dx for i=0,...,300.

The initial condition is u(x,0) = cos(pi*x).

The boundary conditions are Robin: u_x + beta*u = 0 at both boundaries with beta=1.0. These are implemented using 2nd-order one-sided differences for u_x:

- At x=1: (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx) + beta*uN = 0

(u^{n+1}_i - u^n_i)/dt = 0.5*D*(u^{n+1}_{i-1} - 2*u^{n+1}_i + u^{n+1}_{i+1})/dx^2 + 0.5*D*(u^n_{i-1} - 2*u^n_i + u^n_{i+1})/dx^2

The Robin boundary conditions are incorporated into the linear system. At each boundary, the Robin condition provides a relationship that eliminates the ghost point, resulting in modified equations for the boundary rows of the tridiagonal system.
