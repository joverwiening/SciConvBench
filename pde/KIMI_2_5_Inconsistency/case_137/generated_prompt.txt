The task is to solve the 1D advection equation u_t + beta * u_x = 0 with beta = 0.4 on a periodic domain [0,1) with initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x), using a 1st-order upwind spatial discretization and forward Euler time integration with CFL=0.5, computing the solution at T=2.0 (note: the output requirement says T=2.1 but the domain specification says t in [0,2.0]; use T=2.0 as specified in the domain section).

Use a uniform periodic grid with Nx = 512 points, where x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx = 1/512.

For the spatial discretization, use 1st-order upwind finite difference: since beta = 0.4 > 0, use the backward difference u_x ≈ (u_j - u_{j-1})/dx with periodic indexing (j-1 wraps to Nx-1 when j=0).

For time integration, use explicit forward Euler: u^{n+1}_j = u^n_j - dt * beta * (u^n_j - u^n_{j-1})/dx.

Compute the time step using CFL = 0.5: dt = CFL * dx / abs(beta) = 0.5 * dx / 0.4. Then set Nt = ceil(T/dt) and reset dt = T/Nt to hit the final time exactly.

Compute the solution at T = 2.0 on the periodic grid.

Save the file "solution_pdebench_advection_beta0p4.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.

Save a line plot of u(x,T) as "solution_pdebench_advection_beta0p4.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.

Compute and print the max absolute error and L2 error against the reference solution u_ref(x,T) = u0((x - beta*T) mod 1), where u0(x) = sin(2*pi*x) + 0.5*sin(4*pi*x), evaluated on the same x grid.
