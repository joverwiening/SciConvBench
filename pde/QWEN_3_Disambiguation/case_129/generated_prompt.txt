Solve the 1D inviscid conservation law with cubic flux using a finite-volume method on a periodic domain.  
The PDE is ∂u/∂t = -∂/∂x( (1/3)u^3 ).  
The spatial domain is x ∈ [0, 1) with periodic boundary conditions.  
The time domain is t ∈ [0, 0.2].  
Set k = 1.0.  
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.  
Use the initial condition u(x,0) = 0.5*sin(2*pi*x).  
Discretize space with Nx = 1024 uniform grid points on [0, 1).  
Compute dx = 1 / Nx.  
Define grid points as x_j = j*dx for j = 0, 1, ..., 1023.  
Use a conservative finite-volume spatial discretization.  
Compute the flux function f(u) = (1/3)*u^3.  
Use the Rusanov flux for numerical flux computation.  
The Rusanov flux at each interface is (1/2)*(f(u_left) + f(u_right)) - (1/2)*λ*(u_right - u_left), where λ = max(|f'(u_left)|, |f'(u_right)|).  
For this flux, f'(u) = u^2, so λ = max(u_left^2, u_right^2).  
Use SSP-RK2 (second-order strong stability preserving Runge-Kutta) for time integration.  
Estimate the maximum wave speed initially: max|f'(u)| = max|u^2| ≤ 0.25, since |u| ≤ 0.5 at t=0.  
Set the initial time step estimate dt0 = CFL * dx / max|f'|, with CFL = 0.2.  
Compute dt0 = 0.2 * dx / 0.25.  
Set Nt = ceil(0.2 / dt0).  
Set final time step dt = 0.2 / Nt.  
Use Nt uniform time steps of size dt.  
At each time step, update the solution using the finite-volume method with Rusanov flux and SSP-RK2.  
Ensure periodicity by wrapping ghost cell values appropriately in flux computations.  
Output the solution u(x,t) at final time t=0.2.
