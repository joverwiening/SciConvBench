Use the following specification to solve the 1D viscous Burgers equation numerically.  
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 0.2.  
The spatial domain is [0, 1) with periodic boundary conditions.  
The initial condition is u(x,0) = sin(2*pi*x).  
Use a uniform spatial grid with Nx = 512 points.  
Compute dx = (1 - 0) / Nx.  
Set the final time T = 1.0.  
Use Strang splitting for time integration with the following substeps:  
First, perform a diffusion half-step of duration dt/2 using exact integration in Fourier space:  
Compute the FFT of u to obtain u_hat.  
Define wavenumbers k = 2*pi*fftfreq(Nx, d=dx).  
Update u_hat(k) = u_hat(k) * exp(-nu * k^2 * (dt/2)).  
Perform the inverse FFT and take the real part to get u.  
Second, perform a full advection step of duration dt using the inviscid Burgers equation:  
Use a finite-volume method with Rusanov (local Lax-Friedrichs) flux.  
Define flux function f(u) = 0.5 * u**2.  
For each interface between u[j] and u[j+1] (with periodic indexing):  
Compute alpha = max(abs(u[j]), abs(u[j+1])).  
Compute flux F = 0.5 * (f(u[j]) + f(u[j+1])) - 0.5 * alpha * (u[j+1] - u[j]).  
For each cell j, compute F_plus (flux from j to j+1) and F_minus (flux from j-1 to j).  
Update u_new[j] = u[j] - (dt/dx) * (F_plus - F_minus).  
Set u = u_new after the advection step.  
Third, perform another diffusion half-step identical to the first.  
Estimate the maximum wave speed as 1.0 for CFL-based time step calculation.  
Set dt0 = 0.4 * dx / 1.0 based on CFL number 0.4.  
Compute Nt = ceil(T / dt0).  
Set dt = T / Nt to ensure exact final time.  
Iterate over Nt time steps, applying the Strang splitting procedure at each step.  
At final time T = 1.0, compute the solution u(x, T) on the grid.
