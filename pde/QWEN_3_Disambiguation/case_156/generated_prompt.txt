Solve the 1D compressible Navier–Stokes equations without heat conduction on the domain x in [-1, 1] and t in [0, 0.5].  
Use the conservative variables: density rho, momentum m = rho*v, and total energy E = p/(Gamma-1) + 0.5*rho*v^2.  
Set Gamma = 1.6666666666666667, eta = 0.1, and zeta = eta = 0.1.  
Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1], so dx = (1 - (-1)) / 400 = 0.005.  
Define cell centers as x_j = -1 + (j + 0.5)*dx for j = 0 to 399.  
Apply periodic boundary conditions at x = -1 and x = 1 by wrapping indices.  
Initialize the solution using:
  rho(x,0) = 1.0 + 0.2*sin(pi*x)
  v(x,0)   = 0.1*cos(pi*x)
  p(x,0)   = 1.0 + 0.2*cos(pi*x)
Compute initial conservative variables as:
  rho = rho(x,0)
  m   = rho(x,0) * v(x,0)
  E   = p(x,0)/(Gamma-1) + 0.5*rho(x,0)*v(x,0)^2
Use the equation of state: p = (Gamma-1)*(E - 0.5*m^2/rho), and clip rho and p to a floor of 1e-12 if needed to maintain positivity.  
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part:
  F_conv(U) = [m, m^2/rho + p, (E+p)*v] where v = m/rho.  
Compute the interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R), with c = sqrt(Gamma*p/rho).  
Compute the numerical flux as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).  
Compute the viscous stress sigma = (zeta + 4/3*eta)*v_x using centered differences on cell-centered v to get v_x.  
Average the cell-centered sigma values to obtain sigma at interfaces.  
Compute the viscous flux as F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.  
Set the total interface flux as F_total = F_hat + F_visc.  
Advance in time using 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.  
Determine the time step at each iteration using:
  dt_conv = CFL * dx / max_j(|v_j| + c_j), with CFL = 0.4
  dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30)
  dt = min(dt_conv, dt_visc)
Adjust the final time step to ensure the solution reaches T = 0.5 exactly.  
At final time T = 0.5, compute the primitive variables on cell centers:

  p(x,T)   = (Gamma-1)*(U[2] - 0.5*U[1]^2/U[0])
