Solve the 1D advection–diffusion equation with space-dependent drift and periodic boundary conditions.  
The PDE is: u_t = D * u_xx - (1/gamma) * ∂_x(U'(x) * u), where U(x) = cos(2*pi*x).  
Use D = 0.01 and gamma = 1.0.  
The spatial domain is x ∈ [0, 1) with periodic boundary conditions.  
The time domain is t ∈ [0, 1.0].  
Discretize the spatial domain using Nx = 512 uniform grid points on [0, 1).  
Compute dx = 1 / Nx and define grid points as x_j = j * dx for j = 0, 1, ..., Nx-1.  
Use periodic boundary conditions: u(0,t) = u(1,t) for all t.  
Set the initial condition: u(x,0) = 1.0 + 0.2 * sin(2*pi*x).  
Compute U'(x) = -2 * pi * sin(2*pi*x).  
Define the drift velocity at grid points: b_j = U'(x_j) / gamma.  
Treat the drift term in conservative form: flux F = (1/gamma) * U'(x) * u.  
Discretize the spatial derivative ∂_x(F) using upwind finite-volume flux based on the sign of b_j at each interface.  
Use second-order central differences for the diffusion term D * u_xx.  
Use explicit SSP-RK2 (second-order strong stability preserving Runge-Kutta) for time integration.  
Compute the maximum absolute drift velocity: max|b| = max(|b_j|) over all grid points.  
Set the time step dt = min(0.4 * dx / max|b|, 0.2 * dx**2 / D).  
Compute Nt = ceil(1.0 / dt), then set the actual dt = 1.0 / Nt.  
Advance the solution from t = 0 to t = 1.0 using Nt uniform time steps.  
Output the final solution u(x,t) at t = 1.0.  
All trigonometric functions are evaluated in radians.  
In code, use ** for exponentiation (e.g., dx**2).
