Solve the 1D viscous Burgers equation with periodic boundary conditions: u_t + ∂_x(0.5*u^2) = nu * u_xx.
Set the viscosity parameter nu = 0.01.
Use the initial condition u(x,0) = sin(2*pi*x).
Impose periodic boundary conditions: u(0,t) = u(1,t) for all t.
Use a uniform spatial grid with Nx = 512 points over the domain [0,1), so dx = 1/512.
Compute the time step dt0 using CFL = 0.4 and maximum wave speed estimate of 1.0: dt0 = 0.4 * dx / 1.0.
Set the final simulation time T = 1.0.
Determine the number of time steps as Nt = ceil(T / dt0), then set dt = T / Nt to ensure exact final time.
Use Strang splitting for time integration: perform a diffusion half-step (dt/2), then an advection full-step (dt), then another diffusion half-step (dt/2).
For the diffusion steps, solve exactly in Fourier space: compute u_hat = FFT(u), apply the exponential filter exp(-nu * k^2 * (dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then take real part of IFFT(u_hat).
For the advection step, solve the inviscid Burgers equation using finite-volume method with Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u) = 0.5 * u^2.
At each cell interface, compute flux F using: alpha = max(|u_left|, |u_right|), F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell value via: u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is flux at right interface and F_minus at left interface, using periodic indexing.
After completing the full time step, update u = u_new.
Repeat the Strang splitting steps until final time T is reached.
Construct the spatial coordinate array x_i = i*dx for i = 0 to Nx-1.
Save the results in a .npz file named "solution_pdebench_burgers_nu0p01.npz" containing: x, u, nu, T, dx, dt, Nx, Nt.
Generate a line plot of u(x,T) versus x and save it as "solution_pdebench_burgers_nu0p01.png".
