Use a uniform finite-volume grid with Nx = 400 cells on the spatial domain [-1, 1].  
Compute the cell size as dx = (1 - (-1)) / 400 = 0.005.  
Set the cell centers at x_j = -1 + (j + 0.5) * dx for j = 0 to 399.  
Use periodic boundary conditions by wrapping indices.  
Represent the solution using conservative variables U = [rho, m, E] stored as cell averages.  
Initialize the fields using the given smooth initial conditions:  
- rho(x,0) = 1.0 + 0.2*sin(pi*x)  
- v(x,0) = 0.1*cos(pi*x)  
- p(x,0) = 1.0 + 0.2*cos(pi*x)  
Compute initial m = rho * v and E = p/(Gamma-1) + 0.5*rho*v^2.  
Use Gamma = 1.6666666666666667, eta = 0.01, zeta = 0.01.  
Use the equation of state p = (Gamma-1)*(E - 0.5*m^2/rho), with rho and p clipped to a floor of 1e-12 if needed.  
For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux:  
- Compute F_conv(U) = [m, m^2/rho + p, (E+p)*v] with v = m/rho.  
- At each interface, compute the wave speed a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma*p/rho).  
- Compute the numerical flux as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).  
For viscous terms:  
- Compute cell-centered velocity gradient v_x using centered differences.  
- Compute cell-centered sigma = (zeta + 4/3*eta) * v_x.  
- Average sigma and v to interfaces using arithmetic mean.  
- Add viscous flux F_visc = [0, -sigma_interface, -v_interface*sigma_interface] to the total flux.  
- Total interface flux is F_total = F_hat + F_visc.  
Use 2-stage SSP-RK2 (Heun's method) for time integration.  
Set CFL = 0.4 for the convective time step constraint.  
Compute dt_conv = CFL * dx / max_j(|v_j| + c_j) at each time step.  
Compute dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).  
Set dt = min(dt_conv, dt_visc), and adjust the final step to reach T = 0.5 exactly.
