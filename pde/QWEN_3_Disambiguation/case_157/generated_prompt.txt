The domain is x in [-1, 1] with Nx = 400 uniform cells.
The grid has dx = (1 - (-1)) / 400 = 0.005.
Cell centers are located at x_j = -1 + (j + 0.5)*dx for j = 0 to 399.
The final time is T = 0.5.
The conservative variables evolved are U = [rho, m, E], where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
The equation of state is p = (Gamma-1)*(E - 0.5*m^2/rho), with rho and p clipped to a floor of 1e-12 if necessary.
The convective flux uses the Rusanov (local Lax-Friedrichs) numerical flux with wave speed a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma*p/rho).
The inviscid flux is F_conv = [m, m^2/rho + p, (E+p)*v] with v = m/rho.
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The viscous stress is sigma = (zeta + 4/3*eta)*v_x, with zeta = eta = 1e-8.
The velocity gradient v_x is computed via centered differences on cell-centered v values.
Interface values of sigma and v are obtained by averaging adjacent cell-centered values.
The viscous flux is F_visc = [0, -sigma, -v*sigma] at each interface.
The total interface flux is F_total = F_hat + F_visc.
Time integration is performed using 2-stage SSP-RK2 (Heun's method).
The time step is chosen as dt = min(dt_conv, dt_visc), where dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
The CFL number is not specified; use a default value of 0.4 unless otherwise constrained.
The final time step is adjusted to ensure the simulation ends exactly at T = 0.5.
Boundary conditions are transmissive/outflow: ghost cells are set equal to the nearest interior cell (zero-gradient).
Initial conditions are:
  rho(x,0) = 1.0 + 0.2*sin(pi*x)
  v(x,0)   = 0.1*cos(pi*x)
  p(x,0)   = 1.0 + 0.2*cos(pi*x)
The solution is output at T = 0.5 as rho(x,T), v(x,T), p(x,T) on cell centers.
