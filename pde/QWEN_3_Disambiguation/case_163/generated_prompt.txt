Use a uniform finite-volume grid with Nx = 800 cells on the spatial domain [-1, 1].
Compute dx as (1 - (-1)) / 800 = 0.0025.
Define cell centers as x_j = -1 + (j + 0.5) * dx for j = 0 to 799.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Use the equation of state p = (Gamma - 1) * (E - 0.5 * m^2 / rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if necessary.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part with interface wave speed a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma * p / rho).
Compute the convective flux F_conv(U) = [m, m^2 / rho + p, (E + p) * v] with v = m / rho.
Compute the numerical flux F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L).
Compute the viscous stress sigma = (zeta + 4/3 * eta) * v_x using centered differences for v_x on cell-centered velocities.
Average sigma and v to interfaces to compute the viscous flux F_visc = [0, -sigma, -v * sigma].
Set the total interface flux F_total = F_hat + F_visc.
Use SSP-RK2 (Heun's method) for time integration.
Compute the time step dt as the minimum of dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3 * eta, 1e-30).
Adjust the final time step to ensure the solution reaches T = 0.2 exactly.
Implement outflow (zero-gradient) boundary conditions by setting ghost cell values equal to the nearest interior cell values.
Compute the solution at final time T = 0.2.
