Use a uniform finite-volume grid with Nx = 400 cells on the spatial domain [-1, 1].
Compute dx as (1 - (-1)) / Nx, so dx = 0.005.
Define cell centers as x_j = -1 + (j + 0.5) * dx for j = 0 to 399.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Use the equation of state p = (Gamma - 1) * (E - 0.5 * m^2 / rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if necessary.
Apply periodic boundary conditions by wrapping indices.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part.
Compute interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma * p / rho).
Calculate the numerical convective flux as F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L).
Compute viscous stress sigma using centered differences on cell-centered velocity v.
Obtain interface values of sigma by averaging adjacent cell-centered values.
Use interface-averaged v and sigma to compute viscous flux F_visc = [0, -sigma, -v * sigma].
Set total interface flux F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Determine time step each iteration using:
  dt_conv = CFL * dx / max_j(|v_j| + c_j)
  dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30)
  dt = min(dt_conv, dt_visc)
Adjust the final time step to ensure the solution reaches T = 0.5 exactly.
