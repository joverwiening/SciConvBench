Use a uniform finite-volume grid with Nx = 800 cells on the spatial domain [-1, 1].
Compute the cell size as dx = (1 - (-1)) / 800 = 0.0025.
Define cell centers as x_j = -1 + (j + 0.5) * dx for j = 0 to 799.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Use the equation of state p = (Gamma - 1) * (E - 0.5 * m^2 / rho) to compute pressure.
Enforce positivity by clipping rho and p to a floor of 1e-12 if necessary.
Use Gamma = 1.6666666666666667, eta = 1e-8, zeta = 1e-8.
Set initial conditions as a Riemann problem with discontinuity at x = 0:
  For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 1.0.
  For x >= 0: rho_R = 0.1, v_R = 0.0, p_R = 0.1.
Set boundary conditions as transmissive/outflow (zero-gradient) at both x = -1 and x = 1.
Implement ghost cells by copying the nearest interior cell value.
Compute the convective flux using the Rusanov (local Lax-Friedrichs) numerical flux:
  F_conv(U) = [m, m^2/rho + p, (E + p) * v], with v = m / rho.
Compute the interface wave speed a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma * p / rho).
Compute the numerical flux F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L).
Compute viscous stress sigma = (zeta + 4/3 * eta) * v_x using centered differences for v_x on cell-centered velocities.
Approximate interface sigma by averaging adjacent cell-centered sigma values.
Compute viscous flux F_visc = [0, -sigma, -v * sigma] using interface-averaged v and sigma.
Set total interface flux F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Compute the time step each iteration as:
  dt_conv = CFL * dx / max_j(|v_j| + c_j), where CFL is specified or assumed if not given.
  dt_visc = 0.5 * dx^2 / max(zeta + 4/3 * eta, 1e-30).
  dt = min(dt_conv, dt_visc), adjusting the final step to reach T = 0.2 exactly.
