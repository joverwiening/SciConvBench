Use the following specification to solve the 1D viscous Burgers equation numerically.  
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 0.001.  
The spatial domain is [0,1) with periodic boundary conditions.  
The initial condition is u(x,0) = sin(2*pi*x).  
Use a uniform spatial grid with Nx = 512 points.  
Compute dx = (1 - 0) / Nx.  
Set the final time T = 1.0.  
Use Strang splitting for each full time step:  
First, perform a diffusion half-step of duration dt/2 in Fourier space:  
Compute the FFT of u to get u_hat.  
Define wavenumbers k = 2*pi*fftfreq(Nx, d=dx).  
Update u_hat(k) = u_hat(k) * exp(-nu * k^2 * (dt/2)).  
Perform the inverse FFT and take the real part to get u.  
Second, perform a full advection step of duration dt using finite volumes:  
Use the Rusanov (local Lax-Friedrichs) flux for the inviscid Burgers equation.  
Define flux function f(u) = 0.5 * u^2.  
For each interface j, compute flux F[j] using left state u[j] and right state u[j+1] (with periodic indexing):  
Compute alpha = max(|u[j]|, |u[j+1]|).  
Set F[j] = 0.5*(f(u[j]) + f(u[j+1])) - 0.5*alpha*(u[j+1] - u[j]).  
For each cell j, update u_new[j] = u[j] - (dt/dx)*(F[j] - F[j-1]).  
Set u = u_new after the advection step.  
Then, perform a second diffusion half-step identical to the first.  
Estimate the maximum wave speed as 1.0 for CFL calculation.  
Set dt0 = 0.4 * dx / 1.0 based on CFL = 0.4.  
Compute Nt = ceil(T / dt0).  
Set dt = T / Nt to ensure exact final time.  
Run the time loop for Nt steps.  
After the final step, compute the solution u at time T.  
Generate the spatial grid points x[i] = i*dx for i = 0 to Nx-1.  
Save the results in "solution_pdebench_burgers_nu1em3.npz" with arrays x, u, and scalars nu, T, dx, dt, Nx, Nt.  
Create a line plot of u(x,T) versus x and save it as "solution_pdebench_burgers_nu1em3.png".
