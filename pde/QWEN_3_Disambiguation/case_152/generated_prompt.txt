Solve the 1D viscous Burgers equation with periodic boundary conditions: u_t + ∂_x(0.5*u^2) = nu * u_xx.
Use the initial condition u(x,0) = sin(2*pi*x).
Set the viscosity parameter nu = 0.002.
Use a uniform spatial grid with Nx = 512 points over the periodic domain [0,1).
Compute the spatial step size as dx = 1/Nx.
Set the final simulation time T = 1.0.
Estimate the time step using CFL = 0.4 and an estimated maximum wave speed of 1.0: dt0 = CFL * dx / 1.0.
Determine the number of time steps as Nt = ceil(T / dt0).
Adjust the time step to dt = T / Nt to ensure the final time is reached exactly.
Use Strang splitting for each full time step: perform a diffusion half-step, then an advection full-step, then another diffusion half-step.
For the diffusion steps: compute the solution update in Fourier space using the FFT.
Compute the angular wavenumber array: k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Apply the inverse FFT to obtain the real-space solution after each diffusion substep.
For the advection step: solve the inviscid Burgers equation using a finite-volume method with Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u) = 0.5*u^2.
At each cell interface j, compute the flux using left and right states u[j] and u[j+1] (with periodic indexing).
Compute the Rusanov flux: F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where alpha = max(|u_left|, |u_right|).
Update each cell value using the finite-volume formula: u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the right and left interface fluxes.
Apply periodic boundary conditions throughout the simulation.
After completing the time integration, compute the solution u(x,T) at final time T.
