Set q1 = 1.0 and q2 = 0.05.  
Use the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).  
Discretize the spatial domain using a uniform periodic grid with Nx = 512 points, where x_j = j*dx for j = 0, ..., 511 and dx = 1/512.  
Approximate the advection term ∂_x(u) using first-order upwind finite differences.  
Approximate the diffusion term u_xx using second-order central finite differences.  
Use IMEX Euler time integration with diffusion treated implicitly and advection treated explicitly.  
Compute the time step dt as dt = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)), then set Nt = ceil(0.5 / dt) and redefine dt = 0.5 / Nt.  
Advance the solution from t = 0 to t = 0.5 using Nt uniform time steps of size dt.  
Enforce periodic boundary conditions by ensuring u(0,t) = u(1,t) at each time step through the discretization stencil.
