Solve the 1D linear reaction–diffusion equation u_t = q1*u_xx + q2*u with periodic boundary conditions.
Use a spatial domain x in [0, 1) with periodic boundary and time domain t in [0, 0.5].
Set q1 = 0.01 and q2 = -1.0.
Use Nx = 256 grid points in the x-direction, with dx = (1-0)/Nx and x_i = i*dx for i = 0 to Nx-1.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition u(x,0) = sin(2*pi*x).
Use the exact solution u(x,t) = exp(q2*t) * exp(-q1*(2*pi)^2*t) * sin(2*pi*x) for verification.
Compute the numerical solution u(x,T) at T = 0.5 on the grid.
Save the solution in a file named "solution_molk_021.npz" containing: x (1D array of length Nx), u (1D array of length Nx), and scalars T, dx, Nx, q1, q2.
Save a line plot of u(x,T) as "solution_molk_021.png".
Print the minimum value of u, maximum value of u, mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.5.
Compute and print the maximum absolute error between the numerical solution and the exact solution evaluated at T = 0.5 on the same x grid.
