Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) for x in [0,1) with periodic boundary conditions.
Use parameters nu = 1.0 and rho = 10.0.
Use a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and x_j = j*dx for j = 0..Nx-1.
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points (use radians).
Use a fixed time step dt = 0.001 for Nt = 1000 steps so the final time is T = Nt*dt = 1.0.
Advance the solution with Strang splitting for each full time step dt.
Perform the diffusion half-step of duration dt/2 by FFT: compute u_hat = FFT(u).
Define the Fourier wavenumbers as k = 2*pi*fftfreq(Nx, d=dx).
Update diffusion in Fourier space as u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute u = real(IFFT(u_hat)).
Perform the reaction full-step of duration dt pointwise using the exact logistic update u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the second diffusion half-step identically to the first diffusion half-step.
After Nt steps, compute and store the final-time solution u(x,T) on the grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_pdebench_reacdiff_nu1_rho10.npz containing x (length Nx), u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_reacdiff_nu1_rho10.png.
