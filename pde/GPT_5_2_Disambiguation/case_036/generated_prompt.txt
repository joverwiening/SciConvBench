Solve the 1D heat equation u_t = 0.1 u_xx for x in [0,1] and t in [0,0.5].
Use alpha = 0.1 exactly.
Use a uniform grid with Nx = 200 intervals so there are Nx+1 = 201 points including endpoints.
Define dx = (1-0)/Nx = 1/200 and x_i = i*dx for i = 0..Nx.
Use time step dt = 0.0005 and advance for Nt = 1000 steps so T = Nt*dt = 0.5.
Set the initial condition u(x,0) = 0 at all grid points.
Impose Dirichlet boundary conditions by fixing boundary nodes at every time step.
Set u(0,t) = sin(2*pi*t) using radians.
Set u(1,t) = 0.
Discretize u_xx in the interior with 2nd-order central differences: (u_{i-1} - 2u_i + u_{i+1})/dx^2 for i = 1..Nx-1.
Use Crank–Nicolson time integration for the diffusion term on interior nodes.
At each step from t^n to t^{n+1}, solve the tridiagonal linear system for u^{n+1} on interior indices i = 1..Nx-1 with CN coefficients.
Incorporate boundary values at times t^n and t^{n+1} into the right-hand side consistent with Crank–Nicolson.
After the final step, compute u(x,T=0.5) on the full grid including boundary values.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T using the full grid vector u.
