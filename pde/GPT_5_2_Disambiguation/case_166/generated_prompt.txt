Solve the 1D compressible Navier–Stokes equations without heat conduction in conservative form for rho(x,t), v(x,t), p(x,t).
Use m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use viscous stress sigma = (zeta + 4/3*eta) * (dv/dx) with zeta = eta = 1e-08.
Evolve the system:
rho_t + (m)_x = 0.
m_t + (m^2/rho + p - sigma)_x = 0.
E_t + ( (E+p)*v - v*sigma )_x = 0.
Use domain x in [-1, 1] and final time T = 0.2.
Use Gamma = 1.6666666666666667.
Use a uniform finite-volume grid with Nx = 800 cells on [-1, 1].
Use dx = 2/Nx and cell centers x_j = -1 + (j+0.5)*dx for j = 0..Nx-1.
Use transmissive/outflow (zero-gradient) boundary conditions at x = -1 and x = 1 for all evolved quantities.
Initialize a Riemann shock-tube discontinuity at x = 0 with left state (rho, v, p) = (1.0, 0.0, 10.0) for x < 0 and right state (rho, v, p) = (1.0, 0.0, 0.1) for x >= 0, sampled at cell centers.
Advance in time with a stable explicit time step chosen by CFL = 0.5 based on standard compressible-flow wave speed (|v| + c) where c = sqrt(Gamma*p/rho), and include viscosity consistently in the update.
At t = T, compute rho(x,T), v(x,T), p(x,T) on the cell centers.
