Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain [0,1]×[0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1)×(Ny+1)=101×101 grid points.
Define dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Store the solution in a 2D array u with shape (len(y), len(x)) such that u[j,i]=u(x[i],y[j]).
Impose Dirichlet boundary conditions on all four edges consistent with u(x,y)=x.
Set u(0,y)=0 for all y on the left boundary.
Set u(1,y)=1 for all y on the right boundary.
Set u(x,0)=x for all x on the bottom boundary.
Set u(x,1)=x for all x on the top boundary.
Discretize the Laplacian at interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard 5-point second-order finite difference stencil.
Form the sparse linear system Au=b for the unknown interior values only, incorporating boundary values into b.
Use a sparse direct solver to solve the linear system (e.g., scipy.sparse.linalg.spsolve).
Assemble the full grid solution u including boundary values and solved interior values.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Define the reference solution u_exact(x,y)=x evaluated on the same grid.
Compute and print the max absolute error max(|u-u_exact|) over all grid points.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over all grid points.
