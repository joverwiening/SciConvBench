Use the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.002.
Use a periodic spatial domain consistent with u(0,t)=u(1,t), i.e., x ∈ [0,1) with periodicity.
Use a uniform periodic grid with Nx = 512 grid points, dx = (1-0)/Nx, and x_i = i*dx for i=0..Nx-1.
Initialize u(x,0) = sin(2*pi*x) using radians.
Set final time T = 1.0.
Set CFL = 0.4 and estimate max speed as 1.0 to define dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0) and then set dt = T/Nt so the final time is reached exactly in Nt steps.
Advance the solution for Nt time steps using Strang splitting each full step dt.
For each full time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
In the diffusion half-step, compute u_hat = FFT(u).
In the diffusion half-step, define k = 2*pi*fftfreq(Nx, d=dx).
In the diffusion half-step, update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
In the diffusion half-step, compute u = real(IFFT(u_hat)).
After the first diffusion half-step, perform an advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov flux.
In the advection step, define f(u)=0.5*u^2.
In the advection step, for each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, compute alpha = max(abs(u_left), abs(u_right)).
In the advection step, compute the interface flux F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
In the advection step, for each cell j, set F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) using periodic indexing.
In the advection step, update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) for all j.
In the advection step, replace u <- u_new after computing all updates.
After the advection step, perform the second diffusion half-step identical to the first diffusion half-step.
After reaching t = T, compute and print min(u), max(u), mean(u) computed as the discrete average of the Nx values, and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_burgers_nu2em3.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
