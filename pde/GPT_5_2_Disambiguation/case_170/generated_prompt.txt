Solve the 2D variable-coefficient Darcy/Poisson equation -∇·(a(x,y)∇u(x,y)) = 1 on (0,1)×(0,1).
Use Dirichlet boundary conditions u=0 on the entire boundary x=0, x=1, y=0, y=1.
Define the coefficient field a(x,y)=1+beta*(0.5+0.5*sin(2*pi*x)*sin(2*pi*y)) with beta=10.0 and trig in radians.
Use a uniform Cartesian grid with N=128 intervals in each direction, giving (N+1)×(N+1) grid points including boundaries.
Set dx=dy=1/N.
Define x_i=i*dx for i=0..N and y_j=j*dy for j=0..N.
Store u on the full grid as u[i,j] corresponding to (x_i,y_j).
Enforce boundary values u[i,0]=u[i,N]=u[0,j]=u[N,j]=0 exactly.
For interior nodes i=1..N-1 and j=1..N-1, discretize using 2nd-order finite differences with face-centered harmonic averaging:
Compute nodal coefficients a[i,j]=a(x_i,y_j).
Compute face coefficients by harmonic mean:
a_iphalf_j = 2*a[i,j]*a[i+1,j]/(a[i,j]+a[i+1,j]).
a_imhalf_j = 2*a[i,j]*a[i-1,j]/(a[i,j]+a[i-1,j]).
a_i_jphalf = 2*a[i,j]*a[i,j+1]/(a[i,j]+a[i,j+1]).
a_i_jmhalf = 2*a[i,j]*a[i,j-1]/(a[i,j]+a[i,j-1]).
Apply the interior stencil:
-(1/dx^2)*[ a_iphalf_j*(u[i+1,j]-u[i,j]) - a_imhalf_j*(u[i,j]-u[i-1,j]) + a_i_jphalf*(u[i,j+1]-u[i,j]) - a_i_jmhalf*(u[i,j]-u[i,j-1]) ] = 1.
Assemble the sparse linear system A u_vec = b for the (N-1)*(N-1) interior unknowns only, with b being all ones (right-hand side 1) for each interior equation.
Incorporate Dirichlet boundaries by omitting boundary unknowns and adding their contributions (which are zero here) consistently in the assembly.
Solve the symmetric positive definite system using conjugate gradient (CG) to relative residual tolerance 1e-10.
Optionally use a Jacobi (diagonal) preconditioner.
After solving, map the interior solution back into the full (N+1)×(N+1) array u with boundary values set to zero.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete residual norm for the interior system as ||A u_vec - b||_2 / ||b||_2.
