Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu=0.01 for x in [0,1) and t in [0,1.0].
Use periodic boundary conditions with periodic indexing so u[0] neighbors u[Nx-1].
Use a uniform periodic grid with Nx=512 points, dx=1/Nx, and x_j=j*dx for j=0..Nx-1.
Initialize u(x,0)=sin(2*pi*x) evaluated at the grid points using radians.
Choose CFL=0.4 and dt0=CFL*dx/1.0.
Set Nt=ceil(T/dt0) with T=1.0 and then set dt=T/Nt so the final time is hit exactly.
Advance the solution from t=0 to t=T using Strang splitting each full time step dt.
In each time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space by taking u_hat=FFT(u), defining k=2*pi*fftfreq(Nx,d=dx), updating u_hat=u_hat*exp(-nu*k^2*(dt/2)), and setting u=real(IFFT(u_hat)).
Then perform an advection full-step of duration dt for the inviscid Burgers equation using a finite-volume update with Rusanov flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, compute alpha=max(abs(u_left),abs(u_right)) and F=0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j],u[j+1]) and F_minus as the flux between (u[j-1],u[j]) and update u_new[j]=u[j]-(dt/dx)*(F_plus-F_minus).
Replace u with u_new after the advection substep.
Perform a second diffusion half-step identical to the first diffusion half-step.
After reaching t=T, compute and print min(u), max(u), mean(u) as the discrete average over grid points, and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_burgers_nu0p01.npz containing arrays x (length Nx) and u (length Nx at time T) and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at time T as solution_pdebench_burgers_nu0p01.png.
