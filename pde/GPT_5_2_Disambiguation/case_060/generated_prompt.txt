Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) ∈ [0,1] × [0,1].
Use a uniform grid with Nx = Ny = 100 intervals, giving (Nx+1) × (Ny+1) grid points.
Define dx = dy = 1/Nx.
Define x_i = i*dx for i = 0..Nx.
Define y_j = j*dy for j = 0..Ny.
Store the solution in an array u with shape (len(y), len(x)) such that u[j,i] = u(x_i, y_j).
Impose Dirichlet boundary conditions on all four edges matching u(x,y)=y.
Set u(0,y_j) = y_j for all j.
Set u(1,y_j) = y_j for all j.
Set u(x_i,0) = 0 for all i.
Set u(x_i,1) = 1 for all i.
Discretize the Laplacian on interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard 5-point second-order finite difference stencil.
Form the sparse linear system A * u_interior = b for the interior unknowns only, incorporating boundary values into b.
Use a sparse direct solver (scipy.sparse.linalg.spsolve) to solve for the interior unknowns.
Assemble the full grid solution u including boundary values and solved interior values.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete L2 norm of u as sqrt(sum(u^2) * dx * dy) over the full grid.
Evaluate the reference solution u_exact(x_i,y_j) = y_j on the same grid.
Compute and print the max absolute error max(|u - u_exact|) over the full grid.
Compute and print the discrete L2 error as sqrt(sum((u - u_exact)^2) * dx * dy) over the full grid.
Save an NPZ file named solution_agent_laplace_04.npz containing arrays x (1D), y (1D), u (2D), and metadata scalars dx and dy.
