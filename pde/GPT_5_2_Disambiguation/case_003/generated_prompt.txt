Implement a 1D linear advection solver in Python using NumPy for computation and saving .npz, and Matplotlib for plotting.
Solve u_t + a(x) u_x = 0 on x in [0,1) with periodic boundary conditions and t in [0,0.5].
Use a(x) = 1 + 0.5*sin(2*pi*x) with trig in radians.
Use initial condition u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx = 1200 points on [0,1) with dx = 1/Nx and x_i = i*dx for i = 0..Nx-1.
Compute a_i = 1 + 0.5*sin(2*pi*x_i) on the grid.
Use first-order upwind spatial discretization with left-biased stencil because a(x) > 0 everywhere: u_x(x_i) ≈ (u_i - u_{i-1})/dx with periodic wrap u_{-1} = u_{Nx-1}.
Use Forward Euler time integration: u_i^{n+1} = u_i^n - dt * a_i * (u_i^n - u_{i-1}^n)/dx with periodic wrap for i-1.
Set T = 0.5 and amax = 1.5.
Compute dt0 = 0.9*dx/amax.
Set Nt = ceil(T/dt0) as an integer number of time steps.
Set dt = T/Nt so the final time is hit exactly.
Advance the solution for Nt steps from t=0 to t=T.
After reaching T, compute and print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_agent_advection_03.npz containing arrays x (1D) and u (1D, same length as x) and scalar metadata T, dx, dt.
Generate and save a line plot of u versus x at time T as solution_agent_advection_03.png.
