Use a uniform grid with Nx=Ny=120 intervals so there are (Nx+1) by (Ny+1) grid points including boundaries.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Discretize the Laplacian on interior nodes using the standard 2nd-order 5-point finite difference stencil.
Assemble the sparse linear system for interior unknowns only, incorporating Dirichlet boundary values into the right-hand side.

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over the full grid.
