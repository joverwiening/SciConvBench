Solve the 1D heat equation u_t = 0.1 u_xx + 1 on x in [0,1] and t in [0,0.5].
Use Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use initial condition u(x,0)=0 for all x in [0,1].
Discretize space with a uniform grid using Nx=200 intervals, giving Nx+1=201 grid points x_i = i*dx for i=0..200 with dx=1/200.
Approximate u_xx at interior points i=1..199 using 2nd-order central differences (u_{i-1}-2u_i+u_{i+1})/dx^2.
Integrate in time with Crank–Nicolson for the diffusion term using dt=0.001 for 500 steps to reach T=0.5.
Include the constant source term +1 using Crank–Nicolson averaging in time, i.e., add dt*1 to the right-hand side per step.
At each time step, enforce Dirichlet boundary conditions by setting the boundary nodes u_0=0 and u_200=0.
At each time step, solve the resulting tridiagonal linear system for the interior unknowns u_1..u_199.
After advancing to T=0.5, compute u(x,T) on the full grid including boundaries.
