Implement a 1D diffusion solver for u_t = D u_xx with D = 0.1 on x in [0,1] and t in [0,0.5].

Use Robin boundary conditions u_x(0,t) + beta*u(0,t) = 0 and u_x(1,t) + beta*u(1,t) = 0 with beta = 1.0.

Enforce the Robin BC at x=1 using the given 2nd-order one-sided derivative: (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx) + beta*uN = 0, where uN means u_{Nx}.
Advance in time with Crank–Nicolson using dt = 0.001 from t=0 to T=0.5 for 500 steps.

Implement the boundary conditions as linear equations replacing the first and last rows of the system matrix for u^{n+1}, and apply the same replacement consistently on the right-hand side so the boundary equations are enforced at time level n+1 in the Crank–Nicolson solve.
