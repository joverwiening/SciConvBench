Use the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) for x in [0,1) with periodic boundary conditions.
Set parameters nu=0.5 and rho=1.0.
Use a uniform periodic grid on [0,1) with Nx=512 grid points and no duplicated endpoint.
Define dx = (1-0)/Nx and x_i = 0 + i*dx for i=0..Nx-1.
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points using radians.
Use a fixed time step dt=0.001 with Nt=1000 steps and final time T = Nt*dt.
Advance the solution using Strang splitting for each full time step dt.
Implement the diffusion half-step of duration dt/2 by FFT: compute u_hat = FFT(u), define k = 2*pi*fftfreq(Nx, d=dx), update u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then set u <- real(IFFT(u_hat)).
Implement the reaction full-step of duration dt pointwise using the exact logistic update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Apply the diffusion half-step again identically to the first half-step.
After Nt steps, compute u at final time T on the grid.
Compute and print at time T: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu0p5_rho1.npz containing x (length Nx), u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
