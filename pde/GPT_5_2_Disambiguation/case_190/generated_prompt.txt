Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) for u(x,t).
Use domain x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu = 5.0 and rho = 2.0.
Use a uniform periodic spatial grid with Nx = 512 points on [0,1).
Define dx = (1.0 - 0.0)/Nx.
Define grid points x_j = j*dx for j = 0,1,...,Nx-1.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at x_j (with trig in radians).
Use a fixed time step dt = 0.001.
Use Nt = 1000 time steps so that T = Nt*dt = 1.0 exactly.
Advance the solution using Strang splitting for each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute u_hat = FFT(u).
Compute wave numbers k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat <- u_hat * exp(-nu*k^2*(dt/2)).
Compute u <- real(IFFT(u_hat)).
Perform a reaction full-step of duration dt solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
Update each grid point by u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the diffusion half-step again identically to the first half-step.
After Nt steps, compute u(x,T=1.0) on the periodic grid.
Compute and print at T the values min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu5_rho2.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_reacdiff_nu5_rho2.png.
