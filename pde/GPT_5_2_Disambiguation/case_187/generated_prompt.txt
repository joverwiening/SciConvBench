Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) for u(x,t) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu = 2.0 and rho = 5.0.
Use a uniform periodic grid with Nx = 512 points on [0,1) with dx = (1.0 - 0.0)/Nx and x_j = j*dx for j = 0..Nx-1.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = Nt*dt = 1.0 exactly.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points (use radians).
Advance the solution using Strang splitting for each full time step dt.
Perform the diffusion half-step of duration dt/2 by FFT: compute u_hat = FFT(u), set k = 2*pi*fftfreq(Nx, d=dx), update u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then set u <- real(IFFT(u_hat)).
Perform the reaction full-step of duration dt by the exact logistic update applied pointwise: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the diffusion half-step again identically to the first diffusion half-step.
After Nt steps, compute u(x,T=1.0) on the periodic grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_pdebench_reacdiff_nu2_rho5.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_reacdiff_nu2_rho5.png.
