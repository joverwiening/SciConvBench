Solve u_t = -q1 * ∂_x(u) + (q2/pi) * u_xx on x in [0,1) with periodic boundary conditions and t in [0,0.5].
Use q1 = 1.0 and q2 = 0.05.
Use a uniform periodic grid with Nx = 512 points on [0,1) with dx = 1/Nx and x_j = j*dx for j = 0..Nx-1.
Represent the solution as u_j(t) ≈ u(x_j,t) with periodic indexing (e.g., u_{-1}=u_{Nx-1}, u_{Nx}=u_0).
Initialize u_j(0) = sin(2*pi*x_j) + 0.5*sin(4*pi*x_j) using radians.
Discretize ∂_x(u) with 1st-order upwind based on the sign of q1.
For this task with q1>0, use (∂_x u)_j ≈ (u_j - u_{j-1})/dx.
Discretize u_xx with 2nd-order central differences: (u_xx)_j ≈ (u_{j+1} - 2*u_j + u_{j-1})/dx^2.
Advance in time using IMEX Euler with advection explicit and diffusion implicit.
Define the explicit advection operator A(u)_j = -q1 * (u_j - u_{j-1})/dx.
Define the diffusion operator D(u)_j = (q2/pi) * (u_{j+1} - 2*u_j + u_{j-1})/dx^2.
At each step from time level n to n+1, compute u^{n+1} from (I - dt*D) u^{n+1} = u^n + dt*A(u^n) using periodic indexing.
Choose dt from stability guidance: dt0 = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)).
Set Nt = ceil(T/dt0) with T = 0.5 and then reset dt = T/Nt.
Run the simulation for Nt steps to reach t = 0.5.
For verification, compute the exact Fourier-mode evolution for the two initial modes k=1 and k=2 (corresponding to sin(2*pi*x) and sin(4*pi*x)) under advection speed q1 and diffusion coefficient (q2/pi), and compare the numerical solution to the reconstructed exact solution at t = 0.5.
