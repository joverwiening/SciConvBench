Implement a 1D numerical solver for the Allen–Cahn PDE u_t = (0.02)^2 u_xx + u − u^3 on x ∈ [0,1], t ∈ [0,0.2].
Use epsilon = 0.02.
Use a uniform grid with Nx = 1200 intervals, so there are N = Nx+1 = 1201 grid points x_i = i*dx for i=0..Nx with dx = (1−0)/Nx.
Use the initial condition u(x,0) = tanh((0.5 − x)/(sqrt(2)*0.02)) evaluated at the grid points.
Enforce constant Dirichlet boundary conditions at every time step: u(0,t)=1 and u(1,t)=−1.
Discretize u_xx with 2nd-order central differences on interior nodes i=1..Nx−1: u_xx ≈ (u_{i−1} − 2u_i + u_{i+1})/dx^2.
Use time step dt = 0.0001 and final time T = 0.2, so Nt = T/dt = 2000 time steps.
Use the semi-implicit scheme on interior nodes i=1..Nx−1: (u_i^{n+1} − u_i^n)/dt = epsilon^2*(u_xx^{n+1})_i + u_i^n − (u_i^n)^3.
Rearrange the semi-implicit scheme into a linear system A u^{n+1}_int = rhs each step, where u^{n+1}_int contains the interior unknowns u^{n+1}_1..u^{n+1}_{Nx−1}.
Construct A as a tridiagonal matrix with main diagonal (1 + 2*dt*epsilon^2/dx^2) and off-diagonals (−dt*epsilon^2/dx^2).
Form rhs for interior nodes as u_i^n + dt*(u_i^n − (u_i^n)^3) and add boundary contributions: rhs_1 += (dt*epsilon^2/dx^2)*u_0^{n+1} and rhs_{Nx−1} += (dt*epsilon^2/dx^2)*u_{Nx}^{n+1}, using u_0^{n+1}=1 and u_{Nx}^{n+1}=−1.
Solve the linear system each step using Python with NumPy and SciPy (use an efficient tridiagonal solver such as scipy.linalg.solve_banded or scipy.sparse with spsolve).
After each solve, assemble the full u^{n+1} including boundary values set exactly to 1 and −1.
After Nt steps, compute u(x,T) on the same grid.
Compute and print at T the scalar diagnostics: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) using the full grid including boundaries.
