Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) ∈ [0,1] × [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1)×(Ny+1) grid points including boundaries.
Define dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Store the solution in an array u with shape (len(y), len(x)) such that u[j,i] corresponds to u(x_i,y_j).
Impose Dirichlet boundary conditions on all four edges using the analytic solution u_exact(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
Set u(x,0)=0 for all x on the bottom boundary.
Set u(x,1)=sin(pi*x) for all x on the top boundary.
Set u(0,y)=0 for all y on the left boundary.
Set u(1,y)=0 for all y on the right boundary.
Discretize the Laplacian on interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard second-order 5-point stencil.
Assemble the resulting sparse linear system A * u_interior = b, incorporating boundary values into b.
Solve the sparse linear system for interior unknowns using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Combine the solved interior values with the prescribed boundary values to form the full grid solution u.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over the full grid.
Evaluate u_exact on the same grid and compute and print the max absolute error max(|u-u_exact|).
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over the full grid.
