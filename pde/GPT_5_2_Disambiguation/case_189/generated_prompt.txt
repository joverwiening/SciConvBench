Solve u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu = 5.0 and rho = 10.0.
Use a uniform periodic grid with Nx = 512 points on [0,1).
Define dx = (1.0 - 0.0)/Nx.
Define x_j = j*dx for j = 0,1,...,Nx-1.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at x_j (use radians).
Use a fixed time step dt = 0.001.
Use Nt = 1000 time steps so that Nt*dt = T = 1.0 exactly.
Advance the solution with Strang splitting for each full time step dt.
For each time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
In the diffusion half-step, compute u_hat = FFT(u).
In the diffusion half-step, define the wavenumber array k = 2*pi*fftfreq(Nx, d=dx).
In the diffusion half-step, update u_hat <- u_hat * exp(-nu*k^2*(dt/2)).
In the diffusion half-step, compute u <- real(IFFT(u_hat)).
For each time step, perform a reaction full-step of duration dt solved exactly pointwise for du/dt = rho*u*(1-u).
In the reaction step, update each grid value by u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
For each time step, perform a second diffusion half-step identical to the first diffusion half-step.
After Nt steps, compute and store u(x,T=1.0) on the periodic grid.
Compute and print at T: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu5_rho10.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_reacdiff_nu5_rho10.png.
