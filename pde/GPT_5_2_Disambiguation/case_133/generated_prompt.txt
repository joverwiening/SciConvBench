Solve u_t = -k * ∂_x(cos(u)) on x in [0,1) with periodic boundary conditions and t in [0,0.2].
Use k = 1.0.
Use initial condition u(x,0) = 0.5*sin(2*pi*x) with trig in radians.
Use a uniform periodic grid with Nx = 1024 points on [0,1) with dx = 1/Nx and x_j = j*dx for j = 0..Nx-1.
Use a conservative finite-volume method with Rusanov (local Lax-Friedrichs) numerical flux for f(u)=cos(u).
Represent the solution as cell averages u_j(t) on the periodic grid indices j = 0..Nx-1.
Compute interface fluxes at j+1/2 using F_{j+1/2} = 0.5*(f(u_L)+f(u_R)) - 0.5*alpha_{j+1/2}*(u_R-u_L).
Use u_L = u_j and u_R = u_{j+1} with periodic wrap u_{Nx} = u_0.
Use alpha_{j+1/2} = max(|sin(u_L)|, |sin(u_R)|) and note alpha <= 1.
Update with the semi-discrete finite-volume form du_j/dt = -(k/dx) * (F_{j+1/2} - F_{j-1/2}) with periodic wrap for j-1/2 at the left boundary.
Integrate in time with SSP-RK2 (Heun) from t=0 to T=0.2.
Implement SSP-RK2 as u^(1) = u^n + dt*L(u^n) and u^{n+1} = 0.5*u^n + 0.5*(u^(1) + dt*L(u^(1))) where L(u) is the spatial operator.
Choose time step using CFL = 0.2 with dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and dt = T/Nt so the final time is reached exactly.
Run for Nt steps to produce u(x,t) at t = 0.2.
No closed-form exact solution is required; verification may use conservation and stability checks consistent with the scheme.
