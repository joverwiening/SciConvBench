Set q = 1.5.

Set the initial condition u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x) using radians.
Compute a numerical approximation of u(x,T) at T = 1.0 on the x grid.
Evaluate the reference solution u_ref(x,T) = u0(((x - q*T) mod 1)) on the same x grid for error calculation.
Compute and print at T: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error max(|u - u_ref|) and L2 error sqrt(sum((u-u_ref)^2)*dx).
