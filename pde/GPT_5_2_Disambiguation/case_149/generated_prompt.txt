Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 1.0.
Use the periodic spatial domain x ∈ [0, 1) with u(0,t)=u(1,t).
Use Nx = 512 grid points with x_j = j*dx for j=0..Nx-1 and dx = 1/Nx.
Initialize u(x,0) = sin(2*pi*x) evaluated at the grid points (radians for trig).
Run the simulation from t=0 to final time T = 1.0.
Set CFL = 0.4 and estimated max speed = 1.0.
Compute dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0).
Reset dt = T/Nt so the final time is hit exactly.
Advance in time using Strang splitting each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute u_hat = FFT(u).
Compute k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute u = real(IFFT(u_hat)).
Perform an advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov flux and periodic indexing.
Define f(u) = 0.5*u^2.
For each interface between u_left = u[j] and u_right = u[j+1], compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, set F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) using periodic wraparound.
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
Perform the diffusion half-step again identically to the first diffusion half-step.
After Nt steps, treat the resulting u as u(x,T) on the grid.
Compute and print min(u), max(u), mean(u) as the discrete mean value, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_pdebench_burgers_nu1.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at time T as solution_pdebench_burgers_nu1.png.
