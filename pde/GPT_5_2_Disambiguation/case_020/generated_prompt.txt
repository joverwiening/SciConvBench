Solve u_t = ∇·(D(x,y)∇u) on (x,y)∈[0,1]×[0,1], t∈[0,0.1].
Use D(x,y)=0.05*(1+0.5*sin(2*pi*x)*sin(2*pi*y)) with trig in radians.
Use the initial condition u(x,y,0)=sin(pi*x)*sin(pi*y).
Apply Dirichlet boundary conditions u=0 on x=0, x=1, y=0, y=1 for all t.
Use a uniform grid with Nx=Ny=80 intervals on [0,1], so x_i=i*dx, y_j=j*dy, dx=1/Nx, dy=1/Ny, with i=0..Nx and j=0..Ny.
Store the solution as u[j,i]=u(x_i,y_j,t).
Define nodal diffusion D_{i,j}=D(x_i,y_j).
Define arithmetic face averages D_{i+1/2,j}=0.5*(D_{i,j}+D_{i+1,j}) and D_{i,j+1/2}=0.5*(D_{i,j}+D_{i,j+1}).
For interior nodes i=1..Nx-1 and j=1..Ny-1, discretize (∇·(D∇u))_{i,j} by the conservative 2nd-order flux form:
(1/dx^2)[ D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}(u_{i,j}-u_{i-1,j}) ] + (1/dy^2)[ D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}(u_{i,j}-u_{i,j-1}) ].
Enforce Dirichlet boundary values by setting u=0 at all boundary nodes for every time level and by forming the linear system only for interior unknowns (or equivalently modifying rows/columns to impose fixed boundary values).
Use implicit Euler time stepping with dt=0.0005 for 200 steps to reach T=0.1.
At each step solve (I - dt*L) u^{n+1} = u^n for the interior unknowns, where L is the discrete variable-coefficient diffusion operator assembled from the flux-form stencil.
Use a sparse matrix representation for (I - dt*L) and a sparse linear solver each time step.
After the final step, compute u(x,y,T=0.1) on the full grid including boundaries.
