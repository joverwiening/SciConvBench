Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu = 2.0 and rho = 10.0.
Use the periodic uniform grid with Nx = 512 points on [0,1) with dx = (1.0 - 0.0)/Nx and x_j = j*dx for j = 0..Nx-1.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points.
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that T = Nt*dt = 1.0 exactly.
Advance the solution using Strang splitting for each full time step dt.
Implement the diffusion half-step of duration dt/2 by FFT: compute u_hat = FFT(u), define k = 2*pi*fftfreq(Nx, d=dx), update u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then set u <- real(IFFT(u_hat)).
Implement the reaction full-step of duration dt pointwise using the exact logistic update for du/dt = rho*u*(1-u): u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Implement the second diffusion half-step identically to the first diffusion half-step.
After Nt steps, treat the result as u(x,T=1.0) on the periodic grid.
Compute and print at T: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu2_rho10.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_reacdiff_nu2_rho10.png.
