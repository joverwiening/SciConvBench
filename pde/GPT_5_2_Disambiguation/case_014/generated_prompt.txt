Solve the 1D viscous Burgers equation u_t + u*u_x = nu*u_xx on x in [0,1) and t in [0,0.2] with nu=0.005.
Use periodic boundary conditions in x with wrap-around indexing and no duplicated endpoint at x=1.
Use a uniform periodic grid with Nx=1200 grid points on [0,1), dx=(1-0)/Nx=1/Nx, and x_i=i*dx for i=0..Nx-1.
Set dt=5e-5 and Nt=4000 time steps so that T=Nt*dt=0.2 exactly.
Initialize u(x,0)=0.5 + sin(2*pi*x) using radians for the sine argument.
Discretize the convection term in conservative form with f(u)=0.5*u^2 and a Rusanov (local Lax–Friedrichs) numerical flux.
Compute interface fluxes F_{i+1/2}^n = 0.5*(f(u_i^n)+f(u_{i+1}^n)) - 0.5*alpha_{i+1/2}*(u_{i+1}^n-u_i^n), where alpha_{i+1/2}=max(|u_i^n|,|u_{i+1}^n|) and indices are periodic.
Approximate (f(u))_x at grid point i by (F_{i+1/2}^n - F_{i-1/2}^n)/dx using periodic indexing for i±1.
Discretize diffusion with the second-order central difference u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2 using periodic indexing.
Advance in time with first-order IMEX: treat convection explicitly at time level n and diffusion implicitly at time level n+1.
At each step solve (u^{n+1} - u^n)/dt + (F_{i+1/2}^n - F_{i-1/2}^n)/dx = nu*(u_{i+1}^{n+1}-2u_i^{n+1}+u_{i-1}^{n+1})/dx^2 for all i with periodic indexing.
Form the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term^n, where L is the periodic second-difference Laplacian operator and conv_term^n is the discrete convection derivative.
Implement L as a sparse Nx-by-Nx matrix with main diagonal -2/dx^2, first off-diagonals 1/dx^2, and periodic corner entries (0,Nx-1) and (Nx-1,0) equal to 1/dx^2.
Solve the sparse linear system each time step using a direct sparse solver such as scipy.sparse.linalg.spsolve.
After Nt steps, define u as the numerical solution at T=0.2 on the grid x.
Compute and print at T: min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
