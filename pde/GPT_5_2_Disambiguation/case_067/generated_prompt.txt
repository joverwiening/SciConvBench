Implement the solver in Python 3 using NumPy for arrays and FFTs and Matplotlib for plotting.
Solve the 1D periodic Cahn–Hilliard PDE u_t = -(0.01)^2*u_xxxx + ∂^2/∂x^2( u^3 - u ) on x in [0,1) and t in [0,0.05].
Use a Fourier pseudo-spectral method on a periodic grid with Nx=512 equally spaced points x_j=j/Nx for j=0..Nx-1.
Set dx = 1/Nx and T = 0.05.
Initialize u(x,0)=0.1*cos(2*pi*x) + 0.01*cos(6*pi*x) evaluated at the grid points using radians.
Use time step dt=1e-5 for Nt = T/dt = 5000 steps.
Define Fourier wavenumbers k consistent with the periodic domain length 1 using NumPy’s FFT ordering (e.g., k = 2*pi*fftfreq(Nx, d=dx)).
Define the linear operator in Fourier space as L(k)=(-epsilon^2*k^4 + k^2) with epsilon=0.01.
Advance in time using the semi-implicit spectral update û^{n+1} = (û^n + dt * FFT(∂xx(u^3)) ) / (1 - dt*L(k)).
Compute ∂xx(u^3) pseudo-spectrally by forming u^3 in physical space, taking its FFT, applying 2/3 dealiasing to the FFT of u^3 by zeroing modes with |k| > (2/3)*k_max where k_max = max(|k|), then multiplying by -(k^2) in Fourier space, then inverse FFT back to physical space if needed for the update term.
Use real-valued physical fields by taking the real part after inverse FFTs to remove small imaginary roundoff.
After Nt steps, compute u(x,T) on the same grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
