Implement a 1D numerical solver in Python using NumPy and Matplotlib for Task ID agent_wave_17.

Define dx = 1/Nx and x_i = i*dx for i=0..Nx-1.

Set T = 0.7.
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is reached exactly.
Represent the solution at time level n as u^n, a length-Nx NumPy array.
Impose periodicity by using wrap-around indexing in all spatial finite differences.
Discretize u_xx with 2nd-order central differences: (u_{i+1} - 2u_i + u_{i-1})/dx^2 with indices taken modulo Nx.
Set the initial displacement u^0_i = sin(2*pi*x_i) using radians.
Set the initial velocity v^0_i = cos(2*pi*x_i) using radians.
Initialize the first time level using a Taylor start: u^1 = u^0 + dt*v^0 + 0.5*(dt^2)*c^2*(Dxx u^0), where Dxx is the discrete Laplacian defined by the central difference with wrap-around.
Advance in time for n = 1..Nt-1 using the 2nd-order central difference in time scheme: u^{n+1} = 2u^n - u^{n-1} + (c^2*dt^2)*(Dxx u^n).
After completing Nt steps, treat u^Nt as the numerical approximation to u(x,T) on the grid.
Compute and print at T the scalar diagnostics: min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) using u = u^Nt.
Save a NumPy .npz file named solution_agent_wave_17.npz containing arrays x (1D) and u (1D) and metadata scalars T, dx, dt.
