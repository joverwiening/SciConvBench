Solve the 1D wave equation u_tt = c^2 u_xx with c = 1.0 for x in [0,1) periodic and t in [0,1.0].
Use periodic boundary conditions u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t).
Use the exact solution for verification u_exact(x,t)=cos(2*pi*x)*cos(2*pi*t) with radians.
Use initial conditions u(x,0)=cos(2*pi*x) and u_t(x,0)=0.
Discretize space with a uniform periodic grid of Nx=512 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx and x_i = i*dx for i=0..Nx-1.
Approximate u_xx with 2nd-order central differences with periodic wrap-around: (u_{i+1}-2u_i+u_{i-1})/dx^2 using indices modulo Nx.
Use 2nd-order central difference in time for u_tt: u^{n+1} = 2u^n - u^{n-1} + (c*dt)^2 * L(u^n), where L is the discrete Laplacian.
Choose dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that t=1.0 is reached exactly.
Initialize u^0 from u(x,0).
Initialize u^1 using a Taylor start: u^1 = u^0 + dt*u_t(x,0) + 0.5*dt^2*c^2*L(u^0).
Time-step from n=1 to n=Nt-1 to compute u at t=T.
At T=1.0, compute and print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
At T=1.0, evaluate u_exact on the same x grid and compute and print max absolute error and L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_wave_05.npz containing arrays x (1D) and u (1D) and scalars T, dx, dt.
