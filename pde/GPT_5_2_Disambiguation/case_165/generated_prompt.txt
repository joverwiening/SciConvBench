Solve the 1D compressible Navier–Stokes system without heat conduction for rho(x,t), m(x,t)=rho v, and total energy E(x,t)=p/(Gamma-1)+0.5*rho*v^2 on x in [-1,1] and t in [0,0.2].
Use parameters Gamma=1.6666666666666667, eta=1e-08, zeta=eta, and sigma=(zeta+4/3*eta)*v_x.
Use a uniform finite-volume grid with Nx=800 cells on [-1,1] with dx=2/Nx and cell centers x_j=-1+(j+0.5)*dx for j=0..Nx-1.
Represent the conserved state per cell as U_j=[rho_j, m_j, E_j]^T.
Initialize a Riemann problem with discontinuity at x=0 using cell centers: if x_j<0 set rho=0.445, v=0.698, p=3.528; else set rho=0.5, v=0.0, p=0.571; then set m=rho*v and E=p/(Gamma-1)+0.5*rho*v^2.
Apply transmissive/outflow boundary conditions at x=-1 and x=1 using ghost cells with zero-gradient extrapolation of rho, m, and E.
Use first-order piecewise-constant reconstruction for inviscid fluxes: at interface j+1/2 take U_L=U_j and U_R=U_{j+1}.
Compute primitive variables from a conserved state as rho=rho, v=m/rho, p=(Gamma-1)*(E-0.5*rho*v^2), and sound speed c=sqrt(Gamma*p/rho).
Use the Rusanov (local Lax–Friedrichs) numerical flux for the convective part at each interface j+1/2:
Compute F_conv(U)=[m, m^2/rho + p, (E+p)*v]^T.
Compute a=max(|v_L|+c_L, |v_R|+c_R).
Compute Fhat=0.5*(F_conv(U_L)+F_conv(U_R)) - 0.5*a*(U_R-U_L).
Discretize viscosity as follows each time fluxes are assembled.
Compute cell-centered velocity v_j=m_j/rho_j.
Compute cell-centered v_x with centered difference (v_x)_j=(v_{j+1}-v_{j-1})/(2*dx) using outflow ghost cells to define boundary stencils.
Compute cell-centered stress sigma_j=(zeta+4/3*eta)*(v_x)_j.
Compute interface stress sigma_{j+1/2}=0.5*(sigma_j+sigma_{j+1}).
Compute interface-averaged velocity v_{j+1/2}=0.5*(v_j+v_{j+1}).
Compute viscous interface flux F_visc,j+1/2=[0, -sigma_{j+1/2}, -v_{j+1/2}*sigma_{j+1/2}]^T.
Compute total interface flux F_total,j+1/2 = Fhat + F_visc,j+1/2.
Advance the semi-discrete finite-volume update dU_j/dt = -(F_total,j+1/2 - F_total,j-1/2)/dx.
Use adaptive time stepping with CFL=0.5 and dt = CFL*dx / max_j(|v_j|+c_j) evaluated from current cell-centered primitives.
Use 2-stage SSP-RK2 (Heun’s method): U^(1)=U^n + dt*L(U^n); U^(n+1)=0.5*U^n + 0.5*(U^(1) + dt*L(U^(1))), where L(U) is the spatial operator from the flux divergence with the same boundary/flux procedures.
Advance in time until reaching exactly T=0.2 by reducing the final dt so that the last update lands exactly on t=T.
At t=T, compute cell-centered rho_j, v_j=m_j/rho_j, and p_j=(Gamma-1)*(E_j-0.5*rho_j*v_j^2).
