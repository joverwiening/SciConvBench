Solve the 1D heat equation u_t = 0.5 u_xx for x in [0,1] and t in [0,0.2].
Use alpha = 0.5 as the diffusion coefficient in the PDE.
Use the initial condition u(x,0) = sin(2*pi*x) with trig in radians.
Enforce homogeneous Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t in [0,0.2] by fixing the boundary nodes at every time step.
Use a uniform grid on [0,1] with Nx=200 uniform intervals and Nx+1=201 grid points including both endpoints.
Define dx = (1-0)/Nx = 1/200 and x_i = 0 + i*dx for i=0..Nx.
Discretize u_xx in the interior with 2nd-order central differences: (u_{i-1} - 2u_i + u_{i+1})/dx^2 for i=1..Nx-1.
Integrate in time with Crank–Nicolson applied to the diffusion term using dt=0.0005 from t=0 to T=0.2 for 400 time steps.
At each time step, solve the resulting tridiagonal linear system for the interior unknowns u_1..u_{Nx-1} with boundary values held fixed at u_0=0 and u_Nx=0.
Compute the numerical solution u(x,T) at T=0.2 on the same grid.
Compute the reference solution on the same grid as u_exact(x,T) = exp(-0.5*(2*pi)^2*T) * sin(2*pi*x).
Compute and print at T the following diagnostics for the numerical solution: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) using all grid points.
Compute and print the max absolute error max(|u - u_exact|) and the discrete L2 error sqrt(sum((u-u_exact)^2)*dx) using the same dx and grid points.
