Solve the 2D heat equation u_t = 0.1*(u_xx + u_yy) for (x,y) in [0,1]x[0,1] and t in [0,0.2].
Use alpha = 0.1.
Use the initial condition u(x,y,0) = cos(pi*x)*cos(pi*y).
Apply zero Neumann boundary conditions ∂u/∂n = 0 on all four edges x=0, x=1, y=0, y=1.
Use a uniform grid with Nx=Ny=60 intervals on each axis, so x has 61 points and y has 61 points, with dx=1/60 and dy=1/60.
Use the grid convention x_i = 0 + i*dx for i=0..60 and y_j = 0 + j*dy for j=0..60.
Discretize the Laplacian with the standard 5-point stencil at interior nodes.
Implement the Neumann boundaries using ghost nodes with mirror values to achieve second-order accuracy, i.e., enforce u_{-1,j}=u_{1,j}, u_{Nx+1,j}=u_{Nx-1,j}, u_{i,-1}=u_{i,1}, u_{i,Ny+1}=u_{i,Ny-1} when forming second derivatives at boundary-adjacent nodes.
Advance in time using Implicit Euler with dt=0.001 from t=0 to T=0.2 for 200 steps.
At each time step, solve the resulting linear system for u^{n+1} from (I - dt*alpha*L) u^{n+1} = u^n, where L is the discrete Laplacian operator incorporating the Neumann treatment.
Compute the numerical solution u(x,y,T) at T=0.2 on the same grid.
Evaluate the reference solution u_exact(x,y,t) = exp(-2*0.1*pi^2*t)*cos(pi*x)*cos(pi*y) on the same grid at T=0.2.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum_{i,j} u_{j,i}^2 * dx * dy) at T.
Compute and print the max absolute error max_{i,j} |u_{j,i} - u_exact_{j,i}| and the L2 error sqrt(sum_{i,j} (u_{j,i}-u_exact_{j,i})^2 * dx * dy) at T.
