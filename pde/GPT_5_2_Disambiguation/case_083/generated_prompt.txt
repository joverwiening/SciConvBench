Implement a 1D wave-equation solver in Python using NumPy and Matplotlib for Task ID agent_wave_02.
Solve u_tt = (0.5)^2 u_xx on x in [0,1] and t in [0,1.0] with c = 0.5.
Use Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 enforced by setting boundary grid values at every time step.
Use a uniform grid with Nx=400 intervals so there are Nx+1=401 grid points.
Define dx = 1/Nx and x_i = i*dx for i=0..Nx.
Choose dt0 = 0.9*dx/c and set Nt = ceil(T/dt0) with T=1.0.
Set dt = T/Nt so that the final time is reached exactly at n=Nt.
Use second-order central differences for the interior second derivative u_xx: u_xx[i] = (u[i-1] - 2*u[i] + u[i+1]) / dx^2 for i=1..Nx-1.
Use the standard second-order central difference in time (leapfrog / Störmer–Verlet): u^{n+1} = 2u^n - u^{n-1} + (c*dt)^2 * u_xx^n for interior points.
Initialize u^0 from the exact solution at t=0: u^0(x) = cos(0.5*2*pi*0)*sin(2*pi*x) = sin(2*pi*x).
Initialize v0(x) = u_t(x,0) from the exact solution: v0(x) = d/dt[cos(0.5*2*pi*t)]_{t=0} * sin(2*pi*x) = 0.
Compute u_xx^0 from u^0 using the same spatial stencil.
Compute u^1 using the Taylor start with no forcing: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
After computing u^1, enforce Dirichlet boundary values at i=0 and i=Nx.
Time-step from n=1 to n=Nt-1 to compute u^{n+1}, enforcing Dirichlet boundary values at every step.
At the end, take u = u^{Nt} as the numerical solution at T=1.0.
Compute the reference solution on the same grid at T: u_exact(x,T) = cos(0.5*2*pi*T)*sin(2*pi*x).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max(|u-u_exact|) and the L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_wave_02.npz containing arrays x (1D) and u (1D) and scalar metadata T, dx, dt.
