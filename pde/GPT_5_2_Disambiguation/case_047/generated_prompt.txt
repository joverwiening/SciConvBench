Solve the 2D heat equation u_t = 0.1*(u_xx + u_yy) for u(x,y,t).
Use the spatial domain x in [0,1] and y in [0,1] with a uniform grid using Nx=40 and Ny=40 intervals, giving (Nx+1) by (Ny+1) grid points.
Define dx = (1-0)/Nx and dy = (1-0)/Ny.
Define x_i = i*dx for i=0..Nx and y_j = j*dy for j=0..Ny.
Store the solution as a 2D array u with shape (Ny+1, Nx+1) such that u[j,i] corresponds to u(x_i, y_j).
Use the initial condition u(x,y,0) = x + y at all grid points.
Enforce Dirichlet boundary conditions u(x,y,t) = x + y on all four edges for all time steps by fixing boundary nodes each step.
Discretize the Laplacian on interior nodes with the 5-point second-order finite difference stencil: (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2.
Use implicit Euler time integration with dt=0.01 from t=0 to T=1.0 for 100 steps.
At each time step, form and solve the sparse linear system for interior unknowns corresponding to (I - dt*0.1*L) u^{n+1} = u^n with boundary values incorporated into the right-hand side.
After completing the 100 steps, compute u(x,y,T=1.0) on the full grid including boundaries.
Compute the reference solution u_ref(x,y,T) = x + y on the same grid.
Compute and print at T: min(u), max(u), and the discrete L2 norm sqrt(sum_{i,j} u[j,i]^2 * dx * dy).
Compute and print the error at T: max absolute error max_{i,j} |u - u_ref| and L2 error sqrt(sum_{i,j} (u-u_ref)^2 * dx * dy).
