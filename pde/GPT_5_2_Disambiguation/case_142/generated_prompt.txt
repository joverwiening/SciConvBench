Solve the 1D linear advection PDE u_t + beta*u_x = 0 with beta = 7.0 for t in [0, T] with T = 2.0.
Use a periodic spatial domain [0, 1) with periodic boundary conditions u(0,t) = u(1,t).
Use a uniform periodic grid with Nx = 512 grid points, dx = (1 - 0)/Nx, and x_i = 0 + i*dx for i = 0..Nx-1.
Set the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) evaluated at the grid points (trig in radians).
Discretize u_x with 1st-order upwind finite differences using the upwind direction determined by the sign of beta.
For beta > 0, use u_x(x_i) ≈ (u_i - u_{i-1})/dx with periodic wrap u_{-1} = u_{Nx-1}.
Advance in time with explicit forward Euler: u_i^{n+1} = u_i^n - dt*beta*(u_i^n - u_{i-1}^n)/dx (with periodic wrap).
Choose CFL = 0.5 and set dt_initial = CFL*dx/abs(beta).
Set Nt = ceil(T/dt_initial) and then reset dt = T/Nt so the final time is hit exactly.
Run the time stepping for Nt steps to compute u(x,T) on the grid.
Compute the reference solution on the same grid as u_ref(x_i,T) = u0(((x_i - beta*T) mod 1)) where u0(x) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Compute and print at t = T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the error vs reference at t = T: max absolute error max_i |u_i - u_ref_i| and L2 error sqrt(sum((u - u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta7.npz containing x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_advection_beta7.png.
