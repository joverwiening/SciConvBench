Use a 1D compressible Navier–Stokes solver (no heat conduction) in conservative form for unknowns rho(x,t), v(x,t), p(x,t).
Evolve conservative cell-averaged variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use Gamma = 1.6666666666666667.
Use eta = 1e-08 and zeta = eta, and define sigma = (zeta + 4/3*eta) * v_x.
Solve on x in [-1, 1] and t in [0, 0.2] with final time T = 0.2.
Use a uniform cell-centered finite-volume grid with Nx = 800 cells.
Set dx = 2/Nx.
Set cell centers x_j = -1 + (j+0.5)*dx for j = 0..Nx-1.
Apply transmissive/outflow (zero-gradient) boundary conditions at x = -1 and x = 1 using ghost cells set equal to the nearest interior cell.
Initialize a Riemann problem with discontinuity at x = 0 using primitive states.
For x < 0 set rho = 1.0, v = 0.0, p = 1.0.
For x >= 0 set rho = 0.1, v = 0.0, p = 0.1.
Convert initial primitive variables to conservative variables per cell using m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho) during evolution.
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) when needed for stability and for computing c.
Compute inviscid (Euler) physical flux F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part at each interface.
Compute sound speed c = sqrt(Gamma*p/rho) in each cell.
At each interface use wave speed a = max(|v_L| + c_L, |v_R| + c_R).
Compute inviscid numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute cell-centered velocities v_j = m_j / rho_j.
Compute v_x at cell centers using a centered difference on cell-centered v values, using ghost cells for boundary handling.
Compute cell-centered sigma_j = (zeta + 4/3*eta) * (v_x)_j.
Compute interface sigma by averaging neighboring cell-centered sigma values.
Compute interface v by averaging neighboring cell-centered v values.
Compute viscous interface flux F_visc = [0, -sigma, -v*sigma] using the interface-averaged v and sigma.
Compute total interface flux F_total = F_hat + F_visc.
Advance the semi-discrete finite-volume system U_t = -(F_total(i+1/2) - F_total(i-1/2))/dx using 2-stage SSP-RK2 (Heun’s method).
Choose dt each step using dt_conv = CFL * dx / max_j(|v_j| + c_j).
Choose dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc).
Adjust the final time step so that t reaches exactly T = 0.2.
After reaching T, compute rho(x,T) = rho_j, v(x,T) = m_j/rho_j, and p(x,T) from the equation of state on cell centers.
