Solve u_t = ∂/∂x( D(x) u_x ) with D(x)=0.01+0.09*x^2 for x∈[0,1], t∈[0,0.2].
Use initial condition u(x,0)=x(1-x).
Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use a uniform grid with Nx=400 intervals, dx=(1-0)/Nx, and grid points x_i=0+i*dx for i=0..Nx.
Define D_i=D(x_i) and face values D_{i+1/2}=0.5*(D_i+D_{i+1}).
Discretize the diffusion operator in conservative flux form for interior nodes i=1..Nx-1 as (Lu)_i=(1/dx^2)[D_{i+1/2}(u_{i+1}-u_i)-D_{i-1/2}(u_i-u_{i-1})].
Enforce Dirichlet boundaries by setting u_0=0 and u_Nx=0 at every time level and solving only for unknowns u_1..u_{Nx-1}.
Use implicit Euler time stepping with dt=0.0005 for 400 steps to reach T=0.2: (I - dt*L) u^{n+1} = u^n on the interior unknowns.
Assemble the resulting tridiagonal sparse linear system each step using the variable coefficients D_{i±1/2} and solve it with a sparse direct solver.
After the final step, form the full solution vector u of length Nx+1 including boundary values.
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) using all grid points.
Save solution_agent_diffusion_02.npz containing arrays x (1D length Nx+1) and u (1D length Nx+1) and scalars T=0.2, dx, dt.
