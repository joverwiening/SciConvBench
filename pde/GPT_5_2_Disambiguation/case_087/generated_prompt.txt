Implement a 1D wave-equation solver for u(x,t) with u_tt = c^2 u_xx and c = 1.0.
Use the spatial domain x in [0,1] and final time T = 1.0.
Use a uniform grid with Nx = 400 intervals and Nx+1 points.
Define dx = (1 - 0)/Nx and x_i = 0 + i*dx for i = 0..Nx.
Impose Neumann boundary conditions u_x(0,t)=0 and u_x(1,t)=0 using ghost points with mirror values.
Implement ghost points as u_{-1} = u_{1} and u_{Nx+1} = u_{Nx-1} at each time level when forming u_xx.
Discretize u_xx with 2nd-order central differences: (u_{i-1} - 2u_i + u_{i+1})/dx^2 for i = 0..Nx using the ghost-point values at i=-1 and i=Nx+1.
Use 2nd-order central difference in time (leapfrog / Störmer–Verlet): u_i^{n+1} = 2u_i^n - u_i^{n-1} + dt^2 * c^2 * (u_xx)_i^n.
Set dt0 = 0.9*dx/c and Nt = ceil(T/dt0), then set dt = T/Nt so that t= T is reached exactly.
Set initial displacement u(x,0) = cos(pi*x) evaluated in radians on the grid.
Set initial velocity u_t(x,0) = 0 on the grid.
Compute u at the first time step using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0), with v0 = 0 and u_xx^0 computed using the same Neumann ghost-point handling.
Time-march from n=1 to n=Nt-1 using the leapfrog update to obtain u at t = T.
At the end, compute the reference solution u_exact(x,T) = cos(pi*x)*cos(pi*T) on the same x grid.
Compute and print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max(|u - u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_wave_06.npz containing arrays x (1D) and u (1D) and scalar metadata T, dx, dt.
Generate and save a line plot of u(x,T) versus x as solution_agent_wave_06.png using Matplotlib.
Use Python as the implementation language with NumPy for computation and Matplotlib for plotting.
