Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) ∈ [0,1] × [0,1].
Use a uniform grid with Nx = Ny = 100 intervals, giving (Nx+1) × (Ny+1) grid points.
Define dx = (1-0)/Nx and dy = (1-0)/Ny.
Define x_i = i*dx for i = 0..Nx and y_j = j*dy for j = 0..Ny.
Store the solution in an array u with shape (Ny+1, Nx+1) such that u[j,i] corresponds to u(x_i, y_j).
Impose Dirichlet boundary conditions on all four edges using u(x,y) = x^2 - y^2 evaluated on the boundary grid points.
Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil.
Assemble the resulting sparse linear system for the interior unknowns only, incorporating boundary values into the right-hand side.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Populate the full grid solution u including both interior and boundary values.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete L2 norm of u as sqrt(sum(u^2) * dx * dy) over the full grid.
Evaluate the reference solution u_exact(x,y) = x^2 - y^2 on the same grid.
Compute and print the max absolute error max(|u - u_exact|) over the full grid.
