Solve u_t = nu*u_xx + rho*u*(1-u) for x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu = 5.0 and rho = 5.0.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) with trig in radians.
Use a uniform periodic grid on [0,1) with Nx = 512 points.
Define dx = (1.0 - 0.0)/Nx and x_j = j*dx for j = 0..Nx-1.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = Nt*dt = 1.0 exactly.
Advance the solution using Strang splitting for each full time step dt.
In each time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space: compute u_hat = FFT(u), define k = 2*pi*fftfreq(Nx, d=dx), update u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then set u <- real(IFFT(u_hat)).
Then perform a reaction full-step of duration dt solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u) using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Then perform the same diffusion half-step again (FFT, multiply by exp(-nu*k^2*(dt/2)), IFFT, take real part).
After Nt steps, compute and store u(x,T=1.0) on the periodic grid.
Save an NPZ file named solution_pdebench_reacdiff_nu5_rho5.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_reacdiff_nu5_rho5.png.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) evaluated at T.
