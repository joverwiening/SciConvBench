Solve the scalar ODE du/dt = a*exp(-t) + b for u(t) on t in [0.0, 5.0].
Use parameters a = 2.0 and b = -0.5.
Use initial condition u(0.0) = 0.0.
Use a uniform time grid with dt = 0.001 and Nt = 5000 so t_n = 0.0 + n*dt for n = 0..Nt and t_Nt = 5.0 exactly.
Compute u(t_n) for all n = 0..Nt using classical fixed-step RK4.
Implement RK4 with k1 = f(t_n, u_n), k2 = f(t_n + dt/2, u_n + dt*k1/2), k3 = f(t_n + dt/2, u_n + dt*k2/2), k4 = f(t_n + dt, u_n + dt*k3), and u_{n+1} = u_n + (dt/6)*(k1 + 2*k2 + 2*k3 + k4), where f(t,u)=a*exp(-t)+b.
Compute the exact solution on the same grid using u_exact(t) = u0 + a*(1 - exp(-t)) + b*t with u0 = 0.0.
Compute and print u(T) where T = 5.0, min(u) over all time points, and max(u) over all time points.
Compute and print the max absolute error max_n |u_n - u_exact(t_n)|.
Compute and print the L2 error as sqrt(mean_n (u_n - u_exact(t_n))^2) over n = 0..Nt.
Save an NPZ file named solution_molk_001.npz containing arrays t (shape (Nt+1,)), u (shape (Nt+1,)), and parameter scalars a and b and u0.
