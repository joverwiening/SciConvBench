Write a single, runnable Python script (e.g., `molk_031.py`) that numerically solves the 1D PDE u_t = -q1 * ∂_x(cos(u)) + (q2/pi) * u_xx on x in [0,1) with periodic boundary conditions and t in [0,0.5].
Use parameters q1 = 1.0 and q2 = 0.05.
Use the initial condition u(x,0) = 0.5*sin(2*pi*x) with trig in radians.

Compute the discrete convection operator as -(q1/dx) * (F_{j+1/2} - F_{j-1/2}) with periodic indexing.

Set final time T = 0.5.

Set dt = min(dt_adv, dt_diff), Nt = ceil(T/dt), and then reset dt = T/Nt so the final time is hit exactly.
Run the integrator for Nt steps to compute u(x,T=0.5).
At T=0.5, print to stdout the following scalar diagnostics with clear labels: min(u), max(u), mean(u), and discrete L2 norm defined as sqrt(sum(u**2) * dx).
Do not print any error norms or comparisons to reference solutions.
