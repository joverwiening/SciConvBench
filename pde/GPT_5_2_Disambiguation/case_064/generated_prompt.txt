Solve the 2D Laplace equation u_xx + u_yy = 0 for u(x,y).
Use the domain (x,y) in [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1) by (Ny+1) grid points including boundaries.
Set dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Store the solution in an array u with shape (Ny+1, Nx+1) such that u[j,i] = u(x_i, y_j).
Impose Dirichlet boundary conditions on all four edges.
Set u(x,0)=0 for all x on the bottom edge y=0.
Set u(x,1)=sin(2*pi*x) for all x on the top edge y=1.
Set u(0,y)=0 for all y on the left edge x=0.
Set u(1,y)=0 for all y on the right edge x=1.
Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil.
Assemble the sparse linear system for the interior unknowns only, incorporating Dirichlet boundary values into the right-hand side.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Populate the full grid solution u including boundary values.
Evaluate the reference solution u_exact(x,y)=sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi) on the same grid using radians for trig.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Compute and print the max absolute error max(|u-u_exact|) over all grid points.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over all grid points.
