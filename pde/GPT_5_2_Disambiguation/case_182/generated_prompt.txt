Use the 1D periodic spatial domain x in [0, 1) with period 1.
Solve u_t = nu*u_xx + rho*u*(1-u) for u(x,t).
Use parameters nu = 1.0 and rho = 2.0.
Use a uniform periodic grid with Nx = 512 grid points on [0,1) with dx = (1-0)/Nx and x_i = i*dx for i = 0..Nx-1.
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points (use radians).
Use a fixed time step dt = 0.001 for Nt = 1000 steps so the final time is T = Nt*dt = 1.0 exactly.
Advance one full time step dt using Strang splitting: diffusion half-step, reaction full-step, diffusion half-step.
Implement each diffusion half-step of duration dt/2 by FFT: compute u_hat = FFT(u), set k = 2*pi*fftfreq(Nx, d=dx), update u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then set u <- real(IFFT(u_hat)).
Implement the reaction full-step of duration dt pointwise using the exact logistic update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
After Nt steps, compute the final solution array u at time T on the same grid.
Compute and print at time T: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu1_rho2.npz containing x (shape (Nx,)), u (shape (Nx,)), and scalars nu, rho, T, dx, dt, Nx, Nt.
