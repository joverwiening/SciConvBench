Q: What numerical flux (Riemann solver) should be used for the inviscid terms (e.g., Rusanov/Lax-Friedrichs, HLL, HLLC, Roe)?
A: Use the **Rusanov (local Lax–Friedrichs) numerical flux** for the inviscid (Euler) terms:

- \(F_{\text{conv}}(U) = \big[m,\; m^2/\rho + p,\; (E+p)v\big]\), with \(v=m/\rho\)
- Interface speed \(a = \max\left(|v_L|+c_L,\; |v_R|+c_R\right)\), \(c=\sqrt{\Gamma p/\rho}\)
- \( \hat F = \tfrac12\left(F_{\text{conv}}(U_L)+F_{\text{conv}}(U_R)\right) - \tfrac12 a (U_R-U_L)\)

Then add the specified viscous flux contribution separately.

Q: For the viscous terms, which spatial discretization should I use (e.g., compute v_x at interfaces with 2nd-order central differences and add a viscous flux at faces, or treat sigma_x as a cell-centered source term)?
A: Use the **face-flux formulation** (not a cell-centered source term):

- Compute **cell-centered** \(v_j = m_j/\rho_j\).
- Compute \(v_x\) **at cell centers** with a **2nd-order centered difference** on the cell-centered \(v\) values.
- Form **cell-centered** \(\sigma_j = (\zeta + \tfrac{4}{3}\eta)\, (v_x)_j\).
- Approximate **interface** \(\sigma_{j+1/2}\) by **averaging neighboring** cell-centered values (e.g., \(\sigma_{j+1/2} = 0.5(\sigma_j+\sigma_{j+1})\)).
- Add viscous contributions **at interfaces** to the momentum and energy fluxes:
  \[
  F_{\text{visc}} = [0,\; -\sigma,\; -v\sigma]
  \]
  using **interface-averaged** \(v\) and \(\sigma\).
- Total interface flux: \(F_{\text{total}} = \hat F_{\text{Rusanov}} + F_{\text{visc}}\).

Q: What boundary treatment should I use to implement the transmissive/outflow condition in the finite-volume scheme (e.g., how many ghost cells, and should ghost-cell values be copied from the nearest interior cell for all conservative variables)?
A: Use **ghost cells** and implement **outflow (zero-gradient)** by **copying the nearest interior cell state into the ghost cells**.

- **How many ghost cells:** Use **1 ghost cell on each side** (sufficient for the specified first-order Rusanov flux and centered differences).
- **What to copy:** Copy **all conservative variables** \(U=[\rho,\, m,\, E]\):
  - Left boundary: \(U_{-1} = U_{0}\)
  - Right boundary: \(U_{N} = U_{N-1}\)

(Equivalently, \(\rho\), \(m\), and \(E\) have zero normal gradient at the boundary.)
