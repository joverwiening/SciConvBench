Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.004.
Use periodic boundary conditions on a periodic domain with u(0,t)=u(1,t).
Use the spatial domain [0,1) with periodicity.
Use a uniform grid with Nx = 512 grid points on [0,1) (no duplicated endpoint).
Set dx = (1-0)/Nx and x_i = 0 + i*dx for i = 0..Nx-1.
Initialize u(x,0) = sin(2*pi*x) evaluated at the grid points using radians.
Integrate in time from t=0 to final time T = 1.0.
Set CFL = 0.4 and estimate max wave speed as 1.0 for the initial condition.
Compute dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0).
Reset dt = T/Nt so the final time is reached exactly in Nt steps.
Advance the solution using Strang splitting each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute u_hat = FFT(u).
Compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute u = real(IFFT(u_hat)).
Perform an advection full-step of duration dt for inviscid Burgers u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov flux and periodic indexing.
Define f(u) = 0.5*u^2.
For each interface between u_left = u[j] and u_right = u[j+1] (with u[Nx] identified with u[0]), compute alpha = max(abs(u_left), abs(u_right)).
Compute interface flux F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) using periodic indexing.
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
Perform the diffusion half-step again identically to the first diffusion half-step.
After completing Nt steps, treat the result as u(x,T) on the grid.
Compute and print at T: min(u), max(u), mean(u) as the discrete mean of the grid values, and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_burgers_nu4em3.npz containing x (length Nx), u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
