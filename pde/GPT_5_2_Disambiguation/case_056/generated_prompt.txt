Solve the 1D Klein–Gordon PDE u_tt − c^2 u_xx + m^2 u = 0 with c=1.2 and m=0.8.
Use the domain x ∈ [0,1] and t ∈ [0,0.7].
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t in [0,0.7].
Use the initial conditions u(x,0)=sin(3*pi*x) and u_t(x,0)=0.
Use the reference solution u_exact(x,t)=cos(sqrt((1.2*3*pi)^2 + (0.8)^2)*t)*sin(3*pi*x) for verification.
Discretize space with a uniform grid using Nx=600 intervals, giving Nx+1 grid points.
Set dx = (1−0)/Nx = 1/Nx and x_i = i*dx for i=0..Nx.
Approximate u_xx with 2nd-order central differences at interior points i=1..Nx−1.
Enforce the Dirichlet boundary values at i=0 and i=Nx at every time level.
Choose dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) with T=0.7.
Set dt = T/Nt so that the final time is reached exactly.
Use 2nd-order central difference in time (leapfrog) for u_tt.
Update interior points with u_i^{n+1} = 2 u_i^n − u_i^{n−1} + dt^2*(c^2*(u_{i+1}^n − 2u_i^n + u_{i−1}^n)/dx^2 − m^2*u_i^n).
Treat the +m^2*u term explicitly at time level n as −m^2*u_i^n in the acceleration term.
Initialize u^0 from the initial displacement u(x,0).
Initialize u^1 using a Taylor start: u_i^1 = u_i^0 + dt*v_i^0 + 0.5*dt^2*(c^2*(u_{i+1}^0 − 2u_i^0 + u_{i−1}^0)/dx^2 − m^2*u_i^0) for interior points, with v_i^0 = 0.
Set u_0^0=u_Nx^0=0 and u_0^1=u_Nx^1=0 to satisfy Dirichlet boundaries.
March in time for n=1..Nt−1 to compute u at t=T.
Compute and store the final numerical solution array u(x,T) on the same x grid.
Evaluate the reference solution u_exact(x,T) on the same x grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max(|u−u_exact|) and the L2 error sqrt(sum((u−u_exact)^2)*dx) at T.
