Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) for u(x,t).
Use domain x in [0,1) with periodic boundary conditions and final time T = 1.0.
Use parameters nu = 10.0 and rho = 5.0.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) with radians.
Use a uniform periodic grid with Nx = 512 points on [0,1).
Define dx = (1.0 - 0.0)/Nx = 1/512 and x_j = j*dx for j = 0,...,Nx-1.
Use a fixed time step dt = 0.001.
Use Nt = 1000 time steps so that Nt*dt = T exactly.
Advance the solution using Strang splitting for each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute u_hat = FFT(u) using the current real-valued u on the periodic grid.
Define the Fourier wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat <- u_hat * exp(-nu*k^2*(dt/2)).
Compute u <- real(IFFT(u_hat)).
Perform a reaction full-step of duration dt solved exactly pointwise for du/dt = rho*u*(1-u).
Update each grid value by u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the diffusion half-step again identically to the first half-step.
After Nt steps, compute u(x,T=1.0) on the periodic grid.
Compute and print at T the values min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu10_rho5.npz containing x (length Nx), u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_reacdiff_nu10_rho5.png.
