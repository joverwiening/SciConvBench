Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.2.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and x_j = j*dx for j = 0..Nx-1.
Set initial condition u(x,0) = sin(2*pi*x) evaluated at the grid points (radians).
Run the simulation from t = 0 to final time T = 1.0.
Choose CFL = 0.4 and estimate max speed as 1.0 to set dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and then set dt = T/Nt so the final time is hit exactly.
Advance in time using Strang splitting each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute u_hat = FFT(u).
Compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat <- u_hat * exp(-nu*k^2*(dt/2)).
Compute u <- real(IFFT(u_hat)).
Perform an advection full-step of duration dt for the inviscid Burgers equation using a finite-volume update with Rusanov flux.
Define f(u) = 0.5*u^2.
For each interface between u_left = u[j] and u_right = u[j+1] using periodic indexing, compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) with periodic indexing.
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) for all j.
Replace u <- u_new after the advection substep.
Perform the diffusion half-step again identically to the first diffusion half-step.
After completing Nt steps, compute u at time T on the grid.
Save an NPZ file named solution_pdebench_burgers_nu0p2.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_burgers_nu0p2.png.
Print min(u), max(u), mean(u) computed as the discrete average of the grid values, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
