Implement a single self-contained Python script named molk_033.py.

Solve the 1D periodic advection–diffusion PDE u_t = D*u_xx - ∂_x(F) on x in [0,1) and t in [0,1.0], where F = (1/gamma)*U'(x)*u, U(x)=cos(2*pi*x), and U'(x)=-2*pi*sin(2*pi*x).
Use parameters D=0.01 and gamma=1.0.
Use a uniform periodic grid with Nx=512 points on [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Represent u as a length-Nx array corresponding to the grid points.
Initialize u(x,0)=1.0+0.2*sin(2*pi*x) evaluated at the grid points.
Discretize the diffusion term D*u_xx using second-order central differences with periodic wrap-around: u_xx[j]=(u[j+1]-2*u[j]+u[j-1])/dx^2 with indices taken modulo Nx.
Discretize the conservative drift term -∂_x(F) using a finite-volume upwind numerical flux at interfaces.
Define interface locations x_{j+1/2}=(j+0.5)*dx for j=0..Nx-1 with periodic wrap-around.
Compute interface velocities b_{j+1/2}=U'(x_{j+1/2})/gamma using U'(x)=-2*pi*sin(2*pi*x).
Compute interface fluxes F_{j+1/2}=b_{j+1/2}*u_upwind where u_upwind = u[j] if b_{j+1/2}>=0 else u[j+1], with indices modulo Nx.
Compute the discrete divergence (∂_x F)[j] ≈ (F_{j+1/2}-F_{j-1/2})/dx with periodic wrap-around.
Define the semi-discrete RHS as RHS(u)=D*u_xx - (F_{j+1/2}-F_{j-1/2})/dx.
Use explicit SSP-RK2 time integration: u^(1)=u^n+dt*RHS(u^n), u^(n+1)=0.5*u^n+0.5*(u^(1)+dt*RHS(u^(1))).
Compute max|b| over all interfaces and set dt_candidate = min(0.4*dx/max|b|, 0.2*dx^2/D).
Set Nt=ceil(T/dt_candidate) with T=1.0 and then set dt=T/Nt so the final time is reached exactly.
Advance the solution for Nt steps to reach t=T.
At t=T, compute and print diagnostics: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u**2)*dx).
Do not compute or print error metrics because no exact solution is provided.
Save an NPZ file named solution_molk_033.npz in the current working directory containing arrays x (length Nx) and u (length Nx) and scalars T, dx, Nx, D, gamma.
