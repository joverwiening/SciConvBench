Solve u_tt = c^2 u_xx on x in [0,1] and t in [0,0.8] with c = 1.0.

Use 2nd-order central differences for the interior second derivative: u_xx[i] = (u[i-1] - 2*u[i] + u[i+1]) / dx^2 for i = 1..Nx-1.

Advance for n = 1..Nt-1 using the standard 2nd-order central difference in time (leapfrog): u^{n+1} = 2*u^n - u^{n-1} + (c*dt)^2 * u_xx^n, where u_xx^n is computed from u^n.
