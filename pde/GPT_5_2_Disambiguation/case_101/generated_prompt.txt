Implement a local command-line Python script to numerically solve the scalar ODE du/dt = a*sin(2*pi*t)*u on t in [0.0, 5.0].
Use radians for all trigonometric evaluations.
Use parameter a = 1.3.
Use initial condition u0 = u(0) with u0 = 1.0.
Use fixed-step classical 4th-order Runge–Kutta (RK4) time integration.
Use dt = 0.001 and Nt = 5000 so that t_n = 0.0 + n*dt for n = 0..Nt and T = 5.0 is hit exactly.
Allocate arrays t and u of length Nt+1.
Set t[0] = 0.0 and u[0] = u0.
For each step n = 0..Nt-1, advance u[n] to u[n+1] with RK4 using f(t,u) = a*sin(2*pi*t)*u and t[n+1] = t[n] + dt.
Compute the exact solution on the same grid as u_exact(t) = u0 * exp(a*(1 - cos(2*pi*t)) / (2*pi)).
Compute and print u(T) = u[Nt], min(u) over all grid points, and max(u) over all grid points.
Compute and print the max absolute error max(|u - u_exact|) over the grid.
Compute and print the L2 error as sqrt(mean((u - u_exact)^2)) over the grid.
Save a NumPy .npz file named solution_molk_000.npz in the current working directory containing arrays t (shape (Nt+1,)), u (shape (Nt+1,)), and scalar parameters a, dt, Nt, t0, T, u0.
Generate and save a line plot of u(t) versus t as solution_molk_000.png in the current working directory.
Use standard best-practice Python tooling: numpy for arrays/math and matplotlib for plotting.
Ensure the script can be run from the command line and produces the two files and the printed diagnostics without requiring manual interaction.
