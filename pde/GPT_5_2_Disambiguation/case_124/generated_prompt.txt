Solve the 1D nonlinear reaction–diffusion PDE u_t = q1*u_xx + q2*u^2*(1-u)^2 for u(x,t).
Use parameters q1 = 0.01 and q2 = 2.0.
Use spatial domain x in [0,1) with periodic boundary conditions u(0,t)=u(1,t).
Use final time T = 1.0.
Use Nx = 512 periodic grid points with dx = (1-0)/Nx and x_i = i*dx for i=0..Nx-1.
Use initial condition u(x,0) = 0.2 + 0.1*sin(2*pi*x) evaluated in radians on the x grid.
Compute the numerical solution u(x,T) on the same periodic grid.
Save an NPZ file named solution_molk_023.npz containing arrays x (length Nx) and u (length Nx), and scalars T, dx, Nx, q1, q2.
Save a line plot of u versus x at T as solution_molk_023.png.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Do not compute or print error norms because no exact/reference solution is provided.
