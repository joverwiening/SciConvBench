Solve the 1D Allen–Cahn PDE u_t = (0.01)^2 u_xx + u − u^3 for x in [0,1) and t in [0,0.5].
Use periodic boundary conditions in x on the half-open domain [0,1) with no duplicated endpoint and wrap-around indexing, enforcing periodicity of u and u_x.
Use a uniform grid with Nx=800 grid points on [0,1) so dx = (1−0)/Nx and x_i = i*dx for i=0..Nx−1.
Initialize u(x,0) = 0.1*cos(2*pi*x) + 0.05*sin(4*pi*x) evaluated at the grid points using radians.
Discretize u_xx with 2nd-order central differences using periodic indexing: (u_{i+1} − 2u_i + u_{i−1})/dx^2 with indices taken modulo Nx.
Use the semi-implicit time stepping scheme (u^{n+1} − u^n)/dt = ε^2*(u_xx)^{n+1} + u^n − (u^n)^3 with ε=0.01.
Use dt=0.0002 and advance for 2500 steps to reach T=0.5 exactly.
At each time step, form and solve the linear system (I − dt*ε^2*L) u^{n+1} = u^n + dt*(u^n − (u^n)^3), where L is the periodic second-derivative finite-difference operator.
Compute the final numerical solution u(x,T) at T=0.5 on the same grid.
Save an NPZ file named solution_agent_allen_cahn_01.npz containing arrays x (1D) and u (1D, length Nx) and scalars T, dx, dt.
Save a line plot of u versus x at T=0.5 as solution_agent_allen_cahn_01.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) computed from the final u at T=0.5.
