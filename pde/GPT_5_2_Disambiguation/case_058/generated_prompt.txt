Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) ∈ [0,1] × [0,1].
Use a uniform grid with Nx = Ny = 100 intervals, giving (Nx+1) × (Ny+1) grid points including boundaries.
Define dx = dy = 1/Nx.
Define x_i = i*dx for i = 0..Nx and y_j = j*dy for j = 0..Ny.
Store the solution in a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
Impose Dirichlet boundary conditions on all four edges equal to the exact solution u(x,y) = sinh(pi*x)*sin(pi*y)/sinh(pi), using radians for trig.
Set boundary values explicitly as u(0,y)=0, u(1,y)=sin(pi*y), u(x,0)=0, and u(x,1)=0 (consistent with the exact solution).
Discretize the Laplacian at interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard 2nd-order 5-point stencil.
Form the sparse linear system A * u_interior = b for the interior unknowns only, incorporating Dirichlet boundary values into b.
Use a sparse direct solver to solve the system (e.g., scipy.sparse.linalg.spsolve).
Assemble the full grid solution including boundary values.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over the full grid.
Evaluate the reference solution u_exact(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi) on the same grid.
Compute and print the max absolute error max(|u - u_exact|) over the full grid.
Compute and print the discrete L2 error sqrt(sum((u - u_exact)^2)*dx*dy) over the full grid.
