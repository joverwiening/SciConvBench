Implement a numerical solver for the 2D variable-coefficient Darcy/Poisson equation on a unit square with Dirichlet boundary conditions.
Solve for u(x,y) such that -∇·(a(x,y)∇u(x,y)) = 1 on (0,1)×(0,1).
Use the coefficient field a(x,y) = 1 + beta*(0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) with trig in radians.
Use beta = 1.0.
Use a uniform Cartesian grid with N = 128 intervals in each direction, giving (N+1)×(N+1) grid points including boundaries.
Define dx = dy = 1/N.
Define x_i = i*dx for i = 0..N.
Define y_j = j*dy for j = 0..N.
Impose Dirichlet boundary conditions u = 0 on the entire boundary (i=0, i=N, j=0, j=N).
Discretize the PDE on interior nodes (i=1..N-1, j=1..N-1) using 2nd-order finite differences with variable coefficient using face-centered harmonic averaging.
Use the discrete equation -(1/dx^2)*[ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Compute face coefficients by harmonic mean, including a(i+1/2,j) = 2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)), and analogously for a(i-1/2,j), a(i,j+1/2), and a(i,j-1/2).
Evaluate a(i,j) as a(x_i,y_j) at grid nodes.
Assemble the sparse linear system A u_int = b for the interior unknowns only, with b being all ones corresponding to the right-hand side 1.
Use Python with NumPy for arrays, SciPy for sparse matrix assembly, and scipy.sparse.linalg.cg for the conjugate gradient solve.
Solve with CG to relative residual tolerance 1e-10.
Optionally use a Jacobi (diagonal) preconditioner.
After solving, place the interior solution into a full (N+1)×(N+1) array u with boundary values set to 0.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete residual norm ||A u_int - b||_2 / ||b||_2 for the interior system.
Save an NPZ file named solution_pdebench_darcy_beta1.npz containing x (1D), y (1D), u (2D with shape [N+1, N+1]), and scalars beta, N, dx.
Generate and save a heatmap/contour plot of u(x,y) as solution_pdebench_darcy_beta1.png using Matplotlib.
