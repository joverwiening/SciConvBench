Solve the 2D linear advection PDE u_t + a u_x + b u_y = 0 with a = -0.7 and b = 1.2 for u(x,y,t).
Use the spatial domain [0,1)×[0,1) with a half-open periodic grid in both x and y.
Use periodic boundary conditions u(x+1,y,t)=u(x,y,t) and u(x,y+1,t)=u(x,y,t) implemented via wrap-around (modulo) indexing with no duplicated endpoints.
Use Nx=Ny=256 grid points with dx=dy=1/Nx and x_i=i*dx for i=0..Nx-1 and y_j=j*dy for j=0..Ny-1.
Initialize u(x,y,0)=exp(-80*((x-0.2)^2 + (y-0.6)^2)) evaluated at the grid points.
Discretize u_x with first-order upwind chosen by the sign of a, using right-biased differences in x because a<0: u_x(i,j) ≈ (u(i+1,j) - u(i,j))/dx with i+1 wrapped modulo Nx.
Discretize u_y with first-order upwind chosen by the sign of b, using left-biased differences in y because b>0: u_y(i,j) ≈ (u(i,j) - u(i,j-1))/dy with j-1 wrapped modulo Ny.
Advance in time with Forward Euler: u^{n+1} = u^n - dt*(a*u_x + b*u_y).
Set T=0.5 and compute dt0 = 0.9 / (|a|/dx + |b|/dy).
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is reached exactly.
Run the time stepping for Nt steps to compute u(x,y,T) on the same grid.
Store the final solution in a 2D array u with shape (Ny,Nx) such that u[j,i] corresponds to u(x[i],y[j],T).
Save an NPZ file named solution_agent_advection_05.npz containing arrays x (1D), y (1D), u (2D), and scalars T, dx, dy, dt.
Save a heatmap or contour plot of u(x,y,T) as solution_agent_advection_05.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) computed from the final u array.
