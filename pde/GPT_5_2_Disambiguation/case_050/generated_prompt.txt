Implement the solver in Python 3.

Solve the 1D Klein–Gordon PDE u_tt - c^2 u_xx + m^2 u = 0 with c=1.0 and m=0.5 on x in [0,1] and t in [0,1.0].
Use a uniform grid with Nx=400 intervals and Nx+1 points, with dx=(1-0)/Nx and x_i=0+i*dx for i=0..Nx.
Impose zero Neumann boundary conditions u_x(0,t)=0 and u_x(1,t)=0 using ghost points with mirror values at every time level.
Discretize u_xx with 2nd-order central differences.
Discretize u_tt with 2nd-order central differences in time (leapfrog).
Treat the +m^2 u term explicitly at time level n in the leapfrog update.
Choose dt by first computing dt0 = 0.9*dx/c, then Nt = ceil(T/dt0), then dt = T/Nt so that t=T is reached exactly.
Set initial displacement u(x,0)=cos(pi*x) and initial velocity u_t(x,0)=0 using radians for trig.
Initialize u at the first time step using a Taylor start: u^1 = u^0 + dt*v^0 + 0.5*dt^2*(c^2*u_xx^0 - m^2*u^0), where u_xx^0 is computed with the same spatial discretization and boundary handling.
For each subsequent step n>=1, update with u^{n+1} = 2*u^n - u^{n-1} + dt^2*(c^2*u_xx^n - m^2*u^n), where u_xx^n uses the Neumann ghost-point handling.
Compute the numerical solution u(x,T) at T=1.0 on the grid.
Compute the reference solution on the same grid: u_exact(x,T)=cos(sqrt((1.0*pi)^2 + (0.5)^2)*T)*cos(pi*x).
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error metrics at T: max absolute error max(|u-u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx).
