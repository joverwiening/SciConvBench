Solve u_t = 0.05*(u_xx + u_yy) for u(x,y,t) on (x,y) in [0,1]x[0,1] and t in [0,0.5].
Use initial condition u(x,y,0)=exp(-80*((x-0.3)^2+(y-0.7)^2)) on [0,1]x[0,1].
Impose zero-flux Neumann boundary conditions on all four edges: ∂u/∂n = 0.
Use a uniform grid with Nx=Ny=80 intervals on each axis, so there are 81 grid points in x and 81 grid points in y.
Define dx=(1-0)/80 and dy=(1-0)/80, with x_i=0+i*dx for i=0..80 and y_j=0+j*dy for j=0..80.
Store the solution as a 2D array u with shape (len(y), len(x)) such that u[j,i]=u(x_i,y_j).
Discretize the Laplacian with the standard 5-point stencil on the grid interior.
Implement Neumann BC using ghost nodes such that the normal derivative at the boundary is zero, e.g., u_{-1,j}=u_{1,j}, u_{Nx+1,j}=u_{Nx-1,j}, u_{i,-1}=u_{i,1}, u_{i,Ny+1}=u_{i,Ny-1}, and use these ghost values when applying the 5-point stencil at boundary-adjacent nodes.
Advance in time using Implicit Euler with dt=0.001 for 500 steps to reach T=0.5.
At each step solve (I - dt*D*L) u^{n+1} = u^n where D=0.05 and L is the discrete Laplacian operator consistent with the 5-point stencil and Neumann ghost-node treatment.
Compute the final numerical solution u(x,y,T=0.5) on the same grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute total mass M(t)=sum(u)*dx*dy at t=0 and t=T, print M(0), M(T), and the relative change (M(T)-M(0))/M(0).
