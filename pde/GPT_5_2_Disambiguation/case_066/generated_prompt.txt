Solve the 2D Helmholtz-type PDE u_xx + u_yy + k^2 u = f(x,y) on (x,y) in [0,1] x [0,1].
Use k = 5.0.
Use f(x,y) = (k^2 - 2*pi^2)*sin(pi*x)*sin(pi*y) = (25 - 2*pi^2)*sin(pi*x)*sin(pi*y), with trig in radians.
Impose Dirichlet boundary conditions u=0 on x=0, x=1, y=0, y=1.
Use the reference solution u_exact(x,y) = sin(pi*x)*sin(pi*y) for verification.
Use a uniform grid with Nx=Ny=120 intervals, giving (Nx+1) by (Ny+1) grid points including boundaries.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Discretize the operator u_xx + u_yy + k^2 u at interior nodes using the standard 5-point Laplacian plus k^2*u, forming a sparse linear system A*u_vec = b.
Order unknowns as the interior grid values only, excluding boundary nodes fixed to zero.
Assemble b from f(x_i,y_j) at interior nodes, incorporating boundary contributions (which are zero here due to Dirichlet u=0).
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Reconstruct the full (Ny+1, Nx+1) solution array u with boundary values set to zero and interior values filled from the solver result, using indexing u[j,i] = u(x_i,y_j).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over the full grid.
Compute u_exact on the same grid and compute and print the max absolute error max(|u-u_exact|) and the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy).
