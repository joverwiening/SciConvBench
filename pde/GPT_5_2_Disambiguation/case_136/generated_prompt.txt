Use the 1D linear advection PDE u_t + beta*u_x = 0 with beta = 0.2.
Use a periodic spatial domain [0, 1) with periodic boundary condition u(0,t)=u(1,t).
Use a uniform periodic grid with Nx = 512 grid points, dx = (1-0)/Nx, and x_i = 0 + i*dx for i = 0..Nx-1.
Set the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) evaluated in radians on the grid.
Use first-order upwind finite difference for u_x with upwind direction determined by sign(beta).
For beta > 0, approximate u_x at i as (u_i - u_{i-1})/dx using periodic wrap for i-1.
Advance in time with explicit forward Euler: u^{n+1}_i = u^n_i - dt*beta*(u^n_i - u^n_{i-1})/dx with periodic wrap.
Use CFL = 0.5 to set an initial dt0 = CFL*dx/abs(beta).
Set final time T = 2.0.
Choose Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time is hit exactly.
Run the time stepping for Nt steps from t=0 to t=T.
Compute the reference solution on the same grid as u_ref(x_i,T) = u0(((x_i - beta*T) mod 1)) where u0 is the initial condition function.
Compute and print at t=T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error vs reference at t=T: max absolute error max_i |u_i - u_ref_i| and L2 error sqrt(sum((u-u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta0p2.npz containing x (length Nx), u (length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) versus x as solution_pdebench_advection_beta0p2.png.
