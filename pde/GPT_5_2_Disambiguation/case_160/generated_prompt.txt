Use a 1D compressible Navier–Stokes solver (no heat conduction) in conservative form for unknowns rho(x,t), v(x,t), p(x,t).
Evolve conservative cell averages U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use Gamma = 1.6666666666666667.
Use eta = 1e-08 and zeta = eta.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Solve on x in [-1, 1] and t in [0, 0.2].
Use a uniform finite-volume grid with Nx = 800 cells on [-1,1].
Use dx = (1 - (-1)) / Nx = 2/800 = 0.0025.
Use cell centers x_j = -1 + (j+0.5)*dx for j = 0..Nx-1.
Initialize a Riemann problem with discontinuity at x = 0 using cell-center positions.
Set for x < 0: rho = 1.0, v = 0.0, p = 1.0.
Set for x >= 0: rho = 0.125, v = 0.0, p = 0.1.
Convert initial primitive variables to conservative variables with m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use equation of state p = (Gamma-1) * (E - 0.5*m^2/rho) during evolution.
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) when needed for stability and for computing c.
Apply transmissive/outflow boundary conditions at x = -1 and x = 1 using ghost cells set equal to the nearest interior cell (zero-gradient).
Compute inviscid (Euler) physical flux F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part at each interface.
Compute sound speed c = sqrt(Gamma*p/rho) from reconstructed left/right states at the interface.
Set interface wave speed a = max(|v_L| + c_L, |v_R| + c_R).
Compute inviscid numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute cell-centered velocities v_j = m_j / rho_j.
Compute v_x at cell centers using a centered difference on v_j (use ghost cells to define boundary-adjacent differences).
Compute cell-centered sigma_j = (zeta + 4/3*eta) * (v_x)_j.
Compute interface sigma by averaging neighboring cell-centered sigma values.
Compute interface v by averaging neighboring cell-centered v values.
Add viscous contributions to interface fluxes as F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Set total interface flux F_total = F_hat + F_visc.
Advance the semi-discrete finite-volume system dU_j/dt = -(F_{j+1/2} - F_{j-1/2})/dx with 2-stage SSP-RK2 (Heun’s method).
At each time step compute dt_conv = CFL * dx / max_j(|v_j| + c_j).
At each time step compute dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc).
Adjust the final time step so that t reaches T = 0.2 exactly.
Choose and record a CFL scalar value (store it in the output file).
At final time T compute rho(x,T) = rho_j, v(x,T) = m_j/rho_j, and p(x,T) from the equation of state on cell centers.

Save a plot file named solution_pdebench_cns1d_sod1_eta1em8_outflow.png with three line plots (or a 3-panel figure) of rho vs x, v vs x, and p vs x at T.
