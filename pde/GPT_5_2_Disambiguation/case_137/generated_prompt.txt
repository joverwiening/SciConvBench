Solve the 1D linear advection PDE u_t + beta*u_x = 0 for u(x,t) on a periodic domain.
Use beta = 0.4.
Use spatial domain x in [0,1) with periodic boundary conditions and no duplicated endpoint.
Use a uniform grid with Nx = 512 grid points.
Define dx = (1 - 0)/Nx and x_i = 0 + i*dx for i = 0..Nx-1.
Set the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) using radians.
Use first-order upwind finite difference for u_x with upwind direction determined by the sign of beta.
For beta > 0, approximate u_x at i by (u_i - u_{i-1})/dx using periodic wrap for i-1.
Advance in time with explicit forward Euler: u^{n+1}_i = u^n_i - dt*beta*(u^n_i - u^n_{i-1})/dx with periodic indexing.
Use CFL = 0.5 to set an initial dt0 = CFL*dx/abs(beta).
Use final time T = 2.0.
Compute Nt = ceil(T/dt0) as an integer number of steps.
Reset dt = T/Nt so the final time is hit exactly after Nt steps.
Run the simulation from t=0 to t=T using Nt steps of size dt.
Compute the reference solution at T as u_ref(x,T) = u0(((x - beta*T) mod 1)) evaluated on the same x grid, where u0 is the initial condition function.
At final time T, compute and print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error max(|u - u_ref|) and L2 error sqrt(sum((u - u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta0p4.npz containing x (length Nx), u (length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) versus x as solution_pdebench_advection_beta0p4.png.
