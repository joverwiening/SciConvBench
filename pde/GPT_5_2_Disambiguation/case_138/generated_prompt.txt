Use the 1D linear advection PDE u_t + beta*u_x = 0 with beta = 0.7 on a periodic domain.
Use the spatial domain [0, 1) with periodicity u(0,t)=u(1,t).
Use a uniform grid with Nx = 512 grid points on [0,1) so dx = (1-0)/Nx and x_i = i*dx for i=0..Nx-1.
Set the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) evaluated at the grid points (radians for trig).
Discretize u_x with 1st-order upwind finite difference using the upwind direction determined by the sign of beta.
Because beta > 0, use u_x(x_i) ≈ (u_i - u_{i-1})/dx with periodic wrap u_{-1} = u_{Nx-1}.
Advance in time with explicit forward Euler: u_i^{n+1} = u_i^n - dt*beta*(u_i^n - u_{i-1}^n)/dx with periodic indexing.
Use CFL = 0.5 and initial dt0 = CFL*dx/abs(beta).
Set final time T = 2.0.
Choose Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time is hit exactly.
Compute the numerical solution u(x,T) after Nt steps.
Compute the reference solution on the same grid as u_ref(x_i,T) = u0(((x_i - beta*T) mod 1)) where u0(x) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error vs reference at T: max absolute error max(|u-u_ref|) and L2 error sqrt(sum((u-u_ref)^2)*dx).
