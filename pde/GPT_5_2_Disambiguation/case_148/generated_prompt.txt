Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.4.
Use periodic boundary conditions on a periodic domain [0, 1) so that u(0,t)=u(1,t) and the endpoint is not duplicated.
Use Nx = 512 grid points with x_i = 0 + i*dx for i=0..Nx-1 and dx = (1-0)/Nx.
Initialize u(x,0) = sin(2*pi*x) using radians.
Run the simulation for t in [0, T] with T = 1.0.
Set CFL = 0.4 and compute dt0 = CFL*dx/1.0 using estimated max speed 1.0.
Compute Nt = ceil(T/dt0) and then set dt = T/Nt so the final time is hit exactly.
Advance in time using Strang splitting for each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space by u_hat <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat <- u_hat * exp(-nu*k^2*(dt/2)), u <- real(IFFT(u_hat)).
Perform an advection full-step of duration dt for the inviscid Burgers equation using a finite-volume update with Rusanov flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) with periodic indexing, then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u <- u_new after the advection substep.
Perform the diffusion half-step again identically to the first diffusion half-step.
After completing Nt steps, compute u at final time T on the grid.
Save an NPZ file named solution_pdebench_burgers_nu0p4.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_burgers_nu0p4.png.
Print min(u), max(u), mean(u) computed as the discrete average of the grid values, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
