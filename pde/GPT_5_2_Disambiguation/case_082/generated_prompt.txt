Implement a Python 3 script that numerically solves the 1D wave equation u_tt = c^2 u_xx on x in [0,1] and t in [0,1.0] with c = 1.0.
Use a uniform grid with Nx = 400 intervals and Nx+1 points, with dx = (1-0)/Nx and x_i = i*dx for i = 0..Nx.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 by setting the boundary grid values at every time step.
Use 2nd-order central differences for the interior second derivative u_xx: u_xx[i] = (u[i-1] - 2*u[i] + u[i+1]) / dx^2 for i = 1..Nx-1.
Choose the time step by dt0 = 0.9*dx/c, Nt = ceil(T/dt0), and dt = T/Nt with T = 1.0 so that the final time is hit exactly.
Use the standard 2nd-order central difference in time (leapfrog / Störmer–Verlet) for u_tt: u^{n+1} = 2*u^n - u^{n-1} + (c*dt)^2 * u_xx^n for interior points.
Initialize from the exact solution at t=0: u0(x) = sin(pi*x).

Compute u at the first time level using the Taylor start with no forcing: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
After computing u^1, enforce Dirichlet boundary values at i=0 and i=Nx.
For each subsequent time step n = 1..Nt-1, compute u^{n+1} from u^n and u^{n-1} for interior points, then enforce Dirichlet boundary values.
At the end of the time stepping, define the numerical solution array u as u^{Nt} corresponding to t = T.
Compute the reference solution on the same grid at T: u_exact(x,T) = cos(1.0*pi*T)*sin(pi*x).
Compute and print at T the minimum and maximum of the numerical u array.
Compute and print the discrete L2 norm of the numerical solution: sqrt(sum(u^2)*dx).
Compute and print the max absolute error: max(abs(u - u_exact)).
Compute and print the discrete L2 error: sqrt(sum((u - u_exact)^2)*dx).
Save an NPZ file named solution_agent_wave_01.npz using numpy.savez containing arrays x (1D) and u (1D, same length as x) and scalars T, dx, dt.
Generate and save a line plot of u versus x at T as solution_agent_wave_01.png using Matplotlib, with labeled axes and a title indicating T=1.0.
