Solve the 1D linear advection PDE u_t + beta*u_x = 0 with beta = 0.1 on a periodic domain.
Use the spatial domain [0, 1) with periodicity, so Nx is the number of grid points with no duplicated endpoint.
Use Nx = 512 grid points with dx = (1 - 0)/Nx and x_i = 0 + i*dx for i = 0..Nx-1.
Use the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) evaluated in radians.
Use 1st-order upwind finite difference for u_x with upwind direction determined by sign(beta); since beta > 0, use u_x(x_i) ≈ (u_i - u_{i-1})/dx with periodic wrap for i-1.
Use explicit forward Euler time integration: u_i^{n+1} = u_i^n - beta*dt*(u_i^n - u_{i-1}^n)/dx with periodic indexing.
Use CFL = 0.5 and initial dt = CFL*dx/abs(beta).
Use final time T = 2.0.
Choose Nt = ceil(T/dt) and then reset dt = T/Nt so the final time is hit exactly.
Advance the solution from t=0 to t=T using Nt steps of size dt.
Compute the reference solution on the same grid as u_ref(x_i,T) = u0(((x_i - beta*T) mod 1)) where u0 is the initial condition function.
At t = T, compute and print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
At t = T, compute and print the max absolute error max_i |u_i - u_ref_i| and the L2 error sqrt(sum((u - u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta0p1.npz containing x (length Nx), u (length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) versus x as solution_pdebench_advection_beta0p1.png.
