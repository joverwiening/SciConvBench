Solve the 1D heat equation u_t = 0.1*u_xx for x in [0,1] and t in [0,0.5].
Use the initial condition u(x,0) = sin(pi*x).
Use Dirichlet boundary conditions consistent with the exact solution by fixing u(0,t)=0 and u(1,t)=0 at every time step.
Use a uniform grid with Nx=200 intervals on [0,1], giving Nx+1=201 grid points x_i=i*dx with dx=1/Nx.
Use second-order central differences for u_xx at interior points i=1..Nx-1.
Use Crank–Nicolson time integration with dt=0.001 from t=0 to T=0.5 for 500 time steps.
At each time step, enforce Dirichlet boundary conditions by setting the boundary nodes to their fixed values and solving the resulting linear system for interior nodes.
Compute the numerical solution u(x,T) at T=0.5 on the grid.
Compute the reference solution u_exact(x,T)=exp(-0.1*pi^2*T)*sin(pi*x) on the same grid.
Compute and print at T: min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error max(|u-u_exact|) and the L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_heat_01.npz containing arrays x (1D) and u (1D, same length as x), and scalars T, dx, dt.
