Solve u_t = 0.1 u_xx on x ∈ [0,1], t ∈ [0,0.5] for the unknown u(x,t).
Use the initial condition u(x,0) = 1 − x for x ∈ [0,1].
Use Dirichlet boundary conditions consistent with the initial condition by fixing u(0,t)=1 and u(1,t)=0 for all t ∈ [0,0.5].
Discretize space with a uniform grid using Nx=200 intervals, dx=1/Nx, and grid points x_i=i·dx for i=0..Nx.
Approximate u_xx at interior points i=1..Nx−1 with 2nd-order central differences (u_{i-1} − 2u_i + u_{i+1})/dx^2.
Integrate in time with Crank–Nicolson using dt=0.001 for 500 steps to reach T=0.5.
At each time step, enforce Dirichlet boundary conditions by setting the boundary nodes to the fixed values before/after solving the linear system.
Form the Crank–Nicolson linear system for interior unknowns only, using alpha=0.1 and r=alpha·dt/dx^2, with (I − (r/2)A) u^{n+1} = (I + (r/2)A) u^n plus boundary contributions, where A is the standard 1D second-derivative tridiagonal operator on interior nodes.
Compute the numerical solution u(x,T) on the full grid including boundaries.
Compute the reference solution u_ref(x,T)=1−x on the same x grid.
