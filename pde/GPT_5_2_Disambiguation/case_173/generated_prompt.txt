Use the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) with nu=0.5 and rho=10.0.
Use a periodic spatial domain x in [0,1) with no duplicated endpoint.
Use a uniform grid with Nx=512 grid points, dx=(1-0)/Nx, and x_i=i*dx for i=0..Nx-1.
Set the initial condition u(x,0)=0.25+0.1*sin(2*pi*x) evaluated at the grid points (use radians).
Use a fixed time step dt=0.001 for Nt=1000 steps so that final time T=Nt*dt=1.0.
Advance in time using Strang splitting for each full step dt.
Perform the diffusion half-step of duration dt/2 exactly in Fourier space by computing u_hat=FFT(u), defining k=2*pi*fftfreq(Nx,d=dx), updating u_hat <- u_hat*exp(-nu*k^2*(dt/2)), then setting u <- real(IFFT(u_hat)).
Perform the reaction full-step of duration dt exactly pointwise using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the diffusion half-step again identically to the first diffusion half-step.
After Nt steps, compute u at final time T on the grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
Save an NPZ file named solution_pdebench_reacdiff_nu0p5_rho10.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
