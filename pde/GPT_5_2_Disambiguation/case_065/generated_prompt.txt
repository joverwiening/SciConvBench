Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) ∈ [0,1] × [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1)×(Ny+1)=101×101 grid points.
Define dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Store the solution as a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x_i, y_j).
Impose Dirichlet boundary conditions on all boundary grid points.
Set bottom edge: for all i, u(y=0,x_i)=u[0,i]=0.
Set top edge: for all i, u(y=1,x_i)=u[Ny,i]=1.
Set left edge: for all j, u(y_j,x=0)=u[j,0]=0, except the top-left corner which is overridden by the top edge.
Set right edge: for all j, u(y_j,x=1)=u[j,Nx]=0, except the top-right corner which is overridden by the top edge.
Set corner values explicitly as u[0,0]=0, u[0,Nx]=0, u[Ny,0]=1, u[Ny,Nx]=1.
Discretize the Laplacian at interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard 5-point second-order stencil: (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2 = 0.
Assemble the resulting linear system A * u_interior = b for the (Nx-1)*(Ny-1) interior unknowns using a sparse matrix format.
Incorporate Dirichlet boundary values into the right-hand side b for interior equations adjacent to the boundary.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Insert the solved interior values back into the full grid array u while keeping boundary values fixed.
Compute and print min(u) over all grid points.
Compute and print max(u) over all grid points.
Compute and print the discrete L2 norm defined as sqrt(sum_{all grid points}(u^2) * dx * dy).
Save an NPZ file named solution_agent_laplace_09.npz containing x (1D array), y (1D array), u (2D array), and scalars dx and dy.
