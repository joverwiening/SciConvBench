Use the periodic spatial domain x in [0,1) with Nx=512 grid points and no duplicated endpoint.
Define dx = (1-0)/Nx and x_i = i*dx for i=0..Nx-1.
Solve u_t = nu*u_xx + rho*u*(1-u) with nu=0.5 and rho=2.0.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points (trig in radians).
Use fixed dt=0.001 and Nt=1000 time steps so T = Nt*dt = 1.0 exactly.
Advance one full time step with Strang splitting: diffusion half-step, reaction full-step, diffusion half-step.
For each diffusion half-step of duration dt/2, compute u_hat = FFT(u).
For the diffusion half-step, define k = 2*pi*fftfreq(Nx, d=dx).
For the diffusion half-step, update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
For the diffusion half-step, compute u = real(IFFT(u_hat)).
For the reaction full-step of duration dt, update pointwise using the exact logistic solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
After Nt steps, compute u at final time T on the same grid.
Compute and print at T: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
