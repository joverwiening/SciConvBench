Use the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.1.
Use a periodic spatial domain [0, 1) consistent with u(0,t)=u(1,t) and the given initial condition.
Use a uniform periodic grid with Nx = 512 points, dx = (1-0)/Nx, and x_i = 0 + i*dx for i = 0..Nx-1.
Set the initial condition u(x,0) = sin(2*pi*x) evaluated at the grid points using radians.
Integrate in time from t = 0 to final time T = 1.0.
Set CFL = 0.4 and compute dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0) and then set dt = T/Nt so the final time is reached exactly.
Advance the solution using Strang splitting each full time step dt.
Perform the diffusion half-step of duration dt/2 exactly in Fourier space by computing u_hat = FFT(u), k = 2*pi*fftfreq(Nx, d=dx), updating u_hat <- u_hat * exp(-nu*k^2*(dt/2)), and setting u <- real(IFFT(u_hat)).
Perform the advection full-step of duration dt for the inviscid Burgers equation using a finite-volume update with Rusanov flux.
Define f(u) = 0.5*u^2.
For each interface between u_left = u[j] and u_right = u[j+1] with periodic indexing, compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) using periodic indexing, then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u <- u_new after the advection substep.
Perform the diffusion half-step again identically to the first diffusion half-step.
After completing Nt time steps, compute and report min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_pdebench_burgers_nu0p1.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_burgers_nu0p1.png.
