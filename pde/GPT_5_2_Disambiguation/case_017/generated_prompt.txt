Solve u_t = ∂/∂x( D(x) u_x ) with D(x)=0.1*(1+x) for x in [0,1] and t in [0,0.5].
Use the initial condition u(x,0)=sin(pi*x).
Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t in [0,0.5].
Use a uniform grid with Nx=300 intervals, dx=(1-0)/Nx, and grid points x_i=0+i*dx for i=0..Nx.
Define D_i=D(x_i) and face values D_{i+1/2}=0.5*(D_i+D_{i+1}).
For interior nodes i=1..Nx-1, discretize ( (D u_x)_x )_i as (1/dx^2)*[D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1})].
Enforce Dirichlet boundaries in the linear system by setting u_0=0 and u_Nx=0 at every time step.
Use implicit Euler time integration with dt=0.001 for 500 steps to reach T=0.5, solving (I - dt*L) u^{n+1} = u^n each step, where L is the discrete diffusion operator with the boundary conditions applied.
Compute and store the final solution u(x,T) on the full grid including endpoints.
Save an NPZ file named solution_agent_diffusion_01.npz containing arrays x (1D) and u (1D, same length as x) and scalars T, dx, dt.
Save a line plot of u versus x at T as solution_agent_diffusion_01.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) evaluated at T.
