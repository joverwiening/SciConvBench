Implement a numerical solver in Python using NumPy for arrays and np.savez for output, and Matplotlib for plotting.
Solve the 2D wave equation u_tt = (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t) on (x,y) in [0,1]x[0,1] and t in [0,1.0] with wave speed c=1.0.
Use Dirichlet boundary conditions u=0 on all four boundaries for all times.
Use initial conditions u(x,y,0)=0 and u_t(x,y,0)=0.
Create a uniform grid with Nx=Ny=120 intervals, giving (Nx+1) by (Ny+1) grid points including endpoints.
Define dx=1/Nx and dy=1/Ny, x_i=0+i*dx for i=0..Nx, and y_j=0+j*dy for j=0..Ny.
Compute dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) with T=1.0, then set dt = T/Nt so that the final time is reached exactly.
Use a 5-point Laplacian for interior points: Lap(u)[j,i] = (u[j,i+1]-2u[j,i]+u[j,i-1])/dx^2 + (u[j+1,i]-2u[j,i]+u[j-1,i])/dy^2.
Use 2nd-order central differences in time for u_tt: u^{n+1} = 2u^n - u^{n-1} + dt^2*(Lap(u^n) + f(x,y,t_n)), where f(x,y,t)=sin(pi*x)*sin(pi*y)*cos(2*pi*t).
Initialize u^0 from the initial displacement as all zeros on the full grid.
Initialize u^1 using a Taylor start with the initial velocity: u^1 = u^0 + dt*u_t(x,y,0) + 0.5*dt^2*(Lap(u^0) + f(x,y,0)).
At every time step (including initialization), enforce Dirichlet boundary conditions by setting u=0 on i=0, i=Nx, j=0, and j=Ny.
Advance the solution for n=1..Nt-1 to obtain u at t=T.
Store the final-time solution as a 2D array u with shape (Ny+1, Nx+1) such that u[j,i] corresponds to (x_i, y_j).
Compute and print at T: min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Save an NPZ file named solution_agent_wave_11.npz containing arrays x (1D), y (1D), u (2D), and scalar metadata T, dx, dy, dt.
