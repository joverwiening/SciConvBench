Implement a 1D wave-equation solver for u(x,t) with u_tt = c^2 u_xx and c = 1.0.
Use the spatial domain x in [0,1] with Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use the time domain t in [0,1.0] with final time T = 1.0.
Use a uniform grid with Nx = 400 intervals and Nx+1 points.
Define dx = (1-0)/Nx and x_i = i*dx for i = 0..Nx.
Discretize u_xx with 2nd-order central differences at interior points i = 1..Nx-1: u_xx[i] = (u[i-1] - 2*u[i] + u[i+1]) / dx^2.
Use the standard 2nd-order central difference in time (leapfrog / Störmer–Verlet) for u_tt: u^{n+1} = 2u^n - u^{n-1} + (c^2 dt^2) u_xx^n.
Choose dt by CFL with dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that t=T is hit exactly.
Set the initial displacement from the exact solution at t=0: u0(x) = (1/(pi))*sin(pi*x)*sin(pi*0) = 0 for all x.
Set the initial velocity from the time derivative of the exact solution at t=0: v0(x) = u_t(x,0) = cos(pi*0)*sin(pi*x) = sin(pi*x).
Compute the first time level using the Taylor start with no forcing: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Enforce Dirichlet boundary values by setting u[0]=0 and u[Nx]=0 at every time level including initialization and after each update.
Time-march from n=1 to n=Nt-1 to compute u at t=T using the leapfrog update on interior points only.
At the end, compute and store the numerical solution array u(x,T) on the same x grid.
Evaluate the reference solution on the same grid at T: u_exact(x,T) = (1/(pi))*sin(pi*T)*sin(pi*x).
Compute and print at T the diagnostics: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the error metrics at T: max absolute error max(|u-u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx).
