Implement a Python program using NumPy for computation and Matplotlib for plotting.
Solve the 1D linear advection PDE u_t + (1.0)*u_x = 0 on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use a uniform periodic grid with Nx=800 points on [0,1) with dx=1/Nx and x_i=i*dx for i=0..Nx-1.
Set a=1.0.
Initialize u(x,0)=sin(2*pi*x) using radians.
Use 1st-order upwind finite difference for u_x consistent with a>0: u_x(x_i) ≈ (u_i - u_{i-1})/dx with periodic indexing u_{-1}=u_{Nx-1}.
Use Forward Euler time integration: u_i^{n+1} = u_i^n - a*dt*(u_i^n - u_{i-1}^n)/dx with periodic indexing.
Choose dt via CFL: dt0 = 0.9*dx/|a|, Nt = ceil(T/dt0), dt = T/Nt with T=1.0 so the final time is hit exactly.
Advance the solution for Nt time steps to reach t=T.
Compute the reference solution on the same grid at T: u_exact(x,T)=sin(2*pi*(x-a*T)).
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error vs reference at T: max absolute error max(|u-u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_advection_01.npz in the current working directory using numpy.savez containing arrays x (1D) and u (1D) and scalars T, dx, dt.
Save a line plot of u(x,T) as solution_agent_advection_01.png in the current working directory, with x on the horizontal axis and u on the vertical axis.
