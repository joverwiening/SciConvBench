Use the 1D linear advection PDE u_t + beta*u_x = 0 with beta = 1.0.
Use a periodic spatial domain [0, 1) with periodicity u(0,t)=u(1,t).
Use a uniform grid with Nx = 512 grid points on [0,1) so dx = (1-0)/Nx and x_i = i*dx for i=0..Nx-1.
Initialize u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) evaluated at the grid points (use radians).
Discretize u_x with 1st-order upwind finite difference using the upwind direction determined by the sign of beta.
For beta > 0, use u_x(x_i) ≈ (u_i - u_{i-1})/dx with periodic wrap u_{-1} = u_{Nx-1}.
Advance in time with explicit forward Euler: u_i^{n+1} = u_i^n - dt*beta*(u_i^n - u_{i-1}^n)/dx (with periodic wrap).
Set final time T = 2.0.
Set CFL = 0.5 and compute initial dt0 = CFL*dx/abs(beta).
Set Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time is hit exactly.
Run the time loop for Nt steps to compute u at time T on the same x grid.
Compute the reference solution at time T as u_ref(x_i,T) = u0(((x_i - beta*T) mod 1)) where u0(x) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Compute and print at time T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error vs reference on the same grid: max absolute error max(|u - u_ref|) and L2 error sqrt(sum((u-u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta1.npz containing arrays x (length Nx) and u (length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) versus x as solution_pdebench_advection_beta1.png.
