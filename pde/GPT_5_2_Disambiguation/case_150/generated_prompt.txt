Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.001.
Use a periodic spatial domain [0,1) consistent with the periodic boundary condition u(0,t)=u(1,t).
Use a uniform grid with Nx = 512 grid points on [0,1) with dx = (1-0)/Nx and x_i = 0 + i*dx for i=0..Nx-1.
Set the initial condition u(x,0) = sin(2*pi*x) evaluated at the grid points using radians.
Integrate in time on t ∈ [0, T] with T = 1.0.
Set CFL = 0.4 and compute dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0) and then set dt = T/Nt so the final time is reached exactly.
Advance each full time step dt using Strang splitting: diffusion half-step, advection full-step, diffusion half-step.
Implement each diffusion half-step of duration dt/2 exactly in Fourier space by computing u_hat = FFT(u), defining k = 2*pi*fftfreq(Nx, d=dx), updating u_hat <- u_hat * exp(-nu*k^2*(dt/2)), and setting u <- real(IFFT(u_hat)).
Implement the advection full-step of duration dt for inviscid Burgers using a finite-volume update with Rusanov flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j],u[j+1]) and F_minus as the flux between (u[j-1],u[j]) with periodic indexing, then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u <- u_new after the advection substep.
After completing Nt time steps, treat the resulting u as u(x,T) on the grid.
Compute and print min(u), max(u), mean(u) as the discrete mean over grid points, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
