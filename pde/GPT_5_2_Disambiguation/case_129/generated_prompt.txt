Solve the 1D inviscid conservation law u_t = -k * ∂_x((1/3)u^3) with k=1.0 on x in [0,1) with periodic boundary conditions for t in [0,0.2].
Use a uniform periodic grid with Nx=1024 points, dx=1/Nx, and x_j=j*dx for j=0..Nx-1.
Initialize u_j^0 = 0.5*sin(2*pi*x_j) using radians.
Use a conservative finite-volume update with numerical flux given by the Rusanov (local Lax-Friedrichs) flux for f(u)=(1/3)u^3.
Compute interface fluxes F_{j+1/2} = 0.5*(f(u_L)+f(u_R)) - 0.5*a_{j+1/2}*(u_R-u_L) with u_L=u_j and u_R=u_{j+1}.
Set a_{j+1/2} = max(|f'(u_L)|, |f'(u_R)|) with f'(u)=u^2.
Apply periodic indexing so that u_{Nx}=u_0 and u_{-1}=u_{Nx-1}.
Update cell values with u_j^{n+1} = u_j^n - (dt/dx)*(F_{j+1/2}-F_{j-1/2}) within each Runge–Kutta stage.
Use SSP-RK2 time integration: u^(1)=u^n + dt*L(u^n), then u^{n+1}=0.5*u^n + 0.5*(u^(1) + dt*L(u^(1))), where L(u) is the finite-volume spatial operator.
Choose the time step using CFL=0.2 with max|f'(u)| estimated as max(u^2) from the initial condition bound |u|<=0.5 so max|f'|<=0.25, set dt0=CFL*dx/max|f'|, set Nt=ceil(T/dt0), and set dt=T/Nt with T=0.2.
Advance exactly Nt steps to reach t=T.
Output only the final state array u(x_j,T=0.2) on the periodic grid and save it.
