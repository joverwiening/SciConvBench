Solve the 2D variable-coefficient Darcy/Poisson problem on (0,1)×(0,1): −∇·(a(x,y)∇u)=1 with u=0 on the entire boundary.
Use the coefficient field a(x,y)=1+0.1*(0.5+0.5*sin(2*pi*x)*sin(2*pi*y)) with trig in radians.
Use a uniform Cartesian grid with N=128 intervals in x and y, giving (N+1)×(N+1) grid points including boundaries.
Set dx=dy=1/N, x_i=i*dx for i=0..N, and y_j=j*dy for j=0..N.
Store u on the full grid as u[i,j] corresponding to (x_i,y_j).
Impose Dirichlet boundary conditions by setting u[i,0]=u[i,N]=u[0,j]=u[N,j]=0.
For interior nodes i=1..N-1 and j=1..N-1, discretize using 2nd-order finite differences with face-centered harmonic averaging:
Compute nodal coefficients a_ij=a(x_i,y_j).
Compute face coefficients by harmonic mean: a_{i+1/2,j}=2*a_ij*a_{i+1,j}/(a_ij+a_{i+1,j}), a_{i-1/2,j}=2*a_ij*a_{i-1,j}/(a_ij+a_{i-1,j}), a_{i,j+1/2}=2*a_ij*a_{i,j+1}/(a_ij+a_{i,j+1}), a_{i,j-1/2}=2*a_ij*a_{i,j-1}/(a_ij+a_{i,j-1}).
Apply the interior stencil:
-(1/dx^2)*[ a_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - a_{i-1/2,j}(u_{i,j}-u_{i-1,j}) + a_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - a_{i,j-1/2}(u_{i,j}-u_{i,j-1}) ] = 1.
Assemble the sparse linear system A u_int = b for the (N-1)×(N-1) interior unknowns with b being all ones.
Incorporate boundary values (all zeros) into the right-hand side as needed by the stencil.
Solve the symmetric positive definite system using conjugate gradient (CG) to relative residual tolerance 1e-10.
Optionally use a Jacobi (diagonal) preconditioner.
After solving, place the interior solution back into the full (N+1)×(N+1) array u with boundary values zero.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete interior residual norm ||A u_int − b||_2 / ||b||_2.
Save an NPZ file named solution_pdebench_darcy_beta0p1.npz containing x (1D length N+1), y (1D length N+1), u (2D shape [N+1,N+1]), and scalars beta=0.1, N=128, dx=1/N.
