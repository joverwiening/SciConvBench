Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) for x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu = 10.0 and rho = 2.0.
Use a uniform periodic spatial grid with Nx = 512 points on [0,1) with dx = 1/Nx and x_j = j*dx for j = 0,...,Nx-1.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points (use radians).
Advance in time with fixed time step dt and Nt steps such that Nt*dt = T exactly with T = 1.0.
Use Strang splitting for each full time step dt as follows.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space: compute u_hat = FFT(u), set k = 2*pi*fftfreq(Nx, d=dx), update u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then set u <- real(IFFT(u_hat)).
Perform a reaction full-step of duration dt solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u) using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform a second diffusion half-step identical to the first diffusion half-step.
After Nt steps, compute u(x,T=1.0) on the periodic grid.
Save an NPZ file named solution_pdebench_reacdiff_nu10_rho2.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_reacdiff_nu10_rho2.png.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) evaluated at T.
