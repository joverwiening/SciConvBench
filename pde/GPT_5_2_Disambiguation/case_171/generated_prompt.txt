Solve the 2D elliptic PDE -∇·(a(x,y)∇u(x,y)) = 1 on the open domain (0,1)×(0,1).
Use Dirichlet boundary conditions u=0 on the entire boundary of the unit square.
Use the coefficient field a(x,y)=1+beta*(0.5+0.5*sin(2*pi*x)*sin(2*pi*y)) with beta=100.0 and trig in radians.
Use a uniform Cartesian grid with N=128 uniform intervals in each direction, giving (N+1)×(N+1) grid points including boundaries.
Define dx=dy=1/N, x_i=i*dx for i=0..N, and y_j=j*dy for j=0..N.
Represent u on the full grid as u[i,j] corresponding to (x_i,y_j).
Impose boundary values u[i,0]=u[i,N]=u[0,j]=u[N,j]=0 for all valid i,j.
For interior nodes i=1..N-1 and j=1..N-1, discretize using 2nd-order finite differences with variable coefficient using face-centered harmonic averaging:
Compute nodal coefficients a[i,j]=a(x_i,y_j).
Compute face coefficients by harmonic mean:
a_iphalf_j = 2*a[i,j]*a[i+1,j]/(a[i,j]+a[i+1,j]),
a_imhalf_j = 2*a[i,j]*a[i-1,j]/(a[i,j]+a[i-1,j]),
a_i_jphalf = 2*a[i,j]*a[i,j+1]/(a[i,j]+a[i,j+1]),
a_i_jmhalf = 2*a[i,j]*a[i,j-1]/(a[i,j]+a[i,j-1]).
Enforce the interior discrete equation:
-(1/dx^2)*[ a_iphalf_j*(u[i+1,j]-u[i,j]) - a_imhalf_j*(u[i,j]-u[i-1,j]) + a_i_jphalf*(u[i,j+1]-u[i,j]) - a_i_jmhalf*(u[i,j]-u[i,j-1]) ] = 1.
Assemble the sparse linear system Au=b for interior unknowns only, using a consistent interior indexing mapping (i,j) with i=1..N-1, j=1..N-1 to a 1D vector.
Set b to the constant right-hand side corresponding to 1 at each interior node, incorporating boundary values (which are zero) into b as needed.
Solve the symmetric positive definite system with conjugate gradient (CG) to relative residual tolerance 1e-10.
Optionally use a Jacobi (diagonal) preconditioner.
After solving, place the interior solution back into the full (N+1)×(N+1) array u with boundary values remaining zero.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete residual norm for the interior system as ||Au-b||_2 / ||b||_2 using the assembled A and b and the solved interior vector.
