Solve the 1D linear advection PDE u_t + beta*u_x = 0 for x in [0,1) with periodic boundary conditions and t in [0,T].
Use beta = 2.0.
Use the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) with trig in radians.
Use a uniform periodic grid on [0,1) with Nx = 512 grid points, dx = (1-0)/Nx, and x_i = 0 + i*dx for i = 0..Nx-1.
Discretize u_x with a 1st-order upwind finite difference using the upwind direction determined by the sign of beta.
For beta > 0, use (u_x)_i ≈ (u_i - u_{i-1})/dx with periodic indexing (u_{-1} = u_{Nx-1}).
Advance in time with explicit forward Euler: u_i^{n+1} = u_i^n - dt*beta*(u_x)_i^n.
Use CFL = 0.5 and set dt_initial = CFL*dx/abs(beta).
Set Nt = ceil(T/dt_initial) and then reset dt = T/Nt so the final time is hit exactly.
Advance the solution from t=0 to t=T with Nt steps of size dt.
At final time T = 2.0, compute u(x,T) on the grid.
Compute the reference solution on the same grid as u_ref(x_i,T) = u0(((x_i - beta*T) mod 1)), where u0 is the initial condition function.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max_i |u_i - u_ref_i| and the L2 error sqrt(sum((u-u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta2.npz containing arrays x (length Nx) and u (length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) versus x as solution_pdebench_advection_beta2.png.
