Use the PDE u_t = nu*u_xx + rho*u*(1-u) for x in [0,1) with periodic boundary conditions.
Set parameters nu = 0.5 and rho = 5.0.
Use a uniform periodic grid with Nx = 512 points, x_j = j*dx for j = 0..511, and dx = 1/512.
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at the grid points (use radians).
Use a fixed time step dt = 0.001 with Nt = 1000 steps, and set T = Nt*dt = 1.0.
Advance the solution using Strang splitting for each full time step dt.
For each time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space by computing u_hat = FFT(u), defining k = 2*pi*fftfreq(Nx, d=dx), updating u_hat <- u_hat * exp(-nu*k^2*(dt/2)), and setting u <- real(IFFT(u_hat)).
Then perform a reaction full-step of duration dt solved exactly pointwise via u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Then perform the diffusion half-step again identically to the first diffusion half-step.
After Nt steps, compute and store u at final time T on the grid.
Compute and print at time T: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu0p5_rho5.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at time T as solution_pdebench_reacdiff_nu0p5_rho5.png.
