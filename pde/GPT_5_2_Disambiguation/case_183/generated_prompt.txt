Use the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) for x in [0,1) with periodic boundary conditions.
Set parameters nu=1.0 and rho=5.0.
Use a uniform periodic grid with Nx=512 points on [0,1) with dx=(1-0)/Nx and x_i=i*dx for i=0..Nx-1.
Set the initial condition u(x,0)=0.25+0.1*sin(2*pi*x) evaluated at the grid points (use radians).
Use a fixed time step dt=0.001 for Nt=1000 steps so T=Nt*dt=1.0 exactly.
Advance one full time step with Strang splitting: diffusion half-step (dt/2), reaction full-step (dt), diffusion half-step (dt/2).
Implement each diffusion half-step by FFT: compute u_hat=FFT(u), define k=2*pi*fftfreq(Nx,d=dx), update u_hat <- u_hat*exp(-nu*k^2*(dt/2)), then u <- real(IFFT(u_hat)).
Implement the reaction full-step pointwise using the exact logistic update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
After Nt steps, compute the final-time solution array u at T on the same grid.
Compute and print at T: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu1_rho5.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
