Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) in [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1) x (Ny+1) grid points.
Define dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Store the solution as a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
Impose Dirichlet boundary conditions on all four edges using the exact solution u(x,y)=x*y.
Set u(0,y)=0 on x=0.
Set u(1,y)=y on x=1.
Set u(x,0)=0 on y=0.
Set u(x,1)=x on y=1.
Discretize the Laplacian on interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard 5-point second-order finite difference stencil.
Form the sparse linear system A * u_interior = b for the interior unknowns only, incorporating boundary values into b.
Use a sparse direct solver (scipy.sparse.linalg.spsolve or equivalent) to solve for the interior unknowns.
Assemble the full grid solution u by combining solved interior values with the prescribed boundary values.
Compute and print min(u) and max(u) over all grid points.
Compute and print the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Evaluate the reference solution u_exact(x,y)=x*y on the same grid.
Compute and print the max absolute error max(|u-u_exact|) over all grid points.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over all grid points.
Save an NPZ file named solution_agent_laplace_05.npz containing arrays x (1D), y (1D), u (2D), and scalars dx and dy.
