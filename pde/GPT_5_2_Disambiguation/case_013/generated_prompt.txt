Solve the 1D viscous Burgers equation u_t + u*u_x = nu*u_xx on x in [0,1) and t in [0,0.5].
Use nu = 0.01.
Use periodic boundary conditions in x with wrap-around indexing on [0,1) (no duplicated endpoint), enforcing u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t).
Use a uniform periodic grid with Nx=800 grid points, dx=1/Nx, and x_i=i*dx for i=0..Nx-1.
Set the initial condition u(x,0)=sin(2*pi*x) evaluated in radians on the grid.
Discretize convection in conservative form with f(u)=0.5*u^2 using the Rusanov flux F_{i+1/2}=0.5*(f(u_i)+f(u_{i+1}))-0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2}=max(|u_i|,|u_{i+1}|).
Compute the discrete convection term at time level n as (F^n_{i+1/2}-F^n_{i-1/2})/dx using periodic indexing for i±1.
Discretize diffusion with the 2nd-order central difference u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2 using periodic indexing.
Advance in time with 1st-order IMEX: treat convection explicitly and diffusion implicitly via (u^{n+1}-u^n)/dt + conv^n = nu*L u^{n+1}, where L is the periodic second-difference operator.
Use dt=1e-4 and Nt=5000 steps so that T=Nt*dt=0.5 is reached exactly.
At each step, form the right-hand side rhs = u^n - dt*conv^n and solve the linear system (I - dt*nu*L) u^{n+1} = rhs with a sparse linear solver.
Construct (I - dt*nu*L) as an Nx-by-Nx sparse matrix with periodic couplings between indices 0 and Nx-1.
After the final step, compute u(x,T=0.5) on the same grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
