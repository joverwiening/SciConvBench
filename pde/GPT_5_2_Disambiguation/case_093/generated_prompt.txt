Implement a 1D numerical solver for the wave equation u_tt = (2.0)^2 u_xx on x in [0,1] and t in [0,0.5].
Use Python.
Use NumPy for arrays and math.
Use Matplotlib for plotting.
Use a uniform grid with Nx=400 intervals on [0,1], giving Nx+1=401 grid points.
Set dx = (1-0)/Nx = 1/Nx.
Define grid points x_i = 0 + i*dx for i=0..Nx.
Use wave speed c = 2.0.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 by setting the boundary nodes to 0 at every time step.
Set initial displacement u(x,0) = sin(pi*x) evaluated in radians on the grid.

Use 2nd-order central differences in time (leapfrog / Störmer–Verlet) for u_tt.
Choose the time step using CFL ≤ 0.9 as follows: dt0 = 0.9*dx/c.
Set T = 0.5.
Set Nt = ceil(T/dt0).
Set dt = T/Nt so that the final time is hit exactly.
Let u^0 be the array at t=0.

After computing u^1, enforce Dirichlet boundary values by setting u^1[0]=0 and u^1[Nx]=0.
For time steps n=1..Nt-1, update interior nodes with the leapfrog scheme: u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + (c*dt)^2 * u_xx(u^n)[i] for i=1..Nx-1.
After each update, enforce Dirichlet boundary values by setting u^{n+1}[0]=0 and u^{n+1}[Nx]=0.
At the end of the time stepping, take u(x,T) = u^{Nt}.
Compute the reference solution on the same grid at T using u_exact(x,T) = cos(2.0*pi*T)*sin(pi*x) with radians.
Compute and print at T the following diagnostics for the numerical solution: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error max(|u - u_exact|) at T.
Compute and print the discrete L2 error sqrt(sum((u - u_exact)^2)*dx) at T.
