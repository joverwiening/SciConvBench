Solve u_t = 0.02*(u_xx + u_yy) + 3.0*u*(1 - u/1.0) for (x,y) in [0,1]×[0,1] and t in [0,0.5].

Use initial condition u(x,y,0)=0.8*exp(-40*((x-0.5)^2+(y-0.5)^2)) on the full domain.

Set dx=dy=1/Nx with x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Represent the solution as a 2D array u[j,i] = u(x_i,y_j,t).
Approximate diffusion with the standard 5-point Laplacian on interior points: (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2.
Enforce Dirichlet boundaries by fixing u=0 at all boundary grid points at every time level and excluding them from the unknowns in the linear solve.
Use time step dt=0.0005 for Nt=1000 steps to reach T=0.5.
Use first-order IMEX: diffusion implicit (backward Euler) and reaction explicit (forward Euler).
Define the reaction term pointwise as R(u)=3.0*u*(1-u/1.0).
At each step compute rhs = u^n + dt*R(u^n) on interior points.
At each step solve (I - dt*0.02*L) u^{n+1} = rhs for interior unknowns, where L is the discrete Laplacian operator with Dirichlet treatment.
Assemble the sparse matrix A = (I - dt*0.02*L) once and reuse it for all time steps.
Use a sparse direct solver each step to solve A * u^{n+1}_interior = rhs_interior.
After each solve, write the interior values back into the full grid array and set boundary values to 0.
After Nt steps, treat the result as u(x,y,T=0.5) on the grid.
