Numerical Solution Specification for Klein-Gordon PDE (Task ID: agent_kg_05)

Partial Differential Equation:
u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0

Domain Specifications:
x in [0,1]
y in [0,1]
t in [0,0.8]

Grid Parameters:
Use Nx = Ny = 256 intervals
Grid points: Nx+1 by Ny+1 points
dx = dy = 1/Nx
dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2))
Nt = ceil(T/dt0)
dt = T/Nt to hit final time exactly

Numerical Method:
Spatial Discretization: 5-point Laplacian for u_xx+u_yy on uniform grid
Time Integration: 2nd-order central difference for u_tt
Initialization: Taylor start using Laplacian and mass term

Boundary Conditions:
Dirichlet on all boundaries: u = 0

Initial Conditions:
u(x,y,0) = sin(pi*x)*sin(pi*y)
u_t(x,y,0) = 0

Output Requirements:
1. Compute u(x,y,T=0.8) on 2D grid
2. Save "solution_agent_kg_05.npz" with:
   - x (1D array)
   - y (1D array)
   - u (2D array, shape (len(y), len(x)))
   - Metadata: T, dx, dy, dt
3. Save heatmap/contour plot "solution_agent_kg_05.png"
4. Print:
   - min(u)
   - max(u)
   - Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
5. Compute and print:
   - Max absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution:
u(x,y,t) = cos(sqrt((1.0)^2*(2*pi^2) + (1.0)^2)*t)*sin(pi*x)*sin(pi*y)
