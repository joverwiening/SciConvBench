Specification for PDE Reaction-Diffusion Numerical Solution (Task ID: pdebench_reacdiff_nu2_rho1):

Solve 1D Reaction-Diffusion PDE with the following specifications:

PDE: u_t = nu * u_xx + rho * u*(1 - u)
Domain: x in [0, 1) periodic, t in [0, 1.0]
Parameters: nu = 2.0, rho = 1.0

Spatial Discretization:
- Use Nx = 512 points on periodic grid [0,1)
- Grid points: x_j = j*dx for j=0,...,511
- dx = 1.0/512

Numerical Method:
- Use Strang splitting method with three steps:
  (A) Half diffusion step in Fourier space
  (B) Full reaction step solved exactly
  (C) Half diffusion step in Fourier space

Time Discretization:
- Compute time steps to reach T=1.0 exactly
- Use fixed time step dt

Output Requirements:
- Compute u(x,T=1.0) on periodic grid
- Save solution to "solution_pdebench_reacdiff_nu2_rho1.npz"
- Save plot as "solution_pdebench_reacdiff_nu2_rho1.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Boundary Condition:
Periodic: u(0,t) = u(1,t) for all t
