Solve the scalar ODE du/dt = 2.0*exp(-t) - 0.5 using the following specification:

Numerical Solution Method:
Solve the ODE using Classical 4th-order Runge-Kutta (RK4) method.
Use fixed time step dt = 0.001.
Simulate over time domain t ∈ [0.0, 5.0].
Total number of time steps: Nt = 5000.

Initial Condition:
Compute u0 by evaluating the exact solution at t = 0.

Computational Requirements:
Compute u(t) at all time points t_n = t0 + n*dt for n=0..Nt.
Save solution data in "solution_molk_001.npz" file.
Include arrays: t (1D length Nt+1), u (1D length Nt+1), and parameter scalars.

Visualization and Reporting:
Generate line plot of u(t) vs t and save as "solution_molk_001.png".
Print the following scalar diagnostics:
- u(T): Value at final time
- min(u): Minimum value over time grid
- max(u): Maximum value over time grid

Error Analysis:
Compute and print:
- Maximum absolute error vs exact solution
- L2 error vs exact solution

Exact Solution for Verification:
u(t) = u0 + 2.0*(1 - exp(-t)) - 0.5*t
Where u0 is the initial value at t = 0.
