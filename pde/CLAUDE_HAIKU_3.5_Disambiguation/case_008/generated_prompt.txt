Solve the Allen-Cahn PDE with the following specification:

Partial Differential Equation:
u_t = (0.02)^2*u_xx + u - u^3

Computational Domain:
Spatial domain x in [0,1]
Time domain t in [0,0.2]

Numerical Method:
Use a uniform grid with Nx = 1200 grid points
Use time step dt = 0.0001 (total 2000 time steps)
Spatial discretization: 2nd-order central differences for u_xx
Time integration: Semi-implicit scheme 
Boundary conditions: Dirichlet, enforced at each time step

Initial Condition:
u(x,0) = tanh((0.5 - x)/(sqrt(2)*0.02))

Parameters:
epsilon = 0.02

Output Requirements:
Compute u(x, T=0.2) on the grid
Save solution to "solution_agent_allen_cahn_02.npz" with arrays:
- x (1D spatial coordinates)
- u (1D solution at final time)
- Metadata: T, dx, dt
Save line plot of u(x,T) to "solution_agent_allen_cahn_02.png"
Print diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx)

Coding Notes:
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
- Treat all trigonometric functions in radians
