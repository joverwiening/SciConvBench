Solve the 1D inviscid conservation law with cubic flux using the following specification:

Partial Differential Equation:
u_t = -k*∂_x( (1/3)*u^3 )

Domain and Boundary Conditions:
Spatial domain is [0, 1) with periodic boundary conditions.
Time domain is [0, 0.2].
u(0,t) = u(1,t) for all t.

Parameters:
k = 1.0

Initial Condition:
u(x,0) = 0.5*sin(2*pi*x)

Numerical Method Specifications:
Use a uniform periodic grid with Nx = 1024 points.
Grid points: x_j = j*dx for j=0,...,Nx-1, where dx = 1/Nx.
Spatial discretization: Conservative finite-volume method with Rusanov flux for f(u)=(1/3)u^3.
Time integration method: SSP-RK2.
Time step calculation:
- Estimate max|f'(u)| = max|u^2|
- With initial |u|<=0.5, max|f'|<=0.25
- Set dt0 = CFL*dx/max|f'|, where CFL = 0.2
- Calculate Nt = ceil(T/dt0)
- Set dt = T/Nt

Coding Note:
Interpret '^' as exponentiation.
Use '**' for powers in Python implementation.
