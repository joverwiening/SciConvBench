Specification for Heat Equation Numerical Solution (Task ID: agent_heat_06):

Solve the 1D heat equation u_t = 0.1 * u_xx on domain x ∈ [0, 1], t ∈ [0, 0.5].

Numerical Method Specifications:
Spatial Discretization:
- Use uniform grid with Nx = 200 intervals (201 points including boundaries)
- Compute spatial derivatives using 2nd-order central differences
- Grid spacing dx = 1/Nx

Time Integration:
- Use Crank-Nicolson method for diffusion terms
- Time step dt = 0.001
- Total time steps = 500
- Enforce Dirichlet boundary conditions at each time step

Initial and Boundary Conditions:
- Initial condition: u(x,0) = 1 - x
- Boundary conditions: Fixed at initial boundary values

Output Requirements:
- Compute solution u(x, T=0.5)
- Save solution data in "solution_agent_heat_06.npz"
  - Include arrays: x, u
  - Include metadata: T, dx, dt
- Create line plot of u(x,T) saved as "solution_agent_heat_06.png"
- Print scalar diagnostics:
  - Minimum value of u
  - Maximum value of u
  - Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print error metrics:
  - Maximum absolute error vs reference solution
  - L2 error vs reference solution

Reference Solution: u(x,t) = 1 - x (steady state solution)
