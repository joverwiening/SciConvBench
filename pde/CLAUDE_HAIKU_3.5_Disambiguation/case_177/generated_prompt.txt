Numerical Solution for 1D Reaction-Diffusion PDE (Task ID: pdebench_reacdiff_nu10_rho10)

Solve the 1D Reaction-Diffusion PDE with the following specifications:

PDE Equation: u_t = nu * u_xx + rho * u*(1 - u)

Domain Parameters:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 1.0]
- Parameters: nu = 10.0, rho = 10.0

Numerical Method:
- Spatial discretization: Uniform periodic grid with Nx = 512 points
- Compute dx = (1 - 0) / 512
- Grid points: x_j = j*dx for j=0,...,511
- Time grid: Fixed dt to reach T=1.0 exactly
- Method: Strang splitting with three steps:
  (A) Diffusion half-step in Fourier space (dt/2)
  (B) Reaction full-step (dt) using exact pointwise logistic ODE update
  (C) Diffusion half-step in Fourier space (dt/2)

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Boundary Conditions:
- Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu10_rho10.npz"
- Include arrays: x, u, and scalars: nu, rho, T, dx, dt, Nx, Nt
- Create line plot "solution_pdebench_reacdiff_nu10_rho10.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
