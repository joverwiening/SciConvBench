Numerical Solution Specification for 2D Darcy Flow Problem (pdebench_darcy_beta0p1):

Solve the 2D Darcy flow PDE with the following specifications:

PDE Equation: -∇ · ( a(x,y) ∇u(x,y) ) = 1
Domain: (x,y) ∈ (0,1) × (0,1)
Boundary Conditions: Dirichlet u = 0 on all boundaries

Numerical Method Details:
- Grid: Uniform Cartesian grid with N = 128 intervals
- Grid Points: (N+1) × (N+1) points including boundaries
- Grid Spacing: dx = dy = 1/N
- Grid Coordinates: x_i = i*dx, y_j = j*dy for i,j = 0,...,N

Discretization Method:
- 2nd-order finite differences
- Variable coefficient with face-centered harmonic averaging
- Interior node discretization using harmonic mean face coefficients

Linear Solver:
- Conjugate Gradient (CG) method
- Tolerance: 1e-10 relative residual
- Optional: Simple Jacobi preconditioner

Output Requirements:
- Compute u(x,y) on full (N+1) × (N+1) grid
- Save solution to "solution_pdebench_darcy_beta0p1.npz"
- Include arrays: x (1D), y (1D), u (2D)
- Include scalars: beta, N, dx
- Generate contour plot "solution_pdebench_darcy_beta0p1.png"
- Print diagnostics: min(u), max(u), discrete residual norm

Coding Note: Use '^' for exponentiation, translate to '**' in Python implementation.
