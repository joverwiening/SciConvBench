Solve the 2D diffusion equation u_t = 0.05 * (u_xx + u_yy) with the following specifications:

Computational Domain:
- Spatial domain: x ∈ [0,1], y ∈ [0,1]
- Temporal domain: t ∈ [0,0.5]

Numerical Method:
- Grid: Uniform grid with Nx = Ny = 80
- Spatial discretization: 5-point Laplacian with ghost-node implementation for zero Neumann boundary conditions
- Time integration: Implicit Euler method
- Time step: dt = 0.001 (500 total time steps)
- Diffusion coefficient: D = 0.05

Boundary Conditions:
- Neumann (zero-flux) on all boundary edges: ∂u/∂n = 0

Output Requirements:
- Compute final solution u(x,y,T=0.5)
- Save solution to "solution_agent_diffusion_06.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (len(y), len(x)))
  * Metadata: T, dx, dy, dt
- Generate heatmap/contour plot "solution_agent_diffusion_06.png"
- Print diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
  * Total mass at t=0 and t=T
