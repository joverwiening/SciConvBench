Specification for Solving 1D Burgers' Equation Numerically:

Solve the 1D Burgers' equation u_t + u*u_x = 0.01*u_xx numerically with the following specifications:

Equation Details:
- PDE: u_t + u*u_x = 0.01*u_xx
- Domain: x in [0,1), t in [0,0.5]
- Kinematic viscosity (nu): 0.01
- Initial condition: u(x,0) = sin(2*pi*x)

Numerical Method:
- Spatial Discretization:
  Use conservative finite-volume discretization with Rusanov (local Lax-Friedrichs) flux.
  Convection term: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i)
  Diffusion term: Central 2nd-order difference

- Time Integration:
  1st-order IMEX method
  Treat convection explicitly and diffusion implicitly
  Solve linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term

Grid and Numerical Parameters:
- Grid Points: Nx = 800
- Spatial Step: dx = 1/Nx
- Time Step: dt = 1e-4
- Total Time Steps: Nt = 5000

Output Requirements:
- Compute u(x, T=0.5)
- Save solution to "solution_agent_burgers_01.npz"
  Include arrays: x, u, and metadata: T, dx, dt
- Create plot "solution_agent_burgers_01.png"
- Print diagnostics:
  - Minimum value of u at T
  - Maximum value of u at T
  - Discrete L2 norm: sqrt(sum(u^2)*dx)
