Specification for Wave Equation Numerical Solution (Task ID: agent_wave_04):

Solve the 1D wave equation u_tt = c^2 * u_xx numerically with the following specifications:

Equation: u_tt = (1.0)^2 * u_xx
Domain: x in [0,1], t in [0,1.0]
Wave speed (c): 1.0

Spatial Discretization:
- Use uniform grid with Nx = 400 intervals (Nx+1 points)
- dx = 1/Nx
- Use 2nd-order central differences for u_xx in the interior

Time Integration:
- Use 2nd-order central difference (leapfrog/Störmer–Verlet)
- Compute dt0 = 0.9 * dx/c
- Set Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Initial Conditions:
- u(x,0) = sin(pi*x)
- u_t(x,0) = 0
- Compute u(x,dt) using Taylor start method

Boundary Conditions:
- Dirichlet at x=0 and x=1: u = 0 at all times

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_wave_04.npz"
- Include arrays: x, u, with metadata T, dx, dt
- Create plot "solution_agent_wave_04.png" of u(x,T)
- Print diagnostics:
  1. min(u)
  2. max(u)
  3. Discrete L2 norm
  4. Max absolute error vs reference solution
  5. L2 error vs reference solution

Reference Solution: u(x,t) = (1/(1.0*pi)) * sin(1.0*pi*t) * sin(pi*x)

Coding Note: Use '^' for exponentiation, convert to '**' in Python implementation.
