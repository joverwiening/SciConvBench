Solve the 1D Reaction-Diffusion PDE with the following specification:

Partial Differential Equation:
u_t = 0.5 * u_xx + 10.0 * u*(1 - u)

Numerical Solution Parameters:
Spatial Grid: Uniform grid with 512 points
Time Grid: Fixed dt=0.001 with 1000 steps
Total Simulation Time: T = dt * Nt = 0.001 * 1000 = 1.0

Numerical Method:
Use Strang splitting method with three steps:
1. Diffusion half-step in Fourier space (dt/2)
2. Reaction full-step using exact pointwise update
3. Diffusion half-step in Fourier space (dt/2)

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Boundary Conditions:
Periodic boundary conditions (u(0,t) = u(1,t))

Output Requirements:
1. Compute final solution u(x,T)
2. Save solution to "solution_pdebench_reacdiff_nu0p5_rho10.npz"
3. Save line plot of u(x,T) to "solution_pdebench_reacdiff_nu0p5_rho10.png"
4. Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
