Parameters:
- Diffusion coefficient (nu) = 1.0
- Reaction rate (rho) = 1.0

Spatial Discretization:
- Use a uniform grid with Nx = 512 points
- Periodic boundary conditions
- Grid point calculation: x_i = a + i*dx for i=0..Nx-1

Temporal Discretization:
- Use fixed time step dt = 0.001
- Total time steps Nt = 1000

Numerical Method:
- Use Strang splitting method with three stages:
  1. Half diffusion step in Fourier space
  2. Full reaction step using exact pointwise update
  3. Half diffusion step in Fourier space

Initial Condition:
- u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_reacdiff_nu1_rho1.npz"
