Numerical Solution Specification for Wave Equation (Task ID: agent_wave_09)

Solve the wave equation PDE u_tt + 0.5*u_t = (1.0)^2 * u_xx with the following precise specifications:

Spatial Domain: x in [0,1]
Temporal Domain: t in [0,3.0]
Grid Parameters: 
- Nx = 400 grid points
- dx = (1-0)/400
- dt = 0.0005
- Total time steps = 6000

Discretization Method:
- Spatial discretization: 2nd-order central differences for u_xx
- Time integration: First-order system with RK4
- Rewrite PDE as system:
  u_t = v
  v_t = u_xx - 0.5*v

Boundary Conditions:
- Dirichlet at x=0 and x=1: u = 0
- Enforce BC at every RK4 substage

Initial Conditions:
- u(x,0) = sin(pi*x)
- u_t(x,0) = 0

Output Requirements:
- Compute u(x, T=3.0)
- Save solution to "solution_agent_wave_09.npz"
- Include arrays: x, u
- Include metadata: T, dx, dt
- Create plot "solution_agent_wave_09.png"
- Print diagnostics: min(u), max(u), discrete L2 norm
