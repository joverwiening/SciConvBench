Numerical Solution Specification for 2D Wave Equation (Task ID: agent_wave_19)

Implement a numerical solver for the 2D wave equation with the following precise specifications:

PDE: u_tt = (1.0)^2 * (u_xx + u_yy)

Domain Specifications:
- Spatial domain: [0,1) x [0,1) with periodic boundary conditions
- Time domain: [0,0.5]
- Grid: 128 x 128 points (Nx = Ny = 128)
- Grid spacing: dx = dy = 1/128

Initial Conditions:
- u(x,y,0) = cos(2*pi*x) * cos(2*pi*y)
- u_t(x,y,0) = 0

Numerical Method Requirements:
- Spatial discretization: 2nd-order central differences with periodic wrap-around
- Time integration: 2nd-order central in time
- CFL condition: ≤ 0.9
- Time step calculation: 
  * dt0 = 0.9 / (c * sqrt(1/dx^2 + 1/dy^2))
  * Nt = ceil(T/dt0)
  * dt = T/Nt to hit final time exactly

Output Requirements:
- Compute solution u(x,y,T=0.5)
- Save solution to "solution_agent_wave_19.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (Ny, Nx))
  * Metadata: T, dx, dy, dt
- Create heatmap plot "solution_agent_wave_19.png"
- Print diagnostics:
  * Minimum u value
  * Maximum u value
  * Discrete L2 norm
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution:
u(x,y,t) = cos(2*pi*x) * cos(2*pi*y) * cos(1.0 * 2*pi * sqrt(2) * t)
