Solve the 2D Laplace equation (∇²u = 0) on a [0,1] x [0,1] domain using the following specification:

Numerical Method:
Discretize the Laplace equation using a 5-point stencil on a uniform grid.
Use Nx = Ny = 100 intervals (101 x 101 grid points).
Grid spacing: dx = dy = 1/100.
Grid points: x_i = i*dx (i=0..100), y_j = j*dy (j=0..100).
Solve the resulting sparse linear system using a sparse direct solver (scipy.sparse.linalg.spsolve).

Output Requirements:
Compute the steady-state solution u(x,y) on the 2D grid.
Save solution data in "solution_agent_laplace_09.npz" with arrays:
- x (1D x-coordinates)
- y (1D y-coordinates)
- u (2D solution array, shape (101, 101), indexed as u[j,i] = u(x[i], y[j]))
- Metadata: dx, dy

Visualization:
Create a heatmap/contour plot of u(x,y) and save as "solution_agent_laplace_09.png".

Diagnostics:
Print the following scalar values:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
