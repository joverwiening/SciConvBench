Solve the 1D Reaction-Diffusion PDE with the following specification:

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) on the domain x in [0, 1) with periodic boundary conditions.

Numerical Method Details:
- Spatial grid: Uniform periodic grid with Nx=512 points on [0,1)
- Grid points: x_j = j*dx for j=0,...,511 with dx=1/512
- Time domain: t in [0, 1.0]
- Parameters: nu = 2.0, rho = 2.0

Numerical Solving Method (Strang Splitting):
- Diffusion half-step (dt/2): Solve exactly in Fourier space
  - Compute FFT of current solution
  - Apply exponential damping based on wavenumbers
  - Compute inverse FFT
- Reaction step (dt): Solve exact pointwise logistic ODE update
  - Update each grid point using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1))
- Second diffusion half-step (dt/2): Repeat first step

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu2_rho2.npz"
- Save line plot to "solution_pdebench_reacdiff_nu2_rho2.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
