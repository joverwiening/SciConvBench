Specification for 1D Advection PDE Numerical Solution:

Solve the 1D advection PDE u_t + beta * u_x = 0 with the following detailed requirements:

Numerical Method Configuration:
- Use a uniform spatial grid with Nx = 512 points
- Employ 1st-order upwind finite difference for spatial discretization
- Use explicit forward Euler for time integration
- Set beta = 2.0
- Apply periodic boundary conditions

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Time Stepping:
- Compute CFL = 0.5
- Calculate dt = CFL * dx / abs(beta)
- Adjust final dt to hit the exact final time T precisely
- Compute number of time steps as Nt = ceil(T/dt)

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_advection_beta2.npz" with arrays:
  * x (grid points)
  * u (solution at final time)
  * Scalar parameters: beta, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) as "solution_pdebench_advection_beta2.png"
- Print scalar diagnostics:
  * Minimum of u
  * Maximum of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print error metrics:
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution Verification:
- Reference solution: u(x,t) = u0((x - beta*t) mod 1)
- Use initial condition u0(x) for reference solution calculation

Coding Notes:
- Use radians for trigonometric functions
- Interpret '^' as exponentiation
- Use Python's '**' for power operations
