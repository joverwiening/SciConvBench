Solve the 2D Laplace equation numerically with the following specification:

Solve the Partial Differential Equation u_xx + u_yy = 0 on the domain [0,1] x [0,1].
Use a uniform grid with Nx = Ny = 100 intervals in each direction.
Discretize the Laplacian using the standard 5-point stencil (2nd-order accurate).
Solve the resulting sparse linear system using a sparse direct solver (scipy.sparse.linalg.spsolve).
Compute the steady-state solution u(x,y) on the 2D grid.
Create grid coordinates x_i = i*dx, y_j = j*dy where dx = dy = 1/Nx.
Reference solution is u(x,y) = sin(pi*x)*sinh(pi*y)/sinh(pi).
Save solution data in "solution_agent_laplace_01.npz" with arrays:
- x (1D x-coordinates)
- y (1D y-coordinates)
- u (2D solution array with u[j,i] = u(x[i], y[j]))
- Metadata scalars dx and dy
Generate a heatmap/contour plot of u(x,y) and save as "solution_agent_laplace_01.png".
Print the following diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm of u (sqrt(sum(u^2)*dx*dy))
- Maximum absolute error vs reference solution
