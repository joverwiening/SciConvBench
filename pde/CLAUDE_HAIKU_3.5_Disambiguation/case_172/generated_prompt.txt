Numerical Solution for 1D Reaction-Diffusion PDE (Logistic Reaction, Periodic)

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following specifications:

Parameters:
- Diffusion coefficient (nu) = 0.5
- Reaction rate (rho) = 1.0

Spatial Discretization:
- Grid points: Nx = 512
- Grid type: Uniform
- Boundary condition: Periodic

Temporal Discretization:
- Time step (dt) = 0.001
- Number of time steps (Nt) = 1000

Numerical Method:
- Use Strang splitting method with three stages:
  1. Half diffusion step in Fourier space
  2. Full reaction step using exact pointwise update
  3. Half diffusion step in Fourier space

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_reacdiff_nu0p5_rho1.npz"
- Create line plot "solution_pdebench_reacdiff_nu0p5_rho1.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
