Numerical Solution Specification for Wave Equation (Agent Wave 10):

Solve the 1D wave equation u_tt = (1.0)^2 * u_xx + sin(pi*x)*sin(2*pi*t) with the following precise requirements:

Spatial Domain: x ∈ [0,1]
Temporal Domain: t ∈ [0,1.0]
Grid: Nx = 400 intervals (Nx+1 = 401 points)
Spatial Discretization: Uniform grid with 2nd-order central differences for u_xx
Time Integration: 2nd-order central difference (leapfrog/Störmer–Verlet)
Wave Speed: c = 1.0

Initial Conditions:
u(x,0) = 0
u_t(x,0) = 0

Boundary Conditions:
Dirichlet at x=0 and x=1: u = 0

Time Step Calculation:
dx = 1/Nx
dt0 = 0.9*dx/c
Nt = ceil(1.0/dt0)
dt = 1.0/Nt

Output Requirements:
1. Compute u(x, T=1.0)
2. Save solution to "solution_agent_wave_10.npz"
3. Save plot of u(x,T) to "solution_agent_wave_10.png"
4. Print: min(u), max(u), discrete L2 norm sqrt(sum(u^2)*dx)

Coding Note: Use '^' for exponentiation, Python uses '**'
