Specification for Allen-Cahn PDE Numerical Solution:

Solve the Allen-Cahn PDE u_t = (0.02)^2*(u_xx + u_yy) + u - u^3 numerically with the following specifications:

Domain is a 2D square [0,1] x [0,1] with time interval [0,0.1].
Use a uniform grid with Nx = Ny = 300 grid points.
Use time step dt = 0.0001 (total 1000 time steps).
Implement 5-point Laplacian for spatial discretization.
Use semi-implicit time integration method.
Apply Dirichlet boundary conditions at each time step.

Initial condition: u(x,y,0) = tanh((0.25 - r)/(sqrt(2)*0.02)), where r = sqrt((x-0.5)^2 + (y-0.5)^2).

Computational requirements:
Compute final solution u(x,y,T=0.1) on the 2D grid.
Save solution to "solution_agent_allen_cahn_05.npz" with:
- x (1D array of x coordinates)
- y (1D array of y coordinates)
- u (2D array of solution values)
- Metadata: T, dx, dy, dt

Visualization requirements:
Create a heatmap/contour plot of u(x,y,T) and save as "solution_agent_allen_cahn_05.png".

Reporting requirements:
Print the following scalar diagnostics at T=0.1:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm (sqrt(sum(u^2)*dx*dy))

Use radians for trigonometric functions.
Interpret '^' as exponentiation (use '**' in Python implementation).
