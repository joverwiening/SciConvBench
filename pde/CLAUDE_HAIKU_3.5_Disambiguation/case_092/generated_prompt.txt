Solve the 2D wave equation numerically with the following specification:

Partial Differential Equation: u_tt = (1.0)^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t)
Spatial Domain: x, y in [0,1] x [0,1]
Temporal Domain: t in [0,1.0]

Numerical Method Details:
Spatial Grid: Uniform grid with Nx = Ny = 120 intervals
Grid Spacing: dx = dy = 1/Nx
Spatial Discretization: 5-point Laplacian for ∇²u
Time Integration: 2nd-order central difference in time
CFL Condition: CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9

Initial Conditions:
u(x,y,0) = 0
u_t(x,y,0) = 0

Boundary Conditions: Dirichlet (u = 0) on all boundaries

Time Step Calculation:
Compute dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2))
Compute Nt = ceil(T/dt0)
Set dt = T/Nt to hit final time exactly

Output Requirements:
1. Compute u(x,y,T=1.0) on the 2D grid
2. Save solution to "solution_agent_wave_11.npz" with:
   - x (1D array)
   - y (1D array)
   - u (2D array, shape (len(y), len(x)))
   - Metadata: T, dx, dy, dt
3. Save heatmap/contour plot as "solution_agent_wave_11.png"
4. Print:
   - Minimum value of u
   - Maximum value of u
   - Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
