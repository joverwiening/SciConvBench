Numerical Solution Specification for 2D Wave Equation (Task ID: agent_wave_15):

Solve the 2D wave equation u_tt = (1.0)^2 * (u_xx + u_yy) with the following specifications:

Computational Domain:
- Spatial domain: [0,1] x [0,1]
- Time domain: [0,0.5]
- Grid: Uniform grid with Nx = Ny = 160 intervals
- Grid points: (Nx+1) by (Ny+1) points
- Grid spacing: dx = dy = 1/Nx

Initial Conditions:
- u(x,y,0) = sin(pi*x) * sin(2*pi*y)
- u_t(x,y,0) = 0

Boundary Conditions:
- Dirichlet boundary conditions: u = 0 on all boundaries

Numerical Method:
- Spatial discretization: 5-point Laplacian on uniform grid
- Time integration: 2nd-order central difference in time
- Stability condition: CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9
- Time step calculation: 
  * dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2))
  * Nt = ceil(T/dt0)
  * dt = T/Nt to hit final time exactly

Output Requirements:
- Compute u(x,y,T=0.5) on the 2D grid
- Save "solution_agent_wave_15.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (len(y), len(x)))
  * Metadata: T, dx, dy, dt
- Save heatmap plot "solution_agent_wave_15.png"
- Print:
  * min(u)
  * max(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Compute and print:
  * Max absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution:
u(x,y,t) = cos(1.0*pi*sqrt(5)*t) * sin(pi*x) * sin(2*pi*y)
