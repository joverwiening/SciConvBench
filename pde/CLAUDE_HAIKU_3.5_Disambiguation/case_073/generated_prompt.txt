Specification for Solving the Euler-Bernoulli Beam Equation:

Implement a sine-series spectral method to solve the PDE u_tt + 0.01*u_xxxx = 0.

Numerical Method Details:
- Use spatial discretization with Discrete Sine Transform (DST-I)
- Grid parameters: Nx = 800, dx = 1/Nx
- Time parameters: dt = 1e-4, Nt = 10000, T = 1.0
- Boundary conditions: Simply-supported at x=0 and x=1
- Initial conditions: u(x,0) = sin(pi*x), u_t(x,0) = 0

Computational Steps:
- Apply DST-I to transform PDE to modal ODEs
- Solve per-mode updates using exact analytical solution
- Compute solution at T = 1.0

Output Requirements:
- Compute u(x, T=1.0) on the grid
- Save solution to "solution_agent_other_08_beam.npz"
- Include arrays: x, u, and metadata scalars T, dx, dt
- Create line plot "solution_agent_other_08_beam.png"
- Print diagnostics:
  - Minimum value of u
  - Maximum value of u
  - Discrete L2 norm of u
  - Maximum absolute error vs reference solution
  - L2 error vs reference solution

Use radians for trigonometric functions and '^' as exponentiation.
