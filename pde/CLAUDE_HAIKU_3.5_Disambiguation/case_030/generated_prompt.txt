Solve the 1D heat equation u_t = 0.1 * u_xx on the domain x ∈ [0, 1] and t ∈ [0, 0.5].
Use a uniform spatial grid with Nx = 200 intervals (201 points).
Discretize spatial derivatives using 2nd-order central differences.
Apply Crank-Nicolson time integration.
Use fixed time step dt = 0.001 (total 500 time steps).
Enforce Dirichlet boundary conditions at each time step.
Initial condition: u(x,0) = sin(π*x).
Compute and save the solution at final time T = 0.5.
Save solution data in "solution_agent_heat_01.npz" with arrays x, u, and metadata T, dx, dt.
Create a line plot of u(x,T) and save as "solution_agent_heat_01.png".
Print the following diagnostics at final time:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm of u
- Maximum absolute error vs exact solution
- L2 error vs exact solution
Use the exact solution u(x,t) = exp(-0.1*π^2*t) * sin(π*x) for error calculations.
