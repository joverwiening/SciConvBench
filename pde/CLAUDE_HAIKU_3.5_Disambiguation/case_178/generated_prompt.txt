Numerical Solution for 1D Reaction-Diffusion PDE (Task ID: pdebench_reacdiff_nu10_rho2)

Solve the 1D Reaction-Diffusion PDE with the following specifications:

PDE Equation: u_t = nu * u_xx + rho * u*(1 - u)

Domain Parameters:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 1.0]
- Spatial grid points: Nx = 512
- Time steps: Nt = 1000
- Grid spacing: dx = (1 - 0) / 512
- Time step: dt = 0.001

Parameters:
- nu = 10.0
- rho = 2.0

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical Method:
- Use Strang splitting method with three steps:
  (A) Diffusion half-step in Fourier space (dt/2)
  (B) Reaction full-step solved exactly
  (C) Diffusion half-step in Fourier space (dt/2)

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu10_rho2.npz"
- Save line plot to "solution_pdebench_reacdiff_nu10_rho2.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
