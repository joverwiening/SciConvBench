Numerical Solution for 1D Viscous Burgers Equation with Strang Splitting

Solve the 1D viscous Burgers equation with the following specifications:

PDE: u_t + ∂_x(0.5*u^2) = nu * u_xx
Viscosity parameter nu = 0.02
Spatial domain: Uniform grid with Nx = 512 points
Boundary conditions: Periodic
Initial condition: u(x,0) = sin(2*pi*x)

Numerical Method:
Use Strang splitting method with three substeps:
1. Diffusion half-step in Fourier space (duration dt/2)
2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
3. Diffusion half-step in Fourier space (duration dt/2)

Time-stepping:
- Use CFL = 0.4 with estimated max speed of 1.0
- Compute dt0 = CFL * dx / 1.0
- Determine Nt = ceil(T/dt0)
- Adjust final dt to hit exact final time T

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_burgers_nu0p02.npz"
- Create line plot "solution_pdebench_burgers_nu0p02.png"
- Print diagnostics: min(u), max(u), mean(u), L2 norm
