Numerical Solution Specification for 1D Reaction-Diffusion PDE (Task ID: pdebench_reacdiff_nu1_rho10):

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following exact specifications:

Parameters:
- Diffusion coefficient (nu) = 1.0
- Reaction rate (rho) = 10.0

Spatial Discretization:
- Use uniform grid with Nx = 512 points
- Periodic boundary conditions
- Grid point calculation: x_i = a + i*dx for i=0..Nx-1

Temporal Discretization:
- Use fixed time step dt = 0.001
- Total time steps Nt = 1000
- Solve using Strang splitting method with three stages:
  1. Half diffusion step in Fourier space
  2. Full reaction step using exact pointwise update
  3. Half diffusion step in Fourier space

Initial Condition:
- u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical Method Details:
- Use FFT for diffusion steps
- Exact pointwise update for reaction step
- Take real part after inverse FFT

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_reacdiff_nu1_rho10.npz"
- Include arrays: x, u, and scalars: nu, rho, T, dx, dt, Nx, Nt
- Create line plot "solution_pdebench_reacdiff_nu1_rho10.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
