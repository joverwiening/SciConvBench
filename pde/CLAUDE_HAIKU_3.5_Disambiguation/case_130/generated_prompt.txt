Solve the 1D nonlinear convection-diffusion PDE with the following specification:

Partial Differential Equation:
u_t = -q1*∂_x(sin(u)) + (q2/pi)*u_xx

Domain and Boundary Conditions:
Spatial domain is [0, 1) with periodic boundary conditions.
Time domain is [0, 0.5].

Parameters:
q1 = 1.0
q2 = 0.05

Initial Condition:
u(x,0) = 0.5*sin(2*pi*x)

Numerical Method Specifications:
Use a uniform periodic grid with Nx = 1024 points.
Grid points: x_j = j*dx for j=0,...,Nx-1, where dx = 1/Nx.

Spatial Discretization:
- Convection term: Use conservative finite-volume Rusanov flux.
- Flux wave speed: alpha = max|cos(u)|
- Diffusion term: 2nd-order central differences for u_xx

Time Integration:
- Method: SSP-RK2 (Strong Stability Preserving Runge-Kutta 2-stage)
- Time step calculation:
  * dt_adv = 0.2*dx/1
  * dt_diff = 0.2*dx^2/(q2/pi)
  * dt = min(dt_adv, dt_diff)
  * Nt = ceil(0.5/dt)
  * Final dt = 0.5/Nt

Computational Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in mathematical notation
- Use '**' for powers when implementing in Python
