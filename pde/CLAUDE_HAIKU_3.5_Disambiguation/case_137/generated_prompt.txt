Specification for 1D Advection PDE Numerical Solution (Task ID: pdebench_advection_beta0p4):

Solve the 1D advection PDE u_t + 0.4 * u_x = 0 with the following detailed requirements:

Spatial Domain:
- Use a uniform grid with Nx = 512 points
- Implement periodic boundary conditions
- Grid points follow the convention x_i = a + i*dx for i=0..Nx-1

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Numerical Method:
- Spatial discretization: 1st-order upwind finite difference for u_x
- Upwind direction determined by sign of beta (0.4)
- Time integration: Explicit forward Euler
- Time step calculation:
  * CFL = 0.5
  * dt = CFL * dx / abs(beta)
  * Nt = ceil(T/dt)
  * Adjust final dt to hit exact final time T

Output Requirements:
- Compute u at final time T on the grid
- Save solution to "solution_pdebench_advection_beta0p4.npz" with arrays:
  * x (1D, length Nx)
  * u (1D, length Nx)
  * Scalar values: beta, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) as "solution_pdebench_advection_beta0p4.png"
- Print diagnostics:
  * min(u)
  * max(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print error metrics vs reference solution:
  * Maximum absolute error
  * L2 error

Reference Solution:
- u(x,t) = u0((x - 0.4*t) mod 1), where u0 is the initial condition

Coding Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
