Solve the 1D inviscid conservation law PDE with the following specification:

Partial differential equation: u_t = -k*∂_x( cos(u) )
Spatial domain: x in [0, 1) with periodic boundary
Time domain: t in [0, 0.2]
Parameter k: 1.0

Spatial grid:
- Uniform periodic grid
- Number of grid points: Nx = 1024
- Grid points: x_j = j*dx for j=0,...,Nx-1
- Grid spacing: dx = 1/Nx

Numerical method:
- Spatial discretization: Conservative finite-volume Rusanov flux for f(u)=cos(u)
- Wave speed calculation: alpha = max|sin(u)|, bounded by 1
- Time integration: Strong Stability Preserving Runge-Kutta 2 (SSP-RK2)
- Time step calculation:
  * CFL number: 0.2
  * Initial time step: dt0 = CFL*dx/1.0
  * Number of time steps: Nt = ceil(T/dt0)
  * Final time step: dt = T/Nt

Initial condition: u(x,0) = 0.5*sin(2*pi*x)
Boundary condition: Periodic (u(0,t) = u(1,t) for all t)

Trigonometric functions use radians
Exponentiation uses '^' in math notation, '**' in Python implementation
