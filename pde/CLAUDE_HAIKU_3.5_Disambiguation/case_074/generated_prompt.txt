Solve the 2D Poisson equation with the following specification:

Solve the PDE u_xx + u_yy = f(x,y) where:
f(x,y) = -2*pi^2*sin(pi*x)*sin(pi*y)

Domain is the unit square [0,1] x [0,1].

Boundary conditions are Dirichlet with u = 0 on all four edges.

Numerical method details:
Use a uniform grid with Nx = Ny = 120 intervals.
Discretize using the standard 5-point stencil (2nd-order).
Solve the sparse linear system using a sparse direct solver (scipy.sparse.linalg.spsolve).

Output requirements:
Compute the steady-state solution u(x,y) on the 2D grid.
Save solution data in "solution_agent_poisson_01.npz" with arrays x, y, u, and metadata dx, dy.
Create a heatmap/contour plot as "solution_agent_poisson_01.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compute and print max absolute error and L2 error versus the reference solution u(x,y) = sin(pi*x)*sin(pi*y).
