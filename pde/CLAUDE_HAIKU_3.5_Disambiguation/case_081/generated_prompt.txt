Solve the 2D Poisson equation with the following specification:

Partial Differential Equation: u_xx + u_yy = sin(pi*x) + cos(2*pi*y)
Domain: (x,y) in [0,1] x [0,1]
Boundary Conditions: u = 0 on all boundary edges (Dirichlet)

Numerical Method:
Discretize ∇²u = f(x,y) on a uniform grid using the 5-point stencil (2nd-order)
Grid: Nx = Ny = 120 intervals
Grid Points: (Nx+1) by (Ny+1) including boundaries
Grid Spacing: dx = dy = 1/Nx
Grid Coordinates: x_i = i*dx (i=0..Nx), y_j = j*dy (j=0..Ny)

Linear Solver: Use sparse direct solver (scipy.sparse.linalg.spsolve)

Output Requirements:
Compute steady-state solution u(x,y) on 2D grid
Save solution to "solution_agent_poisson_08.npz" with:
- x (1D array)
- y (1D array)
- u (2D array, shape (len(y), len(x)))
- dx, dy as metadata scalars
Save heatmap/contour plot as "solution_agent_poisson_08.png"
Print diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
