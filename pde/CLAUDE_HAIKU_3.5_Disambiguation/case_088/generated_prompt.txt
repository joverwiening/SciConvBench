Numerical Solution Specification for 2D Wave Equation (Task ID: agent_wave_07):

Solve the 2D wave equation u_tt = (1.0)^2 * (u_xx + u_yy) with the following precise specifications:

Computational Domain:
- Spatial domain: [0,1] x [0,1]
- Time domain: [0,1.0]
- Grid: Uniform grid with Nx = Ny = 120 intervals
- Grid points: (Nx+1) by (Ny+1) points
- Grid spacing: dx = dy = 1/Nx

Numerical Method:
- Spatial discretization: 5-point Laplacian on uniform grid
- Time integration: 2nd-order central difference in time
- Stability condition: CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9
- Time step calculation: 
  * dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2))
  * Nt = ceil(T/dt0)
  * dt = T/Nt to hit final time exactly

Initial Conditions:
- u(x,y,0) = sin(π*x)*sin(π*y)
- u_t(x,y,0) = 0
- Use Taylor start for first time step

Boundary Conditions:
- Dirichlet: u = 0 on all boundaries
- Set boundary nodes to zero each time step

Output Requirements:
- Compute u(x,y,T=1.0) on the 2D grid
- Save "solution_agent_wave_07.npz" with:
  * x (1D array)
