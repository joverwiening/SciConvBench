Numerical Solution Specification for Klein-Gordon PDE (Task ID: agent_kg_04):

Solve the Klein-Gordon PDE u_tt - (1.0)^2*u_xx + (3.0)^2*u = 0 with the following specifications:

Spatial Domain: [0,1) periodic with Nx = 512 points
Temporal Domain: [0,0.8] 
Spatial Discretization: Uniform periodic grid with 2nd-order central differences for u_xx
Time Integration: Leapfrog method with mass term inclusion
Grid Parameters:
- dx = 1/Nx
- dt0 = 0.9*dx/c
- Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Initial Conditions:
- u(x,0) = cos(2*pi*x)
- u_t(x,0) = 0

Boundary Conditions: Periodic on x (u and u_x periodic)

Computational Requirements:
- Compute u(x, T=0.8) on the grid
- Save solution to "solution_agent_kg_04.npz"
- Include x, u arrays and metadata (T, dx, dt)
- Create line plot "solution_agent_kg_04.png"

Reporting Requirements:
- Print min(u)
- Print max(u)
- Print discrete L2 norm sqrt(sum(u^2)*dx)
- Compute and print max absolute error vs reference solution
- Compute and print L2 error vs reference solution

Reference Solution: u(x,t) = cos(2*pi*x)*cos(sqrt((1.0*2*pi)^2 + (3.0)^2)*t)

Note: Use radians for trigonometric functions. Interpret '^' as exponentiation.
