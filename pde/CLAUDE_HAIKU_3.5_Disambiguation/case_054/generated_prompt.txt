Solve the 1D Klein-Gordon equation u_tt - u_xx + u = sin(pi*x)*cos(2*t) numerically with the following specification:

Spatial Domain: x in [0,1]
Time Domain: t in [0,5.0]
Grid Parameters:
- Spatial grid points: Nx = 400
- Spatial discretization: Uniform grid with 2nd-order central differences for u_xx
- Time step: dt = 0.001 (5000 total steps)

Numerical Method:
- Spatial discretization: 2nd-order central differences for u_xx
- Time integration: Leapfrog method (2nd-order central difference in time)
- Explicit handling of +m^2*u term at time level n
- CFL condition: c*dt/dx ≤ 0.9

Parameters:
- c = 1.0
- m = 1.0

Initial Conditions:
- u(x,0) = 0
- u_t(x,0) = 0

Forcing Term:
- Include sin(pi*x)*cos(2*t) at time level n in leapfrog update

Output Requirements:
- Compute u(x, T=5.0)
- Save solution to "solution_agent_kg_07.npz" with arrays:
  * x (1D spatial grid)
  * u (1D solution at final time)
  * Metadata: T, dx, dt

  * Minimum value of u
