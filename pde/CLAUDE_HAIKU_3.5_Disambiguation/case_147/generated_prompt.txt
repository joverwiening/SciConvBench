Solve the 1D Viscous Burgers' Equation with the following specification:

Governing Equation:
u_t + ∂_x( 0.5*u^2 ) = nu * u_xx

Specific Parameters:
Viscosity (nu) = 0.2
Initial Condition: u(x,0) = sin(2*pi*x)
Boundary Conditions: Periodic (u(0,t) = u(1,t))

Numerical Method:
Use Strang splitting with three substeps:
1. Diffusion half-step in Fourier space (dt/2)
2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
3. Diffusion half-step in Fourier space (dt/2)

Spatial Discretization:
- Uniform grid with Nx = 512 points
- Grid spacing (dx) depends on domain extent
- Periodic domain indexing

Time Stepping:
- CFL = 0.4
- Initial time step dt0 = CFL*dx/1.0
- Total time steps Nt = ceil(T/dt0)
- Final dt adjusted to hit exact final time T

Output Requirements:
- Compute solution u(x,T)
- Save solution to "solution_pdebench_burgers_nu0p2.npz"
- Create plot "solution_pdebench_burgers_nu0p2.png"
- Print diagnostics: min(u), max(u), mean(u), L2 norm

Computational Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation
- Use '**' for powers in Python implementation
