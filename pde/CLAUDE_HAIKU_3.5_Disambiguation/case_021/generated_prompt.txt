Solve the 1D diffusion equation u_t = 0.1 * u_xx on the domain x ∈ [0,1] from t = 0 to t = 0.5.

Numerical Method Specifications:
Spatial Discretization:
- Use a uniform grid with Nx = 300 intervals
- Apply 2nd-order central differences for u_xx
- Implement Robin boundary conditions using 2nd-order one-sided differences
- At x=0: (-3*u0 + 4*u1 - u2)/(2*dx) + beta*u0 = 0
- At x=1: (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx) + beta*uN = 0

Time Integration:
- Use Crank-Nicolson method
- Time step dt = 0.001
- Total time steps = 500
- Solve resulting linear system using direct solver

Parameters:
- Diffusion coefficient D = 0.1
- Robin boundary condition coefficient beta = 1.0

Output Requirements:
- Compute u(x, T=0.5) on the grid
- Save solution to "solution_agent_diffusion_05.npz"
- Include arrays: x, u, and metadata scalars T, dx, dt
- Create line plot of u(x,T) as "solution_agent_diffusion_05.png"
- Print diagnostics: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx)
