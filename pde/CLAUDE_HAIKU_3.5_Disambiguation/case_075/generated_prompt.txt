Solve the 2D Poisson equation with the following specification:

Partial Differential Equation: ∇²u = f(x,y)
Domain: [0,1] x [0,1]
Grid: Uniform grid with Nx = Ny = 120 intervals
Grid Points: (Nx+1) x (Ny+1) grid points
Grid Spacing: dx = dy = 1/Nx
Grid Coordinates: x_i = i*dx, y_j = j*dy (i,j = 0..Nx/Ny)

Source Term: f(x,y) = 4π²sin(2πx)sin(πy) + 2π²sin(2πx)sin(πy)
Boundary Conditions: Dirichlet, u = 0 on all four edges

Numerical Method:
- Spatial Discretization: 5-point stencil (2nd-order)
- Linear Solver: Sparse direct solver (scipy.sparse.linalg.spsolve)

Reference Solution: u(x,y) = sin(2πx)sin(πy)

Output Requirements:
- Compute steady-state solution u(x,y)
- Save solution to "solution_agent_poisson_02.npz"
- Save contour plot to "solution_agent_poisson_02.png"
- Print diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm of u
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution
