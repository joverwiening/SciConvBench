Numerical Solution Specification for 1D Advection PDE (Task ID: agent_advection_01)

Solve the 1D linear advection equation u_t + u_x = 0 with the following detailed specifications:

Equation: u_t + (1.0)*u_x = 0
Domain: x in [0,1), t in [0,1.0]
Advection speed: a = 1.0

Initial Condition:
u(x,0) = sin(2*pi*x)

Numerical Method Details:
Use a uniform periodic grid with Nx = 800 points on [0,1)
Compute dx = 1/Nx
Calculate dt0 = 0.9*dx/|a|
Set Nt = ceil(1.0/dt0)
Adjust dt to ensure exact final time of T = 1.0

Discretization Specifications:
- Spatial derivative: 1st-order upwind scheme
- Time integration: Forward Euler method
- Boundary handling: Periodic boundary conditions

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_advection_01.npz"
- Include arrays: x, u, with metadata T, dx, dt
- Create plot "solution_agent_advection_01.png"
- Print diagnostics:
  1. Minimum value of u at T
  2. Maximum value of u at T
  3. Discrete L2 norm of u
  4. Maximum absolute error vs reference solution
  5. L2 error vs reference solution

Reference Solution:
u(x,t) = sin(2*pi*(x-(1.0)*t))
