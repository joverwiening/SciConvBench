Specification for Solving 1D Burgers' Equation Numerically:

Solve the 1D Burgers' equation u_t + u*u_x = 0.005*u_xx numerically with the following specifications:

Equation Details:
- PDE: u_t + u*u_x = 0.005*u_xx
- Domain: x in [0,1), t in [0,0.2]
- Viscosity (nu): 0.005

Numerical Method:
- Spatial Discretization: Conservative form using Rusanov flux
- Convection: Finite-volume method with Rusanov (local Lax-Friedrichs) flux
- Diffusion: 2nd-order central difference
- Time Integration: 1st-order IMEX (explicit convection, implicit diffusion)

Grid Parameters:
- Spatial Grid: Nx = 1200 points on [0,1)
- Spatial Step: dx = 1/Nx
- Time Step: dt = 5e-5
- Total Time Steps: Nt = 4000

Initial Condition:
- u(x,0) = 0.5 + sin(2*pi*x)

Boundary Handling:
- Apply consistent boundary indexing for periodic boundary conditions

Output Requirements:
- Compute u(x, T=0.2) on the specified grid
- Save solution to "solution_agent_burgers_02.npz"
- Include in .npz file: x array, u array, T, dx, dt
- Create line plot of u(x,T) as "solution_agent_burgers_02.png"
- Print diagnostics: min(u), max(u), discrete L2 norm

Computational Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math, '**' in Python code
- Solve sparse linear system each time step (e.g., scipy.sparse.linalg.spsolve)
