Solve the 2D Poisson equation with the following specification:

Partial Differential Equation: u_xx + u_yy = 100*exp(-200*((x-0.5)^2 + (y-0.5)^2))
Domain: (x,y) in [0,1] x [0,1]
Boundary Conditions: Dirichlet, u = 0 on all boundary edges

Numerical Method Details:
- Spatial Discretization: 5-point stencil (2nd-order)
- Grid: Uniform grid with Nx = Ny = 120 intervals
- Grid Points: Nx+1 by Ny+1 grid points (including boundaries)
- Grid Spacing: dx = dy = 1/Nx
- Grid Coordinates: x_i = i*dx (i=0..Nx), y_j = j*dy (j=0..Ny)

Linear Solver: Sparse direct solver (scipy.sparse.linalg.spsolve)

Output Requirements:
- Compute steady-state solution u(x,y)
- Save solution to "solution_agent_poisson_07.npz"
- Save contour plot to "solution_agent_poisson_07.png"
- Print diagnostics: min(u), max(u), discrete L2 norm sqrt(sum(u^2)*dx*dy)

Coding Note: Use '^' for exponentiation in math, use '**' in Python code
Trigonometric Functions: Use radians
