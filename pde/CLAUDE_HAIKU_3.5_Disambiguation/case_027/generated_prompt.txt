Specification for Diffusion-Reaction PDE Numerical Solution (Task ID: agent_diffusion_reaction_05):

Solve the 2D diffusion-reaction PDE u_t = 0.01*(u_xx + u_yy) + 2.0*u*(1 - u).
Use a uniform grid with Nx = Ny = 120 intervals on the domain [0,1] x [0,1].
Solve for time interval [0, 1.0] with time step dt = 0.001 (1000 total time steps).
Use IMEX numerical method with:
- Spatial discretization: 5-point Laplacian on uniform grid
- Time integration: Deterministic IMEX (1st order)
  - Diffusion term solved implicitly (backward Euler)
  - Reaction term solved explicitly (forward Euler)
  - Solve (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n)
- Boundary conditions: Zero Neumann via ghost node mirroring on all edges
- Parameters: D = 0.01, r = 2.0

Output requirements:
- Compute final solution u(x,y,T=1.0)
- Save solution to "solution_agent_diffusion_reaction_05.npz" with:
  - x (1D array)
  - y (1D array)
  - u (2D array, shape (len(y), len(x)))
  - Metadata: T, dx, dy, dt
- Create heatmap/contour plot "solution_agent_diffusion_reaction_05.png"

  - Minimum value of u
