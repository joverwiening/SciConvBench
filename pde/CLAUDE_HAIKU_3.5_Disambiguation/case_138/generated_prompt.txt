Numerical Solution Specification for 1D Advection PDE (Task ID: pdebench_advection_beta0p7):

Solve the 1D advection PDE u_t + 0.7 * u_x = 0 with the following detailed requirements:

Spatial Domain:
- Use a uniform grid with Nx = 512 points
- Periodic boundary conditions: u(0,t) = u(1,t)
- Grid points span [0, 1) with no duplicated endpoint

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Numerical Method:
- Spatial discretization: 1st-order upwind finite difference for u_x
- Upwind direction determined by sign of beta (0.7)
- Time integration: Explicit forward Euler
- CFL condition: dt = 0.5 * dx / abs(beta)
- Compute number of time steps Nt = ceil(T/dt)
- Adjust final dt to hit exact final time T

Output Requirements:
- Compute solution u(x,T)
- Save solution to "solution_pdebench_advection_beta0p7.npz"
- Include arrays: x, u, scalars: beta, T, dx, dt, Nx, Nt
- Create line plot "solution_pdebench_advection_beta0p7.png"
- Print diagnostics:
  * Minimum of u
  * Maximum of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print error vs reference solution:
  * Maximum absolute error
  * L2 error

Reference Solution:
u(x,t) = u0( (x - 0.7*t) mod 1 )
