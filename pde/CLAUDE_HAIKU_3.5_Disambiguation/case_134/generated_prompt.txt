Solve the 1D advection-diffusion PDE with space-dependent drift using the following specification:

Partial Differential Equation: u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u )
Domain: x in [0, 1) with periodic boundary, t in [0, 1.0]
Spatial Grid: Uniform periodic grid with Nx=512 points
Grid Points: x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx

Parameters:
D = 0.01
gamma = 1.0
U(x) = cos(2*pi*x)
U'(x) = -2*pi*sin(2*pi*x)

Boundary Conditions: Periodic (u(0,t) = u(1,t) for all t)
Initial Condition: u(x,0) = 1.0 + 0.2*sin(2*pi*x)

Numerical Method Details:
Drift Term: Treat in conservative form with flux F = (1/gamma)*U'(x)*u
Spatial Discretization: 
- Upwind finite-volume flux for ∂_x(F) based on interface velocity b=U'(x)/gamma
- 2nd-order central differences for u_xx
Time Integration: Explicit SSP-RK2
Time Step: 
- dt = min(0.4*dx/max|b|, 0.2*dx^2/D)
- Nt = ceil(T/dt)
- Final dt = T/Nt

Coding Note: Use '^' for exponentiation in math, use '**' for powers in Python implementation.
