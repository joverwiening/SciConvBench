Partial Differential Equation:

Domain:

Boundary Conditions:
Apply Dirichlet boundary conditions u(x,y) = cos(π*x)*cos(π*y) on all four edges

Numerical Method:

Apply 5-point stencil finite difference discretization (2nd-order)
Solve the resulting sparse linear system using scipy.sparse.linalg.spsolve
