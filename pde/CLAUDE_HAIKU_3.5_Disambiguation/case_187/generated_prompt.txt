Specification for 1D Reaction-Diffusion PDE Numerical Solution (Task ID: pdebench_reacdiff_nu2_rho5):

Solve the 1D Reaction-Diffusion PDE with the following specifications:

PDE: u_t = nu * u_xx + rho * u*(1 - u)

Domain Parameters:
- Spatial domain: x in [0, 1) with periodic boundary
- Time domain: t in [0, 1.0]
- Spatial grid: Nx = 512 points
- Parameters: nu = 2.0, rho = 5.0

Numerical Method:
- Spatial discretization: Uniform periodic grid
- Grid points: x_j = j*dx for j=0,...,511 with dx = 1/512
- Time integration: Strang splitting method
  - Diffusion half-step in Fourier space
  - Reaction step with exact pointwise update
  - Second diffusion half-step in Fourier space

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Boundary Conditions:
- Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu2_rho5.npz"
- Save plot to "solution_pdebench_reacdiff_nu2_rho5.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
