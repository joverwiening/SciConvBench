Solve the 2D Darcy flow PDE with the following specification:

Implement a numerical solution for the elliptic PDE -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (0,1) x (0,1).

Numerical Method Details:
Use a uniform Cartesian grid with N=128 intervals (N+1 points including boundaries).
Grid spacing: dx = dy = 1/N.
Grid points: x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.

Discretization:
Use 2nd-order finite differences with face-centered harmonic averaging.
For interior nodes, discretize using the specified stencil with harmonic mean face coefficients.
Compute face coefficients as a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).

Boundary Conditions:
Apply Dirichlet boundary conditions u = 0 on all boundaries of the domain.

Linear Solver:
Assemble sparse linear system Au=b for interior unknowns.
Solve using conjugate gradient (CG) method with:
- Tolerance: 1e-10 relative residual
- Optional: Use Jacobi preconditioner
