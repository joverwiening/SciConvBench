Solve the scalar ODE du/dt = a*sin(2*pi*t)*u numerically with the following specifications:

Differential Equation:
- ODE form: du/dt = 1.3 * sin(2*pi*t) * u
- Initial condition: u(0) = u0 (to be determined from exact solution)

Time Domain:
- Start time: 0.0
- End time: 5.0
- Time step: dt = 0.001
- Total steps: Nt = 5000

Numerical Method:
- Integration scheme: Classical 4th-order Runge-Kutta (RK4)
- Fixed step size integration
- Compute solution at all time points t_n = t0 + n*dt for n=0..Nt

Exact Solution:
- u(t) = u0 * exp( 1.3 * (1 - cos(2*pi*t)) / (2*pi) )
- u0 will be the initial value at t=0

Output Requirements:
- Compute u(t) at all time points
- Save solution data in "solution_molk_000.npz"
- Include arrays: t (1D, length Nt+1), u (1D, length Nt+1), parameters
- Create line plot "solution_molk_000.png" of u(t) vs t
- Print diagnostics:
  * u(T) at final time
  * Minimum u value
  * Maximum u value
- Compute and print error metrics:
  * Maximum absolute error
  * L2 error compared to exact solution
