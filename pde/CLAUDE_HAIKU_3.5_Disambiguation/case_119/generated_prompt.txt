Numerical Solution for 1D Linear Advection (Periodic) PDE

Specification Details:
Solve the 1D linear advection PDE u_t + q*u_x = 0 with the following precise requirements:

Spatial Domain:
- Domain is [0, 1) periodic
- Number of grid points: Nx = 512
- Grid spacing: dx = (1-0)/Nx
- Grid points: x_i = 0 + i*dx, for i = 0 to Nx-1

Temporal Domain:
- Time interval: [0, 1.0]
- Final time: T = 1.0

Parameters:
- Advection velocity: q = 1.5

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x)

Boundary Conditions:
- Periodic: u(0,t) = u(1,t) for all t

Numerical Solution Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_molk_018.npz" containing:
  * x (1D array, length 512)
  * u (1D array, length 512)
  * T (scalar)
  * dx (scalar)
  * Nx (scalar)
  * Parameter scalars

Output Requirements:
- Save line plot of u(x,T) as "solution_molk_018.png"
- Print scalar diagnostics:
  * Minimum of u
  * Maximum of u
  * Mean of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print max absolute error and L2 error vs reference solution

Coding Note:
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
- Use radians for trigonometric functions
