Helmholtz Equation Numerical Solution Specification:

Solve the Helmholtz equation u_xx + u_yy + k^2*u = f(x,y) with the following details:

Equation Parameters:
- Partial differential equation: u_xx + u_yy + k^2*u = f(x,y)
- k = 5.0
- f(x,y) = (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y)

Domain:
- x ∈ [0,1]
- y ∈ [0,1]

Grid Specifications:
- Use Nx = Ny = 120 intervals
- Grid points: (Nx+1) by (Ny+1)
- dx = dy = 1/Nx
- x_i = i*dx (i=0..Nx)
- y_j = j*dy (j=0..Ny)

Boundary Conditions:
- Dirichlet boundary conditions: u = 0 on all boundaries

Numerical Method:
- Spatial discretization: 5-point Laplacian
- Linear solver: Sparse direct solver (scipy.sparse.linalg.spsolve)

Reference Solution:
- u(x,y) = sin(pi*x) * sin(pi*y)

Output Requirements:
- Compute steady-state solution u(x,y)
- Save solution to "solution_agent_other_01_helmholtz.npz"
- Save plot as "solution_agent_other_01_helmholtz.png"
- Print:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm
  * Maximum absolute error
  * L2 error compared to reference solution
