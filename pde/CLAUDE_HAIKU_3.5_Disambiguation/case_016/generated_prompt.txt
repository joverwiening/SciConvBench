Specification for Solving Burgers' Equation (Task ID: agent_burgers_04):

Solve the 1D Burgers' equation u_t + u*u_x = 0.02*u_xx + sin(2*pi*x)*cos(2*pi*t) numerically with the following specifications:

Domain: x in [0,1), t in [0,1.0]
Viscosity (nu): 0.02

Numerical Method Details:
Spatial Discretization:
- Use conservative form discretization
- Convection: Rusanov (local Lax-Friedrichs) flux
- Diffusion: 2nd-order central difference

Time Integration:
- 1st-order IMEX method
- Treat convection explicitly
- Treat diffusion implicitly
- Solve resulting sparse linear system each time step

Grid Parameters:
- Nx = 1000 points
- dx = 1/Nx
- dt = 1e-4
- Nt = 10000 steps

Initial Condition:
- u(x,0) = 0

Boundary Handling:
- Apply consistent boundary indexing

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_burgers_04.npz"
- Include x, u arrays and metadata (T, dx, dt)
- Create line plot "solution_agent_burgers_04.png"
- Print diagnostics: min(u), max(u), discrete L2 norm
