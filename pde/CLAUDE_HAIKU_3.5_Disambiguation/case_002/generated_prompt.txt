Solve the 1D advection equation u_t + (-0.5)*u_x = 0 with the following specification:

Numerical Method:
Solve the PDE on domain x in [0,1) for t in [0,1.0].
Use a uniform periodic grid with Nx = 1000 points.
Compute dx = 1/Nx = 0.001.
Use 1st-order upwind spatial discretization with right-biased (downwind) stencil.
Use Forward Euler time integration.
Compute dt0 = 0.9*dx/|a| = 0.9*dx/0.5.
Set Nt = ceil(1.0/dt0) to ensure exact final time.
Set dt = 1.0/Nt.

Initial Condition:
u(x,0) = exp(-100*(x-0.3)^2)

Boundary Handling:
Apply periodic boundary conditions.

Output Requirements:
Compute u(x, T=1.0) on the grid.
Save solution to "solution_agent_advection_02.npz" with arrays x, u, and metadata T, dx, dt.
Save line plot of u(x,T) as "solution_agent_advection_02.png".
Print scalar diagnostics: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T.
