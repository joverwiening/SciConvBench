Specification for 1D Advection PDE Numerical Solution:

Solve the 1D advection PDE u_t + beta * u_x = 0 with the following detailed requirements:

Numerical Method Configuration:
- Use a uniform spatial grid with Nx = 512 points
- Employ 1st-order upwind finite difference for spatial discretization
- Use explicit forward Euler for time integration
- Set beta = 1.0
- Compute CFL = 0.5
- Calculate dt = CFL * dx / abs(beta)
- Adjust Nt = ceil(T/dt) and reset dt = T/Nt to hit final time exactly

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Boundary Conditions:
- Periodic boundary conditions: u(0,t) = u(1,t) for all t

Computational Requirements:
- Compute solution u(x,T) on the grid
- Save solution to "solution_pdebench_advection_beta1.npz" with arrays:
  * x (1D length Nx)
  * u (1D length Nx)
  * Scalar values: beta, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) and save as "solution_pdebench_advection_beta1.png"

Reporting Requirements:
- Print minimum value of u
- Print maximum value of u
- Print discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print max absolute error vs reference solution
- Compute and print L2 error vs reference solution

Reference Solution:
- u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition

Coding Notes:
- Use radians for trigonometric functions
- Interpret '^' as exponentiation
- Use '**' for powers in Python implementation
