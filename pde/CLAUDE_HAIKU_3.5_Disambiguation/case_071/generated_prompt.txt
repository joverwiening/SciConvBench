Numerical Solution Specification for Advection-Diffusion PDE (Task ID: agent_other_06_advection_diffusion)

Partial Differential Equation:
u_t + (1.0)*u_x + (0.5)*u_y = 0.01*(u_xx + u_yy)

Domain Specifications:
x in [0,1), y in [0,1), t in [0,0.5]
Grid: Uniform periodic grid with Nx = Ny = 400
Grid spacing: dx = dy = 1/Nx = 1/400
Time stepping: dt = 0.001, Nt = 500 steps

Numerical Method Details:
Spatial Discretization:
- Advection: 1st-order upwind differences
- Diffusion: 2nd-order central differences
- Periodic boundary conditions

Time Integration:
- IMEX (1st order)
- Advection: Explicit
- Diffusion: Implicit
- Solve sparse linear system with direct sparse solver

Initial Condition:
u(x,y,0) = sin(2*pi*x)*cos(2*pi*y)

Parameters:
- a = 1.0 (x-advection coefficient)
- b = 0.5 (y-advection coefficient)
- D = 0.01 (diffusion coefficient)

Output Requirements:
1. Compute u(x,y,T=0.5) on 2D grid
2. Save solution to "solution_agent_other_06_advection_diffusion.npz" with:
   - x (1D array)
   - y (1D array)
   - u (2D array, shape (Ny, Nx))
   - Metadata: T, dx, dy, dt
3. Generate heatmap/contour plot "solution_agent_other_06_advection_diffusion.png"
4. Print at T=0.5:
   - min(u)
   - max(u)
   - Discrete L2 norm
5. Compute and print:
   - Max absolute error vs reference solution
   - L2 error vs reference solution

Reference Solution:
u(x,y,t) = exp(-0.01*8*pi^2*t)*sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t))
