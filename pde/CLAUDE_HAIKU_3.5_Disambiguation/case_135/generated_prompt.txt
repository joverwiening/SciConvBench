Numerical Solution Specification for 1D Advection PDE (Task ID: pdebench_advection_beta0p1):

Solve the 1D advection PDE u_t + 0.1 * u_x = 0 with the following detailed requirements:

Spatial Domain:
- Use a uniform grid with Nx = 512 points
- Periodic boundary conditions: u(0,t) = u(1,t)

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Numerical Method:
- Spatial Discretization: 1st-order upwind finite difference for u_x
- Time Integration: Explicit forward Euler
- CFL Condition: 0.5
- Time Step Calculation: dt = CFL * dx / abs(beta)
- Adjust final time step to hit exact final time T

Computational Requirements:
- Compute solution at final time T
- Save solution to "solution_pdebench_advection_beta0p1.npz"
- Include arrays: x (1D, length Nx), u (1D, length Nx)
- Include scalars: beta, T, dx, dt, Nx, Nt

Reporting Requirements:
- Save line plot of u(x,T) as "solution_pdebench_advection_beta0p1.png"
- Print minimum and maximum of u at final time
- Print discrete L2 norm of u
- Compute and print max absolute error vs reference solution
- Compute and print L2 error vs reference solution

Reference Solution:
- u(x,t) = u0( (x - beta*t) mod 1 )
