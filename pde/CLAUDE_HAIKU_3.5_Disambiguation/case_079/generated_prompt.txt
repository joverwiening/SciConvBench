Solve the 2D Poisson equation with the following specification:

Partial Differential Equation: ∇²u = f(x,y), where f(x,y) = 18π²*sin(3πx)*cos(2πy)
Domain: [0,1] x [0,1]
Grid: Uniform grid with Nx = Ny = 120 intervals
Grid Points: (Nx+1) x (Ny+1) grid points
Grid Spacing: dx = dy = 1/120

Boundary Conditions: Dirichlet conditions using u(x,y) = sin(3πx)*cos(2πy) on all four edges

Numerical Method:
Discretize using 5-point stencil (2nd-order finite difference)
Solve sparse linear system using scipy.sparse.linalg.spsolve

Output Requirements:
Compute steady-state solution u(x,y)
Save solution to "solution_agent_poisson_06.npz"
Save contour plot to "solution_agent_poisson_06.png"
Print diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Note: Use radians for trigonometric functions. Interpret '^' as exponentiation.
