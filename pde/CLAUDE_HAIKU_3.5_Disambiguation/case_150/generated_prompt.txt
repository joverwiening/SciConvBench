Numerical Solution Specification for 1D Viscous Burgers Equation:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

PDE Details:
- Equation: u_t + ∂_x(0.5*u^2) = nu * u_xx
- Viscosity parameter nu = 0.001
- Spatial domain: Uniform grid with Nx = 512 points
- Boundary conditions: Periodic (u(0,t) = u(1,t))
- Initial condition: u(x,0) = sin(2*pi*x)

Numerical Method:
- Use Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space (duration dt/2)
  2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
  3. Diffusion half-step in Fourier space (duration dt/2)

Time Stepping:
- CFL = 0.4
- Initial time step dt0 = CFL * dx / 1.0
- Compute Nt = ceil(T/dt0)
- Adjust final dt to hit exact final time T

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_burgers_nu1em3.npz"
  - Arrays: x, u
  - Scalars: nu, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_burgers_nu1em3.png"
- Print diagnostics:
  - Minimum u value
  - Maximum u value
  - Discrete mean value
  - Discrete L2 norm
