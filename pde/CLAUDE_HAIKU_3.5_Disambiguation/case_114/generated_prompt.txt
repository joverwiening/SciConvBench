Numerical Solution Specification for 1D Porous Medium Equation (Task ID: molk_013)

Solve the 1D porous medium equation with the following specifications:

Partial Differential Equation: u_t = ∂_xx( u^2 )
Spatial Domain: x in [0, 1) with periodic boundary
Temporal Domain: t in [0, 0.2]
Nonlinear Exponent: m = 2.0

Initial Condition: u(x,0) = 0.5 + 0.2*cos(2*pi*x)
Boundary Condition: Periodic (u(0,t) = u(1,t) for all t)

Numerical Solution Requirements:
Compute u(x,T=0.2) on a periodic grid.
Save solution data in "solution_molk_013.npz" containing:
- x (1D grid points)
- u (1D solution array)
- T (final time)
- dx (grid spacing)
- Nx (number of grid points)
- Parameter scalars
