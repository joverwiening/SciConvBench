Solve the 2D advection PDE u_t + (-0.7)*u_x + (1.2)*u_y = 0 with the following specifications:

Computational Domain:
- x in [0,1), y in [0,1)
- Time interval [0, 0.5]
- Grid: 256x256 points (Nx = Ny = 256)
- Grid spacing: dx = dy = 1/256

Numerical Method:
- Spatial discretization: Upwind scheme
  - x-direction: Right-biased (since a = -0.7 < 0)
  - y-direction: Left-biased (since b = 1.2 > 0)
- Time integration: Forward Euler
- CFL condition: |a|*dt/dx + |b|*dt/dy ≤ 0.9
- Compute dt0 = 0.9 / (|a|/dx + |b|/dy)
- Compute Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Initial Condition:
u(x,y,0) = exp(-80*((x-0.2)^2 + (y-0.6)^2))

Output Requirements:
- Compute u(x,y,T) at T = 0.5
- Save solution to "solution_agent_advection_05.npz"
  - Include x (1D), y (1D), u (2D array)
  - Include metadata: T, dx, dy, dt
- Create heatmap plot "solution_agent_advection_05.png"
- Print diagnostics:
  - Minimum value of u
  - Maximum value of u
  - Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
