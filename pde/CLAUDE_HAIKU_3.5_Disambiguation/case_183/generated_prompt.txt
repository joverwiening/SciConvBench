Solve the 1D Reaction-Diffusion PDE with the following specification:

Partial Differential Equation: u_t = nu * u_xx + rho * u*(1 - u)
Parameters: nu = 1.0, rho = 5.0

Numerical Solution Method:
Implement Strang splitting method with the following steps:
1. Perform diffusion half-step in Fourier space (dt/2)
2. Perform reaction step for full time step dt using exact pointwise update
3. Perform second diffusion half-step in Fourier space (dt/2)

Grid Specifications:
- Spatial grid: Uniform grid with Nx = 512 points
- Time grid: Fixed dt = 0.001 with Nt = 1000 steps
- Boundary conditions: Periodic (u(0,t) = u(1,t) for all t)

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Computational Requirements:
- Compute solution u(x,T) at final time
- Save solution in "solution_pdebench_reacdiff_nu1_rho5.npz"
- Include arrays: x, u, and scalars: nu, rho, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) as "solution_pdebench_reacdiff_nu1_rho5.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
