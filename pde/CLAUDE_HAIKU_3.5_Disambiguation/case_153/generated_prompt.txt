Numerical Solution Specification for 1D Viscous Burgers Equation:

Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

PDE Details:
Equation: u_t + ∂_x(0.5*u^2) = nu * u_xx
Viscosity (nu): 4.0
Spatial Domain: Periodic domain [0,1]

Numerical Method:
Use Strang splitting method with three substeps:
1. Diffusion half-step in Fourier space (dt/2)
2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
3. Diffusion half-step in Fourier space (dt/2)

Discretization Parameters:
- Spatial Grid: Uniform grid with Nx = 512 points
- Time Stepping: CFL = 0.4, dt0 = CFL*dx/1.0
- Compute Nt = ceil(T/dt0), adjust dt to hit final time exactly

Initial Condition:
u(x,0) = sin(2*pi*x)

Boundary Conditions:
Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
- Compute solution at final time T
- Save solution to "solution_pdebench_burgers_nu4.npz"
- Create plot "solution_pdebench_burgers_nu4.png"
- Print diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete mean value of u
  * Discrete L2 norm

Implementation Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation, '**' in Python
- Perform FFT/IFFT for diffusion substeps
- Use periodic indexing for flux computations
