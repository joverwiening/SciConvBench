Specification for Solving 2D Diffusion PDE (agent_diffusion_04):

Numerical PDE Solution Requirements:
Solve the diffusion equation u_t = ∇·( D(x,y) ∇u ) with variable diffusion coefficient.

Domain and Parameters:
Solve on [0,1] x [0,1] spatial domain from t=0 to t=0.1.
Diffusion coefficient D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).

Numerical Method Specifications:
Use a uniform grid with Nx = Ny = 80 grid points.
Apply conservative 2nd-order spatial discretization in flux form.
Use arithmetic face averages for diffusion coefficient interpolation.
Employ implicit Euler time integration with dt = 0.0005 (200 total time steps).

Output Requirements:
Compute solution u(x,y) at final time T = 0.1.
Save solution data in "solution_agent_diffusion_04.npz" with:
- x (1D x-coordinates)
- y (1D y-coordinates)
- u (2D solution array, shape (len(y), len(x)))
- Metadata: T, dx, dy, dt

Generate visualization:
Create heatmap/contour plot "solution_agent_diffusion_04.png" of final solution.

Diagnostic Reporting:
Print at final time:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
