- Spatial domain: x in [0, 1) with periodic boundary
- Temporal domain: t in [0, 0.5]
- Grid: Uniform periodic grid with Nx grid points

Numerical Method Requirements:
- Solve second-order time-dependent PDE
- Handle periodic boundary conditions
- Compute solution at final time T = 0.5

Initial Conditions:
- u(x,0) = 0.1 * cos(2*pi*x)
- u_t(x,0) = 0

Parameters:
- q = 0.05
- c = 1.0

Output Requirements:
- Compute u(x,T=0.5) on periodic grid
- Save solution to "solution_molk_016.npz" with arrays:
  * x (1D grid points)

  * q and c parameters
