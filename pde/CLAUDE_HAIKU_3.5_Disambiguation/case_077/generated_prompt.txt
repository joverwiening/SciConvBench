Solve the 2D Poisson equation with the following specification:

Partial Differential Equation:
Solve u_xx + u_yy = f(x,y) where f(x,y) = pi^2 * exp(x) * sin(pi*y)

Domain:
Solve on the square [0,1] x [0,1]

Boundary Conditions:
Apply Dirichlet boundary conditions u(x,y) = exp(x)*sin(pi*y) on all four edges

Numerical Method:
Use a uniform grid with Nx = Ny = 120 intervals
Discretize using the standard 5-point stencil (2nd-order finite difference)
Solve the resulting sparse linear system using a sparse direct solver (scipy.sparse.linalg.spsolve)

Grid Details:
x_i = i*dx for i=0..Nx, where dx = 1/Nx
y_j = j*dy for j=0..Ny, where dy = 1/Ny

Output Requirements:
Compute the steady-state solution u(x,y) on the 2D grid
Save solution to "solution_agent_poisson_04.npz" with arrays x, y, u, and metadata dx, dy
Create a heatmap/contour plot of u(x,y) saved as "solution_agent_poisson_04.png"
Print the following diagnostics:
- Minimum value of u
- Maximum value of u
- Discrete L2 norm of u
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Exact Solution (for verification and error calculation):
u(x,y) = exp(x) * sin(pi*y)
