Solve the 2D Laplace equation (u_xx + u_yy = 0) on a [0,1] x [0,1] domain with the following specification:

Numerical Method:
Discretize the Laplace equation using the 5-point stencil on a uniform grid.
Use Nx = Ny = 100 intervals (101 x 101 grid points).
Grid spacing: dx = dy = 1/100.
Grid points: x_i = i*dx (i=0..100), y_j = j*dy (j=0..100).

Boundary Conditions:
Implicitly defined by the reference solution u(x,y) = x.

Solution Process:
Use a sparse direct solver (scipy.sparse.linalg.spsolve) to solve the resulting linear system.

Output Requirements:
Compute the steady-state solution u(x,y) on the 2D grid.
Save solution data in "solution_agent_laplace_03.npz" with:
- x (1D array of x coordinates)
- y (1D array of y coordinates)
- u (2D array where u[j,i] = u(x[i], y[j]))
- dx and dy as metadata scalars

Generate a heatmap/contour plot of u(x,y) and save as "solution_agent_laplace_03.png".

Diagnostic Outputs:
Print minimum value of u.
Print maximum value of u.
Print discrete L2 norm: sqrt(sum(u^2)*dx*dy).
Compute and print maximum absolute error vs reference solution.
Compute and print L2 error vs reference solution.
