Implement a numerical solver for the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following exact details:

Spatial Domain:
- Domain is [0, 1) with periodic boundary
- Use Nx points on the periodic grid
- Grid points: x_j = j*dx for j=0,...,Nx-1
- dx = 1.0/Nx

- Time interval [0, 1.0]
- Fixed time step dt such that Nt steps reach T=1.0 exactly

Parameters:
- nu = 10.0
- rho = 1.0

Initial Condition:
- u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical Method:
- Use Strang splitting with three steps:
  1. Diffusion half-step in Fourier space
  2. Reaction step solved exactly pointwise
  3. Diffusion half-step in Fourier space

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu10_rho1.npz"
- Include arrays: x, u, and scalars: nu, rho, T, dx, dt, Nx, Nt
- Create line plot "solution_pdebench_reacdiff_nu10_rho1.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
