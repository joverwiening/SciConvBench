Solve the 1D Viscous Burgers' Equation with the following specification:

Implement a numerical solver for the PDE u_t + ∂_x(0.5*u^2) = nu * u_xx with the following detailed requirements:

PDE and Physical Parameters:
- Equation: u_t + ∂_x(0.5*u^2) = nu * u_xx
- Viscosity parameter nu = 2.0
- Periodic boundary conditions: u(0,t) = u(1,t) for all t
- Initial condition: u(x,0) = sin(2*pi*x)

Numerical Method:
- Use Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space (duration dt/2)
  2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
  3. Diffusion half-step in Fourier space (duration dt/2)

Discretization Details:
- Spatial grid: Uniform grid with Nx = 512 points
- Time stepping: CFL = 0.4, dt0 = CFL*dx/1.0
- Compute Nt = ceil(T/dt0), then adjust dt to hit final time exactly

Output Requirements:
- Compute solution u(x,T)
- Save solution to "solution_pdebench_burgers_nu2.npz" with arrays:
  x, u, nu, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_burgers_nu2.png" of u(x,T)
- Print diagnostics:
  - Minimum value of u
  - Maximum value of u
  - Discrete mean value of u
  - Discrete L2 norm sqrt(sum(u^2)*dx)
