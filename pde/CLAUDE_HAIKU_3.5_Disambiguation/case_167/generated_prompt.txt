Specification for Task ID: pdebench_darcy_beta0p01 (2D Darcy Flow PDE Numerical Solution)

Numerical Solution Requirements:
Solve the 2D Darcy flow PDE: -∇ · ( a(x,y) ∇u(x,y) ) = 1
Domain: (x,y) in (0,1) x (0,1)
Boundary Conditions: Dirichlet u = 0 on entire boundary

Grid Specifications:
- Use uniform Cartesian grid with N = 128 intervals
- Grid points: (N+1) x (N+1) total points
- dx = dy = 1/N
- x_i = i*dx for i=0,...,N
- y_j = j*dy for j=0,...,N

Numerical Method:
- Discretization: 2nd-order finite differences with face-centered harmonic averaging
- Face coefficient calculation: Harmonic mean (e.g., a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)))
- Linear Solver: Conjugate Gradient (CG)
- Solver Tolerance: 1e-10 relative residual
- Optional: Use Jacobi preconditioner

Output Requirements:
- Compute u(x,y) on full (N+1) x (N+1) grid
- Save NumPy file: "solution_pdebench_darcy_beta0p01.npz"
  * Contains: x (1D), y (1D), u (2D, shape [N+1, N+1]), beta, N, dx
- Save plot: "solution_pdebench_darcy_beta0p01.png" (heatmap/contour of u)
- Print diagnostics: min(u), max(u), discrete residual norm
