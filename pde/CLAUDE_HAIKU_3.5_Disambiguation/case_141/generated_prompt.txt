Specification for 1D Advection PDE Numerical Solution:

Solve the 1D advection PDE u_t + 4.0 * u_x = 0 with the following detailed requirements.

Problem Setup:
Solve on a uniform periodic grid with Nx = 512 points.
Use beta = 4.0 as the advection speed.
Initial condition: u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)
Boundary condition: Periodic (u(0,t) = u(1,t))

Numerical Method:
Use 1st-order upwind finite difference for spatial discretization.
Use explicit forward Euler for time integration.
Compute time step using CFL = 0.5: dt = CFL * dx / abs(beta)
Adjust final time step to hit exact final time T precisely.

Output Requirements:
Compute solution at final time T.
Save solution to "solution_pdebench_advection_beta4.npz" with arrays:
- x (grid points, length Nx)
- u (solution at final time, length Nx)
- Scalar values: beta, T, dx, dt, Nx, Nt

Generate visualization:
Save line plot of u(x,T) as "solution_pdebench_advection_beta4.png"

Diagnostics to Print:
- Minimum value of u at final time
- Maximum value of u at final time
- Discrete L2 norm of u (sqrt(sum(u^2)*dx))
- Maximum absolute error vs reference solution
- L2 error vs reference solution

Reference Solution Computation:
u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition
