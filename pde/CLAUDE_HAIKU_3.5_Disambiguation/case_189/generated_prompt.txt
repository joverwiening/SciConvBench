Solve the 1D Reaction-Diffusion PDE with the following specification:

Implement a numerical solver for the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following precise requirements:

Spatial Domain:
- Domain is [0, 1) with periodic boundary conditions
- Use a uniform periodic grid
- Nx = 256 grid points (x_j = j*dx for j=0,...,Nx-1)
- dx = 1.0/Nx

Time Domain:
- Time interval [0, 1.0]
- Use fixed time step dt such that Nt = 1000 steps
- dt = 1.0/Nt

Parameters:
- nu = 5.0
- rho = 10.0

Numerical Method:
- Use Strang splitting method with three steps:
  1. Diffusion half-step in Fourier space (dt/2)
  2. Reaction full-step using exact pointwise update
  3. Diffusion half-step in Fourier space (dt/2)

Initial Condition:
- u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu5_rho10.npz"
- Save line plot of u(x,T) as "solution_pdebench_reacdiff_nu5_rho10.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm

Coding Notes:
- Use radians for trigonometric functions
- Use '^' for exponentiation in math, '**' in Python code
- Use real part after inverse FFT
