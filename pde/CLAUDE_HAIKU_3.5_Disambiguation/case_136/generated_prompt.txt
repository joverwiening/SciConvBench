Specification for 1D Advection PDE Numerical Solution (Task ID: pdebench_advection_beta0p2):

Solve the 1D advection PDE u_t + 0.2 * u_x = 0 with the following detailed requirements:

Spatial Domain:
- Use a uniform grid with Nx = 512 points
- Implement periodic boundary conditions
- Grid points follow the convention x_i = a + i*dx for i=0..Nx-1

Initial Condition:
- u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)

Numerical Method:
- Spatial Discretization: 1st-order upwind finite difference for u_x
- Time Integration: Explicit forward Euler
- CFL Condition: dt = 0.5 * dx / abs(beta)
- Compute number of time steps Nt = ceil(T/dt), then adjust dt = T/Nt

Reference Solution:
- Compute reference solution as u(x,t) = u0((x - 0.2*t) mod 1)

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_advection_beta0p2.npz" with arrays:
  * x (1D, length Nx)
  * u (1D, length Nx)
  * Scalars: beta, T, dx, dt, Nx, Nt
- Create line plot of u(x,T) as "solution_pdebench_advection_beta0p2.png"
- Print diagnostics:
  * Minimum of u
  * Maximum of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution
