Numerical Solution Specification for 2D Wave Equation:

Solve the 2D wave equation u_tt = (0.7)^2 * (u_xx + u_yy) with the following detailed requirements:

Spatial Domain: [0,1] x [0,1]
Time Domain: [0,0.8]
Wave Speed: c = 0.7

Grid Configuration:
- Use Nx = Ny = 140 intervals
- Grid points: (Nx+1) by (Ny+1)
- dx = dy = 1/Nx
- Uniform grid on [0,1] x [0,1]

Numerical Method:
- Spatial Discretization: 5-point Laplacian for ∇²u
- Time Integration: 2nd-order central difference in time
- Time Step Selection: CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9
- Compute dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2))
- Set Nt = ceil(T/dt0)
- Adjust dt to hit final time exactly

Initial Conditions:
- u(x,y,0) = sin(2*pi*x)*sin(pi*y)
- u_t(x,y,0) = 0
- Use Taylor start for first time step

Boundary Conditions:
- Dirichlet BC: u = 0 on all boundaries
- Set boundary nodes to zero each time step

Output Requirements:
- Compute u(x,y,T=0.8) on the 2D grid
- Save "solution_agent_wave_08.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (len(y), len(x)))
  * Metadata: T, dx, dy, dt
- Create heatmap/contour plot "solution_agent_wave_08.png"
- Print:
  * min(u)

  * Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Compute and print:
  * Max absolute error vs reference solution
