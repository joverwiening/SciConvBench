Numerical Solution Specification for 1D Viscous Burgers Equation:

Solve the PDE u_t + ∂_x(0.5*u^2) = nu * u_xx with the following specifications:

PDE Parameters:
- Viscosity nu = 1.0
- Spatial domain: Uniform grid with Nx = 512 points
- Boundary Condition: Periodic (u(0,t) = u(1,t))
- Initial Condition: u(x,0) = sin(2*pi*x)

Numerical Method:
- Use Strang splitting method with three substeps:
  1. Diffusion half-step in Fourier space (dt/2)
  2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
  3. Diffusion half-step in Fourier space (dt/2)

Time Stepping:
- CFL = 0.4
- dt0 = CFL * dx / 1.0
- Nt = ceil(T/dt0)
- Adjust final dt to hit exact final time T

Output Requirements:
- Compute u(x,T) on the grid
- Save solution to "solution_pdebench_burgers_nu1.npz"
- Include arrays: x, u, and scalars: nu, T, dx, dt, Nx, Nt
- Create plot "solution_pdebench_burgers_nu1.png"
- Print diagnostics: min(u), max(u), mean(u), L2 norm

Coding Notes:
- Use '^' for exponentiation in math
- Use '**' for powers in Python implementation
- Treat all trigonometric functions in radians
