Numerical Solution Specification for Advection PDE (Task ID: agent_advection_04):

Solve the 2D advection PDE u_t + (1.0)*u_x + (0.5)*u_y = 0 with the following detailed requirements:

Computational Domain:
- Spatial domain: [0,1) x [0,1)
- Time domain: [0,1.0]
- Grid: Uniform periodic grid with Nx = Ny = 256 points
- Grid spacing: dx = dy = 1/Nx = 1/256

Numerical Method:
- Spatial discretization: 1st-order upwind scheme in both x and y directions
- Time integration: Forward Euler method
- CFL condition: |a|*dt/dx + |b|*dt/dy ≤ 0.9
- Time step calculation: 
  * dt0 = 0.9 / (|a|/dx + |b|/dy)
  * Nt = ceil(T/dt0)
  * dt = T/Nt to ensure exact final time

Initial Condition:
u(x,y,0) = sin(2*pi*x)*cos(2*pi*y)

Parameters:
- a = 1.0
- b = 0.5
- Final time T = 1.0

Output Requirements:
- Compute u(x,y,T=1.0) on the 2D grid
- Save solution to "solution_agent_advection_04.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (len(y), len(x)))
  * Metadata: T, dx, dy, dt
- Generate heatmap/contour plot "solution_agent_advection_04.png"
- Print diagnostics:
  * min(u)
  * max(u)
  * Discrete L2 norm: sqrt(sum(u^2)*dx*dy)
- Compute and print error metrics:
  * Max absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution:
u(x,y,t) = sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t))

- Use '**' for powers in Python implementation
