Numerical Solution Specification for 1D Reaction-Diffusion PDE:

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) with the following exact specifications:

Parameters:
- Diffusion coefficient (nu) = 1.0
- Reaction rate (rho) = 2.0

Spatial Discretization:
- Use uniform grid with Nx = 512 points
- Periodic boundary conditions
- Grid points span domain [0, 1]
- Compute dx = (1-0)/Nx = 1/512

Temporal Discretization:
- Fixed time step dt = 0.001
- Total time steps Nt = 1000
- Final time T = dt * Nt = 1.0

Initial Condition:
- u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Numerical Method:
- Use Strang splitting method with three stages:
  1. Half diffusion step in Fourier space (dt/2)
  2. Full reaction step using exact pointwise ODE solution
  3. Half diffusion step in Fourier space (dt/2)

Output Requirements:
- Compute final solution u(x,T)
- Save solution to "solution_pdebench_reacdiff_nu1_rho2.npz"
- Save line plot of u(x,T) to "solution_pdebench_reacdiff_nu1_rho2.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm
