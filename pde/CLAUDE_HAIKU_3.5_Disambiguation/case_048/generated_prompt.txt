Solve the 1D Klein-Gordon PDE numerically with the following specification:

Partial Differential Equation: u_tt - (1.0)^2*u_xx + (1.0)^2*u = 0
Spatial Domain: x ∈ [0,1]
Temporal Domain: t ∈ [0,1.0]
Number of Spatial Intervals: Nx = 400
Spatial Grid Points: Nx+1 = 401 points
Spatial Step Size: dx = 1/Nx
Time Step Calculation: 
- Initial dt0 = 0.9*dx/c
- Nt = ceil(T/dt0)
- Final dt = T/Nt to hit exactly T=1.0

Boundary Conditions:
- Dirichlet at x=0 and x=1: u = 0

Initial Conditions:
- u(x,0) = sin(π*x)
- u_t(x,0) = 0

Numerical Method:
- Spatial Discretization: Uniform grid with 2nd-order central differences for u_xx
- Time Integration: 2nd-order central difference (leapfrog)
- Explicit handling of +m^2*u term at time level n
- Taylor series initialization including -m^2*u0

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_kg_01.npz"
- Save line plot of u(x,T) to "solution_agent_kg_01.png"
- Print:
  * min(u)
  * max(u)
  * Discrete L2 norm
  * Max absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = cos(sqrt((1.0*π)^2 + (1.0)^2)*t)*sin(π*x)
