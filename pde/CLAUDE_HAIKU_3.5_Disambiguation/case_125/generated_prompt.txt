Solve the 1D convection-diffusion PDE (Burgers equation with diffusion) with the following specifications:

Partial Differential Equation: u_t = -q1*∂_x(0.5*u^2) + (q2/pi)*u_xx

Simulation Domain:
x in [0, 1) with periodic boundary
t in [0, 0.5]

Parameters:
q1 = 1.0
q2 = 0.1

Spatial Discretization:
Use a uniform periodic grid with Nx = 512 points
Grid points: x_j = j*dx for j=0,...,Nx-1
Grid spacing: dx = 1/Nx

Numerical Method:
Use Rusanov (local Lax-Friedrichs) flux for nonlinear convection term
Use 2nd-order central differences for diffusion term
Use SSP-RK2 (Heun) time integration

Time Step Calculation:
Compute effective diffusion coefficient D_eff = q2/pi
Calculate dt_conv = 0.4 * dx / max|u0| with max|u0| = 1
Calculate dt_diff = 0.4 * dx^2 / D_eff
Set dt0 = min(dt_conv, dt_diff)
Compute Nt = ceil(0.5/dt0)
Set final dt = 0.5/Nt to hit exactly t = 0.5

Initial Condition:
u(x,0) = sin(2*pi*x)

Boundary Condition:
Periodic: u(0,t) = u(1,t) for all t

Use '^' for exponentiation in math
Use '**' for powers in Python implementation
