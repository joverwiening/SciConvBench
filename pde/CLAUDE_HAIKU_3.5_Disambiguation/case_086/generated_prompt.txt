Specification for Wave Equation Numerical Solution (Task ID: agent_wave_05):

Solve the 1D wave equation u_tt = c^2 * u_xx with the following detailed specifications:

PDE: u_tt = (1.0)^2 * u_xx
Domain: x in [0,1) periodic, t in [0,1.0]
Wave speed (c): 1.0

Numerical Method Details:
Spatial Discretization: 
- Use uniform periodic grid with Nx = 512 points
- 2nd-order central difference with periodic wrap-around for u_xx
- dx = 1/Nx

Time Integration:
- 2nd-order central difference in time for u_tt
- CFL condition: c*dt/dx ≤ 0.9
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(1.0/dt0)
- Adjust dt to ensure exact final time of T=1.0

Initialization:
- Use Taylor start with periodic Laplacian

Output Requirements:
- Compute u(x, T=1.0) on the grid
- Save solution to "solution_agent_wave_05.npz" with arrays:
  * x (1D grid points)
  * u (1D solution at T=1.0)
  * Metadata: T, dx, dt
- Create line plot of u(x,T) as "solution_agent_wave_05.png"
- Print diagnostics:
  * Minimum of u
  * Maximum of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
- Compute and print error metrics:
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = cos(2*pi*x)*cos(2*pi*1.0*t)
