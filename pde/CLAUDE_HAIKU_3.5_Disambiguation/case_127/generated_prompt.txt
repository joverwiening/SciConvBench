Solve the 1D linear advection-diffusion PDE with the following specifications:

Partial differential equation: u_t = -q1*∂_x(u) + (q2/pi)*u_xx
Domain: x in [0, 1) with periodic boundary, t in [0, 0.5]
Parameters: q1 = 1.0, q2 = 0.05

Spatial grid:
- Use uniform periodic grid with Nx = 512 points
- Grid points: x_j = j*dx for j=0,...,Nx-1
- Grid spacing: dx = 1/Nx

Numerical discretization:
- Spatial derivative for ∂_x(u): 1st-order upwind scheme
- Spatial derivative for u_xx: 2nd-order central differences
- Time integration: IMEX Euler (diffusion implicit, advection explicit)
- Time step calculation: dt = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi))
- Number of time steps: Nt = ceil(T/dt), with final dt = T/Nt

Initial condition: u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)
Boundary condition: Periodic (u(0,t) = u(1,t) for all t)

Coding note: Use '^' for exponentiation in math, use '**' for powers in Python implementation.
