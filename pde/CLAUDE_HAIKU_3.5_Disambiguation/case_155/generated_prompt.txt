Numerical Solution Specification for 1D Compressible Navier-Stokes PDE:

Solve the 1D Compressible Navier-Stokes PDE with the following specifications:

Domain is x in [-1, 1] with periodic boundary conditions.
Simulation time is t in [0, 0.5].

Numerical Method Details:
Use a uniform finite-volume grid with Nx=100 cells.
Evolve conservative variables U = [rho, m, E] as cell averages.
Use Rusanov numerical flux for convective terms.
Compute viscous terms with centered differences.
Apply 2-stage SSP-RK2 (Heun's method) for time integration.

Parameters:
Gamma = 1.6666666666666667
eta = 0.01
zeta = 0.01

Initial Conditions:
rho(x,0) = 1.0 + 0.2*sin(pi*x)
v(x,0) = 0.1*cos(pi*x)
p(x,0) = 1.0 + 0.2*cos(pi*x)

Time Step Calculation:
Compute dt as minimum of convective and viscous time steps.
Use CFL = 0.5 for time step restriction.

Output Requirements:
Compute final state rho(x,T), v(x,T), p(x,T) at T=0.5.
Save solution to "solution_pdebench_cns1d_eta0p01_periodic_smooth.npz".
Create line plot "solution_pdebench_cns1d_eta0p01_periodic_smooth.png".
Print min/max of rho and p, and mean of rho.

Equation of State:
p = (Gamma-1) * (E - 0.5*m^2/rho)
Enforce positivity by clipping rho and p to 1e-12 if needed.

Numerical Flux Calculation:
Use Rusanov (local Lax-Friedrichs) flux with interface wave speed.
Add viscous flux contributions to total interface flux.

Boundary Conditions:
Implement periodic boundary conditions by wrapping indices.
