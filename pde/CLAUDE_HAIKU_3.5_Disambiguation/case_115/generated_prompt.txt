Numerical Solution Specification for 1D Linear Wave / Klein-Gordon PDE (Task ID: molk_014)

Solve the PDE u_tt + (0.5^2)*(1.0^4)*u = (1.0^2)*u_xx numerically with the following specifications:

Domain is periodic x ∈ [0, 1) with time t ∈ [0, 1.0].
Use periodic boundary conditions: u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t) for all t.
Initial conditions: 
- u(x,0) = sin(2*pi*x)
- u_t(x,0) = 0

Numerical Solution Requirements:
- Use a numerical method that preserves periodic boundary conditions.
- Compute solution at final time T = 1.0.
- Use parameters q1 = 1.0 and q2 = 0.5.

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid.
- Save solution in "solution_molk_014.npz" with arrays:
  * x (1D grid points)
  * u (1D solution at T=1.0)
  * Scalar values: T, dx, Nx, q1, q2
- Create line plot of u(x,T) saved as "solution_molk_014.png".
- Print scalar diagnostics:
  * Minimum of u
  * Maximum of u
  * Mean of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)

Coding Notes:
- Use radians for trigonometric functions.
- Interpret '^' as exponentiation.
- Use Python's '**' for powers.
- Grid convention: Nx points with no duplicated endpoint.

Verification:
- Exact solution: u(x,t) = cos(omega*t) * sin(2*pi*x)
- omega = sqrt(q2^2*q1^4 + q1^2*(2*pi)^2) = 6.303048278758258
