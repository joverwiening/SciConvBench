Numerical Solution Specification for 1D Compressible Navier-Stokes Shock Problem:

Solve the 1D Compressible Navier-Stokes equations on the domain x ∈ [-1, 1] from t = 0 to t = 0.2.

Governing Equations:
- Solve conservation equations for rho, m, and E in conservative form.
- Use equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
- Enforce positivity by clipping rho and p to 1e-12 if needed.

Numerical Method:
- Use uniform finite-volume grid with Nx cells.
- Evolve conservative variables U = [rho, m, E] as cell averages.
- Apply Rusanov (local Lax-Friedrichs) numerical flux for inviscid terms.
- Compute viscous stress sigma with centered differences.
- Use 2-stage SSP-RK2 (Heun's method) for time integration.
- Compute time step dt as minimum of convective and viscous CFL constraints.
- Implement zero-gradient (transmissive) boundary conditions.

Initial Conditions:
- Riemann shock-tube problem with discontinuity at x = 0
- Left state (x < 0): rho = 1.0, v = 0.0, p = 1.0
- Right state (x ≥ 0): rho = 0.1, v = 0.0, p = 0.01

- Gamma = 1.6666666666666667
- eta = 1e-08
- zeta = 1e-08
