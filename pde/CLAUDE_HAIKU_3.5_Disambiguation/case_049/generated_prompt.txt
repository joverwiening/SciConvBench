Solve the 1D Klein-Gordon PDE numerically with the following specification:

Partial Differential Equation: u_tt - (0.5)^2*u_xx + (2.0)^2*u = 0
Spatial Domain: x ∈ [0,1]
Temporal Domain: t ∈ [0,1.0]
Number of Spatial Intervals: Nx = 600
Grid Points: Nx+1 = 601 points
Spatial Step: dx = 1/Nx
Time Step: Compute dt0 = 0.9*dx/c, then set Nt = ceil(1.0/dt0), and dt = 1.0/Nt

Boundary Conditions:
Dirichlet at x=0 and x=1: u = 0

Initial Conditions:
u(x,0) = sin(2*pi*x)
u_t(x,0) = 0

Numerical Method:
- Spatial Discretization: 2nd-order central differences for u_xx
- Time Integration: 2nd-order central difference (leapfrog)
- Explicit handling of +m^2*u term at time level n

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_kg_02.npz"
- Save plot of u(x,T) to "solution_agent_kg_02.png"
- Print:
  * min(u)
  * max(u)
  * Discrete L2 norm
  * Max absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = cos(sqrt((0.5*2*pi)^2 + (2.0)^2)*t)*sin(2*pi*x)
