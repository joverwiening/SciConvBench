Specification for Wave Equation Numerical Solution (Task ID: agent_wave_02):

Solve the 1D wave equation u_tt = (0.5)^2 * u_xx with the following detailed requirements:

Equation: u_tt = (0.5)^2 * u_xx
Domain: x in [0,1], t in [0,1.0]
Wave speed (c): 0.5

Spatial Discretization:
- Use uniform grid with Nx = 400 intervals (Nx+1 points)
- dx = 1/Nx
- Use 2nd-order central differences for u_xx in the interior

Time Integration:
- Use 2nd-order central difference (leapfrog/Störmer–Verlet)
- Compute dt0 = 0.9*dx/c
- Set Nt = ceil(1.0/dt0)
- Adjust dt to ensure exact final time at T=1.0

Initial Conditions:
- u(x,0) = sin(2*pi*x)
- Compute u(x,dt) using Taylor start method

Boundary Conditions:
- Dirichlet at x=0 and x=1
- u(0,t) = 0
- u(1,t) = 0

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_wave_02.npz"
- Include arrays: x, u, with metadata T, dx, dt
- Create plot "solution_agent_wave_02.png" of u(x,T)
- Print diagnostics:
  * min(u)
  * max(u)
  * Discrete L2 norm
  * Max absolute error vs reference solution
  * L2 error vs reference solution

Reference Solution: u(x,t) = cos(0.5*2*pi*t)*sin(2*pi*x)
