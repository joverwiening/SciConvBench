Spatial Domain: x in [0,1]
Time Domain: t in [0,0.7]
Number of Spatial Intervals: Nx = 600
Spatial Grid: Uniform grid with dx = 1/Nx

- u(x,0) = sin(3*pi*x)

Parameters:
- c = 1.2 (wave speed)

Numerical Method Details:
- Use 2nd-order central differences for spatial second derivative
- Handle m^2*u term explicitly at time level n
- Use Taylor expansion for initialization
