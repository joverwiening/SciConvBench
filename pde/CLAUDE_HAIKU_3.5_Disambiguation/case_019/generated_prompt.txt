Specification for Diffusion PDE Numerical Solution (Task ID: agent_diffusion_03):

Solve the 2D diffusion PDE u_t = 0.1 * u_xx + 0.01 * u_yy numerically with the following specifications:

Domain Setup:
- Spatial domain: [0,1] x [0,1]
- Time domain: [0, 0.2]
- Grid: Uniform grid with Nx = Ny = 60
- Spatial step sizes: dx = dy = 1/60

Numerical Method:
- Spatial discretization: 5-point Laplacian with scaled derivatives
- Time integration method: Implicit Euler
- Time step: dt = 0.001 (200 total time steps)
- Diffusion coefficients: Dx = 0.1, Dy = 0.01

Initial Condition:
- u(x,y,0) = sin(pi*x) * sin(pi*y)

Reference Solution:
- u(x,y,t) = exp(-(0.1+0.01)*pi^2*t) * sin(pi*x) * sin(pi*y)

Output Requirements:
- Compute final solution u(x,y,T=0.2)
- Save solution to "solution_agent_diffusion_03.npz" with:
  * x (1D array)
  * y (1D array)
  * u (2D array, shape (Ny, Nx))
  * Metadata: T, dx, dy, dt
- Create heatmap/contour plot "solution_agent_diffusion_03.png"
- Print diagnostics:
  * Minimum value of u at T
  * Maximum value of u at T
  * Discrete L2 norm of u
  * Maximum absolute error vs reference solution
  * L2 error vs reference solution

Coding Notes:
