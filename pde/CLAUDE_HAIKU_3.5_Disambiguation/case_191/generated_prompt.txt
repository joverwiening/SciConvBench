Solve the 1D Reaction-Diffusion PDE with the following specification:

Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) on the domain x in [0, 1) with periodic boundary conditions.

Numerical Method Details:
- Spatial grid: 512 uniform periodic points on [0,1)
- Spatial grid spacing: dx = 1/512
- Time grid: Fixed dt = 0.001
- Total time steps: Nt = 1000 to reach T = 1.0 exactly
- Numerical method: Strang splitting with:
  (A) Diffusion half-step in Fourier space
  (B) Reaction step solved exactly for logistic ODE
  (C) Diffusion half-step in Fourier space

Parameters:
- nu = 5.0
- rho = 5.0

Initial Condition:
u(x,0) = 0.25 + 0.1*sin(2*pi*x)

Boundary Conditions:
Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
- Compute u(x,T=1.0) on the periodic grid
- Save solution to "solution_pdebench_reacdiff_nu5_rho5.npz"
- Save plot to "solution_pdebench_reacdiff_nu5_rho5.png"
- Print diagnostics: min(u), max(u), mean(u), discrete L2 norm

Coding Notes:
- Use radians for trigonometric functions
- Use '^' or '**' for exponentiation
- Interpret grid points as x_j = j*dx for j=0,...,Nx-1
