Specification for Wave Equation Numerical Solution (Task ID: agent_wave_01):

Solve the 1D wave equation u_tt = c^2 * u_xx numerically with the following specifications:

Equation: u_tt = (1.0)^2 * u_xx
Domain: x in [0,1], t in [0,1.0]
Wave speed (c): 1.0

Spatial Discretization:
- Use uniform grid on [0,1]
- Number of intervals: Nx = 400
- Total grid points: Nx+1 = 401
- Compute dx = 1/Nx
- Use 2nd-order central differences for u_xx in the interior

Time Integration:
- Use 2nd-order central difference (leapfrog/Störmer–Verlet)
- Compute dt0 = 0.9 * dx / c
- Set Nt = ceil(1.0 / dt0)
- Adjust dt to ensure exact final time of T = 1.0

Initial Conditions:
- u(x,0) = sin(π*x)
- Compute u(x,dt) using Taylor start method

Boundary Conditions:
- Dirichlet at x=0 and x=1
- u(0,t) = 0
- u(1,t) = 0
- Enforce boundary conditions at every time step

Output Requirements:
- Compute u(x, T=1.0)
- Save solution to "solution_agent_wave_01.npz"
  - Include arrays: x, u
  - Include metadata: T, dx, dt
- Create plot "solution_agent_wave_01.png" of u(x,T)
- Print diagnostics:
  - Minimum value of u
  - Maximum value of u
  - Discrete L2 norm of u
- Compute and print:
  - Maximum absolute error vs reference solution
  - L2 error vs reference solution

Reference Solution: u(x,t) = cos(1.0*π*t) * sin(π*x)

Coding Note: Use '^' for exponentiation, translate to '**' in Python implementation.
