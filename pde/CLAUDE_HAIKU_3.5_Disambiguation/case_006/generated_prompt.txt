Numerical Solution Specification for Advection PDE (Task ID: agent_advection_06):

Solve the 1D advection PDE u_t + (2.0)*u_x = 0 with the following detailed requirements:

Computational Domain:
- Spatial domain: x in [0,1), periodic boundary
- Temporal domain: t in [0,0.3]
- Grid points: Nx = 2000
- Grid spacing: dx = 1/Nx
- Time step: dt0 = 0.9*dx/|a|, Nt = ceil(0.3/dt0), dt = 0.3/Nt

Initial Condition:
- u(x,0) = 1 if 0.2 ≤ x < 0.4
- u(x,0) = 0 otherwise

Numerical Method:
- Spatial discretization: 1st-order upwind scheme
- Time integration: Forward Euler
- Advection velocity: a = 2.0

Output Requirements:
- Compute u(x, T=0.3) on the grid
- Save solution to "solution_agent_advection_06.npz" with arrays:
  * x (grid points)
  * u (solution values)
  * Metadata: T, dx, dt
- Generate plot "solution_agent_advection_06.png" of u(x,T)
- Print diagnostics:
  * Minimum value of u
  * Maximum value of u
  * Discrete L2 norm: sqrt(sum(u^2)*dx)
