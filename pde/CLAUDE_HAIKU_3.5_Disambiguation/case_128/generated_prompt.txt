Numerical Solution for 1D Nonlinear Convection-Diffusion PDE

Solve the following PDE using Python with the following specifications:

Governing PDE: u_t = -q1*∂_x( (1/3)*u^3 ) + (q2/pi)*u_xx
Domain: x in [0, 1) with periodic boundary, t in [0, 0.5]
Parameters: q1 = 1.0, q2 = 0.05

Spatial Grid:
- Uniform periodic grid with Nx = 1024 points
- x_j = j*dx for j=0,...,Nx-1
- dx = 1/Nx

Numerical Method:
- Spatial Discretization:
  - Conservative finite-volume flux for ∂_x((1/3)u^3) using Rusanov scheme
  - 2nd-order central differences for u_xx
- Time Integration: SSP-RK2
- Time Stepping:
  - CFL = 0.2
  - Estimate max|f'(u)| = max|u^2|
  - dt0 = CFL*dx/max|f'|
  - dt_diff = 0.2*dx^2/(q2/pi)
  - dt = min(dt0, dt_diff)
  - Nt = ceil(T/dt)
  - Final dt = T/Nt

Initial Condition:
u(x,0) = 0.5*sin(2*pi*x)

Boundary Condition:
Periodic: u(0,t) = u(1,t) for all t

Computational Environment:
- Programming Language: Python
- Use '**' for exponentiation
- Use radians for trigonometric functions
