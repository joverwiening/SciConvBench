Specification for Solving 1D Burgers' Equation Numerically:

Solve the 1D Burgers' equation u_t + u*u_x = 0.01*u_xx with the following detailed requirements:

PDE Details:
- Equation: u_t + u*u_x = 0.01*u_xx
- Domain: x in [0,1], t in [0,0.5]
- Kinematic viscosity (nu): 0.01
- Initial condition: u(x,0) = sin(π*x)

Numerical Method Specifications:
- Spatial Discretization: Conservative form with Rusanov flux
- Convection Term: Finite-volume method using Rusanov (local Lax-Friedrichs) flux
- Diffusion Term: 2nd-order central difference
- Time Integration: 1st-order IMEX (explicit convection, implicit diffusion)
- Boundary Conditions: Dirichlet (u[0] = u[N] = 0)

Grid and Simulation Parameters:
- Spatial Grid: Nx = 800 intervals (801 points)
- Spatial Domain: [0,1] with dx = 1/Nx
- Time Step: dt = 1e-4
- Total Time Steps: Nt = 5000
- Final Time: T = 0.5

Output Requirements:
- Compute u(x, T=0.5)
- Save solution to "solution_agent_burgers_03.npz"
- Include in NPZ: x array, u array, T, dx, dt
