Solve the Allen-Cahn PDE u_t = (0.02)^2*u_xx + u - u^3 numerically.

Apply Neumann boundary conditions u_x(0,t) = 0 and u_x(1,t) = 0.

Set dt = 0.0005 for 2000 time steps to reach T = 1.0.
Implement zero Neumann boundary conditions using ghost points with mirror values.
Solve the resulting linear system at each time step.
