Solve the 1D Compressible Navier-Stokes equations numerically with the following specifications.
The PDE system in conservative form uses variables rho (density), m = rho*v (momentum), and E = p/(Gamma-1) + 0.5*rho*v^2 (total energy).
The viscous stress is sigma = (zeta + 4/3*eta) * v_x with zeta = eta.
The governing equations are rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, and E_t + ((E+p)*v - v*sigma)_x = 0.
The spatial domain is x in [-1, 1] and temporal domain is t in [0, 0.5].
Use parameters Gamma = 1.6666666666666667, eta = 0.01, and zeta = eta = 0.01.
Apply periodic boundary conditions at x = -1 and x = 1.
Set initial conditions as rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), and p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx = 400 cells on [-1,1] where cell centers are x_j = -1 + (j+0.5)*dx for j = 0,...,Nx-1 and dx = 2/Nx.
Evolve conservative variables U = [rho, m, E] as cell averages.
Apply equation of state p = (Gamma-1) * (E - 0.5*m^2/rho) and enforce positivity by clipping rho and p to 1e-12 if needed.
Use Rusanov numerical flux for convective terms with F_conv(U) = [m, m^2/rho + p, (E+p)*v] where v = m/rho.
Calculate interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Apply numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute viscous terms using centered differences for v_x, then sigma = (zeta + 4/3*eta)*v_x.
Average sigma at interfaces from neighboring cell-centered values.
Add viscous contributions F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Use total interface flux F_total = F_hat + F_visc.
Integrate in time using 2-stage SSP-RK2 (Heun's method).
Choose time step each iteration as dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30), then dt = min(dt_conv, dt_visc).
Use CFL = 0.4 for stability.
Adjust the final time step to hit T = 0.5 exactly.
Implement periodic boundary conditions by wrapping indices.
Compute final solution rho(x,T), v(x,T), p(x,T) on cell centers.
