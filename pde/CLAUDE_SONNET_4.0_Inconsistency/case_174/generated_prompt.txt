Implement a numerical solver for the 1D reaction-diffusion PDE using Python with NumPy, SciPy, and Matplotlib.
Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) where nu = 0.5 and rho = 2.0.
Use spatial domain x in [0, 1) with periodic boundary conditions and temporal domain t in [0, 1.0].
Create a uniform periodic grid with Nx = 512 points where x_j = j*dx for j = 0,...,511 and dx = 1/512.
Use time grid with fixed dt = 0.001 and Nt = 1000 steps.
Apply initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Implement Strang splitting time integration with explicit forward Euler.
For each time step, perform diffusion half-step (dt/2) in Fourier space using FFT.
Compute k = 2*pi*fftfreq(Nx, d=dx) and apply u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Take real part after inverse FFT.
Perform reaction full-step (dt) using exact pointwise solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform second diffusion half-step (dt/2) identical to the first.
Compute final solution u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing arrays x, u and scalars nu, rho, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho2.png".
