Solve the 1D advection-diffusion PDE u_t = D*u_xx - (1/gamma)*∂_x(U'(x)*u) numerically.
Use the domain x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set parameters D = 0.01, gamma = 1.0, U(x) = cos(2*pi*x), U'(x) = -2*pi*sin(2*pi*x).
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 1.0 + 0.2*sin(2*pi*x).
Create a uniform periodic grid with Nx = 512 points on [0,1) using x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Treat the drift term in conservative form as flux F = (1/gamma)*U'(x)*u, so the PDE becomes u_t = D*u_xx - ∂_x(F).
Use upwind finite-volume flux for ∂_x(F) based on the sign of interface velocity b = U'(x)/gamma.
Use 2nd-order central differences for the diffusion term u_xx.
Implement explicit SSP-RK2 time integration with the standard two-stage method.
Choose time step dt = min(0.4*dx/max|b|, 0.2*dx^2/D) where b(x) = U'(x)/gamma.
Set Nt = ceil(T/dt) and adjust dt = T/Nt.
Compute the solution u(x,T=1.0) on the periodic grid.
Save "solution_molk_033.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter scalars.
Save a line plot of u(x,T) as "solution_molk_033.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
