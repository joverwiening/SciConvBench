Solve the 1D Compressible Navier-Stokes equations numerically with the following specifications.
Use a uniform finite-volume grid with Nx=800 cells on the domain x in [-1, 1].
Set cell centers at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Evolve conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Set parameters Gamma = 1.6666666666666667, eta = 1e-08, and zeta = eta = 1e-08.
Apply transmissive/outflow boundary conditions with zero-gradient at x=-1 and x=1.
Initialize with Riemann shock-tube conditions: for x < 0 use rho_L = 1.0, v_L = 0.75, p_L = 1.0; for x >= 0 use rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Compute convective fluxes using Rusanov numerical flux with interface wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Calculate viscous stress sigma = (zeta + 4/3*eta) * v_x using centered differences on cell-centered v values.
Average sigma at interfaces and add viscous contributions F_visc = [0, -sigma, -v*sigma] to total flux.
Use 2-stage SSP-RK2 time integration with adaptive time stepping.
Calculate dt each step as dt = min(dt_conv, dt_visc) where dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Use CFL = 0.4 for stability.
Adjust the final time step to hit T = 0.2 exactly.
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.
Compute final solution rho(x,T), v(x,T), p(x,T) on cell centers.
Save results to "solution_pdebench_cns1d_sod3_eta1em8_outflow.npz" containing arrays x, rho, v, p and scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel line plot of rho, v, p vs x at final time as "solution_pdebench_cns1d_sod3_eta1em8_outflow.png".
Print min/max values of rho and p for positivity check and mean of rho for mass conservation check.
