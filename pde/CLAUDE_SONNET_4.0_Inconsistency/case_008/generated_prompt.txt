Solve the Allen-Cahn PDE numerically with the following specifications.
The PDE is u_t = (0.02)^2*u_xx + u - u^3.
The spatial domain is x in [0,1] and temporal domain is t in [0,0.2].
The parameter epsilon = 0.02.
Apply Dirichlet boundary conditions: u(0,t)=1 and u(1,t)=-1.
The initial condition is u(x,0)=tanh((0.5 - x)/(sqrt(2)*0.02)).
Use uniform spatial grid with Nx=1200 intervals, so there are 1201 grid points including both endpoints.
The spatial step size is dx=(1-0)/1200=1/1200.
The grid points are x_i=0+i*dx for i=0,1,...,1200.
Use 2nd-order central differences for the spatial derivative u_xx.
Use semi-implicit time integration: (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
Use time step dt=0.0001 for 2000 time steps to reach T=0.2.
Enforce Dirichlet boundary conditions by setting boundary nodes to prescribed values at every time step.
Solve the resulting linear system at each time step.
Compute the solution u(x,T=0.2) on the spatial grid.
Save "solution_agent_allen_cahn_02.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save a line plot of u(x,T=0.2) as "solution_agent_allen_cahn_02.png".
