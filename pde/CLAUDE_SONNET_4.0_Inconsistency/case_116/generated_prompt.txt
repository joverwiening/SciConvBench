Solve the 1D sine-Gordon equation u_tt + q*sin(u) = u_xx numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
Set the parameter q = 1.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t) for all t.
Use initial condition u(x,0) = 0.1*sin(2*pi*x).
Use initial condition u_t(x,0) = 0.
Create a uniform periodic spatial grid with Nx = 512 points on [0,1).
Set x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Convert the PDE to a first-order system: u_t = v, v_t = u_xx - q*sin(u).
Use 2nd-order central differences for u_xx on the periodic grid.
Apply RK4 time integration to the (u,v) system.
Use time step dt = 0.0005 with Nt = 4000 steps to reach final time T = 2.0 exactly.
Compute u(x,T=2.0) on the periodic grid.
Save "solution_molk_015.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, q.
Save a line plot of u(x,T) as "solution_molk_015.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 2.0.
