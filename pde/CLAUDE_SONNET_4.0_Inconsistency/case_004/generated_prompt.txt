Solve the 2D advection PDE u_t + (1.0)*u_x + (0.5)*u_y = 0 on the periodic domain (x,y) ∈ [0,1) × [0,1) for t ∈ [0,1.0].
Use parameters a = 1.0 and b = 0.5.
Apply periodic boundary conditions in both x and y directions.
Set the initial condition u(x,y,0) = sin(2*pi*x)*cos(2*pi*y).
Use the exact solution u(x,y,t) = sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t)) for verification.
Create a uniform periodic grid with Nx = Ny = 256 points on [0,1) × [0,1) with no duplicated endpoints.
Set dx = dy = 1/Nx = 1/256.
Use 1st-order upwind finite differences in both x and y directions for spatial discretization.
Apply forward Euler time integration with CFL condition |a|*dt/dx + |b|*dt/dy ≤ 0.9.
Calculate dt0 = 0.9 / (|a|/dx + |b|/dy), then set Nt = ceil(T/dt0) and dt = T/Nt to hit the final time T = 1.0 exactly.
Handle boundaries using periodic wrap-around indexing in both directions.
Compute the solution u(x,y,T=1.0) on the 2D grid.
Save "solution_agent_advection_04.npz" containing arrays x (1D), y (1D), u (2D with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T=1.0), and metadata scalars T, dx, dy, dt.
Save a heatmap plot of u(x,y,T=1.0) as "solution_agent_advection_04.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T=1.0.
