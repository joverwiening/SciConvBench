Solve the Klein-Gordon PDE u_tt - (1.0)^2*u_xx + (0.5)^2*u = 0 numerically.
The spatial domain is x in [0,1] and temporal domain is t in [0,1.0].
Use parameters c = 1.0 and m = 0.5.
Apply Neumann boundary conditions u_x(0,t) = 0 and u_x(1,t) = 0.
Set initial conditions u(x,0) = cos(pi*x) and u_t(x,0) = 0.
Use uniform spatial grid with Nx = 400 intervals giving Nx+1 = 401 grid points including both endpoints.
Set dx = 1/Nx = 1/400.
Apply 2nd-order central differences for spatial derivative u_xx.
Use 2nd-order central difference in time (leapfrog) for u_tt.
Handle the +m^2*u term explicitly at time level n in the update.
Choose dt0 = 0.9*dx/c = 0.9*(1/400)/1.0.
Set Nt = ceil(1.0/dt0) and then dt = 1.0/Nt so final time is hit exactly.
Initialize using Taylor start from u0 and v0, including the -m^2*u0 term.
Handle boundaries using zero Neumann via ghost points by mirroring values.
Compute u(x, T=1.0) on the grid.
Save "solution_agent_kg_03.npz" containing arrays x (1D), u (1D), plus scalars T, dx, dt.
