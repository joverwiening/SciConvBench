Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use temporal domain t in [0, 1.0].
Set viscosity parameter nu = 0.001.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Create uniform periodic grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement Strang splitting time integration with three substeps per full time step dt.
For diffusion half-steps, solve exactly in Fourier space using u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- real(IFFT(u_hat)).
For advection full-step, solve inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using finite-volume update with Rusanov flux.
Define flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell j using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus is flux between (u[j], u[j+1]) and F_minus is flux between (u[j-1], u[j]).
Use CFL=0.4 based on estimated max speed of 1.0 to set dt0 = CFL*dx/1.0.
Choose Nt = ceil(T/dt0) and reset dt = T/Nt to hit final time exactly.
Compute solution u(x,T=1.0) on the periodic grid.
