Solve the 1D convection-diffusion PDE u_t = -q1*∂_x(0.5*u^2) + (q2/pi)*u_xx numerically.
Use spatial domain x in [0,1) with periodic boundary conditions and temporal domain t in [0,0.5].
Set parameters q1 = 1.0 and q2 = 0.1.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Create uniform periodic grid with Nx = 512 points on [0,1) using x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Discretize the nonlinear flux f(u) = 0.5*u^2 using conservative finite-volume with Rusanov (local Lax-Friedrichs) flux.
Discretize the diffusion term u_xx using 2nd-order central differences.
Use SSP-RK2 (Heun) time integration with fixed time step.
Compute effective diffusion D_eff = q2/pi.
Calculate convection time step dt_conv = CFL * dx / max|u0| with CFL = 0.4 and max|u0| = 1.
Calculate diffusion time step dt_diff = 0.4 * dx^2 / D_eff.
Set dt0 = min(dt_conv, dt_diff).
Compute Nt = ceil(T/dt0) and set dt = T/Nt to hit final time T = 0.5 exactly.
Compute the solution u(x,T) at final time T = 0.5.
Save "solution_molk_024.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter scalars q1 and q2.
Save line plot of u(x,T) as "solution_molk_024.png".
