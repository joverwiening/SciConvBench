Solve the 1D Compressible Navier-Stokes equations numerically with the following specifications.
Use a uniform finite-volume grid with Nx=800 cells on the domain [-1,1].
Set cell centers at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1 where dx = 2/Nx.
Evolve conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use Gamma = 1.6666666666666667 and eta = zeta = 1e-08.
Set the viscous stress as sigma = (zeta + 4/3*eta) * v_x.
Apply the PDE system: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
Use transmissive/outflow boundary conditions with zero-gradient at x=-1 and x=1.
Initialize with Riemann shock-tube conditions: for x < 0 use rho_L=1.0, v_L=-0.75, p_L=1.0; for x ≥ 0 use rho_R=0.125, v_R=0.0, p_R=0.1.
Compute the equation of state as p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.
Use Rusanov numerical flux for the convective part: F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L) where a = max(|v_L| + c_L, |v_R| + c_R) and c = sqrt(Gamma*p/rho).
Compute viscous terms using centered differences for v_x, then average sigma at interfaces.
Add viscous contributions F_visc = [0, -sigma, -v*sigma] to get total flux F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 time integration.
Set CFL = 0.4 for stability.
Choose time step as dt = min(dt_conv, dt_visc) where dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Adjust the final time step to hit T = 0.2 exactly.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell.
Compute the final solution rho(x,T), v(x,T), p(x,T) on cell centers.
