Implement a 2D Darcy flow solver in Python using NumPy and SciPy.
Solve the PDE -∇ · ( a(x,y) ∇u(x,y) ) = 1 on domain (0,1) x (0,1).
Set beta = 100.0.
Define coefficient field a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions u = 0 on all boundaries.
Use uniform Cartesian grid with N=128 intervals in each direction.
Set dx = dy = 1/N and grid points x_i = i*dx, y_j = j*dy for i,j = 0,...,N.
Discretize using 2nd-order finite differences with harmonic averaging of face coefficients.
For interior nodes, use the discretization -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Compute face coefficients using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble sparse linear system Au=b for interior unknowns.
Solve using conjugate gradient method with tolerance 1e-10 relative residual.
Compute solution u(x,y) on full (N+1) x (N+1) grid including boundaries.
Save "solution_pdebench_darcy_beta100.npz" containing arrays x, y, u and scalars beta, N, dx.
Save heatmap plot as "solution_pdebench_darcy_beta100.png".
Print min(u), max(u), and discrete residual norm ||Au-b||_2 / ||b||_2.
