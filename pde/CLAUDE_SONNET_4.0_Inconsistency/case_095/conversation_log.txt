Q: What value should be used for the wave speed c in the PDE solution - should I use c = 0.8 (from the PDE coefficient) or c = 1.6 (from the parameters section)?
A: Use c = 0.8. The PDE is u_tt = (0.8)^2 * u_xx, so the wave speed is 0.8. The "c = 1.6" in the parameters section appears to be an error - ignore it and use c = 0.8 consistently throughout your solution.
