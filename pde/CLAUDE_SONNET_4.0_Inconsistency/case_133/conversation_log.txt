Q: What is the exact interpretation of the grid convention for this specific problem - should I use Nx=1024 as the number of intervals (giving 1024 grid points on [0,1) with dx=1/1024) or as stated in the general convention where Nx would be the number of grid points including endpoints (which would conflict with the periodic [0,1) domain)?
A: The requirement explicitly states: "spatial_grid: Uniform periodic grid with Nx=1024 points on [0,1). Use x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx."

So use Nx=1024 as the number of grid points (not intervals), giving you 1024 points on [0,1) with dx=1/1024. The grid points are x_j = j/1024 for j=0,1,2,...,1023.
