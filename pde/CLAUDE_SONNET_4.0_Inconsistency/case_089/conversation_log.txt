Q: What value should be used for the wave speed parameter c in the PDE solution - should I use c = 0.7 (from the PDE coefficient) or c = 1.4 (from the parameters section)?
A: Use c = 0.7. The PDE shows u_tt = (0.7)^2 * (u_xx + u_yy), so the wave speed is 0.7. The "c = 1.4" in the parameters section appears to be an error - ignore it and use c = 0.7 throughout your calculations.
