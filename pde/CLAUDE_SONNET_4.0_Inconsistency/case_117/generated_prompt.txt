Solve the PDE u_tt + (q**2)*u_xxxx + c*∂_x( u * u_x ) = 0 numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
Set parameters q = 0.05 and c = 1.0.
Apply periodic boundary conditions where u and all x-derivatives are periodic on [0,1).
Use initial condition u(x,0) = 0.1*cos(2*pi*x).
Use initial condition u_t(x,0) = 0.
Create a uniform periodic grid with Nx=512 points on [0,1).
Set x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Convert the PDE to first-order system with v=u_t: u_t=v, v_t = -(q**2)*u_xxxx - c*∂_x(u*u_x).
Use Fourier spectral derivatives for computing u_x and u_xxxx.
Apply RK4 time integration on the (u,v) system.
Use time step dt=0.0001 with Nt=5000 steps to reach final time T=0.5.
Compute u(x,T=0.5) on the periodic grid.
Save "solution_molk_016.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, q, c.
Save a line plot of u(x,T) as "solution_molk_016.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
