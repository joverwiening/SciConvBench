Solve the 1D reaction-diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on domain x in [0, 1) with periodic boundary conditions and t in [0, 1.0].
Use parameters nu = 5.0 and rho = 10.0.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use explicit forward Euler time integration with Strang splitting.
Create uniform periodic spatial grid with Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use fixed time step dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
Implement Strang splitting for each full time step dt as follows: (A) diffusion half-step of duration dt/2 solved exactly in Fourier space using u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- real(IFFT(u_hat)), (B) reaction full-step of duration dt solved exactly pointwise using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)), (C) diffusion half-step again same as step A.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_reacdiff_nu5_rho10.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu5_rho10.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
