Solve the wave equation u_tt + 0.5*u_t = (1.0)^2 * u_xx numerically.
The spatial domain is x in [0,1] and time domain is t in [0,3.0].
Use parameters c = 1.0 and gamma = 0.5.
Apply Dirichlet boundary conditions with u=0 at x=0 and x=1.
Set initial conditions u(x,0)=sin(pi*x) and u_t(x,0)=0.
Use 2nd-order central differences for spatial discretization of u_xx on a uniform grid.
Rewrite as first-order system: u_t = v, v_t = c^2*u_xx - gamma*v.
Integrate the (u,v) system using classical RK4 time integration.
Enforce Dirichlet boundary conditions by setting u=0 and v=0 at boundaries at every RK substage.
Use Nx=400 spatial intervals with dx=(1-0)/400=0.0025.
Use dt=0.0005 for time integration with 6000 time steps to reach T=3.0.
Compute the solution u(x,T=3.0) on the spatial grid.
Save "solution_agent_wave_09.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_09.png".
