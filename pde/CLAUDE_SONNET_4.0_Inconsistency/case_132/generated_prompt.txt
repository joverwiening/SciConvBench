Solve the 1D nonlinear convection-diffusion PDE u_t = -q1*∂_x(cos(u)) + (q2/pi)*u_xx on domain x in [0,1) with periodic boundary conditions and t in [0,0.5].
Use parameters q1 = 1.0 and q2 = 0.05.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = 0.5*sin(2*pi*x).
Create uniform periodic grid with Nx = 1024 points on [0,1) using x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Discretize the convection term ∂_x(cos(u)) using conservative finite-volume flux with Rusanov flux and wave speed alpha = max|sin(u)| over all grid points, or alpha = 0 when max|sin(u)| = 0.
Discretize the diffusion term u_xx using 2nd-order central differences.
Use SSP-RK2 for time integration.
Calculate time step as dt_adv = 0.2*dx/1 and dt_diff = 0.2*dx^2/(q2/pi), then use dt = min(dt_adv, dt_diff).
Set Nt = ceil(T/dt) and adjust dt = T/Nt where T = 0.5.
Compute the solution u(x,T=0.5) on the periodic grid.
Save "solution_molk_031.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, q1, q2.
Save a line plot of u(x,T) as "solution_molk_031.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.5.
