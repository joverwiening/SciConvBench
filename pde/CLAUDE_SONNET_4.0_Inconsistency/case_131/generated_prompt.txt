Solve the 1D inviscid conservation law PDE u_t = -k*∂_x(sin(u)) numerically.
Set k = 1.0.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use time domain t in [0, 0.2].
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = 0.5*sin(2*pi*x).
Create uniform periodic grid with Nx = 1024 points on [0,1).
Set x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Use conservative finite-volume Rusanov flux for f(u) = sin(u).
Set wave speed alpha = max|cos(u)|.
Apply SSP-RK2 time integration.
Use CFL = 0.2 to set dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and dt = T/Nt.
Compute u(x,T=0.2) on the periodic grid.
Save "solution_molk_030.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter scalars.
