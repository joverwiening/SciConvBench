Solve the 1D advection PDE u_t + beta * u_x = 0 numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use time domain t in [0, 2.0].
Set parameter beta = 0.2.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Create uniform spatial grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Apply 1st-order upwind finite difference for u_x using upwind direction determined by sign of beta.
Use explicit forward Euler for time integration.
Set time step using CFL=0.5 with dt = CFL * dx / abs(beta).
Calculate number of time steps Nt = ceil(T/dt) then reset dt = T/Nt to hit final time exactly.
Compute solution u(x,T=2.0) on the periodic grid.
Save "solution_pdebench_advection_beta0p2.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.

Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=2.0.
