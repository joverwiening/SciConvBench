Solve the 1D Compressible Navier-Stokes equations numerically with the following specifications.
Use a uniform finite-volume grid with Nx=400 cells on the domain x in [-1, 1].
Set cell centers at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Evolve the conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use the PDE system: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
Set the viscous stress sigma = (zeta + 4/3*eta) * v_x where zeta = eta.
Use parameters Gamma = 1.6666666666666667, eta = 1e-08, zeta = eta = 1e-08.
Apply transmissive/outflow boundary conditions (zero-gradient) at x=-1 and x=1.
Initialize with rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Compute the equation of state as p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.
Use the Rusanov numerical flux for the convective part: F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Calculate the interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Compute viscous terms using centered differences for v_x and average sigma values at interfaces.
Add viscous contributions F_visc = [0, -sigma, -v*sigma] to get total flux F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Calculate time step as dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Use CFL = 0.4 and set dt = min(dt_conv, dt_visc).
Adjust the final time step to hit T = 0.5 exactly.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell.
Compute the final solution rho(x,T), v(x,T), p(x,T) on the cell centers at T = 0.5.
