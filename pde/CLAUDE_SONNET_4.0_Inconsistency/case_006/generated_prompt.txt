Solve the advection PDE u_t + 2.0*u_x = 0 numerically.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,0.3].
The parameter a = 2.0.
Apply periodic boundary conditions where u is periodic in x.
Use the initial condition u(x,0) = 1 if 0.2 ≤ x < 0.4, else 0 (a periodic square pulse).
Use a uniform periodic grid with Nx = 2000 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Use 1st-order upwind finite difference for the spatial derivative u_x.
Use Forward Euler time integration.
Choose dt0 = 0.9*dx/|a| for the CFL condition.
Set Nt = ceil(T/dt0) where T = 0.3, then set dt = T/Nt to hit the final time exactly.
Handle boundaries using periodic wrap-around indexing.
Compute the solution u(x, T=0.3) on the grid.
Save "solution_agent_advection_06.npz" containing arrays x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
Save a line plot of u(x,T=0.3) as "solution_agent_advection_06.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.3.
