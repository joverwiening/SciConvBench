Solve the 1D linear advection-diffusion PDE u_t = -q1*∂_x(u) + (q2/pi)*u_xx numerically.
Use domain x in [0,1) with periodic boundary conditions and t in [0,0.5].
Set parameters q1 = 1.0 and q2 = 0.05.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Create uniform periodic grid with Nx = 512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx = 1/Nx.
Discretize spatial derivatives using 1st-order upwind for ∂_x(u) and 2nd-order central differences for u_xx.
Use IMEX Euler time integration with diffusion implicit and advection explicit, or sufficiently small explicit dt.
Calculate time step as dt = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)), then set Nt = ceil(T/dt) and reset dt = T/Nt.
Derive the exact solution using Fourier-mode evolution for the linear advection-diffusion equation with the given initial condition.
For each Fourier mode sin(n*pi*x), the exact solution is sin(n*pi*x) * exp(-q1*i*n*pi*t) * exp(-(q2/pi)*(n*pi)^2*t).
Apply this to both modes: sin(2*pi*x) (n=2) and 0.5*sin(4*pi*x) (n=4).
The complete exact solution is u_exact(x,t) = sin(2*pi*(x-q1*t)) * exp(-(q2/pi)*(2*pi)^2*t) + 0.5*sin(4*pi*(x-q1*t)) * exp(-(q2/pi)*(4*pi)^2*t).
Compute the numerical solution u(x,T=0.5) on the periodic grid.
