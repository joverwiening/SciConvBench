Solve the wave equation u_tt = (1.5)^2 * u_xx numerically.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,0.7].
The wave speed parameter is c = 1.5.
Apply periodic boundary conditions where both u and u_x are periodic.
Use initial conditions u(x,0) = sin(2*pi*x) and u_t(x,0) = cos(2*pi*x).
Create a uniform periodic grid with Nx = 512 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Use 2nd-order central differences with wrap-around for spatial discretization of u_xx.
Use 2nd-order central difference in time for time integration.
Set dt0 = 0.9*dx/c for the CFL condition.
Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time T = 0.7 is hit exactly.
Initialize using Taylor start including the initial velocity v0 and Laplacian of u0.
Compute u(x, T=0.7) on the grid.
Save "solution_agent_wave_17.npz" containing arrays x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_17.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.7.
