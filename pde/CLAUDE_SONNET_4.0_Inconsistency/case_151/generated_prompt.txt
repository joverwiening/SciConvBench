Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically using Python.
Use domain x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set parameter nu = 2.0.
Apply initial condition u(x,0) = sin(2*pi*x).
Use periodic boundary condition u(0,t) = u(1,t) for all t.
Create uniform periodic grid with Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement Strang splitting with explicit forward Euler time integration.
For each time step dt, perform diffusion half-step (dt/2) solved exactly in Fourier space using FFT.
Apply u_hat(k) <- FFT(u), compute k = 2*pi*fftfreq(Nx, d=dx), update u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), then u <- real(IFFT(u_hat)).

Define f(u)=0.5*u^2 and for each interface compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus and F_minus are fluxes at adjacent interfaces.
Perform second diffusion half-step (dt/2) identical to the first.

Compute solution u(x,T=1.0) on the periodic grid.
