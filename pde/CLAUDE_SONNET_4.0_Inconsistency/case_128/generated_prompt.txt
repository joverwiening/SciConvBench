Solve the 1D nonlinear convection-diffusion PDE u_t = -q1*∂_x((1/3)*u^3) + (q2/pi)*u_xx numerically.
Use spatial domain x in [0,1) with periodic boundary conditions and temporal domain t in [0,0.5].
Set parameters q1 = 1.0 and q2 = 0.05.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.5*sin(2*pi*x).
Create uniform periodic grid with Nx = 1024 points on [0,1) using x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Discretize the convective flux ∂_x((1/3)*u^3) using conservative finite-volume with Rusanov scheme and first-order upwind reconstruction (no flux limiter).
Discretize the diffusive term u_xx using second-order central differences.
Use SSP-RK2 for time integration.
Estimate max|f'(u)| = max|u^2| where initially |u| <= 0.5 so max|f'| <= 0.25.
Calculate dt0 = CFL*dx/max|f'| with CFL = 0.2 and dt_diff = 0.2*dx^2/(q2/pi).
Set dt = min(dt0, dt_diff), then Nt = ceil(T/dt), and final dt = T/Nt.
Compute u(x,T=0.5) on the periodic grid.
Save "solution_molk_027.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, q1, q2.
Save line plot of u(x,T) as "solution_molk_027.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.5.
