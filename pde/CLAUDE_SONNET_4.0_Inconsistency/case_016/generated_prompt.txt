Solve the Burgers PDE u_t + u*u_x = 0.02*u_xx + sin(2*pi*x)*cos(2*pi*t) numerically.
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,1.0].
The parameter nu = 0.02.
The initial condition is u(x,0) = 0.
Use periodic boundary conditions on the spatial domain.
Discretize in conservative form u_t + (f(u))_x = nu*u_xx with f(u) = 0.5*u^2.
For convection, use finite-volume with Rusanov flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
Approximate (f(u))_x as (F_{i+1/2}-F_{i-1/2})/dx.
For diffusion, use 2nd-order central difference: u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Use 1st-order IMEX time integration: treat convection explicitly and diffusion implicitly.
The time stepping equation is (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_{i-1})/dx^2.
Solve the resulting linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term each time step.
Use periodic wrap-around indexing for both convection fluxes and diffusion stencil.
Use Nx = 1000 points on [0,1) with dx = 1/Nx.
Use dt = 1e-4 with Nt = 10000 steps to reach T = 1.0 exactly.
Compute u(x, T=1.0) on the grid.
