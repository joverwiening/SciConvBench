Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain [0,1] x [0,1].
Apply Dirichlet boundary conditions: u(x,0)=0, u(x,1)=1, u(0,y)=0, u(1,y)=0.
Use a uniform grid with Nx=Ny=100 intervals in each direction, creating a (Nx+1) by (Ny+1) grid of points.
Set dx=dy=1/Nx and define grid points as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Discretize the Laplace equation using the standard 5-point stencil with 2nd-order accuracy.
Solve the resulting sparse linear system for interior nodes using scipy.sparse.linalg.spsolve.
Save the solution as "solution_agent_laplace_09.npz" containing arrays x (1D), y (1D), u (2D with shape (len(y), len(x))), and scalars dx, dy.
Save a heatmap plot of the solution as "solution_agent_laplace_09.png".
