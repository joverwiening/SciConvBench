Implement a 2D Darcy flow solver using Python with NumPy and SciPy.
Solve the PDE -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (0,1) × (0,1).
Set beta = 10.0.
Define the coefficient field as a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions u = 0 on the entire boundary.
Use a uniform Cartesian grid with N=128 intervals in each direction, creating (N+1) × (N+1) = 129 × 129 grid points.
Set dx = dy = 1/N = 1/128.
Define grid points as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize using 2nd-order finite differences with variable coefficients and face-centered harmonic averaging.
For interior nodes (i=1..N-1, j=1..N-1), apply the discretization: -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Calculate face coefficients using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for interior unknowns only.
Solve the linear system using conjugate gradient method with relative tolerance 1e-10.
Apply a simple Jacobi preconditioner if needed.
Compute the solution u(x,y) on the full (N+1) × (N+1) grid including boundary values.
Save "solution_pdebench_darcy_beta10.npz" containing arrays x (1D), y (1D), u (2D shape [129, 129]), and scalars beta, N, dx.
