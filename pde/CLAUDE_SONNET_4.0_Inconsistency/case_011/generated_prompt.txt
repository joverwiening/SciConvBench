Solve the Allen-Cahn PDE: u_t = (0.02)^2*(u_xx + u_yy) + u - u^3.
Use spatial domain (x,y) in [0,1] x [0,1] and time domain t in [0,0.1].
Set epsilon = 0.02.
Apply Dirichlet boundary conditions u=0 on all boundaries.
Use initial condition u(x,y,0) = tanh((0.25 - r)/(sqrt(2)*0.02)) where r = sqrt((x-0.5)^2 + (y-0.5)^2).
Discretize space using uniform grid with Nx=Ny=300 intervals so there are 301x301 grid points including endpoints.
Set dx = dy = 1/300 and dt = 0.0001 for 1000 time steps.
Use semi-implicit time integration: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
Discretize the Laplacian using 5-point stencil for u_xx + u_yy.
Solve the resulting sparse linear system at each time step.
Enforce Dirichlet boundary conditions by setting boundary nodes to 0 at every time step.
Compute the solution u(x,y,T=0.1) at the final time.
