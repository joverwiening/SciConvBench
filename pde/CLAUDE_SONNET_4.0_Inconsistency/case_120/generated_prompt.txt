Solve the 1D wave equation u_tt = q*u_xx numerically using the specifications below.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
Set the parameter q = 1.0.
Apply periodic boundary conditions where u and u_x are periodic on [0,1).
Use initial conditions u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.
The exact solution for verification is u(x,t) = cos(2*pi*t) * sin(2*pi*x).
Create a uniform periodic grid with Nx=256 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Convert the PDE to a first-order system with v=u_t: u_t=v, v_t=q*u_xx.
Use 2nd-order central differences for u_xx on the periodic grid.
Apply RK4 time integration on the (u,v) system.
Use time step dt=0.0005 with Nt=2000 steps to reach final time T=1.0 exactly.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_019.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter q.
