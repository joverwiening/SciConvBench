Solve the Klein-Gordon PDE u_tt - (0.5)^2*u_xx + (2.0)^2*u = 0 numerically.
Use spatial domain x in [0,1] and temporal domain t in [0,1.0].
Set parameters c = 0.5 and m = 2.0.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1.
Use initial conditions u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.
The exact solution for verification is u(x,t) = cos(sqrt((0.5*2*pi)^2 + (2.0)^2)*t)*sin(2*pi*x).
Use uniform spatial grid with Nx = 600 intervals giving Nx+1 = 601 grid points including both endpoints.
Set dx = 1/Nx = 1/600.
Apply 2nd-order central differences for spatial discretization of u_xx.
Use 2nd-order central difference in time (leapfrog) for time integration of u_tt.
Handle the +m^2*u term explicitly at time level n in the update.
Choose dt so that c*dt/dx ≤ 0.9, specifically dt0 = 0.9*dx/c = 0.9*dx/0.5.
Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time T = 1.0 is hit exactly.
Use Taylor start from initial conditions u0 and v0, including the -m^2*u0 term.
Compute the solution u(x, T=1.0) on the grid.
Save "solution_agent_kg_02.npz" containing arrays x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
