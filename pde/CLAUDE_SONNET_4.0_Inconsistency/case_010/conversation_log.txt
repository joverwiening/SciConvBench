Q: What value should dt be for the time integration? The specification mentions both dt=0.0002 and 1000 steps, but with T=0.2, these give different dt values (0.0002 would need 1000 steps, but 0.2/1000 = 0.0002 exactly, so they are consistent). Should I use dt=0.0002?
A: Yes, use dt=0.0002. The specification states "Use dt=0.0002 (1000 steps)" and with T=0.2, this gives exactly 1000 time steps: 0.2/0.0002 = 1000.
