Solve the advection PDE u_t + (1.0)*u_x = 0 numerically.
Use spatial domain x in [0,1) with periodic boundary conditions and temporal domain t in [0,1.0].
Set parameter a = 1.0.
Apply periodic boundary condition u(0,t) = u(1,t).
Use initial condition u(x,0) = sin(2*pi*x).
The exact solution for verification is u(x,t) = sin(2*pi*(x - (1.0)*t)).
Create a uniform periodic grid with Nx = 800 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Use 1st-order upwind finite difference for the spatial derivative u_x.
Apply forward Euler time integration.
Choose dt0 = 0.9*dx/|a| to satisfy the CFL condition max|a|*dt/dx ≤ 0.9.
Set Nt = ceil(T/dt0) where T = 1.0, then set dt = T/Nt to hit the final time exactly.
Use periodic wrap-around indexing for boundary handling.
Compute the numerical solution u(x, T=1.0) on the grid.
Save "solution_agent_advection_01.npz" containing arrays x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_advection_01.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
