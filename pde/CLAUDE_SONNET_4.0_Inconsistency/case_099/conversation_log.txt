Q: What value should be used for the wave speed c in the PDE u_tt = c^2 * u_xx? The PDE shows c^2 = (1.0)^2 = 1, but the parameters section lists c = 2, which would give c^2 = 4.
A: The wave speed c should be 1.0. The PDE shows u_tt = (1.0)^2 * u_xx, which means c^2 = 1, so c = 1.0.
