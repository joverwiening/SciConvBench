Solve the wave equation u_tt = u_xx numerically on the domain x in [0,1], t in [0,1.0].
Use wave speed c = 1.0.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1.

Use a uniform spatial grid with Nx = 800 intervals, giving Nx+1 = 801 grid points including both endpoints.
Set dx = 1/Nx = 1/800.
Apply 2nd-order central differences for u_xx in the interior points.
Use 2nd-order central difference time integration (leapfrog/Störmer-Verlet) for u_tt.
Choose dt0 = 0.9*dx/c = 0.9*dx/1.0 for stability with CFL ≤ 0.9.
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit the final time T = 1.0 exactly.
Initialize u at the first time step using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0.
Apply Dirichlet boundary conditions by setting boundary nodes to 0 at every time step.
Compute the solution u(x,T) at the final time T = 1.0.
