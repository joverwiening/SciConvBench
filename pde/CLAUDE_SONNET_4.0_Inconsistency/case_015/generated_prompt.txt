Solve the Burgers equation u_t + u*u_x = 0.01*u_xx numerically.
The spatial domain is [0,1] and the time domain is [0,0.5].
The viscosity parameter nu = 0.01.
Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0.
Use the initial condition u(x,0)=sin(pi*x).
Discretize in conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
For convection, use finite-volume with Rusanov flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
Approximate (f(u))_x as (F_{i+1/2}-F_{i-1/2})/dx.
For diffusion, use 2nd-order central difference u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Use 1st-order IMEX time integration treating convection explicitly and diffusion implicitly.
Solve the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term each time step.
Enforce Dirichlet boundary conditions by setting u[0]=0 and u[N]=0 each step.
Use Nx=800 intervals (801 grid points) with dx=1/800.
Use dt=1e-4 with Nt=5000 steps to reach T=0.5.
Compute u(x,T=0.5) on the grid.
Save "solution_agent_burgers_03.npz" containing arrays x, u, and scalars T, dx, dt.
