Solve the advection PDE u_t + a(x)*u_x = 0 where a(x) = 1 + 0.5*sin(2*pi*x).
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,0.5].
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx = 1200 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Use upwind spatial discretization with left-biased stencil since a(x) > 0 everywhere.
Use Forward Euler time integration.
Set amax = 1.5 and dt0 = 0.9*dx/amax.
Set Nt = ceil(T/dt0) where T = 0.5, then set dt = T/Nt to hit the final time exactly.
Compute the solution u(x, T=0.5) on the grid.
Save "solution_agent_advection_03.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
Save a line plot of u(x,T=0.5) as "solution_agent_advection_03.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
