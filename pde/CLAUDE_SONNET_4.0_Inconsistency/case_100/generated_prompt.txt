Solve the 2D wave equation u_tt = (1.0)^2 * (u_xx + u_yy) numerically.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions in both directions.
The time domain is t in [0,0.5].
The wave speed c = 1.0.
Apply periodic boundary conditions where u and first derivatives match across opposite edges.
Use initial condition u(x,y,0) = cos(2*pi*x)*cos(2*pi*y) and u_t(x,y,0) = 0.
The exact solution for verification is u(x,y,t) = cos(2*pi*x)*cos(2*pi*y)*cos(1.0*2*pi*sqrt(2)*t).
Use a uniform periodic grid with Nx = Ny = 128 points on [0,1) x [0,1) with no duplicated endpoints.
Set dx = dy = 1/Nx = 1/128.
Apply 2nd-order central differences in space with wrap-around for periodic boundaries.
Use 2nd-order central differences in time for time integration.
Choose dt for CFL ≤ 0.9 by setting dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time T = 0.5 is hit exactly.
Initialize the time stepping using Taylor start with the periodic Laplacian.
Compute u(x,y,T=0.5) on the 2D grid.
