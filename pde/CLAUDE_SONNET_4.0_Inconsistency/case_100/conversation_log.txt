Q: What is the wave speed c that should be used in the wave equation u_tt = c^2 * (u_xx + u_yy)?

I notice there's a contradiction: the PDE shows u_tt = (1.0)^2 * (u_xx + u_yy) which implies c = 1.0, but the parameters section lists c = 2, and the exact solution uses c = 1.0 in the time dependence cos(1.0*2*pi*sqrt(2)*t).
A: The wave speed c should be 1.0.

The PDE is u_tt = (1.0)^2 * (u_xx + u_yy), which means c = 1.0. The exact solution also confirms this with cos(1.0*2*pi*sqrt(2)*t). There is no contradiction in the complete requirement - c = 1.0 throughout.
