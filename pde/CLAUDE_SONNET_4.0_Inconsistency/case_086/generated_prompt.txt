Solve the wave equation u_tt = (1.0)^2 * u_xx numerically using the following specifications.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,1.0].
The wave speed is c = 1.0 as specified in the PDE equation.
Apply periodic boundary conditions: u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t).
Use initial conditions u(x,0) = cos(2*pi*x) and u_t(x,0) = 0.
The exact solution for verification is u(x,t) = cos(2*pi*x)*cos(2*pi*1.0*t).
Use a uniform periodic grid with Nx = 512 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Apply 2nd-order central difference with periodic wrap-around for spatial discretization of u_xx.
Use 2nd-order central difference in time for u_tt.
Set dt0 = 0.9*dx/c to satisfy CFL condition c*dt/dx ≤ 0.9.
Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time T = 1.0 is hit exactly.
Initialize the time stepping using Taylor start with the periodic Laplacian.
Compute u(x, T=1.0) on the grid.
Save "solution_agent_wave_05.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_05.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
