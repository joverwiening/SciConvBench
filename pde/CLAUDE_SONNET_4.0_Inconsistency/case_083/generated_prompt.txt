Solve the wave equation u_tt = (0.5)^2 * u_xx numerically on the domain x in [0,1], t in [0,1.0].
Use parameter c = 0.5.
Apply Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0.
Set initial conditions u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.
Use a uniform spatial grid on [0,1] with Nx = 400 intervals, giving Nx+1 = 401 grid points including both endpoints.
Calculate dx = 1/Nx = 1/400.
Apply 2nd-order central differences for u_xx in the interior points.
Use 2nd-order central difference time integration (leapfrog/Störmer-Verlet) for u_tt.
Choose dt such that CFL = c*dt/dx ≤ 0.9, so dt0 = 0.9*dx/c = 0.9*dx/0.5.
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit the final time T = 1.0 exactly.
Initialize u(x,dt) using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0.
Apply Dirichlet boundary conditions by setting boundary nodes to prescribed values at every time step.
Compute the solution u(x,T) at final time T = 1.0.
