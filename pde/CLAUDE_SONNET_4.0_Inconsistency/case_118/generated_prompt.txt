Solve the 1D KdV-type PDE: u_t + (q**2)*u_xxx + u*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
Set parameter q = 0.1.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = cos(2*pi*x).
Use a uniform periodic grid with Nx = 512 points on [0,1).
Set x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Use Fourier spectral derivatives for u_x and u_xxx (periodic).
Use RK4 for time integration.
Set time step dt = 0.0001 with Nt = 2000 steps to reach final time T = 0.2 exactly.
Compute u(x,T=0.2) on the periodic grid.
Save "solution_molk_017.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter q.
Save a line plot of u(x,T) as "solution_molk_017.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 0.2.
