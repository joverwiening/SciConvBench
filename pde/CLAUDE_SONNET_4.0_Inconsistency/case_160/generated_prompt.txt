Solve the 1D Compressible Navier-Stokes equations numerically using finite volume method.
Use conservative form with variables rho (density), m (momentum), and E (total energy).
Define total energy as E = p/(Gamma-1) + 0.5*rho*v^2 where v = m/rho.
Define viscous stress as sigma = (zeta + 4/3*eta) * v_x with zeta = eta.
Evolve the system: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
Set spatial domain to x in [-1, 1] and temporal domain to t in [0, 0.2].
Use parameters Gamma = 1.6666666666666667, eta = 1e-08, zeta = eta = 1e-08.
Apply transmissive/outflow boundary conditions with zero-gradient at x=-1 and x=1.
Initialize with Riemann shock-tube conditions: for x < 0 use rho_L = 1.0, v_L = 0.0, p_L = 1.0; for x >= 0 use rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Create uniform finite-volume grid with Nx=800 cells on [-1,1].
Set cell centers at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1 with dx = 2/Nx.
Evolve conservative variables U = [rho, m, E] as cell averages.
Use equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to floor value 1e-12 if needed.
Compute convective flux using Rusanov scheme: F_conv(U) = [m, m^2/rho + p, (E+p)*v].
Calculate interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Apply numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute viscous terms using centered difference for v_x, then sigma = (zeta + 4/3*eta)*v_x.
Average sigma at interfaces from neighboring cell-centered values.
Add viscous flux F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Use total interface flux F_total = F_hat + F_visc.
Integrate in time using 2-stage SSP-RK2 (Heun's method).
Choose time step each iteration: dt_conv = CFL * dx / max_j(|v_j| + c_j), dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30), dt = min(dt_conv, dt_visc).
Use CFL = 0.4 for stability.
Adjust final time step to hit T = 0.2 exactly.
Implement outflow boundary conditions by setting ghost cell values equal to nearest interior cell.
Compute final solution rho(x,T), v(x,T), p(x,T) on cell centers.
