Solve the 2D Poisson equation u_xx + u_yy = f(x,y) where f(x,y) = -2*(y*(1-y) + x*(1-x)).
The spatial domain is [0,1] x [0,1].
Apply Dirichlet boundary conditions on all four edges with u = x*(1-x)*y*(1-y).
The exact solution for verification is u(x,y) = x*(1-x)*y*(1-y).
Use a uniform grid with Nx = Ny = 120 intervals in each direction.
This creates (Nx+1) by (Ny+1) = 121 by 121 grid points including boundaries.
Set dx = dy = 1/Nx = 1/120.
Define grid points as x_i = i*dx for i = 0 to Nx and y_j = j*dy for j = 0 to Ny.
Discretize the Laplacian using the standard 5-point stencil with 2nd-order accuracy.
Solve the resulting sparse linear system for interior nodes using scipy.sparse.linalg.spsolve.
