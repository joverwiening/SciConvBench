Solve the biharmonic PDE ∇^4 u = f(x,y) where f(x,y) = 4*pi^4*sin(pi*x)*sin(pi*y) on the domain [0,1] x [0,1].
Apply simply-supported boundary conditions: u=0 and Δu=0 on all boundaries.
Use the decomposition method with v = Δu to solve two sequential Poisson problems.
First solve Δv = f with Dirichlet boundary conditions v=0 on all boundaries.
Then solve Δu = v with Dirichlet boundary conditions u=0 on all boundaries.
Use the standard 5-point Laplacian discretization on a uniform grid.
Set Nx=Ny=120 intervals in each direction, creating a (Nx+1) by (Ny+1) grid including boundaries.
Use dx=dy=1/Nx with grid points x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Solve each Poisson system using a sparse direct solver like scipy.sparse.linalg.spsolve.
Save the solution arrays x (1D), y (1D), u (2D with shape (len(y), len(x))), dx, and dy to "solution_agent_other_05_biharmonic.npz".
Save a heatmap plot of u(x,y) as "solution_agent_other_05_biharmonic.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy).
