Solve the diffusion-reaction PDE u_t = 0.01*u_xx + u*(1-u)*(u-0.25) numerically.
The spatial domain is x in [0,1] and time domain is t in [0,0.5].
Use diffusion coefficient D = 0.01 and reaction parameter a = 0.25.
Apply Dirichlet boundary conditions: u(0,t) = 1 and u(1,t) = 0.
Set initial condition u(x,0) = 0.5*(1 - tanh((x-0.5)/0.02)).
Use a uniform spatial grid with Nx = 600 intervals, giving 601 grid points including both endpoints.
Set dx = (1-0)/600 = 1/600 and x_i = 0 + i*dx for i = 0,1,...,600.
Discretize spatial derivatives using 2nd-order central differences for the diffusion term.
Use IMEX time integration with dt = 0.0002 for 2500 time steps.
Treat diffusion implicitly with backward Euler and reaction explicitly with forward Euler.
At each time step solve (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) where L is the discrete Laplacian and R(u) = u*(1-u)*(u-0.25).
Use a sparse direct solver for the linear system at each time step.
Compute the solution u(x, T=0.5) on the grid.
Save "solution_agent_diffusion_reaction_04.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
