Apply Dirichlet boundary conditions u = 0 on the entire boundary.

Use 2nd-order finite differences with variable coefficient using face-centered harmonic averaging.

Compute face coefficients using harmonic means, e.g. a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for interior unknowns only.
Solve the linear system using conjugate gradient method with tolerance 1e-10 for relative residual.
Use a simple Jacobi preconditioner if desired.
Compute u(x,y) on the full (N+1) x (N+1) grid including boundaries.
