Solve the 1D advection PDE u_t + beta * u_x = 0 numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
Set beta = 2.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution is u(x,t) = u0((x - beta*t) mod 1), where u0(x) is the initial condition.
Create a uniform spatial grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Apply 1st-order upwind finite difference for u_x, using the upwind direction determined by the sign of beta.
Use explicit forward Euler for time integration.
Set the time step using CFL=0.5: dt = CFL * dx / abs(beta).
Calculate the number of time steps as Nt = ceil(T/dt) and reset dt = T/Nt so the final time is hit exactly.
Compute u(x,T=2.0) on the periodic grid.
Save "solution_pdebench_advection_beta2.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta2.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=2.0.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
