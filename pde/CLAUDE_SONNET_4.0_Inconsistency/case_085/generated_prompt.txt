Solve the wave equation u_tt = (1.0)^2 * u_xx numerically on the domain x in [0,1], t in [0,1.0].
Use wave speed c = 1.0 as specified in the PDE equation.
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.

Set dx = 1/Nx = 1/400 = 0.0025.
Apply 2nd-order central differences for u_xx in the interior points.
Use 2nd-order central difference in time for u_tt (leapfrog/Störmer-Verlet method).
Choose dt so that CFL = c*dt/dx ≤ 0.9, so dt0 = 0.9*dx/c = 0.9*0.0025/1.0 = 0.00225.
Set Nt = ceil(T/dt0) = ceil(1.0/0.00225) and then dt = T/Nt to hit the final time exactly.

Compute u(x,dt) using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0, where v0(x) = sin(pi*x).
Apply Dirichlet boundary conditions by setting boundary nodes to zero at every time step.
Compute the solution until T = 1.0.
