Create uniform grid on [0,1] x [0,1] with Nx = Ny = 120 intervals giving 121 x 121 grid points.

Initialize first time step using Taylor expansion with initial velocity.
Set boundary nodes to zero at each time step to enforce Dirichlet conditions.
Compute solution at final time T = 1.0.
