Q: What should be the exact format and content of the parameter scalars to save in the NPZ file?
A: Save the parameter scalars as individual variables in the NPZ file:
- alpha = 1.0
- beta = 0.1  
- delta = 0.2

So the NPZ file should contain: t (array), Y (array), alpha (scalar), beta (scalar), delta (scalar).
