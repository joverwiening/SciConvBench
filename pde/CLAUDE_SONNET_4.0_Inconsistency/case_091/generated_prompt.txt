Solve the wave equation u_tt = (1.0)^2 * u_xx + sin(pi*x)*sin(2*pi*t) numerically.
The spatial domain is x in [0,1] and the time domain is t in [0,1.0].
The wave speed is c = 1.0.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1.
Use initial conditions u(x,0) = 0 and u_t(x,0) = 0.
Create a uniform spatial grid on [0,1] with Nx = 400 intervals, giving Nx+1 = 401 grid points.
Set dx = 1/Nx = 1/400.
Use 2nd-order central differences for u_xx in the interior points.
Use 2nd-order central difference in time for u_tt (leapfrog/Störmer-Verlet method).
Choose dt so that CFL = c*dt/dx ≤ 0.9, specifically dt0 = 0.9*dx/c = 0.9*dx/1.0.
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit the final time T = 1.0 exactly.
Initialize u(x,dt) using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0).
Set boundary nodes to u = 0 at every time step.
Compute the solution u(x,T) at the final time T = 1.0.
Save "solution_agent_wave_10.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_10.png".
