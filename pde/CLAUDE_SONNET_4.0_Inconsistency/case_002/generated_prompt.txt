Solve the advection PDE u_t + (-0.5)*u_x = 0 numerically.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,1.0].
The advection coefficient a = -0.5.
The initial condition is u(x,0) = exp(-100*(x-0.3)^2).
Use a uniform periodic grid with Nx = 1000 points on [0,1) with no duplicated endpoint.
The grid spacing is dx = 1/Nx.
Use first-order upwind spatial discretization with right-biased (downwind) stencil since a < 0.
Use forward Euler time integration.
Choose dt0 = 0.9*dx/|a| for the CFL condition.
Set Nt = ceil(T/dt0) where T = 1.0, then set dt = T/Nt to hit the final time exactly.
Apply periodic wrap-around indexing for boundary handling.
Compute the solution u(x,T) at the final time T = 1.0.
Save the results to "solution_agent_advection_02.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_advection_02.png".
Print the minimum value, maximum value, and discrete L2 norm sqrt(sum(u^2)*dx) of the final solution.
