Q: What should be the exact value of Nx for the spatial grid - should it be 1024 points as stated in the spatial_grid requirement, or should it follow the grid convention note that says "interpret Nx as the number of grid points including both endpoints" with dx=(b-a)/(Nx-1)?
A: Use Nx=1024 points as stated in the spatial_grid requirement. The grid convention note is overridden by the specific requirement that says "Uniform periodic grid with Nx=1024 points on [0,1). Use x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx."

For the periodic domain [0,1), you have 1024 grid points with no duplicated endpoint, and dx=1/1024.
