Use the adiabatic index Gamma = 1.6666666666666667.  
Set the CFL number for the convective time step calculation to 0.5.  
Define the spatial domain x ∈ [‑1, 1] with a uniform finite‑volume grid of Nx = 800 cells; cell centers are x_j = ‑1 + (j+0.5)*dx for j = 0,…,799 with dx = 2/800.  
Evolve the conservative variables U = [rho, m, E] as cell averages, where m = rho·v and E = p/(Gamma‑1) + 0.5·rho·v².  
Use the equation of state p = (Gamma‑1)·(E – 0.5·m²/rho) and clip rho and p to a minimum of 1e‑12 after each update to enforce positivity.  
Compute the inviscid convective flux F_conv(U) = [ m, m²/rho + p, (E+p)·v ] with v = m/rho.  
At each cell interface, evaluate the local Rusanov wave speed a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma·p/rho).  
Form the convective numerical flux F_hat = 0.5·(F_conv(U_L) + F_conv(U_R)) – 0.5·a·(U_R – U_L).  
Compute the velocity gradient v_x using a centered difference on cell‑centered v values.  
Set the viscous stress sigma = (zeta + 4/3·eta)·v_x with eta = 1e‑8 and zeta = eta.  
Approximate sigma at interfaces by averaging the neighboring cell‑centered sigma values.  
Form the viscous flux at interfaces F_visc = [ 0, –sigma, –v·sigma ] using the interface‑averaged v and sigma.  
The total interface flux is F_total = F_hat + F_visc.  
Integrate the semi‑discrete finite‑volume system in time with a 2‑stage SSP‑RK2 (Heun’s method).  
At each stage compute the convective time step dt_conv = CFL·dx / max_j( |v_j| + c_j ) and the viscous time step dt_visc = 0.5·dx² / max( zeta + 4/3·eta, 1e‑30 ); set dt = min(dt_conv, dt_visc).  
Adjust the final time step so that the simulation ends exactly at T = 0.2.  
Apply outflow (zero‑gradient) boundary conditions by setting ghost‑cell values equal to the nearest interior cell on both sides of the domain.  
Initialize the solution with a Sod shock‑tube Riemann problem: for x < 0 set rho = 1.0, v = 0.75, p = 1.0; for x ≥ 0 set rho = 0.125, v = 0.0, p = 0.1.  
After reaching the final time, compute rho(x,T), v(x,T) = m/rho, and p(x,T) on the cell centers.
