Q: Should the wave speed coefficient in the PDE be c = 2 (i.e., use u_tt = c² (u_xx + u_yy) + source) instead of the currently written (1.0)²?
A: No. According to the complete requirement the parameter is c = 1.0, so the PDE uses the coefficient (1.0)² in front of (uₓₓ + uᵧᵧ).
