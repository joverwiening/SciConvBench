Apply the standard second‑order 5‑point finite‑difference stencil to approximate the Laplacian at interior nodes.  
Assemble the resulting sparse linear system for the interior unknowns and solve it with a sparse direct solver such as scipy.sparse.linalg.spsolve.  
After solving, obtain the steady‑state solution u(x,y) on the full grid, including boundary values.  
Save the solution to a file named "solution_agent_poisson_03.npz" containing the 1‑D arrays x and y, the 2‑D array u with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]), and the scalar metadata dx and dy.  
Create a heatmap or contour plot of u(x,y) and save it as "solution_agent_poisson_03.png".
