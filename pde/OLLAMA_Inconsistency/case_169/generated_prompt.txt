Use a uniform Cartesian grid with N = 128 intervals in each direction on the domain [0, 1] × [0, 1]; define dx = dy = 1/N and grid points x_i = i·dx, y_j = j·dy for i, j = 0,…,N.  
Define the coefficient field a(x, y) = 1 + beta·(0.5 + 0.5·sin(2·π·x)·sin(2·π·y)) with beta = 2, evaluated at every grid point (including boundaries).  
Impose Dirichlet boundary conditions u = 0 on the entire boundary of the domain.  
For each interior node (i = 1,…,N‑1, j = 1,…,N‑1) discretize the PDE with second‑order finite differences and variable coefficients using face‑centered harmonic averaging:

Compute the face coefficients by harmonic means, e.g. a_{i+½,j} = 2·a_{i,j}·a_{i+1,j}/(a_{i,j}+a_{i+1,j}), and analogously for a_{i‑½,j}, a_{i,j+½}, a_{i,j‑½}.  
Assemble the sparse linear system A u_int = b for the (N‑1)² interior unknowns, where b is a vector of ones (one for each interior node).  
Solve the linear system with the conjugate gradient method to a relative residual tolerance of 1e‑10, using a Jacobi preconditioner if desired.
