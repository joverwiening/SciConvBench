Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx on the periodic domain x∈[0,1) with nu = 0.001, initial condition u(x,0)=sin(2*pi*x), and final time T = 1.0.

Use a uniform periodic grid with Nx = 512 points, x_j = j*dx for j = 0,…,511 where dx = 1/Nx.

Determine the time step using CFL = 0.4 and an estimated maximum wave speed of 1: dt0 = CFL*dx/1. Set Nt = ceil(T/dt0) = 1280 and then dt = T/Nt = 0.00078125 so that the final time is reached exactly.

Advance the solution from t=0 to t=T with Strang splitting for each full time step dt:
1. Diffusion half-step (dt/2) solved exactly in Fourier space:
   - Compute û = FFT(u).
   - Compute wave numbers k = 2*pi*fftfreq(Nx, d=dx).
   - Multiply û by exp(-nu*k^2*(dt/2)).
   - Obtain u = real(IFFT(û)).
2. Advection full-step (dt) for the inviscid Burgers equation using a finite‑volume update with the Rusanov (local Lax‑Friedrichs) flux:
   - Define flux f(u)=0.5*u^2.
   - For each interface between u_left = u[j] and u_right = u[(j+1) mod Nx], compute
     alpha = max(|u_left|, |u_right|),
     F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
   - For each cell j, set
     F_plus = flux at interface (j, j+1),
     F_minus = flux at interface (j-1, j),
     u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
   - Replace u with u_new.
3. Diffusion half-step again identical to step 1.

After completing Nt steps, the solution u(x,T) is obtained.

Output requirements:
- Compute and store the solution at T = 1.0 on the periodic grid.
- Save a NumPy .npz file named "solution_pdebench_burgers_nu1em3.npz" containing the arrays: x (length Nx), u (length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
- Generate a line plot of u versus x and save it as "solution_pdebench_burgers_nu1em3.png".
- Print the following diagnostics at T:
  * min(u)
  * max(u)
  * discrete mean value mean(u) (should be approximately conserved)
  * discrete L2 norm sqrt(sum(u^2)*dx).
