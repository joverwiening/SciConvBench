Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 0.2 on the periodic domain x ∈ [0,1) for final time T = 1.0. Use the initial condition u(x,0) = sin(2*pi*x) and periodic boundary condition u(0,t) = u(1,t).  

Create a uniform periodic grid with Nx = 512 points: dx = 1/Nx, x_j = j*dx for j = 0,…,Nx‑1.  

Compute the time step using CFL = 0.4 based on an estimated maximum wave speed of 1: dt0 = CFL*dx/1.0. Set Nt = ceil(T/dt0) and then dt = T/Nt so that the final time is reached exactly.  

Advance the solution from t = 0 to t = T using Strang splitting with three substeps per full time step:  

A. Diffusion half‑step (duration dt/2):  
   • Compute the Fourier transform û = FFT(u).  
   • Compute wave numbers k = 2*pi*fftfreq(Nx, d=dx).  
   • Multiply û by exp(-nu*k^2*(dt/2)).  
   • Obtain the updated u by inverse FFT and keep the real part.  

B. Advection full‑step (duration dt) for the inviscid Burgers equation using a finite‑volume Rusanov flux:  
   • Define flux f(u) = 0.5*u^2.  
   • For each interface between cells j and j+1 (periodic indexing), compute  
        alpha = max(|u_j|, |u_{j+1}|)  
        F_{j+1/2} = 0.5*(f(u_j) + f(u_{j+1})) - 0.5*alpha*(u_{j+1} - u_j).  
   • Update each cell j by  
        u_new_j = u_j - (dt/dx)*(F_{j+1/2} - F_{j-1/2}).  
   • Replace u with u_new after the advection substep.  

C. Diffusion half‑step again, identical to step A.  

Repeat the Strang splitting sequence Nt times.  

After reaching t = T, compute and store the solution u(x,T).  

Save the results in a NumPy .npz file named "solution_pdebench_burgers_nu0p2.npz" containing the arrays:  
   • x (length Nx)  
   • u (length Nx)  
and the scalars: nu, T, dx, dt, Nx, Nt.  

Create a line plot of u versus x and save it as "solution_pdebench_burgers_nu0p2.png".  

Print the following diagnostics at final time:  
   • min(u)  
   • max(u)  
   • discrete mean value mean(u) (should be approximately conserved)  
   • discrete L2 norm sqrt( sum(u^2) * dx ).
