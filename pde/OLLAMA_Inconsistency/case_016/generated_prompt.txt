Solve the PDE u_t + u*u_x = 0.02*u_xx + sin(2*pi*x)*cos(2*pi*t) on the periodic spatial domain [0,1) for time t in [0,1.0].  
Use a uniform grid with Nx = 1000 points, dx = 1/Nx, and grid points x_i = i*dx for i = 0,…,Nx‑1.  
Set the time step dt = 1e-4 and perform Nt = 10000 steps so that the final time T = 1.0 is reached exactly.  
Initialize the solution with u(x,0) = 0.  
Discretize the convection term in conservative form using the Rusanov (local Lax–Friedrichs) flux:  
F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where f(u)=0.5*u^2 and alpha_{i+1/2}=max(|u_i|,|u_{i+1}|).  
Approximate (f(u))_x by (F_{i+1/2}-F_{i-1/2})/dx with periodic wrap‑around indexing.  
Discretize the diffusion term with the second‑order central difference u_xx ≈ (u_{i+1}-2*u_i+u_{i-1})/dx^2, also using periodic indexing.  
Treat the source term S_i^n = sin(2*pi*x_i)*cos(2*pi*t_n) explicitly at the current time level n.  
Apply a first‑order IMEX scheme:  
(u^{n+1}_i - u^n_i)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu*(u^{n+1}_{i+1}-2*u^{n+1}_i+u^{n+1}_{i-1})/dx^2 + S_i^n, with nu = 0.02.  
Rearrange to the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term + dt*S^n, where L is the periodic Laplacian matrix.  
Solve the linear system at each step using scipy.sparse.linalg.spsolve.  
After the final step, compute u(x,T) on the grid.
