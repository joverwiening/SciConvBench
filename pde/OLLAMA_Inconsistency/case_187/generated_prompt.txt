Solve the PDE u_t = nu*u_xx + rho*u*(1 - u) on the spatial domain x in [0,1) with periodic boundary conditions and on the time interval t in [0,1.0].  
Set the parameters nu = 2.0 and rho = 5.0.  
Create a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and x_j = j*dx for j = 0,…,511.  
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
Initialize the solution with u(x,0) = 0.25 + 0.1*sin(2*pi*x).  
Advance the solution using Strang splitting for each full time step dt:  
(A) Perform a diffusion half-step of duration dt/2 by computing the FFT of u, multiplying each Fourier mode by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then applying the inverse FFT and taking the real part.  
(B) Perform a reaction full-step of duration dt by updating each grid point with the exact logistic solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).  
(C) Perform another diffusion half-step identical to step (A).  
After completing all Nt steps, compute the solution u(x,T) on the periodic grid.  
Save the arrays x (length Nx) and u (length Nx) together with the scalars nu, rho, T, dx, dt, Nx, and Nt to a file named "solution_pdebench_reacdiff_nu2_rho5.npz".  
Create a line plot of u(x,T) versus x and save it as "solution_pdebench_reacdiff_nu2_rho5.png".  
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time T.
