Use a uniform periodic grid with Nx = 1200 points on the interval [0,1) (no duplicated endpoint) and compute dx = 1/Nx.  
Define the advection speed a(x) = 1 + 0.5*sin(2*pi*x) and set amax = 1.5.  
Compute the provisional time step dt0 = 0.9*dx/amax.  
Set the final simulation time T = 0.5.  
Determine the number of time steps Nt = ceil(T/dt0) and then set the actual time step dt = T/Nt so that the final time is reached exactly.  
Initialize the solution u(x,0) = sin(2*pi*x) on the grid.  
For each time step, update u using forward Euler and a left‑biased upwind spatial discretization because a(x) > 0 everywhere:  
u_i^{n+1} = u_i^{n} - dt * a(x_i) * (u_i^{n} - u_{i-1}^{n}) / dx, applying periodic indexing for i‑1.  
After Nt steps, obtain u(x,T) at T = 0.5.  
Save a NumPy .npz file named "solution_agent_advection_03.npz" containing the arrays x (1‑D), u (1‑D, same length as x), and the scalar metadata values T, dx, dt.  
Create a line plot of u versus x and save it as "solution_agent_advection_03.png".
