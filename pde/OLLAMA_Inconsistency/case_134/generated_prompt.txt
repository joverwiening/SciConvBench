Define the spatial domain as the periodic interval [0,1) with Nx = 512 uniformly spaced grid points x_j = j*dx for j = 0,…,511 where dx = 1/Nx.

Set the parameters D = 0.01, gamma = 1.0, and define the potential U(x) = cos(2*pi*x) and its derivative U'(x) = -2*pi*sin(2*pi*x).

Initialize the solution at t = 0 with u(x,0) = 1.0 + 0.2*sin(2*pi*x) evaluated at each grid point.

Compute the drift velocity b(x) = U'(x)/gamma analytically; its maximum absolute value is max|b| = 2*pi.

Choose the time step dt as dt = min(0.4*dx/max|b|, 0.2*dx^2/D). With the given parameters this yields dt = 0.2*dx^2/D. Set the number of time steps Nt = ceil(T/dt) where T = 1.0, and then recompute dt = T/Nt.

Advance the solution from t = 0 to t = T using the explicit second‑order strong stability preserving Runge‑Kutta method (SSP‑RK2):
1. u^{(1)} = u^n + dt * RHS(u^n)
2. u^{n+1} = 0.5*u^n + 0.5*(u^{(1)} + dt * RHS(u^{(1)}))

The right‑hand side RHS(u) is given by
RHS(u) = D * u_xx - ∂_x(F),
where the diffusion term u_xx is approximated with a second‑order central difference:
u_xx_j = (u_{j+1} - 2*u_j + u_{j-1}) / dx^2,
using periodic indexing.

Treat the drift term in conservative form with flux F = b(x)*u. Evaluate b at cell faces x_{j+1/2} = (x_j + x_{j+1})/2 as b_{j+1/2} = U'(x_{j+1/2})/gamma. Compute the numerical flux at each face using an upwind finite‑volume scheme:
if b_{j+1/2} ≥ 0 then F_{j+1/2} = b_{j+1/2} * u_j else F_{j+1/2} = b_{j+1/2} * u_{j+1}.
Then approximate the spatial derivative of the flux with a first‑order difference:
∂_x(F)_j = (F_{j+1/2} - F_{j-1/2}) / dx,
again applying periodic wrap‑around for indices.

After completing Nt time steps, obtain the solution u(x,T) on the periodic grid.

Save the results to a NumPy .npz file named "solution_molk_033.npz" containing the arrays:
- x : 1‑D array of length Nx,
- u : 1‑D array of length Nx (solution at T),
and the scalar values:
- T, dx, Nx, D, gamma.

Create a line plot of u versus x and save it as "solution_molk_033.png".

Print the following diagnostics for the final solution:
- Minimum value of u,
- Maximum value of u,
- Mean value of u (average over all grid points),
- Discrete L2 norm sqrt( Σ_j u_j^2 * dx ).

Since no exact reference solution is provided, no error metrics are required.
