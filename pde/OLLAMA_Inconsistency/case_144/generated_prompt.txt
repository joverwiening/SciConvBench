Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx on the periodic domain x ∈ [0,1) with nu = 0.02, initial condition u(x,0) = sin(2*pi*x), and final time T = 1.0.

Use a uniform periodic grid with Nx = 512 points, x_j = j*dx for j = 0,…,511 where dx = 1/Nx.

Determine the time step using CFL = 0.4 based on an estimated maximum wave speed of 1: dt0 = CFL*dx/1.0. Set Nt = ceil(T/dt0) and then recompute dt = T/Nt so that the final time is reached exactly.

Advance the solution from t = 0 to t = T using Strang splitting for each full time step dt:
1. Diffusion half-step (dt/2): transform u to Fourier space with FFT, multiply each mode by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then inverse FFT and keep the real part.
2. Advection full-step (dt): apply a finite‑volume update with the Rusanov (local Lax‑Friedrichs) flux. For each interface between u_left = u[j] and u_right = u[(j+1) mod Nx], compute alpha = max(|u_left|,|u_right|), flux F = 0.5*(0.5*u_left^2 + 0.5*u_right^2) - 0.5*alpha*(u_right - u_left). Update each cell j by u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the right interface of cell j and F_minus is the flux at the left interface.
3. Diffusion half-step again, identical to step 1.

After completing Nt steps, obtain the solution u(x,T) at T = 1.0.

Save the results to a NumPy .npz file named "solution_pdebench_burgers_nu0p02.npz" containing the arrays:
- x (length Nx)
- u (length Nx)

and the scalar values:
- nu
- T
- dx
- dt
- Nx
- Nt

Create a line plot of u versus x and save it as "solution_pdebench_burgers_nu0p02.png".

Print the following diagnostics for the final solution:

- Maximum value of u (max(u))

- Discrete L2 norm sqrt(sum(u^2)*dx)
