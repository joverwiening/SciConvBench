Use a uniform periodic grid with Nx = 512 points on the interval [0,1) defined by x_j = j*dx for j = 0,…,511 where dx = 1/Nx.
Set the viscosity parameter nu = 0.01.
Initialize the solution u(x,0) = sin(2*pi*x) at the grid points.
Compute the time step using CFL = 0.4 and an estimated maximum wave speed of 1: dt0 = CFL*dx/1.0, Nt = ceil(T/dt0) with T = 1.0, and then set dt = T/Nt so that the final time is reached exactly.
Advance the solution from t = 0 to t = T using Strang splitting with three substeps per full time step:
(A) Diffusion half-step of duration dt/2 solved exactly in Fourier space: compute the FFT of u, multiply each Fourier coefficient by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx,d=dx), then inverse FFT and keep the real part.
(B) Advection full-step of duration dt for the inviscid Burgers equation using a finite‑volume update with the Rusanov (local Lax‑Friedrichs) flux: for each interface between u_left = u[j] and u_right = u[(j+1) mod Nx], compute alpha = max(|u_left|,|u_right|), flux F = 0.5*(0.5*u_left^2 + 0.5*u_right^2) - 0.5*alpha*(u_right - u_left); then update each cell j by u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus and F_minus are the fluxes at the right and left interfaces of cell j, respectively; replace u with u_new.
(C) Diffusion half-step again identical to step (A).
Repeat the three substeps Nt times.
After the final time step, compute the solution u(x,T) on the grid.
Save the arrays x (length Nx) and u (length Nx) together with the scalars nu, T, dx, dt, Nx, and Nt in a NumPy .npz file named "solution_pdebench_burgers_nu0p01.npz".
Create a line plot of u versus x and save it as "solution_pdebench_burgers_nu0p01.png".
Print the minimum value of u, the maximum value of u, the discrete mean value mean(u) (which should be approximately conserved), and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time.
