Use a uniform periodic grid with Nx = Ny = 256 points on the domain [0,1) × [0,1). Compute grid spacing dx = dy = 1/256 and grid coordinates x_i = i*dx, y_j = j*dy for i,j = 0,…,255.  
Set the advection speeds a = 1.0 and b = 0.5.  
Initialize the solution with u(x,y,0) = sin(2 π x) · cos(2 π y).  
Discretize spatial derivatives using first‑order upwind differences: for a > 0 use backward differences in x, and for b > 0 use backward differences in y. Apply periodic wrap‑around indexing for both directions.  
Choose the time step dt to satisfy the CFL condition a·dt/dx + b·dt/dy ≤ 0.9. Compute dt₀ = 0.9 / (a/dx + b/dy). Set the final simulation time T = 1.0, compute Nt = ceil(T/dt₀), and then set dt = T/Nt so that the final time is reached exactly.  
Integrate in time with the forward Euler method using the chosen dt for Nt steps.  
After reaching t = T, compute the reference solution u_exact(x,y,T) = sin(2 π (x − a·T)) · cos(2 π (y − b·T)).  
Save the numerical solution to "solution_agent_advection_04.npz" containing the 1‑D arrays x and y, the 2‑D array u with shape (Ny, Nx) such that u[j,i] = u(x[i], y[j]) at T, and the scalar metadata T, dx, dy, dt.  
Create a heatmap or contour plot of u(x,y,T) and save it as "solution_agent_advection_04.png".  
Print the following diagnostics:
