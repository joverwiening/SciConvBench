Solve the wave equation u_tt = u_xx + sin(pi*x)*sin(2*pi*t) on the spatial interval x∈[0,1] and time interval t∈[0,1] with Dirichlet boundary conditions u(0,t)=u(1,t)=0 and initial conditions u(x,0)=0, u_t(x,0)=0.  

Use a uniform grid with Nx=400 intervals, giving Nx+1=401 grid points x_i = i*dx for i=0,…,400 where dx = 1/Nx = 0.0025.  

Set the wave speed c = 1.0. Compute the time step dt0 = 0.9*dx/c = 0.9*dx = 0.00225. Choose the number of time steps Nt = ceil(T/dt0) = 445, and set the actual time step dt = T/Nt = 1.0/445 ≈ 0.002247191.  

Discretize the spatial second derivative u_xx with a second‑order central difference on interior points (i=1,…,Nx‑1).  

Integrate in time with the standard second‑order central difference (leapfrog/Störmer–Verlet):  

u_i^{n+1} = 2*u_i^{n} - u_i^{n-1} + dt^2 * (c^2 * (u_{i+1}^{n} - 2*u_i^{n} + u_{i-1}^{n})/dx^2 + f_i^{n})  

where f_i^{n} = sin(pi*x_i) * sin(2*pi*t_n).  

Initialize the solution using the Taylor start:  

u_i^{0} = 0,  
u_i^{1} = u_i^{0} + dt*u_t(x_i,0) + 0.5*dt^2 * (c^2 * u_xx(x_i,0) + f(x_i,0)) = 0.  

At each time step enforce the Dirichlet boundary values u_0^{n}=0 and u_{Nx}^{n}=0.  

After completing Nt time steps, obtain the solution u(x,T) at the final time T=1.0 on the grid x.  

Save the results to a NumPy .npz file named "solution_agent_wave_10.npz" containing the arrays:  
- x : 1‑D array of grid coordinates (length Nx+1)  
- u : 1‑D array of the solution at T (same length)  

and the scalar metadata: T, dx, dt.  

Create a line plot of u versus x and save it as "solution_agent_wave_10.png".  

Print the following diagnostics for the final solution:
