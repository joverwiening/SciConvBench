Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx on the periodic domain x ∈ [0,1) for time t ∈ [0,1.0] with nu = 0.1.  
Use a uniform periodic grid with Nx = 512 points, x_j = j*dx for j = 0,…,511 where dx = 1/Nx.  
Set the initial condition u(x,0) = sin(2*pi*x).  
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.  

Time integration:
- Compute dt0 = CFL * dx / 1.0 with CFL = 0.4 (max wave speed ≈ 1).  
- Choose Nt = ceil(1.0 / dt0) and set dt = 1.0 / Nt so that the final time is reached exactly.  
- For each time step perform Strang splitting:
  1. Diffusion half-step (dt/2) in Fourier space:  
     - Compute û = FFT(u).  
     - k = 2*pi*fftfreq(Nx, d=dx).  
     - Multiply û by exp(-nu * k^2 * (dt/2)).  
     - Obtain u by inverse FFT and keep the real part.  
  2. Advection full-step (dt) for the inviscid Burgers equation using a finite‑volume Rusanov flux:  
     - Define f(u) = 0.5*u^2.  
     - For each interface between cells j and j+1 (periodic indexing), compute  
       alpha = max(|u_j|, |u_{j+1}|)  
       F_{j+1/2} = 0.5*(f(u_j) + f(u_{j+1})) - 0.5*alpha*(u_{j+1} - u_j).  
     - Update each cell:  
       u_new_j = u_j - (dt/dx)*(F_{j+1/2} - F_{j-1/2}).  
     - Replace u with u_new after the advection substep.  
  3. Diffusion half-step again identical to step 1.  

After Nt steps, obtain the solution u(x,T) at T = 1.0.

- Save a line plot of u versus x as "solution_pdebench_burgers_nu0p1.png".  
- Print the following diagnostics at T = 1.0: min(u), max(u), the discrete mean value mean(u) (should be approximately conserved), and the discrete L2 norm sqrt( sum(u^2) * dx ).
