Solve the 1D periodic advection equation u_t + 0.2*u_x = 0 on the domain x∈[0,1) with periodic boundary conditions and final time T = 2.0.  
Use a uniform periodic grid with Nx = 512 points: x_j = j*dx for j = 0,…,511 where dx = 1/Nx = 1/512.  
Discretize the spatial derivative u_x with a first‑order upwind finite difference using the upwind direction determined by the sign of beta (beta > 0, so use backward difference).  
Integrate in time with explicit forward Euler.  
Set the time step using CFL = 0.5: initial dt = CFL*dx/|beta| = 0.5*dx/0.2 = 2.5*dx. Compute the number of steps Nt = ceil(T/dt) = 410, then reset dt = T/Nt = 2.0/410.  
Initialize the solution with u(x,0) = sin(2πx) + 0.5*sin(4πx).  
Advance the solution for Nt steps to reach exactly T = 2.0.  
After the final step compute the reference solution u_ref(x,T) = u0((x - beta*T) mod 1) on the same grid.  
Save the results to a NumPy .npz file named "solution_pdebench_advection_beta0p2.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values beta, T, dx, dt, Nx, Nt.  
Create a line plot of u(x,T) versus x and save it as "solution_pdebench_advection_beta0p2.png".  
Print the following diagnostics: the minimum of u, the maximum of u, the discrete L2 norm sqrt(∑_j u_j^2 * dx), the maximum absolute error max|u - u_ref|, and the discrete L2 error sqrt(∑_j (u_j - u_ref_j)^2 * dx).
