Use a uniform periodic grid with Nx = 512 points on the interval [0,1). Compute dx = 1/Nx and define grid points x_j = j*dx for j = 0,…,511.  
Set the viscosity parameter nu = 0.4.  
Initialize the solution as u(x,0) = sin(2 π x) evaluated at the grid points.  
Choose the time step using CFL = 0.4 with an estimated maximum wave speed of 1: compute dt0 = CFL*dx, set Nt = ceil(1.0/dt0) = 1280, and then set dt = 1.0/Nt = 0.00078125 so that the final time T = 1.0 is reached exactly.  
For each of the Nt time steps perform a Strang splitting:  
A. Diffusion half‑step: compute the Fourier transform û = FFT(u), multiply each mode by exp(‑nu*k^2*dt/2) where k = 2 π fftfreq(Nx, d=dx), then obtain u = real(IFFT(û)).  
B. Advection full‑step: use a finite‑volume update with the Rusanov flux. For each interface between cells j and j+1 (periodic indexing) compute f(u)=0.5*u^2, α = max(|u_j|,|u_{j+1}|), and flux F = 0.5*(f(u_j)+f(u_{j+1})) – 0.5*α*(u_{j+1}–u_j). Update each cell by u_new_j = u_j – (dt/dx)*(F_{j+½} – F_{j‑½}). Replace u with u_new after this substep.  
C. Diffusion half‑step again, identical to step A.  
After completing all Nt steps, the solution u(x,T) at T = 1.0 is obtained.
