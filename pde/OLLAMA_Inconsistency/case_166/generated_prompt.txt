Solve the 1D compressible Navier–Stokes equations (no heat conduction) on the domain x ∈ [‑1, 1] for time t ∈ [0, 0.2] using a uniform finite‑volume grid with Nx = 800 cells. Cell centers are x_j = ‑1 + (j+0.5)·dx, where dx = 2/Nx.

Evolve the conservative variables U = [ρ, m, E] (cell averages) with the following definitions:
- Momentum m = ρ v.
- Total energy E = p/(Γ‑1) + 0.5 ρ v².
- Viscous stress σ = (ζ + 4/3 η) ∂v/∂x, with ζ = η = 1e‑8.
- Equation of state: p = (Γ‑1)·(E – 0.5 m²/ρ), using Γ = 1.6666666666666667. Clip ρ and p to a floor of 1e‑12 if needed.

Initial condition (Riemann shock‑tube) with discontinuity at x = 0:
- For x < 0: ρ = 1.0, v = 0.0, p = 10.0.
- For x ≥ 0: ρ = 1.0, v = 0.0, p = 0.1.

Boundary conditions: transmissive/outflow (zero‑gradient) at both x = –1 and x = 1 (ghost cells set equal to the nearest interior cell).

Numerical method:
1. Compute convective flux using the Rusanov (local Lax‑Friedrichs) flux:
   - Primitive variables: v = m/ρ, c = sqrt(Γ p/ρ).
   - Convective flux F_conv(U) = [m, m²/ρ + p, (E + p) v].
   - Interface wave speed a = max(|v_L| + c_L, |v_R| + c_R).
   - Numerical flux: F̂ = 0.5·(F_conv(U_L) + F_conv(U_R)) – 0.5·a·(U_R – U_L).
2. Compute viscous terms:
   - Obtain cell‑centered v values, compute ∂v/∂x with a centered difference.
   - σ = (ζ + 4/3 η)·∂v/∂x at cell centers.
   - Approximate σ at interfaces by averaging neighboring σ values.
   - Viscous flux at interfaces: F_visc = [0, ‑σ, ‑v σ] using interface‑averaged v and σ.
3. Total interface flux: F_total = F̂ + F_visc.
4. Time integration: 2‑stage SSP‑RK2 (Heun’s method) applied to the semi‑discrete finite‑volume system.
5. Time step selection each stage:
   - dt_conv = CFL·dx / max_j(|v_j| + c_j), with CFL = 0.6.
   - dt_visc = 0.5·dx² / max(ζ + 4/3 η, 1e‑30).
   - dt = min(dt_conv, dt_visc). Adjust the final step so that t = 0.2 exactly.
