Use the adiabatic index Γ = 1.6666666666666667.
Set the dynamic viscosity η = 1e-08 and bulk viscosity ζ = η.
Use a CFL number of 0.5 for the time‑step calculation.
Define the spatial domain x ∈ [‑1, 1] with a uniform finite‑volume grid of Nx = 800 cells; cell centers are x_j = ‑1 + (j+0.5)·dx, where dx = 2/Nx.
Evolve the conservative variables U = [ρ, m, E] (cell‑averaged density, momentum, and total energy) from t = 0 to T = 0.2.
Initialize the solution with a Riemann shock‑tube condition at x = 0:
for x < 0: ρ = 0.445, v = 0.698, p = 3.528;
for x ≥ 0: ρ = 0.5, v = 0.0, p = 0.571.
Compute the primitive variables from the conservative ones using the equation of state p = (Γ‑1)·(E – 0.5·m²/ρ) and enforce ρ, p ≥ 1e‑12.
Apply transmissive (zero‑gradient) outflow boundary conditions by copying the nearest interior cell values into ghost cells at both domain ends.
Compute the inviscid convective flux using the Rusanov (local Lax‑Friedrichs) flux:
F_conv(U) = [m, m²/ρ + p, (E + p)·v] with v = m/ρ,
wave speed a = max(|v_L| + c_L, |v_R| + c_R), c = sqrt(Γ·p/ρ),
numerical flux F̂ = 0.5·(F_conv(U_L) + F_conv(U_R)) – 0.5·a·(U_R – U_L).
Compute the viscous stress σ = (ζ + 4/3·η)·v_x, where v_x is obtained by a centered difference of cell‑centered velocities; average σ to interfaces.
Add viscous contributions at interfaces:
F_visc = [0, ‑σ, ‑v·σ] using interface‑averaged v and σ.
Total interface flux: F_total = F̂ + F_visc.
Integrate in time with a 2‑stage SSP‑RK2 (Heun’s method) applied to the semi‑discrete finite‑volume system.
At each stage compute the time step:
dt_conv = CFL·dx / max_j(|v_j| + c_j),
dt_visc = 0.5·dx² / max(ζ + 4/3·η, 1e‑30),
dt = min(dt_conv, dt_visc),
adjusting the final step so that t reaches exactly T = 0.2.
After the final time, compute the primitive fields ρ(x,T), v(x,T), and p(x,T) at the cell centers.

Create a line plot of ρ, v, and p versus x at T and save it as "solution_pdebench_cns1d_sod6_eta1em8_outflow.png" (either three panels in one figure or three separate figures).
Print the following diagnostics:
