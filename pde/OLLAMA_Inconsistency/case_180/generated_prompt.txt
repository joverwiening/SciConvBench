Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) with nu = 1.0 and rho = 1.0 on the periodic domain x in [0,1) and t in [0,1.0]. Use a uniform periodic grid with Nx = 512 points, x_j = j*dx for j = 0,…,511, and dx = 1/Nx. Use a fixed time step dt = 0.001 for Nt = 1000 steps so that the final time T = 1.0 is reached exactly. Advance the solution with Strang splitting each full time step dt: first apply a diffusion half-step of duration dt/2 solved exactly in Fourier space by multiplying the Fourier coefficients by exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx); then apply a reaction full-step of duration dt solved exactly pointwise using the logistic update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)); finally apply another diffusion half-step identical to the first. Initialize the solution with u(x,0) = 0.25 + 0.1*sin(2*pi*x). After reaching T = 1.0, compute u(x,T) on the grid. Save a file named "solution_pdebench_reacdiff_nu1_rho1.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values nu, rho, T, dx, dt, Nx, and Nt. Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu1_rho1.png". Print the minimum, maximum, mean of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
