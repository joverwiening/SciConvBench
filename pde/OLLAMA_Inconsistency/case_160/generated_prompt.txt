Solve the 1D compressible Navier–Stokes equations without heat conduction on the domain x ∈ [‑1, 1] for time t ∈ [0, 0.2] using a uniform finite‑volume grid with Nx = 800 cells (cell centers x_j = –1 + (j+0.5)·dx, dx = 2/800). Evolve the conservative variables U = [ρ, m, E] where m = ρ v and E = p/(Γ‑1) + 0.5 ρ v². Use Γ = 1.6666666666666667, η = 1e‑8, ζ = η, and set the viscous stress σ = (ζ + 4/3 η) ∂v/∂x.

Apply transmissive (zero‑gradient) outflow boundary conditions at both x = –1 and x = 1 by copying the nearest interior cell values into ghost cells.

Initialize with a Sod shock‑tube Riemann problem at x = 0:
- For x < 0: ρ = 1.0, v = 0.0, p = 1.0.
- For x ≥ 0: ρ = 0.125, v = 0.0, p = 0.1.

Use the following numerical method:
- Compute the convective flux with the Rusanov (local Lax‑Friedrichs) flux:
  F_conv(U) = [m, m²/ρ + p, (E + p) v] with v = m/ρ.
  At each interface, compute the maximum wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Γ p/ρ).
  Numerical convective flux: F̂ = 0.5·(F_conv(U_L) + F_conv(U_R)) – 0.5·a·(U_R – U_L).
- Compute the velocity gradient ∂v/∂x with a centered difference on cell‑centered v values.
  Evaluate σ at cell centers, then average neighboring σ values to obtain σ at interfaces.
  Form the viscous flux at interfaces: F_visc = [0, –σ, –v σ] using the interface‑averaged v and σ.
- Total interface flux: F_total = F̂ + F_visc.
- Advance the semi‑discrete finite‑volume system with a 2‑stage SSP‑RK2 (Heun’s method).
- Determine the time step each stage as
  dt_conv = CFL·dx / max_j(|v_j| + c_j) with CFL = 0.5,
  dt_visc = 0.5·dx² / max(ζ + 4/3 η, 1e‑30),
  dt = min(dt_conv, dt_visc).
  Adjust the final step so that the simulation ends exactly at T = 0.2.

Enforce positivity of density and pressure after each update by clipping ρ and p to a floor of 1e‑12, using the equation of state p = (Γ‑1)·(E – 0.5·m²/ρ).

After reaching the final time:
- Compute primitive variables ρ, v = m/ρ, and p from the conserved variables at cell centers.

- Create a line plot of ρ(x), v(x), and p(x) versus x at T and save it as "solution_pdebench_cns1d_sod1_eta1em8_outflow.png" (either three panels in one figure or three separate figures).
- Print the minimum and maximum values of ρ and p for a positivity check, and print the mean of ρ over the domain for a mass‑conservation check.
