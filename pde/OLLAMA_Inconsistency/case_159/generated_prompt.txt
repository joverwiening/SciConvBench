Set the shear viscosity eta = 1e-8 and bulk viscosity zeta = eta = 1e-8.  
Define the spatial domain x ∈ [‑1, 1] and the final time T = 0.2.

Evolve the conservative variables U = [rho, m, E] where m = rho·v and E = p/(Gamma‑1) + 0.5·rho·v² as cell averages.  
Use the equation of state p = (Gamma‑1)·(E – 0.5·m²/rho) and enforce positivity by clipping rho and p to a floor of 1e‑12 if necessary.  
Apply transmissive (zero‑gradient) outflow boundary conditions by setting ghost‑cell values equal to the nearest interior cell.  
Initialize the solution with a Riemann shock‑tube condition at x = 0: for x < 0 set rho = 1.0, v = 0.0, p = 1.0; for x ≥ 0 set rho = 0.1, v = 0.0, p = 0.01.  
Compute the convective flux F_conv(U) = [ m, m²/rho + p, (E + p)·v ] with v = m/rho.  
At each cell interface compute the local wave speed a = max( |v_L| + c_L, |v_R| + c_R ) where c = sqrt(Gamma·p/rho).  
Form the Rusanov numerical flux F_hat = 0.5·(F_conv(U_L) + F_conv(U_R)) – 0.5·a·(U_R – U_L).  
Compute the velocity gradient v_x using a centered difference on cell‑centered v values.  
Calculate the viscous stress sigma = (zeta + 4/3·eta)·v_x and approximate sigma at interfaces by averaging neighboring cell‑centered sigma values.  
Form the viscous flux at interfaces F_visc = [ 0, –sigma, –v·sigma ] using the interface‑averaged v and sigma.  
Add convective and viscous contributions to obtain the total interface flux F_total = F_hat + F_visc.  
Integrate the semi‑discrete finite‑volume system in time with a 2‑stage SSP‑RK2 (Heun’s method).  
At each stage choose the time step dt as dt = min( dt_conv, dt_visc ) where  
dt_conv = CFL·dx / max_j( |v_j| + c_j ),  
dt_visc = 0.5·dx² / max( zeta + 4/3·eta, 1e‑30 ),
