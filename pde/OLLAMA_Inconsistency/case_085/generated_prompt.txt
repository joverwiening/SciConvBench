Solve the wave equation u_tt = (1.0)^2 * u_xx on the spatial domain x ∈ [0,1] and time interval t ∈ [0,1.0] using the wave speed c = 1.0.

Create a uniform spatial grid with Nx = 400 intervals, giving Nx+1 = 401 grid points x_i = i*dx where dx = 1/Nx = 0.0025.

Choose the time step dt so that the Courant number satisfies c*dt/dx ≤ 0.9. Compute the provisional step dt0 = 0.9*dx/c, set Nt = ceil(T/dt0) with T = 1.0, and then set dt = T/Nt so that the final time is reached exactly.

Discretize the spatial second derivative u_xx with a second‑order central difference on interior points.

Integrate in time with the standard second‑order central difference (leapfrog/Störmer–Verlet) for u_tt. Initialise the solution at t = 0 with u^0_i = 0 and the first time level using the Taylor expansion:
u^1_i = u^0_i + dt*v0_i + 0.5*dt^2*(c^2 * u_xx^0_i),
where v0_i = sin(π*x_i) and u_xx^0_i is the discrete second derivative of u^0 (which is zero).

Enforce Dirichlet boundary conditions u(0,t) = u(1,t) = 0 at every time step by setting the boundary nodes to zero.

Advance the solution for n = 1,…,Nt‑1 using:
u^{n+1}_i = 2*u^{n}_i - u^{n-1}_i + dt^2 * c^2 * u_xx^{n}_i
for interior nodes i = 1,…,Nx‑1.

After the final step (t = T), obtain the numerical solution u(x,T) on the grid.

Save the results to a NumPy .npz file named "solution_agent_wave_04.npz" containing the arrays:
- x : 1‑D array of grid coordinates,
- u : 1‑D array of the solution at T,
and the scalar metadata values T, dx, dt.

Create a line plot of u(x,T) versus x and save it as "solution_agent_wave_04.png".

Print the following diagnostics:
- min(u) and max(u),
- discrete L2 norm sqrt( Σ_i u_i^2 * dx ),
- maximum absolute error max|u_i - u_exact(x_i,T)|,
- L2 error sqrt( Σ_i (u_i - u_exact(x_i,T))^2 * dx ),

where the exact solution is u_exact(x,t) = (1/(π)) * sin(π*t) * sin(π*x) evaluated at t = T.
