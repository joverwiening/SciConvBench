Solve the wave equation with damping  
u_tt + 0.5*u_t = (1.0)^2 * u_xx  

Domain: x ∈ [0,1], t ∈ [0,3.0]  

Parameters: c = 1.0, gamma = 0.5  

Boundary conditions: Dirichlet on both ends, enforce u = 0 at x = 0 and x = 1, and also set v = 0 at those boundaries at every RK substage.  

Initial conditions: u(x,0) = sin(π x), v(x,0) = u_t(x,0) = 0  

Spatial discretization: uniform grid with Nx = 400 intervals, dx = (1‑0)/Nx, grid points x_i = 0 + i*dx for i = 0,…,Nx. Use second‑order central differences for u_xx.  

Time integration: rewrite as first‑order system  
u_t = v,  
v_t = c^2*u_xx – gamma*v.  
Integrate (u,v) with the classical fourth‑order Runge‑Kutta method using fixed time step dt = 0.0005 for 6000 steps (T = 3.0). At each RK substage, enforce the Dirichlet conditions by setting u = 0 and v = 0 at the boundary grid points.  

Output: after the final step compute u(x,T) on the grid. Save a NumPy .npz file named "solution_agent_wave_09.npz" containing arrays x (1‑D) and u (1‑D, same length as x) and scalar metadata T, dx, dt. Save a line plot of u(x,T) as "solution_agent_wave_09.png". Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt( Σ_i u_i^2 * dx ) at time T.
