Solve the heat equation u_t = 0.1 * u_xx on the spatial domain x ∈ [0,1] and time interval t ∈ [0,0.5] with diffusion coefficient α = 0.1. Use a uniform grid with Nx = 200 intervals, giving dx = 1/200 and grid points x_i = i*dx for i = 0,…,200. Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t. Integrate in time using the Crank–Nicolson scheme with time step dt = 0.001 for a total of 600 steps, reaching final time T = 0.5. At each time step enforce the Dirichlet boundary values by fixing the boundary nodes.

After the final time step compute the solution vector u(x,T) on the grid. Save the data to a NumPy .npz file named "solution_agent_heat_01.npz" containing the arrays:

- u : 1‑D array of the solution at T,

- T = 0.5,
- dx,
- dt.
