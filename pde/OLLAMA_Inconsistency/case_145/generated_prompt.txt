Use a uniform periodic grid with Nx = 512 points on the interval [0,1) where dx = 1/Nx and x_j = j*dx for j = 0,…,511.  
Set the viscosity parameter nu = 0.04.  
Initialize the solution with u(x,0) = sin(2*pi*x) using radians for the trigonometric function.  
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.  
Set the final simulation time T = 1.0.  
Compute the time step dt from a CFL condition with CFL = 0.4 and an estimated maximum wave speed of 1: dt0 = CFL*dx/1.0. Choose Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is reached exactly.  
For each of the Nt time steps perform Strang splitting:  
A. Diffusion half‑step (duration dt/2) solved exactly in Fourier space:  
 Compute û = FFT(u) using numpy.fft.fft.  
 Define wave numbers k = 2*pi*fftfreq(Nx, d=dx).  
 Update û ← û * exp(-nu*k^2*(dt/2)).  
 Obtain u = real(IFFT(û)) using numpy.fft.ifft.  
B. Advection full‑step (duration dt) for the inviscid Burgers equation using a finite‑volume Rusanov flux:  
 Define the flux function f(u) = 0.5*u^2.  
 For each interface between u_left = u[j] and u_right = u[(j+1) mod Nx], compute  
  alpha = max(|u_left|,|u_right|)  
  F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left).  
 For each cell j compute the net flux difference F_plus - F_minus with periodic indexing and update  
  u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).  
 Replace u with u_new.  
C. Diffusion half‑step again identical to step A.  
After completing Nt steps obtain the solution u(x,T).  
Save the results to a NumPy .npz file named "solution_pdebench_burgers_nu0p04.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values nu, T, dx, dt, Nx, and Nt.  
Create a line plot of u versus x and save it as "solution_pdebench_burgers_nu0p04.png".
