Solve the wave equation u_tt = (0.8)^2 * u_xx on the spatial domain x ∈ [0,1] and time interval t ∈ [0,1.0] using a uniform grid with Nx = 600 intervals (Nx+1 grid points) and spatial step dx = 1/Nx. Use the wave speed c = 0.8.

Compute the time step dt0 = 0.9*dx/c, set Nt = ceil(1.0/dt0), and then set dt = 1.0/Nt so that the final time T = 1.0 is reached exactly. Ensure the CFL condition c*dt/dx ≤ 0.9.

Discretize the spatial second derivative u_xx with a second‑order central difference on interior points. Integrate in time with the standard second‑order central difference (leapfrog/Störmer–Verlet) for u_tt. Initialize the solution using the Taylor start: u^0_i = 0, v0_i = sin(2πx_i), compute u_xx^0 with the spatial stencil, then set u^1_i = u^0_i + dt*v0_i + 0.5*dt^2*(c^2*u_xx^0_i).

Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 at every time step by setting the boundary nodes to zero.

After marching to the final time T = 1.0, compute the solution array u(x,T) on the grid points x_i = i*dx for i = 0,…,Nx.
