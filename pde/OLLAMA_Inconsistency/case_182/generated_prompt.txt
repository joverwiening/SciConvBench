Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) on the periodic domain x in [0,1) and t in [0,1.0] with nu = 1.0 and rho = 2.0. Use a uniform periodic grid with Nx = 512 points, x_j = j*dx for j = 0,…,511, and dx = 1/Nx. Set the time step dt = 0.001 and Nt = 1000 steps so that T = 1.0 is reached exactly. Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x). Advance the solution using Strang splitting each full time step dt: first apply a diffusion half-step of duration dt/2 solved exactly in Fourier space by computing the FFT of u, multiplying the Fourier coefficients by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), and then applying the inverse FFT and taking the real part; next apply a reaction full-step of duration dt solved exactly pointwise for the logistic ODE using the update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)); finally apply another diffusion half-step identical to the first. After completing all Nt steps, compute u(x,T) on the periodic grid. Save the arrays x (length Nx) and u (length Nx) together with the scalars nu, rho, T, dx, dt, Nx, and Nt in a file named "solution_pdebench_reacdiff_nu1_rho2.npz". Create a line plot of u(x,T) and save it as "solution_pdebench_reacdiff_nu1_rho2.png".
