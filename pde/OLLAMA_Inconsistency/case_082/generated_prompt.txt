Solve the wave equation u_tt = u_xx on the spatial domain x ∈ [0,1] and time interval t ∈ [0,1] with wave speed c = 1.0. Use a uniform grid with Nx = 400 intervals, giving Nx+1 = 401 grid points x_i = i*dx where dx = 1/Nx = 0.0025. Choose the time step dt by first computing dt0 = 0.9*dx/c = 0.00225, then set Nt = ceil(1.0/dt0) = 445 and dt = 1.0/Nt ≈ 0.002247191. Apply second‑order central differences for the spatial second derivative u_xx in the interior and the standard second‑order central difference in time (leapfrog/Störmer–Verlet) for u_tt. Initialize the solution with u(x,0) = sin(π*x) and u_t(x,0) = 0 using the Taylor start: u^1 = u^0 + dt*u_t^0 + 0.5*dt^2*(c^2*u_xx^0). Enforce Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 at every time step. Evolve the solution to the final time T = 1.0. After the simulation, compute the solution array u at T on the grid x. Save a NumPy .npz file named "solution_agent_wave_01.npz" containing the arrays x and u and the scalar metadata T, dx, dt. Create a line plot of u versus x and save it as "solution_agent_wave_01.png". Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(∑_i u_i^2 * dx). Also compute the exact solution u_exact(x,T) = cos(π*T)*sin(π*x) on the same grid, and print the maximum absolute error max|u - u_exact| and the L2 error sqrt(∑_i (u_i - u_exact_i)^2 * dx).
