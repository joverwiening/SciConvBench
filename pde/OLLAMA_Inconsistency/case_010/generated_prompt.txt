Solve the Allen‑Cahn equation u_t = ε² (u_xx + u_yy) + u – u³ with ε = 0.01 on the periodic domain [0,1)×[0,1) for time t ∈ [0,0.2].  
Use a uniform Cartesian grid with Nx = Ny = 256 points; because the domain is half‑open and periodic, set dx = dy = 1/256 and define grid coordinates x_i = i·dx, y_j = j·dy for i,j = 0,…,255.  
Initialize the solution as u(x,y,0) = 0.1·cos(2πx)·cos(2πy).  
Advance the solution with a semi‑implicit time‑integration scheme:  

(u^{n+1} – u^{n})/dt = ε²·Δ u^{n+1} + u^{n} – (u^{n})³  

where Δ is the 5‑point Laplacian using periodic wrap‑around indexing.  
At each time step solve the resulting sparse linear system for u^{n+1} (e.g., using SciPy’s sparse direct solver).  
Use a time step dt = 0.0002, performing 1000 steps to reach T = 0.2.  

After the final step compute the solution u(x,y,T) on the grid.  
Save a NumPy .npz file named "solution_agent_allen_cahn_04.npz" containing:  
- x : 1‑D array of length Nx with the x‑coordinates,  
- y : 1‑D array of length Ny with the y‑coordinates,  
- u : 2‑D array of shape (Ny, Nx) where u[j,i] = u(x_i, y_j, T),  
- scalar metadata T, dx, dy, dt.  

Create a heatmap (or contour) plot of u(x,y,T) and save it as "solution_agent_allen_cahn_04.png".  

Print to standard output the minimum value of u, the maximum value of u, and the discrete L2 norm defined as sqrt( Σ_{i,j} u_{i,j}² · dx · dy ) at time T.
