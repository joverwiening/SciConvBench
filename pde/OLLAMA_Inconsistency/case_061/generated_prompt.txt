Solve the Laplace equation u_xx + u_yy = 0 on the square domain (x,y) ∈ [0,1] × [0,1] using a uniform grid with Nx = Ny = 100 intervals, giving Nx+1 = 101 grid points in each direction. Compute grid spacing dx = dy = 1/100 and grid coordinates x_i = i*dx for i = 0..100, y_j = j*dy for j = 0..100.

Apply Dirichlet boundary conditions on all four edges: set u(x,y) = x*y for any point on the boundary (i = 0, i = Nx, j = 0, or j = Ny).

Discretize the Laplacian with the standard second‑order 5‑point finite‑difference stencil for interior nodes (i = 1..Nx‑1, j = 1..Ny‑1):
(u_{i+1,j} - 2*u_{i,j} + u_{i-1,j})/dx^2 + (u_{i,j+1} - 2*u_{i,j} + u_{i,j-1})/dy^2 = 0.

Assemble the resulting sparse linear system for the unknown interior values and solve it with a sparse direct solver (e.g., scipy.sparse.linalg.spsolve).

After solving, obtain the full solution array u of shape (Ny+1, Nx+1) where u[j,i] = u(x_i, y_j).
