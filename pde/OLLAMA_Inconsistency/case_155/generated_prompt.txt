Use the adiabatic index Γ = 1.6666666666666667.
Set the dynamic viscosity η = 0.01 and bulk viscosity ζ = η = 0.01.
Define the spatial domain x ∈ [−1, 1] and the temporal domain t ∈ [0, 0.5].
Create a uniform finite‑volume grid with Nx = 400 cells on [−1, 1]; cell centers are x_j = −1 + (j+0.5)·dx for j = 0,…,399 with dx = 2/Nx.
Evolve the conservative variables U = [ρ, m, E] as cell averages, where m = ρ v and total energy E = p/(Γ−1) + 0.5 ρ v².
Compute pressure from the equation of state p = (Γ−1)·(E − 0.5 m²/ρ) and enforce positivity by clipping ρ and p to a floor of 1e‑12 if necessary.
Apply periodic boundary conditions by wrapping ghost‑cell indices at x = −1 and x = 1.
Initialize the solution at t = 0 with
ρ(x,0) = 1.0 + 0.2·sin(π x),
v(x,0) = 0.1·cos(π x),
p(x,0) = 1.0 + 0.2·cos(π x),
and compute m and E from these primitive values.
For the inviscid convective flux use the Rusanov (local Lax‑Friedrichs) flux:
F_conv(U) = [ m,
             m²/ρ + p,
             (E + p)·v ] with v = m/ρ;
at each interface compute the maximum wave speed a = max(|v_L|+c_L, |v_R|+c_R) where c = sqrt(Γ p/ρ);
the numerical convective flux is F̂ = 0.5·(F_conv(U_L)+F_conv(U_R)) − 0.5·a·(U_R−U_L).
Compute the velocity gradient v_x with a centered difference on cell‑centered v values.
Form the viscous stress σ = (ζ + 4/3 η)·v_x and obtain interface σ by averaging neighboring cell‑centered σ values.
Add viscous contributions at interfaces:
F_visc = [ 0,
           −σ,
           −v·σ ] using the interface‑averaged v and σ.
The total interface flux is F_total = F̂ + F_visc.
Integrate the semi‑discrete finite‑volume system in time with a 2‑stage SSP‑RK2 (Heun’s method).
At each stage compute the time step as
dt_conv = CFL·dx / max_j(|v_j| + c_j),
dt_visc = 0.5·dx² / max(ζ + 4/3 η, 1e‑30),
dt = min(dt_conv, dt_visc) with CFL = 0.6,
and adjust the final step so that the simulation ends exactly at T = 0.5.
After reaching T = 0.5, compute the primitive variables ρ, v = m/ρ, and p from the conserved variables at the cell centers.
