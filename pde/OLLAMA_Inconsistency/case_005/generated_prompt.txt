Use a uniform Cartesian grid with Nx = Ny = 256 points on the periodic domain [0,1) × [0,1). Set dx = dy = 1/256.

Define the velocity coefficients a = -0.7 and b = 1.2.

Compute the provisional time step dt0 = 0.9 / (|a|/dx + |b|/dy). With the given values this is dt0 ≈ 0.00185.

Set the number of time steps Nt = ceil(T / dt0) where the final simulation time T = 0.5. This yields Nt = 271.

Set the actual time step dt = T / Nt ≈ 0.001845.

Initialize the solution u(x,y,0) = exp(-80*((x-0.2)^2 + (y-0.6)^2)) on the grid.

For each time step n = 0,…,Nt‑1 update u using forward Euler:
u^{n+1}_{i,j} = u^{n}_{i,j}
               - dt * a * (∂u/∂x)_{i,j}^{upwind}
               - dt * b * (∂u/∂y)_{i,j}^{upwind}.

Use upwind spatial discretization:
- Because a < 0, approximate ∂u/∂x with a right‑biased (forward) difference:
  (∂u/∂x)_{i,j} ≈ (u_{i+1,j} - u_{i,j}) / dx.
- Because b > 0, approximate ∂u/∂y with a left‑biased (backward) difference:
  (∂u/∂y)_{i,j} ≈ (u_{i,j} - u_{i,j-1}) / dy.

Apply periodic boundary conditions by wrapping indices:
u_{Nx,j} = u_{0,j}, u_{i,Ny} = u_{i,0}, etc.

After Nt steps, the solution corresponds to time T = 0.5. Save the results:

- Create arrays x[i] = i*dx for i = 0,…,Nx‑1 and y[j] = j*dy for j = 0,…,Ny‑1.
- Store the 2‑D array u where u[j,i] = u(x[i], y[j], T).

Save a NumPy .npz file named "solution_agent_advection_05.npz" containing:
x, y, u, and the scalar metadata T, dx, dy, dt.

Generate a heatmap (or contour) plot of u(x,y,T) and save it as "solution_agent_advection_05.png".

Print the following diagnostics:
- min(u) = the minimum value of u on the grid,
- max(u) = the maximum value of u on the grid,
- L2 norm = sqrt( Σ_{i,j} u_{i,j}^2 * dx * dy ).
