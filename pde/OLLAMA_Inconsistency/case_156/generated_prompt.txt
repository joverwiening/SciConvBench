Use Γ = 1.6666666666666667 for the equation of state.  
Set η = 0.1 and ζ = η = 0.1 for the viscous coefficients.  
Define the spatial domain x ∈ [‑1, 1] with a uniform finite‑volume grid of Nx = 400 cells.  
Compute the cell width dx = (1 – (‑1))/Nx = 2/400 = 0.005 and cell centers x_j = –1 + (j+0.5)*dx for j = 0,…,399.  
Evolve the conservative variables U = [ρ, m, E] as cell averages, where m = ρ v and E = p/(Γ‑1) + 0.5 ρ v².  
Initialize the solution at t = 0 by evaluating on each cell center:  
ρ(x,0) = 1.0 + 0.2 sin(π x),  
v(x,0) = 0.1 cos(π x),  
p(x,0) = 1.0 + 0.2 cos(π x),  
then compute m = ρ v and E = p/(Γ‑1) + 0.5 m²/ρ.  
Apply periodic boundary conditions by wrapping ghost‑cell indices at x = –1 and x = 1.  
For each time step, compute the convective flux using the Rusanov (local Lax‑Friedrichs) flux:  
F_conv(U) = [ m, m²/ρ + p, (E + p) v ] with v = m/ρ.  
At each interface, evaluate the maximum wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Γ p/ρ).  
Set the numerical convective flux F̂ = 0.5 (F_conv(U_L) + F_conv(U_R)) – 0.5 a (U_R – U_L).  
Compute the velocity gradient v_x at cell centers with a centered difference of the cell‑centered v values.  
Form the viscous stress σ = (ζ + 4/3 η) v_x and obtain σ at interfaces by averaging the neighboring cell‑centered σ values.  
Define the viscous flux at each interface as F_visc = [ 0, –σ, –v σ ] using the interface‑averaged v and σ.  
The total interface flux is F_total = F̂ + F_visc.  
Advance the semi‑discrete finite‑volume ODE system with a 2‑stage SSP‑RK2 (Heun) method:  
Stage 1: U* = Uⁿ – dt · (ΔF/Δx) using F_total computed from Uⁿ.  
Stage 2: Compute F_total from U* and set Uⁿ⁺¹ = Uⁿ – (dt/2) · [(ΔF/Δx)ⁿ + (ΔF/Δx)*].  
Choose the time step dt each step as the minimum of the convective and viscous limits:  
dt_conv = CFL · dx / max_j(|v_j| + c_j),  
dt_visc = 0.5 · dx² / max(ζ + 4/3 η, 1e‑30),  
dt = min(dt_conv, dt_visc).  
Adopt a CFL number of 0.5 for the convective limit.  
Adjust the final step so that the simulation reaches the exact final time T = 0.5.  
After the final time, compute primitive variables on the cell centers:  
ρ = U[0], v = U[1]/U[0], p = (Γ‑1)·(U[2] – 0.5·U[1]²/U[0]).  
Clip ρ and p to a floor of 1e‑12 before computing v and p to maintain positivity.
