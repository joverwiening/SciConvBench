Q: Should the wave equation use the parameter c as the wave speed (i.e., uₜₜ = c² uₓₓ with c = 2), or keep the coefficient 1.0 as written in the PDE?
A: Use the coefficient 1.0 as written in the PDE. In the complete requirement the wave speed is c = 1.0, so the equation is uₜₜ = (1.0)² uₓₓ.
