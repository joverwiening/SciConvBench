Use a uniform periodic grid with Nx = 800 points on the interval [0,1) (no duplicated endpoint) and compute dx = 1/Nx.  
Set the advection speed a = 1.0.  
Compute the provisional time step dt0 = 0.9*dx/|a|.  
Set the final simulation time T = 1.0.  
Determine the number of time steps Nt = ceil(T/dt0) and then set the actual time step dt = T/Nt so that the final time is reached exactly.  
Discretize the spatial derivative u_x with a first‑order upwind scheme appropriate for positive a (use backward difference).  
Integrate in time with the forward Euler method using the computed dt.  
Apply periodic boundary conditions by wrapping indices: u_{-1}=u_{Nx-1}, u_{Nx}=u_{0}.  
Initialize the solution with u(x,0) = sin(2*pi*x) evaluated at the grid points x_i = i*dx for i = 0,…,Nx‑1.  
Advance the solution for Nt time steps to obtain u(x,T).  
Compute the reference solution at the final time as u_exact(x,T) = sin(2*pi*(x - a*T)).  
Save a NumPy .npz file named "solution_agent_advection_01.npz" containing the arrays x and u, and the scalar metadata T, dx, dt.  
Create a line plot of u(x,T) versus x and save it as "solution_agent_advection_01.png".  
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u**2)*dx) at the final time.
