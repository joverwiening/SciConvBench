Q: Should the solution array include both endpoints (i.e., 401 grid points for Nx = 400) as per the closed‑interval grid convention?
A: Yes. Since the domain is the closed interval [0, 1], Nx = 400 denotes 400 uniform intervals, which yields Nx + 1 = 401 grid points—including both x = 0 and x = 1.
