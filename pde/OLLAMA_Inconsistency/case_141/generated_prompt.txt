Use a uniform periodic grid on the spatial interval [0,1) with Nx = 512 points, dx = 1/Nx, and grid points x_j = j*dx for j = 0,…,511.  
Set the final simulation time T = 2.0 and the advection speed beta = 4.0.  
Initialize the solution with u(x,0) = sin(2 π x) + 0.5 sin(4 π x).  
Choose a CFL number of 0.5 and compute a provisional time step dt_prov = CFL * dx / |beta|.  
Set the number of time steps Nt = ceil(T / dt_prov) and then reset dt = T / Nt so that the final time is reached exactly.  
Discretize the spatial derivative u_x with a first‑order upwind finite difference using the upwind direction determined by the sign of beta (beta > 0 ⇒ backward difference): (u_j – u_{j‑1})/dx, applying periodic wrap‑around for j = 0.  
Integrate in time with explicit forward Euler:  
 u_j^{n+1} = u_j^{n} – beta * dt * (u_j^{n} – u_{j‑1}^{n})/dx for all j, with periodic indexing.  
After Nt steps, obtain the numerical solution u(x,T).  
Save a NumPy .npz file named "solution_pdebench_advection_beta4.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values beta, T, dx, dt, Nx, and Nt.  
Create a line plot of u versus x and save it as "solution_pdebench_advection_beta4.png".  
Print the following diagnostics:  
 min(u), max(u), and the discrete L2 norm sqrt( Σ_j u_j² * dx ).  
Compute the reference solution u_ref(x) = sin(2 π ((x – beta * T) mod 1)) + 0.5 sin(4 π ((x – beta * T) mod 1)) on the same grid.  
Print the maximum absolute error max|u – u_ref| and the L2 error sqrt( Σ_j (u_j – u_ref_j)² * dx ).
