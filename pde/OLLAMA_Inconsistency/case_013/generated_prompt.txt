Solve the Burgers equation u_t + u*u_x = 0.01*u_xx on the periodic domain x∈[0,1) for time t∈[0,0.5].  
Set the viscosity parameter nu = 0.01.  
Use the initial condition u(x,0) = sin(2*pi*x).  
Discretize the spatial domain with Nx = 800 uniform points, dx = 1/Nx, and grid points x_i = i*dx for i = 0,…,799 (periodic indexing, no duplicate at x = 1).  
Write the equation in conservative form with flux f(u) = 0.5*u^2.  
Compute the Rusanov (local Lax–Friedrichs) flux at each interface:  
F_{i+1/2} = 0.5*(f(u_i) + f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1} - u_i), where alpha_{i+1/2} = max(|u_i|,|u_{i+1}|).  
Approximate the convection term as (F_{i+1/2} - F_{i-1/2})/dx using periodic wrap‑around for the indices.  
Approximate the diffusion term with the second‑order central difference (u_{i+1} - 2*u_i + u_{i-1})/dx^2, also using periodic wrap‑around.  
Integrate in time with a first‑order IMEX scheme:  
(u^{n+1} - u^n)/dt + (F^n_{i+1/2} - F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1} - 2*u^{n+1}_i + u^{n+1}_{i-1})/dx^2.  
Form the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term, where L is the periodic Laplacian matrix, and solve it each step (e.g., with scipy.sparse.linalg.spsolve).  
Use a time step dt = 1e-4 and Nt = 5000 steps so that the final time T = 0.5 is reached exactly.  
After the final step compute u(x,T) on the grid.
