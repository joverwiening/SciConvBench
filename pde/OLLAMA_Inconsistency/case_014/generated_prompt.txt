Solve the Burgers equation u_t + u*u_x = 0.005*u_xx on the periodic spatial domain x ∈ [0,1) and time interval t ∈ [0,0.2] with viscosity ν = 0.005.
Use the initial condition u(x,0) = 0.5 + sin(2πx).
Discretize the spatial domain with Nx = 1200 uniform grid points, dx = 1/Nx, and grid points x_i = i*dx for i = 0,…,Nx‑1 (periodic, no duplicate endpoint).
Use a time step dt = 5e‑5 for Nt = 4000 steps so that the final time T = 0.2 is reached exactly.
Treat the convection term in conservative form using the Rusanov (local Lax–Friedrichs) flux:
F_{i+½} = 0.5*(f(u_i)+f(u_{i+1})) – 0.5*α_{i+½}*(u_{i+1}–u_i), where f(u)=0.5*u^2 and α_{i+½}=max(|u_i|,|u_{i+1}|).
Approximate (f(u))_x by (F_{i+½}–F_{i‑½})/dx.
Approximate the diffusion term with a second‑order central difference u_xx ≈ (u_{i+1}–2u_i+u_{i‑1})/dx^2.
Integrate in time with a first‑order IMEX scheme: treat convection explicitly and diffusion implicitly, solving (I – dt*ν*L) u^{n+1} = u^n – dt*conv_term each step, where L is the periodic second‑difference matrix.
Apply periodic wrap‑around indexing for both convection fluxes and diffusion stencil.
After the final step, compute u(x,T) on the grid.
Save the solution to "solution_agent_burgers_02.npz" containing arrays x (1‑D), u (1‑D, same length as x), and scalar metadata T, dx, dt.
Create a line plot of u(x,T) and save it as "solution_agent_burgers_02.png".
