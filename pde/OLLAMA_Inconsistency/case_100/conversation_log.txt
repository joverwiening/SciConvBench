Q: Should the wave speed coefficient in the PDE be 1.0 (as written in u_tt = (1.0)² · (u_xx + u_yy)) or the parameter c = 2 (i.e., u_tt = c² · (u_xx + u_yy))?
A: Use the wave‑speed coefficient 1.0 as written in the complete requirement ( u_tt = (1.0)² · (u_xx + u_yy) ). The parameter c in the complete spec is c = 1.0, not 2.
