Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 4.0 on the periodic domain x ∈ [0,1) and time interval t ∈ [0,1.0].  
Use a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and grid points x_j = j*dx for j = 0,…,511.  
Set the initial condition u(x,0) = sin(2*pi*x) (radians).  
Advance the solution with Strang splitting each time step dt:  
(A) Perform a diffusion half‑step of duration dt/2 by transforming u to Fourier space with FFT, multiplying each mode by exp(-nu*k^2*dt/2) where k = 2*pi*fftfreq(Nx,d=dx), then inverse FFT and keep the real part.  
(B) Perform a full advection step of duration dt for the inviscid Burgers equation using a finite‑volume Rusanov (local Lax‑Friedrichs) flux: f(u)=0.5*u^2, flux at each interface between u_left and u_right is F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left) with alpha = max(|u_left|,|u_right|). Update each cell j by u_new[j] = u[j] - (dt/dx)*(F_{j+1/2} - F_{j-1/2}) using periodic indexing, then replace u with u_new.  
(C) Perform another diffusion half‑step identical to (A).  
Determine the time step size using CFL = 0.4 based on an estimated maximum wave speed of 1: compute dt0 = CFL*dx, set Nt = ceil(T/dt0) with T = 1.0, and then set dt = T/Nt so that the final time is reached exactly.  
After Nt steps compute the solution u(x,T) at T = 1.0.  
Save the results to "solution_pdebench_burgers_nu4.npz" containing the arrays x (length Nx) and u (length Nx) and the scalars nu, T, dx, dt, Nx, and Nt.  
Create a line plot of u versus x and save it as "solution_pdebench_burgers_nu4.png".  
Print the minimum value of u, the maximum value of u, the discrete mean value mean(u) = (1/Nx)∑_j u_j, and the discrete L2 norm sqrt(∑_j u_j^2 * dx).
