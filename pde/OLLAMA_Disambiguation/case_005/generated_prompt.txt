Use a uniform Cartesian grid on the domain [0,1)×[0,1) with Nx=Ny=256 points, dx=dy=1/256, and grid coordinates x_i=i*dx, y_j=j*dy for i,j=0,…,255.  
Apply periodic (wrap‑around) boundary conditions in both the x and y directions.  
Initialize the solution at t=0 by u[i,j]=exp(-80*((x_i-0.2)^2+(y_j-0.6)^2)).  
Set the advection speeds a=−0.7 and b=1.2.  
Discretize the spatial derivatives with upwind schemes: because a<0 use a*(u[i+1,j]−u[i,j])/dx, and because b>0 use b*(u[i,j]−u[i,j−1])/dy, employing periodic indexing for i+1 and j−1.  
Integrate in time with the forward‑Euler method.  
Compute the provisional time step dt0=0.9/(|a|/dx+|b|/dy).  
Set the total simulation time T=0.5, compute Nt=ceil(T/dt0), and define the final time step dt=T/Nt so that the final time is reached exactly.  
For each time step n=0,…,Nt−1 update the solution by u_new = u + dt * ( -a*(u[i+1,j]−u[i,j])/dx - b*(u[i,j]−u[i,j−1])/dy ) using periodic indexing.  
After Nt steps, the array u contains the solution at t=T.  
Save the results to a NumPy .npz file named "solution_agent_advection_05.npz" containing the 1‑D arrays x and y, the 2‑D array u with shape (len(y), len(x)) such that u[j,i]=u(x[i],y[j],T), and the scalar metadata T, dx, dy, and dt.  
Create a heatmap or contour plot of u(x,y,T) and save it as "solution_agent_advection_05.png".
