Generate a uniform spatial grid on the interval [0,1] with Nx = 600 intervals, resulting in Nx+1 = 601 grid points x_i = i*dx where dx = 1/Nx.

Set the wave speed c = 0.5. Compute the provisional time step dt0 = 0.9*dx/c. Determine the number of time steps Nt = ceil(T/dt0) with T = 1.0, then set the actual time step dt = T/Nt so that the final time is reached exactly.

Initialize the solution arrays u^0_i = sin(2*pi*x_i) and v^0_i = u_t(x_i,0) = 0. Compute the second time derivative at t=0 using the PDE: u_tt(x,0) = c^2*u_xx(x,0) - m^2*u^0_i where m = 2.0 and u_xx is approximated with second‑order central differences on the interior points and Dirichlet boundaries u=0. Use a Taylor expansion to obtain the solution at the first time level: u^1_i = u^0_i + dt*v^0_i + 0.5*dt^2*u_tt(x_i,0).

For each subsequent time step n = 1,…,Nt‑1, update the interior solution using the leapfrog scheme with explicit treatment of the mass term:
u^{n+1}_i = 2*u^{n}_i - u^{n-1}_i + (c*dt/dx)^2 * (u^{n}_{i+1} - 2*u^{n}_i + u^{n}_{i-1}) - (m*dt)^2 * u^{n}_i.

Enforce Dirichlet boundary conditions u^{n}_0 = u^{n}_{Nx} = 0 at every time level.

After completing Nt steps, obtain the numerical solution u(x,T) = u^{Nt}_i.

Save the results to a NumPy .npz file named "solution_agent_kg_02.npz" containing the arrays: x (1‑D), u (1‑D, same length as x), and the scalar metadata entries T, dx, dt.

Create a line plot of u(x,T) versus x and save it as "solution_agent_kg_02.png".

Compute and print the following diagnostics:
- Minimum value of u at T.
- Maximum value of u at T.
- Discrete L2 norm sqrt( sum_i u_i^2 * dx ).
- Maximum absolute error max_i |u_i - u_exact(x_i,T)|.
- Discrete L2 error sqrt( sum_i (u_i - u_exact(x_i,T))^2 * dx ).

The exact reference solution is u_exact(x,t) = cos( sqrt( (c*2*pi)^2 + m^2 ) * t ) * sin(2*pi*x). Use this expression evaluated on the same x grid for error calculations.
