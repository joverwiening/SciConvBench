Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = 0.4*u_xx on the half‑open spatial interval [0,1) with periodic boundary conditions.  
Use a uniform grid with Nx = 512 points, dx = (1‑0)/512 = 1/512, and grid points x_i = i*dx for i = 0,…,511.  
Set the final simulation time T = 1.0.  
Compute the time step using CFL = 0.4 and an estimated maximum wave speed of 1: dt0 = 0.4*dx = 0.4/512.  
Choose Nt = ceil(T/dt0) = 1280 and set dt = T/Nt = 1.0/1280 = 0.00078125 so that the final time is reached exactly.  
Advance the solution from t = 0 to t = T with Strang splitting for each full time step dt:  
(A) Diffusion half‑step: transform u to Fourier space with FFT, multiply each mode by exp(-0.4*k^2*dt/2) where k = 2π*fftfreq(Nx, d=dx), then inverse FFT and keep the real part.  
(B) Advection full‑step: update u with a finite‑volume Rusanov flux for the inviscid Burgers equation. For each interface between cells j and j+1 (periodic indexing) compute f(u)=0.5*u^2, α = max(|u_j|,|u_{j+1}|), and flux F = 0.5*(f(u_j)+f(u_{j+1})) - 0.5*α*(u_{j+1}-u_j). Then update each cell j by u_new_j = u_j - (dt/dx)*(F_{j+½} - F_{j‑½}). Replace u with u_new after this substep.  
(C) Diffusion half‑step again, identical to step (A).  
Initialize u(x,0) = sin(2π*x) on the grid.  
After completing Nt steps, compute the solution u(x,T).  
Save the results to a NumPy .npz file named "solution_pdebench_burgers_nu0p4.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values nu = 0.4, T = 1.0, dx, dt, Nx, and Nt.  
Create a line plot of u versus x at the final time and save it as "solution_pdebench_burgers_nu0p4.png".  
Print the following diagnostics at T: the minimum value of u, the maximum value of u, the discrete mean value mean(u) = (1/Nx)∑_i u_i (which should be approximately conserved), and the discrete L2 norm sqrt(∑_i u_i^2 * dx).
