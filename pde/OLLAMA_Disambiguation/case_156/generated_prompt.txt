Solve the 1D compressible Navier–Stokes equations without heat conduction on the spatial domain x∈[-1,1] and time interval t∈[0,0.5] with periodic boundary conditions at x=-1 and x=1.  
Use Gamma = 1.6666666666666667, eta = 0.1, and set zeta = eta = 0.1.  
Define the conservative variables U = [rho, m, E] where m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.  
The viscous stress is sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.  

The governing equations in conservative form are:  
- rho_t + (m)_x = 0  
- m_t + (m^2/rho + p - sigma)_x = 0  
- E_t + ((E+p)*v - v*sigma)_x = 0  

Initial conditions at t=0 are defined pointwise on the grid:  
- rho(x,0) = 1.0 + 0.2*sin(pi*x)  
- v(x,0) = 0.1*cos(pi*x)  
- p(x,0) = 1.0 + 0.2*cos(pi*x)  

Use a uniform finite‑volume grid with Nx = 400 cells on [-1,1].  
Cell centers are x_j = -1 + (j+0.5)*dx for j = 0,…,399, where dx = (1 - (-1))/400 = 0.005.  

Evolve the cell‑averaged conservative variables using the following numerical method:  
- Equation of state: p = (Gamma-1)*(E - 0.5*m^2/rho). Clip rho and p to a minimum of 1e-12 if needed to maintain positivity.  
- Convective flux: F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.  
- Compute the local maximum wave speed at each interface as a = max(|v_L|+c_L, |v_R|+c_R) where c = sqrt(Gamma*p/rho).  
- Use the Rusanov (local Lax‑Friedrichs) numerical flux: F_hat = 0.5*(F_conv(U_L)+F_conv(U_R)) - 0.5*a*(U_R-U_L).  
- Approximate v_x with a centered difference on cell‑centered v values, then sigma = (zeta + 4/3*eta)*v_x.  
- Compute sigma at interfaces by averaging the neighboring cell‑centered sigma values.  
- Viscous flux at interfaces: F_visc = [0, -sigma, -v*sigma] using the interface‑averaged v and sigma.  
- Total interface flux: F_total = F_hat + F_visc.  
- Time integration: 2‑stage SSP‑RK2 (Heun’s method) applied to the semi‑discrete finite‑volume system.  
- Time step selection:  
    dt_conv = CFL * dx / max_j(|v_j| + c_j) with CFL = 0.5.  
    dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).  
    Choose dt = min(dt_conv, dt_visc) each step and adjust the final step to reach T = 0.5 exactly.  
- Apply periodic boundary conditions by wrapping ghost‑cell indices.  

After reaching the final time T = 0.5, compute rho, v, and p at the cell centers.
