Solve the advection equation u_t + a*u_x = 0 with a = -0.5 on the periodic domain x ∈ [0,1) up to final time T = 1.0.

Create a uniform periodic grid with Nx = 1000 points: dx = 1/Nx, x_i = i*dx for i = 0,…,Nx‑1.

Compute the time step dt as follows: dt0 = 0.9*dx/|a|, Nt = ceil(T/dt0), dt = T/Nt. This guarantees max|a|*dt/dx ≤ 0.9 and reaches T exactly.

Initialize u(x,0) = exp(-100*(x-0.3)^2) on the grid.

Advance the solution in time using Forward Euler with a first‑order upwind (right‑biased) stencil appropriate for a < 0:
for each time step n = 0,…,Nt‑1,
    u_new[i] = u[i] - a*dt/dx * (u[(i+1) % Nx] - u[i])   for all i,
    then set u = u_new.

After Nt steps, u contains the numerical solution at t = T.

Save the results to a NumPy .npz file named "solution_agent_advection_02.npz" with the arrays:
    x  (1‑D array of grid points),
    u  (1‑D array of the solution at T),
and the scalar metadata entries:
    T, dx, dt.

Create a line plot of u versus x and save it as "solution_agent_advection_02.png".

Print the following diagnostics for the final solution:
    min(u), max(u), and the discrete L2 norm sqrt( sum(u**2) * dx ).
