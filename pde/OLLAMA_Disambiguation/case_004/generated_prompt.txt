Generate a uniform periodic grid with Nx = Ny = 256 points on the domain [0,1) × [0,1) using dx = dy = 1/Nx and x_i = i*dx, y_j = j*dy for i, j = 0,…,255.  
Set the advection speeds a = 1.0 and b = 0.5.  
Compute the provisional time step dt0 = 0.9 / (|a|/dx + |b|/dy).  
Set Nt = ceil(T / dt0) with T = 1.0 and then define the final time step dt = T / Nt so that the final time is reached exactly.  
Initialize the solution array u(x,y,0) = sin(2πx)·cos(2πy) on the grid.  
For each time step n = 0,…,Nt‑1, update u using a first‑order upwind scheme in both x and y directions and forward Euler time integration:  
u^{n+1}_{i,j} = u^{n}_{i,j} − a·dt/dx·(u^{n}_{i,j} − u^{n}_{i‑1,j}) − b·dt/dy·(u^{n}_{i,j} − u^{n}_{i,j‑1}), applying periodic indexing for i‑1 and j‑1.  
After Nt steps, obtain u(x,y,T).  
Compute the exact reference solution at T: u_exact(x,y,T) = sin(2π·(x−a·T))·cos(2π·(y−b·T)).  
Calculate diagnostics:  
min_u = min(u), max_u = max(u), L2_u = sqrt( Σ_{i,j} u_{i,j}²·dx·dy ).  
max_abs_error = max|u − u_exact|, L2_error = sqrt( Σ_{i,j} (u_{i,j}−u_exact_{i,j})²·dx·dy ).  
Print the values of min_u, max_u, L2_u, max_abs_error, and L2_error.
