Q: What Dirichlet boundary values should be applied on the four edges of the domain?
A: Apply Dirichlet conditions that set the solution equal to the exact harmonic function u(x,y)=x on every boundary:

- **Left edge (x = 0):** u = 0  
- **Right edge (x = 1):** u = 1  
- **Bottom edge (y = 0):** u = x (so u varies linearly from 0 to 1 along the edge)  
- **Top edge (y = 1):** u = x (same linear variation as the bottom edge).
