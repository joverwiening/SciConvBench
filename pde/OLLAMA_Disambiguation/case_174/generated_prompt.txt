Use a uniform half‑open spatial grid on the interval [0, 1) with Nx = 512 points, so dx = (1‑0)/512 and grid points x_i = i*dx for i = 0,…,511.  
Set the time step dt = 0.001 and number of steps Nt = 1000, giving final time T = Nt*dt = 1.0.  
Initialize the field u(x,0) = 0.25 + 0.1 * sin(2 π x) at all grid points.  
For each time step apply Strang splitting:  
1. Perform a diffusion half‑step of duration dt/2 by transforming u to Fourier space with FFT, multiplying each Fourier coefficient by exp(‑nu *k² * (dt/2)) where k = 2 π * fftfreq(Nx, d=dx), and transforming back with inverse FFT, taking the real part.  
2. Perform a reaction full‑step of duration dt by updating each grid point exactly for the logistic ODE: u ← (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) ‑ 1)).  
3. Perform another diffusion half‑step identical to step 1.  
Repeat the three sub‑steps for all Nt time steps.  
After the final step, compute the solution u(x,T) on the grid.  
Save a NumPy .npz file named "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values nu, rho, T, dx, dt, Nx, and Nt.  
Create a line plot of u versus x and save it as "solution_pdebench_reacdiff_nu0p5_rho2.png".  
Print the following diagnostics at time T: the minimum of u, the maximum of u, the mean of u, and the discrete L2 norm sqrt( sum(u**2) * dx ).
