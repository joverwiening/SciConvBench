Solve the diffusion equation u_t = ∇·( D(x,y) ∇u ) with D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)) on the square domain (x,y) ∈ [0,1]×[0,1] for time t ∈ [0,0.1].

Use a uniform Cartesian grid with Nx = Ny = 80 intervals, giving dx = dy = 1/80. Grid points are x_i = i*dx, y_j = j*dy for i,j = 0,…,80.

Apply Dirichlet boundary conditions u = 0 on all four edges of the square for all times.

Set the initial condition u(x,y,0) = sin(pi*x)*sin(pi*y) at all interior grid points.

Discretize the spatial operator in flux form with second‑order accuracy:
- Compute D at cell centers D_{i,j} = D(x_i,y_j).
- Compute face values by arithmetic averaging:
  D_{i+1/2,j} = 0.5*(D_{i,j}+D_{i+1,j}),
  D_{i,j+1/2} = 0.5*(D_{i,j}+D_{i,j+1}).
- For interior nodes (i=1..Nx‑1, j=1..Ny‑1) approximate
  (∇·(D∇u))_{i,j} ≈ (1/dx^2)[ D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i‑1/2,j}(u_{i,j}-u_{i‑1,j}) ]
                 + (1/dy^2)[ D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j‑1/2}(u_{i,j}-u_{i,j‑1}) ].

Integrate in time with the implicit Euler method:
(I - dt*L) u^{n+1} = u^{n},
where L is the discrete diffusion operator defined above.
Use a time step dt = 0.0005, performing 200 steps to reach T = 0.1.
At each step solve the resulting sparse linear system with an appropriate solver (e.g., SciPy’s sparse linear solver).

After the final step, compute the solution u(x,y,T) on the full grid.

Save the results to a NumPy .npz file named "solution_agent_diffusion_04.npz" containing:
- x: 1‑D array of x‑coordinates (length Nx+1),
- y: 1‑D array of y‑coordinates (length Ny+1),
- u: 2‑D array of shape (len(y), len(x)) with u[j,i] = u(x[i], y[j]) at T,
- scalar metadata: T, dx, dy, dt.

Create a heatmap or contour plot of u(x,y,T) and save it as "solution_agent_diffusion_04.png".

Print the following diagnostics for the final solution:
