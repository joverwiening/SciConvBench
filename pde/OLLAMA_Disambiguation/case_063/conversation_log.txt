Q: What Dirichlet boundary values should be used on the edges of the domain?
A: Use Dirichlet conditions on all four sides:

- Bottom edge (y = 0): u(x, 0) = 0  
- Top edge (y = 1):  u(x, 1) = sin(π x)  
- Left edge (x = 0):  u(0, y) = 0  
- Right edge (x = 1): u(1, y) = 0.
