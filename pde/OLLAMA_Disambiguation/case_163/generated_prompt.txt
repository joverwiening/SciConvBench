Solve the 1D compressible Navier–Stokes equations (no heat conduction) on the spatial interval x ∈ [‑1, 1] and time interval t ∈ [0, 0.2] with the following specifications.

Domain and grid:
- Use a uniform finite‑volume grid with Nx = 800 cells on [‑1, 1].
- Cell centers are x_j = –1 + (j + 0.5)·dx for j = 0,…,799.
- dx = (1 – (‑1)) / 800 = 0.0025.
- Employ two ghost cells on each side for boundary condition implementation.

Physical parameters:
- Ratio of specific heats Γ = 1.6666666666666667.
- Dynamic viscosity η = 1e‑8.
- Bulk viscosity ζ = η = 1e‑8.

Governing equations (conservative form):
- Define momentum m = ρ v and total energy E = p/(Γ‑1) + 0.5 ρ v².
- Viscous stress σ = (ζ + 4/3 η) ∂v/∂x, with ζ = η.
- The PDE system is
  ρ_t + (m)_x = 0,
  m_t + (m²/ρ + p – σ)_x = 0,
  E_t + ((E + p) v – v σ)_x = 0.

Equation of state:
- Pressure p = (Γ‑1)·(E – 0.5 m²/ρ).
- Enforce positivity by clipping ρ and p to a floor of 1e‑12 after each update.

Initial condition (Sod shock‑tube):
- For x < 0: ρ = 1.0, v = –0.75, p = 1.0.
- For x ≥ 0: ρ = 0.125, v = 0.0, p = 0.1.
- Compute the corresponding conservative variables U = [ρ, m, E] at each cell center.

Boundary conditions:
- Transmissive (outflow) at x = –1 and x = 1: set ghost‑cell values equal to the nearest interior cell (zero‑gradient).

Numerical method:
- Evolve the cell‑averaged conservative variables U using a finite‑volume discretization.
- Convective flux: use the Rusanov (local Lax‑Friedrichs) flux.
  * Compute primitive variables v = m/ρ and sound speed c = sqrt(Γ p/ρ) in each cell.
  * At each interface, wave speed a = max(|v_L| + c_L, |v_R| + c_R).
  * Convective flux F̂ = 0.5·(F_conv(U_L) + F_conv(U_R)) – 0.5·a·(U_R – U_L),
    where F_conv(U) = [m, m²/ρ + p, (E + p) v].
- Viscous terms:
  * Compute v_x at cell centers with a second‑order centered difference.
  * Compute σ = (ζ + 4/3 η)·v_x at cell centers.
  * Approximate σ at interfaces by averaging the neighboring cell‑center σ values.
  * Viscous flux at interfaces: F_visc = [0, –σ, –v σ], using the interface‑averaged v and σ.
  * Total interface flux: F_total = F̂ + F_visc.
- Time integration: 2‑stage SSP‑RK2 (Heun’s method) applied to the semi‑discrete system.
- Time step selection:
  * CFL number = 0.5.
  * Convective time step: dt_conv = CFL·dx / max_j(|v_j| + c_j).
  * Viscous time step: dt_visc = 0.5·dx² / max(ζ + 4/3 η, 1e‑30).
  * Choose dt = min(dt_conv, dt_visc) each step and adjust the final step to reach T = 0.2 exactly.

Output:
- At final time T = 0.2, compute primitive variables ρ(x,T), v(x,T), p(x,T) at the cell centers.

  * x (length 800),
  * rho,

  * p,
  and scalars: Gamma, eta, zeta, T, dx, CFL.
- Save a plot "solution_pdebench_cns1d_sod4_eta1em8_outflow.png" showing three line panels (or three separate subplots) of ρ, v, and p versus x at T.
- Print the following diagnostics:
  * Minimum and maximum of ρ,
  * Minimum and maximum of p,
  * Mean value of ρ over the domain (mass‑conservation check).
