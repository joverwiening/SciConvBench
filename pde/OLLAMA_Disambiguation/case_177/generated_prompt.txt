Solve the 1D periodic reaction–diffusion equation u_t = nu*u_xx + rho*u*(1 - u) on the domain x ∈ [0,1) with periodic boundary conditions and t ∈ [0,1.0].

Use the parameters nu = 10.0 and rho = 10.0.

Create a uniform periodic spatial grid with Nx = 512 points: x_j = j*dx for j = 0,…,511 where dx = (1‑0)/512 = 0.001953125.

Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.

Advance the solution from t = 0 to t = 1.0 with Strang splitting each full time step dt:
1. Diffusion half‑step (duration dt/2) solved exactly in Fourier space:
   - Compute the discrete Fourier transform û = FFT(u).
   - Define wave numbers k = 2π*fftfreq(Nx, d=dx).
   - Multiply û by exp(-nu*k^2*(dt/2)).
   - Transform back: u = real(IFFT(û)).
2. Reaction full‑step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1‑u):
   - Compute factor = exp(rho*dt).
   - Update each grid value: u = (u*factor) / (1 + u*(factor - 1)).
3. Diffusion half‑step again, identical to step 1.

Initialize the solution at t = 0 with u(x,0) = 0.25 + 0.1*sin(2π*x).

After the final step, compute u(x,T) on the periodic grid.

Save the results to a NumPy .npz file named "solution_pdebench_reacdiff_nu10_rho10.npz" containing the arrays:
- x (length Nx)
- u (length Nx)

and the scalar values:
- nu, rho, T, dx, dt, Nx, Nt.

Create a line plot of u(x,T) and save it as "solution_pdebench_reacdiff_nu10_rho10.png".

Print the following diagnostics at T = 1.0:
- Minimum value of u.
- Maximum value of u.
- Mean value of u.
- Discrete L2 norm sqrt( Σ_i u_i^2 * dx ).
