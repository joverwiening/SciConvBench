Q: Should the saved `x` and `u` arrays include the boundary points at x = 0 and x = 1 (i.e., have length Nx + 1), or only the interior points (length Nx − 1)?
A: Only the interior points should be saved.  
The solution is computed on the interior grid \(x_i=i\,dx\) for \(i=1,\dots,N_x-1\) (the boundary values are known to be zero), so the saved `x` and `u` arrays should have length \(N_x-1\).
