Solve the PDE u_t = -k * ∂_x(sin(u)) on the periodic domain x ∈ [0,1) for t ∈ [0,0.2] with k = 1.0.  
Use the initial condition u(x,0) = 0.5 * sin(2*pi*x) (radians).  
Create a uniform periodic grid with Nx = 1024 points: dx = 1/Nx, x_j = j*dx for j = 0,…,Nx‑1.  
Discretize the spatial derivative with a conservative finite‑volume Rusanov flux for f(u)=sin(u); compute the local wave speed α = max|cos(u)| over the current solution.  
Integrate in time with the SSP‑RK2 scheme.  
Choose the time step using CFL = 0.2: dt0 = CFL * dx / 1.0 (since max|cos(u)| ≤ 1).  
Set Nt = ceil(T / dt0) and dt = T / Nt, where T = 0.2.  
Advance the solution for Nt steps to reach the final time T = 0.2.  
At t = 0.2, save an NPZ file named solution_molk_030.npz containing the arrays `x` (length Nx) and `u` (solution at T, length Nx) and the scalar values `T`, `dx`, `Nx`, and the parameter `k`.
