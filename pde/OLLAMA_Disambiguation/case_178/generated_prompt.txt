Solve the 1D periodic reaction–diffusion equation u_t = nu*u_xx + rho*u*(1-u) with nu = 10.0 and rho = 2.0 on the spatial domain x ∈ [0,1) and time interval t ∈ [0,1.0].

Use a uniform periodic grid with Nx = 512 points: dx = (1‑0)/512 = 0.001953125, and grid points x_j = j*dx for j = 0,…,511.

Use a fixed time step dt = 0.001, giving Nt = T/dt = 1000 time steps so that the final time T = 1.0 is reached exactly.

Advance the solution from t = 0 to t = 1.0 with Strang splitting each full time step dt:
1. Diffusion half‑step (duration dt/2) solved exactly in Fourier space:
   - Compute û(k) = FFT(u).
   - Wave numbers k = 2π*fftfreq(Nx, d=dx).
   - Multiply û(k) by exp(-nu*k^2*(dt/2)).
   - Compute u = real(IFFT(û(k))).
2. Reaction full‑step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1‑u):
   - Update each grid point with u ← (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
3. Diffusion half‑step again, identical to step 1.

Initial condition at t = 0: u(x,0) = 0.25 + 0.1*sin(2π*x).

After completing Nt steps, compute u(x,T=1.0) on the periodic grid.

Save the results to a NumPy .npz file named "solution_pdebench_reacdiff_nu10_rho2.npz" containing the arrays:
- x (1‑D length Nx),
- u (1‑D length Nx),

and the scalar values:
- nu,
- rho,
- T,
- dx,
- dt,
- Nx,
- Nt.

Create a line plot of u(x,T) and save it as "solution_pdebench_reacdiff_nu10_rho2.png".

Print the following diagnostics at T = 1.0:
