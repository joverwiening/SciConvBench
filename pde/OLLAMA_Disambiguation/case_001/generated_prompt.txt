Create a uniform periodic grid on the interval [0,1) with Nx = 800 points, where dx = 1/Nx and x_i = i*dx for i = 0,…,Nx‑1.  
Set the advection speed a = 1.0 and the final time T = 1.0.  
Compute the provisional time step dt0 = 0.9*dx/|a|, set Nt = ceil(T/dt0), and then define the actual time step dt = T/Nt so that the final time is reached exactly.  
Initialize the solution array u_i = sin(2*pi*x_i) for all grid points i.  
For each time step n = 0,…,Nt‑1 update the solution with the forward‑Euler scheme using first‑order upwind for positive a: u_i^{n+1} = u_i^{n} – a*dt/dx * (u_i^{n} – u_{i‑1}^{n}), applying periodic indexing so that u_{‑1} = u_{Nx‑1}.  
After completing Nt steps, the solution u approximates u(x,T) at time T = 1.0.  
Compute the exact solution on the same grid as u_exact_i = sin(2*pi*(x_i – a*T)).
