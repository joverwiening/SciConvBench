Solve the 1D reaction–diffusion PDE u_t = nu * u_xx + rho * u * (1 - u) with nu = 1.0 and rho = 5.0 on the half‑open spatial domain [0, 1) with periodic boundary conditions u(0,t) = u(1,t). Use a uniform grid with Nx = 512 points, dx = (1 - 0)/Nx, and grid points x_i = 0 + i*dx for i = 0,…,511. Set the initial condition u(x,0) = 0.25 + 0.1 * sin(2 * pi * x). Advance the solution to final time T = Nt * dt = 1000 * 0.001 = 1.0 using a fixed time step dt = 0.001 and Nt = 1000 steps. Apply Strang splitting each full time step dt: first perform a diffusion half‑step of duration dt/2 by transforming u to Fourier space with FFT, multiplying each Fourier coefficient by exp(-nu * k^2 * dt/2) where k = 2 * pi * fftfreq(Nx, d=dx), and transforming back with IFFT taking the real part; then perform a reaction full‑step of duration dt by updating each grid point exactly using the logistic solution u <- (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)); finally perform another diffusion half‑step identical to the first. After completing all Nt steps, compute the solution u(x,T) on the grid. Save the arrays x (length Nx) and u (length Nx) together with the scalars nu, rho, T, dx, dt, Nx, and Nt in a NumPy .npz file named "solution_pdebench_reacdiff_nu1_rho5.npz". Create a line plot of u versus x at the final time and save it as "solution_pdebench_reacdiff_nu1_rho5.png".
