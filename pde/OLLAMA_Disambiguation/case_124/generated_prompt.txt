Solve the 1‑D periodic reaction–diffusion equation  

u_t = 0.01 u_xx + 2.0 u² (1‑u)²  

on the spatial domain x∈[0,1) with periodic boundary conditions and time interval t∈[0,1.0].

Use a uniform periodic grid with Nx = 512 points, dx = (1‑0)/Nx, and grid points x_i = i·dx for i = 0,…,511.

Integrate from t = 0 to T = 1.0 with a constant time step dt = 0.0005 (N_t = 2000 steps).

Employ a semi‑implicit scheme: treat the diffusion term implicitly with the backward‑Euler method and the nonlinear reaction term explicitly. At each time step solve the linear system  

(I ‑ dt·q1·D) u^{n+1} = u^{n} + dt·q2·(u^{n})²·(1‑u^{n})²  

where D is the second‑order central difference matrix with periodic wrap‑around.

Initialize u(x,0) = 0.2 + 0.1·sin(2·π·x).

After the final step (t = T), compute and store:

* The solution vector u_T = u(x,T) on the periodic grid.
* The scalar diagnostics:  
  – min(u_T)  
  – max(u_T)  
  – mean(u_T) (average over all grid points)  
  – discrete L2 norm = sqrt( Σ_i u_T[i]² · dx ).

Save the results in a NumPy .npz file named **solution_molk_023.npz** containing the arrays  
x (shape (Nx,)), u (shape (Nx,)), and the scalars T, dx, Nx, q1, q2, dt.

Create a line plot of u_T versus x and save it as **solution_molk_023.png**.

Print to standard output the four diagnostics (min, max, mean, L2 norm) with clear labels. No error comparison is required because no exact solution is provided.
