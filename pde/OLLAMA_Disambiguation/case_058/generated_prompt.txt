Discretize the unit square [0,1]×[0,1] with Nx=Ny=100 uniform intervals, giving Nx+1=101 grid points in each direction; compute dx=dy=1/100 and grid coordinates x_i=i*dx for i=0..100, y_j=j*dy for j=0..100.  
Set Dirichlet boundary values of u on all four edges to the exact harmonic function u_exact(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi) evaluated at the corresponding edge points.  
For each interior node (i=1..99, j=1..99) apply the standard 5‑point finite‑difference stencil: (u_{i+1,j}+u_{i-1,j}+u_{i,j+1}+u_{i,j-1}-4*u_{i,j})/dx^2 = 0.  
Assemble the resulting sparse linear system Au=b, where b contains the contributions of the known boundary values.  
Solve the linear system for the interior unknowns using scipy.sparse.linalg.spsolve.  
Combine the solved interior values with the prescribed boundary values to obtain the full solution array u of shape (101,101) such that u[j,i]=u(x_i,y_j).  
Compute the discrete L2 norm sqrt(sum(u^2)*dx*dy).  
Evaluate the exact solution on the same grid to obtain u_exact_grid.  
Compute the maximum absolute error max|u-u_exact_grid| and the L2 error sqrt(sum((u-u_exact_grid)^2)*dx*dy).
