Define the spatial domain as the periodic interval [0,1) and create a uniform grid with Nx = 512 points: x_i = i*dx for i = 0,…,511 where dx = 1/Nx.

Set the wave speed c = 1.0 and the mass parameter m = 3.0. Compute the provisional time step dt0 = 0.9*dx/c and determine the number of time steps Nt = ceil(T/dt0) with final time T = 0.8. Set the actual time step dt = T/Nt so that the simulation reaches T exactly.

Initialize the solution at t = 0 with u(x,0) = cos(2πx) and u_t(x,0) = 0. Compute the second spatial derivative u_xx at t = 0 using a second‑order central difference with periodic wrap‑around. Obtain the initial acceleration from the PDE: u_tt(0) = c²*u_xx(0) – m²*u(0). Use a second‑order Taylor expansion to obtain the solution at the first half‑step: u¹ = u⁰ + dt*u_t(0) + 0.5*dt²*u_tt(0).

Advance the solution in time for n = 1,…,Nt‑1 using the leapfrog scheme:
u^{n+1}_i = 2*u^{n}_i – u^{n‑1}_i + dt²*(c²*(u^{n}_{i+1} – 2*u^{n}_i + u^{n}_{i‑1})/dx² – m²*u^{n}_i),
with periodic indexing for i‑1 and i+1.

After completing Nt steps, the array u contains the numerical solution at t = T on the grid x.
