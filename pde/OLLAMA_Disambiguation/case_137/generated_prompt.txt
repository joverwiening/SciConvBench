Define the spatial domain as the half‑open interval [0,1) with periodic boundary conditions u(0,t)=u(1,t).  
Create a uniform grid with Nx = 512 points, dx = (1‑0)/Nx = 1/512, and grid points x_i = i*dx for i = 0,…,511.  
Set the advection speed beta = 0.4.  
Initialize the field as u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x), using radians for the trigonometric functions.  
Discretize the spatial derivative u_x with a first‑order upwind finite difference; because beta > 0, use the backward difference (u_i - u_{i‑1})/dx with periodic indexing.  
Integrate in time with the explicit forward Euler method.  
Compute the provisional time step dt_prov = CFL*dx/|beta| with CFL = 0.5, then set Nt = ceil(T/dt_prov) and finally dt = T/Nt so that the final time T is reached exactly.  
For each time step n = 0,…,Nt‑1 update the solution by  
u_i^{n+1} = u_i^{n} - beta*dt/dx * (u_i^{n} - u_{i‑1}^{n})  
with periodic wrap‑around for the index i‑1.  
Run the simulation until the final time T = 2.0 and obtain the numerical solution u(x,T).
