Solve the nonlinear diffusion equation u_t = ∂_xx( u^m ) with m = 2.0 on the periodic spatial domain x ∈ [0,1) using a uniform grid of Nx = 256 points (dx = 1/256, x_i = i*dx for i = 0,…,255). Advance the solution in time from t = 0 to T = 0.2 with a constant time step dt = 0.0001 (Nt = 2000 steps). Use the initial condition u(x,0) = 0.5 + 0.2*cos(2*pi*x). Impose periodic boundary conditions u(0,t) = u(1,t) for all t. Compute the numerical solution u(x,T) at the final time. Save the results in a NumPy .npz file named "solution_molk_013.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values T, dx, Nx, m, and dt. Create a line plot of u(x,T) and save it as "solution_molk_013.png". Print the minimum, maximum, mean of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T. No error analysis is required because no exact solution is provided.
