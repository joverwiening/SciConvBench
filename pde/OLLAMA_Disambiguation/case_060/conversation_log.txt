Q: What Dirichlet boundary values should be applied on the four edges of the square domain?
A: Apply Dirichlet conditions that match the exact solution u(x,y)=y:

- Bottom edge (y = 0): u(x,0) = 0 for all x∈[0,1]  
- Top edge (y = 1):  u(x,1) = 1 for all x∈[0,1]  
- Left edge (x = 0):  u(0,y) = y for all y∈[0,1]  
- Right edge (x = 1): u(1,y) = y for all y∈[0,1]
