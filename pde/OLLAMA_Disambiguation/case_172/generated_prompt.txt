Use the spatial domain x ∈ [0, 1) with periodic boundary conditions.  
Create a uniform half‑open grid with Nx = 512 points, dx = 1/512, and grid points x_i = i*dx for i = 0,…,511.  
Set the diffusion coefficient nu = 0.5 and the reaction rate rho = 1.0.  
Use a fixed time step dt = 0.001 and Nt = 1000 steps, so the final time T = Nt · dt = 1.0.  
Initialize the solution as u(x,0) = 0.25 + 0.1 · sin(2 π x).  
Advance the solution from t = 0 to t = T with Strang splitting for each full time step dt:  
(A) Perform a diffusion half‑step of duration dt/2 by transforming u to Fourier space, multiplying each Fourier coefficient by exp(‑nu k² · (dt/2)) where k = 2 π fftfreq(Nx, d=dx), and transforming back with an inverse FFT, taking the real part.  
(B) Perform a reaction full‑step of duration dt by updating each grid point exactly for the logistic ODE: u ← (u · exp(rho dt)) / (1 + u · (exp(rho dt) – 1)).  
(C) Perform another diffusion half‑step identical to step (A).  
After completing all Nt steps, compute the final solution u(x,T).  
Save the arrays x (length Nx) and u (length Nx) together with the scalars nu, rho, T, dx, dt, Nx, and Nt in a NumPy .npz file named "solution_pdebench_reacdiff_nu0p5_rho1.npz".
