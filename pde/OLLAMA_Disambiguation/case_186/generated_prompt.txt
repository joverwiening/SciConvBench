Use a uniform periodic spatial grid on [0,1) with Nx = 512 points, x_j = j*dx for j = 0,…,511 where dx = 1/512 = 0.001953125.  
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
At each time step apply Strang splitting:  
(A) Diffusion half-step of duration dt/2 solved exactly in Fourier space: compute the FFT of u, multiply each Fourier coefficient by exp(-nu*k^2*(dt/2)) where k = 2π*fftfreq(Nx, d=dx), then inverse FFT and keep the real part.  
(B) Reaction full-step of duration dt solved exactly pointwise for the logistic ODE du/dt = rho*u*(1‑u) using the update u ← (u*exp(rho*dt)) / (1 + u*(exp(rho*dt)‑1)).  
(C) Diffusion half-step identical to (A).  
Parameters: nu = 2.0, rho = 2.0.  
Initial condition: u(x,0) = 0.25 + 0.1*sin(2π*x) evaluated at the grid points.  
Periodic boundary condition is inherent in the Fourier-based diffusion step.  
After completing Nt steps, compute u(x,T) at T = 1.0 on the grid.  
Save a NumPy .npz file named "solution_pdebench_reacdiff_nu2_rho2.npz" containing arrays x, u and scalars nu, rho, T, dx, dt, Nx, Nt.  
Create a line plot of u versus x and save it as "solution_pdebench_reacdiff_nu2_rho2.png".  
Print the diagnostics at T: the minimum of u, the maximum of u, the mean of u, and the discrete L2 norm sqrt(sum(u^2)*dx).
