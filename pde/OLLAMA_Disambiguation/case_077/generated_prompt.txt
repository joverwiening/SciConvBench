Solve the Poisson equation u_xx + u_yy = f(x,y) on the domain (x,y) ∈ [0,1] × [0,1] with the source term f(x,y) = (1 - π²) eˣ sin(π y). Impose Dirichlet boundary conditions on all four edges by setting u equal to the exact solution u(x,y) = eˣ sin(π y). Use the exact solution also as the reference for error calculation.

Discretize the domain with a uniform grid of Nx = Ny = 120 intervals, giving Nx+1 = 121 grid points in each direction. Compute the grid spacing dx = dy = 1/Nx = 1/120. Define grid coordinates x_i = i·dx for i = 0,…,Nx and y_j = j·dy for j = 0,…,Ny.

Apply the standard second‑order 5‑point finite‑difference stencil to approximate the Laplacian at interior nodes. Assemble the resulting sparse linear system for the unknown interior values of u. Solve the linear system with a sparse direct solver, e.g., scipy.sparse.linalg.spsolve.

After solving, obtain the full solution array u of shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]). Compute the following diagnostics:
- Minimum value of u.
- Maximum value of u.
- Discrete L2 norm sqrt( Σ_{i,j} u[j,i]² · dx · dy ).
- Maximum absolute error max|u - u_exact| on the grid.
- L2 error sqrt( Σ_{i,j} (u[j,i] - u_exact(x[i],y[j]))² · dx · dy ).

Save the results to a NumPy .npz file named "solution_agent_poisson_04.npz" containing the arrays x (1‑D), y (1‑D), u (2‑D), and the scalar metadata dx and dy.

Create a heatmap or contour plot of the solution u(x,y) and save it as "solution_agent_poisson_04.png".
