Solve the PDE u_t = nu*u_xx + rho*u*(1-u) with nu = 1.0 and rho = 2.0 on the half‑open spatial interval [0, 1) with periodic boundary conditions.  
Use a uniform grid of Nx = 512 points, dx = (1‑0)/Nx, and grid points x_i = i*dx for i = 0 … 511.  
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).  
Integrate in time with a fixed time step dt = 0.001 for Nt = 1000 steps, reaching final time T = 1.0.  

Apply Strang splitting each full time step dt:
1. Diffusion half‑step (duration dt/2) solved exactly in Fourier space:  
   - Compute û = FFT(u).  
   - Compute wave numbers k = 2*pi*fftfreq(Nx, d=dx).  
   - Update û ← û * exp(-nu*k^2*(dt/2)).  
   - Compute u ← real(IFFT(û)).  
2. Reaction full‑step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1‑u):  
   - u ← (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).  
3. Diffusion half‑step again using the same Fourier procedure as in step 1.  

After completing all Nt steps, compute u(x,T) on the grid.
