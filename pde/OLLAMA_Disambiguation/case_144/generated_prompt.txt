Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = 0.02*u_xx on the half‑open spatial domain [0,1) with periodic boundary conditions. Use a uniform grid with Nx = 512 points, dx = (1‑0)/512, and grid points x_i = i*dx for i = 0,…,511. Set the initial condition u(x,0) = sin(2π*x). Compute the final simulation time T = 1.0.

Determine the time step using CFL = 0.4 based on an estimated maximum wave speed of 1.0: dt0 = 0.4*dx/1.0. Choose Nt = ceil(T/dt0) and set dt = T/Nt so that the final time is reached exactly.

Advance the solution from t = 0 to t = T using Strang splitting with three substeps per full time step:
1. Diffusion half‑step (duration dt/2): transform u to Fourier space with FFT, multiply each Fourier coefficient by exp(-0.02*k^2*dt/2) where k = 2π*fftfreq(Nx, d=dx), then inverse transform and keep the real part.
2. Advection full‑step (duration dt): apply a finite‑volume update with the Rusanov (local Lax‑Friedrichs) flux. For each interface between cells j and j+1 (periodic indexing), compute f(u)=0.5*u^2, α = max(|u_j|,|u_{j+1}|), and flux F = 0.5*(f(u_j)+f(u_{j+1})) - 0.5*α*(u_{j+1}-u_j). Update each cell by u_new[j] = u[j] - (dt/dx)*(F_{j+½} - F_{j‑½}). Replace u with u_new.
3. Diffusion half‑step again, identical to step 1.

After completing Nt time steps, obtain u(x,T) on the grid.

- u : 1‑D array of length Nx with the solution at time T,
and the scalar values nu, T, dx, dt, Nx, Nt.
