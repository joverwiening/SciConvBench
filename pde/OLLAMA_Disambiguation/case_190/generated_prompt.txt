Solve the PDE u_t = nu * u_xx + rho * u * (1 - u) on the periodic domain x in [0,1) with t in [0,1.0].
Use parameters nu = 5.0 and rho = 2.0.
Set the initial condition u(x,0) = 0.25 + 0.1 * sin(2 * pi * x).
Create a uniform periodic spatial grid with Nx = 512 points, x_j = j * dx for j = 0,…,511, where dx = 1 / 512 = 0.001953125.
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.
Advance the solution from t = 0 to t = 1.0 using Strang splitting for each time step dt:
(A) Perform a diffusion half-step of duration dt/2 by transforming u to Fourier space, multiplying each Fourier coefficient by exp(-nu * k^2 * (dt/2)) where k = 2 * pi * fftfreq(Nx, d=dx), and transforming back with an inverse FFT, taking the real part.
(B) Perform a reaction full-step of duration dt by applying the exact logistic update at each grid point: u <- (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
(C) Perform another diffusion half-step identical to step (A).
After completing all Nt steps, compute the solution u(x,T) at T = 1.0 on the periodic grid.
Save the results to a NumPy .npz file named "solution_pdebench_reacdiff_nu5_rho2.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values nu, rho, T, dx, dt, Nx, and Nt.
Create a line plot of u(x,T) versus x and save it as "solution_pdebench_reacdiff_nu5_rho2.png".
Print the diagnostics: the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2) * dx) at the final time.
