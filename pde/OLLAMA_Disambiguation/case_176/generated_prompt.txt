Solve the PDE u_t = nu * u_xx + rho * u * (1 - u) for x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set the parameters nu = 10.0 and rho = 1.0.
Use a uniform periodic spatial grid with Nx = 512 points, x_j = j * dx for j = 0,…,511, where dx = 1 / 512 = 0.001953125.
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.
Advance the solution from t = 0 to t = 1.0 using Strang splitting for each time step dt:
(A) Perform a diffusion half-step of duration dt/2 by transforming u to Fourier space, multiplying each Fourier coefficient by exp(-nu * k^2 * (dt/2)) with k = 2π * fftfreq(Nx, d=dx), and transforming back with an inverse FFT, taking the real part.
(B) Perform a reaction full-step of duration dt by updating each grid point exactly for the logistic ODE: u ← (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
(C) Perform another diffusion half-step identical to step (A).
Initialize the solution at t = 0 with u(x,0) = 0.25 + 0.1 * sin(2 * π * x).
After the final time step, compute u(x,T) on the periodic grid.
Save the arrays x (length Nx) and u (length Nx) together with the scalars nu, rho, T, dx, dt, Nx, and Nt in a NumPy .npz file named "solution_pdebench_reacdiff_nu10_rho1.npz".
Create a line plot of u(x,T) versus x and save it as "solution_pdebench_reacdiff_nu10_rho1.png".
Print the diagnostics at T: the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt( sum(u^2) * dx ).
