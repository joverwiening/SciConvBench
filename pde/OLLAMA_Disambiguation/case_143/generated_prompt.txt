Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx on the half‑open spatial interval [0,1) with periodic boundary conditions. Use nu = 0.01, initial condition u(x,0) = sin(2*pi*x), and final time T = 1.0.

Create a uniform grid with Nx = 512 points: dx = (1‑0)/Nx, x_i = i*dx for i = 0,…,Nx‑1. Compute the time step using CFL = 0.4 and an estimated maximum wave speed of 1: dt0 = CFL*dx/1.0, Nt = ceil(T/dt0), and set dt = T/Nt so that the final time is reached exactly.

Advance the solution from t = 0 to t = T using Strang splitting for each full time step dt:
1. Diffusion half‑step (dt/2): transform u to Fourier space with FFT, multiply each mode by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then inverse FFT and keep the real part.
2. Advection full‑step (dt): apply a finite‑volume update with the Rusanov (local Lax‑Friedrichs) flux. For each interface between cells j and j+1 (periodic indexing), compute
   f(u) = 0.5*u^2,
   alpha = max(|u_j|, |u_{j+1}|),
   F_{j+1/2} = 0.5*(f(u_j) + f(u_{j+1})) - 0.5*alpha*(u_{j+1} - u_j).
   Then update each cell:
   u_new_j = u_j - (dt/dx)*(F_{j+1/2} - F_{j-1/2}).
   Replace u with u_new after this substep.
3. Diffusion half‑step again, identical to step 1.

After completing Nt steps, obtain u(x,T) on the grid.

Save the results to a NumPy .npz file named "solution_pdebench_burgers_nu0p01.npz" containing the arrays:
- x : 1‑D array of length Nx,
- u : 1‑D array of length Nx (solution at T),
and the scalar values nu, T, dx, dt, Nx, Nt.

Create a line plot of u versus x at the final time and save it as "solution_pdebench_burgers_nu0p01.png".

Print the following diagnostics for the solution at T:
- Minimum value of u,
- Maximum value of u,
- Discrete mean value mean(u) = (1/Nx)*sum(u) (should be approximately conserved),
- Discrete L2 norm sqrt(sum(u^2)*dx).
