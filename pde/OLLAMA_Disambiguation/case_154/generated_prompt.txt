Use a periodic spatial domain [0, 1] with uniform grid points x_i = i*dx for i = 0,…,511 where Nx = 512 and dx = (1‑0)/Nx = 1/512.  
Set the viscosity nu = 0.004 and the final simulation time T = 1.0.  
Initialize the solution u(x,0) = sin(2 π x).  

Compute the time step dt as follows: estimate the maximum wave speed as 1, use CFL = 0.4, set dt0 = CFL * dx / 1, choose Nt = ceil(T/dt0), and then set dt = T / Nt so that the final time is reached exactly.  

Advance the solution from t = 0 to t = T using Strang splitting for each full time step dt:  

A. Diffusion half‑step (duration dt/2) solved exactly in Fourier space:  
 • Compute the discrete Fourier transform û = FFT(u).  
 • Define wave numbers k = 2 π fftfreq(Nx, d=dx).  
 • Multiply û by exp(‑nu *k² * (dt/2)).  
 • Obtain the updated u by inverse FFT and keep the real part.  

B. Advection full‑step (duration dt) for the inviscid Burgers equation using a finite‑volume Rusanov (local Lax‑Friedrichs) flux:  
 • Define the flux function f(u) = 0.5 *u².  
 • For each interface between cells j and j+1 (periodic indexing), compute  
  alpha = max(|u_j|, |u_{j+1}|)  
  F_{j+½} = 0.5 [ f(u_j) + f(u_{j+1}) ] – 0.5 alpha ( u_{j+1} – u_j ).  
 • For each cell j, update  
  u_new_j = u_j – (dt/dx) [ F_{j+½} – F_{j‑½} ].  
 • Replace u with u_new after this substep.  

C. Diffusion half‑step again, identical to step A.  

Repeat steps A–C Nt times.  

After reaching t = T, compute the diagnostics:  
 • min(u), max(u)  
 • discrete mean value mean(u) = (1/Nx) ∑_j u_j (should be approximately conserved)  
 • discrete L2 norm = sqrt( ∑_j u_j² * dx ).  

Save the results:  
 • Create a NumPy .npz file named "solution_pdebench_burgers_nu4em3.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values nu, T, dx, dt, Nx, Nt.  
 • Generate a line plot of u versus x at t = T and save it as "solution_pdebench_burgers_nu4em3.png".  

Print the four diagnostics (min, max, mean, L2 norm) to standard output.
