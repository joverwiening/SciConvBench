Solve the Klein‑Gordon equation  
u_tt - (1.0)^2*u_xx + (1.0)^2*u = sin(pi*x)*cos(2*t)  
on the spatial interval x∈[0,1] and time interval t∈[0,5.0] with c=1.0 and m=1.0.  
Use a uniform grid with Nx=400 intervals, so dx = (1‑0)/400 = 0.0025 and grid points x_i = i*dx for i = 0,…,400.  
Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.  
Set the initial displacement u(x,0)=0 and initial velocity u_t(x,0)=0.  

Discretize the spatial second derivative u_xx with a second‑order central difference.  
Integrate in time with a second‑order central difference (leapfrog) scheme:  

u_i^{n+1} = 2*u_i^{n} - u_i^{n‑1} + dt^2 * ( c^2 * (u_{i+1}^{n} - 2*u_i^{n} + u_{i‑1}^{n})/dx^2 - m^2 * u_i^{n} + f_i^{n} )  

where the forcing term f_i^{n} = sin(pi*x_i) * cos(2*t_n).  

Choose the time step dt = 0.001 (5000 steps) which satisfies c*dt/dx = 0.001/0.0025 = 0.4 ≤ 0.9.  

Initialize the first time level using a Taylor expansion that includes the -m^2*u term and the forcing:  

u_i^{1} = u_i^{0} + dt * v_i^{0} + 0.5*dt^2 * ( c^2 * (u_{i+1}^{0} - 2*u_i^{0} + u_{i‑1}^{0})/dx^2 - m^2 * u_i^{0} + f_i^{0} )  

with v_i^{0}=u_t(x_i,0)=0.  

Advance the solution for 5000 steps to reach the final time T = 5.0 and compute the array u(x,T).
