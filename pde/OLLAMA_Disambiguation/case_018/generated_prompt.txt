Solve the PDE u_t = ∂/∂x( D(x) * u_x ) with D(x) = 0.01 + 0.09*x^2 on the spatial domain x ∈ [0,1] and time interval t ∈ [0,0.2]. Use the initial condition u(x,0) = x*(1 - x) for 0 ≤ x ≤ 1. Apply Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0 for all t.

Discretize the spatial domain with Nx = 400 uniform intervals, giving Nx+1 = 401 grid points x_i = i*dx where dx = (1 - 0)/400 = 0.0025 and i = 0,…,400. Compute D_i = D(x_i). Approximate the diffusion operator in flux form with second‑order conservative differences: for interior i = 1,…,399,
( (D u_x)_x )_i ≈ (1/dx^2) * [ D_{i+1/2} (u_{i+1} - u_i) - D_{i-1/2} (u_i - u_{i-1}) ],
where D_{i+1/2} = 0.5*(D_i + D_{i+1}).

Integrate in time from t = 0 to T = 0.2 using implicit Euler with time step dt = 0.0005 (400 steps). At each step solve the linear system (I - dt*L) u^{n+1} = u^n, where L is the matrix representing the discrete diffusion operator defined above and incorporates the Dirichlet boundary conditions (u_0 = u_{400} = 0).

After completing all time steps, compute the solution u(x,T) at the final time T = 0.2 on the grid points.

Save the results to a NumPy .npz file named "solution_agent_diffusion_02.npz" containing the arrays:

and the scalar metadata:
- T : final time (0.2)
- dx : spatial step size (0.0025)
- dt : time step size (0.0005)
