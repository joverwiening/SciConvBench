Use a uniform periodic grid on the interval [0, 1) with Nx = 512 points: dx = 1/Nx and x_i = i*dx for i = 0,…,Nx‑1.  
Set the viscosity nu = 4.0 and the final simulation time T = 1.0.  
Initialize the solution as u(x,0) = sin(2π x).  

Compute the time step using CFL = 0.4 and an estimated maximum wave speed of 1.0: dt₀ = CFL*dx/1.0.  
Set Nt = ceil(T/dt₀) and then define the actual time step dt = T/Nt so that the final time is reached exactly.  

For each of the Nt time steps perform a Strang splitting:

1. Diffusion half‑step (duration dt/2):  
   • Compute the Fourier transform û = FFT(u).  
   • Form the wave numbers k = 2π·fftfreq(Nx, d=dx).  
   • Multiply û by exp(‑nu·k²·(dt/2)).  
   • Obtain the updated u by the inverse FFT and keep the real part.

2. Advection full‑step (duration dt) for the inviscid Burgers equation using a finite‑volume Rusanov flux:  
   • Define the flux function f(u) = 0.5 u².  
   • For each interface j (periodic indexing) with left state u_L = u[j] and right state u_R = u[(j+1) mod Nx], compute  
     α = max(|u_L|, |u_R|) and  
     F_j = 0.5·(f(u_L)+f(u_R)) ‑ 0.5·α·(u_R‑u_L).  
   • For each cell j, set F_plus = F_j and F_minus = F_{j‑1}.  
   • Update the cell value: u_new[j] = u[j] ‑ (dt/dx)·(F_plus ‑ F_minus).  
   • Replace u with u_new.

3. Diffusion half‑step again, identical to step 1.

After completing all Nt steps, the array u contains the numerical solution at time T.

and the scalar values: nu, T, dx, dt, Nx, Nt.
