Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx on the periodic domain x∈[0,1] with nu = 0.002, initial condition u(x,0) = sin(2*pi*x), and final time T = 1.0.  
Use a uniform grid with Nx = 512 points, dx = (1‑0)/Nx, and grid points x_i = i*dx for i = 0,…,511.  
Determine the time step by CFL = 0.4 with an estimated maximum wave speed of 1: compute dt0 = CFL*dx, set Nt = ceil(T/dt0), and then set dt = T/Nt so that the final time is reached exactly.  
Advance the solution from t = 0 to t = T using Strang splitting with three substeps per full time step:  
1. Diffusion half‑step (duration dt/2) solved exactly in Fourier space: compute the FFT of u, multiply each Fourier mode by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then inverse FFT and keep the real part.  
2. Advection full‑step (duration dt) for the inviscid Burgers equation using a finite‑volume update with the Rusanov (local Lax‑Friedrichs) flux: for each interface between cells j and j+1 (periodic indexing) compute alpha = max(|u_j|,|u_{j+1}|), flux F = 0.5*(0.5*u_j^2 + 0.5*u_{j+1}^2) - 0.5*alpha*(u_{j+1} - u_j); then update each cell u_j ← u_j - (dt/dx)*(F_{j+1/2} - F_{j-1/2}).  
3. Diffusion half‑step again identical to step 1.  
After completing Nt time steps, obtain the solution u(x,T).
