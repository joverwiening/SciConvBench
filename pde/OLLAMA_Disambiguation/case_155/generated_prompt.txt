Solve the 1D compressible Navier–Stokes equations (no heat conduction) on the domain x ∈ [‑1, 1] with periodic boundary conditions and final time T = 0.5.

Use a uniform finite‑volume grid with Nx = 400 cells. The cell width is dx = (1 ‑ (‑1))/400 = 0.005. Cell centers are x_j = ‑1 + (j + 0.5)*dx for j = 0,…,399.

Evolve the conservative variables U = [ρ, m, E] (cell averages) using the following components:

- Equation of state: p = (Γ‑1)·(E ‑ 0.5·m²/ρ) with Γ = 1.6666666666666667. Clip ρ and p to a floor of 1e‑12 if needed to maintain positivity.
- Convective flux: F_conv(U) = [ m, m²/ρ + p, (E + p)·v ] where v = m/ρ.
- Interface wave speed: a = max( |v_L| + c_L, |v_R| + c_R ) with sound speed c = sqrt(Γ·p/ρ).
- Rusanov (local Lax‑Friedrichs) numerical flux: F̂ = 0.5·(F_conv(U_L) + F_conv(U_R)) ‑ 0.5·a·(U_R ‑ U_L).
- Viscous stress: σ = (ζ + 4/3·η)·v_x, with η = 0.01, ζ = η = 0.01. Compute v_x by a centered difference on cell‑centered v values; obtain σ at interfaces by averaging neighboring cell‑centered σ.
- Viscous flux at interfaces: F_visc = [ 0, ‑σ, ‑v·σ ] using interface‑averaged v and σ.
- Total interface flux: F_total = F̂ + F_visc.
- Time integration: 2‑stage SSP‑RK2 (Heun’s method) applied to the semi‑discrete finite‑volume system.
- Time step: For each step compute
    dt_conv = CFL·dx / max_j( |v_j| + c_j ),
    dt_visc = 0.5·dx² / max( ζ + 4/3·η, 1e‑30 ),
  with CFL = 0.5. Choose dt = min(dt_conv, dt_visc) and adjust the final step to reach T exactly.
- Boundary conditions: periodic; implement by wrapping ghost‑cell indices.

Initial conditions (evaluated pointwise at cell centers):
- ρ(x,0) = 1.0 + 0.2·sin(π·x)
- v(x,0) = 0.1·cos(π·x)
- p(x,0) = 1.0 + 0.2·cos(π·x)
Compute initial conservative variables from these values.

After advancing to t = T, compute the primitive variables ρ, v, p on the cell centers.
