Solve the PDE u_t = ∂/∂x( D(x) * u_x ) with D(x) = 0.1*(1 + x) on the spatial domain x ∈ [0,1] and time interval t ∈ [0,0.5].
Use a uniform grid with Nx = 300 intervals, giving Nx+1 = 301 grid points x_i = i*dx where dx = (1‑0)/300.
Set the time step dt = 0.001 and advance for 500 steps to reach T = 0.5.
Apply Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0 for all times.
Initialize the solution with u(x,0) = sin(π x) evaluated at each grid point.
Discretize the spatial diffusion operator in flux form using a second‑order conservative scheme: define D_i = D(x_i) and face values D_{i+1/2} = 0.5*(D_i + D_{i+1}); for interior nodes i = 1,…,Nx‑1 compute (D u_x)_x ≈ (1/dx²)[ D_{i+1/2}(u_{i+1}‑u_i) – D_{i‑1/2}(u_i‑u_{i‑1}) ].
Integrate in time with the implicit Euler method: (I – dt L) u^{n+1} = u^{n}, where L is the matrix representing the discrete diffusion operator; solve the resulting sparse linear system at each step.
After the final step, compute u(x,T) on the grid.
Save the results to a NumPy .npz file named "solution_agent_diffusion_01.npz" containing the arrays x (1‑D), u (1‑D, same length as x), and the scalar metadata values T, dx, dt.
Create a line plot of u(x,T) versus x and save it as "solution_agent_diffusion_01.png".
