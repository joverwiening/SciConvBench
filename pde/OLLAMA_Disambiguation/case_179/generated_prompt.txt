Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) on the periodic domain x in [0,1) and t in [0,1.0] with nu = 10.0 and rho = 5.0.  
Use a uniform periodic spatial grid with Nx = 512 points, x_j = j*dx for j = 0,…,511 where dx = 1/512.  
Use a fixed time step dt = 0.001, resulting in Nt = 1000 time steps so that T = 1.0 is reached exactly.  
Advance the solution from t = 0 to t = 1.0 using Strang splitting for each time step dt:  
(A) Perform a diffusion half-step of duration dt/2 by transforming u to Fourier space, multiplying each Fourier coefficient by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), and transforming back with an inverse FFT, taking the real part.  
(B) Perform a reaction full-step of duration dt by updating each grid point with the exact logistic solution: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).  
(C) Perform another diffusion half-step identical to (A).  
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x).  
At final time T = 1.0, compute u(x,T) on the grid.  
Save the results to "solution_pdebench_reacdiff_nu10_rho5.npz" containing arrays x (length Nx) and u (length Nx) and the scalar values nu, rho, T, dx, dt, Nx, Nt.  
Create a line plot of u(x,T) and save it as "solution_pdebench_reacdiff_nu10_rho5.png".  
Print the minimum, maximum, mean of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
