Spatial domain is the half‑open interval [0, 1) with periodic boundary conditions u(0,t)=u(1,t).  
Use a uniform grid with Nx = 512 points: dx = (1‑0)/Nx = 1/512, x_i = i*dx for i = 0,…,511.  
Set parameters nu = 1.0 and rho = 1.0.  
Initial condition: u(x,0) = 0.25 + 0.1 * sin(2 π x) (radians).  
Time step dt = 0.001, number of steps Nt = 1000, final time T = Nt * dt = 1.0.  

For each time step apply Strang splitting:
1. Diffusion half‑step (duration dt/2):  
   - Compute û(k) ← FFT(u).  
   - Wave numbers k ← 2 π * fftfreq(Nx, d=dx).  
   - Multiply û(k) by exp(‑nu * k² * (dt/2)).  
   - Compute u ← real(IFFT(û)).  
2. Reaction full‑step (duration dt): update each grid point exactly for du/dt = rho u(1‑u):  
   u ← (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) ‑ 1)).  
3. Diffusion half‑step again as in step 1.  

After Nt steps, u(x,T) is the final solution.

- x (1‑D length Nx)  
- u (1‑D length Nx)  

and scalars: nu, rho, T, dx, dt, Nx, Nt.
