Solve the PDE u_t = nu*u_xx + rho*u*(1 - u) on the periodic domain x ∈ [0,1) for time t ∈ [0,1] with parameters nu = 2.0 and rho = 1.0.  
Use a uniform periodic grid with Nx = 512 points defined by x_j = j*dx for j = 0,…,511 where dx = 1/512.  
Use a fixed time step size dt = 0.001 and perform Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
Apply Strang splitting each full time step dt: first a diffusion half-step of duration dt/2, then a reaction full-step of duration dt, then another diffusion half-step of duration dt/2.  
For each diffusion half-step compute the Fourier transform û = FFT(u), define wave numbers k = 2*pi*fftfreq(Nx, d=dx), multiply û by exp(-nu*k^2*(dt/2)), and obtain the updated u by taking the real part of the inverse FFT of the modified û.  
For the reaction full-step update each grid point using the exact logistic solution u ← (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).  
Initialize the solution with u(x,0) = 0.25 + 0.1*sin(2*pi*x).  
The periodic boundary condition u(0,t) = u(1,t) is satisfied automatically by the Fourier-based diffusion step.  
After completing all Nt steps compute the solution u(x,T) at T = 1.0.  
Save the arrays x and u and the scalars nu, rho, T, dx, dt, Nx, Nt to a file named "solution_pdebench_reacdiff_nu2_rho1.npz".  
Save a line plot of u versus x to "solution_pdebench_reacdiff_nu2_rho1.png".  
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time.
