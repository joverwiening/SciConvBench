Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1 - u) on the periodic domain x ∈ [0,1) for time t ∈ [0,1.0] with nu = 5.0 and rho = 1.0.

Use a uniform periodic spatial grid with Nx = 512 points: dx = (1‑0)/Nx = 1/512, and grid points x_j = j*dx for j = 0,…,511.

Use a fixed time step dt = 0.001, giving Nt = T/dt = 1000 steps so that the final time T = 1.0 is reached exactly.

Advance the solution from t = 0 to t = 1.0 with Strang splitting each full time step dt:
1. Diffusion half‑step (duration dt/2):
   - Compute the discrete Fourier transform û = FFT(u).
   - Compute wave numbers k = 2π*fftfreq(Nx, d=dx).
   - Multiply û by exp(-nu*k^2*(dt/2)).
   - Obtain the updated u by inverse FFT and keep the real part.
2. Reaction full‑step (duration dt):
   - Update each grid point pointwise using the exact logistic solution:
     u ← (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
3. Diffusion half‑step again, identical to step 1.

Initial condition at t = 0: u(x,0) = 0.25 + 0.1*sin(2π*x).

After completing Nt steps, compute u(x,T) on the periodic grid.

Save the results to "solution_pdebench_reacdiff_nu5_rho1.npz" containing the arrays:
- x (length Nx)
- u (length Nx)
and the scalar values nu, rho, T, dx, dt, Nx, Nt.

Create a line plot of u(x,T) and save it as "solution_pdebench_reacdiff_nu5_rho1.png".

Print the following diagnostics at final time T:
- min(u)
- max(u)
- mean(u)
- discrete L2 norm sqrt( sum(u^2) * dx ).
