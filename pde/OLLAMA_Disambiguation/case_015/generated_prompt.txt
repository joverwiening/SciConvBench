Solve the one-dimensional viscous Burgers equation u_t + u*u_x = 0.01*u_xx on the spatial domain x ∈ [0,1] and time interval t ∈ [0,0.5] using the following numerical procedure.

Discretize the spatial domain with Nx = 800 uniform intervals, giving Nx+1 = 801 grid points x_i = i*dx for i = 0,…,800 where dx = 1/Nx = 0.00125.

Use a time step dt = 1e-4 and advance the solution for Nt = 5000 steps so that the final time T = 0.5 is reached exactly.

Treat the PDE in conservative form u_t + (f(u))_x = ν*u_xx with flux function f(u) = 0.5*u^2 and viscosity ν = 0.01.

Convection term: compute the numerical flux at each cell face i+½ using the Rusanov (local Lax–Friedrichs) flux
F_{i+½} = 0.5*(f(u_i) + f(u_{i+1})) - 0.5*α_{i+½}*(u_{i+1} - u_i),
where α_{i+½} = max(|u_i|, |u_{i+1}|). Approximate (f(u))_x by (F_{i+½} - F_{i-½})/dx.

Diffusion term: approximate the second derivative with a second‑order central difference
u_xx ≈ (u_{i+1} - 2*u_i + u_{i-1})/dx^2.

Time integration: use a first‑order IMEX scheme. For each time step n → n+1 solve
(u^{n+1} - u^n)/dt + (F^n_{i+½} - F^n_{i-½})/dx = ν * (u^{n+1}_{i+1} - 2*u^{n+1}_i + u^{n+1}_{i-1})/dx^2.
Form the linear system (I - dt*ν*L) u^{n+1} = u^n - dt*conv_term, where L is the discrete Laplacian matrix with Dirichlet boundary treatment, and solve it with a sparse linear solver (e.g., scipy.sparse.linalg.spsolve).

Boundary handling: enforce Dirichlet boundary conditions u[0] = 0 and u[Nx] = 0 at every time step. Use one‑sided differences or ghost cells consistent with the diffusion stencil, and compute convection fluxes using the prescribed boundary values.

Initial condition: set u(x,0) = sin(π*x) at all interior grid points.
