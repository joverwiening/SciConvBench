Q: Should I use the standard left‑biased upwind update u_i^{n+1}=u_i^{n}−(dt/dx)·a(x_i)·(u_i^{n}−u_{i−1}^{n}) for all interior points and apply periodic wrapping for the index i=0?
A: Yes. Use the left‑biased upwind formula  

\[
u_i^{n+1}=u_i^{n}-\frac{dt}{dx}\,a(x_i)\,\bigl(u_i^{n}-u_{i-1}^{n}\bigr)
\]

for every grid point, and apply periodic wrapping so that \(u_{-1}^{n}=u_{N-1}^{n}\) (i.e., the index 0 uses the value from the last point).
