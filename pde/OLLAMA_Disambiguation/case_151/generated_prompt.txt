Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx on the periodic domain x ∈ [0,1] with viscosity nu = 2.0.  
Use a uniform grid with Nx = 512 points, dx = (1‑0)/Nx, and grid points x_i = i*dx for i = 0,…,Nx‑1.  
Set the initial condition u(x,0) = sin(2*pi*x).  
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.  
Integrate to the final time T = 1.0 using Strang splitting with time step dt determined by CFL = 0.4 based on an estimated maximum wave speed of 1: compute dt0 = CFL*dx, set Nt = ceil(T/dt0), and then set dt = T/Nt so that the final time is reached exactly.  
For each full time step perform:  
(A) Diffusion half‑step of duration dt/2 solved exactly in Fourier space: compute the FFT of u, multiply each Fourier mode by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then inverse FFT and keep the real part.  
(B) Advection full‑step of duration dt for the inviscid Burgers equation using a finite‑volume update with the Rusanov (local Lax‑Friedrichs) flux: for each interface between cells j and j+1 (periodic indexing) compute alpha = max(|u_j|,|u_{j+1}|), flux F = 0.5*(0.5*u_j^2 + 0.5*u_{j+1}^2) - 0.5*alpha*(u_{j+1} - u_j); then update each cell u_j^{new} = u_j - (dt/dx)*(F_{j+1/2} - F_{j-1/2}). Replace u with u_new.  
(C) Diffusion half‑step again identical to (A).  
After completing Nt steps, compute the solution u(x,T).  
Save the results in a NumPy .npz file named "solution_pdebench_burgers_nu2.npz" containing arrays: x (length Nx), u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.  
Create a line plot of u versus x at time T and save it as "solution_pdebench_burgers_nu2.png".  
Print the minimum value of u, the maximum value of u, the discrete mean value mean(u) (which should be approximately conserved), and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time.
