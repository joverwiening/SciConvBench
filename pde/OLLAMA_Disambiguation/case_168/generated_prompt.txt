Solve the PDE -∇·(a(x,y)∇u(x,y)) = 1 on the domain (0,1)×(0,1) with Dirichlet boundary condition u = 0 on the entire boundary.

Use the coefficient a(x,y) = 1 + β (0.5 + 0.5 sin(2πx) sin(2πy)) with β = 0.1.

Create a uniform Cartesian grid with N = 128 intervals in each direction, giving N+1 = 129 grid points including the boundaries. Set dx = dy = 1/N = 1/128 and define grid coordinates x_i = i·dx for i = 0,…,N and y_j = j·dy for j = 0,…,N.

Discretize the interior nodes (i = 1,…,N‑1, j = 1,…,N‑1) using second‑order finite differences with variable coefficient and face‑centered harmonic averaging:
- Compute face coefficients as harmonic means, e.g. a(i+½,j) = 2 a(i,j) a(i+1,j) / (a(i,j)+a(i+1,j)), and similarly for a(i‑½,j), a(i,j+½), a(i,j‑½).
- Apply the discrete equation
  -(1/dx²)[ a(i+½,j)(u(i+1,j)‑u(i,j)) – a(i‑½,j)(u(i,j)‑u(i‑1,j))
           + a(i,j+½)(u(i,j+1)‑u(i,j)) – a(i,j‑½)(u(i,j)‑u(i,j‑1)) ] = 1.

Assemble the sparse linear system A u = b for all interior unknowns. Solve the symmetric positive‑definite system with the Conjugate Gradient method to a relative residual tolerance of 1e‑10, optionally using a Jacobi preconditioner.

After solving, compute u(x,y) on the full (N+1)×(N+1) grid, setting the boundary values to zero.

Save the results to a NumPy .npz file named "solution_pdebench_darcy_beta0p1.npz" containing:
- x : 1‑D array of length N+1,
- y : 1‑D array of length N+1,
- u : 2‑D array of shape (N+1, N+1),
- scalars beta, N, dx.
