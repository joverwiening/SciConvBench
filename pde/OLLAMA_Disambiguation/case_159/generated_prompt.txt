Solve the 1D compressible Navier–Stokes equations (no heat conduction) for the unknown fields rho(x,t), v(x,t), p(x,t) on the spatial domain x ∈ [‑1, 1] and time interval t ∈ [0, 0.2] using a uniform finite‑volume grid with Nx = 800 cells. The cell centers are x_j = –1 + (j+0.5)·dx for j = 0,…,799, where dx = (1 – (‑1))/800 = 0.0025.

Use the following parameters: Gamma = 1.6666666666666667, eta = 1e‑8, zeta = eta = 1e‑8.

Apply transmissive (zero‑gradient) outflow boundary conditions at both x = –1 and x = 1 by setting ghost‑cell values equal to the nearest interior cell.

Initialize with a Riemann shock‑tube condition discontinuous at x = 0:
- For x < 0: rho = 1.0, v = 0.0, p = 1.0.
- For x ≥ 0: rho = 0.1, v = 0.0, p = 0.01.

Evolve the conservative variables U = [rho, m, E] where m = rho·v and E = p/(Gamma‑1) + 0.5·rho·v², using the following numerical method:

1. Equation of state: p = (Gamma‑1)·(E – 0.5·m²/rho). Clip rho and p to a minimum of 1e‑12 to maintain positivity.
2. Convective flux (Rusanov):
   - Compute primitive v = m/rho and sound speed c = sqrt(Gamma·p/rho).
   - Interface wave speed a = max(|v_L|+c_L, |v_R|+c_R).
   - Convective flux F_conv(U) = [m, m²/rho + p, (E+p)·v].
   - Numerical flux F_hat = 0.5·(F_conv(U_L)+F_conv(U_R)) – 0.5·a·(U_R–U_L).
3. Viscous terms:
   - Compute v_x at cell centers with a centered difference.
   - sigma = (zeta + 4/3·eta)·v_x.
   - Approximate sigma at interfaces by averaging neighboring cell‑center sigma values.
   - Viscous flux F_visc = [0, –sigma, –v·sigma] using interface‑averaged v and sigma.
   - Total interface flux F_total = F_hat + F_visc.
4. Time integration: 2‑stage SSP‑RK2 (Heun’s method) applied to the semi‑discrete finite‑volume system.
5. Time step selection:
   - CFL = 0.5 (reasonable best‑practice value for explicit Rusanov schemes).
   - dt_conv = CFL·dx / max_j(|v_j|+c_j).
   - dt_visc = 0.5·dx² / max(zeta + 4/3·eta, 1e‑30).
   - dt = min(dt_conv, dt_visc); adjust the final step to reach T = 0.2 exactly.
6. Ghost cells: for outflow, copy the nearest interior cell values into ghost cells each stage.

After reaching the final time T = 0.2, compute rho(x,T), v(x,T), and p(x,T) at the cell centers. Save the results in a NumPy .npz file named “solution_pdebench_cns1d_shock_eta1em8_outflow.npz” containing arrays: x (length 800), rho, v, p, and scalars Gamma, eta, zeta, T, dx, CFL.

Create a line plot with three panels (or three separate plots) of rho, v, and p versus x at T and save it as “solution_pdebench_cns1d_shock_eta1em8_outflow.png”.

Print the following diagnostics:
- Minimum and maximum values of rho.
