Set the diffusion coefficient nu = 2.0 and the reaction coefficient rho = 10.0.  
Set the final time T = 1.0.  

Create a uniform periodic spatial grid on the interval [0,1) with Nx = 512 points: x_j = j*dx for j = 0,…,511, where dx = 1/512 = 0.001953125.  

Use a fixed time step dt = 0.001 and Nt = 1000 steps so that T is reached exactly (Nt = T/dt).  

Initialize the solution at t = 0 by u(x,0) = 0.25 + 0.1*sin(2*pi*x) evaluated at each grid point.  

For each time step apply Strang splitting:  
(A) Diffusion half‑step of duration dt/2: compute the FFT of u, multiply each Fourier mode by exp(-nu*k^2*(dt/2)) with k = 2*pi*fftfreq(Nx, d=dx), then inverse FFT and keep the real part.  
(B) Reaction full‑step of duration dt: update each grid point exactly for the logistic ODE du/dt = rho*u*(1‑u) using  
 u ← (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).  
(C) Diffusion half‑step again as in (A).  

After completing Nt steps, obtain the numerical solution u(x,T).  

Save the arrays x (length Nx) and u (length Nx) together with the scalars nu, rho, T, dx, dt, Nx, and Nt to a file named "solution_pdebench_reacdiff_nu2_rho10.npz".  

Create a line plot of u versus x and save it as "solution_pdebench_reacdiff_nu2_rho10.png".  

Print the following diagnostics at final time: the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt( sum(u**2) * dx ).
