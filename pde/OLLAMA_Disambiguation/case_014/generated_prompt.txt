Solve the Burgers equation u_t + u*u_x = 0.005*u_xx on the periodic spatial domain x ∈ [0,1) and time interval t ∈ [0,0.2] using the following numerical method.

Discretize the spatial domain with Nx = 1200 uniform cells, dx = 1/Nx, and grid points x_i = i*dx for i = 0,…,Nx‑1. Use periodic boundary conditions so that u_0 = u_Nx.

Treat the PDE in conservative form u_t + (f(u))_x = nu*u_xx with flux f(u) = 0.5*u^2 and diffusion coefficient nu = 0.005.

Convection term: compute the Rusanov (local Lax–Friedrichs) flux at each cell face
F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i),
where alpha_{i+1/2} = max(|u_i|,|u_{i+1}|). Approximate (f(u))_x by (F_{i+1/2}-F_{i-1/2})/dx.

Diffusion term: approximate u_xx with the second‑order central difference
(u_{i+1} - 2*u_i + u_{i-1})/dx^2.

Time integration: use a first‑order IMEX scheme with dt = 5e-5 and Nt = 4000 steps so that the final time T = 0.2 is reached exactly.
For each step solve
(u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1} - 2*u^{n+1}_i + u^{n+1}_{i-1})/dx^2.
Form the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term, where L is the periodic second‑difference operator, and solve it with a sparse linear solver (e.g., scipy.sparse.linalg.spsolve).

Initial condition: u(x,0) = 0.5 + sin(2*pi*x) evaluated at the grid points.

After completing Nt steps, compute the solution u(x,T) at T = 0.2 on the same grid.

and the scalar metadata:
