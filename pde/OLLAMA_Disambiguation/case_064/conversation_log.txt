Q: Should the Dirichlet boundary values be set using the exact solution u(x,y)=sin(2πx)·sinh(2πy)/sinh(2π) on all four sides of the domain?
A: Yes. The Dirichlet values on the four edges should be those given in the complete requirement ( u(x,0)=0, u(x,1)=sin(2πx), u(0,y)=0, u(1,y)=0 ), which are exactly the values obtained from the exact solution u(x,y)=sin(2πx)·sinh(2πy)/sinh(2π) on each side.
