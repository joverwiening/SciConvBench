Define the spatial domain as the half‑open interval [0, 1) with periodicity and use Nx = 512 uniform grid points. Compute dx = (1 − 0)/Nx = 1/512 and set grid points x_i = i*dx for i = 0,…,511.  
Set the advection speed beta = 1.0.  
Impose periodic boundary conditions u(0, t) = u(1, t) for all t.  
Initialize the field with u(x, 0) = sin(2 π x) + 0.5 sin(4 π x).  
Discretize the spatial derivative u_x with a first‑order upwind finite difference using the upwind direction determined by the sign of beta; because beta > 0, use the backward difference (u_i − u_{i‑1})/dx with periodic wrap for i = 0.  
Integrate in time with the explicit forward Euler method.  
Choose the time step from CFL = 0.5: dt = CFL * dx / |beta| = 0.5 * dx = 0.5/512 = 0.0009765625.  
Set the final simulation time T = 2.0, compute the number of steps Nt = ceil(T/dt) = 2048, and then reset dt = T/Nt so that the final time is reached exactly (dt remains 0.0009765625).  
For each time step n = 0,…,Nt‑1 update the solution by  
u_i^{n+1} = u_i^{n} − beta * dt * (u_i^{n} − u_{i‑1}^{n})/dx,  
applying periodic indexing for i = 0 (u_{‑1} = u_{Nx‑1}).  
After Nt steps obtain the numerical solution u(x, T) on the grid.  
Compute the reference solution on the same grid as u_ref(x, T) = sin(2 π ((x − beta T) mod 1)) + 0.5 sin(4 π ((x − beta T) mod 1)).  
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(∑ u_i² * dx).  
Compute and print the maximum absolute error max|u − u_ref| and the L2 error sqrt(∑ (u_i − u_ref_i)² * dx).
