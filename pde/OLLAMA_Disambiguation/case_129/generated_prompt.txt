Use a uniform periodic grid on the interval [0,1) with Nx = 1024 points. Compute the grid spacing dx = 1/Nx and the grid points x_j = j*dx for j = 0,…,1023.

Initialize the solution array u_j^0 = 0.5 * sin(2 π x_j).

Define the flux function f(u) = (1/3) u³ and its derivative f'(u) = u².

Set the CFL number to 0.2. Estimate the maximum wave speed using the initial condition: max|f'(u)| ≤ 0.25 because |u| ≤ 0.5 initially. Compute the provisional time step dt₀ = CFL * dx / 0.25. Determine the number of time steps Nt = ceil(T / dt₀) where T = 0.2, and set the final time step dt = T / Nt.

For each time step n = 0,…,Nt‑1, advance the solution from tⁿ to tⁿ⁺¹ using the second‑order strong stability preserving Runge–Kutta (SSP‑RK2) method:

1. Compute the numerical flux at each cell interface using the Rusanov (local Lax‑Friedrichs) flux:
   F_{j+½} = ½[ f(u_j) + f(u_{j+1}) ] – ½ a_{j+½} ( u_{j+1} – u_j ),
   where a_{j+½} = max( |f'(u_j)|, |f'(u_{j+1})| ).

2. Update a first intermediate solution:
   u_j^{(1)} = u_jⁿ – (dt/dx) [ F_{j+½} – F_{j‑½} ].

3. Compute the numerical flux again using u^{(1)} to obtain F_{j+½}^{(1)}.

4. Update the solution to the next time level:
   u_j^{n+1} = ½ u_jⁿ + ½ [ u_j^{(1)} – (dt/dx) ( F_{j+½}^{(1)} – F_{j‑½}^{(1)} ) ].

Apply periodic boundary conditions when accessing u_{-1} and u_{Nx} (i.e., treat u_{-1}=u_{Nx‑1} and u_{Nx}=u_0).

After completing Nt steps, the solution u_j at t = 0.2 is the final result. No exact reference solution is required for verification.
