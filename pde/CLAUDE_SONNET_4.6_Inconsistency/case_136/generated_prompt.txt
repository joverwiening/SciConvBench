Solve the 1D advection PDE numerically and save the results as specified below.

PDE: u_t + beta * u_x = 0

Domain: x in [0, 1) with periodic boundary, t in [0, 2.0].

Parameter: beta = 0.2.

Boundary condition: Periodic, u(0, t) = u(1, t) for all t.

Initial condition: u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

Reference solution: u(x, t) = u0((x - beta*t) mod 1), where u0 is the initial condition.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1). Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.

Use 1st-order upwind finite difference for u_x. Since beta = 0.2 > 0, use the left-sided (backward) difference: u_x at j approximated by (u_j - u_{j-1}) / dx, with index j-1 taken modulo Nx for periodicity.

Use explicit forward Euler time integration.

Set CFL = 0.5. Compute dt = CFL * dx / abs(beta). Compute Nt = ceil(T / dt) where T = 2.0. Reset dt = T / Nt so the final time T = 2.0 is hit exactly.

At each time step, update: u_j^{n+1} = u_j^n - beta * dt / dx * (u_j^n - u_{j-1}^n), with periodic indexing.

After advancing to T = 2.0, compute the reference solution on the same grid using u_ref_j = u0((x_j - beta*T) mod 1).

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 2.0.

Print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx).

Save a file named "solution_pdebench_advection_beta0p2.npz" containing: array x of length Nx, array u of length Nx, and scalars beta, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) versus x as "solution_pdebench_advection_beta0p2.png".
