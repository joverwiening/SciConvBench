Solve the PDE u_t + a(x)*u_x = 0 where a(x) = 1 + 0.5*sin(2*pi*x) numerically in Python.
The spatial domain is x in [0,1) periodic with Nx=1200 uniform grid points, no duplicated endpoint, dx=1/1200, x_i = i*dx for i=0..1199.
The time domain is t in [0, T] where T=0.5.
The initial condition is u(x,0) = sin(2*pi*x).
Boundary conditions are periodic: u(0,t)=u(1,t).
Use upwind spatial discretization with a left-biased stencil since a(x)>0 everywhere: u_x at point i is approximated as (u[i] - u[i-1])/dx using modular indexing for periodicity.
Set amax=1.5, dt0=0.9*dx/amax, Nt=ceil(T/dt0), dt=T/Nt so the final time T=0.5 is hit exactly.
Use Forward Euler time integration: u[i]^(n+1) = u[i]^n - dt*a(x[i])*(u[i]^n - u[i-1]^n)/dx.
After advancing Nt steps, the solution u(x, T=0.5) is stored in a 1D array of length 1200.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.
Save a file named "solution_agent_advection_03.npz" containing arrays x (1D, length 1200), u (1D, length 1200), and scalar metadata T=0.5, dx=1/1200, dt=T/Nt.
Save a line plot of u(x, T=0.5) versus x as "solution_agent_advection_03.png".
Use radians for all trigonometric functions.
Use ** for exponentiation in Python code.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
Nx = 1200
T = 0.5
dx = 1.0 / Nx
x = np.arange(Nx) * dx

# Velocity field
a = 1.0 + 0.5 * np.sin(2 * np.pi * x)

# Time stepping
amax = 1.5
dt0 = 0.9 * dx / amax
Nt = int(np.ceil(T / dt0))
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL_max={amax*dt/dx:.4f}")

# Initial condition
u = np.sin(2 * np.pi * x)

# Forward Euler + upwind (left-biased, since a(x)>0 everywhere)
for n in range(Nt):
    u_left = np.roll(u, 1)          # u[i-1] via periodic shift
    dudx = (u - u_left) / dx       # left-biased upwind difference
    u = u - dt * a * dudx          # Forward Euler update

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# Save .npz
np.savez("solution_agent_advection_03.npz",
         x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_advection_03.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.0, color='steelblue', label=f'u(x, T={T})')
ax.set_xlabel('x')
ax.set_ylabel('u')
ax.set_title(f'Advection solution at T={T}  (Nx={Nx}, Nt={Nt})')
ax.legend()
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_agent_advection_03.png", dpi=150)
plt.close()
print("Saved solution_agent_advection_03.png")
```
