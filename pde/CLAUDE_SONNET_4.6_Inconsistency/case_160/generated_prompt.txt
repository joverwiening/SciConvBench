Solve the 1D compressible Navier-Stokes equations (no heat conduction) for rho(x,t), v(x,t), p(x,t) in conservative form using Python.

The conservative variables are U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v**2.

The viscous stress is sigma = (zeta + 4/3*eta) * v_x with zeta = eta = 1e-08.

The PDEs are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

Use Gamma = 5/3 (1.6666666666666667). Ignore the contradictory second Gamma line (0.166666666667) in the parameters; use Gamma = 5/3.

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use a uniform finite-volume grid with Nx = 800 cells. Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., 799, with dx = 2/800.

Set the initial condition as a Riemann problem with discontinuity at x = 0: for x < 0 set rho = 1.0, v = 0.0, p = 1.0; for x >= 0 set rho = 0.125, v = 0.0, p = 0.1.

Apply outflow (zero-gradient) boundary conditions at both x = -1 and x = 1 by setting ghost cell values equal to the nearest interior cell value.

Use the equation of state p = (Gamma - 1) * (E - 0.5*m**2/rho). Clip rho and p to a minimum floor of 1e-12 to enforce positivity.

Compute the convective (Euler) flux at each interface using the Rusanov (local Lax-Friedrichs) scheme. The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] with v = m/rho. The interface wave speed is a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho). The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Reconstruct interface states using piecewise-constant (first-order) reconstruction, so U_L at interface j+1/2 is the value in cell j and U_R is the value in cell j+1.

Compute cell-centered v_x using centered differences: v_x[j] = (v[j+1] - v[j-1]) / (2*dx) for interior cells. At boundary cells use one-sided differences consistent with the outflow ghost cells.

Compute cell-centered sigma = (zeta + 4/3*eta) * v_x.

Compute the interface viscous stress sigma_interface at interface j+1/2 as the average of sigma[j] and sigma[j+1].

Compute the interface velocity v_interface at interface j+1/2 as the average of v[j] and v[j+1].

The viscous flux vector at each interface is F_visc = [0, -sigma_interface, -v_interface * sigma_interface].

The total interface flux is F_total = F_hat + F_visc.

Update cell averages using the finite-volume formula: dU/dt = -(F_total[j+1/2] - F_total[j-1/2]) / dx.

Integrate in time using 2-stage SSP-RK2 (Heun's method): U_star = U^n + dt * L(U^n), then U^{n+1} = 0.5*U^n + 0.5*(U_star + dt * L(U_star)).

Choose the time step each stage as dt = min(dt_conv, dt_visc) where dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30). Use CFL = 0.8.

Adjust the final time step so the simulation ends exactly at T = 0.2.

After the simulation, recover rho, v, p from the conservative variables at all cell centers.

Save a file named "solution_pdebench_cns1d_sod1_eta1em8_outflow.npz" containing 1D arrays x, rho, v, p (each of length 800) and scalars Gamma, eta, zeta, T, dx, CFL.

Print the minimum and maximum of rho over all cells, the minimum and maximum of p over all cells, and the mean of rho over the domain as a mass conservation diagnostic.
