Solve the heat equation u_t = 0.1 * u_xx numerically using the Crank-Nicolson method and save the results.

The PDE is u_t = 0.1 * u_xx (alpha = 0.1).
The spatial domain is x in [0, 1] (closed interval).
The time domain is t in [0, 0.5].
Use Nx = 200 uniform intervals, giving 201 grid points including both endpoints.
Set dx = 1/200 = 0.005.
Set dt = 0.001 and run for 600 time steps to reach T = 0.5.
The grid points are x_i = i * dx for i = 0, 1, ..., 200.
Apply Dirichlet boundary conditions: u(0, t) = 1 and u(1, t) = 0 for all t.
Set the initial condition u(x, 0) = 1 - x at all interior and boundary grid points.
Discretize u_xx using second-order central differences at interior points only.
Apply the Crank-Nicolson scheme: form the tridiagonal system combining the implicit and explicit diffusion contributions at each time step.
At each time step, fix the boundary nodes to their Dirichlet values before and after solving the linear system.
Use the tridiagonal coefficient r = alpha * dt / dx**2.
The Crank-Nicolson left-hand side matrix has diagonal entries (1 + r) and off-diagonal entries (-r/2) for interior nodes.
The right-hand side uses the explicit half-step contribution with diagonal entries (1 - r) and off-diagonal entries (r/2).
After 600 time steps, extract the solution u(x, T=0.5) as a 1D array of length 201.
Compute the reference exact solution u_exact(x) = 1 - x evaluated on the same x grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 0.5.
Compute and print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
Save a file named "solution_agent_heat_06.npz" containing arrays x (1D, length 201), u (1D, length 201), and scalar metadata T = 0.5, dx = 0.005, dt = 0.001.
Save a line plot of u(x, T) versus x as "solution_agent_heat_06.png" with labeled axes.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import solve_banded

# Parameters
alpha = 0.1
Nx = 200
dx = 1.0 / Nx
dt = 0.001
Nt = 600
T = 0.5
x = np.linspace(0.0, 1.0, Nx + 1)  # 201 points

# Initial condition
u = 1.0 - x  # u(x, 0) = 1 - x

# Boundary values
u_left = 1.0   # u(0, t) = 1
u_right = 0.0  # u(1, t) = 0

# Crank-Nicolson setup
# Interior points: indices 1 to Nx-1 (count = Nx - 1 = 199)
N_int = Nx - 1  # number of interior points
r = alpha * dt / dx**2

# Build banded matrix for LHS: (1 + r) on diagonal, -r/2 on off-diagonals
# scipy solve_banded format: ab[0] = upper diag, ab[1] = main diag, ab[2] = lower diag
ab = np.zeros((3, N_int))
ab[0, 1:] = -r / 2.0        # upper diagonal (ab[0, j] corresponds to column j)
ab[1, :] = 1.0 + r          # main diagonal
ab[2, :-1] = -r / 2.0       # lower diagonal

# Time integration
for n in range(Nt):
    u_int = u[1:Nx]  # interior values, length N_int

    # Build RHS using explicit half-step
    rhs = np.zeros(N_int)
    # Interior points i = 1 to Nx-1
    # rhs[i-1] = (r/2)*u[i-1] + (1 - r)*u[i] + (r/2)*u[i+1]
    rhs = (r / 2.0) * u[0:Nx-1] + (1.0 - r) * u[1:Nx] + (r / 2.0) * u[2:Nx+1]

    # Add boundary contributions to RHS (from LHS implicit terms)
    # For i=1 (first interior): LHS has -r/2 * u_new[0] = -r/2 * u_left
    rhs[0] += (r / 2.0) * u_left
    # For i=Nx-1 (last interior): LHS has -r/2 * u_new[Nx] = -r/2 * u_right
    rhs[-1] += (r / 2.0) * u_right

    # Solve banded system
    u_new_int = solve_banded((1, 1), ab, rhs)

    # Update solution
    u[1:Nx] = u_new_int
    u[0] = u_left
    u[Nx] = u_right

# Reference exact solution
u_exact = 1.0 - x

# Compute diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
max_abs_error = np.max(np.abs(u - u_exact))
l2_error = np.sqrt(np.sum((u - u_exact)**2) * dx)

print(f"min(u)       = {u_min:.6e}")
print(f"max(u)       = {u_max:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_abs_error:.6e}")
print(f"L2 error     = {l2_error:.6e}")

# Save npz
np.savez("solution_agent_heat_06.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_heat_06.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, u, label=f"Numerical u(x, T={T})", color="blue", linewidth=2)
ax.plot(x, u_exact, label="Exact u(x) = 1 - x", color="red", linestyle="--", linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Heat Equation Solution at T={T} (Crank-Nicolson)")
ax.legend()
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_heat_06.png", dpi=150)
plt.close()
print("Saved solution_agent_heat_06.png")
```
