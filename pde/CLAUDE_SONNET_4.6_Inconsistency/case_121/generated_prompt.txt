Solve the 1D reaction-diffusion PDE numerically using the following specification.

PDE: u_t = q1 * u_xx + q2 * u * (1 - u)

Spatial domain: x in [0, 1) with periodic boundary conditions.
Temporal domain: t in [0, 1.0].

Parameters: q1 = 0.01, q2 = 5.0.

Spatial grid: Use Nx = 512 uniform points on [0, 1) with no duplicated endpoint. Set dx = 1.0 / Nx and x_j = j * dx for j = 0, 1, ..., Nx-1.

Time grid: Use dt = 0.001 and Nt = 1000 steps so the final time T = 1.0 is hit exactly.

Initial condition: u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x), evaluated on the periodic grid.

Boundary conditions: Periodic, enforced implicitly by the chosen numerical method.

Time integration method: Use either IMEX Euler (diffusion implicit via spectral/matrix solve, reaction explicit) or Strang splitting with diffusion solved via FFT and exact logistic reaction integration. Do not use explicit forward Euler.

If using IMEX Euler: at each time step, treat the diffusion term q1 * u_xx implicitly and the reaction term q2 * u * (1 - u) explicitly. Discretize u_xx with 2nd-order central differences on the periodic grid, forming a circulant tridiagonal system, and solve it efficiently (e.g., via FFT or direct solve of the circulant system).

If using Strang splitting with FFT: split each time step into a half-step of exact logistic reaction, a full step of diffusion solved exactly in Fourier space, and another half-step of exact logistic reaction. The exact solution of the logistic ODE du/dt = q2 * u * (1 - u) over time s starting from u0 is u0 * exp(q2 * s) / (1 - u0 + u0 * exp(q2 * s)). The diffusion step in Fourier space multiplies each Fourier mode k by exp(-q1 * (2 * pi * k / L) ** 2 * s) where L = 1.0.

Spatial discretization for diffusion (if using IMEX): 2nd-order central differences, u_xx at point j approximated as (u_{j-1} - 2*u_j + u_{j+1}) / dx**2 with periodic indexing (indices modulo Nx).

At the end of Nt steps, compute u(x, T=1.0) on the periodic grid.
