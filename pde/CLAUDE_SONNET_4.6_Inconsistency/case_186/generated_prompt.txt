Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Treat all mathematical functions exactly as written and use radians for trigonometric functions.
In Python code, use ** for exponentiation wherever ^ appears in the math.

Domain: x in [0, 1) with periodic boundary conditions, t in [0, 1.0].
Parameters: nu = 2.0, rho = 2.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Spatial grid: Use a uniform periodic grid with Nx = 512 points on [0,1).
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.
Time grid: Use fixed dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Numerical method: Strang splitting applied at each full time step dt.

Step A (Diffusion half-step, duration dt/2): Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Step B (Reaction full-step, duration dt): Apply the exact pointwise logistic ODE update.
For each grid point, set u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).

Step C (Diffusion half-step again): Repeat Step A identically with duration dt/2.

Repeat Steps A, B, C for all Nt = 1000 time steps to advance from t=0 to t=1.0.

Output: Compute u(x, T=1.0) on the periodic grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.
Save a file named "solution_pdebench_reacdiff_nu2_rho2.npz" containing: array x of length Nx, array u of length Nx, and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x, T=1.0) as "solution_pdebench_reacdiff_nu2_rho2.png".

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
nu = 2.0
rho = 2.0
T = 1.0
Nx = 512
dt = 0.001
Nt = 1000

# Spatial grid
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_j = j*dx, j=0,...,Nx-1

# Wavenumbers
k = 2.0 * np.pi * np.fft.fftfreq(Nx, d=dx)

# Initial condition
u = 0.25 + 0.1 * np.sin(2.0 * np.pi * x)

# Precompute diffusion factors
diff_half = np.exp(-nu * k**2 * (dt / 2.0))

# Precompute reaction factor
exp_rho_dt = np.exp(rho * dt)

def diffusion_half_step(u):
    u_hat = np.fft.fft(u)
    u_hat *= diff_half
    return np.fft.ifft(u_hat).real

def reaction_full_step(u):
    return (u * exp_rho_dt) / (1.0 + u * (exp_rho_dt - 1.0))

# Time integration: Strang splitting
for n in range(Nt):
    u = diffusion_half_step(u)   # Step A
    u = reaction_full_step(u)    # Step B
    u = diffusion_half_step(u)   # Step C

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
u_mean = np.mean(u)
u_l2 = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.6e}")
print(f"max(u)  = {u_max:.6e}")
print(f"mean(u) = {u_mean:.6e}")
print(f"L2 norm = {u_l2:.6e}")

# Save .npz
np.savez(
    "solution_pdebench_reacdiff_nu2_rho2.npz",
    x=x,
    u=u,
    nu=nu,
    rho=rho,
    T=T,
    dx=dx,
    dt=dt,
    Nx=Nx,
    Nt=Nt
)

# Save plot
plt.figure(figsize=(8, 4))
plt.plot(x, u, linewidth=1.5)
plt.xlabel("x")
plt.ylabel("u(x, T=1.0)")
plt.title("1D Reaction-Diffusion solution at T=1.0 (nu=2, rho=2)")
plt.tight_layout()
plt.savefig("solution_pdebench_reacdiff_nu2_rho2.png", dpi=150)
plt.close()

print("Files saved: solution_pdebench_reacdiff_nu2_rho2.npz and .png")
```
