Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.

Domain is x in [0, 1) with periodic boundary conditions and t in [0, 2.0].

Use beta = 7.0.

The initial condition is u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

The reference solution is u(x, t) = u0((x - beta*t) mod 1) where u0 is the initial condition.

Use a uniform periodic spatial grid with Nx = 512 points, no duplicated endpoint, x_j = j*dx for j = 0, ..., 511, and dx = 1/512.

Use 1st-order upwind finite difference for u_x. Since beta = 7.0 > 0, use the backward (left-sided) difference: u_x at j approximated as (u_j - u_{j-1}) / dx with periodic indexing.

Use explicit forward Euler for time integration.

Set CFL = 0.5, dt = CFL * dx / abs(beta), Nt = ceil(T / dt), then reset dt = T / Nt so the final time T = 2.0 is hit exactly.

At each time step, update u using: u_j^{n+1} = u_j^n - beta * dt / dx * (u_j^n - u_{j-1}^n) for all j, with j-1 taken mod Nx for periodicity.

After time-stepping to T = 2.0, compute the reference solution u_ref_j = u0((x_j - beta*T) mod 1) on the same grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.

Print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx).

Save a file named "solution_pdebench_advection_beta7.npz" containing arrays x (length 512), u (length 512), and scalars beta, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_advection_beta7.png" with x on the horizontal axis and u on the vertical axis, labeled appropriately.

Use numpy for all array operations and matplotlib for the plot.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
beta = 7.0
T = 2.0
Nx = 512
CFL = 0.5

# Grid
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_j = j*dx, j=0,...,Nx-1

# Time step
dt_raw = CFL * dx / abs(beta)
Nt = math.ceil(T / dt_raw)
dt = T / Nt  # reset so final time is exactly T

# Initial condition
def u0(xi):
    return np.sin(2 * np.pi * xi) + 0.5 * np.sin(4 * np.pi * xi)

u = u0(x).copy()

# Upwind coefficient (beta > 0 => backward difference)
r = beta * dt / dx  # CFL number, should be <= 1

# Time integration: explicit forward Euler with 1st-order upwind
for n in range(Nt):
    # u_x at j ~ (u[j] - u[j-1]) / dx  (backward difference, periodic)
    u_left = np.roll(u, 1)  # u_left[j] = u[j-1] with periodic BC
    u = u - r * (u - u_left)

# Reference solution
x_shifted = (x - beta * T) % 1.0
u_ref = u0(x_shifted)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
max_err = np.max(np.abs(u - u_ref))
l2_err = np.sqrt(np.sum((u - u_ref)**2) * dx)

print(f"min(u)       = {u_min:.6e}")
print(f"max(u)       = {u_max:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_err:.6e}")
print(f"L2 error     = {l2_err:.6e}")

# Save npz
np.savez(
    "solution_pdebench_advection_beta7.npz",
    x=x,
    u=u,
    beta=beta,
    T=T,
    dx=dx,
    dt=dt,
    Nx=Nx,
    Nt=Nt
)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x, T={T})", linewidth=1.2)
ax.plot(x, u_ref, '--', label="Reference solution", linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"1D Advection (beta={beta}) at T={T}, 1st-order Upwind + Forward Euler")
ax.legend()
ax.grid(True, linestyle=':', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_pdebench_advection_beta7.png", dpi=150)
plt.close()

print("Files saved: solution_pdebench_advection_beta7.npz, solution_pdebench_advection_beta7.png")
```
