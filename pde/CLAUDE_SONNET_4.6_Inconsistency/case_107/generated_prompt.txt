Solve the ODE system numerically using the specifications below.

The ODE system is:
dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t)
dI/dt = delta*E - epsilon*I
dH/dt = theta*I - phi*H

The time domain is t in [0.0, 50.0].

Use the following parameter values:
alpha = 1.2
beta = 1.0
gamma = 0.5
delta = 0.8
epsilon = 0.7
theta = 0.9
phi = 0.4

The initial conditions are:
E(0.0) = 0.5
I(0.0) = 0.2
H(0.0) = 0.1

Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.01 and Nt = 5000 steps so that the final time t = 50.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n*0.01 for n = 0 to 5000 inclusive, giving Nt+1 = 5001 time points.

Use ** for exponentiation in Python code. Use radians for all trigonometric functions.

Save a file named "solution_molk_006.npz" containing:
- t: a 1D array of length 5001
- Y: a 2D array of shape [5001, 3] with columns ordered as [E, I, H]
- the parameter scalars alpha, beta, gamma, delta, epsilon, theta, phi as individual entries

Save a plot of each state variable (E, I, H) versus t as line plots in a single figure saved as "solution_molk_006.png".

Print the final state values E(50.0), I(50.0), H(50.0) and the min and max of each state variable over the entire time domain.
