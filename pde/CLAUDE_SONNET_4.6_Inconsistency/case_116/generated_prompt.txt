Solve the 1D sine-Gordon equation u_tt + q*sin(u) = u_xx numerically.
The unknown field is u(x,t), second order in time.
The PDE is u_tt + q*sin(u) = u_xx with q = 1.0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
Use a uniform periodic grid with Nx = 512 points on [0, 1).
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.
The periodic boundary conditions are u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t) for all t.
The initial condition for u is u(x,0) = 0.1*sin(2*pi*x).
The initial condition for u_t is u_t(x,0) = 0.
Convert the PDE to a first-order system by introducing v = u_t, giving u_t = v and v_t = u_xx - q*sin(u).
Discretize u_xx using 2nd-order central differences on the periodic grid: u_xx at j is (u[j+1] - 2*u[j] + u[j-1]) / dx**2 with wrap-around indexing for periodicity.
Integrate in time using the classical 4th-order Runge-Kutta (RK4) method applied to the coupled system (u, v).
Use dt = 0.0005 and Nt = 4000 time steps so the final time T = 2.0 is reached exactly.
At T = 2.0, compute u(x, T) on the periodic grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
Save a file named "solution_molk_015.npz" containing: array x of length Nx, array u of length Nx, scalar T, scalar dx, scalar Nx, and scalar q.
Save a line plot of u(x, T) as "solution_molk_015.png" with x on the horizontal axis and u on the vertical axis.
Use radians for all trigonometric functions.
Use ** for exponentiation in Python code.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Parameters
q = 1.0
Nx = 512
dx = 1.0 / Nx
x = np.array([j * dx for j in range(Nx)])
dt = 0.0005
Nt = 4000
T = 2.0

# Initial conditions
u = 0.1 * np.sin(2 * np.pi * x)
v = np.zeros(Nx)

def compute_uxx(u, dx, Nx):
    # 2nd-order central differences with periodic wrap-around
    u_right = np.roll(u, -1)  # u[j+1]
    u_left  = np.roll(u,  1)  # u[j-1]
    return (u_right - 2.0 * u + u_left) / dx**2

def rhs(u, v, q, dx, Nx):
    uxx = compute_uxx(u, dx, Nx)
    du_dt = v
    dv_dt = uxx - q * np.sin(u)
    return du_dt, dv_dt

# RK4 time integration
for n in range(Nt):
    k1u, k1v = rhs(u,              v,              q, dx, Nx)
    k2u, k2v = rhs(u + 0.5*dt*k1u, v + 0.5*dt*k1v, q, dx, Nx)
    k3u, k3v = rhs(u + 0.5*dt*k2u, v + 0.5*dt*k2v, q, dx, Nx)
    k4u, k4v = rhs(u +     dt*k3u, v +     dt*k3v, q, dx, Nx)

    u = u + (dt / 6.0) * (k1u + 2.0*k2u + 2.0*k3u + k4u)
    v = v + (dt / 6.0) * (k1v + 2.0*k2v + 2.0*k3v + k4v)

# Diagnostics
u_min  = np.min(u)
u_max  = np.max(u)
u_mean = np.mean(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"mean(u)  = {u_mean:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# Save .npz
np.savez("solution_molk_015.npz",
         x=x,
         u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         Nx=np.int64(Nx),
         q=np.float64(q))

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.0, color='steelblue')
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"1D sine-Gordon solution at T = {T}")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_molk_015.png", dpi=150)
plt.close()

print("Files saved: solution_molk_015.npz, solution_molk_015.png")
```
