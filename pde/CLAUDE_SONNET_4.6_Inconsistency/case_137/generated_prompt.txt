Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.

The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0], but compute the final solution at T = 2.1.
Use beta = 0.4.

Set up a uniform periodic grid with Nx = 512 points.
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx - 1.

Apply the initial condition u(x, 0) = sin(2 * pi * x) + 0.5 * sin(4 * pi * x) at all grid points.

Use 1st-order upwind finite difference for the spatial derivative u_x.
Since beta = 0.4 is positive, the upwind direction is from the left, so approximate u_x at point j as (u[j] - u[j-1]) / dx using periodic indexing (u[-1] = u[Nx-1]).

Use explicit forward Euler for time integration.
Set CFL = 0.5.
Set dt = CFL * dx / abs(beta).
Set Nt = ceil(T / dt) where T = 2.1.
Reset dt = T / Nt so the final time T = 2.1 is hit exactly.

At each time step, update u[j] = u[j] - beta * dt / dx * (u[j] - u[j-1]) for j = 0, ..., Nx-1 with periodic indexing.

After Nt steps, the solution u represents u(x, T=2.1).

Compute the reference solution u_ref[j] = sin(2 * pi * ((x_j - beta * T) % 1)) + 0.5 * sin(4 * pi * ((x_j - beta * T) % 1)) at each grid point.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx).
