Solve the Klein-Gordon PDE numerically using the specifications below.

PDE: u_tt - (1.0)**2 * u_xx + (1.0)**2 * u + (1.0) * u**3 = 0

Domain: x in [0,1) periodic, t in [0, 2.0].

Parameters: c = 1.0, m = 1.0, lambda = 1.0.

Boundary conditions: Periodic on x. The domain is half-open [0,1) with periodicity, so there is no duplicated endpoint. Ignore the Dirichlet condition since the domain is periodic.

Initial conditions: u(x,0) = 0.1 * cos(2 * pi * x), u_t(x,0) = 0.

Grid: Use Nx = 512 uniform points on [0,1). dx = 1.0 / 512. x_i = i * dx for i = 0, 1, ..., 511.

Time stepping: dt = 0.0005, total steps = 4000, so T = 2.0.

Spatial discretization: Use 2nd-order central differences with wrap-around (periodic) for u_xx. For each interior index i, u_xx[i] = (u[i+1] - 2*u[i] + u[i-1]) / dx**2, with indices taken modulo Nx.

Time integration: Use the Leapfrog (Stormer) scheme for u_tt. Treat the nonlinear term u**3 explicitly at time level n.

Initialization (Taylor start for the first step): u1[i] = u0[i] + dt * ut0[i] + 0.5 * dt**2 * (c**2 * u0_xx[i] - m**2 * u0[i] - lambda * u0[i]**3), where ut0[i] = 0 and u0_xx is computed from u0 using the periodic central difference stencil.

Leapfrog update for n >= 1: u_new[i] = 2 * u[i] - u_old[i] + dt**2 * (c**2 * u_xx[i] - m**2 * u[i] - lambda * u[i]**3).

Apply periodic indexing (modulo Nx) at every step.

After 4000 steps, the solution u(x, T=2.0) is stored as a 1D array of length 512.

Output: Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T=2.0.

Save "solution_agent_kg_08.npz" containing: x (1D array, length 512), u (1D array, length 512), and metadata scalars T=2.0, dx=1.0/512, dt=0.0005.

Save a line plot of u(x, T=2.0) as "solution_agent_kg_08.png" with x on the horizontal axis and u on the vertical axis.

Use Python with numpy for computation and matplotlib for the plot.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Parameters
c = 1.0
m = 1.0
lam = 1.0

Nx = 512
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_i = i * dx, i = 0..511

dt = 0.0005
Nsteps = 4000
T = dt * Nsteps  # = 2.0

# Initial conditions
u0 = 0.1 * np.cos(2 * np.pi * x)
ut0 = np.zeros(Nx)

def compute_uxx(u, dx, Nx):
    """2nd-order central difference with periodic wrap-around."""
    u_right = np.roll(u, -1)  # u[i+1]
    u_left  = np.roll(u,  1)  # u[i-1]
    return (u_right - 2.0 * u + u_left) / dx**2

def rhs(u, c, m, lam, dx, Nx):
    """Compute c^2 * u_xx - m^2 * u - lambda * u^3."""
    uxx = compute_uxx(u, dx, Nx)
    return c**2 * uxx - m**2 * u - lam * u**3

# Taylor start: compute u at t = dt
uxx0 = compute_uxx(u0, dx, Nx)
accel0 = c**2 * uxx0 - m**2 * u0 - lam * u0**3
u_old = u0.copy()
u_cur = u0 + dt * ut0 + 0.5 * dt**2 * accel0  # Taylor expansion (ut0=0)

# Leapfrog time integration
for n in range(1, Nsteps):
    accel = rhs(u_cur, c, m, lam, dx, Nx)
    u_new = 2.0 * u_cur - u_old + dt**2 * accel
    u_old = u_cur
    u_cur = u_new

u_final = u_cur

# Diagnostics
u_min = np.min(u_final)
u_max = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)

print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_kg_08.npz",
         x=x,
         u=u_final,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_final, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=2.0)")
ax.set_title("Klein-Gordon solution at T=2.0 (agent_kg_08)")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_kg_08.png", dpi=150)
plt.close()

print("Files saved: solution_agent_kg_08.npz, solution_agent_kg_08.png")
```
