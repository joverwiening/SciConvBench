Solve the 1D wave equation u_tt = q*u_xx numerically using the specifications below.

The PDE is u_tt = q*u_xx with q = 1.0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
Use a uniform periodic grid with Nx = 256 points, x_j = j*dx for j = 0, ..., 255, with dx = 1/256.
The initial condition is u(x, 0) = sin(2*pi*x) and u_t(x, 0) = 0.
The exact solution is u(x, t) = cos(2*pi*sqrt(q)*t) * sin(2*pi*x).
Convert the second-order PDE to a first-order system by introducing v = u_t, giving u_t = v and v_t = q*u_xx.
Discretize u_xx using 2nd-order central differences on the periodic grid: u_xx at j = (u[j+1] - 2*u[j] + u[j-1]) / dx**2 with periodic index wrapping.
Integrate in time using the classical 4th-order Runge-Kutta (RK4) method.
Use dt = 0.0005 and Nt = 2000 steps so the simulation ends exactly at T = 1.0.
At T = 1.0, compute u(x, T) on the periodic grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T = 1.0.
Save a file named "solution_molk_019.npz" containing: array x of length 256, array u of length 256, scalar T = 1.0, scalar dx = 1/256, scalar Nx = 256, and scalar q = 1.0.
Save a line plot of u(x, T) as "solution_molk_019.png" with x on the horizontal axis and u on the vertical axis.
Use Python with numpy for computation and matplotlib for plotting.
Use '**' for exponentiation in Python code.
Treat all trigonometric arguments as radians.

Here is the complete Python code implementing the specification:

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Parameters
q   = 1.0
Nx  = 256
dx  = 1.0 / Nx
dt  = 0.0005
Nt  = 2000
T   = 1.0

# Grid
x = np.arange(Nx) * dx  # x_j = j*dx, j = 0,...,Nx-1

# Initial conditions
u = np.sin(2 * np.pi * x).copy()
v = np.zeros(Nx)         # u_t(x,0) = 0

# Laplacian operator (2nd-order central differences, periodic)
def laplacian(u, dx):
    return (np.roll(u, -1) - 2.0 * u + np.roll(u, 1)) / dx**2

# RHS of first-order system: d/dt [u, v] = [v, q*u_xx]
def rhs(u, v):
    dudt = v
    dvdt = q * laplacian(u, dx)
    return dudt, dvdt

# RK4 time integration
for _ in range(Nt):
    k1u, k1v = rhs(u, v)

    u2 = u + 0.5 * dt * k1u
    v2 = v + 0.5 * dt * k1v
    k2u, k2v = rhs(u2, v2)

    u3 = u + 0.5 * dt * k2u
    v3 = v + 0.5 * dt * k2v
    k3u, k3v = rhs(u3, v3)

    u4 = u + dt * k3u
    v4 = v + dt * k3v
    k4u, k4v = rhs(u4, v4)

    u = u + (dt / 6.0) * (k1u + 2.0 * k2u + 2.0 * k3u + k4u)
    v = v + (dt / 6.0) * (k1v + 2.0 * k2v + 2.0 * k3v + k4v)

# Diagnostics
u_min  = np.min(u)
u_max  = np.max(u)
u_mean = np.mean(u)
l2     = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.6e}")
print(f"max(u)  = {u_max:.6e}")
print(f"mean(u) = {u_mean:.6e}")
print(f"L2 norm = {l2:.6e}")

# Exact solution for reference
u_exact = np.cos(2 * np.pi * np.sqrt(q) * T) * np.sin(2 * np.pi * x)
err = np.sqrt(np.sum((u - u_exact)**2) * dx)
print(f"L2 error vs exact = {err:.6e}")

# Save npz
np.savez("solution_molk_019.npz",
         x=x,
         u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         Nx=np.int64(Nx),
         q=np.float64(q))

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x, T={T})")
ax.plot(x, u_exact, '--', label="Exact solution", alpha=0.7)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"1D Wave Equation solution at T={T}")
ax.legend()
plt.tight_layout()
plt.savefig("solution_molk_019.png", dpi=150)
plt.close()
print("Saved solution_molk_019.npz and solution_molk_019.png")
```
