Solve the Duffing oscillator (undriven) ODE system numerically using the specifications below.

The ODE system is:
dx/dt = y
dy/dt = -delta*y - alpha*x - beta*x**3

The time domain is t in [0.0, 50.0].

Use parameters alpha = 2, beta = 0.1, delta = 0.2.

Set initial conditions x(0.0) = 1.0 and y(0.0) = 0.0.

Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.01 and Nt = 5000 steps so the final time 50.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n*0.01 for n = 0 to 5000 inclusive, giving Nt+1 = 5001 time points.

In Python, use ** for exponentiation wherever the math uses ^.

Save a file named solution_molk_011.npz containing: a 1D array t of length 5001, a 2D array Y of shape [5001, 2] with columns ordered as [x, y], and the scalar parameters alpha, beta, delta.

Save a plot of each state variable (x and y) versus t as line plots in a single figure saved as solution_molk_011.png.

Print the final state values x(50.0) and y(50.0) at the end of the simulation.
