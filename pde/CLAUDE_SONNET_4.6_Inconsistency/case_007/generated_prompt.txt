Solve the Allen-Cahn PDE numerically using the following specifications.

PDE: u_t = (0.01)**2 * u_xx + u - u**3

Spatial domain: x in [0, 1), periodic. Temporal domain: t in [0, 0.5].

Parameter: epsilon = 0.01.

Boundary condition: Periodic only. Use periodic wrap-around indexing. Do not apply Dirichlet conditions anywhere.

Initial condition: u(x, 0) = 0.1*cos(2*pi*x) + 0.05*sin(4*pi*x).

Grid: Use Nx = 800 points on the half-open domain [0, 1). Set dx = 1.0/800. Set x_i = i*dx for i = 0, 1, ..., 799. There are exactly 800 grid points with no duplicated endpoint.

Spatial discretization: Use 2nd-order central finite differences for u_xx with periodic wrap-around. For point i, u_xx[i] = (u[i+1] - 2*u[i] + u[i-1]) / dx**2, where indices are taken modulo 800.

Time integration: Use the semi-implicit scheme (u**(n+1) - u**n) / dt = epsilon**2 * u_xx**(n+1) + u**n - (u**n)**3. Rearranged, this gives a linear system for u**(n+1) at each step: u**(n+1) - dt * epsilon**2 * u_xx**(n+1) = u**n + dt * (u**n - (u**n)**3). Assemble the left-hand side as a sparse tridiagonal matrix with periodic corners and solve it each time step.

Time stepping: Use dt = 0.0002. Run for 2500 steps to reach T = 0.5.

At T = 0.5, compute the solution u(x, T) on the 800-point grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 0.5.

Save a file named "solution_agent_allen_cahn_01.npz" containing: array x of shape (800,), array u of shape (800,) holding u(x, T), scalar T = 0.5, scalar dx, scalar dt.
