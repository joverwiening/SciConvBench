Solve the 2D anisotropic diffusion PDE u_t = 0.1 * u_xx + 0.01 * u_yy numerically using implicit Euler time integration on a uniform grid.

Domain is (x,y) in [0,1] x [0,1], t in [0, 0.2].
Parameters are Dx = 0.1 and Dy = 0.01.
Apply Dirichlet boundary conditions u = 0 on all four boundary edges.
Initial condition is u(x,y,0) = sin(pi*x) * sin(pi*y).
Exact solution for verification is u(x,y,t) = exp(-(0.1 + 0.01) * pi**2 * t) * sin(pi*x) * sin(pi*y).

Use Nx = Ny = 60 uniform intervals in each spatial direction.
This gives 61 grid points in each direction including both endpoints.
Set dx = 1.0/60, dy = 1.0/60.
Set x_i = i * dx for i = 0, 1, ..., 60.
Set y_j = j * dy for j = 0, 1, ..., 60.
Use dt = 0.001 and run for 240 time steps to reach T = 0.2.

Discretize the spatial operator using the standard 5-point Laplacian scaled by Dx in x and Dy in y.
The interior points are indices i = 1..59 and j = 1..59, giving 59*59 = 3481 interior unknowns.
Enforce u = 0 at all boundary points throughout the simulation.

At each time step, solve the linear system (I - dt * L) * u_new = u_old where L is the discrete operator matrix for the interior points.
Assemble the matrix L once before the time loop using the 5-point stencil: center coefficient is -(2*Dx/dx**2 + 2*Dy/dy**2), x-neighbor coefficients are Dx/dx**2, y-neighbor coefficients are Dy/dy**2.
Use scipy.sparse to store L as a sparse matrix in CSR format.
Use scipy.sparse.linalg.spsolve to solve the linear system at each step.
Factor or reuse the matrix (I - dt * L) across all steps since it is constant.

After 240 steps, reconstruct the full 2D solution array of shape (61, 61) with boundary values set to zero and interior values filled from the solution vector.
Index convention: u_full[j, i] = u(x_i, y_j).

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx * dy) at T = 0.2.
Evaluate the exact solution on the same grid at T = 0.2.
Compute and print the max absolute error max(|u_numerical - u_exact|) over all grid points.
Compute and print the L2 error sqrt(sum((u_numerical - u_exact)**2) * dx * dy).
