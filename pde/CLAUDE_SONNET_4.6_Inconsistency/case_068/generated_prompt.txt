Solve the KdV PDE numerically using the specifications below.

The PDE is u_t + 6*u*u_x + u_xxx = 0.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 0.1].
The initial condition is u(x,0) = 0.5*cos(2*pi*x).

Use a half-open periodic grid with Nx=1024 points, no duplicated endpoint.
Set dx = 1.0/1024 and x_i = i*dx for i = 0, 1, ..., 1023.

Use a Fourier pseudo-spectral method to compute spatial derivatives.
Compute u_x by multiplying the FFT of u by (i*k) then taking the inverse FFT.
Compute u_xxx by multiplying the FFT of u by (i*k)**3 then taking the inverse FFT.
Use the standard FFT wavenumbers: k = 2*pi*fftfreq(Nx, d=1.0/Nx) divided appropriately, specifically k = 2*pi*numpy.fft.fftfreq(Nx)*Nx so that k_j corresponds to the j-th Fourier mode on [0,1).
More precisely, use k = 2*pi*numpy.fft.fftfreq(Nx, d=dx) which gives wavenumbers in radians per unit length.

Compute the nonlinear term 6*u*u_x entirely in physical space.
Use explicit RK4 time integration with fixed dt = 1e-5.
Run exactly 12000 time steps to reach T = 0.1.

Define the RHS function as: rhs(u) = -(6*u*u_x + u_xxx) where u_x and u_xxx are computed spectrally.

At T = 0.1, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx).

Save a file named "solution_agent_other_03_kdv.npz" containing the 1D array x (length 1024), the 1D array u (length 1024, the solution at T=0.1), and scalar metadata T=0.1, dx, dt=1e-5.

Save a line plot of u(x, T=0.1) as "solution_agent_other_03_kdv.png" with x on the horizontal axis and u on the vertical axis.

Use Python with numpy and matplotlib. Use ^ as exponentiation in math descriptions and ** in Python code.

```python
import numpy as np
import matplotlib.pyplot as plt

# Grid setup
Nx = 1024
x = np.arange(Nx) * (1.0 / Nx)  # x_i = i*dx, i=0..Nx-1
dx = 1.0 / Nx

# Wavenumbers for [0,1) periodic domain
# fftfreq(Nx) gives frequencies in cycles per sample: 0, 1/Nx, 2/Nx, ..., -1/Nx+1/Nx, ...
# Multiply by Nx to get cycles per unit length, then by 2*pi for radians per unit length
k = 2.0 * np.pi * np.fft.fftfreq(Nx, d=dx)

# Initial condition
u = 0.5 * np.cos(2.0 * np.pi * x)

# RHS of KdV: u_t = -(6*u*u_x + u_xxx)
def rhs(u):
    u_hat = np.fft.fft(u)
    u_x = np.real(np.fft.ifft(1j * k * u_hat))
    u_xxx = np.real(np.fft.ifft((1j * k)**3 * u_hat))
    return -(6.0 * u * u_x + u_xxx)

# Time integration parameters
dt = 1e-5
n_steps = 12000

# RK4 time stepping
for _ in range(n_steps):
    k1 = rhs(u)
    k2 = rhs(u + 0.5 * dt * k1)
    k3 = rhs(u + 0.5 * dt * k2)
    k4 = rhs(u + dt * k3)
    u = u + (dt / 6.0) * (k1 + 2.0*k2 + 2.0*k3 + k4)

T = 0.1

# Diagnostics
print(f"min(u)  = {np.min(u):.6f}")
print(f"max(u)  = {np.max(u):.6f}")
L2 = np.sqrt(np.sum(u**2) * dx)
print(f"L2 norm = {L2:.6f}")

# Save npz
np.savez("solution_agent_other_03_kdv.npz", x=x, u=u, T=T, dx=dx, dt=dt)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=0.1)")
ax.set_title("KdV solution at T=0.1 (pseudo-spectral RK4)")
ax.set_xlim(0, 1)
plt.tight_layout()
plt.savefig("solution_agent_other_03_kdv.png", dpi=150)
plt.close()

print("Files saved: solution_agent_other_03_kdv.npz, solution_agent_other_03_kdv.png")
```
