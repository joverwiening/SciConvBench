Solve the Burgers PDE numerically as specified below.

PDE: u_t + u*u_x = 0.02*u_xx + sin(2*pi*x)*cos(2*pi*t)
Unknown field: u(x,t)
Spatial domain: x in [0,1) with periodic boundary conditions
Time domain: t in [0,1.0]
Parameter: nu = 0.02
Initial condition: u(x,0) = 0

Grid setup: Use Nx=1000 uniform points on [0,1) with no duplicated endpoint. dx = 1/1000. x_i = i*dx for i=0..999. Use dt=1e-4 and Nt=10000 steps so T=1.0 is hit exactly.

Spatial discretization: Use conservative form u_t + (f(u))_x = nu*u_xx with f(u) = 0.5*u**2.
Convection term: Use Rusanov (local Lax-Friedrichs) flux at each interface. F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i) where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|). Approximate (f(u))_x at point i as (F_{i+1/2} - F_{i-1/2})/dx. Use periodic wrap-around indexing so index Nx wraps to 0 and index -1 wraps to Nx-1.
Diffusion term: Use 2nd-order central difference u_xx at point i as (u_{i+1} - 2*u_i + u_{i-1})/dx**2 with periodic wrap-around indexing.

Time integration: Use 1st-order IMEX scheme. Treat convection and the source term explicitly, treat diffusion implicitly. The update equation is: (u^{n+1} - u^n)/dt + conv_term^n = nu * L * u^{n+1} + source^n, where conv_term^n is the Rusanov flux divergence evaluated at time level n, source^n = sin(2*pi*x)*cos(2*pi*t^n) evaluated at t^n = n*dt, and L is the discrete Laplacian matrix with periodic wrap-around. Rearrange to the linear system (I - dt*nu*L) * u^{n+1} = u^n - dt*conv_term^n + dt*source^n. Build the matrix (I - dt*nu*L) as a sparse matrix using scipy.sparse with periodic wrap-around in L. Solve the linear system each time step using scipy.sparse.linalg.spsolve.

Boundary handling: Apply periodic wrap-around indexing for both convection fluxes and diffusion stencil at every step. There are no Dirichlet boundary conditions since the domain is periodic; ignore the contradictory Dirichlet condition stated in the problem.
