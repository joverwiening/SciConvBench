Solve the Helmholtz PDE numerically using the specifications below.

PDE is u_xx + u_yy + k**2 * u = f(x,y), where k = 5.0 and f(x,y) = (k**2 - 2*(pi**2)) * sin(pi*x) * sin(pi*y).

The spatial domain is (x,y) in [0,1] x [0,1].

Use Nx = Ny = 120 uniform intervals in each direction, giving Nx+1 = 121 grid points per direction including both endpoints.
Set dx = dy = 1/120.
Define x_i = i * dx for i = 0, 1, ..., 120 and y_j = j * dy for j = 0, 1, ..., 120.

Apply Dirichlet boundary conditions u = 0 on all four boundaries (x=0, x=1, y=0, y=1).
The problem statement also mentions periodic boundaries; since the exact solution sin(pi*x)*sin(pi*y) satisfies u=0 at all boundaries and the domain is closed [0,1]x[0,1], treat the boundary condition as Dirichlet u=0 on all sides (the periodicity note is consistent with this and does not change the discrete system).

Discretize the operator (u_xx + u_yy + k**2 * u) using the standard 5-point Laplacian on the interior nodes only.
For each interior node (i,j) with i=1..119, j=1..119, the discrete equation is:
(u[i-1,j] - 2*u[i,j] + u[i+1,j]) / dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1]) / dy**2 + k**2 * u[i,j] = f(x_i, y_j).
Boundary values are zero and do not appear as unknowns.

Assemble the resulting sparse linear system in CSR format using scipy.sparse.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.

After solving, reconstruct the full (121 x 121) solution array including the zero boundary values.
Store the solution as a 2D array u with shape (len(y), len(x)) = (121, 121) so that u[j, i] = u(x_i, y_j).

Compute the exact solution u_exact[j,i] = sin(pi * x_i) * sin(pi * y_j) on the same grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx * dy) over all grid points.
Print the max absolute error max(|u - u_exact|) and the discrete L2 error sqrt(sum((u - u_exact)**2) * dx * dy).
