Solve the 1D Compressible Navier-Stokes PDE (no heat conduction) numerically in Python and save the results.

Use Gamma = 1.6666666666666667.
Use eta = 1e-08 and zeta = 1e-08.
Use CFL = 0.5 for the convective stability criterion.

The conservative variables are U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v**2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.

The PDEs in conservative form are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use a uniform finite-volume grid with Nx=800 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j=0,...,799, with dx = 2/800.
Evolve cell-average conservative variables U = [rho, m, E].

Apply the Riemann (shock-tube) initial condition with a discontinuity at x=0.
For x < 0: rho_L = 1.0, v_L = -0.75, p_L = 1.0.
For x >= 0: rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Initialize E from p and v using E = p/(Gamma-1) + 0.5*rho*v**2.

Apply transmissive (outflow, zero-gradient) boundary conditions at both x=-1 and x=1 by setting ghost cell values equal to the nearest interior cell.

Recover pressure from conservative variables using p = (Gamma-1)*(E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 before any division or sqrt.

Compute the convective (Euler) flux at each interface using the Rusanov (local Lax-Friedrichs) scheme.
The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] with v = m/rho.
The interface wave speed is a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Use piecewise-constant (first-order) reconstruction, so U_L at interface j+1/2 is the value in cell j and U_R is the value in cell j+1.

Compute v_x at each cell center using centered finite differences on the cell-centered v values.
Compute sigma = (zeta + 4/3*eta)*v_x at each cell center.
Approximate sigma at each interface by averaging the sigma values of the two neighboring cells.
Approximate v at each interface by averaging the v values of the two neighboring cells.
The viscous flux vector is F_visc = [0, -sigma_interface, -v_interface*sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.
At each time step compute dt as follows:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
dt = min(dt_conv, dt_visc)
Adjust the final time step so the simulation ends exactly at T = 0.2.
