Solve the 1D Compressible Navier–Stokes equations (no heat conduction) numerically in Python and save the results.

Use Gamma = 5/3 = 1.6666666666666667. Disregard the second Gamma line in the parameters; it was a typo.

Use eta = 1e-08 and zeta = 1e-08.

The conservative variables are U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v**2.

The viscous stress is sigma = (zeta + 4/3*eta) * v_x.

The PDEs in conservative form are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use a uniform finite-volume grid with Nx = 800 cells on [-1, 1].
Set dx = 2/Nx.
Place cell centers at x_j = -1 + (j + 0.5)*dx for j = 0, ..., Nx-1.
Evolve cell-average conservative variables U = [rho, m, E].

Apply the Riemann (shock-tube) initial condition with a discontinuity at x = 0.
For x < 0: rho_L = 0.445, v_L = 0.698, p_L = 3.528.
For x >= 0: rho_R = 0.5, v_R = 0.0, p_R = 0.571.
Convert to conservative variables at initialization.

Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

Apply transmissive (outflow, zero-gradient) boundary conditions at both x = -1 and x = 1.
Implement outflow BCs by setting ghost cell values equal to the nearest interior cell value.

Compute the convective (inviscid Euler) flux as F_conv = [m, m**2/rho + p, (E+p)*v] where v = m/rho.
Use the Rusanov (local Lax-Friedrichs) numerical flux at each interface.
Compute the interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Compute the Rusanov flux as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Use piecewise-constant (first-order) reconstruction; U_L and U_R at each interface are the left and right cell-average values respectively.

Compute v_x at each cell center using centered finite differences on the cell-centered v values.
Compute sigma = (zeta + 4/3*eta) * v_x at each cell center.
Approximate sigma at each interface by averaging the sigma values of the two neighboring cell centers.
Approximate v at each interface by averaging the v values of the two neighboring cell centers.
Compute the viscous flux at each interface as F_visc = [0, -sigma_interface, -v_interface * sigma_interface].
Compute the total interface flux as F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.

Choose the time step each stage/step as follows.
Compute dt_conv = CFL * dx / max_j(|v_j| + c_j).
Compute dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc).
Use CFL = 0.5.
Adjust the final time step so the simulation ends exactly at T = 0.2.

After the simulation, compute rho(x, T), v(x, T), and p(x, T) at all cell centers from the final conservative variables.
