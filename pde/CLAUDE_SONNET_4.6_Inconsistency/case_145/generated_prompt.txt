Solve the 1D Viscous Burgers equation numerically with the following specifications.

PDE: u_t + d/dx(0.5*u**2) = nu * u_xx

Spatial domain: x in [0, 1) with periodic boundary conditions.
Temporal domain: t in [0, 1.0], so T = 1.0.
Parameter: nu = 0.04.
Initial condition: u(x, 0) = sin(2*pi*x).
No closed-form reference solution is required.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Define dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.

Set CFL = 0.4 and estimate max speed as 1.0.
Compute dt0 = CFL * dx / 1.0.
Compute Nt = ceil(T / dt0) and reset dt = T / Nt so the final time T = 1.0 is hit exactly.

Advance the solution using Strang splitting for each full time step dt.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): apply a finite-volume update using the Rusanov (local Lax-Friedrichs) flux for the inviscid Burgers equation u_t + d/dx(0.5*u**2) = 0.
Define f(u) = 0.5 * u**2.
For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing): compute alpha = max(abs(u_left), abs(u_right)) and flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j: compute F_plus as the flux at the interface between u[j] and u[j+1], compute F_minus as the flux at the interface between u[j-1] and u[j], then set u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.

Step C (diffusion half-step again): repeat Step A identically.

After completing all Nt time steps, the solution u(x, T=1.0) is defined on the 512-point periodic grid.

Save a file named "solution_pdebench_burgers_nu0p04.npz" containing: array x of length 512, array u of length 512, and scalars nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_burgers_nu0p04.png".

Print the following diagnostics at T: min(u), max(u), discrete mean value mean(u) (should be approximately conserved), and discrete L2 norm sqrt(sum(u**2)*dx).
