The PDE is u_t = -1.0 * d/dx(cos(u)) + (0.05/pi) * u_xx.

The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].

Set q1 = 1.0 and q2 = 0.05.

Use a uniform periodic grid with Nx = 1024 points.
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.

The initial condition is u(x, 0) = 0.5 * sin(2 * pi * x).

Discretize the convection term d/dx(cos(u)) using a conservative finite-volume Rusanov flux.
At each interface between cell j and cell j+1, compute the Rusanov flux as F_{j+1/2} = 0.5 * (cos(u_j) + cos(u_{j+1})) - 0.5 * alpha * (u_{j+1} - u_j), where alpha = max(|sin(u_j)|, |sin(u_{j+1}})|) evaluated locally, or use the global max|sin(u)| over all grid points at the current stage.
Use periodic indexing so that index Nx wraps to index 0.
The convection contribution to cell j is -(F_{j+1/2} - F_{j-1/2}) / dx.

The diffusion contribution to cell j is (q2/pi) * (u_{j+1} - 2*u_j + u_{j-1}) / dx**2.

Compute the time step as follows.

Set dt_diff = 0.2 * dx**2 / (q2 / pi).

Stage 1: u_star = u_n + dt * L(u_n).
Stage 2: u_{n+1} = 0.5 * u_n + 0.5 * (u_star + dt * L(u_star)).
Here L(u) is the full right-hand side (convection plus diffusion) evaluated at u.
