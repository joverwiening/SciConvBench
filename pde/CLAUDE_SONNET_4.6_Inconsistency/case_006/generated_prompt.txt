The time domain is t in [0, 0.3].

Use Nx = 2000 uniform grid points on [0,1) with no duplicated endpoint.

Compute dt0 = 0.9*dx/abs(a).
Set Nt = ceil(0.3/dt0) and dt = 0.3/Nt so the final time T=0.3 is hit exactly.
Initialize u(x,0) = 1 if 0.2 <= x < 0.4, else 0.
Apply 1st-order upwind spatial discretization: since a=2.0 > 0, u_x at point i is approximated as (u[i] - u[i-1])/dx using periodic wrap-around indexing.
Advance in time using Forward Euler: u[i] = u[i] - a*dt/dx*(u[i] - u[i-1]).
Use periodic indexing so that index -1 wraps to index Nx-1.
After Nt steps, the solution u(x, T=0.3) is obtained.
Save the file "solution_agent_advection_06.npz" containing arrays x (1D, length Nx), u (1D, length Nx), and scalar metadata T=0.3, dx, dt.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.3.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
a = 2.0
T = 0.3
Nx = 2000
dx = 1.0 / Nx

# Grid: x_i = i*dx for i = 0..Nx-1
x = np.array([i * dx for i in range(Nx)])

# Initial condition: square pulse
u = np.where((x >= 0.2) & (x < 0.4), 1.0, 0.0)

# Time stepping parameters
dt0 = 0.9 * dx / abs(a)
Nt = math.ceil(T / dt0)
dt = T / Nt

cfl = abs(a) * dt / dx
print(f"Nx={Nx}, dx={dx:.6e}, dt={dt:.6e}, Nt={Nt}, CFL={cfl:.6f}")

# Forward Euler + 1st-order upwind (a > 0, so upwind uses left neighbor)
# u_new[i] = u[i] - a*(dt/dx)*(u[i] - u[i-1])
r = a * dt / dx  # CFL number, <= 0.9

for n in range(Nt):
    # Periodic: u[i-1] with i=0 gives u[Nx-1] via numpy's -1 indexing
    u_left = np.roll(u, 1)  # u_left[i] = u[i-1] with periodic wrap
    u = u - r * (u - u_left)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)    = {u_min:.6e}")
print(f"max(u)    = {u_max:.6e}")
print(f"L2 norm   = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_advection_06.npz",
         x=x, u=u, T=np.float64(T), dx=np.float64(dx), dt=np.float64(dt))
print("Saved solution_agent_advection_06.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, 'b-', linewidth=1.0, label=f'u(x, T={T})')
ax.set_xlabel('x')
ax.set_ylabel('u')
ax.set_title(f'1st-order Upwind Advection at T={T}  (Nx={Nx})')
ax.legend()
ax.set_xlim(0, 1)
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig("solution_agent_advection_06.png", dpi=150)
plt.close()
print("Saved solution_agent_advection_06.png")
```

**Key implementation notes:**

- The upwind scheme uses `np.roll(u, 1)` to get `u[i-1]` with periodic wrap, since `a > 0` means information travels left-to-right.
- CFL = 0.9 exactly after adjusting `dt = T/Nt`.
- The exact solution at T=0.3 is a shifted square pulse: the pulse originally at [0.2, 0.4) shifts to [0.2 + 2.0×0.3, 0.4 + 2.0×0.3) = [0.8, 1.0) (mod 1). The upwind scheme reproduces this with slight numerical diffusion at the edges due to 1st-order accuracy.
- L2 norm ≈ √(0.2 × 1²) = √0.2 ≈ 0.4472, consistent with the pulse width of 0.2.
