Solve the wave equation PDE numerically with the following specifications.

The PDE is u_tt = c^2 * u_xx with c = 1.0.
The spatial domain is x in [0, 1] (closed interval) and the time domain is t in [0, 1.0].
The wave speed c = 1.0 is used for both the PDE and the CFL condition.
Use Dirichlet boundary conditions u = 0 at x = 0 and x = 1 at every time step.
The initial condition is u(x, 0) = 0 and u_t(x, 0) = sin(pi * x).
The exact reference solution is u(x, t) = (1 / (1.0 * pi)) * sin(1.0 * pi * t) * sin(pi * x).

Use a uniform grid on [0, 1] with Nx = 400 intervals, giving Nx + 1 = 401 grid points including both endpoints.
Set dx = 1.0 / Nx.
Construct x as x_i = i * dx for i = 0, 1, ..., Nx.

Compute dt0 = 0.9 * dx / c with c = 1.0.
Set Nt = ceil(T / dt0) and then dt = T / Nt so the final time T = 1.0 is hit exactly.
Verify that CFL = c * dt / dx is at most 0.9.

Use 2nd-order central differences for u_xx at interior nodes: u_xx_i = (u[i-1] - 2*u[i] + u[i+1]) / dx**2.
Use the leapfrog (Störmer–Verlet) scheme for time integration: u_next[i] = 2*u_curr[i] - u_prev[i] + dt**2 * c**2 * u_xx[i] for interior nodes.
Initialize u^0 = u(x, 0) = 0 for all nodes.
Compute u^1 using the Taylor start: u^1 = u^0 + dt * v0 + 0.5 * dt**2 * c**2 * u_xx^0, where v0 = sin(pi * x).
Apply Dirichlet boundary conditions u = 0 at the first and last nodes at every time step including the Taylor start step.

After completing all Nt time steps, evaluate the numerical solution u at T = 1.0 on the 401-point grid.
Evaluate the exact solution u_exact = (1.0 / (1.0 * pi)) * sin(1.0 * pi * T) * sin(pi * x) on the same grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).

Save a file named "solution_agent_wave_04.npz" containing arrays x (1D, length 401), u (1D, length 401), and metadata scalars T, dx, dt.
Save a line plot of u(x, T) and u_exact(x, T) versus x as "solution_agent_wave_04.png" with appropriate labels, title, legend, and grid.
