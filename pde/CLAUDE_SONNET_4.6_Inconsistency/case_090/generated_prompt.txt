Solve the 1D damped wave equation u_tt + 0.5*u_t = (1.0)^2 * u_xx numerically using the specifications below.

The PDE is u_tt + gamma*u_t = c^2 * u_xx with c = 1.0 and gamma = 0.5.

The spatial domain is x in [0, 1] (closed interval). The time domain is t in [0, 3.0].

Use Nx = 400 uniform intervals, giving 401 grid points including both endpoints. Compute dx = 1.0 / 400. Set x_i = 0 + i * dx for i = 0, 1, ..., 400.

Use dt = 0.0005 and take 6000 time steps to reach T = 3.0.

Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1 for all time. Despite the mention of periodic boundaries in section 4, the problem also states Dirichlet u = 0 at both endpoints and the numerical method section explicitly enforces Dirichlet BC; use Dirichlet BC (u = 0 and v = 0 at both boundary nodes) as stated in section 7, which takes precedence.

Set the initial condition u(x, 0) = sin(pi * x) and u_t(x, 0) = 0 at all grid points.

Rewrite the PDE as a first-order system: u_t = v and v_t = c**2 * u_xx - gamma * v.

Discretize u_xx using 2nd-order central differences: u_xx at interior node i equals (u[i-1] - 2*u[i] + u[i+1]) / dx**2.

Integrate the system (u, v) using classical 4-stage Runge-Kutta (RK4) with the fixed time step dt = 0.0005.

At every RK4 substage, after computing the stage increments, enforce u = 0 and v = 0 at the boundary nodes i = 0 and i = 400.

After completing all 6000 steps, collect the solution array u of length 401 at T = 3.0.

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx).

Save a file named "solution_agent_wave_09.npz" containing the 1D array x of length 401, the 1D array u of length 401, and the scalar metadata values T = 3.0, dx, and dt.

Save a line plot of u versus x at T = 3.0 as "solution_agent_wave_09.png".

Use Python with numpy for numerics and matplotlib for the plot.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Parameters
c = 1.0
gamma = 0.5
Nx = 400
dx = 1.0 / Nx
x = np.linspace(0.0, 1.0, Nx + 1)  # 401 points

dt = 0.0005
T = 3.0
n_steps = 6000  # 6000 * 0.0005 = 3.0

# Initial conditions
u = np.sin(np.pi * x).copy()
v = np.zeros(Nx + 1)

# Enforce Dirichlet BCs on initial data
u[0] = 0.0;  u[-1] = 0.0
v[0] = 0.0;  v[-1] = 0.0

def compute_uxx(u, dx):
    """2nd-order central differences for u_xx; boundaries handled by Dirichlet (set to 0)."""
    uxx = np.zeros_like(u)
    uxx[1:-1] = (u[:-2] - 2.0 * u[1:-1] + u[2:]) / dx**2
    # boundary values of uxx are irrelevant because we zero out u and v there
    return uxx

def rhs(u, v, c, gamma, dx):
    uxx = compute_uxx(u, dx)
    du_dt = v.copy()
    dv_dt = c**2 * uxx - gamma * v
    return du_dt, dv_dt

def enforce_bc(u, v):
    u[0] = 0.0;  u[-1] = 0.0
    v[0] = 0.0;  v[-1] = 0.0

# Classical RK4 time integration
for step in range(n_steps):
    # Stage 1
    k1u, k1v = rhs(u, v, c, gamma, dx)
    u1 = u + 0.5 * dt * k1u
    v1 = v + 0.5 * dt * k1v
    enforce_bc(u1, v1)

    # Stage 2
    k2u, k2v = rhs(u1, v1, c, gamma, dx)
    u2 = u + 0.5 * dt * k2u
    v2 = v + 0.5 * dt * k2v
    enforce_bc(u2, v2)

    # Stage 3
    k3u, k3v = rhs(u2, v2, c, gamma, dx)
    u3 = u + dt * k3u
    v3 = v + dt * k3v
    enforce_bc(u3, v3)

    # Stage 4
    k4u, k4v = rhs(u3, v3, c, gamma, dx)

    # Update
    u = u + (dt / 6.0) * (k1u + 2.0 * k2u + 2.0 * k3u + k4u)
    v = v + (dt / 6.0) * (k1v + 2.0 * k2v + 2.0 * k3v + k4v)
    enforce_bc(u, v)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)    = {u_min:.6e}")
print(f"max(u)    = {u_max:.6e}")
print(f"L2 norm   = {l2_norm:.6e}")

# Save NPZ
np.savez("solution_agent_wave_09.npz",
         x=x,
         u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.5, color='steelblue')
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=3.0)")
ax.set_title("Damped Wave Equation Solution at T=3.0")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_agent_wave_09.png", dpi=150)
plt.close()

print("Files saved: solution_agent_wave_09.npz, solution_agent_wave_09.png")
```
