Solve the Allen-Cahn PDE numerically using the specifications below.

PDE: u_t = (0.01)**2 * (u_xx + u_yy) + u - u**3

Spatial domain: (x, y) in [0,1) x [0,1) with periodic boundary conditions in both x and y. Time domain: t in [0, 0.2].

Parameter: epsilon = 0.01, so epsilon**2 = 0.0001.

Grid: Use Nx = Ny = 256 uniform intervals on the half-open domain [0,1). dx = 1/256, dy = 1/256. Grid points: x_i = i*dx for i = 0..255, y_j = j*dy for j = 0..255. Do not duplicate endpoints.

Time stepping: dt = 0.0002, number of steps = 1000 (from t=0 to t=0.2).

Initial condition: u(x, y, 0) = 0.1 * cos(2*pi*x) * cos(2*pi*y), evaluated on the 2D grid.

Spatial discretization: Use the standard 5-point Laplacian for u_xx + u_yy with periodic wrap-around indexing in both x and y directions.

Time integration: Use the semi-implicit method each step: (u^{n+1} - u^n) / dt = epsilon**2 * Delta(u^{n+1}) + u^n - (u^n)**3. Rearrange to: u^{n+1} - dt * epsilon**2 * Delta(u^{n+1}) = u^n + dt * (u^n - (u^n)**3). Solve the resulting sparse linear system for u^{n+1} at each time step. The linear operator on the left is (I - dt * epsilon**2 * L) where L is the discrete Laplacian with periodic boundary conditions.

Boundary handling: Use periodic wrap-around indexing (modular indexing) in both x and y. Do not duplicate endpoints.

At final time T = 0.2, compute u(x, y, T) on the full 2D grid.
