Solve the 1D linear advection-diffusion PDE numerically as specified below.

The PDE is u_t = -q1 * d_x(u) + (q2/pi) * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
Set q1 = 1.0 and q2 = 0.05.
The initial condition is u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.

Discretize the advection term -q1 * d_x(u) using 1st-order upwind differences.
Since q1 = 1.0 > 0, the upwind approximation is d_x(u)_j = (u_j - u_{j-1}) / dx with periodic indexing.
Discretize the diffusion term (q2/pi) * u_xx using 2nd-order central differences: u_xx_j = (u_{j+1} - 2*u_j + u_{j-1}) / dx**2 with periodic indexing.

Compute the time step as dt_adv = 0.4 * dx / abs(q1) and dt_diff = 0.2 * dx**2 / (q2 / pi).
Set dt = min(dt_adv, dt_diff).
Set Nt = ceil(0.5 / dt) and reset dt = 0.5 / Nt.

Use IMEX Euler time integration: treat the diffusion term implicitly and the advection term explicitly.
At each time step, the update is: (I - dt*(q2/pi)*D2) * u_new = u_old + dt * (-q1 * D1_upwind * u_old), where D1_upwind and D2 are the upwind and central difference matrices respectively, applied with periodic boundary conditions.
Construct the implicit system as a sparse linear system and solve it at each time step, or equivalently use the circulant structure to solve efficiently via FFT or direct sparse solve.

After advancing to T = 0.5, compute the exact reference solution using Fourier mode evolution.
The exact solution for initial condition sin(2*pi*x) + 0.5*sin(4*pi*x) is:
u_exact(x, T) = exp(-(q2/pi)*(2*pi)**2*T) * sin(2*pi*(x - q1*T)) + 0.5*exp(-(q2/pi)*(4*pi)**2*T) * sin(4*pi*(x - q1*T)).
Evaluate u_exact on the same x grid at T = 0.5.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 0.5.
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
