Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically in Python and save the results.

Use Gamma = 5/3 = 1.6666666666666667. Discard the second Gamma listing (0.166666666667) as a typo.

The conservative variables are U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v**2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.

The PDEs in conservative form are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.5].
Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., Nx-1, with dx = 2/Nx.
Evolve cell-average conservative variables U = [rho, m, E].

The equation of state is p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.

The initial conditions defined pointwise on cell centers are:
rho(x, 0) = 1.0 + 0.2*sin(pi*x)
v(x, 0) = 0.1*cos(pi*x)
p(x, 0) = 1.0 + 0.2*cos(pi*x)
Convert to conservative variables: m = rho*v, E = p/(Gamma-1) + 0.5*rho*v**2.

Boundary conditions are periodic on x = -1 and x = 1. Implement via index wrapping for ghost cells.

For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] with v = m/rho.
The interface wave speed is a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Use first-order reconstruction (piecewise constant), so U_L at interface i+1/2 is cell i and U_R is cell i+1.

For the viscous terms, compute v_x at each cell center using centered differences with periodic wrapping.
Compute sigma at each cell center as sigma = (zeta + 4/3*eta) * v_x.
Approximate sigma at each interface i+1/2 by averaging the sigma values of the two neighboring cell centers.
Approximate v at each interface i+1/2 by averaging the v values of the two neighboring cell centers.
The viscous flux vector at each interface is F_visc = [0, -sigma_interface, -v_interface * sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.
At each time step, compute the time step as follows:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
dt = min(dt_conv, dt_visc)
Use CFL = 0.5.
Adjust the last time step so the simulation ends exactly at T = 0.5.
