Solve the Klein-Gordon PDE numerically using the following specification.

PDE: u_tt - (1.0)**2 * u_xx + (1.0)**2 * u = sin(pi*x) * cos(2*t)

Spatial domain: x in [0, 1], closed interval.
Time domain: t in [0, 5.0].

Parameters: c = 1.0, m = 1.0.

Boundary conditions: Dirichlet, u = 0 at x = 0 and x = 1 for all t. Ignore the periodic condition mentioned in the original specification.

Initial conditions: u(x, 0) = 0 and u_t(x, 0) = 0.

Use a uniform spatial grid with Nx = 400 intervals, giving Nx + 1 = 401 grid points including both endpoints. Set dx = (1 - 0) / 400 = 0.0025. Grid points are x_i = 0 + i * dx for i = 0, 1, ..., 400.

Use 2nd-order central differences for u_xx (standard 3-point stencil).

Use leapfrog (2nd-order central difference in time) for u_tt. Set dt = 0.001, giving 5000 time steps to reach T = 5.0. Verify that c * dt / dx = 1.0 * 0.001 / 0.0025 = 0.4, which satisfies the CFL condition c * dt / dx <= 0.9.

In the leapfrog update, treat the +m**2 * u term explicitly at time level n. Include the forcing term sin(pi * x) * cos(2 * t_n) explicitly at time level n.

Initialize u_1 (the solution at t = dt) using a Taylor expansion: u_1 = u0 + dt * v0 + 0.5 * dt**2 * (c**2 * u0_xx - m**2 * u0 + f(x, 0)), where u0 = 0, v0 = 0, u0_xx = 0, and f(x, 0) = sin(pi * x) * cos(0) = sin(pi * x). So u_1 = 0.5 * dt**2 * sin(pi * x_i) for interior points. Apply Dirichlet conditions u = 0 at i = 0 and i = 400 at every time step including initialization.

The leapfrog update for interior points i = 1 to 399 is: u_new_i = 2 * u_i - u_old_i + dt**2 * (c**2 * (u_{i+1} - 2*u_i + u_{i-1}) / dx**2 - m**2 * u_i + sin(pi * x_i) * cos(2 * t_n)).

After 5000 steps, compute u(x, T = 5.0) on the full 401-point grid.

Save a line plot of u(x, T = 5.0) as "solution_agent_kg_07.png" with x on the horizontal axis and u on the vertical axis.
