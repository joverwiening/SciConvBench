Solve the 1D KdV-type PDE u_t + (q**2)*u_xxx + u*u_x = 0 numerically using the specifications below.

The PDE is u_t + (q**2)*u_xxx + u*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter q equals 0.1.
The initial condition is u(x, 0) = cos(2*pi*x).
No exact reference solution is required or used.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Define x_j = j * dx for j = 0, 1, ..., Nx-1 where dx = 1.0 / Nx.

Compute spatial derivatives u_x and u_xxx using the Fourier spectral method.
To compute a spectral derivative, take the FFT of u, multiply each Fourier coefficient by (i * k) for u_x or (i * k)**3 for u_xxx where k is the wavenumber array, then take the inverse FFT and take the real part.
Define the wavenumber array k using numpy as k = 2*pi * numpy.fft.fftfreq(Nx, d=dx), which gives k_j = 2*pi*j/L for j = 0, ..., Nx/2-1 and negative frequencies for j = Nx/2, ..., Nx-1.

Use RK4 (classical 4th-order Runge-Kutta) for time integration.
Use dt = 0.0001 and Nt = 2000 time steps so the final time T = 0.2 is reached exactly.
At each RK4 stage, evaluate the right-hand side as rhs(u) = -(q**2) * u_xxx - u * u_x where u_xxx and u_x are computed spectrally.

After completing all Nt steps, the solution array u holds u(x, T=0.2) on the Nx-point periodic grid.

Save a file named "solution_molk_017.npz" using numpy.savez.

Below is the complete Python implementation:

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# ── parameters ────────────────────────────────────────────────────────────────
q   = 0.1
Nx  = 512
L   = 1.0
dx  = L / Nx
dt  = 0.0001
Nt  = 2000
T   = dt * Nt          # = 0.2

# ── grid ──────────────────────────────────────────────────────────────────────
x = np.arange(Nx) * dx                          # x_j = j*dx, j=0..Nx-1

# ── wavenumber array ──────────────────────────────────────────────────────────
# k_j = 2*pi * fftfreq(Nx, d=dx)  →  units of rad / length
k  = 2.0 * np.pi * np.fft.fftfreq(Nx, d=dx)
ik  = 1j * k                                    # multiplier for first derivative
ik3 = (1j * k) ** 3                             # multiplier for third derivative

# ── spectral derivative helpers ───────────────────────────────────────────────
def deriv1(u):
    """Spectral first derivative u_x."""
    return np.fft.ifft(ik * np.fft.fft(u)).real

def deriv3(u):
    """Spectral third derivative u_xxx."""
    return np.fft.ifft(ik3 * np.fft.fft(u)).real

# ── right-hand side ───────────────────────────────────────────────────────────
def rhs(u):
    """RHS of u_t = -(q**2)*u_xxx - u*u_x."""
    return -(q**2) * deriv3(u) - u * deriv1(u)

# ── initial condition ─────────────────────────────────────────────────────────
u = np.cos(2.0 * np.pi * x)

# ── RK4 time integration ──────────────────────────────────────────────────────
for _ in range(Nt):
    k1 = rhs(u)
    k2 = rhs(u + 0.5 * dt * k1)
    k3 = rhs(u + 0.5 * dt * k2)
    k4 = rhs(u +       dt * k3)
    u  = u + (dt / 6.0) * (k1 + 2.0*k2 + 2.0*k3 + k4)

# ── diagnostics ───────────────────────────────────────────────────────────────
u_min  = np.min(u)
u_max  = np.max(u)
u_mean = np.mean(u)
u_l2   = np.sqrt(np.sum(u**2) * dx)

print(f"T        = {T}")
print(f"min(u)   = {u_min:.10e}")
print(f"max(u)   = {u_max:.10e}")
print(f"mean(u)  = {u_mean:.10e}")
print(f"L2 norm  = {u_l2:.10e}")

# ── save npz ──────────────────────────────────────────────────────────────────
np.savez(
    "solution_molk_017.npz",
    x   = x,
    u   = u,
    T   = np.float64(T),
    dx  = np.float64(dx),
    Nx  = np.int64(Nx),
    q   = np.float64(q),
)
print("Saved solution_molk_017.npz")

# ── save plot ─────────────────────────────────────────────────────────────────
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=0.2)")
ax.set_title(f"KdV-type solution at T = {T}  (q={q}, Nx={Nx}, RK4)")
ax.grid(True, linewidth=0.4)
fig.tight_layout()
fig.savefig("solution_molk_017.png", dpi=150)
plt.close(fig)
print("Saved solution_molk_017.png")
```
