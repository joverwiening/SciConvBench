Solve the 2D Darcy flow PDE numerically as described below.

The PDE is -div(a(x,y) grad(u(x,y))) = 1 on the domain (0,1) x (0,1).
The coefficient field is a(x,y) = 1 + 2 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions u = 0 on the entire boundary.
Use beta = 2 and N = 128 uniform intervals in each direction.
The grid has N+1 = 129 points in each direction including both endpoints.
Set dx = dy = 1/N.
Set x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.

Discretize using 2nd-order finite differences with face-centered harmonic averaging.
For interior nodes i=1..N-1 and j=1..N-1, apply the stencil:
-(1/dx**2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1
Compute face coefficients using harmonic means, e.g. a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)), and similarly for all other faces.

Assemble the sparse linear system Au = b for the interior unknowns only.
The right-hand side vector b has all entries equal to 1.
Solve the linear system using conjugate gradient (CG) with a relative residual tolerance of 1e-10.
Optionally use a Jacobi preconditioner to accelerate convergence.

After solving, construct the full (N+1) x (N+1) solution grid by placing the interior solution into the interior nodes and setting boundary values to zero.

Print min(u), max(u), and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system.

Save a file named "solution_pdebench_darcy_beta1.npz" containing the 1D array x of length N+1, the 1D array y of length N+1, the 2D array u of shape [N+1, N+1], and the scalars beta, N, and dx.

Save a heatmap or filled contour plot of u(x,y) as "solution_pdebench_darcy_beta1.png".

Use Python with NumPy, SciPy sparse, and Matplotlib.
Use scipy.sparse for matrix assembly (e.g. lil_matrix or csr_matrix).
Use scipy.sparse.linalg.cg for the conjugate gradient solver.
Interpret the caret symbol ^ as exponentiation and use ** in Python code for powers.
