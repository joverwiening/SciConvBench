Solve the 1D viscous Burgers equation u_t + u*u_x = 0.005*u_xx numerically and save the results.

The PDE is u_t + (f(u))_x = nu*u_xx with f(u) = 0.5*u**2 and nu = 0.005.

The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 0.2].

Use Nx = 1200 grid points on [0,1) with no duplicated endpoint.
Set dx = 1.0/1200.
Set x_i = i*dx for i = 0, 1, ..., 1199.

Use dt = 5e-5 and Nt = 4000 time steps so that T = 0.2 is hit exactly.

Apply the initial condition u(x, 0) = 0.5 + sin(2*pi*x).

Discretize convection using the Rusanov (local Lax-Friedrichs) flux in conservative finite-difference form.
Compute F_{i+1/2} = 0.5*(f(u_i) + f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1} - u_i) where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
Compute the convection term at cell i as (F_{i+1/2} - F_{i-1/2}) / dx.
Use periodic wrap-around indexing so that index Nx wraps to 0 and index -1 wraps to Nx-1.

Discretize diffusion using the 2nd-order central difference u_xx ≈ (u_{i+1} - 2*u_i + u_{i-1}) / dx**2.
Use periodic wrap-around indexing for the diffusion stencil as well.

Use 1st-order IMEX time integration: treat convection explicitly and diffusion implicitly.
At each time step, form the right-hand side rhs_i = u_i^n - dt * conv_term_i.
Form the linear system (I - dt*nu*L) u^{n+1} = rhs where L is the tridiagonal periodic second-difference matrix with entries -2 on the diagonal and 1 on the off-diagonals, including periodic corner entries L[0, Nx-1] = 1 and L[Nx-1, 0] = 1, all divided by dx**2.
Build the matrix (I - dt*nu*L) as a sparse matrix using scipy.sparse in CSR format.
Solve the sparse linear system each time step using scipy.sparse.linalg.spsolve.

After Nt = 4000 steps, compute the final solution u(x, T=0.2).

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.2.
