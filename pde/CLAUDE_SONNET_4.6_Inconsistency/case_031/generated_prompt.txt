Solve the heat equation u_t = 0.5 * u_xx numerically using the Crank-Nicolson method and save the results.

The PDE is u_t = 0.5 * u_xx with alpha = 0.5.
The spatial domain is x in [0, 1] (closed interval) and the time domain is t in [0, 0.2].
Use Nx = 200 uniform intervals, giving 201 grid points including both endpoints at x_i = i * dx for i = 0, 1, ..., 200, with dx = 1/200 = 0.005.
Use dt = 0.0005 and run for 480 time steps to reach T = 0.2.
The initial condition is u(x, 0) = sin(2 * pi * x).
Apply Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 for all t by fixing the boundary nodes at each time step.
Discretize u_xx using 2nd-order central differences on the interior nodes only.
Apply the Crank-Nicolson scheme: (u^{n+1} - u^n) / dt = 0.5 * 0.5 * (u_xx^{n+1} + u_xx^n), which gives the implicit system (I - r * A) u^{n+1} = (I + r * A) u^n where r = alpha * dt / (2 * dx**2) = 0.5 * 0.0005 / (2 * 0.005**2) and A is the tridiagonal second-difference matrix for interior nodes.
At each time step, enforce u[0] = 0 and u[200] = 0 before and after solving the linear system.
Solve the tridiagonal linear system at each time step using scipy.linalg.solve_banded or scipy.sparse.linalg.spsolve.
After reaching T = 0.2, compute the exact solution u_exact(x, T) = exp(-0.5 * (2 * pi)**2 * T) * sin(2 * pi * x) on the same x grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) of the numerical solution at T = 0.2.
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
Save a file named "solution_agent_heat_02.npz" containing the 1D array x (length 201), the 1D array u (length 201, numerical solution at T = 0.2), and scalar metadata T = 0.2, dx = 0.005, dt = 0.0005.
Save a line plot of u(x, T) versus x as "solution_agent_heat_02.png" with labeled axes.

```python
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla
import matplotlib.pyplot as plt

# Parameters
alpha = 0.5
Nx = 200
dx = 1.0 / Nx
dt = 0.0005
T = 0.2
Nt = int(round(T / dt))  # 480 time steps

# Grid (201 points including both endpoints)
x = np.linspace(0.0, 1.0, Nx + 1)

# Initial condition
u = np.sin(2 * np.pi * x)

# Enforce Dirichlet BCs on initial condition
u[0] = 0.0
u[-1] = 0.0

# Interior indices: 1 to Nx-1 (199 interior nodes)
N_int = Nx - 1  # 199

# Build tridiagonal matrix A for interior nodes (second-difference operator)
# A has shape (N_int x N_int)
# A[i,i] = -2, A[i,i+1] = 1, A[i-1,i] = 1
diag_main = -2.0 * np.ones(N_int)
diag_off = np.ones(N_int - 1)
A = sp.diags([diag_off, diag_main, diag_off], [-1, 0, 1], shape=(N_int, N_int), format='csr')

# Crank-Nicolson parameter
r = alpha * dt / (2.0 * dx**2)

# Build LHS and RHS matrices
# LHS: I - r * A
# RHS: I + r * A
I = sp.eye(N_int, format='csr')
LHS = I - r * A
RHS_mat = I + r * A

# Factorize LHS once (it doesn't change)
LHS_factored = spla.splu(LHS.tocsc())

# Time integration
for n in range(Nt):
    u_int = u[1:Nx]  # interior values, length N_int

    # Compute RHS vector
    rhs = RHS_mat.dot(u_int)

    # Boundary contributions to RHS are zero since u[0]=u[Nx]=0 always
    # (no correction needed)

    # Solve linear system
    u_int_new = LHS_factored.solve(rhs)

    # Update solution
    u[1:Nx] = u_int_new
    u[0] = 0.0
    u[-1] = 0.0

# Exact solution at T=0.2
u_exact = np.exp(-0.5 * (2 * np.pi)**2 * T) * np.sin(2 * np.pi * x)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
max_abs_error = np.max(np.abs(u - u_exact))
l2_error = np.sqrt(np.sum((u - u_exact)**2) * dx)

print(f"min(u)          = {u_min:.6e}")
print(f"max(u)          = {u_max:.6e}")
print(f"L2 norm of u    = {l2_norm:.6e}")
print(f"Max abs error   = {max_abs_error:.6e}")
print(f"L2 error        = {l2_error:.6e}")

# Save .npz
np.savez("solution_agent_heat_02.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_heat_02.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, u, label=f"Numerical u(x, T={T})", color='blue', linewidth=2)
ax.plot(x, u_exact, label="Exact solution", color='red', linestyle='--', linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Heat Equation Solution at T={T} (Crank-Nicolson)")
ax.legend()
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_heat_02.png", dpi=150)
plt.close()
print("Saved solution_agent_heat_02.png")
```
