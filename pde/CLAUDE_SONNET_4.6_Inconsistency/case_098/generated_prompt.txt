Solve the 1D wave equation u_tt = (1.5)^2 * u_xx numerically with the following specifications.

The PDE is u_tt = (1.5)**2 * u_xx, but note the wave speed used for CFL is c = 3 (as given in parameters).
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 0.7].
Use Nx = 512 uniformly spaced grid points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Set dt0 = 0.9 * dx / c where c = 3.
Set Nt = ceil(0.7 / dt0).
Set dt = 0.7 / Nt so the final time T = 0.7 is hit exactly.
The CFL condition uses c = 3 for the time step calculation.
The PDE coefficient is (1.5)**2, so the wave speed in the equation is 1.5.
The spatial second derivative u_xx is approximated with 2nd-order central differences using wrap-around (periodic): u_xx[i] = (u[i+1] - 2*u[i] + u[i-1]) / dx**2 with indices taken modulo Nx.
Initialize u0[i] = sin(2*pi*x[i]) and v0[i] = cos(2*pi*x[i]) where x[i] = i*dx for i = 0..Nx-1.
Use a Taylor series start for the first time step: u1[i] = u0[i] + dt*v0[i] + 0.5*dt**2*(1.5)**2*u_xx(u0)[i].
Advance subsequent time steps using the 2nd-order central difference in time: u_new[i] = 2*u[i] - u_old[i] + dt**2*(1.5)**2*u_xx(u)[i].
Continue time-stepping until t = T = 0.7 is reached (exactly Nt steps total).
At t = T, compute the solution array u of length 512.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx).
Save a file named "solution_agent_wave_17.npz" containing arrays x (1D, length 512), u (1D, length 512), and scalar metadata T=0.7, dx, dt.
Save a line plot of u(x, T) as "solution_agent_wave_17.png" with x on the horizontal axis and u on the vertical axis.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
Nx = 512
T = 0.7
c_cfl = 3.0          # wave speed used for CFL
c_pde = 1.5          # wave speed in the PDE: u_tt = c_pde^2 * u_xx

dx = 1.0 / Nx
dt0 = 0.9 * dx / c_cfl
Nt = int(np.ceil(T / dt0))
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL={c_cfl*dt/dx:.6f}")

# Grid
x = np.arange(Nx) * dx  # x_i = i*dx, i=0..Nx-1

# Initial conditions
u0 = np.sin(2 * np.pi * x)
v0 = np.cos(2 * np.pi * x)

# Function to compute u_xx with periodic wrap-around (2nd-order central differences)
def laplacian(u, dx):
    return (np.roll(u, -1) - 2.0 * u + np.roll(u, 1)) / dx**2

# Taylor series start for first step
u_xx0 = laplacian(u0, dx)
u_old = u0.copy()
u_cur = u0 + dt * v0 + 0.5 * dt**2 * c_pde**2 * u_xx0

# Time-stepping: 2nd-order central difference in time
for n in range(1, Nt):
    u_xx = laplacian(u_cur, dx)
    u_new = 2.0 * u_cur - u_old + dt**2 * c_pde**2 * u_xx
    u_old = u_cur
    u_cur = u_new

u_final = u_cur

# Diagnostics
u_min = np.min(u_final)
u_max = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)
print(f"min(u)   = {u_min:.10f}")
print(f"max(u)   = {u_max:.10f}")
print(f"L2 norm  = {l2_norm:.10f}")

# Save npz
np.savez("solution_agent_wave_17.npz",
         x=x,
         u=u_final,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))
print("Saved solution_agent_wave_17.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_final, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Wave equation solution at T={T}")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_wave_17.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_17.png")
```
