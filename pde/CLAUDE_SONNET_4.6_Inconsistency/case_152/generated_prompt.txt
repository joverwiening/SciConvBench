Solve the 1D Viscous Burgers equation numerically with the following specifications.

PDE: u_t + d/dx(0.5*u**2) = nu * u_xx

Spatial domain: x in [0, 1) with periodic boundary conditions.
Temporal domain: t in [0, 1.0].
Parameter: nu = 0.002.
Initial condition: u(x, 0) = sin(2*pi*x).
No closed-form reference solution is required.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Define x_j = j * dx for j = 0, ..., 511 where dx = 1/512.

Use Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): apply a finite-volume update for the inviscid Burgers equation u_t + d/dx(0.5*u**2) = 0 using Rusanov (local Lax-Friedrichs) flux. Define f(u) = 0.5*u**2. For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing), compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j, compute F_plus as the flux at the right interface (between u[j] and u[j+1]) and F_minus as the flux at the left interface (between u[j-1] and u[j]), then set u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus). Replace u with u_new after this substep.

Step C (diffusion half-step again): repeat Step A identically.

Set CFL = 0.4 and estimate max speed as 1.0 for this initial condition.
Compute dt0 = CFL * dx / 1.0.
Compute Nt = ceil(T / dt0) where T = 1.0.
Reset dt = T / Nt so the final time T = 1.0 is hit exactly.

Advance the solution from t = 0 to t = 1.0 using Nt steps of Strang splitting.

After the simulation, compute u(x, T=1.0) on the periodic grid.

Print the following diagnostics: min(u), max(u), discrete mean value mean(u) (should be approximately conserved), and discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.

Save a file named "solution_pdebench_burgers_nu2em3.npz" containing the following arrays and scalars: x (1D array of length 512), u (1D array of length 512), nu (scalar = 0.002), T (scalar = 1.0), dx (scalar), dt (scalar), Nx (scalar = 512), Nt (scalar).

Save a line plot of u(x, T=1.0) as a PNG file named "solution_pdebench_burgers_nu2em3.png".
