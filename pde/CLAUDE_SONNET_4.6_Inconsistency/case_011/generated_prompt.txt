Solve the Allen-Cahn PDE numerically and save the results as specified below.

PDE: u_t = (0.02)**2 * (u_xx + u_yy) + u - u**3

Spatial domain: (x,y) in [0,1] x [0,1], closed intervals on all sides.
Time domain: t in [0, 0.1].

Parameter: epsilon = 0.02.

Grid: Use Nx=Ny=300 uniform intervals in each spatial direction.
This gives 301 x 301 grid points including both endpoints.
dx = 1/300, dy = 1/300.
x_i = i*dx for i=0..300, y_j = j*dy for j=0..300.

Time stepping: dt = 0.0001, total steps = 1000, final time T = 0.1.

Spatial discretization: Use the standard 5-point Laplacian stencil for u_xx + u_yy on the interior nodes.

Time integration: Semi-implicit scheme each step.
The update equation is: (u^{n+1} - u^n)/dt = epsilon**2 * Delta(u^{n+1}) + u^n - (u^n)**3.
Rearranged: u^{n+1} - dt*epsilon**2 * Delta(u^{n+1}) = u^n + dt*(u^n - (u^n)**3).
Assemble and solve a sparse linear system for u^{n+1} at each time step.

Boundary conditions: Dirichlet u=0 on all four boundaries (i=0, i=300, j=0, j=300).
Enforce by setting boundary nodes to 0 after each linear solve (or by construction in the linear system).

Initial condition: Let r = sqrt((x-0.5)**2 + (y-0.5)**2). Set u(x,y,0) = tanh((0.25 - r)/(sqrt(2)*0.02)).

Output: Compute u(x,y,T=0.1) on the full 301x301 grid.

Save file "solution_agent_allen_cahn_05.npz" containing:
- x: 1D array of length 301 with x grid points.
- y: 1D array of length 301 with y grid points.
- u: 2D array of shape (301, 301) where u[j,i] = u(x_i, y_j) at T=0.1.
- T: scalar 0.1.
- dx: scalar 1/300.
- dy: scalar 1/300.
- dt: scalar 0.0001.

Save a heatmap or contour plot of u(x,y,T=0.1) as "solution_agent_allen_cahn_05.png".

Print the following scalar diagnostics at T=0.1:
- min(u) over all grid points.
- max(u) over all grid points.
- Discrete L2 norm: sqrt(sum(u**2)*dx*dy) over all grid points.
