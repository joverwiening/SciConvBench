Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Use Python with numpy and matplotlib.
Treat all mathematical functions exactly as written and use radians for trigonometric functions.
Use ** for exponentiation in Python code.

Domain: x in [0, 1) with periodic boundary condition, t in [0, 1.0].
Set nu = 5.0 and rho = 5.0.
Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0 / Nx.
Set grid points as x_j = j * dx for j = 0, 1, ..., Nx-1.
Use fixed time step dt = 0.001 and Nt = 1000 steps so that T = 1.0 is reached exactly.

Set the initial condition as u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).

Advance the solution using Strang splitting for each full time step dt as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).
Step B (reaction full-step, duration dt): update each grid point exactly using the logistic ODE solution u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Step C (diffusion half-step again): repeat Step A identically.
Repeat Steps A, B, C for all Nt = 1000 time steps.

After completing all time steps, compute the final solution u(x, T=1.0) on the periodic grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.
Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu5_rho5.png" with x on the horizontal axis and u on the vertical axis.
Save a file "solution_pdebench_reacdiff_nu5_rho5.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), nu (scalar), rho (scalar), T (scalar), dx (scalar), dt (scalar), Nx (scalar), Nt (scalar).

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
nu = 5.0
rho = 5.0
T = 1.0
Nx = 512
dx = 1.0 / Nx
dt = 0.001
Nt = 1000

# Spatial grid
x = np.array([j * dx for j in range(Nx)])

# Wavenumbers for FFT
k = 2.0 * np.pi * np.fft.fftfreq(Nx, d=dx)

# Precompute diffusion factors for half-step and full-step
diff_half = np.exp(-nu * k**2 * (dt / 2.0))

# Initial condition
u = 0.25 + 0.1 * np.sin(2.0 * np.pi * x)

# Precompute reaction constants
exp_rho_dt = np.exp(rho * dt)

def diffusion_half_step(u):
    u_hat = np.fft.fft(u)
    u_hat *= diff_half
    return np.fft.ifft(u_hat).real

def reaction_full_step(u):
    return (u * exp_rho_dt) / (1.0 + u * (exp_rho_dt - 1.0))

# Time integration using Strang splitting
for n in range(Nt):
    # Step A: diffusion half-step
    u = diffusion_half_step(u)
    # Step B: reaction full-step
    u = reaction_full_step(u)
    # Step C: diffusion half-step
    u = diffusion_half_step(u)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
u_mean = np.mean(u)
u_l2 = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.6e}")
print(f"max(u)  = {u_max:.6e}")
print(f"mean(u) = {u_mean:.6e}")
print(f"L2 norm = {u_l2:.6e}")

# Save plot
plt.figure(figsize=(8, 4))
plt.plot(x, u, linewidth=1.5)
plt.xlabel("x")
plt.ylabel("u(x, T)")
plt.title(f"1D Reaction-Diffusion solution at T={T}, nu={nu}, rho={rho}")
plt.tight_layout()
plt.savefig("solution_pdebench_reacdiff_nu5_rho5.png", dpi=150)
plt.close()

# Save npz
np.savez(
    "solution_pdebench_reacdiff_nu5_rho5.npz",
    x=x,
    u=u,
    nu=nu,
    rho=rho,
    T=T,
    dx=dx,
    dt=dt,
    Nx=Nx,
    Nt=Nt
)

print("Files saved: solution_pdebench_reacdiff_nu5_rho5.npz and solution_pdebench_reacdiff_nu5_rho5.png")
```
