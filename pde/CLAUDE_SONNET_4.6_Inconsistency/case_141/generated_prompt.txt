Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.

Domain: x in [0, 1) with periodic boundary, t in [0, 2.0]. Note the output asks for T=2.1 but the domain says t in [0, 2.0]; use T=2.0 as the final time for time integration, and evaluate/output at T=2.0 (the reference solution uses beta*t mod 1, so use T=2.0).

Parameters: beta = 4.0.

Initial condition: u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

Reference solution: u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition.

Spatial grid: Nx = 512 points on [0,1) with dx = 1/Nx and x_j = j*dx for j = 0, ..., Nx-1.

Spatial discretization: 1st-order upwind finite difference. Since beta = 4.0 > 0, use backward difference: u_x at j approximated as (u_j - u_{j-1}) / dx with periodic indexing (j-1 wraps to Nx-1 when j=0).

Time integration: Explicit forward Euler.

Time step: CFL = 0.5, dt = CFL * dx / abs(beta). Set Nt = ceil(T / dt), then reset dt = T / Nt so the final time T is hit exactly.

At each time step: u_new[j] = u[j] - beta * dt / dx * (u[j] - u[j-1 mod Nx]).

After time integration, compute the reference solution on the same grid using u_ref[j] = u0((x_j - beta*T) mod 1).

Print min(u), max(u), discrete L2 norm sqrt(sum(u**2)*dx), max absolute error max(abs(u - u_ref)), and L2 error sqrt(sum((u - u_ref)**2)*dx).

Save "solution_pdebench_advection_beta4.npz" containing: x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_advection_beta4.png" with x on the horizontal axis and u on the vertical axis.

Use numpy for all array operations and matplotlib for the plot.

Below is the complete Python implementation:

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
beta = 4.0
T    = 2.0
CFL  = 0.5
Nx   = 512

# Spatial grid: x in [0,1), periodic
dx = 1.0 / Nx
x  = np.arange(Nx) * dx          # x_j = j*dx, j=0,...,Nx-1

# Initial condition
def u0(xi):
    return np.sin(2 * np.pi * xi) + 0.5 * np.sin(4 * np.pi * xi)

u = u0(x).copy()

# Time step (CFL-based, then adjusted to hit T exactly)
dt_cfl = CFL * dx / abs(beta)
Nt     = int(np.ceil(T / dt_cfl))
dt     = T / Nt                   # reset so Nt*dt == T exactly

print(f"Nx={Nx}, dx={dx:.6e}, dt={dt:.6e}, Nt={Nt}, T={T}")

# ── Forward Euler + 1st-order upwind (beta > 0 → backward difference) ──────
r = beta * dt / dx                # Courant number (should be <= CFL = 0.5)

for _ in range(Nt):
    # u[j-1] with periodic wrap: np.roll(u, 1) shifts right → index j gets j-1
    u_jm1 = np.roll(u, 1)
    u     = u - r * (u - u_jm1)

# ── Reference solution ───────────────────────────────────────────────────────
x_shifted = (x - beta * T) % 1.0
u_ref     = u0(x_shifted)

# ── Diagnostics ──────────────────────────────────────────────────────────────
u_min   = np.min(u)
u_max   = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

err_abs = np.abs(u - u_ref)
max_err = np.max(err_abs)
l2_err  = np.sqrt(np.sum((u - u_ref)**2) * dx)

print(f"min(u)          = {u_min:.6e}")
print(f"max(u)          = {u_max:.6e}")
print(f"L2 norm of u    = {l2_norm:.6e}")
print(f"Max abs error   = {max_err:.6e}")
print(f"L2 error        = {l2_err:.6e}")

# ── Save .npz ────────────────────────────────────────────────────────────────
np.savez(
    "solution_pdebench_advection_beta4.npz",
    x    = x,
    u    = u,
    beta = beta,
    T    = T,
    dx   = dx,
    dt   = dt,
    Nx   = Nx,
    Nt   = Nt,
)
print("Saved solution_pdebench_advection_beta4.npz")

# ── Save plot ─────────────────────────────────────────────────────────────────
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u,     lw=1.5, label=f"Numerical  (T={T})")
ax.plot(x, u_ref, lw=1.0, ls="--", label="Reference")
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"1D Advection  β={beta}  T={T}  (upwind FD + Forward Euler)")
ax.legend()
fig.tight_layout()
fig.savefig("solution_pdebench_advection_beta4.png", dpi=150)
plt.close(fig)
print("Saved solution_pdebench_advection_beta4.png")
```

Key implementation notes:
Use np.roll(u, 1) to obtain u[j-1] with periodic wrap; this correctly handles the j=0 boundary without an explicit if-statement.
The Courant number r = beta*dt/dx equals CFL = 0.5, which satisfies the upwind stability condition r <= 1.
The reference solution is evaluated by shifting x by -beta*T and wrapping into [0,1) with the modulo operator before applying u0.
All requested scalars (beta, T, dx, dt, Nx, Nt) are stored as zero-dimensional arrays inside the .npz file and can be retrieved with float(data['beta']), etc.
