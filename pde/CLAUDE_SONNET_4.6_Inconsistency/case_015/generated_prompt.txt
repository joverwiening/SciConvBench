Solve the 1D viscous Burgers equation numerically and save the results.

The PDE is u_t + u*u_x = 0.01*u_xx, equivalently u_t + (0.5*u**2)_x = nu*u_xx with nu=0.01.

The spatial domain is x in [0,1] (closed interval). Use Nx=800 uniform intervals giving Nx+1=801 grid points including both endpoints. Set dx=1/800. Grid points are x_i = i*dx for i=0,1,...,800.

The time domain is t in [0,0.5]. Use dt=1e-4 and Nt=5000 steps so T=0.5 is hit exactly.

Apply Dirichlet boundary conditions: u[0]=0 and u[800]=0 at every time step. Ignore the periodic mention in the original section 4; it is an error.

Set the initial condition u(x,0)=sin(pi*x) evaluated at all 801 grid points.

Discretize convection in conservative form using the Rusanov (local Lax-Friedrichs) flux. Define f(u)=0.5*u**2. At each interior interface i+1/2, compute F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*max(|u_i|,|u_{i+1}|)*(u_{i+1}-u_i). Approximate (f(u))_x at interior point i as (F_{i+1/2} - F_{i-1/2})/dx. At the left boundary interface (between ghost/boundary and i=1), use u[0]=0 as the left value. At the right boundary interface (between i=799 and boundary), use u[800]=0 as the right value. Do not use periodic wrap-around for flux computation.

Discretize diffusion implicitly using 2nd-order central differences: u_xx at interior point i approximated as (u_{i+1}-2*u_i+u_{i-1})/dx**2. Enforce Dirichlet BCs in the diffusion operator by treating u[0] and u[800] as known zeros; they do not appear as unknowns.

Use 1st-order IMEX time integration. The unknown vector u^{n+1} contains only the Nx-1=799 interior points (indices 1 through 799). At each step, form the right-hand side as u^n[1:800] minus dt times the convection term at interior points. Form the left-hand side matrix as (I - dt*nu*L) where L is the (799x799) tridiagonal diffusion matrix with diagonal -2/dx**2 and off-diagonals 1/dx**2, with Dirichlet BCs incorporated (boundary values are zero so no correction terms are needed on the rhs). Solve the sparse linear system using scipy.sparse.linalg.spsolve each time step. After solving, set u[0]=0 and u[800]=0 explicitly.

After all Nt steps, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) over all 801 points at T=0.5.
