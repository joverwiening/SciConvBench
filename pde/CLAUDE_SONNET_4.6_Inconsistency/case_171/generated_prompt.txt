Solve the 2D Darcy flow PDE numerically as described below.

The PDE is -div(a(x,y) grad(u(x,y))) = 1 on the domain (x,y) in (0,1) x (0,1).
The coefficient field is a(x,y) = 1 + 100.0 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply homogeneous Dirichlet boundary conditions u = 0 on the entire boundary of the unit square.
Ignore the periodic boundary condition statement; it contradicts the Dirichlet condition, so use Dirichlet only.

Use a uniform Cartesian grid with N = 128 intervals in each direction.
The grid has N+1 = 129 points in each direction including both endpoints.
Set dx = dy = 1/N.
Set x_i = i*dx for i = 0, 1, ..., N and y_j = j*dy for j = 0, 1, ..., N.

Discretize the PDE at interior nodes (i = 1 to N-1, j = 1 to N-1) using second-order finite differences with face-centered harmonic averaging.
The discrete equation at interior node (i, j) is:
-(1/dx**2) * [a(i+1/2,j)*(u[i+1,j]-u[i,j]) - a(i-1/2,j)*(u[i,j]-u[i-1,j]) + a(i,j+1/2)*(u[i,j+1]-u[i,j]) - a(i,j-1/2)*(u[i,j]-u[i,j-1])] = 1.
Compute face coefficients using harmonic means: a(i+1/2,j) = 2*a[i,j]*a[i+1,j] / (a[i,j] + a[i+1,j]), and analogously for all other faces.
Evaluate a(x,y) at grid nodes: a[i,j] = 1 + 100.0 * (0.5 + 0.5*sin(2*pi*x_i)*sin(2*pi*y_j)).

Assemble the sparse linear system A_int * u_int = b for the (N-1)*(N-1) interior unknowns, where b is a vector of ones.
Boundary values are zero and do not contribute to the right-hand side.
Solve the linear system using the conjugate gradient (CG) method from scipy.sparse.linalg.cg with a relative tolerance of 1e-10.
Optionally use a Jacobi preconditioner (diagonal of A_int) to accelerate convergence.

After solving, assemble the full (N+1) x (N+1) solution array u with u = 0 on all boundary nodes and interior values filled from the CG solution.

Print min(u) over the full grid.
Print max(u) over the full grid.
Print the discrete residual norm ||A_int * u_int - b||_2 / ||b||_2.

Save a file named "solution_pdebench_darcy_beta100.npz" containing: x as a 1D array of length N+1, y as a 1D array of length N+1, u as a 2D array of shape [N+1, N+1], and scalars beta = 100.0, N = 128, dx = 1/128.
Save a heatmap or filled-contour plot of u(x,y) as "solution_pdebench_darcy_beta100.png" with labeled axes and a colorbar.

Use Python with numpy, scipy.sparse, scipy.sparse.linalg, and matplotlib.
