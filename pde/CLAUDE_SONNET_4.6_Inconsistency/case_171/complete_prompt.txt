-∇ · ( a(x,y) ∇u(x,y) ) = 1

6) Numerical method requirements (to remove ambiguity)
- grid: Use a uniform Cartesian grid with N=128 intervals in each direction (N+1 points including boundaries).
  dx = dy = 1/N.
  Use x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
- discretization: 2nd-order finite differences with variable coefficient using face-centered harmonic averaging.

    -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j))

  where the face coefficients are harmonic means, e.g.
    a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j))
