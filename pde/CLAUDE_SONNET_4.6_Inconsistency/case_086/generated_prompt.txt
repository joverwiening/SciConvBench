Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically with the following specifications.

The PDE is u_tt = u_xx (the coefficient on the right is 1.0 squared, which equals 1.0).
The parameter c = 2 is used only for the CFL condition and wave speed in the exact solution.
The exact solution is u(x,t) = cos(2*pi*x) * cos(2*pi*1.0*t), confirming wave speed 1.0 in the PDE but c=2 in CFL.

Use Python with numpy for all computation.

Set up the spatial grid as follows.
Use Nx = 512 points on [0,1) with no duplicated endpoint.
Set dx = 1.0 / Nx.
Set x_i = i * dx for i = 0, 1, ..., Nx-1.

Set up the time grid as follows.
Set T = 1.0.
Set dt0 = 0.9 * dx / c where c = 2.
Set Nt = ceil(T / dt0).
Set dt = T / Nt so the final time step lands exactly on T.

Apply the 2nd-order central difference in space for u_xx with periodic wrap-around.
u_xx at point i = (u[i+1] - 2*u[i] + u[i-1]) / dx**2 using numpy roll or modular indexing for the periodic boundary.

Apply the initial conditions as follows.
Set u at t=0: u0[i] = cos(2*pi*x[i]).
Set u_t at t=0: v0[i] = 0.

Use the Taylor expansion start for the first time step.
u1[i] = u0[i] + dt * v0[i] + 0.5 * dt**2 * Laplacian(u0)[i]
where Laplacian(u0)[i] = (u0[i+1] - 2*u0[i] + u0[i-1]) / dx**2 with periodic wrap-around.

Advance all subsequent time steps using the 2nd-order central difference in time.
u_new[i] = 2*u_curr[i] - u_prev[i] + dt**2 * Laplacian(u_curr)[i]
Apply this for n = 1, 2, ..., Nt-1 to reach time T.

After reaching T, compute the following diagnostics and print them.
Print min(u) at T.
Print max(u) at T.
Print the discrete L2 norm: sqrt(sum(u**2) * dx).
Compute the reference solution: u_ref[i] = cos(2*pi*x[i]) * cos(2*pi*1.0*T).
Print the max absolute error: max(abs(u - u_ref)).
Print the L2 error: sqrt(sum((u - u_ref)**2) * dx).

Save the output file "solution_agent_wave_05.npz" containing the following arrays and scalars.
Include array x (1D, length 512).
Include array u (1D, length 512, the numerical solution at T).
Include scalar T = 1.0.

Include scalar dt as computed above.

Save a line plot of u(x, T) versus x as "solution_agent_wave_05.png".

Here is the complete Python code to execute:

import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import math

c = 2.0
T = 1.0
Nx = 512
dx = 1.0 / Nx
x = np.arange(Nx) * dx

dt0 = 0.9 * dx / c
Nt = math.ceil(T / dt0)
dt = T / Nt

u_prev = np.cos(2 * np.pi * x)
v0 = np.zeros(Nx)

def laplacian(u, dx):
    return (np.roll(u, -1) - 2*u + np.roll(u, 1)) / dx**2

lap_u0 = laplacian(u_prev, dx)
u_curr = u_prev + dt * v0 + 0.5 * dt**2 * lap_u0

for n in range(1, Nt):
    lap_curr = laplacian(u_curr, dx)
    u_next = 2*u_curr - u_prev + dt**2 * lap_curr
    u_prev = u_curr
    u_curr = u_next

u = u_curr

u_ref = np.cos(2 * np.pi * x) * np.cos(2 * np.pi * 1.0 * T)

print("min(u) =", np.min(u))
print("max(u) =", np.max(u))
print("L2 norm =", np.sqrt(np.sum(u**2) * dx))
print("Max absolute error =", np.max(np.abs(u - u_ref)))
print("L2 error =", np.sqrt(np.sum((u - u_ref)**2) * dx))

np.savez("solution_agent_wave_05.npz", x=x, u=u, T=T, dx=dx, dt=dt)

plt.figure()
plt.plot(x, u)
plt.xlabel("x")
plt.ylabel("u(x,T)")
plt.title("Wave equation solution at T=1.0")
plt.savefig("solution_agent_wave_05.png")
plt.close()
