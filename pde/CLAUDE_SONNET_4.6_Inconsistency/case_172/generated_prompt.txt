Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.

Use Python with numpy and matplotlib.

Set nu = 0.5 and rho = 1.0.

Set the spatial domain to [0, 1) with periodic boundary conditions.

Set the time domain to [0, 1.0].

Use Nx = 512 grid points on [0, 1) with dx = 1/Nx and x_j = j * dx for j = 0, ..., Nx-1.

Use fixed dt = 0.001 with Nt = 1000 time steps so that T = 1.0 is reached exactly.

Set the initial condition as u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).

Apply Strang splitting for each full time step dt as follows.

Step A is a diffusion half-step of duration dt/2 solved exactly in Fourier space: compute u_hat = FFT(u), compute the wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).

Step B is a reaction full step of duration dt solved exactly pointwise using the logistic ODE exact solution: update each grid point as u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).

Step C is another diffusion half-step identical to Step A.

Apply steps A, B, C in that order for each of the Nt = 1000 time steps.

After all time steps, compute u(x, T=1.0) on the periodic grid.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.

Save a file named "solution_pdebench_reacdiff_nu0p5_rho1.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), nu (scalar), rho (scalar), T (scalar), dx (scalar), dt (scalar), Nx (scalar), Nt (scalar).

Save a line plot of u(x, T) as a PNG file named "solution_pdebench_reacdiff_nu0p5_rho1.png" with x on the horizontal axis and u on the vertical axis.

Use numpy.fft.fft, numpy.fft.ifft, and numpy.fft.fftfreq for all Fourier operations.

Take the real part after each IFFT to eliminate numerical imaginary artifacts.

Do not use any adaptive time-stepping; use only the fixed dt = 0.001 throughout.
