Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.
The unknown field is u(x, t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0], but evaluate and save the solution at T = 2.1.
The parameter beta = 2.0.
The initial condition is u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution is u(x, t) = u0((x - beta*t) mod 1), where u0 is the initial condition function.
Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.
Use 1st-order upwind finite difference for u_x, with the upwind direction determined by the sign of beta.
Since beta = 2.0 > 0, the upwind scheme gives u_x at point j as (u[j] - u[j-1]) / dx, using periodic indexing (j-1 wraps around to Nx-1 when j = 0).
Use explicit forward Euler time integration.
Set CFL = 0.5 and compute dt = CFL * dx / abs(beta).
Compute Nt = ceil(T / dt) where T = 2.1, then reset dt = T / Nt so the final time T = 2.1 is hit exactly.
At each time step, update u using: u_new[j] = u[j] - (dt/dx) * beta * (u[j] - u[j-1]) with periodic indexing.
After Nt steps, the solution array u holds u(x, T=2.1).
Compute the reference solution u_ref[j] = u0((x_j - beta*T) mod 1) on the same grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 2.1.
Print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx).
Save a file named "solution_pdebench_advection_beta2.npz" containing the following arrays and scalars: x (1D, length Nx), u (1D, length Nx), beta (scalar), T (scalar, value 2.1), dx (scalar), dt (scalar), Nx (scalar, 512), Nt (scalar).
Save a line plot of u(x, T=2.1) as "solution_pdebench_advection_beta2.png" with x on the horizontal axis and u on the vertical axis.
Use numpy for array operations and matplotlib for plotting.
Interpret '^' as exponentiation and use '**' in Python code for powers.
Use radians for all trigonometric functions.

Here is the complete Python code:

```python
import numpy as np
import matplotlib.pyplot as plt

# ── parameters ────────────────────────────────────────────────────────────────
beta = 2.0
T    = 2.1
Nx   = 512
CFL  = 0.5

# ── grid ──────────────────────────────────────────────────────────────────────
dx   = 1.0 / Nx
x    = np.arange(Nx) * dx          # x_j = j*dx, j = 0 … Nx-1

# ── time step (CFL-based, then adjusted to hit T exactly) ─────────────────────
dt_cfl = CFL * dx / abs(beta)
Nt     = int(np.ceil(T / dt_cfl))
dt     = T / Nt                     # reset so Nt*dt == T exactly

# ── initial condition ─────────────────────────────────────────────────────────
def u0(xi):
    return np.sin(2 * np.pi * xi) + 0.5 * np.sin(4 * np.pi * xi)

u = u0(x).copy()

# ── time integration: forward Euler + 1st-order upwind (beta > 0) ─────────────
# upwind for beta > 0:  du/dx ≈ (u[j] - u[j-1]) / dx
r = beta * dt / dx                  # Courant number (≤ CFL = 0.5)

for _ in range(Nt):
    u_left = np.roll(u, 1)          # u[j-1] with periodic wrap
    u = u - r * (u - u_left)

# ── reference solution ────────────────────────────────────────────────────────
x_shifted = (x - beta * T) % 1.0
u_ref     = u0(x_shifted)

# ── diagnostics ───────────────────────────────────────────────────────────────
l2_norm      = np.sqrt(np.sum(u**2) * dx)
max_abs_err  = np.max(np.abs(u - u_ref))
l2_err       = np.sqrt(np.sum((u - u_ref)**2) * dx)

print(f"min(u)          = {u.min():.6e}")
print(f"max(u)          = {u.max():.6e}")
print(f"L2 norm of u    = {l2_norm:.6e}")
print(f"Max abs error   = {max_abs_err:.6e}")
print(f"L2 error        = {l2_err:.6e}")

# ── save .npz ─────────────────────────────────────────────────────────────────
np.savez(
    "solution_pdebench_advection_beta2.npz",
    x=x, u=u,
    beta=beta, T=T, dx=dx, dt=dt, Nx=Nx, Nt=Nt
)

# ── save plot ─────────────────────────────────────────────────────────────────
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u,     lw=1.5, label=f"Numerical  T={T}")
ax.plot(x, u_ref, lw=1.0, ls="--", label="Reference")
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"1D Advection (beta={beta}) at T={T}")
ax.legend()
fig.tight_layout()
fig.savefig("solution_pdebench_advection_beta2.png", dpi=150)
plt.close(fig)

print("Files saved: solution_pdebench_advection_beta2.npz / .png")
```

Key implementation details:
The upwind difference for beta > 0 uses u[j] - u[j-1] divided by dx, implemented via np.roll(u, 1) for the periodic left-neighbour.
The Courant number r = beta * dt / dx equals CFL = 0.5 before the dt reset and remains close to 0.5 after, ensuring stability.
The reference solution shifts x by -beta*T and wraps with modulo 1 before evaluating u0, exactly matching the analytic translation.
All requested arrays and scalars are stored in the npz file, and all five scalar diagnostics are printed.
