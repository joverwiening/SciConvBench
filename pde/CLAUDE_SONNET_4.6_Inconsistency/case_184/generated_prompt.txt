Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the exact specifications below.

Parameters are nu = 2.0 and rho = 1.0.
Use a uniform periodic spatial grid with Nx = 512 points on [0, 1), with x_j = j * dx for j = 0, ..., 511 and dx = 1/512.

Apply the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x) at all grid points.

Use Strang splitting for each full time step dt as follows.
Step A is a diffusion half-step of duration dt/2 solved exactly in Fourier space: compute u_hat = FFT(u), compute the wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).
Step B is a reaction full-step of duration dt solved exactly pointwise using the logistic ODE exact solution: update each grid point as u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Step C is another diffusion half-step identical to Step A.
Perform the sequence A, B, C for each of the 1000 time steps.

After completing all time steps, compute u(x, T=1.0) on the periodic grid.
