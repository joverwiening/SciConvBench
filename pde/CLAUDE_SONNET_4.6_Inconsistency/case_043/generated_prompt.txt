Solve the heat equation u_t = 0.1 * u_xx + 1 numerically using the following specifications.

Domain: x in [0, 1], t in [0, 0.5].
Parameter: alpha = 0.1.
Boundary conditions: Dirichlet, u(0, t) = 0 and u(1, t) = 0 for all t.
Initial condition: u(x, 0) = 0.

Spatial grid: Use Nx = 200 uniform intervals on [0, 1], giving Nx + 1 = 201 grid points including both endpoints. Set dx = 1.0 / 200. Set x_i = i * dx for i = 0, 1, ..., 200.

Time grid: Use dt = 0.001 and run for 600 steps, reaching T = 0.5.

Spatial discretization: Approximate u_xx at interior node i using the second-order central difference (u[i-1] - 2*u[i] + u[i+1]) / dx**2.

Time integration: Use the Crank-Nicolson scheme. At each time step, average the diffusion operator and the source term between the current and next time level. Since the source term is constant (value 1), its CN average is also 1.

At each time step, assemble and solve the tridiagonal linear system for the interior nodes (indices 1 through 199). Fix boundary nodes u[0] = 0 and u[200] = 0 at every time step by not including them in the solve and applying them as known values when forming the right-hand side.

The CN system for interior nodes is: (I + 0.5 * dt * alpha * L) * u_new = (I - 0.5 * dt * alpha * L) * u_old + dt * 1, where L is the tridiagonal second-difference matrix divided by dx**2, applied only to interior nodes.

After completing all 600 time steps, extract the solution u(x, T=0.5) as a 1D array of length 201.

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 0.5.

Save a file named "solution_agent_heat_14.npz" containing: array x of shape (201,), array u of shape (201,), scalar T = 0.5, scalar dx = 0.005, scalar dt = 0.001.

Save a line plot of u versus x at T = 0.5 as "solution_agent_heat_14.png" with x on the horizontal axis and u on the vertical axis.

Use Python with numpy and scipy (for the tridiagonal solve or sparse linear algebra) and matplotlib for the plot.

Here is the complete Python code to execute this task:

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import solve_banded

# --- Parameters ---
alpha = 0.1
Nx = 200
dx = 1.0 / Nx
x = np.linspace(0.0, 1.0, Nx + 1)  # 201 points

dt = 0.001
Nt = 600
T = dt * Nt  # = 0.5

# --- Interior indices: 1 .. Nx-1 (199 points) ---
N_int = Nx - 1  # 199

# --- Build CN tridiagonal system for interior nodes ---
# (I + 0.5*dt*alpha*L) u_new = (I - 0.5*dt*alpha*L) u_old + dt*source
# L_ii = -2/dx^2, L_{i,i+-1} = 1/dx^2

r = alpha * dt / (2.0 * dx**2)  # CN coefficient

# Left-hand side tridiagonal (for banded solver)
# ab[0] = superdiagonal, ab[1] = main diagonal, ab[2] = subdiagonal
ab = np.zeros((3, N_int))
ab[0, 1:] = -r          # superdiagonal (upper)
ab[1, :]  = 1.0 + 2*r   # main diagonal
ab[2, :-1] = -r          # subdiagonal (lower)

# Right-hand side matrix coefficients (explicit side)
# rhs = (1 - 2r)*u_old[i] + r*(u_old[i-1] + u_old[i+1]) + dt*1
# Boundary contributions are zero since u[0]=u[Nx]=0 always.

# --- Initial condition ---
u = np.zeros(Nx + 1)  # u(x, 0) = 0

# --- Time integration ---
source = dt * 1.0  # constant source term, CN average = 1

for n in range(Nt):
    u_int = u[1:Nx]  # interior values, length N_int

    # Explicit (right-hand side) diffusion part
    rhs = (1.0 - 2*r) * u_int + r * (u[0:Nx-1] + u[2:Nx+1]) + source
    # Note: u[0] and u[Nx] are always 0, so boundary contributions vanish.

    # Solve tridiagonal system
    u_new_int = solve_banded((1, 1), ab, rhs)

    # Update solution
    u[1:Nx] = u_new_int
    # Boundaries remain 0
    u[0] = 0.0
    u[Nx] = 0.0

# --- Diagnostics ---
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# --- Save NPZ ---
np.savez("solution_agent_heat_14.npz",
         x=x,
         u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))

# --- Save Plot ---
plt.figure(figsize=(8, 5))
plt.plot(x, u, color='steelblue', linewidth=1.5)
plt.xlabel("x")
plt.ylabel("u(x, T)")
plt.title(f"Heat Equation Solution at T = {T}")
plt.tight_layout()
plt.savefig("solution_agent_heat_14.png", dpi=150)
plt.close()

print("Files saved: solution_agent_heat_14.npz, solution_agent_heat_14.png")
```
