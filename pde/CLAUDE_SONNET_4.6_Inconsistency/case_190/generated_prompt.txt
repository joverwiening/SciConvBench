Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Treat all mathematical functions exactly as written and use radians for trigonometric functions.
In Python code, use ** for exponentiation wherever ^ appears in the math.

Domain: x in [0, 1) with periodic boundary condition, t in [0, 1.0].
Parameters: nu = 5.0, rho = 2.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Spatial grid: Use Nx = 512 uniform points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.

Time grid: Use fixed dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Numerical method: Strang splitting applied at each full time step dt.

Step A (diffusion half-step, duration dt/2): Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Step B (reaction full-step, duration dt): Apply the exact pointwise logistic ODE solution.
For each grid point update u as: u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).

Step C (diffusion half-step again): Repeat Step A identically with duration dt/2.

Repeat Steps A, B, C for all Nt = 1000 time steps.

Output: Compute u(x, T=1.0) on the periodic grid after all time steps.

Save a file named "solution_pdebench_reacdiff_nu5_rho2.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), and scalar values nu, rho, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu5_rho2.png".

Print the following scalar diagnostics at T: min(u), max(u), mean(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx).
