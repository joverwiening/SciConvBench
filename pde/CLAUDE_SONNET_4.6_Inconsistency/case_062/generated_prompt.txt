Solve the Laplace PDE numerically with the following specifications.

PDE: u_xx + u_yy = 0 on the domain (x,y) in [0,1] x [0,1].

Use Dirichlet boundary conditions on all four edges of the square: set u(x,y) = x**2 - y**2 on the boundary.

The exact reference solution is u(x,y) = x**2 - y**2.

Use a uniform grid with Nx=Ny=100 intervals in each direction, giving Nx+1=101 grid points in each direction including both endpoints.
Set dx = dy = 1/100.
Set x_i = i*dx for i=0..100 and y_j = j*dy for j=0..100.

Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on interior nodes only.

Assemble the resulting sparse linear system for the interior nodes.

Apply the Dirichlet boundary values by evaluating x**2 - y**2 at all boundary grid points and incorporating them into the right-hand side of the linear system.

Solve the sparse linear system using scipy.sparse.linalg.spsolve.

Construct the full 2D solution array u with shape (101, 101) where u[j,i] = u(x_i, y_j), filling interior values from the solver and boundary values from x**2 - y**2.

Save a file named "solution_agent_laplace_06.npz" containing: x as a 1D array of length 101, y as a 1D array of length 101, u as a 2D array of shape (len(y), len(x)) so that u[j,i] = u(x_i, y_j), and scalar metadata dx and dy.

Save a heatmap or contour plot of u(x,y) as "solution_agent_laplace_06.png".

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy) over all grid points.

Compute the reference solution u_ref[j,i] = x_i**2 - y_j**2 on the same grid.

Print the max absolute error max(|u - u_ref|) and the L2 error sqrt(sum((u - u_ref)**2)*dx*dy) over all grid points.
