Solve the Poisson PDE numerically with the following specifications.

Task ID is agent_poisson_08.

The PDE is u_xx + u_yy = f(x,y), where f(x,y) = sin(pi*x) + cos(2*pi*y).

The spatial domain is (x,y) in [0,1] x [0,1].

The boundary condition is Dirichlet: u = 0 on all four boundary edges (x=0, x=1, y=0, y=1).

Use a uniform grid with Nx = Ny = 120 intervals in each direction, giving Nx+1 = 121 grid points in each direction including both endpoints.
Set dx = dy = 1/120.
Define x_i = i*dx for i = 0..120 and y_j = j*dy for j = 0..120.

Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on the interior nodes only.
Apply the Dirichlet boundary condition by fixing u = 0 at all boundary grid points and excluding them from the linear system.

Assemble the resulting sparse linear system for the interior nodes.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.

Construct the full 2D solution array u of shape (121, 121) with u[j,i] = u(x_i, y_j), setting boundary entries to 0 and filling interior entries from the solver result.

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy).

Save "solution_agent_poisson_08.npz" containing: x as a 1D array of length 121, y as a 1D array of length 121, u as a 2D array of shape (len(y), len(x)) so that u[j,i] = u(x_i, y_j), and scalar metadata dx and dy.
