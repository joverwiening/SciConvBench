Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.
Use beta = 1.0, spatial domain x in [0, 1) with periodic boundary, and time domain t in [0, 2.0].
Use Nx = 512 grid points with dx = 1/512 and x_j = j * dx for j = 0, ..., 511.
Set CFL = 0.5, dt = CFL * dx / abs(beta), Nt = ceil(T / dt), then reset dt = T / Nt so the final time T = 2.0 is hit exactly.
Apply the initial condition u(x, 0) = sin(2 * pi * x) + 0.5 * sin(4 * pi * x).
Use 1st-order upwind finite difference for u_x. Since beta = 1.0 > 0, use the left-sided (backward) difference: u_x at j approximated as (u[j] - u[j-1]) / dx, with periodic indexing so u[-1] = u[Nx-1].
Advance in time using explicit forward Euler: u_new[j] = u[j] - beta * dt / dx * (u[j] - u[j-1]).
After Nt steps, the numerical solution u(x, T) is stored on the grid.
Compute the reference solution u_ref[j] = sin(2 * pi * ((x[j] - beta * T) % 1)) + 0.5 * sin(4 * pi * ((x[j] - beta * T) % 1)).
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u ** 2) * dx).
Print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref) ** 2) * dx).
Save a file named "solution_pdebench_advection_beta1.npz" containing arrays x (length 512), u (length 512), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x, T) as "solution_pdebench_advection_beta1.png" with x on the horizontal axis and u on the vertical axis.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
beta = 1.0
T = 2.0
Nx = 512
CFL = 0.5

# Grid
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_j = j * dx, j = 0, ..., Nx-1

# Time stepping
dt_raw = CFL * dx / abs(beta)
Nt = int(np.ceil(T / dt_raw))
dt = T / Nt  # reset so final time is exactly T

print(f"Nx={Nx}, dx={dx:.6e}, dt={dt:.6e}, Nt={Nt}, T_final={Nt*dt:.6f}")

# Initial condition
def u0(xi):
    return np.sin(2 * np.pi * xi) + 0.5 * np.sin(4 * np.pi * xi)

u = u0(x).copy()

# CFL ratio
r = beta * dt / dx  # = CFL * sign(beta), here = 0.5

# Time integration: explicit forward Euler + 1st-order upwind (beta > 0 => backward diff)
for n in range(Nt):
    # u_x[j] ~ (u[j] - u[j-1]) / dx  (periodic: index -1 wraps to Nx-1)
    u_left = np.roll(u, 1)  # u_left[j] = u[j-1]
    u = u - r * (u - u_left)

# Reference solution
x_shifted = (x - beta * T) % 1.0
u_ref = u0(x_shifted)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u ** 2) * dx)
max_err = np.max(np.abs(u - u_ref))
l2_err = np.sqrt(np.sum((u - u_ref) ** 2) * dx)

print(f"min(u)       = {u_min:.6e}")
print(f"max(u)       = {u_max:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_err:.6e}")
print(f"L2 error     = {l2_err:.6e}")

# Save npz
np.savez(
    "solution_pdebench_advection_beta1.npz",
    x=x,
    u=u,
    beta=beta,
    T=T,
    dx=dx,
    dt=dt,
    Nx=Nx,
    Nt=Nt
)
print("Saved solution_pdebench_advection_beta1.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x, T={T})", linewidth=1.2)
ax.plot(x, u_ref, '--', label="Reference solution", linewidth=1.0, alpha=0.7)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"1D Advection (beta={beta}) at T={T}, Nx={Nx}, CFL={CFL}")
ax.legend()
ax.grid(True, linestyle=':', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_pdebench_advection_beta1.png", dpi=150)
plt.close()
print("Saved solution_pdebench_advection_beta1.png")
```

Key implementation notes:
The upwind direction is left-sided because beta = 1.0 > 0, so u_x at j uses u[j] and u[j-1].
np.roll(u, 1) shifts the array right by one position, giving u[j-1] at index j with automatic periodic wrap-around at j = 0.
dt is recomputed as T / Nt after ceiling so the solver lands exactly at T = 2.0.
The reference solution evaluates u0 at the shifted and wrapped argument (x - beta * T) mod 1 to account for periodic advection.
All requested arrays and scalars are stored in the npz file and all diagnostics are printed to stdout.
