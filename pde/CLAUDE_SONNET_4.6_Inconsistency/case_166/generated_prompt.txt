Solve the 1D Compressible Navier-Stokes PDE (no heat conduction) numerically in Python and save the results.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Define m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.

The PDE in conservative form is:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use Gamma = 1.6666666666666667.
Use eta = 1e-08 and zeta = 1e-08.

Apply transmissive (outflow, zero-gradient) boundary conditions at both x=-1 and x=1.

Set the initial condition as a Riemann (shock-tube) problem with discontinuity at x=0.
For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 10.0.
For x >= 0: rho_R = 1.0, v_R = 0.0, p_R = 0.1.

Use a uniform finite-volume grid with Nx=800 cells on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,799, with dx = 2/800.

Evolve the conservative variables U = [rho, m, E] as cell averages.

Use the equation of state p = (Gamma-1)*(E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
Define F_conv(U) = [m, m**2/rho + p, (E+p)*v] where v = m/rho.
Compute the interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Compute the numerical convective flux as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

For the viscous terms, compute v_x using centered differences on cell-centered v values.
Compute sigma = (zeta + 4/3*eta)*v_x at cell centers.
Approximate sigma at each interface by averaging the two neighboring cell-centered sigma values.
Define the viscous flux as F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.
Compute the total interface flux as F_total = F_hat + F_visc.

For boundary conditions, implement outflow by setting ghost cell values equal to the nearest interior cell (zero-gradient).

Use 2-stage SSP-RK2 (Heun's method) for time integration.

At each time step, compute:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
dt = min(dt_conv, dt_visc)
Use CFL = 0.5.
Adjust the last time step so the simulation ends exactly at T = 0.2.

At the final time T, compute rho(x,T), v(x,T), p(x,T) on the cell centers.
