Solve the 1D wave equation u_tt = (0.5)**2 * u_xx numerically using the specifications below.

PDE is u_tt = (0.5)**2 * u_xx, where the wave speed in the PDE is 0.5 (the coefficient in front of u_xx is 0.25).
The parameter c listed is 1, but the CFL condition and leapfrog scheme use the actual wave speed from the PDE, which is 0.5. Use 0.5 as the wave speed for CFL and time stepping.
The exact solution is u(x,t) = cos(0.5 * 2 * pi * t) * sin(2 * pi * x), confirming the wave speed is 0.5.

Set dt = 1.0 / Nt so the final time T = 1.0 is hit exactly.

Apply 2nd-order central differences for u_xx at interior points only.
Apply Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 at every time step.

Set initial velocity u_t(x, 0) = 0 at all grid points.
Compute the first time step using the Taylor start: u1 = u0 + dt * v0 + 0.5 * dt**2 * (0.5**2 * u_xx0), where u_xx0 is the central difference approximation of u_xx at t=0.
Enforce boundary conditions on u1: set u1[0] = 0 and u1[-1] = 0.

Advance from t = dt to t = T using the leapfrog scheme: u_new = 2 * u_current - u_old + dt**2 * (0.5**2 * u_xx_current) at interior points.
