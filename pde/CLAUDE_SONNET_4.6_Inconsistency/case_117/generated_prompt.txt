Solve the PDE u_tt + (q**2)*u_xxxx + c*d_x(u*u_x) = 0 numerically using the specifications below.

Use Python with numpy and matplotlib.

Interpret '^' as exponentiation and use '**' for powers in Python code.

The PDE is u_tt + (q**2)*u_xxxx + c*d_x(u*u_x) = 0, where u = u(x,t), second order in time.

The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 0.5].

Set parameter q = 0.05 and c = 1.0.

Use a uniform periodic spatial grid with Nx = 512 points on [0,1).
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.

Apply periodic boundary conditions: u and all x-derivatives are periodic on [0,1).

Set initial condition u(x,0) = 0.1*cos(2*pi*x).
Set initial condition u_t(x,0) = 0.

Convert the PDE to a first-order system by introducing v = u_t.
The system is: u_t = v, v_t = -(q**2)*u_xxxx - c*d_x(u*u_x).

Compute all spatial derivatives (u_x and u_xxxx) using Fourier spectral methods.
Compute u_x via the Fourier spectral derivative: take FFT of u, multiply by (i*k), take IFFT, take real part.
Compute u_xxxx via the Fourier spectral derivative: take FFT of u, multiply by (i*k)**4, take IFFT, take real part.
Compute the nonlinear term d_x(u*u_x) spectrally: compute u_x spectrally, form the product u*u_x in physical space, then take the spectral derivative of that product.
Use the standard Fourier wavenumbers k_j = 2*pi*j for j = 0,...,Nx/2-1 and k_j = 2*pi*(j-Nx) for j = Nx/2,...,Nx-1.

Integrate in time using the classical 4th-order Runge-Kutta (RK4) method applied to the state vector (u, v).
Use time step dt = 0.0001 and Nt = 5000 steps so that the final time T = 0.5 is reached exactly.

At T = 0.5, compute u(x, T) on the periodic grid.

Print the following scalar diagnostics at T:
  min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx).

Save the file "solution_molk_016.npz" containing:
  x: 1D array of length Nx (the spatial grid),
  u: 1D array of length Nx (the solution at T),
  T: scalar equal to 0.5,
  dx: scalar equal to 1/Nx,
  Nx: scalar equal to 512,
  q: scalar equal to 0.05,
  c: scalar equal to 1.0.

Save a line plot of u(x, T) versus x as "solution_molk_016.png".
Label the x-axis as "x", the y-axis as "u(x,T)", and title the plot "Solution at T=0.5".

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
q = 0.05
c = 1.0
Nx = 512
dx = 1.0 / Nx
x = np.array([j * dx for j in range(Nx)])
dt = 0.0001
Nt = 5000
T = 0.5

# Fourier wavenumbers
k = np.zeros(Nx)
for j in range(Nx):
    if j < Nx // 2:
        k[j] = 2 * np.pi * j
    else:
        k[j] = 2 * np.pi * (j - Nx)

# Precompute spectral multipliers
ik = 1j * k
ik4 = (1j * k) ** 4

def spectral_derivative(u_phys, multiplier):
    u_hat = np.fft.fft(u_phys)
    return np.real(np.fft.ifft(multiplier * u_hat))

def rhs(u, v):
    # u_xxxx
    u_xxxx = spectral_derivative(u, ik4)
    # u_x
    u_x = spectral_derivative(u, ik)
    # d_x(u * u_x)
    nonlinear = spectral_derivative(u * u_x, ik)
    du_dt = v
    dv_dt = -(q ** 2) * u_xxxx - c * nonlinear
    return du_dt, dv_dt

# Initial conditions
u = 0.1 * np.cos(2 * np.pi * x)
v = np.zeros(Nx)

# RK4 time integration
for n in range(Nt):
    k1u, k1v = rhs(u, v)
    k2u, k2v = rhs(u + 0.5 * dt * k1u, v + 0.5 * dt * k1v)
    k3u, k3v = rhs(u + 0.5 * dt * k2u, v + 0.5 * dt * k2v)
    k4u, k4v = rhs(u + dt * k3u, v + dt * k3v)
    u = u + (dt / 6.0) * (k1u + 2 * k2u + 2 * k3u + k4u)
    v = v + (dt / 6.0) * (k1v + 2 * k2v + 2 * k3v + k4v)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
u_mean = np.mean(u)
u_l2 = np.sqrt(np.sum(u ** 2) * dx)

print(f"min(u)  = {u_min:.6e}")
print(f"max(u)  = {u_max:.6e}")
print(f"mean(u) = {u_mean:.6e}")
print(f"L2 norm = {u_l2:.6e}")

# Save npz
np.savez("solution_molk_016.npz",
         x=x,
         u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         Nx=np.int64(Nx),
         q=np.float64(q),
         c=np.float64(c))

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x,T)")
ax.set_title("Solution at T=0.5")
plt.tight_layout()
plt.savefig("solution_molk_016.png", dpi=150)
plt.close()
```
