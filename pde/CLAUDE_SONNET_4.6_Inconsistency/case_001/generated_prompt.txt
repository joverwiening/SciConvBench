Solve the 1D linear advection PDE numerically and save results.

The PDE is u_t + 1.0 * u_x = 0.
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0, 1.0]. Note: output is requested at T=1.1, so integrate to T=1.1.
The advection speed a = 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The exact solution is u(x,t) = sin(2*pi*(x - 1.0*t)).

Use Nx=800 uniform grid points on [0,1) with no duplicated endpoint.
Set dx = 1.0/Nx.
Set x_i = i*dx for i = 0, 1, ..., Nx-1.
Set dt0 = 0.9 * dx / abs(a).
Set Nt = ceil(1.1 / dt0).
Set dt = 1.1 / Nt so the final time T=1.1 is hit exactly.

Use 1st-order upwind spatial discretization: since a=1.0 > 0, approximate u_x at point i as (u[i] - u[i-1]) / dx using periodic wrap-around (u[-1] = u[Nx-1]).
Use Forward Euler time integration: u_new[i] = u[i] - a * dt/dx * (u[i] - u[i-1]).
Apply periodic indexing at every time step.

After Nt steps, the solution array u has length Nx and corresponds to time T=1.1.

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Compute the reference solution u_exact[i] = sin(2*pi*(x[i] - 1.0*1.1)) on the same grid.
Compute and print max absolute error = max(abs(u - u_exact)) and L2 error = sqrt(sum((u - u_exact)**2) * dx).

Save a file named "solution_agent_advection_01.npz" containing: array x (shape Nx,), array u (shape Nx,), scalar T=1.1, scalar dx, scalar dt.
Save a line plot of u vs x at T=1.1 as "solution_agent_advection_01.png" with x on the horizontal axis and u on the vertical axis.

Use Python with numpy and matplotlib.
Use ** for exponentiation in code.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
a = 1.0
T = 1.1
Nx = 800

# Grid
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_i = i*dx, i=0..Nx-1

# Time stepping
dt0 = 0.9 * dx / abs(a)
Nt = math.ceil(T / dt0)
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL={abs(a)*dt/dx:.6f}")

# Initial condition
u = np.sin(2 * np.pi * x)

# Time integration: Forward Euler + 1st-order upwind (a>0 => backward difference)
cfl = a * dt / dx
for n in range(Nt):
    # Upwind: u_x approx (u[i] - u[i-1])/dx, periodic wrap via np.roll
    u_left = np.roll(u, 1)  # u_left[i] = u[i-1], with u_left[0] = u[Nx-1]
    u = u - cfl * (u - u_left)

# Exact solution at T=1.1
u_exact = np.sin(2 * np.pi * (x - a * T))

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
max_err = np.max(np.abs(u - u_exact))
l2_err = np.sqrt(np.sum((u - u_exact)**2) * dx)

print(f"min(u)       = {u_min:.6e}")
print(f"max(u)       = {u_max:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_err:.6e}")
print(f"L2 error     = {l2_err:.6e}")

# Save npz
np.savez("solution_agent_advection_01.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_advection_01.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x, T={T})")
ax.plot(x, u_exact, '--', label="Exact solution", alpha=0.7)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"1D Advection: u(x, T={T}), Nx={Nx}, 1st-order Upwind + Forward Euler")
ax.legend()
plt.tight_layout()
plt.savefig("solution_agent_advection_01.png", dpi=150)
plt.close()
print("Saved solution_agent_advection_01.png")
```
