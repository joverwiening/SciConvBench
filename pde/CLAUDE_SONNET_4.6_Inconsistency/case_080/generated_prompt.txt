Solve the Poisson PDE numerically with the following specifications.

The PDE is u_xx + u_yy = f(x,y) where f(x,y) = 100*exp(-200*((x-0.5)**2 + (y-0.5)**2)).
The spatial domain is (x,y) in [0,1] x [0,1].
Apply Dirichlet boundary conditions u=0 on all four edges (x=0, x=1, y=0, y=1). Ignore any periodic condition.
Use a uniform grid with Nx=Ny=120 intervals in each direction, giving Nx+1=121 grid points per direction including both endpoints.
Set dx=dy=1/120. Set x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.
Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on interior nodes only.
Assemble the resulting sparse linear system for the interior nodes (indices i=1..119, j=1..119).
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Set boundary values to zero in the full solution array.
Store the solution as a 2D array u with shape (121, 121) where u[j,i] = u(x_i, y_j).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy).
