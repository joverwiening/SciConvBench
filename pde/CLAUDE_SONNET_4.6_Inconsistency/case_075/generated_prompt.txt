Solve the Poisson PDE numerically with the following specifications.

Task ID is agent_poisson_02.
The unknown field is u(x,y).

PDE: u_xx + u_yy = f(x,y), where f(x,y) = -5*pi**2*sin(2*pi*x)*sin(pi*y).

Domain: (x,y) in [0,1] x [0,1].

Boundary conditions: Dirichlet on all four edges, u=0 on the entire boundary.

Exact solution for verification: u(x,y) = sin(2*pi*x)*sin(pi*y).

Use a uniform grid with Nx=Ny=120 intervals in each direction, giving Nx+1=121 grid points per direction including both endpoints.

Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on the interior nodes only.

Assemble the resulting sparse linear system for the interior nodes.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
After solving, fill the full (121x121) grid with the interior solution and set boundary values to zero.
