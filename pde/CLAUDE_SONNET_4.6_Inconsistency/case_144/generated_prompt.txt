Solve the 1D viscous Burgers equation u_t + d/dx(0.5*u^2) = nu*u_xx numerically with the following specifications.

The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 1.0], so the final time is T=1.0.
The parameter nu = 0.02.

Use a uniform periodic spatial grid with Nx=512 points on [0,1).
Set dx = 1/Nx and x_j = j*dx for j=0,...,Nx-1.

The initial condition is u(x,0) = sin(2*pi*x).

Set CFL=0.4 and estimate max speed as 1.0.
Compute dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time T=1.0 is hit exactly.

Advance the solution using Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), then set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): apply a finite-volume update using the Rusanov (local Lax-Friedrichs) flux for the inviscid Burgers equation u_t + d/dx(0.5*u^2)=0.
Define f(u) = 0.5*u**2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, compute F_plus as the flux at the right interface (between u[j] and u[j+1]) and F_minus as the flux at the left interface (between u[j-1] and u[j]).
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after this substep.

Step C (diffusion half-step again): repeat Step A identically.

After completing all Nt time steps, the solution u(x, T=1.0) is defined on the Nx-point periodic grid.

Save the file "solution_pdebench_burgers_nu0p02.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T=1.0) as "solution_pdebench_burgers_nu0p02.png".

Print the following diagnostics at T=1.0: min(u), max(u), the discrete mean value mean(u) (which should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx).
