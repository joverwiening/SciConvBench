Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Use Python with numpy and matplotlib.
Treat all mathematical functions exactly as written and use radians for trigonometric functions.
Use ** for exponentiation in Python code.

Domain: x in [0, 1) with periodic boundary condition, t in [0, 1.0].
Set nu = 2.0 and rho = 10.0.
Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0 / Nx and x_j = j * dx for j = 0, 1, ..., Nx-1.
Use fixed dt = 0.001 and Nt = 1000 time steps so that T = 1.0 is reached exactly.
Set the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x) evaluated at each grid point x_j.

At each of the Nt time steps, apply Strang splitting as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).
Step B (reaction full-step, duration dt): for each grid point update u pointwise using the exact logistic ODE solution u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Step C (diffusion half-step again, duration dt/2): repeat Step A identically.

After all Nt steps, compute the final solution u(x, T=1.0) on the periodic grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
