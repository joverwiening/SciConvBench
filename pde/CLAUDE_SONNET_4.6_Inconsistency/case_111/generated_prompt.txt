The parameters are A = 2 and B = 3.0.

The initial conditions are x(0.0) = 1.0 and y(0.0) = 1.0.

Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.01 and Nt = 2000 steps so the final time 20.0 is hit exactly.

k1 = f(t_n, Y_n)
k2 = f(t_n + dt/2, Y_n + dt/2 * k1)
k3 = f(t_n + dt/2, Y_n + dt/2 * k2)
k4 = f(t_n + dt, Y_n + dt * k3)
Y_{n+1} = Y_n + (dt/6) * (k1 + 2*k2 + 2*k3 + k4)

Store the t array as a 1D array of length 2001.
Store the Y array as a 2D array of shape [2001, 2] with columns ordered as [x, y].
