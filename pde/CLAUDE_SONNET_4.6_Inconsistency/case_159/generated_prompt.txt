Solve the 1D Compressible Navier-Stokes PDE (no heat conduction) numerically in Python and save the results.

Use Gamma = 5/3 = 1.6666666666666667. Discard the second Gamma line in the parameters; it was a typo.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Define m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.

Define viscous stress sigma = (zeta + 4/3*eta) * v_x, with zeta = eta = 1e-8.

The PDEs in conservative form are:
  rho_t + (m)_x = 0
  m_t + (m**2/rho + p - sigma)_x = 0
  E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use a uniform finite-volume grid with Nx = 800 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., Nx-1, where dx = 2/Nx.

Evolve the conservative variables U = [rho, m, E] as cell averages.

Apply the Riemann (shock-tube) initial condition with a discontinuity at x = 0.
For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 1.0.
For x >= 0: rho_R = 0.1, v_R = 0.0, p_R = 0.01.
Initialize E from these primitive variables using E = p/(Gamma-1) + 0.5*rho*v**2.

Apply transmissive (outflow, zero-gradient) boundary conditions at both x = -1 and x = 1.
Implement outflow BCs by setting ghost cell values equal to the nearest interior cell value.

Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

Compute the convective (inviscid Euler) flux at each interface using the Rusanov (local Lax-Friedrichs) scheme.
The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] where v = m/rho.
Compute the interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Reconstruct left and right states at each interface using piecewise-constant (first-order) reconstruction (i.e., U_L = U_{j}, U_R = U_{j+1}).

Compute v_x at each cell center using centered finite differences on the cell-centered v values.
Compute sigma = (zeta + 4/3*eta) * v_x at each cell center.
Approximate sigma at each interface by averaging the sigma values of the two neighboring cell centers.
Approximate v at each interface by averaging the v values of the two neighboring cell centers.
The viscous flux vector at each interface is F_visc = [0, -sigma_interface, -v_interface * sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration of the semi-discrete finite-volume system.

Choose the time step each stage as follows.
Compute dt_conv = CFL * dx / max_j(|v_j| + c_j).
Compute dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc).
Use CFL = 0.5.
Adjust the last time step so the simulation ends exactly at T = 0.2.
