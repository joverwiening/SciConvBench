Solve the heat equation u_t = 0.1 * u_xx + sin(2*pi*x) numerically using the following specifications.

Domain: x in [0,1], t in [0,0.5].
Use Nx=200 uniform intervals giving 201 grid points including both endpoints.
Set dx = 1/200 and x_i = i*dx for i=0,1,...,200.
Use dt=0.001 and take 500 time steps to reach T=0.5. (Note: 0.5/0.001 = 500 steps, not 600; use 500 steps to reach exactly T=0.5.)
Set alpha=0.1.

Apply zero-Neumann boundary conditions at x=0 and x=1 using ghost points.
Ghost point relation at left boundary: u_{-1} = u_{1}.
Ghost point relation at right boundary: u_{201} = u_{199}.

Discretize u_xx with 2nd-order central differences at all interior points and at the boundary points using the ghost-point values.
At i=0: u_xx ≈ (u_{-1} - 2*u_0 + u_1)/dx**2 = (2*u_1 - 2*u_0)/dx**2.
At i=Nx: u_xx ≈ (u_{Nx-1} - 2*u_{Nx} + u_{Nx+1})/dx**2 = (2*u_{Nx-1} - 2*u_{Nx})/dx**2.

Use Crank-Nicolson time integration for the diffusion term.
At each time step solve: (I - 0.5*dt*alpha*L) * u_new = (I + 0.5*dt*alpha*L) * u_old + dt*f(x), where L is the (Nx+1)x(Nx+1) tridiagonal Laplacian matrix incorporating the ghost-point Neumann conditions, and f(x) = sin(2*pi*x) is the source term (treated explicitly as a constant forcing evaluated at the grid points, added fully at each step as dt*f).
Set initial condition u(x,0) = 0 for all grid points.

After completing all time steps, compute u(x, T=0.5) on the 201-point grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx).
Save "solution_agent_heat_17.npz" containing: x (1D array of length 201), u (1D array of length 201), scalar T=0.5, scalar dx=1/200, scalar dt=0.001.
Save a line plot of u vs x at T=0.5 as "solution_agent_heat_17.png".

Use Python with numpy and scipy (or similar) for the tridiagonal solve.
Treat all trig functions in radians.
Use ** for exponentiation in code.

```python
import numpy as np
from scipy.linalg import solve_banded
import matplotlib.pyplot as plt

# Grid setup
Nx = 200
x = np.linspace(0, 1, Nx + 1)  # 201 points
dx = 1.0 / Nx
dt = 0.001
T = 0.5
Nt = int(round(T / dt))  # 500 steps
alpha = 0.1

# Source term
f = np.sin(2 * np.pi * x)

# Build tridiagonal Laplacian matrix L (Nx+1 x Nx+1)
# with ghost-point Neumann BCs:
# Row 0:   (2*u[1] - 2*u[0]) / dx**2  -> diag=-2, upper=2
# Row i (interior): (u[i-1] - 2*u[i] + u[i+1]) / dx**2
# Row Nx:  (2*u[Nx-1] - 2*u[Nx]) / dx**2 -> diag=-2, lower=2

N = Nx + 1
# We'll use scipy solve_banded with ab format (3 x N): rows = upper, main, lower
# r = alpha * dt / (2 * dx**2)
r = alpha * dt / (2.0 * dx**2)

# Construct banded matrix for (I - r*L) and explicit part (I + r*L)
# Main diagonal of L: -2/dx**2 everywhere
# Off-diagonals of L: 1/dx**2 for interior; boundary rows have 2/dx**2 on the one off-diagonal

# For solve_banded: ab[0] = superdiagonal, ab[1] = main diagonal, ab[2] = subdiagonal
# (I - r*L):
main_diag = np.full(N, 1.0 + 2.0 * r)
upper_diag = np.full(N, -r)   # length N, ab[0,1:] used
lower_diag = np.full(N, -r)   # length N, ab[2,:-1] used

# Boundary corrections for ghost points (factor of 2 on the single off-diagonal)
# Row 0: L[0,1] = 2/dx**2 instead of 1/dx**2 -> multiply off-diag by 2
upper_diag[1] = -2.0 * r   # ab[0, 1] corresponds to row 0, col 1
# Row Nx: L[Nx, Nx-1] = 2/dx**2 instead of 1/dx**2
lower_diag[Nx - 1] = -2.0 * r  # ab[2, Nx-1] corresponds to row Nx, col Nx-1

# Assemble banded matrix ab for (I - r*L)
ab = np.zeros((3, N))
ab[0, 1:] = upper_diag[1:]   # superdiagonal: ab[0, j] is for column j, row j-1
ab[1, :] = main_diag          # main diagonal
ab[2, :-1] = lower_diag[:-1]  # subdiagonal: ab[2, j] is for column j, row j+1

# For the RHS: (I + r*L) * u_old
# We apply this as a matrix-vector product
def apply_IplusrL(u, r):
    """Apply (I + r*L) to vector u with ghost-point Neumann BCs."""
    result = np.empty_like(u)
    # Interior points
    result[1:-1] = u[1:-1] + r * (u[:-2] - 2.0 * u[1:-1] + u[2:])
    # Boundary point i=0: ghost u[-1]=u[1]
    result[0] = u[0] + r * (2.0 * u[1] - 2.0 * u[0])
    # Boundary point i=Nx: ghost u[Nx+1]=u[Nx-1]
    result[-1] = u[-1] + r * (2.0 * u[-2] - 2.0 * u[-1])
    return result

# Time integration
u = np.zeros(N)

for n in range(Nt):
    rhs = apply_IplusrL(u, r) + dt * f
    u = solve_banded((1, 1), ab, rhs)

# Diagnostics
min_u = np.min(u)
max_u = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
print(f"min(u) = {min_u:.6e}")
print(f"max(u) = {max_u:.6e}")
print(f"L2 norm = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_heat_17.npz", x=x, u=u, T=T, dx=dx, dt=dt)

# Save plot
plt.figure(figsize=(8, 5))
plt.plot(x, u, 'b-', linewidth=1.5)
plt.xlabel("x")
plt.ylabel("u(x, T=0.5)")
plt.title("Heat Equation Solution at T=0.5 (agent_heat_17)")
plt.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_heat_17.png", dpi=150)
plt.close()
print("Files saved: solution_agent_heat_17.npz, solution_agent_heat_17.png")
```
