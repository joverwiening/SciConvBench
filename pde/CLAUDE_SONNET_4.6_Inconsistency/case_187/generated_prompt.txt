Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Treat all functions exactly as written and use radians for trigonometric functions.
In Python code, use ** for exponentiation wherever ^ appears in the math.

Domain: x in [0, 1) with periodic boundary, t in [0, 1.0].
Parameters: nu = 2.0, rho = 5.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Spatial grid: Use Nx = 512 uniform points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.
Time grid: Use fixed dt = 0.001 and Nt = 1000 steps so that T = 1.0 is reached exactly.

At each time step, apply Strang splitting in three sub-steps.

Sub-step A (diffusion half-step, duration dt/2):
Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Sub-step B (reaction full step, duration dt):
For each grid point, apply the exact logistic ODE solution.
Compute the update: u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).

Sub-step C (diffusion half-step again):
Repeat sub-step A identically with duration dt/2.

Repeat sub-steps A, B, C for all Nt = 1000 time steps.

After all steps, compute u(x, T=1.0) on the periodic grid.

Print the following scalar diagnostics at T:
min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx).

Save a file named "solution_pdebench_reacdiff_nu2_rho5.npz" containing:
Array x of length Nx, array u of length Nx, and scalars nu, rho, T, dx, dt, Nx, Nt.
