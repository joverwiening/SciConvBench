Solve the 1D linear advection PDE u_t + q*u_x = 0 numerically using the specifications below.

The PDE is u_t + q*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0] but the solution is evaluated at T = 1.1.
The parameter q = 1.5.
The periodic boundary condition is u(0, t) = u(1, t) for all t.
The initial condition is u(x, 0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The exact solution is u(x, t) = u0((x - q*t) mod 1) where u0 is the initial condition function.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1/Nx.
Set x_j = j*dx for j = 0, 1, ..., Nx-1.

Use 1st-order upwind finite difference for the spatial derivative u_x.
Since q = 1.5 > 0, the upwind scheme gives u_x at point j as (u_j - u_{j-1}) / dx, with index j-1 taken modulo Nx for periodicity.

Use Forward Euler for time integration.

Compute Nt = ceil(T / dt0) where T = 1.1.
