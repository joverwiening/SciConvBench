Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Treat all mathematical functions exactly as written and use radians for trigonometric functions.
In Python code, use ** for exponentiation wherever ^ appears in the math.

Set nu = 10.0 and rho = 1.0.
The spatial domain is [0, 1) with periodic boundary conditions, and the time domain is [0, 1.0].
Use a uniform periodic spatial grid with Nx = 512 points.
Set dx = 1.0 / Nx and place grid points at x_j = j * dx for j = 0, 1, ..., Nx-1.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Apply the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x) at all grid points.

Advance the solution using Strang splitting for each full time step dt as follows.

Step A is a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute u_hat = FFT(u).
Compute the wavenumbers k = 2 * pi * fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Step B is a reaction full-step of duration dt solved exactly pointwise for the logistic ODE du/dt = rho * u * (1 - u).
For each grid point apply the exact update: u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).

Step C is another diffusion half-step identical to Step A.

Repeat the sequence A, B, C for all Nt = 1000 time steps.

After completing all time steps, compute the following diagnostics at T = 1.0 and print them.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx).

Save a file named "solution_pdebench_reacdiff_nu10_rho1.npz" containing the following arrays and scalars.
Include x as a 1D array of length Nx.
Include u as a 1D array of length Nx holding the solution at T = 1.0.
Include the scalars nu, rho, T, dx, dt, Nx, and Nt.

Save a line plot of u(x, T) as a PNG file named "solution_pdebench_reacdiff_nu10_rho1.png".

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
nu   = 10.0
rho  = 1.0
T    = 1.0
Nx   = 512
dt   = 0.001
Nt   = 1000

# Spatial grid: periodic [0,1)
dx = 1.0 / Nx
x  = np.arange(Nx) * dx          # x_j = j*dx, j=0,...,Nx-1

# Wavenumbers for FFT
k = 2.0 * np.pi * np.fft.fftfreq(Nx, d=dx)

# Diffusion kernel for a half-step dt/2
diff_kernel_half = np.exp(-nu * k**2 * (dt / 2.0))

# Reaction exact-update factor
exp_rho_dt = np.exp(rho * dt)

# Initial condition
u = 0.25 + 0.1 * np.sin(2.0 * np.pi * x)

def diffusion_half_step(u):
    """Exact diffusion half-step in Fourier space."""
    u_hat = np.fft.fft(u)
    u_hat *= diff_kernel_half
    return np.fft.ifft(u_hat).real

def reaction_full_step(u):
    """Exact logistic reaction full-step."""
    return (u * exp_rho_dt) / (1.0 + u * (exp_rho_dt - 1.0))

# Time integration: Strang splitting  A -> B -> C
for _ in range(Nt):
    u = diffusion_half_step(u)   # (A) diffusion dt/2
    u = reaction_full_step(u)    # (B) reaction dt
    u = diffusion_half_step(u)   # (C) diffusion dt/2

# Diagnostics
u_min  = np.min(u)
u_max  = np.max(u)
u_mean = np.mean(u)
u_l2   = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.10f}")
print(f"max(u)  = {u_max:.10f}")
print(f"mean(u) = {u_mean:.10f}")
print(f"L2 norm = {u_l2:.10f}")

# Save .npz
np.savez(
    "solution_pdebench_reacdiff_nu10_rho1.npz",
    x=x, u=u,
    nu=nu, rho=rho, T=T,
    dx=dx, dt=dt, Nx=Nx, Nt=Nt
)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=1.0)")
ax.set_title("1D Reaction-Diffusion solution at T = 1.0  (nu=10, rho=1)")
ax.grid(True, linestyle="--", alpha=0.5)
fig.tight_layout()
fig.savefig("solution_pdebench_reacdiff_nu10_rho1.png", dpi=150)
plt.close(fig)

print("Files saved: solution_pdebench_reacdiff_nu10_rho1.npz / .png")
```
