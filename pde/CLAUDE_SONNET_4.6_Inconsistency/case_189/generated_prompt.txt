Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Treat all mathematical functions exactly as written and use radians for trigonometric functions.
In Python code, use ** for exponentiation wherever ^ appears in the math.

Domain: x in [0, 1) with periodic boundary condition, t in [0, 1.0].
Parameters: nu = 5.0, rho = 10.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Spatial grid: Use Nx = 512 uniform points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.

Time grid: Use fixed dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Numerical method: Strang splitting applied at each full time step dt.

Step A (diffusion half-step, duration dt/2): Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Step B (reaction full-step, duration dt): Apply the exact pointwise logistic ODE solution.
For each grid point update u as: u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).

Step C (diffusion half-step again): Repeat Step A identically with duration dt/2.

Repeat Steps A, B, C for all Nt = 1000 time steps.

Output: Compute u(x, T=1.0) on the periodic grid after all time steps.

Save a file named "solution_pdebench_reacdiff_nu5_rho10.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), and scalar values nu, rho, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu5_rho10.png".

Print the following scalar diagnostics at T: min(u), max(u), mean(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx).

Below is the complete Python implementation:

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
nu   = 5.0
rho  = 10.0
T    = 1.0
Nx   = 512
dt   = 0.001
Nt   = 1000

# Spatial grid: [0,1) periodic, no duplicated endpoint
dx = 1.0 / Nx
x  = np.arange(Nx) * dx          # x_j = j*dx, j=0,...,Nx-1

# Initial condition
u = 0.25 + 0.1 * np.sin(2 * np.pi * x)

# Wavenumbers for FFT
k = 2.0 * np.pi * np.fft.fftfreq(Nx, d=dx)

# Precompute diffusion damping factor for half-step dt/2
diff_factor_half = np.exp(-nu * k**2 * (dt / 2.0))

# Precompute reaction constants for full step dt
exp_rho_dt = np.exp(rho * dt)

def diffusion_half_step(u):
    """Apply diffusion half-step exactly in Fourier space."""
    u_hat = np.fft.fft(u)
    u_hat *= diff_factor_half
    return np.fft.ifft(u_hat).real

def reaction_full_step(u):
    """Apply exact logistic ODE solution for full step dt pointwise."""
    return (u * exp_rho_dt) / (1.0 + u * (exp_rho_dt - 1.0))

# Time integration: Strang splitting (A -> B -> C) for Nt steps
for _ in range(Nt):
    u = diffusion_half_step(u)   # Step A: diffusion half-step
    u = reaction_full_step(u)    # Step B: reaction full-step
    u = diffusion_half_step(u)   # Step C: diffusion half-step

# Scalar diagnostics
u_min  = np.min(u)
u_max  = np.max(u)
u_mean = np.mean(u)
u_l2   = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.6e}")
print(f"max(u)  = {u_max:.6e}")
print(f"mean(u) = {u_mean:.6e}")
print(f"L2 norm = {u_l2:.6e}")

# Save .npz
np.savez(
    "solution_pdebench_reacdiff_nu5_rho10.npz",
    x=x, u=u,
    nu=nu, rho=rho, T=T,
    dx=dx, dt=dt, Nx=Nx, Nt=Nt
)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.5, color="steelblue")
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"1D Reaction-Diffusion solution at T={T}  (nu={nu}, rho={rho})")
ax.grid(True, linestyle="--", alpha=0.5)
plt.tight_layout()
plt.savefig("solution_pdebench_reacdiff_nu5_rho10.png", dpi=150)
plt.close()

print("Files saved: solution_pdebench_reacdiff_nu5_rho10.npz / .png")
```

The script sets up the periodic grid with Nx=512 points and dx=1/Nx.
It initialises u from the given initial condition.
It precomputes the Fourier-space diffusion damping factor for dt/2 and the reaction exponential for dt.
Each of the 1000 time steps applies Strang splitting: diffusion half-step in Fourier space, exact logistic reaction full-step pointwise, then diffusion half-step again.
After all steps it prints min, max, mean, and discrete L2 norm of u at T=1.0.
It saves the solution arrays and scalars to the .npz file and saves the line plot as a .png file.
