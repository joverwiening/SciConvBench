Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the following specification.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Define m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Set zeta = eta.

The PDEs in conservative form are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use Gamma = 1.6666666666666667.
Use eta = 1e-08.
Use zeta = 1e-08.

Apply transmissive/outflow (zero-gradient) boundary conditions at both x=-1 and x=1.
Implement outflow BCs by setting ghost cell values equal to the nearest interior cell value.

Use a uniform finite-volume grid with Nx=800 cells on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,799, with dx = 2/800.
Evolve the conservative variables U = [rho, m, E] as cell averages.

Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

Apply the Riemann (shock-tube) initial condition with a discontinuity at x=0.
For x < 0: rho_L = 1.0, v_L = 0.75, p_L = 1.0.
For x >= 0: rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Initialize E from these values using the equation of state.

Compute the convective (inviscid Euler) flux at each interface using the Rusanov (local Lax-Friedrichs) scheme.
The physical convective flux is F_conv(U) = [m, m**2/rho + p, (E+p)*v] where v = m/rho.
Compute the interface wave speed as a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Compute v_x at cell centers using centered finite differences on the cell-centered v values.
Compute sigma at cell centers as sigma = (zeta + 4/3*eta) * v_x.
Approximate sigma at each interface by averaging the sigma values of the two neighboring cells.
Approximate v at each interface by averaging the v values of the two neighboring cells.
The viscous flux contribution at each interface is F_visc = [0, -sigma_interface, -v_interface*sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.

At each time step compute:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
dt = min(dt_conv, dt_visc)
Use CFL = 0.5.
Adjust the final time step so that the simulation ends exactly at T = 0.2.

After the simulation, compute rho(x,T), v(x,T), p(x,T) on the cell centers.

Save a file named "solution_pdebench_cns1d_sod3_eta1em8_outflow.npz" containing arrays x (length 800), rho (length 800), v (length 800), p (length 800), and scalars Gamma, eta, zeta, T, dx, CFL.

Save a plot of rho, v, and p versus x at time T as a 3-panel figure named "solution_pdebench_cns1d_sod3_eta1em8_outflow.png".

Print the minimum and maximum of rho, the minimum and maximum of p, and the mean of rho over the domain.
