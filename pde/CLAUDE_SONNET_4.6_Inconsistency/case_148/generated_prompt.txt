Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u**2) = nu * u_xx numerically with the following specifications.

The unknown field is u(x,t).

Use nu = 0.4.

The spatial domain is x in [0, 1) with periodic boundary conditions.

The temporal domain is t in [0, 1.0], so T = 1.0.

Use a uniform periodic grid with Nx = 512 points on [0, 1).
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.

Apply the initial condition u(x, 0) = sin(2*pi*x).

Enforce periodic boundary conditions: u(0, t) = u(1, t) for all t.

Set dt0 = CFL*dx/1.0 with CFL = 0.4.
Compute Nt = ceil(T/dt0) and reset dt = T/Nt so the final time T = 1.0 is hit exactly.

Advance the solution using Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), then set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): apply a finite-volume update for the inviscid Burgers equation u_t + ∂_x(0.5*u**2) = 0 using Rusanov (local Lax-Friedrichs) flux.
Define f(u) = 0.5*u**2.
For each interface between u_left = u[j] and u_right = u[(j+1) % Nx], compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, set F_plus = flux between (u[j], u[(j+1) % Nx]) and F_minus = flux between (u[(j-1) % Nx], u[j]), then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.

Step C (diffusion half-step again): repeat Step A identically.

After advancing to T = 1.0, compute the solution u(x, T) on the periodic grid.

Save a file named "solution_pdebench_burgers_nu0p4.npz" containing the following arrays and scalars: x (1D, length Nx), u (1D, length Nx), nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_burgers_nu0p4.png".

Print the following diagnostics at T: min(u), max(u), the discrete mean value mean(u) (which should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx).
