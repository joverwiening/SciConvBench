Solve the 1D Viscous Burgers equation numerically with the following specifications.

PDE: u_t + d/dx(0.5*u**2) = nu * u_xx

Spatial domain: x in [0, 1) with periodic boundary conditions.
Temporal domain: t in [0, 1.0], so T = 1.0.
Parameter: nu = 0.001.

Initial condition: u(x, 0) = sin(2*pi*x).

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0 / Nx.
Set grid points x_j = j * dx for j = 0, 1, ..., Nx-1.

Compute the time step as follows.
Set CFL = 0.4.
Set dt0 = CFL * dx / 1.0.
Set Nt = ceil(T / dt0).
Set dt = T / Nt so the final time T = 1.0 is hit exactly.

Use Strang splitting for each full time step dt, consisting of three substeps.

Substep A (diffusion half-step, duration dt/2):
Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Substep B (advection full-step, duration dt) using finite-volume Rusanov (local Lax-Friedrichs) flux for the inviscid Burgers equation u_t + d/dx(0.5*u**2) = 0:
Define f(u) = 0.5 * u**2.
For each interface between cell j (u_left = u[j]) and cell j+1 (u_right = u[j+1], with periodic indexing):
  Set alpha = max(abs(u_left), abs(u_right)).
  Set F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j:
  F_plus = flux at interface between u[j] and u[j+1].
  F_minus = flux at interface between u[j-1] and u[j].
  u_new[j] = u[j] - (dt/dx) * (F_plus - F_minus).
Replace u with u_new after the advection substep.

Substep C (diffusion half-step again): repeat Substep A identically.

Repeat the full Strang splitting step (A, B, C) for Nt steps to reach T = 1.0.

After the time integration is complete, compute and print the following diagnostics:
Print min(u).
Print max(u).
Print the discrete mean value mean(u) (should be approximately conserved).
Print the discrete L2 norm sqrt(sum(u**2) * dx).

Save the file "solution_pdebench_burgers_nu1em3.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), nu (scalar), T (scalar), dx (scalar), dt (scalar), Nx (scalar), Nt (scalar).

Save a line plot of u(x, T=1.0) as "solution_pdebench_burgers_nu1em3.png".
