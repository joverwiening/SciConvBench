Solve the PDE u_t = -k * d/dx(sin(u)) numerically using the specifications below.

PDE is u_t = -k * partial_x(sin(u)) with k = 1.0.

Spatial domain is x in [0, 1) with periodic boundary conditions.
Time domain is t in [0, 0.2].

Use a uniform periodic grid with Nx = 1024 points.
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.

Initial condition is u(x, 0) = 0.5 * sin(2 * pi * x).

Flux function is f(u) = sin(u).
Use conservative finite-volume discretization with Rusanov (local Lax-Friedrichs) flux at each cell interface.
At each interface between cell j and cell j+1, compute the Rusanov flux as: F_{j+1/2} = 0.5*(f(u_j) + f(u_{j+1})) - 0.5*alpha_{j+1/2}*(u_{j+1} - u_j), where alpha_{j+1/2} = max(|cos(u_j)|, |cos(u_{j+1})|).
The spatial derivative term at cell j is -(F_{j+1/2} - F_{j-1/2}) / dx.
Apply periodic indexing so that index -1 wraps to Nx-1 and index Nx wraps to 0.

Use SSP-RK2 (Heun's method / 2-stage strong stability preserving Runge-Kutta) for time integration.
Stage 1: u_star = u^n + dt * L(u^n).
Stage 2: u^{n+1} = 0.5 * u^n + 0.5 * (u_star + dt * L(u_star)).
Here L(u) denotes the spatial right-hand side operator.

Compute dt0 = CFL * dx / 1.0 with CFL = 0.2.
Compute Nt = ceil(T / dt0) where T = 0.2.
Set dt = T / Nt.

After time-stepping to T = 0.2, compute the final solution u(x, T).

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
No exact solution is provided, so skip error computation.
