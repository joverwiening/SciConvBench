Solve the 1D periodic diffusion PDE numerically using the following specification.

PDE: u_t = c1 * u_xx, where c1 = 0.2.

Spatial domain: x in [0, 1) with periodic boundary conditions, u(0,t) = u(1,t) for all t.
Time domain: t in [0, 0.5].

Spatial grid: Use Nx = 256 uniformly spaced points on [0,1) with no duplicated endpoint. Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.

Initial condition: u(x, 0) = sin(2*pi*x).

Time integration method: Crank-Nicolson (implicit, unconditionally stable).
Time step: dt = 0.001 with Nt = 500 steps so the final time T = 0.5 is hit exactly.

Spatial discretization: 2nd-order central differences for u_xx on the periodic grid. For interior points, u_xx at j is approximated as (u[j-1] - 2*u[j] + u[j+1]) / dx**2. Apply periodic wrap-around so that index -1 maps to Nx-1 and index Nx maps to 0.

Crank-Nicolson scheme: At each time step, solve the linear system (I - (dt*c1/2)*D2) * u_new = (I + (dt*c1/2)*D2) * u_old, where D2 is the second-difference matrix with periodic boundary conditions. Construct D2 as a sparse circulant tridiagonal matrix of size Nx x Nx with -2 on the diagonal, 1 on the super- and sub-diagonals, and 1 in the corners (positions [0, Nx-1] and [Nx-1, 0]) to enforce periodicity, all divided by dx**2.

Solve the linear system at each time step using a sparse solver (e.g., scipy.sparse.linalg.spsolve).

Exact solution for verification: u_exact(x, t) = exp(-c1 * (2*pi)**2 * t) * sin(2*pi*x).
