Solve the Klein-Gordon PDE numerically as described below.

The PDE is u_tt - (0.8)**2 * (u_xx + u_yy) + (0.2)**2 * u = 0.
The spatial domain is (x,y) in [0,1] x [0,1] and the time domain is t in [0, 1.1].
Parameters are c = 0.8 and m = 0.2.
Boundary conditions are Dirichlet u = 0 on all four boundaries.
Initial condition is u(x,y,0) = sin(2*pi*x)*sin(pi*y) and u_t(x,y,0) = 0.
The exact solution for verification is u(x,y,t) = cos(sqrt((0.8)**2*((2*pi)**2 + (pi)**2) + (0.2)**2)*t) * sin(2*pi*x) * sin(pi*y).

Use a uniform grid with Nx = Ny = 160 intervals, giving Nx+1 = 161 grid points in each direction including both endpoints.
Set dx = dy = 1.0/160.
Compute dt0 = 0.5 * min(dx, dy) / c.
Set Nt = ceil(1.1 / dt0) and then dt = 1.1 / Nt so the final time T = 1.1 is hit exactly.
Use the 5-point Laplacian stencil for the spatial second derivatives u_xx + u_yy on the interior points.
Use 2nd-order central differencing in time for u_tt.
Initialize the first time step using a Taylor expansion: u(x,y,dt) = u(x,y,0) + dt*u_t(x,y,0) + 0.5*dt**2*(c**2*(u_xx+u_yy) - m**2*u) evaluated at t=0, where u_t(x,y,0) = 0, so u1 = u0 + 0.5*dt**2*(c**2*L(u0) - m**2*u0), where L denotes the discrete Laplacian.
Enforce u = 0 on all boundary points at every time step.
Advance the solution using the leapfrog update: u_new = 2*u_curr - u_old + dt**2*(c**2*L(u_curr) - m**2*u_curr) for interior points.

At T = 1.1, compute the solution u on the full (Ny+1) x (Nx+1) grid.
Save the file "solution_agent_kg_06.npz" containing: x as a 1D array of length Nx+1, y as a 1D array of length Ny+1, u as a 2D array of shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T, and scalar metadata T, dx, dy, dt.
Save a heatmap or filled contour plot of u(x,y,T) as "solution_agent_kg_06.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) at T.
