Solve the 1D advection-diffusion PDE numerically as described below.

The PDE is u_t = D*u_xx - (1/gamma)*d_x(U'(x)*u), where U(x) = cos(2*pi*x) and U'(x) = -2*pi*sin(2*pi*x).
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
Set D = 0.01 and gamma = 1.0.
The initial condition is u(x, 0) = 1.0 + 0.2*sin(2*pi*x).

Use a uniform periodic grid with Nx = 512 points on [0, 1).
Set dx = 1.0/Nx.
Set x_j = j*dx for j = 0, 1, ..., Nx-1.

Discretize the drift term in conservative form with flux F(x) = (1/gamma)*U'(x)*u.
The PDE becomes u_t = D*u_xx - d_x(F).
Use upwind finite-volume flux for d_x(F) based on the sign of the interface velocity b = U'(x)/gamma.
Use 2nd-order central differences for u_xx.

For the upwind flux at interface j+1/2, evaluate the interface velocity b_{j+1/2} = U'(x_{j+1/2})/gamma where x_{j+1/2} = (j + 0.5)*dx.
If b_{j+1/2} >= 0, set F_{j+1/2} = b_{j+1/2} * u_j.
If b_{j+1/2} < 0, set F_{j+1/2} = b_{j+1/2} * u_{j+1}.
The upwind divergence term at cell j is (F_{j+1/2} - F_{j-1/2}) / dx.

For u_xx at point j, use (u_{j+1} - 2*u_j + u_{j-1}) / dx**2 with periodic index wrapping.

Compute the time step as dt = min(0.4*dx / max(|b|), 0.2*dx**2 / D), where max(|b|) is the maximum of |U'(x)/gamma| over all grid points.
Set Nt = ceil(T / dt) and recompute dt = T / Nt so the integration lands exactly at T = 1.0.

Use explicit SSP-RK2 (Heun's method) for time integration.
SSP-RK2 stage 1: u_star = u^n + dt * L(u^n).
SSP-RK2 stage 2: u^{n+1} = 0.5*u^n + 0.5*(u_star + dt * L(u_star)).
Here L(u) = D*u_xx - d_x(F) is the full spatial operator.

Apply periodic boundary conditions at every stage by using modular index arithmetic (index mod Nx).
