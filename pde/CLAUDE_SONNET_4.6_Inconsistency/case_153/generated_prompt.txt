Solve the 1D viscous Burgers equation u_t + d/dx(0.5*u**2) = nu*u_xx numerically using the specifications below.

Use Python with numpy and matplotlib.

The PDE is u_t + d/dx(0.5*u**2) = nu*u_xx.

The spatial domain is [0,1) with periodic boundary conditions. The time domain is t in [0, 1.0]. Wait — the output requirement says T=1.1 but the domain says t in [0,1.0]. Use T=1.1 as the final time for computation and output, as stated in the output requirements section.

Set nu = 4.0.

Use Nx = 512 grid points on [0,1) with dx = 1.0/Nx and x_j = j*dx for j=0,...,Nx-1.

Set the initial condition u(x,0) = sin(2*pi*x).

Compute dt0 = 0.4 * dx / 1.0. Set Nt = ceil(1.1 / dt0). Set dt = 1.1 / Nt so the final time T=1.1 is hit exactly.

At each time step, apply Strang splitting as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = numpy.fft.fft(u). Compute the wavenumbers k = 2*pi*numpy.fft.fftfreq(Nx, d=dx). Multiply u_hat by exp(-nu * k**2 * (dt/2)). Set u = numpy.real(numpy.fft.ifft(u_hat)).

Step B (advection full-step, duration dt) using finite-volume Rusanov flux: define f(u) = 0.5*u**2. For each interface j (with periodic indexing), set u_left = u[j] and u_right = u[(j+1) % Nx]. Compute alpha = max(abs(u_left), abs(u_right)). Compute F[j] = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j, compute u_new[j] = u[j] - (dt/dx)*(F[j] - F[(j-1) % Nx]). Replace u with u_new.

Step C (diffusion half-step again): repeat Step A identically.

After all Nt time steps, u holds the solution at T=1.1.

Print the following diagnostics: min(u), max(u), mean(u) (discrete mean, should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx).

Save a file named "solution_pdebench_burgers_nu4.npz" using numpy.savez containing: array x of length Nx, array u of length Nx, and scalars nu, T, dx, dt, Nx, Nt.

Save a line plot of u versus x at T=1.1 as "solution_pdebench_burgers_nu4.png" with appropriate axis labels and title.

Use numpy.fft.fft and numpy.fft.ifft for all Fourier transforms.
Use numpy.fft.fftfreq with d=dx for wavenumber computation.
Use numpy.ceil for computing Nt.
Take only the real part after each IFFT step.
Use vectorized numpy operations for the Rusanov flux computation rather than explicit Python loops for efficiency.
