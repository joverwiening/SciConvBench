Solve the 1D wave equation u_tt = (0.8)^2 * u_xx numerically using the specifications below.

The PDE is u_tt = (0.8)**2 * u_xx, where c = 0.8 is the wave speed used in the numerical scheme.
The spatial domain is x in [0, 1] (closed interval) and the time domain is t in [0, 1.0].
Use Nx = 600 uniform intervals, giving Nx+1 = 601 grid points including both endpoints.
Set dx = 1.0 / 600.
Compute dt0 = 0.9 * dx / 0.8 (CFL condition with c = 0.8).
Set Nt = ceil(1.0 / dt0) and then dt = 1.0 / Nt so the final time T = 1.0 is hit exactly.
Build the spatial grid as x_i = i * dx for i = 0, 1, ..., 600.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1 at every time step.

Set the initial velocity u_t(x, 0) = sin(2 * pi * x) for all grid points.
Initialize u^0 using u(x, 0) = 0.
Compute u_xx^0 using 2nd-order central differences on the interior points: u_xx_i = (u_{i-1} - 2*u_i + u_{i+1}) / dx**2.
Compute u^1 using the Taylor start: u^1_i = u^0_i + dt * v0_i + 0.5 * dt**2 * (0.8)**2 * u_xx^0_i for interior points.
Set u^1 = 0 at the boundary nodes i = 0 and i = 600.
Advance from time step n = 1 to Nt using the leapfrog scheme: u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (0.8 * dt / dx)**2 * (u^n_{i-1} - 2*u^n_i + u^n_{i+1}) for interior points.

Below is the complete Python implementation:

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
c = 0.8
T = 1.0
Nx = 600
dx = 1.0 / Nx
dt0 = 0.9 * dx / c
Nt = int(np.ceil(T / dt0))
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL={c*dt/dx:.6f}")

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 601 points

# Initial conditions
u0 = np.zeros(Nx + 1)
v0 = np.sin(2 * np.pi * x)

# Compute u_xx at t=0 using central differences (interior only)
def compute_uxx(u, dx):
    uxx = np.zeros_like(u)
    uxx[1:-1] = (u[:-2] - 2.0 * u[1:-1] + u[2:]) / dx**2
    return uxx

uxx0 = compute_uxx(u0, dx)

# Taylor start: u^1
r = (c * dt / dx)**2
u_prev = u0.copy()
u_curr = np.zeros(Nx + 1)
u_curr[1:-1] = (u_prev[1:-1]
                + dt * v0[1:-1]
                + 0.5 * dt**2 * c**2 * uxx0[1:-1])
u_curr[0] = 0.0
u_curr[-1] = 0.0

# Leapfrog time stepping
u_next = np.zeros(Nx + 1)
for n in range(1, Nt):
    u_next[1:-1] = (2.0 * u_curr[1:-1]
                    - u_prev[1:-1]
                    + r * (u_curr[:-2] - 2.0 * u_curr[1:-1] + u_curr[2:]))
    u_next[0] = 0.0
    u_next[-1] = 0.0
    u_prev, u_curr = u_curr, u_next.copy()

u = u_curr  # solution at T=1.0

# Exact solution
u_exact = (1.0 / (0.8 * 2 * np.pi)) * np.sin(0.8 * 2 * np.pi * T) * np.sin(2 * np.pi * x)

# Diagnostics
print(f"min(u)       = {np.min(u):.6e}")
print(f"max(u)       = {np.max(u):.6e}")
print(f"L2 norm(u)   = {np.sqrt(np.sum(u**2) * dx):.6e}")
print(f"Max abs error= {np.max(np.abs(u - u_exact)):.6e}")
print(f"L2 error     = {np.sqrt(np.sum((u - u_exact)**2) * dx):.6e}")

# Save npz
np.savez("solution_agent_wave_14.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_wave_14.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x, T={T})")
ax.plot(x, u_exact, '--', label="Exact solution")
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Wave equation solution at T={T}")
ax.legend()
plt.tight_layout()
plt.savefig("solution_agent_wave_14.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_14.png")
```
