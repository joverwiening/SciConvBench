Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the exact specifications below.

Domain is x in [0, 1) with periodic boundary conditions and t in [0, 1.0].
Parameters are nu = 0.5 and rho = 10.0.
Use a uniform periodic spatial grid with Nx = 512 points, dx = 1/512, and x_j = j * dx for j = 0, ..., 511.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.
Set the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x) evaluated at each grid point.

At each of the Nt time steps apply Strang splitting as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).

Step B (reaction full step, duration dt): update each grid point exactly using the logistic ODE solution u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).

Step C (diffusion half-step again): repeat Step A identically with duration dt/2.

After all Nt steps, compute u(x, T=1.0) on the periodic grid.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.

Save a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz" containing the following arrays and scalars: x (1D array of length 512), u (1D array of length 512), nu (scalar 0.5), rho (scalar 10.0), T (scalar 1.0), dx (scalar 1/512), dt (scalar 0.001), Nx (scalar 512), Nt (scalar 1000).

Save a line plot of u versus x at T = 1.0 as "solution_pdebench_reacdiff_nu0p5_rho10.png".

Use Python with numpy and matplotlib. Use numpy.fft.fft, numpy.fft.ifft, and numpy.fft.fftfreq. Interpret ^ as exponentiation and use ** in Python code. Treat all trigonometric arguments in radians.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
nu   = 0.5
rho  = 10.0
T    = 1.0
Nx   = 512
Nt   = 1000
dt   = 0.001
dx   = 1.0 / Nx

# Grid
x = np.arange(Nx) * dx

# Initial condition
u = 0.25 + 0.1 * np.sin(2.0 * np.pi * x)

# Wavenumbers for periodic FFT
k = 2.0 * np.pi * np.fft.fftfreq(Nx, d=dx)

# Precompute diffusion factors for half-step and full-step
diff_half = np.exp(-nu * k**2 * (dt / 2.0))

# Precompute reaction constants
exp_rho_dt = np.exp(rho * dt)

def diffusion_half_step(u):
    u_hat = np.fft.fft(u)
    u_hat *= diff_half
    return np.fft.ifft(u_hat).real

def reaction_full_step(u):
    return (u * exp_rho_dt) / (1.0 + u * (exp_rho_dt - 1.0))

# Time integration with Strang splitting
for _ in range(Nt):
    u = diffusion_half_step(u)   # Step A
    u = reaction_full_step(u)    # Step B
    u = diffusion_half_step(u)   # Step C

# Diagnostics
u_min  = np.min(u)
u_max  = np.max(u)
u_mean = np.mean(u)
u_l2   = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.10f}")
print(f"max(u)  = {u_max:.10f}")
print(f"mean(u) = {u_mean:.10f}")
print(f"L2 norm = {u_l2:.10f}")

# Save .npz
np.savez(
    "solution_pdebench_reacdiff_nu0p5_rho10.npz",
    x=x, u=u,
    nu=nu, rho=rho, T=T,
    dx=dx, dt=dt, Nx=Nx, Nt=Nt
)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.5, color='steelblue')
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=1.0)")
ax.set_title(f"1D Reaction-Diffusion at T={T}  (nu={nu}, rho={rho})")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_pdebench_reacdiff_nu0p5_rho10.png", dpi=150)
plt.close()
print("Files saved.")
```
