Solve the Lotka-Volterra predator-prey ODE system numerically using the specifications below.

The ODE system is:
dx/dt = alpha*x - beta*x*y
dy/dt = delta*x*y - gamma*y

The time domain is t in [0.0, 30.0].

Use parameters alpha = 1.5, beta = 2, gamma = 3.0, delta = 1.0.

Set initial conditions x(0.0) = 1.0 and y(0.0) = 1.0.

Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.01 and Nt = 3000 steps so the final time 30.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n*0.01 for n = 0 to 3000 inclusive, giving 3001 time points total.

Use ** for exponentiation in Python code.

Save a file named solution_molk_008.npz containing: a 1D array t of length 3001, a 2D array Y of shape [3001, 2] with columns ordered as [x, y], and the scalar parameters alpha, beta, gamma, delta.

Save a line plot of x vs t and y vs t as solution_molk_008.png.

Print the final state values x(30.0) and y(30.0).

Print the minimum and maximum of x over all time points.

Print the minimum and maximum of y over all time points.

Here is the complete Python code:

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
alpha = 1.5
beta  = 2.0
gamma = 3.0
delta = 1.0

# Time grid
t0 = 0.0
tf = 30.0
dt = 0.01
Nt = 3000
t  = np.linspace(t0, tf, Nt + 1)   # length 3001, exactly hits tf

# ODE right-hand side
def rhs(state, t_cur):
    x, y = state
    dxdt = alpha * x - beta * x * y
    dydt = delta * x * y - gamma * y
    return np.array([dxdt, dydt])

# Classical RK4 integration
Y = np.empty((Nt + 1, 2))
Y[0] = np.array([1.0, 1.0])   # initial conditions

for n in range(Nt):
    s  = Y[n]
    tn = t[n]
    k1 = rhs(s,              tn)
    k2 = rhs(s + 0.5*dt*k1, tn + 0.5*dt)
    k3 = rhs(s + 0.5*dt*k2, tn + 0.5*dt)
    k4 = rhs(s +     dt*k3, tn +     dt)
    Y[n + 1] = s + (dt / 6.0) * (k1 + 2.0*k2 + 2.0*k3 + k4)

x_arr = Y[:, 0]
y_arr = Y[:, 1]

# Save .npz
np.savez(
    "solution_molk_008.npz",
    t=t,
    Y=Y,
    alpha=alpha,
    beta=beta,
    gamma=gamma,
    delta=delta
)

# Save plot
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(t, x_arr, label="x (prey)")
ax.plot(t, y_arr, label="y (predator)")
ax.set_xlabel("t")
ax.set_ylabel("Population")
ax.set_title("Lotka-Volterra Predator-Prey (molk_008)")
ax.legend()
plt.tight_layout()
plt.savefig("solution_molk_008.png", dpi=150)
plt.close()

# Print diagnostics
print("=== Final state at T = 30.0 ===")
print(f"  x(30.0) = {x_arr[-1]:.10f}")
print(f"  y(30.0) = {y_arr[-1]:.10f}")

print("\n=== Min / Max over all time points ===")
print(f"  x : min = {x_arr.min():.10f},  max = {x_arr.max():.10f}")
print(f"  y : min = {y_arr.min():.10f},  max = {y_arr.max():.10f}")
```

The code defines the RK4 stepper explicitly without any library solver.
Each of the four slope evaluations k1 through k4 uses the standard classical RK4 weights.
The time array is built with np.linspace so both endpoints are represented exactly.
The npz file stores t as a 1D array of length 3001, Y as a 2D array of shape [3001, 2] with column 0 being x and column 1 being y, and the four scalar parameters.
The png file shows both state variables plotted against t on the same axes with a legend.
The printed diagnostics report the final values and the global min and max for each state variable.
