Solve the PDE u_t = d/dx(D(x) * u_x) where D(x) = 0.1*(1 + x) numerically.
The spatial domain is x in [0,1] (closed interval) and the time domain is t in [0,0.5].
Use Nx=300 uniform intervals giving 301 grid points including both endpoints, with dx = 1/300 and x_i = i*dx for i=0..300.
Use dt=0.001 and 600 time steps.
Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Set the initial condition u(x,0) = sin(pi*x).
Define D_i = 0.1*(1 + x_i) at each grid point.
Define face-averaged diffusion coefficients D_{i+1/2} = 0.5*(D_i + D_{i+1}) for i=0..Nx-1.
For interior points i=1..Nx-1, discretize the diffusion operator as (1/dx**2) * (D_{i+1/2}*(u_{i+1} - u_i) - D_{i-1/2}*(u_i - u_{i-1})).
Enforce Dirichlet conditions by fixing u[0]=0 and u[Nx]=0 at every time step (rows 0 and Nx in the linear system are identity rows with right-hand side 0).
Use implicit Euler time integration: at each step solve the sparse linear system (I - dt*L) u^{n+1} = u^n where L is the discrete diffusion operator matrix.
Build the matrix as a sparse tridiagonal system using scipy.sparse and solve with scipy.sparse.linalg.spsolve at each of the 600 steps.
After completing all time steps, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.
Save a file named "solution_agent_diffusion_01.npz" containing the 1D array x of length 301, the 1D array u of length 301 representing u(x, T=0.5), and scalar metadata T=0.5, dx=1/300, dt=0.001.
Save a line plot of u(x, T=0.5) as "solution_agent_diffusion_01.png" with x on the horizontal axis and u on the vertical axis.
Use radians for all trigonometric functions.
Use ** for exponentiation in Python code.

```python
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla
import matplotlib.pyplot as plt

# Grid setup
Nx = 300
x = np.linspace(0.0, 1.0, Nx + 1)  # 301 points, x_i = i*dx, i=0..300
dx = 1.0 / Nx

# Time setup
dt = 0.001
T = 0.5
Nsteps = int(round(T / dt))  # 600 steps

# Diffusion coefficient at grid points
D = 0.1 * (1.0 + x)  # length 301

# Face-averaged diffusion coefficients D_{i+1/2} for i=0..Nx-1
D_half = 0.5 * (D[:-1] + D[1:])  # length 300, D_half[i] = D_{i+1/2}

# Build the tridiagonal diffusion operator L (interior rows only, then enforce BCs)
# For interior point i (1..Nx-1):
#   L[i,i-1] = D_{i-1/2} / dx**2  = D_half[i-1] / dx**2
#   L[i,i]   = -(D_{i-1/2} + D_{i+1/2}) / dx**2 = -(D_half[i-1] + D_half[i]) / dx**2
#   L[i,i+1] = D_{i+1/2} / dx**2  = D_half[i] / dx**2
# Boundary rows (i=0 and i=Nx): identity (u=0)

N = Nx + 1  # total number of unknowns = 301

# Diagonals for the full (N x N) matrix of (I - dt*L)
# Start with identity
main_diag = np.ones(N)
lower_diag = np.zeros(N - 1)
upper_diag = np.zeros(N - 1)

# Fill interior rows i=1..Nx-1
for i in range(1, Nx):
    d_minus = D_half[i - 1]  # D_{i-1/2}
    d_plus  = D_half[i]      # D_{i+1/2}
    # L coefficients
    l_lower = d_minus / dx**2
    l_center = -(d_minus + d_plus) / dx**2
    l_upper = d_plus / dx**2
    # (I - dt*L) coefficients
    main_diag[i]      = 1.0 - dt * l_center
    lower_diag[i - 1] = -dt * l_lower   # sub-diagonal at position i-1
    upper_diag[i]     = -dt * l_upper   # super-diagonal at position i

# Boundary rows i=0 and i=Nx remain as identity rows (main_diag=1, off-diags=0)
# lower_diag[Nx-1] and upper_diag[0] are already 0 from initialization

# Build sparse matrix in CSR format
A = sp.diags(
    [lower_diag, main_diag, upper_diag],
    offsets=[-1, 0, 1],
    shape=(N, N),
    format='csr'
)

# Initial condition
u = np.sin(np.pi * x)

# Time integration: implicit Euler
for step in range(Nsteps):
    rhs = u.copy()
    rhs[0]  = 0.0  # Dirichlet BC at x=0
    rhs[Nx] = 0.0  # Dirichlet BC at x=1
    u = spla.spsolve(A, rhs)
    # Enforce BCs explicitly (should already be satisfied)
    u[0]  = 0.0
    u[Nx] = 0.0

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)    = {u_min:.6e}")
print(f"max(u)    = {u_max:.6e}")
print(f"L2 norm   = {l2_norm:.6e}")

# Save .npz
np.savez(
    "solution_agent_diffusion_01.npz",
    x=x,
    u=u,
    T=np.float64(T),
    dx=np.float64(dx),
    dt=np.float64(dt)
)
print("Saved solution_agent_diffusion_01.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, u, linewidth=2, color='steelblue')
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=0.5)")
ax.set_title("Diffusion solution at T=0.5\n(variable D(x)=0.1*(1+x), implicit Euler)")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_agent_diffusion_01.png", dpi=150)
plt.close()
print("Saved solution_agent_diffusion_01.png")
```
