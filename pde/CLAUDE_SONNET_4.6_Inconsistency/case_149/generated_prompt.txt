Solve the 1D viscous Burgers equation u_t + d/dx(0.5*u^2) = nu*u_xx numerically using the specifications below.

Use Python with numpy and matplotlib.

The PDE is u_t + d/dx(0.5*u^2) = nu*u_xx.

The spatial domain is [0,1) with periodic boundary conditions. The time domain is [0, 1.0].

Set nu = 1.0.

Use Nx = 512 uniform grid points on [0,1). Set dx = 1.0/Nx. Set x_j = j*dx for j = 0, 1, ..., Nx-1.

Set the initial condition u(x,0) = sin(2*pi*x).

Compute dt0 = 0.4 * dx / 1.0. Compute Nt = ceil(1.0 / dt0). Reset dt = 1.0 / Nt so the final time T=1.0 is hit exactly.

At each full time step, apply Strang splitting in three substeps.

Substep A (diffusion half-step, duration dt/2): compute u_hat = FFT(u). Compute the wavenumber array k = 2*pi*fftfreq(Nx, d=dx). Multiply u_hat by exp(-nu * k**2 * (dt/2)). Set u = real(IFFT(u_hat)).

Substep B (advection full-step, duration dt): apply a finite-volume update using Rusanov (local Lax-Friedrichs) flux. Define f(u) = 0.5*u**2. For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing so u[Nx] = u[0]), compute alpha = max(abs(u_left), abs(u_right)) and flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j, set F_plus = flux at interface (u[j], u[j+1]) and F_minus = flux at interface (u[j-1], u[j]) with periodic indexing. Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus). Replace u with u_new.

Substep C (diffusion half-step, duration dt/2): repeat substep A identically.

After all Nt time steps, u holds the solution at T = 1.0.

Print min(u), max(u), mean(u) (the discrete mean, which should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx).

Save a file named "solution_pdebench_burgers_nu1.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), nu (scalar), T (scalar), dx (scalar), dt (scalar), Nx (scalar), Nt (scalar).

Save a line plot of u(x, T=1.0) versus x as "solution_pdebench_burgers_nu1.png" with labeled axes and a title.
