Solve the 1D Compressible Navier-Stokes equations (no heat conduction) numerically and save the results.

Use Gamma = 5/3 (1.6666666666666667). Discard the second Gamma value (0.166666666667) as a typo.
Use eta = 1e-08 and zeta = 1e-08.

The conservative variables are U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v**2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.

The PDEs in conservative form are:
  rho_t + (m)_x = 0
  m_t + (m**2/rho + p - sigma)_x = 0
  E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.5].

Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., 399, with dx = 2/400 = 0.005.
Evolve cell-average conservative variables U = [rho, m, E].

Apply periodic boundary conditions by wrapping indices (ghost cells take values from the opposite end of the domain).

Set the initial conditions pointwise at cell centers:
  rho(x, 0) = 1.0 + 0.2*sin(pi*x)
  v(x, 0)   = 0.1*cos(pi*x)
  p(x, 0)   = 1.0 + 0.2*cos(pi*x)
Convert to conservative variables: m = rho*v, E = p/(Gamma-1) + 0.5*rho*v**2.

Recover primitive variables using the equation of state: p = (Gamma-1)*(E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 before any use.

For the convective (inviscid) flux, use the Rusanov (local Lax-Friedrichs) scheme.
The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] with v = m/rho.
At each interface between cells L and R, compute the sound speed c = sqrt(Gamma*p/rho) for each side.
Compute the interface wave speed a = max(|v_L| + c_L, |v_R| + c_R).
Compute the Rusanov numerical flux: F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

For the viscous flux, compute v_x at each cell center using a centered finite difference on the cell-centered v values with periodic wrapping.
Compute sigma at each cell center: sigma = (zeta + 4/3*eta) * v_x.
At each interface, approximate sigma_interface = 0.5*(sigma_L + sigma_R) and v_interface = 0.5*(v_L + v_R).
The viscous flux contribution is F_visc = [0, -sigma_interface, -v_interface*sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

Compute the semi-discrete right-hand side as RHS_j = -(F_total_{j+1/2} - F_total_{j-1/2}) / dx.

Use 2-stage SSP-RK2 (Heun's method) for time integration:
  U_star = U^n + dt * RHS(U^n)
  U^{n+1} = 0.5 * U^n + 0.5 * (U_star + dt * RHS(U_star))

Choose CFL = 0.8 for the convective time-step criterion.
At each step compute:
  dt_conv = CFL * dx / max_j(|v_j| + c_j)
  dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
  dt = min(dt_conv, dt_visc)
Adjust the final time step so the simulation ends exactly at T = 0.5.

At the final time T = 0.5, recover rho, v, p at all cell centers from the conservative variables.

Save a file named "solution_pdebench_cns1d_eta1em8_periodic_smooth.npz" containing arrays x (length 400), rho (length 400), v (length 400), p (length 400), and scalars Gamma, eta, zeta, T, dx, CFL.

Save a figure named "solution_pdebench_cns1d_eta1em8_periodic_smooth.png" showing 3 panels (or 3 separate plots) of rho vs x, v vs x, and p vs x at time T = 0.5.

Print the minimum and maximum of rho and p as a positivity check.
Print the mean of rho over the domain as a mass conservation check.
