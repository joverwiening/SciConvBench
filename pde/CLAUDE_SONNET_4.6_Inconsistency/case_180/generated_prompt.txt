Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the exact specifications below.

Domain is x in [0, 1) with periodic boundary conditions and t in [0, 1.0].
Parameters are nu = 1.0 and rho = 1.0.
Initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Use a uniform periodic spatial grid with Nx=512 points on [0,1).
Set dx = 1/Nx and x_j = j*dx for j=0,...,Nx-1.
Use a fixed time step dt=0.001 with Nt=1000 steps so that T=1.0 is reached exactly.

Apply Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).

Step B (reaction full step, duration dt): apply the exact logistic ODE solution pointwise: u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).

Step C (diffusion half-step again): repeat Step A identically.

Repeat Steps A, B, C for all Nt=1000 time steps.

After all time steps, compute u(x, T=1.0) on the periodic grid.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.

Save a file named "solution_pdebench_reacdiff_nu1_rho1.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), and scalar values nu, rho, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T=1.0) as a PNG file named "solution_pdebench_reacdiff_nu1_rho1.png".

Use numpy for FFT operations (numpy.fft.fft, numpy.fft.ifft, numpy.fft.fftfreq).
Use Python with numpy and matplotlib.
