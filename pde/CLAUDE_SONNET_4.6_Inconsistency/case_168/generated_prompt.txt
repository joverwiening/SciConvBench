Solve the 2D Darcy flow PDE: -div(a(x,y) grad(u)) = 1 on the domain (x,y) in (0,1)x(0,1).
Set beta = 0.1.
Define the coefficient field as a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply homogeneous Dirichlet boundary conditions: u = 0 on all four edges of the domain.
Use a uniform Cartesian grid with N = 128 intervals in each direction, giving N+1 = 129 grid points per axis including both endpoints.
Set dx = dy = 1/N.
Define grid points as x_i = i*dx for i = 0, 1, ..., N and y_j = j*dy for j = 0, 1, ..., N.
Treat boundary nodes (i=0, i=N, j=0, j=N) as known with u = 0; solve only for interior nodes i=1..N-1, j=1..N-1.
Discretize the PDE at each interior node using the second-order finite difference stencil with face-centered harmonic-mean coefficients.
Compute face coefficients as harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)), and analogously for a(i-1/2,j), a(i,j+1/2), a(i,j-1/2).
Apply the stencil: -(1/dx**2) * [a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1))] = 1 for all interior nodes.
Assemble the resulting linear system A*u_interior = b as a sparse matrix in CSR format, where b is a vector of ones of length (N-1)**2.
Solve the sparse linear system using the Conjugate Gradient (CG) method with a relative residual tolerance of 1e-10.
Optionally apply a Jacobi preconditioner (diagonal of A) to accelerate CG convergence.
After solving, construct the full (N+1)x(N+1) solution array u by placing the interior solution into the interior nodes and setting all boundary entries to zero.
Evaluate a(x_i, y_j) at all grid points using the formula with radians for the trigonometric functions.
Compute min(u) and max(u) over the full grid and print them.
Compute the discrete residual norm as ||A*u_interior - b||_2 / ||b||_2 and print it.
Save a file named "solution_pdebench_darcy_beta0p1.npz" containing: x as a 1D array of length N+1, y as a 1D array of length N+1, u as a 2D array of shape [N+1, N+1], and scalars beta, N, dx.
Save a heatmap or filled-contour plot of u(x,y) as a PNG file named "solution_pdebench_darcy_beta0p1.png", with labeled axes and a colorbar.
Use Python with NumPy, SciPy (sparse and linalg.cg), and Matplotlib for all implementation steps.
