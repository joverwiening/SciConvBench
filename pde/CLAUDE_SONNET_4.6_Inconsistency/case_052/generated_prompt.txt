Solve the 2D Klein-Gordon PDE numerically as specified below.

The PDE is u_tt - (1.0)**2 * (u_xx + u_yy) + (1.0)**2 * u = 0, where c = 1.0 and m = 1.0.
The spatial domain is (x, y) in [0, 1] x [0, 1] and the time domain is t in [0, 0.8].
The final output time is T = 0.9 (override the domain end for output purposes; run the simulation to t = 0.9).
Use Nx = Ny = 256 uniform intervals, giving Nx+1 = 257 grid points in each direction including both endpoints.
Set dx = 1.0 / 256 and dy = 1.0 / 256.
Set x_i = i * dx for i = 0, 1, ..., 256 and y_j = j * dy for j = 0, 1, ..., 256.
Compute dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)).
Set Nt = ceil(0.9 / dt0) and then dt = 0.9 / Nt so the simulation hits T = 0.9 exactly.
Apply Dirichlet boundary conditions u = 0 on all four boundaries at all times.
Set the initial displacement u(x, y, 0) = sin(pi * x) * sin(pi * y).
Set the initial velocity u_t(x, y, 0) = 0.
Use a uniform 5-point Laplacian stencil for the spatial discretization of u_xx + u_yy.
Use 2nd-order central differencing in time for u_tt.
Initialize the first time step using a Taylor expansion: u(x, y, dt) = u(x, y, 0) + dt * u_t(x, y, 0) + 0.5 * dt**2 * (c**2 * (u_xx + u_yy) - m**2 * u) evaluated at t = 0, which simplifies to u(x, y, 0) + 0.5 * dt**2 * (c**2 * Laplacian(u0) - m**2 * u0) since u_t = 0.
At each interior time step n >= 1, advance using u_new[i,j] = 2*u[i,j] - u_old[i,j] + dt**2 * (c**2 * L[i,j] - m**2 * u[i,j]), where L[i,j] is the 5-point Laplacian of u at (i, j).
Enforce u = 0 on all boundary points after every time step.
The exact reference solution is u_exact(x, y, t) = cos(sqrt(c**2 * 2 * pi**2 + m**2) * t) * sin(pi * x) * sin(pi * y).
Evaluate both the numerical solution and the exact solution on the full (257 x 257) grid at T = 0.9.
Save a file named "solution_agent_kg_05.npz" containing: x as a 1D array of length 257, y as a 1D array of length 257, u as a 2D array of shape (257, 257) where u[j, i] = u(x_i, y_j) at T, and scalar metadata T, dx, dy, dt.
Save a heatmap or filled contour plot of u(x, y, T) as "solution_agent_kg_05.png" with labeled axes and a colorbar.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx * dy) at T.
