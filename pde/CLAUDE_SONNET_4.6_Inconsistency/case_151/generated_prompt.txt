Solve the 1D viscous Burgers equation u_t + d/dx(0.5*u**2) = nu*u_xx numerically using the specifications below.

Use Python with numpy, scipy, and matplotlib.

The PDE is u_t + d/dx(0.5*u**2) = nu*u_xx.

The spatial domain is [0,1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu = 2.0.

Set Nx = 512.
Set dx = 1.0/Nx.
Build the spatial grid as x[j] = j*dx for j = 0, 1, ..., Nx-1.

Set the initial condition u(x,0) = sin(2*pi*x).

Compute dt0 = 0.4 * dx / 1.0.
Compute Nt = ceil(1.0 / dt0) as an integer.
Set dt = 1.0 / Nt so the final time T=1.0 is hit exactly.

At each time step, apply Strang splitting in three substeps.

Substep A (diffusion half-step, duration dt/2):
Compute u_hat = numpy.fft.fft(u).
Compute the wavenumber array k = 2*pi*numpy.fft.fftfreq(Nx, d=dx).
Multiply u_hat[m] by exp(-nu * k[m]**2 * (dt/2)) for each wavenumber m.
Set u = numpy.real(numpy.fft.ifft(u_hat)).

Substep B (advection full-step, duration dt) using finite-volume Rusanov flux:
Define f(v) = 0.5*v**2.
For each interface between cell j (left state u[j]) and cell j+1 mod Nx (right state u[(j+1) % Nx]):
  Set alpha = max(abs(u[j]), abs(u[(j+1) % Nx])).
  Set F[j] = 0.5*(f(u[j]) + f(u[(j+1) % Nx])) - 0.5*alpha*(u[(j+1) % Nx] - u[j]).
For each cell j:
  Set u_new[j] = u[j] - (dt/dx)*(F[j] - F[(j-1) % Nx]).
Replace u with u_new.

Substep C (diffusion half-step again, identical to Substep A).

Repeat the full Strang splitting step for Nt steps.

After all time steps, compute and print the following diagnostics:
Print min(u).
Print max(u).
Print the discrete mean value mean(u) (this should be approximately conserved, near zero for this IC).
Print the discrete L2 norm sqrt(sum(u**2)*dx).
