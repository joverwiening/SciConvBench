Solve the 2D Darcy flow PDE: -div(a(x,y) grad(u)) = 1 on the domain (x,y) in (0,1)x(0,1).
Use beta = 0.01.
Define the coefficient field as a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions u = 0 on the entire boundary of the domain.
Ignore the periodic boundary condition statement; it contradicts the Dirichlet condition, and the Dirichlet condition takes precedence as it is explicitly specified for the boundary.
Use a uniform Cartesian grid with N=128 intervals in each direction, giving N+1=129 grid points per direction including both endpoints.
Set dx = dy = 1/N.
Set x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Use 2nd-order finite differences with variable coefficients and face-centered harmonic averaging.
For interior nodes (i=1..N-1, j=1..N-1), discretize the operator as: -(1/dx**2)*[a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1))] = 1.
Compute face coefficients using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)), and analogously for all other faces.
Assemble the sparse linear system A*u_interior = b for the (N-1)*(N-1) interior unknowns only, with b being a vector of ones.
Solve the linear system using the Conjugate Gradient (CG) method with a relative residual tolerance of 1e-10.
Optionally apply a Jacobi preconditioner (diagonal of A) to accelerate convergence.
After solving, set boundary values to zero and assemble the full (N+1)x(N+1) solution grid.
Compute and print min(u) over the full grid.
Compute and print max(u) over the full grid.
Compute and print the discrete residual norm ||A*u_interior - b||_2 / ||b||_2 for the interior system.
