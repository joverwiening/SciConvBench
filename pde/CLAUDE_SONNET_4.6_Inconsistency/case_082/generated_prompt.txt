Solve the PDE u_tt = (1.0)**2 * u_xx numerically using Python and save the required outputs.

The PDE is the 1D wave equation with wave speed c = 1.0.
The spatial domain is x in [0, 1] (closed interval).
The time domain is t in [0, 1.0].

Use Nx = 400 uniform intervals, giving Nx+1 = 401 grid points including both endpoints.
Set dx = 1.0 / 400.
Set dt0 = 0.9 * dx / c where c = 1.0.
Set Nt = ceil(1.0 / dt0) and then dt = 1.0 / Nt so the final time T = 1.0 is hit exactly.

The grid points are x_i = i * dx for i = 0, 1, ..., 400.

Apply Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 at every time step.

Set the initial condition u(x, 0) = sin(pi * x) at all interior and boundary grid points.
Set the initial velocity u_t(x, 0) = 0 everywhere.

Compute u at the first time step using the Taylor start formula:
u^1_i = u^0_i + dt * v0_i + 0.5 * dt**2 * c**2 * (u^0_{i-1} - 2*u^0_i + u^0_{i+1}) / dx**2 for interior points.
Set boundary points of u^1 to 0.

Advance from time step 1 to Nt using the standard leapfrog scheme:
u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (c * dt / dx)**2 * (u^n_{i-1} - 2*u^n_i + u^n_{i+1}) for interior points.
Set boundary points to 0 at each step.

After reaching T = 1.0, compute the exact solution u_exact_i = cos(1.0 * pi * 1.0) * sin(pi * x_i) on the same grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.
Print the max absolute error max(|u - u_exact|) and the L2 error sqrt(sum((u - u_exact)**2) * dx).

Save a file named "solution_agent_wave_01.npz" containing the 1D array x (length 401), the 1D array u (length 401), and scalar metadata T = 1.0, dx, and dt.
Save a line plot of u(x, T) versus x as "solution_agent_wave_01.png" with labeled axes.
