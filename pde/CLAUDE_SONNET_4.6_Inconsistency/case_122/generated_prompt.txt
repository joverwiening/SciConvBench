Solve the 1D linear reaction-diffusion PDE numerically using the specifications below.

The PDE is u_t = q1*u_xx + q2*u.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
Set q1 = 0.01 and q2 = -1.0.
The periodic boundary condition is u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
The exact solution for verification is u(x,t) = exp(q2*t) * exp(-q1*(2*pi)**2*t) * sin(2*pi*x).

Use a uniform periodic spatial grid with Nx = 256 points on [0, 1).
Set dx = 1/Nx and place grid points at x_j = j*dx for j = 0, 1, ..., Nx-1.
Use 2nd-order central differences for u_xx with periodic wrap-around at the boundaries.

Use deterministic operator splitting with commuting operators (linear constant coefficients).
Each time step consists of two sub-steps applied in sequence.
Sub-step 1 is a Crank-Nicolson diffusion step: solve (I - 0.5*dt*q1*L) u_tilde = (I + 0.5*dt*q1*L) u^n, where L is the periodic 2nd-order central-difference Laplacian matrix.
Sub-step 2 is a reaction exact step: u^{n+1} = exp(q2*dt) * u_tilde.

Use dt = 0.001 and Nt = 500 time steps so the final time T = 0.5 is reached exactly.

Implement the Crank-Nicolson linear solve efficiently using the fact that L is a circulant matrix; apply the solve via the discrete Fourier transform (numpy.fft.fft/ifft) or by constructing and solving the tridiagonal periodic system directly.
At each time step, first apply the CN diffusion solve to get u_tilde, then multiply by exp(q2*dt) to get u^{n+1}.

After completing all Nt steps, compute u(x, T=0.5) on the periodic grid.

Evaluate the exact solution u_exact(x) = exp(q2*0.5) * exp(-q1*(2*pi)**2*0.5) * sin(2*pi*x) on the same grid.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2)*dx).
