Solve the 1D Viscous Burgers equation numerically with the following specifications.

The PDE is u_t + d/dx(0.5*u**2) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0], so T = 1.0.
The parameter nu = 0.01.
The initial condition is u(x, 0) = sin(2*pi*x).
No closed-form reference solution is required.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Define x_j = j * dx for j = 0, ..., Nx-1 where dx = 1/Nx.

Use Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): apply a finite-volume update for the inviscid Burgers equation u_t + d/dx(0.5*u**2) = 0 using Rusanov (local Lax-Friedrichs) flux. Define f(u) = 0.5*u**2. For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing), compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j, compute F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]), then set u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus). Replace u with u_new after the advection substep.

Step C (diffusion half-step again): repeat Step A identically.

Set the time step using CFL = 0.4 based on an estimated max speed of 1.0. Compute dt0 = CFL * dx / 1.0. Compute Nt = ceil(T / dt0). Reset dt = T / Nt so the simulation hits T = 1.0 exactly.

At T = 1.0, compute u(x, T) on the periodic grid.

Save a file named "solution_pdebench_burgers_nu0p01.npz" containing the following arrays and scalars: x (1D, length Nx), u (1D, length Nx), nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_burgers_nu0p01.png".

Print the following diagnostics at T: min(u), max(u), the discrete mean value mean(u) (which should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2) * dx).
