Solve the Van der Pol ODE system numerically using the specifications below.

The ODE system is:
dx/dt = y
dy/dt = mu*(1 - x**2)*y - x

The time domain is t in [0.0, 20.0].

The parameter mu equals 4.

The initial conditions are x(0.0) = 1.0 and y(0.0) = 0.0.

Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.01 and Nt = 2000 steps so the final time 20.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n*0.01 for n = 0 to 2000 inclusive, giving Nt+1 = 2001 time points.

At each RK4 step from t_n to t_{n+1}, compute:
k1 = f(t_n, Y_n)
k2 = f(t_n + dt/2, Y_n + dt/2 * k1)
k3 = f(t_n + dt/2, Y_n + dt/2 * k2)
k4 = f(t_n + dt, Y_n + dt * k3)
Y_{n+1} = Y_n + (dt/6)*(k1 + 2*k2 + 2*k3 + k4)

Use ^ as exponentiation in math and ** in Python code.

Save a file named "solution_molk_007.npz" containing:
- t: 1D array of length 2001 with values t_n = n*0.01 for n = 0..2000
- Y: 2D array of shape [2001, 2] with columns ordered as [x, y]
- the scalar parameter mu = 4

Save a line plot of each state variable (x and y) versus t as "solution_molk_007.png", with both states shown on the same figure or as subplots.

Print the final state values x(20.0) and y(20.0) at the end of the simulation.

Print the minimum and maximum of each state variable over all 2001 time points.
