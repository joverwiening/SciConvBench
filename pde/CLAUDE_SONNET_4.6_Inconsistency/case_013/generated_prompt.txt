Solve the 1D viscous Burgers equation numerically and save the results.

The PDE is u_t + u*u_x = 0.01*u_xx, equivalently written in conservative form as u_t + (0.5*u**2)_x = 0.01*u_xx.

The spatial domain is x in [0,1) with periodic boundary conditions. The time domain is t in [0, 0.5].

Use nu = 0.01.

Use Nx = 800 uniformly spaced grid points on [0,1) with no duplicated endpoint. Set dx = 1.0/800. Set x_i = i*dx for i = 0, 1, ..., 799.

Use dt = 1e-4 and Nt = 5000 time steps so that T = 0.5 is reached exactly.

Apply the initial condition u(x, 0) = sin(2*pi*x) at all 800 grid points.

Discretize convection using the Rusanov (local Lax-Friedrichs) flux in conservative finite-difference form.
Compute the interface flux F_{i+1/2} = 0.5*(f(u_i) + f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1} - u_i), where f(u) = 0.5*u**2 and alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
Approximate (f(u))_x at point i as (F_{i+1/2} - F_{i-1/2}) / dx.
Use periodic wrap-around indexing so that index -1 maps to index Nx-1 and index Nx maps to index 0.

Discretize diffusion using the 2nd-order central difference u_xx ≈ (u_{i+1} - 2*u_i + u_{i-1}) / dx**2 with periodic wrap-around indexing.

Use 1st-order IMEX time integration: treat convection explicitly and diffusion implicitly.
At each time step, form the right-hand side rhs_i = u_i^n - dt * conv_term_i, where conv_term_i = (F_{i+1/2}^n - F_{i-1/2}^n) / dx.
Form the linear system (I - dt*nu*L) * u^{n+1} = rhs, where L is the Nx-by-Nx sparse tridiagonal matrix representing the periodic second-difference operator with L_{i,i} = -2/dx**2, L_{i,i+1} = 1/dx**2, L_{i,i-1} = 1/dx**2, and periodic wrap-around entries L_{0,Nx-1} = 1/dx**2 and L_{Nx-1,0} = 1/dx**2.
Solve this sparse linear system at every time step using scipy.sparse.linalg.spsolve.

Build the matrix (I - dt*nu*L) once before the time loop since it does not change between steps.

After completing all Nt steps, compute u(x, T=0.5) on the 800-point grid.
