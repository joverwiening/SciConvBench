Solve the 2D advection-diffusion PDE numerically using the IMEX scheme described below and save the results.

The PDE is u_t + 1.0*u_x + 0.5*u_y = 0.01*(u_xx + u_yy).
The spatial domain is [0,1) x [0,1) with periodic boundary conditions in both x and y.
The time domain is t in [0, 0.5].
Parameters are a=1.0, b=0.5, D=0.01.
The initial condition is u(x,y,0) = sin(2*pi*x)*cos(2*pi*y).
The exact solution is u(x,y,t) = exp(-0.01*8*pi**2*t)*sin(2*pi*(x-1.0*t))*cos(2*pi*(y-0.5*t)).

Use Nx=Ny=400 uniform grid points in each direction with no duplicated endpoint.
Set dx = dy = 1.0/400.
Set x_i = i*dx for i=0..399 and y_j = j*dy for j=0..399.
Use dt=0.001 and Nt=500 steps so that T=0.5 is reached exactly.

Use a first-order IMEX time integration scheme where advection is treated explicitly and diffusion is treated implicitly.
Each time step solves the linear system (I - dt*D*L) u^{n+1} = u^n - dt*(a*Dx_up*u^n + b*Dy_up*u^n).
L is the 5-point periodic Laplacian discretized with 2nd-order central differences.
Dx_up is the 1st-order upwind difference operator in x using the sign of a=1.0 (so backward difference: (u_i - u_{i-1})/dx).
Dy_up is the 1st-order upwind difference operator in y using the sign of b=0.5 (so backward difference: (u_j - u_{j-1})/dy).
Construct the operators as sparse matrices using scipy.sparse with periodic boundary conditions enforced via wrap-around indices.
Solve the sparse linear system each step using scipy.sparse.linalg.spsolve.

Flatten u to a 1D array of length Nx*Ny for the linear solve, using row-major (C) order so that index = j*Nx + i corresponds to grid point (x_i, y_j).
Reshape back to 2D array of shape (Ny, Nx) after each step so that u[j,i] = u(x_i, y_j).

After Nt=500 steps, compute the numerical solution u(x,y,T=0.5) on the full 2D grid.
Compute the exact solution on the same grid using the formula above.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy).
Print the max absolute error and the L2 error between the numerical and exact solutions.
