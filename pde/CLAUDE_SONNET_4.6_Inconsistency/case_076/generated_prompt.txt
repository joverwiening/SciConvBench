Solve the Poisson PDE numerically using the following specifications.

PDE: u_xx + u_yy = f(x,y), where f(x,y) = -2*(y*(1-y) + x*(1-x)).

Domain: (x,y) in [0,1] x [0,1].

Boundary conditions: Dirichlet on all four edges. Set u = x*(1-x)*y*(1-y) on all boundary nodes.

Exact/reference solution: u(x,y) = x*(1-x)*y*(1-y).

Use a uniform grid with Nx=Ny=120 intervals in each direction, giving Nx+1=121 grid points per direction including both endpoints. Set dx=dy=1/120. Set x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.

Discretize the Laplacian using the standard 5-point finite difference stencil (2nd-order central differences) on the interior nodes only.

Assemble the resulting sparse linear system for the interior nodes (i=1..119, j=1..119).

Incorporate the Dirichlet boundary values into the right-hand side when assembling the system.

Solve the sparse linear system using scipy.sparse.linalg.spsolve.

After solving, fill in the full (121x121) solution array including boundary values.

Store the solution as a 2D array u with shape (len(y), len(x)) so that u[j,i] = u(x_i, y_j).

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy).

Compute the reference solution on the same grid as u_exact[j,i] = x_i*(1-x_i)*y_j*(1-y_j).

Compute and print the max absolute error max(|u - u_exact|) and the L2 error sqrt(sum((u - u_exact)**2)*dx*dy).
