Solve the heat equation u_t = 0.1 * u_xx numerically using the Crank-Nicolson method and save the results.

The PDE is u_t = 0.1 * u_xx with alpha = 0.1.
The spatial domain is x in [0, 1] (closed interval) and the time domain is t in [0, 0.5].
Use Nx = 200 uniform intervals, giving 201 grid points including both endpoints x=0 and x=1.
Set dx = 1/200 = 0.005.
Use dt = 0.001 and run for 500 time steps to reach T = 0.5.
Apply Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 for all t.
Set the initial condition u(x, 0) = sin(pi * x).
Use second-order central differences for u_xx on interior points.
Discretize time with the Crank-Nicolson scheme: form a tridiagonal linear system at each time step combining the current and next time level with equal weight 0.5.
Fix boundary nodes at 0 at every time step by not updating them (or by enforcing them in the linear system).
At T = 0.5, compute the numerical solution u(x, T) on all 201 grid points.
Compute the exact solution u_exact(x, T) = exp(-0.1 * pi**2 * T) * sin(pi * x) on the same grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
