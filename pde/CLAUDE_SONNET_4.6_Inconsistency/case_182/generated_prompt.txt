Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.
Use Python with NumPy and Matplotlib.
Interpret '^' as exponentiation and use '**' for powers in Python code.

Domain: x in [0, 1) with periodic boundary, t in [0, 1.0].
Parameters: nu = 1.0, rho = 2.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Spatial grid: Use Nx = 512 uniform points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx and x_j = j*dx for j = 0, 1, ..., Nx-1.
Time grid: Use fixed dt = 0.001 and Nt = 1000 steps so that T = 1.0 is reached exactly.

Numerical method: Strang splitting for each full time step dt.

Step A (diffusion half-step, duration dt/2): Compute u_hat = FFT(u).
Compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Step B (reaction full step, duration dt): Apply the exact logistic ODE solution pointwise.
For each grid point compute u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).

Step C (diffusion half-step again): Repeat Step A identically.

Repeat Steps A, B, C for all Nt = 1000 time steps.

After all steps, compute the final solution u(x, T=1.0) on the periodic grid.

Save a file named "solution_pdebench_reacdiff_nu1_rho2.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), and scalar values nu, rho, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu1_rho2.png" with x on the horizontal axis and u on the vertical axis.

Print the following scalar diagnostics at T: min(u), max(u), mean(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx).

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
nu = 1.0
rho = 2.0
T = 1.0
Nx = 512
Nt = 1000
dt = T / Nt
dx = 1.0 / Nx

# Spatial grid: x_j = j*dx for j=0,...,Nx-1 on [0,1) periodic
x = np.arange(Nx) * dx

# Initial condition
u = 0.25 + 0.1 * np.sin(2 * np.pi * x)

# Wavenumbers for FFT on periodic domain
k = 2 * np.pi * np.fft.fftfreq(Nx, d=dx)

# Precompute diffusion factors for half-step and full-step
diff_half = np.exp(-nu * k**2 * (dt / 2))

# Precompute reaction exact update factor
exp_rho_dt = np.exp(rho * dt)

def diffusion_half_step(u):
    u_hat = np.fft.fft(u)
    u_hat *= diff_half
    return np.fft.ifft(u_hat).real

def reaction_full_step(u):
    return (u * exp_rho_dt) / (1.0 + u * (exp_rho_dt - 1.0))

# Time integration using Strang splitting: A -> B -> C
for n in range(Nt):
    u = diffusion_half_step(u)   # Step A: diffusion half-step
    u = reaction_full_step(u)    # Step B: reaction full-step
    u = diffusion_half_step(u)   # Step C: diffusion half-step

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
u_mean = np.mean(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"mean(u)  = {u_mean:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# Save .npz file
np.savez(
    "solution_pdebench_reacdiff_nu1_rho2.npz",
    x=x,
    u=u,
    nu=nu,
    rho=rho,
    T=T,
    dx=dx,
    dt=dt,
    Nx=Nx,
    Nt=Nt
)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.5, color='steelblue')
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"1D Reaction-Diffusion solution at T={T}, nu={nu}, rho={rho}")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_pdebench_reacdiff_nu1_rho2.png", dpi=150)
plt.close()

print("Files saved: solution_pdebench_reacdiff_nu1_rho2.npz and solution_pdebench_reacdiff_nu1_rho2.png")
```
