Solve the PDE u_t = -k * d/dx(cos(u)) numerically using the specifications below.

Use Python with NumPy for all computations.

PDE is u_t = -k * partial_x(cos(u)) where k = 1.0.

The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 0.2].

Use a uniform periodic grid with Nx = 1024 points.
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.

The initial condition is u(x, 0) = 0.5 * sin(2 * pi * x).

Use conservative finite-volume spatial discretization with Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u) = cos(u).
The Rusanov wave speed at each interface is alpha = max(|sin(u_L)|, |sin(u_R)|), which is bounded by 1 since |sin| <= 1.
The Rusanov numerical flux at interface between cell j and cell j+1 is: F_{j+1/2} = 0.5 * (f(u_j) + f(u_{j+1})) - 0.5 * alpha_{j+1/2} * (u_{j+1} - u_j).
The spatial derivative term for cell j is -(F_{j+1/2} - F_{j-1/2}) / dx.
Use periodic indexing so that cell index -1 wraps to Nx-1 and cell index Nx wraps to 0.

Use SSP-RK2 (Shu-Osher 2-stage) for time integration.
Stage 1: u_star = u^n + dt * L(u^n).
Stage 2: u^{n+1} = 0.5 * u^n + 0.5 * (u_star + dt * L(u_star)).
Here L(u) denotes the spatial right-hand side operator.

Compute the time step as follows.
Set CFL = 0.2.
Set dt0 = CFL * dx / 1.0.
Set Nt = ceil(T / dt0) where T = 0.2.
Set dt = T / Nt.

Advance the solution from t = 0 to t = T = 0.2 using Nt steps of SSP-RK2.

After completing the time integration, compute the following diagnostics and print them.
Print min(u), max(u), mean(u), and the discrete L2 norm defined as sqrt(sum(u**2) * dx) at T = 0.2.
No exact solution is provided, so skip the error computation step.
