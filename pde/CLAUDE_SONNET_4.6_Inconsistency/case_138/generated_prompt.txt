Solve the 1D advection PDE numerically with the following specifications.

PDE: u_t + beta * u_x = 0

Spatial domain: x in [0, 1), periodic. Temporal domain: t in [0, 2.0].

Parameter: beta = 0.7.

Boundary condition: Periodic, u(0, t) = u(1, t) for all t.

Initial condition: u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

Reference solution: u(x, t) = u0((x - beta*t) mod 1), where u0 is the initial condition.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1). Set dx = 1/Nx. Define grid points x_j = j*dx for j = 0, 1, ..., Nx-1.

Use 1st-order upwind finite difference for u_x. Since beta = 0.7 > 0, use the left-sided (backward) difference: u_x at j approximated by (u_j - u_{j-1}) / dx, with periodic indexing so index -1 wraps to index Nx-1.

Use explicit forward Euler time integration.

Set CFL = 0.5. Compute dt = CFL * dx / abs(beta). Compute Nt = ceil(T / dt) where T = 2.0. Reset dt = T / Nt so the solver hits T = 2.0 exactly.

At each time step, update: u_j^{n+1} = u_j^n - beta * dt/dx * (u_j^n - u_{j-1}^n) for j = 0, ..., Nx-1, using periodic indexing.

After completing all Nt steps, the solution u represents u(x, T=2.0).

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 2.0.

Evaluate the reference solution u_ref_j = u0((x_j - beta*T) mod 1) on the same grid. Compute and print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx).

Save a file named "solution_pdebench_advection_beta0p7.npz" containing: array x of length Nx, array u of length Nx, and scalars beta, T, dx, dt, Nx, Nt.

Save a line plot of u versus x at T = 2.0 as "solution_pdebench_advection_beta0p7.png" with appropriate axis labels and a title indicating the solution at T = 2.0.
