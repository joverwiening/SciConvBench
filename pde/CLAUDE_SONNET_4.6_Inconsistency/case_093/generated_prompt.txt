Solve the 1D wave equation u_tt = (2.0)^2 * u_xx numerically and save results.

The PDE is u_tt = 4.0 * u_xx on x in [0,1], t in [0,0.5].
The wave speed is c = 2.0 (from the coefficient (2.0)^2, so c=2.0 in the PDE; note the parameter section says c=4 but the PDE coefficient is (2.0)^2=4.0, meaning c=2.0 for CFL purposes as c^2=4.0).
Use c=2.0 for CFL calculation since the PDE is u_tt = c^2 * u_xx with c=2.0.
Use Nx=400 uniform intervals on [0,1], giving Nx+1=401 grid points.
Set dx = 1.0/400.
Set dt0 = 0.9 * dx / c = 0.9 * (1/400) / 2.0.
Set Nt = ceil(0.5 / dt0) and dt = 0.5 / Nt so the final time T=0.5 is hit exactly.
Build x array as x_i = i * dx for i = 0, 1, ..., 400.
Apply Dirichlet boundary conditions u=0 at x=0 and x=1 at every time step.
Set initial condition u^0_i = sin(pi * x_i) for all i.
Set initial velocity v0_i = 0 for all i.
Compute u^1 using the Taylor start: u^1_i = u^0_i + dt * v0_i + 0.5 * dt**2 * c**2 * (u^0_{i-1} - 2*u^0_i + u^0_{i+1}) / dx**2 for interior points.
Enforce u^1_0 = 0 and u^1_400 = 0.
Advance from time step 1 to Nt using the leapfrog scheme: u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (c*dt/dx)**2 * (u^n_{i-1} - 2*u^n_i + u^n_{i+1}) for interior points.
Enforce Dirichlet BC u=0 at both boundary nodes at every time step.
After Nt steps the solution is at T=0.5.
Compute the exact solution u_exact_i = cos(2.0 * pi * T) * sin(pi * x_i) on the same grid.
Print min(u), max(u), and discrete L2 norm sqrt(sum(u**2) * dx) at T=0.5.
Print max absolute error max(|u - u_exact|) and L2 error sqrt(sum((u - u_exact)**2) * dx).
Save file "solution_agent_wave_12.npz" containing arrays x (shape 401), u (shape 401), and scalar metadata T=0.5, dx, dt.
Save a line plot of u(x, T=0.5) versus x as "solution_agent_wave_12.png".

Here is the Python code implementing the above specification:

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
c = 2.0          # wave speed (PDE: u_tt = c^2 * u_xx, c^2 = 4.0)
T = 0.5
Nx = 400
dx = 1.0 / Nx

# Time stepping
dt0 = 0.9 * dx / c
Nt = int(np.ceil(T / dt0))
dt = T / Nt
CFL = c * dt / dx
print(f"Nx={Nx}, dx={dx:.6f}, Nt={Nt}, dt={dt:.8f}, CFL={CFL:.6f}")

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # x_i = i*dx, i=0..Nx

# Initial condition
u0 = np.sin(np.pi * x)
v0 = np.zeros(Nx + 1)

# Taylor start for u^1
r2 = (c * dt / dx) ** 2
u_xx0 = np.zeros(Nx + 1)
u_xx0[1:-1] = (u0[:-2] - 2.0 * u0[1:-1] + u0[2:]) / dx**2

u_prev = u0.copy()
u_curr = u0 + dt * v0 + 0.5 * dt**2 * c**2 * u_xx0
# Enforce Dirichlet BC
u_curr[0] = 0.0
u_curr[-1] = 0.0

# Leapfrog time integration
for n in range(1, Nt):
    u_next = np.empty(Nx + 1)
    u_next[1:-1] = (2.0 * u_curr[1:-1] - u_prev[1:-1]
                    + r2 * (u_curr[:-2] - 2.0 * u_curr[1:-1] + u_curr[2:]))
    u_next[0] = 0.0
    u_next[-1] = 0.0
    u_prev = u_curr
    u_curr = u_next

u = u_curr

# Exact solution at T
u_exact = np.cos(2.0 * np.pi * T) * np.sin(np.pi * x)

# Diagnostics
print(f"min(u)       = {np.min(u):.8f}")
print(f"max(u)       = {np.max(u):.8f}")
L2_u = np.sqrt(np.sum(u**2) * dx)
print(f"L2 norm(u)   = {L2_u:.8f}")

max_err = np.max(np.abs(u - u_exact))
L2_err  = np.sqrt(np.sum((u - u_exact)**2) * dx)
print(f"Max abs error = {max_err:.6e}")
print(f"L2 error      = {L2_err:.6e}")

# Save npz
np.savez("solution_agent_wave_12.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_wave_12.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x, T={T})")
ax.plot(x, u_exact, '--', label="Exact solution")
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"Wave equation solution at T={T}")
ax.legend()
plt.tight_layout()
plt.savefig("solution_agent_wave_12.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_12.png")
```
