Solve the PDE u_t = -k * d/dx( (1/3)*u^3 ) numerically using the specifications below.

Use Python with NumPy and Matplotlib.

Use k = 1.0.

The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 0.2].

Use Nx = 1024 grid points on [0, 1) with no duplicated endpoint.
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.

The flux function is f(u) = (1/3) * u**3.
The flux derivative is f_prime(u) = u**2.

Apply the initial condition u(x, 0) = 0.5 * sin(2 * pi * x).

Use a conservative finite-volume spatial discretization with Rusanov (local Lax-Friedrichs) numerical flux at each cell interface.
For the Rusanov flux at interface between cell j and cell j+1, compute F_{j+1/2} = 0.5*(f(u_j) + f(u_{j+1})) - 0.5*alpha*(u_{j+1} - u_j), where alpha = max(|f_prime(u_j)|, |f_prime(u_{j+1})|).
Enforce periodicity by wrapping indices: the left neighbor of j=0 is j=Nx-1, and the right neighbor of j=Nx-1 is j=0.
The spatial residual for cell j is L(u)_j = -(1/dx) * (F_{j+1/2} - F_{j-1/2}).

Use SSP-RK2 (Heun's method) for time integration.
Stage 1: u_star = u^n + dt * L(u^n).
Stage 2: u^{n+1} = 0.5 * u^n + 0.5 * (u_star + dt * L(u_star)).

Compute the time step as follows.
Set CFL = 0.2.
Estimate max_speed = max(|u**2|) over the initial condition; since |u| <= 0.5 initially, max_speed = 0.25 if the computed value is smaller.
Set dt0 = CFL * dx / max_speed.
Set Nt = ceil(0.2 / dt0) as an integer.
Set dt = 0.2 / Nt.

Advance the solution from t=0 to T=0.2 using Nt steps of SSP-RK2.

After reaching T=0.2, compute and print the following diagnostics.
Print min(u), max(u), mean(u), and the discrete L2 norm defined as sqrt(sum(u**2) * dx).

Save a line plot of u(x, T=0.2) versus x as "solution_molk_028.png".

Below is the complete Python code implementing all of the above.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
k = 1.0
T = 0.2
Nx = 1024
dx = 1.0 / Nx
x = np.array([j * dx for j in range(Nx)])

# Initial condition
u = 0.5 * np.sin(2.0 * np.pi * x)

# Flux and flux derivative
def flux(u):
    return (1.0 / 3.0) * u**3

def flux_prime(u):
    return u**2

# Rusanov flux at all interfaces (vectorized)
# Interface j+1/2 is between cell j and cell j+1
def rusanov_flux(u):
    u_left = u                          # cell j
    u_right = np.roll(u, -1)            # cell j+1 (periodic)
    f_left = flux(u_left)
    f_right = flux(u_right)
    alpha = np.maximum(np.abs(flux_prime(u_left)), np.abs(flux_prime(u_right)))
    return 0.5 * (f_left + f_right) - 0.5 * alpha * (u_right - u_left)

# Spatial residual L(u)
def L(u):
    F_right = rusanov_flux(u)           # F_{j+1/2} for each j
    F_left = np.roll(F_right, 1)        # F_{j-1/2} for each j (shift right by 1)
    return -(1.0 / dx) * (F_right - F_left)

# Time step calculation
max_speed = np.max(np.abs(flux_prime(u)))
max_speed = max(max_speed, 0.25)        # ensure at least 0.25 as per spec
CFL = 0.2
dt0 = CFL * dx / max_speed
Nt = int(np.ceil(T / dt0))
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, max_speed={max_speed:.6f}")

# SSP-RK2 time integration
for n in range(Nt):
    Lu = L(u)
    u_star = u + dt * Lu
    Lu_star = L(u_star)
    u = 0.5 * u + 0.5 * (u_star + dt * Lu_star)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
u_mean = np.mean(u)
u_l2 = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.6e}")
print(f"max(u)  = {u_max:.6e}")
print(f"mean(u) = {u_mean:.6e}")
print(f"L2 norm = {u_l2:.6e}")

# Save npz
np.savez("solution_molk_028.npz",
         x=x,
         u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         Nx=np.int64(Nx),
         k=np.float64(k))

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=0.2)")
ax.set_title("Solution at T=0.2")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_molk_028.png", dpi=150)
plt.close()

print("Saved solution_molk_028.npz and solution_molk_028.png")
```
