Solve the Klein-Gordon PDE numerically using the specifications below.

The PDE is u_tt - (1.2)**2 * u_xx + (0.8)**2 * u = 0.
The spatial domain is x in [0, 1] (closed interval). The time domain is t in [0, 0.7].
Parameters are c = 1.2 and m = 0.8.
Boundary conditions are Dirichlet: u = 0 at x = 0 and x = 1 for all t.
Initial condition is u(x, 0) = sin(3*pi*x) and u_t(x, 0) = 0.
The exact reference solution is u(x, t) = cos(sqrt((1.2*3*pi)**2 + (0.8)**2) * t) * sin(3*pi*x).

Apply boundary conditions u1[0] = 0 and u1[600] = 0 after the Taylor start.
