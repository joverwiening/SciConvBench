Solve the Allen-Cahn PDE numerically in Python and save the required output files.

The PDE is u_t = (0.02)**2 * u_xx + u - u**3.
The spatial domain is x in [0,1] (closed interval). The time domain is t in [0, 1.0].
The parameter epsilon = 0.02.

Use Nx=800 uniform intervals, giving 801 grid points including both endpoints.
Set dx = 1.0/800.
Set x_i = i*dx for i = 0, 1, ..., 800.

Use dt = 0.0005 and run for 2000 time steps to reach T = 1.0.

Apply the initial condition u(x,0) = 0.05*sin(2*pi*x) + 0.02*sin(6*pi*x) at all 801 grid points.

Enforce zero Neumann boundary conditions u_x(0,t)=0 and u_x(1,t)=0 using ghost points.
For the ghost point to the left of x=0, set u_ghost_left = u[1] (mirror of u[1] about x=0).
For the ghost point to the right of x=1, set u_ghost_right = u[Nx-1] (mirror of u[Nx-1] about x=Nx).
This means the second derivative at i=0 uses (u[1] - 2*u[0] + u_ghost_left) / dx**2 = 2*(u[1]-u[0])/dx**2, and similarly at i=Nx.

Use a semi-implicit time integration scheme each step:
(u_new - u_old)/dt = epsilon**2 * u_xx_new + u_old - u_old**3.
Rearrange to: u_new - dt*epsilon**2*u_xx_new = u_old + dt*(u_old - u_old**3).
Discretize u_xx_new using 2nd-order central differences on the interior and ghost-point-extended stencil at the boundaries.
This produces a tridiagonal linear system of size 801x801. Solve it each time step using a tridiagonal (sparse) solver.

Assemble the tridiagonal matrix A where the diagonal entry is (1 + 2*dt*epsilon**2/dx**2) and the off-diagonal entries are (-dt*epsilon**2/dx**2), with the boundary rows modified to reflect the ghost-point Neumann condition (the boundary row diagonal is (1 + 2*dt*epsilon**2/dx**2) and the single neighbor coefficient is -2*dt*epsilon**2/dx**2, since both ghost and real neighbor contribute equally).

The right-hand side vector at each step is u_old + dt*(u_old - u_old**3).

After 2000 steps, compute the solution u(x, T=1.0) on the 801-point grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.
