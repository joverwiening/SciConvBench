Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically, but note the PDE coefficient is 1.0 while the wave speed parameter is c = 2.0; use c = 2.0 for CFL and the leapfrog update (the PDE effectively uses c=2 as stated in parameters).
The spatial domain is x in [0,1] with Nx = 800 uniform intervals giving 801 grid points.
Set dx = 1.0 / 800.
The time domain is t in [0, 1.0].
Compute dt0 = 0.9 * dx / c where c = 2.0.
Set Nt = ceil(1.0 / dt0) and dt = 1.0 / Nt so the final time T = 1.0 is hit exactly.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1 at every time step.
Set the initial condition u(x, 0) = exp(-200 * (x - 0.5)**2) for all interior and boundary grid points.
Set the initial velocity u_t(x, 0) = 0 everywhere.
Compute the first time step using the Taylor start: u1 = u0 + dt * v0 + 0.5 * dt**2 * c**2 * u_xx0, where u_xx0 is computed via 2nd-order central differences on the interior nodes, and v0 = 0.
Enforce u1[0] = 0 and u1[800] = 0 after the Taylor start.
For all subsequent time steps n >= 1, advance using the leapfrog scheme: u_new[i] = 2*u[i] - u_old[i] + (c*dt/dx)**2 * (u[i+1] - 2*u[i] + u[i-1]) for interior nodes i = 1 to 799.
Enforce u_new[0] = 0 and u_new[800] = 0 at every leapfrog step.
Continue stepping until t = T = 1.0 (exactly Nt steps total from t=0).
After reaching T, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Save a file named "solution_agent_wave_18.npz" containing arrays x (shape 801), u (shape 801), and scalar metadata T, dx, dt.
Save a line plot of u(x, T) as "solution_agent_wave_18.png" with x on the horizontal axis and u on the vertical axis.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
c = 2.0
T = 1.0
Nx = 800
dx = 1.0 / Nx
dt0 = 0.9 * dx / c
Nt = int(np.ceil(T / dt0))
dt = T / Nt
r = c * dt / dx  # CFL number

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL={r:.6f}")

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 801 points

# Initial condition
u0 = np.exp(-200.0 * (x - 0.5)**2)
v0 = np.zeros(Nx + 1)

# Enforce Dirichlet BCs on initial condition
u0[0] = 0.0
u0[Nx] = 0.0

# Compute u_xx at t=0 for interior nodes using central differences
def compute_uxx(u, dx, Nx):
    uxx = np.zeros(Nx + 1)
    uxx[1:Nx] = (u[2:Nx+1] - 2.0*u[1:Nx] + u[0:Nx-1]) / dx**2
    return uxx

uxx0 = compute_uxx(u0, dx, Nx)

# Taylor start: u^1
u1 = u0 + dt * v0 + 0.5 * dt**2 * c**2 * uxx0
# Enforce BCs
u1[0] = 0.0
u1[Nx] = 0.0

# Leapfrog time integration
u_old = u0.copy()
u_cur = u1.copy()

r2 = r**2  # (c*dt/dx)^2

for n in range(1, Nt):
    u_new = np.empty(Nx + 1)
    # Interior nodes
    u_new[1:Nx] = (2.0 * u_cur[1:Nx]
                   - u_old[1:Nx]
                   + r2 * (u_cur[2:Nx+1] - 2.0*u_cur[1:Nx] + u_cur[0:Nx-1]))
    # Dirichlet BCs
    u_new[0] = 0.0
    u_new[Nx] = 0.0
    # Advance
    u_old = u_cur
    u_cur = u_new

u_final = u_cur

# Diagnostics
u_min = np.min(u_final)
u_max = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)
print(f"min(u) = {u_min:.6e}")
print(f"max(u) = {u_max:.6e}")
print(f"L2 norm = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_wave_18.npz",
         x=x,
         u=u_final,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))
print("Saved solution_agent_wave_18.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_final, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Wave equation solution at T={T}")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_wave_18.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_18.png")
```
