Solve the 2D wave equation u_tt = (1.0)**2 * (u_xx + u_yy) numerically with the following specifications.

The PDE is u_tt = u_xx + u_yy on the domain (x,y) in [0,1) x [0,1), periodic in both x and y, for t in [0, 0.5].
The parameter c = 2 appears in the CFL condition but note the wave speed in the PDE coefficient is 1.0; use c = 2 for the CFL dt calculation as specified.
Use a uniform periodic grid with Nx = Ny = 128 points on [0,1) x [0,1) with no duplicated endpoints.
Set dx = dy = 1/128.
Compute dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)) where c = 2.
Set Nt = ceil(0.5 / dt0) and then dt = 0.5 / Nt so the final time T = 0.5 is hit exactly.
Define grid points x_i = i * dx for i = 0..127 and y_j = j * dy for j = 0..127.
Apply initial condition u(x,y,0) = cos(2*pi*x)*cos(2*pi*y).
Apply initial time derivative u_t(x,y,0) = 0.
Use a Taylor start for the first time step: u(x,y,dt) = u(x,y,0) + dt*u_t(x,y,0) + 0.5*dt**2 * (u_xx + u_yy) at t=0, where u_xx and u_yy are computed using 2nd-order central differences with wrap-around (periodic).
For all subsequent time steps use the 2nd-order central-in-time leapfrog scheme: u_new = 2*u_curr - u_old + dt**2 * (u_xx + u_yy), where spatial second derivatives use 2nd-order central differences with wrap-around.
Compute u_xx[j,i] = (u[j, i+1] - 2*u[j,i] + u[j, i-1]) / dx**2 with indices taken modulo Nx.
Compute u_yy[j,i] = (u[j+1, i] - 2*u[j,i] + u[j-1, i]) / dy**2 with indices taken modulo Ny.
After advancing to T = 0.5, compute the exact solution u_exact[j,i] = cos(2*pi*x_i)*cos(2*pi*y_j)*cos(1.0*2*pi*sqrt(2)*0.5).
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) of the numerical solution at T.
Print the max absolute error max(|u_numerical - u_exact|) and the L2 error sqrt(sum((u_numerical - u_exact)**2)*dx*dy).
