Solve the 2D Darcy flow PDE numerically as described below.

The PDE is -div(a(x,y) grad(u(x,y))) = 1 on the domain (0,1) x (0,1).
The coefficient field is a(x,y) = 1 + 10.0 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply homogeneous Dirichlet boundary conditions u = 0 on the entire boundary of (0,1) x (0,1).
Ignore the periodic boundary condition statement; it contradicts the Dirichlet condition, and the Dirichlet condition takes precedence as it is more specifically described for this problem.

Use a uniform Cartesian grid with N = 128 intervals in each direction.
The grid has N+1 = 129 points in each direction including both endpoints.
Set dx = dy = 1/N.
Define x_i = i*dx for i = 0, 1, ..., N and y_j = j*dy for j = 0, 1, ..., N.

Discretize the PDE at interior nodes (i = 1 to N-1, j = 1 to N-1) using second-order finite differences with face-centered harmonic averaging.
The discrete equation at interior node (i, j) is:
-(1/dx**2) * [a(i+1/2,j)*(u[i+1,j]-u[i,j]) - a(i-1/2,j)*(u[i,j]-u[i-1,j]) + a(i,j+1/2)*(u[i,j+1]-u[i,j]) - a(i,j-1/2)*(u[i,j]-u[i,j-1])] = 1.
Compute face coefficients using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)), and analogously for all other faces.
At boundary-adjacent faces where one neighbor is a boundary node, use u = 0 for that boundary node value (already enforced by Dirichlet condition).

Assemble the sparse linear system A*u_interior = b for the (N-1)*(N-1) interior unknowns, where b is a vector of ones (the right-hand side value 1 at every interior node).
Solve the linear system using the Conjugate Gradient (CG) method with a relative residual tolerance of 1e-10.
Optionally apply a Jacobi preconditioner (diagonal of A) to accelerate convergence.

After solving, construct the full (N+1) x (N+1) solution array u with u = 0 on all boundary nodes and the CG solution at interior nodes.

Compute and print min(u) over the full grid.
Compute and print max(u) over the full grid.
Compute and print the discrete residual norm ||A*u_interior - b||_2 / ||b||_2 for the interior system.

Save a file named "solution_pdebench_darcy_beta10.npz" containing the following arrays: x as a 1D array of length N+1, y as a 1D array of length N+1, u as a 2D array of shape [N+1, N+1], and scalars beta = 10.0, N = 128, dx = 1/128.
Save a heatmap or filled contour plot of u(x,y) as a PNG file named "solution_pdebench_darcy_beta10.png".
