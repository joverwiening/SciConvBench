Solve the 1D Compressible Navier-Stokes PDE (no heat conduction) numerically in Python and save the results.

The viscous stress is sigma = (zeta + 4/3*eta) * v_x.

The PDE in conservative form is:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.5].
Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., Nx-1, with dx = 2/Nx.
Evolve the conservative cell-average variables U = [rho, m, E].

Apply periodic boundary conditions at x = -1 and x = 1 by wrapping indices (ghost cells take values from the opposite end).

Set initial conditions pointwise at cell centers:
rho(x, 0) = 1.0 + 0.2*sin(pi*x)
v(x, 0) = 0.1*cos(pi*x)
p(x, 0) = 1.0 + 0.2*cos(pi*x)
Convert to conservative variables: m = rho*v, E = p/(Gamma-1) + 0.5*rho*v**2.

Use the equation of state p = (Gamma-1)*(E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

For the convective (inviscid) flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] with v = m/rho.
At each interface, compute the local wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Approximate sigma at each interface by averaging the sigma values of the two neighboring cell centers.
Approximate v at each interface by averaging the v values of the two neighboring cell centers.
The viscous flux contribution at each interface is F_visc = [0, -sigma_interface, -v_interface*sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

After time integration, recover rho, v, p at cell centers from the conservative variables.
