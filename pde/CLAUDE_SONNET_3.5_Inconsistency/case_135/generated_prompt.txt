Solve 1D advection equation u_t + beta * u_x = 0 with the following specifications:
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,2.0].
The advection coefficient beta = 0.1.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use Nx=512 points on a uniform periodic grid with x_j = j*dx for j=0,...,Nx-1 where dx=1/Nx.
Use 1st-order upwind finite difference for spatial discretization.
Use explicit forward Euler time integration.
Set CFL=0.5 and compute dt = CFL * dx / abs(beta).
Set Nt = ceil(T/dt) and adjust dt = T/Nt to hit the final time exactly.
Compute the solution u(x,T=2.0) on the periodic grid.
Save solution data to "solution_pdebench_advection_beta0p1.npz" containing arrays x, u and scalars beta, T, dx, dt, Nx, Nt.
Create and save a line plot of u(x,T) as "solution_pdebench_advection_beta0p1.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=2.0.
Compute and print the max absolute error and L2 error versus the reference solution u(x,T) = u0((x - beta*T) mod 1).
