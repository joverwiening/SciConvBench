Solve the wave equation PDE u_tt = (1.0)^2 * (u_xx + u_yy) numerically.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions in both directions.
The temporal domain is t in [0,0.5].
Use c = 1.0 as the wave speed coefficient.
Apply periodic boundary conditions where u and first derivatives match across opposite edges.
Set initial conditions u(x,y,0) = cos(2*pi*x)*cos(2*pi*y) and u_t(x,y,0) = 0.
The exact solution is u(x,y,t) = cos(2*pi*x)*cos(2*pi*y)*cos(1.0*2*pi*sqrt(2)*t).
Use a uniform periodic grid with Nx = Ny = 128 points on [0,1) x [0,1) without duplicated endpoints.
Set dx = dy = 1/Nx.
Use 2nd-order central differences with wrap-around for spatial discretization.
Use 2nd-order central differences for time integration.
Set dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit final time T = 0.5 exactly.
Use Taylor start with periodic Laplacian for initialization.
Compute u(x,y,T=0.5) on the 2D grid.
Save solution data to "solution_agent_wave_19.npz" containing x, y, u arrays and T, dx, dy, dt scalars.
Save heatmap/contour plot of u(x,y,T) as "solution_agent_wave_19.png".
