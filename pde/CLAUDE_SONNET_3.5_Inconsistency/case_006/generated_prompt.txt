Solve advection equation u_t + 2.0*u_x = 0 numerically with the following specifications:
The spatial domain is [0,1) with periodic boundary conditions.
The temporal domain is [0,0.3].
Use Nx=2000 points for spatial discretization with uniform spacing dx=1/Nx.

Use Forward Euler time integration.
Set dt0 = 0.9*dx/|2.0| to satisfy CFL condition.
Set Nt = ceil(0.3/dt0) and then dt = 0.3/Nt for exact final time.
Use periodic wrap-around indexing for boundary handling.
Compute solution u(x,T=0.3) on the spatial grid.
Save solution data to "solution_agent_advection_06.npz" containing arrays x, u and scalars T, dx, dt.
Save line plot of u(x,T) to "solution_agent_advection_06.png".
