Solve the wave equation u_tt = (0.8)^2 * u_xx numerically.
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
Use parameter c = 0.8 for both the wave equation and CFL condition.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1.
Use initial conditions u(x,0) = 0 and u_t(x,0) = sin(2*pi*x).
The exact solution is u(x,t) = (1/(0.8*2*pi))*sin(0.8*2*pi*t)*sin(2*pi*x).
Use Nx = 600 intervals with uniform grid spacing dx = 1/Nx.
Use 2nd-order central differences for spatial discretization of u_xx in the interior.
Use 2nd-order central differences in time (leapfrog/Störmer-Verlet scheme).
Set dt0 = 0.9*dx/c, Nt = ceil(T/dt0), and dt = T/Nt.
Initialize first time step using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Enforce Dirichlet boundary conditions at every time step.
Compute solution until T = 1.0.
Save solution arrays (x, u) and metadata (T, dx, dt) to "solution_agent_wave_14.npz".
Create and save line plot of u(x,T) as "solution_agent_wave_14.png".
Print minimum value, maximum value, and discrete L2 norm of solution at T.
Compute and print maximum absolute error and L2 error against exact solution.
