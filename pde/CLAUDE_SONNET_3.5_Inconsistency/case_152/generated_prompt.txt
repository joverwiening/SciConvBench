Solve the 1D Viscous Burgers equation using Python with NumPy/SciPy libraries.
Use Python 3.x with NumPy for arrays and FFT operations.
Create a uniform periodic grid with Nx=512 points on [0,1).
Set viscosity parameter nu=0.002.
Set the initial condition u(x,0) = sin(2*pi*x).
Implement Strang splitting with three substeps: diffusion (dt/2), advection (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space using FFT/IFFT.
Implement advection step using Rusanov flux with finite-volume update.
Set CFL=0.4 with estimated max speed of 1.0.
Calculate dt0 = CFL*dx/1.0, then Nt = ceil(T/dt0), and final dt = T/Nt.
Integrate to final time T=1.0.
Save solution arrays (x, u) and parameters (nu, T, dx, dt, Nx, Nt) to solution_pdebench_burgers_nu2em3.npz.
Create and save a line plot of the final solution to solution_pdebench_burgers_nu2em3.png.
