Use SSP-RK2 time integration.
Set time step using CFL=0.2 with dt0 = CFL*dx/1.0, Nt=ceil(T/dt0), dt=T/Nt.
Save the solution at T=0.2 in "solution_molk_030.npz" containing arrays x, u and scalar values T, dx, Nx, k.
Create and save a line plot of u(x,T) as "solution_molk_030.png".
Print the minimum, maximum, mean, and discrete L2 norm of the solution at final time T.
