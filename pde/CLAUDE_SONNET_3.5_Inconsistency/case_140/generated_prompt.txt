Implement a numerical solution for the 1D advection equation with the following specifications:

Use Python with NumPy for numerical computations and Matplotlib for plotting.

Set up a uniform periodic grid with Nx=512 points where x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
Initialize u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use 1st-order upwind finite difference for spatial discretization.
Use explicit forward Euler time integration.
Set time step using CFL=0.5 with dt = CFL * dx / abs(beta).
Compute Nt = ceil(T/dt) and adjust dt = T/Nt for exact final time.
Compute solution until T=2.0.
Save solution data to 'solution_pdebench_advection_beta2.npz' including arrays x, u and scalars beta, T, dx, dt, Nx, Nt.
Create and save a line plot of the final solution as 'solution_pdebench_advection_beta2.png'.
Print minimum, maximum, and L2 norm of the final solution.
Compute and print max absolute error and L2 error against the reference solution u(x,T) = u0((x - beta*T) mod 1).
