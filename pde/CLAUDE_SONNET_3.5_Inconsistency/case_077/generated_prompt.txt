Solve the 2D Poisson equation u_xx + u_yy = f(x,y) numerically with the following specifications:
The source term is f(x,y) = (1 - pi^2)*exp(x)*sin(pi*y).
The domain is [0,1] x [0,1].
Apply Dirichlet boundary conditions on all edges with u(x,y) = exp(x)*sin(pi*y).
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.
Discretize the Laplacian using the standard 5-point stencil.
Solve the sparse linear system using a direct solver.
The exact solution is u(x,y)=exp(x)*sin(pi*y).
Save solution data to solution_agent_poisson_04.npz containing x, y, u arrays and dx, dy scalars.
Create and save a heatmap/contour plot as solution_agent_poisson_04.png.
Print minimum, maximum, and L2 norm of the solution.
Compute and print maximum absolute error and L2 error against the exact solution.
