Create a numerical solver for the 1D Advection equation with the following specifications:

The PDE is u_t + beta * u_x = 0 with beta = 1.0.
The spatial domain is [0, 1) with periodic boundary conditions.
The temporal domain is [0, 2.0].
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use Nx = 512 points for spatial discretization with uniform spacing dx = 1/Nx.
Use 1st-order upwind finite difference scheme for spatial discretization.
Implement explicit forward Euler time integration.
Set time step using CFL = 0.5 where dt = CFL * dx / abs(beta).
Adjust dt to hit final time T = 2.0 exactly by computing Nt = ceil(T/dt) and then dt = T/Nt.
Compute the solution u(x,T) at T = 2.0.
Save solution data to "solution_pdebench_advection_beta1.npz" including x, u, beta, T, dx, dt, Nx, and Nt.
Create and save a line plot of u(x,T) as "solution_pdebench_advection_beta1.png".
Print the minimum, maximum, and discrete L2 norm of the solution at time T.
Compute and print the maximum absolute error and L2 error against the reference solution u(x,t) = u0((x - beta*t) mod 1).
