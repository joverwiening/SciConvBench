Solve a 1D periodic reaction-diffusion PDE using Python with NumPy/SciPy for numerical computations and Matplotlib for plotting.
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,1.0].
Use parameters nu=1.0 and rho=2.0.
Set up a uniform spatial grid with Nx=512 points where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use fixed time step dt=0.001 with Nt=1000 steps.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) on the spatial grid.
Apply Strang splitting for each time step:
First half-step: Solve diffusion for dt/2 using FFT method with exp(-nu*k^2*(dt/2)).
Full step: Solve reaction ODE exactly using u <- (u*exp(rho*dt))/(1 + u*(exp(rho*dt) - 1)).
Second half-step: Repeat the diffusion solve for dt/2.
Save the final solution u(x,T=1.0) in NPZ format with arrays x, u and scalar parameters.
Create and save a line plot of the final solution.
Print the minimum, maximum, mean, and L2 norm of the final solution.
