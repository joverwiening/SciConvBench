Implement a numerical solver for the Fokker-Planck equation with the following specifications:

The PDE is p_t = ∂/∂x( 1.0*x*p ) + 0.1*p_xx on domain x in [-3.0, 3.0], t in [0,1.0].
Use cell-centered finite volume discretization with Nx=2000 uniform cells.
Set dx = 2*L/Nx where L=3.0.
Cell centers are located at x_i = -L + (i+0.5)*dx for i=0..Nx-1.
Use dt=1e-4 with Nt=10000 steps to reach T=1.0.
Initial condition is a normalized Gaussian q(x)=exp(-(x-1)^2/(2*sigma0^2)) with sigma0=0.2.
Use explicit forward Euler time integration.
Implement flux J = -(gamma*x*p + D*p_x) with gamma=1.0 and D=0.1.
Use upwind discretization for advective flux (gamma*x*p) and central difference for diffusive flux (D*p_x).
Enforce reflecting boundary conditions (J=0) at x=±L.
Save solution at T=1.0 in NPZ file with arrays x, p and metadata T, dx, dt.
Create line plot of final solution and save as PNG.
Print min(p), max(p), and L2 norm at final time.
Print initial mass M(0), final mass M(T), and relative change.
