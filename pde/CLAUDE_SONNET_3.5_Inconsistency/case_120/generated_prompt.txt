Reformulate as first-order system: u_t = v, v_t = q*u_xx.

Compute solution u(x,T) at final time T = 1.0.
Save solution data to 'solution_molk_019.npz' containing arrays x, u and scalar values T, dx, Nx, q.
Create and save line plot of u(x,T) as 'solution_molk_019.png'.
Print min(u), max(u), mean(u), and discrete L2 norm at final time T.
