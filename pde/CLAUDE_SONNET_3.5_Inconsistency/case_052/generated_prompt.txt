Solve the Klein-Gordon equation numerically with the following specifications:
The PDE is u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0.
The domain is (x,y) in [0,1] x [0,1], t in [0,0.8].
Use parameters c = 1.0 and m = 1.0.
Apply Dirichlet boundary conditions u=0 on all boundaries.
Set initial conditions u(x,y,0)=sin(pi*x)*sin(pi*y) and u_t(x,y,0)=0.
The exact solution is u(x,y,t)=cos(sqrt((1.0)^2*(2*pi^2) + (1.0)^2)*t)*sin(pi*x)*sin(pi*y).
Use a uniform grid with Nx=Ny=256 intervals.
Use 5-point Laplacian for spatial discretization.
Use 2nd-order central difference in time for u_tt.
Initialize using Taylor start with Laplacian and mass term.
Set dx=dy=1/Nx.
Calculate dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) and then dt = T/Nt.
Compute solution u(x,y,T=0.8) on the 2D grid.
Save solution data to "solution_agent_kg_05.npz" with arrays x, y, u and metadata T, dx, dy, dt.
