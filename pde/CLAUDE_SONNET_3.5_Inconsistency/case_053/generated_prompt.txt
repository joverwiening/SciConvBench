Solve the Klein-Gordon equation numerically with the following specifications:

Set dx = dy = 1/160.
Use 5-point Laplacian stencil for spatial discretization of u_xx + u_yy.
Use 2nd-order central difference in time for u_tt.
Set initial dt0 = 0.5*min(dx,dy)/c for CFL = 0.5.
Set Nt = ceil(T/dt0) and adjust dt = T/Nt to hit final time T = 1.0 exactly.
Use Taylor series initialization with Laplacian and mass terms.
Compute solution u(x,y,T=1.0) on the 2D grid.
