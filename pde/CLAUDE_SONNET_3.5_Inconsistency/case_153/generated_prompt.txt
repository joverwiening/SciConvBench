Implement a numerical solver for the 1D Viscous Burgers equation with the following specifications:

The implementation should use Python with NumPy/SciPy for numerical computations and Matplotlib for plotting.
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
The viscosity parameter nu = 4.0.
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx=512 points for the spatial grid with uniform spacing dx=1/Nx.
Grid points are defined as x_j = j*dx for j=0,...,Nx-1.
Use Strang splitting time integration with three substeps per time step:
First diffusion half-step using Fourier spectral method with exp(-nu*k^2*(dt/2)).
Full advection step using Rusanov flux for inviscid Burgers equation.
Second diffusion half-step identical to the first.
Set time step using CFL=0.4 with estimated maximum speed of 1.0.
Calculate Nt = ceil(T/dt0) where dt0 = CFL*dx/1.0, then set dt = T/Nt.
Save solution data to "solution_pdebench_burgers_nu4.npz" containing x, u, nu, T, dx, dt, Nx, Nt.
Create and save a line plot of the final solution as "solution_pdebench_burgers_nu4.png".
Print the minimum, maximum, mean, and L2 norm of the final solution.
