Solve the 2D wave equation PDE u_tt = (1.0)^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t).
The spatial domain is [0,1] x [0,1] with t in [0,1.0].
The wave speed parameter c = 1.0.
Apply Dirichlet boundary conditions u = 0 on all boundaries.
Set initial conditions u(x,y,0) = 0 and u_t(x,y,0) = 0.
Use a uniform grid with Nx = Ny = 120 intervals (121 x 121 points).
Use the 5-point Laplacian stencil for spatial discretization.
Use 2nd-order central difference in time for u_tt.
Set dx = dy = 1/120.
Calculate dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) and dt = T/Nt to hit final time T = 1.0 exactly.
Initialize first time step using Taylor start with initial velocity.
Apply Dirichlet boundary conditions at each time step.
Compute solution u(x,y,T=1.0) on the 2D grid.
Save solution data to "solution_agent_wave_11.npz" with arrays x, y, u and scalars T, dx, dy, dt.
Create and save heatmap/contour plot of u(x,y,T) as "solution_agent_wave_11.png".
