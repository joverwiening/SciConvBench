PDE category is 1D linear advection with periodic boundary conditions.
The domain is x in [0,1) periodic and t in [0,1.0].
The governing equation is u_t + q*u_x = 0 with q = 1.5.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The exact solution is u(x,t) = u0((x - q*t) mod 1), where u0 is the initial condition.
Use a uniform periodic grid with Nx=512 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use 1st-order upwind finite difference for spatial discretization of u_x.
Use Forward Euler for time integration.
Set time step using CFL=0.5: dt0 = CFL*dx/abs(q).
Calculate Nt=ceil(T/dt0) and then dt=T/Nt.
Compute the solution up to final time T=1.0.
Save solution data to "solution_molk_018.npz" containing x, u arrays and scalar parameters.
Save line plot of u(x,T) to "solution_molk_018.png".
Print min(u), max(u), mean(u), and discrete L2 norm at T=1.0.
Compute and print max absolute error and L2 error versus exact solution.
