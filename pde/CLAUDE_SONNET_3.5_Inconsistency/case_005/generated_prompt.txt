The time domain is [0,0.5].
Use Nx=Ny=256 grid points with uniform spacing dx=dy=1/256.

Use Forward Euler time integration.
Set dt0 = 0.9 / (0.7/dx + 1.2/dy).
Set Nt = ceil(0.5/dt0) and dt = 0.5/Nt.
Compute solution until T=0.5.
Save solution data to "solution_agent_advection_05.npz" with arrays x, y, u and scalars T, dx, dy, dt.
