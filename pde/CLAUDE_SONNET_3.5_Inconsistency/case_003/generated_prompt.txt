Solve the advection equation u_t + a(x)*u_x = 0 with the following specifications:
The spatial domain is [0,1) with periodic boundary conditions.
The temporal domain is [0,0.5].
The advection coefficient is a(x) = 1 + 0.5*sin(2*pi*x).
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx=1200 points for spatial discretization.
Use upwind differencing with left-biased stencil for spatial derivatives.
Use Forward Euler time integration.
Calculate dx = 1/Nx.
Set amax = 1.5.
Calculate dt0 = 0.9*dx/amax.
Set Nt = ceil(T/dt0).
Calculate final dt = T/Nt to hit T=0.5 exactly.
Compute the solution u(x,T) at T=0.5.
Save solution data to "solution_agent_advection_03.npz" containing x, u, T, dx, and dt.
Create and save a line plot of u(x,T) as "solution_agent_advection_03.png".
Print the minimum value of u, maximum value of u, and discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
