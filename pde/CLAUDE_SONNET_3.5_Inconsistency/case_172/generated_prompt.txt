Create a Python script that:
Uses numpy and matplotlib to solve a 1D reaction-diffusion equation with periodic boundary conditions.
Sets up a uniform periodic grid with Nx=512 points on [0,1).
Uses time step dt=0.001 for Nt=1000 steps to reach T=1.0.
Sets parameters nu=0.5 and rho=1.0.
Implements initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Solves using Strang splitting with three substeps per time step:
  - FFT-based diffusion solve for dt/2
  - Exact logistic reaction solve for dt
  - FFT-based diffusion solve for dt/2
Saves solution data to "solution_pdebench_reacdiff_nu0p5_rho1.npz" with arrays x, u and scalar parameters.
Creates and saves a line plot of u(x,T) to "solution_pdebench_reacdiff_nu0p5_rho1.png".
Prints the minimum, maximum, mean, and L2 norm of the final solution.
