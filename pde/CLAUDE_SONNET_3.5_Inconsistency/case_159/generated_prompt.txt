Solve the 1D Compressible Navier-Stokes equations numerically with the following specifications:
The domain is x in [-1, 1] and t in [0, 0.2].
Use Gamma = 1.6666666666666667.
Set viscosity parameters eta = zeta = 1e-08.
Use a uniform finite-volume grid with Nx=800 cells.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, with dx = 2/Nx.
Initial conditions are a Riemann problem with discontinuity at x=0.
Left state (x < 0): rho = 1.0, v = 0.0, p = 1.0.
Right state (x ≥ 0): rho = 0.1, v = 0.0, p = 0.01.
Use transmissive/outflow (zero-gradient) boundary conditions at x = ±1.
Evolve conservative variables U = [rho, m, E] using cell averages.
Use equation of state p = (Gamma-1)*(E - 0.5*m^2/rho) with positivity floor of 1e-12.
Implement Rusanov flux for convective terms with wave speed a = max(|v_L| + c_L, |v_R| + c_R).
Compute viscous stress sigma = (zeta + 4/3*eta)*v_x using centered differences.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Set CFL = 0.5 for stability.
Compute time step as minimum of convective and viscous constraints.
Save solution arrays to solution_pdebench_cns1d_shock_eta1em8_outflow.npz.
Generate and save plots to solution_pdebench_cns1d_shock_eta1em8_outflow.png.
Print minimum/maximum values of rho and p, and mean of rho.
