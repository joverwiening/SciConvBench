Solve the Allen-Cahn equation numerically with the following specifications:
The PDE is u_t = (0.02)^2*u_xx + u - u^3.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.2].
Set epsilon = 0.02.
Apply Dirichlet boundary conditions u(0,t) = 1 and u(1,t) = -1.
Use initial condition u(x,0) = tanh((0.5 - x)/(sqrt(2)*0.02)).
Use a uniform spatial grid with Nx=1200 intervals (Nx+1 points).
Use time step dt=0.0001 for 2000 steps.
Implement 2nd-order central differences for spatial derivatives.
Use semi-implicit time integration: (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
Enforce Dirichlet boundary conditions by setting boundary values at each time step.
Compute the solution until T=0.2.
Save solution data (x, u, T, dx, dt) in "solution_agent_allen_cahn_02.npz".
Create and save a line plot of u(x,T) as "solution_agent_allen_cahn_02.png".
Print the minimum value, maximum value, and discrete L2 norm of u at final time T.
