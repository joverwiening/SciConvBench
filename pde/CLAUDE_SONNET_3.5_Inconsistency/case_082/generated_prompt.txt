Solve wave equation PDE u_tt = u_xx numerically with the following specifications:
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
Use wave speed c = 1.0.
Apply Dirichlet boundary conditions: u(0,t) = 0 and u(1,t) = 0.
Set initial condition u(x,0) = sin(pi*x).
Set initial velocity u_t(x,0) = 0.
The exact solution is u(x,t) = cos(pi*t)*sin(pi*x).
Use uniform spatial grid with Nx=400 intervals (Nx+1 points).
Use 2nd-order central differences for spatial derivatives u_xx.
Use 2nd-order central differences in time (leapfrog scheme).
Compute dx = 1/Nx.
Set dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) and then dt = T/Nt.
Initialize first time step using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0.
Enforce Dirichlet boundary conditions at every time step.
Compute solution until final time T = 1.0.
Save solution arrays (x, u) and metadata (T, dx, dt) to "solution_agent_wave_01.npz".
Create and save line plot of u(x,T) as "solution_agent_wave_01.png".
Print minimum and maximum values of u at final time.
Print discrete L2 norm of final solution.
Compute and print maximum absolute error versus exact solution.
Compute and print L2 error versus exact solution.
