Solve the 2D Poisson equation on [0,1] x [0,1] with the following specification:
The PDE is u_xx + u_yy = f(x,y), where f(x,y) = -2*pi^2*cos(pi*x)*cos(pi*y).
Use Nx=Ny=120 intervals giving a (121 x 121) point grid including boundaries.
Set grid spacing dx=dy=1/120.
Define grid points as x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.
Use the standard 5-point stencil for the Laplacian discretization.
Apply Dirichlet boundary conditions u(x,y)=cos(pi*x)*cos(pi*y) on all four edges.
Solve the resulting sparse linear system using a direct solver.
Save solution data to solution_agent_poisson_05.npz containing x, y, u arrays and dx, dy scalars.
Create and save a heatmap/contour visualization to solution_agent_poisson_05.png.
Print the solution minimum, maximum, and discrete L2 norm.
Compute and print the maximum absolute error and L2 error versus the exact solution u(x,y)=cos(pi*x)*cos(pi*y).
