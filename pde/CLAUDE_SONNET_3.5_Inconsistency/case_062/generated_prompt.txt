Solve the Laplace equation numerically with the following specifications:

Set grid spacing dx=dy=1/100.

Discretize the Laplacian using the standard 5-point stencil.
Solve the resulting sparse linear system using a direct solver.
Compute the solution u(x,y) on the 2D grid.
Save solution data to "solution_agent_laplace_06.npz" containing x, y, u arrays and dx, dy scalars.
