Solve a 1D reaction-diffusion PDE using Python with NumPy/SciPy for numerical computations and Matplotlib for plotting.
Use Python's numpy.fft module for Fourier transforms.
Create a uniform periodic grid with Nx=512 points on [0,1).
Set time step dt=0.001 with Nt=1000 steps to reach T=1.0.
Set physical parameters nu=2.0 and rho=1.0.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) on the grid points.
Apply Strang splitting with three substeps per time step:
  1. Solve diffusion for dt/2 in Fourier space using exp(-nu*k^2*(dt/2))
  2. Solve reaction ODE for dt using exact solution u = (u*exp(rho*dt))/(1 + u*(exp(rho*dt) - 1))
  3. Solve diffusion for dt/2 again
Save solution arrays and parameters to solution_pdebench_reacdiff_nu2_rho1.npz.
Create and save a line plot of u(x,T) to solution_pdebench_reacdiff_nu2_rho1.png.
Print min(u), max(u), mean(u), and L2 norm at final time T.
