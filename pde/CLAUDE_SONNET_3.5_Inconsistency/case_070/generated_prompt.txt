Solve the biharmonic equation ∇^4 u = f(x,y) where f(x,y) = 4*pi^4*sin(pi*x)*sin(pi*y) on [0,1] x [0,1].
Use simply-supported boundary conditions: u=0 and Δu=0 on all boundaries.
Split into two Poisson problems: (1) Δv = f with v=0 on boundary, (2) Δu = v with u=0 on boundary.
Use standard 5-point Laplacian discretization on uniform grid.
Set Nx=Ny=120 intervals (121x121 grid points).
Use dx=dy=1/120.
Grid points are x_i=i*dx (i=0..120), y_j=j*dy (j=0..120).
Solve linear systems using sparse direct solver.
Save solution arrays (x, y, u) and metadata (dx, dy) to "solution_agent_other_05_biharmonic.npz".
Save solution heatmap/contour plot to "solution_agent_other_05_biharmonic.png".
