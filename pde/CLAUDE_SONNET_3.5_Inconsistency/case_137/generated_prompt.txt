Solve 1D advection equation u_t + beta * u_x = 0 with the following specifications:
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,2.0].
The advection coefficient beta is 0.4.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use a uniform grid with Nx=512 points on [0,1).
Use 1st-order upwind finite difference for spatial discretization.
Use explicit forward Euler time integration.
Set CFL=0.5 and compute dt = CFL * dx / abs(beta).
Compute Nt = ceil(T/dt) and reset dt = T/Nt.
Compute the solution u(x,T=2.0) on the periodic grid.
Save solution data to "solution_pdebench_advection_beta0p4.npz" containing x, u, beta, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) to "solution_pdebench_advection_beta0p4.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=2.0.
Compute and print max absolute error and L2 error vs reference solution u(x,T) = u0((x - beta*T) mod 1).
