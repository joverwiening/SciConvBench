Solve 1D periodic diffusion equation u_t = 0.2 * u_xx on [0,1) x [0,0.5].
The spatial domain is periodic with u(0,t) = u(1,t).
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx=256 uniform grid points with x_j = j*dx for j=0,...,Nx-1 where dx=1/Nx.
Use 2nd-order central differences for spatial discretization of u_xx on the periodic grid.
Use Crank-Nicolson time integration with dt=0.001 and Nt=500 steps.
Compute the solution up to final time T=0.5.
Save arrays x, u and scalar parameters to solution_molk_012.npz.
Create and save a line plot of u(x,T) as solution_molk_012.png.
Print min(u), max(u), mean(u), and L2 norm sqrt(sum(u^2)*dx) at T=0.5.
Compare with exact solution u(x,t) = exp(-0.2*(2*pi)^2*t) * sin(2*pi*x).
Print maximum absolute error and L2 error between numerical and exact solutions.
