Solve the 2D Laplace equation numerically with the following specifications:
The PDE is u_xx + u_yy = 0 on the domain [0,1] x [0,1].
Apply Dirichlet boundary conditions: u(x,0)=0, u(x,1)=sin(2*pi*x), u(0,y)=0, u(1,y)=0.
Use a uniform grid with Nx=Ny=100 intervals (101x101 points).
Set grid spacing dx=dy=1/100.
Define grid points as x_i=i*dx for i=0..100 and y_j=j*dy for j=0..100.
Discretize using the standard 5-point stencil for the Laplacian.
Solve the resulting sparse linear system using a direct solver.
Compute the solution u(x,y) on the 2D grid.
Save solution data to "solution_agent_laplace_08.npz" containing x, y, u arrays and dx, dy scalars.
Create and save a heatmap/contour plot as "solution_agent_laplace_08.png".
Print minimum, maximum, and L2 norm of the solution.
Compute and print maximum absolute error and L2 error versus the exact solution u(x,y)=sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi).
