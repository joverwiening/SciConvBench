Solve a 1D Reaction-Diffusion PDE using Python with NumPy/SciPy for computation and Matplotlib for plotting.
Use Python's numpy.fft module for Fourier transforms.
Create a uniform periodic grid with Nx=512 points on [0,1).
Set time step dt=0.001 with Nt=1000 steps to reach T=1.0.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) on the grid points.
Apply Strang splitting for each time step:
First half-step: Solve diffusion using FFT with nu=1.0 for dt/2.
Full step: Solve logistic reaction exactly with rho=5.0 for dt.
Second half-step: Solve diffusion using FFT with nu=1.0 for dt/2.
Save solution arrays and parameters to solution_pdebench_reacdiff_nu1_rho5.npz.
Create and save a line plot of u(x,T) to solution_pdebench_reacdiff_nu1_rho5.png.
Print the minimum, maximum, mean, and L2 norm of the final solution.
