Implement a numerical solver for the 1D nonlinear convection-diffusion equation with the following specifications:
The implementation should use Python with NumPy and Matplotlib libraries.
The PDE to solve is u_t = -q1*∂_x((1/3)*u^3) + (q2/pi)*u_xx on [0,1) with periodic boundary.
Parameters are q1=1.0 and q2=0.05.
Use Nx=1024 grid points on a uniform periodic grid with x_j = j*dx for j=0,...,Nx-1 where dx=1/Nx.
Initial condition is u(x,0) = 0.5*sin(2*pi*x).
Use Rusanov flux for the convective term ∂_x((1/3)*u^3) and 2nd-order central differences for u_xx.
Integrate in time using SSP-RK2 method.
Set time step using CFL=0.2 with dt = min(CFL*dx/0.25, 0.2*dx^2/(q2/pi)).
Compute solution until final time T=0.5.
Save solution data in NPZ format including x, u, T, dx, Nx, and parameters.
Generate and save a line plot of the final solution.
Print minimum, maximum, mean, and L2 norm of the final solution.
No error computation is required as no exact solution is provided.
