Solve the 2D Poisson equation u_xx + u_yy = f(x,y) numerically with the following specifications:
The source term is f(x,y) = -5*pi^2*sin(2*pi*x)*sin(pi*y).
The domain is [0,1] x [0,1].
Apply Dirichlet boundary conditions with u=0 on all boundaries.
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx for i=0..120 and y_j=j*dy for j=0..120.
Discretize using the standard 5-point stencil for the Laplacian.
Solve the sparse linear system using a direct solver.
The exact solution for verification is u(x,y)=sin(2*pi*x)*sin(pi*y).
Save solution data to "solution_agent_poisson_02.npz" with arrays x, y, u and scalars dx, dy.
Save solution plot to "solution_agent_poisson_02.png" as a heatmap/contour plot.
Print minimum, maximum, and L2 norm of the computed solution.
Print maximum absolute error and L2 error compared to the exact solution.
