Solve 1D Viscous Burgers equation with periodic boundary conditions.
The domain is x in [0, 1) and t in [0, 1.0].
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 0.4.
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx = 512 grid points with uniform spacing dx = 1/Nx.
Use Strang splitting with three substeps per time step: diffusion (dt/2), advection (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space using exp(-nu*k^2*dt/2).
Solve advection step using finite-volume update with Rusanov flux.
Set base time step dt0 = CFL*dx/1.0 with CFL = 0.4.
Set Nt = ceil(T/dt0) and adjust dt = T/Nt for exact final time.
Compute solution until final time T = 1.0.
Save solution arrays and parameters to solution_pdebench_burgers_nu0p4.npz.
Save line plot of final solution to solution_pdebench_burgers_nu0p4.png.
Print min(u), max(u), mean(u), and L2 norm at final time.
