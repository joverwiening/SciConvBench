Solve the Helmholtz equation u_xx + u_yy + k^2*u = f(x,y) numerically.
The domain is [0,1] x [0,1].
Use k = 5.0.
Apply Dirichlet boundary conditions u=0 on all boundaries.
Use f(x,y) = (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y) as the source term.
Discretize using the 5-point Laplacian stencil on a uniform grid.
Use Nx=Ny=120 intervals (121x121 grid points).
Set grid spacing dx=dy=1/120.
Generate grid points as x_i=i*dx (i=0..120), y_j=j*dy (j=0..120).
Solve the resulting sparse linear system using a direct solver.
Save solution data to "solution_agent_other_01_helmholtz.npz" containing x, y, u arrays and dx, dy scalars.
Create a heatmap/contour plot using a standard perceptually uniform colormap.
Save the plot as "solution_agent_other_01_helmholtz.png".
Print minimum and maximum solution values.
Print the discrete L2 norm computed as sqrt(sum(u^2)*dx*dy).
Compute and print the maximum absolute error versus u(x,y)=sin(pi*x)*sin(pi*y).
Compute and print the L2 error versus the exact solution.
