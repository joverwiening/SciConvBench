Solve 2D Darcy flow PDE -∇ · ( a(x,y) ∇u(x,y) ) = 1 on unit square domain.
The domain is (x,y) in (0,1) x (0,1).
Set beta = 0.01.
Define coefficient field a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions u = 0 on all boundaries.
Use N = 128 intervals (129 points) in each direction with uniform spacing dx = dy = 1/N.
Grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Use 2nd-order finite differences with variable coefficient using face-centered harmonic averaging.
Solve the linear system Au=b using conjugate gradient to relative tolerance 1e-10.
Save solution arrays to "solution_pdebench_darcy_beta0p01.npz" containing x, y, u, beta, N, and dx.
Create and save heatmap/contour plot to "solution_pdebench_darcy_beta0p01.png".
Print minimum and maximum values of u and the relative residual norm ||Au-b||_2 / ||b||_2.
