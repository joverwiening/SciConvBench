Solve the 1D reaction-diffusion PDE u_t = q1*u_xx + q2*u*(1-u) numerically.
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
Set q1 = 0.01 (diffusion coefficient).
Set q2 = 5.0 (reaction coefficient).
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points on [0,1).
Set grid points as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use either IMEX Euler or Strang splitting method (implementer's choice).
Use time step dt=0.001 with Nt=1000 steps.
Use 2nd-order central differences for spatial discretization of u_xx.
Compute the solution up to final time T=1.0.
Save the solution arrays (x, u) and parameters (T, dx, Nx, q1, q2) in "solution_molk_020.npz".
Create and save a line plot of u(x,T) as "solution_molk_020.png".
Print the minimum, maximum, mean, and discrete L2 norm of u at final time T.
No error computation is required as no exact solution is provided.
