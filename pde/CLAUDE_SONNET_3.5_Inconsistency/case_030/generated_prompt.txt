Numerical solution of 1D heat equation with the following specifications:

The solution shall be implemented in Python using NumPy/SciPy for numerical computations and Matplotlib for plotting.
The PDE u_t = 0.1 * u_xx shall be solved on domain x in [0,1], t in [0,0.5].
The diffusion coefficient alpha shall be 0.1.
Dirichlet boundary conditions shall be u(0,t) = 0 and u(1,t) = 0 for all t.
Initial condition shall be u(x,0) = sin(pi*x).
The exact solution u(x,t) = exp(-0.1*pi^2*t) * sin(pi*x) shall be used for error verification.
Spatial discretization shall use Nx=200 intervals with uniform grid spacing dx=1/200.
Time integration shall use Crank-Nicolson method with dt=0.001 (500 time steps).
The solution shall enforce Dirichlet BC by fixing boundary nodes at each time step.
The code shall compute u(x,T=0.5) on the specified grid.
The solution shall be saved in NPZ format as "solution_agent_heat_01.npz" containing x, u arrays and T, dx, dt scalars.
A line plot of u(x,T) shall be saved as "solution_agent_heat_01.png".
The code shall print min(u), max(u), and L2 norm at final time T.
The code shall compute and print max absolute error and L2 error versus the exact solution.
