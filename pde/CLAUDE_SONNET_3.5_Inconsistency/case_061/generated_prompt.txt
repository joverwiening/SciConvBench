The domain is (x,y) in [0,1] x [0,1].

Set dx=dy=1/100.

Discretize using the standard 5-point stencil for the Laplacian (2nd-order accurate).
Solve the resulting sparse linear system for interior nodes using a direct sparse solver.
The exact solution for verification is u(x,y)=x*y.
Save solution data to "solution_agent_laplace_05.npz" containing x, y, u arrays and dx, dy scalars.
Save visualization to "solution_agent_laplace_05.png" as a heatmap/contour plot.
