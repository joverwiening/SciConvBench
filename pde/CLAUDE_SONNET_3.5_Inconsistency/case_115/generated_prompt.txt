Solve the Klein-Gordon-type equation with the following specifications:
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,1.0].
Use parameters q1=1.0 and q2=0.5.
Set initial conditions u(x,0)=sin(2*pi*x) and u_t(x,0)=0.
Use Nx=256 points on a uniform periodic grid with x_j=j*dx for j=0,...,Nx-1 and dx=1/Nx.
Use Fourier spectral method for spatial derivatives (preferred for periodic domains with smooth solutions).
Convert to first-order system with v=u_t.
Use RK4 time integration with dt=0.0005 and Nt=2000 steps.
Compute solution u(x,T) at final time T=1.0.
Save solution data to "solution_molk_014.npz" containing arrays x, u and scalars T, dx, Nx, q1, q2.
Create and save line plot of u(x,T) as "solution_molk_014.png".
Print min(u), max(u), mean(u), and L2 norm at final time T.
The exact solution is u(x,t)=cos(omega*t)*sin(2*pi*x) with omega=sqrt(q2^2*q1^4+q1^2*(2*pi)^2).
