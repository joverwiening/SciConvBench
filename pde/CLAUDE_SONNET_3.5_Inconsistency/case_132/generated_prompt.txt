Solve a 1D nonlinear convection-diffusion PDE using Python with NumPy/SciPy.
Use Python 3.x with NumPy for numerical computations and Matplotlib for plotting.
Create a uniform periodic grid with Nx=1024 points on [0,1).
Set x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement the PDE u_t = -q1*∂_x(cos(u)) + (q2/pi)*u_xx with q1=1.0, q2=0.05.
Use conservative finite-volume flux for ∂_x(cos(u)) with Rusanov flux using wave speed alpha=max|sin(u)|.
Implement 2nd-order central differences for the diffusion term u_xx.
Use SSP-RK2 time integration.
Set time step using CFL=0.2: dt = min(0.2*dx/1, 0.2*dx^2/(q2/pi)).
Set Nt=ceil(T/dt) and adjust dt=T/Nt.
Apply initial condition u(x,0) = 0.5*sin(2*pi*x).
Enforce periodic boundary conditions u(0,t)=u(1,t).
Compute solution until T=0.5.
Save solution data to "solution_molk_031.npz" with arrays x, u and scalar parameters.
Create and save line plot of u(x,T) as "solution_molk_031.png".
Print min(u), max(u), mean(u), and L2 norm at final time T.
