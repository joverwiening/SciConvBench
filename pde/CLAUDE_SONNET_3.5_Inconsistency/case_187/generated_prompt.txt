Solve a 1D Reaction-Diffusion PDE using Python with NumPy and Matplotlib libraries.
Use Python 3.x as the programming language.
Import numpy for numerical computations and matplotlib.pyplot for plotting.
Use numpy.fft module for the Fourier transforms in the splitting method.
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,1.0].
Set nu = 2.0 and rho = 5.0 as physical parameters.
Use Nx = 512 spatial points with uniform spacing dx = 1/Nx.
Use Nt = 1000 time steps with fixed dt = 0.001.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) on the spatial grid.
Apply Strang splitting with exact solutions for diffusion (FFT) and reaction (logistic).
Compute solution u(x,T) at final time T = 1.0.
Save solution data to 'solution_pdebench_reacdiff_nu2_rho5.npz'.
Create and save a line plot to 'solution_pdebench_reacdiff_nu2_rho5.png'.
Print the minimum, maximum, mean, and L2 norm of the final solution.
