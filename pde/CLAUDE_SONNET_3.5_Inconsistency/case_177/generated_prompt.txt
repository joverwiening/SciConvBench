Solve a 1D reaction-diffusion PDE with periodic boundary conditions using Strang splitting.
The domain is x in [0,1) and t in [0,1.0].
Set parameters nu=10.0 and rho=10.0.
Use Nx=512 grid points with uniform spacing dx=1/Nx.
Use Nt=1000 time steps with fixed dt=0.001.
Set initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Apply Strang splitting for each time step:
First solve diffusion for dt/2 in Fourier space using exp(-nu*k^2*(dt/2)).
Then solve reaction ODE for dt using exact solution u = (u*exp(rho*dt))/(1 + u*(exp(rho*dt) - 1)).
Finally solve diffusion again for dt/2.
Save solution array and parameters to solution_pdebench_reacdiff_nu10_rho10.npz.
Create line plot of final solution and save as solution_pdebench_reacdiff_nu10_rho10.png.
Print minimum, maximum, mean, and L2 norm of final solution.
