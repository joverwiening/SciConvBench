Solve the 1D compressible Navier-Stokes equations on [-1,1] with the following specifications:
Use conservative form PDEs for density (rho), momentum (m), and energy (E).
Set Gamma = 1.6666666666666667.
Set viscosity parameters eta = zeta = 1e-08.
Use transmissive/outflow boundary conditions at x = -1 and x = 1.
Initialize with Riemann shock-tube condition: (rho,v,p) = (1.0,0.0,2.0) for x < 0 and (0.125,0.0,0.2) for x ≥ 0.
Use a uniform finite-volume grid with Nx=800 cells.
Evolve conservative variables U = [rho, m, E] using cell averages.
Compute pressure using p = (Gamma-1)*(E - 0.5*m^2/rho) with positivity floor of 1e-12.
Use Rusanov flux for convective terms with maximum wave speed a = max(|v_L| + c_L, |v_R| + c_R).
Compute viscous stress sigma = (zeta + 4/3*eta)*v_x using centered differences.
Use 2-stage SSP-RK2 time integration.
Set CFL = 0.5 for stability.
Compute time step as minimum of convective and viscous constraints.
Implement outflow boundary conditions by copying nearest interior cell values to ghost cells.
Run simulation until T = 0.2.
