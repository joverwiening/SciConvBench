Solve the 2D Poisson equation u_xx + u_yy = f(x,y) with the following specifications:
The domain is [0,1] x [0,1].
The forcing function f(x,y) = -((3*pi)^2 + (2*pi)^2)*sin(3*pi*x)*cos(2*pi*y).
Use Dirichlet boundary conditions on all edges: u(x,y) = sin(3*pi*x)*cos(2*pi*y).
Use a uniform grid with Nx=Ny=120 intervals (121x121 points).
Grid spacing is dx=dy=1/120.
Grid points are x_i=i*dx for i=0..120, y_j=j*dy for j=0..120.
Discretize using the standard 5-point stencil for the Laplacian.
Solve the sparse linear system using a direct solver.
Save solution data to solution_agent_poisson_06.npz containing x, y, u arrays and dx, dy scalars.
Create and save a heatmap/contour plot as solution_agent_poisson_06.png.
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compute and print max absolute error and L2 error versus exact solution u(x,y)=sin(3*pi*x)*cos(2*pi*y).
