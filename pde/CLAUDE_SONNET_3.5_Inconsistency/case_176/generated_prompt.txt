Solve a 1D reaction-diffusion PDE using Python with the following specifications:
Import numpy and matplotlib.pyplot for computations and plotting.
Set nu = 10.0 and rho = 1.0 as the diffusion and reaction coefficients.
Create a spatial grid with Nx = 512 points on [0,1) using x = np.linspace(0, 1, Nx, endpoint=False).
Set time step dt = 0.001 and number of time steps Nt = 1000 to reach T = 1.0.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) on the spatial grid.
Implement Strang splitting time evolution with three substeps per dt:
  1. Diffusion half-step using FFT with k = 2*pi*fftfreq(Nx, d=dx) and exp(-nu*k^2*(dt/2))
  2. Reaction full-step using exact solution u = (u*exp(rho*dt))/(1 + u*(exp(rho*dt) - 1))
  3. Repeat diffusion half-step
Evolve the solution for Nt time steps.
Save the final solution and parameters in solution_pdebench_reacdiff_nu10_rho1.npz.
Create and save a line plot of u(x,T) as solution_pdebench_reacdiff_nu10_rho1.png.
Print min(u), max(u), mean(u), and sqrt(sum(u^2)*dx) at the final time.
