Load required Python packages (numpy, matplotlib).
Create a uniform grid with Nx=Ny=140 intervals on [0,1]x[0,1].
Set dx=dy=1/140.
Compute dt0 = 0.9/(1.4*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(0.8/dt0).
Set dt = 0.8/Nt for exact end time.
Initialize u(x,y,0) = sin(2*pi*x)*sin(pi*y) on the grid.
Set u=0 on all boundaries.
Initialize u at first timestep using Taylor expansion with u_t(x,y,0)=0.
Use 5-point Laplacian stencil for spatial derivatives.
Use second-order central difference in time.
Enforce u=0 boundary conditions at each timestep.
Compute until T=0.8.
Calculate exact solution = cos(0.7*pi*sqrt(5)*t)*sin(2*pi*x)*sin(pi*y) at T=0.8.
Save x, y, u arrays and metadata (T,dx,dy,dt) to solution_agent_wave_08.npz.
Create and save heatmap plot to solution_agent_wave_08.png.
Print minimum and maximum of u at final time.
Print discrete L2 norm of solution at final time.
Print maximum absolute error versus exact solution.
