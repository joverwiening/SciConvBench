Solve the Laplace equation u_xx + u_yy = 0 numerically with the following specifications:
The domain is (x,y) in [0,1] x [0,1].
Use Dirichlet boundary conditions: u(x,0)=0, u(x,1)=1, u(0,y)=0, u(1,y)=0.
Use a uniform grid with Nx=Ny=100 intervals (101x101 points including boundaries).
Set grid spacing dx=dy=1/100.
Define grid points as x_i=i*dx for i=0..100 and y_j=j*dy for j=0..100.
Discretize using the standard 5-point stencil for the Laplacian (2nd-order accurate).
Solve the resulting sparse linear system using a direct sparse solver.
Save solution array u and grid coordinates x,y to solution_agent_laplace_09.npz with metadata dx,dy.
Create and save a heatmap/contour plot of the solution as solution_agent_laplace_09.png.
Print the minimum value, maximum value, and discrete L2 norm of the solution.
