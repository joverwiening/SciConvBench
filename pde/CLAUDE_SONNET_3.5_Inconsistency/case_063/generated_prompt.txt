Solve the Laplace equation u_xx + u_yy = 0 on [0,1] x [0,1] with the following specifications:
Use a uniform grid with Nx=Ny=100 intervals (101x101 points).
Set dx=dy=1/100.
Grid points are x_i=i*dx (i=0..100), y_j=j*dy (j=0..100).
Apply Dirichlet boundary conditions: u(x,0)=0, u(x,1)=sin(pi*x), u(0,y)=0, u(1,y)=0.
Use the standard 5-point stencil for spatial discretization of the Laplacian.
Solve the resulting sparse linear system using a direct solver.
The exact solution is u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
Save the solution arrays and metadata to solution_agent_laplace_07.npz.
Create and save a heatmap/contour plot as solution_agent_laplace_07.png.
Print the solution minimum, maximum, and discrete L2 norm.
Compute and print the maximum absolute error and L2 error against the exact solution.
