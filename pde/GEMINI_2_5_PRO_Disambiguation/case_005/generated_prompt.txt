The partial differential equation to solve is u_t + (-0.7)*u_x + (1.2)*u_y = 0.
The advection velocities are a = -0.7 in the x-direction and b = 1.2 in the y-direction.
The spatial domain is a doubly periodic box [0,1) x [0,1).
The time domain is [0, 0.5].
The initial condition is u(x,y,0) = exp(-80*((x-0.2)^2 + (y-0.6)^2)).
The boundary conditions are periodic in both the x and y dimensions.
The numerical grid has Nx = 256 points in the x-dimension and Ny = 256 points in the y-dimension.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The x-coordinates are x_i = i*dx for i = 0, ..., Nx-1.
The y-coordinates are y_j = j*dy for j = 0, ..., Ny-1.
The spatial discretization for the u_x term is a right-biased first-order upwind scheme, (u_{i+1,j} - u_{i,j})/dx.
The spatial discretization for the u_y term is a left-biased first-order upwind scheme, (u_{i,j} - u_{i,j-1})/dy.
The time integration scheme is Forward Euler.
The time step dt is calculated to exactly hit the final time T=0.5.
First, a preliminary time step dt0 is calculated as dt0 = 0.9 / (|a|/dx + |b|/dy).
The number of time steps is Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
The simulation is run until the final time T = 0.5.
The final solution u(x,y,T) is computed on the 2D grid.
A file named "solution_agent_advection_05.npz" is saved.
The NPZ file contains the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The shape of the solution array u in the NPZ file is (Ny, Nx), corresponding to u[j,i] = u(x_i, y_j).
The NPZ file also contains the scalar metadata T, dx, dy, and dt.
A heatmap or contour plot of the final solution u(x,y,T) is saved as "solution_agent_advection_05.png".
The minimum value of the final solution u is printed to the console.
The maximum value of the final solution u is printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx*dy), is printed to the console.
