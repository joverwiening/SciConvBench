Solve the 1D viscous Burgers' equation: u_t + ∂_x(0.5*u^2) = nu * u_xx.
The simulation spatial domain is x in [0, 1).
The simulation runs until a final time T = 1.0.
The viscosity parameter nu is 0.01.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points.
The spatial step size is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Use Strang splitting for the time integration.
Each full time step dt consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
Solve the diffusion term u_t = nu * u_xx for a duration of dt/2 by transforming to Fourier space.
The Fourier space update for a half diffusion step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Solve the advection term u_t + ∂_x(0.5*u^2) = 0 for a duration of dt using a finite-volume method.
Use the Rusanov (local Lax-Friedrichs) flux for the advection step.
The Rusanov flux between a left state u_L and a right state u_R is F = 0.5*(f(u_L) + f(u_R)) - 0.5*alpha*(u_R - u_L), where f(u) = 0.5*u^2.
The wave speed estimate for the Rusanov flux is alpha = max(abs(u_L), abs(u_R)).
The finite-volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell, respectively.
Determine the time step dt based on a CFL number of 0.4 and an estimated maximum speed of 1.0.
First, calculate a provisional time step dt0 = 0.4 * dx / 1.0.
Then, calculate the number of time steps Nt = ceil(T / dt0).
Finally, set the actual time step to dt = T / Nt.
