The partial differential equation to solve is u_t + q*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The advection velocity is q = 1.5.
The initial condition at t=0 is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The boundary conditions are periodic.
The number of spatial grid points is Nx = 512.
The spatial grid is defined by dx = 1.0/Nx and x_i = i*dx for i = 0 to Nx-1.
Use a 1st-order upwind finite difference for the spatial derivative u_x.
Use the Forward Euler method for time integration.
The time step dt is determined by a CFL number of 0.5.
Calculate an initial time step dt0 = 0.5 * dx / abs(q).
Calculate the number of time steps Nt = ceil(1.0 / dt0).
The final time step for the simulation is dt = 1.0 / Nt.
Compute the solution u(x,t) at the final time T = 1.0.
Save the solution to a file named "solution_molk_018.npz".
