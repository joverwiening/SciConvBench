The PDE to solve is u_xx + u_yy = 0.
The domain is a square defined by x in [0,1] and y in [0,1].
The boundary condition on the side x=0 is u(0,y) = 0.
The boundary condition on the side x=1 is u(1,y) = 0.
The boundary condition on the side y=0 is u(x,0) = 0.
The boundary condition on the side y=1 is u(x,1) = 1.
Discretize the PDE on a uniform grid using the standard 5-point finite difference stencil for the Laplacian.
The grid will have Nx=100 intervals in the x-direction and Ny=100 intervals in the y-direction.
This corresponds to 101 grid points in each direction, including boundaries.
The grid spacing is dx = 1/100 and dy = 1/100.
The grid points are x_i = i*dx for i=0..100 and y_j = j*dy for j=0..100.
Solve the resulting sparse linear system for the interior grid points using a sparse direct solver.
Compute the steady-state solution u(x,y) on this grid.
Save the solution to a file named "solution_agent_laplace_09.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The shape of the u array must be (101, 101) such that u[j,i] corresponds to the solution at (x_i, y_j).
The NPZ file must also contain the scalar values for dx and dy.
Save a heatmap or contour plot of the solution u(x,y) as "solution_agent_laplace_09.png".
Print the minimum value of the solution array u to the console.
Print the maximum value of the solution array u to the console.
Print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy), to the console.
