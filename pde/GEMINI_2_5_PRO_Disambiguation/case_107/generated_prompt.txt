Solve the system of ordinary differential equations for E(t), I(t), and H(t).
The system of equations is dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t).
The system of equations is dI/dt = delta*E - epsilon*I.
The system of equations is dH/dt = theta*I - phi*H.
The time domain for the simulation is t in [0.0, 50.0].
The initial condition for E at t=0 is E(0) = 0.5.
The initial condition for I at t=0 is I(0) = 0.2.
The initial condition for H at t=0 is H(0) = 0.1.
The parameter alpha is 1.2.
The parameter beta is 1.0.
The parameter gamma is 0.5.
The parameter delta is 0.8.
The parameter epsilon is 0.7.
The parameter theta is 0.9.
The parameter phi is 0.4.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt = 0.01.
The total number of time steps is Nt = 5000.
Compute the full state vector [E, I, H] at all time points t_n = 0.0 + n*dt for n=0 to Nt.
Save the results to a file named "solution_molk_006.npz".
The NPZ file must contain a 1D array 't' of time points of length Nt+1.
The NPZ file must contain a 2D array 'Y' of shape [Nt+1, 3] with columns ordered as [E, I, H].
The NPZ file must also contain the scalar parameters alpha, beta, gamma, delta, epsilon, theta, and phi.
Create a line plot showing E(t), I(t), and H(t) versus t on a single figure.
Save the plot as "solution_molk_006.png".
Print the final state values E(50.0), I(50.0), and H(50.0) to the console.
Print the minimum and maximum values of E(t), I(t), and H(t) over the entire simulation time to the console.
