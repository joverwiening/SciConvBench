Task ID is pdebench_cns1d_eta0p1_periodic_smooth.
The PDE category is 1D Compressible Navier–Stokes without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE is solved numerically.
The conservative variable m is defined as rho*v.
The total energy E is defined as p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress sigma is defined as (zeta + 4/3*eta) * v_x.
The parameter zeta is equal to eta.
The PDE system in conservative form is:
The time derivative of rho plus the spatial derivative of m equals 0.
The time derivative of m plus the spatial derivative of (m^2/rho + p - sigma) equals 0.
The time derivative of E plus the spatial derivative of ((E+p)*v - v*sigma) equals 0.
The spatial domain for x is the closed interval [-1, 1].
The time domain for t is the closed interval [0, 0.5].
The final time T is 0.5.
The parameter Gamma is 1.6666666666666667.
The parameter eta is 0.1.
The parameter zeta is 0.1.
The boundary conditions are periodic on x=-1 and x=1.
The initial condition for rho(x,0) is 1.0 + 0.2*sin(pi*x).
The initial condition for v(x,0) is 0.1*cos(pi*x).
The initial condition for p(x,0) is 1.0 + 0.2*cos(pi*x).
The numerical grid is a uniform finite-volume grid with Nx=400 cells.
The cell width dx is (1 - (-1)) / 400 = 0.005.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0 to 399.
The evolved variables are the cell averages of the conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p become non-positive during the simulation, they are clipped to a floor value of 1e-12.
The convective flux is calculated using the Rusanov (local Lax-Friedrichs) numerical flux.
The convective flux vector F_conv(U) is [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical convective flux at an interface is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is computed using a centered difference on cell-centered velocity values.
The viscous stress sigma = (zeta + 4/3*eta)*v_x is computed at cell centers.
The viscous stress at cell interfaces is approximated by averaging the values from the two neighboring cells.
The viscous flux vector F_visc is [0, -sigma, -v*sigma], using interface-averaged v and sigma.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Time integration is performed using the 2-stage SSP-RK2 (Heun's method).
The CFL number is 0.5.
The time step dt is calculated at each step as the minimum of a convective and a viscous time step.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step used is dt = min(dt_conv, dt_visc).
The final time step is adjusted to land exactly at the final time T=0.5.
Periodic boundary conditions are implemented by wrapping indices for ghost cells.
The final state variables rho(x,T), v(x,T), and p(x,T) are computed on the cell centers.
A file named "solution_pdebench_cns1d_eta0p1_periodic_smooth.npz" is saved.
The NPZ file contains the 1D arrays x, rho, v, p.
The NPZ file also contains the scalars Gamma, eta, zeta, T, dx, and CFL.
A plot of rho, v, and p versus x at the final time T is saved as "solution_pdebench_cns1d_eta0p1_periodic_smooth.png".
The minimum and maximum values of rho and p at the final time are printed to the console.
The mean value of rho over the domain at the final time is printed to the console.
