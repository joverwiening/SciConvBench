Task ID: pdebench_darcy_beta1
PDE category: 2D Darcy flow (elliptic)
Unknown field: u(x,y)
The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The coefficient function is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The parameter beta is 1.0.
The spatial domain is (x,y) in (0,1) x (0,1).
Boundary conditions are Dirichlet on the entire boundary, with u = 0.
No closed-form reference solution is required.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 points.
The grid spacing is dx = dy = 1/N.
Grid points are defined as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using 2nd-order finite differences with variable coefficients.
Use face-centered harmonic averaging for the coefficient a(x,y).
The discrete equation for interior nodes (i=1..N-1, j=1..N-1) is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face coefficient a(i+1/2,j) is the harmonic mean 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknowns.
Solve the linear system using the conjugate gradient (CG) method.
The solver tolerance is a relative residual of 1e-10.
A Jacobi preconditioner may be used.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including boundaries.
Save a file named "solution_pdebench_darcy_beta1.npz".
The NPZ file must contain the 1D array 'x', the 1D array 'y', and the 2D array 'u' of shape [N+1, N+1].
The NPZ file must also contain the scalars 'beta', 'N', and 'dx'.
Save a heatmap or contour plot of the solution u(x,y) as "solution_pdebench_darcy_beta1.png".
Print the minimum value of the solution u.
Print the maximum value of the solution u.
Print the final discrete relative residual norm ||Au-b||_2 / ||b||_2 for the interior system.
