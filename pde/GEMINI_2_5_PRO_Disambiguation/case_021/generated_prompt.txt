The PDE to solve is u_t = 0.1 * u_xx.
The spatial domain is x in the interval [0, 1].
The time domain is t in the interval [0, 0.5].
The initial condition is u(x, 0) = cos(pi*x).
The boundary condition at x=0 is u_x(0,t) + 1.0 * u(0,t) = 0.
The boundary condition at x=1 is u_x(1,t) + 1.0 * u(1,t) = 0.
The spatial grid consists of Nx=300 uniform intervals, creating 301 grid points.
The spatial derivative u_xx is discretized using a 2nd-order central difference scheme for interior grid points.
The time step for integration is dt=0.001.
The time integration is performed using the Crank-Nicolson method.
The Robin boundary condition at x=0 is discretized by enforcing the equation (-3*u_0 + 4*u_1 - u_2)/(2*dx) + 1.0*u_0 = 0 at each time step.
The Robin boundary condition at x=1 is discretized by enforcing the equation (3*u_Nx - 4*u_{Nx-1} + u_{Nx-2})/(2*dx) + 1.0*u_Nx = 0 at each time step.
A linear system is formed and solved at each time step to advance the solution.
The final solution u(x, T=0.5) is computed.
The final solution is saved to a file named "solution_agent_diffusion_05.npz".
The saved file contains the 1D array of grid point locations 'x', the 1D array of the solution 'u', and the scalar values 'T', 'dx', and 'dt'.
A line plot of the final solution u versus x is saved as "solution_agent_diffusion_05.png".
The minimum value of the final solution array u is printed to the console.
The maximum value of the final solution array u is printed to the console.
The discrete L2 norm of the final solution, defined as sqrt(sum(u^2)*dx), is printed to the console.
