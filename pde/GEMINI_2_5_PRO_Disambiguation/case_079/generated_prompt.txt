The partial differential equation to solve is the 2D Poisson equation: u_xx + u_yy = f(x,y).
The forcing function is f(x,y) = -((3*pi)^2 + (2*pi)^2)*sin(3*pi*x)*cos(2*pi*y).
The spatial domain is the unit square, (x,y) in [0,1] x [0,1].
The grid will have Nx = 120 intervals in the x-direction and Ny = 120 intervals in the y-direction.
This corresponds to 121 grid points in each direction, including the boundaries.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are located at x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Dirichlet boundary conditions are applied on all four boundaries of the domain.
The value of u on the boundary is set to match the function u(x,y) = sin(3*pi*x)*cos(2*pi*y).
