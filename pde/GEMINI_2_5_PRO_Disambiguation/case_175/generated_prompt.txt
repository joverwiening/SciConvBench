The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1).
The time domain is t in [0, 1.0].
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The PDE parameters are nu = 0.5 and rho = 5.0.
The spatial domain is discretized with Nx = 512 uniform grid points.
The grid spacing is dx = 1.0 / 512.
The grid points are x_i = i*dx for i = 0, ..., 511.
The time step is dt = 0.001.
The number of time steps is Nt = 1000.
The final time is T = 1.0.
The numerical method is Strang splitting for each time step dt.
A half-step of diffusion of duration dt/2 is applied using a Fourier spectral method.
The Fourier space update for the diffusion half-step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
A full-step of the reaction of duration dt is applied by solving the logistic ODE exactly at each grid point.
The exact update for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
A second half-step of diffusion of duration dt/2 is applied using the same Fourier spectral method.
The final solution u(x,T) is computed.
A file named "solution_pdebench_reacdiff_nu0p5_rho5.npz" is saved.
The NPZ file contains the 1D array x of grid point locations, the 1D array u of the solution at time T, and the scalars nu, rho, T, dx, dt, Nx, Nt.
A file named "solution_pdebench_reacdiff_nu0p5_rho5.png" is saved.
The PNG file is a line plot of the solution u versus x at the final time T.
The minimum, maximum, mean, and discrete L2 norm of the final solution u are printed to the console.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
