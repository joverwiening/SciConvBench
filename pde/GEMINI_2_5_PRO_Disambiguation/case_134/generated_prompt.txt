Solve the partial differential equation u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u ).
The spatial domain is x in the interval [0, 1) with periodic boundary conditions.
The time domain is t in the interval [0, 1.0].
The diffusion coefficient D is 0.01.
The parameter gamma is 1.0.
The drift potential is U(x) = cos(2*pi*x), so the velocity is U'(x) = -2*pi*sin(2*pi*x).
The initial condition is u(x,0) = 1.0 + 0.2*sin(2*pi*x).
Discretize the spatial domain with a uniform grid of Nx=512 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_j = j * dx for j = 0, ..., Nx-1.
Use a finite volume method for spatial discretization.
Discretize the advection term using a first-order upwind scheme based on the velocity b(x) = U'(x)/gamma.
Evaluate the velocity for the upwind flux at the cell interface, b_{j+1/2} = b(x_{j+1/2}).
Discretize the diffusion term using a second-order central difference scheme.
Integrate in time using the explicit SSP-RK2 method.
Calculate a provisional time step dt_prov = min(0.4*dx / (2*pi), 0.2*dx^2 / D).
Set the number of time steps to Nt = ceil(1.0 / dt_prov).
The final time step is dt = 1.0 / Nt.
The final output is the numerical solution u(x,t) at time T=1.0.
