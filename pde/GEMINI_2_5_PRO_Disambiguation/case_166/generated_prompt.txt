The task is to solve a 1D compressible Navier-Stokes system of PDEs.
The PDE system is defined in conservative form for density (rho), momentum (m), and total energy (E).
The vector of conserved variables is U = [rho, m, E].
The conservative flux is F = [m, m^2/rho + p - sigma, (E+p)*v - v*sigma].
The PDE is U_t + F_x = 0.
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The momentum is m = rho*v.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The parameter Gamma is 1.6666666666666667.
The parameter eta is 1e-08.
The parameter zeta is equal to eta.
The spatial domain is x from -1 to 1.
The temporal domain is t from 0 to 0.2.
The final time T is 0.2.
The boundary conditions at x=-1 and x=1 are transmissive (zero-gradient).
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=0.0, p=10.0.
For x >= 0, the initial state is rho=1.0, v=0.0, p=0.1.
The simulation will use a uniform finite-volume grid with Nx=800 cells.
The cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2.0/Nx.
The time integration scheme is the 2-stage SSP-RK2 method (Heun's method).
The time step is determined by a CFL number of 0.5.
The time step dt is calculated as CFL * dx / max(|v|+c) over the entire grid, where c is the sound speed sqrt(Gamma*p/rho).
The inviscid part of the flux at cell interfaces is computed using the Rusanov (local Lax-Friedrichs) Riemann solver.
The left and right states for the Riemann solver at each interface are determined using a second-order MUSCL reconstruction with the MINMOD slope limiter.
The velocity gradient v_x for the viscous stress is computed at cell centers using a second-order centered difference.
The viscous stress sigma at cell interfaces is computed by averaging the values from the two adjacent cell centers.
The simulation will compute the solution rho(x,T), v(x,T), p(x,T) at the cell centers at the final time T=0.2.

The NPZ file must contain the 1D arrays x, rho, v, p.
The NPZ file must also contain the scalars Gamma, eta, zeta, T, dx, CFL.
