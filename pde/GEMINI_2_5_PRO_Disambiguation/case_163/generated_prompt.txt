The PDE to be solved is the 1D Compressible Navier-Stokes system for rho(x,t), v(x,t), and p(x,t).
The conservative variables are U = [rho, m, E], where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE in conservative form is rho_t + (m)_x = 0.
The PDE in conservative form is m_t + (m^2/rho + p - sigma)_x = 0.
The PDE in conservative form is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time T is 0.2.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is equal to eta, so zeta is 1e-08.
Boundary conditions are transmissive (outflow) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial density rho_L is 1.0.
For x < 0, the initial velocity v_L is -0.75.
For x < 0, the initial pressure p_L is 1.0.
For x >= 0, the initial density rho_R is 0.125.
For x >= 0, the initial velocity v_R is 0.0.
For x >= 0, the initial pressure p_R is 0.1.
Use a uniform finite-volume grid with Nx=800 cells.
The cell spacing dx is (1 - (-1)) / 800 = 0.0025.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,799.
Evolve the conservative variables U = [rho, m, E] as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below this value.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective part.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x at cell centers using a centered difference.
The viscous stress sigma = (zeta + 4/3*eta)*v_x is computed at cell centers.
Approximate sigma at cell interfaces by averaging the values from the two adjacent cell centers.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The values of v and sigma in F_visc at an interface are computed by averaging the values from adjacent cell centers.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The CFL number is 0.9.
The time step dt is calculated at each step as the minimum of a convective and a viscous time step.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step is dt = min(dt_conv, dt_visc).
Adjust the final time step to end the simulation exactly at T=0.2.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell value.
Compute the final solution rho(x,T), v(x,T), and p(x,T) on the cell centers at T=0.2.

The NPZ file must contain the 1D arrays 'x', 'rho', 'v', 'p'.
The NPZ file must also contain the scalars 'Gamma', 'eta', 'zeta', 'T', 'dx', 'CFL'.
Save a plot of the final solution rho, v, and p versus x as "solution_pdebench_cns1d_sod4_eta1em8_outflow.png".
The plot should contain three panels or three separate plots for each variable.
Print the minimum and maximum of the final rho array to the console.
