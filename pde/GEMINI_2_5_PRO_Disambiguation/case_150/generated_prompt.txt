The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The simulation parameter is nu = 0.001.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The simulation runs from t=0 to the final time T=1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial domain is discretized using a uniform grid with Nx=512 points.
The grid spacing is dx = 1.0/Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
The time step is determined by a CFL condition.
The CFL number is 0.4.
The maximum expected wave speed is 1.0.
An initial time step is calculated as dt0 = CFL * dx / 1.0.
The number of time steps is Nt = ceil(T / dt0).
The final time step used for the simulation is dt = T / Nt.
The numerical method is Strang splitting for each time step dt.
The first substep is a diffusion step of duration dt/2.
The diffusion step is solved exactly in Fourier space.
The Fourier transform of u, u_hat(k), is computed.
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The Fourier coefficients are updated by u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The solution is transformed back to physical space using an inverse FFT, taking the real part.
The second substep is an advection step of duration dt.
The advection equation is u_t + ∂_x(0.5*u^2) = 0.
The advection step is solved using a finite-volume method with a Rusanov flux.
The flux function is f(u) = 0.5*u^2.
The numerical flux F at the interface between cell j (u_left) and cell j+1 (u_right) is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
Each cell j is updated using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the j+1/2 interface and F_minus is the flux at the j-1/2 interface.
The third substep is another diffusion step of duration dt/2, identical to the first substep.
The final solution u(x,T) is computed on the grid.
