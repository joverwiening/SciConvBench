The task is to solve a partial differential equation numerically.
The PDE is the 1D wave equation: u_tt = c^2 * u_xx.
The wave speed c is 1.0.
The spatial domain is x in [0, 1].
The time domain is t in [0, 1.0].
The boundary condition at x=0 is u(0,t) = 0.
The boundary condition at x=1 is u(1,t) = 0.
The initial condition for the field is u(x,0) = sin(pi*x).
The initial condition for the time derivative of the field is u_t(x,0) = 0.
The spatial domain is to be discretized with a uniform grid of Nx=400 intervals, resulting in 401 grid points.
The spatial step size is dx = 1.0 / Nx.
The spatial second derivative u_xx is to be approximated using a second-order central difference scheme.
The temporal second derivative u_tt is to be approximated using a second-order central difference scheme (leapfrog).
The time step dt must be chosen to satisfy the CFL condition c*dt/dx <= 0.9.
First, calculate a preliminary time step dt0 = 0.9 * dx / c.
Then, determine the number of time steps Nt = ceil(T / dt0), where the final time T is 1.0.
The final time step is dt = T / Nt.
The simulation must be initialized for the first two time levels.
The solution at t=0, u^0, is given by the initial condition u(x,0).
The solution at the first time step, u^1, is computed using a second-order Taylor expansion: u^1 = u^0 + dt*u_t(x,0) + 0.5*dt^2*(c^2*u_xx^0).
The term u_xx^0 should be computed using the same second-order central difference formula applied to u^0.
The Dirichlet boundary conditions must be enforced at every time step.
The final numerical solution u(x,T) at T=1.0 must be computed.
An NPZ file named "solution_agent_wave_01.npz" must be saved.
The NPZ file must contain the 1D array of grid point coordinates 'x', the 1D array of the final solution 'u', and the scalar values 'T', 'dx', and 'dt'.
A PNG file named "solution_agent_wave_01.png" must be saved.
The PNG file must be a line plot of the final solution u against x.
The minimum and maximum values of the final solution u must be printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx), must be printed to the console.
The exact solution for verification is u_exact(x,t) = cos(pi*t)*sin(pi*x).
The maximum absolute error between the numerical solution and the exact solution at T=1.0 must be computed and printed.
The L2 error between the numerical solution and the exact solution at T=1.0 must be computed and printed.
