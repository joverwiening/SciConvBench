The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid spacing is dx = 1.0 / 512.
The grid points are x_j = j*dx for j=0,...,511.
Use a fixed time step of dt = 0.001.
The total number of time steps is Nt = 1000.
The final time is T = 1.0.
Use Strang splitting for the time integration.
Each full time step dt consists of three sub-steps.
First, solve the diffusion equation for a half-step of dt/2 using the Fourier spectral method.
The Fourier wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
The diffusion update in Fourier space is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Second, solve the reaction ODE du/dt = rho * u*(1 - u) for a full step of dt.
The exact update for the reaction step at each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation for another half-step of dt/2 using the Fourier spectral method.
Compute the solution u(x,T) at the final time T=1.0.
Save a file named "solution_pdebench_reacdiff_nu5_rho1.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu5_rho1.png".
Print the minimum, maximum, and mean of the final solution u(x,T).
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
