The PDE to solve is u_t = q1*u_xx + q2*u*(1-u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx=512 points.
The spatial step size is dx = 1.0/Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Use a constant time step of dt = 0.001.
Integrate from t=0 to the final time T=1.0, taking 1000 steps.
Use the Strang splitting method for time integration.
Split the PDE into a diffusion part (u_t = q1*u_xx) and a reaction part (u_t = q2*u*(1-u)).
A single time step from t_n to t_{n+1} consists of three sequential sub-steps:
1. Solve the reaction part for a half time step (dt/2).
2. Solve the diffusion part for a full time step (dt).
3. Solve the reaction part for another half time step (dt/2).
Solve the diffusion part using a spectral method with the Fast Fourier Transform (FFT).
Solve the reaction part by applying the exact analytical solution of the logistic ODE at each grid point.
At the final time T=1.0, compute the solution u(x,T).
Save a file named "solution_molk_020.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'T', 'dx', 'Nx', 'q1', and 'q2'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_molk_020.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u(x,T) to standard output.
