Solve the 1D viscous Burgers' equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The viscosity parameter is nu = 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The simulation runs until a final time T = 1.0.
Use a uniform spatial grid with Nx = 512 points, resulting in a grid spacing of dx = 1.0/512.
The grid points are defined as x_i = i*dx for i = 0, ..., Nx-1.
Use Strang splitting for the time integration.
Each full time step dt consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
Solve the diffusion half-step u_t = nu * u_xx for a duration of dt/2 exactly in Fourier space.
The Fourier space update for diffusion is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Solve the advection full-step u_t + ∂_x(0.5*u^2) = 0 for a duration of dt using a finite-volume method.
The finite-volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The numerical flux at the interface between u_left and u_right is the Rusanov flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The physical flux is f(u) = 0.5*u^2.
The wave speed for the Rusanov flux is alpha = max(abs(u_left), abs(u_right)).
Use periodic indexing for calculating fluxes at the domain boundaries.
The time step dt is determined by a Courant-Friedrichs-Lewy (CFL) condition.
Set an initial time step dt0 = 0.4 * dx / 1.0, based on CFL=0.4 and an estimated max speed of 1.0.
Calculate the number of time steps as Nt = ceil(T/dt0).
Set the final time step as dt = T/Nt to reach the final time exactly.
After the simulation, save the results to a file named "solution_pdebench_burgers_nu1.npz".
The NPZ file must contain the 1D arrays x and the final solution u, and the scalars nu, T, dx, dt, Nx, Nt.
Create a line plot of the final solution u versus x and save it as "solution_pdebench_burgers_nu1.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete mean value of the final solution u, calculated as mean(u).
Print the discrete L2 norm of the final solution u, calculated as sqrt(sum(u^2)*dx).
