The partial differential equation to solve is p_t = ∂/∂x( 1.0*x*p ) + 0.1*p_xx.
This equation must be solved in its conservative form, p_t = -∂x J, where the flux is J = -(gamma*x*p + D*p_x).
The parameter gamma is 1.0.
The parameter D is 0.1.
The spatial domain is the closed interval [-L, L], where L is 3.0.
The simulation runs from t=0 to a final time T=1.0.
The boundary conditions are reflecting, meaning there is zero flux at x = -L and x = L.
The flux J must be set to zero at both boundaries for all time t.
The initial condition p(x,0) is a normalized Gaussian distribution.
First, define an unnormalized Gaussian q(x) = exp(-(x-1)^2 / (2*sigma0^2)).
The parameter sigma0 for the initial condition is 0.2.
Discretize q(x) on the numerical grid.
Normalize the discretized q(x) such that the sum of its values multiplied by dx equals 1.
The initial condition p(x,0) is this normalized, discretized function.
The numerical method is a cell-centered finite-volume scheme.
The spatial grid consists of Nx=2000 uniform cells on the domain [-3.0, 3.0].
The width of each cell is dx = (2*L)/Nx.
The center of cell i is located at x_i = -L + (i+0.5)*dx, for i from 0 to Nx-1.
The time integration method is Forward Euler.
The time step is dt = 1e-4.
The number of time steps is Nt = 10000.
The flux J at the interface between cell i and cell i+1, J_{i+1/2}, is discretized as a sum of an advective and a diffusive part.
The advective part of the flux uses an upwind scheme based on the sign of the velocity v(x) = -gamma*x.
The diffusive part of the flux uses a central difference scheme.
