Solve the partial differential equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain for x is the periodic interval [0, 1).
The final simulation time is T = 1.0.
The viscosity parameter is nu = 0.02.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points.
The spatial step size is dx = 1.0 / Nx.
The grid points are x_i = i * dx for i from 0 to Nx-1.
Use Strang splitting for the time integration.
A full time step dt consists of a half-step of diffusion, a full step of advection, and a final half-step of diffusion.
Each diffusion half-step of duration dt/2 is solved exactly in Fourier space.
The Fourier space update for the diffusion step is u_hat(k) = u_hat(k) * exp(-nu * k^2 * (dt/2)).
The wavenumbers are k = 2 * pi * fftfreq(Nx, d=dx).
The advection full-step of duration dt is solved with a finite-volume method using the Rusanov flux.
The flux function for the advection step is f(u) = 0.5 * u^2.
The Rusanov flux between cells with values u_left and u_right is F = 0.5 * (f(u_left) + f(u_right)) - 0.5 * alpha * (u_right - u_left).
The local wave speed estimate for the Rusanov flux is alpha = max(abs(u_left), abs(u_right)).
The finite volume update for cell j is u_new[j] = u[j] - (dt/dx) * (F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell.
The time step dt is determined by a CFL condition with a CFL number of 0.4.
The maximum wave speed for the CFL calculation is estimated as 1.0.
An initial time step is calculated as dt0 = 0.4 * dx / 1.0.
The total number of time steps is Nt = ceil(T / dt0).
The final time step used for the simulation is dt = T / Nt.
Compute the solution u(x,T) at the final time T.
Save the solution to a file named "solution_pdebench_burgers_nu0p02.npz".
The NPZ file must contain the 1D arrays x and u, and the scalars nu, T, dx, dt, Nx, Nt.
