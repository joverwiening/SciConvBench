Task ID is pdebench_cns1d_eta1em8_outflow_smooth.
The PDE to solve is the 1D Compressible Navier-Stokes system without heat conduction.
The unknown fields are density rho(x,t), velocity v(x,t), and pressure p(x,t).
The conservative variables are U = [rho, m, E], where m = rho*v is the momentum and E = p/(Gamma-1) + 0.5*rho*v^2 is the total energy.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE is expressed in conservative form as rho_t + (m)_x = 0.
The momentum equation is m_t + (m^2/rho + p - sigma)_x = 0.
The energy equation is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.5].
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions at x=-1 and x=1 are transmissive (outflow), implemented with a zero-gradient condition.
The initial condition for density is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial condition for velocity is v(x,0) = 0.1*cos(pi*x).
The initial condition for pressure is p(x,0) = 1.0 + 0.2*cos(pi*x).
The numerical grid is a uniform finite-volume grid with Nx=400 cells.
The cell width is dx = 2.0/400 = 0.005.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,399.
The conservative variables U = [rho, m, E] are evolved as cell averages.
The pressure is recovered from the conservative variables using the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p fall below 1e-12 during the simulation, they are clipped to 1e-12.
The convective flux is calculated using the Rusanov (local Lax-Friedrichs) scheme.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The velocity gradient v_x is computed using a centered difference on cell-centered velocity values.
The viscous stress sigma is computed at cell centers.
The viscous stress at cell interfaces is approximated by averaging the values from the two neighboring cell centers.
The viscous flux vector [0, -sigma, -v*sigma] is added to the convective flux at each interface, using interface-averaged values for v and sigma.
Time integration is performed using the 2-stage SSP-RK2 (Heun's) method.
The time step dt is calculated at each stage.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ), with a CFL number of 0.5.
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step used is dt = min(dt_conv, dt_visc).
The final time step is adjusted to end the simulation at exactly T=0.5.
Outflow boundary conditions are implemented by setting ghost cell values equal to the nearest interior cell's values.
