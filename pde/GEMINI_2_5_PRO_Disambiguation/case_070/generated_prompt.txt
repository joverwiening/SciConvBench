The PDE to solve is the biharmonic equation ∇^4 u = f(x,y).
The forcing function is f(x,y) = 4*pi^4*sin(pi*x)*sin(pi*y).
The domain is the unit square [0,1] x [0,1].
The boundary conditions are u=0 and Δu=0 on all four boundaries.
The numerical method is to decompose the problem into two Poisson equations.
First, solve Δv = f for an intermediate variable v, with the boundary condition v=0.
Second, solve Δu = v for the final solution u, with the boundary condition u=0.
Discretize both Poisson equations using the standard 5-point finite difference stencil for the Laplacian.
Use a uniform grid with Nx = 120 intervals in the x-direction and Ny = 120 intervals in the y-direction.
This results in a grid of 121 by 121 points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Solve the resulting linear systems using a sparse direct solver.
Compute the steady-state solution u(x,y) on the grid.
Save the solution to a file named "solution_agent_other_05_biharmonic.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, the 2D solution array u, and the scalar grid spacings dx and dy.
The shape of the u array should be (121, 121) such that u[j,i] corresponds to u(x_i, y_j).
Save a heatmap or contour plot of the solution u(x,y) to a file named "solution_agent_other_05_biharmonic.png".

Print the maximum value of the computed solution u.
Print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy).
