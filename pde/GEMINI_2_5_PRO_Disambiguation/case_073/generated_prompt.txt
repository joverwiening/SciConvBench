The PDE to solve is u_tt + (0.01)*u_xxxx = 0.
This is the Euler–Bernoulli beam equation.
The spatial domain is x in [0, 1].
The time domain is t in [0, 1.0].
The parameter kappa is 0.01.
The boundary conditions are for a simply-supported beam at x=0 and x=1.
The boundary conditions are u(0,t)=0, u(1,t)=0, u_xx(0,t)=0, and u_xx(1,t)=0.
The initial condition for the displacement is u(x,0)=sin(pi*x).
The initial condition for the velocity is u_t(x,0)=0.
The spatial grid has Nx=800 uniform intervals, resulting in 801 points.
The grid spacing is dx = 1/Nx.
The grid points are x_i = i*dx for i=0 to 800.
The time step is dt=1e-4.
The number of time steps is Nt=10000, for a final time T=1.0.
The spatial discretization uses a sine-series spectral method on the interior grid points.
Use the discrete sine transform of type I (DST-I) to obtain modal coefficients û_n for n=1 to Nx-1.
The PDE transforms into a set of ODEs for each mode n: d^2 û_n / dt^2 + kappa*(n*pi)^4 * û_n = 0.
The angular frequency for each mode is omega_n = (n*pi)^2*sqrt(kappa).
The time integration is performed by solving the modal ODEs exactly.
The solution for each mode is û_n(t) = û_n(0)*cos(omega_n*t) + (v̂_n(0)/omega_n)*sin(omega_n*t).
û_n(0) are the DST-I coefficients of the initial displacement u(x,0).
v̂_n(0) are the DST-I coefficients of the initial velocity u_t(x,0).
Compute the solution u(x,T) at the final time T=1.0.
The solution u(x,T) on the interior grid is found by applying the inverse DST-I to the coefficients û_n(T).
