The PDE to solve is u_xx + u_yy = f(x,y).
The forcing function is f(x,y) = -5*pi^2 * sin(2*pi*x) * sin(pi*y).
The spatial domain is the unit square, (x,y) in [0, 1] x [0, 1].
The boundary conditions are Dirichlet, with u=0 on all four boundaries of the domain.
The exact solution for verification is u_exact(x,y) = sin(2*pi*x) * sin(pi*y).
Discretize the PDE using a standard 5-point finite difference stencil for the Laplacian on a uniform grid.
The grid will have Nx = 120 intervals in the x-direction and Ny = 120 intervals in the y-direction.
This corresponds to 121x121 grid points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Solve the resulting sparse linear system of equations for the interior grid points using a sparse direct solver.
Compute the steady-state numerical solution u(x,y) on the grid.

The shape of the u array must be (Ny+1, Nx+1), corresponding to u[j,i] for y_j and x_i.
The NPZ file must also contain the scalar metadata values for dx and dy.
