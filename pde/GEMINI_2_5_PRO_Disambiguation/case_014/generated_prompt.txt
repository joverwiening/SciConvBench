Solve the partial differential equation u_t + u*u_x = 0.005*u_xx.
The spatial domain is x in [0, 1).
The temporal domain is t in [0, 0.2].
The boundary conditions are periodic.
The initial condition is u(x, 0) = 0.5 + sin(2*pi*x).
Use a uniform spatial grid with Nx = 1200 points, such that x_i = i/Nx for i = 0, ..., Nx-1.
The spatial step size is dx = 1/1200.
Use a time step of dt = 5e-5.
The simulation will run for Nt = 4000 steps to reach the final time T = 0.2.
Discretize the PDE in its conservative form u_t + (f(u))_x = nu*u_xx, where f(u) = 0.5*u^2 and nu = 0.005.
Discretize the convective term (f(u))_x using a finite-volume scheme with the Rusanov flux.
The Rusanov flux is F_{i+1/2} = 0.5*(f(u_i) + f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1} - u_i).
The local wave speed is alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
The discrete convective operator is (F_{i+1/2} - F_{i-1/2}) / dx.
Discretize the diffusive term nu*u_xx using a second-order central difference: nu * (u_{i+1} - 2*u_i + u_{i-1}) / dx^2.
Integrate in time using a first-order IMEX scheme where the convective term is treated explicitly and the diffusive term is treated implicitly.
The update formula is (u^{n+1} - u^n)/dt + explicit_convection_term^n = implicit_diffusion_term^{n+1}.
Solve the resulting sparse linear system for the solution at each time step.
Compute the solution u(x, T) at the final time T = 0.2.

The NPZ file must contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, and the scalars 'T', 'dx', and 'dt'.
