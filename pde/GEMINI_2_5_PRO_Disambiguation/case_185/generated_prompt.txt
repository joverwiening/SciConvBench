The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The diffusion coefficient nu is 2.0.
The reaction coefficient rho is 10.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points.
The spatial step size dx is 1.0 / Nx.
The grid points are x_j = j*dx for j=0,...,Nx-1.
Use a fixed time step dt = 0.001.
The number of time steps Nt is 1000, reaching the final time T=1.0.
Use Strang splitting for time integration.
Each time step of size dt consists of three sub-steps.
The first sub-step is a diffusion step of duration dt/2.
The diffusion step is solved in Fourier space: u_hat(k) is updated by multiplying with exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The second sub-step is a reaction step of duration dt.
The reaction step is solved exactly for the ODE du/dt = rho*u*(1-u) using the update rule: u is updated to (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)) at each grid point.
The third sub-step is a diffusion step of duration dt/2, identical to the first sub-step.
Compute the solution u(x,t) at the final time T=1.0.
Save the solution to a file named "solution_pdebench_reacdiff_nu2_rho10.npz".
The NPZ file must contain the 1D array 'x' of grid point locations, the 1D array 'u' of the solution at T, and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Create a line plot of the final solution u(x,T) versus x.
Save the plot as "solution_pdebench_reacdiff_nu2_rho10.png".
Print the minimum, maximum, and mean of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
