Solve the 1D viscous Burgers' equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx for the unknown field u(x,t).
The spatial domain for x is [0, 1).
The simulation runs until the final time T=1.0.
The viscosity parameter nu is 0.4.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx=512 points.
The grid spacing is dx = 1.0/Nx.
The grid points are x_i = i*dx for i=0 to Nx-1.
Use Strang splitting for the time integration.
The total number of time steps Nt is ceil(T/dt0), where dt0 = 0.4*dx/1.0.
The time step size is dt = T/Nt.
Each time step from t to t+dt consists of three sub-steps.
First, solve the diffusion equation u_t = nu * u_xx for a duration of dt/2.
The diffusion step is solved exactly in Fourier space.
The Fourier space update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Second, solve the advection equation u_t + ∂_x(0.5*u^2) = 0 for a duration of dt.
The advection step is solved using a finite-volume method with Rusanov flux.
The flux between cell j (u_left) and cell j+1 (u_right) is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The flux function is f(u) = 0.5*u^2.
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The cell update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the j+1/2 interface and F_minus is the flux at the j-1/2 interface.
Third, solve the diffusion equation u_t = nu * u_xx for another duration of dt/2 using the same Fourier method.
Compute the solution u(x,T) at the final time T.
Save the output to a file named "solution_pdebench_burgers_nu0p4.npz".
The NPZ file must contain the arrays 'x' and 'u', and the scalars 'nu', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_burgers_nu0p4.png".
Print the minimum value of the final solution u.
