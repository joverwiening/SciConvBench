The partial differential equation to solve is u_t = -1.0 * ∂_x(sin(u)) + (0.05/pi) * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 0.5].
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=1024 points.
The grid points are defined as x_j = j/1024 for j = 0, 1, ..., 1023.
The spatial discretization uses the method of lines, resulting in a system of ordinary differential equations du/dt = L(u).
The spatial operator L(u) is composed of a convection term and a diffusion term.
The convection term ∂_x(sin(u)) is discretized at grid point j using a conservative finite-volume flux: (F_{j+1/2} - F_{j-1/2}) / (1.0/1024).
The numerical flux F_{j+1/2} is the Rusanov flux, calculated as 0.5 * (sin(u_j) + sin(u_{j+1})) - 0.5 * alpha * (u_{j+1} - u_j).
The Rusanov wave speed alpha is calculated as the maximum value of |cos(u)| over the entire spatial grid at the current evaluation time.
The diffusion term u_xx is discretized at grid point j using a second-order central difference: (u_{j+1} - 2*u_j + u_{j-1}) / (1.0/1024)^2.
Time integration is performed using the second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
For each SSP-RK2 stage, the Rusanov wave speed alpha must be recomputed based on the input state vector for that stage.
The time step dt is constant for the entire simulation.
First, calculate a provisional time step based on CFL=0.2.
The convection time step limit is dt_adv = 0.2 * (1.0/1024) / 1.0.
The diffusion time step limit is dt_diff = 0.2 * (1.0/1024)^2 / (0.05/pi).
The provisional time step is dt_provisional = min(dt_adv, dt_diff).
The number of time steps is Nt = ceil(0.5 / dt_provisional).
The final time step used for the simulation is dt = 0.5 / Nt.
The simulation runs for exactly Nt time steps.
