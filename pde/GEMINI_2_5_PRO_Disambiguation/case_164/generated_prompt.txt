Solve the 1D compressible Navier-Stokes equations for density (rho), momentum (m=rho*v), and total energy (E).
The conservative state vector is U = [rho, m, E].
The total flux is F(U) = [m, m^2/rho + p - sigma, (E+p)*v - v*sigma].
The pressure is p = (Gamma-1)*(E - 0.5*m^2/rho).
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1].
The simulation runs from t=0 to the final time T=0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=0.0, p=2.0.
For x >= 0, the initial state is rho=0.125, v=0.0, p=0.2.
Boundary conditions at both x=-1 and x=1 are transmissive (zero-gradient).
Use a finite volume method with Nx=800 uniform cells.
The cell centers are x_i = -1 + (i+0.5)*dx for i=0..Nx-1, where dx = 2.0/Nx.
Discretize the convective terms using the Rusanov (local Lax-Friedrichs) numerical flux at cell interfaces.
The Rusanov flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L), where F_conv is the convective part of the flux.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
Discretize the viscous terms by first computing v_x at each cell center using a second-order centered difference.
Compute the viscous stress sigma at each cell center using the cell-centered v_x.
The viscous stress at a cell interface is the arithmetic average of the sigma values from the two adjacent cell centers.
The velocity at a cell interface is the arithmetic average of the v values from the two adjacent cell centers.
The viscous flux contribution at the interface is then computed as [0, -sigma_interface, -v_interface * sigma_interface].
Integrate in time using the 2-stage Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
Use a Courant-Friedrichs-Lewy (CFL) number of 0.9.
The time step dt is calculated at each stage as dt = CFL * dx / max_i(|v_i| + c_i) over all cells i.
At the final time T=0.2, compute the primitive variables rho, v, p at each cell center.
