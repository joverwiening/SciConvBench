Solve the partial differential equation u_t + (1.0)*u_x = 0 for the unknown field u(x,t).
The spatial domain for x is the periodic interval [0,1).
The temporal domain for t is [0, 1.0].
The advection speed parameter 'a' is 1.0.
The initial condition at t=0 is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=800 points on [0,1).
The spatial grid spacing is dx=1/Nx.
Discretize the spatial derivative u_x using a 1st-order upwind scheme.
Integrate in time using the Forward Euler method.
The final time T is 1.0.
Calculate an initial time step dt0 = 0.9*dx/|a|.
Calculate the number of time steps Nt = ceil(T/dt0).
The final time step used for integration is dt = T/Nt.
Apply periodic boundary conditions.
Compute the solution u(x,T) at the final time T=1.0.
Save the results to a file named "solution_agent_advection_01.npz".
The NPZ file must contain the 1D coordinate array 'x', the 1D solution array 'u', and the scalar values T, dx, and dt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_agent_advection_01.png".
Print the minimum and maximum values of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
The exact solution for verification is u(x,t) = sin(2*pi*(x-t)).
Compute and print the maximum absolute error between the numerical and exact solutions at the final time.
Compute and print the L2 error norm between the numerical and exact solutions at the final time.
