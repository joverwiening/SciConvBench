The PDE to solve is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The unknown field is u(x,y).
The spatial domain is (x,y) in (0,1) x (0,1).
The coefficient function is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The parameter beta is 0.01.
The boundary condition is u = 0 on all boundaries of the domain.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 points per direction.
The grid spacing is dx = 1/N and dy = 1/N.
The grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a second-order finite difference scheme for a variable coefficient operator.
The discretization for an interior node (i,j) is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The coefficients at cell faces are computed using harmonic averaging.
The face coefficient a(i+1/2,j) is calculated as 2*a(x_i,y_j)*a(x_{i+1},y_j) / (a(x_i,y_j)+a(x_{i+1},y_j)).
Analogous formulas apply for the other face coefficients.
Assemble the sparse linear system Au=b for the interior grid points.
Solve the linear system using the conjugate gradient method.
The solver tolerance is a relative residual norm of 1e-10.
A Jacobi preconditioner may optionally be used.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including the boundaries.
Save the output to a file named "solution_pdebench_darcy_beta0p01.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The NPZ file must also contain the scalars beta, N, and dx.
Save a heatmap or contour plot of the solution u(x,y) to a file named "solution_pdebench_darcy_beta0p01.png".
Print the minimum value of the solution u to the console.
Print the maximum value of the solution u to the console.
