The partial differential equation to solve is u_t = (0.01)^2 * (u_xx + u_yy) + u - u^3.
The unknown field is u(x,y,t).
The spatial domain is (x,y) in [0,1) x [0,1).
The time domain is t in [0,0.2].
The initial condition is u(x,y,0) = 0.1 * cos(2*pi*x) * cos(2*pi*y).
The boundary conditions are periodic in both the x and y directions.
Use a uniform grid with Nx = 256 points in the x-direction and Ny = 256 points in the y-direction.
The grid spacing in x is dx = 1.0 / 256.
The grid spacing in y is dy = 1.0 / 256.
The x grid points are x_i = i * dx for i = 0, ..., Nx-1.
The y grid points are y_j = j * dy for j = 0, ..., Ny-1.
The time step is dt = 0.0002.
Discretize the Laplacian term (u_xx + u_yy) using a standard 5-point finite difference stencil.
Use a semi-implicit time-stepping scheme: (u^{n+1} - u^n)/dt = (0.01)^2 * Δ_h u^{n+1} + u^n - (u^n)^3, where Δ_h is the discretized Laplacian.
At each time step, solve the sparse linear system resulting from the semi-implicit scheme for u^{n+1}.
Compute the solution u(x,y,T) at the final time T = 0.2.
Save the numerical solution to a file named "solution_agent_allen_cahn_04.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u at T=0.2.
The solution array u must have shape (Ny, Nx) such that u[j,i] corresponds to u(x_i, y_j).
The NPZ file must also contain the scalar metadata values T, dx, dy, and dt.
Save a heatmap or contour plot of the final solution u(x,y,T) to a file named "solution_agent_allen_cahn_04.png".
