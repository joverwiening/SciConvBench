Task ID is pdebench_cns1d_eta1em8_periodic_smooth.
The PDE category is 1D Compressible Navier–Stokes without heat conduction.
The unknown fields to solve for are rho(x,t), v(x,t), and p(x,t).
The governing PDE is given in conservative form for the variables rho, m, and E.
The momentum is m = rho*v.
The total energy is E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The first PDE is rho_t + (m)_x = 0.
The second PDE is m_t + (m^2/rho + p - sigma)_x = 0.
The third PDE is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.5].
The final time is T = 0.5.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions are periodic on x=-1 and x=1.
The initial condition for density is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial condition for velocity is v(x,0) = 0.1*cos(pi*x).
The initial condition for pressure is p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx=400 cells.
The grid spacing is dx = 0.005.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,399.
Evolve the conservative state vector U = [rho, m, E] representing cell averages.
Use the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below this value.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective terms.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ).
The speed of sound is c = sqrt(Gamma*p/rho).
The Rusanov numerical flux at an interface is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x using a centered difference on cell-centered velocity values.
The viscous stress sigma = (zeta + 4/3*eta)*v_x is computed at cell centers.
Approximate sigma at cell interfaces by averaging the values from the two neighboring cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
Compute the viscous flux at interfaces using interface-averaged values for v and sigma.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The time step dt is calculated at each step as the minimum of a convective and a viscous time step.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The CFL number is 0.8.
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step is dt = min(dt_conv, dt_visc).
Adjust the final time step to land exactly at T = 0.5.
Implement periodic boundary conditions by wrapping around the grid indices for ghost cells.
