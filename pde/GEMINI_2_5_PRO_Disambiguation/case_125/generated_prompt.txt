The PDE to solve is u_t = -q1*∂_x( 0.5*u^2 ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.1.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j/Nx for j=0, ..., Nx-1.
The spatial step size is dx = 1/Nx.
Discretize the convective term -q1*∂_x( 0.5*u^2 ) at grid point j as -q1 * (F_{j+1/2} - F_{j-1/2}) / dx.
The numerical flux F is the Rusanov flux, defined as F_{j+1/2} = 0.5 * (f(u_j) + f(u_{j+1})) - 0.5 * alpha_{j+1/2} * (u_{j+1} - u_j).
The physical flux function is f(u) = 0.5*u^2.
The local wave speed for the Rusanov flux is alpha_{j+1/2} = max(|u_j|, |u_{j+1}|).
Discretize the diffusion term (q2/pi)*u_xx using a second-order central difference: (q2/pi) * (u_{j+1} - 2*u_j + u_{j-1}) / dx^2.
Handle all spatial indices modulo Nx to implement the periodic boundary conditions.
Integrate the resulting system of ODEs in time using the SSP-RK2 (Heun) method.
Use a fixed time step dt for the entire simulation.
Calculate the effective diffusion coefficient as D_eff = q2/pi.
Calculate a preliminary convective time step dt_conv = 0.4 * dx / max|u(x,0)|, using max|u(x,0)|=1.
Calculate a preliminary diffusive time step dt_diff = 0.4 * dx^2 / D_eff.
Set an initial time step dt0 = min(dt_conv, dt_diff).
Set the total number of time steps to Nt = ceil(0.5 / dt0).
The final time step for the simulation is dt = 0.5 / Nt.
Run the simulation until the final time T=0.5 is reached.
