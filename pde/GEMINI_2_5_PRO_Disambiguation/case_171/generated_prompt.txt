The PDE to solve is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The domain is the unit square (0,1) x (0,1).
The coefficient function is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The parameter beta is 100.0.
Boundary conditions are Dirichlet with u = 0 on all boundaries.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in (N+1)x(N+1) grid points.
The grid spacing is dx = dy = 1/N.
Grid points are defined as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a 2nd-order finite difference scheme for the interior grid points.
The discrete equation at an interior node (i,j) is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Evaluate the coefficient a(x,y) at cell centers (i*dx, j*dy) to get a(i,j).
Calculate the face-centered coefficients using the harmonic mean, for example, a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknown values of u.
Solve the linear system using the Conjugate Gradient (CG) method.
The stopping criterion for the CG solver is a relative residual norm of 1e-10.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including the boundary values.
Save the output to a file named "solution_pdebench_darcy_beta100.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u of shape (N+1, N+1).
The NPZ file must also contain the scalar values for beta, N, and dx.
Create a heatmap or contour plot of the solution u(x,y).
