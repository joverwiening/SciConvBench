The PDE to solve is u_xx + u_yy = -2*(y*(1-y) + x*(1-x)).
The domain is the unit square [0,1] x [0,1].
The boundary conditions are Dirichlet on all four edges.
The value of u on the boundary is set to match the function u(x,y) = x*(1-x)*y*(1-y).
The exact solution for verification is u(x,y) = x*(1-x)*y*(1-y).
Discretize the PDE using a standard 5-point finite difference stencil for the Laplacian on a uniform grid.
The grid will have Nx=120 intervals in the x-direction and Ny=120 intervals in the y-direction.
This corresponds to 121 grid points in each direction, including boundaries.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are defined as x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Solve the resulting sparse linear system for the interior grid nodes using a sparse direct solver.
Compute the steady-state solution u(x,y) on the 2D grid.

The NPZ file must also contain the scalar metadata values for dx and dy.
