The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The parameter nu is 0.002.
The spatial domain is x in [0, 1).
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
The final time T is 1.0.
Use a uniform spatial grid with Nx=512 points.
The spatial step size dx is (1-0)/Nx.
The grid points are x_i = i*dx for i=0 to Nx-1.
The time step dt is calculated to exactly reach the final time T.
First, calculate a provisional time step dt0 = 0.4 * dx / 1.0.
The number of time steps Nt is the ceiling of T/dt0.
The final time step is dt = T/Nt.
Use Strang splitting for the time integration.
Each full time step of size dt consists of three sub-steps.
The first sub-step is a diffusion step of duration dt/2.
Solve the diffusion step u_t = nu * u_xx exactly in Fourier space.
The Fourier space update for the diffusion step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers k are defined as 2*pi*fftfreq(Nx, d=dx).
The second sub-step is an advection step of duration dt.
Solve the advection step u_t + ∂_x(0.5*u^2) = 0 using a finite volume method.
The finite volume update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The numerical flux F is the Rusanov (local Lax-Friedrichs) flux.
The Rusanov flux between states u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The physical flux is f(u) = 0.5*u^2.
The wave speed estimate is alpha = max(abs(u_left), abs(u_right)).
The third sub-step is a diffusion step of duration dt/2, identical to the first sub-step.
Compute the solution u(x,T) at the final time T.
Save the solution to a file named "solution_pdebench_burgers_nu2em3.npz".
The NPZ file must contain the 1D arrays x and u.
The NPZ file must also contain the scalars nu, T, dx, dt, Nx, and Nt.
Save a line plot of the final solution u(x,T) versus x to "solution_pdebench_burgers_nu2em3.png".
