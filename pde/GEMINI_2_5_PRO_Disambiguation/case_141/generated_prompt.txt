The partial differential equation to solve is u_t + beta * u_x = 0.
The unknown field is u(x,t).
The spatial domain for x is the periodic interval [0, 1).
The time domain is from t=0 to the final time T=2.0.
The parameter beta is 4.0.
The boundary conditions are periodic.
The initial condition at t=0 is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for error calculation is u(x,t) = u0((x - beta*t) mod 1), where u0(x) is the initial condition.
Use a uniform spatial grid with Nx=512 points.
The grid spacing is dx = (1-0)/Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
The upwind direction is determined by the sign of beta.
Integrate in time using the explicit forward Euler method.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
An initial time step is calculated as dt_initial = CFL * dx / abs(beta).
The number of time steps is Nt = ceil(T / dt_initial).
The final time step used for integration is dt = T / Nt.
Compute the numerical solution u(x,T) at the final time T.
Save the output to a file named "solution_pdebench_advection_beta4.npz".
The NPZ file must contain the 1D array x of grid points, the 1D array u of the final solution, and the scalar values beta, T, dx, dt, Nx, Nt.
