The PDE to be solved is the 1D Compressible Navier-Stokes system in conservative form.
The conservative state vector is U = [rho, m, E], where rho is density, m is momentum (rho*v), and E is total energy.
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The parameter zeta is equal to eta.
The PDE system is rho_t + (m)_x = 0.
The PDE system is m_t + (m^2/rho + p - sigma)_x = 0.
The PDE system is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time T is 0.2.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is 1e-08.
Boundary conditions are transmissive (zero-gradient) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial density rho_L is 1.0, velocity v_L is 0.75, and pressure p_L is 1.0.
For x >= 0, the initial density rho_R is 0.125, velocity v_R is 0.0, and pressure p_R is 0.1.
The numerical grid is a uniform finite-volume grid with 800 cells on [-1,1].
The cell spacing dx is 0.0025.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,799.
The conservative variables U = [rho, m, E] are evolved as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p fall below 1e-12 during the simulation, they should be clipped to 1e-12.
The convective flux is the Rusanov (local Lax-Friedrichs) flux.
The physical flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical convective flux at an interface is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is computed using a centered difference on cell-centered velocity values.
The viscous stress sigma = (zeta + 4/3*eta)*v_x is computed at cell centers.
The value of sigma at a cell interface is the average of the sigma values from the two adjacent cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The values of v and sigma used in the viscous flux at an interface are the averages from the two adjacent cells.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Time integration is performed using the 2-stage SSP-RK2 (Heun's method).
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The time step dt is calculated at each step as the minimum of a convective and a viscous time step.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step used is dt = min(dt_conv, dt_visc).
The final time step is adjusted to end the simulation at exactly T=0.2.
Outflow boundary conditions are implemented by setting ghost cell values equal to the nearest interior cell value.
