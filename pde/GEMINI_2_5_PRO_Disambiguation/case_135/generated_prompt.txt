The PDE to solve is u_t + beta * u_x = 0.
The unknown field is u(x,t).
The spatial domain for x is the periodic interval [0, 1).
The final time T is 2.0.
The advection coefficient beta is 0.1.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The boundary conditions are periodic.
Use a uniform spatial grid with Nx = 512 points.
The spatial grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i * dx for i = 0 to Nx-1.
Discretize the spatial derivative u_x with a 1st-order upwind finite difference.
Integrate in time using the explicit forward Euler method.
Set the CFL number to 0.5.
Calculate the number of time steps Nt as ceil(T / (CFL * dx / abs(beta))).
Set the time step dt as T / Nt.
Compute the solution u at the final time T.
The reference solution is u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition.

The NPZ file must contain the 1D array of grid points 'x'.
The NPZ file must contain the 1D array of the final solution 'u'.
The NPZ file must contain the scalar values 'beta', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
