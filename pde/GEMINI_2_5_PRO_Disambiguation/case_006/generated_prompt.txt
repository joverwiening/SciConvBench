The PDE to solve is u_t + 2.0 * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 0.3].
The final time T is 0.3.
The advection velocity 'a' is 2.0.
The initial condition is u(x,0) = 1 for 0.2 <= x < 0.4, and u(x,0) = 0 otherwise.
The spatial grid is a uniform periodic grid with Nx=2000 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i * dx for i = 0 to Nx-1.
The spatial derivative u_x is discretized using a 1st-order upwind scheme.
The time integration is performed using the Forward Euler method.
The time step dt is calculated as follows:
First, calculate a temporary time step dt0 = 0.9 * dx / |a|.
Second, calculate the number of time steps Nt = ceil(T / dt0).
Third, the final time step is dt = T / Nt.
The solution u(x,T) at the final time T=0.3 is computed.
The solution is saved to a file named "solution_agent_advection_06.npz".
The npz file contains the 1D array 'x' of grid point locations.
The npz file contains the 1D array 'u' of the solution at the final time.
The npz file contains the scalar 'T' representing the final time.
The npz file contains the scalar 'dx' representing the spatial grid spacing.
The npz file contains the scalar 'dt' representing the time step.
A line plot of the final solution u(x,T) versus x is created.
The plot is saved as an image file named "solution_agent_advection_06.png".
The minimum value of the final solution u is printed to the console.
The maximum value of the final solution u is printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx), is printed to the console.
