The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 1.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points.
The spatial step size is dx = 1.0 / Nx.
The grid points are x_j = j * dx for j = 0, ..., Nx-1.
The final time T is 1.0.
Use a fixed time step of dt = 0.001.
The number of time steps is Nt = 1000.
The numerical method is Strang splitting for each time step dt.
A full time step consists of a diffusion half-step, a reaction full-step, and a second diffusion half-step.
The diffusion equation u_t = nu * u_xx is solved for a duration of dt/2 in Fourier space.
The update rule in Fourier space for a diffusion half-step is u_hat(k) <- u_hat(k) * exp(-nu * k^2 * (dt/2)).
The wavenumbers are defined as k = 2 * pi * fftfreq(Nx, d=dx).
The reaction equation du/dt = rho * u * (1 - u) is solved for a duration of dt.
The exact update for the reaction step at each grid point is u <- (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Compute the solution u(x,t) up to the final time T=1.0.
Save an NPZ file named "solution_pdebench_reacdiff_nu2_rho1.npz".
The NPZ file must contain the arrays x and u, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a PNG file named "solution_pdebench_reacdiff_nu2_rho1.png".
The PNG file must be a line plot of the final solution u versus x.
Print the minimum, maximum, and mean of the final solution u.
Print the discrete L2 norm of the final solution u, calculated as sqrt(sum(u^2) * dx).
