The PDE to solve is u_t + beta * u_x = 0.
The spatial domain for x is [0, 1).
The final time T is 2.0.
The parameter beta is 7.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for error calculation is u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition function.
Use a uniform spatial grid with Nx = 512 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i * dx for i = 0, ..., Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
Integrate in time using the explicit forward Euler method.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
Calculate an initial time step dt_temp = CFL * dx / abs(beta).
The number of time steps is Nt = ceil(T / dt_temp).
The final time step for the simulation is dt = T / Nt.
Compute the solution u(x,T) at the final time T.
Save the results to a file named "solution_pdebench_advection_beta7.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'beta', 'T', 'dx', 'dt', 'Nx', 'Nt'.
