The 1D compressible Navier-Stokes equations are solved for density (rho), velocity (v), and pressure (p).
The conserved variables are U = [rho, m, E], where m = rho*v is momentum and E = p/(Gamma-1) + 0.5*rho*v^2 is total energy.
The conservative form of the PDE is U_t + F(U)_x = 0.
The total flux is F(U) = F_conv(U) - F_visc(U).
The convective flux is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The viscous flux is F_visc(U) = [0, sigma, v*sigma].
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1].
The simulation runs from t=0 to the final time T=0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the state is rho=0.445, v=0.698, p=3.528.
For x >= 0, the state is rho=0.5, v=0.0, p=0.571.
The method is a finite volume scheme on a uniform cell-centered grid.
The number of cells is Nx = 800.
The cell width is dx = 2.0 / Nx.
The cell centers are located at x_i = -1 + (i + 0.5)*dx for i=0..Nx-1.
The initial condition is discretized by assigning the corresponding left or right state to each cell center.
Transmissive (zero-gradient) boundary conditions are applied at x=-1 and x=1.
This is implemented using one ghost cell at each boundary.
The state in the left ghost cell (i=-1) is a copy of the state in the first interior cell (i=0).
The state in the right ghost cell (i=Nx) is a copy of the state in the last interior cell (i=Nx-1).
The time integration scheme is the 2-stage, second-order Strong Stability Preserving Runge-Kutta method (SSP-RK2).
The time step dt is variable and determined by a CFL condition.
The CFL number is 0.5.
The time step is calculated as dt = CFL * dx / max(|v_i| + c_i) over all cells i, where c_i is the sound speed sqrt(Gamma*p_i/rho_i).
The numerical flux at each interface x_{i+1/2} is the sum of an inviscid flux and a viscous flux.
The inviscid flux is the Rusanov (local Lax-Friedrichs) flux.
The Rusanov flux is F_hat_inv = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The reconstruction is first-order accurate.
The left state U_L at interface x_{i+1/2} is the cell-centered value U_i.
The right state U_R at interface x_{i+1/2} is the cell-centered value U_{i+1}.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c is the sound speed.
The viscous flux F_hat_visc = [0, sigma_{i+1/2}, (v*sigma)_{i+1/2}] is computed at the interface.
The velocity gradient v_x at cell center i is approximated by a second-order centered difference: (v_{i+1} - v_{i-1}) / (2*dx).
The viscous stress sigma_i = (zeta + 4/3*eta) * (v_x)_i is computed at each cell center i.
The viscous stress at the interface x_{i+1/2} is the average of the neighboring cell values: sigma_{i+1/2} = 0.5 * (sigma_i + sigma_{i+1}).
The velocity at the interface x_{i+1/2} is the average of the neighboring cell values: v_{i+1/2} = 0.5 * (v_i + v_{i+1}).
The viscous energy flux term at the interface is (v*sigma)_{i+1/2} = v_{i+1/2} * sigma_{i+1/2}.
The final solution rho(x,T), v(x,T), p(x,T) is computed at the cell centers at T=0.2.
