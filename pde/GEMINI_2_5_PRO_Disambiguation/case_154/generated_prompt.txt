The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The parameter nu is 0.004.
The spatial domain is x in [0, 1).
The time domain is t in [0, 1.0].
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx=512 points.
The spatial step size is dx = 1.0/Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
The final time is T = 1.0.
The initial time step is dt0 = 0.4 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
Use Strang splitting for the time integration.
Each time step consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
The diffusion step of duration dt_sub is solved in Fourier space.
The Fourier update rule is u_hat(k) = u_hat(k) * exp(-nu * k^2 * dt_sub).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The advection step for u_t + ∂_x(0.5*u^2)=0 is solved using a finite-volume method.
The finite-volume update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The numerical flux between cells with states u_left and u_right is the Rusanov flux.
The Rusanov flux is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The flux function is f(u) = 0.5*u^2.
The wave speed estimate is alpha = max(abs(u_left), abs(u_right)).
