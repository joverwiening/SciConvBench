The PDE to be solved is the 1D compressible Navier-Stokes system without heat conduction.
The conservative variables are density (rho), momentum (m), and total energy (E).
The system of equations is rho_t + (m)_x = 0.
The system of equations is m_t + (m^2/rho + p - sigma)_x = 0.
The system of equations is E_t + ( (E+p)*v - v*sigma )_x = 0.
The primitive variables are density (rho), velocity (v), and pressure (p).
The momentum is defined as m = rho*v.
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The ideal gas constant is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The spatial domain is the interval [-1, 1].
The temporal domain is the interval [0, 0.2].
The final time is T = 0.2.
The boundary conditions at x=-1 and x=1 are transmissive (outflow).
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0 at t=0, the density rho is 1.0.
For x < 0 at t=0, the velocity v is 0.0.
For x < 0 at t=0, the pressure p is 1.0.
For x >= 0 at t=0, the density rho is 0.1.
For x >= 0 at t=0, the velocity v is 0.0.
For x >= 0 at t=0, the pressure p is 0.01.
The numerical method is a finite-volume scheme on a uniform grid.
The number of grid cells is Nx = 800.
The grid spacing is dx = 2.0 / Nx = 0.0025.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0 to Nx-1.
The evolved variables are the cell averages of the conservative state vector U = [rho, m, E].
The pressure is calculated from the conservative variables using the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p fall below 1e-12 during the simulation, they should be clipped to 1e-12.
The convective flux is approximated using the Rusanov (local Lax-Friedrichs) scheme.
The Rusanov interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is computed using a centered difference on cell-centered velocity values.
The viscous stress sigma at cell interfaces is the average of the neighboring cell-centered sigma values.
The viscous flux contribution at interfaces is F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.
The total numerical flux at an interface is the sum of the convective and viscous fluxes.
Time integration is performed using the 2-stage SSP-RK2 (Heun's) method.
The time step dt is calculated at each step as the minimum of the convective and viscous time step limits.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
The CFL number is 0.9.
The final time step is adjusted to land exactly at T = 0.2.
Outflow boundary conditions are implemented using two ghost cells on each side where the values are set equal to the nearest interior cell.
The final solution rho(x,T), v(x,T), p(x,T) on the cell centers must be computed.
