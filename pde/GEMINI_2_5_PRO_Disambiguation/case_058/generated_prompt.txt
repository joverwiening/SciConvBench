The PDE to solve is u_xx + u_yy = 0.
The domain is a square defined by (x,y) in [0,1] x [0,1].
The grid will have Nx=100 intervals in the x-direction and Ny=100 intervals in the y-direction.
This corresponds to 101 grid points in x and 101 grid points in y.
The grid spacing is dx = 1/100 and dy = 1/100.
The grid points are x_i = i*dx for i=0,...,100 and y_j = j*dy for j=0,...,100.
The PDE is discretized using a second-order, 5-point finite difference stencil for the Laplacian on the interior grid nodes.
The resulting sparse linear system of equations for the interior node values will be solved using a sparse direct solver.
The boundary condition on the edge y=0 is u(x,0) = 0.
The boundary condition on the edge y=1 is u(x,1) = 0.
The boundary condition on the edge x=0 is u(0,y) = 0.
The boundary condition on the edge x=1 is u(1,y) = sin(pi*y).
The numerical solution u(x,y) will be computed on the 101x101 grid.
A file named "solution_agent_laplace_02.npz" will be saved.
The NPZ file will contain the 1D x-coordinate array, the 1D y-coordinate array, the 2D solution array u with shape (101, 101), and the scalar grid spacings dx and dy.
The solution array u will be indexed such that u[j,i] corresponds to the solution at (x_i, y_j).
A heatmap or contour plot of the solution u(x,y) will be saved as "solution_agent_laplace_02.png".
The minimum value of the solution u will be printed to the console.
The maximum value of the solution u will be printed to the console.
The discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy), will be printed to the console.
The exact solution for verification is u_exact(x,y) = sinh(pi*x)*sin(pi*y)/sinh(pi).
The maximum absolute error between the numerical and exact solutions will be computed on the grid and printed to the console.
The L2 error between the numerical and exact solutions will be computed on the grid and printed to the console.
