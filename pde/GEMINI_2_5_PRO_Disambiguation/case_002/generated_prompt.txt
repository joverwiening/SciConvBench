The PDE to solve is u_t + (-0.5)*u_x = 0.
The spatial domain is x in the periodic interval [0, 1).
The time domain is t in [0, 1.0].
The advection velocity parameter 'a' is -0.5.
The initial condition is u(x,0) = exp(-100*(x-0.3)^2).
Use a uniform periodic grid with Nx=1000 points.
The spatial grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind scheme, which for negative velocity 'a' is a right-biased stencil: (u_{i+1} - u_i)/dx.
Use periodic boundary conditions, such that the neighbor of the last point x_{Nx-1} is the first point x_0.
Integrate in time using the Forward Euler method.
The final time T is 1.0.
A preliminary time step is dt0 = 0.9 * dx / |a|.
The number of time steps is Nt = ceil(T / dt0).
The final time step used for integration is dt = T / Nt.
Compute the numerical solution u(x,T) on the grid at the final time T.
Save the results to a file named "solution_agent_advection_02.npz".
The saved file must contain the 1D array of grid points 'x'.
The saved file must contain the 1D array of the final solution 'u'.
The saved file must contain the scalar value for the final time 'T'.
The saved file must contain the scalar value for the spatial step 'dx'.
The saved file must contain the scalar value for the time step 'dt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_agent_advection_02.png".
