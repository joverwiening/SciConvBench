The PDE to be solved is the 1D compressible Navier-Stokes system.
The conservative state vector is U = [rho, m, E], where rho is density, m is momentum, and E is total energy density.
The primitive variables are density rho, velocity v, and pressure p.
The momentum is defined as m = rho*v.
The total energy density is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The simulation runs from t = 0 to the final time T = 0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
Boundary conditions at both x=-1 and x=1 are transmissive (outflow).
The initial condition is a Riemann problem (Sod shock tube) with a discontinuity at x=0.
For x < 0, the initial state is rho = 1.0, v = 0.0, and p = 1.0.
For x >= 0, the initial state is rho = 0.125, v = 0.0, and p = 0.1.
Use a uniform finite-volume grid with Nx = 800 cells.
The cell width is dx = 2.0 / 800 = 0.0025.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,799.
The evolved variables are the cell averages of the conservative state vector U.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a minimum value of 1e-12 if they fall below this threshold.
The convective part of the flux is discretized using the Rusanov (local Lax-Friedrichs) scheme.
The physical convective flux is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The Rusanov wave speed at an interface between states L and R is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical convective flux at an interface is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is computed at cell centers using a second-order centered difference.
The viscous stress sigma is computed at cell centers from v_x.
The viscous stress sigma at cell interfaces is computed by averaging the values from the two adjacent cell centers.
The physical viscous flux is F_visc = [0, -sigma, -v*sigma].
The values of v and sigma used to compute the viscous flux at an interface are the averages of the values from the two adjacent cell centers.
The total numerical flux at an interface is the sum of the numerical convective flux and the viscous flux.
Time integration is performed using the 2-stage SSP-RK2 (Heun's) method.
The CFL number for the time step calculation is 0.9.
The time step dt is chosen at each step as the minimum of the convective and viscous time step constraints.
The convective time step constraint is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step constraint is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
The final time step is adjusted to ensure the simulation stops exactly at T = 0.2.
Outflow boundary conditions are implemented by using two ghost cells at each boundary whose values are copied from the nearest interior cell (zero-gradient).
