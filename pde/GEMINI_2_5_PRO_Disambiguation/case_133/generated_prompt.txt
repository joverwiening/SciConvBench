The PDE to solve is u_t = -k * ∂_x(cos(u)).
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.5 * sin(2 * pi * x).
Use a uniform periodic spatial grid with Nx=1024 points.
The grid points are x_j = j/1024 for j=0, ..., 1023.
The spatial discretization is a conservative finite-volume method.
The numerical flux is the Rusanov flux.
The physical flux function is f(u) = cos(u).
The wave speed for the Rusanov flux is a constant alpha=1.0.
The time integration scheme is SSP-RK2.
The final time T is 0.2.
The CFL number is 0.2.
The time step dt is constant and calculated to reach the final time exactly.
First, calculate a reference time step dt0 = CFL * dx / 1.0, where dx = 1/Nx.
Then, calculate the number of time steps Nt = ceil(T / dt0).
Finally, the time step is dt = T / Nt.
