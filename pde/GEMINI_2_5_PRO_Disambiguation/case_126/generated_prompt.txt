The spatial domain is x in [0, 1).
The temporal domain is t in [0, 0.2].
The PDE to solve is u_t = -1.0 * ∂_x(0.5 * u^2).
The boundary conditions are periodic.
The initial condition is u(x, 0) = sin(2 * pi * x).
Use a uniform periodic spatial grid with Nx = 1024 points.
The grid points are x_j = j / Nx for j = 0, ..., Nx-1.
The grid spacing is dx = 1.0 / Nx.
Discretize the initial condition by point-wise evaluation at the grid points: u_j(t=0) = sin(2 * pi * x_j).
Use a conservative finite-volume method for spatial discretization.
The numerical flux between cell j and j+1 is the Rusanov flux.
The physical flux function is f(u) = 0.5 * u^2.
The Rusanov flux is F_{j+1/2} = 0.5 * (f(u_j) + f(u_{j+1})) - 0.5 * S_{j+1/2} * (u_{j+1} - u_j).
The local wave speed is S_{j+1/2} = max(|u_j|, |u_{j+1}|).
The semi-discrete update equation is d(u_j)/dt = -(F_{j+1/2} - F_{j-1/2}) / dx.
Integrate in time using the SSP-RK2 (Heun) method.
The final time is T = 0.2.
Use a fixed time step dt for the entire simulation.
Calculate the number of time steps Nt = ceil(T / (CFL * dx / 1.0)), with CFL = 0.2.
The time step is dt = T / Nt.
