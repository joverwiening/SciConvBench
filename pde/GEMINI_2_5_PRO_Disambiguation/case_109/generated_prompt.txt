Task ID is molk_008.
The ODE system to solve is the Lotka-Volterra predator-prey model.
The system of equations is dx/dt = alpha*x - beta*x*y and dy/dt = delta*x*y - gamma*y.
The unknown functions to solve for are x(t) and y(t).
The time domain is from t=0.0 to t=30.0.
The parameter alpha is 1.5.
The parameter beta is 1.0.
The parameter gamma is 3.0.
The parameter delta is 1.0.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 1.0.
The numerical method for time integration is the classical 4th-order Runge-Kutta (RK4).
A fixed time step of dt=0.01 shall be used.
The total number of time steps is 3000.
The full state vector [x(t), y(t)] must be computed at all time points t_n = n*dt for n=0 to 3000.
Save the solution to a file named "solution_molk_008.npz".
The NPZ file must contain a 1D array 't' of time points of length 3001.
The NPZ file must contain a 2D array 'Y' of shape [3001, 2] with columns corresponding to x and y.
The NPZ file must also contain the scalar parameters alpha, beta, gamma, and delta.
Save a line plot of x(t) and y(t) versus t to a file named "solution_molk_008.png".
Print the final state values of x and y at t=30.0 to standard output.
Print the minimum and maximum values of x(t) over the entire simulation to standard output.
Print the minimum and maximum values of y(t) over the entire simulation to standard output.
