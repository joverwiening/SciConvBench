The PDE to solve is u_t = -q1*∂_x(u) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
Discretize the advection term ∂_x(u) using a 1st-order upwind scheme.
Discretize the diffusion term u_xx using a 2nd-order central difference scheme.
Integrate in time using a fully explicit Forward Euler method.
Calculate a provisional time step dt_provisional = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)).
The number of time steps is Nt = ceil(0.5/dt_provisional).
The final time step used for the simulation is dt = 0.5/Nt.
