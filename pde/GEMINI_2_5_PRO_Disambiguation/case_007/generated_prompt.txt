Solve the partial differential equation u_t = (0.01)^2*u_xx + u - u^3.
The spatial domain is x in [0,1) and the time domain is t in [0,0.5].
The parameter epsilon is 0.01.
The initial condition is u(x,0) = 0.1*cos(2*pi*x) + 0.05*sin(4*pi*x).
The boundary conditions for the spatial domain are periodic.
Use a uniform spatial grid with Nx=800 points, such that dx = 1.0/800 and x_i = i*dx for i=0,...,799.
Discretize the u_xx term using a 2nd-order central difference scheme.
Integrate in time using the semi-implicit scheme (u^{n+1} - u^n)/dt = (0.01)^2*u_xx^{n+1} + u^n - (u^n)^3.
Use a time step of dt = 0.0002.
Compute the solution u(x,t) at the final time T=0.5.
Save the results to a file named "solution_agent_allen_cahn_01.npz".
The NPZ file must contain the 1D array of x coordinates, the 1D array of the solution u at T=0.5, the scalar T, the scalar dx, and the scalar dt.
Save a line plot of the final solution u versus x to a file named "solution_agent_allen_cahn_01.png".
Print the minimum value of the solution u at T=0.5.
Print the maximum value of the solution u at T=0.5.
Print the discrete L2 norm of the solution at T=0.5, calculated as sqrt(sum(u^2)*dx).
