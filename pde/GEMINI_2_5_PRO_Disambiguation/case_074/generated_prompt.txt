The PDE to solve is u_xx + u_yy = -2*pi^2*sin(pi*x)*sin(pi*y).
The spatial domain is the unit square [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges, with u=0.
The exact solution for verification is u(x,y) = sin(pi*x)*sin(pi*y).
Use a uniform grid with Nx=120 intervals in the x-direction and Ny=120 intervals in the y-direction.
This corresponds to 121 grid points in each direction, including boundaries.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are defined as x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Discretize the PDE using the standard second-order 5-point finite difference stencil for the Laplacian.
Solve the resulting sparse linear system for the interior grid nodes using a sparse direct solver.
Compute the steady-state numerical solution u(x,y) on the 2D grid.

The NPZ file must contain the 1D array of x-coordinates, the 1D array of y-coordinates, and the 2D solution array u with shape (Ny+1, Nx+1).
The NPZ file must also contain the scalar metadata values for dx and dy.
