Solve the 1D viscous Burgers' equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1).
The final simulation time is T = 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
The viscosity parameter is nu = 4.0.
Use a uniform spatial grid with Nx = 512 points.
The spatial step size is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
The time step dt is determined by a CFL condition.
Use a CFL number of 0.4 and an estimated maximum speed of 1.0.
Calculate an initial time step dt0 = CFL * dx / 1.0.
Calculate the number of time steps Nt = ceil(T / dt0).
Set the final time step as dt = T / Nt.
Use Strang splitting for the time integration.
Each full time step dt consists of three sub-steps.
The first sub-step is a diffusion step of duration dt/2 solved in Fourier space.
To perform the diffusion step, compute the forward FFT of u to get u_hat(k).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute the inverse FFT of the updated u_hat(k) and take its real part to get the result of the diffusion step.
The second sub-step is an advection step of duration dt for the inviscid Burgers' equation u_t + ∂_x(0.5*u^2) = 0.
Solve the advection step using a finite-volume method with a Rusanov flux.
The flux function is f(u) = 0.5*u^2.
For each interface between cells j and j+1, the Rusanov flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
Update the solution in each cell j using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the j+1/2 interface and F_minus is the flux at the j-1/2 interface.
The third sub-step is another diffusion step of duration dt/2, identical to the first sub-step.
Compute the solution u(x,T) at the final time T.
Save the output to a file named "solution_pdebench_burgers_nu4.npz".
The npz file must contain the 1D arrays x and u, and the scalar values nu, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_burgers_nu4.png".
Print the minimum and maximum values of the final solution u.
Print the discrete mean value of the final solution, calculated as mean(u).
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
