The PDE to solve is u_t = -1.0 * ∂_x(cos(u)) + (0.05/pi) * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
Discretize the spatial domain with a uniform grid of Nx=1024 points, where x_j = j/1024 for j=0,...,1023.
The spatial discretization is a finite-volume method.
The convective flux term ∂_x(cos(u)) is discretized using a Rusanov numerical flux.
The Rusanov flux at the interface between cell j and j+1 is F(u_j, u_{j+1}) = 0.5 * (cos(u_j) + cos(u_{j+1})) - 0.5 * alpha * (u_{j+1} - u_j).
The wave speed alpha for the Rusanov flux is calculated as the maximum value of |sin(u)| over the entire spatial domain.
The diffusion term u_xx is discretized using a second-order central difference stencil.
Integrate in time using the two-stage Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The wave speed alpha is to be computed once at the beginning of each time step and used for all stages within that time step.
The final simulation time is T=0.5.
The time step dt is determined by a CFL condition of 0.2.
First, calculate a provisional time step dt_provisional = min(0.2*dx/1.0, 0.2*dx**2/(0.05/pi)), where dx=1.0/1024.
Then, determine the number of steps Nt = ceil(T/dt_provisional).
The final time step for the simulation is dt = T/Nt.
