The PDE to solve is u_t + 1.0*u_x + 0.5*u_y = 0.01*(u_xx + u_yy).
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The initial condition is u(x,y,0) = sin(2*pi*x)*cos(2*pi*y).
The numerical grid has Nx = 400 points in the x-direction and Ny = 400 points in the y-direction.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are x_i = i*dx for i=0..Nx-1 and y_j = j*dy for j=0..Ny-1.
The time step is dt = 0.001.
The simulation runs for Nt = 500 steps to reach the final time T = 0.5.
The spatial discretization for advection terms (u_x, u_y) uses a 1st-order upwind scheme.
The spatial discretization for diffusion terms (u_xx, u_yy) uses a 2nd-order central difference scheme.
The time integration uses a first-order IMEX scheme where advection is treated explicitly and diffusion is treated implicitly.
The update formula is (I - dt*D*L)u^{n+1} = u^n - dt*(a*D_x^up u^n + b*D_y^up u^n), where D=0.01, a=1.0, b=0.5.
L is the 5-point finite difference Laplacian operator with periodic boundary conditions.
D_x^up and D_y^up are the first-order upwind difference operators corresponding to the positive advection velocities a and b.
The sparse linear system at each time step is solved using a direct sparse solver.
The final numerical solution u(x,y,T) at T=0.5 is computed.
A file named "solution_agent_other_06_advection_diffusion.npz" is saved.
The NPZ file contains the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The shape of the solution array u is (Ny, Nx), where u[j,i] corresponds to u(x_i, y_j).
The NPZ file also contains the scalar metadata T, dx, dy, and dt.
A heatmap or contour plot of the final solution u(x,y,T) is saved as "solution_agent_other_06_advection_diffusion.png".
The minimum and maximum values of the final solution u are printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx*dy), is printed to the console.
The exact solution is u_exact(x,y,t) = exp(-0.01*8*pi^2*t)*sin(2*pi*(x-1.0*t))*cos(2*pi*(y-0.5*t)).
The maximum absolute error between the numerical and exact solutions at T=0.5 is computed and printed.
The L2 norm of the error between the numerical and exact solutions at T=0.5 is computed and printed.
