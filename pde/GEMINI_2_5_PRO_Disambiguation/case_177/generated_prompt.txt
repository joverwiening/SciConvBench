The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The diffusion coefficient nu is 10.0.
The reaction coefficient rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The spatial step size dx is 1.0/512.
The grid points are x_j = j*dx for j=0,...,511.
Use a fixed time step dt = 0.001.
The number of time steps Nt is 1000.
Use Strang splitting for the time integration.
Each time step from t to t+dt consists of three sub-steps.
First, solve the diffusion equation u_t = nu * u_xx for a duration of dt/2 using the Fourier spectral method.
The Fourier space update for the first diffusion half-step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k are the wavenumbers.
The wavenumbers k are defined as 2*pi*fftfreq(Nx, d=dx).
Second, solve the reaction equation du/dt = rho * u*(1 - u) for a duration of dt.
The exact update for the reaction step at each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation u_t = nu * u_xx for another duration of dt/2 using the same Fourier spectral method.
Compute the solution u(x,t) at the final time T=1.0.
Save the results to a file named "solution_pdebench_reacdiff_nu10_rho10.npz".
The npz file must contain the 1D arrays 'x' and 'u', and the scalar values 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Create a line plot of the final solution u(x,T) versus x.
Save the plot as "solution_pdebench_reacdiff_nu10_rho10.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u(x,T).
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
