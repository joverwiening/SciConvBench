Solve the partial differential equation u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain for x is [0, 1).
The time domain is from t=0 to T=1.0.
The parameter nu is 0.5.
The parameter rho is 10.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Discretize the spatial domain using a uniform grid with Nx = 512 points.
The spatial grid spacing is dx = 1.0 / 512.
The spatial grid points are x_i = i * dx for i = 0, ..., 511.
Use a fixed time step of dt = 0.001.
Perform Nt = 1000 time steps to reach the final time T.
Advance the solution in time using Strang splitting for each time step dt.
The first sub-step is to solve the diffusion equation u_t = nu * u_xx for a duration of dt/2 using a Fourier spectral method.
The diffusion update in Fourier space is u_hat(k) <- u_hat(k) * exp(-nu * k^2 * (dt/2)), where k are the wavenumbers.
The wavenumbers are defined as k = 2*pi*fftfreq(Nx, d=dx).
The second sub-step is to solve the reaction equation du/dt = rho*u*(1-u) for a duration of dt using its exact analytical solution.
The pointwise update for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third sub-step is to repeat the diffusion solve for another duration of dt/2.
Compute the final solution u(x,T) on the grid at time T.
Save the results to a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz".
The NPZ file must contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Create a line plot of the final solution u as a function of x.
