The PDE to solve is u_t + a(x)*u_x = 0.
The advection velocity is a(x) = 1 + 0.5*sin(2*pi*x).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=1200 points.
The grid spacing is dx = 1/Nx.
The grid points are x_i = i*dx for i = 0 to Nx-1.
The spatial derivative u_x is discretized using a first-order upwind scheme.
The upwind stencil is left-biased (backward difference) because a(x) is always positive.
The time integration scheme is Forward Euler.
The maximum advection velocity is amax = 1.5.
An initial time step is calculated as dt0 = 0.9 * dx / amax.
The number of time steps is Nt = ceil(T/dt0), where the final time T is 0.5.
The final time step is dt = T/Nt.
The final solution u(x, T=0.5) is computed.
