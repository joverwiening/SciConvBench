Solve the partial differential equation u_xx + u_yy = 0.
The spatial domain for (x,y) is the square [0,1] x [0,1].
Discretize the domain using a uniform grid with Nx = 100 intervals in the x-direction and Ny = 100 intervals in the y-direction.
This results in 101 grid points in each direction, including the boundaries.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are located at x_i = i*dx for i=0..Nx and y_j = j*dy for j=0..Ny.
Apply Dirichlet boundary conditions on all four sides of the domain.
The boundary values are determined by the function u(x,y) = x^2 - y^2.
Discretize the Laplacian operator using the standard second-order 5-point finite difference stencil for all interior grid points.
Assemble the resulting sparse linear system of equations for the values of u at the interior grid points.
Solve this linear system using a sparse direct solver.
The exact solution for verification is u(x,y) = x^2 - y^2.
Save the numerical solution to a file named "solution_agent_laplace_06.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The shape of the u array must be (Ny+1, Nx+1) such that u[j,i] corresponds to u(x_i, y_j).
The NPZ file must also contain the scalar metadata values for dx and dy.
Save a heatmap or contour plot of the 2D solution u(x,y) as "solution_agent_laplace_06.png".
Print the minimum value of the computed solution u to the console.
Print the maximum value of the computed solution u to the console.
Print the discrete L2 norm of the solution, defined as sqrt(sum(u^2)*dx*dy), where the sum is over all grid points.
Compute the error by comparing the numerical solution to the exact solution evaluated at each grid point.
Print the maximum absolute error to the console.
Print the L2 norm of the error to the console.
