The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain for x is [0, 1).
The time domain is from t=0 to t=T.
The parameter nu is 0.5.
The parameter rho is 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx=512 points.
The spatial step dx is (1-0)/Nx.
The grid points are x_i = i*dx for i=0, ..., Nx-1.
Use a fixed time step of dt=0.001.
Perform Nt=1000 time steps.
The final time T is Nt*dt.
Use Strang splitting for the time integration of each step dt.
The first step is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
To perform the diffusion step, compute the FFT of u, multiply by exp(-nu*k^2*(dt/2)), and compute the real part of the inverse FFT.
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The second step is a reaction full-step of duration dt, solved exactly pointwise.
The exact update for the reaction step at each grid point is u_new = (u_old*exp(rho*dt)) / (1 + u_old*(exp(rho*dt) - 1)).
The third step is another diffusion half-step of duration dt/2, identical to the first step.
Compute the solution u(x,T) at the final time T.
Save an NPZ file named "solution_pdebench_reacdiff_nu0p5_rho1.npz".
The NPZ file must contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u versus x as "solution_pdebench_reacdiff_nu0p5_rho1.png".
Print the minimum, maximum, and mean of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
