The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1).
The time domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 2.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Use a fixed time step of dt = 0.001.
Perform Nt = 1000 time steps to reach the final time T = 1.0.
Use Strang splitting for the time integration.
Each time step from t to t+dt consists of three sequential sub-steps.
First, solve the diffusion equation u_t = nu * u_xx for a duration of dt/2 using a Fourier spectral method.
The diffusion half-step is: u_hat = FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat = u_hat * exp(-nu*k^2*(dt/2)), u = real(IFFT(u_hat)).
Second, solve the reaction equation u_t = rho * u*(1 - u) for a duration of dt.
The reaction full-step is applied pointwise: u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation u_t = nu * u_xx for a duration of dt/2 using the same Fourier spectral method as the first sub-step.
Compute the solution u(x,T) at the final time T.

The NPZ file must contain the scalar values for 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
