The PDE to solve is u_xx + u_yy + k^2*u = f(x,y).
The constant k is 5.0.
The forcing function is f(x,y) = (k^2 - 2*pi^2)*sin(pi*x)*sin(pi*y).
The domain is the unit square [0,1] x [0,1].
Dirichlet boundary conditions are applied on all boundaries, with u=0.
The spatial domain is discretized using a uniform grid with Nx=120 intervals in the x-direction and Ny=120 intervals in the y-direction.
This results in a grid of 121x121 points.
The grid spacing is dx = 1/120 and dy = 1/120.
The grid points are x_i = i*dx for i=0..120 and y_j = j*dy for j=0..120.
The PDE is discretized using the 5-point finite difference stencil for the Laplacian.
The resulting sparse linear system of equations for the interior grid points is solved using a sparse direct solver.
The exact solution for verification is u_exact(x,y) = sin(pi*x)*sin(pi*y).
The steady-state numerical solution u(x,y) is computed on the 121x121 grid.
A file named "solution_agent_other_01_helmholtz.npz" is saved.
The NPZ file contains the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The shape of the u array is (121, 121), corresponding to (y, x) indexing.
The NPZ file also contains the scalar metadata values for dx and dy.
A heatmap or contour plot of the solution u(x,y) is saved as "solution_agent_other_01_helmholtz.png".
The minimum value of the numerical solution u is printed to the console.
The maximum value of the numerical solution u is printed to the console.
The discrete L2 norm of the numerical solution, calculated as sqrt(sum(u^2)*dx*dy), is printed to the console.
The maximum absolute error between the numerical solution and the exact solution evaluated on the grid is computed and printed.
The L2 error between the numerical solution and the exact solution evaluated on the grid is computed and printed.
