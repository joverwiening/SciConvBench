The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 5.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points.
The spatial step size is dx = 1.0 / 512.
The grid points are x_j = j*dx for j=0,...,511.
Use a fixed time step of dt = 0.001.
The total number of time steps is Nt = 1000.
The final time is T = 1.0.
Use Strang splitting for the time integration.
Each time step of size dt consists of three sub-steps.
First, solve the diffusion equation u_t = nu * u_xx for a duration of dt/2 using an exact Fourier method.
The Fourier update rule is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Second, solve the reaction equation du/dt = rho * u*(1 - u) for a duration of dt.
The exact update for the reaction step at each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation u_t = nu * u_xx for another duration of dt/2 using the same exact Fourier method.
Compute the solution u(x,T) at the final time T=1.0.
Save the solution to a file named "solution_pdebench_reacdiff_nu5_rho5.npz".
The npz file must contain the 1D array 'x' of grid point locations, the 1D array 'u' of the final solution, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu5_rho5.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u(x,T).
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
