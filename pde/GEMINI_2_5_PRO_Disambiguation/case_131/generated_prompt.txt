Solve the partial differential equation u_t = -k * ∂_x(sin(u)).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5 * sin(2 * pi * x).
Use a uniform periodic spatial grid with Nx=1024 points.
The grid points are x_j = j/Nx for j=0, ..., Nx-1, where dx=1/Nx.
The spatial discretization is a conservative finite-volume scheme.
The numerical flux is the Rusanov flux with a constant wave speed alpha=1.0.
The time integration scheme is the second-order Strong Stability Preserving Runge-Kutta method (SSP-RK2).
The Courant-Friedrichs-Lewy (CFL) number is 0.2.
The time step dt is constant and calculated to ensure the simulation stops exactly at the final time T=0.2.
First, calculate a preliminary time step dt0 = CFL * dx / 1.0.
Then, calculate the number of time steps Nt = ceil(T / dt0).
Finally, the time step used for the simulation is dt = T / Nt.
