The PDE to solve is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The unknown field is u(x,y).
The spatial domain is (x,y) in (0,1) x (0,1).
The coefficient function is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The value of the parameter beta is 10.0.
The boundary condition is u = 0 on the entire boundary of the domain.
A closed-form reference solution is not required.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 points.
The grid spacing is dx = dy = 1/N.
The grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a 2nd-order finite difference scheme with harmonic averaging for the variable coefficient.
The discrete equation for interior nodes (i=1..N-1, j=1..N-1) is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face-centered coefficient a(i+1/2,j) is the harmonic mean 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknown values of u.
Solve the linear system using the conjugate gradient method.
The tolerance for the conjugate gradient solver is a relative residual of 1e-10.
A Jacobi preconditioner may be used.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including the boundaries.

The NPZ file must contain the 1D array 'x', the 1D array 'y', and the 2D array 'u' with shape (N+1, N+1).
The NPZ file must also contain the scalar values 'beta', 'N', and 'dx'.
Save a heatmap or contour plot of the solution u(x,y) as "solution_pdebench_darcy_beta10.png".
