The partial differential equation to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1).
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The parameter beta is 1.0.
The final time is T = 2.0.
The spatial domain is discretized with a uniform grid of Nx = 512 points.
The spatial discretization for u_x is a 1st-order upwind finite difference scheme.
The time integration scheme is explicit forward Euler.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The time step dt is calculated by first setting dt_provisional = CFL * dx / abs(beta).
The number of time steps is Nt = ceil(T / dt_provisional).
The final time step is dt = T / Nt.
The reference solution for error calculation is u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition.
