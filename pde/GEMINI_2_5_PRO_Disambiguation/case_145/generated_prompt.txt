The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The simulation parameter is nu = 0.04.
The spatial domain is x in [0, 1).
The final time is T = 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx=512 points.
The spatial step size is dx = (1-0)/Nx.
The grid points are x_i = i*dx for i=0..Nx-1.
The time integration method is Strang splitting.
Each full time step dt consists of three sub-steps.
The first sub-step is a diffusion step of duration dt/2.
Solve the diffusion step u_t = nu * u_xx exactly in Fourier space.
The Fourier update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The angular wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
The second sub-step is an advection step of duration dt.
Solve the advection step u_t + ∂_x(0.5*u^2) = 0 using a finite-volume method.
The finite-volume update uses the Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u) = 0.5*u^2.
The numerical flux F between cells with values u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The cell update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of cell j.
The third sub-step is a diffusion step of duration dt/2, identical to the first sub-step.
The time step dt is determined by a CFL condition.
Set an initial time step dt0 = 0.4 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
Compute the solution u(x,T) at the final time T.
Save the solution to a file named "solution_pdebench_burgers_nu0p04.npz".
The npz file must contain the arrays x and u, and the scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_burgers_nu0p04.png".
