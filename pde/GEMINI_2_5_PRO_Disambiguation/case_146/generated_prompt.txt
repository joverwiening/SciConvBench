The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The domain is x in [0, 1) and t in [0, 1.0].
The boundary conditions are periodic.
The parameter nu is 0.1.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is uniform with Nx=512 points, such that dx = 1.0/512 and x_i = i*dx for i=0,...,511.
The time step dt is calculated to exactly reach the final time T=1.0.
First, an initial time step is estimated as dt0 = 0.4 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0).
The final time step used for integration is dt = T/Nt.
The time integration method is Strang splitting.
Each time step from t to t+dt consists of three sub-steps.
The first sub-step is solving the diffusion equation u_t = nu * u_xx for a duration of dt/2.
The diffusion sub-step is solved in Fourier space using the exact solution.
The Fourier transform of the solution u_hat(k) is evolved by multiplying with exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The result is transformed back to physical space using an inverse Fourier transform, taking the real part.
The second sub-step is solving the advection equation u_t + ∂_x(0.5*u^2) = 0 for a duration of dt.
The advection sub-step is solved using a finite-volume method with a Rusanov flux.
The flux F at the interface between cell j (with value u_left) and cell j+1 (with value u_right) is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The flux function is f(u) = 0.5*u^2.
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The solution in cell j is updated as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the j+1/2 interface and F_minus is the flux at the j-1/2 interface, using periodic indexing.
The third sub-step is another diffusion step for a duration of dt/2, identical to the first sub-step.
The final solution u at time T is computed on the grid.
A file named "solution_pdebench_burgers_nu0p1.npz" is saved.
The NPZ file contains the 1D arrays 'x' and 'u', and the scalar values 'nu', 'T', 'dx', 'dt', 'Nx', 'Nt'.
A plot of the final solution u(x,T) versus x is saved as "solution_pdebench_burgers_nu0p1.png".
The minimum, maximum, mean, and discrete L2 norm of the final solution u are printed to the console.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
