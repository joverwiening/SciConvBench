Solve the partial differential equation u_t + beta * u_x = 0.
The spatial domain for x is [0, 1).
The final time T for the simulation is 2.0.
The advection coefficient beta is 0.7.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for error calculation is u(x,t) = u0( (x - beta*t) mod 1 ), where u0 is the initial condition function.
Use a uniform spatial grid with Nx=512 points, where x_i = i * (1.0/Nx) for i from 0 to Nx-1.
The spatial grid spacing is dx = 1.0/Nx.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
Integrate in time using the explicit forward Euler method.
Use a Courant-Friedrichs-Lewy (CFL) number of 0.5.
Set an initial time step dt_provisional = CFL * dx / abs(beta).
Calculate the number of time steps as Nt = ceil(T/dt_provisional).
Set the final time step as dt = T/Nt.
Compute the numerical solution u on the grid at the final time T.
Save an NPZ file named "solution_pdebench_advection_beta0p7.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalars 'beta', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_advection_beta0p7.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
Print the maximum absolute error between the numerical solution and the reference solution at time T.
Print the L2 error between the numerical solution and the reference solution at time T.
