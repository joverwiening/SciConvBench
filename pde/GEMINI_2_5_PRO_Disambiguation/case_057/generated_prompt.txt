The PDE to solve is u_xx + u_yy = 0.
The domain is a square where x is in [0,1] and y is in [0,1].
The grid will have Nx=100 intervals in the x-direction and Ny=100 intervals in the y-direction, creating a 101x101 grid of points.
The grid spacing is dx = 1/100 and dy = 1/100.
The grid points are defined by x_i = i*dx for i=0..100 and y_j = j*dy for j=0..100.
The PDE will be discretized using the standard 5-point finite difference stencil for the Laplacian.
Dirichlet boundary conditions are applied on all four sides of the domain.
The value of u on the boundary is set by the function u(x,y) = sin(pi*x)*sinh(pi*y)/sinh(pi).
The resulting sparse linear system for the interior nodes will be solved using a sparse direct solver.
The numerical solution u(x,y) will be computed on the 101x101 grid.
Save a file named "solution_agent_laplace_01.npz".
The NPZ file will contain a 1D array 'x' of x-coordinates, a 1D array 'y' of y-coordinates, and a 2D array 'u' of the solution with shape (101, 101) such that u[j,i] corresponds to u(x[i], y[j]).
The NPZ file will also contain the scalar metadata values dx and dy.
Save a heatmap or contour plot of the solution u(x,y) as "solution_agent_laplace_01.png".

Print the maximum value of the computed solution u.
Print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy).
The exact solution for verification is u_exact(x,y) = sin(pi*x)*sinh(pi*y)/sinh(pi).
