The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The spatial domain for x is [0, 1).
The final time is T = 1.0.
The parameter nu is 0.2.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points.
The grid spacing is dx = (1-0)/Nx.
The grid points are x_i = i*dx for i = 0 to Nx-1.
Use Strang splitting for time integration.
Each full time step dt consists of three substeps.
The first substep is a diffusion step of duration dt/2 solved in Fourier space.
To perform the diffusion step, compute the FFT of u to get u_hat(k).
The Fourier wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute the inverse FFT of the updated u_hat(k) and take the real part to get the updated u.
The second substep is an advection step of duration dt for the inviscid Burgers equation.
Use a finite-volume method with the Rusanov flux for the advection step.
The flux function is f(u) = 0.5*u^2.
The Rusanov flux between a left state u_L and a right state u_R is F = 0.5*(f(u_L) + f(u_R)) - 0.5*alpha*(u_R - u_L).
The local wave speed is alpha = max(abs(u_L), abs(u_R)).
Update each cell j using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell, respectively.
Use periodic indexing for calculating fluxes at the domain boundaries.
The third substep is another diffusion step of duration dt/2, identical to the first substep.
The time step dt is determined by a CFL condition.
Use a CFL number of 0.4 and an estimated maximum speed of 1.0.
Calculate an initial time step dt0 = 0.4 * dx / 1.0.
Calculate the number of time steps Nt = ceil(T / dt0).
Set the final time step as dt = T / Nt.
Compute the solution u(x,T) at the final time T on the grid.

The npz file must contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, and the scalars 'nu', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_burgers_nu0p2.png".
