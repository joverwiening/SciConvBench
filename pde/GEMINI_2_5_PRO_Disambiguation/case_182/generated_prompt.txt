The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain for x is the periodic interval [0, 1).
The temporal domain for t is [0, 1.0].
The parameter nu is 1.0.
The parameter rho is 2.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Discretize the spatial domain with Nx = 512 uniform grid points.
The spatial step size is dx = 1.0 / 512.
The grid points are x_i = i*dx for i = 0, ..., 511.
Integrate in time using Nt = 1000 steps.
The time step is dt = 0.001.
The final time is T = 1.0.
Use Strang splitting for the time integration of each step dt.
The first substep is to solve u_t = nu * u_xx for a duration of dt/2 using a Fourier spectral method.
The Fourier method update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The second substep is to solve du/dt = rho*u*(1-u) for a duration of dt using the exact pointwise update formula.
The exact update is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third substep is to solve u_t = nu * u_xx for a duration of dt/2 using the same Fourier spectral method as the first substep.
