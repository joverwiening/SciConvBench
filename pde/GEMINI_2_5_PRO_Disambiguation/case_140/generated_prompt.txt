The partial differential equation to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1).
The time domain is t in [0, 2.0].
The boundary conditions are periodic.
The parameter beta is 2.0.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for error calculation is u_exact(x,t) = sin(2*pi*((x - beta*t) mod 1)) + 0.5*sin(4*pi*((x - beta*t) mod 1)).
Use a uniform spatial grid with Nx = 512 points.
The grid spacing is dx = (1 - 0) / Nx.
The grid points are x_i = i * dx for i = 0, ..., Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
Since beta is positive, the upwind scheme for u_x at grid point i is (u_i - u_{i-1}) / dx.
Integrate in time using the explicit forward Euler method.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The initial time step dt is calculated as CFL * dx / abs(beta).
The number of time steps Nt is the ceiling of T / dt, where T is the final time 2.0.
The time step dt is then adjusted to T / Nt to ensure the simulation ends exactly at T.
Compute the numerical solution u(x,T) at the final time T = 2.0.
