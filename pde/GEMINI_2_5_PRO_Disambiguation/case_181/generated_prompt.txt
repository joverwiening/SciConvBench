The partial differential equation to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1).
The time interval is t in [0, 1.0].
Use the parameter values nu = 1.0 and rho = 10.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points, resulting in a grid spacing of dx = 1/512.
Use a fixed time step of dt = 0.001 for Nt = 1000 steps.
Use Strang splitting for time integration over each time step dt.
The first step is to advance the solution by a half-step of dt/2 using the diffusion operator u_t = nu * u_xx, solved in Fourier space.
The update in Fourier space is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The second step is to advance the solution by a full-step of dt using the reaction operator du/dt = rho*u*(1-u).
The update for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)) applied pointwise.
The third step is to advance the solution by another half-step of dt/2 using the diffusion operator, identical to the first step.
Compute the solution u(x,T) at the final time T = 1.0.
Save a file named "solution_pdebench_reacdiff_nu1_rho10.npz".
The NPZ file must contain the arrays 'x' and 'u', and the scalar values for nu, rho, T, dx, dt, Nx, and Nt.
Save a line plot of the final solution u versus x as "solution_pdebench_reacdiff_nu1_rho10.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u to the console.
