The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The diffusion coefficient nu is 2.0.
The reaction coefficient rho is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The spatial step size dx is 1.0/512.
The grid points are x_j = j*dx for j=0,...,511.
Use a fixed time step dt=0.001.
The number of time steps Nt is 1000.
The final time T is 1.0.
Use Strang splitting for the time integration.
Each full time step dt consists of three sub-steps.
The first sub-step is a diffusion step of duration dt/2 solved exactly in Fourier space.
For the diffusion step, transform u to Fourier space u_hat using an FFT.
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Transform the result back to real space using an IFFT and take the real part.
The second sub-step is a reaction step of duration dt.
The reaction ODE is du/dt = rho * u*(1 - u).
Solve the reaction step exactly for each grid point using the update formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third sub-step is another diffusion step of duration dt/2, identical to the first sub-step.
Compute the final solution u(x,T) at T=1.0.
Save the output to a file named "solution_pdebench_reacdiff_nu2_rho5.npz".
The npz file must contain the 1D array x of grid point locations, the 1D array u of the final solution, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu2_rho5.png".
Print the minimum, maximum, and mean of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
