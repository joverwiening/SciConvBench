Solve the partial differential equation u_t = ∇·( D(x,y) ∇u ).
The diffusion coefficient is D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The spatial domain is the unit square [0,1] x [0,1].
The time domain is [0, 0.1].
The initial condition is u(x,y,0) = sin(pi*x)*sin(pi*y).
The boundary condition is u=0 on all four boundary edges for all time.
Discretize the spatial domain using a uniform grid with Nx = 80 intervals in the x-direction and Ny = 80 intervals in the y-direction.
This results in 81x81 grid points.
The spatial step sizes are dx = 1/80 and dy = 1/80.
Discretize the PDE using a second-order conservative finite difference method for the spatial term.
The discrete operator for an interior grid node (i,j) is (1/dx^2)[ D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}(u_{i,j}-u_{i-1,j}) ] + (1/dy^2)[ D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}(u_{i,j}-u_{i,j-1}) ].
The diffusion coefficients on cell faces are computed using arithmetic means: D_{i+1/2,j}=0.5*(D(x_i,y_j)+D(x_{i+1},y_j)) and D_{i,j+1/2}=0.5*(D(x_i,y_j)+D(x_i,y_{j+1})).
Integrate in time using the Implicit Euler method.
The time step is dt = 0.0005.
The simulation runs for 200 time steps to reach the final time T = 0.1.
At each time step, solve the sparse linear system (I - dt*L) u^{n+1} = u^n for the interior grid points.
Compute the solution u(x,y,t) at the final time T = 0.1.
Save the solution to a file named "solution_agent_diffusion_04.npz".
The npz file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u at the final time.
The shape of the u array should be (Ny+1, Nx+1) such that u[j,i] corresponds to u(x_i, y_j).
The npz file must also contain the scalar metadata T, dx, dy, and dt.
Create a heatmap or contour plot of the final solution u(x,y,T=0.1).
