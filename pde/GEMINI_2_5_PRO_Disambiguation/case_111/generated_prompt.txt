The task is to solve a system of ordinary differential equations.
The system of equations is dx/dt = A + x^2 * y - (B + 1) * x.
The second equation in the system is dy/dt = B * x - x^2 * y.
The independent variable is t, representing time.
The dependent variables are x(t) and y(t).
The time domain for the simulation is the closed interval [0.0, 20.0].
The parameter A is 1.0.
The parameter B is 3.0.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 1.0.
The numerical integration method is the classical 4th-order Runge-Kutta (RK4).
The time step size dt is fixed at 0.01.
The total number of time steps Nt is 2000.
The solution must be computed at all time points t_n = n*dt for n from 0 to Nt.
A file named "solution_molk_010.npz" must be saved.
The NPZ file must contain a 1D array 't' of time points of length Nt+1.
The NPZ file must contain a 2D array 'Y' of shape (Nt+1, 2) with the solution.
The columns of the 'Y' array must be ordered as [x, y].
The NPZ file must contain the scalar parameters A and B.
A plot file named "solution_molk_010.png" must be saved.
The plot must show x(t) versus t and y(t) versus t as line plots.
The final state values x(20.0) and y(20.0) must be printed to standard output.
The minimum and maximum values of x(t) over the entire simulation must be printed to standard output.
The minimum and maximum values of y(t) over the entire simulation must be printed to standard output.
