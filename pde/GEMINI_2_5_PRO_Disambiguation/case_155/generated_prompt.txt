The task is to solve the 1D Compressible Navier-Stokes equations without heat conduction.
The unknown fields to be solved for are density rho(x,t), velocity v(x,t), and pressure p(x,t).
The simulation will evolve the conservative variables U = [rho, m, E].
The momentum is defined as m = rho*v.
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The continuity equation is rho_t + (m)_x = 0.
The momentum equation is m_t + (m^2/rho + p - sigma)_x = 0.
The energy equation is E_t + ( (E+p)*v - v*sigma )_x = 0.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1].
The simulation will run from t=0 to T=0.5.
The adiabatic index Gamma is 1.6666666666666667.
The dynamic viscosity eta is 0.01.
The bulk viscosity zeta is 0.01.
The boundary conditions are periodic on the spatial domain.
The initial density is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial velocity is v(x,0) = 0.1*cos(pi*x).
The initial pressure is p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx = 400 cells.
The cell spacing is dx = 2.0 / 400 = 0.005.
The cell centers are at x_j = -1 + (j+0.5)*dx for j=0,...,399.
Pressure is recovered from the conservative variables using p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a minimum value of 1e-12 if they fall below it.
Use the Rusanov numerical flux for the convective terms.
The physical convective flux is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The Rusanov flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
Compute the velocity gradient v_x at cell centers using a second-order centered difference.
Compute the viscous stress sigma at cell centers.
Approximate sigma at cell interfaces by averaging the values from the two adjacent cell centers.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.
The total numerical flux at an interface is the sum of the Rusanov flux and the viscous flux.
Integrate in time using the two-stage, second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step dt is the minimum of the convective and viscous time step limits.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
Use a CFL number of 0.9.
Adjust the last time step to end the simulation exactly at T=0.5.
Implement periodic boundary conditions using ghost cells with wrapped-around values.
Compute the solution rho, v, and p on the cell centers at the final time T=0.5.
