The PDE to solve is u_t + beta * u_x = 0.
The unknown field is u(x,t).
The spatial domain is x in [0, 1).
The temporal domain is t in [0, 2.0].
The final time T is 2.0.
The parameter beta is 0.4.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for verification is u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition.
Use a uniform spatial grid with Nx=512 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
The upwind direction is determined by the positive sign of beta.
Integrate in time using the explicit forward Euler method.
The initial time step dt is calculated using a CFL number of 0.5, as dt = 0.5 * dx / abs(beta).
The number of time steps is Nt = ceil(T/dt).
The final time step is adjusted to dt = T/Nt to hit the final time exactly.
Compute the numerical solution u at the final time T.
Save the solution to a file named "solution_pdebench_advection_beta0p4.npz".
