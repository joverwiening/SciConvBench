Solve the Laplace PDE u_xx + u_yy = 0 on the domain [0,1] x [0,1].
The unknown field is u(x,y).
The exact reference solution is u(x,y) = x**2 - y**2.
Use Nx = Ny = 100 uniform intervals in each direction, giving 101 x 101 grid points including boundaries.
Set dx = dy = 1/100.
Define x_i = i * dx for i = 0..100 and y_j = j * dy for j = 0..100.
Apply Dirichlet boundary conditions on all four edges using the exact solution u(x,y) = x**2 - y**2.
Discretize the interior nodes using the standard 5-point finite difference stencil: (u[i-1,j] - 2*u[i,j] + u[i+1,j]) / dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1]) / dy**2 = 0.
Assemble the resulting sparse linear system for all interior nodes only.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Fill in the boundary values from the exact solution after solving.
Store the solution in a 2D array u with shape (101, 101) such that u[j, i] = u(x_i, y_j).
Compute and print min(u) over the full grid.
Compute and print max(u) over the full grid.
Compute and print the discrete L2 norm as sqrt(sum(u**2) * dx * dy) over the full grid.
Evaluate the exact solution u_exact[j, i] = x_i**2 - y_j**2 on the same 101 x 101 grid.
Compute and print the max absolute error: max(|u - u_exact|) over the full grid.
Compute and print the L2 error: sqrt(sum((u - u_exact)**2) * dx * dy) over the full grid.
