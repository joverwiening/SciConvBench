Solve the 2D wave equation u_tt = u_xx + u_yy (wave speed c=1.0) numerically and save results.

The PDE is u_tt = (1.0)**2 * (u_xx + u_yy) on the domain (x,y) in [0,1]x[0,1], t in [0,0.5].

Use Dirichlet boundary conditions u=0 on all four boundaries.

Set initial condition u(x,y,0) = sin(pi*x)*sin(2*pi*y) and u_t(x,y,0) = 0.

The exact solution for error comparison is u(x,y,t) = cos(1.0*pi*sqrt(5)*t)*sin(pi*x)*sin(2*pi*y).

Use a uniform grid with Nx=Ny=160 intervals, giving 161x161 grid points including both endpoints.
Set dx = 1.0/160 and dy = 1.0/160.
Set x_i = i*dx for i=0..160 and y_j = j*dy for j=0..160.

Set c = 1.0.
Compute dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)).
Set Nt = ceil(0.5 / dt0) and then dt = 0.5 / Nt so the simulation hits T=0.5 exactly.

Use the 5-point Laplacian stencil for the spatial second derivatives: u_xx + u_yy at interior point (i,j) = (u[j,i+1] - 2*u[j,i] + u[j,i-1])/dx**2 + (u[j+1,i] - 2*u[j,i] + u[j-1,i])/dy**2.

Use 2nd-order central difference in time: u_new = 2*u_curr - u_old + dt**2 * laplacian(u_curr).

Initialize u_old = u(x,y,0) = sin(pi*x)*sin(2*pi*y).
Compute u_new (first time step, n=0 to n=1) using the Taylor start: u_new = u_old + dt*u_t0 + 0.5*dt**2*laplacian(u_old), where u_t0=0 everywhere, so u_new = u_old + 0.5*dt**2*laplacian(u_old).

After each time step, enforce u=0 on all boundary nodes (i=0, i=160, j=0, j=160).

Advance the solution for Nt steps until t=T=0.5.

After the time loop, compute the 2D array u with shape (161, 161) where u[j,i] = u(x_i, y_j, T).

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy).

Evaluate the exact solution on the same grid and compute and print the max absolute error and the discrete L2 error sqrt(sum((u - u_exact)**2)*dx*dy).
