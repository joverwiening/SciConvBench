Solve the scalar ODE du/dt = a*sin(2*pi*t)*u numerically using the specifications below.

The ODE is du/dt = a*sin(2*pi*t)*u where a = 1.3.
The time domain is t in [0.0, 5.0].
The initial condition is u(0) = u0 = 1.0 (standard default since no other value is given).
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt = 0.001 and Nt = 5000 steps so the final time t = 5.0 is hit exactly.
Compute u(t) at all time points t_n = 0.0 + n*0.001 for n = 0, 1, ..., 5000, giving 5001 total points.
The exact solution is u(t) = u0 * exp( a*(1 - cos(2*pi*t)) / (2*pi) ).
Evaluate the exact solution on the same 5001-point time grid.
Compute the max absolute error: max over n of |u_numerical[n] - u_exact[n]|.
Compute the L2 error: sqrt( mean over n of (u_numerical[n] - u_exact[n])**2 ).
Print u at the final time t=5.0, min(u) over the time grid, max(u) over the time grid, the max absolute error, and the L2 error.

Save a line plot of u(t) vs t as "solution_molk_000.png" with t on the horizontal axis and u on the vertical axis.
