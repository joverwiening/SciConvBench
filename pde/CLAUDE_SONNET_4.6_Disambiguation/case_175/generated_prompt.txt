Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The spatial domain is [0, 1) with periodic boundary conditions.
Use Nx = 512 uniformly spaced grid points with no duplicated endpoint.
Set dx = 1/512 and x_j = j * dx for j = 0, 1, ..., 511.
Set nu = 0.5 and rho = 5.0.
Set dt = 0.001 and Nt = 1000 steps, so T = 1.0.
Apply the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).
Use Strang splitting for each full time step dt as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).
Step B (reaction full step, duration dt): update each grid point exactly using u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Step C (diffusion half-step again): repeat Step A identically.
Repeat the full Strang splitting (A, B, C) for each of the Nt = 1000 time steps.
After all time steps, compute u at final time T = 1.0 on the 512-point grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
