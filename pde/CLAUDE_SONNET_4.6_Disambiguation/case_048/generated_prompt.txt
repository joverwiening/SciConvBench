Solve the Klein-Gordon PDE numerically as specified below.

PDE is u_tt - (1.0)**2 * u_xx + (1.0)**2 * u = 0, where c=1.0 and m=1.0.
Domain is x in [0,1] (closed) and t in [0,1.0].
Boundary conditions are Dirichlet: u=0 at x=0 and x=1 for all t.
Initial condition is u(x,0) = sin(pi*x) and u_t(x,0) = 0.
Exact solution for verification is u(x,t) = cos(sqrt((pi)**2 + 1.0)*t) * sin(pi*x).

Use a uniform spatial grid with Nx=400 intervals, giving Nx+1=401 points including both endpoints.
Set dx = 1.0/400.
Use 2nd-order central differences for u_xx.
Use leapfrog (2nd-order central difference in time) for u_tt.
Treat the +m**2*u term explicitly at time level n in the leapfrog update.
Set dt0 = 0.9 * dx / c.
Set Nt = ceil(T / dt0) where T=1.0.
Set dt = T / Nt so the final time is hit exactly.

Initialize u at time level n=0 as u0[i] = sin(pi * x[i]) for all interior and boundary points.
Apply Taylor start for u at time level n=1: u1[i] = u0[i] + dt * v0[i] + 0.5 * dt**2 * (c**2 * u_xx(u0)[i] - m**2 * u0[i]), where v0[i]=0.
Enforce u1[0]=0 and u1[Nx]=0 after the Taylor start.

At each subsequent leapfrog step from n=1 to Nt-1, compute u_new[i] = 2*u[i] - u_old[i] + dt**2 * (c**2 * (u[i+1] - 2*u[i] + u[i-1]) / dx**2 - m**2 * u[i]) for interior points i=1 to Nx-1.
Enforce u_new[0]=0 and u_new[Nx]=0 at every step.

After completing all time steps, evaluate the solution u(x, T=1.0) on the full grid of 401 points.
Compute the exact solution u_exact[i] = cos(sqrt(pi**2 + 1.0) * T) * sin(pi * x[i]) on the same grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
