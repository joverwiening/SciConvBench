Solve the Klein-Gordon PDE numerically as specified below.

The PDE is u_tt - (1.0)**2 * u_xx + (1.0)**2 * u = sin(pi*x) * cos(2*t).
The spatial domain is x in [0, 1] (closed interval). The time domain is t in [0, 5.0].
Parameters are c = 1.0 and m = 1.0.
Initial conditions are u(x, 0) = 0 and u_t(x, 0) = 0.

Use Nx = 400 uniform intervals on [0, 1], giving 401 grid points including both endpoints.
Compute dx = 1.0 / 400.
Grid points are x_i = 0 + i * dx for i = 0, 1, ..., 400.
Use dt = 0.001 and run for 5000 time steps to reach T = 5.0.
Verify that c * dt / dx <= 0.9 (the CFL condition is satisfied).

Apply homogeneous Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 at all times.

Use 2nd-order central differences for u_xx: u_xx at point i is (u[i-1] - 2*u[i] + u[i+1]) / dx**2.
Use leapfrog (2nd-order central difference in time) for u_tt.
The leapfrog update for interior points is: u_new[i] = 2*u[i] - u_old[i] + dt**2 * (c**2 * u_xx[i] - m**2 * u[i] + sin(pi * x[i]) * cos(2 * t_n)), where t_n is the current time level n.
The m**2 * u term is treated explicitly at time level n.
The forcing term sin(pi * x[i]) * cos(2 * t_n) is evaluated at time level n.

Initialize u_old (time level 0) using u(x, 0) = 0 for all grid points.
Use a Taylor expansion start for u_new at time level 1 (the first step).
The Taylor start formula is: u1[i] = u0[i] + dt * v0[i] + 0.5 * dt**2 * (c**2 * u0_xx[i] - m**2 * u0[i] + sin(pi * x[i]) * cos(0)), where v0[i] = u_t(x, 0) = 0 and u0[i] = 0.
Since u0 = 0 and v0 = 0, the Taylor start simplifies to: u1[i] = 0.5 * dt**2 * sin(pi * x[i]) * cos(0) = 0.5 * dt**2 * sin(pi * x[i]).
Enforce boundary conditions u1[0] = 0 and u1[400] = 0 after the Taylor start.

After completing all 5000 time steps, the array u holds u(x, T=5.0).

Compute and print min(u), max(u), and the discrete L2 norm defined as sqrt(sum(u**2) * dx).
