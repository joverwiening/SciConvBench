Solve the 1D Reaction-Diffusion PDE: u_t = nu * u_xx + rho * u*(1 - u).
Use nu = 0.5 and rho = 10.0.
The spatial domain is the half-open interval [0, 1) with periodic boundary conditions.
Use Nx = 512 uniformly spaced grid points with no duplicated endpoint.
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.
Apply the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).
Use a fixed time step dt = 0.001 and Nt = 1000 steps, so the final time T = dt * Nt = 1.0.
Advance the solution using Strang splitting for each full time step dt as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).
Step B (reaction full step, duration dt): update each grid point exactly using the logistic ODE solution u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Step C (diffusion half-step again): repeat Step A identically.
Repeat Steps A, B, C for all Nt = 1000 time steps.
After all steps, compute the final solution u(x, T).
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at time T.
Save a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz" containing: array x of length Nx, array u of length Nx, and scalars nu, rho, T, dx, dt, Nx, Nt.
