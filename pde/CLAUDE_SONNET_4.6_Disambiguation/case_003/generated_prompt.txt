Solve the PDE u_t + a(x)*u_x = 0 where a(x) = 1 + 0.5*sin(2*pi*x) numerically in Python.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
Use Nx = 1200 uniform grid points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Set x_i = i*dx for i = 0, 1, ..., Nx-1.
Set amax = 1.5.
Set dt0 = 0.9 * dx / amax.
Set Nt = ceil(0.5 / dt0).
Set dt = 0.5 / Nt so the final time T = 0.5 is hit exactly.
Apply the upwind spatial discretization with a left-biased stencil: u_x at point i is approximated as (u[i] - u[i-1]) / dx, using modular indexing for periodicity (i-1 wraps to Nx-1 when i=0).
The semi-discrete equation at each point i is: du[i]/dt = -a(x[i]) * (u[i] - u[i-1]) / dx.
Apply Forward Euler time integration: u[i]^(n+1) = u[i]^n - dt * a(x[i]) * (u[i]^n - u[i-1]^n) / dx.
Set the initial condition u(x, 0) = sin(2*pi*x) evaluated at each grid point.
March forward Nt steps using the Forward Euler update with the upwind stencil.
After completing all time steps, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
