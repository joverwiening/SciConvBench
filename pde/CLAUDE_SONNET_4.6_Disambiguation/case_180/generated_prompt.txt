Solve the 1D Reaction-Diffusion PDE: u_t = nu * u_xx + rho * u*(1 - u).
Use nu = 1.0 and rho = 1.0.
The spatial domain is the half-open interval [0, 1) with periodic boundary conditions.
Use Nx = 512 uniformly spaced grid points with no duplicated endpoint: dx = 1.0/512, x_i = i*dx for i = 0, 1, ..., 511.
The initial condition is u(x, 0) = 0.25 + 0.1*sin(2*pi*x).
Use a fixed time step dt = 0.001 with Nt = 1000 steps, so the final time is T = 1.0.
At each full time step, apply Strang splitting in three substeps.
Substep A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).
Substep B (reaction full step, duration dt): update each grid point exactly using the logistic ODE solution: u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).
Substep C (diffusion half-step again): repeat Substep A identically.
After all Nt steps, compute and print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at final time T.
Save a file named "solution_pdebench_reacdiff_nu1_rho1.npz" containing the 1D array x of length 512, the 1D array u of length 512, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x, T) as a PNG file named "solution_pdebench_reacdiff_nu1_rho1.png".
Use Python with numpy (for FFT via numpy.fft.fft, numpy.fft.ifft, numpy.fft.fftfreq) and matplotlib for the plot.
Interpret '^' as exponentiation and use '**' in Python code for powers.
