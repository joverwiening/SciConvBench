Solve the Poisson PDE u_xx + u_yy = f(x,y) where f(x,y) = sin(pi*x) + cos(2*pi*y).
The spatial domain is (x,y) in [0,1] x [0,1].
Apply Dirichlet boundary conditions u=0 on all four edges.
Use a uniform grid with Nx=Ny=120 intervals, giving 121 grid points in each direction including boundaries.
Set dx=dy=1/120, x_i=i*dx for i=0..120, y_j=j*dy for j=0..120.
Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on interior nodes only.
Assemble the resulting sparse linear system for the interior nodes.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Place the solution values at interior nodes into the full (121x121) grid, with boundary values set to zero.
Store u such that u[j,i] = u(x_i, y_j), giving u a shape of (121, 121).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy).
Save "solution_agent_poisson_08.npz" containing: x (1D array of length 121), y (1D array of length 121), u (2D array of shape (121,121)), and scalar metadata dx and dy.
