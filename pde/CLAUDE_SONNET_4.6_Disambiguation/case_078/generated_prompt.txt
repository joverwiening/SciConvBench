Solve the Poisson PDE numerically with the following specifications.

PDE: u_xx + u_yy = f(x,y), where f(x,y) = -2*pi**2*cos(pi*x)*cos(pi*y).

Domain: (x,y) in [0,1] x [0,1].

Boundary conditions: Dirichlet on all four edges; set u on the boundary to match u(x,y) = cos(pi*x)*cos(pi*y).

Exact solution for verification: u(x,y) = cos(pi*x)*cos(pi*y).

Use a uniform grid with Nx=Ny=120 intervals in each direction, giving Nx+1=121 grid points per direction including both endpoints.
Set dx = dy = 1/120.
Set x_i = i*dx for i=0..120 and y_j = j*dy for j=0..120.

Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on the interior nodes.

Assemble the resulting sparse linear system for all interior nodes.

Solve the sparse linear system using scipy.sparse.linalg.spsolve.

Fill in boundary values from the exact Dirichlet condition u(x,y) = cos(pi*x)*cos(pi*y) on all four edges.

Compute the steady-state solution u(x,y) on the full (Nx+1) x (Ny+1) grid.

Store the solution array u with shape (len(y), len(x)) so that u[j,i] = u(x_i, y_j).

Save a file named "solution_agent_poisson_05.npz" containing: x (1D array of length 121), y (1D array of length 121), u (2D array of shape (121,121)), dx (scalar), dy (scalar).

Save a heatmap or contour plot of u(x,y) as "solution_agent_poisson_05.png".

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy).

Compute the reference solution u_exact(x_i, y_j) = cos(pi*x_i)*cos(pi*y_j) on the same grid.
