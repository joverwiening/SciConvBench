Solve the 1D linear advection PDE numerically and save results.

The PDE is u_t + 1.0 * u_x = 0 on the domain x in [0,1), t in [0, 1.0].
The advection speed is a = 1.0.
The initial condition is u(x, 0) = sin(2 * pi * x).
The exact solution is u(x, t) = sin(2 * pi * (x - 1.0 * t)).

Use a uniform periodic grid with Nx = 800 points on [0,1).
Set dx = 1.0 / Nx.
Grid points are x_i = i * dx for i = 0, 1, ..., Nx-1.

Use 1st-order upwind scheme for the spatial derivative u_x.
Since a = 1.0 > 0, the upwind difference is (u_i - u_{i-1}) / dx with periodic indexing (i-1 wraps around using modulo Nx).

Use Forward Euler time integration.
Set dt0 = 0.9 * dx / abs(a).
Set Nt = ceil(T / dt0) where T = 1.0.
Set dt = T / Nt so the final time is hit exactly.

At each time step, compute u_new_i = u_i - a * dt / dx * (u_i - u_{i-1}) for all i simultaneously, using periodic boundary indexing.
Advance Nt steps to reach t = T = 1.0.

After the time loop, compute the following and print them.
Print min(u) at T.
Print max(u) at T.
Print the discrete L2 norm: sqrt(sum(u**2) * dx) at T.
Evaluate the exact solution u_exact_i = sin(2 * pi * (x_i - 1.0 * T)) on the same grid.
Print the max absolute error: max(abs(u - u_exact)).
Print the L2 error: sqrt(sum((u - u_exact)**2) * dx).

Save a file named "solution_agent_advection_01.npz" containing the 1D array x, the 1D array u (both of length Nx = 800), and the scalar metadata T = 1.0, dx, and dt.
Save a line plot of u(x, T) versus x as "solution_agent_advection_01.png" with x on the horizontal axis and u on the vertical axis.
