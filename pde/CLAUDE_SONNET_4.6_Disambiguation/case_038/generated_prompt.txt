Solve the 2D heat equation u_t = 0.1 * (u_xx + u_yy) numerically using implicit Euler and save results.

The PDE is u_t = 0.1 * (u_xx + u_yy) where alpha = 0.1.

The exact solution for verification is u(x,y,t) = exp(-2 * 0.1 * pi**2 * t) * sin(pi*x) * sin(pi*y).

Apply implicit Euler time integration: at each step, solve the sparse linear system (I - dt * alpha * L) * u_new = u_old for interior nodes only, where L is the discrete Laplacian operator assembled for interior nodes.
