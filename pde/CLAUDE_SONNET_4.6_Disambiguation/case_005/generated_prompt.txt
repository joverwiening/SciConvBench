Solve the 2D linear advection PDE numerically and save the results as specified below.

The PDE is u_t + (-0.7)*u_x + (1.2)*u_y = 0.
The spatial domain is (x,y) in [0,1) x [0,1), periodic in both directions, and the time domain is t in [0,0.5].
The advection coefficients are a = -0.7 in x and b = 1.2 in y.
The initial condition is u(x,y,0) = exp(-80*((x-0.2)**2 + (y-0.6)**2)).

Use Nx = Ny = 256 grid points on the half-open periodic domain [0,1) x [0,1).
Set dx = 1/256 and dy = 1/256.
Set x_i = i*dx for i = 0..255 and y_j = j*dy for j = 0..255.

Compute dt0 = 0.9 / (|a|/dx + |b|/dy).
Set Nt = ceil(0.5 / dt0) and then dt = 0.5 / Nt so the final time T = 0.5 is hit exactly.

Use first-order upwind spatial discretization with direction chosen by the sign of each coefficient.
Since a = -0.7 < 0, use a right-biased (backward in the negative direction) difference in x: u_x at (i,j) approximated as (u[i+1,j] - u[i,j]) / dx, with index i+1 taken modulo Nx for periodicity.
Since b = 1.2 > 0, use a left-biased (forward in the positive direction) difference in y: u_y at (i,j) approximated as (u[i,j] - u[i,j-1]) / dy, with index j-1 taken modulo Ny for periodicity.

Use Forward Euler time integration: u_new = u - dt * (a * u_x_upwind + b * u_y_upwind).

Apply periodic boundary conditions using modulo indexing on both x and y at every time step.

After Nt steps, compute u(x,y,T=0.5) on the 2D grid.

Store the solution array u with shape (Ny, Nx) = (256, 256) such that u[j,i] = u(x_i, y_j) at T.

Save a file named "solution_agent_advection_05.npz" containing: x as a 1D array of length 256, y as a 1D array of length 256, u as the 2D array of shape (256,256), and scalar metadata T=0.5, dx, dy, dt.

Save a heatmap or filled contour plot of u(x,y,T) as "solution_agent_advection_05.png" with x on the horizontal axis and y on the vertical axis.

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy) at T=0.5.

Write and execute Python code using numpy and matplotlib to accomplish all of the above.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
a = -0.7
b = 1.2
T = 0.5
Nx = 256
Ny = 256
dx = 1.0 / Nx
dy = 1.0 / Ny

# Grid (half-open periodic domain)
x = np.arange(Nx) * dx  # shape (Nx,)
y = np.arange(Ny) * dy  # shape (Ny,)

# Time stepping
dt0 = 0.9 / (abs(a)/dx + abs(b)/dy)
Nt = math.ceil(T / dt0)
dt = T / Nt

print(f"dx={dx}, dy={dy}, dt0={dt0:.6f}, Nt={Nt}, dt={dt:.6f}")
print(f"CFL check: |a|*dt/dx + |b|*dt/dy = {abs(a)*dt/dx + abs(b)*dt/dy:.6f}")

# Initial condition: u[j,i] = u(x_i, y_j)
X, Y = np.meshgrid(x, y)  # X,Y shape (Ny, Nx)
u = np.exp(-80.0 * ((X - 0.2)**2 + (Y - 0.6)**2))

# Time integration: Forward Euler with upwind scheme
# a < 0: right-biased in x => u_x ~ (u[j, i+1] - u[j, i]) / dx
# b > 0: left-biased in y  => u_y ~ (u[j, i] - u[j-1, i]) / dy

for n in range(Nt):
    # Upwind differences using periodic indexing
    # a < 0: right-biased difference in x
    u_x = (np.roll(u, -1, axis=1) - u) / dx  # roll left => i+1
    # b > 0: left-biased difference in y
    u_y = (u - np.roll(u, 1, axis=0)) / dy   # roll right => j-1

    u = u - dt * (a * u_x + b * u_y)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx * dy)
print(f"min(u) = {u_min:.6e}")
print(f"max(u) = {u_max:.6e}")
print(f"L2 norm = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_advection_05.npz",
         x=x, y=y, u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         dy=np.float64(dy),
         dt=np.float64(dt))
print("Saved solution_agent_advection_05.npz")

# Save plot
fig, ax = plt.subplots(figsize=(6, 5))
cp = ax.contourf(x, y, u, levels=50, cmap='viridis')
fig.colorbar(cp, ax=ax, label='u(x,y,T)')
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.set_title(f'u(x,y,T=0.5) - 2D Advection (upwind, Forward Euler)')
plt.tight_layout()
plt.savefig("solution_agent_advection_05.png", dpi=150)
plt.close()
print("Saved solution_agent_advection_05.png")
```
