Solve the PDE u_t = -q1 * d/dx(sin(u)) + (q2/pi) * u_xx numerically using the specifications below.

Use Python with numpy for the implementation.

The PDE is u_t = -q1 * d/dx(sin(u)) + (q2/pi) * u_xx.

Set q1 = 1.0 and q2 = 0.05.

The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].

Use Nx = 1024 uniform grid points on [0, 1).
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.

Apply the initial condition u(x, 0) = 0.5 * sin(2 * pi * x).

Apply periodic boundary conditions: u(0, t) = u(Nx-1+1, t), meaning index wrapping via modulo or numpy roll.

Discretize d/dx(sin(u)) using a conservative finite-volume Rusanov flux.
At each cell interface j+1/2, compute the Rusanov flux as F_{j+1/2} = 0.5 * (sin(u_j) + sin(u_{j+1})) - 0.5 * alpha * (u_{j+1} - u_j), where alpha = max(|cos(u)|) over all grid points at the current time step.
Compute the flux divergence as (F_{j+1/2} - F_{j-1/2}) / dx using periodic index wrapping.

Discretize u_xx using second-order central differences: u_xx at j = (u_{j+1} - 2*u_j + u_{j-1}) / dx**2, with periodic index wrapping.

Use SSP-RK2 (Shu-Osher) for time integration.
SSP-RK2 stage 1: u_star = u_n + dt * L(u_n).
SSP-RK2 stage 2: u_{n+1} = 0.5 * u_n + 0.5 * (u_star + dt * L(u_star)).
Here L(u) = -q1 * flux_divergence(u) + (q2/pi) * u_xx(u).

Compute the time step as follows.
Set dt_adv = 0.2 * dx / 1.0.
Set dt_diff = 0.2 * dx**2 / (q2 / pi).
Set dt = min(dt_adv, dt_diff).
Set Nt = ceil(0.5 / dt) as an integer.
Reset dt = 0.5 / Nt so the final step lands exactly at t = 0.5.

Run the time loop for Nt steps, updating u at each step using SSP-RK2.
