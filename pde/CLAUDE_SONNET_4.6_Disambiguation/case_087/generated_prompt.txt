Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically using the specifications below.

PDE is u_tt = c^2 * u_xx where c = 1.0.

Domain is x in [0,1] (closed interval), t in [0, 1.0].

Use Nx = 400 uniform intervals so there are 401 grid points including both endpoints.
Set dx = 1.0 / 400.
Set x_i = 0 + i * dx for i = 0, 1, ..., 400.

Compute dt0 = 0.9 * dx / c.
Set Nt = ceil(1.0 / dt0).
Set dt = 1.0 / Nt so the final time T = 1.0 is hit exactly.

Apply zero Neumann boundary conditions u_x(0,t) = 0 and u_x(1,t) = 0 using ghost points.
For the left ghost point, set u[-1] = u[1] (mirror).
For the right ghost point, set u[Nx+1] = u[Nx-1] (mirror).

Set initial condition u(x, 0) = cos(pi * x) for all grid points.
Set initial velocity v0(x) = u_t(x, 0) = 0 for all grid points.

Compute u_xx at time 0 using 2nd-order central differences including ghost points at the boundaries.
Compute the first time step using the Taylor start: u^1 = u^0 + dt * v0 + 0.5 * dt**2 * c**2 * u_xx^0.
Since v0 = 0 everywhere, this simplifies to u^1 = u^0 + 0.5 * dt**2 * c**2 * u_xx^0.

For all subsequent time steps n = 1, 2, ..., Nt-1, apply the leapfrog update:
u^{n+1} = 2 * u^n - u^{n-1} + dt**2 * c**2 * u_xx^n.
At each step, recompute u_xx^n using 2nd-order central differences with ghost point mirroring at both boundaries before applying the update.

After completing all Nt steps, the solution u is defined at T = 1.0.

Compute the exact solution u_exact(x) = cos(pi * x) * cos(1.0 * pi * 1.0) evaluated on the same x grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).

Save a file named "solution_agent_wave_06.npz" containing arrays x (1D, length 401), u (1D, length 401), and scalar metadata T = 1.0, dx, dt.

Save a line plot of u(x, T=1.0) versus x as "solution_agent_wave_06.png".

Use Python with numpy for numerics and matplotlib for the plot.
Use ** for exponentiation in Python code.
Treat all trigonometric arguments as radians.
