Solve the PDE u_t = -k * d/dx( (1/3)*u^3 ) numerically using the specifications below.

The PDE is u_t = -k * d/dx( (1/3)*u^3 ) with k = 1.0.
The flux function is f(u) = (1/3)*u**3.
The derivative of the flux is f'(u) = u**2.

Use the spatial domain x in [0, 1) with periodic boundary conditions.
Use Nx = 1024 uniform grid points with no duplicated endpoint.
Set dx = 1.0 / Nx.
Set x_j = j * dx for j = 0, 1, ..., Nx-1.

Use the initial condition u(x, 0) = 0.5 * sin(2 * pi * x).
Apply periodic boundary conditions: u(0, t) = u(Nx-1+1, t) meaning index wrapping via modulo Nx.

Use a conservative finite-volume spatial discretization with Rusanov (local Lax-Friedrichs) numerical flux at each cell interface.
At interface between cell j and cell j+1, compute the Rusanov flux as:
F_{j+1/2} = 0.5 * (f(u_j) + f(u_{j+1})) - 0.5 * alpha_{j+1/2} * (u_{j+1} - u_j)
where alpha_{j+1/2} = max(|f'(u_j)|, |f'(u_{j+1})|) = max(u_j**2, u_{j+1}**2).
Use periodic index wrapping so that index Nx maps to index 0.
The spatial update for cell j is: L(u)_j = -(F_{j+1/2} - F_{j-1/2}) / dx.

Use SSP-RK2 (Heun's method) for time integration.
Stage 1: u_star = u^n + dt * L(u^n).
Stage 2: u^{n+1} = 0.5 * u^n + 0.5 * (u_star + dt * L(u_star)).

Set the final time T = 0.2.
Set CFL = 0.2.
Estimate max|f'(u)| = max(u**2) using the initial condition; since |u| <= 0.5 initially, use max_speed = 0.25.
Compute dt0 = CFL * dx / max_speed.
Compute Nt = ceil(T / dt0).
Compute dt = T / Nt.
Use this fixed dt for all time steps.

Integrate from t = 0 to t = T over Nt steps.

At the end, output or store the final solution array u at t = 0.2 on the grid x_j for j = 0, ..., Nx-1.

Use Python with NumPy.
Use '**' for exponentiation in all Python code.
Treat all trigonometric arguments in radians.
