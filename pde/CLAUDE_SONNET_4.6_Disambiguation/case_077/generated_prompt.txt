Solve the Poisson PDE u_xx + u_yy = f(x,y) numerically on the domain (x,y) in [0,1] x [0,1].
The source term is f(x,y) = (1 - pi**2)*exp(x)*sin(pi*y).
The exact solution is u(x,y) = exp(x)*sin(pi*y).
Apply Dirichlet boundary conditions on all four edges by setting u on the boundary equal to exp(x)*sin(pi*y).
Use a uniform grid with Nx=Ny=120 intervals in each direction, giving Nx+1=121 grid points per direction including both endpoints.
Set dx = dy = 1/120.
Set x_i = i*dx for i=0..120 and y_j = j*dy for j=0..120.
Discretize the Laplacian using the standard 5-point stencil (second-order finite differences) on interior nodes only.
Assemble the resulting sparse linear system for the interior unknowns.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Fill in the boundary values from the Dirichlet condition exp(x)*sin(pi*y) to form the full (121 x 121) solution array.
Store the solution array u with shape (len(y), len(x)) so that u[j,i] = u(x_i, y_j).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) over the full grid.
Compute the reference solution u_exact[j,i] = exp(x_i)*sin(pi*y_j) on the same grid.
Compute and print the max absolute error max(|u - u_exact|) and the L2 error sqrt(sum((u - u_exact)**2)*dx*dy).
