Solve the PDE u_tt + 0.01 * u_xxxx = 0 (Euler-Bernoulli beam equation) numerically using a sine-series spectral method in Python.

Use kappa = 0.01.

The spatial domain is x in [0, 1] with Nx = 800 uniform intervals, giving dx = 1/800.
The interior grid points are x_i = i * dx for i = 1 to Nx-1 (799 points); boundaries at i=0 and i=Nx are fixed at u = 0.

The boundary conditions are simply-supported: u(0,t) = 0, u(1,t) = 0, u_xx(0,t) = 0, u_xx(1,t) = 0.

The initial conditions are u(x,0) = sin(pi*x) and u_t(x,0) = 0.

Apply the Discrete Sine Transform type I (DST-I) to the interior values to obtain modal coefficients û_n for n = 1 to Nx-1, corresponding to basis functions sin(n*pi*x).

For each mode n, the angular frequency is omega_n = (n*pi)**2 * sqrt(kappa).

Compute the DST-I of u(x,0) to get û_n(0) and the DST-I of u_t(x,0) to get v̂_n(0).

Use the exact per-mode time update: û_n(t) = û_n(0) * cos(omega_n * t) + (v̂_n(0) / omega_n) * sin(omega_n * t).
For modes where omega_n = 0, use û_n(t) = û_n(0) + v̂_n(0) * t.

Use dt = 1e-4 and Nt = 10000 steps so that T = 1.0 is hit exactly.
Evaluate the solution at T = 1.0 by applying the exact update formula directly at t = T (no time-stepping loop required, just evaluate at t = 1.0).

Apply the inverse DST-I to the modal coefficients at T to recover u(x, T) on the interior grid points i = 1 to Nx-1.

The reference exact solution is u_exact(x, T) = cos((pi**2) * sqrt(0.01) * T) * sin(pi * x), evaluated on the same interior x grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.
Print the max absolute error max(|u - u_exact|) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
