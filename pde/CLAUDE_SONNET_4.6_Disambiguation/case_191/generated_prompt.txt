Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the full specification below.

Domain: x in [0, 1) with periodic boundary, t in [0, 1.0].
Parameters: nu = 5.0, rho = 5.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Spatial grid: Use Nx = 512 uniform points on [0,1). Set dx = 1.0/512. Set x_j = j*dx for j = 0, 1, ..., 511.
Time grid: Use fixed dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Numerical method: Strang splitting for each full time step dt.

Step A (Diffusion half-step, duration dt/2): Compute u_hat = FFT(u). Compute k = 2*pi*fftfreq(Nx, d=dx). Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)). Set u = real(IFFT(u_hat)).

Step B (Reaction full step, duration dt): Apply the exact pointwise logistic ODE update du/dt = rho * u * (1 - u). For each grid point update u as u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).

Step C (Diffusion half-step again): Repeat Step A identically with duration dt/2.

Repeat Steps A, B, C for all Nt = 1000 time steps.

Output: Compute u(x, T=1.0) on the periodic grid after all steps.
Save a file named "solution_pdebench_reacdiff_nu5_rho5.npz" containing arrays x (1D, length 512) and u (1D, length 512), and scalars nu, rho, T, dx, dt, Nx, Nt.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
