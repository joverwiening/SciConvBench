Solve the Laplace PDE u_xx + u_yy = 0 on the domain [0,1] x [0,1].
The exact solution for boundary conditions and verification is u(x,y) = x*y.
Use Nx = Ny = 100 uniform intervals in each direction, giving 101 x 101 grid points including boundaries.
Set dx = dy = 1/100 = 0.01.
Define x_i = i*dx for i = 0..100 and y_j = j*dy for j = 0..100.
Apply Dirichlet boundary conditions on all four edges using the exact solution u(x,y) = x*y evaluated at the boundary nodes.
Discretize the interior nodes using the standard 5-point finite difference stencil: (u[i-1,j] - 2*u[i,j] + u[i+1,j])/dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1])/dy**2 = 0.
Assemble the resulting sparse linear system for all interior nodes only.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Fill the full (101 x 101) solution array by placing the solved interior values and the known boundary values into their correct positions.
Store the solution as a 2D array u with shape (len(y), len(x)) so that u[j, i] = u(x_i, y_j).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) over the full grid.
Compute the reference solution u_exact[j,i] = x_i * y_j on the full grid.
Compute and print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2)*dx*dy).
