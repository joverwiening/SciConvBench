Solve the 1D advection PDE u_t + beta * u_x = 0 numerically in Python.

Use beta = 2.0.

The spatial domain is the half-open interval [0, 1) with periodic boundary conditions.

Use Nx = 512 uniformly spaced grid points with no duplicated endpoint, so dx = 1.0 / 512 and x_j = j * dx for j = 0, 1, ..., 511.

The initial condition is u(x, 0) = sin(2 * pi * x) + 0.5 * sin(4 * pi * x), evaluated on the grid.

The final time is T = 2.0.

Use CFL = 0.5 to set dt = CFL * dx / abs(beta).

Compute Nt = ceil(T / dt) and then reset dt = T / Nt so the solver lands exactly at T.

Advance the solution in time using explicit forward Euler.

At each time step, discretize u_x using 1st-order upwind finite differences; since beta = 2.0 > 0, use the backward difference: u_x at j ≈ (u[j] - u[j-1]) / dx, with the index j-1 taken modulo Nx to enforce periodicity.

The update is: u[j] = u[j] - dt * beta * (u[j] - u[j-1]) / dx for all j, with indices mod Nx.

After Nt steps, the array u holds the numerical solution at time T on the 512-point grid.

Compute the reference solution u_ref[j] = sin(2 * pi * ((x_j - beta * T) % 1.0)) + 0.5 * sin(4 * pi * ((x_j - beta * T) % 1.0)) on the same grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u ** 2) * dx).

Print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref) ** 2) * dx).
