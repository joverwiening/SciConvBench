Solve the 1D advection PDE u_t + beta * u_x = 0 numerically in Python.

Use beta = 1.0.

The spatial domain is the half-open interval [0, 1) with periodic boundary conditions: u(0, t) = u(1, t) for all t.

Use Nx = 512 grid points with no duplicated endpoint. Set dx = 1.0 / 512. Set x_i = i * dx for i = 0, 1, ..., 511.

The initial condition is u(x, 0) = sin(2 * pi * x) + 0.5 * sin(4 * pi * x).

The final time is T = 2.0.

Use CFL = 0.5. Set dt = CFL * dx / abs(beta). Set Nt = ceil(T / dt). Reset dt = T / Nt so the final time is hit exactly.

Use 1st-order upwind finite difference for u_x. Since beta = 1.0 > 0, the upwind direction is backward: approximate u_x at point i as (u[i] - u[i-1]) / dx, with index i-1 taken modulo Nx to enforce periodicity.

Use explicit forward Euler time integration: u_new[i] = u[i] - dt * beta * (u[i] - u[i-1]) / dx for each time step.

Advance the solution for Nt steps.

The reference solution is u_ref(x, T) = u0((x - beta * T) mod 1), where u0 is the initial condition function.

Evaluate the reference solution on the same x grid.

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.

Compute and print the max absolute error and the L2 error between the numerical solution and the reference solution at T. The L2 error is sqrt(sum((u - u_ref)**2) * dx).

Save a file named "solution_pdebench_advection_beta1.npz" containing the following arrays and scalars: x (1D, length 512), u (1D, length 512), beta, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T) as "solution_pdebench_advection_beta1.png" with x on the horizontal axis and u on the vertical axis.
