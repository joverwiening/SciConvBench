Solve the 1D Reaction-Diffusion PDE numerically as described below.

The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
Use nu = 10.0 and rho = 2.0.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0 / 512.
Set x_j = j * dx for j = 0, 1, ..., 511.

Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Apply the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).

At each full time step, apply Strang splitting as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2 * pi * fftfreq(512, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).

Step B (reaction full-step, duration dt): for each grid point apply the exact logistic update u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).

Step C (diffusion half-step again): repeat Step A identically.

Repeat Steps A, B, C for all 1000 time steps.

After all time steps, compute u(x, T=1.0) on the periodic grid.

Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.

Save a file named "solution_pdebench_reacdiff_nu10_rho2.npz" containing the following arrays and scalars: x (1D array of length 512), u (1D array of length 512), nu (scalar 10.0), rho (scalar 2.0), T (scalar 1.0), dx (scalar 1.0/512), dt (scalar 0.001), Nx (scalar 512), Nt (scalar 1000).

Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu10_rho2.png" with x on the horizontal axis and u on the vertical axis.
