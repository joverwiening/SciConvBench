Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the following complete specification.

Domain: x in [-1, 1], t in [0, 0.2].
Use a uniform finite-volume grid with Nx = 800 cells.
Cell spacing: dx = 2.0 / 800 = 0.0025.
Cell centers: x_j = -1 + (j + 0.5) * dx for j = 0, ..., 799.

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08, T = 0.2.
Use CFL = 0.8 for the convective time step limit.

PDE in conservative form with U = [rho, m, E]:
rho_t + (m)_x = 0.
m_t + (m^2/rho + p - sigma)_x = 0.
E_t + ((E + p)*v - v*sigma)_x = 0.
Total energy: E = p / (Gamma - 1) + 0.5 * rho * v^2.
Viscous stress: sigma = (zeta + 4/3 * eta) * v_x, with zeta = eta = 1e-08.

Equation of state: p = (Gamma - 1) * (E - 0.5 * m^2 / rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 before any computation that uses them.

Initial condition: Riemann (shock-tube) discontinuity at x = 0.
For x < 0: rho = 1.0, v = 0.0, p = 1.0.
For x >= 0: rho = 0.1, v = 0.0, p = 0.01.
Initialize cell-average conservative variables U = [rho, m, E] from these primitive values.

Boundary conditions: transmissive/outflow (zero-gradient) at both x = -1 and x = 1.
Implement using one ghost cell on each side set equal to the nearest interior cell value.

Convective flux: use Rusanov (local Lax-Friedrichs) numerical flux.
F_conv(U) = [m, m^2/rho + p, (E + p)*v] with v = m/rho.
Interface wave speed: a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma * p / rho).
Numerical flux: F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L).
Use piecewise-constant reconstruction (first-order), so U_L at interface j+1/2 is cell j and U_R is cell j+1.

Viscous flux: compute v_x at each cell center using centered differences on the cell-centered v values (using ghost cells for boundary cells).
Compute cell-centered sigma = (zeta + 4/3 * eta) * v_x.
At each interface j+1/2, approximate sigma_interface = 0.5 * (sigma_j + sigma_{j+1}).
Approximate v_interface = 0.5 * (v_j + v_{j+1}).
Viscous flux contribution: F_visc = [0, -sigma_interface, -v_interface * sigma_interface].
Total interface flux: F_total = F_hat + F_visc.

Time integration: use 2-stage SSP-RK2 (Heun's method).
Stage 1: U_star = U^n + dt * L(U^n).
Stage 2: U^{n+1} = 0.5 * U^n + 0.5 * (U_star + dt * L(U_star)).
L(U) denotes the finite-volume right-hand side: L_j = -(F_{j+1/2} - F_{j-1/2}) / dx.

Time step selection at each step:
dt_conv = CFL * dx / max_j(|v_j| + c_j).
dt_visc = 0.5 * dx^2 / max(zeta + 4/3 * eta, 1e-30).
dt = min(dt_conv, dt_visc).
Adjust the final time step so that t + dt does not exceed T = 0.2 exactly.

Output: compute rho(x, T), v(x, T), p(x, T) at all 800 cell centers at the final time.
Save file "solution_pdebench_cns1d_shock_eta1em8_outflow.npz" containing arrays x (length 800), rho (length 800), v (length 800), p (length 800), and scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel line plot of rho, v, p versus x at time T as "solution_pdebench_cns1d_shock_eta1em8_outflow.png".
Print the minimum and maximum of rho, the minimum and maximum of p (positivity check), and the mean of rho over the domain (mass conservation check).
