Solve the PDE u_t + (-0.5)*u_x = 0 numerically using the specifications below.

The unknown field is u(x,t).

The spatial domain is x in [0,1) with periodic boundary conditions, and the time domain is t in [0,1.0].

The advection speed parameter is a = -0.5.

The initial condition is u(x,0) = exp(-100*(x-0.3)**2).

Use a uniform periodic grid with Nx = 1000 points on [0,1). Set dx = 1.0/Nx. The grid points are x_i = i*dx for i = 0, 1, ..., 999.

Use 1st-order upwind spatial discretization. Because a < 0, use the right-biased (downwind) stencil: u_x at point i is approximated as (u[i+1] - u[i]) / dx, with index i+1 taken modulo Nx for periodicity.

Use Forward Euler time integration. Compute dt0 = 0.9 * dx / abs(a). Set Nt = ceil(T / dt0) where T = 1.0. Set dt = T / Nt so the final time is hit exactly.

At each time step n, update: u[i]^(n+1) = u[i]^n - a * dt/dx * (u[(i+1) % Nx]^n - u[i]^n) for all i in 0..Nx-1.

Apply periodic boundary indexing using modulo Nx for all spatial index references.

After completing all Nt time steps, the solution u represents u(x, T=1.0).

Save a file named "solution_agent_advection_02.npz" containing the following arrays and scalars: x (1D array of length 1000), u (1D array of length 1000), T (scalar = 1.0), dx (scalar), dt (scalar).

Save a line plot of u(x, T=1.0) as a PNG file named "solution_agent_advection_02.png" with x on the horizontal axis and u on the vertical axis.

Print the following scalar diagnostics: min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx).

Use Python with numpy for computation and matplotlib for plotting. Use ** for exponentiation in code.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
Nx = 1000
T = 1.0
a = -0.5
x = np.arange(Nx) * (1.0 / Nx)
dx = 1.0 / Nx

# Initial condition
u = np.exp(-100 * (x - 0.3)**2)

# Time stepping setup
dt0 = 0.9 * dx / abs(a)
Nt = math.ceil(T / dt0)
dt = T / Nt

# Verify CFL
cfl = abs(a) * dt / dx
print(f"Nx={Nx}, dx={dx:.6e}, dt={dt:.6e}, Nt={Nt}, CFL={cfl:.6f}")

# Forward Euler with 1st-order upwind (right-biased stencil for a < 0)
for _ in range(Nt):
    u_right = np.roll(u, -1)          # u[(i+1) % Nx]
    u = u - a * (dt / dx) * (u_right - u)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_advection_02.npz", x=x, u=u, T=T, dx=dx, dt=dt)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=1.0)")
ax.set_title("Advection solution at T=1.0 (agent_advection_02)")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_advection_02.png", dpi=150)
plt.close()
print("Files saved: solution_agent_advection_02.npz, solution_agent_advection_02.png")
```
