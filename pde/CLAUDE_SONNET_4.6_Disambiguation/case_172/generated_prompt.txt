Solve the 1D Reaction-Diffusion PDE: u_t = nu * u_xx + rho * u*(1 - u).
Set nu = 0.5 and rho = 1.0.
The spatial domain is [0, 1) with periodic boundary conditions.
Use Nx = 512 grid points with dx = 1/512 and x_j = j * dx for j = 0, 1, ..., 511.
Use a fixed time step dt = 0.001 with Nt = 1000 steps, so the final time T = 1.0.
Apply the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).
At each full time step, apply Strang splitting in three substeps.
Substep A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).
Substep B (reaction full step, duration dt): update each grid point exactly using u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Substep C (diffusion half-step again): repeat Substep A identically.
Repeat the full Strang splitting step (A then B then C) for all Nt = 1000 time steps.
After all time steps, compute and print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at final time T.
Save a file named "solution_pdebench_reacdiff_nu0p5_rho1.npz" containing the 1D array x of length 512, the 1D array u of length 512, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu0p5_rho1.png".
Use Python with numpy (for FFT via numpy.fft.fft, numpy.fft.ifft, numpy.fft.fftfreq) and matplotlib for the plot.
