Apply zero Neumann boundary conditions at both ends using ghost points: u[-1]=u[1] and u[Nx+1]=u[Nx-1], meaning u_ghost_left = u[1] and u_ghost_right = u[Nx-1].

Use 2nd-order central differences for u_xx at all interior points and also at the boundary points i=0 and i=Nx using the ghost point values.

At i=0: u_xx[0] = (u_ghost_left - 2*u[0] + u[1]) / dx**2 = (u[1] - 2*u[0] + u[1]) / dx**2 = (2*u[1] - 2*u[0]) / dx**2.

At i=Nx: u_xx[Nx] = (u[Nx-1] - 2*u[Nx] + u_ghost_right) / dx**2 = (2*u[Nx-1] - 2*u[Nx]) / dx**2.

Assemble L as a sparse tridiagonal matrix of size (Nx+1)x(Nx+1). Interior rows i=1,...,Nx-1 have L[i,i-1]=1/dx**2, L[i,i]=-2/dx**2, L[i,i+1]=1/dx**2. Boundary row i=0 has L[0,0]=-2/dx**2, L[0,1]=2/dx**2. Boundary row i=Nx has L[Nx,Nx-1]=2/dx**2, L[Nx,Nx]=-2/dx**2.
