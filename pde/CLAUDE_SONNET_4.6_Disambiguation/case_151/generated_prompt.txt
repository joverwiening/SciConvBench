Solve the 1D viscous Burgers equation u_t + d/dx(0.5*u^2) = nu*u_xx numerically in Python.
The spatial domain is x in [0,1) with periodic boundary conditions.
The final time is T = 1.0.
The viscosity parameter is nu = 2.0.
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx = 512 uniformly spaced grid points on the half-open domain [0,1); dx = 1.0/512; x_i = i*dx for i = 0, 1, ..., 511.
Estimate the maximum speed as 1.0 and set CFL = 0.4; compute dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0) and reset dt = T/Nt so the solver hits T exactly.
At each full time step, apply Strang splitting in three substeps.
Substep A (diffusion half-step, duration dt/2): compute u_hat = FFT(u); compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx); multiply u_hat by exp(-nu*k**2*(dt/2)); set u = real(IFFT(u_hat)).
Substep B (advection full-step, duration dt): use a finite-volume Rusanov (local Lax-Friedrichs) update for the inviscid Burgers equation u_t + d/dx(0.5*u^2) = 0. Define f(u) = 0.5*u**2. For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing so u[Nx] = u[0]), compute alpha = max(abs(u_left), abs(u_right)) and flux F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j, set u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus is the flux at interface (j, j+1) and F_minus is the flux at interface (j-1, j). Replace u with u_new after all cells are updated.
Substep C (diffusion half-step, duration dt/2): same procedure as Substep A.
After all Nt time steps, compute and print min(u), max(u), mean(u) (discrete mean, should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx).
