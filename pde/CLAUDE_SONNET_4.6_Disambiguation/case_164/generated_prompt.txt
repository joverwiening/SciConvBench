Solve the 1D Compressible Navier-Stokes equations (no heat conduction) numerically in Python and save the results.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use conservative variables: momentum m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.

Define the viscous stress as sigma = (zeta + 4/3*eta) * dv/dx, with zeta = eta = 1e-08.

The PDEs in conservative form are:
  rho_t + (m)_x = 0
  m_t + (m**2/rho + p - sigma)_x = 0
  E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use Nx = 800 uniform cells with cell-centered finite volume discretization.
dx = 2.0 / 800 = 0.0025.
Cell centers are at x_i = -1 + (i + 0.5)*dx for i = 0, 1, ..., 799.

Set Gamma = 5/3 (1.6666666666666667), eta = 1e-08, zeta = 1e-08.

Apply the Riemann (Sod shock-tube) initial condition with a discontinuity at x = 0.
For x < 0: rho = 1.0, v = 0.0, p = 2.0.
For x >= 0: rho = 0.125, v = 0.0, p = 0.2.

Apply transmissive (zero-gradient, outflow) boundary conditions at both x = -1 and x = 1.
Implement outflow BCs by copying the nearest interior cell state into one ghost cell on each side.

Use a finite volume method with a Godunov-type or HLLC/AUSM Riemann solver (or Lax-Friedrichs as fallback) for the inviscid fluxes.
Compute viscous fluxes using centered finite differences of v at cell interfaces.
Use a CFL-based adaptive time step: dt = CFL * dx / max_wave_speed, with CFL = 0.5.
Advance in time using a first-order or second-order (e.g., Runge-Kutta) time integrator until T = 0.2.

At the final time T = 0.2, extract rho, v, p at all 800 cell centers.

  x: 1D array of length 800 (cell centers)
  rho: 1D array of length 800
  v: 1D array of length 800
  p: 1D array of length 800
