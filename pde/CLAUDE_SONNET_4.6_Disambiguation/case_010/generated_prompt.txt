Solve the Allen-Cahn PDE numerically as described below.

The PDE is u_t = (0.01)**2 * (u_xx + u_yy) + u - u**3.
The spatial domain is [0,1) x [0,1) with periodic boundary conditions, and the time domain is t in [0, 0.2].
The parameter epsilon = 0.01, so epsilon**2 = 0.0001.
The initial condition is u(x, y, 0) = 0.1 * cos(2*pi*x) * cos(2*pi*y).

Use Nx = Ny = 256 uniform grid points on the half-open domain [0,1) x [0,1).
Compute dx = 1.0/256 and dy = 1.0/256.
Set x_i = i*dx for i = 0..255 and y_j = j*dy for j = 0..255.
Use dt = 0.0002 and run for 1000 time steps to reach T = 0.2.

Discretize the Laplacian using the standard 5-point stencil: (u[i+1,j] - 2*u[i,j] + u[i-1,j])/dx**2 + (u[i,j+1] - 2*u[i,j] + u[i,j-1])/dy**2.
Apply periodic boundary indexing using modulo arithmetic so that index -1 wraps to 255 and index 256 wraps to 0.

Use a semi-implicit time integration scheme: (u_new - u_old)/dt = epsilon**2 * Laplacian(u_new) + u_old - u_old**3.
Rearrange to: u_new - dt*epsilon**2*Laplacian(u_new) = u_old + dt*(u_old - u_old**3).
At each time step, form and solve a sparse linear system of size (256*256) x (256*256) for u_new.
Build the sparse matrix using scipy.sparse with the 5-point Laplacian stencil and periodic wrap-around in both x and y directions.
Use scipy.sparse.linalg.spsolve or a similar direct sparse solver to solve the linear system each step.
The matrix is constant across all time steps, so factor or assemble it once before the time loop.

After completing all 1000 time steps, compute u(x, y, T=0.2) on the 256x256 grid.
Store the result as a 2D array u with shape (256, 256) such that u[j, i] = u(x_i, y_j).

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx * dy) at T=0.2.
