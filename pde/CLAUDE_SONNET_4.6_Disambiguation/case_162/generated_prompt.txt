Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the following complete specification.

Task ID is pdebench_cns1d_sod3_eta1em8_outflow.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Define m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Set zeta = eta.

The PDE in conservative form is:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Parameters are Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Boundary conditions are transmissive/outflow (zero-gradient) at both x=-1 and x=1.

The initial condition is a Riemann (shock-tube) discontinuity at x=0.
For x < 0: rho_L = 1.0, v_L = 0.75, p_L = 1.0.
For x >= 0: rho_R = 0.125, v_R = 0.0, p_R = 0.1.

Use a uniform finite-volume grid with Nx = 800 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., 799, where dx = 2.0/800.

Evolve the conservative variables U = [rho, m, E] as cell averages.

Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux.
The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] where v = m/rho.
The interface wave speed is a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

For the viscous terms, compute v_x at each cell center using a centered difference on the cell-centered v values.
Compute sigma at each cell center as sigma = (zeta + 4/3*eta) * v_x.
Approximate sigma at each interface by averaging the two neighboring cell-centered sigma values.
The viscous flux contribution at each interface is F_visc = [0, -sigma, -v*sigma] using the interface-averaged v and sigma.
The total interface flux is F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.

At each time step, compute the time step as follows.
dt_conv = CFL * dx / max_j(|v_j| + c_j).
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30).
dt = min(dt_conv, dt_visc).
Adjust the last step so the simulation hits the final time T = 0.2 exactly.

Use CFL = 0.8.

For outflow boundary conditions, implement ghost cells by setting their values equal to the nearest interior cell (zero-gradient).

After the simulation, compute rho(x, T), v(x, T), p(x, T) on the 800 cell centers.

Save a plot (3-panel or 3 separate subplots) of rho, v, and p versus x at time T as solution_pdebench_cns1d_sod3_eta1em8_outflow.png.
