Solve the 1D Reaction-Diffusion PDE: u_t = nu * u_xx + rho * u*(1 - u).
Set nu = 0.5 and rho = 2.0.
The spatial domain is [0, 1) with periodic boundary conditions.
Use Nx = 512 grid points with no duplicated endpoint.
Set dx = 1/512 and x_j = j*dx for j = 0, 1, ..., 511.
The initial condition is u(x, 0) = 0.25 + 0.1*sin(2*pi*x).
Use fixed dt = 0.001 and Nt = 1000 time steps, so T = 1.0.
Apply Strang splitting for each full time step dt as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), set u = real(IFFT(u_hat)).
Step B (reaction full step, duration dt): update each grid point exactly using u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Step C (diffusion half-step again): repeat Step A identically.
Repeat Steps A, B, C for all Nt = 1000 time steps.
After all steps, compute the final solution u(x, T).
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at time T.
Save a file named "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing arrays x (length 512), u (length 512), and scalars nu, rho, T, dx, dt, Nx, Nt.
