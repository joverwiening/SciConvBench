Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.

Use beta = 0.4 and final time T = 2.0.

The spatial domain is [0, 1) with periodic boundary conditions: u(0, t) = u(1, t) for all t.

Use Nx = 512 grid points with no duplicated endpoint (half-open interval).
Set dx = 1.0 / Nx.
Set x_i = i * dx for i = 0, 1, ..., Nx-1.

The initial condition is u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

Use 1st-order upwind finite difference for the spatial derivative u_x.
Since beta = 0.4 > 0, the upwind direction is backward: approximate u_x at point i as (u[i] - u[i-1]) / dx, with index i-1 taken modulo Nx for periodicity.

Use explicit forward Euler for time integration.
Set CFL = 0.5.
Set dt = CFL * dx / abs(beta).
Set Nt = ceil(T / dt).
Reset dt = T / Nt so the final time T is hit exactly.

At each time step, update u using: u[i] = u[i] - beta * dt / dx * (u[i] - u[i-1]) for all i, with periodic indexing.

The reference solution is u_ref(x, T) = u0((x - beta*T) mod 1), where u0 is the initial condition function evaluated at the shifted and wrapped x values.

After time-stepping to T, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Compute and print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx) against the reference solution on the same x grid.
