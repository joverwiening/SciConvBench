Solve the PDE u_t = -q1 * d/dx( (1/3)*u^3 ) + (q2/pi)*u_xx numerically in Python.

Use q1 = 1.0 and q2 = 0.05.

The spatial domain is x in [0, 1) with periodic boundary conditions.

The time domain is t in [0, 0.5], so T = 0.5.

Use Nx = 1024 uniform grid points on [0, 1) with no duplicated endpoint.

Set dx = 1.0 / Nx and x_j = j * dx for j = 0, 1, ..., Nx-1.

Apply the initial condition u(x, 0) = 0.5 * sin(2 * pi * x).

Use a conservative finite-volume Rusanov flux to discretize d/dx( (1/3)*u^3 ).

For cell j, define the flux function f(u) = (1/3) * u**3 and its derivative f_prime(u) = u**2.

At each interface between cell j and cell j+1, compute the Rusanov numerical flux as F_{j+1/2} = 0.5 * (f(u_j) + f(u_{j+1})) - 0.5 * alpha_{j+1/2} * (u_{j+1} - u_j), where alpha_{j+1/2} = max(|f_prime(u_j)|, |f_prime(u_{j+1})|).

Use periodic indexing so that cell Nx-1 is adjacent to cell 0.

Compute the convective term for cell j as -q1 * (F_{j+1/2} - F_{j-1/2}) / dx.

Discretize u_xx using 2nd-order central differences: (u_{j+1} - 2*u_j + u_{j-1}) / dx**2 with periodic indexing.

Compute the diffusion term for cell j as (q2 / pi) * (u_{j+1} - 2*u_j + u_{j-1}) / dx**2.

The full right-hand side for cell j is the convective term plus the diffusion term.

Compute the time step as follows.

Set max_fprime = max(u**2) evaluated on the initial condition; if this value is zero, use a small fallback such as 1e-10 to avoid division by zero.

Set dt0 = 0.2 * dx / max_fprime.

Set dt_diff = 0.2 * dx**2 / (q2 / pi).

Set dt = min(dt0, dt_diff).

Set Nt = ceil(T / dt) and recompute dt = T / Nt so the solver lands exactly at T.

Advance the solution using SSP-RK2 (Shu-Osher form).

For each time step: compute k1 = RHS(u), set u_star = u + dt * k1, compute k2 = RHS(u_star), then update u = 0.5 * u + 0.5 * (u_star + dt * k2).
