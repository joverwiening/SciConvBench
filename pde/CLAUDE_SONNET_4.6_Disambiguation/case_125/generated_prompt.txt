Final specification for Task ID: molk_024

Solve the 1D convection-diffusion PDE numerically using Python.

The PDE is u_t = -q1 * d/dx(0.5 * u**2) + (q2/pi) * u_xx.

The spatial domain is x in [0, 1) with periodic boundary conditions. The time domain is t in [0, 0.5].

Set q1 = 1.0 and q2 = 0.1.

Use a uniform periodic grid with Nx = 512 points on [0, 1). Define dx = 1.0 / Nx. Set x_j = j * dx for j = 0, 1, ..., Nx-1. There is no duplicated endpoint.

Apply periodic boundary conditions: u(0, t) = u(1, t) for all t.

Set the initial condition as u(x, 0) = sin(2 * pi * x) evaluated at each grid point x_j.

Compute the effective diffusion coefficient D_eff = q2 / pi.

Compute dt_conv = 0.4 * dx / 1.0, where max|u0| = 1 and CFL = 0.4.

Compute dt_diff = 0.4 * dx**2 / D_eff.

Set dt0 = min(dt_conv, dt_diff).

Set Nt = ceil(0.5 / dt0) and dt = 0.5 / Nt so the simulation hits t = 0.5 exactly.

Discretize the nonlinear convection flux f(u) = 0.5 * u**2 using the Rusanov (local Lax-Friedrichs) flux at each cell interface.

At each interface between cell j and cell j+1, compute the Rusanov flux as F_{j+1/2} = 0.5 * (f(u_j) + f(u_{j+1})) - 0.5 * alpha_{j+1/2} * (u_{j+1} - u_j), where alpha_{j+1/2} = max(|u_j|, |u_{j+1}|) is the local maximum wave speed.

Use periodic index wrapping so that index Nx maps to index 0 and index -1 maps to index Nx-1.

Compute the convection contribution to the right-hand side as -q1 * (F_{j+1/2} - F_{j-1/2}) / dx for each cell j.

Discretize the diffusion term u_xx using second-order central differences: (u_{j+1} - 2*u_j + u_{j-1}) / dx**2, with periodic index wrapping.

Compute the full right-hand side as RHS(u)_j = -q1 * (F_{j+1/2} - F_{j-1/2}) / dx + (q2 / pi) * (u_{j+1} - 2*u_j + u_{j-1}) / dx**2.

Integrate in time using SSP-RK2 (Heun's method). For each time step: compute u_star = u_n + dt * RHS(u_n), then compute u_{n+1} = 0.5 * u_n + 0.5 * (u_star + dt * RHS(u_star)).

Advance for exactly Nt time steps to reach t = 0.5.

After completing the time integration, output or store the final solution array u at t = 0.5 over the grid x_j for j = 0, ..., Nx-1.

No closed-form reference solution is required for verification.
