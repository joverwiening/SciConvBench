Solve the 1D advection PDE u_t + beta * u_x = 0 with beta = 0.2.
The spatial domain is [0, 1) with periodic boundary conditions, treated as half-open.
Use Nx = 512 grid points with dx = 1.0 / 512 and x_i = i * dx for i = 0 to 511.
The initial condition is u(x, 0) = sin(2 * pi * x) + 0.5 * sin(4 * pi * x).
The final time T is not specified in the prompt; use T = 1.0 as the default final time.
Apply 1st-order upwind finite difference for the spatial derivative u_x, using the left-sided (backward) difference because beta > 0: u_x at i approximated as (u[i] - u[i-1]) / dx with periodic index wrapping.
Apply explicit forward Euler time integration: u_new[i] = u[i] - beta * dt * (u[i] - u[i-1]) / dx.
Set CFL = 0.5 and compute dt = CFL * dx / abs(beta).
Compute Nt = ceil(T / dt) and reset dt = T / Nt so the final time T is hit exactly.
March the solution forward Nt steps using the forward Euler upwind update with periodic indexing.
The reference solution is u_ref(x, T) = sin(2 * pi * ((x - beta * T) mod 1)) + 0.5 * sin(4 * pi * ((x - beta * T) mod 1)).
Compute max absolute error as max(abs(u_numerical - u_ref)) over all grid points.
Compute L2 error as sqrt(sum((u_numerical - u_ref) ** 2) * dx).
Print min(u), max(u), discrete L2 norm sqrt(sum(u ** 2) * dx), max absolute error, and L2 error at final time T.
Save "solution_pdebench_advection_beta0p2.npz" containing arrays x (length 512), u (length 512), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x, T) as "solution_pdebench_advection_beta0p2.png".
Use Python with numpy for computation and matplotlib for the plot.

Here is the complete Python code:

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
beta = 0.2
T = 1.0
Nx = 512
CFL = 0.5

# Grid: half-open [0,1), Nx points, no duplicated endpoint
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_i = i * dx, i = 0..Nx-1

# Initial condition
u = np.sin(2 * np.pi * x) + 0.5 * np.sin(4 * np.pi * x)

# Time step
dt_trial = CFL * dx / abs(beta)
Nt = int(np.ceil(T / dt_trial))
dt = T / Nt  # reset so final time is hit exactly

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, T={T}")

# Time integration: forward Euler + 1st-order upwind (beta > 0 => left-sided difference)
for _ in range(Nt):
    # Upwind: beta > 0, use backward difference (u[i] - u[i-1]) / dx
    u_left = np.roll(u, 1)          # u_left[i] = u[i-1] with periodic wrap
    u = u - beta * dt / dx * (u - u_left)

# Reference solution
x_shifted = (x - beta * T) % 1.0
u_ref = np.sin(2 * np.pi * x_shifted) + 0.5 * np.sin(4 * np.pi * x_shifted)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u ** 2) * dx)
max_abs_err = np.max(np.abs(u - u_ref))
l2_err = np.sqrt(np.sum((u - u_ref) ** 2) * dx)

print(f"min(u)       = {u_min:.6e}")
print(f"max(u)       = {u_max:.6e}")
print(f"L2 norm(u)   = {l2_norm:.6e}")
print(f"Max abs error= {max_abs_err:.6e}")
print(f"L2 error     = {l2_err:.6e}")

# Save .npz
np.savez(
    "solution_pdebench_advection_beta0p2.npz",
    x=x,
    u=u,
    beta=beta,
    T=T,
    dx=dx,
    dt=dt,
    Nx=Nx,
    Nt=Nt
)
print("Saved solution_pdebench_advection_beta0p2.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x,T={T})", linewidth=1.2)
ax.plot(x, u_ref, '--', label="Reference solution", linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"1D Advection (beta={beta}), T={T}, Nx={Nx}, Upwind+ForwardEuler")
ax.legend()
ax.grid(True, linestyle=':', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_pdebench_advection_beta0p2.png", dpi=150)
plt.close()
print("Saved solution_pdebench_advection_beta0p2.png")
```
