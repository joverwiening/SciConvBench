Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.

The spatial domain is the half-open interval [0, 1) with periodic boundary conditions.

The reference (exact) solution is u(x, t) = u0((x - beta * t) mod 1), where u0 is the initial condition function.

Use 1st-order upwind finite difference for the spatial derivative u_x.
Since beta = 4.0 > 0, the upwind direction is left, so approximate u_x at point i as (u[i] - u[i-1]) / dx, with index i-1 taken modulo Nx to enforce periodicity.
Use explicit forward Euler for time integration: u_new[i] = u[i] - dt * beta * (u[i] - u[i-1]) / dx.

Set CFL = 0.5 and compute dt = CFL * dx / abs(beta).
Compute Nt = ceil(T / dt) and then reset dt = T / Nt so the final time T = 2.0 is hit exactly.
March the solution forward Nt steps using the forward Euler upwind update.
