Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically using the specifications below.

The PDE is u_tt = c^2 * u_xx with c = 1.0.
The spatial domain is x in [0,1] (closed interval) and the time domain is t in [0,1.0].
The boundary conditions are Dirichlet: u(0,t) = 0 and u(1,t) = 0 for all t.
The initial condition is u(x,0) = 0 (since the exact solution u(x,0) = (1/pi)*sin(0)*sin(pi*x) = 0).
The initial velocity is u_t(x,0) = (1/pi)*pi*cos(0)*sin(pi*x) = sin(pi*x) (derivative of exact solution with respect to t at t=0).
The exact solution for verification is u(x,t) = (1/pi)*sin(pi*t)*sin(pi*x).

Use a uniform grid with Nx=400 intervals, giving Nx+1=401 grid points including both endpoints.
Set dx = 1.0/400.
Compute dt0 = 0.9*dx/c.
Set Nt = ceil(1.0/dt0) and then dt = 1.0/Nt so the final time T=1.0 is hit exactly.
The CFL number c*dt/dx must be at most 0.9.

Use 2nd-order central differences for u_xx in the interior: u_xx at node i = (u[i-1] - 2*u[i] + u[i+1]) / dx**2.
Use the standard leapfrog (Störmer-Verlet) scheme for time integration: u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + dt**2 * c**2 * u_xx^n[i].
Initialize u^0 using u(x,0) = 0 for all interior and boundary nodes.
Compute u^1 using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt**2*c**2*u_xx^0, where v0[i] = sin(pi*x[i]).
Since u^0 = 0 everywhere, u_xx^0 = 0 everywhere, so u^1[i] = dt*sin(pi*x[i]) for interior nodes.
At every time step, enforce Dirichlet boundary conditions by setting u[0] = 0 and u[Nx] = 0.

After completing all Nt time steps, evaluate the numerical solution u(x, T=1.0) on the full grid of 401 points.
Evaluate the exact solution u_exact[i] = (1.0/(1.0*pi))*sin(1.0*pi*1.0)*sin(pi*x[i]) on the same grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2)*dx).
Save a file named "solution_agent_wave_04.npz" containing arrays x (1D, length 401), u (1D, length 401), and scalar metadata T=1.0, dx, dt.
Save a line plot of u(x, T=1.0) versus x as "solution_agent_wave_04.png".

Use Python with numpy for computation and matplotlib for plotting.
Use ** for exponentiation in Python code.
Treat all trigonometric functions as operating in radians.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
c = 1.0
T = 1.0
Nx = 400
dx = 1.0 / Nx
x = np.linspace(0.0, 1.0, Nx + 1)  # 401 points

# Time stepping
dt0 = 0.9 * dx / c
Nt = int(np.ceil(T / dt0))
dt = T / Nt
CFL = c * dt / dx
print(f"Nx={Nx}, dx={dx:.6f}, Nt={Nt}, dt={dt:.6f}, CFL={CFL:.6f}")

# Initial conditions
u0 = np.zeros(Nx + 1)           # u(x, 0) = 0
v0 = np.sin(np.pi * x)          # u_t(x, 0) = sin(pi*x)

# u_xx at t=0 (u0 = 0 everywhere, so u_xx^0 = 0)
u_xx0 = np.zeros(Nx + 1)

# Taylor start for u^1
u_prev = u0.copy()
u_curr = u0 + dt * v0 + 0.5 * dt**2 * c**2 * u_xx0
# Enforce Dirichlet BCs
u_curr[0] = 0.0
u_curr[Nx] = 0.0

# Leapfrog time integration
for n in range(1, Nt):
    # Compute u_xx for interior nodes
    u_xx = np.zeros(Nx + 1)
    u_xx[1:Nx] = (u_curr[0:Nx-1] - 2.0 * u_curr[1:Nx] + u_curr[2:Nx+1]) / dx**2

    # Leapfrog update
    u_next = 2.0 * u_curr - u_prev + dt**2 * c**2 * u_xx

    # Enforce Dirichlet BCs
    u_next[0] = 0.0
    u_next[Nx] = 0.0

    # Advance
    u_prev = u_curr
    u_curr = u_next

u = u_curr  # numerical solution at T=1.0

# Exact solution at T=1.0
u_exact = (1.0 / (1.0 * np.pi)) * np.sin(1.0 * np.pi * T) * np.sin(np.pi * x)

# Diagnostics
min_u = np.min(u)
max_u = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
max_abs_error = np.max(np.abs(u - u_exact))
l2_error = np.sqrt(np.sum((u - u_exact)**2) * dx)

print(f"min(u)       = {min_u:.6e}")
print(f"max(u)       = {max_u:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_abs_error:.6e}")
print(f"L2 error     = {l2_error:.6e}")

# Save npz
np.savez("solution_agent_wave_04.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_wave_04.npz")

# Save plot
plt.figure(figsize=(8, 5))
plt.plot(x, u, label=f"Numerical u(x, T={T})")
plt.plot(x, u_exact, '--', label="Exact solution")
plt.xlabel("x")
plt.ylabel("u")
plt.title(f"Wave equation solution at T={T}")
plt.legend()
plt.tight_layout()
plt.savefig("solution_agent_wave_04.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_04.png")
```
