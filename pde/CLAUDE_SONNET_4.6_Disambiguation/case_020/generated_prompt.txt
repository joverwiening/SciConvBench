Solve the PDE u_t = ∇·(D(x,y)∇u) numerically with the following specifications.

PDE is u_t = ∇·(D(x,y)∇u) where D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).

Spatial domain is (x,y) in [0,1]x[0,1], time domain is t in [0,0.1].

Interpret [0,1] as a closed interval. Use Nx=Ny=80 uniform intervals, giving 81 grid points in each direction including both endpoints. Set dx = 1/80, dy = 1/80. Set x_i = i*dx for i=0..80, y_j = j*dy for j=0..80.

Set dt=0.0005 and run for 200 time steps to reach T=0.1.

Initial condition is u(x_i, y_j, 0) = sin(pi*x_i)*sin(pi*y_j) for all i,j.

Boundary conditions are Dirichlet u=0 on all four boundary edges: i=0, i=80, j=0, j=80. Hold boundary values fixed at zero for all time steps.

Use a conservative 2nd-order finite difference discretization in flux form for the interior nodes i=1..79, j=1..79.

Compute face-averaged diffusion coefficients as D_{i+1/2,j} = 0.5*(D(x_i,y_j) + D(x_{i+1},y_j)) and D_{i,j+1/2} = 0.5*(D(x_i,y_j) + D(x_i,y_{j+1})).

Discretize the diffusion operator at interior node (i,j) as (1/dx^2)*[D_{i+1/2,j}*(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}*(u_{i,j}-u_{i-1,j})] + (1/dy**2)*[D_{i,j+1/2}*(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}*(u_{i,j}-u_{i,j-1})].

Use implicit Euler time integration: at each step solve the sparse linear system (I - dt*L)*u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator applied only to interior nodes, with boundary values enforced by keeping them fixed at zero.

Assemble the sparse matrix for the interior unknowns only (79*79 = 6241 unknowns), using scipy.sparse and solving with scipy.sparse.linalg.spsolve at each time step.

After 200 steps, compute u(x,y,T=0.1) on the full 81x81 grid (boundary rows/columns remain zero).
