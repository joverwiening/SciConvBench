Solve the Brusselator ODE system numerically using the specifications below.

The system has two unknown scalar functions of time: x(t) and y(t).

The ODE system is:
dx/dt = A + x**2 * y - (B + 1) * x
dy/dt = B * x - x**2 * y

The time domain is t in [0.0, 20.0].

Parameters are A = 1.0 and B = 3.0.

Set initial conditions to x(0) = 0.0 and y(0) = 0.0.

Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.01 and Nt = 2000 steps so the final time 20.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n * 0.01 for n = 0 to 2000 inclusive, giving Nt+1 = 2001 time points.

Store results in array t of shape (2001,) and array Y of shape (2001, 2) where column 0 is x and column 1 is y.

Save the output file as "solution_molk_010.npz" containing arrays t, Y and scalar parameters A and B.

Save a line plot of x vs t and y vs t (both on the same figure or as subplots) as "solution_molk_010.png".

Print the final state values x(20.0) and y(20.0).

Print the minimum and maximum of x over all time points.

Print the minimum and maximum of y over all time points.

Use Python with NumPy for the implementation. Use ** for exponentiation in code.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
A = 1.0
B = 3.0

# Time domain
t0 = 0.0
tf = 20.0
Nt = 2000
dt = (tf - t0) / Nt  # = 0.01

# Time array
t = np.linspace(t0, tf, Nt + 1)  # shape (2001,)

# ODE right-hand side
def rhs(state, t_cur):
    x, y = state
    dxdt = A + x**2 * y - (B + 1) * x
    dydt = B * x - x**2 * y
    return np.array([dxdt, dydt])

# Initial conditions
x0 = 0.0
y0 = 0.0
state0 = np.array([x0, y0])

# Allocate solution array
Y = np.zeros((Nt + 1, 2))
Y[0] = state0

# Classical RK4 integration
state = state0.copy()
for n in range(Nt):
    t_n = t[n]
    k1 = rhs(state,          t_n)
    k2 = rhs(state + 0.5*dt*k1, t_n + 0.5*dt)
    k3 = rhs(state + 0.5*dt*k2, t_n + 0.5*dt)
    k4 = rhs(state + dt*k3,     t_n + dt)
    state = state + (dt / 6.0) * (k1 + 2.0*k2 + 2.0*k3 + k4)
    Y[n + 1] = state

# Save .npz
np.savez(
    "solution_molk_010.npz",
    t=t,
    Y=Y,
    A=np.float64(A),
    B=np.float64(B)
)

# Save plot
fig, axes = plt.subplots(2, 1, figsize=(10, 6), sharex=True)
axes[0].plot(t, Y[:, 0], color='tab:blue', linewidth=1.0)
axes[0].set_ylabel("x(t)")
axes[0].set_title("Brusselator Chemical Oscillator (molk_010)")
axes[0].grid(True)

axes[1].plot(t, Y[:, 1], color='tab:orange', linewidth=1.0)
axes[1].set_ylabel("y(t)")
axes[1].set_xlabel("t")
axes[1].grid(True)

plt.tight_layout()
plt.savefig("solution_molk_010.png", dpi=150)
plt.close()

# Print diagnostics
print("=== Final state at T = 20.0 ===")
print(f"  x(20.0) = {Y[-1, 0]:.10f}")
print(f"  y(20.0) = {Y[-1, 1]:.10f}")

print("\n=== Min/Max of each state over all time ===")
print(f"  x: min = {Y[:, 0].min():.10f},  max = {Y[:, 0].max():.10f}")
print(f"  y: min = {Y[:, 1].min():.10f},  max = {Y[:, 1].max():.10f}")
```
