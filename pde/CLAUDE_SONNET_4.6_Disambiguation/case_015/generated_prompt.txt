Solve the 1D viscous Burgers equation numerically and save the results as specified below.

PDE is u_t + u*u_x = 0.01*u_xx, equivalently written in conservative form as u_t + (0.5*u**2)_x = 0.01*u_xx.

The spatial domain is x in [0,1] (closed interval). Use Nx=800 uniform intervals giving Nx+1=801 grid points including both endpoints. Set dx=1.0/800. Grid points are x_i = i*dx for i=0,1,...,800.

The time domain is t in [0,0.5]. Use dt=1e-4 and Nt=5000 steps so that T=0.5 is hit exactly.

Set nu=0.01.

Apply initial condition u(x,0)=sin(pi*x) at all 801 grid points.

Apply Dirichlet boundary conditions u[0]=0 and u[800]=0 at every time step.

Discretize convection in conservative form using the Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u**2.
At each interior interface i+1/2 for i=0,...,Nx-1, compute F_{i+1/2} = 0.5*(f(u[i])+f(u[i+1])) - 0.5*max(abs(u[i]),abs(u[i+1]))*(u[i+1]-u[i]).
At the left boundary interface (i=-1/2), use u[0]=0 as the left ghost value and u[0] as the right value to compute F_{-1/2}, but since u[0]=0 is a Dirichlet node, the convection flux contribution at interior node i=1 uses F_{1/2} and F_{1/2} uses u[0] and u[1]; do not apply convection update to boundary nodes i=0 and i=800.
Compute the convection term at each interior node i (i=1,...,799) as conv[i] = (F_{i+1/2} - F_{i-1/2})/dx.
For the flux at the right boundary interface (i=799+1/2), use u[800]=0 as the right value.

Discretize diffusion implicitly using 2nd-order central differences: u_xx at node i approximated as (u[i+1]-2*u[i]+u[i-1])/dx**2.
Build the tridiagonal diffusion operator L of size 801x801 for interior nodes i=1,...,799 with stencil [1, -2, 1]/dx**2.
Rows 0 and 800 of L are zero (Dirichlet boundary rows), and the right-hand side enforces u[0]=0 and u[800]=0 directly.

At each time step, form the right-hand side rhs[i] = u[i] - dt*conv[i] for interior nodes i=1,...,799, and rhs[0]=0, rhs[800]=0.
Form the matrix A = I - dt*nu*L where I is the 801x801 identity and L is the diffusion operator described above.
Solve the linear system A @ u_new = rhs using scipy.sparse.linalg.spsolve each time step.
After solving, explicitly set u_new[0]=0 and u_new[800]=0 to enforce Dirichlet BCs.
Advance u = u_new and repeat for all 5000 steps.

After completing all time steps, compute the following diagnostics and print them.
Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx).

Save a file named "solution_agent_burgers_03.npz" using numpy.savez containing: array x of shape (801,), array u of shape (801,) holding u(x,T=0.5), scalar T=0.5, scalar dx=1.0/800, scalar dt=1e-4.

Save a line plot of u versus x at T=0.5 as "solution_agent_burgers_03.png" with x on the horizontal axis and u on the vertical axis.

Use Python with numpy, scipy.sparse, scipy.sparse.linalg, and matplotlib.

```python
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla
import matplotlib.pyplot as plt

# Parameters
nu = 0.01
Nx = 800
Nt = 5000
dx = 1.0 / Nx
dt = 1e-4
T = 0.5

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 801 points

# Initial condition
u = np.sin(np.pi * x)

# Build implicit diffusion matrix A = I - dt*nu*L
# L is tridiagonal with [1, -2, 1]/dx^2 for interior rows
# Boundary rows are identity rows (to enforce u=0)
N = Nx + 1  # 801

diag_main = np.zeros(N)
diag_upper = np.zeros(N - 1)
diag_lower = np.zeros(N - 1)

# Interior nodes
for i in range(1, Nx):
    diag_main[i] = -2.0 / dx**2
    diag_upper[i] = 1.0 / dx**2      # connects i to i+1
    diag_lower[i - 1] = 1.0 / dx**2  # connects i to i-1

# Boundary rows: zero in L (identity in A)
diag_main[0] = 0.0
diag_main[Nx] = 0.0

L = sp.diags(
    [diag_lower, diag_main, diag_upper],
    [-1, 0, 1],
    shape=(N, N),
    format='csr'
)

I_mat = sp.eye(N, format='csr')
A = I_mat - dt * nu * L

# Time integration
def compute_convection(u, dx):
    """Compute convection term using Rusanov flux for interior nodes."""
    conv = np.zeros_like(u)
    f = 0.5 * u**2

    # Compute fluxes F_{i+1/2} for i = 0, 1, ..., Nx-1
    # At i=0: left value is u[0]=0 (boundary), right value is u[1]
    # But we need F_{i-1/2} and F_{i+1/2} for interior nodes i=1..Nx-1

    # Build extended arrays with boundary ghost values
    # Left ghost: u_left = 0 (Dirichlet), Right ghost: u_right = 0 (Dirichlet)
    u_ext = np.concatenate(([0.0], u, [0.0]))  # length N+2
    f_ext = 0.5 * u_ext**2

    # F_{i+1/2} for i_ext = 0..N (interfaces between ext[i] and ext[i+1])
    # Interface index k corresponds to i_ext=k, i_ext+1=k+1
    # For original node i (0..Nx), F_{i-1/2} uses ext[i] and ext[i+1] -> k=i
    # Wait, let's be careful:
    # u_ext[0] = ghost left (=0)
    # u_ext[1] = u[0] = 0 (boundary)
    # u_ext[i+1] = u[i] for i=0..Nx
    # u_ext[Nx+2] = ghost right (=0)

    # F at interface between u_ext[k] and u_ext[k+1]:
    # F[k] = 0.5*(f_ext[k]+f_ext[k+1]) - 0.5*max(|u_ext[k]|,|u_ext[k+1]|)*(u_ext[k+1]-u_ext[k])

    alpha = np.maximum(np.abs(u_ext[:-1]), np.abs(u_ext[1:]))
    F = 0.5 * (f_ext[:-1] + f_ext[1:]) - 0.5 * alpha * (u_ext[1:] - u_ext[:-1])
    # F has length N+1 (indices 0..N)
    # For original node i (i=0..Nx):
    #   F_{i-1/2} = F[i]   (interface between u_ext[i] and u_ext[i+1])
    #   F_{i+1/2} = F[i+1] (interface between u_ext[i+1] and u_ext[i+2])

    # conv[i] = (F_{i+1/2} - F_{i-1/2})/dx for interior nodes i=1..Nx-1
    for i in range(1, Nx):
        conv[i] = (F[i + 1] - F[i]) / dx

    # Boundary nodes: conv[0]=0, conv[Nx]=0 (not updated)
    return conv

# Vectorized convection (faster)
def compute_convection_vec(u, dx):
    conv = np.zeros_like(u)
    u_ext = np.concatenate(([0.0], u, [0.0]))
    f_ext = 0.5 * u_ext**2
    alpha = np.maximum(np.abs(u_ext[:-1]), np.abs(u_ext[1:]))
    F = 0.5 * (f_ext[:-1] + f_ext[1:]) - 0.5 * alpha * (u_ext[1:] - u_ext[:-1])
    # Interior nodes i=1..Nx-1 correspond to F[i+1]-F[i]
    conv[1:Nx] = (F[2:Nx + 1] - F[1:Nx]) / dx
    return conv

# Time-stepping loop
for n in range(Nt):
    conv = compute_convection_vec(u, dx)
    rhs = u - dt * conv
    rhs[0] = 0.0
    rhs[Nx] = 0.0
    u_new = spla.spsolve(A, rhs)
    u_new[0] = 0.0
    u_new[Nx] = 0.0
    u = u_new

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# Save npz
np.savez(
    "solution_agent_burgers_03.npz",
    x=x,
    u=u,
    T=np.float64(T),
    dx=np.float64(dx),
    dt=np.float64(dt)
)

# Save plot
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, u, 'b-', linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=0.5)")
ax.set_title("Viscous Burgers Equation Solution at T=0.5")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_burgers_03.png", dpi=150)
plt.close()

print("Files saved: solution_agent_burgers_03.npz, solution_agent_burgers_03.png")
```
