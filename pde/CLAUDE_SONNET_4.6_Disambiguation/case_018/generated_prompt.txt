Solve the PDE u_t = ∂/∂x( D(x) * u_x ) numerically using Python.
D(x) = 0.01 + 0.09*x**2.
The spatial domain is x in [0,1] (closed interval). Use Nx=400 uniform intervals, giving 401 grid points including both endpoints. dx = 1.0/400. x_i = i*dx for i=0..400.
The time domain is t in [0, 0.2]. Use dt=0.0005 and 400 time steps.
The initial condition is u(x,0) = x*(1-x).
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0 for all t.
Use a conservative 2nd-order finite difference discretization in flux form for the spatial operator.
Define D_i = D(x_i) = 0.01 + 0.09*x_i**2 at each grid point i.
Define face diffusion coefficients by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior points i=1..Nx-1 (i.e., i=1..399), the discrete diffusion operator is: L_i(u) = (1/dx**2) * [ D_{i+1/2}*(u_{i+1}-u_i) - D_{i-1/2}*(u_i-u_{i-1}) ].
Apply implicit Euler time integration: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator applied only to interior points.
Enforce Dirichlet boundary conditions u_0 = 0 and u_{400} = 0 at every time step by fixing those rows in the linear system.
Assemble the tridiagonal sparse linear system and solve it at each of the 400 time steps using a sparse solver (e.g., scipy.sparse.linalg.spsolve).
After completing all time steps, compute u(x, T=0.2) on the full 401-point grid.
