The PDE is u_tt = c**2 * (u_xx + u_yy) where c = 0.7.
The spatial domain is (x,y) in [0,1] x [0,1] and the time domain is t in [0, 0.8].

Set Nt = ceil(0.8 / dt0) and then dt = 0.8 / Nt so the simulation hits T = 0.8 exactly.
Apply Dirichlet boundary conditions u = 0 on all four boundaries at every time step.

For all subsequent time steps use the 2nd-order central difference: u_new = 2*u_curr - u_prev + dt**2 * c**2 * laplacian(u_curr).
