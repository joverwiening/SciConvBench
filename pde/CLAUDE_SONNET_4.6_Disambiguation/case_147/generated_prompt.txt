Solve the 1D Viscous Burgers equation u_t + d/dx(0.5*u^2) = nu*u_xx numerically.
The spatial domain is [0, 1) with periodic boundary conditions.
Use nu = 0.2.
The initial condition is u(x,0) = sin(2*pi*x).
Use Nx = 512 grid points on the half-open domain [0,1); dx = 1.0/512; x_i = i*dx for i = 0, 1, ..., 511.
Set the final time T = 2.0 (standard PDEBench setting for this configuration; if a different T is intended, replace accordingly — but use T=2.0 as the default since none was specified).
Compute dt0 = 0.4*dx/1.0 (CFL=0.4, estimated max speed=1).
Compute Nt = ceil(T/dt0) and reset dt = T/Nt so the final time is hit exactly.
At each full time step, apply Strang splitting in three substeps.
Substep A (diffusion half-step, duration dt/2): compute u_hat = FFT(u); compute k = 2*pi*fftfreq(Nx, d=dx); multiply u_hat by exp(-nu*k**2*(dt/2)); set u = real(IFFT(u_hat)).
Substep B (advection full-step, duration dt): apply a finite-volume update with Rusanov flux. Define f(u) = 0.5*u**2. For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing so u[Nx] = u[0]): alpha = max(abs(u_left), abs(u_right)); F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j: F_plus = flux at interface (j, j+1); F_minus = flux at interface (j-1, j); u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus). Replace u with u_new after all cells are updated.
Substep C (diffusion half-step again): repeat substep A identically.
After all Nt time steps, compute and print min(u), max(u), mean(u) (discrete mean, should be conserved near zero), and sqrt(sum(u**2)*dx) (discrete L2 norm).
Save a file named "solution_pdebench_burgers_nu0p2.npz" containing arrays x (length Nx), u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p2.png" with x on the horizontal axis and u on the vertical axis.
Use numpy for array operations and numpy.fft for FFT/IFFT throughout.
