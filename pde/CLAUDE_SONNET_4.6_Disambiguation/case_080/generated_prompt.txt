Solve the Poisson PDE u_xx + u_yy = f(x,y) numerically in Python.
The source term is f(x,y) = 100 * exp(-200 * ((x - 0.5)**2 + (y - 0.5)**2)).
The spatial domain is (x, y) in [0, 1] x [0, 1].
Apply Dirichlet boundary conditions u = 0 on all four edges of the domain.
Use a uniform grid with Nx = Ny = 120 intervals in each direction.
The grid has Nx+1 = 121 points in x and Ny+1 = 121 points in y, including boundary points.
Set dx = dy = 1/120.
Define x_i = i * dx for i = 0, 1, ..., 120 and y_j = j * dy for j = 0, 1, ..., 120.
Discretize the Laplacian using the standard 5-point stencil (second-order finite differences) on interior nodes only.
Assemble the resulting sparse linear system for the interior nodes (i = 1..119, j = 1..119).
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Construct the full solution array u of shape (121, 121) with u[j, i] = u(x_i, y_j), setting boundary values to 0 and filling interior values from the solver result.
Save the output file "solution_agent_poisson_07.npz" containing: x as a 1D array of length 121, y as a 1D array of length 121, u as a 2D array of shape (len(y), len(x)) so that u[j, i] = u(x_i, y_j), and scalar metadata dx and dy.
Save a heatmap or contour plot of u(x,y) as "solution_agent_poisson_07.png".
Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx * dy) over all grid points.
