Solve the Laplace PDE u_xx + u_yy = 0 on the domain [0,1] x [0,1].
The unknown field is u(x,y).
The exact reference solution is u(x,y) = y.
Use Nx = Ny = 100 uniform intervals in each direction.
The grid has Nx+1 = 101 points in x and Ny+1 = 101 points in y including both endpoints.
Set dx = dy = 1/100 = 0.01.
Define x_i = i * dx for i = 0, 1, ..., 100 and y_j = j * dy for j = 0, 1, ..., 100.
Apply boundary conditions derived from the exact solution u(x,y) = y on all four edges.
On the bottom edge (y=0): u(x_i, 0) = 0 for all i.
On the top edge (y=1): u(x_i, 1) = 1 for all i.
On the left edge (x=0): u(0, y_j) = y_j for all j.
On the right edge (x=1): u(1, y_j) = y_j for all j.
Discretize the Laplacian at each interior node (i,j) with i in 1..99 and j in 1..99 using the standard 5-point stencil: (u[i-1,j] - 2*u[i,j] + u[i+1,j]) / dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1]) / dy**2 = 0.
Assemble the resulting sparse linear system for all interior nodes.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Store the full solution array u with shape (101, 101) where u[j, i] = u(x_i, y_j).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx * dy) over the full grid.
Compute the reference solution u_exact[j, i] = y_j on the same grid.
Compute and print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx * dy).
