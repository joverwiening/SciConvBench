Solve the 1D advection PDE u_t + beta * u_x = 0 numerically using Python.

Use beta = 7.0 and final time T = 2.0.

The spatial domain is [0, 1) with periodic boundary conditions: u(0,t) = u(1,t) for all t.

Use Nx = 512 grid points on the half-open domain [0,1). Set dx = 1.0 / Nx. Set x_i = i * dx for i = 0, 1, ..., Nx-1.

Set the initial condition u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x).

Use 1st-order upwind finite difference for the spatial derivative u_x. Since beta = 7.0 > 0, use the left-sided (backward) difference: u_x at point i approximated as (u[i] - u[i-1]) / dx, with index i-1 taken modulo Nx to enforce periodicity.

Use explicit forward Euler time integration.

Set CFL = 0.5. Compute dt = CFL * dx / abs(beta). Compute Nt = ceil(T / dt). Reset dt = T / Nt so the final time T is hit exactly.

At each time step, update u using: u[i] = u[i] - beta * dt / dx * (u[i] - u[i-1 mod Nx]).

The reference solution is u_ref(x, T) = u0((x - beta*T) mod 1), where u0(x) = sin(2*pi*x) + 0.5*sin(4*pi*x). Evaluate u_ref on the same x grid.

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.

Compute and print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx).

Save a file named "solution_pdebench_advection_beta7.npz" containing the following arrays and scalars: x (1D, length Nx), u (1D, length Nx), beta (scalar), T (scalar), dx (scalar), dt (scalar), Nx (scalar), Nt (scalar).
