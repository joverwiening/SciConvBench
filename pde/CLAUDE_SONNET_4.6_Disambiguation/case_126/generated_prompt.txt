Solve the 1D inviscid Burgers equation numerically using the specifications below.

The PDE is u_t = -k * d/dx(0.5 * u**2) where k = 1.0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The initial condition is u(x, 0) = sin(2 * pi * x).

Use a uniform periodic grid with Nx = 1024 points on [0, 1).
Define dx = 1.0 / Nx.
Set grid points as x_j = j * dx for j = 0, 1, ..., Nx-1.

Use a conservative finite-volume spatial discretization.
Compute numerical fluxes at cell interfaces using the Rusanov (local Lax-Friedrichs) flux for f(u) = 0.5 * u**2.
The Rusanov flux at interface between cell i and cell i+1 is F_{i+1/2} = 0.5 * (f(u_i) + f(u_{i+1})) - 0.5 * alpha * (u_{i+1} - u_i), where alpha = max(|u_i|, |u_{i+1}|).
The spatial update for cell i is -( F_{i+1/2} - F_{i-1/2} ) / dx.
Apply periodic indexing so that the interface to the left of cell 0 uses cell Nx-1 as the left state.

Use SSP-RK2 (Heun's method) for time integration.
Compute dt0 = CFL * dx / max|u| where CFL = 0.2 and max|u| is estimated as 1.0 at the start.
Compute Nt = ceil(0.2 / dt0).
Set dt = 0.2 / Nt.
Use this fixed dt for all time steps.

At each SSP-RK2 step, compute the stage as follows.
Define L(u) as the spatial right-hand side operator described above.
Stage 1: u_star = u_n + dt * L(u_n).
Stage 2: u_{n+1} = 0.5 * u_n + 0.5 * (u_star + dt * L(u_star)).

Advance the solution from t = 0 to t = 0.2 using exactly Nt steps.
Store the final solution array u of length 1024 at t = 0.2.
Output the array of x values (length 1024) and the corresponding final u values (length 1024).
Use Python with NumPy for the implementation.
Use '**' for exponentiation in the Python code.
