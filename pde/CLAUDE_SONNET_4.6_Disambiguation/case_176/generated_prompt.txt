Solve the 1D Reaction-Diffusion PDE: u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
Use nu = 10.0 and rho = 1.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0/512 and x_j = j*dx for j = 0, 1, ..., 511.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.
Apply Strang splitting for each full time step dt as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute k = 2*pi*fftfreq(512, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).
Step B (reaction full-step, duration dt): for each grid point apply the exact logistic update u = (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).
Step C (diffusion half-step again): repeat Step A identically.
Repeat Steps A, B, C for all 1000 time steps.
After all steps, compute u(x, T=1.0) on the periodic grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.
Save a file named "solution_pdebench_reacdiff_nu10_rho1.npz" containing arrays x (1D, length 512) and u (1D, length 512), and scalars nu, rho, T, dx, dt, Nx, Nt.
