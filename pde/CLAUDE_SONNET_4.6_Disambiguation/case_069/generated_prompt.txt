Solve the Kuramoto–Sivashinsky PDE numerically using the exact specifications below.

The PDE is u_t + u*u_x + u_xx + u_xxxx = 0 on a periodic domain.

The spatial domain is x in [0, 2*pi), periodic, with t in [0, 1.0].

Use Nx = 1024 grid points with no duplicated endpoint; dx = 2*pi / Nx and x_i = i * dx for i = 0, 1, ..., Nx-1.

Use dt = 1e-4 and take 10000 time steps to reach T = 1.0.

Use Fourier pseudo-spectral differentiation: compute u_x, u_xx, and u_xxxx via FFT using wavenumbers k = fftfreq(Nx, d=1/Nx) (i.e., integer wavenumbers scaled for the [0, 2*pi) domain).

Use a semi-implicit time integration scheme in Fourier space.

At each time step, compute the nonlinear term N = u * u_x in physical space, then transform to Fourier space.

Update each Fourier mode as: u_hat_new[k] = (u_hat[k] - dt * fft(N)[k]) / (1 - dt * (-k**2 + k**4)).

The denominator uses the linear operator eigenvalue: -k**2 (from u_xx) + k**4 (from u_xxxx), consistent with the sign convention in the PDE where both u_xx and u_xxxx appear with positive sign on the left side.

Use the initial condition u(x, 0) = cos(x) * (1 + sin(x)) (a standard KS initial condition; if the prompt does not specify one, use this).

After 10000 steps, compute u(x, T=1.0) by taking the real part of the inverse FFT of the final u_hat array.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.

Save a file named "solution_agent_other_04_kuramoto_sivashinsky.npz" containing: array x (1D, length 1024), array u (1D, length 1024), scalar T = 1.0, scalar dx = 2*pi/1024, scalar dt = 1e-4.

Here is the complete Python code:

```python
import numpy as np
import matplotlib.pyplot as plt

# Grid
Nx = 1024
L = 2 * np.pi
dx = L / Nx
x = np.arange(Nx) * dx

# Wavenumbers for [0, 2*pi) domain
k = np.fft.fftfreq(Nx, d=1.0/Nx)  # integer wavenumbers: 0,1,...,Nx/2-1,-Nx/2,...,-1

# Time parameters
dt = 1e-4
Nt = 10000
T = 1.0

# Initial condition
u = np.cos(x)

# Precompute denominator for semi-implicit scheme (does not change with time)
# Linear operator eigenvalue: -k^2 + k^4
linear_eigenvalue = -k**2 + k**4
denom = 1.0 - dt * linear_eigenvalue

# Time integration
u_hat = np.fft.fft(u)

for n in range(Nt):
    # Compute u in physical space
    u_phys = np.real(np.fft.ifft(u_hat))
    
    # Compute u_x in physical space via spectral differentiation
    u_x_hat = 1j * k * u_hat
    u_x_phys = np.real(np.fft.ifft(u_x_hat))
    
    # Nonlinear term in physical space
    N_phys = u_phys * u_x_phys
    
    # Transform nonlinear term to Fourier space
    N_hat = np.fft.fft(N_phys)
    
    # Semi-implicit update
    u_hat = (u_hat - dt * N_hat) / denom

# Final solution in physical space
u_final = np.real(np.fft.ifft(u_hat))

# Diagnostics
u_min = np.min(u_final)
u_max = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)

print(f"min(u)    = {u_min:.6f}")
print(f"max(u)    = {u_max:.6f}")
print(f"L2 norm   = {l2_norm:.6f}")

# Save npz
np.savez(
    "solution_agent_other_04_kuramoto_sivashinsky.npz",
    x=x,
    u=u_final,
    T=T,
    dx=dx,
    dt=dt
)

# Save plot
fig, ax = plt.subplots(figsize=(10, 4))
ax.plot(x, u_final, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=1.0)")
ax.set_title("Kuramoto-Sivashinsky solution at T=1.0")
ax.set_xlim(0, 2 * np.pi)
plt.tight_layout()
plt.savefig("solution_agent_other_04_kuramoto_sivashinsky.png", dpi=150)
plt.close()

print("Files saved: solution_agent_other_04_kuramoto_sivashinsky.npz and .png")
```
