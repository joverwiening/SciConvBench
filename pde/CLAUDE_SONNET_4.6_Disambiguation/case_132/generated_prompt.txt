Final Specification:

Solve the following 1D nonlinear convection-diffusion PDE numerically.

PDE: u_t = -q1 * d/dx( cos(u) ) + (q2/pi) * u_xx

Spatial domain: x in [0, 1), periodic, with Nx = 1024 uniform grid points.
Set dx = 1/Nx and x_j = j * dx for j = 0, 1, ..., Nx-1. No duplicated endpoint.

Temporal domain: t in [0, 0.5].

Parameters: q1 = 1.0, q2 = 0.05.

Initial condition: u(x, 0) = 0.5 * sin(2 * pi * x).

Boundary conditions: Periodic. Implement periodicity via index wrapping (mod Nx) when accessing neighbors.

Spatial discretization of the convection term: Use a conservative finite-volume Rusanov flux for d/dx( cos(u) ).
Define the flux function f(u) = cos(u).
At each cell interface between cell j and cell j+1, compute the Rusanov flux as:
F_{j+1/2} = 0.5 * ( f(u_j) + f(u_{j+1}) ) - 0.5 * alpha_{j+1/2} * ( u_{j+1} - u_j )
where alpha_{j+1/2} = max( |sin(u_j)|, |sin(u_{j+1})| ), since |f'(u)| = |sin(u)|.
The convection contribution to the RHS at cell j is: -q1 * ( F_{j+1/2} - F_{j-1/2} ) / dx.
Use periodic index wrapping: index j+1 is taken as (j+1) mod Nx, and j-1 as (j-1) mod Nx.

Spatial discretization of the diffusion term: Use standard 2nd-order central differences.
u_xx at cell j = ( u_{j+1} - 2*u_j + u_{j-1} ) / dx**2, with periodic index wrapping.
The diffusion contribution to the RHS at cell j is: (q2/pi) * u_xx_j.

Full RHS: L(u)_j = -q1 * ( F_{j+1/2} - F_{j-1/2} ) / dx + (q2/pi) * ( u_{j+1} - 2*u_j + u_{j-1} ) / dx**2.

Time step selection:
Compute dt_adv = 0.2 * dx / 1.0 (using max|sin(u)| <= 1 and CFL = 0.2).
Compute dt_diff = 0.2 * dx**2 / (q2 / pi).
Set dt_candidate = min(dt_adv, dt_diff).
Set Nt = ceil(0.5 / dt_candidate).
Set dt = 0.5 / Nt.

Time integration: Use SSP-RK2 (Shu-Osher 2-stage scheme).
Stage 1: u_star = u_n + dt * L(u_n).
Stage 2: u_{n+1} = 0.5 * u_n + 0.5 * ( u_star + dt * L(u_star) ).
Apply periodic boundary conditions implicitly through index wrapping at each stage.

Advance from t = 0 to t = 0.5 using exactly Nt steps of size dt.

Output: After completing all Nt time steps, print or return the array u at t = 0.5.
Also print the following diagnostics at the final time: min(u), max(u), and the L2 norm defined as sqrt( dx * sum( u**2 ) ).

Use Python with NumPy. Use ** for exponentiation throughout the code.
All trigonometric functions use radians.
No closed-form reference solution is required.
