Solve the 1D Compressible Navier-Stokes equations (no heat conduction) numerically using the specifications below.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use Python with NumPy for the implementation.

The PDE is in conservative form with m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x, where zeta = eta.
The three conservation equations are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use Nx = 800 cells with a cell-centered finite volume layout.
The cell width is dx = (1 - (-1)) / 800 = 2.0 / 800.
Cell centers are located at x_i = -1 + (i + 0.5)*dx for i = 0, 1, ..., 799.

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Apply transmissive (zero-gradient, outflow) boundary conditions at both x = -1 and x = 1.
Implement outflow BCs by copying the nearest interior cell state into ghost cells at each boundary.

Set the initial condition as a Riemann (shock-tube) problem with a discontinuity at x = 0.
For cell centers with x < 0: rho = 0.445, v = 0.698, p = 3.528.
For cell centers with x >= 0: rho = 0.5, v = 0.0, p = 0.571.

Use a finite volume method with a Godunov-type approach for the inviscid fluxes.
Use the HLLC or HLL Riemann solver for the inviscid flux computation at cell interfaces.
Compute the viscous stress sigma at each interface using a centered finite difference of v across the interface: sigma_{i+1/2} = (zeta + 4/3*eta) * (v_{i+1} - v_i) / dx.
Add the viscous flux contribution to the momentum and energy fluxes at each interface.

Use a CFL-based adaptive time step.
Set CFL = 0.5.
At each time step compute dt = CFL * dx / max(|v_i| + c_i) over all cells, where c_i = sqrt(Gamma * p_i / rho_i) is the local sound speed.
Clip dt so the simulation does not overshoot T = 0.2.

Advance the solution in time using a first-order or second-order (e.g., Runge-Kutta) time integration method.
Enforce positivity of rho and p after each stage; if any value goes non-positive, raise an error or clamp with a warning.

At the final time T = 0.2, extract rho, v, p at the 800 cell centers.
