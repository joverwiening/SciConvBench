Solve the Klein-Gordon PDE numerically using the exact specifications below.

PDE: u_tt - (0.5)**2 * u_xx + (2.0)**2 * u = 0

Spatial domain: x in [0, 1], closed interval.
Time domain: t in [0, 1.0].

Use Nx = 600 uniform intervals, giving Nx+1 = 601 grid points including both endpoints.
Set dx = 1.0 / 600.
Set x_i = i * dx for i = 0, 1, ..., 600.

Set c = 0.5 (wave speed coefficient in front of u_xx).
Set m = 2.0 (mass term coefficient in front of u).
Set dt0 = 0.9 * dx / c.
Set Nt = ceil(1.0 / dt0).
Set dt = 1.0 / Nt so the final time T = 1.0 is hit exactly.

Boundary conditions: Dirichlet, u = 0 at x = 0 and x = 1 for all time.

Initial condition: u(x, 0) = sin(2 * pi * x) for all interior and boundary points.
Initial velocity: u_t(x, 0) = 0.

Spatial discretization: use 2nd-order central differences for u_xx, so u_xx at point i is (u[i-1] - 2*u[i] + u[i+1]) / dx**2.

Time integration: use leapfrog (2nd-order central difference in time).
The update formula at interior points is: u_new[i] = 2*u[i] - u_old[i] + dt**2 * (c**2 * (u[i-1] - 2*u[i] + u[i+1]) / dx**2 - m**2 * u[i]).
Handle the m**2 * u term explicitly at time level n (current time step) in the update.

Initialization (Taylor start for the first step):
u_new[i] = u[i] + dt * v0[i] + 0.5 * dt**2 * (c**2 * (u[i-1] - 2*u[i] + u[i+1]) / dx**2 - m**2 * u[i])
where v0[i] = u_t(x_i, 0) = 0, so the v0 term vanishes.
Apply Dirichlet boundary conditions at every time step: u_new[0] = 0, u_new[600] = 0.

Exact reference solution: u_exact(x, t) = cos(sqrt((0.5 * 2 * pi)**2 + (2.0)**2) * t) * sin(2 * pi * x).
Evaluate u_exact on the same x grid at T = 1.0.

After time-stepping to T = 1.0, compute and print the following:
Print min(u) over all grid points.
Print max(u) over all grid points.
Print the discrete L2 norm: sqrt(sum(u**2) * dx).
Print the max absolute error: max(abs(u - u_exact)).
Print the L2 error: sqrt(sum((u - u_exact)**2) * dx).
