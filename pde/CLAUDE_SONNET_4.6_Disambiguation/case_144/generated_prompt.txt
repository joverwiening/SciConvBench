Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx numerically in Python.
The spatial domain is [0,1) with periodic boundary conditions.
The unknown field is u(x,t).
The parameter nu = 0.02.
The final time is T = 1.0.
The initial condition is u(x,0) = sin(2*pi*x).

Use a uniform periodic grid with Nx = 512 points.
Set dx = 1.0/512 and x_i = i*dx for i = 0, 1, ..., 511.

Compute dt0 = 0.4*dx/1.0 (CFL=0.4, estimated max speed = 1).
Compute Nt = ceil(T/dt0) and reset dt = T/Nt so the final time T=1.0 is hit exactly.

Advance the solution using Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2):
Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu*k**2*(dt/2)).
Set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt) using finite-volume Rusanov flux:
Define f(u) = 0.5*u**2.
For each interface between cell j (u_left = u[j]) and cell j+1 (u_right = u[j+1], with periodic indexing):
  alpha = max(abs(u_left), abs(u_right))
  F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left)
For each cell j:
  F_plus  = flux at interface between u[j] and u[(j+1) % Nx]
  F_minus = flux at interface between u[(j-1) % Nx] and u[j]
  u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus)
Replace u with u_new after the advection substep.

Step C (diffusion half-step again, identical to Step A).

After all Nt time steps, compute and print min(u), max(u), mean(u) (discrete mean, should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx).

Save a file named "solution_pdebench_burgers_nu0p02.npz" containing the following arrays and scalars: x (1D, length Nx), u (1D, length Nx), nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p02.png".
