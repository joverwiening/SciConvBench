Solve the 1D linear advection PDE u_t + q*u_x = 0 numerically using Python.

The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The advection speed parameter is q = 1.5.

The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The exact solution is u(x,t) = u0((x - q*t) mod 1), where u0 is the initial condition function.

Wavenumbers are defined as k = [0, 1, ..., Nx/2-1, -Nx/2, ..., -1] using numpy.fft.fftfreq(Nx, d=dx) multiplied by 2*pi, or equivalently use numpy.fft.fftfreq(Nx)*Nx as integer wavenumbers and multiply phase by 2*pi/Nx*q*T*k_int.
