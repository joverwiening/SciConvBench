Solve the 2D Darcy flow PDE numerically according to the following specification.

The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (x,y) in (0,1) x (0,1).
The diffusion coefficient is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) with beta = 10.0.
Apply Dirichlet boundary conditions u = 0 on the entire boundary of (0,1) x (0,1).

Use a uniform Cartesian grid with N = 128 intervals in each direction, giving N+1 = 129 grid points per direction including both endpoints.
Set dx = dy = 1/N.
Define grid points as x_i = i*dx for i = 0, 1, ..., N and y_j = j*dy for j = 0, 1, ..., N.

Discretize the PDE using 2nd-order finite differences with face-centered harmonic averaging of the variable coefficient.
For each interior node (i=1..N-1, j=1..N-1), apply the stencil:
-(1/dx**2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1
Compute face coefficients using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)), and analogously for all other faces.

Assemble the sparse linear system A*u_interior = b for the (N-1)*(N-1) interior unknowns, where b is a vector of ones.
Solve the linear system using the Conjugate Gradient (CG) method with a relative residual tolerance of 1e-10.
Optionally use a Jacobi preconditioner to accelerate convergence.

After solving, construct the full (N+1) x (N+1) solution array u on the complete grid, setting boundary values to zero and filling interior values from the CG solution.

Print the following scalar diagnostics: min(u), max(u), and the discrete residual norm ||A*u_interior - b||_2 / ||b||_2.

Save a file named "solution_pdebench_darcy_beta10.npz" containing: the 1D array x of length N+1, the 1D array y of length N+1, the 2D array u of shape [N+1, N+1], and the scalars beta, N, and dx.
Save a heatmap or filled-contour plot of u(x,y) as "solution_pdebench_darcy_beta10.png".

Use radians for all trigonometric function evaluations.
Interpret '^' as exponentiation and use '**' for powers in Python code.
