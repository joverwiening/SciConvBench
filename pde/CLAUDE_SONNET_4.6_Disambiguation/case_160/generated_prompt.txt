Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the full specification below.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use Python with NumPy for the implementation.

Use '^' as exponentiation in math and '**' in Python code.

PDE in conservative form:
Define m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Assume zeta = eta.
The three conservation laws are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

Domain: x in [-1, 1], t in [0, 0.2].

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Boundary conditions: transmissive/outflow (zero-gradient) at both x=-1 and x=1.

Initial condition: Riemann (shock-tube) with discontinuity at x=0.
For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 1.0.
For x >= 0: rho_R = 0.125, v_R = 0.0, p_R = 0.1.

Grid: uniform finite-volume grid with Nx = 800 cells on [-1, 1].
dx = 2.0 / 800.
Cell centers x_j = -1 + (j + 0.5)*dx for j = 0, ..., 799.

Evolve conservative variables U = [rho, m, E] as cell averages.

Equation of state: p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

Convective flux (Rusanov / local Lax-Friedrichs):
F_conv(U) = [m, m**2/rho + p, (E+p)*v] where v = m/rho.
Interface wave speed: a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma*p/rho).
Numerical convective flux: F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Viscous terms:
Compute v_x at each cell center using centered differences on the cell-centered v values.
Compute sigma at each cell center as (zeta + 4/3*eta) * v_x.
Approximate sigma at each interface by averaging the two neighboring cell-centered sigma values.
Approximate v at each interface by averaging the two neighboring cell-centered v values.
Viscous flux contribution at each interface: F_visc = [0, -sigma_interface, -v_interface * sigma_interface].
Total interface flux: F_total = F_hat + F_visc.

Ghost cells for boundary conditions:
For outflow, set the left ghost cell equal to cell 0 and the right ghost cell equal to cell Nx-1 (zero-gradient).

Time integration: 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.

Time step selection at each step:
CFL = 0.5 (use this value).
dt_conv = CFL * dx / max_j(|v_j| + c_j).
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30).
dt = min(dt_conv, dt_visc).
Adjust the final step so the simulation ends exactly at T = 0.2.

Output:

Save a 3-panel line plot of rho, v, p versus x at time T as "solution_pdebench_cns1d_sod1_eta1em8_outflow.png".
