Solve the Laplace PDE u_xx + u_yy = 0 on the domain [0,1] x [0,1].
The unknown field is u(x,y).
The exact reference solution is u(x,y) = sin(pi*x)*sinh(pi*y)/sinh(pi).
Use Nx=Ny=100 uniform intervals in each direction, giving 101x101 grid points including boundaries.
Set dx = dy = 1/100.
Define x_i = i*dx for i=0..100 and y_j = j*dy for j=0..100.
Apply boundary conditions derived from the exact solution on all four edges: u(x,0)=0, u(x,1)=sin(pi*x), u(0,y)=0, u(1,y)=0.
Discretize the Laplacian using the standard 5-point finite difference stencil at all interior nodes: (u[i-1,j] - 2*u[i,j] + u[i+1,j])/dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1])/dy**2 = 0.
Assemble the resulting sparse linear system for all interior nodes (99x99 = 9801 unknowns).
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Construct the full solution array u with shape (101, 101) where u[j,i] = u(x_i, y_j), filling interior values from the solver and boundary values from the boundary conditions.
Save a file named "solution_agent_laplace_07.npz" containing: x as a 1D array of length 101, y as a 1D array of length 101, u as a 2D array of shape (101,101) with u[j,i]=u(x_i,y_j), and scalar metadata dx and dy.
Save a heatmap or filled-contour plot of u(x,y) as "solution_agent_laplace_07.png".
Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy) over the full grid.
Evaluate the exact solution u_exact[j,i] = sin(pi*x_i)*sinh(pi*y_j)/sinh(pi) on the same 101x101 grid.
Compute and print the max absolute error: max(|u - u_exact|) over all grid points.
Compute and print the discrete L2 error: sqrt(sum((u - u_exact)**2)*dx*dy) over the full grid.
Use Python with numpy and scipy. Interpret '^' as exponentiation and use '**' for powers in code.
