Solve the PDE u_t + 2.0*u_x = 0 numerically using the specifications below.

The spatial domain is [0,1) with periodicity, using Nx=2000 uniform grid points.
Set dx = 1.0/Nx and x_i = i*dx for i=0..Nx-1.
The time domain is t in [0, 0.3].
The advection speed is a = 2.0.

Set dt0 = 0.9*dx/abs(a).
Set Nt = ceil(0.3/dt0) using math.ceil.
Set dt = 0.3/Nt so the final time T=0.3 is hit exactly.

Initialize u(x,0) = 1 if 0.2 <= x < 0.4, else 0.

Use 1st-order upwind spatial discretization for u_x.
Since a = 2.0 > 0, the upwind approximation is u_x at index i = (u[i] - u[i-1])/dx.
Use periodic indexing so that index -1 wraps to index Nx-1.

Advance in time using Forward Euler: u[i] at next step = u[i] - a*(dt/dx)*(u[i] - u[i-1]).

After Nt steps, the solution u(x, T=0.3) is on the grid x.

Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx).

Save a file named "solution_agent_advection_06.npz" containing arrays x (1D, length Nx), u (1D, length Nx), and scalar metadata T=0.3, dx, dt.

Save a line plot of u versus x at T=0.3 as "solution_agent_advection_06.png" with x on the horizontal axis and u on the vertical axis.
