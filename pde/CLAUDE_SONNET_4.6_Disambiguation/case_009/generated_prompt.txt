Solve the Allen-Cahn PDE numerically using the specifications below.

The PDE is u_t = (0.02)^2 * u_xx + u - u**3.
The spatial domain is x in [0,1] (closed interval) and the time domain is t in [0,1.0].
The parameter epsilon is 0.02.
The initial condition is u(x,0) = 0.05*sin(2*pi*x) + 0.02*sin(6*pi*x).

Use a uniform grid with Nx=800 intervals, giving 801 grid points including both endpoints.
Set dx = 1.0/800 and x_i = i*dx for i=0,1,...,800.
Use dt=0.0005 and take 2000 time steps to reach T=1.0.

Discretize u_xx with 2nd-order central differences.
Apply zero Neumann boundary conditions via ghost points: the ghost point to the left of x=0 mirrors x_1, and the ghost point to the right of x=1 mirrors x_{Nx-1}.
This means u_xx at i=0 uses 2*(u[1]-u[0])/dx**2 and u_xx at i=Nx uses 2*(u[Nx-1]-u[Nx])/dx**2.

Use a semi-implicit time integration scheme: (u^{n+1} - u^n)/dt = epsilon**2 * u_xx^{n+1} + u^n - (u^n)**3.
Rearrange to: u^{n+1} - dt*epsilon**2 * u_xx^{n+1} = u^n + dt*(u^n - (u^n)**3).
Assemble a tridiagonal linear system for u^{n+1} at each time step and solve it.
The diagonal of the matrix is 1 + 2*dt*epsilon**2/dx**2 for interior points, modified at boundaries.
The off-diagonals are -dt*epsilon**2/dx**2.
At boundary index i=0, the row reflects the ghost-point Neumann condition, giving diagonal 1 + 2*dt*epsilon**2/dx**2 and one off-diagonal -2*dt*epsilon**2/dx**2 (since both neighbors contribute equally).
At boundary index i=Nx, apply the same symmetric treatment.
The right-hand side at each interior point is u^n[i] + dt*(u^n[i] - u^n[i]**3).

Solve the tridiagonal system using scipy.linalg.solve_banded or numpy.linalg.solve or scipy.sparse.linalg.spsolve at each of the 2000 steps.

After completing all time steps, compute u(x, T=1.0) on the 801-point grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.
Save a file named "solution_agent_allen_cahn_03.npz" containing the 1D array x of length 801, the 1D array u of length 801, and scalar metadata T=1.0, dx=1.0/800, dt=0.0005.
Save a line plot of u(x,T) as "solution_agent_allen_cahn_03.png" with x on the horizontal axis and u on the vertical axis.
