Solve the 1D advection-diffusion PDE numerically using Python as described below.

The PDE is u_t = D*u_xx - (1/gamma)*d_x(U'(x)*u), where U(x) = cos(2*pi*x) and U'(x) = -2*pi*sin(2*pi*x).
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
Use D = 0.01 and gamma = 1.0.
The initial condition is u(x,0) = 1.0 + 0.2*sin(2*pi*x).

Set up a uniform periodic grid with Nx = 512 points on [0,1).
Compute dx = 1.0/Nx.
Set grid points x_j = j*dx for j = 0, 1, ..., Nx-1.

Define the drift velocity at each grid point as b_j = U'(x_j)/gamma = -2*pi*sin(2*pi*x_j)/gamma.
Compute the maximum absolute drift speed as max_b = max(|b_j|) over all j.
Compute the advective time step limit as dt_adv = 0.4*dx/max_b.
Compute the diffusive time step limit as dt_diff = 0.2*dx**2/D.
Set dt_trial = min(dt_adv, dt_diff).
Compute Nt = ceil(T/dt_trial) where T = 1.0.
Set dt = T/Nt.

Discretize the diffusion term u_xx using 2nd-order central differences with periodic indexing: u_xx at j = (u[j+1] - 2*u[j] + u[j-1])/dx**2, where indices are taken modulo Nx.

Discretize the drift term in conservative form as -d_x(F) where F_j = b_j * u_j.
Compute the upwind flux at each cell interface between j and j+1 as follows.
Evaluate the interface velocity as b_half = 0.5*(b_j + b_{j+1}) using periodic indexing.
If b_half >= 0, set the interface flux to b_j * u_j.
If b_half < 0, set the interface flux to b_{j+1} * u_{j+1}.
Compute the divergence of the flux at cell j as (flux_{j+1/2} - flux_{j-1/2})/dx using periodic indexing.
The spatial right-hand side at j is D*u_xx_j - (flux_{j+1/2} - flux_{j-1/2})/dx.

Integrate in time using explicit SSP-RK2 (Heun's method).
For each time step from n=0 to Nt-1:
Compute k1 = L(u^n) where L is the spatial right-hand side operator.
Compute u_star = u^n + dt*k1.
Compute k2 = L(u_star).
Set u^{n+1} = 0.5*u^n + 0.5*(u_star + dt*k2).

After completing all Nt time steps, output the final solution array u at t = 1.0.
Print or return the array of x values and the corresponding u values.
Also print the minimum and maximum values of u at t=1.0 and the numerical integral of u over [0,1) approximated as dx*sum(u), which should remain close to 1.0 (the initial mass).
