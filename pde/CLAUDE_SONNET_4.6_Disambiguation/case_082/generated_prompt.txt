Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically using the specifications below.

The PDE is u_tt = c^2 * u_xx with c = 1.0.
The spatial domain is x in [0, 1] (closed interval).
The time domain is t in [0, 1.0].
The boundary conditions are Dirichlet: u(0, t) = 0 and u(1, t) = 0 for all t.
The initial condition for displacement is u(x, 0) = sin(pi * x).
The initial condition for velocity is u_t(x, 0) = 0 (derived from the exact solution u(x,t) = cos(1.0*pi*t)*sin(pi*x), so v0(x) = 0).
The exact solution for verification is u(x, t) = cos(pi * t) * sin(pi * x).

Use a uniform spatial grid with Nx = 400 intervals, giving Nx + 1 = 401 grid points including both endpoints.
Set dx = 1.0 / Nx = 1.0 / 400.
Set dt0 = 0.9 * dx / c.
Set Nt = ceil(T / dt0) where T = 1.0.
Set dt = T / Nt so the simulation hits T = 1.0 exactly.

Use 2nd-order central differences for u_xx in the interior: u_xx at node i = (u[i-1] - 2*u[i] + u[i+1]) / dx**2.
Use the leapfrog (Stormer-Verlet) scheme for time integration: u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + dt**2 * c**2 * u_xx^n[i].
Initialize u^0[i] = sin(pi * x[i]) for all interior and boundary nodes.
Compute u^1 using the Taylor start: u^1[i] = u^0[i] + dt * v0(x[i]) + 0.5 * dt**2 * c**2 * u_xx^0[i], where v0(x) = 0.
At every time step, enforce Dirichlet boundary conditions by setting u[0] = 0 and u[Nx] = 0.

After completing all Nt time steps, evaluate u(x, T) on the full grid of 401 points.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.
Compute the reference solution u_exact[i] = cos(pi * T) * sin(pi * x[i]) on the same grid.
Compute and print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
Save a file named solution_agent_wave_01.npz containing arrays x (1D, length 401), u (1D, length 401), and scalar metadata T, dx, dt.
Save a line plot of u(x, T) versus x as solution_agent_wave_01.png with labeled axes.

Use Python with numpy for computation and matplotlib for plotting.
Interpret ^ as exponentiation and use ** in Python code for powers.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
c = 1.0
T = 1.0
Nx = 400
dx = 1.0 / Nx

# Time step
dt0 = 0.9 * dx / c
Nt = math.ceil(T / dt0)
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6f}, Nt={Nt}, dt={dt:.6f}, CFL={c*dt/dx:.6f}")

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 401 points

# Initial conditions
u0 = np.sin(np.pi * x)              # u(x, 0)
v0 = np.zeros(Nx + 1)               # u_t(x, 0) = 0

# Function to compute u_xx (interior only, central differences)
def compute_uxx(u, dx):
    uxx = np.zeros_like(u)
    uxx[1:-1] = (u[:-2] - 2.0 * u[1:-1] + u[2:]) / dx**2
    return uxx

# Initialize u^0
u_prev = u0.copy()

# Compute u^1 using Taylor start
uxx0 = compute_uxx(u_prev, dx)
u_curr = u_prev + dt * v0 + 0.5 * dt**2 * c**2 * uxx0
# Enforce BCs at t = dt
u_curr[0] = 0.0
u_curr[-1] = 0.0

# Time-stepping loop (leapfrog)
for n in range(1, Nt):
    uxx_curr = compute_uxx(u_curr, dx)
    u_next = 2.0 * u_curr - u_prev + dt**2 * c**2 * uxx_curr
    # Enforce BCs
    u_next[0] = 0.0
    u_next[-1] = 0.0
    # Advance
    u_prev = u_curr
    u_curr = u_next

# Final solution at T
u_final = u_curr

# Exact solution at T
u_exact = np.cos(np.pi * T) * np.sin(np.pi * x)

# Diagnostics
min_u = np.min(u_final)
max_u = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)
max_abs_err = np.max(np.abs(u_final - u_exact))
l2_err = np.sqrt(np.sum((u_final - u_exact)**2) * dx)

print(f"min(u)       = {min_u:.6e}")
print(f"max(u)       = {max_u:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_abs_err:.6e}")
print(f"L2 error     = {l2_err:.6e}")

# Save .npz
np.savez("solution_agent_wave_01.npz",
         x=x,
         u=u_final,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))
print("Saved solution_agent_wave_01.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_final, label=f"Numerical u(x, T={T})", linewidth=2)
ax.plot(x, u_exact, '--', label="Exact solution", linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Wave equation solution at T={T}")
ax.legend()
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_wave_01.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_01.png")
```
