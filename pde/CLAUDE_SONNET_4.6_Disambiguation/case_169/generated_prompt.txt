Solve the 2D Darcy flow PDE numerically as described below.

The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (x,y) in (0,1) x (0,1).
The coefficient function is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) with beta = 1.0.
Apply Dirichlet boundary conditions u = 0 on the entire boundary of (0,1) x (0,1).

Use a uniform Cartesian grid with N = 128 intervals in each direction, giving N+1 = 129 grid points per direction including both endpoints.
Set dx = dy = 1/N.
Set x_i = i*dx for i = 0, ..., N and y_j = j*dy for j = 0, ..., N.

Discretize the PDE using 2nd-order finite differences with variable coefficients and face-centered harmonic averaging.
For interior nodes (i = 1..N-1, j = 1..N-1), apply:
-(1/dx**2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1
Compute face coefficients using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)), and analogously for all other faces.

Assemble the sparse linear system Au = b for the interior unknowns only (the (N-1)*(N-1) interior nodes).
The right-hand side vector b has all entries equal to 1.
Solve the linear system using the Conjugate Gradient (CG) method to a relative residual tolerance of 1e-10.
Optionally use a Jacobi preconditioner to accelerate convergence.

After solving, construct the full (N+1) x (N+1) solution grid by placing the interior solution into the interior nodes and setting boundary values to 0.

Compute and print min(u) over the full grid.
Compute and print max(u) over the full grid.
Compute and print the discrete residual norm ||Au - b||_2 / ||b||_2 for the interior system.

Save a file named "solution_pdebench_darcy_beta1.npz" containing: x as a 1D array of length N+1, y as a 1D array of length N+1, u as a 2D array of shape [N+1, N+1], and the scalars beta = 1.0, N = 128, dx = 1/128.
Save a heatmap or contour plot of u(x,y) as a PNG file named "solution_pdebench_darcy_beta1.png".
