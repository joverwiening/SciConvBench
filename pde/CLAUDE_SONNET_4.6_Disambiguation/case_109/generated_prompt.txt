Compute the full state vector at all time points t_n = 0.0 + n*0.01 for n = 0 to 3000 inclusive, giving Nt+1 = 3001 time points.

In Python, use ** for exponentiation wherever powers appear.

Save a file named solution_molk_008.npz containing: a 1D array t of length 3001, a 2D array Y of shape [3001, 2] with columns ordered as [x, y], and the scalar parameters alpha, beta, gamma, delta.

Save a plot of x vs t and y vs t as line plots in a single figure saved as solution_molk_008.png, with axes labeled and a legend identifying each state.
