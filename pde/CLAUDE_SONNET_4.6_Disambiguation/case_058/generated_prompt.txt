Solve the Laplace PDE u_xx + u_yy = 0 on the domain [0,1] x [0,1].
The unknown field is u(x,y).
The exact reference solution is u(x,y) = sinh(pi*x)*sin(pi*y)/sinh(pi).
Use Nx = Ny = 100 uniform intervals in each direction, giving 101 x 101 grid points including boundaries.
Set dx = dy = 1/100.
Define x_i = i*dx for i = 0..100 and y_j = j*dy for j = 0..100.
Apply boundary conditions derived from the exact solution on all four edges: u(0,y)=0, u(1,y)=sinh(pi)*sin(pi*y)/sinh(pi)=sin(pi*y), u(x,0)=0, u(x,1)=sinh(pi*x)*sin(pi*1)/sinh(pi)=0 (since sin(pi)=0).
Discretize the Laplacian using the standard 5-point stencil on interior nodes: (u[i-1,j] - 2*u[i,j] + u[i+1,j])/dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1])/dy**2 = 0.
Assemble the resulting sparse linear system for all interior nodes (99x99 = 9801 unknowns).
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Construct the full solution array u with shape (101, 101) where u[j,i] = u(x_i, y_j), filling boundary rows/columns from the boundary conditions and interior from the solver result.
Save a file named "solution_agent_laplace_02.npz" containing: x as a 1D array of length 101, y as a 1D array of length 101, u as a 2D array of shape (101, 101) with u[j,i] = u(x_i, y_j), and scalar metadata dx and dy.
Save a heatmap or filled-contour plot of u(x,y) as "solution_agent_laplace_02.png".
Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy) over all grid points.
Evaluate the exact solution u_exact[j,i] = sinh(pi*x_i)*sin(pi*y_j)/sinh(pi) on the same 101x101 grid.
Compute and print the max absolute error: max(|u - u_exact|) over all grid points.
Compute and print the discrete L2 error: sqrt(sum((u - u_exact)**2)*dx*dy) over all grid points.
Use radians for all trigonometric and hyperbolic function evaluations.
