Solve the heat equation u_t = 0.5 * u_xx numerically using the Crank-Nicolson method and save the results.

The PDE is u_t = 0.5 * u_xx with alpha = 0.5.
The spatial domain is x in [0, 1] (closed interval) and the time domain is t in [0, 0.2].
Use Nx = 200 uniform intervals, giving 201 grid points including both endpoints x=0 and x=1.
Set dx = 1/200 = 0.005.
Use dt = 0.0005 and take 400 time steps to reach T = 0.2.
The initial condition is u(x, 0) = sin(2*pi*x), derived from the exact solution at t=0.
The boundary conditions are Dirichlet: u(0, t) = 0 and u(1, t) = 0 for all t.
Discretize u_xx using 2nd-order central differences at interior points only.
Apply the Crank-Nicolson scheme: form the tridiagonal system (I - 0.5*dt*alpha*D2) * u_new = (I + 0.5*dt*alpha*D2) * u_old at each time step, where D2 is the second-difference matrix for interior points.
Fix boundary nodes u[0] = 0 and u[Nx] = 0 at every time step by not including them in the linear system.
After 400 time steps, compute u(x, T=0.2) on all 201 grid points.
The exact solution is u_exact(x, t) = exp(-0.5*(2*pi)**2*t) * sin(2*pi*x).
Evaluate u_exact on the same 201-point x grid at T=0.2.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) of the numerical solution at T.
Compute and print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2)*dx).
Save a file named "solution_agent_heat_02.npz" containing the 1D array x (201 points), the 1D array u (201 points), and scalar metadata T=0.2, dx=0.005, dt=0.0005.
Save a line plot of u(x, T) versus x as "solution_agent_heat_02.png" with labeled axes.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import solve_banded

# ── parameters ────────────────────────────────────────────────────────────────
alpha = 0.5
Nx    = 200
dx    = 1.0 / Nx
dt    = 0.0005
Nt    = 400          # 400 * 0.0005 = 0.2
T     = Nt * dt

# ── grid ──────────────────────────────────────────────────────────────────────
x = np.linspace(0.0, 1.0, Nx + 1)   # 201 points

# ── initial condition ─────────────────────────────────────────────────────────
u = np.sin(2.0 * np.pi * x)          # exact solution at t=0

# ── Crank–Nicolson tridiagonal system for interior nodes ──────────────────────
# Interior indices: 1 .. Nx-1  →  N_int = Nx-1 = 199 unknowns
N_int = Nx - 1
r     = alpha * dt / (2.0 * dx**2)   # r = 0.5*0.0005/(2*0.000025) = 2.5

# LHS band matrix  (I - r*D2)  stored in banded form for solve_banded
# ab[0] = super-diagonal, ab[1] = main diagonal, ab[2] = sub-diagonal
ab = np.zeros((3, N_int))
ab[0, 1:]  = -r          # super-diagonal (ab[0,0] unused)
ab[1, :]   = 1.0 + 2.0*r # main diagonal
ab[2, :-1] = -r          # sub-diagonal  (ab[2,-1] unused)

# ── time integration ──────────────────────────────────────────────────────────
for _ in range(Nt):
    u_int = u[1:Nx]      # interior values at current step

    # RHS: (I + r*D2) * u_int  +  boundary contributions (both BCs = 0 here)
    rhs = np.empty(N_int)
    rhs[0]    = r*u[0]        + (1.0 - 2.0*r)*u_int[0]    + r*u_int[1]
    rhs[-1]   = r*u_int[-2]   + (1.0 - 2.0*r)*u_int[-1]   + r*u[Nx]
    rhs[1:-1] = r*u_int[:-2]  + (1.0 - 2.0*r)*u_int[1:-1] + r*u_int[2:]

    # Solve banded system
    u_new_int = solve_banded((1, 1), ab, rhs)

    # Update solution; boundaries stay 0
    u[1:Nx] = u_new_int
    u[0]    = 0.0
    u[Nx]   = 0.0

# ── exact solution at T ───────────────────────────────────────────────────────
u_exact = np.exp(-0.5 * (2.0 * np.pi)**2 * T) * np.sin(2.0 * np.pi * x)

# ── diagnostics ───────────────────────────────────────────────────────────────
min_u   = np.min(u)
max_u   = np.max(u)
l2_u    = np.sqrt(np.sum(u**2) * dx)
max_err = np.max(np.abs(u - u_exact))
l2_err  = np.sqrt(np.sum((u - u_exact)**2) * dx)

print(f"min(u)          = {min_u:.6e}")
print(f"max(u)          = {max_u:.6e}")
print(f"L2 norm of u    = {l2_u:.6e}")
print(f"Max abs error   = {max_err:.6e}")
print(f"L2 error        = {l2_err:.6e}")

# ── save .npz ─────────────────────────────────────────────────────────────────
np.savez("solution_agent_heat_02.npz",
         x=x, u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))
print("Saved solution_agent_heat_02.npz")

# ── save plot ─────────────────────────────────────────────────────────────────
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u,       label=f"Numerical  (CN, T={T})", linewidth=2)
ax.plot(x, u_exact, label="Exact solution",          linewidth=1.5, linestyle="--")
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Heat equation  u_t = 0.5 u_xx  at  T = {T}")
ax.legend()
ax.grid(True)
fig.tight_layout()
fig.savefig("solution_agent_heat_02.png", dpi=150)
plt.close(fig)
print("Saved solution_agent_heat_02.png")
```
