Solve the 2D wave equation numerically as specified below.

The PDE is u_tt = (1.0)**2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t), where c = 1.0.
The spatial domain is (x,y) in [0,1] x [0,1] and the time domain is t in [0, 1.0].
Use Nx = Ny = 120 uniform intervals, giving 121 x 121 grid points including both endpoints.
Set dx = 1.0/120 and dy = 1.0/120.
The grid points are x_i = i*dx for i=0..120 and y_j = j*dy for j=0..120.
Apply Dirichlet boundary conditions u=0 on all four boundaries at every time step.
Set initial condition u(x,y,0) = 0 for all interior and boundary points.
Set initial velocity u_t(x,y,0) = 0 for all points.
Compute dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)).
Set Nt = ceil(1.0 / dt0) and then dt = 1.0 / Nt so the simulation hits T=1.0 exactly.
Use the 5-point Laplacian stencil: u_xx + u_yy at interior point (i,j) = (u[j,i+1] - 2*u[j,i] + u[j,i-1])/dx**2 + (u[j+1,i] - 2*u[j,i] + u[j-1,i])/dy**2.
Use 2nd-order central difference in time: u_new[j,i] = 2*u[j,i] - u_old[j,i] + dt**2 * (laplacian[j,i] + sin(pi*x_i)*sin(pi*y_j)*cos(2*pi*t_current)).
For the first time step (Taylor start), use: u_new[j,i] = u[j,i] + dt*u_t0[j,i] + 0.5*dt**2 * (laplacian_at_t0[j,i] + sin(pi*x_i)*sin(pi*y_j)*cos(0)), where u_t0 = 0 everywhere and laplacian_at_t0 = 0 everywhere since u(x,y,0) = 0.
After each time step, enforce u=0 on all boundary nodes (i=0, i=120, j=0, j=120).
After completing all Nt steps, the solution u(x,y,T=1.0) is defined on the 121x121 grid.
