Solve the 1D wave equation u_tt = (1.0)^2 * u_xx + sin(pi*x)*sin(2*pi*t) numerically using the specifications below.

The PDE is u_tt = c^2 * u_xx + f(x,t) where c = 1.0 and f(x,t) = sin(pi*x)*sin(2*pi*t).
The spatial domain is x in [0,1] (closed interval) and the time domain is t in [0, T] where T = 1.0.
Use Nx = 400 uniform intervals so there are 401 grid points including both endpoints.
Set dx = 1.0 / Nx.
Set dt0 = 0.9 * dx / c.
Set Nt = ceil(T / dt0) and then dt = T / Nt so the final time T is hit exactly.
The CFL condition c * dt / dx must be at most 0.9.
The interior grid points are x_i = i * dx for i = 0, 1, ..., 400.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1 at every time step.
Set the initial condition u(x, 0) = 0 for all grid points.
Set the initial velocity u_t(x, 0) = 0 for all grid points.
Compute u at the first time step using the Taylor start formula: u^1_i = u^0_i + dt * v0_i + 0.5 * dt^2 * (c^2 * u_xx^0_i + f(x_i, 0)) for interior points, where u_xx^0_i is approximated by the second-order central difference (u^0_{i-1} - 2*u^0_i + u^0_{i+1}) / dx^2.
After computing u^1, enforce Dirichlet boundary conditions by setting u^1_0 = 0 and u^1_{Nx} = 0.
For all subsequent time steps n = 1, 2, ..., Nt-1, advance the solution using the leapfrog scheme: u^{n+1}_i = 2*u^n_i - u^{n-1}_i + dt^2 * (c^2 * (u^n_{i-1} - 2*u^n_i + u^n_{i+1}) / dx^2 + f(x_i, n*dt)) for interior points i = 1, ..., Nx-1.
After each leapfrog step, enforce Dirichlet boundary conditions by setting u^{n+1}_0 = 0 and u^{n+1}_{Nx} = 0.
After completing all Nt time steps, extract the solution u(x, T) as the final 1D array of length 401.
Compute and print min(u), max(u), and the discrete L2 norm defined as sqrt(sum(u^2) * dx) at T = 1.0.
Save a file named "solution_agent_wave_10.npz" containing the array x (1D, length 401), the array u (1D, length 401), and the scalar metadata T, dx, dt.
Save a line plot of u(x, T) versus x as "solution_agent_wave_10.png" with x on the horizontal axis and u on the vertical axis.
Use Python with numpy for computation and matplotlib for plotting.
Use '**' for exponentiation in Python code.
Treat all trigonometric functions as operating in radians.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
c = 1.0
T = 1.0
Nx = 400
dx = 1.0 / Nx
dt0 = 0.9 * dx / c
Nt = math.ceil(T / dt0)
dt = T / Nt

print(f"Nx={Nx}, dx={dx}, Nt={Nt}, dt={dt:.6e}, CFL={c*dt/dx:.4f}")

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 401 points

# Forcing function
def f(x_arr, t):
    return np.sin(np.pi * x_arr) * np.sin(2.0 * np.pi * t)

# Initial conditions
u0 = np.zeros(Nx + 1)   # u(x, 0) = 0
v0 = np.zeros(Nx + 1)   # u_t(x, 0) = 0

# Allocate arrays
u_prev = u0.copy()  # u^{n-1}
u_curr = np.zeros(Nx + 1)  # u^{n}

# Taylor start: compute u^1
# u_xx^0 at interior points
u_xx0 = np.zeros(Nx + 1)
u_xx0[1:Nx] = (u_prev[0:Nx-1] - 2.0*u_prev[1:Nx] + u_prev[2:Nx+1]) / dx**2

f0 = f(x, 0.0)
u_curr = u_prev + dt * v0 + 0.5 * dt**2 * (c**2 * u_xx0 + f0)

# Enforce Dirichlet BCs
u_curr[0] = 0.0
u_curr[Nx] = 0.0

# Time stepping (leapfrog)
u_next = np.zeros(Nx + 1)

for n in range(1, Nt):
    t_n = n * dt
    # Compute u_xx at interior points
    u_xx = (u_curr[0:Nx-1] - 2.0*u_curr[1:Nx] + u_curr[2:Nx+1]) / dx**2
    # Forcing at interior points
    f_n = f(x[1:Nx], t_n)
    # Leapfrog update for interior points
    u_next[1:Nx] = 2.0*u_curr[1:Nx] - u_prev[1:Nx] + dt**2 * (c**2 * u_xx + f_n)
    # Dirichlet BCs
    u_next[0] = 0.0
    u_next[Nx] = 0.0
    # Shift
    u_prev = u_curr.copy()
    u_curr = u_next.copy()

u_final = u_curr

# Diagnostics
u_min = np.min(u_final)
u_max = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)
print(f"min(u) = {u_min:.6e}")
print(f"max(u) = {u_max:.6e}")
print(f"L2 norm = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_wave_10.npz", x=x, u=u_final, T=T, dx=dx, dt=dt)
print("Saved solution_agent_wave_10.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, u_final, linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Wave equation solution at T={T}")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_wave_10.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_10.png")
```
