Solve the SIR epidemiological ODE system numerically using the specifications below.

The ODE system is:
dS/dt = -beta * S * I
dI/dt = beta * S * I - gamma * I
dR/dt = gamma * I

The time domain is t in [0.0, 40.0].

Use parameters beta = 0.5 and gamma = 0.1.

Use initial conditions S(0) = 0.99, I(0) = 0.01, R(0) = 0.0.

Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt = 0.01 and Nt = 4000 steps so the final time 40.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n * dt for n = 0 to Nt inclusive, giving Nt+1 = 4001 time points.

At each RK4 step from t_n to t_{n+1}, compute k1 = f(t_n, y_n), k2 = f(t_n + dt/2, y_n + dt/2 * k1), k3 = f(t_n + dt/2, y_n + dt/2 * k2), k4 = f(t_n + dt, y_n + dt * k3), then y_{n+1} = y_n + (dt/6) * (k1 + 2*k2 + 2*k3 + k4).

Use the caret symbol ^ to mean exponentiation; in Python code use ** for powers.

Store the time array t as a 1D array of length Nt+1.

Store the solution Y as a 2D array of shape [Nt+1, 3] with columns ordered as [S, I, R].

Save a file named solution_molk_005.npz containing the arrays t and Y and the scalar parameters beta and gamma.

Save a plot of S, I, and R each as a line versus t, with a legend labeling each line, and save it as solution_molk_005.png.

Print the final state values S(40), I(40), R(40) at the end of the simulation.
