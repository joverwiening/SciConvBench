Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the specifications below.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v**2.

The viscous stress is sigma = (zeta + 4/3*eta) * v_x, with zeta = eta = 0.1.

The PDEs in conservative form are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.5].

Parameters: Gamma = 1.6666666666666667, eta = 0.1, zeta = 0.1.

Boundary conditions are periodic on x = -1 and x = 1.

Initial conditions defined pointwise:
rho(x,0) = 1.0 + 0.2*sin(pi*x)
v(x,0) = 0.1*cos(pi*x)
p(x,0) = 1.0 + 0.2*cos(pi*x)

Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., 399, where dx = 2.0/400 = 0.005.

Evolve the conservative cell-average variables U = [rho, m, E].

Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.

For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
The physical convective flux is F_conv(U) = [m, m**2/rho + p, (E+p)*v] with v = m/rho.
The interface wave speed is a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

For the viscous terms, compute v_x at each cell center using a centered difference on the cell-centered v values.
Compute sigma at each cell center as sigma = (zeta + 4/3*eta) * v_x.
Approximate sigma at each interface by averaging the two neighboring cell-centered sigma values.
Approximate v at each interface by averaging the two neighboring cell-centered v values.
The viscous flux contribution at each interface is F_visc = [0, -sigma_interface, -v_interface * sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.

At each time step, compute the time step as follows:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
dt = min(dt_conv, dt_visc)
Adjust the last step so the simulation hits the final time T = 0.5 exactly.

Use CFL = 0.8.

Implement periodic boundary conditions by wrapping indices (ghost cells take values from the opposite end of the domain).

At the final time T = 0.5, compute rho(x,T), v(x,T), p(x,T) on the 400 cell centers.
