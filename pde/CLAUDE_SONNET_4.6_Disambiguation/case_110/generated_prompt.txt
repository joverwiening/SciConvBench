Solve the FitzHugh-Nagumo ODE system numerically using the specifications below.

The system has two unknown scalar functions of time: v(t) and w(t).

The ODE system is:
dv/dt = v - (v**3)/3 - w + I
dw/dt = (1/tau)*(v + a - b*w)

The time domain is t in [0.0, 200.0].

The parameters are I = 0.5, a = 0.7, b = 0.8, tau = 12.5.

The initial conditions are v(0) = 0.0 and w(0) = 0.0.

Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.05 and Nt = 4000 steps so the final time 200.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n*dt for n = 0 to Nt inclusive, giving Nt+1 = 4001 time points.

Store the time array t as a 1D array of length 4001.

Store the state array Y as a 2D array of shape [4001, 2] with columns ordered as [v, w].

Save a file named solution_molk_009.npz containing the arrays t and Y and the scalar parameters I, a, b, tau.

Save a plot named solution_molk_009.png showing line plots of v vs t and w vs t on the same or separate axes.

Print the final state values v(200.0) and w(200.0).

Print the minimum and maximum of v over all time points.

Print the minimum and maximum of w over all time points.

Use ** for exponentiation in Python code.

Treat all mathematical functions as operating in radians where applicable.
