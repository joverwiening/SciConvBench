The time domain is t in [0.0, 5.0].

The initial condition is u(0) = u0. Use u0 = 0.0 unless otherwise specified (it cancels in the error since the exact solution uses the same u0).

The exact solution for verification is u(t) = u0 + a*(1 - exp(-t)) + b*t.

Evaluate the exact solution on the same time grid of 5001 points.
