Solve the 1D wave equation u_tt = (0.5)^2 * u_xx numerically using the specifications below.

PDE is u_tt = c**2 * u_xx with c = 0.5.
Domain is x in [0,1], t in [0,1.0].
Use Nx = 400 uniform intervals so there are 401 grid points including both endpoints.
dx = 1.0 / 400.
Compute dt0 = 0.9 * dx / c.
Set Nt = ceil(1.0 / dt0) and then dt = 1.0 / Nt so the final time T = 1.0 is hit exactly.
CFL = c * dt / dx must be at or below 0.9.
Use 2nd-order central differences for u_xx in the interior: u_xx[i] = (u[i+1] - 2*u[i] + u[i-1]) / dx**2.
Use the leapfrog / Störmer–Verlet scheme for time integration: u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + dt**2 * c**2 * u_xx^n[i].
Initial condition is u(x, 0) = sin(2*pi*x).
Initial velocity is u_t(x, 0) = v0(x) where v0(x) = -0.5 * 2 * pi * sin(0.5*2*pi*0) * sin(2*pi*x) = 0 (since the time derivative of cos(0.5*2*pi*t)*sin(2*pi*x) at t=0 is -0.5*2*pi*sin(0)*sin(2*pi*x) = 0).
Compute the first time step using the Taylor start: u^1 = u^0 + dt * v0 + 0.5 * dt**2 * c**2 * u_xx^0.
Since v0 = 0 everywhere, u^1 = u^0 + 0.5 * dt**2 * c**2 * u_xx^0.
Apply Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 at every time step by setting u[0] = 0 and u[Nx] = 0.
The exact solution for verification is u_exact(x, t) = cos(0.5 * 2 * pi * t) * sin(2 * pi * x).
Evaluate the numerical solution u(x, T=1.0) on the 401-point grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 1.0.
Compute and print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx) where u_exact is evaluated at the same x grid at t = 1.0.
Save a file named solution_agent_wave_02.npz containing arrays x (1D, length 401), u (1D, length 401), and metadata scalars T, dx, dt.
Save a line plot of u(x, T=1.0) as solution_agent_wave_02.png with x on the horizontal axis and u on the vertical axis.
Use radians for all trigonometric functions.
Use ** for exponentiation in Python code.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
c = 0.5
T = 1.0
Nx = 400
dx = 1.0 / Nx

# Time step
dt0 = 0.9 * dx / c
Nt = math.ceil(T / dt0)
dt = T / Nt

CFL = c * dt / dx
print(f"Nx={Nx}, dx={dx:.6f}, Nt={Nt}, dt={dt:.6f}, CFL={CFL:.6f}")

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 401 points

# Initial conditions
u0 = np.sin(2 * np.pi * x)
v0 = np.zeros_like(x)  # time derivative at t=0 is zero

# Apply Dirichlet BCs to initial condition
u0[0] = 0.0
u0[Nx] = 0.0

def compute_uxx(u, dx):
    uxx = np.zeros_like(u)
    uxx[1:-1] = (u[2:] - 2.0 * u[1:-1] + u[:-2]) / dx**2
    return uxx

# Taylor start for u^1
uxx0 = compute_uxx(u0, dx)
u1 = u0 + dt * v0 + 0.5 * dt**2 * c**2 * uxx0
u1[0] = 0.0
u1[Nx] = 0.0

# Leapfrog time integration
u_prev = u0.copy()
u_curr = u1.copy()

for n in range(1, Nt):
    uxx = compute_uxx(u_curr, dx)
    u_next = 2.0 * u_curr - u_prev + dt**2 * c**2 * uxx
    u_next[0] = 0.0
    u_next[Nx] = 0.0
    u_prev = u_curr
    u_curr = u_next

u_numerical = u_curr

# Exact solution at T=1.0
u_exact = np.cos(0.5 * 2 * np.pi * T) * np.sin(2 * np.pi * x)

# Diagnostics
min_u = np.min(u_numerical)
max_u = np.max(u_numerical)
l2_norm = np.sqrt(np.sum(u_numerical**2) * dx)
max_abs_error = np.max(np.abs(u_numerical - u_exact))
l2_error = np.sqrt(np.sum((u_numerical - u_exact)**2) * dx)

print(f"min(u)       = {min_u:.6e}")
print(f"max(u)       = {max_u:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_abs_error:.6e}")
print(f"L2 error     = {l2_error:.6e}")

# Save npz
np.savez("solution_agent_wave_02.npz", x=x, u=u_numerical, T=T, dx=dx, dt=dt)
print("Saved solution_agent_wave_02.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_numerical, label="Numerical u(x,T=1.0)", linewidth=1.5)
ax.plot(x, u_exact, '--', label="Exact u(x,T=1.0)", linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title("Wave equation solution at T=1.0 (agent_wave_02)")
ax.legend()
plt.tight_layout()
plt.savefig("solution_agent_wave_02.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_02.png")
```
