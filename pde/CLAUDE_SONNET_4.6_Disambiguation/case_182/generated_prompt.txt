Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The spatial domain is the half-open periodic interval [0, 1) with Nx = 512 uniformly spaced grid points.
Compute dx = 1.0 / 512 and set x_i = i * dx for i = 0, 1, ..., 511.
Use nu = 1.0 and rho = 2.0.
Apply periodic boundary conditions: u(0, t) = u(1, t) for all t.
Set the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that T = 1.0 exactly.
At each full time step, apply Strang splitting in three substeps.
Substep A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2 * pi * fftfreq(512, d=dx), multiply u_hat by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).
Substep B (reaction full step, duration dt): update each grid point exactly using u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Substep C (diffusion half-step again): repeat substep A identically.
After all Nt steps, compute the final solution u(x, T) on the 512-point grid.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at time T.
Save a file named "solution_pdebench_reacdiff_nu1_rho2.npz" containing the 1D array x of length 512, the 1D array u of length 512, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x, T) as a PNG file named "solution_pdebench_reacdiff_nu1_rho2.png".
Use Python with numpy (for FFT via numpy.fft.fft, numpy.fft.ifft, numpy.fft.fftfreq) and matplotlib for the plot.
