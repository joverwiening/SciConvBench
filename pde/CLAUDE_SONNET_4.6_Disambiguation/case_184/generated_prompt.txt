Solve the 1D Reaction-Diffusion PDE numerically using the following specification.

The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
Set nu = 2.0 and rho = 1.0.
The periodic boundary condition is u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0 / 512.
Set x_j = j * dx for j = 0, 1, ..., 511.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

At each full time step, apply Strang splitting as follows.

Step A (diffusion half-step, duration dt/2):
Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(512, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Step B (reaction full-step, duration dt):
The local ODE is du/dt = rho * u * (1 - u).
Apply the exact pointwise logistic update: u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).

Step C (diffusion half-step again):
Repeat Step A identically with duration dt/2.

After completing all Nt = 1000 steps, compute the solution u(x, T=1.0) on the periodic grid.

Save a file named "solution_pdebench_reacdiff_nu2_rho1.npz" containing the following arrays and scalars: x (1D array of length 512), u (1D array of length 512), nu (scalar 2.0), rho (scalar 1.0), T (scalar 1.0), dx (scalar 1.0/512), dt (scalar 0.001), Nx (scalar 512), Nt (scalar 1000).

Save a line plot of u(x, T=1.0) as "solution_pdebench_reacdiff_nu2_rho1.png".

Print the following scalar diagnostics at T=1.0: min(u), max(u), mean(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx).
