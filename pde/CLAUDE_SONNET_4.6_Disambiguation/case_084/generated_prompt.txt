Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically using the specifications below.

PDE is u_tt = c^2 * u_xx with c = 1.0.
Domain is x in [0,1], t in [0, 0.8].
Use Nx = 600 uniform intervals so there are 601 grid points including both endpoints.
dx = 1.0 / 600.
Compute dt0 = 0.9 * dx / c.
Set Nt = ceil(0.8 / dt0) and then dt = 0.8 / Nt so the final time T = 0.8 is hit exactly.

Initial condition u(x, 0) = cos(1.0*pi*0)*sin(pi*x) + 0.5*cos(1.0*3*pi*0)*sin(3*pi*x), which simplifies to u0(x) = sin(pi*x) + 0.5*sin(3*pi*x).
Initial velocity v0(x) = du/dt at t=0 = -1.0*pi*sin(1.0*pi*0)*sin(pi*x) - 0.5*1.0*3*pi*sin(1.0*3*pi*0)*sin(3*pi*x), which simplifies to v0(x) = 0.
There is no forcing term f.

Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1 at every time step.

Use 2nd-order central differences for u_xx in the interior: u_xx at node i = (u[i-1] - 2*u[i] + u[i+1]) / dx**2.
Use the leapfrog / Störmer–Verlet scheme: u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + dt**2 * c**2 * u_xx^n[i] for interior nodes.
Initialize the first time step using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt**2 * c**2 * u_xx^0, since there is no forcing term.
Set boundary nodes u^1[0] = 0 and u^1[Nx] = 0.

After advancing to t = T = 0.8, compute the numerical solution u(x, T) on all 601 grid points.
Compute the exact solution u_exact(x, T) = cos(1.0*pi*0.8)*sin(pi*x) + 0.5*cos(1.0*3*pi*0.8)*sin(3*pi*x) on the same grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).

Save a file named "solution_agent_wave_03.npz" containing the 1D array x of length 601, the 1D array u of length 601, and scalar metadata T = 0.8, dx, dt.
Save a line plot of u(x, T) versus x as "solution_agent_wave_03.png".

Use Python with numpy for numerics and matplotlib for plotting.
Interpret ^ as exponentiation and use ** in Python code for powers.
Use radians for all trigonometric functions.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
c = 1.0
T = 0.8
Nx = 600
x = np.linspace(0.0, 1.0, Nx + 1)  # 601 points
dx = 1.0 / Nx

# Time step
dt0 = 0.9 * dx / c
Nt = math.ceil(T / dt0)
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL={c*dt/dx:.6f}")

# Initial conditions
u0 = np.sin(np.pi * x) + 0.5 * np.sin(3.0 * np.pi * x)
v0 = np.zeros(Nx + 1)  # zero initial velocity

# Compute u_xx for an array using central differences (interior only)
def compute_uxx(u, dx):
    uxx = np.zeros_like(u)
    uxx[1:-1] = (u[:-2] - 2.0 * u[1:-1] + u[2:]) / dx**2
    return uxx

# Initialize u^0
u_prev = u0.copy()

# Taylor start for u^1
uxx0 = compute_uxx(u_prev, dx)
u_curr = u_prev + dt * v0 + 0.5 * dt**2 * c**2 * uxx0
# Apply Dirichlet BCs
u_curr[0] = 0.0
u_curr[-1] = 0.0

# Time stepping (leapfrog)
for n in range(1, Nt):
    uxx = compute_uxx(u_curr, dx)
    u_next = 2.0 * u_curr - u_prev + dt**2 * c**2 * uxx
    # Apply Dirichlet BCs
    u_next[0] = 0.0
    u_next[-1] = 0.0
    u_prev = u_curr
    u_curr = u_next

u_numerical = u_curr

# Exact solution at T
u_exact = (np.cos(1.0 * np.pi * T) * np.sin(np.pi * x)
           + 0.5 * np.cos(1.0 * 3.0 * np.pi * T) * np.sin(3.0 * np.pi * x))

# Diagnostics
u_min = np.min(u_numerical)
u_max = np.max(u_numerical)
l2_norm = np.sqrt(np.sum(u_numerical**2) * dx)
max_abs_error = np.max(np.abs(u_numerical - u_exact))
l2_error = np.sqrt(np.sum((u_numerical - u_exact)**2) * dx)

print(f"min(u)       = {u_min:.6e}")
print(f"max(u)       = {u_max:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_abs_error:.6e}")
print(f"L2 error     = {l2_error:.6e}")

# Save npz
np.savez("solution_agent_wave_03.npz",
         x=x,
         u=u_numerical,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))
print("Saved solution_agent_wave_03.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_numerical, label=f"Numerical u(x, T={T})", linewidth=1.5)
ax.plot(x, u_exact, '--', label="Exact solution", linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"Wave equation solution at T={T}")
ax.legend()
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_wave_03.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_03.png")
```
