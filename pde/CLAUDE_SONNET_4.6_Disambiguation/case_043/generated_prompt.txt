Solve the heat equation u_t = 0.1 * u_xx + 1 numerically using the Crank-Nicolson method and save the results.

The PDE is u_t = 0.1 * u_xx + 1, where alpha = 0.1 and the source term is the constant 1.
The spatial domain is x in [0, 1] and the time domain is t in [0, 0.5].
Use Nx = 200 uniform intervals, giving 201 grid points including both endpoints x=0 and x=1.
Set dx = 1.0 / 200.
Use dt = 0.001 and run for 500 time steps to reach T = 0.5.
Apply 2nd-order central differences for u_xx at interior points.
Use the Crank-Nicolson scheme for the diffusion term, averaging the diffusion operator at time level n and n+1.
Include the constant source term 1 consistently in the Crank-Nicolson framework, meaning add 0.5 * dt * 1 from both the current and next time level (i.e., add dt * 1 total to the right-hand side at each step).
The initial condition is not explicitly stated; assume u(x, 0) = 0 everywhere.
The boundary conditions are not explicitly stated; assume homogeneous Dirichlet: u(0, t) = 0 and u(1, t) = 0 for all t.
Enforce Dirichlet boundary conditions by fixing the boundary nodes at each time step.
At each time step, assemble the tridiagonal linear system for the interior points only and solve it.
After 500 steps, extract u(x, T=0.5) as a 1D array of length 201.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T=0.5.
Save a file named "solution_agent_heat_14.npz" containing: x (1D array of 201 points), u (1D array of 201 values at T=0.5), and metadata scalars T=0.5, dx=0.005, dt=0.001.
Save a line plot of u vs x at T=0.5 as "solution_agent_heat_14.png" with labeled axes.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import solve_banded

# Parameters
alpha = 0.1
Nx = 200
dx = 1.0 / Nx
dt = 0.001
T = 0.5
Nsteps = int(round(T / dt))  # 500

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 201 points

# Initial condition
u = np.zeros(Nx + 1)

# Boundary conditions (homogeneous Dirichlet)
u[0] = 0.0
u[-1] = 0.0

# Interior indices: 1 to Nx-1 (199 interior points)
N_int = Nx - 1  # 199

# Crank-Nicolson coefficient
r = alpha * dt / (dx ** 2)

# Build the tridiagonal system for CN
# (I + r/2 * A) u^{n+1} = (I - r/2 * A) u^n + dt * source
# where A is the second-difference matrix (negative Laplacian sign convention below)
# The system: -r/2 * u_{i-1} + (1 + r) * u_i - r/2 * u_{i+1} = RHS_i

# LHS tridiagonal (stored in banded form for solve_banded)
# ab[0] = upper diagonal, ab[1] = main diagonal, ab[2] = lower diagonal
ab = np.zeros((3, N_int))
ab[0, 1:] = -r / 2.0          # upper diagonal (ab[0, j] corresponds to column j)
ab[1, :] = 1.0 + r             # main diagonal
ab[2, :-1] = -r / 2.0          # lower diagonal

# Source term contribution per step (constant source = 1, CN average = dt*1)
source_rhs = dt * 1.0 * np.ones(N_int)

# Time integration
for n in range(Nsteps):
    u_int = u[1:Nx]  # interior values, length N_int

    # RHS: (I - r/2 * A) u^n + dt * source
    rhs = np.zeros(N_int)
    # Main diagonal contribution
    rhs[:] = (1.0 - r) * u_int
    # Off-diagonal contributions
    rhs[:-1] += (r / 2.0) * u_int[1:]
    rhs[1:] += (r / 2.0) * u_int[:-1]
    # Source term
    rhs += source_rhs
    # Boundary contributions to RHS (BC = 0, so these are zero, but kept for clarity)
    # rhs[0]  += (r/2.0) * u[0]   = 0
    # rhs[-1] += (r/2.0) * u[-1]  = 0

    # Solve tridiagonal system
    u_int_new = solve_banded((1, 1), ab, rhs)

    # Update interior
    u[1:Nx] = u_int_new
    # Boundaries remain 0
    u[0] = 0.0
    u[-1] = 0.0

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u ** 2) * dx)
print(f"min(u)   = {u_min:.6e}")
print(f"max(u)   = {u_max:.6e}")
print(f"L2 norm  = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_heat_14.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_heat_14.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, u, color='steelblue', linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"Heat equation solution at T={T}  (CN, Nx={Nx}, dt={dt})")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_agent_heat_14.png", dpi=150)
plt.close()
print("Saved solution_agent_heat_14.png")
```
