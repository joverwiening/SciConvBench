Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The spatial domain is [0, 1) with periodic boundary conditions, treated as half-open.
Use Nx = 512 grid points with dx = 1.0 / 512 and x_i = i * dx for i = 0 to 511.
Set nu = 1.0 and rho = 10.0.
Set the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).
Use fixed dt = 0.001 and Nt = 1000 time steps so that T = 1.0.
At each full time step, apply Strang splitting in three substeps.
Substep A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2 * pi * fftfreq(Nx, d=dx), multiply u_hat by exp(-nu * k**2 * (dt/2)), set u = real(IFFT(u_hat)).
Substep B (reaction full-step, duration dt): update each grid point exactly using u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Substep C (diffusion half-step again): repeat substep A identically.
After all Nt steps, compute the final solution u(x, T).
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
Save a file named "solution_pdebench_reacdiff_nu1_rho10.npz" containing arrays x (length 512) and u (length 512), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu1_rho10.png" with x on the horizontal axis and u on the vertical axis.
Use Python with numpy (for FFT use numpy.fft.fft, numpy.fft.ifft, numpy.fft.fftfreq) and matplotlib for the plot.
Interpret ^ as exponentiation and use ** in Python code.

Here is the complete Python code:

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
nu = 1.0
rho = 10.0
Nx = 512
dt = 0.001
Nt = 1000
T = dt * Nt  # = 1.0

# Spatial grid: half-open [0, 1), Nx points
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_i = i * dx, i = 0..Nx-1

# Initial condition
u = 0.25 + 0.1 * np.sin(2 * np.pi * x)

# Precompute wavenumbers and diffusion factors
k = 2 * np.pi * np.fft.fftfreq(Nx, d=dx)
diff_factor_half = np.exp(-nu * k**2 * (dt / 2))

# Precompute reaction factor
exp_rho_dt = np.exp(rho * dt)

def diffusion_half_step(u):
    u_hat = np.fft.fft(u)
    u_hat *= diff_factor_half
    return np.fft.ifft(u_hat).real

def reaction_full_step(u):
    return (u * exp_rho_dt) / (1.0 + u * (exp_rho_dt - 1.0))

# Time integration with Strang splitting
for n in range(Nt):
    # (A) Diffusion half-step
    u = diffusion_half_step(u)
    # (B) Reaction full-step
    u = reaction_full_step(u)
    # (C) Diffusion half-step
    u = diffusion_half_step(u)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
u_mean = np.mean(u)
u_l2 = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)  = {u_min:.6f}")
print(f"max(u)  = {u_max:.6f}")
print(f"mean(u) = {u_mean:.6f}")
print(f"L2 norm = {u_l2:.6f}")

# Save .npz
np.savez(
    "solution_pdebench_reacdiff_nu1_rho10.npz",
    x=x,
    u=u,
    nu=nu,
    rho=rho,
    T=T,
    dx=dx,
    dt=dt,
    Nx=Nx,
    Nt=Nt
)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T)")
ax.set_title(f"1D Reaction-Diffusion solution at T={T}, nu={nu}, rho={rho}")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_pdebench_reacdiff_nu1_rho10.png", dpi=150)
plt.close()

print("Files saved: solution_pdebench_reacdiff_nu1_rho10.npz and .png")
```
