Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
The spatial domain is [0,1) with periodic boundary conditions.
Use Nx=512 uniformly spaced grid points with no duplicated endpoint.
Set dx = 1/512 and x_j = j*dx for j=0,...,511.
The viscosity parameter is nu = 0.04.
The initial condition is u(x,0) = sin(2*pi*x).
The final time T must be specified; since no T was given in the prompt, use T=1.0 as the simulation end time.
Use CFL=0.4 with an estimated max speed of 1.0 to set dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0) and reset dt = T/Nt so the final time is hit exactly.
Advance the solution using Strang splitting at each full time step dt.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), set u = real(IFFT(u_hat)).
Step B (advection full-step, duration dt): apply a finite-volume update using Rusanov (local Lax-Friedrichs) flux with f(u)=0.5*u**2.
For each interface between u_left=u[j] and u_right=u[(j+1) % Nx], compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, set F_plus = flux between u[j] and u[(j+1)%Nx], F_minus = flux between u[(j-1)%Nx] and u[j], then u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
Step C (diffusion half-step again): repeat Step A identically.
After all Nt time steps, compute and print min(u), max(u), mean(u) (should be conserved near zero), and the discrete L2 norm sqrt(sum(u**2)*dx).
