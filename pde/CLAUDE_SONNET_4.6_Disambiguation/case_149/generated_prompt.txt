Solve the 1D Viscous Burgers equation u_t + d/dx(0.5*u^2) = nu*u_xx numerically in Python.
The spatial domain is [0,1) with periodic boundary conditions.
Use Nx=512 uniformly spaced grid points with no duplicated endpoint; dx=1.0/512; x_i=i*dx for i=0..511.
The viscosity parameter nu=1.0.
The initial condition is u(x,0)=sin(2*pi*x).
The final simulation time is T=1.0.
Set dt0=CFL*dx/1.0 with CFL=0.4; compute Nt=ceil(T/dt0); reset dt=T/Nt so the final time is hit exactly.
At each full time step, apply Strang splitting in three substeps.
Substep A (diffusion half-step, duration dt/2): compute u_hat=FFT(u); compute wavenumbers k=2*pi*fftfreq(Nx,d=dx); multiply u_hat by exp(-nu*k**2*(dt/2)); set u=real(IFFT(u_hat)).
Substep B (advection full-step, duration dt) using finite-volume Rusanov flux: define f(u)=0.5*u**2; for each interface between u_left=u[j] and u_right=u[(j+1)%Nx], compute alpha=max(abs(u_left),abs(u_right)) and F=0.5*(f(u_left)+f(u_right))-0.5*alpha*(u_right-u_left); update u_new[j]=u[j]-(dt/dx)*(F_plus-F_minus) where F_plus is the flux at the right interface of cell j and F_minus is the flux at the left interface of cell j; replace u with u_new.
Substep C (diffusion half-step again): identical to Substep A.
After all Nt time steps, compute and print min(u), max(u), mean(u) (should be conserved near zero), and sqrt(sum(u**2)*dx) as the discrete L2 norm.
Save a file named "solution_pdebench_burgers_nu1.npz" containing arrays x (length 512), u (length 512), and scalars nu, T, dx, dt, Nx, Nt.
