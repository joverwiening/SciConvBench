Solve the Helmholtz PDE numerically using the following specification.

PDE: u_xx + u_yy + k**2 * u = f(x,y), where k = 5.0 and f(x,y) = (k**2 - 2*(pi**2)) * sin(pi*x) * sin(pi*y).

Domain: (x,y) in [0,1] x [0,1].

Exact solution for verification: u(x,y) = sin(pi*x) * sin(pi*y).

Use a uniform grid with Nx = Ny = 120 intervals in each direction, giving Nx+1 = 121 grid points per direction including both endpoints.
Set dx = dy = 1/120.
Set x_i = i * dx for i = 0, 1, ..., 120.
Set y_j = j * dy for j = 0, 1, ..., 120.

Apply Dirichlet boundary conditions u = 0 on all four boundaries.

Discretize the PDE on interior nodes using the standard 5-point Laplacian stencil: (u[i-1,j] - 2*u[i,j] + u[i+1,j]) / dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1]) / dy**2 + k**2 * u[i,j] = f(x_i, y_j).

Assemble the resulting sparse linear system for all interior nodes.

Solve the sparse linear system using scipy.sparse.linalg.spsolve.

Construct the full solution array u of shape (121, 121) with u[j,i] = u(x_i, y_j), incorporating the zero boundary values.

Compute and print min(u), max(u), and the discrete L2 norm defined as sqrt(sum(u**2) * dx * dy) over all grid points.

Compute the exact solution on the same grid and compute and print the max absolute error and the discrete L2 error between the numerical and exact solutions.
