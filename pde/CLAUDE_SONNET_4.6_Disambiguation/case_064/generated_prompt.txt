Solve the Laplace PDE u_xx + u_yy = 0 on the domain [0,1] x [0,1].
The unknown field is u(x,y).
Use the exact solution u(x,y) = sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi) for boundary conditions and verification.
Use Nx = Ny = 100 uniform intervals in each direction, giving 101 x 101 grid points including boundaries.
Set dx = dy = 1/100.
Define x_i = i*dx for i = 0..100 and y_j = j*dy for j = 0..100.
Apply Dirichlet boundary conditions on all four edges using the exact solution evaluated at the boundary nodes.
Discretize the interior nodes using the standard 5-point finite difference stencil: (u[i-1,j] - 2*u[i,j] + u[i+1,j])/dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1])/dy**2 = 0.
Assemble the resulting sparse linear system for all interior nodes.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Store the full solution array u with shape (101, 101) where u[j,i] = u(x_i, y_j).
Compute and print min(u), max(u), and the discrete L2 norm defined as sqrt(sum(u**2)*dx*dy) over all grid points.
Evaluate the exact solution on the same 101x101 grid.
Compute and print the max absolute error (max of abs(u_numerical - u_exact)) and the L2 error defined as sqrt(sum((u_numerical - u_exact)**2)*dx*dy).
