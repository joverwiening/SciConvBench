Solve the 1D damped wave equation u_tt + 0.5*u_t = (1.0)^2 * u_xx numerically using the specifications below.

The PDE is u_tt + 0.5*u_t = u_xx, with damping coefficient gamma=0.5 and wave speed c=1.0.

Rewrite as a first-order system: u_t = v, v_t = c**2 * u_xx - gamma * v.

The spatial domain is x in [0,1] (closed interval). Use Nx=400 uniform intervals, giving 401 grid points including both endpoints. Compute dx = 1.0/400. Grid points are x_i = 0 + i*dx for i=0,1,...,400.

The time domain is t in [0,3.0]. Use fixed dt=0.0005, giving 6000 time steps.

Apply Dirichlet boundary conditions u=0 at x=0 and x=1 at every RK4 substage. Also set v=0 at the boundary points at every substage.

Set initial conditions u(x,0) = sin(pi*x) and v(x,0) = u_t(x,0) = 0 at all interior and boundary grid points.

Discretize u_xx using 2nd-order central differences: u_xx at interior point i equals (u[i-1] - 2*u[i] + u[i+1]) / dx**2.

Integrate the system using classical 4-stage RK4 with the fixed dt=0.0005 for exactly 6000 steps to reach T=3.0.

At each RK4 substage, after computing the stage update for u and v, enforce u=0 and v=0 at the boundary indices i=0 and i=400 before computing the next stage slope.

After completing all 6000 steps, extract the final u array of length 401.

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx) at T=3.0.

Save a file named "solution_agent_wave_09.npz" containing: array x of shape (401,), array u of shape (401,), scalar T=3.0, scalar dx=1.0/400, scalar dt=0.0005.

Save a line plot of u(x, T=3.0) versus x as "solution_agent_wave_09.png" with x on the horizontal axis and u on the vertical axis.

Use Python with numpy for the computation and matplotlib for the plot.

Interpret the caret symbol ^ as exponentiation and use ** in Python code for powers.

Use radians for all trigonometric function evaluations.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Parameters
c = 1.0
gamma = 0.5
Nx = 400
dx = 1.0 / Nx
x = np.linspace(0.0, 1.0, Nx + 1)  # 401 points

dt = 0.0005
T = 3.0
Nsteps = 6000  # dt * Nsteps = 3.0

# Initial conditions
u = np.sin(np.pi * x)
v = np.zeros(Nx + 1)

# Enforce BCs on initial condition (already zero at endpoints for sin(pi*x))
u[0] = 0.0; u[Nx] = 0.0
v[0] = 0.0; v[Nx] = 0.0

def compute_rhs(u, v):
    """Compute (du/dt, dv/dt) = (v, c^2 * u_xx - gamma * v)"""
    dudt = v.copy()
    dvdt = np.zeros_like(v)
    # Central differences for u_xx at interior points
    dvdt[1:Nx] = c**2 * (u[0:Nx-1] - 2.0*u[1:Nx] + u[2:Nx+1]) / dx**2 - gamma * v[1:Nx]
    # Boundaries remain zero (enforced after)
    return dudt, dvdt

def enforce_bc(u, v):
    u[0] = 0.0; u[Nx] = 0.0
    v[0] = 0.0; v[Nx] = 0.0
    return u, v

# Classical RK4 time integration
for step in range(Nsteps):
    # Stage 1
    k1u, k1v = compute_rhs(u, v)
    u1 = u + 0.5 * dt * k1u
    v1 = v + 0.5 * dt * k1v
    u1, v1 = enforce_bc(u1, v1)

    # Stage 2
    k2u, k2v = compute_rhs(u1, v1)
    u2 = u + 0.5 * dt * k2u
    v2 = v + 0.5 * dt * k2v
    u2, v2 = enforce_bc(u2, v2)

    # Stage 3
    k3u, k3v = compute_rhs(u2, v2)
    u3 = u + dt * k3u
    v3 = v + dt * k3v
    u3, v3 = enforce_bc(u3, v3)

    # Stage 4
    k4u, k4v = compute_rhs(u3, v3)

    # Update
    u = u + (dt / 6.0) * (k1u + 2.0*k2u + 2.0*k3u + k4u)
    v = v + (dt / 6.0) * (k1v + 2.0*k2v + 2.0*k3v + k4v)
    u, v = enforce_bc(u, v)

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)

print(f"min(u)    = {u_min:.6e}")
print(f"max(u)    = {u_max:.6e}")
print(f"L2 norm   = {l2_norm:.6e}")

# Save NPZ
np.savez("solution_agent_wave_09.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_wave_09.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, linewidth=1.5, color='steelblue')
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=3.0)")
ax.set_title("Wave equation solution at T=3.0 (agent_wave_09)")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_agent_wave_09.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_09.png")
```
