Solve the 1D Compressible Navier–Stokes equations (no heat conduction) numerically using the specifications below.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use Python with NumPy for the implementation.

Use '^' as exponentiation in math; in Python code use '**' for powers.

The PDE is in conservative form with m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.
The viscous stress is sigma = (zeta + 4/3*eta) * dv/dx.
Assume zeta = eta.
The three equations are:
  rho_t + (m)_x = 0
  m_t + (m**2/rho + p - sigma)_x = 0
  E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].

Use a cell-centered finite volume discretization.
Nx = 800 cells (control volumes).
dx = (1 - (-1)) / Nx = 2.0 / 800 = 0.0025.
Cell centers are at x_i = -1 + (i + 0.5)*dx for i = 0, 1, ..., Nx-1.

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Initial condition is a Riemann (shock-tube) problem with discontinuity at x = 0.
For cell centers with x < 0: rho = 1.0, v = 0.0, p = 10.0.
For cell centers with x >= 0: rho = 1.0, v = 0.0, p = 0.1.

Boundary conditions are transmissive/outflow (zero-gradient) at both x = -1 and x = 1.
Implement outflow BCs by copying the nearest interior cell state into one ghost cell on each side.

Use a finite volume method with an approximate Riemann solver (e.g., HLLC or Roe) for the inviscid fluxes.
Use at least first-order reconstruction; second-order reconstruction with a slope limiter (e.g., minmod) is preferred.
Compute viscous fluxes using central differences of v at cell interfaces.
Use a CFL-based adaptive time step with CFL = 0.5.
The time step is dt = CFL * dx / max(|v| + c) where c = sqrt(Gamma * p / rho) is the local sound speed.
Advance in time using a first-order or second-order (e.g., Runge-Kutta) time integrator until T = 0.2.
Ensure rho and p remain positive at every time step; if not, clip or abort with an error message.

Output requirements:
Compute rho(x, T), v(x, T), p(x, T) on the Nx = 800 cell centers at the final time T = 0.2.
Save a file named "solution_pdebench_cns1d_sod7_eta1em8_outflow.npz" containing: x (1D array of length 800), rho (1D array), v (1D array), p (1D array), and scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel line plot of rho vs x, v vs x, and p vs x at T = 0.2 as "solution_pdebench_cns1d_sod7_eta1em8_outflow.png".
Print the minimum and maximum of rho over the domain (positivity check).
Print the minimum and maximum of p over the domain (positivity check).
