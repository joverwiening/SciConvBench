Solve the Laplace PDE u_xx + u_yy = 0 on the domain [0,1] x [0,1].
The unknown field is u(x,y).
The exact reference solution is u(x,y) = sin(pi*x)*sinh(pi*y)/sinh(pi).
Use Nx = Ny = 100 uniform intervals in each direction, giving 101 x 101 grid points including boundaries.
Define dx = dy = 1/100.
Define grid points as x_i = i*dx for i = 0..100 and y_j = j*dy for j = 0..100.
Apply boundary conditions from the exact solution: u(x,0) = 0, u(x,1) = sin(pi*x)/sinh(pi)*sinh(pi) = sin(pi*x), u(0,y) = 0, u(1,y) = 0.
Evaluate boundary values using the exact formula u(x,y) = sin(pi*x)*sinh(pi*y)/sinh(pi) at all boundary nodes.
Discretize the Laplacian using the standard 5-point stencil: (u[i-1,j] - 2*u[i,j] + u[i+1,j])/dx**2 + (u[i,j-1] - 2*u[i,j] + u[i,j+1])/dy**2 = 0 for all interior nodes.
Assemble the resulting sparse linear system for all interior nodes only.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Store the full solution array u with shape (101, 101) where u[j,i] = u(x_i, y_j).
Compute and print min(u) over the full grid.
Compute and print max(u) over the full grid.
Compute and print the discrete L2 norm as sqrt(sum(u**2)*dx*dy) over the full grid.
Evaluate the exact reference solution on the same 101 x 101 grid.
Compute and print the max absolute error between the numerical and exact solutions.
Compute and print the L2 error between the numerical and exact solutions using the same discrete norm formula.
