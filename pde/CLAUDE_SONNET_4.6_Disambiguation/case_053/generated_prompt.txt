Solve the Klein-Gordon PDE numerically as specified below.

The PDE is u_tt - (0.8)**2 * (u_xx + u_yy) + (0.2)**2 * u = 0.
The spatial domain is (x,y) in [0,1] x [0,1] and the time domain is t in [0, 1.0].
Use Dirichlet boundary conditions u=0 on all four boundaries.
The initial condition is u(x,y,0) = sin(2*pi*x)*sin(pi*y) and u_t(x,y,0) = 0.
The exact solution for verification is u(x,y,t) = cos(sqrt((0.8)**2*((2*pi)**2 + (pi)**2) + (0.2)**2)*t) * sin(2*pi*x) * sin(pi*y).

Use a uniform grid with Nx=Ny=160 intervals, giving Nx+1=161 grid points in each direction including both endpoints.

The wave speed is c = 0.8.

Set Nt = ceil(1.0 / dt0) and then dt = 1.0 / Nt so the final time T=1.0 is hit exactly.
Use the 5-point Laplacian stencil for the spatial second derivatives u_xx + u_yy.
Use second-order central differencing in time for u_tt.

Enforce u=0 on all boundary points at every time step.

At T=1.0, compute u on the full 2D grid.
