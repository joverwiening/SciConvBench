Solve the PDE u_t = -k * d/dx(cos(u)) numerically using the specifications below.

Use k = 1.0.

The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].

Use a uniform periodic grid with Nx = 1024 points on [0, 1).
Define dx = 1.0 / Nx.
Define grid points as x_j = j * dx for j = 0, 1, ..., Nx-1.

The initial condition is u(x, 0) = 0.5 * sin(2 * pi * x).
Apply periodic boundary conditions: u(0, t) = u(1, t) for all t.

Use a conservative finite-volume spatial discretization with Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u) = cos(u).
The derivative of the flux is f'(u) = -sin(u).
The Rusanov wave speed at each interface is alpha = max(|sin(u_L)|, |sin(u_R)|), which is bounded by 1.
The Rusanov numerical flux at interface between cell j and cell j+1 is:
F_{j+1/2} = 0.5 * (f(u_L) + f(u_R)) - 0.5 * alpha * (u_R - u_L)
where u_L = u[j] and u_R = u[j+1] (with periodic indexing).
The spatial update for cell j is: du_j = -(F_{j+1/2} - F_{j-1/2}) / dx.

Use SSP-RK2 (Heun's method) for time integration.
SSP-RK2 stage 1: u_star = u^n + dt * L(u^n).
SSP-RK2 stage 2: u^{n+1} = 0.5 * u^n + 0.5 * (u_star + dt * L(u_star)).
Here L(u) denotes the spatial right-hand side operator giving du/dt = L(u).

Compute the time step as follows.
Set CFL = 0.2.
Set dt0 = CFL * dx / 1.0.
Set Nt = ceil(T / dt0) where T = 0.2.
Set dt = T / Nt.

Advance the solution from t = 0 to t = 0.2 using Nt steps of size dt.

At the end of the simulation, output the array of x values (length 1024) and the corresponding array of u values at t = 0.2.

No closed-form reference solution is required for verification.

Use Python with NumPy. Use '**' for exponentiation in code. Treat all trigonometric functions as operating in radians.
