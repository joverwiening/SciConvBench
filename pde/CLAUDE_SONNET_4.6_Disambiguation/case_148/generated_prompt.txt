Solve the 1D viscous Burgers equation u_t + d/dx(0.5*u^2) = nu*u_xx numerically using the specifications below.

The spatial domain is [0,1) with periodic boundary conditions.
Use Nx = 512 grid points with no duplicated endpoint; dx = 1.0/512; x_i = i*dx for i = 0, 1, ..., 511.
Set nu = 0.4.
Set the final time T = 1.0.
Use the initial condition u(x,0) = sin(2*pi*x).

Compute the time step as follows: set CFL = 0.4, dt0 = CFL*dx/1.0, Nt = ceil(T/dt0), then reset dt = T/Nt so the final time is hit exactly.

Advance the solution using Strang splitting for each full time step dt.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt) for the inviscid Burgers equation u_t + d/dx(0.5*u**2) = 0 using a finite-volume Rusanov (local Lax-Friedrichs) flux: define f(u) = 0.5*u**2. For each interface between u_left = u[j] and u_right = u[j+1] (with periodic indexing), compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j, compute F_plus = flux between (u[j], u[j+1]) and F_minus = flux between (u[j-1], u[j]), then set u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus). Replace u with u_new after the advection substep.

Step C (diffusion half-step again): repeat Step A identically.

After completing all Nt time steps, compute and print min(u), max(u), mean(u) (the discrete mean, which should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx).
