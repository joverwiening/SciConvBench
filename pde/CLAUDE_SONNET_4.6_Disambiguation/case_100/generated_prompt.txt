Solve the 2D wave equation u_tt = u_xx + u_yy numerically with the following specifications.

Domain is (x,y) in [0,1) x [0,1), periodic in both directions, t in [0, 0.5].

Use a uniform periodic grid with Nx=Ny=128 points. dx = dy = 1/128. Grid points are x_i = i*dx for i=0..127, y_j = j*dy for j=0..127. No duplicated endpoints.

Boundary conditions are periodic in both x and y: use wrap-around indexing.

Spatial discretization uses 2nd-order central finite differences with periodic (wrap-around) stencil: u_xx at (i,j) = (u[i-1,j] - 2*u[i,j] + u[i+1,j]) / dx**2 with indices taken mod Nx, similarly for u_yy.

Time integration uses 2nd-order central differences (leapfrog).

Compute dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)). Set Nt = ceil(0.5 / dt0). Set dt = 0.5 / Nt so the final time T=0.5 is hit exactly.

Advance all subsequent steps using the leapfrog update: u_next = 2*u_curr - u_prev + dt**2 * c**2 * (u_xx + u_yy).

At T=0.5, compute the exact solution u_exact(x,y,T) = cos(2*pi*x)*cos(2*pi*y)*cos(1.0*2*pi*sqrt(2)*T) on the same grid.

Store the numerical solution in a 2D array u with shape (Ny, Nx) such that u[j,i] = u(x_i, y_j).

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) of the numerical solution at T.
