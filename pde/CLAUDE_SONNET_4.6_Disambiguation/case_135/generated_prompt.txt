Solve the 1D advection PDE u_t + beta * u_x = 0 numerically in Python.

The spatial domain is the half-open interval [0, 1) with periodic boundary conditions.
The time domain is [0, T] where T = 2.0.
The parameter beta = 0.1.

Use Nx = 512 grid points with no duplicated endpoint.
Compute dx = 1.0 / Nx.
Set x_i = i * dx for i = 0, 1, ..., Nx-1.

Apply the initial condition u(x, 0) = sin(2*pi*x) + 0.5*sin(4*pi*x) at all grid points.

Use 1st-order upwind finite difference for the spatial derivative u_x.
Since beta > 0, the upwind direction is left, so approximate u_x at point i as (u[i] - u[i-1]) / dx, with index i-1 taken modulo Nx to enforce periodicity.

Use explicit forward Euler for time integration.
Set CFL = 0.5.
Set dt = CFL * dx / abs(beta).
Set Nt = ceil(T / dt).
Reset dt = T / Nt so the final time T = 2.0 is hit exactly.

At each time step, update u using: u[i] = u[i] - beta * dt / dx * (u[i] - u[i-1 mod Nx]) for all i.

After Nt steps, the solution u represents u(x, T).

Compute the reference solution u_ref[i] = sin(2*pi*((x_i - beta*T) mod 1)) + 0.5*sin(4*pi*((x_i - beta*T) mod 1)) at each grid point.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
Print the max absolute error max(abs(u - u_ref)) and the L2 error sqrt(sum((u - u_ref)**2) * dx).

Save a file named "solution_pdebench_advection_beta0p1.npz" containing the following arrays and scalars: x (1D array of length Nx), u (1D array of length Nx), beta (scalar), T (scalar), dx (scalar), dt (scalar), Nx (scalar), Nt (scalar).
