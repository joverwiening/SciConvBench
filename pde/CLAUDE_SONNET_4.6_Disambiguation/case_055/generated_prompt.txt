Solve the Klein-Gordon PDE numerically using the specifications below.

The PDE is u_tt - (1.0)**2 * u_xx + (1.0)**2 * u + (1.0) * u**3 = 0.
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
Parameters are c = 1.0, m = 1.0, lambda = 1.0.
Use Nx = 512 uniform grid points on [0,1) with no duplicated endpoint.
Set dx = 1.0 / 512.
Set x_i = i * dx for i = 0, 1, ..., 511.
Use dt = 0.0005 and take 4000 time steps to reach T = 2.0.
Apply initial condition u(x, 0) = 0.1 * cos(2 * pi * x).
Apply initial condition u_t(x, 0) = 0.
Use 2nd-order central differences with wrap-around (periodic) for u_xx.
Use the leapfrog time integration scheme for u_tt.
Treat the nonlinear term u**3 explicitly at time level n.
Initialize the first step using a Taylor expansion: u^1 = u^0 + dt * u_t^0 + 0.5 * dt**2 * (c**2 * u_xx^0 - m**2 * u^0 - lambda * (u^0)**3).
At each subsequent time step n (from 1 to 3999), compute u_xx at level n using central differences with wrap-around.
Update using leapfrog: u^(n+1) = 2 * u^n - u^(n-1) + dt**2 * (c**2 * u_xx^n - m**2 * u^n - lambda * (u^n)**3).
After all time steps, extract u(x, T=2.0) as the final 1D array of length 512.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T = 2.0.
Save a file named "solution_agent_kg_08.npz" containing the array x (1D, length 512), the array u (1D, length 512), and scalar metadata T = 2.0, dx, dt.
Save a line plot of u(x, T=2.0) as "solution_agent_kg_08.png" with x on the horizontal axis and u on the vertical axis.
Use Python with numpy for computation and matplotlib for plotting.
Interpret ^ as exponentiation and use ** in Python code for powers.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Parameters
c = 1.0
m = 1.0
lam = 1.0
Nx = 512
dx = 1.0 / Nx
x = np.arange(Nx) * dx  # x_i = i*dx, i=0..511
dt = 0.0005
Nt = 4000  # 4000 steps -> T = 2.0
T = Nt * dt  # should be 2.0

# Initial conditions
u0 = 0.1 * np.cos(2 * np.pi * x)
ut0 = np.zeros(Nx)

# Function to compute u_xx with periodic wrap-around (2nd-order central differences)
def compute_uxx(u, dx):
    u_xx = (np.roll(u, -1) - 2.0 * u + np.roll(u, 1)) / dx**2
    return u_xx

# Taylor start for first step
uxx0 = compute_uxx(u0, dx)
rhs0 = c**2 * uxx0 - m**2 * u0 - lam * u0**3
u_prev = u0.copy()
u_curr = u0 + dt * ut0 + 0.5 * dt**2 * rhs0

# Leapfrog time integration
for n in range(1, Nt):
    uxx_curr = compute_uxx(u_curr, dx)
    rhs_curr = c**2 * uxx_curr - m**2 * u_curr - lam * u_curr**3
    u_next = 2.0 * u_curr - u_prev + dt**2 * rhs_curr
    u_prev = u_curr
    u_curr = u_next

u_final = u_curr

# Diagnostics
u_min = np.min(u_final)
u_max = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)
print(f"min(u) = {u_min:.6e}")
print(f"max(u) = {u_max:.6e}")
print(f"L2 norm = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_kg_08.npz", x=x, u=u_final, T=T, dx=dx, dt=dt)

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_final, linewidth=1.0)
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=2.0)")
ax.set_title("Klein-Gordon solution at T=2.0")
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_kg_08.png", dpi=150)
plt.close()

print("Files saved: solution_agent_kg_08.npz, solution_agent_kg_08.png")
```
