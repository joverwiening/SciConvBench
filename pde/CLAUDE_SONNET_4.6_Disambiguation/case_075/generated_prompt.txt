Solve the Poisson PDE u_xx + u_yy = f(x,y) numerically with the following specifications.

The PDE is u_xx + u_yy = f(x,y) where f(x,y) = -5*pi**2*sin(2*pi*x)*sin(pi*y).
The spatial domain is (x,y) in [0,1] x [0,1].
Apply Dirichlet boundary conditions u=0 on all four edges of the domain.
The exact reference solution is u(x,y) = sin(2*pi*x)*sin(pi*y).

Use a uniform grid with Nx=Ny=120 intervals in each direction, giving Nx+1=121 grid points per direction including both endpoints.
Set dx = dy = 1/120.
Define grid points as x_i = i*dx for i=0..120 and y_j = j*dy for j=0..120.

Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on interior nodes only.
Assemble the resulting sparse linear system for all interior nodes.
Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Set boundary values to zero in the solution array.

Store the solution in a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x_i, y_j).

Save the file "solution_agent_poisson_02.npz" containing the 1D array x, the 1D array y, the 2D array u, and metadata scalars dx and dy.
Save a heatmap or contour plot of u(x,y) as "solution_agent_poisson_02.png".

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy).
Evaluate the exact solution u_exact(x_i, y_j) = sin(2*pi*x_i)*sin(pi*y_j) on the same grid.
Compute and print the max absolute error and the discrete L2 error between the numerical solution and the exact solution.
