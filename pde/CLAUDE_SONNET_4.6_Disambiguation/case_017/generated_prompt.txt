Solve the PDE u_t = ∂/∂x( D(x) * u_x ) where D(x) = 0.1*(1 + x) numerically using the specifications below.

Domain: x in [0,1], t in [0,0.5].

Initial condition: u(x,0) = sin(pi*x).

Boundary conditions: Dirichlet, u(0,t) = 0 and u(1,t) = 0 for all t.

Use Nx=300 uniform intervals on [0,1], giving 301 grid points including both endpoints.
Set dx = 1/300 and x_i = i*dx for i=0,1,...,300.

Use dt=0.001 and take 500 time steps to reach T=0.5.

Define D_i = 0.1*(1 + x_i) at each grid point.
Define face diffusion coefficients by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}) for i=0,...,299.

For interior nodes i=1,...,299, discretize the diffusion operator as (1/dx**2) * [ D_{i+1/2}*(u_{i+1} - u_i) - D_{i-1/2}*(u_i - u_{i-1}) ].

Apply implicit Euler time integration: at each step solve the sparse linear system (I - dt*L) u^{n+1} = u^n, where L encodes the discrete variable-coefficient diffusion operator above for interior nodes.

Enforce Dirichlet boundary conditions u_0 = 0 and u_300 = 0 at every time step by fixing those rows in the linear system (identity row with right-hand side 0).

After 500 steps, compute u(x, T=0.5) on the full 301-point grid.

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.

Save "solution_agent_diffusion_01.npz" containing: x (1D array of length 301), u (1D array of length 301), and metadata scalars T=0.5, dx=1/300, dt=0.001.

Save a line plot of u(x, T=0.5) as "solution_agent_diffusion_01.png".
