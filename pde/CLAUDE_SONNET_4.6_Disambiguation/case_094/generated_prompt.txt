Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically using the specifications below.

The PDE is u_tt = c^2 * u_xx where c = 1.0.
The spatial domain is x in [0,1] (closed interval) and the time domain is t in [0, 0.25].
Use Nx = 800 uniform intervals giving Nx+1 = 801 grid points including both endpoints.
Set dx = 1.0 / 800.
Compute dt0 = 0.9 * dx / c.
Set Nt = ceil(0.25 / dt0) and then dt = 0.25 / Nt so the final time T = 0.25 is hit exactly.
Apply Dirichlet boundary conditions u = 0 at x = 0 and x = 1 at every time step.
Set the initial condition u(x, 0) = sin(4 * pi * x) at all interior and boundary grid points.
Set the initial velocity u_t(x, 0) = 0 everywhere.
Use the Taylor start to compute u at t = dt: u^1 = u^0 + dt * 0 + 0.5 * dt**2 * c**2 * u_xx^0, where u_xx^0 is computed via 2nd-order central differences on the interior nodes of u^0.
Enforce boundary conditions u^1[0] = 0 and u^1[Nx] = 0 after the Taylor start.
For all subsequent time steps n >= 1 up to Nt, advance using the leapfrog scheme: u^{n+1}[i] = 2 * u^n[i] - u^{n-1}[i] + (c * dt / dx)**2 * (u^n[i+1] - 2 * u^n[i] + u^n[i-1]) for interior nodes i = 1 to Nx-1.
Enforce boundary conditions u^{n+1}[0] = 0 and u^{n+1}[Nx] = 0 at every leapfrog step.
After completing all Nt time steps, the solution array u holds u(x, T=0.25).
Compute the exact solution u_exact[i] = cos(1.0 * 4 * pi * T) * sin(4 * pi * x[i]) on the same grid.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).
Save a file named "solution_agent_wave_13.npz" containing arrays x (1D, length 801), u (1D, length 801), and scalar metadata T = 0.25, dx, dt.
Save a line plot of u(x, T) versus x as "solution_agent_wave_13.png" with x on the horizontal axis and u on the vertical axis.
Use Python with numpy for numerics and matplotlib for the plot.
Interpret ^ as exponentiation and use ** in Python code for powers.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
c = 1.0
T = 0.25
Nx = 800
dx = 1.0 / Nx
CFL_target = 0.9
dt0 = CFL_target * dx / c
Nt = math.ceil(T / dt0)
dt = T / Nt

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL={c*dt/dx:.6f}")

# Grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 801 points

# Initial condition
u0 = np.sin(4 * np.pi * x)
v0 = np.zeros(Nx + 1)

# Enforce Dirichlet BCs on initial condition (should already be 0 at endpoints)
u0[0] = 0.0
u0[Nx] = 0.0

# Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0
# Compute u_xx^0 at interior nodes via central differences
r = (c * dt / dx) ** 2  # CFL^2

u_prev = u0.copy()

# u^1 using Taylor start
u_curr = np.zeros(Nx + 1)
# Interior nodes
u_curr[1:Nx] = (u_prev[1:Nx]
                + dt * v0[1:Nx]
                + 0.5 * dt**2 * c**2 * (u_prev[2:Nx+1] - 2*u_prev[1:Nx] + u_prev[0:Nx-1]) / dx**2)
# Boundary conditions
u_curr[0] = 0.0
u_curr[Nx] = 0.0

# Leapfrog time stepping
for n in range(1, Nt):
    u_next = np.zeros(Nx + 1)
    # Interior nodes
    u_next[1:Nx] = (2.0 * u_curr[1:Nx]
                    - u_prev[1:Nx]
                    + r * (u_curr[2:Nx+1] - 2.0*u_curr[1:Nx] + u_curr[0:Nx-1]))
    # Boundary conditions
    u_next[0] = 0.0
    u_next[Nx] = 0.0
    # Advance
    u_prev = u_curr
    u_curr = u_next

u = u_curr

# Exact solution
u_exact = np.cos(1.0 * 4 * np.pi * T) * np.sin(4 * np.pi * x)

# Diagnostics
min_u = np.min(u)
max_u = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx)
max_abs_error = np.max(np.abs(u - u_exact))
l2_error = np.sqrt(np.sum((u - u_exact)**2) * dx)

print(f"min(u)       = {min_u:.6e}")
print(f"max(u)       = {max_u:.6e}")
print(f"L2 norm      = {l2_norm:.6e}")
print(f"Max abs error= {max_abs_error:.6e}")
print(f"L2 error     = {l2_error:.6e}")

# Save npz
np.savez("solution_agent_wave_13.npz", x=x, u=u, T=T, dx=dx, dt=dt)
print("Saved solution_agent_wave_13.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u, label=f"Numerical u(x, T={T})", color="blue", linewidth=1.5)
ax.plot(x, u_exact, label="Exact solution", color="red", linestyle="--", linewidth=1.5)
ax.set_xlabel("x")
ax.set_ylabel("u")
ax.set_title(f"Wave equation solution at T={T}")
ax.legend()
ax.grid(True)
plt.tight_layout()
plt.savefig("solution_agent_wave_13.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_13.png")
```
