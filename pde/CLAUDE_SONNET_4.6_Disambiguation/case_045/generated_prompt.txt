Solve the 2D heat equation u_t = 0.05 * (u_xx + u_yy) numerically using the following specifications.

Domain: x in [0,1] (Dirichlet), y in [0,1) (periodic), t in [0,0.3].

Parameters: alpha = 0.05.

Grid: Use Nx=60 uniform intervals in x, giving 61 grid points including both endpoints; dx = 1/60; x_i = i*dx for i=0..60. Use Ny=64 uniform points in y (periodic, no duplicated endpoint); dy = 1/64; y_j = j*dy for j=0..63.

Time stepping: dt=0.001, 300 steps, from t=0 to t=0.3.

Initial condition: set u(x,y,0) = sin(pi*x)*cos(2*pi*y) evaluated on the full 2D grid.

Boundary conditions: Dirichlet in x: u(0,y,t)=0 and u(1,y,t)=0 for all t. Periodic in y: wrap-around using periodic finite differences.

Spatial discretization: use second-order central differences on the tensor grid. In x, apply standard 3-point stencil with Dirichlet boundary rows zeroed out. In y, apply standard 3-point stencil with periodic wrap (y_{-1} = y_{Ny-1}, y_{Ny} = y_0).

Assemble the full 2D Laplacian operator L as a sparse matrix acting on the interior+boundary degrees of freedom in x and all Ny points in y. Use Kronecker products: L = I_y ⊗ Lx + Ly ⊗ I_x, where Lx is the (Nx+1)x(Nx+1) tridiagonal matrix with Dirichlet rows and Ly is the Ny×Ny circulant matrix for periodic second differences.

Time integration: Implicit Euler. At each step solve (I - dt*alpha*L) * u_new = u_old as a linear system. Enforce Dirichlet boundary conditions by fixing rows corresponding to x=0 and x=1 to zero after each solve (or by modifying those rows in the system matrix to be identity rows with zero right-hand side).

Exact/reference solution: u_exact(x,y,t) = exp(-0.05*((pi**2) + (2*pi)**2)*t) * sin(pi*x) * cos(2*pi*y).

At T=0.3, compute the numerical solution u on the 2D grid with shape (Ny, Nx+1) so that u[j,i] = u(x_i, y_j).

Print the following scalars at T=0.3:
- min(u)
- max(u)
- discrete L2 norm: sqrt(sum(u**2)*dx*dy)
- max absolute error vs exact solution on the same grid
- L2 error vs exact solution: sqrt(sum((u - u_exact)**2)*dx*dy)
