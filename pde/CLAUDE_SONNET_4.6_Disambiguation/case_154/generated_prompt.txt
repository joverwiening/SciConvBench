Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u**2) = nu * u_xx numerically.
The spatial domain is [0,1), half-open and periodic.
Use Nx = 512 grid points with no duplicated endpoint.
Set dx = 1.0/512.
Set x_j = j*dx for j = 0, 1, ..., 511.
Set nu = 0.004.
Set the final time T = 1.0.
Apply the initial condition u(x,0) = sin(2*pi*x).
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.

Compute the time step as follows.
Set CFL = 0.4 and estimated max speed = 1.0.
Set dt0 = CFL * dx / 1.0.
Set Nt = ceil(T / dt0).
Set dt = T / Nt so the final time T is hit exactly.

Advance the solution using Strang splitting for each full time step dt.

Substep A (diffusion half-step, duration dt/2):
Compute u_hat = FFT(u).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)).
Set u = real(IFFT(u_hat)).

Substep B (advection full-step, duration dt) using finite-volume Rusanov flux:
Define f(u) = 0.5 * u**2.
For each interface between cell j (u_left = u[j]) and cell j+1 (u_right = u[j+1], with periodic indexing):
  Set alpha = max(abs(u_left), abs(u_right)).
  Set F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j:
  Set F_plus = flux at interface between u[j] and u[j+1].
  Set F_minus = flux at interface between u[j-1] and u[j].
  Set u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.

Substep C (diffusion half-step again, identical to Substep A).

After all Nt time steps, compute and print the following diagnostics at time T:
Print min(u).
Print max(u).
Print the discrete mean value mean(u) (should be approximately conserved).
Print the discrete L2 norm sqrt(sum(u**2)*dx).

Save the file "solution_pdebench_burgers_nu4em3.npz" containing the following arrays and scalars:
  x: 1D array of length Nx (the grid points).
  u: 1D array of length Nx (the solution at time T).
  nu: scalar, value 0.004.
  T: scalar, value 1.0.
  dx: scalar, value 1.0/512.
  dt: scalar, the computed time step.
  Nx: scalar, value 512.
  Nt: scalar, the computed number of time steps.

Save a line plot of u(x,T) as "solution_pdebench_burgers_nu4em3.png".
