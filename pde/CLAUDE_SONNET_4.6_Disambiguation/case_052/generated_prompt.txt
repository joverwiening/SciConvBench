Solve the Klein-Gordon PDE numerically as specified below.

The PDE is u_tt - (1.0)**2 * (u_xx + u_yy) + (1.0)**2 * u = 0, where c = 1.0 and m = 1.0.
The spatial domain is (x, y) in [0, 1] x [0, 1] and the time domain is t in [0, 0.8].
Use Dirichlet boundary conditions u = 0 on all boundaries.
Set the initial condition u(x, y, 0) = sin(pi*x) * sin(pi*y) and u_t(x, y, 0) = 0.
The exact solution for verification is u(x, y, t) = cos(sqrt((1.0)**2 * (2 * pi**2) + (1.0)**2) * t) * sin(pi*x) * sin(pi*y).

Use Nx = Ny = 256 uniform intervals so there are 257 grid points in each direction including both endpoints.
Set dx = 1.0 / 256 and dy = 1.0 / 256.
Set x_i = i * dx for i = 0, 1, ..., 256 and y_j = j * dy for j = 0, 1, ..., 256.
Set c = 1.0.
Compute dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)).
Set Nt = ceil(0.8 / dt0) and then dt = 0.8 / Nt so the final time T = 0.8 is hit exactly.

Use the 5-point Laplacian stencil for u_xx + u_yy on the interior points.
Use 2nd-order central differencing in time for u_tt.
Initialize the first time step using a Taylor expansion: u(x, y, dt) = u(x, y, 0) + dt * u_t(x, y, 0) + 0.5 * dt**2 * (c**2 * (u_xx + u_yy) - m**2 * u) evaluated at t=0, where u_t(x, y, 0) = 0, so u^1 = u^0 + 0.5 * dt**2 * (c**2 * Laplacian(u^0) - m**2 * u^0).
Enforce u = 0 on all boundary points at every time step.

After advancing to T = 0.8, compute the numerical solution u(x, y, T) on the full 257 x 257 grid.
Save a file named "solution_agent_kg_05.npz" containing: x as a 1D array of length 257, y as a 1D array of length 257, u as a 2D array of shape (257, 257) where u[j, i] = u(x_i, y_j) at T, and scalar metadata T = 0.8, dx, dy, dt.
Save a heatmap or filled contour plot of u(x, y, T) as "solution_agent_kg_05.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx * dy) at T.
Evaluate the exact solution on the same grid at T = 0.8 and print the max absolute error and the discrete L2 error between the numerical and exact solutions.
