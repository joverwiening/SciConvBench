Solve the ODE du/dt = a*t*sin(u) numerically using the specifications below.

The ODE is du/dt = a*t*sin(u) where sin is evaluated in radians.
The parameter a = 0.8.
The time domain is t in [0.0, 5.0].
Use an initial condition of u(0) = 1.0 (assumed standard; no initial condition was specified, so use u(0) = 1.0).
Use Classical 4th-order Runge-Kutta (RK4) with a fixed step size dt = 0.001 and Nt = 5000 steps so the final time t = 5.0 is hit exactly.
Compute u(t) at all time points t_n = 0.0 + n*0.001 for n = 0 to 5000, producing arrays of length 5001.
Save a file named "solution_molk_004.npz" containing: a 1D array t of length 5001, a 1D array u of length 5001, and the scalar parameter a = 0.8.
Save a line plot of u(t) vs t as "solution_molk_004.png".
Print the value of u at the final time T = 5.0, the minimum of u over the time grid, and the maximum of u over the time grid.
No exact solution is provided, so skip the error computation step.
Use Python with numpy for numerics and matplotlib for plotting.
Interpret '^' as exponentiation and use '**' for powers in Python code.

```python
import numpy as np
import matplotlib.pyplot as plt

# Parameters
a = 0.8
t0 = 0.0
T = 5.0
dt = 0.001
Nt = 5000
u0 = 1.0

# Time array
t = np.linspace(t0, T, Nt + 1)  # length Nt+1 = 5001

# ODE right-hand side
def f(t_val, u_val):
    return a * t_val * np.sin(u_val)

# RK4 integration
u = np.zeros(Nt + 1)
u[0] = u0

for n in range(Nt):
    tn = t[n]
    un = u[n]
    k1 = f(tn,          un)
    k2 = f(tn + dt/2.0, un + dt/2.0 * k1)
    k3 = f(tn + dt/2.0, un + dt/2.0 * k2)
    k4 = f(tn + dt,     un + dt      * k3)
    u[n + 1] = un + (dt / 6.0) * (k1 + 2.0*k2 + 2.0*k3 + k4)

# Save npz
np.savez("solution_molk_004.npz", t=t, u=u, a=np.float64(a))

# Save plot
plt.figure(figsize=(8, 5))
plt.plot(t, u, linewidth=1.2, color='steelblue')
plt.xlabel("t")
plt.ylabel("u(t)")
plt.title("Solution of du/dt = a·t·sin(u),  a = 0.8")
plt.tight_layout()
plt.savefig("solution_molk_004.png", dpi=150)
plt.close()

# Print diagnostics
print(f"u(T=5.0)  = {u[-1]:.10f}")
print(f"min(u)    = {np.min(u):.10f}")
print(f"max(u)    = {np.max(u):.10f}")
```
