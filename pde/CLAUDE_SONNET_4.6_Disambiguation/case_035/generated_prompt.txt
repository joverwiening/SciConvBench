Solve the heat equation u_t = 0.1 * u_xx numerically using the Crank-Nicolson method and save the results.

PDE is u_t = 0.1 * u_xx with alpha = 0.1.
The spatial domain is x in [0, 1] (closed interval) and the time domain is t in [0, 0.5].
Use Nx = 200 uniform intervals, giving 201 grid points including both endpoints, with dx = 1/200 = 0.005.
Use dt = 0.001 and run for 500 time steps to reach T = 0.5.
Grid points are x_i = i * dx for i = 0, 1, ..., 200.

The exact solution is u(x, t) = 1 - x, which is steady since u_xx = 0 everywhere.
Use this as the initial condition: u(x, 0) = 1 - x.
Apply Dirichlet boundary conditions consistent with the exact solution: u(0, t) = 1 and u(1, t) = 0 at every time step.

Discretize u_xx in the interior using 2nd-order central differences: (u_{i-1} - 2*u_i + u_{i+1}) / dx**2.
Apply Crank-Nicolson time integration: the diffusion term is averaged equally between the current time level n and the next time level n+1.
At each time step, fix the boundary nodes u_0 = 1 and u_{200} = 0 by removing them from the linear system and incorporating them into the right-hand side.
Solve the resulting tridiagonal linear system at each time step for the interior nodes i = 1, ..., 199.
