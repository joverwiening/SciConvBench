Solve the 1D Reaction-Diffusion PDE numerically with the following specifications.

PDE: u_t = nu * u_xx + rho * u*(1 - u)

Spatial domain: x in [0, 1) with periodic boundary conditions.
Temporal domain: t in [0, 1.0].

Parameters: nu = 10.0, rho = 5.0.

Boundary condition: Periodic, u(0,t) = u(1,t) for all t.

Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).

Spatial grid: Uniform periodic grid with Nx = 512 points on [0,1). Use x_j = j*dx for j = 0,...,511 with dx = 1/512.

Time grid: Use fixed dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Numerical method: Strang splitting applied at each full time step dt.

Step A (Diffusion half-step, duration dt/2): Compute u_hat = FFT(u). Compute wavenumbers k = 2*pi*fftfreq(Nx, d=dx). Multiply u_hat(k) by exp(-nu * k**2 * (dt/2)). Set u = real(IFFT(u_hat)).

Step B (Reaction full-step, duration dt): Apply the exact pointwise logistic ODE update du/dt = rho * u*(1 - u). For each grid point update u as u = (u * exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).

Step C (Diffusion half-step again): Repeat Step A identically with duration dt/2.

Repeat Steps A, B, C for all Nt = 1000 time steps.

Output: Compute u(x, T=1.0) on the periodic grid of length Nx = 512.

Save a file named "solution_pdebench_reacdiff_nu10_rho5.npz" containing the following arrays and scalars: x (1D array of length 512), u (1D array of length 512), nu (scalar 10.0), rho (scalar 5.0), T (scalar 1.0), dx (scalar 1/512), dt (scalar 0.001), Nx (scalar 512), Nt (scalar 1000).

Save a line plot of u(x, T=1.0) as "solution_pdebench_reacdiff_nu10_rho5.png".

Print the following scalar diagnostics at T=1.0: min(u), max(u), mean(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx).

Use Python with numpy and matplotlib. Use numpy.fft.fft, numpy.fft.ifft, and numpy.fft.fftfreq for the Fourier operations. Take the real part after each IFFT step.
