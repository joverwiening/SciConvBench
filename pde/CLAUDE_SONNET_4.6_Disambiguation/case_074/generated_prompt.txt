Solve the Poisson PDE numerically with the following specifications.

PDE: u_xx + u_yy = f(x,y), where f(x,y) = -2*pi**2*sin(pi*x)*sin(pi*y).
Unknown field: u(x,y).
Domain: (x,y) in [0,1] x [0,1].
Boundary conditions: Dirichlet u=0 on all four edges.
Exact solution for verification: u(x,y) = sin(pi*x)*sin(pi*y).

Grid: Use Nx=Ny=120 uniform intervals in each direction.
Grid points: Nx+1=121 points in x, Ny+1=121 points in y, including both endpoints.
dx = dy = 1/120.
x_i = i*dx for i=0..120.
y_j = j*dy for j=0..120.

Spatial discretization: Discretize the Laplacian using the standard 5-point stencil (2nd-order finite differences) on the interior nodes only.
Linear solver: Assemble the resulting sparse linear system and solve it using scipy.sparse.linalg.spsolve.

Compute the steady-state solution u(x,y) on the full 2D grid (including boundary values, which are zero).
Store u as a 2D array of shape (121, 121) where u[j,i] = u(x_i, y_j).

Save a file named "solution_agent_poisson_01.npz" containing: x (1D array of length 121), y (1D array of length 121), u (2D array of shape (121,121)), dx (scalar), dy (scalar).
Save a heatmap or contour plot of u(x,y) as "solution_agent_poisson_01.png".

Print min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u**2)*dx*dy).
Compute the exact solution u_exact[j,i] = sin(pi*x_i)*sin(pi*y_j) on the same grid.
Print the max absolute error max(|u - u_exact|) and the discrete L2 error sqrt(sum((u - u_exact)**2)*dx*dy).

Use radians for all trigonometric functions.
Use ** for exponentiation in Python code.
