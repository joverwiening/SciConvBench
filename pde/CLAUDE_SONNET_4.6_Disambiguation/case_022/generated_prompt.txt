Solve the 2D diffusion PDE numerically using the specifications below.

PDE: u_t = 0.05 * (u_xx + u_yy)

Spatial domain: (x,y) in [0,1] x [0,1], closed interval in both dimensions.
Time domain: t in [0, 0.5].
Diffusion coefficient D = 0.05.

Initial condition: u(x,y,0) = exp(-80*((x-0.3)**2 + (y-0.7)**2)).

Boundary conditions: zero-flux Neumann (du/dn = 0) on all four boundary edges, implemented via ghost nodes.

Grid: Use Nx=Ny=80 uniform intervals, giving 81 grid points in each direction including both endpoints.
dx = 1.0/80, dy = 1.0/80.
x_i = i*dx for i=0..80, y_j = j*dy for j=0..80.

Spatial discretization: 5-point Laplacian on the interior nodes.
Apply zero Neumann BC using ghost nodes: for a boundary node, the ghost node value equals the interior neighbor value so that the centered difference gives zero normal derivative.
This means the Laplacian stencil at boundary nodes uses the reflected (ghost) value in place of the out-of-domain neighbor.

Time integration: Implicit Euler with dt=0.001, 500 steps total, reaching T=0.5.
At each time step solve the linear system (I - dt*D*L) * u_new = u_old, where L is the discrete Laplacian operator (with ghost-node Neumann BC incorporated).
Flatten the 2D grid into a 1D vector for the linear solve, then reshape back.

Output: compute u(x,y,T=0.5) on the full 81x81 grid.

Save file "solution_agent_diffusion_06.npz" containing:
x as a 1D array of length 81,
y as a 1D array of length 81,
u as a 2D array of shape (81, 81) where u[j,i] = u(x_i, y_j) at T=0.5,
scalar metadata T=0.5, dx=1/80, dy=1/80, dt=0.001.

Save a heatmap or filled-contour plot of u(x,y,T=0.5) as "solution_agent_diffusion_06.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) at T=0.5.

Compute total mass M = sum(u)*dx*dy at t=0 and at t=T=0.5.
Print M(0), M(T), and the relative change abs(M(T)-M(0))/abs(M(0)).
With zero-flux Neumann BC and pure diffusion, mass should be approximately conserved.
