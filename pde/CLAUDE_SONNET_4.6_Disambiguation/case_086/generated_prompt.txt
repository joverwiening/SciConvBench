Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically using the specifications below.

The PDE is u_tt = c^2 * u_xx with c = 1.0.
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0, T] with T = 1.0.
Use Nx = 512 grid points on [0,1) with no duplicated endpoint.
Set dx = 1.0 / Nx.
Set dt0 = 0.9 * dx / c.
Set Nt = ceil(T / dt0) and then dt = T / Nt so the final time T is hit exactly.
The spatial grid is x_i = i * dx for i = 0, 1, ..., Nx-1.

Discretize u_xx using 2nd-order central differences with periodic wrap-around: u_xx at index i = (u[i-1] - 2*u[i] + u[i+1]) / dx**2, where indices wrap modulo Nx.
Discretize u_tt using 2nd-order central difference in time: u_new[i] = 2*u[i] - u_old[i] + dt**2 * c**2 * u_xx[i].

Initialize u at t=0 using the exact solution: u(x, 0) = cos(2*pi*x).
Initialize u_t at t=0 using the exact time derivative: u_t(x, 0) = 2*pi*1.0*sin(2*pi*x)*(-1) = -2*pi*sin(2*pi*x). Note: d/dt[cos(2*pi*x)*cos(2*pi*t)] at t=0 = -2*pi*sin(2*pi*x).
Use a Taylor start to compute u at t=dt: u_1[i] = u_0[i] + dt * u_t(x_i, 0) + 0.5 * dt**2 * c**2 * u_xx_0[i], where u_xx_0 is the periodic Laplacian of u_0.

Advance the solution from t=dt to t=T using the leapfrog update for Nt-1 additional steps.

The exact reference solution at time T is u_exact(x, T) = cos(2*pi*x) * cos(2*pi*1.0*T).

After reaching t=T, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
Compute and print the max absolute error max(abs(u - u_exact)) and the L2 error sqrt(sum((u - u_exact)**2) * dx).

Save a line plot of u(x, T) as "solution_agent_wave_05.png" with x on the horizontal axis and u on the vertical axis.
