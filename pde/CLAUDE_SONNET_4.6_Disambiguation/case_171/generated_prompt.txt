Solve the 2D Darcy flow PDE numerically as described below.

The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (x,y) in (0,1) x (0,1).

The coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) with beta = 100.0.

Apply Dirichlet boundary conditions u = 0 on the entire boundary of (0,1) x (0,1).

Use a uniform Cartesian grid with N = 128 intervals in each direction, giving N+1 = 129 grid points per direction including both endpoints.
Set dx = dy = 1/N.
Set x_i = i*dx for i = 0, 1, ..., N and y_j = j*dy for j = 0, 1, ..., N.

Evaluate a(x,y) at each grid node (i,j) using x_i and y_j.

Compute face-centered harmonic mean coefficients as follows.
For the east face: a(i+1/2, j) = 2*a(i,j)*a(i+1,j) / (a(i,j) + a(i+1,j)).
For the west face: a(i-1/2, j) = 2*a(i-1,j)*a(i,j) / (a(i-1,j) + a(i,j)).
For the north face: a(i, j+1/2) = 2*a(i,j)*a(i,j+1) / (a(i,j) + a(i,j+1)).
For the south face: a(i, j-1/2) = 2*a(i,j-1)*a(i,j) / (a(i,j-1) + a(i,j)).

For each interior node (i=1..N-1, j=1..N-1), discretize the PDE as:
-(1/dx**2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.

Assemble the resulting sparse linear system A*u_interior = b for the (N-1)*(N-1) interior unknowns, where b is a vector of ones.
Boundary values are zero and are incorporated into the right-hand side where needed (they contribute zero since u=0 on the boundary).

Solve the sparse linear system using the Conjugate Gradient (CG) method with a relative residual tolerance of 1e-10.
Optionally apply a Jacobi preconditioner (diagonal of A) to accelerate convergence.

After solving, assemble the full (N+1) x (N+1) solution array u, setting boundary entries to zero and filling interior entries from the CG solution.

Print min(u), max(u), and the discrete residual norm ||A*u_interior - b||_2 / ||b||_2.

Save a file named "solution_pdebench_darcy_beta100.npz" containing the following arrays: x (1D, length N+1), y (1D, length N+1), u (2D, shape [N+1, N+1]), and the scalars beta (100.0), N (128), and dx (1/128).

Save a heatmap or filled-contour plot of u(x,y) as "solution_pdebench_darcy_beta100.png".

Use Python with NumPy, SciPy (for sparse matrix assembly and CG solver), and Matplotlib (for the plot).
Use '**' for exponentiation in all Python code.
Use radians for all trigonometric function calls.
