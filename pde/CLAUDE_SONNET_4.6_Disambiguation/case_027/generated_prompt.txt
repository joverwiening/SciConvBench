Solve the PDE u_t = 0.01*(u_xx + u_yy) + 2.0*u*(1 - u) numerically as specified below.

The spatial domain is (x,y) in [0,1]x[0,1] and the time domain is t in [0,1.0].
Use D = 0.01 and r = 2.0.
Apply zero Neumann boundary conditions (∂u/∂n = 0) on all four boundary edges.

Use a uniform grid with Nx = Ny = 120 intervals, giving 121 x 121 grid points including both endpoints.
Set dx = dy = 1/120.
Use dt = 0.001 and Nt = 1000 time steps.

Set the initial condition to u(x,y,0) = 0.5 + 0.1*cos(pi*x)*cos(pi*y).

Discretize the Laplacian using the standard 5-point stencil on the interior.
Implement zero Neumann BCs via ghost nodes: mirror interior values across each boundary edge so that the normal derivative is zero.
Incorporate the ghost-node conditions directly into the discrete Laplacian matrix L so that boundary rows of L reflect the mirrored stencil.

At each time step apply the IMEX scheme: (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where R(u) = 2.0*u*(1 - u).
Flatten the 2D grid to a 1D vector of length (Nx+1)*(Ny+1) for the linear system.
Build L as a sparse matrix and use a sparse direct solver (e.g., scipy.sparse.linalg.spsolve) at each step.
