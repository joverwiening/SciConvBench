Solve the 2D Darcy flow PDE numerically as described below.

The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (x,y) in (0,1) x (0,1).
The coefficient function is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) with beta = 0.01.
Apply Dirichlet boundary conditions u = 0 on the entire boundary of (0,1) x (0,1).

Use a uniform Cartesian grid with N = 128 intervals in each direction, giving N+1 = 129 grid points per direction including both endpoints.
Set dx = dy = 1/N.
Set x_i = i*dx for i = 0, 1, ..., N and y_j = j*dy for j = 0, 1, ..., N.

Discretize the PDE at interior nodes (i=1..N-1, j=1..N-1) using 2nd-order finite differences with face-centered harmonic averaging of the variable coefficient.
The discrete equation at each interior node is -(1/dx**2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Compute face coefficients using harmonic means: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)), and analogously for all other faces.

Assemble the sparse linear system Au = b for the (N-1)*(N-1) interior unknowns only, with boundary values fixed at zero.
Solve the linear system using the Conjugate Gradient (CG) method to a relative residual tolerance of 1e-10.
A simple Jacobi preconditioner may optionally be used.

After solving, construct the full (N+1) x (N+1) solution array u(x,y) by placing the interior solution into the interior nodes and setting boundary nodes to zero.

Print min(u), max(u), and the discrete residual norm ||Au - b||_2 / ||b||_2 for the interior system.

Save a file named "solution_pdebench_darcy_beta0p01.npz" containing the following arrays: x (1D, length N+1), y (1D, length N+1), u (2D, shape [N+1, N+1]), and the scalars beta=0.01, N=128, dx=1/128.

Save a heatmap or filled-contour plot of u(x,y) as "solution_pdebench_darcy_beta0p01.png".
