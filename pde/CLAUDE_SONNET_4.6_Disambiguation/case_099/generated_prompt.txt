Solve the 1D wave equation u_tt = (1.0)^2 * u_xx numerically using the specifications below.

The PDE is u_tt = c^2 * u_xx where c = 1.0.
The spatial domain is x in [0,1] (closed interval). The time domain is t in [0,1.0].
Use Nx = 800 uniform intervals, giving Nx+1 = 801 grid points including both endpoints.
Set dx = 1.0 / 800.
Set dt0 = 0.9 * dx / c. Set Nt = ceil(1.0 / dt0). Set dt = 1.0 / Nt so the final time T=1.0 is hit exactly.
Build the spatial grid as x_i = i * dx for i = 0, 1, ..., 800.

Apply Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 at every time step.

Set the initial condition u(x, 0) = exp(-200 * (x - 0.5)^2) for all interior and boundary points.
Set u_t(x, 0) = 0 everywhere.

Compute u at time level 1 (t = dt) using the Taylor start formula: u^1_i = u^0_i + dt * 0 + 0.5 * dt^2 * c^2 * (u^0_{i-1} - 2*u^0_i + u^0_{i+1}) / dx^2 for all interior points i = 1 to 799.
Enforce u^1_0 = 0 and u^1_800 = 0.

For time steps n = 1, 2, ..., Nt-1, advance using the leapfrog scheme: u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (c*dt/dx)^2 * (u^n_{i-1} - 2*u^n_i + u^n_{i+1}) for all interior points i = 1 to 799.
Enforce u^{n+1}_0 = 0 and u^{n+1}_800 = 0 at every step.

After completing all Nt steps, the solution array u holds u(x, T=1.0).

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2) * dx) at T=1.0.

Save a file named "solution_agent_wave_18.npz" containing: array x (length 801, the spatial grid), array u (length 801, the solution at T=1.0), scalar T=1.0, scalar dx, scalar dt.

Save a line plot of u(x, T=1.0) versus x as "solution_agent_wave_18.png" with x on the horizontal axis and u on the vertical axis.

Use Python with numpy for computation and matplotlib for the plot. Use ** for exponentiation in code.

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import math

# Parameters
c = 1.0
T = 1.0
Nx = 800
dx = 1.0 / Nx
dt0 = 0.9 * dx / c
Nt = math.ceil(T / dt0)
dt = T / Nt
CFL = c * dt / dx

print(f"Nx={Nx}, dx={dx:.6e}, Nt={Nt}, dt={dt:.6e}, CFL={CFL:.6f}")

# Spatial grid
x = np.linspace(0.0, 1.0, Nx + 1)  # 801 points

# Initial condition
u0 = np.exp(-200.0 * (x - 0.5)**2)
u0[0] = 0.0
u0[Nx] = 0.0

v0 = np.zeros(Nx + 1)  # u_t(x,0) = 0

# CFL ratio squared
r2 = (c * dt / dx)**2

# Taylor start: u^1
u_prev = u0.copy()
u_curr = np.zeros(Nx + 1)

# Interior points
i = np.arange(1, Nx)  # 1 to 799
uxx0 = (u0[i-1] - 2.0*u0[i] + u0[i+1]) / dx**2
u_curr[i] = u0[i] + dt * v0[i] + 0.5 * dt**2 * c**2 * uxx0

# Boundary
u_curr[0] = 0.0
u_curr[Nx] = 0.0

# Leapfrog time stepping
u_next = np.zeros(Nx + 1)

for n in range(1, Nt):
    u_next[i] = (2.0 * u_curr[i] - u_prev[i]
                 + r2 * (u_curr[i-1] - 2.0*u_curr[i] + u_curr[i+1]))
    u_next[0] = 0.0
    u_next[Nx] = 0.0
    # Cycle arrays
    u_prev, u_curr, u_next = u_curr, u_next, u_prev

# u_curr now holds u(x, T=1.0)
u_final = u_curr

# Diagnostics
u_min = np.min(u_final)
u_max = np.max(u_final)
l2_norm = np.sqrt(np.sum(u_final**2) * dx)

print(f"min(u)    = {u_min:.6e}")
print(f"max(u)    = {u_max:.6e}")
print(f"L2 norm   = {l2_norm:.6e}")

# Save npz
np.savez("solution_agent_wave_18.npz",
         x=x,
         u=u_final,
         T=np.float64(T),
         dx=np.float64(dx),
         dt=np.float64(dt))
print("Saved solution_agent_wave_18.npz")

# Save plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, u_final, linewidth=1.0, color='steelblue')
ax.set_xlabel("x")
ax.set_ylabel("u(x, T=1.0)")
ax.set_title("Wave equation solution at T=1.0 (agent_wave_18)")
ax.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.savefig("solution_agent_wave_18.png", dpi=150)
plt.close()
print("Saved solution_agent_wave_18.png")
```
