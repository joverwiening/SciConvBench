Solve the 2D linear advection PDE numerically and save the results as specified.

The PDE is u_t + 1.0*u_x + 0.5*u_y = 0.
The spatial domain is [0,1) x [0,1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The advection speeds are a = 1.0 in x and b = 0.5 in y.
The initial condition is u(x,y,0) = sin(2*pi*x)*cos(2*pi*y).
The exact solution is u(x,y,t) = sin(2*pi*(x - 1.0*t))*cos(2*pi*(y - 0.5*t)).

Use a uniform periodic grid with Nx = Ny = 256 points on [0,1) x [0,1).
Set dx = dy = 1/256.
Grid points are x_i = i*dx for i = 0..255 and y_j = j*dy for j = 0..255.
Use 1st-order upwind finite differences in both x and y directions.
Since a = 1.0 > 0, the upwind x-derivative at point (i,j) is (u[j,i] - u[j,i-1]) / dx using periodic indexing.
Since b = 0.5 > 0, the upwind y-derivative at point (i,j) is (u[j,i] - u[j-1,i]) / dy using periodic indexing.
Use numpy roll or modular indexing to handle the periodic boundary.

Compute dt0 = 0.9 / (|a|/dx + |b|/dy).
Set Nt = ceil(T / dt0) where T = 1.0.
Set dt = T / Nt so the final time is hit exactly.

Use Forward Euler time integration: u_new = u - dt*(a*(u - u_shift_x)/dx + b*(u - u_shift_y)/dy).
Advance Nt steps from t=0 to t=T.

Store the solution u as a 2D array of shape (256, 256) where u[j, i] = u(x_i, y_j, T).
Store x as a 1D array of length 256 and y as a 1D array of length 256.

Save a file named "solution_agent_advection_04.npz" containing arrays x, y, u and scalars T, dx, dy, dt.
Save a heatmap or contour plot of u(x,y,T) as "solution_agent_advection_04.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) at T.
Evaluate the exact solution on the same grid at T.
Print the max absolute error and the L2 error between the numerical and exact solutions.

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Parameters
a = 1.0
b = 0.5
T = 1.0
Nx = 256
Ny = 256

# Grid
dx = 1.0 / Nx
dy = 1.0 / Ny
x = np.arange(Nx) * dx  # shape (Nx,)
y = np.arange(Ny) * dy  # shape (Ny,)

# Time stepping
dt0 = 0.9 / (abs(a) / dx + abs(b) / dy)
Nt = math.ceil(T / dt0)
dt = T / Nt

print(f"dx={dx}, dy={dy}, dt={dt}, Nt={Nt}")
print(f"CFL check: |a|*dt/dx + |b|*dt/dy = {abs(a)*dt/dx + abs(b)*dt/dy:.6f}")

# Initial condition: u[j, i] = u(x_i, y_j, 0)
X, Y = np.meshgrid(x, y)  # X shape (Ny, Nx), Y shape (Ny, Nx)
u = np.sin(2 * np.pi * X) * np.cos(2 * np.pi * Y)

# Time integration: Forward Euler with 1st-order upwind
# a > 0: upwind in x uses u[j,i] - u[j,i-1]
# b > 0: upwind in y uses u[j,i] - u[j-1,i]
for n in range(Nt):
    # Upwind differences (periodic)
    du_dx = (u - np.roll(u, 1, axis=1)) / dx  # axis=1 is x-direction
    du_dy = (u - np.roll(u, 1, axis=0)) / dy  # axis=0 is y-direction
    u = u - dt * (a * du_dx + b * du_dy)

# Exact solution at T
u_exact = np.sin(2 * np.pi * (X - a * T)) * np.cos(2 * np.pi * (Y - b * T))

# Diagnostics
u_min = np.min(u)
u_max = np.max(u)
l2_norm = np.sqrt(np.sum(u**2) * dx * dy)
max_err = np.max(np.abs(u - u_exact))
l2_err = np.sqrt(np.sum((u - u_exact)**2) * dx * dy)

print(f"min(u) = {u_min:.6f}")
print(f"max(u) = {u_max:.6f}")
print(f"L2 norm of u = {l2_norm:.6f}")
print(f"Max absolute error = {max_err:.6e}")
print(f"L2 error = {l2_err:.6e}")

# Save npz
np.savez("solution_agent_advection_04.npz",
         x=x, y=y, u=u,
         T=np.float64(T),
         dx=np.float64(dx),
         dy=np.float64(dy),
         dt=np.float64(dt))

# Save plot
fig, ax = plt.subplots(figsize=(7, 6))
cp = ax.contourf(X, Y, u, levels=50, cmap='RdBu_r')
fig.colorbar(cp, ax=ax, label='u(x,y,T)')
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.set_title(f'u(x,y,T=1.0) — 2D Advection (Upwind, Forward Euler)')
plt.tight_layout()
plt.savefig("solution_agent_advection_04.png", dpi=150)
plt.close()
print("Files saved: solution_agent_advection_04.npz, solution_agent_advection_04.png")
```
