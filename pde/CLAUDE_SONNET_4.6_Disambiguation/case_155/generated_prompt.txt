Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the full specification below.

The PDE is in conservative form with fields rho(x,t), v(x,t), p(x,t).
Define m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v**2.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Set zeta = eta = 0.01.

The three conservation laws are:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] (periodic), time domain is t in [0, 0.5].
Parameters: Gamma = 1.6666666666666667, eta = 0.01, zeta = 0.01.
Boundary conditions are periodic: x = -1 and x = 1 are identified.

Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
dx = 2.0 / 400 = 0.005.
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, 1, ..., 399.
Evolve the conservative variables U = [rho, m, E] as cell averages.

Initialize cell averages by evaluating the following at each cell center x_j:
rho(x_j, 0) = 1.0 + 0.2*sin(pi*x_j)
v(x_j, 0) = 0.1*cos(pi*x_j)
p(x_j, 0) = 1.0 + 0.2*cos(pi*x_j)
Compute m_j = rho_j * v_j and E_j = p_j/(Gamma-1) + 0.5*rho_j*v_j**2.

Use the equation of state: p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 whenever needed.

For the convective (inviscid) flux, use the Rusanov (local Lax-Friedrichs) scheme.
The physical convective flux vector is F_conv = [m, m**2/rho + p, (E+p)*v] with v = m/rho.
At each cell interface between cell j (left) and cell j+1 (right), compute the interface wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

For the viscous flux, compute v_x at each cell center using centered differences: v_x_j = (v_{j+1} - v_{j-1}) / (2*dx), with periodic index wrapping.
Compute sigma_j = (zeta + 4/3*eta) * v_x_j at each cell center.
At each interface between cell j and cell j+1, approximate sigma at the interface as the average: sigma_interface = 0.5*(sigma_j + sigma_{j+1}).
Approximate v at the interface as v_interface = 0.5*(v_j + v_{j+1}).
The viscous flux contribution at the interface is F_visc = [0, -sigma_interface, -v_interface * sigma_interface].
The total interface flux is F_total = F_hat + F_visc.

Apply periodic boundary conditions by wrapping indices (index -1 maps to index Nx-1, index Nx maps to index 0).

Use 2-stage SSP-RK2 (Heun's method) for time integration.
Stage 1: U_star = U^n + dt * L(U^n)
Stage 2: U^{n+1} = 0.5*U^n + 0.5*(U_star + dt * L(U_star))
where L(U) is the finite-volume right-hand side: L(U)_j = -(F_total_{j+1/2} - F_total_{j-1/2}) / dx.

Choose the time step each step as follows.
dt_conv = CFL * dx / max_j(|v_j| + c_j), using CFL = 0.5.
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30).
dt = min(dt_conv, dt_visc).
Adjust the final time step so that the simulation ends exactly at T = 0.5.

After time integration, recover the primitive variables at cell centers:
rho_j = U[0,j], m_j = U[1,j], E_j = U[2,j].
v_j = m_j / rho_j.
p_j = (Gamma-1) * (E_j - 0.5*m_j**2/rho_j).
