Solve the 2D heat equation u_t = 0.2 * (u_xx + u_yy) numerically using implicit Euler time integration and save the results.

Domain is (x,y) in [0,1] x [0,1], t in [0, 0.2].

Use alpha = 0.2.

Use a uniform grid with Nx = Ny = 60 intervals, giving 61 x 61 grid points including both endpoints.
Set dx = 1/60, dy = 1/60.
Set x_i = i * dx for i = 0..60, y_j = j * dy for j = 0..60.

Use dt = 0.001 and run for 200 time steps to reach T = 0.2.

Apply the 5-point Laplacian for spatial discretization on interior nodes.

Set Dirichlet boundary conditions by fixing boundary nodes to the exact solution values at t=0 (which are zero on all boundaries since sin(0)=sin(pi)=0 for both sin(2*pi*x) and sin(pi*y) at x=0,1 and y=0,1).

Set the initial condition u(x,y,0) = sin(2*pi*x) * sin(pi*y).

At each time step, solve the sparse linear system for interior nodes only using implicit Euler: (I - dt * alpha * L) * u_new = u_old, where L is the discrete Laplacian operator on interior nodes.
After solving, fix boundary nodes to zero each step.

The exact solution for verification is u(x,y,t) = exp(-0.2 * ((2*pi)**2 + (pi)**2) * t) * sin(2*pi*x) * sin(pi*y).

After completing all 200 steps, compute u(x,y,T=0.2) on the full 61x61 grid.

Save "solution_agent_heat_10.npz" containing:
- x: 1D array of length 61
- y: 1D array of length 61
- u: 2D array of shape (61, 61) where u[j,i] = u(x_i, y_j) at T=0.2
- T: scalar 0.2
- dx: scalar 1/60
- dy: scalar 1/60
- dt: scalar 0.001

Save a heatmap or contour plot of u(x,y,T=0.2) as "solution_agent_heat_10.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx * dy) at T=0.2.

Evaluate the exact solution on the same 61x61 grid at T=0.2 and print the max absolute error and the L2 error sqrt(sum((u_numerical - u_exact)**2) * dx * dy).
