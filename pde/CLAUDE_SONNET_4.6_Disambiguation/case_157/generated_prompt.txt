Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the specifications below.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use Python with NumPy for the implementation.

Use '^' as exponentiation in math and '**' in Python code.

PDE in conservative form:
Define m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Assume zeta = eta.
The three equations are:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

Domain: x in [-1, 1], t in [0, 0.5].

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Boundary conditions: Transmissive/outflow (zero-gradient) at both x=-1 and x=1.

Initial conditions (pointwise on the grid):
rho(x,0) = 1.0 + 0.2*sin(pi*x)
v(x,0) = 0.1*cos(pi*x)
p(x,0) = 1.0 + 0.2*cos(pi*x)

Grid: Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., 399.
dx = 2.0 / 400 = 0.005.

Evolve the conservative variables U = [rho, m, E] as cell averages.

Equation of state: p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.

Convective flux: Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
F_conv(U) = [m, m**2/rho + p, (E+p)*v] where v = m/rho.
Interface wave speed: a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Numerical flux: F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Viscous terms: Compute v_x with centered differences on cell-centered v values.
Compute sigma = (zeta + 4/3*eta)*v_x at cell centers.
Approximate sigma at interfaces by averaging the two neighboring cell-centered sigma values.
Add viscous contributions to momentum and energy fluxes at interfaces:
F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Total interface flux: F_total = F_hat + F_visc.

Time integration: Use 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.

Time step: At each step compute:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
dt = min(dt_conv, dt_visc)
Use CFL = 0.5.
Adjust the last time step so the simulation hits T = 0.5 exactly.

Ghost cell / BC implementation: For outflow boundaries, set ghost cell values equal to the nearest interior cell (zero-gradient).

Output: Compute rho(x,T), v(x,T), p(x,T) on the 400 cell centers at T = 0.5.

Save a 3-panel line plot of rho, v, and p versus x at T = 0.5 as "solution_pdebench_cns1d_eta1em8_outflow_smooth.png".
