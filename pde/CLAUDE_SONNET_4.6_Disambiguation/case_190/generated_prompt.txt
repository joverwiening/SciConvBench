Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using the specifications below.

The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu equals 5.0.
The parameter rho equals 2.0.
The periodic boundary condition is u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use radians for all trigonometric functions.
Use the operator '^' as exponentiation; in Python code use '**' for powers.

Use a uniform periodic spatial grid with Nx = 512 points on [0, 1).
Set dx = 1.0 / 512.
Set x_j = j * dx for j = 0, 1, ..., 511.
Use a fixed time step dt = 0.001 with Nt = 1000 steps so that T = 1.0 is reached exactly.

Apply Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu * k**2 * (dt/2)), then set u = real(IFFT(u_hat)).

Step B (reaction full-step, duration dt): solve du/dt = rho * u * (1 - u) exactly pointwise using the logistic exact solution: u = (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).

Step C (diffusion half-step again): repeat Step A identically with duration dt/2.

Repeat the full Strang splitting step (A, B, C) for Nt = 1000 iterations to reach T = 1.0.

After completing all time steps, compute u(x, T=1.0) on the periodic grid.

Save a file named "solution_pdebench_reacdiff_nu5_rho2.npz" containing the following arrays and scalars: x (1D array of length 512), u (1D array of length 512), nu (scalar 5.0), rho (scalar 2.0), T (scalar 1.0), dx (scalar 1.0/512), dt (scalar 0.001), Nx (scalar 512), Nt (scalar 1000).

Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu5_rho2.png".

Print the following scalar diagnostics at T: min(u), max(u), mean(u), and the discrete L2 norm computed as sqrt(sum(u**2) * dx).
