Solve u_tt − (1.0)^2 u_xx + (1.0)^2 u = 0 on x ∈ [0,1], t ∈ [0,1.0] with c=1.0 and m=1.0.
Use Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use initial conditions u(x,0)=sin(pi*x) and u_t(x,0)=0.
Use a uniform grid with Nx=400 intervals on [0,1], giving Nx+1 points x_i=i*dx with dx=1/Nx.
Discretize u_xx with 2nd-order central differences on interior points i=1..Nx−1.
Use 2nd-order central difference in time (leapfrog) for u_tt with explicit handling of the +m^2 u term at time level n.
Choose dt0 = 0.9*dx/c with c=1.0.
Set Nt = ceil(T/dt0) with T=1.0 and then set dt = T/Nt so that t=1.0 is reached exactly.
Initialize u^0_i from u(x_i,0).
Initialize u^1_i using a Taylor start: u^1_i = u^0_i + dt*v^0_i + 0.5*dt^2*(c^2*u_xx(u^0)_i − m^2*u^0_i), with v^0_i = 0 and u_xx(u^0)_i computed by the same 2nd-order stencil.
Enforce boundary values u^n_0=0 and u^n_Nx=0 for all n including n=0 and n=1.
For n≥1, update interior points with u^{n+1}_i = 2u^n_i − u^{n−1}_i + dt^2*(c^2*u_xx(u^n)_i − m^2*u^n_i).
Compute the numerical solution u(x,T) at T=1.0 on the grid.
Evaluate the reference solution u_exact(x,t)=cos(sqrt((1.0*pi)^2+(1.0)^2)*t)*sin(pi*x) on the same x grid at t=T.
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error metrics at T: max absolute error max_i |u_i−u_exact_i| and L2 error sqrt(sum((u−u_exact)^2)*dx).
