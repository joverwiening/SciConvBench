Solve the 2D Laplace equation u_xx + u_yy = 0 for u(x,y) on the square domain (x,y) ∈ [0,1] × [0,1].

Define dx = 1/Nx and dy = 1/Ny.
Define x_i = i*dx for i = 0..Nx and y_j = j*dy for j = 0..Ny.
Store the solution in an array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
Apply Dirichlet boundary conditions on all four edges by setting u(x,y) = x*y at every boundary grid point.
Do not apply periodic boundary conditions and ignore any periodicity statement.
Discretize the Laplacian on interior grid points (i = 1..Nx-1, j = 1..Ny-1) using the standard 5-point second-order finite difference stencil.
Form the sparse linear system A * u_interior = b corresponding to the interior unknowns, incorporating boundary values into b.
Use a sparse direct solver (e.g., scipy.sparse.linalg.spsolve) to solve for the interior unknowns.
Assemble the full grid solution u by combining the solved interior values with the prescribed boundary values.
Compute the reference solution u_ref(x,y) = x*y evaluated on the same grid.
Compute and print min(u) and max(u) over all grid points.
Compute and print the discrete L2 norm of u as sqrt(sum(u^2) * dx * dy) over all grid points.
