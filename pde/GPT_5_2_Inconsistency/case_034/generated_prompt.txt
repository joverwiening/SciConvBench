Create a Python script named agent_heat_05.py.
Solve the 1D heat equation u_t = alpha * u_xx with alpha = 0.05 on x in [0,1) with periodicity and t in [0,1.0].
Use a uniform periodic grid with Nx = 256 points on [0,1) with no duplicated endpoint at x=1.
Define dx = 1/Nx and x_i = i*dx for i = 0..Nx-1.
Use the initial condition u(x,0) = sin(2*pi*x) + 0.2*cos(4*pi*x) with trig in radians.
Discretize u_xx with 2nd-order central differences using periodic wrap-around: (u_{i+1} - 2u_i + u_{i-1})/dx^2 with indices modulo Nx.
Use Crank–Nicolson time integration with dt = 0.001 from t=0 to T=1.0.
Use exactly 1000 time steps so that T = Nt*dt = 1.0.
Form the linear system (I - 0.5*dt*alpha*L) u^{n+1} = (I + 0.5*dt*alpha*L) u^n where L is the periodic second-derivative matrix consistent with the finite-difference stencil.
Assemble (I - 0.5*dt*alpha*L) as a sparse cyclic tridiagonal matrix of shape (Nx, Nx) using scipy.sparse.
Solve for u^{n+1} each step using scipy.sparse.linalg.spsolve.
After advancing to T=1.0, compute and store u(x,T) on the same grid.
Compute the reference solution on the same grid: u_exact(x,t)=exp(-0.05*(2*pi)^2*t)*sin(2*pi*x) + 0.2*exp(-0.05*(4*pi)^2*t)*cos(4*pi*x).
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error max(|u-u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx).
