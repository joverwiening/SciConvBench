Implement the solver in Python 3 using NumPy for computation and Matplotlib for plotting.
Solve the 1D Klein–Gordon PDE u_tt - (0.5)^2 u_xx + (2.0)^2 u = 0 on x in [0,1] and t in [0,1.0].
Use Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all time steps.
Use initial conditions u(x,0)=sin(2*pi*x) and u_t(x,0)=0 with trig in radians.
Create a uniform grid with Nx=600 intervals and Nx+1 points, dx=1/Nx, and x_i=i*dx for i=0..Nx.
Set c=1 for the CFL calculation and define dt0=0.9*dx/c.
Set T=1.0, Nt=ceil(T/dt0), and dt=T/Nt so that the final time is reached exactly.
Discretize u_xx with 2nd-order central differences on interior points i=1..Nx-1: u_xx[i]=(u[i+1]-2*u[i]+u[i-1])/dx^2.
Use leapfrog time stepping with 2nd-order central difference for u_tt and treat the +m^2*u term explicitly at time level n in the update.
Use m=2.0 in the discrete update.
For n>=1, update interior points with u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + dt^2*((0.5)^2*u_xx^n[i] - (2.0)^2*u^n[i]).
Enforce boundary values u^n[0]=0 and u^n[Nx]=0 at every time level including initialization.
Initialize u^0 from the initial condition evaluated on the x grid.
Initialize u^1 using a Taylor start: u^1[i] = u^0[i] + dt*v0[i] + 0.5*dt^2*((0.5)^2*u_xx^0[i] - (2.0)^2*u^0[i]) for interior points, with v0=0 and boundary values set to 0.
Advance the solution for Nt time steps so that u at t=T is obtained on the same x grid.
Compute and print at T the scalars min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) using the final u array.
Evaluate the reference solution on the same x grid at T: u_exact(x,T)=cos(sqrt((0.5*2*pi)^2 + (2.0)^2)*T)*sin(2*pi*x).
Compute and print the max absolute error max(|u-u_exact|) and the L2 error sqrt(sum((u-u_exact)^2)*dx).
