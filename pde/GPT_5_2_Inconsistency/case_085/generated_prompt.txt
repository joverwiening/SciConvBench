Solve the 1D wave equation u_tt = (1.0)^2 u_xx for u(x,t).
Use wave speed c = 1.0 everywhere in the numerical method, including CFL, Taylor start, and time stepping.
Use the spatial domain x in [0,1] with Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 enforced at every time step.
Use the time domain t in [0,1.0] with final time T = 1.0.
Use initial displacement u(x,0)=0.
Use initial velocity u_t(x,0)=sin(pi*x) with pi interpreted in radians.
Use the reference solution u_exact(x,t) = (1/(1.0*pi))*sin(1.0*pi*t)*sin(pi*x) for verification.
Use a uniform grid on [0,1] with Nx=400 uniform intervals and Nx+1 grid points including endpoints.
Set dx = 1/Nx and x_i = i*dx for i=0..Nx.
Discretize u_xx in the interior with 2nd-order central differences: u_xx[i] = (u[i-1] - 2*u[i] + u[i+1]) / dx^2 for i=1..Nx-1.
Use 2nd-order central differences in time (leapfrog / Störmer–Verlet) for u_tt.
Choose dt using CFL ≤ 0.9 by computing dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that t=T is reached exactly.
Initialize u^0[i] = u(x_i,0) for all grid points.
Compute u_xx^0 from u^0 using the same spatial stencil and with boundary nodes set to the Dirichlet values.
Compute the first time level using the Taylor start with no forcing: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0), where v0[i]=sin(pi*x_i).
After computing u^1, enforce Dirichlet boundary values at i=0 and i=Nx.
For each subsequent step n=1..Nt-1, update interior nodes with u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + (c*dt/dx)^2*(u^n[i-1] - 2*u^n[i] + u^n[i+1]) for i=1..Nx-1.
At every time step, set u^n[0]=0 and u^n[Nx]=0.
At the end of the run, take u(x,T) as the numerical solution at time step n=Nt.
Evaluate u_exact(x_i,T) on the same x grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T using the numerical u.
Compute and print the max absolute error max_i |u[i]-u_exact[i]| at T.
Compute and print the L2 error sqrt(sum((u-u_exact)^2)*dx) at T.
