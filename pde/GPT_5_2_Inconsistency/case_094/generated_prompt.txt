Solve the 1D wave equation u_tt = (1.0)^2 u_xx for u(x,t).
Use the spatial domain x in [0,1] with Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use the time domain t in [0,0.25] with final time T=0.25.
Use wave speed c=1.0 everywhere, including the CFL condition and the update formula.
Use the initial displacement u(x,0)=sin(4*pi*x) with pi interpreted in radians.
Use the initial velocity u_t(x,0)=0.
Use a uniform grid with Nx=800 intervals and Nx+1 points, with dx=1/Nx and x_i=i*dx for i=0..Nx.
Discretize u_xx with 2nd-order central differences at interior points i=1..Nx-1: u_xx[i]=(u[i+1]-2*u[i]+u[i-1])/dx^2.
Choose dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is reached exactly.
Use 2nd-order central differences in time (leapfrog / Störmer–Verlet) for u_tt.
Initialize u^0[i]=u(x_i,0) for all grid points.
Compute u_xx^0 at interior points using the spatial stencil and enforce boundary values u^0[0]=0 and u^0[Nx]=0.
Compute the first time level using the Taylor start with v0=0 and no forcing: u^1[i]=u^0[i] + dt*v0[i] + 0.5*dt^2*(c^2*u_xx^0[i]) for interior points, then set u^1[0]=0 and u^1[Nx]=0.
For each subsequent step n=1..Nt-1, update interior points with u^{n+1}[i]=2*u^n[i]-u^{n-1}[i] + (c*dt/dx)^2*(u^n[i+1]-2*u^n[i]+u^n[i-1]).
At every time step, enforce Dirichlet boundary values by setting u^n[0]=0 and u^n[Nx]=0.
After advancing to time T, compute and report min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) using the final u array.
Evaluate the reference solution on the same grid at T: u_exact(x,T)=cos(1.0*4*pi*T)*sin(4*pi*x).
Compute and print the max absolute error max(|u-u_exact|) and the discrete L2 error sqrt(sum((u-u_exact)^2)*dx).
