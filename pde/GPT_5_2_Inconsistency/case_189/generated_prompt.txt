Implement the solver in Python 3.
Use NumPy for arrays and FFTs via numpy.fft.
Use Matplotlib for plotting.
Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set parameters nu=5.0 and rho=10.0.
Use a uniform periodic grid with Nx=512 points on [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Set T=1.0, dt=0.001, Nt=1000, and advance exactly Nt steps to reach T.
Initialize u(x,0)=0.25 + 0.1*sin(2*pi*x) using radians.
Advance one full time step dt using Strang splitting: diffusion half-step, reaction full-step, diffusion half-step.
Compute the diffusion half-step of duration dt/2 exactly in Fourier space by taking u_hat=FFT(u), forming k=2*pi*fftfreq(Nx, d=dx), updating u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then u <- real(IFFT(u_hat)).
Compute the reaction full-step of duration dt exactly pointwise using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
After Nt steps, treat the result as u(x,T=1.0) on the periodic grid.
Compute and print at T the scalars min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
