Solve the 2D Poisson equation u_xx + u_yy = f(x,y) with f(x,y) = 100*exp(-200*((x-0.5)^2 + (y-0.5)^2)) on the domain [0,1] x [0,1].
Use a uniform grid with Nx=Ny=120 intervals so there are (Nx+1) x (Ny+1) grid points including boundaries.
Set dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Store the solution in an array u with shape (len(y), len(x)) such that u[j,i] corresponds to u(x[i], y[j]).
Enforce Dirichlet boundary conditions only: set u=0 on all four edges (i=0, i=Nx, j=0, j=Ny).
Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil.
Assemble the sparse linear system A*u_interior = b for interior unknowns only, incorporating boundary values into the right-hand side.
Use a sparse direct solver such as scipy.sparse.linalg.spsolve to solve for the interior unknowns.
Insert the solved interior values back into the full u array while keeping boundary values at zero.
Compute and print min(u), max(u), and the discrete L2 norm defined as sqrt(sum(u^2)*dx*dy) over all grid points.
Save an NPZ file named solution_agent_poisson_07.npz containing x (1D), y (1D), u (2D), and metadata scalars dx and dy.
