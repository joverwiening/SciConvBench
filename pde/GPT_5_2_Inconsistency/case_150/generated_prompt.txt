Solve the 1D viscous Burgers PDE u_t + ∂_x(0.5*u^2) = nu*u_xx on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use nu = 0.001.
Use initial condition u(x,0) = sin(2*pi*x) with x in radians.
Use a uniform periodic grid with Nx = 512 points on [0,1) with dx = 1/Nx and x_j = j*dx for j=0..Nx-1.
Use Strang splitting for each full time step dt: diffusion half-step, advection full-step, diffusion half-step.
Implement each diffusion half-step of duration dt/2 exactly in Fourier space by FFT(u) to u_hat, using k = 2*pi*fftfreq(Nx, d=dx), multiplying u_hat by exp(-nu*k^2*(dt/2)), then inverse FFT and taking the real part.
Implement the advection full-step of duration dt for inviscid Burgers using a finite-volume update with Rusanov flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j],u[j+1]) and F_minus as the flux between (u[j-1],u[j]) with periodic indexing, then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), and replace u with u_new after the advection substep.
Choose the time step using CFL=0.4 with estimated max speed 1.0 by setting dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) with T = 1.0, then reset dt = T/Nt so the final time is hit exactly.
Advance the solution from t=0 to t=T=1.0 using Nt steps of size dt.
At the end, compute and report min(u), max(u), mean(u) as the discrete average of the Nx values, and the discrete L2 norm sqrt(sum(u^2)*dx).
