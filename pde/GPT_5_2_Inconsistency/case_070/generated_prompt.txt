Solve the 2D biharmonic PDE ∇^4 u = f(x,y) on the domain [0,1]×[0,1].

Use the exact/reference solution u_exact(x,y) = sin(pi*x)*sin(pi*y) for verification.
Enforce simply-supported boundary conditions only: u = 0 on the entire boundary and Δu = 0 on the entire boundary.
Do not enforce any Neumann/zero-flux boundary condition.
Introduce v = Δu and solve two Poisson problems sequentially.
Solve Poisson problem (1): Δv = f with Dirichlet boundary condition v = 0 on the entire boundary.
Solve Poisson problem (2): Δu = v with Dirichlet boundary condition u = 0 on the entire boundary.
Use a uniform grid with Nx = Ny = 120 intervals, giving (Nx+1)×(Ny+1) grid points including boundaries.
Set dx = dy = 1/Nx.

Discretize each Poisson equation using the standard 5-point finite-difference Laplacian on the uniform grid.

Use a sparse direct solver for each Poisson solve, such as scipy.sparse.linalg.spsolve.
