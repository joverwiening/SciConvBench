Solve the 2D Laplace equation u_xx + u_yy = 0 for u(x,y).
Use the spatial domain (x,y) in [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1) x (Ny+1) grid points.
Define dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Store u as a 2D array with shape (Ny+1, Nx+1) such that u[j,i] corresponds to u(x_i, y_j).
Impose Dirichlet boundary conditions on all four edges only.
Set boundary values to u(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi) evaluated at the boundary grid points.
Do not apply periodic boundary conditions.
Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil.
For each interior node (i=1..Nx-1, j=1..Ny-1), enforce (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2 = 0.
Assemble the resulting sparse linear system A * u_interior = b for the interior unknowns only.
Incorporate Dirichlet boundary values into the right-hand side b for interior equations adjacent to the boundary.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Reconstruct the full grid solution u by combining the solved interior values with the prescribed boundary values.
Define the reference solution on the grid as u_exact(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi) using radians for trig.
Compute and print min(u) and max(u) over all grid points.
Compute and print the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Compute and print the max absolute error max(|u-u_exact|) over all grid points.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over all grid points.
