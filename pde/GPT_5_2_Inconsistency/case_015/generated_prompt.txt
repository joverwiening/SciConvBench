Solve the 1D viscous Burgers equation u_t + u*u_x = nu*u_xx on x in [0,1] and t in [0,0.5] with nu=0.01.
Use the conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
Use a uniform grid with Nx=800 intervals on [0,1] including endpoints, so dx=1/Nx and x_i=i*dx for i=0..Nx.
Use dt=1e-4 and Nt=5000 time steps so that T=Nt*dt=0.5 is reached exactly.
Set the initial condition u(x,0)=sin(pi*x) evaluated at the grid points using radians.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Do not use periodic wrapping anywhere in flux computations or diffusion stencils.
Discretize convection using the Rusanov flux at interfaces i+1/2: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i) with alpha_{i+1/2}=max(|u_i|,|u_{i+1}|).
Approximate (f(u))_x at interior points i=1..Nx-1 by (F_{i+1/2}-F_{i-1/2})/dx using the boundary values u_0=0 and u_Nx=0 when forming the edge fluxes F_{1/2} and F_{Nx-1/2}.
Discretize diffusion with the second-order central difference u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2 for i=1..Nx-1.
Advance in time with first-order IMEX: treat convection explicitly at time level n and diffusion implicitly at time level n+1 via (u^{n+1}-u^n)/dt + conv^n = nu*L*u^{n+1}.
Form the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv^n for the unknown interior values i=1..Nx-1.
Incorporate Dirichlet boundary conditions into the diffusion operator by fixing u^{n+1}_0=0 and u^{n+1}_Nx=0 and moving any boundary contributions to the right-hand side consistently with the central stencil.
After solving each step, explicitly set u[0]=0 and u[Nx]=0.
Solve the sparse linear system each time step using a direct sparse solver such as scipy.sparse.linalg.spsolve.
At final time T=0.5, compute and report min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) over all grid points.
