Solve the 1D wave equation u_tt = c^2 u_xx with c = 1.0.
Use the spatial domain x in [0,1] and final time T = 1.0.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use initial conditions u(x,0)=sin(pi*x) and u_t(x,0)=0.
Use the reference solution u_exact(x,t)=cos(pi*t)*sin(pi*x) for verification.
Discretize space on a uniform grid with Nx=400 intervals and Nx+1 points, dx=1/Nx, x_i=i*dx for i=0..Nx.
Approximate u_xx at interior points with 2nd-order central differences: (u_{i+1}-2u_i+u_{i-1})/dx^2.
Use 2nd-order central differences in time (leapfrog / Störmer–Verlet): u_i^{n+1} = 2u_i^n - u_i^{n-1} + (c*dt)^2 * (u_{i+1}^n - 2u_i^n + u_{i-1}^n)/dx^2 for interior i.
Choose dt via CFL with c=1.0: dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) and then dt = T/Nt so that t=T is reached exactly.
Initialize u^0 from u(x,0) on the grid.
Compute u^1 using the Taylor start with v0=0 and no forcing: u_i^1 = u_i^0 + dt*v0_i + 0.5*dt^2*(c^2*u_xx_i^0) for interior i, and enforce boundary values at i=0 and i=Nx.
At every time step n, enforce Dirichlet boundary values by setting u_0^n=0 and u_{Nx}^n=0.
Advance the solution until time T using the leapfrog update.
At T, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
At T, evaluate u_exact on the same x grid and compute and print the max absolute error and discrete L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_wave_01.npz containing arrays x (1D) and u (1D at T, same length as x) and scalars T, dx, dt.
