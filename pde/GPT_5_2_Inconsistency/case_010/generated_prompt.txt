Solve the 2D Allen–Cahn PDE u_t = ε^2 (u_xx + u_yy) + u − u^3 for u(x,y,t).
Use ε = 0.01.
Use the spatial domain (x,y) ∈ [0,1) × [0,1) with periodic boundary conditions in both x and y.
Use the time domain t ∈ [0, 0.2] with final time T = 0.2.
Use a uniform periodic grid with Nx = 256 and Ny = 256 grid points (no duplicated endpoints).
Define dx = 1/Nx and dy = 1/Ny.
Define x_i = i*dx for i = 0..Nx−1 and y_j = j*dy for j = 0..Ny−1.
Initialize u(x,y,0) = 0.1*cos(2*pi*x)*cos(2*pi*y) evaluated on the grid using radians.
Discretize the Laplacian with the standard 5-point stencil using periodic wrap-around indexing: Δu[i,j] ≈ (u[i+1,j]−2u[i,j]+u[i−1,j])/dx^2 + (u[i,j+1]−2u[i,j]+u[i,j−1])/dy^2 with indices wrapped modulo Nx and Ny.
Use dt = 0.0002 and perform Nt = 1000 time steps so that Nt*dt = 0.2.
Advance in time with the semi-implicit scheme (diffusion implicit, reaction explicit): (u^{n+1} − u^n)/dt = ε^2 Δu^{n+1} + u^n − (u^n)^3.
At each step, form and solve the sparse linear system (I − dt*ε^2*L) u^{n+1} = u^n + dt*(u^n − (u^n)^3), where L is the discrete Laplacian operator with periodic wrap-around.
Compute the final solution array u at T = 0.2 on the same grid.
Save an NPZ file named solution_agent_allen_cahn_04.npz containing x (1D), y (1D), u (2D with shape (len(y), len(x)) and indexing u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
Save a heatmap or contour plot of u(x,y,T) as solution_agent_allen_cahn_04.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) computed from the final grid values.
