Implement a 1D heat-equation solver in Python using NumPy (and optionally SciPy for linear solves) and Matplotlib for plotting.
Solve u_t = 0.1 u_xx for x in [0,1] and t in [0,0.4].
Use alpha = 0.1.
Use a uniform grid with Nx = 200 intervals, so there are N = Nx+1 = 201 grid points.
Define dx = (1-0)/Nx and x_i = i*dx for i = 0..Nx.
Use time step dt = 0.001 and advance for Nt = 0.4/dt = 400 steps to reach T = 0.4 exactly.
Initialize u(x,0) = cos(pi*x) evaluated at the grid points (use radians).
Discretize u_xx with 2nd-order central differences in the interior.
Impose zero Neumann boundary conditions using ghost-point relations at every application/assembly of the Laplacian: u_{-1} = u_1 at x=0 and u_{Nx+1} = u_{Nx-1} at x=1.
Construct the discrete Laplacian operator L consistent with the ghost-point Neumann treatment, yielding 2nd-order accuracy at boundaries.
Advance in time with Crank–Nicolson: (I - (dt*alpha/2) L) u^{n+1} = (I + (dt*alpha/2) L) u^n.
At each time step, solve the linear system for u^{n+1} using a stable solver (numpy.linalg.solve or scipy.linalg.solve; sparse methods are allowed but not required).
After Nt steps, compute the numerical solution u at T = 0.4 on the same grid.
Compute the reference solution u_exact(x,T) = exp(-0.1*pi^2*T) * cos(pi*x) on the same x grid.
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error metrics vs u_exact at T: max absolute error max(|u-u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_heat_04.npz containing arrays x (1D) and u (1D, same length as x), and scalars T, dx, dt.
