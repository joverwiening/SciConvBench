Solve the 2D Poisson equation u_xx + u_yy = f(x,y) on (x,y) in [0,1] x [0,1].
Use f(x,y) = -2*pi^2*sin(pi*x)*sin(pi*y) with trig in radians.
Use Dirichlet boundary conditions only: set u=0 on all four edges x=0, x=1, y=0, y=1.
Use a uniform grid with Nx=Ny=120 intervals so there are (Nx+1) by (Ny+1) grid points including boundaries.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Store the solution in an array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil.
Assemble the sparse linear system A*u_interior = b for interior unknowns only, incorporating Dirichlet boundary values into the right-hand side.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Construct the full grid solution u by inserting the solved interior values and setting boundary values to 0.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over the full grid.
Define the exact solution u_exact(x,y)=sin(pi*x)*sin(pi*y) evaluated on the same grid for verification.
Compute and print the max absolute error max(|u-u_exact|) over the full grid.
Compute and print the L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over the full grid.
