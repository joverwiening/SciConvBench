Solve the 1D viscous Burgers equation u_t + u*u_x = nu*u_xx in conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
Use domain x in [0,1) with periodic boundary conditions and periodic wrap-around indexing, and t in [0,0.5].
Use nu = 0.01.
Use initial condition u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=800 grid points on [0,1) with no duplicated endpoint at x=1.
Set dx = 1/Nx and x_i = i*dx for i=0..Nx-1.
Use time step dt = 1e-4 for Nt=5000 steps so that T=0.5 is reached exactly.
Discretize convection using the Rusanov (local Lax–Friedrichs) numerical flux with alpha_{i+1/2} = max(|u_i|,|u_{i+1}|).
Compute f(u_i)=0.5*u_i^2.
Compute F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i) using periodic wrap-around for i+1.
Approximate (f(u))_x at cell i by (F_{i+1/2}-F_{i-1/2})/dx using periodic wrap-around for i-1.
Discretize diffusion with the 2nd-order central difference u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2 using periodic wrap-around.
Advance in time with 1st-order IMEX: treat convection explicitly at time level n and diffusion implicitly at time level n+1.
At each step solve (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu*(u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_{i-1})/dx^2.
Form the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term where L is the periodic second-difference Laplacian operator.
Implement L with periodic wrap-around entries connecting i=0 with i=Nx-1.
Solve the sparse linear system each time step (e.g., scipy.sparse.linalg.spsolve).
After Nt steps, compute u(x,T=0.5) on the same grid.
Save an NPZ file named solution_agent_burgers_01.npz containing arrays x (1D) and u (1D) and scalar metadata T, dx, dt.
Save a line plot of u versus x at T as solution_agent_burgers_01.png.
