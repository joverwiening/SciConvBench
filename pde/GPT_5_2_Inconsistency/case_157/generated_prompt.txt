Solve the 1D compressible Navier–Stokes system without heat conduction on x in [-1, 1] and t in [0, 0.5] using a uniform finite-volume method with outflow boundary conditions.
Use unknowns rho(x,t), v(x,t), p(x,t) and evolve conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use Gamma = 1.6666666666666667 everywhere for the equation of state and sound speed.
Use eta = 1e-08 and zeta = eta = 1e-08.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Solve the conservative PDE system: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ( (E+p)*v - v*sigma )_x = 0.
Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1] with dx = 2/Nx and cell centers x_j = -1 + (j+0.5)*dx for j = 0..Nx-1.
Initialize pointwise at cell centers: rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Convert initial primitive variables to conservative variables using m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Implement transmissive/outflow boundary conditions at x = -1 and x = 1 by setting ghost cell values equal to the nearest interior cell values (zero-gradient).
Compute pressure from conservative variables by p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) when needed for stability and for computing derived quantities.
Compute inviscid (Euler) interface fluxes using the Rusanov (local Lax-Friedrichs) flux with F_conv(U) = [m, m^2/rho + p, (E+p)*v] and v = m/rho.
Compute sound speed c = sqrt(Gamma*p/rho) and interface wave speed a = max(|v_L| + c_L, |v_R| + c_R).
Compute Rusanov numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute v_x using a centered difference on cell-centered v values, using ghost cells to support the stencil at boundaries.
Compute cell-centered sigma = (zeta + 4/3*eta) * v_x.
Approximate interface sigma by averaging neighboring cell-centered sigma values.
Approximate interface v by averaging neighboring cell-centered v values.
Compute viscous interface flux contribution F_visc = [0, -sigma, -v*sigma] using the interface-averaged v and sigma.
Form total interface flux F_total = F_hat + F_visc.
Advance the semi-discrete finite-volume system using 2-stage SSP-RK2 (Heun’s method).
At each time step compute dt_conv = CFL * dx / max_j(|v_j| + c_j).
At each time step compute dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc) and adjust the final step so that t reaches exactly T = 0.5.
After reaching T, compute rho(x,T), v(x,T), p(x,T) at cell centers from the final conservative state.
