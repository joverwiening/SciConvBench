Solve the 1D linear advection PDE u_t + q*u_x = 0 for u(x,t).
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the time domain t in [0,1.0] with final time T=1.0.
Use parameter q=1.5.
Impose periodicity so u(0,t)=u(1,t) for all t, implemented on the [0,1) grid without duplicating the endpoint.
Use the initial condition u(x,0)=sin(2*pi*x)+0.2*sin(6*pi*x) with trig in radians.
Use a uniform periodic grid with Nx=512 points, dx=1/Nx, and x_j=j*dx for j=0,...,Nx-1.
Discretize u_x with a 1st-order upwind finite difference consistent with the sign of q.
For q>0, use u_x(x_j) ≈ (u_j - u_{j-1})/dx with periodic wrap so u_{-1}=u_{Nx-1}.
Advance in time with Forward Euler: u^{n+1} = u^n - dt*q*(upwind derivative of u^n).
Choose the timestep from CFL=0.5 via dt0=CFL*dx/abs(q), set Nt=ceil(T/dt0), then set dt=T/Nt.
March the solution from t=0 to t=T using exactly Nt steps of size dt.
Compute the reference solution on the same grid using u_exact(x_j,T)=u0(((x_j - q*T) mod 1)) where u0 is the initial condition function.
At t=T, print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
At t=T, compute and print the max absolute error max_j |u_j - u_exact_j| and the L2 error sqrt(sum((u-u_exact)^2)*dx).
