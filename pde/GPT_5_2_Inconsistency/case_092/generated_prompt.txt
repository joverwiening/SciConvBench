Solve the 2D forced wave equation u_tt = (1.0)^2*(u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t) for u(x,y,t).
Use the spatial domain (x,y) in [0,1] x [0,1] and time domain t in [0,1.0].
Use Dirichlet boundary conditions u=0 on all four boundaries for all times.
Use initial conditions u(x,y,0)=0 and u_t(x,y,0)=0.
Use wave speed c=1.0 in both the finite-difference update and the CFL condition.
Discretize space with a uniform grid using Nx=Ny=120 intervals, giving (Nx+1) by (Ny+1) grid points including endpoints.
Define dx=dy=1/Nx, x_i=0+i*dx for i=0..Nx, and y_j=0+j*dy for j=0..Ny.
Approximate the Laplacian with the 5-point stencil: (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2 on interior nodes.
Use 2nd-order central differences in time for u_tt with the explicit update u^{n+1} = 2u^n - u^{n-1} + dt^2*(c^2*Lap(u^n) + f(x,y,t^n)) on interior nodes.
Use the forcing f(x,y,t)=sin(pi*x)*sin(pi*y)*cos(2*pi*t) evaluated at grid points and at time t^n.
Choose dt via CFL ≤ 0.9 using dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) with T=1.0, then set dt = T/Nt so that the final time is reached exactly.
Initialize u^0 from the initial displacement as u^0(x_i,y_j)=0 everywhere.
Initialize u^1 using a Taylor start with the initial velocity: u^1 = u^0 + dt*u_t(x,y,0) + 0.5*dt^2*(c^2*Lap(u^0) + f(x,y,0)) on interior nodes.
Enforce Dirichlet boundary conditions by setting u=0 on all boundary nodes for u^n at every time level including n=0 and n=1 and after each update.
March in time from n=1 to n=Nt-1 to compute u at t=T.
At the end, compute u(x,y,T=1.0) on the full grid including boundaries.
