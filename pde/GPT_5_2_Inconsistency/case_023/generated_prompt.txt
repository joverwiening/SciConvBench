Solve the 1D diffusion-reaction PDE u_t = 0.1*u_xx + (-1.0)*u for u(x,t).
Use the spatial domain x in [0,1] and time domain t in [0,0.5].
Use a uniform grid with Nx=200 intervals, giving Nx+1=201 grid points including endpoints.
Define dx = (1-0)/Nx and x_i = 0 + i*dx for i=0..Nx.
Use time step dt=0.001 for 500 steps to reach T=0.5.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Do not use periodic endpoint identification anywhere in the discretization.
Set the initial condition u(x,0)=sin(pi*x) evaluated at the grid points.
Discretize u_xx with 2nd-order central differences on the uniform grid for interior points i=1..Nx-1.
Construct the discrete Laplacian operator L consistent with Dirichlet boundaries, acting on the full grid vector with boundary values enforced as zero.
Define the reaction term as R(u) = (-1.0)*u applied pointwise.
Advance in time using 1st-order IMEX: diffusion implicit (backward Euler) and reaction explicit (forward Euler).
At each time step solve (I - dt*D*L) u^{n+1} = u^n + dt*R(u^n) with D=0.1.
Use a sparse direct solver to solve the linear system at each step.
After each step, enforce u^{n+1}[0]=0 and u^{n+1}[Nx]=0 to maintain Dirichlet boundaries.
At final time T=0.5, compute u(x,T) on the same grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute the reference solution u_exact(x,T)=exp((-1.0 - 0.1*pi^2)*T)*sin(pi*x) on the same x grid.
Compute and print the max absolute error max(|u-u_exact|) at T.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx) at T.
