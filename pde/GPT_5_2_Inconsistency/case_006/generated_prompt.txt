Solve the 1D linear advection PDE u_t + (2.0)*u_x = 0 for u(x,t).
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the time domain t in [0,0.3] with final time T = 0.3.
Use a uniform periodic grid with Nx = 2000 grid points on [0,1) with no duplicated endpoint.
Define dx = 1/Nx and x_i = i*dx for i = 0..Nx-1.
Set the initial condition u(x,0) = 1 if 0.2 ≤ x < 0.4 else 0, interpreted periodically on [0,1).
Use first-order upwind differencing for u_x appropriate for positive advection speed a = 2.0.
Implement periodic wrap-around indexing for the upwind stencil.
Use Forward Euler time integration.
Compute dt0 = 0.9*dx/|a|.
Compute Nt = ceil(T/dt0).
Set dt = T/Nt so that the final time is reached exactly after Nt steps.
Advance the solution for Nt steps to obtain u(x,T).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_agent_advection_06.npz containing arrays x (1D) and u (1D, same length as x) and metadata scalars T, dx, dt.
