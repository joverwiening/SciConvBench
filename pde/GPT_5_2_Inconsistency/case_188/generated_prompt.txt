Implement the solver in Python 3 using NumPy for arrays/FFTs and Matplotlib for plotting.
Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu=5.0 and rho=1.0.
Use a uniform periodic grid with Nx=512 points on [0,1) defined by dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Use a fixed time step dt=0.001 with Nt=1000 steps so that T=Nt*dt=1.0 exactly.
Initialize u(x,0)=0.25 + 0.1*sin(2*pi*x) evaluated at the grid points using radians.
Advance the solution with Strang splitting for each full time step dt.
Perform the diffusion half-step of duration dt/2 by FFT: compute u_hat=FFT(u), define k=2*pi*fftfreq(Nx, d=dx), update u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then set u <- real(IFFT(u_hat)).
Perform the reaction full-step of duration dt pointwise using the exact logistic update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the second diffusion half-step identical to the first diffusion half-step.
After Nt steps, treat the result as u(x,T=1.0) on the same periodic grid.
Compute and print at T the scalar diagnostics: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
