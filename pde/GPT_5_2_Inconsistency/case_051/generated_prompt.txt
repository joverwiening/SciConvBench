Solve the 1D Klein–Gordon PDE u_tt - c^2 u_xx + m^2 u = 0 with c=1.0 and m=3.0 for x in [0,1) periodic and t in [0,0.8].
Use a uniform periodic grid with Nx=512 points on [0,1) with no duplicated endpoint.
Define dx = 1.0/Nx and x_i = i*dx for i=0..Nx-1.
Impose periodic boundary conditions by wrap-around indexing for all spatial finite differences.
Discretize u_xx with 2nd-order central differences: (u_{i+1}-2u_i+u_{i-1})/dx^2 using periodic wrap-around.
Set dt0 = 0.9*dx/c and T = 0.8.
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is hit exactly.
Use leapfrog time integration for u_tt with the mass term included at time level n: u^{n+1} = 2u^n - u^{n-1} + dt^2*(c^2*u_xx^n - m^2*u^n).
Initialize u^0_i = cos(2*pi*x_i) and v^0_i = u_t(x_i,0) = 0.
Use a Taylor start consistent with the PDE including the mass term: u^1 = u^0 + dt*v^0 + 0.5*dt^2*(c^2*u_xx^0 - m^2*u^0).
Advance the solution from n=1 to n=Nt-1 to obtain u at t=T.
Compute the reference solution on the same grid at T: u_exact(x_i,T) = cos(2*pi*x_i)*cos(sqrt((c*2*pi)^2 + m^2)*T).
Compute and print at t=T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print error vs reference at t=T: max absolute error max_i |u_i-u_exact_i| and L2 error sqrt(sum((u-u_exact)^2)*dx).
