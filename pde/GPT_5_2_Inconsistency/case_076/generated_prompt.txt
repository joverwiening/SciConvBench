Solve the 2D Poisson equation u_xx + u_yy = f(x,y) on the domain (x,y) in [0,1] x [0,1].
Use f(x,y) = -2*(y*(1-y) + x*(1-x)) exactly as written.
Use the exact/reference solution u_exact(x,y) = x*(1-x)*y*(1-y) for verification.
Use a uniform grid with Nx=Ny=120 intervals so there are (Nx+1) by (Ny+1) grid points including boundaries.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Store x as a 1D array of length Nx+1 and y as a 1D array of length Ny+1.
Represent the numerical solution u as a 2D array with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
Enforce Dirichlet boundary conditions on all four edges: set u(x,y) on the boundary ∂Ω to u_exact(x,y)=x*(1-x)*y*(1-y).
Do not apply periodic boundary conditions.
Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil on the uniform grid.
Assemble the resulting sparse linear system for the interior unknowns only, incorporating Dirichlet boundary values into the right-hand side.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Construct the full grid solution u by combining the solved interior values with the prescribed boundary values.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Compute the pointwise absolute error |u - u_exact| on the same grid.
Compute and print the max absolute error over all grid points.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over all grid points.
