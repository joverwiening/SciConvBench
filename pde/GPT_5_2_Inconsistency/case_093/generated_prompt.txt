Implement a numerical solver in Python using NumPy for arrays and Matplotlib for plotting.
Solve the 1D wave equation u_tt = (2.0)^2 * u_xx on x in [0,1] and t in [0,0.5].
Use wave speed c = 4 for the CFL condition and for the update formula.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use initial displacement u(x,0)=sin(pi*x).
Use initial velocity u_t(x,0)=0.
Use a uniform grid on [0,1] with Nx=400 intervals and Nx+1 points.
Define dx = (1-0)/Nx and x_i = 0 + i*dx for i=0..Nx.
Discretize u_xx with 2nd-order central differences at interior points i=1..Nx-1.
Use 2nd-order central differences in time (leapfrog / Störmer–Verlet) for u_tt.
Choose dt via dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that t=0.5 is reached exactly.
Initialize u^0 from u(x,0) on the grid.
Compute u^1 using the Taylor start u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0) with v0(x)=0 and no forcing term.
At every time step, enforce Dirichlet boundary values by setting u[0]=0 and u[Nx]=0.
Advance the solution for n=1..Nt-1 using u^{n+1} = 2*u^n - u^{n-1} + (c*dt)^2 * u_xx^n at interior points.
Compute the numerical solution u(x,T) at T=0.5 on the same grid.
Evaluate the reference solution u_exact(x,T)=cos(2.0*pi*T)*sin(pi*x) on the same x grid.
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error max(|u-u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_wave_12.npz to the current working directory containing arrays x (1D) and u (1D) and scalars T, dx, dt.
