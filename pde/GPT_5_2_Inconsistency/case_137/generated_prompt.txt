Solve the 1D linear advection PDE u_t + beta*u_x = 0 for u(x,t).
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the time domain t in [0,2.0] with final time T=2.0.
Set beta = 0.4.
Impose periodicity such that u(0,t) = u(1,t) for all t.
Use the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) with trig in radians.
Use a uniform periodic grid with Nx=512 grid points on [0,1) (no duplicated endpoint).
Define dx = 1/Nx and x_j = j*dx for j=0,...,Nx-1.
Discretize u_x with a 1st-order upwind finite difference using the upwind direction determined by the sign of beta.
For beta>0, use u_x(x_j) ≈ (u_j - u_{j-1})/dx with periodic indexing (u_{-1}=u_{Nx-1}).
Advance in time with explicit forward Euler.
Use CFL=0.5 to set an initial dt0 = CFL*dx/abs(beta).
Choose Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time is hit exactly.
Evolve the solution for Nt steps from t=0 to t=T using the fixed dt.
Compute the numerical solution array u(x,T) on the same periodic grid x.
Compute the reference solution on the same grid as u_ref(x_j,T) = u0(((x_j - beta*T) mod 1)), where u0 is the initial condition function.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum_j(u_j^2)*dx) at T.
Compute and print the max absolute error max_j |u_j - u_ref_j| at T.
Compute and print the L2 error sqrt(sum_j((u_j - u_ref_j)^2)*dx) at T.
