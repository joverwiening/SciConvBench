Solve u_t = 0.05*u_xx + 2.0*u for x in [0,1] and t in [0,0.3] with u(0,t)=0 and u(1,t)=0.
Use the initial condition u(x,0)=sin(2*pi*x).
Use a uniform grid with Nx=250 intervals so there are Nx+1=251 grid points including both endpoints.
Set dx=(1-0)/Nx and x_i=0+i*dx for i=0..Nx.
Use 2nd-order central differences for the diffusion term on interior points i=1..Nx-1.
Enforce Dirichlet boundary values by setting u_0^n=0 and u_Nx^n=0 for all time steps.
Define the discrete Laplacian operator L acting on the interior unknown vector u_int as (L u)_i = (u_{i-1} - 2*u_i + u_{i+1})/dx^2 for i=1..Nx-1 with boundary values u_0=0 and u_Nx=0.
Use IMEX Euler time stepping with dt=0.0005 for 600 steps to reach T=0.3.
Treat diffusion implicitly and reaction explicitly by solving at each step (I - dt*D*L) u_int^{n+1} = u_int^n + dt*(lambda*u_int^n) with D=0.05 and lambda=2.0.
Use a sparse direct solver to solve the linear system for u_int^{n+1} each time step.
After each solve, assemble the full solution vector u^{n+1} of length Nx+1 by inserting u_0^{n+1}=0, u_Nx^{n+1}=0, and the interior values.
At final time T=0.3, compute and report min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) using all grid points.
Evaluate the reference solution u_exact(x,t)=exp((2.0 - 0.05*(2*pi)^2)*t)*sin(2*pi*x) on the same x grid at t=T.
Compute and print the max absolute error max(|u-u_exact|) and the discrete L2 error sqrt(sum((u-u_exact)^2)*dx).
Save an NPZ file named solution_agent_diffusion_reaction_02.npz containing arrays x (1D) and u (1D, same length as x) and scalars T, dx, dt.
