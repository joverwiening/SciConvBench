Solve u_t + a(x) u_x = 0 on x in [0,1) periodic and t in [0,0.5] with a(x)=1+0.5*sin(2*pi*x) and u(x,0)=sin(2*pi*x).
Use a uniform periodic grid with Nx=1200 points on [0,1) with no duplicated endpoint.
Set dx=1/Nx and x_i=i*dx for i=0..Nx-1.
Compute a_i = 1 + 0.5*sin(2*pi*x_i) using radians.
Use first-order upwind with left-biased stencil (since a(x)>0 everywhere): u_x(x_i) ≈ (u_i - u_{i-1})/dx with periodic wrap u_{-1}=u_{Nx-1}.
Advance in time with Forward Euler: u_i^{n+1} = u_i^n - dt * a_i * (u_i^n - u_{i-1}^n)/dx.
Use amax=1.5 and dt0 = 0.9*dx/amax.
Set T=0.5.
Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time is hit exactly.
Run the scheme for Nt steps from t=0 to t=T.
At t=T, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_agent_advection_03.npz containing arrays x (1D) and u (1D) and scalars T, dx, dt.
Save a line plot of u versus x at t=T as solution_agent_advection_03.png.
