Solve the 1D wave equation u_tt = c^2 u_xx with c = 1.0 for x in [0,1] and t in [0,1.0].
Use a uniform grid on [0,1] with Nx = 400 intervals and Nx+1 points, dx = 1/Nx, and x_i = i*dx for i = 0..Nx.
Impose Neumann boundary conditions u_x(0,t)=0 and u_x(1,t)=0 using ghost points with mirror values at each time level.
Discretize u_xx with 2nd-order central differences in the interior.
For the Neumann boundaries, enforce u_{-1} = u_{1} and u_{Nx+1} = u_{Nx-1} before applying the same central-difference stencil at i=0 and i=Nx.
Use 2nd-order central differences in time (leapfrog / Störmer–Verlet) for u_tt.
Set dt0 = 0.9*dx/c and choose Nt = ceil(T/dt0) with T = 1.0, then set dt = T/Nt so that t=1.0 is reached exactly.
Initialize u^0_i = u(x_i,0) = cos(pi*x_i).
Set v0(x)=u_t(x,0)=0 and compute u^1 using the Taylor start u^1_i = u^0_i + dt*v0_i + 0.5*dt^2*(c^2*(u_xx)^0_i), with (u_xx)^0 computed from u^0 using the same Neumann ghost-point handling.
Advance for n = 1..Nt-1 using u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (c*dt/dx)^2*(u^n_{i+1} - 2*u^n_i + u^n_{i-1}) with ghost points applied to u^n before evaluating the stencil.
At final time T=1.0, compute the numerical solution array u(x,T) on the same x grid.
Evaluate the reference solution u_exact(x,T) = cos(pi*x)*cos(pi*T) on the same x grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max(|u-u_exact|) and the L2 error sqrt(sum((u-u_exact)^2)*dx) at T.
