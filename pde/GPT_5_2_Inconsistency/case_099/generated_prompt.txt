Solve the 1D wave equation u_tt = c^2 u_xx on x in [0,1] and t in [0,1.0] with wave speed c = 1.0.
Use a uniform grid with Nx = 800 intervals and Nx+1 points including endpoints, with dx = 1/Nx and x_i = i*dx for i = 0..Nx.
Impose Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0 by setting the boundary nodes to 0 at every time step.
Set the initial displacement u(x,0) = exp(-200*(x-0.5)^2) evaluated at grid points.
Set the initial velocity u_t(x,0) = 0 evaluated at grid points.
Discretize u_xx in the interior using 2nd-order central differences: u_xx[i] = (u[i+1] - 2*u[i] + u[i-1]) / dx^2 for i = 1..Nx-1.
Use 2nd-order central differences in time (leapfrog / Störmer–Verlet) for u_tt.
Choose dt via CFL with c = 1.0: compute dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that t = T is reached exactly.
Initialize the first time step using the Taylor start with no forcing: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0), with v0 = 0 and u_xx^0 computed from u^0, and enforce boundary values after initialization.
Advance for n = 1..Nt-1 using u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + (c*dt/dx)^2*(u^n[i+1] - 2*u^n[i] + u^n[i-1]) for i = 1..Nx-1, and enforce boundary values u^{n+1}[0]=0 and u^{n+1}[Nx]=0 each step.
At final time T = 1.0, compute and report min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) using the final u array over all grid points.
