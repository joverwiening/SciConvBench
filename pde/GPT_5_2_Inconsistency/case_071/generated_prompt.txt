Solve the 2D advection–diffusion PDE u_t + a u_x + b u_y = D (u_xx + u_yy) for u(x,y,t).
Use parameters a=1.0, b=0.5, D=0.01.
Use the periodic spatial domain (x,y) in [0,1)×[0,1) with no duplicated endpoints.
Use a uniform grid with Nx=Ny=400 grid points, dx=dy=1/Nx, x_i=i*dx for i=0..Nx-1, y_j=j*dy for j=0..Ny-1.
Use time domain t in [0,0.5] with dt=0.001 and Nt=500 steps so T=Nt*dt=0.5 is reached exactly.
Initialize u(x,y,0)=sin(2*pi*x)*cos(2*pi*y) evaluated on the grid.
Discretize advection with 1st-order upwind differences using the signs of a and b.
For a>0 use D_x^up u(i,j) = (u(i,j)-u(i-1,j))/dx with periodic wrap in i.
For b>0 use D_y^up u(i,j) = (u(i,j)-u(i,j-1))/dy with periodic wrap in j.
Discretize diffusion with the 5-point 2nd-order central Laplacian L with periodic wrap: (L u)(i,j) = (u(i+1,j)-2u(i,j)+u(i-1,j))/dx^2 + (u(i,j+1)-2u(i,j)+u(i,j-1))/dy^2.
Advance in time with the 1st-order IMEX scheme: (I - dt*D*L) u^{n+1} = u^n - dt*(a*D_x^up u^n + b*D_y^up u^n).
At each step, form the sparse matrix A = (I - dt*D*L) corresponding to the periodic 5-point stencil on the 2D grid.
Solve A * vec(u^{n+1}) = vec(rhs) each step using a direct sparse solver.
Store u as a 2D array with shape (Ny, Nx) such that u[j,i] = u(x_i, y_j).
After Nt steps, compute u(x,y,T) at T=0.5.
Compute the reference solution on the same grid: u_exact(x,y,T)=exp(-D*8*pi^2*T)*sin(2*pi*(x-a*T))*cos(2*pi*(y-b*T)).
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy).
Compute and print error metrics at T: max absolute error max(|u-u_exact|) and L2 error sqrt(sum((u-u_exact)^2)*dx*dy).
