Solve the 2D variable-coefficient Darcy/Poisson equation -∇·(a(x,y)∇u(x,y)) = 1 on the open domain (0,1)×(0,1).
Use Dirichlet boundary conditions only: set u=0 on the entire boundary x=0, x=1, y=0, y=1.
Use beta = 10.0.
Define a(x,y) = 1 + beta*(0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) using radians for trig.
Use a uniform Cartesian grid with N=128 intervals in each direction, giving (N+1)×(N+1) grid points.
Set dx=dy=1/N.
Use x_i=i*dx for i=0..N and y_j=j*dy for j=0..N.
Compute a(i,j)=a(x_i,y_j) on all grid points.
Treat unknowns as the interior values u(i,j) for i=1..N-1 and j=1..N-1, with boundary values fixed to 0.
Discretize the operator with 2nd-order finite differences using face-centered harmonic averaging.
For each interior node (i,j), enforce:
-(1/dx^2)*[ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Define harmonic face coefficients by a(i+1/2,j)=2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)) and analogously for a(i-1/2,j), a(i,j+1/2), a(i,j-1/2).
Assemble the sparse linear system Au=b for the interior unknowns only, incorporating boundary values u=0 into the right-hand side where needed.
Set b to the constant source term 1 at every interior node consistent with the discrete equation.
Solve Au=b using conjugate gradient (CG) to relative residual tolerance 1e-10.
Optionally use a Jacobi (diagonal) preconditioner.
After solving, construct the full u array of shape (N+1,N+1) with interior filled from the solution and boundary entries set to 0.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete interior residual norm ||Au-b||_2 / ||b||_2 using the assembled interior A and b and the solved interior vector.
Save an NPZ file named solution_pdebench_darcy_beta10.npz containing x (1D length N+1), y (1D length N+1), u (2D shape [N+1,N+1]), and scalars beta, N, dx.
Save a heatmap or contour plot of u(x,y) as solution_pdebench_darcy_beta10.png.
