Implement the solver in Python 3 using NumPy for arrays and FFTs (numpy.fft) and Matplotlib for plotting.
Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use nu = 1.0 and final time T = 1.0.
Use a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and x[j] = j*dx for j = 0..Nx-1.
Initialize u[j] = sin(2*pi*x[j]) at t = 0 using radians.
Choose CFL = 0.4 and dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and then set dt = T/Nt so the final time is reached exactly.
Advance the solution for Nt time steps using Strang splitting per full step dt.
For each full time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
In the diffusion half-step, compute u_hat = FFT(u) using numpy.fft.fft.
In the diffusion half-step, form the wavenumber array k = 2*pi*fftfreq(Nx, d=dx) using numpy.fft.fftfreq.
In the diffusion half-step, update u_hat <- u_hat * exp(-nu*k^2*(dt/2)).
In the diffusion half-step, compute u <- real(IFFT(u_hat)) using numpy.fft.ifft and take the real part.
After the first diffusion half-step, perform an advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov flux.
Define f(u) = 0.5*u^2.
For each interface j between left state u_left = u[j] and right state u_right = u[(j+1) mod Nx], compute alpha = max(abs(u_left), abs(u_right)).
For each interface j, compute the Rusanov flux F[j] = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, set F_plus = F[j] and F_minus = F[(j-1) mod Nx].
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) for all j.
Replace u <- u_new after the advection substep.
Perform the second diffusion half-step identical to the first diffusion half-step.
After completing Nt steps, treat the result as u(x,T=1.0) on the periodic grid.
Compute and print min(u), max(u), mean(u) as the discrete mean value, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_pdebench_burgers_nu1.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
