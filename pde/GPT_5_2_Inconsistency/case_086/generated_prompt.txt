Solve the 1D wave equation u_tt = (1.0)^2 u_xx for u(x,t).
Use wave speed c = 1.0 everywhere, including the CFL condition and time step selection.
Use the spatial domain x in [0,1) with periodic boundary conditions u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t).
Use the time domain t in [0,1.0] with final time T = 1.0.
Use the initial conditions u(x,0)=cos(2*pi*x) and u_t(x,0)=0.
Use the reference solution u_exact(x,t)=cos(2*pi*x)*cos(2*pi*1.0*t) for verification.
Use a uniform periodic grid with Nx = 512 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx and x_i = i*dx for i = 0..Nx-1.
Discretize u_xx with a 2nd-order central difference using periodic wrap-around: (u_{i+1}-2u_i+u_{i-1})/dx^2 with indices modulo Nx.
Discretize u_tt with a 2nd-order central difference in time using the standard explicit leapfrog update.
Choose dt0 = 0.9*dx/c and set Nt = ceil(T/dt0) and then dt = T/Nt so that t=T is reached exactly.
Initialize the scheme with a Taylor start using the periodic Laplacian: u^0_i = u(x_i,0) and u^1_i = u^0_i + dt*u_t(x_i,0) + 0.5*dt^2*c^2*(u_xx at t=0)_i.
Advance for n = 1..Nt-1 using u^{n+1}_i = 2u^n_i - u^{n-1}_i + (c*dt/dx)^2*(u^n_{i+1}-2u^n_i+u^n_{i-1}) with periodic wrap-around.
Compute the numerical solution array u at time T on the same x grid.
Evaluate the reference solution u_exact(x,T) on the same x grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max(|u-u_exact|) and the L2 error sqrt(sum((u-u_exact)^2)*dx) at T.
