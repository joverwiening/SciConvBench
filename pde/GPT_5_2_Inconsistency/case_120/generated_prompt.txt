Implement a Python 3 command-line script that numerically solves the 1D periodic wave equation u_tt = q*u_xx on x in [0,1) and t in [0,1.0].
Use q = 1.0.
Use a uniform periodic grid with Nx = 256 points on [0,1) with x_j = j*dx for j=0..Nx-1 and dx = 1/Nx.
Represent the solution as arrays u and v on the grid, where v = u_t.
Use the first-order system u_t = v and v_t = q*u_xx.
Initialize u(x,0) = sin(2*pi*x) evaluated at the grid points using radians.
Initialize v(x,0) = 0 at all grid points.
Discretize u_xx with 2nd-order central differences on the periodic grid using wrap-around indexing: u_xx[j] = (u[j+1] - 2*u[j] + u[j-1]) / dx^2 with indices taken modulo Nx.
Advance (u,v) in time using classical RK4 applied to the semi-discrete system.
Use dt = 0.0005 and Nt = 2000 time steps so that T = Nt*dt = 1.0 is reached exactly.
After time stepping, compute u(x,T) on the same periodic grid.
Compute and print at T the following diagnostics for u: min(u), max(u), mean(u), and discrete L2 norm defined as sqrt(sum(u^2)*dx).
Do not compute or print an error norm versus the exact solution.
Save an NPZ file named solution_molk_019.npz in the current working directory containing x (1D array length Nx), u (1D array length Nx), and scalars T, dx, Nx, and q.
Save a line plot of u versus x at T as solution_molk_019.png in the current working directory.
Use only NumPy and Matplotlib as dependencies.
