Implement the solver in Python 3 using NumPy.
Define parameters nu=0.5, rho=1.0, T=1.0, dt=0.001, Nt=1000, Nx=512.
Use a periodic spatial grid on x in [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Initialize u(x,0)=0.25+0.1*sin(2*pi*x) evaluated on the grid using radians.
Precompute the Fourier wavenumbers k = 2*pi*numpy.fft.fftfreq(Nx, d=dx).
Precompute the diffusion half-step multiplier E = exp(-nu*k**2*(dt/2)).
For each time step n=1..Nt, apply Strang splitting over one full dt.
For the diffusion half-step, compute u_hat = numpy.fft.fft(u), set u_hat = u_hat*E, then set u = real(numpy.fft.ifft(u_hat)).
For the reaction full-step, compute a = exp(rho*dt) and update pointwise u = (u*a)/(1 + u*(a - 1)).
For the second diffusion half-step, repeat the same FFT-multiply-IFFT procedure and take the real part.
After Nt steps, treat the result as u(x,T=1.0) on the same periodic grid.
Compute and print at T: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u**2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu0p5_rho1.npz containing arrays x (shape (Nx,)) and u (shape (Nx,)) and scalars nu, rho, T, dx, dt, Nx, Nt.
