Solve the 2D Klein–Gordon PDE u_tt - c^2 (u_xx + u_yy) + m^2 u = 0 with c=1.0 and m=1.0 for u(x,y,t).
Use the spatial domain (x,y) in [0,1] x [0,1] with Dirichlet boundary conditions u=0 on all boundaries for all t.
Use the time domain t in [0,0.8] with final time T=0.8.
Use the initial conditions u(x,y,0)=sin(pi*x)*sin(pi*y) and u_t(x,y,0)=0.
Use a uniform grid with Nx=Ny=256 intervals, giving (Nx+1) by (Ny+1) grid points including endpoints.
Define dx=dy=1/Nx and x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Discretize u_xx+u_yy with the standard 5-point Laplacian on the interior points.
Advance in time using 2nd-order central differences for u_tt: u^{n+1} = 2u^n - u^{n-1} + dt^2 (c^2 Lap(u^n) - m^2 u^n) on interior points.
Enforce Dirichlet boundaries by setting u=0 on all boundary grid points at every time level.
Choose the time step by first computing dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is hit exactly.
Initialize the scheme with a Taylor start: compute acceleration at t=0 as a0 = c^2 Lap(u^0) - m^2 u^0, then set u^1 = u^0 + dt*u_t^0 + 0.5*dt^2*a0 on interior points, with boundary values set to 0.
Evolve the solution from n=1 to n=Nt-1 to obtain u at t=T.
For verification, evaluate the reference solution u_exact(x,y,t)=cos(sqrt(c^2*(2*pi^2)+m^2)*t)*sin(pi*x)*sin(pi*y) on the same grid at t=T.
Compute and print at t=T: min(u), max(u), and the discrete L2 norm sqrt(sum_{i,j} u_{j,i}^2 * dx * dy).
Compute and print the error at t=T versus u_exact: max absolute error max_{i,j} |u-u_exact| and L2 error sqrt(sum_{i,j} (u-u_exact)_{j,i}^2 * dx * dy).
