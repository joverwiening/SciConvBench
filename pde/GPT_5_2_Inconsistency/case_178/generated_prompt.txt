Implement the solver in Python 3 using NumPy and numpy.fft (fft, ifft, fftfreq).
Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu=10.0 and rho=2.0.
Use a uniform periodic grid with Nx=512 points, dx=1/Nx, and x_j=j*dx for j=0..Nx-1.
Initialize u(x,0)=0.25+0.1*sin(2*pi*x) evaluated at the grid points using radians.
Use a fixed time step dt=0.001 and Nt=1000 steps so that T=Nt*dt=1.0 exactly.
Advance the solution with Strang splitting for each full time step dt.
Perform the diffusion half-step of duration dt/2 by FFT: u_hat=fft(u), k=2*pi*fftfreq(Nx,d=dx), u_hat=u_hat*exp(-nu*k^2*(dt/2)), u=real(ifft(u_hat)).
Perform the reaction full-step of duration dt by the exact logistic update pointwise: u=(u*exp(rho*dt))/(1+u*(exp(rho*dt)-1)).
Perform the second diffusion half-step identical to the first diffusion half-step.
After Nt steps, treat the result as u(x,T=1.0) on the same periodic grid.
Compute and print at T the following diagnostics: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu10_rho2.npz containing arrays x (shape (Nx,)) and u (shape (Nx,)) and scalars nu, rho, T, dx, dt, Nx, Nt.
