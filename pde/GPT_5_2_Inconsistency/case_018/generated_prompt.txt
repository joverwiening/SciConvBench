Implement the solver in Python.
Use NumPy for arrays and math.
Use SciPy sparse matrices and a SciPy sparse linear solver to solve the implicit Euler system each time step.
Use Matplotlib to generate and save the final line plot.
Solve u_t = ∂/∂x( D(x) * u_x ) with D(x)=0.01+0.09*x^2 on x∈[0,1], t∈[0,0.2].
Use a uniform grid with Nx=400 intervals, so there are N=Nx+1=401 grid points.
Define dx=(1-0)/Nx and x_i=0+i*dx for i=0..Nx.
Set T=0.2, dt=0.0005, and take Nt=round(T/dt)=400 time steps so that Nt*dt=T exactly.
Initialize u_i at t=0 by u_i = x_i*(1-x_i).
Impose Dirichlet boundary conditions strongly at every time step: u_0=0 and u_Nx=0.
Define D_i = 0.01 + 0.09*x_i^2 for all grid points.
Define face diffusion coefficients by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}) for i=0..Nx-1.
For interior nodes i=1..Nx-1, discretize the diffusion operator in conservative flux form:
(Lu)_i = (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
Assemble the sparse matrix L corresponding to the interior unknowns u_1..u_{Nx-1} only.
For each interior row i (mapped to interior index k=i-1), set the tridiagonal entries:
L_{k,k-1} = D_{i-1/2}/dx^2.
L_{k,k} = -(D_{i+1/2}+D_{i-1/2})/dx^2.
L_{k,k+1} = D_{i+1/2}/dx^2.
Use implicit Euler time stepping on the interior unknowns:
(I - dt*L) u^{n+1}_int = u^n_int.
At each step, solve the sparse linear system for u^{n+1}_int using a SciPy sparse direct solver (or an appropriate iterative solver) applied to the CSR/CSC matrix A = (I - dt*L).
After solving, reconstruct the full u^{n+1} of length 401 by setting boundary values u_0=0, u_Nx=0 and filling interior values from u^{n+1}_int.
After Nt steps, treat the result as u(x,T) at T=0.2.
Compute and print at T: min(u), max(u), and the discrete L2 norm defined as sqrt(sum(u^2)*dx) using all grid points.
Save an NPZ file named solution_agent_diffusion_02.npz containing arrays x (shape (401,)) and u (shape (401,)) and scalar metadata T, dx, dt.
