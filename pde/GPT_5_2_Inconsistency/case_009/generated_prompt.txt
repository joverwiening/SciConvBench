Solve the 1D Allen–Cahn PDE u_t = (0.02)^2 u_xx + u − u^3 for x in [0,1] and t in [0,1.0] with unknown u(x,t).
Use epsilon = 0.02.
Use a uniform grid on [0,1] with Nx = 800 uniform intervals, so dx = (1−0)/800 and x_i = i*dx for i = 0..800.
Use the initial condition u(x,0) = 0.05*sin(2*pi*x) + 0.02*sin(6*pi*x) evaluated at the grid points (pi in radians).
Enforce only zero Neumann boundary conditions u_x(0,t)=0 and u_x(1,t)=0 for all t.
Implement the Neumann boundary conditions using ghost points with mirror values: u_{-1} = u_{1} and u_{Nx+1} = u_{Nx-1} (with Nx=800 and interior indices 0..Nx).
Discretize u_xx with 2nd-order central differences at all grid points, using the ghost-point values at the boundaries.
Use time step dt = 0.0005 and advance for 2000 steps to reach T = 1.0.
Use the semi-implicit time integrator: (u^{n+1} − u^n)/dt = epsilon^2 * (u_xx)^{n+1} + u^n − (u^n)^3.
At each time step, form and solve the linear system (I − dt*epsilon^2*L) u^{n+1} = u^n + dt*(u^n − (u^n)^3), where L is the discrete Laplacian operator consistent with the Neumann ghost-point treatment.
Use a linear solver appropriate for the resulting banded/tridiagonal system.
After the final step, treat the result as u(x,T=1.0) on the same grid.
Compute and print at T=1.0: min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) using the grid values.
