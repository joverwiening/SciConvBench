Solve the scalar ODE du/dt = a*exp(-t) + b for u(t).
Use parameters a = 2.0 and b = -0.5.
Use time domain t in [0.0, 5.0] with t0 = 0.0 and T = 5.0.
Use initial condition u(0.0) = 0.0.
Use fixed-step classical 4th-order Runge–Kutta (RK4) time integration.
Use dt = 0.001 with Nt = 5000 steps so that t_n = t0 + n*dt for n = 0..Nt and t_Nt = T exactly.
Compute and store u(t_n) for all n = 0..Nt.
Compute the exact solution on the same grid using u_exact(t) = u0 + a*(1 - exp(-t)) + b*t with u0 = u(0.0).
Compute and print u(T) using the numerical solution.
Compute and print min(u) and max(u) over all stored time points.
Compute and print the max absolute error max_n |u_n - u_exact(t_n)|.
Compute and print the L2 error defined as sqrt(mean_n (u_n - u_exact(t_n))^2) over n = 0..Nt.
Save an NPZ file named solution_molk_001.npz containing arrays t (1D length Nt+1) and u (1D length Nt+1) and the parameter scalars a and b.
