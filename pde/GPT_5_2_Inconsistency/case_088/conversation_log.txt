Q: In the PDE you wrote the wave speed as (1.0)^2, but in the parameters you set c = 2; which value should be used for the numerical solver and CFL condition?
A: Use **c = 1.0** for the numerical solver and for the CFL condition.

The PDE coefficient is \((1.0)^2\) and the **complete requirement** specifies **Parameters: c = 1.0** (the earlier “c = 2” is not part of the complete requirement).
