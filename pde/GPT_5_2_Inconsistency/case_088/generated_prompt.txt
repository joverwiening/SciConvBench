Solve u_tt = (1.0)^2 (u_xx + u_yy) for u(x,y,t) on (x,y) in [0,1]x[0,1] and t in [0,1.0].
Use wave speed c = 1.0 in the numerical update and in the CFL condition.
Impose Dirichlet boundary conditions u=0 on all four boundaries for all t.
Use initial conditions u(x,y,0)=sin(pi*x)*sin(pi*y) and u_t(x,y,0)=0.
Use a uniform grid with Nx=Ny=120 intervals so there are Nx+1 by Ny+1 grid points including endpoints.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Discretize the Laplacian with the 5-point stencil: (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2 on interior nodes.
Use 2nd-order central differences in time for u_tt with the explicit update u^{n+1} = 2u^n - u^{n-1} + (c*dt)^2 * Laplacian(u^n) on interior nodes.
Choose dt via CFL ≤ 0.9 where CFL = c*dt*sqrt(1/dx^2+1/dy^2).
Compute dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) with T=1.0 and then set dt = T/Nt so that the final time is hit exactly.
Initialize u^0 from the initial displacement evaluated on the grid.
Initialize u^1 using a Taylor start with initial velocity: u^1 = u^0 + dt*u_t(x,y,0) + 0.5*(dt^2)*c^2*Laplacian(u^0) on interior nodes.
Enforce Dirichlet boundary values u=0 on all boundary nodes for u^0, u^1, and at every subsequent time step.
March the solution from n=1 to n=Nt-1 to obtain u at T=1.0.
Compute the reference solution on the same grid at T: u_exact(x,y,T)=cos(1.0*sqrt(2)*pi*T)*sin(pi*x)*sin(pi*y).
Compute and print at T the minimum and maximum of u, and the discrete L2 norm sqrt(sum_{i,j} u_{j,i}^2 * dx * dy).
Compute and print the max absolute error max_{i,j} |u-u_exact| and the L2 error sqrt(sum_{i,j} (u-u_exact)_{j,i}^2 * dx * dy).
