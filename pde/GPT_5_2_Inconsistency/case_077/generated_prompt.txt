Solve the 2D Poisson equation u_xx + u_yy = f(x,y) on the domain (x,y) in [0,1] x [0,1].
Use f(x,y) = (1 - pi^2)*exp(x)*sin(pi*y) with pi as the mathematical constant and trig in radians.
Use Dirichlet boundary conditions on all four edges with u(x,y) = exp(x)*sin(pi*y) prescribed on the entire boundary.
Do not apply periodic boundary conditions anywhere.
Use a uniform grid with Nx=Ny=120 intervals so there are (Nx+1) by (Ny+1) grid points including boundaries.
Define dx=dy=1/Nx.
Define x_i = i*dx for i=0..Nx and y_j = j*dy for j=0..Ny.
Store the solution in an array u with shape (len(y), len(x)) such that u[j,i] corresponds to u(x[i], y[j]).
Discretize the Laplacian on interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard 5-point second-order finite difference stencil.
Form the linear system Au=b for the interior unknowns only.
Incorporate Dirichlet boundary values into the right-hand side b for interior equations adjacent to the boundary.
Assemble A as a sparse matrix.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Fill the full grid u with the solved interior values and the prescribed boundary values.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete L2 norm of u as sqrt(sum(u^2)*dx*dy) over the full grid.
Evaluate the exact solution u_exact(x,y)=exp(x)*sin(pi*y) on the same grid.
Compute and print the max absolute error max(|u-u_exact|) over the full grid.
Compute and print the L2 error as sqrt(sum((u-u_exact)^2)*dx*dy) over the full grid.
