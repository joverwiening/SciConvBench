Solve the 1D compressible Navier–Stokes system without heat conduction on x in [-1, 1] and t in [0, 0.2].
Use conservative variables U = [rho, m, E] with m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use equation of state p = (Gamma-1) * (E - 0.5*m^2/rho) with Gamma = 1.6666666666666667.
Use viscous stress sigma = (zeta + 4/3*eta) * v_x with eta = 1e-08 and zeta = eta.
Evolve the conservative PDEs: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + (((E+p)*v) - v*sigma)_x = 0.
Use a uniform cell-centered finite-volume grid with Nx = 800 cells on [-1, 1].
Define dx = 2/Nx and cell centers x_j = -1 + (j+0.5)*dx for j = 0..Nx-1.
Initialize a Riemann problem with discontinuity at x = 0 using cell-center position.
Set left state for x < 0: rho = 1.0, v = -0.75, p = 1.0.
Set right state for x >= 0: rho = 0.125, v = 0.0, p = 0.1.
Convert initial primitive variables to conservative variables via m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Apply transmissive/outflow boundary conditions at x = -1 and x = 1 by setting ghost cell values equal to the nearest interior cell (zero gradient).
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part at each interface.
Compute primitive variables in each cell as v = m/rho and p from the equation of state.
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) when needed for stability and for computing c.
Compute sound speed c = sqrt(Gamma*p/rho).
For each interface, compute a = max(|v_L| + c_L, |v_R| + c_R).
Compute inviscid flux F_conv(U) = [m, m^2/rho + p, (E+p)*v].
Compute Rusanov flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute viscous terms by first computing cell-centered v_j = m_j/rho_j.
Compute v_x at cell centers using a centered difference on v values.
Compute cell-centered sigma_j = (zeta + 4/3*eta) * (v_x)_j.
Compute interface sigma by averaging neighboring cell-centered sigma values.
Compute interface v by averaging neighboring cell-centered v values.
Form viscous interface flux F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Form total interface flux F_total = F_hat + F_visc.
Advance the semi-discrete finite-volume system using SSP-RK2 (Heun’s method).
At each time step, compute dt_conv = CFL * dx / max_j(|v_j| + c_j).
At each time step, compute dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc).
Adjust the final time step so that the integration ends exactly at T = 0.2.
Compute final rho(x,T), v(x,T), p(x,T) on cell centers from the final conservative state.
