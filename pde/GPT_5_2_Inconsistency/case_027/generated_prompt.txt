Solve u_t = 0.01*(u_xx + u_yy) + 2.0*u*(1 - u) for (x,y) in [0,1]x[0,1] and t in [0,1.0].
Use the initial condition u(x,y,0)=0.2 + 0.05*cos(2*pi*x)*cos(2*pi*y) with trig in radians.
Use a uniform grid with Nx=Ny=120 intervals on [0,1], giving (Nx+1)x(Ny+1) points including endpoints.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Use time step dt=0.001 for Nt=1000 steps to reach T=1.0.
Discretize diffusion with the standard 5-point Laplacian on the grid.
Enforce zero Neumann boundary conditions (∂u/∂n=0) on all four edges using ghost nodes with mirror values.
Do not apply any Dirichlet boundary condition.
Use IMEX first-order time stepping: diffusion implicit (backward Euler) and reaction explicit (forward Euler).
At each step compute R(u^n)=2.0*u^n*(1-u^n) pointwise.
At each step solve (I - dt*0.01*L) u^{n+1} = u^n + dt*R(u^n), where L is the discrete Laplacian with the Neumann ghost-node treatment.
Assemble the linear system as a sparse matrix and use a sparse direct solver at each time step.
Compute the final solution u(x,y,T=1.0) on the same grid.
