Solve the 1D forced wave equation u_tt = c^2 u_xx + sin(pi*x)*sin(2*pi*t) with c = 1.0.
Use the domain x in [0,1] and t in [0,1.0].
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use initial conditions u(x,0)=0 and u_t(x,0)=0.
Discretize space with a uniform grid on [0,1] using Nx=400 intervals and Nx+1 points, with dx = 1/Nx and x_i = i*dx for i=0..Nx.
Approximate u_xx at interior points with 2nd-order central differences: (u_{i+1}-2u_i+u_{i-1})/dx^2.
Discretize time with the standard 2nd-order central difference (leapfrog / Störmer–Verlet): u_i^{n+1} = 2u_i^n - u_i^{n-1} + dt^2*(c^2*u_xx_i^n + f_i^n), where f(x,t)=sin(pi*x)*sin(2*pi*t).
Choose dt using CFL ≤ 0.9 with dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) with T=1.0, then set dt = T/Nt so that t=1.0 is reached exactly.
Initialize u^0 from u(x,0)=0 at all grid points.
Compute u^1 using the Taylor start: u_i^1 = u_i^0 + dt*v0_i + 0.5*dt^2*(c^2*u_xx_i^0 + f_i^0), with v0_i = 0 and f_i^0 = sin(pi*x_i)*sin(0)=0.
Enforce Dirichlet boundary values by setting u_0^n=0 and u_Nx^n=0 at every time step including initialization.
March in time from n=1 to n=Nt-1 to compute u at t=T.
At the end, compute u(x,T) as the 1D array u of length Nx+1 on the grid x.
Save an NPZ file named solution_agent_wave_10.npz containing arrays x and u, and scalars T, dx, dt.
Save a line plot of u versus x at T as solution_agent_wave_10.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) evaluated at T.
