Solve the 1D compressible Navier–Stokes equations without heat conduction in conservative form for rho(x,t), m(x,t)=rho*v, and total energy E(x,t)=p/(Gamma-1)+0.5*rho*v^2.

Use domain x in [-1,1] and time t in [0,0.2] with final time T=0.2.
Use a uniform cell-centered finite-volume grid with Nx=800 cells, dx=2/Nx, and cell centers x_j=-1+(j+0.5)*dx for j=0..Nx-1.
Evolve conservative cell averages U=[rho,m,E] in time.
Compute pressure by p=(Gamma-1)*(E-0.5*m^2/rho) and enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) if needed.
Initialize a Riemann problem with discontinuity at x=0: for x<0 set rho=1.0, v=0.0, p=2.0; for x>=0 set rho=0.125, v=0.0, p=0.2; convert to m=rho*v and E=p/(Gamma-1)+0.5*rho*v^2.
Apply transmissive/outflow boundary conditions at x=-1 and x=1 by using ghost cells set equal to the nearest interior cell (zero-gradient).
Compute inviscid (Euler) numerical fluxes using the Rusanov (local Lax-Friedrichs) flux with F_conv(U)=[m, m^2/rho+p, (E+p)*v] and v=m/rho.
At each interface, compute c=sqrt(Gamma*p/rho) on left and right states and set a=max(|v_L|+c_L, |v_R|+c_R).
Compute Rusanov interface flux F_hat=0.5*(F_conv(U_L)+F_conv(U_R)) - 0.5*a*(U_R-U_L).
Compute v_x using a centered difference on cell-centered v values.
Compute cell-centered sigma=(zeta+4/3*eta)*v_x.
Compute interface sigma by averaging neighboring cell-centered sigma values.
Compute interface v by averaging neighboring cell-centered v values.
Add viscous flux contribution at interfaces F_visc=[0, -sigma, -v*sigma] using the interface-averaged v and sigma.
Use total interface flux F_total=F_hat+F_visc in the finite-volume update.
Advance in time using 2-stage SSP-RK2 (Heun’s method) applied to the semi-discrete finite-volume system.
Choose dt each step by dt_conv=CFL*dx/max_j(|v_j|+c_j) and dt_visc=0.5*dx^2/max(zeta+4/3*eta,1e-30), then dt=min(dt_conv,dt_visc).
Adjust the final time step so that the integration hits T=0.2 exactly.
After reaching T, compute rho(x,T), v(x,T)=m/rho, and p(x,T) on cell centers.
