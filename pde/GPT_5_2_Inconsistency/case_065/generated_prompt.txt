Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) ∈ [0,1] × [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1)×(Ny+1)=101×101 grid points.
Define dx=dy=1/Nx and x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Impose Dirichlet boundary conditions on all four edges: u(x,0)=0, u(x,1)=1, u(0,y)=0, u(1,y)=0.
Do not apply periodic boundary conditions anywhere.
Discretize the Laplacian on interior nodes (i=1..Nx-1, j=1..Ny-1) using the standard 5-point second-order finite difference stencil.
Form the sparse linear system Au=b for the unknown interior values u_{j,i}.
Incorporate Dirichlet boundary values into the right-hand side b for interior nodes adjacent to the boundary.
Use a sparse direct solver (scipy.sparse.linalg.spsolve or equivalent) to solve the linear system.
Assemble the full solution array u on the entire 101×101 grid including boundary values.
Store u as a 2D array with shape (len(y), len(x)) such that u[j,i] corresponds to u(x[i], y[j]).
Compute and print min(u), max(u), and the discrete L2 norm defined as sqrt(sum(u^2)*dx*dy) over all grid points.
Save an NPZ file named solution_agent_laplace_09.npz containing arrays x (1D), y (1D), u (2D), and scalars dx and dy.
