Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx on a periodic domain.
Use spatial domain x in [0,1) with periodic boundary conditions u(0,t)=u(1,t).
Use time domain t in [0,1.0] with final time T=1.0.
Set nu = 0.2.
Use initial condition u(x,0) = sin(2*pi*x) with trig in radians.
Use a uniform periodic grid with Nx=512 points on [0,1).
Define dx = 1/Nx.
Define grid points x_j = j*dx for j=0,...,Nx-1.
Choose CFL = 0.4 and estimated max speed = 1.0.
Compute dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0).
Reset dt = T/Nt so the final time is hit exactly.
Advance the solution for Nt full time steps of size dt using Strang splitting.
In each full time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
In the diffusion half-step, compute u_hat = FFT(u).
In the diffusion half-step, define k = 2*pi*fftfreq(Nx, d=dx).
In the diffusion half-step, update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
In the diffusion half-step, compute u = real(IFFT(u_hat)).
After the first diffusion half-step, perform an advection full-step of duration dt for inviscid Burgers u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] using periodic indexing, compute alpha = max(abs(u_left), abs(u_right)).
For each interface, compute F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) with periodic indexing.
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u <- u_new after the advection substep.
Perform the second diffusion half-step identical to the first diffusion half-step.
After completing Nt steps, treat the result as u(x,T=1.0) on the periodic grid.
Compute and print min(u), max(u), mean(u) as the discrete mean value, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_pdebench_burgers_nu0p2.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
