Implement the solver in Python 3 using NumPy (including numpy.fft) and Matplotlib.
Solve the 1D viscous Burgers PDE u_t + ∂_x(0.5*u^2) = nu*u_xx on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use nu = 2.0 and final time T = 1.0.
Use a uniform periodic grid with Nx = 512 points on [0,1) with dx = 1/Nx and x[j] = j*dx for j = 0..Nx-1.
Initialize u[j] = sin(2*pi*x[j]) at t = 0 using radians.
Set CFL = 0.4 and estimate max speed as 1.0 to define dt0 = CFL*dx/1.0.
Compute Nt = ceil(T/dt0) and then set dt = T/Nt so the final time is reached exactly.
Advance the solution for Nt steps using Strang splitting per full step dt.
Perform the diffusion half-step of duration dt/2 exactly in Fourier space by computing u_hat = FFT(u).
Construct the wavenumber array k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat = u_hat * exp(-nu*k^2*(dt/2)).
Compute u = real(IFFT(u_hat)).
Perform the advection full-step of duration dt for inviscid Burgers using a finite-volume update with Rusanov flux.
Define f(u) = 0.5*u^2.
For each interface between indices j and j+1 with periodic indexing, set u_left = u[j], u_right = u[(j+1) mod Nx], alpha = max(abs(u_left), abs(u_right)), and F[j] = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, set F_plus = F[j] and F_minus = F[(j-1) mod Nx], then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
Perform the diffusion half-step again identically to the first diffusion half-step.
After time stepping, treat the result as u(x,T=1.0) on the periodic grid.
Compute and print min(u), max(u), mean(u) as the discrete mean value, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
