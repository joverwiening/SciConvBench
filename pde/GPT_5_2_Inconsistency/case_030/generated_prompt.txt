Implement the solver in Python 3.
Use NumPy for arrays and math.
Use SciPy sparse matrices and sparse linear solvers (scipy.sparse, scipy.sparse.linalg) for the Crank–Nicolson linear system.
Use Matplotlib for plotting.

Solve the 1D heat equation u_t = alpha * u_xx with alpha = 0.1.
Use the spatial domain x in [0, 1] with Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Use the time domain t in [0, 0.5] with final time T = 0.5.
Use the initial condition u(x,0) = sin(pi*x) with pi in radians.

Use a uniform grid with Nx = 200 intervals and Nx+1 = 201 grid points.
Define dx = (1 - 0) / Nx.
Define x_i = 0 + i*dx for i = 0..Nx.

Use dt = 0.001.
Use Nt = 600 time steps so that Nt*dt = 0.6.
Advance the solution for exactly 500 steps so that the reported final time is exactly T = 0.5.
Store and report metadata scalars T=0.5, dx, dt in the output file.

Discretize u_xx with 2nd-order central differences on interior nodes i=1..Nx-1: (u_{i-1} - 2u_i + u_{i+1}) / dx^2.
Enforce Dirichlet boundary conditions by setting u_0 = 0 and u_Nx = 0 at initialization and after each time step.

Use Crank–Nicolson time integration on interior nodes.
Form the standard CN system for diffusion: (I - (r/2) L) u^{n+1} = (I + (r/2) L) u^{n}, where r = alpha*dt/dx^2 and L is the 1D second-difference operator on interior nodes with stencil [1, -2, 1].
Build the interior-node sparse tridiagonal matrices A = I - (r/2)L and B = I + (r/2)L of size (Nx-1) x (Nx-1).
At each step, compute rhs = B * u_interior^n and solve A * u_interior^{n+1} = rhs using a SciPy sparse solver.
Reconstruct the full u^{n+1} including boundary values 0 at i=0 and i=Nx.

After advancing to T=0.5, compute u(x,T) on the full grid.
Compute the reference solution on the same grid: u_exact(x,T) = exp(-0.1*pi^2*T) * sin(pi*x).

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T using the full-grid u.
Compute and print the max absolute error max(|u - u_exact|).
Compute and print the L2 error sqrt(sum((u - u_exact)^2)*dx).
