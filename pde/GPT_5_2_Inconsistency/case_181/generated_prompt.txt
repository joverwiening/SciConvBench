Implement the solver in Python 3.

Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set parameters nu=1.0 and rho=10.0.
Use a uniform periodic grid with Nx=512 points on [0,1) with x_j = j*dx for j=0..Nx-1 and dx=1/Nx.
Set T=1.0, dt=0.001, Nt=1000, and advance exactly Nt steps so that t=Nt*dt=T.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) using radians and pi from NumPy.
Advance one full time step dt using Strang splitting.
For each time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space by computing u_hat = FFT(u), forming k = 2*pi*fftfreq(Nx, d=dx), multiplying u_hat by exp(-nu*k^2*(dt/2)), and setting u = real(IFFT(u_hat)).
Then perform a reaction full-step of duration dt solved exactly pointwise for du/dt = rho*u*(1-u) using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Then perform the same diffusion half-step again.
After Nt steps, treat the result as u(x,T=1.0) on the same periodic grid.
Compute and print at T the scalars min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
