Solve the 2D Helmholtz-type PDE u_xx + u_yy + k^2 u = f(x,y) on (x,y) in [0,1]×[0,1] with k = 5.0.
Use f(x,y) = (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y) with trig in radians.
Use Dirichlet boundary conditions only: set u = 0 on all four edges x=0, x=1, y=0, y=1.
Use a uniform grid with Nx=Ny=120 intervals so there are (Nx+1)×(Ny+1) grid points including boundaries.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Discretize the Laplacian with the standard 5-point finite-difference stencil on the uniform grid.
Form a sparse linear system for the unknowns at interior nodes only, incorporating Dirichlet boundary values into the right-hand side as needed.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Assemble the full solution array u on the (Ny+1, Nx+1) grid, including boundary values set to 0.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Define the reference solution u_exact(x,y)=sin(pi*x)*sin(pi*y) evaluated on the same grid.
Compute and print the max absolute error max(|u-u_exact|) over all grid points.
Compute and print the L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over all grid points.
