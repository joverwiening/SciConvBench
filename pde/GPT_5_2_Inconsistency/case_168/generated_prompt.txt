Solve the 2D variable-coefficient elliptic PDE -∇·(a(x,y)∇u(x,y)) = 1 on the domain (0,1)×(0,1).
Use beta = 0.1.
Define a(x,y) = 1 + beta*(0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) using radians for trig.
Use a uniform Cartesian grid with N = 128 intervals in each direction, giving (N+1)×(N+1) grid points.
Set dx = dy = 1/N.
Define x_i = i*dx for i = 0..N.
Define y_j = j*dy for j = 0..N.
Enforce Dirichlet boundary conditions only: set u(i,j) = 0 for all boundary nodes where i=0 or i=N or j=0 or j=N.
Ignore the periodic boundary condition line entirely.
For interior nodes (i=1..N-1, j=1..N-1), discretize with 2nd-order finite differences using face-centered harmonic averaging:
Compute nodal coefficients a(i,j) = a(x_i,y_j).
Compute face coefficients by harmonic mean, e.g. a(i+1/2,j) = 2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)), and analogously a(i-1/2,j), a(i,j+1/2), a(i,j-1/2).
Apply the discrete operator for each interior node:
-(1/dx^2)*[ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Assemble the sparse linear system Au=b for the interior unknowns only, incorporating boundary values u=0 into the right-hand side where needed.
Solve the linear system with conjugate gradient (CG) to relative residual tolerance 1e-10.
Optionally use a Jacobi (diagonal) preconditioner.
After solving, construct u on the full (N+1)×(N+1) grid with boundary values set to 0.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete residual norm for the interior system as ||Au-b||_2 / ||b||_2.
Save an NPZ file named solution_pdebench_darcy_beta0p1.npz containing x (1D), y (1D), u (2D with shape [N+1, N+1]), and scalars beta, N, dx.
Save a heatmap or contour plot of u(x,y) as solution_pdebench_darcy_beta0p1.png.
