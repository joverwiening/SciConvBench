Implement the solver in Python 3 (assume Python 3.11) as a single self-contained script.
Assume a Linux/macOS-like environment and save all outputs to the current working directory using relative filenames.
Use NumPy for array computing and Matplotlib for plotting, with no SciPy dependency.
Solve the 1D linear advection PDE u_t + beta*u_x = 0 on x in [0,1) with periodic boundary conditions and t in [0,2.0].
Use beta = 0.1.
Use a periodic uniform grid with Nx = 512 grid points on [0,1), dx = 1/Nx, and x_j = j*dx for j = 0..Nx-1.
Initialize u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) evaluated at the grid points using radians.
Discretize u_x with 1st-order upwind finite difference using the upwind direction determined by the sign of beta.
For beta > 0, compute u_x at j as (u_j - u_{j-1})/dx with periodic wrap so u_{-1} means u_{Nx-1}.
Advance in time with explicit forward Euler: u^{n+1} = u^n - dt*beta*u_x^n.
Set CFL = 0.5 and compute an initial dt0 = CFL*dx/abs(beta).
Set Nt = ceil(T/dt0) with T = 2.0, then reset dt = T/Nt so the final time is hit exactly.
Evolve the solution from t=0 to t=T using Nt steps of size dt.
After time stepping, compute the reference solution on the same grid as u_ref(x,T) = u0(((x - beta*T) mod 1)) where u0 is the initial condition function.
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the error versus reference at T: max absolute error max(|u-u_ref|) and L2 error sqrt(sum((u-u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta0p1.npz containing arrays x (length Nx) and u (length Nx) and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T to solution_pdebench_advection_beta0p1.png.
