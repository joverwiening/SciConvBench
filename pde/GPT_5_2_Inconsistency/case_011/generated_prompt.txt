Solve the 2D Allen–Cahn PDE u_t = ε^2 (u_xx + u_yy) + u − u^3 for u(x,y,t).
Use ε = 0.02.
Use the spatial domain x ∈ [0,1], y ∈ [0,1] with Dirichlet boundary conditions u=0 on all boundaries for all t.
Use the time domain t ∈ [0, 0.1] with final time T = 0.1.
Use a uniform grid with Nx = 300 and Ny = 300 interpreted as numbers of uniform intervals on closed intervals, so there are Nx+1 and Ny+1 grid points including endpoints.
Define dx = (1−0)/Nx and dy = (1−0)/Ny.
Define x_i = 0 + i dx for i=0..Nx and y_j = 0 + j dy for j=0..Ny.
Store the solution as a 2D array u with shape (Ny+1, Nx+1) such that u[j,i] = u(x_i, y_j).
Initialize u(x,y,0) by r = sqrt((x−0.5)^2 + (y−0.5)^2) and u = tanh((0.25 − r)/(sqrt(2)*0.02)) evaluated at each grid point.
Enforce Dirichlet boundary conditions by setting u=0 at all boundary nodes (i=0, i=Nx, j=0, j=Ny) at initialization and after every time step.
Approximate u_xx + u_yy on interior nodes with the standard 5-point Laplacian: (u_{i+1,j}−2u_{i,j}+u_{i−1,j})/dx^2 + (u_{i,j+1}−2u_{i,j}+u_{i,j−1})/dy^2.
Use dt = 0.0001 and advance for Nt = 1000 steps so that Nt*dt = T.
Use the semi-implicit time stepping scheme: (u^{n+1} − u^n)/dt = ε^2 Δu^{n+1} + u^n − (u^n)^3.
At each step, form the right-hand side on interior nodes as rhs = u^n + dt*(u^n − (u^n)^3).
At each step, solve the sparse linear system on interior nodes: (I − dt*ε^2*Δ) u^{n+1} = rhs, using the same 5-point Laplacian stencil for Δ and incorporating Dirichlet boundary values (zero) by excluding boundary unknowns or by modifying rhs appropriately.
After solving, set boundary nodes of u^{n+1} to zero.
After the final step, treat the resulting field as u(x,y,T=0.1).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points at T.
Save an NPZ file named solution_agent_allen_cahn_05.npz containing x (1D array of length Nx+1), y (1D array of length Ny+1), u (2D array shape (Ny+1, Nx+1) at T), and scalar metadata T, dx, dy, dt.
