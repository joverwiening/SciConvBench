Solve the 1D wave equation u_tt = c^2 u_xx on x in [0,1] and t in [0,1.0] with c = 0.8.
Use a uniform grid with Nx = 600 intervals so there are Nx+1 points x_i = i*dx for i=0..Nx with dx = 1/Nx.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 by setting the boundary nodes to 0 at every time step.
Set initial displacement u(x,0)=0 on the grid.
Set initial velocity u_t(x,0)=sin(2*pi*x) on the grid using radians.
Discretize u_xx in the interior with 2nd-order central differences: u_xx[i] = (u[i+1] - 2*u[i] + u[i-1]) / dx^2 for i=1..Nx-1.
Choose dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) with T = 1.0 and then set dt = T/Nt so that the final time is hit exactly.
Initialize the first time level using the Taylor start with no forcing: u^0 = u(x,0) and u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0), applying Dirichlet boundary values to u^1 at i=0 and i=Nx.
Advance in time for n = 1..Nt-1 using the standard 2nd-order central difference in time (leapfrog): u^{n+1}[i] = 2*u^n[i] - u^{n-1}[i] + (c*dt/dx)^2*(u^n[i+1] - 2*u^n[i] + u^n[i-1]) for i=1..Nx-1.
Apply Dirichlet boundary values to u^{n+1} at i=0 and i=Nx at every step.
At the end of the run, define the numerical solution array u as u(x,T) at T = 1.0.
Evaluate the reference solution on the same grid: u_exact(x,T) = (1/(c*2*pi))*sin(c*2*pi*T)*sin(2*pi*x) with c = 0.8.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max(|u - u_exact|) and the discrete L2 error sqrt(sum((u-u_exact)^2)*dx) at T.
Save an NPZ file named solution_agent_wave_14.npz containing arrays x (1D) and u (1D, same length as x) and scalars T, dx, dt.
