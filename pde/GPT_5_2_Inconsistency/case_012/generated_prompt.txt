Solve the 2D Allen–Cahn PDE u_t = ε^2 (u_xx + u_yy) + u − u^3 for u(x,y,t).
Use ε = 0.015.
Use the spatial domain (x,y) ∈ [0,1] × [0,1] and time domain t ∈ [0,0.2].
Use a uniform grid with Nx = 200 and Ny = 200 interpreted as numbers of uniform intervals on closed intervals, giving (Nx+1)×(Ny+1) grid points.
Define dx = (1−0)/Nx and dy = (1−0)/Ny.
Define x_i = 0 + i·dx for i = 0..Nx and y_j = 0 + j·dy for j = 0..Ny.
Initialize u(x,y,0) = sin(pi*x)·sin(pi*y) evaluated on the grid (radians).
Impose zero Neumann boundary conditions on all boundaries using ghost nodes with mirror values.
Discretize Δu = u_xx + u_yy with the standard 5-point Laplacian on the uniform grid.
Advance in time with dt = 0.0002 from t=0 to T=0.2 for 1000 steps.
Use the semi-implicit scheme (diffusion implicit, reaction explicit): (u^{n+1}−u^n)/dt = ε^2 Δu^{n+1} + u^n − (u^n)^3.
At each time step, form and solve the sparse linear system (I − dt·ε^2·L) u^{n+1} = u^n + dt·(u^n − (u^n)^3), where L is the discrete Laplacian operator with Neumann boundary handling via ghost-node mirroring.
Compute the final solution array u at T = 0.2 on the same grid.
Save an NPZ file named solution_agent_allen_cahn_06.npz containing x (1D), y (1D), u (2D with shape (len(y), len(x)) and indexing u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
Save a heatmap/contour plot image of u(x,y,T) as solution_agent_allen_cahn_06.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)·dx·dy) computed at T.
