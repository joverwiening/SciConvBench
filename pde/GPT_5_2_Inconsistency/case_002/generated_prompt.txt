Solve the 1D linear advection PDE u_t + (-0.5) u_x = 0 for u(x,t).
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the time domain t in [0,1.0] with final time T = 1.0.
Use the initial condition u(x,0) = exp(-100*(x-0.3)^2) evaluated pointwise on the grid.
Use a uniform periodic grid with Nx = 1000 grid points on [0,1) with no duplicated endpoint.
Define dx = (1-0)/Nx = 1/Nx and x_i = 0 + i*dx for i = 0..Nx-1.
Use first-order upwind finite differences for u_x with a right-biased stencil because a = -0.5 < 0.
Compute the spatial derivative as (u_{i+1} - u_i)/dx with periodic wrap-around indexing for i+1 at the last point.
Advance in time using Forward Euler: u_i^{n+1} = u_i^n - a*dt*((u_{i+1}^n - u_i^n)/dx).
Choose dt0 = 0.9*dx/|a| to satisfy max|a|*dt/dx ≤ 0.9.
Set Nt = ceil(T/dt0).
Set dt = T/Nt so that the final time T is reached exactly after Nt steps.
Apply periodic boundary handling via wrap-around indexing at every time step.
After Nt steps, treat the result as u(x,T) at T = 1.0 on the same x grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
