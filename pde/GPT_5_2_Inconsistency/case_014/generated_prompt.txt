Solve the 1D viscous Burgers equation u_t + u*u_x = nu*u_xx on x in [0,1) with periodic boundary conditions and t in [0,0.2].
Use nu = 0.005.
Use the initial condition u(x,0) = 0.5 + sin(2*pi*x) with trig in radians.
Use a uniform periodic grid with Nx = 1200 grid points on [0,1) with no duplicated endpoint at x=1.
Set dx = 1/Nx and x_i = i*dx for i = 0..Nx-1.
Use dt = 5e-5 and Nt = 4000 time steps so that T = Nt*dt = 0.2 is reached exactly.
Discretize the convection term in conservative form u_t + (f(u))_x = nu*u_xx with f(u) = 0.5*u^2.
Compute numerical fluxes with the Rusanov (local Lax–Friedrichs) flux F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i) where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
Approximate (f(u))_x at i by (F_{i+1/2} - F_{i-1/2})/dx using periodic wrap-around indexing for i+1 and i-1.
Approximate diffusion with the 2nd-order central difference u_xx ≈ (u_{i+1} - 2u_i + u_{i-1})/dx^2 using periodic wrap-around indexing.
Advance in time with 1st-order IMEX: treat convection explicitly and diffusion implicitly via (u^{n+1} - u^n)/dt + conv^n = nu * L u^{n+1}, where conv^n is the discrete convection term and L is the periodic second-derivative operator.
At each step solve the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv^n with periodic wrap-around in L.
Assemble the resulting sparse cyclic tridiagonal matrix for (I - dt*nu*L) and solve each step with a sparse direct solver (e.g., scipy.sparse.linalg.spsolve).
After Nt steps, compute u(x,T) at T = 0.2 on the same grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
