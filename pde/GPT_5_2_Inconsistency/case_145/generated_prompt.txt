Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx on a periodic domain.
Use x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set nu = 0.04.
Use a uniform periodic grid with Nx=512 points on [0,1).
Define dx = 1/Nx.
Define grid points x[j] = j*dx for j=0..Nx-1.
Set the initial condition u(x,0) = sin(2*pi*x) evaluated at the grid points.
Use Strang splitting for each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute u_hat = FFT(u).
Compute wave numbers k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat = u_hat * exp(-nu*k^2*(dt/2)).
Compute u = real(IFFT(u_hat)).
Perform an advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] using periodic indexing, compute alpha = max(abs(u_left), abs(u_right)).
Compute the numerical flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]) with periodic indexing.
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u <- u_new after the advection substep.
Perform the diffusion half-step again exactly as in the first diffusion half-step.
Choose the time step using CFL=0.4 with an estimated max speed of 1 for this initial condition.
Compute dt0 = CFL*dx/1.0.
Set T = 1.0.
Choose Nt = ceil(T/dt0).
Reset dt = T/Nt so the final time is hit exactly.
Advance the solution for Nt full Strang-splitting steps to reach t = T.
At t = T, compute and print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_burgers_nu0p04.npz containing x (length Nx), u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at t = T as solution_pdebench_burgers_nu0p04.png.
