Solve the 1D linear advection PDE u_t + beta*u_x = 0 for u(x,t).
Use beta = 7.0.
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the time domain t in [0,2.0] with final time T = 2.0.
Impose periodicity so that u(0,t) = u(1,t) for all t, implemented via periodic indexing on the grid.
Use the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x), with trig in radians.
Use a uniform periodic grid with Nx = 512 grid points on [0,1), with dx = 1/Nx and x_j = j*dx for j = 0..Nx-1.
Discretize u_x with a 1st-order upwind finite difference using the upwind direction determined by the sign of beta.
Because beta > 0, approximate u_x at grid point j by (u_j - u_{j-1})/dx with periodic wraparound for j-1.
Advance in time using explicit forward Euler: u^{n+1}_j = u^n_j - dt*beta*(u^n_j - u^n_{j-1})/dx.
Use CFL = 0.5 to set an initial dt0 = CFL*dx/abs(beta).
Choose Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time is hit exactly.
Evolve the solution from t=0 to t=T using Nt steps of size dt.
Compute the reference solution on the same grid at time T as u_ref(x_j,T) = u0(((x_j - beta*T) mod 1)), where u0 is the initial condition function.
Compute and print at t=T the diagnostics min(u), max(u), and the discrete L2 norm sqrt(sum_j(u_j^2)*dx).
Compute and print the error versus the reference solution at t=T as max absolute error max_j |u_j - u_ref_j| and L2 error sqrt(sum_j((u_j - u_ref_j)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta7.npz containing arrays x (length Nx) and u (length Nx), and scalars beta, T, dx, dt, Nx, Nt.
