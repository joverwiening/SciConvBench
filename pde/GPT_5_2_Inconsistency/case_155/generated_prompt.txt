Solve the 1D compressible Navier–Stokes equations without heat conduction in conservative form for unknowns rho(x,t), v(x,t), p(x,t).
Use conservative variables U = [rho, m, E] with m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Use Gamma = 1.6666666666666667 everywhere, and ignore the other Gamma value.
Use dynamic viscosity eta = 0.01.
Use bulk viscosity zeta = eta = 0.01.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Solve on x in [-1, 1] with periodic boundary conditions, and t in [0, 0.5].
Use a uniform finite-volume grid with Nx = 400 cells, dx = 2/Nx, and cell centers x_j = -1 + (j+0.5)*dx for j = 0..Nx-1.
Initialize pointwise at cell centers using rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x), with trig in radians.
Convert initial conditions to conservative cell values using m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Evolve the finite-volume semi-discrete system dU_j/dt = -(F_{j+1/2} - F_{j-1/2})/dx using interface fluxes.
Compute inviscid (Euler) physical flux F_conv(U) = [m, m^2/rho + p, (E+p)*v] with v = m/rho.
Compute the Rusanov numerical flux for the inviscid part at each interface as F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the interface wave speed a = max(|v_L| + c_L, |v_R| + c_R) with c = sqrt(Gamma*p/rho).
Enforce positivity for computations by clipping rho and p to a small floor (e.g., 1e-12) if needed.
Compute cell-centered velocities v_j = m_j/rho_j.
Compute v_x at cell centers using a centered difference on cell-centered v values with periodic wrapping.
Compute cell-centered sigma_j = (zeta + 4/3*eta) * (v_x)_j.
Compute interface sigma_{j+1/2} by averaging neighboring cell-centered sigma values.
Compute interface v_{j+1/2} by averaging neighboring cell-centered v values.
Compute viscous interface flux contribution F_visc = [0, -sigma_{j+1/2}, -v_{j+1/2}*sigma_{j+1/2}].
Set total interface flux F_total = F_hat + F_visc.
Implement periodic boundary conditions by wrapping indices for all reconstructions and differences.
Advance in time using 2-stage SSP-RK2 (Heun’s method) applied to the semi-discrete finite-volume operator.
Choose dt each step using dt_conv = CFL*dx/max_j(|v_j| + c_j) and dt_visc = 0.5*dx^2/max(zeta + 4/3*eta, 1e-30), then dt = min(dt_conv, dt_visc).
Adjust the final time step so that t reaches T = 0.5 exactly.
After reaching T, compute rho(x,T) = rho_j, v(x,T) = m_j/rho_j, and p(x,T) from the equation of state at cell centers.
