Solve the 1D linear advection PDE u_t + beta*u_x = 0 for u(x,t) on a periodic domain.
Use beta = 2.0.
Use spatial domain x in [0,1) with periodic boundary conditions u(0,t)=u(1,t).
Use final time T = 2.0.
Use initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) with trig in radians.
Use a uniform periodic grid with Nx = 512 grid points, dx = 1/Nx, and x_j = j*dx for j=0..Nx-1.
Discretize u_x with 1st-order upwind finite difference using the upwind direction determined by the sign of beta.
For beta > 0, use (u_j - u_{j-1})/dx with periodic indexing u_{-1}=u_{Nx-1}.
Advance in time with explicit forward Euler: u^{n+1} = u^n - dt*beta*(upwind derivative).
Set CFL = 0.5 and compute initial dt0 = CFL*dx/abs(beta).
Set Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time is hit exactly.
Run the time loop for Nt steps to compute u(x,T) on the same periodic grid.
Compute the reference solution on the same grid as u_ref(x_j,T) = u0(((x_j - beta*T) mod 1)).
Compute and print at T: min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error max_j |u_j - u_ref_j| and the L2 error sqrt(sum((u-u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta2.npz containing arrays x (length Nx) and u (length Nx) and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at T as solution_pdebench_advection_beta2.png.
