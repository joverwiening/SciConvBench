Solve the 2D linear advection PDE u_t + a u_x + b u_y = 0 with a = -0.7 and b = 1.2.
Use the spatial domain x in [0,1) and y in [0,1) with periodic boundary conditions in both directions.
Use the time domain t in [0, 0.5] with final time T = 0.5.
Use a uniform periodic grid with Nx = 256 and Ny = 256 grid points, with dx = 1/Nx and dy = 1/Ny.
Define grid coordinates x_i = i*dx for i = 0..Nx-1 and y_j = j*dy for j = 0..Ny-1.
Store the solution as a 2D array u with shape (Ny, Nx) such that u[j,i] corresponds to u(x_i, y_j).
Initialize u(x,y,0) = exp(-80*((x-0.2)^2 + (y-0.6)^2)) evaluated at all grid points.
Discretize u_x using first-order upwind based on the sign of a, using right-biased differencing because a < 0: u_x ≈ (u_{i+1,j} - u_{i,j})/dx with periodic wrap-around in i.
Discretize u_y using first-order upwind based on the sign of b, using left-biased differencing because b > 0: u_y ≈ (u_{i,j} - u_{i,j-1})/dy with periodic wrap-around in j.
Advance in time using Forward Euler: u^{n+1} = u^n - dt*(a*u_x^n + b*u_y^n).
Compute dt0 = 0.9 / (|a|/dx + |b|/dy).
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is reached exactly.
Run Nt time steps to reach t = T.
After reaching T, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) using the final u array.
Save an NPZ file named solution_agent_advection_05.npz containing x (1D array), y (1D array), u (2D array at T), and scalars T, dx, dy, dt.
