Solve the 1D compressible Navier–Stokes equations without heat conduction in conservative form for rho(x,t), m(x,t)=rho*v, and total energy E(x,t).
Use E = p/(Gamma-1) + 0.5*rho*v^2 and equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Use viscous stress sigma = (zeta + 4/3*eta) * v_x with zeta = eta = 1e-08.
Use Gamma = 1.6666666666666667 everywhere, and ignore the other Gamma value.
Solve on x in [-1, 1] and t in [0, 0.2].
Use transmissive/outflow (zero-gradient) boundary conditions at x=-1 and x=1 implemented via ghost cells equal to nearest interior cell.
Use a uniform cell-centered finite-volume grid with Nx=800 cells, dx=2/Nx, and cell centers x_j = -1 + (j+0.5)*dx for j=0..Nx-1.
Initialize a Riemann problem with discontinuity at x=0: for x<0 set rho=1.0, v=0.75, p=1.0; for x>=0 set rho=0.125, v=0.0, p=0.1.
Evolve conservative cell averages U=[rho, m, E] using a semi-discrete finite-volume method with interface fluxes.
Compute inviscid (Euler) numerical flux using Rusanov: F_hat = 0.5*(F_conv(U_L)+F_conv(U_R)) - 0.5*a*(U_R-U_L).
Use F_conv(U) = [m, m^2/rho + p, (E+p)*v] with v=m/rho.
Compute sound speed c = sqrt(Gamma*p/rho) and interface wave speed a = max(|v_L|+c_L, |v_R|+c_R).
Compute v_x using centered differences on cell-centered v values, then compute cell-centered sigma.
Compute interface sigma by averaging neighboring cell-centered sigma values.
Compute viscous interface flux F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Use total interface flux F_total = F_hat + F_visc.
Advance in time with SSP-RK2 (Heun’s method) applied to the finite-volume residual.
At each step compute dt_conv = CFL*dx/max_j(|v_j|+c_j), dt_visc = 0.5*dx^2/max(zeta+4/3*eta, 1e-30), and dt = min(dt_conv, dt_visc).
Adjust the final time step so that t reaches exactly T=0.2.
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) if needed when computing derived quantities.
At final time T compute rho(x,T), v(x,T)=m/rho, and p(x,T) on cell centers.
