Solve the 2D wave equation u_tt = c^2 (u_xx + u_yy) with c = 1.0.
Use the spatial domain (x,y) in [0,1] x [0,1] and time domain t in [0,0.5].
Use a uniform grid with Nx = Ny = 160 intervals, giving (Nx+1) by (Ny+1) grid points including endpoints.
Set dx = (1-0)/Nx and dy = (1-0)/Ny, and define x_i = i*dx for i=0..Nx and y_j = j*dy for j=0..Ny.
Discretize the Laplacian with the standard 5-point stencil on interior nodes: (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2.
Impose Dirichlet boundary conditions u = 0 on all boundaries for all time by setting boundary grid values each time step.
Use second-order central differences in time for u_tt with the explicit update u^{n+1} = 2u^n - u^{n-1} + (c*dt)^2 * Laplacian(u^n) on interior nodes.
Compute dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) with T = 0.5, then set dt = T/Nt so the final time is reached exactly.
Initialize u^0 from u(x,y,0) = sin(pi*x)*sin(2*pi*y) evaluated on the grid.
Initialize u^1 using a Taylor start with initial velocity u_t(x,y,0)=0: u^1 = u^0 + dt*u_t^0 + 0.5*dt^2*c^2*Laplacian(u^0) on interior nodes, then enforce boundary values u=0.
Advance the solution for n = 1..Nt-1 using the explicit update, enforcing boundary values u=0 at every step.
At final time T, compute u(x,y,T) on the same grid.
Evaluate the reference solution u_exact(x,y,T) = cos(1.0*pi*sqrt(5)*T)*sin(pi*x)*sin(2*pi*y) on the same grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum_{i,j} u_{j,i}^2 * dx * dy) at T.
Compute and print the max absolute error max_{i,j} |u_{j,i} - u_exact_{j,i}| and the L2 error sqrt(sum_{i,j} (u_{j,i}-u_exact_{j,i})^2 * dx * dy) at T.
