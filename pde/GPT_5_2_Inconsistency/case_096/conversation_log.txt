Q: In the PDE you wrote the wave speed as (1.0)^2 but in the parameters you set c = 2; which value should be used for the CFL condition and the time stepping update (the wave speed in u_tt = c^2 (u_xx + u_yy))?
A: Use **c = 1.0**.

The PDE is \(u_{tt} = (1.0)^2 (u_{xx}+u_{yy})\) and the complete requirement specifies **Parameters: c = 1.0**, consistent with the exact solution. So use **c=1.0** both in the time-stepping update and in the CFL calculation.
