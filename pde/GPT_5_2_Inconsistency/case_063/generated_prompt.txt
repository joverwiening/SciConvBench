Solve the 2D Laplace equation u_xx + u_yy = 0 for u(x,y).
Use the spatial domain (x,y) in [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals so there are 101x101 grid points including boundaries.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Store the solution in an array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
Enforce Dirichlet boundary conditions on all four edges: u(x,0)=0, u(x,1)=sin(pi*x), u(0,y)=0, u(1,y)=0, using radians for trig.
Do not apply periodic boundary conditions anywhere.
Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil.
Assemble the sparse linear system for the interior unknowns only, incorporating Dirichlet boundary values into the right-hand side.
Solve the resulting sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Construct the full grid solution u including boundary values after solving for interior nodes.
Evaluate the reference solution u_exact(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi) on the same grid.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete L2 norm sqrt(sum(u^2)*dx*dy) over the full grid.
Compute and print the max absolute error max(|u-u_exact|) over the full grid.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over the full grid.
