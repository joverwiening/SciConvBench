Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu=0.1.
Use spatial domain x in [0,1) with periodic boundary conditions.
Use time domain t in [0,1.0] with final time T=1.0.
Use a uniform periodic grid with Nx=512 points, dx=1/Nx, and x_j=j*dx for j=0..Nx-1.
Set the initial condition u(x,0)=sin(2*pi*x) evaluated at the grid points.
Choose CFL=0.4 and dt0=CFL*dx/1.0.
Set Nt=ceil(T/dt0) and then set dt=T/Nt so the final time is hit exactly.
Advance the solution with Strang splitting for each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space by FFT(u) to u_hat, using k=2*pi*fftfreq(Nx,d=dx), multiplying u_hat by exp(-nu*k^2*(dt/2)), then inverse FFT and taking the real part.
Perform an advection full-step of duration dt for the inviscid Burgers equation using a finite-volume update with Rusanov flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, compute alpha=max(abs(u_left),abs(u_right)) and F=0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, compute F_plus as the flux between (u[j],u[j+1]) and F_minus as the flux between (u[j-1],u[j]) with periodic indexing, then update u_new[j]=u[j]-(dt/dx)*(F_plus-F_minus).
Replace u with u_new after the advection substep.
Perform the diffusion half-step again as in the first diffusion half-step.
After Nt steps, treat the result as u(x,T) at T=1.0.
Compute and print min(u), max(u), mean(u) as the discrete mean over grid points, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Save an NPZ file named solution_pdebench_burgers_nu0p1.npz containing arrays x (length Nx) and u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
