Solve the 2D variable-coefficient elliptic PDE -∇·(a(x,y)∇u(x,y)) = 1 on the open domain (0,1)×(0,1).
Use Dirichlet boundary conditions only: set u=0 on the entire boundary of the unit square, and do not apply periodic boundary conditions.
Set beta = 0.01.
Define a(x,y) = 1 + beta*(0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)) using radians for trig.
Use a uniform Cartesian grid with N=128 intervals in each direction, giving (N+1)×(N+1) grid points including boundaries.
Use dx=dy=1/N, x_i=i*dx for i=0..N, and y_j=j*dy for j=0..N.
Represent u on the full grid as u[i,j] corresponding to (x_i,y_j).
Impose boundary values u[i,0]=u[i,N]=u[0,j]=u[N,j]=0 for all valid i,j.
For interior nodes i=1..N-1 and j=1..N-1, discretize with 2nd-order finite differences using face-centered harmonic averaging:
Compute nodal coefficients a[i,j]=a(x_i,y_j).
Compute harmonic face coefficients:
a_iphalf = 2*a[i,j]*a[i+1,j]/(a[i,j]+a[i+1,j]) for the (i+1/2,j) face.
a_imhalf = 2*a[i,j]*a[i-1,j]/(a[i,j]+a[i-1,j]) for the (i-1/2,j) face.
a_jphalf = 2*a[i,j]*a[i,j+1]/(a[i,j]+a[i,j+1]) for the (i,j+1/2) face.
a_jmhalf = 2*a[i,j]*a[i,j-1]/(a[i,j]+a[i,j-1]) for the (i,j-1/2) face.
Enforce the interior discrete equation:
-(1/dx^2)*[ a_iphalf*(u[i+1,j]-u[i,j]) - a_imhalf*(u[i,j]-u[i-1,j]) + a_jphalf*(u[i,j+1]-u[i,j]) - a_jmhalf*(u[i,j]-u[i,j-1]) ] = 1.
Assemble the sparse linear system Au=b for the interior unknowns only, using a consistent interior indexing mapping from (i,j) with i=1..N-1, j=1..N-1 to a 1D vector.
Incorporate Dirichlet boundary values by treating boundary u values as known (zero) when forming the right-hand side contributions for interior equations.
Solve Au=b using conjugate gradient (CG) to relative residual tolerance 1e-10.
Optionally apply a Jacobi (diagonal) preconditioner.
After solving, place the interior solution back into a full (N+1)×(N+1) array u with boundary values equal to zero.
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete residual norm for the interior system as ||Au-b||_2 / ||b||_2 using the assembled A, b, and the solved interior vector.
