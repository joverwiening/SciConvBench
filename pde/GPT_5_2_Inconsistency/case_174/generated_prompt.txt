Implement the solver in Python 3.
Use NumPy for arrays and FFTs, and Matplotlib for plotting.
Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set parameters nu=0.5 and rho=2.0.
Use a uniform periodic grid with Nx=512 points on [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Initialize u(x,0)=0.25+0.1*sin(2*pi*x) using radians.
Use a fixed time step dt=0.001 with Nt=1000 steps so that T=Nt*dt=1.0 exactly.
Advance the solution using Strang splitting for each full time step dt.
For each time step, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space by computing u_hat=FFT(u), defining k=2*pi*fftfreq(Nx,d=dx), updating u_hat=u_hat*exp(-nu*k^2*(dt/2)), and setting u=real(IFFT(u_hat)).
Then perform a reaction full-step of duration dt solved exactly pointwise via u=(u*exp(rho*dt))/(1+u*(exp(rho*dt)-1)).
Then perform the same diffusion half-step again.
After Nt steps, treat the result as u(x,T=1.0) on the periodic grid.
Compute and print at T the scalar diagnostics min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
