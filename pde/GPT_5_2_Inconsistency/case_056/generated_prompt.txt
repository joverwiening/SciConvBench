Solve the 1D Klein–Gordon PDE u_tt − (1.2)^2 u_xx + (0.8)^2 u = 0 on x ∈ [0,1] with Dirichlet boundaries u(0,t)=0 and u(1,t)=0.
Use initial conditions u(x,0)=sin(3*pi*x) and u_t(x,0)=0.
Use the reference solution u_exact(x,t)=cos(sqrt((1.2*3*pi)^2 + (0.8)^2)*t)*sin(3*pi*x) for verification.
Discretize space with a uniform grid on [0,1] using Nx=600 uniform intervals and Nx+1 grid points.
Set dx = 1/Nx and x_i = i*dx for i=0..Nx.
Approximate u_xx with 2nd-order central differences on interior points i=1..Nx−1.
Enforce Dirichlet boundary values u_0^n=0 and u_Nx^n=0 for all time levels n.
Use leapfrog (2nd-order central difference in time) for u_tt with the +m^2*u term handled explicitly at time level n in the update.
Choose dt0 = 0.9*dx/c with c=1.2.
Set final time T=0.7.
Set Nt = ceil(T/dt0) and then set dt = T/Nt so that the final time is hit exactly.
Initialize u^0 from u(x,0) on the grid.
Initialize u^1 using a Taylor start with v0=u_t(x,0) and including the PDE acceleration term u_tt(x,0)=c^2*u_xx(x,0)−m^2*u(x,0) with m=0.8, using the same 2nd-order spatial discretization for u_xx.
For each time step n=1..Nt−1, update interior points with u_i^{n+1} = 2*u_i^n − u_i^{n−1} + dt^2*(c^2*(u_{i+1}^n − 2*u_i^n + u_{i−1}^n)/dx^2 − m^2*u_i^n).
After stepping, take u(x,T) as u^Nt.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Evaluate u_exact(x,T) on the same x grid.
Compute and print the max absolute error max(|u−u_exact|) and the L2 error sqrt(sum((u−u_exact)^2)*dx).
