Solve the 1D linear advection PDE u_t + (1.0)*u_x = 0 for u(x,t).
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the time domain t in [0,1.0] with final simulation time T = 1.0.
Use parameter a = 1.0 as the advection speed.
Use the initial condition u(x,0) = sin(2*pi*x) with trig in radians.
Use the exact solution for verification u_exact(x,t) = sin(2*pi*(x-(1.0)*t)).
Discretize space with a uniform periodic grid with Nx = 800 points on [0,1) with no duplicated endpoint.
Define dx = 1/Nx and x_i = i*dx for i = 0..Nx-1.
Approximate u_x with 1st-order upwind consistent with a = 1.0, i.e., (u_i - u_{i-1})/dx.
Implement periodic wrap-around indexing so u_{-1} refers to u_{Nx-1}.
Advance in time using Forward Euler.
Choose dt0 = 0.9*dx/|a|.
Set Nt = ceil(T/dt0).
Set dt = T/Nt so that the final time T is reached exactly after Nt steps.
Compute the numerical solution u(x,T=1.0) on the grid.
Evaluate the reference solution u_exact(x,T) on the same x grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error max(|u - u_exact|) at T.
Compute and print the L2 error sqrt(sum((u - u_exact)^2)*dx) at T.
Save an NPZ file named solution_agent_advection_01.npz containing arrays x (1D) and u (1D) and scalars T, dx, dt.
