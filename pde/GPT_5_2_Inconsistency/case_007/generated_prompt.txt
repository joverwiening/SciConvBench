Solve the 1D Allen–Cahn PDE u_t = (0.01)^2 u_xx + u − u^3 for u(x,t).
Use the spatial domain x in [0,1) with periodic boundary conditions for both u and u_x.
Use the time domain t in [0,0.5] and compute the solution at T = 0.5.
Use the initial condition u(x,0) = 0.1*cos(2*pi*x) + 0.05*sin(4*pi*x) with trig in radians.
Use a uniform periodic grid with Nx = 800 grid points on [0,1) (no duplicated endpoint).
Define dx = (1−0)/Nx and x_i = 0 + i*dx for i = 0..Nx−1.
Discretize u_xx with 2nd-order central differences using periodic wrap-around indexing.
Use the semi-implicit time stepping scheme (u^{n+1} − u^n)/dt = ε^2*(u_xx)^{n+1} + u^n − (u^n)^3 with ε = 0.01.
Use dt = 0.0002 for 2500 time steps to reach T = 0.5 exactly.
At each time step, form and solve the linear system (I − dt*ε^2*L) u^{n+1} = u^n + dt*(u^n − (u^n)^3), where L is the periodic Laplacian matrix from the central-difference stencil.
Compute u(x,T) on the same grid used for the simulation.
Save an NPZ file named solution_agent_allen_cahn_01.npz containing arrays x (1D) and u (1D, same length as x) and scalars T, dx, dt.
Save a line plot of u versus x at T as solution_agent_allen_cahn_01.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
