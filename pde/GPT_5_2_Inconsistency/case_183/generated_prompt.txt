Implement a Python 3 script that numerically solves the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu=1.0 and rho=5.0.
Use a uniform periodic spatial grid with Nx=512 points on [0,1) defined by dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Initialize u(x,0)=0.25+0.1*sin(2*pi*x) evaluated on the grid using radians.
Use a fixed time step dt=0.001 and Nt=1000 steps so that T=Nt*dt=1.0 is reached exactly.
Advance the solution with Strang splitting for each full time step dt.
For each time step, perform a diffusion half-step of duration dt/2 by FFT: compute u_hat=FFT(u) using numpy.fft.fft.
For the diffusion operator, use k = 2*pi*numpy.fft.fftfreq(Nx, d=dx) and multiply u_hat by exp(-nu*k^2*(dt/2)) elementwise.
Compute u = real(IFFT(u_hat)) using numpy.fft.ifft and take the real part.
Perform the reaction full-step of duration dt pointwise using the exact logistic update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the second diffusion half-step identical to the first diffusion half-step.
After Nt steps, treat the result as u(x,T=1.0) on the same periodic grid.
Compute and print at T the scalar diagnostics: min(u), max(u), mean(u), and discrete L2 norm defined as sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu1_rho5.npz containing arrays x (shape (Nx,)) and u (shape (Nx,)) and scalars nu, rho, T, dx, dt, Nx, Nt.
Generate and save a line plot of u versus x at T as solution_pdebench_reacdiff_nu1_rho5.png using Matplotlib.
