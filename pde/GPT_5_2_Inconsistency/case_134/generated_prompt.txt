Implement a numerical solver for Task ID molk_033 in a single runnable Python script named molk_033.py.
Solve the 1D periodic advection–diffusion PDE u_t = D*u_xx - ∂_x(F) on x in [0,1) and t in [0,1.0], where F(x,t) = (1/gamma)*U'(x)*u(x,t).
Use parameters D=0.01 and gamma=1.0.
Use U(x)=cos(2*pi*x) and U'(x)=-2*pi*sin(2*pi*x), with trig in radians.
Use a uniform periodic grid with Nx=512 points on [0,1) defined by x_j = j*dx for j=0..Nx-1 with dx=1/Nx.
Represent u as a length-Nx NumPy array corresponding to values at x_j.
Impose periodicity by using wrap-around indexing for all spatial operators.
Initialize u(x,0) = 1.0 + 0.2*sin(2*pi*x) evaluated on the grid.
Discretize diffusion with second-order central differences: u_xx[j] = (u[j+1]-2*u[j]+u[j-1]) / dx^2 with periodic wrap.
Discretize the conservative drift term -∂_x(F) using a finite-volume upwind numerical flux at interfaces j+1/2.
Define interface locations x_{j+1/2} = (j+0.5)*dx modulo 1 and interface velocities b_{j+1/2} = U'(x_{j+1/2})/gamma.
Compute upwind interface fluxes F_{j+1/2} = b_{j+1/2} * u_upwind where u_upwind = u[j] if b_{j+1/2}>=0 else u[j+1], with periodic wrap for j+1.
Compute the drift derivative as (∂_x F)[j] ≈ (F_{j+1/2} - F_{j-1/2})/dx with periodic wrap.
Form the semi-discrete RHS as RHS(u)[j] = D*u_xx[j] - ( (F_{j+1/2}-F_{j-1/2})/dx ).
Advance in time with explicit SSP-RK2 (Heun): u1 = u^n + dt*RHS(u^n); u^{n+1} = 0.5*u^n + 0.5*(u1 + dt*RHS(u1)).
Choose dt from dt0 = min(0.4*dx/max|b|, 0.2*dx^2/D) where max|b| is taken over the interface velocities b_{j+1/2}.
Set Nt = ceil(T/dt0) with T=1.0 and then set dt = T/Nt so the final time is reached exactly in Nt steps.
Run the solver from t=0 to t=T=1.0 and compute u(x,T) on the same periodic grid.
After completion, print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
