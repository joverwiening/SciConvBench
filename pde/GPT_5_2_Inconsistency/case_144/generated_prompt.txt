Use spatial domain x in [0, 1) with periodic boundary conditions.

Set final time T = 1.0.

Choose time step using CFL = 0.4 with estimated max speed 1.0.

Advance the solution from t=0 to t=T using Strang splitting each full time step dt.

Update u_hat = u_hat * exp(-nu*k^2*(dt/2)).
Compute u = real(IFFT(u_hat)) using numpy.fft.ifft and take the real part.

For each interface between indices j and j+1 with periodic indexing, set u_left = u[j] and u_right = u[(j+1) mod Nx].
Compute alpha = max(abs(u_left), abs(u_right)).
Compute interface flux F[j] = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, set F_plus = F[j] and F_minus = F[(j-1) mod Nx].
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
Perform the second diffusion half-step identical to the first diffusion half-step.
