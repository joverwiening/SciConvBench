Solve the 1D compressible Navier–Stokes equations without heat conduction on x in [-1, 1] and t in [0, 0.2].
Use conservative variables U = [rho, m, E] with m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Use Gamma = 1.6666666666666667 for the equation of state and sound speed.
Use eta = 1e-08 and zeta = eta = 1e-08.
Define viscous stress sigma = (zeta + 4/3*eta) * v_x.
Evolve the conservative PDE system: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
Use a uniform finite-volume grid with Nx = 800 cells on [-1, 1].
Use cell centers x_j = -1 + (j+0.5)*dx for j = 0..Nx-1 with dx = 2/Nx.
Store U as cell averages at cell centers.
Initialize a Riemann problem with discontinuity at x = 0.
Set for x < 0: rho = 1.0, v = 0.0, p = 1.0.
Set for x >= 0: rho = 0.1, v = 0.0, p = 0.1.
Convert initial primitive variables to conservative variables using m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Apply transmissive/outflow boundary conditions at x = -1 and x = 1 by setting ghost cell values equal to the nearest interior cell values (zero-gradient).
Use a Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
Compute primitive variables from U using v = m/rho and p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) when needed for stability and diagnostics.
Define inviscid flux F_conv(U) = [m, m^2/rho + p, (E+p)*v].
At each interface, compute c = sqrt(Gamma*p/rho) on left and right states and set a = max(|v_L| + c_L, |v_R| + c_R).
Compute the Rusanov inviscid interface flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute v_x using a centered difference on cell-centered v values, using ghost cells to support the stencil at boundaries.
Compute cell-centered sigma = (zeta + 4/3*eta) * v_x.
Approximate interface sigma by averaging neighboring cell-centered sigma values.
Approximate interface v by averaging neighboring cell-centered v values.
Define viscous interface flux F_visc = [0, -sigma, -v*sigma] using the interface-averaged v and sigma.
Define total interface flux F_total = F_hat + F_visc.
Advance the semi-discrete finite-volume system with 2-stage SSP-RK2 (Heun’s method).
At each time step compute dt_conv = CFL * dx / max_j(|v_j| + c_j) over all cells.
At each time step compute dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc).
Adjust the final time step so that the integration ends exactly at T = 0.2.
After reaching T, compute rho(x,T), v(x,T), p(x,T) on the cell centers.
