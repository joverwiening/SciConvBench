Solve the 2D linear advection PDE u_t + 1.0*u_x + 0.5*u_y = 0 for u(x,y,t).
Use the periodic spatial domain (x,y) in [0,1) x [0,1) with no duplicated endpoints.
Use final time T = 1.0.
Use a uniform grid with Nx = Ny = 256 points.
Define dx = 1/Nx and dy = 1/Ny.
Define x_i = i*dx for i = 0..Nx-1 and y_j = j*dy for j = 0..Ny-1.
Store u as a 2D array with shape (Ny, Nx) such that u[j,i] = u(x_i, y_j).
Use the initial condition u(x,y,0) = sin(2*pi*x)*cos(2*pi*y) with trig in radians.
Use first-order upwind finite differences in x and y on the periodic grid.
For upwinding, use backward difference in x because a = 1.0 > 0 and backward difference in y because b = 0.5 > 0.
Implement periodic wrap-around indexing in both directions for the upwind stencils.
Use Forward Euler time integration.
Compute dt0 = 0.9 / (|a|/dx + |b|/dy) with a = 1.0 and b = 0.5.
Compute Nt = ceil(T/dt0).
Set dt = T/Nt so that the final time is reached exactly.
Advance the solution for Nt steps to reach t = T.
Compute the reference solution on the same grid at time T using u_exact(x,y,T) = sin(2*pi*(x-1.0*T))*cos(2*pi*(y-0.5*T)).
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at time T.
Compute and print the max absolute error max(|u - u_exact|) at time T.
Compute and print the L2 error sqrt(sum((u - u_exact)^2)*dx*dy) at time T.
