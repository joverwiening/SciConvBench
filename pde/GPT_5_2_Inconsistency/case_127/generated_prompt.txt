Solve the 1D linear advection–diffusion PDE u_t = -q1 * ∂_x(u) + (q2/pi) * u_xx on x in [0,1) with periodic boundary conditions and t in [0,0.5].
Use parameters q1 = 1.0 and q2 = 0.05.
Use the periodic uniform grid with Nx = 512 points, x_j = j*dx for j=0..Nx-1, and dx = 1/Nx.
Initialize u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x) evaluated at the grid points using radians.
Discretize ∂_x(u) with 1st-order upwind consistent with the sign of q1, using periodic indexing.
Discretize u_xx with 2nd-order central differences using periodic indexing.
Advance in time with IMEX Euler: treat the advection term explicitly and the diffusion term implicitly each step.
At each time step, form the right-hand side as u^n + dt * ( -q1 * D_upwind(u^n) ).
Solve for u^{n+1} from (I - dt*(q2/pi)*D2) u^{n+1} = RHS, where D2 is the periodic second-derivative central-difference operator.
Implement the implicit diffusion solve as a periodic circulant linear system solve (e.g., via FFT diagonalization of the circulant operator or an equivalent exact circulant solver).
Choose dt = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)), then set Nt = ceil(T/dt) and reset dt = T/Nt with T = 0.5.
Run Nt steps to compute u(x,T) on the same periodic grid.
Compute the reference solution at T by Fourier-mode evolution for the two initial sine modes and evaluate it on the same x grid.
Compute and print at T: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx).
Compute and print the max absolute error and L2 error versus the reference solution on the same grid.
