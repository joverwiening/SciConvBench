Solve the 2D Laplace equation u_xx + u_yy = 0 for u(x,y).
Use the spatial domain (x,y) in [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1) by (Ny+1) grid points including boundaries.
Define dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Impose Dirichlet boundary conditions on all four edges using u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi) evaluated at boundary grid points.
Do not apply periodic boundary conditions.
Discretize the Laplacian on interior nodes using the standard 2nd-order 5-point finite difference stencil.
Assemble the resulting sparse linear system for the interior unknowns only, incorporating boundary values into the right-hand side.
Solve the sparse linear system using a sparse direct solver such as scipy.sparse.linalg.spsolve.
Construct the full solution array u on the entire grid including boundary values.
Evaluate the reference solution u_exact(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi) on the same grid for verification.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) over all grid points.
Compute and print the max absolute error max(|u-u_exact|) over all grid points.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over all grid points.
