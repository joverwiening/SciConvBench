Implement the solver in Python 3.
Use NumPy for arrays and FFT via numpy.fft.
Use Matplotlib to generate and save the plot.
Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set parameters nu=2.0 and rho=2.0.
Use a uniform periodic grid with Nx=512 points on [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Set the initial condition u(x,0)=0.25+0.1*sin(2*pi*x) evaluated at the grid points using radians.
Use a fixed time step dt=0.001 with Nt=1000 steps so that T=Nt*dt=1.0 exactly.
Advance the solution using Strang splitting for each full time step dt.
Perform the diffusion half-step of duration dt/2 by transforming u to Fourier space with FFT, multiplying each Fourier mode by exp(-nu*k^2*(dt/2)), and transforming back with IFFT, taking the real part.
Compute the wavenumber array as k = 2*pi*fftfreq(Nx, d=dx).
Perform the reaction full-step of duration dt by applying the exact logistic update pointwise: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform the second diffusion half-step identical to the first diffusion half-step.
After Nt steps, treat the result as u(x,T=1.0) on the periodic grid.
Compute and print at T the following diagnostics: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_reacdiff_nu2_rho2.npz containing x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
