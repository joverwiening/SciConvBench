Solve the 1D wave equation u_tt = (1.0)^2 u_xx for u(x,t).
Use wave speed c = 1.0 everywhere in the solver, CFL condition, and initialization.
Use the spatial domain x in [0,1] with Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0.
Use the time domain t in [0,0.8] with final time T = 0.8.
Use initial displacement u(x,0)=sin(pi*x) + 0.5*sin(3*pi*x).
Use initial velocity u_t(x,0)=0.
Use the reference solution u_exact(x,t)=cos(1.0*pi*t)*sin(pi*x) + 0.5*cos(1.0*3*pi*t)*sin(3*pi*x) for verification.
Discretize space with a uniform grid on [0,1] using Nx=600 uniform intervals and Nx+1 grid points.
Set dx = 1/Nx and x_i = i*dx for i=0..Nx.
Approximate u_xx at interior points with 2nd-order central differences.
Use 2nd-order central differences in time for u_tt (leapfrog / Störmer–Verlet) to advance the solution.
Choose dt using dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that t=T is reached exactly.
Initialize u^0 at t=0 from u0(x) on the grid.
Compute u_xx^0 from u^0 using the same spatial stencil.
Initialize the first time level using the Taylor start u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0) with v0(x)=0 and no forcing.
At every time step, enforce Dirichlet boundary values by setting the boundary nodes to 0.
Advance interior nodes for n>=1 using u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (c*dt/dx)^2*(u^n_{i+1} - 2*u^n_i + u^n_{i-1}).
Compute the numerical solution u(x,T) on the grid at t=T.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute u_exact(x,T) on the same x grid.
Compute and print the max absolute error max(|u-u_exact|) and the L2 error sqrt(sum((u-u_exact)^2)*dx) at T.
