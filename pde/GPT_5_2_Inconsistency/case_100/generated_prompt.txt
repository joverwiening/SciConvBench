Solve the 2D wave equation u_tt = (1.0)^2 (u_xx + u_yy) for u(x,y,t).
Use the spatial domain (x,y) in [0,1) x [0,1) with periodic boundary conditions in both x and y.
Use the time domain t in [0, 0.5] with final time T = 0.5.
Use wave speed c = 1.0.
Use a uniform periodic grid with Nx = Ny = 128 points on [0,1) in each direction with no duplicated endpoints.
Define dx = 1/Nx and dy = 1/Ny.
Define x_i = i*dx for i = 0..Nx-1 and y_j = j*dy for j = 0..Ny-1.
Discretize u_xx and u_yy with 2nd-order central differences using wrap-around indexing for periodicity.
Use 2nd-order central differences in time for u_tt.
Initialize with u(x,y,0) = cos(2*pi*x)*cos(2*pi*y) evaluated on the grid.
Initialize with u_t(x,y,0) = 0 evaluated on the grid.
Use a Taylor start to compute u at the first time level using the periodic Laplacian: u^1 = u^0 + dt*u_t^0 + 0.5*dt^2*c^2*Lap(u^0).
Choose dt by first computing dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0).
Set dt = T/Nt so that the final time is hit exactly.
Advance for n = 1..Nt-1 using u^{n+1} = 2*u^n - u^{n-1} + (dt^2)*c^2*Lap(u^n).
Compute the numerical solution u(x,y,T) on the same grid at t = T.
Compute the reference solution u_exact(x,y,T) = cos(2*pi*x)*cos(2*pi*y)*cos(1.0*2*pi*sqrt(2)*T) evaluated on the same grid.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute and print the max absolute error max(|u - u_exact|) at T.
Compute and print the L2 error sqrt(sum((u - u_exact)^2)*dx*dy) at T.
