Solve the 1D linear advection PDE u_t + beta*u_x = 0 for u(x,t).
Use the spatial domain x in [0,1) with periodic boundary conditions.
Use the time domain t in [0,2.0] with final time T=2.0.
Set beta = 0.7.
Impose periodicity u(0,t)=u(1,t) for all t.
Set the initial condition u(x,0)=sin(2*pi*x)+0.5*sin(4*pi*x) using radians.
Use a uniform periodic grid with Nx=512 grid points on [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Discretize u_x with 1st-order upwind finite differences using the upwind direction determined by the sign of beta.
For beta>0, use u_x(x_j) ≈ (u_j - u_{j-1})/dx with periodic wrap u_{-1}=u_{Nx-1}.
Advance in time with explicit forward Euler: u^{n+1}_j = u^n_j - dt*beta*(u^n_j - u^n_{j-1})/dx (for beta>0).
Use CFL=0.5 to set an initial dt0 = CFL*dx/abs(beta).
Choose Nt = ceil(T/dt0) and then reset dt = T/Nt so the final time is hit exactly.
Evolve the solution from t=0 to t=T using Nt steps of size dt.
Compute the reference solution on the same grid as u_ref(x_j,T)=u0(((x_j - beta*T) mod 1)) where u0 is the initial condition function.
At t=T, compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
At t=T, compute and print the max absolute error max_j |u_j-u_ref_j| and the L2 error sqrt(sum((u-u_ref)^2)*dx).
Save an NPZ file named solution_pdebench_advection_beta0p7.npz containing arrays x (length Nx) and u (length Nx) and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at t=T as solution_pdebench_advection_beta0p7.png.
