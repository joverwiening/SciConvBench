Use Python 3.
Use NumPy for arrays and grid generation.
Use SciPy scipy.sparse to assemble the sparse matrix and scipy.sparse.linalg.spsolve as the linear solver.
Use Matplotlib to generate and save the plot.

Solve the 2D Laplace equation u_xx + u_yy = 0 on the domain (x,y) in [0,1] x [0,1].
Use a uniform grid with Nx=Ny=100 intervals, giving (Nx+1) by (Ny+1) grid points.
Define dx=dy=1/Nx.
Define x_i=i*dx for i=0..Nx.
Define y_j=j*dy for j=0..Ny.
Store the solution as u[j,i] = u(x[i], y[j]) with u having shape (len(y), len(x)).

Apply Dirichlet boundary conditions on all four edges.
Set u(x,y)=y on the entire boundary of the square, i.e., for i=0 or i=Nx or j=0 or j=Ny set u[j,i]=y[j].
Do not apply periodic boundary conditions.

Discretize the Laplacian on interior nodes using the standard 5-point second-order finite difference stencil.
For each interior node (i,j) with 1<=i<=Nx-1 and 1<=j<=Ny-1, enforce (u_{i+1,j}-2u_{i,j}+u_{i-1,j})/dx^2 + (u_{i,j+1}-2u_{i,j}+u_{i,j-1})/dy^2 = 0.
Assemble a sparse linear system A * u_interior = b for the unknown interior values only.
Incorporate Dirichlet boundary values into the right-hand side b wherever the stencil references boundary nodes.

Solve the sparse linear system using scipy.sparse.linalg.spsolve.
Reconstruct the full (Ny+1, Nx+1) array u including boundary values.

Define the reference solution u_exact(x,y)=y evaluated on the same grid as u_exact[j,i]=y[j].
Compute and print min(u) and max(u) over the full grid.
Compute and print the discrete L2 norm sqrt(sum(u^2)*dx*dy) over the full grid.
Compute and print the max absolute error max(|u-u_exact|) over the full grid.
Compute and print the discrete L2 error sqrt(sum((u-u_exact)^2)*dx*dy) over the full grid.
