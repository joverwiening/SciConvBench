Implement a Python 3 script that numerically solves the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use nu = 0.4.
Use a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and x[j] = j*dx for j = 0..Nx-1.
Initialize u(x,0) = sin(2*pi*x) using radians.
Choose CFL = 0.4 and estimate max speed as 1.0 to set dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) with T = 1.0 and then set dt = T/Nt so the final time is hit exactly.
Advance the solution for Nt time steps using Strang splitting per full step dt.
Perform the diffusion half-step of duration dt/2 exactly in Fourier space using numpy.fft.
Compute u_hat = FFT(u).
Compute the wavenumber array k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat <- u_hat * exp(-nu*k^2*(dt/2)).
Compute u <- real(IFFT(u_hat)).
Perform the advection full-step of duration dt for the inviscid Burgers equation using a finite-volume update with Rusanov flux.
Define f(u) = 0.5*u^2.
For each interface j between cells j and j+1 with periodic indexing, set u_left = u[j], u_right = u[(j+1) mod Nx], alpha = max(abs(u_left), abs(u_right)), and F[j] = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left).
For each cell j, set F_plus = F[j] and F_minus = F[(j-1) mod Nx], then update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u <- u_new after the advection substep.
Perform the diffusion half-step again identically to the first diffusion half-step.
After time integration, produce the solution at the final time T = 1.0 on the periodic grid.
Save an NPZ file named solution_pdebench_burgers_nu0p4.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u versus x at final time as solution_pdebench_burgers_nu0p4.png using Matplotlib.
Print min(u), max(u), mean(u) computed as the discrete average of u over grid points, and the discrete L2 norm computed as sqrt(sum(u^2)*dx) at the final time.
Use only Python 3 with NumPy (including numpy.fft) and Matplotlib as dependencies.
