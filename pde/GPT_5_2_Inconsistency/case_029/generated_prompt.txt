Solve the 2D diffusion-reaction PDE u_t = D*(u_xx + u_yy) + r*u*(1 - u/K) with D=0.02, r=3.0, K=1.0.
Use the spatial domain (x,y) in [0,1]×[0,1] and time domain t in [0,0.5].
Use a uniform grid with Nx=Ny=120 intervals, giving (Nx+1)×(Ny+1) grid points including boundaries.
Define dx=dy=1/Nx, x_i=i*dx for i=0..Nx, and y_j=j*dy for j=0..Ny.
Impose Dirichlet boundary conditions u=0 on all four edges for all times.
Do not apply periodic boundary conditions and do not identify endpoints.
Set the initial condition u(x,y,0)=0.8*exp(-40*((x-0.5)^2 + (y-0.5)^2)) evaluated at all grid points, then enforce boundary nodes to u=0.
Use a 5-point finite-difference Laplacian on the uniform grid for the diffusion term.
Form the unknown vector only from interior nodes (i=1..Nx-1, j=1..Ny-1), giving (Nx-1)×(Ny-1) unknowns.
Treat boundary nodes as fixed zeros and incorporate their contributions when assembling the interior RHS (which are zero contributions here because boundary values are zero).
Use deterministic first-order IMEX time stepping with diffusion implicit (backward Euler) and reaction explicit (forward Euler).
Use dt=0.0005 and Nt=1000 steps to reach T=0.5 exactly.
At each step compute the reaction term on interior nodes as R(u)=r*u*(1-u/K) using u at time level n.
At each step solve (I - dt*D*L) u^{n+1} = u^n + dt*R(u^n) for the interior unknowns, where L is the interior-node discrete Laplacian operator consistent with Dirichlet boundaries.
Assemble (I - dt*D*L) as a sparse matrix and use a sparse direct solver each time step.
After each solve, write the interior solution back into a full (Ny+1)×(Nx+1) array and enforce boundary nodes to exactly zero.
After Nt steps, define the final solution u(x,y,T) on the full grid with shape (len(y), len(x)) such that u[j,i]=u(x[i],y[j],T).
