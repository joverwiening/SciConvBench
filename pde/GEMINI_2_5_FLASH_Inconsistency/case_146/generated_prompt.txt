The simulation solves the 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.1.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: Diffusion half-step (duration dt/2), Advection full-step (duration dt), and Diffusion half-step (duration dt/2).
The diffusion half-step is solved exactly in Fourier space.
For the diffusion half-step, compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Then compute u = IFFT(u_hat) and take the real part.
The advection full-step solves the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The updated value for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated max speed is 1.0.
Calculate Nt = ceil(T/dt0), where T=1.0.
Reset dt = T/Nt to ensure the final time T is hit exactly.
Compute u(x,T=1.0) on the periodic grid.
