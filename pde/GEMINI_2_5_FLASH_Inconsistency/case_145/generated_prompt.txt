The task is to numerically solve the 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.04.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), solve exactly in Fourier space.
Transform u to Fourier space: u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Transform back to real space: u = IFFT(u_hat), taking the real part.
For the advection full-step (B), solve the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
The time step dt is determined by CFL=0.4 based on an estimated max speed of 1.
Calculate dt0 = CFL*dx/1.0.
Determine the number of time steps Nt = ceil(T/dt0).
Reset dt = T/Nt to hit the final time T exactly.
Compute u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_burgers_nu0p04.npz".
The .npz file must contain the 1D arrays x (length Nx) and u (length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p04.png".
The plot should show u on the y-axis and x on the x-axis.
Report (print to console) the minimum value of u, the maximum value of u, the discrete mean value of u (mean(u)), and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
