The PDE to be solved numerically is u_tt = (0.8)^2 * u_xx.
The spatial domain is x in [0,1] and the temporal domain is t in [0,1.0].
The wave speed for all calculations, including the PDE, CFL condition, and Taylor start, is 0.8.
Dirichlet boundary conditions are applied at x=0 and x=1, where u=0.
The initial conditions are u(x,0)=0 and u_t(x,0)=sin(2*pi*x).
The reference exact solution for verification is u(x,t) = (1/(0.8*2*pi))*sin(0.8*2*pi*t)*sin(2*pi*x).
A uniform grid is used on the spatial domain [0,1] with Nx=600 intervals, resulting in Nx+1=601 grid points.
The spatial step size is dx = 1/Nx.
Second-order central differences are used for the u_xx term in the interior.
The standard second-order central difference in time (leapfrog / Störmer–Verlet) is used for u_tt.
The time step dt is chosen such that the CFL condition (0.8 * dt / dx) <= 0.9 is met.
First, calculate dt0 = 0.9 * dx / 0.8.
Then, calculate Nt = ceil(T/dt0), where T=1.0.
Finally, set dt = T/Nt to ensure the final time T is hit exactly.
The initial condition u(x,0)=u0(x) is used.
The first time step u(x,dt) is computed using the Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(0.8^2*u_xx^0), where v0 = u_t(x,0) and there is no forcing term.
For Dirichlet boundary conditions, the boundary nodes at x=0 and x=1 are set to the prescribed value of 0 at every time step.
