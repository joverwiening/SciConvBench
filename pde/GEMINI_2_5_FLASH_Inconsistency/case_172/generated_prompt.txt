The task is to numerically solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 1.0].
The parameters are nu = 0.5 and rho = 1.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A uniform periodic spatial grid will be used with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
A fixed time step dt=0.001 will be used for Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
Each Strang splitting step consists of three parts:
First, a diffusion half-step (duration dt/2) is solved exactly in Fourier space.
This involves computing the FFT of u, multiplying the Fourier coefficients u_hat(k) by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), and then computing the IFFT of the result, taking the real part.
Second, a reaction full-step (duration dt) is solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, another diffusion half-step (duration dt/2) is performed, identical to the first diffusion half-step.
The final solution u(x,T=1.0) on the periodic grid must be computed.
The solution data must be saved to "solution_pdebench_reacdiff_nu0p5_rho1.npz".
This NPZ file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu0p5_rho1.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed to the console.
