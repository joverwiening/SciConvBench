The task is to numerically solve the 1D advection partial differential equation u_t + (-0.5)*u_x = 0.
The unknown field is u(x,t).
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0,1.0].
The parameter 'a' is -0.5.
The initial condition is u(x,0)=exp(-100*(x-0.3)^2).
The spatial discretization uses a uniform periodic grid with Nx=1000 points on [0,1).
The grid spacing dx is 1/Nx.
The spatial discretization method is 1st-order upwind, using a right-biased (downwind) stencil consistent with the negative speed (a<0).
The time integration method is Forward Euler.
The time step dt is chosen based on the CFL condition max|a|*dt/dx ≤ 0.9.
Specifically, calculate dt0 = 0.9*dx/|a|.
Calculate the number of time steps Nt = ceil(T/dt0), where T=1.0.
Set the actual time step dt = T/Nt to ensure the final time T is hit exactly.
Boundary handling uses periodic wrap-around indexing.
Compute the solution u(x, T=1.0) on the grid.
Save the solution to a file named "solution_agent_advection_02.npz".
The .npz file must contain the 1D arrays x and u (same length as x), and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_advection_02.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
