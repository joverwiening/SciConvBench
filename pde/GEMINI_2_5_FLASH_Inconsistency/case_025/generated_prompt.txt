The spatial domain is x in [0,1] and the temporal domain is t in [0,1.0].
The diffusion coefficient D is 0.01 and the reaction rate r is 5.0.
Apply Neumann boundary conditions at x=0 and x=1, specifically u_x(0,t)=0 and u_x(1,t)=0.
The initial condition at t=0 is u(x,0)=0.1 + 0.1*sin(2*pi*x).
Discretize the spatial domain using 2nd-order central differences for diffusion terms on a uniform grid.
The grid should have Nx=400 intervals, resulting in Nx+1 grid points.
The time integration method is a 1st-order deterministic IMEX scheme, with diffusion treated implicitly (backward Euler) and reaction treated explicitly (forward Euler).
At each time step, solve the equation (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where L is the discrete Laplacian and R(u) is the reaction term.
Use a sparse direct solver for the linear system at each time step.
Implement the zero Neumann boundary conditions using ghost points with mirror values.
The time step size dt is 0.0005, leading to 2000 time steps.
Compute the solution u(x, T=1.0) on the specified grid.
Save the computed solution to a file named "solution_agent_diffusion_reaction_03.npz".
The .npz file must contain the 1D arrays x and u (both of length Nx+1), and the scalar metadata T, dx, and dt.
Generate and save a line plot of u(x,T) as "solution_agent_diffusion_reaction_03.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) of the solution at time T.
