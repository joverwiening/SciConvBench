The PDE to be solved is u_xx + u_yy = 0.
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square.
The boundary conditions are u(x,0)=0, u(x,1)=sin(2*pi*x), u(0,y)=0, and u(1,y)=0.
The numerical method will discretize the PDE on a uniform grid over (0,1) x (0,1) using the standard 5-point stencil, which is 2nd-order accurate.
The grid will use Nx=Ny=100 intervals in each direction.
This results in Nx+1 by Ny+1 grid points, including boundaries.
The grid spacing will be dx=dy=1/Nx.
The grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The resulting sparse linear system for interior nodes will be solved using a sparse direct solver, such as scipy.sparse.linalg.spsolve.
The steady-state solution u(x,y) will be computed on the 2D grid.
The computed solution will be saved to "solution_agent_laplace_08.npz".
The .npz file will contain the 1D arrays x and y, and a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]), along with scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) will be saved as "solution_agent_laplace_08.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed.
The maximum absolute error and the L2 error will be computed and printed by comparing the numerical solution to the reference solution u(x,y)=sin(2*pi*x)*sinh(2*pi*y)/sinh(2*pi) evaluated on the same grid.
