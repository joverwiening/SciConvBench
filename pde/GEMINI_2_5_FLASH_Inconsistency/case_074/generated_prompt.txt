Solve the 2D Poisson equation u_xx + u_yy = f(x,y) numerically.
The source term is f(x,y) = -2*pi^2*sin(pi*x)*sin(pi*y).
The spatial domain is (x,y) in [0,1] x [0,1].
Apply Dirichlet boundary conditions u=0 on all four edges of the domain.
Discretize the PDE using the standard 5-point stencil (2nd-order accurate) on a uniform grid.
Use Nx=120 intervals in the x-direction and Ny=120 intervals in the y-direction.
The grid points are x_i = i*dx for i=0 to Nx and y_j = j*dy for j=0 to Ny, where dx = (1-0)/Nx and dy = (1-0)/Ny.
Solve the resulting sparse linear system for the interior nodes using a sparse direct solver.
Compute the steady-state solution u(x,y) on the defined 2D grid.
Save the solution data to a file named "solution_agent_poisson_01.npz".
The .npz file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and the scalar values dx and dy.
Generate and save a heatmap or contour plot of u(x,y) as "solution_agent_poisson_01.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm calculated as sqrt(sum(u^2)*dx*dy).
Compute and print the maximum absolute error and the L2 error between the computed solution and the exact solution u_exact(x,y) = sin(pi*x)*sin(pi*y) evaluated on the same grid.
