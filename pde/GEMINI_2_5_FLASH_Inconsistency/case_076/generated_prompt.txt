The task is to numerically solve the 2D Poisson equation u_xx + u_yy = f(x,y) where f(x,y) = -2*(y*(1-y) + x*(1-x)).
The spatial domain is (x,y) in [0,1] x [0,1].
Apply Dirichlet boundary conditions on all four edges, setting u on the boundary to match u(x,y)=x*(1-x)*y*(1-y).
Discretize the PDE on a uniform grid using the standard 5-point stencil (2nd-order) for interior nodes.
Use Nx=Ny=120 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points including boundaries.
The grid spacing is dx=dy=1/Nx.
The grid points are x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Solve the resulting sparse linear system for interior nodes using a sparse direct solver (e.g., scipy.sparse.linalg.spsolve).
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution to "solution_agent_poisson_03.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), plus metadata scalars dx, dy.
Save a heatmap/contour plot of u(x,y) as "solution_agent_poisson_03.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm calculated as sqrt(sum(u^2)*dx*dy).
Compute and print the maximum absolute error and the L2 error against the provided reference solution u(x,y)=x*(1-x)*y*(1-y), evaluated on the same grid.
