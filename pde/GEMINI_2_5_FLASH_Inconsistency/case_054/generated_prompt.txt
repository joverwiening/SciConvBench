The PDE to be solved is u_tt - (1.0)^2*u_xx + (1.0)^2*u = sin(pi*x)*cos(2*t).
The unknown field is u(x,t).
The spatial domain is x in [0,1].
The temporal domain is t in [0,5.0].
The parameter c is 1.0.
The parameter m is 1.0.
Dirichlet boundary conditions are applied at x=0 and x=1, with u=0.
The initial condition for u(x,0) is 0.
The initial condition for u_t(x,0) is 0.
The spatial discretization uses a uniform grid on the interval [0,1] with 2nd-order central differences for u_xx.
The time integration uses 2nd-order central differences in time (leapfrog) for u_tt.
The +m^2*u term is handled explicitly at time level n in the leapfrog update.
The time step dt is chosen such that c*dt/dx ≤ 0.9.
The initialization uses a Taylor start from u0 and v0, including the -m^2*u0 term and the forcing term if present.
The number of spatial intervals Nx is 400.
The time step dt is 0.001, resulting in 5000 time steps.
The forcing term is included at time level n in the leapfrog update.
The solution u(x, T=5.0) is computed on the grid.
The solution is saved to "solution_agent_kg_07.npz" containing arrays x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_kg_07.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
