The ODE system dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t), dI/dt = delta*E - epsilon*I, dH/dt = theta*I - phi*H will be solved numerically.
The time domain is t in [0.0, 50.0].
The parameters are alpha = 1.2, beta = 1.0, gamma = 0.5, delta = 0.8, epsilon = 0.7, theta = 0.9, phi = 0.4.
The initial conditions are E(0.0) = 0.5, I(0.0) = 0.2, H(0.0) = 0.1.
The numerical method will be Classical 4th-order Runge–Kutta (RK4) with a fixed time step.
The time step will be dt = 0.01, with Nt = 5000 steps.
The full state vector will be computed at all time points t_n = t0 + n*dt for n=0..Nt.
The solution will be saved to "solution_molk_006.npz".
The "solution_molk_006.npz" file will contain a 1D array 't' of length Nt+1, a 2D array 'Y' of shape [Nt+1, n_state] with columns ordered as [E, I, H], and the parameter scalars.
Line plots of each state vs t will be saved as "solution_molk_006.png".
The final state values at T will be printed.
The minimum and maximum values of each state over time will be printed.
