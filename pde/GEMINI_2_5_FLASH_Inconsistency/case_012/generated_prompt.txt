The PDE to solve is u_t = (0.015)^2*(u_xx + u_yy) + u - u^3.
The spatial domain is x in [0,1] and y in [0,1].
The time domain is t in [0,0.2].
The parameter epsilon is 0.015.
Neumann boundary conditions (∂u/∂n = 0) are applied on all boundaries.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y).
The numerical method uses a uniform grid with Nx=200 and Ny=200.
The spatial discretization uses a 5-point Laplacian for u_xx+u_yy.
The time integration scheme is semi-implicit: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
A sparse linear system must be solved at each time step.
Zero Neumann boundary conditions are handled using ghost nodes with mirror values.
The time step is dt=0.0002, for a total of 1000 time steps.
The final solution u(x,y,T=0.2) on the 2D grid must be computed.
The solution must be saved to "solution_agent_allen_cahn_06.npz".
The NPZ file must contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_allen_cahn_06.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
