The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical solution will be computed using a uniform periodic spatial grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time integration uses a fixed time step dt=0.001 for Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps:
(A) A diffusion half-step of duration dt/2 is solved exactly in Fourier space.
This involves transforming u to Fourier space (u_hat), multiplying u_hat(k) by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), and then transforming back to real space (u), taking the real part.
(B) A reaction full-step of duration dt is solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Another diffusion half-step of duration dt/2 is solved exactly in Fourier space, identical to step (A).
The final solution u(x,T=1.0) on the periodic grid must be computed.
The solution must be saved to a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz".
This NPZ file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu0p5_rho10.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed to the console.
