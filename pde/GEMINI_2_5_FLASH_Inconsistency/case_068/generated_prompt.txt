Solve the one-dimensional Korteweg-de Vries (KdV) equation u_t + 6*u*u_x + u_xxx = 0 numerically.
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0,0.1].
The initial condition is u(x,0)=0.5*cos(2*pi*x).
Use a Fourier pseudo-spectral method for spatial derivatives u_x and u_xxx.
Compute u_x by multiplying the Fourier transform of u by (ik).
Compute u_xxx by multiplying the Fourier transform of u by (ik)^3.
Use explicit RK4 for time integration with a fixed time step dt.
Compute the nonlinear term 6*u*u_x in physical space.
Use Nx=1024 grid points for the spatial domain.
Use dt=1e-5 for the time step.
The simulation should run for 10000 time steps to reach T=0.1.
Compute the solution u(x, T=0.1) on the grid.
Save the solution to a file named "solution_agent_other_03_kdv.npz".
The .npz file must contain the 1D arrays x and u, and the scalar metadata T, dx, and dt.
Generate a line plot of u(x,T) and save it as "solution_agent_other_03_kdv.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
