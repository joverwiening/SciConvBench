Solve the Poisson PDE u_xx + u_yy = f(x,y) numerically.
The source term is f(x,y) = 100*exp(-200*((x-0.5)^2 + (y-0.5)^2)).
The spatial domain is (x,y) in [0,1] x [0,1].
Apply Dirichlet boundary conditions u=0 on all four boundary edges.
Discretize the PDE on a uniform grid using the standard 5-point stencil (2nd-order accuracy).
Use Nx=120 and Ny=120 intervals in each direction.
The grid will have Nx+1 by Ny+1 grid points, including boundaries.
The grid spacing is dx=dy=1/Nx.
The grid points are x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
Solve the resulting sparse linear system for the interior nodes using a sparse direct solver.
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution to "solution_agent_poisson_07.npz".
The .npz file must contain 1D arrays x, y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx, dy.
Save a heatmap/contour plot of u(x,y) as "solution_agent_poisson_07.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy).
