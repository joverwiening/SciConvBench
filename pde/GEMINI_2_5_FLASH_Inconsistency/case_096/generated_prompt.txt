The PDE to be solved is u_tt = (1.0)^2 * (u_xx + u_yy).
The spatial domain is x in [0,1] and y in [0,1].
The time domain is t in [0,0.5].
The wave speed parameter c is 1.0.
Dirichlet boundary conditions are applied on all boundaries, with u=0.
The initial condition for u is u(x,y,0)=sin(pi*x)*sin(2*pi*y).
The initial condition for u_t is u_t(x,y,0)=0.
The reference exact solution is u(x,y,t)=cos(1.0*pi*sqrt(5)*t)*sin(pi*x)*sin(2*pi*y).
The spatial discretization uses a uniform grid on [0,1] x [0,1] with Nx=160 and Ny=160 intervals, resulting in Nx+1 by Ny+1 grid points.
The spatial step sizes are dx=dy=1/Nx.
The 5-point Laplacian is used for the spatial discretization of ∇²u.
Time integration uses a 2nd-order central difference for u_tt.
The time step dt is chosen such that the CFL condition c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9 is met.
Specifically, dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)) is calculated.
The number of time steps Nt is ceil(T/dt0), and the final dt is T/Nt to hit the final time exactly.
The first time step for u is computed using a Taylor start with the initial velocity.
For Dirichlet boundary conditions, boundary nodes are set to u=0 at each time step.
The numerical solution u(x,y,T=0.5) on the 2D grid is computed.
The solution is saved to "solution_agent_wave_15.npz" containing 1D arrays x, y, and a 2D array u (shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T), along with metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) is saved as "solution_agent_wave_15.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T are printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid, are computed and printed.
