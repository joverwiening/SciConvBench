The PDE to be solved numerically is u_xx + u_yy = 0.
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square, setting u on the boundary to match u(x,y)=x*y.
The reference exact solution for verification is u(x,y)=x*y.
The spatial discretization will use the standard 5-point stencil (2nd-order) for ∇²u=0 on a uniform grid over (0,1) x (0,1).
The resulting sparse linear system for interior nodes will be solved using a sparse direct solver.
The grid will use Nx=Ny=100 intervals in each direction, resulting in Nx+1 by Ny+1 grid points including boundaries.
The grid spacing will be dx=dy=1/Nx.
The grid points will be x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The steady-state solution u(x,y) will be computed on the 2D grid.
The solution will be saved to "solution_agent_laplace_05.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx, dy.
A heatmap/contour plot of u(x,y) will be saved as "solution_agent_laplace_05.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed.
The maximum absolute error and L2 error against the reference solution evaluated on the same grid will be computed and printed.
