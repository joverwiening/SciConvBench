The PDE to be solved is u_tt - (1.2)^2*u_xx + (0.8)^2*u = 0.
The unknown field is u(x,t).
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.7].
The parameter c is 1.2.
The parameter m is 0.8.
Dirichlet boundary conditions are applied at x=0 and x=1, with u=0.
The initial condition for u(x,0) is sin(3*pi*x).
The initial condition for u_t(x,0) is 0.
The reference exact solution is u(x,t)=cos(sqrt((1.2*3*pi)^2 + (0.8)^2)*t)*sin(3*pi*x).
The spatial discretization will use a uniform grid on the interval [0,1] with 2nd-order central differences for u_xx.
The time integration will use 2nd-order central difference in time (leapfrog).
The +m^2*u term will be handled explicitly at time level n in the update.
The time step dt must satisfy c*dt/dx <= 0.9.
The initialization will use a Taylor start from u0 and v0, including the -m^2*u0 term.
The grid will use Nx=600 intervals, resulting in Nx+1 grid points.
The spatial step dx will be 1/Nx.
An initial time step dt0 will be calculated as 0.9*dx/c.
The number of time steps Nt will be ceil(T/dt0).
The final time step dt will be T/Nt to hit the final time exactly.
The simulation will compute u(x, T=0.7) on the grid.
The solution will be saved to "solution_agent_kg_09.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) will be saved as "solution_agent_kg_09.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T will be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid, will be computed and printed.
