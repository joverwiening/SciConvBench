The task is to numerically solve a 1D nonlinear reaction-diffusion partial differential equation.
The PDE is u_t = q1*u_xx + q2*(u**2)*(1-u)**2.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameters are q1 = 0.01 and q2 = 2.0.
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
The spatial grid will be uniform and periodic with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization for u_xx will use 2nd-order central differences.
The time integration method will be Explicit RK4.
The time step will be dt=0.0005, with Nt=2000 steps to reach the final time T=1.0 exactly.
Compute the solution u(x,T=1.0) on the specified periodic grid.
Save the solution to a file named "solution_molk_023.npz".
This NPZ file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values T, dx, Nx, q1, and q2.
Save a line plot of u(x,T) as "solution_molk_023.png".
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
No reference solution is provided, so error computation against a reference solution is not required.
