The task ID is agent_wave_03.
The PDE category is Wave equation.
The unknown field is u(x,t).
The PDE to solve numerically is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.8].
The parameter c is 1.0.
The boundary conditions are Dirichlet at x=0 and x=1, with u=0.
The initial condition for u(x,0) is sin(pi*x) + 0.5*sin(3*pi*x).
The initial condition for u_t(x,0) is 0.
The reference exact solution is u(x,t)=cos(1.0*pi*t)*sin(pi*x) + 0.5*cos(1.0*3*pi*t)*sin(3*pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx=600 intervals, resulting in Nx+1 grid points.
The spatial step dx is 1/Nx.
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen such that CFL = c*dt/dx ≤ 0.9.
Specifically, dt0 = 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt, ensuring the final time T is hit exactly.
The initialization uses u(x,0)=u0(x).
u(x,dt) is computed using u_t(x,0)=v0(x) via the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value (0) at every time step.
The simulation computes u(x, T=0.8) on the defined grid.
The solution is saved to "solution_agent_wave_03.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_wave_03.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid, are computed and printed.
