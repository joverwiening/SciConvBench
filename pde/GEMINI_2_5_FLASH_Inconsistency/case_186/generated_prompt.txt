The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 1.0].
The parameters are nu = 2.0 and rho = 2.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1), defined by x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
The time integration method is Strang splitting for each full time step dt.
The Strang splitting sequence is: Diffusion half-step (duration dt/2), Reaction full-step (duration dt), Diffusion half-step (duration dt/2).
The diffusion half-step is solved exactly in Fourier space: u_hat(k) is computed via FFT(u), k is 2*pi*fftfreq(Nx, d=dx), u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)), and u is obtained via IFFT(u_hat) taking the real part.
The reaction full-step solves the logistic ODE du/dt = rho*u*(1-u) exactly pointwise for each grid point using the update formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The final solution u(x,T=1.0) on the periodic grid must be computed.
The results must be saved to "solution_pdebench_reacdiff_nu2_rho2.npz" containing the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu2_rho2.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed to the console.
