The PDE to be solved is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 2.0].
The parameter beta is 4.0.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
A uniform spatial grid will be used with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization for u_x will be a 1st-order upwind finite difference, using the upwind direction determined by the sign of beta.
Time integration will use the explicit forward Euler method.
The time step dt will be determined using a CFL number of 0.5, so dt = CFL * dx / abs(beta).
The number of time steps Nt will be ceil(T/dt), and then dt will be reset to T/Nt to hit the final time T exactly.
The final time T for computation and output is 2.0.
The numerical solution u(x,T=2.0) will be computed on the periodic grid.
The solution will be saved to a file named "solution_pdebench_advection_beta4.npz".
This NPZ file will contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars beta, T, dx, dt, Nx, Nt.
A line plot of u(x,T) will be saved as "solution_pdebench_advection_beta4.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T will be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same x grid, will also be computed and printed.
