The task is to numerically solve the 1D inviscid conservation law u_t = -k*∂_x( sin(u) ) for u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required for verification.
The numerical method requirements are as follows:
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization uses a conservative finite-volume Rusanov flux for f(u)=sin(u) with wave speed alpha=max|cos(u)|.
The time integration method is SSP-RK2.
The time step is determined using a CFL number of 0.2, such that dt0 = CFL*dx/1.0 (since max|cos(u)|<=1).
The total number of time steps Nt is ceil(T/dt0), and the final time step dt is T/Nt.
The output requirements are as follows:
Compute u(x,T=0.2) on the periodic grid.
Save the computed solution to a file named "solution_molk_030.npz".
This NPZ file must contain the 1D arrays x (length Nx) and u (length Nx), and the scalar values T, dx, Nx, and k.
Save a line plot of u(x,T) as "solution_molk_030.png".
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
Error computation against a reference solution is not required as no exact solution is provided.
