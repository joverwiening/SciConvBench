Solve the 1D Diffusion-Reaction PDE u_t = 0.01*u_xx + u*(1-u)*(u-0.25) numerically.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.5].
The diffusion coefficient is D = 0.01.
The parameter 'a' in the reaction term is 0.25.
Apply Dirichlet boundary conditions: u(0,t)=1 at x=0 and u(1,t)=0 at x=1.
The initial condition is u(x,0)=0.5*(1 - tanh((x-0.5)/0.02)).
Use 2nd-order central differences for spatial discretization of diffusion terms on a uniform grid.
For time integration, use a 1st-order IMEX scheme: diffusion implicitly (Backward Euler) and reaction explicitly (Forward Euler).
The time integration scheme is (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where L is the discrete Laplacian and R(u) is the reaction term.
Use a sparse direct solver at each time step.
The grid should have Nx=600 spatial intervals.
The time step should be dt=0.0002, resulting in 2500 time steps to reach T=0.5.
Compute the solution u(x, T=0.5) on the specified grid.
Save the solution to a file named "solution_agent_diffusion_reaction_04.npz".
This NPZ file must contain the 1D arrays x and u (solution at T=0.5), and scalar metadata T, dx, and dt.
Save a line plot of u(x,T=0.5) as "solution_agent_diffusion_reaction_04.png".
Report the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) of the solution at T=0.5.
