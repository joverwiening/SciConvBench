The PDE to solve is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1] and the temporal domain is t in [0,1.0].
The wave speed parameter c is 1.0.
Dirichlet boundary conditions are applied at x=0 and x=1, with u(0,t)=0 and u(1,t)=0.
The initial condition for u is u(x,0)=sin(pi*x).
The initial condition for u_t is u_t(x,0)=0.
The reference exact solution for verification is u(x,t)=cos(1.0*pi*t)*sin(pi*x).
A uniform grid on [0,1] with Nx intervals (Nx+1 points) will be used for spatial discretization.
Second-order central differences will be used for u_xx in the interior.
The time integration will use the standard second-order central difference in time (leapfrog / Störmer–Verlet).
For stability, dt will be chosen such that CFL = c*dt/dx <= 0.9.
Initialization will use a Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0), where v0=u_t(x,0) and f^0=0.
For Dirichlet boundary conditions, boundary nodes will be set to the prescribed value at every time step.
The grid will use Nx=400 intervals, resulting in Nx+1 points.
The spatial step dx will be 1/Nx.
An initial time step dt0 will be calculated as 0.9*dx/c.
The number of time steps Nt will be ceil(T/dt0).
The final time step dt will be T/Nt to ensure the final time T=1.0 is hit exactly.
The numerical solution u(x, T=1.0) will be computed on the grid.
A file named "solution_agent_wave_01.npz" will be saved, containing the 1D arrays x and u (at T), and scalar metadata T, dx, dt.
A line plot of u(x,T) will be saved as "solution_agent_wave_01.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T will be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid at time T, will be computed and printed.
