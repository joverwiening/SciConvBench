The PDE to solve is u_t = -q1*∂_x( cos(u) ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
A uniform periodic spatial grid will be used with Nx=1024 points on [0,1).
The grid points are defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization for the convection term ∂_x(cos(u)) will use a conservative finite-volume Rusanov flux.
The Rusanov flux wave speed alpha will be max|sin(u)|.
The spatial discretization for the diffusion term u_xx will use 2nd-order central differences.
Time integration will be performed using SSP-RK2.
The time step dt will be determined using a CFL number of 0.2.
The advective time step dt_adv is 0.2*dx/1, noting that max|sin(u)|<=1.
The diffusive time step dt_diff is 0.2*dx^2/(q2/pi).
The time step dt will be min(dt_adv, dt_diff).
The number of time steps Nt will be ceil(T/dt).
The final time step dt will be adjusted to T/Nt to ensure the simulation ends exactly at T=0.5.
The solution u(x,T=0.5) will be computed on the periodic grid.
The solution will be saved to "solution_molk_031.npz".
The npz file will contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values T, dx, Nx, q1, and q2.
A line plot of u(x,T) will be saved as "solution_molk_031.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T will be printed.
No error computation against a reference solution is required.
