Solve the 2D Poisson equation u_xx + u_yy = f(x,y) numerically.
The source term is f(x,y) = -5*pi^2*sin(2*pi*x)*sin(pi*y).
The spatial domain is [0,1] x [0,1].
Apply Dirichlet boundary conditions u=0 on all four edges of the domain.
The exact solution for verification is u(x,y)=sin(2*pi*x)*sin(pi*y).
Discretize the PDE using the standard 5-point stencil (2nd-order accurate) on a uniform grid.
Use Nx=120 and Ny=120 intervals in each direction.
The grid points are x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny, where dx=dy=1/Nx.
Solve the resulting sparse linear system for the interior nodes using a sparse direct solver.
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution data to "solution_agent_poisson_02.npz".
The .npz file must contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar values dx and dy.
Save a heatmap or contour plot of u(x,y) as "solution_agent_poisson_02.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm of u (calculated as sqrt(sum(u^2)*dx*dy)).
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution evaluated on the same grid.
