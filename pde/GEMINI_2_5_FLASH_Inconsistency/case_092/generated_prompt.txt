The PDE to solve is u_tt = (1.0)^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t).
The spatial domain is x in [0,1] and y in [0,1].
The temporal domain is t in [0,1.0].
The wave speed parameter c is 1.0.
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition for u is u(x,y,0)=0.
The initial condition for u_t is u_t(x,y,0)=0.
A uniform grid is used on [0,1] x [0,1] with Nx=120 and Ny=120 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The spatial discretization uses the 5-point Laplacian for the ∇²u term.
The time integration uses a 2nd-order central difference scheme for u_tt.
The time step dt is chosen such that the CFL condition c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9 is met.
Specifically, dx = (1-0)/Nx and dy = (1-0)/Ny.
A preliminary time step dt0 is calculated as 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
The number of time steps Nt is ceil(T/dt0), where T=1.0.
The final time step dt is T/Nt, ensuring the simulation ends exactly at T=1.0.
The first time step for u is computed using a Taylor series expansion with the initial velocity.
Boundary nodes are set to the Dirichlet value of 0 at each time step.
The solution u(x,y,T=1.0) on the 2D grid must be computed.
The solution data must be saved to a file named "solution_agent_wave_11.npz".
The "solution_agent_wave_11.npz" file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and the scalar metadata T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T) must be saved as "solution_agent_wave_11.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed to the console.
