The PDE to solve is u_t + u*u_x = 0.02*u_xx + sin(2*pi*x)*cos(2*pi*t).
The spatial domain is x in [0,1) and the temporal domain is t in [0,1.0].
The parameter nu is 0.02.
The boundary condition is periodic on x.
The initial condition is u(x,0)=0.
The spatial discretization uses a conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
Convection is discretized using finite-volume / conservative finite-difference with the Rusanov (local Lax–Friedrichs) flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|). The spatial derivative is approximated as (f(u))_x ≈ (F_{i+1/2}-F_{i-1/2})/dx.
Diffusion is discretized using a 2nd-order central difference: u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Time integration uses a 1st-order IMEX scheme, treating convection explicitly and diffusion implicitly.
The time integration scheme is (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_{i-1})/dx^2 + sin(2*pi*x_i)*cos(2*pi*t^n).
This yields a linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term + dt*source_term, with periodic wrap-around in L.
The resulting sparse linear system must be solved at each time step.
Boundary handling uses periodic wrap-around indexing for both the convection fluxes and the diffusion stencil.
The grid uses Nx=1000 points on [0,1) with periodic indexing, so dx=1/Nx.
The time step is dt=1e-4, and Nt=10000 steps are taken to reach T=1.0 exactly.
