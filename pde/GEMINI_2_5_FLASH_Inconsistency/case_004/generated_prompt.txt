The PDE to be solved numerically is u_t + (1.0)*u_x + (0.5)*u_y = 0.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions.
The temporal domain is t in [0,1.0].
The initial condition is u(x,y,0)=sin(2*pi*x)*cos(2*pi*y).
The exact solution for verification is u(x,y,t)=sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t)).
The numerical method will use a uniform periodic grid with Nx=256 and Ny=256 points on [0,1) x [0,1).
The spatial discretization will use 1st-order upwind in both x and y directions.
The time integration will use Forward Euler.
The time step dt will satisfy the CFL condition |a|*dt/dx + |b|*dt/dy ≤ 0.9, where a=1.0 and b=0.5.
Specifically, calculate dt0 = 0.9 / (|a|/dx + |b|/dy), then set Nt = ceil(T/dt0) and dt = T/Nt to hit the final time T=1.0 exactly.
The grid spacing is dx=dy=1/Nx.
Boundary handling will use periodic wrap-around indexing in both directions.
