The task ID is agent_heat_18.
The PDE category is Heat equation.
The unknown field is u(x,y,t).
The PDE to solve numerically is u_t = 0.1 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,1.0].
The parameter alpha is 0.1.
Dirichlet boundary conditions are applied on all boundary edges, with u(x,y,t) = x + y for all t.
The initial condition is u(x,y,0) = x + y for all interior points.
The reference exact solution for verification is u(x,y,t) = x + y.
The spatial discretization uses a uniform grid on [0,1] x [0,1] with Nx=40 and Ny=40 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The 5-point Laplacian (2nd-order) is used for spatial discretization.
Time integration uses Implicit Euler (backward Euler) for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step.
A sparse linear system is solved for the interior nodes at each time step.
The time step size dt is 0.01.
The simulation runs for 100 time steps.
The final solution u(x,y,T=1.0) is computed on the 2D grid.
The solution is saved to "solution_agent_heat_18.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) is saved as "solution_agent_heat_18.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T are printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid, are computed and printed.
