The task is to numerically solve the Van der Pol oscillator system of ordinary differential equations.
The system is dx/dt = y and dy/dt = mu*(1 - x**2)*y - x.
The time domain is t in [0.0, 20.0].
The parameter mu is 4.
The initial conditions are x(0.0) = 1.0 and y(0.0) = 0.0.
The numerical method is Classical 4th-order Runge–Kutta (RK4) with a fixed time step.
The time step is dt = 0.01.
The number of time steps is Nt = 2000.
The full state vector at all time points t_n = t0 + n*dt for n=0..Nt must be computed.
The solution must be saved to "solution_molk_007.npz".
The "solution_molk_007.npz" file must contain a 1D array 't' of length Nt+1.
The "solution_molk_007.npz" file must contain a 2D array 'Y' of shape [Nt+1, 2].
The columns of the 'Y' array must be ordered as [x, y].
The "solution_molk_007.npz" file must contain the parameter scalars.
Line plots of each state versus time must be saved as "solution_molk_007.png".
The final state values at the final time T must be printed.
The minimum and maximum values of each state over time must be printed.
