The 1D Compressible Navier-Stokes equations without heat conduction will be solved numerically.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE in conservative form is: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ( (E+p)*v - v*sigma )_x = 0.
Here, m = rho*v, total energy E = p/(Gamma-1) + 0.5*rho*v^2, and viscous stress sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1] and the temporal domain is t in [0, 0.2].
The parameters are Gamma = 1.6666666666666667, eta = 1e-08, and zeta = 1e-08.
Transmissive/outflow (zero-gradient) boundary conditions will be applied at x=-1 and x=1.
The initial condition is a Riemann (shock-tube) problem with a discontinuity at x=0.
For x < 0, rho_L = 1.0, v_L = 0.0, p_L = 1.0.
For x ≥ 0, rho_R = 0.125, v_R = 0.0, p_R = 0.1.
A uniform finite-volume grid with Nx=800 cells will be used on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Conservative variables U = [rho, m, E] (cell averages) will be evolved.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Rho and p will be clipped to a floor of 1e-12 if needed to enforce positivity.
The Rusanov (local Lax-Friedrichs) numerical flux will be used for the inviscid Euler part.
The convective flux is F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
v_x will be computed with a centered difference on the cell-centered v values.
Sigma will be computed as sigma = (zeta + 4/3*eta)*v_x.
Sigma at interfaces will be approximated by averaging neighboring cell-centered sigma values.
Viscous contributions to the momentum and energy fluxes at interfaces are F_visc = [ 0, -sigma, -v*sigma ] using interface-averaged v and sigma.
The total interface flux is F_total = F_hat + F_visc.
2-stage SSP-RK2 (Heun's method) will be used for time integration on the semi-discrete finite-volume system.
The time step dt will be chosen each step by dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step dt = min(dt_conv, dt_visc) will be used, and the last step will be adjusted to hit the final time T exactly.
The CFL number will be set to 0.5.
For outflow boundary conditions, ghost cell values will be set equal to the nearest interior cell (zero-gradient).
The final values of rho(x,T), v(x,T), p(x,T) will be computed on the cell centers.
A file named "solution_pdebench_cns1d_sod1_eta1em8_outflow.npz" will be saved.
This .npz file will contain 1D arrays: x (length Nx), rho, v, p, and scalars: Gamma, eta, zeta, T, dx, CFL.
A 3-panel line plot of rho, v, p vs x at T will be saved as "solution_pdebench_cns1d_sod1_eta1em8_outflow.png".
The minimum and maximum of rho and p will be printed (positivity check).
The mean of rho over the domain will be printed (mass conservation check).
