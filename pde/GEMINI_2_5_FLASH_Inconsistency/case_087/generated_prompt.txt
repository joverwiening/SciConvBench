The simulation will solve the 1D wave equation u_tt = c^2 * u_xx.
The wave speed c will be 1.0.
The spatial domain is x in [0,1].
The time domain is t in [0,1.0].
The boundary conditions are Neumann at x=0 and x=1, specifically u_x(0,t)=0 and u_x(1,t)=0.
The initial condition for u is u(x,0)=cos(pi*x).
The initial condition for u_t is u_t(x,0)=0.
The exact solution for verification is u(x,t)=cos(pi*x)*cos(1.0*pi*t).
The spatial discretization will use a uniform grid on [0,1] with Nx=400 intervals, resulting in Nx+1 grid points.
The spatial step size dx will be 1/Nx.
Second-order central differences will be used for u_xx in the interior.
Time integration will use the standard second-order central difference method (leapfrog / Störmer–Verlet).
The time step dt will be chosen such that the CFL condition c*dt/dx ≤ 0.9 is met.
Specifically, dt0 = 0.9*dx/c.
The number of time steps Nt will be ceil(T/dt0).
The final time step dt will be T/Nt to ensure the simulation ends exactly at T=1.0.
Boundary conditions will be handled using ghost points with mirror values for zero Neumann conditions.
The initialization for the first time step u^1 will use the Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
The simulation will compute u(x, T=1.0) on the defined grid.
The results will be saved to a NumPy compressed archive named "solution_agent_wave_06.npz".
This NPZ file will contain the 1D arrays x and u, and scalar metadata T, dx, and dt.
A line plot of u(x,T) will be saved as "solution_agent_wave_06.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T will be printed to the console.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same x grid, will also be computed and printed.
