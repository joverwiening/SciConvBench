The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 1.0.
The parameter rho is 1.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time grid uses a fixed time step dt=0.001.
The total number of time steps is Nt=1000, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting sequence is (A) Diffusion half-step, (B) Reaction full-step, (C) Diffusion half-step.
For the diffusion half-step (duration dt/2), the solution is computed exactly in Fourier space.
The Fourier transform of u is u_hat(k).
The wave numbers k are defined as k = 2*pi*fftfreq(Nx, d=dx).
The Fourier update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The inverse Fourier transform of u_hat is u, taking the real part.
For the reaction full-step (duration dt), the logistic ODE du/dt = rho*u*(1-u) is solved exactly pointwise.
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The final solution u(x,T=1.0) on the periodic grid must be computed.
The solution data must be saved to "solution_pdebench_reacdiff_nu1_rho1.npz".
The saved NPZ file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu1_rho1.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed to the console.
