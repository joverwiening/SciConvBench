The task ID is molk_028.
Solve the 1D inviscid conservation law with cubic flux numerically.
The partial differential equation is u_t = -k*∂_x( (1/3)*u^3 ).
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The boundary condition is periodic, u(0,t)=u(1,t) for all t.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1.
The spatial step size dx is 1/Nx.
The spatial discretization is a conservative finite-volume method with Rusanov flux for f(u)=(1/3)u^3.
The time integration method is SSP-RK2.
The time step is determined using a CFL condition.
Set CFL=0.2.
Estimate max|f'(u)| = max|u^2|.
Use max|f'| = 0.25 for the CFL calculation.
Calculate an initial time step dt0 = CFL*dx/max|f'|.
Calculate the number of time steps Nt = ceil(T/dt0).
The final time step dt = T/Nt.
Compute u(x,T=0.2) on the periodic grid.
Save the solution to "solution_molk_028.npz".
The npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values T, dx, Nx, and k.
Save a line plot of u(x,T) as "solution_molk_028.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the mean value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
