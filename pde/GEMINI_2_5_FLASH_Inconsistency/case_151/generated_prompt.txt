The 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx will be solved numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 1.0].
The parameter nu is set to 2.0.
The initial condition is u(x,0) = sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method uses Strang splitting for each full time step dt.
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
Each Strang splitting step consists of three substeps:
(A) A diffusion half-step of duration dt/2 is solved exactly in Fourier space.
For this, the FFT of u is computed to get u_hat(k).
The wave numbers k are defined as k = 2*pi*fftfreq(Nx, d=dx).
u_hat(k) is updated by multiplying with exp(-nu*k^2*(dt/2)).
The inverse FFT of u_hat is computed, and its real part is taken as the new u.
(B) An advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 is solved using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), alpha is calculated as max(abs(u_left), abs(u_right)).
The Rusanov flux F is calculated as 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]), and F_minus is the flux between (u[j-1], u[j]).
The new value u_new[j] is computed as u[j] - (dt/dx)*(F_plus - F_minus).
After computing all u_new[j], u is replaced with u_new.
(C) Another diffusion half-step (same as A) is performed.
The time step dt is determined using a CFL condition.
CFL is set to 0.4, based on an estimated maximum speed of 1.0 for the initial condition.
An initial time step dt0 is calculated as CFL*dx/1.0.
The number of time steps Nt is calculated as ceil(T/dt0).
The final time step dt is reset to T/Nt to ensure the simulation ends exactly at T=1.0.
The simulation will compute u(x,T=1.0) on the periodic grid.
The results will be saved to a file named "solution_pdebench_burgers_nu2.npz".
This NPZ file will contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, T, dx, dt, Nx, and Nt.
A line plot of u(x,T) will be saved as "solution_pdebench_burgers_nu2.png".
The minimum value of u, the maximum value of u, the discrete mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T will be printed to the console.
