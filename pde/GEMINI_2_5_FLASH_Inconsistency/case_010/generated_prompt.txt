The PDE to be solved is u_t = (0.01)^2*(u_xx + u_yy) + u - u^3.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions.
The time domain is t in [0,0.2].
The parameter epsilon is 0.01.
The initial condition is u(x,y,0)=0.1*cos(2*pi*x)*cos(2*pi*y).
The numerical method for time integration is semi-implicit: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
A sparse linear system must be solved at each time step.
The spatial discretization uses a uniform grid with a 5-point Laplacian for u_xx+u_yy.
Boundary handling uses periodic wrap-around indexing in both x and y, without duplicating endpoints.
The grid size is Nx=Ny=256.
The time step is dt=0.0002, resulting in 1000 time steps.
The solution u(x,y,T=0.2) on the 2D grid must be computed.
The solution must be saved to "solution_agent_allen_cahn_04.npz".
The NPZ file must contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T) must be saved as "solution_agent_allen_cahn_04.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
