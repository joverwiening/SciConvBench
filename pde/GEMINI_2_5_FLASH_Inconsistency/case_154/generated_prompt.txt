The PDE to be solved is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.004.
The initial condition is u(x,0) = sin(2*pi*x).
The numerical solution will be computed on a uniform periodic grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), the solution is obtained exactly in Fourier space.
First, compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Then, update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, compute u = IFFT(u_hat) and take the real part.
For the advection full-step (B), the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 is solved using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The updated solution u_new[j] is computed as u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated maximum speed is 1.0.
The number of time steps Nt is ceil(T/dt0), where T=1.0.
The final time step dt is reset to T/Nt to hit the final time exactly.
Compute u(x,T=1.0) on the periodic grid.

This NPZ file must contain the arrays: x (1D length Nx), u (1D length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
