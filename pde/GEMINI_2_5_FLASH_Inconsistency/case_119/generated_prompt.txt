The PDE to solve is u_t + q*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q is 1.5.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The exact solution for verification is u(x,t) = u0( (x - q*t) mod 1 ), where u0 is the initial condition.
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
Grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization for u_x is 1st-order upwind finite difference.
Time integration uses Forward Euler.
The time step is determined by CFL=0.5: dt0 = CFL*dx/abs(q); set Nt=ceil(T/dt0) and then dt=T/Nt.
Compute u(x,T=1.0) on the periodic grid.
