The PDE u_xx + u_yy = f(x,y) will be solved numerically, where f(x,y) = -2*pi^2*cos(pi*x)*cos(pi*y).
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions will be applied on all four edges, setting u on the boundary to match the exact solution u(x,y)=cos(pi*x)*cos(pi*y).
The exact solution for verification is u(x,y)=cos(pi*x)*cos(pi*y).
The spatial discretization will use the standard 5-point stencil (2nd-order) for ∇²u = f(x,y) on a uniform grid.
The linear system for interior nodes will be solved using a sparse direct solver.
The grid will have Nx=Ny=120 intervals in each direction, resulting in Nx+1 by Ny+1 grid points including boundaries.
The grid spacing will be dx=dy=1/Nx.
Grid points will be defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The steady-state solution u(x,y) will be computed on the 2D grid.
A file named "solution_agent_poisson_05.npz" will be saved, containing 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx and dy.
A heatmap/contour plot of u(x,y) will be saved as "solution_agent_poisson_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, will be computed and printed.
