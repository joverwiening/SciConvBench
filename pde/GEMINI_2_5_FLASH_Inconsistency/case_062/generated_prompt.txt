The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is a square (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square, setting u on the boundary to match u(x,y)=x^2 - y^2.
The numerical method uses a uniform grid with Nx=Ny=100 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The spatial discretization uses the standard 5-point stencil (2nd-order accurate) for the Laplacian operator.
The resulting sparse linear system for the interior nodes is solved using a sparse direct solver.
The steady-state solution u(x,y) on the 2D grid must be computed.
The reference exact solution for verification is u(x,y)=x^2 - y^2.
A file named "solution_agent_laplace_06.npz" must be saved, containing the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and the scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) must be saved as "solution_agent_laplace_06.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) must be printed to the console.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, must be computed and printed to the console.
