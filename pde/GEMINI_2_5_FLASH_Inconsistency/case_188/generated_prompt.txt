The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 1.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting sequence is Diffusion half-step (duration dt/2), Reaction full-step (duration dt), Diffusion half-step (duration dt/2).
The diffusion half-step is solved exactly in Fourier space.
For the diffusion half-step, compute u_hat(k) = FFT(u).
The Fourier wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Transform back to real space using u = IFFT(u_hat), taking the real part.
The reaction full-step solves the logistic ODE du/dt = rho*u*(1-u) exactly pointwise.
For the reaction full-step, update u at each grid point using u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
