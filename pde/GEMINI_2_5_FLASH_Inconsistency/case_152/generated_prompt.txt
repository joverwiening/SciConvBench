The PDE is 1D Viscous Burgers (periodic) for the unknown field u(x,t).
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.002.
The initial condition is u(x,0) = sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time integration uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step, (B) Advection full-step, (C) Diffusion half-step.
Substep (A) is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
For substep (A), compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Then compute u = IFFT(u_hat) and take the real part.
Substep (B) is an advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
Substep (B) uses a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The update for u_new[j] is u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
Substep (C) is a diffusion half-step, identical to substep (A).
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated max speed is 1.0.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is reset to T/Nt to hit the final time T exactly.
The simulation computes u(x,T=1.0) on the periodic grid.
The solution is saved to "solution_pdebench_burgers_nu2em3.npz".
The saved npz file contains the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
A line plot of u(x,T) is saved as "solution_pdebench_burgers_nu2em3.png".
The report prints min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
