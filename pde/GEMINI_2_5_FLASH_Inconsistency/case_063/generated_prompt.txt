The PDE to be solved is u_xx + u_yy = 0.
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square.
The boundary conditions are u(x,0)=0, u(x,1)=sin(pi*x), u(0,y)=0, and u(1,y)=0.
The reference exact solution is u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
The spatial discretization uses a uniform grid over (0,1) x (0,1) with the standard 5-point stencil for ∇²u=0, which is 2nd-order accurate.
The linear system for interior nodes is solved using a sparse direct solver.
The grid uses Nx=Ny=100 intervals in each direction.
The grid spacing is dx=dy=1/Nx.
The grid points are x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The steady-state solution u(x,y) is computed on the 2D grid.
The solution is saved to "solution_agent_laplace_07.npz".
The npz file contains 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]), and scalar values dx and dy.
A heatmap or contour plot of u(x,y) is saved as "solution_agent_laplace_07.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) are printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, are computed and printed.
