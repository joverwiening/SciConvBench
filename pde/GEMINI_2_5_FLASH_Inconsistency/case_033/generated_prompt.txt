The task is to numerically solve the 1D heat equation u_t = 0.1 * u_xx.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 0.4].
The parameter alpha is 0.1.
Boundary conditions are zero-flux Neumann at x=0 and x=1 for all t: u_x(0,t)=0 and u_x(1,t)=0.
The initial condition is u(x,0) = cos(pi*x).
The exact solution for verification is u(x,t) = exp(-0.1*pi^2*t) * cos(pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx=200 intervals, resulting in Nx+1=201 grid points.
The spatial step size dx is 1/Nx = 1/200.
Second-order central differences are used for u_xx in the interior.
Time integration uses the Crank–Nicolson method for diffusion.
Zero Neumann boundary conditions are implemented using ghost points: u[-1]=u[1] at x=0 and u[Nx+1]=u[Nx-1] at x=1.
The time step size dt is 0.001.
The simulation runs for 400 time steps to reach the final time T=0.4.
Compute the numerical solution u(x, T=0.4) on the grid.
Save the solution to "solution_agent_heat_04.npz" containing the 1D arrays x and u, and scalar metadata T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_heat_04.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the maximum absolute error and the L2 error against the exact solution evaluated on the same x grid.
