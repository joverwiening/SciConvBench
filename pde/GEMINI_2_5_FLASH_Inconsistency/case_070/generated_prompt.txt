The PDE ∇^4 u = f(x,y) will be solved numerically on the domain (x,y) in [0,1] x [0,1].
The source term is f(x,y) = 4*pi^4*sin(pi*x)*sin(pi*y).
Simply-supported boundary conditions will be applied on all boundaries: u=0 on the boundary and (Δu)=0 on the boundary.
The numerical method involves introducing an auxiliary field v = Δu.
First, solve the Poisson problem Δv = f with Dirichlet boundary condition v=0 on the boundary.
Second, solve the Poisson problem Δu = v with Dirichlet boundary condition u=0 on the boundary.
Each Poisson problem will be discretized using the standard 5-point Laplacian on a uniform grid.
Each linear system resulting from the discretization will be solved using a sparse direct solver.
The grid will have Nx=Ny=120 intervals in each direction.
This results in Nx+1 by Ny+1 grid points including boundaries.
The grid spacing will be dx=dy=1/Nx.
The grid points will be x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The steady-state solution u(x,y) will be computed on the 2D grid.
The computed solution will be saved to "solution_agent_other_05_biharmonic.npz".
The NPZ file will contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) will be saved as "solution_agent_other_05_biharmonic.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed.
The maximum absolute error and the L2 error between the computed solution and the exact solution u(x,y)=sin(pi*x)*sin(pi*y) (evaluated on the same grid) will be computed and printed.
