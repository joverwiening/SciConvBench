The task is to numerically solve the Allen-Cahn partial differential equation u_t = (0.02)^2*u_xx + u - u^3.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.2].
The parameter epsilon is 0.02.
Dirichlet boundary conditions are applied: u(0,t)=1 at x=0 and u(1,t)=-1 at x=1.
The initial condition is u(x,0)=tanh((0.5 - x)/(sqrt(2)*0.02)).
A uniform grid with Nx=1200 spatial intervals is used, resulting in Nx+1 grid points.
The spatial discretization uses 2nd-order central differences for the u_xx term.
The time integration uses a semi-implicit scheme: (u^{n+1} - u^n)/dt = ε^2*u_xx^{n+1} + u^n - (u^n)^3.
This scheme requires solving a linear system at each time step.
The time step is dt=0.0001, leading to 2000 time steps to reach T=0.2.
Dirichlet boundary conditions are enforced by setting the boundary nodes to the prescribed values at every time step.
The solution u(x, T=0.2) on the computational grid must be computed.
The computed solution, along with the x-coordinates, T, dx, and dt, must be saved to a file named "solution_agent_allen_cahn_02.npz".
A line plot of u(x,T) must be saved as "solution_agent_allen_cahn_02.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.2 must be printed to the console.
