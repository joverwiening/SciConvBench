The task is to numerically solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 1.0].
The parameters are nu = 5.0 and rho = 2.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A uniform periodic spatial grid with Nx=512 points on [0,1) must be used, where x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
A fixed time step dt=0.001 must be used for Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
Each Strang splitting step consists of three parts:
(A) A diffusion half-step of duration dt/2, solved exactly in Fourier space. This involves computing the FFT of u to get u_hat(k), defining k = 2*pi*fftfreq(Nx, d=dx), updating u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)), and then computing the IFFT of u_hat (taking the real part) to get u.
(B) A reaction full-step of duration dt, solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u). The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Another diffusion half-step of duration dt/2, identical to part (A).
The final solution u(x,T=1.0) on the periodic grid must be computed.
The computed solution must be saved to a file named "solution_pdebench_reacdiff_nu5_rho2.npz". This .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu5_rho2.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed to the console.
