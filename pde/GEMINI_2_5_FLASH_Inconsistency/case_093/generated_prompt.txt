The PDE to be solved is u_tt = (2.0)^2 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.5].
The wave speed parameter c is 2.0.
Dirichlet boundary conditions are applied at x=0 and x=1, where u=0.
The initial condition for u is u(x,0)=sin(pi*x).
The initial condition for u_t is u_t(x,0)=0.
The reference exact solution is u(x,t)=cos(2.0*pi*t)*sin(pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx intervals, resulting in Nx+1 grid points.
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt must satisfy the stability condition CFL = c*dt/dx <= 0.9.
Initialization uses u(x,0)=u0(x) for the first time step.
The second time step u(x,dt) is computed using the Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Boundary handling for Dirichlet BC involves setting boundary nodes to the prescribed value (0) at every time step.
The grid uses Nx=400 intervals, so dx=1/Nx.
The initial time step dt0 is calculated as 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is adjusted to T/Nt to hit the final time T=0.5 exactly.
The simulation must compute u(x, T=0.5) on the defined grid.
The solution must be saved to "solution_agent_wave_12.npz" as a NumPy archive containing 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_12.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T must be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid at time T, must be computed and printed.
