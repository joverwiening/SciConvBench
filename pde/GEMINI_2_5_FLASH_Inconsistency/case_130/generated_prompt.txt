The PDE to be solved is u_t = -q1*∂_x( sin(u) ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The parameters are q1 = 1.0 and q2 = 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization for the convection term ∂_x(sin(u)) uses a conservative finite-volume flux.
The Rusanov flux is used for the convection term with a wave speed alpha=max|cos(u)|.
The diffusion term u_xx is discretized using 2nd-order central differences.
Time integration is performed using SSP-RK2.
The time step dt is determined using a CFL number of 0.2.
The advective time step is dt_adv = 0.2*dx/1, using max|cos(u)|<=1.
The diffusive time step is dt_diff = 0.2*dx^2/(q2/pi).
The time step dt is min(dt_adv, dt_diff).
The number of time steps Nt is ceil(T/dt).
The final time step dt is adjusted to T/Nt to hit the final time T exactly.
The solution u(x,T=0.5) is computed on the periodic grid.
The solution is saved to "solution_molk_029.npz".
The NPZ file contains arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, q1, q2.
A line plot of u(x,T) is saved as "solution_molk_029.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T are printed.
No reference solution is provided, so error calculations are skipped.
