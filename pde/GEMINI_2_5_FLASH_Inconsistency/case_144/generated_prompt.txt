Solve the 1D Viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx numerically.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.02.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps:
(A) A diffusion half-step of duration dt/2, solved exactly in Fourier space.
For this step, compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) to u_hat(k) * exp(-nu*k^2*(dt/2)).
Then compute u = IFFT(u_hat) and take the real part.
(B) An advection full-step of duration dt for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
This step uses a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after this advection substep.
(C) A second diffusion half-step of duration dt/2, identical to step (A).
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated maximum speed is 1.0.
Calculate the number of time steps Nt = ceil(T/dt0), where T=1.0.
Reset dt = T/Nt to ensure the final time T is hit exactly.
Compute the solution u(x,T=1.0) on the periodic grid.
Save the computed solution to a file named "solution_pdebench_burgers_nu0p02.npz".
This NPZ file must contain the 1D arrays x and u, and the scalars nu, T, dx, dt, Nx, and Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p02.png".
Report the minimum value of u, the maximum value of u, the discrete mean value of u (mean(u)), and the discrete L2 norm (sqrt(sum(u^2)*dx)) at time T by printing them to the console.
