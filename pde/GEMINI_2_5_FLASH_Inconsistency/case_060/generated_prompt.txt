The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is a unit square (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square, setting u(x,y) to match the exact solution u(x,y)=y.
The numerical method will use a uniform grid with Nx=Ny=100 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points.
The grid spacing will be dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The spatial discretization will use the standard 5-point stencil for the Laplacian, which is 2nd-order accurate.
The resulting sparse linear system for the interior nodes will be solved using a sparse direct solver, such as scipy.sparse.linalg.spsolve.
The steady-state solution u(x,y) will be computed on the 2D grid.
The computed solution will be saved to a file named "solution_agent_laplace_04.npz".
This NPZ file will contain 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]), and scalar metadata dx and dy.
A heatmap or contour plot of u(x,y) will be saved as "solution_agent_laplace_04.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) will be printed to the console.
The maximum absolute error and the L2 error against the reference solution u(x,y)=y, evaluated on the same grid, will also be computed and printed.
