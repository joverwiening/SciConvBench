The PDE to be solved is u_t = 0.02*(u_xx + u_yy) + 3.0*u*(1 - u/1.0).
The spatial domain is (x,y) in [0,1] x [0,1].

The diffusion coefficient D is 0.02.
The reaction rate r is 3.0.
The carrying capacity K is 1.0.
Dirichlet boundary conditions u=0 are applied on all spatial boundary edges.
The initial condition is u(x,y,0)=0.8*exp(-40*((x-0.5)^2 + (y-0.5)^2)).
The spatial discretization uses a uniform grid with Nx=Ny=120 intervals, resulting in Nx+1 by Ny+1 grid points.
The grid spacing is dx=dy=1/Nx.
A 5-point Laplacian is used for the diffusion term.
Time integration uses a 1st order deterministic IMEX scheme.
Diffusion is treated implicitly using backward Euler.
Reaction is treated explicitly using forward Euler.
At each time step, solve (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where L is the discrete Laplacian incorporating Dirichlet boundary conditions and R(u) is the reaction term.
A sparse direct solver is used at each time step.
The time step size is dt=0.0005, for a total of Nt=1000 steps.
