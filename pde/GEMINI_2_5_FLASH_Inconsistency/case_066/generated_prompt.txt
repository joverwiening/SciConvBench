The task is to numerically solve the 2D Helmholtz equation u_xx + u_yy + k^2*u = f(x,y) on a uniform grid.
The unknown field is u(x,y).
The domain is (x,y) in [0,1] x [0,1].
The parameter k is 5.0.
The source term f(x,y) is (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y).
Dirichlet boundary conditions u=0 are applied on all boundaries.
The reference exact solution is u(x,y)=sin(pi*x)*sin(pi*y).
The spatial discretization uses a uniform grid with Nx=Ny=120 intervals in each direction, resulting in (Nx+1) by (Ny+1) grid points.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The 5-point Laplacian is used to discretize the PDE, yielding a sparse linear system for the interior nodes.
The resulting sparse linear system is solved using a sparse direct solver.
The steady-state solution u(x,y) is computed on the 2D grid.
The solution is saved to "solution_agent_other_01_helmholtz.npz".
The NPZ file contains 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j])), and scalar metadata dx and dy.
A heatmap/contour plot of u(x,y) is saved as "solution_agent_other_01_helmholtz.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) are printed.
The maximum absolute error and the L2 error against the reference solution, evaluated on the same grid, are computed and printed.
