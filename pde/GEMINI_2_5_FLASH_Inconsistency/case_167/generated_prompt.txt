The PDE to be solved is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The spatial domain is (x,y) in (0,1) x (0,1).
The parameter beta is 0.01.
The coefficient field a(x,y) is defined as 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Dirichlet boundary conditions are applied on the entire boundary, with u = 0 on ∂((0,1) x (0,1)).
A uniform Cartesian grid will be used with N=128 intervals in each direction, resulting in (N+1)x(N+1) grid points including boundaries.
The grid spacing is dx = dy = 1/N.
Grid points are defined as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
The PDE will be discretized using 2nd-order finite differences with variable coefficients.
Face-centered harmonic averaging will be used for the coefficients.
For interior nodes (i=1..N-1, j=1..N-1), the discretization is: -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Face coefficients are harmonic means, for example, a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
The sparse linear system Au=b will be assembled for the interior unknowns.
The linear system will be solved using the Conjugate Gradient (CG) method to a relative residual tolerance of 1e-10.
A simple Jacobi preconditioner may be used.
The solution u(x,y) will be computed on the full (N+1) x (N+1) grid, including boundary points.
The solution will be saved to a file named "solution_pdebench_darcy_beta0p01.npz".
The .npz file will contain the 1D arrays x and y, the 2D array u (shape [N+1, N+1]), and the scalars beta, N, and dx.
A heatmap or contour plot of u(x,y) will be saved as "solution_pdebench_darcy_beta0p01.png".
The minimum value of u, the maximum value of u, and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system will be printed to the console.
