The CFL number should be 0.9.

Solve the 1D Compressible Navier–Stokes equations (without heat conduction) numerically.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE is given in conservative form:
Let m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
Let the viscous stress be sigma = (zeta + 4/3*eta) * v_x.
Assume zeta = eta.
The PDE system is:
- rho_t + (m)_x = 0
- m_t + (m^2/rho + p - sigma)_x = 0
- E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1] and the temporal domain is t in [0, 0.2].
The parameters are Gamma = 1.6666666666666667, eta = 1e-08, and zeta = 1e-08.
Boundary conditions are transmissive/outflow (zero-gradient) at x=-1 and x=1.
The initial condition is a Riemann (shock-tube) problem with a discontinuity at x=0:
For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 1.0.
For x ≥ 0: rho_R = 0.1, v_R = 0.0, p_R = 0.1.
Use a uniform finite-volume grid with Nx=800 cells on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Evolve the conservative variables U = [rho, m, E] as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) if needed.
For the inviscid Euler part, use the Rusanov (local Lax-Friedrichs) numerical flux.
The convective flux is F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute v_x with a centered difference on the cell-centered v values.
Then, sigma = (zeta + 4/3*eta)*v_x.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Add viscous contributions to the momentum and energy fluxes at interfaces: F_visc = [ 0, -sigma, -v*sigma ] (using interface-averaged v and sigma).
The total interface flux is F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration on the semi-discrete finite-volume system.
Choose the time step dt each step by dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step is dt = min(dt_conv, dt_visc).
Adjust the last time step so the final time T is hit exactly.
For outflow boundary conditions, set ghost cell values equal to the nearest interior cell (zero-gradient).
The CFL number is 0.9.
Compute rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T.
