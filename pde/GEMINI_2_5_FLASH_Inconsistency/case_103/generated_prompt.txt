The task is to numerically solve the nonlinear scalar ordinary differential equation du/dt = a*t**2 * cos(u) + b*u.
The time domain for the solution is t in [0.0, 3.0].
The parameters are a = 0.5 and b = -0.2.
The initial condition is u(0.0) = 0.1.
No closed-form reference solution is required for verification.
The numerical method for time integration is the Classical 4th-order Runge–Kutta (RK4) method.
A fixed time step size of dt = 0.001 must be used, resulting in Nt = 3000 steps to reach the final time exactly.
Compute u(t) at all time points t_n = t0 + n*dt for n=0..Nt.
Save the computed solution to a file named "solution_molk_002.npz".
The "solution_molk_002.npz" file must contain the 1D array t (length Nt+1), the 1D array u (length Nt+1), and the scalar parameters a and b.
Save a line plot of u(t) vs t as "solution_molk_002.png".
Print the value of u(T), the minimum value of u over the time grid, and the maximum value of u over the time grid.
Error computation against an exact solution is not required as no exact solution is provided.
