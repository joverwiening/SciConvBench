The PDE to solve is u_tt - (1.0)^2*u_xx + (3.0)^2*u = 0.
The unknown field is u(x,t).
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0,0.8].
The parameter c is 1.0.
The parameter m is 3.0.
The boundary conditions are periodic for u and u_x.
The initial condition for u(x,0) is cos(2*pi*x).
The initial condition for u_t(x,0) is 0.
The reference exact solution is u(x,t)=cos(2*pi*x)*cos(sqrt((1.0*2*pi)^2 + (3.0)^2)*t).
The spatial discretization uses a uniform periodic grid with Nx points on [0,1).
Second-order central differences with wrap-around are used for u_xx.
The time integration uses the Leapfrog method for u_tt.
The mass term +m^2*u at time n is included in the Leapfrog update.
The CFL condition c*dt/dx must be less than or equal to 0.9.
The initialization uses a Taylor start including the -m^2*u0 term.
The number of spatial grid points Nx is 512.
The spatial step dx is 1/Nx.
The initial time step dt0 is 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt to hit the final time exactly.
The simulation computes u(x, T=0.8) on the grid.
The solution is saved to "solution_agent_kg_04.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_kg_04.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
The maximum absolute error and L2 error against the reference solution evaluated on the same x grid are computed and printed.
