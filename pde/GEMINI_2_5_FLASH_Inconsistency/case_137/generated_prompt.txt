The PDE to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 2.0].
The parameter beta is 0.4.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
Use a uniform spatial grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The spatial discretization is 1st-order upwind finite difference for u_x, using the upwind direction determined by the sign of beta.
The time integration method is Explicit forward Euler.
The time step dt is determined by CFL=0.5, such that dt = CFL * dx / abs(beta).
The number of time steps Nt is ceil(T/dt), and then dt is reset to T/Nt to hit the final time T exactly.
Compute the numerical solution u(x,T=2.0) on the periodic grid.
Save the solution data to "solution_pdebench_advection_beta0p4.npz".
The .npz file must contain the 1D arrays x (length Nx) and u (length Nx), and the scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta0p4.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
Compute and print the maximum absolute error and the L2 error against the reference solution evaluated on the same x grid at time T.
