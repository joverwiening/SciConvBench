The PDE u_xx + u_yy = 0 shall be solved numerically.
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions shall be applied on all four edges of the square.
The boundary values shall match the analytic harmonic function u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
The reference exact solution for verification is u(x,y)=sin(pi*x)*sinh(pi*y)/sinh(pi).
The spatial discretization shall use the standard 5-point stencil (2nd-order) on a uniform grid.
The resulting sparse linear system for interior nodes shall be solved using a sparse direct solver.
The grid shall use Nx=Ny=100 intervals in each direction, resulting in Nx+1 by Ny+1 grid points including boundaries.
The grid spacing shall be dx=dy=1/Nx.
The grid points shall be x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The steady-state solution u(x,y) shall be computed on the 2D grid.
The solution shall be saved to "solution_agent_laplace_01.npz".
The npz file shall contain arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j])), plus metadata scalars dx, dy.
A heatmap/contour plot of u(x,y) shall be saved as "solution_agent_laplace_01.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) shall be printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same grid shall be computed and printed.
