The PDE to solve is u_t = -k*∂_x( 0.5*u^2 ).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=1024 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization uses a conservative finite-volume method with Rusanov (local Lax–Friedrichs) flux for f(u)=0.5*u^2.
Time integration uses SSP-RK2 (Heun) with a fixed time step.
The time step dt is determined by CFL=0.2, where dt0 = CFL*dx/max|u| (estimate max|u|≈1).
The number of time steps Nt is ceil(T/dt0), and dt is set to T/Nt.
