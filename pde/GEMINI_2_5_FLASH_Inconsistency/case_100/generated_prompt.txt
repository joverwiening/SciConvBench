The PDE to be solved is u_tt = (1.0)^2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions in both directions.
The temporal domain is t in [0,0.5].
The wave speed parameter c is 1.0.
The initial condition for u is u(x,y,0)=cos(2*pi*x)*cos(2*pi*y).
The initial condition for u_t is u_t(x,y,0)=0.
The reference exact solution for verification is u(x,y,t)=cos(2*pi*x)*cos(2*pi*y)*cos(1.0*2*pi*sqrt(2)*t).
The spatial discretization will use a uniform periodic grid with Nx x Ny points on [0,1) x [0,1).
Second-order central differences with wrap-around will be used for spatial derivatives.
The time integration will use a 2nd-order central in time scheme.
The time step dt will be chosen such that the CFL condition is less than or equal to 0.9.
The simulation will be initialized using a Taylor start method with a periodic Laplacian.
The grid will use Nx=Ny=128 points on [0,1) x [0,1), representing a periodic domain with no duplicated endpoints.
The spatial step sizes are dx=dy=1/Nx.
The initial time step dt0 is calculated as 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
The number of time steps Nt is set to ceil(T/dt0), where T=0.5.
The final time step dt is then calculated as T/Nt to ensure the simulation ends exactly at T=0.5.
The simulation will compute u(x,y,T=0.5) on the 2D grid.
The solution will be saved to "solution_agent_wave_19.npz".
The NPZ file will contain 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T, and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) will be saved as "solution_agent_wave_19.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid, will be computed and printed.
