The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 1.0.
The boundary condition is periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps: (A) Diffusion half-step, (B) Reaction full-step, (C) Diffusion half-step.
For the Diffusion half-step (duration dt/2), solve exactly in Fourier space.
First, compute the Fourier transform of u: u_hat(k) <- FFT(u).
Then, define the wave numbers k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, compute the inverse Fourier transform: u <- IFFT(u_hat), taking the real part.
For the Reaction full-step (duration dt), solve exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
