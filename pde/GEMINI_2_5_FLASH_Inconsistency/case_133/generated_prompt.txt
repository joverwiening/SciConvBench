The task is to numerically solve the 1D inviscid conservation law u_t = -k*∂_x( cos(u) ) for u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method requirements are as follows:
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization uses a conservative finite-volume Rusanov flux for f(u)=cos(u).
The wave speed for the Rusanov flux is alpha=max|sin(u)|, which is less than or equal to 1.
The time integration method is SSP-RK2.
The time step is determined using a CFL number of 0.2.
The initial time step dt0 is calculated as CFL*dx/1.0.
The total number of time steps Nt is ceil(T/dt0), and the actual time step dt is T/Nt.
The computation should produce u(x,T=0.2) on the periodic grid.
The results must be saved to a file named "solution_molk_032.npz".
This NPZ file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values T, dx, Nx, and k.
A line plot of u(x,T) must be saved as "solution_molk_032.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at time T must be printed to the console.
