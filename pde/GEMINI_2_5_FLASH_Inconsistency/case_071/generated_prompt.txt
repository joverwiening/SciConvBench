The task is to numerically solve the 2D advection-diffusion PDE u_t + (1.0)*u_x + (0.5)*u_y = 0.01*(u_xx + u_yy).
The spatial domain is [0,1) x [0,1) with periodic boundary conditions in both x and y.
The time domain is [0,0.5].
The initial condition is u(x,y,0)=sin(2*pi*x)*cos(2*pi*y).
The numerical method will use a uniform periodic grid with Nx=Ny=400, resulting in dx=dy=1/400.
The time step is dt=0.001, for a total of Nt=500 steps, reaching T=0.5 exactly.
The time integration scheme is Deterministic IMEX (1st order), where advection is explicit and diffusion is implicit.
The IMEX scheme is defined by the equation (I - dt*D*L) u^{n+1} = u^n - dt*(a*D_x^up u^n + b*D_y^up u^n).
Here, D=0.01, a=1.0, and b=0.5.
L is the 5-point periodic Laplacian operator.
D_x^up and D_y^up are 1st-order upwind operators, using backward differences for positive advection coefficients a and b.
The sparse linear system at each time step will be solved using a direct sparse solver.
The spatial discretization for diffusion uses 2nd-order central differences.
The exact solution for verification is u(x,y,t)=exp(-0.01*8*pi^2*t)*sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t)).
The final solution u(x,y,T=0.5) on the 2D grid must be computed.
A file named "solution_agent_other_06_advection_diffusion.npz" must be saved, containing the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_other_06_advection_diffusion.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid, must also be computed and printed.
