The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is a square (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square.
The boundary values for u are set to match the exact solution u(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi).
The numerical method uses a uniform grid with Nx=Ny=100 intervals in each direction, resulting in (Nx+1)x(Ny+1) grid points.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The spatial discretization uses the standard 5-point stencil for the Laplacian, which is 2nd-order accurate.
The resulting sparse linear system for the interior nodes is solved using a sparse direct solver.
The steady-state solution u(x,y) on the 2D grid must be computed.
The computed solution, along with x, y, dx, and dy arrays, must be saved to a file named "solution_agent_laplace_02.npz".
The u array should have shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]).
A heatmap or contour plot of u(x,y) must be saved as "solution_agent_laplace_02.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) must be printed.
The maximum absolute error and the L2 error between the computed solution and the reference solution (u(x,y)=sinh(pi*x)*sin(pi*y)/sinh(pi)) evaluated on the same grid must be computed and printed.
