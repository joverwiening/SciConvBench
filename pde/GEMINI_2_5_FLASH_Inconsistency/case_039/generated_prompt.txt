The PDE to be solved numerically is u_t = 0.2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.2].
The parameter alpha is 0.2.
Dirichlet boundary conditions are applied on all boundary edges, with u=0.
The initial condition is u(x,y,0) = sin(2*pi*x)*sin(pi*y).
The reference exact solution for verification is u(x,y,t) = exp(-0.2*((2*pi)^2 + (pi)^2)*t) * sin(2*pi*x)*sin(pi*y).
A uniform grid on [0,1] x [0,1] will be used for spatial discretization, with Nx=60 and Ny=60 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The 5-point Laplacian (2nd-order) will be used for spatial discretization.
Implicit Euler (backward Euler) will be used for time integration of diffusion terms.
Dirichlet boundary conditions will be enforced by fixing boundary nodes at each time step.
A sparse linear system will be solved for the interior nodes at each time step.
The time step size dt is 0.001.
The total number of time steps is 200.
The numerical solution u(x,y,T=0.2) will be computed on the 2D grid.
The solution will be saved to "solution_agent_heat_10.npz".
The "solution_agent_heat_10.npz" file will contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) will be saved as "solution_agent_heat_10.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed.
The maximum absolute error and L2 error against the reference solution (evaluated on the same grid) will be computed and printed.
