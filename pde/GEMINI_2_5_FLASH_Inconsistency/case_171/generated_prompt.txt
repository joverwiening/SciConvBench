Solve the 2D Darcy flow PDE numerically.
The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The spatial domain is (x,y) in (0,1) x (0,1).
The parameter beta is 100.0.
The coefficient field a(x,y) is defined as 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions: u = 0 on the entire boundary ∂((0,1) x (0,1)).
Use a uniform Cartesian grid with N=128 intervals in each direction.
The grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N, where dx = dy = 1/N.
Discretize the PDE using 2nd-order finite differences with variable coefficients.
For interior nodes (i=1..N-1, j=1..N-1), use the discretization: -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face coefficients are harmonic means, e.g., a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknowns.
Solve the linear system using the Conjugate Gradient (CG) method to a relative residual tolerance of 1e-10.
Compute u(x,y) on the full (N+1) x (N+1) grid, including boundaries.
Save the solution data to a file named "solution_pdebench_darcy_beta100.npz".
The .npz file must contain the 1D arrays x and y, the 2D array u (shape [N+1, N+1]), and the scalars beta, N, and dx.
Save a heatmap or contour plot of u(x,y) as "solution_pdebench_darcy_beta100.png".
Print the minimum value of u, the maximum value of u, and the discrete relative residual norm ||Au-b||_2 / ||b||_2 for the interior system.
