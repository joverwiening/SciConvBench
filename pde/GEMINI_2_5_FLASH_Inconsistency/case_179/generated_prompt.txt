Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 1.0].
The parameters are nu = 10.0 and rho = 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points on [0,1), defined by x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a fixed time step dt=0.001 for Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt:
First, perform a diffusion half-step of duration dt/2. This is solved exactly in Fourier space: transform u to u_hat using FFT, compute the wave numbers k = 2*pi*fftfreq(Nx, d=dx), update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)), then transform back to real space u using IFFT and take the real part.
Next, perform a reaction full-step of duration dt. This is solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u) using the update formula u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Finally, perform another diffusion half-step of duration dt/2, identical to the first diffusion half-step.
Compute u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_reacdiff_nu10_rho5.npz" as a NumPy NPZ file, containing the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho5.png".
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
