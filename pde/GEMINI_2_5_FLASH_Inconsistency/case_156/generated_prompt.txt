The 1D Compressible Navier-Stokes equations without heat conduction must be solved numerically.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE in conservative form is: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ( (E+p)*v - v*sigma )_x = 0.
Conservative variables U = [rho, m, E] are evolved, where m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1] and the temporal domain is t in [0, 0.5].
Parameters are Gamma = 1.6666666666666667, eta = 0.1, and zeta = 0.1.
Boundary conditions are periodic at x=-1 and x=1.
Initial conditions are rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), and p(x,0) = 1.0 + 0.2*cos(pi*x).
The numerical grid is a uniform finite-volume grid with Nx=400 cells on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, with dx = 2/Nx.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Rho and p must be clipped to a small floor (e.g., 1e-12) to enforce positivity.
The convective flux uses the Rusanov (local Lax-Friedrichs) numerical flux.
The convective flux function is F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
The interface wave speed for Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Viscous terms are computed by first calculating v_x with a centered difference on cell-centered v values.
Sigma is then calculated as sigma = (zeta + 4/3*eta)*v_x.
Sigma at interfaces is approximated by averaging neighboring cell-centered sigma values.
Viscous contributions to the momentum and energy fluxes at interfaces are F_visc = [ 0, -sigma, -v*sigma ] using interface-averaged v and sigma.
The total interface flux is F_total = F_hat + F_visc.
Time integration uses 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.
The time step dt is chosen each step by dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step dt = min(dt_conv, dt_visc).
The last time step must be adjusted so the final time T is hit exactly.
The CFL number is 0.9.
Periodic boundary conditions are implemented by wrapping indices for ghost cells.
The solution rho(x,T), v(x,T), p(x,T) must be computed on the cell centers.
The solution must be saved to "solution_pdebench_cns1d_eta0p1_periodic_smooth.npz".
The npz file must contain 1D arrays: x (length Nx), rho, v, p.
The npz file must contain scalars: Gamma, eta, zeta, T, dx, CFL.
A 3-panel line plot of rho, v, p vs x at T must be saved as "solution_pdebench_cns1d_eta0p1_periodic_smooth.png".
The minimum and maximum values of rho and p must be printed for positivity checks.
The mean of rho over the domain must be printed for mass conservation checks.
