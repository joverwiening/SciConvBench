The task is to solve the 1D Compressible Navier–Stokes equations numerically.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE in conservative form is defined by:
Let m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
Let the viscous stress be sigma = (zeta + 4/3*eta) * v_x.
Assume zeta = eta.
The PDE is:
- rho_t + (m)_x = 0
- m_t   + (m^2/rho + p - sigma)_x = 0
- E_t   + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1] and the temporal domain is t in [0, 0.5].
The parameters are Gamma = 1.6666666666666667, eta = 1e-08, and zeta = 1e-08.
The boundary conditions are periodic on x=-1 and x=1.
The initial conditions are:
- rho(x,0) = 1.0 + 0.2*sin(pi*x)
- v(x,0)   = 0.1*cos(pi*x)
- p(x,0)   = 1.0 + 0.2*cos(pi*x)
The numerical method requirements are as follows:
Use a uniform finite-volume grid with Nx=400 cells on [-1,1].
Cell centers x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Evolve conservative variables U = [rho, m, E] as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) if needed.
For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
The convective flux function is F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
For viscous terms, compute v_x with a centered difference on the cell-centered v values.
Then sigma = (zeta + 4/3*eta)*v_x.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Add viscous contributions to the momentum and energy fluxes at interfaces: F_visc = [ 0, -sigma, -v*sigma ] using interface-averaged v and sigma.
The total interface flux is F_total = F_hat + F_visc.
For time integration, use 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.
Choose dt each step by dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step is dt = min(dt_conv, dt_visc).
Adjust the last step so the final time T is hit exactly.
Use a CFL number of 0.5.
For ghost cells and boundary condition implementation, wrap indices for periodic boundaries.
The output requirements are:
Compute rho(x,T), v(x,T), p(x,T) on the cell centers.
Save "solution_pdebench_cns1d_eta1em8_periodic_smooth.npz" containing arrays: x (1D length Nx), rho (1D), v (1D), p (1D), and scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel (or 3 separate) line plot(s) of rho, v, p vs x at T as "solution_pdebench_cns1d_eta1em8_periodic_smooth.png".
Print the minimum and maximum of rho and p (positivity check), and the mean of rho over the domain (mass conservation check).
