The PDE is the 1D Compressible Navier-Stokes equations without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The conservative variables are rho, m = rho*v, and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE in conservative form is: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1] and the temporal domain is t in [0, 0.5].
The parameter Gamma is 1.6666666666666667.
The parameter eta is 0.01.
The parameter zeta is 0.01.
Periodic boundary conditions are applied at x=-1 and x=1.
The initial conditions at t=0 are rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), and p(x,0) = 1.0 + 0.2*cos(pi*x).
The numerical solution will use a uniform finite-volume grid with Nx=400 cells on [-1,1].
Cell centers x_j are defined as -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
The simulation will evolve the conservative variables U = [rho, m, E] as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Rho and p values will be clipped to a small floor (e.g., 1e-12) to enforce positivity.
The convective flux F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho will be computed using the Rusanov (local Lax-Friedrichs) numerical flux.
The interface wave speed 'a' for the Rusanov flux is max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L) will be used for the inviscid part.
Viscous terms will be computed by first calculating v_x with a centered difference on the cell-centered v values.
Sigma = (zeta + 4/3*eta)*v_x will be approximated at interfaces by averaging neighboring cell-centered sigma values.
Viscous contributions to the momentum and energy fluxes at interfaces are F_visc = [ 0, -sigma, -v*sigma ], using interface-averaged v and sigma.
The total interface flux is F_total = F_hat + F_visc.
Time integration will use 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.
The time step dt will be chosen at each step as dt = min(dt_conv, dt_visc).
dt_conv = CFL * dx / max_j( |v_j| + c_j ).
dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The CFL number is 0.5.
The last time step will be adjusted to hit the final time T exactly.
Periodic boundary conditions will be implemented by wrapping indices for ghost cells.
The simulation will compute rho(x,T), v(x,T), p(x,T) on the cell centers.
The solution will be saved to "solution_pdebench_cns1d_eta0p01_periodic_smooth.npz" containing arrays: x (1D length Nx), rho (1D), v (1D), p (1D), and scalars Gamma, eta, zeta, T, dx, CFL.
A 3-panel line plot of rho, v, p vs x at T will be saved as "solution_pdebench_cns1d_eta0p01_periodic_smooth.png".
The minimum and maximum values of rho and p will be printed for positivity checks.
The mean of rho over the domain will be printed for mass conservation checks.
