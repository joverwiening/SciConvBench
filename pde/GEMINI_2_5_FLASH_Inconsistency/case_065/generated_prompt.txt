The task is to numerically solve the 2D Laplace equation u_xx + u_yy = 0.
The spatial domain is a square (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges: u(x,0)=0, u(x,1)=1, u(0,y)=0, and u(1,y)=0.
The spatial discretization will use a uniform grid with Nx=Ny=100 intervals in each direction.
This results in (Nx+1) by (Ny+1) grid points, including boundaries.
The grid spacing is dx=dy=1/Nx.
Grid points are defined as x_i=i*dx for i=0..Nx and y_j=j*dy for j=0..Ny.
The Laplace operator will be discretized using the standard 5-point stencil (2nd-order accuracy) for interior nodes.
The resulting sparse linear system for the interior nodes will be solved using a sparse direct solver.
The steady-state solution u(x,y) on the 2D grid must be computed.
The solution data must be saved to a file named "solution_agent_laplace_09.npz".
This NPZ file must contain the 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]), and scalar values dx and dy.
A heatmap or contour plot of u(x,y) must be saved as "solution_agent_laplace_09.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) must be printed to standard output.
