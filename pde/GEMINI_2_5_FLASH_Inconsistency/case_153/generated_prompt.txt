The PDE to be solved is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 4.0.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The diffusion half-step (duration dt/2) is solved exactly in Fourier space.
For the diffusion step, u_hat(k) is computed by FFT(u).
The wave numbers k are 2*pi*fftfreq(Nx, d=dx).
u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)).
The spatial field u is then obtained by IFFT(u_hat), taking the real part.
The advection full-step (duration dt) solves the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
A finite-volume update with Rusanov (local Lax-Friedrichs) flux is used for advection.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), alpha is defined as max(abs(u_left), abs(u_right)).
The Rusanov flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The updated field u_new[j] is computed as u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, u is replaced by u_new.
The second diffusion half-step (duration dt/2) is performed identically to the first.
The time step dt is determined using a CFL condition.
The CFL number is 0.4, based on an estimated maximum speed of 1.0 for the initial condition.
An initial time step dt0 is calculated as CFL*dx/1.0.
The number of time steps Nt is ceil(T/dt0), where T=1.0.
The final time step dt is reset to T/Nt to ensure the simulation ends exactly at T.
The simulation computes u(x,T=1.0) on the periodic grid.
The solution is saved to a file named "solution_pdebench_burgers_nu4.npz".
This NPZ file contains the 1D array x (length Nx), the 1D array u (length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
A line plot of u(x,T) is saved as "solution_pdebench_burgers_nu4.png".
The minimum value of u, the maximum value of u, the discrete mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T are printed to the console.
