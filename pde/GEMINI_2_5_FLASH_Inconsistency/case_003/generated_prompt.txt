Solve the 1D advection PDE u_t + a(x)*u_x = 0 numerically.
The advection coefficient is a(x) = 1 + 0.5*sin(2*pi*x).
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0,0.5].
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=1200 points on [0,1).
The grid spacing is dx = 1/Nx.
Discretize the spatial derivatives using a left-biased upwind scheme because a(x) > 0 everywhere.
Integrate in time using the Forward Euler method.
Determine the time step dt such that max_x a(x) * dt / dx <= 0.9.
Specifically, set amax = 1.5.
Calculate an initial time step dt0 = 0.9 * dx / amax.
Calculate the number of time steps Nt = ceil(0.5 / dt0).
Set the final time step dt = 0.5 / Nt to hit the final time exactly.
Compute the solution u(x, T=0.5) on the grid.
Save the solution to a file named "solution_agent_advection_03.npz".
The .npz file must contain the 1D array x, the 1D array u (solution at T=0.5), and scalar metadata T, dx, dt.
Save a line plot of u(x,T=0.5) as "solution_agent_advection_03.png".
Print the minimum value of u at T=0.5.
