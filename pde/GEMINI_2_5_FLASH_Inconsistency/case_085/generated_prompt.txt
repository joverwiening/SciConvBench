The task is to solve the 1D wave equation numerically.
The PDE is u_tt = (1.0)^2 * u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The wave speed parameter c is 1.0.
Dirichlet boundary conditions are applied at x=0 and x=1, with u=0.
The initial condition for u(x,0) is 0.
The initial condition for u_t(x,0) is sin(pi*x).
The reference exact solution is u(x,t) = (1/(1.0*pi))*sin(1.0*pi*t)*sin(pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx=400 intervals, resulting in Nx+1 points.
The spatial step dx is 1/Nx.
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen such that CFL = c*dt/dx <= 0.9 for stability.
Specifically, dt0 = 0.9*dx/c.
Nt is calculated as ceil(T/dt0).
The final dt is set to T/Nt to ensure the final time T is hit exactly.
Initialization uses u(x,0)=u0(x).
u(x,dt) is computed using u_t(x,0)=v0(x) via the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value at every time step.
The simulation computes u(x, T=1.0) on the grid.
The solution is saved to "solution_agent_wave_04.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_wave_04.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same x grid are computed and printed.
