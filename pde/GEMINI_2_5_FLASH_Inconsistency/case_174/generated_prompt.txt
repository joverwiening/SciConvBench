The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 2.0.
The boundary condition is periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps, reaching T=1.0 exactly.
The time integration method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps:
  (A) Diffusion half-step (duration dt/2) solved exactly in Fourier space.
      First, compute u_hat(k) = FFT(u).
      Then, compute k = 2*pi*fftfreq(Nx, d=dx).
      Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
      Finally, compute u = IFFT(u_hat) and take the real part.
  (B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
      Update each grid point u using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
  (C) Diffusion half-step again, identical to step (A).
The simulation must compute u(x,T=1.0) on the periodic grid.
The results must be saved to a file named "solution_pdebench_reacdiff_nu0p5_rho2.npz".
This NPZ file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu0p5_rho2.png".
The minimum value of u, maximum value of u, mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed to standard output.
