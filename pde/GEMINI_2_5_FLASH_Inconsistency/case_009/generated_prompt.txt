The task is to numerically solve the 1D Allen-Cahn equation.
The partial differential equation is u_t = (0.02)^2*u_xx + u - u^3.
The spatial domain is x in [0,1] and the temporal domain is t in [0,1.0].
The parameter epsilon is 0.02.
The boundary conditions are Neumann: u_x(0,t)=0 and u_x(1,t)=0.
The initial condition is u(x,0)=0.05*sin(2*pi*x) + 0.02*sin(6*pi*x).
The spatial discretization will use a uniform grid with Nx=800 intervals, resulting in 801 grid points including endpoints, and dx=(1-0)/800.
Second-order central differences will be used for the u_xx term.
Zero Neumann boundary conditions will be implemented using ghost points with mirror values.
The time integration will use a semi-implicit scheme: (u^{n+1} - u^n)/dt = epsilon^2*u_xx^{n+1} + u^n - (u^n)^3.
This scheme requires solving a linear system at each time step.
The time step size is dt=0.0005, leading to 2000 time steps to reach T=1.0.
The solution u(x, T=1.0) on the computational grid must be computed.
The computed solution will be saved to a file named "solution_agent_allen_cahn_03.npz".
This NPZ file will contain the 1D arrays x and u, and scalar metadata T, dx, and dt.
A line plot of u(x,T) will be saved as "solution_agent_allen_cahn_03.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0 will be printed to the console.
