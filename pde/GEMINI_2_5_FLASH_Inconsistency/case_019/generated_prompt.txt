The PDE to be solved is u_t = 0.1 * u_xx + 0.01 * u_yy.
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.2].
The diffusion coefficient for the x-derivative is Dx = 0.1.
The diffusion coefficient for the y-derivative is Dy = 0.01.
Dirichlet boundary conditions are applied on all boundary edges, with u=0.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y).
The reference exact solution for verification is u(x,y,t)=exp(-( 0.1+0.01 )*pi^2*t)*sin(pi*x)*sin(pi*y).
The spatial discretization will use a uniform grid with Nx=Ny=60 intervals.
The grid points will include both endpoints, resulting in Nx+1 points in each dimension.
The spatial discretization will use a standard 5-point Laplacian, scaling x- and y- second derivatives by Dx and Dy respectively.
The time integration method will be Implicit Euler.
The time step size is dt=0.001.
The total simulation time is T=0.2.
The number of time steps will be 200.
The simulation will compute u(x,y,T=0.2) on the 2D grid.
The solution will be saved to "solution_agent_diffusion_03.npz".
The NPZ file will contain arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) will be saved as "solution_agent_diffusion_03.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed.
The maximum absolute error and L2 error versus the reference solution, evaluated on the same grid, will be computed and printed.
