The PDE to solve is u_t = (0.02)^2*(u_xx + u_yy) + u - u^3.
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.1].
The parameter epsilon is 0.02.
Dirichlet boundary conditions are applied on all boundaries, with u=0.
The initial condition is u(x,y,0)=tanh((0.25 - r)/(sqrt(2)*0.02)), where r = sqrt((x-0.5)^2 + (y-0.5)^2).
The numerical method uses a uniform grid with Nx=Ny=300.
The spatial discretization uses a 5-point Laplacian for u_xx+u_yy.
The time integration is semi-implicit, following the scheme (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
A sparse linear system must be solved at each time step.
Dirichlet boundary conditions are enforced by setting boundary nodes to the prescribed values at every time step.
The time step is dt=0.0001, for a total of 1000 steps.
The solution u(x,y,T=0.1) on the 2D grid must be computed.
The solution must be saved to "solution_agent_allen_cahn_05.npz".
The npz file must contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_allen_cahn_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed to standard output.
