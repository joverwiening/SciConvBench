The task ID is agent_wave_02.
The PDE category is Wave equation.
The unknown field is u(x,t).
The PDE to solve numerically is u_tt = (0.5)^2 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The wave speed parameter c is 0.5.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The initial condition for u is u(x,0)=sin(2*pi*x).
The initial condition for u_t is u_t(x,0)=0.
The reference exact solution is u(x,t)=cos(0.5*2*pi*t)*sin(2*pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx intervals, resulting in Nx+1 grid points.
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
For stability, the time step dt is chosen such that CFL = c*dt/dx ≤ 0.9, where c=0.5.
The initialization uses u(x,0)=u0(x).
u(x,dt) is computed using u_t(x,0)=v0(x) via the Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0), where c=0.5 is the wave speed from the PDE.
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value at every time step.
The grid uses Nx=400 intervals, resulting in Nx+1 points.
The spatial step dx is 1/Nx.
An initial time step dt0 is calculated as 0.9*dx/c, where c=0.5.
The number of time steps Nt is calculated as ceil(T/dt0).
The final time step dt is set to T/Nt to ensure the final time T=1.0 is hit exactly.
The numerical solution u(x, T=1.0) is computed on the grid.
A file named "solution_agent_wave_02.npz" is saved, containing the 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_wave_02.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
