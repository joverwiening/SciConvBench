Solve the 1D heat equation u_t = 0.1 * u_xx numerically.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 0.5].
The parameter alpha is 0.1.
Dirichlet boundary conditions are u(0,t)=0 and u(1,t)=0 for all t.
The initial condition is u(x,0) = sin(pi*x).
The exact solution for verification is u(x,t) = exp(-0.1*pi^2*t) * sin(pi*x).
Use a uniform spatial grid on [0,1] with Nx=200 intervals, resulting in Nx+1=201 grid points including both boundaries.
The spatial discretization for u_xx in the interior should use 2nd-order central differences.
The time integration method should be Crank–Nicolson for diffusion terms.
Enforce Dirichlet boundary conditions by fixing boundary nodes at each time step.
Use a time step dt=0.001.
The total number of time steps is 500, reaching T=0.5.
Compute the numerical solution u(x, T=0.5) on the specified grid.
Save the solution to a file named "solution_agent_heat_01.npz".
This NPZ file must contain the 1D array x, the 1D array u (same length as x), and the scalar metadata T, dx, and dt.
Save a line plot of u(x,T) as "solution_agent_heat_01.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) of the solution at T=0.5.
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution evaluated on the same x grid at T=0.5.
