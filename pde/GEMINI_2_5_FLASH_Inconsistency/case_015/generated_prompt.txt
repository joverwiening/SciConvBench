The PDE to solve is u_t + u*u_x = 0.01*u_xx.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.5].
The parameter nu is 0.01.
Dirichlet boundary conditions are applied: u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0)=sin(pi*x).
The spatial discretization uses a conservative form u_t + (f(u))_x = nu*u_xx with f(u)=0.5*u^2.
Convection is discretized using finite-volume/conservative finite-difference with the Rusanov (local Lax–Friedrichs) flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|). The spatial derivative is approximated as (f(u))_x ≈ (F_{i+1/2}-F_{i-1/2})/dx.
Diffusion is discretized using a 2nd-order central difference: u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Time integration uses a 1st-order IMEX scheme, treating convection explicitly and diffusion implicitly: (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_{i-1})/dx^2.
This yields a linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term, which should be solved each step.
Boundary conditions are enforced by setting u[0]=0 and u[N]=0 at each step. One-sided/ghost treatment consistent with the diffusion stencil is used, and convection fluxes are computed using boundary values/ghosts.
The grid uses Nx=800 intervals, resulting in Nx+1 points on [0,1] including endpoints.
The spatial step size is dx=1/Nx.
The time step size is dt=1e-4, with Nt=5000 steps to reach T=0.5 exactly.
The solution u(x, T=0.5) on the grid must be computed.
The solution must be saved to "solution_agent_burgers_03.npz" as a NumPy archive containing arrays: x (1D), u (1D, same length as x), and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_burgers_03.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
