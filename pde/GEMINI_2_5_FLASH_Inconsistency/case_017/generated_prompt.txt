The task is to numerically solve the 1D diffusion PDE u_t = ∂/∂x( D(x) * u_x ) for u(x,t).
The diffusion coefficient is D(x) = 0.1*(1 + x).
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.5].
Dirichlet boundary conditions are u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0)=sin(pi*x).
A uniform spatial grid with Nx=300 intervals will be used, resulting in Nx+1 grid points.
The spatial discretization will use a conservative 2nd-order finite difference scheme in flux form.
The discrete diffusion operator for interior points i=1..Nx-1 is (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
Face values D_{i+1/2} are computed by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
Time integration will use the Implicit Euler method: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
The sparse linear system will be solved at each time step.
The time step size is dt=0.001.
The simulation will run for 500 time steps to reach T=0.5.
The solution u(x, T=0.5) on the computational grid will be computed.
The arrays x and u, along with metadata scalars T, dx, and dt, will be saved to "solution_agent_diffusion_01.npz".
A line plot of u(x,T) will be saved as "solution_agent_diffusion_01.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5 will be printed to the console.
