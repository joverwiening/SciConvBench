The PDE to be solved is u_t = ∇·( D(x,y) ∇u ).
The unknown field is u(x,y,t).
The spatial domain is (x,y) in [0,1] x [0,1].
The temporal domain is t in [0,0.1].
The diffusion coefficient is D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Dirichlet boundary conditions u=0 are applied on all boundary edges.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y).
The spatial discretization uses a conservative 2nd-order scheme in flux form for ∇·(D(x,y)∇u) on a uniform grid (x_i,y_j).
Arithmetic face averages are used for the diffusion coefficient: D_{i+1/2,j}=0.5*(D_{i,j}+D_{i+1,j}) and D_{i,j+1/2}=0.5*(D_{i,j}+D_{i,j+1}).
For interior nodes (i=1..Nx-1, j=1..Ny-1), the discrete operator is (∇·(D∇u))_{i,j} ≈ (1/dx^2)[ D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}(u_{i,j}-u_{i-1,j}) ] + (1/dy^2)[ D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}(u_{i,j}-u_{i,j-1}) ].
The time integration uses the Implicit Euler method: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
A sparse linear system must be solved at each time step.
The grid resolution is Nx=80 and Ny=80.
The time step size is dt=0.0005.
The simulation runs for a total time of T=0.1, which corresponds to 200 time steps.
The solution u(x,y,T=0.1) must be computed on the 2D grid.
The solution must be saved to "solution_agent_diffusion_04.npz".
The npz file must contain the 1D arrays x and y, the 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and the scalar metadata T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T) must be saved as "solution_agent_diffusion_04.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed to the console.
