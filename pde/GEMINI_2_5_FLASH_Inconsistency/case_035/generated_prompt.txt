The PDE to be solved is u_t = 0.1 * u_xx.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 0.5].
The parameter alpha is 0.1.
Dirichlet boundary conditions are applied: u(0,t)=1 and u(1,t)=0 for all t.
The initial condition is u(x,0) = 1 - x.
The reference exact solution is u(x,t) = 1 - x.
The spatial discretization uses a uniform grid on [0,1] with Nx=200 intervals, resulting in Nx+1 grid points.
Second-order central differences are used for the u_xx term in the interior.
Time integration uses the Crank–Nicolson method for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step.
The time step is dt=0.001.
The total number of time steps is 500.
The simulation computes u(x, T=0.5) on the specified grid.
The solution is saved to "solution_agent_heat_06.npz" containing arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_heat_06.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid, are computed and printed.
