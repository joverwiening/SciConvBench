The PDE to be solved is u_xx + u_yy = 0.
The spatial domain is (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square.
The value of u on the boundary is set to match u(x,y)=x.
The reference exact solution for verification is u(x,y)=x.
The spatial discretization uses a standard 5-point stencil (2nd-order) on a uniform grid over (0,1) x (0,1).
The resulting sparse linear system for interior nodes is solved using a sparse direct solver.
The grid uses Nx=Ny=100 intervals in each direction.
The grid points include boundaries, resulting in Nx+1 by Ny+1 points.
The grid spacing is dx=dy=1/Nx.
The x-coordinates are x_i=i*dx for i=0..Nx.
The y-coordinates are y_j=j*dy for j=0..Ny.
The steady-state solution u(x,y) is computed on the 2D grid.
The solution is saved to "solution_agent_laplace_03.npz".
The npz file contains arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j])), and scalar metadata dx, dy.
A heatmap/contour plot of u(x,y) is saved as "solution_agent_laplace_03.png".
The minimum value of u is printed.
The maximum value of u is printed.
The discrete L2 norm sqrt(sum(u^2)*dx*dy) is printed.
The maximum absolute error versus the reference solution evaluated on the same grid is computed and printed.
The L2 error versus the reference solution evaluated on the same grid is computed and printed.
