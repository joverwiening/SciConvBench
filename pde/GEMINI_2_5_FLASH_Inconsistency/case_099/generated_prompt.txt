The task ID is agent_wave_18.
The PDE to solve is the 1D wave equation u_tt = c^2 * u_xx.
The unknown field is u(x,t).
The wave speed c is 1.0.
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The boundary conditions are Dirichlet u=0 at x=0 and x=1 for all t.
The initial condition for u is u(x,0) = exp(-200*(x-0.5)^2).
The initial condition for u_t is u_t(x,0) = 0.
The spatial discretization uses a uniform grid on [0,1] with Nx=800 intervals, resulting in Nx+1 grid points.
The spatial step size dx is (1-0)/Nx.
Second-order central differences are used for the u_xx term in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen such that the CFL condition c*dt/dx <= 0.9 is met.
Specifically, dt0 = 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt to ensure the final time T=1.0 is hit exactly.
The initialization for the first time step u(x,dt) uses a Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0).
Given v0=0 and f^0=0, this simplifies to u^1 = u^0 + 0.5*dt^2*c^2*u_xx^0.
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value (0) at every time step.
The solution u(x, T=1.0) must be computed on the grid used.
The solution must be saved to a file named "solution_agent_wave_18.npz".
The .npz file must contain the 1D array x, the 1D array u (same length as x), and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_18.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T must be printed to the console.
