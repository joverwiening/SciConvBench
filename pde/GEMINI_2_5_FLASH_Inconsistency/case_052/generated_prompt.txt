The task is to numerically solve the 2D Klein-Gordon equation u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0 for the unknown field u(x,y,t).
The spatial domain is [0,1] x [0,1] and the temporal domain is [0,0.8].
The parameters are c = 1.0 and m = 1.0.
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition for u(x,y,0) is sin(pi*x)*sin(pi*y).
The initial condition for u_t(x,y,0) is 0.
The reference exact solution for verification is u(x,y,t)=cos(sqrt((1.0)^2*(2*pi^2) + (1.0)^2)*t)*sin(pi*x)*sin(pi*y).
The spatial discretization will use a uniform grid with Nx=Ny=256 intervals, resulting in Nx+1 by Ny+1 grid points.
The spatial step sizes are dx=dy=1/Nx.
A 5-point Laplacian stencil will be used for the u_xx+u_yy term.
Time integration will use a 2nd-order central difference scheme for u_tt.
The simulation will be initialized using a Taylor start, incorporating the Laplacian and mass terms.
The time step dt will be calculated as follows: first, calculate dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Then, set Nt = ceil(T/dt0) where T=0.8.
Finally, set dt = T/Nt to ensure the final time T is hit exactly.
The numerical solution u(x,y,T=0.8) on the 2D grid must be computed.
The computed solution and metadata must be saved to a file named "solution_agent_kg_05.npz".
This NPZ file must contain the 1D arrays x and y, a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T=0.8, and scalar metadata T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T=0.8) must be saved as "solution_agent_kg_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T=0.8 must be printed.
The maximum absolute error and the L2 error between the computed solution and the reference exact solution, both evaluated on the same grid at T=0.8, must also be computed and printed.
