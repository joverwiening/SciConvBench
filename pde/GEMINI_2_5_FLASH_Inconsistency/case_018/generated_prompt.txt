The task ID is agent_diffusion_02.
The PDE category is Diffusion.
The unknown field is u(x,t).
Solve the PDE numerically.
Treat all functions exactly as written, using radians for trigonometric functions.
The PDE is u_t = ∂/∂x( D(x) * u_x ), where D(x) = 0.01 + 0.09*x^2.
The spatial domain for x is [0,1].
The temporal domain for t is [0,0.2].
The parameter D(x) is 0.01 + 0.09*x^2.
Dirichlet boundary conditions are applied at x=0 and x=1: u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0)=x*(1-x).
Use a conservative 2nd-order discretization in flux form for (D(x) u_x)_x on a uniform grid x_i.
Define D_i = D(x_i).
Define face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior points i=1..Nx-1, approximate ( (D u_x)_x )_i as (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
Use Implicit Euler for time integration: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
Solve the sparse linear system at each time step.
Use Nx=400 for the spatial grid.
The spatial domain [0,1] with Nx=400 means there are Nx+1 grid points, dx=(1-0)/Nx, and x_i=0+i*dx.
Use dt=0.0005 for the time step.
The simulation will run for 400 time steps to reach T=0.2.
Compute u(x, T=0.2) on the grid.
