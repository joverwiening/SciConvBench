The PDE to solve is u_tt + 0.5*u_t = (1.0)^2 * u_xx.
The spatial domain is x in [0,1].
The time domain is t in [0,3.0].
The parameter c is 1.0.
The parameter gamma is 0.5.
Dirichlet boundary conditions are applied at x=0 and x=1, where u=0.
The initial condition for u is u(x,0)=sin(pi*x).
The initial condition for u_t is u_t(x,0)=0.
The spatial discretization uses 2nd-order central differences for u_xx on a uniform grid.
The problem is rewritten as a first-order system in time with v = u_t: u_t = v, v_t = c^2*u_xx - gamma*v.
The u_xx term in the first-order system is discretized with 2nd-order central differences.
The system (u,v) is integrated using classical RK4.
The time step dt is fixed at 0.0005.
Dirichlet boundary conditions are enforced by setting u=0 at the boundaries at every RK substage.
The boundary values for v are set to 0 for consistency at every RK substage.
The number of spatial intervals Nx is 400.
The final time T for computation is 3.0.
The solution u(x, T=3.0) is computed on the grid.
