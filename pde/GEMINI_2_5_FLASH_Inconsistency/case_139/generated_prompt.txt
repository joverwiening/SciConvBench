The PDE to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
The parameter beta is 1.0.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
The numerical method uses explicit forward Euler for time integration.
The spatial grid is uniform with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
Spatial discretization uses 1st-order upwind finite difference for u_x, with the upwind direction determined by the sign of beta.
The time step dt is determined by CFL=0.5, calculated as dt = CFL * dx / abs(beta).
The number of time steps Nt is ceil(T/dt), and dt is then reset to T/Nt to hit the final time exactly.
Compute the numerical solution u(x,T=2.0) on the periodic grid.
Save the solution to "solution_pdebench_advection_beta1.npz" containing arrays x, u, and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta1.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
