The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 1.0.
The parameter rho is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time step is fixed at dt=0.001.
The total number of time steps is Nt=1000, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three sub-steps: (A) Diffusion half-step (duration dt/2), (B) Reaction full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), solve exactly in Fourier space.
First, compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Then, compute u = IFFT(u_hat) and take the real part.
For the reaction full-step (B), solve the logistic ODE du/dt = rho*u*(1-u) exactly pointwise for each grid point.
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
