The task is to numerically solve the 2D Diffusion-Reaction PDE u_t = 0.01*(u_xx + u_yy) + 2.0*u*(1 - u).
The spatial domain is (x,y) in [0,1] x [0,1], and the time domain is t in [0,1.0].
The diffusion coefficient D is 0.01 and the reaction rate r is 2.0.
Zero Neumann boundary conditions (∂u/∂n = 0) are applied on all boundary edges.
The initial condition is u(x,y,0)=0.2 + 0.05*cos(2*pi*x)*cos(2*pi*y).
A uniform grid with Nx=Ny=120 intervals is used, resulting in (Nx+1) by (Ny+1) grid points.
The spatial discretization uses a 5-point Laplacian for diffusion.
Zero Neumann boundary conditions are implemented using ghost nodes with mirror values.
The time integration uses a 1st order deterministic IMEX scheme: diffusion is treated implicitly (backward Euler), and reaction is treated explicitly (forward Euler).
At each time step, the equation (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) is solved, where L is the discrete Laplacian and R(u) is the reaction term.
A sparse direct solver is used at each time step.
The time step size dt is 0.001, leading to Nt=1000 steps.
The solution u(x,y,T=1.0) on the 2D grid must be computed.
The solution data must be saved to "solution_agent_diffusion_reaction_05.npz".
The .npz file must contain 1D arrays x and y, a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_diffusion_reaction_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
