The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 1.0].
The parameters are nu = 5.0 and rho = 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1), defined by x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The time integration uses a fixed time step dt=0.001 for Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
Each Strang splitting step consists of three sub-steps:
First, a diffusion half-step of duration dt/2 is solved exactly in Fourier space.
This involves computing the FFT of u to get u_hat(k), where k = 2*pi*fftfreq(Nx, d=dx).
Then, u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, the inverse FFT of the updated u_hat is computed, and its real part is taken to get u.
Second, a reaction full-step of duration dt is solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, another diffusion half-step of duration dt/2 is performed, identical to the first sub-step.
The final solution u(x,T=1.0) on the periodic grid must be computed.
The results must be saved to a file named "solution_pdebench_reacdiff_nu5_rho5.npz".
This NPZ file must contain the 1D arrays x (length Nx) and u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu5_rho5.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed to the console.
