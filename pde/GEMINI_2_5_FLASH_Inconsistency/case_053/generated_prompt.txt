The PDE to be solved is u_tt - (0.8)^2*(u_xx + u_yy) + (0.2)^2*u = 0.
The unknown field is u(x,y,t).
The spatial domain is [0,1] x [0,1].
The temporal domain is [0,1.0].
The parameter c is 0.8.
The parameter m is 0.2.
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition for u is u(x,y,0)=sin(2*pi*x)*sin(pi*y).
The initial condition for u_t is u_t(x,y,0)=0.
The reference exact solution is u(x,y,t)=cos(sqrt((0.8)^2*((2*pi)^2 + (pi)^2) + (0.2)^2)*t)*sin(2*pi*x)*sin(pi*y).
The spatial discretization uses a uniform grid with Nx=Ny=160 intervals, resulting in Nx+1 by Ny+1 grid points.
The spatial step sizes are dx=dy=1/Nx.
The spatial discretization uses a 5-point Laplacian for u_xx+u_yy.
The time integration uses a 2nd-order central difference scheme for u_tt.
The initial time step dt0 is calculated as 0.5*min(dx,dy)/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is adjusted to T/Nt to hit the final time exactly.
The simulation uses a Taylor start initialization, incorporating the Laplacian and mass term.
The simulation computes u(x,y,T=1.0) on the 2D grid.
The solution is saved to "solution_agent_kg_06.npz" containing 1D arrays x, y, and a 2D array u (with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T), along with scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) is saved as "solution_agent_kg_06.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T are printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid, are computed and printed.
