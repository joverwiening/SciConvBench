The PDE u_tt = (0.7)^2 * (u_xx + u_yy) will be solved numerically.
The spatial domain is (x,y) in [0,1] x [0,1] and the temporal domain is t in [0,0.8].
The parameter c = 1.4 will be used for the CFL condition.
Dirichlet boundary conditions u=0 will be applied on all boundaries.
The initial condition is u(x,y,0)=sin(2*pi*x)*sin(pi*y) and u_t(x,y,0)=0.
The reference exact solution is u(x,y,t)=cos(0.7*pi*sqrt(5)*t)*sin(2*pi*x)*sin(pi*y).
A uniform grid on [0,1] x [0,1] will be used with Nx=140 and Ny=140 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The spatial discretization will use the 5-point Laplacian for ∇²u.
Time integration will use a 2nd-order central difference for u_tt.
The time step dt will be chosen such that CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9, where c=1.4.
Specifically, dx=dy=1/Nx. dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)). Nt = ceil(T/dt0) and dt = T/Nt, where T=0.8.
u at the first time step will be computed using the Taylor start with the initial velocity.
For Dirichlet boundary conditions, boundary nodes will be set to u=0 at each time step.
The solution u(x,y,T=0.8) will be computed on the 2D grid.
The solution will be saved to "solution_agent_wave_08.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) will be saved as "solution_agent_wave_08.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same grid, will also be computed and printed.
