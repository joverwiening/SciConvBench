The PDE to be solved is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.4.
The initial condition is u(x,0) = sin(2*pi*x).
The numerical solution will be computed on a uniform periodic grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step, (B) Advection full-step, (C) Diffusion half-step.
For the diffusion half-step (A and C), the solution is obtained exactly in Fourier space.
First, compute u_hat(k) by taking the Fast Fourier Transform (FFT) of u.
The wave numbers k are defined as k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) using the formula u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Then, compute u by taking the Inverse Fast Fourier Transform (IFFT) of u_hat, retaining only the real part.
For the advection full-step (B), solve the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F at the interface is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, define F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
Update u_new[j] using the finite-volume formula u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
The time step dt is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated maximum speed is 1.0.
Calculate the number of time steps Nt = ceil(T/dt0), where T=1.0.
Reset dt = T/Nt to ensure the final time T is hit exactly.
Compute the solution u(x,T=1.0) on the periodic grid.

The .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values nu, T, dx, dt, Nx, Nt.
