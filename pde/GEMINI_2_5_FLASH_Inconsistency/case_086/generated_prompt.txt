The task ID is agent_wave_05.
Solve the 1D wave equation numerically.

The spatial step size is dx = 1/Nx.

Calculate an initial time step dt0 = 0.9*dx/c.
Determine the number of time steps Nt = ceil(T/dt0), where T=1.0.
Set the final time step dt = T/Nt to hit the final time exactly.
Initialize the solution using a Taylor start with the periodic Laplacian.
Compute the numerical solution u(x, T=1.0) on the grid.
Save the solution to a file named "solution_agent_wave_05.npz".
