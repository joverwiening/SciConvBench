The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 10.0.
The parameter rho is 1.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A uniform periodic spatial grid will be used with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
A fixed time step dt=0.001 will be used for Nt=1000 steps, reaching T=1.0 exactly.
The numerical method is Strang splitting for each full time step dt.
The first half-step (duration dt/2) is for diffusion, solved exactly in Fourier space.
The Fourier transform of u is computed as u_hat(k).
The wave numbers k are calculated as k = 2*pi*fftfreq(Nx, d=dx).
The Fourier coefficients are updated as u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The inverse Fourier transform of u_hat is computed, taking the real part, to get u.
The full step (duration dt) is for reaction, solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The second half-step (duration dt/2) is for diffusion, identical to the first half-step.
The final solution u(x,T=1.0) on the periodic grid will be computed.
The solution will be saved to "solution_pdebench_reacdiff_nu10_rho1.npz".
The .npz file will contain the 1D arrays x (length Nx) and u (length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) will be saved as "solution_pdebench_reacdiff_nu10_rho1.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T will be printed.
