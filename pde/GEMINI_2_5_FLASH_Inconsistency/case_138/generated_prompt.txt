The PDE to be solved is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 2.0].
The parameter beta is 0.7.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
The spatial grid is uniform with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The spatial discretization uses a 1st-order upwind finite difference for u_x, with the upwind direction determined by the sign of beta.
Time integration uses the Explicit forward Euler method.
The time step dt is determined by CFL=0.5, calculated as dt = CFL * dx / abs(beta).
The number of time steps Nt is ceil(T/dt), and dt is then reset to T/Nt to hit the final time T exactly.
The simulation computes u(x,T=2.0) on the periodic grid.
The results are saved to "solution_pdebench_advection_beta0p7.npz", containing arrays x and u, and scalars beta, T, dx, dt, Nx, Nt.
A line plot of u(x,T) is saved as "solution_pdebench_advection_beta0p7.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid, are computed and printed.
