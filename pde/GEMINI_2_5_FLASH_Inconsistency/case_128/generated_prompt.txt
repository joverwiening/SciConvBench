Solve the 1D nonlinear convection–diffusion PDE u_t = -q1*∂_x( (1/3)*u^3 ) + (q2/pi)*u_xx numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions, and the temporal domain is t in [0, 0.5].
The parameters are q1 = 1.0 and q2 = 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required.
Use a uniform periodic spatial grid with Nx=1024 points on [0,1).
Calculate dx as 1/Nx.
The grid points are x_j = j*dx for j=0,...,Nx-1.
For spatial discretization, use a conservative finite-volume Rusanov flux for the convection term ∂_x((1/3)u^3).
For spatial discretization, use 2nd-order central differences for the diffusion term u_xx.
For time integration, use SSP-RK2.
Determine the time step using a CFL condition: estimate max|f'(u)| = max|u^2|.
With the initial condition, assume max|u|<=0.5, so max|f'|<=0.25.
Calculate dt0 = CFL*dx/max|f'| with CFL=0.2.
Calculate dt_diff = 0.2*dx^2/(q2/pi).
Set dt = min(dt0, dt_diff).
Calculate the number of time steps Nt = ceil(T/dt), where T=0.5.
Recalculate dt = T/Nt to ensure the simulation ends exactly at T.
Compute the solution u(x,T=0.5) on the periodic grid.
Save the solution to a file named "solution_molk_027.npz".
The .npz file must contain the 1D array x (length Nx), the 1D array u (length Nx), and the scalar values T, dx, Nx, q1, and q2.
Save a line plot of u(x,T) as "solution_molk_027.png".
Print the minimum value of u at T.

Print the mean value of u at T.
