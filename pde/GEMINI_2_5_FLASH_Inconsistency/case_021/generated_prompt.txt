The PDE to solve is u_t = D * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.5].
The diffusion coefficient D is 0.1.
The Robin boundary condition parameter beta is 1.0.
The boundary condition at x=0 is u_x(0,t) + beta*u(0,t) = 0.
The boundary condition at x=1 is u_x(1,t) + beta*u(1,t) = 0.
The initial condition is u(x,0) = cos(pi*x).
The spatial discretization uses a uniform grid with Nx=300 intervals.
There are Nx+1 grid points in the spatial domain.
The spatial step size dx is (1-0)/Nx.
Second-order central differences are used for the u_xx term.
The Robin boundary conditions are implemented using 2nd-order one-sided differences for u_x at the boundary.
At x=0 (grid index i=0), the approximation for u_x(0) is (-3*u0 + 4*u1 - u2)/(2*dx).
This approximation is enforced in the boundary condition: (-3*u0 + 4*u1 - u2)/(2*dx) + beta*u0 = 0.
At x=1 (grid index i=Nx), the approximation for u_x(1) is (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx).
This approximation is enforced in the boundary condition: (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx) + beta*uN = 0.
Time integration uses the Crank–Nicolson method.
The time step size dt is 0.001.
The total simulation time T is 0.5.
The number of time steps is 500.
A linear system is solved at each time step.
The solution u(x, T=0.5) on the computational grid must be computed.
The computed solution and metadata must be saved to a file named "solution_agent_diffusion_05.npz".
The "solution_agent_diffusion_05.npz" file must contain 1D arrays for x and u, and scalar metadata T, dx, and dt.
A line plot of u(x,T) must be saved as "solution_agent_diffusion_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T must be printed to the console.
