Solve the 2D Darcy flow PDE on the unit square (0,1)x(0,1).
Use the PDE -∇ · ( a(x,y) ∇u(x,y) ) = 1.
Set the coefficient a(x,y) = 1 + 2 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary condition u = 0 on all four sides of the square.
Use a uniform Cartesian grid with 128 intervals in each direction, resulting in 129x129 grid points.
Define grid spacing dx = dy = 1/128.
Define grid points x_i = i*dx for i=0,...,128 and y_j = j*dy for j=0,...,128.
Discretize the PDE at interior nodes (i=1..127, j=1..127) using second-order finite differences.
Compute face-centered coefficients using harmonic averaging, e.g., a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the resulting sparse linear system Au = b for the interior unknowns.
Solve the linear system using the conjugate gradient method to a relative residual tolerance of 1e-10.
Apply a Jacobi preconditioner to the linear solver.
Compute the solution u(x,y) on the full 129x129 grid, enforcing the zero Dirichlet boundary condition.
Save the results to a file named "solution_pdebench_darcy_beta1.npz".
The NPZ file must contain the 1D arrays 'x' and 'y', the 2D solution array 'u', and the scalars 'beta', 'N', and 'dx'.
Create a heatmap or contour plot of the solution u(x,y).
Save the plot as "solution_pdebench_darcy_beta1.png".
Print to the console the minimum value of u, the maximum value of u, and the discrete relative residual norm ||Au-b||_2 / ||b||_2 for the interior system.
