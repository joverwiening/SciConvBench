Solve the 1D Viscous Burgers equation numerically.
Use the PDE: u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
Set the parameter nu = 0.2.
Use the spatial domain x in [0, 1) with periodic boundary conditions.
Use the temporal domain t in [0, 1.0].
Apply the initial condition u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
Define grid points as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Set the final time T = 1.0.
Calculate the initial time step dt0 using CFL=0.4 and an estimated max speed of 1.0, as dt0 = CFL*dx/1.0.
Determine the number of time steps Nt = ceil(T/dt0).
Recalculate the actual time step as dt = T/Nt.
Use Strang splitting for each full time step dt.
Perform a diffusion half-step of duration dt/2 exactly in Fourier space.
Perform an advection full-step of duration dt using a finite-volume method with Rusanov flux.
Perform another diffusion half-step identical to the first.
Compute the solution u(x, T=1.0) on the periodic grid.
Save the results to "solution_pdebench_burgers_nu0p2.npz".
Include the arrays x and u, and the scalars nu, T, dx, dt, Nx, Nt in the .npz file.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p2.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the discrete mean value of u at T.
