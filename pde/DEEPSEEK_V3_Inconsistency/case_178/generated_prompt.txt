Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
Use the domain x in [0, 1) with periodic boundary and t in [0, 1.0].
Set the parameter nu to 10.0.
Set the parameter rho to 2.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition to u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use the Explicit forward Euler time integration method.
Use a uniform periodic spatial grid with Nx = 512 points.
Define the spatial grid points as x_j = j*dx for j=0,...,Nx-1 with dx = 1/Nx.
Use a fixed time step dt = 0.001.
Set the number of time steps Nt = 1000 to reach exactly T = 1.0.
Implement the Strang splitting method for each full time step dt.
For the diffusion half-step of duration dt/2, solve exactly in Fourier space.
Compute the FFT of u to get u_hat(k).
Calculate the wave numbers k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) <- u_hat(k) * exp(-nu * k**2 * (dt/2)).
Compute the inverse FFT to get u, taking the real part.
For the reaction full-step of duration dt, solve the logistic ODE exactly pointwise.
At each grid point, update u using the formula u <- (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).
Apply the diffusion half-step again after the reaction step.
Compute the final solution u(x, T=1.0) on the periodic grid.

Include in the .npz file the arrays x and u.
Include in the .npz file the scalar values nu, rho, T, dx, dt, Nx, and Nt.
