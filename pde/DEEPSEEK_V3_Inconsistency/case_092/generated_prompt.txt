Solve the two-dimensional wave equation with a forcing term on the unit square.
The PDE is u_tt = (1.0)^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t).
The spatial domain is (x,y) in [0,1] x [0,1].
The temporal domain is t in [0, 1.0].
The wave speed parameter c is 2.
Apply Dirichlet boundary conditions (u=0) on all four boundaries.
The initial conditions are u(x,y,0)=0 and u_t(x,y,0)=0.
Use a uniform spatial grid with Nx=120 intervals in x and Ny=120 intervals in y.
This results in Nx+1 grid points in x and Ny+1 grid points in y.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
Discretize the spatial Laplacian using the standard 5-point finite difference stencil.
Discretize the temporal second derivative using a second-order central difference.
For stability, calculate a provisional time step dt0 = 0.9 / (c * sqrt(1/dx^2 + 1/dy^2)).
Set the number of time steps Nt = ceil(T / dt0), where T=1.0.
Define the final time step as dt = T / Nt to ensure the simulation ends exactly at t=T=1.0.
Initialize the solution at the first time step using a Taylor expansion incorporating the initial velocity.
Enforce the Dirichlet boundary conditions by explicitly setting the boundary nodes to zero at each time step.
Advance the numerical solution from t=0 to t=T=1.0.
Compute the final solution field u(x,y,T=1.0) on the spatial grid.
Save the results to a file named "solution_agent_wave_11.npz".
The NPZ file must contain the following arrays: x (1D), y (1D), u (2D).
The 2D array u must have shape (len(y), len(x)) such that u[j, i] = u(x[i], y[j]).
The NPZ file must also contain the scalar metadata values: T, dx, dy, dt.
Generate a heatmap or contour plot of the final solution u(x,y,T).
Save this plot as "solution_agent_wave_11.png".
