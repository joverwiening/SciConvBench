Solve the 2D Darcy flow PDE -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (x,y) in (0,1) x (0,1).
Use the parameter beta = 0.1.
Define the coefficient field as a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary condition u = 0 on the entire boundary ∂((0,1) x (0,1)).
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1=129 points per side.
Set grid spacing dx = dy = 1/N.
Define grid points as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using second-order finite differences with variable coefficient.
Use face-centered harmonic averaging for the coefficient at cell interfaces.
For interior nodes (i=1..N-1, j=1..N-1), implement the discrete equation: -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Define the harmonic mean for the face coefficient as a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the resulting sparse linear system Au = b for the interior unknown values.
Solve the linear system using the conjugate gradient (CG) method.
Set the solver tolerance to a relative residual of 1e-10.
Use a Jacobi preconditioner for the solver.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including boundary points.
