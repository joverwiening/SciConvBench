Solve the PDE u_t + (-0.7)*u_x + (1.2)*u_y = 0.
Use the spatial domain (x,y) in [0,1) x [0,1) with periodic boundary conditions.
Use the temporal domain t in [0,0.5].
Use the constant parameters a = -0.7 and b = 1.2.
Apply periodic boundary conditions in both the x and y directions.
Set the initial condition u(x,y,0) = exp(-80*((x-0.2)**2 + (y-0.6)**2)).
Use a spatial grid with Nx=256 and Ny=256 points on the half-open periodic domain.
Calculate grid spacing as dx = 1/Nx and dy = 1/Ny.
Use an upwind spatial discretization, choosing the stencil direction by the sign of the coefficients.
For the x-direction, since a < 0, use a right-biased finite difference.
For the y-direction, since b > 0, use a left-biased finite difference.
Use Forward Euler for time integration.
Calculate a preliminary timestep dt0 = 0.9 / (|a|/dx + |b|/dy).
Set the number of timesteps Nt = ceil(0.5 / dt0).
Calculate the final timestep dt = 0.5 / Nt to exactly reach the final time.
Time-integrate the solution from t=0 to t=0.5.
