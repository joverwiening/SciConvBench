Solve the 1D Viscous Burgers equation on the periodic domain x in [0,1) and t in [0, 1.0].
Use the exact initial condition u(x,0) = sin(2*pi*x).
Set the viscosity parameter nu to 1.0.
Use a uniform spatial grid with Nx=512 points, defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
For time integration, use an explicit forward Euler method with Strang splitting per full time step.
For each full time step dt, first perform a diffusion half-step of duration dt/2 exactly in Fourier space.
Calculate the wave numbers k using a standard FFT frequency ordering.
Update the Fourier coefficients by multiplying by exp(-nu * k**2 * (dt/2)).
Transform back to physical space, taking the real part.
Next, perform an advection full-step of duration dt for the inviscid Burgers equation.
Use a finite-volume method with Rusanov (local Lax-Friedrichs) numerical flux.
Compute the flux at each interface using the local maximum wave speed alpha = max(abs(u_left), abs(u_right)).
Update each cell value using the flux difference and the ratio dt/dx.
After the advection step, perform a second diffusion half-step identical to the first.
Determine the time step dt using a CFL condition of 0.4 and an estimated maximum speed of 1.0.
Calculate the initial dt0 as CFL * dx / 1.0.
Set the number of time steps Nt to the ceiling of the total time T divided by dt0.
Recalculate the final dt as T divided by Nt to exactly reach the final time.
Compute the numerical solution u(x, T=1.0) on the defined spatial grid.
