Solve the 1D reaction-diffusion PDE u_t = 0.5 * u_xx + 10.0 * u*(1 - u).
Use the spatial domain x in [0, 1) with periodic boundary conditions.
Use the temporal domain t in [0, 1.0].
Set the initial condition to u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
Define the spatial grid points as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a fixed time step of dt=0.001.
Take Nt=1000 time steps to reach exactly T=1.0.
Use the Strang splitting method for each full time step dt.
For the diffusion half-step (duration dt/2), solve exactly in Fourier space.
Compute the FFT of u to get u_hat(k).
Calculate the wavenumber array k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) <- u_hat(k) * exp(-0.5*k**2*(dt/2)).
Compute the inverse FFT of the updated u_hat to get the real part of u.
For the reaction full-step (duration dt), solve the logistic ODE exactly pointwise.
At each grid point, update u using the formula u <- (u*exp(10.0*dt)) / (1 + u*(exp(10.0*dt) - 1)).
Apply a second diffusion half-step identical to the first.
Compute the final solution u(x, T=1.0) on the periodic grid.
