Solve the 1D reaction-diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically.
Use the domain x in [0, 1) with periodic boundary and t in [0, 1.0].
Set the parameters nu = 5.0 and rho = 2.0.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Employ an explicit forward Euler time integration scheme.
Use a uniform periodic spatial grid with Nx=512 points on [0,1).
Define grid points as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a fixed time step dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
Implement Strang splitting for each full time step dt.
Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
Compute the FFT of u to get u_hat(k).
Calculate k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) by multiplying by exp(-nu*k**2*(dt/2)).
Compute the inverse FFT to get u, taking the real part.
Perform a reaction full-step of duration dt solved exactly pointwise.
Update each grid point value u using the formula u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform a second diffusion half-step identical to the first.
Compute the solution u(x,T=1.0) on the periodic grid.

Include in the .npz file the arrays x and u, and the scalars nu, rho, T, dx, dt, Nx, Nt.
