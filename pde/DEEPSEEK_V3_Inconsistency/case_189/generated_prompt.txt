Solve the 1D reaction-diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the domain x in [0,1) with periodic boundary conditions and t in [0, 1.0].
Use the parameters nu = 5.0 and rho = 10.0.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Employ an explicit forward Euler time integration scheme with Strang splitting.
Use a uniform periodic spatial grid with Nx = 512 points, defined as x_j = j*dx for j=0,...,Nx-1 with dx = 1/Nx.
Use a fixed time step dt = 0.001 for Nt = 1000 steps to reach T=1.0 exactly.
For each full time step dt, perform the following Strang splitting steps in order.
Perform a diffusion half-step of duration dt/2 by solving exactly in Fourier space.
Compute the discrete Fourier transform (FFT) of the current solution u to obtain u_hat(k).
Calculate the wavenumber array k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) <- u_hat(k) * exp(-nu * k**2 * (dt/2)).
Compute the inverse FFT of the updated u_hat to obtain the real-valued solution u.
Perform a reaction full-step of duration dt by solving the logistic ODE exactly pointwise.
For each grid point, update the solution using the exact formula: u <- (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).
Perform a second diffusion half-step identical to the first.
Compute the final solution u(x, T=1.0) on the defined periodic grid.
Save the results to a file named "solution_pdebench_reacdiff_nu5_rho10.npz".
The saved NPZ file must contain the following arrays: x (1D, length Nx), u (1D, length Nx).
The saved NPZ file must also contain the following scalar values: nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) as "solution_pdebench_reacdiff_nu5_rho10.png".
Print the following scalar diagnostics for the final solution: min(u), max(u), mean(u).
Print the discrete L2 norm calculated as sqrt(sum(u**2)*dx).
