Solve the 1D Reaction-Diffusion PDE using the Strang splitting method with the specified parameters.
Use a periodic spatial domain x in [0,1) with Nx=512 grid points.
Define the grid points as x_j = j * dx for j=0,...,Nx-1, where dx = 1/Nx.
Use a time domain t in [0, 1.0] with a fixed time step dt=0.001.
Set the total number of time steps Nt to 1000 to reach T=1.0 exactly.
Set the diffusion coefficient nu to 10.0.
Set the reaction coefficient rho to 5.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition to u(x,0) = 0.25 + 0.1*sin(2*pi*x).
For each full time step dt, perform Strang splitting in the order A, B, C.
For step A (diffusion half-step of duration dt/2), compute the discrete Fourier transform (FFT) of u.
Define the wavenumber array k using 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) = u_hat(k) * exp(-nu * k**2 * (dt/2)).
Obtain the updated u by taking the real part of the inverse FFT.
For step B (reaction full-step of duration dt), update each grid point value exactly using the logistic ODE solution: u = (u * exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
For step C (diffusion half-step), repeat step A exactly.
After completing Nt time steps, compute the final solution u(x, T=1.0).
Save the results to a file named "solution_pdebench_reacdiff_nu10_rho5.npz".
The NPZ file must contain the following arrays and scalars: x (1D, length Nx), u (1D, length Nx), nu, rho, T, dx, dt, Nx, Nt.
Generate a line plot of the final solution u(x, T) and save it as "solution_pdebench_reacdiff_nu10_rho5.png".
