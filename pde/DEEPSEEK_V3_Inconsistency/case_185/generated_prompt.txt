Solve the 1D reaction-diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the domain x in [0,1) with periodic boundary conditions and t in [0, 1.0].
Use parameters nu = 2.0 and rho = 10.0.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points.
Define the spatial grid points as x_j = j * dx for j = 0,..., Nx-1, where dx = 1/Nx.
Use a fixed time step dt = 0.001.
Take Nt = 1000 time steps to reach T = 1.0 exactly.
For each full time step dt, apply Strang splitting in the order: diffusion half-step, reaction full-step, diffusion half-step.
Perform the diffusion half-step of duration dt/2 exactly in Fourier space.
Compute the discrete Fourier transform (FFT) of the current solution u to get u_hat(k).
Compute the wavenumbers k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients as u_hat(k) <- u_hat(k) * exp(-nu * k**2 * (dt/2)).
Compute the inverse FFT (IFFT) of the updated u_hat and take the real part to obtain the updated u.
Perform the reaction full-step of duration dt exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
Update each grid point value u as u <- (u * exp(rho*dt)) / (1 + u * (exp(rho*dt) - 1)).
Apply the diffusion half-step again, identical to the first one.
Compute the final solution u(x, T=1.0) on the spatial grid.
Save the results to a file named "solution_pdebench_reacdiff_nu2_rho10.npz".
The saved .npz file must contain the following arrays and scalars: x (1D, length Nx), u (1D, length Nx), nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) as "solution_pdebench_reacdiff_nu2_rho10.png".
Print the following scalar diagnostics at time T: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx).
