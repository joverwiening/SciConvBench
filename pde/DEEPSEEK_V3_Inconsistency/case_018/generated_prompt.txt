Solve the diffusion equation u_t = ∂/∂x( D(x) * u_x ) with D(x) = 0.01 + 0.09*x^2.
Use the spatial domain x in [0,1] and temporal domain t in [0,0.2].
Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0.
Set the initial condition u(x,0)=x*(1-x).
Discretize the spatial operator using a conservative 2nd-order flux form on a uniform grid with Nx=400 intervals.
Define the diffusion coefficient at grid points as D_i = D(x_i).
Define face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior points i=1..Nx-1, approximate ( (D u_x)_x )_i as (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
Use Implicit Euler time integration with a timestep dt=0.0005.
Advance the solution for 480 steps to reach the final time T=0.2.
Compute the solution u(x, T=0.2) on the spatial grid.
Save the arrays x and u, along with metadata scalars T, dx, and dt, to a file named "solution_agent_diffusion_02.npz".
Generate a line plot of u(x,T) and save it as "solution_agent_diffusion_02.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at the final time T=0.2.
