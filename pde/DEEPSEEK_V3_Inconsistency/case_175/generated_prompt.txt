Solve the 1D reaction-diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the domain x in [0,1) with periodic boundary conditions and t in [0, 1.0].
Use the parameters nu = 0.5 and rho = 5.0.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points, defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a fixed time step dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
Implement the time integration using Strang splitting with explicit forward Euler.
For each full time step dt, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
For the diffusion step, compute the FFT of u to get u_hat(k), define k = 2*pi*fftfreq(Nx, d=dx), update u_hat(k) as u_hat(k) * exp(-nu*k**2*(dt/2)), and set u to the real part of the inverse FFT.
For each full time step dt, perform a reaction full-step of duration dt solved exactly pointwise.
For the reaction step, update each grid point value u using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
For each full time step dt, perform a second diffusion half-step identical to the first.
Compute the final solution u(x, T=1.0) on the periodic grid.
Save the results to a file named "solution_pdebench_reacdiff_nu0p5_rho5.npz".
The saved file must contain the 1D arrays x and u, and the scalar values nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho5.png".
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u**2)*dx) at time T.
