Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the domain x in [0,1) with periodic boundary conditions and t in [0, 1.0].
Use parameters nu = 10.0 and rho = 10.0.
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points, defined as x_j = j*dx for j=0,...,Nx-1 with dx = 1/Nx.
Use a fixed time step dt = 0.001 with Nt = 1000 steps to reach T = 1.0 exactly.
Implement the Strang splitting method with the following steps per full time step dt.
Perform a diffusion half-step of duration dt/2 by solving exactly in Fourier space: compute the FFT of u, multiply each Fourier mode u_hat(k) by exp(-nu * k**2 * (dt/2)), and take the real part of the inverse FFT.
Perform a reaction full-step of duration dt by solving the logistic ODE exactly pointwise: update each grid point value u to (u * exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Perform a second diffusion half-step identical to the first.
Compute the final solution u(x, T=1.0) on the spatial grid.
Save the results to a file named "solution_pdebench_reacdiff_nu10_rho10.npz" containing the arrays 'x' and 'u', and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Generate and save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho10.png".
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u**2)*dx) at time T.
