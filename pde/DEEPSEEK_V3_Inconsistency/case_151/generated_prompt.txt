Solve the 1D Viscous Burgers equation for the unknown field u(x,t) on the domain x in [0,1) and t in [0, 1.0].
Use the equation u_t + ∂_x(0.5*u^2) = nu * u_xx.
Set the viscosity parameter nu to 2.0.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition to u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx = 512 points.
Define the grid points as x_j = j*dx for j=0,...,Nx-1, where dx = 1/Nx.
Use an explicit forward Euler time integration scheme with Strang splitting for each full time step dt.
For the diffusion half-steps (A and C), solve exactly in Fourier space.
Compute the FFT of u to get u_hat(k).
Define the wavenumber k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) <- u_hat(k) * exp(-nu*k**2*(dt/2)).
Take the inverse FFT and use the real part to update u.
For the advection full-step (B), solve the inviscid Burgers equation u_t + ∂_x(0.5*u**2)=0.
Use a finite-volume update with a Rusanov (local Lax-Friedrichs) flux.
Define the flux function f(u) = 0.5*u**2.
For each interface between u_left and u_right, compute alpha = max(abs(u_left), abs(u_right)).
Compute the numerical flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, compute F_plus as the flux between u[j] and u[j+1].
For each cell j, compute F_minus as the flux between u[j-1] and u[j].
Update the cell value: u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
Set the time step dt using a CFL number of 0.4 and an estimated maximum speed of 1.0.
Calculate the initial time step dt0 = CFL * dx / 1.0.
Calculate the number of time steps Nt = ceil(T / dt0).
Recalculate the final time step as dt = T / Nt to hit the final time exactly.
