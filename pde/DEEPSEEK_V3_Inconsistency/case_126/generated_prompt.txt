Solve the 1D inviscid Burgers equation u_t = -k * ∂_x(0.5*u^2) on the domain x in [0,1) with periodic boundary conditions and t in [0, 0.2].
Use the parameter k = 1.0.
Use the initial condition u(x,0) = sin(2*pi*x).
Create a uniform periodic spatial grid with Nx=1024 points.
Define the grid points as x_j = j*dx for j=0,...,Nx-1, where dx = 1/Nx.
Discretize the spatial derivative using a conservative finite-volume method.
Compute the numerical flux using the Rusanov (local Lax–Friedrichs) flux for f(u)=0.5*u^2.
Integrate in time using the SSP-RK2 (Heun) method.
Calculate the initial time step dt0 using a CFL number of 0.2, with dt0 = CFL * dx / max|u|, estimating max|u| ≈ 1.
Calculate the total number of time steps as Nt = ceil(T / dt0), where T=0.2.
Set the final time step size as dt = T / Nt.
Advance the solution from t=0 to t=T=0.2.
Compute the final solution u(x, T=0.2) on the defined spatial grid.
Save the results to a file named "solution_molk_025.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'T', 'dx', 'Nx', and 'k'.
Create a line plot of the final solution u(x,T) and save it as "solution_molk_025.png".
