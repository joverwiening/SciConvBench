Solve the advection equation u_t + (-0.5)*u_x = 0 numerically.
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The constant advection speed is a = -0.5.
The initial condition is u(x,0) = exp(-100*(x-0.3)**2).
Use a uniform periodic grid with Nx = 1000 points.
Define the grid spacing as dx = 1 / Nx.
Use a first-order upwind spatial discretization.
Because a < 0, use a right-biased (downwind) stencil.
For time integration, use the Forward Euler method.
Set dt0 = 0.9 * dx / |a|.
Set Nt = ceil(T / dt0) where T = 1.0.
Set dt = T / Nt to hit the final time exactly.
Implement periodic boundary conditions via wrap-around indexing.
Compute the numerical solution u(x, T) at the final time T = 1.0.
Save the results to a file named "solution_agent_advection_02.npz".
The .npz file must contain the 1D array x, the 1D solution array u, and the scalar metadata T, dx, and dt.
Save a line plot of the final solution as "solution_agent_advection_02.png".
Print the minimum value of u at the final time.
Print the maximum value of u at the final time.
Print the discrete L2 norm, calculated as sqrt(sum(u**2) * dx), at the final time.
