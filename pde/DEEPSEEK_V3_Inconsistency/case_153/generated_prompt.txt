Solve the 1D Viscous Burgers equation numerically on the domain x in [0,1) and t in [0,1.0].
Use the initial condition u(x,0) = sin(2*pi*x).
Use the viscosity parameter nu = 4.0.
Apply periodic boundary conditions u(0,t) = u(1,t).
Use a uniform spatial grid with Nx=512 points, defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a Strang splitting time-stepping method.
For each full time step dt, perform a diffusion half-step for duration dt/2 exactly in Fourier space.
For each full time step dt, perform an advection full-step for duration dt using a finite-volume method with Rusanov flux.
For each full time step dt, perform a second diffusion half-step identical to the first.
Set the initial time step dt0 using a CFL condition of 0.4 and an estimated max speed of 1.0, as dt0 = CFL*dx/1.0.
Calculate the number of time steps Nt as ceil(T/dt0) and adjust the final time step to dt = T/Nt to reach exactly T=1.0.
Compute the solution u(x, T=1.0) on the spatial grid.
Save the results to a file named "solution_pdebench_burgers_nu4.npz" containing the arrays x and u and the scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_burgers_nu4.png".
Print to the console the minimum value of u, the maximum value of u, the discrete mean of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
