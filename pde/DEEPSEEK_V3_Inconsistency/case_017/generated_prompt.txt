Solve the one-dimensional diffusion equation u_t = ∂/∂x( D(x) * u_x ) on the domain x in [0,1] and t in [0,0.5].
Use the variable diffusion coefficient D(x) = 0.1*(1 + x).
Apply Dirichlet boundary conditions: u(0,t)=0 and u(1,t)=0.
Use the initial condition u(x,0)=sin(pi*x).
Discretize the spatial domain with Nx=300 uniform intervals, resulting in 301 grid points including endpoints.
Calculate the spatial step as dx = (1-0)/300.
Use a time step of dt=0.001.
Perform time integration from t=0 to the final time T=0.5, requiring 600 steps.
Use the Implicit Euler method for time integration: (I - dt*L) u^{n+1} = u^n.
Define the discrete diffusion operator L using a conservative 2nd-order flux form.
Define D_i = D(x_i) at each grid point.
Define face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior points i=1..Nx-1, approximate ( (D u_x)_x )_i as (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
Solve the resulting sparse linear system at each time step.
Compute the numerical solution u(x, T=0.5) on the spatial grid.
Save the results to a file named "solution_agent_diffusion_01.npz".
The NPZ file must contain the 1D array x, the 1D array u, and the scalar metadata values T, dx, and dt.
