Solve the advection equation u_t + 1.0*u_x + 0.5*u_y = 0.
Use a periodic spatial domain (x,y) in [0,1) x [0,1) and a time domain t in [0, 1.0].
Use the constant parameters a = 1.0 and b = 0.5.
Apply periodic boundary conditions in both the x and y directions.
Set the initial condition to u(x,y,0) = sin(2*pi*x) * cos(2*pi*y).
The exact solution for verification is u(x,y,t) = sin(2*pi*(x - 1.0*t)) * cos(2*pi*(y - 0.5*t)).
Use a uniform periodic grid with Nx = 256 and Ny = 256 points on the half-open domain [0,1) x [0,1).
Define grid spacing as dx = 1/Nx and dy = 1/Ny.
Spatially discretize the PDE using a first-order upwind scheme in both the x and y directions.
For time integration, use the Forward Euler method.
Calculate the initial time step as dt0 = 0.9 / (|a|/dx + |b|/dy).
Set the number of time steps to Nt = ceil(T / dt0), where the final time T = 1.0.
Recalculate the time step as dt = T / Nt to exactly reach the final time.
Compute the numerical solution u(x,y,T) at the final time T = 1.0.
Save the results to a file named "solution_agent_advection_04.npz".
The .npz file must contain the 1D arrays x and y, the 2D solution array u with shape (len(y), len(x)), and the scalar metadata T, dx, dy, and dt.
Create and save a heatmap or contour plot of the final solution as "solution_agent_advection_04.png".
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at time T.
Compute the exact reference solution on the same spatial grid at time T.
Print the maximum absolute error and the L2 error between the numerical and exact solutions.
