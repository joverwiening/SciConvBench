Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) on the domain x in [0, 1) with periodic boundary conditions and t in [0, 1.0].
Use the parameters nu = 0.5 and rho = 2.0.
Apply the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points, defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a fixed time step dt=0.001 with Nt=1000 steps to reach exactly T=1.0.
Implement the time integration using Strang splitting with explicit forward Euler.
For each full time step dt, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space using the FFT.
For each full time step dt, perform a reaction full-step of duration dt solved exactly pointwise using the logistic ODE update formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
For each full time step dt, perform a second diffusion half-step identical to the first.
Compute the final solution u(x, T=1.0) on the defined spatial grid.
Save the results to an NPZ file named "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing the arrays 'x' and 'u' and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Save a line plot of the final solution u(x,T) as a PNG file named "solution_pdebench_reacdiff_nu0p5_rho2.png".
Print the diagnostics min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at time T.
