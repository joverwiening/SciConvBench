Solve the 1D advection equation u_t + beta * u_x = 0 with beta = 2.0.
Use the domain x in [0, 1) with periodic boundary conditions and t in [0, 2.0].
Use the initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Create a uniform spatial grid with Nx=512 points on [0,1), defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Discretize the spatial derivative u_x using a first-order upwind finite difference scheme, with the upwind direction determined by the sign of beta.
Use explicit forward Euler for time integration.
Set the time step using a CFL number of 0.5, where dt = CFL * dx / abs(beta).
Calculate the number of time steps Nt as ceil(T/dt) and then reset dt = T/Nt to exactly reach the final time T=2.0.
Compute the numerical solution u(x, T=2.0) on the defined periodic grid.
Save the results to a file named "solution_pdebench_advection_beta2.npz".
The saved file must contain the arrays x and u, and the scalar values beta, T, dx, dt, Nx, and Nt.
Generate a line plot of the solution u(x,T) and save it as "solution_pdebench_advection_beta2.png".
Print to the console the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u**2)*dx) at time T.
Compute the reference solution as u0((x - beta*T) mod 1), where u0 is the initial condition.
Calculate and print the maximum absolute error and the L2 error between the numerical and reference solutions on the grid.
