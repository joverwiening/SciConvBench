Solve the Klein-Gordon equation for u(x,y,t) on the domain (x,y) in [0,1] x [0,1], t in [0,0.8].
Use the PDE: u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0.
Set the wave speed parameter c = 1.0.
Set the mass parameter m = 1.0.
Apply Dirichlet boundary conditions (u=0) on all spatial boundaries.
Set the initial condition u(x,y,0) = sin(pi*x)*sin(pi*y).
Set the initial time derivative condition u_t(x,y,0) = 0.
Use a uniform spatial grid with Nx=256 intervals and Ny=256 intervals.
This results in Nx+1 grid points in the x-direction and Ny+1 grid points in the y-direction.
Calculate the spatial step sizes as dx = 1/Nx and dy = 1/Ny.
Define the final time T = 0.8.
Calculate a provisional time step dt0 = 0.9 / (c * sqrt(1/dx^2 + 1/dy^2)).
Set the number of time steps Nt = ceil(T / dt0).
Calculate the actual time step dt = T / Nt.
Use a second-order central finite difference scheme for the time derivative u_tt.
Use a five-point stencil for the spatial Laplacian (u_xx + u_yy).
Initialize the first two time steps using a Taylor expansion that incorporates the Laplacian and the mass term.
Time-integrate the solution from t=0 to t=T.
Compute the numerical solution u(x,y,T) on the final 2D grid.
Compute the exact reference solution: u_exact(x,y,t) = cos(sqrt((1.0)^2*(2*pi^2) + (1.0)^2)*t)*sin(pi*x)*sin(pi*y).
Evaluate the exact solution on the same spatial grid at time T.
Calculate the minimum value of the numerical solution at T.
Calculate the maximum value of the numerical solution at T.
Calculate the discrete L2 norm of the numerical solution: sqrt(sum(u^2)*dx*dy).
Calculate the maximum absolute error between the numerical and exact solutions.
Calculate the discrete L2 error between the numerical and exact solutions.
Print the following diagnostics: min(u), max(u), discrete L2 norm, max absolute error, and L2 error.
Save the results to a file named "solution_agent_kg_05.npz".
The NPZ file must contain the following arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x))).
The NPZ file must also contain the following scalar metadata: T, dx, dy, dt.
