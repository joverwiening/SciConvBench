Solve the Van der Pol oscillator ODE system numerically.
Use the ODE system: dx/dt = y, dy/dt = mu*(1 - x**2)*y - x.
Set the parameter mu to 4.
Set the initial conditions: x(0.0) = 1.0, y(0.0) = 0.0.
Integrate over the time domain t in [0.0, 20.0].
Use the Classical 4th-order Runge–Kutta (RK4) method with a fixed step size.
Set the time step dt to 0.01.
Use Nt = 2000 steps so the final time is hit exactly.
Compute the full state vector at all time points t_n = t0 + n*dt for n=0..Nt.
Set n_state to 2.
Save the results to a file named "solution_molk_007.npz".
The .npz file must contain the following arrays: t (1D, length Nt+1), Y (2D array shape [Nt+1, n_state]).
The columns of Y must be ordered as [x, y].
The .npz file must also contain the parameter scalars.
Save line plots of each state variable versus time to a file named "solution_molk_007.png".
Print the final state values at the final time T.
