Solve the PDE u_t = 2.0 * u_xx + 5.0 * u*(1 - u) on the domain x in [0, 1) with periodic boundary and t in [0, 1.0].
Use the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points, defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a fixed time step dt=0.001 with Nt=1000 steps.
Apply the Strang splitting method for each full time step dt.
Perform a diffusion half-step of duration dt/2 by updating the Fourier transform u_hat(k) as u_hat(k) * exp(-2.0*k**2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
Perform a reaction full-step of duration dt by updating each grid point value u as (u*exp(5.0*dt)) / (1 + u*(exp(5.0*dt) - 1)).
Perform a second diffusion half-step identical to the first.
Compute the solution u(x,T=1.0) on the periodic grid.
Save the arrays x and u, and the scalars nu=2.0, rho=5.0, T=1.0, dx, dt=0.001, Nx=512, Nt=1000 to the file "solution_pdebench_reacdiff_nu2_rho5.npz".
Save a line plot of u(x,T) to the file "solution_pdebench_reacdiff_nu2_rho5.png".
Print the values min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at time T.
