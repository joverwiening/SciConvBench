The PDE to be solved is the 1D Compressible Navier-Stokes system without heat conduction.
The conservative variables are rho, m, and E, where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
The PDE system in conservative form is rho_t + (m)_x = 0.
The PDE system in conservative form is m_t + (m^2/rho + p - sigma)_x = 0.
The PDE system in conservative form is E_t + ((E+p)*v - v*sigma)_x = 0.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.5].
The final simulation time is T = 0.5.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions at x=-1 and x=1 are transmissive (zero-gradient).
The initial condition for density is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial condition for velocity is v(x,0) = 0.1*cos(pi*x).
The initial condition for pressure is p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx=400 cells.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The cell width is dx = 2/Nx.
Evolve the cell-averaged conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p become negative during the simulation, clip them to a floor of 1e-12.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective terms.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ).
The speed of sound is c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x at each cell center using a second-order centered difference stencil, (v_{j+1} - v_{j-1})/(2*dx).
At the boundaries, use ghost cells with values set equal to the nearest interior cell to complete the stencil.
Compute the cell-centered viscous stress sigma_j = (zeta + 4/3*eta) * (v_x)_j.
Approximate the viscous stress sigma at cell interfaces by averaging the sigma values from the two neighboring cell centers.
Approximate the velocity v at cell interfaces by averaging the v values from the two neighboring cell centers.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma], evaluated using interface-averaged v and sigma.
The total numerical flux at each interface is the sum of the Rusanov flux and the viscous flux.
Integrate the semi-discrete system in time using the 2-stage SSP-RK2 (Heun's) method.
The time step dt is determined at each stage by dt = min(dt_conv, dt_visc).
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Use a CFL number of 0.5.
Adjust the final time step to ensure the simulation stops exactly at T = 0.5.
Implement the zero-gradient boundary conditions by setting ghost cell values equal to the nearest interior cell's values.
Compute the solution rho(x,T), v(x,T), and p(x,T) on the cell centers at the final time T.
