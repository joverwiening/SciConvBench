Solve the partial differential equation u_t = 0.5 * u_xx + 1.0 * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The spatial step size is dx = 1/Nx.
The grid points are x_j = j*dx for j=0, ..., Nx-1.
Use a fixed time step of dt = 0.001 for Nt=1000 steps to reach the final time T=1.0.
Use the Strang splitting method for time integration.
Each full time step dt consists of three sequential sub-steps.
The first sub-step is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
The Fourier wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
The update for the Fourier coefficients u_hat(k) is u_hat(k) * exp(-0.5*k^2*(dt/2)).
The second sub-step is a reaction full-step of duration dt.
The reaction step is solved exactly pointwise using the formula u_new = (u_old*exp(1.0*dt)) / (1 + u_old*(exp(1.0*dt) - 1)).
The third sub-step is another diffusion half-step of duration dt/2, identical to the first.
Compute the solution u(x,T) at the final time T=1.0.
Save a file named "solution_pdebench_reacdiff_nu0p5_rho1.npz".
The NPZ file must contain the 1D array 'x' of length Nx.
The NPZ file must contain the final solution 1D array 'u' of length Nx.
The NPZ file must contain the scalar parameters nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u versus x as "solution_pdebench_reacdiff_nu0p5_rho1.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the mean value of the final solution u.
