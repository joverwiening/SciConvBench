Solve the partial differential equation u_t + 1.0*u_x + 0.5*u_y = 0.01*(u_xx + u_yy).
The spatial domain is x in [0, 1) and y in [0, 1).
The time domain is t in [0, 0.5].
The boundary conditions are periodic in both x and y.

Use a uniform grid with Nx = 400 points and Ny = 400 points, with no duplicated endpoints.
The grid spacing is dx = 1.0/Nx and dy = 1.0/Ny.
The final time is T = 0.5.
Use a time step of dt = 0.001 for a total of 500 steps.
Use a first-order IMEX (Implicit-Explicit) time integration scheme.
Treat the advection term (u_x, u_y) explicitly using first-order upwind differences.
Treat the diffusion term (u_xx, u_yy) implicitly using second-order central differences (a 5-point Laplacian).
Solve the resulting sparse linear system at each time step using a direct sparse solver.
Compute the solution u(x,y,T) at the final time T=0.5.
Save the results to a file named "solution_agent_other_06_advection_diffusion.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The solution array u must have a shape of (Ny, Nx) such that u[j,i] corresponds to the solution at (x_i, y_j).
The NPZ file must also contain the scalar metadata T, dx, dy, and dt.
Create a heatmap plot of the final solution u(x,y,T).

Print the discrete L2 norm of the final solution, sqrt(sum(u^2)*dx*dy), to the console.
