The task is to solve a 1D Compressible Navier-Stokes PDE system.
The unknown fields are density rho(x,t), velocity v(x,t), and pressure p(x,t).
The system is evolved using the conservative variables U = [rho, m, E], where m = rho*v is the momentum and E = p/(Gamma-1) + 0.5*rho*v^2 is the total energy.
The first PDE is rho_t + (m)_x = 0.
The second PDE is m_t + (m^2/rho + p - sigma)_x = 0.
The third PDE is E_t + ( (E+p)*v - v*sigma )_x = 0.
The viscous stress is defined as sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is the interval [-1, 1].
The time domain is the interval [0, 0.2].
The final time T is 0.2.
The adiabatic index Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is equal to eta, so zeta is 1e-08.
The boundary conditions at both x=-1 and x=1 are transmissive (zero-gradient).
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0 at t=0, the initial density is 1.0, velocity is -0.75, and pressure is 1.0.
For x >= 0 at t=0, the initial density is 0.125, velocity is 0.0, and pressure is 0.1.
Use a uniform finite-volume grid with Nx=800 cells.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0 to Nx-1, where dx = 2/Nx.
The pressure is recovered from the conservative variables using p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p fall below 1e-12 during the simulation, they should be clipped to 1e-12.
The convective part of the flux is calculated using the Rusanov numerical flux.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho) is the sound speed.
The velocity gradient v_x for the viscous term is computed with a centered difference on cell-centered velocity values.
The viscous stress sigma at cell interfaces is calculated by averaging the sigma values from the two adjacent cells.
The viscous flux vector at an interface is F_visc = [0, -sigma, -v*sigma], using interface-averaged values for v and sigma.
The total numerical flux at an interface is the sum of the Rusanov convective flux and the viscous flux.
Time integration is performed using the 2-stage SSP-RK2 method (Heun's method).
The time step dt is the minimum of a convective and a viscous time step constraint.
The convective time step constraint is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The CFL number to use is 0.9.
The viscous time step constraint is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The last time step should be adjusted to end the simulation exactly at T=0.2.
Outflow boundary conditions are implemented by setting ghost cell values equal to the nearest interior cell.
Compute the solution rho, v, and p on the cell centers at the final time T.

The saved file must contain 1D arrays for x, rho, v, and p.
The saved file must also contain the scalar values for Gamma, eta, zeta, T, dx, and CFL.
