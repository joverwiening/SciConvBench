The PDE to solve is u_t + 1.0 * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The final time T is 1.0.
The advection velocity 'a' is 1.0.
The initial condition is u(x, 0) = sin(2*pi*x).
The exact solution for verification is u(x, t) = sin(2*pi*(x - 1.0*t)).
Use a uniform periodic grid with Nx=800 points for the spatial domain [0, 1).
The grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0 to Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind scheme.
Integrate in time using the Forward Euler method.
The CFL number is 0.9.
Calculate an initial timestep dt0 = 0.9 * dx / |a|.
Calculate the number of time steps Nt = ceil(T / dt0).
Calculate the final timestep dt = T / Nt.
Run the simulation until the final time T.
Compute the numerical solution u(x, T) on the grid.
Save the solution to a file named "solution_agent_advection_01.npz".
The npz file must contain the 1D array 'x' for grid points, the 1D array 'u' for the solution at time T, and the scalars T, dx, and dt.
Save a line plot of the final solution u(x, T) versus x to a file named "solution_agent_advection_01.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
Evaluate the exact solution on the grid at the final time T.
Compute and print the maximum absolute error between the numerical and exact solutions.
