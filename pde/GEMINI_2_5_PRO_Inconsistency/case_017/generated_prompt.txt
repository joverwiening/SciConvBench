The PDE to solve is u_t = ∂/∂x( D(x) * u_x ).
The diffusion coefficient is D(x) = 0.1 * (1 + x).
The spatial domain is x in [0, 1].
The temporal domain is t in [0, 0.5].
The boundary condition at x=0 is a Dirichlet condition with u(0, t) = 0.
The boundary condition at x=1 is a Dirichlet condition with u(1, t) = 0.
The initial condition is u(x, 0) = sin(pi * x).
Use a conservative 2nd-order finite difference spatial discretization on a uniform grid.
The discrete operator for the spatial term at interior point i is (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
The face-centered diffusion coefficient is the arithmetic mean D_{i+1/2} = 0.5 * (D(x_i) + D(x_{i+1})).
The number of spatial intervals is Nx = 300.
The time integration method is Implicit Euler.
The time step is dt = 0.001.
The number of time steps is 500, for a final time T=0.5.
Compute the solution u(x, T) at the final time T=0.5.
Save the results to a file named "solution_agent_diffusion_01.npz".
The NPZ file must contain the 1D array 'x' for grid coordinates, the 1D array 'u' for the solution at T, and the scalars T, dx, and dt.
Save a line plot of the final solution u(x, T) versus x to a file named "solution_agent_diffusion_01.png".
