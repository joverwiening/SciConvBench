The PDE to solve is u_t = ∂/∂x( D(x) * u_x ).
The diffusion coefficient is D(x) = 0.01 + 0.09*x^2.
The spatial domain is x in the closed interval [0,1].
The time domain is t in the closed interval [0,0.2].
The boundary condition at x=0 is u(0,t)=0.
The boundary condition at x=1 is u(1,t)=0.
The initial condition is u(x,0)=x*(1-x).
Use a uniform spatial grid with Nx=400 intervals, resulting in 401 points.
The spatial step size is dx = 1/400.
Discretize the spatial operator (D(x) u_x)_x at an interior grid point i using the 2nd-order conservative formula: (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
The diffusion coefficient at face i+1/2 is defined by arithmetic averaging: D_{i+1/2} = 0.5*(D(x_i) + D(x_{i+1})).
Integrate in time using the Implicit Euler method.
The time step is dt=0.0005.
The simulation will run for 400 steps to reach the final time T=0.2.
At each time step, solve the sparse linear system (I - dt*L) u^{n+1} = u^n, where L is the matrix representing the discrete spatial operator.
Compute the solution u(x) at the final time T=0.2.
Save the solution to a file named "solution_agent_diffusion_02.npz".
The npz file must contain the 1D array of grid point coordinates 'x', the 1D array of the final solution 'u', and the scalars 'T', 'dx', and 'dt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_agent_diffusion_02.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
