Solve the PDE -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The spatial domain is (x,y) in (0,1) x (0,1).
The parameter beta is 0.1.
The coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Use Dirichlet boundary conditions on the entire boundary, with u = 0.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 grid points.
The grid spacing is dx = dy = 1/N.
The grid coordinates are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a 2nd-order finite difference method with variable coefficients.
For interior nodes (i=1..N-1, j=1..N-1), the discrete equation is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Calculate face coefficients using harmonic averaging, for example a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknown values of u.
Solve the linear system using the conjugate gradient (CG) method.
The stopping criterion for the CG solver is a relative residual norm of 1e-10.
A Jacobi preconditioner may be used with the CG solver.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including the boundaries.
Save a file named "solution_pdebench_darcy_beta0p1.npz".
The NPZ file must contain the 1D arrays 'x' and 'y', the 2D solution array 'u' with shape [N+1, N+1], and the scalars 'beta', 'N', and 'dx'.
Save a heatmap or contour plot of the solution u(x,y) to a file named "solution_pdebench_darcy_beta0p1.png".
Print the minimum value of the solution u.
Print the maximum value of the solution u.
Print the final relative residual norm ||Au-b||_2 / ||b||_2 of the interior linear system.
