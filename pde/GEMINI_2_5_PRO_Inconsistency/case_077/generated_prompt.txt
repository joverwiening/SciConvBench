The spatial domain is the unit square [0,1] x [0,1].
The grid will have Nx = 120 intervals in the x-direction and Ny = 120 intervals in the y-direction.
This corresponds to 121 grid points in each direction, including the boundaries.
The grid spacing is dx = 1/120 and dy = 1/120.
The grid points are defined by x_i = i*dx for i=0..120 and y_j = j*dy for j=0..120.
The PDE is discretized using the standard second-order 5-point finite difference stencil for the Laplacian.
Dirichlet boundary conditions are applied on all four boundaries.
The value of u on the boundary is set to match the function u(x,y) = exp(x)*sin(pi*y).
The resulting sparse linear system for the interior grid points is solved using a sparse direct solver.
The exact solution for verification is u(x,y) = exp(x)*sin(pi*y).
