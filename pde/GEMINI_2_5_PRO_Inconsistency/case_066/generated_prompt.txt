Solve the Helmholtz equation u_xx + u_yy + k^2*u = f(x,y) numerically.
The equation is defined on the domain (x,y) in [0,1] x [0,1].
The parameter k is 5.0.
The source function is f(x,y) = (k^2 - 2*(pi^2)) * sin(pi*x) * sin(pi*y).
Use Dirichlet boundary conditions with u=0 on all four boundaries of the domain.
Discretize the equation on a uniform grid with Nx=120 intervals in the x-direction and Ny=120 intervals in the y-direction.
This results in a grid of 121x121 points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Use the second-order central difference 5-point stencil for the Laplacian operator.
Assemble the resulting sparse linear system for the unknown values of u at the interior grid points.
Solve the sparse linear system using a sparse direct solver.
The computed solution u is a 2D array of shape (Ny+1, Nx+1).
Save the solution to a file named "solution_agent_other_01_helmholtz.npz".
The npz file must contain the 1D x-coordinate array, the 1D y-coordinate array, the 2D solution array u, the scalar dx, and the scalar dy.
The solution array u should have shape (len(y), len(x)) such that u[j,i] corresponds to u(x_i, y_j).
Create and save a heatmap or contour plot of the solution u(x,y) as "solution_agent_other_01_helmholtz.png".
Print the minimum value of the computed solution u.
Print the maximum value of the computed solution u.
Print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy) over all grid points.
The exact solution for verification is u_exact(x,y) = sin(pi*x) * sin(pi*y).
Evaluate the exact solution on the same grid.
Compute and print the maximum absolute error between the numerical and exact solutions over all grid points.
Compute and print the L2 error norm between the numerical and exact solutions, calculated as sqrt(sum((u - u_exact)^2)*dx*dy) over all grid points.
