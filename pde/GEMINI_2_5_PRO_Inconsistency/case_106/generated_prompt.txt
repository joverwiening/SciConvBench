The task is to solve a system of ordinary differential equations.
The system of equations is the SIR model for epidemiology.
The equations are dS/dt = -beta * S * I, dI/dt = beta * S * I - gamma * I, and dR/dt = gamma * I.
The independent variable is time, t.
The dependent variables are S(t), I(t), and R(t).
The simulation time domain is from t=0.0 to t=40.0.
The parameter beta is 0.5.
The parameter gamma is 0.1.
The initial condition for S at t=0.0 is 0.99.
The initial condition for I at t=0.0 is 0.01.
The initial condition for R at t=0.0 is 0.0.
The numerical integration method is the classical 4th-order Runge-Kutta (RK4).
The time step, dt, is fixed at 0.01.
The total number of time steps, Nt, is 4000.
The full state vector [S, I, R] must be computed at every time step from t=0 to t=40.0.
A file named "solution_molk_005.npz" must be saved.
The NPZ file must contain a 1D array 't' of time points of length 4001.
The NPZ file must contain a 2D array 'Y' of shape [4001, 3] with the columns ordered as S, I, R.
The NPZ file must contain the scalar values for the parameters beta and gamma.
A plot showing S(t), I(t), and R(t) versus time must be saved as "solution_molk_005.png".
The final values of S, I, and R at t=40.0 must be printed to the console.
The minimum and maximum values of S(t), I(t), and R(t) over the entire simulation must be printed to the console.
