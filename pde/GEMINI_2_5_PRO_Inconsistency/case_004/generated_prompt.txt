The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundaries in both x and y.

The y grid points are y_j = j*dy for j = 0 to Ny-1.
Discretize the spatial derivatives using first-order upwind differencing.
Integrate in time using the Forward Euler method.

Calculate a preliminary time step dt0 = 0.9 / (|a|/dx + |b|/dy).
Calculate the number of time steps Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
