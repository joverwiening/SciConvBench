The partial differential equation to solve is u_t + a(x)*u_x = 0.
The advection velocity is a(x) = 1 + 0.5*sin(2*pi*x).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The final time T is 0.5.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=1200 points.
The grid spacing is dx = 1/Nx.
The grid points are x_i = i*dx for i = 0 to Nx-1.
Discretize the spatial derivative u_x using a first-order upwind scheme with a left-biased stencil.
Integrate in time using the Forward Euler method.
The maximum advection velocity is amax = 1.5.
The preliminary timestep is dt0 = 0.9 * dx / amax.
The number of time steps is Nt = ceil(T/dt0).
The final timestep is dt = T/Nt.
Compute the numerical solution u(x,T) at the final time T=0.5.
Save the solution to a file named "solution_agent_advection_03.npz".
