The partial differential equation to solve is u_t + (-0.5)*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The final time for the simulation is T = 1.0.
The initial condition at t=0 is u(x,0) = exp(-100*(x-0.3)^2).
The spatial grid is a uniform periodic grid with Nx=1000 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
The advection velocity is a = -0.5.
An initial time step is calculated as dt0 = 0.9 * dx / |a|.
The number of time steps is Nt = ceil(T / dt0).
The final time step is dt = T / Nt.
Use the Forward Euler method for time integration.
Use a first-order upwind scheme for spatial discretization of the u_x term.
The upwind stencil for the negative velocity a=-0.5 is a right-biased difference: (u_{i+1} - u_i) / dx.
Use periodic wrap-around indexing to handle boundary conditions.
