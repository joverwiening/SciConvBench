Solve the partial differential equation u_tt = (0.5)^2 * u_xx.
The spatial domain is x in [0, 1].
The temporal domain is t in [0, 1.0].
The wave speed is c = 0.5.
The boundary condition at x=0 is u(0,t) = 0.
The boundary condition at x=1 is u(1,t) = 0.
The initial condition for the field is u(x,0) = sin(2*pi*x).
The initial condition for the time derivative of the field is u_t(x,0) = 0.
Discretize the spatial domain [0,1] into Nx=400 uniform intervals, resulting in 401 grid points.
The spatial step size is dx = 1/Nx.
Use second-order central differences for the spatial derivative u_xx.
Use the second-order central difference in time (leapfrog method) for the temporal derivative u_tt.
Calculate an initial time step dt0 = 0.9 * dx / c.
Set the number of time steps Nt = ceil(T/dt0) where the final time T is 1.0.
Set the final time step dt = T/Nt.
Initialize the solution at the first time step t=dt using the Taylor series expansion: u(x,dt) = u(x,0) + dt*u_t(x,0) + 0.5*dt^2*c^2*u_xx(x,0).
At every time step, enforce the Dirichlet boundary conditions by setting the values at the boundary grid points.
Compute the numerical solution u(x,t) up to the final time T=1.0.
The exact solution for verification is u(x,t) = cos(0.5*2*pi*t)*sin(2*pi*x).
Save the final solution at T=1.0 to a file named "solution_agent_wave_02.npz".
The npz file must contain a 1D array 'x' for the grid coordinates, a 1D array 'u' for the solution at T=1.0, and scalar metadata T, dx, and dt.
