The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The final time T is 1.0.
The viscosity parameter nu is 0.04.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method is Strang splitting for each time step dt.
The first step of the splitting is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
For the diffusion step, the Fourier transform of u is multiplied by exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The second step of the splitting is an advection full-step of duration dt for the inviscid Burgers equation.
The advection step uses a finite-volume update with the Rusanov flux.
The flux function is f(u) = 0.5*u^2.
The Rusanov flux between u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed for the Rusanov flux is alpha = max(abs(u_left), abs(u_right)).
The finite volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell.
The third step of the splitting is another diffusion half-step of duration dt/2, identical to the first step.
The time step dt is determined by setting a target CFL number of 0.4 based on an estimated maximum speed of 1.0.
First, calculate a preliminary time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T/dt0).
Finally, set the actual time step dt = T/Nt to ensure the final time is reached exactly.
