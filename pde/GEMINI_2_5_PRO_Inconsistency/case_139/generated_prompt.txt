The partial differential equation to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 2.0].
The parameter beta is 1.0.
The boundary condition is periodic.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The simulation will be run on a uniform periodic grid with Nx=512 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The spatial derivative u_x is discretized using a 1st-order upwind finite difference scheme based on the sign of beta.
The time integration is performed using the explicit forward Euler method.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The initial time step dt is calculated as CFL * dx / abs(beta).
The number of time steps Nt is calculated as ceil(T/dt), where T is the final time 2.0.
The time step dt is then adjusted to T/Nt to ensure the final time is reached exactly.
The final solution u(x,T) at T=2.0 is computed.
The solution is saved to a file named "solution_pdebench_advection_beta1.npz".
The npz file contains the 1D arrays 'x' and 'u', and the scalars 'beta', 'T', 'dx', 'dt', 'Nx', 'Nt'.
A line plot of the final solution u(x,T) is saved as "solution_pdebench_advection_beta1.png".
The minimum and maximum values of the final solution u are printed to the console.
The discrete L2 norm of the final solution, sqrt(sum(u^2)*dx), is printed to the console.
The reference solution is u_ref(x,t) = u( (x - beta*t) mod 1, 0).
The maximum absolute error between the numerical and reference solutions at T=2.0 is computed and printed.
The L2 error between the numerical and reference solutions at T=2.0 is computed and printed.
