The PDE to be solved is u_t = -q1*∂_x( cos(u) ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 0.5].
The final time T is 0.5.
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=1024 points.
The grid points are x_j = j*dx for j=0, ..., Nx-1.
The spatial step size is dx = 1/Nx.
The time integration scheme is second-order Strong Stability Preserving Runge-Kutta (SSP-RK2).
The convection term ∂_x(cos(u)) is discretized using a conservative finite-volume method with Rusanov flux.
The wave speed alpha for the Rusanov flux is calculated at each stage as the maximum value of |sin(u)| over the entire spatial grid.
The diffusion term u_xx is discretized using a second-order central difference scheme.
The time step dt is determined by first calculating dt_adv = 0.2 * dx / 1.0 and dt_diff = 0.2 * dx^2 / (q2/pi).
A nominal time step is set to dt_nominal = min(dt_adv, dt_diff).
The number of time steps is Nt = ceil(T / dt_nominal).
The final time step used for integration is dt = T / Nt.
Compute the solution u(x,t) at the final time T=0.5.
Save a file named "solution_molk_031.npz".
The saved file must contain the 1D arrays 'x' and 'u', and the scalar values 'T', 'dx', 'Nx', 'q1', and 'q2'.
Save a line plot of the final solution u versus x as "solution_molk_031.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u to standard output.
The discrete L2 norm is defined as sqrt(sum(u^2)*dx).
