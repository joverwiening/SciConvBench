Task ID is pdebench_cns1d_eta0p1_periodic_smooth.
The PDE category is 1D Compressible Navier–Stokes without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
Solve the PDE numerically.
The conservative variables are rho, m = rho*v, and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE in conservative form is rho_t + (m)_x = 0.
The PDE in conservative form is m_t + (m^2/rho + p - sigma)_x = 0.
The PDE in conservative form is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.5].

The dynamic viscosity eta is 0.1.
The bulk viscosity zeta is equal to eta, so zeta is 0.1.
The boundary conditions are periodic on the spatial domain boundaries.
The initial condition for density is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial condition for velocity is v(x,0) = 0.1*cos(pi*x).
The initial condition for pressure is p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx=400 cells.
The domain width is 2, so the cell width is dx = 2/Nx.

Evolve the cell averages of the conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below this value.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective terms.

The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ).
The speed of sound is c = sqrt(Gamma*p/rho).
The Rusanov numerical flux at an interface is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x at cell centers using a second-order centered difference.
For periodic boundaries, the centered difference should wrap around the domain.
Compute the viscous stress sigma = (zeta + 4/3*eta)*v_x at cell centers.
Compute the viscous stress at cell interfaces by averaging the values from the two adjacent cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The velocity v in the viscous flux term is computed at the cell interface by averaging the values from the two adjacent cells.
The total numerical flux at an interface is the sum of the Rusanov flux and the viscous flux.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The time step dt is calculated at each step as the minimum of a convective and a viscous time step.
The convective time step is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step is dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
