The PDE to solve is u_xx + u_yy = 0.
The domain is the unit square, (x,y) in [0,1] x [0,1].
Dirichlet boundary conditions are applied on all four edges of the square.
The value of u on the boundary is set to match the function u(x,y) = x*y.
The exact solution for verification is u(x,y) = x*y.
The spatial discretization uses the standard 5-point stencil for the Laplacian on a uniform grid.
The resulting sparse linear system for interior nodes is solved using a sparse direct solver.
The grid has Nx=100 intervals in the x-direction and Ny=100 intervals in the y-direction, creating 101x101 grid points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are defined by x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
The steady-state solution u(x,y) is computed on this 2D grid.
A file named "solution_agent_laplace_05.npz" is saved.
The NPZ file contains the 1D x-coordinate array, the 1D y-coordinate array, the 2D solution array u, and the scalar metadata values for dx and dy.
The shape of the u array is (101, 101) such that u[j,i] corresponds to u(x_i, y_j).
A heatmap or contour plot of the solution u(x,y) is saved as "solution_agent_laplace_05.png".
The minimum and maximum values of the computed solution u are printed to the console.
The discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy) over all grid points, is printed to the console.
The maximum absolute error between the numerical solution and the exact solution on the grid is computed and printed.
The L2 error between the numerical solution and the exact solution on the grid is computed and printed.
