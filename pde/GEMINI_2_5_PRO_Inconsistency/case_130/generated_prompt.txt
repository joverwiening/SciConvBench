The PDE is u_t = -1.0*∂_x(sin(u)) + (0.05/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 0.5].
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The simulation will be run on a uniform periodic grid with Nx=1024 points.
The grid spacing is dx = 1/Nx.
The grid points are x_j = j*dx for j=0, ..., Nx-1.
The semi-discretized equation is treated as a system of ordinary differential equations using the method of lines.
The convection term ∂_x(sin(u)) is discretized using a conservative finite-volume formulation on the point-value grid.
The numerical flux for the convection term is the Rusanov flux, F(u_L, u_R) = 0.5*(sin(u_L) + sin(u_R)) - 0.5*alpha*(u_R - u_L).
The wave speed alpha for the Rusanov flux is computed as the maximum of |cos(u)| over the entire grid.
The diffusion term u_xx is discretized using the standard 2nd-order central difference formula.
The time integration scheme is the second-order Strong Stability Preserving Runge-Kutta method (SSP-RK2).
The wave speed alpha is re-computed at each stage of the SSP-RK2 integrator.
The time step dt is determined by taking the minimum of an advective and a diffusive time step constraint.
The advective time step constraint is dt_adv = 0.2 * dx / 1.0.
The diffusive time step constraint is dt_diff = 0.2 * dx^2 / (0.05/pi).
The provisional time step is dt_prov = min(dt_adv, dt_diff).
The number of time steps is Nt = ceil(0.5/dt_prov).
The final time step used is dt = 0.5/Nt.
The final solution u(x, T=0.5) will be computed.
A file named "solution_molk_029.npz" will be saved.
The NPZ file will contain the 1D arrays for x and the final solution u.
The NPZ file will also contain the scalars T=0.5, dx, Nx=1024, q1=1.0, and q2=0.05.
A line plot of the final solution u(x,T) versus x will be saved as "solution_molk_029.png".
The minimum, maximum, mean, and discrete L2 norm of the final solution u will be printed to the console.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
