The user wants to solve a system of three ordinary differential equations.
The ODE system is defined as:
dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t)
dI/dt = delta*E - epsilon*I
dH/dt = theta*I - phi*H
The time domain for the simulation is from t=0.0 to t=50.0.
The parameters for the ODE system are:
alpha = 1.2
beta = 1.0
gamma = 0.5
delta = 0.8
epsilon = 0.7
theta = 0.9
phi = 0.4
The initial conditions at t=0.0 are:
E(0.0) = 0.5
I(0.0) = 0.2
H(0.0) = 0.1
The numerical integration will be performed using the classical 4th-order Runge-Kutta (RK4) method.
A fixed time step of dt=0.01 will be used for a total of Nt=5000 steps.
The full state vector [E, I, H] must be computed at all time points from t=0.0 to t=50.0.
The results will be saved in a file named "solution_molk_006.npz".
This file will contain a 1D array 't' of time points of length 5001.
This file will contain a 2D array 'Y' of shape [5001, 3] with the state variables ordered as [E, I, H].
This file will also contain the scalar values of all the parameters.
A plot showing the time evolution of each state variable (E, I, H) versus time will be saved as "solution_molk_006.png".
The final state values E(50.0), I(50.0), and H(50.0) will be printed to the console.
The minimum and maximum values of each state variable over the entire time domain will be printed to the console.
