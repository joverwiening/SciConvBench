The PDE to solve is u_xx + u_yy = 0.
The domain is the square (x,y) in [0,1] x [0,1].
Use a uniform grid with Nx=100 intervals in the x-direction and Ny=100 intervals in the y-direction, resulting in 101x101 grid points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are defined by x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Apply Dirichlet boundary conditions on all four edges of the domain.
The value of u on the boundary is set by the function u(x,y) = x^2 - y^2.
Discretize the PDE using a standard second-order 5-point finite difference stencil for the Laplacian.
Solve the resulting sparse linear system for the interior grid points using a sparse direct solver.
Compute the steady-state solution u(x,y) on the 101x101 grid.
Save the results to a file named "solution_agent_laplace_06.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, the 2D solution array u with shape (101, 101) such that u[j,i] corresponds to u(x_i, y_j), and the scalar grid spacings dx and dy.
Create a heatmap or contour plot of the solution and save it as "solution_agent_laplace_06.png".
Print the minimum and maximum values of the computed solution u.
Print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy) over all grid points.
The exact solution for verification is u_exact(x,y) = x^2 - y^2.
Compute and print the maximum absolute error between the numerical solution and the exact solution on the grid.
