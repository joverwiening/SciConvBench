Solve the partial differential equation u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 2.0].
The advection coefficient is beta = 7.0.
The boundary condition is periodic, u(0,t) = u(1,t).
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use a uniform periodic grid with Nx=512 points, where x_j = j/512 for j=0,...,511.
The spatial step size is dx = 1/512.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
Since beta is positive, the upwind approximation for the derivative at grid point j is (u_j - u_{j-1})/dx.
Integrate in time using the explicit forward Euler method.
The initial time step dt is calculated using a CFL number of 0.5, such that dt = 0.5 * dx / abs(beta).
The final time T is 2.0.
The number of time steps Nt is calculated as ceil(T/dt).
The time step dt is then recalculated as T/Nt to ensure the final time is reached exactly.
Compute the numerical solution u(x,T) at the final time T=2.0.
The reference solution for verification is u_ref(x,t) = u( (x - beta*t) mod 1, 0).
