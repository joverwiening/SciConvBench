The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 4.0.
The boundary condition is periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The final time T is 1.0.
The time step dt is determined by a CFL number of 0.4 and an estimated maximum speed of 1.0.
First, calculate an initial time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T/dt0).
Finally, set the actual time step to dt = T/Nt.
Use Strang splitting for the time integration over each time step dt.
The first sub-step is to solve the diffusion equation u_t = nu * u_xx for a duration of dt/2 using a Fourier spectral method.
The Fourier diffusion step involves an FFT, multiplication by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), and an IFFT back to real space.
The second sub-step is to solve the advection equation u_t + ∂_x(0.5*u^2) = 0 for a duration of dt using a finite-volume method with a Rusanov flux.
The Rusanov flux between cells with values u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u)=0.5*u^2 and alpha = max(abs(u_left), abs(u_right)).
The finite volume update for each cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces.
The third sub-step is to solve the diffusion equation for another duration of dt/2 using the same Fourier spectral method as the first sub-step.
