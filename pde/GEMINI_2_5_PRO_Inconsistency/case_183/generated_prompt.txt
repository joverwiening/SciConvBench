The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 1.0.
The parameter rho is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The spatial step size is dx = 1/Nx.
The grid points are x_j = j*dx for j=0,...,Nx-1.
The time step is dt = 0.001.
The number of time steps is Nt = 1000.
The final time T is 1.0.
The numerical method is Strang splitting for each time step dt.
A full time step consists of a diffusion half-step of duration dt/2, a reaction full-step of duration dt, and a second diffusion half-step of duration dt/2.
The diffusion half-step is solved exactly in Fourier space.
First, compute the Fourier transform of u, denoted u_hat.
The angular wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute the inverse Fourier transform of the updated u_hat and take its real part to get the updated u.
The reaction full-step is solved exactly for the logistic ODE du/dt = rho*u*(1-u).
Update each grid point value using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute the solution u(x,T) at the final time T=1.0.
