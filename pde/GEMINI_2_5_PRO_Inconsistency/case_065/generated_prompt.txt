The partial differential equation to solve is u_xx + u_yy = 0.
The unknown field is u(x,y).
The domain is the unit square defined by (x,y) in [0,1] x [0,1].
The boundary conditions are of the Dirichlet type on all four edges.
The boundary condition on the bottom edge is u(x,0) = 0.
The boundary condition on the top edge is u(x,1) = 1.
The boundary condition on the left edge is u(0,y) = 0.
The boundary condition on the right edge is u(1,y) = 0.
The spatial domain is to be discretized using a uniform grid.
The number of intervals in the x-direction, Nx, is 100.
The number of intervals in the y-direction, Ny, is 100.
This results in a grid of 101x101 points.
The grid spacing in x is dx = 1/Nx.
The grid spacing in y is dy = 1/Ny.
The grid points are defined by x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
The Laplacian operator is to be discretized using the standard second-order accurate 5-point stencil.
The resulting sparse linear system for the interior grid points must be solved using a sparse direct solver.
The steady-state solution u(x,y) on the 2D grid must be computed.
A file named "solution_agent_laplace_09.npz" must be saved.
The NPZ file must contain a 1D array 'x' for the x-coordinates.
The NPZ file must contain a 1D array 'y' for the y-coordinates.
The NPZ file must contain a 2D array 'u' for the solution, with shape (Ny+1, Nx+1), where u[j,i] corresponds to u(x_i, y_j).
The NPZ file must contain the scalar metadata dx and dy.
A heatmap or contour plot of the solution u(x,y) must be saved as "solution_agent_laplace_09.png".
The minimum value of the computed solution u must be printed to the console.
The maximum value of the computed solution u must be printed to the console.
The discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy), must be printed to the console.
