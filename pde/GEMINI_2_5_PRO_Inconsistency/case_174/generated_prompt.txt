Task ID is pdebench_reacdiff_nu0p5_rho2.
The PDE category is 1D Reaction-Diffusion with a logistic reaction term and periodic boundary conditions.
The unknown field to solve for is u(x,t).
The governing PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The diffusion coefficient nu is 0.5.
The reaction coefficient rho is 2.0.
The boundary conditions are periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial domain is discretized using a uniform periodic grid with Nx=512 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time domain is discretized using a fixed time step dt=0.001.
The simulation will run for Nt=1000 steps to reach the final time T=1.0.
The numerical method is Strang splitting for each time step dt.
A single time step consists of three sequential operations.
First, solve the diffusion equation for a half-step of duration dt/2.
The first diffusion half-step is solved exactly in Fourier space.
The Fourier space update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
Second, solve the reaction equation for a full-step of duration dt.
The reaction step is solved exactly for the logistic ODE at each grid point.
The update for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation for another half-step of duration dt/2, identical to the first.
The final solution u(x,T=1.0) on the spatial grid must be computed.
Save the results to a file named "solution_pdebench_reacdiff_nu0p5_rho2.npz".
The NPZ file must contain the 1D array 'x' of length Nx.
The NPZ file must contain the final 1D solution array 'u' of length Nx.
The NPZ file must contain the scalar values nu, rho, T, dx, dt, Nx, and Nt.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_reacdiff_nu0p5_rho2.png".
Print the minimum value of the final solution u.

Print the mean value of the final solution u.
