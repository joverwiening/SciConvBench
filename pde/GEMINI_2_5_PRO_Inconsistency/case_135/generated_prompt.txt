Solve the partial differential equation u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 2.0].
The advection coefficient beta is 0.1.
The boundary condition is periodic, u(0,t) = u(1,t).
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for verification is u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition.
Use a uniform periodic grid for the spatial domain with Nx=512 points.
The grid points are x_j = j/Nx for j=0,...,Nx-1.
The spatial step size is dx = 1/Nx.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
The upwind direction is determined by the sign of beta.
Integrate in time using the explicit forward Euler method.
Set the Courant-Friedrichs-Lewy number CFL to 0.5.
Calculate an initial time step dt = CFL * dx / abs(beta).
Calculate the number of time steps Nt = ceil(T/dt), where the final time T is 2.0.
Recalculate the time step as dt = T/Nt to ensure the final time is reached exactly.
Compute the numerical solution u(x,T) at the final time T=2.0.
Save the results to a file named "solution_pdebench_advection_beta0p1.npz".
The NPZ file must contain the 1D array x of grid points, the 1D array u of the final solution, and the scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_advection_beta0p1.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
Evaluate the reference solution on the spatial grid x at the final time T.
Compute and print the maximum absolute error between the numerical and reference solutions.
Compute and print the L2 error between the numerical and reference solutions.
