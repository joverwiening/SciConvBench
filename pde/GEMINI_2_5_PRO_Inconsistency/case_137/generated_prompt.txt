The PDE to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 2.0].
The final time T is 2.0.
The parameter beta is 0.4.
The boundary condition is periodic.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution is u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition.
Use a uniform spatial grid with Nx=512 points, where x_j = j/Nx for j=0,...,Nx-1.
The spatial step dx is 1/Nx.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference.
Integrate in time using the explicit forward Euler method.
Set the Courant-Friedrichs-Lewy number CFL to 0.5.
Calculate an initial time step dt = CFL * dx / abs(beta).
Calculate the number of time steps Nt = ceil(T/dt).
Update the time step to dt = T/Nt to ensure the final time is reached exactly.
