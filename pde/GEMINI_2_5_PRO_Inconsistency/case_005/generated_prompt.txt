The PDE to solve is u_t + (-0.7)*u_x + (1.2)*u_y = 0.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundaries.
The simulation will run from t=0 to a final time T=0.5.
The advection velocity component 'a' is -0.7.
The advection velocity component 'b' is 1.2.
Boundary conditions are periodic in both the x and y directions.
The initial condition is u(x,y,0) = exp(-80*((x-0.2)^2 + (y-0.6)^2)).
Use a uniform grid with Nx = 256 points and Ny = 256 points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The x grid points are x_i = i*dx for i=0..Nx-1.
The y grid points are y_j = j*dy for j=0..Ny-1.
Discretize the spatial derivatives using a first-order upwind scheme.
For the x-derivative, use a forward difference since a < 0.
For the y-derivative, use a backward difference since b > 0.
Integrate in time using the Forward Euler method.
Calculate the time step dt by first setting dt0 = 0.9 / (|a|/dx + |b|/dy).
The number of time steps Nt is ceil(T/dt0).
The final time step is dt = T/Nt.
Compute the solution u(x,y,t) at the final time T=0.5.
Save the results to a file named "solution_agent_advection_05.npz".
The NPZ file will contain the 1D array 'x', the 1D array 'y', and the 2D solution array 'u' of shape (Ny, Nx).
The NPZ file will also contain the scalar metadata T, dx, dy, and dt.
Save a heatmap or contour plot of the final solution u(x,y,T) as "solution_agent_advection_05.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx*dy).
