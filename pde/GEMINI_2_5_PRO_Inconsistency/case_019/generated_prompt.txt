The PDE to solve is u_t = 0.1 * u_xx + 0.01 * u_yy.
The spatial domain is the unit square for (x,y) in [0,1] x [0,1].
The time domain is t in [0, 0.2].
The diffusion coefficient in the x-direction is Dx = 0.1.
The diffusion coefficient in the y-direction is Dy = 0.01.
The initial condition is u(x,y,0) = sin(pi*x) * sin(pi*y).
Dirichlet boundary conditions are applied on all four boundary edges, with the value u=0.
The numerical grid is a uniform Cartesian grid with Nx = 60 intervals in the x-direction and Ny = 60 intervals in the y-direction, resulting in 61x61 grid points.
The spatial discretization uses a standard 5-point finite difference stencil for the Laplacian.
The time integration method is Implicit Euler.
The time step is dt = 0.001.
The simulation runs for 200 time steps to reach the final time T = 0.2.
The final numerical solution u(x,y,T) is computed at T = 0.2.
A file named "solution_agent_diffusion_03.npz" is saved.
The NPZ file contains the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u at the final time.
The u array has a shape of (61, 61) corresponding to (y, x) indexing.
The NPZ file also contains the scalar metadata T, dx, dy, and dt.
A heatmap or contour plot of the final solution u(x,y,T) is saved as "solution_agent_diffusion_03.png".
The minimum and maximum values of the final solution u are printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx*dy), is printed to the console.
The exact solution for verification is u_exact(x,y,t) = exp(-(0.1 + 0.01) * pi^2 * t) * sin(pi*x) * sin(pi*y).
The maximum absolute error between the numerical and exact solutions on the grid at T=0.2 is computed and printed.
The L2 norm of the error between the numerical and exact solutions at T=0.2 is computed and printed.
