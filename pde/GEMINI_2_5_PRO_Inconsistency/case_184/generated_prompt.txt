The governing PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 1.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid spacing is dx = 1/Nx.
The grid points are x_j = j*dx for j=0, ..., Nx-1.
The time step is dt = 0.001.
The number of time steps is Nt = 1000, for a final time T=1.0.
The numerical method is Strang splitting for each time step dt.
A single time step consists of three sequential operations.
First, solve the diffusion equation u_t = nu * u_xx for a duration of dt/2 using a Fourier spectral method.
The diffusion step in Fourier space is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers k are defined as 2*pi*fftfreq(Nx, d=dx).
Second, solve the reaction equation du/dt = rho*u*(1-u) for a duration of dt.
The exact update for the reaction step at each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation u_t = nu * u_xx for another duration of dt/2 using the same Fourier spectral method.
Compute the final solution u(x,T) at T=1.0.
Save the solution to a file named "solution_pdebench_reacdiff_nu2_rho1.npz".
The npz file must contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu2_rho1.png".
Print the minimum, maximum, and mean of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
