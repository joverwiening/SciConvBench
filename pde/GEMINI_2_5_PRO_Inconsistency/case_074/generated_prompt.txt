The PDE to solve is u_xx + u_yy = -2*pi^2*sin(pi*x)*sin(pi*y).
The spatial domain is (x,y) in [0,1] x [0,1].
Use Dirichlet boundary conditions with u=0 on all four edges of the domain.
Discretize the domain using a uniform grid with Nx=120 intervals in the x-direction and Ny=120 intervals in the y-direction.
This results in an (Nx+1) by (Ny+1) grid of points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid coordinates are x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Discretize the PDE using a standard second-order 5-point finite difference stencil for the Laplacian on the interior grid points.
Solve the resulting sparse linear system for the interior node values using a sparse direct solver.
The final computed solution u(x,y) should be defined on the full (Nx+1) by (Ny+1) grid.
Save a file named "solution_agent_poisson_01.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, the 2D solution array u with shape (Ny+1, Nx+1), and the scalar grid spacings dx and dy.
Save a heatmap or contour plot of the solution u(x,y) as "solution_agent_poisson_01.png".
Print the minimum value of the computed solution u.
Print the maximum value of the computed solution u.
Print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy) over the entire grid.
The exact solution for verification is u_exact(x,y) = sin(pi*x)*sin(pi*y).
Compute the error between the numerical solution and the exact solution evaluated on the same grid.
Print the maximum absolute error over the entire grid.
