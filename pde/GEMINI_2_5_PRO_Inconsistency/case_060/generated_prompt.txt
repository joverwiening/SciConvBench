The PDE to solve is u_xx + u_yy = 0.
The domain is the unit square, (x,y) in [0,1] x [0,1].
Discretize the domain using a uniform grid with Nx=100 intervals in the x-direction and Ny=100 intervals in the y-direction.
This results in a grid with Nx+1 by Ny+1 points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid coordinates are x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Apply Dirichlet boundary conditions on all four edges of the domain.
The value of the solution on the boundary is specified by the function u(x,y) = y.
Discretize the PDE on interior nodes using the standard 5-point finite difference stencil for the Laplacian.
Solve the resulting sparse linear system using a sparse direct solver.
The exact solution for verification is u(x,y) = y.
Compute the numerical solution u(x,y) on the (Nx+1) by (Ny+1) grid.
Save the results to a file named "solution_agent_laplace_04.npz".
