Solve the partial differential equation u_xx + u_yy = 0.
The spatial domain for (x,y) is the closed interval [0,1] x [0,1].
Apply Dirichlet boundary conditions on all four edges of the domain.
The value of the unknown field u on the boundary is given by the function u(x,y) = sinh(pi*x)*sin(pi*y)/sinh(pi).
The exact solution for verification is u(x,y) = sinh(pi*x)*sin(pi*y)/sinh(pi).
Use a uniform grid with Nx = 100 intervals in the x-direction and Ny = 100 intervals in the y-direction.
This results in 101 grid points in each direction, including the endpoints.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are defined as x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Discretize the PDE using the standard second-order accurate 5-point stencil for the Laplacian.
Solve the resulting sparse linear system for the interior grid nodes using a sparse direct solver.
Compute the steady-state solution u(x,y) on the 2D grid.
Save the solution to a file named "solution_agent_laplace_02.npz".
The NPZ file must contain the 1D array 'x', the 1D array 'y', the 2D solution array 'u', and the scalar metadata 'dx' and 'dy'.
The shape of the 'u' array must be (len(y), len(x)) such that u[j,i] corresponds to the solution at (x[i], y[j]).
Save a heatmap or contour plot of the solution u(x,y) as "solution_agent_laplace_02.png".
Print the minimum value of the computed solution u.
Print the maximum value of the computed solution u.
Print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy) over all grid points.
Compute and print the maximum absolute error between the numerical solution and the exact solution on the grid.
