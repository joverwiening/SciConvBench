Solve the PDE u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 5.0.
The boundary condition is periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points, where x_j = j/Nx for j=0,...,Nx-1.
The spatial grid spacing dx is 1/Nx.
Use a fixed time step of dt=0.001.
Perform Nt=1000 time steps to reach the final time T=1.0.
Use the Strang splitting method for time integration over each full time step dt.
The first step of the splitting is a diffusion half-step for a duration of dt/2, solved exactly in Fourier space.
To perform the diffusion step, compute the FFT of u, multiply the Fourier coefficients u_hat(k) by exp(-nu*k^2*(dt/2)), and then compute the real part of the inverse FFT.
The wave numbers k are defined as 2*pi*fftfreq(Nx, d=dx).
The second step of the splitting is a reaction full-step for a duration of dt, solved exactly pointwise.
The exact update for the reaction step at each grid point is u_new = (u_old*exp(rho*dt)) / (1 + u_old*(exp(rho*dt) - 1)).
The third step of the splitting is another diffusion half-step for a duration of dt/2, identical to the first step.
Compute the solution u(x,T) at the final time T=1.0.
Save a file named "solution_pdebench_reacdiff_nu0p5_rho5.npz".
The NPZ file must contain the 1D array of grid point coordinates 'x', the 1D array of the final solution 'u', and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x as "solution_pdebench_reacdiff_nu0p5_rho5.png".
Print the minimum, maximum, and mean of the final solution u(x,T).
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
