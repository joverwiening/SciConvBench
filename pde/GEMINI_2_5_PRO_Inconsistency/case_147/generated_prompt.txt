The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 0.2.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The numerical method is Strang splitting for each time step dt.
The first substep is a diffusion half-step of duration dt/2 solved in Fourier space.
The Fourier transform of the solution u is computed.
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The Fourier coefficients are updated by multiplying with exp(-nu*k^2*(dt/2)).
The solution is updated by taking the real part of the inverse Fourier transform.
The second substep is an advection full-step of duration dt for the inviscid Burgers equation.
The advection step uses a finite-volume update with the Rusanov flux.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] with periodic indexing, the numerical flux F is calculated.
The wave speed is alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Each cell j is updated using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the right interface and F_minus is the flux at the left interface.
The solution u is replaced by u_new after the advection substep.
The third substep is another diffusion half-step of duration dt/2, identical to the first substep.
The time step dt is fixed for the entire simulation.
An initial time step dt0 is calculated as CFL*dx/1.0, with CFL=0.4 and an estimated max speed of 1.0.
The number of time steps is Nt = ceil(T/dt0), where the final time T is 1.0.
The final time step is dt = T/Nt.
The final solution u(x,T) at T=1.0 is computed.
An NPZ file named "solution_pdebench_burgers_nu0p2.npz" is saved.
The NPZ file contains the 1D array x of length Nx, the 1D array u of length Nx, and the scalars nu, T, dx, dt, Nx, Nt.
A PNG file named "solution_pdebench_burgers_nu0p2.png" is saved.
The PNG file contains a line plot of the final solution u as a function of x.
The minimum value of the final solution u is printed.
The maximum value of the final solution u is printed.
The discrete mean value of the final solution u is printed.
The discrete L2 norm of the final solution u, defined as sqrt(sum(u^2)*dx), is printed.
