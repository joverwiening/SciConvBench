The PDE to solve is u_xx + u_yy = -2*(y*(1-y) + x*(1-x)).
The spatial domain is the square defined by (x,y) in [0,1] x [0,1].
Use Dirichlet boundary conditions on all four edges of the domain.
The value of u on the boundary is specified by the function u(x,y) = x*(1-x)*y*(1-y).
Discretize the domain using a uniform grid with Nx = 120 intervals in the x-direction and Ny = 120 intervals in the y-direction.
This grid will have Nx+1 by Ny+1 total grid points.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid point coordinates are x_i = i*dx for i=0,...,Nx and y_j = j*dy for j=0,...,Ny.
Discretize the Laplacian operator using the standard second-order 5-point finite difference stencil.
Solve the resulting sparse linear system for the interior grid points using a sparse direct solver.
The exact solution for verification is u(x,y) = x*(1-x)*y*(1-y).
Compute the numerical solution for u(x,y) on all grid points.
Save the output to a file named "solution_agent_poisson_03.npz".

The solution array 'u' must have a shape of (Ny+1, Nx+1) such that u[j,i] corresponds to the solution at (x_i, y_j).
