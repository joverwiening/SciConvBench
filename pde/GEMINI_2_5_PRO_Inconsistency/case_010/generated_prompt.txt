The PDE to solve is u_t = (0.01)^2 * (u_xx + u_yy) + u - u^3.
The spatial domain is (x,y) in [0,1) x [0,1).
The time domain is t in [0,0.2].
The boundary conditions are periodic in both x and y.
The initial condition is u(x,y,0) = 0.1 * cos(2*pi*x) * cos(2*pi*y).
Use a uniform grid with Nx = 256 and Ny = 256 points.
The grid points for the periodic domain [0,1) are defined as x_i = i/Nx for i=0,...,Nx-1, and similarly for y.
Discretize the Laplacian (u_xx + u_yy) using a standard 5-point finite difference stencil.
Use a time step of dt = 0.0002.
Integrate in time using the semi-implicit scheme: (u^{n+1}-u^n)/dt = (0.01)^2 * Δu^{n+1} + u^n - (u^n)^3.
Compute the solution u(x,y,T) at the final time T = 0.2.
