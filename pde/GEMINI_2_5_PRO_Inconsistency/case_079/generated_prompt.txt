The PDE to solve is u_xx + u_yy = f(x,y).
The forcing function is f(x,y) = -((3*pi)^2 + (2*pi)^2)*sin(3*pi*x)*cos(2*pi*y).
The spatial domain is the unit square [0,1] x [0,1].
Discretize the domain with a uniform grid.
The number of intervals in the x-direction is Nx = 120.
The number of intervals in the y-direction is Ny = 120.
This results in a grid with 121 points in x and 121 points in y.
The grid spacing is dx = 1/120 and dy = 1/120.
The grid points are x_i = i*dx for i=0..120 and y_j = j*dy for j=0..120.
Discretize the Laplacian operator using the standard second-order 5-point finite difference stencil.
Apply Dirichlet boundary conditions on all four boundaries.
The boundary values are set by the function u(x,y) = sin(3*pi*x)*cos(2*pi*y).
Solve the resulting sparse linear system of equations for the interior grid points.
Use a sparse direct solver to find the solution.
The exact solution for verification is u_exact(x,y) = sin(3*pi*x)*cos(2*pi*y).
Compute the steady-state numerical solution u(x,y) on the 121x121 grid.
