The task is to solve a 1D Compressible Navier-Stokes PDE system.
The PDE system is defined in conservative form for density (rho), momentum (m), and total energy (E).
The conserved variables are U = [rho, m, E].
The momentum is m = rho * v.
The total energy is E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The first PDE is rho_t + (m)_x = 0.
The second PDE is m_t + (m^2/rho + p - sigma)_x = 0.
The third PDE is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time T is 0.2.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is equal to eta, so zeta is 1e-08.
The boundary conditions are transmissive (outflow) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho_L = 0.445, v_L = 0.698, p_L = 3.528.
For x >= 0, the initial state is rho_R = 0.5, v_R = 0.0, p_R = 0.571.
The numerical grid is a uniform finite-volume grid with Nx=800 cells.
The cell width is dx = 2/Nx.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The conservative variables U = [rho, m, E] are evolved as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p become negative during the evolution, they should be clipped to a small positive floor of 1e-12.
The convective flux is calculated using the Rusanov (local Lax-Friedrichs) scheme.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ).
The speed of sound is c = sqrt(Gamma*p/rho).
The numerical convective flux at an interface is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is computed using a centered difference on cell-centered velocity values.
The viscous stress sigma is computed at cell centers.
The viscous stress sigma at cell interfaces is approximated by the arithmetic average of the neighboring cell-centered values.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The velocity v in the viscous flux at an interface is the arithmetic average of the neighboring cell-centered values.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Time integration is performed using the 2-stage SSP-RK2 (Heun's method).
The time step dt is chosen at each step as the minimum of the convective and viscous time steps.
The convective time step is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The CFL number is 0.8.
The viscous time step is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
The final time step is adjusted to end the simulation exactly at T=0.2.
Outflow boundary conditions are implemented using two ghost cells on each side.
The values in the ghost cells are set equal to the nearest interior cell value (zero-gradient).
Compute the primitive variables rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T.
