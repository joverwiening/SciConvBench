Solve the ordinary differential equation du/dt = a*exp(-t) + b.
The time domain is the closed interval [0.0, 5.0].
The parameter 'a' is 2.0.
The parameter 'b' is -0.5.
The initial condition is u(0.0) = 0.0.
The exact solution for verification is u(t) = u(0) + a*(1 - exp(-t)) + b*t.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step 'dt' of 0.001.
Use a total of 5000 time steps, resulting in a final time of 5.0.
The time grid consists of Nt+1 points, t_n = 0.0 + n*dt for n from 0 to 5000.
Compute the numerical solution u(t) at all points on the time grid.
Save the results to a file named "solution_molk_001.npz".
The NPZ file must contain a 1D array 't' of length 5001 for the time points.
The NPZ file must contain a 1D array 'u' of length 5001 for the numerical solution.
The NPZ file must contain the scalar parameters 'a' and 'b'.
Save a line plot of u(t) versus t to a file named "solution_molk_001.png".
Print the value of the numerical solution at the final time, u(5.0).
Print the minimum value of the numerical solution over the entire time grid.
Print the maximum value of the numerical solution over the entire time grid.
Compute the maximum absolute error between the numerical and exact solutions on the time grid.
Compute the L2 error between the numerical and exact solutions on the time grid.
Print the computed maximum absolute error.
