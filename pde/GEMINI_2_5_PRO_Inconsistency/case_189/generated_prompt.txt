Task ID is pdebench_reacdiff_nu5_rho10.
The PDE category is 1D Reaction–Diffusion with a logistic reaction term and periodic boundary conditions.
The unknown field to solve for is u(x,t).
The governing PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain for x is the interval [0, 1) with periodic boundaries.
The time domain for t is the interval [0, 1.0].
The diffusion coefficient nu is 5.0.
The reaction coefficient rho is 10.0.
The boundary condition is periodic, such that u(0,t) = u(1,t).
The initial condition at t=0 is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method is Strang splitting.
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The time grid uses a fixed time step dt=0.001.
The simulation runs for Nt=1000 steps to reach the final time T=1.0.
Each time step of size dt is performed using a Strang splitting sequence.
First, solve the diffusion equation for a half-step of duration dt/2.
This diffusion half-step is solved exactly in Fourier space using the update rule u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wave numbers k are defined as 2*pi*fftfreq(Nx, d=dx).
Second, solve the reaction equation for a full-step of duration dt.
This reaction step is solved exactly pointwise using the update rule u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation for another half-step of duration dt/2, identical to the first diffusion step.
The final solution u(x,T=1.0) on the spatial grid must be computed.
Save the results to a file named "solution_pdebench_reacdiff_nu5_rho10.npz".
The NPZ file must contain the 1D array 'x' of grid point locations, the 1D array 'u' of the final solution, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu5_rho10.png".
Print the minimum, maximum, and mean values of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
