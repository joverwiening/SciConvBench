The task is to solve a 2D Darcy flow partial differential equation.
The unknown field to solve for is u(x,y).
The governing PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The spatial domain is (x,y) in (0,1) x (0,1).
The parameter beta is 10.0.
The coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Implement Dirichlet boundary conditions where u = 0 on the entire boundary of the domain.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 points per direction.
The grid spacing is dx = dy = 1/N.
The grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a 2nd-order finite difference scheme.
The discretization for interior nodes (i=1..N-1, j=1..N-1) is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face-centered coefficients are calculated using harmonic averaging, for example a(i+1/2,j) = 2*a(x_i,y_j)*a(x_{i+1},y_j) / (a(x_i,y_j)+a(x_{i+1},y_j)).
Assemble the sparse linear system Au=b for the interior unknown values of u.
Solve the linear system using the conjugate gradient (CG) method.
The stopping criterion for the CG solver is a relative residual norm of 1e-10.
A Jacobi preconditioner may optionally be used.
The final computed solution u(x,y) must be on the full (N+1) x (N+1) grid, including the boundary values.
Save the output to a file named "solution_pdebench_darcy_beta10.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, the 2D solution array u of shape [N+1, N+1], and the scalar values for beta, N, and dx.
Save a heatmap or contour plot of the solution u(x,y) to a file named "solution_pdebench_darcy_beta10.png".
Print the minimum value of the final solution u to the console.
Print the maximum value of the final solution u to the console.
Print the final relative residual norm ||Au-b||_2 / ||b||_2 of the interior linear system to the console.
