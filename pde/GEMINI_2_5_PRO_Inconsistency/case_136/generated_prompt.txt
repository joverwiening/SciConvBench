The PDE to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 2.0].
The final time T is 2.0.
The parameter beta is 0.2.
The boundary condition is periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution is u(x,t) = u0((x - beta*t) mod 1), where u0(x) is the initial condition.
Use a uniform periodic grid with Nx=512 points.
The grid points are x_j = j/Nx for j=0, ..., Nx-1.
The spatial step size is dx = 1/Nx.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference.
Integrate in time using the explicit forward Euler method.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The initial time step dt is calculated as CFL * dx / abs(beta).
The number of time steps Nt is the ceiling of T/dt.
The final time step is recalculated as dt = T/Nt.
Compute the numerical solution u(x,T) at the final time T=2.0.
