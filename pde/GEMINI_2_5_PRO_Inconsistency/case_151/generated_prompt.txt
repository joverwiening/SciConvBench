Solve the partial differential equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 2.0.
The boundary condition is periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The final time T is 1.0.
Calculate an initial time step dt0 = 0.4 * dx / 1.0.
Calculate the number of time steps Nt = ceil(T/dt0).
Set the final time step dt = T/Nt.
Use Strang splitting for the time integration over each time step dt.
The first Strang splitting step is a diffusion half-step for a duration of dt/2.
Solve the diffusion half-step u_t = nu * u_xx exactly in Fourier space.
To solve the diffusion step, compute the forward FFT of u to get u_hat(k).
The angular wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute the inverse FFT of the updated u_hat(k) and take its real part to get the result of the diffusion step.
The second Strang splitting step is an advection full-step for a duration of dt.
Solve the advection step u_t + ∂_x(0.5*u^2)=0 using a finite-volume method with a Rusanov flux.
The flux function is f(u) = 0.5*u^2.
For each interface between a left state u_left and a right state u_right, the Rusanov flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed alpha is max(abs(u_left), abs(u_right)).
Update each cell j using the conservative formula u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the right interface and F_minus is the flux at the left interface.
The third Strang splitting step is another diffusion half-step for a duration of dt/2, identical to the first step.
Compute the solution u(x,T) at the final time T=1.0.
Save a file named "solution_pdebench_burgers_nu2.npz".
The NPZ file must contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, and the scalars 'nu', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Save a line plot of the final solution u versus x as "solution_pdebench_burgers_nu2.png".
