The PDE to be solved is the 1D Compressible Navier-Stokes system without heat conduction.
The conservative variables are rho, m = rho*v, and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time T is 0.2.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is equal to eta, so zeta is 1e-08.
The boundary conditions are transmissive (outflow/zero-gradient) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=0.0, p=2.0.
For x >= 0, the initial state is rho=0.125, v=0.0, p=0.2.
Use a uniform finite-volume grid with Nx=800 cells.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Evolve the cell-averaged conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below it.
The total numerical flux at an interface is the sum of a convective flux and a viscous flux.
The convective flux is the Rusanov (local Lax-Friedrichs) flux.
The physical convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The Rusanov interface flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The viscous terms are calculated as follows.
First, compute cell-centered velocity gradient v_x using a centered difference on cell-centered velocities.
Second, compute cell-centered viscous stress sigma = (zeta + 4/3*eta)*v_x.
Third, compute interface values of sigma and v by averaging the values from the two adjacent cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma], using the interface-averaged values.
The time integration scheme is the 2-stage SSP-RK2 (Heun's method).
The time step dt is chosen at each step as the minimum of the convective and viscous time steps.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
The CFL number is 0.5.
The final time step is adjusted to land exactly at T=0.2.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell.
Compute the primitive variables rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T=0.2.
