The PDE to be solved is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The unknown field is u(x,y).
The spatial domain is (x,y) in (0,1) x (0,1).
The parameter beta is 0.01.
The coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Use Dirichlet boundary conditions with u = 0 on the entire boundary.
A uniform Cartesian grid will be used.
The grid will have N=128 intervals in each direction, resulting in (N+1)x(N+1) grid points.
The grid spacing is dx = dy = 1/128.
The grid points are defined by x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
The PDE will be discretized using a 2nd-order finite difference scheme with variable coefficients.
Harmonic averaging will be used for the coefficients at the cell faces.
The discrete equation for interior nodes is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face coefficient a(i+1/2,j) is calculated as 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknown grid points.
Solve the linear system using the conjugate gradient method without a preconditioner.
The convergence tolerance for the linear solver is a relative residual of 1e-10.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including the boundaries.
Save the output to a file named "solution_pdebench_darcy_beta0p01.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The NPZ file must also contain the scalar values for beta, N, and dx.
Save a heatmap or contour plot of the solution u(x,y) as "solution_pdebench_darcy_beta0p01.png".
Print the minimum value of the solution u.
Print the maximum value of the solution u.
Print the final relative residual norm of the interior linear system, calculated as ||Au-b||_2 / ||b||_2.
