Task ID is pdebench_cns1d_eta1em8_periodic_smooth.
The PDE category is 1D Compressible Navier–Stokes without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The PDE is to be solved numerically.
All mathematical functions are to be interpreted exactly as written, using radians for trigonometric functions.
In Python code, use '**' for exponentiation.
The grid convention for a periodic domain [a,b) is that Nx is the number of grid points with no duplicated endpoint.
The grid spacing is dx=(b-a)/Nx and grid points are x_i=a+i*dx for i=0..Nx-1.

The PDE is given in conservative form.
Let the momentum be m = rho*v.
Let the total energy be E = p/(Gamma-1) + 0.5*rho*v^2.
Let the viscous stress be sigma = (zeta + 4/3*eta) * v_x.
The parameter zeta is equal to eta.
The first PDE equation is rho_t + (m)_x = 0.
The second PDE equation is m_t + (m^2/rho + p - sigma)_x = 0.
The third PDE equation is E_t + ( (E+p)*v - v*sigma )_x = 0.

The spatial domain for x is [-1, 1].
The time domain for t is [0, 0.5].

The parameter Gamma is 1.6666666666666667.
The parameter eta is 1e-08.
The parameter zeta is 1e-08.
The CFL number is 0.5.

The boundary conditions are periodic on x=-1 and x=1.

The initial condition for rho is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial condition for v is v(x,0) = 0.1*cos(pi*x).
The initial condition for p is p(x,0) = 1.0 + 0.2*cos(pi*x).

A uniform finite-volume grid with Nx=400 cells is used on [-1,1].
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
The conservative variables U = [rho, m, E] are evolved as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below this value.
The convective flux is calculated using the Rusanov (local Lax-Friedrichs) numerical flux.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is computed with a centered difference on the cell-centered v values.
The viscous stress sigma = (zeta + 4/3*eta)*v_x is computed at cell centers.
The value of sigma at interfaces is approximated by averaging the neighboring cell-centered sigma values.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.
The total interface flux is F_total = F_hat + F_visc.
Time integration is performed using the 2-stage SSP-RK2 (Heun's method).
The time step dt is chosen at each step.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step is dt = min(dt_conv, dt_visc).
The final time step is adjusted to hit the final time T=0.5 exactly.
Periodic boundary conditions are implemented by wrapping indices for ghost cells.
