The PDE to be solved is u_t = -1.0 * ∂_x( (1/3)*u^3 ) + (0.05/pi)*u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 0.5].
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The boundary conditions are periodic.
The spatial grid is a uniform periodic grid with Nx = 1024 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_j = j*dx for j = 0, ..., Nx-1.
The time integration method is Second-Order Strong Stability Preserving Runge-Kutta (SSP-RK2).
The convective term ∂_x((1/3)u^3) is discretized using a conservative finite-volume method with a Rusanov flux.
The Rusanov flux uses a constant maximum wave speed of 0.25 for all interfaces and all time steps.
The diffusive term u_xx is discretized using a second-order central difference scheme.
The time step dt is constant for the entire simulation.
Calculate an advective time step dt_adv = 0.2 * dx / 0.25.
Calculate a diffusive time step dt_diff = 0.2 * dx^2 / (0.05/pi).
Set a provisional time step dt_prov = min(dt_adv, dt_diff).
The number of time steps is Nt = ceil(0.5 / dt_prov).
The final time step is dt = 0.5 / Nt.
