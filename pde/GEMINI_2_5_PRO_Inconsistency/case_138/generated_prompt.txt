The PDE to solve is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
The final time T for the simulation is 2.0.
The parameter beta is 0.7.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
Discretize the spatial derivative u_x using a first-order upwind finite difference.
Since beta is positive, the upwind approximation for u_x at grid point j is (u_j - u_{j-1}) / dx, handling the j-1 index periodically.
Integrate in time using the explicit forward Euler method.
Use a Courant-Friedrichs-Lewy (CFL) number of 0.5.
Calculate an initial time step dt = CFL * dx / abs(beta).
Calculate the number of time steps Nt = ceil(T/dt).
Adjust the time step to dt = T/Nt to hit the final time exactly.
Compute the solution u(x,T) at the final time T=2.0.
