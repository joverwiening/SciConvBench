The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 5.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are defined as x_j = j/Nx for j=0, ..., Nx-1.
The spatial step size dx is 1/Nx.
The time step dt is fixed at 0.001.
The number of time steps Nt is 1000, resulting in a final time T of 1.0.
The time integration method is Strang splitting.
Each time step from t to t+dt consists of three sequential operations.
First, solve the diffusion equation u_t = nu * u_xx for a half-step of duration dt/2.
The diffusion half-step is solved exactly in Fourier space using the update rule u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wave numbers k are defined as 2*pi*fftfreq(Nx, d=dx).
Second, solve the reaction equation du/dt = rho*u*(1-u) for a full-step of duration dt.
The reaction step is solved exactly for each grid point using the update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation u_t = nu * u_xx for another half-step of duration dt/2 using the same Fourier method as the first step.
Compute the solution u(x,T) at the final time T=1.0.
Save the solution to a file named "solution_pdebench_reacdiff_nu2_rho5.npz".
The npz file must contain the 1D array 'x' of grid point locations, the 1D array 'u' of the final solution, and the scalar values for nu, rho, T, dx, dt, Nx, and Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu2_rho5.png".
Print the minimum, maximum, and mean values of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
