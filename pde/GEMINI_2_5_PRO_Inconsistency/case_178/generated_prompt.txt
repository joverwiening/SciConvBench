Solve the partial differential equation u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 1.0].
The parameter nu is 10.0.
The parameter rho is 2.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j/Nx for j=0, ..., Nx-1.
The spatial step size is dx = 1/Nx.
Use a fixed time step of dt=0.001.
Perform Nt=1000 time steps to reach the final time T=1.0.
Use Strang splitting for time integration for each time step dt.
The first step of the splitting is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
The Fourier space update for the diffusion half-step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The second step of the splitting is a reaction full-step of duration dt, solved exactly pointwise.
The pointwise update for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third step of the splitting is another diffusion half-step of duration dt/2, identical to the first step.
Compute the solution u(x,T) at the final time T=1.0.
Save the results to a file named "solution_pdebench_reacdiff_nu10_rho2.npz".
The NPZ file must contain the 1D array 'x' of grid point locations.
The NPZ file must contain the 1D array 'u' of the final solution.
The NPZ file must contain the scalar 'nu'.
The NPZ file must contain the scalar 'rho'.
The NPZ file must contain the scalar 'T'.
The NPZ file must contain the scalar 'dx'.
The NPZ file must contain the scalar 'dt'.
The NPZ file must contain the scalar 'Nx'.
The NPZ file must contain the scalar 'Nt'.
Create a line plot of the final solution u(x,T).
