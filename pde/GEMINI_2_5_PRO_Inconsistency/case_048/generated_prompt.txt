The PDE to solve is u_tt - c^2*u_xx + m^2*u = 0.
The wave speed c is 1.0.
The mass term m is 1.0.
The spatial domain for x is the closed interval [0, 1].
The time domain for t is the closed interval [0, 1.0].
The boundary condition at x=0 is u=0.
The boundary condition at x=1 is u=0.
The initial condition for u at t=0 is u(x,0) = sin(pi*x).
The initial condition for the time derivative of u at t=0 is u_t(x,0) = 0.
The spatial grid will have Nx=400 uniform intervals, resulting in 401 grid points.
The spatial step size dx is 1/Nx.
The spatial discretization for u_xx is the 2nd-order central difference.
The time integration scheme is the 2nd-order central difference, also known as the leapfrog method.
In the leapfrog update, the m^2*u term is evaluated explicitly at time level n.
The first time step is calculated using a 2nd-order Taylor series expansion based on the initial conditions and the PDE.
The Courant-Friedrichs-Lewy (CFL) number for the time step calculation is 0.9.
The time step dt is calculated to ensure the final time T=1.0 is reached exactly.
First, an initial time step dt0 = 0.9 * dx / c is calculated.
Then, the number of time steps Nt is the ceiling of T / dt0.
The final time step dt is T / Nt.
The numerical solution for u(x,t) is computed at the final time T=1.0.
The solution is saved to a file named "solution_agent_kg_01.npz".
The NPZ file contains the 1D x-coordinate array named 'x'.
The NPZ file contains the 1D solution array u(x,T) named 'u'.
The NPZ file contains the scalar final time T.
The NPZ file contains the scalar spatial step dx.
The NPZ file contains the scalar time step dt.
A line plot of the final solution u(x,T) versus x is created.
The plot is saved to a file named "solution_agent_kg_01.png".
The minimum value of the final solution u(x,T) is printed to the console.
The maximum value of the final solution u(x,T) is printed to the console.
The discrete L2 norm of the final solution, defined as sqrt(sum(u^2)*dx), is printed to the console.
The exact solution for verification is u_exact(x,t) = cos(sqrt((pi)^2 + 1)*t)*sin(pi*x).
The maximum absolute error between the numerical and exact solutions at T=1.0 is computed and printed.
The L2 norm of the error between the numerical and exact solutions at T=1.0 is computed and printed.
