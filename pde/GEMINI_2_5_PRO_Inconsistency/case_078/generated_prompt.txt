The PDE to solve is u_xx + u_yy = -2*pi^2*cos(pi*x)*cos(pi*y).
The domain is a square defined by (x,y) in [0,1] x [0,1].
The grid will have Nx=120 intervals in the x-direction and Ny=120 intervals in the y-direction.
This corresponds to 121 grid points in each direction, including the boundaries.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are defined by x_i = i*dx for i=0..Nx and y_j = j*dy for j=0..Ny.
The spatial discretization of the Laplacian operator will use the standard second-order 5-point stencil.
The boundary conditions are Dirichlet on all four edges.
The value of u on the boundary is set to match the function u(x,y) = cos(pi*x)*cos(pi*y).
The resulting sparse linear system for the interior grid nodes will be solved using a sparse direct solver.
The exact solution for verification is u(x,y) = cos(pi*x)*cos(pi*y).
