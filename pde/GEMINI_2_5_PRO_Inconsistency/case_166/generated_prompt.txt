The PDE to be solved is the 1D Compressible Navier-Stokes system without heat conduction.
The conservative state vector is U = [rho, m, E], where rho is density, m is momentum (rho*v), and E is total energy.
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE in conservative form is rho_t + (m)_x = 0.
The PDE in conservative form is m_t + (m^2/rho + p - sigma)_x = 0.
The PDE in conservative form is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final simulation time is T = 0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The CFL number is 0.8.
Boundary conditions are transmissive (outflow) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho_L = 1.0, v_L = 0.0, p_L = 10.0.
For x >= 0, the initial state is rho_R = 1.0, v_R = 0.0, p_R = 0.1.
Use a uniform finite-volume grid with Nx=800 cells.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The cell width is dx = 2/Nx.
Evolve the conservative variables U = [rho, m, E] as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below this value.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x using a centered difference on cell-centered velocity values.
Compute the viscous stress sigma = (zeta + 4/3*eta)*v_x at cell centers.
Approximate sigma at cell interfaces by averaging the values from the two adjacent cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
Compute the viscous flux at interfaces using interface-averaged values for v and sigma.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The time step dt is chosen at each step as the minimum of the convective and viscous time steps.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
The final time step should be adjusted to end the simulation exactly at T=0.2.
Implement outflow boundary conditions by setting ghost cell values equal to the nearest interior cell value.
Compute the solution rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T.

The npz file must also contain the scalars Gamma, eta, zeta, T, dx, CFL.
