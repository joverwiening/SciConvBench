The PDE to solve is u_tt = 4.0 * u_xx.
The spatial domain is x in the interval [0, 1].
The temporal domain is t in the interval [0, 0.5].
The wave speed c is 2.0.
The boundary condition at x=0 is u(0, t) = 0.
The boundary condition at x=1 is u(1, t) = 0.
The initial condition for the field is u(x, 0) = sin(pi*x).
The initial condition for the time derivative of the field is u_t(x, 0) = 0.
The spatial domain is discretized into Nx=400 uniform intervals, resulting in 401 grid points.
The spatial step size is dx = 1.0 / Nx.
The spatial second derivative u_xx is discretized using a second-order central difference scheme.
The temporal second derivative u_tt is discretized using a second-order central difference scheme (leapfrog).
A preliminary time step dt0 is calculated as 0.9 * dx / c.
The number of time steps Nt is calculated as the ceiling of T / dt0, where the final time T is 0.5.
The final time step dt is calculated as T / Nt.
The solution at the first time step u(x, dt) is calculated using a Taylor series expansion: u^1 = u^0 + dt*u_t(x,0) + 0.5*dt^2*(c^2*u_xx(x,0)).
The simulation is run until the final time T=0.5.
The final solution u(x, T) is computed on the grid.
A file named "solution_agent_wave_12.npz" is saved.
The NPZ file contains the 1D array of grid point coordinates 'x', the 1D array of the final solution 'u', the final time 'T', the spatial step 'dx', and the time step 'dt'.
A line plot of the final solution u(x, T) versus x is saved as "solution_agent_wave_12.png".
The minimum value of the final solution u is printed to the console.
The maximum value of the final solution u is printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx), is printed to the console.
The exact solution for verification is u_exact(x,t) = cos(2.0*pi*t)*sin(pi*x).
The maximum absolute error between the numerical and exact solutions at T=0.5 is computed and printed.
The L2 error between the numerical and exact solutions at T=0.5 is computed and printed.
