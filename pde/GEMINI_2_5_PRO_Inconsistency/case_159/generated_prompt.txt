The PDE to be solved is the 1D compressible Navier-Stokes system in conservative form.
The system equations are rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, and E_t + ( (E+p)*v - v*sigma )_x = 0.
The conserved variables are density rho, momentum m = rho*v, and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The adiabatic index Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is equal to eta, so it is 1e-08.
Boundary conditions are transmissive (zero-gradient) at x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=0.0, p=1.0.
For x >= 0, the initial state is rho=0.1, v=0.0, p=0.01.
Use a uniform finite-volume grid with Nx=800 cells.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, where dx = 2/Nx.
Evolve the cell-averaged conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a minimum value of 1e-12 if they fall below it.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective part of the PDE.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x at cell centers using a second-order centered difference.
Approximate the viscous stress sigma at cell interfaces by arithmetically averaging the values from the two adjacent cell centers.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The velocity v in the viscous energy flux term at an interface is the arithmetic average of the velocities from the two adjacent cell centers.
The total numerical flux at an interface is the sum of the Rusanov convective flux and the viscous flux.
Use the two-stage, second-order, strong stability-preserving Runge-Kutta (SSP-RK2) method for time integration.
The time step dt is the minimum of the convective and viscous time step limits.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
Use a CFL number of 0.8.
Adjust the final time step to ensure the simulation stops exactly at T=0.2.
Implement boundary conditions using ghost cells.
For the outflow boundary condition, set the values in the ghost cells equal to the value of the nearest interior cell.
Compute the solution rho(x,T), v(x,T), and p(x,T) at the final time T=0.2 on the cell centers.

The NPZ file must contain the 1D arrays x, rho, v, p.
The NPZ file must also contain the scalars Gamma, eta, zeta, T, dx, CFL.
