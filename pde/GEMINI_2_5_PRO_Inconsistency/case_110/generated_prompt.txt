The task is to solve the FitzHugh-Nagumo ODE system.
The system of equations is dv/dt = v - (v^3)/3 - w + I.
The system of equations is dw/dt = (1/tau)*(v + a - b*w).
The independent variable is time t.
The dependent variables are v(t) and w(t).
The time domain is from t=0.0 to t=200.0.
The parameter I is 0.5.
The parameter a is 0.7.
The parameter b is 0.8.
The parameter tau is 12.5.
The initial condition for v at t=0.0 is -1.0.
The initial condition for w at t=0.0 is 1.0.
The system must be solved using the classical 4th-order Runge-Kutta method.
A fixed time step dt of 0.05 must be used.
The total number of time steps Nt is 4000.
The full state vector [v, w] must be computed at all time points from t=0.0 to t=200.0.
Save the results to a file named "solution_molk_009.npz".
The NPZ file must contain a 1D array 't' of time points of length 4001.
The NPZ file must contain a 2D array 'Y' of shape [4001, 2] with the state variables.
The columns of the 'Y' array must be ordered as v, then w.
The NPZ file must also contain the scalar parameters I, a, b, and tau.
Create a line plot showing v(t) and w(t) versus time.
Save the plot as "solution_molk_009.png".
Print the final values of v and w at t=200.0 to the console.
Print the minimum and maximum values of v over the entire simulation to the console.
Print the minimum and maximum values of w over the entire simulation to the console.
