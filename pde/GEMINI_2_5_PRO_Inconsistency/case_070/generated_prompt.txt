The PDE to solve is ∇⁴u = 4*π⁴*sin(π*x)*sin(π*y).
The spatial domain is the unit square [0,1] x [0,1].
Use simply-supported boundary conditions on all boundaries.
The simply-supported condition means u=0 on the boundary.
The simply-supported condition also means Δu=0 on the boundary.
The numerical method is to decompose the problem into two Poisson equations by defining v = Δu.
First, solve the Poisson equation Δv = 4*π⁴*sin(π*x)*sin(π*y) for v.
The boundary condition for the first Poisson problem is v=0 on all boundaries.
Second, solve the Poisson equation Δu = v for u.
The boundary condition for the second Poisson problem is u=0 on all boundaries.
Discretize both Poisson equations using the standard 5-point finite difference stencil for the Laplacian.
Use a uniform grid with Nx = 120 intervals in the x-direction and Ny = 120 intervals in the y-direction.
The grid will have 121 points in each direction, from i=0 to 120 and j=0 to 120.
The grid spacing is dx = 1/120 and dy = 1/120.
Solve the linear system for each Poisson problem using a sparse direct solver.
