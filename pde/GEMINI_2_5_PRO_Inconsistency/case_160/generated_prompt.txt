The PDE to be solved is the 1D Compressible Navier-Stokes system in conservative form.
The conservative variables are U = [rho, m, E], where rho is density, m is momentum (rho*v), and E is total energy.
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time T is 0.2.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is equal to eta, so zeta is 1e-08.
The CFL number is 0.9.
The boundary conditions are transmissive (outflow) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=0.0, p=1.0.
For x >= 0, the initial state is rho=0.125, v=0.0, p=0.1.
The numerical grid is a uniform finite-volume grid with Nx=800 cells.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The cell width is dx = 2/Nx.
The conservative variables U = [rho, m, E] are evolved as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p become negative during the simulation, they should be clipped to a small positive floor of 1e-12.
The convective flux is calculated using the Rusanov (local Lax-Friedrichs) scheme.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is computed using a centered difference on cell-centered velocity values.
The viscous stress sigma at cell interfaces is computed by averaging the sigma values from the two neighboring cells.
The viscous flux vector is F_visc = [ 0, -sigma, -v*sigma ], using interface-averaged v and sigma.
The total numerical flux at an interface is the sum of the convective and viscous fluxes.
Time integration is performed using the 2-stage SSP-RK2 (Heun's) method.
The time step dt is chosen at each step as the minimum of the convective and viscous time step limits.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The final time step is adjusted to end the simulation exactly at T=0.2.
Outflow boundary conditions are implemented by setting ghost cell values equal to the nearest interior cell value.
