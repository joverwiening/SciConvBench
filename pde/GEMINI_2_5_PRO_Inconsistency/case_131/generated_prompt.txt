The partial differential equation to be solved is u_t = -k * ∂_x(sin(u)).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter k is 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.5 * sin(2*pi*x).
A uniform periodic spatial grid will be used with Nx = 1024 points.
The grid spacing is dx = 1/Nx.
The grid points are defined as x_j = j*dx for j = 0, ..., Nx-1.
The spatial discretization will be a conservative finite-volume method using the Rusanov flux.
The flux function for the Rusanov scheme is f(u) = k * sin(u).
The wave speed for the Rusanov flux is alpha = 1.0, which is the global maximum of |k*cos(u)|.
The time integration will be performed using the second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step will be calculated based on a CFL number of 0.2.
The initial time step is calculated as dt0 = 0.2 * dx / 1.0.
The number of time steps is Nt = ceil(0.2/dt0).
The final time step used for integration is dt = 0.2/Nt.
The final solution u(x, T=0.2) will be computed.
A file named "solution_molk_030.npz" will be saved.
The NPZ file will contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, the scalar 'T' for the final time, the scalar 'dx' for the grid spacing, the scalar 'Nx' for the number of grid points, and the scalar parameter 'k'.
A line plot of the final solution u versus x will be saved as "solution_molk_030.png".
The minimum, maximum, and mean values of the final solution array u will be printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx), will be printed to the console.
