Solve the ordinary differential equation du/dt = a*sin(2*pi*t)*u.
The time domain is from t=0.0 to t=5.0.
The parameter 'a' is 1.3.
The initial condition is u(0.0) = 1.0.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt=0.001.
Perform a total of 5000 time steps, so the final time is exactly 5.0.
The time grid will have 5001 points from t=0.0 to t=5.0 inclusive.
Compute the numerical solution u(t) at all points on the time grid.
Save the results to a file named "solution_molk_000.npz".
The saved file must contain a 1D array 't' of length 5001 for the time points.
The saved file must contain a 1D array 'u' of length 5001 for the numerical solution.
The saved file must contain the scalar parameter 'a'.
Save a line plot of u(t) versus t to a file named "solution_molk_000.png".
Print the value of the numerical solution at the final time, u(5.0).
Print the minimum value of the numerical solution over the time grid.
Print the maximum value of the numerical solution over the time grid.
The exact solution for verification is u(t) = 1.0 * exp( a*(1 - cos(2*pi*t)) / (2*pi) ).
Evaluate the exact solution on the same time grid.
Compute and print the maximum absolute error between the numerical and exact solutions.
Compute and print the L2 error between the numerical and exact solutions.
