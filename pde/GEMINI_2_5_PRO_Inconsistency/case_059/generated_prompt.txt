The PDE to solve is u_xx + u_yy = 0.
The domain is a square defined by (x,y) in [0,1] x [0,1].
The grid will have Nx=100 intervals in the x-direction and Ny=100 intervals in the y-direction.
This corresponds to 101 grid points in each direction, including the boundaries.
The grid spacing is dx = 1/Nx and dy = 1/Ny.
The grid points are defined by x_i = i*dx for i=0 to Nx, and y_j = j*dy for j=0 to Ny.
Dirichlet boundary conditions are applied on all four edges of the domain.
The boundary values are set to match the function u(x,y) = x.
Specifically, u(0,y)=0, u(1,y)=1, u(x,0)=x, and u(x,1)=x.
The PDE is to be discretized using the standard 5-point stencil for the Laplacian, which is a second-order accurate method.
The resulting sparse linear system for the interior grid points must be solved using a sparse direct solver.
The steady-state solution u(x,y) on the 2D grid must be computed.
The solution must be saved to a file named "solution_agent_laplace_03.npz".
The NPZ file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u.
The shape of the u array must be (Ny+1, Nx+1) such that u[j,i] corresponds to u(x_i, y_j).
The NPZ file must also contain the scalar metadata values for dx and dy.
A heatmap or contour plot of the solution u(x,y) must be saved as "solution_agent_laplace_03.png".
The minimum and maximum values of the computed solution u must be printed to the console.
The discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx*dy), must be printed to the console.
The exact solution for verification is u_exact(x,y) = x.
The maximum absolute error between the numerical solution and the exact solution on the grid must be computed and printed.
The L2 error between the numerical solution and the exact solution on the grid must be computed and printed.
