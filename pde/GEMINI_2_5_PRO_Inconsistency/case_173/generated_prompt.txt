Solve the PDE u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 10.0.
The boundary condition is periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
Use a fixed time step of dt=0.001 for Nt=1000 steps to reach the final time T=1.0.
The time integration method is Strang splitting.
Each time step dt consists of three sequential operations.
First, advance the diffusion term u_t = nu * u_xx for a half-step of dt/2.
This diffusion half-step is solved exactly in Fourier space using the update rule: u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k are the angular wavenumbers.
Second, advance the reaction term du/dt = rho*u*(1-u) for a full-step of dt.
This reaction step is solved exactly at each grid point using the update rule: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, advance the diffusion term u_t = nu * u_xx for another half-step of dt/2 using the same Fourier space method.
Compute the solution u(x,T) at the final time T=1.0.
Save a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz".
The NPZ file must contain the 1D array 'x' of grid point locations, the 1D array 'u' of the final solution, and the scalar values for 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu0p5_rho10.png".
Print the minimum value of the final solution array u.
Print the maximum value of the final solution array u.
Print the mean value of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
