Use a uniform periodic grid with Nx=512 points.

The spatial step size is dx = 1/Nx.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference.
Integrate in time using the explicit forward Euler method.
The Courant-Friedrichs-Lewy number is CFL=0.5.
The initial time step is calculated as dt = CFL * dx / abs(beta).
The number of time steps is Nt = ceil(T/dt).
The final time step is reset to dt = T/Nt to ensure the simulation ends exactly at T.
The reference solution for error calculation is u_ref(x,t) = u( (x - beta*t) mod 1, 0).
