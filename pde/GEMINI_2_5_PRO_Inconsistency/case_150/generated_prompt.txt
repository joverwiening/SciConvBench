The final time for the simulation is T=1.0.
The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 0.001.
The boundary condition is periodic: u(0,t) = u(1,t).
The initial condition is u(x,0) = sin(2*pi*x).
No closed-form reference solution is required.
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
Use Strang splitting for the time integration.
Each full time step dt consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
The diffusion half-step of duration dt/2 is solved exactly in Fourier space.
The Fourier space update for diffusion is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The advection full-step of duration dt is for the inviscid equation u_t + ∂_x(0.5*u^2)=0.
Use a finite-volume method with Rusanov (local Lax-Friedrichs) flux for the advection step.
The flux F at the interface between u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u)=0.5*u^2 and alpha = max(abs(u_left), abs(u_right)).
The finite-volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the j+1/2 interface and F_minus is the flux at the j-1/2 interface.
The time step is determined by a CFL number of 0.4 and an estimated maximum speed of 1.0.
First, calculate an initial time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T/dt0).
Finally, set the actual time step to dt = T/Nt.
Compute the solution u(x,t) up to the final time T=1.0.
