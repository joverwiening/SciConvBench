The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 5.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The time grid uses a fixed time step dt=0.001.
The simulation runs for Nt=1000 steps to reach the final time T=1.0.
The time integration method is Strang splitting for each full time step dt.
The first step of the splitting is a diffusion half-step of duration dt/2, solved in Fourier space.
In the diffusion step, compute the Fourier transform of u to get u_hat(k).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute the inverse Fourier transform of the updated u_hat(k) and take its real part to get the new u.
The second step of the splitting is a reaction full-step of duration dt.
The reaction step is solved exactly for the logistic ODE du/dt = rho*u*(1-u) at each grid point.
The update formula for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third step of the splitting is another diffusion half-step of duration dt/2, identical to the first step.
The final solution u(x, T=1.0) should be computed.
Save the solution to a file named "solution_pdebench_reacdiff_nu5_rho5.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_reacdiff_nu5_rho5.png".
Print the minimum, maximum, and mean of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
