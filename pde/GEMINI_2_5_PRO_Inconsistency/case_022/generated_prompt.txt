The PDE to solve is u_t = 0.05 * (u_xx + u_yy).
The spatial domain is a square defined by x in [0,1] and y in [0,1].
The time domain is t in [0, 0.5].
The diffusion coefficient D is 0.05.
The initial condition is u(x,y,0) = exp(-80*((x-0.3)^2 + (y-0.7)^2)).
All four boundary edges have a zero-flux Neumann boundary condition, ∂u/∂n = 0.
The spatial domain is discretized with a uniform grid of Nx=80 intervals in x and Ny=80 intervals in y.
This results in 81x81 grid points.
The spatial discretization uses a 5-point finite difference stencil for the Laplacian.
The Neumann boundary conditions are implemented using a ghost-node approach.
The time integration is performed using the Implicit Euler method.
The time step is dt = 0.001.
The simulation runs until a final time T = 0.5.
The final solution u(x,y,T) is computed on the 81x81 grid.
A file named "solution_agent_diffusion_06.npz" is saved.
The NPZ file contains the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u at time T.
The shape of the solution array u in the NPZ file is (81, 81), corresponding to (len(y), len(x)).
The NPZ file also contains the scalar metadata T, dx, dy, and dt.
A heatmap or contour plot of the final solution u(x,y,T) is saved as "solution_agent_diffusion_06.png".
The minimum and maximum values of the final solution u are printed to the console.
The discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx*dy), is printed to the console.
The total mass M(t), calculated as the sum of u*dx*dy over the grid, is computed at t=0 and t=T.
The values M(0), M(T), and the relative change (M(T)-M(0))/M(0) are printed to the console.
