The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 0.02.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid spacing is dx = 1/Nx.
The grid points are x_j = j*dx for j=0,...,Nx-1.
The numerical method is Strang splitting for each time step.
The final time for the simulation is T=1.0.
First, calculate a provisional time step dt0 = 0.4 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
Each full time step from t to t+dt consists of three substeps.
Substep A is a diffusion half-step of duration dt/2.
Substep A is solved in Fourier space.
First, compute the discrete Fourier transform of u, u_hat = FFT(u).
The angular wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) is multiplied by exp(-nu*k^2*(dt/2)).
Compute the inverse Fourier transform of the updated u_hat to get the new u, taking the real part.
Substep B is an advection full-step of duration dt for the inviscid Burgers equation.
Substep B uses a finite-volume method with Rusanov flux.
The flux function is f(u) = 0.5*u^2.
For each interface between cell j (value u_left) and cell j+1 (value u_right), the numerical flux F is computed.
The local wave speed estimate is alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Each cell value u[j] is updated using the fluxes at its interfaces, F_plus and F_minus, with periodic indexing.
The update formula is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The solution array u is replaced by u_new after computing all updates for this substep.
Substep C is another diffusion half-step of duration dt/2, identical to Substep A.
The simulation runs for Nt time steps until the final time T=1.0.
