Task ID is pdebench_cns1d_eta0p01_periodic_smooth.
The PDE to solve is the 1D Compressible Navier-Stokes system without heat conduction.
The unknown fields are density rho(x,t), velocity v(x,t), and pressure p(x,t).
The conservative variables are U = [rho, m, E], where m = rho*v is the momentum and E = p/(Gamma-1) + 0.5*rho*v^2 is the total energy.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.5].
The final simulation time T is 0.5.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 0.01.
The bulk viscosity zeta is equal to eta, so zeta is 0.01.
Boundary conditions are periodic on x=-1 and x=1.
The initial condition for density is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial condition for velocity is v(x,0) = 0.1*cos(pi*x).
The initial condition for pressure is p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx=400 cells.
The cell width is dx = 2/Nx.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The initial cell averages are set by evaluating the continuous initial condition functions at the cell centers.
Evolve the cell averages of the conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below this value.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part of the equations.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x in each cell using a centered difference on the cell-centered velocity values.
Compute the viscous stress sigma = (zeta + 4/3*eta)*v_x in each cell.
Approximate sigma at cell interfaces by averaging the sigma values from the two neighboring cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
Approximate v at cell interfaces by averaging the v values from the two neighboring cells for use in the viscous energy flux term.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The CFL number is 0.8.
The time step dt is calculated at each step as dt = min(dt_conv, dt_visc).
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
Adjust the final time step to end the simulation exactly at T=0.5.
Implement periodic boundary conditions using ghost cells that wrap around the domain.
Compute the final solution rho(x,T), v(x,T), p(x,T) on the cell centers at T=0.5.
