The PDE to solve is u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u ).
The field to solve for is u(x,t).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The initial condition is u(x,0) = 1.0 + 0.2*sin(2*pi*x).
The diffusion coefficient is D = 0.01.
The parameter gamma is 1.0.
The potential function is U(x) = cos(2*pi*x).
The derivative of the potential is U'(x) = -2*pi*sin(2*pi*x).
The PDE will be solved using the method of lines.
A uniform periodic spatial grid will be used with Nx = 512 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_j = j*dx for j = 0, 1, ..., Nx-1.
The PDE is treated in conservative form u_t = D*u_xx - ∂_x(F), where the flux is F = (1/gamma)*U'(x)*u.
The diffusion term D*u_xx is discretized using a second-order central difference stencil.
The advection term ∂_x(F) is discretized using a first-order upwind finite-volume method.
The velocity for the upwind scheme, b(x) = U'(x)/gamma, is evaluated at the cell interfaces.
Time integration is performed using the explicit SSP-RK2 method.
A provisional time step is calculated as dt_prov = min(0.4*dx/max|b|, 0.2*dx^2/D), where max|b| is the maximum of |U'(x)/gamma| over the domain.
The number of time steps is Nt = ceil(T/dt_prov), where the final time T is 1.0.
The time step used for the simulation is dt = T/Nt.
The simulation will run until the final time T = 1.0.
