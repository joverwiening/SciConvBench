The PDE to solve is u_tt + 0.5*u_t = (1.0)^2 * u_xx.
The spatial domain is x in [0, 1].
The time domain is t in [0, 3.0].
The wave speed parameter c is 1.0.
The damping parameter gamma is 0.5.
The boundary condition at x=0 is Dirichlet with u=0.
The boundary condition at x=1 is Dirichlet with u=0.
The initial condition for the field is u(x,0) = sin(pi*x).
The initial condition for the field's time derivative is u_t(x,0) = 0.
The spatial domain is discretized into Nx=400 uniform intervals, resulting in 401 grid points.
The spatial second derivative u_xx is discretized using a 2nd-order central difference scheme.
The PDE is rewritten as a first-order system in time where v = u_t.
The system (u_t = v, v_t = c^2*u_xx - gamma*v) is integrated using the classical 4th-order Runge-Kutta method.
A fixed time step of dt=0.0005 is used for the integration.
At every RK4 sub-stage, u is set to 0 at the boundaries.
At every RK4 sub-stage, v is set to 0 at the boundaries.
The final solution u(x,T) is computed at T=3.0.
