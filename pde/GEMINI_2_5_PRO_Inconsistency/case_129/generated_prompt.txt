The PDE to solve is u_t = -k * ∂_x( (1/3) * u^3 ).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5 * sin(2 * pi * x).
The numerical grid is a uniform periodic grid with Nx=1024 points.
The grid spacing is dx = 1/Nx.
The grid points are x_j = j*dx for j=0, ..., Nx-1.
The spatial discretization is a conservative finite-volume method.
The numerical flux is the Rusanov flux for the physical flux F(u) = k * (1/3) * u^3.
The time integration scheme is the second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step is determined by a CFL condition with CFL=0.2.
The maximum wave speed for the CFL condition is calculated only once from the initial condition.
The maximum wave speed is estimated as max|F'(u(x,0))| = max|k * u(x,0)^2|.
The number of time steps is Nt = ceil(T/dt0), where T=0.2 and dt0 = CFL * dx / max|F'(u(x,0))|.
The final time step used is dt = T/Nt.
The final solution u(x,T) at T=0.2 is computed.
A file named "solution_molk_028.npz" is saved.
The NPZ file contains the 1D arrays 'x' and 'u', and the scalars 'T', 'dx', 'Nx', and 'k'.
A line plot of the final solution u(x,T) versus x is saved as "solution_molk_028.png".
The minimum, maximum, mean, and discrete L2 norm of the final solution u(x,T) are printed to the console.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
