Solve the partial differential equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 1.0].
The final time for the simulation is T=1.0.
The viscosity parameter nu is 0.1.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid spacing is dx=1/Nx.
The grid points are x_j = j*dx for j=0,...,Nx-1.
The numerical method is Strang splitting for each time step dt.
The first step is a diffusion half-step of duration dt/2 solved in Fourier space.
The Fourier space diffusion update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
The second step is an advection full-step of duration dt for the inviscid Burgers equation.
The advection step uses a finite-volume method with Rusanov flux.
The flux function is f(u) = 0.5*u^2.
The Rusanov flux between states u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed for the Rusanov flux is alpha = max(abs(u_left), abs(u_right)).
The finite volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell.
The third step is another diffusion half-step of duration dt/2, identical to the first step.
The time step dt is determined by a CFL condition.
The CFL number is 0.4.
The maximum wave speed for the CFL calculation is estimated as 1.0.
The number of time steps is Nt = ceil(T / (CFL*dx/1.0)).
The final time step used is dt = T/Nt.
Compute the solution u(x,T) at the final time T=1.0.
Save a file named "solution_pdebench_burgers_nu0p1.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'nu', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x as "solution_pdebench_burgers_nu0p1.png".
Print the minimum value of the final solution.
Print the maximum value of the final solution.
