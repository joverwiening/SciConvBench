Task ID is pdebench_reacdiff_nu10_rho5.
The PDE category is 1D Reaction–Diffusion with a logistic reaction term and periodic boundary conditions.
The unknown field to solve for is u(x,t).
The governing PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain for x is the interval [0, 1) with periodic boundaries.
The time domain for t is the interval [0, 1.0].
The diffusion coefficient nu is 10.0.
The reaction rate rho is 5.0.
The boundary condition is periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial domain is discretized using a uniform periodic grid with Nx=512 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time domain is discretized with a fixed time step dt=0.001.
The simulation will run for Nt=1000 steps to reach the final time T=1.0.
The time integration method is Strang splitting.
Each time step of duration dt consists of three sequential operations.
First, solve the diffusion equation for a half-step of dt/2 using a Fourier spectral method.
The Fourier half-step for diffusion is: u_hat = FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat = u_hat * exp(-nu*k^2*(dt/2)), u = real(IFFT(u_hat)).
Second, solve the reaction equation for a full-step of dt using the exact pointwise solution.
The exact update for the reaction step is: u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation for another half-step of dt/2 using the same Fourier spectral method as the first step.
The final solution u(x,T) at T=1.0 must be computed.
Save the results to a file named "solution_pdebench_reacdiff_nu10_rho5.npz".
The NPZ file must contain the 1D array 'x' of grid points, the 1D array 'u' of the final solution, and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu10_rho5.png".
Print the minimum, maximum, and mean values of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
