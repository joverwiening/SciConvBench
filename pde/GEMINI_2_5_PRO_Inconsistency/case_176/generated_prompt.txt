The PDE to solve is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 10.0.
The parameter rho is 1.0.
The boundary condition is periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A closed-form reference solution is not required.
The spatial grid is a uniform periodic grid with Nx=512 points.
The spatial grid points are defined as x_j = j*dx for j=0,...,Nx-1.
The spatial step size is dx = 1/Nx.
The time grid uses a fixed time step of dt=0.001.
The simulation will run for Nt=1000 steps to reach the final time T=1.0.
The numerical method is Strang splitting for each time step dt.
The first step of the splitting is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
The Fourier space update for the diffusion half-step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The second step of the splitting is a reaction full-step of duration dt, solved exactly pointwise.
The exact update for the logistic reaction step at each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third step of the splitting is another diffusion half-step of duration dt/2, identical to the first step.
The final solution u(x,T=1.0) on the spatial grid must be computed.
