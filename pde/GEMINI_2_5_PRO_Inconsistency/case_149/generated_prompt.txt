The PDE to solve is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter nu is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The final time is T=1.0.
The time step dt is determined by a CFL number of 0.4 and an estimated maximum speed of 1.0.
First, calculate an initial time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T/dt0).
The final time step used is dt = T/Nt.
The time integration method is Strang splitting.
Each time step from t to t+dt consists of three sub-steps.
First, solve the diffusion equation u_t = nu * u_xx for a half-step of dt/2 using a Fourier spectral method.
The diffusion half-step is performed by transforming u to Fourier space, multiplying by exp(-nu*k^2*(dt/2)), and transforming back.
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Second, solve the advection equation u_t + ∂_x(0.5*u^2) = 0 for a full step of dt.
The advection step uses a finite-volume method with a Rusanov flux.
The flux between cells with values u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u)=0.5*u^2.
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The cell update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), using periodic indexing.
Third, solve the diffusion equation u_t = nu * u_xx for another half-step of dt/2 using the same Fourier spectral method.
