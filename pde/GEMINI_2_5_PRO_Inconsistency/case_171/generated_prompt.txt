The PDE to solve is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The unknown field is u(x,y).
The spatial domain is (x,y) in (0,1) x (0,1).
The parameter beta is 100.0.
The coefficient field is defined as a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions, u = 0, on the entire boundary of the domain.
Use a uniform Cartesian grid with N=128 intervals in each spatial direction.
The grid will have N+1 points in each direction, including boundaries.
The grid spacing is dx = dy = 1/N.
The grid points are defined as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a 2nd-order finite difference scheme.
Use face-centered harmonic averaging for the variable coefficient a(x,y).
The discrete equation for interior nodes is -(1/dx^2) * [ a_ip_j*(u_ip1_j - u_i_j) - a_im_j*(u_i_j - u_im1_j) + a_i_jp*(u_i_jp1 - u_i_j) - a_i_jm*(u_i_j - u_i_jm1) ] = 1.
The face-centered coefficients are harmonic means, for example a_ip_j = 2*a_i_j*a_ip1_j / (a_i_j + a_ip1_j).
Assemble the sparse linear system Au=b for the interior unknown grid points.
Solve the linear system using the conjugate gradient (CG) method.
The CG solver must reach a relative residual tolerance of 1e-10.
A Jacobi preconditioner may be used with the CG solver.
Compute the solution u(x,y) on the full (N+1) x (N+1) grid, including the boundaries.
Save the output to a file named "solution_pdebench_darcy_beta100.npz".
The NPZ file must contain the 1D array 'x', the 1D array 'y', the 2D solution array 'u', and the scalars 'beta', 'N', and 'dx'.
Save a heatmap or contour plot of the solution u(x,y) to a file named "solution_pdebench_darcy_beta100.png".
Print the minimum value of the solution u to the console.
Print the maximum value of the solution u to the console.
Print the final relative residual norm ||Au-b||_2 / ||b||_2 for the interior system to the console.
