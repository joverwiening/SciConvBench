The PDE to solve is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The unknown field to solve for is u(x,y).
The spatial domain is (x,y) in (0,1) x (0,1).
The parameter beta is 2.
The coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The boundary condition is u = 0 on the entire boundary of the domain.
A closed-form reference solution is not required for verification.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 points per direction.
The grid spacing is dx = dy = 1/N.
The grid points are located at x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a 2nd-order finite difference scheme with face-centered harmonic averaging for the variable coefficient.
The discretized equation for interior nodes is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face coefficient a at (i+1/2, j) is calculated as 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknown values of u.
Solve the linear system using the conjugate gradient (CG) method.
The stopping criterion for the CG solver is when the relative residual norm, ||Au-b||_2 / ||b||_2, is less than 1e-10.
A Jacobi preconditioner may optionally be used to accelerate convergence.
The final solution u(x,y) must be computed on the full (N+1) x (N+1) grid, including the boundaries.
Save the output to a file named "solution_pdebench_darcy_beta1.npz".
The NPZ file must contain the 1D array 'x' of grid coordinates, the 1D array 'y' of grid coordinates, and the 2D array 'u' of the solution with shape (N+1, N+1).
The NPZ file must also contain the scalars 'beta', 'N', and 'dx'.
Save a heatmap or contour plot of the solution u(x,y) to a file named "solution_pdebench_darcy_beta1.png".
