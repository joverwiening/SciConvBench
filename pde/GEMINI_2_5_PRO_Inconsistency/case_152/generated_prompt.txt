Solve the partial differential equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain for x is [0, 1) with periodic boundaries.
The time domain for t is [0, 1.0].
The final time T for the simulation is 1.0.
The parameter nu is 0.002.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use Strang splitting for the time integration.
Each full time step dt consists of a diffusion half-step, an advection full-step, and a second diffusion half-step.
The diffusion half-step of duration dt/2 is solved exactly in Fourier space.
To perform the diffusion half-step, compute the forward FFT of u, multiply the k-th mode by exp(-nu*k^2*(dt/2)), and compute the real part of the inverse FFT of the result.
The wave numbers for the diffusion step are k = 2*pi*fftfreq(Nx, d=dx).
The advection full-step of duration dt solves u_t + ∂_x(0.5*u^2)=0 using a finite-volume method.
The finite-volume update uses the Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u)=0.5*u^2.
The Rusanov flux between a left state u_left and a right state u_right is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed alpha for the Rusanov flux is max(abs(u_left), abs(u_right)).
The finite-volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus is the flux at the right interface and F_minus is the flux at the left interface.
The time step dt is determined by a CFL condition.
The CFL number is 0.4.
The maximum wave speed for the CFL calculation is 1.0.
Calculate an initial time step dt0 = CFL*dx/1.0.
The number of time steps is Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
Compute the solution u(x,T) at the final time T=1.0.
Save the output to a file named "solution_pdebench_burgers_nu2em3.npz".
The NPZ file must contain the 1D array x of grid points, the 1D array u of the solution at T, and the scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_burgers_nu2em3.png".
Print the minimum value of the final solution.
Print the maximum value of the final solution.
Print the discrete mean value of the final solution, calculated as mean(u).
