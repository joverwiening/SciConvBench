Use N, mm, and MPa as the unit system throughout.
The specimen has an initial diameter d0 = 12.5 mm.
The specimen has an initial gage length L0 = 50 mm.
An axial load P = 15000 N is applied during the linear-elastic portion of the test.
The elongation over the gage length is ΔL = 0.15 mm.
Compute the original cross-sectional area A0 using d0.
Compute engineering stress σ = P / A0 using the original area.
Compute engineering strain ε = ΔL / L0 using the original gage length.
Determine the modulus of elasticity E = σ / ε from the slope of the stress-strain relationship.
