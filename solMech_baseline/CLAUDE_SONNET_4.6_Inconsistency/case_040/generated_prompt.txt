A simply supported beam has span L = 3000 mm.
The beam is made of structural steel with E = 200000 MPa and constant I = 1500000 mm^4.
A point load P = 2000 N is applied downward at midspan.
Use N, mm, and MPa as the unit system throughout.
Define M(x) piecewise over 0 ≤ x ≤ L using the actual bending moment field for a midspan point load on a simply supported beam.
Compute the strain energy U = ∫ M(x)^2 / (2EI) dx integrated over the full span 0 ≤ x ≤ L using the piecewise moment field.
Apply Castigliano's theorem by differentiating U with respect to P to obtain the vertical deflection at midspan.
Do not use the approximation of applying M = PL/4 over the full span.
