Use N–mm–MPa units throughout.
A solid circular shaft has diameter d = 45 mm.
The shaft is subjected to a bending moment M = 2000000 N·mm and a torque T = 500000 N·mm at a critical section.
Consider the stress state at the outer surface of the shaft at the location of maximum bending stress.

Part (a): Compute the maximum bending normal stress using σ = M·c / I, where c = d/2 and I = π·d^4 / 64.

Part (b): Compute the torsional shear stress using τ = T·c / J, where c = d/2 and J = π·d^4 / 32.

Part (c): Treat the surface stress state as plane stress with σx = σ (from bending), σy = 0, and τxy = τ (from torsion).
Compute the two principal stresses σ1 and σ2 using the standard plane-stress principal stress formula.
Compute the maximum in-plane shear stress using τmax = sqrt(((σx - σy)/2)^2 + τxy^2).
The torsional shear stress is included in the plane stress state for part (c) and is not set to zero.
