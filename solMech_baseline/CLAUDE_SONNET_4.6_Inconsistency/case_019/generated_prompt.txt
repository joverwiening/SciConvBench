Use N–mm–MPa units throughout.
A solid circular shaft has diameter d = 30 mm and total length L = 1200 mm.
The shaft is fixed at x = 0.
A torque T1 = 200000 N·mm is applied at the free end x = L = 1200 mm in the positive sense.
A torque T2 = -200000 N·mm is applied at x = 400 mm (negative sense, opposite direction).
The material is AISI 1020 steel with shear modulus G = 76923.1 MPa.
The shaft diameter is constant.
Take a single internal torque equal to the algebraic sum of the applied torques over the full length when computing both stress and twist.
Part (a): Construct the internal torque diagram, identifying the value in each segment (segment 1: x = 0 to x = 400 mm, segment 2: x = 400 mm to x = 1200 mm).
Part (b): Compute the maximum shear stress in each segment using τ = T·c / J, where c = d/2 and J = π·d⁴/32.
Part (c): Compute the angle of twist at x = L relative to the fixed end by summing the twist of each segment using φ = T·L_seg / (G·J).
