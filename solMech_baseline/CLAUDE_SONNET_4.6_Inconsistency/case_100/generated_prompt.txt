Use N, mm, and MPa as the unit system throughout.
Assume linear elastic isotropic behavior.
The rod is a brass rod with initial diameter d0 = 30 mm and length L = 500 mm.
An axial tensile load P = 25000 N is applied through the centroid.
Use Young's modulus E = 105000 MPa and Poisson's ratio ν = 0.34.
The rod is free (uniaxial stress state); there is no plane-strain constraint.
Compute (i) the average axial normal stress using σ = P/A, where A = π·d0²/4.
Compute (ii) the axial strain using ε_axial = σ/E.
Compute (iii) the lateral (diametral) strain using ε_lateral = −ν × ε_axial.
Compute (iv) the change in diameter using Δd = ε_lateral × d0.
