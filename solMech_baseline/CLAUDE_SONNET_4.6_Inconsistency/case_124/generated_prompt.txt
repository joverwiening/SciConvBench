Use N–mm–MPa units throughout.
The shaft is linearly elastic and has a solid circular cross section.
Material is AISI 1020 steel.
Shaft diameter d = 30 mm.
Shaft length L = 1000 mm.
Applied torque T = 250000 N·mm.
Use the polar second moment of area J = π d^4 / 32.
Compute maximum shear stress using τ_max = T c / J, where c = d / 2.
Compute the angle of twist using φ = T L / (J G), with G = 76923.1 MPa.
Report the maximum shear stress in MPa.
Report the angle of twist φ in degrees.
Do not use the bending second moment I = π d^4 / 64 in any torsion relation; use J = π d^4 / 32 exclusively.
