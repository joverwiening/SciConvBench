Solve a statically determinate torsion problem for a solid circular shaft using N–mm–MPa units.

Shaft properties: solid circular cross-section, diameter d = 40 mm, total length L = 1500 mm.
The shaft is fixed at x = 0 (cantilever).
Material is 6061-T6 aluminum with shear modulus G = 25939.8 MPa.

Applied torques:
- T1 = +300000 N·mm applied at the free end x = 1500 mm.
- T2 = -150000 N·mm applied at the midpoint x = 750 mm.

Segment definitions:
- Segment 1: from x = 0 to x = 750 mm (call it 0→a).
- Segment 2: from x = 750 mm to x = 1500 mm (call it a→L).

Special instruction: because the shaft diameter is constant, take a single internal torque equal to the algebraic sum of all applied torques over the full length when computing both stress and twist (do not use equilibrium cut-by-cut; use the net sum).

Part (a): Construct the internal torque in each segment (0→a and a→L).
Part (b): Compute the maximum shear stress in each segment using τ = Tc/J, where c = d/2 and J = πd⁴/32.
Part (c): Compute the angle of twist at x = L relative to the fixed end by summing the twist of each segment using φ = TL/(GJ), then sum the two segment contributions.
