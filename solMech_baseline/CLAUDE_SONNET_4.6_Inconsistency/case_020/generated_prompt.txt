Use N–mm–MPa units throughout.
A solid circular shaft has diameter d = 35 mm and total length L = 1200 mm.
The shaft is fixed at x = 0.
A torque T1 = 200000 N·mm is applied at the free end x = L = 1200 mm in the positive sense.
A torque T2 = -250000 N·mm is applied at x = 800 mm in the negative sense.
The material has shear modulus G = 77519.4 MPa.
The shaft diameter is constant throughout.
Use a single internal torque equal to the algebraic sum of the applied torques over the full length when computing both stress and twist.
Part (a): Construct the internal torque diagram, identifying the value in each segment: segment 1 from x = 0 to x = 800 mm, and segment 2 from x = 800 mm to x = 1200 mm.
Part (b): Compute the maximum shear stress in each segment using τ = T·c / J, where c = d/2 and J = π·d⁴/32.
Part (c): Compute the angle of twist at x = L relative to the fixed end by summing the twist of each segment using φ = T·L_seg / (G·J).
