Use N, mm, and MPa as the unit system throughout.

A solid circular shaft has diameter d = 25 mm.

It carries an axial tensile force P = 25000 N and a torque T = 300000 N·mm applied simultaneously.

Part (a): Compute the average axial stress using σ = P/A, where A = π d² / 4.

Part (b): Compute the torsional shear stress at the outer surface using τ = T·c / J, where c = d/2 and J = π d⁴ / 32.

Part (c): Using a plane stress state with σx = σ (from part a), σy = 0, and τxy = τ (from part b), compute the two principal stresses and the maximum in-plane shear stress using the standard plane-stress principal stress formulas.

The torsional shear stress τ is included in the principal stress calculation in part (c) and is not set to zero.
