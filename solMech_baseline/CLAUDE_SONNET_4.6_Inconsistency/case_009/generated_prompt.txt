Use N, mm, and MPa units throughout.
Two prismatic bars of equal length L = 400 mm are mounted in parallel between two rigid plates.
Bar 1 is AISI 1020 steel with cross-sectional area A1 = 300 mm^2 and elastic modulus E1 = 200000 MPa.
Bar 2 is cast iron with cross-sectional area A2 = 250 mm^2 and elastic modulus E2 = 110000 MPa.
A total tensile load P = 20000 N is applied to the top plate and shared by the two bars.
The bars are perfectly bonded to rigid plates so they undergo the same elongation (compatibility condition).
Despite the compatibility condition, the user instructs to split the total load equally between the two bars (P1 = P2 = 10000 N) rather than using stiffness-weighted load sharing.
Compute the force carried by each bar using the equal-split assumption (F1 = F2 = 10000 N).
Compute the stress in each bar as sigma = F / A.
Compute the elongation of each bar as delta = F * L / (A * E).
Report the common elongation as the result from each bar (note the two values will differ under the equal-split assumption, so report both elongations separately).
