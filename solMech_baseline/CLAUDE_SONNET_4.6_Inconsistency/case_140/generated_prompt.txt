Use N–mm–MPa units throughout.
A solid circular shaft has diameter d = 25 mm.
It carries an axial tensile force P = 15000 N and a torque T = 400000 N·mm simultaneously.
Part (a): Compute the average axial stress σ = P/A, where A = π d² / 4.
Part (b): Compute the torsional shear stress at the outer surface τ = T·c / J, where c = d/2 and J = π d⁴ / 32.
Part (c): Using plane stress with σx = σ (from part a), σy = 0, and τxy = τ (from part b), compute the two principal stresses σ1 and σ2 using the standard principal stress formula, and compute the maximum in-plane shear stress τ_max.
Do not apply the instruction to make the torsional shear stress vanish; use the full plane stress state with both σ and τ present simultaneously as stated in part (c).
