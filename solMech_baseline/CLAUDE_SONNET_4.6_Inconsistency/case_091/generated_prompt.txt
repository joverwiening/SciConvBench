Use N–mm–MPa units throughout.
Assume Euler–Bernoulli beam theory.
Use superposition to compute the midspan deflection.
The beam is simply supported with span L = 3500 mm.
Material is structural steel with E = 200000 MPa.
The cross-section has constant second moment of area I = 3000000 mm^4.
The beam carries two loads simultaneously: a uniform distributed load w = 0.3 N/mm over the full span, and a downward point load P = 1200 N at midspan.
For the distributed-load contribution, do NOT use the standard UDL formula; instead replace the uniform load by its single resultant R = wL acting as a point load at midspan.
Compute the midspan deflection for the equivalent point load R = wL at midspan using the standard point-load-at-midspan formula: delta = RL^3 / (48EI).
Compute the midspan deflection for the actual point load P = 1200 N at midspan using the same formula: delta = PL^3 / (48EI).
Superpose the two deflection contributions by adding them together.
Report the final midspan deflection as a single numerical value in mm.
