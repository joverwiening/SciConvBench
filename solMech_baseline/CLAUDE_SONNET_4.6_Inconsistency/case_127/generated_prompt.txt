Use N, mm, and MPa as the unit system throughout.
The cross section is rectangular with width b = 60 mm and height h = 100 mm.
The cross-sectional area is A = b × h = 6000 mm².
The internal normal force is P = 40000 N (tension).
The internal shear force is V = 16000 N, acting parallel to the width direction.
Compute the average normal stress as σ = P/A.
Compute the average shear stress as τ = V/A.
Treat the stress state as plane stress with σ_x = σ, σ_y = 0, and τ_xy = τ.
Use the plane stress principal stress formula: σ₁,₂ = (σ_x + σ_y)/2 ± sqrt(((σ_x − σ_y)/2)² + τ_xy²).
Compute both principal stresses σ₁ and σ₂.
Compute the maximum in-plane shear stress as τ_max = sqrt(((σ_x − σ_y)/2)² + τ_xy²).
Report all results in MPa.
