Use the N–mm–MPa unit system throughout.
Given power P = 10 kW, convert to P = 10,000,000 N·mm/s.
Given rotational speed n = 1800 rpm, compute angular speed as ω = 2π(n/60) in rad/s.
Compute transmitted torque T from P = T·ω and report T in N·mm.
Use a solid circular shaft with diameter d = 35 mm and length L = 1000 mm.
Use polar moment of inertia J = (π d^4)/32 with d in mm so J is in mm^4.
Compute maximum shear stress using τ_max = (T c)/J with c = d/2 and report τ_max in MPa.
Use shear modulus G = 76923.1 MPa.
Compute angle of twist using θ = (T L)/(J G) and report θ in radians.
Assume the shaft transmits the computed torque uniformly along the full length L for stress and twist calculations.
