Use N–mm–MPa units throughout.
Assume linear elastic isotropic material behavior with E = 200000 MPa and ν = 0.29.
Given a structural steel rod with initial diameter d0 = 25 mm and length L = 1200 mm.
Apply an axial tensile load P = 45000 N through the centroid.
Compute (i) the average axial normal stress using engineering stress with the original area A0 = (π d0^2)/4 and σavg = P/A0.
Compute (ii) the axial strain using the uniaxial relation εx = σx/E with σx taken as the average axial stress from (i).
Compute (iii) the lateral (diametral) strain using the standard uniaxial Poisson relation εlat = −ν εx (do not set lateral strain to zero).
Compute (iv) the change in diameter using Δd = εlat d0.
Report final numeric answers to 3 significant figures.
