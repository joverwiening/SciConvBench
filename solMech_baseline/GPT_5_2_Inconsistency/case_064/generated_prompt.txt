Use N–mm–MPa units throughout.
Assume the shaft is linearly elastic and has a circular solid cross section.
Given a brass shaft with diameter d = 18 mm and length L = 400 mm transmitting torque T = 500000 N·mm.
Use the standard torsion polar moment for a solid circular shaft: J = π d^4/32.
Compute maximum shear stress using τ_max = T c / J with c = d/2.
Compute angle of twist using φ = T L / (J G) with G = 39179.1 MPa.
Report φ in degrees.
Use π = 3.14159 (or an equivalent built-in π constant).
Round results to 3 significant figures for both τ_max (MPa) and φ (degrees).
