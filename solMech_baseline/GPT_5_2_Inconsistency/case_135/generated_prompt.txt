Work in N–mm–MPa units.
Use a rectangular cross section with width b = 40 mm and height h = 120 mm.
At the cross section, use internal resultant normal force P = 30000 N in tension.
At the cross section, use internal resultant transverse shear force V = 12000 N acting parallel to width b.
Use the full rectangular cross-sectional area for averages: A = b h = 4800 mm^2.
Assume uniform stress distributions and use average values for both normal stress and shear stress.
Compute average normal stress as σ_avg = P/A.
Compute average shear stress as τ_avg = V/A.
Because both resultants act over the same area, take the maximum in-plane shear to be based on these average stresses.
Compute the magnitude of the maximum in-plane shear stress using τ_max = sqrt((σ_avg/2)^2 + τ_avg^2).
Report σ_avg, τ_avg, and τ_max in MPa (N/mm^2).
