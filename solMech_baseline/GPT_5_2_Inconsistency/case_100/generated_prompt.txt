Use N–mm–MPa units throughout.
Assume linear elastic isotropic material behavior with E = 105000 MPa and ν = 0.34.
Model the rod as a free uniaxially loaded member with σx = σy = 0.
Given d0 = 30 mm, L = 500 mm, and axial tensile load P = 25000 N applied through the centroid.
Compute (i) the average (engineering) axial normal stress using the original area A0 = π d0^2 / 4 and σavg = P / A0.
Compute (ii) the axial (engineering) strain using Hooke’s law εax = σavg / E.
Compute (iii) the lateral (diametral) strain using εlat = −ν εax and report it as negative in tension.
Compute (iv) the change in diameter using Δd = εlat d0, which will be negative for a decrease in diameter.
