Use N–mm–MPa units throughout.
Assume the shaft is linearly elastic with a solid circular cross section.
Given diameter d = 30 mm and length L = 1200 mm.
Given constant applied torque along the full length: T = 400000 N·mm.
Compute the polar moment of inertia using J = π d^4 / 32.
Compute maximum shear stress using τ_max = T c / J with c = d/2.
Report τ_max in MPa.
Compute angle of twist using φ = T L / (J G).
Use shear modulus G = 39179.1 MPa.
Report φ in degrees.
Report φ to a reasonable precision (about 2–3 decimal places).
Do not substitute the bending second moment I = π d^4 / 64 for J in any calculation.
