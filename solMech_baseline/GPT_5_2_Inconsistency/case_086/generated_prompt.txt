Use N–mm–MPa units and assume linear-elastic behavior.
Model a stepped circular structural-steel bar fixed at the left end and loaded in tension at the right end by P = 25000 N.
Use segment 1 (left): L1 = 400 mm, d1 = 16 mm.
Use segment 2 (right): L2 = 400 mm, d2 = 40 mm.
Use Young’s modulus E = 200000 MPa.
Assume the same axial force P passes through both segments.
Compute normal stress separately in each segment using σ1 = P/A1 and σ2 = P/A2 with Ai = (π di^2)/4.
Compute each segment elongation using δi = (P Li)/(Ai E).
Compute total elongation as δ = δ1 + δ2.
Report (i) σ1 and σ2, and (ii) δ between the fixed end and the load application point.
