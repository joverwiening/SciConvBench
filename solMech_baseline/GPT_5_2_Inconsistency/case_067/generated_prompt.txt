Use N–mm–MPa units throughout.
Assume the shaft is linearly elastic and has a solid circular cross section.
Given a 6061-T6 aluminum shaft with diameter d = 30 mm and length L = 800 mm transmitting torque T = 500000 N·mm.
Use the polar moment of inertia J = π d^4/32.
Compute the maximum shear stress using τ_max = T c / J with c = d/2.
Report τ_max in MPa.
Compute the angle of twist over the length using φ = T L / (J G) with G = 25939.8 MPa.
Report φ in degrees.
Use reasonable best-practice rounding for φ (about 2–3 decimal places).
Provide only the J-based results and do not include any I-based torsion calculations.
