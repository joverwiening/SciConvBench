Use N–mm–MPa units.
Assume linear elastic isotropic behavior with E = 200000 MPa and ν = 0.30.
Given an AISI 1020 steel rod with initial diameter d0 = 20 mm and length L = 1200 mm.
Apply an axial tensile load P = 35000 N through the centroid.
Compute (i) the average axial normal stress as engineering stress using the original area A0 = π d0^2 / 4 and σ = P / A0.
Compute (ii) the axial strain as engineering strain using Hooke’s law εax = σ / E.
Compute (iii) the lateral (diametral) strain using εlat = −ν εax.
Compute (iv) the change in diameter using Δd = εlat d0.
Do not assume plane strain; do not set lateral strain to zero.
