Use N–mm–MPa units throughout.
Assume linear elastic isotropic material behavior for 6061-T6 aluminum with E = 69000 MPa and ν = 0.33.
Model the rod as a circular cylinder with initial diameter d0 = 40 mm and length L = 500 mm.
Apply an axial tensile load P = 35000 N through the centroid along the z-axis.
Treat the “plane strain in the two transverse directions” statement as irrelevant/mistaken for this problem.
Assume free lateral surfaces so σx = σy = 0 (uniaxial stress state).
Compute (i) the average axial normal stress as σz = P/A using A = π d0^2 / 4.
Compute (ii) the axial strain as εz = σz / E.
Compute (iii) the lateral (diametral) strain as εx = εy = −ν εz.
Compute (iv) the change in diameter as Δd = εx d0 (equivalently εy d0).
