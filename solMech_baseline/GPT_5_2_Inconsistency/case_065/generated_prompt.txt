Use N–mm–MPa units throughout.
Assume the shaft is linearly elastic with a solid circular cross section.
Given a solid circular shaft of AISI 1020 steel with diameter d = 45 mm and length L = 1000 mm transmitting torque T = 400000 N·mm.
Use the bending second moment I = π d^4/64 in the torsion relations for both shear stress and twist.
Also use J = π d^4/32 and τ_max = T c / J with c = d/2 to determine the maximum shear stress.
Report the maximum shear stress in MPa.
Compute the angle of twist over the length using φ = TL/(JG) with G = 76923.1 MPa.
Report φ in degrees.
Use reasonable rounding best practices for final reported values (about 2–3 decimal places for degrees and about 3 significant figures overall where appropriate).
