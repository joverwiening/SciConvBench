Use N–mm–MPa units throughout.
Assume the shaft is linearly elastic and has a solid circular cross section.
Given diameter d = 50 mm.
Given length L = 600 mm.
Given constant applied torque along the entire length T = 500000 N·mm with no variation and no additional loads.
Use π = 3.1416 consistently.
Compute the maximum shear stress using J = π d^4/32, c = d/2, and τ_max = T c / J.
Compute the angle of twist using φ = T L / (J G) with J = π d^4/32 and G = 77519.4 MPa.
Report φ in degrees.
Do not use I = π d^4/64 for the twist calculation.
