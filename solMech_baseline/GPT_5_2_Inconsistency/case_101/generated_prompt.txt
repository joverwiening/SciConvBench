Use the N–mm–MPa unit system throughout.
Assume the bar is vertical, prismatic, and linearly elastic.
Given L = 3000 mm.
Given A = 300 mm^2.
Given E = 69000 MPa.
Given mass density ρ = 8900 kg/m^3.
Given g = 9.81 m/s^2.
Ignore external loads and include only self-weight.
Convert ρg to a consistent weight density in N/mm^3 using ρg = 87309 N/m^3 = 8.7309×10^-5 N/mm^3.
Measure x downward from the top.
Use the distributed-force axial force function P(x) = ρ g A (L − x).
Compute elongation using δ = ∫₀ᴸ P(x)/(A E) dx.
Report the elongation in millimeters (mm).
Round the final elongation to three decimal places (0.001 mm).
