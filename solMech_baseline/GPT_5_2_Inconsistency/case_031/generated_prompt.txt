Use the N–mm–MPa unit system.
Model a vertical, prismatic, linearly elastic bar with length L = 3500 mm, area A = 200 mm^2, and modulus E = 69000 MPa.
Include only self-weight with gravitational acceleration g = 9.81 m/s^2.
Use density ρ = 8.90×10^-6 kg/mm^3.
Measure x downward from the top.
Use the distributed self-weight axial force P(x) = ρ g A (L − x).
Compute elongation using δ = ∫₀ᴸ P(x)/(A E) dx.
Do not use a single concentrated end-load approximation.
Be careful with unit conversions between m and mm.
Report the final elongation δ in mm.
