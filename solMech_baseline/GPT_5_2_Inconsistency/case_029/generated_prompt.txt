Use N–mm–MPa units.
Assume linear elastic isotropic behavior.
A brass rod has initial diameter d0 = 20 mm and length L = 1000 mm.
Apply an axial tensile load P = 25000 N through the centroid.
Use E = 105000 MPa.
Use Poisson’s ratio ν = 0.34.
Compute (i) the average axial normal (engineering) stress using σ = P/A0 with A0 = (π d0^2)/4.
Compute (ii) the axial strain using εx = σ/E.
Compute (iii) the lateral (diametral) strain using εlat = −ν εx.
Compute (iv) the change in diameter using Δd = εlat d0.
Do not set the lateral (diametral) strain to zero.
