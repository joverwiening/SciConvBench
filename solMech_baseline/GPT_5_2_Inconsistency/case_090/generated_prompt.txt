Use N–mm–MPa units throughout.
Model a beam of span L = 3000 mm with simple supports at x = 0 and x = L.
Enforce boundary conditions for simple supports: deflection v(0) = 0 and v(L) = 0 with free rotation at both ends.
Use AISI 1020 steel with E = 200000 MPa and second moment of area I = 1200000 mm^4, both constant along the span.
Apply a real point load P = 800 N downward at x = 2000 mm.
Compute the deflection at x = 2000 mm using the unit-load (virtual work) method.
Use the virtual work integral δ = ∫(0→L) (M(x)·m(x))/(E I) dx.
Define M(x) as the real bending moment diagram from the 800 N load.
Define m(x) as the bending moment diagram from an auxiliary system consisting of a unit vertical force of 1 N downward applied at x = 2000 mm.
Use the sign convention that sagging bending moment is positive and hogging is negative for both M(x) and m(x).
Report deflection as a signed value with downward deflection taken as negative and upward as positive.
Assume Euler–Bernoulli bending only with no shear deformation effects.
Report the final deflection at x = 2000 mm in mm rounded to 3 decimal places.
