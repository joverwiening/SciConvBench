Use the N–mm–MPa unit system throughout.
Model a simply supported beam with span L = 3000 mm.
Use structural steel with E = 200000 MPa.
Use a constant second moment of area I = 1500000 mm^4.
Apply a downward point load P = 2000 N at midspan.
Define the bending moment function M(x) piecewise over 0 ≤ x ≤ L for a simply supported beam with a midspan point load.
Form the bending strain energy as U = ∫_0^L M(x)^2/(2EI) dx using the piecewise M(x).
Compute the vertical deflection at midspan using Castigliano’s theorem as δ_mid = ∂U/∂P treating P as the variable load.
Do not treat M(x) as a constant equal to PL/4 over the full span.
Report the final midspan deflection in millimeters (mm).
