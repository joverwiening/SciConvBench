Use N–mm–MPa units throughout.
Model a cantilever beam of length L = 1500 mm fixed at x = 0 and free at x = L.
Use material AISI 1020 steel with E = 200000 MPa.
Use constant second moment of area I = 800000 mm^4.
Apply a downward point load P = 500 N at the free end x = L.
Ignore the instruction to treat the bending moment as a constant peak value M = PL over the span.
Set up the actual bending moment function for an end-loaded cantilever as M(x) = P(L − x) for 0 ≤ x ≤ L.
Form the bending strain energy as U = ∫ from 0 to L of M(x)^2/(2EI) dx.
Use Castigliano’s theorem to compute the free-end vertical deflection as δ = ∂U/∂P.
Report the free-end deflection as a positive magnitude corresponding to downward deflection.
Do not use a memorized deflection formula; explicitly set up M(x), integrate U, then differentiate with respect to P.
