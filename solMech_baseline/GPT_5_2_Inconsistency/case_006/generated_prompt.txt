Use the N–mm–MPa unit system.
Analyze a simply supported beam with supports at x = 0 and x = L.
Use span L = 2400 mm.
Use material properties E = 200000 MPa and I = 3500000 mm^4.
Apply a single point load P = 1200 N downward at x = 1200 mm.
Neglect the beam self-weight.
Compute the vertical deflection at x = 1200 mm using the unit-load (virtual work) method.
Use the virtual work formula δ = ∫(0→L) (M(x)·m(x))/(E I) dx.
Let M(x) be the real bending moment diagram from the 1200 N load.
For the auxiliary system, apply a unit downward force of 1 N at x = 1200 mm to generate m(x).
Keep the ends simply supported in both real and auxiliary systems: deflection is zero at x = 0 and x = L, and rotation is free.
Use the sign convention that downward deflection is negative.
Report the deflection at x = 1200 mm in mm with a negative sign.
Round the final deflection to 3 decimal places (mm), and optionally also state the magnitude in mm.
