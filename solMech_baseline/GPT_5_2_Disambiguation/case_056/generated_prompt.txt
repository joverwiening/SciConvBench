Assume small-deformation, linear-elastic axial bar behavior.
Use a bar of length L = 800 mm with linearly varying cross-sectional area A(x) = A0(1 + k x/L) for 0 ≤ x ≤ L.
Use A0 = 250 mm^2 and k = 0.8 with x measured from the left end.
Apply a constant tensile axial force P = 30,000 N.
Use Young’s modulus E = 200,000 MPa in consistent N–mm–MPa units.
Impose the displacement boundary condition u(0) = 0 as the reference.
Compute only the total elongation δ = u(L) − u(0).
Evaluate δ using δ = ∫0^L P/(A(x)E) dx.
Show the symbolic integral form if desired, but report the final elongation δ numerically.
