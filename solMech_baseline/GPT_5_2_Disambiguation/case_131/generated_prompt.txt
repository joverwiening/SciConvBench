Assume small-deformation, linear-elastic solid mechanics.
Use a rectangular cross section with width b = 40 mm and height h = 120 mm.
Use cross-sectional area A = b·h = 4800 mm².
Apply an axial tensile force P = 40,000 N.
Apply a transverse shear force V = 8,000 N acting parallel to the width.
Model the stress state as uniform average plane stress at a point.
Set σx = P/A.
Set σy = 0.
Set τxy = +V/A using the convention that positive τxy acts on the +x face in the +y direction (and on the +y face in the +x direction).
Set σz = 0, τxz = 0, and τyz = 0.
Compute the combined plane-stress response quantities from σx, σy, and τxy.
Compute principal stresses from the plane-stress transformation relations.
Compute maximum in-plane shear stress from the plane-stress transformation relations.
Do not compute principal strains numerically.
Do not assume or use material properties for numerical strain results.
