Assume small-deformation, linear-elastic solid mechanics.
Model a prismatic, homogeneous, isotropic solid circular shaft under pure Saint-Venant torsion with constant torque and no transverse shear force.
Use N–mm–MPa consistent units.
Given shaft length L = 600 mm.
Given shaft diameter d = 50 mm with radius c = 25 mm.
Given applied torque T = 500,000 N·mm applied uniformly along the shaft.
Given shear modulus G = 77,519.4 MPa.
Determine the relevant response quantities: maximum shear stress at the outer surface and the angle of twist.
Compute maximum shear stress at r = c using τ_max = T c / J.
Use polar moment of inertia for a solid circular shaft J = π d^4 / 32.
Compute angle of twist using φ = T L / (J G).
Report the angle of twist in degrees.
