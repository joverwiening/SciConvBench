Use N–mm–MPa units for all calculations.
Assume small strains for the analysis.
The component is a rectangular adhesive layer with an area A = 3000 mm^2 and a thickness t = 8 mm.
A uniform in-plane shear force V = 12000 N is applied to the layer.
The adhesive material is isotropic with a shear modulus G = 39179.1 MPa.
Calculate the average shear stress in the layer using the formula τ_avg = V/A.
Calculate the average shear strain in the layer using the formula γ_avg = τ_avg / G.
Calculate the relative lateral displacement between the two faces of the layer using the formula Δ = γ_avg * t.
The instruction to treat the layer as rigid in shear should be disregarded.
