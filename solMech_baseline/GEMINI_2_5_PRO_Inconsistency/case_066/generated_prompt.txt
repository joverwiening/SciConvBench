Use the N-mm-MPa system of units.
Assume the shaft is linearly elastic and has a solid circular cross-section.
The shaft diameter is d = 35 mm.
The shaft length is L = 400 mm.
The transmitted torque is T = 250000 N·mm.
The shear modulus is G = 77519.4 MPa.
Use the polar moment of inertia J = π d^4 / 32 for all calculations.
Determine the maximum shear stress using the formula τ_max = T * c / J, with c = d/2.
Compute the angle of twist over the length using the formula φ = T * L / (J * G).
Report the angle of twist φ in degrees.
