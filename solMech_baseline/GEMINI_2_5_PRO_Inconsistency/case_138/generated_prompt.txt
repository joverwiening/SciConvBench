Use N, mm, and MPa as the system of units.
The analysis is for a solid circular shaft with a diameter of 35 mm.
The shaft is subjected to a bending moment of 3,000,000 N·mm and a torque of 500,000 N·mm.
The analysis focuses on the stress state at the outer surface at the location of maximum bending stress.
Compute the maximum bending normal stress (σ) using the formula σ = M * c / I, where c = d/2 and I = π * d^4 / 64.
Compute the torsional shear stress (τ) at the surface using the formula τ = T * c / J, where c = d/2 and J = π * d^4 / 32.
Treat the surface stress state as plane stress.
For the plane stress calculation, set the normal stress in the x-direction (σx) equal to the bending stress (σ) from the first calculation.
For the plane stress calculation, set the normal stress in the y-direction (σy) to 0.
For the plane stress calculation, set the shear stress (τxy) equal to the torsional shear stress (τ) from the second calculation.
Using this plane stress state, compute the principal stresses.
Using this plane stress state, compute the maximum in-plane shear stress.
The initial instruction to take the torsional shear stress as vanishing for the principal stress calculation should be ignored.
