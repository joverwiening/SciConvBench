Compute the Euler critical buckling load P_cr for a straight column made of AISI 1020 steel with length L = 2000 mm, modulus E = 200000 MPa, and moment of inertia I = 1200000 mm^4. Use the effective length factor K = 0.7 for the fixed‑pinned end condition. Evaluate the Euler load using the formula P_cr = π^2 E I / (K L)^2. Report the result in newtons (N) and in kilonewtons (kN). Use three significant figures for the value in N and round to the nearest kilonewton for the value in kN. Use the N–mm–MPa unit system throughout.
