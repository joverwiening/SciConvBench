Use N–mm–MPa units.  
Assume the shaft is linearly elastic and has a circular solid cross section.  
A solid circular shaft made of brass has diameter d = 30 mm and length L = 1200 mm.  
It transmits a torque T = 400000 N·mm.  
Use the bending second moment I = π d^4/64 in the torsion relations for both shear stress and twist.  
Using J = π d^4/32 and τ_max = T c / J (with c = d/2), determine the maximum shear stress in the shaft.  
Also compute the angle of twist over the length, φ = TL/(J G), using G = 39179.1 MPa.  
Report φ in degrees.
