Use N–mm–MPa units throughout the calculations.  
Consider a solid circular shaft with diameter d = 30 mm.  
The shaft is subjected to a bending moment M = 4,000,000 N·mm and a torque T = 400,000 N·mm at a critical section.  
Compute the maximum bending normal stress at the outer surface using σ = M c / I, where I = π d⁴ / 64 and c = d / 2.  
Compute the torsional shear stress at the outer surface using τ = T c / J, where J = π d⁴ / 32.  
Treat the surface stress state as plane stress with σₓ equal to the bending normal stress, σ_y = 0, and τ_xy equal to the torsional shear stress.  
Compute the principal stresses from this plane‑stress state.  
Compute the maximum in‑plane shear stress from this plane‑stress state.  
Report all final stress values in MPa, rounded to two decimal places.
