Compute the average axial stress σ = P/A for a solid circular shaft with diameter d = 25 mm carrying an axial tensile force P = 25000 N.  
Compute the torsional shear stress τ = T c / J at the outer surface for the same shaft subjected to a torque T = 300000 N·mm, where c = d/2 and J = π d⁴/32.  
Using plane‑stress conditions (σₓ = σ, σ_y = 0, τ_xy = τ), calculate the two principal stresses and the maximum in‑plane shear stress.  
Report all computed results in N–mm–MPa units with three significant figures.
