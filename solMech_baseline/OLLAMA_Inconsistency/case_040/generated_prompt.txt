Use N‑mm‑MPa units throughout the calculation.  
The beam span is L = 3000 mm, made of structural steel with Young’s modulus E = 200000 MPa and constant second moment of area I = 1500000 mm⁴.  
A vertical point load P = 2000 N is applied downward at the midspan (x = L/2).  
Define the bending moment distribution piecewise: for 0 ≤ x ≤ L/2, M(x) = P x / 2; for L/2 ≤ x ≤ L, M(x) = P (L − x) / 2.  
Form the bending strain‑energy integral U = ∫₀ᴸ [M(x)² / (2 E I)] dx using the piecewise M(x).  
Apply Castigliano’s theorem: the vertical deflection at midspan δ = ∂U/∂P.  
Report the vertical deflection at midspan as a positive magnitude in millimetres, rounded to three decimal places, and note that the deflection is downward.
