Use N–mm–MPa units. The beam is simply supported with span L = 3000 mm, modulus E = 200000 MPa, moment of inertia I = 3000000 mm⁴, and a downward point load P = 2000 N applied at midspan. Define the bending moment distribution M(x) piecewise over 0 ≤ x ≤ L: for 0 ≤ x ≤ L/2, M(x) = P·x / 2; for L/2 ≤ x ≤ L, M(x) = P·(L − x) / 2. Compute the strain energy U = ∫₀ᴸ [M(x)² / (2 E I)] dx. Apply Castigliano’s theorem by differentiating U with respect to P to obtain the vertical deflection at midspan. Report the deflection as a positive magnitude in millimetres, noting that it corresponds to a downward displacement, using a reasonable number of decimal places (e.g., three).
