Compute the Euler critical buckling load P_cr for a straight column of structural steel with length L = 2000 mm. Use the given flexural rigidity EI where E = 200000 MPa and I = 800000 mm⁴. Apply fixed–fixed end conditions with an effective length factor K = 0.5. Evaluate the Euler load using the expression π² E I / L² for the mode shape. Compute the critical load as P_cr = π² E I / (K L)². Report the resulting P_cr in newtons (N) and in kilonewtons (kN). Round both reported values to three significant figures, which for the kN value is equivalent to rounding to the nearest kilonewton. Use the N–mm–MPa unit system throughout.
