Determine the required height h of a rectangular simply supported beam with width b = 60 mm that must resist a maximum bending moment M = 6 kN·m while keeping the bending stress below the allowable value σ_allow = 170 MPa. Assume small‑deformation, linear‑elastic behavior. Use the bending stress relation σ = M·c/I, where c = h/2 and I = b·h³/12, which gives the section modulus S = b·h²/6. Set the required section modulus S_req = M/σ_allow and solve for h. Present the calculated beam height and state any additional assumptions made (e.g., material isotropy, neglect of shear deformation, no axial loads).
