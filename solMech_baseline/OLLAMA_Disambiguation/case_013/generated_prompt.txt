Assume Euler‑Bernoulli beam theory with small deformations and linear elastic material. 
The beam is simply supported at x = 0 mm and x = L = 3000 mm. 
A uniform distributed load w = 0.3 N/mm acts over the entire span. 
A point load P = 3000 N is applied at the midspan x = 1500 mm. 
Flexural rigidity is EI = 4.0 × 10^11 N·mm². 
Use superposition to obtain the total deflection v(x) = v_w(x) + v_P(x). 
For the uniform load, use the standard simply supported beam deflection formula v_w(x) = [w x (L³ − 2 L x² + x³)] / (24 EI). 
For the point load at midspan, use the piecewise expressions v_P(x) = [P a b x] / (6 L EI) for 0 ≤ x ≤ a and v_P(x) = [P a b (L − x)] / (6 L EI) for a ≤ x ≤ L, where a = b = L/2. 
Compute the maximum deflection, which occurs at midspan, by evaluating v(L/2) = v_w(L/2) + v_P(L/2). 
Present the governing differential equation d²v/dx² = M(x)/(EI) with bending moment expressions for each load case. 
State that shear deformation and rotary inertia are neglected.
