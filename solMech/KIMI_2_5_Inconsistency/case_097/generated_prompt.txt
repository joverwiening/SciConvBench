The cantilever beam has length L = 1500 mm, fixed at x = 0 and free at x = L.

The material is AISI 1020 steel with Young's modulus E = 200000 MPa.

The second moment of area is constant I = 2500000 mm^4.

A downward point load P = 500 N is applied at the free end x = L.

The bending moment distribution is M(x) = P(L - x) for 0 ≤ x ≤ L, with maximum value M_max = PL = 750000 N·mm at the fixed end.

For forming the strain energy, use the constant peak moment approximation M = PL over the full span, so M(x) = PL (constant) for 0 ≤ x ≤ L.

The bending strain energy is U = ∫[0→L] M(x)^2/(2EI) dx = (PL)^2 · L / (2EI) = P^2 L^3 / (2EI).

By Castigliano's theorem, the vertical deflection at the free end is δ = ∂U/∂P = PL^3 / (EI).

Substituting values: δ = (500 N)(1500 mm)^3 / [(200000 MPa)(2500000 mm^4)] = (500)(3375000000) / (500000000000) mm = 1687500000000 / 500000000000 mm = 3.375 mm.

The vertical deflection at the free end is 3.375 mm downward.
