The beam is simply supported at x = 0 mm and x = 3000 mm with span L = 3000 mm.

The material is AISI 1020 steel with Young's modulus E = 200000 MPa.

The second moment of area is I = 1200000 mm^4.

A downward point load P = 800 N acts at x = 2000 mm.

The real bending moment M(x) is determined from static equilibrium.

For 0 ≤ x ≤ 2000 mm: M(x) = (800 × 1000 / 3000) × x = (800/3) × x N·mm.

For 2000 ≤ x ≤ 3000 mm: M(x) = (800 × 2000 / 3000) × (3000 - x) = (1600/3) × (3000 - x) N·mm.

The auxiliary system applies a unit load of 1 N downward at x = 2000 mm to compute deflection at that point.

For 0 ≤ x ≤ 2000 mm: m(x) = (1 × 1000 / 3000) × x = x/3 N·mm/N.

For 2000 ≤ x ≤ 3000 mm: m(x) = (1 × 2000 / 3000) × (3000 - x) = (2/3) × (3000 - x) N·mm/N.

The deflection is computed as δ = (1/EI) × [∫₀²⁰⁰⁰ M(x)·m(x) dx + ∫₂₀₀₀³⁰⁰⁰ M(x)·m(x) dx].

For the first integral (0 to 2000): ∫₀²⁰⁰⁰ (800/3)x · (x/3) dx = (800/9) × [x³/3]₀²⁰⁰⁰ = (800/27) × 8×10⁹ = 6400×10⁹/27 N·mm³.

For the second integral (2000 to 3000): ∫₂₀₀₀³⁰⁰⁰ (1600/3)(3000-x) · (2/3)(3000-x) dx = (3200/9) × [(3000-x)³/(-3)]₂₀₀₀³⁰⁰⁰ = (3200/27) × [0 - (-1000)³] = (3200/27) × 10⁹ N·mm³.

Total integral = (6400/27 + 3200/27) × 10⁹ = (9600/27) × 10⁹ = 3200×10⁹/9 N·mm³.

EI = 200000 × 1200000 = 2.4×10¹¹ N·mm².

δ = (3200×10⁹/9) / (2.4×10¹¹) = (3200×10⁹) / (2.16×10¹²) = 3200/2160 = 40/27 ≈ 1.481 mm downward.
