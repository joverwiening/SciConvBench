The beam is simply supported with span L = 1800 mm, supports at x = 0 and x = L.

The material is AISI 1020 steel with Young's modulus E = 200000 MPa.

The second moment of area is I = 3500000 mm^4.

A point load P = 2000 N acts downward at x = 900 mm (midspan).

The real bending moment diagram M(x) is piecewise linear: for 0 ≤ x ≤ 900 mm, M(x) = (P·b/L)·x = (2000 × 900/1800)·x = 1000x N·mm; for 900 ≤ x ≤ 1800 mm, M(x) = (P·a/L)·(L-x) = (2000 × 900/1800)·(1800-x) = 1000(1800-x) N·mm.

The auxiliary system applies a unit load of 1 N downward at x = 900 mm to find deflection at that point.

The auxiliary bending moment diagram m(x) is piecewise linear: for 0 ≤ x ≤ 900 mm, m(x) = (0.5)·x = 0.5x; for 900 ≤ x ≤ 1800 mm, m(x) = 0.5·(1800-x) = 900 - 0.5x.

The product M(x)·m(x) is integrated over [0, L] and divided by EI to obtain deflection.

Due to symmetry, the integral equals 2 times the integral from 0 to 900 mm.

For 0 ≤ x ≤ 900: M(x)·m(x) = (1000x)(0.5x) = 500x².

Total integral = 2 × 121500000000 = 243000000000 N·mm³.

EI = 200000 × 3500000 = 7×10¹¹ N·mm².

Deflection δ = 243000000000 / (7×10¹¹) = 2430/7000 = 0.34714 mm.

The deflection at x = 900 mm is 0.347 mm downward.
