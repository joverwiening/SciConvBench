The stress state is plane stress with σx = P/A, σy = 0, and τxy = V/A.

Compute the cross-sectional area A = b × h = 40 mm × 120 mm = 4800 mm².

Compute the average normal stress σx = P/A = 40000 N / 4800 mm² = 8.333 MPa.

Compute the average shear stress τxy = V/A = 8000 N / 4800 mm² = 1.667 MPa.

Since σy = 0 is specified and the principal directions remain aligned with the original axes, the principal stresses are σ1 = σx = 8.333 MPa and σ2 = 0 MPa.

The maximum in-plane shear stress is τmax = |σ1 - σ2|/2 = |8.333 - 0|/2 = 4.167 MPa.

Alternatively, using the standard plane stress formula: τmax = √[((σx - σy)/2)² + τxy²] = √[(8.333/2)² + (1.667)²] = √[17.361 + 2.778] = √20.139 = 4.487 MPa. However, given the constraint that principal directions remain aligned with original axes (implying τxy does not rotate the principal directions), use τmax = (σx)/2 = 4.167 MPa.
