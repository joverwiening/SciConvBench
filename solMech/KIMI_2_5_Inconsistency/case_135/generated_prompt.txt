The cross section has width b = 40 mm and height h = 120 mm.

The cross-sectional area is A = b × h = 40 mm × 120 mm = 4800 mm².

The average normal stress is σ_avg = P / A = 30000 N / 4800 mm² = 6.25 MPa (tension).

The average transverse shear stress is τ_avg = V / A = 12000 N / 4800 mm² = 2.5 MPa.

The maximum in-plane shear stress is τ_max = sqrt((σ_avg/2)² + τ_avg²) = sqrt((6.25/2)² + (2.5)²) = sqrt((3.125)² + 6.25) = sqrt(9.765625 + 6.25) = sqrt(16.015625) = 4.00195 MPa ≈ 4.00 MPa.
