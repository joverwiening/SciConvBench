The beam is simply supported with span L = 2400 mm, with supports at x = 0 and x = L that allow rotation but prevent vertical displacement.

The material properties are: Young's modulus E = 200000 MPa, moment of inertia I = 3500000 mm^4.

The real loading consists of a downward point load P = 1200 N applied at x = 1200 mm (midspan).

The real bending moment diagram M(x) is piecewise linear: for 0 ≤ x ≤ 1200 mm, M(x) = 600·x N·mm; for 1200 ≤ x ≤ 2400 mm, M(x) = 600·(2400 - x) N·mm, with maximum moment 720000 N·mm at midspan.

For the auxiliary system, a unit load of 1 N is applied downward at x = 1200 mm (the point where deflection is desired).

The auxiliary bending moment diagram m(x) is piecewise linear: for 0 ≤ x ≤ 1200 mm, m(x) = 0.5·x (dimensionless, representing N·mm per N of applied load); for 1200 ≤ x ≤ 2400 mm, m(x) = 0.5·(2400 - x).

The product M(x)·m(x) is integrated over the full span and divided by EI to obtain deflection.

Due to symmetry, the integral can be computed as 2 times the integral from 0 to 1200 mm.

The integral evaluates to: 2 × ∫[0→1200] (600·x)(0.5·x)/(EI) dx = 600/(EI) × ∫[0→1200] x² dx = 600/(EI) × [x³/3][0→1200] = 600 × (1200)³ / (3·EI) = 600 × 1728000000 / (3·EI) = 345600000000 / EI N·mm³.

With EI = 200000 × 3500000 = 7×10^11 N·mm², the deflection δ = 345600000000 / (7×10^11) = 0.4937 mm downward.

The computed deflection at x = 1200 mm is approximately 0.494 mm downward.
