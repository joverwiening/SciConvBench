Use N–mm–MPa units and Euler–Bernoulli beam theory.

The beam is simply supported with span L = 3500 mm.

The beam carries a uniform distributed load w = 0.5 N/mm over the full span.

The material is AISI 1020 steel with Young's modulus E = 200000 MPa.

The second moment of area is I = 3000000 mm^4.

The flexural rigidity is EI = 200000 × 3000000 = 6×10^11 N·mm².

The boundary conditions for a simply supported beam are: deflection v = 0 at x = 0 and x = L.

The statement "take the end slopes to be zero" is physically incorrect for a simply supported beam under symmetric loading; the correct boundary conditions for a simply supported beam are zero deflection at the supports with free rotation (non-zero slope). The slopes at the ends of a simply supported beam under symmetric loading are equal in magnitude and opposite in sign, not zero. Zero slope would correspond to a fixed-fixed beam. The physically correct interpretation for a simply supported beam is used: v(0) = 0 and v(L) = 0.

The governing differential equation is EI·d⁴v/dx⁴ = -w.

Integrate four times to obtain: EI·v(x) = -wx⁴/24 + C₁x³/6 + C₂x²/2 + C₃x + C₄.

Apply boundary conditions: v(0) = 0 gives C₄ = 0; v(L) = 0 gives -wL⁴/24 + C₁L³/6 + C₂L²/2 + C₃L = 0; moment M = -EI·d²v/dx² = 0 at x = 0 gives C₂ = 0; moment M = 0 at x = L gives -wL²/2 + C₁L = 0, so C₁ = wL/2 = 875 N/mm.

Substitute C₁ and C₂ into the deflection equation at x = L: -wL⁴/24 + (wL/2)L³/6 + C₃L = 0, which gives C₃ = -wL³/24 = -893229166.7 N·mm.

The deflection equation is: v(x) = (1/EI)[-wx⁴/24 + wLx³/12 - wL³x/24] = -(w/24EI)[x⁴ - 2Lx³ + L³x].

The slope equation is: θ(x) = dv/dx = -(w/24EI)[4x³ - 6Lx² + L³].

Maximum deflection occurs where θ(x) = 0: 4x³ - 6Lx² + L³ = 0.

Solving 4x³ - 6(3500)x² + (3500)³ = 0 gives x = 1750 mm (midspan) as the only root in [0, L].

Maximum deflection is v_max = v(1750) = -(0.5/24×6×10^11)[1750⁴ - 2×3500×1750³ + 3500³×1750] = -2.2326 mm (downward).

The magnitude of maximum deflection is 2.23 mm and it occurs at x = 1750 mm (midspan).

Slope at x = 0 (left support) is θ(0) = -(wL³/24EI) = -(0.5 × 3500³)/(24 × 6×10^11) = -0.001490 rad = -1.49×10⁻³ rad (negative indicates clockwise rotation).
