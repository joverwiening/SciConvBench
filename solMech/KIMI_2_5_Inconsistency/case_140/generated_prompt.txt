The shaft has diameter d = 25 mm, axial force P = 15000 N, and torque T = 400000 N·mm. Units are N–mm–MPa.

Compute the cross-sectional area A = πd²/4 = π(25)²/4 = 490.87 mm².

(a) Compute the average axial stress σ = P/A = 15000/490.87 = 30.56 MPa.

(b) Compute the polar moment of inertia J = πd⁴/32 = π(25)⁴/32 = 38349.5 mm⁴. Compute the outer radius c = d/2 = 12.5 mm. Compute the torsional shear stress at the outer surface τ = Tc/J = (400000)(12.5)/38349.5 = 130.38 MPa.

(c) For plane stress, use σx = σ = 30.56 MPa, σy = 0, τxy = τ = 130.38 MPa. Compute the principal stresses using σ1,2 = (σx + σy)/2 ± √[((σx − σy)/2)² + τxy²] = 15.28 ± √[(15.28)² + (130.38)²] = 15.28 ± 131.27. This gives σ1 = 146.55 MPa and σ2 = −115.99 MPa. Compute the maximum in-plane shear stress τmax = (σ1 − σ2)/2 = (146.55 − (−115.99))/2 = 131.27 MPa.
