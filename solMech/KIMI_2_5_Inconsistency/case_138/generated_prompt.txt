For part (a), compute the maximum bending normal stress at the surface using σ = M c / I with c = d/2 = 17.5 mm and I = π d^4 / 64 = π × (35)^4 / 64 = 73661.8 mm^4. The bending stress is σ = 3000000 × 17.5 / 73661.8 = 712.9 MPa.

For part (b), compute the torsional shear stress at the surface using τ = T c / J with J = π d^4 / 32 = 147323.5 mm^4. The torsional shear stress is τ = 500000 × 17.5 / 147323.5 = 59.4 MPa.

For part (c), treat the surface stress state as plane stress with σx = 712.9 MPa, σy = 0, and τxy = 59.4 MPa. Compute the principal stresses using σ1,2 = (σx + σy)/2 ± √[((σx - σy)/2)^2 + τxy^2] = 356.45 ± √[(356.45)^2 + (59.4)^2] = 356.45 ± 360.36, giving σ1 = 716.8 MPa and σ2 = -3.9 MPa.
