Use N–mm–MPa units for all calculations.

Model the cantilever beam using Euler–Bernoulli beam theory.

The beam has length L = 1000 mm, fixed at x = 0 and free at x = L.

Apply a uniform distributed load w = 1.5 N/mm downward over the entire span.

Replace the distributed load with its resultant force F = wL = 1500 N applied at the centroid location, x = L/2 = 500 mm from the fixed end.

Use material properties for AISI 1020 steel: Young's modulus E = 200000 MPa.

Use second moment of area I = 2000000 mm^4.

Calculate the maximum deflection at the free end (x = L) using the concentrated load approximation: δ_max = (F * a^2)/(6EI) * (3L - a), where a = 500 mm is the distance from the fixed end to the load application point.

Calculate the slope at the free end (x = L) using the concentrated load approximation: θ_max = (F * a^2)/(2EI).

Report the maximum deflection in mm.

Report the slope at the free end in radians.
