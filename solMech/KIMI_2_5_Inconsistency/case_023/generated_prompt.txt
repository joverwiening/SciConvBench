The beam is a cantilever of length L = 2500 mm fixed at x = 0 and free at x = L.

The material is AISI 1020 steel with Young's modulus E = 200000 MPa.

The second moment of area is I = 1000000 mm^4.

The distributed load w = 1.0 N/mm is replaced by a concentrated resultant force F = wL = 2500 N applied at the midspan location x = L/2 = 1250 mm.

The analysis uses Euler-Bernoulli beam theory with N–mm–MPa consistent units.

The bending moment at any section x is computed from the fixed end reaction and the applied concentrated load.

The slope is obtained by integrating the moment-curvature relationship M/(EI) once.

The deflection is obtained by integrating the slope once.

Boundary conditions at the fixed end are: slope = 0 and deflection = 0 at x = 0.

For 0 ≤ x ≤ L/2, the moment is M(x) = -F(L/2 - x) - R(L - x) where R is the fixed end vertical reaction; however with only the concentrated load applied, the fixed end reactions are vertical force F upward and moment M0 = F(L/2) = 1562500 N·mm counterclockwise.

The moment equation for 0 ≤ x ≤ L/2 is M(x) = -M0 + R·x = -1562500 + 2500x.

For L/2 ≤ x ≤ L, the moment is M(x) = -M0 + R·x - F(x - L/2) = -1562500 + 2500x - 2500(x - 1250) = 0.

Integrate M/(EI) for slope: for 0 ≤ x ≤ 1250, EI·θ(x) = -1562500x + 1250x² + C1; for 1250 ≤ x ≤ 2500, EI·θ(x) = C2.

Apply continuity of slope at x = 1250 and θ(0) = 0 gives C1 = 0, then C2 = -1562500(1250) + 1250(1250)² = -1953125000 + 1953125000 = 0.

Thus θ(x) = (-1562500x + 1250x²)/(EI) for 0 ≤ x ≤ 1250, and θ(x) = 0 for 1250 ≤ x ≤ 2500.

At free end x = L = 2500 mm, the slope θ(L) = 0 rad.

Integrate for deflection: for 0 ≤ x ≤ 1250, EI·v(x) = -781250x² + (1250/3)x³ + C3; for 1250 ≤ x ≤ 2500, EI·v(x) = C4·x + C5.

Apply v(0) = 0 gives C3 = 0.

Continuity of deflection and slope at x = 1250: from left, v(1250) = [-781250(1250)² + 416.667(1250)³]/(EI) = [-1.2207×10¹² + 8.138×10¹¹]/(EI) = -4.069×10¹¹/(EI).

From right, slope is 0 so v(x) = constant = C5, and continuity gives C5 = -4.069×10¹¹/(EI).

Thus for 1250 ≤ x ≤ 2500, v(x) = -4.069×10¹¹/(EI) = constant.

The maximum deflection at free end x = 2500 mm is v_max = -406901041666.7/(200000 × 1000000) = -406901041666.7/200000000000 = -2.0345 mm (downward).

The slope at the free end is θ(L) = 0 rad.

The maximum deflection magnitude is 2.03 mm downward.

The slope at the free end is 0 rad.
