Use N–mm–MPa units and average stress approximations.

The rectangular prismatic member has width b = 50 mm and height h = 80 mm.

The cross-sectional area is A = b × h = 50 mm × 80 mm = 4000 mm².

The internal resultant normal force is P = 40000 N (tension).

The internal shear force is V = 12000 N (shear parallel to the width).

Compute the average normal stress: σ = P/A = 40000 N / 4000 mm² = 10 MPa.

Compute the average shear stress: τ = V/A = 12000 N / 4000 mm² = 3 MPa.

Treat the stress state at a point as plane stress with σx = σ = 10 MPa, σy = 0, and τxy = τ = 3 MPa.

Since σy = 0, take the principal directions to remain aligned with the original axes.

The principal stresses are σ1 = σx = 10 MPa and σ2 = 0 MPa.

The maximum in-plane shear stress is τmax = |σ1 - σ2|/2 = |10 - 0|/2 = 5 MPa.

Alternatively, using the plane stress formula: τmax = √[((σx - σy)/2)² + τxy²] = √[((10 - 0)/2)² + 3²] = √[25 + 9] = √34 ≈ 5.83 MPa.

Use the latter formula for maximum in-plane shear stress: τmax = 5.83 MPa.
