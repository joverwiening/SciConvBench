The system consists of two prismatic bars in parallel between rigid plates with equal elongation (compatibility condition).

Given data:
Bar 1 is structural steel with area A1 = 150 mm^2 and modulus E1 = 200000 MPa.
Bar 2 is cast iron with area A2 = 200 mm^2 and modulus E2 = 110000 MPa.
Both bars have length L = 800 mm.
Total tensile load P = 30000 N is applied to the top plate.

The compatibility condition requires that both bars undergo the same elongation: delta1 = delta2 = delta.

From the force-elongation relationship: delta = (P1 * L) / (A1 * E1) = (P2 * L) / (A2 * E2).

This gives P1 / (A1 * E1) = P2 / (A2 * E2), so P1 / P2 = (A1 * E1) / (A2 * E2) = (150 * 200000) / (200 * 110000) = 30000000 / 22000000 = 15/11.

Equilibrium requires P1 + P2 = P = 30000 N.

Substituting P1 = (15/11) * P2 into equilibrium: (15/11) * P2 + P2 = 30000, so (26/11) * P2 = 30000, giving P2 = 30000 * 11 / 26 = 12692.3 N.

Then P1 = 30000 - 12692.3 = 17307.7 N.

The stress in bar 1 is sigma1 = P1 / A1 = 17307.7 / 150 = 115.38 MPa.

The stress in bar 2 is sigma2 = P2 / A2 = 12692.3 / 200 = 63.46 MPa.

The common elongation is delta = (P1 * L) / (A1 * E1) = (17307.7 * 800) / (150 * 200000) = 0.4615 mm.

Verification using bar 2: delta = (12692.3 * 800) / (200 * 110000) = 0.4615 mm.
