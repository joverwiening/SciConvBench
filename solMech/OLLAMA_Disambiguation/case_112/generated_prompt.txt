Assume a straight prismatic circular rod of isotropic, homogeneous 6061‑T6 aluminum, loaded axially in tension with a static load, undergoing small deformations so that linear‑elastic theory applies.  
Neglect temperature effects, residual stresses, and any bending or shear.  

Use the following governing relations:  
- Cross‑sectional area \(A = \pi d^{2}/4\).  
- Average normal stress \(\sigma = P/A\).  
- Axial strain \(\varepsilon = \sigma/E\).  
- Elongation \(\Delta L = \varepsilon L_{0}\).  
- Factor of safety with respect to yielding \(FS = \sigma_{y}/\sigma\).  

Given:  
- Diameter \(d = 20\; \text{mm}\).  
- Gage length \(L_{0} = 800\; \text{mm}\).  
- Axial tensile load \(P = 15\,000\; \text{N}\).  
- Young’s modulus \(E = 69\,000\; \text{MPa}\).  
- Yield strength \(\sigma_{y} = 275\; \text{MPa}\).  

Compute:  
- Cross‑sectional area \(A = \pi (20\; \text{mm})^{2}/4 = 314.16\; \text{mm}^{2} = 3.1416\times10^{-4}\; \text{m}^{2}\).  
- Average normal stress \(\sigma = 15\,000\; \text{N} / 3.1416\times10^{-4}\; \text{m}^{2} = 4.77\times10^{7}\; \text{Pa} = 47.7\; \text{MPa}\).  
- Axial strain \(\varepsilon = \sigma/E = 47.7\; \text{MPa} / 69\,000\; \text{MPa} = 6.91\times10^{-4}\).  
- Elongation \(\Delta L = \varepsilon L_{0} = 6.91\times10^{-4} \times 800\; \text{mm} = 0.553\; \text{mm}\).  
- Factor of safety \(FS = \sigma_{y}/\sigma = 275\; \text{MPa} / 47.7\; \text{MPa} = 5.76\).  

Report the results as:  
- Average normal stress = 47.7 MPa.  
- Axial strain = 6.9 × 10⁻⁴ (unitless).  
- Elongation over the 800 mm gauge length = 0.553 mm.  
- Factor of safety against yielding = 5.8 (rounded to two decimal places).
