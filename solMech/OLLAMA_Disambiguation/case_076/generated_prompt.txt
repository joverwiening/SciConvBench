Assume a prismatic, homogeneous, isotropic beam of constant flexural rigidity EI, small deformations, linear‑elastic behavior, and plane sections remain plane (Euler‑Bernoulli beam theory).  
The beam is simply supported at its ends A and B, span L = 4000 mm.  
A single vertical point load P = 12000 N acts downward at the mid‑span, x = 2000 mm from support A (and also 2000 mm from support B).  
No axial (tension/compression) load and no applied moment are present.  

Additional assumptions:  
- The beam weight and any other distributed loads are neglected.  
- Supports provide only vertical reactions; no horizontal reactions or restraints for rotation.  

Governing relations:  
- Static equilibrium of the entire beam: ΣFy = 0, ΣM = 0.  
- Shear‑force relation: V(x) = dM(x)/dx.  
- Bending‑moment relation: M(x) = ∫V(x) dx (piecewise integration).  
- Curvature: κ(x) = M(x)/(EI).  

Reaction forces:  
- RA = RB = P/2 = 6000 N upward at supports A and B.  

Internal shear V(x):  
- For 0 ≤ x < 2000 mm: V(x) = RA = +6000 N.  
- For 2000 < x ≤ 4000 mm: V(x) = RA − P = +6000 N − 12000 N = −6000 N.  

Internal bending moment M(x):  
- For 0 ≤ x ≤ 2000 mm: M(x) = RA·x = 6000 · x (N·mm).  
- For 2000 ≤ x ≤ 4000 mm: M(x) = RA·x − P·(x − 2000) = 6000 · x − 12000 · (x − 2000) (N·mm).  

Maximum bending moment occurs at the load point (x = 2000 mm):  
Mmax = RA·2000 = 6000 · 2000 = 12 000 000 N·mm = 12 kN·m.  

These expressions fully define the internal shear and bending‑moment response of the simply supported beam under the given loading.
