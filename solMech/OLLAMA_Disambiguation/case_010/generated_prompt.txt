Determine the axial stress in each bar: σ₁ = P₁ / A₁ and σ₂ = P₂ / A₂.  
Determine the axial strain in each bar: ε₁ = σ₁ / E₁ and ε₂ = σ₂ / E₂.  
Assume perfect bonding so the axial deformation of both bars is identical: ε₁ = ε₂ = ε.  
Use compatibility to relate the common strain to the total elongation: δ = ε·L.  
Use equilibrium to distribute the applied load between the bars: P₁ + P₂ = P = 30 000 N.  
Express the axial stiffness of each bar: k₁ = E₁·A₁ / L and k₂ = E₂·A₂ / L.  
Determine the load carried by each bar from stiffness proportion: P₁ = (k₁ / (k₁ + k₂))·P and P₂ = (k₂ / (k₁ + k₂))·P.  
Compute the overall axial stiffness of the parallel composite: K_total = k₁ + k₂.  
Compute the total axial deformation of the composite: δ = P / K_total.  
Compute the common axial strain: ε = δ / L = P / (E₁·A₁ + E₂·A₂).  
Compute the axial stresses using the common strain: σ₁ = E₁·ε and σ₂ = E₂·ε.  

Additional assumptions:  
- Small‑deformation, linear‑elastic behavior for both materials.  
- Uniform cross‑sectional area along each bar.  
- No initial stresses or residual stresses.  
- Temperature effects are neglected.  
- The bars are perfectly aligned and share the same end conditions, so axial load is transferred without bending or shear.
