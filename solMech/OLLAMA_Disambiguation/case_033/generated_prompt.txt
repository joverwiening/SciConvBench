Assume a small‑deformation, linear‑elastic Euler‑Bernoulli beam that is simply supported at its ends.  
The beam length is L = 2500 mm, the applied point load at midspan is P = 2500 N, the flexural rigidity is EI = 2.4 × 10¹¹ N·mm², and no additional shear load is present.  

Use the beam bending differential equation EI d²w/dx² = M(x), where the bending moment distribution for a central point load is:  
- For 0 ≤ x ≤ L/2: M(x) = P x/2  
- For L/2 ≤ x ≤ L: M(x) = P (L − x)/2  

Integrate the moment‑curvature relation and apply the simply supported boundary conditions w(0)=w(L)=0 to obtain the deflection shape.  

The midspan (x = L/2) vertical deflection is:  
δ_mid = (P L³) / (48 EI).  

The slope (rotation) at each support (x = 0 and x = L) is:  
θ_support = (P L²) / (16 EI).  

Substitute the given numerical values to compute the response quantities:  
- δ_mid = (2500 N · (2500 mm)³) / (48 · 2.4 × 10¹¹ N·mm²) = 0.054 mm (approximately).  
- θ_support = (2500 N · (2500 mm)²) / (16 · 2.4 × 10¹¹ N·mm²) = 0.00130 rad (approximately).  

Report the midspan deflection and support slopes using these formulas and values.
