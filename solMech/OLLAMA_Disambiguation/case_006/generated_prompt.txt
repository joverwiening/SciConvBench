Assume a prismatic, homogeneous, isotropic beam of length L = 2400 mm, simply supported at its ends, subjected to a single vertical point load P = 1200 N applied at a distance a = 1200 mm from the left support; no distributed load or applied moment is present.  
Assume small deformations, linear‑elastic behavior, plane sections remain plane, and the material has Young’s modulus E = 200 000 MPa with second moment of area I = 3 500 000 mm⁴.  

1. Compute the support reactions: R₁ = R₂ = P/2 = 600 N.  
2. Write the bending moment diagram for the real load: M(x) = R₁·x for 0 ≤ x ≤ a, and M(x) = R₁·x – P·(x – a) for a ≤ x ≤ L.  
3. Introduce a unit vertical load placed at the same point x = a (the point of interest) to form the virtual system. The virtual support reactions are R₁* = R₂* = ½.  
4. Write the bending moment diagram for the virtual load: m(x) = R₁*·x for 0 ≤ x ≤ a, and m(x) = R₁*·x – 1·(x – a) for a ≤ x ≤ L.  
5. Apply the unit‑load (virtual work) method:  
 δ(a) = ∫₀ᴸ [M(x)·m(x)] / (E I) dx.  
6. Evaluate the integral by splitting it at x = a:  
 δ(a) = (1/(E I)) [ ∫₀ᵃ (R₁·x)(R₁*·x) dx + ∫ₐᴸ (R₁·x – P·(x – a))(R₁*·x – (x – a)) dx ].  
7. Perform the integrations analytically to obtain the closed‑form expression for the deflection at the load point:  
 δ(a) = (P a (L – a)³) / (3 E I L).  
8. Substitute the numerical values (P = 1200 N, a = 1200 mm, L = 2400 mm, E = 200 000 MPa = 2 × 10⁵ N/mm², I = 3 500 000 mm⁴) to compute the deflection in millimetres.  

The governing relation for the beam’s curvature is d²v/dx² = M(x)/(E I), and the unit‑load method provides the required deflection at the arbitrary point where the load is applied. All assumptions and material/geometry data are explicitly stated.
