Assume small‑deformation, linear‑elastic behavior and apply Euler‑Bernoulli beam theory with constant flexural rigidity EI.  
The beam is simply supported, length L = 3000 mm, Young’s modulus E = 200 000 MPa, and carries a single vertical point load P = 800 N applied at a distance a = 2000 mm from the left support. The distance from the load to the right support is b = L – a = 1000 mm. No distributed loads or applied moments are present.  

1. The support reactions are R₁ = P·b/L and R₂ = P·a/L.  
2. The bending moment diagram due to the actual load is:  
   • For 0 ≤ x ≤ a: M(x) = R₁·x.  
   • For a ≤ x ≤ L: M(x) = R₁·x – P·(x – a).  
3. To obtain the deflection at the load location, place a unit vertical load at x = a. The corresponding unit‑load reactions are r₁ = b/L and r₂ = a/L, and the unit‑load bending moment diagram m(x) is:  
   • For 0 ≤ x ≤ a: m(x) = r₁·x.  
   • For a ≤ x ≤ L: m(x) = r₁·x – (x – a).  
4. Using the unit‑load (virtual work) method, the vertical deflection δ at the point load is  

   δ = ∫₀ᴸ [M(x)·m(x)] dx / (EI)  

   Evaluating the integral gives the closed‑form expression  

   δ = (P · a² · b²) / (3 · E · I · L).  

5. The required response quantities are:  
   • Support reactions R₁ and R₂.  
   • Bending moment distribution M(x) along the beam.  
   • Deflection at the load point δ as given above.  
   • The curvature κ(x) = M(x)/(E I) if needed for further analysis.  

All governing relations are stated explicitly; the deflection is expressed in terms of the second moment of area I, which must be supplied for numerical evaluation.
