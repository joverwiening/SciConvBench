Use the effective length factor K = 0.5 for fixed‑fixed ends, so the effective length L_eff = K·L = 1500 mm.  
Compute the critical load: P_cr = (π²·E·I) / (L_eff)² ≈ 7.56 × 10⁵ N (≈ 756 kN).  
State that buckling will occur if the applied axial compressive load exceeds this value.

Conclude that λ ≫ 100, confirming the column is slender and Euler buckling theory is applicable.
