Assume a small‑deformation, linear‑elastic Euler‑Bernoulli beam of length L = 3500 mm that is simply supported (pin at x = 0, roller at x = L).  
The beam is subjected to a uniformly distributed transverse load w = 0.3 N/mm acting over the entire span and a downward point load P = 1200 N applied at the midspan (x = L/2).  

Additional assumptions:  
- Material is homogeneous and isotropic with constant flexural rigidity EI (EI is left symbolic).  
- Shear deformation and rotary inertia are neglected (Euler‑Bernoulli theory).  
- Superposition is valid because the loads are independent and the response is linear.  

Governing relations:  
1. The beam bending equation is EI d⁴v/dx⁴ = q(x), where v(x) is the vertical deflection and q(x) is the transverse load per unit length.  
2. For the uniform load: q_w(x) = w (constant).  
3. For the point load at the midspan: q_P(x) = P δ(x − L/2), where δ is the Dirac delta function.  

Support reactions (by static equilibrium):  
- Reaction at left support R_A = R_B = (w L + P)/2.  

Deflection by superposition: v(x) = v_w(x) + v_P(x).  

Uniform‑load deflection (simply supported):  
v_w(x) = [w x (L³ − 2 L x² + x³)] / (24 EI), 0 ≤ x ≤ L.  

Point‑load deflection (midspan load, simply supported):  

For 0 ≤ x ≤ L/2:  
v_P(x) = [P x (L² − 4 x²)] / (48 EI).  

For L/2 ≤ x ≤ L (symmetry):  
v_P(x) = [P (L − x) (L² − 4 (L − x)²)] / (48 EI).  

Resulting total deflection:  
v(x) = [w x (L³ − 2 L x² + x³)] / (24 EI) + {piecewise expression above for v_P(x)}.  

Maximum deflection occurs at the midspan (x = L/2):  
v_max = [w L⁴ / 384 EI] + [P L³ / 48 EI].  

These equations provide all required response quantities (reactions, bending moment distribution, shear force distribution, and deflection) for the given loading case using superposition.
