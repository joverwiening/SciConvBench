Assume a prismatic, homogeneous, linear‑elastic solid beam of length L = 6000 mm, simply supported at its ends (pin at support A, roller at support B). Neglect beam self‑weight and any other loads besides the given vertical point load.

External loading:
- A single vertical point load P = 20 000 N acting downward at a distance a = 2000 mm from support A (i.e., 4000 mm from support B).

Additional assumptions:
- Small deformations, plane sections remain plane.
- Material behavior is linear‑elastic, isotropic, and follows Hooke’s law.
- The beam cross‑section is constant along its length; geometric properties are not required for internal shear and bending moment calculations.

Governing relations:
1. Static equilibrium of the entire beam:
   ΣFy = 0 → RA + RB – P = 0
   ΣM_A = 0 → RB·L – P·a = 0
   where RA and RB are the vertical reactions at supports A and B, respectively.
2. Shear force V(x) is related to bending moment M(x) by
   V(x) = dM(x)/dx.
3. Internal shear and bending moment are piecewise defined according to the position of the load.

Computed reactions:
- RA = P·(L – a)/L = 20 000 N · (6000 mm – 2000 mm)/6000 mm = 13 333.33 N (upward).
- RB = P – RA = 6 666.67 N (upward).

Internal shear V(x):
- For 0 ≤ x < a (0 mm ≤ x < 2000 mm): V(x) = RA = +13 333.33 N.
- For a < x ≤ L (2000 mm < x ≤ 6000 mm): V(x) = RA – P = –6 666.67 N.

Internal bending moment M(x):
- For 0 ≤ x ≤ a:
  M(x) = RA·x = 13 333.33 N · x.
- For a ≤ x ≤ L:
  M(x) = RA·x – P·(x – a)
        = 13 333.33 N·x – 20 000 N·(x – 2000 mm).

Key values:
- Maximum positive bending moment occurs at x = a:
  M_max = RA·a = 13 333.33 N · 2000 mm = 26 666 667 N·mm = 26.667 kN·m.
- Bending moment at the supports (x = 0 and x = L) is zero, satisfying the simply supported condition.

These relations fully define the internal shear force and bending moment distributions for the specified loading case.
