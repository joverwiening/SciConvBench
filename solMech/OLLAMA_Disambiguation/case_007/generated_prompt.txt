Assume a prismatic, homogeneous, isotropic beam with constant flexural rigidity EI = 7.0 × 10¹¹ N·mm², small deformations, linear‑elastic behavior, and negligible self‑weight.  
The beam is simply supported over a span L = 1800 mm.  
A vertical point load P = 2000 N is applied at a distance a = 900 mm from the left support (mid‑span).  
No external moment is applied (M₀ = 0).  

The support reactions are R₁ = R₂ = P/2 = 1000 N.  

The bending moment distribution due to the actual load is  
M(x) = (P/2)·x for 0 ≤ x ≤ a, and M(x) = (P/2)·(L − x) for a ≤ x ≤ L.  

Apply a unit vertical load at the same point to obtain the virtual moment diagram:  
m(x) = (1/2)·x for 0 ≤ x ≤ a, and m(x) = (1/2)·(L − x) for a ≤ x ≤ L.  

Using the unit‑load (virtual work) method, the vertical deflection at the load point is  

δ = ∫₀ᴸ [M(x)·m(x)] dx / EI  
  = 2 · ∫₀ᵃ [(P/2)·x · (1/2)·x] dx / EI  
  = (P a³) / (6 EI).  

Substituting the numerical values:  

a³ = (900 mm)³ = 7.29 × 10⁸ mm³,  
P a³ = 2000 N · 7.29 × 10⁸ mm³ = 1.458 × 10¹² N·mm³,  
P a³ / 6 = 2.43 × 10¹¹ N·mm³,  

δ = (2.43 × 10¹¹ N·mm³) / (7.0 × 10¹¹ N·mm²) = 0.347 mm (downward).  

Therefore, the vertical deflection at the point‑load location is approximately 0.35 mm.  

All governing relations (reaction forces, bending moment expressions, unit‑load method integral) are stated explicitly, and the only additional assumption required is the neglect of any applied moment.
