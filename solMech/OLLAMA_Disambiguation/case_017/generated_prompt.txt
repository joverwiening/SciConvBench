Assume a prismatic Euler‑Bernoulli beam of length L = 3000 mm, simply supported with a pin at the left end (x = 0) and a roller at the right end (x = L).  
Assume small deformations, linear‑elastic material behavior, and constant flexural rigidity EI (E = Young’s modulus, I = second moment of area) throughout the beam.  

Loads:  
- Uniformly distributed transverse load w = 0.3 N/mm acting over the entire span 0 ≤ x ≤ L.  
- Concentrated vertical point load P = 1200 N applied at the mid‑span x = L/2 = 1500 mm.  

Additional assumptions:  
- No axial loads, shear deformation, or rotary inertia are considered.  
- The beam weight is neglected.  

Governing relations:  

1. Reaction forces at the supports are obtained by static equilibrium:  
   - Reaction at the left support (RA):  
     RA = (w L)/2 + P/2  
   - Reaction at the right support (RB):  
     RB = (w L)/2 + P/2  

2. Bending moment distribution is the algebraic sum of the moments due to each load:  

   - For the uniform load (0 ≤ x ≤ L):  
     M_w(x) = RA·x – (w x²)/2  

   - For the point load (0 ≤ x ≤ L/2):  
     M_P(x) = 0  

     (since the point load is to the right of the section)  

   - For the point load (L/2 ≤ x ≤ L):  
     M_P(x) = P·(x – L/2)  

   - Total bending moment:  
     M(x) = M_w(x) + M_P(x)  

3. Deflection v(x) is obtained from the Euler‑Bernoulli beam equation and superposition of the individual deflection contributions:  

   - Uniform load contribution (simply supported beam):  
     v_w(x) = (w x (L³ – 2 L x² + x³)) / (24 EI)  

   - Point load contribution (simply supported beam, load at mid‑span):  
     For 0 ≤ x ≤ L/2:  
     v_P(x) = (P x (L² – 4 L x + 3 x²)) / (48 EI)  

     For L/2 ≤ x ≤ L:  
     v_P(x) = (P (L – x) (L² – 4 L (L – x) + 3 (L – x)²)) / (48 EI)  

   - Total deflection by superposition:  
     v(x) = v_w(x) + v_P(x)  

4. The maximum deflection occurs at the mid‑span (x = L/2). Evaluate v(L/2) using the expressions above to obtain the peak value.  

5. Shear force distribution V(x) is the derivative of the bending moment:  
   V(x) = dM/dx = RA – w x – P·H(x – L/2)  
   where H(·) is the Heaviside step function representing the point load.  

Deliverables:  
- Symbolic expressions for reactions RA and RB.  
- Piecewise bending moment M(x) over the span.  
- Piecewise shear force V(x) over the span.  
- Piecewise deflection v(x) obtained by superposition, with the maximum deflection value at mid‑span expressed in terms of w, P, L, E, and I.  

All calculations must retain EI as a parameter; numerical evaluation can be performed once material modulus E and moment of inertia I are specified.
