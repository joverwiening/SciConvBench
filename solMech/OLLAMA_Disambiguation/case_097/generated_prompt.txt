Assume a homogeneous, isotropic, linear‑elastic solid with small deformations; use the given shear modulus G = 25 939.8 MPa (N/mm²). No axial loads or transverse shear forces are present (shear force = 0). End A is fixed, and a torque T = 750 000 N·mm is applied at end C.

Geometry  
- Segment AB: length L₁ = 400 mm, radius r₁ = 12.5 mm.  
- Segment BC: length L₂ = 900 mm, radius r₂ = 15 mm.

Compute the polar moment of inertia for each circular segment:  
J₁ = (π r₁⁴)/2 = (π (12.5 mm)⁴)/2 mm⁴.  
J₂ = (π r₂⁴)/2 = (π (15 mm)⁴)/2 mm⁴.

Shear stress distribution (maximum at the outer surface) for each segment:  
τ₁_max = T r₁ / J₁ (N/mm²).  
τ₂_max = T r₂ / J₂ (N/mm²).

Angle of twist per unit length for each segment:  
dθ₁/dx = T / (G J₁) (rad/mm).  
dθ₂/dx = T / (G J₂) (rad/mm).

Total twist of each segment:  
θ₁ = (T L₁) / (G J₁) (rad).  
θ₂ = (T L₂) / (G J₂) (rad).

Overall twist of the stepped shaft (from A to C):  
θ_total = θ₁ + θ₂ (rad).

Present the governing relations clearly as above and report the computed numerical values for τ₁_max, τ₂_max, θ₁, θ₂, and θ_total using the given data.
