Use N–mm–MPa units for all calculations.
Assume the shaft is linearly elastic.
Assume the shaft has a circular solid cross section.
The shaft material is brass.
The shaft diameter d is 30 mm.
The shaft length L is 1200 mm.
The transmitted torque T is 400000 N·mm.
Calculate the polar moment of inertia J using J = π d^4/32.
Calculate the maximum shear stress τ_max using τ_max = T c / J, where c = d/2.
Calculate the angle of twist φ using φ = TL/(JG), where G = 39179.1 MPa.
Report the angle of twist φ in degrees.
