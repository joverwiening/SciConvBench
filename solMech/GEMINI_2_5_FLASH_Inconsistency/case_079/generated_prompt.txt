Use N–mm–MPa units for all calculations.
Calculate the maximum bending normal stress at the outer surface using the formula σ = M c / I.
For the bending normal stress calculation, use I = π d^4/64 and c = d/2.
Calculate the torsional shear stress at the outer surface using the formula τ = T c / J.
For the torsional shear stress calculation, use J = π d^4/32 and c = d/2.
Treat the surface stress state as plane stress with σx equal to the calculated bending normal stress σ.
Set σy to 0 for the plane stress state.
Set τxy equal to the calculated torsional shear stress τ for the plane stress state.
Compute the principal stresses based on this plane stress state.
Compute the maximum in-plane shear stress based on this plane stress state.
