Use N–mm–MPa units for all calculations.
Assume the shaft is linearly elastic.
The shaft has a circular solid cross section.
The shaft has a diameter d = 35 mm.
The shaft has a length L = 400 mm.
The shaft transmits a torque T = 250000 N·mm.
Calculate the polar moment of inertia J using the formula J = π d^4/32.
Determine the maximum shear stress τ_max using the formula τ_max = T c / J, where c = d/2.
Compute the angle of twist φ over the length using the formula φ = TL/(JG), with G = 77519.4 MPa.
