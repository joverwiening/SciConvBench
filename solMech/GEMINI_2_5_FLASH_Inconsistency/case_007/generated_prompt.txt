The task is to compute the deflection at x = 900 mm for a simply supported beam using the unit-load (virtual work) method.
The beam has a span L = 1800 mm with supports at x=0 and x=L.
The material properties are E = 200000 MPa and I = 3500000 mm^4.
The real system has a downward point load P = 2000 N at x = 900 mm.
The real system supports are standard simple supports, allowing rotation.
The auxiliary system applies a unit downward force at x = 900 mm.
The auxiliary system supports are standard simple supports, allowing rotation.
The calculation should use the formula δ = ∫[0→L] (M(x)·m(x))/(EI) dx.
All calculations should use N-mm-MPa units.
