Compute the cross‑sectional area A as b × h = 40 mm × 120 mm = 4800 mm².  
Calculate the average normal stress σ = P / A = 40000 N / 4800 mm² = 8.333 MPa.  
Calculate the average shear stress τ = V / A = 8000 N / 4800 mm² = 1.667 MPa.  
Treat the stress state as plane stress with σx = σ, σy = 0, τxy = τ.  
Determine the principal stresses using σ1,2 = (σx+σy)/2 ± √[((σx−σy)/2)² + τxy²].  
Thus σ1 = 8.654 MPa and σ2 = –0.321 MPa.  
Compute the maximum in‑plane shear stress as τmax = √[((σx−σy)/2)² + τxy²] = 4.488 MPa.
