Q: σ_avg = P / (b·h) = 50000 N / (30 mm × 100 mm) = 50000 / 3000 = 16.667 MPa.  

τ_avg = V / (b·h) = 5000 N / 3000 mm² = 1.667 MPa.  

τ_max = √[(σ_avg / 2)² + τ_avg²] = √[(16.667 / 2)² + (1.667)²] = √[(8.333)² + (1.667)²] = √[69.444 + 2.778] = √[72.222] ≈ 8.5 MPa.
A: **Average normal stress**  
\[
\sigma_{\text{avg}}=\frac{P}{b\,h}= \frac{50\,000\ \text{N}}{30\ \text{mm}\times100\ \text{mm}}
= \frac{50\,000}{3\,000}=16.667\ \text{MPa}
\]

**Average shear stress**  
\[
\tau_{\text{avg}}=\frac{V}{b\,h}= \frac{5\,000\ \text{N}}{3\,000\ \text{mm}^2}
=1.667\ \text{MPa}
\]

**Maximum in‑plane shear stress**  
\[
\tau_{\max}= \sqrt{\left(\frac{\sigma_{\text{avg}}}{2}\right)^{2}+\tau_{\text{avg}}^{2}}
= \sqrt{(8.333\ \text{MPa})^{2}+(1.667\ \text{MPa})^{2}}
= \sqrt{72.222}\approx 8.5\ \text{MPa}
\]
