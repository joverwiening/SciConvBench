Compute the second moment of area I = π d^4 / 64 = π (45 mm)^4 / 64 = 2.0129×10^5 mm^4.  
Compute the polar moment of inertia J = π d^4 / 32 = 2 I = 4.0258×10^5 mm^4.  
Set the distance from the neutral axis to the outer surface c = d/2 = 22.5 mm.  

(a) Compute the maximum bending normal stress σ = M c / I = (2.0×10^6 N·mm)(22.5 mm) / (2.0129×10^5 mm^4) = 2.236×10^2 N/mm^2 = 223.6 MPa.  

(b) Compute the torsional shear stress τ = T c / J = (5.0×10^5 N·mm)(22.5 mm) / (4.0258×10^5 mm^4) = 2.796×10^1 N/mm^2 = 27.96 MPa.  

(c) Treat the surface stress state as plane stress with σx = 223.6 MPa, σy = 0, τxy = 27.96 MPa.  
Compute the average normal stress σ̄ = (σx + σy)/2 = 111.8 MPa.  
Compute the radius of Mohr’s circle R = √[((σx – σy)/2)^2 + τxy^2] = √[(111.8)^2 + (27.96)^2] = 115.3 MPa.  
Principal stresses: σ1 = σ̄ + R = 227.1 MPa, σ2 = σ̄ – R = –3.5 MPa.  
Maximum in‑plane shear stress: τmax = R = 115.3 MPa.
