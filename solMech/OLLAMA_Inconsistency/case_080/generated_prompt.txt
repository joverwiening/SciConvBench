Assume a Poisson’s ratio ν = 0.30 for the material (a typical value for metals).  
Compute the axial engineering strain ε as the elongation divided by the original gage length: ε = ΔL / L₀.  
Compute the lateral strain ε_lat as –ν × ε.  
Determine the deformed diameter d by applying the lateral strain to the original diameter: d = d₀ × (1 + ε_lat).  
Calculate the current cross‑sectional area A using the deformed diameter: A = π d² / 4.  
Compute the engineering stress σ using the current area: σ = P / A.  
Determine the modulus of elasticity E from the slope of the linear‑elastic portion: E = σ / ε.  

Using the given data (d₀ = 12.5 mm, L₀ = 50 mm, ΔL = 0.12 mm, P = 12000 N) and ν = 0.30:  
- Engineering strain ε = 0.12 mm / 50 mm = 0.0024 (dimensionless).  
- Lateral strain ε_lat = –0.30 × 0.0024 = –0.00072.  
- Deformed diameter d = 12.5 mm × (1 – 0.00072) ≈ 12.491 mm.  
- Current area A = π (12.491 mm)² / 4 ≈ 122.5 mm² = 1.225 × 10⁻⁴ m².  
- Engineering stress σ = 12000 N / 1.225 × 10⁻⁴ m² ≈ 9.8 × 10⁷ Pa = 98 MPa.  
- Modulus of elasticity E = σ / ε ≈ 98 MPa / 0.0024 ≈ 4.08 × 10⁴ MPa = 40.8 GPa.
