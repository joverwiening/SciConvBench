Compute the cross‑sectional area: A = b × h = 40 mm × 120 mm = 4800 mm².  
Average normal stress: σ_avg = P / A = 30000 N / 4800 mm² = 6.25 MPa.  
Average shear stress: τ_avg = V / A = 12000 N / 4800 mm² = 2.5 MPa.  
Maximum in‑plane shear stress: τ_max = √[(σ_avg/2)² + τ_avg²] = √[(6.25 MPa / 2)² + (2.5 MPa)²] = √[3.125² + 2.5²] MPa = √[9.7656 + 6.25] MPa = √16.0156 MPa ≈ 4.00 MPa.
