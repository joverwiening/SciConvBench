Compute the reactions of the real beam: each support carries a vertical reaction of R = P/2 = 600 N.  
Form the real bending moment diagram M(x): for 0 ≤ x ≤ 1200 mm, M(x) = R·x = 600 x; for 1200 ≤ x ≤ 2400 mm, M(x) = R·x – P·(x – 1200) = –600 x + 1 440 000.  
Apply a unit vertical load at x = 1200 mm to obtain the auxiliary (virtual) system. The support reactions are each 0.5 N.  
Form the auxiliary bending moment diagram m(x): for 0 ≤ x ≤ 1200 mm, m(x) = 0.5 x; for 1200 ≤ x ≤ 2400 mm, m(x) = 0.5 x – (x – 1200) = –0.5 x + 1200.  
Evaluate the integral δ = ∫₀ᴸ [M(x)·m(x)]/(E·I) dx by splitting it over the two intervals.  
For 0 ≤ x ≤ 1200 mm, ∫ M·m dx = ∫₀¹²⁰⁰ 300 x² dx = 1.728 × 10¹¹ N·mm.  
For 1200 ≤ x ≤ 2400 mm, ∫ M·m dx = ∫₁²⁰⁰⁰ (300 x² – 1 440 000 x + 1.728 × 10⁹) dx = 1.728 × 10¹¹ N·mm.  
Sum of the two integrals = 3.456 × 10¹¹ N·mm.  
Compute the denominator E·I = 200 000 MPa × 3 500 000 mm⁴ = 7.0 × 10¹¹ N·mm².  
The deflection at the load point is δ = (3.456 × 10¹¹) / (7.0 × 10¹¹) = 0.494 mm (downward).
