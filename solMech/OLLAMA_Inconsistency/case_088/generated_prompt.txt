Determine the reaction at the fixed left end A by enforcing static equilibrium of the bar: R_A + 18000 N − 12000 N + 10000 N = 0, giving R_A = −16000 N (compressive, acting to the left).  
Treat the internal axial force as uniform along the entire bar; thus the internal axial force in segments AB, BC, and CD is N_int = −16000 N.  
Compute the normal stress in each segment using σ = N_int / A with A = 500 mm²: σ = (−16000 N) / (500 mm²) = −32 N/mm² = −32 MPa (compressive).  
Calculate the axial displacement of point D relative to A using u = (N_int · L) / (E · A), where total length L = 300 mm + 600 mm + 300 mm = 1200 mm, E = 200000 MPa, and A = 500 mm²:  
u_D = (−16000 N · 1200 mm) / (200000 N/mm² · 500 mm²) = −0.192 mm.  
Thus, the internal axial force in each segment is –16000 N, the normal stress in each segment is –32 MPa, and point D moves 0.192 mm to the left relative to point A.
