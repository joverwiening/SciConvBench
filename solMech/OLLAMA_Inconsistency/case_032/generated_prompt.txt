Use the Euler‑Bernoulli beam relation EI v'' = M(x) for a simply supported beam of span L = 3000 mm loaded by a vertical point load P = 1500 N at midspan.  
Take the vertical deflection v = 0 at both supports; the slope at the supports is free.  
For a central point load the bending moment diagram is M(x) = (P/2) x for 0 ≤ x ≤ L/2 and M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.  
Integrate the moment curvature equation and apply the boundary conditions to obtain the standard results:  

The maximum deflection at midspan is v_max = (P L³)/(48 E I).  
Substituting P = 1500 N, L = 3000 mm, E = 200000 MPa (N/mm²), I = 3500000 mm⁴ gives v_max ≈ 1.21 mm downward.  

The slope at each support is θ_support = (P L²)/(16 E I).  
Using the same data yields θ_support ≈ 1.21 × 10⁻³ rad (≈ 0.069°).  

Report the maximum midspan deflection as 1.21 mm and the support slope as 1.21 × 10⁻³ rad.
