The rod cross‑sectional area is A = π (20 mm)² / 4 = 100π mm² ≈ 314.16 mm².  
The average normal stress is σ_avg = 15000 N / A ≈ 15000 N / 314.16 mm² = 47.75 MPa.  
The elastic normal strain is ε = σ_avg / E = 47.75 MPa / 69000 MPa ≈ 6.93 × 10⁻⁴ (unitless).  
The axial elongation of the 800 mm gage length is ΔL = ε · L₀ = 6.93 × 10⁻⁴ × 800 mm ≈ 0.55 mm.  
The factor of safety against yielding, using n = S_y / σ_avg, is n = 275 MPa / 47.75 MPa ≈ 5.76.
