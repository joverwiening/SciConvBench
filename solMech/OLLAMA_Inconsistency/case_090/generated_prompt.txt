Compute the reactions of the real beam: RA = P·(L‑a)/L = 800·(3000‑2000)/3000 = 800/3 N, RB = P‑RA = 1600/3 N.  
Form the real bending moment diagram M(x):  
- For 0 ≤ x ≤ 2000 mm, M(x) = RA·x = (800/3)·x.  
- For 2000 mm ≤ x ≤ 3000 mm, M(x) = RA·x – P·(x‑2000) = –(1600/3)·x + 1 600 000.  

Apply a unit vertical load at x = 2000 mm. Compute the auxiliary reactions: RA_u = (L‑a)/L = 1/3, RB_u = a/L = 2/3.  
Form the auxiliary bending moment diagram m(x):  
- For 0 ≤ x ≤ 2000 mm, m(x) = RA_u·x = (1/3)·x.  
- For 2000 mm ≤ x ≤ 3000 mm, m(x) = RA_u·x – 1·(x‑2000) = –(2/3)·x + 2000.  

Integrate the product M·m over the beam length and divide by EI:  

δ = (1/(E·I)) [ ∫₀^{2000} (800/3 x)(1/3 x) dx + ∫_{2000}^{3000} (–1600/3 x+1 600 000)(–2/3 x+2000) dx ]  

Evaluate the integrals:  

I₁ = (800/9) ∫₀^{2000} x² dx = (800/9)·(2000³/3) = 2.37037037 × 10¹¹  
I₂ = ∫_{2000}^{3000} [ (3200/9) x² – (6 400 000/3) x + 3 200 000 000 ] dx = 1.18518519 × 10¹¹  

Total I = I₁ + I₂ = 3.55555556 × 10¹¹  

EI = E·I = 200 000 MPa · 1 200 000 mm⁴ = 2.4 × 10¹¹ N·mm²  

Deflection at the load point:  

δ = I / (EI) = 3.55555556 × 10¹¹ / 2.4 × 10¹¹ = 1.48148148 mm  

Therefore, the vertical deflection at x = 2000 mm is approximately 1.48 mm downward.
