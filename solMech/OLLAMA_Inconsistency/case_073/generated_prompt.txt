Use the given units N·mm for forces and MPa (N/mm²) for stresses.  
Apply the bending stress formula with the extreme‑fiber distance taken as half the height: σ_max = M_max (h/2) / (b h³/12).  
Simplify the expression to σ_max = (6 M_max) / (b h²).  
Set σ_max equal to the allowable stress and solve for h: h² = (6 M_max) / (b σ_allow).  
Substitute M_max = 6 000 000 N·mm, b = 60 mm, and σ_allow = 170 MPa (170 N/mm²).  
Calculate h² = (6 × 6 000 000) / (60 × 170) ≈ 3529.4 mm².  
Take the square root to obtain h ≈ 59.4 mm.  
Select the next higher practical dimension, so the minimum required height is h = 60 mm.
