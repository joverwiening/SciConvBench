Compute the cross‑sectional area A as b × h = 60 mm × 100 mm = 6000 mm².  
Calculate the average normal stress σ = P/A = 40000 N / 6000 mm² = 6.667 MPa.  
Calculate the average shear stress τ = V/A = 16000 N / 6000 mm² = 2.667 MPa.  
Treat the stress state as plane stress with σx = σ, σy = 0, τxy = τ.  
Determine the principal stresses using σ1,2 = (σx+σy)/2 ± √[((σx‑σy)/2)² + τxy²].  
The principal stresses are σ1 = 7.602 MPa and σ2 = –0.936 MPa.  
The maximum in‑plane shear stress is τmax = √[((σx‑σy)/2)² + τxy²] = 4.269 MPa.
