Compute the polar moment of inertia for the circular cross‑section:  
J = π d⁴ / 32 = π (30 mm)⁴ / 32 ≈ 7.95 × 10⁴ mm⁴.

Determine the effective length:  
K L = 2.0 × 1500 mm = 3000 mm, so (K L)² = 9.0 × 10⁶ mm².

Calculate the Euler critical load using the given expression:  
P_cr = π² E J / (K L)² = (π²)(200 000 N/mm²)(7.95 × 10⁴ mm⁴) / 9.0 × 10⁶ mm² ≈ 1.74 × 10⁴ N ≈ 17.4 kN.

Apply the factor of safety n = 2.0 to obtain the allowable axial compressive load:  
P_allow = P_cr / n = 17.4 kN / 2 ≈ 8.7 kN.
