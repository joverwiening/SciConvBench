Use the given units N‑mm‑MPa throughout the calculation.  
Set the required critical load as n·P = 2.0 × 30000 N = 60000 N.  
Write the Euler buckling formula for a solid circular column:  
Pcr = π² E I / (K L)², with I = π d⁴ / 64 and K = 1.0.  
Substitute I into Pcr to obtain:  
Pcr = (π³ E d⁴) / (64 L²).  
Impose the safety requirement Pcr ≥ 60000 N:  
(π³ E d⁴) / (64 L²) ≥ 60000.  
Solve for d⁴:  
d⁴ ≥ (60000 × 64 L²) / (π³ E).  
Insert the numerical values L = 1800 mm, E = 200000 MPa, π ≈ 3.14159:  
d⁴ ≥ (60000 × 64 × 1800²) / (π³ × 200000)  
d⁴ ≥ 2.006 × 10⁶ mm⁴.  
Take the fourth‑root:  
d ≥ (2.006 × 10⁶)¹⁄⁴ ≈ 37.6 mm.  
Select the next higher standard size for safety, e.g., d = 38 mm.  

The minimum required diameter of the solid circular steel column is 38 mm.
