Define the bending moment distribution for the simply supported beam with a central point load P as  
M(x) = (P/2)·x for 0 ≤ x ≤ L/2,  
M(x) = (P/2)·(L − x) for L/2 ≤ x ≤ L.  

Compute the strain energy using the bending strain‑energy expression  
U = ∫₀ᴸ [M(x)² / (2 E I)] dx,  

which evaluates to  
U = P² L³ / (96 E I).  

Apply Castigliano’s theorem: the vertical deflection at the load point is the partial derivative of U with respect to P, giving  
δ = ∂U/∂P = P L³ / (48 E I).  

Insert the given data (P = 2000 N, L = 3000 mm, E = 200000 MPa, I = 3000000 mm⁴) and compute:  
δ = (2000 N · 3000³ mm³) / [48 · 200000 N/mm² · 3000000 mm⁴] = 1.875 mm.  

State the result: the vertical deflection at midspan is 1.875 mm downward.
