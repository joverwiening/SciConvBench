Compute the cross‑sectional area A as b × h = 50 mm × 80 mm = 4000 mm².  
Calculate the average normal stress σ = P / A = 40000 N / 4000 mm² = 10 N/mm² = 10 MPa.  
Calculate the average shear stress τ = V / A = 12000 N / 4000 mm² = 3 N/mm² = 3 MPa.  
Treat the stress state as plane stress with σx = σ, σy = 0, τxy = τ.  
Compute the principal stresses using σ1,2 = (σx+σy)/2 ± √[((σx−σy)/2)² + τxy²].  
Thus σ1 = 5 MPa + √(5² + 3²) MPa = 5 MPa + √34 MPa ≈ 10.831 MPa.  
σ2 = 5 MPa – √34 MPa ≈ –0.831 MPa.  
The maximum in‑plane shear stress is τmax = √[((σx−σy)/2)² + τxy²] = √34 MPa ≈ 5.831 MPa.
