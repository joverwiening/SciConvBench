Compute the polar moment of inertia J using the diameter d = 30 mm:  
J = π d⁴ / 32 = π (30 mm)⁴ / 32 ≈ 7.952 × 10⁴ mm⁴.

Calculate the angle of twist φ with Castigliano’s theorem, using the torsional strain‑energy expression U = ∫₀ᴸ T²/(2 G J) dx and φ = ∂U/∂T = T L / (G J):

φ = (T · L) / (G · J) = (450 000 N·mm · 1000 mm) / (25939.8 MPa · 7.952 × 10⁴ mm⁴)  

= 4.5 × 10⁸ N·mm² / 2.0627 × 10⁹ N·mm² ≈ 0.218 rad.
