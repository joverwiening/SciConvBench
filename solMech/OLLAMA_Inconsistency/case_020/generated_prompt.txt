Use N·mm–MPa units throughout.  
The shaft has diameter d = 35 mm, length L = 1200 mm, and is fixed at x = 0.  
A torque T1 = 200 000 N·mm (positive sense) is applied at the free end x = L.  
A torque T2 = –250 000 N·mm (negative sense) is applied at x = a = 800 mm.  
The material shear modulus is G = 77 519.4 MPa.  

1. Compute the polar moment of inertia of the circular cross‑section:  
   J = π d⁴ / 32 = π (35 mm)⁴ / 32 ≈ 1.4726 × 10⁵ mm⁴.  

2. Determine the internal torque in each segment by taking the algebraic sum of all external torques acting to the right of the section:  
   • For 0 < x < a (0 → 800 mm): internal torque T_int₁ = T1 = +200 000 N·mm.  
   • For a < x < L (800 mm → 1200 mm): internal torque T_int₂ = T1 + T2 = +200 000 N·mm – 250 000 N·mm = –50 000 N·mm.  

3. Compute the maximum shear stress in each segment using τ_max = |T_int| c / J, where c = d/2 = 17.5 mm:  
   • Segment 0 → a: τ_max₁ = (200 000 N·mm)(17.5 mm) / 1.4726 × 10⁵ mm⁴ ≈ 23.8 MPa.  
   • Segment a → L: τ_max₂ = (50 000 N·mm)(17.5 mm) / 1.4726 × 10⁵ mm⁴ ≈ 5.9 MPa.  

4. Compute the angle of twist of each segment using θ = T_int L_seg / (G J):  
   • Segment 0 → a (L₁ = 800 mm): θ₁ = (200 000 N·mm)(800 mm) / (77 519.4 MPa · 1.4726 × 10⁵ mm⁴) ≈ 0.0140 rad.  
   • Segment a → L (L₂ = 400 mm): θ₂ = (–50 000 N·mm)(400 mm) / (77 519.4 MPa · 1.4726 × 10⁵ mm⁴) ≈ –0.00175 rad.  

5. Sum the twists to obtain the total angle of twist at the free end relative to the fixed end:  
   θ_total = θ₁ + θ₂ ≈ 0.0123 rad ≈ 0.70°.  

The internal torque distribution, maximum shear stresses, and total angle of twist are thus fully specified.
