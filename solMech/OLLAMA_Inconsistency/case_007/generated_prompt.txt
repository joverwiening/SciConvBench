Use the given beam data: span L = 1800 mm, modulus E = 200000 MPa, second moment of area I = 3500000 mm⁴, point load P = 2000 N at x = 900 mm.  
Treat the supports as simple (zero vertical displacement, zero rotation).  

1. Compute real reactions: RA = RB = P/2 = 1000 N.  
2. Form the real bending moment diagram M(x):  
   - For 0 ≤ x ≤ 900 mm, M(x) = RA·x = 1000 x (N·mm).  
   - For 900 ≤ x ≤ 1800 mm, M(x) = RA·x – P·(x‑900) = –1000 x + 1 800 000 (N·mm).  

3. In the auxiliary (virtual) system apply a unit vertical downward load at x = 900 mm.  
   - Virtual reactions: rA = rB = 0.5 N.  
   - Virtual bending moment diagram m(x):  
     * For 0 ≤ x ≤ 900 mm, m(x) = rA·x = 0.5 x (N·mm).  
     * For 900 ≤ x ≤ 1800 mm, m(x) = rA·x – 1·(x‑900) = –0.5 x + 900 (N·mm).  

4. Evaluate the unit‑load integral  
   \[
   \delta = \frac{1}{EI}\int_{0}^{L} M(x)\,m(x)\,dx
   \]  
   - For 0 ≤ x ≤ 900 mm, M·m = 500 x².  
     \[
     I_1 = \int_{0}^{900} 500x^{2}\,dx = \frac{500}{3} (900)^{3}=1.215\times10^{11}
     \]  
   - For 900 ≤ x ≤ 1800 mm, M·m = 500 x² – 1.8\times10^{6}x + 1.62\times10^{9}.  
     \[
     I_2 = \int_{900}^{1800}\!\!\bigl(500x^{2} - 1.8\times10^{6}x + 1.62\times10^{9}\bigr)dx =1.215\times10^{11}
     \]  
   - Total integral \(I = I_1 + I_2 = 2.43\times10^{11}\).  

5. Compute EI: \(EI = 200000\;\text{MPa}\times 3500000\;\text{mm}^4 = 7.0\times10^{11}\;\text{N·mm}^2\).  

6. Deflection at the load point:  
   \[
   \delta = \frac{2.43\times10^{11}}{7.0\times10^{11}} = 0.347\;\text{mm}
   \]  

The vertical deflection at x = 900 mm is approximately **0.347 mm downward**.
