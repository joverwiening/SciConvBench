Define the bending moment distribution for the simply supported beam with a point load P at midspan (x = L/2):
- For 0 ≤ x ≤ L/2, M(x) = (P/2)·x.
- For L/2 ≤ x ≤ L, M(x) = (P/2)·(L − x).

Compute the total bending strain energy:
U = ∫₀ᴸ [M(x)² / (2 E I)] dx
= 2 · ∫₀ᴸ⁄₂ [(P/2)² x² / (2 E I)] dx
= (P² L³) / (96 E I).

Apply Castigliano’s theorem to obtain the vertical deflection at the load point:
δ = ∂U/∂P = (P L³) / (48 E I).

Insert the given numerical values (using N‑mm‑MPa units):
- P = 1000 N
- L = 2500 mm
- E = 200 000 MPa
- I = 3 000 000 mm⁴

δ = (1000 · 2500³) / (48 · 200 000 · 3 000 000) mm
= 0.00054 mm (approximately).

Thus the vertical deflection at midspan is about 5.4 × 10⁻⁴ mm.
