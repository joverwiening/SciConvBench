Use the given axial load P = 25000 N and material modulus E = 200000 MPa.

Compute the cross‑sectional areas:
A1 = π · (d1)² / 4 with d1 = 16 mm.
A2 = π · (d2)² / 4 with d2 = 40 mm.

Calculate the normal stress in each segment using σ = P / A:
σ1 = 25000 N / A1 (result in MPa).
σ2 = 25000 N / A2 (result in MPa).

Determine the axial elongation of each segment using δ = P · L / (A · E):
δ1 = 25000 N · 400 mm / (A1 · 200000 MPa) (result in mm).
δ2 = 25000 N · 400 mm / (A2 · 200000 MPa) (result in mm).

Compute the total elongation of the bar as the sum of the segment elongations:
Δtotal = δ1 + δ2 (result in mm).
