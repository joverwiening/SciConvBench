Model the beam as simply supported: vertical deflection y = 0 at x = 0 and x = L; slopes are free (only the left‑support slope is to be reported).  

1. Compute the maximum deflection using the closed‑form expression for a simply supported beam under a uniform distributed load:  
 y(x) = (w · x · (L³ − 2 L x² + x³)) / (24 E I).

 Maximum deflection y_max ≈ 3.26 mm (downward).

 θ₀ = (w · L³) / (24 E I) ≈ 0.003 rad (≈ 0.17°).
