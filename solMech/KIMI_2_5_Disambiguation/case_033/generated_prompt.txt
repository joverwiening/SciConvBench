Assume small-deformation, linear-elastic solid mechanics.

Assume Euler-Bernoulli beam theory applies.

Assume the beam has constant flexural rigidity EI along its length.

Assume the beam has length L.

Assume the point load P is applied at midspan (x = L/2).

Assume shear loading refers to transverse shear force, which is already accounted for in the point load case.

Assume self-weight of the beam is negligible.

Assume the beam is prismatic with symmetric cross-section.

Assume material is homogeneous and isotropic.

The governing differential equation for Euler-Bernoulli beam theory is: EI * (d^4w/dx^4) = q(x), where w is transverse deflection and q(x) is distributed load.

For a point load P at midspan, use discontinuity functions or solve two segments: 0 ≤ x ≤ L/2 and L/2 ≤ x ≤ L.

Boundary conditions for simply supported beam: w(0) = 0, w(L) = 0, M(0) = EI*(d^2w/dx^2)|_{x=0} = 0, M(L) = EI*(d^2w/dx^2)|_{x=L} = 0.

Continuity conditions at midspan: deflection continuity w(L/2^-) = w(L/2^+), slope continuity dw/dx|_{x=L/2^-} = dw/dx|_{x=L/2^+}, shear jump condition: V(L/2^+) - V(L/2^-) = -P.

The midspan deflection is: w(L/2) = -P*L^3 / (48*EI), with negative sign indicating downward deflection.

The support slope magnitude is: |dw/dx|_{x=0} = |dw/dx|_{x=L} = P*L^2 / (16*EI).

The bending moment distribution is: M(x) = P*x/2 for 0 ≤ x ≤ L/2, and M(x) = P*(L-x)/2 for L/2 ≤ x ≤ L.

The maximum bending moment occurs at midspan: M_max = P*L/4.

The shear force distribution is: V(x) = P/2 for 0 ≤ x < L/2, and V(x) = -P/2 for L/2 < x ≤ L.

The transverse shear stress is computed from τ = V*Q/(I*b), where Q is first moment of area and b is width at the location of interest.

The maximum normal stress due to bending is: σ_max = M_max*c/I = (P*L/4)*c/I, where c is distance from neutral axis to outer fiber.
