The system consists of two rigid plates connected by two parallel bars subjected to axial tension.

The total tensile load P = 20000 N is applied to the top plate.

Bar 1 is AISI 1020 steel with cross-sectional area A1 = 300 mm² and Young's modulus E1 = 200000 MPa.

Bar 2 is 6061-T6 aluminum with cross-sectional area A2 = 200 mm² and Young's modulus E2 = 69000 MPa.

Both bars have equal length L = 500 mm.

The deformation is small and the material behavior is linear-elastic.

For composite bars in parallel, the key kinematic assumption is that both bars undergo equal elongation: δ1 = δ2 = δ.

The compatibility condition requires equal strains: ε1 = ε2 = ε = δ/L.

The constitutive relations give the stresses: σ1 = E1·ε and σ2 = E2·ε.

The internal forces in each bar are: P1 = σ1·A1 = E1·A1·ε and P2 = σ2·A2 = E2·A2·ε.

The equilibrium equation requires: P = P1 + P2 = (E1·A1 + E2·A2)·ε.

The equivalent axial stiffness of the parallel system is: Keq = E1·A1 + E2·A2.

The common strain is: ε = P / (E1·A1 + E2·A2).

The elongation of the system is: δ = P·L / (E1·A1 + E2·A2).

The load carried by each bar is: P1 = P·(E1·A1)/(E1·A1 + E2·A2) and P2 = P·(E2·A2)/(E1·A1 + E2·A2).

The stress in each bar is: σ1 = P·E1/(E1·A1 + E2·A2) and σ2 = P·E2/(E1·A1 + E2·A2).

Numerical values: E1·A1 = 200000 MPa × 300 mm² = 60000 kN, E2·A2 = 69000 MPa × 200 mm² = 13800 kN, Keq = 73800 kN.

The common strain: ε = 20000 N / 73800000 N = 2.710×10⁻⁴ (dimensionless).

The elongation: δ = 2.710×10⁻⁴ × 500 mm = 0.1355 mm.

Load in bar 1: P1 = 20000 × (60000/73800) = 16260.2 N.

Load in bar 2: P2 = 20000 × (13800/73800) = 3739.8 N.

Stress in bar 1: σ1 = 16260.2 N / 300 mm² = 54.20 MPa.

Stress in bar 2: σ2 = 3739.8 N / 200 mm² = 18.70 MPa.
