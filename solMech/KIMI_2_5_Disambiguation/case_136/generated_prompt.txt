The beam is a simply supported beam with total span length L = 6000 mm.

Support A is located at x = 0. Support B is located at x = L = 6000 mm.

A single concentrated vertical load P = 20000 N acts downward at x = a = 2000 mm from support A.

The material follows small-deformation, linear-elastic solid mechanics.

The beam has constant cross-sectional properties along its length.

Self-weight of the beam is neglected.

Vertical reactions at supports A and B are determined from static equilibrium.

Sum of vertical forces equals zero: R_A + R_B - P = 0.

Sum of moments about support A equals zero: R_B * L - P * a = 0.

Solving gives R_B = P * a / L = 20000 * 2000 / 6000 = 6666.67 N.

Solving gives R_A = P - R_B = 20000 - 6666.67 = 13333.33 N.

The internal shear force V(x) is piecewise constant due to the concentrated load.

For 0 < x < a: V(x) = R_A = 13333.33 N.

For a < x < L: V(x) = R_A - P = 13333.33 - 20000 = -6666.67 N.

At x = a, the shear force has a discontinuity equal to the applied load P.

The internal bending moment M(x) varies linearly in each segment.

For 0 ≤ x ≤ a: M(x) = R_A * x = 13333.33 * x N·mm.

For a ≤ x ≤ L: M(x) = R_A * x - P * (x - a) = 13333.33 * x - 20000 * (x - 2000) N·mm.

The maximum bending moment occurs at x = a where shear force changes sign.

M_max = M(a) = 13333.33 * 2000 = 26,666,667 N·mm = 26.67 kN·m.

The bending moment is zero at both supports: M(0) = 0 and M(L) = 0.

Sign convention: positive shear causes clockwise rotation of the element, positive bending moment causes compression in the top fiber.
