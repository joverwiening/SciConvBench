The beam is a simply-supported Euler-Bernoulli beam with span length L = 2000 mm.

The beam carries a single concentrated load P = 3000 N applied at midspan (x = L/2 = 1000 mm from each support).

The material is 6061-T6 aluminum with Young's modulus E = 69000 MPa.

The cross-section is rectangular with width b = 30 mm and unknown height h (to be determined).

The maximum allowable deflection is δ_allow = 3 mm (absolute value).

The governing relation for maximum deflection at midspan of a simply-supported beam with central point load is δ_max = PL³ / (48EI).

The second moment of area for a rectangular cross-section is I = bh³ / 12.

Substituting I into the deflection equation gives δ_max = PL³ / (48E × bh³/12) = PL³ / (4Ebh³).

Setting δ_max = δ_allow and solving for the required height h gives h_required = [PL³ / (4Ebδ_allow)]^(1/3).

Numerical substitution yields h_required = [(3000 N)(2000 mm)³ / (4 × 69000 MPa × 30 mm × 3 mm)]^(1/3) = 24.0 / 0.828 / 0.669 → h_required = 36.6 mm.

The minimum required beam height is h_min = 36.6 mm, which should be rounded up to a practical value such as h = 40 mm for design purposes.
