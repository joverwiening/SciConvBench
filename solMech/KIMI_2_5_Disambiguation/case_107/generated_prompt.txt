The governing differential equation for small-deformation, linear-elastic beam bending is:

EI * d^4v/dx^4 = w

where v(x) is the transverse deflection, E is Young's modulus, I is the second moment of area, and w is the uniformly distributed transverse load.

For a simply supported beam of span length L with coordinate x measured from the left support, the boundary conditions are:
v(0) = 0
v(L) = 0
M(0) = EI * d^2v/dx^2 |_{x=0} = 0
M(L) = EI * d^2v/dx^2 |_{x=L} = 0

The general solution obtained by four successive integrations is:
EI * v(x) = (w*x^4)/24 + (C1*x^3)/6 + (C2*x^2)/2 + C3*x + C4

Applying the boundary conditions yields the integration constants:
C1 = -w*L/2
C2 = 0
C3 = w*L^3/24
C4 = 0

The deflection equation is:
v(x) = (w*x)/(24*EI) * (L^3 - 2*L*x^2 + x^3)

The slope equation is:
theta(x) = dv/dx = (w)/(24*EI) * (L^3 - 6*L*x^2 + 4*x^3)

The maximum deflection occurs at midspan x = L/2:
v_max = (5*w*L^4)/(384*EI) = (5 * 0.7 N/mm * (2500 mm)^4) / (384 * 200000 MPa * 2000000 mm^4) = 8.93 mm

The maximum slope occurs at the supports x = 0 and x = L:
theta_max = (w*L^3)/(24*EI) = (0.7 N/mm * (2500 mm)^3) / (24 * 200000 MPa * 2000000 mm^4) = 0.00568 rad = 0.326 degrees

The end slopes are equal in magnitude and opposite in sign, with theta(0) = +w*L^3/(24*EI) and theta(L) = -w*L^3/(24*EI).
