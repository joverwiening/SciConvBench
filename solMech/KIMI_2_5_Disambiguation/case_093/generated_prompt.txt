The simply supported beam has span length L = 3000 mm with flexural rigidity EI = 2.4 × 10^11 N·mm^2.

A concentrated downward point load P = 800 N is applied at x = 2000 mm from the left support.

The deflection at the load point (x = 2000 mm) is to be determined using the unit-load method.

The unit-load method requires application of a virtual unit load at the point and in the direction of the desired displacement.

The real moment distribution M(x) is determined from static equilibrium for the actual loading.

The virtual moment distribution m(x) is determined from static equilibrium for a unit load applied at x = 2000 mm.

The deflection at the load point is given by the integral of M(x)·m(x)/EI over the beam length.

For a simply supported beam with point load P at distance a = 2000 mm from left support and b = 1000 mm from right support:

The reaction at the left support is R_A = P·b/L = 800 × 1000/3000 = 266.67 N.

The reaction at the right support is R_B = P·a/L = 800 × 2000/3000 = 533.33 N.

The real moment in region 0 ≤ x ≤ a is M(x) = R_A·x = (P·b/L)·x.

The real moment in region a ≤ x ≤ L is M(x) = R_B·(L-x) = (P·a/L)·(L-x).

For virtual unit load at x = a = 2000 mm, the virtual reactions are r_A = b/L = 1/3 and r_B = a/L = 2/3.

The virtual moment in region 0 ≤ x ≤ a is m(x) = r_A·x = (b/L)·x.

The virtual moment in region a ≤ x ≤ L is m(x) = r_B·(L-x) = (a/L)·(L-x).

The deflection at x = a is Δ = (1/EI) × [integral from 0 to a of M(x)·m(x) dx + integral from a to L of M(x)·m(x) dx].

Evaluating the integrals: first integral gives (P·b²·a³)/(3·L²) and second integral gives (P·a²·b³)/(3·L²).

The total deflection is Δ = (P·a²·b²)/(3·E·I·L) = (800 × 2000² × 1000²)/(3 × 2.4×10^11 × 3000) = 1.481 mm downward.
