Assume a circular solid cross-section with diameter d = 50 mm based on typical slender column proportions for the given length.

The column has fixed-pinned end conditions with effective length factor K = 0.7.

The column length is L = 2000 mm.

The material is AISI 1020 steel with elastic modulus E = 200000 MPa.

The analysis assumes small-deformation, linear-elastic solid mechanics.

The governing relation for Euler critical buckling load is P_cr = (π² * E * I) / (K * L)².

The area moment of inertia for a circular solid cross-section is I = (π * d⁴) / 64.

Substituting d = 50 mm yields I = (π * 50⁴) / 64 = 306796 mm⁴.

The effective length is L_e = K * L = 0.7 * 2000 = 1400 mm.

The Euler critical buckling load is P_cr = (π² * 200000 * 306796) / (1400)² = 308.4 kN.

The cross-sectional area is A = (π * d²) / 4 = (π * 50²) / 4 = 1963.5 mm².

The critical buckling stress is σ_cr = P_cr / A = 308400 / 1963.5 = 157.1 MPa.

For AISI 1020 steel, typical yield strength is σ_y = 350 MPa.

The slenderness ratio is λ = (K * L) / r where r = √(I/A) = √(306796/1963.5) = 12.5 mm, giving λ = 1400 / 12.5 = 112.

The limiting slenderness ratio for Euler buckling validity is λ_limit = π * √(E / σ_y) = π * √(200000 / 350) = 75.1.

Since λ = 112 > λ_limit = 75.1, Euler buckling governs and elastic buckling occurs before yielding.

The safety factor against buckling should be evaluated based on applied load; if applied load P_applied is specified, check P_applied < P_cr / FS where typical FS = 1.5 to 3.0 for compression members.
