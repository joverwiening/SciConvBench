The beam is a simply supported beam of span length L = 3000 mm with supports at A (x = 0) and B (x = L).

A concentrated vertical load P = 12000 N acts downward at midspan, located at x = 1500 mm from support A.

The analysis assumes small-deformation, linear-elastic solid mechanics.

The axial tension is zero.

The applied moment is zero.

No other loads are present.

The support reactions are determined from static equilibrium.

Sum of vertical forces equals zero: R_A + R_B - P = 0.

Sum of moments about support A equals zero: R_B * L - P * (L/2) = 0.

Solving gives R_B = P/2 = 6000 N and R_A = P/2 = 6000 N.

The internal shear force V(x) is defined as follows.

For 0 <= x < L/2: V(x) = R_A = 6000 N (constant, positive).

For L/2 < x <= L: V(x) = R_A - P = -6000 N (constant, negative).

At x = L/2, the shear force has a discontinuity of magnitude P, dropping from +6000 N to -6000 N.

The internal bending moment M(x) is defined as follows.

For 0 <= x <= L/2: M(x) = R_A * x = 6000 * x N·mm.

At x = 0: M = 0.

At x = L/2: M = 6000 * 1500 = 9,000,000 N·mm = 9.0 kN·m.

For L/2 <= x <= L: M(x) = R_A * x - P * (x - L/2) = 6000 * x - 12000 * (x - 1500) = 6000 * (3000 - x) N·mm.

At x = L/2: M = 9,000,000 N·mm (continuous).

At x = L: M = 0.

The maximum bending moment occurs at midspan and equals M_max = P*L/4 = 9,000,000 N·mm = 9.0 kN·m.

The shear force diagram consists of two rectangular regions: positive constant 6000 N from 0 to 1500 mm, and negative constant -6000 N from 1500 mm to 3000 mm.

The bending moment diagram is triangular, increasing linearly from 0 at the supports to maximum at midspan, forming a symmetric triangle with peak value 9.0 kN·m.

Additional assumptions include: the beam is prismatic with constant cross-section, the material is homogeneous and isotropic, plane sections remain plane (Euler-Bernoulli beam theory), and self-weight of the beam is neglected.
