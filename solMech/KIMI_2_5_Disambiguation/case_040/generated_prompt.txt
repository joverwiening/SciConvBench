The beam is simply supported with span length L = 3000 mm.

The beam is subjected to a central point load P = 2000 N acting at midspan.

The second moment of area is I = 1500000 mm^4.

The material is structural steel with Young's modulus E = 200000 MPa.

The analysis assumes small-deformation, linear-elastic solid mechanics.

The analysis uses Castigliano's second theorem to determine midspan deflection.

The strain energy due to bending is U = integral from 0 to L of (M^2 / 2EI) dx.

The beam is symmetric about midspan, so analysis considers 0 <= x <= L/2.

For 0 <= x <= L/2, the bending moment is M(x) = (P/2) * x.

The partial derivative of moment with respect to P is dM/dP = x/2.

By Castigliano's theorem, the midspan deflection is delta = dU/dP = (1/EI) * integral from 0 to L/2 of M * (dM/dP) dx.

Substituting the moment expression gives delta = (1/EI) * integral from 0 to L/2 of (Px/2) * (x/2) dx.

Evaluating the integral yields delta = (P / 4EI) * [x^3 / 3] from 0 to L/2 = (P / 4EI) * (L^3 / 24) = PL^3 / (48EI).

The final expression for midspan deflection is delta = PL^3 / (48EI).

Numerical substitution gives delta = (2000 N) * (3000 mm)^3 / (48 * 200000 MPa * 1500000 mm^4) = 7.5 mm.

Shear deformation effects are neglected as per standard Euler-Bernoulli beam theory assumptions.

The cross-sectional shape is not specified; only the second moment of area I is used in the analysis.
