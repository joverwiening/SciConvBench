The column is made of structural steel with Young's modulus E = 200000 MPa.

The yield strength of structural steel is assumed to be 250 MPa based on common ASTM A36 specifications.

The column length is L = 1800 mm with pinned-pinned end conditions, giving an effective length factor K = 1.0.

The applied compressive load is P = 30000 N.

The required factor of safety against buckling is n = 2.0.

The analysis assumes small-deformation, linear-elastic solid mechanics behavior.

The critical buckling load is governed by Euler's formula: P_cr = (π² * E * I) / (K * L)².

For a solid circular cross-section, the area moment of inertia is I = (π * d⁴) / 64.

The required moment of inertia to achieve the target factor of safety is found by setting P_cr = n * P, yielding I_req = (n * P * (K * L)²) / (π² * E).

Substituting values: I_req = (2.0 * 30000 N * (1.0 * 1800 mm)²) / (π² * 200000 MPa) = 9842.6 mm⁴.

The required diameter is found from d_req = (64 * I_req / π)^(1/4) = (64 * 9842.6 mm⁴ / π)^(1/4) = 18.8 mm.

The design diameter is selected as d = 19 mm (or next standard size, e.g., 20 mm).

The actual moment of inertia with d = 19 mm is I = (π * 19⁴) / 64 = 10179 mm⁴.

The actual critical buckling load is P_cr = (π² * 200000 MPa * 10179 mm⁴) / (1.0 * 1800 mm)² = 31003 N.

The actual factor of safety against buckling is n_actual = P_cr / P = 31003 N / 30000 N = 1.03, which does not meet the requirement.

Using d = 20 mm: I = (π * 20⁴) / 64 = 12566 mm⁴, P_cr = 38294 N, n_actual = 1.28, still insufficient.

Using d = 22 mm: I = (π * 22⁴) / 64 = 18298 mm⁴, P_cr = 55720 N, n_actual = 1.86, still insufficient.

Using d = 24 mm: I = (π * 24⁴) / 64 = 26055 mm⁴, P_cr = 79348 N, n_actual = 2.64, which exceeds the required n = 2.0.

The minimum adequate diameter is d = 23.8 mm, so select d = 24 mm for the design.

The actual factor of safety with d = 24 mm is n_actual = 2.64.

The compressive stress at the applied load is σ = P / A = 30000 N / (π * 24² / 4 mm²) = 66.3 MPa, which is well below the assumed yield strength of 250 MPa, confirming elastic buckling governs the design.
