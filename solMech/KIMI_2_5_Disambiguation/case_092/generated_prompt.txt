The specification is complete. The governing relations and solution for the axially loaded bar with multiple point loads are as follows.

Assumptions:
The material is linear elastic and isotropic.
Deformations are small, so geometric linearity applies.
The bar is prismatic with constant cross-sectional area throughout.
Plane sections remain plane (Saint-Venant's principle applies away from load points).
Self-weight of the bar is neglected.
Axial loads are applied concentrically (no bending induced).

Governing Relations:
Equilibrium: dN/dx + q = 0, where N is axial force and q is distributed load (here q = 0).
Constitutive: sigma = E * epsilon, where sigma is axial stress, E is Young's modulus, epsilon is axial strain.
Kinematic: epsilon = du/dx, where u is axial displacement.
Combined: N = EA * du/dx.

Solution Procedure:
First determine the internal axial force in each segment by equilibrium.
Segment AB (0 <= x <= 700 mm): Sum forces from right end. Forces at C and D: -12000 + 10000 = -2000 N (net leftward). With no force at D affecting AB directly, use free body diagram from left. At A, reaction R_A balances all applied loads: R_A + 15000 - 12000 + 10000 = 0, so R_A = -13000 N (13000 N to the left, or negative x).
Segment AB internal force N_AB = R_A = -13000 N (compressive).
Segment BC (700 <= x <= 1100 mm): N_BC = R_A + 15000 = 2000 N (tensile).
Segment CD (1100 <= x <= 1400 mm): N_CD = 2000 - 12000 = -10000 N (compressive), or check: N_CD = -10000 N balances the 10000 N at D.

Displacement calculation using u(x) = u(start) + N*(x-x_start)/(EA):
EA = 200000 MPa * 500 mm² = 100000 N/mm² = 100 kN/mm.
u_A = 0 (fixed).
u_B = u_A + N_AB * L_AB / (EA) = 0 + (-13000)(700) / 100000 = -91 mm.
u_C = u_B + N_BC * L_BC / (EA) = -91 + (2000)(400) / 100000 = -91 + 8 = -83 mm.
u_D = u_C + N_CD * L_CD / (EA) = -83 + (-10000)(300) / 100000 = -83 - 30 = -113 mm.

Stresses: sigma = N/A.
sigma_AB = -13000/500 = -26 MPa (compressive).
sigma_BC = 2000/500 = 4 MPa (tensile).
sigma_CD = -10000/500 = -20 MPa (compressive).

Strains: epsilon = sigma/E = N/(EA).
epsilon_AB = -13000/100000 = -0.13.
epsilon_BC = 2000/100000 = 0.02.
epsilon_CD = -10000/100000 = -0.10.

Elongations per segment: delta = NL/(EA).
delta_AB = -91 mm (shortening).
delta_BC = 8 mm (elongation).
delta_CD = -30 mm (shortening).
Total elongation: -113 mm (net shortening).
