Assume small-deformation, linear-elastic solid mechanics.

The structural member is a rectangular prismatic member with width b = 50 mm and height h = 80 mm.

The tension load is an internal resultant normal force P = 40000 N (tension). The shear load is an internal shear force V = 12000 N, acting parallel to the width.

Use uniform average stress approximations: σ = P/A and τ = V/A, where A = b × h = 4000 mm².

Treat the stress state at a point as plane stress: σx = σ, σy = 0, τxy = τ.

Compute the average normal stress: σ = P/A = 40000 N / 4000 mm² = 10 MPa (tension).

Compute the average shear stress: τ = V/A = 12000 N / 4000 mm² = 3 MPa.

The plane stress state is: σx = 10 MPa, σy = 0 MPa, τxy = 3 MPa.

Compute the principal stresses using the plane stress transformation equations.

The center of Mohr's circle: σavg = (σx + σy)/2 = (10 + 0)/2 = 5 MPa.

The radius of Mohr's circle: R = √[((σx - σy)/2)² + τxy²] = √[(5)² + (3)²] = √(25 + 9) = √34 ≈ 5.831 MPa.

The principal stresses are: σ1 = σavg + R = 5 + 5.831 = 10.831 MPa, σ2 = σavg - R = 5 - 5.831 = -0.831 MPa.

The maximum in-plane shear stress equals the radius: τmax,in-plane = R = 5.831 MPa.

The principal angle θp is found from: tan(2θp) = 2τxy/(σx - σy) = 6/10 = 0.6, so 2θp = 30.96° and θp = 15.48° from the x-axis.

For principal strains under plane stress, use Hooke's law with assumed material properties: Young's modulus E = 200 GPa (typical steel) and Poisson's ratio ν = 0.3.

The principal strains are: ε1 = (σ1 - νσ2)/E = (10.831 - 0.3×(-0.831))/200000 = 55.5×10⁻⁶, ε2 = (σ2 - νσ1)/E = (-0.831 - 0.3×10.831)/200000 = -20.5×10⁻⁶.

The out-of-plane principal strain: ε3 = -ν(σ1 + σ2)/E = -0.3×(10.831 - 0.831)/200000 = -15.0×10⁻⁶.

Report all response quantities with appropriate significant figures: principal stresses σ1 = 10.8 MPa, σ2 = -0.831 MPa; maximum in-plane shear stress τmax = 5.83 MPa; principal strains ε1 = 55.5 με, ε2 = -20.5 με, ε3 = -15.0 με; principal angle θp = 15.5°.
