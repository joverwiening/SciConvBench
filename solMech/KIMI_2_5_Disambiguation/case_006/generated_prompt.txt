The specification is complete. The following governing relations and assumptions apply:

Assume small-deformation, linear-elastic solid mechanics.

The beam is simply supported with span L = 2400 mm, supports at x = 0 and x = L.

A single point load P = 1200 N acts downward at x = a = 1200 mm (midspan).

No separate bending load or applied moment is present.

The flexural rigidity is EI = (200000 MPa)(3500000 mm⁴) = 7.0 × 10¹¹ N·mm².

Use the unit-load method to determine deflection at the point load location.

Apply a virtual unit load (1 N downward) at x = a = 1200 mm where deflection is desired.

The real moment M(x) and virtual moment m(x) are required.

For 0 ≤ x ≤ a: M(x) = Pbx/L where b = L - a = 1200 mm, so M(x) = 600x N·mm.

For a ≤ x ≤ L: M(x) = Pa(L-x)/L = 600(L-x) N·mm.

For 0 ≤ x ≤ a: m(x) = b'x/L where b' = L - a = 1200 mm for unit load at midspan, so m(x) = 0.5x (dimensionless, represents moment per unit load).

For a ≤ x ≤ L: m(x) = a(L-x)/L = 0.5(L-x).

The deflection at x = a is Δ = (1/EI) ∫₀ᴸ M(x)m(x) dx.

By symmetry, compute Δ = (2/EI) ∫₀ᵃ M(x)m(x) dx = (2/EI) ∫₀ᵃ (Pbx/L)(b'x/L) dx.

With a = b = b' = L/2: Δ = (2/EI)(Pb/L²) ∫₀^(L/2) x² dx = (2/EI)(P(L/2)/L²)(L³/24) = PL³/(48EI).

Substitute values: Δ = (1200 N)(2400 mm)³ / (48 × 7.0 × 10¹¹ N·mm²) = 0.493 mm downward.

The deflection at the point load location (midspan) is 0.493 mm downward.
