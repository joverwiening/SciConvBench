The specification is complete. The following governing relations and solution procedure apply:

The total deflection is obtained by superposition of three cases: a simply supported beam under uniform distributed load, a simply supported beam under point load at midspan, and noting that only one distributed load exists (w = 0.3 N/mm).

The flexural rigidity is EI = 4×10^11 N·mm² = 4×10^5 N·m².

For a simply supported beam with uniform load w over full span L, the maximum deflection at midspan is δ_w = (5wL⁴)/(384EI).

For a simply supported beam with point load P at midspan, the maximum deflection at midspan is δ_P = (PL³)/(48EI).

The total maximum deflection at midspan is δ_total = δ_w + δ_P = (5wL⁴)/(384EI) + (PL³)/(48EI).

Substituting values: w = 0.3 N/mm = 300 N/m, P = 3000 N, L = 3000 mm = 3 m, EI = 4×10^11 N·mm² = 4×10^5 N·m².

Compute δ_w = (5 × 300 × 3⁴)/(384 × 4×10^5) = (5 × 300 × 81)/(384 × 4×10^5) = 121500/(1.536×10^8) = 7.910×10⁻⁴ m = 0.791 mm.

Compute δ_P = (3000 × 3³)/(48 × 4×10^5) = (3000 × 27)/(1.92×10^7) = 81000/(1.92×10^7) = 4.219×10⁻³ m = 4.219 mm.

Total maximum deflection: δ_total = 0.791 + 4.219 = 5.01 mm downward at midspan.

The deflection equation along the span can be written by superposing the individual deflection equations for each load case. For 0 ≤ x ≤ L/2, the deflection is v(x) = v_w(x) + v_P(x), where v_w(x) = (wx)/(24EI)(L³ - 2Lx² + x³) and v_P(x) = (Px)/(48EI)(3L² - 4x²). For L/2 ≤ x ≤ L, use symmetry.

The reactions at supports are R_A = R_B = wL/2 + P/2 = (0.3 × 3000)/2 + 3000/2 = 450 + 1500 = 1950 N.

The bending moment distribution is M(x) = R_A·x - wx²/2 for 0 ≤ x ≤ L/2, and M(x) = R_A·x - wx²/2 - P(x - L/2) for L/2 ≤ x ≤ L, with maximum moment at midspan M_max = wL²/8 + PL/4 = (0.3 × 3000²)/8 + (3000 × 3000)/4 = 337500 + 2250000 = 2.5875×10⁶ N·mm = 2587.5 N·m.
