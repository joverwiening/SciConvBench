Assume the shaft length is 1 meter for calculation purposes, though stress state is independent of length.

No axial force or axial moment is applied.

Calculate the polar moment of area J for the circular cross-section.
Calculate the maximum bending stress using the flexure formula.
Calculate the maximum torsional shear stress using the torsion formula.

At this element, the state of stress is a normal bending stress and a torsional shear stress.
Construct the 2D stress matrix for this element.
Calculate the principal stresses using the standard plane stress transformation equations.
Calculate the maximum shear stress.
