The beam is a simply supported, linear-elastic, prismatic beam of length L = 1800 mm.
The beam is subjected to a single concentrated load P = 2000 N applied at the midspan, x = 900 mm.
The deflection is to be computed at the same location as the load, x = 900 mm.
The unit-load method (also known as the method of virtual work) is to be used.
The flexural rigidity EI of the beam is assumed constant but its specific value is not provided.
The governing relation for the deflection at the load point is: δ = ∫_0^L (M_v * M / (EI)) dx, where M is the moment due to the real load and M_v is the moment due to a virtual unit load at the point of interest.
For a simply supported beam with a central point load, the real moment is M(x) = (P/2)*x for 0 ≤ x ≤ L/2 and M(x) = (P/2)*(L-x) for L/2 ≤ x ≤ L.
The virtual moment for a unit load at midspan is M_v(x) = (1/2)*x for 0 ≤ x ≤ L/2 and M_v(x) = (1/2)*(L-x) for L/2 ≤ x ≤ L.
The deflection at midspan is therefore δ = (1/EI) * [ ∫_0^(L/2) ((x/2) * ((Px)/2)) dx + ∫_(L/2)^L (((L-x)/2) * (P(L-x)/2)) dx ].
The result of the integration is δ = (P * L^3) / (48 * E * I).
