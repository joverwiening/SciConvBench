The shaft is made of AISI 1020 steel.
The shaft length between fixed ends is L = 1000 mm.
The shaft diameter is d = 20 mm.
The applied power is P = 5 kW.
The rotational speed is ω = 2π(1200/60) rad/s.
Calculate the transmitted torque T using the relation P = T·ω.
Assume small-deformation, linear-elastic solid mechanics.
Assume the shaft is a homogeneous, isotropic, linear-elastic solid.
Assume the shaft is prismatic and straight.
Assume the loading is pure torsion (Saint-Venant's principle applies).
Neglect any additional shear loading not specified.
Use the polar moment of inertia for a solid circular cross-section, J = πd⁴/32.
Calculate the maximum shear stress using τ_max = (T * r) / J, where r = d/2.
Calculate the angle of twist using θ = (T * L) / (J * G).
Use the shear modulus G for AISI 1020 steel, typically 80 GPa.
Check that the maximum shear stress τ_max is less than the allowable shear stress for the material.
The governing relation for power–torque conversion is T = P / ω.
The governing relation for torsional shear stress is τ = (T * r) / J.
The governing relation for the angle of twist is θ = (T * L) / (J * G).
