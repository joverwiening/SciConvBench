The objective is to design the height of a rectangular beam based on allowable bending stress.
The beam is subjected to a maximum bending moment M_max = 6000000 N·mm.
The allowable bending stress for the material is σ_allow = 170 MPa.
The width of the rectangular beam is b = 60 mm.
The analysis assumes small-deformation, linear-elastic solid mechanics.
The analysis assumes the beam has a rectangular cross-section.
The analysis assumes the maximum bending moment M_max is the critical moment for design.
The governing relation for bending stress is σ = M * y / I.
For a rectangular beam, the moment of inertia I = (b * h^3) / 12.
The distance from the neutral axis to the outermost fiber is y = h / 2.
Substituting I and y into the bending stress equation yields σ = (M * (h/2)) / ((b * h^3) / 12) = (6 * M) / (b * h^2).
To determine the minimum height h, set σ = σ_allow: h = sqrt((6 * M_max) / (b * σ_allow)).
Calculate the required beam height h using the given values.
