Use N–mm–MPa units consistently.
Model the beam with Euler–Bernoulli theory and neglect shear deformation.
Given L = 3000 mm, P = 1500 N at x = L/2, E = 200000 MPa, I = 3500000 mm^4.
Use simply supported boundary conditions v(0) = 0 and v(L) = 0.
Use symmetry boundary condition v′(L/2) = 0.
Define bending moment piecewise: for 0 ≤ x ≤ L/2, M(x) = (P/2)x; for L/2 ≤ x ≤ L, M(x) = (P/2)(L − x).
Solve EI v″(x) = M(x) on each region with continuity of v and v′ at x = L/2 and apply the boundary conditions.
Compute maximum deflection at midspan as v_max = v(L/2) = P L^3 / (48 E I).
Compute support slope magnitude as |v′(0)| = |v′(L)| = P L^2 / (16 E I), with v′(0) negative and v′(L) positive under the chosen sign convention (downward deflection positive).
Numerical result for maximum deflection: v_max = (1500)(3000^3) / (48·200000·3500000) mm = 1.205 mm downward.
Numerical result for support slope: v′(0) = −(1500)(3000^2) / (16·200000·3500000) = −0.001205 rad, and v′(L) = +0.001205 rad.
