Use N–mm–MPa units consistently.
Model a simply supported beam with span L = 3000 mm.
Use a midspan downward point load P = 2000 N at x = L/2.
Use material modulus E = 200000 MPa and second moment of area I = 1500000 mm^4.
Define the reactions as R_A = R_B = P/2.
Define the bending moment piecewise as M(x) = (P/2)x for 0 ≤ x ≤ L/2.
Define the bending moment piecewise as M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.
Form the bending strain energy as U = ∫_0^L M(x)^2/(2EI) dx using the piecewise M(x).
Evaluate U by splitting the integral over 0→L/2 and L/2→L.
Apply Castigliano’s theorem for the midspan deflection in the load direction as δ_mid = ∂U/∂P.
Compute the numerical result as δ_mid = P L^3/(48 E I).
Report δ_mid in mm using the given values, giving δ_mid = 2000·3000^3/(48·200000·1500000) = 3.75 mm downward.
