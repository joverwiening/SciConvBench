Use N–mm–MPa units throughout.
Model the two bars as axial members in parallel between rigid plates with perfect bonding so both bars have the same elongation and strain.
Given L = 400 mm, P = 20000 N, A1 = 300 mm^2, E1 = 200000 MPa, A2 = 250 mm^2, E2 = 110000 MPa.
Compute axial stiffnesses k1 = A1 E1 / L and k2 = A2 E2 / L.
Compute load share by stiffness: F1 = P k1/(k1 + k2) and F2 = P k2/(k1 + k2).
Compute stresses: σ1 = F1/A1 and σ2 = F2/A2.
Compute common elongation: δ = F1 L/(A1 E1) and verify δ = F2 L/(A2 E2) and δ = P/(k1 + k2).
Report forces and stresses to 3 significant figures and elongation to 3 significant figures.

Numerical results:
k1 = (300×200000)/400 = 150000 N/mm.
k2 = (250×110000)/400 = 68750 N/mm.
F1 = 20000×150000/(150000+68750) = 1.37×10^4 N.
F2 = 20000×68750/(150000+68750) = 6.28×10^3 N.
σ1 = 13700/300 = 45.7 MPa.
σ2 = 6280/250 = 25.1 MPa.
δ = 13700×400/(300×200000) = 0.0914 mm (common to both bars).
