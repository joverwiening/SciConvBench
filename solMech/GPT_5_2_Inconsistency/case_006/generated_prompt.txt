Use N–mm–MPa units consistently.
Model a prismatic Euler–Bernoulli beam with span L = 2400 mm.
Set supports at x = 0 and x = 2400 mm as simply supported: v(0) = 0 and v(L) = 0 with free rotation.
Use material and section properties E = 200000 MPa and I = 3500000 mm^4 so EI = 7.0e11 N·mm^2.
Apply a real concentrated load P = 1200 N downward at x = a = 1200 mm.
Compute real support reactions from statics: R_A = R_B = P/2 = 600 N.
Define the real bending moment function M(x) piecewise:
For 0 ≤ x ≤ 1200 mm, M(x) = R_A x = 600 x (N·mm).
For 1200 ≤ x ≤ 2400 mm, M(x) = R_A x − P(x − 1200) = 600 x − 1200(x − 1200) = −600 x + 1,440,000 (N·mm).
Define the auxiliary (virtual) system as the same simply supported beam with a unit vertical force 1 N downward applied at x = 1200 mm.
Compute auxiliary reactions: r_A = r_B = 0.5 N.
Define the auxiliary bending moment function m(x) piecewise:
For 0 ≤ x ≤ 1200 mm, m(x) = r_A x = 0.5 x (N·mm).
For 1200 ≤ x ≤ 2400 mm, m(x) = r_A x − 1(x − 1200) = 0.5 x − (x − 1200) = −0.5 x + 1200 (N·mm).
Compute the deflection at x = 1200 mm using the unit-load integral:
δ(1200) = ∫(0→2400) [M(x) m(x)]/(EI) dx.
Evaluate the integral in two regions:
δ(1200) = (1/EI) { ∫(0→1200) (600x)(0.5x) dx + ∫(1200→2400) (−600x + 1,440,000)(−0.5x + 1200) dx }.
Compute the first integral: ∫(0→1200) 300 x^2 dx = 300[ x^3/3 ](0→1200) = 100(1200^3) = 172,800,000,000 N^2·mm^3.
Expand the second integrand: (−600x + 1,440,000)(−0.5x + 1200) = 300x^2 − 1,440,000x + 1,728,000,000.
Compute the second integral:
∫(1200→2400) 300x^2 dx = 300[ x^3/3 ](1200→2400) = 100(2400^3 − 1200^3) = 1,209,600,000,000.
∫(1200→2400) (−1,440,000x) dx = −1,440,000[ x^2/2 ](1200→2400) = −3,110,400,000,000.
∫(1200→2400) 1,728,000,000 dx = 1,728,000,000(2400 − 1200) = 2,073,600,000,000.
Sum the second integral: 1,209,600,000,000 − 3,110,400,000,000 + 2,073,600,000,000 = 172,800,000,000 N^2·mm^3.
Sum both regions: 172,800,000,000 + 172,800,000,000 = 345,600,000,000 N^2·mm^3.
Divide by EI to get deflection: δ(1200) = 345,600,000,000 / 700,000,000,000 = 0.4937142857 mm.
Report the deflection at the load point as δ(1200) = 0.494 mm downward.
