Use N–mm–MPa units throughout.
Given M_max = 6000000 N·mm.
Given rectangular cross section width b = 30 mm.
Let the unknown cross section height be h in mm.
Given allowable bending stress σ_allow = 90 MPa (90 N/mm^2).
Compute the maximum bending stress using σ_max = M_max (h/2) / (b h^3/12).
Set σ_max = σ_allow and solve for the minimum required h.
Report h in mm.
