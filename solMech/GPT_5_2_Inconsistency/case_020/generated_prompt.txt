Use N–mm–MPa units throughout.
Model a solid circular shaft with diameter d = 35 mm and total length L = 1200 mm.
Fix the shaft at x = 0.
Apply torque T1 = +200000 N·mm at x = 1200 mm.
Apply torque T2 = −250000 N·mm at x = 800 mm.
Use shear modulus G = 77519.4 MPa.
Use polar moment of inertia J = (π d^4)/32 with d = 35 mm, and use J ≈ 1.473×10^5 mm^4 for calculations.
Define positive torque as the sense of T1.
Construct the internal torque diagram using equilibrium with piecewise-constant internal torque in each segment.
Compute internal torque in segment 0 ≤ x < 800 mm as Tint,1 = −(T1 + T2) = −(200000 − 250000) = +50000 N·mm.
Compute internal torque in segment 800 ≤ x ≤ 1200 mm as Tint,2 = −T1 = −200000 N·mm.
Compute maximum shear stress in each segment using τmax = |Tint| c / J with c = d/2 = 17.5 mm.
Report τmax,1 for segment 0→800 mm using Tint,1 = 50000 N·mm.
Report τmax,2 for segment 800→1200 mm using Tint,2 = 200000 N·mm.
Compute the angle of twist at x = L relative to x = 0 by summing segment twists using θ = Σ(Tint,i Li)/(GJ), keeping the algebraic sign of Tint,i.
