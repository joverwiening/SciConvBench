Use N–mm–MPa units throughout.
Model the member as an Euler–Bernoulli cantilever beam with small deflection and linear elastic behavior.
Set beam length L = 1200 mm.
Set material modulus E = 200000 MPa.
Set second moment of area I = 2000000 mm^4 (constant).
Apply a downward point load P = 2000 N at the free end x = L.
Use the physically correct free-end boundary condition: bending moment M(L) = 0.
Use the fixed-end boundary conditions at x = 0: deflection v(0) = 0 and slope θ(0) = v′(0) = 0.
Use the internal bending moment distribution for an end point load: M(x) = −P(L − x) for 0 ≤ x ≤ L (sign consistent with downward load causing negative/sagging curvature).
Use Euler–Bernoulli curvature relation: E I v″(x) = M(x).
Integrate v″(x) twice and apply v(0) = 0 and v′(0) = 0 to obtain v′(x) and v(x).
Compute the free-end slope as θ(L) = v′(L) = −P L^2 / (2 E I).
Compute the free-end vertical deflection as v(L) = −P L^3 / (3 E I).
Evaluate numerically with the given values to report results:
Compute θ(L) = −(2000)(1200^2) / (2·200000·2000000) = −0.0036 rad (≈ −0.206°).
Compute v(L) = −(2000)(1200^3) / (3·200000·2000000) = −1.152 mm.
Report slope in radians (and optionally degrees) and deflection in mm, with sign indicating downward deflection and clockwise rotation for the chosen sign convention.
