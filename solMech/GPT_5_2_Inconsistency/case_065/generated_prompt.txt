Use N–mm–MPa units throughout.
Model the shaft as linearly elastic AISI 1020 steel with shear modulus G = 76923.1 MPa.
Use a solid circular cross section with diameter d = 45 mm and length L = 1000 mm.
Use applied torque T = 400000 N·mm.
Compute polar moment of inertia as J = π d^4 / 32.
Compute outer radius as c = d / 2.
Compute maximum shear stress using τ_max = T c / J and report τ_max in MPa.
Compute angle of twist using φ = T L / (J G).
Convert φ from radians to degrees using φ_deg = φ_rad × (180/π).
