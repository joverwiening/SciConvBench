Use N–mm–MPa units consistently throughout.
Model a cantilever beam of length L = 1500 mm fixed at x = 0 and free at x = L.
Use material modulus E = 69000 MPa and constant second moment of area I = 2500000 mm^4.
Apply a downward point load P = 500 N at the free end x = L.
Define x measured from the fixed end toward the free end.
Set up the actual internal bending moment distribution for a cantilever with an end point load as a function of x, using the sign convention consistently, e.g., M(x) = P(L − x) for 0 ≤ x ≤ L.
Form the bending strain energy using U = ∫ from 0 to L of [M(x)^2/(2EI)] dx.
Carry out the integration symbolically in terms of P, E, I, and L.
Apply Castigliano’s theorem to obtain the free-end vertical deflection as δ(L) = ∂U/∂P.
Substitute P = 500 N, L = 1500 mm, E = 69000 MPa, and I = 2500000 mm^4 to compute the numerical value of the downward deflection at the free end in mm.
Do not use a memorized closed-form deflection formula; the result must come from M(x), integration of U, and differentiation with respect to P.
