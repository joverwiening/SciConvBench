Use N–mm–MPa units consistently.
Model the two bars as axial springs in parallel between rigid plates.
Enforce compatibility: the elongations are equal, so δ1 = δ2 = δ.
Enforce equilibrium: P = F1 + F2.
Compute axial stiffnesses k1 = A1E1/L and k2 = A2E2/L.
Compute k1 = (300)(200000)/500 = 120000 N/mm.
Compute k2 = (200)(69000)/500 = 27600 N/mm.
Compute the force split by stiffness: F1 = P·k1/(k1+k2) and F2 = P·k2/(k1+k2).
Compute F1 = 20000·120000/(120000+27600) = 16260 N (tension).
Compute F2 = 20000·27600/(120000+27600) = 3740 N (tension).
Compute stresses: σ1 = F1/A1 and σ2 = F2/A2.
Compute σ1 = 16260/300 = 54.2 MPa (tension).
Compute σ2 = 3740/200 = 18.7 MPa (tension).
Compute common elongation from δ = F1L/(A1E1) (or equivalently δ = F2L/(A2E2) or δ = P/(k1+k2)).
Compute δ = 20000/(120000+27600) = 0.1355 mm.
Report results: Bar 1 force 16260 N, stress 54.2 MPa, elongation 0.1355 mm; Bar 2 force 3740 N, stress 18.7 MPa, elongation 0.1355 mm.
