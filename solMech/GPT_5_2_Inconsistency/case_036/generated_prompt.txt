Use N–mm–MPa units throughout.
Given L = 1800 mm.
Given E = 200000 MPa.
Given applied compressive load P = 30000 N.
Given buckling factor of safety n = 2.0.
Given effective length factor K = 1.0 for pinned–pinned end condition.
Use Euler elastic buckling: P_cr = (π^2 E I) / (K L)^2.
Use solid circular second moment of area: I = (π d^4) / 64.
Interpret the buckling safety requirement as P_cr ≥ n·P.
Set P_cr = n·P and solve for the minimum diameter d.
Compute required critical load: P_req = n·P = 60000 N.
Solve for required I: I_req = P_req (K L)^2 / (π^2 E).
Compute I_req = 60000 × (1800)^2 / (π^2 × 200000) = 984,556 mm^4 (approximately).
Solve for diameter: d = [64 I_req / π]^(1/4).
Compute d = [64 × 984,556 / π]^(1/4) = 66.9 mm (approximately).
Report the minimum required diameter as d_min = 66.9 mm, and if rounding to a practical value, use d = 67 mm.
