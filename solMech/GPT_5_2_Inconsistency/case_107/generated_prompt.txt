Use N–mm–MPa units throughout.
Model a simply supported beam with span L = 3000 mm.
Use material modulus E = 200000 MPa.
Use constant second moment of area I = 3000000 mm^4.
Apply a single downward point load P = 2000 N at midspan x = L/2.
Use the correct piecewise bending moment diagram for a simply supported beam with a central point load.
Define the reactions as R_A = R_B = P/2.
Define bending moment piecewise as M(x) = (P/2)x for 0 ≤ x ≤ L/2.
Define bending moment piecewise as M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.
Form the bending strain energy as U = ∫_0^L M(x)^2/(2EI) dx using the piecewise M(x).
Apply Castigliano’s theorem for the midspan deflection in the load direction as δ_mid = ∂U/∂P.
Report δ_mid in mm (downward positive).
