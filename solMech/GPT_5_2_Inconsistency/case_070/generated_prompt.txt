Use N–mm–MPa units throughout.
Given b = 50 mm and h = 80 mm, compute the cross-sectional area as A = b h = 4000 mm^2.
Given P = 40000 N in tension, compute the average normal stress as σx = σ = P/A = 40000/4000 = 10 MPa.
Given V = 12000 N and the sign convention τxy = +V/A, compute the average shear stress as τxy = τ = 12000/4000 = 3 MPa.
Assume plane stress with σy = 0 MPa and τxy = +3 MPa.
Compute the in-plane principal stresses from σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)^2 + τxy^2).
Compute (σx + σy)/2 = (10 + 0)/2 = 5 MPa.
Compute ((σx − σy)/2)^2 + τxy^2 = (10/2)^2 + 3^2 = 25 + 9 = 34 MPa^2.
Compute sqrt(34) = 5.83095 MPa.
Report principal stresses as σ1 = 5 + 5.83095 = 10.83095 MPa and σ2 = 5 − 5.83095 = −0.83095 MPa.
Compute the maximum in-plane shear stress as τmax,in-plane = sqrt(((σx − σy)/2)^2 + τxy^2) = 5.83095 MPa.
Optionally verify τmax,in-plane = (σ1 − σ2)/2 = (10.83095 − (−0.83095))/2 = 5.83095 MPa.
