Use N–mm–MPa units consistently throughout.
Given power P = 10 kW.
Convert power to N·mm/s using 1 W = 1 N·m/s = 1000 N·mm/s, so P = 10,000 W = 10,000,000 N·mm/s.
Given rotational speed n = 1800 rpm.
Compute angular speed in rad/s as ω = 2π(n/60).
Compute transmitted torque as T = P/ω, yielding T in N·mm.
Given shaft diameter d = 35 mm.
Compute polar moment of inertia for a solid circular shaft as J = (π d^4)/32 in mm^4.
Compute maximum shear stress using torsion theory as τ_max = T c / J with c = d/2, yielding τ_max in MPa (since 1 MPa = 1 N/mm^2).
Given shear modulus G = 76923.1 MPa.
Given shaft length L = 1000 mm.
Treat the shaft as a standard segment with one end fixed and the other end subjected to torque.
Compute angle of twist as θ = T L / (J G), yielding θ in radians.
