Use N–mm–MPa units throughout.
Model the bar as a linear elastic axial spring with stiffness k = AE/L.
Use A = 300 mm^2, L = 800 mm, E = 200000 MPa, and P = 8000 N.
Compute the static stress as σ_static = P/A = 8000/300 = 26.6667 MPa.
For a suddenly applied constant load on an undamped linear elastic spring, equate external work to strain energy: P·δ_max = (1/2)k·δ_max^2.
Solve for maximum displacement: δ_max = 2P/k.
Compute maximum force: F_max = k·δ_max = 2P.
Compute maximum stress: σ_max = F_max/A = 2P/A = 2·8000/300 = 53.3333 MPa.
Report the maximum transient stress as 53.33 MPa.
