Use N–mm–MPa units throughout.
Use a rectangular cross section with width b = 30 mm and height h = 100 mm.
Use the full cross-sectional area A = b h = 3000 mm^2.
Use internal resultant normal force P = 50000 N in tension.
Use internal resultant transverse shear force V = 5000 N acting parallel to width b.
Assume uniform (average) stress distributions for both normal and shear stress.
Compute average normal stress as σ_avg = P/A.
Compute average shear stress as τ_avg = V/A.
Compute maximum in-plane shear stress magnitude as τ_max = sqrt((σ_avg/2)^2 + τ_avg^2).
Report σ_avg in MPa, τ_avg in MPa, and τ_max in MPa.
Compute σ_avg = 50000/3000 = 16.667 MPa.
Compute τ_avg = 5000/3000 = 1.667 MPa.
Compute τ_max = sqrt((16.667/2)^2 + (1.667)^2) = sqrt(8.333^2 + 1.667^2) = 8.498 MPa.
