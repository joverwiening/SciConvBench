Use N–mm–MPa units throughout.
Assume Euler elastic buckling applies.
Given L = 2000 mm.
Given E = 200000 MPa (200000 N/mm^2).
Given I = 1200000 mm^4.
Given effective length factor K = 0.7 for fixed–pinned end conditions.
Compute the Euler critical buckling load as P_cr = π^2 E I / (K L)^2.
Use (K L) = 0.7 × 2000 mm = 1400 mm.
Compute numerator π^2 E I = π^2 × 200000 × 1200000 N·mm^2.
Compute denominator (K L)^2 = (1400 mm)^2.
Calculate P_cr = (π^2 × 200000 × 1200000) / (1400^2) N = 1,208,304 N (rounded to nearest N).
Report P_cr = 1,208,304 N.
Report P_cr = 1208.304 kN.
