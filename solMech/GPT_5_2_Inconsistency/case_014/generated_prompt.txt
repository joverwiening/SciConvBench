Model the member as an Euler–Bernoulli cantilever beam with small deflection and linear elastic behavior.
Use L = 1200 mm, E = 200000 MPa (N/mm^2), I = 2500000 mm^4, and a downward tip load P = 800 N at x = L.
Apply physically correct cantilever boundary conditions: fixed end at x = 0 has v(0) = 0 and θ(0) = 0; free end at x = L has bending moment M(L) = 0.
Use the standard closed-form results for a cantilever with a tip point load: θ(L) = P L^2 / (2 E I) and v(L) = P L^3 / (3 E I).
Compute the free-end slope: θ(L) = 800·(1200^2) / (2·200000·2500000) = 0.001152 rad (≈ 0.0660°), clockwise/downward rotation.
Compute the free-end vertical deflection: v(L) = 800·(1200^3) / (3·200000·2500000) = 0.9216 mm downward.
