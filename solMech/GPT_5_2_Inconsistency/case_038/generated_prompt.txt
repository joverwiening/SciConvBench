Use N–mm–MPa units throughout.
Model the beam with Euler–Bernoulli theory using E = 200000 MPa and I = 3000000 mm^4.
Use a simply supported beam of span L = 3500 mm with x measured from the left support, x = 0 at the left support and x = L at the right support.
Apply a uniform distributed load w = 0.5 N/mm over 0 ≤ x ≤ L.
Use standard simply supported boundary conditions y(0) = 0 and y(L) = 0.
Use zero end moment boundary conditions M(0) = 0 and M(L) = 0, equivalently y''(0) = 0 and y''(L) = 0.
Do not impose zero end slopes; compute the slope at x = 0 from the solution.
Solve the governing relation EI y''''(x) = w with the stated boundary conditions to obtain y(x) and θ(x) = y'(x).
Determine the location of maximum deflection by solving y'(x) = 0 within 0 < x < L and selecting the extremum consistent with symmetry.
Report the maximum deflection magnitude and its x-location.
Compute and report the slope at the left support θ(0) = y'(0).
