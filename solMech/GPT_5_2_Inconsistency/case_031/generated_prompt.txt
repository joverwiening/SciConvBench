Use N–mm–MPa units throughout.
Model a vertical, prismatic, linearly elastic bar fixed at the top and free at the bottom.
Set bar length L = 3500 mm.
Set cross-sectional area A = 200 mm^2.
Set elastic modulus E = 69000 MPa (treat as 69000 N/mm^2).
Set density ρ = 8900 kg/m^3.
Set gravitational acceleration g = 9.81 m/s^2.
Ignore all external loads; include only self-weight.
Measure coordinate x downward from the top, with x = 0 at the top and x = L at the bottom.
Use the exact axial force distribution due to self-weight: P(x) = ρ g A (L − x).
Convert units so P(x) is in N using consistent SI inputs (A in m^2 and L, x in m), or equivalently convert ρg to N/mm^3 and use A in mm^2 and L, x in mm.
Compute elongation by integrating strain: δ = ∫0^L P(x)/(A E) dx.
Evaluate the integral analytically to obtain δ = (ρ g L^2)/(2 E) with consistent units.
Convert the final elongation δ to mm.
