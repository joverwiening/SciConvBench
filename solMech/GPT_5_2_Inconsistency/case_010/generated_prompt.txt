Use N–mm–MPa units throughout.
Model two prismatic bars in parallel between rigid plates with perfect bonding so both bars undergo the same elongation.
Given L = 800 mm, P = 30000 N.
Given Bar 1 (steel): A1 = 150 mm^2, E1 = 200000 MPa.
Given Bar 2 (cast iron): A2 = 200 mm^2, E2 = 110000 MPa.
Do not split the load equally; explicitly correct that statement.
Impose compatibility: δ1 = δ2 = δ, with δi = Fi L / (Ai Ei).
Impose equilibrium: F1 + F2 = P.
Solve for force split using Fi proportional to axial stiffness AiEi: F1 = P (A1E1)/(A1E1 + A2E2), F2 = P (A2E2)/(A1E1 + A2E2).
Compute stiffness terms: A1E1 = 150×200000 = 30,000,000 N, A2E2 = 200×110000 = 22,000,000 N.
Compute forces: F1 = 30000×30/52 = 17307.7 N, F2 = 30000×22/52 = 12692.3 N.
Compute stresses: σ1 = F1/A1 = 17307.7/150 = 115.38 MPa (tension), σ2 = F2/A2 = 12692.3/200 = 63.46 MPa (tension).
Compute common elongation using either bar: δ = F1 L/(A1E1) = 17307.7×800/30,000,000 = 0.4615 mm.
Report results: Bar 1 force 17.31 kN, stress 115.38 MPa; Bar 2 force 12.69 kN, stress 63.46 MPa; common elongation 0.4615 mm.
