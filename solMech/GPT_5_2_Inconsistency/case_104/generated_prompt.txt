Use N–mm–MPa units throughout.
Model the member with Euler–Bernoulli beam theory with constant E and I.
Given L = 2500 mm, w = 0.7 N/mm (uniform over 0 ≤ x ≤ L), E = 200000 MPa, I = 2000000 mm^4.
Treat the beam as simply supported with boundary conditions v(0) = 0 and v(L) = 0.
Use symmetry only to set the midspan slope to zero: θ(L/2) = dv/dx|x=L/2 = 0.
Do not impose θ(0) = 0 or θ(L) = 0.
Define x measured from the left support.
Use the governing relation E I v''''(x) = w with consistent sign convention, or equivalently integrate M(x) = E I v''(x) derived from statics.
Compute reactions by statics: R_A = R_B = wL/2.
Write bending moment for 0 ≤ x ≤ L: M(x) = R_A x − (w x^2)/2.
Integrate E I v''(x) = M(x) twice to obtain θ(x) = v'(x) and v(x), introducing integration constants.
Determine integration constants using v(0) = 0 and v(L) = 0, and verify symmetry condition θ(L/2) = 0 is satisfied.
Report the maximum deflection magnitude and its location, taking the location as x = L/2 by symmetry.
Compute maximum deflection at midspan using v(L/2).
Compute the slope at the left support as θ(0) = v'(0).
Numerical results:
Maximum deflection occurs at x = L/2 = 1250 mm.
Maximum deflection v_max = v(L/2) = −(5 w L^4)/(384 E I) = −7.1206 mm (downward).
Slope at left support θ(0) = v'(0) = −(w L^3)/(24 E I) = −0.011393 rad.
