Use N–mm–MPa units throughout.
Model the beam with Euler–Bernoulli theory.
Use a cantilever beam of length L = 1000 mm fixed at x = 0 and free at x = L.
Use material properties E = 200000 MPa and second moment of area I = 2000000 mm^4.
Replace the uniform distributed load w = 1.5 N/mm over 0 ≤ x ≤ L by a single concentrated force only.
Set the concentrated force magnitude to P = wL = 1500 N acting downward.
Apply the concentrated force at x = L/2 = 500 mm.
Apply no additional applied couple/moment anywhere (do not include any equivalent moment of the distributed load).
Compute the free-end slope θ(L) and the free-end deflection v(L) using the cantilever-with-interior-point-load solution.
Report θ(L) in radians and v(L) in mm, with downward deflection taken as negative (or explicitly state the sign convention used).
