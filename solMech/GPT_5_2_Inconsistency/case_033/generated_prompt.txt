Use N–mm–MPa units throughout.
Model the member as an Euler–Bernoulli beam with constant E = 200000 MPa and I = 1200000 mm^4.
Use a simply supported beam of span L = 2500 mm with a downward point load P = 2500 N at midspan x = L/2.
Use the governing relation EI v''(x) = M(x) with sagging moment taken as positive.
Use boundary conditions v(0) = 0 and v(L) = 0.
Use symmetry condition v'(L/2) = 0.
Solve for the deflection curve v(x) piecewise on 0 ≤ x ≤ L/2 and L/2 ≤ x ≤ L using the bending moment from reactions R1 = R2 = P/2.
Compute the maximum deflection as v_max = v(L/2).
Compute the support slopes as v'(0) and v'(L), and report them with sign convention and also their equal magnitudes.

Numerical results:
Maximum deflection at midspan: v_max = P L^3 / (48 E I) = 2500·(2500^3) / (48·200000·1200000) mm = 3.390 mm downward.
Slope at left support: v'(0) = + P L^2 / (16 E I) = +2500·(2500^2) / (16·200000·1200000) rad = +0.004069 rad.
Slope at right support: v'(L) = − P L^2 / (16 E I) = −0.004069 rad.
Support slope magnitude: |v'(0)| = |v'(L)| = 0.004069 rad.
