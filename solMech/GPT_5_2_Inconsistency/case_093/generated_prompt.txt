Use N–mm–MPa units throughout.
Model the member as an Euler–Bernoulli cantilever beam with small deflection and linear elastic behavior.
Set beam length L = 800 mm, fixed at x = 0 and free at x = L.
Use material modulus E = 69000 MPa.
Use constant second moment of area I = 800000 mm^4.
Apply a downward point load P = 500 N at x = L.
Use the physically correct cantilever free-end boundary condition M(L) = 0 and allow nonzero free-end rotation.
Use the internal bending moment distribution for an end point load: M(x) = -P(L - x) for 0 ≤ x ≤ L (sign per chosen convention).
Use Euler–Bernoulli curvature relation: E I v''(x) = M(x).
Apply fixed-end boundary conditions: v(0) = 0 and v'(0) = 0.
Solve for slope and deflection at the free end.
Compute free-end slope magnitude: θ(L) = P L^2 / (2 E I).
Compute free-end deflection magnitude: v(L) = P L^3 / (3 E I).
Evaluate numerically with given values: θ(L) = 500·800^2 / (2·69000·800000) = 0.00289855 rad.
Optionally convert slope to degrees: 0.00289855·(180/π) = 0.1661°.
Evaluate free-end deflection: v(L) = 500·800^3 / (3·69000·800000) = 1.54589 mm downward.
