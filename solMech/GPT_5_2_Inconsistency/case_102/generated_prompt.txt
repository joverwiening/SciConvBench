Use N–mm–MPa units throughout.
Model the bar as vertical, prismatic, and linearly elastic.
Given L = 3500 mm, A = 200 mm^2, E = 69000 MPa, ρ = 7850 kg/m^3, g = 9.81 m/s^2.
Ignore all external loads; include only self-weight.
Measure x downward from the top support, with x = 0 at the top and x = L at the free end.
Use the variable axial force P(x) = ρ g A (L − x) corresponding to the weight of the portion of bar below the section.
Compute elongation using δ = ∫₀ᴸ P(x)/(A E) dx.
Convert density to consistent N–mm–MPa units by using ρ = 7850 kg/m^3 = 7.85×10^-6 kg/mm^3 and g = 9.81 m/s^2 = 9810 mm/s^2, so ρg = 0.0770085 N/mm^3.
Evaluate δ = (ρ g / E) ∫₀ᴸ (L − x) dx = (ρ g / E) (L^2/2).
Compute δ = (0.0770085 / 69000) × (3500^2 / 2) mm = 6.83 mm (rounded to three significant figures).
