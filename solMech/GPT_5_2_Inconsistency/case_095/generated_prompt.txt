Use N–mm–MPa units throughout.
Model a solid circular shaft with two segments in series: AB and BC.
Set segment AB length L1 = 400 mm.
Set segment AB diameter d1 = 30 mm.
Set segment BC length L2 = 700 mm.
Set segment BC diameter d2 = 30 mm.
Use structural steel with shear modulus G = 77519.4 MPa.
Apply an external torque T = 600000 N·mm at end C.
Fix end A against rotation.
Assume no other applied torques along the shaft.
Compute the internal torque distribution consistent with series segments (the internal torque is the same through AB and BC).
Do not redistribute the applied torque between segments by torsional stiffness because the segments are in series.
Compute the polar moment of inertia for each segment as J = (π d^4)/32.
Compute maximum shear stress in each segment using τmax = T c / J with c = d/2.
Report τmax,AB and τmax,BC in MPa.
Identify the governing segment as the one with the larger τmax.
Compute the twist of each segment using φ = T L / (J G).
Compute total twist at C relative to A as φtotal = φAB + φBC.
Report φtotal in radians and in degrees.
