Use N–mm–MPa units throughout.
Given a solid circular shaft with diameter d = 25 mm, axial tensile force P = 15000 N, and torque T = 400000 N·mm.
Compute the cross-sectional area as A = (π/4) d^2.
(a) Compute the average axial normal stress as σ = P/A and report it in MPa.
Compute the polar moment of inertia for a solid circular shaft as J = (π/32) d^4.
Set the outer radius as c = d/2.
(b) Compute the torsional shear stress at the outer surface as τ = T c / J and report it in MPa.
(c) Evaluate the plane-stress state at the outer surface r = c using σx = σ, σy = 0, and τxy = τ where τ is the value from part (b).
Compute the in-plane principal stresses using σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)^2 + τxy^2).
Compute the maximum in-plane shear stress using τmax,in-plane = sqrt(((σx − σy)/2)^2 + τxy^2).
Do not set τxy = 0 in part (c).
