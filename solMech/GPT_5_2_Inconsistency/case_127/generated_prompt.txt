Use N–mm–MPa units throughout.
Use the rectangular cross-section dimensions b = 60 mm and h = 100 mm.
Compute the cross-sectional area as A = b h = 6000 mm^2.
Take the average normal stress as σx = σ = P/A with P = +40000 N (tension).
Compute σx = 40000/6000 = 6.6667 MPa.
Set σy = 0 MPa.
Take the average shear stress as τxy = τ = +V/A with V = +16000 N.
Compute τxy = 16000/6000 = 2.6667 MPa.
Treat the stress state as plane stress with (σx, σy, τxy) = (6.6667 MPa, 0 MPa, +2.6667 MPa).
Compute the in-plane principal stresses using σ1,2 = (σx+σy)/2 ± sqrt(((σx−σy)/2)^2 + τxy^2).
Compute (σx+σy)/2 = 3.3333 MPa.
Compute (σx−σy)/2 = 3.3333 MPa.
Compute sqrt(((σx−σy)/2)^2 + τxy^2) = sqrt(3.3333^2 + 2.6667^2) = 4.2687 MPa.
Compute σ1 = 3.3333 + 4.2687 = 7.6020 MPa.
Compute σ2 = 3.3333 − 4.2687 = −0.9353 MPa.
Compute the maximum in-plane shear stress as τmax,in-plane = sqrt(((σx−σy)/2)^2 + τxy^2).
Report τmax,in-plane = 4.2687 MPa.
