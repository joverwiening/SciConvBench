Use N–mm–MPa units throughout.
Model a simply supported Euler–Bernoulli beam with span L = 3000 mm and supports at x = 0 and x = 3000 mm.
Use material and section properties E = 200000 MPa and I = 1200000 mm^4, so EI = 2.4×10^11 N·mm^2.
Apply the real load P = 800 N downward at a = 2000 mm from the left support.
Compute real reactions from statics: R_A = P(L−a)/L = 266.6667 N and R_B = Pa/L = 533.3333 N.
Define the real bending moment M(x) (N·mm) as M(x) = R_A x for 0 ≤ x ≤ 2000, and M(x) = R_A x − P(x−2000) for 2000 ≤ x ≤ 3000.
Create the auxiliary (unit-load) system by applying a unit vertical force 1 N downward at x = 2000 mm on the same simply supported beam.
Compute auxiliary reactions: r_A = (L−a)/L = 1/3 and r_B = a/L = 2/3.
Define the auxiliary bending moment m(x) (N·mm) as m(x) = r_A x for 0 ≤ x ≤ 2000, and m(x) = r_A x − 1·(x−2000) for 2000 ≤ x ≤ 3000.
Compute the deflection at x = 2000 mm using the unit-load integral δ = ∫(0→L) M(x)m(x)/(EI) dx, split at x = 2000 mm.
Evaluate the first segment integral: ∫(0→2000) [ (R_A x)(r_A x) ] dx = ∫(0→2000) (800/9)x^2 dx = 2.37037037×10^11 N^2·mm^3.
Evaluate the second segment integral using M(x) = 800000 − (1600/3)x and m(x) = 2000 − (2/3)x: ∫(2000→3000) M(x)m(x) dx = 7.40740741×10^10 N^2·mm^3.
Sum integrals: ∫(0→3000) M(x)m(x) dx = 3.11111111×10^11 N^2·mm^3.
Divide by EI to get deflection: δ(2000) = (3.11111111×10^11)/(2.4×10^11) = 1.29629630 mm.
Report the deflection at the load point as δ(x=2000 mm) = 1.296 mm downward.
