Use N–mm–MPa as the working unit system throughout.
Treat the shaft as a solid circular shaft with diameter d = 20 mm and length L = 1200 mm.
Use power P = 5 kW and rotational speed n = 1200 rpm.
Convert power to consistent units before solving for torque (e.g., P = 5000 W = 5000 N·m = 5,000,000 N·mm).
Compute angular speed as ω = 2π(n/60) in rad/s and do not substitute rpm directly for ω.
Compute transmitted torque from P = T·ω using ω in rad/s and report T in N·mm (and optionally N·m).
Compute polar moment of inertia for a solid circular shaft as J = (π d^4)/32 in mm^4.
Compute maximum shear stress using torsion theory τ_max = T c / J with c = d/2, and report τ_max in MPa (using 1 MPa = 1 N/mm^2).
Use shear modulus G = 25939.8 MPa.
Compute angle of twist using the standard case of one end fixed and the other end subjected to the transmitted torque: θ = T L / (J G).
Report θ in radians (and optionally degrees via θ_deg = θ·180/π).
Do not apply any “both ends fixed” modification; interpret “between fixed ends” only as defining the span length L to use.
