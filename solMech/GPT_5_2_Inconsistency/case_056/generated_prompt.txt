Use N–mm–MPa units throughout.
Treat E as constant at 200000 MPa.
Use L = 800 mm, P = 30000 N, A0 = 250 mm^2, k = 0.8.
Define the linearly varying area as A(x) = A0(1 + kx/L).
Compute the end areas A(0) = A0 and A(L) = A0(1 + k).
Replace A(x) by the arithmetic-mean of the end areas: Amean = (A(0) + A(L))/2.
Treat Amean as exact and compute elongation using δ = ∫0→L P/(Amean E) dx = PL/(Amean E).
Calculate A(L) = 250(1 + 0.8) = 450 mm^2.
Calculate Amean = (250 + 450)/2 = 350 mm^2.
Calculate δ = (30000×800)/(350×200000) mm = 0.343 mm.
Report elongation as 0.343 mm (3 significant figures).
