Use N–mm–MPa units consistently.
Model a cantilever beam of length L = 1500 mm fixed at x = 0 and free at x = L.
Use material modulus E = 200000 MPa and second moment of area I = 2500000 mm^4, both constant along the span.
Apply a downward point load P = 500 N at the free end x = L.
Set up the actual internal bending moment function for a cantilever with an end point load as M(x) = P(L − x) for 0 ≤ x ≤ L (sign convention may be chosen, but M(x)^2 must be used in energy).
Form the bending strain energy as U = ∫(0→L) [M(x)^2/(2EI)] dx.
Evaluate the integral symbolically in terms of P, L, E, I.
Apply Castigliano’s theorem for the vertical deflection at the load point as δ(L) = ∂U/∂P.
Substitute P = 500 N, L = 1500 mm, E = 200000 MPa, I = 2500000 mm^4 to compute the numerical deflection in mm.
Report the final free-end vertical deflection magnitude as δ(L) = P L^3/(3 E I) = 1.125 mm downward.
