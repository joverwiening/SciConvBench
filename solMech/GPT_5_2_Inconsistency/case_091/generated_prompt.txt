Use N–mm–MPa units throughout.
Model the beam with Euler–Bernoulli beam theory and linear elastic behavior.
Use E = 200000 MPa and I = 3000000 mm^4 as constants along the span.
Use a simply supported beam with span L = 3500 mm.
Apply two simultaneous loads: a uniform distributed load w = 0.3 N/mm over the full span and a midspan point load P = 1200 N downward.
Compute midspan deflection by superposition: δmid = δw + δP.
Use the exact simply supported midspan deflection for full-span UDL: δw = (5 w L^4) / (384 E I).
Use the exact simply supported midspan deflection for a central point load: δP = (P L^3) / (48 E I).
Adopt the sign convention that downward deflection is positive and upward deflection is negative.
Calculate δw numerically: δw = (5·0.3·3500^4)/(384·200000·3000000) = 0.979655 mm (positive).
Calculate δP numerically: δP = (1200·3500^3)/(48·200000·3000000) = 1.787326 mm (positive).
Report the total midspan deflection: δmid = 0.979655 + 1.787326 = 2.766981 mm downward (positive).
