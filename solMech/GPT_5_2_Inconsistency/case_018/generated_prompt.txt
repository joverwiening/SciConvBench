Use N–mm–MPa units throughout.
Model a solid circular shaft with diameter d = 40 mm and total length L = 1500 mm.
Fix the shaft at x = 0.
Apply torque T1 = +300000 N·mm at x = 1500 mm.
Apply torque T2 = −150000 N·mm at x = 750 mm.
Use material 6061-T6 aluminum with shear modulus G = 25939.8 MPa.
Take positive torque as the same sense as T1.
Compute the polar moment of inertia for a solid circular shaft as J = (π d^4) / 32.
Define two segments: Segment 1 from x = 0 to x = 750 mm, and Segment 2 from x = 750 mm to x = 1500 mm.
Construct the internal torque in each segment using equilibrium of the portion of shaft to the right of the cut so that the internal torque equals the algebraic sum of applied torques to the right of the cut.
Set internal torque in Segment 2 (750→1500) to Tint,2 = +300000 N·mm.
Set internal torque in Segment 1 (0→750) to Tint,1 = +300000 − 150000 = +150000 N·mm.
Compute maximum shear stress in each segment using τmax = |Tint| c / J with c = d/2.
Report τmax,1 using Tint,1 and τmax,2 using Tint,2 in MPa.
Compute the angle of twist by summing segment twists using θ = Σ (Tint,i Li) / (G J).
Use L1 = 750 mm and L2 = 750 mm.
Report the total twist at x = L relative to x = 0 as θ(L) in radians.
Optionally also report θ(L) in degrees in parentheses using degrees = radians × 180/π.
