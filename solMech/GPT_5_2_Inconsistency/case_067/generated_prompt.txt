Use N–mm–MPa units throughout.
Model the shaft as linearly elastic 6061-T6 aluminum with shear modulus G = 25939.8 MPa.
Use a solid circular cross section with diameter d = 30 mm and length L = 800 mm.
Apply a transmitted torque T = 500000 N·mm.
Use the torsion polar moment of inertia J = π d^4 / 32 for all torsion calculations.
Compute the maximum shear stress using τ_max = T c / J with c = d/2.
Compute the angle of twist using φ = T L / (J G).
Report τ_max in MPa.
Convert φ from radians to degrees and report φ in degrees.
