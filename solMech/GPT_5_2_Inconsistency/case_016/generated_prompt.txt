Use N–mm–MPa units throughout.
Model the member as an Euler–Bernoulli cantilever beam with small deflection and linear elastic behavior.
Set beam length L = 800 mm, fixed at x = 0 and free at x = L.
Use material modulus E = 69000 MPa.
Use constant second moment of area I = 1600000 mm^4.
Apply a downward point load P = 2500 N at x = L.
Use the physically correct free-end boundary condition of no applied end couple: bending moment at the free end is zero, M(L) = 0.
Use fixed-end boundary conditions at x = 0: deflection v(0) = 0 and rotation v′(0) = 0.
Use the internal bending moment distribution for a cantilever with a tip load: M(x) = −P(L − x) for 0 ≤ x ≤ L (sign consistent with downward load causing hogging).
Use Euler–Bernoulli relation E I v″(x) = M(x) and integrate with the boundary conditions to obtain slope and deflection.
Compute the free-end slope as θ(L) = v′(L) = −P L^2 / (2 E I).
Compute the free-end vertical deflection as v(L) = −P L^3 / (3 E I).
Evaluate numerically: θ(L) = −2500·800^2 / (2·69000·1600000) = −0.007246 rad (≈ −0.415°).
Evaluate numerically: v(L) = −2500·800^3 / (3·69000·1600000) = −3.864 mm.
