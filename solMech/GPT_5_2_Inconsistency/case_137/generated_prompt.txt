Use N–mm–MPa units throughout.
Model a solid circular shaft with diameter d = 45 mm at the critical section.
Use bending moment M = 2,000,000 N·mm and torque T = 500,000 N·mm.
Evaluate stresses at the outer surface point where the bending normal stress magnitude is maximum.
Do not set torsional shear stress to zero at this surface point.
Compute the area moment of inertia as I = (π d^4) / 64.
Compute the polar moment of inertia as J = (π d^4) / 32.
Use c = d/2 as the outer radius.
Compute the maximum bending normal stress magnitude at the surface using σ = M c / I.
Compute the torsional shear stress magnitude at the surface using τ = T c / J.
Treat the surface stress state as plane stress with σx = σ, σy = 0, and τxy = τ.
Compute the principal stresses using σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)^2 + τxy^2).
Compute the maximum in-plane shear stress using τmax,in-plane = sqrt(((σx − σy)/2)^2 + τxy^2).
Report σ (MPa), τ (MPa), σ1 (MPa), σ2 (MPa), and τmax,in-plane (MPa).
