Use N–mm–MPa units throughout.
Model the beam with Euler–Bernoulli small-deflection theory with constant E and I.
Beam is a cantilever of length L = 2500 mm fixed at x = 0 and free at x = L.
Apply a uniform distributed load w = 1.0 N/mm downward over 0 ≤ x ≤ L.
Use material properties E = 200000 MPa and second moment of area I = 1000000 mm^4.
Compute the free-end slope using the standard cantilever-with-UDL result θ(L) = w L^3 / (6 E I) with sign consistent with downward loading.
Compute the free-end deflection using the standard cantilever-with-UDL result v(L) = w L^4 / (8 E I) with sign consistent with downward loading.
Report numerical results: θ(L) = 0.0325521 rad (downward rotation) and v(L) = 244.1406 mm (downward deflection).
