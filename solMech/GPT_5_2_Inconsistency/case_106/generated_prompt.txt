Use N–mm–MPa units throughout.
Model a simply supported prismatic beam with span L = 2500 mm.
Use material modulus E = 200000 MPa.
Use second moment of area I = 3000000 mm^4.
Apply a single concentrated load P = 1000 N downward at midspan x = L/2.
Compute support reactions as R_A = R_B = P/2.
Define the bending moment function piecewise over the full span as M(x) = (P/2)x for 0 ≤ x ≤ L/2 and M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.
Form the bending strain energy as U = ∫_0^L M(x)^2/(2EI) dx using the piecewise M(x).
Apply Castigliano’s theorem for the midspan deflection in the load direction as δ_mid = ∂U/∂P.
Differentiate U with respect to P after integrating (or equivalently differentiate the integrand with respect to P and integrate) while treating E, I, and L as constants.
Report δ_mid in mm with sign convention consistent with the applied load direction (downward deflection positive if chosen).
Use the closed-form result for verification: δ_mid = P L^3/(48 E I).
Substitute the given values to obtain δ_mid = 1000·(2500^3)/(48·200000·3000000) mm = 0.5425 mm downward.
