Use N–mm–MPa units throughout.
Model the beam with Euler–Bernoulli theory and neglect shear deformation.
Beam span is L = 3000 mm.
Material is 6061-T6 aluminum with E = 69000 MPa.
Second moment of area is constant I = 3,500,000 mm^4.
A concentrated load P = 4000 N acts downward at midspan x = L/2.
Use simply supported boundary conditions v(0) = 0 and v(L) = 0.
Use symmetry condition v′(L/2) = 0.
Define the bending moment as M(x) = (P/2)x for 0 ≤ x ≤ L/2 and M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.
Use the governing relation E I v″(x) = M(x) with consistent sign convention.
Compute the maximum deflection as the midspan deflection v(L/2).
Compute the support slope as v′(0) (equal in magnitude and opposite in sign to v′(L) by symmetry).
Report numerical results for (i) v(L/2) in mm and (ii) v′(0) in radians.
Use the standard closed-form results for a simply supported beam with a central point load: v_max = P L^3 / (48 E I and |v′(0)| = P L^2 / (16 E I).
Substitute the given values to obtain v_max = 4000·3000^3 / (48·69000·3500000) = 9.32 mm downward.
Substitute the given values to obtain v′(0) = +4000·3000^2 / (16·69000·3500000) = 0.0186 rad (with v′(L) = −0.0186 rad under the same sign convention).
