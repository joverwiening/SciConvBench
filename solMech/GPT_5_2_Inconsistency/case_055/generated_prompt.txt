Use N–mm–MPa units consistently.
Treat E as constant at 69000 MPa.
Use the given linear area function A(x) = A0(1 + k x/L) only to compute the end areas.
Compute A(0) = A0 = 200 mm^2.
Compute A(L) = A0(1 + k) = 200(1 + 0.6) = 320 mm^2.
Replace A(x) by the end-area arithmetic mean A_mean = (A(0) + A(L))/2 = (200 + 320)/2 = 260 mm^2.
Treat A_mean as exact in the axial deformation integral.
Compute elongation using δ = ∫0→L P/(A_mean E) dx = P L/(A_mean E).
Substitute P = 20000 N, L = 1200 mm, A_mean = 260 mm^2, E = 69000 N/mm^2.
Compute δ = (20000×1200)/(260×69000) mm = 1.337 mm (approximately).
