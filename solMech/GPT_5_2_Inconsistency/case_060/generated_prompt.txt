Use N–mm–MPa units throughout.
Assume Euler buckling applies and the column remains elastic.
Use L = 2000 mm.
Use E = 200000 MPa.
Use I = 800000 mm^4.
Use fixed–fixed end conditions with effective length factor K = 0.5.
Compute the Euler critical buckling load using P_cr = π^2 E I / (K L)^2.
Use π = 3.141592653589793 (or calculator built-in π).
Compute (K L) = 0.5 × 2000 mm = 1000 mm.
Compute E I = 200000 MPa × 800000 mm^4 = 1.6×10^11 N·mm^2.
Compute P_cr = π^2 × (1.6×10^11 N·mm^2) / (1000 mm)^2 = 1.5791367041742976×10^6 N.
Report P_cr = 1,579,136.704 N.
Report P_cr = 1,579.137 kN.
