Use N–mm–MPa units throughout.
Treat the modulus of elasticity as constant with E = 200000 MPa.
Use bar length L = 800 mm.
Use constant axial tensile force P = 12000 N.
Use linearly varying area A(x) = A0(1 + kx/L) with A0 = 250 mm^2 and k = 0.6 only to compute the arithmetic-mean area.
Compute end areas as A(0) = 250 mm^2 and A(L) = 400 mm^2.
Use arithmetic-mean area Amean = (A(0) + A(L))/2 = 325 mm^2 as an exact constant area for deformation.
Compute elongation using δ = ∫0→L P/(Amean E) dx = P L/(Amean E).
Calculate δ = (12000 N)(800 mm)/((325 mm^2)(200000 N/mm^2)) = 0.147692 mm.
Report elongation as δ ≈ 0.148 mm.
