Use N–mm–MPa units throughout.
Given d = 25 mm, P = 25000 N, T = 300000 N·mm.
Compute cross-sectional area A = (π/4) d^2.
Compute average axial stress σ = P/A in MPa (since 1 MPa = 1 N/mm^2).
Compute polar moment of inertia J = (π/32) d^4.
Use outer radius c = d/2.
Compute torsional shear stress at the outer surface τ = T c / J in MPa.
For plane stress, set σx = σ, σy = 0, τxy = τ.
Compute principal stresses using σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)^2 + τxy^2).
Compute maximum in-plane shear stress using τmax,in-plane = sqrt(((σx − σy)/2)^2 + τxy^2).
Ignore the statement “torsional shear stress to vanish” because it conflicts with the required use of τ = T c / J in parts (b) and (c).
