Use N–mm–MPa units throughout.
Given M_max = 6000000 N·mm, b = 60 mm, and σ_allow = 170 MPa.
Treat h as the full rectangular cross-section depth.
Use the standard extreme-fiber distance c = h/2.
Use the rectangular second moment of area I = b h^3 / 12.
Compute maximum bending stress as σ_max = M_max c / I = M_max (h/2) / (b h^3/12) = 6 M_max / (b h^2).
Set σ_max = σ_allow and solve for h: h = sqrt(6 M_max / (b σ_allow)).
Substitute values: h = sqrt(6·6000000 / (60·170)) mm = sqrt(3529.4118) mm = 59.41 mm.
Report the minimum required height as h_min = 59.41 mm, and if rounding up to a practical value is required, use h = 60 mm.
