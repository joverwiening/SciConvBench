Use N–mm–MPa units throughout.
Given a simply supported beam with maximum bending moment M_max = 3,000,000 N·mm.
Use a rectangular cross section with width b = 40 mm and unknown height h.
Use allowable bending stress σ_allow = 90 MPa (i.e., 90 N/mm^2).
Use the second moment of area for a rectangle about its centroidal axis I = b h^3 / 12.
Use the extreme-fiber distance c = h/2.
Compute maximum bending stress using σ_max = M_max (h/2) / (b h^3/12).
Set σ_max = σ_allow and solve for the minimum required height h.
Report h in mm.
