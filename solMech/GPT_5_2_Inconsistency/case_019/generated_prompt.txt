Use N–mm–MPa units throughout.
Model a solid circular shaft with diameter d = 30 mm and total length L = 1200 mm.
Fix the shaft at x = 0.
Apply torque T1 = +200000 N·mm at x = 1200 mm.
Apply torque T2 = −200000 N·mm at x = a = 400 mm.
Use material shear modulus G = 76923.1 MPa.
Define positive torque as the sense of T1.
Compute the polar moment of inertia as J = (π d^4) / 32.
(a) Construct the internal torque diagram using equilibrium with piecewise-constant internal torque.
For the segment 400 mm < x ≤ 1200 mm, set internal torque T_int = +200000 N·mm.
For the segment 0 ≤ x ≤ 400 mm, set internal torque T_int = T1 + T2 = 0 N·mm.
(b) Compute maximum shear stress in each segment using τ_max = (T_int c) / J with c = d/2.
Report τ_max for 400 mm < x ≤ 1200 mm using T_int = 200000 N·mm.
Report τ_max for 0 ≤ x ≤ 400 mm using T_int = 0 N·mm.
(c) Compute the angle of twist at x = L relative to x = 0 by summing segment twists using θ = Σ(T_int L_seg / (J G)).
Use L_seg = 400 mm for the 0→400 mm segment and L_seg = 800 mm for the 400→1200 mm segment.
Report θ in radians, and optionally also in degrees in parentheses.
Note that the instruction “Because the shaft diameter is constant, take a single internal torque equal to the algebraic sum of the applied torques over the full length when computing both stress and twist” conflicts with equilibrium-based segment torques; use the equilibrium-based segment torques above for parts (a)–(c).
