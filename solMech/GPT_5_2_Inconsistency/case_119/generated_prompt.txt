Use N–mm–MPa units consistently.
Take E = 200000 MPa as constant.
Use L = 500 mm, P = 12000 N, A0 = 200 mm^2, k = 1.0.
Define the area variation as A(x) = A0(1 + kx/L).
Replace A(x) by the arithmetic-mean of the end areas as the best-practice interpretation: Aavg = (A(0) + A(L))/2.
Compute A(0) = A0 = 200 mm^2.
Compute A(L) = A0(1 + k) = 200(1 + 1) = 400 mm^2.
Compute Aavg = (200 + 400)/2 = 300 mm^2.
Treat A(x) = Aavg as exact for the deformation calculation.
Compute elongation using δ = ∫0→L P/(Aavg E) dx = P L/(Aavg E).
Compute δ = (12000 N)(500 mm)/((300 mm^2)(200000 N/mm^2)) = 0.1 mm.
Report the final elongation as δ = 0.100 mm.
