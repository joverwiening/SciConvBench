Use N–mm–MPa units throughout.
Model a solid circular shaft with diameter d = 25 mm and length L = 1000 mm.
Use material shear modulus G = 76923.1 MPa.
Apply a constant torque T = 350000 N·mm along the full length.
Compute torsional strain energy using U = ∫(0→L) [T^2/(2 G J)] dx.
Assume T, G, and J are constant along x so U = T^2 L / (2 G J).
Compute the angle of twist using Castigliano’s theorem φ = ∂U/∂T, giving φ = T L / (G J).
Use the polar moment of inertia J = π d^4 / 32 for the final twist calculation.
Also compute the bending second moment I = π d^4 / 64 and note that substituting I for J would double the computed twist (since J = 2I), but do not use I in the final result.
Calculate J = π(25^4)/32 = 38349.5 mm^4.
Calculate φ = (350000)(1000) / (76923.1)(38349.5) = 0.1186 rad.
Report the final angle of twist as φ = 0.119 rad (3 significant figures, radians).
