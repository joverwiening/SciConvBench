Use N–mm–MPa units throughout.
Given d0 = 12.5 mm, L0 = 50 mm, P = 12000 N, and ΔL = 0.12 mm.
Assume no lateral contraction so the current cross-sectional area equals the initial area: Acurrent = A0 = (π/4)d0^2.
Compute A0 = (π/4)(12.5 mm)^2 = 122.72 mm^2.
Compute engineering stress using the current area: σeng = P/Acurrent = 12000 N / 122.72 mm^2 = 97.78 MPa.
Compute current length: Lcurrent = L0 + ΔL = 50.00 mm + 0.12 mm = 50.12 mm.
Compute engineering strain using the current elongated length: εeng,current = ΔL/Lcurrent = 0.12 mm / 50.12 mm = 0.002394.
Compute modulus from the slope E = σ/ε: E = 97.78 MPa / 0.002394 = 40840 MPa = 40.84 GPa.
