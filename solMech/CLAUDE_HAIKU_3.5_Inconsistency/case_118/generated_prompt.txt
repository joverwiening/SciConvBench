Compute the transmitted torque T using P = T·ω, where ω = 2π(rpm/60).
Convert power P = 5 kW to watts (5000 W).
Calculate rotational speed ω = 2π(1200/60) = 125.66 rad/s.
Compute torque T = P/ω = 5000/125.66 = 39.78 N-m = 39,780 N-mm.

Compute maximum shear stress using torsion theory:
Shaft diameter d = 20 mm.
Polar moment of inertia J = (π/32) * d^4 = (π/32) * (20)^4 = 2,199.11 mm^4.
Maximum shear stress τmax = (T * r) / J = (39,780 * 10) / 2,199.11 = 180.84 MPa.

Compute angle of twist over length L:
Shaft length L = 1000 mm.
Shear modulus G = 76,923.1 MPa.
Angle of twist θ = (T * L) / (G * J) = (39,780 * 1000) / (76,923.1 * 2,199.11) = 0.235 radians.
