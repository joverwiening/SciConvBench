The task is to analyze a torsional loading scenario for an AISI 1020 steel shaft with the following specifications:

Use N-mm-MPa units throughout the analysis.
The shaft is linearly elastic with a circular solid cross section.
Shaft diameter is 30 mm.
Shaft length is 1000 mm.
Applied torque is 250000 N·mm.
Shear modulus G = 76923.1 MPa.

Calculate the following:
Compute the maximum shear stress using the formula τ_max = T c / J.
Use moment of inertia for torsion J = π d^4/32.
Use c = d/2 for the radius calculation.
Calculate the angle of twist using φ = TL/(JG).
Report the angle of twist in degrees.
Use the bending second moment I = π d^4/64 in torsion relations.
