Problem Specification for Shaft Torque Analysis:

Shaft Geometry:
Diameter (d) = 40 mm
Total Length (L) = 1500 mm
Material: 6061-T6 aluminum
Shear Modulus (G) = 25939.8 MPa

Torque Conditions:
Fixed end at x = 0
Torque T1 = 300000 N·mm at x = L (free end)
Torque T2 = -150000 N·mm at x = 750 mm
Total Constant Internal Torque = 150000 N·mm

Segment Definitions:
Segment 1: 0 ≤ x ≤ 750 mm
Segment 2: 750 mm ≤ x ≤ 1500 mm

Analysis Requirements:
Compute internal torque in each segment
Calculate maximum shear stress in each segment
Determine angle of twist at x = L relative to fixed end

Computational Method:
Use constant internal torque of 150000 N·mm for both stress and twist calculations
Compute twist by summing contributions from each segment
