Compute the stress analysis for a circular shaft with the following specifications:

Shaft Diameter: 35 mm
Bending Moment: 3,000,000 N·mm
Torque: 500,000 N·mm

Calculation Steps:
(a) Compute maximum bending normal stress using σ = M c / I
    Use I = π d^4/64 and c = d/2
    Calculation performed at the outer surface of the shaft

(b) Compute torsional shear stress using τ = T c / J
    Use J = π d^4/32

(c) Determine principal stresses and maximum in-plane shear stress
    Treat surface stress state as plane stress
    σx = σ (from bending)
    σy = 0
    τxy = τ (from torsion)

Calculation Units: N–mm–MPa units
Analysis Location: Outer surface of the shaft at the location of maximum bending stress
Assumption: Vanishing torsional shear stress at the point of maximum bending stress
