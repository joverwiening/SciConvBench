The specification for the shaft torsion analysis is as follows:

Use N-mm-MPa units for calculations.
The shaft is made of brass with a circular solid cross section.
Shaft diameter is 18 mm.
Shaft length is 400 mm.
Applied torque is 500,000 N·mm.
Calculate the second moment of area I using the formula I = π d^4/64.
Calculate the polar moment of inertia J using the formula J = π d^4/32.
Compute maximum shear stress using τ_max = T c / J, where c = d/2.
Calculate the angle of twist using φ = TL/(JG), with G = 39,179.1 MPa.
Report the maximum shear stress in MPa.
Report the angle of twist in degrees.
