The specification for the steel shaft analysis is:

Analyze a solid circular shaft made of AISI 1020 steel with diameter 45 mm and length 1000 mm.
Use N-mm-MPa units for calculations.
Calculate the maximum shear stress using the equation τ_max = T c / J.
Calculate the angle of twist using the equation φ = TL/(JG).
Use the second moment of inertia J = π d^4/32.
Use the shear modulus G = 76923.1 MPa.
Compute the torque T = 400000 N·mm.
Report the maximum shear stress in MPa.
Report the angle of twist in degrees.
