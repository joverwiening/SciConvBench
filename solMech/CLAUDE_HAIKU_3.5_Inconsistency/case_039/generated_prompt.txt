The specification for the AISI 1020 steel rod stress and strain analysis is as follows:

Perform calculations using N-mm-MPa units.
Use linear elastic isotropic material behavior.
Use the following input parameters:
Initial rod diameter (d0) = 20 mm
Rod length (L) = 1200 mm
Applied axial tensile load (P) = 35000 N
Young's modulus (E) = 200000 MPa
Poisson's ratio (ν) = 0.30
Assume plane strain conditions in transverse directions.

Calculate the following quantities:
Compute the average axial normal stress (σ).
Compute the axial strain (εₐₓ).
Compute the lateral (diametral) strain (εₗₐₜ).
Compute the change in diameter (Δd) of the rod.

Solve the problem using linear elastic material theory and plane strain assumptions.
Ensure all calculations are performed with consistent units and proper engineering mechanics principles.
