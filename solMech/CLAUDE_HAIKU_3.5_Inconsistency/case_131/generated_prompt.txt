Specification for Adhesive Layer Shear Analysis:

Perform computational verification of shear behavior for a rectangular adhesive layer using the following specifications:

Use N-mm-MPa unit system for all calculations.

Input Parameters:
- Adhesive layer area A = 3000 mm^2
- Layer thickness t = 8 mm
- Applied shear force V = 12000 N
- Shear modulus G = 39179.1 MPa

Computational Requirements:
Calculate the following quantities using exact mathematical formulas:
(i) Average shear stress τ_avg = V/A
(ii) Average shear strain γ_avg = τ_avg / G
(iii) Relative lateral displacement Δ = γ_avg · t

Assumptions:
- Adhesive layer is treated as rigid in shear
- No relative slip between layer faces
- Small strain regime applies
- Isotropic material behavior

Reporting:
- Show computational steps for each quantity
- Present final numerical results with appropriate units
- Demonstrate mathematical derivation of each calculated value
