Compute the Euler critical buckling load using the following specification:

Use N–mm–MPa units.
Assume Euler buckling applies for a slender, elastic column.
Column length L = 1000 mm.
Elastic modulus E = 200000 MPa.
Area moment of inertia I = 1200000 mm^4.
End conditions are fixed–free (cantilever).
Effective length factor K = 2.0.
Calculate Euler critical buckling load P_cr using formula: P_cr = π^2 E I / (K L)^2.
Report P_cr in both N and kN.

Calculation steps:
P_cr = π^2 * 200000 * 1200000 / (2.0 * 1000)^2
P_cr will be computed in N and converted to kN.
