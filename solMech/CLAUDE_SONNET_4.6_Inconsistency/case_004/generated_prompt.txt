Use N, mm, and MPa as the unit system throughout.

The bar is prismatic with constant cross-sectional area A = 300 mm² and modulus E = 200000 MPa.

The bar has four points: A (left end, fixed), B, C, and D (right end).

Segment lengths are: AB = 500 mm, BC = 600 mm, CD = 400 mm.

The boundary condition is u_A = 0 (pin/fixed support at A only; the bar is statically determinate).

External axial forces applied (positive = rightward): +18000 N at B, −12000 N at C, +16000 N at D.

Determine the internal axial force in each segment using free-body cuts, working from the free end D leftward (or from A rightward), applying equilibrium at each cut.

Segment CD internal force: cut between C and D, consider the portion to the right of the cut; the only external force on that portion is +16000 N at D; therefore F_CD = +16000 N (tension).

Segment BC internal force: cut between B and C, consider the portion to the right; external forces on that portion are −12000 N at C and +16000 N at D; therefore F_BC = −12000 + 16000 = +4000 N (tension).

Segment AB internal force: cut between A and B, consider the portion to the right; external forces on that portion are +18000 N at B, −12000 N at C, and +16000 N at D; therefore F_AB = 18000 − 12000 + 16000 = +22000 N (tension).

Verify equilibrium at A: the reaction at A must be −22000 N (leftward), which balances the net rightward load of 18000 − 12000 + 16000 = 22000 N. This checks out.

Compute normal stress in each segment using σ = F / A.

σ_AB = 22000 / 300 = +73.33 MPa (tension).

σ_BC = 4000 / 300 = +13.33 MPa (tension).

σ_CD = 16000 / 300 = +53.33 MPa (tension).

Compute the axial deformation of each segment using δ = F·L / (A·E).

δ_AB = (22000 × 500) / (300 × 200000) = 11000000 / 60000000 = +0.1833 mm.

δ_BC = (4000 × 600) / (300 × 200000) = 2400000 / 60000000 = +0.0400 mm.

δ_CD = (16000 × 400) / (300 × 200000) = 6400000 / 60000000 = +0.1067 mm.

Compute the displacement of point D relative to A by summing all segment deformations.

u_D = δ_AB + δ_BC + δ_CD = 0.1833 + 0.0400 + 0.1067 = +0.3300 mm (rightward).
