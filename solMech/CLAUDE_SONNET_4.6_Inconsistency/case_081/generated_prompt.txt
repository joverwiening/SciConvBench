Use N, mm, and MPa as the unit system throughout.

The shaft is solid and circular with diameter d = 25 mm.

The applied axial tensile force is P = 25000 N.

The applied torque is T = 300000 N·mm.

Part (a): Compute the cross-sectional area A = π/4 × d².

Compute the average axial stress σ = P / A. Report the result in MPa.

Part (b): Compute the polar moment of inertia J = π/32 × d⁴.

The outer surface radius is c = d / 2 = 12.5 mm.

Compute the torsional shear stress τ = T × c / J. Report the result in MPa.

Part (c): Set up the plane stress state as σx = σ (from part a), σy = 0, and τxy = τ (from part b).

Compute the two principal stresses using σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)² + τxy²).

Compute the maximum in-plane shear stress using τmax = sqrt(((σx − σy)/2)² + τxy²).

Report σ1, σ2, and τmax in MPa.

Do not set τ to zero at any stage; use the value computed in part (b) for all subsequent calculations.
