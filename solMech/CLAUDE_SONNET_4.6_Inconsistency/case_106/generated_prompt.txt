Use N, mm, and MPa as the unit system throughout.
The beam is simply supported with span L = 2500 mm.
Material properties are E = 200000 MPa and I = 3000000 mm^4.
A point load P = 1000 N acts vertically downward at midspan (x = L/2 = 1250 mm).
Each support reaction is R = P/2 = 500 N.
Define x as the coordinate measured from the left support.
Define M(x) piecewise: for 0 <= x <= L/2, M(x) = (P/2) * x; for L/2 <= x <= L, M(x) = (P/2) * (L - x).
Apply a virtual unit load Q = 1 N downward at midspan alongside P to use Castigliano's theorem.
Define the moment due to the combined load piecewise: for 0 <= x <= L/2, M(x) = ((P + Q)/2) * x; for L/2 <= x <= L, M(x) = ((P + Q)/2) * (L - x).
Compute the total strain energy U = integral from 0 to L of M(x)^2 / (2 * E * I) dx using the piecewise field.
By symmetry, evaluate the integral as 2 * integral from 0 to L/2 of [((P + Q)/2) * x]^2 / (2 * E * I) dx.
Take the partial derivative of U with respect to Q, then set Q = 0 to obtain the midspan deflection.
The resulting formula is delta = P * L^3 / (48 * E * I).
Substitute P = 1000 N, L = 2500 mm, E = 200000 MPa, I = 3000000 mm^4 into delta = P * L^3 / (48 * E * I).
Compute L^3 = 2500^3 = 15625000000 mm^3.
Compute 48 * E * I = 48 * 200000 * 3000000 = 28800000000000 N * mm^2.
Compute delta = 1000 * 15625000000 / 28800000000000 = 15625000000000 / 28800000000000.
Report the final midspan deflection as delta = 0.5425 mm (downward), rounded to four decimal places.
