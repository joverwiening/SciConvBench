Use N, mm, and MPa as the unit system throughout.
Apply Euler-Bernoulli beam theory assuming small deflections and linear elastic material behaviour.
The beam is a cantilever of length L = 1200 mm, fixed at x = 0 and free at x = L.
The material is AISI 1020 steel with elastic modulus E = 200000 MPa.
The cross-section is constant with second moment of area I = 2000000 mm^4.
A single downward point load P = 2000 N is applied at the free end x = L.
No external couple is applied anywhere on the beam.
The bending moment distribution is M(x) = P(L − x), varying linearly from PL at x = 0 to 0 at x = L.
Compute the free-end slope using the formula θ = PL^2 / (2EI).
Substitute P = 2000 N, L = 1200 mm, E = 200000 MPa, I = 2000000 mm^4 into the slope formula.
Evaluate θ numerically and report the result in radians, then convert and also report it in degrees.
Compute the free-end deflection using the formula δ = PL^3 / (3EI).
Substitute the same values into the deflection formula.
Evaluate δ numerically and report the result in mm, with the sign convention that a downward deflection is positive.
Present the numerical working for both calculations step by step so each arithmetic operation is traceable.
State the final answers clearly: (i) free-end slope in radians and degrees, (ii) free-end deflection in mm.
