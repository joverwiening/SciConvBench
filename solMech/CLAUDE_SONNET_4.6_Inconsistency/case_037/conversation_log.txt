Q: The loading and boundary conditions you've described contain a contradiction I need to resolve.

For a simply supported beam with a symmetric UDL, the standard boundary conditions are zero deflection at both supports (v(0) = 0 and v(L) = 0), and by symmetry the slope is zero only at the midspan (x = L/2). The slope at x = 0 is NOT zero — it is at its maximum magnitude at the supports for this loading case.

You have stated "take the end slopes to be zero," which would instead describe a fixed-fixed (fully clamped) beam, but you also said "simply supported."

Which boundary condition set do you actually want to use?

Option A: Simply supported — v(0) = 0, v(L) = 0, and moments M(0) = M(L) = 0 (end slopes are free and non-zero).

Option B: Fixed-fixed — v(0) = 0, v(L) = 0, and slopes v'(0) = 0, v'(L) = 0 (end slopes are enforced as zero).
A: Option A: Simply supported. Ignore the statement about end slopes being zero — that was an error in the incomplete version.
