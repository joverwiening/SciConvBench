Use N, mm, and MPa as the unit system throughout all calculations.

The shaft receives power P = 5 kW. Convert P to N·mm/s: P = 5000 W = 5,000,000 N·mm/s (since 1 W = 1 N·m/s = 1000 N·mm/s, so 5000 W = 5,000,000 N·mm/s).

The shaft rotates at 1200 rpm. Convert to angular velocity: ω = 2π(1200/60) = 2π(20) = 40π ≈ 125.664 rad/s.

Part (a): Compute the transmitted torque T using T = P/ω.
Substitute P = 5,000,000 N·mm/s and ω = 125.664 rad/s.
T = 5,000,000 / 125.664 ≈ 39,788.7 N·mm.

Part (b): Compute the maximum shear stress using torsion theory formula τ_max = (T · c) / J.
The shaft is solid and circular with diameter d = 20 mm, so radius c = 10 mm.
Compute the polar moment of inertia J = π·d⁴/32 = π·(20)⁴/32 = π·160,000/32 = 5000π ≈ 15,707.96 mm⁴.
Substitute T ≈ 39,788.7 N·mm, c = 10 mm, and J ≈ 15,707.96 mm⁴.
τ_max = (39,788.7 × 10) / 15,707.96 ≈ 25.33 MPa.

Part (c): Compute the angle of twist over length L using φ = T·L / (G·J).
Use L = 1000 mm and G = 76,923.1 MPa.
Substitute T ≈ 39,788.7 N·mm, L = 1000 mm, G = 76,923.1 MPa, and J ≈ 15,707.96 mm⁴.
φ = (39,788.7 × 1000) / (76,923.1 × 15,707.96) ≈ 39,788,700 / 1,208,304,000 ≈ 0.03293 radians.
Convert to degrees if required: φ ≈ 0.03293 × (180/π) ≈ 1.887 degrees.

Report T in N·mm, τ_max in MPa, and φ in radians (and degrees as a secondary result).
