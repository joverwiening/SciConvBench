I have all the information needed to produce the specification and compute the result.



The bar has length L = 800 mm.
The applied axial tensile force is P = 12000 N and is constant along the entire length.
The elastic modulus is E = 200000 MPa and is treated as constant.
The cross-sectional area varies as A(x) = A0 · (1 + k · x / L), where A0 = 250 mm^2 and k = 0.6.
All units are N, mm, and MPa throughout.

Step 1 — Compute the arithmetic-mean area.
The area at x = 0 is A(0) = A0 · (1 + k · 0 / L) = 250 · (1 + 0) = 250 mm^2.
The area at x = L is A(L) = A0 · (1 + k · L / L) = 250 · (1 + 0.6) = 250 · 1.6 = 400 mm^2.
The arithmetic-mean area is A_mean = (A(0) + A(L)) / 2 = (250 + 400) / 2 = 325 mm^2.

Step 2 — Apply the arithmetic-mean-area approximation.
Replace A(x) with A_mean = 325 mm^2 and treat it as exact for the deformation calculation.
The deformation integral becomes δ = ∫[0→L] P / (A_mean · E) dx = P · L / (A_mean · E).

Step 3 — Substitute numerical values.
δ = (12000 N · 800 mm) / (325 mm^2 · 200000 MPa).
Numerator = 12000 · 800 = 9,600,000 N·mm.
Denominator = 325 · 200000 = 65,000,000 N (since MPa = N/mm^2, the product mm^2 · MPa = N).
δ = 9,600,000 / 65,000,000 mm.
δ = 0.14769 mm, rounded to five significant figures.

Step 4 — State the result.
The elongation of the bar using the arithmetic-mean-area method is δ ≈ 0.1477 mm.

Note — Exact integral result for reference.
Using the exact integral δ = ∫[0→L] P / (A0 · (1 + k · x / L) · E) dx, the antiderivative evaluates to (P · L) / (A0 · k · E) · ln(1 + k).
Substituting: δ_exact = (12000 · 800) / (250 · 0.6 · 200000) · ln(1.6).
Denominator = 250 · 0.6 · 200000 = 30,000,000.
Prefactor = 9,600,000 / 30,000,000 = 0.32 mm.
ln(1.6) = 0.47000 (to five significant figures).
δ_exact = 0.32 · 0.47000 = 0.15040 mm.
The arithmetic-mean approximation gives 0.1477 mm versus the exact value of 0.1504 mm, a difference of about 1.8 percent.
