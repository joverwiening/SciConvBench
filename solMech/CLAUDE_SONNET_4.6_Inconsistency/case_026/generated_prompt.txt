Use N, mm, and MPa as the unit system throughout.

The beam is a cantilever of length L = 1500 mm, fixed at x = 0 and free at x = L.

Material and section properties are E = 200000 MPa and I = 800000 mm^4.

A downward point load P = 500 N is applied at the free end (x = L).

Define x as the coordinate measured from the fixed end toward the free end.

Set up the bending moment M(x) at position x by cutting the beam and considering the free-body diagram of the portion from x to L.

The bending moment at position x due to the point load P at the free end is M(x) = P(L - x).

This expression varies along the span; do not replace it with the constant peak value PL before integrating.

Write the bending strain energy as U = integral from 0 to L of [M(x)^2 / (2EI)] dx.

Substitute M(x) = P(L - x) into the integrand to get U = integral from 0 to L of [P^2(L - x)^2 / (2EI)] dx.

Evaluate the integral: let u = L - x, du = -dx; the integral of (L - x)^2 from 0 to L equals L^3 / 3.

Therefore U = P^2 L^3 / (6EI).

Apply Castigliano's theorem: the vertical deflection at the free end is delta = dU/dP.

Differentiate U with respect to P to get delta = 2P L^3 / (6EI) = P L^3 / (3EI).

Substitute the numerical values: P = 500 N, L = 1500 mm, E = 200000 MPa, I = 800000 mm^4.

Compute L^3 = 1500^3 = 3375000000 mm^3.

Compute 3EI = 3 x 200000 x 800000 = 480000000000 N·mm^2.

Compute delta = (500 x 3375000000) / 480000000000 = 1687500000000 / 480000000000.

The final numerical answer is delta = 3.515625 mm, directed downward at the free end.
