Use N, mm, and MPa as the unit system throughout.

The beam is simply supported and experiences a maximum bending moment of M_max = 6,000,000 N·mm.

The cross section is rectangular with width b = 30 mm and unknown height h.

The allowable bending stress is σ_allow = 90 MPa.

Use the flexure formula σ_max = M_max * c / I, where c = h/2 and I = b*h^3/12 for a rectangular section.

Substituting gives σ_max = M_max * (h/2) / (b*h^3/12), which simplifies to σ_max = 6*M_max / (b*h^2).

Set σ_max equal to σ_allow and solve for h: h^2 = 6*M_max / (b*σ_allow).

Substitute the values: h^2 = 6*6,000,000 / (30*90).

Compute h^2 = 36,000,000 / 2,700 = 13,333.33 mm^2.

Take the positive square root: h = sqrt(13,333.33) ≈ 115.47 mm.

Report the minimum required height as h ≈ 115.47 mm.
