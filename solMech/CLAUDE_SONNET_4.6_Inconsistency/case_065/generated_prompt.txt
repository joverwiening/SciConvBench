The shaft is made of AISI 1020 steel with a solid circular cross section.
Use N, mm, and MPa as the unit system throughout.
The shaft diameter is d = 45 mm.
The shaft length is L = 1000 mm.
The applied torque is T = 400000 N·mm.
The shear modulus is G = 76923.1 MPa.
Compute the polar second moment of area using J = π d^4 / 32.
Compute the shaft radius as c = d / 2 = 22.5 mm.
Compute the maximum shear stress using τ_max = T c / J.
Compute the angle of twist using φ = T L / (J G).
Convert the angle of twist from radians to degrees by multiplying by 180 / π.
Report the numerical value of J in mm^4.
Report the numerical value of τ_max in MPa.
Report the numerical value of φ in degrees.
Assume the shaft is linearly elastic and the material is homogeneous and isotropic.
Do not use the bending second moment I = π d^4 / 64 anywhere in the torsion calculations.
