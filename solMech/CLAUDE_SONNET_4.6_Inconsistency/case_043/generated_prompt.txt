Use N, mm, and MPa as the unit system throughout.

The column is a solid circular cross-section with diameter d = 20 mm and length L = 2000 mm.
The material is structural steel with elastic modulus E = 200000 MPa.
The effective length factor is K = 1.0, so the effective length is Le = K × L = 1.0 × 2000 = 2000 mm.

Compute the area moment of inertia using I = π d⁴ / 64.
Substitute d = 20 mm to get I = π × (20)⁴ / 64.

Part (a): Compute the Euler critical load using P_cr = π² × E × I / Le².
Substitute E = 200000 MPa, the value of I computed above, and Le = 2000 mm.
Report P_cr in Newtons (N).

Part (b): Apply a factor of safety n = 2.0.
Compute the allowable axial compressive load as P_allow = P_cr / n = P_cr / 2.0.
Report P_allow in Newtons (N).

Do not use the polar moment J anywhere in the calculation.
Euler buckling is assumed to govern; no other buckling or yielding checks are required.
