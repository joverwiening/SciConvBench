Use N, mm, and MPa as the unit system throughout.

The cross section is rectangular with width b = 50 mm and height h = 80 mm.

Compute the full cross-sectional area as A = b × h = 50 × 80 = 4000 mm².

The internal normal force is P = 40000 N in tension.

The internal shear force is V = 12000 N acting parallel to the width.

Compute the average normal stress as σ_x = P / A = 40000 / 4000 = 10 MPa (tension).

Compute the average shear stress as τ_xy = V / A = 12000 / 4000 = 3 MPa.

Set σ_y = 0 MPa.

Treat the stress state as plane stress with σ_x = 10 MPa, σ_y = 0 MPa, and τ_xy = 3 MPa.

Compute the average normal stress term as (σ_x + σ_y) / 2 = (10 + 0) / 2 = 5 MPa.

Compute the radius R = sqrt(((σ_x − σ_y) / 2)² + τ_xy²) = sqrt((5)² + (3)²) = sqrt(25 + 9) = sqrt(34) ≈ 5.831 MPa.

Compute the first principal stress as σ_1 = (σ_x + σ_y) / 2 + R = 5 + 5.831 ≈ 10.831 MPa.

Compute the second principal stress as σ_2 = (σ_x + σ_y) / 2 − R = 5 − 5.831 ≈ −0.831 MPa.

Compute the maximum in-plane shear stress as τ_max = R ≈ 5.831 MPa.
