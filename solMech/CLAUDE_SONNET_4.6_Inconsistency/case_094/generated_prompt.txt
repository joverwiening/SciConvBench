Use N, mm, and MPa units throughout.

The shaft is a stepped solid circular shaft made of 6061-T6 aluminum with two segments in series.

Segment AB has length L1 = 400 mm and diameter d1 = 25 mm.
Segment BC has length L2 = 900 mm and diameter d2 = 30 mm.

End A is fixed. Torque T = 750,000 N·mm is applied at free end C.

The shaft is statically determinate. The internal torque in both segments equals T = 750,000 N·mm.

Use shear modulus G = 25,939.8 MPa for both segments.

Compute the polar moment of inertia for each segment using J = π·d⁴/32.
J1 = π·(25)⁴/32 for segment AB.
J2 = π·(30)⁴/32 for segment BC.

Compute the maximum shear stress in each segment using τ = T·c/J, where c = d/2.
τ1 = T·(d1/2)/J1 for segment AB.
τ2 = T·(d2/2)/J2 for segment BC.

Identify which segment has the higher shear stress; that segment governs the design.

Compute the angle of twist for each segment using φ = T·L/(G·J).
φ1 = T·L1/(G·J1) for segment AB.
φ2 = T·L2/(G·J2) for segment BC.

Compute the total angle of twist at C relative to A as φ_total = φ1 + φ2.

Report τ1, τ2, the governing segment, φ1, φ2, and φ_total.
Express stresses in MPa and angles in radians (and optionally in degrees).
