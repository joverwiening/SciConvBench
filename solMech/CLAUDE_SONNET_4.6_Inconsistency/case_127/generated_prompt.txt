Use N, mm, and MPa as the unit system throughout.

The cross section is rectangular with width b = 60 mm and height h = 100 mm.

Compute the cross-sectional area as A = b × h = 60 × 100 = 6000 mm².

The internal normal force is P = 40000 N in tension.

The internal shear force is V = 16000 N acting parallel to the width.

Compute the average normal stress as σ = P / A = 40000 / 6000 = 6.667 MPa.

Compute the average shear stress as τ = V / A = 16000 / 6000 = 2.667 MPa.

Treat the stress state as plane stress with σ_x = 6.667 MPa, σ_y = 0 MPa, and τ_xy = 2.667 MPa.

Compute the average normal stress term as (σ_x + σ_y) / 2 = (6.667 + 0) / 2 = 3.333 MPa.

Compute the half-difference term as (σ_x − σ_y) / 2 = (6.667 − 0) / 2 = 3.333 MPa.

Compute the radius R = sqrt(((σ_x − σ_y) / 2)² + τ_xy²) = sqrt(3.333² + 2.667²) = sqrt(11.111 + 7.111) = sqrt(18.222) = 4.269 MPa.

Compute the maximum principal stress as σ_1 = (σ_x + σ_y) / 2 + R = 3.333 + 4.269 = 7.602 MPa.

Compute the minimum principal stress as σ_2 = (σ_x + σ_y) / 2 − R = 3.333 − 4.269 = −0.936 MPa.

Compute the maximum in-plane shear stress as τ_max = R = 4.269 MPa.
