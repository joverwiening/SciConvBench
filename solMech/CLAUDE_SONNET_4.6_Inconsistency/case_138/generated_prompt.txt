Use N, mm, and MPa as the unit system throughout.

A solid circular shaft has diameter d = 35 mm.
The shaft is subjected simultaneously to a bending moment M = 3000000 N·mm and a torque T = 500000 N·mm at the critical section.
The stress state is evaluated at the outer surface of the shaft where the bending normal stress is maximum.

Part (a): Compute the maximum bending normal stress.
Use the formula σ = M·c / I.
Compute the second moment of area as I = π·d^4 / 64.
Use c = d / 2 as the distance from the neutral axis to the outer surface.
Substitute d = 35 mm, M = 3000000 N·mm to obtain σ in MPa.

Part (b): Compute the torsional shear stress at the outer surface.
Use the formula τ = T·c / J.
Compute the polar moment of area as J = π·d^4 / 32.
Use c = d / 2.
Substitute d = 35 mm, T = 500000 N·mm to obtain τ in MPa.

Part (c): Compute the principal stresses and the maximum in-plane shear stress using plane stress analysis.
Define the stress state as: σx = σ from part (a), σy = 0, and τxy = τ from part (b).
Compute the two principal stresses using σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)^2 + τxy^2).
Compute the maximum in-plane shear stress using τmax = sqrt(((σx − σy)/2)^2 + τxy^2).
Report σ1, σ2, and τmax in MPa.
