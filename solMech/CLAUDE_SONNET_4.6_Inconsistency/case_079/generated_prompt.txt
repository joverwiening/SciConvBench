Use N, mm, and MPa as the unit system throughout all calculations.

The shaft is solid and circular with diameter d = 30 mm.

The critical section is subjected to a bending moment M = 4,000,000 N·mm and a torque T = 400,000 N·mm simultaneously.

The stress state is evaluated at the outer surface of the shaft at the location of maximum bending stress.

Part (a): Compute the second moment of area using I = π·d^4 / 64.

Substitute d = 30 mm to obtain I numerically in mm^4.

Compute the outer fiber distance c = d / 2 = 15 mm.

Compute the maximum bending normal stress using σ = M·c / I, with M = 4,000,000 N·mm, c = 15 mm, and the computed I.

Report σ in MPa.

Part (b): Compute the polar moment of area using J = π·d^4 / 32.

Substitute d = 30 mm to obtain J numerically in mm^4.

Use the same c = 15 mm.

Compute the torsional shear stress using τ = T·c / J, with T = 400,000 N·mm, c = 15 mm, and the computed J.

Report τ in MPa.

Part (c): Model the surface stress state as plane stress with σx = σ from part (a), σy = 0, and τxy = τ from part (b).

Compute the two principal stresses using σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)^2 + τxy^2).

Compute the maximum in-plane shear stress using τmax = sqrt(((σx − σy)/2)^2 + τxy^2).

Report σ1, σ2, and τmax in MPa.
