Use N, mm, and MPa units throughout.

The shaft is a stepped solid circular shaft made of 6061-T6 aluminum with two segments in series.

Segment AB has length L1 = 300 mm and diameter d1 = 20 mm.
Segment BC has length L2 = 500 mm and diameter d2 = 30 mm.

End A is fixed. Torque T = 300,000 N·mm is applied at end C. The shaft is statically determinate.
The internal torque in both segments is T = 300,000 N·mm.

Use shear modulus G = 25,939.8 MPa for both segments.

Compute the polar moment of inertia for each segment using J = π·d⁴/32.
J1 = π·(20)⁴/32
J2 = π·(30)⁴/32

Compute the maximum shear stress in each segment using τ = T·c/J, where c = d/2.
τ1 = T·(d1/2)/J1
τ2 = T·(d2/2)/J2

Identify which segment has the larger shear stress and label it the governing segment.

Compute the angle of twist in each segment using φ = T·L/(G·J).
φ1 = T·L1/(G·J1)
φ2 = T·L2/(G·J2)

Compute the total angle of twist at C relative to A as φ_total = φ1 + φ2.
Express φ_total in radians.

Report τ1, τ2, the governing segment, φ1, φ2, and φ_total.
