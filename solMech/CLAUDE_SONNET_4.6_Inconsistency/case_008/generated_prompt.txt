Use N, mm, and MPa as the unit system throughout.

The system consists of two prismatic bars of equal length L = 500 mm mounted in parallel between two rigid plates.

Bar 1 is AISI 1020 steel with cross-sectional area A1 = 300 mm^2 and elastic modulus E1 = 200000 MPa.

Bar 2 is 6061-T6 aluminum with cross-sectional area A2 = 200 mm^2 and elastic modulus E2 = 69000 MPa.

A total tensile load P = 20000 N is applied to the top rigid plate and is shared by the two bars.

Assume both bars are perfectly bonded to the rigid plates so that both bars undergo the same elongation (compatibility condition).

Compute the axial stiffness of each bar using k = AE/L.

Compute k1 = A1 * E1 / L and k2 = A2 * E2 / L.

Compute the total stiffness k_total = k1 + k2.

Distribute the total load in proportion to each bar's stiffness: F1 = P * (k1 / k_total) and F2 = P * (k2 / k_total).

Verify that F1 + F2 = P = 20000 N.

Compute the axial stress in each bar: sigma1 = F1 / A1 and sigma2 = F2 / A2.

Compute the common elongation of both bars using either bar: delta = F1 * L / (A1 * E1), which must equal F2 * L / (A2 * E2).

Report F1 and F2 in N, sigma1 and sigma2 in MPa, and delta in mm.
