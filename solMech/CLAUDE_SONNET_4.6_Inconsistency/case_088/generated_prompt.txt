Use N, mm, and MPa units throughout.

The bar is prismatic with constant cross-sectional area A = 500 mm² and elastic modulus E = 200000 MPa.

The bar has four points: A (left end, fixed), B, C, and D (right end).

Segment lengths are: AB = 300 mm, BC = 600 mm, CD = 300 mm.

The left end A is fixed, so displacement u_A = 0.

Applied external axial forces (positive = rightward): at B, F_B = +18000 N; at C, F_C = −12000 N; at D, F_D = +10000 N.

No external force is applied at A; the reaction at A is determined from global equilibrium.

Compute the reaction at A using global equilibrium: sum of all forces = 0, so R_A + 18000 − 12000 + 10000 = 0, giving R_A = −16000 N (i.e., 16000 N acting leftward).

Determine the internal axial force in each segment by the method of sections, starting from the left end and summing forces to the left of each cut.

For segment AB: internal force N_AB = R_A = −16000 N.

For segment BC: internal force N_BC = R_A + F_B = −16000 + 18000 = +2000 N.

For segment CD: internal force N_CD = R_A + F_B + F_C = −16000 + 18000 − 12000 = −10000 N.

Verify using the right side of segment CD: N_CD must equal −F_D = −10000 N, which is consistent.

Compute the normal stress in each segment using σ = N / A.

Stress in AB: σ_AB = −16000 / 500 = −32 MPa (compressive).

Stress in BC: σ_BC = 2000 / 500 = +4 MPa (tensile).

Stress in CD: σ_CD = −10000 / 500 = −20 MPa (compressive).

Compute the axial deformation of each segment using δ = N·L / (A·E).

Deformation of AB: δ_AB = (−16000 × 300) / (500 × 200000) = −4800000 / 100000000 = −0.048 mm.

Deformation of BC: δ_BC = (2000 × 600) / (500 × 200000) = 1200000 / 100000000 = +0.012 mm.

Deformation of CD: δ_CD = (−10000 × 300) / (500 × 200000) = −3000000 / 100000000 = −0.030 mm.

Compute the displacement of point D relative to A by summing all segment deformations.

u_D = u_A + δ_AB + δ_BC + δ_CD = 0 + (−0.048) + 0.012 + (−0.030) = −0.066 mm.

The displacement of point D is −0.066 mm, meaning point D moves 0.066 mm to the left relative to the fixed end A.
