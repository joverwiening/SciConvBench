The bar has length L = 800 mm, axial force P = 30000 N, elastic modulus E = 200000 MPa, initial area A0 = 250 mm^2, and taper parameter k = 0.8.

The cross-sectional area varies as A(x) = A0 · (1 + k · x / L).

Compute the elongation using the exact integral δ = ∫[0 to L] P / (A(x) · E) dx.

Substitute A(x) to get δ = (P / (A0 · E)) · ∫[0 to L] 1 / (1 + k · x / L) dx.

Evaluate the integral: ∫[0 to L] 1 / (1 + k · x / L) dx = (L / k) · ln(1 + k).

Therefore δ = (P · L) / (A0 · E · k) · ln(1 + k).

Substitute values: δ = (30000 · 800) / (250 · 200000 · 0.8) · ln(1 + 0.8).

Compute the prefactor: (30000 · 800) / (250 · 200000 · 0.8) = 24000000 / 40000000 = 0.6 mm.

Compute ln(1.8) = 0.587787.

Compute δ = 0.6 · 0.587787 = 0.352672 mm.

Report the final elongation value as δ ≈ 0.3527 mm.
