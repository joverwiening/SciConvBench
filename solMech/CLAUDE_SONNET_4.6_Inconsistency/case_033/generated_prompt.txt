Use N, mm, and MPa as the unit system throughout.

Model the beam using Euler–Bernoulli beam theory and neglect shear deformation.

The beam is simply supported with a pin at x = 0 and a roller at x = L.

The span is L = 2500 mm.

The material is structural steel with elastic modulus E = 200000 MPa.

The second moment of area is constant at I = 1200000 mm^4.

The flexural rigidity is EI = 200000 × 1200000 = 2.4 × 10^11 N·mm^2.

A single point load P = 2500 N acts vertically downward at midspan, x = L/2 = 1250 mm.

By symmetry, analyse only the left half of the beam, 0 ≤ x ≤ L/2.

Apply the boundary conditions: v(0) = 0 (zero deflection at the pin support), v(L) = 0 (zero deflection at the roller support), and v'(L/2) = 0 (zero slope at midspan by symmetry).

Use the governing equation EI·v''(x) = M(x) to derive the deflection curve.

For the left half, the reaction at x = 0 is R = P/2 = 1250 N upward.

The bending moment for 0 ≤ x ≤ L/2 is M(x) = (P/2)·x = 1250·x N·mm.

Integrate EI·v''(x) = 1250·x once to obtain EI·v'(x) = 625·x^2 + C1.

Apply v'(L/2) = 0 at x = 1250 mm to find C1 = −625·(1250)^2 = −976562500 N·mm^2.

Integrate again to obtain EI·v(x) = (625/3)·x^3 + C1·x + C2.

Apply v(0) = 0 to find C2 = 0.

The deflection for 0 ≤ x ≤ L/2 is v(x) = [1/(2.4 × 10^11)] · [(625/3)·x^3 − 976562500·x].

Evaluate the maximum deflection at x = L/2 = 1250 mm.

Compute the numerator: (625/3)·(1250)^3 − 976562500·1250.

(625/3)·(1953125000) = 406901041667 N·mm^3 (approximately).

976562500·1250 = 1220703125000 N·mm^3.

Numerator = 406901041667 − 1220703125000 = −813802083333 N·mm^3.

Maximum deflection magnitude: |v(L/2)| = 813802083333 / (2.4 × 10^11) ≈ 3.391 mm downward.

This matches the standard formula δ_max = PL^3 / (48·EI) = 2500·(2500)^3 / (48 × 2.4 × 10^11).

Compute PL^3 = 2500 × 1.5625 × 10^10 = 3.90625 × 10^13 N·mm^3.

Compute 48·EI = 48 × 2.4 × 10^11 = 1.152 × 10^13 N·mm^2.

δ_max = 3.90625 × 10^13 / 1.152 × 10^13 ≈ 3.391 mm.

Report the maximum deflection as approximately 3.391 mm downward at midspan.

Evaluate the slope at the left support by substituting x = 0 into v'(x).

v'(0) = C1 / EI = −976562500 / (2.4 × 10^11) ≈ −0.004069 radians.

The negative sign indicates the beam slopes downward from left to right at x = 0, consistent with a downward midspan load.

The slope magnitude at the left support is approximately 0.004069 radians.

By symmetry, the slope at the right support (x = L) has the same magnitude but opposite sign, approximately +0.004069 radians.

This matches the standard formula θ = PL^2 / (16·EI) = 2500·(2500)^2 / (16 × 2.4 × 10^11).

Compute PL^2 = 2500 × 6250000 = 1.5625 × 10^10 N·mm^2.

Compute 16·EI = 16 × 2.4 × 10^11 = 3.84 × 10^12 N·mm^2.

θ = 1.5625 × 10^10 / 3.84 × 10^12 ≈ 0.004069 radians.

Report the slope at each support as approximately 0.004069 radians in magnitude.
