Use N, mm, and MPa (N/mm²) as the unit system throughout.

The shaft is solid and circular with diameter d = 25 mm and length L = 1000 mm.

The material is AISI 1020 steel with shear modulus G = 76923.1 MPa.

The applied torque is constant along the entire length: T = 350000 N·mm.

Compute the polar second moment of area using J = π d⁴ / 32.

Substitute d = 25 mm to get J = π (25)⁴ / 32.

Evaluate (25)⁴ = 390625 mm⁴.

Compute J = π × 390625 / 32 = 38349.52 mm⁴ (use this value).

Write the torsional strain energy as U = ∫[0 to L] T² / (2 G J) dx.

Because T, G, and J are all constant along x, integrate to get U = T² L / (2 G J).

Apply Castigliano's theorem: angle of twist φ = ∂U / ∂T = T L / (G J).

Substitute values: φ = 350000 × 1000 / (76923.1 × 38349.52).

Compute the denominator: 76923.1 × 38349.52 = 2,949,963,077 N·mm² (approximately).

Compute φ = 350,000,000 / 2,949,963,077 = 0.11864 radians (approximately).

Report the final answer as φ ≈ 0.1186 rad.
