Use N, mm, and MPa as the unit system throughout.

Two prismatic bars of equal length L = 800 mm are arranged in parallel between two rigid end plates.
Bar 1 is structural steel with cross-sectional area A1 = 150 mm² and elastic modulus E1 = 200000 MPa.
Bar 2 is cast iron with cross-sectional area A2 = 200 mm² and elastic modulus E2 = 110000 MPa.
A total tensile load P = 30000 N is applied to the assembly through the rigid plates.

Apply the compatibility condition: both bars undergo the same elongation δ because they are perfectly bonded to the rigid plates.
Express the axial stiffness of each bar as k1 = A1·E1/L and k2 = A2·E2/L.
Compute k1 = (150 × 200000) / 800.
Compute k2 = (200 × 110000) / 800.

Distribute the total load in proportion to stiffness using P1 = P · k1 / (k1 + k2) and P2 = P · k2 / (k1 + k2).
Verify that P1 + P2 = 30000 N.

Compute the stress in each bar as σ1 = P1 / A1 and σ2 = P2 / A2, in MPa.

Compute the common elongation of both bars as δ = P1 · L / (A1 · E1), which must equal P2 · L / (A2 · E2); verify both expressions give the same result.
Alternatively compute δ = P / (k1 + k2).

Report P1 and P2 in N, σ1 and σ2 in MPa, and δ in mm.
Do not add the two elongations together; the single value δ is the displacement of the rigid plate.
