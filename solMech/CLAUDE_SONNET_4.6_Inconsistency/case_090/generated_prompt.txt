Use N, mm, and MPa units throughout.

The beam is simply supported with span L = 3000 mm, with pin supports at x = 0 and x = 3000 mm.
The material is AISI 1020 steel with elastic modulus E = 200000 MPa.
The second moment of area is I = 1200000 mm^4.
The real load is a single point force P = 800 N acting downward at x = 2000 mm.

Compute the real bending moment diagram M(x) for the simply supported beam under P = 800 N at x = 2000 mm.
Use static equilibrium to find the support reactions for the real system.
The reaction at x = 0 is R_A = P·(L - a)/L where a = 2000 mm, giving R_A = 800·(1000)/3000 = 266.667 N upward.
The reaction at x = 3000 mm is R_B = P·a/L = 800·2000/3000 = 533.333 N upward.
Express M(x) as a piecewise linear function: M(x) = R_A·x for 0 ≤ x ≤ 2000 mm, and M(x) = R_A·x - P·(x - 2000) for 2000 mm ≤ x ≤ 3000 mm.

For the auxiliary system, apply a unit point force (1 N) downward at x = 2000 mm on the same simply supported beam.
Compute the auxiliary bending moment diagram m(x) using the same procedure.
The auxiliary reaction at x = 0 is r_A = 1·(1000)/3000 = 1/3 N upward.
The auxiliary reaction at x = 3000 mm is r_B = 1·2000/3000 = 2/3 N upward.
Express m(x) as a piecewise linear function: m(x) = (1/3)·x for 0 ≤ x ≤ 2000 mm, and m(x) = (1/3)·x - 1·(x - 2000) for 2000 mm ≤ x ≤ 3000 mm.

Compute the deflection at x = 2000 mm using the unit-load integral:
δ = ∫[0 to L] M(x)·m(x) / (E·I) dx.

Split the integral into two segments: segment 1 from x = 0 to x = 2000 mm, and segment 2 from x = 2000 mm to x = 3000 mm.

For segment 1, M(x) = (266.667)·x and m(x) = (1/3)·x, so M(x)·m(x) = (266.667/3)·x^2 = 88.889·x^2.
Integrate 88.889·x^2 from 0 to 2000: result = 88.889·(2000^3)/3 = 88.889·(8·10^9)/3 = 2.3704·10^11 N^2·mm^3.

For segment 2, M(x) = 266.667·x - 800·(x - 2000) = -533.333·x + 1600000 and m(x) = (1/3)·x - (x - 2000) = -(2/3)·x + 2000.
Multiply: M(x)·m(x) = (-533.333·x + 1600000)·(-(2/3)·x + 2000).
Expand: M(x)·m(x) = (355.556)·x^2 - (1066666.667 + 1066666.667)·x·(1/2 terms) — perform the full polynomial expansion and integrate term by term from x = 2000 to x = 3000.
Expanded form: M(x)·m(x) = 355.556·x^2 - 2133333.333·x + 3200000000·(1/3 correction) — recompute carefully:
(-533.333·x)·(-(2/3)·x) = 355.556·x^2.
(-533.333·x)·(2000) = -1066666.667·x.
(1600000)·(-(2/3)·x) = -1066666.667·x.
(1600000)·(2000) = 3200000000.
So M(x)·m(x) = 355.556·x^2 - 2133333.333·x + 3200000000.
Integrate from 2000 to 3000: ∫(355.556·x^2 - 2133333.333·x + 3200000000) dx = [355.556·x^3/3 - 2133333.333·x^2/2 + 3200000000·x] evaluated from 2000 to 3000.
At x = 3000: 355.556·(2.7·10^10)/3 - 2133333.333·(9·10^6)/2 + 3200000000·3000 = 3.2·10^12 - 9.6·10^12 + 9.6·10^12 = 3.2·10^12.
At x = 2000: 355.556·(8·10^9)/3 - 2133333.333·(4·10^6)/2 + 3200000000·2000 = 9.4815·10^11 - 4.2667·10^12 + 6.4·10^12 = 3.1148·10^12.
Segment 2 integral = 3.2·10^12 - 3.1148·10^12 = 8.519·10^10 N^2·mm^3.

Sum both segments: total numerator integral = 2.3704·10^11 + 8.519·10^10 = 3.2222·10^11 N^2·mm^3.

Divide by E·I = 200000·1200000 = 2.4·10^11 N·mm^2.

δ = 3.2222·10^11 / 2.4·10^11 = 1.3426 mm downward.

Report the deflection at x = 2000 mm as δ ≈ 1.343 mm downward.
