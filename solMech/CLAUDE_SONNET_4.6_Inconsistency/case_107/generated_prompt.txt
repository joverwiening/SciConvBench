Use N, mm, and MPa as the unit system throughout.

The beam is simply supported with span L = 3000 mm.

Material and section properties are E = 200000 MPa and I = 3000000 mm^4, both constant along the span.

A point load P = 2000 N acts vertically downward at midspan (x = L/2 = 1500 mm).

The reaction at each support is R = P/2 = 1000 N.

Define M(x) piecewise as follows: for 0 <= x <= L/2, M(x) = R * x = (P/2) * x; for L/2 <= x <= L, M(x) = R * (L - x) = (P/2) * (L - x).

Compute the total strain energy U = integral from 0 to L of M(x)^2 / (2EI) dx using this piecewise definition.

Exploit symmetry: U = 2 * integral from 0 to L/2 of [(P/2 * x)^2 / (2EI)] dx.

Evaluate the integral: integral from 0 to L/2 of x^2 dx = (L/2)^3 / 3 = L^3 / 24.

Substitute to get U = 2 * (P^2/4) * (1/(2EI)) * (L^3/24) = P^2 * L^3 / (96EI).

Apply Castigliano's theorem: the vertical deflection at midspan is delta = dU/dP = 2 * P * L^3 / (96EI) = P * L^3 / (48EI).

Substitute numerical values: delta = (2000 * 3000^3) / (48 * 200000 * 3000000).

Compute numerator: 2000 * 27000000000 = 54000000000000 N·mm^3.

Compute denominator: 48 * 200000 * 3000000 = 28800000000000 N·mm^2.

Compute delta = 54000000000000 / 28800000000000 = 1.875 mm.

The vertical deflection at midspan is delta = 1.875 mm downward.
