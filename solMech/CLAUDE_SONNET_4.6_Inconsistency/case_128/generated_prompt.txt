Use N, mm, and MPa as the unit system throughout.

The cross section is rectangular with width b = 40 mm and height h = 120 mm.

Compute the full cross-sectional area: A = b × h = 40 × 120 = 4800 mm².

Compute the average normal stress: σ = P / A = 40000 / 4800 = 8.333 MPa (tension).

Compute the average shear stress: τ = V / A = 8000 / 4800 = 1.667 MPa.

Define the plane stress state at the point as: σ_x = 8.333 MPa, σ_y = 0 MPa, τ_xy = 1.667 MPa.

Compute the average normal stress term: (σ_x + σ_y) / 2 = (8.333 + 0) / 2 = 4.167 MPa.

Compute the half-difference term: (σ_x − σ_y) / 2 = (8.333 − 0) / 2 = 4.167 MPa.

Compute the radius R of the Mohr's circle: R = sqrt(((σ_x − σ_y) / 2)² + τ_xy²) = sqrt(4.167² + 1.667²) = sqrt(17.361 + 2.779) = sqrt(20.140) = 4.488 MPa.

Compute the maximum principal stress: σ_1 = (σ_x + σ_y) / 2 + R = 4.167 + 4.488 = 8.654 MPa.

Compute the minimum principal stress: σ_2 = (σ_x + σ_y) / 2 − R = 4.167 − 4.488 = −0.321 MPa.

Compute the maximum in-plane shear stress: τ_max = R = 4.488 MPa.
