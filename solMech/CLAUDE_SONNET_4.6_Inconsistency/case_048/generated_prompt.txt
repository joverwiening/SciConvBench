Use N, mm, and MPa as the unit system throughout.

The shaft is a hollow circular cylinder made of AISI 1020 steel.

Outer diameter do = 60 mm, so outer radius ro = 30 mm.

Inner diameter di = 48 mm, so inner radius ri = 24 mm.

Shaft length L = 800 mm.

Applied torque T = 450000 N·mm.

Shear modulus G = 76923.1 MPa.

Assume linear elastic behavior throughout.

Compute the polar moment of inertia using J = π(do⁴ − di⁴)/32.

Substitute values: J = π(60⁴ − 48⁴)/32.

Compute 60⁴ = 12960000 mm⁴ and 48⁴ = 5308416 mm⁴.

Compute do⁴ − di⁴ = 12960000 − 5308416 = 7651584 mm⁴.

Compute J = π × 7651584 / 32 = 750994.7 mm⁴ (approximately).

Compute the maximum shear stress using τ_max = T · ro / J.

Substitute values: τ_max = 450000 × 30 / 750994.7.

Report τ_max in MPa.

Compute the angle of twist using φ = T · L / (J · G).

Substitute values: φ = 450000 × 800 / (750994.7 × 76923.1).

Report φ in radians.

Do not use any thin-walled or shear-flow approximation.
