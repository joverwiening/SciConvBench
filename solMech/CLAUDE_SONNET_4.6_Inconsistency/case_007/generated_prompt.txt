Use N, mm, and MPa units throughout.

The beam is simply supported with span L = 1800 mm, with pin supports at x = 0 and x = 1800 mm.

Material and section properties: E = 200000 MPa, I = 3500000 mm^4, so EI = 7.0 × 10^11 N·mm^2.

Real loading: a single point load P = 2000 N acting downward at x = 900 mm (midspan).

Compute the real bending moment diagram M(x) for the simply supported beam under P = 2000 N at x = 900 mm.

Reaction at x = 0: R_A = P/2 = 1000 N upward.
Reaction at x = 1800: R_B = P/2 = 1000 N upward.

M(x) for 0 ≤ x ≤ 900: M(x) = 1000·x (N·mm).
M(x) for 900 ≤ x ≤ 1800: M(x) = 1000·x − 2000·(x − 900) = −1000·x + 1800000 (N·mm).

Auxiliary loading: a unit point load of 1 N acting downward at x = 900 mm on the same simply supported beam.

Reaction at x = 0: r_A = 0.5 N upward.
Reaction at x = 1800: r_B = 0.5 N upward.

m(x) for 0 ≤ x ≤ 900: m(x) = 0.5·x (mm, dimensionless unit consistent with unit load of 1 N).
m(x) for 900 ≤ x ≤ 1800: m(x) = 0.5·x − 1·(x − 900) = −0.5·x + 900 (mm).

Apply the virtual work integral: δ = ∫[0 to L] M(x)·m(x) / (EI) dx.

Split the integral into two segments by symmetry.

Segment 1, 0 ≤ x ≤ 900: integrand = (1000·x)·(0.5·x) = 500·x^2.
Integral over segment 1 = ∫[0 to 900] 500·x^2 dx = 500·[x^3/3] from 0 to 900 = 500·(900^3/3) = 500·(729000000/3) = 500·243000000 = 1.215 × 10^11 N·mm^3.

By symmetry of both M(x) and m(x) about x = 900, segment 2 gives the same value: 1.215 × 10^11 N·mm^3.

Total integral = 2 × 1.215 × 10^11 = 2.43 × 10^11 N·mm^3.

Compute deflection: δ = 2.43 × 10^11 / (7.0 × 10^11) = 0.3471 mm.

The deflection at x = 900 mm is δ = 2.43 × 10^11 / (7.0 × 10^11) ≈ 0.347 mm downward.

Verification using the standard midspan deflection formula for a central point load: δ = PL^3 / (48·EI) = 2000·(1800^3) / (48·7.0×10^11) = 2000·5.832×10^9 / (3.36×10^13) = 1.1664×10^13 / 3.36×10^13 ≈ 0.347 mm. The virtual work result matches the closed-form formula exactly.
