Use N, mm, and MPa as the unit system throughout.

The beam is simply supported with span L = 3000 mm.
The material is structural steel with elastic modulus E = 200000 MPa.
The second moment of area is constant at I = 1500000 mm^4.
A single point load P = 2000 N acts vertically downward at midspan (x = L/2 = 1500 mm).

Define the x-coordinate from the left support to the right support.
The left reaction is R_A = P/2 = 1000 N upward.
The right reaction is R_B = P/2 = 1000 N upward.

Define M(x) piecewise as follows.
For 0 <= x <= L/2: M(x) = R_A * x = (P/2) * x.
For L/2 <= x <= L: M(x) = R_A * x - P * (x - L/2) = (P/2) * (L - x).

Compute the total strain energy using U = integral from 0 to L of M(x)^2 / (2EI) dx.
Split the integral into two segments: 0 to L/2 and L/2 to L.
Use symmetry to write U = 2 * integral from 0 to L/2 of [(P/2 * x)^2 / (2EI)] dx.
Evaluate the integral: U = 2 * (P^2 / (4 * 2EI)) * integral from 0 to L/2 of x^2 dx.
The integral of x^2 from 0 to L/2 equals (L/2)^3 / 3 = L^3 / 24.
Substitute to obtain U = (P^2 * L^3) / (96 * E * I).

Apply Castigliano's theorem: the vertical deflection at midspan equals delta = dU/dP.
Differentiate: delta = (2 * P * L^3) / (96 * E * I) = (P * L^3) / (48 * E * I).

Substitute numerical values: P = 2000 N, L = 3000 mm, E = 200000 MPa, I = 1500000 mm^4.
Compute L^3 = 3000^3 = 2.7 x 10^10 mm^3.
Compute 48 * E * I = 48 * 200000 * 1500000 = 1.44 x 10^13 N*mm^2.
Compute delta = (2000 * 2.7 x 10^10) / (1.44 x 10^13) = 5.4 x 10^13 / 1.44 x 10^13.
The vertical deflection at midspan is delta = 3.75 mm downward.
