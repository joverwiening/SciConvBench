Use N, mm, and MPa as the unit system throughout.

The shaft is solid and circular with diameter d = 35 mm and length L = 1000 mm.

The material is AISI 1020 steel with shear modulus G = 76923.1 MPa.

The input power is P = 10 kW = 10,000 W = 10,000 N·m/s = 10,000,000 N·mm/s.

The rotational speed is n = 1800 rpm.

Convert rotational speed to rad/s using ω = 2π(n/60) = 2π(1800/60) = 60π rad/s.

Part (a): Compute the transmitted torque T using T = P/ω.
Substitute P = 10,000,000 N·mm/s and ω = 60π rad/s.
T = 10,000,000 / (60π) N·mm.
Evaluate to give T ≈ 53,051.6 N·mm.

Part (b): Compute the maximum shear stress using torsion theory.
The polar moment of inertia for a solid circular shaft is J = π·d⁴/32.
Substitute d = 35 mm to get J = π(35)⁴/32.
Evaluate J ≈ 147,323.5 mm⁴.
The maximum shear stress occurs at the outer surface: τ_max = T·c/J, where c = d/2 = 17.5 mm.
Substitute T ≈ 53,051.6 N·mm, c = 17.5 mm, and J ≈ 147,323.5 mm⁴.
Evaluate τ_max ≈ 6.30 MPa.

Part (c): Compute the angle of twist over length L.
Use the formula φ = T·L / (G·J).
Substitute T ≈ 53,051.6 N·mm, L = 1000 mm, G = 76923.1 MPa, and J ≈ 147,323.5 mm⁴.
Evaluate φ = 53,051.6 × 1000 / (76923.1 × 147,323.5).
Evaluate φ ≈ 0.004681 radians.
Convert to degrees if needed: φ ≈ 0.2682°.
