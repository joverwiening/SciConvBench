Use N, mm, and MPa as the unit system throughout.

Model the beam as a simply supported Euler-Bernoulli beam; neglect shear deformation entirely.

The beam span is L = 3000 mm.

The material is 6061-T6 aluminum with elastic modulus E = 69000 MPa.

The second moment of area is constant at I = 3500000 mm^4.

Compute EI = 69000 × 3500000 = 241500000000 N·mm².

A single point load P = 4000 N acts vertically downward at midspan, x = L/2 = 1500 mm.

Apply the boundary conditions: deflection v = 0 at x = 0, deflection v = 0 at x = L, and slope dv/dx = 0 at x = L/2 by symmetry.

By symmetry each support reaction is R = P/2 = 2000 N upward.

Use the governing equation EI v''(x) = M(x) for the left half 0 ≤ x ≤ L/2.

Write the bending moment in the left half as M(x) = R·x = 2000·x N·mm.

Integrate once to get EI v'(x) = 1000·x² + C1.

Apply the symmetry condition v'(L/2) = 0 at x = 1500 mm to find C1 = -1000·(1500)² = -2250000000 N·mm².

Integrate again to get EI v(x) = (1000/3)·x³ + C1·x + C2.

Apply the boundary condition v(0) = 0 to find C2 = 0.

The deflection in the left half is v(x) = [1000·x³/3 − 2250000000·x] / 241500000000.

Compute the maximum deflection at x = 1500 mm.

Numerator at x = 1500: (1000/3)·(1500)³ − 2250000000·1500 = 1125000000000 − 3375000000000 = −2250000000000 N·mm³.

Maximum deflection magnitude: |v(1500)| = 2250000000000 / 241500000000 = 9.317 mm downward.

Alternatively confirm using the standard formula δ_max = PL³ / (48EI) = 4000·(3000)³ / (48·241500000000) = 108000000000000 / 11592000000000 = 9.317 mm.

Compute the slope at the left support by evaluating v'(0).

EI v'(0) = C1 = −2250000000 N·mm².

Slope at x = 0: θ = −2250000000 / 241500000000 = −0.009317 radians.

The magnitude of the slope at each support is 0.009317 radians (the negative sign indicates the beam slopes downward to the right at the left support; by symmetry the right support has equal and opposite slope).

Alternatively confirm using the standard formula θ_support = PL² / (16EI) = 4000·(3000)² / (16·241500000000) = 36000000000 / 3864000000000 = 0.009317 radians.

Result (i): maximum deflection at midspan = 9.317 mm downward.

Result (ii): slope magnitude at each support = 0.009317 radians.
