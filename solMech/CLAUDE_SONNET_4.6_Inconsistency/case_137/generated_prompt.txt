Use N, mm, and MPa as the unit system throughout (forces in N, lengths in mm, stresses in MPa).

The shaft is solid and circular with diameter d = 45 mm.

The critical section carries a bending moment M = 2,000,000 N·mm and a torque T = 500,000 N·mm applied simultaneously.

Part (a): Compute the second moment of area I = π · d^4 / 64 using d = 45 mm.

Compute the outer fiber distance c = d / 2 = 22.5 mm.

Compute the maximum bending normal stress as σ = M · c / I, expressing the result in MPa.

Part (b): Compute the polar moment of area J = π · d^4 / 32 using d = 45 mm.

Compute the torsional shear stress as τ = T · c / J using the same c = 22.5 mm, expressing the result in MPa.

Part (c): Model the stress state at the outer surface as plane stress with σx = σ (the bending normal stress from part a), σy = 0, and τxy = τ (the torsional shear stress from part b).

Compute the two principal stresses using σ1,2 = (σx + σy) / 2 ± sqrt(((σx − σy) / 2)^2 + τxy^2).

Compute the maximum in-plane shear stress as τmax = sqrt(((σx − σy) / 2)^2 + τxy^2).

Express all final stress results in MPa, rounded to two decimal places.
