Use N, mm, and MPa as the unit system throughout.

The beam is simply supported with span L = 2400 mm, with pin/roller supports at x = 0 and x = 2400 mm.

Material and section properties are E = 200000 MPa and I = 3500000 mm^4, giving EI = 200000 × 3500000 = 700000000000 N·mm^2.

The real loading is a single point load P = 1200 N acting downward at x = 1200 mm (midspan).

Compute the real bending moment diagram M(x) using static equilibrium.
The reactions are R_A = R_B = 600 N (upward) by symmetry.
For 0 ≤ x ≤ 1200 mm: M(x) = 600·x.
For 1200 mm ≤ x ≤ 2400 mm: M(x) = 600·x − 1200·(x − 1200) = 600·(2400 − x).

The auxiliary system is the same simply supported beam with a unit downward point load (1 N) applied at x = 1200 mm.
The auxiliary reactions are r_A = r_B = 0.5 N (upward) by symmetry.
For 0 ≤ x ≤ 1200 mm: m(x) = 0.5·x.
For 1200 mm ≤ x ≤ 2400 mm: m(x) = 0.5·(2400 − x).

Compute the deflection using the virtual work integral:
δ = ∫[0 to L] M(x)·m(x) / (EI) dx.

Split the integral into two equal halves and use symmetry.
For 0 ≤ x ≤ 1200 mm: M(x)·m(x) = 600·x · 0.5·x = 300·x^2.
By symmetry the contribution from 1200 mm ≤ x ≤ 2400 mm is identical.

Evaluate ∫[0 to 1200] 300·x^2 dx = 300 · [x^3/3] from 0 to 1200 = 100 · (1200)^3 = 100 · 1728000000 = 172800000000 N·mm^3.

The total integral over the full span is 2 × 172800000000 = 345600000000 N·mm^3.

Divide by EI: δ = 345600000000 / 700000000000 = 0.4937 mm (rounded to four significant figures).

The deflection at x = 1200 mm is δ ≈ 0.4937 mm downward.

Verify against the closed-form midspan deflection formula for a central point load: δ = PL^3/(48EI) = 1200·(2400)^3/(48·700000000000) = 1200·13824000000000/33600000000000 = 16588800000000000/33600000000000 ≈ 0.4937 mm, confirming the result.
