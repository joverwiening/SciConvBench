Use N, mm, and MPa as the unit system throughout.

The beam is simply supported with span L = 2500 mm.

The material is AISI 1020 steel with elastic modulus E = 200000 MPa.

The second moment of area is constant at I = 3500000 mm^4.

The flexural rigidity is EI = 200000 × 3500000 = 700000000000 N·mm^2 (7.0 × 10^11 N·mm^2).

A single point load P = 2500 N acts vertically downward at midspan (x = 1250 mm).

Apply Euler–Bernoulli beam theory and neglect shear deformation entirely.

The boundary conditions are: deflection v = 0 at x = 0, deflection v = 0 at x = L = 2500 mm, and slope dv/dx = 0 at x = L/2 = 1250 mm by symmetry.

By symmetry, each support reaction is R = P/2 = 1250 N upward.

For the left half of the beam (0 ≤ x ≤ L/2), the bending moment is M(x) = R·x = 1250·x N·mm.

Integrate EI·v'' = M(x) = 1250·x once to obtain EI·v' = 625·x^2 + C1.

Apply the symmetry condition v' = 0 at x = 1250 mm to find C1 = −625·(1250)^2 = −976562500 N·mm^2.

So EI·v' = 625·x^2 − 976562500.

Integrate again to obtain EI·v = (625/3)·x^3 − 976562500·x + C2.

Apply the boundary condition v = 0 at x = 0 to find C2 = 0.

The deflection in the left half is v(x) = (1 / EI)·[(625/3)·x^3 − 976562500·x].

Compute the maximum deflection at midspan x = 1250 mm.

EI·v(1250) = (625/3)·(1250)^3 − 976562500·(1250).

(1250)^3 = 1953125000.

(625/3)·1953125000 = 625 × 651041666.67 = 406901041666.67 N·mm^3.

976562500 × 1250 = 1220703125000 N·mm^3.

EI·v(1250) = 406901041666.67 − 1220703125000 = −813802083333.33 N·mm^3.

v_max = |−813802083333.33 / 700000000000| = 1.1626 mm downward.

This matches the standard formula v_max = PL^3 / (48·EI) = 2500·(2500)^3 / (48 × 7.0 × 10^11).

PL^3 = 2500 × 15625000000000 = 39062500000000000 N·mm^3.

48·EI = 48 × 700000000000 = 33600000000000 N·mm^2.

v_max = 39062500000000000 / 33600000000000 = 1.1626 mm downward.

Compute the slope at the left support x = 0.

EI·v'(0) = 625·(0)^2 − 976562500 = −976562500 N·mm^2.

v'(0) = −976562500 / 700000000000 = −0.001395 rad.

The magnitude of the slope at each support is 0.001395 rad (the left support has a negative slope and the right support has an equal and opposite positive slope by symmetry).

This matches the standard formula θ = PL^2 / (16·EI) = 2500·(2500)^2 / (16 × 7.0 × 10^11).

PL^2 = 2500 × 6250000 = 15625000000 N·mm^2.

16·EI = 16 × 700000000000 = 11200000000000 N·mm^2.

θ = 15625000000 / 11200000000000 = 0.001395 rad.

Result (i): maximum deflection at midspan = 1.1626 mm downward.

Result (ii): slope magnitude at each support = 0.001395 rad (0.07994 degrees), with the left support sloping downward to the right and the right support sloping upward to the right.
