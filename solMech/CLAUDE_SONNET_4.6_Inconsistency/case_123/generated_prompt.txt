Use N, mm, and MPa as the unit system throughout.
The shaft is a solid circular cross section made of brass.
The shaft diameter is d = 30 mm.
The shaft length is L = 1200 mm.
The applied torque is T = 400000 N·mm.
The shear modulus is G = 39179.1 MPa.
Compute the polar second moment of area using J = π d^4 / 32.
Compute the radial distance to the outer fiber using c = d / 2 = 15 mm.
Compute the maximum shear stress using τ_max = T c / J.
Compute the angle of twist using φ = T L / (J G).
Convert the angle of twist from radians to degrees by multiplying by 180 / π.
Report τ_max in MPa and φ in degrees.
The shaft is assumed to be linearly elastic for all calculations.
