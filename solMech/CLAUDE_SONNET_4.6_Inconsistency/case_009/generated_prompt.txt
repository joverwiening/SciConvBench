Use N, mm, and MPa as the unit system throughout.

The system consists of two prismatic bars of equal length L = 400 mm mounted in parallel between two rigid plates.

Bar 1 is AISI 1020 steel with cross-sectional area A1 = 300 mm^2 and elastic modulus E1 = 200000 MPa.

Bar 2 is cast iron with cross-sectional area A2 = 250 mm^2 and elastic modulus E2 = 110000 MPa.

A total tensile load P = 20000 N is applied to the rigid plates and shared by the two bars.

Apply the compatibility condition: both bars undergo the same elongation delta, because they are perfectly bonded to rigid plates spanning the same distance L.

Compute the axial stiffness of each bar as k = AE/L.

k1 = (300 * 200000) / 400 = 150000 N/mm.

k2 = (250 * 110000) / 400 = 68750 N/mm.

Distribute the total load in proportion to stiffness: F1 = P * k1 / (k1 + k2) and F2 = P * k2 / (k1 + k2).

F1 = 20000 * 150000 / (150000 + 68750).

F2 = 20000 * 68750 / (150000 + 68750).

Compute the stress in each bar as sigma = F / A.

sigma1 = F1 / 300 in MPa.

sigma2 = F2 / 250 in MPa.

Compute the common elongation as delta = F1 / k1 (or equivalently F2 / k2; both must give the same result, which serves as a check).

Report F1 and F2 in N, sigma1 and sigma2 in MPa, and delta in mm.

Verify equilibrium: F1 + F2 must equal 20000 N.

Verify compatibility: elongation computed from bar 1 must equal elongation computed from bar 2.
