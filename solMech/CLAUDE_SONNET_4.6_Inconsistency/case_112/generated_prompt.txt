Use N, mm, and MPa as the unit system throughout.

Assume linear elastic material behavior.

The shaft is a hollow circular cylinder made of structural steel.

The outer diameter is do = 60 mm and the inner diameter is di = 44 mm, giving a wall thickness of t = (60 - 44) / 2 = 8 mm.

The shaft length is L = 1200 mm.

The applied torque is T = 600000 N·mm, constant along the entire length.

The shear modulus is G = 77519.4 MPa.

Compute the polar moment of inertia using the exact hollow-circle formula: J = π (do^4 - di^4) / 32.

Substitute do = 60 mm and di = 44 mm: J = π (60^4 - 44^4) / 32.

Compute 60^4 = 12960000 mm^4 and 44^4 = 3748096 mm^4.

Compute do^4 - di^4 = 12960000 - 3748096 = 9211904 mm^4.

Compute J = π × 9211904 / 32 = 904070.3 mm^4 (retain at least one decimal place).

Compute the maximum shear stress at the outer surface using the standard torsion formula: τ_max = T × (do / 2) / J.

Substitute T = 600000 N·mm, do/2 = 30 mm, J = 904070.3 mm^4.

Compute τ_max = 600000 × 30 / 904070.3 = 19.91 MPa.

Also compute the thin-walled shear-flow result for comparison as instructed.

Define the mean diameter as d_m = (do + di) / 2 = (60 + 44) / 2 = 52 mm.

Define the mean radius as r_m = d_m / 2 = 26 mm.

Compute the mean enclosed area: A_m = π × r_m^2 = π × 26^2 = π × 676 = 2123.72 mm^2.

Compute the shear flow: q = T / (2 × A_m) = 600000 / (2 × 2123.72) = 141.27 N/mm.

Compute the thin-walled shear stress: τ_thin = q / t = 141.27 / 8 = 17.66 MPa.

Note that the thin-walled result (17.66 MPa) differs from the exact result (19.91 MPa) because the wall thickness t = 8 mm is not negligible relative to the mean radius r_m = 26 mm (t / r_m ≈ 0.31), so the thin-walled approximation introduces noticeable error here.

Report the exact value τ_max = 19.91 MPa as the primary answer for maximum shear stress.

Compute the angle of twist using the exact formula: φ = T × L / (G × J).

Substitute T = 600000 N·mm, L = 1200 mm, G = 77519.4 MPa, J = 904070.3 mm^4.

Compute G × J = 77519.4 × 904070.3 = 70073.0 × 10^6 N·mm^2 (i.e., 7.00730 × 10^10 N·mm^2).

Compute φ = (600000 × 1200) / (7.00730 × 10^10) = 7.20 × 10^8 / 7.00730 × 10^10 = 0.010275 radians.

Convert to degrees: φ = 0.010275 × (180 / π) = 0.5887 degrees.

Report the final answers as:
Maximum shear stress (exact): τ_max = 19.91 MPa.
Thin-walled shear stress (approximate): τ_thin = 17.66 MPa.
Angle of twist: φ = 0.010275 rad = 0.589 degrees.
