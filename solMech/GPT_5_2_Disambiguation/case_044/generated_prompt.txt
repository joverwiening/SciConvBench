Assume small-deformation, linear-elastic, homogeneous, isotropic material behavior.
Use 6061-T6 properties: Young’s modulus E = 69,000 MPa and Poisson’s ratio ν = 0.33.
Model the rod as a straight prismatic circular bar with original diameter d0 = 40 mm and original gauge length L0 = 500 mm.
Apply a concentric axial tensile force P = 35,000 N through the centroid.
Assume no lateral load is applied.
Assume end effects are negligible and the stress/strain state is uniform over the gauge length (Saint-Venant).
Assume the rod remains in the elastic range.

Compute cross-sectional area as A = (π/4) d0^2.
Compute axial (engineering) normal stress as σx = P/A.
Use uniaxial linear elasticity (plane stress with σy = σz = 0) so axial strain is εx = σx/E.
Compute axial elongation over the gauge length as ΔL = εx L0.
Use Poisson effect to compute lateral strains as εy = εz = −ν εx.
Relate lateral strain to diameter change as Δd = εy d0.
Compute the deformed diameter as d = d0 + Δd.
Optionally report volumetric strain under uniaxial stress as εv = εx + εy + εz = εx(1 − 2ν).

For the given numbers:
A = (π/4)(40 mm)^2 = 1256.64 mm^2.
σx = 35,000 N / 1256.64 mm^2 = 27.85 MPa.
εx = 27.85 MPa / 69,000 MPa = 4.036×10^-4.
ΔL = (4.036×10^-4)(500 mm) = 0.2018 mm.
εy = εz = −0.33(4.036×10^-4) = −1.332×10^-4.
Δd = (−1.332×10^-4)(40 mm) = −0.00533 mm.
d = 40.000 mm − 0.00533 mm = 39.9947 mm.
εv = (4.036×10^-4)(1 − 2·0.33) = 1.372×10^-4.
