Assume a straight, prismatic, isotropic, linear-elastic rod with small strains and small deformations.
Use a circular cross-section with initial diameter d0 = 30 mm.
Use original (gauge) length L0 = 500 mm.
Apply only a concentric axial tensile force P = 25,000 N through the centroid.
Assume no transverse (lateral) load, no bending, no shear, and no torsion.
Assume Saint-Venant/uniform uniaxial stress away from the loaded ends.
Use Young’s modulus E = 105,000 MPa and Poisson’s ratio ν = 0.34.
Compute cross-sectional area A = (π/4) d0^2.
Compute axial (engineering) normal stress σx = P/A.
Compute axial strain εx = σx/E.
Compute axial elongation ΔL = εx L0.
Use uniaxial stress condition σy = 0 and σz = 0.
Compute lateral strains from Poisson effect: εy = −ν εx and εz = −ν εx.
Relate lateral strain to diameter change: εd = Δd/d0 = εy (equivalently εz), so Δd = εy d0.
Report final diameter d = d0 + Δd.
Optionally report volumetric strain under uniaxial stress: εv = εx + εy + εz = εx(1 − 2ν).
Numerical results using the given data:
A = (π/4)(30 mm)^2 = 706.858 mm^2.
σx = 25,000 N / 706.858 mm^2 = 35.368 MPa.
εx = 35.368 / 105,000 = 3.368×10^-4.
ΔL = (3.368×10^-4)(500 mm) = 0.1684 mm.
εy = εz = −0.34(3.368×10^-4) = −1.145×10^-4.
Δd = (−1.145×10^-4)(30 mm) = −0.00344 mm.
d = 30.000 mm − 0.00344 mm = 29.9966 mm.
