Assume a straight prismatic bar in the sense of 1D axial deformation, with linearly varying cross-sectional area A(x).
Assume small deformation, linear elastic, homogeneous and isotropic material with constant Young’s modulus E.
Assume quasi-static loading, no body forces, no temperature effects, and no bending (load is concentric so stress is uniform over each cross-section).
Use x measured from the left end, with 0 ≤ x ≤ L.
Use the given area variation A(x) = A0(1 + k x/L), with A0 = 250 mm^2, k = 0.8, L = 800 mm.
Use the given constant tensile end force P = 30,000 N, implying internal axial force N(x) = P for 0 ≤ x ≤ L.
Use the given Young’s modulus E = 200,000 N/mm^2.

Define axial stress as σ(x) = N(x)/A(x) = P / (A0(1 + k x/L)).
Define axial strain as ε(x) = σ(x)/E = P / (E A0(1 + k x/L)).
Relate strain to displacement by ε(x) = du/dx.

Compute axial displacement field (taking u(0)=0 as the reference boundary condition) as
u(x) = ∫0^x [P/(E A(ξ))] dξ
u(x) = (P L)/(E A0 k) ln(1 + k x/L).

Compute total elongation as
δ = u(L) = (P L)/(E A0 k) ln(1 + k).

For the provided values (consistent N and mm units),
δ = (30,000·800)/(200,000·250·0.8) ln(1.8) mm
δ ≈ 0.441 mm.

Compute stress at the ends as
σ(0) = P/A0 = 30,000/250 = 120 MPa.
σ(L) = P/A(L) = 30,000/450 ≈ 66.67 MPa.

Compute strain at the ends as
ε(0) = σ(0)/E = 120/200,000 = 6.0×10^-4.
ε(L) = σ(L)/E = 66.67/200,000 ≈ 3.33×10^-4.

State the governing differential relation equivalently as
du/dx = P/(E A0(1 + k x/L)),
with u(0)=0 and δ = u(L).
