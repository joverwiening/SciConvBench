Assume small-deformation, linear-elastic behavior and Euler elastic buckling governs.
Model the member as a straight, prismatic, solid circular column with diameter d = 30 mm and length L = 1500 mm.
Use Young’s modulus E = 200,000 MPa (N/mm^2).
Use effective length factor K = 2.0 (fixed–free cantilever condition).
Neglect initial imperfections, residual stresses, eccentricity, and inelastic buckling effects.
Compute the second moment of area for a solid circular cross-section as I = (π/64) d^4.
Compute the Euler critical buckling load as P_cr = (π^2 E I) / (K L)^2.
Use factor of safety n = 2.0 for allowable load in buckling.
Compute allowable axial compressive load against buckling as P_allow = P_cr / n.
Because the applied axial load P is not specified, report the buckling factor of safety symbolically as n_buckling = P_cr / P.
Numerically evaluate I = (π/64)(30 mm)^4 = 39,760.78 mm^4.
Numerically evaluate P_cr = (π^2 (200,000 N/mm^2)(39,760.78 mm^4)) / (2·1500 mm)^2 = 8,726.65 N (≈ 8.73 kN).
Numerically evaluate P_allow = 8,726.65 N / 2.0 = 4,363.33 N (≈ 4.36 kN).
