Use small-deformation, linear-elastic Euler–Bernoulli beam theory with constant EI.
Model a simply supported beam of span L = 2500 mm with supports at x = 0 and x = L.
Apply a single concentrated load P = 2500 N downward at midspan x = L/2.
Assume no additional distributed transverse load; the only shear force distribution is that induced by P.
Use the sign convention: positive bending moment is sagging, positive curvature satisfies v''(x) = M(x)/EI, and downward deflection v is taken as positive.
Use reactions for a symmetric midspan point load: R_A = R_B = P/2.
Use internal bending moment:
For 0 ≤ x ≤ L/2: M(x) = (P/2) x.
For L/2 ≤ x ≤ L: M(x) = (P/2)(L − x).
Use the governing relation EI v''(x) = M(x), integrate piecewise to obtain slope θ(x) = v'(x) and deflection v(x), and enforce boundary/continuity conditions v(0)=0, v(L)=0, and continuity of v and θ at x = L/2.
Report midspan deflection (downward) for a simply supported beam with a central point load:
v(L/2) = P L^3 / (48 EI).
Report support rotations (slopes) with symmetry:
θ(0) = + P L^2 / (16 EI).
θ(L) = − P L^2 / (16 EI).
Use EI = 7.0×10^11 N·mm^2 to compute numerical values:
v(L/2) = (2500)(2500^3) / (48·7.0×10^11) = 1.162 mm (downward).
θ(0) = +(2500)(2500^2) / (16·7.0×10^11) = +0.001395 rad.
θ(L) = −0.001395 rad.
