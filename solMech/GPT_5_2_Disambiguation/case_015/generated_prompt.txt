Model the member as an Euler–Bernoulli cantilever beam with fixed end at x = 0 and free end at x = L.
Use small-deformation, linear-elastic behavior with constant flexural rigidity EI along the span.
Neglect shear deformation and rotary inertia.
Take x measured from the fixed end toward the free end.
Given L = 1200 mm.
Given EI = 4.0×10^11 N·mm^2.
Apply a concentrated transverse load P = 2000 N downward at the free end x = L.
Apply no end moment at the free end, so M_applied(L) = 0 N·mm.
Adopt the sign convention that downward transverse load produces negative deflection v(x) (downward) and negative bending moment (hogging) for this cantilever.

Define the relevant response quantities as internal shear force V(x), internal bending moment M(x), rotation (slope) θ(x) = dv/dx, and transverse deflection v(x).
Use the Euler–Bernoulli moment–curvature relation EI d^2v/dx^2 = M(x).
Use the equilibrium relations dV/dx = 0 for 0 < x < L and dM/dx = V(x) for 0 < x < L, with the point load applied at x = L.

For 0 ≤ x ≤ L, the internal shear force is V(x) = −P.
For 0 ≤ x ≤ L, the internal bending moment is M(x) = −P (L − x).
For 0 ≤ x ≤ L, the curvature is d^2v/dx^2 = M(x)/EI = −P (L − x)/EI.
Apply cantilever boundary conditions at the fixed end: v(0) = 0 and θ(0) = 0.

For 0 ≤ x ≤ L, the rotation is θ(x) = dv/dx = −(P/EI) (L x − x^2/2).
For 0 ≤ x ≤ L, the deflection is v(x) = −(P/EI) (L x^2/2 − x^3/6).

The free-end rotation is θ(L) = −P L^2/(2 EI).
The free-end deflection magnitude is δ = |v(L)| = P L^3/(3 EI), with v(L) = −P L^3/(3 EI) under the stated sign convention.

With the given values, θ(L) = −(2000)(1200^2)/(2·4.0×10^11) = −0.0036 rad.
With the given values, v(L) = −(2000)(1200^3)/(3·4.0×10^11) = −2.88 mm.

The maximum bending moment magnitude occurs at the fixed end and equals |M(0)| = P L = 2.4×10^6 N·mm.
The shear force magnitude is constant along the span and equals |V| = P = 2000 N.
