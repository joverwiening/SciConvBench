Assume small-deformation, linear-elastic behavior.
Assume a straight, prismatic, solid circular column with constant diameter d.
Assume concentric axial compressive load P with no eccentricity and no initial imperfection.
Assume Euler elastic buckling governs.
Use unsupported length L = 2200 mm.
Use effective length factor K = 2.0 (fixed–free cantilever).
Use axial compressive load P = 25,000 N.
Use Young’s modulus E = 69,000 MPa.
Use target buckling factor of safety n = 2.5, meaning require Pcr ≥ nP.

Define the effective buckling length Le = K L.
Compute Le = 2.0 × 2200 mm = 4400 mm.

Use Euler critical load Pcr = (π^2 E I) / (Le^2).
For a solid circular cross-section, use second moment of area I = (π d^4) / 64.

Design requirement: (π^2 E (π d^4 / 64)) / (Le^2) ≥ n P.
Solve for diameter: d ≥ [ (64 n P Le^2) / (π^3 E) ]^(1/4).

With E = 69,000 N/mm^2, P = 25,000 N, n = 2.5, Le = 4400 mm, compute d ≥ 53.8 mm.
Select a practical design diameter d = 54 mm (or larger).

For any chosen diameter d, evaluate the buckling factor of safety as FoS = Pcr / P.
With d = 54 mm, compute I = (π 54^4)/64 = 4.17×10^5 mm^4.
With d = 54 mm, compute Pcr = (π^2 × 69,000 × 4.17×10^5) / (4400^2) = 1.46×10^5 N.
With d = 54 mm, compute FoS = 1.46×10^5 / 25,000 = 5.83.

Report relevant response quantities as Le, I, Pcr, and FoS, and the minimum required diameter dmin from the design inequality.
