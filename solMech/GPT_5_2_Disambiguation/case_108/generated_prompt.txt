Use the coordinate x measured from the left support, with 0 ≤ x ≤ L.

Use the given uniformly distributed transverse load w = 0.5 N/mm acting downward over the full span.
Use the given material and section properties E = 200000 N/mm² and I = 1,500,000 mm⁴, so EI = 3.0×10^11 N·mm².
Compute support reactions for a simply supported beam under full-span UDL as R_A = R_B = wL/2.
Use the shear-force relation V(x) = R_A − wx.
Use the bending-moment relation M(x) = R_A x − (w x^2)/2.
Use the Euler–Bernoulli moment-curvature relation EI v''(x) = M(x), where v(x) is the transverse deflection (positive in the chosen sign convention).
Integrate EI v''(x) = M(x) twice to obtain slope θ(x) = v'(x) and deflection v(x).
Apply the simply supported deflection boundary conditions v(0) = 0 and v(L) = 0 to determine the integration constants.
