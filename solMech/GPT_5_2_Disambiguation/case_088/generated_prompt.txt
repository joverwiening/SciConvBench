Assume small deformation, linear-elastic, homogeneous, isotropic material behavior.
Assume the bar is axially loaded in tension by a static force P = 35,000 N applied at the right end, with the left end fixed.
Assume each segment is prismatic with constant circular cross-section and perfectly bonded at the step so axial force is transmitted without slip.
Assume stress is uniform over each cross-section (Saint-Venant), neglect stress concentration at the diameter change for segment-average stress and elongation.
Use Young’s modulus E = 200 GPa = 200,000 MPa.
Use consistent units; here use N and mm so E = 200,000 N/mm^2 and P = 35,000 N.

Compute cross-sectional areas.
A1 = (π/4) d1^2 = (π/4)(12 mm)^2 = 113.097 mm^2.
A2 = (π/4) d2^2 = (π/4)(30 mm)^2 = 706.858 mm^2.

Axial force in each segment.
N1 = N2 = P = 35,000 N.

Average normal stress in each segment.
σ1 = N1/A1 = 35,000 / 113.097 = 309.27 N/mm^2 = 309.27 MPa (tension).
σ2 = N2/A2 = 35,000 / 706.858 = 49.51 N/mm^2 = 49.51 MPa (tension).

Axial strain in each segment (Hooke’s law).
ε1 = σ1/E = 309.27 / 200,000 = 0.001546.
ε2 = σ2/E = 49.51 / 200,000 = 0.0002476.

Elongation of each segment.
δ1 = ε1 L1 = (P L1)/(A1 E) = (35,000·300)/(113.097·200,000) = 0.464 mm.
δ2 = ε2 L2 = (P L2)/(A2 E) = (35,000·800)/(706.858·200,000) = 0.198 mm.

Total elongation.
δtotal = δ1 + δ2 = 0.464 mm + 0.198 mm = 0.662 mm.
