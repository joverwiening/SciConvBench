Assume small deformation, linear-elastic, homogeneous, isotropic material behavior with Young’s modulus E = 200 GPa.
Assume uniaxial axial loading with the same internal axial force P throughout both segments (no intermediate axial loads).
Assume each segment has a constant circular cross-section with diameters d1 = 16 mm and d2 = 40 mm.
Assume stress is uniformly distributed over each cross-section (Saint-Venant; neglect stress concentrations at the step).
Use applied tensile load P = 35,000 N, left end fixed, right end pulled in tension.

Compute cross-sectional areas as A1 = (π/4)d1^2 and A2 = (π/4)d2^2.
A1 = (π/4)(16 mm)^2 = 201.06 mm^2 = 2.0106×10^-4 m^2.
A2 = (π/4)(40 mm)^2 = 1256.64 mm^2 = 1.2566×10^-3 m^2.

Compute average normal stress in each segment as σi = P/Ai.
σ1 = 35,000 N / (2.0106×10^-4 m^2) = 1.740×10^8 Pa = 174 MPa (tension).
σ2 = 35,000 N / (1.2566×10^-3 m^2) = 2.785×10^7 Pa = 27.9 MPa (tension).

Compute axial strain in each segment as εi = σi/E.
ε1 = (174 MPa)/(200,000 MPa) = 8.70×10^-4.
ε2 = (27.9 MPa)/(200,000 MPa) = 1.39×10^-4.

Compute elongation of each segment as δi = (P Li)/(Ai E) = εi Li.
Use L1 = 400 mm = 0.4 m and L2 = 800 mm = 0.8 m.
δ1 = (35,000×0.4)/(2.0106×10^-4×200×10^9) = 3.48×10^-4 m = 0.348 mm.
δ2 = (35,000×0.8)/(1.2566×10^-3×200×10^9) = 1.11×10^-4 m = 0.111 mm.

Compute total elongation as δtotal = δ1 + δ2.
δtotal = 0.348 mm + 0.111 mm = 0.459 mm.
