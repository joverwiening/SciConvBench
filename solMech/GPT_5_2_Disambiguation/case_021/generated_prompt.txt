Assume small-deformation, linear-elastic, isotropic material behavior.
Model the shaft as two prismatic circular segments in series: AB and BC.
Use segment AB length L1 = 300 mm and diameter d1 = 20 mm.
Use segment BC length L2 = 500 mm and diameter d2 = 30 mm.
Fix end A against rotation.
Apply a torque T = 300,000 N·mm at end C.
Assume the applied torque is transmitted without loss so the internal torque is constant and equal to T in both segments.
Use shear modulus G = 25,939.8 N/mm².
Neglect stress concentrations at the diameter step and treat each segment with Saint-Venant torsion of a circular shaft.
Neglect warping restraint effects and assume uniform torsion with plane cross-sections remaining plane.

Compute polar moment of area for each segment as J = (π d^4)/32.
Compute maximum torsional shear stress in each segment as τ_max = T c / J with c = d/2, equivalently τ_max = 16 T / (π d^3).
Report τ_max,AB using d1 and τ_max,BC using d2.
Compute angle of twist of each segment as φ = T L / (G J).
Compute φ_AB = T L1 / (G J1) and φ_BC = T L2 / (G J2).
Compute total twist from A to C as φ_total = φ_AB + φ_BC.
Optionally report twist per unit length for each segment as (dφ/dx) = T / (G J).
