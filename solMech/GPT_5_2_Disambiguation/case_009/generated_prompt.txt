Assume small deformation, linear-elastic, homogeneous, isotropic axial behavior for each bar.
Model the system as two prismatic bars in parallel between two perfectly rigid plates.
Assume perfect bonding/attachment at both plates so the end displacements of both bars match (compatibility).
Assume the load is applied concentrically to the rigid plate so no bending occurs and only axial forces develop.
Given total applied tensile load P = 20,000 N carried by the two bars.
Given Bar 1 (AISI 1020 steel): A1 = 300 mm^2, E1 = 200,000 MPa, L = 400 mm.
Given Bar 2 (cast iron): A2 = 250 mm^2, E2 = 110,000 MPa, L = 400 mm.
Use consistent units: N and mm, with 1 MPa = 1 N/mm^2.

Define unknown axial forces in each bar: P1 in Bar 1 and P2 in Bar 2.
Apply equilibrium of the rigid plate: P1 + P2 = P.
Apply compatibility (equal elongation due to rigid plates): δ1 = δ2 = δ.
Use axial constitutive/kinematic relation for each bar: δi = Pi L / (Ai Ei).
Combine compatibility with constitutive relations: P1/(A1 E1) = P2/(A2 E2).
Define axial stiffness of each bar: k1 = A1 E1 / L and k2 = A2 E2 / L.
Express load sharing using stiffness: P1 = (k1/(k1 + k2)) P and P2 = (k2/(k1 + k2)) P.
Compute stiffnesses: k1 = (300)(200,000)/400 = 150,000 N/mm.
Compute stiffnesses: k2 = (250)(110,000)/400 = 68,750 N/mm.
Compute force in Bar 1: P1 = (150,000/(150,000 + 68,750)) 20,000 = 13,714 N (tension).
Compute force in Bar 2: P2 = (68,750/(150,000 + 68,750)) 20,000 = 6,286 N (tension).
Compute common elongation: δ = P/(k1 + k2) = 20,000/218,750 = 0.09143 mm.
Compute strain in each bar (same due to equal L and equal δ): ε1 = ε2 = δ/L = 0.09143/400 = 2.286×10^-4.
Compute stress in Bar 1: σ1 = P1/A1 = 13,714/300 = 45.71 MPa (tension).
Compute stress in Bar 2: σ2 = P2/A2 = 6,286/250 = 25.14 MPa (tension).
Check stress via Hooke’s law: σ1 = E1 ε = 200,000(2.286×10^-4) = 45.71 MPa.
Check stress via Hooke’s law: σ2 = E2 ε = 110,000(2.286×10^-4) = 25.14 MPa.
