Use small-deformation, linear-elastic behavior.
Model the member as a prismatic, simply supported beam of span L = 3000 mm.
Use Euler–Bernoulli beam theory and neglect shear deformation and axial deformation.
Assume constant flexural rigidity with E = 200000 N/mm² and I = 1,500,000 mm⁴, so EI = 3.0×10^11 N·mm².
Apply a single concentrated load P = 2000 N downward at midspan (x = L/2).
Take x measured from the left support, with 0 ≤ x ≤ L.
Use static equilibrium to obtain reactions RA = RB = P/2.
Use the bending moment function M(x) defined piecewise as M(x) = (P/2)x for 0 ≤ x ≤ L/2 and M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.
Use Castigliano’s theorem with bending strain energy only: U = ∫0^L [M(x)^2/(2EI)] dx.
Introduce the load P as the generalized force associated with the midspan deflection δmid, and compute δmid = ∂U/∂P.
Evaluate U using the piecewise M(x) and symmetry: U = 2∫0^(L/2) [( (P/2)x )^2/(2EI)] dx.
Differentiate to obtain the governing deflection relation δmid = P L^3 /(48 EI).
Compute the numerical midspan deflection: δmid = (2000×3000^3)/(48×3.0×10^11) mm = 3.75 mm downward.
