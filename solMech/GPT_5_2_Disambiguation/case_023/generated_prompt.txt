Assume an Euler–Bernoulli prismatic cantilever beam with small deflections, linear-elastic material behavior, and constant flexural rigidity EI.
Neglect shear deformation and rotary inertia.
Use x measured from the fixed end, with x = 0 at the clamp and x = L at the free end.
Take transverse deflection v(x) positive upward.
Apply a uniformly distributed transverse load w over 0 ≤ x ≤ L, with w = −1.0 N/mm (downward) and no other loads.
Use beam length L = 2500 mm.
Use E = 200000 N/mm^2, I = 1,000,000 mm^4, so EI = 2.0×10^11 N·mm^2.
Use the Euler–Bernoulli governing relation EI v''''(x) = w.
Use the moment-curvature relation M(x) = EI v''(x).
Use the shear-moment relation V(x) = dM/dx = EI v'''(x).
Apply cantilever boundary conditions v(0) = 0 and v'(0) = 0 at the fixed end.
Apply free-end boundary conditions M(L) = 0 and V(L) = 0 at the free end.
The internal shear force distribution is V(x) = w (x − L).
The internal bending moment distribution is M(x) = (w/2) (x − L)^2.
The slope distribution is v'(x) = (w/(6EI)) (x − L)^3 − (w/(6EI)) L^3.
The deflection distribution is v(x) = (w/(24EI)) (x − L)^4 − (w/(6EI)) L^3 x + (w/(24EI)) L^4.
The maximum deflection magnitude occurs at the free end x = L.
The free-end deflection is v(L) = w L^4 / (8EI).
With the given values, v(L) = (−1.0)(2500^4) / (8·2.0×10^11) mm = −24.414 mm (downward).
The free-end slope is v'(L) = w L^3 / (6EI).
With the given values, v'(L) = (−1.0)(2500^3) / (6·2.0×10^11) rad = −0.013021 rad.
The fixed-end reactions are V(0) = −wL and M(0) = (w/2)L^2.
With the given values, V(0) = −(−1.0)(2500) N = +2500 N (upward reaction) and M(0) = (−1.0/2)(2500^2) N·mm = −3.125×10^6 N·mm (hogging sign per the chosen convention).
