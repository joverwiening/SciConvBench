Assume small-deformation, linear-elastic Euler–Bernoulli beam theory.
Assume the beam is prismatic with a solid rectangular cross-section of constant width b = 40 mm and unknown height h.
Assume the beam is simply supported and the design is governed by the given maximum internal bending moment M_max = 3,000,000 N·mm.
Assume bending stress is computed from the flexure formula using the elastic section modulus.
Use allowable bending stress σ_allow = 90 MPa = 90 N/mm^2.
Use the governing relation for maximum bending stress: σ_max = M_max c / I.
For a rectangle, use c = h/2.
For a rectangle, use second moment of area about the centroidal strong axis: I = b h^3 / 12.
Combine to get σ_max = 6 M_max / (b h^2).
Impose the design criterion σ_max ≤ σ_allow.
Solve for required height: h ≥ sqrt(6 M_max / (b σ_allow)).
Substitute values: h ≥ sqrt(6·3,000,000 / (40·90)) mm.
Compute: h ≥ sqrt(18,000,000 / 3,600) = sqrt(5,000) = 70.71 mm.
Select a practical design height: h = 71 mm minimum (or round up to the next standard size as required).
Report the relevant response quantity for this design case as the maximum bending stress σ_max and the required section height h based on M_max and σ_allow.
