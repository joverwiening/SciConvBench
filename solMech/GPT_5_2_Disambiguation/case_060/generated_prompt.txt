Assume small-deformation, linear-elastic behavior and Euler (elastic) column buckling theory applies.
Use a prismatic, initially straight column with constant properties along its length.
Use fixed–fixed end conditions with effective length factor K = 0.5.
Use column length L = 2000 mm.
Use second moment of area about the governing buckling axis I = 800,000 mm^4.
Use Young’s modulus E = 200,000 MPa = 200,000 N/mm^2.
Compute the effective buckling length as Le = K·L.
Compute the Euler critical buckling load as Pcr = (pi^2·E·I)/(Le^2) = (pi^2·E·I)/((K·L)^2).
Substitute values: Le = 0.5·2000 mm = 1000 mm.
Substitute values: Pcr = (pi^2·200,000 N/mm^2·800,000 mm^4)/(1000 mm)^2.
Report the numerical result as Pcr ≈ 1.579×10^6 N.
Report the numerical result as Pcr ≈ 1579 kN.
