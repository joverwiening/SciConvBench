Assume a prismatic, homogeneous, isotropic, linear-elastic beam under small deformation.
Assume Euler–Bernoulli beam theory applies (plane sections remain plane), and bending about the strong axis of a rectangular cross-section.
Assume the provided maximum bending moment M_max governs design everywhere along the span, so span length, load type, and end-moment application details are not required for bending-stress sizing.
Use M_max = 6,000,000 N·mm.
Use allowable bending stress σ_allow = 90 MPa = 90 N/mm^2.
Use rectangular cross-section width b = 30 mm and unknown height h to be sized.
Use the flexure formula for maximum bending stress: σ_max = M_max c / I.
For a rectangle, use I = b h^3 / 12 about the centroidal strong axis.
For a rectangle, use c = h/2.
Combine to get σ_max = 6 M_max / (b h^2).
Impose the allowable-stress criterion: σ_max ≤ σ_allow.
Solve for required height: h ≥ sqrt(6 M_max / (b σ_allow)).
Compute h ≥ sqrt(6·6,000,000 / (30·90)) mm = sqrt(13,333.33) mm = 115.47 mm.
Select the design height h = 116 mm (or the next larger standard size) to satisfy allowable bending stress.
