Assume a straight, prismatic, solid circular column with constant diameter d.
Assume small deformation, linear-elastic behavior with Young’s modulus E = 200 GPa.
Assume concentric axial compressive load P = 30,000 N with no eccentricity.
Assume unsupported length L = 1800 mm.
Assume Euler elastic buckling governs and inelastic buckling is not checked.
Assume end condition represented by effective length factor K = 1.0 (pinned–pinned).
Assume buckling design factor of safety n = 2.0, requiring Pcr ≥ nP.
Use Euler critical buckling load Pcr = (π^2 E I) / (K L)^2.
Use second moment of area for a solid circular section I = (π d^4) / 64.
Compute required critical load Pcr,req = nP = 60,000 N.
Solve for required I: Ireq = Pcr,req (K L)^2 / (π^2 E).
Use consistent units: E = 200,000 N/mm^2, L = 1800 mm, K = 1.0, Pcr,req = 60,000 N.
Calculate Ireq = 60,000·(1800)^2 / (π^2·200,000) = 98,550 mm^4 (approximately).
Solve for diameter: d = [64 Ireq / π]^(1/4).
Calculate d = [64·98,550/π]^(1/4) = 37.7 mm (approximately).
Select a design diameter ddesign ≥ 37.7 mm; if selecting a standard size, use ddesign = 38 mm (or the next larger standard diameter).
For any chosen diameter d, compute I = (π d^4)/64 and Pcr = (π^2 E I)/(K L)^2.
Compute buckling factor of safety for any chosen diameter as FoS = Pcr / P.
For d = 37.7 mm, Pcr ≈ 60.0 kN and FoS ≈ 2.00 by construction.
For d = 38.0 mm, Pcr ≈ 61.9 kN and FoS ≈ 2.06.
