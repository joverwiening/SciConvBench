Use small-deformation, linear-elastic Euler–Bernoulli beam theory.
Model a prismatic beam of length L = 3000 mm with constant flexural rigidity EI = 4.0×10^11 N·mm^2.
Use a simply supported boundary condition with a pin at x = 0 and a roller at x = L.
Apply a uniformly distributed load w = 0.3 N/mm downward over 0 ≤ x ≤ L.
Apply a concentrated point load P = 3000 N downward at x = L/2 = 1500 mm.
Assume plane sections remain plane and normal to the neutral axis (shear deformation neglected).
Assume deflections and rotations are small so geometric nonlinearity is neglected.
Take positive deflection v(x) downward, and take x measured from the left support.

Compute support reactions by statics.
Use RA + RB = wL + P.
Use RB·L = wL·(L/2) + P·(L/2).
Use RA = (wL + P) − RB.
With the given symmetry, use RA = RB = (wL + P)/2.

Use superposition for deflection: v(x) = v_w(x) + v_P(x).
Use the Euler–Bernoulli governing relation EI v''(x) = M(x).
Alternatively use EI v''''(x) = w(x) with w(x) including the point load via a singularity function.

Uniform-load-only bending moment function.
For 0 ≤ x ≤ L, use M_w(x) = RA_w x − (w x^2)/2, where RA_w = wL/2.
Uniform-load-only curvature relation: v_w''(x) = M_w(x)/EI.
Integrate twice to obtain v_w(x) and apply simply supported boundary conditions v_w(0) = 0 and v_w(L) = 0.

Point-load-only bending moment function.
Let a = L/2.
For 0 ≤ x ≤ a, use M_P(x) = RA_P x, where RA_P = P/2.
For a ≤ x ≤ L, use M_P(x) = RA_P x − P(x − a).
Point-load-only curvature relation: v_P''(x) = M_P(x)/EI.
Integrate piecewise to obtain v_P(x) on [0,a] and [a,L].
Enforce v_P(0) = 0 and v_P(L) = 0.
Enforce continuity at x = a of deflection and slope: v_P(a−) = v_P(a+) and v_P'(a−) = v_P'(a+).

Use the standard closed-form deflection contributions (downward positive).
For a simply supported beam with full-span UDL, use v_w(x) = (w x (L^3 − 2L x^2 + x^3)) / (24 EI) for 0 ≤ x ≤ L.
For a simply supported beam with a midspan point load, use v_P(x) = (P x (3L^2 − 4x^2)) / (48 EI) for 0 ≤ x ≤ L/2.
For a simply supported beam with a midspan point load, use v_P(x) = (P (L − x) (3L^2 − 4(L − x)^2)) / (48 EI) for L/2 ≤ x ≤ L.

Form the total deflection by superposition.
For 0 ≤ x ≤ L/2, use v(x) = v_w(x) + (P x (3L^2 − 4x^2)) / (48 EI).
For L/2 ≤ x ≤ L, use v(x) = v_w(x) + (P (L − x) (3L^2 − 4(L − x)^2)) / (48 EI).

Identify relevant response quantities to report.
Report v(x) over 0 ≤ x ≤ L as the primary response quantity.
Report maximum deflection v_max, which occurs at midspan for this symmetric loading.
Use v_w,max = (5 w L^4) / (384 EI).
Use v_P,max = (P L^3) / (48 EI).
Use v_max = v_w,max + v_P,max.

Optionally report slope and bending moment relations if needed for completeness.
Use θ(x) = v'(x).
Use M(x) = EI v''(x).
Use shear V(x) = dM/dx.

Use consistent units throughout (N, mm, N/mm, N·mm, N·mm^2).
Substitute L = 3000 mm, w = 0.3 N/mm, P = 3000 N, EI = 4.0×10^11 N·mm^2 for numerical evaluation if required.
