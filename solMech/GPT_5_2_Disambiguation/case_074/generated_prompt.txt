Assume small-deformation, linear-elastic beam behavior.
Assume Euler–Bernoulli beam theory applies (plane sections remain plane).
Assume the beam has a prismatic rectangular cross-section with constant width b = 60 mm and unknown height h.
Assume bending about the strong axis of the rectangle (section modulus based on h as the depth in the bending plane).
Use the given maximum bending moment directly for sizing: M_max = 6,000,000 N·mm.
Use the allowable bending stress for sizing: σ_allow = 170 MPa = 170 N/mm^2.
Use the flexure formula for maximum bending stress: σ_max = M_max c / I.
For a rectangle, use I = b h^3 / 12 and c = h/2.
Derive the section modulus: S = I/c = b h^2 / 6.
Compute bending stress using section modulus: σ_max = M_max / S = 6 M_max / (b h^2).
Impose the allowable-stress design criterion: σ_max ≤ σ_allow.
Solve for required height: h ≥ sqrt(6 M_max / (b σ_allow)).
Substitute values: h ≥ sqrt(6·6,000,000 / (60·170)) mm.
Compute: h ≥ sqrt(3,529.4118) mm.
Report required height: h ≥ 59.41 mm.
Select a practical design height meeting the criterion: h = 60 mm (or the next available standard size ≥ 59.41 mm).
