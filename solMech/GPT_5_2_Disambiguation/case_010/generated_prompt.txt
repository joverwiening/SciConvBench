Model two axially loaded bars connected in parallel between two perfectly rigid plates.
Assume small deformation, linear-elastic, homogeneous, isotropic material behavior for each bar.
Assume perfect bonding/connection at the plates so both bars undergo the same axial elongation.
Assume concentric axial loading so only uniform axial normal stress acts in each bar (no bending, shear, or eccentricity).
Given total applied tensile force P = 30,000 N on the top rigid plate.
Given bar 1 (steel): A1 = 150 mm^2, L1 = 800 mm, E1 = 200,000 MPa.
Given bar 2 (cast iron): A2 = 200 mm^2, L2 = 800 mm, E2 = 110,000 MPa.
Use consistent units with N and mm so that 1 MPa = 1 N/mm^2.

Enforce equilibrium of the rigid plate: P = P1 + P2.
Enforce compatibility due to rigid plates: Δ1 = Δ2 = Δ.
Use axial constitutive/kinematic relations for each bar: σi = Ei εi, εi = Δ/Li, σi = Pi/Ai.
Combine to get each bar force–elongation relation: Pi = (Ai Ei / Li) Δ.
Define axial stiffness ki = Ai Ei / Li.
Compute stiffnesses: k1 = (150×200,000)/800 = 37,500 N/mm, k2 = (200×110,000)/800 = 27,500 N/mm.
Compute total stiffness for parallel bars: keq = k1 + k2 = 65,000 N/mm.
Compute common elongation from equilibrium and compatibility: Δ = P/keq = 30,000/65,000 = 0.461538 mm.
Compute load share: P1 = k1 Δ = 37,500×0.461538 = 17,307.7 N, P2 = k2 Δ = 27,500×0.461538 = 12,692.3 N.
Check equilibrium: P1 + P2 = 30,000 N.

Compute stresses: σ1 = P1/A1 = 17,307.7/150 = 115.385 MPa (tension), σ2 = P2/A2 = 12,692.3/200 = 63.462 MPa (tension).
Compute strains: ε1 = Δ/L1 = 0.461538/800 = 5.76923×10^-4, ε2 = Δ/L2 = 5.76923×10^-4.
Verify constitutive consistency: σ1/E1 = 115.385/200,000 = 5.76923×10^-4, σ2/E2 = 63.462/110,000 = 5.76929×10^-4 (difference only from rounding).

Relevant response quantities to report for composite bars in parallel are the common elongation Δ, the force carried by each bar Pi, the stress in each bar σi, the strain in each bar εi, and the equivalent axial stiffness keq (or equivalent EA, where (EA)eq = Σ Ai Ei for equal lengths).
