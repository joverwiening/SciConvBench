Assume a solid, circular, prismatic shaft of uniform diameter d over the full length L = 800 mm.
Assume small deformation, linear elastic torsion with Saint-Venant theory (plane sections remain plane and circular; no warping restraint effects).
Assume the applied torque is constant along the length: T = 600,000 N·mm.
Use shear modulus G = 76,923.1 MPa = 76,923.1 N/mm^2.
Use the polar second moment of area for a solid circular shaft: J = (π d^4)/32.
Use the torsion angle-of-twist relation: φ = (T L)/(J G).
Impose the design constraint: φ ≤ φ_allow, where φ_allow = 1.5° = 1.5·π/180 rad.
Solve for the minimum required diameter from the twist limit: d_min = [ (32 T L)/(π G φ_allow) ]^(1/4).
Compute the numerical value: d_min = [ (32·600,000·800)/(π·76,923.1·(1.5·π/180)) ]^(1/4) mm.
Report the design diameter as d ≥ 37.6 mm (minimum from twist limit), and select a practical standard size at or above this value if required.
Optionally report the corresponding maximum shear stress at the outer surface for the designed diameter: τ_max = (T c)/J = (16 T)/(π d^3), with c = d/2.
Optionally report the shear strain at the outer surface: γ_max = τ_max/G.
Optionally report the twist rate: dφ/dx = T/(J G).
