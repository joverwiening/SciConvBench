Assume a straight, prismatic, solid circular column with diameter d = 25 mm and length L = 2000 mm.
Assume linear-elastic isotropic material with Young’s modulus E = 200,000 MPa and yield strength Sy = 250 MPa.
Assume concentric axial compressive load P = 25,000 N with no initial eccentricity and no initial crookedness.
Assume effective length factor K = 0.7 so the effective buckling length is Le = K·L = 1400 mm.
Assume small deformation theory and Euler elastic buckling applicability (slender column, elastic instability).

Compute cross-sectional area A = (π/4)d^2.
Compute second moment of area I = (π/64)d^4.
Compute radius of gyration r = sqrt(I/A) = d/4.
Compute slenderness ratio λ = Le/r.

Compute average compressive stress from the applied load as σ = P/A.
Compute yielding check as σ ≤ Sy.
Compute the axial load that would cause first yield in uniform compression as Py = Sy·A.

Compute Euler critical buckling load as Pcr = (π^2·E·I)/(Le^2).
Compute Euler critical buckling stress as σcr = Pcr/A = (π^2·E)/(λ^2).

Compare governing failure mode by comparing Py versus Pcr.
If Pcr < Py then elastic buckling governs before yielding.
If Py ≤ Pcr then yielding governs before Euler buckling.

Evaluate instability check under the given load using a buckling utilization ratio ηb = P/Pcr.
Evaluate yielding utilization ratio ηy = P/Py.
Report factors of safety as FS_buckling = Pcr/P and FS_yield = Py/P.

Numerical results using consistent N and mm units (1 MPa = 1 N/mm^2).
Area A = (π/4)(25^2) = 490.87 mm^2.
Second moment I = (π/64)(25^4) = 19,174.76 mm^4.
Radius of gyration r = d/4 = 6.25 mm.
Effective length Le = 1400 mm.
Slenderness λ = Le/r = 1400/6.25 = 224.

Applied compressive stress σ = P/A = 25,000/490.87 = 50.93 MPa.
Yield check: 50.93 MPa ≤ 250 MPa so yielding does not occur at the applied load.
Yield load Py = Sy·A = 250·490.87 = 122,718 N = 122.7 kN.

Euler critical load Pcr = (π^2·E·I)/(Le^2) = (π^2·200,000·19,174.76)/(1400^2) = 19,300 N = 19.3 kN.
Euler critical stress σcr = Pcr/A = 19,300/490.87 = 39.32 MPa.

Mode comparison: Pcr (19.3 kN) < Py (122.7 kN) so Euler elastic buckling governs before yielding.
Instability check at applied load: ηb = P/Pcr = 25.0/19.3 = 1.30 so the column is predicted to buckle (not acceptable) under the given load.
Yield utilization at applied load: ηy = P/Py = 25.0/122.7 = 0.204 so yielding is not limiting.
Factors of safety: FS_buckling = 0.772 and FS_yield = 4.91.

Additional note on applicability: because λ = 224 is high, the Euler elastic buckling assumption is consistent for a first-pass instability check, but real columns may buckle at lower loads if initial imperfections or eccentricity exist.
