Assume a straight, prismatic, two-segment stepped circular bar loaded in uniaxial tension.
Assume small deformation, linear-elastic, homogeneous, isotropic material behavior with Young’s modulus E = 200,000 N/mm².
Assume static loading with axial force P = 30,000 N applied at the right end and the left end fixed.
Assume perfect load transfer at the step, so the internal axial force is the same in both segments: N1 = N2 = P.
Assume stress is uniform over each segment’s cross-section away from the step (ignore stress concentration at the diameter change).
Use the N–mm–MPa unit system.

Given geometry.
Segment 1: L1 = 300 mm, d1 = 25 mm.
Segment 2: L2 = 1000 mm, d2 = 35 mm.

Cross-sectional areas.
A1 = (π/4) d1² = (π/4)(25²) = 490.874 mm².
A2 = (π/4) d2² = (π/4)(35²) = 962.113 mm².

Axial stress in each segment (engineering/nominal stress).
σ1 = P / A1 = 30,000 / 490.874 = 61.12 MPa (tension).
σ2 = P / A2 = 30,000 / 962.113 = 31.18 MPa (tension).

Axial strain in each segment (Hooke’s law).
ε1 = σ1 / E = 61.12 / 200,000 = 3.056×10^-4.
ε2 = σ2 / E = 31.18 / 200,000 = 1.559×10^-4.

Elongation of each segment.
δ1 = (P L1) / (A1 E) = (30,000×300)/(490.874×200,000) = 0.09167 mm.
δ2 = (P L2) / (A2 E) = (30,000×1000)/(962.113×200,000) = 0.15591 mm.

Total elongation.
δtotal = δ1 + δ2 = 0.09167 + 0.15591 = 0.24758 mm.

Governing relations (general form for stepped axial members).
Ai = (π/4) di².
σi = P / Ai.
εi = σi / E.
δi = εi Li = (P Li)/(Ai E).
δtotal = Σ δi over all segments.
