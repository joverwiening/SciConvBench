Model the member as an Euler–Bernoulli beam with small deformation, linear-elastic behavior.
Use a simply supported boundary condition at x = 0 and x = L.
Use span length L = 2500 mm.
Use Young’s modulus E = 200000 N/mm².
Use second moment of area I = 1,200,000 mm⁴.
Use flexural rigidity EI = 2.4×10^11 N·mm².
Apply a single concentrated load P = 2500 N downward at midspan x = L/2.
Assume no other distributed load or applied shear load (w(x) = 0), so internal shear arises only from the point load and reactions.
Neglect shear deformation (Euler–Bernoulli assumption), neglect rotary inertia, and assume prismatic constant EI along the span.

Compute support reactions from statics: R_A = R_B = P/2.
Define internal shear force V(x): V(x) = +P/2 for 0 < x < L/2, and V(x) = −P/2 for L/2 < x < L.
Define internal bending moment M(x): M(x) = (P/2)x for 0 ≤ x ≤ L/2, and M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.
Use the Euler–Bernoulli governing relation between curvature and moment: EI·v''(x) = M(x), where v(x) is the transverse deflection.
Use slope definition: θ(x) = v'(x).
Impose simply supported displacement boundary conditions: v(0) = 0 and v(L) = 0.
Impose continuity at midspan: v is continuous at x = L/2 and θ is continuous at x = L/2.

Report the midspan deflection magnitude for a simply supported beam with a central point load:
v(L/2) = P L^3 / (48 EI).
With the given values: v(L/2) = 2500·(2500^3) / (48·2.4×10^11) mm = 3.390 mm downward.

Report the support slope magnitude for a simply supported beam with a central point load:
θ(0) = + P L^2 / (16 EI) and θ(L) = − P L^2 / (16 EI).
With the given values: |θ(0)| = |θ(L)| = 2500·(2500^2) / (16·2.4×10^11) = 0.004069 rad.
State sign convention: positive θ(0) corresponds to counterclockwise rotation at the left support for a downward midspan load, and θ(L) is equal magnitude with opposite sign.
