Assume a straight, prismatic, solid circular column with small deflections, linear-elastic isotropic material behavior, and initially perfect geometry unless otherwise stated.
Use Euler elastic buckling theory (slender column; inelastic buckling and crushing/yield are not considered unless separately checked).
Use pinned–pinned end conditions represented by effective length factor K = 1.0.
Use unsupported length L = 2000 mm, so effective buckling length Le = K·L = 2000 mm.
Use diameter d = 20 mm.
Use Young’s modulus E = 200,000 MPa (N/mm²).
Compute cross-sectional second moment of area for a solid circular section as I = (π/64) d^4.
Compute Euler critical buckling load as Pcr = (π^2 E I) / (Le^2) = (π^2 E I) / ((K L)^2).
Compute allowable axial compressive load against buckling using factor of safety n = 2.0 as Pallow = Pcr / n.
Given an applied axial compressive load P (if provided), compute buckling factor of safety as nbuckling = Pcr / P.
If the applied load equals the allowable load definition, then nbuckling = n = 2.0 by construction.
Report response quantities at minimum as Pcr, Pallow, and nbuckling (if P is specified).
