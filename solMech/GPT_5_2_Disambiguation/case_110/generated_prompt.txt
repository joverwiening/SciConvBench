Model the member as a prismatic, straight Euler–Bernoulli beam with small deflections and linear-elastic behavior.
Use a simply supported boundary condition at x = 0 and x = L with zero vertical deflection at both supports.
Neglect shear deformation and rotary inertia.
Neglect self-weight.
Apply a single concentrated load P downward at midspan x = L/2.
Use consistent N–mm units with E in MPa (N/mm²), I in mm⁴, and EI in N·mm².
Given L = 3000 mm, E = 200000 MPa, I = 3000000 mm⁴, EI = 6.0×10^11 N·mm², and P = 2000 N.

Compute support reactions from statics.
Set RA = RB = P/2.

Define the bending moment function M(x).
For 0 ≤ x ≤ L/2, use M(x) = RA x = (P/2)x.
For L/2 ≤ x ≤ L, use M(x) = RB(L − x) = (P/2)(L − x).

Use Castigliano’s theorem to obtain the midspan deflection in the direction of P.
Use strain energy in bending only: U = ∫0^L [M(x)^2/(2EI)] dx.
Apply Castigliano: δmid = ∂U/∂P.

Evaluate U by symmetry.
Use U = 2 ∫0^(L/2) [( (P/2)x )^2/(2EI)] dx.
Compute U = 2 ∫0^(L/2) [P^2 x^2/(8EI)] dx = (P^2/(4EI)) [x^3/3]0^(L/2) = P^2 L^3/(96 EI).

Differentiate with respect to P to get midspan deflection.
Use δmid = ∂U/∂P = (2P L^3)/(96 EI) = P L^3/(48 EI).

Substitute the given values.
Compute L^3 = (3000 mm)^3 = 27×10^9 mm^3.
Compute δmid = (2000×27×10^9)/(48×6.0×10^11) mm = 1.875 mm.

Report the relevant response quantity.
The midspan vertical deflection is δmid = 1.875 mm downward.
