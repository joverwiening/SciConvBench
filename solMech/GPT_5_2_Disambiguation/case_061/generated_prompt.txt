Use small-deformation, linear-elastic solid mechanics.
Model the member as a short column so global buckling is neglected.
Assume the load is applied parallel to the member axis with a constant eccentricity e, so the internal resultants are an axial force P and a bending moment Mz = P e about the centroidal z-axis.
Assume Saint-Venant (beam) stress distribution over the cross-section and neglect stress concentrations at the load introduction.
Use a rectangular cross-section with width b = 60 mm and height h = 120 mm.
Use compressive axial load magnitude P = 60,000 N.
Use eccentricity e = 20 mm along the width direction, producing bending about the centroidal z-axis.
Compute cross-sectional area as A = b h.
Compute second moment of area about the centroidal z-axis as Iz = (h b^3)/12.
Compute the bending moment as Mz = P e.
Define the width-direction coordinate x measured from the centroid, positive toward the eccentricity side, with x ∈ [−b/2, +b/2].
Compute normal stress due to combined axial load and bending as σ(x) = −P/A − (Mz x)/Iz, where negative stress is compressive.
Compute extreme-fiber stresses at x = +b/2 and x = −b/2 as σmax,comp = −P/A − (Mz (b/2))/Iz and σmin = −P/A + (Mz (b/2))/Iz.
Determine whether any part of the section is in tension by checking if σmin > 0.
Compute the neutral axis location (if it exists within the section) from σ(xn) = 0, giving xn = −(P Iz)/(A Mz).
Compute the kern (no-tension) condition for a rectangular section in the width direction as |e| ≤ b/6, and report whether the given e satisfies it.
If strains are needed, relate strain to stress by ε(x) = σ(x)/E using Young’s modulus E.
If axial shortening at the centroidal axis is needed for a prismatic member of length L, use δ = (P L)/(A E) (not including bending deflection).
If bending curvature is needed, use κz = Mz/(E Iz).
