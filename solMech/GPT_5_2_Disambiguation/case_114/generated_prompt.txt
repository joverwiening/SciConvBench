Assume a straight, prismatic, circular rod with constant diameter and a concentric axial tensile load applied through the centroid.
Assume small deformation, linear-elastic, homogeneous, isotropic material behavior.
Assume uniaxial stress state away from load introduction regions (Saint-Venant’s principle), so average normal stress represents the axial stress.
Given diameter d = 12 mm.
Given axial tensile force P = 30,000 N.
Given gage length L = 800 mm.
Given Young’s modulus E = 200,000 MPa.
Given yield strength Sy = 250 MPa.
Compute cross-sectional area as A = (π/4) d^2.
Compute average normal stress as σavg = P/A.
Compute axial strain as ε = σavg/E.
Compute elongation over the gage length as δ = ε L = (P L)/(A E).
Compute factor of safety against yielding as n = Sy/σavg.
Use consistent units: N and mm so that stress is in MPa (since 1 MPa = 1 N/mm^2).
Numerical area: A = (π/4)(12 mm)^2 = 113.097 mm^2.
Numerical average normal stress: σavg = 30,000 N / 113.097 mm^2 = 265.26 MPa (tension).
Numerical strain: ε = 265.26 MPa / 200,000 MPa = 0.001326.
Numerical elongation: δ = ε L = 0.001326 × 800 mm = 1.061 mm.
Numerical factor of safety: n = 250 MPa / 265.26 MPa = 0.943.
Conclude that the computed average axial stress exceeds the specified yield strength, so yielding is predicted under the stated assumptions (n < 1).
