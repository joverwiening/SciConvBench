Use small-deformation, linear-elastic Euler–Bernoulli beam theory.
Model a prismatic beam of constant flexural rigidity EI over the span.
Use a simply supported beam with a pin at x = 0 and a roller at x = L.
Set span length L = 2000 mm.
Apply a single concentrated downward point load P = 3000 N at midspan x = L/2 = 1000 mm.
Assume the beam self-weight is neglected unless otherwise stated.
Assume material is homogeneous and isotropic with Young’s modulus E.
Assume plane sections remain plane and shear deformation is neglected (Euler–Bernoulli assumption).
Assume the deflection limit applies to the maximum vertical deflection, which occurs at midspan for this loading.
Use the deflection criterion δ_max ≤ δ_allow with δ_allow = 3 mm.
Compute support reactions from statics as R_A = R_B = P/2.
Use the bending moment distribution M(x) = (P/2)x for 0 ≤ x ≤ L/2.
Use the bending moment distribution M(x) = (P/2)(L − x) for L/2 ≤ x ≤ L.
Use the governing relation EI w''(x) = M(x), where w(x) is the transverse deflection.
Use boundary conditions w(0) = 0 and w(L) = 0.
Use symmetry about midspan to simplify if desired, with slope w'(L/2) = 0.
Use the standard closed-form maximum deflection for a simply supported beam with a central point load as δ_max = P L^3 / (48 E I).
Enforce the sizing requirement I ≥ P L^3 / (48 E δ_allow).
If a rectangular cross-section is selected, use I = b h^3 / 12 about the strong axis and solve for h (or b) to satisfy the inequality.
If a circular solid cross-section is selected, use I = π d^4 / 64 and solve for d to satisfy the inequality.
Report at minimum the required second moment of area I_required and the resulting section dimension(s) for the chosen shape.
Optionally report maximum bending moment M_max = P L / 4 at midspan for stress checks if needed, even though the focus is deflection sizing.
