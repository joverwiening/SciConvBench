Assume small-deformation, linear-elastic, isotropic material behavior.
Assume a prismatic solid circular shaft with diameter d = 20 mm (radius r = 10 mm).
Assume shaft length for twist check is L = 1000 mm.
Assume steady power transmission with constant speed n = 1200 rpm and power P = 5 kW.
Compute angular speed as ω = 2π(n/60) = 40π rad/s ≈ 125.66 rad/s.
Compute transmitted torque from power as T = P/ω ≈ 39.79 N·m = 3.979×10^4 N·mm.
Assume Saint-Venant torsion applies (no stress concentrations, no warping restraint effects, uniform circular section).
Use polar second moment of area for a solid circular shaft: J = (π d^4)/32.
Compute J for d = 20 mm: J = (π·20^4)/32 = 5000π mm^4 ≈ 1.5708×10^4 mm^4.
Compute maximum torsional shear stress at the outer surface: τ_max = T r / J = 16T/(π d^3).
Compute τ_max using T = 3.979×10^4 N·mm and d = 20 mm: τ_max ≈ 25.33 MPa.
Use shear modulus for AISI 1020 steel as given: G = 76923.1 MPa = 76923.1 N/mm^2.
Compute angle of twist for a uniform shaft: θ = T L / (J G).
Compute θ using T = 3.979×10^4 N·mm, L = 1000 mm, J = 5000π mm^4, G = 76923.1 N/mm^2: θ ≈ 0.03293 rad ≈ 1.887°.
Assume a typical serviceability twist limit of 1° per meter for general power-transmission shafts.
Check twist serviceability: θ_allow = 1° over 1000 mm, so θ ≈ 1.887° exceeds the assumed limit.
Assume AISI 1020 steel condition is hot-rolled for selecting yield strength.
Assume a typical published yield strength for hot-rolled AISI 1020 steel: S_y = 294 MPa.
Assume a design factor (safety factor) N = 2.0 for yielding in torsion.
Use von Mises criterion to set allowable shear stress in pure torsion: τ_allow = 0.577 S_y / N.
Compute τ_allow: τ_allow = 0.577·294/2 ≈ 84.8 MPa.
Check torsional shear stress: τ_max ≈ 25.33 MPa ≤ 84.8 MPa, so the stress check passes under the stated assumptions.
Report relevant response quantities for torsion checks as T, J, τ_max, θ, and pass/fail versus τ_allow and θ_allow.
