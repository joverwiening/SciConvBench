Assume a straight, prismatic bar aligned with the x-axis, with constant cross-sectional area A and constant Young’s modulus E.
Assume small deformation, linear elasticity, uniaxial stress state, and Saint-Venant behavior away from point-load application points.
Assume point loads act collinearly with the bar axis and are applied at x = 300 mm (B), x = 900 mm (C), and x = 1200 mm (D).
Use the sign convention: positive axial force N(x) is tension (acting to pull the cut faces apart), positive displacement u(x) is to the right, and applied point loads are positive to the right.
Define geometry: A at x = 0 mm, B at x = 300 mm, C at x = 900 mm, D at x = 1200 mm.
Use properties: A = 500 mm^2, E = 200,000 N/mm^2.
Use loads: P_B = +18,000 N at x = 300 mm, P_C = −12,000 N at x = 900 mm, P_D = +10,000 N at x = 1200 mm.
Apply boundary condition: u(0) = 0 at the fixed left end A.
Treat the right end D as traction-loaded by the applied point load at x = 1200 mm, with no displacement prescribed.

Enforce global axial force equilibrium to determine the support reaction at A.
Compute reaction: R_A + P_B + P_C + P_D = 0.
Evaluate reaction: R_A + 18,000 − 12,000 + 10,000 = 0, so R_A = −16,000 N (reaction acts to the left).

Define internal axial force N(x) piecewise between point loads using equilibrium of the left segment.
For 0 < x < 300 mm (segment AB), N(x) = −R_A = 16,000 N (tension).
For 300 < x < 900 mm (segment BC), N(x) = −(R_A + P_B) = −(−16,000 + 18,000) = −2,000 N (compression).
For 900 < x < 1200 mm (segment CD), N(x) = −(R_A + P_B + P_C) = −(−16,000 + 18,000 − 12,000) = 10,000 N (tension).
At each point load, enforce the jump condition N(x_i^+) − N(x_i^−) = −P_i.

Relate strain, stress, and displacement by 1D linear elasticity.
Use axial strain: ε(x) = du/dx.
Use axial stress: σ(x) = E ε(x).
Use axial force-stress relation: N(x) = A σ(x).
Combine to get the governing differential relation on each load-free segment: du/dx = N(x)/(A E).

Compute stress piecewise from σ(x) = N(x)/A.
On AB: σ = 16,000 / 500 = 32 MPa (tension).
On BC: σ = −2,000 / 500 = −4 MPa (compression).
On CD: σ = 10,000 / 500 = 20 MPa (tension).

Compute strain piecewise from ε(x) = σ(x)/E = N(x)/(A E).
On AB: ε = 32 / 200,000 = 1.6×10^−4.
On BC: ε = −4 / 200,000 = −2.0×10^−5.
On CD: ε = 20 / 200,000 = 1.0×10^−4.

Compute displacement by integrating du/dx = N/(A E) on each segment with continuity of u at B and C and u(0)=0.
Compute segment elongations Δu = N L/(A E) using L_AB = 300 mm, L_BC = 600 mm, L_CD = 300 mm.
Δu_AB = 16,000·300 / (500·200,000) = 0.048 mm.
Δu_BC = (−2,000)·600 / (500·200,000) = −0.012 mm.
Δu_CD = 10,000·300 / (500·200,000) = 0.030 mm.
Compute nodal displacements: u_A = 0, u_B = 0.048 mm, u_C = 0.048 − 0.012 = 0.036 mm, u_D = 0.036 + 0.030 = 0.066 mm.
State total end displacement: u(1200 mm) = 0.066 mm to the right.

Report relevant response quantities for an axially loaded bar with multiple point loads as: support reaction R_A, internal axial force diagram N(x), stress distribution σ(x), strain distribution ε(x), displacement field u(x) (piecewise linear), segment elongations, and maximum tensile/compressive stress and where they occur.
Identify extrema here: maximum tension N = 16,000 N (σ = 32 MPa) on AB, maximum compression N = −2,000 N (σ = −4 MPa) on BC.
