Model the member as an Euler–Bernoulli beam with small deflection, linear-elastic behavior, constant E and I, and prismatic cross-section.
Use a simply supported boundary condition: v(0)=0 and v(L)=0, where v(x) is the transverse deflection.
Use span length L = 3500 mm.
Use Young’s modulus E = 200000 N/mm².
Use second moment of area I = 3,000,000 mm⁴.
Use flexural rigidity EI = 6.0×10^11 N·mm².
Apply a uniformly distributed transverse load w(x)=w=0.5 N/mm downward over 0≤x≤L.
Assume no other loads act (no additional distributed load, no axial load, no applied end moments).
Take x measured from the left support, positive to the right, and take downward deflection as positive.

Use the governing relations:
Use the load–shear–moment relations dV/dx = −w, dM/dx = V.
Use the curvature–moment relation M(x) = EI v''(x).
Equivalently use the beam equation EI v''''(x) = w.

Compute reactions (by statics):
RA = RB = wL/2.

Use the standard closed-form response for a simply supported beam under full-span UDL:
Deflection:
v(x) = (w x (L^3 − 2L x^2 + x^3)) / (24 EI), for 0≤x≤L.
Slope:
θ(x) = v'(x) = (w (L^3 − 6L x^2 + 4x^3)) / (24 EI), for 0≤x≤L.

Report key quantities:
Maximum deflection occurs at midspan x = L/2:
vmax = (5 w L^4) / (384 EI).
Maximum slope magnitude occurs at the supports x = 0 and x = L:
θ(0) = + (w L^3) / (24 EI), and θ(L) = − (w L^3) / (24 EI).

Evaluate numerically with the given data:
RA = RB = (0.5×3500)/2 = 875 N.
vmax = (5×0.5×3500^4)/(384×6.0×10^11) = 1.626 mm (downward).
θ(0) = (0.5×3500^3)/(24×6.0×10^11) = 0.001490 rad.
θ(L) = −0.001490 rad.
