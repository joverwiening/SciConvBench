Use small-deformation Euler–Bernoulli beam theory with linear-elastic material behavior.
Model a prismatic cantilever beam of length L = 1500 mm fixed at x = 0 and free at x = L.
Use Young’s modulus E = 200000 N/mm².
Use second moment of area about the bending axis I = 1,500,000 mm⁴.
Use flexural rigidity EI = 3.0×10^11 N·mm².
Apply a uniformly distributed transverse load w = 1.5 N/mm acting downward over 0 ≤ x ≤ L.
Neglect shear deformation and rotary inertia.
Assume constant EI along the span.
Take downward deflection as positive.
Use the Euler–Bernoulli governing relation EI y''''(x) = w for 0 ≤ x ≤ L.
Use boundary conditions at the fixed end: y(0) = 0 and y'(0) = 0.
Use boundary conditions at the free end: bending moment M(L) = 0 and shear force V(L) = 0, equivalently y''(L) = 0 and y'''(L) = 0.
Use internal force relations M(x) = -EI y''(x) and V(x) = -EI y'''(x).
Compute the free-end (tip) deflection magnitude as δ_tip = y(L) = w L^4 / (8 EI).
Compute the free-end slope as θ_tip = y'(L) = w L^3 / (6 EI).
With the given values, compute δ_tip = (1.5×1500^4)/(8×3.0×10^11) mm = 3.164 mm downward.
With the given values, compute θ_tip = (1.5×1500^3)/(6×3.0×10^11) rad = 0.0028125 rad (≈ 0.161°) downward rotation.
