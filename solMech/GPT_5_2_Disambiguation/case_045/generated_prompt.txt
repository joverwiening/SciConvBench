Assume a straight, prismatic, homogeneous, isotropic circular rod loaded in concentric axial tension.
Assume small deformation, linear elasticity, and uniform stress/strain away from end effects.
Use diameter d = 12 mm, axial tensile force P = 15,000 N, gage length L = 800 mm, Young’s modulus E = 69,000 MPa, yield strength Sy = 275 MPa.
Compute cross-sectional area A = (π/4)d^2.
Compute average normal stress σavg = P/A.
Compute average axial strain εavg = σavg/E.
Compute elongation δ = εavg L = (PL)/(AE).
Compute factor of safety against yielding n = Sy/σavg.

A = (π/4)(12 mm)^2 = 113.10 mm^2.
σavg = 15,000 N / 113.10 mm^2 = 132.63 N/mm^2 = 132.63 MPa (tension).
εavg = 132.63 MPa / 69,000 MPa = 0.001922 (dimensionless).
δ = εavg L = 0.001922(800 mm) = 1.54 mm (elongation).
n = 275 MPa / 132.63 MPa = 2.07.
