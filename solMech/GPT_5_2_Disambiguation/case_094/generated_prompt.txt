Model the member as an Euler–Bernoulli beam with small deflection, linear-elastic behavior, constant E and I, and prismatic geometry.
Use a simply supported (pin–roller) beam of span L = 3500 mm with coordinate x measured from the left support, 0 ≤ x ≤ L.
Use E = 200000 N/mm² and I = 3,000,000 mm⁴ so EI = 6.0×10¹¹ N·mm².
Apply a uniformly distributed load w = 0.3 N/mm downward over the full span 0 ≤ x ≤ L.
Apply a point load P = 1200 N downward at midspan x = L/2 = 1750 mm.
Assume no additional “other distributed load function” beyond the given UDL (i.e., set it to zero).
Neglect shear deformation and rotary inertia (Euler–Bernoulli assumptions).
Take downward deflection as positive (or state the chosen sign convention and use it consistently).

Compute deflection by superposition as v(x) = v_w(x) + v_P(x).
Use the standard closed-form deflection for a simply supported beam under full-span UDL:
v_w(x) = (w x (L³ − 2 L x² + x³)) / (24 EI).
Use the standard closed-form deflection for a simply supported beam under a central point load:
For 0 ≤ x ≤ L/2: v_P(x) = (P x (3 L² − 4 x²)) / (48 EI).
For L/2 ≤ x ≤ L: v_P(x) = (P (L − x) (3 L² − 4 (L − x)²)) / (48 EI).
Report the total deflection function v(x) by adding the above expressions piecewise.
Report the maximum deflection at midspan as v_max = v(L/2) = (5 w L⁴)/(384 EI) + (P L³)/(48 EI).
Optionally report support reactions for completeness: R_A = R_B = (w L)/2 + P/2.
Optionally report slope if needed using θ(x) = dv/dx applied to v(x) from superposition.
