Model the shaft as a prismatic, solid, circular, stepped shaft in torsion with small deformation and linear-elastic material behavior.
Assume Saint-Venant torsion applies in each segment (plane sections remain plane and no warping restraint effects are included).
Assume the applied torque is static, concentric with the shaft axis, and the only load (no transverse shear force, no bending, no axial load).
Assume perfect bonding/continuity at the step so internal torque is the same through AB and BC and the twist is compatible (twists add in series).
Use a constant shear modulus G for both segments.

Given geometry: segment AB has L1 = 400 mm and d1 = 30 mm.
Given geometry: segment BC has L2 = 700 mm and d2 = 30 mm.
Given loading: end A is fixed (θA = 0) and an end torque T = 600,000 N·mm is applied at end C.

Compute the polar second moment of area for each solid circular segment as J = (π d^4)/32.
For d = 30 mm, use J1 = J2 = (π (30 mm)^4)/32.

Internal torque in each segment is T1 = T2 = T.

Compute the torsional shear stress distribution in each segment using τ(r) = (T r)/J for 0 ≤ r ≤ d/2.
Compute the maximum torsional shear stress in each segment at the outer surface r = c = d/2 using τmax = (T c)/J = (16 T)/(π d^3).
With d1 = d2, τmax is the same in AB and BC.

Compute the twist rate in each segment using dθ/dx = T/(G J).
Compute the twist of each segment as θ1 = (T L1)/(G J1) and θ2 = (T L2)/(G J2).
Compute the total twist at end C relative to A as θtotal = θC − θA = θ1 + θ2 = T (L1/(G J1) + L2/(G J2)).
With J1 = J2, θtotal = (T (L1 + L2))/(G J).

Report response quantities as τ(r) and τmax for each segment, plus θ1, θ2, and θtotal.
