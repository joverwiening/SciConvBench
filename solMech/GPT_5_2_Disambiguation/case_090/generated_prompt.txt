Assume small deformation, linear-elastic, homogeneous, isotropic material behavior.
Assume both segments are perfectly bonded in series, coaxial, and carry the same axial force (no slip at the step).
Assume static loading, prismatic segments, and neglect stress concentrations at the diameter change (use average axial stress P/A in each segment).
Given axial tensile load P = 25,000 N, with the left end fixed and the load applied at the right end.
Given Segment 1: L1 = 300 mm, d1 = 12 mm.
Given Segment 2: L2 = 600 mm, d2 = 30 mm.
Given Young’s modulus E = 200,000 MPa = 200,000 N/mm^2, same for both segments.

Compute cross-sectional areas.
A1 = (π/4) d1^2 = (π/4)(12^2) = 113.097 mm^2.
A2 = (π/4) d2^2 = (π/4)(30^2) = 706.858 mm^2.

Use axial stress in each segment (average).
σ1 = P/A1 = 25,000 / 113.097 = 221.0 MPa (tension).
σ2 = P/A2 = 25,000 / 706.858 = 35.37 MPa (tension).

Use axial strain in each segment (Hooke’s law).
ε1 = σ1/E = 221.0 / 200,000 = 0.001105.
ε2 = σ2/E = 35.37 / 200,000 = 0.0001769.

Use elongation of each segment.
δ1 = (P L1)/(A1 E) = (25,000·300)/(113.097·200,000) = 0.3316 mm.
δ2 = (P L2)/(A2 E) = (25,000·600)/(706.858·200,000) = 0.1061 mm.

Total elongation (series sum).
δtotal = δ1 + δ2 = 0.3316 + 0.1061 = 0.4377 mm.
