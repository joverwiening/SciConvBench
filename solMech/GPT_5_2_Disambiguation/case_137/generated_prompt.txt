Model the member as a prismatic, straight Euler–Bernoulli beam with small deformation and linear elasticity.
Let the beam be simply supported at A (x = 0) and B (x = L), with L = 3000 mm.
Take x measured from A toward B.
Take positive shear V(x) as upward on the left face of a cut section.
Take positive bending moment M(x) as sagging (tension at the bottom fibers).
Apply a single concentrated load P = 12000 N downward at x = L/2 = 1500 mm.
Assume the supports provide only vertical reactions (no end moments), and neglect beam self-weight.
Assume static equilibrium (no dynamics).

Compute support reactions from global equilibrium.
Use ΣFy = 0: RA + RB − P = 0.
Use ΣMA = 0: RB·L − P·(L/2) = 0.
Solve: RB = P/2 = 6000 N.
Solve: RA = P/2 = 6000 N.

Define internal shear force V(x) using a cut at position x and equilibrium of the left segment.
For 0 < x < L/2: V(x) = RA = +6000 N.
For L/2 < x < L: V(x) = RA − P = 6000 − 12000 = −6000 N.
At x = L/2, V has a downward jump of magnitude P (i.e., V(L/2+) − V(L/2−) = −P).

Define internal bending moment M(x) using a cut at position x and equilibrium of the left segment.
For 0 ≤ x ≤ L/2: M(x) = RA·x = 6000 x (N·mm if x is in mm).
For L/2 ≤ x ≤ L: M(x) = RA·x − P·(x − L/2) = 6000 x − 12000(x − 1500) (N·mm).
Enforce simply supported boundary conditions: M(0) = 0 and M(L) = 0 (satisfied by the expressions above).

State the differential relations between load, shear, and moment for reference.
Let distributed load intensity be w(x) (positive upward); here w(x) = 0 except at the point load location.
Use dV/dx = w(x) (with point loads represented as jumps in V).
Use dM/dx = V(x).

Report key response quantities.
Maximum absolute shear magnitude is |V|max = 6000 N (occurs on either side of midspan).
Maximum bending moment occurs where V changes sign (at the point load location x = L/2).
Compute Mmax = M(L/2) = RA·(L/2) = (P/2)(L/2) = P L / 4 = 12000·3000/4 = 9.0×10^6 N·mm = 9.0 kN·m (sagging).
