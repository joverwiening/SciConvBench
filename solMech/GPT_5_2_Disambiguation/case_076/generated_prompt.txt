Model the member as a prismatic, straight Euler–Bernoulli beam with small deformation and linear-elastic behavior.
Assume the beam is simply supported with a pin at A and a roller at B.
Assume the load is applied statically and quasi-statically (no inertia effects).
Assume the beam self-weight is neglected.
Take x measured from A toward B with 0 ≤ x ≤ L, where L = 4000 mm.
Take positive shear V(x) as upward on the left face of a cut section.
Take positive bending moment M(x) as sagging (tension at the bottom fibers).

Use global equilibrium to find reactions.
Sum of vertical forces: RA + RB − P = 0.
Sum of moments about A: RB L − P (L/2) = 0.
Compute reactions: RA = RB = P/2 = 6000 N.

Define the internal shear force function V(x).
For 0 < x < L/2: V(x) = +RA = +6000 N.
At x = L/2: V has a negative jump of magnitude P (downward point load), so V(L/2+) = V(L/2−) − P = 6000 − 12000 = −6000 N.
For L/2 < x < L: V(x) = RA − P = −6000 N.
At x = L: V jumps up by RB to return to zero, consistent with equilibrium.

Define the internal bending moment function M(x) using dM/dx = V(x) with boundary condition M(0) = 0 for a simple support.
For 0 ≤ x ≤ L/2: M(x) = RA x = 6000 x (N·mm if x is in mm).
For L/2 ≤ x ≤ L: M(x) = RA x − P (x − L/2) = 6000 x − 12000 (x − 2000) (N·mm with x in mm).
Enforce the simple support condition at B: M(L) = 0, which is satisfied by the above expressions.

Report key response quantities.
Maximum bending moment occurs where V changes sign, at x = L/2.
Mmax = M(L/2) = RA (L/2) = 6000·2000 = 12,000,000 N·mm = 12 kN·m (sagging).
Maximum shear magnitude is |V|max = 6000 N, occurring on either side of the midspan point load.
