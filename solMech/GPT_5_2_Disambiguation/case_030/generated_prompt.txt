Assume small strains and small deformations.
Assume linear-elastic, homogeneous, isotropic material behavior.
Assume the rod is straight, prismatic, and initially stress-free.
Use a circular cross-section with initial diameter d0 = 25 mm.
Use an initial gauge length L0 = 1200 mm.
Apply a concentric axial tensile load P = 45,000 N through the centroid.
Assume no lateral load and no bending, so the stress state is uniaxial (σx ≠ 0, σy = σz = 0).
Neglect self-weight and temperature effects.
Use material properties E = 200,000 MPa and ν = 0.29.

Compute cross-sectional area A = (π/4) d0^2.
Compute axial (engineering) stress σx = P / A.
Compute axial strain εx = σx / E.
Compute lateral strains from Poisson effect εy = εz = −ν εx.
Compute axial elongation ΔL = εx L0.
Compute diameter change Δd = εy d0.
Compute final diameter d = d0 + Δd.
Compute volumetric strain εv = εx + εy + εz = εx (1 − 2ν).
State the governing constitutive relations for isotropic linear elasticity under uniaxial stress: εx = σx/E, εy = εz = −ν σx/E.
State the governing kinematic relations for small strain: εx = ΔL/L0 and εy = Δd/d0.
Report the relevant response quantities focusing on Poisson effect: εx, εy, εz, ΔL, Δd, and d.
