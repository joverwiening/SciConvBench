Use small-deformation, linear-elastic Euler–Bernoulli beam theory (plane sections remain plane and normal to the neutral axis; shear deformation neglected).
Model a prismatic, straight beam of span L = 4500 mm with constant flexural rigidity EI = 4.0×10^11 N·mm^2.
Apply a uniformly distributed transverse load q(x) = w = 0.3 N/mm over 0 ≤ x ≤ L, acting downward.
Use x measured from the left support (x = 0 at left support, x = L at right support).
Take positive deflection v(x) upward; therefore the applied load is q(x) = −w in the governing equation if using the sign convention EI v''''(x) = q(x).
Impose simply supported boundary conditions: v(0) = 0, v(L) = 0, bending moment M(0) = 0, bending moment M(L) = 0 (equivalently v''(0) = 0 and v''(L) = 0 with M = −EI v'').
Use the governing relations: V(x) = dM/dx, M(x) = −EI v''(x), and EI v''''(x) = q(x).
Use the standard closed-form response for a simply supported beam under full-span uniform load w (downward), with downward deflection taken as negative:
v(x) = −(w x (L^3 − 2 L x^2 + x^3)) / (24 EI), for 0 ≤ x ≤ L.
θ(x) = v'(x) = −(w (L^3 − 6 L x^2 + 4 x^3)) / (24 EI), for 0 ≤ x ≤ L.
The maximum deflection occurs at midspan x = L/2:
v_max = v(L/2) = −(5 w L^4) / (384 EI).
The slope at the supports is:
θ(0) = −(w L^3) / (24 EI), and θ(L) = +(w L^3) / (24 EI).
With the given values (w = 0.3 N/mm, L = 4500 mm, EI = 4.0×10^11 N·mm^2):
v_max = −(5·0.3·4500^4)/(384·4.0×10^11) mm = −3.999 mm (approximately −4.00 mm downward).
θ(0) = −(0.3·4500^3)/(24·4.0×10^11) rad = −0.002848 rad (approximately −0.163°).
θ(L) = +0.002848 rad (approximately +0.163°).
