Assume an Euler–Bernoulli beam with small deflections, linear-elastic material behavior, constant prismatic section, constant E and I, and neglect shear deformation and axial effects.
Use a simply supported beam of span L = 3000 mm with supports at x = 0 and x = L.
Apply a single concentrated load P = 800 N downward at a = 2000 mm from the left support.
Assume no applied end moments and no distributed loads.
Use E = 200000 MPa = 200000 N/mm² and I = 1,200,000 mm⁴ so EI = 2.4×10¹¹ N·mm².
Define the response quantity of interest as the vertical deflection at x = a in the downward direction, δ(a).

Compute support reactions from static equilibrium.
Use R_A = P(L − a)/L and R_B = Pa/L.
With L = 3000 mm and a = 2000 mm, use R_A = 800(1000)/3000 = 266.6667 N and R_B = 800(2000)/3000 = 533.3333 N.

Define the real bending moment function M(x) using Macaulay/piecewise form.
For 0 ≤ x < a, use M(x) = R_A x.
For a ≤ x ≤ L, use M(x) = R_A x − P(x − a).

Apply the unit-load method for deflection at x = a in the downward direction.
Apply a fictitious unit point load 1 N downward at x = a on the same simply supported beam.
Compute the corresponding unit-load reactions r_A = (L − a)/L and r_B = a/L.
With L = 3000 mm and a = 2000 mm, use r_A = 1/3 and r_B = 2/3.

Define the unit-load bending moment function m(x).
For 0 ≤ x < a, use m(x) = r_A x.
For a ≤ x ≤ L, use m(x) = r_A x − 1·(x − a).

Use the unit-load (virtual work) integral for deflection.
Use δ(a) = ∫₀ᴸ [M(x)m(x)/(EI)] dx.
Evaluate the integral piecewise over [0, a] and [a, L] using the above M(x) and m(x).

Use the closed-form result for a simply supported beam with a point load at x = a for the deflection at the load point.
Use δ(a) = P a² (L − a)² / (3 E I L).

Substitute the given values.
Use δ(a) = 800·(2000)²·(1000)² / (3·200000·1,200,000·3000) mm.
Compute δ(a) = 1.48148 mm downward.

Report the relevant response quantities for this case.
Report reactions R_A = 266.6667 N upward and R_B = 533.3333 N upward.
Report bending moment functions M(x) as defined piecewise.
Report unit-load moment functions m(x) as defined piecewise.
Report deflection at the load point δ(2000 mm) = 1.48148 mm downward.
