Use small-deformation, linear-elastic Euler–Bernoulli beam theory (plane sections remain plane; shear deformation neglected).
Use a prismatic beam with constant E and I along the span.
Use simply supported boundary conditions at x = 0 and x = L with L = 1800 mm, so v(0) = 0 and v(L) = 0.
Use a single concentrated load P = 2000 N acting downward at a = 900 mm from the left support.
Use E = 200000 N/mm^2 and I = 3,500,000 mm^4, so EI = 7.0×10^11 N·mm^2.
Take x measured from the left support, with positive deflection v(x) downward.

Compute support reactions from statics.
R_A = P(L − a)/L.
R_B = Pa/L.
For the given a = L/2, R_A = R_B = P/2.

Define the real bending moment function M(x) for the actual load.
For 0 ≤ x ≤ a: M(x) = R_A x.
For a ≤ x ≤ L: M(x) = R_A x − P(x − a).

Define the unit-load (virtual) system to obtain deflection at an arbitrary point x = ξ.
Apply a unit downward point load 1 at x = ξ on the same simply supported beam.
Compute the unit-load reactions.
r_A = (L − ξ)/L.
r_B = ξ/L.

Define the unit-load bending moment function m(x; ξ).
For 0 ≤ x ≤ ξ: m(x; ξ) = r_A x.
For ξ ≤ x ≤ L: m(x; ξ) = r_A x − 1·(x − ξ).

Use the unit-load (virtual work) relation for deflection at x = ξ.
v(ξ) = ∫_0^L [M(x) m(x; ξ)]/(EI) dx.

Evaluate the integral piecewise over the intervals split by x = a and x = ξ (i.e., integrate over 0→min(a,ξ), min(a,ξ)→max(a,ξ), and max(a,ξ)→L using the appropriate expressions for M and m on each sub-interval).

For the special case where the evaluation point is at midspan (ξ = a = L/2), the closed-form deflection is:
v(L/2) = P L^3 /(48 EI).

With the given values, the midspan deflection magnitude is:
v(900 mm) = (2000)(1800^3) / (48·7.0×10^11) mm = 0.347 mm downward.

Relevant response quantities for this case are:
Support reactions R_A and R_B.
Shear force V(x) derived from equilibrium (piecewise constant with a jump of magnitude P at x = a).
Bending moment M(x) as given above (piecewise linear with a slope change at x = a).
Deflection at an arbitrary point v(ξ) obtained from v(ξ) = ∫_0^L [M m]/(EI) dx using the unit-load system defined above.
Slope (rotation) can be obtained similarly by using a unit moment at x = ξ if needed, via θ(ξ) = ∫_0^L [M(x) m_θ(x; ξ)]/(EI) dx, where m_θ is the bending moment diagram from the unit moment.
