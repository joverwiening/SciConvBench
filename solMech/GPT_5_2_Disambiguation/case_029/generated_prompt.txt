Assume small-deformation, linear-elastic, homogeneous, isotropic material behavior.
Assume the rod is prismatic with a circular cross-section of initial diameter d0 = 20 mm.
Assume the rod is subjected only to a centric axial tensile force P = 25,000 N (no lateral load).
Assume Saint-Venant/uniform uniaxial stress away from load introduction regions.
Use Young’s modulus E = 105,000 MPa and Poisson’s ratio ν = 0.34.
Compute initial cross-sectional area as A0 = (π/4) d0^2.
Compute axial (engineering) normal stress as σz = P / A0.
Assume plane stress in the transverse directions for a free lateral surface: σx = 0 and σy = 0.
Use 3D isotropic Hooke’s law in compliance form: εx = (1/E)[σx − ν(σy + σz)], εy = (1/E)[σy − ν(σx + σz)], εz = (1/E)[σz − ν(σx + σy)].
With σx = σy = 0, reduce to uniaxial relations: εz = σz / E and εx = εy = −ν σz / E.
Define Poisson effect as the ratio of transverse to axial strain under uniaxial loading: ν = −εtrans/εaxial, where εtrans = εx = εy and εaxial = εz.
Compute transverse (diametral) engineering strain as εd = Δd / d0 = εx = εy.
Compute diameter change as Δd = εd d0 = (−ν σz / E) d0.
If needed, compute axial elongation using the rod length L: ΔL = εz L = (σz / E) L.
If needed, compute volumetric strain under uniaxial stress as εv = εx + εy + εz = (1 − 2ν) σz / E.
State sign convention: tensile stress/strain positive; transverse strain under tension is negative (contraction).
