Assume small-deformation, linear-elastic, isotropic material behavior.
Assume Saint-Venant torsion of circular shafts applies (plane sections remain plane and circular; warping effects neglected).
Assume the shaft is solid, perfectly bonded at the step, and the applied torque is static.
Assume no transverse shear forces act (torsion-only), so the internal torque is constant along the shaft.
Use units N–mm–MPa consistently.

Geometry is a stepped solid circular shaft with two segments in series.
Segment AB has length L1 = 400 mm and diameter d1 = 25 mm.
Segment BC has length L2 = 900 mm and diameter d2 = 30 mm.

Boundary conditions are end A fixed (zero twist at A) and an applied torque at end C of T = 750,000 N·mm.
Internal torque in each segment is T1 = T2 = T.

Material property is shear modulus G = 25,939.8 MPa.

Compute polar second moment of area for each solid circular segment as J = (π d^4)/32.
Compute maximum torsional shear stress in each segment as τ_max = T c / J with c = d/2, equivalently τ_max = 16 T / (π d^3).
Report τ_max,AB using d1 and τ_max,BC using d2.
If needed, report shear stress at radius r as τ(r) = T r / J for 0 ≤ r ≤ d/2.

Compute angle of twist of each segment as φ_i = T L_i / (G J_i).
Compute total twist from A to C as φ_total = φ_AB + φ_BC.
Compute twist at the step B relative to A as φ_B = φ_AB.
Report twists in radians (and optionally convert to degrees using 180/π).

Numerical results:
J1 = (π/32)(25^4) = 38,349.52 mm^4.
J2 = (π/32)(30^4) = 79,521.56 mm^4.
τ_max,AB = 16(750,000)/(π 25^3) = 244.46 MPa.
τ_max,BC = 16(750,000)/(π 30^3) = 141.47 MPa.
φ_AB = (750,000)(400)/(25,939.8)(38,349.52) = 0.3018 rad = 17.29 deg.
φ_BC = (750,000)(900)/(25,939.8)(79,521.56) = 0.3274 rad = 18.76 deg.
φ_total = 0.6292 rad = 36.05 deg.
