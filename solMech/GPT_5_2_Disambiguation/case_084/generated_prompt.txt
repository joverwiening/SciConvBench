Assume small-deformation, linear-elastic behavior.
Model the member as a built-up beam consisting of a flange plate connected to a web.
Assume the flange and web are connected along a single flange–web interface line with discrete fasteners.
Assume the connection is designed so that the fasteners carry the longitudinal shear transfer required by beam shear flow at the interface.
Assume the given section properties are valid at the cross-section of interest and about the neutral axis.
Use the provided second moment of area I = 18,000,000 mm^4.
Use the provided first moment of area for the flange–web interface Q = 45,000 mm^3.
Use the provided internal shear force at the cross-section V = 25,000 N.
Compute the interface shear flow using q = VQ/I.
Maintain unit consistency so that q is obtained in N/mm when V is in N and Q and I are in mm^3 and mm^4.
Calculate q = (25,000 N)(45,000 mm^3)/(18,000,000 mm^4) = 62.5 N/mm.
Use the provided allowable shear capacity per fastener P_allow = 1800 N per fastener.
Assume a single row of fasteners along the interface so that the force transferred per fastener equals q·s, where s is the fastener spacing along the beam.
Size the spacing by q·s ≤ P_allow.
Compute the maximum allowable spacing s_max = P_allow/q = 1800 N / (62.5 N/mm) = 28.8 mm.
Specify the required fastener spacing as s ≤ 28.8 mm (select a practical standard spacing not exceeding this value).
