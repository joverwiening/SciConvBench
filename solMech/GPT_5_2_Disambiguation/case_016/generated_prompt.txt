Model the member as a straight, prismatic Euler–Bernoulli cantilever beam of length L = 800 mm with constant E = 69,000 N/mm² and I = 1,600,000 mm⁴.
Use small-deformation, linear-elastic behavior and neglect shear deformation (Euler–Bernoulli assumption), rotary inertia, and axial effects.
Take x measured from the fixed end (x = 0) to the free end (x = L).
Apply a downward point load P = 2500 N at the free end x = L.
Apply no end moment at the free end, i.e., M_end = 0 N·mm.
Use the sign convention where downward deflection is negative, and sagging bending moment is positive (consistent with EI v'' = M).
Compute flexural rigidity as EI = E I = 69,000 × 1,600,000 = 1.104×10^11 N·mm².
Use the Euler–Bernoulli governing relation EI d^4v/dx^4 = w(x), with w(x) = 0 for 0 < x < L (no distributed load).
Use internal force relations V(x) = dM/dx and M(x) = EI d^2v/dx^2.
For an end point load with no distributed load, use shear force V(x) = −P for 0 ≤ x ≤ L.
For an end point load with no distributed load, use bending moment M(x) = −P (L − x) for 0 ≤ x ≤ L.
Apply cantilever boundary conditions at the fixed end: v(0) = 0 and dv/dx(0) = 0.
Apply free-end boundary conditions consistent with the applied end moment and end shear: M(L) = 0 and V(L) = −P.
Obtain slope (rotation) distribution as θ(x) = dv/dx = −(P/(2EI)) (2Lx − x^2).
Obtain deflection distribution as v(x) = −(P/(6EI)) (3Lx^2 − x^3).
Compute free-end slope as θ(L) = −P L^2/(2EI).
Compute free-end deflection magnitude as δ = |v(L)| = P L^3/(3EI).
Evaluate numerically: δ = 2500 × 800^3 / (3 × 1.104×10^11) mm = 3.86 mm (downward).
Evaluate numerically: θ(L) = −2500 × 800^2 / (2 × 1.104×10^11) rad = −0.00725 rad (≈ −0.415°).
