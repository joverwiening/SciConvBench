Use small-deformation, linear-elastic assumptions, but compute stresses only (no strains).
Model the stress state at the section as uniform plane stress with σx = P/A and τxy = V/A.
Take σy = 0 and τyx = τxy, with all out-of-plane stresses zero (σz = τxz = τyz = 0).
Use A = b h = (40 mm)(120 mm) = 4800 mm^2.
Compute average normal stress as σx = P/A = 40000 N / 4800 mm^2 = 8.33 MPa (tension).
Compute average shear stress as τxy = V/A = 8000 N / 4800 mm^2 = 1.67 MPa.
Compute in-plane principal stresses from σ1,2 = (σx + σy)/2 ± sqrt(((σx − σy)/2)^2 + τxy^2).
With σy = 0, compute σavg = (σx + σy)/2 = 4.165 MPa and R = sqrt((σx/2)^2 + τxy^2) = sqrt(4.165^2 + 1.67^2) = 4.487 MPa.
Report principal stresses as σ1 = σavg + R = 8.65 MPa and σ2 = σavg − R = −0.322 MPa.
Compute maximum in-plane shear stress as τmax,in-plane = R = 4.49 MPa.
Optionally report principal plane orientation using tan(2θp) = 2τxy/(σx − σy) = 2(1.67)/8.33 = 0.400, giving 2θp = 21.8° and θp = 10.9° (measured from the x-plane to the σ1 principal plane, sign per τxy convention).
