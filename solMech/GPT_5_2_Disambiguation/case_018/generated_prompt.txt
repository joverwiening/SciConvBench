Use small-deformation, linear-elastic torsion of a prismatic, solid circular shaft.
Use a right-handed sign convention where positive torque produces positive twist about the shaft axis.
Model the shaft as a 1D torsion member along x with x = 0 fixed and x = L = 1500 mm free.
Use diameter d = 40 mm, radius r = 20 mm, and shear modulus G = 25939.8 MPa (N/mm²).
Assume no transverse shear force and no bending: V(x) = 0 and M(x) = 0 everywhere.
Assume Saint-Venant torsion applies (no warping restraint effects) and the shaft is uniform (constant J).
Compute polar moment of area for a solid circle as J = (π d^4)/32 = (π r^4)/2.
Define the intermediate torque location as a = 750 mm.
Apply concentrated torques T2 = −150000 N·mm at x = a and T1 = +300000 N·mm at x = L.
Enforce global torque equilibrium to obtain the fixed-end reaction torque Tr at x = 0: Tr + T2 + T1 = 0.
Compute Tr = −(T1 + T2) = −(300000 − 150000) N·mm = −150000 N·mm.
Define internal torque T(x) as the algebraic sum of external torques to the right of the cut (or equivalently enforce piecewise equilibrium consistently with the chosen sign convention).
For segment 2 (a < x < L), internal torque is T(x) = T1 = +300000 N·mm.
For segment 1 (0 < x < a), internal torque is T(x) = T1 + T2 = +150000 N·mm.
Report the internal torque diagram as piecewise constant with a jump of magnitude T2 at x = a and a jump of magnitude T1 at x = L.
Compute maximum torsional shear stress in each segment using τmax = |T| r / J.
Use τmax,1 = |Tsegment1| r / J with Tsegment1 = 150000 N·mm.
Use τmax,2 = |Tsegment2| r / J with Tsegment2 = 300000 N·mm.
Compute twist rate using dθ/dx = T(x)/(G J).
Compute twist of segment 1 as θ1 = (Tsegment1 a)/(G J).
Compute twist of segment 2 as θ2 = (Tsegment2 (L − a))/(G J).
Compute free-end twist relative to the fixed end by summation: θ(L) = θ1 + θ2.
Report θ(L) in radians (and optionally degrees via θdeg = θ(rad)·180/π).
Do not use Young’s modulus E or Poisson’s ratio ν because pure torsion with given G is sufficient under the stated assumptions.
