Use small-deformation, linear-elastic torsion theory for a prismatic, uniform, solid circular shaft.
Assume Saint-Venant torsion with plane cross-sections remaining plane and no warping restraint effects.
Assume the applied torque is constant along the full length and the shaft is free of stress concentrations (no keyways, shoulders, or fillets).
Given L = 1200 mm.
Given T = 800,000 N·mm.
Given G = 77,519.4 MPa = 77,519.4 N/mm^2.
Given allowable twist φ_allow = 1.0° = (1.0·π/180) rad.
Use the torsion angle-of-twist relation φ = T L / (J G).
For a solid circular shaft, use polar second moment J = (π d^4)/32.
Impose the design constraint φ ≤ φ_allow.
Solve for diameter: d ≥ [32 T L / (π G φ_allow)]^(1/4).
Compute the required diameter using the given values: d ≥ [32(800,000)(1200) / (π(77,519.4)(π/180))]^(1/4) mm.
Evaluate numerically: d ≥ 38.6 mm.
Select a practical design diameter d_design ≥ 38.6 mm (e.g., 39 mm or the next standard size).
Report the corresponding torsional stiffness k_t = T/φ = JG/L for the selected diameter.
Optionally report the maximum torsional shear stress at the outer surface for the selected diameter using τ_max = T c / J with c = d/2, giving τ_max = 16T/(π d^3).
