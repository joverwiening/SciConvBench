Assume small deformation, linear-elastic, homogeneous, isotropic behavior for each bar.
Assume both bars are perfectly bonded to the rigid plates so the end displacements are identical (no slip), implying equal axial elongation in both bars.
Assume the rigid plates remain rigid and parallel so the axial strain is uniform in each bar.
Assume concentric axial loading so bending and shear are neglected and each bar carries only axial force.
Given total applied tensile load P = 20,000 N shared by two parallel bars between rigid plates.
Given Bar 1: E1 = 200,000 MPa, A1 = 300 mm^2, L = 500 mm.
Given Bar 2: E2 = 69,000 MPa, A2 = 200 mm^2, L = 500 mm.
Use consistent units: 1 MPa = 1 N/mm^2, so E in MPa with A in mm^2 gives stiffness in N/mm.

Define unknown internal axial forces N1 and N2 in bars 1 and 2.
Apply force equilibrium on the loaded rigid plate: N1 + N2 = P.
Apply compatibility (parallel composite bars): Δ1 = Δ2 = Δ, equivalently ε1 = ε2 = ε.
Use linear axial constitutive/kinematic relations for each bar: σi = Ei εi, εi = Δ/L, σi = Ni/Ai.
Combine to get bar force–elongation relation: Ni = (Ei Ai / L) Δ.
Define axial stiffness of each bar: ki = Ei Ai / L.
Compute stiffnesses: k1 = (200,000 N/mm^2)(300 mm^2)/(500 mm) = 120,000 N/mm.
Compute stiffnesses: k2 = (69,000 N/mm^2)(200 mm^2)/(500 mm) = 27,600 N/mm.
Compute total parallel stiffness: keq = k1 + k2 = 147,600 N/mm.
Compute common elongation from P = keq Δ: Δ = P/keq = 20,000/147,600 = 0.1355 mm.
Compute common strain: ε = Δ/L = 0.1355/500 = 2.71×10^-4.

Compute load share using stiffness proportion: N1 = (k1/keq) P = (120,000/147,600)(20,000) = 16,260 N.
Compute load share using stiffness proportion: N2 = (k2/keq) P = (27,600/147,600)(20,000) = 3,740 N.
Report axial stresses: σ1 = N1/A1 = 16,260/300 = 54.2 MPa (tension).
Report axial stresses: σ2 = N2/A2 = 3,740/200 = 18.7 MPa (tension).
Check consistency with Hooke’s law: σ1/E1 ≈ 54.2/200,000 = 2.71×10^-4 and σ2/E2 ≈ 18.7/69,000 = 2.71×10^-4, matching compatibility.

Relevant response quantities for composite bars in parallel under prescribed total axial force are: common elongation Δ, common strain ε, individual bar forces N1 and N2, individual stresses σ1 and σ2, and equivalent axial stiffness keq.
