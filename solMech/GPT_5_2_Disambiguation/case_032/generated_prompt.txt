Use small-deformation, linear-elastic Euler–Bernoulli beam theory.
Model a simply supported prismatic beam of span L = 3000 mm with constant flexural rigidity EI = 7.0×10^11 N·mm^2.
Apply a single concentrated load P = 1500 N downward at midspan x = L/2.
Assume no additional distributed transverse load (w(x)=0) and no applied end moments.
Assume supports provide zero vertical deflection at x=0 and x=L and allow free rotation (simple supports).
Use the Euler–Bernoulli governing relation EI·v''''(x) = w(x), with w(x)=0 on (0,L/2) and (L/2,L), and enforce the point-load jump condition on shear: V(L/2^+) − V(L/2^−) = −P.
Use symmetry about midspan for this loading: v'(L/2)=0 and reactions R_A = R_B = P/2.
Use internal moment for 0 ≤ x ≤ L/2: M(x) = R_A x = (P/2)x.
Use internal moment for L/2 ≤ x ≤ L: M(x) = R_B (L−x) = (P/2)(L−x).
Relate curvature to moment: EI·v''(x) = M(x) with sign convention consistent with downward deflection positive (final magnitudes below are unaffected).
Midspan deflection magnitude for a simply supported beam with a central point load is δ_mid = P L^3 / (48 EI).
Support slope magnitude for a simply supported beam with a central point load is |θ_support| = P L^2 / (16 EI), with θ(0)=−P L^2/(16EI) and θ(L)=+P L^2/(16EI) under the usual sign convention.
Compute δ_mid = (1500)(3000^3) / (48·7.0×10^11) mm = 1.205 mm downward.
Compute |θ_support| = (1500)(3000^2) / (16·7.0×10^11) rad = 0.001205 rad (≈ 0.0691°).
