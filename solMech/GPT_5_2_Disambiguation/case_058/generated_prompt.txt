Assume a straight, prismatic column with small deformations and linear-elastic isotropic material behavior.
Assume the column is initially perfectly straight with concentric axial loading (no initial imperfection or eccentricity) for the Euler critical load calculation.
Assume buckling occurs about the axis associated with the provided second moment of area I = 1,200,000 mm^4.
Use fixed–pinned end conditions represented by effective length factor K = 0.7.
Use column length L = 2000 mm.
Use Young’s modulus E = 200,000 MPa = 200,000 N/mm^2.
Compute the effective buckling length as Le = K L = 0.7 × 2000 mm = 1400 mm.
Compute the Euler critical buckling load as Pcr = (pi^2 E I) / (Le^2) = (pi^2 E I) / ((K L)^2).
Evaluate numerically: Pcr = (pi^2 × 200,000 N/mm^2 × 1,200,000 mm^4) / (1400 mm)^2.
Report the result: Pcr ≈ 1.21 × 10^6 N = 1.21 MN (approximately 1210 kN).
Treat the applied compressive load P as an input not provided in the requirement.
Define the elastic buckling utilization (instability check) as eta = P / Pcr.
State the buckling check criterion as stable if eta < 1 and at the Euler bifurcation point if eta = 1 (predicted elastic buckling onset).
If a factor of safety is required but not specified, express it generically as FS = Pcr / P and leave it unevaluated until P is provided.
