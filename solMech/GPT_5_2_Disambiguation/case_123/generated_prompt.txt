Assume a straight, prismatic, homogeneous, isotropic AISI rod of length L and constant cross-sectional area A.
Assume small strain, linear elasticity, and 1D axial (uniaxial) stress/strain state with no bending.
Assume uniform temperature change along the rod: ΔT = 50°C for 0 ≤ x ≤ L.
Assume no external axial mechanical load is applied (no prescribed end force; only thermal loading).
Impose full axial restraint by rigid, unyielding supports: u(0) = 0 and u(L) = 0, hence total elongation ΔL = 0.
Use the additive strain decomposition: ε(x) = εm(x) + εth(x).
Define free thermal strain (unrestrained): εth = α ΔT, where α is the coefficient of thermal expansion.
Relate mechanical strain to stress: εm = σ/E, where E is Young’s modulus.
Write the total strain-displacement relation: ε = du/dx.
Apply the restraint condition in strain form: ΔL = ∫0L ε dx = 0, and for uniform fields this reduces to ε = 0 everywhere.
Conclude that under full restraint with uniform ΔT, the total axial strain is ε = 0.
Compute the mechanical strain required to enforce ε = 0: εm = −εth = −α ΔT.
Compute the resulting uniform axial stress: σ = E εm = −E α ΔT.
Compute the resulting uniform internal axial force (reaction force): N = σ A = −E A α ΔT.
State sign convention: for ΔT > 0, σ < 0 and N < 0 indicate compressive stress/force under the usual tension-positive convention.
Report the relevant response quantities for “thermal strain with full axial restraint” as εth = α ΔT, εm = −α ΔT, ε = 0, σ = −E α ΔT, and N = −E A α ΔT.
Assume material properties (E, α) are constant over the temperature change and that no yielding, creep, or thermal gradients occur.
