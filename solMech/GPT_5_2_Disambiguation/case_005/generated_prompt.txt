Model the member as a 1D prismatic axial bar on 0 ≤ x ≤ L with L = 1800 mm.
Use small-deformation, linear-elastic behavior with constant E = 200,000 MPa and constant cross-sectional area A = 200 mm^2.
Use the sign convention: axial force N(x) is positive in tension; displacement u(x) is positive to the right; applied point loads are positive to the right.
Apply boundary condition u(0) = 0 at end A (x = 0).
Apply point loads at xB = 700 mm: PB = +18,000 N; at xC = 1300 mm: PC = −8,000 N; at xD = 1800 mm: PD = +20,000 N.
Assume no distributed axial load along the bar (b(x) = 0) and neglect self-weight.
Assume the end at x = 1800 mm is not displacement-prescribed; the only action there is the applied point load PD.

Compute the global axial reaction at A from overall axial equilibrium: RA + PB + PC + PD = 0.
Use the 1D axial equilibrium relation away from point loads: dN/dx + b(x) = 0, which reduces to dN/dx = 0 on each open interval (0,700), (700,1300), (1300,1800).
Represent point loads as jumps in internal axial force: N(xi+) − N(xi−) = −Pi at xi ∈ {700,1300,1800}.
Construct the piecewise-constant internal axial force N(x) using RA at x = 0 and the jump conditions at B, C, and D.
Compute axial stress as a piecewise-constant field: σ(x) = N(x)/A.
Compute axial strain as a piecewise-constant field: ε(x) = σ(x)/E = N(x)/(E A).
Use the kinematic relation ε(x) = du/dx.
Compute displacement by integrating on each segment: u(x) = u(0) + ∫0x N(s)/(E A) ds, enforcing continuity of u at x = 700 mm and x = 1300 mm.
Report segment elongations: ΔAB = ∫0^700 N/(E A) dx, ΔBC = ∫700^1300 N/(E A) dx, ΔCD = ∫1300^1800 N/(E A) dx.
Report nodal displacements uB = u(700), uC = u(1300), uD = u(1800).
