Assume small deformation, linear-elastic, homogeneous, isotropic material behavior with constant Young’s modulus E = 200,000 MPa.
Assume the bar is axially loaded in tension by a static, concentric force P = 25,000 N, with the left end fixed and the right end pulled.
Assume each segment is prismatic with constant circular cross-section and the load path is purely axial (no bending, shear, or torsion).
Assume stress concentrations at the diameter step are neglected and each segment is treated by 1D axial bar theory.
Use consistent N–mm–MPa units: 1 MPa = 1 N/mm².

Given geometry: Segment 1 has L1 = 400 mm and d1 = 16 mm.
Given geometry: Segment 2 has L2 = 400 mm and d2 = 40 mm.

Compute cross-sectional areas: A1 = (π/4) d1² and A2 = (π/4) d2².
Numerically, A1 = (π/4)(16²) = 201.06 mm².
Numerically, A2 = (π/4)(40²) = 1256.64 mm².

Internal axial force is constant along the bar: N1 = N2 = P.

Average normal stress in each segment: σi = P / Ai.
Numerically, σ1 = 25,000 / 201.06 = 124.34 MPa (tension).
Numerically, σ2 = 25,000 / 1256.64 = 19.89 MPa (tension).

Axial strain in each segment (Hooke’s law): εi = σi / E.
Numerically, ε1 = 124.34 / 200,000 = 6.217×10^-4.
Numerically, ε2 = 19.89 / 200,000 = 9.947×10^-5.

Elongation of each segment: δi = (P Li) / (Ai E) = εi Li.
Numerically, δ1 = (25,000·400) / (201.06·200,000) = 0.2487 mm.
Numerically, δ2 = (25,000·400) / (1256.64·200,000) = 0.03979 mm.

Total elongation of the stepped bar (series sum): δtotal = δ1 + δ2.
Numerically, δtotal = 0.2487 + 0.03979 = 0.2885 mm.
