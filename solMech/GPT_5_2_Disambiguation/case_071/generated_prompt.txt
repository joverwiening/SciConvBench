Assume small-deformation, linear-elastic, homogeneous, isotropic material behavior.
Assume plane stress at the section: σz = τxz = τyz = 0.
Assume the given internal resultants produce uniform average stresses over the rectangular area (use average normal stress and average shear stress).
Use the rectangular cross-section dimensions b = 50 mm and h = 80 mm, giving area A = b h = 4000 mm².
Use axial force P = 40,000 N (tension) to compute average normal stress σx = P/A.
Use shear force V = 12,000 N acting parallel to the width (b-direction) to compute average in-plane shear stress τxy = V/A.
Compute σx = 40,000 N / 4000 mm² = 10 N/mm² = 10 MPa.
Compute τxy = 12,000 N / 4000 mm² = 3 N/mm² = 3 MPa.
Set σy = 0 MPa unless an additional transverse normal stress is specified.
Represent the in-plane stress state as [σx σy τxy] = [10 MPa 0 MPa 3 MPa].
Compute principal stresses for plane stress using σ1,2 = (σx+σy)/2 ± sqrt(((σx−σy)/2)² + τxy²).
Evaluate (σx+σy)/2 = 5 MPa and sqrt(((σx−σy)/2)² + τxy²) = sqrt(25+9) = 5.83095 MPa.
Report σ1 = 10.83095 MPa and σ2 = −0.83095 MPa.
Compute maximum in-plane shear stress as τmax,in-plane = sqrt(((σx−σy)/2)² + τxy²) = 5.83095 MPa.
Compute principal plane orientation using tan(2θp) = 2τxy/(σx−σy) = 6/10 = 0.6, giving 2θp = arctan(0.6) and θp = 15.482° (principal direction for σ1 measured from the x-axis).
Compute maximum in-plane shear plane orientation using θs = θp + 45° = 60.482°.
If strain results are required, assume structural steel with E = 200,000 MPa and ν = 0.30.
Use plane-stress Hooke’s law: εx = (1/E)(σx − νσy), εy = (1/E)(σy − νσx), γxy = τxy/G.
Use shear modulus G = E/(2(1+ν)) = 200,000/(2·1.3) = 76,923.08 MPa.
Compute εx = (1/200,000)(10 − 0.3·0) = 5.0×10⁻⁵.
Compute εy = (1/200,000)(0 − 0.3·10) = −1.5×10⁻⁵.
Compute γxy = 3/76,923.08 = 3.9×10⁻⁵.
Compute principal strains using ε1,2 = (εx+εy)/2 ± sqrt(((εx−εy)/2)² + (γxy/2)²).
Evaluate (εx+εy)/2 = 1.75×10⁻⁵ and sqrt(((εx−εy)/2)² + (γxy/2)²) = 3.52136×10⁻⁵.
Report ε1 = 5.27136×10⁻⁵ and ε2 = −1.77136×10⁻⁵.
Compute maximum in-plane engineering shear strain as γmax,in-plane = 2·sqrt(((εx−εy)/2)² + (γxy/2)²) = 7.04272×10⁻⁵.
Optionally report out-of-plane strain under plane stress as εz = −(ν/E)(σx+σy) = −(0.3/200,000)(10) = −1.5×10⁻⁵.
State that all stress results (σ1, σ2, τmax,in-plane, θp) depend only on σx, σy, τxy, while strain results additionally depend on E and ν.
