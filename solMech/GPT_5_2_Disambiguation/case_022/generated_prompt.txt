Use small-deformation, linear-elastic torsion of circular shafts.
Use N–mm–MPa units consistently.
Model a stepped solid circular shaft with two prismatic segments in series: AB and BC.
Take segment AB length L1 = 300 mm and diameter d1 = 25 mm.
Take segment BC length L2 = 700 mm and diameter d2 = 30 mm.
Use shear modulus G = 77519.4 MPa (i.e., N/mm^2).
Assume Saint-Venant torsion with uniform twist rate in each prismatic segment.
Assume the applied torque is concentric with the shaft axis and produces pure torsion (no bending).
Assume no stress concentrations at the diameter step (use nominal torsion formulas).
Fix end A against rotation so θA = 0.
Apply torque T = 450000 N·mm at end C.
Take internal torque to be constant along the shaft: T(x) = 450000 N·mm in both segments.

Compute polar second moment of area for each solid circular segment as J = (π d^4)/32.
Compute J1 = (π d1^4)/32 for segment AB and J2 = (π d2^4)/32 for segment BC.

Compute maximum torsional shear stress in each segment using τmax = T c / J with c = d/2.
Equivalently compute τmax = 16 T / (π d^3).
Report τmax,AB using d1 and τmax,BC using d2.
State that the shear stress varies linearly with radius: τ(r) = T r / J for 0 ≤ r ≤ d/2.

Compute angle of twist of each segment using θ = T L / (G J).
Compute θAB = T L1 / (G J1).
Compute θBC = T L2 / (G J2).

Compute total twist between A and C by summing segment twists:
θAC = θAB + θBC.
Report θAC in radians (and optionally convert to degrees using 180/π).

If needed, compute torsional rigidity of each segment as (GJ/L) and note that the torque is the same while twist partitions according to compliance L/(GJ).
