Assume a straight, prismatic, solid circular shaft of diameter d = 25 mm subjected to a concentric axial tensile force P = +15,000 N and a torque T = +400,000 N·mm.
Assume small deformation, linear elastic behavior, homogeneous isotropic material, and Saint-Venant torsion for a circular shaft.
Assume the axial load produces uniform normal stress over the cross-section and the torque produces a linearly varying shear stress with radius.
Neglect stress concentrations, warping restraint effects, and any bending or transverse shear.
Use a right-handed coordinate system with x along the shaft axis and the stress state evaluated at a point on the outer surface (r = c) unless otherwise stated.
Define c = d/2.
Compute cross-sectional area A = (π/4)d^2.
Compute polar second moment of area J = (π/32)d^4.
Compute axial normal stress σx = P/A (tension positive).
Compute torsional shear stress distribution τxθ(r) = T r / J, with outer-surface magnitude τmax = T c / J.
At the outer surface, take the in-plane stress components as σx = P/A, σθ = 0, and τxθ = τmax (plane stress at the free surface).
Compute principal stresses at the outer surface from σ1,2 = (σx + σθ)/2 ± sqrt(((σx − σθ)/2)^2 + τxθ^2), with σ3 = 0 for plane stress.
Compute maximum in-plane shear stress τmax,in-plane = sqrt(((σx − σθ)/2)^2 + τxθ^2).
Compute principal stress orientation (angle from the x-axis in the x–θ plane) using tan(2φp) = 2τxθ/(σx − σθ).
If principal strains are requested, require material properties E and ν and use plane-stress Hooke’s law: εx = (1/E)(σx − νσθ), εθ = (1/E)(σθ − νσx), and γxθ = τxθ/G with G = E/[2(1+ν)].
Compute principal strains from ε1,2 = (εx + εθ)/2 ± sqrt(((εx − εθ)/2)^2 + (γxθ/2)^2), with ε3 = −(ν/E)(σx + σθ) for plane stress.
Report numerical values for A, J, σx, τmax, σ1, σ2, σ3, τmax,in-plane, and φp at r = c using the given P, T, and d.
If any strain quantities are requested numerically, adopt typical steel properties only then (for example E = 200 GPa and ν = 0.30) and state them explicitly.
