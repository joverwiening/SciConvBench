Assume a straight, prismatic, solid circular shaft of constant diameter d = 30 mm and length L = 1000 mm.
Assume small deformation, linear-elastic, homogeneous, isotropic material behavior with shear modulus G = 76,923.1 N/mm².
Assume Saint-Venant torsion of a circular shaft so cross-sections remain plane and undistorted (no warping effects for a solid circular section).
Assume the shaft is subjected to a constant applied torque T = 250,000 N·mm about its longitudinal axis.
Use consistent units N and mm so stresses are in N/mm² (MPa) and rotations are in radians.

Compute the polar second moment of area for a solid circular shaft as J = (π d^4) / 32.
For d = 30 mm, J = (π (30 mm)^4) / 32 = 79,521.6 mm^4.

Define the torsional shear stress distribution as τ(r) = (T r) / J for 0 ≤ r ≤ d/2.
Define the maximum shear stress at the outer surface r = d/2 as τ_max = (T (d/2)) / J = (16 T) / (π d^3).
For the given values, τ_max = (16·250,000) / (π·30^3) = 47.16 N/mm² (MPa).

Define the angle of twist over length L as φ = (T L) / (J G).
For the given values, φ = (250,000·1000) / (79,521.6·76,923.1) = 0.04084 rad.
Convert to degrees if needed using φ_deg = φ·(180/π), giving φ = 2.340 degrees.
