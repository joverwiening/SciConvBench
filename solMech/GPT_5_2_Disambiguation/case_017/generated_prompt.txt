Use small-deformation, linear-elastic Euler–Bernoulli beam theory with constant E and I.
Model a prismatic beam of span L = 3000 mm with simply supported boundary conditions at x = 0 (pin) and x = L (roller).
Take the transverse deflection as v(x), positive upward, with downward loads taken as negative in q(x).
Assume plane sections remain plane and normal to the neutral axis (Euler–Bernoulli), neglect shear deformation and rotary inertia.
Use E = 200000 N/mm² and I = 3,000,000 mm⁴, so EI = 6.0×10^11 N·mm².
Apply a uniformly distributed load w = 0.3 N/mm downward over 0 ≤ x ≤ L.
Apply a point load P = 1200 N downward at x = L/2 = 1500 mm.
Assume no additional distributed load beyond the given UDL (i.e., the “other distributed load function” is taken as zero).

Define the total load as q(x) = −w for 0 < x < L plus a concentrated load −P at x = L/2.
Use the Euler–Bernoulli governing relation EI v''''(x) = q(x) in the distributional sense, or equivalently use standard closed-form deflection solutions and superposition.
Impose simply supported deflection boundary conditions v(0) = 0 and v(L) = 0.
Impose simply supported moment boundary conditions M(0) = 0 and M(L) = 0, with M(x) = −EI v''(x).

Compute deflection by superposition as v(x) = v_w(x) + v_P(x).
For the full-span UDL component, use the standard simply supported deflection:
v_w(x) = −(w x (L^3 − 2 L x^2 + x^3)) / (24 EI) for 0 ≤ x ≤ L.
For the midspan point load component, use the standard simply supported deflection (piecewise):
For 0 ≤ x ≤ L/2: v_P(x) = −(P x (3 L^2 − 4 x^2)) / (48 EI).
For L/2 ≤ x ≤ L: v_P(x) = −(P (L − x) (3 L^2 − 4 (L − x)^2)) / (48 EI).

Report relevant response quantities focused on deflection by superposition as v(x) over 0 ≤ x ≤ L and the maximum deflection.
Use symmetry to note the maximum deflection occurs at midspan for these symmetric loads, so v_max = v(L/2).
Evaluate midspan deflection contributions:
v_w(L/2) = −(5 w L^4) / (384 EI).
v_P(L/2) = −(P L^3) / (48 EI).
Compute the numerical values with L = 3000 mm, w = 0.3 N/mm, P = 1200 N, EI = 6.0×10^11 N·mm²:
v_w(L/2) = −(5·0.3·3000^4)/(384·6.0×10^11) mm = −0.5273 mm (approximately).
v_P(L/2) = −(1200·3000^3)/(48·6.0×10^11) mm = −1.1250 mm (approximately).
v_max = v(L/2) = v_w(L/2) + v_P(L/2) = −1.6523 mm (approximately, downward).

Optionally report support reactions for completeness (not required for deflection-by-superposition but consistent with the model):
For UDL: R_A = R_B = wL/2.
For midspan point load: R_A = R_B = P/2.
Total reactions: R_A = R_B = (wL + P)/2 = (0.3·3000 + 1200)/2 N = 1050 N.
