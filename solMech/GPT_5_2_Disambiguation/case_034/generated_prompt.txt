Model the member as an Euler–Bernoulli prismatic beam with small deflection, linear-elastic behavior.
Use a simply supported boundary condition: vertical deflection v(0)=0 and v(L)=0 with free rotation at both supports.
Use span length L = 3000 mm.
Use Young’s modulus E = 69,000 N/mm².
Use second moment of area I = 3,500,000 mm⁴.
Use flexural rigidity EI = 2.415×10^11 N·mm².
Apply a single concentrated load P = 4000 N downward at midspan x = L/2.
Assume no distributed load: w = 0 N/mm.
Neglect shear deformation (Euler–Bernoulli assumption) and neglect axial effects.

Compute support reactions for the midspan point load case as RA = RB = P/2.
Use the governing Euler–Bernoulli relation EI v''''(x) = q(x), with q(x)=P δ(x−L/2) for a point load representation, or equivalently use piecewise bending moment relations.
Use bending moment for 0 ≤ x ≤ L/2: M(x) = RA x = (P/2) x.
