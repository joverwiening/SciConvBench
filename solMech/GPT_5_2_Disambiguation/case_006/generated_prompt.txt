Use small-deformation, linear-elastic Euler–Bernoulli beam theory.
Assume the beam is prismatic with constant E and I over 0 ≤ x ≤ L.
Neglect shear deformation and rotary inertia.
Take x measured from the left support at x = 0 to the right support at x = L.
Use sign convention: downward loads produce positive (downward) deflection; sagging bending moment is positive.
Given L = 2400 mm.
Given a single concentrated load P = 1200 N downward at x = a = 1200 mm.
No distributed load acts on the span.
No externally applied couple/end moment acts anywhere on the beam.
The relevant response quantity is the vertical deflection v(x0) at an arbitrary point x0 in [0, L], computed via the unit-load (virtual work) method.

Compute support reactions from static equilibrium.
Use R_A + R_B = P.
Use moments about x = 0: R_B L − P a = 0.
Therefore R_B = P a / L and R_A = P(1 − a/L).

Define the real bending moment diagram M(x) for the actual loading.
For 0 ≤ x < a: M(x) = R_A x.
For a ≤ x ≤ L: M(x) = R_A x − P(x − a).

Introduce a unit (virtual) load at the point where deflection is desired.
Let the target point be x0 in [0, L].
Apply a virtual unit downward point load 1 at x = x0 on the same simply supported beam.
Compute the virtual reactions r_A and r_B from equilibrium.
Use r_A + r_B = 1.
Use moments about x = 0: r_B L − 1·x0 = 0.
Therefore r_B = x0/L and r_A = 1 − x0/L.

Define the virtual bending moment diagram m(x) due to the unit load.
For 0 ≤ x < x0: m(x) = r_A x.
For x0 ≤ x ≤ L: m(x) = r_A x − 1·(x − x0).

Compute the deflection at x0 by the unit-load method (virtual work).
Use v(x0) = ∫_0^L [M(x) m(x)]/(E I) dx.
Evaluate the integral piecewise over intervals split at x = a and x = x0.
Use the interval partition [0, min(a, x0)], [min(a, x0), max(a, x0)], [max(a, x0), L] with the appropriate expressions for M(x) and m(x) on each sub-interval.

Provide the closed-form result for the special case here (a = L/2) if desired.
For a = L/2 and x0 = a (midspan deflection under a midspan point load), the result reduces to v(a) = P L^3 /(48 E I) (downward positive under the stated convention).

Report additionally, if needed for completeness, the governing field relation between load and deflection.
Use Euler–Bernoulli relation: E I v''(x) = M(x).
Use boundary conditions for simply supported ends: v(0) = 0 and v(L) = 0.
