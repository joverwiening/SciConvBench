Assume small-deformation, linear-elastic torsion of a prismatic, solid circular shaft with constant diameter d = 20 mm.
Assume the shaft is homogeneous and isotropic with shear modulus G = 25939.8 N/mm^2 (6061-T6 aluminum).
Assume Saint-Venant torsion applies (no warping restraint effects included in stiffness).
Assume steady power transmission with P = 5000 W at rotational speed n = 1200 rpm.
Compute angular speed as ω = 2π(n/60) = 40π rad/s ≈ 125.6637 rad/s.
Convert power to torque using P = Tω, so T = P/ω = 5000/125.6637 ≈ 39.79 N·m = 3.979×10^4 N·mm.
Use the polar second moment for a solid circular shaft J = (π d^4)/32.
Compute J for d = 20 mm as J = (π·20^4)/32 = 5000π mm^4 ≈ 1.5708×10^4 mm^4.
Compute maximum torsional shear stress at the outer surface using τ_max = T c / J with c = d/2, equivalently τ_max = 16T/(π d^3).
Evaluate τ_max = 16(3.979×10^4)/(π·20^3) N/mm^2 ≈ 25.33 MPa.
Compute the torsional shear strain at the outer surface using γ_max = τ_max/G.
Evaluate γ_max ≈ 25.33/25939.8 ≈ 9.76×10^-4.
Use the torsion angle-of-twist relation θ = T L /(J G) for a uniform shaft.
Use shaft length L = 1200 mm.
Evaluate θ = (3.979×10^4·1200)/( (5000π)·25939.8 ) rad ≈ 0.0372 rad.
Report twist in degrees as θ_deg = θ·(180/π) ≈ 2.13°.
Assume a torsional strength check based on yielding of 6061-T6 aluminum using the von Mises criterion.
Assume 6061-T6 yield strength Sy = 276 MPa as a standard reference value.
Assume a design factor of safety N = 2.0 as a reasonable general-purpose value for static loading with moderate uncertainty.
Compute allowable equivalent stress as σ_allow = Sy/N = 276/2 = 138 MPa.
For pure torsion, relate von Mises equivalent stress to shear stress by σ_vm = √3 τ, so allowable shear stress is τ_allow = σ_allow/√3.
Evaluate τ_allow = 138/1.732 ≈ 79.7 MPa.
Perform the torsion stress utilization check as τ_max ≤ τ_allow.
Compute utilization ratio U = τ_max/τ_allow ≈ 25.33/79.7 ≈ 0.318, which satisfies the assumed allowable.
Optionally report torque capacity at the assumed allowable as T_allow = τ_allow·J/c = τ_allow·(π d^3)/16.
Evaluate T_allow ≈ 79.7·(π·20^3)/16 N·mm ≈ 1.251×10^5 N·mm ≈ 125 N·m.
