Calculate the midspan deflection of a simply supported beam using superposition of two load cases.
Given parameters: L = 3000 mm, E = 200000 MPa, I = 2000000 mm^4.
Load Case 1: Uniform distributed load w = 0.3 N/mm over the full span.
Load Case 2: Point load P = 3000 N at midspan.
Use Euler-Bernoulli beam theory throughout the analysis.
For the distributed load case, replace the uniform load with its resultant force wL acting at midspan.
Calculate the resultant force as wL = 0.3 × 3000 = 900 N.
Apply the point load formula δ = PL³/(48EI) to both the resultant distributed load and the actual point load.
For the distributed load contribution: δ₁ = (900)(3000)³/(48)(200000)(2000000).
For the point load contribution: δ₂ = (3000)(3000)³/(48)(200000)(2000000).
Sum the two deflections to get the total midspan deflection: δ_total = δ₁ + δ₂.
Express the final answer in millimeters using the N-mm-MPa unit system.
