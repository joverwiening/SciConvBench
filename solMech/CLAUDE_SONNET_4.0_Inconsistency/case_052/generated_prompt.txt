Calculate the transmitted torque T using P = T·ω where ω = 2π(rpm/60).
Convert the rotational speed: ω = 2π(1800/60) = 188.5 rad/s.
Calculate torque: T = P/ω = 10,000 W / 188.5 rad/s = 53.05 N·m.
Convert to N·mm: T = 53.05 × 1000 = 53,050 N·mm.

Calculate the maximum shear stress using torsion theory τ_max = T·c/J.
Determine the radius: c = d/2 = 35/2 = 17.5 mm.
Calculate the polar moment of inertia: J = π·d⁴/32 = π·(35)⁴/32 = 147,323 mm⁴.
Calculate maximum shear stress: τ_max = (53,050 × 17.5)/147,323 = 6.30 MPa.

Calculate the angle of twist using φ = T·L/(G·J).
Substitute values: φ = (53,050 × 1000)/(76,923.1 × 147,323).
Calculate: φ = 53,050,000/11,334,615,461 = 0.00468 radians.
Convert to degrees: φ = 0.00468 × (180/π) = 0.268 degrees.
