Calculate the vertical deflection at midspan of a simply supported beam using Castigliano's theorem.
Use the given beam properties: span L = 2500 mm, elastic modulus E = 200000 MPa, moment of inertia I = 3000000 mm^4.
Apply a point load P = 1000 N downward at midspan.
Define the bending moment M(x) piecewise as M(x) = Px/2 for 0 ≤ x ≤ L/2 and M(x) = P(L-x)/2 for L/2 ≤ x ≤ L.
Calculate the strain energy U using the integral U = ∫ M²/(2EI) dx over the full span.
Apply Castigliano's theorem by taking the partial derivative of U with respect to P to find the deflection.
Express the final answer in millimeters using the N-mm-MPa unit system.
