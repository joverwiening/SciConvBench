Calculate the Euler critical load using the formula P_cr = π²EI/(KL)².
Use the moment of inertia I = πd⁴/64 for a solid circular cross-section.
Substitute the given values: d = 20 mm, L = 2000 mm, E = 200000 MPa, K = 1.0.
Calculate I = π(20)⁴/64 = π(160000)/64 = 7853.98 mm⁴.
Calculate P_cr = π²(200000)(7853.98)/(1.0 × 2000)² = π²(1570796000)/4000000 = 3869.7 N.
Calculate the allowable load using P_allow = P_cr/n where n = 2.0.
Calculate P_allow = 3869.7/2.0 = 1934.85 N.
Present both results clearly with proper units.
