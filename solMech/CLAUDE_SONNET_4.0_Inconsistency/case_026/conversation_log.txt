Q: What is the bending moment function M(x) that you want to use in the integration, given that you specified to take it as the constant peak value M = P L over the full span?
A: The complete requirement doesn't actually specify using a constant peak value M = PL over the full span. You should use the correct bending moment function M(x) = P(L-x) for a cantilever beam with a point load at the free end, where x is measured from the fixed end.
