Calculate the elongation of a steel bar using the axial deformation integral.
Use the given parameters: L = 800 mm, P = 30000 N, E = 200000 MPa, A0 = 250 mm², k = 0.8.
Use the varying cross-sectional area function A(x) = A0·(1 + k·x/L) where x is measured from the left end.
Apply the axial deformation integral δ = ∫[0→L] P/(A(x)E) dx.
Substitute A(x) = A0·(1 + k·x/L) into the integral.
Evaluate the integral δ = ∫[0→L] P/(A0·(1 + k·x/L)·E) dx from x = 0 to x = L.
Express the final elongation result in millimeters.
Use N-mm-MPa units throughout the calculation.
Treat E as constant at 200000 MPa.
