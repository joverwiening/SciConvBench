Calculate the transmitted torque T using the formula P = T·ω where ω = 2π(rpm/60).
Convert the given power P = 5 kW to watts: P = 5000 W.
Convert the rotational speed from rpm to rad/s: ω = 2π(1200/60) = 125.66 rad/s.
Calculate torque: T = P/ω = 5000/125.66 = 39.79 N·m.
Convert torque to N·mm: T = 39.79 × 1000 = 39,790 N·mm.

Calculate the maximum shear stress using the torsion formula τ_max = Tc/J.
The polar moment of inertia for a solid circular shaft is J = πd⁴/32.
Calculate J using d = 20 mm: J = π(20)⁴/32 = 15,708 mm⁴.
The maximum shear stress occurs at the outer surface where c = d/2 = 10 mm.
Calculate maximum shear stress: τ_max = (39,790 × 10)/15,708 = 25.3 MPa.

Calculate the angle of twist using the formula φ = TL/(GJ).
Use T = 39,790 N·mm, L = 1000 mm, G = 76923.1 MPa, and J = 15,708 mm⁴.
Calculate angle of twist: φ = (39,790 × 1000)/(76923.1 × 15,708) = 0.0329 radians.
Convert to degrees if needed: φ = 0.0329 × (180/π) = 1.89 degrees.
