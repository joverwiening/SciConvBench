Calculate the maximum shear stress in a solid circular steel shaft using the torsion formula.
The shaft has diameter d = 50 mm and length L = 600 mm.
The applied torque is T = 500000 N·mm.
Use the polar moment of inertia J = π d^4/32.
Calculate the maximum shear stress using τ_max = T c / J where c = d/2.
Calculate the angle of twist using φ = TL/(JG) where G = 77519.4 MPa.
Convert the angle of twist from radians to degrees.
Use N–mm–MPa units throughout the calculation.
Assume the shaft material is linearly elastic.
Report both the maximum shear stress in MPa and the angle of twist in degrees.
