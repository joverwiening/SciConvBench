Calculate the maximum shear stress in a solid circular brass shaft using the torsion formula.
Given parameters: diameter d = 30 mm, length L = 1200 mm, applied torque T = 400000 N·mm, shear modulus G = 39179.1 MPa.
Use the polar moment of inertia J = π d^4/32.
Calculate the maximum shear stress using τ_max = T c / J where c = d/2.
Calculate the angle of twist using φ = TL/(JG).
Convert the angle of twist from radians to degrees.
Use N-mm-MPa units throughout all calculations.
Report both the maximum shear stress in MPa and the angle of twist in degrees.
