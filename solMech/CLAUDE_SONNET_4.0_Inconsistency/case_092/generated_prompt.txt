Solve the cantilever beam deflection problem using the integration method for the differential equation.
The beam has length L = 1800 mm, fixed at x = 0 and free at x = L.
Material properties are E = 200000 MPa and I = 1200000 mm^4.
A downward point load P = 2000 N is applied at the free end.
Use Euler-Bernoulli beam theory with small deflection and linear elastic assumptions.
Apply N-mm-MPa units throughout the calculation.
The moment distribution is constant at M = PL over the full span.
Apply boundary conditions: y(0) = 0 and dy/dx(0) = 0 at the fixed end.
Start with the differential equation EI d²y/dx² = -M.
Integrate twice to obtain the slope and deflection equations.
Apply the boundary conditions to determine integration constants.
Calculate the slope at the free end x = L in radians or degrees.
Calculate the vertical deflection at the free end x = L in mm.
Report both the slope and deflection values clearly.
