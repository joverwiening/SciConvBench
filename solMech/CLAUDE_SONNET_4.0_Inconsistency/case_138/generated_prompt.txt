Calculate the stress analysis for a solid circular shaft with the following specifications and steps.

Given parameters: diameter d = 35 mm, bending moment M = 3000000 N·mm, torque T = 500000 N·mm.

Use N-mm-MPa units throughout all calculations.

Part (a): Calculate the maximum bending normal stress at the outer surface using σ = M c / I where I = π d^4/64 and c = d/2.

Part (b): Calculate the torsional shear stress at the outer surface using τ = T c / J where J = π d^4/32.

Part (c): Treat the surface stress state as plane stress with σx = σ (from bending), σy = 0, and τxy = τ (from torsion).

Calculate the principal stresses using σ₁,₂ = (σₓ + σᵧ)/2 ± √[((σₓ - σᵧ)/2)² + τₓᵧ²].

Calculate the maximum in-plane shear stress using τₘₐₓ = √[((σₓ - σᵧ)/2)² + τₓᵧ²].

Consider the stress state at the outer surface of the circular shaft at the location of maximum bending stress.

At the outer surface where the bending normal stress is maximum, the torsional shear stress vanishes, so the principal stresses are governed by bending alone.
