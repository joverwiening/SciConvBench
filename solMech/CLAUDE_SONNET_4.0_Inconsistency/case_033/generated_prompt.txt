Calculate the maximum deflection and slope at supports for a simply supported beam using the following specifications:
Beam geometry: span L = 2500 mm, constant moment of inertia I = 1200000 mm^4.
Material properties: structural steel with elastic modulus E = 200000 MPa.
Loading: single point load P = 2500 N acting downward at midspan (x = L/2 = 1250 mm).
Support conditions: simply supported at both ends (zero deflection at x = 0 and x = L).
Theory: apply Euler-Bernoulli beam theory, neglect shear deformation.
Boundary conditions: slope vanishes at both supports (x = 0 and x = L) and at midspan (x = L/2) due to symmetry.
Solution method: use either differential equation approach with EI v'' = M(x) and integration with boundary conditions, or apply standard beam deflection formulas.
Units: use N-mm-MPa unit system throughout.
Required outputs: (i) maximum deflection at midspan in mm, (ii) slope at the supports in radians.
