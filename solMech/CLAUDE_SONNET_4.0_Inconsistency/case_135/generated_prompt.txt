Calculate the cross-sectional area as A = b × h = 40 mm × 120 mm = 4800 mm².
Calculate the average normal stress as σ_avg = P/A = 30000 N / 4800 mm² = 6.25 MPa.
Calculate the average shear stress as τ_avg = V/A = 12000 N / 4800 mm² = 2.5 MPa.
Calculate the maximum in-plane shear stress using τ_max = sqrt((σ_avg/2)² + τ_avg²) = sqrt((6.25/2)² + 2.5²) = sqrt(3.125² + 2.5²) = sqrt(9.765625 + 6.25) = sqrt(16.015625) = 4.002 MPa.
The final answers are σ_avg = 6.25 MPa, τ_avg = 2.5 MPa, and τ_max = 4.002 MPa.
