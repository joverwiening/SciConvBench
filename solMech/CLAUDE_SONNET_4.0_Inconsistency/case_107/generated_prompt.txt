Calculate the vertical deflection at midspan of a simply supported beam using Castigliano's theorem with the following specifications:

Beam properties: span L = 3000 mm, structural steel with E = 200000 MPa, constant moment of inertia I = 3000000 mm^4.

Loading: point load P = 2000 N applied downward at midspan.

Use N-mm-MPa units throughout the calculation.

Define the bending moment M(x) piecewise over the span: for 0 ≤ x ≤ L/2, M(x) = Px/2; for L/2 ≤ x ≤ L, M(x) = P(L-x)/2.

Calculate the strain energy using U = ∫ M²/(2EI) dx integrated over the full span 0 ≤ x ≤ L.

Apply Castigliano's theorem by taking the partial derivative of strain energy with respect to the load P to find the vertical deflection at the point of load application.

Present the final deflection value in millimeters.
