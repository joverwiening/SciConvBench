Q: What specific value or expression should be used for M(x) in each piece of the piecewise function over the span 0 ≤ x ≤ L?
A: For a simply supported beam with a point load P at midspan, the bending moment M(x) should be defined piecewise as:

- For 0 ≤ x ≤ L/2: M(x) = Px/2
- For L/2 ≤ x ≤ L: M(x) = P(L-x)/2

This represents the actual moment distribution in the beam due to the point load at midspan.
