Use N-mm-MPa units throughout the analysis.
The beam is simply supported with span L = 3000 mm.
The beam is made of structural steel with E = 200000 MPa.
The beam has constant moment of inertia I = 1500000 mm^4.
A point load P = 2000 N is applied downward at midspan (x = L/2 = 1500 mm).
Define the bending moment M(x) piecewise over the span 0 ≤ x ≤ L as follows: For 0 ≤ x ≤ L/2, M(x) = Px/2; For L/2 ≤ x ≤ L, M(x) = P(L-x)/2.
Calculate the bending strain energy using U = ∫ M²/(2EI) dx integrated over the full span.
Apply Castigliano's theorem by taking the partial derivative of strain energy with respect to the load P to find the vertical deflection at midspan.
The final answer should be the vertical deflection at midspan in mm.
