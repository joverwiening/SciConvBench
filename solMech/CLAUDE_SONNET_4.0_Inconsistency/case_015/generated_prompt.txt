Calculate the slope and deflection of a cantilever beam using the integration method for the differential equation of the elastic curve.
Use N-mm-MPa units throughout the analysis.
Apply Euler-Bernoulli beam theory with small deflection and linear elastic assumptions.
The cantilever beam has length L = 1200 mm, fixed at x = 0, and free at x = L.
The beam material is AISI 1020 steel with elastic modulus E = 200000 MPa.
The beam has constant second moment of area I = 2000000 mm^4.
Apply a downward point load P = 2000 N at the free end (x = L).
Use the moment equation M(x) = -P(L-x) for 0 ≤ x ≤ L.
Set up the differential equation EI d²y/dx² = -M(x) = P(L-x).
Integrate once to find the slope equation EI dy/dx = P(Lx - x²/2) + C₁.
Apply boundary condition dy/dx = 0 at x = 0 to find C₁ = 0.
Integrate again to find the deflection equation EI y = P(Lx²/2 - x³/6) + C₂.
Apply boundary condition y = 0 at x = 0 to find C₂ = 0.
Calculate the slope at the free end using dy/dx at x = L = PL²/(2EI).
Calculate the vertical deflection at the free end using y at x = L = PL³/(3EI).
Substitute the given values: P = 2000 N, L = 1200 mm, E = 200000 MPa, I = 2000000 mm^4.
Report the slope in radians and also convert to degrees.
Report the deflection in mm.
