Calculate the elongation of a vertical prismatic bar due to its own weight using the exact integration method.
Given parameters: L = 3000 mm, A = 300 mm², E = 69000 MPa, ρ = 8900 kg/m³, g = 9.81 m/s².
The bar hangs vertically from a rigid support at the top end with the bottom end free.
The bar is linearly elastic and has constant cross-sectional area.
Only self-weight acts on the bar with no external loads.
Use coordinate x measured downward from the top of the bar.
The axial force at any section x is P(x) = ρgA(L-x).
Calculate elongation using δ = ∫₀ᴸ P(x)/(AE) dx.
Substitute P(x) = ρgA(L-x) into the integral to get δ = ∫₀ᴸ ρgA(L-x)/(AE) dx.
Simplify to δ = (ρg/E) ∫₀ᴸ (L-x) dx.
Evaluate the integral ∫₀ᴸ (L-x) dx = [Lx - x²/2]₀ᴸ = L²/2.
The final elongation is δ = ρgL²/(2E).
Convert density from kg/m³ to appropriate units for consistency with N-mm-MPa system.
Use ρ = 8900 kg/m³ = 8900 × 10⁻⁹ kg/mm³ = 8.9 × 10⁻⁵ N/mm³.
Substitute all values and calculate the numerical result in millimeters.
