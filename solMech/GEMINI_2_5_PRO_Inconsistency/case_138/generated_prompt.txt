Use N-mm-MPa as the unit system.
The solid circular shaft has a diameter d = 35 mm.
The shaft is subjected to a bending moment M = 3,000,000 N·mm.
The shaft is subjected to a torque T = 500,000 N·mm.
The analysis is for the stress state at the outer surface of the shaft at the location of maximum bending stress.
Calculate the moment of inertia I using the formula I = π * d^4 / 64.
Calculate the polar moment of inertia J using the formula J = π * d^4 / 32.
Calculate the distance from the neutral axis to the outer surface c as d/2.
Calculate the maximum bending normal stress σ using the formula σ = M * c / I.
Calculate the torsional shear stress τ at the outer surface using the formula τ = T * c / J.
Model the stress state as plane stress with σx equal to the calculated bending stress σ.
In the plane stress model, set σy = 0.
In the plane stress model, set τxy equal to the calculated torsional shear stress τ.
