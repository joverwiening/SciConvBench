Use N, mm, and MPa as the units for all calculations.
The column is made of structural steel with a modulus of elasticity E = 200000 MPa.
The column has a length L = 2000 mm.
The column has a constant second moment of area I = 800000 mm^4.
The column has fixed-fixed end conditions with an effective length factor K = 0.5.
Assume the column is slender and remains elastic, so Euler buckling applies.
Calculate the Euler critical buckling load using the formula P_cr = (π^2 * E * I) / (K * L)^2.
Report the calculated P_cr value in Newtons (N).
Report the calculated P_cr value in kiloNewtons (kN).
