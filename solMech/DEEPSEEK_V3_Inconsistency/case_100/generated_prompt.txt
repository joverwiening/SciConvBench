Use N, mm, and MPa as the units for all calculations.
Assume the brass rod material exhibits linear elastic isotropic behavior.
The rod has an initial diameter d0 = 30 mm.
The rod has an initial length L = 500 mm.
The rod is subjected to an axial tensile load P = 25000 N applied through the centroid.
Use a Young's Modulus E = 105000 MPa.
Use a Poisson's ratio ν = 0.34.
Compute the average axial normal stress (σ_axial) using the formula σ_axial = P / A0, where A0 is the initial cross-sectional area.
Compute the axial strain (ε_axial) using the formula ε_axial = σ_axial / E.
Compute the lateral (diametral) strain (ε_lateral) using the formula ε_lateral = -ν * ε_axial.
Compute the change in diameter (Δd) using the formula Δd = ε_lateral * d0.
