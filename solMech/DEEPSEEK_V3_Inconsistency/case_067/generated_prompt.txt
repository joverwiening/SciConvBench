Use N, mm, and MPa as the units.
Assume the shaft is linearly elastic and has a solid circular cross-section.
The shaft is made of 6061-T6 aluminum.
The shaft diameter d is 30 mm.
The shaft length L is 800 mm.
The transmitted torque T is 500000 N·mm.
The shear modulus G is 25939.8 MPa.
Calculate the polar second moment of area J using the formula J = π * d^4 / 32.
Calculate the maximum shear stress τ_max using the formula τ_max = T * c / J, where c = d / 2.
Calculate the angle of twist φ over the length using the formula φ = T * L / (J * G).
Report the angle of twist φ in degrees.
