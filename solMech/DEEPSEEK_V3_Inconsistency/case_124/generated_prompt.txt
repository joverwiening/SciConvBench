Use N, mm, and MPa as the units for all calculations.
Assume the shaft is linearly elastic and has a solid circular cross-section.
The shaft is made of AISI 1020 steel.
The shaft diameter d is 30 mm.
The shaft length L is 1000 mm.
The applied torque T is 250000 N·mm.
Calculate the polar second moment of area J using the formula J = π * d^4 / 32.
Calculate the maximum shear stress τ_max using the formula τ_max = T * c / J, where c = d / 2.
The shear modulus G is 76923.1 MPa.
Calculate the angle of twist φ over the length L using the formula φ = T * L / (J * G).
Report the final angle of twist φ in degrees.
