Use N, mm, and MPa as the consistent unit system.
Model two prismatic bars, Bar 1 and Bar 2, mounted in parallel between two rigid plates.
Set the length of both bars, L, to 800 mm.
Set the cross-sectional area of Bar 1, A1, to 150 mm^2.
Set the elastic modulus of Bar 1, E1, to 200000 MPa.
Set the cross-sectional area of Bar 2, A2, to 200 mm^2.
Set the elastic modulus of Bar 2, E2, to 110000 MPa.
Apply a total tensile load, P, of 30000 N to the top plate.
Assume the bars are perfectly bonded to the rigid plates, enforcing a common elongation (compatibility).
Calculate the force in each bar, F1 and F2, by solving the system: F1 + F2 = P and (F1 * L) / (A1 * E1) = (F2 * L) / (A2 * E2).
Calculate the stress in Bar 1, σ1, as F1 / A1.
Calculate the stress in Bar 2, σ2, as F2 / A2.
Calculate the common elongation of the bars, δ, as (F1 * L) / (A1 * E1) or equivalently (F2 * L) / (A2 * E2).
