Use N–mm–MPa units.
Assume the bar behaves like a linear axial spring and neglect the mass of the bar.
The vertical AISI 1020 steel rod has a length L = 800 mm and a diameter d = 25 mm.
The rod is fixed at its top end.
A weight W = 1500 N is dropped onto a collar attached to the bottom end from a height h = 200 mm.
The impact load stretches the rod.
Let P_max be the maximum axial force in the rod during the impact.
Use energy conservation: W(h + δ_max) = (P_max^2 L) / (2AE).
The maximum elongation is δ_max = P_max L / (AE).
The cross-sectional area is A = π d^2 / 4.
Use π = 3.1416.
Calculate A = 3.1416 × (25 mm)^2 / 4 = 490.875 mm^2.
The modulus of elasticity is E = 200000 MPa.
Because the rod is linear elastic, let the drop height affect only the contact duration and use the suddenly applied-load result P_max = 2W for the peak force.
Calculate P_max = 2 × 1500 N = 3000 N.
Compute the maximum normal stress σ_max = P_max / A.
Calculate σ_max = 3000 N / 490.875 mm^2.
Report P_max and σ_max.
