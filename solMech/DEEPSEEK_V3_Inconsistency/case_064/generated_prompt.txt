Use N, mm, and MPa as the units for all calculations.
Assume the shaft material is linearly elastic and isotropic.
The shaft has a solid circular cross-section with a diameter of 18 mm.
The shaft has a length of 400 mm.
The shaft transmits a torque of 500000 N·mm.
Calculate the polar second moment of area J using the formula J = π * d^4 / 32.
Calculate the maximum shear stress τ_max using the formula τ_max = T * c / J, where c = d/2.
Use the given shear modulus G = 39179.1 MPa.
Calculate the angle of twist φ over the full shaft length using the formula φ = T * L / (J * G).
