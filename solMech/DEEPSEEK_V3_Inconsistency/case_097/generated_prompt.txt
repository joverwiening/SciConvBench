Use N, mm, and MPa as the units for all calculations.
The beam is a cantilever of length L = 1500 mm, fixed at x = 0 and free at x = L.
The beam material is AISI 1020 steel with modulus of elasticity E = 200000 MPa.
The beam has a constant second moment of area I = 2500000 mm^4.
A downward point load P = 500 N is applied at the free end (x = L).
The bending moment function is M(x) = –P·(L – x) for 0 ≤ x ≤ L.
The squared moment function for the strain energy integrand is M(x)² = P²·(L – x)².
The strain energy is U = ∫ from 0 to L of [M(x)² / (2EI)] dx.
Substitute the expression for M(x)² to get U = ∫ from 0 to L of [P²·(L – x)² / (2EI)] dx.
Compute the integral to find U as a function of P.
Apply Castigliano’s theorem: the vertical deflection at the free end δ = ∂U/∂P.
Differentiate the expression for U with respect to the load P.
Evaluate the resulting deflection expression using the given numerical values for P, L, E, and I.
Report the final numerical value for the vertical deflection at the free end in mm.
