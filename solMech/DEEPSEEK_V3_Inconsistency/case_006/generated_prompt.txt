For segment 0 ≤ x < 1200 mm, M(x) = 600x N·mm.
For segment 1200 < x ≤ 2400 mm, M(x) = 600 * (2400 - x) N·mm.
The auxiliary bending moment m(x) is defined piecewise.
For segment 0 ≤ x < 1200 mm, m(x) = 0.5x N·mm.
For segment 1200 < x ≤ 2400 mm, m(x) = 0.5 * (2400 - x) N·mm.
The product EI is 7.0 × 10¹¹ N·mm².
Compute the deflection δ at x = 1200 mm using the integral δ = ∫[0→L] (M(x)·m(x))/(EI) dx.
Calculate the integral by summing the integrals over the two segments: 0 to 1200 mm and 1200 mm to 2400 mm.
Perform the integration for each segment.
Sum the results from the two integrations to get the total deflection.
