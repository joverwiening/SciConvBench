Use N, mm, and MPa as the units for all calculations.
The shaft is solid and circular with a diameter d = 30 mm.
The shaft is subjected to a bending moment M = 4,000,000 N·mm and a torque T = 400,000 N·mm at the critical section.
Consider the stress state at the outer surface of the shaft at the location of maximum bending stress.
Calculate the maximum bending normal stress using the formula σ = M * c / I.
Use c = d / 2 = 15 mm.
Use I = π * d^4 / 64.
Calculate the torsional shear stress using the formula τ = T * c / J.
Use J = π * d^4 / 32.
Model the surface stress state as plane stress with σx equal to the calculated bending stress σ.
Set σy = 0.
Set τxy equal to the calculated torsional shear stress τ.
Compute the principal stresses σ1 and σ2 from the stress components σx, σy, and τxy.
Compute the maximum in-plane shear stress τmax from the stress components σx, σy, and τxy.
