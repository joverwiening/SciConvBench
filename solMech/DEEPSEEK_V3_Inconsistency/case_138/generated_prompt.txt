Use N, mm, and MPa as the units for all calculations.
The shaft is solid and circular with a diameter d = 35 mm.
The applied bending moment is M = 3000000 N·mm.
The applied torque is T = 500000 N·mm.
Calculate the maximum bending normal stress at the outer surface using the formula σ = M * c / I.
Use c = d / 2 = 17.5 mm as the distance from the neutral axis.
Use I = π * d^4 / 64 as the second moment of area.
Calculate the torsional shear stress at the outer surface using the formula τ = T * c / J.
Use J = π * d^4 / 32 as the polar second moment of area.
Model the stress state at the surface as a plane stress condition.
Set the normal stress σx equal to the calculated bending stress σ.
Set the normal stress σy to 0.
Set the shear stress τxy equal to the calculated torsional shear stress τ.
Compute the two in-plane principal stresses σ1 and σ2 from the stress components σx, σy, and τxy.
