The problem is a simply supported rectangular beam under bending.
The maximum bending moment is given directly as M_max = 6,000,000 N·mm.
The beam has a rectangular cross-section with width b = 60 mm.
The allowable bending stress is σ_allow = 170 MPa = 170 N/mm².
Assume small-deformation, linear-elastic behavior (Euler-Bernoulli beam theory).
Assume the neutral axis passes through the centroid of the rectangular cross-section, at h/2 from either outer fiber.
Assume the beam is homogeneous and isotropic.
The bending stress formula is σ = M · c / I, where c is the distance from the neutral axis to the outermost fiber and I is the second moment of area.
For a rectangle, I = b · h³ / 12 and c = h / 2.
The section modulus is S = I / c = b · h² / 6.
The design condition is σ_allow ≥ M_max / S, which gives S_required = M_max / σ_allow.
Compute S_required = 6,000,000 / 170 = 35,294.12 mm³.
Set S = b · h² / 6 ≥ S_required, so h² ≥ 6 · S_required / b.
Compute h² ≥ 6 · 35,294.12 / 60 = 211,764.7 / 60 = 3,529.41 mm².
Compute h ≥ √3,529.41 = 59.41 mm.
The minimum required beam height is h_min = 59.41 mm, which should be rounded up to the next practical dimension (e.g., h = 60 mm) to satisfy the allowable stress constraint.
