Problem: Cantilever beam under a single downward point load at the free end.

Assumptions:
Small-deformation, linear-elastic (Hookean) material behavior applies throughout.
The beam obeys Euler-Bernoulli beam theory: plane sections remain plane, shear deformation is neglected, and rotations are small.
The beam is prismatic: E and I are constant along the entire length.
The beam is fixed (clamped) at x = 0 and free at x = L.
There is no applied moment anywhere on the beam.
Self-weight and distributed loads are neglected; the only load is the point load P at x = L.
Units are consistent: force in N, length in mm, stress in MPa (N/mm²).

Given values:
P = 2000 N (downward, applied at x = L).
L = 1200 mm.
E = 200,000 MPa = 200,000 N/mm².
I = 2,000,000 mm⁴.
EI = 200,000 × 2,000,000 = 4.0 × 10¹¹ N·mm².

Governing differential equation (Euler-Bernoulli):
EI · d⁴v/dx⁴ = q(x), where q(x) = 0 for 0 ≤ x < L (no distributed load).
Equivalently, EI · d²v/dx² = M(x), where v(x) is the transverse deflection (positive upward).

Boundary conditions:
At x = 0 (fixed end): v(0) = 0 (no deflection), dv/dx(0) = 0 (no rotation).
At x = L (free end): M(L) = EI · d²v/dx²|_{x=L} = 0 (no applied moment), V(L) = EI · d³v/dx³|_{x=L} = -P (shear equals applied load, sign consistent with downward P).

Internal reactions at the fixed support (x = 0):
Vertical reaction force: R = P = 2000 N (upward).
Reaction moment: M_fixed = P · L = 2000 × 1200 = 2,400,000 N·mm = 2400 N·m (counterclockwise, resisting the load).

Bending moment distribution along the beam:
M(x) = -P · (L - x) for 0 ≤ x ≤ L.
M(0) = -P · L = -2,400,000 N·mm (maximum magnitude, hogging at the fixed end).
M(L) = 0 (free end, as required).

Shear force distribution:
V(x) = -P = -2000 N (constant along the entire beam, downward sense).

Elastic curve (deflection equation):
Integrate EI · d²v/dx² = M(x) = -P(L - x) twice and apply boundary conditions.
EI · dv/dx = -P(Lx - x²/2) + C₁; applying dv/dx(0) = 0 gives C₁ = 0.
EI · v(x) = -P(Lx²/2 - x³/6) + C₂; applying v(0) = 0 gives C₂ = 0.
Deflection equation: v(x) = -P·x²·(3L - x) / (6EI).

Maximum deflection (at the free end, x = L):
v(L) = -P·L³ / (3EI).
v(L) = -(2000 × 1200³) / (3 × 4.0 × 10¹¹).
Numerator: 2000 × 1,728,000,000 = 3.456 × 10¹² N·mm³.
Denominator: 3 × 4.0 × 10¹¹ = 1.2 × 10¹² N·mm².
v(L) = -3.456 × 10¹² / 1.2 × 10¹² = -2.88 mm.
The free end deflects 2.88 mm downward.

Maximum slope (rotation at the free end, x = L):
dv/dx|_{x=L} = -P·L² / (2EI).
dv/dx|_{x=L} = -(2000 × 1200²) / (2 × 4.0 × 10¹¹).
= -(2000 × 1,440,000) / (8.0 × 10¹¹).
= -2.88 × 10⁹ / 8.0 × 10¹¹ = -0.0036 radians.
The free end rotates 0.0036 rad (≈ 0.206°) clockwise.

Summary of key results:
Maximum bending moment: |M|_max = 2,400,000 N·mm at the fixed support (x = 0).
Maximum shear force: |V|_max = 2000 N (constant throughout).
Maximum deflection: |v|_max = 2.88 mm downward at the free end (x = L).
Maximum slope: |dv/dx|_max = 0.0036 rad at the free end (x = L).
