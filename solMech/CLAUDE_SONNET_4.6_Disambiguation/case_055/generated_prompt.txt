The bar is a straight, prismatic-axis member with a continuously varying circular (or arbitrary) cross-section.
Assume small deformations and linear-elastic, homogeneous, isotropic material behavior throughout.
Assume the bar is statically determinate: one end is fixed (left end, x = 0) and the axial load P is applied at the free end (right end, x = L).
Assume no body forces act along the bar's length.
Assume plane sections remain plane and stress is uniform across any cross-section (Saint-Venant uniaxial assumption).

The cross-sectional area varies as A(x) = A0 · (1 + k · x / L).
Use A0 = 200 mm², k = 0.6, L = 1200 mm, P = 20000 N, E = 69000 MPa.

The internal axial force at every cross-section is constant and equal to P = 20000 N (equilibrium of a free body cut at position x).
N(x) = P = 20000 N for all x in [0, L].

The axial (normal) stress at position x is σ(x) = N(x) / A(x) = P / [A0 · (1 + k · x / L)].
Evaluate σ at x = 0: σ(0) = P / A0 = 20000 / 200 = 100 MPa.
Evaluate σ at x = L: σ(L) = P / [A0 · (1 + k)] = 20000 / [200 · 1.6] = 62.5 MPa.

The axial strain at position x is ε(x) = σ(x) / E = P / [E · A0 · (1 + k · x / L)].

The total axial deformation (elongation) is obtained by integrating the strain over the length:
δ = ∫₀ᴸ ε(x) dx = ∫₀ᴸ P / [E · A0 · (1 + k · x / L)] dx.

Perform the substitution u = 1 + k · x / L, so du = k / L · dx, giving dx = L / k · du.
The limits transform as: x = 0 → u = 1, x = L → u = 1 + k = 1.6.
The integral becomes δ = (P · L) / (E · A0 · k) · ∫₁^(1+k) du / u = (P · L) / (E · A0 · k) · ln(1 + k).

Substitute numerical values: δ = (20000 · 1200) / (69000 · 200 · 0.6) · ln(1.6).
Compute the prefactor: (20000 · 1200) / (69000 · 200 · 0.6) = 24000000 / 8280000 = 2.8986 mm.
Compute ln(1.6) = 0.4700.
Compute δ = 2.8986 · 0.4700 = 1.3623 mm.

The total axial elongation of the bar is δ ≈ 1.362 mm.

The displacement field u(x) (measured from the fixed left end) is:
u(x) = (P · L) / (E · A0 · k) · ln(1 + k · x / L).

Report σ(x) = 20000 / [200 · (1 + 0.6 x / 1200)] MPa as the stress distribution.
Report ε(x) = σ(x) / 69000 as the strain distribution.
Report u(x) = (20000 · 1200) / (69000 · 200 · 0.6) · ln(1 + 0.6 x / 1200) mm as the displacement field.
Report δ = u(L) ≈ 1.362 mm as the total elongation.
