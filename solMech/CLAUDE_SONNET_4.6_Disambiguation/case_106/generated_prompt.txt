The problem is a simply supported Euler-Bernoulli beam of span L = 2500 mm subjected to a single concentrated point load P = 2500 N applied downward at midspan.

Material and section properties are E = 200,000 MPa (N/mm²) and I = 3,500,000 mm⁴.

Work entirely in consistent N, mm, MPa units throughout.

Assume small deformations so that the undeformed geometry is used for equilibrium.

Assume the beam is prismatic, meaning E and I are constant along the full span.

Assume the beam is homogeneous and isotropic.

Assume Euler-Bernoulli beam theory, meaning plane sections remain plane and perpendicular to the neutral axis, and shear deformation is neglected.

Assume the supports are ideal: a pin at the left end (restrains vertical and horizontal translation, free to rotate) and a roller at the right end (restrains vertical translation only, free to rotate and translate horizontally).

The self-weight of the beam is neglected; the only load is the applied point load P.

By symmetry, each support reaction is R = P/2 = 2500/2 = 1250 N upward.

The governing Euler-Bernoulli bending relation is EI d²v/dx² = M(x), where v is the transverse deflection (positive downward here) and M(x) is the bending moment at position x measured from the left support.

For 0 ≤ x ≤ L/2, the bending moment is M(x) = R·x = 1250·x N·mm.

Integrate once to obtain EI dv/dx = (1250/2)x² + C1 = 625x² + C1.

Integrate again to obtain EI·v = (625/3)x³ + C1·x + C2.

Apply boundary condition v(0) = 0 to get C2 = 0.

Apply symmetry condition dv/dx = 0 at x = L/2 = 1250 mm to find C1.

At x = 1250: 625·(1250)² + C1 = 0, so C1 = −625·1,562,500 = −976,562,500 N·mm².

The slope function for 0 ≤ x ≤ L/2 is dv/dx = (1/(EI))·(625x² − 976,562,500).

The deflection function for 0 ≤ x ≤ L/2 is v(x) = (1/(EI))·((625/3)x³ − 976,562,500·x).

Compute the stiffness product EI = 200,000 × 3,500,000 = 7.0 × 10¹¹ N·mm².

Compute midspan deflection at x = L/2 = 1250 mm using the standard closed-form result v_max = PL³/(48EI).

v_max = (2500 × 2500³) / (48 × 7.0 × 10¹¹).

Numerator: 2500 × 15,625,000,000 = 3.90625 × 10¹³ N·mm³.

Denominator: 48 × 7.0 × 10¹¹ = 3.36 × 10¹³ N·mm².

v_max = 3.90625 × 10¹³ / 3.36 × 10¹³ = 1.1626 mm (downward).

Compute support slope at x = 0 using the standard closed-form result θ = PL²/(16EI).

θ = (2500 × 2500²) / (16 × 7.0 × 10¹¹).

Numerator: 2500 × 6,250,000 = 1.5625 × 10¹⁰ N·mm².

Denominator: 16 × 7.0 × 10¹¹ = 1.12 × 10¹³ N·mm².

θ = 1.5625 × 10¹⁰ / 1.12 × 10¹³ = 0.001395 radians (the beam slopes downward from left support toward midspan).

The maximum bending moment occurs at midspan and equals M_max = PL/4 = 2500 × 2500 / 4 = 1,562,500 N·mm.

Summary of results: midspan deflection v_max = 1.163 mm downward, left support slope θ = 0.001395 rad (0.0799 degrees), maximum bending moment M_max = 1,562,500 N·mm at midspan, and each support reaction is 1250 N upward.
