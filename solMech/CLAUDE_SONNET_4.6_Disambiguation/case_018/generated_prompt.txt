The shaft is a solid circular cross-section with diameter D = 40 mm and total length L = 1500 mm.
The cross-section is uniform along the entire length.
The material is 6061-T6 aluminum with shear modulus G = 25939.8 MPa.
The shaft is fixed at x = 0 (zero angle of twist at x = 0).
Torque T2 = -150000 N·mm is applied at x = 750 mm (midpoint).
Torque T1 = 300000 N·mm is applied at x = 1500 mm (free end).
Assume small deformation and linear-elastic behavior throughout.
Assume the shaft is straight, prismatic, and loaded purely in torsion (no bending, axial, or transverse shear loads are considered).
Assume Saint-Venant torsion theory applies (plane sections remain plane, warping is unrestrained or neglected for circular sections).

Compute the polar moment of inertia J = π D^4 / 32.
J = π (40)^4 / 32 = π (2560000) / 32 = 251327 mm^4.

Determine the internal torque T(x) in each segment by applying equilibrium from the free end (x = 1500 mm) inward, using the sign convention that positive torque follows the right-hand rule in the +x direction.

Segment 2: 750 mm < x < 1500 mm.
The only external torque to the right of any cut in this segment is T1 = 300000 N·mm at x = 1500 mm.
Internal torque T(x) = 300000 N·mm in Segment 2.

Segment 1: 0 < x < 750 mm.
External torques to the right of any cut in this segment are T1 at x = 1500 mm and T2 at x = 750 mm.
Internal torque T(x) = T1 + T2 = 300000 + (-150000) = 150000 N·mm in Segment 1.

Compute the angle of twist in each segment using φ = T L_seg / (G J).

Angle of twist over Segment 1 (length 750 mm): φ1 = (150000 × 750) / (25939.8 × 251327).
φ1 = 112500000 / 6521817186 = 0.01726 rad.

Angle of twist over Segment 2 (length 750 mm): φ2 = (300000 × 750) / (25939.8 × 251327).
φ2 = 225000000 / 6521817186 = 0.03451 rad.

Determine the absolute angle of twist at each key location using φ(0) = 0.
φ(0) = 0 rad (fixed end, boundary condition).
φ(750) = φ(0) + φ1 = 0 + 0.01726 = 0.01726 rad.
φ(1500) = φ(750) + φ2 = 0.01726 + 0.03451 = 0.05177 rad.

Compute the maximum shear stress in each segment using τ = T c / J, where c = D/2 = 20 mm.

Maximum shear stress in Segment 1: τ1 = (150000 × 20) / 251327 = 3000000 / 251327 = 11.94 MPa.
Maximum shear stress in Segment 2: τ2 = (300000 × 20) / 251327 = 6000000 / 251327 = 23.87 MPa.

The governing torsion relations used are: T(x) from static equilibrium, φ = T L / (G J), and τ_max = T c / J.
The reaction torque at the fixed wall (x = 0) equals the negative of the net internal torque in Segment 1: T_reaction = -150000 N·mm.
Verify equilibrium: T_reaction + T2 + T1 = -150000 + (-150000) + 300000 = 0. Equilibrium is satisfied.
