The shaft is a stepped solid circular shaft fixed at end A, with segment AB (length L1 = 400 mm, diameter d1 = 25 mm) and segment BC (length L2 = 900 mm, diameter d2 = 30 mm).
A torque T = 750000 N·mm is applied at end C.
The shear modulus is G = 25939.8 MPa throughout.
Use N, mm, and MPa units throughout.
Assume small-deformation linear-elastic behavior.
Assume the material is homogeneous and isotropic.
Assume the shaft is straight and prismatic within each segment.
Assume Saint-Venant torsion applies (plane sections remain plane, no warping restraint).
Assume the fixed support at A provides full rotational restraint (zero twist at A).
Assume no shear force, bending moment, or axial force is present — pure torque only.
Since the shaft is statically determinate under pure torque with one fixed end and one free loaded end, the internal torque in both segments equals the applied torque T = 750000 N·mm.

Polar second moment of area for a solid circular cross-section:
J = pi * d^4 / 32

For segment AB: J1 = pi * (25)^4 / 32 = pi * 390625 / 32 = 38349.5 mm^4
For segment BC: J2 = pi * (30)^4 / 32 = pi * 810000 / 32 = 79521.6 mm^4

Shear stress in each segment (maximum, at the outer surface):
tau = T * r / J, where r = d/2

For segment AB: r1 = 12.5 mm, tau1 = 750000 * 12.5 / 38349.5 = 244.4 MPa
For segment BC: r2 = 15.0 mm, tau2 = 750000 * 15.0 / 79521.6 = 141.5 MPa

Angle of twist in each segment:
phi = T * L / (G * J)

For segment AB: phi1 = 750000 * 400 / (25939.8 * 38349.5) = 300000000 / 994668000 = 0.30161 rad
For segment BC: phi2 = 750000 * 900 / (25939.8 * 79521.6) = 675000000 / 2062700000 = 0.32724 rad

Total twist at end C relative to fixed end A:
phi_total = phi1 + phi2 = 0.30161 + 0.32724 = 0.62885 rad

Summary of results:
Maximum shear stress in segment AB: tau1 = 244.4 MPa (governs).
Maximum shear stress in segment BC: tau2 = 141.5 MPa.
Twist of segment AB: phi1 = 0.3016 rad.
Twist of segment BC: phi2 = 0.3272 rad.
Total twist at C: phi_total = 0.6289 rad.
