The shaft is a stepped solid circular shaft fixed at end A and free at end C, loaded only by a torque T = 300,000 N·mm applied at end C.

Use small-deformation, linear-elastic solid mechanics throughout.

Use N, mm, and MPa as the unit system throughout.

Assume the shaft is in pure torsion only; no bending, axial, or transverse shear loads are present.

Assume the material is homogeneous and isotropic in both segments with shear modulus G = 25,939.8 MPa.

Assume both segments are prismatic (constant cross-section within each segment).

Assume the fixed support at A provides a perfect wall condition: zero rotation at A.

Assume Saint-Venant torsion theory applies; cross-sections remain plane and circular.

Segment AB has length L1 = 300 mm and diameter d1 = 20 mm.

Segment BC has length L2 = 500 mm and diameter d2 = 30 mm.

The applied torque is T = 300,000 N·mm at end C.

Because the shaft is statically determinate in torsion (one fixed end, one free end, single external torque), the internal torque in both segments equals T = 300,000 N·mm throughout.

Compute the polar second moment of area for each segment using J = π d⁴ / 32.

For segment AB: J1 = π (20)⁴ / 32 = π (160,000) / 32 = 15,707.96 mm⁴.

For segment BC: J2 = π (30)⁴ / 32 = π (810,000) / 32 = 79,521.56 mm⁴.

Compute the maximum shear stress in each segment using τ_max = T c / J, where c is the outer radius.

For segment AB: c1 = 10 mm, τ1 = 300,000 × 10 / 15,707.96 = 190.99 MPa.

For segment BC: c2 = 15 mm, τ2 = 300,000 × 15 / 79,521.56 = 56.59 MPa.

The maximum shear stress in the shaft is 190.99 MPa, occurring in segment AB.

Compute the angle of twist in each segment using φ = T L / (G J).

For segment AB: φ1 = 300,000 × 300 / (25,939.8 × 15,707.96) = 90,000,000 / 407,380,000 = 0.22093 rad.

For segment BC: φ2 = 300,000 × 500 / (25,939.8 × 79,521.56) = 150,000,000 / 2,062,800,000 = 0.072718 rad.

Compute the total angle of twist at end C relative to the fixed end A by summing the two segment twists.

Total twist φ_total = φ1 + φ2 = 0.22093 + 0.072718 = 0.29365 rad.

Convert to degrees if desired: 0.29365 rad × (180 / π) = 16.824 degrees.

State the governing torsion relations used.

Shear stress distribution: τ(r) = T r / J, maximum at the outer fiber.

Angle of twist per segment: φ = T L / (G J).

Total twist for a stepped shaft: φ_total = Σ (T_i L_i) / (G J_i) summed over all segments.
