Beam type is Euler-Bernoulli, simply supported at both ends, span L = 3500 mm.
Material and cross-section are linearly elastic and prismatic, so flexural rigidity EI is constant along the span.
Small-deformation theory applies throughout.
Self-weight of the beam is neglected unless EI is given to include it.
The two applied loads are: a uniformly distributed transverse load w = 0.3 N/mm acting downward over the full span, and a concentrated point load P = 1200 N acting downward at midspan (x = L/2 = 1750 mm).
Deflection is determined by superposition: compute the deflection due to each load separately using the standard closed-form solutions for a simply supported beam, then add the results algebraically at every position x.

Governing differential equation for each load case is EI d⁴v/dx⁴ = q(x), where v(x) is the transverse deflection (positive downward) and q(x) is the distributed load intensity.
Boundary conditions are v(0) = 0, v(L) = 0, v''(0) = 0, v''(L) = 0 (zero deflection and zero moment at both simple supports).

Load Case 1 — UDL w over full span.
Reaction at each support is R = wL/2 = 0.3 × 3500 / 2 = 525 N.
Deflection at position x is v1(x) = (w / 24EI)(x⁴ - 2Lx³ + L³x).
Maximum deflection occurs at midspan: v1_max = 5wL⁴ / 384EI.
Substituting numbers: v1_max = 5 × 0.3 × 3500⁴ / (384 × EI) = 5 × 0.3 × 1.500625 × 10¹³ / (384 × EI).
Numerically v1_max = 5.627 × 10¹² / EI mm (with EI in N·mm²).
Bending moment at position x is M1(x) = (w/2)(Lx - x²).
Maximum moment at midspan is M1_max = wL²/8 = 0.3 × 3500² / 8 = 459375 N·mm.

Load Case 2 — Point load P = 1200 N at midspan a = L/2.
Reaction at each support is R = P/2 = 600 N.
For 0 ≤ x ≤ L/2, deflection is v2(x) = (Px / 48EI)(3L² - 4x²).
Maximum deflection occurs at midspan: v2_max = PL³ / 48EI.
Substituting numbers: v2_max = 1200 × 3500³ / (48 × EI) = 1200 × 4.2875 × 10¹⁰ / (48 × EI).
Numerically v2_max = 1.072 × 10¹² / EI mm (with EI in N·mm²).
Bending moment for 0 ≤ x ≤ L/2 is M2(x) = Px/2.
Maximum moment at midspan is M2_max = PL/4 = 1200 × 3500 / 4 = 1050000 N·mm.

Superposition — total response.
Total deflection at position x (for 0 ≤ x ≤ L/2) is v(x) = v1(x) + v2(x) = (w/24EI)(x⁴ - 2Lx³ + L³x) + (Px/48EI)(3L² - 4x²).
Total maximum deflection at midspan is v_max = v1_max + v2_max = (5wL⁴/384EI) + (PL³/48EI).
Factoring: v_max = (L³/EI)(5wL/384 + P/48).
Substituting numbers: v_max = (3500³/EI)(5 × 0.3 × 3500/384 + 1200/48).
Compute each bracket term: 5 × 0.3 × 3500 / 384 = 5250/384 = 13.672 N/mm² equivalent coefficient; 1200/48 = 25.
Sum = 13.672 + 25 = 38.672.
v_max = (4.2875 × 10¹⁰ / EI) × 38.672 = 1.659 × 10¹² / EI mm (with EI in N·mm²).
Total bending moment at position x (for 0 ≤ x ≤ L/2) is M(x) = M1(x) + M2(x) = (w/2)(Lx - x²) + Px/2.
Total maximum moment at midspan is M_max = wL²/8 + PL/4 = 459375 + 1050000 = 1509375 N·mm = 1509.375 N·m.
Total shear force for 0 < x < L/2 is V(x) = wL/2 + P/2 - wx = 525 + 600 - 0.3x = 1125 - 0.3x N.

Additional assumptions stated.
EI is uniform and must be supplied to obtain numerical deflection values in mm.
Shear deformation and rotary inertia are neglected (Euler-Bernoulli hypothesis).
The beam remains in the elastic range at all load levels.
Deflections are small relative to the span so geometry remains unaffected by loading.
