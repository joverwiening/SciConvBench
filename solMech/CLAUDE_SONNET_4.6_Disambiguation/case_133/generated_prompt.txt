The beam is simply supported and subjected to bending.
Assume small-deformation, linear-elastic material behavior (Euler-Bernoulli beam theory).
Assume the cross-section is a solid rectangle with width b and height h.
Assume the maximum bending moment is given directly as M_max = 6,000,000 N·mm.
Assume the allowable bending stress is σ_allow = 90 MPa.
Assume the beam width is b = 30 mm.
Assume the neutral axis passes through the centroid of the rectangular cross-section (at h/2 from either edge).

The governing relation for bending stress is σ = M · c / I, where c is the distance from the neutral axis to the outermost fiber and I is the second moment of area of the cross-section.

For a solid rectangle, I = b · h³ / 12.
The distance to the outermost fiber is c = h / 2.
The section modulus is S = I / c = b · h² / 6.

The design condition is σ_allow ≥ M_max / S, which gives S_required = M_max / σ_allow.
Compute S_required = 6,000,000 N·mm / 90 N/mm² = 66,667 mm³.

Set the section modulus equal to the required value: b · h² / 6 = S_required.
Substitute b = 30 mm: 30 · h² / 6 = 66,667 mm³, which gives 5 · h² = 66,667 mm³.
Solve for h²: h² = 66,667 / 5 = 13,333 mm².
Solve for h: h = √13,333 ≈ 115.47 mm.

Round h up to the next practical value to ensure the allowable stress is not exceeded.
The minimum required beam height is h ≈ 115.47 mm, to be rounded up in practice (e.g., h = 116 mm or the next standard size).

State the result: for b = 30 mm, M_max = 6,000,000 N·mm, and σ_allow = 90 MPa, the required minimum rectangular beam height is h ≈ 115.47 mm.
