The beam is simply supported and subjected to bending.
Assume small-deformation, linear-elastic material behavior.
Assume the cross-section is a solid rectangle with width b and height h.
Assume the neutral axis passes through the centroid of the rectangular cross-section (at h/2 from either edge).
The maximum bending moment is given directly as M_max = 3,000,000 N·mm.
The allowable bending stress is σ_allow = 90 MPa (N/mm²).
The beam cross-section width is b = 40 mm.
The height h is the unknown to be determined.

Governing relation: the bending stress formula is σ = M · c / I, where c is the distance from the neutral axis to the outermost fiber and I is the second moment of area of the cross-section.

For a solid rectangle: I = b · h³ / 12 and c = h / 2.
Therefore the section modulus is S = I / c = b · h² / 6.

The design condition is σ_allow ≥ M_max / S, which gives S_required = M_max / σ_allow.

Compute S_required: S_required = 3,000,000 / 90 = 33,333.33 mm³.

Set S = b · h² / 6 equal to S_required: 40 · h² / 6 = 33,333.33.
Solve for h²: h² = 33,333.33 · 6 / 40 = 200,000 / 40 = 5,000 mm².
Solve for h: h = √5,000 = 70.71 mm.

Round up to the nearest practical value to satisfy the allowable stress condition.
The required beam height is h ≥ 70.71 mm, so adopt h = 71 mm (or the next standard size above 70.71 mm).

Verify: S_provided = 40 · 71² / 6 = 40 · 5,041 / 6 = 33,606.67 mm³.
Actual stress = 3,000,000 / 33,606.67 = 89.27 MPa, which is less than 90 MPa, so the design is acceptable.
