Problem: Two bars in parallel between two rigid plates, subjected to a total axial tensile load.

Assume small-deformation, linear-elastic behavior throughout.
Assume both bars are perfectly bonded to the rigid plates at each end, so both bars undergo identical axial deformation (compatibility condition).
Assume the load is applied concentrically so no bending or eccentricity is introduced.
Assume self-weight of bars is neglected.
Assume temperature effects are absent.

Given data:
L1 = L2 = L = 800 mm
A1 = 150 mm², E1 = 200000 MPa (structural steel)
A2 = 200 mm², E2 = 110000 MPa (cast iron)
Total applied tensile load P = 30000 N

Compute the axial stiffness of each bar:
k1 = E1 * A1 / L = (200000 * 150) / 800 = 37500 N/mm
k2 = E2 * A2 / L = (110000 * 200) / 800 = 27500 N/mm
Total stiffness k_total = k1 + k2 = 65000 N/mm

Compatibility condition: both bars share the same axial deformation delta.
delta = P / k_total = 30000 / 65000 mm

Compute delta:
delta = 0.4615 mm

Force in each bar using stiffness share:
P1 = (k1 / k_total) * P = (37500 / 65000) * 30000 = 17307.7 N
P2 = (k2 / k_total) * P = (27500 / 65000) * 30000 = 12692.3 N
Verify: P1 + P2 = 30000 N (equilibrium satisfied)

Axial stress in each bar:
sigma1 = P1 / A1 = 17307.7 / 150 = 115.38 MPa (tensile)
sigma2 = P2 / A2 = 12692.3 / 200 = 63.46 MPa (tensile)

Axial strain in each bar (must be equal by compatibility):
epsilon1 = sigma1 / E1 = 115.38 / 200000 = 5.769e-4
epsilon2 = sigma2 / E2 = 63.46 / 110000 = 5.769e-4
Both strains are equal, confirming compatibility is satisfied.

Governing relations summary:
Equilibrium: P1 + P2 = P
Compatibility: delta1 = delta2 = delta
Constitutive: Pi = (Ei * Ai / L) * delta for i = 1, 2
Solution: delta = P / (k1 + k2), Pi = ki * delta, sigma_i = Pi / Ai, epsilon_i = sigma_i / Ei
