The system is a stepped circular bar fixed at the left end with an axial tensile load P = 35000 N applied at the right end.

Use N, mm, and MPa as the unit system throughout.

Assume small deformation and linear-elastic material behavior.
Assume the bar is prismatic within each segment (constant cross-section per segment).
Assume the load is applied as a pure axial force with no bending or torsion.
Assume the material is homogeneous and isotropic in both segments.
Assume stress is uniformly distributed over each cross-section (Saint-Venant assumption away from the step).

Segment 1 (left): length L1 = 300 mm, diameter d1 = 12 mm.
Segment 2 (right): length L2 = 800 mm, diameter d2 = 30 mm.
Both segments: elastic modulus E = 200000 MPa (AISI 1020 steel).
Applied load: P = 35000 N in tension at the right end; left end is fixed.

Compute the cross-sectional area of each segment using A = π d² / 4.
A1 = π (12)² / 4 = 113.097 mm².
A2 = π (30)² / 4 = 706.858 mm².

Because the bar is statically determinate (one fixed support, one axial load), the internal axial force in each segment equals P by equilibrium.
N1 = N2 = 35000 N (tensile).

Compute the axial normal stress in each segment using σ = N / A.
σ1 = 35000 / 113.097 = 309.5 MPa (tensile).
σ2 = 35000 / 706.858 = 49.5 MPa (tensile).

Compute the elongation of each segment using δ = N L / (A E).
δ1 = (35000 × 300) / (113.097 × 200000) = 0.4642 mm.
δ2 = (35000 × 800) / (706.858 × 200000) = 0.1979 mm.

Compute the total elongation as the sum of the two segment elongations.
δ_total = δ1 + δ2 = 0.4642 + 0.1979 = 0.6621 mm.

Summary of results:
Stress in Segment 1: σ1 = 309.5 MPa (tensile).
Stress in Segment 2: σ2 = 49.5 MPa (tensile).
Elongation of Segment 1: δ1 = 0.4642 mm.
Elongation of Segment 2: δ2 = 0.1979 mm.
Total elongation of the bar: δ_total = 0.6621 mm.
