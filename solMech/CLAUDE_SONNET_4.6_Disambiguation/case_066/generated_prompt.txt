The shaft is a solid circular cross-section subjected to pure torque only; no transverse shear force is applied.

Assume small deformations and linear-elastic isotropic material behavior throughout.

Assume the shaft is prismatic (constant cross-section) along its entire length.

Assume the torque is applied along the longitudinal axis and is constant along the length (no distributed torque).

Assume one end is fixed and the torque is applied at the free end for the angle-of-twist calculation.

Use the following given values in N, mm, and MPa units:
Diameter d = 45 mm
Radius c = d / 2 = 22.5 mm
Length L = 1000 mm
Torque T = 400,000 N·mm
Shear modulus G = 76,923.1 MPa

Compute the polar moment of inertia J for a solid circular cross-section using J = π·d⁴ / 32.
J = π·(45)⁴ / 32 = π·4,100,625 / 32 = 402,124.0 mm⁴ (retain at least 4 significant figures).

Compute the maximum shear stress τ_max at the outer surface using the torsion formula τ_max = T·c / J.
τ_max = 400,000 · 22.5 / 402,124.0 = 9,000,000 / 402,124.0 ≈ 22.38 MPa.

The maximum shear stress τ_max ≈ 22.38 MPa occurs at the outer radius of the shaft.

The shear stress distribution is linear from zero at the centroidal axis to τ_max at the outer surface, given by τ(r) = T·r / J for 0 ≤ r ≤ c.

Compute the angle of twist φ using φ = T·L / (G·J).
φ = 400,000 · 1000 / (76,923.1 · 402,124.0) = 400,000,000 / 30,932,630,440 ≈ 0.012931 radians.

Convert the angle of twist to degrees using φ_deg = φ · (180 / π).
φ_deg ≈ 0.012931 · 57.2958 ≈ 0.7409 degrees.

State the governing relations explicitly:
Polar moment of inertia: J = π·d⁴ / 32
Torsional shear stress: τ = T·r / J, with maximum τ_max = T·c / J at r = c
Angle of twist: φ = T·L / (G·J)

All results are valid only within the elastic range; verify that τ_max does not exceed the shear yield strength of the chosen material.
