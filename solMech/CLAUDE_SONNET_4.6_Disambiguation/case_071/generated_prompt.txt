Perform a plane stress analysis of a structural member under combined normal and shear loading using small-deformation, linear-elastic solid mechanics.

The cross-section is rectangular with width 50 mm and height 80 mm, giving an area A = 4000 mm².
The axial load is P = 40000 N, producing a uniform average normal stress σx = P/A = 10 MPa.
The shear load is V = 12000 N, producing an average shear stress τxy = V/A = 3 MPa.
Assume the out-of-plane normal stress σz = 0 (plane stress condition).
Assume σy = 0 (no transverse normal stress applied).
Assume the material is isotropic and homogeneous.
Use a representative material with elastic modulus E = 200 GPa and Poisson's ratio ν = 0.3 unless the user specifies otherwise.

Compute the in-plane principal stresses using σ1,2 = (σx + σy)/2 ± sqrt(((σx - σy)/2)² + τxy²).
Compute the maximum in-plane shear stress using τmax = sqrt(((σx - σy)/2)² + τxy²).
Compute the principal angle using θp = 0.5 × arctan(2τxy / (σx - σy)).
Compute the normal strains εx = (σx - ν·σy) / E and εy = (σy - ν·σx) / E.
Compute the shear strain γxy = τxy / G, where the shear modulus G = E / (2(1 + ν)).
Compute the principal strains ε1,2 = (εx + εy)/2 ± sqrt(((εx - εy)/2)² + (γxy/2)²).
Compute the maximum in-plane shear strain γmax = 2 × sqrt(((εx - εy)/2)² + (γxy/2)²).
Compute the absolute maximum shear stress considering all three principal stresses, including the out-of-plane zero principal stress.
Present the Mohr's circle parameters: center C = (σx + σy)/2 and radius R = τmax.
Present all results numerically with units of MPa for stresses and dimensionless (×10⁻⁶ or με) for strains.
