Model a cantilever Euler-Bernoulli beam of length L, fixed at x = 0 and free at x = L.
Apply a single downward point load P = 500 N at the free end (x = L).
No applied moment acts anywhere on the beam.
Assume small deformations and linear-elastic material behavior throughout.
Assume the beam is homogeneous, prismatic, and has a uniform cross-section with constant flexural rigidity EI.
Assume the beam's self-weight is neglected (no distributed load).
Assume Euler-Bernoulli beam theory: plane sections remain plane, shear deformations are neglected, and rotations are small.
Define x as the coordinate along the beam axis measured from the fixed end, and v(x) as the transverse deflection (positive upward).

Governing differential equation:
EI * d4v/dx4 = q(x) = 0 for 0 <= x < L (no distributed load).

Boundary conditions:
At x = 0 (fixed end): v(0) = 0 (no deflection) and dv/dx(0) = 0 (no rotation).
At x = L (free end): EI * d2v/dx2 = 0 (zero bending moment) and EI * d3v/dx3 = -P (shear force equals applied load, with downward load convention giving -P).

Integrate the governing equation four times and apply the four boundary conditions to determine the constants of integration.

Resulting deflection profile:
v(x) = (P / (6EI)) * (3Lx^2 - x^3) for 0 <= x <= L.

Maximum deflection occurs at the free end (x = L):
v_max = PL^3 / (3EI).

Substituting P = 500 N:
v_max = (500 * L^3) / (3EI).

Slope (rotation) along the beam:
dv/dx = (P / (2EI)) * (2Lx - x^2).

Maximum slope occurs at the free end (x = L):
theta_max = PL^2 / (2EI) = (500 * L^2) / (2EI).

Bending moment distribution:
M(x) = -EI * d2v/dx2 = -P(L - x) for 0 <= x <= L.

Maximum bending moment occurs at the fixed end (x = 0):
M_max = -PL = -500L N·m (negative indicating hogging).

Shear force distribution:
V(x) = -EI * d3v/dx3 = P = 500 N (constant along the entire beam).

Reaction at the fixed end:
Vertical reaction force = P = 500 N (upward).
Reaction moment = PL = 500L N·m (hogging, resisting the applied load).

To obtain numerical values for v_max, theta_max, and M_max, provide the beam length L and the flexural rigidity EI (or separately, the elastic modulus E and the second moment of area I).
