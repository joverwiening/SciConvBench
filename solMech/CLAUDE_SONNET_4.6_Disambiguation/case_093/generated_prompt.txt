The beam is a simply supported beam of span L = 3000 mm with pinned support at x = 0 and roller support at x = L.
A single point load P = 800 N acts vertically downward at x = a = 2000 mm from the left support.
There is no distributed load and no applied moment anywhere on the beam.
The deflection is to be evaluated at x = a = 2000 mm, the same location as the point load.
Assume small deformations and linear-elastic material behavior throughout.
Assume the beam has a uniform cross-section with constant flexural rigidity EI along its entire length.
Assume the beam is prismatic, straight, and slender so that Euler-Bernoulli beam theory applies.
Neglect shear deformation (no Timoshenko correction).
Neglect self-weight of the beam.

Define b = L - a = 3000 - 2000 = 1000 mm as the distance from the load to the right support.

Compute the support reactions under the actual load P.
Left reaction: R_A = P·b/L = 800·1000/3000 = 266.67 N.
Right reaction: R_B = P·a/L = 800·2000/3000 = 533.33 N.

Apply the unit-load method (virtual work / Mohr's integral).
Place a virtual unit load Q = 1 N downward at x = a = 2000 mm, the point where deflection is sought.
The virtual load is identical in position to the real load, so the virtual bending moment diagram m(x) has the same shape as the real bending moment diagram M(x), scaled by factor 1/P.

Compute the real bending moment M(x) in two regions.
For 0 ≤ x ≤ a: M(x) = R_A · x = (P·b/L)·x.
For a ≤ x ≤ L: M(x) = R_A · x - P·(x - a) = (P·a/L)·(L - x).

Compute the virtual bending moment m(x) due to Q = 1 N at x = a.
For 0 ≤ x ≤ a: m(x) = (1·b/L)·x = (b/L)·x.
For a ≤ x ≤ L: m(x) = (a/L)·(L - x).

Apply the unit-load deflection integral.
delta = (1/EI) · [integral from 0 to L of M(x)·m(x) dx].

Evaluate the integral over the two regions.
Integral over 0 to a: integral of (P·b/L)·x · (b/L)·x dx = (P·b²/L²)·[x³/3] from 0 to a = P·b²·a³/(3·L²).
Integral over a to L: integral of (P·a/L)·(L-x) · (a/L)·(L-x) dx = (P·a²/L²)·[(L-x)³/(-3)] evaluated from a to L = P·a²·b³/(3·L²).

Sum the two integrals.
Total integral = P·b²·a³/(3·L²) + P·a²·b³/(3·L²) = P·a²·b²·(a + b)/(3·L²) = P·a²·b²·L/(3·L²) = P·a²·b²/(3·L).

The deflection at x = a is therefore:
delta = P·a²·b²/(3·E·I·L).

Substitute numerical values (with a = 2000 mm, b = 1000 mm, L = 3000 mm, P = 800 N).
delta = 800·(2000)²·(1000)²/(3·E·I·3000).
delta = 800·4·10⁶·1·10⁶/(9000·E·I).
delta = 3.2·10¹⁵/(9000·E·I).
delta = 3.556·10¹¹/(E·I) mm, where E is in N/mm² and I is in mm⁴.

This result is exact within Euler-Bernoulli beam theory for a simply supported beam with a single point load.
To obtain a numerical value, substitute the known cross-sectional moment of inertia I (mm⁴) and elastic modulus E (N/mm²) for the beam material and section.
