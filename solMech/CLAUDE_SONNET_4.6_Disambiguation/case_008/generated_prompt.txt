The system consists of two bars connected in parallel between two rigid plates, analyzed under small-deformation, linear-elastic assumptions.

Bar 1 is AISI 1020 steel with cross-sectional area A₁ = 300 mm², elastic modulus E₁ = 200000 MPa, and length L = 500 mm.
Bar 2 is 6061-T6 aluminum with cross-sectional area A₂ = 200 mm², elastic modulus E₂ = 69000 MPa, and length L = 500 mm.
A total tensile axial load P = 20000 N is applied to the top rigid plate and reacted at the bottom rigid plate.
Both bars share the same length L = 500 mm.

Additional assumptions:
The two rigid plates remain perfectly parallel and do not rotate, so both bars experience identical axial deformation (compatibility condition).
Both bars are pin-connected to the rigid plates with no bending or shear transfer.
Self-weight of the bars is neglected.
The load is applied concentrically so no eccentricity or moment is introduced.
Material behavior is linear-elastic throughout; no yielding occurs.

Governing relations:

Compatibility: both bars undergo the same axial elongation delta.
delta = delta_1 = delta_2

Force-deformation relations:
delta_1 = (F₁ * L) / (A₁ * E₁)
delta_2 = (F₂ * L) / (A₂ * E₂)

Equilibrium:
F₁ + F₂ = P = 20000 N

Define axial stiffnesses:
k₁ = (A₁ * E₁) / L = (300 * 200000) / 500 = 120000 N/mm
k₂ = (A₂ * E₂) / L = (200 * 69000) / 500 = 27600 N/mm
k_total = k₁ + k₂ = 147600 N/mm

Load sharing by stiffness ratio:
F₁ = P * (k₁ / k_total) = 20000 * (120000 / 147600) = 16260.2 N
F₂ = P * (k₂ / k_total) = 20000 * (27600 / 147600) = 3739.8 N

Common elongation:
delta = P / k_total = 20000 / 147600 = 0.1355 mm

Axial stresses:
sigma₁ = F₁ / A₁ = 16260.2 / 300 = 54.20 MPa (tensile)
sigma₂ = F₂ / A₂ = 3739.8 / 200 = 18.70 MPa (tensile)

Axial strains:
epsilon₁ = sigma₁ / E₁ = 54.20 / 200000 = 2.710 × 10⁻⁴
epsilon₂ = sigma₂ / E₂ = 18.70 / 69000 = 2.710 × 10⁻⁴
Both strains are equal, confirming compatibility is satisfied.

Summary of results:
F₁ = 16260.2 N, sigma₁ = 54.20 MPa, epsilon₁ = 2.710 × 10⁻⁴
F₂ = 3739.8 N, sigma₂ = 18.70 MPa, epsilon₂ = 2.710 × 10⁻⁴
Common elongation delta = 0.1355 mm
