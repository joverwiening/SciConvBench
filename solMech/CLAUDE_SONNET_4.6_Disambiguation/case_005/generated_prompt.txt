The bar is prismatic with three segments: AB, BC, and CD.
The left end A is fixed (zero displacement). The right end D is free.
Point loads are applied at B (+18000 N), C (-8000 N), and D (+20000 N); positive is taken as rightward.
Cross-sectional area A = 200 mm² is uniform across all segments.
Elastic modulus E = 200000 MPa is uniform across all segments.
Assume small deformation and linear-elastic material behavior throughout.
Assume the bar is straight, prismatic, and loaded purely axially (no bending or shear).
Assume self-weight is neglected.

Governing relations:

The internal axial force N(x) in each segment is found by method of sections using equilibrium.
Starting from the fixed end A, apply global equilibrium to find the wall reaction R_A.

Global equilibrium (sum of all external forces = 0):
R_A + 18000 + (-8000) + 20000 = 0
R_A = -30000 N (i.e., 30000 N directed leftward).

Internal axial force in each segment by sectioning from the left:
N_AB = R_A = -30000 N (compressive, 30000 N).
N_BC = R_A + 18000 = -30000 + 18000 = -12000 N (compressive, 12000 N).
N_CD = R_A + 18000 - 8000 = -30000 + 10000 = -20000 N... 

Recheck: N_CD = -30000 + 18000 - 8000 = -20000 N; verify with free end: N_CD must equal -20000 N (the end load of 20000 N rightward means section from right gives N_CD = +20000 N rightward on right face, so N_CD = +20000 N tensile when sectioned from right).

Resolve sign convention: define positive N as tension (rightward on right-facing cut face).
Sectioning from the right end is cleaner for verification.

From the right (free end D), moving leftward:
N_CD = +20000 N (tension), because the only force to the right of a cut in CD is the 20000 N rightward end load.
N_BC = 20000 - (-8000) ... 

Use consistent left-to-right sectioning with R_A = -30000 N (leftward = negative):
N_AB: cut in AB, sum forces to the left: N_AB = -R_A = +30000 N ... 

Adopt the standard: N in a segment = sum of all external forces to the LEFT of the cut, positive rightward.
R_A acts leftward, so R_A = -30000 N as an external force value.
N_AB = R_A = -30000 N → 30000 N compressive.
N_BC = R_A + P_B = -30000 + 18000 = -12000 N → 12000 N compressive.
N_CD = R_A + P_B + P_C = -30000 + 18000 + (-8000) = -20000 N → 20000 N compressive.

Verify from right: only force to the right of a cut in CD is P_D = +20000 N rightward; equilibrium of right portion gives N_CD (acting leftward on right portion) = 20000 N, so N_CD = -20000 N on left portion. Consistent.

Axial stress in each segment: σ = N / A.
σ_AB = -30000 / 200 = -150 MPa (compressive).
σ_BC = -12000 / 200 = -60 MPa (compressive).
σ_CD = -20000 / 200 = -100 MPa (compressive).

Axial strain in each segment: ε = σ / E.
ε_AB = -150 / 200000 = -0.00075.
ε_BC = -60 / 200000 = -0.00030.
ε_CD = -100 / 200000 = -0.00050.

Deformation (elongation) of each segment: δ = N·L / (A·E), where L is the length of each segment.
Assign lengths L_AB, L_BC, L_CD (not provided; substitute numerical values once lengths are known).
δ_AB = (-30000 · L_AB) / (200 · 200000) = -0.00075 · L_AB.
δ_BC = (-12000 · L_BC) / (200 · 200000) = -0.00030 · L_BC.
δ_CD = (-20000 · L_CD) / (200 · 200000) = -0.00050 · L_CD.

Displacement at any point is found by accumulating deformations from the fixed end A where u_A = 0.
u_B = u_A + δ_AB = δ_AB.
u_C = u_B + δ_BC.
u_D = u_C + δ_CD.

The total deformation of the bar equals δ_AB + δ_BC + δ_CD.
Negative values indicate shortening (compressive segments move leftward relative to A).
