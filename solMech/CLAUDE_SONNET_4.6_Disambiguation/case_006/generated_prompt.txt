The beam is a simply supported beam of span L with both ends pinned (one pin, one roller), under small-deformation, linear-elastic conditions.

The beam has uniform cross-section with constant flexural rigidity EI throughout its length.

A single point load P = 1200 N acts vertically downward at x = L/2 (midspan), where L = 2400 mm.

There is no distributed load and no applied moment anywhere on the beam.

The goal is to determine the deflection at an arbitrary point x = a along the beam using the unit-load method (also called the virtual work method or method of virtual forces).

Assume Euler-Bernoulli beam theory: plane sections remain plane, shear deformations are neglected, and deflection is due to bending only.

Assume the beam material is homogeneous and isotropic with Young's modulus E and second moment of area I (both constant).

Step 1: Determine the real bending moment diagram M(x) due to P = 1200 N at x = L/2.

The reactions are R_A = R_B = P/2 = 600 N (by symmetry).

For 0 ≤ x ≤ L/2: M(x) = (P/2) * x = 600x (N·mm, with x in mm).

For L/2 ≤ x ≤ L: M(x) = (P/2) * (L - x) = 600(L - x).

Step 2: Apply a unit virtual load (Q = 1 N) downward at the arbitrary point x = a where deflection is sought.

The virtual reactions are r_A = (L - a)/L and r_B = a/L.

For 0 ≤ x ≤ a: m(x) = [(L - a)/L] * x.

For a ≤ x ≤ L: m(x) = (a/L) * (L - x).

Step 3: Apply the unit-load (virtual work) equation for deflection.

The deflection at x = a is given by:

delta(a) = integral from 0 to L of [M(x) * m(x) / (EI)] dx.

Step 4: Evaluate the integral by splitting at both x = a and x = L/2.

Case A — Deflection at midspan (a = L/2), using symmetry:

delta(L/2) = 2 * integral from 0 to L/2 of [(P/2)*x * (x/2)] / (EI) dx

delta(L/2) = (P * L^3) / (48 * EI).

Substituting P = 1200 N and L = 2400 mm:

delta(L/2) = (1200 * 2400^3) / (48 * EI) = (1200 * 1.3824 × 10^10) / (48 * EI).

delta(L/2) = 1.6589 × 10^12 / (48 * EI) = 3.456 × 10^10 / EI (N·mm³ / (N·mm²)) = 3.456 × 10^10 / EI mm.

Case B — Deflection at arbitrary point a ≤ L/2 (by symmetry the result for a ≥ L/2 is obtained by replacing a with L - a):

delta(a) = (P * a * (3L^2 - 4a^2)) / (48 * EI), valid for 0 ≤ a ≤ L/2.

Substituting P = 1200 N and L = 2400 mm:

delta(a) = [1200 * a * (3*(2400)^2 - 4a^2)] / (48 * EI).

delta(a) = [25 * a * (17280000 - 4a^2)] / EI (with a in mm, delta in mm, EI in N·mm²).

The maximum deflection occurs at midspan and equals PL^3/(48EI) = 3.456 × 10^10 / EI mm.
