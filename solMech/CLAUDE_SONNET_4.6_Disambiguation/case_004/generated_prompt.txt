The bar is prismatic with constant cross-section A = 300 mm² and elastic modulus E = 200000 MPa throughout.

The bar has three segments: AB, BC, and CD, with point loads applied at B, C, and D.

The boundary condition is u_A = 0 (fixed at A); end D is free.

Positive direction is rightward; tensile internal forces and rightward displacements are positive.

Assume small deformations and linear-elastic material behavior (Hooke's law applies).

Assume the bar is straight, prismatic, and that loads are applied exactly along the centroidal axis (no bending or shear).

Assume self-weight is neglected.

The axial stiffness of each segment is k = EA/L, where L is the length of the respective segment.

Step 1 – Find the reaction at A using global equilibrium.

Sum of all external forces = 0: R_A + 18000 − 12000 + 16000 = 0, giving R_A = −22000 N (i.e., 22000 N leftward).

Step 2 – Determine internal axial force in each segment by method of sections (cut each segment and apply equilibrium to the left portion).

Segment AB: N_AB = −R_A = 22000 N (tensile).

Segment BC: N_BC = N_AB − 18000 = 22000 − 18000 = 4000 N (tensile).

Segment CD: N_CD = N_BC + 12000 = 4000 + 12000 = 16000 N (tensile).

Verify at D: N_CD − 16000 = 0, which is satisfied (free end condition confirmed).

Step 3 – Compute axial stress in each segment using σ = N/A.

σ_AB = 22000 / 300 = 73.33 MPa (tensile).

σ_BC = 4000 / 300 = 13.33 MPa (tensile).

σ_CD = 16000 / 300 = 53.33 MPa (tensile).

Step 4 – Compute axial strain in each segment using ε = σ/E = N/(EA).

ε_AB = 73.33 / 200000 = 3.667 × 10⁻⁴ (elongation per unit length).

ε_BC = 13.33 / 200000 = 6.667 × 10⁻⁵ (elongation per unit length).

ε_CD = 53.33 / 200000 = 2.667 × 10⁻⁴ (elongation per unit length).

Step 5 – Compute elongation of each segment using δ = NL/(EA), where L_AB, L_BC, L_CD are the respective segment lengths (to be substituted once lengths are known).

δ_AB = (22000 × L_AB) / (200000 × 300) = 22000 L_AB / 60000000.

δ_BC = (4000 × L_BC) / (200000 × 300) = 4000 L_BC / 60000000.

δ_CD = (16000 × L_CD) / (200000 × 300) = 16000 L_CD / 60000000.

Step 6 – Compute displacements using u_A = 0 as the reference.

u_B = u_A + δ_AB = δ_AB.

u_C = u_B + δ_BC.

u_D = u_C + δ_CD.

The governing relation for each segment is N = EA (du/dx), where u(x) is the axial displacement field.

The internal force diagram is piecewise constant: N = 22000 N on AB, N = 4000 N on BC, N = 16000 N on CD.

The stress diagram is piecewise constant and directly proportional to the internal force diagram via σ = N/A.

The displacement field is piecewise linear within each segment, with slope equal to the axial strain of that segment.
