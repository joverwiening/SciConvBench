The shaft is a solid circular cross-section with diameter d = 25 mm.

The applied axial tensile force is P = 25000 N acting along the shaft axis.

The applied torque is T = 300000 N·mm acting about the shaft axis.

Assume small-deformation, linear-elastic solid mechanics throughout.

Assume the shaft is prismatic, homogeneous, and isotropic.

Assume the cross-section is far from any stress concentration or end effects (Saint-Venant's principle applies).

No material properties are required since only stress quantities are to be determined.

Compute the cross-sectional area A = π·d²/4.

A = π·(25)²/4 = 490.874 mm².

Compute the polar moment of inertia J = π·d⁴/32.

J = π·(25)⁴/32 = 38349.5 mm⁴.

Compute the outer radius c = d/2 = 12.5 mm.

Compute the axial (normal) stress due to the axial load: σ_x = P/A.

σ_x = 25000 / 490.874 = 50.93 MPa (tensile, positive).

Compute the shear stress due to torsion at the outer surface: τ = T·c/J.

τ = 300000 · 12.5 / 38349.5 = 97.83 MPa.

The stress state at the critical point on the outer surface is: normal stress σ_x = 50.93 MPa, shear stress τ_xy = 97.83 MPa, and σ_y = 0.

Compute the average normal stress: σ_avg = (σ_x + σ_y)/2 = (50.93 + 0)/2 = 25.465 MPa.

Compute the radius of Mohr's circle: R = sqrt(((σ_x - σ_y)/2)² + τ²) = sqrt((25.465)² + (97.83)²).

R = sqrt(648.47 + 9570.71) = sqrt(10219.18) = 101.09 MPa.

Compute the maximum principal stress: σ_1 = σ_avg + R = 25.465 + 101.09 = 126.56 MPa.

Compute the minimum principal stress: σ_2 = σ_avg - R = 25.465 - 101.09 = -75.62 MPa.

Compute the maximum in-plane shear stress: τ_max = R = 101.09 MPa.

Compute the orientation of the principal plane: tan(2θ_p) = 2τ/(σ_x - σ_y) = 2·97.83/(50.93 - 0) = 195.66/50.93 = 3.842.

2θ_p = arctan(3.842) = 75.41 degrees, so θ_p = 37.70 degrees from the x-axis to the σ_1 plane.

The von Mises equivalent stress is: σ_vm = sqrt(σ_1² - σ_1·σ_2 + σ_2²).

σ_vm = sqrt((126.56)² - (126.56)·(-75.62) + (-75.62)²).

σ_vm = sqrt(16017.43 + 9571.47 + 5718.38) = sqrt(31307.28) = 176.94 MPa.

Alternatively, σ_vm = sqrt(σ_x² + 3τ²) = sqrt((50.93)² + 3·(97.83)²) = sqrt(2593.87 + 28706.57) = sqrt(31300.44) = 176.92 MPa (consistent).

Summary of results:
Cross-sectional area A = 490.87 mm².
Polar moment of inertia J = 38349.5 mm⁴.
Axial normal stress σ_x = 50.93 MPa (tensile).
Torsional shear stress τ = 97.83 MPa.
Maximum principal stress σ_1 = 126.56 MPa.
Minimum principal stress σ_2 = -75.62 MPa.
Maximum in-plane shear stress τ_max = 101.09 MPa.
Principal plane orientation θ_p = 37.70 degrees.
Von Mises equivalent stress σ_vm = 176.93 MPa.
