The shaft is a solid circular cross-section subjected to pure torque only; no transverse shear force is applied.
Assume small-deformation, linear-elastic behavior throughout.
Assume the material is homogeneous and isotropic.
Assume the shaft is prismatic (constant cross-section along its entire length).
Assume Saint-Venant's principle applies and end effects are neglected.

Given values are: T = 400,000 N·mm, L = 1200 mm, d = 30 mm, c = d/2 = 15 mm, G = 39,179.1 MPa.

Compute the polar moment of inertia J for a solid circular shaft using J = (pi * d^4) / 32.
J = (pi * (30)^4) / 32 = (pi * 810,000) / 32 = 79,521.56 mm^4.

Compute the maximum shear stress using the torsion formula tau_max = T * c / J.
tau_max = 400,000 * 15 / 79,521.56 = 6,000,000 / 79,521.56 = 75.45 MPa.
This maximum shear stress occurs at the outer surface of the shaft (r = c = 15 mm).

The shear stress at any interior radius rho is given by tau(rho) = T * rho / J, which varies linearly from zero at the centroidal axis to tau_max at the outer surface.

Compute the angle of twist using phi = T * L / (J * G).
phi = 400,000 * 1200 / (79,521.56 * 39,179.1) = 480,000,000 / 3,115,097,450 = 0.15410 radians.
Convert to degrees: phi = 0.15410 * (180 / pi) = 8.83 degrees.

The governing relations are:
Polar moment of inertia: J = pi * c^4 / 2 = pi * d^4 / 32.
Shear stress distribution: tau(rho) = T * rho / J, with maximum tau_max = T * c / J at the outer fiber.
Angle of twist: phi = T * L / (J * G).

Summary of results:
J = 79,521.56 mm^4.
tau_max = 75.45 MPa at r = 15 mm (outer surface).
phi = 0.15410 radians = 8.83 degrees over the full length L = 1200 mm.
