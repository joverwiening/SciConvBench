The shaft is a solid circular cross-section with diameter d = 30 mm, constant along its entire length L = 1200 mm.
The material is AISI 1020 steel with shear modulus G = 76923.1 MPa.
Assume small-deformation, linear-elastic behavior throughout.
Assume the shaft is straight, prismatic, and loaded purely in torsion (no bending, axial, or transverse shear effects are considered).
Assume Saint-Venant torsion theory applies.

Geometry and section properties:
Compute the polar moment of inertia as J = pi * d^4 / 32 = pi * (30)^4 / 32.
J = pi * 810000 / 32 = 79521.56 mm^4 (use this value throughout).
The outer radius is c = 15 mm.

Loading definition:
T1 = +200000 N·mm is applied at x = 1200 mm (the free end).
T2 = -200000 N·mm is applied at x = 400 mm (an intermediate point).
The shaft is fixed at x = 0 (zero angle of twist) and free at x = 1200 mm.

Reaction torque:
Apply moment equilibrium about the shaft axis.
The wall reaction at x = 0 is T_R = -(T1 + T2) = -(200000 + (-200000)) = 0 N·mm.
The reaction torque at the fixed end is T_R = 0 N·mm.

Internal torque distribution using the method of sections (measuring x from the fixed end at x = 0):
For segment 1, 0 <= x < 400 mm, cut the shaft and sum torques from the left (fixed end).
Internal torque T(x) = T_R = 0 N·mm in this segment.
For segment 2, 400 mm <= x < 1200 mm, the applied torque T2 = -200000 N·mm has been passed.
Internal torque T(x) = T_R + T2 = 0 + (-200000) = -200000 N·mm in this segment.
At x = 1200 mm, T1 = +200000 N·mm is applied, which closes the equilibrium: -200000 + 200000 = 0 (free end condition satisfied).

Shear stress in each segment:
Use the torsion formula tau = T * c / J.
For segment 1 (0 <= x < 400 mm): tau_1 = 0 * 15 / 79521.56 = 0 MPa.
For segment 2 (400 mm <= x < 1200 mm): tau_2 = |-200000| * 15 / 79521.56 = 3000000 / 79521.56 = 37.73 MPa.
The maximum shear stress in the shaft is tau_max = 37.73 MPa, occurring on the outer surface throughout segment 2.

Angle of twist distribution (measuring from the fixed end where phi(0) = 0):
Use the relation d(phi)/dx = T(x) / (G * J).
G * J = 76923.1 * 79521.56 = 6.117 x 10^9 N·mm^2.
For segment 1 (0 <= x <= 400 mm): d(phi)/dx = 0 / (G*J) = 0, so phi(x) = 0.
phi(400) = 0 radians.
For segment 2 (400 mm <= x <= 1200 mm): d(phi)/dx = -200000 / (6.117 x 10^9) = -3.269 x 10^-5 rad/mm.
phi(x) = phi(400) + (-3.269 x 10^-5) * (x - 400).
phi(x) = -3.269 x 10^-5 * (x - 400) for 400 <= x <= 1200 mm.
At the free end x = 1200 mm: phi(1200) = -3.269 x 10^-5 * 800 = -0.02615 radians = -1.498 degrees.

Summary of results:
Reaction torque at fixed end: T_R = 0 N·mm.
Internal torque in segment 1 (0 to 400 mm): 0 N·mm.
Internal torque in segment 2 (400 to 1200 mm): -200000 N·mm.
Maximum shear stress: 37.73 MPa, located on the outer surface of segment 2.
Angle of twist at x = 400 mm: 0 radians.
Angle of twist at x = 1200 mm (free end): -0.02615 radians (-1.498 degrees).
The negative sign on the torque and twist in segment 2 indicates the sense is opposite to the positive convention (right-hand rule about the positive x-axis).
