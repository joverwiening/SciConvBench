The problem is a straight prismatic circular rod under uniaxial tensile axial load.

Assume small-deformation, linear-elastic, isotropic, homogeneous solid mechanics throughout.
Assume the rod is prismatic, meaning the cross-section is constant along the entire length.
Assume the load P is applied concentrically along the centroidal axis, producing pure axial tension with no bending or torsion.
Assume the material is ductile, so the failure criterion is yielding, and the yield strength Sy is used for the factor of safety.
Assume Saint-Venant's principle applies, meaning stress is uniform over the cross-section away from the load application points.

Given values are: axial load P = 15000 N, rod diameter d = 30 mm, rod length L = 800 mm, yield strength Sy = 275 MPa, elastic modulus E = 69000 MPa.

Compute the cross-sectional area using A = pi * d^2 / 4.
A = pi * (30)^2 / 4 = 706.86 mm^2.

Compute the average normal stress using sigma = P / A.
sigma = 15000 / 706.86 = 21.22 MPa (tensile).

Compute the axial strain using epsilon = sigma / E.
epsilon = 21.22 / 69000 = 3.075 x 10^-4 (dimensionless).

Compute the total elongation using delta = P * L / (A * E), equivalently delta = epsilon * L.
delta = 3.075 x 10^-4 * 800 = 0.246 mm.

Compute the factor of safety with respect to yielding using FS = Sy / sigma.
FS = 275 / 21.22 = 12.96.

Summary of results:
Cross-sectional area A = 706.86 mm^2.
Average normal stress sigma = 21.22 MPa (tensile).
Axial strain epsilon = 3.075 x 10^-4.
Total elongation delta = 0.246 mm.
Factor of safety against yielding FS = 12.96.

The rod is well within the elastic range, the stress is far below the yield strength, and the factor of safety is large, indicating the design is structurally safe under the given load.
