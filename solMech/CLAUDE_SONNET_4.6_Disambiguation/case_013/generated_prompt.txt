Beam type is Euler-Bernoulli, simply supported, span L = 3000 mm.
Material and cross-section are linearly elastic and homogeneous with constant flexural rigidity EI along the full span.
Small-deformation theory applies throughout.
Self-weight of the beam is neglected unless EI is given with it included.
Positive deflection is taken as downward.
The x-axis runs from the left support (A) to the right support (B).

Load case 1: Uniformly distributed load (UDL), intensity w = 0.3 N/mm, acting downward over the full span 0 ≤ x ≤ L.
Load case 2: Concentrated point load P = 3000 N acting downward at midspan x = L/2 = 1500 mm.

Governing equation for each load case is EI d⁴v/dx⁴ = q(x), where v(x) is the transverse deflection and q(x) is the distributed load intensity.
Boundary conditions for a simply supported beam are v(0) = 0, v(L) = 0, v''(0) = 0, v''(L) = 0.

By the principle of superposition, the total deflection at any point x is v_total(x) = v_UDL(x) + v_P(x).

Standard closed-form result for Load case 1 (UDL, full span):
v_UDL(x) = (w x (L³ - 2 L x² + x³)) / (24 EI)
Maximum deflection occurs at midspan x = L/2:
v_UDL_max = 5 w L⁴ / (384 EI)

Substitute values: w = 0.3 N/mm, L = 3000 mm.
v_UDL_max = 5 × 0.3 × 3000⁴ / (384 EI)
v_UDL_max = 5 × 0.3 × 8.1 × 10¹⁰ / (384 EI)
v_UDL_max = 1.2150 × 10¹¹ / (384 EI)
v_UDL_max = 3.164 × 10⁸ / EI mm (with EI in N·mm²)

Standard closed-form result for Load case 2 (point load at midspan):
v_P(x) = (P x (3 L² - 4 x²)) / (48 EI) for 0 ≤ x ≤ L/2
Maximum deflection occurs at midspan x = L/2:
v_P_max = P L³ / (48 EI)

Substitute values: P = 3000 N, L = 3000 mm.
v_P_max = 3000 × 3000³ / (48 EI)
v_P_max = 3000 × 2.7 × 10¹⁰ / (48 EI)
v_P_max = 8.1 × 10¹³ / (48 EI)
v_P_max = 1.6875 × 10¹² / (48 EI)
v_P_max = 1.6875 × 10¹² / (48 EI) mm
v_P_max = 3.516 × 10¹⁰ / EI mm (with EI in N·mm²)

Total maximum deflection at midspan by superposition:
v_max = v_UDL_max + v_P_max
v_max = (3.164 × 10⁸ + 3.516 × 10¹⁰) / EI
v_max = (0.03164 × 10¹⁰ + 3.516 × 10¹⁰) / EI
v_max = 3.548 × 10¹⁰ / EI mm (with EI in N·mm²)

Reaction forces at each support by superposition:
R_A = R_B = wL/2 + P/2
R_A = R_B = (0.3 × 3000)/2 + 3000/2
R_A = R_B = 450 + 1500
R_A = R_B = 1950 N

Maximum bending moment at midspan by superposition:
M_max = w L² / 8 + P L / 4
M_max = 0.3 × 3000² / 8 + 3000 × 3000 / 4
M_max = 0.3 × 9 × 10⁶ / 8 + 9 × 10⁶ / 4
M_max = 337500 + 2250000
M_max = 2587500 N·mm = 2.5875 × 10⁶ N·mm

To obtain a numerical deflection value, provide the value of EI in N·mm².
