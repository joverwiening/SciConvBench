The problem involves a straight prismatic circular rod under uniaxial tensile axial load, analyzed using small-deformation linear-elastic solid mechanics.

Given values are: applied axial load P = 20000 N, diameter d = 25 mm, length L = 800 mm, yield strength Sy = 250 MPa, and elastic modulus E = 200000 MPa.

Assume the load is applied concentrically along the centroidal axis, so bending is absent and the stress state is purely uniaxial.
Assume the material is homogeneous, isotropic, and linear-elastic up to yielding.
Assume the cross-section is uniform along the entire length (prismatic rod).
Assume static loading with no dynamic or fatigue effects.
Assume small deformations so that geometry changes are negligible.

Compute the cross-sectional area using A = π × d² / 4.
A = π × (25)² / 4 = π × 625 / 4 ≈ 490.87 mm².

Compute the average normal stress using σ = P / A.
σ = 20000 N / 490.87 mm² ≈ 40.74 MPa (tensile).

Compute the axial strain using ε = σ / E.
ε = 40.74 MPa / 200000 MPa ≈ 2.037 × 10⁻⁴ (dimensionless).

Compute the total elongation using δ = P × L / (A × E), equivalently δ = ε × L.
δ = 2.037 × 10⁻⁴ × 800 mm ≈ 0.163 mm.

Compute the factor of safety with respect to yielding using FS = Sy / σ.
FS = 250 MPa / 40.74 MPa ≈ 6.14.

The rod does not yield under the given load since σ = 40.74 MPa is well below Sy = 250 MPa.
The factor of safety of approximately 6.14 indicates a large margin against yielding.
No lateral (Poisson) strain or shear stress calculation is required for this uniaxial case unless requested.
