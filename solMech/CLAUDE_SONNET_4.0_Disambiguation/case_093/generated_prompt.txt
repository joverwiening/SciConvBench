The beam is simply supported with supports at x = 0 mm and x = 3000 mm.
A single point load P = 800 N acts downward at x = 2000 mm.
The beam material is AISI 1020 steel with elastic modulus E = 200000 MPa.
The beam cross-section has second moment of area I = 1200000 mm^4.
Small-deformation theory applies with linear-elastic material behavior.
Euler-Bernoulli beam theory governs the bending behavior.
The governing differential equation is EI d^4v/dx^4 = q(x) where v is deflection and q(x) is distributed load.
For point loads, use EI d^2v/dx^2 = M(x) where M(x) is the bending moment.
The reaction forces are R_A = P(L-a)/L = 800(3000-2000)/3000 = 266.67 N at x = 0.
The reaction force R_B = Pa/L = 800(2000)/3000 = 533.33 N at x = 3000 mm.
The bending moment for 0 ≤ x ≤ 2000 mm is M(x) = R_A × x = 266.67x N⋅mm.
The bending moment for 2000 mm ≤ x ≤ 3000 mm is M(x) = R_A × x - P(x-2000) = 266.67x - 800(x-2000) N⋅mm.
Use the unit-load method to find deflection at any arbitrary point by applying a unit load at that location.
Calculate the virtual work integral δ = ∫(M_real × M_unit)/(EI) dx over the beam length.
The maximum deflection occurs at x = 2000 mm and equals δ_max = Pa²b²/[3EIL] where a = 2000 mm and b = 1000 mm.
