The prismatic bar has a constant circular cross-sectional area A = 300 mm².
The total length is 1500 mm, segmented as AB = 500 mm, BC = 600 mm, and CD = 400 mm.
The material is AISI 1020 steel with elastic modulus E = 200,000 MPa.
The left end A is fixed with displacement u_A = 0.
The right end D is free with no constraints.
Point loads are applied at B (18,000 N rightward), C (-12,000 N leftward), and D (16,000 N rightward).
The analysis assumes small deformations and linear elastic behavior.
The governing equation is the equilibrium condition dN/dx + f = 0, where N is the axial force and f is the distributed load per unit length.
For this case with point loads only, f = 0 between load application points.
The axial force N is constant within each segment between point loads.
The stress-strain relation is σ = Eε, where σ is axial stress and ε is axial strain.
The strain-displacement relation is ε = du/dx, where u is axial displacement.
The axial stress is σ = N/A in each segment.
The axial displacement is found by integrating ε = σ/E = N/(EA) over each segment.
The relevant response quantities are axial force N(x), axial stress σ(x), axial strain ε(x), and axial displacement u(x).
Determine the axial force in each segment using equilibrium of forces.
Calculate the axial stress in each segment as σ = N/A.
Calculate the axial strain in each segment as ε = σ/E.
Integrate the strain to find displacement in each segment, applying continuity conditions at segment boundaries.
Apply the boundary condition u_A = 0 to determine integration constants.
