The system consists of two parallel bars of equal length connecting two rigid plates under axial loading.

Given parameters: Total load P = 20000 N, length L = 500 mm for both bars.
Bar 1: AISI 1020 steel, A1 = 300 mm², E1 = 200000 MPa.
Bar 2: 6061-T6 aluminum, A2 = 200 mm², E2 = 69000 MPa.

Boundary conditions: Bottom ends fixed to bottom rigid plate, top ends connected to top rigid plate which receives the applied load.

Additional assumptions: The rigid plates remain parallel during loading, perfect bonding between bars and plates, no buckling occurs, temperature effects neglected.

The load is distributed between bars based on their relative stiffnesses.
Bar stiffness: k1 = E1A1/L = (200000)(300)/500 = 120000 N/mm.
Bar stiffness: k2 = E2A2/L = (69000)(200)/500 = 27600 N/mm.
Total system stiffness: ktotal = k1 + k2 = 147600 N/mm.

Load distribution: P1 = P(k1/ktotal) = 20000(120000/147600) = 16260 N.
Load distribution: P2 = P(k2/ktotal) = 20000(27600/147600) = 3740 N.

Displacement of top plate: δ = P/ktotal = 20000/147600 = 0.1355 mm.

Stress in bar 1: σ1 = P1/A1 = 16260/300 = 54.2 MPa.
Stress in bar 2: σ2 = P2/A2 = 3740/200 = 18.7 MPa.

Strain in both bars: ε = δ/L = 0.1355/500 = 0.000271.
