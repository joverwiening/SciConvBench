The shaft is a solid circular aluminum shaft with diameter 40 mm and length 1500 mm.
The shaft is fixed at x = 0 and free at x = L = 1500 mm.
Two torques are applied: T1 = 300000 N·mm at x = 1500 mm and T2 = -150000 N·mm at x = 750 mm.
The material is 6061-T6 aluminum with shear modulus G = 25939.8 MPa.
Small-deformation and linear-elastic behavior are assumed.
The polar moment of inertia is J = πd⁴/32 = π(0.04)⁴/32 = 2.513 × 10⁻⁷ m⁴.
The internal torque distribution is: T(x) = 150000 N·mm for 0 ≤ x ≤ 750 mm and T(x) = 300000 N·mm for 750 mm < x ≤ 1500 mm.
The angle of twist per unit length is φ'(x) = T(x)/(GJ).
For 0 ≤ x ≤ 750 mm: φ'(x) = 150000/(25939.8 × 10⁶ × 2.513 × 10⁻⁷) = 0.02302 rad/m.
For 750 mm < x ≤ 1500 mm: φ'(x) = 300000/(25939.8 × 10⁶ × 2.513 × 10⁻⁷) = 0.04604 rad/m.
The angle of twist is φ(x) = ∫φ'(x)dx with φ(0) = 0.
For 0 ≤ x ≤ 750 mm: φ(x) = 0.02302x.
For 750 mm < x ≤ 1500 mm: φ(x) = 0.02302(0.75) + 0.04604(x - 0.75) = 0.04604x - 0.01726.
The maximum shear stress occurs at the outer surface: τ_max = Tc/J where c = d/2 = 0.02 m.
For 0 ≤ x ≤ 750 mm: τ_max = 150000 × 0.02/(2.513 × 10⁻⁷) = 11.94 MPa.
For 750 mm < x ≤ 1500 mm: τ_max = 300000 × 0.02/(2.513 × 10⁻⁷) = 23.88 MPa.
The total angle of twist at the free end is φ(1500) = 0.04604(1.5) - 0.01726 = 0.0518 rad = 2.97°.
