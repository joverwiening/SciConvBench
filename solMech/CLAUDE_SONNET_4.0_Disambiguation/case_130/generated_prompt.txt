The member is subjected to internal resultant forces of normal force P = 40000 N (tension) and shear force V = 16000 N (shear parallel to the width).
Assume the material is structural steel with elastic modulus E = 200 GPa and Poisson's ratio ν = 0.3.
Use small-deformation, linear-elastic solid mechanics theory.
Apply plane stress conditions where stress components perpendicular to the cross-section are negligible.
Calculate average normal stress as σ_avg = P/A where A = b × h is the cross-sectional area.
Calculate average shear stress as τ_avg = V/A using the same cross-sectional area.
The stress state consists of combined average normal stress σ_avg and average shear stress τ_avg.
Determine principal stresses using σ_1,2 = (σ_avg/2) ± sqrt((σ_avg/2)² + τ_avg²).
Calculate maximum shear stress as τ_max = (σ_1 - σ_2)/2.
Determine principal stress directions using tan(2θ_p) = 2τ_avg/σ_avg.
Calculate principal strains using ε_1 = (σ_1 - ν×σ_2)/E and ε_2 = (σ_2 - ν×σ_1)/E.
