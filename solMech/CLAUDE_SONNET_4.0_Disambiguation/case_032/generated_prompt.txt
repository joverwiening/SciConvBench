The beam is a simply supported Euler-Bernoulli beam with length L = 3000 mm.
The beam has flexural rigidity EI = 7×10^11 N·mm^2.
A downward point load P = 1500 N is applied at midspan (x = L/2 = 1500 mm).
The beam is subjected to small deformations and behaves as a linear elastic material.
The beam supports allow rotation but prevent vertical displacement.
Determine the midspan deflection at x = L/2.
Determine the slope at the left support (x = 0).
Determine the slope at the right support (x = L).
Use the standard Euler-Bernoulli beam theory with the governing differential equation EI d^4w/dx^4 = q(x).
For a point load at midspan, the moment distribution is M(x) = Px/2 for 0 ≤ x ≤ L/2 and M(x) = P(L-x)/2 for L/2 ≤ x ≤ L.
Apply boundary conditions: w(0) = 0, w(L) = 0, M(0) = 0, M(L) = 0.
The midspan deflection is w(L/2) = PL^3/(48EI).
The slope at the left support is dw/dx(0) = PL^2/(16EI).
The slope at the right support is dw/dx(L) = -PL^2/(16EI).
