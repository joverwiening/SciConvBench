Use N–mm–MPa units throughout.  
The bar has a length L = 500 mm.  
The axial tensile force P = 12000 N is constant along the bar.  
The material is AISI 1020 steel with Young's modulus E = 200000 MPa.  
The cross-sectional area varies linearly as A(x) = A0·(1 + k·x/L), where x is measured from the left end.  
The reference area A0 = 200 mm².  
The area variation parameter k = 1.0.  
The arithmetic-mean area is used to replace the varying area A(x).  
The arithmetic-mean area is calculated as (A(0) + A(L)) / 2.  
A(0) = A0 = 200 mm².  
A(L) = A0·(1 + k) = 200·(1 + 1.0) = 400 mm².  
The arithmetic-mean area = (200 + 400) / 2 = 300 mm².  
The elongation δ is computed using the formula δ = P·L / (A_mean·E).  
Substitute values: δ = (12000 N) × (500 mm) / (300 mm² × 200000 MPa).  
Compute δ = 6000000 / 60000000 = 0.1 mm.  
The elongation of the bar is 0.1 mm.
