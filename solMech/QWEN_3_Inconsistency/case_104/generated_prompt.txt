Use N–mm–MPa units throughout.  
Apply Euler–Bernoulli beam theory.  
Model a simply supported beam with span L = 2500 mm.  
Apply a uniform distributed load w = 0.7 N/mm over the full span.  
Use material property E = 200000 MPa.  
Use second moment of area I = 2000000 mm^4.  
The beam is simply supported at both ends, so deflections at x = 0 and x = L are zero.  
Due to symmetric loading, the maximum deflection occurs at midspan, x = L/2 = 1250 mm.  
Use the analytical formula for maximum deflection: δ_max = (5 * w * L^4) / (384 * E * I).  
Compute δ_max using the given values.  
Use the analytical formula for slope at the left support (x = 0): θ_0 = (w * L^3) / (24 * E * I).  
Compute θ_0 using the given values.  
Report the maximum deflection and its location.
