Q: What is the expression for the real bending moment M(x) in the two segments (0 ≤ x ≤ 1200 mm and 1200 mm ≤ x ≤ 2400 mm) due to the 1200 N point load at midspan?
A: For 0 ≤ x ≤ 1200 mm:  
M(x) = 600x N·mm

For 1200 mm ≤ x ≤ 2400 mm:  
M(x) = 600(2400 − x) N·mm

Q: What is the expression for the virtual moment m(x) in the two segments (0 ≤ x ≤ 1200 mm and 1200 mm ≤ x ≤ 2400 mm) due to a unit moment applied at x = 1200 mm for the auxiliary system?
A: A unit moment is not applied; instead, a unit load (1 N) is applied downward at x = 1200 mm for the auxiliary system to compute deflection.

For 0 ≤ x ≤ 1200 mm:  
m(x) = 0.5x N·mm

For 1200 mm ≤ x ≤ 2400 mm:  
m(x) = 0.5(2400 − x) N·mm
