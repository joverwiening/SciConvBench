Use N–mm–MPa units throughout.  
The beam is simply supported with span L = 2400 mm, supported at x = 0 and x = L.  
The material has elastic modulus E = 200000 MPa.  
The second moment of area is I = 3500000 mm⁴.  
A point load P = 1200 N acts downward at midspan, x = 1200 mm.  
The real bending moment M(x) is:  
For 0 ≤ x ≤ 1200 mm: M(x) = 600x N·mm  
For 1200 mm ≤ x ≤ 2400 mm: M(x) = 600(2400 − x) N·mm  
The virtual system uses a unit load of 1 N applied downward at x = 1200 mm to compute vertical deflection.  
The virtual moment m(x) is:  
For 0 ≤ x ≤ 1200 mm: m(x) = 0.5x N·mm  
For 1200 mm ≤ x ≤ 2400 mm: m(x) = 0.5(2400 − x) N·mm  
The supports are treated as zero-rotation boundaries in both real and virtual systems.  
The flexural rigidity EI is constant and equal to 200000 × 3500000 = 7.0 × 10¹¹ N·mm².  
The deflection at x = 1200 mm is computed using the virtual work formula:  
δ = ∫₀ᴸ [M(x)·m(x)] / (EI) dx  
The integral is split into two segments: from 0 to 1200 mm and from 1200 mm to 2400 mm.  
Due to symmetry, the integral from 0 to 1200 mm is equal to the integral from 1200 mm to 2400 mm.  
Compute δ = (2 / EI) × ∫₀¹²⁰⁰ (600x)(0.5x) dx  
Simplify integrand: (600)(0.5)x² = 300x²  
Integrate: ∫₀¹²⁰⁰ 300x² dx = 300 × [x³/3]₀¹²⁰⁰ = 100 × (1200)³ = 100 × 1.728 × 10⁹ = 1.728 × 10¹¹  
Multiply by 2: 2 × 1.728 × 10¹¹ = 3.456 × 10¹¹  
Divide by EI = 7.0 × 10¹¹: δ = 3.456 × 10¹¹ / 7.0 × 10¹¹ = 0.4937 mm  
The deflection at x = 1200 mm is 0.4937 mm downward.
