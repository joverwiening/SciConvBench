Use N–mm–MPa units throughout the calculation.  
The shaft has a diameter of 25 mm.  
An axial tensile force of 25000 N is applied.  
A torque of 300000 N·mm is applied.  
The material is homogeneous, isotropic, and linear elastic.  
Compute the cross-sectional area A = π × (d/2)².  
Calculate the average axial stress σ = P / A.  
Identify the radius c = d / 2.  
Compute the polar moment of inertia J = π × (d/2)⁴ / 2.  
Calculate the torsional shear stress τ = T × c / J.  
Use plane stress state with σx = σ, σy = 0, τxy = τ.  
Compute the principal stresses using the formula: σ₁,₂ = (σx + σy)/2 ± √[((σx − σy)/2)² + τxy²].  
Compute the maximum in-plane shear stress τ_max = √[((σx − σy)/2)² + τxy²].
