Use N–mm–MPa units throughout.  
The diameter of the circular shaft is 30 mm.  
The bending moment M is 4000000 N·mm.  
The torque T is 400000 N·mm.  
The maximum bending normal stress is calculated using σ = M c / I, where c = d/2 and I = π d⁴ / 64.  
The torsional shear stress is calculated using τ = T c / J, where J = π d⁴ / 32.  
At the outer surface, the bending normal stress is maximum and the torsional shear stress is not zero, so both bending and torsion contribute to the stress state.  
The stress state is treated as plane stress with σx = σ (bending), σy = 0, and τxy = τ (torsion).  
The principal stresses are computed using the plane stress transformation equations.  
The maximum in-plane shear stress is computed as τ_max = √[(σx - σy)/2)² + τxy²].  
All calculations are performed at the critical section of the shaft.
