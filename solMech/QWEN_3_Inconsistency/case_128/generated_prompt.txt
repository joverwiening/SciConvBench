Use N–mm–MPa units throughout.  
The cross-sectional area A is calculated as b × h = 40 mm × 120 mm.  
Compute the average normal stress σ = P / A, where P = 40000 N (tensile).  
Compute the average shear stress τ = V / A, where V = 8000 N (shear parallel to width).  
Assume plane stress state with σx = σ, σy = 0, and τxy = τ.  
Compute principal stresses using the formula:  
σ₁ = (σx / 2) + √[(σx / 2)² + τxy²]  
σ₂ = (σx / 2) − √[(σx / 2)² + τxy²]  
Compute maximum in-plane shear stress using:  
τ_max_in_plane = √[(σx / 2)² + τxy²]  
Report σ₁, σ₂, and τ_max_in_plane in MPa.
