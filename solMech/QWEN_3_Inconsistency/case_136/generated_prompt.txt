Work in N–mm–MPa units.  
The cross-sectional area A is calculated as b × h, where b = 30 mm and h = 100 mm.  
The average normal stress σ_avg is computed as P / A, where P = 50000 N (tension).  
The average shear stress τ_avg is computed as V / A, where V = 5000 N (acting parallel to the width b).  
The maximum in-plane shear stress τ_max is computed using the formula τ_max = sqrt((σ_avg / 2)^2 + τ_avg^2).  
Use uniform stress distributions and average values for all calculations.  
Report σ_avg in MPa.  
Report τ_avg in MPa.
