Use N–mm–MPa units throughout.  
Assume the shaft is linearly elastic and has a circular solid cross section.  
The shaft is made of structural steel with diameter d = 50 mm and length L = 600 mm.  
The shaft transmits a torque T = 500000 N·mm.  
Use the polar moment of inertia J = π d^4 / 32.  
Calculate maximum shear stress using τ_max = T c / J, where c = d / 2.  
The maximum shear stress τ_max is to be reported in MPa.  
Compute the angle of twist φ = T L / (J G), where G = 77519.4 MPa.  
Report the angle of twist φ in degrees.  
Use π = 3.1415926535 for calculations.
