Perform a variable‑cell relaxation (vc‑relax) using Quantum ESPRESSO with the following settings:

Use the LDA pseudopotentials hg.upf and te.upf from the PseudoDojo SR_v0.4.1 LDA_standard library.  
Retrieve the primitive zincblende structure of HgTe (space group F‑43m) with lattice constant a = 6.46 Å, Hg at (0 0 0) and Te at (0.25 0.25 0.25) in fractional coordinates.  

Set calculation = "vc-relax".  
Fix the lattice vectors during the relaxation by setting cell_dofree = "none".  

Use a gamma‑centered k‑point grid of 8 × 8 × 8.  
Set ecutwfc = 40 Ry and ecutrho = 320 Ry.  
Set the total‑energy convergence threshold etot_conv_thr = 1.0e‑4 Ry (≈ 0.001 eV per atom).  
Set the force convergence threshold forc_conv_thr = 1.0e‑3 Ry/Bohr (≈ 0.01 eV/Å).  

Run the vc‑relax calculation until both the energy and forces meet the specified thresholds.  
Output the fully relaxed structure, reporting the final lattice vectors (identical to the initial ones) and the relaxed atomic fractional coordinates.
