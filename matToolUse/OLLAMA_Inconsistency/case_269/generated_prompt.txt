Create a file named INCAR containing the following lines:
ALGO = Fast
EDIFF = 5e-05
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 26*-0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05
Run VASP using the provided launcher script with the command: bash run_vasp.sh
After VASP finishes, copy the used INCAR to a backup file named INCAR1 with the command: cp INCAR INCAR1
Extract the optimized total energy by executing the post‑processing script: python get_energy.py
The script will print the final total energy; a reasonable assumed value for bulk Al under these settings is -15.60 eV.
