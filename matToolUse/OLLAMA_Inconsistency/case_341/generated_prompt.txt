Create an INCAR file containing the following parameters: EDIFF = 1e-5, EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, LCHARG = .FALSE., LWAVE = .FALSE..
Place this identical INCAR file in the CO directory and run the preparation and VASP launch command: python op.py CO POTCAR-CO POSCAR-CO.
Place the same INCAR file in the surface directory and run: python op.py surface POTCAR-RuO2face POSCAR-RuO2face.
Place the same INCAR file in the absorbed directory and run: python op.py absorbed POTCAR-RuO2CO POSCAR-RuO2CO.
After the three relaxations finish, execute the post‑processing script to compute the adsorption energy: bash ./calc_absorption_energy.sh.
