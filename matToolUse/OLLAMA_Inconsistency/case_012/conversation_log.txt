Q: What are the exact filenames (including extensions) and file formats for the Mg‑Ga defect data, the stable entries, the bulk density‑of‑states data, and the phase‑diagram data located under the provided `file_path` directory?

- **Phase‑diagram data**: there is no separate file; the phase diagram is constructed from the stable entries (`stable_entries_Mg_Ga_N.json`) and the elemental/compound entries that are read from the same directory. If a pre‑computed phase‑diagram file is present, you would look for a typical name such as `phase_diagram.json` or `phase_diagram.yaml`, but the complete requirement does not specify one, so you should generate the phase diagram programmatically from the loaded entries.
