Q: What specific INCAR parameters should be used for the PBE ground‑state calculation in Step 1?
A: Use a standard PBE‑GGA INCAR such as the one below (these are typical best‑practice settings for a ground‑state calculation):

```
SYSTEM = BN PBE ground state
PREC   = Accurate
ENCUT  = 450          # same cutoff as used later for HSE
EDIFF  = 1E-5
ISMEAR = 0            # Gaussian smearing
SIGMA  = 0.05
IBRION = -1           # static calculation (no ionic steps)
NSW    = 0
ISIF   = 2            # stress tensor only (no relaxation)
ISPIN  = 1            # non‑magnetic
LCHARG = .TRUE.
LWAVE  = .TRUE.
LREAL  = Auto
NPAR   = 1
KPAR   = 4
NCORE  = 1
ALGO   = Normal
LORBIT = 11
```

Save this file as **INCAR** before running `bash run_vasp.sh`, then copy it to `INCAR1` after the run. If any of these values are not explicitly required by the task, they can be adjusted, but the above set satisfies a typical PBE ground‑state calculation.
