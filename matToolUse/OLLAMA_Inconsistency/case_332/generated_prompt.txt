Create an INCAR file for the PBE ground‑state calculation with typical settings (e.g., PREC=Accurate, ENCUT appropriate for the POTCAR, ISMEAR=0, SIGMA=0.05, IBRION=2, NSW=100, EDIFF=1E-5, LCHARG=.TRUE., LWAVE=.TRUE., ISPIN=1, and any other standard PBE parameters). Save this file as `INCAR`.

Run VASP for the PBE step:
```
bash run_vasp.sh
```

Copy the INCAR used in the PBE step to `INCAR1`:
```
cp INCAR INCAR1
```

Create a new INCAR for the HSE calculation using the parameter block provided in the task description, but modify `ICHARG` to a value ≤ 10 (e.g., ICHARG=10) because a hybrid functional calculation must recompute the charge density. Do not include magnetic moment specifications, NBAND, or NELECT entries. Save this file as `INCAR`.

Run VASP for the HSE step:
```
bash run_vasp.sh
```

Copy the INCAR used in the HSE step to `INCAR2`:
```
cp INCAR INCAR2
```

After the HSE calculation finishes, execute the post‑processing script to extract the band gap:
```
python gap.py
```

The script will read `vasprun.xml` from the HSE run and print the electronic band‑gap value. Record the printed number as the final result.
