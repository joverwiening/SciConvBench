Q: Can you specify the exact VASP output filenames (e.g., vasprun.xml) located in the `v_Ga/ccd_0_-1` directory and in the neutral‑defect directory that should be used to load the band structures?
A: The band‑structure data should be taken from the following VASP output files:

* **In the `v_Ga/ccd_0_-1` directory**
  * `v_Ga/ccd_0_-1/0/vasprun.xml`
  * `v_Ga/ccd_0_-1/1/vasprun.xml`
  * `v_Ga/ccd_0_-1/2/vasprun.xml`
  * `v_Ga/ccd_0_-1/1/PROCAR`

These four files are the ones used to build the `HarmonicDefect` (with `charge_state = 0` and `store_bandstructure = True`) and to obtain the defect band structures. No additional VASP output files are required.

Q: Which directory contains the VASP output files for the neutral defect (charge_state = 0) that should be used to obtain its defect band structure?
A: The VASP output files for the neutral defect ( charge_state = 0 ) are located in the **`v_Ga/ccd_0_-1`** directory (i.e., the subfolders `v_Ga/ccd_0_-1/0`, `v_Ga/ccd_0_-1/1`, and `v_Ga/ccd_0_-1/2`).
