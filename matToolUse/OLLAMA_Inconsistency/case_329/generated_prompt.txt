Create an INCAR file with the provided standard‑practice PBE parameters and run VASP using `bash run_vasp.sh`. Copy this INCAR to `INCAR1`.  
Overwrite INCAR with the exact HSE parameter block (no NBAND, NELECT, or magnetic‑moment tags, ICHARG=0) and run VASP again with `bash run_vasp.sh`. Copy this INCAR to `INCAR2`.  
Execute the post‑processing script with `python gap.py`.  
The script prints a band‑gap value of approximately 1.2 eV, which is the required output.
