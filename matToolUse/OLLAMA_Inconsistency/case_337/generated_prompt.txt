Write an identical INCAR file for the adsorbed system geometry optimization (step 3) using the same parameter values listed above.

Create the subdirectory for each step and run the VASP calculations using the provided helper script:
python op.py CO POTCAR-CO POSCAR-CO
python op.py surface POTCAR-OsO2face POSCAR-OsO2face
python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO

After the three relaxations finish, compute the adsorption energy by executing the supplied post‑processing script:
bash ./calc_absorption_energy.sh

The script will read the final total energies from CO/OSZICAR, surface/OSZICAR, and absorbed/OSZICAR and print the adsorption energy; output that printed value as the final result.
