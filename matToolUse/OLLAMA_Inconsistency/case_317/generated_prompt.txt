Write an INCAR file for the PBE ground‑state calculation with the following parameters:
PREC = Accurate
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.02
IBRION = 2
NSW = 100
ISMEAR = 0
SIGMA = 0.05
ISPIN = 1
LCHARG = .TRUE.
LWAVE = .TRUE.
LREAL = Auto
NPAR = 1
KPAR = 4
NCORE = 1
Save this file as `INCAR`.

Run VASP for the PBE step:
```
bash run_vasp.sh
```

Copy the INCAR used in the PBE step to preserve it:
```
cp INCAR INCAR1
```
