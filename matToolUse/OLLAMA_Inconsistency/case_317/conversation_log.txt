Q: What INCAR parameters should be used for the PBE ground‑state calculation in Step 1?
A: Use a standard PBE‑ground‑state INCAR, for example:

```
PREC    = Accurate
ENCUT   = 450          # same cutoff as the HSE step
EDIFF   = 1E-5
EDIFFG  = -0.02
IBRION  = 2            # conjugate‑gradient ionic relaxation
NSW     = 100          # number of ionic steps (adjust as needed)
ISMEAR  = 0
SIGMA   = 0.05
ISPIN   = 1
LCHARG  = .TRUE.
LWAVE   = .TRUE.
LREAL   = Auto
NPAR    = 1
KPAR    = 4
NCORE   = 1
```

These parameters give a reliable PBE ground‑state calculation and are consistent with the rest of the workflow. (If you prefer a slightly faster run you can change `PREC` to `Normal`.)
