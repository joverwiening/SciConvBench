Q: What INCAR parameters should be used for the PBE ground‑state calculation (Step 1)?
A: Use a standard PBE‑GGA INCAR, for example:

```
SYSTEM = MoS2 PBE ground state
PREC   = Accurate
ENCUT  = 450          # or at least 1.3 × the max POTCAR ENMAX
EDIFF  = 1E-5
EDIFFG = -0.02
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2            # conjugate‑gradient ionic relaxation
NSW    = 100          # number of ionic steps (adjust as needed)
ISIF   = 3            # relax ions and cell shape/volume
ISPIN  = 1            # non‑magnetic
LCHARG = .TRUE.
LWAVE  = .TRUE.
LREAL  = Auto
NELM   = 100
NELMIN = 4
```

These settings give a reliable PBE ground‑state calculation and can be saved as `INCAR` before running `bash run_vasp.sh`. If you need a different convergence criterion or ionic algorithm, adjust `EDIFF`, `EDIFFG`, `IBRION`, `NSW`, etc., but keep the overall structure above.
