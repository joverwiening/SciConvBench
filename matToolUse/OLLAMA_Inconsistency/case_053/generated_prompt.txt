Retrieve the primitive wurtzite GaN structure using the structure‑retrieval tool based on the metadata (formula=GaN, structure=wurtzite, space_group=P6_3mc, atoms_per_primitive_cell=4).  
Perform a variable‑cell relaxation (vc‑relax) with the LDA pseudopotentials ga.upf and n.upf, using a plane‑wave kinetic‑energy cutoff ecutwfc = 60 Ry and ecutrho = 240 Ry.  
Use a gamma‑centered Monkhorst‑Pack k‑point grid of 8 × 8 × 6 for the vc‑relax calculation, with an automatic half‑grid shift.  
Set the electronic convergence threshold etot_conv_thr = 1.0e‑4 Ry (≈1 meV/atom) and the force convergence threshold forc_conv_thr = 1.0e‑3 Ry/Bohr.  
Apply Gaussian smearing with degauss = 0.01 Ry and occupations = smearing.  
After vc‑relax, run a self‑consistent field (scf) calculation on the relaxed structure using the same ecutwfc, ecutrho, k‑point grid, smearing, and convergence thresholds.  
Run a non‑self‑consistent field (nscf) calculation on the scf charge density using a denser gamma‑centered k‑point grid of 12 × 12 × 9 and the same ecutwfc and ecutrho.  
Perform a bands calculation (pw.x with calculation="bands") using the same k‑point grid as the nscf step and the same cutoffs.  
Post‑process the bands with the bands.x utility to generate the band data (output not required to be returned).  
Post‑process the density of states with dos.x using the nscf wavefunctions, a Gaussian smearing of 0.01 Ry, and a dense gamma‑centered k‑point grid of 16 × 16 × 12 to obtain a converged DOS.  
All calculations are non‑magnetic, without Hubbard U or spin‑orbit coupling.  
Report completion of the workflow; no explicit band structure output is required.
