Create an INCAR file for the PBE ground‑state calculation using the following parameters:
SYSTEM = C – PBE ground state
PREC   = Accurate
ENCUT  = 450
EDIFF  = 1E-5
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2
NSW    = 50
ISIF   = 3
ISPIN  = 1
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 100
NELMIN = 4
ALGO   = Normal

Run VASP for the PBE step:
bash run_vasp.sh

Copy the PBE INCAR to a backup file:
cp INCAR INCAR1

Create an INCAR file for the HSE calculation using the parameter block from data.json, but set ICHARG to a value ≤ 10 (use ICHARG = 0) and do not add any magnetic‑moment, NBAND, or NELECT entries. The HSE INCAR should contain:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Run VASP for the HSE step:
bash run_vasp.sh

Copy the HSE INCAR to a backup file:
cp INCAR INCAR2

After the HSE run finishes, execute the post‑processing script to extract the band gap:
python gap.py

The script will read the generated vasprun.xml and print the electronic band‑gap value, which is the required output.
