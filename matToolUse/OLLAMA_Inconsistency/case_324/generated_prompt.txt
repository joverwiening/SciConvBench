Place the files POSCAR, KPOINTS, POTCAR, run_vasp.sh, and gap.py in the directory data/bandgap/InP.  
Create an INCAR file with the following contents for the PBE ground‑state calculation:  
SYSTEM = InP PBE ground state  
PREC   = Accurate  
ENCUT  = 450  
EDIFF  = 1E-5  
EDIFFG = -0.02  
ISMEAR = 0  
SIGMA  = 0.05  
IBRION = 2  
NSW    = 100  
ISPIN  = 1  
ISIF   = 3  
LCHARG = .TRUE.  
LWAVE  = .TRUE.  
NELM   = 100  
NELMIN = 4  
LREAL  = Auto  
NPAR   = 1  
KPAR   = 4  
NCORE  = 1  
Run VASP for the PBE step: `bash run_vasp.sh`.  
After the run finishes, copy the INCAR used to `INCAR1`: `cp INCAR INCAR1`.  
Create a new INCAR file for the HSE calculation with the exact parameter block:  
PREC=Normal  
ENCUT=450  
NELM=500  
IBRION=-1  
ISPIN=1  
NSW=0  
ISIF=2  
EDIFF=1E-5  
EDIFFG=-5E-3  
ISTART=0  
ICHARG=0  
ISMEAR=0  
SIGMA=0.05  
LWAVE=.T.  
LCHARG=.T.  
LREAL=Auto  
LPLANE=.TRUE.  
NPAR=1  
KPAR=4  
NCORE=1  
LORBIT=11  
ALGO=All  
LHFCALC=.TRUE.  
HSE06=.TRUE.  
HFSCREEN=0.2  
TIME=0.4  
AEXX=0.25  
AGGAX=0.75  
LMAXFOCK=4  
PRECFOCK=Fast  
Do not add NBAND, NELECT, or magnetic moment tags.  
Run VASP for the HSE step: `bash run_vasp.sh`.  
After the run finishes, copy the INCAR used to `INCAR2`: `cp INCAR INCAR2`.  
Execute the post‑processing script to extract the band gap: `python gap.py`.  
The value printed by `gap.py` is the final electronic band‑gap result.
