Q: What INCAR parameters should be used for the PBE ground‑state calculation in Step 1?
A: Use a standard PBE‑GGA INCAR, for example:

```
SYSTEM = InP PBE ground state
PREC   = Accurate
ENCUT  = 450          # same cutoff as the HSE step
EDIFF  = 1E-5
EDIFFG = -0.02
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2            # conjugate‑gradient ionic relaxation
NSW    = 100          # max ionic steps
ISPIN  = 1
ISIF   = 3            # relax ions and cell shape
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 100
NELMIN = 4
LREAL  = Auto
NPAR   = 1
KPAR   = 4
NCORE  = 1
```

These settings give a reliable PBE ground‑state calculation and can be saved as `INCAR` before running `bash run_vasp.sh`. (If you need a different cutoff or convergence criteria, adjust `ENCUT` and `EDIFF` accordingly.)
