Retrieve the primitive perovskite BaTiO3 structure (space group P4mm, 5 atoms) using a structure‑retrieval tool and use it as the starting configuration.  
Perform a variable‑cell relaxation (vc‑relax) with LDA pseudopotentials (ba.upf, ti.upf, o.upf) using a gamma‑centered 8 × 8 × 8 k‑point grid, plane‑wave cutoff ecutwfc = 60 Ry, charge‑density cutoff ecutrho = 480 Ry, total‑energy convergence threshold etot_conv_thr = 1 × 10⁻⁴ Ry (≈1 meV/atom), and force convergence threshold forc_conv_thr = 1 × 10⁻⁴ Ry/Bohr. Use fixed occupations (no smearing) appropriate for an insulating ferroelectric.  

After vc‑relax, run a self‑consistent field (scf) calculation on the relaxed cell with the same pseudopotentials, k‑point grid, ecutwfc, ecutrho, and convergence thresholds.  

Next, run a non‑self‑consistent calculation for band extraction using pw.x with calculation="bands", keeping the same k‑point sampling along high‑symmetry lines (e.g., a standard path for tetragonal perovskite).  

Post‑process the bands with the appropriate post‑processing tool (e.g., bands.x) to generate the band‑structure data (output not required to be returned).  

Finally, compute the density of states directly from the scf result using dos.x (or equivalent), employing the same gamma‑centered 8 × 8 × 8 grid and the previously defined cutoffs.  

All calculations must use the LDA functional, the specified pseudopotentials, and the convergence criteria stated above. No additional spin‑orbit coupling, Hubbard U, or magnetization settings are applied.
