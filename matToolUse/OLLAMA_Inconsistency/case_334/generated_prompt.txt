Write an INCAR file named `INCAR` containing the following parameters (use the same file for all three relaxation steps):
```
EDIFFG = -0.05
ENCUT  = 450
IBRION = 1
ISIF   = 2
ISMEAR = 1
ISPIN  = 1
POTIM  = 0.2
SIGMA  = 0.2
NSW    = 200
```

Step 1 – Optimize the CO molecule  
1. Place `POSCAR-CO` and `POTCAR-CO` in the current directory.  
2. Run `python op.py CO POTCAR-CO POSCAR-CO`.  
3. The script creates a subdirectory `CO`, copies `POSCAR-CO` → `POSCAR` and `POTCAR-CO` → `POTCAR`, writes the above `INCAR`, and executes `run.sh` to launch VASP.

Step 2 – Optimize the clean Ir surface  
1. Run `python op.py surface POTCAR-Irface POSCAR-Irface`.  
2. The script creates a subdirectory `surface`, copies the provided files to generic names, writes the same `INCAR`, and runs VASP.

Step 3 – Optimize the CO‑adsorbed Ir slab  
1. Run `python op.py absorbed POTCAR-IrCO POSCAR-IrCO`.  
2. The script creates a subdirectory `absorbed`, copies the files, writes the same `INCAR`, and runs VASP.

Step 4 – Compute the adsorption energy  
1. After the three relaxations finish, execute `bash ./calc_absorption_energy.sh`.  
2. The script reads the final total energies (`E0`) from `CO/OSZICAR`, `surface/OSZICAR`, and `absorbed/OSZICAR`, computes the adsorption energy, and prints it.  

The printed value from `calc_absorption_energy.sh` is the required adsorption energy of CO on the Ir surface.
