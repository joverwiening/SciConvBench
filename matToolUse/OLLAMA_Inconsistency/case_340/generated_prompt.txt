Write an INCAR file for the CO geometry optimization containing the following lines: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, and any additional standard VASP tags you deem appropriate (e.g., PREC = Accurate, LCHARG = .FALSE., LWAVE = .FALSE.).  
Run the command `python op.py CO POTCAR-CO POSCAR-CO` to create the CO subdirectory, copy the files, and launch VASP with `run.sh`.  

Write an INCAR file for the clean surface geometry optimization using exactly the same parameter set as the CO step (including NSW = 200).  
Run the command `python op.py surface POTCAR-IrO2face POSCAR-IrO2face` to create the surface subdirectory, copy the files, and launch VASP with `run.sh`.  

Write an INCAR file for the adsorbed system geometry optimization using exactly the same parameter set as the previous steps (including NSW = 200).  
Run the command `python op.py absorbed POTCAR-IrO2CO POSCAR-IrO2CO` to create the absorbed subdirectory, copy the files, and launch VASP with `run.sh`.  

After all three VASP calculations have finished, execute `bash ./calc_absorption_energy.sh`.  
The script will read the final total energies from `CO/OSZICAR`, `surface/OSZICAR`, and `absorbed/OSZICAR`, compute the adsorption energy, and print it; return that printed value as the final result.
