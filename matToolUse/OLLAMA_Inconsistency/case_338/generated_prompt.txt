Write an INCAR file containing the following parameters for all three geometry‑optimization steps (CO, clean surface, adsorbed system):
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 200
Add any other standard VASP settings you deem necessary (e.g., LCHARG = .FALSE., LWAVE = .FALSE., NELM = 60).

Step 1 – Optimize CO molecule:
1. Place the INCAR file in the current directory.
2. Run `python op.py CO POTCAR-CO POSCAR-CO` to create the CO subdirectory, copy POSCAR and POTCAR, and launch VASP with `run.sh`.

Step 2 – Optimize clean PdO₂ surface:
1. Ensure the same INCAR file is present.
2. Run `python op.py surface POTCAR-PdO2face POSCAR-PdO2face` to create the surface subdirectory and launch the calculation.

Step 3 – Optimize CO‑adsorbed PdO₂ system:
1. Ensure the same INCAR file is present.
2. Run `python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO` to create the absorbed subdirectory and launch the calculation.

Step 4 – Compute adsorption energy:
After the three relaxations finish, execute `bash ./calc_absorption_energy.sh`. The script reads the final total energies from `CO/OSZICAR`, `surface/OSZICAR`, and `absorbed/OSZICAR` and prints the adsorption energy. Return the printed adsorption energy value exactly as output.
