Create a file named `INCAR` in the current directory containing exactly the following lines:
ALGO = Fast
EDIFF = 0.0008
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 31*0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05

Run VASP using the provided launch script with the command:
bash run_vasp.sh

After VASP finishes, copy the used INCAR file to a backup named `INCAR1`:
cp INCAR INCAR1

Execute the post‑processing script to obtain the optimized total energy:
python get_energy.py

Output exactly the string printed by `get_energy.py`, which is the optimized total energy after relaxation.
