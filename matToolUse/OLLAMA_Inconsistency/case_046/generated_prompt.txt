Retrieve the primitive Fe3O4 crystal structure (space group Fd-3m, 7 atoms per primitive cell) from a structure‑retrieval database and use it as the starting configuration.  
Perform the following sequential calculations using Quantum ESPRESSO with LDA pseudopotentials (fe.upf, o.upf):  

1. Run a variable‑cell relaxation (calculation="vc‑relax") with a gamma‑centered 6 × 6 × 6 Monkhorst‑Pack k‑point grid (half‑shift), ecutwfc = 60 Ry, ecutrho = 480 Ry, smearing = Methfessel‑Paxton, degauss = 0.02 Ry, starting_magnetization(Fe)=0.5, starting_magnetization(O)=0.0, spin‑polarized (nspin=2), no Hubbard U, no spin‑orbit coupling, etot_conv_thr = 1.0e‑5 Ry (≈1 meV/atom), forc_conv_thr = 1.0e‑4 Ry/Bohr.  

2. Using the relaxed structure, run a self‑consistent field calculation (calculation="scf") with the same k‑point grid, ecutwfc, ecutrho, smearing, degauss, magnetization, and convergence thresholds as in step 1.  

3. Perform a non‑self‑consistent field calculation (calculation="nscf") on the SCF charge density using a denser gamma‑centered 12 × 12 × 12 k‑point grid, keeping all other parameters identical to step 2.  

4. Run a bands calculation (calculation="bands") on the same dense k‑point grid, requesting the band eigenvalues along the high‑symmetry path appropriate for the primitive cell.  

5. Post‑process the bands output with the pwtools “bands.x” utility to generate the band structure data (no need to return the plot).  

6. Post‑process the DOS using “dos.x” on the nscf results with a Gaussian broadening of 0.02 Ry to obtain the total and projected density of states.  

All calculations must use the same pseudopotential files, spin‑polarized setup, and convergence criteria, and the final DOS data should be written to standard output files (e.g., *.dos, *.pdos).
