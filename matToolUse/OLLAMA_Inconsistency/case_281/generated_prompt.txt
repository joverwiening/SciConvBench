Create an INCAR file containing the following lines:
ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 35*2.758
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Run VASP using the provided launch script:
bash run_vasp.sh

After the VASP run finishes, copy the used INCAR to a backup file:
cp INCAR INCAR1

Extract the optimized total energy by executing the post‑processing script:
python get_energy.py

Return the exact output printed by get_energy.py as the optimized total energy.
