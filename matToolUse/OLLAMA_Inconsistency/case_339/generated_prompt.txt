Write an INCAR file for the CO molecule geometry optimization containing the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200. Save this file as `INCAR` in the directory that will be created for step 1.

Run the preparation script for the CO calculation:
```
python op.py CO POTCAR-CO POSCAR-CO
```
This creates a subdirectory named `CO`, copies `POSCAR-CO` to `POSCAR`, copies `POTCAR-CO` to `POTCAR`, and then executes `run.sh` which launches VASP with the prepared `INCAR`.

Write an identical INCAR file (same parameter values as above) for the clean RhO₂ surface geometry optimization. Save it as `INCAR` in the directory that will be created for step 2.

Run the preparation script for the clean surface calculation:
```
python op.py surface POTCAR-RhO2face POSCAR-RhO2face
```
This creates a subdirectory named `surface`, copies the appropriate POSCAR and POTCAR files, and runs VASP.

Write the same INCAR file (same parameter values as above) for the CO‑adsorbed RhO₂ slab geometry optimization. Save it as `INCAR` in the directory that will be created for step 3.

Run the preparation script for the adsorbed system calculation:
```
python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO
```
This creates a subdirectory named `absorbed`, copies the appropriate POSCAR and POTCAR files, and runs VASP.

After all three VASP jobs have finished, compute the adsorption energy by executing the provided post‑processing script from the case root:
```
bash ./calc_absorption_energy.sh
```
The script reads the final total energies from `CO/OSZICAR`, `surface/OSZICAR`, and `absorbed/OSZICAR` and prints the adsorption energy; output this printed value as the result.
