Q: What INCAR parameters should be used for the PBE ground‑state calculation in Step 1?
A: Use a standard PBE‑GGA INCAR, for example:

```
SYSTEM = GaAs PBE ground state
PREC   = Accurate
ENCUT  = 400          # or the maximum ENMAX in the POTCAR + 30 eV
EDIFF  = 1E-5
EDIFFG = -0.02
IBRION = 2            # conjugate‑gradient ionic relaxation
NSW    = 50           # number of ionic steps (adjust as needed)
ISMEAR = 0            # Gaussian smearing
SIGMA  = 0.05
ISPIN  = 1            # non‑magnetic
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 100
NELMIN = 4
ALGO   = Normal
LREAL  = Auto
```

These settings give a reliable PBE ground‑state calculation and can be written to the file `INCAR` before running `bash run_vasp.sh`. (If you prefer a different ENCUT or convergence criteria, adjust them according to your usual best‑practice values.)
