Write an INCAR file for the initial‑state relaxation (Step 1) containing the following parameters: EDIFF = 1e-5, EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, PREC = Accurate, LREAL = Auto, ALGO = Fast. Save this file as `IS/INCAR`.

Run the initial‑state relaxation with the command: `python op.py IS POTCARagpd IS1POSCAR`.

Write an INCAR file for the final‑state relaxation (Step 2) using the same parameter set as the initial‑state INCAR (EDIFF = 1e-5, EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, PREC = Accurate, LREAL = Auto, ALGO = Fast). Save this file as `FS/INCAR`.

Run the final‑state relaxation with the command: `python op.py FS POTCARagpd FS1POSCAR`.

Run the ASE interpolation to generate the NEB images with the command: `python nebmake.py`.

Write an INCAR file for the NEB calculation (Step 4) containing the following parameters: EDIFF = 1e-5, EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 3, IMAGES = 4, LCLIMB = .TRUE., IOPT = 7, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0, SIGMA = 0.2, SPRING = -5, NSW = 200, PREC = Accurate, LREAL = Auto, ALGO = Fast. Save this file as `INCAR` in the NEB root directory.

Run the NEB calculation with the command: `python op2.py ./`.

Extract the energy profile and barrier after the NEB run with the command: `bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'`.

The extraction step reports a reaction‑barrier of approximately 0.6 eV for the hydrogenation of ethylene on the metal surface.
