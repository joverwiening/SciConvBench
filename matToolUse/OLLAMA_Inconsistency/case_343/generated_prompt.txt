Create an INCAR file for the three geometry‑optimization steps (CO, clean surface, adsorbed system) containing at least the following parameters:  
EDIFFG = -0.05  
ENCUT = 450  
IBRION = 1  
ISIF = 2  
ISMEAR = 1  
ISPIN = 1  
POTIM = 0.2  
SIGMA = 0.2  
NSW = 200 (or a larger value to ensure convergence).  
Add any other standard VASP settings you normally use (e.g., LCHARG = .FALSE., LWAVE = .FALSE., PREC = Normal).  

Step 1 – Optimize CO  
1. Place the provided POSCAR‑CO and POTCAR‑CO files in a new directory named CO using the command:  
   python op.py CO POTCAR-CO POSCAR-CO  
2. Ensure the INCAR created above is present in the CO directory.  
3. Run the VASP calculation by executing run.sh inside the CO directory.  

Step 2 – Optimize the clean Pd surface  
1. Create the surface directory with the provided POSCAR‑Pdface and POTCAR‑Pdface files using:  
   python op.py surface POTCAR-Pdface POSCAR-Pdface  
2. Copy the same INCAR file used in Step 1 into the surface directory.  
3. Execute run.sh inside the surface directory.  

Step 3 – Optimize the CO‑adsorbed Pd slab  
1. Create the absorbed directory with the provided POSCAR‑PdCO and POTCAR‑PdCO files using:  
   python op.py absorbed POTCAR-PdCO POSCAR-PdCO  
2. Copy the same INCAR file into the absorbed directory.  
3. Execute run.sh inside the absorbed directory.  

Step 4 – Compute the adsorption energy  
1. After the three VASP runs have finished, run the post‑processing script from the case root:  
   bash ./calc_absorption_energy.sh  
2. The script will read the final total energies from CO/OSZICAR, surface/OSZICAR, and absorbed/OSZICAR and print the adsorption energy.  

Assumed result: based on typical DFT practice for CO on Pd, the adsorption energy printed by calc_absorption_energy.sh is –1.6 eV.
