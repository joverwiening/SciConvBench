Set the total‑energy convergence threshold (etot_conv_thr) to 7.5 × 10⁻⁵ Ry per atom to achieve ≤ 1 meV/atom accuracy.  
Set the force convergence threshold (forc_conv_thr) to 1.0 × 10⁻⁴ Ry/Bohr.  
Do not enable spin polarization, Hubbard U, or spin‑orbit coupling.  
Run the vc‑relax calculation with the above parameters.
