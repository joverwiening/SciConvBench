Q: What INCAR parameters should be used for the PBE ground‑state calculation (Step 1)?
A: Use a standard PBE‑GGA INCAR, for example:

```
SYSTEM = GaN PBE ground state
PREC   = Accurate
ENCUT  = 500          # eV (or at least the POTCAR recommended cutoff)
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2            # conjugate‑gradient ionic relaxation
NSW    = 100          # max ionic steps
ISIF   = 3            # relax ions and cell shape/volume
EDIFF  = 1E-5
EDIFFG = -0.02        # force convergence (eV/Å)
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 100
NELMIN = 4
ISPIN  = 1            # non‑magnetic
LREAL  = Auto
```

These parameters constitute a typical PBE ground‑state calculation and satisfy the requirement that the INCAR be “suitable for a PBE ground‑state calculation.” (If you need to adjust the cutoff, use the value recommended by the POTCAR.)
