Write an INCAR file for each VASP geometry‑optimization step (CO, surface, absorbed) containing the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, EDIFF = 1E-5, PREC = Accurate.  
Create a subdirectory named `CO`, copy `POSCAR-CO` to `CO/POSCAR` and `POTCAR-CO` to `CO/POTCAR`, place the INCAR file in `CO/INCAR`, and run `python op.py CO POTCAR-CO POSCAR-CO` inside the main case directory.  
Create a subdirectory named `surface`, copy `POSCAR-PtO2face` to `surface/POSCAR` and `POTCAR-PtO2face` to `surface/POTCAR`, place the same INCAR file (with the values above) in `surface/INCAR`, and run `python op.py surface POTCAR-PtO2face POSCAR-PtO2face`.  
Create a subdirectory named `absorbed`, copy `POSCAR-PtO2CO` to `absorbed/POSCAR` and `POTCAR-PtO2CO` to `absorbed/POTCAR`, place the same INCAR file in `absorbed/INCAR`, and run `python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO`.  
After the three relaxations finish, execute the provided post‑processing script with `bash ./calc_absorption_energy.sh`.  
The script will read the final total energies from `CO/OSZICAR`, `surface/OSZICAR`, and `absorbed/OSZICAR`, compute the adsorption energy, and print it; return that printed value as the final result.
