Create the INCAR file containing the specified parameters.  
Run VASP using the command `bash run_vasp.sh`.  
Copy the used INCAR to `INCAR1` with `cp INCAR INCAR1`.  
Extract the optimized total energy by executing `python get_energy.py`.
