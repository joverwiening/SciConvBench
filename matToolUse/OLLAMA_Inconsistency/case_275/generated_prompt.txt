Create a file named INCAR containing the following lines:
ALGO = Fast
EDIFF = 0.00025
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 6
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 19*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Run VASP using the provided launch script with the command `bash run_vasp.sh`.
After VASP finishes, copy the used INCAR file to a backup named INCAR1 with `cp INCAR INCAR1`.
Extract the optimized total energy by executing `python get_energy.py` and output the printed value exactly as it appears.
