Write a Python function named `compute_freysoldt_correction` with no required arguments.  
The function must:

- Assume a global variable `file_path` that points to the base directory containing the data.  
- Locate the `Mg_Ga` directory inside `file_path`.  
- Identify a sub‑folder whose name is either `neutral` or `0` (case‑insensitive) and treat it as the neutral‑defect calculation folder.  
- Identify the first sub‑folder whose name contains a “+” or “‑” character (excluding the neutral folder) and treat it as a charged‑defect calculation folder.  
- In each of the two folders, read the gzipped VASP output files `vasprun.xml.gz` and `LOCPOT.gz` using `pymatgen.io.vasp.outputs.Vasprun` and `pymatgen.io.vasp.outputs.Locpot`.  
- Extract the defect structure from the neutral folder’s `vasprun.xml.gz`.  
- Extract the bulk (reference) structure from the same neutral folder’s `vasprun.xml.gz` (the neutral defect is used as the bulk reference for this example).  
- Load the defect and bulk electrostatic potentials from the corresponding `LOCPOT.gz` files.  
- Call `pymatgen.analysis.defects.corrections.freysoldt.get_freysoldt_correction` with the defect structure, bulk structure, defect LOCPOT, bulk LOCPOT, and a charge of 0 (neutral state).  
- Store the returned correction energy (a float, expected to be approximately 0) in a dictionary under the key `freysoldt_correction_energy`.  
- Return the dictionary.  

The function must include all necessary imports, handle missing files with informative exceptions, and contain a complete docstring that describes:  

- No input parameters.  
- The expected global variable `file_path`.  
- The types of the returned dictionary values.  
- The overall purpose of the function.
