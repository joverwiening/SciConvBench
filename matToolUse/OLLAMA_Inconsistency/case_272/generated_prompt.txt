Create a file named INCAR in the current directory containing the following lines:
ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 15*0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05
Save a copy of this INCAR file as INCAR1.
Execute the VASP calculation by running the command: bash run_vasp.sh.
After the VASP run completes, extract the optimized total energy by executing: python get_energy.py.
Return the optimized total energy exactly as printed by get_energy.py.
