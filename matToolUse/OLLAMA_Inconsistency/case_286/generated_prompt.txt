Create a file named INCAR in the current directory containing the following lines:
ALGO = Fast
EDIFF = 0.00015000000000000001
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*-0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05
Run VASP using the provided launch script with the command: bash run_vasp.sh
After VASP finishes, copy the INCAR file to a new file named INCAR1 with the command: cp INCAR INCAR1
Extract the optimized total energy by executing the post‑processing script: python get_energy.py
The optimized total energy printed by get_energy.py is -15.432 eV.
