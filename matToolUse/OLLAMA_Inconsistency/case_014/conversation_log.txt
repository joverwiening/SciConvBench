Q: What file or data should be used to create the slightly unstable AlN bulk entry before calling `ensure_stable_bulk`?
A: Use the hull energy of **GaN** (obtained from the phase diagram built from the `stable_entries_Mg_Ga_N.json` file) and add 2 (eV) to that value. That resulting energy defines the slightly unstable computed entry for **GaN** that you then pass to `ensure_stable_bulk`. No separate AlN file or data is required.
