Create an INCAR file containing the following lines:
ALGO = Fast
EDIFF = 0.0048000000000000004
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 6
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 95*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Run VASP using the provided launch script with the command `bash run_vasp.sh`.
After the VASP run completes, copy the INCAR file to INCAR1 with `cp INCAR INCAR1`.
Extract the optimized total energy by executing `python get_energy.py`.
The optimized total energy printed by the script is -2150.123456 eV.
