Q: What are the filenames and formats (e.g., `vasprun.xml`, `OUTCAR`) inside each Mg_Ga charge‑state folder that should be read to obtain the defect and bulk energies and any potential‑alignment data?
A: Inside each **Mg_Ga** charge‑state subfolder you should read:

| File | Format | Purpose |
|------|--------|---------|
| **vasprun.xml.gz** | Gzipped XML (VASP output) | Provides the total energy of the defect supercell (and, if present, the defect‑level information). |
| **LOCPOT.gz** | Gzipped plain‑text (VASP local electrostatic potential) | Supplies the electrostatic‑potential data needed for the Freysoldt potential‑alignment correction. |

For the bulk reference you should also read **`bulk_sc/LOCPOT.gz`** (same gzipped plain‑text format) to obtain the bulk electrostatic‑potential reference.

Q: What are the exact names or naming pattern of the subfolders that contain the Mg_Ga defect calculations for each charge state (e.g., `Mg_Ga_-2`, `Mg_Ga_-1`, etc.)?
A: The complete requirement only states that you should **load all subfolders under `file_path / "Mg_Ga"`**; it does not prescribe a specific naming convention.  

**Make a reasonable assumption based on best practices:**  
Typically each subfolder is named for the charge state it represents, e.g.:

```
Mg_Ga/
│── -2/
│── -1/
│── 0/
│── 1/
```

or, equivalently,

```
Mg_Ga/
│── Mg_Ga_-2/
│── Mg_Ga_-1/
│── Mg_Ga_0/

```

Either of these patterns would satisfy “load all subfolders under `Mg_Ga`”. Use whatever naming pattern is present in your directory structure.
