Q: What INCAR parameters should be used for the PBE ground‑state calculation (Step 1)?
A: Use a standard PBE‑GGA INCAR, for example:

```
SYSTEM = ZnS PBE ground state
PREC   = Accurate
ENCUT  = 500          # eV (or at least the POTCAR recommended cutoff)
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2            # conjugate‑gradient ionic relaxation
NSW    = 100          # max ionic steps
ISIF   = 3            # relax ions and cell shape/volume
EDIFF  = 1E-5
EDIFFG = -0.02
LCHARG = .TRUE.       # write CHGCAR
LWAVE  = .TRUE.       # write WAVECAR
NELM   = 100
NELMIN = 4
ISPIN  = 1            # non‑magnetic
LREAL  = Auto
```

These parameters constitute a typical PBE ground‑state calculation and satisfy the requirement that you create an appropriate INCAR for Step 1. (If you prefer a slightly lower cutoff, you may set `ENCUT` to the value recommended in the POTCAR file.)
