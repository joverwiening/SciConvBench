Q: What INCAR parameters should be used for the PBE ground‑state calculation in Step 1?
A: Use a standard PBE ground‑state INCAR, for example:

```
SYSTEM = CdS PBE ground state
PREC   = Accurate
ENCUT  = 450          # same cutoff as the HSE step (or ≥ 400 eV)
EDIFF  = 1E-5
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2            # ionic relaxation (conjugate‑gradient)
NSW    = 100          # number of ionic steps
ISIF   = 3            # relax ions and cell shape/volume
ISPIN  = 1            # non‑magnetic
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 100
NELMIN = 4
LREAL  = Auto
```

These parameters give a reliable PBE self‑consistent calculation and produce the WAVECAR/CHGCAR needed for the subsequent HSE step. (If you prefer a different cutoff or convergence criteria, adjust them accordingly.)
