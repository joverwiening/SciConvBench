Q: What is the exact directory structure and filenames for the Mg_Ga defect entries and the Ga‑vacancy reference entry relative to `file_path`?
A: **Directory layout relative to `file_path`**

```
file_path/
│
├─ GaN.vasp                         # bulk structure file
│
├─ bulk_sc/
│   └─ LOCPOT.gz                    # bulk electrostatic potential (reference)
│
├─ Mg_Ga/                           # Mg on Ga defect‑entry root folder
│   ├─ -2/
│   │   ├─ vasprun.xml.gz
│   │   └─ LOCPOT.gz
│   ├─ -1/
│   │   ├─ vasprun.xml.gz
│   │   └─ LOCPOT.gz
│   ├─ 0/
│   │   ├─ vasprun.xml.gz
│   │   └─ LOCPOT.gz
│   └─ 1/
│       ├─ vasprun.xml.gz
│       └─ LOCPOT.gz
│
└─ Ga_vacancy/                      # Ga‑vacancy reference entry (used for name‑consistency check)
    ├─ vasprun.xml.gz
    └─ LOCPOT.gz
```

- **Mg_Ga defect entries**: each charge state (`-2`, `-1`, `0`, `1`) is a sub‑directory inside `Mg_Ga/` and contains the files `vasprun.xml.gz` and `LOCPOT.gz`.
- **Bulk reference**: `bulk_sc/LOCPOT.gz`.
- **Ga‑vacancy reference entry**: located in `Ga_vacancy/` with the same two files (`vasprun.xml.gz` and `LOCPOT.gz`).  

If the exact Ga‑vacancy folder name differs in your data set, make a reasonable assumption based on the naming convention used for the Mg_Ga defect folders.
