Use Quantum ESPRESSO pw.x for both steps.
Retrieve a primitive Bi2Te3 crystal structure consistent with space group R-3m and 5 atoms per primitive cell using any available structure-retrieval tool/source.
If no structure-retrieval tool/source is available, stop and report that the local inputs do not contain enough structure data to start the calculation.
Use LDA pseudopotentials PseudoDojo/SR_v0.4.1/LDA_standard/bi.upf for Bi and PseudoDojo/SR_v0.4.1/LDA_standard/te.upf for Te.
Run a variable-cell relaxation (calculation = "vc-relax") starting from the retrieved primitive structure.
Set etot_conv_thr = 1.0e-8 and forc_conv_thr = 1.0e-7 for the vc-relax.
Set conv_thr = 1.0e-8 for electronic self-consistency in both vc-relax and SCF.
Assume Bi2Te3 is non-magnetic and use nspin = 1 for both vc-relax and SCF.
Include spin–orbit coupling using noncolin = .true. and lspinorb = .true. for both vc-relax and SCF.
Do not apply any van der Waals dispersion correction.
Allow full cell shape and volume relaxation by setting cell_dofree = "all".
Use a target external pressure press = 0.0 kbar.
Choose a reasonable plane-wave kinetic-energy cutoff ecutwfc based on best practices for the given LDA PseudoDojo pseudopotentials and use the same ecutwfc for both vc-relax and SCF.
Set ecutrho consistently with best practices for the chosen ecutwfc and the pseudopotentials and use the same ecutrho for both vc-relax and SCF.
Use an automatic Monkhorst-Pack k-point mesh with half shift for both vc-relax and SCF.
Choose a reasonable k-point grid density based on best practices for primitive-cell Bi2Te3 and use the same grid for both vc-relax and SCF.
After vc-relax converges, run an SCF total-energy calculation (calculation = "scf") on the fully relaxed structure using consistent settings.
Return the fully relaxed structure (final cell vectors and atomic positions) from vc-relax.
