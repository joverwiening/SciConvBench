Work in the directory data/NEB2/Pdneb1.
Assume a typical SLURM-based HPC environment.
Assume VASP 6.x is available as vasp_std via the environment modules or PATH.
Assume VASP is launched with srun using MPI.
Assume 32 MPI ranks per job.
Assume a walltime limit of 24:00:00 per job.
Assume the SLURM partition name is normal.
Assume no explicit account/project code is required (omit --account).
Assume both run_1.sh and run.sh read an INCAR file named INCAR located in the working directory where the script is executed (IS/ for IS relaxation, FS/ for FS relaxation, and the NEB root directory for the NEB run).

Create the IS relaxation INCAR at ./INCAR before running op.py so it gets copied/used in IS/.
Use these IS relaxation INCAR settings.
SYSTEM = IS_relax
ENCUT = 450
NPAR = 1
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
EDIFF = 1E-5
EDIFFG = -0.05
IBRION = 1
POTIM = 0.2
NSW = 300
ISIF = 2
PREC = Accurate
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.

Run the IS relaxation.
python op.py IS POTCARpdch IS1POSCAR

Create the FS relaxation INCAR at ./INCAR before running op.py so it gets copied/used in FS/.
Use these FS relaxation INCAR settings.
SYSTEM = FS_relax
ENCUT = 450
NPAR = 1
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
EDIFF = 1E-5
EDIFFG = -0.05
IBRION = 1
POTIM = 0.2
NSW = 300
ISIF = 2
PREC = Accurate
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.

Run the FS relaxation.
python op.py FS POTCARpdch FS1POSCAR

Interpolate NEB images using the relaxed endpoints.
python nebmake.py

Create the NEB INCAR at ./INCAR in the NEB root directory (the directory containing 00 through 05).
Use these NEB INCAR settings.
SYSTEM = NEB
ENCUT = 450
NPAR = 1
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
EDIFF = 1E-5
EDIFFG = -0.05
IBRION = 3
POTIM = 0
NSW = 300
ISIF = 2
IOPT = 7
SPRING = -5
LCLIMB = .TRUE.
IMAGES = 4
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.

Run the NEB calculation.
python op2.py ./

Extract the NEB energy profile and barrier using the provided script.
bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'

Report the reaction-barrier value as the maximum energy along the NEB path minus the initial-state energy, as printed by nebef.pl.
Do not fabricate a numeric barrier value unless the nebef.pl output is available from the completed run.
