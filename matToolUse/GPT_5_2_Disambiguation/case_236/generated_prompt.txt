Use Quantum ESPRESSO to run a variable-cell relaxation (vc-relax) followed by an SCF total-energy calculation on the relaxed structure for ferroelectric BiFeO3.
Use LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard: bi.upf, fe.upf, o.upf.
Retrieve the initial crystal structure from Materials Project as the primitive R3c (space group 161) BiFeO3 structure with 10 atoms per primitive cell, and use its cell vectors and atomic positions as the starting configuration.
If Materials Project retrieval is not available, stop and report that the calculation cannot be started due to missing cell vectors and atomic coordinates.
Use collinear spin polarization with G-type antiferromagnetic order on Fe.
Set nspin = 2.
Assign opposite initial magnetizations to the two Fe sites in the 10-atom primitive cell: starting_magnetization(Fe1)=+0.6 and starting_magnetization(Fe2)=-0.6.
Set starting_magnetization(Bi)=0.0 and starting_magnetization(O)=0.0.
Do not use DFT+U (omit lda_plus_u and any Hubbard_U/J parameters).
Treat the system as an insulator with occupations='fixed' and no smearing parameters.
Use ecutwfc = 80 Ry.
Use ecutrho = 320 Ry.
Use an automatic Monkhorst-Pack k-point grid of 6x6x6 with half shift for both vc-relax and SCF.
Set conv_thr = 1.0e-8.
Set etot_conv_thr = 1.0e-8.
Set forc_conv_thr = 1.0e-7.
Run vc-relax with cell_dofree = 'all' to relax both cell shape and volume.
Use a zero external pressure target for vc-relax (press = 0.0 kbar).
After vc-relax converges, run an SCF calculation on the relaxed cell and atomic positions using the same pseudopotentials, cutoffs, k-point grid, occupations, and spin settings.
Return the fully relaxed structure (final cell vectors and atomic positions) from vc-relax.
Return the final total energy from the SCF calculation on the relaxed structure.
