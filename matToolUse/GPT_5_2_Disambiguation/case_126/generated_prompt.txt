Use Quantum ESPRESSO (pw.x) version 7.2 or newer.
Run a variable-cell relaxation (calculation = 'vc-relax') for wurtzite ZnO and output the fully relaxed cell and atomic positions.
Use LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard/zn.upf and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf.
Model ZnO in the hexagonal wurtzite setting with ibrav = 4 and nat = 4 and ntyp = 2.
Set the starting lattice parameters to celldm(1) = 6.14 Bohr and celldm(3) = 1.60.
Use the standard wurtzite fractional coordinates with internal parameter u = 0.382.
Set Zn fractional positions to (0.000000, 0.000000, 0.000000) and (0.6666667, 0.3333333, 0.5000000).
Set O fractional positions to (0.000000, 0.000000, 0.3820000) and (0.6666667, 0.3333333, 0.8820000).
Use ATOMIC_POSITIONS in crystal coordinates.
Use a Gamma-centered Monkhorst-Pack k-point grid of 12 12 8.
Set ecutwfc = 120 Ry.
Set ecutrho = 480 Ry.
Use zero external pressure with press = 0.0 kbar.
Allow up to nstep = 200 ionic/cell optimization steps.
Use an electronic self-consistency threshold conv_thr = 1.0d-10 Ry.
Use an ionic force convergence threshold forc_conv_thr = 1.0d-4 Ry/Bohr.
Use an energy convergence threshold etot_conv_thr = 1.0d-5 Ry.
Use occupations = 'fixed' (insulating/semiconducting default for ZnO).
Use non-spin-polarized calculations with nspin = 1.
Use ion_dynamics = 'bfgs'.
Use cell_dynamics = 'bfgs'.
Use cell_dofree = 'all'.
Return the final relaxed lattice parameters and the final relaxed atomic fractional coordinates from the vc-relax output.
