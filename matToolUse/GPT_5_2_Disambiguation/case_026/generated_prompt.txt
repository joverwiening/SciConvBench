Implement a Python function named compute_localized_bands() that takes no required input arguments.
Assume a global variable file_path exists and points to the base directory containing the defect calculation folders.
Read VASP outputs from the directories file_path/v_Ga/ccd_0_-1 and file_path/v_Ga/ccd_-1_0.
In each directory, load vasprun.xml using pymatgen.io.vasp.outputs.Vasprun with parse_projected_eigen=True when possible.
In each directory, load PROCAR using pymatgen.io.vasp.outputs.Procar from the file named PROCAR in that directory.
In each directory, load the final structure from CONTCAR if present, otherwise from POSCAR, using pymatgen.core.Structure.from_file.
Infer the Ga vacancy neighborhood without any pristine reference by selecting defect-adjacent atoms as the nearest-neighbor shell around the vacancy proxy point.
Define the vacancy proxy point as the centroid (average fractional coordinate mapped into the unit cell) of the nearest-neighbor anion sublattice around the missing Ga site, approximated by finding the anion cluster with the most undercoordinated local environment relative to typical bulk coordination in the same structure.
Compute defect-adjacent atom indices as the set of atoms in the first coordination shell around the vacancy proxy point using a distance cutoff equal to 1.25 times the minimum distance from the proxy point to any atom.
Use these defect-adjacent atom indices (0-based indices in the Structure ordering) as the “defect-site atom(s)” for PROCAR projection summation.
For each spin channel present in PROCAR, for each k-point, and for each band, compute the summed projection weight on the defect-adjacent atom indices by summing over all orbitals for those atoms.
If PROCAR provides per-ion per-orbital weights, sum across all orbitals and across the selected ions; if PROCAR provides already-summed totals, use the totals for the selected ions.
If the calculation is spin-polarized, sum the defect-site weights across spins for the same (k-point, band) before applying the localization criterion.
Classify a band as localized if there exists at least one k-point where the summed defect-site projection weight for that band exceeds 0.5.
Return localized band indices as a Python set of 1-based band indices (i.e., add 1 to the 0-based band index used internally).
Compute localized_bands_set_1 from the directory file_path/v_Ga/ccd_0_-1 using all bands present in PROCAR.
Compute localized_bands_set_2 from the directory file_path/v_Ga/ccd_-1_0 using a specified band window.
Define the band window for localized_bands_set_2 as the bands within ±1.0 eV of the Fermi level from vasprun.xml, mapped to band indices present in PROCAR, and only evaluate localization for those bands.
If vasprun.xml is missing or cannot be parsed for energies, fall back to evaluating all bands for localized_bands_set_2.
Implement robust file handling that raises a clear ValueError if required files (PROCAR and at least one of CONTCAR/POSCAR) are missing in a directory.
Include necessary imports at the top of the function, including os, numpy as np, Vasprun, Procar, and Structure.
Return a dictionary with exactly the keys localized_bands_set_1 and localized_bands_set_2 mapped to their computed set values.
Include a complete docstring describing that the function takes no arguments, relies on the global file_path, reads VASP outputs from the two CCD directories, defines localization by PROCAR defect-site projection weight > 0.5 at any k-point, uses 1-based band indices, and returns a dict[str, set[int]].
