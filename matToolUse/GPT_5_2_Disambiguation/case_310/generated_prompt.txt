Work in the directory data/bandgap/AlN.
Use POSCAR, KPOINTS, and POTCAR from the current directory as the inputs for all VASP runs.
Step 1 (PBE ground-state): create an INCAR suitable for a non-magnetic, static ground-state calculation that produces WAVECAR and CHGCAR for reuse in Step 2.
Run the Step 1 calculation by executing bash run_vasp.sh.
After Step 1 finishes, save the INCAR used for Step 1 by running cp INCAR INCAR1.
Step 2 (hybrid functional): overwrite INCAR with the following settings exactly: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., TIME=0.4.
In Step 2, do not set magnetic moments, do not set NBAND, do not set NELECT, and do not set ICHARG to a value larger than 10.
Run the Step 2 calculation by executing bash run_vasp.sh.
After Step 2 finishes, save the INCAR used for Step 2 by running cp INCAR INCAR2.
Step 3 (band gap extraction): run python gap.py to extract the band gap from the hybrid-functional output.
Because the numeric output from gap.py is not available, assume the literature HSE06 band gap for wurtzite AlN as the reported band gap.
