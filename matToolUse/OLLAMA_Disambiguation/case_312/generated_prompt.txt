Create an INCAR file for the ground‑state PBE calculation using the parameters:
SYSTEM = BN PBE ground state
ENCUT = 450
PREC = Normal
EDIFF = 1E-5
ISMEAR = 0
SIGMA = 0.05
IBRION = -1
NSW = 0
ISIF = 2
ISPIN = 1
LCHARG = .TRUE.
LWAVE = .TRUE.
LREAL = Auto
NPAR = 1
KPAR = 4
NCORE = 1
Save this file as INCAR and run VASP with `bash run_vasp.sh`. After the run completes, copy the INCAR to INCAR1 with `cp INCAR INCAR1`.

Create a new INCAR file for the hybrid‑functional calculation using the following block:
PREC = Normal
ENCUT = 450
NELM = 500
IBRION = -1
ISPIN = 1
NSW = 0
ISIF = 2
EDIFF = 1E-5
EDIFFG = -5E-3
ISMEAR = 0
SIGMA = 0.05
LWAVE = .TRUE.
LCHARG = .TRUE.
LREAL = Auto
LPLANE = .TRUE.
NPAR = 1
KPAR = 4
NCORE = 1
LORBIT = 11
ALGO = All
LHFCALC = .TRUE.
TIME = 0.4
Do not include ICHARG values larger than 10, do not specify MAGMOM, NBAND, or NELECT. Save this file as INCAR and run VASP again with `bash run_vasp.sh`. After the run completes, copy the INCAR to INCAR2 with `cp INCAR INCAR2`.

Execute the post‑processing script with `python gap.py`. Capture and output the band‑gap value printed by the script.
