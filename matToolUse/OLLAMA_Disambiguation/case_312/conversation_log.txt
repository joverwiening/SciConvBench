Q: What specific INCAR parameters should be used for the ground‑state (Step 1) calculation?
A: A reasonable PBE ground‑state INCAR can be built from standard best‑practice settings, for example:

```
SYSTEM = BN PBE ground state
ENCUT   = 450          # plane‑wave cutoff (same as used later)
PREC    = Normal
EDIFF   = 1E-5
ISMEAR  = 0            # Gaussian smearing
SIGMA   = 0.05
IBRION  = -1           # static calculation (no ionic steps)
NSW     = 0
ISIF    = 2            # stress/force calculation (optional)
ISPIN   = 1            # non‑magnetic
LCHARG  = .TRUE.       # write CHGCAR
LWAVE   = .TRUE.       # write WAVECAR
LREAL   = Auto
NPAR    = 1
KPAR    = 4
NCORE   = 1
```

These parameters give a well‑converged PBE ground‑state calculation and match the settings used in the subsequent hybrid‑functional step. If you prefer a slightly different cutoff or precision, adjust `ENCUT` and `PREC` accordingly, but keep the overall structure of the INCAR as shown.
