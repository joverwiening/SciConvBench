Retrieve a primitive Fe₃O₄ spinel structure (space group Fd‑3m, 7 atoms per primitive cell) from a reliable database such as the Materials Project (e.g., MP‑1925) or an equivalent well‑cited literature source and use the reported lattice constant (≈ 8.40 Å for the cubic cell) as the initial cell parameter.

Use the LDA pseudopotentials provided: PseudoDojo/SR_v0.4.1/LDA_standard/fe.upf and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf.

Set the plane‑wave cutoffs to:
- ecutwfc = 60 Ry
- ecutrho = 480 Ry (8 × ecutwfc)

Use a gamma‑centered Monkhorst‑Pack k‑point grid:
- vc‑relax: 6 × 6 × 6
- scf, nscf, bands: 8 × 8 × 8
- DOS post‑processing: same 8 × 8 × 8 grid used in the nscf step

Electronic convergence:
- etot_conv_thr = 3.7 × 10⁻⁵ Ry (≈ 1 meV per atom)
- conv_thr (for SCF) = 1.0 × 10⁻⁸ Ry

Ionic convergence (vc‑relax):
- forc_conv_thr = 1.0 × 10⁻⁴ Ry/Bohr

Smearing:
- occupations = smearing
- smearing = methfessel‑paxton
- degauss = 0.02 Ry

Spin configuration:
- nspin = 2 (spin‑polarized)
- starting_magnetization(Fe) = 0.5
- starting_magnetization(O) = 0.0
- No spin‑orbit coupling (lspinorb = .false.)

No Hubbard U correction is applied.

Workflow:

1. **vc‑relax**
   - calculation = 'vc-relax'
   - cell_dofree = 'all'
   - Include the above cutoffs, k‑points, convergence thresholds, smearing, and spin settings.

2. **scf**
   - calculation = 'scf'
   - Use the relaxed cell and atomic positions from step 1.
   - Same cutoffs, k‑points, convergence, smearing, and spin settings.

3. **nscf**
   - calculation = 'nscf'
   - Use the SCF charge density.
   - Same cutoffs, k‑points, smearing, and spin settings.
   - Set occupations = 'fixed' (no smearing) if desired for DOS accuracy.

4. **pw.x (bands)**
   - calculation = 'bands'
   - Use the same nscf charge density.
   - Same cutoffs and k‑point grid as in step 3.
   - Enable `nosym=.true.` to preserve k‑point ordering for band post‑processing.

5. **Band post‑processing (pp.x)**
   - Use `bands` input to extract eigenvalues along the high‑symmetry path (optional, not required for final output).

6. **DOS post‑processing (dos.x)**
   - Use the nscf output.
   - Set `degauss` = 0.02 Ry and `DeltaE` = 0.01 eV for a smooth DOS.
   - Generate total DOS and projected DOS on Fe and O.

All input files must reference the LDA pseudopotentials listed above, and the calculation should be run sequentially following the steps described. The final deliverable is the converged total and projected density‑of‑states files for Fe₃O₄.
