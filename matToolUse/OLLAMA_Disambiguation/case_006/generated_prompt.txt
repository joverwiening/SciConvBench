Write a Python function named `compute_named_defect_properties` with no input arguments.

The function must:
- Import `Path` from `pathlib`, `Structure` from `pymatgen.core`, and `NamedDefect` from `pymatgen.analysis.defects.named_defect`.
- Define `file_path` as the current working directory (`Path.cwd()`).
- Construct the full paths to the bulk and defect structure files:
  - Bulk: `file_path / "Mg_Ga" / "bulk_sc" / "CONTCAR.gz"`
  - Defect: `file_path / "Mg_Ga" / "q=0" / "CONTCAR.gz"`
- Load the bulk and defect structures using `Structure.from_file`.
- Create two `NamedDefect` objects:
  - `named_defect_auto` using the loaded defect structure, bulk structure, and a name of your choice (e.g., `"Mg_Ga_defect"`).
  - `named_defect_manual` constructed in the same way (identical arguments) to serve as a reference for equality checks.
- Compute `element_changes` as the difference between the defect and bulk compositions. Convert the resulting `Composition` to a plain dictionary mapping element symbols to numeric counts.
- Build `defect_string_representation` by concatenating the bulk formula (use `bulk_structure.composition.reduced_formula`) with the defect name, separated by an underscore.
- Determine `defect_equality` by evaluating `named_defect_auto == named_defect_manual`.
- Determine `defect_inequality` by evaluating `named_defect_auto != named_defect_manual`.
- Return a dictionary with the keys `"element_changes"`, `"defect_string_representation"`, `"defect_equality"`, and `"defect_inequality"` mapping to the computed values.
- Include a comprehensive docstring that describes the function, its lack of parameters, the types of the returned dictionary values, and any assumptions about file locations.
