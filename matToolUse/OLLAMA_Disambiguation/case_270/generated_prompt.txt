Create an INCAR file containing the following lines:
ALGO = Fast
EDIFF = 0.0002
ENCUT = 520.0
IBRION = 2
ISMEAR = -5
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Save the file as INCAR in the case directory.
Copy the INCAR file to INCAR1 to preserve the used settings.
Execute the VASP calculation using the provided launch script: bash run_vasp.sh.
After VASP finishes, run the post‑processing script: python get_energy.py.
Report the optimized total energy exactly as printed by get_energy.py, which is -158.342 eV.
