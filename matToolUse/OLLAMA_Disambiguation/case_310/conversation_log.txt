Q: What parameters should be included in the INCAR file for the ground‑state PBE calculation (Step 1)?
A: Use a standard PBE ground‑state INCAR, for example:

```
PREC    = Accurate
ENCUT   = 500          # or at least the recommended ENMAX of the POTCAR
EDIFF   = 1E-5
EDIFFG  = -0.02
ISMEAR  = 0
SIGMA   = 0.05
IBRION  = 2            # conjugate‑gradient ionic relaxation
NSW     = 100          # number of ionic steps (adjust as needed)
ISIF    = 3            # relax ions and cell shape/volume
ISPIN   = 1            # non‑magnetic
LCHARG  = .TRUE.       # write charge density
LWAVE   = .TRUE.       # write wavefunctions
LREAL   = Auto
NELM    = 60
NELMIN  = 4
```

These parameters constitute a typical PBE ground‑state calculation. (If you need a different ENCUT or other settings, adjust them according to the POTCAR recommendations.)
