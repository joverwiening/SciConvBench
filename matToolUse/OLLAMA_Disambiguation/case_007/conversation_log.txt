Q: What are the filenames and formats of the input files that contain the Mg_Ga defect data, bulk supercell information, and any required parameters (e.g., dielectric constant) needed for the calculations?
A: **Input files and their formats**

| Purpose | File (relative to `file_path`) | Format |
|---------|--------------------------------|--------|
| Defect‑supercell VASP output (energy, forces, etc.) | `Mg_Ga/<subfolder>/vasprun.xml.gz` | gzipped VASP XML (`vasprun.xml`) |
| Defect‑supercell electrostatic potential | `Mg_Ga/<subfolder>/LOCPOT.gz` | gzipped VASP LOCPOT (plain‑text potential grid) |
| Bulk‑supercell electrostatic potential reference | `bulk_sc/LOCPOT.gz` | gzipped VASP LOCPOT (plain‑text potential grid) |
| Bulk GaN structure used to create the Mg‑on‑Ga defect | `GaN.vasp` | VASP POSCAR/CONTCAR style structure file (text) |
| Dielectric constant (parameter for Freysoldt correction) | **Not a file** – the value is given directly in the code as `dielectric_constant = 14` (float). |

These are the only files/parameters required by the complete specification to compute the Freysoldt correction, the potential‑alignment consistency check, and the defect‑vs‑bulk energy difference.
