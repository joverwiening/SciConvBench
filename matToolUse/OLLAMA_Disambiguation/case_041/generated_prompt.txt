Use the primitive rhombohedral R3c cell for BiFeO₃ with lattice parameters a = 5.63 Å and α = β = γ = 59.35°. Convert these to Cartesian cell vectors for the input structure.

Employ the LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard: bi.upf, fe.upf, and o.upf.

Set the plane‑wave cutoffs to ecutwfc = 80 Ry and ecutrho = 320 Ry (four times ecutwfc).

Use a strict total‑energy convergence threshold etot_conv_thr = 1.0 × 10⁻⁵ Ry (≈0.14 meV) and a force convergence threshold forc_conv_thr = 1.0 × 10⁻⁴ Ry/Bohr.

Choose a gamma‑centered k‑point grid of 6 × 6 × 6 for the vc‑relax, scf, and nscf calculations. For the DOS post‑processing step, use a denser 12 × 12 × 12 gamma‑centered grid.

Perform the calculations in the following sequence:
1. vc‑relax: variable‑cell relaxation with the settings above, allowing the cell shape and volume to converge while keeping the R3c symmetry as a starting point.
2. scf: self‑consistent field calculation on the relaxed structure using the same cutoffs and k‑point grid.
3. nscf: non‑self‑consistent field calculation on the scf charge density, using the same k‑point grid, to generate eigenvalues for the band‑structure step.
4. pw.x with calculation = "bands": compute the band energies along a standard high‑symmetry path for R3c (e.g., Γ‑L‑Z‑Γ‑X‑U‑R‑Γ) using the nscf wavefunctions.
5. Band post‑processing: run bands.x to interpolate the band energies and generate a band‑structure file (optional for verification, not required to be returned).
6. DOS post‑processing: run dos.x on the nscf results with a Gaussian smearing of 0.01 Ry to obtain the total and projected density of states.

Do not output the band‑structure plot; only ensure that the DOS calculation completes successfully and that the final DOS data files are generated.
