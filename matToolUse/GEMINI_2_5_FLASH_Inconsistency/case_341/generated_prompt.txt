The overall goal is to compute the adsorption energy of CO on the RuO2 surface using VASP.
The calculation will proceed in four sequential steps.
All VASP geometry optimization calculations will use the following INCAR parameters: ENCUT = 450, EDIFF = 1E-6, ISMEAR = 1, SIGMA = 0.2, ISPIN = 1, ALGO = Fast, NELM = 100, IBRION = 1, EDIFFG = -0.05, NSW = 200, ISIF = 2, POTIM = 0.2, PREC = Accurate, LREAL = Auto, LWAVE = .FALSE., LCHARG = .FALSE., NWRITE = 2.
Step 1: Optimize the CO molecule.
Create an INCAR file with the specified parameters.
Execute the command: python op.py CO POTCAR-CO POSCAR-CO.
Step 2: Optimize the clean RuO2 surface.
Create an INCAR file with the specified parameters.
Execute the command: python op.py surface POTCAR-RuO2face POSCAR-RuO2face.
Step 3: Optimize the CO-adsorbed RuO2 system.
Create an INCAR file with the specified parameters.
Execute the command: python op.py absorbed POTCAR-RuO2CO POSCAR-RuO2CO.
Step 4: Compute the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh.
The final output will be the adsorption energy as printed by calc_absorption_energy.sh.
