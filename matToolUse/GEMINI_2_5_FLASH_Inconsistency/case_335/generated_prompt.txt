The task is to compute the adsorption energy of CO on the PtO2 surface using VASP.
All VASP calculations will use the provided KPOINTS file.
All VASP calculations will use the following INCAR parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, NSW = 100, POTIM = 0.2, SIGMA = 0.2.

Step 1: Optimize the CO molecule.
Create an INCAR file with the specified parameters.
Execute the command: python op.py CO POTCAR-CO POSCAR-CO.

Step 2: Optimize the clean PtO2 surface.
Use the same INCAR file as in Step 1.
Execute the command: python op.py surface POTCAR-PtO2face POSCAR-PtO2face.

Step 3: Optimize the CO-adsorbed PtO2 system.
Use the same INCAR file as in Step 1.
Execute the command: python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO.

Step 4: Compute the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh.
Report the adsorption energy exactly as printed by calc_absorption_energy.sh.
