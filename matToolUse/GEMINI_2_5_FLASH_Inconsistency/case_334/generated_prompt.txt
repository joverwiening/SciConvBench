The VASP INCAR file for all geometry optimization steps will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, PREC = Accurate, ALGO = Fast, LREAL = Auto, LWAVE = .FALSE., LCHARG = .FALSE..
Step 1 involves optimizing the CO molecule.
Create the INCAR file with the specified parameters in the `CO` directory.
Execute the command: python op.py CO POTCAR-CO POSCAR-CO.
Step 2 involves optimizing the clean Ir surface.
Create the INCAR file with the specified parameters in the `surface` directory.
Execute the command: python op.py surface POTCAR-Irface POSCAR-Irface.
Step 3 involves optimizing the CO-adsorbed Ir system.
Create the INCAR file with the specified parameters in the `absorbed` directory.
Execute the command: python op.py absorbed POTCAR-IrCO POSCAR-IrCO.
Step 4 involves computing the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh.
The final output will be the adsorption energy as printed by `calc_absorption_energy.sh`.
