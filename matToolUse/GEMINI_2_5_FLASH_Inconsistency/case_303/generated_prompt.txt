The VASP input file INCAR will be created with the following parameters: ALGO = Fast, EDIFF = 0.0004, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 4, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 31*-0.0, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
VASP will be executed using the command bash run_vasp.sh.
The created INCAR file will be copied to INCAR1.
The optimized total energy will be extracted by running the command python get_energy.py.
The output will be the optimized total energy as printed by get_energy.py.
