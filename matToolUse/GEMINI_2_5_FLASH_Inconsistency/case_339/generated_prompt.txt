The VASP INCAR file for all geometry optimization steps will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, PREC = Accurate, LREAL = Auto, ALGO = Fast, EDIFF = 1E-6, LWAVE = .FALSE., LCHARG = .FALSE..
Step 1 involves optimizing the CO molecule.
First, create an INCAR file with the specified parameters in the current directory.
Then, execute the command: python op.py CO POTCAR-CO POSCAR-CO.
Step 2 involves optimizing the clean RhO2 surface.
Use the same INCAR file created in Step 1.
Then, execute the command: python op.py surface POTCAR-RhO2face POSCAR-RhO2face.
Step 3 involves optimizing the CO-adsorbed RhO2 system.
Use the same INCAR file created in Step 1.
Then, execute the command: python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO.
Step 4 involves computing the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh.
The final output will be the adsorption energy as printed by the calc_absorption_energy.sh script.
