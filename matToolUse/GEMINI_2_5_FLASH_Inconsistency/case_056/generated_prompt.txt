The task is to calculate the density of states for CdS.
The calculation will use the LDA pseudopotential files PseudoDojo/SR_v0.4.1/LDA_standard/cd.upf and PseudoDojo/SR_v0.4.1/LDA_standard/s.upf.
If a structure-retrieval tool is available, retrieve a primitive starting structure consistent with formula=CdS, structure=wurtzite, space_group=P6_3mc, and atoms_per_primitive_cell=4, and use it as the starting configuration.
If a structure-retrieval tool is not available, report that the local inputs do not contain enough structure data to start the calculation.
The workflow consists of the following steps: 1) vc-relax, 2) scf, 3) nscf, 4) pw.x with calculation="bands", 5) band post-processing, and 6) DOS post-processing.
The calculation requires a strict energy convergence of 1 meV/atom.
For the vc-relax step, the etot_conv_thr parameter will be set to 1.0e-5 Ry.
For the vc-relax step, the forc_conv_thr parameter will be set to 1.0e-3 Ry/Bohr.
For the scf step, the conv_thr parameter will be set to 1.0e-5 Ry.
The plane-wave cutoff energy (ecutwfc) will be set to 50 Ry.
A gamma-centered k-point grid of 6x6x4 will be used for sampling.
The final output of the task is the density of states.
The band structure does not need to be explicitly returned.
