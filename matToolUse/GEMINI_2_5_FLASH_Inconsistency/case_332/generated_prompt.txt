The PBE ground-state calculation INCAR will use the following parameters: SYSTEM = ZnO PBE Ground State, ISTART = 0, ICHARG = 2, ISMEAR = 0, SIGMA = 0.05, PREC = Normal, ENCUT = 450, EDIFF = 1E-6, EDIFFG = -1E-2, IBRION = 2, ISIF = 3, NSW = 100, ISPIN = 1, LCHARG = .TRUE., LWAVE = .TRUE..
The workflow begins by creating the INCAR file for the PBE ground-state calculation with the specified parameters.
Execute the VASP calculation using the command: bash run_vasp.sh.
Save a copy of the INCAR file as INCAR1 using the command: cp INCAR INCAR1.
For the HSE calculation, create a new INCAR file using the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=10, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
Execute the VASP calculation for the HSE step using the command: bash run_vasp.sh.
Save a copy of the INCAR file as INCAR2 using the command: cp INCAR INCAR2.
Finally, run the post-processing script to extract the band gap using the command: python gap.py.
The final output will be the band-gap value printed by gap.py.
