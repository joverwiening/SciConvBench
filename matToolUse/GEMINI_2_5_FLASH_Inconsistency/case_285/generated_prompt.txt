Create the VASP input file INCAR in the current directory.
Write the following parameters into INCAR: ALGO = Fast, EDIFF = 0.0025, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 4, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 49*-0.0, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Run VASP using the command bash run_vasp.sh.
Copy the INCAR file to INCAR1.
Extract the optimized total energy by executing the command python get_energy.py.
Report the optimized total energy exactly as printed by get_energy.py.
