The current working directory is `data/bandgap/Cu2O`.
The `POSCAR`, `KPOINTS`, and `POTCAR` files in the current directory will be used as inputs.

Step 1: Perform a PBE ground-state calculation.
Create an `INCAR` file with the following parameters:
PREC = Normal
ENCUT = 450
EDIFF = 1E-5
ISMEAR = 0
SIGMA = 0.05
IBRION = 2
ISIF = 3
NSW = 100
ISTART = 0
ICHARG = 2
ISPIN = 1
ALGO = Fast
LREAL = Auto
LCHARG = .T.
LWAVE = .T.
LORBIT = 11
LPLANE = .TRUE.
NPAR = 1
KPAR = 4
NCORE = 1
Execute the VASP calculation using `bash run_vasp.sh`.
Copy the `INCAR` file to `INCAR1`.

Step 2: Perform an HSE calculation.
Create a new `INCAR` file with the following parameters:
PREC = Normal
ENCUT = 450
NELM = 500
IBRION = -1
ISPIN = 1
NSW = 0
ISIF = 2
EDIFF = 1E-5
EDIFFG = -5E-3
ISTART = 0
ICHARG = 0
ISMEAR = 0
SIGMA = 0.05
LWAVE = .T.
LCHARG = .T.
LREAL = Auto
LPLANE = .TRUE.
NPAR = 1
KPAR = 4
NCORE = 1
LORBIT = 11
ALGO = All
LHFCALC = .TRUE.
HSE06 = .TRUE.
HFSCREEN = 0.2
TIME = 0.4
AEXX = 0.25
AGGAX = 0.75
LMAXFOCK = 4
PRECFOCK = Fast
Execute the VASP calculation using `bash run_vasp.sh`.
Copy the `INCAR` file to `INCAR2`.

Step 3: Extract the band gap.
Execute the post-processing script using `python gap.py`.
The final output is the band-gap value printed by `gap.py`.
