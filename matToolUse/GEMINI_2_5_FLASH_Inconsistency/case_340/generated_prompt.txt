The VASP calculation will use the following INCAR parameters for all geometry optimization steps: EDIFF = 1E-6, EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, NSW = 200, POTIM = 0.2, PREC = Accurate, SIGMA = 0.2, ALGO = Fast, LWAVE = .FALSE., LCHARG = .FALSE..
First, optimize the CO molecule by writing the INCAR file and then executing `python op.py CO POTCAR-CO POSCAR-CO`.
Second, optimize the clean IrO2 surface by writing the INCAR file and then executing `python op.py surface POTCAR-IrO2face POSCAR-IrO2face`.
Third, optimize the CO-adsorbed IrO2 system by writing the INCAR file and then executing `python op.py absorbed POTCAR-IrO2CO POSCAR-IrO2CO`.
Finally, compute the adsorption energy by executing `bash ./calc_absorption_energy.sh`.
The final output will be the adsorption energy value printed by `calc_absorption_energy.sh`.
