The task is to calculate the density of states for MgB2.
The workflow consists of six steps: vc-relax, scf, nscf, pw.x with calculation="bands", band post-processing, and DOS post-processing.
The calculation uses LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard/mg.upf and PseudoDojo/SR_v0.4.1/LDA_standard/b.upf.
A strict energy convergence of 1 meV/atom is required, which translates to an etot_conv_thr of 2.2e-4 Ry for the primitive cell.
The forc_conv_thr parameter is set to 1.0e-4 Ry/Bohr.
The scf convergence threshold (conv_thr) is set to 1.0e-9 Ry.
The plane-wave cutoff energy (ecutwfc) is 60 Ry.
The charge density cutoff energy (ecutrho) is 240 Ry.
Electronic sampling uses an automatic Monkhorst-Pack k-point grid with dimensions 10x10x10 and a half shift (0.5, 0.5, 0.5).
Occupations are determined using smearing with the 'marzari-vanderbilt' method and a degauss value of 0.01 Ry.
If a structure-retrieval tool is available, retrieve a primitive starting structure consistent with formula=MgB2, structure=phonon-mediated, space_group=P6/mmm, and atoms_per_primitive_cell=3.
If a structure-retrieval tool is not available, report that the local inputs do not contain enough structure data to start the calculation.
The band structure does not need to be explicitly returned.
