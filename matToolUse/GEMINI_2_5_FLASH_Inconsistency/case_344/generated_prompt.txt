The VASP NEB workflow will be executed in five steps to compute the transition-state energy barrier.
Step 1: Optimize the initial state structure.
Create an INCAR file for initial state optimization with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200.
Execute the command: python op.py IS POTCARagpd IS1POSCAR.
Step 2: Optimize the final state structure.
Create an INCAR file for final state optimization with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200.
Execute the command: python op.py FS POTCARagpd FS1POSCAR.
Step 3: Interpolate intermediate images.
Execute the command: python nebmake.py.
This will create NEB image folders from 00 to 05.
Step 4: Perform the NEB calculation.
Create an INCAR file for the NEB calculation with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 3, IMAGES = 4, LCLIMB = .TRUE., IOPT = 7, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0, SIGMA = 0.2, SPRING = -5, NSW = 200.
Execute the command: python op2.py ./.
Step 5: Extract energies and determine the barrier.
Execute the command: bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'.
The final output will be the reaction-barrier value produced by the extraction step.
