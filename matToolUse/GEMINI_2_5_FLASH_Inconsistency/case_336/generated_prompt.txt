The VASP calculation will be performed in four steps.
Step 1: Optimize the CO molecule.
The INCAR file for Step 1 will contain the following parameters:
PREC = Normal
ALGO = Fast
LREAL = Auto
EDIFF = 1E-5
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
NSW = 200
POTIM = 0.2
SIGMA = 0.2
Execute the command: python op.py CO POTCAR-CO POSCAR-CO.
Step 2: Optimize the clean surface.
The INCAR file for Step 2 will be identical to the INCAR file used in Step 1.
Execute the command: python op.py surface POTCAR-Rhface POSCAR-Rhface.
Step 3: Optimize the adsorbed system.
The INCAR file for Step 3 will be identical to the INCAR file used in Step 1.
Execute the command: python op.py absorbed POTCAR-RhCO POSCAR-RhCO.
Step 4: Compute the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh.
The final output will be the adsorption energy printed by calc_absorption_energy.sh.
