Create a VASP input file named INCAR.
Write the following parameters into INCAR: ALGO = Fast, EDIFF = 0.00015000000000000001, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 23*0.0, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Execute the VASP simulation by running the script: bash run_vasp.sh.
Create a copy of the INCAR file named INCAR1.
Extract the optimized total energy by running the script: python get_energy.py.
Report the optimized total energy exactly as printed by get_energy.py.
