The current working directory is data/bandgap/GaAs.
The POSCAR file is located at POSCAR.
The KPOINTS file is located at KPOINTS.
The POTCAR file is located at POTCAR.
Step 1: Create an INCAR file with the following parameters: PREC = Normal, ENCUT = 450, EDIFF = 1E-5, NELM = 500, IBRION = -1, NSW = 0, ISMEAR = 0, SIGMA = 0.05, ISTART = 0, ICHARG = 2, LWAVE = .TRUE., LCHARG = .TRUE., ISPIN = 1, ALGO = Fast, LREAL = Auto, LORBIT = 11.
Step 1: Execute the command bash run_vasp.sh.
Step 1: Execute the command cp INCAR INCAR1.
Step 2: Create an INCAR file with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
Step 2: Do not specify magnetic moments in the INCAR file.
Step 2: Do not specify NBAND in the INCAR file.
Step 2: Do not specify NELECT in the INCAR file.
Step 2: Execute the command bash run_vasp.sh.
Step 2: Execute the command cp INCAR INCAR2.
Step 3: Execute the command python gap.py.
The final output is the band gap value printed by gap.py.
