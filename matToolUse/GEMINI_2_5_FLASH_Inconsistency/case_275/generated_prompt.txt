Create the VASP input file INCAR in the current directory.
Write the following parameters into INCAR: ALGO = Fast, EDIFF = 0.00025, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 6, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 19*0.0, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Execute the VASP simulation by running the script bash run_vasp.sh.
Create a copy of the INCAR file named INCAR1.
Execute the Python script python get_energy.py to extract the optimized total energy.
Report the optimized total energy exactly as printed by get_energy.py.
