Create the VASP input file INCAR for structure optimization.
Set ALGO = Fast in INCAR.
Set EDIFF = 0.0002 in INCAR.
Set ENCUT = 520.0 in INCAR.
Set IBRION = 2 in INCAR.
Set ISIF = 3 in INCAR.
Set ISMEAR = -5 in INCAR.
Set ISPIN = 2 in INCAR.
Set LASPH = .TRUE. in INCAR.
Set LMAXMIX = 4 in INCAR.
Set LORBIT = 11 in INCAR.
Set LREAL = Auto in INCAR.
Set LWAVE = .FALSE. in INCAR.
Set MAGMOM = 15*3.445 16*0.22 in INCAR.
Set NELM = 100 in INCAR.
Set NSW = 99 in INCAR.
Set PREC = Accurate in INCAR.
Set SIGMA = 0.05 in INCAR.
Run VASP using the command bash run_vasp.sh.
Preserve a copy of the INCAR file as INCAR1 using the command cp INCAR INCAR1.
Extract the optimized total energy using the command python get_energy.py.
Report the optimized total energy exactly as printed by get_energy.py.
