The INCAR file for all geometry optimization steps will contain the following parameters: PREC = Accurate, EDIFF = 1E-6, EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, NSW = 100, POTIM = 0.2, SIGMA = 0.2, LREAL = Auto, ALGO = Fast, LWAVE = .FALSE., LCHARG = .FALSE..
Step 1: Perform geometry optimization of the carbon monoxide (CO) molecule.
Step 1: Write the INCAR file to the current directory.
Step 1: Execute the command: python op.py CO POTCAR-CO POSCAR-CO.
Step 2: Perform geometry optimization of the clean surface.
Step 2: Ensure the INCAR file is consistent with the parameters defined above.
Step 2: Execute the command: python op.py surface POTCAR-PdO2face POSCAR-PdO2face.
Step 3: Perform geometry optimization of the adsorbed system.
Step 3: Ensure the INCAR file is consistent with the parameters defined above.
Step 3: Execute the command: python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO.
Step 4: Compute the adsorption energy from the three total energies.
Step 4: Execute the command: bash ./calc_absorption_energy.sh.
The final output will be the adsorption energy as printed by calc_absorption_energy.sh.
