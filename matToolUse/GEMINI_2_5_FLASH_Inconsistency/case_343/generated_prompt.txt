The task is to compute the adsorption energy of CO on the provided surface using VASP.
The calculation will proceed in four steps.
The INCAR file for the geometry optimization steps (Steps 1-3) will be identical and contain the following parameters:
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 100
ISTART = 0
ICHARG = 2
PREC = Accurate
ALGO = Fast
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.
EDIFF = 1E-6

Step 1: Optimize the CO molecule.
Write the INCAR file with the specified parameters.
Execute the command: python op.py CO POTCAR-CO POSCAR-CO

Step 2: Optimize the clean surface.
Ensure the INCAR file is identical to the one used in Step 1.
Execute the command: python op.py surface POTCAR-Pdface POSCAR-Pdface

Step 3: Optimize the adsorbed system.
Ensure the INCAR file is identical to the one used in Step 1.
Execute the command: python op.py absorbed POTCAR-PdCO POSCAR-PdCO

Step 4: Compute the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh
The final output will be the adsorption energy as printed by calc_absorption_energy.sh.
