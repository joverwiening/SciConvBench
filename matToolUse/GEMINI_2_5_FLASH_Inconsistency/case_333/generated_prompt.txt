The task is to compute the electronic band gap of ZnS using VASP.
The current working directory is `data/bandgap/ZnS`.
The `POSCAR`, `KPOINTS`, and `POTCAR` files in the current directory will be used as inputs.
The workflow consists of three sequential steps.

Step 1: PBE ground state calculation.
Create an `INCAR` file with the following parameters for the PBE ground-state calculation:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=Fast
Run VASP using the command `bash run_vasp.sh`.
Save a copy of the `INCAR` file used for Step 1 as `INCAR1` using the command `cp INCAR INCAR1`.

Step 2: HSE calculation.
Create a new `INCAR` file for the HSE calculation.
The calculation must continue from the existing `WAVECAR` and charge density generated in Step 1.
The `INCAR` parameters for the HSE calculation are:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast
Do not specify magnetic moments, NBAND, or NELECT parameters.
Run VASP using the command `bash run_vasp.sh`.
Save a copy of the `INCAR` file used for Step 2 as `INCAR2` using the command `cp INCAR INCAR2`.

Step 3: Band gap extraction.
Run the provided post-processing script using the command `python gap.py`.
The final output is the band-gap value exactly as printed by `gap.py`.
