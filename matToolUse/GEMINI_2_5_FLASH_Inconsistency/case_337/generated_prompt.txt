The INCAR file for all geometry optimization steps will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, PREC = Accurate, ALGO = Fast, LREAL = Auto, LWAVE = .FALSE., LCHARG = .FALSE..
Step 1: Optimize the CO molecule.
Write the INCAR file with the specified parameters into the `CO` directory.
Execute the command: python op.py CO POTCAR-CO POSCAR-CO.
Step 2: Optimize the clean OsO2 surface.
Write the INCAR file with the specified parameters into the `surface` directory.
Execute the command: python op.py surface POTCAR-OsO2face POSCAR-OsO2face.
Step 3: Optimize the CO-adsorbed OsO2 system.
Write the INCAR file with the specified parameters into the `absorbed` directory.
Execute the command: python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO.
Step 4: Compute the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh.
The final output will be the adsorption energy as printed by `calc_absorption_energy.sh`.
