The INCAR file for all geometry optimization steps will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, PREC = Accurate, LREAL = Auto, ALGO = Fast, LWAVE = .FALSE., LCHARG = .FALSE., EDIFF = 1E-5, NELM = 60.
First, perform geometry optimization of the CO molecule.
Write the INCAR file to the current directory.
Execute the command: python op.py CO POTCAR-CO POSCAR-CO.
Second, perform geometry optimization of the clean Pt surface.
Ensure the INCAR file is consistent with the specified parameters.
Execute the command: python op.py surface POTCAR-Ptface POSCAR-Ptface.
Third, perform geometry optimization of the CO-adsorbed Pt system.
Ensure the INCAR file is consistent with the specified parameters.
Execute the command: python op.py absorbed POTCAR-PtCO POSCAR-PtCO.
Fourth, compute the adsorption energy.
Execute the command: bash ./calc_absorption_energy.sh.
The final output will be the adsorption energy as printed by calc_absorption_energy.sh.
