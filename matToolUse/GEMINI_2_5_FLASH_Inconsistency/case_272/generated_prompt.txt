Create a VASP input file named INCAR.
Write the following parameters into INCAR: ALGO = Fast, EDIFF = 0.0001, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 15*0.0, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Run VASP using the command: bash run_vasp.sh.
Preserve a copy of the INCAR file as INCAR1 using the command: cp INCAR INCAR1.
Extract the optimized total energy using the command: python get_energy.py.
Report the optimized total energy exactly as printed by get_energy.py.
