The goal is to compute the electronic band gap of MoS2 using VASP.
The workflow involves a PBE ground state calculation followed by an HSE calculation.
The input files POSCAR, KPOINTS, and POTCAR are located in the current directory.

Step 1: PBE ground state calculation.
Create an INCAR file for the PBE ground-state calculation.
Set SYSTEM to 'MoS2 PBE Ground State'.
Set ISTART to 0.
Set ICHARG to 2.
Set ISMEAR to 0.
Set SIGMA to 0.05.
Set PREC to Normal.
Set ENCUT to 450.
Set EDIFF to 1E-5.
Set EDIFFG to -0.02.
Set IBRION to 2.
Set ISIF to 3.
Set NSW to 100.
Set ISPIN to 1.
Set LCHARG to .TRUE..
Set LWAVE to .TRUE..
Set ALGO to Fast.
Set NELM to 200.
Execute VASP by running 'bash run_vasp.sh'.
Copy the INCAR file to INCAR1.

Step 2: HSE calculation.
Create a new INCAR file for the HSE calculation.
Set PREC to Normal.
Set ENCUT to 450.
Set NELM to 500.
Set IBRION to -1.
Set ISPIN to 1.
Set NSW to 0.
Set ISIF to 2.
Set EDIFF to 1E-5.
Set EDIFFG to -5E-3.
Set ISTART to 0.
Set ICHARG to 1.
Set ISMEAR to 0.
Set SIGMA to 0.05.
Set LWAVE to .T..
Set LCHARG to .T..
Set LREAL to Auto.
Set LPLANE to .TRUE..
Set NPAR to 1.
Set KPAR to 4.
Set NCORE to 1.
Set LORBIT to 11.
Set ALGO to All.
Set LHFCALC to .TRUE..
Set HSE06 to .TRUE..
Set HFSCREEN to 0.2.
Set TIME to 0.4.
Set AEXX to 0.25.
Set AGGAX to 0.75.
Set LMAXFOCK to 4.
Set PRECFOCK to Fast.
Do not specify NBAND or NELECT parameters.
Do not specify magnetic moments.
Execute VASP by running 'bash run_vasp.sh'.
Copy the INCAR file to INCAR2.

Step 3: Band gap extraction.
Run the post-processing script 'python gap.py'.
The final output is the band-gap value exactly as printed by 'gap.py'.
