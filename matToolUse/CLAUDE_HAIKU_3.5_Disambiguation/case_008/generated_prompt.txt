Compute defect-related properties using Pymatgen for a GaN system.

Collects bulk and elemental entries, constructs a formation energy diagram, and computes key defect-related properties.

The function will:
- Read the structure from 'GaN.vasp'
- Load stable entries from 'stable_entries_Mg_Ga_N.json'
- Create a phase diagram and formation energy diagram
- Compute chemical potential limits
- Determine the defect chemical system
- Extract the bulk material formula
- Return a dictionary with the computed properties

Requires the following input files in the same directory:
- 'GaN.vasp': VASP structure file for the bulk material
- 'stable_entries_Mg_Ga_N.json': JSON file containing stable entries for the system

The returned dictionary will contain:
- 'chempot_limits_count': Number of chemical potential limits
- 'defect_chemsys': Chemical system of defects as hyphen-separated elements
- 'bulk_formula': Reduced chemical formula of the bulk material

Note: The valence band maximum (VBM) should be replaced with an actual calculated value in a production environment.
