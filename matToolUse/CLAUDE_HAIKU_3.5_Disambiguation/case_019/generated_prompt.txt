Semiconductor Defect Properties Computation Function

The function `compute_semiconductor_defect_properties()` is a comprehensive Python implementation for computing semiconductor defect properties using Pymatgen. It performs the following key tasks:

Reads and sorts WSWQ files from a specified directory.
Builds a HarmonicDefect with neutral configuration and band structure.
Calculates Shockley-Read-Hall (SRH) coefficient at multiple temperatures (300, 400, 500 Kelvin).
Verifies RuntimeError handling with invalid defect configurations.
Returns a dictionary containing:
- SRH coefficient values as a list of floats
- A boolean indicating RuntimeError verification status

The implementation uses advanced Pymatgen features including:
- HarmonicDefect.from_files() method
- Numeric file sorting
- Temperature-based SRH coefficient calculation
- Comprehensive error handling

The function meets all specified requirements for semiconductor defect property computation.
