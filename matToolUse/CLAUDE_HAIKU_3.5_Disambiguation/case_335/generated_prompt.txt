Specification for CO Molecule Optimization in VASP:

Create an INCAR file with the following contents:
```
SYSTEM = CO molecule optimization
PREC = Normal
ENCUT = 450
IBRION = 1
ISMEAR = 1
SIGMA = 0.2
POTIM = 0.2
EDIFFG = -0.05
EDIFF = 1E-4
ISTART = 0
ICHARG = 2
NSW = 50
ISIF = 2
ISPIN = 1
```

Execution steps:
1. Save the above content to an INCAR file in the current directory.
2. Run the optimization command: `python op.py CO POTCAR-CO POSCAR-CO`
3. Verify the calculation completes successfully by checking the `CO/OSZICAR` file for final energy convergence.
