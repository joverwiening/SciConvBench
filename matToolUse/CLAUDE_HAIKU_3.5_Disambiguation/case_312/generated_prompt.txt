Workflow Specification for BN Band Gap Calculation:

Step 1 — Ground-state Calculation
Create INCAR with the following contents:
```
SYSTEM=BN Ground State
PREC=Normal
ENCUT=450
EDIFF=1E-5
EDIFFG=-0.01
IBRION=-1
ISIF=2
NSW=0
ISMEAR=0
SIGMA=0.05
LREAL=Auto
ISPIN=1
LWAVE=.TRUE.
LCHARG=.TRUE.
NPAR=1
KPAR=4
NCORE=1
```

Execute the following commands in sequence:
1. Write the INCAR file as described above
2. Run VASP ground-state calculation:
   ```
   bash run_vasp.sh
   ```
3. Save a copy of the INCAR:
   ```
   cp INCAR INCAR1
   ```

Step 2 — Hybrid-functional Calculation
1. Create new INCAR using the hybrid functional parameters provided in the original task description
2. Run VASP hybrid calculation:
   ```
   bash run_vasp.sh
   ```
3. Save a copy of the INCAR:
   ```
   cp INCAR INCAR2
   ```

Step 3 — Band Gap Extraction
Run post-processing script:
```
python gap.py
```

The final output will be the band gap value printed by `gap.py`.
