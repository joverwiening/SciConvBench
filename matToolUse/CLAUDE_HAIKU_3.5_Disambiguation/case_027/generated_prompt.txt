Compute Defect Grouping Properties for GaN Structure

The Python function `compute_defect_grouping()` is designed to:
- Load the GaN structure from the "GaN.vasp" file
- Create vacancy defects at site indices 0, 1, 2, and 3
- Create nitrogen interstitials at fractional coordinates [0.0, 0.0, 0.0] and [0.0, 0.0, 0.25]
- Perform defect grouping without and with a key function
- Return a dictionary containing three string representations of defect groupings
- Use Pymatgen's core defect and structure classes for implementation
- Provide type hints and a comprehensive docstring
- Handle defect grouping using Python's `itertools.groupby`
- Return results as specified in the original requirements

The function meets all specified technical and functional requirements for defect analysis using Pymatgen.
