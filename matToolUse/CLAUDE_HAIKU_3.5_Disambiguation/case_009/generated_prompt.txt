Specification for Chemical Potential Properties Computation Function:

The function `compute_chemical_potential_properties()` shall:
Compute chemical potential properties for a Mg-Ga-N defect system using Pymatgen.
Accept an optional file path parameter pointing to the base directory of input files.
Load stable entries from a JSON file named 'stable_entries_Mg_Ga_N.json'.
Process bulk system calculation from 'bulk_sc/vasprun.xml.gz' and 'bulk_sc/LOCPOT.gz'.
Create DefectEntry objects for charge states [-2, -1, 0, 1] using Freysoldt correction.
Apply a dielectric constant of 14 for the Freysoldt correction.
Extract and process LOCPOT plot data for both bulk and defect systems.
Construct a Formation Energy Diagram using bulk entry, defect entries, and elemental entries.
Compute and return the number of chemical potential limits as an integer.
Return results in a dictionary with the key 'chemical_potential_limits_count'.
Handle file loading, potential corrections, and energy calculations using Pymatgen classes.
Provide robust error handling for file not found or processing errors.
