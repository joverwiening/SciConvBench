```python
from pymatgen.core import Structure
from pymatgen.analysis.defects.core import NamedDefect
from collections import Counter

def analyze_mg_ga_defect(file_path='./'):
    """
    Analyze defect properties for an Mg_Ga system using Pymatgen.

    Returns:
        dict: A dictionary containing defect-related properties:
            - 'element_changes': Change in atom counts between bulk and defect structures
            - 'defect_string_representation': Combined bulk formula and defect name
            - 'defect_equality': Boolean comparison of defect objects
            - 'defect_inequality': Boolean comparison of defect objects
    """
    # Load bulk and defect structures
    bulk_structure = Structure.from_file(f'{file_path}/Mg_Ga/bulk_sc/CONTCAR.gz')
    defect_structure = Structure.from_file(f'{file_path}/Mg_Ga/q=0/CONTCAR.gz')

    # Calculate element changes
    bulk_elements = Counter(bulk_structure.species)
    defect_elements = Counter(defect_structure.species)
    element_changes = dict(defect_elements - bulk_elements)

    # Create NamedDefect objects
    bulk_defect = NamedDefect(bulk_structure, 'Bulk')
    defect = NamedDefect(defect_structure, 'Vacancy')

    # Generate defect string representation
    defect_string_representation = f"{bulk_structure.composition.reduced_formula}_{defect.name}"

    # Defect equality checks
    defect_equality = bulk_defect == defect
    defect_inequality = bulk_defect != defect

    return {
        'element_changes': element_changes,
        'defect_string_representation': defect_string_representation,
        'defect_equality': defect_equality,
        'defect_inequality': defect_inequality
    }
```

This implementation follows the specified requirements:
- Uses Pymatgen to load and analyze structures
- Calculates element changes by comparing atom counts
- Creates a string representation with bulk formula and defect name
- Performs defect equality and inequality checks
- Returns a dictionary with the requested properties
- Includes a comprehensive docstring
- Uses default `file_path` for flexibility
- Handles gzipped CONTCAR files

The function can be called without arguments and will use the default file path, or a specific path can be provided.
