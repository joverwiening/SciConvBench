Q: Looking at this task, I need to understand the structure of the input files to write the correct code.

What is the exact directory structure and file format of the `Mg_Ga` defect-entry directory — specifically, what files are inside it (e.g., JSON files per charge state, a single combined file, VASP output files) and how are the bulk/band-edge data stored (e.g., as separate files or embedded within the same directory)?
A: The `Mg_Ga` directory contains subfolders for each charge state. Each subfolder contains `vasprun.xml.gz` and `LOCPOT.gz` files. The bulk reference data is stored separately in a `bulk_sc` directory which contains `LOCPOT.gz` (and the bulk `vasprun.xml.gz` for obtaining VBM and bulk entry). There are no JSON files inside the defect-entry directory — everything is VASP output files.
