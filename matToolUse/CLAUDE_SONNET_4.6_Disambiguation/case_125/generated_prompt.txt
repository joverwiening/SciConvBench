Perform a vc-relax calculation for Cr2O3 using Quantum ESPRESSO.
Use the LDA exchange-correlation functional throughout.
Use the local pseudopotential files PseudoDojo/SR_v0.4.1/LDA_standard/cr.upf and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf.
Set calculation = 'vc-relax' in the &CONTROL namelist.
Set the starting structure to the experimentally known antiferromagnetic Cr2O3 corundum structure with space group R-3c and 5 atoms in the primitive cell (2 Cr + 3 O).
Use rhombohedral primitive cell vectors consistent with the R-3c space group and standard LDA lattice parameters for Cr2O3 (approximately a = 4.95 Angstrom, alpha = 55.1 degrees in rhombohedral setting, or equivalently hexagonal a ≈ 4.95 Angstrom, c ≈ 13.56 Angstrom; choose the primitive rhombohedral cell with 5 atoms).
Place Cr atoms at Wyckoff position 4c of the hexagonal setting (or equivalent in the primitive cell) and O atoms at Wyckoff position 6e, using standard fractional coordinates for R-3c Cr2O3.
Set up collinear spin-polarized calculation by setting nspin = 2 in the &SYSTEM namelist.
Assign antiferromagnetic starting magnetization: set starting_magnetization for the first Cr sublattice to +1.0 and for the second Cr sublattice to -1.0; set starting_magnetization for O to 0.0.
Do not include Hubbard U corrections unless explicitly requested; use plain LDA.
Do not include spin-orbit coupling.
Choose ecutwfc sufficient for LDA PseudoDojo standard potentials for Cr and O; use ecutwfc = 80 Ry.
Set ecutrho = 640 Ry (8x the wavefunction cutoff, appropriate for norm-conserving pseudopotentials).
Set occupations = 'smearing', smearing = 'mv', and degauss = 0.01 Ry for metallic-style treatment during relaxation; alternatively use 'fixed' if the system is confirmed insulating — use 'smearing' with methfessel-paxton and degauss = 0.005 Ry to be safe during vc-relax.
Use a gamma-centered Monkhorst-Pack k-point grid; choose a 6x6x6 grid for the primitive cell to achieve 1 meV/atom energy convergence accuracy for this oxide.
Set the energy convergence threshold for the SCF cycle: conv_thr = 1.0e-10 Ry (tight SCF convergence to support 1 meV/atom total energy accuracy).
Set etot_conv_thr = 1.0e-5 Ry (approximately 1 meV for a 5-atom cell, satisfying the 1 meV/atom requirement).
Set forc_conv_thr = 1.0e-4 Ry/Bohr as the force convergence threshold for ionic relaxation.
Set ion_dynamics = 'bfgs' in the &IONS namelist.
Set cell_dynamics = 'bfgs' in the &CELL namelist.
Set cell_dofree = 'all' to allow full cell relaxation.
Set press_conv_thr = 0.1 kbar in the &CELL namelist.
After the vc-relax run completes, extract and report the fully relaxed cell vectors, relaxed fractional atomic coordinates for all 5 atoms, the final total energy, the final forces on each atom, and the final stress tensor.
Report the relaxed structure in a format suitable for re-use as a Quantum ESPRESSO input (CELL_PARAMETERS and ATOMIC_POSITIONS cards).
