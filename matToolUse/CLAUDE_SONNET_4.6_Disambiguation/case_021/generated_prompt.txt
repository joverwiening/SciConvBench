Write a Python function called `compute_freysoldt_correction` with no required input arguments.

The function accepts one optional parameter `file_path` of type `str` or `pathlib.Path`, defaulting to `"."` (current directory), pointing to the base directory that contains the `Mg_Ga` subfolder.

Include a complete docstring describing the optional parameter, the assumed directory layout, and the returned dictionary.

Import the following at the top of the function or module: `os`, `numpy`, `pathlib.Path`, `pymatgen.core.Structure`, `pymatgen.io.vasp.outputs.Vasprun` and `Locpot`, and `pymatgen.analysis.defects.corrections.freysoldt.get_freysoldt_correction`.

Assume the directory `file_path/Mg_Ga` contains subfolders named `bulk`, and one or more charge-state folders whose names follow the pattern `q=<integer>` (e.g., `q=0`, `q=-1`, `q=-2`).

Each subfolder contains exactly one `vasprun.xml.gz` and one `LOCPOT.gz` file.

Load all subfolders into a data dictionary keyed by folder name, where each value is itself a dictionary with keys `"vasprun"` (a `Vasprun` object) and `"locpot"` (a `Locpot` object).

Parse the `vasprun.xml.gz` files using `Vasprun` with `parse_dos=False` and `parse_eigen=False` to reduce memory usage.

Use a scalar isotropic dielectric constant of `12.0` (a reasonable default for a III-V or II-VI semiconductor like GaN/MgO context), represented as `dielectric = 12.0`.

Identify the bulk entry from the dictionary using the key `"bulk"`.

Identify all defect charge states by finding keys that match the pattern `q=<integer>`; parse the integer charge from the folder name.

Select the charge state `q = -1` as the default defect state to evaluate; if `q=-1` is not present, select the charge-state folder with the most negative integer charge available.

Obtain the bulk `Locpot` object and the defect `Locpot` object for the selected charge state.

Call `get_freysoldt_correction` passing the defect `Locpot`, the bulk `Locpot`, the parsed integer charge, and the dielectric constant.

Store the total correction energy returned by `get_freysoldt_correction` as a `float` in a variable named `freysoldt_correction_energy`.

Return a dictionary with exactly one key-value pair: `{"freysoldt_correction_energy": freysoldt_correction_energy}`.

The returned value for `freysoldt_correction_energy` should be a Python `float`.

Handle the case where no `q=<integer>` folders are found by raising a `FileNotFoundError` with a descriptive message.

Handle the case where the `bulk` folder is missing by raising a `FileNotFoundError` with a descriptive message.
