Work inside the case directory data/bandgap/BN throughout all steps.

Step 1: Ground-state PBE calculation.

Write the following content to INCAR:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
NSW=0
ISIF=2
ISPIN=1
ISMEAR=0
SIGMA=0.05
EDIFF=1E-5
EDIFFG=-5E-3
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Use the existing POSCAR, KPOINTS, and POTCAR files as inputs without modification.

Run VASP by executing: bash run_vasp.sh

After VASP completes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1

Step 2: Hybrid-functional HSE calculation.

Write the following content to INCAR, replacing the previous INCAR:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
TIME=0.4
ICHARG=1

Do not add MAGMOM, NBAND, or NELECT to this INCAR.

Set ICHARG=1 so that VASP reads the charge density from the previous PBE step (ICHARG must not exceed 10 when starting from an existing WAVECAR in a hybrid calculation).

Use the same POSCAR, KPOINTS, and POTCAR files as inputs without modification.

Run VASP by executing: bash run_vasp.sh

After VASP completes, copy the INCAR to INCAR2 by executing: cp INCAR INCAR2

Step 3: Band gap extraction.

Run the post-processing script by executing: python gap.py

Capture the value printed to standard output by gap.py and return it exactly as printed — that value is the final band gap of BN.
