The task is to calculate the density of states for BaTiO3 (ferroelectric perovskite, space group P4mm, 5 atoms per primitive cell) using Quantum ESPRESSO, following a strict 6-step workflow.

Use LDA pseudopotentials throughout all steps: PseudoDojo/SR_v0.4.1/LDA_standard/ba.upf, PseudoDojo/SR_v0.4.1/LDA_standard/ti.upf, and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf.

Use the LDA exchange-correlation functional (pz or equivalent) in every step: vc-relax, scf, nscf, bands, and DOS.

Treat BaTiO3 as an insulator with fixed occupations (occupations='fixed', no smearing, no degauss) in all steps, consistent with best practice for a wide-gap insulator/semiconductor.

Use the tetrahedron method (occupations='tetrahedra') for the DOS post-processing step to obtain an accurate density of states, which is standard best practice for insulators.

Start from the experimentally known tetragonal perovskite structure of BaTiO3 consistent with space group P4mm with 5 atoms per primitive cell (Ba at corner, Ti at body center, O at face centers with tetragonal distortion). Use approximate lattice parameters a = 3.994 Angstrom and c = 4.034 Angstrom as the starting configuration for vc-relax.

Target a strict energy convergence of 1 meV/atom. With 5 atoms per primitive cell, 1 meV/atom corresponds to 5 meV total = approximately 3.67e-4 Ry total energy convergence per cell.

Set etot_conv_thr = 3.7e-4 Ry (i.e., 1 meV/atom x 5 atoms, converted to Ry) for the vc-relax step.
Set forc_conv_thr = 1.0e-3 Ry/Bohr for the vc-relax step, consistent with high-accuracy relaxation.
Set conv_thr = 1.0e-10 Ry for the scf and nscf self-consistency threshold, consistent with 1 meV/atom accuracy.

Choose ecutwfc = 80 Ry as the plane-wave kinetic energy cutoff, appropriate for the PseudoDojo norm-conserving pseudopotentials for Ba, Ti, and O.
Set ecutrho = 320 Ry (4x ecutwfc) for the charge density cutoff, consistent with norm-conserving pseudopotentials.

Use a gamma-centered Monkhorst-Pack k-point grid of 8x8x8 for the vc-relax and scf steps, sufficient for 1 meV/atom accuracy in a 5-atom perovskite cell.
Use a gamma-centered 8x8x8 k-point grid for the nscf step as well.
Use a denser gamma-centered 16x16x16 k-point grid for the DOS nscf/tetrahedra step to obtain a well-converged DOS.

Step 1: Run vc-relax using pw.x with calculation='vc-relax', ibrav=0 or explicit cell parameters for tetragonal P4mm, the LDA functional, fixed occupations, ecutwfc=80 Ry, ecutrho=320 Ry, 8x8x8 k-grid, etot_conv_thr=3.7e-4 Ry, forc_conv_thr=1.0e-3 Ry/Bohr, and cell_dofree='all' to allow full cell relaxation.

Step 2: Run scf using pw.x with calculation='scf' on the relaxed structure from step 1, using the same LDA functional, fixed occupations, ecutwfc=80 Ry, ecutrho=320 Ry, 8x8x8 k-grid, and conv_thr=1.0e-10 Ry.

Step 3: Run nscf using pw.x with calculation='nscf' on the scf charge density, using a 16x16x16 gamma-centered k-grid, occupations='tetrahedra', and conv_thr=1.0e-10 Ry, to prepare for DOS calculation.

Step 4: Run pw.x with calculation='bands' using a standard high-symmetry k-path appropriate for the tetragonal P4mm Brillouin zone (e.g., Gamma-X-M-Gamma-Z-R-A-Z path), with enough bands to cover the valence and lower conduction bands, conv_thr=1.0e-10 Ry.

Step 5: Run bands.x (band post-processing) to extract and reorder the band structure from step 4. Set lsym=.true. and specify the Fermi energy from the scf step.

Step 6: Run dos.x (DOS post-processing) using the nscf charge density from step 3. Set DeltaE = 0.01 eV for the DOS energy resolution. Set Emin and Emax to cover the full valence and conduction band range (e.g., -20 eV to +20 eV relative to the Fermi level). Output the total DOS to a file.

Do not apply Hubbard U corrections, spin-orbit coupling, or spin-polarization in any step.
Do not use any starting_magnetization settings.
The final deliverable is the completed DOS output file from step 6; the band structure from steps 4 and 5 does not need to be explicitly returned.
