Use Quantum ESPRESSO (QE) for this calculation, as it is the standard open-source DFT code best suited to the provided pseudopotential format (.upf files from PseudoDojo).

Perform a vc-relax calculation using the pw.x executable in Quantum ESPRESSO.

Set calculation = 'vc-relax' in the CONTROL namelist.

Use the LDA pseudopotentials provided: PseudoDojo/SR_v0.4.1/LDA_standard/ga.upf for Ga and PseudoDojo/SR_v0.4.1/LDA_standard/n.upf for N.

Set the exchange-correlation functional consistent with LDA by setting input_dft = 'lda' (or leave it to be read from the pseudopotential files).

The material is GaN in the wurtzite structure with space group P6_3mc and 4 atoms per primitive cell.

Use the following starting structural parameters for wurtzite GaN in the hexagonal primitive cell.
Set the lattice parameter a = 3.189 Angstrom and c = 5.185 Angstrom, with c/a = 1.626.
Set celldm(1) = 6.0267 bohr (a in bohr), celldm(3) = 1.6259 (c/a ratio).
Use ibrav = 4 to specify the hexagonal Bravais lattice.

Place 4 atoms in the primitive cell: 2 Ga and 2 N atoms.
Set the atomic positions in crystal (fractional) coordinates as follows.
Ga at (0.33333, 0.66667, 0.00000).
Ga at (0.66667, 0.33333, 0.50000).
N at (0.33333, 0.66667, 0.37600).
N at (0.66667, 0.33333, 0.87600).

The internal parameter u = 0.376 is the fractional z-coordinate of N relative to Ga, consistent with the ideal wurtzite structure for GaN.

Set ecutwfc = 80 Ry as the plane-wave kinetic energy cutoff, consistent with PseudoDojo standard accuracy recommendations for LDA norm-conserving pseudopotentials.

Set ecutrho = 320 Ry (4 times ecutwfc), appropriate for norm-conserving pseudopotentials.

The strict energy convergence requirement is 1 meV/atom, which equals 4 meV for the 4-atom cell, which equals approximately 2.94e-4 Ry for the cell.

Set etot_conv_thr = 2.9e-4 Ry (1 meV/atom times 4 atoms, converted: 1 meV = 7.3498e-5 Ry, so 4 meV = 2.94e-4 Ry).

Set forc_conv_thr = 1.0e-4 Ry/bohr, which is a tight force convergence consistent with high-accuracy relaxation.

Set conv_thr = 1.0e-10 Ry for the self-consistent field (SCF) electronic convergence, ensuring the electronic structure is converged well below the ionic convergence threshold.

Use a gamma-centered Monkhorst-Pack k-point grid.
Set a 8x8x6 k-point mesh, which is appropriate for the hexagonal wurtzite cell of GaN at this accuracy level (the c-axis is longer, so fewer k-points are needed along that direction).

Set K_POINTS automatic with grid 8 8 6 and offset 0 0 0 for a gamma-centered grid.

Use the BFGS algorithm for the ionic and cell relaxation by setting ion_dynamics = 'bfgs' and cell_dynamics = 'bfgs'.

Set press_conv_thr = 0.1 kbar for the cell pressure convergence threshold.

Set nstep = 200 to allow sufficient relaxation steps.

Set tprnfor = .true. and tstress = .true. to print forces and stress tensor at each step.

Set outdir to a local scratch or output directory, and prefix = 'GaN_vc_relax'.

Set pseudo_dir to the directory containing the two pseudopotential files.

Do not set occupations, smearing, degauss, starting_magnetization, Hubbard U, or spin-orbit coupling flags, as this is a non-magnetic, non-SOC, insulating system with no Hubbard correction required.

After the calculation completes, extract the fully relaxed structure including the final lattice vectors (or celldm values) and the final atomic positions in both crystal and Cartesian coordinates from the output file.

Report the final total energy, the final forces on all atoms, the final stress tensor, and the relaxed internal coordinate u for N in the wurtzite structure.
