The task is a variable-cell relaxation (vc-relax) followed by a self-consistent field (SCF) calculation for NbSe2 using Quantum ESPRESSO with LDA pseudopotentials from PseudoDojo SR v0.4.1 standard.

Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/nb.upf for Nb and PseudoDojo/SR_v0.4.1/LDA_standard/se.upf for Se.

Use an automatic Monkhorst-Pack k-point grid of 12x12x4 with a half shift (1 1 1) for both the vc-relax and SCF calculations, based on standard practice for the layered hexagonal cell of NbSe2.

For the vc-relax calculation, set calculation = 'vc-relax'.

Set etot_conv_thr = 1.0e-8 Ry for the vc-relax convergence on total energy.

Set forc_conv_thr = 1.0e-7 Ry/Bohr for the vc-relax convergence on forces.

Set conv_thr = 1.0e-8 Ry for the SCF convergence threshold in both the vc-relax inner SCF loops and the final SCF calculation.

Use cell_dynamics = 'bfgs' and ion_dynamics = 'bfgs' for the vc-relax.

Allow both atomic positions and cell parameters to relax freely (no constraints on cell shape unless symmetry enforces them).

After the vc-relax completes, extract the final relaxed cell vectors and atomic positions from the output.

Run a second Quantum ESPRESSO input with calculation = 'scf' using the relaxed structure and all other settings identical to the vc-relax (same ecutwfc, ecutrho, k-points, smearing, conv_thr).

Return the fully relaxed lattice parameters, relaxed fractional atomic coordinates, and the final total energy in Ry from the SCF calculation.
