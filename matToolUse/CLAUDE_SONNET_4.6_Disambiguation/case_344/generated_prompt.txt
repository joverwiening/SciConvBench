Work inside the case directory: data/NEB1/AgPdneb1.

All files referenced (IS1POSCAR, FS1POSCAR, KPOINTS, POTCARagpd, nebmake.py, op.py, op2.py, run.sh, run_1.sh, nebef.pl, Vasp.pm) are already present in that directory. Do not recreate or paste their contents.

---

STEP 1 — Relax the Initial State (IS)

Write a file named INCAR in the working directory with the following contents:

ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 300
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
NPAR = 1

NSW is set to 300 to accommodate potentially non-ideal initial structures as noted in the task specification.
ISIF = 2 ensures no cell shape or volume optimization (ions only).
ISPIN = 1 disables spin polarization for the metal surface.

After writing the INCAR, run:
python op.py IS POTCARagpd IS1POSCAR

This creates the IS directory, copies the POSCAR and POTCAR into it, and launches run_1.sh to perform the IS relaxation.

---

STEP 2 — Relax the Final State (FS)

Use the same INCAR as Step 1 (no changes needed; all parameters are identical for the FS relaxation).

Confirm the INCAR in the working directory still contains the same values listed in Step 1, then run:
python op.py FS POTCARagpd FS1POSCAR

This creates the FS directory, copies the POSCAR and POTCAR into it, and launches run_1.sh to perform the FS relaxation.

---

STEP 3 — Interpolate Intermediate Images

No INCAR is needed for this step.

Run:
python nebmake.py

This reads IS/CONTCAR and FS/CONTCAR, interpolates 4 intermediate images using ASE, and writes POSCAR files into directories 00, 01, 02, 03, 04, and 05 (6 folders total).

---

STEP 4 — Run the NEB Calculation

Write a new INCAR in the working directory (overwriting the relaxation INCAR) with the following contents:

ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 300
IBRION = 3
POTIM = 0
IOPT = 7
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
NPAR = 1
IMAGES = 4
SPRING = -5
LCLIMB = .TRUE.

IMAGES = 4 specifies the 4 intermediate images (folders 01 through 04).
SPRING = -5 sets the spring constant for the elastic band.
IBRION = 3 with POTIM = 0 delegates geometry optimization to the VTST optimizer.
IOPT = 7 selects the FIRE optimizer from the VTST library.
LCLIMB = .TRUE. enables the climbing-image NEB for accurate saddle-point location.

After writing the INCAR, run:
python op2.py ./

This copies POTCARagpd to POTCAR in the NEB directory and launches run.sh to perform the NEB calculation.

---

STEP 5 — Extract Energies and Determine the Barrier

No INCAR is needed for this step.

Run:
bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'

This copies the IS and FS OUTCAR files into the endpoint image directories, then runs nebef.pl, which reads the OUTCAR files from all six image directories (00 through 05) and prints the force and energy profile.

Read the printed output from nebef.pl. The reaction energy barrier is the energy difference between the highest-energy image (the transition state) and the initial-state image (00). Report that value in eV as the result of this NEB calculation.
