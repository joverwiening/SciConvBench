Write a Python function that computes three properties related to a formation energy diagram for GaN defects using Pymatgen.

The function takes no required input arguments.

Define a variable `file_path` at the top of the function pointing to the base directory containing the input files.

Load the bulk structure from `GaN.vasp` located in `file_path` using `pymatgen.core.Structure.from_file`.

Load the stable entries from `stable_entries_Mg_Ga_N.json` located in `file_path` using `monty.serialization.loadfn` or `json` with `MontyDecoder`.

Build a `CompetingPhases`-style chemical potential diagram or use `pymatgen.analysis.phase_diagram.PhaseDiagram` and `ChemicalPotentialDiagram` from `pymatgen.analysis.chempot_diagram` using the loaded stable entries to obtain the chemical potential limits.

Use `pymatgen.analysis.defects.generators.VacancyGenerator` (or equivalent generator such as `InterstitialGenerator` and `SubstitutionGenerator`) applied to the loaded GaN structure to generate a representative set of defect objects.

For each generated defect, create a `DefectEntry` object with a placeholder computed energy and the bulk entry derived from the stable entries list matching the GaN bulk formula.

Identify the bulk entry from the stable entries as the entry whose reduced formula matches the GaN structure formula.

Construct a `FormationEnergyDiagram` object from `pymatgen.analysis.defects.thermo` using the generated defect entries, the bulk entry, and the loaded stable entries.

Retrieve the chemical potential limits from the `FormationEnergyDiagram` object via its `chempot_limits` attribute or equivalent property.

Compute `chempot_limits_count` as the integer length of the chemical potential limits list or collection returned by the diagram.

Compute `defect_chemsys` as a hyphen-separated string of sorted unique element symbols present across all defect entries, derived from the elements of the defects' structures or the chemsys of the defect set.

Compute `bulk_formula` as the string of the reduced or pretty formula of the bulk structure loaded from `GaN.vasp`, obtained via `structure.formula` or `structure.composition.reduced_formula`.

Return a dictionary with exactly three keys: `"chempot_limits_count"` mapped to the integer count, `"defect_chemsys"` mapped to the hyphen-separated element string, and `"bulk_formula"` mapped to the bulk formula string.

Include all necessary imports at the top of the function or module, including at minimum `from pymatgen.core import Structure`, `from pymatgen.analysis.defects.generators import VacancyGenerator`, `from pymatgen.analysis.defects.thermo import FormationEnergyDiagram`, `from pymatgen.entries.computed_entries import ComputedStructureEntry`, and `from monty.serialization import loadfn`.

Include a complete docstring describing that the function reads `GaN.vasp` and `stable_entries_Mg_Ga_N.json` from `file_path`, generates vacancy defect entries using Pymatgen tools, builds a formation energy diagram, and returns a dictionary containing `chempot_limits_count` as an int, `defect_chemsys` as a str, and `bulk_formula` as a str.
