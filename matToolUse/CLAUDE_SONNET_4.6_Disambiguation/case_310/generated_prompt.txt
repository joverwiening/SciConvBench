Work inside the directory data/bandgap/AlN throughout all steps.

Step 1: Create the INCAR file for the ground-state PBE calculation with the following content:
PREC=Normal
ENCUT=450
EDIFF=1E-5
EDIFFG=-5E-3
IBRION=-1
NSW=0
ISIF=2
ISPIN=1
ISMEAR=0
SIGMA=0.05
ALGO=Normal
NELM=500
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Write that content to a file named INCAR in the current directory.

Use the existing POSCAR, KPOINTS, and POTCAR files as inputs without modification.

Run the ground-state calculation by executing: bash run_vasp.sh

After the run completes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1

Step 2: Create a new INCAR file for the hybrid-functional (HSE) calculation with the following content:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
TIME=0.4
ICHARG=1

Do not include MAGMOM, NBAND, or NELECT in this INCAR.

Set ICHARG=1 so that VASP reads the charge density from the existing CHGCAR written in Step 1, satisfying the requirement that ICHARG is not larger than 10 when starting from an existing WAVECAR.

Write that content to the file named INCAR, overwriting the previous one.

Run the hybrid-functional calculation by executing: bash run_vasp.sh

After the run completes, copy the INCAR to INCAR2 by executing: cp INCAR INCAR2

Step 3: Run the band-gap extraction script by executing: python gap.py

Capture and return the band-gap value exactly as printed to standard output by gap.py.
