Perform a vc-relax calculation using Quantum ESPRESSO.

Use the pw.x executable from Quantum ESPRESSO for the calculation.

Set calculation = 'vc-relax' in the CONTROL namelist.

Use the LDA pseudopotentials located at PseudoDojo/SR_v0.4.1/LDA_standard/sn.upf for Sn and PseudoDojo/SR_v0.4.1/LDA_standard/se.upf for Se.

Set the material as SnSe with an orthorhombic Pnma structure containing 8 atoms per primitive cell.

Use a starting structure consistent with the Pnma orthorhombic crystal structure of SnSe (space group 62), with 4 Sn atoms and 4 Se atoms in the conventional unit cell, using experimentally reported Wyckoff positions: Sn at 4c and Se at 4c sites, with approximate lattice parameters a ≈ 11.49 Å, b ≈ 4.15 Å, c ≈ 4.44 Å and standard fractional coordinates for Pnma SnSe.

Set ibrav = 8 for orthorhombic cell, or alternatively set ibrav = 0 and provide CELL_PARAMETERS explicitly consistent with the Pnma SnSe structure.

Set nat = 8 and ntyp = 2.

Set the energy cutoff for wavefunctions, ecutwfc, to 80 Ry, which is appropriate for PseudoDojo LDA standard pseudopotentials for Sn and Se at high accuracy.

Set ecutrho = 640 Ry (8 times ecutwfc) for the charge density cutoff.

Set the strict energy convergence requirement of 1 meV/atom, which for 8 atoms equals 8 meV = approximately 5.88e-4 Ry.

Set etot_conv_thr = 5.88e-4 Ry (i.e., 1 meV/atom × 8 atoms, converted: 1 meV = 7.3498e-5 Ry, so 8 meV ≈ 5.88e-4 Ry).

Set forc_conv_thr = 1.0e-4 Ry/Bohr to ensure well-converged forces consistent with the high-accuracy requirement.

Set conv_thr = 1.0e-10 Ry for the self-consistent field (SCF) electronic convergence, consistent with high-accuracy relaxation.

Use a gamma-centered Monkhorst-Pack k-point grid of 6×16×14 to sample the Brillouin zone of the orthorhombic Pnma cell, chosen to achieve approximately uniform k-point density consistent with 1 meV/atom accuracy.

Set K_POINTS automatic with grid 6 16 14 and shift 0 0 0 for gamma-centered sampling.

Set occupations = 'smearing', smearing = 'mv' (Marzari-Vanderbilt cold smearing), and degauss = 0.01 Ry, appropriate for a semiconductor/thermoelectric material at this accuracy level.

Set cell_dynamics = 'bfgs' and ion_dynamics = 'bfgs' in the CELL and IONS namelists respectively.

Set press_conv_thr = 0.1 kbar in the CELL namelist for cell pressure convergence.

Set nstep = 200 to allow sufficient ionic and cell relaxation steps.

Set restart_mode = 'from_scratch' in the CONTROL namelist.

Set tprnfor = .true. and tstress = .true. to print forces and stress tensor.

Set outdir and prefix appropriately for output file management.

After the calculation completes, extract and report the fully relaxed structure including the final lattice parameters (cell vectors), atomic species, and fractional or Cartesian atomic coordinates from the output file.
