Work inside the case directory: data/absorptionE1/Ir.

Use the following INCAR for all three geometry-optimization steps (Steps 1, 2, and 3). Do not change the INCAR between steps.

INCAR contents:
SYSTEM = relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 200
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
LWAVE = .FALSE.
LCHARG = .FALSE.

Use the same KPOINTS file (already present in the directory) for all three relaxation steps without modification.

Step 1: Write the INCAR file with the contents above, then run: python op.py CO POTCAR-CO POSCAR-CO

Step 2: Keep the same INCAR file unchanged, then run: python op.py surface POTCAR-Irface POSCAR-Irface

Step 3: Keep the same INCAR file unchanged, then run: python op.py absorbed POTCAR-IrCO POSCAR-IrCO

Step 4: After all three VASP calculations have completed successfully, run: bash ./calc_absorption_energy.sh

Capture and report the adsorption energy exactly as printed to stdout by calc_absorption_energy.sh.
