Write a Python function named `compute_srh_properties` that takes no required arguments.

The function must include a complete docstring describing its purpose, that it reads local VASP output files to build a HarmonicDefect and compute SRH recombination properties, and that it returns a dictionary with keys `SRH_Coefficient` and `RuntimeError_Check`.

Import the following at the top of the function or module: `from pathlib import Path`, `from pymatgen.analysis.defects.ccd import HarmonicDefect, get_SRH_coefficient`, `from pymatgen.io.vasp.outputs import Vasprun`, `from pymatgen.io.vasp.inputs import Procar`, `import numpy as np`.

Define `file_path` as a `Path` object pointing to the base directory containing the `v_Ga` subdirectory.

Assume the following directory structure under `file_path / "v_Ga"`:
- `ccd_0_-1/` contains the WSWQ files under `ccd_0_-1/wswqs/`
- `ccd_0_-1/` contains `vasprun.xml` and `PROCAR` for the neutral (charge 0) defect state at the defect geometry
- `ccd_-1_0/` contains `vasprun.xml` and `PROCAR` for the negative (charge -1) defect state at the defect geometry

Build the neutral `HarmonicDefect` (charge state 0) using `HarmonicDefect.from_vasp_outputs` by passing the `Vasprun` parsed from `file_path / "v_Ga" / "ccd_0_-1" / "vasprun.xml"` and the `Procar` parsed from `file_path / "v_Ga" / "ccd_0_-1" / "PROCAR"`. Set `store_bandstructure=True` when parsing the `Vasprun`.

Build the charged `HarmonicDefect` (charge state -1) using `HarmonicDefect.from_vasp_outputs` by passing the `Vasprun` parsed from `file_path / "v_Ga" / "ccd_-1_0" / "vasprun.xml"` and the `Procar` parsed from `file_path / "v_Ga" / "ccd_-1_0" / "PROCAR"`.

Read the WSWQ files into the neutral `HarmonicDefect` by calling its `read_wswqs` method with the path `file_path / "v_Ga" / "ccd_0_-1" / "wswqs"`.

Use a temperature array of `np.arange(100, 1100, 100)` (i.e., 100 K to 1000 K in steps of 100 K) as the temperature set for the SRH coefficient calculation.

Compute the SRH coefficient by calling `get_SRH_coefficient` with the neutral `HarmonicDefect` as the first argument, the charged `HarmonicDefect` as the second argument, and the temperature array as the third argument. Store the result.

Store the SRH coefficient result as a list of Python floats under the key `SRH_Coefficient` in the output dictionary.

For `RuntimeError_Check`, attempt to call `get_SRH_coefficient` with an intentionally invalid defect state configuration, specifically by passing the same `HarmonicDefect` object for both the first and second arguments (i.e., both set to the neutral defect), wrapped in a `try/except RuntimeError` block. If a `RuntimeError` is raised, set `RuntimeError_Check` to `True`. If no error is raised, set `RuntimeError_Check` to `False`.

Return the dictionary `{"SRH_Coefficient": <list of floats>, "RuntimeError_Check": <bool>}`.
