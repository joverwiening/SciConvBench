Work inside the case directory: data/absorptionE10/PtO2.

Use the following files as inputs without modifying them: POSCAR-CO, POSCAR-PtO2face, POSCAR-PtO2CO, POTCAR-CO, POTCAR-PtO2face, POTCAR-PtO2CO, KPOINTS, op.py, calc_absorption_energy.sh, run.sh.

Apply the following INCAR parameters consistently to all three geometry-optimization steps (Steps 1–3): EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISMEAR = 1, POTIM = 0.2, SIGMA = 0.2.

Set NSW = 200 for all three relaxation steps as a reasonable best-practice value to accommodate potentially non-ideal initial structures.

Do not use spin polarization (do not set ISPIN = 2; omit it or set ISPIN = 1).

Do not optimize the cell (do not set ISIF to a value that relaxes the cell; use ISIF = 2 or omit it).

Use ISTART = 0 and ICHARG = 2 for fresh starts in all three steps.

Set EDIFF = 1E-4 for the electronic convergence criterion in all three steps.

Set PREC = Normal in all three steps.

For Step 1 (CO molecule relaxation), use gamma-point-only k-point sampling (a 1x1x1 Monkhorst-Pack or Gamma-centered grid) because the molecule is in a box.

For Step 2 (clean surface relaxation) and Step 3 (adsorbed system relaxation), use the k-point sampling provided in the KPOINTS file.

Step 1: Write the INCAR file with the parameters above appropriate for the CO molecule, then run: python op.py CO POTCAR-CO POSCAR-CO

Step 2: Update the INCAR file if needed (same parameter set, surface-appropriate k-points already handled by KPOINTS), then run: python op.py surface POTCAR-PtO2face POSCAR-PtO2face

Step 3: Keep the same INCAR constraints, then run: python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO

Step 4: Run the adsorption energy script: bash ./calc_absorption_energy.sh

Return the adsorption energy exactly as printed by calc_absorption_energy.sh and nothing else.
