Use the wurtzite GaN structure with space group P6_3mc and 4 atoms per primitive cell.
Set the lattice constant a to 3.190 Angstroms.
Set the lattice constant c to 5.189 Angstroms, corresponding to a c/a ratio of 1.627.
Set the internal parameter u to 0.377.
Use the LDA pseudopotential files ga.upf and n.upf from the PseudoDojo/SR_v0.4.1/LDA_standard library.
Set the plane-wave energy cutoff for wavefunctions (ecutwfc) to 60 Rydberg.
Set the plane-wave energy cutoff for charge density (ecutrho) to 240 Rydberg.
Perform a variable-cell relaxation (vc-relax) calculation with a gamma-centered 6x6x4 k-point grid.
Set the total energy convergence threshold for the vc-relax to 1e-5 Ry/atom to meet the 1 meV/atom requirement.
Set the force convergence threshold for the vc-relax to 1e-4 Ry/Bohr.
Perform a self-consistent field (scf) calculation using the relaxed structure.
Use a gamma-centered 8x8x6 k-point grid for the scf calculation.
Set the total energy convergence threshold for the scf calculation to 1e-6 Ry.
Perform a non-self-consistent field (nscf) calculation for band structure and DOS.
Use a gamma-centered 12x12x8 k-point grid for the nscf calculation.
Run a bands calculation (pw.x with calculation="bands") using the path for the wurtzite Brillouin zone.
Perform band post-processing to obtain the band structure data.
Perform DOS post-processing to obtain the density of states.
