Use the LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard.
Set the plane-wave energy cutoff (ecutwfc) to 60 Ry.
Use an automatic Monkhorst-Pack k-point grid with a half shift and a spacing of 0.04 1/Å.
Construct a starting structure for Bi2Te3 with the R-3m space group and 5 atoms per primitive cell.
Perform a variable-cell relaxation (vc-relax) using this starting structure.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-8.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7.
After the vc-relax finishes, run a self-consistent field calculation on the relaxed structure.
Set the self-consistent field convergence threshold (conv_thr) to 1.0e-8.
Return the fully relaxed structure and the final total energy.
