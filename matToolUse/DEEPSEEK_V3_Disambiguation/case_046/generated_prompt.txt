Use the LDA pseudopotential files fe.upf and o.upf from the PseudoDojo/SR_v0.4.1/LDA_standard directory.
Construct a starting structure for Fe3O4 with the ferrimagnetic Fd-3m space group and 7 atoms per primitive cell.
Set the lattice constant for the cubic cell to 8.396 Angstroms.
Place Fe atoms at the 8a Wyckoff position (0.125, 0.125, 0.125).
Place Fe atoms at the 16d Wyckoff position (0.5, 0.5, 0.5).
Place O atoms at the 32e Wyckoff position (0.2548, 0.2548, 0.2548).
Assign starting magnetizations: set the initial magnetic moment for Fe at the 8a site to -4.0 Bohr magnetons.
Assign starting magnetizations: set the initial magnetic moment for Fe at the 16d site to +4.0 Bohr magnetons.
Perform a variable-cell relaxation (vc-relax) calculation.
Use an energy cutoff for wavefunctions (ecutwfc) of 60 Rydberg.
Set the total energy convergence threshold (etot_conv_thr) for the relaxation to 1.0e-6 Rydberg.
Set the force convergence threshold (forc_conv_thr) for the relaxation to 1.0e-4 Rydberg/Bohr.
Use a 4x4x4 gamma-centered k-point grid for the relaxation.
Use a Gaussian smearing scheme for electronic occupations.
Set the smearing parameter (degauss) to 0.02 Rydberg.
After relaxation, perform a self-consistent field (scf) calculation on the relaxed structure.
Set the convergence threshold (conv_thr) for the scf calculation to 1.0e-8 Rydberg.
Use a 6x6x6 gamma-centered k-point grid for the scf calculation.
Use the same smearing and degauss parameters as the relaxation.
After the scf, perform a non-self-consistent field (nscf) calculation for band structure.
Set the convergence threshold (conv_thr) for the nscf calculation to 1.0e-8 Rydberg.
Use a 12x12x12 gamma-centered k-point grid for the nscf calculation.
Use the same smearing and degauss parameters as the scf.
After the nscf, run a bands calculation (pw.x with calculation="bands") along a high-symmetry path.
Use the same k-point path for the bands calculation as is standard for a cubic Fd-3m structure.
Perform band post-processing using the bands.x tool.
Perform DOS post-processing using the dos.x tool.
Ensure the total energy is converged to within 1 meV per atom across all steps.
