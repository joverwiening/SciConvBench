Perform a variable-cell relaxation (vc-relax) calculation for CoSb3 in the skutterudite structure (space group Im-3, 8 atoms per primitive cell).
Use the LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard: co.upf and sb.upf.
Construct a starting structure consistent with the skutterudite type for the formula CoSb3.
Set the plane-wave energy cutoff (ecutwfc) to 60 Ry.
Use an automatic Monkhorst-Pack k-point grid with a half shift; choose a grid spacing of approximately 0.04 Å⁻¹.
Set the SCF convergence threshold (conv_thr) to 1.0e-8 Ry.
Set the total energy convergence threshold for ionic steps (etot_conv_thr) to 1.0e-8 Ry.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7 Ry.
Set the pressure convergence threshold (press_conv_thr) to 0.5 kbar.
After the vc-relax finishes, run a self-consistent field calculation on the final relaxed structure using the same ecutwfc and k-point grid.
Return the fully relaxed structure and the final total energy from the SCF calculation.
