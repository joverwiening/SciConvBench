Write an INCAR file for the ground-state calculation with the following parameters.
Set PREC=Normal.
Set ENCUT=450.
Set NELM=500.
Set IBRION=-1.
Set ISPIN=1.
Set NSW=0.
Set ISIF=2.
Set EDIFF=1E-5.
Set EDIFFG=-5E-3.
Set ISMEAR=0.
Set SIGMA=0.05.
Set LWAVE=.TRUE.
Set LCHARG=.TRUE.
Set LREAL=Auto.
Set LPLANE=.TRUE.
Set NPAR=1.
Set KPAR=4.
Set NCORE=1.
Set LORBIT=11.
Set ALGO=Normal.
Set ICHARG=2.
Run VASP using the command 'bash run_vasp.sh'.
Save a copy of the INCAR used for Step 1 as 'INCAR1'.
Create a new INCAR file for the hybrid-functional calculation using the provided parameter block.
Run VASP again using the command 'bash run_vasp.sh'.
Save a copy of the INCAR used for Step 2 as 'INCAR2'.
Run the post-processing script using the command 'python gap.py'.
Return the band-gap value exactly as printed by 'gap.py'.
