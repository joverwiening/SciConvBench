The function shall be named `compute_defect_properties`.
The function shall take no required input arguments.
The function shall import necessary modules: `os`, `json`, `pymatgen.analysis.defects.thermodynamics`, `pymatgen.entries.computed_entries`, and `pymatgen.core`.
The function shall define a variable `file_path` as the base directory for input files.
The function shall construct the full path to the structure file as `os.path.join(file_path, "GaN.vasp")`.
The function shall load the structure from the VASP file using `pymatgen.core.Structure.from_file`.
The function shall construct the full path to the stable entries file as `os.path.join(file_path, "stable_entries_Mg_Ga_N.json")`.
The function shall load the stable entries from the JSON file.
The function shall create a `DefectEntry` for each relevant defect from the loaded data.
The function shall create a `DefectPhaseDiagram` object using the defect entries, the bulk structure, and the stable entries.
The function shall extract the formation energy diagram from the `DefectPhaseDiagram`.
The function shall calculate `chempot_limits_count` as the number of chemical potential limits in the diagram.
The function shall calculate `defect_chemsys` as the chemical system of the defects, formatted as a hyphen-separated string of element symbols.
The function shall calculate `bulk_formula` as the chemical formula of the bulk material.
The function shall return a dictionary with keys `'chempot_limits_count'`, `'defect_chemsys'`, and `'bulk_formula'` mapping to their calculated values.
The function shall include a complete docstring describing its purpose, parameters, and return value.
