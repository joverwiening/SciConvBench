Perform a variable-cell relaxation (vc-relax) calculation for NbSe2.
Use the LDA pseudopotential files nb.upf and se.upf.
Start from a structure with formula NbSe2, layered geometry, space group P6_3/mmc, and 3 atoms per primitive cell.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-8.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7.
Set the self-consistent field convergence threshold (conv_thr) to 1.0e-8.
Use an automatic Monkhorst-Pack grid with a half shift and a k-point spacing of 0.04 1/Å.
Set the plane-wave energy cutoff (ecutwfc) to 60 Ry.
After the vc-relax finishes, run a self-consistent field calculation on the relaxed structure with the same settings.
Return the fully relaxed structure and the final total energy.
