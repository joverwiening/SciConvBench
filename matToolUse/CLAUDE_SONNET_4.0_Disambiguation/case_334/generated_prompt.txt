Create INCAR file for CO molecule optimization with EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISMEAR = 1, POTIM = 0.2, SIGMA = 0.2, and NSW = 100.
Run python op.py CO POTCAR-CO POSCAR-CO to optimize the CO molecule using Gamma-point only k-point sampling.
Update INCAR file for surface optimization keeping the same parameter constraints.
Run python op.py surface POTCAR-Irface POSCAR-Irface to optimize the clean Ir surface using the provided KPOINTS file.
Update INCAR file for adsorbed system optimization keeping the same parameter constraints.
Run python op.py absorbed POTCAR-IrCO POSCAR-IrCO to optimize the CO-adsorbed Ir system using the provided KPOINTS file.
Run bash ./calc_absorption_energy.sh to compute and output the adsorption energy from the three total energies.
Return the adsorption energy exactly as printed by the calc_absorption_energy.sh script.
