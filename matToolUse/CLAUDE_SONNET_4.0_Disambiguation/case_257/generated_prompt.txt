Perform a variable-cell relaxation followed by an SCF calculation on NbSe2 using Quantum ESPRESSO.
Use the hexagonal P6_3/mmc space group structure with 3 atoms per primitive cell.
Set initial lattice parameters to a = b = 3.44 Å, c = 12.54 Å, with angles α = β = 90°, γ = 120°.
Place Nb atom at fractional coordinates (0, 0, 0).
Place Se atoms at fractional coordinates (1/3, 2/3, 0.25) and (2/3, 1/3, 0.75).
Use LDA pseudopotentials nb.upf and se.upf from PseudoDojo/SR_v0.4.1/LDA_standard.
Set ecutwfc = 60 Ry for the plane-wave cutoff energy.
Use a 12x12x4 Monkhorst-Pack k-point grid with automatic generation and half shift.
Set etot_conv_thr = 1.0e-8 for total energy convergence.
Set forc_conv_thr = 1.0e-7 for force convergence.
Set conv_thr = 1.0e-8 for SCF convergence threshold.
First run calculation = 'vc-relax' to optimize both atomic positions and cell parameters.
After vc-relax completes, run calculation = 'scf' on the relaxed structure with identical computational parameters.
Return the final relaxed atomic structure and total energy from the SCF calculation.
