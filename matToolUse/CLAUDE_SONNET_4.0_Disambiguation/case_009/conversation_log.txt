Q: What is the exact file structure and naming convention for the defect entries in the `Mg_Ga` defect-entry directory?
A: Based on the complete requirement, the `Mg_Ga` defect-entry directory contains subfolders for each charge state, and each subfolder contains `vasprun.xml.gz` and `LOCPOT.gz` files. The charge states are `[-2, -1, 0, 1]`, and there's also a `bulk_sc/LOCPOT.gz` file as the bulk reference.

The structure should be:
```
Mg_Ga/
├── charge_-2/
│   ├── vasprun.xml.gz
│   └── LOCPOT.gz
├── charge_-1/
│   ├── vasprun.xml.gz
│   └── LOCPOT.gz
├── charge_0/
│   ├── vasprun.xml.gz
│   └── LOCPOT.gz
├── charge_1/
│   ├── vasprun.xml.gz
│   └── LOCPOT.gz
└── bulk_sc/
    └── LOCPOT.gz
```
