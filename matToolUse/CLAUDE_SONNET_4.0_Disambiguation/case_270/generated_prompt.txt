Create the VASP input file INCAR for structure optimization using the specified parameter block.
Write the following lines into INCAR file: ALGO = Fast, EDIFF = 0.0002, ENCUT = 520.0, IBRION = 2, ISMEAR = -5, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Run VASP using the command: bash run_vasp.sh.
The run_vasp.sh script executes vasp_std with MPI.
Preserve a copy of the INCAR file as INCAR1 using the command: cp INCAR INCAR1.
Extract the optimized total energy using the command: python get_energy.py.
The get_energy.py script reads vasprun.xml and prints the optimized total energy after relaxation.
Return the optimized total energy exactly as printed by get_energy.py.
The input files POSCAR, KPOINTS, and POTCAR are already available in the current directory.
The goal is to perform VASP structural relaxation of AlN and report the final optimized total energy.
