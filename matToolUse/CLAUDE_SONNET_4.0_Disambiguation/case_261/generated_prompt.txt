Perform a variable-cell relaxation followed by an SCF calculation on CoSb3 skutterudite structure.
Use the Im-3 space group with 8 atoms per primitive cell as specified in the metadata.
Set the initial cubic lattice parameter to 9.04 Angstroms based on experimental CoSb3 values.
Use LDA pseudopotentials co.upf and sb.upf from PseudoDojo/SR_v0.4.1/LDA_standard.
Set ecutwfc to 60 Ry for adequate convergence with these pseudopotentials.
Use a 6x6x6 Monkhorst-Pack k-point grid with half shift for good sampling of the Brillouin zone.
Set etot_conv_thr = 1.0e-8 for total energy convergence.
Set forc_conv_thr = 1.0e-7 for force convergence.
Set conv_thr = 1.0e-8 for SCF convergence.
First run the variable-cell relaxation calculation to optimize both atomic positions and cell parameters.
After vc-relax completes, run an SCF calculation on the relaxed structure using identical computational parameters.
Return the fully relaxed crystal structure and the final total energy from the SCF calculation.
