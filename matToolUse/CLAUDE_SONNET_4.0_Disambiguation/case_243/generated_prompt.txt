Perform a variable-cell relaxation (vc-relax) on wurtzite ZnO using Quantum ESPRESSO.
Use the LDA pseudopotential files PseudoDojo/SR_v0.4.1/LDA_standard/zn.upf and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf.
Set the initial wurtzite structure with lattice parameters a = 3.25 Å and c = 5.21 Å in space group P6_3mc with 4 atoms per primitive cell.
Place Zn atoms at fractional coordinates (1/3, 2/3, 0) and (2/3, 1/3, 1/2).
Place O atoms at fractional coordinates (1/3, 2/3, u) and (2/3, 1/3, 1/2+u) where u = 0.38.
Use ecutwfc = 80 Ry for the plane-wave cutoff energy.
Use a 8x8x6 Monkhorst-Pack k-point grid with automatic generation and half shift.
Set etot_conv_thr = 1.0e-8 for energy convergence.
Set forc_conv_thr = 1.0e-7 for force convergence.
Set conv_thr = 1.0e-8 for SCF convergence.
Allow all cell parameters and atomic positions to relax during vc-relax.
After vc-relax completes, perform a single-point SCF calculation on the relaxed structure using identical computational parameters.
Return the final relaxed crystal structure with optimized lattice parameters and atomic positions.
Return the final total energy from the SCF calculation on the relaxed structure.
