Compute the electronic band gap of AlN using VASP with a three-step hybrid-functional workflow.
Use the provided files POSCAR, KPOINTS, and POTCAR as inputs.
Step 1: Create an INCAR file for PBE ground-state calculation using reasonable DFT parameters including PREC=Normal, ENCUT=450, appropriate convergence criteria, and PBE exchange-correlation functional.
Run VASP using the command "bash run_vasp.sh".
Save the ground-state INCAR as INCAR1 using "cp INCAR INCAR1".
Step 2: Create a new INCAR file for hybrid-functional calculation using the specified parameter block with LHFCALC=.TRUE. and TIME=0.4.
Set ICHARG to a value not larger than 10 since starting from existing WAVECAR.
Do not specify magnetic moments, NBAND, or NELECT parameters.
Run VASP again using "bash run_vasp.sh".
Save the hybrid-functional INCAR as INCAR2 using "cp INCAR INCAR2".
Step 3: Extract the band gap by running "python gap.py".
Return the exact band gap value as printed by gap.py.
