Create the VASP input file INCAR for structure optimization using the specified parameter block.
Write the INCAR file with the following parameters: ALGO = Fast, EDIFF = 5e-05, ENCUT = 520.0, IBRION = 2, ISMEAR = -5, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Run VASP using the command: bash run_vasp.sh.
The run_vasp.sh script uses the vasp_std executable with MPI.
Copy the INCAR file to INCAR1 using the command: cp INCAR INCAR1.
Extract the optimized total energy using the command: python get_energy.py.
Return the optimized total energy exactly as printed by get_energy.py.
The input files POSCAR, KPOINTS, and POTCAR are already provided in the current directory.
The goal is to perform structural relaxation of Al and obtain the final optimized total energy.
