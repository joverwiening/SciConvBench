Execute the following VASP workflow to compute the electronic band gap of ZnS:

Step 1 — PBE ground state
Create a file named `INCAR` with the following content:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Run VASP with the command:
bash run_vasp.sh

Save the INCAR for Step 1:
cp INCAR INCAR1

Step 2 — HSE calculation
Create a new file named `INCAR` with the following content:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Run VASP with the command:
bash run_vasp.sh

Save the INCAR for Step 2:
cp INCAR INCAR2

Step 3 — Band gap extraction
Run the post-processing script:
python gap.py

Return the band gap value exactly as printed by `gap.py`.
