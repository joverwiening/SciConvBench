Perform a variable-cell relaxation (vc-relax) calculation on wurtzite GaN using LDA pseudopotentials.

Retrieve a primitive starting structure for wurtzite GaN (space group P6_3mc, 4 atoms per primitive cell) using a structure-retrieval tool.

Set the smearing method to cold smearing with a degauss value of 0.01 Ry.

Set occupations to smearing.

Do not use Hubbard U corrections.

Do not include spin-orbit coupling.

Start from the retrieved primitive wurtzite structure with initial lattice parameters approximately a=3.189 Angstrom and c=5.185 Angstrom.

Relax both the atomic positions and the cell parameters (a and c axes) simultaneously.
