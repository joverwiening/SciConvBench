The task is to perform a VASP structural relaxation for MgO and report the optimized total energy. The specification is complete with all necessary details provided.

Create the INCAR file with the following content:
ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05

Run VASP using the provided launcher script:
bash run_vasp.sh

Preserve a copy of the INCAR file as INCAR1:
cp INCAR INCAR1

Extract the optimized total energy using the provided post-processing script:
python get_energy.py

Return the optimized total energy exactly as printed by get_energy.py.
