Step 1 — Optimize CO

Write the following INCAR file:

```
SYSTEM = CO molecule relaxation
ENCUT = 450
EDIFF = 1E-6
EDIFFG = -0.05
IBRION = 1
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
POTIM = 0.2
NSW = 100
```

Run:
```
python op.py CO POTCAR-CO POSCAR-CO
```
