Create an INCAR file for Step 1 (PBE ground-state calculation) with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Run VASP for Step 1 by executing: bash run_vasp.sh

Save a copy of the INCAR used for Step 1 as INCAR1 by executing: cp INCAR INCAR1

Run the post-processing script to extract the band gap by executing: python gap.py

Return the band-gap value exactly as printed by gap.py.
