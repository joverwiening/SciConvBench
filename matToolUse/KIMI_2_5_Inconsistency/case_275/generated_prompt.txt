The task is to perform a VASP structural relaxation for Bi2Te3 and report the optimized total energy. The specification is complete and actionable:

Create the INCAR file with the exact parameters provided in the task description, including ALGO = Fast, EDIFF = 0.00025, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 6, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 19*0.0, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.

Run VASP using the command: bash run_vasp.sh

Preserve the INCAR file by copying it to INCAR1 using: cp INCAR INCAR1

Extract the optimized total energy using: python get_energy.py

Return the optimized total energy value exactly as printed by get_energy.py.
