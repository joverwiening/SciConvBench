Step 1 — Optimize CO:
Write INCAR with the following content:
ISPIN = 1
ISIF = 2
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISMEAR = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 100
Run: python op.py CO POTCAR-CO POSCAR-CO

Step 2 — Optimize the clean surface:
Use the same INCAR as Step 1.
Run: python op.py surface POTCAR-PdO2face POSCAR-PdO2face

Step 3 — Optimize the adsorbed system:
Use the same INCAR as Step 1.
Run: python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO

Step 4 — Compute adsorption energy:
Run: bash ./calc_absorption_energy.sh

Output requirement: Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
