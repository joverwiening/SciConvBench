Step 1 — Relax/optimize the Initial State (IS)

Write the following INCAR file for the IS relaxation:

SYSTEM = IS Relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
IBRION = 1
ISIF = 2
NSW = 200
EDIFFG = -0.05
POTIM = 0.2
NPAR = 1

Run:
python op.py IS POTCARagpd IS1POSCAR

Step 2 — Relax/optimize the Final State (FS)

Write the following INCAR file for the FS relaxation:

SYSTEM = FS Relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
IBRION = 1
ISIF = 2
NSW = 200
EDIFFG = -0.05
POTIM = 0.2
NPAR = 1

Run:
python op.py FS POTCARagpd FS1POSCAR

Step 3 — Interpolate intermediate images (ASE)

No INCAR needed. Run:
python nebmake.py

Step 4 — Run the NEB calculation

Write the following INCAR file for the NEB calculation:

SYSTEM = NEB Calculation
ISTART = 0
ICHARG = 2
ENCUT = 450
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
IBRION = 3
ISIF = 2
IMAGES = 4
LCLIMB = .TRUE.
IOPT = 7
SPRING = -5
NSW = 500
EDIFFG = -0.05
POTIM = 0
NPAR = 1

Run:
python op2.py ./

Step 5 — Extract energies and determine the barrier

No INCAR needed. Run:
bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'

Output requirement: Return the reaction-barrier value produced by the extraction step.
