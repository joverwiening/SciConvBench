The task is to calculate the electronic band gap of InP using VASP with a two-step workflow: PBE ground state followed by HSE calculation.

Step 1 — PBE ground state:
Create an INCAR file with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Run VASP using the provided script:
bash run_vasp.sh

Save the INCAR for reference:
cp INCAR INCAR1

Step 2 — HSE calculation:
Create a new INCAR file with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Run VASP again:
bash run_vasp.sh

Save the INCAR for reference:
cp INCAR INCAR2

Step 3 — Band gap extraction:
Run the post-processing script to obtain the band gap value:
python gap.py

The final output is the band gap value printed by gap.py.
