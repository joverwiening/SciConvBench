Step 1 — Optimize CO:
Write INCAR with the following content:
ISPIN = 1
ENCUT = 450
EDIFFG = -0.05
IBRION = 1
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
POTIM = 0.2
NSW = 100

Run: python op.py CO POTCAR-CO POSCAR-CO

Step 2 — Optimize the clean surface:
Use the same INCAR as Step 1.
Run: python op.py surface POTCAR-Irface POSCAR-Irface

Step 3 — Optimize the adsorbed system:
Use the same INCAR as Step 1.
Run: python op.py absorbed POTCAR-IrCO POSCAR-IrCO

Step 4 — Compute adsorption energy:
Run: bash ./calc_absorption_energy.sh

Return the adsorption energy value exactly as printed by calc_absorption_energy.sh.
