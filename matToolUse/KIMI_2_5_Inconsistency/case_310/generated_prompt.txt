Create an INCAR file for Step 1 (PBE ground-state calculation) with the following parameters:
PREC=Normal
ENCUT=450
ISMEAR=0
SIGMA=0.05
ISPIN=1
ISTART=0
ICHARG=2
LWAVE=.T.
LCHARG=.T.
NELM=100
EDIFF=1E-5
IBRION=-1
NSW=0
ISIF=2
EDIFFG=-5E-3
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Run VASP using the command: bash run_vasp.sh

Save a copy of the INCAR as INCAR1 using: cp INCAR INCAR1

Run VASP again using: bash run_vasp.sh

Save a copy of the INCAR as INCAR2 using: cp INCAR INCAR2

Run the post-processing script: python gap.py
