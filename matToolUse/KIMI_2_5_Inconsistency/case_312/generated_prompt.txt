The task is to compute the electronic band gap of BN using VASP with a two-step workflow: PBE ground state followed by HSE calculation, then extract the band gap using gap.py.

Step 1 — PBE ground state:
Create an INCAR file with the following parameters for a standard PBE ground-state calculation:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
Run VASP using `bash run_vasp.sh`.
Save a copy of the INCAR as `INCAR1` using `cp INCAR INCAR1`.

Step 2 — HSE calculation:
Create a new INCAR file with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast
Run VASP again using `bash run_vasp.sh`.
Save a copy of the INCAR as `INCAR2` using `cp INCAR INCAR2`.

Step 3 — Band gap extraction:
Run the post-processing script using `python gap.py`.

Output requirement:
Return the band-gap value exactly as printed by gap.py.
