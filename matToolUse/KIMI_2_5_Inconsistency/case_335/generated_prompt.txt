Step 1 — Optimize CO

Write INCAR with the following parameters:
ISPIN = 1
ENCUT = 450
EDIFFG = -0.05
IBRION = 1
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
POTIM = 0.2
NSW = 100

Run:
python op.py CO POTCAR-CO POSCAR-CO

Step 2 — Optimize the clean surface

Use the same INCAR as Step 1.

Run:
python op.py surface POTCAR-PtO2face POSCAR-PtO2face

Step 3 — Optimize the adsorbed system

Use the same INCAR as Step 1.

Run:
python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO

Step 4 — Compute adsorption energy

Run:
bash ./calc_absorption_energy.sh

Return the adsorption energy value exactly as printed by the script.
