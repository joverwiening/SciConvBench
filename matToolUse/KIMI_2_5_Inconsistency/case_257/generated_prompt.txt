Perform a variable-cell relaxation (vc-relax) calculation on NbSe2 using LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard/nb.upf and PseudoDojo/SR_v0.4.1/LDA_standard/se.upf.

Set etot_conv_thr to 1.0e-8, forc_conv_thr to 1.0e-7, and conv_thr to 1.0e-8.

Set the target pressure for the variable-cell relaxation to 0 kbar (ambient pressure).

Use an automatic Monkhorst-Pack k-point grid with a half shift.

Set the plane-wave kinetic energy cutoff (ecutwfc) to 60 Ry.

Set the k-point density to correspond to a minimum k-point spacing of approximately 0.2 Å⁻¹, which for NbSe2 translates to a Monkhorst-Pack grid of 12x12x4.

Retrieve a primitive starting structure for NbSe2 consistent with the metadata: formula=NbSe2, structure=layered, space_group=P6_3/mmc, atoms_per_primitive_cell=3. Use this retrieved structure as the starting configuration for the vc-relax calculation.

Run the vc-relax calculation to obtain the fully relaxed cell parameters and atomic positions.

After vc-relax completes, run a self-consistent field (SCF) total-energy calculation on the relaxed structure using consistent settings: same pseudopotentials, same ecutwfc, same k-point grid, and conv_thr = 1.0e-8.

For the final SCF calculation, use the original starting structure (before relaxation) rather than the vc-relaxed structure, so that the total energy is referenced to the same cell.

Return the fully relaxed structure from the vc-relax calculation and the final total energy from the SCF calculation.
