The task is fully specified with all necessary details to execute the VASP structural relaxation for AlN. The INCAR parameters are explicitly provided, the input files (POSCAR, KPOINTS, POTCAR) are available in the working directory, and the execution steps are clearly defined. The goal is to perform an ion-only, non-spin-polarized relaxation with fixed cell, extract the optimized total energy, and preserve the INCAR as INCAR1.

Specification:
Create an INCAR file with the exact parameter block provided in the task description.
Run VASP using the command bash run_vasp.sh.
Copy the INCAR file to INCAR1 using the command cp INCAR INCAR1.
Extract the optimized total energy by running python get_energy.py.
Return the optimized total energy value exactly as printed by get_energy.py.
