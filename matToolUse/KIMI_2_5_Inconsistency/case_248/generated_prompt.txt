Perform a variable-cell relaxation (vc-relax) calculation on wurtzite GaN using LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard/ga.upf and PseudoDojo/SR_v0.4.1/LDA_standard/n.upf.

Retrieve a primitive starting structure for wurtzite GaN (space group P6_3mc, 4 atoms per primitive cell) using the available structure-retrieval tool.

Set ecutwfc = 55 Ry for the plane-wave basis set cutoff.

Set ecutrho = 220 Ry for the charge density cutoff (4 × ecutwfc).

Use an automatic Monkhorst-Pack k-point grid of 6x6x4 with a half shift, keeping the grid gamma-centered.

Set etot_conv_thr = 1.0e-8 for the total energy convergence threshold.

Set forc_conv_thr = 1.0e-7 for the force convergence threshold.

Set conv_thr = 1.0e-8 for the SCF convergence threshold.

After the vc-relax calculation completes, perform a self-consistent field (SCF) calculation on the relaxed structure using the same computational settings (pseudopotentials, ecutwfc, ecutrho, k-point grid, and conv_thr).

Return the fully relaxed structure (final atomic positions and cell parameters) and the final total energy from the SCF calculation.
