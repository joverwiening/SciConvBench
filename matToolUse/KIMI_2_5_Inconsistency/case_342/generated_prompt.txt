Step 1 — Optimize CO:
Write an INCAR file with the following parameters:

ENCUT = 450
EDIFFG = -0.05
IBRION = 1
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
POTIM = 0.2

Run the command: python op.py CO POTCAR-CO POSCAR-CO

Step 2 — Optimize the clean surface:
Use the same INCAR parameters as Step 1.
Run the command: python op.py surface POTCAR-Ptface POSCAR-Ptface

Step 3 — Optimize the adsorbed system:
Use the same INCAR parameters as Step 1.
Run the command: python op.py absorbed POTCAR-PtCO POSCAR-PtCO

Step 4 — Compute adsorption energy:
Run the command: bash ./calc_absorption_energy.sh
