Q: I need to create an INCAR file for the PBE ground-state calculation (Step 1). Since no explicit INCAR parameters are provided for Step 1 in data.json, I need to determine what parameters to use.

What PBE-specific INCAR parameters should I use for the ground-state calculation, particularly for the exchange-correlation functional (e.g., GGA=PE or similar)?
A: For the PBE ground-state calculation (Step 1), use the following INCAR parameters:

```
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
```

Note: VASP uses PBE by default when no hybrid functional parameters are specified, so you don't need to explicitly set GGA=PE. The key difference from Step 2 is that Step 1 should NOT include any HSE-related parameters (LHFCALC, HSE06, HFSCREEN, AEXX, AGGAX, etc.).
