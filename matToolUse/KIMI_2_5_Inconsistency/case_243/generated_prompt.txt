The task is to perform a variable-cell relaxation (vc-relax) followed by a self-consistent field calculation on ZnO using LDA pseudopotentials, then return to the original starting structure for the final SCF energy reference.

Use the LDA pseudopotentials PseudoDojo/SR_v0.4.1/LDA_standard/zn.upf and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf.

Set etot_conv_thr = 1.0e-8, forc_conv_thr = 1.0e-7, and conv_thr = 1.0e-8.

Use an automatic Monkhorst-Pack k-point grid with a half shift and a k-point spacing of 0.15 Å⁻¹.

Set ecutwfc = 60 Ry.

Retrieve a primitive wurtzite ZnO structure consistent with the metadata (formula=ZnO, structure=wurtzite, space_group=P6_3mc, atoms_per_primitive_cell=4) using the structure-retrieval tool as the starting configuration.

Perform the vc-relax calculation first.

After vc-relax completes, run a final SCF calculation on the original unrelaxed starting structure using the same computational settings (pseudopotentials, ecutwfc, k-points, conv_thr, etc.) to obtain the total energy referenced to the same cell.

Return the fully relaxed structure from the vc-relax step and the final total energy from the SCF step on the original structure.
