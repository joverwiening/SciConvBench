Work inside the directory data/bandgap/ZnS.

Step 1: Create the INCAR file for the PBE ground-state calculation.
Write the following content to INCAR, derived from the Step 2 parameter block with all HSE-specific tags removed:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=Normal

Step 2: Run VASP for the PBE ground-state step.
Execute: bash run_vasp.sh

Step 3: Save a copy of the PBE INCAR.
Execute: cp INCAR INCAR1

Step 4: Create a new INCAR file for the HSE calculation.
Write the following content to INCAR exactly as specified, with ISTART set to 1 to read the existing WAVECAR and ICHARG set to 0 (which is less than 10, satisfying the charge-density recalculation requirement), and without any magnetic moment tags, NBAND, or NELECT:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Step 5: Run VASP for the HSE step.
Execute: bash run_vasp.sh

Step 6: Save a copy of the HSE INCAR.
Execute: cp INCAR INCAR2

Step 7: Extract and report the band gap.
Execute: python gap.py
Read the value printed to stdout by gap.py and return it exactly as printed, without modification.
