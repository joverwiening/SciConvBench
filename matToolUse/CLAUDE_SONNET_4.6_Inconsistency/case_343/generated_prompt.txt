The working directory is `data/absorptionE9/Pd`.

Use the following INCAR for Step 1 (CO molecule optimization):
Write a file named `INCAR` with these parameters: SYSTEM = CO molecule relaxation, ISTART = 0, ICHARG = 2, ENCUT = 450, EDIFF = 1E-5, EDIFFG = -0.05, NSW = 200, IBRION = 1, POTIM = 0.2, ISIF = 2, ISMEAR = 1, SIGMA = 0.2, ISPIN = 1, LWAVE = .FALSE., LCHARG = .FALSE.

Run Step 1 by executing: python op.py CO POTCAR-CO POSCAR-CO

Use the same INCAR (no changes needed) for Step 2 (clean Pd surface optimization).
Run Step 2 by executing: python op.py surface POTCAR-Pdface POSCAR-Pdface

Use the same INCAR (no changes needed) for Step 3 (CO-adsorbed Pd system optimization).
Run Step 3 by executing: python op.py absorbed POTCAR-PdCO POSCAR-PdCO

Run Step 4 by executing: bash ./calc_absorption_energy.sh

Capture and report the adsorption energy value exactly as printed to stdout by `calc_absorption_energy.sh`.

NSW = 200 is chosen as the reasonable default based on standard VASP best practices for surface and molecular relaxations where initial structures may not be ideal.
ISPIN = 1 is applied uniformly to all three relaxation steps (no spin polarization).
ISIF = 2 is applied to all three steps (no cell shape or volume optimization).
EDIFFG = -0.05 eV/Å is the force convergence criterion for all three steps.
ENCUT = 450 eV is used consistently across all three steps.
IBRION = 1 (quasi-Newton RMM-DIIS) with POTIM = 0.2 is used for all ionic relaxations.
ISMEAR = 1 with SIGMA = 0.2 is used consistently across all three steps.
