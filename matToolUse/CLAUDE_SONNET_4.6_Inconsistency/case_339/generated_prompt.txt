Work inside the case directory: data/absorptionE5/RhO2.

Use the files already present in that directory as inputs; do not recreate or paste their contents.

Step 1 — Write the INCAR for CO geometry optimization, then run the CO relaxation.

Write an INCAR file with the following parameters:
SYSTEM = CO relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 200
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1

Run the command: python op.py CO POTCAR-CO POSCAR-CO

Step 2 — Update the INCAR for the clean RhO2 surface relaxation, then run it.

Overwrite the INCAR file with the same parameters as Step 1 (all values identical, including ISPIN = 1, ISIF = 2, NSW = 200).

Run the command: python op.py surface POTCAR-RhO2face POSCAR-RhO2face

Step 3 — Update the INCAR for the CO-adsorbed RhO2 system relaxation, then run it.

Overwrite the INCAR file with the same parameters as Steps 1 and 2 (all values identical, including ISPIN = 1, ISIF = 2, NSW = 200).

Run the command: python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO

Step 4 — Compute the adsorption energy.

Run the command: bash ./calc_absorption_energy.sh

Capture and return the adsorption energy exactly as printed to stdout by calc_absorption_energy.sh, with no modification or reformatting.
