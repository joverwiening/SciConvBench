The function must have a complete docstring describing that it reads VASP output files from two CCD directories under `v_Ga/`, computes localized band indices for two defect configurations using PROCAR localization ratios, and returns a dictionary with keys `localized_bands_set_1` and `localized_bands_set_2` whose values are sets of integer band indices.

Define a variable `file_path` as the base directory string pointing to where the local input files reside. All file paths must be constructed relative to `file_path` using `os.path.join`.

Load three `vasprun.xml` files from `v_Ga/ccd_0_-1/0/vasprun.xml`, `v_Ga/ccd_0_-1/1/vasprun.xml`, and `v_Ga/ccd_0_-1/2/vasprun.xml` using `Vasprun` with `parse_dos=False` and `parse_eigen=True`.

Load three `vasprun.xml` files from `v_Ga/ccd_-1_0/0/vasprun.xml`, `v_Ga/ccd_-1_0/1/vasprun.xml`, and `v_Ga/ccd_-1_0/2/vasprun.xml` using `Vasprun` with `parse_dos=False` and `parse_eigen=True`.

Load the PROCAR for the first configuration set from `v_Ga/ccd_-1_0/1/PROCAR` using `Procar`.

Load the PROCAR for the second configuration set from `v_Ga/ccd_0_-1/1/PROCAR` using `Procar`.

Define a helper function `find_localized_bands` that accepts a `Procar` object, a `Vasprun` object, a localization threshold (default 0.5), and an optional band window as a tuple of two integers `(band_min, band_max)` or `None`.

Inside `find_localized_bands`, retrieve the number of bands and number of k-points from the Vasprun bandstructure object.

Inside `find_localized_bands`, access the `data` attribute of the `Procar` object, which is a dict keyed by `Spin`. Use `Spin.up` as the primary spin channel; if `Spin.up` is not present, fall back to the first available spin.

Inside `find_localized_bands`, for each band index in the specified band window (or all bands if no window is given), compute the localization ratio for that band by summing the orbital projections over all ions for each k-point, then computing the ratio of the maximum single-ion contribution to the total contribution, averaged across all k-points. Specifically, for each k-point, sum projections over all orbitals per ion to get per-ion weights, compute the fraction of the largest single-ion weight to the total weight for that k-point, then average this fraction across all k-points to get the band's localization ratio.

Inside `find_localized_bands`, if the averaged localization ratio for a band exceeds the threshold (0.5), add that band index (0-based) to the localized set.

Return the localized set from `find_localized_bands`.

For `localized_bands_set_1`, call `find_localized_bands` using the first PROCAR (from `v_Ga/ccd_-1_0/1/PROCAR`) paired with the middle Vasprun from `v_Ga/ccd_0_-1/1/vasprun.xml`, with no band window restriction.

For `localized_bands_set_2`, call `find_localized_bands` using the second PROCAR (from `v_Ga/ccd_0_-1/1/PROCAR`) paired with the middle Vasprun from `v_Ga/ccd_-1_0/1/vasprun.xml`, with a band window of `(70, 85)` as a reasonable window around expected defect states near the band gap.

Return a dictionary with keys `"localized_bands_set_1"` and `"localized_bands_set_2"` mapping to the respective sets of integer band indices.

Handle any `KeyError` or missing spin channel gracefully by returning an empty set for that configuration.

Do not hardcode expected output values; all results must be computed from the files.
