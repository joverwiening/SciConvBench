Write a Python function using Pymatgen that computes a set of defect complex properties for a GaN-based system.

The function takes no required input arguments.

The function has a parameter `file_path` with a default value pointing to the directory containing `GaN.vasp`.

Read the base structure from `GaN.vasp` using `pymatgen.core.Structure.from_file`.

Create a 2x2x2 supercell from the base GaN structure using `make_supercell`.

Identify a nitrogen site in the supercell and create an O-on-N substitution defect using `pymatgen.analysis.defects.core.Substitution`, substituting one N atom with O.

Identify a gallium site in the supercell and create a Ga vacancy defect using `pymatgen.analysis.defects.core.Vacancy`, removing one Ga atom.

Create an H interstitial defect using `pymatgen.analysis.defects.core.Interstitial` at fractional coordinates `[0, 0, 0.75]` in the supercell.

Build `dc` as a `pymatgen.analysis.defects.core.DefectComplex` containing only the O-on-N substitution and the Ga vacancy.

Build `dc2` as a second `pymatgen.analysis.defects.core.DefectComplex` containing the same O-on-N substitution and the same Ga vacancy (identical defects to `dc`).

Compute `defect_complex_name` as `dc.name`.

Compute `supercell_structure_formula` as the reduced formula of the supercell structure generated by `dc.get_supercell_structure()` (or equivalent method that returns the structure after applying the defect complex to the supercell).

Compute `defect_complex_oxidation_state` as the sum of the `oxi_state` attribute of each individual defect in `dc`, cast to `int`.

Compute `element_changes` as `dc.element_changes`, which is a dict mapping element symbols to net integer changes in atom count.

Compute `defect_structure_formula` as the reduced formula of `dc.defect_structure` (the structure of the defect complex itself, not the full supercell).

Compute `defect_complex_with_interstitial_name` by treating `dc2` as if it includes the H interstitial: create a new `DefectComplex` from the O-on-N substitution, the Ga vacancy, and the H interstitial, and take its `.name`.

Compute `supercell_structure_with_dummy_formula` as the reduced formula of the supercell structure obtained from the interstitial-containing defect complex, where the interstitial site is represented by a dummy species (use `get_supercell_structure(dummy_species="X")` or equivalent).

Compute `defect_complex_equality` as the boolean result of `dc == dc2`.

Compute `defect_complex_inequality` as the boolean result of `dc != dc2`.

Return a dictionary with keys `defect_complex_name`, `supercell_structure_formula`, `defect_complex_oxidation_state`, `element_changes`, `defect_structure_formula`, `defect_complex_with_interstitial_name`, `supercell_structure_with_dummy_formula`, `defect_complex_equality`, `defect_complex_inequality` mapping to their respective computed values.

Include all necessary imports at the top of the function or module, including `from pymatgen.core import Structure, Species, Element`, `from pymatgen.analysis.defects.core import Substitution, Vacancy, Interstitial, DefectComplex`, and any other required Pymatgen submodules.

Include a complete docstring describing the function purpose, the optional `file_path` parameter, and the returned dictionary with each key, its type, and its meaning.

```python
import os
from pymatgen.core import Structure, Species, PeriodicSite, Lattice
from pymatgen.analysis.defects.core import (
    Substitution,
    Vacancy,
    Interstitial,
    DefectComplex,
)


def compute_defect_complex_properties(file_path: str = ".") -> dict:
    """
    Compute a set of defect complex properties for a GaN-based system.

    This function reads a GaN structure from a VASP file, builds a 2x2x2
    supercell, creates an O-on-N substitution defect and a Ga vacancy defect,
    and assembles them into a DefectComplex. It also constructs a second
    equivalent complex and an interstitial-augmented complex for comparison.

    Parameters
    ----------
    file_path : str, optional
        Path to the directory containing the input file `GaN.vasp`.
        Defaults to the current directory.

    Returns
    -------
    dict
        A dictionary with the following keys and types:

        defect_complex_name : str
            The name of the defect complex (substitution + vacancy).
        supercell_structure_formula : str
            Reduced chemical formula of the supercell after applying dc.
        defect_complex_oxidation_state : int
            Sum of oxidation states of the individual defects in dc.
        element_changes : dict
            Net change in atom count per element due to dc.
        defect_structure_formula : str
            Reduced formula of the defect complex structure itself.
        defect_complex_with_interstitial_name : str
            Name of the defect complex that includes the H interstitial.
        supercell_structure_with_dummy_formula : str
            Reduced formula of the supercell with a dummy species at the
            interstitial site.
        defect_complex_equality : bool
            True if dc == dc2.
        defect_complex_inequality : bool
            True if dc != dc2.
    """
    # ------------------------------------------------------------------
    # 1. Load base structure and build supercell
    # ------------------------------------------------------------------
    structure_file = os.path.join(file_path, "GaN.vasp")
    base_structure = Structure.from_file(structure_file)

    supercell = base_structure.copy()
    supercell.make_supercell([2, 2, 2])

    # ------------------------------------------------------------------
    # 2. Identify defect sites
    # ------------------------------------------------------------------
    # Find the first N site for the O-on-N substitution
    n_site = next(
        site for site in supercell if site.specie.symbol == "N"
    )

    # Find the first Ga site for the vacancy
    ga_site = next(
        site for site in supercell if site.specie.symbol == "Ga"
    )

    # ------------------------------------------------------------------
    # 3. Create individual defects
    # ------------------------------------------------------------------
    substitution = Substitution(supercell, n_site, Species("O"))
    vacancy = Vacancy(supercell, ga_site)
    interstitial = Interstitial(
        supercell,
        PeriodicSite(
            Species("H"),
            [0, 0, 0.75],
            supercell.lattice,
        ),
    )

    # ------------------------------------------------------------------
    # 4. Build defect complexes
    # ------------------------------------------------------------------
    dc = DefectComplex([substitution, vacancy])
    dc2 = DefectComplex([substitution, vacancy])
    dc_with_interstitial = DefectComplex([substitution, vacancy, interstitial])

    # ------------------------------------------------------------------
    # 5. Compute properties
    # ------------------------------------------------------------------
    defect_complex_name = dc.name

    sc_structure = dc.get_supercell_structure()
    supercell_structure_formula = sc_structure.composition.reduced_formula

    defect_complex_oxidation_state = int(
        sum(d.oxi_state for d in dc.defects)
    )

    element_changes = dc.element_changes

    defect_structure_formula = dc.defect_structure.composition.reduced_formula

    defect_complex_with_interstitial_name = dc_with_interstitial.name

    sc_with_dummy = dc_with_interstitial.get_supercell_structure(
        dummy_species="X"
    )
    supercell_structure_with_dummy_formula = (
        sc_with_dummy.composition.reduced_formula
    )

    defect_complex_equality = dc == dc2
    defect_complex_inequality = dc != dc2

    # ------------------------------------------------------------------
    # 6. Return results
    # ------------------------------------------------------------------
    return {
        "defect_complex_name": defect_complex_name,
        "supercell_structure_formula": supercell_structure_formula,
        "defect_complex_oxidation_state": defect_complex_oxidation_state,
        "element_changes": element_changes,
        "defect_structure_formula": defect_structure_formula,
        "defect_complex_with_interstitial_name": defect_complex_with_interstitial_name,
        "supercell_structure_with_dummy_formula": supercell_structure_with_dummy_formula,
        "defect_complex_equality": defect_complex_equality,
        "defect_complex_inequality": defect_complex_inequality,
    }
```
