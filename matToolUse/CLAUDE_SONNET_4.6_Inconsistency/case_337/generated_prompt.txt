Work inside the directory data/absorptionE3/OsO2.

Use the following INCAR for all three geometry-optimization steps (Steps 1–3), with NSW = 200, ISPIN = 1, ISIF = 2, EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISMEAR = 1, POTIM = 0.2, SIGMA = 0.2, and NSW = 200.

Step 1: Write the INCAR file with these contents:
SYSTEM = CO relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 200
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1

Then run: python op.py CO POTCAR-CO POSCAR-CO

Step 2: Keep the same INCAR (no changes needed; ISPIN = 1 and ISIF = 2 remain as specified).
Then run: python op.py surface POTCAR-OsO2face POSCAR-OsO2face

Step 3: Keep the same INCAR (no changes needed).
Then run: python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO

Step 4: Run the adsorption energy script: bash ./calc_absorption_energy.sh

Capture and return the adsorption energy value exactly as printed to stdout by calc_absorption_energy.sh.
