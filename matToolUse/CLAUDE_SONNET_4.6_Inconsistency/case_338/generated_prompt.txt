Work inside the directory data/absorptionE4/PdO2 for all steps.

Use the following INCAR for Step 1 (CO geometry optimization) and keep the same file for Steps 2 and 3 unless noted:
SYSTEM = relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 200
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1

Step 1: Write the INCAR above, then run: python op.py CO POTCAR-CO POSCAR-CO

Step 2: Keep the same INCAR (no changes needed given the constraints: ISPIN=1, ISIF=2, same ENCUT), then run: python op.py surface POTCAR-PdO2face POSCAR-PdO2face

Step 3: Keep the same INCAR, then run: python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO

Step 4: Run bash ./calc_absorption_energy.sh and capture the printed adsorption energy value as the final output.

NSW is set to 200 as a reasonable best-practice value for potentially non-ideal initial structures; increase further if any relaxation does not converge.
ISPIN is fixed at 1 (no spin polarization) for all three relaxation steps as required.
ISIF is fixed at 2 (no cell shape or volume optimization) for all three relaxation steps as required.
EDIFFG = -0.05 enforces the loose force convergence criterion of 0.05 eV/Å.
ENCUT = 450 eV is used consistently across all three steps.
Do not change POTCAR or POSCAR filenames; op.py copies the selected files to the generic POSCAR and POTCAR names inside each subdirectory before launching run.sh.
The adsorption energy is computed by calc_absorption_energy.sh as E(absorbed) - E(surface) - E(CO), reading the final E0 line from each subdirectory's OSZICAR.
