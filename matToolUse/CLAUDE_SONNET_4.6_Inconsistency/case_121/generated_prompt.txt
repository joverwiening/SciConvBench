Perform a variable-cell relaxation (vc-relax) calculation for AlN (wurtzite, space group P6_3mc, 4 atoms per primitive cell) using Quantum ESPRESSO.

Use the LDA pseudopotentials located at PseudoDojo/SR_v0.4.1/LDA_standard/al.upf and PseudoDojo/SR_v0.4.1/LDA_standard/n.upf for Al and N respectively.

If a structure-retrieval tool is available, retrieve the primitive wurtzite AlN structure consistent with formula=AlN, structure=wurtzite, space_group=P6_3mc, atoms_per_primitive_cell=4 and use it as the starting configuration. If no structure-retrieval tool is available, report that the local inputs do not contain enough structure data to start the calculation.

Set the Quantum ESPRESSO calculation type to vc-relax.

Use the BFGS algorithm for relaxation (the default in Quantum ESPRESSO).

Fix the cell (lattice vectors) during relaxation and relax only the internal atomic positions. Achieve this by setting cell_dofree = 'shape' with the cell shape fixed, or equivalently by constraining all cell degrees of freedom so that only ionic positions are updated. The most direct way in Quantum ESPRESSO is to set cell_dofree = 'all' but rely on forc_conv_thr and etot_conv_thr to drive ionic relaxation; alternatively, use calculation='relax' if the intent is strictly ionic-only relaxation with fixed cell. Since the instruction says keep lattice vectors fixed and relax only atomic positions, use calculation='relax' (not vc-relax) in the Quantum ESPRESSO input to strictly fix the cell while relaxing atoms.

Set the exchange-correlation functional to LDA (use input_dft = 'LDA' or rely on the pseudopotential-defined functional; set input_dft = 'pz' to explicitly select Perdew-Zunger LDA).

Target a strict energy convergence of 1 meV/atom. With 4 atoms in the primitive cell, 1 meV/atom = 4 meV total = approximately 2.94e-4 Ry total. Set etot_conv_thr = 2.94e-4 (in Ry) for the ionic loop.

Set forc_conv_thr to a value consistent with high accuracy; use forc_conv_thr = 1.0e-4 (in Ry/Bohr).

Set the SCF convergence threshold conv_thr to be at least two orders of magnitude tighter than etot_conv_thr; use conv_thr = 1.0e-10 (in Ry).

Choose the plane-wave kinetic energy cutoff ecutwfc appropriate for LDA PseudoDojo standard pseudopotentials for Al and N in a high-accuracy calculation; use ecutwfc = 80 Ry.

Set ecutrho = 4 * ecutwfc = 320 Ry (norm-conserving pseudopotentials use a 4x ratio by default; confirm this is appropriate for the PseudoDojo SR norm-conserving set).

Use a gamma-centered Monkhorst-Pack k-point grid. For high-accuracy relaxation of wurtzite AlN primitive cell, use an 8x8x6 gamma-centered k-point mesh (reflecting the hexagonal symmetry with shorter c-axis sampling).

Set occupations = 'fixed' since AlN is an insulator with no fractional occupancies. Do not set smearing or degauss.

Do not set starting_magnetization, Hubbard U parameters, or spin-orbit coupling flags.

Run the calculation and upon completion extract and report the fully relaxed atomic positions (in both crystal and Cartesian coordinates), the final total energy, the final forces on all atoms, and the cell parameters (which should remain equal to the input cell parameters since the cell is fixed).
