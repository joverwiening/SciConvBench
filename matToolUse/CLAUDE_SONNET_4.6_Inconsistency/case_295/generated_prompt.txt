Work inside the case directory: data/relax/MgB2.

Create a file named INCAR in the current directory with exactly the following lines:
ALGO = Fast
EDIFF = 0.00015000000000000001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11

LWAVE = .FALSE.
MAGMOM = 23*0.0
NELM = 100

PREC = Accurate

Use the existing files POSCAR, KPOINTS, and POTCAR as-is without modification.

Run VASP by executing: bash run_vasp.sh

After VASP completes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1

Extract the optimized total energy by executing: python get_energy.py

Report the optimized total energy exactly as printed by get_energy.py, with no modifications or reformatting.
