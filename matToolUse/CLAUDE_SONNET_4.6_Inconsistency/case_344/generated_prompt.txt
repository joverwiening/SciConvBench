Work inside the case directory: data/NEB1/AgPdneb1.

All commands are run from that directory unless a subdirectory is specified.

STEP 1 — Write the IS relaxation INCAR and run the IS optimization.

Create a file named INCAR in the working directory with exactly the following content:

SYSTEM = IS relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 300
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
NPAR = 1

Run the command:
python op.py IS POTCARagpd IS1POSCAR

This creates the IS subdirectory, copies IS1POSCAR as POSCAR and POTCARagpd as POTCAR into IS, copies the INCAR into IS, and launches run_1.sh to perform the relaxation.
Wait for the IS relaxation to complete before proceeding.

STEP 2 — Write the FS relaxation INCAR and run the FS optimization.

Use the same INCAR as Step 1 (no changes are needed; all parameter values are identical for the FS relaxation).

Verify the INCAR in the working directory still contains:

SYSTEM = FS relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 300
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
NPAR = 1

Run the command:
python op.py FS POTCARagpd FS1POSCAR

This creates the FS subdirectory, copies FS1POSCAR as POSCAR and POTCARagpd as POTCAR into FS, copies the INCAR into FS, and launches run_1.sh to perform the relaxation.
Wait for the FS relaxation to complete before proceeding.

STEP 3 — Interpolate intermediate images using ASE.

No INCAR is needed for this step.

Run the command:
python nebmake.py

nebmake.py reads IS/CONTCAR and FS/CONTCAR, interpolates 4 intermediate images using ASE, and writes POSCAR files into directories 00, 01, 02, 03, 04, and 05 (6 folders total: IS image in 00, 4 intermediate images in 01–04, FS image in 05).
Verify that directories 00 through 05 exist and each contains a POSCAR before proceeding.

STEP 4 — Write the NEB INCAR and run the NEB calculation.

Overwrite the INCAR in the working directory with exactly the following content:

SYSTEM = NEB calculation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 300
IBRION = 3
POTIM = 0
IOPT = 7
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
NPAR = 1
IMAGES = 4
LCLIMB = .TRUE.
SPRING = -5

Run the command:
python op2.py ./

op2.py copies POTCARagpd as POTCAR into the current NEB directory and launches run.sh to perform the multi-image NEB calculation.
Wait for the NEB calculation to complete (all image OUTCARs written) before proceeding.

STEP 5 — Extract the energy profile and determine the reaction barrier.

No INCAR is needed for this step.

Run the command:
bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'

This copies the IS OUTCAR into directory 00 and the FS OUTCAR into directory 05, then runs nebef.pl, which reads the OUTCAR files from all six image directories (00 through 05) and prints the force and energy profile for each image.

Read the printed energy profile output.
Identify the image with the highest energy relative to the initial state (image 00).
The reaction barrier is the energy difference between that highest-energy image and the initial state (image 00), reported in eV.
Record and report that barrier value as the final result.
