The working directory for all operations is `data/bandgap/GaAs`.

All input files (POSCAR, KPOINTS, POTCAR, gap.py, run_vasp.sh) are already present in the working directory; do not modify or recreate them.

Assume a Linux HPC environment with VASP 5.4+ licensed and installed, and that `bash run_vasp.sh` successfully invokes `vasp_std` via MPI.

Step 1: Create an INCAR file suitable for a PBE ground-state calculation.
Write the following content to `INCAR`:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
GGA=PE

Step 2: Run VASP for the PBE ground-state step by executing `bash run_vasp.sh`.

Step 3: Save the PBE INCAR by executing `cp INCAR INCAR1`.

Step 4: Create a new INCAR file for the HSE calculation.
Write the following content to `INCAR`:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Do not include MAGMOM, NBAND, or NELECT in the HSE INCAR.
Set ISTART=1 so VASP reads the existing WAVECAR from Step 1.
Set ICHARG=0 so VASP computes the charge density from the WAVECAR (ICHARG must not exceed 10 for a hybrid functional calculation starting from an existing WAVECAR).

Step 5: Run VASP for the HSE step by executing `bash run_vasp.sh`.

Step 6: Save the HSE INCAR by executing `cp INCAR INCAR2`.

Step 7: Extract the band gap by executing `python gap.py`.

Step 8: Capture and return the exact numerical value printed to stdout by `gap.py`; that value is the final band gap of GaAs computed with the HSE06 functional.
