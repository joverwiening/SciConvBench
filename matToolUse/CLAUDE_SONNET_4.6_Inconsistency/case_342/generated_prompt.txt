Work inside the directory: data/absorptionE8/Pt

Use the following INCAR for Step 1 (CO molecule optimization):
SYSTEM = CO molecule relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 200
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1

Write that content to the file named INCAR in the working directory.

Run Step 1 with the command: python op.py CO POTCAR-CO POSCAR-CO

Use the same INCAR (no changes needed) for Step 2 (clean Pt surface optimization).

Run Step 2 with the command: python op.py surface POTCAR-Ptface POSCAR-Ptface

Use the same INCAR (no changes needed) for Step 3 (CO-adsorbed Pt system optimization).

Run Step 3 with the command: python op.py absorbed POTCAR-PtCO POSCAR-PtCO

After all three VASP calculations finish successfully, run Step 4 with the command: bash ./calc_absorption_energy.sh

Capture and return the adsorption energy value exactly as printed to stdout by calc_absorption_energy.sh.

Use NSW = 200 as the assumed value for all three relaxation steps, which is a standard best-practice upper bound for ionic relaxations in VASP when the initial structure may not be ideal.

Do not include spin polarization (ISPIN = 1) in any step.

Do not optimize the unit cell (ISIF = 2) in any step.

Keep ENCUT = 450 eV consistently across all three relaxation steps.

Keep EDIFFG = -0.05 eV/Å as the force convergence criterion for all three relaxation steps.
