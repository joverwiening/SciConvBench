The task is to perform a VASP structural relaxation for FeSe and report the optimized total energy.

Work in the directory data/relax/FeSe.

Create a file named INCAR with the following parameters:
ALGO = Fast
EDIFF = 0.0002
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 15*3.445 16*0.22
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Run VASP using the command: bash run_vasp.sh
Copy the INCAR file to INCAR1 using: cp INCAR INCAR1
Extract the optimized total energy using: python get_energy.py
The optimized total energy after relaxation is -174.32461384 eV.
