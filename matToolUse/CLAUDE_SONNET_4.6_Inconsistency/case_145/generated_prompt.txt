Perform a variable-cell relaxation (vc-relax) calculation using Quantum ESPRESSO.

Use the pw.x executable from Quantum ESPRESSO for the calculation.

Set calculation = 'vc-relax' in the CONTROL namelist.

Use LDA exchange-correlation functional. Set input_dft = 'LDA' consistent with the provided PseudoDojo SR v0.4.1 LDA standard pseudopotentials.

Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/sn.upf for Sn.

Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/se.upf for Se.

The material is SnSe with orthorhombic structure, space group Pnma, and 8 atoms per primitive cell.

If a structure-retrieval tool is available, retrieve the primitive cell structure for SnSe consistent with space group Pnma and 8 atoms per primitive cell, and use the retrieved cell vectors and atomic coordinates as the starting configuration.

If no structure-retrieval tool is available, report that the local inputs do not contain enough structure data to start the calculation.

Set the strict energy convergence target to 1 meV/atom. With 8 atoms per primitive cell, this corresponds to etot_conv_thr = 8.0e-4 Ry (since 1 meV/atom = 7.3498e-5 Ry/atom, and 8 atoms × 7.3498e-5 Ry ≈ 5.88e-4 Ry; round conservatively to etot_conv_thr = 8.0e-4 Ry).

Set forc_conv_thr = 1.0e-3 Ry/Bohr as a tight force convergence threshold consistent with high-accuracy relaxation.

Set conv_thr = 1.0e-10 Ry for the self-consistent field (SCF) electronic convergence, consistent with high-accuracy requirements.

Choose ecutwfc = 80 Ry as the plane-wave kinetic energy cutoff, appropriate for PseudoDojo LDA standard pseudopotentials for Sn and Se.

Set ecutrho = 640 Ry (8× ecutwfc) for the charge density cutoff, consistent with norm-conserving PseudoDojo pseudopotentials.

Use a Monkhorst-Pack k-point grid with automatic generation and a half shift (gamma-centered Monkhorst-Pack with offset). Use a 6×6×2 k-point mesh for the orthorhombic Pnma primitive cell of SnSe, which provides sufficient sampling consistent with 1 meV/atom accuracy. Set the K_POINTS card to 'automatic' with grid 6 6 2 and shift 1 1 1.

Do not set occupations, smearing, or degauss (use the default fixed occupations appropriate for a semiconductor).

Do not apply Hubbard U corrections.

Do not enable spin-orbit coupling.

Do not set starting magnetization (non-magnetic calculation).

Set cell_dynamics = 'bfgs' in the IONS and CELL namelists for the variable-cell relaxation algorithm.

Set ion_dynamics = 'bfgs'.

Set press_conv_thr = 0.1 kbar as the pressure convergence threshold for the cell relaxation.

Set nstep = 200 to allow sufficient ionic and cell relaxation steps.

After the calculation completes, extract and report the fully relaxed structure including the final cell vectors (lattice parameters and angles) and the final fractional atomic coordinates of all 8 atoms in the primitive cell.
