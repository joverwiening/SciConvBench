Work inside the directory: data/absorptionE2/Rh

Use the following INCAR parameter values for all three geometry-optimization steps (Steps 1–3): EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2.
Set NSW = 300 for all three geometry-optimization steps, as a reasonable "higher NSW" value consistent with best practices when initial structures may not be ideal.
Do not include spin polarization in any step (ISPIN = 1 throughout).
Do not optimize the unit cell (ISIF = 2 throughout).
Use a force convergence criterion of EDIFFG = -0.05 eV/Å throughout.
Keep ENCUT = 450 eV consistently across all three relaxation steps.

Step 1 — Optimize the CO molecule.
Write an INCAR file with the following content:
SYSTEM = CO molecule relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
NSW = 300
IBRION = 1
POTIM = 0.2
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
LWAVE = .FALSE.
LCHARG = .FALSE.
Run the command: python op.py CO POTCAR-CO POSCAR-CO

Step 2 — Optimize the clean Rh surface.
Keep the same INCAR file (no changes are needed; ISPIN = 1 and ISIF = 2 remain as specified).
Run the command: python op.py surface POTCAR-Rhface POSCAR-Rhface

Step 3 — Optimize the CO-adsorbed Rh system.
Keep the same INCAR file unchanged.
Run the command: python op.py absorbed POTCAR-RhCO POSCAR-RhCO

Step 4 — Compute the adsorption energy.
After all three VASP calculations have completed successfully, run the command: bash ./calc_absorption_energy.sh
Capture and report the adsorption energy exactly as printed by calc_absorption_energy.sh.
