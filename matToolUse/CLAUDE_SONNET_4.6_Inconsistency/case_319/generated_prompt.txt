Work inside the case directory: data/bandgap/Ga2O3.

Step 1 — PBE ground state

Create a file named INCAR in the current directory with parameters suitable for a PBE ground-state calculation (standard settings: PREC=Normal, ENCUT=450, IBRION=-1, NSW=0, ISPIN=1, ISMEAR=0, SIGMA=0.05, EDIFF=1E-5, ISTART=0, ICHARG=2, LWAVE=.TRUE., LCHARG=.TRUE., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=Fast).

Run VASP by executing: bash run_vasp.sh

Save a copy of the INCAR used in this step by executing: cp INCAR INCAR1

Step 2 — HSE calculation

Create a new INCAR in the current directory using exactly the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Do not include ICHARG=11 (use ICHARG=0 as specified above).
Do not specify magnetic moment tags (e.g., MAGMOM).
Do not specify NBAND or NELECT.

Run VASP by executing: bash run_vasp.sh

Save a copy of the INCAR used in this step by executing: cp INCAR INCAR2

Step 3 — Band gap extraction

Run the post-processing script by executing: python gap.py

Capture and return the band-gap value exactly as printed to stdout by gap.py.
