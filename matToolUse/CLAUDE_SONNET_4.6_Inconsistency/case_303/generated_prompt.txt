Work inside the case directory: data/relax/SnSe.

Step 1: Create the INCAR file with exactly the following lines:
ALGO = Fast
EDIFF = 0.0004
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 31*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Step 2: Run VASP using the provided launcher script by executing: bash run_vasp.sh

Step 3: Copy the INCAR file to INCAR1 by executing: cp INCAR INCAR1

Step 4: Extract the optimized total energy by executing: python get_energy.py

Step 5: Capture and return the output printed by get_energy.py exactly as it appears, without modification. That printed value is the final answer (the optimized total energy after relaxation).

Use the existing files POSCAR, KPOINTS, and POTCAR as-is without modification. Do not alter the INCAR block in any way. Do not interpret or reformat the energy value returned by get_energy.py.
