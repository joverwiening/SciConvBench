Perform a variable-cell relaxation (vc-relax) calculation for MgB2 using Quantum ESPRESSO.
Use the LDA pseudopotentials located at PseudoDojo/SR_v0.4.1/LDA_standard/mg.upf and PseudoDojo/SR_v0.4.1/LDA_standard/b.upf for Mg and B respectively.
The material is MgB2 with space group P6/mmm and 3 atoms per primitive cell.
If a structure-retrieval tool is available, retrieve the primitive cell structure consistent with formula=MgB2, space_group=P6/mmm, atoms_per_primitive_cell=3, and use it as the starting configuration.
If no structure-retrieval tool is available, report that the local inputs do not contain enough structure data to start the calculation.
Set the calculation type to vc-relax in the Quantum ESPRESSO input.
Keep the lattice vectors fixed during relaxation by setting cell_dofree = 'shape' or equivalent so that only atomic positions are relaxed, not the cell shape or volume.
Use a gamma-centered k-point grid (use the AUTOMATIC k-points option with the shift set to 0 0 0).
Choose the k-point mesh density sufficient to achieve strict energy convergence of 1 meV/atom; a mesh of at least 12x12x12 is recommended for MgB2 given its small primitive cell.
Set ecutwfc to at least 60 Ry, which is appropriate for the PseudoDojo LDA standard pseudopotentials for Mg and B.
Set ecutrho to 4 times ecutwfc (at least 240 Ry) for norm-conserving pseudopotentials.
Set etot_conv_thr to 3 times the number of atoms times 1 meV converted to Ry; with 3 atoms and 1 meV/atom = approximately 7.35e-5 Ry/atom, set etot_conv_thr = 2.2e-4 Ry (i.e., 3 atoms x 7.35e-5 Ry).
Set forc_conv_thr to 1.0e-4 Ry/Bohr as a tight force convergence threshold consistent with the energy accuracy requirement.
Set conv_thr for the SCF cycle to at least one order of magnitude tighter than etot_conv_thr, so set conv_thr = 1.0e-10 Ry or smaller.
Use occupations = 'smearing' with smearing = 'methfessel-paxton' and degauss = 0.02 Ry, appropriate for the metallic character of MgB2.
Do not set starting_magnetization, Hubbard U, or spin-orbit-coupling flags, as none are specified for this case.
Use the BFGS algorithm for ionic relaxation (ion_dynamics = 'bfgs').
Use the default cell dynamics for vc-relax (cell_dynamics = 'bfgs').
Return the fully relaxed structure including the final lattice vectors and all relaxed atomic positions in crystal coordinates.
Report the total energy of the relaxed structure in Ry and eV.
Report the final forces on all atoms and confirm they are below forc_conv_thr.
Report the number of ionic steps taken to reach convergence.
