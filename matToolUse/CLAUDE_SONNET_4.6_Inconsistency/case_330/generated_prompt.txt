Work inside the case directory: data/bandgap/SiC.

Use the existing files POSCAR, KPOINTS, and POTCAR as inputs without modification.

Step 1 — PBE ground state.
Write an INCAR file suitable for a PBE ground-state calculation (standard settings: ISTART=0, ICHARG=2, PREC=Normal, ENCUT=450, EDIFF=1E-5, NSW=0, IBRION=-1, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., LCHARG=.TRUE., and any other reasonable PBE defaults).
Run the command: bash run_vasp.sh
After VASP completes, run: cp INCAR INCAR1

Step 2 — HSE calculation.
Write a new INCAR file with exactly the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast
Do not include any magnetic moment tags (MAGMOM, ISPIN overridden, etc.) beyond ISPIN=1 already listed.
Do not include NBAND or NELECT in this INCAR.
ICHARG is set to 0 (not 11) so that it does not exceed 10, satisfying the hybrid functional charge-density requirement.
Run the command: bash run_vasp.sh
After VASP completes, run: cp INCAR INCAR2

Step 3 — Band gap extraction.
Run the command: python gap.py
Capture and return the band-gap value exactly as printed by gap.py, with no modification.
