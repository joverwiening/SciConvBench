Write a Python function with no required input arguments that computes two properties using Pymatgen and returns them in a dictionary.

The function is named `compute_mg_ga_defect_properties`.

The function has a complete docstring describing that it reads local VASP output files and a JSON entries file, computes the Fermi level solution at 300 K and the formation energy diagram count at 1000 K for the Mg_Ga defect system, and returns a dictionary with keys `Fermi_Level_Solution` (float) and `Formation_Energy_Diagrams_Count` (int).

The base directory variable `file_path` is defined inside the function and points to the directory containing all input files.

Import the following at the top of the function or module: `os`, `json`, `glob`, `pymatgen.core.Structure`, `pymatgen.io.vasp.outputs.Vasprun`, `pymatgen.io.vasp.outputs.Locpot`, `pymatgen.analysis.defects.core.Substitution`, `pymatgen.analysis.defects.thermo.DefectEntry`, `pymatgen.analysis.defects.thermo.FormationEnergyDiagram`, `pymatgen.analysis.defects.thermo.MultiFormationEnergyDiagram`, `pymatgen.analysis.phase_diagram.PhaseDiagram`, `pymatgen.entries.computed_entries.ComputedStructureEntry`, and any other Pymatgen defect or DOS analysis utilities needed.

Load stable entries by reading `stable_entries_Mg_Ga_N.json` from `file_path` using `ComputedStructureEntry.from_dict` for each entry in the JSON list.

Construct the phase diagram using `PhaseDiagram` with the loaded stable entries.

Assume the bulk VASP output is located in a subfolder named `bulk` under `file_path`, containing `vasprun.xml.gz`. Parse it with `Vasprun` to obtain the bulk `ComputedStructureEntry`, the bulk band structure or DOS, and the VBM energy.

Assume charge-state subfolders for the Mg_Ga defect follow the naming pattern `charge_0`, `charge_-1`, `charge_-2`, `charge_1`, `charge_2` under `file_path`. Use `glob` or `os.listdir` to discover all subfolders matching the pattern `charge_*`. Each subfolder contains `vasprun.xml.gz` and `LOCPOT.gz`.

For each charge-state subfolder, parse `vasprun.xml.gz` with `Vasprun` to get the defect `ComputedStructureEntry` and parse `LOCPOT.gz` with `Locpot` to get the electrostatic potential for finite-size correction.

Construct a `DefectEntry` for each charge state using the parsed data, the bulk entry, and the VBM. Apply the Freysoldt (FNV) finite-size correction using the bulk and defect `Locpot` objects.

Build a `FormationEnergyDiagram` for each charge state using the defect entries, the bulk entry, the phase diagram, and the stable entries.

Construct a `MultiFormationEnergyDiagram` from the list of `FormationEnergyDiagram` objects.

Compute `Formation_Energy_Diagrams_Count` as the integer count of formation energy diagrams contained in the `MultiFormationEnergyDiagram` object, evaluated at 1000 K.

Obtain the bulk DOS from the bulk `Vasprun` object using `.complete_dos`.

Compute `Fermi_Level_Solution` by calling the Fermi level solver provided by Pymatgen's defect thermodynamics utilities, passing the chemical potentials derived from the phase diagram, the bulk DOS, and the temperature 300 K. Ensure the returned Fermi level value is greater than zero; if it is not, raise a `ValueError` with a descriptive message.

Return a dictionary with exactly two keys: `Fermi_Level_Solution` mapped to the float Fermi level value, and `Formation_Energy_Diagrams_Count` mapped to the integer diagram count.
