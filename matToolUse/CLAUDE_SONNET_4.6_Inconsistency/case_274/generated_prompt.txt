Work inside the case directory: data/relax/BaTiO3.

Create a file named INCAR in the current directory with exactly the following lines:
ALGO = Fast
EDIFF = 0.0005
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 39*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Use POSCAR, KPOINTS, and POTCAR as they exist in the current directory without modification.

Run VASP by executing: bash run_vasp.sh

After VASP completes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1

Extract and report the optimized total energy by executing: python get_energy.py

Return the optimized total energy exactly as printed by get_energy.py, with no modification or rounding.
