Write a Python function called `compute_defect_properties` with no required input arguments.

The function uses pymatgen's defect and analysis modules to compute formation energy and defect concentration for a Mg substituting Ga (Mg_Ga) defect system.

Import the following: os, json, gzip, pymatgen.core.Structure, pymatgen.io.vasp.outputs.Vasprun, pymatgen.analysis.defects.core.Substitution, pymatgen.analysis.defects.thermo.DefectEntry, pymatgen.analysis.defects.thermo.FormationEnergyDiagram, pymatgen.entries.computed_entries.ComputedStructureEntry, and pytest.approx.

Accept a parameter `file_path` with a default value of the directory containing the script (use `os.path.dirname(os.path.abspath(__file__))` as default).

Load the bulk supercell vasprun from `os.path.join(file_path, "Mg_Ga", "bulk_sc", "vasprun.xml.gz")` using `Vasprun` with `parse_dos=False` and `parse_eigen=False`.

Extract the bulk `ComputedStructureEntry` from the bulk vasprun using `vasprun.get_computed_entry(inc_structure=True)`.

Load the stable entries from `os.path.join(file_path, "stable_entries_Mg_Ga_N.json")` by reading the JSON file and deserializing each entry using `ComputedStructureEntry.from_dict`.

Construct the defect object as a `Substitution` by identifying the Ga site in the bulk structure and replacing it with Mg. Use the first site in the bulk structure whose species string is "Ga" as the defect site. Create the `Substitution` with the bulk structure, the defect site, and species "Mg".

Construct a `DefectEntry` using the defect object and the bulk computed entry. Set the `sc_entry` to the bulk computed entry and `sc_defect_frac_coords` to the fractional coordinates of the chosen defect site. Set `charge_state` to 0.

Construct the `FormationEnergyDiagram` using `FormationEnergyDiagram.with_atomic_entries`, passing the list containing the single `DefectEntry`, the list of stable entries loaded from the JSON, and the bulk computed entry as `vbm_entry`.

Define `chempots` as a dictionary mapping each element symbol present in the stable entries to 0.0 (use neutral chemical potentials as a reasonable default assumption).

Compute `formation_energy` by calling `formation_energy_diagram.get_formation_energy` with the defect entry, `fermi_level=0.3`, and `chempots=chempots`. Store the result as a float.

Compute `defect_concentration` by calling `formation_energy_diagram.get_concentration` with the defect entry, `fermi_level=1.0`, `chempots=chempots`, and `temperature=1000`. Store the result as a float.

Return a dictionary with keys `"formation_energy"` and `"defect_concentration"` mapped to `pytest.approx(formation_energy)` and `pytest.approx(defect_concentration)` respectively.

Include a complete docstring describing: the purpose of the function, the optional `file_path` parameter and its type (str), and the return value as a dict with keys `formation_energy` (float, pytest.approx-wrapped) and `defect_concentration` (float, pytest.approx-wrapped).

Handle the gzip-compressed vasprun.xml.gz transparently since pymatgen's `Vasprun` supports gzipped files natively when the filename ends in `.gz`.

Do not hardcode any absolute paths; always construct paths using `os.path.join(file_path, ...)`.
