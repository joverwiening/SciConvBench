Work inside the directory data/bandgap/SnO2.

Step 1 — Create the PBE ground-state INCAR.
Write a file named INCAR with the following content:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
GGA=PE

Step 2 — Run VASP for the PBE ground state.
Execute: bash run_vasp.sh

Step 3 — Save the PBE INCAR.
Execute: cp INCAR INCAR1

Step 4 — Create the HSE INCAR.
Write a file named INCAR with the following content, setting ISTART=1 and ICHARG=0 so VASP reads the existing WAVECAR but recomputes the charge density (ICHARG must not exceed 10 for a hybrid starting from WAVECAR):

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Do not include NBANDS, NELECT, or any MAGMOM tag.

Step 5 — Run VASP for the HSE calculation.
Execute: bash run_vasp.sh

Step 6 — Save the HSE INCAR.
Execute: cp INCAR INCAR2

Step 7 — Extract the band gap.
Execute: python gap.py

Step 8 — Capture and return the output.
Record exactly what gap.py prints to stdout; that printed value is the final band gap result to return.
