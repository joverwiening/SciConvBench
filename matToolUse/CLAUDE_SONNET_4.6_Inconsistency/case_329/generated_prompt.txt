Work inside the directory: data/bandgap/Si

All input files (POSCAR, KPOINTS, POTCAR, gap.py, run_vasp.sh) are already present in the working directory. Do not modify them.

Step 1 — PBE ground state

Write the following content to INCAR:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=Fast

Run VASP:
bash run_vasp.sh

Save a copy of the INCAR used for Step 1:
cp INCAR INCAR1

Step 2 — HSE calculation

Write the following content to INCAR:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Note: ISTART=1 tells VASP to read the existing WAVECAR from Step 1. ICHARG=0 (less than 10) ensures the charge density is recalculated from the wavefunction, which is required when starting a hybrid functional calculation from an existing WAVECAR. No magnetic moment tags (MAGMOM) are included. NBAND and NELECT are not specified.

Run VASP again for the HSE step:
bash run_vasp.sh

Save a copy of the INCAR used for Step 2:
cp INCAR INCAR2

Step 3 — Band gap extraction

Run the post-processing script:
python gap.py

Capture and return the band-gap value exactly as printed by gap.py to stdout. That printed value is the final result.
