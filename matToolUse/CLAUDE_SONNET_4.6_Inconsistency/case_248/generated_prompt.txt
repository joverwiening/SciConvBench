The task is a variable-cell relaxation (vc-relax) followed by a self-consistent field (SCF) calculation for wurtzite GaN using Quantum ESPRESSO with LDA pseudopotentials.

Use the material metadata: formula=GaN, structure=wurtzite, space_group=P6_3mc, atoms_per_primitive_cell=4.

Use the pseudopotential files PseudoDojo/SR_v0.4.1/LDA_standard/ga.upf and PseudoDojo/SR_v0.4.1/LDA_standard/n.upf for Ga and N respectively.

If a structure-retrieval tool is available, retrieve the primitive wurtzite GaN structure consistent with the metadata (space group P6_3mc, 4 atoms per primitive cell) and use it as the starting configuration for the vc-relax.

If no structure-retrieval tool is available and no local structure file is provided, report that the local inputs do not contain enough structure data to start the calculation and stop.

Set the calculation type to vc-relax for the first run.

Use the LDA exchange-correlation functional consistent with the PseudoDojo LDA pseudopotentials.

Set ecutwfc = 80 Ry as a well-converged value appropriate for Ga and N with PseudoDojo norm-conserving pseudopotentials.

Set ecutrho = 320 Ry (four times ecutwfc), consistent with norm-conserving pseudopotentials.

Set etot_conv_thr = 1.0e-8 Ry for the vc-relax ionic convergence.

Set forc_conv_thr = 1.0e-7 Ry/Bohr for the vc-relax force convergence.

Set conv_thr = 1.0e-10 Ry for the SCF convergence inside the vc-relax (one order tighter than etot_conv_thr to avoid noise).

Use a 6x6x4 Monkhorst-Pack k-point grid with a half-shift (offset = 1 1 1 in Quantum ESPRESSO notation) for the vc-relax, which is appropriate for the hexagonal primitive cell of wurtzite GaN.

Keep the k-point grid gamma-centered for consistency; apply the half-shift uniformly so the grid remains consistent with the relaxed structure symmetry.

Do not specify occupations, smearing, degauss, starting magnetization, Hubbard U, or spin-orbit-coupling flags; treat GaN as a non-magnetic insulator with fixed occupations.

Use the cell_dofree = 'all' option in the CELL namelist to allow full relaxation of both cell shape and volume.

After the vc-relax calculation converges, extract the fully relaxed atomic positions and cell vectors from the final output or restart file.

Construct a new Quantum ESPRESSO input for an SCF calculation using the relaxed structure (cell vectors and atomic positions from the vc-relax output).

Set calculation = 'scf' for the second run.

Use identical pseudopotentials, ecutwfc, ecutrho, and k-point settings for the SCF run as used in the vc-relax.

Set conv_thr = 1.0e-8 Ry for the SCF run as specified.

Do not perform a further relaxation in the SCF run; use the relaxed structure as a fixed input.

Return the fully relaxed structure, including the relaxed lattice parameters (a, c, c/a ratio, and internal coordinate u for the wurtzite structure) and the Cartesian or fractional atomic positions.

Return the final total energy from the SCF calculation in Ry and in eV.
