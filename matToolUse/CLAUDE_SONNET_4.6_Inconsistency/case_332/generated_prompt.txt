Work inside the case directory: data/bandgap/ZnO.

All input files (POSCAR, KPOINTS, POTCAR, gap.py, run_vasp.sh) are already present in the current directory. Do not modify them.

Step 1 — PBE ground-state calculation.
Write an INCAR file suitable for a standard PBE ground-state calculation for ZnO. Use typical PBE settings (ISTART=0, ICHARG=2, IBRION=-1, NSW=0, ISPIN=1, PREC=Normal, ENCUT=450, EDIFF=1E-5, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., LCHARG=.TRUE., LREAL=Auto).
Run VASP by executing: bash run_vasp.sh
After VASP finishes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1

Step 2 — HSE calculation.
Write a new INCAR file with exactly the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast
Do not include MAGMOM, NBAND, or NELECT in this INCAR.
Use ISTART=0 and ICHARG=0 (overriding the original block which had ICHARG=11).
Run VASP by executing: bash run_vasp.sh
After VASP finishes, copy the INCAR to INCAR2 by executing: cp INCAR INCAR2

Step 3 — Band gap extraction.
Run the post-processing script by executing: python gap.py
Capture and return the band-gap value exactly as printed by gap.py.
