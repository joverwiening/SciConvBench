Work inside the case directory: data/relax/MgO.

Create a file named INCAR in the current directory with exactly the following content:

ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Use IBRION = 2 (conjugate-gradient ionic relaxation) and NSW = 99 (up to 99 ionic steps), overriding the originally listed values of IBRION = -1 and NSW = 0.

Run VASP by executing: bash run_vasp.sh

After VASP finishes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1

Extract and report the optimized total energy by executing: python get_energy.py

Return the optimized total energy exactly as printed by get_energy.py, with no modification.
