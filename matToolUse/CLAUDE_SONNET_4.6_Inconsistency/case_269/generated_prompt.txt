Work inside the case directory: data/relax/Al.

Create a file named INCAR in the current directory with exactly the following content:
ALGO = Fast
EDIFF = 5e-05
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 26*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Use IBRION = 2 (conjugate gradient ionic relaxation) instead of -1, and NSW = 99 instead of 0, to enable actual structural relaxation.
All other parameters remain exactly as listed above.

The input files POSCAR, KPOINTS, and POTCAR are already present in the current directory; do not modify them.

Run VASP by executing: bash run_vasp.sh

After VASP completes, copy the INCAR to preserve it: cp INCAR INCAR1

Extract and report the optimized total energy by running: python get_energy.py

Return the optimized total energy exactly as printed by get_energy.py, with no modification or rounding.
