Work inside the directory: data/bandgap/CdTe.

All input files (POSCAR, KPOINTS, POTCAR, run_vasp.sh, gap.py) are already present in the working directory; do not modify them.

Step 1 — PBE ground-state calculation.
Write an INCAR file suitable for a standard PBE ground-state calculation for CdTe (use typical PBE settings: PREC=Normal, ENCUT=450, IBRION=-1, NSW=0, ISPIN=1, ISMEAR=0, SIGMA=0.05, EDIFF=1E-5, LWAVE=.TRUE., LCHARG=.TRUE., and any other standard PBE tags appropriate for this system; do not specify NBAND, NELECT, or magnetic moments).
Run VASP by executing: bash run_vasp.sh
Copy the INCAR used in this step: cp INCAR INCAR1

Step 2 — HSE calculation.
Write a new INCAR file with exactly the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast
Do not include NBAND, NELECT, or any magnetic moment tags (no MAGMOM, no NUPDOWN).
Run VASP by executing: bash run_vasp.sh
Copy the INCAR used in this step: cp INCAR INCAR2

Step 3 — Band gap extraction.
Run the post-processing script: python gap.py
Capture and return the band-gap value exactly as printed by gap.py, with no modification.
