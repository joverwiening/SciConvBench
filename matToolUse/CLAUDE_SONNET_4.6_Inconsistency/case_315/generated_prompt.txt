Work inside the case directory: data/bandgap/CdS.

Step 1 — Create the PBE ground-state INCAR.
Write a file named INCAR with the following content, derived from the Step 2 parameter block but with all hybrid functional tags removed and ISTART/ICHARG set for a fresh start:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=Fast

Run VASP for the PBE ground-state step:
bash run_vasp.sh

Save a copy of the PBE INCAR:
cp INCAR INCAR1

Step 2 — Create the HSE INCAR.
Write a file named INCAR with the following content exactly as specified in data.json, with ISTART=1 to read the existing WAVECAR and ICHARG=0 (which is less than 10, so charge density will be recalculated as required):

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Do not include MAGMOM, NBAND, or NELECT in this INCAR.
ICHARG=0 satisfies the constraint that ICHARG must not be larger than 10 when starting a hybrid calculation from an existing WAVECAR.

Run VASP for the HSE step:
bash run_vasp.sh

Save a copy of the HSE INCAR:
cp INCAR INCAR2

Step 3 — Extract the band gap.
Run the post-processing script:
python gap.py

Capture and return the band-gap value exactly as printed by gap.py.
