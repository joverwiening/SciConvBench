You are working inside the case directory: data/bandgap/InP.

The goal is to compute the electronic band gap of InP using VASP with a two-step workflow (PBE ground state followed by HSE), then extract the band gap using gap.py.

Use the existing files POSCAR, KPOINTS, and POTCAR as inputs without modification.

Step 1: Write an INCAR file suitable for a PBE ground-state calculation for InP. Use standard PBE settings (ISTART=0, ICHARG=2, ISMEAR=0, SIGMA=0.05, PREC=Normal, ENCUT=450, EDIFF=1E-5, IBRION=-1, NSW=0, LWAVE=.TRUE., LCHARG=.TRUE., ISPIN=1, and any other reasonable PBE defaults). Do not include hybrid functional tags.

Run VASP by executing: bash run_vasp.sh

After VASP completes for Step 1, save the INCAR as INCAR1 by running: cp INCAR INCAR1

Step 2: Write a new INCAR file for the HSE calculation using exactly the following parameters:

NELM=500

Set ICHARG=0 (not larger than 10) so that the charge density is recalculated even when starting from an existing WAVECAR. Do not include any magnetic moment tags (no MAGMOM). Do not include NBAND or NELECT parameters.

Run VASP again by executing: bash run_vasp.sh

After VASP completes for Step 2, save the INCAR as INCAR2 by running: cp INCAR INCAR2

Step 3: Run the post-processing script by executing: python gap.py

The script reads vasprun.xml, builds the band structure, and prints the band gap value. Report the band gap value exactly as printed by gap.py, with no modification or rounding.
