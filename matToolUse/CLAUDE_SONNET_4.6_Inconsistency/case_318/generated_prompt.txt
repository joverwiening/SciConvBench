Work inside the directory data/bandgap/Cu2O.

Step 1 — PBE ground state.

Create a file named INCAR with the following contents:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
ALGO=Fast
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Use the existing POSCAR, KPOINTS, and POTCAR files as inputs without modification.

Run VASP by executing: bash run_vasp.sh

After the run completes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1

Step 2 — HSE calculation.

Create a new INCAR (overwriting the previous one) with the following contents:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Set ISTART=1 so VASP reads the WAVECAR produced in Step 1.
Set ICHARG=0 so VASP computes the charge density from the WAVECAR rather than reading CHGCAR, satisfying the requirement that ICHARG must not exceed 10 when starting a hybrid calculation from an existing WAVECAR.
Do not include MAGMOM or any magnetic-moment tag.
Do not include NBANDS or NELECT.

Run VASP by executing: bash run_vasp.sh

After the run completes, copy the INCAR to INCAR2 by executing: cp INCAR INCAR2

Step 3 — Band gap extraction.

Run the post-processing script by executing: python gap.py

Record the band-gap value exactly as printed to standard output by gap.py and return that value as the final result.
