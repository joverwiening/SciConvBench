Generate one `Vacancy` defect for each unique site in the GaN structure.

Generate one `Interstitial` defect for each unique site in the GaN structure using a reasonable interstitial finding method available in Pymatgen.

Combine all generated vacancy and interstitial defects into a single list called `all_defects`.

For `group_names_with_key_function`: using the same grouping result from `defect_grouping_with_key_function`, collect the name of the first defect in each group to form a list of group representative names, then convert that list to a string for the return value.

Return a dictionary with exactly these three keys and their corresponding string values:
`defect_grouping_without_key_function`, `defect_grouping_with_key_function`, `group_names_with_key_function`.
