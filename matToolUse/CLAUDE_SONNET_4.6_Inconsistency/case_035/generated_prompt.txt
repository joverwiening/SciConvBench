The material is BaTiO3 in the perovskite structure with space group P4mm and 5 atoms per primitive cell.
Use Quantum ESPRESSO for all calculations: pw.x for DFT steps, bands.x for band post-processing, and dos.x for DOS post-processing.
Use LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard: ba.upf, ti.upf, and o.upf.
Retrieve a primitive starting structure consistent with formula=BaTiO3, structure=perovskite, space_group=P4mm, atoms_per_primitive_cell=5 using a structure-retrieval tool before beginning.
If no structure-retrieval tool is available, report that the local inputs do not contain enough structure data to start the calculation and stop.
The workflow has six steps executed in this order: vc-relax, scf, nscf, pw.x with calculation="bands", bands.x post-processing, and dos.x post-processing.
For the DOS post-processing stage, feed dos.x directly from the SCF charge density; do not run an additional NSCF step before dos.x.
The nscf step and the pw.x bands step are still executed as part of the workflow for the band structure portion; only the DOS branch skips a separate NSCF and reads from SCF instead.
Use the LDA exchange-correlation functional throughout all pw.x runs.
Set the energy convergence target to 1 meV/atom, which equals 5 meV total for the 5-atom primitive cell; convert to Rydberg: 1 meV = 7.3498e-5 Ry, so 5 meV total = 3.675e-4 Ry.
Set etot_conv_thr = 3.675e-4 Ry for the vc-relax step.
Set conv_thr for the SCF self-consistency loop to one order of magnitude tighter than etot_conv_thr: use conv_thr = 3.675e-5 Ry (approximately 3.7e-5 Ry).
Set forc_conv_thr = 1.0e-3 Ry/Bohr for the vc-relax step as a reasonable tight default consistent with 1 meV/atom accuracy.
Choose ecutwfc = 80 Ry as appropriate for the PseudoDojo LDA standard norm-conserving pseudopotentials for Ba, Ti, and O.
Set ecutrho = 320 Ry (four times ecutwfc) for the charge density cutoff.
Use a gamma-centered Monkhorst-Pack k-point grid.
Use an 8x8x8 gamma-centered k-point grid for the vc-relax and scf steps to achieve 1 meV/atom accuracy for a 5-atom perovskite cell.
Use a denser 12x12x12 gamma-centered k-point grid for the nscf and bands steps to improve sampling for spectral properties.
Do not use smearing (occupations = 'fixed') since BaTiO3 is an insulator; if the calculation fails to converge with fixed occupations, switch to occupations = 'smearing' with smearing = 'gaussian' and degauss = 0.01 Ry.
Do not apply Hubbard U corrections unless explicitly requested.
Do not include spin-orbit coupling.
Do not use spin-polarization (nspin = 1).
In the vc-relax step, allow both atomic positions and cell parameters to relax (cell_dofree = 'all').
Use the relaxed structure output from vc-relax as the input geometry for all subsequent steps.
For the pw.x bands calculation, use the same ecutwfc, ecutrho, and pseudopotentials as the scf step, and provide a k-point path through the high-symmetry points of the tetragonal Brillouin zone consistent with space group P4mm: Gamma, X, M, Gamma, Z, R, A, Z and X, R and M, A as a representative path.
Run bands.x after the pw.x bands calculation to post-process and extract the band structure; the band structure result does not need to be explicitly returned.
Run dos.x after the scf calculation using the SCF charge density to compute the density of states; set the energy window and broadening automatically or use Emin and Emax spanning the full valence and conduction band range with a Gaussian broadening of 0.01 Ry.
Save all output files and the final DOS data file as the primary deliverable of this workflow.
