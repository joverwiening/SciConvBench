Work inside the directory: data/absorptionE10/PtO2

The task is to compute the adsorption energy of CO on a PtO2 surface using VASP, following a four-step workflow.

Use the following INCAR parameter values for all three geometry-optimization steps (Steps 1–3): EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2.
Set NSW = 200 for all geometry-optimization steps as a reasonable "higher NSW" assumption based on best practices.
Do not include spin polarization in any step (ISPIN = 1 throughout).
Do not optimize the unit cell (ISIF = 2 throughout).
Keep all INCAR settings identical across Steps 1, 2, and 3 unless a step-specific override is noted below.
No step-specific overrides are needed given the constraints (no spin, no cell relaxation, loose force criterion).

Step 1: Optimize the CO molecule.
Write an INCAR file containing: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, NSW = 200, POTIM = 0.2, SIGMA = 0.2.
Run: python op.py CO POTCAR-CO POSCAR-CO

Step 2: Optimize the clean PtO2 surface.
Update the INCAR file with the same parameters (no changes needed given the constraints).
Run: python op.py surface POTCAR-PtO2face POSCAR-PtO2face

Step 3: Optimize the CO-adsorbed PtO2 system.
Keep the same INCAR file (no changes needed).
Run: python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO

Step 4: Compute the adsorption energy.
Run: bash ./calc_absorption_energy.sh
Capture and return the adsorption energy exactly as printed by calc_absorption_energy.sh.

The KPOINTS file provided in the directory is used as-is for all three VASP calculations; do not modify it.
The POTCAR and POSCAR files are selected per step by op.py using the arguments provided in each run command above.
op.py creates the step subdirectory (CO, surface, or absorbed), copies the selected POSCAR-* and POTCAR-* to generic POSCAR and POTCAR inside that directory, and then executes run.sh to launch vasp_std.
calc_absorption_energy.sh reads the final E0 values from CO/OSZICAR, surface/OSZICAR, and absorbed/OSZICAR and computes the adsorption energy as E_adsorption = E(absorbed) - E(surface) - E(CO).
Return only the numeric adsorption energy value (with units) exactly as printed by calc_absorption_energy.sh.
