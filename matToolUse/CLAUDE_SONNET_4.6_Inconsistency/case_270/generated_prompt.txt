Work inside the case directory: data/relax/AlN.

Create a file named INCAR in the current directory with exactly the following lines:
ALGO = Fast
EDIFF = 0.0002
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 31*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Do not add, remove, or modify any line in the INCAR file.

Use the existing files POSCAR, KPOINTS, and POTCAR as-is; do not modify them.

Run VASP by executing: bash run_vasp.sh

After VASP finishes, copy the INCAR file to INCAR1 by executing: cp INCAR INCAR1

Extract the optimized total energy by executing: python get_energy.py

Capture the output printed by get_energy.py exactly as it appears and return that value as the final answer.
Do not interpret, round, or reformat the energy value; return it verbatim.
