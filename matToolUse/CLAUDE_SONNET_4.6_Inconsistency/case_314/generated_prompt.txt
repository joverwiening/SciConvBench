Work inside the case directory: data/bandgap/C.

All input files (POSCAR, KPOINTS, POTCAR, gap.py, run_vasp.sh) are already present in the current directory. Do not modify them.

Step 1: Create an INCAR file suitable for a PBE ground-state calculation. Use standard PBE settings (e.g., ISTART=0, ICHARG=2, IBRION=-1, NSW=0, ISPIN=1, PREC=Normal, ENCUT=450, EDIFF=1E-5, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., LCHARG=.TRUE., ALGO=Fast, LREAL=Auto). Write this as the file named INCAR in the current directory.

Step 2: Run VASP for the PBE ground-state step by executing: bash run_vasp.sh

Step 3: Save the PBE INCAR as INCAR1 by executing: cp INCAR INCAR1

Step 4: Create a new INCAR file for the HSE calculation with exactly the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Do not include ICHARG=11 from the original block; use ICHARG=0 instead. Do not specify magnetic moments (no MAGMOM). Do not specify NBAND or NELECT. Write this as the file named INCAR in the current directory.

Step 5: Run VASP for the HSE step by executing: bash run_vasp.sh

Step 6: Save the HSE INCAR as INCAR2 by executing: cp INCAR INCAR2

Step 7: Extract the band gap by executing: python gap.py

Step 8: Capture and return the exact output printed by gap.py as the final result.
