Work inside the case directory: data/relax/LiCoO2.

Create a file named INCAR in the current directory with exactly the following content:
ALGO = Fast
EDIFF = 0.0002
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LDAU = .TRUE.
LDAUJ = 0 0 0
LDAUL = 0 2 0
LDAUPRINT = 1
LDAUTYPE = 2
LDAUU = 0 3.32 0
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 31*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Use the existing POSCAR, KPOINTS, and POTCAR files as-is without modification.

Run VASP by executing: bash run_vasp.sh

After VASP completes, copy the INCAR to preserve it: cp INCAR INCAR1

Extract and report the optimized total energy by running: python get_energy.py

Return the optimized total energy exactly as printed by get_energy.py, with no modification or rounding.
