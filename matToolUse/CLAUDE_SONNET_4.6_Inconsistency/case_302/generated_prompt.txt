Work inside the case directory: data/relax/SiO2.

Create a file named INCAR in the current directory with exactly the following lines:
ALGO = Fast
EDIFF = 0.00030000000000000003
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Use IBRION = 2 (conjugate-gradient ionic relaxation) and NSW = 99 (maximum 99 ionic steps), overriding the originally listed IBRION = -1 and NSW = 0.
Use ISIF = 3 to allow both ionic positions and cell shape/volume to relax.
Use EDIFF = 0.00030000000000000003 as the electronic convergence criterion.
Use ENCUT = 520.0 eV as the plane-wave cutoff energy.
Use ISMEAR = -5 (tetrahedron method with Blöchl corrections) for k-point integration.
Use ISPIN = 2 to enable spin-polarized calculation.
Use LASPH = .TRUE. to include non-spherical contributions to the gradient corrections.
Use LORBIT = 11 to write projected DOS and PROCAR.
Use LREAL = Auto for real-space projection in large systems.
Use LWAVE = .FALSE. to skip writing the WAVECAR file.
Use MAGMOM = 23*0.0 to initialize all 23 magnetic moments to zero.
Use NELM = 100 as the maximum number of electronic self-consistency steps.
Use PREC = Accurate for high-precision FFT grids.
Use SIGMA = 0.05 eV as the smearing width.
Use the existing POSCAR, KPOINTS, and POTCAR files as the other VASP inputs without modification.
Run VASP by executing: bash run_vasp.sh
After VASP completes, copy the INCAR to INCAR1 by executing: cp INCAR INCAR1
Extract and report the optimized total energy by executing: python get_energy.py
Return the optimized total energy exactly as printed by get_energy.py, with no modification.
