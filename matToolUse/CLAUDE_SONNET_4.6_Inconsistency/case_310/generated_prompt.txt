Work inside the directory data/bandgap/AlN.

Step 1: Create the INCAR file for the PBE ground-state calculation.
Write the following content to INCAR:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=Fast

Run VASP for the PBE ground-state step:
bash run_vasp.sh

Save a copy of the INCAR used in Step 1:
cp INCAR INCAR1

Step 2: Create the INCAR file for the HSE calculation.
Write the following content to INCAR, using the parameter block from data.json but correcting ICHARG to a value no larger than 10 (use ICHARG=1 to read the charge density from CHGCAR) and omitting NBAND, NELECT, and any magnetic moment tags:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=1
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Run VASP for the HSE step:
bash run_vasp.sh

Save a copy of the INCAR used in Step 2:
cp INCAR INCAR2

Step 3: Extract the band gap.
Run the post-processing script:
python gap.py

Record and report the exact numeric value printed to standard output by gap.py as the final band gap of AlN.
