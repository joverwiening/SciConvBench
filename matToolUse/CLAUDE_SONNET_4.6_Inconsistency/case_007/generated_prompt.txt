Write a Python function named `compute_defect_properties` that takes no required input arguments.

Use `file_path = Path(".")` as the default base directory inside the function.

Import the following: `from pathlib import Path`, `from pymatgen.core import Structure`, `from pymatgen.io.vasp.outputs import Vasprun, Locpot`, `from pymatgen.analysis.defects.core import Substitution`, `from pymatgen.analysis.defects.thermo import DefectEntry`, `from pymatgen.analysis.defects.corrections.freysoldt import FreysoldtCorrection`, and standard library modules `re` and `os`.

Load the host structure from `file_path / "GaN.vasp"` using `Structure.from_file`.

Load the bulk LOCPOT from `file_path / "bulk_sc/LOCPOT.gz"` using `Locpot.from_file`.

Scan all immediate subdirectories under `file_path / "Mg_Ga"` to find charge-state folders.

Parse the charge state integer from each folder name by extracting the last integer token (including a leading minus sign if present) using a regex such as `re.search(r'(-?\d+)$', folder_name)`. Skip any subfolder whose name yields no integer match.

For each charge-state folder, load `vasprun.xml.gz` using `Vasprun` and `LOCPOT.gz` using `Locpot.from_file`.

Construct the `Mg_Ga` substitution defect: identify the Ga site in the host structure and create a `Substitution` object with Mg replacing Ga at that site.

Build a `DefectEntry` object for each charge state using the parsed charge, the computed defect energy from the vasprun, and the associated LOCPOT.

The defect energy passed to each `DefectEntry` is the total energy of the defect supercell minus the total energy of the bulk supercell, obtained from the respective `Vasprun` objects. Store this raw energy difference for the `q = 1` entry as the `energy_difference` output.

Generate Freysoldt correction metadata for all charge states using dielectric constant `14`. Use `FreysoldtCorrection` with `dielectric_const=14` applied to each `DefectEntry`.

For the `q = 1` entry, separately compute the Freysoldt correction using dielectric constant `10` and store the resulting correction value as the `freysoldt_correction` output. This is the scalar float correction energy from that calculation.

For `potential_alignment_consistency`, compare the potential alignment value stored in the correction metadata generated with dielectric `14` for `q = 1` against the potential alignment value computed during the dielectric `10` correction run for `q = 1`. If the absolute difference between the two potential alignment values is less than `0.01` eV, set `potential_alignment_consistency` to `True`, otherwise `False`.

Return a dictionary with exactly three keys: `"freysoldt_correction"` (float), `"potential_alignment_consistency"` (bool), and `"energy_difference"` (float).

Include a complete docstring describing: that the function reads defect and bulk VASP output files from a local directory, constructs Mg_Ga substitution DefectEntry objects for charge states [-2, -1, 0, 1], computes Freysoldt corrections and energy differences, and returns a dictionary of the three properties with their types and meanings.

Handle gzipped files transparently since Pymatgen's `from_file` and `Vasprun` support `.gz` files natively.

Do not require any input arguments; all paths are resolved internally relative to `file_path`.
