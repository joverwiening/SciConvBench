Work inside the case directory: data/bandgap/BN.

Step 1 — PBE ground state

Create an INCAR file for the PBE ground-state calculation by taking the Step 2 parameter block and removing all HSE-specific tags (LHFCALC, HSE06, HFSCREEN, TIME, AEXX, AGGAX, LMAXFOCK, PRECFOCK, ALGO=All, LORBIT). Use the following parameters:

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Write this content to the file named INCAR in the working directory.

Run VASP using the command: bash run_vasp.sh

After VASP completes, copy the INCAR to INCAR1 using the command: cp INCAR INCAR1

Step 2 — HSE calculation

Create a new INCAR file with the following parameters, modifying ISTART and ICHARG to read from the existing WAVECAR while still computing charge density (ICHARG must not exceed 10). Do not include NBAND, NELECT, or any magnetic moment tags (no MAGMOM, no ISPIN=2):

PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=1
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Write this content to the file named INCAR in the working directory.

Run VASP using the command: bash run_vasp.sh

After VASP completes, copy the INCAR to INCAR2 using the command: cp INCAR INCAR2

Step 3 — Band gap extraction

Run the post-processing script using the command: python gap.py

Capture and return the band-gap value exactly as printed by gap.py to standard output.
