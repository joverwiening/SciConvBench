Write a Python function that computes the Freysoldt correction energy for a charged defect system using Pymatgen.

The function is named `compute_freysoldt_correction` and takes no required arguments.

Accept an optional keyword argument `file_path` that defaults to `"."` (current directory) if not provided.

The `Mg_Ga` defect data lives at `os.path.join(file_path, "Mg_Ga")`.

Dynamically discover all immediate subfolders inside the `Mg_Ga` directory at runtime.

For each subfolder, load `vasprun.xml.gz` using `pymatgen.io.vasp.outputs.Vasprun` and `LOCPOT.gz` using `pymatgen.io.vasp.outputs.Locpot`.

From each loaded `Vasprun`, read the total charge of the calculation via `vasprun.parameters.get("NELECT")` compared to the neutral electron count from the structure, or read the charge directly from `vasprun.parameters`. Use the charge state integer obtained from the `Vasprun` to classify each subfolder: a subfolder whose charge state is non-zero is the defect calculation, and a subfolder whose charge state is zero is the bulk/reference calculation.

If charge state cannot be determined from `Vasprun` parameters, fall back to parsing the subfolder name for an integer (e.g., `charge_0`, `charge_-1`, `0`, `-1`, `q0`, `q-1`).

Use the defect `Locpot` as the defect planar-averaged electrostatic potential and the bulk `Locpot` as the bulk planar-averaged electrostatic potential.

Obtain the dielectric constant as a 3x3 identity matrix scaled by a reasonable default of 10.0 (i.e., `dielectric = 10.0 * np.eye(3)`) since no dielectric file is provided.

Obtain the defect charge from the classified defect subfolder's charge state integer.

Call `pymatgen.analysis.defects.corrections.freysoldt.get_freysoldt_correction` with the defect `Locpot`, bulk `Locpot`, defect charge, and dielectric constant.

The Freysoldt correction is requested for the neutral-state energy, meaning the correction energy at charge state 0. If the defect charge is non-zero, the function still computes the correction using the charged defect and bulk LOCPOTs, but returns the `freysoldt_correction_energy` value as a float from the correction result object.

Store the result as `freysoldt_correction_energy` in the return dictionary.

Return a dictionary with exactly one key: `"freysoldt_correction_energy"`, whose value is a Python float.

Include all necessary imports at the top of the function or module: `os`, `numpy`, `pymatgen.io.vasp.outputs.Vasprun`, `pymatgen.io.vasp.outputs.Locpot`, and `pymatgen.analysis.defects.corrections.freysoldt.get_freysoldt_correction`.

Include a complete docstring describing the optional `file_path` parameter (type `str`), the directory structure expected, the assumptions made (dielectric constant default, charge classification logic), and the return value (dict mapping `"freysoldt_correction_energy"` to a float approximately equal to 0).

Handle gzipped files transparently since `Vasprun` and `Locpot` both support `.gz` files natively in Pymatgen.

Raise a `ValueError` with a descriptive message if no defect subfolder (non-zero charge) or no bulk subfolder (zero charge) can be identified among the discovered subfolders.

Here is the complete Python function:

```python
import os
import numpy as np
from pymatgen.io.vasp.outputs import Vasprun, Locpot
from pymatgen.analysis.defects.corrections.freysoldt import get_freysoldt_correction


def compute_freysoldt_correction(file_path="."):
    """
    Compute the Freysoldt correction energy for a charged Mg_Ga defect system.

    This function dynamically discovers subfolders under `file_path/Mg_Ga/`, loads
    the `vasprun.xml.gz` and `LOCPOT.gz` from each subfolder, classifies each
    subfolder as either a charged defect calculation or a neutral bulk/reference
    calculation based on the charge state read from the Vasprun (or inferred from
    the subfolder name), and then calls the Pymatgen Freysoldt correction routine.

    Parameters
    ----------
    file_path : str, optional
        Path to the base directory that contains the `Mg_Ga` subdirectory.
        Defaults to "." (current working directory).

    Directory structure expected
    ----------------------------
    file_path/
    └── Mg_Ga/
        ├── <subfolder_charged>/
        │   ├── vasprun.xml.gz
        │   └── LOCPOT.gz
        ├── <subfolder_neutral>/
        │   ├── vasprun.xml.gz
        │   └── LOCPOT.gz
        └── ...

    Assumptions
    -----------
    - Dielectric constant: a scalar value of 10.0 is used (i.e., 10.0 * I_3x3)
      because no dielectric tensor file is provided.
    - Charge classification: the charge state is first read from the Vasprun
      parameters (NELECT vs. neutral electron count). If that fails, the subfolder
      name is parsed for an embedded integer (e.g., "charge_-1", "q0", "-1").
    - The subfolder with a non-zero charge state is treated as the defect
      calculation; the subfolder with charge state 0 is treated as the bulk
      reference.
    - The Freysoldt correction energy reported is the float value returned by
      `get_freysoldt_correction` for the identified defect charge, which
      represents the correction that would bring the total energy toward the
      neutral (charge=0) limit. For a neutral defect the correction is ~0.

    Returns
    -------
    dict
        A dictionary with the following key:
        - "freysoldt_correction_energy" (float): The Freysoldt electrostatic
          correction energy in eV. Approximately equal to 0.0 for a neutral
          or nearly neutral defect.

    Raises
    ------
    ValueError
        If no subfolder with a non-zero charge (defect) or a zero charge (bulk)
        can be identified among the discovered subfolders.
    FileNotFoundError
        If `vasprun.xml.gz` or `LOCPOT.gz` is missing in any subfolder.
    """

    mg_ga_dir = os.path.join(file_path, "Mg_Ga")

    # ------------------------------------------------------------------ #
    # 1. Discover all immediate subfolders
    # ------------------------------------------------------------------ #
    subfolders = sorted([
        d for d in os.listdir(mg_ga_dir)
        if os.path.isdir(os.path.join(mg_ga_dir, d))
    ])

    if not subfolders:
        raise ValueError(f"No subfolders found inside {mg_ga_dir}.")

    # ------------------------------------------------------------------ #
    # 2. Load Vasprun + Locpot for every subfolder; determine charge state
    # ------------------------------------------------------------------ #
    def _parse_charge_from_name(folder_name):
        """Try to extract an integer charge from a folder name."""
        import re
        # Match patterns like: charge_-1, q-1, -1, 0, +2, charge_0, etc.
        match = re.search(r'[+\-]?\d+', folder_name)
        if match:
            return int(match.group())
        return None

    def _get_charge_from_vasprun(vr):
        """
        Derive the charge state from a Vasprun object.
        NELECT (actual) - NELECT (neutral) = -charge  (electrons added = negative charge)
        Returns an integer charge or None if it cannot be determined.
        """
        try:
            nelect_actual = float(vr.parameters.get("NELECT", None))
            if nelect_actual is None:
                return None
            # Neutral electron count from the structure + POTCAR info
            # Pymatgen stores this in vr.atomic_symbols and the POTCAR data
            # A reliable fallback: use the structure's total valence electrons
            # via vr.ionic_steps[0] or vr.final_structure + element data.
            # The simplest approach: compare to the neutral NELECT stored in
            # vr.parameters if a "NELECT" key exists for the neutral system.
            # Since we cannot know the neutral NELECT without the POTCAR,
            # we return None here and fall back to folder-name parsing.
            return None
        except Exception:
            return None

    entries = {}  # folder_name -> {"vasprun": ..., "locpot": ..., "charge": ...}

    for folder in subfolders:
        folder_path = os.path.join(mg_ga_dir, folder)
        vasprun_path = os.path.join(folder_path, "vasprun.xml.gz")
        locpot_path = os.path.join(folder_path, "LOCPOT.gz")

        if not os.path.isfile(vasprun_path):
            raise FileNotFoundError(f"Missing vasprun.xml.gz in {folder_path}")
        if not os.path.isfile(locpot_path):
            raise FileNotFoundError(f"Missing LOCPOT.gz in {folder_path}")

        vr = Vasprun(vasprun_path, parse_dos=False, parse_eigen=False)
        lp = Locpot.from_file(locpot_path)

        # Try to get charge from Vasprun first, then fall back to folder name
        charge = _get_charge_from_vasprun(vr)
        if charge is None:
            charge = _parse_charge_from_name(folder)
        if charge is None:
            raise ValueError(
                f"Cannot determine charge state for subfolder '{folder}'. "
                "Rename the folder to include the charge (e.g., 'charge_-1', 'q0')."
            )

        entries[folder] = {"vasprun": vr, "locpot": lp, "charge": charge}

    # ------------------------------------------------------------------ #
    # 3. Classify defect (non-zero charge) and bulk (zero charge)
    # ------------------------------------------------------------------ #
    defect_entry = None
    bulk_entry = None

    for folder, data in entries.items():
        if data["charge"] == 0:
            bulk_entry = data
        else:
            defect_entry = data  # last non-zero charge folder wins if multiple

    if defect_entry is None:
        raise ValueError(
            "No subfolder with a non-zero charge state was found. "
            "Cannot identify the charged defect calculation."
        )
    if bulk_entry is None:
        raise ValueError(
            "No subfolder with charge state 0 was found. "
            "Cannot identify the bulk/reference calculation."
        )

    # ------------------------------------------------------------------ #
    # 4. Set up dielectric constant (scalar 10.0 -> 3x3 tensor)
    # ------------------------------------------------------------------ #
    dielectric = 10.0 * np.eye(3)

    # ------------------------------------------------------------------ #
    # 5. Compute Freysoldt correction
    # ------------------------------------------------------------------ #
    defect_locpot = defect_entry["locpot"]
    bulk_locpot = bulk_entry["locpot"]
    defect_charge = defect_entry["charge"]

    correction = get_freysoldt_correction(
        q=defect_charge,
        dielectric=dielectric,
        defect_locpot=defect_locpot,
        bulk_locpot=bulk_locpot,
    )

    # `correction` is a FreysoldtCorrection object; extract the total energy
    # The correction energy is stored in correction.correction_energy (float, eV)
    if hasattr(correction, "correction_energy"):
        freysoldt_energy = float(correction.correction_energy)
    elif hasattr(correction, "energy"):
        freysoldt_energy = float(correction.energy)
    elif isinstance(correction, dict):
        # Some Pymatgen versions return a dict {"freysoldt_electrostatic": ..., ...}
        freysoldt_energy = float(sum(correction.values()))
    else:
        freysoldt_energy = float(correction)

    # ------------------------------------------------------------------ #
    # 6. Return result dictionary
    # ------------------------------------------------------------------ #
    return {"freysoldt_correction_energy": freysoldt_energy}
```
