Work inside the directory data/bandgap/GaN throughout all steps.

Step 1: Create an INCAR file suitable for a PBE ground-state calculation using standard parameters.
Write the following content to INCAR:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=Normal
GGA=PE

Run VASP for the PBE ground-state step by executing: bash run_vasp.sh

Save a copy of the INCAR used in Step 1 by executing: cp INCAR INCAR1

Step 2: Create a new INCAR file for the HSE calculation.
Write the following content to INCAR, using ICHARG=0 (not 11) because when starting a hybrid functional calculation from an existing WAVECAR the charge density must still be computed, requiring ICHARG to be less than or equal to 10, and ICHARG=0 reads the WAVECAR and recomputes the charge density from it:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Do not include MAGMOM, NBAND, or NELECT in the HSE INCAR.

Run VASP for the HSE step by executing: bash run_vasp.sh

Save a copy of the INCAR used in Step 2 by executing: cp INCAR INCAR2

Step 3: Extract the band gap by executing: python gap.py

Record the band-gap value exactly as printed to standard output by gap.py and return it as the final result.
