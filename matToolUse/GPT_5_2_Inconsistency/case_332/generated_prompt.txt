Assume VASP 6.x (vasp_std) is available and invoked by run_vasp.sh in the current directory data/bandgap/ZnO.
Assume the compute environment is an HPC cluster where bash run_vasp.sh launches an MPI VASP job appropriately.
Use the existing input files POSCAR, KPOINTS, and POTCAR in the current directory for all VASP runs.

Write INCAR for Step 1 with these best-practice defaults: GGA=PE.
Write INCAR for Step 1 with these best-practice defaults: ISPIN=1.

Write INCAR for Step 1 with these best-practice defaults: ISIF=2.

Write INCAR for Step 1 with these best-practice defaults: ISMEAR=0.
Write INCAR for Step 1 with these best-practice defaults: SIGMA=0.05.

Write INCAR for Step 1 with these best-practice defaults: LWAVE=.TRUE.
Write INCAR for Step 1 with these best-practice defaults: LCHARG=.TRUE.

Run VASP for Step 1 using: bash run_vasp.sh.
After Step 1 completes, save a copy of the INCAR as INCAR1 using: cp INCAR INCAR1.
