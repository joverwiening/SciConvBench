Use Quantum ESPRESSO pw.x to run a two-step workflow for Fe3O4: (1) vc-relax, then (2) scf on the relaxed structure to obtain the final total energy.
Use LDA pseudopotentials fe.upf and o.upf from PseudoDojo/SR_v0.4.1/LDA_standard.
If a structure-retrieval tool is available, retrieve a primitive Fe3O4 structure consistent with space group Fd-3m, ferrimagnetic ordering, and 7 atoms per primitive cell, and use it as the starting configuration.
If no structure-retrieval tool is available, stop and report that the local inputs do not contain enough structure data to start the calculation.
Use spin-polarized collinear magnetism with nspin=2.
Set starting_magnetization(Fe)=0.5 and starting_magnetization(O)=0.0.
Do not use DFT+U (do not set lda_plus_u or Hubbard_U).
Use occupations='smearing', smearing='mv', and degauss=0.02 Ry.
Use ecutwfc=80 Ry and ecutrho=320 Ry.
Use conv_thr=1.0e-8.
For vc-relax, set etot_conv_thr=1.0e-8 and forc_conv_thr=1.0e-7.
For vc-relax, relax both ions and cell with press=0.0 kbar.
Use an automatic Monkhorst-Pack k-point mesh of 6 6 6 with half shift: K_POINTS automatic with 6 6 6 1 1 1.
Keep the k-point grid gamma-centered for consistency with the relaxed structure by using the same k-point specification in both vc-relax and scf.
Run pw.x with calculation='vc-relax' using the retrieved primitive structure, then extract the relaxed CELL_PARAMETERS and ATOMIC_POSITIONS from the vc-relax output.
Run pw.x with calculation='scf' using the relaxed structure and the same computational settings (pseudopotentials, cutoffs, k-points, smearing, magnetization, thresholds).
Return the fully relaxed structure in Quantum ESPRESSO format (CELL_PARAMETERS and ATOMIC_POSITIONS for the primitive cell).
Return the final total energy from the scf calculation (the final “!” total energy value) with units as reported by QE.
