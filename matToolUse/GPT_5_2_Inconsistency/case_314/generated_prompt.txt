Work inside the directory data/bandgap/C.
Use the existing input files POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh as provided in this directory.
Follow a three-step workflow: PBE ground state, then HSE, then band-gap extraction with gap.py.
For Step 1 (PBE ground state), create an INCAR suitable for a non-magnetic PBE SCF ground-state calculation for carbon using the provided POSCAR/KPOINTS/POTCAR.
For Step 1, do not set any hybrid-functional tags (e.g., LHFCALC, HSE06).
For Step 1, run VASP using bash run_vasp.sh.
After Step 1 completes, save the INCAR used for Step 1 by running cp INCAR INCAR1.
For Step 2 (HSE), overwrite INCAR with the HSE INCAR settings.
For Step 2, use exactly these INCAR tags and values:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast
For Step 2, do not specify magnetic moments (do not set MAGMOM).
For Step 2, do not specify NBAND.
For Step 2, do not specify NELECT.
For Step 2, run VASP using bash run_vasp.sh.
After Step 2 completes, save the INCAR used for Step 2 by running cp INCAR INCAR2.
For Step 3, run python gap.py in the same directory after Step 2 so it reads the resulting vasprun.xml.
Return the band-gap value exactly as printed by gap.py.
