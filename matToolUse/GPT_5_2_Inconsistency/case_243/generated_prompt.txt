Use Quantum ESPRESSO pw.x with two sequential calculations: first a vc-relax, then an scf on the vc-relaxed structure.
Use a primitive ZnO wurtzite structure consistent with formula=ZnO, space_group=P6_3mc, atoms_per_primitive_cell=4.
If a structure-retrieval tool is available, retrieve the primitive wurtzite ZnO starting structure from it and use it as the initial configuration.
If no structure-retrieval tool is available, stop and report that the local inputs do not contain enough structure data to start the calculation.
Use LDA pseudopotentials: PseudoDojo/SR_v0.4.1/LDA_standard/zn.upf for Zn and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf for O.

Use ecutwfc = 80 Ry.
Use ecutrho = 320 Ry.
Use an automatic Monkhorst-Pack k-point grid with half shift.
Use K_POINTS automatic 8 8 6 1 1 1 for both vc-relax and scf.
Set conv_thr = 1.0d-8 for both vc-relax and scf.
Set etot_conv_thr = 1.0d-8 for the vc-relax.
Set forc_conv_thr = 1.0d-7 for the vc-relax.
Use cell_dofree = 'all' for the vc-relax.
Use press = 0.0 for the vc-relax.
After vc-relax completes, run an scf calculation using the relaxed cell parameters and relaxed atomic positions from the vc-relax output.
Keep pseudopotentials, input_dft, cutoffs, k-point grid, and conv_thr consistent between vc-relax and scf.
Return the fully relaxed structure (cell vectors and atomic coordinates) from the vc-relax result.
Return the final total energy from the scf run on the vc-relaxed structure.
