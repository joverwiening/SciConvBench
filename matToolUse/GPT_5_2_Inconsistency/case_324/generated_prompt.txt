Work in the directory data/bandgap/InP.
Use POSCAR, KPOINTS, and POTCAR from the current directory as the inputs for all VASP runs.
Use run_vasp.sh which invokes vasp_std to run VASP for this case.
Perform three sequential steps: PBE ground-state SCF, then HSE06 single-point, then band-gap extraction with gap.py.
For Step 1, write an INCAR suitable for a PBE ground-state SCF calculation for a non-magnetic semiconductor.
Set in Step 1 INCAR: GGA=PE, PREC=Normal, ENCUT=450, EDIFF=1E-6, NELM=200, IBRION=-1, NSW=0, ISIF=2, ISPIN=1, ISTART=0, ICHARG=2, ISMEAR=0, SIGMA=0.05, LREAL=Auto, LWAVE=.T., LCHARG=.T.
Run Step 1 VASP using: bash run_vasp.sh.
After Step 1 completes, save the INCAR as INCAR1 using: cp INCAR INCAR1.
For Step 2, overwrite INCAR with exactly the provided HSE parameter block: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
In Step 2, do not set any magnetic moments.
In Step 2, do not specify NBAND or NELECT.
In Step 2, keep ICHARG not larger than 10 and use ICHARG=0 as given.
Run Step 2 VASP using: bash run_vasp.sh.
After Step 2 completes, save the INCAR as INCAR2 using: cp INCAR INCAR2.
For Step 3, run the band-gap extraction script using: python gap.py.
Return the band-gap value exactly as printed by gap.py.
