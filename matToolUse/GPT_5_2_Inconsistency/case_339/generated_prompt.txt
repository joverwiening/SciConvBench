Work inside the directory data/absorptionE5/RhO2.
Use VASP to compute the adsorption energy of CO on the provided RhO2 surface via three geometry optimizations plus a post-processing script.
Use the provided KPOINTS file for all three VASP calculations.
Do not include spin polarization in any step by setting ISPIN = 1.
Do not optimize the unit cell in any step by setting ISIF = 2.
Use a loose force convergence criterion by setting EDIFFG = -0.05.
Keep ENCUT low and consistent across steps by setting ENCUT = 450.
Use IBRION = 1, POTIM = 0.2, ISMEAR = 1, SIGMA = 0.2 for the relaxation steps.
Set NSW = 200 for Step 1 (CO), Step 2 (clean surface), and Step 3 (adsorbed system).
Add any other standard, non-conflicting VASP relaxation settings as needed, but keep the specified constraints unchanged across Steps 1–3.
Create an INCAR for Step 1 (CO relaxation) containing at least: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200.
Run Step 1 by executing: python op.py CO POTCAR-CO POSCAR-CO.
Create/update an INCAR for Step 2 (clean surface relaxation) using the same constrained settings and NSW = 200.
Run Step 2 by executing: python op.py surface POTCAR-RhO2face POSCAR-RhO2face.
Create/update an INCAR for Step 3 (adsorbed system relaxation) using the same constrained settings and NSW = 200.
Run Step 3 by executing: python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO.
After Steps 1–3 complete, compute the adsorption energy by running: bash ./calc_absorption_energy.sh.
Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
