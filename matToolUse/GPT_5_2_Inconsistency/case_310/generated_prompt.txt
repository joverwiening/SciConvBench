Use the existing inputs POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh in data/bandgap/AlN.
Run a three-step workflow: PBE single-point SCF, then HSE single-point SCF, then band-gap extraction with gap.py.
Assume VASP is launched via run_vasp.sh using vasp_std under MPI with 16 total MPI ranks.
Assume the KPOINTS mesh is Monkhorst–Pack 6 6 6.
For Step 1 (PBE ground state), write INCAR as a single-point SCF calculation with no ionic relaxation.
Set in Step 1 INCAR: PREC=Normal.
Set in Step 1 INCAR: ENCUT=450.
Set in Step 1 INCAR: GGA=PE.
Set in Step 1 INCAR: ISPIN=1.
Set in Step 1 INCAR: IBRION=-1.
Set in Step 1 INCAR: NSW=0.
Set in Step 1 INCAR: ISIF=2.
Set in Step 1 INCAR: EDIFF=1E-5.
Set in Step 1 INCAR: ISMEAR=0.
Set in Step 1 INCAR: SIGMA=0.05.
Set in Step 1 INCAR: LREAL=Auto.
Set in Step 1 INCAR: LPLANE=.TRUE.
Set in Step 1 INCAR: LWAVE=.T.
Set in Step 1 INCAR: LCHARG=.T.
Set in Step 1 INCAR: ALGO=Normal.
Set in Step 1 INCAR: NELM=200.
Set in Step 1 INCAR: NPAR=1.
Set in Step 1 INCAR: KPAR=4.
Set in Step 1 INCAR: NCORE=1.
Run Step 1 VASP using: bash run_vasp.sh.
After Step 1 completes, save the INCAR used as INCAR1 by running: cp INCAR INCAR1.
For Step 2 (HSE), overwrite INCAR using the provided HSE parameter block, but correct ICHARG to obey the constraint that it cannot be larger than 10 when charge density must be computed.
Set in Step 2 INCAR: PREC=Normal.
Set in Step 2 INCAR: ENCUT=450.
Set in Step 2 INCAR: NELM=500.
Set in Step 2 INCAR: IBRION=-1.
Set in Step 2 INCAR: ISPIN=1.
Set in Step 2 INCAR: NSW=0.
Set in Step 2 INCAR: ISIF=2.
Set in Step 2 INCAR: EDIFF=1E-5.
Set in Step 2 INCAR: EDIFFG=-5E-3.
Set in Step 2 INCAR: ISTART=0.
Set in Step 2 INCAR: ICHARG=0.
Set in Step 2 INCAR: ISMEAR=0.
Set in Step 2 INCAR: SIGMA=0.05.
Set in Step 2 INCAR: LWAVE=.T.
Set in Step 2 INCAR: LCHARG=.T.
Set in Step 2 INCAR: LREAL=Auto.
Set in Step 2 INCAR: LPLANE=.TRUE.
Set in Step 2 INCAR: NPAR=1.
Set in Step 2 INCAR: KPAR=4.

Do not set MAGMOM in Step 2 INCAR.

Do not set NELECT in Step 2 INCAR.
Run Step 2 VASP using: bash run_vasp.sh.
After Step 2 completes, save the INCAR used as INCAR2 by running: cp INCAR INCAR2.
For Step 3, extract the band gap by running: python gap.py.
Report the band-gap value exactly as printed by gap.py.
