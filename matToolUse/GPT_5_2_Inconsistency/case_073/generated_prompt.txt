Retrieve the primitive Na3Bi (P6_3/mmc) structure from the Materials Project database via API and use it as the starting geometry.
Use Quantum ESPRESSO 7.4 (or the closest available 7.x release if 7.4 is not installed).
Use the provided PseudoDojo/SR_v0.4.1/LDA_standard LDA pseudopotentials na.upf and bi.upf.
Enable fully relativistic spin–orbit coupling for all steps (noncolin=.true., lspinorb=.true.).
Perform the workflow in this exact order: (1) vc-relax, (2) scf, (3) nscf, (4) pw.x with calculation="bands", (5) band post-processing, (6) DOS post-processing.
Use a strict total-energy convergence target equivalent to 1 meV/atom for all electronic steps and ensure the relaxation thresholds are tight enough to not dominate this accuracy target.
Use a gamma-centered k-point grid for vc-relax and scf.
Use an automatic Monkhorst-Pack grid with half shift for nscf and for the bands run.
Choose k-point grids dense enough to meet the 1 meV/atom convergence requirement, increasing density until the criterion is satisfied.
Set ecutwfc to 100 Ry.
Set ecutrho to 400 Ry.
Use fixed occupations with a small smearing suitable for a semimetal and converge results with respect to smearing width to preserve the 1 meV/atom target.
In vc-relax, relax both cell and ions starting from the retrieved primitive cell until forces and stresses are consistent with the 1 meV/atom accuracy requirement.
In scf, compute the self-consistent charge density on the relaxed structure.
In nscf, compute eigenvalues on a denser k-point mesh than scf suitable for DOS and band interpolation.
In the pw.x bands step, compute bands along a standard high-symmetry path for hexagonal P6_3/mmc using the relaxed structure and SOC.
Run band post-processing (bands.x) to generate band energies for consistency checks, without needing to present plots.
Compute total DOS plus projected DOS (PDOS) resolved by atom and angular momentum (s, p, d) using projwfc.x.
Output DOS over an energy window from -5 eV to +5 eV relative to the Fermi level.
Use a DOS energy grid spacing of 0.01 eV per point (or finer if needed for smooth convergence).
Document the final chosen k-point grids, smearing, and convergence thresholds used to satisfy the 1 meV/atom requirement.
If Materials Project access is not actually available at runtime, stop and report that no structure data is available locally to start the calculation.
