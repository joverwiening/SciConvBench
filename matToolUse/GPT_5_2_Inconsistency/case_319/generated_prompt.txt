Work inside the directory data/bandgap/Ga2O3.
Use POSCAR, KPOINTS, POTCAR, gap.py, run_vasp.sh as provided in the directory.
Perform a three-step workflow: PBE ground state, then HSE, then band-gap extraction via gap.py.
Create an INCAR for Step 1 (PBE ground state) suitable for a static ground-state calculation using GGA = PE and no hybrid-functional tags.
Run Step 1 VASP using bash run_vasp.sh, which invokes vasp_std.
After Step 1 completes, save the Step 1 INCAR as INCAR1 by running cp INCAR INCAR1.
Create an INCAR for Step 2 (HSE) using the provided parameter block, but set ICHARG = 0 instead of ICHARG=11.
Do not set any magnetic moment tags in the Step 2 INCAR.
Do not set NBAND or NELECT in the Step 2 INCAR.
Run Step 2 VASP using bash run_vasp.sh, which invokes vasp_std.
After Step 2 completes, save the Step 2 INCAR as INCAR2 by running cp INCAR INCAR2.
Run python gap.py to extract the band gap from vasprun.xml.
Return the band-gap value exactly as printed by gap.py.
