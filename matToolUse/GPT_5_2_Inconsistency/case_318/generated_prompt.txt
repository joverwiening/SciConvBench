Work inside the directory data/bandgap/Cu2O.
Use the existing input files POSCAR, KPOINTS, and POTCAR as provided in the directory.
Use the existing launch script run_vasp.sh to run VASP with the vasp_std executable.
Assume a SLURM HPC environment.
Assume the MPI launch inside run_vasp.sh uses srun to invoke vasp_std.
Assume 32 total MPI ranks for each VASP run.
Assume a walltime limit of 24:00:00 for each VASP run.
Assume the SLURM partition name is compute.
Assume no SLURM account flag is required.
Assume the SLURM job name is Cu2O_HSE_gap.
Assume no SLURM QoS is required.

Step 1 (PBE ground state): create an INCAR suitable for a PBE ground-state single-point calculation for Cu2O using the provided POSCAR, KPOINTS, and POTCAR.
In Step 1 INCAR, use GGA = PE.
In Step 1 INCAR, do not set any hybrid-functional tags.
In Step 1 INCAR, do not set any magnetic-moment tags.
In Step 1 INCAR, set NSW = 0 and IBRION = -1.
In Step 1 INCAR, write wavefunction and charge density by setting LWAVE = .TRUE. and LCHARG = .TRUE.
Run VASP for Step 1 by executing bash run_vasp.sh.
After Step 1 completes, save the INCAR used as INCAR1 by running cp INCAR INCAR1.

Set ISIF=2.

Set EDIFFG=-5E-3.
Set ISTART=0.
Set ICHARG=0.

Run VASP for Step 2 by executing bash run_vasp.sh.
After Step 2 completes, save the INCAR used as INCAR2 by running cp INCAR INCAR2.

Step 3 (band gap extraction): run python gap.py in the same directory containing the final vasprun.xml from the HSE calculation.
