Work in the directory data/bandgap/BN.
Use the existing POSCAR, KPOINTS, and POTCAR files in this directory as VASP inputs.
Assume VASP writes its default XML output file vasprun.xml in the run directory.
Step 1 (PBE ground state): create a file named INCAR containing exactly these parameters and no MAGMOM, NBAND, or NELECT.
Set PREC=Normal.
Set ENCUT=450.
Set NELM=200.
Set IBRION=-1.
Set ISPIN=1.
Set NSW=0.
Set ISIF=2.
Set EDIFF=1E-5.
Set ISTART=0.
Set ICHARG=2.
Set ISMEAR=0.
Set SIGMA=0.05.
Set LWAVE=.T.
Set LCHARG=.T.
Set LREAL=Auto.
Set LPLANE=.TRUE.
Set NPAR=1.
Set KPAR=4.
Set NCORE=1.
Set GGA=PE.
Run VASP for Step 1 by executing bash run_vasp.sh.
After Step 1 completes, save the INCAR used for Step 1 by executing cp INCAR INCAR1.
Step 2 (HSE calculation): keep the exchange-correlation treatment consistent with Step 1 and continue from existing WAVECAR/charge density.
Step 2 (HSE calculation): create a new file named INCAR containing exactly the following parameters and do not set MAGMOM, NBAND, or NELECT.
Set PREC=Normal.
Set ENCUT=450.
Set NELM=500.
Set IBRION=-1.
Set ISPIN=1.
Set NSW=0.
Set ISIF=2.
Set EDIFF=1E-5.
Set EDIFFG=-5E-3.
Set ISTART=0.
Set ICHARG=0.
Set ISMEAR=0.
Set SIGMA=0.05.
Set LWAVE=.T.
Set LCHARG=.T.
Set LREAL=Auto.
Set LPLANE=.TRUE.
Set NPAR=1.
Set KPAR=4.
Set NCORE=1.
Set LORBIT=11.
Set ALGO=All.
Set LHFCALC=.TRUE.
Set HSE06=.TRUE.
Set HFSCREEN=0.2.
Set TIME=0.4.
Set AEXX=0.25.
Set AGGAX=0.75.
Set LMAXFOCK=4.
Set PRECFOCK=Fast.
Run VASP for Step 2 by executing bash run_vasp.sh.
After Step 2 completes, save the INCAR used for Step 2 by executing cp INCAR INCAR2.
Step 3 (band gap extraction): run python gap.py in the same directory containing vasprun.xml from the final (HSE) run.
Report the band-gap value exactly as printed by gap.py.
