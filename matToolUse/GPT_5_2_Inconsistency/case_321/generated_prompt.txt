Set up and run a 3-step VASP workflow in data/bandgap/GaN to compute the GaN band gap, using POSCAR, KPOINTS, and POTCAR in the current directory, and extracting the final band gap by running python gap.py on the final vasprun.xml.
Use run_vasp.sh to launch vasp_std under MPI for all VASP runs.
Step 1 is a static PBE SCF ground-state calculation with no ionic relaxation.
Write INCAR for Step 1 with: PREC=Normal.
Write INCAR for Step 1 with: ENCUT=450.
Write INCAR for Step 1 with: GGA=PE.
Write INCAR for Step 1 with: NELM=200.
Write INCAR for Step 1 with: IBRION=-1.
Write INCAR for Step 1 with: NSW=0.
Write INCAR for Step 1 with: ISIF=2.
Write INCAR for Step 1 with: ISPIN=1.
Write INCAR for Step 1 with: EDIFF=1E-5.
Write INCAR for Step 1 with: ISMEAR=0.
Write INCAR for Step 1 with: SIGMA=0.05.
Write INCAR for Step 1 with: LWAVE=.T.
Write INCAR for Step 1 with: LCHARG=.T.
Write INCAR for Step 1 with: LREAL=Auto.
Write INCAR for Step 1 with: LPLANE=.TRUE.
Write INCAR for Step 1 with: KPAR=4.
Write INCAR for Step 1 with: NPAR=1.
Write INCAR for Step 1 with: NCORE=1.
Write INCAR for Step 1 with: ISTART=0.
Write INCAR for Step 1 with: ICHARG=2.
Run Step 1 VASP using: bash run_vasp.sh.
After Step 1 completes, save the INCAR used as INCAR1 by running: cp INCAR INCAR1.
Step 2 is an HSE06 hybrid-functional calculation starting from the Step 1 outputs.
Write INCAR for Step 2 using the provided parameter block, but ensure ICHARG is not larger than 10 by setting ICHARG=0.
Do not specify any magnetic moments in Step 2 INCAR.
Do not specify NBAND in Step 2 INCAR.
Do not specify NELECT in Step 2 INCAR.
Run Step 2 VASP using: bash run_vasp.sh.
After Step 2 completes, save the INCAR used as INCAR2 by running: cp INCAR INCAR2.
Step 3 extracts the band gap from the final calculation by running: python gap.py.
Report the band-gap value exactly as printed by gap.py.
