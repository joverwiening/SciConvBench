Work in the directory data/relax/Li2S.
Create a file named INCAR in data/relax/Li2S.
Write exactly the following lines into INCAR:
ALGO = Fast
EDIFF = 0.00015000000000000001
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*-0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05
Use the existing POSCAR, KPOINTS, and POTCAR files in the same directory as VASP inputs.
Run VASP by executing bash run_vasp.sh in data/relax/Li2S.
After VASP finishes, copy the INCAR used to a file named INCAR1 by executing cp INCAR INCAR1.
Extract the optimized total energy by executing python get_energy.py.
Return the optimized total energy exactly as printed by get_energy.py.
