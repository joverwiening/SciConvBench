Work in the directory data/bandgap/CdTe.
Use POSCAR, KPOINTS, and POTCAR from the current directory as VASP inputs for all steps.
Use run_vasp.sh to run VASP with MPI invoking vasp_std.

Step 1 (PBE ground state): create an INCAR suitable for a non-magnetic PBE single-point ground-state calculation.
Set ISPIN=1 in Step 1.
Set ISMEAR=0 and SIGMA=0.05 in Step 1.
Run bash run_vasp.sh for Step 1.
Copy the Step 1 INCAR to INCAR1 using cp INCAR INCAR1.

Step 2 (HSE): create a new INCAR for an HSE06 calculation starting fresh.
Set ISTART=0 in Step 2.
Set ICHARG=0 in Step 2.
Do not set any magnetic moments in Step 2.
Do not specify NBAND in Step 2.
Do not specify NELECT in Step 2.
Use the provided HSE parameter block from data.json domain_knowledge for all other Step 2 settings, except override any conflicting ISTART and ICHARG values to ISTART=0 and ICHARG=0.
Run bash run_vasp.sh for Step 2.
Copy the Step 2 INCAR to INCAR2 using cp INCAR INCAR2.

Step 3 (band gap extraction): run python gap.py after Step 2 completes.
Return the band-gap value exactly as printed by gap.py.
