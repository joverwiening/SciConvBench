Create one INCAR template to be used unchanged for Steps 1–3 (CO, surface, absorbed) to keep settings consistent.
Set ISPIN = 1 to disable spin polarization for all three relaxations.
Set ISIF = 2 to relax ions only without cell/shape optimization for all three relaxations.
Set IBRION = 1 for ionic relaxation.
Set POTIM = 0.2.
Set NSW = 200.
Set EDIFFG = -0.05.
Set ENCUT = 450.
Set ISMEAR = 1.
Set SIGMA = 0.2.
Add EDIFF = 1E-5.
Add PREC = Normal.
Add LREAL = Auto.
Add ALGO = Fast.
Add NELM = 120.
Add LWAVE = .FALSE.
Add LCHARG = .FALSE.
Use the same KPOINTS file provided in the case directory for all three steps.
Step 1: Write the INCAR with the above settings in the case directory, then run python op.py CO POTCAR-CO POSCAR-CO.
Step 2: Keep the same INCAR, then run python op.py surface POTCAR-Ptface POSCAR-Ptface.
Step 3: Keep the same INCAR, then run python op.py absorbed POTCAR-PtCO POSCAR-PtCO.
After each step, confirm the relaxation finished normally by checking that the corresponding OUTCAR/OSZICAR indicates ionic convergence or that NSW was reached.
Step 4: Run bash ./calc_absorption_energy.sh from the case directory after all three runs complete.
Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
