Work in the directory data/relax/LiCoO2.
Create a file named INCAR containing exactly the provided INCAR parameter block.
Run VASP using bash run_vasp.sh to generate the relaxation outputs including vasprun.xml.
Copy the INCAR actually used to a file named INCAR1 using cp INCAR INCAR1.
Run python get_energy.py to extract the optimized total energy from vasprun.xml.
Report the optimized total energy exactly as printed by get_energy.py.
If python get_energy.py cannot be executed or vasprun.xml is not available, do not report any numeric energy value.
