Use Quantum ESPRESSO pw.x to run a variable-cell relaxation (vc-relax) followed by an SCF total-energy calculation.
Use LDA pseudopotentials PseudoDojo/SR_v0.4.1/LDA_standard/nb.upf and PseudoDojo/SR_v0.4.1/LDA_standard/se.upf.
Assume a structure-retrieval capability is available and retrieve a primitive NbSe2 structure consistent with space group P6_3/mmc, layered, and 3 atoms per primitive cell.
Use the retrieved primitive structure as the starting configuration for vc-relax.
Set ecutwfc = 80 Ry.
Set ecutrho = 320 Ry.
Use an automatic Monkhorst-Pack k-point grid of 12x12x6 with half shift for both vc-relax and SCF.
Use metallic occupations with Marzari-Vanderbilt cold smearing with smearing='cold' and degauss = 0.02 Ry.
Set conv_thr = 1.0e-8.
Set etot_conv_thr = 1.0e-8.
Set forc_conv_thr = 1.0e-7.
Run vc-relax to relax both atomic positions and cell parameters starting from the retrieved primitive structure.
After vc-relax completes, run an SCF calculation on the vc-relaxed structure using consistent computational settings.
Report the fully relaxed structure (cell vectors and atomic positions) from vc-relax.
Report the final total energy from the SCF on the vc-relaxed structure.
