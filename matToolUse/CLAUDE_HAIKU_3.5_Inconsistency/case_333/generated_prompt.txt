Workflow Specification for ZnS Band Gap Calculation:

Step 1 — PBE Ground State
Create INCAR with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=2
ISPIN=1
NSW=100
ISIF=2
EDIFF=1E-5
EDIFFG=-0.01
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11

Execute the ground state calculation:
Write the INCAR file with the above parameters.
Run VASP using: bash run_vasp.sh
Save the INCAR as INCAR1: cp INCAR INCAR1

Step 2 — HSE Calculation
Create INCAR with the HSE parameters provided in the original specification.
Ensure ICHARG=0 (to calculate charge density from existing WAVECAR)
Run VASP using: bash run_vasp.sh
Save the INCAR as INCAR2: cp INCAR INCAR2

Step 3 — Band Gap Extraction
Run post-processing script: python gap.py
Report the band gap value exactly as printed by gap.py.
