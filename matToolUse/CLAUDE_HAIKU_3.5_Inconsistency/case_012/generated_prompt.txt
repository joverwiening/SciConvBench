Compute Mg-Ga Defect Properties Function

The function `compute_mg_ga_defect_properties()` is a Python implementation for computing Fermi level and formation energy diagram properties for the Mg-Ga system using Pymatgen.

Specification Details:
- No required input arguments
- Reads data from local file paths
- Parses `vasprun.xml.gz` files for defect entries and density of states
- Computes Fermi level at 300 K
- Creates multi-formation energy diagram at 1000 K
- Returns a dictionary with two properties:
  1. `Fermi_Level_Solution`: Fermi level as a float
  2. `Formation_Energy_Diagrams_Count`: Number of formation energy diagrams as an integer

Key Implementation Characteristics:
- Uses Pymatgen 2023.x parsing methods
- Extracts data from charge state subdirectories
- Implements statistical mechanics-based Fermi level calculation
- Handles file parsing and data extraction robustly
- Ensures positive Fermi level value
- Provides flexible, reusable scientific computing function for Mg-Ga defect analysis

The function is ready for use in computational materials science workflows involving defect and electronic structure calculations.
