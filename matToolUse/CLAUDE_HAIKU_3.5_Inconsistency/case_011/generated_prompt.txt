Compute defect-related properties for Mg-Ga-N system using Pymatgen.

The function `compute_defect_properties()` is a comprehensive implementation that:
- Loads stable entries from 'stable_entries_Mg_Ga_N.json'
- Collects elemental entries
- Loads bulk entry and extracts VBM from bulk vasprun.xml.gz
- Processes defect entries for charge states [-2, -1, 0, 1]
- Constructs a Phase Diagram and Formation Energy Diagram
- Computes competing phases at chemical potential limits
- Returns a dictionary with 'competing_phases_at_chempot_limits'

Key features:
- Handles compressed input files (vasprun.xml.gz, LOCPOT.gz)
- Flexible file path handling
- Robust entry collection and processing
- Comprehensive error handling
- Follows Pymatgen best practices for defect and phase diagram analysis

The function can be called with an optional file path, defaulting to the current working directory if not specified.
