Workflow for Carbon Band Gap Calculation:

Step 1 — PBE Ground State
Create INCAR with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=2
ISPIN=1
NSW=100
ISIF=2
EDIFF=1E-5
EDIFFG=-0.01
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.

Execute PBE ground state calculation:
bash run_vasp.sh

Save ground state INCAR:
cp INCAR INCAR1

Step 2 — HSE Calculation
Create INCAR with HSE parameters from domain knowledge:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=11
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Execute HSE calculation:
bash run_vasp.sh

Save HSE INCAR:
cp INCAR INCAR2

Step 3 — Band Gap Extraction
Extract band gap:
python gap.py

The final output will be the band gap value printed by gap.py.
