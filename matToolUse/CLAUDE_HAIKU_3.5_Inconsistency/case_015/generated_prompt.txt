Mg_Ga Defect Properties Computation Function

The Python function `compute_defect_properties()` is designed to:
- Load the GaN crystal structure from 'GaN.vasp'
- Create a substitutional Mg defect at the Ga site (index 0)
- Compute defect entries for charge states [-2, -1, 0, 1]
- Calculate Freysoldt corrections using a dielectric constant of 14
- Check defect name consistency across charge states
- Collect comprehensive plot-data metadata

Key Features:
- Uses Pymatgen for defect and structure handling
- Supports gzipped input files (vasprun.xml.gz, LOCPOT.gz)
- Returns a dictionary with:
  1. Defect name consistency boolean
  2. Defect entry objects
  3. Detailed plot-data metadata

The implementation meets all specified requirements for defect property computation in the Mg_Ga substitutional defect system.
