Create INCAR file with specified parameters
Run VASP using run_vasp.sh script
Copy INCAR to INCAR1
Extract optimized total energy using get_energy.py
The specific steps are:

1. Create INCAR file with the exact parameters provided in the task description
2. Execute `bash run_vasp.sh` to run the VASP structural relaxation
3. Copy INCAR to INCAR1 using `cp INCAR INCAR1`
4. Run `python get_energy.py` to extract the optimized total energy
5. Report the total energy printed by get_energy.py

Note: The task specifies NSW = 0, which means no ionic steps will be performed, so this appears to be more of an energy calculation than a full structural relaxation. The script will run and extract the total energy of the initial structure.
