Workflow for Ga2O3 Band Gap Calculation:

Step 1 — PBE Ground State
Create INCAR with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=2
ISPIN=1
NSW=100
ISIF=2
EDIFF=1E-5
EDIFFG=-0.01
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto

Execute the workflow steps:
1. Write the INCAR file with the above parameters
2. Run VASP using: bash run_vasp.sh
3. Save a copy of INCAR as INCAR1: cp INCAR INCAR1

Step 2 — HSE Calculation
Create INCAR with the provided HSE parameters, ensuring:
- ICHARG is 11 (to use existing charge density)
- No magnetic moment specification
- No NBAND or NELECT parameters

Execute the workflow steps:
1. Write the HSE INCAR file
2. Run VASP using: bash run_vasp.sh
3. Save a copy of INCAR as INCAR2: cp INCAR INCAR2

Step 3 — Band Gap Extraction
Run post-processing script: python gap.py

The final output will be the band gap value printed by gap.py.
