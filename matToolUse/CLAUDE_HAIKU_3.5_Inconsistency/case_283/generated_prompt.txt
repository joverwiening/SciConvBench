Create INCAR file with specified parameters:
```
cp /dev/null INCAR
cat > INCAR << EOF
ALGO = Fast
EDIFF = 0.0002
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 15*3.445 16*0.22
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05
EOF

cp INCAR INCAR1

bash run_vasp.sh

python get_energy.py
```

The final step will output the optimized total energy as requested.
