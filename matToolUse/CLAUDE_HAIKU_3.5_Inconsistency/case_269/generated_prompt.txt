Specification for Al Structural Relaxation:

Create INCAR file with the following parameters:
ALGO = Fast
EDIFF = 5e-05
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 26*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05

Execute the following commands in sequence:
1. Copy INCAR to INCAR1
2. Run VASP using run_vasp.sh
3. Extract total energy using get_energy.py
