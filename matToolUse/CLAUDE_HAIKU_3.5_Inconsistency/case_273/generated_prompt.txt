1. Create INCAR file with the specified parameters:
```
cp /dev/null INCAR
cat > INCAR << 'EOF'
ALGO = Fast
EDIFF = 0.00025
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LDAU = .TRUE.
LDAUJ = 0 0 0
LDAUL = 0 2 0
LDAUPRINT = 1
LDAUTYPE = 2
LDAUU = 0 5.3 0
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 7*0.009000000000000001 8*3.48 24*0.127
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
EOF
```

2. Run VASP:
```
bash run_vasp.sh
```

3. Preserve INCAR copy:
```
cp INCAR INCAR1
```

4. Extract optimized total energy:
```
python get_energy.py
```
