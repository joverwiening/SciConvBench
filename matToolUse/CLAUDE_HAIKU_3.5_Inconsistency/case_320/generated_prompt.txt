Specification for GaAs Band Gap Calculation Workflow:

Step 1 — PBE Ground State Preparation
Create INCAR with the following parameters:
PREC=Normal
ENCUT=450
NELM=100
IBRION=2
ISPIN=1
NSW=50
ISIF=2
EDIFF=1E-5
EDIFFG=-0.01
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto

Execute the ground state calculation:
Run VASP using the command: bash run_vasp.sh
Save the INCAR: cp INCAR INCAR1

Step 2 — HSE Calculation
Create INCAR with the provided HSE parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Execute the HSE calculation:
Run VASP using the command: bash run_vasp.sh
Save the INCAR: cp INCAR INCAR2

Step 3 — Band Gap Extraction
Run band gap extraction script:
Execute command: python gap.py

The final output will be the band gap value printed by gap.py.
