Compute chemical potential limits and defect chemical system properties for the Ga-N defect system.

Reads input files for GaN structure and stable entries to generate a Formation Energy Diagram and extract defect-related properties.

Returns a dictionary containing:
- Number of facets in the formation energy diagram
- Chemical system of defects
- Chemical formula of bulk material

The function uses Pymatgen to:
- Read the GaN structure from 'GaN.vasp'
- Load stable entries from 'stable_entries_Mg_Ga_N.json'
- Create a Formation Energy Diagram
- Compute defect-related properties
- Return results as a dictionary

Assumes a valence band maximum (VBM) of 0.5 for semiconductor systems.
