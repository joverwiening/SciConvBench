Specification for CO Adsorption Energy Calculation on Pd Surface:

Prepare and execute a four-step VASP calculation workflow for computing CO adsorption energy.

Step 1: CO Molecule Optimization
Create an INCAR file with the following parameters:
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 100
ISTART = 0
ICHARG = 2

Execute optimization using:
python op.py CO POTCAR-CO POSCAR-CO

Step 2: Clean Pd Surface Optimization
Use the same INCAR parameters as Step 1.
Execute optimization using:
python op.py surface POTCAR-Pdface POSCAR-Pdface

Step 3: Adsorbed System (PdCO) Optimization
Use the same INCAR parameters as previous steps.
Execute optimization using:
python op.py absorbed POTCAR-PdCO POSCAR-PdCO

Step 4: Adsorption Energy Calculation
Run the energy extraction script:
bash ./calc_absorption_energy.sh

The final output will be the computed adsorption energy printed by the script.
