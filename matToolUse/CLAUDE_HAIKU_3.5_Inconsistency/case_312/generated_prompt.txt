Specification for BN Band Gap Calculation:

Step 1 — PBE Ground State Calculation
Create an INCAR file with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=2
ISPIN=1
NSW=100
ISIF=2
EDIFF=1E-5
EDIFFG=-0.01
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto

Execute the workflow steps:
1. Write the INCAR file with the specified parameters.
2. Run VASP using `bash run_vasp.sh`.
3. Save a copy of the INCAR as `INCAR1`.

Step 2 — HSE Calculation
Create an INCAR file with the parameters provided in the original specification:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast

Execute the workflow steps:
1. Write the INCAR file with the specified parameters.
2. Run VASP using `bash run_vasp.sh`.
3. Save a copy of the INCAR as `INCAR2`.

Step 3 — Band Gap Extraction
Run the post-processing script:
`python gap.py`

The final output will be the band gap value printed by the `gap.py` script.
