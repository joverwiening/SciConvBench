Specification for CO Molecule Optimization INCAR:

Create an INCAR file with the following contents:
Write the file to the current directory as `INCAR`.
Ensure the file contains exactly these lines:
```
SYSTEM = CO molecule optimization
PREC = Normal
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
EDIFFG = -0.05
POTIM = 0.2
SIGMA = 0.2
ISTART = 0
ICHARG = 2
NSW = 100
NELMIN = 5
NELM = 100
```

Next steps:
Run the command `python op.py CO POTCAR-CO POSCAR-CO` to execute the CO molecule optimization calculation.
