Workflow Specification for SiC Band Gap Calculation:

Step 1 — PBE Ground State
Create INCAR with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto

Execute workflow steps:
1. Write INCAR for PBE ground state
2. Run VASP using run_vasp.sh
3. Save a copy of INCAR as INCAR1

Step 2 — HSE Calculation
Create INCAR with the provided HSE parameters
1. Write INCAR for HSE calculation
2. Run VASP using run_vasp.sh
3. Save a copy of INCAR as INCAR2

Step 3 — Band Gap Extraction
Run gap.py to extract band gap value

Input files to use:
- POSCAR: Structural input
- KPOINTS: K-point sampling
- POTCAR: Pseudopotential data

Final output will be the band gap value printed by gap.py.
