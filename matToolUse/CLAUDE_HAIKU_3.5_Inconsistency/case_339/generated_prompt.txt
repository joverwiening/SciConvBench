Specification for CO Molecule Optimization in VASP:

Create an INCAR file in the CO calculation directory with the following contents:
```
SYSTEM = CO molecule optimization
PREC = Normal
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
EDIFFG = -0.05
POTIM = 0.2
SIGMA = 0.2
NELMIN = 4
NELM = 100
NSW = 50
ISTART = 0
ICHARG = 2
```

Execute the optimization by running:
```
python op.py CO POTCAR-CO POSCAR-CO
```

Execution steps:
1. Ensure current working directory is `data/absorptionE5/RhO2`
2. Create the INCAR file with the specified parameters
3. Run the optimization script
4. Verify successful completion by checking the output files in the `CO` subdirectory

Next step will be to prepare the INCAR for the clean surface optimization.
