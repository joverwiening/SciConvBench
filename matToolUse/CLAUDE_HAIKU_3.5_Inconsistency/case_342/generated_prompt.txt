Specification for CO Adsorption Energy Calculation on Pt Surface:

Prepare and execute a four-step VASP calculation workflow for CO adsorption energy determination.

Step 1: CO Molecule Optimization
Create an INCAR file with the following parameters:
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 100
ISTART = 0
ICHARG = 2

Execute: python op.py CO POTCAR-CO POSCAR-CO

Step 2: Clean Pt Surface Optimization
Use the same INCAR parameters as Step 1.
Execute: python op.py surface POTCAR-Ptface POSCAR-Ptface

Step 3: CO-Adsorbed Pt System Optimization
Use the same INCAR parameters as previous steps.
Execute: python op.py absorbed POTCAR-PtCO POSCAR-PtCO

Step 4: Adsorption Energy Calculation
Execute: bash ./calc_absorption_energy.sh

The final output will be the computed adsorption energy of CO on the Pt surface.
