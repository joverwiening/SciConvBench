Create INCAR file with specified parameters:
cp INCAR1 INCAR
echo "ALGO = Fast
EDIFF = 0.0048000000000000004
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 6
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 95*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05" > INCAR

Run VASP relaxation:
bash run_vasp.sh

Preserve INCAR copy:
cp INCAR INCAR1

Extract optimized total energy:
python get_energy.py

Note: The actual total energy will be printed by the `get_energy.py` script when executed. The specific numerical value depends on the VASP relaxation results for this specific Li7La3Zr2O12 structure.
