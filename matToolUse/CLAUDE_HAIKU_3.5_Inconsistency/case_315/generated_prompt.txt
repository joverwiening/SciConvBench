Specification for CdS Band Gap Calculation:

Step 1 — PBE Ground State Calculation
Create INCAR with the following parameters:
PREC=Normal
ENCUT=450
NELM=100
IBRION=2
ISPIN=1
NSW=50
ISIF=2
EDIFF=1E-5
EDIFFG=-0.01
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto

Execute workflow steps:
1. Write the above INCAR file
2. Run VASP using `bash run_vasp.sh`
3. Save a copy of INCAR as INCAR1 using `cp INCAR INCAR1`

Step 2 — HSE Calculation
Create INCAR with the provided HSE parameters, ensuring:
- ICHARG is 0
- No magnetic moment specification
- No NBAND or NELECT parameters
- Use the parameters from the domain knowledge block in data.json

Execute workflow steps:
1. Write the HSE INCAR file
2. Run VASP using `bash run_vasp.sh`
3. Save a copy of INCAR as INCAR2 using `cp INCAR INCAR2`

Step 3 — Band Gap Extraction
Run post-processing script: `python gap.py`

Output: Band gap value printed by `gap.py`
