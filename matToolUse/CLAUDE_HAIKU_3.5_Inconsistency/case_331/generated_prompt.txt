Workflow for SnO2 Band Gap Calculation:

Step 1 — PBE Ground State
Create INCAR with the following contents:
```
PREC=Normal
ENCUT=450
NELM=100
IBRION=2
ISPIN=1
NSW=50
ISIF=3
EDIFF=1E-4
EDIFFG=-0.01
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
```

Execute the workflow:
1. Write the INCAR file with the above parameters
2. Run VASP:
```
bash run_vasp.sh
```
3. Save a copy of the INCAR:
```
cp INCAR INCAR1
```

Step 2 — HSE Calculation
Create INCAR with the provided HSE parameters, ensuring:
- `ICHARG=0`
- No magnetic moment specification
- No `NBAND` or `NELECT` parameters

Execute the HSE calculation:
1. Write the HSE INCAR file
2. Run VASP:
```
bash run_vasp.sh
```
3. Save a copy of the INCAR:
```
cp INCAR INCAR2
```

Step 3 — Band Gap Extraction
Run the post-processing script:
```
python gap.py
```

The final output will be the band gap value printed by `gap.py`.
