Create a VASP input file named INCAR for aluminum structural relaxation using the provided parameters.
Set ALGO to Fast for efficient electronic convergence.
Set EDIFF to 5e-05 for electronic convergence criterion.
Set ENCUT to 520.0 eV for plane wave cutoff energy.
Set IBRION to -1 for ionic relaxation algorithm.
Set ISIF to 3 to relax ionic positions, cell shape, and cell volume.
Set ISMEAR to -5 for tetrahedron method with Blöchl corrections.
Set ISPIN to 2 for spin-polarized calculation.
Set LASPH to .TRUE. for non-spherical contributions from gradient corrections.
Set LORBIT to 11 for DOSCAR and lm-decomposed PROCAR files.
Set LREAL to Auto for real space projection.
Set LWAVE to .FALSE. to not write WAVECAR file.
Set MAGMOM to 26*-0.0 for initial magnetic moments on all atoms.
Set NELM to 100 for maximum number of electronic steps.
Set NSW to 0 for number of ionic steps.
Set PREC to Accurate for precision level.
Set SIGMA to 0.05 for broadening in eV.
Execute the VASP calculation using the run_vasp.sh script.
Copy the INCAR file to INCAR1 to preserve the used parameters.
Extract the optimized total energy using the get_energy.py script.
Return the final optimized total energy value as output by get_energy.py.
