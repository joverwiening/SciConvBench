Create INCAR files for three VASP geometry optimization calculations with the following parameters:
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 150

Execute Step 1 by writing the INCAR file and running: python op.py CO POTCAR-CO POSCAR-CO

Execute Step 2 by using the same INCAR file and running: python op.py surface POTCAR-PdO2face POSCAR-PdO2face

Execute Step 3 by using the same INCAR file and running: python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO

Execute Step 4 by running: bash ./calc_absorption_energy.sh

Return the adsorption energy value exactly as printed by the calc_absorption_energy.sh script.
