Compute the electronic band gap of CdS using VASP following a two-step workflow.
Use the provided files POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh as inputs.
Create an INCAR file for PBE ground-state calculation using reasonable parameters based on best practices.
Run VASP using bash run_vasp.sh for the PBE ground-state calculation.
Save the PBE INCAR as INCAR1 using cp INCAR INCAR1.
Create a new INCAR file for HSE calculation using the specified parameter block from data.json domain_knowledge.
Set ICHARG to a value not larger than 10 since starting from existing WAVECAR.
Do not specify magnetic moments, NBAND, or NELECT parameters in the HSE INCAR.
Run VASP again using bash run_vasp.sh for the HSE calculation.
Save the HSE INCAR as INCAR2 using cp INCAR INCAR2.
Run python gap.py to extract the band gap value.
Return the band gap value exactly as printed by gap.py.
