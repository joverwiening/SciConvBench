Create the VASP input file INCAR for structure optimization using the specified parameter block.
Run VASP using the command bash run_vasp.sh with vasp_std executable.
Copy the INCAR file to INCAR1 after the calculation using cp INCAR INCAR1.
Extract the optimized total energy using python get_energy.py.
Return the optimized total energy exactly as printed by get_energy.py.
The calculation performs ion-only, non-spin-polarized relaxation with fixed cell for Li7La3Zr2O12 structure.
Use the provided POSCAR, KPOINTS, and POTCAR files as inputs.
The INCAR parameters include ALGO=Fast, EDIFF=0.0048000000000000004, ENCUT=520.0, IBRION=2, ISIF=3, ISMEAR=-5, ISPIN=2, LASPH=.TRUE., LMAXMIX=6, LORBIT=11, LREAL=Auto, LWAVE=.FALSE., MAGMOM=95*0.0, NELM=100, NSW=99, PREC=Accurate, SIGMA=0.05.
