Create the VASP input file INCAR for structure optimization using the specified parameter block.
Run VASP using the provided launcher script with the command bash run_vasp.sh.
The run_vasp.sh script runs vasp_std with MPI for this case.
Preserve a copy of the INCAR file as INCAR1 using the command cp INCAR INCAR1.
Extract the optimized total energy using the provided post-processing script with the command python get_energy.py.
Return the optimized total energy exactly as printed by get_energy.py.
The INCAR file must contain these exact parameters: ALGO = Fast, EDIFF = 0.0005, ENCUT = 520.0, IBRION = -1, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 4, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 39*0.0, NELM = 100, NSW = 0, PREC = Accurate, SIGMA = 0.05.
The working directory is data/relax/LiNbO3.
Use the existing files POSCAR, KPOINTS, and POTCAR as inputs for the VASP calculation.
