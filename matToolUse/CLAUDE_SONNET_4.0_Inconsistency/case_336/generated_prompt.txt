Create INCAR files for three VASP geometry optimization calculations with the following parameters:
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 200
Use NSW = 200 for all three calculations as a reasonable value for potentially non-ideal initial structures.
Apply these same INCAR parameters consistently across all three geometry optimization steps (CO molecule, clean surface, and adsorbed system).
Execute Step 1 by writing the INCAR file and running "python op.py CO POTCAR-CO POSCAR-CO".
Execute Step 2 by using the same INCAR file and running "python op.py surface POTCAR-Rhface POSCAR-Rhface".
Execute Step 3 by using the same INCAR file and running "python op.py absorbed POTCAR-RhCO POSCAR-RhCO".
Execute Step 4 by running "bash ./calc_absorption_energy.sh" to compute and output the final adsorption energy.
Return the adsorption energy value exactly as printed by the calc_absorption_energy.sh script.
