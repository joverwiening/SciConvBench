Compute the electronic band gap of CdTe using VASP following a two-step workflow: PBE ground state followed by HSE calculation.
Work in the directory data/bandgap/CdTe.
Use the provided files POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh as inputs.
Create an INCAR file for PBE ground-state calculation using reasonable parameters based on best practices.
Run VASP using bash run_vasp.sh.
Save the Step 1 INCAR as INCAR1 using cp INCAR INCAR1.
Create a new INCAR for HSE calculation using the parameter block from data.json domain_knowledge.
Set ICHARG to a value not larger than 10 since starting hybrid functional calculation from existing WAVECAR requires charge density calculation.
Do not specify magnetic moments, NBAND, or NELECT parameters.
Run VASP again using bash run_vasp.sh.
Save the Step 2 INCAR as INCAR2 using cp INCAR INCAR2.
Run python gap.py to extract the band gap.
Return the band gap value exactly as printed by gap.py.
