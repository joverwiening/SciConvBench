Perform a variable-cell relaxation (vc-relax) calculation on Bi2Te3 using Quantum ESPRESSO.
Use the structure retrieval tool to obtain a primitive Bi2Te3 structure with space group R-3m and 5 atoms per primitive cell.
Use LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard: bi.upf and te.upf.
Set ecutwfc to 4 times the maximum recommended cutoff from the pseudopotential files.
Use an automatic Monkhorst-Pack k-point grid with half shift and density of approximately 0.03 Å⁻¹ spacing in reciprocal space.
Set etot_conv_thr = 1.0e-8 for energy convergence.
Set forc_conv_thr = 1.0e-7 for force convergence.
Set conv_thr = 1.0e-8 for wavefunction convergence.
Allow all cell parameters and atomic positions to relax during vc-relax.
After vc-relax completes, run a self-consistent field calculation on the relaxed structure using the same computational parameters.
Return the fully relaxed crystal structure with optimized lattice parameters and atomic positions.
Return the final total energy from the SCF calculation on the relaxed structure.
