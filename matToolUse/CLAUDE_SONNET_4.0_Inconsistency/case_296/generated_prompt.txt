Create a VASP input file named INCAR for structural relaxation of MgO with the specified parameters.
Set ALGO to Fast for efficient electronic optimization.
Set EDIFF to 0.0001 for electronic convergence criterion.
Set ENCUT to 520.0 eV for plane wave cutoff energy.
Set IBRION to -1 for ionic relaxation algorithm.
Set ISIF to 3 to optimize both ionic positions and cell shape/volume simultaneously.
Set ISMEAR to -5 for tetrahedron method with Blöchl corrections.
Set ISPIN to 2 for spin-polarized calculation.
Set LASPH to .TRUE. to include non-spherical contributions from gradient corrections.
Set LORBIT to 11 for DOSCAR and lm-decomposed PROCAR files.
Set LREAL to Auto for real space projection.
Set LWAVE to .FALSE. to not write WAVECAR file.
Set MAGMOM to 23*0.0 for initial magnetic moments of all atoms.
Set NELM to 100 for maximum number of electronic steps.
Set NSW to 0 for number of ionic steps.
Set PREC to Accurate for high precision calculation.
Set SIGMA to 0.05 for smearing width.
Execute the VASP calculation using the command bash run_vasp.sh.
Copy the INCAR file to INCAR1 using the command cp INCAR INCAR1.
Extract the optimized total energy using the command python get_energy.py.
Return the optimized total energy value exactly as printed by the get_energy.py script.
