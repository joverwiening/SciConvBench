Compute the adsorption energy of CO on RuO2 surface using VASP with a four-step workflow.
Use the provided files in the data/absorptionE7/RuO2 directory as inputs.
Apply the following INCAR parameter constraints consistently across all geometry optimization steps: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2.
Set NSW = 100 for all three geometry optimization calculations to handle potentially non-ideal initial structures.
Do not use spin polarization (ISPIN = 1).
Do not optimize the unit cell (ISIF = 2).
Use loose force convergence criterion of 0.05 eV/Å (EDIFFG = -0.05).
Keep ENCUT relatively low at 450 eV.
Step 1: Write INCAR file with the specified constraints and NSW = 100, then run "python op.py CO POTCAR-CO POSCAR-CO" to optimize the CO molecule.
Step 2: Use the same INCAR file, then run "python op.py surface POTCAR-RuO2face POSCAR-RuO2face" to optimize the clean RuO2 surface.
Step 3: Use the same INCAR file, then run "python op.py absorbed POTCAR-RuO2CO POSCAR-RuO2CO" to optimize the CO-adsorbed RuO2 system.
Step 4: Run "bash ./calc_absorption_energy.sh" to compute and print the adsorption energy from the three total energies.
Return the adsorption energy value exactly as printed by the calc_absorption_energy.sh script.
