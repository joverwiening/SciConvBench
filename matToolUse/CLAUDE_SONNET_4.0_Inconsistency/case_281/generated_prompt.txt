Create a VASP input file named INCAR with the following parameters: ALGO = Fast, EDIFF = 0.0001, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 4, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 35*2.758, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Run VASP using the command: bash run_vasp.sh.
Copy the INCAR file to INCAR1 using the command: cp INCAR INCAR1.
Extract the optimized total energy using the command: python get_energy.py.
Return the optimized total energy value exactly as printed by the get_energy.py script.
