Create a VASP input file named INCAR with the specified parameters for full structural relaxation of Li2S.
Write the INCAR file containing ALGO = Fast, EDIFF = 0.00015000000000000001, ENCUT = 520.0, IBRION = -1, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 23*-0.0, NELM = 100, NSW = 0, PREC = Accurate, and SIGMA = 0.05.
Execute the VASP calculation by running the command bash run_vasp.sh.
Copy the INCAR file to INCAR1 using the command cp INCAR INCAR1.
Extract and report the optimized total energy by running python get_energy.py.
The final output should be the exact total energy value as printed by the get_energy.py script.
