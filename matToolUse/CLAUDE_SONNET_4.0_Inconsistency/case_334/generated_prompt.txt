Create INCAR files for three VASP geometry optimization calculations with the following parameters.
Set EDIFFG = -0.05 for force convergence criterion.
Set ENCUT = 450 for plane-wave cutoff energy.
Set IBRION = 1 for ionic relaxation algorithm.
Set ISIF = 2 to relax atomic positions only without cell optimization.
Set ISMEAR = 1 for Methfessel-Paxton smearing.
Set ISPIN = 1 to disable spin polarization.
Set POTIM = 0.2 for ionic step size.
Set SIGMA = 0.2 for smearing width.
Set NSW = 200 to allow sufficient ionic steps for potentially non-ideal initial structures.
Add standard VASP parameters PREC = Accurate and LREAL = Auto.
Use the same INCAR for all three geometry optimization steps.
Execute Step 1 by writing the INCAR file and running "python op.py CO POTCAR-CO POSCAR-CO".
Execute Step 2 by running "python op.py surface POTCAR-Irface POSCAR-Irface".
Execute Step 3 by running "python op.py absorbed POTCAR-IrCO POSCAR-IrCO".
Execute Step 4 by running "bash ./calc_absorption_energy.sh".
Return the adsorption energy value exactly as printed by the calc_absorption_energy.sh script.
