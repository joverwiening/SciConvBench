Compute the electronic band gap of SiC using VASP following a two-step workflow: PBE ground state followed by HSE calculation.
Use the provided files POSCAR, KPOINTS, POTCAR, and gap.py as inputs.
Create an INCAR file for PBE ground-state calculation using reasonable parameters based on best practices.
Run VASP using the command "bash run_vasp.sh".
Save the Step 1 INCAR as INCAR1 using "cp INCAR INCAR1".
Create a new INCAR for HSE calculation using the specified parameter block from data.json domain_knowledge.
Set ICHARG to a value no larger than 10 since starting hybrid functional calculation from existing WAVECAR requires charge density calculation.
Do not specify magnetic moments in the HSE INCAR.
Do not specify NBAND or NELECT parameters in the HSE INCAR.
Run VASP again for the HSE step using "bash run_vasp.sh".
Save the Step 2 INCAR as INCAR2 using "cp INCAR INCAR2".
Extract the band gap by running "python gap.py".
Return the band gap value exactly as printed by gap.py.
