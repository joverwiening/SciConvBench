Compute the adsorption energy of CO on the IrO2 surface using VASP with a four-step process.
Use the provided files in the data/absorptionE6/IrO2 directory as inputs.
Set NSW = 200 for all geometry optimization calculations to handle potentially non-ideal initial structures.
Apply these INCAR parameters consistently across all three optimization steps: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2.
Do not use spin polarization (ISPIN = 1).
Do not optimize the unit cell (ISIF = 2).
Use a loose force convergence criterion of 0.05 eV/Å (EDIFFG = -0.05).
Step 1: Write INCAR file with the specified constraints and NSW = 200, then run "python op.py CO POTCAR-CO POSCAR-CO" to optimize the CO molecule.
Step 2: Use the same INCAR file, then run "python op.py surface POTCAR-IrO2face POSCAR-IrO2face" to optimize the clean IrO2 surface.
Step 3: Use the same INCAR file, then run "python op.py absorbed POTCAR-IrO2CO POSCAR-IrO2CO" to optimize the CO-adsorbed IrO2 system.
Step 4: Run "bash ./calc_absorption_energy.sh" to compute and output the adsorption energy from the three total energies.
Return the adsorption energy exactly as printed by the calc_absorption_energy.sh script.
