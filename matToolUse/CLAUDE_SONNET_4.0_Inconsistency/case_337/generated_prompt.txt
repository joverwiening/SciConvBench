Compute the adsorption energy of CO on the OsO2 surface using VASP with a four-step process.
Use the provided POSCAR and POTCAR files for each step.
Create INCAR files with the specified parameter constraints for all geometry optimization steps.
Set EDIFFG = -0.05 for force convergence criterion.
Set ENCUT = 450 for the plane-wave cutoff.
Set IBRION = 1 for ionic relaxation algorithm.
Set ISIF = 2 to prevent cell optimization.
Set ISMEAR = 1 for Methfessel-Paxton smearing.
Set ISPIN = 1 to disable spin polarization.
Set POTIM = 0.2 for ionic step size.
Set SIGMA = 0.2 for smearing width.
Set NSW = 150 for maximum number of ionic steps.
Step 1: Write INCAR file and run "python op.py CO POTCAR-CO POSCAR-CO" to optimize the CO molecule.
Step 2: Use the same INCAR file and run "python op.py surface POTCAR-OsO2face POSCAR-OsO2face" to optimize the clean OsO2 surface.
Step 3: Use the same INCAR file and run "python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO" to optimize the CO-adsorbed OsO2 system.
Step 4: Run "bash ./calc_absorption_energy.sh" to compute and output the adsorption energy from the three total energies.
Return the adsorption energy value exactly as printed by the calc_absorption_energy.sh script.
