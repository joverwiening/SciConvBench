Compute the electronic band gap of Ga2O3 using VASP following a three-step workflow.
Use the provided files POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh as inputs.
Create an INCAR file for PBE ground-state calculation in Step 1 using reasonable parameters based on best practices.
Run VASP using bash run_vasp.sh for the PBE calculation.
Save the Step 1 INCAR as INCAR1 using cp INCAR INCAR1.
Create a new INCAR file for HSE calculation in Step 2 using the specified parameter block from data.json domain_knowledge.
Set ICHARG to a value not larger than 10 since starting hybrid functional calculation from existing WAVECAR requires charge density calculation.
Do not specify magnetic moments in the HSE INCAR.
Do not specify NBAND and NELECT parameters in the HSE INCAR.
Run VASP again using bash run_vasp.sh for the HSE calculation.
Save the Step 2 INCAR as INCAR2 using cp INCAR INCAR2.
Run python gap.py to extract the band gap value.
Return the band gap value exactly as printed by gap.py.
