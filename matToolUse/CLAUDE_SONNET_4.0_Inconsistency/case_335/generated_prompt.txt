Create INCAR file with the following parameters for all three geometry optimization steps (CO molecule, clean surface, and adsorbed system):
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 200
PREC = Normal
ALGO = Normal

Execute Step 1 by writing the INCAR file and running: python op.py CO POTCAR-CO POSCAR-CO

Execute Step 2 by using the same INCAR file and running: python op.py surface POTCAR-PtO2face POSCAR-PtO2face

Execute Step 3 by using the same INCAR file and running: python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO

Execute Step 4 by running: bash ./calc_absorption_energy.sh

Return the adsorption energy value exactly as printed by the calc_absorption_energy.sh script.
