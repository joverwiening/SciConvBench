Create an INCAR file for PBE ground-state calculation using standard parameters for electronic structure calculations.
Set PREC to Normal for balanced accuracy and efficiency.
Set ENCUT to 450 eV for the plane-wave cutoff energy.
Set NELM to 500 for maximum electronic steps.
Set IBRION to -1 for no ionic relaxation.
Set ISPIN to 1 for non-spin-polarized calculation.
Set NSW to 0 for no ionic steps.
Set ISIF to 2 for stress tensor calculation.
Set EDIFF to 1E-5 for electronic convergence criterion.
Set EDIFFG to -5E-3 for ionic convergence criterion.
Set ISTART to 0 to start from scratch.
Set ICHARG to 2 to calculate charge density from initial wave functions.
Set ISMEAR to 0 for Gaussian smearing.
Set SIGMA to 0.05 for smearing width.
Set LWAVE to .TRUE. to write WAVECAR file.
Set LCHARG to .TRUE. to write CHGCAR file.
Set LREAL to Auto for real-space projection.
Set LPLANE to .TRUE. for plane-wise data distribution.
Set NPAR to 1 for parallelization over bands.
Set KPAR to 4 for k-point parallelization.
Set NCORE to 1 for parallelization over plane-wave coefficients.
Run VASP using the command bash run_vasp.sh.
Save the INCAR file as INCAR1 using cp INCAR INCAR1.
Create a new INCAR file for HSE calculation with the provided parameter block from data.json.
Modify ICHARG to 0 in the HSE INCAR to calculate charge density from existing WAVECAR.
Do not specify MAGMOM, NBAND, or NELECT parameters in the HSE INCAR.
Run VASP again for HSE calculation using bash run_vasp.sh.
Save the HSE INCAR file as INCAR2 using cp INCAR INCAR2.
Run the post-processing script using python gap.py.
Return the band-gap value exactly as printed by gap.py.
