Compute the adsorption energy of CO on RhO2 surface using VASP with a four-step workflow.
Use the provided files in the data/absorptionE5/RhO2 directory as inputs.
Set NSW = 200 for all geometry optimization steps to handle potentially non-ideal initial structures.
Apply these INCAR parameters consistently across all three optimization steps: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2.
Use no spin polarization (ISPIN = 1) for all calculations.
Do not optimize unit cells (ISIF = 2) for any calculations.
Use loose force convergence criterion of 0.05 eV/Å (EDIFFG = -0.05).
Step 1: Write INCAR file with the specified constraints and NSW = 200, then run "python op.py CO POTCAR-CO POSCAR-CO" to optimize the CO molecule.
Step 2: Use the same INCAR file, then run "python op.py surface POTCAR-RhO2face POSCAR-RhO2face" to optimize the clean RhO2 surface.
Step 3: Use the same INCAR file, then run "python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO" to optimize the CO-adsorbed RhO2 system.
Step 4: Run "bash ./calc_absorption_energy.sh" to extract total energies from the three OSZICAR files and compute the adsorption energy.
Return the adsorption energy value exactly as printed by the calc_absorption_energy.sh script.
