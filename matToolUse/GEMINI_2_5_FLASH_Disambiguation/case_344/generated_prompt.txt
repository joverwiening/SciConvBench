The goal is to compute the transition-state energy barrier for the hydrogenation of ethylene on single-metal or alloy surfaces using the VASP NEB workflow.
The process consists of five steps.

Step 1: Optimize the initial state structure of the reaction.
The INCAR file for initial state relaxation is:
SYSTEM = IS_FS_relaxation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
IBRION = 1
NSW = 100
POTIM = 0.2
ISIF = 2
NPAR = 1
LREAL = Auto
Execute the initial state relaxation by running: python op.py IS POTCARagpd IS1POSCAR

Step 2: Optimize the final state structure of the reaction.
The INCAR file for final state relaxation is the same as for initial state relaxation.
Execute the final state relaxation by running: python op.py FS POTCARagpd FS1POSCAR

Step 3: Interpolate intermediate images using ASE.
No INCAR file is required for this step.
Execute the interpolation by running: python nebmake.py
This action creates the NEB image folders from 00 to 05.

Step 4: Perform the NEB calculation using the interpolated images.
The INCAR file for the NEB calculation is:
SYSTEM = NEB_calculation
ISTART = 0
ICHARG = 2
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
ISMEAR = 1
SIGMA = 0.2
ISPIN = 1
IBRION = 3
NSW = 100
POTIM = 0
ISIF = 2
NPAR = 1
LREAL = Auto
IMAGES = 4
IOPT = 7
SPRING = -5
Execute the NEB calculation by running: python op2.py ./

Step 5: Extract energies and determine the reaction barrier.
No INCAR file is required for this step.
Execute the barrier extraction by running: bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'
The output of this step will be the reaction-barrier value.
