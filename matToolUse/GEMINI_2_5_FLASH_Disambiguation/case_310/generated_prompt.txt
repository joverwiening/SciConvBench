The current working directory is data/bandgap/AlN.
The POSCAR file is 'POSCAR'.
The KPOINTS file is 'KPOINTS'.
The POTCAR file is 'POTCAR'.
Step 1: Perform a PBE ground-state calculation.
Create an INCAR file with the following parameters: PREC = Normal, ENCUT = 450, EDIFF = 1E-5, ISMEAR = 0, SIGMA = 0.05, IBRION = -1, NSW = 0, ISIF = 2, NELM = 100, ISPIN = 1, ALGO = Normal, LCHARG = .T., LWAVE = .T., LREAL = Auto, NPAR = 1, KPAR = 4, NCORE = 1.
Execute the VASP calculation using the command: bash run_vasp.sh.
Save the INCAR file used for Step 1 as INCAR1 using the command: cp INCAR INCAR1.
Step 2: Perform a hybrid-functional calculation.
Create a new INCAR file with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., TIME=0.4, ICHARG=0.
Do not specify magnetic moments.
Do not specify NBAND.
Do not specify NELECT.
Execute the VASP calculation using the command: bash run_vasp.sh.
Save the INCAR file used for Step 2 as INCAR2 using the command: cp INCAR INCAR2.
Step 3: Extract the band gap.
Run the post-processing script using the command: python gap.py.
Return the band-gap value exactly as printed by gap.py.
