The INCAR file for all geometry optimization steps will contain EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISMEAR = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 250, ISPIN = 1, LREAL = Auto, PREC = Accurate, and ALGO = Fast, and EDIFF = 1E-6.
The provided KPOINTS file will be used for all three geometry optimization steps.
Step 1: Optimize CO.
Write the INCAR file.
Run `python op.py CO POTCAR-CO POSCAR-CO`.
Step 2: Optimize the clean surface.
Write the INCAR file.
Run `python op.py surface POTCAR-PtO2face POSCAR-PtO2face`.
Step 3: Optimize the adsorbed system.
Write the INCAR file.
Run `python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO`.
Step 4: Compute adsorption energy from the three total energies.
Run `bash ./calc_absorption_energy.sh`.
