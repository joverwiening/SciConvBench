The calculation will perform a variable-cell relaxation (vc-relax) followed by a self-consistent field (SCF) calculation.
The material is Fe3O4, which is ferrimagnetic with a space group of Fd-3m and 7 atoms per primitive cell.
The starting structure will be consistent with the provided metadata.
Local pseudopotential files PseudoDojo/SR_v0.4.1/LDA_standard/fe.upf and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf will be used.
The plane-wave kinetic energy cutoff (ecutwfc) will be set to 70 Ry.
The k-point sampling will use an automatic 6x6x6 Monkhorst-Pack grid with a half shift.
The electronic convergence threshold (etot_conv_thr) will be set to 1.0e-8.
The force convergence threshold (forc_conv_thr) will be set to 1.0e-7.
The self-consistency convergence threshold (conv_thr) will be set to 1.0e-8.
The starting magnetization for each Fe atom will be set to 0.5 Bohr magnetons.
The vc-relax calculation will relax the cell shape, cell volume, and atomic positions.
After the vc-relax, an SCF calculation will be performed on the fully relaxed structure using the same settings.
The final output will include the fully relaxed structure and the total energy from the SCF calculation.
