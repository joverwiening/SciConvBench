Perform a variable-cell relaxation using LDA pseudopotentials.
Use the PseudoDojo/SR_v0.4.1/LDA_standard/bi.upf, PseudoDojo/SR_v0.4.1/LDA_standard/o.upf, and PseudoDojo/SR_v0.4.1/LDA_standard/fe.upf pseudopotential files.
Set etot_conv_thr to 1.0e-8.
Set forc_conv_thr to 1.0e-7.
Set conv_thr to 1.0e-8.
Use an automatic 4x4x4 Monkhorst-Pack k-point grid with a half shift.
Set ecutwfc to 70 Ry.
Use a starting structure consistent with BiFeO3, perovskite, space group R3c, and 10 atoms per primitive cell as the starting configuration.
After the variable-cell relaxation finishes, run a self-consistent field calculation on the relaxed structure.
The self-consistent field calculation must use the same settings as the variable-cell relaxation.
Return the fully relaxed structure.
Return the final total energy from the self-consistent field calculation.
