The VASP calculation will use the following INCAR parameters for all geometry optimization steps:
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
NSW = 200
POTIM = 0.2
SIGMA = 0.2
EDIFF = 1E-6
PREC = Accurate
LWAVE = .FALSE.
LCHARG = .FALSE.
The provided KPOINTS file will be used for all three relaxation steps.
Step 1: Optimize CO.
The INCAR file will be created with the specified parameters.
The command `python op.py CO POTCAR-CO POSCAR-CO` will be executed.
Step 2: Optimize the clean surface.
The INCAR file will be created with the specified parameters.
The command `python op.py surface POTCAR-Irface POSCAR-Irface` will be executed.
Step 3: Optimize the adsorbed system.
The INCAR file will be created with the specified parameters.
The command `python op.py absorbed POTCAR-IrCO POSCAR-IrCO` will be executed.
Step 4: Compute adsorption energy from the three total energies.
The command `bash ./calc_absorption_energy.sh` will be executed.
The adsorption energy printed by `calc_absorption_energy.sh` will be returned as the final output.
