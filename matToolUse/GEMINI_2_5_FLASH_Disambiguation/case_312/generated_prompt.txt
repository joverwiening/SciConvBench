The current working directory is data/bandgap/BN.
The goal is to compute the electronic band gap of BN using VASP.
The workflow consists of three steps: a ground-state calculation, a hybrid-functional calculation, and band gap extraction.
The POSCAR, KPOINTS, and POTCAR files are located at 'POSCAR', 'KPOINTS', and 'POTCAR' respectively.

Step 1: Perform a PBE ground-state calculation.
Create an INCAR file with the following parameters:
PREC = Normal
ENCUT = 450
EDIFF = 1E-5
ISMEAR = 0
SIGMA = 0.05
IBRION = 2
ISIF = 3
NSW = 99
EDIFFG = -1E-2
ISPIN = 1
LCHARG = .TRUE.
LWAVE = .TRUE.
ALGO = Fast
NELM = 60
LREAL = Auto
LPLANE = .TRUE.
NPAR = 1
KPAR = 4
NCORE = 1
Execute the VASP calculation by running `bash run_vasp.sh`.
Save a copy of the INCAR file used for Step 1 as `INCAR1` by running `cp INCAR INCAR1`.

Step 2: Perform a hybrid-functional calculation.
Create a new INCAR file with the following parameters:
PREC = Normal
ENCUT = 450
NELM = 500
IBRION = -1
ISPIN = 1
NSW = 0
ISIF = 2
EDIFF = 1E-5
EDIFFG = -5E-3
ISMEAR = 0
SIGMA = 0.05
LWAVE = .TRUE.
LCHARG = .TRUE.
LREAL = Auto
LPLANE = .TRUE.
NPAR = 1
KPAR = 4
NCORE = 1
LORBIT = 11
ALGO = All
LHFCALC = .TRUE.
TIME = 0.4
ICHARG = 1
Do not specify magnetic moments.
Do not specify NBAND.
Do not specify NELECT.
Execute the VASP calculation by running `bash run_vasp.sh`.
Save a copy of the INCAR file used for Step 2 as `INCAR2` by running `cp INCAR INCAR2`.

Step 3: Extract the band gap.
Execute the post-processing script by running `python gap.py`.
Return the band-gap value exactly as printed by `gap.py`.
