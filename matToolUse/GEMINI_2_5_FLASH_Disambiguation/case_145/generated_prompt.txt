Perform a variable-cell relaxation calculation.
Use the LDA pseudopotential files PseudoDojo/SR_v0.4.1/LDA_standard/sn.upf for Sn and PseudoDojo/SR_v0.4.1/LDA_standard/se.upf for Se.
Generate a starting structure for SnSe consistent with an orthorhombic Pnma space group and 8 atoms per primitive cell.
Set the plane-wave cutoff energy (ecutwfc) to 70 Ry.
Set the charge density cutoff energy (ecutrho) to 280 Ry.
Use a gamma-centered k-point grid of 8x8x8.
Set the self-consistency convergence threshold (conv_thr) to 1.0e-9 Ry.
Set the total energy convergence threshold (etot_conv_thr) for relaxation to 0.000588 Ry.
Set the force convergence threshold (forc_conv_thr) for relaxation to 0.001 Ry/Bohr.
Allow all cell parameters to relax during the variable-cell relaxation.
Set occupations to 'fixed'.
Return the fully relaxed structure, including the atomic positions and cell parameters.
