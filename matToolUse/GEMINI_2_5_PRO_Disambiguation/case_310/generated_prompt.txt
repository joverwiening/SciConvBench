Create an INCAR file for the ground-state calculation with the following parameters: SYSTEM = AlN Ground State, PREC = Accurate, ENCUT = 450, IBRION = 2, ISIF = 3, NSW = 100, NELM = 100, EDIFF = 1E-6, EDIFFG = -1E-2, ISMEAR = 0, SIGMA = 0.05, LREAL = Auto, LWAVE = .TRUE., LCHARG = .TRUE., ISPIN = 1, NPAR = 1, KPAR = 4, NCORE = 1.
Execute the command `bash run_vasp.sh`.
Copy the INCAR file to INCAR1 using the command `cp INCAR INCAR1`.
Create a new INCAR file for the hybrid-functional calculation with the following parameters: PREC = Normal, ENCUT = 450, NELM = 500, IBRION = -1, ISPIN = 1, NSW = 0, ISIF = 2, EDIFF = 1E-5, EDIFFG = -5E-3, ISMEAR = 0, SIGMA = 0.05, LWAVE = .TRUE., LCHARG = .TRUE., LREAL = Auto, LPLANE = .TRUE., NPAR = 1, KPAR = 4, NCORE = 1, LORBIT = 11, ALGO = All, LHFCALC = .TRUE., TIME = 0.4, ICHARG = 11.
Execute the command `bash run_vasp.sh`.
Copy the INCAR file to INCAR2 using the command `cp INCAR INCAR2`.
Execute the command `python gap.py`.
The final output is the band-gap value printed by the `gap.py` script.
