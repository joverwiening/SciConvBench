The calculation is a variable-cell relaxation.
The material is KNbO3.
Generate a starting crystal structure for KNbO3 consistent with the perovskite structure type and the Amm2 space group.
Use the LDA exchange-correlation functional.
Use the k.upf, nb.upf, and o.upf pseudopotential files provided.
Set the plane-wave kinetic energy cutoff (ecutwfc) to 90 Ry.
Set the charge density cutoff (ecutrho) to 720 Ry.
Use a gamma-centered 8x8x8 k-point grid.
Use fixed electronic occupations.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-4 Ry.
Set the force convergence threshold (forc_conv_thr) to 1.0e-4 Ry/au.
Set the self-consistent field (SCF) convergence threshold (conv_thr) to 1.0e-9 Ry.
The final output is the fully relaxed structure.
