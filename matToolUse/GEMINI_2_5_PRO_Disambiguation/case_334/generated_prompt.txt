Create an INCAR file for all three optimization steps with the following content:
ENCUT = 450
EDIFF = 1E-5
EDIFFG = -0.05
IBRION = 1
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
NSW = 500
POTIM = 0.2
NELM = 60
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.
ISPIN = 1
For the CO molecule optimization, create a KPOINTS file with a 1x1x1 Gamma-centered grid.
Execute the CO molecule optimization by running `python op.py CO POTCAR-CO POSCAR-CO`.
For the clean surface optimization, use the `KPOINTS` file provided in the case directory.
Execute the clean surface optimization by running `python op.py surface POTCAR-Irface POSCAR-Irface`.
For the adsorbed system optimization, use the same `KPOINTS` file as the clean surface optimization.
Execute the adsorbed system optimization by running `python op.py absorbed POTCAR-IrCO POSCAR-IrCO`.
Calculate the final adsorption energy by running `bash ./calc_absorption_energy.sh`.
The required output is the numerical value printed to standard output by the `calc_absorption_energy.sh` script.
