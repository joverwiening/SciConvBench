Create an INCAR file with the following content:
```
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISMEAR = 1
POTIM = 0.2
SIGMA = 0.2
ISPIN = 1
NSW = 500
EDIFF = 1E-5
LREAL = Auto
PREC = Normal
LWAVE = .FALSE.
LCHARG = .FALSE.
```
Execute the command `python op.py CO POTCAR-CO POSCAR-CO`.
Execute the command `python op.py surface POTCAR-PtO2face POSCAR-PtO2face`.
Execute the command `python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO`.
Execute the command `bash ./calc_absorption_energy.sh`.
The final output is the numerical value printed by the `calc_absorption_energy.sh` script.
