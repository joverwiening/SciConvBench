Create an INCAR file for the initial state relaxation with the following parameters: SYSTEM = AgPd-NEB-Relax, EDIFF = 1E-5, EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, LREAL = Auto, NPAR = 1, NSW = 400, POTIM = 0.2, SIGMA = 0.2.
Run the initial state relaxation using the command `python op.py IS POTCARagpd IS1POSCAR`.
Use the same INCAR file for the final state relaxation.
Run the final state relaxation using the command `python op.py FS POTCARagpd FS1POSCAR`.
Generate the intermediate images using the command `python nebmake.py`.
Create a new INCAR file for the NEB calculation with the following parameters: SYSTEM = AgPd-NEB-Run, EDIFF = 1E-5, EDIFFG = -0.05, ENCUT = 450, IBRION = 3, IMAGES = 4, IOPT = 7, ISIF = 2, ISMEAR = 1, ISPIN = 1, LCLIMB = .TRUE., LREAL = Auto, NPAR = 1, NSW = 400, POTIM = 0, SIGMA = 0.2, SPRING = -5.
Run the NEB calculation using the command `python op2.py ./`.
Extract the energy profile using the command `bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'`.
The final output is the reaction barrier value from the extraction step.
