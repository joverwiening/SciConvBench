Create a file named INCAR for the ground-state calculation with the following content, ensuring each parameter is on a new line.
PREC=Normal
ENCUT=450
IBRION=2
ISIF=3
NSW=100
EDIFF=1E-6
EDIFFG=-1E-2
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
ISPIN=1
NELM=100
ALGO=Normal
LREAL=Auto
Execute the VASP ground-state calculation by running the command: bash run_vasp.sh.
Save the INCAR file from the ground-state calculation by running the command: cp INCAR INCAR1.
Create a new file named INCAR for the hybrid-functional calculation with the following content, ensuring each parameter is on a new line.
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
TIME=0.4
ICHARG=1
Execute the VASP hybrid-functional calculation by running the command: bash run_vasp.sh.
Save the INCAR file from the hybrid-functional calculation by running the command: cp INCAR INCAR2.
Extract the band gap by running the command: python gap.py.
The final output is the numerical value printed to standard output by the gap.py script.
