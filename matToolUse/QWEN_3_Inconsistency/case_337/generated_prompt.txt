Use the following INCAR settings for Steps 1–3: ENCUT = 450, EDIFFG = -0.05, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, NSW = 200, POTIM = 0.2, SIGMA = 0.2.
Use the same INCAR file for the CO molecule relaxation, clean surface relaxation, and adsorbed system relaxation.
For Step 1, run: python op.py CO POTCAR-CO POSCAR-CO.
For Step 2, run: python op.py surface POTCAR-OsO2face POSCAR-OsO2face.
For Step 3, run: python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO.
For Step 4, run: bash ./calc_absorption_energy.sh.
Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
