Create an INCAR file for the PBE ground-state calculation using standard PBE parameters suitable for a ground-state DFT calculation.
Set PREC to Normal.
Set ENCUT to 450.
Set NELM to 500.
Set IBRION to -1.
Set ISPIN to 1.
Set NSW to 0.
Set ISIF to 2.
Set EDIFF to 1E-5.
Set EDIFFG to -5E-3.
Set ISTART to 0.
Set ICHARG to 2.
Set ISMEAR to 0.
Set SIGMA to 0.05.
Set LWAVE to .TRUE..
Set LCHARG to .TRUE..
Set LREAL to Auto.
Set LPLANE to .TRUE..
Set NPAR to 1.
Set KPAR to 4.
Set NCORE to 1.
Set ALGO to Fast.
Do not specify magnetic moments.
Do not specify NBANDS or NELECT.
Run VASP using bash run_vasp.sh.
Copy the INCAR file to INCAR1.
Replace the INCAR file with the provided HSE parameter block from data.json → domain_knowledge.
Ensure ICHARG is set to 0 to allow charge density calculation from the existing WAVECAR.
Ensure LHFCALC, HSE06, and related HSE parameters are included as specified.
Run VASP again using bash run_vasp.sh.
Copy the INCAR file to INCAR2.
Run the post-processing script python gap.py.
Return the band gap value exactly as printed by gap.py, which outputs only the numerical value without additional text.
