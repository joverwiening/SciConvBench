Create the VASP input file `INCAR` with the following parameters:
ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 35*2.758
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Run the VASP calculation using the command: bash run_vasp.sh
After the calculation completes, copy the used INCAR file to INCAR1: cp INCAR INCAR1
Extract the optimized total energy by running: python get_energy.py
The optimized total energy is the value printed by get_energy.py.
