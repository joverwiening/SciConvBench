Use the following INCAR parameters for the PBE ground-state calculation:
PREC=Normal
ENCUT=450
ISPIN=1
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.TRUE.
LCHARG=.TRUE.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
Do not include NBANDS, NELECT, or any magnetic moment settings.
Write the INCAR file for Step 1 using these parameters.
Run the VASP calculation for the PBE ground state using: bash run_vasp.sh
Save a copy of the INCAR file as INCAR1: cp INCAR INCAR1
Create a new INCAR file for the HSE calculation using the parameter block from data.json → domain_knowledge.
Ensure ICHARG is set to 0 for the HSE step when starting from an existing WAVECAR.
Do not specify NBANDS, NELECT, or magnetic moments in the HSE INCAR.
Run the VASP calculation for the HSE step using: bash run_vasp.sh
Save a copy of the INCAR file as INCAR2: cp INCAR INCAR2
Run the post-processing script to extract the band gap: python gap.py
Return the band gap value as a float in eV, exactly as printed by gap.py.
