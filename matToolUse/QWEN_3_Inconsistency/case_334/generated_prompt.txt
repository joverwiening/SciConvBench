Use the following INCAR parameters for Step 1 (CO molecule optimization):
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
NSW = 200
POTIM = 0.2
SIGMA = 0.2
Write the INCAR file with these settings.
Run the command: python op.py CO POTCAR-CO POSCAR-CO
Use the same INCAR settings for Step 2 (clean surface optimization).
Run the command: python op.py surface POTCAR-Irface POSCAR-Irface
Use the same INCAR settings for Step 3 (adsorbed system optimization).
Run the command: python op.py absorbed POTCAR-IrCO POSCAR-IrCO
After completing the three optimization steps, run the adsorption energy calculation script.
Run the command: bash ./calc_absorption_energy.sh
Report the adsorption energy exactly as printed by calc_absorption_energy.sh.
