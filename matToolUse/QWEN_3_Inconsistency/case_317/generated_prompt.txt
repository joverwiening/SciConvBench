Create an INCAR file for the PBE ground-state calculation using standard parameters suitable for a PBE functional, including PREC=Normal, ENCUT=450, ISMEAR=-5, SIGMA=0.05, EDIFF=1E-6, IBRION=-1, NSW=0, ISPIN=1, ISTART=0, ICHARG=2, and other appropriate defaults.
Run the VASP calculation using the command: bash run_vasp.sh.
Save the INCAR file used for the PBE ground state as INCAR1 using the command: cp INCAR INCAR1.
Create a new INCAR file for the HSE calculation using the provided parameter block from data.json → domain_knowledge, ensuring ICHARG=11 is used but not exceeding ICHARG=10 due to the requirement to recalculate charge density from the existing WAVECAR, so modify ICHARG to 1.
Ensure the HSE INCAR does not specify magnetic moments, NBANDS, or NELECT.
Run the VASP calculation again for the HSE step using the command: bash run_vasp.sh.
Save the INCAR file used for the HSE calculation as INCAR2 using the command: cp INCAR INCAR2.
Run the post-processing script gap.py using the command: python gap.py.
The output is the band gap value printed as a single number without additional text.
