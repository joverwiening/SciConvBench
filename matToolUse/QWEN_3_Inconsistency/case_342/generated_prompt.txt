Set NSW to 200 for the geometry optimization steps to allow sufficient ionic steps for convergence, especially given potentially non-ideal initial structures.  

  
Use the following INCAR parameters for Step 1 (CO molecule optimization):  
EDIFFG = -0.05  
ENCUT = 450  
IBRION = 1  
ISIF = 2  
ISMEAR = 1  
ISPIN = 1  
POTIM = 0.2  
SIGMA = 0.2  
NSW = 200  
Add standard VASP tags for molecular relaxation: PREC = Medium, ALGO = Fast, EDIFF = 1E-5.  
Use the same INCAR settings for Step 2 (clean surface optimization).  
Use the same INCAR settings for Step 3 (adsorbed system optimization).  
Run the CO optimization using: python op.py CO POTCAR-CO POSCAR-CO.  
Run the clean surface optimization using: python op.py surface POTCAR-Ptface POSCAR-Ptface.  
Run the adsorbed system optimization using: python op.py absorbed POTCAR-PtCO POSCAR-PtCO.  
After all optimizations complete, run the adsorption energy calculation script: bash ./calc_absorption_energy.sh.  
Report the adsorption energy exactly as printed by calc_absorption_energy.sh.
