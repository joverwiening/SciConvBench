Use the following INCAR parameters for all three geometry optimization steps (CO, surface, and adsorbed system).
Set EDIFFG = -0.05 for force convergence.
Set ENCUT = 450 for all calculations.
Set IBRION = 1 to enable ionic relaxation using the conjugate gradient algorithm.
Set ISIF = 2 to relax ions but keep the cell shape and volume fixed.
Set ISMEAR = 1 for the Methfessel-Paxton smearing method.
Set ISPIN = 1 to disable spin polarization.
Set NSW = 200 to allow sufficient ionic steps for convergence.
Set POTIM = 0.2 as the time step for ionic relaxation.
Set SIGMA = 0.2 for the smearing width.
For Step 1, create a directory named CO and write the INCAR file with these settings.
Run the script op.py with arguments CO, POTCAR-CO, and POSCAR-CO to set up and run the CO optimization.
For Step 2, create a directory named surface and use the same INCAR settings.
Run the script op.py with arguments surface, POTCAR-IrO2face, and POSCAR-IrO2face to set up and run the clean surface optimization.
For Step 3, create a directory named absorbed and use the same INCAR settings.
Run the script op.py with arguments absorbed, POTCAR-IrO2CO, and POSCAR-IrO2CO to set up and run the adsorbed system optimization.
For Step 4, execute the script calc_absorption_energy.sh to read the final E0 values from CO/OSZICAR, surface/OSZICAR, and absorbed/OSZICAR.
The script will compute and print the adsorption energy; return that value exactly as output.
