Create the VASP input file `INCAR` with the specified parameters.  
Use the following INCAR settings: ALGO = Fast.  
Set EDIFF = 0.0025.  
Set ENCUT = 520.0.  
Set IBRION = 2.  
Set ISIF = 3.  
Set ISMEAR = -5.  
Set ISPIN = 2.  
Set LASPH = .TRUE.  
Set LMAXMIX = 4.  
Set LORBIT = 11.  
Set LREAL = Auto.  
Set LWAVE = .FALSE.  
Set MAGMOM = 49*-0.0.  
Set NELM = 100.  
Set NSW = 99.  
Set PREC = Accurate.  
Set SIGMA = 0.05.  
Run the VASP calculation using the command: bash run_vasp.sh.  
After the calculation completes, copy the used INCAR file to INCAR1 using: cp INCAR INCAR1.  
Extract the optimized total energy by running: python get_energy.py.  
Report the optimized total energy exactly as printed by get_energy.py.
