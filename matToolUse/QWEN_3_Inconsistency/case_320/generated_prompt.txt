Create an INCAR file for the PBE ground-state calculation using standard parameters suitable for a semiconductor like GaAs.
Set PREC to Normal.
Set ENCUT to 450.
Set ISTART to 0.
Set ICHARG to 2.
Set ISPIN to 1.
Set ISMEAR to 0.
Set SIGMA to 0.05.
Set EDIFF to 1E-5.
Set IBRION to -1.
Set NSW to 0.
Set ISIF to 2.
Set LWAVE to .TRUE.
Set LCHARG to .TRUE.
Set LREAL to Auto.
Set LPLANE to .TRUE.
Set NPAR to 1.
Set KPAR to 4.
Set NCORE to 1.
Set ALGO to Fast.
Include the tag GGA = PE to select PBE exchange-correlation functional.
Do not specify NBANDS or NELECT.
Do not specify magnetic moments.
Write the INCAR file to disk.
Run VASP using the command: bash run_vasp.sh.
After completion, copy the INCAR file to INCAR1.
Replace the INCAR file with the HSE parameter block provided in data.json → domain_knowledge.
Ensure ICHARG is set to 0 to allow charge density update from the existing WAVECAR.
Ensure LHFCALC, HSE06, and related hybrid functional tags are included as specified.
Ensure no magnetic moment tags are present.
Ensure NBANDS and NELECT are not specified.
Write the new INCAR file to disk.
Run VASP again using the command: bash run_vasp.sh.
After completion, copy the INCAR file to INCAR2.
Run the post-processing script using the command: python gap.py.
Capture the output of gap.py, which is a single floating-point number representing the band gap.
Return the band gap value exactly as printed by gap.py.
