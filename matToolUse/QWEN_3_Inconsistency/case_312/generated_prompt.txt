Create an INCAR file for the PBE ground-state calculation using standard PBE parameters suitable for a ground state calculation.
Run the VASP calculation using the command: bash run_vasp.sh.
Save the INCAR file used for the PBE calculation as INCAR1 using the command: cp INCAR INCAR1.
Create a new INCAR file for the HSE calculation using the provided parameter block from data.json → domain_knowledge.
Ensure ICHARG is set to a value not greater than 10 since the calculation starts from an existing WAVECAR.
Do not specify magnetic moments, NBANDS, or NELECT in the HSE INCAR.
Run the VASP calculation again for the HSE step using the command: bash run_vasp.sh.
Save the INCAR file used for the HSE calculation as INCAR2 using the command: cp INCAR INCAR2.
Run the post-processing script using the command: python gap.py.
Return the band gap value exactly as printed by gap.py, which outputs only the numerical value without additional text.
