Create an INCAR file for the PBE ground-state calculation using standard PBE parameters suitable for a structural relaxation or ground-state electronic calculation.
Set PREC to Normal.
Set ENCUT to 450.
Set ISTART to 0.
Set ICHARG to 2.
Set ISPIN to 1.
Set ISMEAR to 0.
Set SIGMA to 0.05.
Set EDIFF to 1E-5.
Set LWAVE to .FALSE..
Set LCHARG to .TRUE..
Set LREAL to Auto.
Set LPLANE to .TRUE..
Set NPAR to 1.
Set KPAR to 4.
Set NCORE to 1.
Run VASP using the command: bash run_vasp.sh.
Copy the PBE INCAR file to INCAR1 using the command: cp INCAR INCAR1.
Create a new INCAR file for the HSE calculation using the provided parameter block from data.json → domain_knowledge.
Ensure ISTART is set to 1 to continue from the existing WAVECAR.
Ensure ICHARG is set to 0 to calculate the charge density from the wavefunctions.
Do not specify NBANDS or NELECT.
Do not specify any magnetic moments.
Run VASP again using the command: bash run_vasp.sh.
Copy the HSE INCAR file to INCAR2 using the command: cp INCAR INCAR2.
Run the post-processing script using the command: python gap.py.
Return the band gap value exactly as printed by gap.py, which outputs only the numerical value without additional text.
