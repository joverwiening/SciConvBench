Use the following INCAR parameters for all three geometry optimization steps (CO, surface, absorbed).
Set NSW to 100 to allow sufficient ionic steps for convergence given the loose force criterion and potentially suboptimal initial structures.
Use EDIFFG = -0.05 for force convergence.
Set ENCUT = 450.
Use IBRION = 1 for ionic relaxation.
Set ISIF = 2 to relax ions only, not the cell.
Use ISMEAR = 1 for partial occupancies.
Set ISPIN = 1 to disable spin polarization.
Use POTIM = 0.2 for the ionic time step.
Set SIGMA = 0.2 for the smearing width.
Include PREC = Medium to keep calculations efficient while maintaining reasonable accuracy.
Write the INCAR file with these settings before each VASP run.
Run the op.py script for the CO system with POTCAR-CO and POSCAR-CO.
Run the op.py script for the surface system with POTCAR-Rhface and POSCAR-Rhface.
Run the op.py script for the absorbed system with POTCAR-RhCO and POSCAR-RhCO.
After all three optimizations, execute calc_absorption_energy.sh to compute the adsorption energy.
Report the adsorption energy exactly as printed by calc_absorption_energy.sh.
