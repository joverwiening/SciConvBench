Create an INCAR file for the PBE ground-state calculation using standard parameters suitable for a ground-state DFT calculation with PBE.
Set PREC to Normal.
Set ENCUT to 450.
Set NELM to 500.
Set IBRION to -1.
Set ISPIN to 1.
Set NSW to 0.
Set ISIF to 2.
Set EDIFF to 1E-5.
Set EDIFFG to -5E-3.
Set ISTART to 0.
Set ICHARG to 2.
Set ISMEAR to 0.
Set SIGMA to 0.05.
Set LWAVE to .TRUE..
Set LCHARG to .TRUE..
Set LREAL to Auto.
Set LPLANE to .TRUE..
Set NPAR to 1.
Set KPAR to 4.
Set NCORE to 1.
Run VASP using the command: bash run_vasp.sh.
Copy the INCAR file to INCAR1 using the command: cp INCAR INCAR1.
Create a new INCAR file for the HSE calculation using the parameter block provided in data.json → domain_knowledge.
Ensure ICHARG is set to 11 in the HSE INCAR.
Ensure no magnetic moment specifications are included in the INCAR.
Ensure NBANDS and NELECT are not specified in the INCAR.
Run VASP again using the command: bash run_vasp.sh.
Copy the INCAR file to INCAR2 using the command: cp INCAR INCAR2.
Run the post-processing script using the command: python gap.py.
Return the band gap value exactly as printed by gap.py, in eV, without any rounding or formatting changes.
