Perform a PBE ground-state calculation using VASP with the provided POSCAR, KPOINTS, and POTCAR files.
Write an INCAR file suitable for the PBE ground-state calculation based on standard settings for such a task.
Run the VASP calculation using the command: bash run_vasp.sh.
Save the INCAR file used in the first step as INCAR1 by copying it: cp INCAR INCAR1.
Create a new INCAR file for the HSE calculation using the parameter block specified in data.json → domain_knowledge.
Ensure that ICHARG is set to a value no greater than 10 because the calculation starts from an existing WAVECAR and charge density must be recalculated.
Do not specify magnetic moments, NBANDS, or NELECT in the INCAR for the HSE step.
Run the VASP calculation again for the HSE step using: bash run_vasp.sh.
Save the INCAR file used in the second step as INCAR2 by copying it: cp INCAR INCAR2.
Execute the post-processing script to extract the band gap: python gap.py.
Return only the numerical value of the band gap as printed by gap.py, with no additional text or formatting.
