Use the following INCAR parameters for all geometry optimization steps (CO, surface, and adsorbed system).
Set EDIFFG = -0.05 for force convergence.
Set ENCUT = 450 for all calculations.
Set IBRION = 1 to use the conjugate gradient algorithm for ionic relaxation.
Set ISIF = 2 to relax ions but not the cell shape or volume.
Set ISMEAR = 1 for the Methfessel-Paxton smearing method.
Set ISPIN = 1 to disable spin polarization.
Set NSW = 200 to allow sufficient ionic steps for convergence.
Set POTIM = 0.2 for the ionic time step.
Set SIGMA = 0.2 for the smearing width.
For Step 1, create a directory named CO and write the INCAR file with these settings.
Run the script op.py with arguments CO, POTCAR-CO, and POSCAR-CO to set up and run the CO optimization.
For Step 2, create a directory named surface and use the same INCAR settings.
Run the script op.py with arguments surface, POTCAR-Pdface, and POSCAR-Pdface to set up and run the clean surface optimization.
For Step 3, create a directory named absorbed and use the same INCAR settings.
Run the script op.py with arguments absorbed, POTCAR-PdCO, and POSCAR-PdCO to set up and run the adsorbed system optimization.
After all three optimizations are complete, execute the script calc_absorption_energy.sh to read the final E0 values from CO/OSZICAR, surface/OSZICAR, and absorbed/OSZICAR.
The script will compute and print the adsorption energy; return that value exactly as output.
