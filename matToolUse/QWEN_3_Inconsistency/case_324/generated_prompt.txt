Create an INCAR file for the PBE ground-state calculation using standard parameters suitable for a semiconductor like InP.
Set PREC to Normal.
Set ENCUT to 450.
Set ISTART to 0.
Set ICHARG to 2.
Set ISPIN to 1.
Set ISMEAR to 0.
Set SIGMA to 0.05.
Set EDIFF to 1E-5.
Set IBRION to -1.
Set NSW to 0.
Set ISIF to 2.
Set LWAVE to .TRUE.
Set LCHARG to .TRUE.
Set LREAL to Auto.
Set LPLANE to .TRUE.
Set NPAR to 1.
Set KPAR to 4.
Set NCORE to 1.
Set ALGO to Fast.
Include the POSCAR, KPOINTS, and POTCAR files in the directory for the calculation.
Run VASP using the command: bash run_vasp.sh.
After the first VASP run, copy the INCAR file to INCAR1.
Replace the INCAR file with the new parameter block specified for the HSE calculation from data.json.
Ensure ICHARG is set to 0 to allow charge density calculation from the existing WAVECAR.
Ensure ISPIN is set to 1.
Ensure no NBANDS or NELECT parameters are specified.
Ensure no magnetic moment tags are present.
Run VASP again using the command: bash run_vasp.sh.
After the second VASP run, copy the INCAR file to INCAR2.
Run the post-processing script using the command: python gap.py.
Capture and return the single numerical value printed by gap.py as the band gap.
