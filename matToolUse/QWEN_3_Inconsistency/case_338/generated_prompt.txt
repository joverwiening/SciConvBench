Use the following INCAR parameters for Step 1 (CO molecule optimization).
Set EDIFFG = -0.05.
Set ENCUT = 450.
Set IBRION = 1.
Set ISIF = 2.
Set ISMEAR = 1.
Set ISPIN = 1.
Set NSW = 200.
Set POTIM = 0.2.
Set SIGMA = 0.2.
Write the INCAR file to the current directory before running the first step.
Run the command: python op.py CO POTCAR-CO POSCAR-CO.
Use the same INCAR settings for Step 2 (clean surface optimization).
Run the command: python op.py surface POTCAR-PdO2face POSCAR-PdO2face.
Use the same INCAR settings for Step 3 (adsorbed system optimization).
Run the command: python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO.
After completing the three optimization steps, run: bash ./calc_absorption_energy.sh.
Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
