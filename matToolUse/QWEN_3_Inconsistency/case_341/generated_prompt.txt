Use the following INCAR parameters for all geometry optimization steps (CO, surface, and adsorbed system).
Set EDIFFG = -0.05 for force convergence.
Set ENCUT = 450 for all calculations.
Set IBRION = 1 to enable ionic relaxation.
Set ISIF = 2 to relax ions but not the cell shape or volume.
Set ISMEAR = 1 for the Methfessel-Paxton smearing method.
Set ISPIN = 1 to disable spin polarization.
Set NSW = 200 to allow sufficient ionic steps for convergence.
Set POTIM = 0.2 for the time step during ionic relaxation.
Set SIGMA = 0.2 for the smearing width.
Use the KPOINTS file as provided for k-point sampling.
For Step 1, create a directory named CO and write the INCAR file there.
For Step 1, copy POSCAR-CO to POSCAR and POTCAR-CO to POTCAR in the CO directory.
For Step 1, run python op.py CO POTCAR-CO POSCAR-CO.
For Step 2, create a directory named surface and write the same INCAR file there.
For Step 2, copy POSCAR-RuO2face to POSCAR and POTCAR-RuO2face to POTCAR in the surface directory.
For Step 2, run python op.py surface POTCAR-RuO2face POSCAR-RuO2face.
For Step 3, create a directory named absorbed and write the same INCAR file there.
For Step 3, copy POSCAR-RuO2CO to POSCAR and POTCAR-RuO2CO to POTCAR in the absorbed directory.
For Step 3, run python op.py absorbed POTCAR-RuO2CO POSCAR-RuO2CO.
After all three optimizations are complete, run bash ./calc_absorption_energy.sh.
Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
