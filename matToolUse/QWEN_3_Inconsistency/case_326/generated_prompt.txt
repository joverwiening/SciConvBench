Use the provided POSCAR, KPOINTS, and POTCAR files located in the current directory.
Create an INCAR file for the PBE ground-state calculation with appropriate parameters for a standard DFT ground state using the PBE functional.
Run the first VASP calculation using the command: bash run_vasp.sh.
After completion, save the INCAR file as INCAR1 using: cp INCAR INCAR1.
Create a new INCAR file for the HSE calculation using the parameter block specified in data.json → domain_knowledge.
Ensure ICHARG is set to a value not greater than 10 since the calculation starts from an existing WAVECAR and charge density must be recalculated.
Do not specify NBANDS, NELECT, or magnetic moments in the HSE INCAR.
Run the second VASP calculation using the command: bash run_vasp.sh.
After completion, save the INCAR file as INCAR2 using: cp INCAR INCAR2.
Execute the post-processing script using: python gap.py.
Return only the numerical value of the band gap as printed by gap.py.
