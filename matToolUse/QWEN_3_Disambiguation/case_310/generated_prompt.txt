Create the INCAR file for Step 1 with the following settings: PREC = Normal.  
Set ENCUT = 450.  
Set EDIFF = 1E-6.  
Set ISMEAR = 0.  
Set SIGMA = 0.05.  
Set IBRION = -1.  
Set NSW = 0.  
Set ISPIN = 1.  
Set ALGO = Fast.  
Set LWAVE = .TRUE.  
Set LCHARG = .TRUE.  
Set LREAL = Auto.  
Set LPLANE = .TRUE.  
Set NPAR = 1.  
Set KPAR = 4.  
Set NCORE = 1.  
Do not specify NBANDS or NELECT.  
Do not set any magnetic moments.  
Set ICHARG = 2 for Step 1 since starting from atomic orbitals.  
Run VASP using bash run_vasp.sh.  
Copy the INCAR file to INCAR1.  
Create the INCAR file for Step 2 using the parameter block from data.json → domain_knowledge.  
Ensure ICHARG is not greater than 10 when starting hybrid-functional calculation from existing WAVECAR.  
Do not specify NBANDS or NELECT in Step 2.  
Do not set any magnetic moments in Step 2.  
Run VASP again using bash run_vasp.sh for the hybrid-functional step.  
Copy the INCAR file to INCAR2.  
Run the post-processing script using python gap.py.  
Return the band-gap value exactly as printed by gap.py.
