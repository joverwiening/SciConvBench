Use the provided IS1POSCAR as the initial-state structure.  
Use the provided FS1POSCAR as the final-state structure.  
Use the provided KPOINTS file for k-point sampling.  
Use the provided POTCARpdch as the pseudopotential file.  
For Step 1 (IS relaxation), write an INCAR file with the following parameters:  
EDIFFG = -0.05  
ENCUT = 450  
NPAR = 1  
IBRION = 1  
ISIF = 2  
ISMEAR = 1  
ISPIN = 1  
POTIM = 0.2  
SIGMA = 0.2  
NSW = 200  
Set PREC = Medium to avoid unnecessarily high precision.  
Run the IS relaxation using: python op.py IS POTCARpdch IS1POSCAR.  
For Step 2 (FS relaxation), write an INCAR file with the same parameters as Step 1.  
Run the FS relaxation using: python op.py FS POTCARpdch FS1POSCAR.  
For Step 3 (interpolation), run: python nebmake.py.  
This creates image directories 00 through 05.  
For Step 4 (NEB calculation), write an INCAR file with the following parameters:  
EDIFFG = -0.05  
ENCUT = 450  
NPAR = 1  
IBRION = 3  
IOPT = 7  
ISIF = 2  
ISMEAR = 1  
ISPIN = 1  
POTIM = 0  
SIGMA = 0.2  
SPRING = -5  
LCLIMB = TRUE  
NSW = 200  
Set PREC = Medium.  
Run the NEB calculation using: python op2.py ./  
For Step 5 (barrier extraction), run:  
cp IS/OUTCAR 00/  
cp FS/OUTCAR 05/  
perl nebef.pl  
Capture the output energy barrier value printed by nebef.pl.  
The reaction-barrier value is the maximum energy along the NEB path relative to the initial state.
