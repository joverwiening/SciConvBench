Use the provided IS1POSCAR as the initial-state structure for the NEB reaction path.
Use the provided FS1POSCAR as the final-state structure for the NEB reaction path.
Use the provided KPOINTS file for k-point sampling in all calculations.
Use the provided POTCARagpd as the pseudopotential file, renaming it to POTCAR where required.
For the initial-state relaxation, create an INCAR file with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200.
Run the initial-state relaxation by executing: python op.py IS POTCARagpd IS1POSCAR.
For the final-state relaxation, create an INCAR file with the same parameters as the initial-state relaxation.
Run the final-state relaxation by executing: python op.py FS POTCARagpd FS1POSCAR.
Interpolate intermediate images using ASE by running: python nebmake.py, which creates image directories 00 through 05.
For the NEB calculation, create an INCAR file with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 3, IOPT = 7, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0, SIGMA = 0.2, SPRING = -5, NSW = 200.
Run the NEB calculation by executing: python op2.py ./.
Before energy extraction, copy the final OUTCAR from the initial-state relaxation to directory 00: cp IS/OUTCAR 00/.
Before energy extraction, copy the final OUTCAR from the final-state relaxation to directory 05: cp FS/OUTCAR 05/.
Extract the energy profile and determine the reaction barrier by running: bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'.
Return the reaction-barrier value produced by the nebef.pl script.
