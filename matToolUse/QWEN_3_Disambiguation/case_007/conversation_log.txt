Q: What is the file format and structure of the input data (e.g., JSON, XML, directory layout) containing the Mg_Ga defect and bulk supercell information?
A: The input data is organized in a directory structure under `file_path`. The `Mg_Ga` defect data is located in subdirectories of `file_path / "Mg_Ga"`, each containing `vasprun.xml.gz` and `LOCPOT.gz` files. The bulk reference electrostatic potential is in `file_path / "bulk_sc" / "LOCPOT.gz"`. The defect structure is defined by substituting Mg onto the Ga site (index 0) in the `GaN.vasp` file. All data should be read from these local files.

=== 2026-07-26 01:34:42 ===
Q: What is the path to the `GaN.vasp` file that defines the defect structure?
A: The `GaN.vasp` file is located directly in the base directory specified by `file_path`. So the full path is `file_path / "GaN.vasp"`.
