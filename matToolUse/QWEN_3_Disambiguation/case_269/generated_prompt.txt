Create the VASP input file `INCAR` with the following parameters:  
ALGO = Fast  
EDIFF = 5e-05  
ENCUT = 520.0  
IBRION = 2  
ISMEAR = -5  
LASPH = .TRUE.  
LORBIT = 11  
LREAL = Auto  
LWAVE = .FALSE.  
NELM = 100  
NSW = 99  
PREC = Accurate  
SIGMA = 0.05  
Run the VASP calculation using the command: bash run_vasp.sh  
After the calculation completes, copy the input INCAR file to INCAR1 using: cp INCAR INCAR1  
Extract the optimized total energy by running: python get_energy.py  
Return the optimized total energy exactly as printed by the get_energy.py script.
