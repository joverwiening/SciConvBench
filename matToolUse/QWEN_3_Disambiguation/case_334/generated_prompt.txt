Use the following INCAR parameters for Step 1 (CO molecule optimization).
Set EDIFFG = -0.05 for force convergence.
Set ENCUT = 450 for consistent energy cutoff.
Set IBRION = 1 to enable ionic relaxation.
Set ISMEAR = 1 for Fermi-Dirac smearing.
Set NSW = 200 to allow sufficient ionic steps.
Set POTIM = 0.2 for the time step in molecular dynamics.
Set SIGMA = 0.2 for the smearing width.
Use the POSCAR-CO file as the input structure for the CO molecule.
Use the POTCAR-CO file as the pseudopotential for the CO calculation.
Run the op.py script with arguments: CO POTCAR-CO POSCAR-CO.
Use the same INCAR parameters for Step 2 (clean surface optimization).
Run the op.py script with arguments: surface POTCAR-Irface POSCAR-Irface.
Use the same INCAR parameters for Step 3 (adsorbed system optimization).
Run the op.py script with arguments: absorbed POTCAR-IrCO POSCAR-IrCO.
After completing the three relaxation steps, run calc_absorption_energy.sh to compute the adsorption energy.
Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
