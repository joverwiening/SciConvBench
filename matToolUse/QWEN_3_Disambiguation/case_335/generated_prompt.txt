Use the following INCAR parameters for Step 1 (CO molecule optimization).
Set EDIFFG = -0.05 for force convergence.
Set ENCUT = 450 for all calculations.
Set IBRION = 1 for ionic relaxation.
Set ISMEAR = 1 for electronic smearing.
Set NSW = 100 to allow sufficient ionic steps.
Set POTIM = 0.2 for time step in ionic relaxation.
Set SIGMA = 0.2 for smearing width.
Use the provided POSCAR-CO for the CO molecule structure.
Use the provided POTCAR-CO for the CO calculation.
Run the script op.py with arguments CO, POTCAR-CO, and POSCAR-CO to set up the CO calculation directory.
Use the same INCAR settings for Step 2 (clean surface optimization).
Run the script op.py with arguments surface, POTCAR-PtO2face, and POSCAR-PtO2face to set up the surface calculation directory.
Use the same INCAR settings for Step 3 (adsorbed system optimization).
Run the script op.py with arguments absorbed, POTCAR-PtO2CO, and POSCAR-PtO2CO to set up the absorbed system calculation directory.
After all three optimizations complete, run calc_absorption_energy.sh to compute the adsorption energy.
Return the adsorption energy exactly as printed by calc_absorption_energy.sh.
