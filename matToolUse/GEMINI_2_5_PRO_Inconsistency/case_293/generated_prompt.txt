Create the VASP input file named INCAR.
The INCAR file contains ALGO = Fast.
The INCAR file contains EDIFF = 0.0005.
The INCAR file contains ENCUT = 520.0.
The INCAR file contains IBRION = 2.
The INCAR file contains ISIF = 3.
The INCAR file contains ISMEAR = -5.
The INCAR file contains ISPIN = 2.
The INCAR file contains LASPH = .TRUE..
The INCAR file contains LMAXMIX = 4.
The INCAR file contains LORBIT = 11.
The INCAR file contains LREAL = Auto.
The INCAR file contains LWAVE = .FALSE..
The INCAR file contains MAGMOM = 39*0.0.
The INCAR file contains NELM = 100.
The INCAR file contains NSW = 99.
The INCAR file contains PREC = Accurate.
The INCAR file contains SIGMA = 0.05.
The input structure is read from the POSCAR file.
The k-point sampling is read from the KPOINTS file.
The pseudopotentials are read from the POTCAR file.
Run the VASP calculation using the command `bash run_vasp.sh`.
After the VASP run completes, copy the INCAR file to a new file named INCAR1.
Extract the final total energy by running the command `python get_energy.py`.
The final output is the numerical value printed to standard output by get_energy.py.
