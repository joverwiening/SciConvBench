Create a file named INCAR in the current directory with the following content.
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 400
EDIFF = 1E-5
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.
Execute the command: python op.py CO POTCAR-CO POSCAR-CO.
After the previous command completes, execute the command: python op.py surface POTCAR-Rhface POSCAR-Rhface.
After the previous command completes, execute the command: python op.py absorbed POTCAR-RhCO POSCAR-RhCO.
After the previous command completes, execute the command: bash ./calc_absorption_energy.sh.
The final output is the numerical value printed by the calc_absorption_energy.sh script.
