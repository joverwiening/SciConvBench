Create an INCAR file for the PBE ground state calculation.
In the PBE INCAR file, set SYSTEM = SnO2.
In the PBE INCAR file, set PREC = Normal.
In the PBE INCAR file, set ENCUT = 450.
In the PBE INCAR file, set IBRION = -1.
In the PBE INCAR file, set NSW = 0.
In the PBE INCAR file, set ISIF = 2.
In the PBE INCAR file, set EDIFF = 1E-5.
In the PBE INCAR file, set ISMEAR = 0.
In the PBE INCAR file, set SIGMA = 0.05.
In the PBE INCAR file, set ISTART = 0.
In the PBE INCAR file, set ICHARG = 2.
In the PBE INCAR file, set LWAVE = .TRUE..
In the PBE INCAR file, set LCHARG = .TRUE..
In the PBE INCAR file, set ISPIN = 1.
Run the command `bash run_vasp.sh`.
Run the command `cp INCAR INCAR1`.

In the HSE INCAR file, set LCHARG = .T..
