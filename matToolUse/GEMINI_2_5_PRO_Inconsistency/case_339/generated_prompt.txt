The goal is to compute the adsorption energy of CO on the RhO2 surface.
A single INCAR file will be used for the three geometry optimization steps.
The INCAR file must be created in the current directory before running the optimization steps.
The INCAR file must set EDIFFG to -0.05.
The INCAR file must set ENCUT to 450.
The INCAR file must set IBRION to 1.
The INCAR file must set ISIF to 2.
The INCAR file must set ISMEAR to 1.
The INCAR file must set ISPIN to 1.
The INCAR file must set NSW to 500.
The INCAR file must set POTIM to 0.2.
The INCAR file must set SIGMA to 0.2.
Step 1 is to optimize the CO molecule by running the command `python op.py CO POTCAR-CO POSCAR-CO`.
Step 2 is to optimize the clean RhO2 surface by running the command `python op.py surface POTCAR-RhO2face POSCAR-RhO2face`.
Step 3 is to optimize the CO-adsorbed RhO2 system by running the command `python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO`.
Step 4 is to calculate the adsorption energy by running the command `bash ./calc_absorption_energy.sh`.
The final result is the adsorption energy value printed to standard output by the script in Step 4.
