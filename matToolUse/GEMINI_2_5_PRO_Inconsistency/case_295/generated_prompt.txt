Create a file named INCAR with the following content:
ALGO = Fast
EDIFF = 0.00015000000000000001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the command `bash run_vasp.sh` to run the VASP calculation.
After the calculation is complete, execute the command `cp INCAR INCAR1`.
Execute the command `python get_energy.py` to extract the final total energy.
The final output is the numerical value printed to standard output by the `get_energy.py` script.
