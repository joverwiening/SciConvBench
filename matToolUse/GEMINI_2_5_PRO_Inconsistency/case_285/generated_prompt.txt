Create a VASP input file named INCAR.
The INCAR file must contain the following key-value pairs:
ALGO = Fast
EDIFF = 0.0025
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 49*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the VASP calculation by running the command `bash run_vasp.sh`.
After the VASP calculation completes, create a copy of the INCAR file named INCAR1.
Extract the final total energy by running the command `python get_energy.py`.
The final output must be the numerical value printed to standard output by `get_energy.py`.
