Create a single INCAR file with the following content to be used for all VASP calculations.
SYSTEM = Adsorption Energy Calculation
PREC = Accurate
ENCUT = 450
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
IBRION = 1
POTIM = 0.2
NSW = 200
EDIFFG = -0.05
ISIF = 2
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.
Execute the following command to optimize the CO molecule.
python op.py CO POTCAR-CO POSCAR-CO
Execute the following command to optimize the clean PdO2 surface.
python op.py surface POTCAR-PdO2face POSCAR-PdO2face
Execute the following command to optimize the CO-adsorbed PdO2 system.
python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO
Execute the following command to calculate the final adsorption energy.
bash ./calc_absorption_energy.sh
The final output is the numerical value printed to standard output by the calc_absorption_energy.sh script.
