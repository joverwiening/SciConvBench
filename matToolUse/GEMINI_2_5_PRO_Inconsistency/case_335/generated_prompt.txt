A single INCAR file will be used for all three geometry optimization steps.
The INCAR file sets the plane-wave energy cutoff ENCUT to 450.
The INCAR file sets the electronic energy convergence criterion EDIFF to 1E-5.
The INCAR file sets the ionic force convergence criterion EDIFFG to -0.05.
The INCAR file sets the ionic relaxation algorithm IBRION to 1.
The INCAR file sets the cell optimization flag ISIF to 2.
The INCAR file sets the smearing method ISMEAR to 1.
The INCAR file sets the smearing width SIGMA to 0.2.
The INCAR file disables spin polarization by setting ISPIN to 1.
The INCAR file sets the maximum number of ionic steps NSW to 500.
The INCAR file sets the ionic step size POTIM to 0.2.
The INCAR file sets the precision level PREC to Normal.
The INCAR file sets the real-space projection flag LREAL to Auto.
The INCAR file sets LWAVE to .FALSE. to disable writing the wavefunction.
The INCAR file sets LCHARG to .FALSE. to disable writing the charge density.
The INCAR file sets the maximum number of electronic steps NELM to 100.
First, execute `python op.py CO POTCAR-CO POSCAR-CO` to optimize the CO molecule.
Second, execute `python op.py surface POTCAR-PtO2face POSCAR-PtO2face` to optimize the clean surface.
Third, execute `python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO` to optimize the adsorbed system.
Finally, execute `bash ./calc_absorption_energy.sh` to compute the final energy.
The required output is the single numerical value printed by the `calc_absorption_energy.sh` script.
