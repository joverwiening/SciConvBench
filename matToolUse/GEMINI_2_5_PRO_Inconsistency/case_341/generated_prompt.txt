Create one INCAR file to be used for all three VASP relaxation calculations.
Set the `PREC` parameter to `Normal`.
Set the `LREAL` parameter to `Auto`.
Set the `LWAVE` parameter to `.FALSE.`.
Set the `LCHARG` parameter to `.FALSE.`.
Set the `ENCUT` parameter to `450`.
Set the `EDIFF` parameter to `1E-5`.
Set the `ISMEAR` parameter to `1`.
Set the `SIGMA` parameter to `0.2`.
Set the `ISPIN` parameter to `1`.
Set the `IBRION` parameter to `1`.
Set the `ISIF` parameter to `2`.
Set the `NSW` parameter to `200`.
Set the `EDIFFG` parameter to `-0.05`.
Set the `POTIM` parameter to `0.2`.
Run the geometry optimization for the CO molecule with the command `python op.py CO POTCAR-CO POSCAR-CO`.
Run the geometry optimization for the clean surface with the command `python op.py surface POTCAR-RuO2face POSCAR-RuO2face`.
Run the geometry optimization for the adsorbed system with the command `python op.py absorbed POTCAR-RuO2CO POSCAR-RuO2CO`.
Run the post-processing script to calculate the adsorption energy with the command `bash ./calc_absorption_energy.sh`.
The final output is the numerical value printed by the `calc_absorption_energy.sh` script.
