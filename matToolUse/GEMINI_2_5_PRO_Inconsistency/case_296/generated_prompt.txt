Create a file named INCAR.
Write the following 16 lines into the INCAR file:
ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the command `bash run_vasp.sh`.
After the VASP calculation finishes, execute the command `cp INCAR INCAR1`.
Execute the command `python get_energy.py`.
Report the numerical value printed by `get_energy.py` as the final result.
