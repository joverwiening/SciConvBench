Create an INCAR file with the following content:
ALGO = Fast
EDIFF = 0.0003
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 23*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the command `bash run_vasp.sh`.
Execute the command `cp INCAR INCAR1`.
Execute the command `python get_energy.py`.
The final output is the numerical value printed to standard output by `get_energy.py`.
