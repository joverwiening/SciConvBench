Create a Python function named `compute_defect_properties`.
The function accepts no arguments.
The function assumes the input files `GaN.vasp` and `stable_entries_Mg_Ga_N.json` are in the current working directory.
The function reads the crystal structure from the `GaN.vasp` file.
The function determines the bulk chemical formula from this structure.
The function reads the list of computed entries from the `stable_entries_Mg_Ga_N.json` file.
The function filters the entries to retain only those belonging to the Ga-N chemical system.
The function constructs a Pymatgen `PhaseDiagram` object using the filtered Ga-N entries.
The function calculates the number of chemical potential limits from the phase diagram.
The function defines the defect chemical system as the string "Ga-Mg-N".
The function returns a dictionary with three keys: `bulk_formula`, `chempot_limits_count`, and `defect_chemsys`.
The value for `bulk_formula` is the reduced chemical formula of the bulk material as a string.
The value for `chempot_limits_count` is the number of chemical potential limits as an integer.
The value for `defect_chemsys` is the string "Ga-Mg-N".
The function must include a docstring describing its purpose and return value.
The function must include all necessary imports from the Pymatgen and standard libraries.
