Create an INCAR file with the following key-value pairs.
ALGO = Fast
EDIFF = 0.0004
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 31*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the VASP calculation by running the command `bash run_vasp.sh`.
After the calculation is complete, copy the INCAR file to a new file named INCAR1.
Extract the final total energy by running the command `python get_energy.py`.
Report the numerical value printed by the `python get_energy.py` script as the final result.
