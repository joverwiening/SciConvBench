Retrieve a primitive starting structure for PbTiO3 with space group P4mm.
Perform a variable-cell relaxation calculation.
Use the LDA exchange-correlation functional.
Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/pb.upf for Pb.
Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/ti.upf for Ti.
Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/o.upf for O.
Set the plane-wave kinetic energy cutoff (ecutwfc) to 80 Ry.
Set the charge density and potential cutoff (ecutrho) to 320 Ry.
Use an 8x8x8 Monkhorst-Pack k-point grid.
Apply a half shift to the k-point grid.
Set the total energy convergence threshold for relaxation (etot_conv_thr) to 1.0e-8 Ry.
Set the force convergence threshold for relaxation (forc_conv_thr) to 1.0e-7 Ry/Bohr.
Set the self-consistency convergence threshold (conv_thr) to 1.0e-8 Ry.
After the relaxation is complete, perform a self-consistent field calculation on the relaxed structure.
The self-consistent field calculation must use the same settings as the relaxation step.
Return the fully relaxed structure.
Return the final total energy from the self-consistent field calculation.
