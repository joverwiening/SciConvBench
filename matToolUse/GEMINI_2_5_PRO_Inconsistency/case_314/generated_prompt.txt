Create a file named INCAR for the PBE ground-state calculation with the following content:
SYSTEM = C
PREC = Normal
ENCUT = 450
EDIFF = 1E-5
IBRION = -1
NSW = 0
ISIF = 2
ISMEAR = 0
SIGMA = 0.05
ALGO = Normal
LREAL = Auto
LWAVE = .TRUE.
LCHARG = .TRUE.
ISPIN = 1
Execute the VASP calculation by running the command: bash run_vasp.sh
Save the INCAR file from the PBE step by running the command: cp INCAR INCAR1
Create a new file named INCAR for the HSE calculation with the following content:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=0
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
HSE06=.TRUE.
HFSCREEN=0.2
TIME=0.4
AEXX=0.25
AGGAX=0.75
LMAXFOCK=4
PRECFOCK=Fast
Execute the second VASP calculation by running the command: bash run_vasp.sh
Save the INCAR file from the HSE step by running the command: cp INCAR INCAR2
Extract the band gap by running the command: python gap.py
The final output is the numerical value printed to standard output by the gap.py script.
