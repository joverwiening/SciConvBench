Create a file named INCAR.
Set the INCAR parameter ALGO to Fast.
Set the INCAR parameter EDIFF to 0.0002.
Set the INCAR parameter ENCUT to 520.0.
Set the INCAR parameter IBRION to 2.
Set the INCAR parameter ISIF to 3.
Set the INCAR parameter ISMEAR to -5.
Set the INCAR parameter ISPIN to 2.
Set the INCAR parameter LASPH to .TRUE..
Set the INCAR parameter LORBIT to 11.
Set the INCAR parameter LREAL to Auto.
Set the INCAR parameter LWAVE to .FALSE..
Set the INCAR parameter MAGMOM to 31*0.0.
Set the INCAR parameter NELM to 100.
Set the INCAR parameter NSW to 99.
Set the INCAR parameter PREC to Accurate.
Set the INCAR parameter SIGMA to 0.05.
Execute the command `bash run_vasp.sh` to run the VASP calculation.
Execute the command `cp INCAR INCAR1` to preserve the input file.
Execute the command `python get_energy.py` to extract the result.
The final output is the text printed to standard output by the `python get_energy.py` script.
