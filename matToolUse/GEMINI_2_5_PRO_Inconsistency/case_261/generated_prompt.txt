Retrieve a primitive starting structure for CoSb3 with space group Im-3.
Use the LDA pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/co.upf for Cobalt.
Use the LDA pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/sb.upf for Antimony.
Set the plane-wave kinetic energy cutoff (ecutwfc) to 80 Rydbergs for all calculations.
Perform a variable-cell relaxation (vc-relax) on the starting structure.
For the vc-relax calculation, use a 6x6x6 Monkhorst-Pack k-point grid.
The vc-relax k-point grid must be gamma-centered with a half shift.
Set the total energy convergence threshold (etot_conv_thr) for the vc-relax to 1.0e-8 Ry.
Set the force convergence threshold (forc_conv_thr) for the vc-relax to 1.0e-7 Ry/Bohr.
After the vc-relax is complete, perform a self-consistent field (scf) calculation on the relaxed structure.
For the scf calculation, use an 8x8x8 Monkhorst-Pack k-point grid.
The scf k-point grid must be gamma-centered with a half shift.
Set the electron density convergence threshold (conv_thr) for the scf calculation to 1.0e-8.
Return the fully relaxed structure from the vc-relax calculation.
Return the final total energy from the scf calculation.
