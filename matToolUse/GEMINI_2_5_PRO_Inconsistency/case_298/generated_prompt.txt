Create a file named INCAR.
The INCAR file will contain the line `ALGO = Fast`.
The INCAR file will contain the line `EDIFF = 0.0004`.
The INCAR file will contain the line `ENCUT = 520.0`.
The INCAR file will contain the line `IBRION = 2`.
The INCAR file will contain the line `ISIF = 3`.
The INCAR file will contain the line `ISMEAR = -5`.
The INCAR file will contain the line `ISPIN = 2`.
The INCAR file will contain the line `LASPH = .TRUE.`.
The INCAR file will contain the line `LMAXMIX = 4`.
The INCAR file will contain the line `LORBIT = 11`.
The INCAR file will contain the line `LREAL = Auto`.
The INCAR file will contain the line `LWAVE = .FALSE.`.
The INCAR file will contain the line `MAGMOM = 23*-0.001 8*-0.0`.
The INCAR file will contain the line `NELM = 100`.
The INCAR file will contain the line `NSW = 99`.
The INCAR file will contain the line `PREC = Accurate`.
The INCAR file will contain the line `SIGMA = 0.05`.
Execute the command `bash run_vasp.sh` to run the VASP calculation.
After the calculation finishes, execute the command `cp INCAR INCAR1`.
Execute the command `python get_energy.py` to extract the energy.
The final result is the single numerical value printed by the `get_energy.py` script.
