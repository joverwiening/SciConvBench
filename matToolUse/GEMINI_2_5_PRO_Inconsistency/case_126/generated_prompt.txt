Perform a variable-cell relaxation calculation for wurtzite ZnO.
Retrieve the primitive starting structure for ZnO with space group P6_3mc.
Use the LDA pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/zn.upf for Zinc.
Use the LDA pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/o.upf for Oxygen.
Allow both the atomic positions and the lattice vectors to relax.
Set the kinetic energy cutoff for wavefunctions (ecutwfc) to 80 Ry.
Set the kinetic energy cutoff for charge density (ecutrho) to 640 Ry.
Use a gamma-centered 8x8x6 k-point grid.
Set the convergence threshold for the total energy between ionic steps to be consistent with 1 meV/atom.
Set the convergence threshold for forces to 1.0e-4 Ry/Bohr.
Set the convergence threshold for the electronic self-consistency loop to 1.0e-8 Ry.
Use fixed occupations for the electronic states.
The final output must be the fully relaxed structure, including the final lattice vectors and atomic coordinates.
