Create an INCAR file to be used for all VASP calculations.
Set ENCUT to 450 in the INCAR file.
Set EDIFF to 1E-5 in the INCAR file.
Set EDIFFG to -0.05 in the INCAR file.
Set IBRION to 1 in the INCAR file.
Set ISIF to 2 in the INCAR file.
Set ISMEAR to 1 in the INCAR file.
Set ISPIN to 1 in the INCAR file.
Set LCHARG to .FALSE. in the INCAR file.
Set LREAL to Auto in the INCAR file.
Set LWAVE to .FALSE. in the INCAR file.
Set NELM to 100 in the INCAR file.
Set NSW to 200 in the INCAR file.
Set POTIM to 0.2 in the INCAR file.
Set PREC to Normal in the INCAR file.
Set SIGMA to 0.2 in the INCAR file.
Execute the command `python op.py CO POTCAR-CO POSCAR-CO`.
Execute the command `python op.py surface POTCAR-Pdface POSCAR-Pdface`.
Execute the command `python op.py absorbed POTCAR-PdCO POSCAR-PdCO`.
Execute the command `bash ./calc_absorption_energy.sh`.
The final output is the numerical value printed to standard output by the `calc_absorption_energy.sh` script.
