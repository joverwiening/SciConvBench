Create a file named INCAR with the following content:
ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 35*2.758
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the command `bash run_vasp.sh` to run the VASP calculation.
After the VASP calculation finishes, execute the command `cp INCAR INCAR1`.
Execute the command `python get_energy.py` to extract the final total energy.
The final output is the numerical value printed to standard output by `get_energy.py`.
