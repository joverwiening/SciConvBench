Create a VASP input file named INCAR.
The INCAR file will contain the following parameters:
ALGO = Fast
EDIFF = 0.00025
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LDAU = .TRUE.
LDAUJ = 0 0 0
LDAUL = 0 2 0
LDAUPRINT = 1
LDAUTYPE = 2
LDAUU = 0 5.3 0
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 7*0.009000000000000001 8*3.48 24*0.127
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
The POSCAR input file is located at 'POSCAR'.
The KPOINTS input file is located at 'KPOINTS'.
The POTCAR input file is located at 'POTCAR'.
Execute the VASP calculation by running the command `bash run_vasp.sh`.
After the VASP calculation, create a copy of the INCAR file named INCAR1 using the command `cp INCAR INCAR1`.
Extract the final total energy by running the command `python get_energy.py`.
The final output will be the numerical value printed by `get_energy.py`.
