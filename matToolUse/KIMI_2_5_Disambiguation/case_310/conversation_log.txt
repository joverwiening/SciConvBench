Q: I need to create an INCAR file for Step 1 (ground-state calculation) before running VASP. Since `data.json` doesn't provide an explicit INCAR parameter block for Step 1, I need to determine what parameters are appropriate for a standard PBE ground-state calculation that will properly prepare the WAVECAR for the subsequent hybrid-functional step.

What specific INCAR parameters should I use for the PBE ground-state calculation in Step 1?
A: For the PBE ground-state calculation in Step 1, use these INCAR parameters:

```
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
```

This is a standard PBE single-point energy calculation with charge density initialization (ICHARG=2), writing WAVECAR and CHGCAR for the subsequent HSE step.
