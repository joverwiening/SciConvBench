Create an INCAR file for Step 1 (ground-state calculation) with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Run VASP using the command: bash run_vasp.sh

Save a copy of the INCAR as INCAR1 using: cp INCAR INCAR1

Create a new INCAR file for Step 2 (hybrid-functional calculation) with the following parameters:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
TIME=0.4

Run VASP again using the command: bash run_vasp.sh

Save a copy of the INCAR as INCAR2 using: cp INCAR INCAR2

Run the post-processing script to extract the band gap: python gap.py

Return the band-gap value exactly as printed by gap.py.
