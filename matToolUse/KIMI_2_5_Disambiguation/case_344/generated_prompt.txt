Step 1 — Relax/optimize the Initial State (IS)

Write the following INCAR file for IS relaxation:

SYSTEM = IS relaxation
ISTART = 0
ENCUT = 450
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
IBRION = 1
ISIF = 2
NSW = 200
EDIFFG = -0.05
POTIM = 0.2
NPAR = 1
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.

Run:
```
python op.py IS POTCARagpd IS1POSCAR
```

Step 2 — Relax/optimize the Final State (FS)

Write the following INCAR file for FS relaxation:

SYSTEM = FS relaxation
ISTART = 0
ENCUT = 450
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
IBRION = 1
ISIF = 2
NSW = 200
EDIFFG = -0.05
POTIM = 0.2
NPAR = 1
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.

Run:
```
python op.py FS POTCARagpd FS1POSCAR
```

Step 3 — Interpolate intermediate images (ASE)

Run:
```
python nebmake.py
```

Step 4 — Run the NEB calculation

Write the following INCAR file for the NEB run:

SYSTEM = NEB calculation
ISTART = 0
ENCUT = 450
ISPIN = 1
ISMEAR = 1
SIGMA = 0.2
IBRION = 3
IOPT = 7
ISIF = 2
NSW = 500
EDIFFG = -0.05
POTIM = 0
SPRING = -5
NPAR = 1
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.
IMAGES = 4

Run:
```
python op2.py ./
```

Step 5 — Extract energies and determine the barrier

Run:
```
bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'
```

Output requirement: Return the reaction-barrier value (in eV) printed by the nebef.pl extraction step, which reports the energy difference between the highest-energy image and the reference energy.
