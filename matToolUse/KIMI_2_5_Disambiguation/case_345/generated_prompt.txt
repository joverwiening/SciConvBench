Step 1 — Relax/optimize the Initial State (IS)

Write the INCAR file for IS relaxation with the following content:

ISPIN = 1
ENCUT = 450
NPAR = 1
EDIFFG = -0.05
IBRION = 1
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
POTIM = 0.2
NSW = 200

Run the command:
python op.py IS POTCARpdch IS1POSCAR

Step 2 — Relax/optimize the Final State (FS)

Write the INCAR file for FS relaxation with the following content:

ISPIN = 1
ENCUT = 450
NPAR = 1
EDIFFG = -0.05
IBRION = 1
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
POTIM = 0.2
NSW = 200

Run the command:
python op.py FS POTCARpdch FS1POSCAR

Step 3 — Interpolate intermediate images (ASE)

Run the command:
python nebmake.py

Step 4 — Run the NEB calculation

Write the INCAR file for the NEB calculation with the following content:

ISPIN = 1
ENCUT = 450
NPAR = 1
EDIFFG = -0.05
IBRION = 3
IOPT = 7
ISIF = 2
ISMEAR = 1
SIGMA = 0.2
POTIM = 0
SPRING = -5
LCLIMB = .TRUE.
NSW = 200

Run the command:
python op2.py ./

Step 5 — Extract energies and determine the barrier

Run the command:
bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'

Return the reaction-barrier value produced by the extraction step.
