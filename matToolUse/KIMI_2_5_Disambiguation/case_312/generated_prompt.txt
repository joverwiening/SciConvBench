Execute the following steps to compute the electronic band gap of BN using VASP with the hybrid-functional workflow:

Step 1 — Ground-state calculation
Create an INCAR file with the following parameters for the PBE ground-state calculation:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISTART=0
ICHARG=2
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1

Run VASP using the provided launch script:
bash run_vasp.sh

Save a copy of the INCAR used for Step 1:
cp INCAR INCAR1

Step 2 — Hybrid-functional calculation
Create a new INCAR file with the following parameters for the hybrid-functional calculation:
PREC=Normal
ENCUT=450
NELM=500
IBRION=-1
ISPIN=1
NSW=0
ISIF=2
EDIFF=1E-5
EDIFFG=-5E-3
ISMEAR=0
SIGMA=0.05
LWAVE=.T.
LCHARG=.T.
LREAL=Auto
LPLANE=.TRUE.
NPAR=1
KPAR=4
NCORE=1
LORBIT=11
ALGO=All
LHFCALC=.TRUE.
TIME=0.4

Run VASP again for the hybrid-functional step:
bash run_vasp.sh

Save a copy of the INCAR used for Step 2:
cp INCAR INCAR2

Step 3 — Band gap extraction
Run the post-processing script to extract the band gap:
python gap.py

Return the band-gap value exactly as printed by gap.py.
