Retrieve a primitive starting structure for CoSb3 with skutterudite structure, space group Im-3, and 8 atoms per primitive cell.
Perform a variable-cell relaxation (vc-relax) calculation.
Use the LDA pseudopotential files co.upf and sb.upf from the PseudoDojo/SR_v0.4.1/LDA_standard directory.
Set the plane-wave energy cutoff (ecutwfc) to 60 Rydberg.
Set the charge density cutoff (ecutrho) to 240 Rydberg.
Set the total energy convergence threshold for the relaxation (etot_conv_thr) to 1.0e-6 Rydberg.
Set the force convergence threshold for the relaxation (forc_conv_thr) to 1.0e-4 Rydberg/Bohr.
Use a gamma-centered 4x4x4 k-point grid for the relaxation.
Do not apply starting magnetization to any atomic species.
After relaxation, perform a self-consistent field (scf) calculation on the relaxed structure.
Use the same pseudopotentials, ecutwfc, and ecutrho values as the relaxation.
Set the total energy convergence threshold for the scf calculation (conv_thr) to 1.0e-8 Rydberg.
Use a gamma-centered 6x6x6 k-point grid for the scf calculation.
After the scf calculation, perform a non-self-consistent field (nscf) calculation for band structure.
Use the same pseudopotentials, ecutwfc, and ecutrho values as the scf calculation.
Set the total energy convergence threshold for the nscf calculation (conv_thr) to 1.0e-8 Rydberg.
Use a gamma-centered 8x8x8 k-point grid for the nscf calculation.
After the nscf calculation, run a bands calculation using pw.x with calculation="bands".
After the bands calculation, perform band post-processing.
After the band post-processing, perform DOS post-processing, feeding the calculation directly from the scf result.
