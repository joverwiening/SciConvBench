Set NSW = 100 in the INCAR files for all three geometry optimization steps (CO, clean surface, adsorbed system).
Write an INCAR file for Step 1 (CO optimization) with the following parameters: SYSTEM = CO optimization, ENCUT = 450, EDIFF = 1e-6, EDIFFG = -0.05, IBRION = 1, ISIF = 2, ISMEAR = 1, SIGMA = 0.2, NSW = 100, POTIM = 0.2, ISPIN = 1.
Write an INCAR file for Step 2 (clean surface optimization) with the following parameters: SYSTEM = Ir surface optimization, ENCUT = 450, EDIFF = 1e-6, EDIFFG = -0.05, IBRION = 1, ISIF = 2, ISMEAR = 1, SIGMA = 0.2, NSW = 100, POTIM = 0.2, ISPIN = 1.
Write an INCAR file for Step 3 (adsorbed system optimization) with the following parameters: SYSTEM = CO adsorbed on Ir optimization, ENCUT = 450, EDIFF = 1e-6, EDIFFG = -0.05, IBRION = 1, ISIF = 2, ISMEAR = 1, SIGMA = 0.2, NSW = 100, POTIM = 0.2, ISPIN = 1.
Execute Step 1 by running the command: python op.py CO POTCAR-CO POSCAR-CO.
Execute Step 2 by running the command: python op.py surface POTCAR-Irface POSCAR-Irface.
Execute Step 3 by running the command: python op.py absorbed POTCAR-IrCO POSCAR-IrCO.
Execute Step 4 by running the command: bash ./calc_absorption_energy.sh.
Return the adsorption energy value printed by the calc_absorption_energy.sh script.
