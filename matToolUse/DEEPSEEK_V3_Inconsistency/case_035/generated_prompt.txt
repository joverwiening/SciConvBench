Retrieve a primitive BaTiO3 perovskite structure with space group P4mm and 5 atoms per primitive cell using a structure-retrieval tool.
Perform a variable-cell relaxation (vc-relax) using the retrieved structure as the starting configuration.
Use the LDA pseudopotential files ba.upf, ti.upf, and o.upf from the PseudoDojo/SR_v0.4.1/LDA_standard directory.
Set the plane-wave energy cutoff for wavefunctions (ecutwfc) to 50 Ry.
Set the total energy convergence threshold for the relaxation (etot_conv_thr) to 1.0e-6 Ry.
Set the force convergence threshold for the relaxation (forc_conv_thr) to 1.0e-4 Ry/Bohr.
Use a gamma-centered 4x4x4 k-point grid for the relaxation and SCF calculations.
Set the SCF convergence threshold (conv_thr) to 1.0e-8 Ry.
After relaxation, perform a self-consistent field (scf) calculation with the same k-point grid and convergence settings.
Perform a non-self-consistent field (nscf) calculation for band structure using a gamma-centered 8x8x8 k-point grid.
Run a bands calculation (pw.x with calculation="bands") using the path from the nscf calculation.
Perform band post-processing to obtain the band structure data.
Perform DOS post-processing, feeding the calculation directly from the SCF result, to obtain the density of states.
The entire calculation must achieve a final energy convergence of 1 meV/atom.
