Perform a variable-cell relaxation (vc-relax) calculation for NbSe2.
Use the primitive structure with formula NbSe2, layered structure, space group P6_3/mmc, and 3 atoms per primitive cell.
Retrieve the starting structure from a structure database using the provided metadata.
Use the LDA pseudopotentials nb.upf and se.upf from the PseudoDojo/SR_v0.4.1/LDA_standard directory.
Set the plane-wave energy cutoff (ecutwfc) to 60 Ry.
Set the total-energy convergence threshold (etot_conv_thr) to 1.0e-8 Ry.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7 Ry/bohr.
Set the target pressure (press) to 0.0 kbar for the variable-cell relaxation.
Use an automatic Monkhorst-Pack k-point grid with a half shift and a target density of 0.04 Å^-3.
After the vc-relax finishes, run a self-consistent field (SCF) calculation on the relaxed structure.
For the final SCF, use the same k-point grid and energy cutoff as the relaxation.
Set the SCF convergence threshold (conv_thr) to 1.0e-8 Ry.
Return the fully relaxed atomic structure and the final total energy from the SCF calculation.
