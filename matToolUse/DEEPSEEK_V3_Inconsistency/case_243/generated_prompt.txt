Retrieve a primitive wurtzite ZnO structure with space group P6_3mc and 4 atoms per primitive cell.
Use the pseudopotential files zn.upf and o.upf from the PseudoDojo/SR_v0.4.1/LDA_standard directory.
Set the plane-wave energy cutoff (ecutwfc) to 60 Ry.
Set the k-point grid to a 6x6x4 Monkhorst-Pack grid with a half shift.
Set the convergence threshold for self-consistency (conv_thr) to 1.0e-8.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-8.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7.
Perform a variable-cell relaxation (vc-relax) calculation.
After the vc-relax finishes, run a self-consistent field calculation on the original, unrelaxed starting structure.
Return the fully relaxed structure from the vc-relax calculation.
Return the final total energy from the SCF calculation on the original structure.
