Create an INCAR file for the PBE ground-state calculation with the following parameters: PREC=Normal, ENCUT=450, ISIF=2, EDIFF=1E-5, ISMEAR=0, SIGMA=0.05.
Run the VASP calculation using the command `bash run_vasp.sh`.
Save a copy of the INCAR file as INCAR1 using the command `cp INCAR INCAR1`.
Create a new INCAR file for the HSE calculation using the provided parameter block from data.json.
Run the VASP calculation again using the command `bash run_vasp.sh`.
Save a copy of the INCAR file as INCAR2 using the command `cp INCAR INCAR2`.
Run the post-processing script using the command `python gap.py`.
Return the band-gap value exactly as printed by `gap.py`.
