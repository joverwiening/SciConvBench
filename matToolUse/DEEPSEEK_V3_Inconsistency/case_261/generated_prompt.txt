Use the LDA pseudopotentials from PseudoDojo/SR_v0.4.1/LDA_standard/.
Retrieve a primitive CoSb3 structure with the skutterudite type, space group Im-3, and 8 atoms per primitive cell.
Perform a variable-cell relaxation (vc-relax) calculation.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-8 Ry.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7 Ry/bohr.
Set the self-consistency convergence threshold (conv_thr) to 1.0e-8 Ry.
Set the plane-wave kinetic energy cutoff (ecutwfc) to 50 Ry.
Use an automatic Monkhorst-Pack k-point grid with a half shift and keep it gamma-centered.
Set the automatic k-point grid to a density of 0.04 2π/Å (equivalent to a spacing of ~0.25 Å⁻¹).
After the vc-relax finishes, run a self-consistent field calculation on the final relaxed structure.
Use the same ecutwfc and k-point grid settings for the final SCF calculation as were used in the relaxation.
Return the fully relaxed atomic structure and the final total energy from the SCF calculation.
