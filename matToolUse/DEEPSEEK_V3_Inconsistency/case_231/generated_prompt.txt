Use the LDA pseudopotential files pb.upf, ti.upf, and o.upf from the PseudoDojo/SR_v0.4.1/LDA_standard set.
Retrieve a primitive perovskite structure for PbTiO3 with space group P4mm and 5 atoms per primitive cell as the starting configuration.
Perform a variable-cell relaxation (vc-relax) calculation on the starting structure.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-8 Ry.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7 Ry/bohr.
Use a plane-wave energy cutoff (ecutwfc) of 50 Ry.
Generate k-points using an automatic Monkhorst-Pack grid with a half shift and a density of 40 points per reciprocal Å.
After the vc-relax finishes, run a self-consistent field (SCF) calculation on the relaxed structure.
Set the SCF convergence threshold (conv_thr) to 1.0e-8 Ry.
Use the same ecutwfc and k-point grid for the SCF as used in the vc-relax.
Return the fully relaxed atomic structure and lattice vectors.
Return the final total energy from the SCF calculation on the relaxed structure.
