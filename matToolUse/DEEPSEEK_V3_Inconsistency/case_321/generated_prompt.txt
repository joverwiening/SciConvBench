Create an INCAR file for a PBE ground-state calculation.
Set the system to be a non-spin-polarized semiconductor calculation.
Use PREC = Normal.
Set ENCUT = 450 eV.
Set IBRION = -1 for a static calculation.
Set NSW = 0 for a single-point energy calculation.
Set ISIF = 2 to allow relaxation of cell shape and volume.
Set EDIFF = 1E-5 for electronic convergence.
Set EDIFFG = -5E-3 for ionic convergence.
Set ISTART = 0 to start from scratch.
Set ICHARG = 2 to compute the charge density from superposition of atomic densities.
Set ISMEAR = 0 and SIGMA = 0.05 for Gaussian smearing.
Set LWAVE = .TRUE. to write the WAVECAR file.
Set LCHARG = .TRUE. to write the CHGCAR file.
Set LREAL = Auto.
Set LPLANE = .TRUE..
Set NPAR = 1.
Set KPAR = 4.
Set NCORE = 1.
Set LORBIT = 11 to generate detailed PROCAR files.
Set ALGO = Normal.
Set GGA = PE for the PBE functional.
Run the VASP calculation using the command 'bash run_vasp.sh'.
After the calculation, save the used INCAR file as INCAR1 with the command 'cp INCAR INCAR1'.
Create a new INCAR file for the HSE06 calculation using the provided parameter block.
Ensure ICHARG is set to 11 to read the charge density from the previous step.
Run the VASP calculation again using the command 'bash run_vasp.sh'.
After the calculation, save the used INCAR file as INCAR2 with the command 'cp INCAR INCAR2'.
Run the post-processing script with the command 'python gap.py'.
Return the band-gap value exactly as printed by the gap.py script.
