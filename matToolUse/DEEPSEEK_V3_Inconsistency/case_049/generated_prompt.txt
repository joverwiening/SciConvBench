Retrieve a primitive corundum structure for Al2O3 with space group R-3c and 5 atoms per primitive cell.
Perform a variable-cell relaxation (vc-relax) calculation.
Use the LDA pseudopotential files al.upf and o.upf from the PseudoDojo/SR_v0.4.1/LDA_standard directory.
Set the plane-wave energy cutoff for wavefunctions (ecutwfc) to 60 Ry.
Set the plane-wave energy cutoff for charge density (ecutrho) to 240 Ry.
Use a gamma-centered 6x6x4 k-point grid for the SCF calculation.
Use a gamma-centered 12x12x8 k-point grid for the NSCF calculation.
Use a Gaussian smearing (smearing='gaussian') with a width (degauss) of 0.01 Ry.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-6 Ry.
Set the force convergence threshold (forc_conv_thr) to 1.0e-4 Ry/Bohr.
Set the convergence threshold for self-consistency (conv_thr) to 1.0e-8 Ry.
Perform a self-consistent field (scf) calculation with the relaxed structure.
Perform a non-self-consistent field (nscf) calculation.
Perform a bands calculation (pw.x with calculation="bands").
Perform band post-processing.
Perform DOS post-processing, feeding the calculation directly from the SCF result and skipping the dedicated NSCF step for DOS.
