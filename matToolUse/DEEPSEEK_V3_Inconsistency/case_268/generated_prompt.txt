Use the LDA pseudopotential files na.upf and bi.upf from the PseudoDojo/SR_v0.4.1/LDA_standard set.
Retrieve a primitive starting structure for Na3Bi with space group P6_3/mmc and 4 atoms per primitive cell.
Set the calculation type to variable-cell relaxation (vc-relax).
After the vc-relax, run a self-consistent field calculation on the relaxed structure.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-8 Ry.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7 Ry/bohr.
Set the self-consistency convergence threshold (conv_thr) to 1.0e-8 Ry.
Set the plane-wave kinetic energy cutoff (ecutwfc) to 60 Ry.
Use an automatic Monkhorst-Pack k-point grid with a half shift and gamma-centering.
Set the target k-point density to 0.04 inverse Ångström.
Return the fully relaxed structure and the final total energy.
