Determine the first-order X-ray diffraction angle 2θ for a cubic crystal.
Use lattice parameter a = 0.5499 nm.
Use X-ray wavelength λ = 0.0537 nm.
Use reflecting planes (211) with h = 2, k = 1, l = 1.
Assume a cubic crystal with interplanar spacing d = a / sqrt(h^2 + k^2 + l^2), so d211 = a / sqrt(6).
Assume no structure-factor or selection-rule constraints beyond the cubic spacing formula.
Use first-order diffraction (n = 1) with Bragg’s law.
Report 2θ in degrees.
Report 2θ to two decimal places.
