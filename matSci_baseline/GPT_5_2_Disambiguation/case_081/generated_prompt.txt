Determine the carrier concentration for a rectangular semiconductor sample using the Hall effect.
Use the given current I = 15 mA.
Use the given magnetic field B = 0.80 T.
Use the given Hall voltage V_H = 24 mV.
Use the given sample thickness t = 0.50 mm (5.0 × 10⁻⁴ m).
Assume the Hall voltage is measured across the full sample width (contact separation equals the sample width).
Assume a single dominant carrier type.
Assume Hall factor r_H = 1.
Compute carrier concentration using n = (I B) / (q V_H t), with q as the elementary charge.
