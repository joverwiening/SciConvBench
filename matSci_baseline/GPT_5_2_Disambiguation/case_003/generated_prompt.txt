Estimate the equilibrium number of vacancies at T = 1443 K.
Use the atomic weight A = 169.90 g/mol.
Use the density ρ = 3.380 g/cm^3.
Assume one atomic site per atom with N = (ρ/A) N_A.
Use N_A = 6.022×10^23 mol^-1.
Use the equilibrium vacancy relation n_v = N exp(-Q_v/(R T)).
Treat Q_v = 87.6 kJ/mol as the vacancy formation energy per mole of vacancies, i.e., Q_v = 87.6×10^3 J/mol.
Use R = 8.314 J/mol·K.
Report the final result as vacancies per cubic meter (vacancies/m^3).
