Determine the fiber volume fraction V_f for a composite. 
The fiber weight (mass) fraction of the composite is 0.361. 
The matrix weight fraction is 0.639 (1 minus the fiber weight fraction). 
The fiber density is 4.277 g/cm^3. 
The matrix density is 2.035 g/cm^3. 
Calculate V_f using the formula V_f = (w_f / rho_f) / (w_f / rho_f + w_m / rho_m).
