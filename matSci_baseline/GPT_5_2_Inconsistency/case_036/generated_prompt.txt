Use a powder diffraction peak from an FCC metal to calculate the cubic lattice parameter a.
Treat the first observed peak as the (111) reflection.
Use the peak position 2θ = 43.5°.
Use Cu Kα₁ radiation with wavelength λ = 1.5406 Å.
Assume first-order Bragg reflection with n = 1.
Use the standard convention θ = (2θ)/2 = 21.75° in Bragg’s law.
Compute the d-spacing from Bragg’s law and then compute a using d111 = a/√3.
