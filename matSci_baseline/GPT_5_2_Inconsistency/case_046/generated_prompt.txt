Determine whether primary α or primary β forms on cooling for a binary eutectic alloy.
Use eutectic composition Ce = 42 wt% B.
Use overall alloy composition C0 = 28 wt% B.
Assume α is the low-B (left) phase on the phase diagram.
Assume β is the high-B (right) phase on the phase diagram.
Treat the description “hypereutectic” as a typo.
Classify the alloy by comparing C0 to Ce, so the alloy is hypoeutectic because C0 < Ce.
