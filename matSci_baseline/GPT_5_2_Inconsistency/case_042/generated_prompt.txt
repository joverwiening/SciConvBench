Determine the diffusion flux Jx across a membrane using Fick’s first law with D = 3.0×10^-11 m^2/s and L = 1 mm.
Use the concentration boundary values C(0) = 0.12 mol/m^3 and C(L) = 0.02 mol/m^3.
Assume a linear concentration profile between x = 0 and x = L so that dC/dx ≈ (C(L) − C(0))/L.
Use the standard signed convention Jx = −D dC/dx and report J as a signed value.
Treat positive Jx as flux in the +x direction, and the stated requirement is that the flux is in the +x direction so J should come out positive.
