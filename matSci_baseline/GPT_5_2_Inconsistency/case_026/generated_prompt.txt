Compute the cubic lattice parameter a for a metal using the density relation ρ = nA/(N_A a^3).
Assume a BCC lattice with unit-cell population n = 2 atoms per unit cell.
Use atomic weight A = 186.76 g/mol.
Use theoretical density ρ = 14.274 g/cm^3 with no rounding during the calculation.
Use Avogadro’s number N_A = 6.022×10^23 mol^-1.
Solve for a and convert the result to nm.
Report the final lattice parameter to 4 significant figures.
