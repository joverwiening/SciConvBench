Q: Should I use the formula exactly as written (ignoring the HCP-specific c dependence) when calculating \(d_{(100)}\)?
A: No. Use the **hexagonal (HCP) interplanar-spacing relation**, which accounts for the hexagonal indices; for \(d_{(100)}\) the result depends only on \(a\) (the \(c\) term drops out because \(l=0\)), but you should still use the hexagonal formula—not \(a/\sqrt{h^2+k^2+l^2}\).

Q: What hexagonal interplanar-spacing formula should I use (e.g., the 3-index \(hkl\) form or the 4-index Miller–Bravais \(hkil\) form)?
A: Use the **hexagonal (HCP) interplanar-spacing relation in the 3-index \(hkl\) form**:

\[
\frac{1}{d_{hkl}^{2}}=\frac{4}{3}\frac{(h^{2}+hk+k^{2})}{a^{2}}+\frac{l^{2}}{c^{2}}.
\]

For \((100)\), \(l=0\), so only the \(a\)-term applies.
