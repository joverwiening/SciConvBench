Calculate the interplanar spacing d_(100) for HCP magnesium with lattice parameters a = 0.321 nm and c = 0.521 nm.
Use the hexagonal (HCP) interplanar-spacing relation in the 3-index hkl form: 1/d_hkl^2 = (4/3)*((h^2 + hk + k^2)/a^2) + (l^2/c^2).
For the (100) plane, use h = 1, k = 0, l = 0 so the c-term drops out.
Report d_(100) in nm as the required unit.
Optionally also provide the equivalent value in Å.
