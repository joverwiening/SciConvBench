Assume the working fluid is air modeled as an ideal gas with specific‑heat ratio γ = 1.4 and gas constant R = 287 J/(kg·K).  
Take the upstream (state 1) static pressure p₁ = 101.3 kPa, static temperature T₁ = 288 K, and Mach number M₁ = 2.0.  

Compute the upstream stagnation pressure p₀₁ using p₀₁ = p₁·(1 + (γ‑1)/2·M₁²)^(γ/(γ‑1)).  

Determine the downstream Mach number M₂ from the normal‑shock relation  
M₂² = [1 + (γ‑1)/2·M₁²] / [γ·M₁² – (γ‑1)/2].  

Calculate the static pressure ratio across the shock  
p₂/p₁ = 1 + (2·γ/(γ+1))·(M₁² – 1).  

Calculate the density ratio across the shock  
ρ₂/ρ₁ = [(γ+1)·M₁²] / [(γ‑1)·M₁² + 2].  

Obtain the downstream static pressure p₂ = p₁·(p₂/p₁).  

Obtain the downstream static temperature from the ideal‑gas relation  
T₂ = T₁·(p₂/p₁) / (ρ₂/ρ₁).  

Compute the downstream density ρ₂ = p₂ / (R·T₂).  

Compute the downstream stagnation pressure p₀₂ using the normal‑shock total‑pressure ratio  
p₀₂/p₀₁ = [ ( (γ+1)·M₁² ) / ( (γ‑1)·M₁² + 2 ) ]^( -γ/(γ‑1) ) · [ ( (γ+1) ) / ( 2·γ·M₁² – (γ‑1) ) ]^( 1/(γ‑1) ).  

Report the following downstream properties: static pressure p₂, static temperature T₂, Mach number M₂, density ρ₂, and the total‑pressure ratio p₀₂/p₀₁.
