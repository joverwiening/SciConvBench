Compute the Mach angle mu as the arcsine of the reciprocal of the Mach number (mu = arcsin(1/M)).  
For Mach 3, calculate mu = arcsin(1/3) ≈ 19.47 degrees.  
Add the wedge angle theta (25 degrees) to mu using the small‑angle approximation beta ≈ mu + theta.  
Thus beta ≈ 19.47° + 25° = 44.47°, so the oblique shock angle beta is approximately 44.5 degrees.
