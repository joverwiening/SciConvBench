Assume a homogeneous slab of thickness L with constant thermal conductivity k (or thermal diffusivity α, which does not affect the steady solution).  
Apply Dirichlet boundary conditions: the temperature at the left surface x = 0 is T_left and the temperature at the right surface x = L is T_right.  
Set the governing steady‑state equation to d²T/dx² = 0 (since ∂T/∂t = 0).  
Integrate twice with respect to x to obtain the temperature distribution:  
 T(x) = T_left + (T_right – T_left)·(x / L).  
Compute the constant heat flux through the slab using Fourier’s law:  
 q = –k·dT/dx = –k·(T_right – T_left) / L.  
Report the linear temperature profile T(x) for 0 ≤ x ≤ L and the constant heat flux q.  
Allow the user to specify the numerical values of L, k (or α), T_left, and T_right; if not provided, use typical engineering values (e.g., L = 0.1 m, k = 200 W/(m·K), T_left = 100 °C, T_right = 0 °C).  
Provide the analytical solution in closed form and optionally a simple script (e.g., in Python or MATLAB) that evaluates T(x) and q for any given set of parameters.
