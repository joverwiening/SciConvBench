Assume the upstream flow depth y₁ is 1 m (a standard reference depth for hydraulic‑jump calculations).  
Compute the sequent depth y₂ using the hydraulic‑jump relation y₂/y₁ = (½)[√(1 + 8 Fr₁²) − 1] with Fr₁ = 0.5.  
Calculate: Fr₁² = 0.25, 8 Fr₁² = 2, √(1 + 2) = √3 ≈ 1.732.  
Thus y₂/y₁ = 0.5 × (1.732 − 1) ≈ 0.366.  
Therefore y₂ = 0.366 × y₁ = 0.366 m.
