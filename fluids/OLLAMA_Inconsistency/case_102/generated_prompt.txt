Compute the downstream static pressure, temperature, and density for an ideal‑gas (γ = 1.4) flow with upstream Mach number M₁ = 2, upstream static pressure P₁ = 101325 Pa, and upstream static temperature T₁ = 288.15 K, using the normal‑shock relations for a perfect gas. Use the standard relations:  

- Pressure ratio across the shock: P₂/P₁ = 1 + 2γ/(γ+1)·(M₁² − 1).  
- Temperature ratio across the shock: T₂/T₁ = [ (1 + ((γ‑1)/2)·M₁²)·(2γ·M₁² − (γ‑1)) ] / [ (γ+1)²·M₁² ].  
- Density ratio across the shock: ρ₂/ρ₁ = ( (γ+1)·M₁² ) / ( (γ‑1)·M₁² + 2 ).  

Calculate P₂ = (P₂/P₁)·P₁, T₂ = (T₂/T₁)·T₁, and ρ₂ = (ρ₂/ρ₁)·ρ₁, where ρ₁ = P₁/(R·T₁) with R = 287 J/(kg·K). Output the numerical values of P₂ (Pa), T₂ (K), and ρ₂ (kg/m³).
