Calculate the downstream depth y2 for the hydraulic jump as follows.
Use the given channel width b = 3 m, upstream depth y1 = 0.4 m, and upstream velocity V1 = 6.0 m/s.
Compute the discharge Q = b · y1 · V1 = 3 · 0.4 · 6.0 = 7.2 m³/s.
Express the downstream velocity V2 in terms of the unknown depth y2 using continuity: V2 = Q / (b · y2) = 7.2 / (3 · y2) = 2.4 / y2.
Apply Bernoulli’s equation (energy conservation) between the upstream and downstream sections: y1 + V1²/(2g) = y2 + V2²/(2g), where g = 9.81 m/s².
Substitute the known values and V2 expression to obtain the equation: y2 + (0.2937 / y2²) = 2.235, where 0.2937 = (2.4)² / (2g).
Rearrange to a cubic form: y2³ – 2.235 y2² + 0.2937 = 0.
Solve this cubic equation for the positive real root; the physically relevant solution is y2 ≈ 2.18 m.
Report the downstream depth y2 as approximately 2.18 meters.
