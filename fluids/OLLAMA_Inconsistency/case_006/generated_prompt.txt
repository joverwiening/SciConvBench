Calculate the downstream properties of a normal shock for air with γ = 1.4 and upstream Mach number M₁ = 2.0.  
Compute the downstream Mach number using M₂ = sqrt[ ((γ‑1)M₁² + 2) / (2γM₁² – (γ‑1)) ].  
Compute the static‑pressure ratio p₂/p₁ = 1 + (2γ/(γ+1))·(M₁² – 1).  
Compute the density ratio ρ₂/ρ₁ = ((γ+1)M₁²) / ((γ‑1)M₁² + 2).  
Compute the temperature ratio T₂/T₁ = (p₂/p₁) / (ρ₂/ρ₁).  
Report the numerical results: M₂ ≈ 0.577, p₂/p₁ = 4.5, ρ₂/ρ₁ ≈ 2.667, T₂/T₁ ≈ 1.688.
