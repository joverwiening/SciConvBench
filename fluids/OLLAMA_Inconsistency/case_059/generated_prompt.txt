Use the standard gravitational acceleration g = 9.81 m/s².  
Compute the critical depth y_c for a rectangular open channel with unit‑width discharge q = 1.0 m²/s using the relation q² = g y_c³.  
Calculate y_c = (q² / g)^(1/3) = (1.0² / 9.81)^(1/3) ≈ (0.10194)^(1/3) ≈ 0.466 m.  
Report the critical depth as y_c ≈ 0.466 m.
