Q: Which wave speed formula should be used: the shallow‑water expression c = √(g h) or the deep‑water expression c = √(g λ / 2π)?
A: Use the deep‑water expression c = √(g λ / 2π).

Q: Use the deep‑water wave speed formula c = √(g λ / 2π).  
Insert the given values: g = 9.81 m/s², λ = 20 m.  
Compute the argument of the square root: (9.81 × 20) / (2π) = 196.2 / 6.283185307 ≈ 31.235.  
Take the square root: √31.235 ≈ 5.59 m/s.  
Therefore, the deep‑water wave speed is approximately 5.6 m/s.
A: The deep‑water wave phase speed is  

\[
c = \sqrt{\frac{g\,\lambda}{2\pi}} = \sqrt{\frac{9.81\;\text{m/s}^2 \times 20\;\text{m}}{2\pi}} \approx 5.6\;\text{m/s}.
