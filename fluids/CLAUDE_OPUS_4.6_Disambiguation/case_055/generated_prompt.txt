Calculate the boundary work done during the polytropic compression of Nitrogen gas.
The process is polytropic with a polytropic index n = 1.25.
The initial pressure is P1 = 100 kPa.
The final pressure is P2 = 600 kPa.
The initial volume is V1 = 0.2 m³.
Treat Nitrogen as an ideal gas.
Assume the initial temperature is 300 K (approximately standard ambient temperature).
Determine the final volume V2 using the polytropic relation P1 * V1^n = P2 * V2^n.
Compute the work using the polytropic work formula: W = (P2 * V2 - P1 * V1) / (1 - n).
Report the work done on the gas as a positive value, following the standard engineering convention for compression work.
Report the result in kilojoules (kJ).
