Calculate the cavitation index (sigma) for a valve using the following parameters.
The upstream pressure P_in is 400 kPa.
The downstream pressure P_out is 150 kPa.
The vapor pressure of the fluid P_v is 2.5 kPa.
The cavitation index is defined as sigma = (P_out - P_v) / (P_in - P_out).
Report the resulting dimensionless cavitation index value.
