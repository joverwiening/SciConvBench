Write a Python script that computes the lift coefficient of a NACA 4412 airfoil at 5 degrees angle of attack using thin airfoil theory.

The camber line is defined by the standard NACA 4-digit camber equations with maximum camber of 4% (m = 0.04) located at 40% chord (p = 0.40).

The camber line equations are: yc = (m / p^2) * (2*p*x - x^2) for 0 <= x <= p, and yc = (m / (1 - p)^2) * ((1 - 2*p) + 2*p*x - x^2) for p < x <= 1, where x is normalized by chord length.

Use the standard thin airfoil theory Fourier coefficient approach: transform the chordwise coordinate x to theta via x = (c/2)*(1 - cos(theta)), where theta ranges from 0 to pi.

Compute the Fourier coefficients A0 and A1 by numerically evaluating the integrals: A0 = alpha - (1/pi) * integral from 0 to pi of (dz/dx) d(theta), and A1 = (2/pi) * integral from 0 to pi of (dz/dx) * cos(theta) d(theta), where dz/dx is the slope of the camber line.

The lift coefficient is given by Cl = 2*pi*(A0 + A1/2).

Use 1000 discrete points along theta from 0 to pi for numerical integration.

The angle of attack is 5 degrees, converted to radians for computation.

The script should print the computed lift coefficient Cl to the console.

The script should also print the zero-lift angle of attack (alpha_L0) in degrees for reference.

Use only the Python standard library and NumPy.
