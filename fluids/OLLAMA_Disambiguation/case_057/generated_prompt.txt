Calculate the static temperature ratio across a normal shock wave for an upstream Mach number of 2.0 and a specific‑heat ratio γ = 1.4. Use the normal‑shock temperature‑ratio formula  

T₂/T₁ = [ (2 γ M₁² – (γ – 1)) · ((γ – 1) M₁² + 2) ] / [ (γ + 1)² · M₁² ].  

Substituting M₁ = 2.0 and γ = 1.4 gives  

T₂/T₁ = (10.8 · 3.6) / (2.4² · 4) = 38.88 / 23.04 ≈ 1.69.  

Therefore, the static temperature downstream of the shock is about 1.69 times the upstream static temperature.
