Determine the Darcy friction factor for a flow with Reynolds number Re = 2.5 × 10⁵.

Assume the pipe is a commercial steel pipe with an absolute roughness ε = 4.5 × 10⁻⁵ m (0.045 mm).  
Assume a representative pipe inner diameter D = 0.10 m.  

Calculate the relative roughness ε/D = 4.5 × 10⁻⁴.  

Use the Swamee‑Jain explicit approximation for turbulent flow:  

f = 0.25 / [log₁₀( (ε/D)/3.7 + 5.74 / Re⁰·⁹ )]²  

Substitute ε/D = 4.5 × 10⁻⁴ and Re = 2.5 × 10⁵:  

f = 0.25 / [log₁₀( 1.216 × 10⁻⁴ + 7.95 × 10⁻⁵ )]²  
f ≈ 0.0183  

Report the Darcy friction factor as f ≈ 0.018 (dimensionless).  

If a more precise value is required, solve the Colebrook‑White equation iteratively using the same ε, D, and Re values.
