Determine the Taylor number for flow between rotating cylinders with a 2 mm gap.

Use the inner cylinder radius r_i = 0.05 m and the outer cylinder radius r_o = r_i + 0.002 m = 0.052 m, giving a gap d = r_o – r_i = 0.002 m.

The inner cylinder rotates at ω_i = 10.5 rad/s, the outer cylinder is stationary (ω_o = 0 rad/s).

Assume a fluid with kinematic viscosity ν = 1.0 × 10⁻⁵ m²/s.

Compute the Taylor number using the standard definition for inner‑cylinder rotation only:
Ta = ( (ω_i · r_i · d) / ν )² · (r_i / d).

Calculate:
A = (10.5 · 0.05 · 0.002) / 1.0 × 10⁻⁵ = 105.
A² = 11025.
r_i / d = 0.05 / 0.002 = 25.
Ta = 11025 · 25 = 275 625 ≈ 2.8 × 10⁵.

The Taylor number for the specified configuration is approximately 2.8 × 10⁵.
