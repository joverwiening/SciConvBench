Use the stagnation temperature formula T0 = T * (1 + (γ‑1)/2 * M²).  
Insert the given values: ambient static temperature T = 220 K, γ = 1.4, Mach number M = 2.5.  
Calculate the term (γ‑1)/2 * M² = (0.4/2) * (2.5)² = 0.2 * 6.25 = 1.25.  
Add 1 to obtain the multiplier: 1 + 1.25 = 2.25.  
Multiply by the static temperature: T0 = 220 K * 2.25 = 495 K.  
Therefore, the stagnation temperature on the rocket nose is 495 K.
