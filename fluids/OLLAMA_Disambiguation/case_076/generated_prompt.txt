Assume water density is 1000 kg/m³, the inlet diameter of the conical draft tube is 0.5 m, the outlet diameter is 1.0 m, and the tube length is 2.0 m.  
Calculate the inlet cross‑sectional area A_in = π (d_in)² / 4.  
Calculate the outlet cross‑sectional area A_out = π (d_out)² / 4.  
Apply continuity to find the outlet velocity: V_out = (A_in / A_out) × V_in.  
Compute the kinetic‑energy efficiency η as the ratio of outlet to inlet kinetic energy: η = (V_out²) / (V_in²).  
Substitute the numbers: A_in = 0.196 m², A_out = 0.785 m², V_out = 2.5 m/s, η = 0.0625 (6.25 %).  
Report the draft‑tube efficiency as approximately 6.3 % (rounded).  
State that this is a simplified estimate that neglects frictional and turbulent losses.
