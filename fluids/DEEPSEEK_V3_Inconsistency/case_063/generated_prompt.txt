The task is to find the critical depth for a rectangular channel flow.
The flow is described as critical, with a given Froude number of 0.2 for a specific velocity and depth.
Use the discharge per unit width, q, as the primary flow variable.
Assume a standard, reasonable value for the discharge per unit width, q, of 1.0 cubic meter per second per meter (m²/s).
Calculate the critical depth, y_c, using the formula y_c = (q² / g)^(1/3), where g is the acceleration due to gravity (9.81 m/s²).
