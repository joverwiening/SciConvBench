Assume the upstream Mach number (M1) is 2.0.
Assume the upstream static pressure (P1) is 101325 Pascals (standard atmospheric pressure).
Assume the upstream static temperature (T1) is 288.15 Kelvin (standard atmospheric temperature).
Compute the downstream Mach number (M2) using the ideal gas normal shock relation: M2^2 = [(gamma-1)*M1^2 + 2] / [2*gamma*M1^2 - (gamma-1)].
Compute the downstream static pressure (P2) using the relation: P2/P1 = 1 + [2*gamma/(gamma+1)]*(M1^2 - 1).
Compute the downstream static temperature (T2) using the relation: T2/T1 = [ (2*gamma*M1^2 - (gamma-1)) * ((gamma-1)*M1^2 + 2) ] / [ (gamma+1)^2 * M1^2 ].
Compute the downstream stagnation pressure ratio (P02/P01) using the relation: P02/P01 = [ ( (gamma+1)*M1^2 ) / ( (gamma-1)*M1^2 + 2 ) ]^(gamma/(gamma-1)) * [ (gamma+1) / (2*gamma*M1^2 - (gamma-1)) ]^(1/(gamma-1)).
Report the computed values for M2, P2, T2, and P02/P01.
