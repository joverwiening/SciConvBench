The task is to compute a transient cooling curve.
The object is a solid sphere.
Use the lumped-capacitance method for the calculation.
The Biot number is 0.05.
The x-axis of the curve represents the Fourier number.
The y-axis of the curve represents the non-dimensional temperature ratio (T(t) - T_inf) / (T_i - T_inf).
Compute the curve for Fourier numbers ranging from 0 to 100.
