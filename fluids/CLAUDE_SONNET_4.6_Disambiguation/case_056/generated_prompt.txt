Calculate the stagnation pressure at the nose of a jet flying at Mach 1.5 with an ambient static pressure of 20 kPa.
Since the Mach number is 1.5 (supersonic), a normal shock exists at the nose of the jet.
Apply the normal shock relations to find the static pressure ratio across the shock (P2/P1) using M1 = 1.5.
Use the normal shock static pressure ratio formula: P2/P1 = (2*gamma*M1^2 - (gamma - 1)) / (gamma + 1), where gamma = 1.4.
Compute P2/P1 = (2*1.4*1.5^2 - 0.4) / 2.4 = (6.3 - 0.4) / 2.4 = 5.9 / 2.4 = 2.4583.
Calculate the static pressure behind the shock: P2 = 2.4583 * 20 kPa = 49.167 kPa.
Determine the Mach number behind the normal shock (M2) using: M2^2 = ((gamma-1)*M1^2 + 2) / (2*gamma*M1^2 - (gamma-1)).
Compute M2^2 = (0.4*2.25 + 2) / (2*1.4*2.25 - 0.4) = (0.9 + 2) / (6.3 - 0.4) = 2.9 / 5.9 = 0.4915, so M2 = 0.7011.
Apply the isentropic stagnation pressure relation behind the shock: P0 = P2 * (1 + (gamma-1)/2 * M2^2)^(gamma/(gamma-1)).
Compute the isentropic factor: (1 + 0.2 * 0.4915)^3.5 = (1.0983)^3.5 = 1.3961.
Calculate the stagnation pressure: P0 = 49.167 kPa * 1.3961 = 68.64 kPa.
Report the stagnation pressure at the nose of the jet as approximately 68.6 kPa.
