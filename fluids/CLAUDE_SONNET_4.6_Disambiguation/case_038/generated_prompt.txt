Determine the specific work output of an ideal Brayton cycle using the following parameters and method.

Use air as the working fluid with Cp = 1.005 kJ/kg·K and γ = 1.4.
The pressure ratio (rp) is 10.
The compressor inlet temperature is T1 = 300 K.
The turbine inlet temperature is T3 = 1200 K.

Assume an ideal (isentropic) Brayton cycle with no component inefficiencies.

Calculate the compressor outlet temperature using T2 = T1 × (rp)^((γ-1)/γ).
Calculate the turbine outlet temperature using T4 = T3 / (rp)^((γ-1)/γ).
Calculate the specific compressor work as Wc = Cp × (T2 - T1).
Calculate the specific turbine work as Wt = Cp × (T3 - T4).
Calculate the net specific work output as W_net = Wt - Wc.
Express the final answer in kJ/kg.
