Calculate the specific speed of a Francis turbine using the specific speed formula: Ns = N * sqrt(P) / H^(5/4).
Use rotational speed N = 450 rpm.
Use power output P = 5000 kW.
Use net head H = 120 meters.
Compute sqrt(P) = sqrt(5000) ≈ 70.711.
Compute H^(5/4) = 120^(5/4).
Calculate 120^(1/4) = (120)^0.25 ≈ 3.3096.
Calculate 120^(5/4) = 120 * 3.3096 ≈ 397.15.
Compute Ns = 450 * 70.711 / 397.15.
Compute numerator = 450 * 70.711 ≈ 31819.8.
Compute Ns = 31819.8 / 397.15 ≈ 80.12.
Express the final result as Ns ≈ 80.12 rpm (in metric kW units).
