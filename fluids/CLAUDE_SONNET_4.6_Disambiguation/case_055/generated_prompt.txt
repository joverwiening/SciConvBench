Calculate the work done during the polytropic compression of Nitrogen gas.
The initial pressure P1 is 100 kPa.
The final pressure P2 is 600 kPa.
The initial volume V1 is 0.2 m³.
The process is polytropic with polytropic index n = 1.25.
Use the polytropic relation P * V^n = constant to find the final volume V2.
Calculate V2 using V2 = V1 * (P1/P2)^(1/n).
Calculate the work done using the polytropic work formula: W = (P2*V2 - P1*V1) / (1 - n).
Express the final answer in Joules (J) or kilojoules (kJ).
Note that the work value will be negative, indicating work is done on the gas during compression.
