Determine the torque measured by a rotational viscometer using the Couette (concentric cylinder) viscometer model.

The fluid dynamic viscosity is mu = 0.5 Pa·s.
The inner cylinder radius is R1 = 0.02 m.
The gap between the inner and outer cylinder is d = 0.001 m, so the outer cylinder radius is R2 = 0.021 m.
The cylinder height is h = 0.05 m.
The rotational speed is N = 100 rpm, which converts to angular velocity omega = 100 × 2π / 60 rad/s.
Assume the gap is small relative to the radius, so the velocity profile across the gap is linear (narrow-gap Couette approximation).
Calculate the shear rate as gamma_dot = omega × R1 / d, using the inner cylinder radius and gap width.
Calculate the shear stress as tau = mu × gamma_dot.
Calculate the torque as T = tau × 2π × R1^2 × h, representing the tangential force integrated over the inner cylinder surface area times the moment arm R1.
Report the final torque T in Newton-meters (N·m).
