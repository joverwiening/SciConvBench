Solve the steady-state 1D heat equation with internal heat generation in a plane wall.

The governing equation is d²T/dx² + q_gen/k = 0, where q_gen is the volumetric heat generation rate.

The wall thickness is L = 0.20 m.

Place the coordinate origin at the left face, so x runs from 0 to 0.20 m.

The thermal conductivity is k = 15 W/m·K.

The internal heat generation rate is q_gen = 2×10⁵ W/m³.

The boundary condition at x = 0 is T = 50°C.

The boundary condition at x = L = 0.20 m is T = 50°C.

Integrate the governing equation twice to obtain the general solution T(x) = -(q_gen / 2k) x² + C1·x + C2.

Apply both boundary conditions to solve for the constants C1 and C2.

C2 = 50 (from the left boundary condition).

C1 = (q_gen / 2k) · L (from the right boundary condition, using symmetry).

The final analytical solution is T(x) = -(q_gen / 2k) · x² + (q_gen · L / 2k) · x + 50.

Compute and report the temperature distribution T(x) at regular intervals across the wall (e.g., every 2 cm from x = 0 to x = 20 cm).

Identify and report the location and value of the maximum temperature, which occurs at the midplane x = L/2 = 0.10 m due to symmetry.

Calculate the maximum temperature using T_max = T(L/2) = 50 + (q_gen · L²) / (8k).

Substitute values to get T_max = 50 + (2×10⁵ × 0.04) / (8 × 15) = 50 + 8000/120 ≈ 50 + 66.67 = 116.67°C.

Report the heat flux at both surfaces using q = -k · dT/dx evaluated at x = 0 and x = L.
