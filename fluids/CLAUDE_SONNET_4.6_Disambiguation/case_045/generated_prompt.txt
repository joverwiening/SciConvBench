Calculate the cavitation index (sigma) for a valve using the formula: σ = (P2 - Pv) / (P1 - P2).
Use upstream pressure P1 = 400 kPa.
Use downstream pressure P2 = 150 kPa.
Use vapor pressure Pv = 2.5 kPa.
Compute the numerator as P2 - Pv = 150 - 2.5 = 147.5 kPa.
Compute the denominator as P1 - P2 = 400 - 150 = 250 kPa.
Divide numerator by denominator to get σ = 147.5 / 250 = 0.59.
Report the cavitation index as σ = 0.59 (dimensionless).
Interpret the result: a lower cavitation index indicates a higher risk of cavitation; compare this value against the valve's critical cavitation index provided by the manufacturer to assess cavitation risk.
