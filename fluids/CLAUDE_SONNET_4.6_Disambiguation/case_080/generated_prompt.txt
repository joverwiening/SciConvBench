Calculate the outlet temperature of a compressor given the following conditions.
The working fluid is air with a ratio of specific heats γ = 1.4.
The inlet temperature is 300 K.
The compression pressure ratio (P_out / P_in) is 8.
The isentropic efficiency of the compressor is 85% (0.85).
First calculate the isentropic outlet temperature using T2s = T1 × (pressure ratio)^((γ-1)/γ).
Compute the exponent as (γ-1)/γ = (1.4-1)/1.4 = 0.4/1.4 ≈ 0.2857.
Compute T2s = 300 × (8)^0.2857.
Evaluate (8)^0.2857 ≈ 1.8114, giving T2s ≈ 300 × 1.8114 ≈ 543.4 K.
Apply the isentropic efficiency definition for a compressor: η = (T2s - T1) / (T2_actual - T1).
Rearrange to find the actual outlet temperature: T2_actual = T1 + (T2s - T1) / η.
Substitute values: T2_actual = 300 + (543.4 - 300) / 0.85.
Compute the numerator: 543.4 - 300 = 243.4 K.
Divide by efficiency: 243.4 / 0.85 ≈ 286.4 K.
Add inlet temperature: T2_actual = 300 + 286.4 ≈ 586.4 K.
Report the final outlet temperature of the compressor as approximately 586.4 K.
