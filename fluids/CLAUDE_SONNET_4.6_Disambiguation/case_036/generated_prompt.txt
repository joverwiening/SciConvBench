Calculate the volumetric flow rate through a Venturi meter using the given conditions.

The fluid is water at standard conditions (temperature = 20°C, density = 998 kg/m³, dynamic viscosity = 0.001 Pa·s).
The differential pressure across the Venturi meter is ΔP = 20 kPa (20,000 Pa).
The inlet diameter is D1 = 100 mm (0.1 m).
The throat diameter is D2 = 50 mm (0.05 m).
Calculate the inlet cross-sectional area as A1 = π/4 × D1².
Calculate the throat cross-sectional area as A2 = π/4 × D2².
Calculate the diameter ratio β = D2 / D1.
Calculate the theoretical volumetric flow rate using the Venturi meter equation: Q = Cd × A2 × sqrt(2 × ΔP / (ρ × (1 - β⁴))), where Cd is the discharge coefficient.
Use a discharge coefficient Cd = 0.98, which is the standard value for a well-machined Venturi meter as per ISO 5167.
Compute the numerical value of Q and express the result in cubic meters per second (m³/s) and also convert it to liters per second (L/s).
Verify the flow regime is turbulent by estimating the Reynolds number at the throat using Re = ρ × V2 × D2 / μ, where V2 = Q / A2, to confirm the Cd assumption is valid (Re should be above 2×10⁵ for Cd = 0.98 to apply).
