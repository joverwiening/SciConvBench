Calculate the Lewis number for a process using the given thermal and mass diffusivity values.
The thermal diffusivity (α) is 2.2e-5 m²/s.
The mass diffusivity (D) is 1.8e-5 m²/s.
Use the Lewis number formula: Le = α / D.
Divide 2.2e-5 by 1.8e-5 to obtain the Lewis number.
Report the resulting dimensionless Lewis number value.
