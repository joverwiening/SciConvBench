Assume the fluid is water at 20°C.
Assume the specific gravity of the fluid is 1.0.
Assume the fluid velocity is negligible for the cavitation index calculation.
Assume a standard flow condition is not required for the basic index calculation.
Calculate the cavitation index (sigma) using the formula: sigma = (P_out - P_v) / (P_in - P_out).
Substitute the given values: P_in = 400 kPa, P_out = 150 kPa, P_v = 2.5 kPa.
Perform the calculation: sigma = (150 - 2.5) / (400 - 150) = 147.5 / 250.
Report the cavitation index result as 0.59.
