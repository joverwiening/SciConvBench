Calculate the cavitation index for a valve using the formula: Cavitation Index = (P1 - P2) / (P1 - Pv).
Use an upstream pressure (P1) of 400 kPa.
Use a downstream pressure (P2) of 150 kPa.
Use a vapor pressure (Pv) of 2.5 kPa.
The cavitation index equals (400 - 150) / (400 - 2.5) = 250 / 397.5 = 0.629.
