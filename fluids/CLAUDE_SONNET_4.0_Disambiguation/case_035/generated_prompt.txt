Calculate the Prandtl number using the formula Pr = (μ × cp) / k.
Use dynamic viscosity μ = 0.05 Pa·s.
Use specific heat capacity cp = 2100 J/kg·K.
Use thermal conductivity k = 0.14 W/m·K.
The calculation should yield Pr = (0.05 × 2100) / 0.14 = 750.
Report the final Prandtl number as a dimensionless value.
