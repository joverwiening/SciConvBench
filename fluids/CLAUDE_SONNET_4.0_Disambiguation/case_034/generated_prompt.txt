Calculate the Lewis number using the formula Le = α/D where α is thermal diffusivity and D is mass diffusivity.
Use thermal diffusivity α = 2.2e-5 m²/s.
Use mass diffusivity D = 1.8e-5 m²/s.
Divide the thermal diffusivity by the mass diffusivity to obtain the dimensionless Lewis number.
The result should be Le = 2.2e-5 / 1.8e-5 = 1.22.
