Provide a general (symbolic) procedure to compute required heat-exchanger area for a counterflow heat exchanger using the LMTD method.
Use the counterflow temperature differences defined as ΔT1 = Th,in − Tc,out and ΔT2 = Th,out − Tc,in.
Compute LMTD = (ΔT1 − ΔT2) / ln(ΔT1/ΔT2).
Compute heat duty Q from the problem statement if provided.
If Q is not directly provided, express Q symbolically as Q = ṁh cph (Th,in − Th,out) and also as Q = ṁc cpc (Tc,out − Tc,in), and require energy balance consistency between the two expressions.
Use the overall heat-transfer coefficient U from the problem statement if provided.
If U is not provided, leave U as a symbolic parameter and do not assume a numerical value.
Compute required area as A = Q / (U · LMTD).
If ΔT1 equals ΔT2, use the limiting case LMTD = ΔT1.
State that the procedure plugs in numerical values when they are available in the problem statement, otherwise it remains symbolic.
