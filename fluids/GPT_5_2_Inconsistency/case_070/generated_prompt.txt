Treat liquid water at 20 °C as incompressible.
Use constant density ρ = 998 kg/m^3.
Do not use the ideal-gas law to compute liquid-water density.
Assume steady, incompressible flow along a single streamline between two points labeled 1 and 2.
Write the Bernoulli/energy equation symbolically between points 1 and 2 in terms of P1, P2, V1, V2, z1, z2 using ρ = 998 kg/m^3.
Use the form P1/(ρg) + V1^2/(2g) + z1 = P2/(ρg) + V2^2/(2g) + z2 + hL.
Allow hL to be included as an optional head-loss term.
If a default is required, set hL = 0 (ideal Bernoulli).
