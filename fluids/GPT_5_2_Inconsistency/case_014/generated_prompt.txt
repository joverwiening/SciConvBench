Solve steady, incompressible, fully developed plane Poiseuille flow between two infinite parallel plates using the Stokes (creeping-flow) equations appropriate for Re = 0.1.
Use Cartesian coordinates with x as the streamwise direction and y as the wall-normal direction.
Set the plates at y = -1 and y = +1 (half-gap h = 1, total gap 2).
Assume velocity field u = u(y), v = 0, w = 0.
Assume constant pressure gradient dp/dx = -1 and dp/dy = 0.
Use constant dynamic viscosity μ = 1 (nondimensional) unless dimensional form is explicitly required.
Enforce incompressibility ∇·u = 0, which is satisfied by v = 0 and u = u(y).
Neglect convective acceleration terms (u·∇u = 0) and retain viscous terms, yielding the x-momentum Stokes balance 0 = -dp/dx + μ d²u/dy².
Apply no-slip boundary conditions u(±1) = 0.
Solve the resulting ODE to obtain the velocity profile u(y) = (1/(2μ))(-dp/dx)(1 - y²).
With dp/dx = -1 and μ = 1, report u(y) = (1/2)(1 - y²).
Compute and report the volumetric flow rate per unit spanwise width Q = ∫_{-1}^{1} u(y) dy.
Compute and report the centerline velocity u(0) and the wall shear stress τ_w = μ (du/dy)|_{y=±1}.
State the pressure field as p(x) = p0 - x (up to an arbitrary constant p0) consistent with dp/dx = -1.
