Compute the oblique-shock wave angle β for a calorically perfect gas using the full θ–β–M relation (no small-angle approximation).
Use upstream Mach number M1 = 3.0.
Use wedge/deflection angle θ = 25.0 degrees.
Use angles in degrees for inputs and report β in degrees.
Assume γ = 1.4 unless otherwise specified.
Solve the θ–β–M equation: tan(θ) = 2 cot(β) * (M1^2 sin^2(β) − 1) / (M1^2(γ + cos(2β)) + 2).
Select the weak-shock branch solution, i.e., the smaller physically valid β satisfying β > μ where μ = asin(1/M1).
Return the numerical value of β (degrees) to a reasonable precision (e.g., 0.1° or better).
