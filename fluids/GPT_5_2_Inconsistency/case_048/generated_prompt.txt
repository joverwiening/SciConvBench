Assume steady-state, one-dimensional heat conduction in a plane wall spanning 0 ≤ x ≤ L with constant thermal conductivity k.
Assume no internal heat generation, so q''' = 0 everywhere in the wall.
Governing equation: d²T/dx² = 0 for 0 < x < L.
Boundary condition at x = 0: T(0) = 350 K.
Boundary condition at x = L: dT/dx|x=L = 0 (insulated/adiabatic).
Solve d²T/dx² = 0 to obtain T(x) = C1 x + C2.
Apply T(0) = 350 K to get C2 = 350 K.
Apply dT/dx|x=L = 0 to get C1 = 0.
Final temperature distribution: T(x) = 350 K for all x in [0, L].
Heat flux: qx = -k dT/dx = 0 everywhere.
