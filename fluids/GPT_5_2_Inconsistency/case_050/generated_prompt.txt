Use the lumped-capacitance method to compute the transient cooling curve for a solid sphere when the Biot number is Bi = 0.05.
If Bi ≈ 5, do not use lumped-capacitance and instead use a spatially resolved transient conduction model (Heisler chart or equivalent series solution) to produce the cooling curve.
Assume the sphere radius is R = 0.05 m (diameter D = 0.10 m).
Assume the sphere material is steel with density ρ = 7800 kg/m^3, specific heat c_p = 470 J/(kg·K), and thermal conductivity k = 50 W/(m·K).
Assume the initial uniform sphere temperature is T_i = 100 °C.
Assume the ambient fluid temperature is T_∞ = 25 °C.
Use the Biot definition Bi = h L_c / k with characteristic length L_c = V/A = R/3 for a sphere.
Compute the convection coefficient from the specified Bi as h = Bi k / L_c.
Compute the lumped time constant τ = (ρ c_p V)/(h A) = (ρ c_p L_c)/h.
Compute the transient temperature as T(t) = T_∞ + (T_i − T_∞) exp(−t/τ).
Report the cooling curve as the dimensionless temperature ratio θ(t) = (T(t) − T_∞)/(T_i − T_∞) versus time.
Provide tabulated values of T(t) at t = 0, 0.25τ, 0.5τ, 1τ, 2τ, 3τ, 4τ, and 5τ.
Optionally provide a plot of T(t) versus time from t = 0 to t = 5τ.
