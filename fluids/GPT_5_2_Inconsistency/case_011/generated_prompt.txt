Compute inlet area A1 = π(D1^2)/4 using D1 = 0.050 m.
Compute outlet area A2 = π(D2^2)/4 using D2 = 0.100 m.
Compute velocities V1 = Q/A1 and V2 = Q/A2 using Q = 0.010 m^3/s.
Assume steady incompressible flow of water with constant density ρ = 1000 kg/m^3.
Assume a horizontal pipe so z2 − z1 = 0 m.
Apply Bernoulli between inlet (1) and outlet (2) including the Borda–Carnot sudden expansion head loss hL = (V1 − V2)^2/(2g) with g = 9.81 m/s^2.
Use the energy equation in head form: p1/(ρg) + V1^2/(2g) + z1 = p2/(ρg) + V2^2/(2g) + z2 + hL.
Solve for the pressure rise (pressure recovery) Δp = p2 − p1.
Report Δp in Pa (and optionally in kPa) as the final result.
