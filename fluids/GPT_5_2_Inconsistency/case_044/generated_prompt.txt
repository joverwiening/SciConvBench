Model the flow as steady, laminar, incompressible, viscous Newtonian flow of oil between two infinite parallel plates.
Use dynamic viscosity μ = 0.1 Pa·s.
Let the plates be located at y = 0 and y = h with no-slip boundary conditions u(0) = U0 and u(h) = U1.
Allow for an optional constant streamwise pressure gradient dp/dx.
Use the Couette–Poiseuille velocity profile u(y) = U0 + (U1 − U0)(y/h) + (1/(2μ))(dp/dx)(y^2 − hy).
Compute the shear stress distribution from τ(y) = μ du/dy.
Compute du/dy = (U1 − U0)/h + (1/(2μ))(dp/dx)(2y − h).
Report wall shear stresses at both walls:
At y = 0: τw,0 = μ(U1 − U0)/h − (h/2)(dp/dx).
At y = h: τw,h = μ(U1 − U0)/h + (h/2)(dp/dx).
State that if dp/dx = 0 this reduces to pure Couette flow with τw,0 = τw,h = μ(U1 − U0)/h.
State that if U0 = U1 this reduces to pure plane Poiseuille flow with τw,0 = −(h/2)(dp/dx) and τw,h = +(h/2)(dp/dx).
