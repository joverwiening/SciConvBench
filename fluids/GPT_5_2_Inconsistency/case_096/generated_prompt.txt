Compute downstream conditions across a normal shock in air using ideal-gas normal-shock relations.
Use upstream Mach number M1 = 2.0.
Use ratio of specific heats gamma = 1.4.
Assume upstream static temperature T1 = 288.15 K.
Assume upstream static pressure P1 = 101325 Pa.
Use SI units only for all reported values (Pa, K, kg/m³, m/s).
Assume air behaves as a calorically perfect ideal gas with gas constant R = 287.05 J/(kg·K).
Compute and report downstream Mach number M2.
Compute and report downstream static pressure P2.
Compute and report downstream static temperature T2.
Compute and report downstream static density rho2.
Compute and report downstream flow speed V2.
Also compute and report the shock ratios P2/P1, T2/T1, rho2/rho1, and total pressure ratio P0,2/P0,1.
Compute upstream density rho1 from P1 = rho1*R*T1.
Compute upstream speed of sound a1 = sqrt(gamma*R*T1) and upstream flow speed V1 = M1*a1.
Compute downstream speed of sound a2 = sqrt(gamma*R*T2) and downstream flow speed V2 = M2*a2.
Use standard normal-shock relations for a perfect gas to obtain M2 and the static property ratios.
Use isentropic relations on each side of the shock to compute P0,1 from (P0,1/P1) = (1 + (gamma-1)/2*M1^2)^(gamma/(gamma-1)) and P0,2 from (P0,2/P2) = (1 + (gamma-1)/2*M2^2)^(gamma/(gamma-1)).
Present results numerically with a clear label for each quantity and ratio.
