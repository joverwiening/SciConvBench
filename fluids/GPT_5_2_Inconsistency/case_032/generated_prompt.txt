Compute the Biot number for the steel sphere using Bi = h Lc / k.
Use h = 80 W/m^2·K.
Use k = 45 W/m·K.
Use R = 0.01 m.
Use the characteristic length for a sphere Lc = V/A = R/3.
Compute Lc = 0.01/3 = 3.33×10^-3 m.
Compute Bi = (80)(3.33×10^-3)/45 ≈ 5.93×10^-3.
Conclude the solid temperature can be treated as spatially uniform because Bi ≪ 0.1.
State that the lumped-capacitance method is valid for the sphere under these conditions.
State that the “fluid temperature uniformity” is not determined by the Biot number; Biot assesses internal temperature gradients in the solid relative to the convection resistance at the surface.
