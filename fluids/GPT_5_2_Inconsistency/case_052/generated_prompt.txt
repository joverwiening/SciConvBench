Solve the steady 1D heat conduction in a homogeneous slab of thickness L using the governing equation ∂T/∂t = α ∂²T/∂x² with no time dependence, i.e., set ∂T/∂t = 0.
Reduce the PDE to the steady ODE d²T/dx² = 0 for 0 ≤ x ≤ L.
Apply Dirichlet boundary conditions T(0) = T_L and T(L) = T_R, where T_L and T_R are constants.
Solve for the temperature distribution T(x) and present it in closed form.
The expected solution form is linear in x: T(x) = T_L + (T_R − T_L) x / L.
Optionally compute the constant heat flux q'' = −k dT/dx = −k (T_R − T_L) / L if thermal conductivity k is provided; otherwise report dT/dx.
