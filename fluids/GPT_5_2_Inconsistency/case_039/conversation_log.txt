Q: What relative roughness value (ε/D) should I use for the “smooth pipe” in the Colebrook equation?
A: Don’t use the Colebrook equation here. Since Re = 800 is laminar, use the laminar relation for a smooth circular pipe:

- **Darcy friction factor:** \( f = \dfrac{64}{Re} = \dfrac{64}{800} = 0.08 \)

So **no \(\varepsilon/D\)** value is needed.
