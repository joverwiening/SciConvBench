Calculate the specific speed of the Francis turbine using the formula: Ns = (N * sqrt(P)) / (H^(5/4)).

Use N = 450 rpm as the rotational speed.

Use P = 5000 kW as the power output.

Use H = 120 m as the net head.

Compute sqrt(P) = sqrt(5000) = 70.71.

Compute H^(5/4) = 120^(1.25) = 120^1 * 120^0.25 = 120 * 3.309 = 397.08.

Compute Ns = (450 * 70.71) / 397.08 = 31819.5 / 397.08 = 80.13.

Report the specific speed as approximately 80 (dimensionless, or 80 rpm-metric if units are specified).
