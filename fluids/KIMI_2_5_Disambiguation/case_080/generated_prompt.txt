Calculate the isentropic outlet temperature using the relation T2s = T1 * (P2/P1)^((gamma-1)/gamma), where T1 = 300 K, P2/P1 = 8, and gamma = 1.4.

Compute the exponent (gamma-1)/gamma = 0.4/1.4 = 0.2857.

Calculate T2s = 300 * 8^0.2857 = 300 * 1.811 = 543.3 K.

Calculate the actual outlet temperature using the isentropic efficiency definition eta_c = (T2s - T1) / (T2 - T1), rearranged to T2 = T1 + (T2s - T1) / eta_c.

Substitute values: T2 = 300 + (543.3 - 300) / 0.85 = 300 + 243.3 / 0.85 = 300 + 286.2 = 586.2 K.

Report the compressor outlet temperature as 586 K (or 313°C).
