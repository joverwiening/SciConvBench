Calculate the cavitation index (sigma) for the valve using the formula: sigma = (P_downstream - P_vapor) / (P_upstream - P_downstream).

Use the following values:
Upstream pressure is 400 kPa.
Downstream pressure is 150 kPa.
Vapor pressure is 2.5 kPa.
Fluid density is 1000 kg/m³ (assumed to be water, which is the standard assumption for valve cavitation calculations when fluid type is unspecified).

The cavitation index is calculated as: (150 - 2.5) / (400 - 150) = 147.5 / 250 = 0.59.
