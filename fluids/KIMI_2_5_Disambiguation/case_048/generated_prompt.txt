Calculate the downstream Mach number using the normal shock relation for a perfect gas.

Assume the specific heat ratio gamma equals 1.4, which is the standard value for diatomic gases like air at moderate temperatures.

Use the normal shock Mach number formula: M2_squared = ((gamma - 1) * M1^2 + 2) / (2 * gamma * M1^2 - (gamma - 1)).

Substitute M1 = 2.2 and gamma = 1.4 into the equation.

Compute M2_squared = (0.4 * 4.84 + 2) / (2 * 1.4 * 4.84 - 0.4) = (1.936 + 2) / (13.552 - 0.4) = 3.936 / 13.152 = 0.2993.

Take the square root to obtain the downstream Mach number: M2 = sqrt(0.2993) = 0.547.

Report the final downstream Mach number as approximately 0.55.
