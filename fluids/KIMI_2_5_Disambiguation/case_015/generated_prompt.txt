Calculate the Nusselt number for turbulent pipe flow using the Dittus-Boelter correlation.

Use the Dittus-Boelter equation: Nu = 0.023 * Re^0.8 * Pr^n.

Assume the pipe surface is smooth, as this is the standard assumption for heat transfer calculations when roughness is unspecified.

Assume the fluid is being heated, so use n = 0.4. If the fluid were being cooled, n would be 0.3.

Use Re = 15000.

Use Pr = 6.0.

Calculate Nu = 0.023 * (15000)^0.8 * (6.0)^0.4.

The resulting Nusselt number is approximately 104.5.
