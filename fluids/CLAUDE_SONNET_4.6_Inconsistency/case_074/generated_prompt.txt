This is a compressible flow problem in a duct where air is compressed from 1 bar to 10 bar.

Treat air as an ideal gas with the equation of state: P = ρRT, where R = 287 J/(kg·K) for air.

Assume inlet temperature T1 = 300 K (standard ambient condition).

Assume the compression process is isentropic (adiabatic and reversible), which is the standard best-practice assumption for compressible duct flow analysis.

For an isentropic process, use the relation T2/T1 = (P2/P1)^((γ-1)/γ), where γ = 1.4 for air.

Calculate outlet temperature: T2 = 300 × (10/1)^(0.4/1.4), which gives T2 ≈ 579 K.

Calculate inlet density using ideal gas law: ρ1 = P1/(R×T1) = 100000/(287×300) ≈ 1.161 kg/m³.

Calculate outlet density using ideal gas law: ρ2 = P2/(R×T2) = 1000000/(287×579) ≈ 6.013 kg/m³.

Assume inlet cross-sectional area A1 = 0.1 m² (a reasonable duct size for an engineering example).

Assume inlet velocity V1 = 50 m/s (a typical low-to-moderate compressible flow inlet velocity, well below sonic conditions).

Apply mass continuity: ρ1 × A1 × V1 = ρ2 × A2 × V2.

Assume the duct area decreases proportionally to maintain a constant mass flow rate with a practical outlet velocity; set A2 = A1 × (ρ1/ρ2) so that V2 = V1, giving A2 ≈ 0.01932 m².

If instead the duct area is held constant (A1 = A2 = 0.1 m²), then apply continuity directly: V2 = (ρ1 × V1)/ρ2 = (1.161 × 50)/6.013 ≈ 9.66 m/s.

Present both cases: the constant-area duct case and the area-varying case.

For the constant-area duct: inlet velocity V1 = 50 m/s, outlet velocity V2 ≈ 9.66 m/s.

Verify that both inlet and outlet Mach numbers are subsonic: M1 = V1/√(γRT1) = 50/√(1.4×287×300) ≈ 0.144; M2 = V2/√(γRT2) = 9.66/√(1.4×287×579) ≈ 0.020. Both are subsonic, confirming the solution is physically consistent.

Report the mass flow rate: ṁ = ρ1 × A1 × V1 = 1.161 × 0.1 × 50 ≈ 5.805 kg/s, and verify it is conserved at the outlet.
