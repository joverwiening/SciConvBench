Simulate a Venturi meter flow rate calculation using ideal Bernoulli equation with discharge coefficient Cd = 1.

Use an inlet diameter D1 = 100 mm (0.1 m), which is a common pipe size in industrial Venturi applications.
Use a throat diameter D2 = 50 mm (0.05 m), giving a diameter ratio beta = D2/D1 = 0.5, which is within the standard recommended range of 0.3 to 0.75.
Use a measured differential pressure delta_p = 50,000 Pa (50 kPa), a typical mid-range operating pressure differential for industrial Venturi meters.
Assume the flowing fluid is water at 20 degrees Celsius with density rho = 998 kg/m³.
Assume steady, incompressible, inviscid flow along the centerline streamline.
Assume the Venturi meter is installed horizontally so elevation terms cancel in the Bernoulli equation.

Compute the cross-sectional areas at the inlet and throat using A = pi * (D/2)^2.
Apply the continuity equation: A1 * V1 = A2 * V2, so V1 = V2 * (A2 / A1).
Apply the ideal Bernoulli equation between inlet and throat: p1 + 0.5 * rho * V1^2 = p2 + 0.5 * rho * V2^2.
Substitute delta_p = p1 - p2 into the Bernoulli equation and solve for V2.
The formula for throat velocity is V2 = sqrt(2 * delta_p / (rho * (1 - (A2/A1)^2))).
Compute the volumetric flow rate as Q = Cd * A2 * V2, where Cd = 1.
Compute the mass flow rate as m_dot = rho * Q.

Report the following output values: inlet area A1, throat area A2, throat velocity V2, volumetric flow rate Q in m³/s and in liters per second, and mass flow rate m_dot in kg/s.
Note in the output that Cd = 1 represents the ideal case with no irreversible losses, and that real Venturi meters typically use Cd in the range 0.95 to 0.99 to account for actual losses in the throat and diffuser.
