Compute the available Net Positive Suction Head (NPSHa) for a centrifugal pump drawing water from an open reservoir.

Use the standard formula: NPSHa = Patm/(ρg) - hs - hL - Pv/(ρg)

Define hs as the suction lift = +4.0 m (pump centerline is 4.0 m above the reservoir free surface).

Define hL as the suction-line head loss = 1.0 m.

Use Patm = 101,300 Pa.

Use Pv = 3,200 Pa.

Use ρ = 997 kg/m³.

Use g = 9.81 m/s².

Compute Patm/(ρg) = 101,300 / (997 × 9.81) = 101,300 / 9,780.57 = 10.357 m.

Compute Pv/(ρg) = 3,200 / (997 × 9.81) = 3,200 / 9,780.57 = 0.327 m.

Substitute into the formula: NPSHa = 10.357 - 4.0 - 1.0 - 0.327.

Calculate NPSHa = 5.03 m.

Report the final answer as NPSHa ≈ 5.03 m.
