Apply the isentropic (Saint-Venant) flow relations to a flow with Mach number M = 0.5.
Assume a calorically perfect gas with ratio of specific heats gamma = 1.4.
Compute the stagnation-to-static pressure ratio using P0/P = (1 + (gamma-1)/2 * M^2)^(gamma/(gamma-1)).
Compute the stagnation-to-static temperature ratio using T0/T = 1 + (gamma-1)/2 * M^2.
Compute the stagnation-to-static density ratio using rho0/rho = (1 + (gamma-1)/2 * M^2)^(1/(gamma-1)).
Substitute M = 0.5 and gamma = 1.4 into each relation and evaluate numerically.
Present each ratio as a dimensionless numerical result rounded to four decimal places.
State explicitly that no shock is present and that the process is isentropic throughout.
Note that these relations are valid because M = 0.5 is subsonic and the Rayleigh-Pitot formula, which accounts for a detached normal shock, does not apply here.
