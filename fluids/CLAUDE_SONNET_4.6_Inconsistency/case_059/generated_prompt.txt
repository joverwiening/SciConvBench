Use q = 1.0 m²/s as the discharge per unit width for all calculations.
Ignore the given depth y = 1.0 m and velocity V = 0.5 m/s as they are inconsistent with q = 1.0 m²/s.
The channel is rectangular and open.
Find the critical depth yc using the critical flow condition for a rectangular channel.
Apply the formula yc = (q²/g)^(1/3), where g = 9.81 m/s².
Compute q² = (1.0)² = 1.0 m⁴/s².
Compute q²/g = 1.0 / 9.81 = 0.10194 m³.
Compute yc = (0.10194)^(1/3).
The critical depth yc ≈ 0.467 m.
Verify by computing critical velocity Vc = q / yc = 1.0 / 0.467 ≈ 2.14 m/s.
Verify Froude number Fr = Vc / sqrt(g × yc) = 2.14 / sqrt(9.81 × 0.467) = 2.14 / 2.14 ≈ 1.0, confirming critical flow.
Report the final answer as yc ≈ 0.467 m.
