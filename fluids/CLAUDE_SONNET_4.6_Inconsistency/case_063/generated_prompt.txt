The flow state is subcritical with a Froude number of 0.2; it is not critical.
Accept two inputs from the user: the flow velocity V (in m/s) and the flow depth y (in meters).
Compute the discharge per unit width using q = V * y.
Compute the critical depth using yc = (q² / g)^(1/3), where g = 9.81 m/s².
Use the given V and y only to determine q; do not use them to imply critical conditions.
Report the critical depth yc in meters.
Do not compute or report a Froude number for the given state unless separately requested.
