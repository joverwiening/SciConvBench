Calculate the pressure drop in a horizontal pipe using the Darcy-Weisbach equation.

Pipe length L = 40 m.
Pipe diameter D = 50 mm = 0.05 m.
Mean flow velocity v = 2.0 m/s.
The pipe is horizontal with constant diameter throughout.
Use water properties at standard conditions: density rho = 1000 kg/m³, dynamic viscosity mu = 0.001 Pa·s.

Step 1: Calculate the Reynolds number using Re = rho * v * D / mu.

Step 2: Determine the flow regime. If Re < 2300, the flow is laminar; if Re >= 4000, the flow is turbulent. Use the transitional boundary if Re falls between 2300 and 4000, treating it as turbulent for conservatism.

Step 3: Calculate the Darcy friction factor f_D based on the flow regime.
For laminar flow, use the Hagen-Poiseuille relation: f_D = 64 / Re.
For turbulent flow in a smooth pipe, use the Blasius correlation: f_D = 0.316 * Re^(-0.25), valid for Re up to approximately 100,000.

Step 4: Calculate the pressure drop using the Darcy-Weisbach equation: delta_P = f_D * (L / D) * (rho * v^2 / 2).

Report the Reynolds number, the flow regime, the Darcy friction factor, and the final pressure drop in Pascals.
