Model a viscous, incompressible, steady, two-dimensional laminar boundary layer flow over a semi-infinite flat plate (the Blasius problem).

The fluid is Newtonian and viscous with constant density and constant dynamic viscosity.

The flat plate is oriented horizontally, starting at x=0, aligned with the free-stream flow direction.

The free-stream velocity U_infinity is uniform, constant, and parallel to the plate surface.

Apply the no-slip boundary condition u=0 and v=0 at the plate surface (y=0) for all x greater than 0.

Apply the far-field boundary condition u approaches U_infinity as y approaches infinity.

Govern the flow using the 2D boundary layer (Prandtl) equations derived from the Navier-Stokes equations under the boundary layer approximation.

Use the Blasius similarity transformation: eta = y * sqrt(U_infinity / (nu * x)), where nu is the kinematic viscosity.

Reduce the governing PDE to the Blasius ODE: f''' + 0.5 * f * f'' = 0, where f is the dimensionless stream function and primes denote derivatives with respect to eta.

Apply the boundary conditions on the ODE: f(0)=0, f'(0)=0 (no-slip), and f'(eta) approaches 1 as eta approaches infinity (free-stream matching).

Solve the Blasius ODE numerically using a shooting method or a standard ODE solver (e.g., Runge-Kutta 4th order).

Output the dimensionless velocity profile u/U_infinity = f'(eta) as a function of eta, ranging from eta=0 to eta=8.

Also output the boundary layer thickness delta_99, defined as the value of y where u = 0.99 * U_infinity, expressed as delta_99 = 5.0 * sqrt(nu * x / U_infinity).

Present the final result as a table of eta values versus f'(eta) and as a plotted velocity profile curve.
