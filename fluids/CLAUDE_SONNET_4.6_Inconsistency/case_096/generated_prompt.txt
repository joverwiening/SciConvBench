Compute the downstream conditions across a normal shock for air flowing at Mach 1 = 2.0.
Use the ideal-gas normal shock relations with gamma = 1.4.
Treat the upstream flow as a calorically perfect ideal gas.
Compute the following downstream quantities:
Downstream Mach number (M2) using M2^2 = (M1^2 + 5) / (7*M1^2 - 1) for gamma=1.4.
Static pressure ratio (P2/P1) using P2/P1 = (2*gamma*M1^2 - (gamma-1)) / (gamma+1).
Static temperature ratio (T2/T1) using T2/T1 = [2*gamma*M1^2 - (gamma-1)] * [(gamma-1)*M1^2 + 2] / [(gamma+1)^2 * M1^2].
Static density ratio (rho2/rho1) using rho2/rho1 = (gamma+1)*M1^2 / ((gamma-1)*M1^2 + 2).
Total pressure ratio (P02/P01) using the Rayleigh Pitot formula.
Input values are M1 = 2.0 and gamma = 1.4.
Report each result as a dimensionless ratio or Mach number rounded to four decimal places.
No upstream absolute values (pressure, temperature, density) are specified, so report only ratios.
