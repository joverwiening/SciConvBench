The task is to calculate air velocity using a Pitot-static tube with the incompressible Bernoulli equation.

Use the incompressible Bernoulli-based Pitot formula: V = sqrt(2 * delta_P / rho).
The differential pressure (dynamic pressure) is delta_P = 20 kPa = 20,000 Pa.
The static pressure is P_static = 100 kPa = 100,000 Pa.
Assume the temperature is standard atmospheric: T = 288.15 K (15°C).
Calculate air density using the ideal gas law: rho = P_static / (R * T), where R = 287 J/(kg·K) for air.
Compute rho = 100,000 / (287 * 288.15) = 1.2092 kg/m³.
Compute velocity: V = sqrt(2 * 20,000 / 1.2092).
Compute V = sqrt(40,000 / 1.2092) = sqrt(33,080.7) = 181.88 m/s.
Report the final answer as V ≈ 181.9 m/s.
Note: At this velocity (Mach ≈ 0.53), compressibility effects begin to matter, so the incompressible result is an approximation as explicitly requested.
