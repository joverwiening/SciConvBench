Calculate the deep-water gravity wave speed using the formula c = sqrt(g * λ / (2π)).
Use gravitational acceleration g = 9.81 m/s².
Use wavelength λ = 20 m.
Ocean depth h = 100 m is provided as context but is not used in the deep-water formula.
Confirm that the deep-water condition is satisfied by verifying h >> λ (100 m >> 20 m), which holds true.
Compute 2π ≈ 6.2832.
Compute g * λ / (2π) = 9.81 * 20 / 6.2832 = 196.2 / 6.2832 ≈ 31.23 m²/s².
Compute c = sqrt(31.23) ≈ 5.59 m/s.
Report the final wave speed as c ≈ 5.59 m/s.
