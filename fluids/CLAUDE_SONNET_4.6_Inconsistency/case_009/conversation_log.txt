Q: I need one clarification before finalizing the specification.

The problem states the flow is **rotational** (nonzero vorticity), which means points A and B lie on **different streamlines**. In rotational flow, the Bernoulli constant is **not** the same between different streamlines — it can only be applied along the same streamline, or across streamlines only if the flow is irrotational.

Applying the same Bernoulli constant across two different streamlines in a rotational flow is physically incorrect.

How would you like to proceed: should the flow be treated as **irrotational** (so the same Bernoulli constant applies everywhere), or should A and B be placed on the **same streamline** (so Bernoulli applies along it regardless of rotation)?
A: The flow is irrotational (zero vorticity), so the same Bernoulli constant applies everywhere in the field. Use rho = 1000 kg/m^3.
