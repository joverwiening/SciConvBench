The flow is steady, inviscid, and irrotational (zero vorticity), so the Bernoulli constant is the same throughout the entire flow field.

Use the Bernoulli equation: p + 0.5 * rho * V^2 + rho * g * z = constant, applied between point A and point B.

Given values are: pA = 200,000 Pa, VA = 5 m/s, zA = 0 m, VB = 8 m/s, zB = 0 m, rho = 1000 kg/m^3.

Since zA = zB = 0, the elevation terms cancel and the equation reduces to: pA + 0.5 * rho * VA^2 = pB + 0.5 * rho * VB^2.

Solve for pB: pB = pA + 0.5 * rho * (VA^2 - VB^2).

Substitute values: pB = 200,000 + 0.5 * 1000 * (25 - 64).

Compute: pB = 200,000 + 500 * (-39).

Compute: pB = 200,000 - 19,500.

Report the final answer as pB = 180,500 Pa, or equivalently 180.5 kPa.
