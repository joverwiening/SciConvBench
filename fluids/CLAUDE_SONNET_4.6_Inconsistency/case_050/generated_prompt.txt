Simulate the transient cooling of a solid sphere using the lumped-capacitance method.

The Biot number is Bi = h·L/k = 0.05, where L = R/3 (volume-to-surface-area ratio), confirming validity of the lumped-capacitance method (Bi < 0.1).

Use the following assumed material and thermal properties, representative of a steel sphere as a best-practice baseline:
Density ρ = 7800 kg/m³.
Specific heat c_p = 500 J/(kg·K).
Thermal conductivity k = 50 W/(m·K).
Convection coefficient h = 250 W/(m²·K).
Sphere radius R = 0.03 m, so characteristic length L = R/3 = 0.01 m.
Verify Bi = h·L/k = 250·0.01/50 = 0.05, confirming consistency.

Use the following thermal conditions:
Initial sphere temperature T_i = 300 °C.
Ambient fluid temperature T_∞ = 25 °C.
Plot the cooling curve over a time range of 0 to 600 seconds.

Apply the lumped-capacitance governing equation:
(T(t) - T_∞) / (T_i - T_∞) = exp(−t / τ)
where the time constant τ = ρ·c_p·V / (h·A_s) = ρ·c_p·L / h.

Compute τ = 7800 · 500 · 0.01 / 250 = 156 seconds.

Compute T(t) at uniform time steps of 1 second from t = 0 to t = 600 s.

Plot T(t) in °C on the vertical axis versus time t in seconds on the horizontal axis.
