The working fluid is air with a specific heat ratio gamma = 1.4 and gas constant R = 287 J/(kg·K).

The nozzle is NOT choked. Use the subsonic throat Mach number Mt = 0.3 for all calculations.

Assume standard stagnation conditions as reasonable engineering defaults: stagnation pressure P0 = 101325 Pa (1 atm) and stagnation temperature T0 = 288.15 K (15°C, ISA sea-level standard).

Assume a throat area At = 0.01 m² (100 cm²) as a reasonable representative nozzle size.

Compute the static temperature at the throat using the isentropic relation: T_t = T0 / (1 + ((gamma - 1) / 2) * Mt²).

Substitute values: T_t = 288.15 / (1 + 0.2 * 0.09) = 288.15 / 1.018 = 283.05 K.

Compute the static pressure at the throat using the isentropic relation: P_t = P0 / (1 + ((gamma - 1) / 2) * Mt²)^(gamma / (gamma - 1)).

Substitute values: P_t = 101325 / (1.018)^3.5 = 101325 / 1.0635 = 95,275 Pa.

Compute the throat density using the ideal gas law: rho_t = P_t / (R * T_t) = 95275 / (287 * 283.05) = 1.173 kg/m³.

Compute the speed of sound at the throat: a_t = sqrt(gamma * R * T_t) = sqrt(1.4 * 287 * 283.05) = sqrt(113,892) = 337.5 m/s.

Compute the throat velocity: V_t = Mt * a_t = 0.3 * 337.5 = 101.25 m/s.

Compute the mass flow rate using the continuity equation: m_dot = rho_t * V_t * At.

Substitute values: m_dot = 1.173 * 101.25 * 0.01 = 1.188 kg/s.

The resulting mass flow rate is approximately 1.19 kg/s under these assumed conditions.

Note that this result scales linearly with At, proportionally with P0, and inversely with the square root of T0, so it can be adjusted directly if different inlet conditions or throat area are specified.
