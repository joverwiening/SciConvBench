Solve an isentropic nozzle flow problem for a calorically perfect gas.

Use γ = 1.4 and R = 287 J/(kg·K) for air.

Assume stagnation temperature T₀ = 300 K throughout (isentropic flow, so T₀ is constant).

The inlet Mach number is M1 = 2.0.

The nozzle is converging with area ratio A2/A1 = 0.7.

The flow is isentropic, adiabatic, frictionless, and one-dimensional.

Step 1: Compute the inlet static temperature using T1 = T₀ / (1 + (γ-1)/2 * M1²).
T1 = 300 / (1 + 0.2 * 4) = 300 / 1.8 = 166.67 K.

Step 2: Compute the inlet speed of sound using a1 = sqrt(γ * R * T1).
a1 = sqrt(1.4 * 287 * 166.67) = sqrt(66,946.7) ≈ 258.74 m/s.

Step 3: Compute the inlet velocity using V1 = M1 * a1.
V1 = 2.0 * 258.74 = 517.48 m/s.

Step 4: Find the inlet area ratio A1/A* using the isentropic area-Mach relation.
A/A* = (1/M) * [(2/(γ+1)) * (1 + (γ-1)/2 * M²)]^((γ+1)/(2(γ-1))).
For M1 = 2.0: A1/A* = (1/2) * [(1/1.2) * (1 + 0.2*4)]^(2.4/0.8) = (1/2) * [1.8/1.2]^3 = (1/2) * (1.5)^3 = (1/2) * 3.375 = 1.6875.

Step 5: Compute the exit area ratio relative to the throat using A2/A* = (A2/A1) * (A1/A*).
A2/A* = 0.7 * 1.6875 = 1.18125.

Step 6: Since the inlet flow is supersonic (M1 = 2.0) and the nozzle is converging (A2 < A1), the flow decelerates toward the throat.
A2/A* = 1.18125 is greater than 1.0, so the exit is still supersonic and has not reached the throat.
Solve A2/A* = 1.18125 for the supersonic exit Mach number M2 using the isentropic area-Mach relation iteratively or numerically.
The supersonic solution for A/A* = 1.18125 gives M2 ≈ 1.60 (iterate: at M=1.6, A/A* = (1/1.6)*[(1.8/1.2)*(1+0.2*2.56)]^3 = 0.625*[1.5*1.512]^3... use standard isentropic tables: at M=1.6, A/A* ≈ 1.2502; at M=1.55, A/A* ≈ 1.2271; at M=1.50, A/A* ≈ 1.1762; interpolate between M=1.50 and M=1.55: target 1.18125 is between these, closer to M=1.50; linear interpolation gives M2 ≈ 1.502).
Use M2 ≈ 1.50 as the exit Mach number.

Step 7: Compute the exit static temperature using T2 = T₀ / (1 + (γ-1)/2 * M2²).
T2 = 300 / (1 + 0.2 * 2.25) = 300 / 1.45 = 206.90 K.

Step 8: Compute the exit speed of sound using a2 = sqrt(γ * R * T2).
a2 = sqrt(1.4 * 287 * 206.90) = sqrt(83,170.5) ≈ 288.39 m/s.

Step 9: Compute the exit velocity using V2 = M2 * a2.
V2 = 1.50 * 288.39 = 432.58 m/s.

Step 10: Compute the change in velocity.
ΔV = V2 - V1 = 432.58 - 517.48 = -84.90 m/s.

The exit velocity is approximately 432.6 m/s and the inlet velocity is approximately 517.5 m/s.
The exit velocity decreases by approximately 84.9 m/s compared to the inlet.
There is no increase in exit velocity; the converging nozzle decelerates the supersonic flow from M1 = 2.0 toward M2 ≈ 1.50, reducing velocity by roughly 85 m/s under the given conditions with T₀ = 300 K.
