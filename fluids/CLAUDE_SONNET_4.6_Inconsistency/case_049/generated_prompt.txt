Solve the steady-state 1D heat conduction problem in a slab using the governing equation d2T/dx2 = 0 (steady state means dT/dt = 0, reducing the diffusion equation to a second-order ODE).

The slab spans from x = 0 to x = L, where L = 1 meter.
Apply a Dirichlet (fixed temperature) boundary condition at x = 0: T(0) = 100 degrees Celsius.
Apply a Dirichlet (fixed temperature) boundary condition at x = L: T(L) = 0 degrees Celsius.
The thermal diffusivity alpha is not needed for the steady-state solution but assume alpha = 1e-4 m^2/s as a material property for reference.
Solve the ODE analytically: the exact solution is T(x) = 100 * (1 - x/L).
Also solve numerically using a finite difference method with a uniform grid of N = 50 equally spaced nodes from x = 0 to x = L.
Discretize d2T/dx2 using the standard second-order central difference scheme: (T[i-1] - 2*T[i] + T[i+1]) / dx^2 = 0.
Assemble the resulting tridiagonal linear system of equations.
Solve the linear system using a standard direct solver (e.g., numpy.linalg.solve or scipy.linalg.solve).
Apply the boundary conditions by fixing T[0] = 100 and T[N-1] = 0 in the system.
Plot the numerical solution as discrete points and the analytical solution as a continuous line on the same graph.
Label the x-axis as "Position x (m)", the y-axis as "Temperature T (°C)", and the title as "Steady-State 1D Heat Conduction in a Slab".
Include a legend distinguishing the analytical and numerical solutions.
Print the maximum absolute error between the numerical and analytical solutions.
