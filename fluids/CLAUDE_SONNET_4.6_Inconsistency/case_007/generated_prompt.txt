The channel is a rectangular open channel with a width of 3 m.
The channel is horizontal with zero slope.
The upstream flow depth is y1 = 0.4 m.
The upstream flow velocity is V1 = 6.0 m/s.
Water undergoes a hydraulic jump between the upstream and downstream sections.
Use the momentum equation (specific force / momentum function) to find the sequent depth y2.
Do not use Bernoulli's equation, as energy is not conserved across a hydraulic jump.
Compute the upstream unit discharge q = V1 × y1 per unit width.
Compute the upstream Froude number Fr1 = V1 / sqrt(g × y1) using g = 9.81 m/s².
Apply the momentum function equality: (y1² / 2) + (q² / (g × y1)) = (y2² / 2) + (q² / (g × y2)).
Solve the resulting equation for the positive real root y2, which is the sequent (downstream) depth.
Report the final value of y2 in meters.
Optionally verify using the standard sequent depth formula for a rectangular channel: y2 = (y1 / 2) × (sqrt(1 + 8 × Fr1²) - 1).
