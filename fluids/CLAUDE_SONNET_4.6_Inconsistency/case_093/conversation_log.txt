Q: The pressure coefficient Cp is defined as (p - p_inf) / (0.5 * rho * V_inf^2).

At a stagnation point, the velocity is zero by definition.

Applying Bernoulli's equation for incompressible flow:

p_inf + 0.5 * rho * V_inf^2 = p_stag + 0.5 * rho * (0)^2

This gives:

p_stag - p_inf = 0.5 * rho * V_inf^2

Substituting into the Cp definition:

Cp = (p_stag - p_inf) / (0.5 * rho * V_inf^2) = (0.5 * rho * V_inf^2) / (0.5 * rho * V_inf^2) = **1.0**

The correct stagnation-point pressure coefficient for incompressible flow is **Cp = 1.0**, not 1.5.

The value Cp = 1.5 is **incorrect** for incompressible flow under Bernoulli's equation.

Would you like me to clarify where Cp = 1.5 might arise (e.g., compressible flow, or a different definition), or was this a test of whether the stated value is correct?
A: Yes, Cp = 1.5 is incorrect. The correct value is Cp = 1.0 for incompressible inviscid flow. If Cp > 1 appears, it indicates an error in definitions, compressibility effects, or measurement errors.
