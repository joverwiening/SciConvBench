Implement a counterflow heat exchanger area calculation using the Log Mean Temperature Difference (LMTD) method with the "parapression" (parallel-expression) formula.
Assume a water-to-water counterflow heat exchanger as the fluid combination.
Use the following assumed best-practice temperature values: Th,in = 90°C, Th,out = 60°C, Tc,in = 30°C, Tc,out = 55°C.
Define ΔT1 = Th,in - Tc,out = 90 - 55 = 35°C (hot inlet minus cold outlet, counterflow convention).
Define ΔT2 = Th,out - Tc,in = 60 - 30 = 30°C (hot outlet minus cold inlet, counterflow convention).
Compute LMTD = (ΔT1 - ΔT2) / ln(ΔT1 / ΔT2).
Assume an overall heat transfer coefficient U = 1500 W/(m²·K), which is a typical best-practice value for liquid-to-liquid heat exchangers.
Assume a heat duty Q = 100,000 W (100 kW) as a representative best-practice design load.
Compute the required heat transfer area using A = Q / (U × LMTD).
Deliver the solution as a Python script.
The Python script must define each variable explicitly with inline comments explaining its meaning and units.
The script must print ΔT1, ΔT2, LMTD, and the required area A in a clearly labeled output.
The script must include a check that ΔT1 and ΔT2 are not equal before applying the logarithmic formula to avoid division by zero; if they are equal, set LMTD = ΔT1 directly.
All temperature values are in degrees Celsius, Q in Watts, U in W/(m²·K), and A in square meters.
