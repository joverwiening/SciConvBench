Use the water-hammer equation Δp = ρ a ΔV to estimate the pressure rise from valve closure.
Assume water density ρ = 1000 kg/m³.
Assume wave speed a = 1000 m/s, which is a typical value for water in a rigid metal pipe.
Use velocity change ΔV = 2 m/s (from 2 m/s to 0 m/s).
Compute pressure rise Δp = (1000 kg/m³)(1000 m/s)(2 m/s) = 2,000,000 Pa = 2 MPa.
State that this is an estimate and actual wave speed depends on pipe material, wall thickness, and fluid properties.
