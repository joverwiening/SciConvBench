Calculate the downstream sequent depth y2 for a hydraulic jump in a rectangular open channel using the momentum equation.

The channel width is 3 m.
The upstream depth y1 is 0.4 m.
The upstream velocity V1 is 6.0 m/s.
The gravitational acceleration g is 9.81 m/s².

First, compute the upstream Froude number Fr1 = V1 / sqrt(g * y1).
Fr1 = 6.0 / sqrt(9.81 * 0.4) = 6.0 / 1.980 = 3.03.

Since Fr1 > 1, the flow is supercritical and a hydraulic jump will occur.

For a rectangular channel, the sequent depth relationship from the momentum equation is:
y2 / y1 = 0.5 * (-1 + sqrt(1 + 8 * Fr1²))

Substitute Fr1 = 3.03:
y2 / y1 = 0.5 * (-1 + sqrt(1 + 8 * (3.03)²))
y2 / y1 = 0.5 * (-1 + sqrt(1 + 8 * 9.181))
y2 / y1 = 0.5 * (-1 + sqrt(1 + 73.45))
y2 / y1 = 0.5 * (-1 + sqrt(74.45))
y2 / y1 = 0.5 * (-1 + 8.628)
y2 / y1 = 0.5 * 7.628
y2 / y1 = 3.814

Therefore:
y2 = 3.814 * 0.4 m = 1.526 m

The downstream sequent depth y2 is approximately 1.53 m (or more precisely, 1.526 m).
