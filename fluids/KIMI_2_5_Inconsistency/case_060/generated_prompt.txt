The available NPSH shall be computed using the following specification:

Use the formula NPSHa = -hs - hL - Pv/(rho*g), where hs represents suction lift as a positive value.

Set hs = 4.0 m.

Set hL = 1.0 m.

Set Pv = 3200 Pa.

Set water density rho = 997 kg/m³ for water at 25°C.

Set gravitational acceleration g = 9.81 m/s².

Neglect atmospheric pressure entirely as specified.

Compute Pv/(rho*g) = 3200 / (997 * 9.81) = 0.327 m.

Compute NPSHa = -4.0 - 1.0 - 0.327 = -5.327 m.

Report the final result as NPSHa = -5.33 m (or -5.3 m).
