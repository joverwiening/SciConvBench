The Thoma cavitation coefficient (sigma) for a Francis turbine shall be computed using the given parameters.

Use the Thoma sigma formula: sigma = (Ha - Hv) / H, where Ha is the atmospheric head, Hv is the vapor pressure head, and H is the net head.

The atmospheric head Ha is given as 10.3 m.

The vapor pressure head Hv is given as 0.3 m.

The water temperature is 100 C, which corresponds to boiling conditions where vapor pressure equals atmospheric pressure; however, use the provided Hv = 0.3 m as specified rather than calculating from temperature.

The net head H is not explicitly provided in the problem statement.

Assume the user intends to compute the Thoma sigma value as (Ha - Hv) expressed in meters, or the user will provide H separately.

If H must be assumed for demonstration purposes, state that H is required for a complete numerical answer.

The Thoma sigma formula is: sigma = (Ha - Hv) / H = (10.3 - 0.3) / H = 10.0 / H.

Without H, the result is expressed as 10.0 / H (dimensionless).

If H = 10.0 m is assumed for illustration, then sigma = 1.0.
