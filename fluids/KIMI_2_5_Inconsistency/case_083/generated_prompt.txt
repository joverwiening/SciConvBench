The user wants to find the oblique shock wave angle beta using a small-angle approximation for an oblique shock.

Given information:
- Wedge angle theta = 25 degrees
- Freestream Mach number M = 3
- Approximation to use: beta ≈ mu + theta, where mu is the Mach angle

The Mach angle mu is defined as: mu = arcsin(1/M)

For M = 3:
- mu = arcsin(1/3) = arcsin(0.333...) ≈ 19.47 degrees

Using the approximation:
- beta ≈ mu + theta = 19.47° + 25° = 44.47°

However, I need to check if this is physically reasonable. The small-angle approximation beta ≈ mu + theta is typically valid when theta is small (usually < 10°). Here theta = 25°, which is not a small angle. The actual oblique shock relation would give a different answer.

Using the exact theta-beta-Mach relation:
- tan(theta) = 2*cot(beta)*(M²sin²(beta) - 1)/(M²*(gamma + cos(2*beta)) + 2)

For theta = 25° and M = 3, solving numerically gives two solutions:
- Weak shock: beta ≈ 42.8°
- Strong shock: beta ≈ 77.8°

The small-angle approximation gives beta ≈ 44.47°, which is reasonably close to the weak shock solution (about 4% error), but the user specifically asked to use this approximation.

Calculation:
- Mach angle: mu = arcsin(1/3) = 19.4712... degrees
- Wave angle: beta = 19.4712° + 25° = 44.4712°

The oblique shock wave angle beta is approximately 44.5 degrees (or more precisely, 44.47°).
