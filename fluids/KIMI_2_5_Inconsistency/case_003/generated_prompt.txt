The simulation calculates the increase in exit velocity of air passing through a frictionless converging nozzle.

The incoming air has a Mach number of 2.0 at the inlet.

The nozzle has an area ratio A2/A1 = 0.7, where A1 is the inlet area and A2 is the exit area.

The stagnation temperature of the incoming air is assumed to be 288.15 K (standard sea level temperature, 15°C).

The stagnation pressure of the incoming air is assumed to be 101325 Pa (standard atmospheric pressure, 1 atm).

The specific heat ratio (gamma) of air is 1.4.

The inlet static temperature is calculated from the stagnation temperature and Mach number using isentropic relations: T1 = T0 / (1 + (gamma-1)/2 * M1^2) = 288.15 / (1 + 0.2 * 4) = 160.08 K.

The inlet static pressure is calculated from the stagnation pressure and Mach number using isentropic relations: P1 = P0 / (1 + (gamma-1)/2 * M1^2)^(gamma/(gamma-1)) = 101325 / (1.8)^3.5 = 12770.5 Pa.

The inlet velocity is calculated as V1 = M1 * sqrt(gamma * R * T1), where R = 287 J/(kg·K) for air, giving V1 = 2.0 * sqrt(1.4 * 287 * 160.08) = 507.0 m/s.

For a converging nozzle with supersonic inlet flow (M1 = 2.0), the flow must decelerate to M2 = 1.0 (choked flow) at the exit since the area ratio A2/A1 = 0.7 is less than the critical area ratio for M=2.0.

The exit Mach number is determined to be 1.0 (sonic condition at throat).

The exit static temperature is T2 = T0 / (1 + (gamma-1)/2 * M2^2) = 288.15 / 1.2 = 240.13 K.

The exit velocity is V2 = M2 * sqrt(gamma * R * T2) = 1.0 * sqrt(1.4 * 287 * 240.13) = 310.5 m/s.

The increase in exit velocity compared to the inlet is V2 - V1 = 310.5 - 507.0 = -196.5 m/s (a decrease of 196.5 m/s, or approximately 38.8% reduction).

The simulation reports that for supersonic flow entering a converging nozzle, the velocity decreases as the flow is compressed toward the sonic condition at the minimum area.
