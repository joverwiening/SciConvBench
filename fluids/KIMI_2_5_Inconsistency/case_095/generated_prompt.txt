The momentum flux for fully developed laminar flow in a circular pipe shall be computed using the following specifications:

Use the parabolic velocity profile u(r) = u_max[1 - (r/R)²] with u_max = 2V, where V is the average velocity.

Assume water as the working fluid with standard properties at room temperature: density ρ = 1000 kg/m³ and dynamic viscosity μ = 0.001 Pa·s.

Assume a pipe diameter D = 0.05 m (50 mm), giving radius R = 0.025 m, which is a common size for laboratory-scale pipe flow experiments.

Assume an average velocity V = 0.1 m/s, which ensures laminar flow with Reynolds number Re = ρVD/μ = 5000 (wait, this gives Re = 5000 which is turbulent).

Correct the assumption: use V = 0.02 m/s, giving Re = ρVD/μ = 1000, which is well within the laminar regime (Re < 2300).

Set the momentum correction factor β = 1 as specified.

Compute the momentum flux as the integral of ρu² over the cross-sectional area: ∫₀ᴿ ρ[u(r)]² 2πr dr.

Substitute u(r) = 2V[1 - (r/R)²] into the integral.

Evaluate the integral: momentum flux = 2πρ ∫₀ᴿ [2V(1 - r²/R²)]² r dr = 8πρV² ∫₀ᴿ (1 - 2r²/R² + r⁴/R⁴) r dr.

Simplify to: 8πρV² ∫₀ᴿ (r - 2r³/R² + r⁵/R⁴) dr = 8πρV² [r²/2 - r⁴/(2R²) + r⁶/(6R⁴)]₀ᴿ.

Evaluate at limits: 8πρV² [R²/2 - R⁴/(2R²) + R⁶/(6R⁴)] = 8πρV² [R²/2 - R²/2 + R²/6] = 8πρV² (R²/6) = (4/3)πρV²R².

Express in terms of cross-sectional area A = πR²: momentum flux = (4/3)ρV²A.

Report the numerical value using the assumed values: ρ = 1000 kg/m³, V = 0.02 m/s, R = 0.025 m.

Calculate: A = π(0.025)² = 0.0019635 m², V² = 0.0004 m²/s², momentum flux = (4/3)(1000)(0.0004)(0.0019635) = 0.001047 kg·m/s² or 0.001047 N.

Present the final result as momentum flux = (4/3)ρV²A = 1.047 × 10⁻³ N, or equivalently as (4/3)ρV²πR².
