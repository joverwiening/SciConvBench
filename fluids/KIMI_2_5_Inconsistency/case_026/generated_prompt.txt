Compute the Reynolds number for water flow in a circular pipe using the following specifications.

The pipe has diameter D = 0.10 m.

The mean flow velocity is V = 2.0 m/s.

Use hydraulic diameter Dh = D = 0.10 m for the full circular pipe cross-section.

Use water properties at 20°C: density rho = 998 kg/m³ and dynamic viscosity mu = 1.0 × 10⁻³ Pa·s.

Calculate Reynolds number using the formula Re = (rho × V × Dh) / mu.

Report the final Reynolds number value.
