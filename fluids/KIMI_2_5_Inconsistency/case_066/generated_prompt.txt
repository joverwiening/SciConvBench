The degree of reaction for an axial compressor rotor shall be computed using the given velocity triangle data with the following specifications:

Assume axial velocity is constant through the rotor.
Use the given relative velocities: W1 = 150 m/s at beta1 = 45 degrees, and W2 = 100 m/s at beta2 = 30 degrees.
Compute the axial velocity component from the inlet conditions: Ca = W1 * cos(beta1) = 150 * cos(45°) = 106.07 m/s.
Verify axial velocity consistency: Ca = W2 * cos(beta2) = 100 * cos(30°) = 86.60 m/s.
Note that the given data contains an inconsistency, as the constant axial velocity assumption yields two different values (106.07 m/s vs 86.60 m/s).
Proceed with the calculation using the inlet-derived axial velocity Ca = 106.07 m/s as the reference value.
Compute the tangential components of relative velocity: Cw1 = W1 * sin(beta1) = 150 * sin(45°) = 106.07 m/s, and Cw2 = W2 * sin(beta2) = 100 * sin(30°) = 50 m/s.
Compute the rotor tangential velocity: U = Cw1 + Cw2 = 106.07 + 50 = 156.07 m/s (assuming Cw1 and Cw2 are in opposite directions, typical for a rotor).
Compute the degree of reaction using the standard formula: R = (Ca / (2U)) * (tan(beta1) + tan(beta2)).
Substitute values: R = (106.07 / (2 * 156.07)) * (tan(45°) + tan(30°)) = 0.3397 * (1.0 + 0.577) = 0.536.
Alternatively, use the alternative form: R = 0.5 + (Ca / (2U)) * (tan(beta1) - tan(beta2)) / 2, but the standard definition for compressors applies.
