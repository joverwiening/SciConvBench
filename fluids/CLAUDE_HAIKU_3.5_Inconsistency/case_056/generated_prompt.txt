Compute the Rayleigh number for natural convection from a vertical plate using the following parameters.
Surface temperature (Ts) = 80°C.
Ambient temperature (T∞) = 20°C.
Characteristic length (L) = 0.5 m.
Gravitational acceleration (g) = 9.81 m/s².
Film temperature (T_f) = 50°C or 323.15 K.
Kinematic viscosity (ν) = 1.5 × 10^-5 m²/s.
Thermal diffusivity (α) = 2.5 × 10^-5 m²/s.
Volumetric thermal expansion coefficient (β) = 3.09 × 10^-3 K^-1.
Calculate Rayleigh number using the formula: Ra = g β ΔT L^3 /(ν α).
Temperature difference (ΔT) = Ts - T∞ = 80°C - 20°C = 60°C.
