The task is to analyze isentropic supersonic flow through a frictionless converging nozzle and determine the change in velocity between inlet and exit.

Air enters the converging nozzle at Mach 2.0.
The exit-to-inlet area ratio is A2/A1 = 0.7.
The flow is isentropic throughout the nozzle with no normal shocks.
The supersonic branch of the area-Mach relation is used at both inlet and exit.
The ratio of specific heats is gamma = 1.4.
The gas constant for air is R = 287 J/(kg·K).
The stagnation temperature is assumed to be T0 = 300 K, consistent with standard atmospheric conditions.
Use the isentropic area-Mach relation: A/A* = (1/M) * [(2/(gamma+1)) * (1 + (gamma-1)/2 * M^2)]^((gamma+1)/(2*(gamma-1))).
Compute A1/A* from the inlet Mach number of 2.0 using the area-Mach relation.
Compute A2/A* as (A2/A1) * (A1/A*) = 0.7 * (A1/A*).
Solve the area-Mach relation for the exit Mach number using the supersonic solution (M > 1).
Compute the static temperature at the inlet using T1 = T0 / (1 + (gamma-1)/2 * M1^2).
Compute the static temperature at the exit using T2 = T0 / (1 + (gamma-1)/2 * M2^2).
Compute the speed of sound at each station using a = sqrt(gamma * R * T).
Compute the velocity at each station using V = M * a.
Report the inlet velocity, exit velocity, and the change in exit velocity relative to inlet velocity (V2 - V1).
The velocity change is expected to be negative, indicating a decrease in velocity as supersonic flow decelerates in the converging duct.
All results are reported in SI units (m/s for velocities, K for temperatures).
