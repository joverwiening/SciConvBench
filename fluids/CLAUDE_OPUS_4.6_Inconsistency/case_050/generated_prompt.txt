The task is a transient cooling analysis of a solid sphere using the lumped-capacitance method.

The Biot number is Bi = h L_c / k = 0.05, which satisfies the criterion Bi < 0.1, so the lumped-capacitance method is valid.

The characteristic length is defined as L_c = V / A_s = R / 3, where R is the radius of the sphere, V = (4/3) pi R^3, and A_s = 4 pi R^2.

Present the solution in dimensionless form as theta / theta_i = exp(-t / tau), where theta = T(t) - T_infinity, theta_i = T_i - T_infinity, and tau is the lumped-capacitance time constant.

The time constant is tau = (rho V c_p) / (h A_s) = (rho c_p L_c) / h = (rho c_p R) / (3 h).

Also present the solution using illustrative dimensional values: T_i = 200 degrees Celsius and T_infinity = 25 degrees Celsius, so theta_i = 175 degrees Celsius.

Plot or tabulate the transient cooling curve showing theta / theta_i as a function of dimensionless time t / tau, from t / tau = 0 to t / tau = 5.

Include key reference points on the curve: at t / tau = 1 the ratio is approximately 0.368, at t / tau = 2 it is approximately 0.135, at t / tau = 3 it is approximately 0.050, and at t / tau = 5 it is approximately 0.007.

Also express the cooling curve in dimensional form as T(t) = T_infinity + (T_i - T_infinity) exp(-t / tau), which gives T(t) = 25 + 175 exp(-t / tau) in degrees Celsius using the illustrative values.

State explicitly that the lumped-capacitance method assumes a spatially uniform temperature throughout the sphere at each instant in time, which is justified because Bi = 0.05 < 0.1.
