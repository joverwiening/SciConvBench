The task is a steady, incompressible flow analysis in a constant-area pipe.
The inlet volumetric flow rate is given as Q_in = 0.01 m^3/s.
The outlet volumetric flow rate is given as Q_out = 0.02 m^3/s, which is intentionally inconsistent.
Apply the continuity equation for steady incompressible flow in a constant-area pipe to show that Q_in must equal Q_out.
Correct the outlet flow rate to Q_out = Q_in = 0.01 m^3/s using mass conservation.
The pipe has a constant cross-sectional area A, which is not specified numerically.
Compute the velocity at the inlet as V_in = Q_in / A = 0.01 / A m/s.
Compute the velocity at the outlet as V_out = Q_out / A = 0.01 / A m/s.
Show that V_in = V_out, consistent with the continuity equation for these conditions.
Express the final velocities in terms of A since no numerical value for the cross-sectional area is provided.
