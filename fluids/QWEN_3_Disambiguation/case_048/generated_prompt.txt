Calculate the upstream Mach number, which is given as 2.2.
Use the normal shock relations for a perfect gas with constant specific heats.
Assume the ratio of specific heats (γ) is 1.4, typical for air.
Apply the normal shock equation to find the downstream Mach number.
The downstream Mach number is calculated using the formula: 
M2 = sqrt(( (γ - 1) * M1^2 + 2 ) / ( 2 * γ * M1^2 - (γ - 1) )) where M1 is 2.2.
Substitute M1 = 2.2 into the equation.
Compute the downstream Mach number.
The result is approximately 0.547.
