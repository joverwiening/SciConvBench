Assume turbulent flow with Reynolds number Re = 10000 as this is within the valid range for Dittus-Boelter correlation.
Assume heating condition (n = 0.4) as this is the more common case in heat transfer applications.
The Dittus-Boelter correlation is: Nu = 0.023 * Re^0.8 * Pr^0.4
Given Pr = 7.0, Re = 10000, and n = 0.4, calculate: Nu = 0.023 * (10000)^0.8 * (7.0)^0.4
The resulting Nusselt number is Nu = 82.84.
