Solve the steady-state heat conduction problem in a 1D slab with the following specifications:
The governing equation is d2T/dx2 = 0 (steady-state form of the heat equation).
Use a slab length of 1 meter.
Apply fixed temperature boundary conditions: T(0) = 100°C and T(L) = 20°C.
Use thermal diffusivity α = 1.0 × 10^-5 m²/s for a typical metal (aluminum).
Implement a linear solution T(x) = T0 + (T1-T0)x/L where x is the position along the slab.
Present the temperature distribution as a function of position T(x).
Output the temperature values at minimum 10 equally spaced points along the slab.
Plot the temperature distribution showing position (x) on horizontal axis and temperature (T) on vertical axis.
