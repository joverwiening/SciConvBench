The base temperature Tb is assumed to be 100°C (373.15 K) as a typical industrial process temperature.
The ambient temperature T_infinity is assumed to be 25°C (298.15 K) as standard room temperature.
The fin material is aluminum with thermal conductivity k = 237 W/mK.
The fin dimensions are length L = 0.1 m, thickness t = 0.003 m, and width w = 0.05 m.
The convection heat transfer coefficient h is assumed to be 25 W/m²K for natural convection in air.
The fin efficiency eta_f is 1.25 as specified.
Calculate the fin heat transfer rate using Q = eta_f * h * P * L * theta_b.
Use perimeter P = 2(t + w) for a rectangular fin.
Use theta_b as the temperature difference (Tb - T_infinity).
The calculation should use SI units throughout.
