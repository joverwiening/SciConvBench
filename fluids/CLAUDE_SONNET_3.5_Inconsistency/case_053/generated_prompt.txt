Use an aluminum sphere (k = 237 W/m·K, ρ = 2700 kg/m³, cp = 903 J/kg·K).
The sphere has a radius of 0.1 meters.
Set initial temperature T0 = 100°C.
Set ambient temperature T∞ = 25°C.
Calculate convection coefficient h from given Biot number (Bi = 5) and sphere dimensions.
Simulate cooling curve for 1 hour (3600 seconds).
Use time steps of 1 second for numerical solution.
Plot temperature vs time curve from t = 0 to 3600 seconds.
Calculate temperature using equation: T(t) = T∞ + (T0 - T∞)exp(-ht/ρcpV/A).
Note: Since Bi > 0.1, lumped capacitance method will give approximate results only.
