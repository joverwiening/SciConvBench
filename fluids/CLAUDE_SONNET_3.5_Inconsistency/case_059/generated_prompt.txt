Use gravitational acceleration g = 9.81 m/s^2 as the standard value at Earth's surface.
The critical depth can be found using yc = (q^2/g)^(1/3).
Given discharge per unit width q = 1.0 m^2/s.
Calculate critical depth yc = (1.0^2/9.81)^(1/3) = 0.467 m.
Note that the given depth of 1.0 m and velocity of 0.5 m/s are inconsistent with critical flow conditions.
The actual critical depth is 0.467 m, at which the Froude number would equal 1.
