Use water as the working fluid at standard conditions (20°C).
Set the diameter ratio (β = d/D) to 0.5, which is within typical industrial Venturi meter range.
Use a pressure difference (Δp) of 50 kPa, which is a common operating range.
Apply the ideal Bernoulli equation assuming Cd = 1.0 (no losses).
Calculate the theoretical flow rate Q using: Q = (A2/sqrt(1-β^4))*sqrt((2*Δp)/ρ).
Use SI units throughout all calculations.
Report the flow rate in both m³/s and L/min.
Note that this calculation will overestimate the actual flow rate due to neglecting losses.
