Calculate the turbulent pipe-flow Nusselt number using the Dittus–Boelter heating correlation Nu = 0.023·Re^0.8·Pr^0.4.
Use Re = 1.5×10^4.
Use Pr = 6.0.
Compute Re^0.8 = (1.5×10^4)^0.8 ≈ 2.204×10^3.
Compute Pr^0.4 = 6.0^0.4 ≈ 2.047.
Compute Nu = 0.023 × 2.204×10^3 × 2.047 ≈ 1.04×10^2.
Report Nu ≈ 104 (dimensionless).
