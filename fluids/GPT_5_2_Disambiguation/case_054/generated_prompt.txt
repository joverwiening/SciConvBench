Compute the average Nusselt number for external forced convection of air over a smooth, isothermal flat plate of length 1.5 m.
Use free-stream velocity U∞ = 10 m/s.
Use free-stream temperature T∞ = 20°C (293 K) and assume the plate surface is isothermal at Ts = T∞.
Use kinematic viscosity ν = 1.5×10^-5 m²/s and Prandtl number Pr = 0.7 as given.
Compute the Reynolds number based on plate length as ReL = U∞ L / ν.
Use the transition criterion that flow is turbulent for Re > 5×10^5.
If ReL ≤ 5×10^5, compute the average Nusselt number over the full plate using the laminar flat-plate correlation NūL = 0.664 ReL^0.5 Pr^(1/3).
If ReL > 5×10^5, compute the average Nusselt number over the full plate using a correlation that accounts for a laminar leading edge and turbulent remainder: NūL = (0.037 ReL^0.8 − 871) Pr^(1/3).
Report the final result as the dimensionless average Nusselt number NūL.
