Compute the Taylor number for Taylor–Couette flow between concentric cylinders with inner radius Rin = 0.050 m and outer radius Rout = 0.052 m.
Use gap d = Rout − Rin = 0.002 m.
Assume only the inner cylinder rotates at 100 rpm and the outer cylinder is stationary.
Convert rotation rate to angular velocity ω = 100·2π/60 = 10.4719755 rad/s.
Use dynamic viscosity μ = 0.01 Pa·s.
Use density ρ = 1000 kg/m³.
Compute kinematic viscosity ν = μ/ρ = 1.0×10^-5 m²/s.
Use the Taylor number definition Ta = (ω^2 · Rin · d^3) / ν^2.
Calculate Ta = (10.4719755^2 · 0.050 · (0.002)^3) / (1.0×10^-5)^2 = 4.386×10^3 (dimensionless).
