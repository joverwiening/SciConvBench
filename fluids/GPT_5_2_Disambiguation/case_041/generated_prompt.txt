Use the Darcy–Weisbach equation to compute head loss in a straight circular pipe.
Given pipe length L = 50 m.
Given pipe inner diameter D = 0.05 m.
Given average flow velocity V = 2 m/s.
Given Darcy friction factor f = 0.02.
Assume gravitational acceleration g = 9.81 m/s² as standard best-practice.
Compute head loss in meters of fluid head using h_f = f (L/D) (V²/(2g)).
Compute L/D = 50/0.05 = 1000.
Compute V²/(2g) = 4/(2·9.81) = 0.2039 m.
Compute h_f = 0.02 · 1000 · 0.2039 = 4.08 m.
Report Darcy–Weisbach head loss h_f ≈ 4.08 m of fluid head.
Do not use kinematic viscosity in the head-loss calculation because f is provided directly.
