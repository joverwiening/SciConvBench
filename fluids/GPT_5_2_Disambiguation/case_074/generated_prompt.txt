Compute the degree of reaction for a single axial-flow compressor rotor/stage using the given mean-radius velocity-triangle data.
Use the given inputs: rotor blade speed U = 200 m/s, rotor-inlet relative speed W1 = 150 m/s, rotor-exit relative speed W2 = 100 m/s, rotor-inlet relative flow angle β1 = 45° from the axial direction, rotor-exit relative flow angle β2 = 30° from the axial direction.
Assume constant axial velocity through the rotor, i.e., Vx1 = Vx2.
Interpret β angles as relative flow angles measured from the axial direction, so Wθ = W·sin(β) and Vx = W·cos(β).
Compute axial velocity from inlet relative quantities: Vx = W1·cos(β1).
Compute rotor-inlet relative whirl component: Wθ1 = W1·sin(β1).
Compute rotor-exit relative whirl component: Wθ2 = W2·sin(β2).
Convert relative to absolute whirl using Vθ = U − Wθ (from V = U + W with U purely tangential).
Compute absolute whirl components: Vθ1 = U − Wθ1 and Vθ2 = U − Wθ2.
Compute the rotor specific work (Euler): Δh0,rotor = U·(Vθ2 − Vθ1).
Compute the rotor static enthalpy rise using Δh_rotor = Δh0,rotor − (V2^2 − V1^2)/2, where V1^2 = Vx^2 + Vθ1^2 and V2^2 = Vx^2 + Vθ2^2.
Compute the stage (or rotor) degree of reaction as R = Δh_rotor / Δh0,rotor.
Report the numeric value of R and the intermediate velocity-triangle components (Vx, Vθ1, Vθ2, V1, V2) used to obtain it.
