Use the simple cavitation number definition sigma = (Pin − Pv) / (Pin − Pout).
Set upstream pressure Pin = 400 kPa (absolute).
Set downstream pressure Pout = 150 kPa (absolute).
Assume the fluid is liquid water.
Assume water temperature is 20 °C.
Use water vapor pressure at 20 °C as Pv = 2.34 kPa (absolute).
Compute pressure drop ΔP = Pin − Pout = 250 kPa.
Compute sigma = (400 − 2.34) / 250 = 1.59064.
Report cavitation index (sigma) ≈ 1.59 (dimensionless).
