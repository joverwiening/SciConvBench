Compute the Rayleigh number for natural convection along a vertical wall of height L = 0.5 m.
Use wall temperature Ts = 80°C and ambient temperature T∞ = 25°C, so ΔT = Ts − T∞ = 55 K.
Evaluate properties at the film temperature Tf = (Ts + T∞)/2 = 52.5°C = 325.65 K.
Use the ideal-gas thermal expansion coefficient β = 1/Tf = 1/325.65 = 0.00307 K^-1.
Use kinematic viscosity ν = 1.8×10^-5 m^2/s.
Use thermal diffusivity α = 2.6×10^-5 m^2/s.
Use gravitational acceleration g = 9.81 m/s^2.
Compute the Rayleigh number as RaL = g β ΔT L^3 / (ν α).
Report the numerical value RaL ≈ 4.5×10^8 (dimensionless).
