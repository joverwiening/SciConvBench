Compute the Reynolds number for internal flow in a smooth circular pipe using Re = (ρ V D) / μ.
Use D = 0.04 m as the pipe inner diameter.
Use V = 1.5 m/s as the average water velocity.
Use ρ = 998 kg/m³ as the water density.
Use μ = 0.001 Pa·s as the dynamic viscosity.
Calculate Re numerically and report the value.
Classify the flow as laminar if Re < 2300.
Classify the flow as transitional if 2300 ≤ Re ≤ 4000.
Classify the flow as turbulent if Re > 4000.
State the final classification (laminar, transitional, or turbulent) based on the computed Re.
