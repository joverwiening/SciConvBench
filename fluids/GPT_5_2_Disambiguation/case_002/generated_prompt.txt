Write a Python 3 script that computes the 2D lift coefficient CL at angle of attack α = 5 degrees using thin airfoil theory.
Use the NACA 4-digit mean camber line for NACA 4412 with m = 0.04 and p = 0.4.
Assume unit chord length c = 1.0 so x ∈ [0, 1] and x/c = x.
Implement the mean camber line yc(x) piecewise: for 0 ≤ x < p, yc = (m/p^2) (2 p x − x^2); for p ≤ x ≤ 1, yc = (m/(1−p)^2) ((1 − 2 p) + 2 p x − x^2).
Compute the camber-line slope dyc/dx piecewise: for 0 ≤ x < p, dyc/dx = (2 m/p^2) (p − x); for p ≤ x ≤ 1, dyc/dx = (2 m/(1−p)^2) (p − x).
Use the thin airfoil theory mapping x = (1 − cos θ)/2 with θ ∈ [0, π].
Evaluate dyc/dx at x(θ) to obtain z′(θ) = dyc/dx(x(θ)).
Compute the Fourier coefficients A0 and A1 using numerical integration over θ: A0 = α − (1/π) ∫0^π z′(θ) dθ; A1 = (2/π) ∫0^π z′(θ) cos θ dθ, with α in radians.
Compute lift coefficient using CL = 2 π (A0 + A1/2).
Use a numerical quadrature method (e.g., trapezoidal rule) with a sufficiently fine uniform θ grid (e.g., N = 10000) to ensure stable results.
Print the resulting CL as a single numeric value and also print intermediate values A0 and A1 for traceability.
Do not use thickness terms anywhere in the computation.
