Use an ideal Brayton cycle with air as an ideal gas with constant specific heats.
Set compressor inlet conditions to T1 = 300 K and P1 = 100 kPa.
Use pressure ratio rp = P2/P1 = 10 so P2 = 1000 kPa.
Use isentropic compressor efficiency ηc = 1.0.
Use turbine inlet temperature T3 = 1200 K.
Assume no pressure losses in the combustor so P3 = P2 = 1000 kPa.
Expand in the turbine to P4 = P1 = 100 kPa with isentropic turbine efficiency ηt = 1.0.
Use k = 1.4 and cp = 1.004 kJ/(kg·K).
Compute compressor exit temperature as T2 = T1 * (P2/P1)^((k-1)/k).
Compute turbine exit temperature as T4 = T3 * (P4/P3)^((k-1)/k).
Compute compressor specific work input as wc = cp * (T2 - T1) in kJ/kg.
Compute turbine specific work output as wt = cp * (T3 - T4) in kJ/kg.
Compute net specific work output as wnet = wt - wc in kJ/kg.
Report the numerical result: T2 ≈ 579.2 K, T4 ≈ 621.7 K, wc ≈ 280.4 kJ/kg, wt ≈ 580.6 kJ/kg, wnet ≈ 300.2 kJ/kg.
