Assume a calorically perfect gas with specific heat ratio gamma = 1.4 (air).
Use the normal-shock relation M2^2 = (1 + ((gamma - 1)/2) M1^2) / (gamma M1^2 - (gamma - 1)/2).
Set upstream Mach number M1 = 2.2.
Compute M2^2 = (1 + 0.2*(2.2^2)) / (1.4*(2.2^2) - 0.2) = 1.968 / 6.576 = 0.29927.
Compute downstream Mach number M2 = sqrt(0.29927) = 0.547.
