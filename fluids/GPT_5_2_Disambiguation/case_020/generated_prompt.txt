Compute the cavitation number σ for water flowing at 20 m/s.
Use the definition σ = (p_ref − p_v) / (0.5 ρ V^2).
Use reference static pressure p_ref = 50 kPa.
Use vapor pressure p_v = 2.3 kPa.
Use water density ρ = 1000 kg/m³.
Use flow speed V = 20 m/s.
Convert all pressures to Pa before calculation.
Compute dynamic pressure q = 0.5 ρ V^2 = 200,000 Pa.
Compute pressure difference Δp = p_ref − p_v = 47,700 Pa.
Compute cavitation number σ = Δp / q = 0.2385.
Report σ ≈ 0.24 (dimensionless).
