Compute the thermal Peclet number for external flow over a small object.
Use the definition Pe = U L / α.
Use characteristic length L = 5 cm = 0.05 m.
Use flow speed U = 0.1 m/s.
Use thermal diffusivity α = 1.2×10⁻⁷ m²/s.
Calculate Pe = (0.1)(0.05)/(1.2×10⁻⁷) = 4.17×10⁴ (dimensionless).
Report the result as Pe ≈ 4.2×10⁴.
