Compute the compressor outlet temperature T2 for a steady-flow compressor.
Use inlet temperature T1 = 300 K.
Use pressure ratio rp = P2/P1 = 8.
Use working fluid as ideal-gas air with constant specific heats.
Use specific heat ratio k = 1.4.
Use compressor isentropic efficiency ηc = 0.85, defined as ηc = (T2s − T1)/(T2 − T1) for a compressor.
Compute the isentropic outlet temperature using T2s = T1 * (P2/P1)^((k−1)/k).
Compute the actual outlet temperature using T2 = T1 + (T2s − T1)/ηc.
Report T2 in kelvin.
