Calculate the static temperature ratio T2/T1 across a normal shock wave.
Use upstream Mach number M1 = 2.0.
Use specific heat ratio γ = 1.4.
Compute the downstream-to-upstream static pressure ratio using p2/p1 = 1 + (2γ/(γ+1))·(M1^2 − 1).
Compute the downstream-to-upstream density ratio using ρ2/ρ1 = ((γ+1)·M1^2)/((γ−1)·M1^2 + 2).
Compute the static temperature ratio using T2/T1 = (p2/p1)/(ρ2/ρ1).
Report the numerical value of T2/T1 to at least 4 significant figures.
