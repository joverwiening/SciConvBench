Compute the hydraulic efficiency of a Pelton wheel turbine using η_h = P_runner / (ρ g Q H).
Use P_runner = 1300 kW.
Use Q = 0.5 m^3/s.
Use H = 300 m.
Use ρ = 1000 kg/m^3.
Use g = 9.81 m/s^2.
Convert P_runner to watts before substitution.
Compute the hydraulic power input as P_hyd = ρ g Q H.
Compute η_h as η_h = P_runner / P_hyd.
Report η_h as a decimal and as a percentage.
Using the given values, P_hyd = 1000 × 9.81 × 0.5 × 300 = 1,471,500 W.
Using the given values, η_h = 1,300,000 / 1,471,500 = 0.8834 ≈ 88.34%.
