Compute volumetric flow rate through a Venturi meter using incompressible liquid water.
Use differential pressure ΔP = 20 kPa between inlet and throat.
Use inlet diameter D1 = 100 mm.
Use throat diameter D2 = 50 mm.
Use discharge coefficient Cd = 0.98.
Assume water density ρ = 1000 kg/m³.
Compute area ratio β = D2/D1.
Compute A2 = π D2²/4.
Compute ideal flow Qideal = A2 * sqrt((2 ΔP)/(ρ (1 - β^4))).
Compute actual flow Q = Cd * Qideal.
Report Q in m³/s and in L/s.
