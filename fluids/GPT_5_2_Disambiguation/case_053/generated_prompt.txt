Compute torque for a Couette (concentric-cylinder) viscometer with inner cylinder rotating and outer cylinder stationary.
Use Newtonian fluid with constant dynamic viscosity μ = 0.5 Pa·s.
Use inner radius Ri = 0.020 m.
Use outer radius Ro = 0.021 m.
Use immersed height h = 0.050 m.
Use rotation speed N = 100 rpm and convert to angular speed ω = 2πN/60 rad/s.
Assume steady, laminar, axisymmetric Couette flow with no end effects and no slip at both cylinders.
Use the exact concentric-cylinder Couette solution giving torque on the inner cylinder: T = 4π μ h ω Ri^2 Ro^2 / (Ro^2 − Ri^2).
Calculate ω = 2π(100)/60 = 10.4719755 rad/s.
Calculate Ro^2 − Ri^2 = 0.021^2 − 0.020^2 = 4.1×10^-5 m^2.
Calculate Ri^2 Ro^2 = (0.020^2)(0.021^2) = 1.764×10^-7 m^4.
Calculate T = 4π(0.5)(0.05)(10.4719755)(1.764×10^-7)/(4.1×10^-5) N·m.
Report torque T ≈ 1.41×10^-2 N·m (≈ 0.0141 N·m).
