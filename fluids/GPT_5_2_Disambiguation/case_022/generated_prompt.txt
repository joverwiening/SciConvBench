Compute the drag coefficient Cd for a rigid, smooth, no-slip sphere in creeping flow at Reynolds number Re = 0.1.
Use the standard Stokes-law creeping-flow relation Cd = 24/Re.
Substitute Re = 0.1 to obtain Cd = 24/0.1 = 240.
Report Cd as dimensionless and note it is valid in the creeping-flow (Re ≪ 1) regime for a no-slip rigid sphere.
