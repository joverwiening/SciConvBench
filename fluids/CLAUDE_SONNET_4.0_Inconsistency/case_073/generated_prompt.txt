Analyze a Diesel cycle with the following specifications.
Use air as the working fluid with gamma = 1.4.
Set the compression ratio to 18 (typical for diesel engines).
Set the cutoff ratio to 2.0 (typical for diesel engines).
Calculate the thermal efficiency using the Diesel cycle efficiency formula: eta = 1 - (1/r^(gamma-1)) * ((rc^gamma - 1)/(gamma*(rc - 1))).
Where r is the compression ratio, rc is the cutoff ratio, and gamma is the specific heat ratio.
Substitute the values: r = 18, rc = 2.0, gamma = 1.4.
Report the final efficiency as a percentage.
