Analyze viscous flow of oil between parallel plates using the following specifications.
Use oil with dynamic viscosity μ = 0.1 Pa·s.
Set up pure Poiseuille flow with both plates stationary.
Use a plate separation distance of h = 0.01 m (1 cm gap).
Apply a pressure gradient of dp/dx = -1000 Pa/m driving the flow.
Develop the velocity profile u(y) = -(dp/dx)/(2μ) × y(h-y) where y is measured from the bottom plate.
Calculate the velocity gradient du/dy = -(dp/dx)/(2μ) × (h-2y).
Compute wall shear stress at the bottom plate using τ_wall = μ(du/dy)|_{y=0} = -μh(dp/dx)/(2μ) = -h(dp/dx)/2.
Compute wall shear stress at the top plate using τ_wall = μ(du/dy)|_{y=h} = μh(dp/dx)/(2μ) = h(dp/dx)/2.
Report the magnitude of wall shear stress as |τ_wall| = h|dp/dx|/2.
Substitute the values to get |τ_wall| = (0.01 m)(1000 Pa/m)/2 = 5 Pa.
