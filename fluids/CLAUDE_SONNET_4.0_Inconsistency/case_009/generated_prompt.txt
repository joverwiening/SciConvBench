Calculate the pressure at point B using Bernoulli's equation with the given conditions.
The flow is steady, inviscid, and rotational with fluid density of 1000 kg/m³.
At point A: pressure is 200 kPa, velocity is 5 m/s, elevation is 0 m.
At point B: velocity is 8 m/s, elevation is 0 m, pressure is unknown.
Apply Bernoulli's equation between points A and B using the same Bernoulli constant.
Use the standard form: p + (1/2)ρV² + ρgz = constant.
Solve for pressure pB at point B.
Note that applying Bernoulli's equation with the same constant between different streamlines in rotational flow is not strictly valid, but proceed as requested.
