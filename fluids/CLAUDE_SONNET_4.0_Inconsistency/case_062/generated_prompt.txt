Assume an upstream depth y1 = 1.0 meter for the hydraulic jump calculation.
Use the upstream Froude number Fr1 = 0.5.
Apply the hydraulic jump equation to find the sequent depth y2.
The sequent depth formula is y2/y1 = 0.5 * (-1 + sqrt(1 + 8*Fr1^2)).
Substitute Fr1 = 0.5 into the equation.
Calculate y2/y1 = 0.5 * (-1 + sqrt(1 + 8*0.25)) = 0.5 * (-1 + sqrt(3)) = 0.5 * (-1 + 1.732) = 0.366.
The sequent depth y2 = 0.366 * y1 = 0.366 * 1.0 = 0.366 meters.
Report the sequent depth as y2 = 0.366 meters.
