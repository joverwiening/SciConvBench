Use legacy FEniCS (dolfin) 2019.1.0 with mshr to solve a 2D small-strain linear elasticity plane-stress problem on the right triangle with vertices (0,0), (1,0), (0,0.5).
Generate the mesh in-code using mshr.Polygon([Point(0,0), Point(1,0), Point(0,0.5)]) and mshr.generate_mesh(domain, resolution) with resolution set to 16 as a reasonable choice to yield on the order of ~64 cells.
Use a vector-valued continuous Lagrange P2 displacement space: VectorFunctionSpace(mesh, "Lagrange", 2).
Impose a clamped (Dirichlet) boundary condition u = (0,0) on the base y = 0.
Leave the edge x = 0 as natural (traction-free) with no Neumann term.
Apply a uniform global x-directed traction on the sloping edge x + 2y = 1: t = (2000, 0) Pa, added as a boundary integral in the variational form.
Apply gravity as a volumetric body force f = (0, -rho*g) = (0, -26487) N/m^3 in the domain integral, consistent with unit thickness plane stress.
Formulate the weak problem: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_Ω f·v dx + ∫_{Γ_slope} t·v ds for all v in V0.
Use ε(u) = sym(grad(u)) in 2D.
Use plane-stress constitutive law in Lamé form with μ = E/(2(1+ν)), λ = Eν/((1+ν)(1-2ν)), and λ_ps = 2μλ/(λ+2μ).
Compute in-plane Cauchy stress as σ(u) = 2μ ε(u) + λ_ps tr(ε(u)) I (2D identity).
Solve the resulting linear system with a direct solver using MUMPS via solver_parameters = {"linear_solver": "mumps"}.
Post-process displacement magnitude as sqrt(u_x^2 + u_y^2) and project or interpolate it to a scalar CG space suitable for output.
Compute von Mises stress from the in-plane stress components (σxx, σyy, σxy) using σ_vm = sqrt(σxx^2 - σxx*σyy + σyy^2 + 3*σxy^2), and project it to a scalar CG space for output.
Write VTK/PVD files for ParaView for displacement magnitude and von Mises stress.
Also produce on-screen plots of displacement magnitude and von Mises stress using dolfin plotting utilities if available.
