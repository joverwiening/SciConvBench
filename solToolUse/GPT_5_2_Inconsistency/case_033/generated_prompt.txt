Use legacy FEniCS (dolfin) to solve a 3D displacement-only nonlinear hyperelasticity problem on the unit cube.
Create a UnitCubeMesh with 16 x 16 x 16 cells.
Define the displacement space as VectorFunctionSpace(mesh, "Lagrange", 1).
Use a compressible neo-Hookean material model with Young’s modulus E = 10.0 and Poisson ratio nu = 0.3.
Compute Lamé parameters from E and nu using mu = E/(2*(1+nu)) and lambda = E*nu/((1+nu)*(1-2*nu)).
Define the unknown displacement field u in the displacement space and a corresponding test function v.
Define kinematics with I = Identity(3), F = I + grad(u), C = F.T*F, and J = det(F).
Define the compressible neo-Hookean strain energy density psi = (mu/2)*(tr(C) - 3) - mu*ln(J) + (lambda/2)*(ln(J))^2.
Define the body force b = Constant((0.0, -0.5, 0.0)).
Define the traction h = Constant((0.1, 0.0, 0.0)).
Clamp the face x = 0 with a Dirichlet boundary condition u = (0,0,0) on that boundary.
Apply traction on all exterior faces except the clamped face, i.e. on x = 1, y = 0, y = 1, z = 0, and z = 1.
Implement boundary marking so that ds(traction_id) integrates only over the traction faces and excludes x = 0.
Interpret the traction as a constant dead-load traction in the reference configuration and include it via an external virtual work term integrated with ds.
Form the total potential energy Pi = integral_Omega psi dx - integral_Omega dot(b, u) dx - integral_Gamma_t dot(h, u) ds.
Compute the residual as the first variation R = derivative(Pi, u, v).
Compute the consistent tangent Jacobian as Jaco = derivative(R, u, du) where du is a TrialFunction in the displacement space.
Solve R == 0 for u using Newton’s method in dolfin with the assembled Jacobian.
Use a nonlinear solver configuration appropriate for Newton (e.g., NonlinearVariationalProblem/NonlinearVariationalSolver) and report convergence per iteration.
Output the final displacement field u (and optionally derived fields like J) to file for visualization.
