Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity problem on a right-triangular domain.
Use the triangle with vertices (0,0), (1,0), (0,0.5) in meters.
Treat the model as plane stress with unit thickness.
Use isotropic linear elastic material with E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3.
Apply gravity as a body force b = (0, -ρ g) with g = 9.81 m/s^2.
Use a vector-valued continuous Galerkin displacement space of first order (VectorFunctionSpace(mesh, "CG", 1)).
Generate a mesh with characteristic resolution corresponding to “64 elements” (use a 64-division mesh parameter for the triangle so the resulting mesh is of that order).
Impose a clamped (Dirichlet) boundary condition u = (0,0) on the left edge x = 0.
Apply a vertical traction on the hypotenuse boundary x + 2y = 1 with traction vector t = (0, σ_yy(x,y)).
Define the traction magnitude on the hypotenuse as σ_yy(x,y) = -5e3*sin(pi*x) Pa using the global x coordinate.
Do not reparameterize the sinusoidal traction by local arclength.
Formulate the weak form for static equilibrium: find u such that ∫Ω σ(u):ε(v) dx = ∫Ω b·v dx + ∫Γt t·v ds for all test functions v.
Use small-strain kinematics ε(u) = sym(grad(u)).
Use the reduced plane-stress constitutive law to compute in-plane Cauchy stress from ε(u).
Solve the resulting linear system with a direct linear solver.
Postprocess the in-plane Cauchy stress field σ(u) and compute von Mises stress from the in-plane components.
Output displacement and von Mises stress distributions over the domain (e.g., write to file for visualization).
