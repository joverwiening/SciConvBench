Implement a 2D small-strain linear elasticity solver in legacy FEniCS (dolfin) for a right-triangular domain with vertices (0,0), (1,0), (0,0.5).
Assume a standard legacy FEniCS/dolfin environment consistent with best practices (e.g., dolfin 2019.1.0 style APIs) without requiring a specific Docker/image tag.
Use plane-stress kinematics with unit thickness.
Use isotropic linear elastic material properties E = 70e9 Pa and ν = 0.33 with a reduced plane-stress constitutive law.
Use density ρ = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2.
Apply gravity as a constant body force b = (0, -ρ g) in N/m^3 over the domain.
Define the displacement unknown u as a vector-valued function in a continuous Galerkin space of degree 1 (e.g., VectorFunctionSpace(mesh, "CG", 1)).
Use a mesh resolution corresponding to 64 elements as the target discretization (e.g., a 64-cell mesh or an equivalent refinement producing comparable resolution for the triangle).
Impose clamped (Dirichlet) boundary conditions u = (0,0) on the vertical edge x = 0.
Identify the sloping boundary as the line segment satisfying x + 2y = 1 between (1,0) and (0,0.5).
Apply a true outward normal traction on the sloping boundary with magnitude p = 3000 Pa, using t = p n where n is the outward unit normal to that boundary.
Formulate the variational problem for plane-stress linear elasticity using ε(u) = sym(grad(u)) and σ(u) from the plane-stress constitutive relation.
Assemble the linear system corresponding to ∫Ω σ(u):ε(v) dx = ∫Ω b·v dx + ∫Γt (p n)·v ds for all test functions v.
Solve the linear system using a direct linear solver available in dolfin (e.g., LU via solve(A, u.vector(), b, "lu") or equivalent).
Post-process and output the displacement magnitude field |u| over the domain.
Compute the in-plane Cauchy stress tensor field σ(u) over the domain from the solved displacement.
Compute the von Mises stress field from the in-plane stress components (plane-stress von Mises based on σxx, σyy, σxy).
Output/visualize the displacement magnitude and von Mises stress distributions (e.g., write to XDMF/PVD for ParaView).
