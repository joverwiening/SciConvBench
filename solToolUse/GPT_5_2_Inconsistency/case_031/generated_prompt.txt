Implement a 2D small-strain linear elasticity solver in FEniCS legacy (dolfin), targeting FEniCS 2019.1.0 / dolfin 2019.1.0 behavior.
Model the domain as a parallelogram with vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3).
Generate an unstructured triangular mesh of the domain with 72 total triangular cells.
Use a vector-valued Lagrange displacement space of first order (CG1) on the mesh.
Assume plane stress with unit thickness.
Use material parameters E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2.
Apply gravity as a body force f = (0, -ρ g) over the domain.
Define small-strain kinematics ε(u) = sym(grad(u)).
Use the reduced plane-stress constitutive law to compute in-plane Cauchy stress σ(u) from ε(u).
Formulate the variational problem: find u in V such that ∫Ω σ(u):ε(v) dx = ∫Ω f·v dx + (point load contribution) for all v in V.
Apply a fully fixed (Dirichlet) boundary condition u = (0,0) on the left inclined edge defined by y = 1.5 x within the domain boundary.
Apply no other essential boundary conditions on the remaining three edges.
Treat the remaining three edges as traction-free natural boundaries (zero Neumann) except for the point load.
Apply a concentrated point load at the point (1.1, 0.15) using dolfin PointSource on the appropriate displacement component(s), not as a smeared traction.
Interpret the given load as a global horizontal vector of magnitude 5 kN with the given sign (i.e., a global x-direction load).
Identify the local outward unit normal of the right skew boundary edge (the edge from (1,0) to (1.2,0.3)).
Resolve the global horizontal load vector into the local normal direction of that right skew boundary.
Apply only the normal component (scalar projection onto the boundary normal, with sign) of the resolved load at (1.1, 0.15) via PointSource.
Assemble the linear system and solve with a direct solver using MUMPS if available, otherwise fall back to the default LU.
Post-process the displacement magnitude field ||u||.
Compute the in-plane Cauchy stress tensor field σ(u) over the domain.
Compute the von Mises stress field from the in-plane Cauchy stress components for plane stress.
Save the displacement field to an XDMF file for visualization (or PVD if XDMF is not convenient).
Save the von Mises stress field to an XDMF file for visualization (or PVD if XDMF is not convenient).
Print to the console the minimum and maximum of displacement magnitude over the domain.
Print to the console the minimum and maximum of von Mises stress over the domain.
