Determine success by inspecting beamfstrucdamp.sta for a successful termination message such as “JOB COMPLETED”.
Write results.json in the same directory with fields solver="calculix", case_id="beamfstrucdamp", status set to "success" if the .sta indicates completion otherwise "error", ccx_version set to the captured version string, artifacts as an empty array, and notes containing the exact ccx command used plus, if status="error", the error message and which file indicated failure.
