Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity plane-stress problem on Ω = (0, 1.0) × (0, 0.20) m with unit thickness.
Create a structured rectangular mesh with 100 elements along x and 20 elements along y.
Use a vector-valued Lagrange finite element space for displacement u = (u_x, u_y).
Model kinematics with infinitesimal strain ε(u) = sym(grad(u)).
Use Poisson’s ratio ν = 0.30 constant everywhere.
Define a spatially varying Young’s modulus as a function of height only: E(y) = 100e9 + 100e9*(y/0.20) Pa for y ∈ [0, 0.20].
Represent E(y) in the formulation using polynomial degree 1.
Use the reduced plane-stress constitutive law with Lamé-type parameters computed from E and ν as λ_ps = E*ν/(1-ν^2) and μ = E/(2*(1+ν)).
Define Cauchy stress as σ(u) = 2*μ*ε(u) + λ_ps*tr(ε(u))*I in 2D.
Formulate the variational problem: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_{Γ_R} t·v ds for all test functions v in V.
Apply essential boundary conditions on the left edge x = 0: u_x = 0 and u_y = 0.
Apply a uniform Neumann traction on the right edge x = 1: t = (2e6, 0) in units of N/m (traction per unit thickness).
Apply traction-free natural boundary conditions on the top and bottom edges by not adding any boundary integrals there.
Assemble the linear system and solve using a direct linear solver available in dolfin.
Compute the displacement magnitude field |u| = sqrt(u_x^2 + u_y^2).
Save a color map image of |u| over the domain to q9_disp.png.
Write the displacement solution field u to an XDMF file for post-processing.
