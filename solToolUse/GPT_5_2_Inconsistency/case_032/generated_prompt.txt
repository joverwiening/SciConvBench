Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity problem on a right-triangular domain in plane stress with unit thickness.
Create the domain as the triangle with vertices (0,0), (1,0), (0,0.5).
Generate a mesh with a characteristic resolution corresponding to 64 elements (use a standard triangular mesh generator available in dolfin such as mshr with an equivalent resolution parameter).
Use a vector-valued continuous Galerkin displacement space of first order (VectorFunctionSpace(mesh, "CG", 1)).
Use material parameters E = 70e9 Pa and ν = 0.33.
Use plane-stress constitutive law by converting (E, ν) to Lamé-like parameters for plane stress: μ = E/(2(1+ν)) and λ_ps = 2 μ ν/(1-ν).
Define strain as ε(u) = sym(grad(u)).
Define Cauchy stress for plane stress as σ(u) = 2 μ ε(u) + λ_ps tr(ε(u)) I in 2D.
Apply a clamped (Dirichlet) boundary condition u = (0,0) on the sloping edge x + 2y = 1.
Apply a constant traction boundary condition on the vertical edge x = 0 with traction vector t = (4000, 0) Pa.
Apply gravity as a constant body force b = (0, -ρ g) N/m^3 with ρ = 2700 kg/m^3 and g = 9.81 m/s^2, i.e., b = (0, -26487) N/m^3.
Formulate the variational problem: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_Ω b·v dx + ∫_{Γ_t} t·v ds for all test functions v in V.
Use a direct linear solver in dolfin (e.g., solve(a == L, u, bcs, solver_parameters={"linear_solver":"mumps"})).
Compute the displacement field u over the domain.
Compute the in-plane Cauchy stress tensor field σ(u) over the domain.
Compute von Mises stress from the in-plane stress components as σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2).
Project von Mises stress to a scalar CG1 space for visualization/output.
