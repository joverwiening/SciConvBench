Implement a legacy FEniCS (dolfin 2019.1.0 with mshr) script for small-strain 2D linear elasticity on a semi-circular (half-disk) domain in plane stress with unit thickness.
Create the geometry as a radius-1 m circle clipped to y ≥ 0 and generate the mesh with mshr using mesh = generate_mesh(domain, 64).
Use a vector-valued Lagrange CG2 (P2) function space for displacement u on the 2D mesh.
Use material parameters E = 70e9 Pa and nu = 0.33 and implement the reduced plane-stress constitutive law.
Define kinematics with epsilon(u) = sym(grad(u)).
Define plane-stress Lamé-like constants as mu = E/(2*(1+nu)) and lambda_ps = E*nu/(1 - nu**2).
Compute Cauchy stress as sigma(u) = 2*mu*epsilon(u) + lambda_ps*tr(epsilon(u))*Identity(2).
Apply gravity as a volumetric body force f = (0, -rho*g) with rho = 2700 kg/m^3 and g = 9.81 m/s^2 in the weak form.
Formulate and solve the variational problem: find u in V such that inner(sigma(u), epsilon(v))*dx = dot(f, v)*dx for all v in V, plus concentrated point loads.
Apply two concentrated point loads of -3000 N each in the negative y direction at the points (0.707, 0.707) and (-0.707, 0.707) using PointSource on the y-component subspace of the displacement function space.
Constrain only the two base points (-1, 0) and (1, 0) by enforcing pointwise DirichletBC with method="pointwise" fixing both displacement components u_x = 0 and u_y = 0 at those points.
Treat the diameter line segment y = 0 from x = -1 to x = 1 as part of the external boundary with no additional boundary conditions applied on it except the two pointwise fixed points.
Assemble the linear system and solve with a direct LU solver using PETSc/MUMPS.
Postprocess von Mises stress from the in-plane Cauchy stress field using sigma_dev = sigma - (1/3)*tr(sigma)*Identity(2) and sigma_vm = sqrt(3/2*inner(sigma_dev, sigma_dev)).
Project von Mises stress to a scalar CG1 space for output.
Write displacement u and von Mises stress sigma_vm to XDMF files suitable for visualization.
Print to the console the maximum displacement magnitude max(sqrt(dot(u,u))) and the maximum von Mises stress max(sigma_vm) over the mesh.
Use consistent SI units throughout.
