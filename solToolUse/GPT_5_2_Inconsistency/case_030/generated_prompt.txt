Implement a 2D small-strain linear elasticity solver in legacy FEniCS (dolfin) targeting FEniCS 2019.1.0 (e.g., quay.io/fenicsproject/stable:2019.1.0).
Model an L-shaped domain defined as the unit square [0,1]×[0,1] minus the top-right cutout square [0.5,1]×[0.5,1].
Use plane-stress kinematics with unit thickness.
Use isotropic linear elasticity with E = 70e9 Pa and ν = 0.33.
Use the reduced plane-stress constitutive law with λ_ps = E*ν/(1-ν^2) and μ = E/(2*(1+ν)).
Define strain ε(u) = sym(grad(u)).
Define Cauchy stress σ(u) = 2μ ε(u) + λ_ps tr(ε(u)) I in 2D.
Use density ρ = 2700 kg/m^3 and gravity g = 9.81 m/s^2.
Apply body force f = (0, -ρ*g) over the entire domain.
Apply a horizontal traction on the remaining outer right boundary x = 1 for y in [0, 0.5] with traction vector t = (2.65e4, 0) in Pa.
Keep the inner cutout boundaries traction-free (no displacement constraints and no applied traction).
Apply homogeneous Dirichlet boundary conditions u = (0,0) on the entire outer left edge x = 0 for y in [0,1].
Apply homogeneous Dirichlet boundary conditions u = (0,0) on the entire outer bottom edge y = 0 for x in [0,1].
Generate a mesh with resolution corresponding to 64 elements per outer edge (use an equivalent mesh density for the L-shape).
Use a vector-valued continuous Galerkin Lagrange displacement space of degree 1 (VectorFunctionSpace(mesh, "CG", 1)).
Formulate the variational problem: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_Ω f·v dx + ∫_{Γ_N} t·v ds for all v in V.
Solve the resulting linear system with a direct solver suitable for dolfin 2019.1.0 (e.g., MUMPS via LinearVariationalSolver parameters).
Compute the in-plane Cauchy stress field from the solved displacement.
Compute von Mises stress from the in-plane stress components as σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2).
Project von Mises stress to a scalar CG1 space for output.
Write displacement u to an XDMF file with a reasonable filename (e.g., "case_030_u.xdmf").
Write von Mises stress to an XDMF file with a reasonable filename (e.g., "case_030_von_mises.xdmf").
Print to console the maximum displacement magnitude max|u| over the mesh.
Print to console the maximum von Mises stress max(σ_vm) over the mesh.
