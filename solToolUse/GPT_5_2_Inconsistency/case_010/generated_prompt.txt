Use legacy FEniCS (dolfin) to solve a 2D small-strain orthotropic plane-stress linear elasticity problem with rotated material axes.
Define the domain Ω = (0, 1.0) × (0, 0.20) in meters.
Create a structured rectangular mesh with 50 elements along x and 25 elements along y.
Use a vector-valued continuous Galerkin finite element space of first order (CG1) for displacement u = (u_x, u_y).
Assume plane stress with unit out-of-plane thickness t_z = 1.0 m.
Use small-strain kinematics with ε(u) = sym(grad(u)).
Define local orthotropic lamina properties in the material (1-2) frame as E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, ν12 = 0.25.
Compute ν21 = ν12 * E2 / E1 for plane-stress orthotropic consistency.
Build the standard plane-stress reduced stiffness matrix Q in the material frame using E1, E2, G12, ν12, and ν21.
Rotate the stiffness from the material frame to the global (x-y) frame using a rotation angle of -30 degrees for assembly.
Form the global constitutive relation in Voigt form for plane stress as σ_voigt = Qbar * ε_voigt, where ε_voigt = [ε_xx, ε_yy, γ_xy]^T and γ_xy = 2 ε_xy.
Convert σ_voigt back to the 2×2 Cauchy stress tensor σ for use in the weak form.
Solve the variational problem: find u such that ∫_Ω ε(v):σ(u) dΩ = ∫_{Γ_top} v·t ds for all test functions v satisfying essential boundary conditions.
Apply Dirichlet boundary conditions on the bottom edge y = 0: u_x = 0 and u_y = 0.
Apply Neumann boundary condition on the top edge y = 0.20: uniform downward line traction per unit thickness t = (0, -10 MPa·m) applied directly with no additional thickness scaling.
Leave the vertical sides x = 0 and x = 1 traction-free.
Use a direct linear solver for the resulting linear system.
Compute and output the displacement field u.
Compute the Cauchy stress field σ from u using the rotated stiffness.
Compute the von Mises stress field for plane stress from σ.
