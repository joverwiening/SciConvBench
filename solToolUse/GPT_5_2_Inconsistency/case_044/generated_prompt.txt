Implement a 2D small-strain linear elasticity solver in legacy FEniCS (dolfin) for a plane-stress problem with unit thickness.
Target a typical legacy dolfin environment consistent with best practices (e.g., FEniCS 2019.1.0-style APIs), without requiring a specific Docker tag.
Create the parallelogram domain with vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3).
Generate an unstructured triangular mesh of the polygon using mshr Polygon meshing.
Choose the mesh resolution so the final mesh has approximately 72 triangular cells total, selecting the closest achievable cell count if exact 72 is not possible.
Use a vector-valued continuous Galerkin displacement space of first order (VectorFunctionSpace(mesh, "CG", 1)).
Use small-strain kinematics with strain epsilon(u) = sym(grad(u)).
Use a reduced plane-stress constitutive law with E = 70e9 Pa and nu = 0.33.
Compute the plane-stress Lamé-like parameters as mu = E/(2*(1+nu)) and lambda_ps = 2*mu*nu/(1-nu).
Define the in-plane Cauchy stress as sigma(u) = 2*mu*epsilon(u) + lambda_ps*tr(epsilon(u))*I, where I is the 2x2 identity.
Apply body force due to gravity as f = (0, -rho*g) with rho = 2700 kg/m^3 and g = 9.81 m/s^2.
Apply a true inward normal traction of magnitude 5000 Pa on the horizontal top edge, which corresponds to a vertical downward traction vector t = (0, -5000) in global coordinates.
Impose fully clamped Dirichlet boundary conditions u = (0,0) on both sloped side edges (the left edge from (0,0) to (0.2,0.3) and the right edge from (1,0) to (1.2,0.3)).
Leave the bottom edge traction-free.
Formulate the variational problem: find u in V such that a(u,v) = L(v) for all v in V, with a(u,v) = ∫_Ω inner(sigma(u), epsilon(v)) dx and L(v) = ∫_Ω dot(f,v) dx + ∫_{Γ_top} dot(t,v) ds.
Mark boundaries with MeshFunction/Measure so the top edge and the two sloped edges are identified robustly for traction and Dirichlet application.
Solve the resulting linear system with a direct solver using solver_parameters={"linear_solver": "mumps"}.
If MUMPS is unavailable, fall back to a standard direct alternative such as UMFPACK.
Postprocess the displacement field u and compute the in-plane von Mises stress from the Cauchy stress field.
Compute von Mises using the 2D in-plane formula: sigma_vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).
Project the von Mises scalar field to a first-order continuous scalar space for visualization.
Produce on-screen plots of displacement magnitude and von Mises stress using dolfin plot() and matplotlib show().
Optionally write results to VTK/PVD files using File("u.pvd") for displacement and File("von_mises.pvd") for von Mises stress.
Deliver the solution as a single runnable Python script that builds the mesh, applies loads and boundary conditions, solves for displacement, and outputs/plots displacement and von Mises stress.
