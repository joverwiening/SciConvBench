Implement a 2D small-strain linear elasticity solver in legacy FEniCS (dolfin) for a bonded two-material strip under plane-stress assumptions.
Use the computational domain Ω = (0, 1.0) × (0, 0.20) in meters with unit thickness.
Generate a structured conforming mesh of Ω with 80 elements along x and 16 elements along y.
Define two bonded subdomains separated by the horizontal interface y = 0.10 m.
Mark the top half (0, 1.0) × (0.10, 0.20) as steel.
Mark the bottom half (0, 1.0) × (0.00, 0.10) as aluminium.
Use a single conforming displacement function space for u = (u_x, u_y) over the whole mesh.
Represent material properties using cell markers or a DG0 field so that E varies by subdomain while ν is constant.
Set aluminium properties to E = 70e9 Pa and ν = 0.30.
Set steel properties to E = 200e9 Pa and ν = 0.30.
Formulate the variational problem for plane stress using the reduced plane-stress constitutive law with Lamé-type parameters derived for plane stress.
Use the small-strain tensor ε(u) = sym(grad(u)).
Define the Cauchy stress σ(u) from the plane-stress constitutive relation and the local material parameters.
Enforce perfect bonding at the interface implicitly by using the conforming displacement space (displacement continuity) and the standard weak form (traction continuity).
Apply Dirichlet boundary conditions on the left edge x = 0: u_x = 0 and u_y = 0.
Apply a uniform Neumann line traction on the right edge x = 1: t = (0, -5000) N/m.
Apply traction-free natural boundary conditions on the top edge y = 0.20 and bottom edge y = 0.00 by not adding Neumann terms there.
Assemble the linear system from the bilinear form ∫_Ω σ(u):ε(v) dx and the linear form ∫_{x=1} t·v ds.
Solve the linear system using a direct linear solver available in dolfin.
Compute the displacement magnitude |u| over the domain.
Save a color map image of |u| to q7_disp.png.
Write the displacement field u to an XDMF file suitable for ParaView visualization.
