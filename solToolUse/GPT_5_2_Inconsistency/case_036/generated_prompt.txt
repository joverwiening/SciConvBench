Implement a 2D small-strain linear elasticity solver in legacy FEniCS (dolfin) targeting dolfin 2019.1.0 behavior.
Use a single runnable Python script as the deliverable.
Model the domain as a parallelogram with vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3) in that order.
Generate a 2D mesh of the domain with exactly 72 total cells (elements).
Use a vector-valued Lagrange P1 (degree 1) finite element space for displacement.
Assume unit thickness for the 2D plane-stress model.
Use isotropic linear elastic material properties E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2.
Apply gravity as a body force in the negative y direction: f = (0, -ρ g).
Formulate the variational problem for plane stress using the reduced plane-stress constitutive law (compute σ from in-plane strains with plane-stress stiffness).
Define strain as ε(u) = sym(grad(u)).
Compute the in-plane Cauchy stress tensor σ(u) from ε(u) using the plane-stress constitutive matrix.
Clamp the right inclined edge (segment from (1,0) to (1.2,0.3)) with a full Dirichlet condition u = (0,0).
Leave the top and bottom horizontal edges traction-free (natural boundary conditions).
Leave any boundary not explicitly loaded traction-free by default.
Apply a constant traction load on the left inclined edge (segment from (0,0) to (0.2,0.3)) as a global horizontal traction vector t = (6000, 0) Pa.
Assemble and solve the resulting linear system using a direct linear solver, using "mumps" in dolfin.
Postprocess to compute the von Mises stress field from the in-plane Cauchy stress tensor σ(u) using the 2D von Mises expression based on σ_xx, σ_yy, and σ_xy.
Project or interpolate von Mises stress to a suitable scalar function space for output.
Write the displacement field to disk in a standard visualization format (XDMF preferred; PVD/VTK acceptable).
Write the von Mises stress field to disk in the same visualization format.
Print to the console the maximum displacement magnitude and the maximum von Mises stress over the domain.
