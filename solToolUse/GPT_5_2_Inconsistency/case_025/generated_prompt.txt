Use legacy FEniCS (dolfin) with mshr to solve a 2D small-strain linear-elasticity plane-stress problem on a stepped 8-vertex polygonal domain with unit thickness.

Assume the polygon vertices (counterclockwise, meters) are (0.0,0.0), (1.0,0.0), (1.0,0.4), (0.7,0.4), (0.7,0.7), (0.4,0.7), (0.4,1.0), (0.0,1.0).

Generate a triangular mesh of the polygon with a target of approximately 72 cells by choosing an mshr resolution parameter that yields about 72 elements (accept small deviation if exact 72 is not achievable).

Use a vector-valued continuous Galerkin displacement space V = VectorFunctionSpace(mesh, "CG", 1).

Use material parameters E = 70e9 Pa and nu = 0.33 with plane-stress constitutive law: lambda_ps = E*nu/(1 - nu**2) and mu = E/(2*(1+nu)).

Define strain eps(u) = sym(grad(u)).

Define plane-stress Cauchy stress sigma(u) = 2*mu*eps(u) + lambda_ps*tr(eps(u))*Identity(2).

Apply body force for gravity as f = (0, -rho*g) with rho = 2700 kg/m^3 and g = 9.81 m/s^2.

Apply Dirichlet boundary condition u = (0,0) on the entire bottom boundary where y = 0.

Apply Neumann traction t = (0, -10000.0) Pa on only the portion of the top boundary where y = 1.0 and 0.3 <= x <= 0.5.

Form the variational problem: find u in V such that a(u,v) = L(v) for all v in V, with a(u,v) = inner(sigma(u), eps(v))*dx and L(v) = dot(f, v)*dx + dot(t, v)*ds(top_segment).

Use a direct linear solver (e.g., solve(a == L, u, bcs, solver_parameters={"linear_solver":"mumps"})).

Compute displacement magnitude field umag = sqrt(dot(u,u)) and project it to a scalar CG1 space for output.

Compute von Mises stress from the in-plane stress components as vm = sqrt(sxx**2 - sxx*syy + syy**2 + 3*sxy**2), where sxx = sigma(u)[0,0], syy = sigma(u)[1,1], sxy = sigma(u)[0,1], and project vm to a scalar CG1 space for output.

Output u, umag, and vm to file (e.g., XDMF or VTK) for visualization.

Report the minimum and maximum of umag and vm over the domain.
