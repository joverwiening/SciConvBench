Implement a legacy FEniCS (dolfin) 2019.1.0 solution for 2D small-strain linear elasticity on a semi-circular domain using a plane-stress constitutive law with unit thickness.
Use SI units throughout with geometry in meters.
Create the half-disk domain of radius R = 1.0 m with y ≥ 0 by intersecting Circle(Point(0,0), 1.0) with Rectangle(Point(-1,0), Point(1,1)) using mshr.
Generate the mesh in-code with mshr using generate_mesh(domain, 64).
Use a vector-valued quadratic Lagrange displacement space: VectorFunctionSpace(mesh, "Lagrange", 2).
Use material parameters E = 70e9 Pa, nu = 0.33, density rho = 2700 kg/m^3.
Model gravity as a body force per unit volume f = (0, -rho*g) with g = 9.81 m/s^2.
Use the reduced 2D plane-stress linear elastic constitutive law (sigma_zz = 0) with unit thickness in the weak form.
Define small-strain tensor eps(u) = sym(grad(u)).
Define the in-plane Cauchy stress sigma(u) from the plane-stress constitutive law and use it in the variational formulation.
Solve for displacement u in the variational problem: find u such that ∫_Ω sigma(u):eps(v) dx = ∫_Ω f·v dx + ∫_{Γ_arc} t·v ds for all test functions v.
Apply a fully clamped Dirichlet boundary condition on the base boundary y = 0: u_x = 0 and u_y = 0.
Leave all other boundaries traction-free by default except the semicircular arc.
Apply an inward normal pressure on the semicircular arc boundary as traction t = -p*n with p = 20e3 Pa and n the outward unit normal of the solid.
Mark boundaries with MeshFunction/Measure so that the pressure traction is applied only on the semicircular arc and not on the base.
Use a direct linear solver (e.g., PETSc LU) to solve the resulting linear system.
Post-process the in-plane stress field to compute von Mises stress from the 2D Cauchy stress components (sigma_xx, sigma_yy, sigma_xy).
Compute von Mises as sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).
Project displacement, stress, and von Mises to suitable function spaces for output.
Write displacement and von Mises fields to ParaView-ready XDMF files.
Print on-screen summaries including maximum displacement magnitude and maximum von Mises stress over the domain.
