Target legacy FEniCS (dolfin) 2019.1.0 style APIs.
Implement a 2D small-strain linear elasticity solver under plane-stress assumptions with unit thickness.
Use material properties E = 70e9 Pa and nu = 0.33.
Use density rho = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2.
Model gravity as a constant body force b = (0, -rho*g) in N/m^3 applied over the domain.
Define the geometry as a rectangle from (0,0) to (1,0.5) with a circular hole of radius 0.1 centered at (0.5, 0.25) removed.
Generate the mesh using mshr (Rectangle minus Circle) with a resolution corresponding to approximately 64 elements along each outer edge.
Use a vector-valued Lagrange CG2 (P2) function space for displacement u.
Formulate the variational problem for linear elasticity with small strain epsilon(u) = sym(grad(u)).
Use the reduced plane-stress constitutive law to compute in-plane Cauchy stress sigma(u) from epsilon(u).
Apply Dirichlet boundary conditions clamping the entire left edge x = 0 with u = (0,0).
Leave the bottom edge y = 0 traction-free with no displacement constraints.
Leave the top edge y = 0.5 traction-free with no displacement constraints.
Leave the right edge x = 1 traction-free with no displacement constraints except for the applied point loads.
Leave the hole boundary traction-free with no displacement constraints and no applied traction/pressure.
Apply two concentrated point loads using dolfin PointSource on the x-displacement component: Fx = -3000 N at (1, 0.2) and Fx = +3000 N at (1, 0.3).
Assemble the linear system for the plane-stress elasticity problem including the body force contribution.
Solve the linear system using a direct solver with linear_solver set to "mumps".
Post-process the in-plane Cauchy stress field sigma(u) and compute the von Mises stress sigma_vm from the in-plane stress components.
Compute and print to stdout the maximum displacement magnitude max(|u|) over the domain.
Compute and print to stdout the maximum von Mises stress max(sigma_vm) over the domain.
Write the displacement field u to an XDMF file.
Write the von Mises stress field sigma_vm to an XDMF file.
Use consistent SI units throughout (meters, Newtons, Pascals, kilograms, seconds).
