Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem for displacement u = (u_x, u_y).
Define the rectangular domain Ω = (0, 1.0) x (0, 0.20) metres.
Create a uniform structured mesh with 20 subdivisions in x and 4 subdivisions in y using RectangleMesh.
Use a vector-valued continuous Lagrange finite element space of degree 1 (P1) for the displacement field.
Set Young's modulus E = 200e9 Pa and Poisson's ratio ν = 0.30.
Derive the plane-stress constitutive law with the reduced modulus: use lambda_ps = E*ν/((1 - ν**2)) and mu = E/(2*(1 + ν)).
Define the plane-stress stress tensor as sigma(u) = lambda_ps * tr(eps) * I + 2 * mu * eps, where eps = sym(grad(u)).
Apply the following Dirichlet boundary conditions using DirichletBC.
On the left edge (x = 0): fix both components, u_x = 0 and u_y = 0.
On the right edge (x = 1.0): prescribe u_x = 0.001 m and u_y = 0.
Apply no traction (natural boundary condition) on the top edge (y = 0.20) and bottom edge (y = 0).
Formulate the weak form as: a(u, v) = integral over Ω of inner(sigma(u), sym(grad(v))) dx, with zero body force so L(v) = 0.
Solve the resulting linear system using a direct linear solver (e.g., LUSolver or the default direct solver via solve).
After solving, extract the x-component of the displacement field (u_x).
Plot a colour map of u_x using matplotlib, add a colorbar and title, and save the figure as q1_ux.png.
Save the full displacement field u to an XDMF file using XDMFFile, naming the output file displacement.xdmf.
Use unit thickness (thickness = 1.0) implicitly, as the 2D formulation already assumes unit out-of-plane thickness.
Do not apply any body forces or distributed tractions; the only loading is the prescribed displacement on the right edge.
