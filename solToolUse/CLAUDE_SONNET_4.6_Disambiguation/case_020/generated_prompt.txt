Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem for displacement u = (u_x, u_y).
Define the rectangular domain Omega = (0, 1.0) x (0, 0.20) metres.
Create a uniform structured mesh with 40 subdivisions in x and 8 subdivisions in y using RectangleMesh.
Use Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.30.
Compute the plane-stress constitutive parameters: lambda_ps = E*nu/(1 - nu**2) and mu = E/(2*(1 + nu)).
Define the plane-stress stress tensor as sigma(u) = lambda_ps*tr(eps)*I + 2*mu*eps, where eps = sym(grad(u)).
Define a vector-valued function space using VectorFunctionSpace with Lagrange elements of degree 1.
Apply a Dirichlet boundary condition on the left edge (x = 0) fixing both u_x = 0 and u_y = 0.
Apply a uniform downward Neumann traction t = (0, -2000) N/m on the top edge (y = 0.20) as a surface integral using ds with a marked boundary.
Leave the right edge (x = 1.0) and bottom edge (y = 0) traction-free (natural boundary condition, no additional terms).
Mark boundaries using a MeshFunction and SubDomain classes to identify the top edge for the Neumann condition.
Formulate the bilinear form a(u, v) = integral of inner(sigma(u), eps(v)) dx over Omega.
Formulate the linear form L(v) = integral of dot(t, v) ds over the top edge.
Solve the resulting linear system using a direct linear solver (e.g., LUSolver or the default direct solver via solve).
After solving, extract the y-component of the displacement field u_y.
Plot a colour map of u_y using matplotlib, add a colorbar and title, and save the figure as q2_uy.png.
Save the full displacement field u to an XDMF file using XDMFFile, writing both the mesh and the displacement function.
Use unit thickness (thickness = 1.0) implicitly, consistent with the 2D plane-stress formulation.
