Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a right triangular domain.
Define the triangle vertices as (0,0), (1,0), and (0,0.5).
Generate the mesh using mshr with a resolution of 64 elements (mshr.generate_mesh with resolution=64).
Use material properties E=70e9 Pa, nu=0.33, rho=2700 kg/m^3, g=9.81 m/s^2.
Define the plane-stress constitutive law using the reduced elasticity tensor: lambda_ps = E*nu/(1-nu**2), mu = E/(2*(1+nu)).
Define the stress tensor as sigma(u) = lambda_ps * tr(eps(u)) * I + 2*mu*eps(u), where eps(u) = sym(grad(u)).
Use a vector-valued continuous Lagrange function space of degree 2 (VectorFunctionSpace with 'CG', degree 2) for displacement.
Apply a Dirichlet boundary condition fixing both displacement components to zero on the base edge y=0.
Identify the base boundary y=0 using a SubDomain or near() tolerance of 1e-10.
Apply gravity as a body force f = (0, -rho*g) using a Constant or as_vector.
Identify the sloping edge using the condition x + 2*y >= 1 - 1e-10 (the line x + 2y = 1).
Apply the horizontal shear traction tau_x = 2000 Pa on the sloping edge as a Neumann condition using a surface measure ds restricted to that boundary.
Define the Neumann traction vector as T = (2000, 0) on the sloping edge.
Mark boundaries using a MeshFunction of dimension 1 and integer markers: base=1, slope=2, left=0 (unmarked).
Define the variational problem: a(u,v) = integral of inner(sigma(u), eps(v)) dx; L(v) = inner(f, v)*dx + inner(T, v)*ds(2).
Solve the linear system using a direct solver by calling solve(a == L, u, bc) or using LUSolver.
After solving, compute the displacement magnitude as a scalar field: disp_mag = sqrt(u[0]**2 + u[1]**2) projected onto a scalar CG2 space.
Compute the full in-plane Cauchy stress tensor components sigma_xx, sigma_yy, sigma_xy by projecting sigma(u) onto a tensor function space (TensorFunctionSpace with 'DG', degree 1 or 'CG', degree 1).
Compute von Mises stress as: von_mises = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2), projected onto a scalar function space.
Project von Mises stress onto a scalar CG1 or DG1 function space.
Print the maximum displacement magnitude and maximum von Mises stress to the console.
Save the displacement field, displacement magnitude, and von Mises stress to separate XDMF or PVD files for visualization.
Plot the displacement magnitude and von Mises stress distributions using dolfin's built-in plot() function and matplotlib, showing colorbars and titles.
Do not use FEniCSx or dolfinx; use only the legacy dolfin API throughout.
