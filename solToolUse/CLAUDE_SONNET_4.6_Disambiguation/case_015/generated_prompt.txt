Use FEniCS legacy (dolfin) for the entire implementation.

Solve the incompressible finite-strain neo-Hookean problem using a mixed displacement-pressure formulation with Newton's method (plane strain).

Domain: rectangle Omega = (0, 1.0) x (0, 0.20) metres with a circular hole of radius a = 0.04 m centred at (0.50, 0.10).

Generate the mesh using mshr: create a Rectangle minus a Circle, with sufficient resolution to resolve the hole boundary accurately (use mesh resolution of at least 64).

Material: incompressible neo-Hookean solid with Young's modulus E = 5 MPa and Poisson's ratio nu = 0.5 (exactly).

Compute the shear modulus as mu = E / (2 * (1 + nu)).

Use the standard incompressible neo-Hookean strain energy density: W = (mu/2) * (tr(C) - 3) with the incompressibility constraint J = 1 enforced via the Lagrange multiplier pressure p.

The mixed formulation has unknowns (u, p) where u is the displacement vector (2D) and p is the hydrostatic pressure scalar.

Use a Taylor-Hood-like mixed element: vector CG2 for displacement and scalar CG1 for pressure, defined on a MixedFunctionSpace.

Define the deformation gradient F = I + grad(u), the Jacobian J = det(F), the left Cauchy-Green tensor B = F * F^T, and the right Cauchy-Green tensor C = F^T * F.

The total potential energy functional is: Pi = integral_Omega [ (mu/2)*(tr(F^T F) - 3) - p*(J - 1) ] dx minus the follower pressure contribution on the hole boundary.

The follower pressure load on the hole boundary is an inward pressure of magnitude P_hole = 0.10 MPa, giving a Neumann traction t = -P_hole * J * inv(F)^T * N ds in the reference configuration (Nanson's formula), where N is the outward unit normal on the hole boundary in the reference configuration.

Implement the follower pressure contribution to the virtual work as: delta_W_ext = P_hole * J * dot(inv(F)^T * N, v) * ds(hole), where v is the test function for displacement.

Identify the hole boundary using a SubDomain or a MeshFunction that marks facets where (x - 0.5)^2 + (y - 0.1)^2 <= (0.04 + tol)^2 for a small tolerance tol = 1e-3.

Boundary conditions: fix both components of u to zero on the left edge (x = 0) using DirichletBC.

Right edge, top edge, and bottom edge are traction-free (natural boundary conditions, no explicit Neumann term needed).

Derive the residual F_res as the Gateaux derivative of Pi with respect to (u, p) in the direction of test functions (v, q), including the follower pressure term.

Derive the Jacobian J_jac as the Gateaux derivative of F_res with respect to (u, p) in the direction of trial functions (du, dp) using derivative().

Solve the nonlinear problem using a manual Newton loop or NonlinearVariationalProblem / NonlinearVariationalSolver with Newton solver settings: relative tolerance 1e-10, absolute tolerance 1e-10, maximum iterations 25.

After convergence, extract the displacement field u_sol and pressure field p_sol from the mixed solution.

Compute the Cauchy stress tensor: sigma = (mu / J) * B - p_sol * Identity(2).

Compute the von Mises stress from the Cauchy stress as: vm = sqrt(sigma[0,0]**2 - sigma[0,0]*sigma[1,1] + sigma[1,1]**2 + 3*sigma[0,1]**2), projected onto a scalar DG0 or CG1 function space.
