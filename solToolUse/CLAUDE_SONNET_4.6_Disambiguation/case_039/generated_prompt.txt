Final Specification:

Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-stress linear elasticity problem using the dolfin finite element library.
Use a vector-valued displacement function space with triangular elements (P2 Lagrange recommended, or P1 if preferred) on a 2D mesh.
Use a direct linear solver (e.g., LU) to solve the assembled linear system.

Geometry:
Create a rectangular domain of width 1.0 m and height 0.5 m.
Place a circular hole of radius 0.1 m centered at (0.5, 0.25) in the plate.
Use mshr (or dolfin mesh generation) to subtract the circle from the rectangle.
Set mesh resolution to 64 elements per edge (pass 64 as the resolution parameter to mshr generate).

Material Properties:
Set Young's modulus E = 70e9 Pa.
Set Poisson's ratio nu = 0.33.
Set density rho = 2700 kg/m^3.
Set gravitational acceleration g = 9.81 m/s^2.
Derive plane-stress Lame-like parameters: lambda_ps = E*nu / (1 - nu**2), mu = E / (2*(1 + nu)).
Use the reduced plane-stress constitutive law: sigma = lambda_ps * tr(eps) * I + 2*mu*eps, where eps is the symmetric gradient of displacement and I is the 2x2 identity.
Assume unit thickness (t = 1.0 m) for all surface/volume integral scaling.

Boundary Conditions:
Identify the left edge as x[0] near 0.0.
Identify the right edge as x[0] near 1.0.
Identify the bottom edge as x[1] near 0.0.
Identify the top edge as x[1] near 0.5.
Apply a Dirichlet condition uy = 0 (vertical displacement component = 0) on the left edge.
Apply a Dirichlet condition ux = 0 (horizontal displacement component = 0) on the right edge.
Do not apply any Dirichlet condition on the top or bottom edges; they receive Neumann (traction) loads.

Loading:
Apply a uniform vertical compressive traction of sigma_yy = -2500 Pa on both the top and bottom edges as Neumann boundary conditions.
On the top edge, the outward normal points in the +y direction, so the traction vector is (0, -2500) Pa.
On the bottom edge, the outward normal points in the -y direction, so the traction vector is (0, +2500) Pa (to maintain compression, i.e., t = sigma * n gives (0, -2500)*(-1) = (0, +2500)).
Include body force due to gravity: f = (0, -rho*g) N/m^3 as a volumetric body force in the weak form.

Variational Formulation:
Define the bilinear form a(u, v) = integral over domain of inner(sigma(u), eps(v)) dx, where eps is the symmetric gradient.
Define the linear form L(v) = integral of dot(f, v) dx + integral over top/bottom boundaries of dot(t, v) ds.
Use a MeshFunction to mark boundary subdomains and a ds measure restricted to top and bottom edges for the Neumann terms.

Solution and Post-Processing:
Solve the variational problem a(u, v) = L(v) for displacement u using a direct solver.
After solving, compute the Cauchy stress tensor field sigma_h = lambda_ps * tr(eps(u)) * I + 2*mu*eps(u) projected onto a tensor function space (DG0 or P1 tensor space).
Compute the von Mises stress as: von_mises = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2), using only in-plane components.
Project von Mises stress onto a scalar function space.
Save displacement field u to a file named displacement.pvd.
Save von Mises stress field to a file named von_mises.pvd.
Print the maximum displacement magnitude and maximum von Mises stress value to the console.
Plot displacement magnitude and von Mises stress using dolfin's built-in plot function and matplotlib, with colorbars and titles, and save figures as displacement_magnitude.png and von_mises_stress.png.
