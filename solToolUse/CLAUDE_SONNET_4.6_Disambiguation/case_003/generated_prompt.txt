Use FEniCS legacy (dolfin) for the entire implementation.
Define the L-shaped domain as the set difference of a 1x1 square minus a 0.5x0.5 square in the lower-right corner, specifically the region where x in [0,1], y in [0,1], excluding x in [0.5,1] and y in [0,0.5].
Generate the mesh using mshr with a resolution of 64 elements per edge (mshr.generate_mesh with resolution=64).
Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace with "Lagrange", degree=2) for the displacement field.
Apply plane-stress constitutive law with Young's modulus E=70e9 Pa and Poisson ratio nu=0.33.
Compute the plane-stress Lame-like parameters as lambda_ps = E*nu/(1-nu**2) and mu = E/(2*(1+nu)).
Define the symmetric strain tensor as eps(u) = sym(grad(u)).
Define the plane-stress Cauchy stress tensor as sigma(u) = lambda_ps*tr(eps(u))*Identity(2) + 2*mu*eps(u).
Apply a Dirichlet boundary condition fixing both displacement components to zero on the left boundary where x=0, using a tolerance of 1e-10.
Apply body force due to gravity as f = (0, -rho*g) with rho=2700 kg/m^3 and g=9.81 m/s^2, expressed as a Constant vector.
Apply a Neumann traction on the right boundary where x=1, with traction vector T = (0, t_y) where t_y varies linearly in y: t_y = -2.65e4 * y / 1.0, so t_y = 0 at y=0 and t_y = -2.65e4 Pa at y=1.
Express the linearly varying traction as a FEniCS Expression with degree=1: t_y = Expression("-2.65e4 * x[1]", degree=1).
Define the right boundary as the facets where x[0] >= 1.0 - 1e-10, and mark it using a MeshFunction and ds measure.
Formulate the bilinear form a(u,v) = inner(sigma(u), eps(v)) * dx.
Formulate the linear form L(v) = dot(f, v)*dx + dot(T, v)*ds(right_boundary_marker).
Assemble and solve the linear system using a direct solver (LUSolver or the default direct solver via solve(a==L, u, bc)).
After solving, compute the full in-plane stress tensor field by projecting sigma(u) onto a tensor function space (TensorFunctionSpace with "Lagrange", degree=1).
Compute von Mises stress as von_mises = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where s11, s22, s12 are the in-plane stress components, using the deviatoric stress definition for plane stress.
Specifically, compute von Mises as: sigma_vm = sqrt(sigma_xx^2 + sigma_yy^2 - sigma_xx*sigma_yy + 3*sigma_xy^2) from the projected stress tensor components.
Project the von Mises stress onto a scalar FunctionSpace ("Lagrange", degree=1).
Save the displacement field to a file named "displacement.pvd".
Save the von Mises stress field to a file named "von_mises.pvd".
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
Do not use any deprecated or non-legacy FEniCS API; use only dolfin imports.
Use mshr for geometry creation: mshr.Rectangle and mshr.generate_mesh.
Define the L-shape as mshr.Rectangle(Point(0,0), Point(1,1)) minus mshr.Rectangle(Point(0.5,0), Point(1,0.5)) to remove the lower-right quadrant.
