Use FEniCS legacy (dolfin) for the entire implementation.

Solve a 2D plane-stress small-strain linear elasticity problem on a two-material bonded strip.

Define the domain Ω as a rectangle (0, 1.0) x (0, 0.20) metres.

Create a structured rectangular mesh of 80 x 16 cells over Ω using RectangleMesh.

Define two material subdomains: Ω_Steel is the bottom half where y < 0.10 m, and Ω_Al is the top half where y >= 0.10 m.

Mark subdomains using a MeshFunction of type size_t over cells, with marker 1 for Ω_Steel and marker 2 for Ω_Al.

Assign material properties: Ω_Steel has E = 200e9 Pa and ν = 0.30; Ω_Al has E = 70e9 Pa and ν = 0.30.

Use the plane-stress reduced constitutive law with unit thickness (t = 1 m).

Express the plane-stress constitutive relation as: σ = (E / (1 - ν²)) * [(1-ν)*ε + ν*tr(ε)*I] where ε is the symmetric small-strain tensor.

Define E and ν as piecewise-constant functions using a DG0 (discontinuous Galerkin, degree 0) FunctionSpace, assigning values cell-by-cell based on the subdomain markers.

Use a vector-valued continuous Lagrange finite element space of degree 2 (P2) for the displacement field u.

Apply the following boundary conditions:
Left edge (x = 0): Dirichlet condition u_x = 0 and u_y = 0 (fully fixed).
Right edge (x = 1.0): apply a uniform downward Neumann traction t = (0, -5000) N/m.
Top edge (y = 0.20) and bottom edge (y = 0.00): traction-free (no condition applied, natural BC).

Mark the right edge boundary using a MeshFunction and ds measure to apply the Neumann traction as a surface integral in the weak form.

Formulate the weak form: a(u, v) = integral over Ω of inner(sigma(u), epsilon(v)) dx, and L(v) = integral over right edge of dot(t_vec, v) ds, where t_vec = (0, -5000).

Solve the resulting linear system using a direct linear solver (e.g., LU via dolfin's default direct solver or by specifying solver type "lu").

After solving, compute the displacement magnitude field |u| = sqrt(u_x² + u_y²) as a scalar Function.

Save a colour map plot of |u| as q7_disp.png using matplotlib, with a colorbar and axis labels.

Save the displacement field u to an XDMF file using XDMFFile, with the file named to reflect the problem (e.g., q7_displacement.xdmf).

The perfect bond at y = 0.10 m is enforced implicitly by the continuous P2 function space spanning both subdomains; no explicit interface condition is needed beyond the piecewise material definition.
