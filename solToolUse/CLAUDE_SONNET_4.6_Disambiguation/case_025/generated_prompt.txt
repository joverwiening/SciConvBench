Use FEniCS legacy (dolfin) for the entire implementation.

The 2D domain is a stepped polygon with 8 vertices defined as follows (reasonable best-practice assumption for a domain consistent with traction on 0.3 <= x <= 0.5):
(0.0, 0.0), (0.6, 0.0), (0.6, 0.3), (0.5, 0.3), (0.5, 0.6), (0.3, 0.6), (0.3, 0.3), (0.0, 0.3).
This creates an L-shaped / stepped polygon with overall width 0.6 m and overall height 0.6 m, with a notch cut from the upper-right region.

Generate the mesh using mshr (dolfin's mshr module) by creating a Polygon from the 8 vertices listed above and calling generate_mesh with a resolution of 72.

Use plane-stress linear elasticity in 2D with unit thickness.

Material parameters: E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3, g = 9.81 m/s^2.

Compute the Lame-like plane-stress parameters: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)).

Define the plane-stress constitutive law: sigma(u) = lambda_ps * tr(eps) * I + 2 * mu * eps, where eps = sym(grad(u)).

Define a vector-valued function space using VectorFunctionSpace with element family "Lagrange" and degree 1.

Apply a Dirichlet boundary condition fixing both displacement components to zero on the bottom edge where y <= 1e-10.

Apply a body force f = (0, -rho * g) as a Constant over the entire domain.

Apply a Neumann traction t = (0, -10000) Pa on the partial top boundary segment where y >= (max y of domain - 1e-10) AND 0.3 <= x <= 0.5.
Mark this partial top boundary using a MeshFunction of dimension (mesh dimension - 1) and a SubDomain, then use ds(marked_id) in the variational form.

Formulate the bilinear form a(u, v) = inner(sigma(u), sym(grad(v))) * dx.
Formulate the linear form L(v) = dot(f, v) * dx + dot(t_vector, v) * ds(traction_id).

Solve the linear system using a direct solver (LUSolver or the default direct solve via solve(a == L, u, bc)).

After solving, compute the displacement magnitude as a scalar field: magnitude = sqrt(u[0]**2 + u[1]**2), projected onto a scalar FunctionSpace of degree 1.

Compute the von Mises stress as follows: evaluate sigma(u) at each point, compute s = sigma - (1/3)*tr(sigma)*I (deviatoric, but for 2D plane stress use: von_mises = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2)), project this scalar field onto a scalar FunctionSpace of degree 1.

Save the displacement magnitude field to a file named displacement_magnitude.pvd.
Save the von Mises stress field to a file named von_mises_stress.pvd.
Print the maximum displacement magnitude and maximum von Mises stress to the console.
