Create the file case_085.inp in the working directory with the following content.

The heading line is: Model: beam     Date: 10-Mar-1998

Define all 262 nodes using the *NODE keyword with the coordinates given in the input deck, adding node 262 at coordinates (0.0, 0.0, 1.0).

Define 32 elements of type C3D20 (20-node hexahedral) using the *ELEMENT keyword with ELSET=B1, using the connectivity listed in the input deck.

Define node set CN7 containing nodes: 97, 96, 95, 94, 93, 20, 19, 18, 17, 16, 15, 14, 13, 12, 11, 10, 9, 4, 3, 2, 1.

Define element set EALL using *ELSET,ELSET=EALL,GENERATE spanning elements 1 to 32.

Define node set NALL using *NSET,NSET=NALL,GENERATE spanning nodes 1 to 261.

Define the material using *MATERIAL,NAME=LIN_ISO_EL followed by *ELASTIC with values 210000 and 0.3.

Assign the material to all elements using *SOLID SECTION,ELSET=EALL,MATERIAL=LIN_ISO_EL.

Define the MPC constraint using *MPC with the MEANROT type linking nodes 5, 6, 7, 8 to node 262 as written in the input deck: MEANROT,5,5,5,6,6,6,7,7,7,8,8,8,262.

Define the step using *STEP,INC=100,NLGEOM.

Inside the step, apply *CONTROLS,PARAMETERS=FIELD with values: 0.25,0.25,0.01,0.02,1.E-5,1.E-3,1.E-8.

Apply boundary conditions inside the step using *BOUNDARY to fix node set CN7 in DOFs 1, 2, and 3 (set each to zero displacement).

Apply a prescribed displacement to node 262 in DOF 1 with a value of 0.5 using *BOUNDARY inside the step.

Request displacement output using *NODE PRINT,NSET=NALL with U.

Request force output using *NODE PRINT,NSET=NALL with RF.

Request stress output using *EL PRINT,ELSET=EALL with S.

Request strain output using *EL PRINT,ELSET=EALL with E.

Request internal energy density output using *EL PRINT,ELSET=EALL with ENER.

Close the step with *END STEP.

Run CalculiX using the command: ccx -i case_085

Check the file case_085.sta for the string "JOB COMPLETED" to confirm success.

Obtain the version string by running: ccx -v

Write results.json in the working directory with the following fields.
Set "solver" to "calculix".
Set "case_id" to "case_085".
Set "status" to "success" if case_085.sta contains "JOB COMPLETED", otherwise set it to "error".
Set "ccx_version" to the version string obtained from ccx -v.
Set "artifacts" to a list containing the filenames: ["case_085.inp", "case_085.dat", "case_085.frd", "case_085.sta", "case_085.cvg"].
Set "notes" to the exact ccx command used, and if the run failed, append the error message and the name of the file that indicated the failure.
