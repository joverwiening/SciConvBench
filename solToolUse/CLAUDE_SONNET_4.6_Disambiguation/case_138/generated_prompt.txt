Create a file named case_138.inp in the working directory with the following content.

The file begins with comment lines describing the model as a cantilever beam testing COUPLING and KINEMATIC for large displacements.

Include the *HEADING line: Model: beam     Date: 10-Mar-1998

Include all *NODE definitions from node 1 through node 262, exactly as provided, with node 262 at coordinates 10., 0., 0.

Include the *ELEMENT block with ELSET=Eall, containing all 32 C3D20 elements exactly as provided.

Include *MATERIAL,NAME=EL followed by *ELASTIC on the next line, then the values 210000.0, 0.3 on the line after that.

Include *SOLID SECTION,ELSET=Eall,MATERIAL=EL with no additional parameters.

Include the *SURFACE definition named S1 listing the face entries exactly as provided.

Include *COUPLING,REF NODE=262,SURFACE=S1,CONSTRAINT NAME=CN1 followed by *KINEMATIC and then the line 1,3.

Include *NSET,NSET=N1 followed by node 100.

Include *STEP,NLGEOM to enable large displacement analysis.

Include *BOUNDARY with the lines 262,1,5 and 262,6,6,1.57 to fix DOFs 1 through 5 of node 262 and apply a rotation of 1.57 radians at DOF 6.

Include *NODE PRINT,NSET=N1,FREQUENCY=100 followed by U to request displacement output for node set N1 every 100 increments.

Include *END STEP to close the step.

Run CalculiX using the command: ccx -i case_138

Check the file case_138.sta for the string JOB COMPLETED to confirm successful termination.

Get the version string by running: ccx -v

Write results.json with solver set to calculix, case_id set to case_138, status set to success if JOB COMPLETED is found in case_138.sta or error otherwise, ccx_version set to the version string obtained from ccx -v, artifacts set to an empty list, and notes recording the exact ccx command used plus any error message and the file that indicated failure if the run did not succeed.
