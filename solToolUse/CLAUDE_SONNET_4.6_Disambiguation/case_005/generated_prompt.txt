Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-strain nearly incompressible linear elasticity problem using a mixed displacement-pressure formulation with a direct saddle-point solve.
The domain is a rectangle Ω = (0, 1.0) x (0, 0.20) metres.
Create a structured mesh of 100 x 20 quadrilateral-based triangular cells over Ω using RectangleMesh.
Use small-strain linear elasticity in plane strain.
Set Young's modulus E = 5 MPa and Poisson's ratio ν = 0.49.
Compute the Lamé parameters as lmbda = E*nu/((1+nu)*(1-2*nu)) and mu = E/(2*(1+nu)).
Use a mixed finite element formulation with Taylor-Hood elements: continuous piecewise quadratic vector elements (P2) for displacement and continuous piecewise linear scalar elements (P1) for pressure.
Define the mixed function space as W = VectorElement("CG", triangle, 2) x FiniteElement("CG", triangle, 1).
Define the constitutive relation using the plane-strain stress tensor: sigma(u, p) = 2*mu*sym(grad(u)) + p*Identity(2), where p is the Lagrange multiplier for the volumetric constraint.
Define the incompressibility constraint equation as: div(u) - p/lmbda = 0 (or equivalently the saddle-point weak form coupling displacement and pressure).
Apply the following boundary conditions:
Left edge (x = 0): fix both components, u_x = 0 and u_y = 0.
Right edge (x = 1.0): prescribe u_x = 0.03 m and u_y = 0.
Top edge (y = 0.20) and bottom edge (y = 0.0): traction-free (natural boundary condition, no action required).
Assemble the full saddle-point system and solve using a direct linear solver (e.g., LU via dolfin's default direct solver or "mumps").
After solving, extract the displacement sub-function u and pressure sub-function p from the mixed solution.
Compute the displacement magnitude field |u| = sqrt(u_x^2 + u_y^2) at each node.
Save a colour map plot of |u| over the domain as q10_disp.png using matplotlib, with a colorbar and axis labels.
Save the displacement field u to an XDMF file named q10_displacement.xdmf using dolfin's XDMFFile with write_checkpoint or standard write, compatible with ParaView.
Do not apply any body forces (f = 0).
All units are SI: metres and Pascals.
