Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a cross-shaped plate with four circular holes.
Define the cross geometry as the union of a horizontal rectangle spanning x in [-1, 1] and y in [-0.3, 0.3], and a vertical rectangle spanning x in [-0.3, 0.3] and y in [-1, 1].
Subtract four circular holes of radius 0.12 centered at (0.6, 0), (-0.6, 0), (0, 0.6), and (0, -0.6) from the cross geometry.
Use the mshr library to construct the geometry and generate the mesh with resolution 100.
Use a vector-valued second-order Lagrange finite element function space (VectorFunctionSpace with degree 2) for the displacement field.
Apply the plane-stress constitutive law with Young's modulus E = 210000 and Poisson's ratio nu = 0.3.
Compute the plane-stress Lame-like parameters as lambda_ps = (E * nu) / (1 - nu**2) and mu = E / (2 * (1 + nu)).
Define the stress tensor using the plane-stress reduced form: sigma = lambda_ps * tr(eps) * I + 2 * mu * eps, where eps is the symmetric gradient of displacement.
Apply a Dirichlet boundary condition u = (0, 0) on the left edge where x = -1, using a tolerance of 1e-10 for boundary identification.
Apply a Neumann traction t = (0, -5e4) on the right edge where x = 1 as a natural boundary condition in the weak form.
Mark the right edge boundary using a MeshFunction and a SubDomain, and use ds(subdomain) to integrate the traction term.
Assemble and solve the linear variational problem using a direct linear solver (LUSolver or the default direct solver via solve).
After solving, compute the von Mises stress field as a scalar quantity: von_Mises = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2).
Project the von Mises stress onto a scalar first-order Lagrange function space for visualization and output.
Save the displacement field and the von Mises stress field to separate XDMF files named displacement.xdmf and von_mises.xdmf.
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
