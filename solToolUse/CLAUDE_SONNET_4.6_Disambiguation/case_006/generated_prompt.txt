Use FEniCS legacy (dolfin) for the entire implementation.

Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement finite element space and a direct linear solver (e.g., LUSolver or the default direct solver via solve()).

Material properties: E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3, g = 9.81 m/s^2.

Derive the plane-stress constitutive constants: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)).

Define the stepped polygon with the following 8 vertices in order: (0.0, 0.0), (1.0, 0.0), (1.0, 0.2), (0.5, 0.2), (0.5, 0.4), (0.3, 0.4), (0.3, 0.2), (0.0, 0.2).

The top segment (partial top edge) is the horizontal edge from (0.3, 0.4) to (0.5, 0.4), at y = 0.4.

Create the mesh using mshr: define the domain as a Polygon with those 8 vertices and generate a mesh with resolution 72.

Use a vector-valued CG1 (P1) function space for displacement.

Define the strain tensor as epsilon(u) = sym(grad(u)).

Define the plane-stress Cauchy stress tensor as sigma(u) = lambda_ps * tr(epsilon(u)) * Identity(2) + 2 * mu * epsilon(u).

Define the variational form: a(u, v) = inner(sigma(u), epsilon(v)) * dx, L(v) = dot(f_body, v) * dx + dot(t_traction, v) * ds(traction_marker).

Body force vector: f = Constant((0.0, -rho * g)).

Horizontal traction on the partial top edge: t = Constant((5000.0, 0.0)), applied only on the boundary segment where y is approximately 0.4 and 0.3 <= x <= 0.5.

Mark boundary regions using a MeshFunction of size_t on facets (dimension 1).

Mark the bottom support (y = 0, full bottom edge) with marker value 1.

Mark the left stem support (x = 0.3, vertical edge between y=0.2 and y=0.4) with marker value 2.

Mark the right stem support (x = 0.5, vertical edge between y=0.2 and y=0.4) with marker value 3.

Mark the partial top edge (y = 0.4, 0.3 <= x <= 0.5) with marker value 4.

Use a tolerance of 1e-10 for all boundary coordinate comparisons.

Apply Dirichlet boundary conditions: fix both u_x = 0 and u_y = 0 on the bottom support (marker 1).

Apply Dirichlet boundary condition: fix u_y = 0 on the left stem support (marker 2).

Apply Dirichlet boundary condition: fix u_y = 0 on the right stem support (marker 3).

Define a Measure ds using the facet MeshFunction so that ds(4) integrates over the partial top edge.

Assemble and solve the linear system using the direct solver.

After solving, compute the von Mises stress field as a scalar quantity projected onto a scalar CG1 function space.

Compute von Mises stress as: sigma_vm = sqrt(s11^2 + s22^2 - s11*s22 + 3*s12^2), where s11, s22, s12 are the in-plane components of the Cauchy stress tensor evaluated from the solution displacement field.

Project the von Mises stress expression onto a scalar DG0 or CG1 function space.

Print the maximum and minimum values of the von Mises stress field.

Save the displacement field to a file named displacement.pvd.

Save the von Mises stress field to a file named von_mises.pvd.
