Compute the Lame-like plane-stress parameters as: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)).

Define the plane-stress constitutive relation: sigma(u) = lambda_ps * tr(eps) * I + 2 * mu * eps, where eps = sym(grad(u)).

Function space: Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace, 'CG', 2) on the half-disk mesh.

Variational formulation: Write the weak form as: inner(sigma(u), eps(v)) * dx = dot(f, v) * dx + dot(t, v) * ds(arc), where v is the test function.

Use a ds measure restricted to the arc boundary using a MeshFunction and FacetNormal for the outward normal.
