Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement finite element space and a direct linear solver.
The domain is a 1.0 m x 0.5 m rectangle with a circular hole of radius 0.1 m centered at (0.5, 0.25).
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s².
Use the plane-stress reduced constitutive law with unit thickness.
The effective plane-stress Lamé-like parameters are: λ_eff = E·ν / (1 - ν²), μ = E / (2·(1 + ν)).
The stress tensor is σ(u) = λ_eff · tr(ε(u)) · I + 2·μ·ε(u), where ε(u) = sym(grad(u)).
Generate the mesh using mshr (or pygmsh/gmsh if mshr is unavailable): create a Rectangle(Point(0,0), Point(1,0.5)) minus a Circle(Point(0.5,0.25), 0.1) and generate with resolution 64.
Use a continuous Lagrange vector element of degree 2 (P2) for the displacement field.
Apply a Dirichlet boundary condition fixing both displacement components to zero on the left edge (x = 0).
Apply body force f = (0, -ρ·g) as a volume load in the weak form.
Apply a Neumann traction on the right edge (x = 1): t = (0, -6000·sin(4·π·y)) Pa, meaning a vertical traction t_y = -6000·sin(4·π·y).
Apply a Neumann traction on the top edge (y = 0.5): t = (1000, 0) Pa, meaning a constant shear traction t_x = 1000 Pa.
Leave the hole boundary and the bottom edge traction-free (natural boundary condition, no additional terms).
Define boundary subdomains using SubDomain classes or by marking a MeshFunction of dimension (mesh.topology().dim()-1) for left, right, top, and hole boundaries.
Assemble the bilinear form a(u,v) = integral of inner(sigma(u), epsilon(v)) dx.
Assemble the linear form L(v) = integral of dot(f, v) dx + integral of dot(t_right, v) ds(right) + integral of dot(t_top, v) ds(top).
Solve the linear system using a direct solver (e.g., LUSolver or solver type "lu").
After solving, project or compute the Cauchy stress tensor field onto a tensor function space (DG0 or P1 tensor space).
Compute the von Mises stress as: σ_vm = sqrt(σ_xx² - σ_xx·σ_yy + σ_yy² + 3·σ_xy²), using the in-plane stress components only (plane-stress assumption, σ_zz = 0).
Output the following: the maximum displacement magnitude, the maximum von Mises stress, and the location of the maximum von Mises stress.
Save the displacement field to a file named "displacement.pvd" and the von Mises stress field to a file named "von_mises.pvd" for visualization in ParaView.
Print a summary to stdout including max displacement magnitude and max von Mises stress value.
