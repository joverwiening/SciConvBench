Use FEniCS legacy (dolfin) for all implementation.

Geometry: Create an L-shaped 2D domain defined as a 1x1 square with a 0.5x0.5 square removed from the top-right corner.
The L-shape occupies the region: (0 <= x <= 1, 0 <= y <= 0.5) union (0 <= x <= 0.5, 0.5 <= y <= 1).
Use a mesh resolution of 64 elements per edge.
Generate the mesh using mshr with a Rectangle(Point(0,0), Point(1,1)) minus a Rectangle(Point(0.5,0.5), Point(1,1)), with resolution 64.

Material properties: E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3, g = 9.81 m/s^2.
Compute the plane-stress Lame-like parameters: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)).

Formulation: Use 2D plane-stress with unit thickness.
Define the displacement function space as a vector-valued Lagrange element of degree 2 on the mesh: VectorFunctionSpace(mesh, 'Lagrange', 2).
Define the plane-stress constitutive law: sigma(u) = lambda_ps * tr(eps(u)) * Identity(2) + 2 * mu * eps(u), where eps(u) = sym(grad(u)).

Boundary conditions: Apply a homogeneous Dirichlet (fixed) boundary condition on the left boundary where x = 0, fixing both displacement components to zero.
Define the left boundary as the set of points where x[0] < DOLFIN_EPS.

Body force: Include gravity as a body force vector f = (0, -rho * g) applied as a Constant((0.0, -rho*g)).

Variational problem: Define the bilinear form a(u, v) = inner(sigma(u), eps(v)) * dx.
Define the linear form L(v) = dot(f, v) * dx.

Point load: Apply a downward vertical point load of magnitude -2.65e4 N at coordinates (0.5, 0.5) using PointSource.
Create a PointSource on the y-component of the function space (sub-space index 1) at Point(0.5, 0.5) with magnitude -2.65e4.
Assemble the system matrix A and vector b from a and L first, then apply the PointSource to b using point_source.apply(b).
Apply the Dirichlet boundary condition to both A and b before solving.

Solver: Use a direct linear solver via solve(A, u.vector(), b) or the dolfin solve() interface with a direct method (e.g., LU).

Post-processing: Compute the von Mises stress from the in-plane Cauchy stress field.
Project the stress tensor sigma(u) onto a tensor function space.
Compute von Mises as: von_mises = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2), where s11, s22, s12 are the in-plane stress components and the deviatoric stress is used.
Use the formula: von_mises = sqrt(0.5 * ((s11-s22)**2 + (s22)**2 + (s11)**2 + 6*s12**2)) or equivalently project sqrt(3/2 * inner(dev(sigma_expr), dev(sigma_expr))) onto a scalar FunctionSpace.
Project von Mises stress onto a scalar Lagrange function space of degree 2.

Output: Print the maximum displacement magnitude (max of u.vector()).
Print the maximum von Mises stress value.
Save the displacement field u to a file named displacement.pvd.
Save the von Mises stress field to a file named von_mises.pvd.
Plot the displacement magnitude and von Mises stress using dolfin plot() and matplotlib if running interactively.
