Use FEniCS legacy (dolfin) for the entire implementation.
Solve the incompressible finite-strain neo-Hookean problem in plane strain using a mixed displacement-pressure (u, p) formulation with Newton's method.
The domain is a rectangle Ω = (0, 1.0) x (0, 0.20) m with a circular hole of radius a = 0.04 m centred at (0.50, 0.10).
Generate the mesh using mshr (or gmsh via dolfin) by subtracting the circle from the rectangle.
Use a mesh resolution sufficient to resolve the hole geometry (recommend characteristic size ~0.01 m near the hole).
The material is an incompressible neo-Hookean solid with Young's modulus E = 5 MPa and Poisson's ratio ν = 0.5.
Compute the shear modulus as mu = E / (2 * (1 + nu)).
Use the incompressible neo-Hookean strain energy density W = (mu / 2) * (tr(F^T F) - 3), where F = I + grad(u) and J = det(F) = 1 is enforced via the pressure field p.
The total energy functional is Pi = integral of [W - p * (J - 1)] dV.
Derive the weak form by taking the Gateaux derivative of Pi with respect to (u, p) in the directions (v, q).
Use a mixed function space: Taylor-Hood elements P2 for displacement u and P1 for pressure p, defined on the same mesh.
Apply the following boundary conditions:
Left edge (x = 0): u_x = 0 and u_y = 0 (fully fixed).
Right edge (x = 1.0): u_x = 0.060 m (prescribed) and u_y = 0.
Top edge, bottom edge, and the hole boundary: traction-free (natural boundary conditions, no Dirichlet condition applied).
Apply the prescribed displacement on the right edge incrementally using at least 10 load steps to aid Newton convergence.
At each load step, solve the nonlinear system using Newton's method via dolfin's NonlinearVariationalSolver or by manually assembling and solving the linearised system.
Use a relative tolerance of 1e-10 and absolute tolerance of 1e-10 for Newton convergence, with a maximum of 50 iterations per step.
After the final load step, compute the deformation gradient F = I + grad(u) using the converged displacement field.
Compute the left Cauchy-Green tensor b = F * F^T.
Compute the Cauchy stress tensor sigma = (mu / J) * b - p * I, where I is the identity tensor and J = det(F).
Compute the von Mises stress as sigma_vm = sqrt(3/2 * s:s) where s = sigma - (1/3)*tr(sigma)*I is the deviatoric Cauchy stress.
Project the hydrostatic pressure p onto a suitable scalar function space for visualisation.
Project the von Mises stress sigma_vm onto a suitable scalar function space for visualisation.
Save a colour map of the hydrostatic pressure field p as q12_p.png using matplotlib with a suitable colormap (e.g., 'RdBu_r').
Save a colour map of the von Mises stress field as q12_vm.png using matplotlib with a suitable colormap (e.g., 'viridis').
Save the displacement field u to an XDMF file named q12_displacement.xdmf using dolfin's XDMFFile.
All output files (q12_p.png, q12_vm.png, q12_displacement.xdmf) are to be written to the working directory.
