Assign the material to all elements using *SOLID SECTION,ELSET=Eall,MATERIAL=EL with thickness 1.57d0.

Request stress output using *EL PRINT, ELSET=Eall with S.

Close the step with *END STEP.

Run CalculiX using the command `ccx -i case_050`.
