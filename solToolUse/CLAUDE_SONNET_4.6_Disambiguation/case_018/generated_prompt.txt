Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress static linear elasticity problem using a vector-valued displacement finite element space and a direct linear solver.
The geometry is a rectangle of width 4.0 and height 1.0 with a circular hole centred at (1.0, 0.5) with radius 0.3.
Generate the mesh using mshr with a resolution of 72.
Use a second-order vector Lagrange function space (VectorFunctionSpace with degree 2) for the displacement field.
Material properties are Young's modulus E = 210e3 and Poisson's ratio nu = 0.3.
Derive the plane-stress constitutive parameters: lambda_ps = E*nu/(1 - nu**2) and mu = E/(2*(1 + nu)).
Define the symmetric gradient (strain) as eps(u) = sym(grad(u)).
Define the plane-stress constitutive relation as sigma(u) = lambda_ps * tr(eps(u)) * Identity(2) + 2*mu*eps(u).
Apply a Dirichlet boundary condition u = (0, 0) on the left edge where x[0] is near 0.0.
Apply a uniform downward Neumann traction t = (0, -1e5) on the right edge where x[0] is near 4.0.
There is no body force.
Formulate the bilinear form a(u, v) = inner(sigma(u), eps(v)) * dx.
Formulate the linear form L(v) = dot(t, v) * ds restricted to the right edge using a boundary subdomain or ds with a marked boundary.
Mark boundaries using a MeshFunction and SubDomain classes: left edge (x[0] near 0.0) for Dirichlet, right edge (x[0] near 4.0) for the Neumann traction.
Use the marked ds measure so the traction integral is applied only on the right edge.
Solve the linear system using a direct solver (e.g., LUSolver or solve with default direct backend).
After solving, compute the von Mises stress field as a scalar quantity projected onto a scalar function space.
Compute von Mises stress as: s = sigma(u) - (1/3)*tr(sigma(u))*Identity(2), then von_mises = sqrt(3/2 * inner(s, s)).
Project the von Mises stress onto a scalar CG degree-2 (or degree-1) function space.
Save the displacement field u and the von Mises stress field to separate XDMF or PVD files for visualisation.
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
