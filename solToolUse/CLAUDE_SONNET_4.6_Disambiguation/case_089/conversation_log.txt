Q: What is the input deck content for the `*AMPLITUDE,NAME=QUADRATIC,USER` section — specifically, does the user amplitude require a Fortran subroutine (e.g., `uamplitude.f`), and if so, what is the source code for that subroutine?
A: Yes, the `*AMPLITUDE,NAME=QUADRATIC,USER` keyword requires a user-supplied Fortran subroutine called `uamplitude.f`. The complete requirement describes it as a "quadratic" amplitude. Based on the test case context (the amplitude at time 0.5 gives half the full-load result, and at time 1.0 gives the full result, consistent with a quadratic function of time), the subroutine should return `amplitude = time^2`.

The subroutine source code is:

      implicit none
      real*8 time,ampli
      integer jstep,jinc,noel,kstep,kamp
      ampli=time*time
      return
      end
