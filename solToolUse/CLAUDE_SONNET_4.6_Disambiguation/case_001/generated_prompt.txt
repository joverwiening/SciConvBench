Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem using the dolfin finite element library.
Material properties: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s².
Define the stepped polygon domain with vertices (0,0), (0.8,0), (0.8,0.2), (0.5,0.2), (0.5,0.5), (0.3,0.5), (0.3,0.2), (0,0.2) in order, forming a closed polygon.
Generate a mesh of the polygon domain using dolfin's Mesh or mshr with approximately 72 elements.
Use a vector-valued continuous Lagrange finite element space (degree 2 recommended, or degree 1) for the displacement field over the mesh.
Apply the plane-stress constitutive law: compute the stress tensor σ from the strain tensor ε(u) = 0.5*(grad(u) + grad(u).T) using the plane-stress reduced form with effective Lamé-like parameters derived from E and ν.
The plane-stress constitutive relation is: σ = (E/(1-ν²)) * ((1-ν)*ε + ν*tr(ε)*I) for the in-plane components, with unit thickness.
Apply a Dirichlet boundary condition fixing both displacement components (u_x = 0, u_y = 0) on the bottom edge where y = 0 (from x=0 to x=0.8).
Apply body force due to gravity as a volume load: f = (0, -ρ*g) in the variational form.
Apply a Neumann traction on the top segment where y = 0.5 and 0.3 ≤ x ≤ 0.5.
The traction on that segment is purely vertical: t = (0, -8000*x) Pa, where x is the global x-coordinate of the point on the boundary.
Define the traction using a dolfin Expression or equivalent that evaluates -8000*x using the spatial coordinate x[0].
Mark the traction boundary using a SubDomain or MeshFunction that identifies facets where y is approximately 0.5 and x is between 0.3 and 0.5.
Integrate the traction term as dot(t, v) * ds(traction_marker) in the weak form, where ds is the boundary measure restricted to the marked traction facet.
All other boundary segments (left, right, interior steps) have zero Neumann traction (natural boundary condition, no action needed).
Assemble and solve the resulting linear system using a direct linear solver (e.g., dolfin's LUSolver or the default direct solver via solve()).
After solving, compute the Cauchy stress tensor field from the displacement solution using the same plane-stress constitutive law.
Compute the von Mises stress as: σ_vm = sqrt(σ_xx² - σ_xx*σ_yy + σ_yy² + 3*σ_xy²) using the in-plane stress components only (plane-stress assumption, σ_zz = 0).
Project the von Mises stress scalar field onto a scalar function space (e.g., DG0 or CG1) for visualization and output.
Output or plot the displacement magnitude field and the von Mises stress field.
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
