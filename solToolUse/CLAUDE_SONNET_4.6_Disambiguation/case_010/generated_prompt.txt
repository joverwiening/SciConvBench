Use FEniCS legacy (dolfin) for the entire implementation.
Solve a plane-strain small-strain von Mises elastoplasticity problem on a quarter plate with a quarter hole.
The domain is [0, 100] x [0, 180] mm with a quarter-circular hole of radius 50 mm centered at the origin, leaving the region where x^2 + y^2 >= 50^2 inside the rectangle.
Use millimeters as the length unit and GPa as the stress unit throughout (convert consistently so that 1 mm = 1 length unit, 1 GPa = 1e3 MPa = 1e6 kPa).
Material parameters: Lame first parameter lambda = 19.44 GPa, shear modulus mu = 29.17 GPa, yield stress sigma_Y = 243 MPa = 0.243 GPa.
Use perfect plasticity (no hardening).
Use associative flow rule with von Mises yield criterion.
Enforce plane-strain conditions (epsilon_zz = 0, gamma_xz = gamma_yz = 0).
Generate the mesh using mshr (or gmsh via dolfin-mshr) by subtracting a quarter-disk of radius 50 mm from the rectangle [0,100]x[0,180].
Use a mesh resolution sufficient for accuracy, targeting approximately 50 or more elements along each side (choose a mesh size parameter of 3 or finer).
Define displacement u in a vector FunctionSpace of degree 2 (Taylor-Hood or standard CG2 for displacement).
Store internal variables (plastic strain tensor components and equivalent plastic strain) as DG0 or Quadrature-point functions; use a quadrature degree consistent with the displacement space.
Implement the incremental radial-return (return-mapping) algorithm for von Mises perfect plasticity at each quadrature point or element.
At each load step, perform Newton iterations to solve the nonlinear residual; use a relative tolerance of 1e-8 or absolute tolerance of 1e-10 for convergence, with a maximum of 25 Newton iterations per step.
Apply the total vertical displacement of 1 mm at y = 180 mm incrementally over 20 equal load steps (delta_u_y = 0.05 mm per step).
Boundary condition on x = 0: fix u_x = 0 (symmetry, no normal displacement).
Boundary condition on y = 0: fix u_y = 0 (symmetry, no normal displacement).
Boundary condition on y = 180 mm: prescribe u_y = current load step value (Dirichlet), leave u_x free.
Boundary condition on x = 100 mm: traction-free (natural boundary condition, no Neumann term needed).
Boundary condition on the quarter-hole arc (x^2 + y^2 = 50^2, x>=0, y>=0): traction-free (natural boundary condition).
At each Newton iteration, assemble the consistent tangent stiffness matrix using the algorithmic (consistent) elastoplastic tangent modulus derived from the return-mapping algorithm.
Update the plastic strain and internal variables only upon convergence of each load step.
After each converged load step, print the load step number, the applied displacement, and the maximum von Mises stress in the domain.
After all load steps are complete, save the final displacement field u to an XDMF file named displacement.xdmf using dolfin XDMFFile.
Also save the final equivalent plastic strain field to an XDMF file named plastic_strain.xdmf.
Use dolfin.MPI.comm_world for all file output to support parallel runs.
Include comments in the code explaining each major section: mesh generation, function spaces, boundary conditions, return-mapping, Newton loop, and output.
