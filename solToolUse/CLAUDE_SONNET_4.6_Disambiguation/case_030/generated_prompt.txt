Use FEniCS legacy (dolfin) for the entire implementation.

Define the L-shaped domain as the set difference of a 1x1 square minus a 0.5x0.5 square in the upper-right corner, specifically the region where NOT (x >= 0.5 AND y >= 0.5).

Generate the mesh using mshr with resolution 64 (mshr.generate_mesh).

Use material parameters E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3, g = 9.81 m/s^2.

Formulate the problem as 2D plane stress with unit thickness.

Use the plane-stress reduced constitutive law: sigma = (E / (1 - nu**2)) * ((1 - nu) * eps + nu * tr(eps) * I) for normal components, and (E / (2 * (1 + nu))) * 2 * eps_12 for shear, implemented via the standard plane-stress elasticity tensor.

Express the plane-stress constitutive relation using lambda_eff = (E * nu) / (1 - nu**2) and mu = E / (2 * (1 + nu)), so sigma(u) = lambda_eff * tr(eps(u)) * I + 2 * mu * eps(u), where eps(u) = sym(grad(u)).

Define a vector-valued function space using VectorFunctionSpace with CG (Lagrange) elements of degree 1 on the mesh.

Apply a Dirichlet (clamped) boundary condition fixing all displacement components to zero on the left edge where x <= DOLFIN_EPS (x = 0).

Apply a Dirichlet (clamped) boundary condition fixing all displacement components to zero on the bottom edge where y <= DOLFIN_EPS (y = 0).

Define the right edge as the boundary where x >= 1.0 - DOLFIN_EPS, restricted to the L-shaped domain (i.e., y <= 0.5).

Apply a Neumann traction on the right edge with traction vector t = (2.65e4, 0) Pa (horizontal normal traction sigma_xx = 2.65e4 Pa, zero shear).

Include a body force due to gravity: f = (0, -rho * g) N/m^3 as a Constant vector.

Write the weak form as: a(u, v) = integral over domain of inner(sigma(u), eps(v)) dx, L(v) = integral over domain of dot(f, v) dx + integral over right Neumann boundary of dot(t, v) ds.

Use a ds measure marked for the right Neumann boundary using a MeshFunction and the corresponding subdomain.

Solve the linear system using a direct solver: solve(a == L, u, bcs, solver_parameters={"linear_solver": "mumps"}) or equivalent direct solver available in dolfin.

After solving, compute the full stress tensor field by projecting sigma(u) onto a tensor function space (TensorFunctionSpace, CG degree 1 or DG degree 0).

Compute von Mises stress as: von_mises = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where s11, s22, s12 are the in-plane Cauchy stress components, using the deviatoric definition for plane stress.

Project the von Mises scalar field onto a scalar FunctionSpace (CG degree 1 or DG degree 0).

Save the displacement field u to a file named displacement.pvd using dolfin File.

Save the von Mises stress field to a file named von_mises.pvd using dolfin File.

Print the maximum displacement magnitude: compute it as u.vector().norm("linf") or by evaluating the projected magnitude field, and print to console.

Print the maximum von Mises stress value from the projected field vector to console.

Use matplotlib to produce and save two plots: one showing the von Mises stress distribution over the mesh and one showing the displacement magnitude, both saved as PNG files named von_mises.png and displacement_magnitude.png respectively, using dolfin's plot function with colorbar.
