Use FEniCS legacy (dolfin) for the entire implementation.
Solve a quasi-incompressible finite-strain hyperelastic problem using a mixed displacement-pressure neo-Hookean formulation with Newton's method.
The problem is plane strain.

Geometry:
Define the domain Omega as a rectangle (0, 1.0) x (0, 0.20) metres.
Cut out two circular holes of radius a = 0.04 m centred at (0.40, 0.10) m and (0.60, 0.10) m.
Mesh the resulting geometry using mshr (or equivalent dolfin-compatible mesher) with sufficient resolution to resolve the hole boundaries accurately.

Material:
Use an isotropic neo-Hookean solid.
Young's modulus E = 5.0 MPa, Poisson's ratio nu = 0.49.
Compute Lame parameters: mu = E / (2*(1+nu)), lam = E*nu / ((1+nu)*(1-2*nu)).
Use the quasi-incompressible neo-Hookean strain energy density: Psi = (mu/2)*(I1_bar - 3) + (lam/2)*(J-1)^2, where I1_bar = J^(-2/3)*tr(C) and J = det(F), with F = I + grad(u).
The hydrostatic pressure unknown p is introduced via a mixed formulation; use the relation p = lam*(J-1) or treat p as an independent Lagrange multiplier enforcing near-incompressibility, consistent with the standard u-p mixed formulation for quasi-incompressible hyperelasticity.

Finite element formulation:
Use a mixed function space: Taylor-Hood elements (P2 for displacement u, P1 for pressure p) or mini elements, ensuring LBB stability.
Assemble the weak form by taking the Gateaux derivative of the total potential energy with respect to (u, p) and their test functions.
Include the follower pressure contribution as a Neumann term on the hole boundaries: the traction is t = -P_hole * n_current, where n_current is the outward normal in the current (deformed) configuration, giving a follower load. Implement this using Nanson's formula: t_ref * dA_ref = -P_hole * J * F^{-T} * N * dA_ref, where N is the reference outward normal on the hole boundary.
P_hole = 0.10 MPa applied as inward (compressive) follower pressure, meaning the pressure acts to compress the hole inward (the traction points inward toward the hole centre).

Boundary conditions:
Left edge (x = 0): fix u_x = 0 and u_y = 0 (fully clamped).
Right edge (x = 1.0): prescribe u_x = 0.060 m and u_y = 0.
Top edge (y = 0.20) and bottom edge (y = 0): traction-free (natural boundary condition, no action needed).
Hole boundaries: apply follower pressure P_hole = 0.10 MPa as described above.

Loading strategy:
Apply the prescribed right-edge displacement and hole pressure incrementally using a load-stepping scheme with at least 10 equal steps to aid Newton convergence.
At each load step, solve the nonlinear system with Newton's method using dolfin's NonlinearVariationalSolver or manual Newton loop.
Use relative and absolute tolerances of 1e-8 and 1e-10 respectively for Newton convergence, with a maximum of 25 iterations per step.

Post-processing:
After the final converged solution, compute the Cauchy stress tensor: sigma = (1/J) * F * S * F^T, where S = 2 * dPsi/dC is the second Piola-Kirchhoff stress.
Compute the von Mises stress from the Cauchy stress: vm = sqrt(0.5*((s11-s22)^2 + (s22-s33)^2 + (s33-s11)^2 + 6*(s12^2))), where s33 = 0 for plane strain in the out-of-plane Cauchy stress sense (use the full 3D expression with the plane-strain assumption that the out-of-plane Cauchy stress component is lam*(J-1) or computed consistently).
Project p and von Mises stress onto a suitable scalar function space (e.g., DG0 or P1) for visualisation.
Save a colour map of the hydrostatic pressure p as q14_p.png using matplotlib with a suitable colormap (e.g., coolwarm).
Save a colour map of the von Mises stress as q14_vm.png using matplotlib.
Save the displacement field u in XDMF format as q14_displacement.xdmf using dolfin's XDMFFile.

Output files:
