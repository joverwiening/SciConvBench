Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem using the dolfin finite element library.
Material properties: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
Geometry: a 1.0 m x 0.5 m rectangular plate with a central circular hole of radius 0.1 m centered at (0.5, 0.25).
Generate the mesh using mshr (or equivalent dolfin-compatible mesher): subtract the circle from the rectangle and generate a mesh with approximately 72 elements resolution parameter.
Use a vector-valued continuous Lagrange finite element space (degree 2 recommended, or degree 1) for the displacement field over the 2D domain.
Apply the plane-stress constitutive law with unit thickness (t = 1 m).
Define the plane-stress stiffness using the reduced constitutive relations: lambda_ps = E*nu/(1-nu^2), mu = E/(2*(1+nu)).
The stress tensor sigma(u) = lambda_ps * tr(eps(u)) * I + 2*mu*eps(u), where eps(u) = 0.5*(grad(u) + grad(u).T).
Body force: f = (0, -rho*g) applied as a volume load over the entire domain.
Point load: a downward concentrated force of magnitude 5000 N applied at coordinates (1.0, 0.25) in the negative y-direction.
Implement the point load using a PointSource object applied to the assembled right-hand side vector at the degree-of-freedom corresponding to the y-component at (1.0, 0.25).
Boundary condition: fix all displacement components (u = (0, 0)) on the left edge where x = 0, using a Dirichlet boundary condition.
The left edge is identified by the subdomain condition x[0] < DOLFIN_EPS.
No boundary conditions are applied on the hole boundary, the right edge, the top edge, or the bottom edge (all traction-free).
Assemble the bilinear form a(u,v) = integral of sigma(u):eps(v) dx and the linear form L(v) = integral of f·v dx.
Solve the resulting linear system using a direct linear solver (e.g., LUSolver or the default direct solver via solve()).
After solving, compute the Cauchy stress tensor field projected onto a tensor function space.
Compute the von Mises stress as: sigma_vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2) using the in-plane stress components only (plane-stress assumption, sigma_zz = 0).
Project the von Mises stress onto a scalar function space for visualization and output.
Save the displacement field and von Mises stress field to VTK or XDMF files for post-processing.
Print the maximum displacement magnitude and maximum von Mises stress value to the console.
