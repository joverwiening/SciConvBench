Use FEniCS legacy (dolfin) for the entire implementation.

Define the geometry as a 2D right triangle with vertices at (0,0), (1,0), and (0,0.5).

Generate the mesh using mshr with a triangle polygon and resolution of 64.

Use a vector-valued continuous Lagrange finite element space of degree 2 (P2) for the displacement field over this mesh.

Apply plane-stress assumption with unit thickness throughout.

Use material parameters E=70e9 Pa, nu=0.33, rho=2700 kg/m^3, g=9.81 m/s^2.

Compute the plane-stress constitutive matrix using the reduced plane-stress relations: C_1111 = C_2222 = E/(1-nu^2), C_1122 = nu*E/(1-nu^2), C_1212 = E/(2*(1+nu)).

Define the strain tensor as the symmetric gradient of displacement: epsilon(u) = sym(grad(u)).

Define the stress tensor sigma(u) using the plane-stress constitutive law: sigma = lambda_ps * tr(epsilon) * I + 2 * mu_ps * epsilon, where lambda_ps = E*nu/(1-nu^2) and mu_ps = E/(2*(1+nu)).

Define the body force vector f = (0, -rho*g).

Identify the Dirichlet boundary as the sloping edge where x + 2*y = 1 (within a tolerance of 1e-10).

Apply a homogeneous Dirichlet boundary condition (zero displacement) on the sloping edge x + 2*y = 1 for both displacement components.

Identify the loaded boundary as the left edge where x = 0 (within a tolerance of 1e-10), excluding the corner point shared with the sloping edge.

Apply a Neumann traction of sigma_xx = 4000 Pa on the boundary x = 0 as a surface traction vector t = (-4000, 0) (inward normal on x=0 points in the -x direction, so the traction applied to the face is t = (4000, 0) in the outward-normal convention; use t = as_vector([4000, 0]) dotted with the test function integrated over ds on x=0).

Define the variational problem: a(u,v) = integral over domain of inner(sigma(u), epsilon(v)) dx; L(v) = integral over domain of dot(f, v) dx + integral over x=0 boundary of dot(t, v) ds.

Mark the boundary x=0 using a MeshFunction and a SubDomain, then integrate the Neumann term over that marked boundary using the corresponding ds measure.

Solve the linear system using a direct solver (LU factorization) via the dolfin solve function with solver_parameters set to linear_solver "mumps" or "lu".

After solving, compute the Cauchy stress tensor field by projecting sigma(u) onto a tensor-valued DG0 or DG1 function space.

Compute the von Mises stress as: sigma_vm = sqrt(sigma_xx^2 + sigma_yy^2 - sigma_xx*sigma_yy + 3*sigma_xy^2), using the in-plane stress components only (plane-stress, sigma_zz=0).

Project the von Mises stress expression onto a scalar function space (DG0 or CG1).

Output the maximum displacement magnitude, the maximum von Mises stress value, and the coordinates where each maximum occurs.

Save the displacement field to a file named displacement.pvd and the von Mises stress field to a file named von_mises.pvd for visualization in ParaView.

Print the L2 norm of the displacement field and the L2 norm of the von Mises stress field to the console.
