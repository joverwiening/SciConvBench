Create a file named `case_053.inp` in the working directory with the following content.

The file begins with comment lines describing the structure as a cantilever plate and the test objective as C3D8I elements (static).

Define all nodes under `*NODE, NSET=nall` exactly as listed in the input deck, from node 1 through node 188 with their respective coordinates.

Define all elements under `*ELEMENT, TYPE=C3D8I, ELSET=elall` exactly as listed in the input deck, elements 1 through 15, each with their node connectivity including the incompatible mode nodes.

Add `*SOLID SECTION, ELSET=elall, MATERIAL=steel` with no thickness value (solid 3D section).

Define node set LEFT containing nodes 1, 2, 5, 6 using `*NSET, NSET=left`.

Define node set RIGHT containing nodes 180, 183, 185, 188 using `*NSET, NSET=right`.

Define the material block with `*MATERIAL, NAME=steel`.

Under the material, add `*DENSITY` with value `7.85e-09`.

Under the material, add `*ELASTIC` with values `209000.0, 0.3` on the data line.

Begin the analysis step with `*STEP, NLGEOM, INC=10000`.

On the next line after `*STEP`, add `*STATIC`.

On the line after `*STATIC`, add the time increment parameters `0.1, 1.0, 1.0e-08`.

Add boundary conditions with `*BOUNDARY` followed by `left, 1, 3` to fix nodes in set LEFT in all three translational degrees of freedom.

Add distributed load with `*DLOAD` followed by `elall, P2, 0.001` to apply uniform pressure on face 2 of all elements in set elall with magnitude 0.001.

Close the step with `*END STEP`.

Run CalculiX using the command `ccx -i case_053`.

Check the file `case_053.sta` for the string `JOB COMPLETED` to determine if the run succeeded.

Obtain the CalculiX version by running `ccx -v` and recording the version string.

Write a `results.json` file with fields: `solver` set to `"calculix"`, `case_id` set to `"case_053"`, `status` set to `"success"` if `JOB COMPLETED` is found in `case_053.sta` or `"error"` otherwise, `ccx_version` set to the version string from `ccx -v`, `artifacts` set to a list of output files produced (e.g., `.dat`, `.frd`, `.sta`), and `notes` recording the exact ccx command used and, if the run failed, the error message and the file that indicated the failure.
