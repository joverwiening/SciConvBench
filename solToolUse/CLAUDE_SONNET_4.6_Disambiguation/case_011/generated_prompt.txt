Use FEniCS legacy (dolfin) for the entire implementation.

Solve a 2D plane-stress linear elasticity problem on a functionally graded rectangular plate.

Define the domain Ω as the rectangle (0, 1.0) x (0, 0.20) in metres.

Create a structured rectangular mesh of 100 x 20 quadrilateral-equivalent cells over Ω using RectangleMesh with nx=100, ny=20.

Use a vector function space of degree 2 (P2) Lagrange elements for the displacement field u = (u_x, u_y).

Define Young's modulus as a spatially varying expression: E(y) = 100e9 + 100e9 * (y / 0.20), where y is the spatial coordinate. This gives E = 100 GPa at y=0 and E = 200 GPa at y=0.20.

Set Poisson's ratio ν = 0.30 as a constant.

Use the plane-stress reduced constitutive law. The plane-stress stiffness relates stress to strain as: σ_xx = E/(1-ν²) * (ε_xx + ν*ε_yy), σ_yy = E/(1-ν²) * (ε_yy + ν*ε_xx), σ_xy = E/(1-ν²) * (1-ν)/2 * 2*ε_xy. Implement this as the stress tensor sigma(u) using the symmetric gradient (strain) of u.

Assume unit thickness (t = 1.0 m) for the plane-stress formulation.

Apply Dirichlet boundary conditions on the left edge (x = 0): fix both components u_x = 0 and u_y = 0.

Apply a Neumann traction on the right edge (x = 1.0): traction vector t = (2e6, 0) N/m (force per unit area times unit thickness), implemented as a surface integral term in the weak form.

Leave the top and bottom edges traction-free (no additional boundary terms needed).

Formulate the standard weak form: integrate sigma(u):epsilon(v) dx over Ω equals integrate t·v ds over the right boundary.

Assemble the linear system and solve using a direct linear solver (e.g., LU via dolfin's default direct solver or by specifying solver type "lu").

After solving, compute the displacement magnitude field |u| = sqrt(u_x² + u_y²) as a scalar function projected onto a scalar function space.

Save a colour map of |u| as q9_disp.png using matplotlib, showing the full plate geometry with a colorbar labelled "Displacement magnitude (m)".

Save the displacement field u to an XDMF file named q9_displacement.xdmf using dolfin's XDMFFile, with encoding set to HDF5.
