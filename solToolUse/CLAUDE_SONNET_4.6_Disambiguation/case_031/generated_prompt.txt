Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a parallelogram-shaped domain.
The parallelogram has vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3) defined in order.
Create the mesh by defining the parallelogram as a polygon and meshing it with approximately 72 elements using mshr (dolfin's mshr module) with generate_mesh.
Use material properties E=70e9 Pa, nu=0.33, rho=2700 kg/m^3, g=9.81 m/s^2.
Implement the plane-stress reduced constitutive law: lambda_ps = E*nu/(1-nu**2), mu = E/(2*(1+nu)).
Define the stress tensor as sigma(u) = lambda_ps*tr(eps)*I + 2*mu*eps where eps = sym(grad(u)).
Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace, 'CG', 2) for displacement.
Apply a Dirichlet boundary condition of zero displacement (clamped) on the left inclined edge connecting (0,0) to (0.2,0.3).
Identify the clamped boundary using the line equation y = 1.5*x with a small tolerance (e.g., abs(y - 1.5*x) < 1e-10).
Apply body force f = (0, -rho*g) as a Constant vector over the entire domain.
Apply a horizontal point load of -5000 N (i.e., -5 kN in the x-direction) at the point (1.1, 0.15) using a PointSource on the first component of the test function.
Formulate the bilinear form a(u,v) = inner(sigma(u), sym(grad(v)))*dx.
Formulate the linear form L(v) = dot(f, v)*dx, then add the point load contribution via PointSource.
Solve the resulting linear system using a direct solver (LUSolver or the default direct solver via solve).
After solving, compute the von Mises stress from the in-plane Cauchy stress components.
Compute von Mises as: sigma_vm = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where s11, s22, s12 are the in-plane stress components projected onto a scalar DG or CG function space.
Project the stress components and von Mises stress onto a scalar FunctionSpace('DG', 0) or ('CG', 1) for visualization.
Plot the displacement magnitude field using dolfin's plot function or matplotlib.
Plot the von Mises stress distribution using dolfin's plot function or matplotlib.
Print the maximum displacement magnitude and maximum von Mises stress value to the console.
Use unit thickness (thickness = 1.0) implicitly, as the 2D formulation already assumes unit out-of-plane thickness.
