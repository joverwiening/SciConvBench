Create the file `case_051.inp` in the working directory with the following exact content.

The file begins with two comment lines: `**` and `** Structure: shell roof.` and `** Test objective: *NORMAL`.

Add a `*NODE, NSET=Nall` section with 13 nodes at the coordinates given in the input deck.

Add a `*ELEMENT, TYPE=S8R, ELSET=Eall` section defining elements 1 and 2 with the connectivity given in the input deck.

Add a `*NSET,NSET=FIX` section listing nodes 2,3,6,9,10,13.

Add a `*MATERIAL,NAME=EL` block immediately followed by `*ELASTIC` on the next line and `21000.,.3` on the line after that.

Add a `*SHELL SECTION,ELSET=Eall,MATERIAL=EL` block with thickness `0.05` on the next line.

Add a `*NORMAL` block with the six lines as given in the input deck.

Add a `*BOUNDARY` block (before `*STEP`) applying all 6 DOFs (1 through 6, value 0) to the FIX set, written as `FIX,1,6`.

Add `*STEP,NLGEOM` to begin the step.

Add `*STATIC` on the next line inside the step.

Add `*CLOAD` followed by `8,2,-0.1` to apply a concentrated load of -0.1 in DOF 2 at node 8.

Add `*NODE PRINT,NSET=Nall` followed by `U` to request nodal displacement output.

Add `*EL PRINT,ELSET=Eall,GLOBAL=YES` followed by `S` to request element stress output.

Add `*END STEP` to close the step.

Run CalculiX with the command `ccx -i case_051`.

Check `case_051.sta` for the string `JOB COMPLETED` to confirm success.

Record the version string from `ccx -v` in the `ccx_version` field of `results.json`.

Write `results.json` with fields: `solver` set to `"calculix"`, `case_id` set to `"case_051"`, `status` set to `"success"` if `JOB COMPLETED` is found in `case_051.sta` or `"error"` otherwise, `ccx_version` set to the version string, `artifacts` set to an empty list, and `notes` set to the exact ccx command used plus any error message and failure file name if the run failed.
