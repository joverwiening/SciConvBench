Create a file named case_107.inp in the working directory with the following content.

The file begins with comment lines and a heading block.
Use *HEADING with the line: Model: beam     Date: 10-Mar-1998

Define all 261 nodes using the *NODE keyword with the coordinates exactly as given in the input deck section.

Define 32 elements of type C3D20R assigned to element set B1 using the *ELEMENT keyword with connectivity exactly as given in the input deck section.

Define node set CN7 containing nodes: 97, 96, 95, 94, 93, 20, 19, 18, 17, 16, 15, 14, 13, 12, 11, 10, 9, 4, 3, 2, 1.

Define element set EALL using *ELSET,ELSET=EALL,GENERATE spanning elements 1 to 32.

Define node set NALL using *NSET,NSET=NALL,GENERATE spanning nodes 1 to 261.

Define the material using *MATERIAL,NAME=LIN_ISO_EL followed by *ELASTIC with values 210000 and 0.3 on the data line.

Assign the material to all elements using *SOLID SECTION,ELSET=EALL,MATERIAL=LIN_ISO_EL.

Define the MPC constraint using *MPC with the line: STRAIGHT,28,163,175.

Define boundary conditions outside the step block.
Use *BOUNDARY to fix all nodes in set CN7 in DOF 3 to 3 (line: CN7,3,3).
Use *BOUNDARY to fix node 1 in DOFs 1 through 2 (line: 1,1,2).
Use *BOUNDARY to fix node 2 in DOF 2 to 2 (line: 2,2,2).

Open the analysis step using *STEP,INC=100,NLGEOM.

Specify the analysis type as *STATIC.

Apply a concentrated load using *CLOAD with the line: 22,2,200. (force of 200 in the y-direction at node 22).

Request nodal output using *NODE PRINT,NSET=NALL followed by U on the next line.

Request element output using *EL PRINT,ELSET=EALL followed by S on the next line.

Close the step with *END STEP.

Run CalculiX using the command: ccx -i case_107

Check the file case_107.sta for the string JOB COMPLETED to determine whether the run succeeded.

Record the CalculiX version by running ccx -v and capturing the version string.

Write a results.json file with the following fields.
Set "solver" to "calculix".
Set "case_id" to "case_107".
Set "status" to "success" if JOB COMPLETED is found in case_107.sta, otherwise set it to "error".
Set "ccx_version" to the version string obtained from ccx -v.
Set "artifacts" to an empty list.
Set "notes" to the exact ccx command used; if the run failed, append the error message and the name of the file that indicated the failure.
