Use FEniCS legacy (dolfin) and mshr for all mesh generation.

The domain is a rectangle (0, 1.0) x (0, 0.20) metres with a semicircular notch of radius a = 0.05 m removed from the top edge, with the notch centre at (0.5, 0.2).

Create the geometry using mshr by subtracting a Circle of radius 0.05 centred at (0.5, 0.2) from a Rectangle((0,0), (1.0, 0.2)).

Generate a mesh with mshr.generate_mesh at a resolution sufficient to resolve the curved notch boundary (use resolution = 64 or higher).

Solve 2D plane-stress linear elasticity for the vector-valued displacement field u = (u_x, u_y) on this domain.

Use Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.30.

Derive the plane-stress constitutive law: the stress tensor is sigma = (E / (1 - nu**2)) * ((1 - nu) * sym(grad(u)) + nu * tr(sym(grad(u))) * Identity(2)), which corresponds to the reduced plane-stress stiffness with unit thickness.

Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace with "CG", 2) for the displacement.

Apply Dirichlet boundary conditions on the bottom edge (y = 0): fix both components u_x = 0 and u_y = 0.

Identify the top edge excluding the notch opening as the region where y is near 0.2 AND the point is outside the semicircle (i.e., (x - 0.5)**2 + (y - 0.2)**2 >= a**2).

Apply a downward Neumann traction t = (0, -10e6) N/m (line traction per unit thickness, in Pa·m units consistent with unit thickness) on the top edge outside the notch opening using a ds measure marked for that boundary.

Mark boundaries using a MeshFunction of dimension (mesh.topology().dim() - 1) and use SubDomain classes to tag: bottom edge, top edge outside notch, left edge, right edge, and notch arc.

The left edge (x = 0), right edge (x = 1.0), and notch arc are traction-free (natural boundary conditions, no explicit Neumann term needed).

Assemble the bilinear form a(u, v) = inner(sigma(u), sym(grad(v))) * dx and the linear form L(v) = dot(Constant((0.0, -10e6)), v) * ds(top_loaded_tag).

Solve the resulting linear system using a direct solver (LUSolver or the default direct backend via solve(a == L, u, bcs)).

After solving, compute the von Mises stress field as a scalar field: vm = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2) projected onto a scalar FunctionSpace("CG", 1) or ("DG", 0).

Save the von Mises stress plot to q6_vm.png using matplotlib, with a colorbar and title, showing the full domain with the notch visible.

Save the displacement field u to a file named q6_displacement.xdmf in XDMF format using XDMFFile.
