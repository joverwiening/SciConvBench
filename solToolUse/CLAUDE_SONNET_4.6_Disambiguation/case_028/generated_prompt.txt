Use FEniCS legacy (dolfin) for all implementation.

Solve a 2D plane-stress linear elasticity problem on an L-shaped domain.

The L-shaped domain is defined as the unit square [0,1]x[0,1] minus the inner square [0.5,1]x[0.5,1], leaving an L-shaped region.

Use a structured mesh with 64 elements per edge, constructed via a mesh of the full unit square refined to 64 divisions per side, then marking and removing the upper-right quadrant cells to form the L-shape. Use a dolfin Mesh built with mshr or by using a RectangleMesh combined with cell removal, or use mshr to define the L-shape polygon directly with resolution 64.

Material properties: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

Apply plane-stress constitutive law with unit thickness.

The plane-stress Lame-like parameters are: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)).

Define the stress tensor as sigma(u) = lambda_ps * tr(eps(u)) * I + 2 * mu * eps(u), where eps(u) = 0.5 * (grad(u) + grad(u).T) and I is the 2x2 identity.

Use a vector-valued continuous Lagrange finite element space of degree 2 (P2) for displacement on the L-shaped mesh.

Boundary condition: fix all displacement components (u = [0, 0]) on the left boundary where x = 0 (Dirichlet BC).

Body force: f = [0, -rho * g] applied as a volume load throughout the domain.

Neumann boundary condition: apply shear traction t = [2.65e4, 0] Pa on the top edge segment where y = 1 and x >= 0.5 (from x=0.5 to x=1).

No traction is applied on any other boundary (free surfaces).

Formulate the weak form: integrate sigma(u):eps(v) dx = integrate f·v dx + integrate t·v ds(loaded_top), where ds(loaded_top) is the surface measure restricted to the loaded top-right segment.

Use a MeshFunction to mark boundary facets: mark the left boundary (x=0) for the Dirichlet BC, and mark the top-right segment (y=1 and x>=0.5) as a separate Neumann boundary tag.

Use a direct linear solver (e.g., LU via dolfin's default direct solver or PETSc LU) to solve the assembled linear system.

After solving, compute the full in-plane Cauchy stress tensor field by projecting sigma(u) onto a tensor function space (DG0 or P1 tensor space).

Compute von Mises stress as: von_mises = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2), where s11, s22, s12 are the in-plane stress components, projected onto a scalar function space.

Visualize the following using matplotlib: the displacement magnitude field, the x-displacement field, the y-displacement field, and the von Mises stress field.

Save each visualization as a separate PNG file with descriptive filenames (e.g., displacement_magnitude.png, von_mises_stress.png).

Also export the displacement field and von Mises stress to XDMF or VTK files for optional post-processing in ParaView.

Print to console the maximum displacement magnitude and the maximum von Mises stress value.
