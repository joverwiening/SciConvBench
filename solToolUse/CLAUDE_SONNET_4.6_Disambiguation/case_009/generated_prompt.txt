Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a perforated rectangular plate.
The plate dimensions are 1.0 m (x-direction) by 0.5 m (y-direction).
The circular hole has radius 0.1 m and is centered at (0.5, 0.25).
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
Generate the mesh using mshr: create a Rectangle domain minus a Circle domain, then call generate_mesh with resolution 64.
Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace, 'CG', 2) for the displacement field.
Apply the plane-stress reduced constitutive law throughout.
Define the plane-stress constitutive relation as follows: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)), and sigma(u) = lambda_ps * tr(eps(u)) * Identity(2) + 2 * mu * eps(u), where eps(u) = sym(grad(u)).
Apply a Dirichlet boundary condition fixing both displacement components to zero on the left edge where x = 0 (within a small tolerance).
Apply a Neumann boundary condition representing internal pressure of 1e5 Pa acting outward (in the direction of the outward normal) on the hole boundary.
Identify the hole boundary as all boundary facets where the distance from point (0.5, 0.25) is less than 0.1 + a small tolerance (1e-3).
Mark all boundary subdomains using a MeshFunction of dimension (mesh.topology().dim() - 1): mark the hole boundary as 1 and all other boundaries as 0.
Define the body force as a Constant vector (0, -rho * g) representing gravity.
Formulate the weak form: a(u, v) = integral of inner(sigma(u), eps(v)) dx; L(v) = integral of dot(f, v) dx + integral of dot(p * n, v) ds(1), where n is the outward facet normal, p = 1e5, and ds(1) integrates over the hole boundary marker 1.
Assemble and solve the linear system using a direct solver: call solve(a == L, u, bc) or equivalently use LUSolver.
After solving, project the von Mises stress onto a scalar DG0 or CG1 function space.
Compute the von Mises stress from the in-plane Cauchy stress tensor as: sigma_vm = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2), where sij are components of the deviatoric or full stress tensor; equivalently use von_mises = sqrt(3/2 * inner(dev(sigma(u)), dev(sigma(u)))), treating the out-of-plane stress component as zero (plane stress assumption).
Save the displacement field u to a file named displacement.pvd using File('displacement.pvd') << u.
Save the von Mises stress field to a file named von_mises.pvd using File('von_mises.pvd') << von_mises_projected.
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
Use a try/except or direct import of dolfin and mshr at the top of the script.
Do not use FEniCSx (dolfinx); use only legacy dolfin and mshr imports.
Write the entire implementation as a single self-contained Python script.
