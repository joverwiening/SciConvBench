Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress small-strain orthotropic elasticity problem for displacement u = (u_x, u_y).
The domain Ω is a rectangle (0, 1.0) x (0, 0.20) metres.
Create a structured rectangular mesh of 50 x 25 quadrilateral-equivalent triangular cells over Ω using RectangleMesh.
Use a vector function space with continuous Lagrange elements of degree 1 (P1) for the displacement field.
The local orthotropic material properties are E1 = 40e9 Pa, E2 = 10e9 Pa, G12 = 5e9 Pa, nu12 = 0.25.
Compute nu21 = nu12 * E2 / E1.
Compute the plane-stress reduced stiffness matrix [Q] in the local material frame as follows.
Set D = 1 - nu12 * nu21.
Q11 = E1 / D, Q22 = E2 / D, Q12 = nu12 * E2 / D, Q66 = G12, Q16 = Q26 = 0.
Rotate [Q] to the global x-y frame using the standard tensor rotation for a fibre angle of 30 degrees anticlockwise from the global x-axis.
Use the standard transformation matrix T based on m = cos(30°), n = sin(30°) and apply Qbar = T^{-1} Q T^{-T} (or equivalently the Reuter-matrix-based rotation) to obtain the 3x3 rotated stiffness matrix Qbar with components Qbar11, Qbar12, Qbar16, Qbar22, Qbar26, Qbar66.
Express the constitutive relation in Voigt notation: sigma = Qbar * epsilon, where epsilon = (eps_xx, eps_yy, 2*eps_xy) and sigma = (sig_xx, sig_yy, sig_xy).
Implement the bilinear form a(u, v) = integral over Ω of sigma(u) : epsilon(v) dx using the rotated Qbar matrix applied to the symmetric gradient of u.
Implement the linear form L(v) = integral over the top edge of t · v ds, where t = (0, -10e6) N/m (line traction per unit thickness in-plane).
Apply Dirichlet boundary conditions on the bottom edge (y = 0): u_x = 0 and u_y = 0 (fully fixed).
The top edge (y = 0.20), left edge (x = 0), and right edge (x = 1.0) are natural (Neumann) boundaries; the left and right edges are traction-free by default.
Mark the top edge boundary using a SubDomain or near() criterion and integrate the traction over it using a ds measure with the appropriate subdomain marker.
Solve the resulting linear system using a direct linear solver (e.g., LU via dolfin's default direct solver or by specifying "mumps" or "petsc").
After solving, compute the Cauchy stress tensor components (sig_xx, sig_yy, sig_xy) by projecting or interpolating sigma = Qbar * epsilon(u) onto a suitable function space (e.g., DG0 or projected P1 tensor space).
Compute the von Mises stress as sqrt(sig_xx^2 - sig_xx*sig_yy + sig_yy^2 + 3*sig_xy^2) in plane stress.

Save a colour map of the von Mises stress field as q8_vm.png using matplotlib with a suitable colorbar and axis labels.
Write the displacement field u and the stress field to q8_solution.xdmf using dolfin's XDMFFile, with encoding XDMFFile.Encoding.HDF5 if available.
Label the output files exactly as q8_ux.png, q8_vm.png, and q8_solution.xdmf.
