Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem for a notched rectangular plate.

Geometry:
The full plate domain is the rectangle (0, 1.0) x (0, 0.20) m.
A rectangular notch is cut from the left edge, occupying the region (0, 0.06) x (0.08, 0.12) m.
The notch extends 0.06 m into the plate from the left edge and spans vertically from y = 0.08 to y = 0.12 m.
The computational domain Omega is the full rectangle minus the notch region.

Mesh:
Generate the geometry using mshr (dolfin's built-in meshing) by subtracting the notch rectangle from the plate rectangle.
Use a mesh resolution sufficient to capture stress concentration near the notch (recommend resolution of at least 64 or higher).

Material:
Young's modulus E = 200e9 Pa.
Poisson's ratio nu = 0.30.
Use the plane-stress reduced constitutive law.
Compute the plane-stress Lame-like parameters as: lambda_ps = E*nu/(1 - nu**2), mu = E/(2*(1 + nu)).
The plane-stress stress tensor is sigma(u) = lambda_ps * tr(eps(u)) * I + 2 * mu * eps(u), where eps(u) = sym(grad(u)).

Finite Element Formulation:
Use a vector-valued continuous Lagrange function space of degree 2 (P2) for displacement u = (u_x, u_y).
Formulate the standard linear elasticity variational problem: integral of sigma(u):eps(v) dx = integral of t.v ds over the right edge.

Boundary Conditions:
Left outer boundary at x = 0 (excluding the notch opening): apply homogeneous Dirichlet BC, u_x = 0 and u_y = 0.
The left outer boundary for Dirichlet application is the segment x = 0, y in [0, 0.08] union [0.12, 0.20].
Right edge at x = 1.0: apply Neumann traction t = (2e6 Pa, 0) as a line traction per unit thickness.
Top edge (y = 0.20), bottom edge (y = 0.0), and all notch boundary faces: traction-free (natural boundary condition, no action needed).

Solver:
Use a direct linear solver (e.g., LU) to solve the assembled linear system.

Outputs:
Compute the von Mises stress field under plane-stress assumption.
The plane-stress von Mises stress is: sigma_vm = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2), where sij are components of the Cauchy stress tensor.
Project the von Mises stress onto a scalar DG0 or CG1 function space for visualization.
Save a plot of the von Mises stress field to a file named q5_vm.png using matplotlib/dolfin plot utilities with a colorbar and title.
Save the displacement field u to an XDMF file named q5_displacement.xdmf using dolfin's XDMFFile.

Implementation Notes:
Use unit thickness (thickness = 1.0 m) implicitly; the traction magnitude 2e6 Pa directly gives force per unit area on the right edge face.
Interpret the applied traction as a Neumann boundary term: integral over the right edge of t.v ds, with t = Constant((2e6, 0)).
Mark boundaries using a MeshFunction and SubDomain classes to identify the right edge for the Neumann term and the left outer boundary for the Dirichlet BC.
Ensure the notch boundary faces are left unmarked (traction-free).
