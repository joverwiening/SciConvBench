Use FEniCS legacy (dolfin).
Solver: nonlinear finite-strain elasticity in legacy FEniCS (dolfin); solve the Saint-Venant-Kirchhoff problem with Newton's method.
Task:
Define and solve the static twisting of a hyperelastic cube using a St. Venant-Kirchhoff material model with spatially varying Lamé parameters
Case details:
The cube has St. Venant-Kirchhoff material with:
μ (shear modulus) = 3.8461 N/m^2
λ (Lamé parameter) varies as λ = 5.8x1 + 5.7(1 - x1)
Boundary Conditions:
x1 = 0 is fixed.
x1 = 1 is rotated by 60 degrees
Implementation notes:
Use a UnitCube mesh with 8x8x8 cells and solve a finite-strain Saint-Venant-Kirchhoff problem.
Evaluate the spatially varying Lamé field lambda(x1) = 5.8*x1 + 5.7*(1 - x1) in the reference coordinate x1.
Impose a 60-degree twist on the face x1 = 1 about the cube centreline and clamp x1 = 0.
