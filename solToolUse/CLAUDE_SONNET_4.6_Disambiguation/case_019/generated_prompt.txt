Use FEniCS legacy (dolfin) for the entire implementation.
Create a UnitCubeMesh with 8x8x8 cells.
Define a vector function space using Lagrange elements of degree 1 (linear) for the displacement field u.
Define the spatially varying first Lamé parameter as a dolfin Expression: lmbda = 5.8*x[0] + 5.7*(1 - x[0]), which simplifies to lmbda = 5.7 + 0.1*x[0].
Define the shear modulus mu as a constant: mu = 3.8461.
Use the Saint-Venant-Kirchhoff (SVK) hyperelastic material model.
Define the deformation gradient F = I + grad(u), where I is the second-order identity tensor.
Define the right Cauchy-Green tensor C = F^T * F.
Define the Green-Lagrange strain tensor E = 0.5*(C - I).
Define the strain energy density as psi = (lmbda/2)*(tr(E))^2 + mu*tr(E*E).
Define the total potential energy functional Pi = psi*dx (no body forces, no traction).
Derive the residual (weak form) F_form = derivative(Pi, u, v) where v is a TestFunction.
Derive the Jacobian J_form = derivative(F_form, u, du) where du is a TrialFunction.
Apply a Dirichlet boundary condition on the face x[0] = 0 (with tolerance 1e-14) fixing all displacement components to zero: u = (0, 0, 0).
Apply a Dirichlet boundary condition on the face x[0] = 1 (with tolerance 1e-14) prescribing a 60-degree rotation about the x1-axis centered at the centroid (1, 0.5, 0.5).
Compute the rotated position of each point (1, y, z) on the face x[0]=1 as: y_new = 0.5 + (y-0.5)*cos(60°) - (z-0.5)*sin(60°), z_new = 0.5 + (y-0.5)*sin(60°) + (z-0.5)*cos(60°).
Express the prescribed displacement on x[0]=1 as: u2 = y_new - y, u3 = z_new - z, u1 = 0, implemented as a dolfin Expression using cos(pi/3) and sin(pi/3).
Apply both Dirichlet boundary conditions to the function space and collect them in a list.
Solve the nonlinear variational problem using Newton's method via dolfin's NonlinearVariationalProblem and NonlinearVariationalSolver.
Set the Newton solver parameters: relative tolerance = 1e-6, absolute tolerance = 1e-10, maximum iterations = 50.
Print the number of Newton iterations and the final residual norm upon convergence.
Save the displacement field u to a file named "twist_displacement.pvd" for post-processing in ParaView.
Compute and print the maximum displacement magnitude over all degrees of freedom as a verification output.
