Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem using the dolfin finite element library.
The domain is a 1.0 m (width) by 0.5 m (height) rectangle.
A circular hole of radius 0.1 m is centered at (0.5, 0.25) m.
Generate the mesh using mshr with approximately 72 elements; use mshr.Rectangle and mshr.Circle to define the perforated domain.
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s².
Use the plane-stress reduced constitutive law with unit thickness.
The plane-stress constitutive tensor relates in-plane strains to in-plane stresses using the standard plane-stress reduction: σ = (E / (1 - ν²)) * [(1-ν)*ε + ν*tr(ε)*I] adjusted for plane stress.
Define a vector-valued displacement function space using Lagrange elements of degree 2 (P2) on the mesh.
Apply Dirichlet boundary conditions: fix all displacement components (u = [0, 0]) on the left edge (x = 0) and on the bottom edge (y = 0).
Apply a Neumann traction of +1000 Pa in the x-direction on the top edge (y = 0.5 m).
Apply a Neumann traction of -1000 Pa in the x-direction on the bottom edge (y = 0.0 m), only on the portion not already constrained by the Dirichlet condition, or handle consistently with the boundary marking.
Apply body force due to gravity as f = [0, -ρ*g] N/m³ throughout the domain.
Formulate the weak form: integrate the inner product of the stress tensor and the test function strain tensor over the domain, plus the body force term, plus the Neumann traction boundary integrals over the top and bottom edges.
Use a MeshFunction to mark boundaries: left edge (x ≈ 0), bottom edge (y ≈ 0), top edge (y ≈ 0.5), and use ds measures accordingly.
Solve the resulting linear system using a direct linear solver (e.g., LU via dolfin's default direct solver or PETSc LU).
After solving, compute the in-plane Cauchy stress tensor field from the displacement solution using the plane-stress constitutive law.
Compute the von Mises stress as: σ_vm = sqrt(σ_xx² - σ_xx*σ_yy + σ_yy² + 3*σ_xy²) using the in-plane stress components.
Project the von Mises stress onto a scalar function space (DG0 or CG1) for visualization.
Output or save the displacement field and von Mises stress field (e.g., to XDMF or VTK files, or plot using dolfin's built-in plot function).
Print the maximum displacement magnitude and maximum von Mises stress value to the console.
