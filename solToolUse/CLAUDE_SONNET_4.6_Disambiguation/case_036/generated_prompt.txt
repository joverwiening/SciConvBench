Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a parallelogram-shaped domain.
Define the parallelogram with vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3) using a dolfin Mesh built from these four corner points.
Triangulate the parallelogram into 72 triangular elements using a structured or manual mesh approach compatible with dolfin.
Use material parameters E=70e9 Pa, nu=0.33, rho=2700 kg/m^3, g=9.81 m/s^2.
Derive the plane-stress constitutive parameters: lambda_ps = E*nu/(1-nu**2), mu = E/(2*(1+nu)).
Define the plane-stress stress tensor as sigma(u) = lambda_ps*tr(eps)*I + 2*mu*eps where eps = sym(grad(u)).
Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace, 'CG', 2) for the displacement field u.
Define the bilinear form a(u,v) = integral of inner(sigma(u), sym(grad(v))) dx over the domain.
Apply body force f = (0, -rho*g) as a Constant vector in the linear form L(v) = dot(f, v)*dx.
Identify the right slope boundary as the edge connecting vertices (1,0) and (1.2,0.3).
Apply a homogeneous Dirichlet boundary condition (zero displacement) on the right slope boundary.
Identify the left slope boundary as the edge connecting vertices (0,0) and (0.2,0.3).
Apply a Neumann traction on the left slope boundary corresponding to sigma_xx = 6000 Pa acting in the x-direction.
Compute the outward unit normal on the left slope boundary analytically from the edge direction vector (0.2,0.3); the edge direction is (0.2,0.3), so the outward normal pointing left is (-0.3, 0.2)/norm or equivalently normalize(-0.3, 0.2).
Express the Neumann traction vector as T = sigma_xx * n_x * e_x where the traction in the variational form is dot(T_vec, v)*ds on the left slope boundary, with T_vec = (6000 * n_x_component_of_stress_application).
Implement the Neumann condition as the surface integral of dot(as_vector([6000*nx, 0]), v)*ds(left_slope) added to L, where nx is the x-component of the outward normal on the left slope.
Use a MeshFunction to mark the left slope boundary and right slope boundary with integer tags for use with ds(tag).
Identify boundary facets using a tolerance-based geometric test: a facet belongs to the left slope if both its vertices lie on the line from (0,0) to (0.2,0.3), and to the right slope if both vertices lie on the line from (1,0) to (1.2,0.3).
Use a direct linear solver (LUSolver or the default direct backend) to solve the assembled linear system.
After solving, compute the Cauchy stress tensor field by projecting sigma(u) onto a tensor function space (TensorFunctionSpace, 'DG', 0 or 'CG', 1).
Compute von Mises stress as vm = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where sij are the projected in-plane stress components, assuming plane stress so s33=0.
Project the von Mises expression onto a scalar FunctionSpace ('CG', 1 or 'DG', 0) for visualization and output.
Save the displacement field u to a file named displacement.pvd using dolfin File.
Save the von Mises stress field to a file named von_mises.pvd using dolfin File.
Print the maximum displacement magnitude and maximum von Mises stress value to the console.
Do not use FEniCSx, dolfinx, or any non-legacy FEniCS component anywhere in the code.
