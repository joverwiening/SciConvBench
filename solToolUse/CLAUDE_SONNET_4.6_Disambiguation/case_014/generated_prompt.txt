Use FEniCS legacy (dolfin) for the entire implementation.
Solve the Saint-Venant-Kirchhoff nonlinear hyperelasticity problem on a 3D unit cube.
Use a UnitCubeMesh with 8 divisions in each direction (8x8x8 cells).
Define the deformation gradient as F = I + grad(u), where u is the displacement field.
Define the Green-Lagrange strain tensor as E = 0.5 * (F.T * F - I).
Define the Saint-Venant-Kirchhoff strain energy density as Psi = 0.5*lmbda*(tr(E))**2 + mu*tr(E*E).
Derive the first Piola-Kirchhoff stress as the derivative of Psi with respect to F using UFL automatic differentiation (diff or derivative).
Use Lamé parameters lambda = 115.38 and mu = 76.92, corresponding to Young's modulus E = 200 and Poisson's ratio nu = 0.3 (standard structural steel-like values in consistent units).
Define the manufactured exact solution as u_ex = (0.1*sin(pi*x[0]), 0.1*sin(pi*x[1]), 0.1*sin(pi*x[2])).
Compute the body force f0 analytically by substituting u_ex into the strong form residual -div(P) using UFL symbolic differentiation, so that u_ex is the exact solution.
Use a vector function space of continuous Lagrange elements of degree 1 (P1) on the mesh.
Apply Dirichlet boundary conditions enforcing u = u_ex on the entire boundary (all faces).
Formulate the weak form residual R = inner(P, grad(v))*dx - inner(f0, v)*dx, where v is the test function.
Solve the nonlinear problem using FEniCS built-in Newton solver via the solve() function applied to R == 0.
Use default Newton solver tolerances (relative tolerance 1e-10, absolute tolerance 1e-10) and a maximum of 25 iterations.
After solving, compute the L2 error norm between the numerical solution u and the exact solution u_ex using errornorm() or assemble(inner(u - u_ex, u - u_ex)*dx) and take the square root.
Print the L2 error norm to the console at the end of the run.
Verify that the L2 error is small (expected to be on the order of 1e-3 or smaller for an 8x8x8 mesh with P1 elements).
