Solve a 2D plane-stress linear elasticity problem for a rectangular plate with a centred circular hole.
The domain Ω is the rectangle (0, 1.0) x (0, 0.20) metres with a circular hole of radius a = 0.05 m centred at (0.50, 0.10) m removed.
Use Gmsh or mshr to construct the geometry: create the rectangle, subtract the circle, and mesh the resulting domain.
Use a mesh resolution fine enough to resolve stress concentrations near the hole boundary (characteristic element size of approximately 0.005 m near the hole and 0.02 m elsewhere).
Define the displacement field u = (u_x, u_y) using a vector-valued function space of degree 2 Lagrange elements (VectorFunctionSpace with dim=2).
Use the plane-stress reduced constitutive law with Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.30.
Compute the plane-stress Lamé-like parameters as: lambda_ps = E*nu/(1 - nu**2) and mu = E/(2*(1 + nu)).
Define the strain tensor as epsilon(u) = sym(grad(u)).
Define the plane-stress Cauchy stress tensor as sigma(u) = lambda_ps * tr(epsilon(u)) * Identity(2) + 2*mu*epsilon(u).
Define the bilinear form a(u, v) = inner(sigma(u), epsilon(v)) * dx integrated over the domain.
Apply a Dirichlet boundary condition on the left edge (x = 0): u_x = 0 and u_y = 0 (fully fixed).
Apply a Neumann traction t = (2e6, 0) N/m on the right edge (x = 1.0) as a surface integral term in the linear form L(v) = dot(t, v) * ds(right_edge).
All other external boundaries, including the hole boundary, are traction-free (no contribution to L).
Use a direct linear solver (e.g., LUSolver or solver parameter "lu") to solve the variational problem.
After solving, compute the von Mises stress field as a scalar field projected onto a scalar function space.
For plane stress, compute von Mises as: sigma_vm = sqrt(s11^2 + s22^2 - s11*s22 + 3*s12^2) where s11, s22, s12 are the components of the stress tensor evaluated from the solution.
Project the von Mises stress onto a DG0 or CG1 scalar function space.
Save a plot of the von Mises stress field to a file named q3_vm.png using matplotlib or FEniCS built-in plot, with a colourbar and title.
Save the displacement field u to an XDMF file (e.g., displacement.xdmf) using XDMFFile.
Identify the hole boundary as the circular boundary at distance approximately equal to a = 0.05 m from centre (0.50, 0.10).
Extract the von Mises stress values at all degrees of freedom or quadrature points on the hole boundary.
Compute sigma_max as the maximum von Mises stress on the hole boundary.
Compute the stress concentration factor Kt = sigma_max / 2e6.
Print sigma_max and Kt to the console.
Use unit thickness (thickness = 1.0 m) implicitly, consistent with the 2D plane-stress formulation.
Do not apply any body forces (f = 0).
