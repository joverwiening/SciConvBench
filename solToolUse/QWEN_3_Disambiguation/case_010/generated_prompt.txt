Solve a small-strain von Mises elastoplasticity problem using return mapping, symmetry conditions, and Newton iterations for the incremental solve.  
Consider the quarter plate domain [0, 100] mm × [0, 180] mm with a quarter hole of radius 50 mm centered at the origin.  
Model the material under plane-strain conditions with associative flow and perfect plasticity.  
Use displacement u = (u_x, u_y) as the primary unknown.  
Define the strain as epsilon = 0.5*(grad(u) + grad(u)^T).  
Set the Lamé parameters to lambda = 19.44 GPa and mu = 29.17 GPa.  
Set the yield stress to sigma_Y = 243 MPa.  
On the boundary x = 0, impose symmetry by setting u_x = 0 and enforcing zero tangential traction.  
On the boundary y = 0, impose symmetry by setting u_y = 0 and enforcing zero tangential traction.  
On the boundary y = 180 mm, prescribe a displacement u = (0, 1) mm.  
On the boundary x = 100 mm and on the hole boundary, apply traction-free conditions.  
Implement an incremental return-mapping algorithm consistent with plane-strain perfect plasticity.  
Use Newton iterations to solve each increment.
