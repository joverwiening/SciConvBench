Create the file case_116.inp in the working directory with the provided input deck.
Run the command ccx -v to determine the CalculiX version and capture the output.
Use the command ccx -i case_116 to run the simulation.
Check the file case_116.sta for the phrase JOB COMPLETED to determine success.
If the run succeeded, set the status in results.json to success; otherwise, set it to error.
Include the exact command used (ccx -i case_116) in the notes field of results.json.
If the run failed, include the error message and the name of the file that indicated the failure in the notes field.
The results.json file must contain the solver name (calculix), case ID (case_116), status, version string from ccx -v, an empty artifacts array, and the notes.
