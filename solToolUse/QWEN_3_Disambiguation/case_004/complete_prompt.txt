Solver: small-strain linear elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with a vector-valued displacement space and a direct linear solver.
Task:
Analyze stress in a complex stepped domain with spring-supported top edge under gravity using Robin boundary conditions. Implement plane stress elasticity with E=70e9 Pa, ν=0.33. Compute displacement and von Mises stress distributions with elastic foundation support.
Case details:
Material: E=70e9, ν=0.33, ρ=2700 kg/m^3, g=9.81 m/s^2. Geometry: Stepped polygon (8 vertices). Loads: Gravity (-y). Boundaries: y=0 fixed, top segment (0.3≤x≤0.5) with k=1e6 N/m^2 spring foundation. Mesh: 72 elements.
Implementation notes:
Treat the 2D domain as plane stress with unit thickness and use the reduced plane-stress constitutive law.
Compute von Mises from the in-plane Cauchy stress field.
On the spring-supported segment use the Robin traction t = -k*(u.n)*n.
Apply the spring support only on the partial top segment 0.3 <= x <= 0.5; the rest of the top boundary is traction-free.
