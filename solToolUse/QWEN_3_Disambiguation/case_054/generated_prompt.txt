Create the file `case_054.inp` in the working directory with the provided input deck content.  
Run the CalculiX solver using the command `ccx case_054` (or `ccx -i case_054` if the first fails).  
Check the output file `case_054.sta` for the message indicating job completion.  
Extract the CalculiX version using `ccx -v` or equivalent.  
Write a `results.json` file with the following structure:  
The `solver` field is set to "calculix".  
The `case_id` field is set to "case_054".  
The `status` field is set to "success" if the run completed, otherwise "error".  
The `ccx_version` field contains the version string obtained from the executable.  
The `artifacts` field is an empty list.  
The `notes` field contains the exact command used and, if the run failed, the error message and the file that indicated the failure.
