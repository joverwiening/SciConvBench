Create the file case_081.inp in the working directory with the provided input deck content.
Run the CalculiX solver using the command ccx case_081.
Check the file case_081.sta for a successful termination message such as 'JOB COMPLETED'.
Record the CalculiX version string by running ccx -v or the closest equivalent available.
Create a results.json file in the working directory with the following structure:
The solver field is set to "calculix".
The case_id field is set to "case_081".
The status field is set to "success" if the run completed successfully, otherwise "error".
The ccx_version field contains the version string obtained from the ccx executable.
The artifacts field is an empty array.
The notes field contains the exact command used to run ccx and, if the run failed, includes the error message and the file that indicated the failure.
