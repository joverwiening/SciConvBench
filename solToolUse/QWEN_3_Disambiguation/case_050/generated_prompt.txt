Create the file case_050.inp in the current working directory using the provided input deck.
Run CalculiX using the command ccx -i case_050 or ccx case_050, whichever is supported by the system.
Check the file case_050.sta for successful termination, indicated by the message 'JOB COMPLETED'.
Record the CalculiX version string obtained from running ccx -v or the closest equivalent.
Write a results.json file in the current working directory with the following structure:
The solver field is set to "calculix".
The case_id field is set to "case_050".
The status field is set to "success" if the run completed successfully, otherwise "error".
The ccx_version field contains the version string obtained from the ccx executable.
The artifacts field is an empty array.
The notes field contains the exact ccx command used and, if the run failed, includes the error message and the file that indicated the failure.
Do not retry the simulation if it fails; a single attempt is sufficient.
