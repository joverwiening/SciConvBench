Create the file case_135.inp in the working directory with the provided input deck content.
Run the CalculiX solver using the command ccx -i case_135 or ccx case_135, whichever is compatible with the system.
Check the file case_135.sta for the presence of a successful termination message such as 'JOB COMPLETED'.
Extract the CalculiX version string by running ccx -v or the closest available equivalent.
Write a JSON file named results.json in the working directory with the following structure:
The solver field must be set to "calculix".
The case_id field must be set to "case_135".
The status field must be set to "success" if the run completed successfully, or "error" if it failed.
The ccx_version field must contain the version string obtained from the solver.
The artifacts field must be an empty array.
The notes field must include the exact ccx command used to run the simulation.
If the run failed, the notes field must also include the error message and the name of the file that indicated the failure.
