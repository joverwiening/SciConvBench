Create a file named `beampt.inp` in the working directory.
The content of `beampt.inp` is the provided multi-line text block starting with `**` and ending with `*END STEP`.
Execute the command `ccx -v` to get the CalculiX version string.
Store the version string for later use.
Execute the command `ccx -i beampt`.
If the previous command fails, try executing `ccx beampt`.
After the command finishes, check the contents of the file `beampt.sta`.
The run is considered successful if `beampt.sta` contains the phrase 'JOB COMPLETED'.
The run is considered an error otherwise.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object.
The "solver" key has the string value "calculix".
The "case_id" key has the string value "beampt".
The "status" key has the string value "success" or "error" based on the check of `beampt.sta`.
The "ccx_version" key has the version string obtained earlier.
The "artifacts" key has an empty list as its value.
The "notes" key contains a string with the exact command used to run the simulation.
If the status is "error", the "notes" string must also include the error message from the solver and identify the file where the failure was indicated.
