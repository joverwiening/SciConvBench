The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem to be solved is 2D small-strain linear elasticity.
The analysis will use the plane stress constitutive relation.
The domain is a semi-circle with a radius of 1 meter, located in the y>=0 half-plane.
The mesh will be generated with a resolution resulting in approximately 64 elements.
The material's Young's modulus is 70e9 Pa.
The material's Poisson's ratio is 0.33.
The material's density is 2700 kg/m^3.
A body force representing gravity acts in the negative y-direction, with g = 9.81 m/s^2.
The boundary at y=0 is fixed with a zero-displacement Dirichlet condition.
A uniform vertical traction vector of (0, -20000) Pa is applied to the semi-circular arc boundary.
The vector-valued displacement function space will use continuous Lagrange elements of polynomial degree 2.
The linear variational problem will be solved using a direct solver.
The simulation will compute the displacement field.
The simulation will compute the von Mises stress distribution from the in-plane Cauchy stress components.
