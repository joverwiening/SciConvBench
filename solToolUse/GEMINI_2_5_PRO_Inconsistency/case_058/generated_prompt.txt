The job name is segststate.
The input file must be named segststate.inp.
The finite element model is titled "segment".
The model uses the nodes and C3D20 elements defined in the provided input deck.
The material has an elastic modulus of 210,000, a Poisson's ratio of 0.3, and a density of 7.8E-9.
All elements are assigned to a solid section with this material.
Node sets Nleft, Nright, and Nfix are defined as in the provided input deck.
The left and right surfaces (Nleft and Nright) are tied using cyclic symmetry with a position tolerance of 1.0.
The cyclic symmetry model consists of 12 sectors, with the axis of symmetry defined by the vector (1, 0, 0).
Output for all 12 sectors should be generated.
A fixed boundary condition constraining all three translational degrees of freedom is applied to the node set Nfix.
The analysis consists of two steps.
The first step is a frequency analysis that stores the first 10 modes.
In the first step, cyclic symmetry modes from 0 to 6 are selected.
The second step is a steady-state dynamics analysis.
The frequency range for the steady-state analysis is from 0.5e6 to 0.55e6, with 2 frequency points and a bias of 1.
Rayleigh modal damping is used, with the stiffness-proportional damping coefficient (beta) set to 5000.
Distributed pressure loads of 100.0 are applied to face P6 of elements 25 and 37 in sectors 1, 5, and 6.
The real and imaginary parts of the displacements for all nodes (Nset=Nall) are printed to the output file.
