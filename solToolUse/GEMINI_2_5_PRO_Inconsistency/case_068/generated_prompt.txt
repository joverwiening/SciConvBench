Create a file named `beammix.inp` in the working directory.
The content of `beammix.inp` must be the exact text provided in the "Input deck (`beammix.inp`)" section of the prompt.
Run the CalculiX solver using the command `ccx -i beammix` or `ccx beammix`.
Check the `beammix.sta` file for a message indicating the job completed successfully.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the key "solver" set to the string "calculix".
The `results.json` file must contain a JSON object with the key "case_id" set to the string "beammix".
The `results.json` file must contain a JSON object with the key "status" set to "success" if the run succeeded, or "error" if it failed.
The `results.json` file must contain a JSON object with the key "ccx_version" set to the version string obtained from running `ccx -v`.
The `results.json` file must contain a JSON object with the key "artifacts" set to an empty list.
The `results.json` file must contain a JSON object with the key "notes" containing the exact ccx command used.
If the run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
