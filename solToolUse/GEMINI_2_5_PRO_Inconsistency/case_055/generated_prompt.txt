Create a file named `uprofile.inp` with the exact content provided in the initial prompt's input deck.
Run the CalculiX solver using the command `ccx -i uprofile` or `ccx uprofile`.
Determine the success of the run by checking for the string 'JOB COMPLETED' in the `uprofile.sta` file.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object with the key "solver" and the string value "calculix".
The JSON object will have a key "case_id" with the string value "uprofile".
The JSON object will have a key "status" with the string value "success" or "error" based on the run's outcome.
The JSON object will have a key "ccx_version" with the version string obtained from the `ccx -v` command.
The JSON object will have a key "artifacts" with an empty list as its value.
The JSON object will have a key "notes" containing a string with the exact command used to run the simulation.
If the run fails, the "notes" string will also include the error message and the file that indicated the failure.
