Create a file named `scheibejc.inp` in the working directory.
The content of `scheibejc.inp` must be the exact text provided in the "Input deck (`scheibejc.inp`)" section.
The simulation will use C3D8R elements as defined in the input file.
The simulation will use the Johnson-Cook material model as defined in the input file.
Run the CalculiX solver on the `scheibejc.inp` file.
Use the command `ccx -i scheibejc` or `ccx scheibejc`, whichever is available on the system.
Determine the success of the simulation by checking the `scheibejc.sta` file for a successful completion message.
Create a file named `results.json` in the working directory.
The `results.json` file must conform to the specified JSON schema.
The `solver` field in `results.json` shall be "calculix".
The `case_id` field in `results.json` shall be "scheibejc".
The `status` field in `results.json` shall be "success" if the run completed successfully, otherwise "error".
The `ccx_version` field in `results.json` shall contain the version string obtained by running `ccx -v`.
The `artifacts` field in `results.json` shall be an empty list.
The `notes` field in `results.json` shall contain the exact CalculiX command used to run the simulation.
If the simulation fails, the `notes` field shall also include the error message and the file that indicated the failure.
