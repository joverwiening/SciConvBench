Create a file named `scheibe.inp` in the working directory.
The content of `scheibe.inp` must be the exact text provided in the "Input deck" section of the prompt.
Execute the CalculiX solver on the `scheibe.inp` file using the command `ccx -i scheibe` or `ccx scheibe`.
After execution, determine the run status by checking the `scheibe.sta` file for a successful completion message.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "scheibe".
The JSON object must have a key "status" with the string value "success" or "error" based on the run status.
The JSON object must have a key "ccx_version" with the version string from the `ccx -v` command.
The JSON object must have a key "artifacts" with an empty list as its value.
The JSON object must have a key "notes" containing a string with the exact command used to run the solver.
If the run status is "error", the "notes" string must also include the error message and the name of the file that indicated the failure.
