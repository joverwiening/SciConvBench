Create a file named `c3d6.inp` in the working directory.
The content of `c3d6.inp` must be the exact text provided in the "Input deck (`c3d6.inp`)" section.
The simulation will use C3D6 elements as specified in the input file.
The nodal loads will be applied in the x-direction as specified in the input file.
Execute the CalculiX solver on the input file using a command such as `ccx -i c3d6` or `ccx c3d6`.
Check the contents of the generated `c3d6.sta` file for a successful termination message like 'JOB COMPLETED' to determine the run status.
Determine the CalculiX version by running a command like `ccx -v`.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object must have a "solver" key with the string value "calculix".
The JSON object must have a "case_id" key with the string value "c3d6".
The JSON object must have a "status" key with the string value "success" or "error" based on the run status.
The JSON object must have a "ccx_version" key with a string value containing the version information obtained from the solver.
The JSON object must have an "artifacts" key with an empty list `[]` as its value.
The JSON object must have a "notes" key containing a string with the exact CalculiX command used.
If the run failed, the "notes" string must also include the error message and the file that indicated the failure.
