Create a file named dloadlinIf.inp in the working directory.
The content of dloadlinIf.inp must be the exact text provided in the "Input deck" section.
The analysis is a frequency analysis as defined by the *FREQUENCY card in the input file.
The element type used is C3D8I as defined by the *ELEMENT card in the input file.
Execute the CalculiX solver on the input file using either the command `ccx -i dloadlinIf` or `ccx dloadlinIf`.
Determine the success of the run by checking the `dloadlinIf.sta` file for a successful termination message.
Execute the command `ccx -v` to get the solver version string.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object has a key "solver" with the string value "calculix".
The JSON object has a key "case_id" with the string value "dloadlinIf".
The JSON object has a key "status" with the string value "success" if the run completed successfully, or "error" otherwise.
The JSON object has a key "ccx_version" with the string value obtained from the `ccx -v` command.
The JSON object has a key "artifacts" with an empty list as its value.
The JSON object has a key "notes" containing a string with the exact CalculiX command used.
If the run status is "error", the "notes" string must also include the error message and the file that indicated the failure.
