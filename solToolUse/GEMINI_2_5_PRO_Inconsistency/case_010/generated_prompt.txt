Case ID is case_010.
Use the FEniCS legacy library (dolfin) for the simulation.
The geometry is a 2D rectangle defined by the domain Omega = (0, 1.0) x (0, 0.20) meters.
Create a structured mesh of 50 elements in the x-direction and 25 elements in the y-direction over the domain.
The displacement vector function space is a continuous Galerkin space of polynomial degree 2.
The model is 2D small-strain orthotropic elasticity under plane-stress conditions.
The local material axes (1-2) are rotated 30 degrees counter-clockwise relative to the global (x-y) axes.
The local orthotropic material properties are E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
Calculate the transverse Poisson's ratio as nu21 = nu12 * (E2 / E1).
Construct the plane-stress stiffness matrix in the local material frame (1-2).
Rotate the local stiffness matrix into the global coordinate frame (x-y) to define the constitutive relationship.
The bottom boundary (y=0) is fixed, with displacement u = (0, 0).
The vertical boundaries (x=0 and x=1) are traction-free.
Apply a uniform downward traction vector t = (0, -10e6) N/m to the top boundary (y=0.2).
Solve the linear variational problem using the 'lu' direct solver.
After solving, calculate the von Mises stress field from the Cauchy stress tensor.
Save a color plot of the x-component of displacement (u_x) to the file q8_ux.png.
Save a color plot of the von Mises stress to the file q8_vm.png.
Write the displacement and a suitable stress tensor representation to the file q8_solution.xdmf.
