Create a file named c3d15.inp in the working directory with the exact content provided in the "Input deck (`c3d15.inp`)" section.
The simulation will use C3D15 elements as defined in the input file.
The simulation will apply the pressure loads as defined by the *DLOAD cards in the input file.
Execute the CalculiX solver on the input file using the command `ccx -i c3d15` or `ccx c3d15`.
Determine the success of the simulation by checking for a successful termination message in the `c3d15.sta` file.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
Set the "solver" field to "calculix".
Set the "case_id" field to "c3d15".
Set the "status" field to "success" if the run completed successfully, otherwise set it to "error".
Set the "ccx_version" field to the version string obtained from running `ccx -v`.
Set the "artifacts" field to an empty list.
In the "notes" field, record the exact CalculiX command used to run the simulation.
If the run failed, append the error message and the name of the file indicating the failure to the "notes" field.
