Use FEniCS legacy (dolfin) for the simulation.
The simulation domain is a 2D rectangle defined by (0, 1.0) x (0, 0.20) meters.
Create a structured mesh of 80x16 elements over the domain.
The top subdomain, (0, 1.0) x (0.10, 0.20), is Aluminium.
The bottom subdomain, (0, 1.0) x (0.00, 0.10), is Steel.
The material properties for Aluminium are E = 70 GPa and ν = 0.30.
The material properties for Steel are E = 200 GPa and ν = 0.30.
Use cell markers to assign the different material properties to the subdomains.
Model the problem using small-strain linear elasticity under plane stress conditions.
The displacement vector function space must use continuous Lagrange elements of polynomial degree 2.
Apply a fixed boundary condition (u_x = 0, u_y = 0) on the left edge (x = 0).
Apply a uniform downward line traction of t = (0, -5000) N/m on the right edge (x = 1).
The top edge (y = 0.20) and bottom edge (y = 0.00) are traction-free.
Solve the linear system using a direct solver.
Save a color plot of the displacement magnitude to a file named q7_disp.png.
Save the displacement vector field to an XDMF file named q7_disp.xdmf.
