Case ID: case_009.
Use the FEniCS legacy library (dolfin) to solve the problem.
The problem is a 2D small-strain linear elasticity simulation using a plane-stress model.
The geometry is a rectangle defined by the domain (0, 1.0) x (0, 0.20) meters.
A rectangular notch is removed from the geometry, defined by the region (0, 0.06) x (0.08, 0.12) meters.
Generate a mesh of the geometry with approximately 100 elements along the 1.0-meter length.
The material has a Young's modulus E of 200 GPa and a Poisson's ratio ν of 0.3.
Define the function space for the vector displacement field using continuous Lagrange elements of degree 2.
Apply a fixed boundary condition (u_x = 0, u_y = 0) on the left edge at x = 0.
Apply a traction vector T = (2e6, 0) N/m^2 on the right edge at x = 1.0.
The top, bottom, and notch boundaries are traction-free.
Solve the linear variational problem using a direct solver.
After solving, compute the von Mises stress field.
Save a plot of the von Mises stress field as `q5_vm.png`.
Save the displacement vector field to an XDMF file named `q5_displacement.xdmf`.
