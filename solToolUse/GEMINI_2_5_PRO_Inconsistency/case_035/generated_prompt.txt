The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem to be solved is 2D small-strain linear elasticity under the plane stress assumption.
The geometry is a polygon defined by the vertices (0,0), (0.8,0), (0.8,0.2), (0.5,0.2), (0.5,0.5), (0.3,0.5), (0.3,0.2), and (0,0.2).
The material's Young's modulus is 70e9 Pa and its Poisson's ratio is 0.33.
The material density is 2700 kg/m^3.
A body force representing gravity (g=9.81 m/s^2) acts in the negative y-direction.
A concentrated point load of -5000 N is applied in the y-direction at the coordinate (0.4, 0.5).
The point load will be implemented using a `dolfin.PointSource`.
The bottom boundary of the domain, where y=0, is fixed with zero displacement.
The domain will be meshed with approximately 72 triangular elements.
The mesh must contain a vertex at the point load location (0.4, 0.5).
The vector-valued displacement function space will use second-degree Lagrange elements.
The linear system will be solved using a direct solver.
The simulation will compute the displacement magnitude field.
The simulation will compute the von Mises stress field.
