Create the file `segmentunsmooth.inp` in the working directory using the provided input deck text.
The element type in the input deck will be C3D10.
The concentrated load on node 260 will be 1 unit in the y-direction.
Run the CalculiX solver using the command `ccx -i segmentunsmooth` or `ccx segmentunsmooth`.
Determine the solver version by running `ccx -v` or an equivalent command.
Check the `segmentunsmooth.sta` file for a successful termination message like 'JOB COMPLETED'.
Create a `results.json` file in the working directory.
The `results.json` file will contain a JSON object.
The `solver` key will have the value "calculix".
The `case_id` key will have the value "segmentunsmooth".
The `status` key will have the value "success" if the run completed successfully, otherwise "error".
The `ccx_version` key will contain the version string obtained from the solver.
The `artifacts` key will be an array of strings containing the filenames: `segmentunsmooth.inp`, `segmentunsmooth.dat`, `segmentunsmooth.frd`, and `segmentunsmooth.sta`.
The `notes` key will contain the exact CalculiX command used.
If the run fails, the `notes` key will also include the error message and the file that indicated the failure.
