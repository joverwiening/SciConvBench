Create a file named `zerovel.inp` in the working directory.
The content of `zerovel.inp` is the provided CalculiX input deck.
The CalculiX input deck uses the B31 element type.
The CalculiX input deck applies a concentrated load in the x-direction at node 1.
The CalculiX input deck requests nodal output for displacements (U) and velocities (V).
Execute the CalculiX solver on the `zerovel.inp` file.
The command to execute the solver is either `ccx -i zerovel` or `ccx zerovel`.
Determine the success of the run by checking the `zerovel.sta` file for a successful termination message.
Create a file named `results.json` in the working directory.
The `results.json` file contains a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
The value for the "solver" key is "calculix".
The value for the "case_id" key is "zerovel".
The value for the "status" key is "success" if the run completed successfully, otherwise it is "error".
The value for the "ccx_version" key is the version string obtained from running `ccx -v`.
The value for the "artifacts" key is a JSON array containing the strings 'zerovel.inp', 'zerovel.sta', and 'zerovel.dat'.
The value for the "notes" key is a string containing the exact CalculiX command used for the run.
If the run failed, the "notes" string also includes the error message and the file that indicated the failure.
