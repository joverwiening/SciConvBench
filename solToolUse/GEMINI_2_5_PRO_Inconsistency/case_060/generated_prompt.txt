Create a file named `axiplane.inp` in the working directory.
The content of `axiplane.inp` is the exact text from the `Input deck` section of the user's prompt.
Run the CalculiX solver on the `axiplane.inp` file using a command like `ccx -i axiplane` or `ccx axiplane`.
Determine if the simulation succeeded by checking for a successful termination message in the `axiplane.sta` file.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the key "solver" set to the string "calculix".
The "case_id" key in the JSON object must be the string "axiplane".
The "status" key in the JSON object must be "success" if the run completed successfully, and "error" otherwise.
The "ccx_version" key in the JSON object must be the version string obtained from the CalculiX solver.
The "artifacts" key in the JSON object must be an empty list.
The "notes" key in the JSON object must contain the exact command used to run the solver, and any error messages if the run failed.
