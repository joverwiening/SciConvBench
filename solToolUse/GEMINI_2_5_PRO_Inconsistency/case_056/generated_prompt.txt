Create a file named `membrane3.inp` in the working directory.
The content of `membrane3.inp` is the provided multi-line text block starting with `**` and ending with `*END STEP`.
The simulation will use M3D8 elements as specified in the `membrane3.inp` file.
The simulation will apply a load in the z-direction (degree of freedom 3) as specified in the `membrane3.inp` file.
Run the CalculiX solver on the input file using the command `ccx -i membrane3` or `ccx membrane3`.
Check for a successful termination message in the `membrane3.sta` file.
Execute `ccx -v` to get the solver version string.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object with the following key-value pairs.
The "solver" key will have the value "calculix".
The "case_id" key will have the value "membrane3".
The "status" key will have the value "success" or "error" based on the run's outcome.
The "ccx_version" key will have the version string from the solver.
The "artifacts" key will have an empty list `[]` as its value.
The "notes" key will contain the exact CalculiX command used.
If the run fails, the "notes" field will also include the error message and the file that indicated the failure.
