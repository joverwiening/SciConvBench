Create a file named cubenewt.inp in the working directory with the exact content provided in the input deck.
Run the CalculiX solver on the input file using a command such as `ccx -i cubenewt` or `ccx cubenewt`.
The analysis is a dynamic simulation as defined by the `*DYNAMIC` step in the provided input deck.
The simulation is driven by a distributed load due to Newtonian gravity applied to the element set Eall.
Determine the run's success by checking the `cubenewt.sta` file for a successful termination message like 'JOB COMPLETED'.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
The "solver" field must be the string "calculix".
The "case_id" field must be the string "cubenewt".
The "status" field must be "success" if the run completed successfully, and "error" otherwise.
The "ccx_version" field must contain the version string obtained from running `ccx -v`.
The "artifacts" field must be an empty list.
The "notes" field must contain the exact CalculiX command used to run the simulation.
If the run fails, the "notes" field must also include the error message and the name of the file that indicated the failure.
