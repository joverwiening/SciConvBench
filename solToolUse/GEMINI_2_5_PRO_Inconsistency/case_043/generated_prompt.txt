The simulation task is to solve a 2D plane strain solid mechanics problem using FEniCS legacy (dolfin).
The problem is Case ID case_043.
The model is small-strain linear elasticity for a nearly incompressible material.
The formulation is a mixed displacement-pressure approach.
The geometry is a rectangular domain defined by the corners (0, 0) and (1.0, 0.2) meters.
A circular hole of radius 0.04 meters is centered at (0.50, 0.10) meters and is removed from the domain.
The material has a Young's modulus E of 5 MPa and a Poisson's ratio ν of 0.49.
The left boundary (x=0) is fixed, with displacement components u_x and u_y both set to 0.
The right boundary (x=1.0) has a prescribed displacement of u_x = 0.001 meters and u_y = 0.
The top boundary (y=0.2), bottom boundary (y=0), and the circular hole boundary are traction-free.
A triangular mesh with a characteristic element size of 0.005 meters will be used.
Taylor-Hood elements will be used, with Continuous Galerkin degree 2 for displacement and degree 1 for pressure.
The linear system will be solved using a direct saddle-point solver.
The von Mises stress field will be computed and saved as a PNG file named q11_vm.png.
A color map of the x-component of displacement (u_x) will be saved as a PNG file named q11_ux.png.
The displacement vector field will be saved to a file in XDMF format.
