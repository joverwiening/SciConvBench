Create a file named leifer1.inp in the current working directory.
The content of the leifer1.inp file must be the exact text provided in the "Input deck (`leifer1.inp`)" section.
The simulation uses S8 shell elements as defined in the input file.
The simulation performs a dynamic analysis step as defined in the input file.
Execute the CalculiX solver on the leifer1.inp file.
Use either the command `ccx -i leifer1` or `ccx leifer1`.
Determine the success of the simulation by checking for a successful termination message in the `leifer1.sta` file.
Create a file named `results.json` in the current working directory.
The `results.json` file must contain a JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "leifer1".
The JSON object must have a key "status" with the string value "success" or "error".
The JSON object must have a key "ccx_version" with the version string from the `ccx -v` command as its value.
The JSON object must have a key "artifacts" with an empty list as its value.
The JSON object must have a key "notes" containing a string with the exact ccx command used.
If the simulation fails, the "notes" string must also include the error message and the file that indicated the failure.
