The simulation will be performed using FEniCS legacy (dolfin).
The geometry is a 2D rectangle defined by the corners (0, 0) and (1.0, 0.20).
A structured mesh of 100x20 quadrilateral elements will be used.
The problem is modeled as small-strain linear elasticity under plane strain conditions.
A mixed displacement-pressure formulation will be used.
The displacement field will be discretized using second-degree continuous Lagrange elements.
The pressure field will be discretized using first-degree continuous Lagrange elements.
The material's Young's modulus is 5 MPa.
The material's Poisson's ratio is 0.49.
The left boundary (x=0) is fixed, with displacement components u_x and u_y both equal to zero.
The right boundary (x=1.0) has a prescribed displacement of u_x = 0.03 and u_y = 0.
The top and bottom boundaries are traction-free.
The resulting linear system will be solved using a direct saddle-point solver.
A color plot of the displacement magnitude will be saved as `q10_disp.png`.
The displacement vector field will be saved in XDMF format to a file named `q10_displacement.xdmf`.
