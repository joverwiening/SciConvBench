The simulation will be performed using the FEniCS legacy library (dolfin).
The problem to be solved is a 2D small-strain linear elasticity problem under plane stress conditions.
The geometry is a rectangle defined by the domain Ω = (0.0, 1.0) x (0.0, 0.20) meters.
A structured rectangular mesh of 100 elements in the x-direction and 20 elements in the y-direction will be used.
The displacement vector field will be discretized using continuous Lagrange elements of polynomial degree 2.
The material has a constant Poisson's ratio of 0.3.
The Young's modulus is functionally graded along the vertical direction, defined by the expression E(y) = 1.0e11 + 1.0e11 * (y / 0.20) Pascals.
The left boundary (x=0) is fixed, with displacement u = (0, 0).
A uniform traction vector T = (2.0e6, 0.0) Pascals is applied to the right boundary (x=1).
The top (y=0.2) and bottom (y=0) boundaries are traction-free.
The linear system will be solved using a direct solver.
The displacement field solution will be saved to a file in XDMF format.
A color plot of the displacement magnitude, |u|, will be saved as q9_disp.png.
