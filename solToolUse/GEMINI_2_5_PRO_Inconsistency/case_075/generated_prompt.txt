Create a file named `pendel.inp` in the working directory.
The content of `pendel.inp` must be the exact text provided in the "Input deck (`pendel.inp`)" section.
The simulation uses `B32` elements as defined in the `pendel.inp` file.
The simulation uses a gravity load as defined in the `pendel.inp` file.
Execute the CalculiX solver on the `pendel.inp` file.
Attempt to run the solver using the command `ccx -i pendel`.
If the command `ccx -i pendel` is not found or fails, attempt to run the solver using the command `ccx pendel`.
Determine the version of the CalculiX solver by running `ccx -v`.
After the run attempt, check the contents of the `pendel.sta` file.
The run is considered successful if the `pendel.sta` file contains the string 'JOB COMPLETED'.
Otherwise, the run is considered to have an error.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The "solver" key must have the string value "calculix".
The "case_id" key must have the string value "pendel".
The "status" key must have the string value "success" if the run was successful, or "error" if it was not.
The "ccx_version" key must have a string value containing the version information obtained from the solver.
The "artifacts" key must have a value of an empty list.
The "notes" key must have a string value containing the exact command used to run the solver.
If the run resulted in an error, the "notes" string must also include the error message and identify the file that indicated the failure.
