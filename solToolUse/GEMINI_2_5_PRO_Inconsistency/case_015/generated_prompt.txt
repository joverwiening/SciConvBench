Use the FEniCS legacy library (dolfin).
The simulation solves a 2D plane-stress linear elasticity problem.
The geometry is a rectangle defined by corners at (0, 0) and (1.0, 0.2).
A semicircle of radius 0.05 is removed from the top edge, centered at (0.5, 0.2).
The geometry is meshed with a characteristic element size of 0.005.
The displacement vector field is discretized using continuous Lagrange elements of degree 2.
The material has a Young's modulus of 200e9 Pa and a Poisson's ratio of 0.3.
The bottom boundary of the plate (y=0) is fixed with a Dirichlet boundary condition of (0,0) for the displacement.
A traction vector of (0, -10e6) is applied to the top boundary segments where y=0.2 and x is in [0, 0.45] or [0.55, 1.0].
The vertical side boundaries (x=0 and x=1) and the semicircular notch boundary are traction-free.
The linear system is solved using a direct solver.
The von Mises stress field is computed from the displacement solution.
The von Mises stress field is plotted and saved to a file named `q6_vm.png`.
The displacement field is saved in XDMF format to a file named `q6_displacement.xdmf`.
