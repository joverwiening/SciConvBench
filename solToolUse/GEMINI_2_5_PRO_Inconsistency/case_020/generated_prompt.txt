Use the FEniCS legacy library (dolfin).
The simulation domain is a rectangle defined by the corners (0, 0) and (1.0, 0.20).
Generate a uniform structured mesh of the rectangle with 40 elements in the x-direction and 8 elements in the y-direction.
Define a vector-valued function space for displacement using continuous Lagrange elements of degree 2.
Set the material's Young's modulus to 200e9 Pa.
Set the material's Poisson's ratio to 0.3.
The model is governed by the plane-stress linear elasticity equations.
Apply a Dirichlet boundary condition to the left boundary (x=0), fixing the displacement to (0, 0).
Apply a traction vector of (0, -2000) N/m to the top boundary (y=0.20).
The right (x=1.0) and bottom (y=0) boundaries are traction-free.
Solve the resulting linear system using a direct solver.
Save a color plot of the y-component of the displacement field to a file named 'q2_uy.png'.
Save the displacement vector field solution to an XDMF file.
