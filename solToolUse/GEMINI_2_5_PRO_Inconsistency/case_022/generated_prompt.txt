Define the geometry as a rectangle from (0, 0) to (1.0, 0.20).

Define a vector-valued function space for the displacement field using first-degree Lagrange elements.
Set the material's Young's modulus to 200e9.
Set the material's Poisson's ratio to 0.3.
Implement a plane-stress linear elastic constitutive model.
Define the left boundary (x=0) as a fixed Dirichlet boundary condition with displacement (0, 0).
Define the right boundary (x=1) as a Dirichlet boundary condition with a prescribed displacement of (0.001, 0).
The top (y=0.20) and bottom (y=0) boundaries are traction-free.
Solve the variational problem using a direct linear solver.
