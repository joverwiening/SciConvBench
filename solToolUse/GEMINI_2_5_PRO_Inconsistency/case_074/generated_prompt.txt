Create a file named `achtelc.inp` in the working directory.
The content of `achtelc.inp` must be the exact text provided in the "Input deck" section of the prompt.
Execute the CalculiX solver on the input file using a command like `ccx -i achtelc` or `ccx achtelc`.
Determine the CalculiX version by running a command like `ccx -v` and store the output string.
Check the `achtelc.sta` file for a line indicating the job completed successfully.
If the job completed successfully, the status is "success".
If the job did not complete successfully, the status is "error".
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The value for the key "solver" must be the string "calculix".
The value for the key "case_id" must be the string "achtelc".
The value for the key "status" must be the "success" or "error" string determined previously.
The value for the key "ccx_version" must be the version string obtained from the solver.
The value for the key "artifacts" must be an empty list.
The value for the key "notes" must be a string containing the exact CalculiX command used to run the simulation.
If the simulation status is "error", the "notes" string must also include the error message and the file that indicated the failure.
