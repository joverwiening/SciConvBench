Case ID: case_008
Use FEniCS legacy (dolfin).
Solver: small-strain linear elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with a vector-valued displacement space and a direct linear solver.
Task:
Simulate stress in a right triangular domain with fixed left (x=0) and bottom (y=0) edges under vertical point load at centroid. Implement linear elasticity with E=70e9 Pa, ν=0.33. Compute displacement and von Mises stress distributions.
Case details:
Material: E=70e9, ν=0.33. Geometry: Right triangle (0,0)-(1,0)-(0,0.5). Constraints: u_x=0 (left), u_y=0 (bottom). Load: -5 kN at (0.5,0.25) on y-component. Mesh: 64 elements.
Implementation notes:
Treat the 2D domain as plane stress with unit thickness and use the reduced plane-stress constitutive law.
Compute von Mises from the in-plane Cauchy stress field.
Represent each concentrated load with PointSource on the appropriate displacement component instead of smearing it over an edge.
Use two support conditions, u_x = 0 on x = 0 and u_y = 0 on y = 0, and apply the vertical point load at the stated point.
