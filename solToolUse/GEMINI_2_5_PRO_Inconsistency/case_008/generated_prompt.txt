The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem to be solved is 2D small-strain linear elasticity under the plane-stress assumption.
The domain is a right triangle with vertices at coordinates (0, 0), (1, 0), and (0, 0.5).
The material is defined by a Young's modulus of 70e9 Pa and a Poisson's ratio of 0.33.
An unstructured mesh of the domain will be generated with approximately 64 elements.
The displacement vector field is discretized using second-order (P2) Lagrange elements.
A boundary condition of u_x = 0 is applied to the left edge of the triangle (x=0).
A boundary condition of u_y = 0 is applied to the bottom edge of the triangle (y=0).
A vertical point load of -5000 N is applied at the coordinate (0.5, 0.25) using a `PointSource`.
The resulting linear system of equations will be solved using a direct solver.
The simulation will output the final displacement field.
The simulation will also compute and output the von Mises stress distribution.
A unit thickness of 1.0 is assumed for the 2D domain.
