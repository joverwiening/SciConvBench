Create a file named axial.inp in the working directory with the provided content.
Run the CalculiX solver using the command `ccx -i axial`.
If the command `ccx -i axial` fails, attempt to run the solver with the command `ccx axial`.
Determine the run's success by checking for the exact string 'JOB COMPLETED' in the axial.sta file.
Obtain the solver version string by executing `ccx -v`.
Create a file named results.json in the working directory.
The results.json file must contain a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
Set the "solver" value to "calculix".
Set the "case_id" value to "axial".
Set the "status" value to "success" if the run succeeded, otherwise set it to "error".
Set the "ccx_version" value to the version string obtained from the solver.
Set the "artifacts" value to an empty array.
Set the "notes" value to a string containing the exact command used to run the solver.
If the run failed, append the error message and the name of the file indicating the failure to the "notes" string.
The simulation uses CAX8R elements as defined in the input deck.
The simulation applies a centrifugal load as defined in the input deck.
