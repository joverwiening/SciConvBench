Create a file named `beamcontact.inp` in the working directory.
The content of `beamcontact.inp` must be the exact text provided in the "Input deck (`beamcontact.inp`)" section.
Run the CalculiX solver on the input file.
The command to run the solver should be `ccx -i beamcontact` or `ccx beamcontact`.
Determine the version of the CalculiX solver by running a command like `ccx -v`.
Check for the successful completion of the job by inspecting the `beamcontact.sta` file for a success message like 'JOB COMPLETED'.
Create a file named `results.json` in the working directory.
The `results.json` file must conform to the specified JSON schema.
The `solver` field in `results.json` must be "calculix".
The `case_id` field in `results.json` must be "beamcontact".
The `status` field in `results.json` must be "success" if the job completed successfully, otherwise it must be "error".
The `ccx_version` field in `results.json` must contain the version string obtained from the solver.
The `artifacts` field in `results.json` must be an empty list.
The `notes` field in `results.json` must contain the exact command used to run the solver.
If the run fails, the `notes` field must also include the error message and the name of the file that indicated the failure.
