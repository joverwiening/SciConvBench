Create the file `planestrain2.inp` in the working directory with the specified content.
The input deck defines an 8-node plane strain element (CPE8).
The material has an elastic modulus of 210000 and a Poisson's ratio of 0.3.
The solid section has a thickness of 0.01.
Boundary conditions are applied to fix node 1 in the x and y directions, and nodes 2 and 8 in the y direction.
Concentrated loads are applied in the y-direction to nodes 3, 4, and 6.
The analysis is a single static step.
Nodal displacements, reaction forces, element strains, and element stresses are requested as output.
Run the CalculiX solver on the `planestrain2.inp` file.
Attempt to execute the simulation using the command `ccx -i planestrain2`.
If the previous command fails, execute the simulation using the command `ccx planestrain2`.
Check the `planestrain2.sta` file for a successful completion message to determine the run status.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
The "solver" value is "calculix".
The "case_id" value is "planestrain2".
The "status" value is "success" if the run completed successfully, otherwise it is "error".
The "ccx_version" value is the version string from the `ccx -v` command.
The "artifacts" value is an empty array.
The "notes" value contains the exact command used to run the solver.
If the run failed, the "notes" value also includes the error message and the file that indicated the failure.
