The simulation will be implemented using the FEniCS legacy library (dolfin).
The computational domain is a square defined by the vertices (-1,-1), (1,-1), (1,1), and (-1,1).
An interior slit is defined on the line segment from (0,0) to (1,0).
A conforming mesh of the square domain will be generated, treating the slit as an internal boundary.
The mesh resolution will be approximately 30 elements along each edge of the square.
The physical model is small-strain linear elasticity under the plane strain assumption.
The first Lamé parameter λ is 0.5444837367825.
The second Lamé parameter μ is 0.5444837367825.
The exact displacement field u0 is defined using polar coordinates (r, θ) centered at the crack tip (0,0), where r = sqrt(x^2 + y^2) and θ = atan2(y, x).
The displacement field exponent q is 0.5430755788367.
The Kolosov constant κ is 2.0.
The radial component of displacement is ur = (r^q / (2*μ)) * (-(κ - q - 1)*cos(q*θ) + (q + 1)*cos((q-2)*θ)).
The tangential component of displacement is uθ = (r^q / (2*μ)) * ((κ + q + 1)*sin(q*θ) - (q + 1)*sin((q-2)*θ)).
The Cartesian components of displacement are ux = ur*cos(θ) - uθ*sin(θ) and uy = ur*sin(θ) + uθ*cos(θ).
The displacement field is discretized using continuous vector Lagrange elements of degree 2.
Dirichlet boundary conditions are applied to the four outer edges of the square and to the faces of the interior slit.
The values for the Dirichlet boundary conditions are prescribed by the exact displacement field u0.
The body force f is zero.
The resulting linear system is solved using the GMRES iterative method.
The GMRES solver is preconditioned with an Incomplete LU (ILU) factorization.
