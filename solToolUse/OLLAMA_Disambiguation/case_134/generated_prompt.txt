## 🚀 Quick‑start usage

```bash
# 1️⃣ Default CSV → stdout
./process_file.py --input data.csv

# 2️⃣ Pipe‑separated file + debug log
./process_file.py -i data.psv -d '|' -l process.log

# 3️⃣ Custom error‑code map (JSON)
./process_file.py -i data.csv -e err_map.json
```

You can chain it in a shell script and react to the exit code:

```bash
./process_file.py -i data.csv
rc=$?
if (( rc != 0 )); then
    echo "❌ Processing failed (code $rc) – see log for details"
fi
```
