## 5. Common pitfalls when you start to **post‑process with Python**

Below is a **tiny script** you can run from the Abaqus command line (`abaqus python getPlastic.py`) to extract the maximum plastic strain in the model:

```python
# getPlastic.py -------------------------------------------------
from odbAccess import *
from abaqusConstants import *

odb = openOdb('Job-1.odb')               # <-- change to your ODB name
step = odb.steps['Pressure-step']
frame = step.frames[-1]                  # last increment (or any you like)

# 1. Plastic strain (PEEQ) field
plastic = frame.fieldOutputs['PEEQ']
maxPlas = max(plastic.values, key=lambda v: v.data)
print('Maximum equivalent plastic strain = %.6e' % maxPlas.data)

# 2. Stress (S) field – locate the element with the highest von‑Mises stress
stress = frame.fieldOutputs['S']
vonMises = stress.getScalarField(invariant=MISES)
maxStress = max(vonMises.values, key=lambda v: v.data)
print('Maximum von‑Mises stress = %.2f MPa' % maxStress.data)

odb.close()
```

*What it does*:  
- Opens the ODB, grabs the **last frame** of the static step, extracts the **equivalent plastic strain** (`PEEQ`) and the **von‑Mises stress** (`MISES`).  
- Prints the **global maxima**. You can easily adapt it to write a CSV file with the values for every increment if you need a time/history plot.

## 3. Quick Python script to extract the maximum plastic strain & von‑Mises stress

Save the following as `extractPlastic.py` and run it with  

```bash
abaqus python extractPlastic.py
```

```python
# --------------------------------------------------------------
# extractPlastic.py – prints max PEEQ and max von‑Mises stress
# --------------------------------------------------------------
from odbAccess import openOdb
from abaqusConstants import *

odb_name = 'cantilever.odb'          # <-- change if your job name differs
odb = openOdb(odb_name)

step = odb.steps['Pressure-step']   # name must match the *STEP title
frame = step.frames[-1]             # last increment (final state)

# ---- Equivalent plastic strain (PEEQ) ----
peeq = frame.fieldOutputs['PEEQ']
max_peeq = max(peeq.values, key=lambda v: v.data)
print('Maximum equivalent plastic strain (PEEQ) = {:.6e}'.format(max_peeq.data))

# ---- von‑Mises stress (MISES) ----
stress = frame.fieldOutputs['S']
von_mises = stress.getScalarField(invariant=MISES)
max_vm = max(von_mises.values, key=lambda v: v.data)
print('Maximum von‑Mises stress = {:.2f} MPa'.format(max_vm.data))

odb.close()
```

*What it does*:  
- Opens the ODB, grabs the final frame of the static step, extracts `PEEQ` and the von‑Mises invariant of `S`, and prints the global maxima.  
- You can easily extend it to write a CSV file with the values for every increment if you need a history plot.

## 2️⃣ What changed and why (one‑liner recap)

| # | Change | Reason |
|---|--------|--------|
| 1 | `*SURFACE … PRESSFACE` + `*DLOAD PRESSFACE, P2, -1.0` | Pressure must act on a **surface**, not on a single element ID. |
| 2 | Realistic `*PLASTIC` curve (250 MPa yield) | Gives the model a proper elastic‑plastic response. |
| 3 | `*BOUNDARY` on **all** nodes of the X = 0 face (`CLAMPED_NODES`) | Prevents a single‑node “pin” that lets the rest of the face rotate. |
| 4 | Replace `*DYNAMIC` with `*STATIC` (NLGEOM) | Quasi‑static loading is sufficient for a pressure‑controlled cantilever and avoids inertial effects. |
| 5 | `*OUTPUT` fields `S, PE, PEEQ` + history `RF, U` | Guarantees you can see plastic strain, von‑Mises stress and reaction forces. |
| 6 | Density `7.85E‑9` tonne/mm³ (consistent with mm‑kg‑s) | Keeps units coherent; otherwise Abaqus will silently scale the mass. |
| 7 | Minimum 2–3 elements through thickness (you can keep 1 for a quick test, but add layers for production) | Improves strain‑gradient resolution; a coarse mesh can hide plasticity. |

## 3️⃣ Running the job

1. **Save** the text above as `cantilever.inp` (or any name you like).  
2. In Abaqus/CAE → *Job* → *Create* → select the file → **Submit**.  
3. The job should finish without “maximum number of increments exceeded” warnings.  
   - If you see convergence warnings, increase the number of increments (`*STATIC` line: `0.1, 0.5, 1e‑05, 1.`) or refine the mesh a little.

## 4️⃣ Step‑by‑step sanity‑check (what to look for)

| Step | Action in Abaqus/CAE |
|------|----------------------|
| **A** | Open the resulting `.odb`. |
| **B** | *Result* → *Field Output* → choose **PEEQ** → *Contour*. <br>**Non‑zero** values → plastic strain is active. |
| **C** | Add a second contour for **S, MISES** (von‑Mises). <br>Values > 250 MPa near the clamp confirm yielding. |
| **D** | *Result* → *History Output* → plot **RF** (reaction force) vs. step time. <br>Look for a change in slope (elastic → plastic). |
| **E** | If **PEEQ** is still zero, either: <br>• Increase the pressure magnitude (`-2.0`, `-5.0`, …) <br>• Lower the yield stress a little (e.g., 200 MPa) <br>• Verify that the surface definition really matches the +X face (use *Tools → Query → Pick* → *Elements* → *Face*). |

---

## 5️⃣ What to do if plastic strain is still zero

| Symptom | Likely cause | Quick fix |
|---------|--------------|-----------|
| **No PEEQ** but von‑Mises > 250 MPa | Pressure not applied (surface mis‑identified) | In the viewport, *Tools → Query → Pick* the element face, note the element number and face label (S1‑S6). Update the `*SURFACE` line accordingly. |
| **Zero reaction force** | Boundary set does not include all X = 0 nodes | Double‑check the node list (`CLAMPED_NODES`). Use `*NSET, NSET=CLAMPED_NODES, GENERATE` with the correct node IDs. |
| **Convergence warnings** | Pressure step too large for the current mesh | Reduce the initial increment (`*STATIC` line: `0.1, 0.5, 1e‑05, 1.`) or add a few more elements through the thickness. |
| **Plastic strain appears only in one element** | Mesh too coarse → strain localises | Refine the mesh (e.g., split the block into 2 × 2 × 4 elements). |

If any of the above occurs, paste the relevant part of the `.log` file or a screenshot of the ODB view and I’ll help you fine‑tune the model.

---

### TL;DR (the “cheat‑sheet”)

1. **Define a surface** (`*SURFACE … PRESSFACE`) and apply the pressure with `*DLOAD PRESSFACE, P2, -1.0`.  
2. **Give steel a realistic plastic curve** (yield ≈ 250 MPa).  
3. **Clamp every node** on the X = 0 face (`*BOUNDARY` on a node set).  
4. **Run a static NLGEOM step** (`*STATIC`).  
5. **Request field output** `S, PE, PEEQ` and history `RF, U`.  
6. **Keep density consistent** (`7.85E‑9` tonne/mm³ for mm‑kg‑s).  
7. **Use at least 2–3 elements through the thickness** for a production run.

Copy the input file above, submit the job, and verify with the **PEEQ** contour – you should now see plasticity develop in the cantilever.  

Happy modelling!
