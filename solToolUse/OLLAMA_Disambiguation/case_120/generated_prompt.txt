**What went wrong**

Your `.inp` file never tells CalculiX to write any field results.  
When the solver does not see an `*OUTPUT` (or `*NODE OUTPUT`) block it only produces the status file (`.sta`) and a very small summary (`.dat`).  
Therefore no tables with nodal displacements, reaction forces, stresses, … were written, and there is nothing for me (or a post‑processor) to extract.

---

## Fix – add an `*OUTPUT` block

You only need to request the global nodal displacements (`U1 U2 U3`) for the node set **`TRA`** (and, optionally, reaction forces for a restrained set).  
Insert the block **before the first `*STEP`** (or inside a specific step if you want the output only for that step).

```abaqus
*OUTPUT, FIELD, VARIABLE=U, TIME POINTS=ALL
*NODE OUTPUT, NSET=TRA
U1, U2, U3
```

*Optional – reaction forces* (replace `FIXED` with the name of the node set that is fully restrained):

```abaqus
*OUTPUT, FIELD, VARIABLE=RF
*NODE OUTPUT, NSET=FIXED
RF1, RF2, RF3, RM1, RM2, RM3
```
