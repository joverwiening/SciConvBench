| What is missing in the input | Effect on the linear system |
|------------------------------|-----------------------------|
| **Loads** (`*CLOAD`, `*DLOAD`, `*GRAVITY`, …) | Right‑hand side vector **F** = 0. |
| **Constraints** (`*ENCASTRE`, `*DISPLACEMENT`, `*BOUNDARY` …) | **K** retains the six rigid‑body modes → **K** is rank‑deficient (singular). |
| **Abaqus handling of a singular system** | Abaqus prints a warning and forces the solution to the zero‑displacement field (or a field that differs only by round‑off). |

Typical warning in the job log (`*.msg` or `*.log`):

```
WARNING:  THE MODEL IS UNCONSTRAINED.  THE STIFFNESS MATRIX IS SINGULAR.
         THE SOLUTION WILL BE SET TO ZERO DISPLACEMENTS.
```

Because the system is homogeneous (`F = 0`) **and** the matrix is singular, the only admissible solution is `U = 0`.

### 2.2. Inspect the ODB in Abaqus/Viewer  

**Manually**

1. Open the ODB.  
2. Choose **Result → Field Output → U**.  
3. All entries will read `0.000000E+00` (or a number of order 1e‑16).

**Programmatically** – run the short script from the Abaqus command line (or the CAE Python console) to print a few displacement values:

```python
# -------------------------------------------------
# Verify that the displacement field is zero
# -------------------------------------------------
from odbAccess import openOdb

odb = openOdb('case_047.odb')          # change to your ODB name
step = odb.steps['Step-1']             # name of the step you defined
frame = step.frames[-1]                # last increment of the step
disp = frame.fieldOutputs['U']

print('First 10 nodal displacements (machine precision):')
for v in disp.values[:10]:
    # v.data is a tuple (Ux, Uy, Uz)
    print(f'Node {v.nodeLabel:5d}: {v.data}')
odb.close()
```

**Typical output**

```
First 10 nodal displacements (machine precision):
Node     1: (0.0, 0.0, 0.0)
Node     2: (0.0, 0.0, 0.0)
...
```

Values such as `1.2E‑16` are just round‑off noise; they are effectively zero.

Search for the displacement section (lines that start with `U`). They will contain `0.000000E+00`. Any non‑zero numbers would indicate you are looking at a different job or that the analysis terminated before the final step.

## 3. What to add if you *need* a non‑zero response  

| Desired feature | Input‑file addition (inside a `*STEP`) |
|-----------------|----------------------------------------|
| **Apply loads** | `*CLOAD` (point loads), `*DLOAD` (distributed loads), `*GRAVITY`, `*PRESCRIBED FIELD`, etc. |
| **Prevent rigid‑body motion** | At least three independent constraints that remove the six rigid‑body modes, e.g. <br>`*ENCASTRE, NSET=FIXED` (all 6 DOFs on one node) <br>`*DISPLACEMENT, NSET=SUPP1, DOF=1,2` (fix two translational DOFs on a second node) <br>`*DISPLACEMENT, NSET=SUPP2, DOF=3` (fix one translational or rotational DOF on a third node) |
| **Define a proper analysis step** | ```*STEP, name=Step-1, nlgeom=NO<br>*STATIC<br>   … (loads & BCs) …<br>*END STEP``` |

### Minimal working example (static cantilever beam)

```abaqus
*Heading
** Simple cantilever beam – static analysis
*Preprint, echo=NO, model=NO, history=NO, contact=NO

*Part, name=BEAM
*Node
1, 0., 0., 0.
2, 10., 0., 0.
*Element, type=B31
1, 1, 2
*End Part

*Assembly, name=ASSEMBLY
*Instance, name=BEAM-1, part=BEAM
*End Instance
*End Assembly

*Material, name=STEEL
*Elastic
210000., 0.3
*Beam Section, elset=EALL, material=STEEL, section=RECT
0.1, 0.1   ; (height, width)

*Step, name=Step-1, nlgeom=NO
*Static
** Load at node 2 (negative Y‑direction)
*Cload
2, 2, -1000.          ; node‑2, DOF‑2 (Y), magnitude -1000 N
** Fully fix node 1 (encastre) – removes all six rigid‑body modes
*Encastre
1,
*End Step
```

Running this model will produce a **non‑zero** displacement field because:

1. A load is applied (`*CLOAD`).  
2. Node 1 is fully constrained (`*ENCASTRE`), eliminating the six rigid‑body modes.  
3. The stiffness matrix is now full rank, so Abaqus solves a non‑singular linear system.

\[
K\,U = F ,
\]

with  

* **F = 0** (no `*CLOAD`, `*DLOAD`, `*GRAVITY`, …)  
* **K** still contains the six rigid‑body modes (the stiffness matrix is singular because nothing restrains the model).

For a homogeneous system with a singular matrix the only mathematically admissible solution is  

\[
U \approx 0\;(\text{≈ 1 × 10⁻¹⁶ in double precision}),
\]

so Abaqus writes “0.000000E+00” (or a round‑off value) for every node.
