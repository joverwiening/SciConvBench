**简要结论**  
打开的 *.odb* 中只有 0（或 1e‑16 量级的数）是因为 **该模型在静力分析中没有施加任何载荷，也没有约束边界**。在 Abaqus 中静力求解满足  

\[
K\,U = F
\]

其中  

* **F = 0**（没有 `*CLOAD`、`*DLOAD`、`*GRAVITY` 等载荷），  
* **K** 仍然保留六个刚体自由度（模型未被约束），导致刚度矩阵奇异。  

对一个齐次且奇异的线性系统，唯一的数值解就是 **U≈0**（在双精度下约为 1 × 10⁻¹⁶），因此所有节点的位移都显示为 `0.000000E+00`（或极小的舍入误差）。

---

## 1. 为什么必然得到零位移

| 缺失的关键卡片 | 对线性方程的影响 |
|----------------|-------------------|
| **载荷** (`*CLOAD`, `*DLOAD`, `*GRAVITY` …) | 右端项 **F** 为 0 |
| **约束** (`*ENCASTRE`, `*DISPLACEMENT`, `*BOUNDARY` …) | 刚度矩阵 **K** 仍含六个刚体模态 → **K** 为奇异矩阵 |
| **Abaqus 对奇异系统的处理** | 在 *.msg* 或 *.log* 中给出 “STIFFNESS MATRIX IS SINGULAR” 警告，并把位移解强制为零（仅有数值舍入误差） |

> **示例警告**  
> ```
> WARNING: THE MODEL IS UNCONSTRAINED. THE STIFFNESS MATRIX IS SINGULAR.
>          THE SOLUTION WILL BE SET TO ZERO DISPLACEMENTS.
> ```

## 3. 若需要得到非零位移，必须补充以下内容

| 目标 | 在 `*STEP` 块中应加入的卡片 |
|------|------------------------------|
| **施加载荷** | `*CLOAD`（点载荷），`*DLOAD`（分布载荷），`*GRAVITY`，`*PRESCRIBED FIELD` 等 |
| **消除刚体自由度** | 至少三组相互独立的约束，使六个刚体模态被约束。例如：<br>`*ENCASTRE, NSET=FIXED`（单点全部 6 自由度）<br>`*DISPLACEMENT, NSET=SUPP1, DOF=1,2`（第二点固定 X、Y）<br>`*DISPLACEMENT, NSET=SUPP2, DOF=3`（第三点固定 Z） |
| **定义分析步** | ```*STEP, name=Step-1, nlgeom=NO<br>*STATIC<br>   …（载荷 + 约束）…<br>*END STEP``` |

### 最小可运行示例（静态悬臂梁）

```abaqus
*Heading
** 简单悬臂梁 – 静态分析
*Preprint, echo=NO, model=NO, history=NO, contact=NO

*Part, name=BEAM
*Node
1, 0., 0., 0.
2, 10., 0., 0.
*Element, type=B31
1, 1, 2
*End Part

*Assembly, name=ASSEMBLY
*Instance, name=BEAM-1, part=BEAM
*End Instance
*End Assembly

*Material, name=STEEL
*Elastic
210000., 0.3
*Beam Section, elset=EALL, material=STEEL, section=RECT
0.1, 0.1   ; (高度, 宽度)

*Step, name=Step-1, nlgeom=NO
*Static
** 在节点 2 施加向下的 Y 方向集中力
*Cload
2, 2, -1000.          ; 节点 2, DOF 2 (Y), 力值 -1000 N
** 完全固定节点 1（encastre），消除所有刚体自由度
*Encastre
1,
*End Step
```

运行后，`U` 场将出现非零位移（例如节点 2 在 Y 方向的下沉），因为：

1. **加载**：`*CLOAD` 给结构施加了外力。  
2. **约束**：`*ENCASTRE` 完全固定了节点 1，消除了刚体自由度。  
3. **矩阵满秩**：刚度矩阵不再奇异，Abaqus 能求得唯一的非零位移解。
