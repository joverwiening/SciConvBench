Use FEniCS legacy (dolfin) to solve a small‑strain linear elasticity problem in 2‑D plane‑stress.  
Create a rectangular domain of width 4.0 and height 1.0 with a circular hole of radius 0.5 centred at (1.0, 0.5).  
Generate a mesh with a characteristic resolution of about 72 divisions along the longer side of the rectangle.  
Define a second‑order (P2) vector Lagrange function space for the displacement field.  
Use material parameters Young’s modulus E = 210 000 and Poisson’s ratio ν = 0.3 and apply the reduced plane‑stress constitutive law with unit thickness.  
Impose the displacement boundary condition u = 0 on the left edge (x = 0).  
Apply a uniform downward traction of magnitude 1e5 (per unit thickness) on the right edge (x = 4.0).  
Set body forces to zero.  
Formulate the variational problem for static equilibrium, assemble the linear system, and solve it with a direct linear solver.  
Post‑process the solution to compute the von Mises stress field.  
Save the displacement vector field and the von Mises stress scalar field to output files (e.g., XDMF or VTK) for visualization.
