## 10️⃣  Step definition – static analysis with large deformation  

```text
*STEP, INC=100000, NLGEOM
.5E-5, .5E-5
*END STEP
```

* `*STEP` starts a new analysis step.  
  * `INC=100000` – maximum number of increments that Abaqus may use in this step.  
  * `NLGEOM` – **N**on‑**L**inear **GEOM**etry flag; tells Abaqus to include geometric (large‑deformation) effects.  
* The line immediately after `*STEP` (`.5E-5, .5E-5`) is the ***STATIC** keyword (the keyword itself can be omitted; Abaqus assumes a static step when the first line after *STEP contains two numbers).  
  * The two numbers are **initial time increment** and **total step time**.  
  * Here both are `5 × 10⁻⁶ s`. This means the step will start with a very small increment (5 µs) and the total duration of the step is also 5 µs.  
  * Because the total time is equal to the initial increment, Abaqus will try to finish the step in a **single increment** (unless the solution does not converge, in which case it will automatically reduce the increment).  

* `*END STEP` terminates the step definition.

## 12️⃣  Common “gotchas” that you may run into  

1. **Elastic constants missing** – Abaqus will stop with an error like  
   `ERROR: No elastic constants defined for material EL`.  
   Add, for example:  

   ```text
   *ELASTIC
   210000., 0.30
   ```

   (E = 210 GPa, ν = 0.30 for steel, assuming the same unit system).

2. **No loads / constraints** – The model will produce a trivial solution (zero displacement).  
   Typical constraints for a cantilever‑type block would be:  

   ```text
   *BOUNDARY
   N1, 1, 1, 0.0          ; fix X‑translation of node 100 (or a reference point)
   LAST, 1, 3, 0.0        ; fix all three DOFs of the nodes at the far end
   ```

   Or a pressure/force using the amplitudes you defined:

   ```text
   *CLOAD
   N1, 1, 1.0, A1         ; apply a prescribed displacement in X at node 100
   ```

3. **Output** – If you want stress, strain, or reaction forces, add an `*OUTPUT` block, e.g.:

   ```text
   *OUTPUT, FIELD, VARIABLE=PRESELECT
   *OUTPUT, HISTORY, VARIABLE=PRESELECT
   ```

4. **Large‑deformation step with a single increment** – Because the total step time equals the initial increment, Abaqus will try to solve the whole step in one increment.  
   If the problem is highly non‑linear (contact, plasticity, etc.) you will almost certainly need a **longer step time** (e.g. `0.0, 1.0`) and a **minimum increment** that is much smaller than the total time (e.g. `0.0, 1.0, 1e‑5`).  
   The `INC=100000` limit is generous, but the solver will still be forced to use a single increment unless convergence fails.

5. **Surface definition for contact** – If you later intend to use `CN7` as a contact surface, you would need a surface definition, e.g.:

   ```text
   *SURFACE, TYPE=ELEMENT, NAME=INTF
   B1, S1   ; S1 is the side of the brick that corresponds to the node set CN7
   ```

   (The side label `S1` follows the C3D20 ordering; you can also use `*ELEMENT, TYPE=C3D20, ELSET=...` together with `*SURFACE, TYPE=ELEMENT, NAME=...`.)

* Because **no loads or boundary conditions are defined**, the model will simply sit idle – the only possible response would be a rigid‑body motion (which is suppressed by any constraints you add later).
