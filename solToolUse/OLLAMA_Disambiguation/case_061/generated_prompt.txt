**Abaqus *.inp* – what to change and where to add**

---

### 1️⃣ Tiny fixes (must be done first)

| # | What to edit | Replace **exactly** with the lines below | Why |
|---|--------------|------------------------------------------|-----|
| 1 | **Material** – engineering constants need nine numbers | ```*ELASTIC, TYPE=ENGINEERING CONSTANTS```<br>```210000., 210000., 210000., 0.30, 0.30, 0.30, 80000., 80000., 80000.``` | Abaqus aborts if the list is not nine values. |
| 2 | **Section** – be sure the element‑set name contains **all** your elements | ```*SHELL SECTION, ELSET=Eall, MATERIAL=MyMat```  *(or `*SOLID SECTION, ELSET=Eall, MATERIAL=MyMat` if you use solid elements)* | The section must be attached to the correct elements. |
| 3 | **Every `*BOUNDARY` line** – add the missing fourth field (prescribed value) | ```<node>, <dof>, <dof>, 0.```  *(replace `<node>` and `<dof>` with the numbers you already have)* | Abaqus expects four fields; a three‑field line is a syntax error. |

*How to find them*: open the *.inp* in any text editor and **Ctrl + F** for `*ELASTIC, TYPE=ENGINEERING CONSTANTS`, `*SHELL SECTION`, `*SOLID SECTION` and `*BOUNDARY`. Replace the lines **exactly** as shown.

---

### 2️⃣ New blocks – paste **once**  

Insert the three blocks **after the last material/section definition** and **outside any existing `*STEP … *END STEP` pair** (i.e. before the first `*STEP` or after the last one).

```abaqus
** -------------------------------------------------
** 1) Element set that contains the top‑layer faces
** -------------------------------------------------
*ELSET, ELSET=Etop
1, 529, 1               ! <-- replace with the IDs of the top‑layer elements
                         ! (you can also use a range, e.g. 1, 10000, 1)

** -------------------------------------------------
** 2) Surface that uses the outermost ply (S1) of those elements
** -------------------------------------------------
*SURFACE, TYPE=ELEMENT, NAME=TopSurf
Etop, S1                ! S1 = outermost ply of the composite lay‑up

** -------------------------------------------------
** 3) Load step – uniform pressure on the top surface
** -------------------------------------------------
*STEP, NAME=PressStep, NLGEOM=YES
*STATIC
*DLOAD
TopSurf, P, 1.0e-3      ! <-- change 1.0e-3 to the pressure you need (same units as the material)
*END STEP
```

**What to edit inside the blocks**

| Block | What to edit | Example |
|-------|--------------|---------|
| `*ELSET, ELSET=Etop` | List **all element IDs** whose outer face (S1) must be pressurised. Use a range (`first, last, increment`) or a comma‑separated list. | `1, 529, 1` → `1, 1000, 1` if elements 1‑1000 belong to the top surface. |
| `*DLOAD` line | Replace `1.0e-3` with the actual pressure magnitude you want (MPa, Pa, etc.). | `TopSurf, P, 2.5e-2` for 0.025 MPa. |

If you already have a step after the one that contains your original loads, you may paste the three blocks **after that step**; they will simply run as an additional step.

### 3️⃣ TL;DR – only the lines you really need to add/modify

```abaqus
*ELASTIC, TYPE=ENGINEERING CONSTANTS
210000., 210000., 210000., 0.30, 0.30, 0.30, 80000., 80000., 80000.

*BOUNDARY
<node>, <dof>, <dof>, 0.          ! (add the missing 4th field to every line)

*ELSET, ELSET=Etop
1, 529, 1                         ! (or your actual top‑surface element range)

*SURFACE, TYPE=ELEMENT, NAME=TopSurf
Etop, S1

*STEP, NAME=PressStep, NLGEOM=YES
*STATIC
*DLOAD
TopSurf, P, 1.0e-3               ! (change to required pressure)
*END STEP
```

### 4️⃣ Quick sanity‑check after editing  

1. **Syntax check** – In Abaqus/CAE choose **File → Import → Model** (or run `abaqus job=MyJob input=MyFile.inp`). Abaqus will stop at the first syntax error and report the line number.  
2. **Model tree** – After a successful import you should see a new surface called **TopSurf** under *Assembly → Surfaces*.  
3. **Step manager** – You will now have a step named **PressStep** with a *DLOAD* entry that references *TopSurf*.  

If Abaqus still aborts, **copy the exact error message (including the line number)** and paste it back here – we’ll pinpoint the remaining issue in seconds.

---

### What to do now  

1. Open your *.inp* file in a plain‑text editor.  
2. Apply the three tiny fixes (material line, section line, boundary lines).  
3. Scroll to the end of the file (or just after the last `*STEP … *END STEP`).  
4. Paste the three new blocks exactly as shown.  
5. Save the file and run the job again.

**If any error appears, copy the error text and line number and send it back here – we’ll troubleshoot together.** Good luck!
