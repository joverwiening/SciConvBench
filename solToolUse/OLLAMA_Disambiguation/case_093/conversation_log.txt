| **STEP line** | Only step‑level options (`NLGEOM`, `MAXINC`, `NAME`, `TIME`, …). **Never** put `INC`, `STEP`, or `TIME` here. |
| **Analysis keyword** | Must follow `*STEP` immediately (`*STATIC`, `*DYNAMIC`, `*BUCKLE`, …). Include `STEP=` (or `TIME=` for dynamics) **and** an initial increment (`INC=`) plus a limit (`MAXINC=` or `MAXLPF=`). |
| **Element definition** | Every `*ELEMENT` line needs a `TYPE=` that matches the element topology (e.g., `C3D20` for a 20‑node brick, `C3D8` for an 8‑node brick, etc.). |
| **Loads / BCs** | Use `NSET=` (or `ELSET=`) when applying loads: `*CLOAD, NSET=MySet`. The data line is `node‑or‑DOF, magnitude`. |
| **Material → Section** | `*MATERIAL` must appear **before** any `*SOLID SECTION` that references it. |
| **GENERATE syntax** | `first, last, step` – no extra commas, no missing values. |
| **Comments** | Lines beginning with `**` are ignored – safe for notes. |
| **Step termination** | End each step with `*END STEP`. The file should finish with a blank line or `*END`. |
| **NLGEOM flag** | Write `NLGEOM=YES` (or `NO`) on the `*STEP` line if large‑deformation effects are needed. |
| **Increment control** | Provide an initial increment (`INC=`) and a maximum (`MAXINC=`) to avoid uncontrolled step growth. |
| **Optional output** | Add `*OUTPUT, FIELD, VARIABLE=PRESELECT` (or custom variables) **inside** the step after the loads if you need extra results. |
| **Mesh changes** | If you edit the mesh, update the `*ELEMENT` connectivity and the generated `ELSET`/`NSET` ranges accordingly. |
| **Check line numbers** | When Abaqus reports an error, note the line number it cites and verify that line against this checklist – most aborts stem from one of the items above. |
