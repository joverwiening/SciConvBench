`*BOUNDARY, FIXED` (or `*BOUNDARY,FIXED`) is a special‑purpose boundary‑condition that **may be used only in an explicit‑dynamic step** (`*DYNAMIC, EXPLICIT`).  
All the steps in your model are declared as static (`*STATIC`). When Abaqus reads the second step it encounters a `*BOUNDARY,FIXED` card that is illegal for a static (or implicit‑dynamic) analysis, so the job aborts with  

```
The boundary condition defined on the node set LOAD in step 2 is not
compatible with the analysis type.
```

### How to fix it
Replace the illegal `*BOUNDARY,FIXED` card with a boundary condition that is allowed in static steps. Both of the following forms fully restrain the node set **FIX** (U1 = U2 = U3 = 0) and are accepted by any `*STATIC` step.

**Option 1 – Encastre (shortest form)**  

```abaqus
*BOUNDARY, ENCASTRE
FIX          ! name of the node set to be fully restrained
```

**Option 2 – Generic displacement form**  

```abaqus
*BOUNDARY, TYPE=DISPLACEMENT
FIX, 1, 3, 0.0   ! prescribe U1 = U2 = U3 = 0
```

Either choice gives the same physical constraint.

### Minimal corrected input (only the changed lines)

```abaqus
*HEADING
Cantilever beam – static analysis (fixed nodes)

*PREPRINT, ECHO=YES

*NODE
...                     ! (your node list – unchanged)

*NSET, NSET=FIX
    97, 96, 95, 94, 93, 20, 19, 18, 17, 16, 15,
    14, 13, 12, 11, 10, 9, 4, 3, 2, 1

*ELEMENT, TYPE=C3D20R, ELSET=Eall
...                     ! (your element list – unchanged)

*MATERIAL, NAME=EL
*ELASTIC
210000., 0.3            ! (your material data)

*SOLID SECTION, ELSET=Eall, MATERIAL=EL

*STEP
*STATIC
*BOUNDARY, ENCASTRE     ! <-- legal in static steps
FIX                     ! node set to be fully restrained
*END STEP

*STEP
*STATIC
*CLOAD
LOAD, 1, -500.0        ! example point load on node set LOAD
*END STEP
```

*If you prefer the generic displacement form, replace the two lines inside the first step with*

```abaqus
*BOUNDARY, TYPE=DISPLACEMENT
FIX, 1, 3, 0.0
```

Both alternatives impose the same constraint (U1 = U2 = U3 = 0) and are valid for a static analysis.

### Quick checklist – avoid the same mistake again

| What to verify                              | Correct setting |
|---------------------------------------------|-----------------|
| Use of `*BOUNDARY,FIXED`                    | Only with `*DYNAMIC, EXPLICIT`. |
| Static or implicit‑dynamic steps             | Use `*BOUNDARY, ENCASTRE` **or** `*BOUNDARY, TYPE=DISPLACEMENT`. |
| Node‑set definition                         | Must be defined **before** it is referenced. |
| Load application                            | Apply loads (`*CLOAD`, `*DLOAD`, …) **after** the restraints are defined. |
| Analysis‑type consistency                   | All cards in a step must match the step type (`*STATIC`, `*DYNAMIC, EXPLICIT`, `*DYNAMIC, IMPLICIT`). |

**Bottom line:** Replace the illegal `*BOUNDARY,FIXED` card with either `*BOUNDARY, ENCASTRE` or the generic displacement form. After this change the input file is compatible with the static analysis type, and Abaqus will run without the reported error.
