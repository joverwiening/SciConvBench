Use FEniCS legacy (dolfin) to solve a 2D small‑strain orthotropic elasticity problem in plane stress.

Define the rectangular domain Ω = (0, 1.0) m × (0, 0.20) m.

Create a structured rectangular mesh with 50 elements in the x‑direction and 25 elements in the y‑direction.

Define the displacement field u = (u_x, u_y) as a vector‑valued function in the appropriate function space.

Material properties in the local material axes:
E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, ν12 = 0.25.
Compute ν21 = ν12·E2/E1 = 0.0625.

Form the plane‑stress reduced stiffness matrix Q in the local axes:
Q11 = E1/(1‑ν12·ν21), Q22 = E2/(1‑ν12·ν21), Q12 = ν12·E2/(1‑ν12·ν21), Q66 = G12.

Rotate the stiffness matrix to the global x‑y axes using a rotation angle θ = 30° anticlockwise (θ = π/6 rad) and the standard transformation for orthotropic tensors.

Define the strain tensor ε(u) = sym(∇u) and the stress tensor σ = C : ε, where C is the rotated stiffness matrix.

Apply boundary conditions:
- Bottom edge y = 0: u_x = 0 and u_y = 0 (essential Dirichlet conditions).
- Top edge y = 0.20: apply a uniform downward traction t = (0, –10 MPa) as a Neumann boundary condition (interpreted as line traction per unit thickness).
- Left and right edges x = 0 and x = 1.0: traction‑free (natural Neumann condition).

Formulate the variational problem: find u ∈ V such that
∫_Ω ε(v) : σ(u) dx = ∫_{Γ_top} v · t ds for all test functions v ∈ V₀ (V₀ respects the Dirichlet constraints).

Assemble the linear system and solve it with a direct linear solver (e.g., MUMPS).

Post‑process:
- Compute the von Mises stress σ_vm = sqrt(σ_xx² – σ_xx·σ_yy + σ_yy² + 3σ_xy²) at each mesh point.
