**Why the warning appears**

`*EXPANSION` defines the coefficient of thermal expansion (CTE) of a material.  
For every expansion entry Abaqus must know the temperature at which that CTE
was measured – the **reference temperature**.  
If the keyword is written without the optional field  

```text
*EXPANSION, ZERO = <reference‑temperature>
```  

Abaqus cannot find a reference temperature, assumes **0 °C** and prints  

```
THE USER HAS NOT DEFINED A REFERENCE TEMPERATURE FOR EXPANSION.
THE REFERENCE TEMPERATURE IS SET TO 0.0.
```  

The warning disappears as soon as a valid `ZERO=` value is supplied.

---

## Complete material definition (no warning)

| Keyword (order)                     | Required? | What it supplies                                   | Remarks |
|-------------------------------------|-----------|----------------------------------------------------|---------|
| `*MATERIAL, NAME=`                  | Yes       | Starts a new material block                        | Name is later used in the section definition |
| `*ELASTIC`                          | **Yes** (if the material also has `*PLASTIC` or `*EXPANSION`) | Young’s modulus **E** and Poisson’s ratio **ν** (linear‑elastic constants) | Must be the **first** card after `*MATERIAL` |
| `*PLASTIC`                          | Optional (only when a yield curve is needed) | σ‑εp pairs (yield stress – plastic strain)        | Omit for a purely elastic‑thermal material |
| `*EXPANSION, ZERO=<Tref>`           | **Yes** when thermal expansion is used | Coefficient of thermal expansion **α** and the temperature at which α was measured (`Tref`) | `ZERO=` may be any temperature (commonly 0 °C → `ZERO=0.0`) |
| `*SOLID SECTION` (or `*SHELL SECTION`, …) | Yes – to assign the material to a region of the model | Links the material name to an element set (`ELSET=`) | Must appear after the material cards |

**Recommended order (works for every Abaqus version)**  

```
*ELASTIC
*PLASTIC   (if needed)
*EXPANSION (if needed)
```

Keeping this order avoids the “material definition incomplete” error that can
appear when the cards are read out of sequence.

## Ready‑to‑copy example

*(Replace the numbers with the actual data for your alloy; units can be MPa for
stresses and °C for temperature, or any consistent system.)*

```abaqus
*MATERIAL, NAME=MY_MATERIAL
*ELASTIC
210000., 0.30                ! Young’s modulus (MPa) and Poisson’s ratio
*PLASTIC
800.,   0.0                  ! σy (MPa) , εp (plastic strain)
1600.,  0.10                 ! σ2 (MPa) , εp2
*EXPANSION, ZERO=0.0         ! Reference temperature = 0 °C (change if needed)
12.0E-6                      ! Coefficient of thermal expansion α (1/°C)
*SOLID SECTION, ELSET=EALL, MATERIAL=MY_MATERIAL
```

### What each line does

| Line                              | Purpose |
|-----------------------------------|---------|
| `*MATERIAL, NAME=…`               | Starts a new material block. |
| `*ELASTIC`                        | Supplies the mandatory linear‑elastic constants. |
| `*PLASTIC`                        | Gives the yield curve (optional – delete if not needed). |
| `*EXPANSION, ZERO=0.0`            | Provides the CTE **and** an explicit reference temperature, eliminating the warning. |
| `*SOLID SECTION …`                | Assigns the material to the element set `EALL`. |

### Quick pre‑run checklist

1. **Elastic card present?** – Yes (`*ELASTIC`).  
2. **Reference temperature supplied?** – Yes (`ZERO=`).  
3. **Cards are in the correct order?** – `*ELASTIC → *PLASTIC → *EXPANSION`.  
4. **No data on the same line as a keyword** (e.g., `*BOUNDARY` must be on its own line).  
5. **Units are consistent** (E in MPa if stresses are in MPa, temperature in °C).  
6. **Material name matches the name used in the section definition** (`MATERIAL=MY_MATERIAL`).  

When all of the above are satisfied, Abaqus reads the material without
producing the “reference temperature for expansion” warning, and the analysis
runs correctly using the thermal‑expansion data.
