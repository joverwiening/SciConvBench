`*BOUNDARY, TYPE=DISPLACEMENT` tells Abaqus that the next number is a **reference‑point ID**.  
In your model the number **5** is a **node** (it belongs to the node set **LAST**), and no reference point with ID = 5 has been defined. Consequently Abaqus stops with  

```
The specified boundary reference point 5 does not exist.
```

## Prescribing a displacement to a **node set**

Use the *node‑set* form of the `*BOUNDARY` command (or its short‑hand equivalent).  
The command must contain:

* `NSET=` – name of the node set that holds the nodes you want to control.  
* `DOF=` – the global degree of freedom to constrain (1‑X, 2‑Y, 3‑Z, 4‑RX, 5‑RY, 6‑RZ).  
* The value of the prescribed displacement (or rotation).

### Full three‑line form (most explicit)

```abaqus
*STEP, NLGEOM=YES
*BOUNDARY, NSET=LAST, DOF=2
-2.0
*END STEP
```

* `NSET=LAST` – the set that contains nodes 5, 6, 7, 8, 22, 25, 28, 31, 100.  
* `DOF=2` – global Y‑translation.  
* `-2.0` – prescribed Y‑displacement (applied to **all** nodes in the set).

### Short‑hand (single‑line) equivalent

```abaqus
*BOUNDARY, NSET=LAST, 2, -2.0
```

Both snippets give exactly the same result—a –2.0 unit Y‑displacement applied to every node in the set **LAST**—and they eliminate the “reference point does not exist” error.

## If you need additional constraints

| Desired condition | Full three‑line form | Short‑hand form |
|-------------------|----------------------|-----------------|
| Fix all three translations (encastre) | `*BOUNDARY, NSET=LAST, DOF=1, 0.0`<br>`*BOUNDARY, NSET=LAST, DOF=2, 0.0`<br>`*BOUNDARY, NSET=LAST, DOF=3, 0.0` | `*BOUNDARY, NSET=LAST, 1,2,3, 0.0` |
| Prescribe a rotation about Z (DOF = 6) | `*BOUNDARY, NSET=LAST, DOF=6, 0.5` | `*BOUNDARY, NSET=LAST, 6, 0.5` |
| Time‑dependent displacement (using an amplitude) | `*BOUNDARY, NSET=LAST, DOF=2, AMPLITUDE=DispAmp`<br>`-2.0` | Same, just add `AMPLITUDE=` |
| Apply to a few nodes listed explicitly (instead of a set) | `*BOUNDARY, NODE=5,6,7,8,22,25,28,31,100, DOF=2`<br>`-2.0` | Not recommended for large groups; use a set. |

* Do **not** use `TYPE=DISPLACEMENT` when the condition is to be applied to nodes.

```abaqus
*BOUNDARY, NSET=LAST, DOF=2
-2.0
```

or the equivalent one‑line version

```abaqus
*BOUNDARY, NSET=LAST, 2, -2.0
```

These commands correctly apply the –2.0 unit Y‑displacement to every node in the set **LAST** and eliminate the “reference point does not exist” error.
