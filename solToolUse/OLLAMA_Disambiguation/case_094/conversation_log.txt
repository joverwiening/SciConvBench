## How to prescribe a displacement on a **node set**  

To apply a displacement (or any other kinematic constraint) to a group
of nodes you must use the *node‑set* form of the `*BOUNDARY` command.
The syntax is:

```
*BOUNDARY, NSET=<node‑set name>, DOF=<dof‑number>
<value>
```

* `NSET=` – name of the node set that contains the nodes to be
  constrained (here `LAST`).
* `DOF=` – the translational or rotational degree of freedom you want
  to control  
  (1 = X‑translation, 2 = Y‑translation, 3 = Z‑translation,
  4‑6 = rotations about X‑Y‑Z respectively).
* The line that follows gives the prescribed value (displacement,
  rotation, or zero for a fixed DOF).  
  The same value is applied to **all** nodes in the set.

---

### Example – prescribe a Y‑direction displacement of –2.0 units
to every node in the set `LAST`

```abaqus
*STEP, NLGEOM=YES
*BOUNDARY, NSET=LAST, DOF=2
-2.0
*END STEP
```

*All nodes 5, 6, 7, 8, 22, 25, 28, 31, 100 (the members of `LAST`) will move
–2.0 in the global Y‑direction.*
