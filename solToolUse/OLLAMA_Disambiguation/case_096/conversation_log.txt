## 1.  Material definition – you need an *ELASTIC* entry

A material that has **elastic → plastic → creep** behaviour must contain an *ELASTIC* card **before** the *PLASTIC* and *CREEP* cards.  
If you omit *ELASTIC* Abaqus will stop with the error *“Missing elastic data for material …”*.

```abaqus
*MATERIAL,NAME=HY
*ELASTIC
210000.,0.3                ! E (MPa) and ν – change to your values
*PLASTIC
0.,0.
0.,10.
*CREEP,TYPE=POWER          ! TYPE=POWER is the default, you may omit it
1.e-10,5.,0.               ! A  n  m   (A·σⁿ·tᵐ)
```

*Explanation of the creep line*  

| Symbol | Meaning (POWER law) |
|--------|---------------------|
| **A**  | Creep coefficient (MPa⁻ⁿ s⁻¹) |
| **n**  | Stress exponent |
| **m**  | Time‑temperature exponent (often 0) |

Your line `1.e-10,5.,0.` is syntactically correct for a power‑law creep model; just be sure you really want **A = 1 × 10⁻¹⁰**, **n = 5**, **m = 0**.

---

## 2.  Single‑point constraint (SPC)

In **Abaqus/Standard** (the solver you are using – you have `*STEP,NLGEOM`), displacement constraints are introduced with the **`*BOUNDARY`** keyword, **not** with `*SPC`.  
`*SPC` is only for Abaqus/Explicit.

### 2.1 Define a node set that contains the “top” node(s)

If you want to constrain **one node only** (say node 100) you can keep the set you already have:

```abaqus
*NSET,NSET=TOP
100
```

If you want to constrain a whole face (e.g. all nodes on the top surface) create a set that contains those nodes, e.g.

```abaqus
*NSET,NSET=TOP
100,101,102,103   ! <-- replace with the actual top‑face node numbers
```

### 2.2 Apply the constraint in the step

The syntax of `*BOUNDARY` is

```
*BOUNDARY
node‑or‑set, dof‑start, dof‑end, value
```

* `dof‑start` / `dof‑end` = 1 (U1), 2 (U2), 3 (U3) for the three translational DOFs.  
* `value` = prescribed displacement (0 for a fixed point).

**Example – fully encastre the top node (all three translations = 0):**

```abaqus
*BOUNDARY
TOP, 1, 3, 0.0
```

If you only need to fix the **vertical (Z) direction**, use DOF = 3 only:

```abaqus
*BOUNDARY
TOP, 3, 3, 0.0
```

Place the `*BOUNDARY` line **inside the same step** where you apply the loads (or in a separate step if you prefer).  
A minimal step block would look like this:

```abaqus
*STEP,INC=1000,NLGEOM
*VISCO,CETOL=8.e-4
0.001,0.001
*BOUNDARY
TOP, 1, 3, 0.0          ! <-- SPC (fixed point)
*CLOAD,AMPLITUDE=A1
N4,3,80.33333
N5,3,5.0                ! <-- example load, keep your original values
*END STEP
```

> * `*BOUNDARY` fixes the translational DOFs; because you are using a solid (continuum) element there are no rotational DOFs, so the line above completely restrains the node.  
> * The model now has a well‑defined elastic response, a plastic flow rule, and a creep law – all of which are read from the *MATERIAL* definition.

## 5.  Common pitfalls you may have already hit

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| **“The constraint is not applied”** | Used `*SPC` in a Standard step or placed the `*BOUNDARY` line **outside** the step. | Use `*BOUNDARY` **inside** the step (or a separate step). |
| **“Missing elastic data for material HY”** | No *ELASTIC* card. | Add the *ELASTIC* entry as shown above. |
| **“Creep data not recognized”** | `*CREEP` placed in the *SOLID SECTION* or missing `TYPE=` keyword (only needed for non‑POWER laws). | Keep `*CREEP` **inside the material definition**; the line you wrote is fine for a POWER law. |
| **“No convergence – rigid body motion”** | No point (or face) fixed → model can translate/rotate as a whole. | Add the `*BOUNDARY` line (or a set of bottom nodes) to lock the model. |
| **“Too many DOFs for a node set”** | Using a set that contains nodes belonging to different parts (e.g., a face that also has a symmetry plane). | Make sure the set you use for `*BOUNDARY` contains only the nodes you really want to constrain. |
