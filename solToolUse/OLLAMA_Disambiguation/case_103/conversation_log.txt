## 2.  Fixing the base (encastre)

For a solid model the only kinematic DOFs are the three translations **U1, U2, U3**.  
The simplest way to lock the base is the built‑in `*ENCASTRE` command:

```abaqus
*BOUNDARY
CN7, ENCASTRE
```

If you prefer the long form, it is equivalent to three separate `*BOUNDARY` lines:

```abaqus
*BOUNDARY
CN7, 1, 1, 0.0   ! U1 = 0
CN7, 2, 2, 0.0   ! U2 = 0
CN7, 3, 3, 0.0   ! U3 = 0
```

Both ways give the same result – the whole root of the cantilever is completely restrained.

---

## 3.  Loading the free end

### 3‑a.  Point (concentrated) load on the tip nodes

If you really want a **single resultant force** that is shared by the nodes in `LAST`, you can use the `*CLOAD` command.  
Assume you want a vertical (‑Y) load of **‑10 000 N** (negative because the beam points in the +Y direction).  

```abaqus
*CLOAD
LAST, 2, -10000.0
```

* `LAST` – the node set you already defined.  
* `2` – the degree of freedom (1 = X, 2 = Y, 3 = Z).  
* `-10000.0` – magnitude of the force (N).  

If you prefer to distribute the load equally among the tip nodes, you can split the magnitude yourself, e.g.

```abaqus
*CLOAD
5, 2, -2000.0
6, 2, -2000.0
7, 2, -2000.0
8, 2, -2000.0
22,2, -2000.0
25,2, -2000.0
28,2, -2000.0
31,2, -2000.0
100,2, -2000.0
```

(10 tip nodes → 10 000 N / 10 = 1 000 N each; the numbers above are just an illustration.)

### 3‑b.  Uniform pressure on the end face (recommended)

Applying a pressure to the **whole end surface** is usually more realistic for a cantilever and avoids the artificial stress‑singularity that a point load can create.  

#### 3‑b‑i.  Define the end surface

First you need a **surface definition** that tells Abaqus which element faces belong to the tip.  
Because you are using 20‑node reduced‑integration bricks (`C3D20R`), each element has 6 faces.  
The face that lies on the free end is the one that contains the nodes you listed in `LAST`.  
In the element list the tip face is **face 3** (the face opposite the “root” face).  

```abaqus
*SURFACE, TYPE=ELEMENT, NAME=END_FACE
EALL, 3
```

`EALL` is the element set that already contains all 32 elements.  
`3` is the face number (see Abaqus Element Library – C3D20R, face 3 is the one with nodes 5‑8‑31‑...‑100 in your element definition).  
If you are not 100 % sure about the face number, you can also create the surface by **node list**:

```abaqus
*SURFACE, TYPE=NODE, NAME=END_FACE
LAST
```

Both definitions are equivalent for a solid brick; the node‑based version is easier to read.

#### 3‑b‑ii.  Apply a pressure

Now the pressure load is a single line:

```abaqus
*DLOAD
END_FACE, P, 1.0
```

* `END_FACE` – the surface you just created.  
* `P` – pressure (force per unit area).  
* `1.0` – magnitude (N/mm² if you are using the default SI units).  

If you want a **total resultant force** of 10 000 N, compute the pressure as  

\[
p = \frac{F_{\text{total}}}{A_{\text{tip}}}
\]

where `A_tip` is the area of the end face (you can obtain it from a quick *PRE‑ANALYSIS* or from the geometry).  
Insert that value for `p` instead of `1.0`.

## 5.  A quick note on the anisotropic material definition

You used  

```abaqus
*ELASTIC, TYPE=ANISOTROPIC
180000.,390000.,200000.,210000.,220000.,230000.,440000.,250000.,
260000.,270000.,280000.,290000.,500000.
```

For **type = ANISOTROPIC** Abaqus expects **21 independent constants** (the full 6 × 6 stiffness matrix in Voigt notation).  
If you really need a fully general orthotropic material you only need **9 constants** (E₁,E₂,E₃, ν₁₂,ν₁₃,ν₂₃, G₁₂,G₁₃,G₂₃) and the keyword must be

```abaqus
*ELASTIC, TYPE=ORTHOTROPIC
E1, E2, E3, NU12, NU13, NU23, G12, G13, G23
```

If you intend to use a **general anisotropic** (21‑constant) model, you must supply the missing numbers, e.g.

```abaqus
*ELASTIC, TYPE=ANISOTROPIC
C11, C12, C13, C14, C15, C16,
C22, C23, C24, C25, C26,
C33, C34, C35, C36,
C44, C45, C46,
C55, C56,
C66
```

(Replace the `Cij` with the actual stiffness values in the same order as shown in the Abaqus documentation.)  
If you only have the 13 numbers you listed, they correspond to a **transversely isotropic** material; in that case the correct keyword is

```abaqus
*ELASTIC, TYPE=TRANSVERSE ISOTROPIC
E1, E2, NU12, G12, G13, G23
```

and you must supply **exactly 6 numbers**.  
So double‑check the material data you have and use the matching keyword; otherwise Abaqus will stop with an “invalid number of elastic constants” error.
