\(u_{0}^{(x)}(r,\theta) = r^{\,q}\,\bigl[ A\cos(q\theta) + B\sin(q\theta) \bigr]\) and

Create a vector‑valued Lagrange finite element space of appropriate order (e.g., degree 1) on the mesh.

Formulate the weak form: find \(u\in V\) such that \(\int_{\Omega} \sigma(u):\varepsilon(v)\,dx = 0\) for all test functions \(v\in V\) with homogeneous Neumann conditions on the crack faces.  
Apply Dirichlet boundary conditions on the outer square boundary using the exact displacement \(u_{0}\) evaluated at the boundary points.  
Assemble the linear system and solve it with the GMRES iterative solver preconditioned by an ILU (or PETSc ILU) preconditioner.
