**PickedSurf4** is an element‑type surface that is built from the element set **_PickedSurf4_S2**.  
The set is created with the `generate` option

```abaqus
*Elset, elset=_PickedSurf4_S2, generate
   1, 113, 1
```

which tells Abaqus to place **every element whose label runs from 1 to 113 with a step of 1** into the set.  
Consequently, provided the model actually contains them, the set `_PickedSurf4_S2` consists of the element IDs

```
1, 2, 3, … , 111, 112, 113
```

The surface definition that follows

```abaqus
*Surface, type=ELEMENT, name=PickedSurf4
_PickedSurf4_S2, S2
```

assigns **side S2** of each element in that set to the surface named **PickedSurf4**.

### Elements that belong to `PickedSurf4`

| Element ID | Surface side |
|------------|--------------|
| 1          | S2 |

**In short:** `PickedSurf4` = the S2 faces of every element whose label is between 1 and 113 (any numbers in that range that do not exist in the model are simply omitted).
