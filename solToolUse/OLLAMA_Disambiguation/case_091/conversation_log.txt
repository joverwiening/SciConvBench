Q: Which CalculiX command should I use to run the analysis: `ccx -i case_091` or `ccx case_091`?
A: **Answer:**  
Use the **`-i` option** – the correct command is  

```bash
ccx -i case_091
```

---

### Why `ccx -i case_091` is the proper way

| Aspect | `ccx -i case_091` | `ccx case_091` |
|--------|-------------------|----------------|
| **Official syntax** (as documented in the CalculiX User Manual) | ✔︎ Uses the `-i` flag to tell the solver which **input file** (`case_091.inp`) to read. | ✘ No flag; the program interprets the first argument as a **command‑line option**, not as an input file. |
| **Portability** | Works on all standard builds of CalculiX (both Linux and Windows). | Only works on some custom builds that have been patched to treat the first argument as an input file; not guaranteed. |
| **Error handling** | If the file is missing or the name is wrong, the solver prints a clear “cannot open input file” message. | May produce a cryptic “unknown option” error because the argument is parsed as an option. |
| **Clarity** | Explicitly shows that you are providing an **input file** (`-i`). | Ambiguous – a reader cannot tell whether you intended an option or a file. |
| **Future‑proof** | If CalculiX adds new command‑line options, the `-i` form will remain valid. | Could break if a new option with the same name is introduced. |

---

### How the command works

1. **Prepare the input file**  
   The solver expects a file named `case_091.inp` (the `.inp` extension is added automatically).  
   ```bash
   ls case_091.inp   # verify it exists
   ```

2. **Run the solver**  
   ```bash
   ccx -i case_091
   ```
   - `ccx` – the CalculiX **solver** executable.  
   - `-i` – tells the solver “**i**nput file”.  
   - `case_091` – the base name of the input file (without the `.inp` extension).

3. **Result files**  
   After the run finishes you will typically see:  
   - `case_091.dat` – results (displacements, stresses, etc.)  
   - `case_091.frd` – results in binary format for post‑processing (e.g., with **cgx** or **Paraview**)  
   - `case_091.log` – solver log (if you redirected output).

---

### Quick checklist before running

| ✅ Check | How to verify |
|--------|----------------|
| Input file exists (`case_091.inp`) | `ls case_091.inp` |
| Solver executable is in your `PATH` | `which ccx` (Linux/macOS) or `where ccx` (Windows) |
| Correct number of CPU cores (optional) | Add `-n <N>` after `-i` if you want parallel execution, e.g., `ccx -i case_091 -n 4` |
| Environment variables (e.g., `OMP_NUM_THREADS`) set if using OpenMP | `echo $OMP_NUM_THREADS` |

---

### Bottom line

- **Use `ccx -i case_091`** – it follows the documented, robust, and universally supported syntax for running a CalculiX analysis.  
- The form `ccx case_091` is **not** standard and may fail or behave unpredictably on most installations.  

Feel free to ask if you need help with additional options (e.g., parallel runs, memory limits, or post‑processing). Happy solving!
