## 1️⃣  Get the two source blocks from the original model  

| What you need | Where to find it |
|---------------|------------------|
| **Node block** – everything from the line `*NODE, NSET=GLOBAL` **up to** (but **not** including) the next line that starts with `*` | `case_052.inp` |
| **Element block** – everything from the line `*ELEMENT, TYPE=C3D15, ELSET=P3` **up to** (but **not** including) the next `*` line | `case_052.inp` |

**How to copy them**

1. Open **`case_052.inp`** in any plain‑text editor (Notepad++, VS Code, Sublime Text, …).  
2. **Node block**  
   * Click at the first character of `*NODE, NSET=GLOBAL`.  
   * Drag/select **downward** until the line **just before** the next line that begins with `*` (normally `*ELEMENT`).  
   * Press **Ctrl + C** (or right‑click → *Copy*).  
3. **Element block**  
   * Locate the line `*ELEMENT, TYPE=C3D15, ELSET=P3`.  
   * Select from that line **downward** until the line **just before** the next `*` keyword (e.g. `*ELSET`, `*BOUNDARY`, `*DLOAD`, …).  
   * Press **Ctrl + C**.

> **Do not edit anything in `case_052.inp`** – you are only copying.

## 4️⃣  Run the analysis  

Open a command prompt (or use the Abaqus/CAE Job Manager) and execute:


*If you prefer a pure batch run, replace `interactive` with `ask` or simply omit the last argument.*

Abaqus will generate the usual output files (`.odb`, `.dat`, `.msg`, …).

## 6️⃣  Troubleshooting checklist  

| Symptom | Most likely cause | Fix |
|---------|-------------------|-----|
| **All displacements are zero** | Node 10 or 78 missing from the `*NODE` block, or wrong IDs in `*BOUNDARY`. | Open `case_052_fixed.inp` → confirm that nodes 10 & 78 appear in the node list and that the `*BOUNDARY` lines reference those exact IDs. |
| **No reaction forces appear** | A later `*DLOAD` or `*CLOAD` overwrote the pressure. | Search the file for any extra `*DLOAD`/`*CLOAD` statements and comment (`**`) or delete them. |
| **Huge compressive stress on a “free” face** | Wrong faces were loaded (e.g., face 3 instead of faces 1 & 2). | In Abaqus/CAE, select element set `P3` → **Tools → Query → Surface** → verify that faces 1 & 2 are the two triangular wedge faces. |
| **Syntax error near line X** | A comma/space was lost while pasting. | Turn on “show invisible characters” in your editor. Ensure each node line is `id, x, y, z` and each element line is `id, n1, n2, …, n15` with **commas between every entry**. |
| **Job aborts with convergence problems** | Pressure sign opposite to intended direction (pulling the model apart). | Change the two `*DLOAD` magnitudes from `20.` to `-20.` and re‑run. |

If after these checks the results still look odd, **post the complete `case_052_fixed.inp`** (with the node and element blocks filled in) together with a short excerpt of the `.dat` file (or a screenshot of the `.odb` view). That will let anyone help you pinpoint the remaining issue.
