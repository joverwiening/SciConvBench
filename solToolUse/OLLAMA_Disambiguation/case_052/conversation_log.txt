## 1.  How to define the triangular faces of a C3D15 wedge

A C3D15 element has **three triangular faces** (faces 1‑3) and **three quadrilateral faces** (faces 4‑6).  
The local face numbers are:

| Face | Nodes (local numbering) |
|------|--------------------------|
| 1    | 1‑2‑3 (the “bottom” triangle) |
| 2    | 4‑5‑6 (the “top” triangle) |
| 3    | 1‑2‑4‑5 (first quad) |
| 4    | 2‑3‑5‑6 (second quad) |
| 5    | 3‑1‑6‑4 (third quad) |
| 6    | 1‑3‑2 (the “bottom” triangle **re‑ordered** – not used for pressure) |

For a pressure that acts **normal to the triangular faces** you normally need only faces **1** and **2**.  
The syntax for an element surface is:

```
*SURFACE, TYPE=ELEMENT, NAME=P1
  <element‑ID>, <face‑ID>
```

where `<face‑ID>` is the **local face number** (1‑6).  
If you want to apply the same pressure to *all* triangular faces of the first 24 elements (the lower half of the model) you can generate the surface set automatically:

```abaqus
*SURFACE, TYPE=ELEMENT, NAME=P1
17:40, 1   ! face‑1 of elements 17‑40
*SURFACE, TYPE=ELEMENT, NAME=P2
17:40, 2   ! face‑2 of elements 17‑40
```

(If you need both triangular faces on each element you can list both face‑IDs on the same line, e.g. `17:40, 1, 2`.)
