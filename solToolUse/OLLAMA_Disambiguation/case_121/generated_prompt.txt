### What was changed and why  

| # | Original problem | Fix applied | Why it matters |
|---|------------------|-------------|----------------|
| 1️⃣ | `*CONTACT PAIR … TYPE=NODE TO SURFACE` (invalid for pressure‑overclosure) | `TYPE=SURFACE TO SURFACE` | Pressure‑overclosure works only with surface‑to‑surface contact. |
| 2️⃣ | `Sslav,Smast` interpreted as *node‑set* + *surface* | Both `Sslav` and `Smast` are now **surfaces** (`*SURFACE`) and listed as `Sslav, Smast` in the contact pair | A surface‑to‑surface pair must contain two surfaces – slave then master. |
| 3️⃣ | Load lines used the non‑existent keyword `P5` | Changed to `P` (uniform pressure) | `P5` is not a valid load type; `P` correctly applies pressure. |
| 4️⃣ | `*CONTACT PRINT,NSET=Nall` referenced a set that does not exist | Replaced with `NSET=Nfix` (or any existing node set) | Prevents an abort caused by an undefined node set. |
| 5️⃣ | No increment control for a highly non‑linear step | Added `INC=0.01` on the `*STEP` line | Gives the solver a smoother start and improves convergence. |
| 6️⃣ | `*AMPLITUDE` block defined but never used (or used without being defined) | Keep the block **and** reference it (`AMPLITUDE=A1`) **or** delete both together. | Removes an unused definition and keeps the file tidy. |

### Quick sanity‑check before a full run  

1. **Linear static test** – add a temporary `*STEP, NLGEOM=NO` and run the job. If Abaqus reads the file without aborting, the syntax is now correct.  
2. **Contact verification** – after the non‑linear step, inspect the `CDISP` and `CSTRESS` output. The slave surface (`Sslav`) should be in contact with the master (`Smast`).  
3. **If contact never activates** – reduce the initial gap, increase the pressure‑overclosure coefficient, or insert a short “pre‑contact” step with a larger pressure.  
4. **If the solution diverges** (large deformations, `NLGEOM=YES`) – lower the initial increment (`INC=0.005` or smaller) or adjust the friction penalty.
