### 📋 Quick‑Run Checklist (avoid the common pitfalls)

| ✅ | Pitfall | Fix / Avoid |
|---|---------|-------------|
| 1 | **Material block missing or wrong constants** | Ensure `*Material, name=FaultMat` → `*Elastic` (e.g., E = 200 GPa, ν = 0.3). |
| 2 | **Node‑set name typo** (`LEFT` / `RIGHT`) | Open the `.inp` and verify the exact spelling of the `*Nset` definitions. |
| 3 | **Fault element set not defined** (`FAULT`) | Make sure `*Elset, elset=FAULT` lists all fault elements. |
| 4 | **No U or S output request** | `*Output, field` must contain `*Node Output, Nset=LEFT, Nset=RIGHT, U` and `*Element Output, Elset=FAULT, S`. |
| 5 | **Running the script outside Abaqus Python** | Use the Abaqus interpreter: `abaqus python check_fault.py …`. |
| 6 | **Memory‑limit abort (large mesh)** | Add `memory=4GB` (or similar) to the command line, or start with a coarser mesh. |
| 7 | **Units mismatch** | Keep everything in SI (m, Pa, s). |

*If the script reports a failure, it tells you the offending node/element and the observed value. Probe that item in the ODB, correct the input file, and re‑run.*

### 🚀 Extending the Model – at a Glance

| Extension | What to edit in `FaultSlip.inp` | Example values to try |
|-----------|--------------------------------|-----------------------|
| **Different slip magnitude** | Change the constant in the `*Equation` (or `*Boundary`) for the RIGHT set | `1.0 → 0.5 m`, `2.0 m`, … |
| **Finer fault mesh** | Refine node spacing in the fault region (reduce element size) | From 0.1 m → 0.05 m (≈ 4× more elements). |
| **Plasticity** | Add a `*Plastic` block under the material definition and set `nlgeom=YES` in the step | Yield = 250 MPa, hardening = 10 MPa. |
| **Normal loading** | Insert a pressure `*Dsload, type=PRESSURE` on the fault surface | `-10e6` Pa (compressive). |
| **3‑D version** | Replace `CPE4` → `C3D8`, extrude geometry, define a surface set for the fault | Thickness = 0.1 m, 8‑node bricks. |

**After any edit, simply repeat steps 1‑3** to verify the new model.
