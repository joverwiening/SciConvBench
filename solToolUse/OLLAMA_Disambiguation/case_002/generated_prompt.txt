Use the legacy FEniCS (dolfin) Python interface.  
Define the 2‑D right‑triangular domain with vertices (0,0), (1,0) and (0,0.5).  
Create a conforming triangular mesh of the domain consisting of 64 elements.  
Define a continuous Lagrange vector function space of degree 1 for the displacement field.  
Set material parameters: Young’s modulus E = 70e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³, and gravitational acceleration g = 9.81 m/s².  
Assume plane‑stress conditions with unit thickness and use the reduced plane‑stress constitutive matrix  
\(D = \frac{E}{1-\nu^{2}}\begin{bmatrix}1 & \nu & 0\\ \nu & 1 & 0\\ 0 & 0 & \frac{1-\nu}{2}\end{bmatrix}\).  
Define the body force vector \(f = (0,\,-\rho g)\).  
Apply a Dirichlet boundary condition u = (0,0) on the vertical edge x = 0 (clamped edge).  
Apply a Neumann boundary condition on the sloping edge defined by x + 2y = 1: the upward normal traction vector is (0, 3000) Pa, where the normal points outward from the domain.  
Formulate the weak form: find u in the displacement space such that  
\(\int_{\Omega} \sigma(\varepsilon(u)):\varepsilon(v)\,dx - \int_{\Omega} f\cdot v\,dx - \int_{\Gamma_{sloping}} t\cdot v\,ds = 0\) for all test functions v,  
with \(\varepsilon(u)=\tfrac12(\nabla u + \nabla u^{T})\) and \(\sigma = D\,\varepsilon\).  
Assemble the linear system and solve it with a direct linear solver (e.g., LU).  
After solving, compute the strain \(\varepsilon\) and the Cauchy stress \(\sigma\).  
Compute the von Mises stress as \(\sigma_{vm}= \sqrt{\sigma_{xx}^{2} - \sigma_{xx}\sigma_{yy} + \sigma_{yy}^{2} + 3\sigma_{xy}^{2}}\).  
Compute the displacement magnitude as \(|u| = \sqrt{u_{x}^{2}+u_{y}^{2}}\).  
Save the displacement magnitude field and the von Mises stress field to VTK files for visualization.  
Optionally, output the maximum displacement magnitude and the maximum von Mises stress values.
