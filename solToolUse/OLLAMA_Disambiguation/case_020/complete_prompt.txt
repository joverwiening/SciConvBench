Task:
Solve Solid Mechanics Problem 2 from the paper: a rectangular plate in plane stress loaded by a uniform top-edge traction.
Case details:
Geometry:
Let Ω = (0, 1.0) x (0, 0.20) m be a rectangular plate.
Mesh:
Uniform structured mesh with 40 x 8 subdivisions across (x, y).
Model:
Plane-stress linear elasticity for displacement u = (u_x, u_y) in Ω.
Material:
Young's modulus E = 200 GPa, Poisson's ratio ν = 0.30.
Boundary conditions:
Left edge (x = 0): fixed, u_x = 0, u_y = 0.
Top edge (y = 0.20): traction t = (0, -2000) N/m.
Right edge (x = 1.0) and bottom edge (y = 0): traction-free.
Outputs:
Save a colour map of u_y as q2_uy.png.
Save the resulting displacement field in XDMF format.
Implementation notes:
Treat the 2D strip as plane stress with unit thickness and use the reduced plane-stress constitutive law.
Interpret the top-edge load as a 2D line traction per unit out-of-plane thickness.
