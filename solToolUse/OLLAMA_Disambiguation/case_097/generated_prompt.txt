`*DISTRIBUTING COUPLING` 是 **关键字卡**。  
在 *.inp* 文件中，关键字卡的 **第一行** 只能写关键字本身以及它的可选参数（如 `ELSET=`、`NSET=`），所有数值数据必须放在 **第二行（数据行）**。  

你把负载名和幅值写在同一行：

```abaqus
*DISTRIBUTING COUPLING,ELSET=E1 LOAD,1.
```

Abaqus 把 `LOAD,1.` 当成了额外的关键字参数，而该卡并不接受这些参数，于是报出

```
Incorrect number of parameters for *DISTRIBUTING COUPLING
```

---

## 正确写法（两行）

```abaqus
*DISTRIBUTING COUPLING, ELSET=E1          ; 关键字行，只写参数
LOAD, 1.0                                 ; 数据行：<load name>, <magnitude>
```

* `ELSET=E1`（必须）——要耦合的单元集合名称。  
* `NSET=`（可选）——如果需要把耦合负载施加到特定节点集，可在关键字行加入 `NSET=…`。  
* 第二行（数据行）只能有两列：  
  - **负载名**（任意合法标签，如 `LOAD`），不需要事先定义。  
  - **幅值**（数值或已定义的幅值名称），这里用 `1.0` 表示常数幅值。

### 带节点集的写法（可选）

```abaqus
*DISTRIBUTING COUPLING, ELSET=E1, NSET=NLOAD
LOAD, 1.0
```

> **注意**：`ELSET`（以及 `NSET`）必须在模型中已经用 `*ELSET`、`*NSET` 定义，否则会出现 “undefined set” 错误。

---

## 快速检查清单

| 项目 | 正确写法 | 常见错误 |
|------|----------|----------|
| 关键字行 | `*DISTRIBUTING COUPLING, ELSET=… [, NSET=…]` | 在同一行写入负载名或数值 |
| 数据行 | `load_name, magnitude`（两列，用逗号或空格分隔） | 把数据写在关键字行后面 |
| ELSET / NSET | 必须已在模型中定义（`*ELSET`、`*NSET`） | 未定义或拼写错误 |
| 负载名 | 任意合法标签（如 `LOAD`），不需要提前声明 | 与已有关键字冲突或使用非法字符 |

只要把关键字行与数据行分开写，确保集合已正确定义，Abaqus 就能顺利读取 `*DISTRIBUTING COUPLING` 卡，错误将不再出现。祝你建模顺利！
