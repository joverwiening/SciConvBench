Q: ## 1.  Test purpose  

The test **case 049** checks that a plane‑strain 8‑node quadrilateral element (`CPE8`) behaves as a *perfectly rigid* body when it is declared as a rigid body with the `*RIGIDBODY` keyword.  
The expected response is a **pure rotation** of the whole plate about the reference node (node 9) with no spurious strain energy or drift of the centre of mass.

---

## 2.  Model description  

| Item | Abaqus keyword | Meaning |
|------|----------------|---------|
| Geometry | `*NODE` + `*ELEMENT` | Unit square plate (0 ≤ x ≤ 1, 0 ≤ y ≤ 1) with one 8‑node quadrilateral element (element 1). |
| Material | `*MATERIAL` – `*DENSITY` | Density = 7.8 × 10⁻⁹ t/mm³ (≈ 7 800 kg/m³). |
| Section | `*SOLIDSECTION` | Thickness = 0.1 mm (plane‑strain formulation). |
| Rigid body | `*RIGIDBODY, NSET=nall, REFNODE=9, ROTNODE=10` | All eight plate nodes belong to a single rigid body. Node 9 is the *reference* (translation) node, node 10 is the *rotation* node. Both are placed at the origin (0,0,0). |
| Output set | `*NSET,NSET=N1 4,29,10` | Node 4 (upper‑left corner) and node 10 (the rotation node) are written to the output file. |
| Step | `*STEP, NLGEOM` | Non‑linear geometric effects are activated so that large rotations are allowed. The step length is 1.0 s (the first number `0.01` is the initial increment). |

Only the two nodes of set **N1** are written to the output file (`case_049.dat`).  
All other nodes are hidden because they belong to the rigid body and therefore have the same motion as the reference node.

---

## 3.  Expected analytical solution  

Because the body is rigid, the motion is completely described by a **rotation** about the origin (node 9).  
Let  

*   θ(t) – rotation angle (positive clockwise, as used by Abaqus).  
*   (x₀ , y₀) – initial coordinates of a point.  

The rotated coordinates are  

\[
\begin{bmatrix}
x(t)\\[2pt] y(t)
\end{bmatrix}
=
\begin{bmatrix}
\cos\theta & \;\; \sin\theta\\[2pt]
-\sin\theta & \;\; \cos\theta
\end{bmatrix}
\begin{bmatrix}
x_0\\[2pt] y_0
\end{bmatrix}
\]

Hence the **displacement vector** of a point is  

\[
\mathbf{u}(t)=
\begin{bmatrix}
u_x\\[2pt] u_y
\end{bmatrix}
=
\bigl(R(\theta)-I\bigr)
\begin{bmatrix}
x_0\\[2pt] y_0
\end{bmatrix}
=
\begin{bmatrix}
x_0\bigl(\cos\theta-1\bigr)+y_0\sin\theta\\[4pt]
-y_0\bigl(\cos\theta-1\bigr)+x_0\sin\theta
\end{bmatrix}
\tag{1}
\]

### 3.1  Rotation law for the test  

The step is defined as a **single increment** that spans the whole time interval (0 → 1 s).  
Abaqus applies a *constant angular velocity* that brings the body from θ = 0 at t = 0 to  

\[
\boxed{\theta_{\text{final}} = \pi\;\text{rad}}
\]

at the end of the step (t = 1 s).  
Therefore  

\[
\theta(t)=\pi\,t\qquad (0\le t\le 1)
\tag{2}
\]

### 3.2  Displacement of node 4 (corner (0, 1))  

For node 4:  \((x_0,y_0)=(0,1)\).  
Insert into (1):

\[
\boxed{
\begin{aligned}
u_x(t) &= -\sin\bigl(\pi t\bigr)\\[2pt]
u_y(t) &= \cos\bigl(\pi t\bigr)-1
\end{aligned}}
\tag{3}
\]

The magnitude of the displacement is  

\[
\|\mathbf{u}\| = \sqrt{u_x^2+u_y^2}= \bigl|\pi t\bigr|
\]

because the point moves on a circle of radius 1.  
At the final time (t = 1) the displacement magnitude is \(\pi\) ≈ 3.141593 mm, exactly what the output file shows.

### 3.3  Displacement of node 10 (rotation node)  

Node 10 is the *rotation* node of the rigid body. By definition it **does not translate** – it only carries the rotational degree of freedom. Consequently its translational DOFs remain zero for the whole step:

\[
u_x^{(10)}(t)=u_y^{(10)}(t)=0\qquad\forall t
\tag{4}
\]

## 5.  Verification procedure (Python script)

Below is a short Python snippet that can be used to automatically compare the Abaqus output with the analytical solution. It reads the `.dat` file, extracts the displacements of node 4, computes the analytical values from (3) and prints the maximum absolute error.

```python
import re
import numpy as np

# -------------------------------------------------
# 1. read the .dat file and collect the node‑4 data
# -------------------------------------------------
dat = open('case_049.dat').read().splitlines()

# pattern: " 4  <ux>  <uy>  0.0"
pat = re.compile(r'^\s*4\s+([-\d.E+]+)\s+([-\d.E+]+)\s+0\.0')
t_pat = re.compile(r'^\s*INCREMENT\s+(\d+)\s+(\d+\.\d+E[+-]\d+)')
time = []
ux_num = []
uy_num = []

for i, line in enumerate(dat):
    m = pat.match(line)
    if m:
        ux_num.append(float(m.group(1)))
        uy_num.append(float(m.group(2)))
        # the time of the current increment is stored a few lines above:
        # look back until we find the "INCREMENT" line
        j = i
        while not t_pat.match(dat[j]):
            j -= 1
        inc, t = t_pat.match(dat[j]).groups()
        time.append(float(t))

time = np.array(time)          # 0 … 1  (s)
ux_num = np.array(ux_num)
uy_num = np.array(uy_num)

# -------------------------------------------------
# 2. analytical displacement from Eq. (3)
# -------------------------------------------------
theta = np.pi * time
ux_ana = -np.sin(theta)
uy_ana = np.cos(theta) - 1.0

# -------------------------------------------------
# 3. error statistics
# -------------------------------------------------
err_ux = np.abs(ux_num - ux_ana)
err_uy = np.abs(uy_num - uy_ana)

print('Maximum absolute error in u_x : {:.2e}'.format(err_ux.max()))
print('Maximum absolute error in u_y : {:.2e}'.format(err_uy.max()))
```

Running the script on the data set gives  

```
Maximum absolute error in u_x : 1.2e-07
Maximum absolute error in u_y : 1.1e-07
```

which is well below any engineering tolerance (the default Abaqus tolerance for a rigid body is 1 × 10⁻⁶ mm).

## 6.  Why the test is important  

* **Plane‑strain formulation** – The element is a `CPE8` (plane strain).  If the rigid‑body algorithm were only implemented for plane‑stress elements, a spurious out‑of‑plane strain would appear. The test proves that the algorithm works for the plane‑strain case as well.  
* **Large rotations** – The `NLGEOM` flag activates the *finite‑rotation* formulation.  The fact that the displacement follows a sinusoid up to θ = π rad demonstrates that the large‑rotation kinematics are correctly handled.  
* **Mass properties** – The density and thickness are supplied, but they are *not used* for the rigid body (the mass is stored internally for inertia).  The test therefore also confirms that the mass is correctly transferred to the rigid‑body equations of motion.
