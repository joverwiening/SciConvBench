### What you have

Only the **top** edge is given a displacement.  
The **bottom** edge (or any other node) is *not* restrained in any direction.  
Consequences:

* The model can translate in X, translate in Y (the prescribed displacement does not prevent a rigid‑body translation of the whole part) and rotate about the Z‑axis.

### How to fix it

Add a minimal set of constraints that removes the three rigid‑body modes. The simplest way is to fix one node (or a small group of nodes) in all three DOFs, e.g.

```text

310,1,3,0.          ! fix node 310 in X, Y and Z (or 1,2,3)
```

or, if you want the bottom edge to stay in place while the top edge is pulled down:

```text
*BOUNDARY
Nbottom,1,1,0.     ! fix X‑translation of the bottom edge
Nbottom,2,2,0.     ! fix Y‑translation of the bottom edge
Nbottom,3,3,0.     ! fix rotation about Z (or fix a single node in Z)
```

Only two constraints are needed to prevent translation in X and Y; a third one (either a rotation or a second point in Y) eliminates the remaining rigid‑body rotation.

Abaqus 在静力学步中报 “**singular matrix / rigid body motion detected**” 的根本原因只有两点：

## 1️⃣ 材料定义（必须包含 `*Elastic`，且 \(E>0\)）

```abaqus

```

> **要点**：`*Elastic` 必须出现，弹性模量不能为 0。若只写 `*Density`，所有壳单元刚度为 0，矩阵必然奇异。

```abaqus

```

- `elset=ALL_SHELLS` 为包含全部壳单元的集合（如果已有集合，请改为对应名称）。

### 3.1 选取约束节点集合（示例：底边节点）

```abaqus

1, 50, 1          ! 起止节点号请根据实际网格修改
```

### 3.2 施加三自由度的固定约束（U1、U2、UR3）

```abaqus
*Boundary
BOT_EDGE, 1, 1, 0.0   ! X 位移 = 0
BOT_EDGE, 2, 2, 0.0   ! Y 位移 = 0
BOT_EDGE, 3, 3, 0.0   ! 绕 Z 轴转动 = 0

```

```abaqus
*Boundary
```
