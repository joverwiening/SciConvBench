Use FEniCS legacy (dolfin) to solve a small‑strain linear elasticity problem in 2‑D plane‑stress on an L‑shaped domain.  

The outer square is the region \([0,1]\times[0,1]\) m².  Remove the lower‑left quarter \([0,0.5]\times[0,0.5]\) m² to obtain the L‑shape with a re‑entrant corner at \((0.5,0.5)\).  

Generate a conforming triangular mesh of the domain with 64 divisions along each outer edge (use mshr or MeshEditor).  

Material properties: Young’s modulus \(E = 70\text{e}9\) Pa, Poisson’s ratio \(\nu = 0.33\), density \(\rho = 2700\) kg/m³.  Use unit thickness for plane‑stress.  

Define the plane‑stress constitutive matrix  
\(D = \dfrac{E}{1-\nu^{2}}\begin{bmatrix}1 & \nu & 0\\ \nu & 1 & 0\\ 0 & 0 & \dfrac{1-\nu}{2}\end{bmatrix}\).  

Define the vector‑valued displacement function space \(V = \text{VectorFunctionSpace}(mesh, \"CG\", 1)\).  

Apply Dirichlet boundary conditions fixing the entire left edge (\(x=0\)): set both displacement components to zero on that boundary.  

Apply a body force representing gravity: \(\mathbf{f} = (0,\,-\rho\,g)\) N/m³ with \(g = 9.81\) m/s².  

Apply a Neumann traction on the right edge (\(x=1\)):  
\(\mathbf{t}(y) = \bigl(0,\; -2.65\times10^{4}\,y\bigr)\) Pa, where \(y\) is the vertical coordinate (downward direction is negative).  

Form the weak form  
Find \(\mathbf{u}\in V\) such that  
\(\int_{\Omega} \varepsilon(\mathbf{v}):D:\varepsilon(\mathbf{u})\,\mathrm{d}x = \int_{\Omega} \mathbf{v}\cdot\mathbf{f}\,\mathrm{d}x + \int_{\Gamma_{N}} \mathbf{v}\cdot\mathbf{t}\,\mathrm{d}s\)  
for all test functions \(\mathbf{v}\in V\) that vanish on the left edge.  

Assemble the linear system \(A\,\mathbf{u}=b\) and solve with a direct linear solver, e.g. `solve(A, u.vector(), b, "lu")`.  

Compute the Cauchy stress tensor \(\sigma = D:\varepsilon(\mathbf{u})\).  

From the in‑plane stress components \(\sigma_{xx},\sigma_{yy},\sigma_{xy}\) compute the von Mises stress:  
\(\sigma_{vm} = \sqrt{\sigma_{xx}^{2} - \sigma_{xx}\sigma_{yy} + \sigma_{yy}^{2} + 3\sigma_{xy}^{2}}\).  

Save the displacement field, the full stress tensor, and the von Mises scalar field to VTK/XDMF files for post‑processing.  

The implementation must use only legacy dolfin classes and functions, and all quantities must be expressed in SI units.
