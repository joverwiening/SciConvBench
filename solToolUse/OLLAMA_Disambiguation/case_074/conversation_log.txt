## 2. What you really need to obtain the first natural frequency

For a **cantilever beam** the most straightforward way is a **modal (eigenvalue) analysis**:

```text
*STEP
*FREQUENCY, NMODES=5, EIGENSOLVER=SUBSPACE
*OUTPUT, FIELD, VARIABLE=PRESELECT
*END STEP
```

* `*FREQUENCY` tells Abaqus to solve the generalized eigenvalue problem **K u = λ M u**.  
* `NMODES` is the number of eigen‑values you want (set it to 5 or more – you will read the first one from the output).  
* No frequency range, no loads, and no damping are required.  

If you also want to see the mode shape, request nodal displacements in the output:

```text
*NODE PRINT, NSET=ALL, FREQUENCY
  U1, U2, U3
*END PRINT
```

### 2.4. Analysis type – **modal (frequency) step**

```abaqus
*STEP
*FREQUENCY, NMODES=5, EIGENSOLVER=SUBSPACE, MAXEIGEN=5
*OUTPUT, FIELD, VARIABLE=PRESELECT
*END STEP
```

* `*FREQUENCY` tells Abaqus to solve the eigenvalue problem.  
* `NMODES=5` asks for the first five natural frequencies – you will read the first one from the output.  
* `MAXEIGEN=5` limits the subspace size (keeps the solve fast).  
* No damping is required for a pure modal analysis – you can delete the `*RAYLEIGH DAMPING` line entirely.  

If you really want a **steady‑state dynamics** (forced‑vibration) analysis, you would keep the `*STEADY STATE DYNAMICS` step **but** you must (i) **refine the mesh** (e.g. at least 8–10 elements along the length) and (ii) **choose a realistic frequency range** (e.g. 0–500 rad s⁻¹). For the purpose of “first natural frequency” a modal step is far simpler.

### 2.5. Optional – request the frequencies in the output file

```abaqus
*NODE PRINT, NSET=ALL, FREQUENCY
  U1, U2, U3
*END PRINT
```

Abaqus writes the eigen‑values (ω²) and the corresponding frequencies (ω/2π) in the `.dat` file under the heading **“FREQUENCIES”**. The first entry is the fundamental frequency you are after.

|---------|---------------------|

| Symptom (last lines of console / `.log`) | Typical cause | One‑line fix |
|-------------------------------------------|---------------|--------------|
| `ERROR: Invalid element set name` | `*Elset` / `*Node Set` defined **after** the `*Step` card | Move the `*Node Set` (and any `*Elset`) **above** the `*Step` block (already done in the file). |
