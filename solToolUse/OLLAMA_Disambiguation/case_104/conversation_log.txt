If you simply want a beam that is clamped at one end and pulled (or pushed) a given amount at the other end, use a **static step** and prescribe the displacements with `*BOUNDARY`.

### Minimal corrected fragment (static)

```abaqus
*STEP
*STATIC                     ! declare the step type
** 1) Clamp the fixed end (all three translational DOFs = 0)
*BOUNDARY
CN7, 1, 3, 0.0

** 2) Prescribe a uniform Z‑displacement of 0.5 mm at the free end
*BOUNDARY
LAST, 3, 3, 0.5
*END STEP
```

* `CN7` – node set that contains the 20 nodes on the clamped face (already defined).  
* `LAST` – node set that contains the 8 nodes on the free face (also already defined).  
* `1,3` – apply the value to DOFs 1, 2 and 3 (X, Y, Z).  
* `3,3` – apply the value only to the Z‑direction (DOF 3).  
* `0.0` – zero displacement (clamping).  
* `0.5` – magnitude of the prescribed translation (change to the value you need).

If you also want to keep the free end from moving in X and Y, add two more lines:

```abaqus
LAST, 1, 1, 0.0
LAST, 2, 2, 0.0
```

## 2.  When you really need an **initial displacement** (dynamic analysis)

If the goal is to start a **dynamic** analysis with the beam already displaced (e.g., to study free vibration after a prescribed deflection), you must:

1. Declare a **dynamic step** (`*DYNAMIC, IMPLICIT` or `*DYNAMIC, EXPLICIT`).  
2. Use `*INITIAL CONDITIONS, TYPE=DISPLACEMENT` to give the initial field.

### Example – implicit dynamic step with an initial displacement

```abaqus
*STEP
*DYNAMIC, IMPLICIT, TIME=1.0   ! total analysis time = 1 s (adjust as required)
*INITIAL CONDITIONS, TYPE=DISPLACEMENT
CN7, 1, 3, 0.0                 ! fixed end stays at the origin
LAST, 3, 3, 0.5                ! free end is initially displaced 0.5 mm in Z
*END STEP
```

The numbers after the node‑set are the **actual displacement components** (in the model’s length unit). Abaqus does **not** compute them for you; you must decide the magnitude you want.

*INITIAL CONDITIONS, TYPE=DISPLACEMENT
CN7, 1, 3, 0.0
LAST, 3, 3, 0.5
*END STEP

Insert the appropriate fragment (or adjust the displacement magnitudes) into your input file, run the job, and the “card rejected” errors will disappear.
A: **Why the cards are rejected**

In an Abaqus *.inp* file every load, boundary‑condition or initial‑condition **must be placed inside a step definition**.  
When a `*STEP` block is opened without a step type (`*STATIC`, `*DYNAMIC`, …) Abaqus creates a **default static step**.  

* `*INITIAL CONDITIONS, TYPE=DISPLACEMENT` is **only legal in a dynamic step** (implicit or explicit) and it has to be inside that step.  
* `*BOUNDARY` can be used in a static or a dynamic step, but it also **must be inside** the step block.

Because your file contains only

```abaqus
*STEP
*END STEP
```

Abaqus creates a default static step, and the two cards are therefore **outside any step** (and the `*INITIAL CONDITIONS` card is illegal for a static step). The parser therefore reports **“card rejected”**.

---

## How to fix the input file

### 1. Decide which type of analysis you need  

| Desired physics                              | Step type to use                | How to prescribe the displacement |
|----------------------------------------------|--------------------------------|------------------------------------|
| **Static pull‑out / static deflection**      | `*STATIC`                      | Use `*BOUNDARY` cards.             |
| **Dynamic analysis that starts from a shape**| `*DYNAMIC, IMPLICIT` (or `EXPLICIT`) | Use `*INITIAL CONDITIONS, TYPE=DISPLACEMENT`. |

### 2. Put the cards **inside** the appropriate step

Below are two ready‑to‑run fragments. Choose the one that matches the physics you want to simulate and replace the node‑set names (`CN7`, `LAST`) with the sets you have defined in the mesh.

---

#### a) **Static analysis (most common for a cantilever‑type pull‑out)**  

```abaqus
*STEP
*STATIC                         ! static analysis
*BOUNDARY
CN7, 1, 3, 0.0                  ! fixed face: X, Y, Z = 0
LAST, 3, 3, 0.5                 ! free face: 0.5 mm displacement in Z
*END STEP
```

*Explanation*  

* `CN7` – node set that contains the nodes on the clamped face.  
* `LAST` – node set that contains the nodes on the pulled face.  
* `1,3` – apply the value to DOFs 1‑3 (X, Y, Z).  
* `3,3` – apply the value only to the Z‑direction (DOF 3).  

If you also want the free end to stay fixed in X and Y, add two more `*BOUNDARY` lines inside the same step:

```abaqus
LAST, 1, 1, 0.0
LAST, 2, 2, 0.0
```

---

#### b) **Dynamic analysis that starts from an initial displacement**  

```abaqus
*STEP
*DYNAMIC, IMPLICIT, TIME=1.0   ! total analysis time = 1 s (adjust as needed)
*INITIAL CONDITIONS, TYPE=DISPLACEMENT
CN7, 1, 3, 0.0                 ! fixed end stays at the origin
LAST, 3, 3, 0.5                ! free end is initially displaced 0.5 mm in Z
*END STEP
```

*Explanation*  

* `*DYNAMIC, IMPLICIT` creates a dynamic (implicit) step; you can also use `*DYNAMIC, EXPLICIT` if you prefer an explicit solver.  
* The `*INITIAL CONDITIONS` card is now inside a dynamic step, which is allowed.  
* No `*BOUNDARY` cards are required unless you want to apply additional loads during the dynamic step.

---

### 3. Quick checklist – what to modify in your original file

| What you have                               | Why it fails                                            | What to replace it with                                   |
|---------------------------------------------|----------------------------------------------------------|-----------------------------------------------------------|
| `*STEP`<br>`*END STEP`                     | No step type → default static step; cards are outside any step | Add a step type (`*STATIC` or `*DYNAMIC,…`).             |
| `*INITIAL CONDITIONS, TYPE=DISPLACEMENT` (outside any step) | Allowed only in a dynamic step **and** must be inside a step block | Move it inside a `*DYNAMIC` step, or replace it with `*BOUNDARY` for a static analysis. |
| `*BOUNDARY` (outside any step)             | Abaqus expects the card inside a step                    | Place the `*BOUNDARY` lines inside a `*STATIC` (or `*DYNAMIC`) step. |

---

## Final recommended input fragment (static case)

```abaqus
*STEP
*STATIC
*BOUNDARY
CN7, 1, 3, 0.0          ! clamp the fixed face
LAST, 3, 3, 0.5         ! pull the free face 0.5 mm in Z
*END STEP
```

*or* (dynamic case)

```abaqus
*STEP
*DYNAMIC, IMPLICIT, TIME=1.0
*INITIAL CONDITIONS, TYPE=DISPLACEMENT
CN7, 1, 3, 0.0
LAST, 3, 3, 0.5
*END STEP
```

Insert the appropriate fragment (or adjust the displacement magnitudes) into your input file, run the job, and the “card rejected” errors will disappear.
