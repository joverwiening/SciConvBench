Use FEniCS legacy (dolfin) to solve a static, small‑strain, linear‑elastic plane‑stress problem on an L‑shaped domain.  

The outer square spans the region \([0,1]\times[0,1]\).  Remove the inner square \([0.5,1]\times[0.5,1]\) to obtain the L‑shape.  

Generate a conforming mesh with 64 elements along each outer edge (use mshr to create the geometry and call generate_mesh with a resolution that yields approximately 64 cells per outer edge).  

Define a vector‑valued continuous Lagrange function space \(V\) for the displacement \(\mathbf{u}\).  

Material parameters: Young’s modulus \(E = 70\text{e}9\) Pa, Poisson ratio \(\nu = 0.33\), density \(\rho = 2700\) kg/m³, gravitational acceleration \(g = 9.81\) m/s².  

Treat the problem as plane stress with unit thickness.  Use the plane‑stress constitutive matrix  
\(D = \frac{E}{1-\nu^{2}}\begin{bmatrix}1 & \nu & 0\\ \nu & 1 & 0\\ 0 & 0 & \frac{1-\nu}{2}\end{bmatrix}\).  

Define the strain \(\varepsilon(\mathbf{u}) = \frac{1}{2}(\nabla\mathbf{u} + \nabla\mathbf{u}^{T})\) and the Cauchy stress \(\sigma = D:\varepsilon(\mathbf{u})\).  

Body force: \(\mathbf{f} = (0,\,-\rho g)\).  

Boundary conditions:  
* Fix the left boundary \(x=0\) (both displacement components set to zero).  
* Apply a vertically varying traction on the outer right edge segment where \(x=1\) and \(0\le y\le 0.5\).  The traction vector is \(\mathbf{t}(y) = (0,\,t_y(y))\) with  
\(t_y(y) = -2.65\times10^{4}\,\frac{y}{1}\) Pa (linear from 0 Pa at \(y=0\) to \(-2.65\times10^{4}\) Pa at \(y=1\); on the applied segment this yields \(-1.325\times10^{4}\) Pa at \(y=0.5\)).  
* All other boundaries, including the interior edge of the removed square (\(x=1,\;0.5<y\le1\)), are traction‑free.  

Form the weak form: find \(\mathbf{u}\in V\) such that for all test functions \(\mathbf{v}\in V\)  
\(\int_{\Omega} \varepsilon(\mathbf{v}):D:\varepsilon(\mathbf{u})\,\mathrm{d}x = \int_{\Omega} \mathbf{v}\cdot\mathbf{f}\,\mathrm{d}x + \int_{\Gamma_{t}} \mathbf{v}\cdot\mathbf{t}(y)\,\mathrm{d}s\).  

Assemble the linear system and solve it with a direct LU solver (e.g., `solver_parameters["linear_solver"] = "lu"`).  

Post‑process:  
* Compute the stress field \(\sigma(\mathbf{u})\) on the mesh.  
* Compute the von Mises stress \(\sigma_{vm} = \sqrt{\sigma_{xx}^{2} - \sigma_{xx}\sigma_{yy} + \sigma_{yy}^{2} + 3\sigma_{xy}^{2}}\).  
* Save the displacement vector, the full stress tensor components, and the von Mises field to XDMF files for visualization.  

The code must be written in a single Python script compatible with FEniCS legacy (dolfin) and must run without requiring any external libraries beyond FEniCS and mshr.
