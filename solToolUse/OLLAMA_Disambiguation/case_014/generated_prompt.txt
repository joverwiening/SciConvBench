Use FEniCS legacy (dolfin) to implement a three‑dimensional nonlinear hyperelasticity solver for a Saint‑Venant‑Kirchhoff material on the unit cube domain Ω=[0,1]³.
Create a structured mesh of the unit cube with 8 cells in each spatial direction (8×8×8 hexahedral elements) and use a continuous Lagrange vector function space of degree 2 for the displacement field u.
Assume the Lamé parameters λ = 1.0e5 Pa and μ = 5.0e4 Pa (both positive and physically consistent).
Define the exact manufactured displacement field  
u_ex(x,y,z) = 0.1 [ sin(π x) sin(π y) sin(π z),  sin(π x) sin(π y) sin(π z),  sin(π x) sin(π y) sin(π z) ]ᵀ.  
From u_ex compute the deformation gradient F = I + ∇u_ex, the Green‑Lagrange strain ε = ½(Fᵀ F – I), the strain energy density Ψ = ½ λ (tr ε)² + μ tr(ε²), and the Piola‑Kirchhoff stress σ = ∂Ψ/∂ε.
Derive the body force f₀ = –∇·σ analytically from the exact solution and implement it as a known source term in the weak form.
Impose Dirichlet boundary conditions u = u_ex on the entire boundary ∂Ω so that the exact solution satisfies the prescribed displacement.
Formulate the nonlinear variational problem: find u ∈ V such that ∫_Ω σ(u):∇v dx = ∫_Ω f₀·v dx for all test functions v ∈ V₀, where σ(u) is evaluated using the current iterate of u.
Solve the nonlinear problem with Newton’s method using the dolfin NewtonSolver, set a relative tolerance of 1e‑8, an absolute tolerance of 1e‑10, and a maximum of 25 iterations.
After convergence, compute the L² error norm ‖u – u_ex‖_{L²(Ω)} and the H¹ semi‑norm error ‖∇(u – u_ex)‖_{L²(Ω)} and output both values.
Write the final displacement field to a VTK file named “displacement.vtk” for visualization.
