Abaqus reads an input file in two stages  

| Pass | What is read | When it becomes available |
|------|--------------|--------------------------|
| **Definition pass** | `*NODE`, `*ELEMENT`, `*MATERIAL`, `*NSET`, `*ELSET`, `*SECTION`, … | **Before** the first `*STEP` is encountered. |
| **Step‑parsing pass** | Everything that lies **between** a `*STEP` and its matching `*END STEP` (loads, boundary conditions, amplitudes, output requests, etc.) | **During** the step pass. The objects referenced must already exist from the definition pass. |

If a load or a boundary condition refers to a set that has not been created **by the time the step is parsed**, Abaqus aborts with  

```
ERROR: Node set N1 is not defined.
```

In your file the node‑set **N1** *is* defined, but the `*BOUNDARY` (or any other load) that uses it is placed **outside any `*STEP … *END STEP` block** (or the step is declared without a step type). Consequently, when Abaqus reaches the load during the step‑parsing pass the set does not exist yet, and the error is raised.

---

1. **Define all sets, materials, sections, etc. before the first `*STEP`.**  
   Your `*NSET, NSET=N1` line already satisfies this.

4. (Optional) If you want a time‑dependent load, define an `*AMPLITUDE` and attach its name to the load line.

5. The `*TRANSFORM` line you used is syntactically correct; it translates the whole mesh by (0.5, 0.5, 0) and scales the Z‑direction by 8. It is **not** the cause of the error.

## Frequently asked follow‑up questions  

| Question | Answer |
|----------|--------|
| **Do I have to keep `NLGEOM`?** | Only if you need geometric non‑linearity (large deformations). If you don’t, you can drop it (`*STEP, STATIC`). |

| **Is `*TRANSFORM` mandatory?** | No. It is only needed if you want to translate/rotate/scale the mesh after it is defined. It does not affect set definitions. |
| **Why does Abaqus abort instead of just warning?** | Loads/BCs that reference undefined objects are fatal because the solver would have no way to apply them. The parser therefore stops immediately. |
