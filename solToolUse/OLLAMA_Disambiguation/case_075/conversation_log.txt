## 1. What Abaqus really needs for a cyclic‑symmetry analysis  

| Keyword | What it does | What you must supply |
|---------|--------------|----------------------|
| `*NODE` | List of all nodal coordinates. | **All** nodes of the sector (you already have this). |
| `*ELEMENT` | List of all elements and their connectivity. | Element type (CPE4, CPE8, etc.) **and** an element set name (e.g. `Eall`). |
| `*ELSET` | Define the element set that will be used by the material/section definition. | Must contain **all** elements that belong to the sector. |
| `*NSET` (Nall) | A node set that contains **every** node of the sector. It is used later for the initial temperature, for the stress‑domain set, and for the cyclic‑symmetry tie. | You have to create it (or generate it automatically). |
| `*SURFACE, TYPE=NODE` | The two “master” and “slave” node surfaces that will be tied together. | Two node sets that contain the nodes on the left and right radial faces of the sector (`Nleft` and `Nright`). |
| `*TIE, CYCLIC SYMMETRY` | Ties the two node surfaces together. | The two surface names (`left` and `right`). |
| `*CYCLIC SYMMETRY MODEL` | Defines the axis of symmetry and the number of sectors (`N`). | A point on the symmetry axis **and** a point that lies on the reference plane (the plane that is rotated). |
| `*INITIAL CONDITIONS, TYPE=TEMPERATURE` | Gives the starting temperature for every node. | A node set that contains **all** nodes (`Nall`). |
| `*STEP` → `*TEMPERATURE` → `*END STEP` | The “pre‑load” step in which you prescribe the temperature field that will generate the thermal stress. | The node sets that receive the hot temperature (`Nout`) and the node sets that stay at the reference temperature (`Nrest`). |
| `*STEP, PERTURBATION` → `*SELECT CYCLIC SYMMETRY MODES` | The eigen‑frequency (or buckling) step that extracts the cyclic‑symmetry modes. | The mode numbers you want (here mode 2). |

If any of the items above is missing or incorrectly defined, Abaqus stops with a *“input data error”* or, if it gets past the parser, the cyclic‑symmetry algorithm will not be activated.

| 8 | `*STEP, PERTURBATION` | You did not give a name for the step (`*STEP, PERTURBATION, NAME=EIGEN`). Not required, but adding a name makes the output file easier to read. | Optional – you can leave it as is. |
| 9 | `*SELECT CYCLIC SYMMETRY MODES` | You asked for `NMIN=2, NMAX=2`. That is fine, but you must also request the eigenvalue output (`*FREQUENCY OUTPUT, EIGENVALUE`). Otherwise Abaqus will not write the eigenvalues to the .dat file. | Add `*FREQUENCY OUTPUT, EIGENVALUE` after the `*SELECT CYCLIC SYMMETRY MODES` line. |

The material is incomplete, so the solver will stop when it tries to assemble the stiffness matrix. | Add `*ELASTIC` (or `*ELASTIC, TYPE=ISO`) under the material definition, e.g. `*ELASTIC\n210E3, 0.3`. |
