**Short answer**

1. **`Ctrl + C`** – tries to interrupt the script (SIGINT).  
2. If nothing happens, **`Ctrl + Z`** – suspends the job, then kill it:  

   ```bash
   kill %1          # polite (SIGTERM)
   # or, if it still lives
   kill -9 %1       # force‑kill (SIGKILL)
   ```

3. If the whole terminal is unresponsive (no prompt at all), open a second terminal (or switch to a virtual console) and kill the process by its PID:

   ```bash
   pgrep -f myscript.py          # prints the PID(s)
   # or
   ps -ef | grep myscript.py | grep -v grep

   kill <PID>        # SIGTERM – try first
   kill -9 <PID>     # SIGKILL – if it refuses to die
   ```

## Quick cheat‑sheet

| Action                              | Key / Command                | Signal sent |
|-------------------------------------|------------------------------|-------------|
| Interrupt (most cases)              | **Ctrl + C**                 | SIGINT (2)  |
| Suspend (if interrupt fails)        | **Ctrl + Z**                 | SIGTSTP (20)|
| List stopped/background jobs       | `jobs`                       | –           |
| Graceful kill (by job)              | `kill %N`                    | SIGTERM (15)|
| Force kill (by job)                 | `kill -9 %N`                 | SIGKILL (9) |
| Find PID by name                    | `pgrep -f scriptname`        | –           |
| Graceful kill (by PID)              | `kill <PID>`                 | SIGTERM (15)|
| Force kill (by PID)                 | `kill -9 <PID>`              | SIGKILL (9) |

---

## Why the terminal looks “frozen”

Your script is probably printing thousands of lines (`print(i, p[0], p[1])`). The terminal has to:

1. Render each line,
2. Append it to the scroll‑back buffer,
3. Update the screen.

That I/O work can consume a lot of CPU, so the cursor appears stuck even though the process is still running. Stopping the process stops the flood of output and the terminal becomes responsive again.

## Step‑by‑step summary you can copy‑paste

```bash
# 1. Try the normal interrupt
#   (press Ctrl+C in the same terminal)
#   If the script exits → you’re done.

# 2. If nothing happens, suspend and kill by job number
Ctrl+Z          # puts the script in background as [1]+ Stopped
kill %1         # try graceful termination (SIGTERM)
# or
kill -9 %1      # force‑kill if needed

# 3. If the terminal is completely locked, use another terminal:
pgrep -f myscript.py          # get PID(s)
kill <PID>                    # try graceful stop (SIGTERM)
kill -9 <PID>                 # force kill if it won’t die
```

These commands instantly stop a runaway script and return you to a usable prompt.
