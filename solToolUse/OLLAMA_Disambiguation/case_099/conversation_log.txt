## 4. Step definition – **missing *STATIC* keyword**

### What Abaqus expects  

A static analysis step must contain a **procedure keyword** (`*STATIC`,
`*STATIC, ...` or `*STATIC, ...` with optional parameters). The generic
`*STEP` line only opens a step; the next line **must** be a procedure keyword.
If it is not, Abaqus tries to interpret the following numbers (`1.,1.`) as a
procedure definition, fails, and the model database is flagged as corrupted.

### Fix

```abaqus
*STEP, NLGEOM, INC=100

*CLOAD
N4, 3, 0.000833333
N5, 3, 0.001666666
*END STEP
```

If you want to control the time increment you can add the optional arguments
to *STATIC*:

```abaqus
*STATIC, STEADY STATE TIME=1.0, INCREMENT=0.01, MAX INCREMENT=0.1
```

> **Why the original “1.,1.” line is wrong** – those numbers are interpreted as
> the *TIME* and *INITIAL INCREMENT* arguments of a *STATIC* step, but because
> the *STATIC* keyword itself is missing the parser cannot associate them with
> any procedure, leading to a corrupted database.

## 5. CLOAD – **node set names used as node numbers**  

```abaqus
*CLOAD
N4,3,0.000833333
N5,3,0.001666666
```

### What Abaqus expects  

`*CLOAD` can be written in **two** ways:

1. **Explicit node numbers** (the classic format)  

   ```
   node, dof, magnitude
   ```

2. **Node set reference** – you must add the optional `NSET=` argument to the
   keyword and **do not** list the set name in the data lines. Example:

   ```abaqus
   *CLOAD, NSET=N4
   3, 0.000833333
   ```

   (Here the first column is the DOF, the second column is the magnitude.)

Your current syntax mixes the two: you give a *node‑set name* (`N4`) in the
first column, which Abaqus interprets as a **node number**. Since node numbers
are integers, the parser throws an error and the model database is marked as
corrupted.

### Fix  

Either **list every node** individually** (tedious but works):

```abaqus
*CLOAD
21, 3, 0.000833333
23, 3, 0.000833333
24, 3, 0.000833333
...
```

or **use the NSET option** (highly recommended):

```abaqus
*CLOAD, NSET=N4
3, 0.000833333
*CLOAD, NSET=N5
3, 0.001666666
```

> **Note:** The magnitude you gave (0.000833333) is per node. If you intend a
> *total* load of 0.000833333 N distributed over the whole set, you must divide
> it by the number of nodes in the set (e.g., `0.000833333/8` for N4 which has
> 8 nodes). Abaqus does **not** automatically distribute a load over a set.
