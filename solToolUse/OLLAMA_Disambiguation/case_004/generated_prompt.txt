Use FEniCS legacy (dolfin) to solve a 2‑D plane‑stress linear elasticity problem on a stepped polygon domain defined by eight vertices.  
Define the polygon with a total width of 2.0 m and a total height of 1.0 m, consisting of two horizontal steps: the lower step occupies the full width (2.0 m) and a height of 0.5 m, the upper step is centered and spans 1.2 m in width with a height of 0.5 m.  
The vertex coordinates (counter‑clockwise starting at the lower‑left corner) are:  
(0.0, 0.0), (2.0, 0.0), (2.0, 0.5), (1.6, 0.5), (1.6, 1.0), (0.4, 1.0), (0.4, 0.5), (0.0, 0.5).  

Create a mesh of the domain with 72 triangular elements (use `Mesh` with `generate_mesh` or `RectangleMesh` refined to achieve the required element count).  

Define a vector‑valued continuous Lagrange function space `V` of degree 1 for the displacement field **u**.  

Use the plane‑stress constitutive matrix  
\( C = \frac{E}{1-\nu^{2}} \begin{bmatrix} 1 & \nu & 0 \\ \nu & 1 & 0 \\ 0 & 0 & \frac{1-\nu}{2} \end{bmatrix} \)  
with \(E = 70\text{e}9\) Pa and \(\nu = 0.33\).  

Form the strain tensor \(\varepsilon(\mathbf{u}) = \frac{1}{2}(\nabla\mathbf{u} + \nabla\mathbf{u}^T)\) and the stress tensor \(\sigma = C:\varepsilon(\mathbf{u})\).  

Apply body force \(\mathbf{f} = (0,\,-\rho g)\) with \(\rho = 2700\) kg/m³ and \(g = 9.81\) m/s².  

Boundary conditions:  
- Bottom edge (y = 0) is fixed: \(\mathbf{u} = (0,0)\).  
- On the portion of the top edge belonging to the upper step (y = 1.0, 0.4 ≤ x ≤ 1.6) apply a Robin (elastic foundation) condition \(\sigma\cdot\mathbf{n} + k\,\mathbf{u} = \mathbf{0}\) with spring stiffness \(k = 1.0\text{e}8\) N/m³.  

Form the weak variational problem: find \(\mathbf{u}\in V\) such that  
\(\int_{\Omega} \varepsilon(\mathbf{v}):C:\varepsilon(\mathbf{u})\,\mathrm{d}x - \int_{\Gamma_{\text{top}}} k\,\mathbf{v}\cdot\mathbf{u}\,\mathrm{d}s = \int_{\Omega} \mathbf{v}\cdot\mathbf{f}\,\mathrm{d}x\)  
for all test functions \(\mathbf{v}\in V\) that vanish on the fixed bottom edge.  

Solve the linear system with a direct solver (e.g., `LUSolver`).  

Post‑process:  
- Compute the von Mises stress \(\sigma_{vm} = \sqrt{\sigma_{xx}^2 - \sigma_{xx}\sigma_{yy} + \sigma_{yy}^2 + 3\sigma_{xy}^2}\) at each cell.  
- Export the displacement field and von Mises stress to VTK files for visualization.  

The implementation must use only the legacy dolfin API (no `fenicsx`), assume unit thickness, and run as a single Python script.
