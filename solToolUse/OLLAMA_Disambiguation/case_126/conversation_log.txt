Q: **What the message means**

`The specified load case is not supported for the perturbation step.`  

Abaqus is telling you that the *STEP* you have defined as  

```abaqus
*STEP,PERTURBATION
10
*END STEP
```

cannot be used with the load definition that precedes it.  

A *PERTURBATION* step is a **linear‑perturbation** analysis.  
Only loads that are *perturbation loads* (i.e. incremental loads that are
applied **inside the perturbation step**) are allowed.  
A static step that already contains a *CLOAD* (or any other load) cannot be
re‑used as a “load case’’ for a perturbation step – Abaqus does not know what
to perturb.

In addition, the way the loads are written in the static step is also
incorrect (you are trying to apply a load to a node **set** with the syntax
used for a single node).

---

## How to fix it

You have three options, depending on what you really want to do.

### 1. Only a static (non‑linear) analysis – delete the perturbation step

If you only need the static solution with the two point loads, simply
remove the perturbation step:

```abaqus
*STEP,NLGEOM
1.,1.
*CLOAD
N4,3,80.33333
N5,3,160.66666
*END STEP
```

(You will also need to correct the *CLOAD* syntax – see below.)

### 2. Linear buckling / eigenvalue analysis – use a **BUCKLE** step

If you want a linear buckling analysis (eigenvalue buckling) you must
replace the perturbation step with a *BUCKLE* step and request the
required number of eigenvalues:

```abaqus
*STEP,BUCKLE
1.,1.,10          ! 10 eigenvalues will be extracted
*CLOAD
N4,3,80.33333
N5,3,160.66666
*END STEP
```

No *PERTURBATION* keyword is needed.

### 3. Linear perturbation (frequency, modal, sensitivity) – define a
proper perturbation step

If you really need a linear‑perturbation analysis (e.g. a frequency
analysis) you must:

* keep the static step (or a *STATIC* step) that brings the model to the
  pre‑loaded configuration,
* start a new *PERTURBATION* step **without** any loads (the loads are
  already present in the deformed configuration), and
* request the desired output (e.g. *FREQUENCY*).

```abaqus
*STEP,NLGEOM
1.,1.
*CLOAD
N4,3,80.33333
N5,3,160.66666
*END STEP

*STEP,PERTURBATION
*FREQUENCY
10                ! request 10 natural frequencies
*END STEP
```

Again, the loads are **not** repeated inside the perturbation step.
