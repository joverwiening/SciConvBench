Use FEniCS legacy (dolfin) to solve a 2‑D small‑strain linear elasticity plane‑stress problem on the right‑triangular domain with vertices (0,0), (1,0) and (0,0.5).  

Create the mesh by generating an 8 × 8 structured rectangular grid on the rectangle [0,1] × [0,0.5], triangulating each rectangle into two right triangles, and then discarding all triangles that lie outside the right‑triangle defined by x + 2y ≤ 1. This yields approximately 64 triangular elements.  

Define a vector‑valued continuous Lagrange function space of degree 1 for the displacement field **u**.  

Use the linear strain tensor ε(**u**) = sym(∇**u**) and the plane‑stress constitutive matrix  

D = (E/(1‑ν²)) * [[1, ν, 0],
                 [ν, 1, 0],
                 [0, 0, (1‑ν)/2]]  

with E = 70e9 Pa and ν = 0.33.  

Compute the Cauchy stress σ = D · ε(**u**) (treated as a 3‑component vector [σ_xx, σ_yy, σ_xy]ᵀ).  

Apply body force **f** = (0, ‑ρ g) with ρ = 2700 kg/m³ and g = 9.81 m/s².  

Impose a Neumann traction **t** = (4000, 0) Pa on the vertical boundary x = 0 (the side of the triangle where x = 0).  

Impose a Dirichlet condition **u** = (0, 0) on the sloping edge defined by x + 2y = 1 (the clamped edge).  

Form the variational problem: find **u** in the displacement space such that  

∫_Ω ε(**v**) : σ(**u**) dx = ∫_Ω **v**·**f** dx + ∫_{Γ_N} **v**·**t** ds  

for all test functions **v** in the same space, where Γ_N is the traction boundary (x = 0).  

Assemble the linear system and solve it with a direct linear solver (e.g., “lu”).  

After solving, compute the von Mises stress at each point using  

σ_vM = sqrt(σ_xx² - σ_xx σ_yy + σ_yy² + 3 σ_xy²).  

Export the displacement field and the von Mises stress field (e.g., to VTK files) for visualization.  

The implementation must use only the legacy dolfin API (no dolfinx) and assume unit thickness for the plane‑stress formulation.
