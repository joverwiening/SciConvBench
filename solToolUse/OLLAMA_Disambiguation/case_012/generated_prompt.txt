Use legacy FEniCS (dolfin) to solve the incompressible finite‑strain hyperelastic problem for a perforated strip in plane strain.
Define the rectangular domain Ω = (0, 1.0) m × (0, 0.20) m with a circular hole of radius a = 0.04 m centred at (0.50, 0.10) m.
Model the material as an isotropic incompressible neo‑Hookean solid with Young’s modulus E = 5 MPa and Poisson’s ratio ν = 0.5, using the standard incompressible strain‑energy function and a mixed displacement‑pressure formulation (unknowns u = (u_x,u_y) and hydrostatic pressure p).
Set the deformation gradient F = I + grad(u) and its determinant J = det(F); enforce incompressibility by the pressure field p such that J = 1.
Apply the following boundary conditions:
- Left edge (x = 0): u_x = 0, u_y = 0 (fixed).
- Right edge (x = 1.0): prescribe horizontal displacement u_x = 0.060 m and enforce u_y = 0.
- Top edge (y = 0.20), bottom edge (y = 0), and the hole boundary: traction‑free (natural Neumann condition).
Discretize the domain with a conforming triangular mesh of uniform element size approximately 5 mm, and add local refinement around the circular hole to capture stress gradients (e.g., reduce element size to about 2 mm within a band of width 0.02 m around the hole).
Formulate the mixed variational problem using appropriate function spaces (e.g., P2 elements for displacement and P1 elements for pressure) and solve the nonlinear system with Newton’s method, using a relative tolerance of 1e‑6 and a maximum of 25 iterations.
After convergence, compute the Cauchy stress tensor σ from the deformation gradient and pressure, and evaluate the von Mises stress from σ.
