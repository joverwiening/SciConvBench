**Why the “Reference point not defined” error occurs**

When a **frequency (modal) step** is created with  

```text
*STEP … FREQ=YES
```  

Abaqus automatically inserts a **hidden history‑output request** for the displacement of **node 1**.  

* In a **static** step this request is harmless – the solver just writes the displacement of node 1 to the *.dat* file.  
* In a **modal** step the request is interpreted as a **reference‑point output**.  
  * The solver therefore looks for a **reference point whose label is 1** (the point that would be used to monitor rigid‑body motions).  
  * Because the model does **not** contain a reference point with label 1, the modal solver aborts and prints  

```
ERROR: Reference point not defined
```

The element type (`C3D8I`) is not the cause; the error is triggered by a **modal step without any explicit output request** together with **no reference point** of the expected label.

---

## What a modal analysis really needs

| Requirement | How to supply it | Why it is mandatory for a modal step |
|-------------|------------------|--------------------------------------|
| **Elastic stiffness** (`*ELASTIC`) | Define Young’s modulus and Poisson’s ratio for the material. | Provides the global stiffness matrix **K** for the eigen‑value problem *K u = λ M u*. |
| **Mass density** (`*DENSITY`) | Add a `*DENSITY` card (or `*MATERIAL, DENSITY=`). | Supplies the global mass matrix **M**. |
| **Removal of rigid‑body modes** (boundary conditions) | Fully constrain six DOFs (e.g., `*BOUNDARY, ENCASTRE`). | Prevents the first six eigenvalues from being zero and eliminates the need for a reference point. |
| **Frequency step** (`*STEP … FREQ=YES` + `*FREQUENCY`) | Create a step of type **FREQUENCY** (or **MODES**) and request the desired number of modes. | Activates the modal solver. |
| **Explicit output request** (`*NODE PRINT`, `*EL PRINT`, `*FIELD OUTPUT`, …) | Add any output request inside the frequency step. | Suppresses the hidden node‑1 request, so the solver no longer looks for a reference point. |

If any of the items above is missing, the modal solver will stop with an error (as above) or return meaningless results.

---

## Two ways to eliminate the error

| Option | What you do | When to use it |
|--------|-------------|----------------|
| **A – Add an explicit output request** (recommended) | Insert, for example, `*NODE PRINT, NSET=RIGHT, U` (or any other output) inside the frequency step. | The hidden node‑1 request is suppressed; no extra geometry is needed. |
| **B – Define a reference point with label 1** | Create a reference point (`*REFERENCE POINT, REF=1`) and, if desired, tie it to the model. | Works, but a reference point is usually unnecessary for a simple cantilever modal analysis. |

**Option A** is the simplest and works for virtually every cantilever modal study.

---

## Minimal, corrected input file (Option A)

```abaqus
*HEADING
Cantilever beam – modal analysis with C3D8I elements

*PART, NAME=BEAM
*NODE
# (list of node coordinates)
*ELEMENT, TYPE=C3D8I, ELSET=ALL
# (list of element connectivities)
*END PART

*ASSEMBLY, NAME=ASSEMBLY
*INSTANCE, PART=BEAM, NAME=BEAM-1
*END INSTANCE
*END ASSEMBLY

*MATERIAL, NAME=STEEL
*DENSITY
7.85e-09               ; density (consistent with your unit system)
*ELASTIC
210000., 0.3           ; Young’s modulus, Poisson’s ratio
*END MATERIAL

*SET, NSET=LEFT, NODE
# (nodes at the fixed end, e.g. 1,2,3,…)
*SET, NSET=RIGHT, NODE
# (any node you want to print displacement for)
*END SET

*BOUNDARY
LEFT, ENCASTRE         ; fully fix the left end → removes the 6 rigid‑body modes
*END BOUNDARY

*STEP, NLGEOM=NO, MODES=10, FREQ=YES
*FREQUENCY, NMODES=10, EIGENSOLVER=SUBSPACE
*OUTPUT, FIELD
*NODE PRINT, NSET=RIGHT, U   ; explicit output request – suppresses hidden node‑1 request
*END STEP
```

### What each added block does  

| Block | Content | Effect |
|-------|---------|--------|
| `*DENSITY` | `7.85e-09` | Supplies the mass matrix **M** (units must match the rest of the model). |
| `*ELASTIC` | `210000., 0.3` | Supplies the stiffness matrix **K**. |
| `*BOUNDARY … ENCASTRE` | `LEFT, ENCASTRE` | Fully constrains the left end → eliminates the six zero‑frequency rigid‑body modes. |
| `*STEP … FREQ=YES` + `*FREQUENCY` | `NMODES=10` (or any number you need) | Runs a **modal (frequency) analysis** and extracts the requested number of eigenvalues/mode shapes. |
| `*NODE PRINT, NSET=RIGHT, U` | (any explicit output) | Overrides the hidden node‑1 history request, so the solver no longer looks for a reference point. |

## Quick pre‑run checklist  

| ✅ | Item | Why it matters |
|---|------|----------------|
| 1 | **Consistent unit system** (e.g., mm‑tonne‑MPa) | All geometric, material, and density values must be in the same system. |
| 2 | **Node sets `LEFT` and `RIGHT`** correctly defined | `LEFT` must contain the nodes you want to fully fix; `RIGHT` can be any set (used only for the explicit output request). |
| 3 | **Number of modes (`NMODES`)** appropriate for your study | Choose enough modes to cover the frequency range of interest (10–20 is typical for a simple cantilever). |
| 4 | **Solver option** – default `SUBSPACE` works for most problems; for very large models you may switch to `EIGENSOLVER=LANCZOS`. |
| 5 | **Mesh quality** – avoid highly distorted C3D8I elements | Poor element quality can cause convergence warnings in the eigen‑value extraction. |

---

## Expected results after a successful run  

* **`.dat` file** – a table titled **“FREQUENCY ANALYSIS”** listing eigenvalues (ω) and the corresponding natural frequencies *f = ω/(2π)*.  
* **`.odb` file** – a **Mode** output database that can be opened with **Abaqus/Viewer**; use *Result → Plot Mode Shapes* to visualise each mode.

If you need more modes, increase `NMODES` (or add another frequency step). To limit the frequency range, use the `*FREQUENCY, FREQ=…` option.

---

## TL;DR – Four steps to get rid of the error  

1. **Add material stiffness (`*ELASTIC`) and density (`*DENSITY`).**  
2. **Fully fix the left end** (e.g., `LEFT, ENCASTRE`) to suppress the six rigid‑body modes.  
3. **Run the analysis in a frequency step** (`*STEP … FREQ=YES` + `*FREQUENCY`).  
4. **Add any explicit output request** (e.g., `*NODE PRINT, NSET=RIGHT, U`) to override the hidden node‑1 request.  

After these four steps the model runs without the “Reference point not defined” error and provides the natural frequencies of the cantilever beam.
