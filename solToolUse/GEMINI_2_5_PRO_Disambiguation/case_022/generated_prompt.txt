The simulation will be run using the FEniCS legacy library (dolfin).
The problem to be solved is 2D small-strain linear elasticity under plane-stress conditions.
The geometry is a rectangle defined by the corners (0, 0) and (1.0, 0.20) meters.
A uniform structured mesh of 20x4 quadrilateral elements will be used.
The material is defined by a Young's modulus of 200 GPa and a Poisson's ratio of 0.3.
The displacement vector field will be discretized using a continuous Galerkin function space of polynomial degree 1.
The left boundary (x=0) is fixed with a Dirichlet boundary condition of u_x = 0 and u_y = 0.
The right boundary (x=1) has a prescribed Dirichlet boundary condition of u_x = 0.001 and u_y = 0.
The top (y=0.20) and bottom (y=0) boundaries are traction-free.
The linear system will be solved using a direct solver.
The x-component of the resulting displacement field will be plotted and saved as a PNG file named `q1_ux.png`.
The complete displacement vector field will be saved in XDMF format to a file named `q1_displacement.xdmf`.
