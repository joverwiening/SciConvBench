Create a file named case_090.inp in the working directory.
The content of case_090.inp is the provided CalculiX input deck.
Execute the CalculiX solver on the input file using either the command `ccx -i case_090` or `ccx case_090`.
Determine if the run was successful by checking the content of the `case_090.sta` file.
A successful run is indicated by the presence of the text 'JOB COMPLETED' in `case_090.sta`.
Execute the command `ccx -v` to obtain the CalculiX version string.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object has a key "solver" with the string value "calculix".
The JSON object has a key "case_id" with the string value "case_090".
The JSON object has a key "status" with the string value "success" if the run was successful, and "error" otherwise.
The JSON object has a key "ccx_version" with the version string obtained from the `ccx -v` command.
The JSON object has a key "artifacts" with an empty array as its value.
The JSON object has a key "notes" containing a string with the exact command used to run the solver.
If the run status is "error", the "notes" string must also include the error message and identify which file indicated the failure.
