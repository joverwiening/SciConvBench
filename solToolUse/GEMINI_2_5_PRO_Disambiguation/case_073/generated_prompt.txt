Create a file named `case_073.inp` in the working directory.
The content of `case_073.inp` is the text provided in the `Input deck` section.
Execute the CalculiX solver on the input file `case_073.inp`.
Attempt to run the solver using the command `ccx -i case_073`.
If the first command fails, attempt to run the solver using the command `ccx case_073`.
Check the file `case_073.sta` to determine the run status.
If `case_073.sta` contains the string 'JOB COMPLETED', the run is considered successful.
Otherwise, the run is considered to have failed.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object.
The value for the key "solver" is the string "calculix".
The value for the key "case_id" is the string "case_073".
The value for the key "status" is the string "success" if the run was successful, and "error" otherwise.
The value for the key "ccx_version" is the version string obtained by running the command `ccx -v`.
The value for the key "artifacts" is an empty list.
The value for the key "notes" is a string containing the exact command used to run the solver.
If the run failed, the "notes" string will also include the error message and the name of the file that indicated the failure.
