Create a file named `case_068.inp` in the working directory.
The content of `case_068.inp` is the text provided in the `Input deck` section.
Execute the CalculiX solver on the input file.
The command to execute is `ccx -i case_068` or `ccx case_068`.
Determine the version of the CalculiX solver by running `ccx -v`.
Check for the existence of a file named `case_068.sta` after the solver is executed.
Read the content of the `case_068.sta` file to determine the job status.
The job is successful if the file contains the string 'JOB COMPLETED'.
If the job is not successful, capture any error messages from the solver's output.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object.
The `solver` key will have the value "calculix".
The `case_id` key will have the value "case_068".
The `status` key will have the value "success" if the job completed successfully, otherwise "error".
The `ccx_version` key will contain the version string obtained from the solver.
The `artifacts` key will be an empty array.
The `notes` key will contain a string with the exact CalculiX command used for the execution.
If the status is "error", the `notes` key will also include the error message and the name of the file that indicated the failure.
