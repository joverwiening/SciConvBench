The simulation uses the FEniCS legacy library (dolfin).
The problem to be solved is nonlinear hyperelasticity.
The geometry is a unit cube.
The mesh is generated using UnitCubeMesh(24, 16, 16).
The function space is a VectorFunctionSpace with Lagrange elements of degree 1.
The material is defined by Young's modulus E = 10.0 and Poisson's ratio ν = 0.3.
The Lamé parameters are mu = E/(2*(1+nu)) and lambda = E*nu/((1+nu)*(1-2*nu)).
The compressible neo-Hookean strain energy density function is Psi = (mu/2)*(tr(C) - 3) - mu*ln(J) + (lambda/2)*(ln(J))**2.
The deformation gradient is F = I + grad(u).
The right Cauchy-Green tensor is C = F.T * F.
The determinant of the deformation gradient is J = det(F).
The boundary at x = 0 is clamped, with a displacement of (0, 0, 0).
A rotational displacement is prescribed on the boundary at x = 1.
The displacement vector u = (ux, uy, uz) on the x = 1 face is defined by the expressions:
ux = 0.0
uy = 0.5 * ((y - 0.5)*(cos(pi/3) - 1) - (z - 0.5)*sin(pi/3))
uz = 0.5 * ((y - 0.5)*sin(pi/3) + (z - 0.5)*(cos(pi/3) - 1))
A constant body force B = (0, -0.5, 0) is applied to the entire domain.
A constant traction vector T = (0.1, 0, 0) is applied to the boundary surface at z = 1.
The nonlinear displacement problem is solved using Newton's method by minimizing the total potential energy.
