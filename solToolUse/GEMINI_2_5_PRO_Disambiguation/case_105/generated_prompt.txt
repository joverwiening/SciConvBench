Create a file named case_105.inp in the current working directory.
The content of case_105.inp must be the exact text from the 'Input deck' section.
Execute the command `ccx -v` and store the output as the CalculiX version string.
Attempt to run the simulation using the command `ccx -i case_105`.
If the command `ccx -i case_105` fails, attempt to run the simulation using the command `ccx case_105`.
The command that is executed will be referred to as the executed command.
Check for the existence of a file named case_105.sta.
If case_105.sta exists, check if it contains the string 'JOB COMPLETED'.
If case_105.sta exists and contains 'JOB COMPLETED', the run status is 'success'.
In all other situations, the run status is 'error'.
Create a file named results.json in the current working directory.
The results.json file will contain a JSON object with six keys: "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
The value for the "solver" key is the string "calculix".
The value for the "case_id" key is the string "case_105".
The value for the "status" key is the determined run status string, either "success" or "error".
The value for the "ccx_version" key is the stored CalculiX version string.
The value for the "artifacts" key is an empty list.
The value for the "notes" key is a string containing the executed command.
If the run status is "error", append the error message and the name of the file that indicated the failure to the "notes" string.
