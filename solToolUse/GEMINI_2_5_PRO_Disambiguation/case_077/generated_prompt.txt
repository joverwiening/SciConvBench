Create a file named `case_077.inp` in the working directory.
The content for `case_077.inp` must be the text from the `Input deck` section, starting with `**` and ending with `*END STEP`.
Execute the CalculiX solver by first attempting the command `ccx -i case_077`.
If the first command fails, attempt to run the solver with the command `ccx case_077`.
Determine the solver version by executing `ccx -v` and capture the output string.
After the run attempt, check the `case_077.sta` file to determine if the job completed successfully.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object with six fields: `solver`, `case_id`, `status`, `ccx_version`, `artifacts`, and `notes`.
Set the `solver` field to "calculix".
Set the `case_id` field to "case_077".
Set the `status` field to "success" if the run completed successfully, otherwise set it to "error".
Set the `ccx_version` field to the version string obtained from the solver.
Set the `artifacts` field to an empty list.
Set the `notes` field to a string containing the exact command used to run the solver.
If the solver run resulted in an error, append the error message and the name of the file indicating the failure to the `notes` field.
