The simulation will be implemented using the FEniCS legacy library, dolfin.
The problem to be solved is 2D small-strain linear elasticity.
The variational formulation will be based on the plane-stress assumption.
The geometry is a rectangle defined by the domain (0, 1.0) x (0, 0.20) meters.
A uniform structured mesh of 40x8 subdivisions will be used.
The material is linear elastic with a Young's modulus of 200 GPa and a Poisson's ratio of 0.3.
The displacement field will be discretized using continuous Lagrange vector elements of polynomial degree 2.
The left boundary, where x=0, is fixed with displacement u=(0,0).
The top boundary, where y=0.2, is subjected to a uniform downward traction of t=(0, -2000) N/m.
The right boundary, where x=1.0, is traction-free.
The bottom boundary, where y=0, is traction-free.
The linear system will be solved using a direct solver.
The vertical displacement component, u_y, will be plotted and saved as a PNG file named q2_uy.png.
The full displacement vector field will be saved to an XDMF file.
