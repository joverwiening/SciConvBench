The simulation solves a 2D plane-strain linear elasticity problem using the FEniCS legacy library (dolfin).
The geometry is a rectangle defined by the domain (0, 1.0) x (0, 0.20) meters.
A structured mesh of 100x20 quadrilateral elements is used to discretize the domain.
The material model is linear elastic with a Young's modulus of 5 MPa and a Poisson's ratio of 0.49.
The analysis is performed under the assumption of plane strain.
A mixed displacement-pressure formulation is used to handle the nearly incompressible material.
The displacement field is discretized using second-order continuous Lagrange elements (P2).
The pressure field is discretized using first-order continuous Lagrange elements (P1).
The left boundary (x=0) is fixed, with displacement components u_x and u_y set to zero.
The right boundary (x=1.0) has a prescribed horizontal displacement of u_x = 0.03 m and a vertical displacement of u_y = 0 m.
The top (y=0.20) and bottom (y=0) boundaries are traction-free.
The resulting saddle-point linear system is solved using a direct solver.
The magnitude of the displacement field is plotted as a color map and saved to a file named q10_disp.png.
The displacement vector field is saved to an XDMF file named q10_displacement.xdmf for visualization.
