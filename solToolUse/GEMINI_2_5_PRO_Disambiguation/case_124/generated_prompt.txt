Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the following key-value pairs.
The `solver` key must have the string value "calculix".
The `case_id` key must have the string value "case_124".
The `status` key must have the string value "success" if the job completed successfully, or "error" otherwise.
The `ccx_version` key must have a string value containing the version information from the solver.
The `artifacts` key must have an empty list as its value.
The `notes` key must have a string value containing the exact command used to run the solver.
If the run fails, the `notes` string must also include the error message and the name of the file that indicated the failure.
