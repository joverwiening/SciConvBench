Use the FEniCS legacy library (dolfin).
Define the simulation as a 2D plane stress linear elasticity problem.
Create a parallelogram mesh with vertices at (0,0), (1,0), (1.2,0.3), and (0.2,0.3).
Use 6 mesh divisions in the first direction and 6 mesh divisions in the second direction, creating 72 triangular elements.
Define a vector function space using continuous Lagrange elements of polynomial degree 2.
Set Young's modulus E to 70e9 Pa.
Set Poisson's ratio ν to 0.33.
Apply a constant body force representing gravity f = (0, -2700 * 9.81) N/m^3.
Apply a Dirichlet boundary condition to fix the displacement u = (0, 0) on the right boundary of the domain.
The right boundary is the line segment connecting vertices (1,0) and (1.2,0.3).
Apply a traction vector T = (6000, 0) N/m^2 on the left boundary of the domain.
The left boundary is the line segment connecting vertices (0,0) and (0.2,0.3).
The top and bottom boundaries are traction-free.
Solve the variational problem for the displacement vector u.
Use a direct linear solver with LU factorization.
After solving for displacement, compute the Cauchy stress tensor using the plane stress constitutive relation.
From the Cauchy stress tensor, calculate the scalar von Mises stress field.
Save the displacement field and the von Mises stress field to a file for visualization.
