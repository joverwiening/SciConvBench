Execute the CalculiX solver on the `case_048.inp` file using either the command `ccx -i case_048` or `ccx case_048`.
Determine if the run was successful by checking for a completion message in the `case_048.sta` file.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "case_048".
The JSON object must have a key "status" with the string value "success" for a successful run or "error" for a failed run.
The JSON object must have a key "ccx_version" containing the version string from the `ccx -v` command.
The JSON object must have a key "artifacts" with a value of an empty list.
The JSON object must have a key "notes" with a string value.
The "notes" string must record the exact command used to run the solver.
If the run failed, the "notes" string must also include the error message and the name of the file that indicated the failure.
