Create a file named `case_083.inp` in the current working directory.
The content of `case_083.inp` must be the text provided in the `Input deck` section.
Execute the CalculiX solver on the input file using the command `ccx -i case_083` or `ccx case_083`.
After the execution attempt, check the contents of the file `case_083.sta`.
If `case_083.sta` contains the string 'JOB COMPLETED', the run is considered a success.
Any outcome other than the success condition is considered an error.
Determine the CalculiX version by running a command like `ccx -v`.
Create a file named `results.json` in the current working directory.
The `results.json` file must contain a JSON object with the following key-value pairs.
The `solver` key must have the string value "calculix".
The `case_id` key must have the string value "case_083".
The `status` key must have the string value "success" if the run succeeded, or "error" if it failed.
The `ccx_version` key must have a string value containing the version information obtained from the solver.
The `artifacts` key must have an empty list `[]` as its value.
The `notes` key must contain a string with the exact command used to run the solver.
If the run status is "error", the `notes` string must also include the error message and the name of the file that indicated the failure.
