Create the file `case_046.inp` in the working directory with the provided input deck content.
Execute the command `ccx -v` to get the solver version string.
Run the CalculiX solver using the command `ccx -i case_046` or `ccx case_046`.
Check the contents of the file `case_046.sta` for a successful termination message such as 'JOB COMPLETED'.
If the run is successful, set the status to "success".
If the run fails, set the status to "error".
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object.
The value for the key "solver" is the string "calculix".
The value for the key "case_id" is the string "case_046".
The value for the key "status" is the status determined from the run.
The value for the key "ccx_version" is the version string obtained from the `ccx -v` command.
The value for the key "artifacts" is an empty list.
The value for the key "notes" is a string containing the exact CalculiX command used to run the simulation.
If the run failed, the "notes" string will also include the error message and the file that indicated the failure.
