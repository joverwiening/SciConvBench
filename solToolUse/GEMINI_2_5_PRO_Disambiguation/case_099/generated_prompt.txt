Create a file named `case_099.inp` in the working directory.
Write the provided input deck content into `case_099.inp`.
Execute the command `ccx -v` to get the solver version string.
Execute the CalculiX solver for the input file `case_099.inp`.
Use the command `ccx -i case_099` or `ccx case_099` to run the solver.
Check the contents of the output file `case_099.sta`.
Determine the run status by searching for a successful termination message in `case_099.sta`.
Create a file named `results.json` in the working directory.
Write a JSON object to `results.json`.
The JSON object must contain a "solver" key with the value "calculix".
The JSON object must contain a "case_id" key with the value "case_099".
The JSON object must contain a "status" key with the value "success" if the run completed successfully, otherwise "error".
The JSON object must contain a "ccx_version" key with the version string obtained from the solver.
The JSON object must contain an "artifacts" key with an empty list as its value.
The JSON object must contain a "notes" key.
The value of the "notes" key must be a string containing the exact command used to run the solver.
If the run status is "error", the "notes" string must also include the error message and the file that indicated the failure.
