The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem to be solved is a 2D small-strain linear elasticity problem.
The analysis will be conducted under plane stress conditions.
The geometry is a rectangle defined by the domain (0, 1.0) x (0, 0.20) meters.
The domain is meshed with a structured 80x16 grid.
The domain consists of two material subdomains with a perfect bond at the interface y = 0.10 m.
The bottom subdomain, where 0 <= y <= 0.10 m, is made of Steel.
The top subdomain, where 0.10 < y <= 0.20 m, is made of Aluminum.
The material properties for Steel are Young's modulus E = 200 GPa and Poisson's ratio ν = 0.30.
The material properties for Aluminum are Young's modulus E = 70 GPa and Poisson's ratio ν = 0.30.
The left boundary of the domain (x = 0) is fixed, with displacement u = (0, 0).
A uniform downward line traction of t = (0, -5000) N/m is applied to the right boundary (x = 1).
The top (y = 0.20) and bottom (y = 0) boundaries are traction-free.
The linear system will be solved using a direct solver.
The computed displacement field will be saved to a file in XDMF format.
A color plot of the displacement magnitude will be saved as a PNG file named q7_disp.png.
