Create a file named `case_101.inp` in the working directory.
The content of `case_101.inp` must be the text provided in the "Input deck" section.
Execute the command `ccx -v` and capture its output for the CalculiX version string.
Execute the CalculiX solver for the input file `case_101.inp`.
First, attempt to run the solver using the command `ccx -i case_101`.
If the command `ccx -i case_101` fails, then attempt to run the solver using the command `ccx case_101`.
Store the exact command that was used to run the solver.
After the solver execution, check for the existence of the file `case_101.sta`.
If `case_101.sta` exists, read its contents to determine if the run succeeded.
A successful run is indicated by the presence of the string 'JOB COMPLETED' in `case_101.sta`.
If `case_101.sta` is not created or does not contain 'JOB COMPLETED', the run has failed.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object must have a key `solver` with the string value `calculix`.
The JSON object must have a key `case_id` with the string value `case_101`.
The JSON object must have a key `status` with the string value `success` if the run was successful.
The JSON object must have a key `status` with the string value `error` if the run failed.
The JSON object must have a key `ccx_version` with the version string captured from the `ccx -v` command.
The JSON object must have a key `artifacts` with an empty array value.
The JSON object must have a key `notes` containing a string with the exact solver command that was used.
If the run failed, the `notes` string must also include the error message and identify which file indicated the failure.
