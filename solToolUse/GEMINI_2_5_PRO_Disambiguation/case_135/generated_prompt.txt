Create a file named `case_135.inp` in the working directory.
The content of `case_135.inp` must be the text provided in the `Input deck` section.
Execute the CalculiX solver by running the command `ccx -i case_135`.
If the command `ccx -i case_135` fails, attempt to run `ccx case_135`.
Capture the standard error stream from the CalculiX execution.
Determine the run's success by checking for the phrase 'JOB COMPLETED' in the `case_135.sta` file.
If the phrase 'JOB COMPLETED' is present in `case_135.sta`, the run is a "success".
Any other outcome, including the absence of `case_135.sta` or the absence of the success phrase, constitutes an "error".
Execute the command `ccx -v` to get the solver version string.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "case_135".
The JSON object must have a key "status" with the string value "success" or "error" based on the run outcome.
The JSON object must have a key "ccx_version" with a string value equal to the output of the `ccx -v` command.
The JSON object must have a key "artifacts" with an empty list `[]` as its value.
The JSON object must have a key "notes" containing a string with the exact command used to run the simulation.
If the status is "error", the "notes" string must also include the full content of the standard error stream from the CalculiX execution and state that the failure was indicated by the `case_135.sta` file.
