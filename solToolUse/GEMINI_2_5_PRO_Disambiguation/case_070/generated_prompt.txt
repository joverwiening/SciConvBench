Create a file named `case_070.inp` in the working directory with the provided input deck content.
Execute the command `ccx -v` to get the CalculiX version string.
Attempt to run the solver using the command `ccx -i case_070`.
If the previous command fails, attempt to run the solver using the command `ccx case_070`.
After the solver run, check the contents of the file `case_070.sta`.
If `case_070.sta` contains a successful termination message such as 'JOB COMPLETED', the run is considered a success.
If a successful termination message is not found in `case_070.sta`, the run is considered an error.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "case_070".
The JSON object must have a key "status" with the string value "success" if the run succeeded, or "error" if it failed.
The JSON object must have a key "ccx_version" with the version string obtained from the `ccx -v` command.
The JSON object must have a key "artifacts" with an empty array value.
The JSON object must have a key "notes" with a string value containing the exact ccx command used for the run.
If the run status is "error", the "notes" string must also include the error message and the name of the file that indicated the failure.
