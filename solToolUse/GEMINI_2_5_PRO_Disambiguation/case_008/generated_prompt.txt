The simulation will be run using the FEniCS legacy library (dolfin).
The problem is a 2D small-strain orthotropic elasticity problem under plane-stress conditions.
The geometry is a rectangle defined by the domain Omega = (0, 1.0) x (0, 0.20) meters.
A structured mesh of 50 elements in the x-direction and 25 elements in the y-direction will be generated over the domain.
The displacement field will be approximated using continuous Lagrange finite elements of polynomial degree 2.
The local orthotropic material properties are E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
The local material axes are rotated 30 degrees counter-clockwise with respect to the global x-y axes.
The bottom edge of the plate (y=0) is fixed, with displacement components u_x = 0 and u_y = 0.
The top edge of the plate (y=0.20) is subjected to a uniform downward traction vector of (0, -10e6) N/m.
The vertical sides (x=0 and x=1) are traction-free.
The resulting linear system of equations will be solved using a direct solver.
After solving for the displacement field, the von Mises stress field will be computed.
A color plot of the x-component of displacement will be saved to a file named q8_ux.png.
A color plot of the von Mises stress will be saved to a file named q8_vm.png.
The displacement vector field and the stress tensor field will be saved to a file named q8_solution.xdmf.
