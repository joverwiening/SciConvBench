Create a file named `case_061.inp` in the working directory.
The content of `case_061.inp` must be the text provided in the "Input deck" section.
Execute the CalculiX solver on the input file.
The command to execute the solver is either `ccx -i case_061` or `ccx case_061`.
Determine the version of the CalculiX solver by running `ccx -v`.
After the run, check the contents of the `case_061.sta` file.
If `case_061.sta` contains a successful termination message such as 'JOB COMPLETED', the run is considered a success.
Otherwise, the run is considered an error.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the following key-value pairs.
The value for the key "solver" must be the string "calculix".
The value for the key "case_id" must be the string "case_061".
The value for the key "status" must be the string "success" if the run succeeded, or "error" if it failed.
The value for the key "ccx_version" must be the version string obtained from the solver.
The value for the key "artifacts" must be an empty list.
The value for the key "notes" must be a string containing the exact command used to run the solver.
If the run failed, the "notes" string must also include the error message and the name of the file that indicated the failure.
