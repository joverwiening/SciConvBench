Use the FEniCS legacy library (dolfin).
The simulation domain is a 2D rectangle from (0,0) to (1.0, 0.2).
Create a structured rectangular mesh with 100 elements in the x-direction and 20 elements in the y-direction.
Use a Vector Function Space with Continuous Galerkin elements of polynomial degree 2 for the displacement field.
The material model is linear elasticity under plane stress conditions.
The Poisson's ratio is a constant value of 0.3.
The Young's modulus is spatially varying according to the expression E(y) = 1e11 + 1e11 * (y / 0.2) in Pascals.
The left boundary (x=0) is fixed with a displacement of (0, 0).
A uniform traction vector of (2e6, 0) N/m^2 is applied to the right boundary (x=1).
The top (y=0.2) and bottom (y=0) boundaries are traction-free.
Solve the resulting linear system using a direct solver.
Save the displacement solution field to an XDMF file named `q9_displacement.xdmf`.
Calculate the magnitude of the displacement vector field.
Save a color plot of the displacement magnitude to a PNG file named `q9_disp.png`.
