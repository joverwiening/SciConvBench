Use the FEniCS legacy library (dolfin).
The simulation domain is a rectangle defined by corners (0, 0) and (1.0, 0.20).
A circular hole of radius 0.04 is removed from the domain, centered at (0.50, 0.10).
The material is an incompressible neo-Hookean solid in a state of plane strain.
The Young's modulus is 5.0e6 and the Poisson's ratio is 0.5.
The shear modulus mu is derived from the Young's modulus and Poisson's ratio.
The problem is solved using a mixed displacement-pressure formulation.
The displacement field is discretized using continuous Lagrange elements of degree 2.
The pressure field is discretized using continuous Lagrange elements of degree 1.
An unstructured triangular mesh is used for the domain.
The mesh is generated such that the circular hole boundary is resolved with 64 segments.
The boundary at x=0 is fixed with displacement (0, 0).
The boundary at x=1.0 has a prescribed displacement of (0.060, 0).
The top boundary (y=0.20), bottom boundary (y=0), and the circular hole boundary are traction-free.
The non-linear system is solved using Newton's method with default solver parameters.
The computed displacement field is saved to a file named `displacement.xdmf`.
The computed pressure field is visualized as a color map and saved to a file named `q12_p.png`.
The von Mises stress is computed from the Cauchy stress tensor.
The von Mises stress is visualized as a color map and saved to a file named `q12_vm.png`.
