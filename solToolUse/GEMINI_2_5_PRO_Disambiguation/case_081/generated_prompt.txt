Execute the CalculiX solver on the input file case_081.inp.
Attempt to run the solver using the command `ccx -i case_081`.

After execution, check for the existence of the file case_081.sta.
A successful run is indicated by the presence of the string 'JOB COMPLETED' within the case_081.sta file.

The results.json file will contain a JSON object with six specific key-value pairs.

The "case_id" key's value is the string "case_081".
The "status" key's value is the string "success" or "error", based on the run's outcome.
The "ccx_version" key's value is the version string obtained from the solver.
The "artifacts" key's value is an empty list.
