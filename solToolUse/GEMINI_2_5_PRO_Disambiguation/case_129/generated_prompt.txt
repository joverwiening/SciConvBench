Create a file named case_129.inp in the working directory with the provided input deck content.
Execute the CalculiX solver on the input file using either the command `ccx -i case_129` or `ccx case_129`.
Determine the success of the run by checking for the string 'JOB COMPLETED' within the file case_129.sta.
Create a file named results.json in the working directory.
The results.json file must contain a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
The "solver" value shall be the string "calculix".
The "case_id" value shall be the string "case_129".
The "status" value shall be "success" if the run succeeded, otherwise it shall be "error".
The "ccx_version" value shall be the version string obtained by running `ccx -v`.
The "artifacts" value shall be an empty list.
The "notes" value shall contain the exact command used to run CalculiX.
If the status is "error", the "notes" value shall also include the error message and identify the file that indicated the failure.
