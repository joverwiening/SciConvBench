Create a file named case_060.inp in the working directory.
The content of case_060.inp must be the text from the "Input deck" section.
Execute the CalculiX solver on the input file case_060.inp.
Attempt to run the solver using the command `ccx -i case_060`.
If the command `ccx -i case_060` fails, use the command `ccx case_060`.
After the run, check the file case_060.sta for a successful termination message.
A successful termination is indicated by a line containing the text 'JOB COMPLETED'.
Determine the CalculiX version by executing the command `ccx -v`.
Create a file named results.json in the working directory.
The results.json file must contain a JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "case_060".
The JSON object must have a key "status" with the string value "success" if the run terminated successfully, otherwise "error".
The JSON object must have a key "ccx_version" with the version string obtained from the `ccx -v` command.
The JSON object must have a key "artifacts" with an empty list `[]` as its value.
The JSON object must have a key "notes" containing a string with the exact command used to run CalculiX.
If the run status is "error", the "notes" string must also include the error message and the name of the file that indicated the failure.
