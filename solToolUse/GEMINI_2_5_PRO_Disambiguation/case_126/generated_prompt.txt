Create a file named `case_126.inp` in the working directory with the content from the `Input deck` section.
Execute `ccx -v` to determine the CalculiX version.
Run the CalculiX simulation using the command `ccx -i case_126`.
If the previous command fails, run the simulation using the command `ccx case_126`.
Record which of the two commands was used to run the simulation.
Check the file `case_126.sta` for the text 'JOB COMPLETED' to determine the run status.
If the text is present, the status is 'success'.
If the text is not present, the status is 'error'.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with a key "solver" set to the string "calculix".
The JSON object must have a key "case_id" set to the string "case_126".
The JSON object must have a key "status" set to the determined run status.
The JSON object must have a key "ccx_version" set to the version string obtained from `ccx -v`.
The JSON object must have a key "artifacts" set to an empty array.
The JSON object must have a key "notes" set to a string containing the exact ccx command that was used.
If the status is "error", the "notes" string must also include the error message and the name of the file that indicated the failure.
