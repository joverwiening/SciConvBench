The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem is a 2D small-strain linear elasticity analysis.
A plane stress formulation will be used.
The domain is a rectangle with dimensions 1.0m by 0.5m.
A circular hole with a radius of 0.1m is centered at the coordinate (0.5m, 0.25m).
The domain will be discretized with a mesh containing 72 elements.
The displacement function space will be a vector-valued space using continuous Lagrange elements of polynomial order 2.
The material's Young's Modulus is 70e9 Pa.
The material's Poisson's Ratio is 0.33.
The material's density is 2700 kg/m^3.
A body force representing gravity will be applied, with g=9.81 m/s^2 acting in the negative y-direction.
A concentrated downward point load of 5000 N will be applied at the coordinate (1.0m, 0.25m).
The left edge of the rectangle (x=0) will be fixed with a zero-displacement Dirichlet boundary condition.
The linear system will be solved using a direct solver.
The simulation will output the displacement field.
The simulation will output the von Mises stress distribution.
