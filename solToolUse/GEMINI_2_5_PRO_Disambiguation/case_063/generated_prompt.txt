Create a file named case_063.inp in the working directory.
The content of case_063.inp is the provided input deck.
Execute the CalculiX solver on the input file.
The command to execute the solver is either `ccx -i case_063` or `ccx case_063`.
Determine the success of the run by checking the case_063.sta file.
A successful run is indicated by the presence of the string 'JOB COMPLETED' in case_063.sta.
Create a file named results.json in the working directory.
The results.json file must conform to the specified JSON schema.
The solver field in results.json shall be "calculix".
The case_id field in results.json shall be "case_063".
The status field in results.json shall be "success" if the run completed successfully, otherwise it shall be "error".
The ccx_version field in results.json shall be the version string obtained by running `ccx -v`.
The artifacts field in results.json shall be an empty list.
The notes field in results.json shall contain the exact command used to run CalculiX.
If the run fails, the notes field must also include the error message and the name of the file that indicated the failure.
