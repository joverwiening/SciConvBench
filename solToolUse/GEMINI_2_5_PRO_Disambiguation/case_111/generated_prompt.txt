Create the file `case_111.inp` using the input deck from the user's prompt.
Insert an `*ELASTIC` card below the `*MATERIAL,NAME=EL` card.
The `*ELASTIC` card must specify a Young's Modulus of 210000.0 and a Poisson's Ratio of 0.3.
Insert a `*STATIC` card as the first line inside the `*STEP` block.
Insert a `*BOUNDARY` card inside the `*STEP` block.
The `*BOUNDARY` card must constrain the node set `FIX` for degrees of freedom 1 through 3.
Insert a `*CLOAD` card inside the `*STEP` block.
The `*CLOAD` card must apply a load of magnitude 1.0 to the node set `LOAD` in degree of freedom 2.
Insert a `*NODE PRINT, NSET=NALL` card inside the `*STEP` block to request displacement (U) output.
Insert an `*EL PRINT, ELSET=FIX` card inside the `*STEP` block to request stress (S) output.
Run the CalculiX solver on the `case_111.inp` file using either `ccx -i case_111` or `ccx case_111`.
Determine if the run succeeded by checking the `case_111.sta` file for a successful termination message.
Execute the command `ccx -v` to get the solver version string.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the key "solver" and the string value "calculix".
The JSON object must contain the key "case_id" and the string value "case_111".
The JSON object must contain the key "status" and the string value "success" or "error" based on the run outcome.
The JSON object must contain the key "ccx_version" and the solver version string as its value.
The JSON object must contain the key "artifacts" and an empty list as its value.
The JSON object must contain the key "notes" and the exact solver command used as its string value.
If the run status is "error", append the error message and the name of the file indicating the failure to the "notes" value.
