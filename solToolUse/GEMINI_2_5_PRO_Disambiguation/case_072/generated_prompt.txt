Create a file named `case_072.inp` in the working directory with the content from the provided "Input deck".
Run the CalculiX solver for the input file `case_072.inp`.
Attempt to run the solver with the command `ccx -i case_072`.
If the first command fails, attempt to run the solver with the command `ccx case_072`.
Determine the solver version by executing `ccx -v`.
Check the file `case_072.sta` for the string 'JOB COMPLETED' to determine if the run was successful.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object.
The JSON object must have a "solver" key set to the string "calculix".
The JSON object must have a "case_id" key set to the string "case_072".
The JSON object must have a "status" key set to "success" if the run was successful, or "error" otherwise.
The JSON object must have a "ccx_version" key set to the version string obtained from the solver.
The JSON object must have an "artifacts" key set to an empty array.
The JSON object must have a "notes" key containing a string with the exact command used to run the solver.
If the status is "error", the "notes" string must also include the error message and the name of the file that indicated the failure.
