The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem to be solved is a quasi-incompressible finite-strain hyperelasticity analysis.
The formulation is a mixed displacement-pressure neo-Hookean model under plane strain conditions.
The solver will be Newton's method using default FEniCS parameters.
The geometry is a rectangular domain defined by (0, 1.0) x (0, 0.20) meters.
Two circular holes of radius 0.04 meters are present in the domain.
The first hole is centered at (0.40, 0.10) meters.
The second hole is centered at (0.60, 0.10) meters.
The material is a large-deformation isotropic quasi-incompressible neo-Hookean solid.
The material's Young's modulus is 5 MPa.
The material's Poisson's ratio is 0.49.
The domain will be meshed with a characteristic element size of 0.01.
The displacement function space will use continuous Lagrange elements of polynomial degree 2.
The pressure function space will use continuous Lagrange elements of polynomial degree 1.
The left edge of the domain (x=0) is fixed with displacement (u_x, u_y) = (0, 0).
The right edge of the domain (x=1.0) has a prescribed displacement of (u_x, u_y) = (0.060, 0) meters.
The top and bottom edges of the domain are traction-free.
A follower pressure of 0.10 MPa is applied to the boundaries of both holes.
The displacement field will be saved to a file in XDMF format.
A color map of the hydrostatic pressure field will be saved as q14_p.png.
The von Mises stress will be computed from the Cauchy stress.
A color map of the von Mises stress field will be saved as q14_vm.png.
