Create a file named `case_075.inp` in the working directory.
The content of `case_075.inp` is the text provided in the "Input deck" section.
Execute the CalculiX solver on the input file.
The command to execute is either `ccx -i case_075` or `ccx case_075`.
Determine the version of the CalculiX solver by running `ccx -v` or an equivalent command.
Check for the existence of the file `case_075.sta` after the run.
Read the content of `case_075.sta` to determine if the job completed successfully.
A successful job is indicated by the presence of the string 'JOB COMPLETED' in `case_075.sta`.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object.
The value for the key "solver" is the string "calculix".
The value for the key "case_id" is the string "case_075".
The value for the key "status" is "success" if the job completed successfully, otherwise it is "error".
The value for the key "ccx_version" is the version string obtained from the solver.
The value for the key "artifacts" is an empty list.
The value for the key "notes" is a string containing the exact CalculiX command used to run the simulation.
If the simulation status is "error", the "notes" string must also include the error message and the file that indicated the failure.
