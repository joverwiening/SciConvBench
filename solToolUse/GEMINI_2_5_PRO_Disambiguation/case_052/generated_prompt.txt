Create a file named `case_052.inp` in the working directory with the content from the `Input deck` section.
Execute the command `ccx -v` and store the outputted version string.
Run the CalculiX solver using the command `ccx -i case_052`.
If the command `ccx -i case_052` fails, attempt to run the solver using the command `ccx case_052`.
Record which of the two commands was used to execute the solver.
After execution, check the file `case_052.sta` for a successful termination message, such as 'JOB COMPLETED'.
If a successful termination message is found, the run status is "success".
If a successful termination message is not found, the run status is "error".
If the run status is "error", record any error messages produced by the solver and note the file used to determine the failure.
Create a file named `results.json` in the working directory.
The `results.json` file will contain a JSON object with six keys: `solver`, `case_id`, `status`, `ccx_version`, `artifacts`, and `notes`.
Set the value of the `solver` key to the string "calculix".
Set the value of the `case_id` key to the string "case_052".
Set the value of the `status` key to the run status determined previously.
Set the value of the `ccx_version` key to the version string obtained from the `ccx -v` command.
Set the value of the `artifacts` key to an empty list.
Set the value of the `notes` key to a string containing the exact command used to run the solver.
If the run status was "error", append the captured error message and the failure-indicating file to the `notes` string.
