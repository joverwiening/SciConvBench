Create a file named case_128.inp in the working directory.
The content of case_128.inp must be the text provided in the Input deck section.
Execute the CalculiX solver by first attempting the command `ccx -i case_128`.
If the first command fails, attempt the command `ccx case_128`.
Record the exact command that was executed.
Check the contents of the file case_128.sta for the string 'JOB COMPLETED'.
If the string 'JOB COMPLETED' is found, the run status is "success".
If the string 'JOB COMPLETED' is not found, the run status is "error".
Execute the command `ccx -v` to obtain the solver version string.
Create a file named results.json in the working directory.
The results.json file must be a JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "case_128".
The JSON object must have a key "status" with the value determined from the run status ("success" or "error").
The JSON object must have a key "ccx_version" with the string value obtained from the `ccx -v` command.
The JSON object must have a key "artifacts" with an empty array value.
The JSON object must have a key "notes" with a string value containing the exact CalculiX command that was executed.
If the run status is "error", the "notes" string must also include the error message and identify which file indicated the failure.
