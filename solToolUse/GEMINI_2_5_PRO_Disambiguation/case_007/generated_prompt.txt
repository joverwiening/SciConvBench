The simulation will be performed using the FEniCS legacy library (dolfin).
The problem is a 2D small-strain linear elasticity simulation.
The formulation is plane stress.
The geometry is a rectangle defined by corners (0, 0) and (1.0, 0.20).
A rectangular notch is removed from the geometry, defined by the region (0, 0.06) x (0.08, 0.12).
The mesh will have a characteristic element size of 0.005.
The vector-valued displacement function space will use Lagrange elements of polynomial degree 2.
The material has a Young's modulus of 200 GPa.
The material has a Poisson's ratio of 0.30.
A fixed boundary condition (u_x = 0, u_y = 0) is applied to the left edge at x=0, excluding the notch opening.
A line traction of (2.0e6, 0.0) N/m is applied to the right edge at x=1.0.
All other boundaries, including the top, bottom, and notch surfaces, are traction-free.
The linear system will be solved using a direct solver.
The von Mises stress field will be computed and saved as a PNG file named q5_vm.png.
The displacement field will be saved in XDMF format.
