The simulation will be implemented in FEniCS legacy (dolfin).
The problem is nonlinear finite-strain elasticity using a Saint-Venant-Kirchhoff material model.
The governing equation to solve is the static balance of momentum ∇⋅σ + f0 = 0 in the current configuration, which corresponds to Div(P) + f0 = 0 in the reference configuration, where P is the first Piola-Kirchhoff stress.
The material model is defined by the strain energy density function Ψ = 0.5*λ*(tr(ε))^2 + μ*tr(ε^2).
The Green-Lagrange strain tensor is defined as ε = 0.5*(F^T*F - I).
The deformation gradient is defined as F = I + ∇u, where u is the displacement vector.
The domain is a UnitCube mesh discretized with 8x8x8 hexahedral cells.
The manufactured exact solution for the displacement field is u_ex = (0.1*sin(π*x)*sin(π*y)*sin(π*z), 0.1*sin(π*x)*sin(π*y)*sin(π*z), 0.1*sin(π*x)*sin(π*y)*sin(π*z)).
The body force f0 is derived by substituting the exact solution u_ex into the governing equation.
The first Lamé parameter λ is 125.0.
The second Lamé parameter μ is 80.0.
The displacement field is approximated using continuous Lagrange elements of polynomial degree 2.
Dirichlet boundary conditions are applied to the entire boundary of the domain, setting the displacement u to the exact solution u_ex.
The nonlinear system is solved using Newton's method.
The numerical solution is verified by computing the L2 norm of the error in the displacement field, ||u - u_ex||_L2.
