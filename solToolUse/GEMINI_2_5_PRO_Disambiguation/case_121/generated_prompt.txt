Create a file named case_121.inp in the working directory.
The content of case_121.inp is the provided input deck with the following modifications.
Under the *MATERIAL,NAME=EL card, add an *ELASTIC card.
The Young's modulus is 210000 and the Poisson's ratio is 0.3.
The *STEP card should contain a *STATIC analysis procedure.
A boundary condition must be applied to the node set Nfix, constraining degrees of freedom 1, 2, and 3.
A boundary condition must be applied to the node set Nload, constraining degrees of freedom 1 and 2.
Run the CalculiX solver on the case_121.inp file.
The command to run the solver should be either `ccx -i case_121` or `ccx case_121`.
Check for the string 'JOB COMPLETED' in the file case_121.sta to determine if the run was successful.
Create a file named results.json in the working directory.
The results.json file must conform to the specified JSON schema.
The "solver" field in results.json shall be "calculix".
The "case_id" field in results.json shall be "case_121".
The "status" field in results.json shall be "success" if the run completed successfully, otherwise it shall be "error".
The "ccx_version" field in results.json shall contain the version string obtained by running `ccx -v`.
The "artifacts" field in results.json shall be an empty list.
The "notes" field in results.json shall contain the exact CalculiX command used to run the simulation.
If the simulation fails, the "notes" field must also include the error message and the name of the file that indicated the failure.
