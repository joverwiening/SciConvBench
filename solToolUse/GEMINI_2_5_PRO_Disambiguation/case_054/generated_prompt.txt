Create a file named `case_054.inp` in the working directory.
The content of `case_054.inp` must be the provided complete and correct input deck.
Execute the CalculiX solver on the input file using the command `ccx -i case_054` or `ccx case_054`.
Determine the CalculiX version by executing `ccx -v` and capturing its output string.
After the solver execution, check the file `case_054.sta` for the presence of the string 'JOB COMPLETED'.
If the string 'JOB COMPLETED' is found, the run status is "success".
If the string 'JOB COMPLETED' is not found, the run status is "error".
Create a file named `results.json` in the working directory.
The `results.json` file must contain a single JSON object.
The JSON object must have a key "solver" with the string value "calculix".
The JSON object must have a key "case_id" with the string value "case_054".
The JSON object must have a key "status" with the determined run status string, either "success" or "error".
The JSON object must have a key "ccx_version" with the captured CalculiX version string as its value.
The JSON object must have a key "artifacts" with an empty list `[]` as its value.
The JSON object must have a key "notes" with a string value containing the exact command used to run the solver.
If the run status is "error", the "notes" string must also include the error message and the name of the file that indicated the failure.
