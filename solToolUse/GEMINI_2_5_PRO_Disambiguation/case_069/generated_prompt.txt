Create a file named `case_069.inp` in the working directory with the content from the `Input deck`.
Execute the command `ccx -v` and store the output as the version string.
Run the CalculiX simulation by first attempting the command `ccx -i case_069`.
If the first command fails, attempt to run the simulation with the command `ccx case_069`.
Record which of the two commands was used to run the simulation.
Check the file `case_069.sta` for a successful termination message, such as 'JOB COMPLETED'.
Create a file named `results.json` in the working directory.
The `results.json` file must conform to the specified JSON schema.
Set the `solver` field in `results.json` to "calculix".
Set the `case_id` field in `results.json` to "case_069".
Set the `status` field in `results.json` to "success" if the run completed successfully, otherwise set it to "error".
Set the `ccx_version` field in `results.json` to the version string obtained earlier.
Set the `artifacts` field in `results.json` to an empty list.
Set the `notes` field in `results.json` to a string containing the exact command used to run the simulation.
If the simulation failed, append the error message and the name of the file indicating the failure to the `notes` field.
