Create a file named case_132.inp in the working directory.
The file case_132.inp must contain the provided node, element, nset, surface, and contact definitions.
The material named EL must be defined with a Young's Modulus of 210000 and a Poisson's Ratio of 0.
A solid section using material EL must be applied to the element set Eall.
An element set named Eload must be created containing only element 2.
A nonlinear static analysis step must be defined.
The node set Nfix must be constrained in degrees of freedom 1, 2, and 3.
The node set Nfix2 must be constrained in degrees of freedom 1 and 2.
A pressure load of 100 must be applied to face P5 of the element set Eload.
Contact displacement output must be requested for the step.
Run the CalculiX solver using the case_132.inp file.
Determine the CalculiX version string.
Check the case_132.sta file to determine if the job completed successfully.
Create a JSON file named results.json in the working directory.
The results.json file must contain the key "solver" with the value "calculix".
The results.json file must contain the key "case_id" with the value "case_132".
The results.json file must contain the key "status" with the value "success" or "error".
The results.json file must contain the key "ccx_version" with the determined version string.
The results.json file must contain the key "artifacts" with an empty list as the value.
The results.json file must contain a "notes" string recording the exact ccx command used.
If the run fails, the "notes" string must also include the error message and the file that indicated the failure.
