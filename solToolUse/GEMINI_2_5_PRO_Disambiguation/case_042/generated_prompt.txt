Use the FEniCS legacy library (dolfin) to solve the problem.
The problem is a 2D plane-strain, nearly incompressible, small-strain linear elasticity problem.
The simulation domain is a rectangle defined by the corners (0, 0) and (1.0, 0.2).
A circular hole with a radius of 0.04 is centered at (0.5, 0.1) within the domain.
The material has a Young's modulus of 5 MPa.
The material has a Poisson's ratio of 0.49.
Use a mixed displacement-pressure formulation.
Use the Taylor-Hood (P2-P1) finite element pair: continuous Lagrange elements of degree 2 for displacement and degree 1 for pressure.
Generate a triangular mesh of the domain with approximately 4000 cells.
The mesh should be refined near the boundary of the circular hole.
Apply a fixed boundary condition (u_x = 0, u_y = 0) to the left edge of the rectangle (x = 0).
Apply a prescribed displacement (u_x = 0.001, u_y = 0) to the right edge of the rectangle (x = 1.0).
The top edge (y = 0.2), bottom edge (y = 0), and the boundary of the circular hole are traction-free.
Solve the resulting linear system using a direct saddle-point solver.
Compute the von Mises stress field from the solution.
Save a plot of the von Mises stress field to a file named q11_vm.png.
Save a plot of the x-component of the displacement field (u_x) to a file named q11_ux.png.
Save the displacement vector field to an XDMF file named q11_displacement.xdmf.
