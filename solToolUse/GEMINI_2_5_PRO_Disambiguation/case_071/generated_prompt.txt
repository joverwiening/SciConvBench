Create a file named case_071.inp in the working directory.
The content of case_071.inp is the provided input deck.
Execute the command `ccx -v` to get the CalculiX version string.
Execute the command `ccx -i case_071`.
If the command `ccx -i case_071` fails, execute the command `ccx case_071`.
Record the exact command that was used to run the analysis.
Check the contents of the file `case_071.sta` for a successful termination message.
A successful termination message is 'JOB COMPLETED'.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The value for the key "solver" is the string "calculix".
The value for the key "case_id" is the string "case_071".
The value for the key "status" is "success" if the run terminated successfully, otherwise it is "error".
The value for the key "ccx_version" is the version string obtained from the `ccx -v` command.
The value for the key "artifacts" is an empty list.
The value for the key "notes" is a string containing the exact command used to run the analysis.
If the analysis run resulted in an error, the "notes" string must also include the error message and the file that indicated the failure.
