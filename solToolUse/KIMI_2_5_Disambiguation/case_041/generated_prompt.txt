The finite element code shall solve linear elasticity on a slit domain using FEniCS legacy (dolfin).

The domain is a square [-1,1]^2 with a slit along (0,0)-(1,0), created using mshr with a mesh resolution of 30.

The exact displacement field u0 for Mode I crack tip is defined as:
u0_x = (1/(2*mu)) * r**q * (cos((q+1)*theta) - (q+1)/(q-1)*cos((q-1)*theta))
u0_y = (1/(2*mu)) * r**q * (sin((q+1)*theta) - (q+1)/(q-1)*sin((q-1)*theta))
where r = sqrt(x^2 + y^2), theta = atan2(y,x), q = 0.5430755788367, and mu = 1.0 (shear modulus assumed as unity).

The material parameter lambda = 0.5444837367825 relates to shear modulus via lambda = 2*mu*q/(q-1), which is satisfied with mu = 1.0.

The stress-strain relationship uses plane strain conditions with Lamé parameters mu = 1.0 and lambda = 0.5444837367825.

The variational form uses: a(u,v) = inner(sigma(u), epsilon(v))*dx and L(v) = dot(f, v)*dx with zero body force f = (0,0).

The function space uses vector Lagrange elements of degree 2 (P2).

Dirichlet boundary conditions are applied on the entire boundary using the exact displacement field u0.

The linear system is solved using GMRES with ILU preconditioning, with relative tolerance 1e-10, absolute tolerance 1e-12, and maximum 1000 iterations.

The code outputs the computed solution and can compute L2 error norms against the exact solution for verification.
