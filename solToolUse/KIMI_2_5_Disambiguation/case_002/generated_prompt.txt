Use FEniCS legacy (dolfin) to solve a 2D plane-stress linear elasticity problem on a right triangular domain.

Create the geometry with vertices at (0,0), (1,0), and (0,0.5).

Generate a mesh with 64 triangular elements using mshr or define the mesh programmatically.

Define the vector-valued function space V = VectorFunctionSpace(mesh, 'P', 1) for displacement.

Implement plane-stress constitutive law: build the reduced 3x3 compliance matrix for plane stress, invert to get the elasticity matrix D, and extract the 3x3 matrix relating [sigma_xx, sigma_yy, sigma_xy] to [epsilon_xx, epsilon_yy, 2*epsilon_xy].

Use E = 70e9 Pa and nu = 0.33.

Define the strain-displacement relation epsilon(u) = sym(grad(u)).

Define the stress sigma = D * epsilon(u) as a UFL expression.

Apply body force from gravity: f = Constant((0, -rho*g)) with rho = 2700 kg/m^3 and g = 9.81 m/s^2.

Apply clamped boundary condition on the vertical edge x=0: DirichletBC(V, Constant((0,0)), 'on_boundary && near(x[0], 0)').

Identify the sloping boundary x + 2*y = 1 using a tolerance-based subdomain or mesh boundary marking.

Apply upward normal traction on the sloping boundary: define the unit normal vector n = [1, 2]/sqrt(5) and traction vector t = t_mag * n with t_mag specified (default to 1e6 Pa if not specified, though user should clarify magnitude).

Formulate the variational problem: find u in V such that inner(sigma(u), epsilon(v))*dx == dot(f, v)*dx + dot(t, v)*ds(sloping_boundary) for all v in V.

Solve using a direct linear solver: solve(a == L, u, bc).

Compute displacement magnitude: project(sqrt(dot(u,u)), P1) where P1 = FunctionSpace(mesh, 'P', 1).

Compute von Mises stress: extract stress components, compute sigma_vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2), and project to P1.

Output displacement magnitude and von Mises stress fields for visualization and analysis.
