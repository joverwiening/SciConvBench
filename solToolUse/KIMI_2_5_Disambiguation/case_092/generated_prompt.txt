Create a file named `case_092.inp` in the working directory with the following content:

**
** Structure: cantilever beam.
** Test objective: B32 elements, application of torque.
**
*NODE, NSET=Nall
       1, -1.49012e-08, 0.00000e+00, 0.00000e+00
       2, 1.00000e+00, 0.00000e+00, 0.00000e+00
       3, 5.00000e-01, 0.00000e+00, 0.00000e+00
       4, 2.00000e+00, 0.00000e+00, 0.00000e+00
       5, 1.50000e+00, 0.00000e+00, 0.00000e+00
*ELEMENT, TYPE=B32, ELSET=Eall
     1, 1, 3, 2
     2, 2, 5, 4
*MATERIAL,NAME=EL
*BEAM SECTION,ELSET=Eall,MATERIAL=EL,SECTION=RECT
0.05, 0.08
0.d0,1.d0,0.d0
*STEP,NLGEOM
*END STEP

Run CalculiX using the command `ccx -i case_092` or `ccx case_092` to execute the analysis.

Check the file `case_092.sta` for successful termination indicators such as 'JOB COMPLETED'.

Create a file named `results.json` in the working directory with the following schema:
The solver field must contain the string "calculix".
The case_id field must contain the string "case_092".
The status field must contain either "success" or "error".
The ccx_version field must contain the version string obtained from running `ccx -v` or equivalent.
The artifacts field must contain an empty array [].
The notes field must contain the exact ccx command used, and if the run failed, include the error message and the file that indicated the failure.
