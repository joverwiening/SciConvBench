Implement a nonlinear hyperelasticity problem with manufactured solution verification in FEniCS legacy (dolfin).

Use a UnitCube mesh with 8x8x8 cells.

Define the manufactured exact solution displacement field as u_ex = [0.1*sin(pi*x)*sin(pi*y)*sin(pi*z), 0.1*sin(pi*x)*sin(pi*y)*sin(pi*z), 0.1*sin(pi*x)*sin(pi*y)*sin(pi*z)].

Set material parameters to λ = 100.0 and μ = 50.0 (Lamé parameters for a compressible material with Poisson's ratio ν ≈ 0.25 and Young's modulus E ≈ 133.3 MPa in consistent units).

Define the deformation gradient F = I + ∇u where I is the identity tensor.

Define the Green-Lagrange strain tensor ε = ½(F^T·F - I).

Define the strain energy density Ψ = 0.5*λ*(tr(ε))^2 + μ*tr(ε·ε).

Compute the second Piola-Kirchhoff stress S = ∂Ψ/∂ε = λ*tr(ε)*I + 2*μ*ε.

Compute the first Piola-Kirchhoff stress P = F·S.

Derive the body force f0 from the manufactured solution by substituting u_ex into the equilibrium equation: f0 = -∇·(F·S) evaluated with u = u_ex.

Apply Dirichlet boundary conditions u = u_ex on all boundaries of the UnitCube (x=0, x=1, y=0, y=1, z=0, z=1).

Use P1 (first-order Lagrange) finite elements for the displacement field.

Formulate the variational problem: find u such that ∫(P : ∇v) dx = ∫(f0 · v) dx for all test functions v, with v = 0 on Dirichlet boundaries.

Solve the nonlinear problem using Newton's method with absolute tolerance 1e-10 and relative tolerance 1e-9 for the residual, and maximum 50 Newton iterations.

Compute the L2 error between the numerical solution u_h and the exact solution u_ex as ||u_h - u_ex||_{L2}.

Compute the H1 error (energy norm) as ||u_h - u_ex||_{H1}.

Output the final displacement solution, the computed errors, and the number of Newton iterations required for convergence.
