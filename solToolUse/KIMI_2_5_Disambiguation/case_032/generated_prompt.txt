Solve a 3D compressible neo-Hookean elasticity problem using legacy FEniCS (dolfin) with the following specifications.

Use UnitCubeMesh(24, 16, 16) to create the computational domain.

Define the function space as VectorFunctionSpace(mesh, "Lagrange", 1) for the displacement field u.

Set material parameters: Young's modulus E = 10.0 and Poisson's ratio ν = 0.3. Compute the Lamé parameters as μ = E / (2.0 * (1.0 + ν)) and λ = E * ν / ((1.0 + ν) * (1.0 - 2.0 * ν)).

Define the kinematics: F = I + grad(u), where I is the identity tensor; C = F^T * F; and J = det(F).

Define the compressible neo-Hookean strain energy density: ψ = (μ / 2.0) * (tr(C) - 3.0) - μ * ln(J) + (λ / 2.0) * (ln(J))^2.

Compute the total potential energy as the integral of ψ over the domain minus the work done by body forces and traction.

Apply body force B = (0, -0.5, 0) throughout the domain.

Apply traction T = (0.1, 0, 0) on the natural boundary, defined as all faces where displacement is not prescribed (all faces except x = 0 and x = 1).

Clamp the left face at x = 0 by setting u = (0, 0, 0).

Apply a prescribed rotational displacement on the right face at x = 1. The rotation is about the x-axis with center at (y0, z0) = (0.5, 0.5) and effective rotation angle θ = π/6 ≈ 0.5236 radians. The displacement field on x = 1 is given by: u_x = 0, u_y = (y - 0.5) * (cos(θ) - 1) - (z - 0.5) * sin(θ), u_z = (y - 0.5) * sin(θ) + (z - 0.5) * (cos(θ) - 1).

Use DirichletBC to enforce boundary conditions on x = 0 and x = 1.

Define the variational problem by computing the first variation of the total potential energy with respect to u in the direction of a test function v.

Use the NonlinearVariationalProblem and NonlinearVariationalSolver classes to solve the nonlinear problem with Newton's method.

Set the solver parameters: use Newton's method with absolute tolerance 1e-8, relative tolerance 1e-7, maximum 50 iterations, and report convergence information.

Output the final displacement field and compute the deformed configuration for visualization.
