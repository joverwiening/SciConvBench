Use FEniCS legacy (dolfin) to solve a 2D plane-stress linear elasticity problem on an L-shaped domain.

The domain is defined as the unit square [0,1]x[0,1] minus the inner square [0.5,1]x[0.5,1], creating an L-shape.

Generate a mesh with 64 elements per edge using mshr or define the geometry with constructive solid geometry operations.

Define the vector-valued function space V = VectorFunctionSpace(mesh, 'P', 1) for displacement.

Apply clamped boundary conditions (zero displacement) on the left edge (x=0) and bottom edge (y=0) using DirichletBC.

Apply a horizontal traction (Neumann boundary condition) with sigma_xx = 2.65e4 Pa on the right edge (x=1).

Use material properties: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

Compute the plane-stress Lamé parameters: mu = E/(2*(1+nu)) and lambda_ = E*nu/((1+nu)*(1-nu)).

Define the strain tensor epsilon(u) = 0.5*(grad(u) + grad(u).T).

Define the stress tensor sigma(u) = lambda_*tr(epsilon(u))*Identity(2) + 2*mu*epsilon(u).

Include body force due to gravity: f = Constant((0, -rho*g)).

Formulate the variational problem: find u in V such that inner(sigma(u), epsilon(v))*dx == dot(f, v)*dx + dot(t, v)*ds for all v in V, where t is the traction vector.

Solve using a direct linear solver (solve(a == L, u, bc)).

Project the stress tensor to a tensor function space for post-processing.

Compute von Mises stress as sqrt(sigma_xx^2 + 3*sigma_xy^2) for plane stress, or equivalently sqrt(3/2 * s:s) where s is the deviatoric stress.

Output displacement magnitude and von Mises stress fields for visualization.
