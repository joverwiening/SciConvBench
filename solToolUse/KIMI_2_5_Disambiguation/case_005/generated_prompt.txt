Use FEniCS legacy (dolfin) to solve a nearly incompressible small-strain elasticity problem in 2D plane strain with a mixed displacement-pressure formulation and direct saddle-point solve.

Define the rectangular domain Ω = (0, 1.0) x (0, 0.20) meters.

Create a structured mesh with 100 elements in the x-direction and 20 elements in the y-direction using RectangleMesh.

Define a mixed function space W = V x Q where V is a vector-valued Lagrange element of degree 2 for displacement and Q is a scalar Lagrange element of degree 1 for pressure.

Set material parameters: Young's modulus E = 5.0e6 Pa, Poisson's ratio ν = 0.49.

Compute Lamé parameters: μ = E / (2.0 * (1.0 + ν)) and λ = E * ν / ((1.0 + ν) * (1.0 - 2.0 * ν)).

Define the strain tensor ε(u) = 0.5 * (grad(u) + grad(u).T).

Define the variational formulation for the mixed method: find (u, p) in W such that for all test functions (v, q), the following holds:
- 2 * μ * inner(ε(u), ε(v)) * dx + inner(p, div(v)) * dx = 0
- inner(div(u), q) * dx - (1.0 / λ) * inner(p, q) * dx = 0

Apply boundary conditions:
- On the left edge (x = 0.0): DirichletBC(W.sub(0), Constant((0.0, 0.0)), "near(x[0], 0.0)")
- On the right edge (x = 1.0): DirichletBC(W.sub(0).sub(0), Constant(0.01), "near(x[0], 1.0)") for horizontal displacement and DirichletBC(W.sub(0).sub(1), Constant(0.0), "near(x[0], 1.0)") for zero vertical displacement

Assemble the system and solve using a direct solver (solve(a == L, w, bcs) or equivalent).

Extract the displacement component from the solution.

Compute the magnitude of displacement |u| = sqrt(u_x^2 + u_y^2).

Plot |u| using matplotlib with a color map and save as "q10_disp.png".

Save the displacement field in XDMF format using XDMFFile.
