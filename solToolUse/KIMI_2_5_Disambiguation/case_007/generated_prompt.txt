The simulation solves a plane-stress linear elasticity problem for a notched rectangular plate using legacy FEniCS (dolfin).

The domain is the rectangle (0, 1.0) x (0, 0.20) m with a rectangular notch removed from the left edge, where the notch occupies the region (0, 0.06) x (0.08, 0.12) m.

The mesh is generated using mshr with a characteristic element size of 0.005 m, which provides adequate resolution around the notch tip and stress concentration regions while maintaining computational efficiency.

The function space is a vector-valued Lagrange space of degree 1 (P1) for the displacement field u = (u_x, u_y) defined on the notched domain.

The material follows plane-stress linear elasticity with Young's modulus E = 200 GPa and Poisson's ratio ν = 0.30. The constitutive law uses the reduced plane-stress stiffness tensor with components C_1111 = C_2222 = E/(1-ν^2), C_1122 = ν*E/(1-ν^2), and C_1212 = E/(2*(1+ν)).

The strain-displacement relation uses the symmetric gradient epsilon(u) = 0.5*(grad(u) + grad(u).T).

The stress tensor sigma is computed as the double contraction of the stiffness tensor with the strain tensor.

The variational problem seeks u in the displacement space such that the bilinear form a(u, v) = inner(sigma(u), epsilon(v))*dx equals the linear form L(v) = dot(t, v)*ds for all test functions v, where the traction t = (2e6, 0) N/m is applied on the right edge x = 1.0.

Dirichlet boundary conditions enforce u_x = 0 and u_y = 0 on the left outer boundary x = 0, which excludes the notch interior.

The linear system is solved using a direct solver (LU factorization via MUMPS or default direct solver).

The von Mises stress is computed as sigma_vm = sqrt(sigma_xx^2 + sigma_yy^2 - sigma_xx*sigma_yy + 3*sigma_xy^2) and projected onto a P1 scalar function space.

The von Mises field is plotted using matplotlib with a colorbar and saved to the file q5_vm.png.

The displacement field is saved in XDMF format to a file named displacement.xdmf, with the file opened in append mode to store the solution.
