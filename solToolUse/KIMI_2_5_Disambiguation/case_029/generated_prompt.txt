The simulation solves a 2D plane-stress linear elasticity problem using legacy FEniCS (dolfin).

The domain is a 1.0m by 0.5m rectangular plate with a circular hole of radius 0.1m centered at (0.5, 0.25).

The mesh consists of 72 triangular elements with P1 Lagrange elements for the vector-valued displacement field.

Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

The constitutive law is the reduced plane-stress elasticity tensor with unit thickness.

Boundary conditions fix displacement to zero on the left edge (x = 0) and bottom edge (y = 0).

Loading consists of three contributions: body force due to gravity acting in the negative y-direction with magnitude ρ*g, horizontal traction σ_xx = +1000 Pa applied on the top edge (y = 0.5), and horizontal traction σ_xx = -1000 Pa applied on the bottom edge (y = 0), creating a shear loading pattern.

The variational problem uses the standard linear elasticity weak form: find displacement u in the vector-valued P1 function space such that the stress-divergence inner product equals the sum of traction and body force virtual work contributions for all test functions.

The linear system is solved using a direct solver (MUMPS or default LU).

Post-processing computes the Cauchy stress tensor from the displacement gradient using the plane-stress constitutive law.

Von Mises equivalent stress is computed from the in-plane stress components as sqrt(σ_xx^2 + σ_yy^2 - σ_xx*σ_yy + 3*σ_xy^2).

Output includes displacement magnitude and von Mises stress distributions visualized or saved to file.
