Use FEniCS legacy (dolfin) to solve a 2D plane-stress linear elasticity problem on a rectangular plate with a central circular hole.

Create a rectangular domain of dimensions 1.0 m (width) by 0.5 m (height) with a circular hole of radius 0.1 m centered at (0.5, 0.25).

Generate a mesh with approximately 72 elements using the FEniCS mesh generation capabilities.

Define the vector-valued function space V = VectorFunctionSpace(mesh, 'P', 1) for displacement.

Implement plane-stress linear elasticity with Young's modulus E = 70e9 Pa and Poisson's ratio ν = 0.33.

Compute the plane-stress Lamé parameters: mu = E/(2*(1+nu)) and lambda_ = E*nu/((1+nu)*(1-nu)).

Define the strain tensor epsilon(u) = 0.5*(grad(u) + grad(u).T).

Define the stress tensor sigma(u) = lambda_*tr(epsilon(u))*Identity(2) + 2*mu*epsilon(u).

Apply body force from gravity: f = Constant((0, -rho*g)) with rho = 2700 kg/m^3 and g = 9.81 m/s^2.

Apply Dirichlet boundary condition: fix the left edge (x = 0) by setting u = (0, 0).

Apply a concentrated point load of 5 kN downward at point (1.0, 0.25) using a PointSource in the y-direction with magnitude -5000.0.

Formulate the variational problem: find u in V such that inner(sigma(u), epsilon(v))*dx == dot(f, v)*dx for all v in V, with the point load applied separately.

Solve the linear system using a direct solver (default LU solver in FEniCS).

Compute the stress field by projecting sigma(u) onto a TensorFunctionSpace.

Compute von Mises stress as sqrt(0.5*((s[0,0]-s[1,1])**2 + s[1,1]**2 + s[0,0]**2 + 6*s[0,1]**2)) where s is the deviatoric stress, or equivalently for plane stress: sqrt(s[0,0]**2 - s[0,0]*s[1,1] + s[1,1]**2 + 3*s[0,1]**2).

Output the displacement magnitude and von Mises stress distributions for visualization.
