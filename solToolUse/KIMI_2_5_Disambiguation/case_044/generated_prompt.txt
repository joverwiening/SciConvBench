Use FEniCS legacy (dolfin) to solve a small-strain linear elasticity problem for a two-material bonded strip in plane stress.

Create a rectangular domain Ω = (0, 1.0) x (0, 0.20) meters.

Generate a structured mesh with 80 elements in the x-direction and 16 elements in the y-direction.

Define two subdomains separated at y = 0.10 m: the lower subdomain Ω_Al (0 <= y < 0.10) and the upper subdomain Ω_Steel (0.10 <= y <= 0.20).

Assign material properties: for Ω_Al, Young's modulus E = 70 GPa and Poisson's ratio ν = 0.30; for Ω_Steel, E = 200 GPa and ν = 0.30.

Define the plane-stress constitutive law with unit thickness, computing the stress-strain relationship using the reduced plane-stress formulation.

Define the function space as a vector function space of continuous piecewise linear elements (CG1) for the displacement field u = (u_x, u_y).

Apply boundary conditions: on the left edge (x = 0), enforce u_x = 0 and u_y = 0 (Dirichlet); on the right edge (x = 1), apply a uniform traction t = (0, -5000) N/m as a Neumann boundary condition; leave the top and bottom edges traction-free.

Formulate the variational problem: find u in the appropriate function space such that the bilinear form a(u, v) equals the linear form L(v) for all test functions v, where a(u, v) integrates the stress-strain product over the domain and L(v) integrates the traction dot v over the right boundary.

Use a direct linear solver (MUMPS or default LU) to solve the linear system.

Compute the magnitude of displacement |u| = sqrt(u_x^2 + u_y^2).

Save the displacement field u in XDMF format for post-processing.
