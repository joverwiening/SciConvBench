Use FEniCS legacy (dolfin) to implement a small-strain linear elasticity solver for a 2D plane-stress variational problem.

Create a rectangular domain with length 1.0 m in the x-direction and height 0.5 m in the y-direction.

Generate a mesh with 64 elements per edge using RectangleMesh.

Define a circular hole of radius 0.1 m centered at coordinates (0.5, 0.25) and subtract it from the domain using CSG geometry or by marking facets for boundary conditions.

Define the material properties: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m^3, and gravitational acceleration g = 9.81 m/s^2.

Construct the plane-stress constitutive law by converting the standard 3D Hooke's law to 2D plane stress: compute the modified Lamé parameters or use the reduced stiffness matrix for plane stress conditions.

Define a vector-valued FunctionSpace of degree 1 for the displacement field.

Apply boundary conditions: set uy = 0 on the left edge (x = 0), set ux = 0 on the right edge (x = 1.0), and apply uniform vertical compressive traction σ_yy = -2500 Pa on the top edge (y = 0.5) and bottom edge (y = 0.0).

Define the variational form for linear elasticity: the bilinear form a(u,v) = inner(sigma(u), epsilon(v)) * dx and the linear form L(v) = dot(traction, v) * ds + dot(body_force, v) * dx, where sigma(u) is the stress tensor computed from the strain epsilon(u) = 0.5 * (grad(u) + grad(u).T).

Solve the variational problem using a direct linear solver (MUMLU or default LU).

Post-process the solution to compute the Cauchy stress tensor field from the displacement gradient.

Compute the von Mises equivalent stress from the in-plane stress components: σ_vm = sqrt(σ_xx^2 + σ_yy^2 - σ_xx*σ_yy + 3*σ_xy^2).

Output and visualize the displacement magnitude, displacement components (ux, uy), stress components (σ_xx, σ_yy, σ_xy), and von Mises stress.

Analyze the displacement and stress patterns, noting the effect of the asymmetric constraints (vertical fixation on left, horizontal fixation on right) combined with the uniform compression and the stress concentration around the hole.
