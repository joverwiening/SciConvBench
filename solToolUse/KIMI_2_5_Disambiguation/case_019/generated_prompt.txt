Define and solve the static twisting of a hyperelastic cube using a St. Venant-Kirchhoff material model with spatially varying Lamé parameters in legacy FEniCS (dolfin).

The computational domain is a unit cube with mesh resolution 8x8x8 cells using UnitCubeMesh.

The material model is St. Venant-Kirchhoff hyperelasticity with strain energy density ψ = (λ/2)(tr(E))² + μ tr(E²), where E = ½(FᵀF - I) is the Green-Lagrange strain tensor and F = I + ∇u is the deformation gradient.

The shear modulus μ is constant with value 3.8461 N/m².

The first Lamé parameter λ varies spatially in the reference configuration as λ(x₁) = 5.8·x₁ + 5.7·(1 - x₁), where x₁ is the first reference coordinate.

Boundary conditions enforce fixed displacement on the face x₁ = 0 (u = 0) and a rigid rotation on the face x₁ = 1.

The rotation angle is θ = π/3 ≈ 1.0472 radians about the x₁-axis (the longitudinal axis of the cube).

The rotation boundary condition on x₁ = 1 is applied by prescribing u such that the deformed position x + u equals the rotated position: the face rotates rigidly about the centerline (x₂ = 0.5, x₃ = 0.5) with transformation [x₁, (x₂-0.5)cosθ - (x₃-0.5)sinθ + 0.5, (x₂-0.5)sinθ + (x₃-0.5)cosθ + 0.5].

The variational problem uses a VectorFunctionSpace of degree 1 with Lagrange elements.

The nonlinear variational form is derived from the first variation of the total potential energy: find u such that ∫Ω P : ∇v dx = 0 for all test functions v, where P = F·S is the first Piola-Kirchhoff stress and S = λ·tr(E)·I + 2μ·E is the second Piola-Kirchhoff stress.

The spatially varying λ is implemented as a dolfin Expression or by interpolating onto a Function space to ensure proper evaluation during assembly.

The nonlinear system is solved using Newton's method with default solver parameters or customized linear solver settings for convergence robustness.

The solution yields the displacement field u(x) throughout the cube showing the twist deformation from the fixed face to the rotated face.
