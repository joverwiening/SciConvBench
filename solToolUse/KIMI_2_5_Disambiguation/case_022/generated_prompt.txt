Solve Solid Mechanics Problem 1 using legacy FEniCS (dolfin) with the following specification:

Import dolfin from fenics.

Define the rectangular domain Omega = (0, 1.0) x (0, 0.20) meters.

Create a uniform structured mesh with 20 subdivisions in the x-direction and 4 subdivisions in the y-direction using RectangleMesh.

Define a vector-valued function space V = VectorFunctionSpace(mesh, 'P', 1) with Lagrange elements of degree 1.

Set material properties: Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.30.

Compute Lamé parameters: mu = E / (2.0 * (1.0 + nu)) and lambda_ = E * nu / ((1.0 + nu) * (1.0 - nu)) for plane stress.

Define the strain tensor epsilon(u) = 0.5 * (grad(u) + grad(u).T).

Define the stress tensor sigma(u) = lambda_ * tr(epsilon(u)) * Identity(2) + 2 * mu * epsilon(u) for plane stress.

Define the variational problem with trial function u in V and test function v in V.

Set the bilinear form a = inner(sigma(u), epsilon(v)) * dx.

Set the linear form L = Constant(0) * v[0] * dx since there are no body forces.

Assemble the system and solve using a direct linear solver (solve(a == L, u, bcs)).

Compute and output the maximum displacement in x and y directions.
