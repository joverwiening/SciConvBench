Create a file named `case_112.inp` in the working directory with the exact content provided in the input deck section.

Run CalculiX using the command `ccx -i case_112` or `ccx case_112`, whichever executes successfully on the system.

Check the file `case_112.sta` to determine if the job completed successfully by looking for a successful termination message such as 'JOB COMPLETED'.

Create a file named `results.json` in the working directory with the following schema and content:
The field `solver` must be set to the string "calculix".
The field `case_id` must be set to the string "case_112".
The field `status` must be set to "success" if the job completed successfully, otherwise set to "error".
The field `ccx_version` must contain the version string obtained from running `ccx -v` or the closest equivalent version command.
The field `artifacts` must be an empty array.
The field `notes` must contain the exact ccx command used to run the simulation, and if the run failed, must also include the error message and the file that indicated the failure.
