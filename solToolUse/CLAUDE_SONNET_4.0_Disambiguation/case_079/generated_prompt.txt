The input deck defines a cantilever beam with geometric nonlinearity using C3D20R elements.
Material properties are elastic modulus 210000.0 and Poisson's ratio 0.3 with density 7.8E-9.
Boundary conditions fix all degrees of freedom at nodes in set CN7 (cantilever base).
Loading applies concentrated force of 5 units in Y-direction to nodes in set LAST (free end).
Analysis uses static step with NLGEOM flag for geometric nonlinearity over time period 1.0.
