Create the file case_095.inp in the working directory with the provided input deck content.
Run CalculiX using ccx -i case_095 or ccx case_095 command.
The analysis is a frequency analysis to calculate the first 10 natural frequencies of a cantilever plate structure.
The structure uses C3D8I elements (8-node brick elements with incompatible modes).
The left end of the cantilever (nodes 1, 2, 5, 6) is fixed with boundary conditions preventing all translations.
The material is steel with elastic modulus 209000.0, Poisson's ratio 0.3, and density 7.85e-09.
