Define and solve the static twisting of a hyperelastic cube using a St. Venant-Kirchhoff material model with spatially varying Lamé parameters.
Use FEniCS legacy (dolfin) for implementation.
Create a UnitCube mesh with 8x8x8 cells with dimensions 1 x 1 x 1 meters.
Implement the Saint-Venant-Kirchhoff material model for finite-strain elasticity.
Set the shear modulus μ = 3.8461 N/m².
Set the Lamé parameter λ to vary spatially as λ = 5.8*x1 + 5.7*(1 - x1).
Apply fixed boundary conditions at x1 = 0 (all displacements zero).
Apply a 60-degree rotation boundary condition at x1 = 1 about the cube centerline (x1-axis).
The rotation axis passes through the center of the cube parallel to the x1 direction.
Solve the nonlinear finite-strain elasticity problem using Newton's method.
Use the Saint-Venant-Kirchhoff strain energy density function for the hyperelastic material.
