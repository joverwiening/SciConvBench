Solve a 2D plane-stress orthotropic elasticity problem using FEniCS legacy (dolfin).
Create a rectangular domain Ω = (0, 1.0) x (0, 0.20) m representing a plate.
Generate a structured mesh with 50 x 25 elements over the domain.
Use small-strain orthotropic plane-stress elasticity for displacement field u = (u_x, u_y).
Define local orthotropic material properties: E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, nu12 = 0.25.
Rotate the local material axes by theta = 30 degrees anticlockwise with respect to global x-y axes.
Construct the plane-stress reduced stiffness matrix [Q] in local coordinates and rotate it to the global frame.
Apply fixed boundary conditions on the bottom edge (y = 0): u_x = 0, u_y = 0.
Apply uniform downward traction t = (0, -10 MPa*m) on the top edge (y = 0.20).
Set traction-free boundary conditions on vertical sides (x = 0 and x = 1).
Interpret the top-edge load as a line traction per unit thickness.
Solve the variational problem using a direct linear solver.
Compute von Mises stress from the solution.

Save a color map of von Mises stress as q8_vm.png.
