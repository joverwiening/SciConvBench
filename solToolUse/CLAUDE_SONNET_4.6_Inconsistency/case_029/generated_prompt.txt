Use FEniCS legacy (dolfin) for all implementation.

Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement finite element space and a direct linear solver (e.g., LU).

Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

The geometry is a 1.0 m x 0.5 m rectangle with a circular hole of radius 0.1 m centered at (0.5, 0.25).

Generate the mesh using mshr (legacy FEniCS meshing): create a Rectangle from (0,0) to (1,0.5) and subtract a Circle of radius 0.1 centered at (0.5, 0.25), then call generate_mesh with a resolution targeting approximately 72 elements (use resolution=10 or adjust to approximate 72 elements).

Use the plane-stress reduced constitutive law. Define the effective Lame-like parameters for plane stress as: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)). The plane-stress stress tensor is sigma(u) = lambda_ps * tr(eps(u)) * I + 2 * mu * eps(u), where eps(u) = sym(grad(u)) and I is the 2x2 identity tensor.

Use a vector CG (Lagrange) element of degree 1 for the displacement field on the 2D mesh.

Apply Dirichlet boundary conditions: fix all displacement components (ux = 0, uy = 0) on the left edge (x = 0) and on the bottom edge (y = 0).

Apply Neumann traction boundary conditions on the top and bottom horizontal edges as follows. On the top edge (y = 0.5), apply an inward normal traction of magnitude 1000 Pa, meaning the traction vector is t = -1000 * n where n is the outward normal (so the traction acts inward, i.e., downward on the top edge: t = (0, -1000) Pa). On the bottom edge (y = 0), apply an outward normal traction of magnitude 1000 Pa, meaning the traction vector acts outward (upward on the bottom edge: t = (0, +1000) Pa). Note: the bottom edge also has a Dirichlet BC, so the Neumann condition there is overridden by the Dirichlet condition; include the Neumann term in the variational form regardless, as the Dirichlet BC will take precedence.

Apply a body force due to gravity: f = (0, -rho * g) N/m^3 as a volumetric load in the variational form.

The hole boundary is traction-free; apply no Neumann condition on it (natural boundary condition is zero traction by default).

Assume unit thickness (t = 1.0 m) for the plane-stress formulation.

Formulate the standard weak form: find u in V such that for all v in V, integral(sigma(u) : eps(v)) dx = integral(f . v) dx + integral(t . v) ds over the top and bottom edges.

Use a MeshFunction or boundary SubDomain markers to identify the top edge (y near 0.5) and bottom edge (y near 0) for applying the Neumann tractions via a ds measure with subdomain data.

Solve the assembled linear system using a direct solver (call solve with method "lu" or use LUSolver).

After solving, compute the von Mises stress from the in-plane Cauchy stress field. Project the stress tensor sigma(u) onto a tensor function space (DG0 or CG1). Compute von Mises as: sigma_vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2), using only the in-plane components (sigma_xx, sigma_yy, sigma_xy). Project sigma_vm onto a scalar function space.

Output or save the displacement field u and the von Mises stress field to files (e.g., XDMFor PVD format) for visualization.

Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
