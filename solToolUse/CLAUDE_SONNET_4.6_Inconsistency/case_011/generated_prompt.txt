Final Specification:

Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-stress linear elasticity problem on a perforated rectangular plate.
The plate dimensions are 1.0 m (x-direction) by 0.5 m (y-direction).
A circular hole of radius 0.1 m is centered at (0.5, 0.25) m.
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
Use the reduced plane-stress constitutive law with unit thickness.
The plane-stress constitutive tensor relates in-plane strains to in-plane stresses using the standard plane-stress reduction of the 3D isotropic linear elastic law.
Define the Lame-like plane-stress parameters as: lambda_ps = E*nu/(1 - nu**2), mu = E/(2*(1 + nu)).
The stress tensor sigma is defined as lambda_ps * tr(eps) * I + 2 * mu * eps, where eps is the symmetric gradient of displacement.
Use a vector-valued continuous Lagrange finite element space of degree 1 (P1) for the displacement field.
Generate the geometry using mshr: create a Rectangle from (0,0) to (1, 0.5) and subtract a Circle of radius 0.1 centered at (0.5, 0.25).
Set the mesh resolution parameter to 64 when calling mshr.generate_mesh.
Define boundary subdomains using a MeshFunction of dimension (mesh.topology().dim() - 1) to mark boundaries.
Mark the left edge (x = 0, within tolerance 1e-10) as subdomain 1 (Dirichlet boundary).
Mark the hole boundary (distance from (0.5, 0.25) less than 0.1 + 1e-3) as subdomain 2 (Neumann traction boundary).
Apply a homogeneous Dirichlet boundary condition (u = [0, 0]) on the left edge (subdomain 1) using DirichletBC.
Apply a body force vector f = [0, -rho * g] as a Constant over the entire domain.
Apply a traction on the hole boundary representing internal pressure acting outward from the cavity (i.e., outward from the solid into the hole).
Define the traction as t = p * n, where p = 1e5 Pa and n is the outward unit normal of the solid domain on the hole boundary.
Use ds restricted to subdomain 2 for the hole traction Neumann integral.
Formulate the weak form: a(u, v) = integral of inner(sigma(u), sym(grad(v))) dx over the domain.
Formulate the right-hand side: L(v) = integral of dot(f, v) dx + integral of dot(t, v) ds(2), where ds(2) is the measure on the hole boundary.
Solve the linear system using a direct solver by calling solve(a == L, u, bc) or equivalently using LUSolver.
After solving, compute the full in-plane Cauchy stress tensor components: sigma_xx, sigma_yy, sigma_xy by projecting or expressing sigma(u) onto a suitable function space.
Compute the von Mises stress from the in-plane stress components using the plane-stress formula: von_mises = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2).
Project the von Mises stress expression onto a scalar DG0 or CG1 function space.
Project the displacement field u and the stress components for output.
Save the displacement field to a file named displacement.pvd using File("displacement.pvd").
Save the von Mises stress field to a file named von_mises.pvd using File("von_mises.pvd").
Print the maximum von Mises stress value and the maximum displacement magnitude to the console.
Do not use any MPI-parallel or complex solver settings; keep the solver as a standard direct LU solve.
