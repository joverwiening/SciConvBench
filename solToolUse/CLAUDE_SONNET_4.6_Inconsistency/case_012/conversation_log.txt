Q: I need one clarification before writing the final specification.

The boundary conditions as stated contain a contradiction: you say "On x = 0 impose symmetry: u_x = 0" and "On y = 0 impose symmetry: u_y = 0", but then you say "Fully clamp x = 0 and y = 0 in both displacement components." Clamping both components on both symmetry edges would over-constrain the problem and prevent the plate from deforming correctly under the top displacement — a symmetry condition only fixes the normal component, not the tangential one.

Which condition should be used on the symmetry edges: the standard symmetry conditions (u_x = 0 on x = 0, u_y = 0 on y = 0), or full clamping (both u_x and u_y fixed to zero on both edges)?
A: Use standard symmetry conditions only: u_x = 0 on x = 0, and u_y = 0 on y = 0. Do not fully clamp those edges.
