Determine the CalculiX version by running "ccx -v" or the closest equivalent and recording the version string.
Create a file named results.json in the working directory with the following fields: "solver" set to "calculix", "case_id" set to "leifer1", "status" set to "success" if leifer1.sta contains "JOB COMPLETED" and "error" otherwise, "ccx_version" set to the version string obtained from "ccx -v", "artifacts" set to a list of output files produced by the run, "notes" set to the exact ccx command used and, if the run failed, the error message and the file that indicated the failure.
