Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement finite element space and a direct linear solver.
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
The 2D domain is treated as plane stress with unit thickness (t = 1 m).
Use the reduced plane-stress constitutive law relating in-plane stresses to in-plane strains.
The geometry is a polygonal domain defined by the vertices in order: (0,0), (0.8,0), (0.8,0.2), (0.5,0.2), (0.5,0.5), (0.3,0.5), (0.3,0.2), (0,0.2), closing back to (0,0).
This shape is an L-shaped or T-shaped multi-rectangle polygon (a wide base rectangle with a narrower notch rectangle on top).
Build the mesh using the dolfin Mesh and MeshEditor or by using mshr.Polygon with the listed vertices and generate with mshr.generate_mesh targeting approximately 72 elements.
Apply a Dirichlet boundary condition fixing both displacement components (u_x = 0, u_y = 0) on the bottom edge where y = 0.
Apply body force due to gravity as a volume load with components (0, -rho*g) over the entire domain.
Apply the -5 kN vertical load distributed uniformly as a traction over the top segment of the upper notch, which is the edge from (0.3, 0.5) to (0.5, 0.5).
The traction on that top segment is (0, -5000 / 0.2) N/m^2, i.e., total force -5000 N divided by the segment length 0.2 m, giving traction magnitude 25000 N/m in the negative y direction (per unit thickness of 1 m, so 25000 Pa).
Mark the top notch boundary segment (y = 0.5, 0.3 <= x <= 0.5) using a MeshFunction or SubDomain and apply the Neumann traction via a surface integral ds over that marked region.
Use a continuous Lagrange vector element of degree 2 (P2) for the displacement field, or degree 1 (P1) if degree 2 causes mesh size issues, but prefer P2.
Define the plane-stress strain tensor as epsilon(u) = sym(grad(u)).
Define the plane-stress constitutive relation: sigma_xx = E/(1-nu^2) * (eps_xx + nu*eps_yy), sigma_yy = E/(1-nu^2) * (eps_yy + nu*eps_xx), sigma_xy = E/(1+nu) * eps_xy.
Implement the stress tensor as a UFL expression using the plane-stress formula: sigma = E/(1-nu^2)*((1-nu)*epsilon + nu*tr(epsilon)*Identity) adjusted correctly for plane stress, or equivalently use the lambda_ps and mu_ps Lame-like parameters for plane stress: lambda_ps = E*nu/(1-nu^2), mu_ps = E/(2*(1+nu)), and sigma = 2*mu_ps*epsilon(u) + lambda_ps*tr(epsilon(u))*Identity(2).
Assemble the bilinear form a(u,v) = integral of inner(sigma(u), epsilon(v)) dx over the domain.
Assemble the linear form L(v) = integral of dot(f_body, v) dx + integral of dot(t_traction, v) ds over the marked top notch boundary.
Solve the resulting linear system using a direct solver (e.g., LUSolver or the default direct solver via solve).
After solving, compute the displacement magnitude field as sqrt(u_x^2 + u_y^2) and project it onto a scalar function space.
Compute the von Mises stress from the in-plane Cauchy stress field using the formula: sigma_vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).
Project the von Mises stress expression onto a scalar DG0 or CG1 function space.
Print the maximum displacement magnitude and the maximum von Mises stress to the console.
Save the displacement field, displacement magnitude, and von Mises stress to VTK or XDMF files for visualization.
Do not use any deprecated or FEniCS-X (dolfinx) API; use only dolfin (legacy FEniCS) API throughout.
