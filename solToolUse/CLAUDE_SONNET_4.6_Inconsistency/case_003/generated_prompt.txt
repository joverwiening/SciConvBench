Use FEniCS legacy (dolfin) for all implementation.

Define the domain as a rectangle (0, 1.0) x (0, 0.20) metres with two circular holes of radius 0.04 m centred at (0.33, 0.10) m and (0.67, 0.10) m.

Generate the mesh using mshr: create a Rectangle domain minus two Circle domains, then generate the mesh with sufficient resolution (suggested resolution parameter of 80 or higher to resolve the hole boundaries accurately).

Use plane-stress linear elasticity for the vector-valued displacement field u = (u_x, u_y).

Set material properties: Young's modulus E = 200e9 Pa, Poisson's ratio nu = 0.30.

Assemble the 2D isotropic constitutive response using the full 3D Lamé parameter lambda = E * nu / ((1 + nu) * (1 - 2 * nu)) and mu = E / (2 * (1 + nu)).

Apply the plane-stress correction by replacing lambda with lambda_ps = 2 * mu * lambda / (lambda + 2 * mu) in the 2D stress-strain relation, so that sigma = lambda_ps * tr(eps) * I + 2 * mu * eps where eps = sym(grad(u)).

Define the variational problem: find u in V such that for all v in V, the integral of inner(sigma(u), sym(grad(v))) dx equals the integral of the Neumann traction term.

Use a vector-valued function space V = VectorFunctionSpace(mesh, 'P', 2) (quadratic Lagrange elements).

Apply Dirichlet boundary condition u_x = 0 and u_y = 0 on the left edge x = 0 using a DirichletBC with a SubDomain or near() condition.

Identify the right edge as x = 1.0 using a boundary marker and apply the Neumann traction t = (2e6, 0) N/m as a surface traction per unit thickness, implemented as ds integral: inner(t_vec, v) * ds(right_marker).

Leave the top edge, bottom edge, and both hole boundaries as traction-free (natural boundary condition, no additional terms).

Mark all boundary regions using a MeshFunction of dimension (mesh.topology().dim() - 1) and use FacetNormal and ds measures accordingly.

Solve the linear system using a direct linear solver (e.g., LUSolver or the default direct solver via solve()).

After solving, compute the von Mises stress field in plane stress: sigma_vm = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where s11, s22, s12 are the in-plane stress components projected onto a scalar DG or CG function space.

Project the von Mises stress onto a scalar function space for visualisation and output.

Save the von Mises stress plot as q4_vm.png using matplotlib, with a filled contour or tripcolor plot showing the full plate geometry including the holes.

Save the displacement field u in XDMF format to a file named displacement.xdmf using XDMFFile.

Identify all mesh facets on the hole boundaries by checking proximity to each hole centre: a point is on a hole boundary if its distance from (0.33, 0.10) or (0.67, 0.10) is within a small tolerance of 0.04 m.

Evaluate the von Mises stress at all degrees of freedom or vertices located on the hole boundaries and compute the maximum value sigma_max.

Compute the stress concentration factor Kt = sigma_max / 2e6 and print it to stdout.

Print a summary report to stdout containing: the maximum von Mises stress on the hole boundaries in MPa and the stress concentration factor Kt.

Do not use any external mesh files; generate the mesh entirely within the script using mshr.
