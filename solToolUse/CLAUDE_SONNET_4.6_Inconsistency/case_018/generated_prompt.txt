Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement function space.
Use a direct linear solver (e.g., LUSolver or the default direct solver via solve()).
Define the L-shaped domain as a 1x1 square minus a 0.5x0.5 square cut from one corner (e.g., the top-right corner), resulting in vertices at (0,0), (1,0), (1,0.5), (0.5,0.5), (0.5,1), (0,1).
Mesh the L-shaped domain with approximately 64 elements per edge using a suitable FEniCS meshing approach (e.g., via mshr or a built-in mesh).
Use material properties: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
Apply the plane-stress reduced constitutive law: λ_eff = (E*ν)/((1+ν)*(1-ν)), μ = E/(2*(1+ν)).
Define the stress tensor using the plane-stress constitutive relation: σ = λ_eff * tr(ε) * I + 2*μ*ε, where ε is the symmetric gradient of displacement.
Include gravity as a body force vector f = (0, -ρ*g) in the weak form.
Apply a homogeneous Dirichlet boundary condition (fixed, zero displacement) on the left boundary where x = 0.
Keep all other boundaries traction-free (natural boundary condition, no Neumann term needed).
Apply a concentrated point load of -2.65e4 N in the y-component at the point (0.5, 0.5) using FEniCS PointSource.
Assemble the linear system, apply the PointSource to the right-hand side vector, then solve using a direct linear solver.
After solving, compute the in-plane Cauchy stress field by projecting or interpolating the stress tensor onto a suitable function space.
Compute the von Mises stress from the in-plane stress components as: σ_vm = sqrt(σ_xx^2 - σ_xx*σ_yy + σ_yy^2 + 3*σ_xy^2).
Output or save the displacement field and von Mises stress field for visualization (e.g., via .pvd or .xdmf files).
Assume unit thickness (t = 1 m) for the plane-stress model; no thickness scaling is needed in the weak form.
