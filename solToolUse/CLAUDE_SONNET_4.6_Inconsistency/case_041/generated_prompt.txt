Use FEniCS legacy (dolfin) for the entire implementation.

Solve a finite-strain Saint-Venant-Kirchhoff elasticity problem in plane strain on a three-hole strip.

Define the domain as a rectangle Ω = (0, 1.20) x (0, 0.20) m with three circular holes of radius a = 0.03 m centred on the midline y = 0.10 m at x = 0.30 m, x = 0.60 m, and x = 0.90 m.

Generate the mesh using mshr (or equivalent legacy FEniCS meshing) by subtracting three discs from the rectangle.

Use plane strain conditions throughout.

The primary unknown is the displacement vector u = (u_x, u_y).

Define the deformation gradient as F = I + grad(u).

Define the Green-Lagrange strain tensor as E_GL = 0.5 * (F^T * F - I).

Define the second Piola-Kirchhoff stress as S = lambda * tr(E_GL) * I + 2 * mu * E_GL.

Use Lamé parameters lambda = 5.769e6 Pa and mu = 3.846e6 Pa.

Define J = det(F).

Define the Cauchy stress as sigma = (1/J) * F * S * F^T.

Apply boundary condition u_x = 0 and u_y = 0 on the left edge (x = 0).

Apply boundary condition u_x = 0.012 m and u_y = 0 on the right edge (x = 1.20 m).

Apply traction-free (natural) boundary conditions on the top edge, bottom edge, and all three hole boundaries.

Implement load stepping by incrementally scaling the prescribed right-edge displacement from 0 to 0.012 m over a number of steps.

At each load step, solve the nonlinear equilibrium equations using Newton iterations via the built-in nonlinear solver (e.g., NonlinearVariationalSolver or Newton solver).

Formulate the weak form using the first Piola-Kirchhoff stress P = F * S and take its variation with respect to u.

After each converged load step, compute the maximum principal Green-Lagrange strain E_max as the largest eigenvalue of E_GL projected onto a suitable function space.

Stop advancing load steps if E_max exceeds 0.03; retain the last converged solution at that point.

Save a plot of the deformed configuration (mesh displaced by u, coloured by displacement magnitude or a relevant field) as q15_def.png.

Compute E_max over the domain and save a filled contour plot as q15_Emax.png.

Compute the deviatoric second Piola-Kirchhoff stress invariant (von Mises-like invariant of S) defined as sqrt(3/2 * dev(S):dev(S)) and save a filled contour plot as q15_vmS.png.

Export the final displacement field u to an XDMF file named q15_u.xdmf.

Export the final E_max scalar field to an XDMF file named q15_Emax.xdmf.
