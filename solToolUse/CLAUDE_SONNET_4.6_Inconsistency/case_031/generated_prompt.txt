Solve a 2D plane-stress linear elasticity problem on a parallelogram-shaped domain.

Define the parallelogram with vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3) using a mesh of 72 elements.

Generate the mesh by creating a rectangle mesh and mapping it to the parallelogram geometry using a coordinate transformation, or use mshr to define the polygon directly with approximately 72 triangular elements.

Use material properties E=70e9 Pa, nu=0.33, rho=2700 kg/m^3, g=9.81 m/s^2.

Apply the plane-stress constitutive law with unit thickness (t=1 m).

Define the plane-stress stiffness using the reduced constitutive relations: lambda_ps = E*nu/(1-nu^2), mu = E/(2*(1+nu)).

Define the stress tensor as sigma(u) = lambda_ps*tr(eps)*I + 2*mu*eps where eps = sym(grad(u)).

Use a vector-valued continuous Lagrange finite element space of degree 1 (VectorFunctionSpace, 'CG', 1) for the displacement field.

Identify the left inclined edge as the boundary where x=0.2*y/0.3, i.e., the line connecting (0,0) to (0.2,0.3), which satisfies y = 1.5*x (or equivalently x = y/1.5).

Apply a homogeneous Dirichlet boundary condition (zero displacement in both x and y) on the left inclined edge defined by the condition near(x[1] - 1.5*x[0], 0) and x[0] between 0 and 0.2.

Apply body force f = (0, -rho*g) as a volumetric load in the weak form using an inner product with the test function over the domain.

Compute the outward unit normal of the left inclined boundary (from (0,0) to (0.2,0.3)): the edge direction vector is (0.2, 0.3), so the outward normal pointing left is n = (-0.3, 0.2)/norm = (-0.3, 0.2)/sqrt(0.13).

Normalize the left boundary outward normal: n = (-0.3/sqrt(0.13), 0.2/sqrt(0.13)).

The applied load is described as -5 kN horizontal, meaning a force vector F_applied = (-5000, 0) N at point (1.1, 0.15).

Resolve the 5 kN horizontal load into the local normal component of the skew left boundary normal direction: F_normal = dot(F_applied, n) * n where n is the left boundary outward normal computed above.

Compute dot((-5000, 0), n) = -5000 * (-0.3/sqrt(0.13)) = 1500/sqrt(0.13).

Compute the normal component vector: F_normal = (1500/sqrt(0.13)) * (-0.3/sqrt(0.13), 0.2/sqrt(0.13)) = (1500/0.13)*(-0.3, 0.2) = (-3461.5, 2307.7) N approximately.

Apply this resolved normal load at point (1.1, 0.15) using two PointSource objects: one on the x-component of the displacement function space with magnitude F_normal[0], and one on the y-component with magnitude F_normal[1].

Apply the PointSource objects to the right-hand side vector b after assembling the linear system.

Assemble the bilinear form a = inner(sigma(u), eps(v)) * dx and the linear form L = inner(f, v) * dx.

Apply Dirichlet boundary conditions using apply() on both the matrix A and vector b.

Apply PointSource contributions to b after DirichletBC application.

Solve the linear system using a direct solver: use LUSolver or solve(A, u.vector(), b) with default direct method.

After solving, compute the full Cauchy stress tensor components sigma_xx, sigma_yy, sigma_xy by projecting or interpolating the stress expressions onto a scalar or tensor function space.

Compute von Mises stress as: von_mises = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).

Project the von Mises expression onto a scalar FunctionSpace('CG', 1) or ('DG', 0).

Output or save the displacement field u and von Mises stress field to files (e.g., XDMFFile or VTK) for visualization.

Print the maximum displacement magnitude and maximum von Mises stress value to the console.
