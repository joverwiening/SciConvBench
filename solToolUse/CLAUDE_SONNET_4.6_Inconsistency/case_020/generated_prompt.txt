Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-stress linear elasticity problem for displacement u = (u_x, u_y) on a rectangular domain Ω = (0, 1.0) x (0, 0.20) metres.
Create a uniform structured rectangular mesh with 40 subdivisions in x and 8 subdivisions in y using RectangleMesh with Point(0, 0) and Point(1.0, 0.20).
Define a vector-valued function space using VectorFunctionSpace with Lagrange elements of degree 1.
Use Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.30.
Derive plane-stress material constants: lambda_ps = E * nu / (1 - nu**2), mu = E / (2 * (1 + nu)).
Define the plane-stress constitutive law as sigma(u) = lambda_ps * tr(eps) * I + 2 * mu * eps, where eps = sym(grad(u)) and I is the 2x2 identity tensor.
Define the variational problem as: find u in V such that inner(sigma(u), sym(grad(v))) * dx = dot(T, v) * ds(top) for all v in V, where T = (0, -2000) N/m is the applied traction on the top edge.
Interpret the top-edge load as a 3D pressure of 2000 Pa acting on the top face with unit thickness, giving a 2D line traction of magnitude 2000 N/m in the negative y-direction, so T = Constant((0.0, -2000.0)).
Apply Dirichlet boundary conditions on the left edge (x = 0): fix both u_x = 0 and u_y = 0 using a single DirichletBC with a zero vector Constant((0.0, 0.0)).
Define the left boundary as the subdomain where x[0] < DOLFIN_EPS.
Define the top boundary as the subdomain where x[1] > 0.20 - DOLFIN_EPS.
Mark boundaries using a MeshFunction of dimension (mesh.topology().dim() - 1) and assign integer tags: tag 1 for the top edge, leaving all other boundaries unmarked (traction-free by default).
Define the measure ds using the boundary MeshFunction so that ds(1) integrates over the top edge only.
Assemble and solve the linear system using a direct linear solver (LUSolver or the default direct solver via solve).
After solving, extract the u_y component by projecting or interpolating the second component of u onto a scalar function space.
Save a colour map of u_y as q2_uy.png using matplotlib: extract vertex coordinates and u_y nodal values, use tripcolor or tricontourf with the mesh triangulation, add a colorbar, title the plot "u_y displacement (m)", and save with plt.savefig("q2_uy.png", dpi=150).
Save the full displacement field u to an XDMF file named q2_displacement.xdmf using XDMFFile, calling write_checkpoint or write with the displacement function labelled "displacement".
Use with XDMFFile(MPI.comm_world, "q2_displacement.xdmf") as xdmf and call xdmf.write(u) or xdmf.write_checkpoint(u, "displacement", 0).
Do not apply any Dirichlet or Neumann conditions on the right edge (x = 1.0) or the bottom edge (y = 0); these are traction-free by the natural boundary condition of the variational formulation.
Print the minimum and maximum values of u_x and u_y to the console after solving.
