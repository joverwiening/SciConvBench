Use FEniCS legacy (dolfin) for the entire implementation.
Solve the linear elasticity equations on a 2D square domain [-1,1]^2 with a slit along the segment from (0,0) to (1,0).
Use Lame parameters lambda_ = 0.5444837367825 and mu derived from plane-strain conventions; set mu = 1.0 and compute kappa = 3 - 4*nu for plane strain, but since only lambda and q are given, use lambda_ = 0.5444837367825 and set mu = 0.5 as the second Lame parameter (so that the pair is consistent with the given lambda).
Use q = 0.5430755788367 as the singularity exponent.
Define polar coordinates r = sqrt(x^2 + y^2) and theta = atan2(y, x) with theta in (-pi, pi].
Define the exact mode-I crack-tip displacement field using the Williams expansion:
u0_x = r^q * ( (2*kappa - 1)*cos(q*theta) - q*cos((q-2)*theta) ) / (2*mu)
u0_y = r^q * ( (2*kappa + 1)*sin(q*theta) + q*sin((q-2)*theta) ) / (2*mu)
where kappa = 3 - 4*nu, nu = lambda_ / (2*(lambda_ + mu)), and mu = 0.5.
Express u0_x and u0_y as FEniCS Expression objects using the C++ string interface with r, theta, q, kappa, and mu as parameters.
Generate a mesh of the square [-1,1]^2 using mshr or a built-in mesh generator with resolution 30.
Represent the slit as a single interior seam so the mesh is conforming and displacement remains single-valued across the slit faces.
Use vector Lagrange elements of degree 2 (VectorFunctionSpace with 'Lagrange', degree 2) for the displacement.
Define the linear elasticity bilinear form a(u,v) = integral of sigma(u):epsilon(v) dx, where sigma(u) = lambda_*div(u)*I + 2*mu*epsilon(u) and epsilon(u) = 0.5*(grad(u) + grad(u).T).
Define the linear form L(v) = 0 (no body forces).
Identify the outer square boundary (all four edges of [-1,1]^2) as a Dirichlet boundary.
Identify the slit faces (the top and bottom faces of the slit segment from (0,0) to (1,0)) as Dirichlet boundaries.
Impose the exact displacement field u0 as a Dirichlet boundary condition on both the outer square boundary and the slit faces.
Assemble the stiffness matrix and load vector from the variational forms.
Apply the Dirichlet boundary conditions to the assembled system.
Solve the resulting linear system using GMRES as the iterative solver with ILU preconditioning via FEniCS's KrylovSolver interface.
Set solver parameters: relative tolerance 1e-10, absolute tolerance 1e-12, maximum iterations 10000.
After solving, compute the L2 error norm between the FEniCS solution and the exact field u0 over the domain.
Print the L2 error norm to the console.
Optionally save the solution to a VTK or XDMF file for visualization.
