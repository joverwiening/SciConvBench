The job name is c3d15 and the input file must be named c3d15.inp.
Use the input deck exactly as provided in the reference, with no modifications to nodes, elements, boundary conditions, loads, material properties, or any other physics.
The element type is C3D15 (wedge elements) as specified in the input deck.
Create c3d15.inp in the working directory by writing out the full input deck verbatim.
Run CalculiX using the command ccx -i c3d15 or ccx c3d15, whichever works on the system.
Check c3d15.sta after the run to determine success by looking for the string JOB COMPLETED.
Retrieve the CalculiX version string by running ccx -v or the closest equivalent.
Write a results.json file in the working directory with the following fields: solver set to calculix, case_id set to c3d15, status set to success if JOB COMPLETED is found in c3d15.sta or error otherwise, ccx_version set to the version string obtained from ccx -v, artifacts set to an empty list, and notes set to the exact ccx command used plus any error message and the file that indicated failure if the run did not succeed.
