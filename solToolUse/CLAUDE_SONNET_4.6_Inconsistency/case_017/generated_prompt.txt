Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem using the dolfin finite element library.
Build the geometry as a cross-shaped plate: the union of a horizontal bar spanning x in [-1, 1] with width 0.6 (i.e., y in [-0.3, 0.3]) and a vertical bar spanning y in [-1, 1] with width 0.6 (i.e., x in [-0.3, 0.3]).
Subtract four circular holes of radius 0.12 centered at (0.6, 0), (-0.6, 0), (0, 0.6), and (0, -0.6) from the cross shape.
Generate the mesh using mshr with a resolution of 100.
Use a vector-valued second-order Lagrange finite element function space (VectorFunctionSpace with degree 2) for the displacement field.
Use the plane-stress constitutive law with Young's modulus E = 210000 and Poisson's ratio nu = 0.3.
Compute the plane-stress Lame-like parameters as: lambda_ps = E*nu/(1 - nu**2) and mu = E/(2*(1 + nu)).
Define the stress tensor using the plane-stress reduced form: sigma = lambda_ps * tr(eps) * I + 2*mu*eps, where eps is the symmetric gradient of displacement.
Apply a homogeneous Dirichlet boundary condition u = (0, 0) on the left edge where x = -1, using a tolerance of 1e-10.
Apply a Neumann traction t = (0, -5e4) on the right edge where x = 1, using a tolerance of 1e-10, by adding the surface integral of dot(t, v) * ds over that boundary to the right-hand side.
Leave all four circular hole boundaries traction-free (natural Neumann, do nothing).
Leave the top, bottom, and all other outer edges of the cross traction-free as well.
Use a direct linear solver (e.g., LUSolver or the default direct solver via solve) to solve the resulting linear system.
After solving, compute the von Mises stress field projected onto a scalar second-order Lagrange function space.
Compute von Mises stress as: sigma_vm = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2), evaluated from the stress tensor components.
Save the displacement field to a file named displacement.pvd.
Save the von Mises stress field to a file named von_mises.pvd.
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
