Use FEniCS legacy (dolfin) for all implementation.

Solve a 2D plane-stress linear elasticity problem on a right triangular domain with vertices at (0,0), (1,0), and (0,0.5).

Generate the mesh using mshr with a polygon defined by the three vertices and a resolution of 64.

Use material properties E=70e9 Pa, nu=0.33, rho=2700 kg/m^3, g=9.81 m/s^2.

Define the Lame parameters for plane stress as lmbda = E*nu/((1+nu)*(1-nu)) and mu = E/(2*(1+nu)).

Define the plane-stress constitutive law: sigma(u) = lmbda*tr(eps)*I + 2*mu*eps where eps = sym(grad(u)) and I is the 2x2 identity tensor.

Use a vector-valued continuous Lagrange finite element space of degree 1 (VectorFunctionSpace with 'CG', 1) for the displacement field.

Apply a Dirichlet boundary condition fixing both displacement components to zero on the base edge y=0, identified by the condition near(x[1], 0.0).

Apply body force f = (0, -rho*g) as a Constant vector over the entire domain.

Identify the sloping edge as the boundary where x[0] + 2*x[1] is near 1.0 (within tolerance 1e-10).

Treat the sloping-edge load as a uniform inward normal pressure of magnitude 2000 Pa applied as a Neumann traction on that edge.

Compute the outward unit normal of the sloping edge x + 2y = 1 analytically as n_slope = (1, 2) / sqrt(5), so the inward normal is (-1, -2) / sqrt(5).

Define the traction vector T = 2000 * (-1/sqrt(5), -2/sqrt(5)) as a Constant and apply it via the surface integral ds over the sloping edge boundary.

Define the variational problem: a(u,v) = integral of inner(sigma(u), sym(grad(v))) dx and L(v) = dot(f, v)*dx + dot(T, v)*ds(sloping_edge).

Use a MeshFunction of dimension (mesh.topology().dim()-1) to mark the sloping edge with tag 1 and define ds = Measure('ds', domain=mesh, subdomain_data=boundary_markers).

Solve the linear system using the default direct solver via solve(a == L, u, bc).

After solving, compute the displacement magnitude as a scalar field: disp_mag = sqrt(u[0]^2 + u[1]^2), projected onto a scalar CG1 function space using project().

Compute the full in-plane Cauchy stress tensor sigma_h = sigma(u) evaluated at each point.

Compute von Mises stress as: von_mises = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2), projected onto a scalar DG0 or CG1 function space using project().

Print the maximum displacement magnitude value using disp_mag.vector().max().

Print the maximum von Mises stress value using von_mises.vector().max().

Plot the displacement magnitude field using dolfin's plot() function and save to a file named displacement_magnitude.png.

Plot the von Mises stress field using dolfin's plot() function and save to a file named von_mises_stress.png.

Do not apply any Dirichlet or Neumann condition on the vertical edge x=0 (it is a free surface).
