Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement function space and a direct linear solver.
The domain is a right triangle with vertices at (0,0), (1,0), and (0,0.5).
Generate the mesh using 64 elements (use a mesh resolution parameter of 64 with a suitable dolfin mesh generator for the triangular domain).
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
Use the plane-stress reduced constitutive law to define the stress-strain relationship.
Assume unit thickness for the 2D domain.
Define the strain tensor as the symmetric gradient of displacement.
Define the plane-stress constitutive relation: σ = (E/(1-ν^2)) * ((1-ν)*ε + ν*tr(ε)*I) for in-plane components, with appropriate shear term using (1-ν)/2.
Apply a Dirichlet boundary condition fixing both displacement components to zero on the left edge where x = 0.
Apply gravity as a body force in the negative y direction with magnitude ρ * g.
Identify the hypotenuse as the boundary where x + 2y = 1 (within a suitable numerical tolerance).
Apply a Neumann traction on the hypotenuse representing a vertical (y-direction) surface traction of σ_yy = -5e3 * sin(π * x) Pa, where x is the global x-coordinate of the point on the hypotenuse.
The traction vector on the hypotenuse is (0, -5e3 * sin(π * x)) in the global frame, applied as a surface traction in the variational form.
Formulate the standard weak form: integrate σ:ε(v) over the domain equals integrate body force dot v over the domain plus integrate traction dot v over the hypotenuse boundary.
Use a continuous Lagrange (CG) vector function space of degree 1 (P1 elements) for the displacement field.
Solve the resulting linear system using a direct solver (e.g., LU factorization via dolfin's default direct solver).
After solving, compute the full in-plane Cauchy stress tensor field from the displacement solution using the plane-stress constitutive law.
Compute the von Mises stress from the in-plane stress components as: σ_vm = sqrt(σ_xx^2 - σ_xx*σ_yy + σ_yy^2 + 3*σ_xy^2).
Project both the displacement field and the von Mises stress field onto appropriate function spaces for output.
Print or save the maximum displacement magnitude and the maximum von Mises stress value.
