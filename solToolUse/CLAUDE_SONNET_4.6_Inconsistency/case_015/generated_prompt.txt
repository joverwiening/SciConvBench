Use FEniCS legacy (dolfin) for all implementation.

The domain is a 2D rectangle (0, 1.0) x (0, 0.20) metres with a semicircular notch of radius a = 0.05 m removed from the top edge, centred at (0.5, 0.2).

Build the geometry using mshr: create a Rectangle from (0,0) to (1.0, 0.2) and subtract a Circle centred at (0.5, 0.2) of radius 0.05. Use mshr.generate_mesh with resolution 64 or higher to resolve the notch.

Use plane-stress linear elasticity for the vector-valued displacement field u = (u_x, u_y) defined on the 2D mesh.

Use material parameters E = 200e9 Pa and nu = 0.30.

Define the plane-stress constitutive law: lambda_ps = E*nu/(1 - nu**2), mu = E/(2*(1 + nu)), and stress sigma(u) = lambda_ps*tr(eps)*I + 2*mu*eps where eps = sym(grad(u)).

Use a vector-valued CG (Lagrange) function space of degree 2 for the displacement.

Apply Dirichlet boundary conditions on the bottom edge (y = 0, within tolerance): u_x = 0 and u_y = 0.

Define the top edge as the region where y >= 0.2 - tolerance AND the point is NOT inside the semicircular notch (i.e., distance from (0.5, 0.2) >= 0.05 - tolerance).

Apply a Neumann traction t = (0, -10e6) N/m on the top edge segments (the portions of y = 0.2 excluding the notch arc), using a surface integral ds over that boundary region.

Mark the notch arc as traction-free (no Neumann term added for it).

Mark both vertical sides x = 0 and x = 1 as traction-free (no Neumann term).

Use a MeshFunction of dimension (mesh.topology().dim() - 1) to mark boundary facets: mark top-edge facets (excluding notch arc) with tag 1, and leave all other boundaries unmarked (natural zero traction).

Identify top-edge facets as those whose midpoint satisfies y >= 0.2 - tolerance and distance from (0.5, 0.2) >= 0.05 - tolerance.

Define the variational problem: a(u, v) = integral over Omega of inner(sigma(u), sym(grad(v))) dx, L(v) = integral over marked top boundary of dot(t_vec, v) ds(1) where t_vec = Constant((0.0, -10e6)).

Assemble and solve the linear system using a direct solver (LUSolver or the default direct backend).

After solving, compute the von Mises stress field on a scalar DG0 or CG1 function space using the plane-stress formula: sigma_vm = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where s = sigma(u) - (1/3)*tr(sigma(u))*I is the deviatoric stress, but use the full plane-stress von Mises: vm = sqrt(sigma_11^2 - sigma_11*sigma_22 + sigma_22^2 + 3*sigma_12^2) projected onto a scalar function space.

Project the von Mises stress onto a scalar CG1 (or DG0) function space using project().
