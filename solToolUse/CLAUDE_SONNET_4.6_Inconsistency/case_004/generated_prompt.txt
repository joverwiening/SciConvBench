Use FEniCS legacy (dolfin) for the entire implementation.

The problem is 2D plane-stress linear elasticity solved with the dolfin finite element library.

Geometry is an L-shaped domain defined as a 1x1 square with a 0.5x0.5 square cutout removed from one corner (e.g., the top-right corner, so the cutout occupies x in [0.5, 1] and y in [0.5, 1]).

Generate the mesh using dolfin's built-in meshing or mshr with 64 elements per edge resolution.

Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

Use the plane-stress reduced constitutive law throughout.

The plane-stress constitutive parameters are: lambda_ps = E*nu / (1 - nu**2), mu = E / (2*(1 + nu)).

Define the stress tensor using the plane-stress form: sigma(u) = lambda_ps * tr(eps(u)) * I + 2*mu*eps(u), where eps(u) = sym(grad(u)) and I is the 2x2 identity.

Use a vector-valued continuous Lagrange finite element space of degree 2 (or degree 1 if degree 2 is impractical) for the displacement field on the L-shaped domain.

The body force is f = (0, -rho*g) applied over the entire domain volume.

Define boundary regions using SubDomain classes or a MeshFunction on facets.

The left boundary is defined as all facets where x[0] is approximately 0 (within a small tolerance).

Apply a homogeneous Dirichlet boundary condition (zero displacement in both x and y) on the left boundary x = 0.

The traction boundary is defined as all facets where x[0] is approximately 1 (within a small tolerance), which is the outer right edge only.

The traction on the outer right edge x = 1 is a vertical (y-direction) traction that varies linearly with y: T = (0, -2.65e4 * y).

All other boundaries, including the re-entrant inner boundaries of the cutout, are traction-free (natural boundary condition, no action required).

Formulate the weak form: integrate sigma(u):eps(v) dx = integrate f·v dx + integrate T·v ds(traction_boundary) for all test functions v.

Solve the resulting linear system using a direct linear solver (e.g., LU via dolfin's default direct solver or by specifying "mumps" or "petsc").

After solving, compute the full in-plane Cauchy stress tensor field by projecting sigma(u) onto an appropriate tensor function space.

Compute the von Mises stress from the in-plane stress components as: von_mises = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2), where sij are the in-plane Cauchy stress components.

Project the von Mises stress onto a scalar function space for output.

Save the displacement field, the stress tensor field, and the von Mises stress field to output files (e.g., XDMF or VTK format) for visualization.

Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
