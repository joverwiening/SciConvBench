Run CalculiX with the command `ccx -i scheibe` or `ccx scheibe`, using whichever form the installed binary accepts.

After the run, check `scheibe.sta` for a successful termination line such as `JOB COMPLETED`.

Obtain the CalculiX version string by running `ccx -v` or the closest equivalent available.

Write a file named `results.json` in the working directory with the following schema:
- `solver`: set to the string `calculix`
- `case_id`: set to the string `scheibe`
- `status`: set to `success` if `scheibe.sta` contains a successful termination indicator, otherwise set to `error`
- `ccx_version`: set to the version string obtained from `ccx -v`
- `artifacts`: set to a list of output files produced by the run (e.g., `scheibe.dat`, `scheibe.frd`, `scheibe.sta`)
- `notes`: record the exact ccx command used; if the run failed, include the error message and the name of the file that indicated the failure

The expected output in `scheibe.dat` is 100 increments of displacement data for node set N1, with node 4 showing in-plane rigid body rotation displacements and node 10 showing a z-rotation accumulating to 3.141593 radians at the final increment, and all z-displacements equal to zero throughout.
