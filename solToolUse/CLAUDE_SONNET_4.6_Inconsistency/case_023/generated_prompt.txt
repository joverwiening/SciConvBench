Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a semi-circular domain of radius 1 m (the half-disk defined by y >= 0).
Use material properties E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3, and g = 9.81 m/s^2.
Assume unit thickness (t = 1 m) for the plane-stress formulation.
Generate the semi-circular mesh using mshr with a resolution of 64 elements (mshr.generate_mesh with resolution=64 on a mshr.Circle intersected or a half-disk constructed via mshr.Rectangle and mshr.Circle or directly via mshr.Circle with a cut).
Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace with "Lagrange", degree 2) for the displacement field.
Apply the reduced plane-stress constitutive law: sigma = E/(1-nu^2) * ((1-nu)*eps + nu*tr(eps)*I) where eps is the symmetric gradient of displacement and I is the 2x2 identity.
Define the bilinear form as the integral of inner(sigma(u), sym(grad(v))) dx over the domain.
Apply gravity as a body force vector f = (0, -rho*g) in the linear form integrated over the domain volume (dx).
Identify the flat base boundary as all facets where the y-coordinate is at or below a small tolerance (y <= 1e-10).
Apply a homogeneous Dirichlet boundary condition (zero displacement) on the entire flat base y = 0, clamping it fully in both x and y directions.
Replace the apex point load with a uniform pressure patch centred at the crown of the semicircle at point (0, 1).
Define the pressure patch as all boundary facets whose arc-length angular position satisfies abs(x) <= sin(patch_half_angle) and y >= 0, using a patch half-angle corresponding to approximately 5 degrees (patch_half_angle = pi/36), so the patch covers points on the curved boundary where abs(x) <= sin(5*pi/180).
Compute the total applied force from the patch as F_total = -5000 N in the vertical direction.
Compute the arc length of the patch as L_patch = 2 * 1 * sin(patch_half_angle) (chord approximation) or use the arc length = 2 * R * patch_half_angle = 2 * pi/36 metres.
Compute the pressure magnitude as p = F_total / (arc_length * thickness) where thickness = 1 m, so p = -5000 / (2 * pi/36) Pa (negative because it is compressive, directed inward along the outward normal).
Apply the pressure patch as a Neumann boundary condition by marking the patch facets with a MeshFunction, then adding the term -p * dot(n, v) * ds(patch_marker) to the linear form, where n is the outward unit normal.
Use a MeshFunction of dimension (mesh.topology().dim() - 1) to mark boundary facets: mark flat base facets as 1, mark the pressure patch facets as 2, and leave all other curved boundary facets unmarked (or marked 0).
Assemble the system and apply the Dirichlet boundary condition using the standard FEniCS apply method.
Solve the resulting linear system using a direct solver by calling solve(A, u.vector(), b, "lu") or dolfin.solve(a == L, u, bc) with the default direct LU solver.
After solving, compute the Cauchy stress tensor field sigma_h = sigma(u) projected onto a tensor function space (TensorFunctionSpace with "Lagrange", degree 1 or DG degree 0).
Compute the von Mises stress as von_mises = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2) using the in-plane stress components only (plane-stress assumption, sigma_zz = 0).
Project the von Mises expression onto a scalar FunctionSpace ("Lagrange", degree 1) to obtain a scalar field.
Save the displacement field u to a file named "displacement.pvd" using a dolfin File object.
Save the von Mises stress field to a file named "von_mises.pvd" using a dolfin File object.
Print to console the maximum displacement magnitude (u.vector().norm("linf") or the max of the projected magnitude field) and the maximum von Mises stress value.
Do not use any external meshing tool other than mshr (which is part of the FEniCS legacy distribution).
Do not use FEniCS-X (dolfinx); use only the dolfin Python interface.
