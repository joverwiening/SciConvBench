Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress static linear elasticity problem on a cantilever plate with a circular hole.
Geometry is a rectangle of width 4.0 and height 1.0.
The circular hole has radius 0.3 and is centred at (1.0, 0.5).
Generate the mesh using mshr with resolution 72 by subtracting a Circle from a Rectangle domain.
Use a second-order vector Lagrange function space (VectorFunctionSpace with degree 2) for the displacement field.
Material properties are Young's modulus E = 210e3 and Poisson's ratio nu = 0.3.
Compute the Lame parameters as lmbda = E*nu/((1+nu)*(1-2*nu)) and mu = E/(2*(1+nu)).
Do not apply any plane-stress reduction to the constitutive law; use the standard 3D isotropic Lame form directly.
Define the strain as the symmetric gradient of displacement: eps(u) = sym(grad(u)).
Define the stress as sigma(u) = lmbda*tr(eps(u))*Identity(2) + 2*mu*eps(u).
Apply a homogeneous Dirichlet boundary condition u = (0, 0) on the left edge where x[0] < 1e-10.
Apply a uniform downward Neumann traction t = (0, -1e5) on the right edge where x[0] > 4.0 - 1e-10.
Leave the hole boundary and the top and bottom edges traction-free (natural boundary condition, no explicit treatment needed).
Apply no body force.
Assemble and solve the linear system using a direct solver (LUSolver or the default direct backend via solve).
After solving, compute the von Mises stress field projected onto a scalar DG0 or CG1 function space.
Compute von Mises stress as sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2) using the plane-stress components of the stress tensor.
Save the displacement field to a file named displacement.pvd in PVD/VTK format.
Save the von Mises stress field to a file named von_mises.pvd in PVD/VTK format.
Print to the console the maximum absolute displacement magnitude and the maximum von Mises stress value.
