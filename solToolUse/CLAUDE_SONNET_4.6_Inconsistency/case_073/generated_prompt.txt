Create a file named beamheatplas.inp in the working directory using exactly the input deck provided in the reference text, without any modifications.
The input deck defines a cantilever beam finite element model using C3D20R elements with 261 nodes and 32 elements.
The model includes plasticity with isotropic hardening, thermal expansion, density, specific heat, and conductivity for material HY.
The analysis step uses *COUPLED TEMPERATURE-DISPLACEMENT, STEADY STATE, DIRECT with a time increment of 0.1 and end time of 1.0.
The *CONTROLS card with TIME INCREMENTATION parameters must be included exactly as written to ensure convergence.
Distributed loads *DLOAD are applied to elements 29, 30, 31, 32 with P2 = -1000.
Heat flux *DFLUX is applied to element set B1 with BFNU.
Boundary conditions constrain node set CN7 in direction 3, node 1 in directions 1-2, and node 2 in direction 2, plus CN7 in DOF 11 set to 0.
Initial temperature conditions are set to 0 for all nodes in NALL.
*NODE PRINT outputs NT for NSET=NALL at FREQUENCY=100.
Run CalculiX using the command ccx -i beamheatplas or ccx beamheatplas, whichever is available on the system.
Check beamheatplas.sta for successful termination indicated by the text JOB COMPLETED.
Record the CalculiX version string obtained from ccx -v.
Write a results.json file in the working directory with fields: solver set to calculix, case_id set to beamheatplas, status set to success if JOB COMPLETED is found in the sta file or error otherwise, ccx_version set to the version string, artifacts set to an empty array, and notes containing the exact ccx command used and any error message with the file that indicated failure if the run did not succeed.
