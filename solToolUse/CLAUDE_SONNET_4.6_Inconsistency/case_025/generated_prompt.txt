Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement finite element space and a direct linear solver.
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
Assume unit thickness for the plane-stress formulation.
Use the reduced plane-stress constitutive law: sigma = (E / (1 - nu^2)) * ((1 - nu) * eps + nu * tr(eps) * I) with the appropriate shear term (E / (2*(1+nu))) for off-diagonal components.
Define the geometry as a stepped polygon with 8 vertices that forms a recognizable stepped shape, for example: (0.0, 0.0), (1.0, 0.0), (1.0, 0.3), (0.7, 0.3), (0.7, 0.6), (0.3, 0.6), (0.3, 0.3), (0.0, 0.3), closing back to (0.0, 0.0).
Create the mesh using the dolfin Mesh and MeshEditor or mshr polygon with approximately 72 elements (use mshr with generate_mesh resolution targeting ~72 elements, e.g., resolution=6 or similar).
Use a continuous Lagrange vector function space of degree 1 (P1) for the displacement field.
Apply a Dirichlet boundary condition fixing all displacement components (ux = 0, uy = 0) on the bottom edge where y = 0 (within a small tolerance).
Apply a vertical traction of sigma_yy = -10000 Pa (i.e., traction vector t = (0, -10000) N/m^2) as a Neumann condition on the entire top boundary of the domain.
Identify the top boundary as the set of facets where y equals the maximum y-coordinate of the domain (within a small tolerance).
Apply body force due to gravity as a volume load f = (0, -rho * g) = (0, -2700 * 9.81) N/m^3 in the weak form.
Formulate the bilinear form a(u, v) = integral of sigma(u) : epsilon(v) dx over the domain.
Formulate the linear form L(v) = integral of f dot v dx + integral of t dot v ds over the top boundary.
Use the symmetric gradient epsilon(u) = 0.5 * (grad(u) + grad(u).T) for the strain tensor.
Compute the in-plane Cauchy stress tensor components from the plane-stress constitutive law applied to the computed displacement solution.
Compute the von Mises stress as: sigma_vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).
Project the displacement magnitude sqrt(ux^2 + uy^2) onto a scalar function space and save it.
Project the von Mises stress onto a scalar DG0 or P1 function space.
Save the displacement magnitude field to a file named displacement_magnitude.pvd.
Save the von Mises stress field to a file named von_mises_stress.pvd.
Print the maximum displacement magnitude and the maximum von Mises stress to the console.
Do not use any deprecated or non-legacy FEniCS features; use only dolfin imports.
