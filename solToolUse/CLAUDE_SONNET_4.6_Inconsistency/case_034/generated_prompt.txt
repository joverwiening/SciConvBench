Use FEniCS legacy (dolfin) for all implementation.

The problem is 2D plane-stress linear elasticity solved with a vector-valued displacement finite element space and a direct linear solver.

The geometry is an L-shaped domain defined as a 1x1 square with a 0.5x0.5 square removed from the top-right corner, giving vertices at (0,0), (1,0), (1,0.5), (0.5,0.5), (0.5,1), (0,1).

Generate the L-shaped mesh using mshr with 64 elements per edge resolution, or equivalent mesh refinement targeting 64 elements per edge.

Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

Use the plane-stress reduced constitutive law throughout.

Define the plane-stress Lame-like parameters as: lambda_ps = E*nu / (1 - nu**2), mu = E / (2*(1 + nu)).

Define the symmetric strain tensor as epsilon(u) = sym(grad(u)).

Define the plane-stress Cauchy stress tensor as sigma(u) = lambda_ps * tr(epsilon(u)) * Identity(2) + 2*mu*epsilon(u).

Use a vector-valued continuous Lagrange finite element space of degree 2 (VectorFunctionSpace with 'CG', degree 2) defined on the L-shaped mesh.

Apply a Dirichlet boundary condition fixing both displacement components to zero on the left boundary where x <= DOLFIN_EPS.

Apply a body force representing gravity: f = (0, -rho*g) as a Constant or Expression over the entire domain.

Apply a Neumann traction on the outer right edge where x >= 1 - DOLFIN_EPS.

The traction vector on the right edge is t = (0, -2.65e4 * x[0]), where x[0] is the global x-coordinate of the point being evaluated (not the y-coordinate).

The re-entrant inner boundaries (the two edges forming the removed corner at x=0.5 and y=0.5) are traction-free; apply no Neumann condition there.

Formulate the standard weak form: inner(sigma(u), epsilon(v))*dx == dot(f, v)*dx + dot(t, v)*ds(right_boundary).

Use a FacetFunction or MeshFunction to mark the right boundary (x >= 1 - DOLFIN_EPS) and integrate the traction term only over that marked subdomain using a ds measure restricted to that marker.

Solve the resulting linear system using a direct solver (LUSolver or solver with 'mumps' or 'petsc' backend).

After solving, compute the full in-plane Cauchy stress tensor field by projecting sigma(u) onto a tensor function space (TensorFunctionSpace with 'DG', degree 1 or 'CG', degree 1).

Compute the von Mises stress as: sigma_vm = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2), using the in-plane stress components only (plane-stress assumption, sigma_zz = 0).

Project the von Mises stress onto a scalar function space (FunctionSpace with 'CG' or 'DG', degree 1).

Output the following: maximum displacement magnitude over all mesh nodes, maximum von Mises stress over all mesh nodes, and save the displacement field, von Mises stress field, and stress tensor components to VTK or XDMF files for visualization.

Print the maximum displacement magnitude and maximum von Mises stress to stdout with clear labels.
