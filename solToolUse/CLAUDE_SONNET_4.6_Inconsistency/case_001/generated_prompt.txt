Final Specification:

Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement finite element space and a direct linear solver.
Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.
The 2D domain is a stepped polygon defined by the vertices in order: (0,0), (0.8,0), (0.8,0.2), (0.5,0.2), (0.5,0.5), (0.3,0.5), (0.3,0.2), (0,0.2), closing back to (0,0).
Mesh the polygon using dolfin/mshr with a resolution targeting approximately 72 elements.
Use the plane-stress reduced constitutive law throughout.
Assume unit thickness in the out-of-plane direction.
Define the plane-stress stiffness tensor using the standard reduced formulation: lambda_ps = 2*lambda*mu/(lambda+2*mu) and mu unchanged, where lambda and mu are the standard Lame parameters derived from E and nu.
Apply a Dirichlet boundary condition fixing both displacement components (ux=0, uy=0) on the bottom edge where y=0.
Apply a body force vector f = (0, -rho*g) throughout the entire domain volume.
Apply a Neumann traction on the top partial edge segment where 0.3 <= x <= 0.5 and y = 0.5.
The traction on that top segment is a vertical normal traction sigma_yy(y) = -8000 * y Pa, evaluated using the global coordinate y at each point on that boundary segment.
No traction is applied on any other boundary (all remaining edges are traction-free natural boundaries).
Use a continuous Lagrange vector function space of degree 2 (P2 elements) for the displacement field.
Assemble and solve the linear variational problem using a direct solver (e.g., LU factorization via dolfin's default direct solver).
After solving, compute the full in-plane Cauchy stress tensor field sigma from the displacement solution using the plane-stress constitutive relation.
Compute the von Mises stress from the in-plane stress components as: von_mises = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).
Project both the displacement field and the von Mises stress scalar field onto appropriate function spaces for output.
Save the displacement field to a file named displacement.pvd.
Save the von Mises stress field to a file named von_mises.pvd.
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
