Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-strain small-strain linear elasticity problem for a nearly incompressible perforated strip.
The domain is a rectangle (0, 1.0) x (0, 0.20) metres with a circular hole of radius 0.04 m centred at (0.50, 0.10).
Generate the mesh using mshr: create a Rectangle minus a Circle, and use a mesh resolution of 64 (mshr generate parameter).
Use a displacement-only formulation (no pressure field) since the hole relieves volumetric locking.
Use vector-valued P2 (quadratic Lagrange) triangular elements for the displacement field.
Apply the plane-strain assumption by using the 3D strain energy with the out-of-plane strain set to zero, i.e., use the standard plane-strain constitutive law expressed via Lame parameters.
Compute Lame parameters as lmbda = E*nu/((1+nu)*(1-2*nu)) and mu = E/(2*(1+nu)) with E = 5e6 Pa and nu = 0.49.
Define the strain tensor as eps(u) = sym(grad(u)) in 2D.
Define the stress tensor as sigma(u) = lmbda*tr(eps(u))*I + 2*mu*eps(u) where I is the 2x2 identity.
Define the weak form as the inner product of sigma(u) and eps(v) integrated over the domain, with zero body force and zero traction on all Neumann boundaries.
Apply Dirichlet boundary condition on the left edge (x = 0): fix both u_x = 0 and u_y = 0.
Apply Dirichlet boundary condition on the right edge (x = 1.0): prescribe u_x = 0.001 m and u_y = 0.
The top edge, bottom edge, and hole boundary are traction-free (natural boundary conditions, no action needed).
Solve the linear system using a direct solver (LU factorisation via dolfin's default direct solver, e.g., "mumps" or "default").
After solving, compute the von Mises stress field as a scalar field: vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2) projected onto a scalar DG0 or P1 function space.
Save a colour map plot of the von Mises stress field to q11_vm.png using matplotlib, with a labelled colorbar and title.
Save a colour map plot of the x-displacement field u_x to q11_ux.png using matplotlib, with a labelled colorbar and title.
Save the displacement field (the solution u) to a file named displacement.xdmf in XDMF format using dolfin's XDMFFile.
Use dolfin.plot or extract vertex values and use matplotlib's tripcolor for all plots; do not rely on any interactive display (use matplotlib Agg backend).
All output files (q11_vm.png, q11_ux.png, displacement.xdmf) are saved in the current working directory.
