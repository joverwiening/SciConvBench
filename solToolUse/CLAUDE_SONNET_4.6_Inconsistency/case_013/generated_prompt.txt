Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a functionally graded rectangular plate.
Define the domain Ω = (0, 1.0) x (0, 0.20) metres.
Create a structured rectangular mesh of 100 x 20 quadrilateral-equivalent cells over Ω using RectangleMesh.
Use vector Lagrange elements (degree 1) for the displacement field u = (u_x, u_y).
Define Young's modulus as a spatially varying field E(y) = 100e9 + 100e9 * (y / 0.20) Pa, where y is the spatial coordinate.
Set Poisson's ratio ν = 0.30 uniformly throughout the domain.
Use the plane-stress reduced constitutive law to define the stress tensor in terms of strain.
The plane-stress constitutive relation is: σ = (E / (1 - ν²)) * ((1 - ν) * ε + ν * tr(ε) * I) adjusted for plane stress, i.e., σ_xx = E/(1-ν²) * (ε_xx + ν*ε_yy), σ_yy = E/(1-ν²) * (ε_yy + ν*ε_xx), σ_xy = E/(1+ν) * ε_xy.
Apply a Dirichlet boundary condition on the left edge (x = 0): fix both u_x = 0 and u_y = 0.
Apply a Neumann traction boundary condition on the right edge (x = 1.0): traction vector t = (2e6, 0) Pa (force per unit area, unit thickness assumed).
Leave the top edge (y = 0.20) and bottom edge (y = 0.0) traction-free (natural boundary condition, no additional terms needed).
Assemble the bilinear form a(u, v) = integral over Ω of σ(u) : ε(v) dx.
Assemble the linear form L(v) = integral over the right boundary of t · v ds.
Use a direct linear solver (e.g., LU) to solve the resulting linear system.
After solving, compute the displacement magnitude field |u| = sqrt(u_x² + u_y²).
Save a colour map of |u| as q9_disp.png using matplotlib, with a colorbar and axis labels.
Save the displacement field u in XDMF format to a file named q9_displacement.xdmf.
Assume unit thickness (1 m) in the out-of-plane direction for all traction and constitutive calculations.
