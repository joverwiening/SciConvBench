Use FEniCS legacy (dolfin) for all implementation.

Solve a 2D plane-stress linear elasticity problem using the dolfin finite element library.

Use material properties: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

Assume unit thickness for the plane-stress formulation.

Use the reduced plane-stress constitutive law to relate in-plane stresses to in-plane strains.

Define the stepped polygon domain with the following 8 vertices in order: (0.0, 0.0), (1.0, 0.0), (1.0, 0.3), (0.5, 0.3), (0.5, 0.6), (0.3, 0.6), (0.3, 0.3), (0.0, 0.3).

This geometry has a wide base from x=0 to x=1 at y=0, rising to y=0.3 on both outer sides, with a raised central step between x=0.3 and x=0.5 reaching y=0.6.

Create the mesh using the dolfin Mesh and mshr (or dolfin built-in polygon meshing) with approximately 72 elements, or use generate_mesh with resolution targeting ~72 elements.

Define a vector-valued function space using Lagrange elements of degree 1 (P1) for the displacement field over this mesh.

Apply a Dirichlet boundary condition fixing both displacement components (u_x = 0, u_y = 0) on the bottom edge where y = 0 (within a small tolerance).

Apply a Dirichlet boundary condition fixing u_y = 0 on the left outer vertical face at x = 0 (within tolerance) where y > 0, treating it as a roller in the vertical direction.

Apply a Dirichlet boundary condition fixing u_y = 0 on the right outer vertical face at x = 1 (within tolerance) where y > 0, treating it as a roller in the vertical direction.

Apply a Dirichlet boundary condition fixing u_x = 0 on the left stem face at x = 0.3 (within tolerance), treating it as a roller support with zero normal displacement.

Apply a Dirichlet boundary condition fixing u_x = 0 on the right stem face at x = 0.5 (within tolerance), treating it as a roller support with zero normal displacement.

Apply a Neumann traction boundary condition of sigma_xx = 5000 Pa (horizontal normal traction) on the top edge segment where y = 0.6 and 0.3 <= x <= 0.5.

Apply body force due to gravity as a distributed volume force f = (0, -rho * g) throughout the domain.

Formulate the bilinear form a(u, v) using the plane-stress strain energy and the linear form L(v) using the body force and the Neumann traction.

Use the plane-stress stress tensor: sigma_xx = E/(1-nu^2) * (eps_xx + nu*eps_yy), sigma_yy = E/(1-nu^2) * (eps_yy + nu*eps_xx), sigma_xy = E/(2*(1+nu)) * 2*eps_xy.

Solve the resulting linear system using a direct linear solver (e.g., LU factorization via dolfin's default direct solver or by specifying solver type "lu").

After solving, compute the Cauchy stress tensor field projected onto a suitable function space (e.g., DG0 or CG1 tensor function space).

Compute the von Mises stress from the in-plane stress components as: von_mises = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).

Project the von Mises stress onto a scalar function space for visualization and output.
