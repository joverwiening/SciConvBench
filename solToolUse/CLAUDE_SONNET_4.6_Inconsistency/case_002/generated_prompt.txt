Use FEniCS legacy (dolfin) for all implementation.

The 2D domain is a right triangle with vertices at (0,0), (1,0), and (0,0.5).

Generate the triangular mesh using mshr with a resolution of 64 elements (CircleMesh or mshr.Polygon with the three vertices and generate with resolution=64).

Use a vector-valued continuous Lagrange finite element space of degree 1 (P1) for the displacement field.

Formulate the problem as 2D plane stress with unit thickness.

Use the reduced plane-stress constitutive law: the in-plane stress tensor is sigma = (E/(1-nu^2)) * ((1-nu)*eps + nu*tr(eps)*I) where eps is the symmetric gradient of displacement, E=70e9 Pa, nu=0.33.

Apply a Dirichlet boundary condition fixing both displacement components to zero on the edge x=0 (the clamped vertical edge).

Apply a body force f = (0, -rho*g) with rho=2700 kg/m^3 and g=9.81 m/s^2 throughout the domain.

Apply a Neumann traction on the sloping boundary defined by x + 2y = 1.

The traction on the sloping boundary is a true outward normal traction of magnitude p=3000 Pa: t = p * n where the outward unit normal is n = (2, 1)/sqrt(5).

Identify the sloping boundary in the mesh by marking facets where x + 2y is approximately equal to 1 (within a small tolerance, e.g., 1e-10).

Assemble the Neumann term as the integral of dot(t, v) ds over the sloping boundary facets, where v is the test function.

Solve the resulting linear system using a direct linear solver (e.g., LU via dolfin's default direct solver or PETSc LU).

After solving, compute the displacement magnitude field as sqrt(u_x^2 + u_y^2) and project it onto a scalar DG0 or CG1 space for output.

Compute the von Mises stress from the in-plane Cauchy stress field using the formula: von_mises = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where s11, s22, s12 are the in-plane stress components.

Project the von Mises stress onto a scalar function space (e.g., DG0 or CG1) for output.

Print or save the maximum displacement magnitude and maximum von Mises stress values.

Save the displacement field, displacement magnitude, and von Mises stress to output files (e.g., XDMF or PVD format) for visualization.
