Use FEniCS legacy (dolfin) for all implementation.

Solve a 2D plane-stress linear elasticity problem on a parallelogram-shaped domain.

Define the parallelogram with vertices at (0,0), (1,0), (1.2,0.3), and (0.2,0.3) using a mesh of 72 triangular elements generated via dolfin's built-in meshing or by defining the geometry explicitly with the four corner points.

Use material parameters E=70e9 Pa, nu=0.33, rho=2700 kg/m^3, and g=9.81 m/s^2.

Define the plane-stress constitutive law with Lame-like parameters expressed as E_ps = E/(1-nu^2) and nu_ps = nu, giving sigma = (E/(1-nu^2)) * ((1-nu)*eps + nu*tr(eps)*I) for in-plane components, with the shear modulus G = E/(2*(1+nu)).

Use a vector-valued continuous Lagrange finite element space of degree 1 (P1) for the displacement field u = (u_x, u_y).

Apply a body force f = (0, -rho*g) as a volume load over the entire domain.

Identify the left slope as the edge connecting vertices (0,0) and (0.2,0.3).

Compute the unit tangent vector of the left slope as t = (0.2, 0.3) / norm((0.2, 0.3)), which gives t = (0.2, 0.3) / sqrt(0.04 + 0.09).

Apply a tangential shear traction on the left slope equal to T = sigma_xx_magnitude * t, where sigma_xx_magnitude = 6000 Pa, so T = 6000 * t as a Neumann boundary condition expressed as a surface traction vector.

Identify the right slope as the edge connecting vertices (1,0) and (1.2,0.3).

Apply a homogeneous Dirichlet boundary condition (u = (0,0)) on the right slope.

Leave the bottom edge (from (0,0) to (1,0)) and the top edge (from (0.2,0.3) to (1.2,0.3)) as traction-free (natural boundary conditions with zero traction).

Mark boundaries using a SubDomain approach or a MeshFunction on facets with tolerance 1e-10 for geometric identification.

Formulate the weak form as: integral over domain of inner(sigma(u), eps(v)) dx = integral over domain of dot(f, v) dx + integral over left slope of dot(T, v) ds.

Use the symmetric gradient eps(u) = 0.5*(grad(u) + grad(u).T) for the strain tensor.

Assemble the linear system and solve using a direct linear solver (LUSolver or the default direct solver via solve()).

After solving, compute the full in-plane Cauchy stress tensor components sigma_xx, sigma_yy, sigma_xy by projecting or interpolating the stress expressions onto a suitable scalar or tensor function space (DG0 or P1 projection).

Compute the von Mises stress as von_mises = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2) using the plane-stress formula (sigma_zz = 0).

Project the von Mises stress onto a scalar DG0 or P1 function space.

Output or save the displacement field u and the von Mises stress field to files (e.g., XDMF or PVD format) for visualization.

Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
