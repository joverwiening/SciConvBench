Use FEniCS legacy (dolfin) for the entire implementation.

Solve a 2D plane-stress linear elasticity problem on a right triangular domain.

The triangle vertices are (0,0), (1,0), and (0,0.5).

Use material properties E = 70e9 Pa and nu = 0.33.

Treat the domain as plane stress with unit thickness.

Use the plane-stress reduced constitutive law: sigma = (E/(1-nu^2)) * ((1-nu)*eps + nu*tr(eps)*I) with the shear term scaled by (1-nu)/2.

Build the mesh by defining the triangular domain using mshr (or a built-in triangular mesh) with a resolution targeting approximately 64 elements.

Define a vector-valued continuous Lagrange finite element space (degree 1) for the displacement field u over the triangular mesh.

Apply the Dirichlet boundary condition u_x = 0 on the left edge where x = 0 (within a small tolerance).

Apply the Dirichlet boundary condition u_y = 0 on the bottom edge where y = 0 (within a small tolerance).

Apply a concentrated vertical load of -5000 N (i.e., -5 kN) at the point (0.5, 0.25) using FEniCS PointSource acting on the y-component of the displacement test function.

Formulate the standard bilinear form a(u,v) = integral of inner(sigma(u), epsilon(v)) dx and the linear form L(v) = 0 (body forces are zero; the PointSource is added directly to the assembled right-hand side vector).

Assemble the stiffness matrix and right-hand side vector, apply the PointSource to the right-hand side, then apply the Dirichlet boundary conditions.

Solve the resulting linear system using a direct linear solver (e.g., LU factorization via the default dolfin direct solver).

Compute the von Mises stress from the in-plane Cauchy stress field using the formula: von_mises = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2) where s11, s22, s12 are the in-plane stress components.

Project the von Mises stress onto a scalar DG0 or CG1 function space for output.

Output or print the maximum displacement magnitude and the maximum von Mises stress value.

Save the displacement field and von Mises stress field to files (e.g., XDMF or PVD format) for visualization.
