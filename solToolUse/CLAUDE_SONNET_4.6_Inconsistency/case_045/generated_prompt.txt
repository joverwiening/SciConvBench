Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-stress small-strain linear elasticity problem on a two-material bonded rectangular strip.
Define the domain Omega as a rectangle (0, 1.0) x (0, 0.20) metres.
Create a structured mesh of 80 divisions in x and 16 divisions in y over Omega using RectangleMesh with Point(0, 0) and Point(1.0, 0.20).
Define two subdomains using MeshFunction of type size_t on cells: mark cells with y >= 0.10 as subdomain 1 (aluminium, top half) and cells with y < 0.10 as subdomain 2 (steel, bottom half).
Use a DG0 (piecewise constant) FunctionSpace to represent material fields E and nu over the mesh.
Assign E = 70e9 Pa and nu = 0.30 to subdomain 1 (aluminium, top half Omega_Al).
Assign E = 200e9 Pa and nu = 0.30 to subdomain 2 (steel, bottom half Omega_Steel).
Use the plane-stress reduced constitutive law: sigma = (E / (1 - nu^2)) * ((1 - nu) * sym(grad(u)) + nu * tr(sym(grad(u))) * I) expressed via Lame-equivalent plane-stress parameters lambda_ps = E*nu/(1-nu^2) and mu = E/(2*(1+nu)).
Define the stress tensor as sigma(u) = lambda_ps * tr(eps) * I + 2 * mu * eps where eps = sym(grad(u)).
Use a continuous Lagrange vector function space (CG, degree 2) for the displacement field u = (u_x, u_y).
Define the bilinear form a(u, v) = integral over Omega of inner(sigma(u), sym(grad(v))) dx using the DG0 material coefficients.
Define the linear form L(v) using a Neumann boundary condition on the right edge (x = 1.0): apply traction t = (0, -5000) N/m as a surface integral ds over the right boundary.
Mark the right boundary as the subdomain where x >= 1.0 - 1e-10 using a MeshFunction and define the corresponding surface measure ds.
Apply Dirichlet boundary conditions on the left edge (x = 0): fix u_x = 0 and u_y = 0 (fully fixed).
Leave the top edge (y = 0.20) and bottom edge (y = 0.00) traction-free (natural boundary condition, no additional terms needed).
Enforce perfect bonding at the interface y = 0.10 implicitly through the single conforming displacement function space (continuity of displacement is automatic; traction continuity is enforced weakly by the variational formulation).
Assemble the system and solve using a direct linear solver (LU factorisation via dolfin's default direct solver, e.g., solver type "lu").
Assume unit thickness (t = 1 m) so that the 2D integrals directly represent the physical problem per unit thickness.
After solving, compute the displacement magnitude field |u| = sqrt(u_x^2 + u_y^2) as a scalar Function projected onto a CG1 scalar space.
Save a colour map of |u| as q7_disp.png using matplotlib: plot the mesh with the |u| field using dolfin's plot function or a manual tripcolor plot, add a colorbar, title it "Displacement magnitude |u|", and save with plt.savefig("q7_disp.png", dpi=150).
Save the displacement field u to an XDMF file named q7_displacement.xdmf using XDMFFile with encoding XDMFFile.Encoding.HDF5, writing the function with write_checkpoint or a standard file.write(u, 0.0) call.
Print the maximum displacement magnitude value to stdout after solving.
