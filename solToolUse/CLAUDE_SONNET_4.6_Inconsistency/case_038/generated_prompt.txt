Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem on a semi-circular domain of radius 1 m (the half-disk with y >= 0).
Use material properties E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3, g = 9.81 m/s^2.
Generate the semi-circular mesh using mshr with a resolution of 64 elements (mshr.Circle and mshr.Rectangle or mshr.Polygon to cut the half-disk, then generate with resolution=64).
Define the displacement function space as a vector-valued CG (Lagrange) element of degree 1 on the mesh.
Apply the plane-stress reduced constitutive law: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)).
Define the stress tensor as sigma(u) = lambda_ps * tr(eps) * I + 2 * mu * eps, where eps = sym(grad(u)).
Apply a Dirichlet boundary condition fixing all displacement components to zero on the flat base where y = 0 (within a small tolerance).
Apply a uniform vertical traction of (0, -20000) Pa (i.e., -20 kPa in the y-direction) on the arc boundary (all boundary facets not on y = 0) as a Neumann condition via the boundary integral in the weak form.
Include body force due to gravity as a volume load f = (0, -rho * g) in the weak form.
Assemble the bilinear form a(u, v) = integral of inner(sigma(u), eps(v)) dx.
Assemble the linear form L(v) = integral of dot(f, v) dx + integral of dot(traction, v) ds over the arc.
Use a direct linear solver (LUSolver or the default direct solver via solve) to solve the linear system.
After solving, compute the full in-plane Cauchy stress components sigma_xx, sigma_yy, sigma_xy by projecting the stress tensor onto a tensor function space (DG0 or CG1).
Compute von Mises stress as von_mises = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2) using the in-plane components only (plane-stress assumption, sigma_zz = 0).
Project the von Mises expression onto a scalar function space.
Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
Save the displacement field to a file named displacement.pvd.
Save the von Mises stress field to a file named von_mises.pvd.
Do not use any external mesh file; generate the mesh entirely within the script using mshr.
Do not use FEniCSx or dolfinx; use only the legacy dolfin and mshr packages.
