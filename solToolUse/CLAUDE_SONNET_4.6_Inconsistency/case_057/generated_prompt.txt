Create a file named `zerovel.inp` in the working directory with the following exact contents:

**
**   Structure: beam.
**   Test objective: velocity for OUTPUT=2D.
**
*NODE
1,0,0,0
2,0.1,0,0
*ELEMENT,TYPE=B31,ELSET=Default
1,2,1
*MATERIAL,NAME=Material
*ELASTIC,TYPE=ISOTROPIC
10000000000,0
*DENSITY
1000
*BEAM SECTION,ELSET=Default,MATERIAL=Material,SECTION=RECT
0.01,0.01
0,-1,0
*STEP
*DYNAMIC
0.01,0.1,0,0
*CLOAD
1,1,0.01
*NODE FILE,GLOBAL=YES,OUTPUT=2D,FREQUENCY=10
U,V
*END STEP

Run CalculiX with the command `ccx -i zerovel` or `ccx zerovel`, whichever succeeds on the system.
Check `zerovel.sta` for a line indicating successful termination such as "JOB COMPLETED".
Obtain the CalculiX version string by running `ccx -v` or the closest equivalent available.
Write a file named `results.json` in the working directory using this schema:
{
  "solver": "calculix",
  "case_id": "zerovel",
  "status": "success" or "error",
  "ccx_version": the version string obtained from ccx -v,
  "artifacts": [],
  "notes": the exact ccx command used, and if the run failed, include the error message and the name of the file that indicated the failure
}
Set "status" to "success" if `zerovel.sta` contains a successful termination indicator, otherwise set it to "error".
Do not change any physics, element types, material properties, boundary conditions, or output requests from the input deck as written above.
