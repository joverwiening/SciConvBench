Use FEniCS legacy (dolfin) for the entire implementation.

Solve a 2D plane-stress linear elasticity problem using the dolfin finite element library.

Material properties: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravitational acceleration g = 9.81 m/s^2.

Geometry: a 1.0 m x 0.5 m rectangle with a circular hole of radius 0.1 m centered at (0.5, 0.25).

Generate the mesh using mshr (dolfin's built-in meshing): create the rectangle domain, subtract the circular hole, and generate a mesh targeting approximately 72 elements.

Use a vector-valued continuous Lagrange finite element space of degree 1 (P1) for the displacement field on this mesh.

Apply the plane-stress constitutive law with unit thickness (t = 1.0 m).

The plane-stress stiffness tensor components are: lambda_ps = (E * nu) / (1 - nu**2), mu = E / (2 * (1 + nu)).

Define the stress tensor as sigma(u) = lambda_ps * tr(eps(u)) * I + 2 * mu * eps(u), where eps(u) = sym(grad(u)) and I is the 2x2 identity.

Define the bilinear form a(u, v) = integral over domain of inner(sigma(u), eps(v)) dx.

Apply body force due to gravity as a volume load: f = (0, -rho * g) in the linear form L.

Replace the point load of -5000 N in the y-direction at (1.0, 0.25) with a uniform traction applied over the entire right edge (x = 1.0).

Compute the uniform traction magnitude as T_y = -5000 / 0.5 N/m (total force divided by the length of the right edge, 0.5 m), giving a traction vector t_right = (0, -10000) N/m.

Add the right-edge traction to the linear form as: integral over the right boundary of dot(t_right, v) ds(right_marker).

Mark the right boundary (x = 1.0) using a MeshFunction and a SubDomain, and use the corresponding surface measure ds restricted to that marker.

Leave the top edge (y = 0.5), bottom edge (y = 0.0), and hole boundary traction-free (no Neumann terms added for those boundaries).

Apply a Dirichlet boundary condition fixing both displacement components (u_x = 0, u_y = 0) on the left edge (x = 0).

Identify the left boundary using a SubDomain where x[0] < DOLFIN_EPS and apply the DirichletBC using the full vector zero condition.

Solve the resulting linear system using a direct solver (LUSolver or the default direct backend via solve(a == L, u, bc)).

After solving, compute the in-plane Cauchy stress field by projecting sigma(u) onto a tensor function space (DG0 or degree-1 tensor space).

Compute the von Mises stress as: von_mises = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2), using the in-plane stress components only (plane-stress assumption, sigma_zz = 0).

Project the von Mises expression onto a scalar function space for visualization and output.

Save the displacement field u, the von Mises stress field, and optionally the stress tensor components to VTK or XDMF files for post-processing.

Print the maximum displacement magnitude and the maximum von Mises stress value to the console.
