Use FEniCS legacy (dolfin) for all implementation.
Solve a 2D plane-strain nearly incompressible linear elasticity problem using a mixed displacement-pressure (u-p) saddle-point formulation.
Define the domain Ω = (0, 1.0) x (0, 0.20) metres as a rectangle.
Generate a structured mesh of 100 x 20 quadrilateral-based triangular cells over Ω using RectangleMesh.
Use small-strain linear elasticity in plane strain.
Set Young's modulus E = 5 MPa and Poisson's ratio ν = 0.49.
Compute the Lamé parameters as λ = E·ν / ((1+ν)(1−2ν)) and μ = E / (2(1+ν)).
Define a mixed finite element space using Taylor-Hood elements: continuous piecewise quadratic (P2) vector elements for displacement u and continuous piecewise linear (P1) scalar elements for pressure p.
Define the plane-strain constitutive relation using the deviatoric stress plus pressure split: σ(u, p) = 2μ·ε(u) + p·I, where ε(u) = sym(grad(u)).
Define the volumetric constraint equation: p = −λ·div(u).
Formulate the saddle-point weak form: find (u, p) in the mixed space such that the momentum equation and the incompressibility constraint are both satisfied weakly.
Apply the following Dirichlet boundary conditions: on the left edge (x = 0), fix u_x = 0 and u_y = 0; on the right edge (x = 1.0), prescribe u_x = 0.03 m and u_y = 0.
Leave the top and bottom edges traction-free (natural boundary conditions, no additional terms).
Assemble the full saddle-point system and solve it using a direct linear solver (e.g., LU via dolfin's default direct solver).
Extract the displacement sub-function u and the pressure sub-function p from the solution.
Compute the displacement magnitude |u| = sqrt(u_x² + u_y²) at each node.
Save a colour map of |u| as q10_disp.png using matplotlib, with a colourbar and axis labels.
Save the displacement field u to an XDMF file (e.g., q10_displacement.xdmf) using dolfin's XDMFFile.
