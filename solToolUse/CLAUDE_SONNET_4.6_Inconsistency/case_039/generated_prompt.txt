Use FEniCS legacy (dolfin) for the entire implementation.
Solve a 2D plane-stress linear elasticity problem using a vector-valued displacement finite element space.
Use a direct linear solver (e.g., LU) to solve the assembled linear system.

Geometry: create a 1.0 m x 0.5 m rectangular plate.
Subtract a circular hole of radius 0.1 m centered at (0.5, 0.25) from the rectangle.
Generate the mesh using mshr with a resolution of 64 elements per edge (mshr resolution parameter = 64).
The domain is treated as 2D plane stress with unit thickness (t = 1.0 m).

Material properties: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3, gravity g = 9.81 m/s^2.
Use the reduced plane-stress constitutive law.
Compute the plane-stress stiffness tensor components from E and nu directly.
The plane-stress constitutive relation gives sigma = C : epsilon where C is the 2D plane-stress elasticity tensor.

Define the strain tensor as epsilon(u) = 0.5 * (grad(u) + grad(u).T).
Define the plane-stress Cauchy stress tensor sigma(u) using the plane-stress reduced form: sigma_xx = E/(1-nu^2) * (eps_xx + nu*eps_yy), sigma_yy = E/(1-nu^2) * (eps_yy + nu*eps_xx), sigma_xy = E/(1+nu) * eps_xy.

Use a vector-valued continuous Lagrange finite element space of degree 2 (P2) for the displacement field u.

Boundary conditions:
Impose u_x = 0 (roller) on the left edge (x = 0).
Impose u_x = 0 (roller) on the right edge (x = 1.0).
Do NOT impose any constraint on u_y on the left or right edges.
Do NOT impose any Dirichlet condition on the top or bottom edges.
Do NOT impose any traction or load on the hole boundary (traction-free).

Loading:
Apply a uniform vertical compression as a Neumann traction t = (0, -2500) Pa on the top edge (y = 0.5).
Apply a uniform vertical compression as a Neumann traction t = (0, +2500) Pa on the bottom edge (y = 0.0) so that both surfaces are compressed inward (i.e., the bottom traction points upward and the top traction points downward, both compressive).
Include body force due to gravity: f = (0, -rho * g) N/m^3 as a volumetric body force in the weak form.

Weak form: find u in V such that for all v in V: integral(sigma(u):epsilon(v) dx) = integral(f . v dx) + integral(t_top . v ds on top) + integral(t_bottom . v ds on bottom).

Mark boundaries using a MeshFunction on facets: left (x near 0), right (x near 1.0), top (y near 0.5), bottom (y near 0.0), using a tolerance of 1e-10.
Apply Dirichlet BCs for u_x = 0 on left and right using the sub-space for the x-component.

After solving, compute the von Mises stress from the in-plane Cauchy stress components as: sigma_vm = sqrt(sigma_xx^2 - sigma_xx*sigma_yy + sigma_yy^2 + 3*sigma_xy^2).
Project the von Mises stress onto a scalar DG0 or CG1 function space for output.
Project the displacement magnitude onto a scalar function space for output.

Save the displacement field u to a file named displacement.pvd.
Save the von Mises stress field to a file named von_mises.pvd.
Print the maximum displacement magnitude (scalar) to the console.
Print the maximum von Mises stress value to the console.
