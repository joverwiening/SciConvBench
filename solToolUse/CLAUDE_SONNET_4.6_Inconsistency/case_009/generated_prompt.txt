Final Specification:

Use FEniCS legacy (dolfin) for all implementation.

Geometry:
Define the domain Omega as the rectangle (0, 1.0) x (0, 0.20) minus the rectangular notch region (0, 0.06) x (0.08, 0.12).
The notch is cut from the left edge, so the notch occupies x in [0, 0.06], y in [0.08, 0.12].
Use mshr (dolfin's mshr module) to construct the geometry as a Rectangle minus a Rectangle.
Use a mesh resolution of 64 or higher to adequately resolve the notch stress concentration.

Material:
Young's modulus E = 200e9 Pa.
Poisson's ratio nu = 0.30.
Use the plane-stress reduced constitutive law.
Compute the plane-stress Lame-like parameters as: lambda_ps = E*nu/(1 - nu**2), mu = E/(2*(1 + nu)).
The plane-stress stress tensor is sigma(u) = lambda_ps * tr(eps(u)) * I + 2*mu*eps(u), where eps(u) = sym(grad(u)) and I is the 2x2 identity, and tr is the 2D trace.

Finite Element Space:
Use a vector-valued continuous Lagrange finite element space of degree 2 (P2) for the displacement u = (u_x, u_y).

Boundary Conditions:
Identify the left outer boundary as the portion of x = 0 that is NOT part of the notch, i.e., x = 0 with y in [0, 0.08) union (0.12, 0.20].
Identify the two notch faces as: the vertical notch face at x = 0.06 for y in [0.08, 0.12], the horizontal notch face at y = 0.08 for x in [0, 0.06], and the horizontal notch face at y = 0.12 for x in [0, 0.06].
Apply homogeneous Dirichlet boundary conditions u_x = 0 and u_y = 0 on the left outer boundary (x = 0, excluding the notch opening) AND on all three notch faces (x = 0.06 strip, y = 0.08 strip, y = 0.12 strip within the notch region).
Use a tolerance of 1e-10 for all boundary identification.

Loading:
Apply a Neumann traction t = (2e6, 0) N/m on the right edge x = 1.0 as a line traction per unit thickness.
Implement this as a surface integral term in the weak form: inner(T, v) * ds(right_boundary).
Top edge (y = 0.20), bottom edge (y = 0), and all notch boundary faces not clamped are traction-free (natural boundary condition, no additional term needed).

Variational Formulation:
Define the bilinear form a(u, v) = integral over Omega of inner(sigma(u), eps(v)) dx.
Define the linear form L(v) = integral over right edge of inner(T, v) ds, where T = (2e6, 0).
Solve the linear system a(u, v) = L(v) for all test functions v using a direct linear solver (LU).

Post-processing:
Compute the von Mises stress field in plane stress as: sigma_vm = sqrt(s11^2 - s11*s22 + s22^2 + 3*s12^2), where s11, s22, s12 are the components of the Cauchy stress tensor evaluated from the solution u.
Project the von Mises stress onto a scalar DG0 or CG1 function space for visualization.
Save the von Mises stress plot as q5_vm.png using matplotlib, with a colorbar labeled "von Mises stress (Pa)", title "Von Mises Stress - Notched Plate", and the geometry aspect ratio preserved.
Save the displacement field u to an XDMF file named q5_displacement.xdmf using dolfin's XDMFFile with write mode.

Output files:
q5_vm.png: von Mises stress field plot.
q5_displacement.xdmf: displacement field in XDMF format.
