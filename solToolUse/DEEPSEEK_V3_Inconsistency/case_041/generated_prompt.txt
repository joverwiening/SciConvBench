Use FEniCS legacy (dolfin) to solve a finite-strain Saint-Venant-Kirchhoff elasticity problem in plane strain.
The geometry is a rectangular strip with dimensions (0, 1.20) m in x and (0, 0.20) m in y.
Create three circular holes of radius 0.03 m, each centered at y = 0.10 m and at x = 0.30 m, 0.60 m, and 0.90 m.
The material is defined by Lamé parameters lambda = 5.769e6 Pa and mu = 3.846e6 Pa.
The unknown is the displacement vector u = (u_x, u_y).
Define the deformation gradient as F = I + grad(u).
Define the Green-Lagrange strain tensor as E_GL = 0.5*(F.T*F - I).
Define the second Piola-Kirchhoff stress as S = lambda*tr(E_GL)*I + 2*mu*E_GL.
Define J = det(F).
Define the Cauchy stress as sigma = (1/J) * F * S * F.T.
For the constitutive update, use the infinitesimal strain tensor epsilon = sym(grad(u)) inside the Saint-Venant-Kirchhoff law.
Apply a fixed boundary condition (u_x = 0, u_y = 0) on the left edge (x = 0).
Apply a prescribed displacement (u_x = 0.012 m, u_y = 0) on the right edge (x = 1.20).
Apply traction-free conditions on the top, bottom, and all hole boundaries.
Use load stepping with Newton iterations to apply the prescribed displacement incrementally.
During the simulation, compute the maximum principal Green-Lagrange strain E_max.
During the simulation, compute the von Mises Cauchy stress.
Stop advancing the load step if the computed E_max exceeds 0.03.
Also, stop advancing the load step if the computed von Mises Cauchy stress exceeds 0.03 MPa.
