Solve a 2D plane-stress linear elasticity problem on a two-material bonded strip.
Use FEniCS legacy (dolfin).
Define the domain as a rectangle with dimensions 1.0 m in x and 0.20 m in y.
Define the top subdomain (y from 0.10 to 0.20) as material 'Steel'.
Define the bottom subdomain (y from 0.00 to 0.10) as material 'Aluminium'.
Assign a Young's modulus of 200 GPa and Poisson's ratio of 0.30 to the 'Steel' subdomain.
Assign a Young's modulus of 70 GPa and Poisson's ratio of 0.30 to the 'Aluminium' subdomain.
Create a structured mesh of 80 by 16 quadrilateral elements over the entire domain.
Use a conforming displacement vector function space of continuous piecewise linear Lagrange elements.
Use a discontinuous Galerkin zero (DG0) function space to define a material indicator field.
Mark cells in the top half of the mesh with a value of 1 for 'Steel'.
Mark cells in the bottom half of the mesh with a value of 0 for 'Aluminium'.
Define the plane-stress constitutive law using the material indicator to select the correct Young's modulus and Poisson's ratio for each cell.
Apply a fixed (zero displacement) boundary condition on the left edge (x = 0).
Apply a uniform downward line traction of -5000 N/m on the right edge (x = 1.0).
Leave the top and bottom edges traction-free.
Enforce perfect bonding at the material interface through the conforming mesh and shared degrees of freedom.
Solve the variational problem using a direct linear solver ('lu').
Save a color map of the displacement magnitude as 'q7_disp.png'.
Save the computed displacement field in XDMF format with the filename 'displacement.xdmf'.
