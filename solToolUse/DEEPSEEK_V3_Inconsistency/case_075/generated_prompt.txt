Create a file named pendel.inp in the working directory with the provided input deck content.
Run the CalculiX solver using the command ccx -i pendel.
Check the file pendel.sta for the string 'JOB COMPLETED' to determine if the run succeeded.
Run ccx -v to obtain the solver version string.
Create a file named results.json in the working directory.
The results.json file must contain a JSON object with the key "solver" and value "calculix".
The results.json file must contain a key "case_id" with value "pendel".
The results.json file must contain a key "status" with value "success" if the job completed, otherwise "error".
The results.json file must contain a key "ccx_version" with the version string from ccx -v.
The results.json file must contain a key "artifacts" with an empty array.
The results.json file must contain a key "notes".
In the "notes" field, record the exact ccx command that was used.
If the run failed, include the error message and the file that indicated the failure in the "notes" field.
The simulation uses a gravitational body force as the dominant distributed load.
The total simulation time is 1.0 seconds.
The dynamic step uses 1000000 time increments.
