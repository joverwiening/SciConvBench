Create a file named zerovel.inp in the working directory with the provided content.
Run CalculiX using the command ccx -i zerovel.
Check the file zerovel.sta for the string 'JOB COMPLETED' to determine if the run succeeded.
Create a results.json file in the working directory.
The results.json file must contain the key "solver" with the value "calculix".
The results.json file must contain the key "case_id" with the value "zerovel".
The results.json file must contain the key "status" with a value of either "success" or "error".
The results.json file must contain the key "ccx_version" with the version string from ccx -v.
The results.json file must contain the key "artifacts" with an empty list as its value.
The results.json file must contain the key "notes" with a string describing the exact ccx command used and any error messages if the run failed.
The input deck must define two nodes at coordinates (0,0,0) and (0.1,0,0).
The input deck must connect the nodes with a B31 beam element.
The input deck must define a material with an elastic modulus of 10,000,000,000 and a density of 1000.
The input deck must define a rectangular beam cross-section with dimensions 0.01 by 0.01.
The input deck must define the beam section orientation using a vector pointing in the negative y-direction.
The input deck must define a dynamic step from time 0.01 to 0.1 seconds.
The input deck must apply a concentrated load of 0.01 units in the x-direction at node 1.
The input deck must request output of nodal displacements (U and V) in a 2D global format every 10 time steps.
