The geometry is an L-shaped domain defined by a 1x1 outer square with a 0.5x0.5 inner square removed from its top-right corner.

Use a vector-valued displacement function space.

Apply a traction boundary condition on the outer right edge (x=1, 0 ≤ y ≤ 1).
The traction is defined as σ_yy = -2.65e4 * y, where 'y' is the global y-coordinate.
All other boundaries, including the re-entrant inner boundaries, are traction-free.
Use the reduced plane-stress constitutive law with unit thickness.
Assemble and solve the linear system using a direct linear solver.
Compute the displacement field solution.
Compute the in-plane Cauchy stress field from the displacement solution.
