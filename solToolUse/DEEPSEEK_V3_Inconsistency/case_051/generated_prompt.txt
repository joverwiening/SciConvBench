Create a file named axial.inp in the working directory with the provided input deck content.
Run CalculiX using the command ccx -i axial.
Check the file axial.sta for the string 'JOB COMPLETED' to determine if the run succeeded.
Create a file named results.json in the working directory.
The results.json file must contain the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
Set the "solver" value to "calculix".
Set the "case_id" value to "axial".
Set the "status" value to "success" if the run succeeded, otherwise set it to "error".
Set the "ccx_version" value to the output string from the command ccx -v.
Set the "artifacts" value to an empty list.
Set the "notes" value to a string containing the exact ccx command used.
If the run failed, append the error message and the name of the file that indicated the failure to the "notes" value.
Do not add a gravity body force to the input deck.
Use the input deck exactly as provided by the user.
