Create a file named beammix.inp in the working directory with the CalculiX input deck.
The input deck must define a beam model fixed at both ends.
The model must use nodes at coordinates: (0,0,0), (1,0,0), (0.5,0,0), (2,0,0), and (1.5,0,0).
The model must use two B32 beam elements.
Element 1 connects nodes 1, 3, and 2.
Element 2 connects nodes 2, 5, and 4.
Apply boundary conditions to fix all degrees of freedom (1-6) at node 1.
Apply boundary conditions to fix all degrees of freedom (1-6) at node 4.
Define a material named EL with an elastic modulus of 210000 and Poisson's ratio of 0.3.
Assign element 1 to element set SET1.
Assign element 2 to element set SET2.
Define a beam section for element set SET1 using the RECT type.
Use a width of 0.05 and a height of 0.08 for the rectangular section.
Define a local beam orientation for SET1 using the vector (0,1,0).
Define a beam section for element set SET2 using the RECT type.
Use a width of 0.05 and a height of 0.08 for the rectangular section.
Define a local beam orientation for SET2 using the vector (0,0.7071,0.7071).
Apply a static load of magnitude 0.0025 in direction 3 (global Y) on node 2.
Run a nonlinear geometric static step.
Request nodal displacement output for all nodes.
Request element stress output for all elements.
Run CalculiX using the command `ccx -i beammix`.
Check the file beammix.sta for the string 'JOB COMPLETED' to determine success.
Run `ccx -v` and capture the version string.
Create a results.json file in the working directory.
Populate the results.json with the solver name 'calculix'.
Populate the results.json with the case_id 'beammix'.
Set the status in results.json to 'success' if the run succeeded, otherwise 'error'.
Record the ccx version string in the ccx_version field of results.json.
Record the exact ccx command used in the notes field of results.json.
If the run failed, include the error message and the file that indicated the failure in the notes field.
Leave the artifacts array empty in the results.json file.
