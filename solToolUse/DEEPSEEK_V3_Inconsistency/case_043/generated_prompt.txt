Use the FEniCS legacy (dolfin) library.
Define a 2D rectangular domain with dimensions (0, 1.0) meters in x and (0, 0.20) meters in y.
Subtract a circular hole of radius 0.04 meters centered at (0.50, 0.10) from the rectangle to create the final geometry.
Mesh the domain with a suitable resolution.
Define a small-strain linear elasticity problem under plane strain conditions.
Use a displacement-only vector finite element formulation.
Set the Young's modulus to 5e6 Pa and the Poisson's ratio to 0.49.
Apply a Dirichlet boundary condition on the left edge (x=0) to fix both displacement components to zero.
Apply a Dirichlet boundary condition on the right edge (x=1.0) to prescribe u_x = 0.001 meters and u_y = 0.
Apply a traction-free (natural) boundary condition on the top, bottom, and hole boundaries.
Solve the linear variational problem for the displacement field.
Compute the von Mises stress field from the solution.
Create and save a color map plot of the von Mises stress field as 'q11_vm.png'.
Create and save a color map plot of the x-component of displacement (u_x) as 'q11_ux.png'.
Save the computed displacement field to an XDMF file.
