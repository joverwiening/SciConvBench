Populate the `results.json` file with a JSON object.

The JSON object must have a key "case_id" with the value "case_091".
The JSON object must have a key "status" with the value "success" or "error".
The JSON object must have a key "ccx_version" with the version string from `ccx -v`.
The JSON object must have a key "artifacts" with an empty array as its value.
The JSON object must have a key "notes" with a string value.
The "notes" string must contain the exact ccx command that was used.
If the run failed, the "notes" string must also contain the error message and the file that indicated the failure.
