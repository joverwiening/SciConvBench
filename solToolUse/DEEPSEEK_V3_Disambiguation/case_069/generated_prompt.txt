Run the CalculiX solver using the command `ccx -i case_069`.
Check the file `case_069.sta` for the phrase 'JOB COMPLETED' to determine success.
Run the command `ccx -v` to get the version string.
Create a file named `results.json` in the working directory.
Write a JSON object into `results.json` with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
Set the "solver" value to "calculix".
Set the "case_id" value to "case_069".
Set the "status" value to "success" if the run succeeded, otherwise set it to "error".
Set the "ccx_version" value to the output from `ccx -v`.
Set the "artifacts" value to an empty list.
Set the "notes" value to a string containing the exact ccx command used and, if the run failed, the error message and the file that indicated the failure.
