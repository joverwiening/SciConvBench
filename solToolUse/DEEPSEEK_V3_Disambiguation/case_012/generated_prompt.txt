Use FEniCS legacy (dolfin) to solve an incompressible finite-strain hyperelasticity problem.
The geometry is a rectangular strip (0, 1.0) x (0, 0.20) meters with a circular hole of radius 0.04 m centered at (0.50, 0.10).
Model a large-deformation isotropic incompressible neo-Hookean solid in plane strain.
The material has Young's modulus E = 5 MPa and Poisson's ratio ν = 0.5.
Use a mixed displacement-pressure formulation with unknowns u and p.
Use the strain energy for a standard incompressible neo-Hookean material.
Enforce incompressibility via J = 1 with the pressure field p.
Define the deformation gradient as F = I + grad(u).
Apply boundary conditions: left edge (x=0) fixed with u_x = 0 and u_y = 0.
Apply boundary conditions: right edge (x=1.0) has a prescribed horizontal displacement u_x = 0.060 m and u_y = 0.
Apply boundary conditions: top, bottom, and hole boundaries are traction-free.
Solve the nonlinear system using Newton's method.
Use a maximum of 50 Newton iterations.
Use an absolute tolerance for the Newton solver residual norm of 1.0e-10.
Use a relative tolerance for the Newton solver residual norm of 1.0e-8.
Generate a mesh with a global element size of 0.01 meters.
Use a Taylor-Hood (P2-P1) finite element pair: P2 for displacement and P1 for pressure.
For the Newton step linear systems, use the default direct solver (MUMPS) with default preconditioner.
