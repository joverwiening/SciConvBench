Create a file named case_125.inp in the working directory with the provided input deck content.
Run the CalculiX solver using the command ccx -i case_125.
Check the file case_125.sta for the phrase 'JOB COMPLETED' to determine if the run succeeded.
Execute ccx -v to obtain the version string for the ccx_version field.
Write a results.json file in the working directory.
The results.json file must contain the key "solver" with the value "calculix".
The results.json file must contain the key "case_id" with the value "case_125".
The results.json file must contain the key "status" with the value "success" or "error".
The results.json file must contain the key "ccx_version" with the version string from ccx -v.
The results.json file must contain the key "artifacts" with an empty list as its value.
The results.json file must contain the key "notes".
The notes field must contain the exact ccx command used.
If the run failed, the notes field must also contain the error message and the name of the file that indicated the failure.
