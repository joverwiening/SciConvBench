Create a file named case_118.inp in the working directory with the exact content provided in the Input Deck section.
Run the CalculiX solver on the input deck using the command ccx -i case_118.
Check the file case_118.sta for the string 'JOB COMPLETED' to determine if the run succeeded.
Run ccx -v to obtain the CalculiX version string.
Write a file named results.json in the working directory.
The results.json file must contain a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
Set the "solver" value to "calculix".
Set the "case_id" value to "case_118".
Set the "status" value to "success" if the run succeeded, otherwise set it to "error".
Set the "ccx_version" value to the version string obtained from ccx -v.
Set the "artifacts" value to an empty list.
Set the "notes" value to a string containing the exact ccx command used and, if the run failed, the error message and the file that indicated the failure.
