Use FEniCS legacy (dolfin) to solve a small-strain orthotropic elasticity problem.
Define the domain Ω as a 2D rectangular plate with coordinates (0, 1.0) m in x and (0, 0.20) m in y.
Generate a structured mesh of 50 x 25 elements over Ω.
Model the problem as 2D plane-stress elasticity for displacement vector u = (u_x, u_y).
Use orthotropic material properties: E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
Construct the standard plane-stress reduced stiffness matrix [Q] in the local material coordinate system.
Rotate the stiffness tensor to the global x-y frame using a 30-degree anticlockwise rotation angle.
Apply a fixed boundary condition on the bottom edge (y = 0): u_x = 0 and u_y = 0.
Apply a uniform downward traction of t = (0, -10 MPa*m) on the top edge (y = 0.20), interpreted as a line load per unit thickness.
Leave the vertical sides (x = 0 and x = 1.0) traction-free.
Solve the variational problem using a direct linear solver.
Save a colour map of the displacement component u_x to a file named q8_ux.png.
Save a colour map of the von Mises stress to a file named q8_vm.png.
Write the computed displacement (u) and stress fields to an XDMF file named q8_solution.xdmf.
