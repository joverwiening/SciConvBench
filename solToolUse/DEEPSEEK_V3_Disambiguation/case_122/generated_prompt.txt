Create a file named case_122.inp in the current working directory with the provided input deck content.
Run the CalculiX solver using the command ccx case_122.
Check the file case_122.sta for the string 'JOB COMPLETED' to determine success.
Run the command ccx -v to obtain the CalculiX version string.
Create a file named results.json in the current working directory.
The results.json file must contain a JSON object with the keys "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
Set the "solver" value to "calculix".
Set the "case_id" value to "case_122".
Set the "status" value to "success" if the run succeeded, otherwise set it to "error".
Set the "ccx_version" value to the output string from the ccx -v command.
Set the "artifacts" value to an empty list.
Set the "notes" value to a string containing the exact ccx command used and, if the run failed, the error message and the file that indicated the failure.
