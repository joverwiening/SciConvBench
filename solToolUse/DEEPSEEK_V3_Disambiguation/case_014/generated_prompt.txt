Use FEniCS legacy (dolfin) with the dolfin module.
Solve the nonlinear finite-strain elasticity problem for a Saint-Venant-Kirchhoff material.
Use a UnitCube mesh with 8 subdivisions in each direction (8x8x8 cells).
Define the Lamé parameters with λ = 1.0 and μ = 1.0.
Define the exact displacement solution as u_ex = 0.1 * [sin(pi*x)*sin(pi*y)*sin(pi*z), sin(pi*x)*sin(pi*y)*sin(pi*z), sin(pi*x)*sin(pi*y)*sin(pi*z)].
Compute the body force f0 analytically as -∇·σ, where σ is the Saint-Venant-Kirchhoff stress derived from the exact displacement u_ex.
Apply Dirichlet boundary conditions setting u = u_ex on the entire boundary of the unit cube.
Use a zero vector field as the initial guess for the Newton solver.
Use Newton's method to solve the nonlinear variational problem.
Set the Newton solver's absolute tolerance for the residual to 1.0e-10.
Set the maximum number of Newton iterations to 50.
Compute the L2 error norm between the numerical solution and the exact displacement solution u_ex.
Print the computed L2 error to the console.
