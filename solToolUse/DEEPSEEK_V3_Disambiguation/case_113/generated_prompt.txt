Create a file named case_113.inp in the working directory with the exact content provided in the Input deck section.
Run the CalculiX solver using the command ccx -i case_113.
Check the file case_113.sta for the phrase 'JOB COMPLETED' to determine if the run succeeded.
Run the command ccx -v to obtain the version string.
Create a file named results.json in the working directory.
Populate the results.json file with the solver name "calculix".
Populate the results.json file with the case_id "case_113".
Set the status field in results.json to "success" if the run succeeded, otherwise set it to "error".
Set the ccx_version field in results.json to the version string from ccx -v.
Set the artifacts field in results.json to an empty list.
Set the notes field in results.json to the exact ccx command used and, if the run failed, the error message and the file that indicated the failure.
