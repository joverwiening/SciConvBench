Q: What is the exact constitutive law you want to use for plane stress? Please provide the stress-strain relation (e.g., the specific form of the reduced stiffness matrix C for each material).
A: Use the standard linear isotropic plane-stress constitutive law:  
σ = C ε, with  
C = E/(1−ν²) * [ [1, ν, 0], [ν, 1, 0], [0, 0, (1−ν)/2] ]  
for each material (E, ν given in the complete requirement).
