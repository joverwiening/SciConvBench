Create a file named case_055.inp in the working directory with the provided input deck content.
Run the CalculiX solver using the command ccx -i case_055.
Check the file case_055.sta for the phrase 'JOB COMPLETED' to determine if the run succeeded.
Execute the command ccx -v to obtain the version string.
Write a JSON file named results.json in the working directory.
The JSON file must contain the key "solver" with the value "calculix".
The JSON file must contain the key "case_id" with the value "case_055".
The JSON file must contain the key "status" with a value of either "success" or "error".
The JSON file must contain the key "ccx_version" with the version string from ccx -v.
The JSON file must contain the key "artifacts" with an empty list as its value.
The JSON file must contain the key "notes" with a string describing the exact ccx command used.
If the run failed, the "notes" must also include the error message and the file that indicated the failure.
