Use FEniCS legacy (dolfin).
Solve the static finite-strain Saint-Venant-Kirchhoff hyperelasticity problem.
Use a UnitCube mesh with 8 subdivisions along each axis, resulting in 8x8x8 hexahedral cells.
Define the material as a Saint-Venant-Kirchhoff model.
Set the shear modulus μ to a constant value of 3.8461 N/m².
Set the first Lamé parameter λ to vary spatially according to the function λ = 5.8*x1 + 5.7*(1 - x1).
Assume a Poisson's ratio ν of 0.3 for the material.
Calculate the corresponding Young's modulus E from the given μ and assumed ν using the relation E = 2μ(1+ν).
Apply a Dirichlet boundary condition fixing all degrees of freedom on the face where x1 = 0.
Apply a Dirichlet boundary condition on the face where x1 = 1, prescribing a rotation of 60 degrees about the x1-axis.
Use Newton's method to solve the resulting nonlinear system for static equilibrium.
