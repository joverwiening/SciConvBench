Use FEniCS legacy (dolfin).
Solve a 3D nonlinear hyperelasticity problem using Newton's method.
Use a compressible neo-Hookean material model.
The geometry is a unit cube meshed with UnitCubeMesh(24, 16, 16).
Use a VectorFunctionSpace with Lagrange elements of degree 1.
Set the Young's modulus E to 10.0.
Set the Poisson ratio ν to 0.3.
Define the deformation gradient as F = I + grad(u).
Define the right Cauchy-Green tensor as C = F^T F.
Define the volume change as J = det(F).
Clamp the face at x = 0 with a zero Dirichlet boundary condition.
On the face at x = 1, impose a prescribed rotational displacement.
The rotation is 60 degrees about the face center (0.5, 0.5).
The displacement is scaled by a factor of 0.5.
The exact expression is u(1, y, z) = 0.5 * R(60°) * [(y, z) - (0.5, 0.5)] - [(y, z) - (0.5, 0.5)].
Apply a body force B = (0, -0.5, 0).
Apply a boundary traction T = (0.1, 0, 0) on the natural boundary.
Assume the natural boundary for the traction is the face at y = 0.
Solve the nonlinear displacement problem by minimizing the total potential energy.
