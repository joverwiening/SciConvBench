Create a file named case_135.inp in the working directory with the provided input deck content.
Run the CalculiX solver on the input deck using the command ccx case_135.
Check the file case_135.sta for the string 'JOB COMPLETED' to determine if the run succeeded.
Execute the command ccx -v to obtain the solver version string.
Write a JSON file named results.json in the working directory.
The JSON file must have a top-level object.
The JSON object must contain a key named "solver" with the string value "calculix".
The JSON object must contain a key named "case_id" with the string value "case_135".
The JSON object must contain a key named "status" with a string value of either "success" or "error".
The JSON object must contain a key named "ccx_version" with a string value from the ccx -v command output.
The JSON object must contain a key named "artifacts" with an empty array as its value.
The JSON object must contain a key named "notes" with a string value.
The notes string must record the exact ccx command used.
If the run failed, the notes string must include the error message and the file that indicated the failure.
