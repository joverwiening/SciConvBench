Create a 2D plane-stress linear elasticity simulation using FEniCS legacy (dolfin).
Define the rectangular domain Ω = (0, 1.0) x (0, 0.20) meters.
Generate a uniform structured mesh with 20 x 4 subdivisions across (x, y) directions.
Use a vector-valued displacement function space for u = (u_x, u_y).
Set material properties: Young's modulus E = 200 GPa and Poisson's ratio ν = 0.30.
Calculate Lamé parameter lambda = E*nu/((1+nu)*(1-2*nu)) for the 2D constitutive law.
Apply fixed boundary conditions on the left edge (x = 0): u_x = 0 and u_y = 0.
Apply prescribed displacement on the right edge (x = 1): u_x = 0.001 m and u_y = 0.
Set traction-free boundary conditions on top edge (y = 0.20) and bottom edge (y = 0).
Formulate the plane-stress variational problem using the standard isotropic constitutive relation.
Solve the linear system using a direct linear solver.
