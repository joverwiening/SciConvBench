Create the file `membrane3.inp` in the working directory with the exact content provided in the reference text.  
Run CalculiX using the command `ccx membrane3`.  
Check the file `membrane3.sta` for the presence of a successful termination message such as 'JOB COMPLETED'.  
Extract the CalculiX version string by running `ccx -v` or the closest equivalent available.  
Write a file named `results.json` in the working directory with the following structure:  
{
  "solver": "calculix",
  "case_id": "membrane3",
  "status": "success" if the simulation completed successfully, otherwise "error",
  "ccx_version": the version string obtained from `ccx -v`,
  "artifacts": [],
  "notes": "Command used: ccx membrane3. If failed, include error message and the file that indicated failure."
}
