Create the file c3d6.inp in the working directory with the provided input deck.
Use C3D20R elements for the discretization instead of C3D6.
Change the primary nodal load to act in the global z-direction instead of the x-direction.
Run CalculiX using the command `ccx c3d6`.
Check the file c3d6.sta for successful termination, specifically looking for 'JOB COMPLETED'.
Record the CalculiX version string obtained from running `ccx -v`.
Create a results.json file with the solver set to "calculix".
Set the case_id in results.json to "c3d6".
Set the status in results.json to "success" if the run completed, otherwise set it to "error".
Include the version string from `ccx -v` in the ccx_version field of results.json.
Leave the artifacts array in results.json empty.
In the notes field of results.json, record the exact command used (`ccx c3d6`).
If the run failed, include the error message and the name of the file that indicated the failure in the notes field.
