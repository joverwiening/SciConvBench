Create the file `achtelc.inp` in the working directory with the provided input deck.
Run CalculiX using the command `ccx achtelc`.
Check the file `achtelc.sta` for a successful termination message such as 'JOB COMPLETED'.
If the run succeeded, set the status in `results.json` to "success"; otherwise, set it to "error".
Obtain the CalculiX version string by running `ccx -v` or the closest equivalent.
Write a file named `results.json` in the working directory with the following schema:
{
  "solver": "calculix",
  "case_id": "achtelc",
  "status": "success" or "error",
  "ccx_version": "<version_string>",
  "artifacts": [],
  "notes": "<exact_ccx_command_used>. If the run failed, include the error message and the file that indicated the failure."
}
Do not retry or modify any parameters if the simulation fails.
