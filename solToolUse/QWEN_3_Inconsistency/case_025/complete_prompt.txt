Case ID: case_025
Use FEniCS legacy (dolfin).
Solver: small-strain linear elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with a vector-valued displacement space and a direct linear solver.
Task:
Analyze stress in a complex polygonal domain with fixed bottom edge and vertical traction on partial top edge under gravity. Implement plane stress elasticity with E=70e9 Pa, ν=0.33. Compute displacement magnitude and von Mises stress distributions.
Case details:
Material: E=70e9, ν=0.33, ρ=2700 kg/m^3, g=9.81 m/s^2. Geometry: Stepped polygon (8 vertices). Loads: σ_yy=-10 kPa (top segment 0.3≤x≤0.5), gravity (-y). Boundaries: y=0 fixed. Mesh: 72 elements.
Implementation notes:
Treat the 2D domain as plane stress with unit thickness and use the reduced plane-stress constitutive law.
Compute von Mises from the in-plane Cauchy stress field.
Apply the vertical traction only on the partial top segment 0.3 <= x <= 0.5.
