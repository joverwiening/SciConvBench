Create the file beamtor.inp in the working directory with the specified input deck using B32 elements.  
Run CalculiX using the command ccx -i beamtor or ccx beamtor, whichever works on the system.  
Check the beamtor.sta file for a successful termination message such as 'JOB COMPLETED'.  
Record the CalculiX version string from ccx -v in the results.json file under ccx_version.  
Write a results.json file with the solver set to calculix, case_id set to beamtor, and status set to success if the run completed, otherwise error.  
Include the exact ccx command used in the notes field of results.json.  
If the run failed, include the error message and the file that indicated the failure in the notes field.  
Leave the artifacts array empty in results.json.
