Use FEniCS legacy (dolfin) to solve the incompressible finite-strain hyperelasticity problem using the mixed displacement-pressure formulation.  
Model the domain Ω = (0, 1.0) × (0, 0.20) m as a rectangular strip with a circular hole of radius 0.04 m centered at (0.50, 0.10).  
Apply plane strain conditions.  
Use an isotropic incompressible neo-Hookean material model with Young's modulus E = 5 MPa and Poisson's ratio ν = 0.5.  
Set the unknown fields as displacement u = (u_x, u_y) and hydrostatic pressure p.  
Fix the left edge (x = 0) with u_x = 0 and u_y = 0.  
Apply a uniform follower pressure P_hole = 0.10 MPa on the hole boundary as traction σ·n = -P_hole·n in the deformed configuration.  
Treat the hole pressure as a dead load using the reference normal vector from the undeformed hole boundary.  
Set the right, top, and bottom edges as traction-free.  
Solve using Newton's method.  
Compute the von Mises stress field from the Cauchy stress tensor.
