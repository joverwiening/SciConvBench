Use FEniCS legacy (dolfin) to solve the 2D plane-stress small-strain orthotropic elasticity problem.  
Define the domain Ω as a rectangle (0, 1.0) × (0, 0.20) m.  
Generate a structured mesh with 50 × 25 quadrilateral elements over Ω.  
Use continuous Galerkin finite elements of degree 1 for displacement u = (u_x, u_y).  
Set material properties: E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, nu12 = 0.25.  
Compute the plane-stress reduced stiffness matrix [Q] in the local material (1-2) frame.  
Rotate the stiffness matrix [Q] by -30 degrees to transform from the local 1-2 frame to the global x-y frame.  
Apply boundary condition: at y = 0, set u_x = 0 and u_y = 0 (fully fixed).  
Apply boundary condition: at y = 0.20, apply a uniform downward traction t = (0, -10) MPa (per unit thickness).  
Set traction-free conditions on vertical edges x = 0 and x = 1.  
Use a direct linear solver (e.g., LU decomposition) to solve the linear variational problem.  
Compute the displacement field u and the Cauchy stress tensor field in the global frame.  
Compute the von Mises stress from the Cauchy stress tensor.  
Save the u_x component as a color map in the file q8_ux.png.  
Save the von Mises stress as a color map in the file q8_vm.png.  
Write the displacement u and stress fields to q8_solution.xdmf using XDMF format.
