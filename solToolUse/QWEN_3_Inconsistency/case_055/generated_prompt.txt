Create the file `uprofile.inp` in the working directory with the provided input deck.
Run CalculiX using the command `ccx -i uprofile` or `ccx uprofile`, whichever is supported by the system.
Check the file `uprofile.sta` for the message 'JOB COMPLETED' to determine if the simulation succeeded.
Retrieve the CalculiX version string by executing `ccx -v` or the equivalent command.
Write a file named `results.json` in the working directory with the following structure:
{
  "solver": "calculix",
  "case_id": "uprofile",
  "status": "success" if the run completed successfully, otherwise "error",
  "ccx_version": the version string obtained from `ccx -v`,
  "artifacts": [],
  "notes": "Command used: [actual command]. If failed: [error message from relevant output file, e.g., uprofile.dat or uprofile.sta]."
}
