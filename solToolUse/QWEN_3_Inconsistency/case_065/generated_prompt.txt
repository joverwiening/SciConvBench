Create the file `cubenewt.inp` in the working directory with the provided input deck content.
Run the CalculiX simulation using the command `ccx -i cubenewt` or `ccx cubenewt`, whichever is compatible with the system.
Check the `cubenewt.sta` file for the presence of the exact phrase "JOB COMPLETED" to determine success.
If "JOB COMPLETED" is found, set the status in `results.json` to "success"; otherwise, set it to "error".
Obtain the CalculiX version string by running `ccx -v` or the closest equivalent command.
Create a `results.json` file in the working directory with the following structure:
{
  "solver": "calculix",
  "case_id": "cubenewt",
  "status": "success" or "error",
  "ccx_version": "<version_string>",
  "artifacts": [],
  "notes": "<exact_ccx_command_used>; <error_message_if_any> from <failed_file_if_any>"
}
In the `notes` field, include the exact command used to run CalculiX, and if the run failed, append the error message and the file that indicated the failure.
