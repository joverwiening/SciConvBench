Use legacy FEniCS (dolfin) 2019.1.0 with Python 3.8.
Solve 2D small-strain linear elasticity in plane stress on a rectangular plate with a semicircular notch removed from the top edge.
Define the domain as Ω = (0, 1.0) × (0, 0.20) m minus the semicircle of radius a = 0.05 m centered at (0.5, 0.20) whose arc lies inside the rectangle (a top-edge notch).
Generate the mesh using mshr with a global target resolution chosen by best practice and apply local refinement near the notch arc to capture the stress concentration.
Use a vector-valued continuous Galerkin displacement space of at least first order (CG1) on triangles.
Assume unit thickness and interpret the applied traction as a line traction per unit thickness.
Use isotropic linear elastic material properties E = 200e9 Pa and ν = 0.30.
Use the reduced plane-stress constitutive law: λ_ps = E*ν/(1-ν^2) and μ = E/(2*(1+ν)).
Define strain ε(u) = sym(grad(u)).
Define stress σ(u) = 2μ ε(u) + λ_ps tr(ε(u)) I.
Impose Dirichlet boundary conditions u_x = 0 and u_y = 0 on the bottom edge y = 0.
Apply a downward traction t = (0, -10e6) in N/m on the top edge segments outside the notch opening: y = 0.20 with x ∈ [0, 0.45) ∪ (0.55, 1.0].
Apply traction-free (natural) boundary conditions on both vertical sides x = 0 and x = 1 and on the notch arc.
Formulate the variational problem: find u such that ∫_Ω σ(u):ε(v) dx = ∫_{Γ_t} t·v ds for all test functions v satisfying the essential boundary conditions.
Solve the resulting linear system using a direct linear solver available in dolfin (e.g., LU via PETSc).
Compute the plane-stress von Mises equivalent stress field from σ(u) using the 2D formula σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2).
Project or interpolate the von Mises field to a scalar CG space suitable for visualization.
Save an autoscaled von Mises plot to q6_vm.png.
Save the displacement solution field to XDMF with filename q6_u.xdmf (and associated HDF5 data) using a time value of 0.0.
Ensure boundary marking distinguishes the two loaded top segments from the notch arc and other boundaries so the traction is applied only where specified.
Use SI units consistently throughout (meters, Pascals, Newtons).
