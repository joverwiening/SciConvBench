Define the domain as the counterclockwise polygon with vertices (0.0, 0.0), (1.0, 0.0), (1.0, 0.6), (0.5, 0.6), (0.5, 1.0), (0.3, 1.0), (0.3, 0.6), (0.0, 0.6).
Generate a conforming triangular mesh of the polygon with approximately 72 elements (coarsen/refine to hit this target).
Use a vector-valued continuous Galerkin space of degree 1 for displacement u = (u_x, u_y).

Apply body force f = (0, -ρ g) over the domain.
Impose Dirichlet boundary conditions: u_x = 0 and u_y = 0 on the entire bottom boundary y = 0.
Impose additional Dirichlet boundary conditions: u_y = 0 on the boundary segments x = 0.3 and x = 0.5 for 0.6 ≤ y ≤ 1.0, leaving u_x unconstrained on those segments.
Apply a Neumann traction on the top boundary segment y = 1.0 where 0.3 ≤ x ≤ 0.5 with traction vector t = (5000, 0) Pa (unit thickness).
Use the small-strain tensor ε(u) = sym(grad(u)).
Use plane-stress Lamé-type parameters via λ_ps = E ν / (1 - ν^2) and μ = E / (2 (1 + ν)), and compute in-plane Cauchy stress as σ(u) = 2 μ ε(u) + λ_ps tr(ε(u)) I.
Formulate the variational problem: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_Ω f·v dx + ∫_{Γ_t} t·v ds for all test functions v in V satisfying homogeneous Dirichlet conditions.
Solve the resulting linear system with a direct solver (e.g., LU).
Postprocess displacement magnitude ||u|| over the domain.
Compute von Mises stress from the in-plane Cauchy stress field using σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2).
Output fields suitable for visualization (e.g., XDMF or VTK) for u and σ_vm.
