Use legacy FEniCS (dolfin) to solve a 3D nonlinear hyperelasticity problem on a unit cube using a displacement-based formulation.
Create the mesh as UnitCubeMesh(24, 16, 16) over the domain Ω = [0,1]×[0,1]×[0,1].
Use a first-order vector Lagrange space V = VectorFunctionSpace(mesh, "Lagrange", 1) for the displacement u.
Use material parameters Young’s modulus E = 10.0 and Poisson ratio ν = 0.3.
Compute Lamé parameters as μ = E/(2(1+ν)) and λ = Eν/((1+ν)(1−2ν)).
Define kinematics with F = I + grad(u), C = FᵀF, and J = det(F).
Use a compressible neo-Hookean strain energy density ψ(F) = (μ/2)(tr(C) − 3) − μ ln(J) + (λ/2)(ln(J))².
Define the total potential energy Π(u) = ∫_Ω ψ(F) dX − ∫_Ω b·u dX − ∫_{∂Ω_N} t·u dS.
Use a constant body force b = (0, −0.5, 0) in the reference configuration.
Apply a constant traction t = (0.1, 0, 0) on the natural boundary ∂Ω_N consisting of the faces y=0, y=1, z=0, z=1.
Apply Dirichlet boundary conditions on the faces x=0 and x=1 only.
Clamp the face x=0 with u = (0,0,0).
On the face x=1, prescribe a rotational displacement about the x-axis passing through the line {(x, 0.5, 0.5)} with rotation angle θ = 60 degrees.
Construct the prescribed displacement on x=1 by rotating the point (y,z) about (y0,z0)=(0.5,0.5): y′ = y0 + cos(θ)(y−y0) − sin(θ)(z−z0), z′ = z0 + sin(θ)(y−y0) + cos(θ)(z−z0).
Set the unscaled rotational displacement as u_rot = (0, y′−y, z′−z) on x=1.
Scale the prescribed rotational displacement by 0.5, i.e., enforce u = 0.5*u_rot on x=1.
Solve for u by minimizing Π(u) using a Newton method implemented via the variational equations: residual R(u;v) = dΠ/du[v] = 0 for all test functions v, and Jacobian J(u;δu,v) = dR/du[δu].
Use dolfin’s nonlinear variational solver (NonlinearVariationalProblem/NonlinearVariationalSolver) with the residual and Jacobian derived from Π(u).
Output the converged displacement field u and (optionally) derived fields such as J and the first Piola stress P = ∂ψ/∂F for postprocessing.
