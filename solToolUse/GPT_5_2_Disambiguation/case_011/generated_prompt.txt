Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity problem in plane stress on a rectangular plate with spatially varying Young’s modulus.
Let the domain be Ω = (0, 1.0) × (0, 0.20) meters.
Create a structured rectangular mesh with 100 elements along x and 20 elements along y.
Use a vector-valued Lagrange finite element space of degree 1 for displacement u = (u_x, u_y).
Assume unit thickness for the plane-stress model.
Set Poisson’s ratio to ν = 0.30 (constant).
Define Young’s modulus as a height-only graded field E(y) = 100e9 + 100e9*(y/0.20) Pascals for y in [0, 0.20].
Use the plane-stress constitutive law with Lamé-type parameters expressed via E and ν as λ_ps = E*ν/(1-ν^2) and μ = E/(2*(1+ν)), evaluated pointwise using E(y).
Define strain as ε(u) = sym(grad(u)).
Define stress as σ(u) = 2*μ*ε(u) + λ_ps*tr(ε(u))*I in 2D.
Formulate the variational problem: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_{Γ_R} t·v ds for all v in V, with no body forces.
Apply essential boundary conditions on the left edge x = 0: u_x = 0 and u_y = 0.
Apply a uniform Neumann traction on the right edge x = 1: t = (2e6, 0) in units of N/m (Pa·m) per unit thickness.
Apply traction-free natural boundary conditions on the top edge y = 0.20 and bottom edge y = 0 by not adding any boundary integrals there.
Use a direct linear solver available in dolfin (e.g., LU) to solve the resulting linear system.
Compute the displacement magnitude field |u| = sqrt(u_x^2 + u_y^2) for visualization.
Save a color map image of |u| to q9_disp.png.
Write the displacement solution u to an XDMF file (including mesh) for post-processing.
