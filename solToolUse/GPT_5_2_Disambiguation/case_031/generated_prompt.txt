Use legacy FEniCS (dolfin) targeting version 2019.1.0.
Solve a 2D small-strain linear elasticity problem under plane-stress assumptions with unit thickness.
Use material parameters E = 70e9 Pa and nu = 0.33.
Use density rho = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2.
Define the parallelogram domain with vertices (0,0), (1,0), (1.2,0.3), (0.2,0.3).
Generate a triangular mesh of the domain with exactly 72 total cells.
Use a vector-valued Lagrange displacement space of first order (CG1) on the mesh.
Clamp the left inclined edge from (0,0) to (0.2,0.3) by enforcing u = (0,0) on that boundary.
Leave the other three edges as natural traction-free boundaries.
Apply gravity as a constant body force b = (0, -rho*g) in N/m^3 (unit thickness plane stress).
Apply a horizontal point load at (1.1, 0.15) of magnitude -5000 N in the x-direction using PointSource on the x-component of the displacement test space.
Formulate the variational problem for linear elasticity using small-strain kinematics eps(u) = sym(grad(u)).
Use the reduced plane-stress constitutive law with Lamé-type parameters for plane stress: mu = E/(2*(1+nu)) and lambda_ps = 2*mu*nu/(1-nu).
Compute in-plane Cauchy stress as sigma(u) = 2*mu*eps(u) + lambda_ps*tr(eps(u))*I.
Assemble and solve the resulting linear system with a direct solver (e.g., LU via PETSc).
Compute and output the displacement field u over the domain.
Compute von Mises stress from the in-plane stress components as sigma_vm = sqrt(sxx^2 - sxx*syy + syy^2 + 3*sxy^2).
Project von Mises stress to a scalar CG1 space for visualization/output.
Write displacement and von Mises stress to XDMF files suitable for ParaView (e.g., results.xdmf) as the default output.
