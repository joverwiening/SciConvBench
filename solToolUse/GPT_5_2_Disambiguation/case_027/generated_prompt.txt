Use legacy FEniCS 2019.1.0 (dolfin) with Python 3.x (e.g., 3.8).
Create a 2D right-triangular domain with vertices (0,0), (1,0), (0,0.5).
Generate an unstructured triangular mesh with approximately 64 total triangular cells over the domain.
Define a vector-valued displacement function space V using first-order Lagrange elements (VectorFunctionSpace(mesh, "Lagrange", 1)).
Formulate small-strain linear elasticity under plane-stress assumptions with unit thickness.
Use the reduced plane-stress constitutive law: compute Lamé parameters from E and ν, then use an effective λ_ps = 2μλ/(λ+2μ) with μ unchanged, and define σ(u) = 2μ ε(u) + λ_ps tr(ε(u)) I for in-plane stress.
Set material parameters E = 70e9 Pa and ν = 0.33.
Define strain as ε(u) = sym(grad(u)).
Apply a clamped (Dirichlet) boundary condition u = (0,0) on the base boundary y = 0.
Mark the sloping boundary x + 2y = 1 for Neumann loading.
Apply a constant global x-directed traction t = (2000, 0) Pa on the sloping boundary as a boundary integral term.
Apply gravity as a constant body force f = (0, -ρ g) N/m^3 with ρ = 2700 kg/m^3 and g = 9.81 m/s^2, using unit thickness implicitly in the 2D formulation.
Define the variational problem: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_Ω f·v dx + ∫_{Γ_slope} t·v ds for all v in V.
Solve the resulting linear system using a direct LU solver via solve(a == L, u, bcs, solver_parameters={"linear_solver": "lu"}).
Post-process displacement magnitude as |u| = sqrt(u_x^2 + u_y^2) and project or interpolate it to a scalar CG1 space for output.
Compute the in-plane Cauchy stress tensor field σ(u) and derive von Mises stress for plane stress as σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2), then project it to a scalar CG1 space for output.
Write both displacement magnitude and von Mises stress to XDMF files with flush_output=True and functions_share_mesh=True.
Deliver the solution as a single runnable Python script using dolfin imports only (no notebook).
