Implement in legacy FEniCS (dolfin) a 2D small-strain linear elasticity solver on a square domain with a slit crack.
Target a commonly used legacy release such as FEniCS 2019.1.0 (dolfin) and write code compatible with that API.
Use the computational domain Ω = [-1,1]×[-1,1] minus the slit Γc = {(x,0) : x∈[0,1]} treated as an internal boundary (crack faces).
Generate a mesh that resolves the crack tip at (0,0), using a baseline resolution parameter around 30 and allowing refinement near the tip if needed.
Represent the slit as an internal facet set so that the two crack faces are not tied together and can carry natural boundary conditions.
Use polar coordinates centered at the crack tip: r = sqrt(x^2+y^2) and θ = atan2(y,x) with the branch cut along the slit so that approaching the slit from above gives θ→+π and from below gives θ→−π.
Define parameters λ = 0.5444837367825 and q = 0.5430755788367.
Define the exact displacement field u0(x,y) = (u0,1,u0,2) by u0,1 = r^q (cos(qθ) − λ cos((q−2)θ)) and u0,2 = r^q (sin(qθ) + λ sin((q−2)θ)).
Use a plane strain constitutive assumption as the default best-practice choice when Lamé parameters are provided directly.
Treat the given λ as the first Lamé parameter in the constitutive law.
Choose a reasonable default shear modulus μ = 1.0 (dimensionless) as the second Lamé parameter since it is unspecified.
Define strain ε(u) = sym(grad(u)) and stress σ(u) = 2μ ε(u) + λ tr(ε(u)) I.
Solve the homogeneous equilibrium equations −div(σ(u)) = 0 in Ω.
Impose Dirichlet boundary conditions u = u0 on the outer boundary ∂Ωouter = boundary of the square [-1,1]^2.
Do not impose Dirichlet conditions on the slit crack faces Γc, leaving them traction-free via the natural boundary condition σ(u)n = 0.
Exclude the crack tip point (0,0) from the Dirichlet boundary marking; if point exclusion is not robust in marking, constrain that single point to u = (0,0) as a fallback.
Use a vector-valued continuous Lagrange finite element space with a reasonable default polynomial degree P2.
Formulate the variational problem: find u in V such that a(u,v) = L(v) for all v in V0, with a(u,v) = ∫Ω σ(u):ε(v) dx and L(v) = 0.
Apply Dirichlet boundary conditions strongly on ∂Ωouter using dolfin DirichletBC.
Assemble the linear system and solve it with an iterative Krylov method using GMRES and ILU preconditioning.
Set solver parameters to use GMRES with an ILU-type preconditioner available in dolfin/PETSc (or the closest supported equivalent in the chosen legacy build).
Compute and print the L2 norm of the displacement error ||u−u0||_{L2(Ω)}.
Optionally compute and print the H1 seminorm error ||∇(u−u0)||_{L2(Ω)} as an additional verification metric.
Write the computed displacement u to an output file suitable for visualization, using XDMF as the default (or PVD if XDMF is unavailable).
Optionally write u0 and the error field u−u0 to the same output format for visualization.
Ensure the implementation uses only legacy dolfin constructs (FunctionSpace, TrialFunction/TestFunction, assemble, DirichletBC, KrylovSolver or PETScKrylovSolver, XDMFFile/File).
