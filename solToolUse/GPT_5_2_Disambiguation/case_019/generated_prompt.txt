Use legacy FEniCS (dolfin) to solve a 3D static finite-strain hyperelasticity problem on the unit cube with a Saint-Venant–Kirchhoff material model using Newton’s method.
Create a UnitCubeMesh with 8x8x8 cells on the reference domain Ω = [0,1]^3 with reference coordinates (x1,x2,x3).
Use a vector-valued continuous Galerkin displacement space of polynomial degree 2 (CG2/P2) for the unknown displacement field u(x).
Define the deformation map as y(x) = x + u(x).
Define the deformation gradient F = I + grad(u).
Define the right Cauchy–Green tensor C = FᵀF.
Define the Green–Lagrange strain tensor E = 0.5*(C − I).
Use a Saint-Venant–Kirchhoff strain energy density ψ(E,x) = (λ(x)/2)*(tr(E))^2 + μ*inner(E,E).

Define the spatially varying Lamé parameter λ(x) as λ(x1,x2,x3) = 5.8*x1 + 5.7*(1 − x1) (independent of x2 and x3).
Form the total potential energy Π(u) = ∫_Ω ψ(E(x),x) dx with no body forces and no traction terms.
Obtain the nonlinear weak form as the first variation R(u;v) = dΠ/du[v] = 0 for all test functions v in the same vector space with homogeneous essential constraints applied where appropriate.
Compute the consistent Jacobian J(u;du,v) = dR/du[du] for Newton iterations.
Apply essential boundary conditions on the face x1 = 0 by fixing all displacement components to zero (u = (0,0,0)).
Apply essential boundary conditions on the face x1 = 1 by prescribing a 60-degree rotation about the axis parallel to x1 passing through (x2,x3) = (0.5,0.5).
Implement the rotation boundary condition at x1 = 1 as u(x) = y_rot(x) − x where y_rot keeps x1 unchanged and rotates the (x2,x3) coordinates around (0.5,0.5) by θ = 60 degrees using y2 = 0.5 + cosθ*(x2−0.5) − sinθ*(x3−0.5) and y3 = 0.5 + sinθ*(x2−0.5) + cosθ*(x3−0.5).
Use Newton’s method to solve the nonlinear system arising from R(u;v)=0 with the assembled Jacobian J.
Use standard dolfin nonlinear solver infrastructure (NonlinearVariationalProblem/NonlinearVariationalSolver) with a direct linear solver for the Newton step unless otherwise required.
Converge the Newton iterations based on a residual norm and/or increment norm tolerance suitable for static nonlinear elasticity.
