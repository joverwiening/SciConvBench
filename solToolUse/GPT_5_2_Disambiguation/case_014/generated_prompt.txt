Implement in legacy FEniCS (dolfin) a nonlinear finite-strain hyperelasticity solver for the Saint-Venant–Kirchhoff material using Newton’s method.
Target FEniCS legacy version is 2019.1.0 (e.g., Docker image quay.io/fenicsproject/stable:2019.1.0).
Use a UnitCubeMesh with 8×8×8 cells on Ω = (0,1)^3.
Use a vector-valued Lagrange displacement space of degree 2 (VectorFunctionSpace(mesh, "CG", 2)).
Use Lamé parameters λ = 1.0 and μ = 1.0.
Define the manufactured exact displacement field u_ex(x,y,z) = 0.1*sin(pi*x)*sin(pi*y)*sin(pi*z)*as_vector([1,1,1]).
Impose strong Dirichlet boundary conditions u = u_ex on the entire boundary ∂Ω.
Use the physically consistent total Lagrangian formulation for finite strain.
Define the deformation gradient F(u) = I + grad(u).
Define the Green–Lagrange strain E(u) = 0.5*(F(u).T*F(u) - I).
Define the Saint-Venant–Kirchhoff second Piola–Kirchhoff stress S(u) = λ*tr(E(u))*I + 2*μ*E(u).
Define the first Piola–Kirchhoff stress P(u) = F(u)*S(u).
Define the manufactured body force in the reference configuration as f0 = -Div(P(u_ex)) so that u_ex is an exact solution of the same model.
Formulate the weak residual as: find u such that for all test functions v, ∫_Ω inner(P(u), grad(v)) dx - ∫_Ω dot(f0, v) dx = 0.
Use automatic differentiation to form the Jacobian J = derivative(residual, u, du) with du as the trial function.
Solve the nonlinear system with a Newton solver (NonlinearVariationalProblem/NonlinearVariationalSolver) using the residual and Jacobian.
Use reasonable Newton settings suitable for this smooth manufactured solution (e.g., absolute/relative tolerances around 1e-8 and a maximum iteration count around 25) and report Newton convergence.
After solving, compute and report the L2 norm of the displacement error ||u - u_ex||_{L2(Ω)}.
Optionally also compute and report the H1 seminorm of the displacement error ||grad(u - u_ex)||_{L2(Ω)}.
Ensure the same kinematic and constitutive definitions are used consistently in both the solve and the manufactured forcing construction.
Provide a single runnable Python script that executes the solve on the 8×8×8 mesh and prints the requested error norms.
