Implement a 2D small-strain linear elasticity solver in legacy FEniCS (dolfin) for an L-shaped domain under gravity body force and a prescribed shear traction on part of the top edge.
Target environment: legacy FEniCS 2019.1.0 (dolfin) with mshr available.
Deliverable: a single self-contained Python script.
Use file-based output for visualization: write displacement, stress components, and von Mises stress to XDMF (ParaView-ready), with mesh sharing enabled.
Model type: plane stress with unit thickness.
Geometry: outer square [0,1]×[0,1] minus inner square [0,0.5]×[0,0.5], producing an L-shape.
Mesh: generate with mshr and a resolution corresponding to approximately 64 elements per outer edge (choose mshr resolution parameter to achieve comparable refinement).
Function space: vector-valued continuous Galerkin P1 (CG1) for displacement u.
Material parameters: Young’s modulus E = 70e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m^3.
Gravity: g = 9.81 m/s^2 applied as a body force b = (0, -ρ g) in N/m^3 (consistent with unit thickness plane stress formulation).
Kinematics: small strain ε(u) = sym(grad(u)).
Plane-stress constitutive law: use Lamé parameter μ = E/(2(1+ν)) and plane-stress effective λ_ps = 2 μ λ /(λ + 2 μ) where λ = E ν/((1+ν)(1-2ν)), then define σ(u) = 2 μ ε(u) + λ_ps tr(ε(u)) I.
Weak form: find u in V such that ∫_Ω σ(u):ε(v) dx = ∫_Ω b·v dx + ∫_{Γ_t} t·v ds for all v in V.
Boundary conditions: clamp the entire left outer boundary x = 0 with u = (0,0).
Traction boundary: apply shear traction on the top edge segment y = 1 with x ∈ (0.5, 1.0], using traction vector t = ( +2.65e4, 0 ) in Pa (N/m^2), applied as Neumann load on that boundary segment.
All other outer boundaries not clamped and not traction-loaded are traction-free natural Neumann boundaries (zero traction) by omission from the Neumann integral.
Mark boundaries using SubDomain classes and MeshFunction/Measure to integrate traction only on the loaded segment.
Linear solver: assemble the linear system and solve with a direct solver (e.g., PETSc LU via “lu”).
Post-processing: compute the in-plane Cauchy stress tensor field σ(u) as a UFL expression and project it to a tensor-valued DG0 or CG1 space for output.
Compute von Mises stress for plane stress from σ_xx, σ_yy, σ_xy using σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2), then project to a scalar space for output.
Output fields: displacement u, stress tensor components (at least σ_xx, σ_yy, σ_xy), and von Mises σ_vm to XDMF files suitable for ParaView.
Include minimal runtime diagnostics: report mesh size (number of cells/vertices) and optionally min/max of displacement magnitude and von Mises stress.
