Assume a 2D small-strain linear-elastic plane-stress analysis in legacy FEniCS (dolfin) on a stepped polygonal domain with unit thickness.
Use material properties E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2.
Apply gravity as a constant body force b = (0, -ρ g) in N/m^3.
Define the stepped domain as an 8-vertex polygon with coordinates in meters ordered counterclockwise: (0.0, 0.0), (1.0, 0.0), (1.0, 0.3), (0.6, 0.3), (0.6, 0.7), (0.3, 0.7), (0.3, 1.0), (0.0, 1.0).
Generate a conforming triangular mesh of the polygon with approximately 72 elements total.
Use a vector-valued continuous Galerkin displacement space V = [CG1]^2.
Impose a fully fixed (Dirichlet) boundary condition u = (0, 0) on the bottom boundary where y = 0.
Apply an elastic foundation (Robin) support on the top boundary segment where y = 1.0 and 0.3 ≤ x ≤ 0.5.
Use the Robin traction law t = -k (u·n) n on that segment with k = 1e6 N/m^2, where n is the outward unit normal.
Apply natural traction-free boundary conditions on all remaining exterior boundaries.
Use the small-strain tensor ε(u) = sym(grad(u)).
Use the plane-stress constitutive law by converting (E, ν) to Lamé-like parameters for plane stress: μ = E/(2(1+ν)) and λ_ps = 2 μ λ_3D/(λ_3D + 2 μ) with λ_3D = E ν/((1+ν)(1-2ν)).
Compute Cauchy stress as σ(u) = 2 μ ε(u) + λ_ps tr(ε(u)) I in 2D.
Form the variational problem: find u ∈ V such that ∫_Ω σ(u):ε(v) dx + ∫_{Γ_robin} k (u·n)(v·n) ds = ∫_Ω b·v dx for all v ∈ V.
Solve the resulting linear system using a direct linear solver available in dolfin (e.g., LU).
Postprocess displacement magnitude ||u|| over the domain.
Compute von Mises stress from the in-plane stress components using σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2).
Project von Mises stress to a scalar CG1 space for visualization/output.
Write displacement and von Mises fields to file (e.g., XDMF or VTK) for visualization.
