Use legacy FEniCS (dolfin) with mshr to generate the mesh internally.
Target FEniCS 2019.1.0 (dolfin + mshr) and Python 3.
Model a 2D plane-stress, small-strain, linear elastic cantilever plate of unit thickness.
Create the geometry as a rectangle of size 4.0 by 1.0 minus a circular hole of radius 0.3 centered at (1.0, 0.5).
Generate a mesh with resolution parameter 72.
Use a second-order (P2) vector Lagrange function space for displacement.
Use material parameters E = 210e3 and ν = 0.3.
Use the reduced plane-stress constitutive law (plane-stress Lamé-type parameters or equivalent formulation) consistent with unit thickness.
Define strain as ε(u) = sym(grad(u)).
Define stress σ(u) from the plane-stress constitutive relation.
Apply a clamped Dirichlet boundary condition u = (0, 0) on the left edge x = 0.
Apply a uniform Neumann traction t = (0, -1e5) per unit thickness on the outer right boundary segment x = 4.0.
Apply no traction on the hole boundary (traction-free) and no body forces.
Formulate and solve the static variational problem: find u in V such that ∫Ω σ(u):ε(v) dx = ∫Γ_right t·v ds for all v in V0.
Use a direct linear solver suitable for symmetric positive definite systems (e.g., MUMPS or default LU) via dolfin’s LinearVariationalSolver or solve(A, u, b, "lu").
Compute the displacement field u over the domain.
Compute the Cauchy stress tensor field σ(u) over the domain.
Compute the von Mises stress field from σ(u) using the 2D plane-stress von Mises expression.
Project displacement magnitude and von Mises stress to appropriate scalar function spaces for output.
Write results to XDMF files (mesh, displacement, displacement magnitude, stress components as needed, von Mises) for ParaView visualization.
Ensure boundary markers are defined to apply traction only on x = 4.0 and clamping only on x = 0.
Run in serial by default but remain compatible with MPI execution without code changes.
