Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity problem in plane stress on a rectangular plate.
Define the domain Ω = (0, 1.0) × (0, 0.20) meters.
Create a uniform structured mesh with 20 subdivisions in x and 4 subdivisions in y over Ω.
Use a vector-valued continuous Galerkin displacement space V = [CG1]^2.
Let the unknown displacement field be u = (u_x, u_y) in Ω.
Assume unit thickness for the plane-stress model.
Use isotropic linear elastic material parameters E = 200e9 Pa and ν = 0.30.
Use the small-strain tensor ε(u) = sym(grad(u)).
Use the plane-stress constitutive law by setting λ_ps = 2μλ/(λ + 2μ) and μ = E/(2(1+ν)) with λ = Eν/((1+ν)(1-2ν)).
Define the Cauchy stress as σ(u) = 2μ ε(u) + λ_ps tr(ε(u)) I.
Solve the variational problem: find u ∈ V such that ∫_Ω σ(u):ε(v) dx = 0 for all v ∈ V satisfying homogeneous essential boundary conditions.
Apply Dirichlet boundary conditions on the left edge x = 0: u_x = 0 and u_y = 0.
Apply Dirichlet boundary conditions on the right edge x = 1: u_x = 0.001 m and u_y = 0.
Apply traction-free natural boundary conditions on the top edge y = 0.20 and bottom edge y = 0 by not adding Neumann terms.
Assemble the linear system and solve using a direct linear solver available in dolfin (e.g., LU).
Write the displacement solution u to an XDMF file (with mesh) for post-processing.
Compute u_x as the first component of u and save a color map image of u_x to q1_ux.png.
