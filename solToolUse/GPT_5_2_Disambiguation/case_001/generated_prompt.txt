Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity problem in plane stress on a stepped polygonal domain.
Create the polygonal domain with vertices (0,0)-(0.8,0)-(0.8,0.2)-(0.5,0.2)-(0.5,0.5)-(0.3,0.5)-(0.3,0.2)-(0,0.2) and close the polygon.
Generate a 2D mesh of the domain with a target resolution corresponding to 72 elements.
Use a vector-valued continuous Galerkin displacement space of first order (CG1) on the mesh.
Assume unit thickness for the plane stress model.
Set material parameters to E = 70e9 Pa and ν = 0.33.
Use plane-stress linear elastic constitutive law with Lamé-type parameters adapted for plane stress: μ = E/(2(1+ν)) and λ_ps = Eν/(1-ν^2).
Define strain as ε(u) = sym(grad(u)).
Define in-plane Cauchy stress as σ(u) = 2μ ε(u) + λ_ps tr(ε(u)) I, with I the 2x2 identity.
Apply body force due to gravity as f = (0, -ρ g) with ρ = 2700 kg/m^3 and g = 9.81 m/s^2.
Impose Dirichlet boundary condition u = (0,0) on the entire bottom edge y = 0.
Apply a Neumann traction only on the top boundary segment y = 0.5 with 0.3 ≤ x ≤ 0.5.
Define the applied traction vector on that segment as t(x) = (0, σ_yy(x)) with σ_yy(x) = -8000*x Pa, using the global coordinate x from the mesh.
Formulate the variational problem: find u in the displacement space satisfying ∫Ω σ(u):ε(v) dx = ∫Ω f·v dx + ∫Γt t·v ds for all test functions v, where Γt is the specified loaded top segment.
Solve the resulting linear system using a direct linear solver available in dolfin.
Postprocess the displacement field u over the domain.
Compute the in-plane stress tensor field σ(u) over the domain.
Compute von Mises stress from the in-plane Cauchy stress using σ_vm = sqrt(σ_xx^2 - σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2).
Output displacement magnitude and von Mises stress distributions as fields suitable for visualization (e.g., XDMF/PVD).
Ensure boundary marking distinguishes the fixed bottom edge and the partially loaded top segment defined by y = 0.5 and 0.3 ≤ x ≤ 0.5.
