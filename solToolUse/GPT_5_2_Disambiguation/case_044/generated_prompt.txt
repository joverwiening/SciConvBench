Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity problem in plane stress on a bonded two-material strip.
Define the domain Ω = (0, 1.0) × (0, 0.20) meters with unit thickness.
Create a structured rectangular mesh with 80 elements along x and 16 elements along y.
Split Ω into two perfectly bonded subdomains by the horizontal interface y = 0.10 m.
Assign Ω_Steel to the bottom half 0 ≤ y < 0.10 m.
Assign Ω_Al to the top half 0.10 ≤ y ≤ 0.20 m.
Use isotropic linear elasticity with a plane-stress constitutive law (reduced plane-stress stiffness) separately in each subdomain.
Use material parameters: Steel E = 200 GPa, ν = 0.30; Aluminium E = 70 GPa, ν = 0.30.
Use a continuous displacement space so displacement continuity across y = 0.10 m is enforced strongly by the function space.
Ensure traction continuity across y = 0.10 m is satisfied in the weak form via the standard single-field formulation with piecewise material coefficients.
Let the unknown be displacement u = (u_x, u_y).
Use small-strain kinematics ε(u) = sym(grad(u)).
Apply Dirichlet boundary conditions on the left edge x = 0: u_x = 0 and u_y = 0.
Apply Neumann boundary condition on the right edge x = 1: uniform line traction t = (0, -5000) N/m.
Apply traction-free boundary conditions on the top edge y = 0.20 and bottom edge y = 0.0.
Formulate and solve the variational problem for equilibrium in plane stress with the above boundary conditions.
Use a direct linear solver for the resulting linear system.
Write the displacement solution field to an XDMF file.
