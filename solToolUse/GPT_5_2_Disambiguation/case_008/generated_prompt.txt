Use legacy FEniCS (dolfin) to solve a 2D small-strain orthotropic linear elasticity problem in plane stress on a rectangular domain.
Let the domain be Ω = (0, 1.0) × (0, 0.20) meters.
Create a structured rectangular mesh with 50 elements along x and 25 elements along y.
Use a vector-valued Lagrange finite element space for displacement u = (u_x, u_y).
Assume small strain with ε(u) = sym(grad(u)).
Use orthotropic lamina properties in the local 1–2 axes: E1 = 40e9 Pa, E2 = 10e9 Pa, G12 = 5e9 Pa, ν12 = 0.25.
Compute ν21 = ν12 * E2 / E1 for plane-stress orthotropic consistency.
Form the plane-stress reduced stiffness matrix Q in the local 1–2 axes using standard lamina relations: Q11 = E1/(1-ν12*ν21), Q22 = E2/(1-ν12*ν21), Q12 = ν12*E2/(1-ν12*ν21), Q66 = G12.
Rotate the stiffness from local 1–2 to global x–y using a +30 degree anticlockwise rotation of the material axes relative to the global axes.
Implement the constitutive law in global coordinates so that the stress used in the weak form is σ = C_global : ε, consistent with plane stress.
Apply Dirichlet boundary conditions on the bottom edge y = 0: u_x = 0 and u_y = 0.
Apply Neumann boundary conditions on the top edge y = 0.20: uniform downward line traction per unit thickness t = (0, -10e6) in SI units.
Apply traction-free conditions on the vertical sides x = 0 and x = 1 by not applying any Neumann load there.
Use the standard variational form: find u in V such that ∫_Ω ε(v):σ(u) dx = ∫_{Γ_top} v·t ds for all test functions v in V.
Solve the resulting linear system with a direct linear solver available in dolfin.

Compute a plane-stress von Mises stress field from the in-plane stress components and save a color map image to q8_vm.png.
