Use legacy FEniCS (dolfin) with mshr for geometry and meshing.
Model small-strain, linear elastic, 2D plane-stress with unit thickness.
Use material parameters E = 70e9 Pa and nu = 0.33.
Use density rho = 2700 kg/m^3 and gravity g = 9.81 m/s^2.
Create the polygonal domain with vertices (0,0), (0.8,0), (0.8,0.2), (0.5,0.2), (0.5,0.5), (0.3,0.5), (0.3,0.2), (0,0.2) in that order and close the polygon.
Generate the mesh internally using mshr from the polygon.
Choose the mshr mesh resolution so the resulting mesh has about 72 cells/elements.
Define a vector-valued continuous Galerkin displacement space, degree 1 (CG1).
Define the kinematics with epsilon(u) = sym(grad(u)).
Use the reduced plane-stress constitutive law to compute in-plane Cauchy stress sigma(u) from epsilon(u).
Formulate the variational problem: find u in V such that a(u,v) = L(v) for all v in V, where a(u,v) = integral_Omega inner(sigma(u), epsilon(v)) dx.
Apply gravity as a body force f = (0, -rho*g) and include it in L(v) = integral_Omega dot(f, v) dx.
Apply a concentrated vertical point load of -5000 N at (0.4, 0.5) acting only on the y component, added to the right-hand side using a PointSource on the y subspace.
Clamp the entire bottom edge y = 0 with Dirichlet boundary conditions ux = 0 and uy = 0.
Assemble the linear system and solve with a direct LU solve using the default best-available backend.
Post-process the displacement solution to compute and save the displacement vector field u.
Compute and save the displacement magnitude |u| as a scalar field.
Compute the in-plane Cauchy stress tensor field from u and then compute von Mises stress from the in-plane stress components.
Save results to XDMF files suitable for ParaView, including u (vector), |u| (scalar), and von Mises stress (scalar), with appropriate function names for visualization.
