Use legacy FEniCS (dolfin) 2019.1.0.
Solve 2D small-strain linear elasticity in plane stress with unit thickness.
Use material parameters E = 70e9 Pa and nu = 0.33.
Use density rho = 2700 kg/m^3 and gravity g = 9.81 m/s^2.
Define the computational domain as a rectangle [0,1] x [0,0.5] with a circular hole of radius 0.1 m centered at (0.5, 0.25) removed.
Generate the mesh internally in the script using mshr.
Target a mesh resolution corresponding to 64 elements per outer edge (use an mshr resolution parameter chosen to achieve approximately that density).
Use a vector-valued continuous Galerkin displacement space, degree 1 (CG1).
Define kinematics with epsilon(u) = sym(grad(u)).
Use the reduced plane-stress constitutive law to compute the in-plane Cauchy stress sigma(u) from epsilon(u).
Apply a clamped Dirichlet boundary condition u = (0,0) on the entire left edge x = 0.
Apply a Neumann traction on the right edge x = 1 given by t(y) = (0, -6000*sin(4*pi*y)) Pa for y in [0,0.5].
Apply a Neumann traction on the top edge y = 0.5 given by t = (1000, 0) Pa.
Leave the bottom edge y = 0 and the hole boundary traction-free.
Apply a body force b = (0, -rho*g) N/m^3 over the domain.
Formulate the variational problem: find u in V such that integral_Omega sigma(u):epsilon(v) dx = integral_Omega b·v dx + integral_GammaN t·v ds for all v in V, with the stated Dirichlet condition.
Assemble and solve the resulting linear system using a direct LU solve via PETSc with solver_parameters {"linear_solver":"lu"}.
Postprocess the in-plane Cauchy stress tensor field sigma(u).
Compute the von Mises equivalent stress from the in-plane stress components (plane-stress von Mises using sigma_xx, sigma_yy, sigma_xy).
Write displacement u, stress tensor sigma, and von Mises field to files suitable for ParaView visualization (XDMF preferred; PVD acceptable).
Print a quick scalar summary of von Mises (at least min and max over the domain).
