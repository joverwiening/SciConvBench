Use legacy FEniCS (dolfin) to solve a 2D plane-strain, finite-strain, isotropic incompressible neo-Hookean solid mechanics problem on a perforated strip with a follower pressure load on the hole boundary.
Define the domain as the rectangle (0, 1.0) × (0, 0.20) m with a circular hole of radius a = 0.04 m centered at (0.50, 0.10), with the hole removed from the rectangle.
Generate a 2D triangular mesh with local refinement near the hole targeting h_hole ≈ 0.004 m and coarser sizing away from the hole targeting h_far ≈ 0.02 m, yielding roughly 20k–50k cells.
Assume unit out-of-plane thickness t = 1.0 m for the 2D plane-strain formulation.
Use a mixed displacement-pressure formulation with unknowns u = (u_x, u_y) and p (hydrostatic pressure) enforcing incompressibility.
Use Taylor–Hood elements: u in CG2 (P2) vector space and p in CG1 (P1) scalar space.
Use a finite-strain incompressible neo-Hookean model with Young’s modulus E = 5 MPa and Poisson’s ratio ν = 0.5, using μ = E/(2(1+ν)) and treating incompressibility via the mixed formulation.
Formulate the weak form in the reference configuration using the first Piola–Kirchhoff stress consistent with the incompressible neo-Hookean energy and the pressure constraint.
Apply plane-strain kinematics (2D deformation gradient with out-of-plane strain constrained to zero).
Apply Dirichlet boundary conditions on the left edge x = 0: u_x = 0 and u_y = 0.
Apply traction-free Neumann conditions on the right edge x = 1.0, the top edge y = 0.20, and the bottom edge y = 0.
Apply a uniform follower pressure on the hole boundary with magnitude P_hole = 0.10 MPa, using the sign convention that the traction in the deformed configuration satisfies σ n = −P_hole n so positive P_hole is inward/compressive.
Implement the follower pressure consistently as a load that depends on the current configuration normal (updated each Newton iteration).
Solve using Newton’s method on the coupled mixed system.
Use incremental loading by ramping the hole pressure from 0 to 0.10 MPa over 10 equal load steps, using the converged solution from the previous step as the initial guess for the next step.
Use Newton convergence based on relative residual tolerance 1e-8 with a maximum of 25 Newton iterations per load step.
