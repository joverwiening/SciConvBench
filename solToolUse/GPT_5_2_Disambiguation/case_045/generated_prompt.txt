Use legacy FEniCS (dolfin) to solve a 2D small-strain linear elasticity problem in plane stress on a rectangular plate with a central circular hole.
Target legacy FEniCS version 2019.1.0 (dolfin + mshr) as the reference environment.
Model geometry as a rectangle of width 1.0 m and height 0.5 m with a circular hole of radius 0.1 m centered at (0.5, 0.25).
Generate the mesh using mshr with a target resolution parameter of 72 via generate_mesh(domain, 72).
Use triangular elements as produced by mshr.
Use a vector-valued continuous Galerkin Lagrange displacement space of polynomial degree 2 (CG2).
Assume unit thickness (t = 1.0) consistent with plane stress.
Use material parameters E = 70e9 Pa and ν = 0.33.
Use density ρ = 2700 kg/m^3 and gravitational acceleration g = 9.81 m/s^2.
Apply gravity as a constant body force b = (0, -ρ g) in N/m^3 over the 2D domain with unit thickness.
Impose Dirichlet boundary conditions u = (0, 0) on the entire left edge x = 0.
Apply a downward concentrated point load of magnitude 5000 N at point (1.0, 0.25) in the −y direction using a PointSource on the y-component of the displacement space.
Formulate the variational problem for small-strain linear elasticity with strain ε(u) = sym(grad(u)).
Use the reduced plane-stress constitutive law by defining the in-plane stress σ(u) = 2 μ ε(u) + λ_ps tr(ε(u)) I with μ = E/(2(1+ν)) and λ_ps = E ν/(1−ν^2).
Solve the linear system with a direct solver (e.g., LU via solve(a == L, u, bcs, solver_parameters={"linear_solver":"mumps"})).
Compute the in-plane Cauchy stress tensor field from the solved displacement.
Compute von Mises stress from the in-plane stress components as σ_vm = sqrt(σ_xx^2 − σ_xx σ_yy + σ_yy^2 + 3 σ_xy^2).
Project displacement and von Mises stress to suitable function spaces for output (vector CG2 for displacement and scalar CG1 or CG2 for von Mises).
Write results to XDMF files suitable for ParaView post-processing, including displacement and von Mises stress, with mesh written once and functions appended.
Include minimal console output reporting solver completion and basic extrema (min/max) of displacement magnitude and von Mises stress.
