Run CalculiX using the command ccx -i case_107.
Determine whether the run succeeded by checking for 'JOB COMPLETED' in the case_107.sta file.
Write a results.json file in the working directory.
The results.json file must contain the key "solver" with the value "calculix".
The results.json file must contain the key "case_id" with the value "case_107".
The results.json file must contain the key "status" with the value "success" if the run completed successfully, or "error" otherwise.
The results.json file must contain the key "ccx_version" with the version string obtained from running ccx -v.
The results.json file must contain the key "artifacts" with a list of strings: "case_107.sta", "case_107.dat", "case_107.frd", "results.json".
The results.json file must contain the key "notes" with the exact ccx command used.
If the run failed, the "notes" field must also include the error message and the file that indicated the failure.
