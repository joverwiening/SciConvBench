Create a file named case_129.inp in the working directory.
The content of case_129.inp must be exactly as provided in the "Input deck" section.
Execute the CalculiX analysis using the command ccx -i case_129 or ccx case_129, using whichever command successfully runs the analysis on the system.
Determine the CalculiX version by executing ccx -v and record the output string.
After the analysis, check the file case_129.sta for the string 'JOB COMPLETED' to determine if the run succeeded.
Create a file named results.json in the working directory.
The results.json file must conform to the specified schema.
Set the solver field in results.json to "calculix".
Set the case_id field in results.json to "case_129".
Set the status field in results.json to "success" if 'JOB COMPLETED' is found in case_129.sta, otherwise set it to "error".
Set the ccx_version field in results.json to the version string obtained from ccx -v.
Set the artifacts field in results.json to an array containing the strings "case_129.inp", "case_129.sta", "case_129.dat", and "case_129.frd".
Set the notes field in results.json to include the exact ccx command used for the analysis.
If the run failed, the notes field must also include the error message and the name of the file that indicated the failure.
