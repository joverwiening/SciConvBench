Create a file named case_067.inp in the working directory.
The content of case_067.inp must be exactly the text provided in the Input deck section.
Execute the CalculiX analysis using the command ccx -i case_067.
Determine the success of the run by checking the case_067.sta file for the string 'JOB COMPLETED'.
Create a file named results.json in the working directory.
The results.json file must adhere to the specified schema.
The "solver" field in results.json must be "calculix".
The "case_id" field in results.json must be "case_067".
The "status" field in results.json must be "success" if 'JOB COMPLETED' is found in case_067.sta, otherwise it must be "error".
The "ccx_version" field in results.json must contain the version string obtained from running ccx -v.
The "artifacts" field in results.json must be an empty array.
The "notes" field in results.json must record the exact ccx command used.
If the run failed, the "notes" field must also include the error message and the file that indicated the failure.
