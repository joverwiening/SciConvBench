Create a file named case_088.inp in the working directory.
The content of case_088.inp must be the provided input deck.
Run the CalculiX analysis using the case_088.inp input file.
Determine the success or failure of the run by checking the case_088.sta file for the string 'JOB COMPLETED'.
Create a results.json file in the working directory.
The results.json file must have the following schema: {"solver": "calculix", "case_id": "case_088", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Set the "solver" field to "calculix".
Set the "case_id" field to "case_088".
Set the "status" field to "success" if the run completed successfully, otherwise set it to "error".
Set the "ccx_version" field to the version string obtained from running `ccx -v` or its closest equivalent.
Set the "artifacts" field to an empty list.
Set the "notes" field to include the exact ccx command used for the analysis.
If the run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
