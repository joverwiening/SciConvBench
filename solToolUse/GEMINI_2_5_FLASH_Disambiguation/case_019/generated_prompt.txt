The simulation uses FEniCS legacy (dolfin).
The problem is a static twisting of a hyperelastic cube.
The material model is Saint-Venant-Kirchhoff hyperelasticity.
The solver uses Newton's method for the nonlinear problem.
The geometry is a UnitCube mesh with 8x8x8 cells.
The shear modulus μ is 3.8461 N/m^2.
The Lamé parameter λ varies spatially as λ = 5.8x1 + 5.7(1 - x1).
The boundary condition at x1 = 0 is fixed displacement (u = 0).
The boundary condition at x1 = 1 is a 60-degree rotation about the line passing through (1, 0.5, 0.5) and parallel to the x1-axis.
