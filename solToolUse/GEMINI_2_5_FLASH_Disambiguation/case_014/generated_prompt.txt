Implement a nonlinear hyperelasticity problem using FEniCS legacy (dolfin).
Solve the Saint-Venant-Kirchhoff problem with Newton's method.
The governing equation is ∇⋅σ + f0 = 0, where σ = ∂Ψ/∂ε.
The strain energy function is Ψ = 0.5λ(trε)^2 + μtr(ε^2).
The Green-Lagrange strain tensor is ε = ½(F^TF - I).
The deformation gradient is F = I + ∇u.
Use a UnitCube mesh with 8x8x8 cells.
The Lame parameters are λ = 1.0 and μ = 1.0.
The manufactured exact solution for the displacement field is u_ex = 0.1 * sin(πx) * sin(πy) * sin(πz) in all three components.
Verify the numerical solution against this manufactured exact solution.
