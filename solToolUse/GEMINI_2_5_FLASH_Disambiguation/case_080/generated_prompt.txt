Create a file named case_080.inp in the working directory.
Populate case_080.inp with the provided input deck content.
Execute the CalculiX analysis using either the command ccx -i case_080 or ccx case_080, selecting the command that successfully runs on the system.
Determine the CalculiX run status by examining the case_080.sta file for the string 'JOB COMPLETED'.
Retrieve the CalculiX version string by executing the command ccx -v.
Create a results.json file in the working directory.
The results.json file must adhere to the specified schema.
Set the "solver" field to "calculix".
Set the "case_id" field to "case_080".
Set the "status" field to "success" if 'JOB COMPLETED' is found in case_080.sta, otherwise set it to "error".
Set the "ccx_version" field to the version string obtained from ccx -v.
Set the "artifacts" field to an empty list.
Set the "notes" field to include the exact ccx command used for the analysis.
If the CalculiX run failed, also include the error message and the file that indicated the failure in the "notes" field.
