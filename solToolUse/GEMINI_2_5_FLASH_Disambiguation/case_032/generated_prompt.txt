The system will use FEniCS legacy (dolfin) for the simulation.
The solver will implement nonlinear hyperelasticity using Newton's method.
The problem is a displacement-based compressible neo-Hookean problem.
The geometry is a 3D unit cube.
The mesh is generated using UnitCubeMesh(24, 16, 16).
The function space is VectorFunctionSpace(mesh, "Lagrange", 1).
The material properties are Young's modulus E = 10.0 and Poisson ratio ν = 0.3.
Kinematics are defined by the deformation gradient F = I + grad(u), the right Cauchy-Green deformation tensor C = F^T F, and the Jacobian J = det(F).
The compressible neo-Hookean energy formulation will be used.
Boundary conditions include clamping the face at x = 0, meaning displacement u = (0, 0, 0).
On the face at x = 1, a prescribed rotational displacement field is imposed.
This prescribed displacement is obtained from a 60-degree rotation about the section center (y0, z0) = (0.5, 0.5), scaled by 0.5.
A body force B = (0, -0.5, 0) is applied throughout the domain.
A natural boundary traction T = (0.1, 0, 0) is applied on the face at y = 0.
The task is to solve the nonlinear displacement problem by minimizing the total potential energy.
