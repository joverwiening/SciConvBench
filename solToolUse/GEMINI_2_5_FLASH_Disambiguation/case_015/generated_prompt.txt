The simulation will use FEniCS legacy (dolfin).
The solver will implement incompressible finite-strain hyperelasticity using the mixed displacement-pressure neo-Hookean formulation.
Newton's method will be used for solving the nonlinear problem.
The task is to solve Solid Mechanics Problem 13, which involves an incompressible neo-Hookean perforated strip with follower pressure on the hole boundary.
The geometry is a rectangular strip Ω = (0, 1.0) x (0, 0.20) m with a circular hole of radius a = 0.04 m centered at (0.50, 0.10).
The model is a large-deformation isotropic incompressible neo-Hookean solid with displacement u = (u_x, u_y) and hydrostatic pressure p as unknowns.
The problem is set in plane strain.
The material properties are Young's modulus E = 5 MPa and Poisson's ratio ν = 0.5.
The left edge (x = 0) has fixed boundary conditions, with u_x = 0 and u_y = 0.
A uniform follower pressure P_hole = 0.10 MPa is applied on the hole boundary.
The right, top, and bottom edges are traction-free.
The maximum element size for the mesh will be 0.01 m.
A magnified (x5) deformed plot will be saved as q13_def.png.
The von Mises field, computed from the Cauchy stress, will be saved as q13_vm.png.
The displacement field will be saved in XDMF format.
