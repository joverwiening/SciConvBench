Create a file named case_083.inp in the working directory.
Populate case_083.inp with the provided input deck content.
Execute the CalculiX analysis using the command ccx -i case_083.
If the previous command fails, execute the CalculiX analysis using the command ccx case_083.
Determine the success of the run by examining the case_083.sta file for a 'JOB COMPLETED' message.
Retrieve the CalculiX version string by running ccx -v.
Create a results.json file in the working directory.
The results.json file must contain the following fields: "solver" with value "calculix", "case_id" with value "case_083", "status" with value "success" if the run completed successfully or "error" otherwise, "ccx_version" with the retrieved version string, "artifacts" as an empty array, and "notes".
The "notes" field must contain the exact ccx command used for the analysis.
If the run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
