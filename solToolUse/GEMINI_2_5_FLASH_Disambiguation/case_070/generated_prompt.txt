Create a file named case_070.inp in the working directory with the provided input deck content.
Attempt to run the CalculiX analysis using the command ccx -i case_070.
If the first command fails, attempt to run the CalculiX analysis using the command ccx case_070.
Determine the CalculiX run status by checking the case_070.sta file for the string 'JOB COMPLETED'.
Execute ccx -v to obtain the CalculiX version string.
Create a results.json file in the working directory.
The results.json file must contain the key "solver" with the value "calculix".
The results.json file must contain the key "case_id" with the value "case_070".
The results.json file must contain the key "status" with the value "success" if 'JOB COMPLETED' is found in case_070.sta, otherwise "error".
The results.json file must contain the key "ccx_version" with the version string obtained from ccx -v.
The results.json file must contain the key "artifacts" with an empty array value.
The results.json file must contain the key "notes" with the exact ccx command used for the analysis.
If the CalculiX run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
