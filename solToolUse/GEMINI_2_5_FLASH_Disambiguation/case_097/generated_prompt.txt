Populate case_097.inp with the provided input deck content.
Execute the CalculiX analysis using either the command ccx -i case_097 or ccx case_097, selecting the one that functions on the system.
Determine the success of the run by examining the case_097.sta file for the string 'JOB COMPLETED'.
Create a results.json file in the working directory.
The results.json file must contain the following schema: {"solver": "calculix", "case_id": "case_097", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Record the CalculiX version string obtained from running ccx -v in the ccx_version field.
Record the exact ccx command used for the analysis in the notes field.
If the CalculiX run fails, include the error message and the file that indicated the failure in the notes field.
The artifacts array in results.json must be empty.
