Create a file named case_050.inp in the working directory.
Populate case_050.inp with the provided input deck content.
Execute the CalculiX analysis using the command ccx -i case_050.
Determine the success of the run by checking the case_050.sta file for the string 'JOB COMPLETED'.
Obtain the CalculiX version string by running ccx -v.
Create a file named results.json in the working directory.
Populate results.json with the following structure: {"solver": "calculix", "case_id": "case_050", "status": "...", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Set the "status" field to "success" if 'JOB COMPLETED' is found in case_050.sta, otherwise set it to "error".
Set the "ccx_version" field to the version string obtained from ccx -v.
Set the "artifacts" field to an empty array.
Set the "notes" field to the exact ccx command used (ccx -i case_050).
If the run failed, append the error message and the file indicating the failure to the "notes" field.
