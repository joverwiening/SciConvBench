Create a file named case_121.inp in the working directory.
Populate case_121.inp with the provided input deck content.
Execute the CalculiX analysis using the command ccx -i case_121.
If the command ccx -i case_121 fails, execute the CalculiX analysis using the command ccx case_121.
Determine the success of the CalculiX run by checking the case_121.sta file for the string 'JOB COMPLETED'.
Obtain the CalculiX version string by running the command ccx -v.
Create a file named results.json in the working directory.
Populate results.json with a JSON object.
The results.json object must contain a "solver" field with the value "calculix".
The results.json object must contain a "case_id" field with the value "case_121".
The results.json object must contain a "status" field, which is "success" if 'JOB COMPLETED' is found in case_121.sta, otherwise "error".
The results.json object must contain a "ccx_version" field with the version string obtained from ccx -v.
The results.json object must contain an "artifacts" field with an empty list value.
The results.json object must contain a "notes" field.
The "notes" field must record the exact ccx command used for the analysis.
If the CalculiX run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
