The simulation will use FEniCS legacy (dolfin).
The problem is small-strain linear elasticity in 2D plane-stress.
The variational problem will use a vector-valued displacement space.
A direct linear solver will be used.
The geometry is a rectangular plate Ω = (0, 1.0) x (0, 0.20) m.
The mesh is a uniform structured mesh with 40 subdivisions in x and 8 subdivisions in y.
The material properties are Young's modulus E = 200 GPa and Poisson's ratio ν = 0.30.
The left edge (x = 0) has fixed boundary conditions, u_x = 0 and u_y = 0.
The top edge (y = 0.20) has a downward traction t = (0, -2000) N/m.
The right edge (x = 1.0) and bottom edge (y = 0) are traction-free.
The 2D strip is treated as plane stress with unit thickness.
The reduced plane-stress constitutive law will be used.
A colour map of the u_y displacement component will be saved as q2_uy.png.
The resulting displacement field will be saved in XDMF format.
