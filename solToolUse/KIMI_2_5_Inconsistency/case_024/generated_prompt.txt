Solve a 2D plane-stress linear elasticity problem for a rectangular plate with a centered circular hole using FEniCS legacy (dolfin).

Create a rectangular domain with corners at (0, 0) and (1.0, 0.20) meters.

Subtract a circular hole of radius 0.05 m centered at (0.50, 0.10) from the domain.

Define the material properties: Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.30.

Compute the plane-stress Lamé parameters: mu = E / (2.0 * (1.0 + nu)) and lambda_ = E * nu / (1.0 - nu**2).

Define the plane-stress stress-strain relationship: sigma(u) = lambda_ * tr(epsilon(u)) * Identity(2) + 2 * mu * epsilon(u), where epsilon(u) = 0.5 * (grad(u) + grad(u).T).

Create a vector-valued FunctionSpace of degree 1 for the displacement field u.

Apply Dirichlet boundary conditions: fix both displacement components to zero on the left edge where x = 0.

Apply a zero normal displacement constraint on the hole boundary to prevent ovalization.

Define the variational problem: find u in V such that inner(sigma(u), epsilon(v)) * dx = dot(t, v) * ds for all test functions v in V, where t = (2e6, 0) is the traction vector on the right edge x = 1.0.

Mark the right edge boundary (x = 1.0) for applying the Neumann traction condition.

Mark all remaining external boundaries and the hole boundary as traction-free (natural boundary condition).

Use a direct linear solver (MUMPS or default LU) to solve the linear system.

Compute the von Mises stress from the plane-stress stress tensor: von_Mises = sqrt(sigma_xx**2 - sigma_xx*sigma_yy + sigma_yy**2 + 3*sigma_xy**2).

Project the von Mises stress onto a suitable function space for visualization.
