Generate a structured mesh with 80 elements in the x-direction and 16 elements in the y-direction.

Use a DG0 (discontinuous Galerkin degree 0) function space to represent piecewise constant material properties that vary by cell according to the subdomain markers.

Apply boundary conditions: fix both displacement components on the left edge (x = 0), apply a uniform traction t = (0, -5000) N/m on the right edge (x = 1.0), and leave the top and bottom edges traction-free.

Define the variational problem: find u in a vector function space of continuous piecewise linear elements such that the bilinear form a(u, v) = inner(sigma(u), epsilon(v)) * dx equals the linear form L(v) = dot(t, v) * ds on the right boundary for all test functions v.

Assemble the system and solve using a direct linear solver (MUMPS or default LU).

Compute the magnitude of displacement |u| = sqrt(u_x^2 + u_y^2).
