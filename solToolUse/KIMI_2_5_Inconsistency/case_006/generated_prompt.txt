Solve a nearly incompressible small-strain elasticity problem in 2D plane strain using FEniCS legacy (dolfin) with a mixed displacement-pressure formulation and direct saddle-point solver.

The domain is a rectangular strip Omega = (0, 1.0) x (0, 0.20) meters.

Create a structured mesh with 100 elements in the x-direction and 20 elements in the y-direction.

Use small-strain linear elasticity with plane strain conditions.

Set Young's modulus E = 5.0e6 Pa and Poisson's ratio nu = 0.49.

Define the mixed function space using a stable element pair for the saddle-point problem: use continuous Lagrange elements of degree 2 for displacement (vector) and continuous Lagrange elements of degree 1 for pressure, i.e., V = VectorElement("CG", mesh.ufl_cell(), 2) for displacement and Q = FiniteElement("CG", mesh.ufl_cell(), 1) for pressure, combined as TH = V * Q.

Compute the Lamé parameters from E and nu: mu = E / (2.0 * (1.0 + nu)) and lambda = E * nu / ((1.0 + nu) * (1.0 - 2.0 * nu)).

Define the strain epsilon(u) = sym(grad(u)) and the deviatoric strain epsilon_dev(u) = epsilon(u) - tr(epsilon(u)) / 3 * Identity(2), noting that for plane strain the out-of-plane strain component is zero.

Formulate the variational problem: find (u, p) in W such that for all (v, q) in W, the following holds: 2 * mu * inner(epsilon_dev(u), epsilon_dev(v)) * dx - inner(p, div(v)) * dx - inner(q, div(u)) * dx - (1.0 / lambda) * inner(p, q) * dx = 0, where the last term comes from the pressure constitutive relation p = -lambda * tr(epsilon(u)).

Apply boundary conditions: on the left edge (x = 0), fix both displacement components using DirichletBC(W.sub(0), Constant((0.0, 0.0)), left_boundary). On the right edge (x = 1.0), apply prescribed displacement u_x = 0.03 m and u_y = 0 using DirichletBC(W.sub(0), Constant((0.03, 0.0)), right_boundary). The top and bottom edges remain traction-free (natural boundary conditions).

Solve the linear system using a direct solver (MUMPS or default LU) via solve(a == L, w, bcs) where w is the mixed solution function.

Extract the displacement and pressure components: u, p = w.split().

Compute the magnitude of displacement |u| = sqrt(u[0]**2 + u[1]**2).

Save a color map plot of |u| to the file q10_disp.png using matplotlib or dolfin's built-in plotting, with a colorbar and appropriate title.

Save the displacement field u in XDMF format using XDMFFile, writing both the vector field and optionally the magnitude as a scalar function.
