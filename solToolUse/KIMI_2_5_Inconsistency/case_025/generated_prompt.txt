The simulation solves a 2D plane-stress linear elasticity problem using legacy FEniCS (dolfin).

The domain is a stepped polygon defined by 8 vertices with approximate coordinates: (0.0, 0.0), (0.6, 0.0), (0.6, 0.2), (0.5, 0.2), (0.5, 0.4), (0.3, 0.4), (0.3, 0.2), (0.0, 0.2). These coordinates create a reasonable stepped geometry with a bottom rectangular section and a narrower top section.

The mesh contains approximately 72 triangular elements, generated using a characteristic element size of approximately 0.05 m to achieve this element count on the given geometry.

The function space is a vector-valued Lagrange space of degree 1 (CG1) for displacement, with 2 components for the 2D problem.

Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s².

The plane-stress constitutive law uses the modified Lamé parameters: λ = Eν/((1+ν)(1-ν)) and μ = E/(2(1+ν)), with the stress-strain relation σ = 2με + λ tr(ε) I, where ε is the symmetric gradient of displacement.

Boundary conditions are: fixed displacement (zero) on the bottom edge where y = 0; vertical traction σ_yy = -10 kPa (compressive) applied on the top segment where 0.3 ≤ x ≤ 0.5 and y is at maximum; body force due to gravity applied as (0, -ρg) in the y-direction.

The variational form uses the standard linear elasticity formulation: find u in the displacement space such that ∫ σ(u) : ε(v) dx = ∫ f·v dx + ∫ t·v ds for all test functions v, where f is the body force and t is the traction.

The solver uses a direct linear solver (MUMPS or LU) to solve the resulting linear system.

Post-processing computes the displacement magnitude as sqrt(u_x² + u_y²) and the von Mises stress from the in-plane Cauchy stress components as σ_vm = sqrt(σ_xx² - σ_xxσ_yy + σ_yy² + 3σ_xy²), where the stress components are extracted from the computed stress tensor field.
