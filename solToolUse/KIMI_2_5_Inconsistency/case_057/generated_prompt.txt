Create a file named `zerovel.inp` in the working directory with the following exact content:

**
**   Structure: beam.
**   Test objective: velocity for OUTPUT=2D.
**
*NODE
1,0,0,0
2,0.1,0,0
*ELEMENT,TYPE=B31,ELSET=Default
1,2,1
*MATERIAL,NAME=Material
*ELASTIC,TYPE=ISOTROPIC
10000000000,0
*DENSITY
1000
*BEAM SECTION,ELSET=Default,MATERIAL=Material,SECTION=RECT
0.01,0.01
0,-1,0
*STEP
*DYNAMIC
0.01,0.1,0,0
*CLOAD
1,1,0.01
*NODE FILE,GLOBAL=YES,OUTPUT=2D,FREQUENCY=10
U,V
*END STEP

Run CalculiX using the command `ccx -i zerovel` or `ccx zerovel`, whichever works on the system.

Check the file `zerovel.sta` for successful termination indicated by 'JOB COMPLETED'.

Create a file named `results.json` in the working directory with the following schema:
- Set "solver" to "calculix"
- Set "case_id" to "zerovel"
- Set "status" to "success" if the job completed successfully, otherwise "error"
- Set "ccx_version" to the version string obtained from running `ccx -v` (or equivalent)
- Set "artifacts" to an empty array []
- Set "notes" to include the exact ccx command used, and if the run failed, include the error message and what file indicated the failure
