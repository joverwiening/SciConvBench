Solve a finite-strain Saint-Venant-Kirchhoff elasticity problem for a three-hole strip using legacy FEniCS (dolfin).

The domain is a rectangular strip Ω = (0, 1.20) x (0, 0.20) m with three circular holes of radius a = 0.03 m centered on the midline y = 0.10 m at x = 0.30 m, 0.60 m, and 0.90 m.

Use plane strain conditions.

The displacement field u = (u_x, u_y) is the unknown.

Define the deformation gradient F = I + grad(u).

Define the Green-Lagrange strain E_GL = 0.5*(F^T*F - I).

Define the second Piola-Kirchhoff stress S = lambda*tr(E_GL)*I + 2*mu*E_GL.

Define J = det(F) and the Cauchy stress sigma = (1/J)*F*S*F^T.

Use material parameters lambda = 5.769 MPa and mu = 3.846 MPa.

Apply boundary conditions: left edge (x = 0) fixed with u_x = 0 and u_y = 0; right edge (x = 1.20) with prescribed displacement u_x = 0.012 m and u_y = 0; top, bottom, and hole boundaries are traction-free.

Use load stepping with Newton iterations to solve the nonlinear problem.

Stop advancing the load if the maximum principal Green-Lagrange strain E_max exceeds 0.03.

Save a deformed-configuration plot as q15_def.png.

Compute the maximum principal Green-Lagrange strain E_max and save as q15_Emax.png.

Compute the deviatoric second Piola stress invariant (von Mises equivalent) and save as q15_vmS.png.

Export the final displacement u and E_max to XDMF format.
