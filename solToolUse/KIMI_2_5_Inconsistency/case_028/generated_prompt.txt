The simulation solves a 2D plane-stress linear elasticity problem for an L-shaped structure using FEniCS legacy (dolfin).

The geometry consists of an L-shape formed by a 1x1 outer square with a 0.5x0.5 inner square removed from the top-right corner.

Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s².

The computational mesh uses 64 elements per edge with triangular elements.

The function space is a vector-valued Lagrange space of degree 1 for displacement.

Boundary conditions are: fixed displacement (u = 0) on the left edge at x = 0; horizontal shear traction σ_xy = 2.65e4 Pa applied on the top-right segment where y = 1 and x > 0.5; all other outer edges are traction-free natural boundaries.

Body forces include gravity acting in the negative y-direction with magnitude ρ*g.

The constitutive law uses the reduced plane-stress formulation with the elasticity tensor adapted for unit thickness.

The variational problem uses the standard linear elasticity bilinear form with strain energy density and linear form incorporating both body forces and surface tractions.

The linear system is solved using a direct solver (MUMPS or default LU).

Post-processing computes the Cauchy stress tensor from the displacement gradient.

Von Mises equivalent stress is computed from the in-plane stress components using the standard formula for plane stress.

Visualization includes the displacement magnitude field and von Mises stress distribution.
