Use FEniCS legacy (dolfin) to solve a 2D plane-stress linear elasticity problem on an L-shaped domain.

The domain is defined as the unit square [0,1] × [0,1] with the top-right quadrant [0.5,1] × [0.5,1] removed, forming an L-shape.

Create a mesh with 64 elements per edge on the outer boundary using the FEniCS mesh generation utilities or external meshing with appropriate resolution near the re-entrant corner.

Define a vector-valued FunctionSpace of continuous Lagrange elements of degree 1 for the displacement field u = (u_x, u_y).

Apply clamped boundary conditions (u = 0) on the left edge at x=0 for all y in [0,1].

Apply clamped boundary conditions (u = 0) on the bottom edge at y=0 for all x in [0,0.5].

Apply clamped boundary conditions (u = 0) on the vertical cutout face at x=0.5 for y in [0.5,1].

Apply clamped boundary conditions (u = 0) on the horizontal cutout face at y=0.5 for x in [0.5,1].

Apply a horizontal traction boundary condition on the right edge at x=1 for y in [0,0.5] with σ_xx = 2.65e4 Pa (tension in x-direction, zero shear traction).

Use material properties: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³.

Implement the plane-stress constitutive law with the reduced stiffness tensor: the stress-strain relation is σ = C:ε where for plane stress, C_1111 = E/(1-ν²), C_1122 = νE/(1-ν²), C_2222 = E/(1-ν²), C_1212 = E/(2(1+ν)), with C_2211 = C_1122 and appropriate symmetry.

Define the strain tensor as ε(u) = 0.5*(∇u + ∇u^T).

Formulate the variational problem: find u in the displacement space satisfying the essential boundary conditions such that ∫_Ω σ(u):ε(v) dx = ∫_Γ_traction t·v ds for all test functions v, where t = (2.65e4, 0) on the right edge.

Use a direct linear solver (MUMPS or default LU) to solve the resulting linear system.

Compute the Cauchy stress tensor σ from the displacement solution using the plane-stress constitutive law.

Compute the von Mises equivalent stress as σ_vm = sqrt(σ_11² - σ_11*σ_22 + σ_22² + 3*σ_12²) from the in-plane stress components.

Output the displacement magnitude and von Mises stress fields for visualization and analysis.
