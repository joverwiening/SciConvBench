Run CalculiX using the command `ccx -i beammix` or `ccx beammix`, whichever works on the system.

Check the file `beammix.sta` to determine if the run succeeded by looking for a successful termination message such as 'JOB COMPLETED'.

Create a file named `results.json` in the working directory with the following schema:
{
  "solver": "calculix",
  "case_id": "beammix",
  "status": "success" | "error",
  "ccx_version": "...",
  "artifacts": [],
  "notes": "..."
}

Record the version string from `ccx -v` (or the closest equivalent) in the `ccx_version` field.

Record the exact ccx command used in the `notes` field.

If the run failed, include the error message and what file indicated the failure in the `notes` field.
