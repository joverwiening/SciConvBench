Use FEniCS legacy (dolfin) to solve a 2D plane-stress linear elasticity problem on a parallelogram domain.

The domain vertices are (0,0), (1,0), (1.2,0.3), (0.2,0.3).

The left edge runs from (0,0) to (0.2,0.3) with horizontal run 0.2 and vertical rise 0.3.

The right edge runs from (1,0) to (1.2,0.3) with the same inclination.

Material properties are E = 70e9 Pa, ν = 0.33, ρ = 2700 kg/m³, g = 9.81 m/s².

Use plane stress constitutive law with unit thickness.

The right inclined edge is fully fixed (Dirichlet BC: u = 0).

Apply a horizontal traction σ_xx = 6000 Pa on the left slope as a global horizontal load (not tangential shear).

Apply gravity loading in the negative y-direction as a body force.

Create a mesh with 72 elements.

Use a vector-valued Lagrange finite element space of degree 1 for displacement.

Define the variational form for plane stress elasticity.

Solve using a direct linear solver (MUMPS or default LU).

Compute the Cauchy stress tensor from the displacement gradient.

Compute von Mises stress from the in-plane stress components.

Output displacement and von Mises stress distributions.
