Solve the 2D plane-strain small-strain elasticity problem for a nearly incompressible perforated strip using legacy FEniCS (dolfin).

Use a mixed displacement-pressure formulation with Taylor-Hood elements: continuous piecewise quadratic vector elements for displacement and continuous piecewise linear elements for pressure.

Define the rectangular domain Ω = (0, 1.0) × (0, 0.20) m with a circular hole of radius a = 0.04 m centered at (0.50, 0.10).

Set material properties: Young's modulus E = 5 MPa, Poisson's ratio ν = 0.49.

Compute Lamé parameters: μ = E / (2(1+ν)) and λ = Eν / ((1+ν)(1-2ν)).

Apply boundary conditions: on the left edge (x = 0) set u_x = 0 and u_y = 0; on the right edge (x = 1.0) set u_x = 0.001 m and u_y = 0; all other boundaries (top, bottom, and hole) remain traction-free.

Formulate the variational problem using the mixed formulation: find (u, p) such that the momentum balance and the constitutive relation for pressure are satisfied weakly, with the deviatoric stress σ_dev = 2με(u) where ε(u) is the symmetric gradient.

Use a direct solver for the saddle-point system.

After solving, compute the von Mises equivalent stress from the total stress σ = σ_dev - pI.
