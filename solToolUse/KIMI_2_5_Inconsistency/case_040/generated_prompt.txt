The specification for this task is as follows:

Use FEniCS legacy (dolfin) to solve a quasi-incompressible finite-strain hyperelasticity problem with a mixed displacement-pressure formulation.

The geometry consists of a rectangular strip Ω = (0, 1.0) x (0, 0.20) m with two circular holes of radius a = 0.04 m centered at (0.40, 0.10) m and (0.60, 0.10) m.

Use a neo-Hookean material model with Young's modulus E = 5 MPa and Poisson's ratio ν = 0.49.

Use a mixed function space with vector-valued quadratic Lagrange elements (degree 2) for displacement and scalar linear Lagrange elements (degree 1) for pressure, satisfying the Ladyzhenskaya-Babuska-Brezzi (LBB) stability condition.

Define the deformation gradient F = I + grad(u), the Jacobian J = det(F), the isochoric part of F as F_bar = J^(-1/3) * F, and the right Cauchy-Green tensor C = F.T * F.

Define the neo-Hookean strain energy density as Ψ = (μ/2) * (tr(C_bar) - 3) + (κ/2) * (ln(J))^2, where C_bar = F_bar.T * F_bar.

Formulate the weak form: find (u, p) such that the variation of the total potential energy plus the pressure constraint is stationary, using the Lagrange multiplier formulation where p enforces the volumetric constraint.

Apply boundary conditions as follows: on the left edge (x = 0), set u_x = 0 and u_y = 0; on the right edge (x = 1.0), set u_x = 0.060 m and u_y = 0; on top and bottom edges, apply traction-free conditions.

Apply follower pressure P_hole = 0.10 MPa on each hole boundary using the reference (undeformed) normals, not the current normals.

At each load step, solve the nonlinear system using Newton's method with default solver parameters or MUMPS direct solver.

After convergence at full load, compute the Cauchy stress σ = (1/J) * F * S * F.T, where S is the second Piola-Kirchhoff stress derived from the strain energy.

Compute the von Mises equivalent stress from the Cauchy stress as σ_vm = sqrt(3/2 * dev(σ):dev(σ)), where dev(σ) = σ - (1/3)*tr(σ)*I.
