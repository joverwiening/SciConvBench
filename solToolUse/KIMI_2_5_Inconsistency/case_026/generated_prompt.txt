The simulation solves a 2D plane-stress linear elasticity problem on a right triangular domain using FEniCS legacy (dolfin).

The domain is defined by vertices (0,0), (1,0), and (0,0.5) with unit thickness.

The mesh consists of 64 triangular elements.

Material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m^3, and gravitational acceleration g = 9.81 m/s^2 acting in the negative y-direction.

The constitutive law uses the reduced plane-stress formulation with the standard compliance matrix for isotropic linear elasticity.

The left edge at x = 0 is fully clamped with zero displacement Dirichlet boundary conditions applied to both components.

The hypotenuse boundary is defined by the line x + 2y = 1.

A surface traction is applied on the hypotenuse with σ_yy = -5e3*sin(π*x) Pa, where x is the global x-coordinate as explicitly stated in the load definition.

The variational problem uses a vector-valued Lagrange finite element space of degree 1 for displacement.

The bilinear form integrates the plane-stress stiffness tensor contracted with the symmetric gradient of test and trial functions.

The linear form includes body forces from gravity (0, -ρ*g) and the specified surface traction on the hypotenuse.

A direct linear solver (MUMPS or default LU) solves the resulting symmetric positive-definite system.

Post-processing computes the Cauchy stress tensor from the displacement gradient using the plane-stress constitutive relation.

The von Mises equivalent stress is computed from the in-plane stress components as sqrt(σ_xx^2 + σ_yy^2 - σ_xx*σ_yy + 3*σ_xy^2).

Output includes the displacement field and von Mises stress distribution for visualization.
