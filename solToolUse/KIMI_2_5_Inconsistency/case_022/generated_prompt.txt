The task is to solve a 2D plane-stress linear elasticity problem using legacy FEniCS (dolfin).

The domain is a rectangular plate with Omega = (0, 1.0) x (0, 0.20) meters.

Use a uniform structured mesh with 20 subdivisions in the x-direction and 4 subdivisions in the y-direction.

The material properties are Young's modulus E = 200 GPa and Poisson's ratio nu = 0.30.

The plane-stress formulation uses unit thickness t = 1.0 m.

Compute the Lamé parameters as lambda = E*nu/((1+nu)*(1-2*nu)) and mu = E/(2*(1+nu)).

The constitutive law for plane stress uses the modified lambda* = 2*lambda*mu/(lambda+2*mu) or equivalently E*nu/(1-nu^2), with mu = E/(2*(1+nu)).

The variational form uses the strain epsilon(u) = 0.5*(grad(u) + grad(u).T) and stress sigma = lambda* * tr(epsilon)*Identity(2) + 2*mu*epsilon.

The function space is a vector-valued Lagrange space of degree 1 for displacement u = (u_x, u_y).

Apply Dirichlet boundary conditions: on the left edge (x = 0), set u_x = 0 and u_y = 0. On the right edge (x = 1), set u_x = 0.001 and u_y = 0.

The top edge (y = 0.20) and bottom edge (y = 0) are traction-free (natural boundary conditions).

Solve the variational problem: find u in V such that inner(sigma(u), epsilon(v))*dx = 0 for all test functions v, using a direct linear solver (MUMPS or LU).

Save a color map of the u_x displacement component as q1_ux.png.

Save the displacement field in XDMF format for visualization.
