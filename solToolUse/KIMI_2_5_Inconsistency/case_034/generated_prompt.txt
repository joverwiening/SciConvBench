The L-shaped domain is defined as the unit square [0,1]×[0,1] with the upper-right quadrant [0.5,1]×[0.5,1] removed.

Use FEniCS legacy (dolfin) to solve a 2D plane-stress linear elasticity problem.

Create the L-shaped geometry by defining the outer unit square [0,1]×[0,1] and subtracting the inner square [0.5,1]×[0.5,1].

Generate a mesh with 64 elements per edge resolution on the L-shaped domain.

Define the vector-valued function space V = VectorFunctionSpace(mesh, 'P', 1) for displacement.

Set material properties: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s².

Compute Lamé parameters: μ = E/(2*(1+ν)) and λ = E*ν/((1+ν)*(1-ν)) for plane stress.

Define the strain tensor ε(u) = 0.5*(grad(u) + grad(u).T).

Define the stress tensor σ(u) = 2*μ*ε(u) + λ*tr(ε(u))*Identity(2) using the reduced plane-stress constitutive law.

Apply body force due to gravity: f = (0, -ρ*g) acting in the negative y-direction.

Apply traction boundary condition on the outer right edge where x = 1 and y ∈ [0, 0.5]: σ_yy = -2.65e4*y (compressive, negative sign), with zero shear traction.

The traction vector on the loaded boundary is t = (0, -2.65e4*y).

Identify boundaries: left edge (x=0) for Dirichlet BC, outer right edge (x=1, y≤0.5) for traction loading, all other boundaries are traction-free.

Fix the left boundary (x=0) with Dirichlet BC: u = (0, 0).

Define the variational form: Find u ∈ V such that inner(σ(u), ε(v))*dx = inner(f, v)*dx + inner(t, v)*ds for all v ∈ V.

Use a direct linear solver (MUMPS or default LU) to solve the linear system.

Compute displacement field u and extract the magnitude for visualization.

Compute stress field by projecting σ(u) to a TensorFunctionSpace of degree 1.

Extract in-plane stress components σ_xx, σ_yy, σ_xy from the computed stress tensor.

Compute von Mises equivalent stress as σ_vm = sqrt(σ_xx² + σ_yy² - σ_xx*σ_yy + 3*σ_xy²).

Output displacement magnitude and von Mises stress distributions for visualization.
