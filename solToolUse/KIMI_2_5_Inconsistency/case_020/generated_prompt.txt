Solve a 2D plane-stress linear elasticity problem for a rectangular plate using FEniCS legacy (dolfin).

Define the domain as Omega = (0, 1.0) x (0, 0.20) meters.

Create a uniform structured mesh with 40 subdivisions in the x-direction and 8 subdivisions in the y-direction.

Define the vector-valued function space V = VectorFunctionSpace(mesh, 'P', 1) for displacement u = (u_x, u_y).

Set material properties: Young's modulus E = 200e9 Pa, Poisson's ratio nu = 0.30.

Compute the plane-stress constitutive parameters: mu = E / (2.0 * (1.0 + nu)) and lambda_ = E * nu / ((1.0 + nu) * (1.0 - nu)).

Define the strain tensor epsilon(u) = 0.5 * (grad(u) + grad(u).T).

Define the stress tensor sigma(u) = lambda_ * tr(epsilon(u)) * Identity(2) + 2 * mu * epsilon(u).

Apply Dirichlet boundary conditions on the left edge (x = 0): u_x = 0 and u_y = 0, using a function that identifies x[0] < DOLFIN_EPS.

Define the variational problem: Find u in V such that inner(sigma(u), epsilon(v)) * dx == dot(t, v) * ds for all v in V, where t = (0, -2000) is the traction vector.

Mark the top edge (y = 0.20) with a boundary measure ds where the traction is applied, using a function that identifies abs(x[1] - 0.20) < DOLFIN_EPS.

Solve the linear variational problem using a direct linear solver (solve(a == L, u, bc)).
