Create the file beammix.inp in the working directory with the provided content.
Run CalculiX using either ccx -i beammix or ccx beammix.
Determine whether the run succeeded by checking beammix.sta for 'JOB COMPLETED'.
Write a results.json file in the working directory with the schema: {"solver": "calculix", "case_id": "beammix", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Record the version string from ccx -v in ccx_version.
Record the exact ccx command used in notes.
If the run failed, include the error message and the file indicating failure in notes.
