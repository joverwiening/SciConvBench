The agent will create a file named beampfix.inp in the working directory.
The agent will write the provided CalculiX input deck content into beampfix.inp.
The agent will execute the CalculiX analysis using the command ccx -i beampfix.
The agent will check the beampfix.sta file for the string 'JOB COMPLETED' to determine if the run succeeded.
The agent will create a file named results.json in the working directory.
The results.json file will contain the field "solver" with the value "calculix".
The results.json file will contain the field "case_id" with the value "beampfix".
The results.json file will contain the field "status" with the value "success" if 'JOB COMPLETED' is found in beampfix.sta, otherwise "error".
The results.json file will contain the field "ccx_version" with the version string obtained from running ccx -v.
The results.json file will contain the field "artifacts" as an empty list.
The results.json file will contain the field "notes" recording the exact ccx command used.
If the CalculiX run failed, the "notes" field will also include the error message and the file that indicated the failure.
