Create a file named ball.inp in the working directory with the provided content.
Execute the CalculiX analysis using the command ccx -i ball.
If the command fails, attempt to execute the CalculiX analysis using the command ccx ball.
Check the ball.sta file for the string 'JOB COMPLETED' to determine if the run succeeded.
Obtain the CalculiX version string by running ccx -v.
Create a results.json file in the working directory.
The results.json file must contain the fields "solver", "case_id", "status", "ccx_version", "artifacts", and "notes".
Set "solver" to "calculix".
Set "case_id" to "ball".
Set "status" to "success" if 'JOB COMPLETED' is found in ball.sta, otherwise set it to "error".
Set "ccx_version" to the version string obtained from ccx -v.
Set "artifacts" to an empty list.
Set "notes" to the exact ccx command used for the analysis.
If the run failed, append the error message and the file indicating the failure to the "notes" field.
