Create the file beamcontact.inp in the working directory with the provided content.
Run CalculiX using the command `ccx -i beamcontact` or `ccx beamcontact`, whichever is functional on the system.
Determine the success of the run by checking the `beamcontact.sta` file for the string 'JOB COMPLETED'.
Create a `results.json` file in the working directory.
The `results.json` file must have the following schema:
{
  "solver": "calculix",
  "case_id": "beamcontact",
  "status": "success" | "error",
  "ccx_version": "...",
  "artifacts": [],
  "notes": "..."
}
Populate the `ccx_version` field with the version string obtained from running `ccx -v` or its closest equivalent.
Populate the `notes` field with the exact CalculiX command used for the run.
If the CalculiX run failed, include the error message and the file that indicated the failure in the `notes` field.
