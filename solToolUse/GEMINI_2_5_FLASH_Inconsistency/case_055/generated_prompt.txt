The agent will create a file named `uprofile.inp` in the working directory.
The content of `uprofile.inp` will be exactly as provided in the input deck section.
The agent will run CalculiX using either `ccx -i uprofile` or `ccx uprofile`, selecting the command that works on the system.
The agent will determine if the run succeeded by checking the `uprofile.sta` file for a successful termination message such as 'JOB COMPLETED'.
The agent will write a `results.json` file in the working directory.
The `results.json` file will adhere to the specified schema: {"solver": "calculix", "case_id": "uprofile", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
The `ccx_version` field in `results.json` will contain the version string obtained from `ccx -v` or its closest equivalent.
The `notes` field in `results.json` will record the exact CalculiX command used.
If the CalculiX run fails, the `notes` field will also include the error message and the name of the file that indicated the failure.
