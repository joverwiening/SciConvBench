Create a file named `achtelc.inp` in the working directory with the provided content.
Execute the CalculiX analysis using the command `ccx -i achtelc`.
Verify the success of the CalculiX run by checking the `achtelc.sta` file for the string 'JOB COMPLETED'.
If the run is successful, set the status in `results.json` to "success".
If the run fails, set the status in `results.json` to "error", and record the error message and the file indicating the failure in the `notes` field.
Determine the CalculiX version string by running `ccx -v`.
Create a `results.json` file in the working directory with the following structure:
{
  "solver": "calculix",
  "case_id": "achtelc",
  "status": "success" | "error",
  "ccx_version": "...",
  "artifacts": [],
  "notes": "..."
}
Populate the `ccx_version` field with the version string obtained from `ccx -v`.
Populate the `notes` field with the exact CalculiX command used for the run.
