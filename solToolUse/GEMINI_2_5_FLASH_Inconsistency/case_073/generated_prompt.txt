Create the file beamheatplas.inp in the working directory.
The beamheatplas.inp file must be based on the provided input deck, with the following modifications to ensure a purely mechanical analysis:
Remove the *SPECIFIC HEAT and *CONDUCTIVITY lines from the *MATERIAL block.
Remove the *PHYSICAL CONSTANTS line.
Remove the *INITIAL CONDITIONS,TYPE=TEMPERATURE block.
Change the *COUPLED TEMPERATURE-DISPLACEMENT,STEADY STATE,DIRECT line to *STATIC,NLGEOM.
Remove the *DFLUX block.
Remove the NT line from the *NODE PRINT block.
Run CalculiX using the command ccx -i beamheatplas.
Determine whether the run succeeded by checking the beamheatplas.sta file for the string 'JOB COMPLETED'.
Write a results.json file in the working directory with the following schema:
{
  "solver": "calculix",
  "case_id": "beamheatplas",
  "status": "success" | "error",
  "ccx_version": "...",
  "artifacts": [],
  "notes": "..."
}
Record the version string from ccx -v in the ccx_version field.
Record the exact ccx command used in the notes field.
If the run failed, include the error message and the file that indicated the failure in the notes field.
