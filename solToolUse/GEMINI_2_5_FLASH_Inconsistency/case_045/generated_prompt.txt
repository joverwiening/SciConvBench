The simulation will be implemented using FEniCS legacy (dolfin).
The problem is a small-strain linear elasticity problem in 2D plane stress.
The domain Ω is a rectangular plate defined as (0, 1.0) x (0, 0.20) m.
The top half subdomain Ω_Al is (0, 1.0) x (0.10, 0.20) m and consists of Aluminium.
The bottom half subdomain Ω_Steel is (0, 1.0) x (0.00, 0.10) m and consists of Steel.
A structured mesh of 80 x 16 elements will be used over Ω.
The model uses small-strain linear elasticity for the displacement field u = (u_x, u_y).
For Aluminium (Ω_Al), Young's modulus E = 70 GPa and Poisson's ratio ν = 0.30.
For Steel (Ω_Steel), Young's modulus E = 200 GPa and Poisson's ratio ν = 0.30.
A perfect bond is enforced at the interface y = 0.10 m, ensuring continuity of displacement and traction.
The left edge (x = 0) is fixed, with u_x = 0 and u_y = 0.
The right edge (x = 1) has a uniform downward line traction t = (0, -5000) N/m.
The top and bottom edges are traction-free.
The displacement finite element space will use continuous piecewise linear (P1) elements.
The problem will be solved using a direct linear solver.
Cell markers or a DG0 material field will be used to assign different elastic moduli to the subdomains within one conforming displacement space.
The 2D strip will be treated as plane stress with unit thickness, using the reduced plane-stress constitutive law.
A colour map of the magnitude of the displacement field |u| will be saved as q7_disp.png.
The displacement field will be saved in XDMF format.
