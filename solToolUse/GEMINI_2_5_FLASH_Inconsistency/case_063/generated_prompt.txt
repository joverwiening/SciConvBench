Create a file named beamfsh1.inp in the working directory.
The content of beamfsh1.inp must be exactly as provided in the "Input deck (beamfsh1.inp)" section.
Run CalculiX using the command ccx -i beamfsh1 or ccx beamfsh1, using whichever command works on the system.
Determine if the CalculiX run succeeded by checking the beamfsh1.sta file for the phrase 'JOB COMPLETED'.
Create a file named results.json in the working directory.
The results.json file must adhere to the specified JSON schema.
The "solver" field in results.json must be "calculix".
The "case_id" field in results.json must be "beamfsh1".
The "status" field in results.json must be "success" if 'JOB COMPLETED' is found in beamfsh1.sta, otherwise it must be "error".
The "ccx_version" field in results.json must contain the version string obtained from running ccx -v or its closest equivalent.
The "artifacts" field in results.json must be an empty array.
The "notes" field in results.json must record the exact ccx command used.
If the CalculiX run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
