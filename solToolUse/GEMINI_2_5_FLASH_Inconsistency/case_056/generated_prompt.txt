Create the file membrane3.inp in the working directory with the provided content.
Run CalculiX using either `ccx -i membrane3` or `ccx membrane3`, selecting the command that works on the system.
Determine the CalculiX version by executing `ccx -v` or the closest equivalent command.
Check the `membrane3.sta` file for the string 'JOB COMPLETED' to determine if the run succeeded.
Create a `results.json` file in the working directory.
The `results.json` file must contain the key "solver" with the value "calculix".
The `results.json` file must contain the key "case_id" with the value "membrane3".
The `results.json` file must contain the key "status" with the value "success" if the run completed successfully, or "error" otherwise.
The `results.json` file must contain the key "ccx_version" with the version string obtained from `ccx -v`.
The `results.json` file must contain the key "artifacts" with an empty list as its value.
The `results.json` file must contain the key "notes" with the exact ccx command used for the simulation.
If the run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
