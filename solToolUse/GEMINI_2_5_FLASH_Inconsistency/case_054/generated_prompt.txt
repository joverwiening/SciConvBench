Create the file dloadlinI.inp in the working directory.
The dloadlinI.inp file defines a finite element analysis model for a cantilever plate.
The model uses C3D8I elements.
The nodes are defined with their coordinates.
The elements are defined using the C3D8I type and are grouped into the elall set.
The material for the elements is steel.
Steel has an elastic modulus of 209000.0 MPa and a Poisson's ratio of 0.3.
Steel has a density of 7.85e-09.
Boundary conditions fix nodes in the 'left' set in all directions (1, 2, 3).
The analysis step is a static analysis with nonlinear geometry considerations.
The analysis allows for up to 10000 increments.
A distributed pressure load of 0.001 is applied to the elements in the elall set on face 2.
Reaction forces for the 'left' nodes are printed to the output file with a frequency of 100.
Stress values for all elements in the 'elall' set are printed to the output file.
Run CalculiX using either `ccx -i dloadlinI` or `ccx dloadlinI`.
Determine whether the run succeeded by checking `dloadlinI.sta` for 'JOB COMPLETED'.
Write a `results.json` file in the working directory.
The `results.json` file schema is: {"solver": "calculix", "case_id": "dloadlinI", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Record the CalculiX version string from `ccx -v` in the `ccx_version` field.
Record the exact ccx command used in the `notes` field.
If the run failed, include the error message and the file indicating the failure in the `notes` field.
