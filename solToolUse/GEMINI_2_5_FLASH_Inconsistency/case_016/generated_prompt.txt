The simulation will use FEniCS legacy (dolfin).
The problem is an incompressible finite-strain hyperelasticity problem.
The solver will use a mixed displacement-pressure neo-Hookean formulation.
Newton's method will be used for solving the nonlinear system.
The geometry is a rectangular strip Ω = (0, 1.0) x (0, 0.20) m.
A circular hole of radius 0.04 m is centered at (0.50, 0.10) within the strip.
The model is a large-deformation isotropic incompressible neo-Hookean solid.
The unknowns are displacement u = (u_x, u_y) and hydrostatic pressure p.
The problem is solved under plane strain conditions.
The material properties are Young's modulus E = 5 MPa and Poisson's ratio ν = 0.5.
The left edge (x = 0) is fixed, with u_x = 0 and u_y = 0.
A uniform follower pressure P_hole = 0.10 MPa is applied on the hole boundary.
The follower pressure is applied as traction sigma*n = -P_hole*n in the deformed configuration, using the current normal.
The right, top, and bottom edges are traction-free.
The displacement field will be represented using continuous piecewise quadratic finite elements (P2).
The pressure field will be represented using continuous piecewise linear finite elements (P1).
A magnified (x5) plot of the deformed configuration will be saved as q13_def.png.
The von Mises stress field, computed from the Cauchy stress, will be saved as q13_vm.png.
The displacement field will be saved in XDMF format.
