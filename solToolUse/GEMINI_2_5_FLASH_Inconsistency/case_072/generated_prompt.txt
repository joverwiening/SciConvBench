Create a file named testmortar.inp in the working directory.
The content of testmortar.inp must be exactly as provided in the "Input deck" section.
Run CalculiX using either the command ccx -i testmortar or ccx testmortar, selecting the command that functions correctly on the system.
Determine if the CalculiX run succeeded by examining the testmortar.sta file for the phrase 'JOB COMPLETED'.
Create a file named results.json in the working directory.
The results.json file must adhere to the specified JSON schema.
The "solver" field in results.json must be "calculix".
The "case_id" field in results.json must be "testmortar".
The "status" field in results.json must be "success" if the run completed successfully, or "error" if it failed.
The "ccx_version" field in results.json must contain the version string obtained from running ccx -v or its closest equivalent.
The "artifacts" field in results.json must be an empty array.
The "notes" field in results.json must record the exact ccx command used for the analysis.
If the CalculiX run failed, the "notes" field must also include the error message and specify which file indicated the failure.
