The simulation will use FEniCS legacy (dolfin).
The solver will implement small-strain linear elasticity in 2D plane-stress.
A vector-valued displacement space will be used.
A direct linear solver will be used.
The material properties are Young's Modulus E=70e9 Pa and Poisson's ratio ν=0.33.
The geometry is a right triangular domain with vertices at (0,0), (1,0), and (0,0.5).
The domain will be treated as plane stress with unit thickness, using the reduced plane-stress constitutive law.
Boundary conditions include u_x=0 on the left edge (x=0) and u_y=0 on the bottom edge (y=0).
A vertical point load of -5 kN will be applied at the point (0.5, 0.25) using `PointSource`.
The mesh will be generated by creating a rectangular mesh for the bounding box [0,1] x [0,0.5] with 64 divisions along the x-axis and 32 divisions along the y-axis.
The triangular domain will be extracted from this rectangular mesh.
The simulation will compute the displacement distribution.
The simulation will compute the von Mises stress distribution from the in-plane Cauchy stress field.
