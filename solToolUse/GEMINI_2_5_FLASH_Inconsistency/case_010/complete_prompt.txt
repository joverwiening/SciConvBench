Case ID: case_010
Use FEniCS legacy (dolfin).
Solver: small-strain orthotropic elasticity in legacy FEniCS (dolfin); solve the 2D plane-stress variational problem with an angle-rotated stiffness tensor and a direct linear solver.
Task:
Solve Solid Mechanics Problem 8 from the paper: an orthotropic lamina in plane stress with rotated material axes.
Case details:
Geometry:
Let Ω = (0, 1.0) x (0, 0.20) m be a rectangular plate in 2D plane stress.
Mesh:
Structured mesh 50 x 25 over Ω.
Model:
Small-strain orthotropic plane-stress elasticity for displacement u = (u_x, u_y).
Material:
The local material axes (1-2) are rotated by theta = 30 degrees anticlockwise with respect to the global x-y axes.
Local orthotropic properties:
E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, nu12 = 0.25.
Use the standard plane-stress reduced stiffness matrix [Q] and rotate it to the global frame.
Boundary conditions:
Bottom edge (y = 0): fixed, u_x = 0, u_y = 0.
Top edge (y = 0.20): uniform downward traction t = (0, -10 MPa*m).
Vertical sides (x = 0 and x = 1): traction-free.
Outputs:
Save a colour map of u_x as q8_ux.png.
Save a colour map of von Mises stress as q8_vm.png.
Write u and stress fields to q8_solution.xdmf.
Implementation notes:
Build the constitutive tensor in the material frame and rotate it into the global x-y frame by +30 degrees before assembly.
Interpret the top-edge load as a line traction per unit thickness.
