Use FEniCS legacy (dolfin).
Solve the 2D plane-stress variational problem for small-strain orthotropic elasticity.
The computational domain is a rectangle Ω = (0, 1.0) x (0, 0.20) m.
A structured mesh of 50 x 25 elements is used over Ω.
The model uses small-strain orthotropic plane-stress elasticity for displacement u = (u_x, u_y).
The local material axes are rotated by +30 degrees anticlockwise with respect to the global x-y axes.
The local orthotropic material properties are E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
The standard plane-stress reduced stiffness matrix [Q] is built in the material frame and rotated by +30 degrees to the global frame.
The bottom edge (y = 0) has fixed boundary conditions: u_x = 0 and u_y = 0.
The top edge (y = 0.20) has a uniform downward line traction t = (0, -10 MPa*m) per unit thickness.
The vertical sides (x = 0 and x = 1) are traction-free.
A direct linear solver of type 'lu' is used.
A colour map of the u_x displacement field is saved as q8_ux.png.
A colour map of the von Mises stress field is saved as q8_vm.png.
The displacement and stress fields are written to q8_solution.xdmf.
