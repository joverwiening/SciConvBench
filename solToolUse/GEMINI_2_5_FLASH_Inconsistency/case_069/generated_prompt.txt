Create a file named beamtor.inp in the working directory.
Populate beamtor.inp with the provided CalculiX input deck content.
Execute the CalculiX analysis using the command ccx -i beamtor.
Verify the success of the analysis by checking the beamtor.sta file for the string 'JOB COMPLETED'.
Create a results.json file in the working directory.
The results.json file must adhere to the specified schema: {"solver": "calculix", "case_id": "beamtor", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Record the CalculiX version string obtained from ccx -v in the "ccx_version" field.
Record the exact ccx command used in the "notes" field.
If the run fails, include the error message and the name of the file that indicated the failure in the "notes" field.
