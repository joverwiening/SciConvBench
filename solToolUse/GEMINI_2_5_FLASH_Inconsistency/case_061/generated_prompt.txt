Create a file named segmentunsmooth.inp in the working directory.
The content of segmentunsmooth.inp must be the provided input deck, with the element type C3D10 changed to C3D20R, and the concentrated load on node 260 changed from direction 2 (y-direction) to direction 1 (x-direction).
Run CalculiX using the command `ccx -i segmentunsmooth` or `ccx segmentunsmooth`, whichever is functional on the system.
Determine the success of the run by checking the `segmentunsmooth.sta` file for the string 'JOB COMPLETED'.
Obtain the CalculiX version string by executing `ccx -v`.
Create a `results.json` file in the working directory with the following schema:
{
  "solver": "calculix",
  "case_id": "segmentunsmooth",
  "status": "success" | "error",
  "ccx_version": "...",
  "artifacts": [],
  "notes": "..."
}
Set `status` to "success" if 'JOB COMPLETED' is found in `segmentunsmooth.sta`, otherwise set it to "error".
Record the obtained CalculiX version string in `ccx_version`.
Record the exact ccx command used in `notes`.
If the run failed, also include the error message and specify that `segmentunsmooth.sta` indicated the failure in the `notes` field.
