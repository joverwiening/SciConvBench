The simulation will use FEniCS legacy (dolfin).
The problem is a 2D plane-stress variational problem of small-strain linear elasticity.
A direct linear solver will be used.
The geometry is a rectangular plate Ω = (0, 1.0) x (0, 0.20) m.
The mesh is a structured 100 x 20 grid over Ω.
The model uses linear elasticity for displacement u = (u_x, u_y).
The material has a Poisson's ratio ν = 0.30.
The Young's modulus varies with height as E(y) = 100 GPa + 100 GPa*(y/0.20) for y in [0, 0.20] m.
The left edge (x = 0) is fixed, with u_x = 0 and u_y = 0.
The right edge (x = 1) has a uniform traction t = (2e6 Pa*m, 0) per unit thickness.
The top and bottom edges are traction-free.
The 2D strip is treated as plane stress with unit thickness, using the reduced plane-stress constitutive law.
A colour map of the magnitude of displacement |u| will be saved as q9_disp.png.
The displacement field will be saved in XDMF format.
