The simulation will use FEniCS legacy (dolfin).
The solver will implement small-strain linear elasticity.
The problem will be solved on a square domain defined by [-1,1]^2 with a slit from (0,0) to (1,0).
Vector Lagrange elements will be used for the finite element solution.
Dirichlet boundary conditions will be enforced using an exact displacement field u0.
The exact displacement field u0 will be defined in polar coordinates (r, theta) centered at the crack tip (0,0) as:
u_x = lambda_param * (1 / (2 * mu)) * r^q_exponent * ( (kappa + q_exponent) * cos(q_exponent * theta) - q_exponent * cos((q_exponent - 2) * theta) )
u_y = lambda_param * (1 / (2 * mu)) * r^q_exponent * ( (kappa - q_exponent) * sin(q_exponent * theta) + q_exponent * sin((q_exponent - 2) * theta) )
The parameter lambda_param is 0.5444837367825.
The parameter q_exponent is 0.5430755788367.
The material is assumed to be in plane strain.
Poisson's ratio (nu) is assumed to be 0.3.
Young's Modulus (E) is assumed to be 1.0.
The shear modulus (mu) is derived as E / (2 * (1 + nu)) = 1.0 / (2 * (1 + 0.3)) = 0.3846153846.
The plane strain constant kappa is derived as 3 - 4 * nu = 3 - 4 * 0.3 = 1.8.
A mesh will be generated for the domain, ensuring it is fine enough to resolve the crack tip, with a baseline resolution around 30.
The slit will be represented as a single interior seam in a conforming mesh, ensuring displacement remains single-valued across the slit faces.
The elasticity variational form will be set up using the defined material properties and exact displacement field.
The problem will be solved using an iterative linear solver, specifically GMRES with ILU preconditioning.
The exact displacement field u0 will be imposed as Dirichlet boundary conditions on the slit faces and the outer square boundary.
