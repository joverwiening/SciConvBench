Case ID: case_033
Use FEniCS legacy (dolfin).
Solver: nonlinear hyperelasticity in legacy FEniCS (dolfin); solve the displacement-based compressible neo-Hookean problem with Newton's method.
Task:
Implement a DOLFIN solver for a 3D compressible neo-Hookean solid on the unit cube. Use Newton's method to minimize the total potential energy for the displacement field under body force and boundary traction.
Case details:
Geometry and mesh: UnitCube mesh with 16x16x16 cells. Function space: VectorFunctionSpace(mesh, "Lagrange", 1). Material: Young's modulus E = 10.0, Poisson ratio ν = 0.3. Kinematics: F = I + grad(u), C = F^T F, J = det(F). Boundary conditions and loads: clamp the face x = 0, apply body force b = (0, -0.5, 0), and apply boundary traction h = (0.1, 0, 0) on the natural boundary.
Implementation notes:
Use a displacement-only compressible neo-Hookean formulation with F = I + grad(u), C = F^T F, J = det(F), and solve the total potential by Newton iteration.
Use the UnitCube mesh with 16x16x16 cells and a first-order vector Lagrange displacement space.
Clamp the face x = 0, include body force b = (0, -0.5, 0), and apply boundary traction h = (0.1, 0, 0) on the natural boundary.
