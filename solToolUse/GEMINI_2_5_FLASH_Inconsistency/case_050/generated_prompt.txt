Create a file named scheibe.inp in the working directory.
The content of scheibe.inp must be exactly as provided in the "Input deck (scheibe.inp)" section.
Run CalculiX using the command ccx -i scheibe.
Determine the success of the run by checking the scheibe.sta file for a successful termination message such as 'JOB COMPLETED'.
Create a results.json file in the working directory.
The results.json file must adhere to the schema: {"solver": "calculix", "case_id": "scheibe", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Populate the "ccx_version" field with the version string obtained from running ccx -v.
Set the "status" field to "success" if the run completed successfully, otherwise set it to "error".
Record the exact ccx command used in the "notes" field.
If the run failed, also include the error message and the file that indicated the failure in the "notes" field.
