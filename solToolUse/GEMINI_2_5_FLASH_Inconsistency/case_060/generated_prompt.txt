The agent will create a file named axiplane.inp in the working directory.
The axiplane.inp file will contain the exact content provided in the "Input deck (axiplane.inp)" section.
The agent will run CalculiX using either the command ccx -i axiplane or ccx axiplane.
The agent will determine run success by checking the axiplane.sta file for the string 'JOB COMPLETED'.
The agent will create a results.json file in the working directory.
The results.json file will have the schema {"solver": "calculix", "case_id": "axiplane", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
The ccx_version field in results.json will contain the version string obtained from running ccx -v.
The notes field in results.json will record the exact ccx command used.
If the CalculiX run fails, the notes field in results.json will also include the error message and the file that indicated the failure.
