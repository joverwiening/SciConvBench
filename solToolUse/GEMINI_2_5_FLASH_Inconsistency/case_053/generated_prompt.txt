Create a file named c3d15.inp in the working directory.
The content of c3d15.inp must be exactly as provided in the input deck section.
Run CalculiX using the command ccx -i c3d15. If that command fails, use ccx c3d15.
Determine if the CalculiX run succeeded by checking the c3d15.sta file for the string 'JOB COMPLETED'.
Create a file named results.json in the working directory.
The results.json file must contain a JSON object with the following schema: {"solver": "calculix", "case_id": "c3d15", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Set the "status" field to "success" if 'JOB COMPLETED' is found in c3d15.sta, otherwise set it to "error".
Set the "ccx_version" field to the version string obtained by running the command ccx -v.
Set the "notes" field to the exact ccx command used to run the analysis.
If the CalculiX run failed, also include the error message and the name of the file that indicated the failure in the "notes" field.
