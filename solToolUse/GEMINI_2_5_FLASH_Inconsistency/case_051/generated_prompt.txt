Create the file axial.inp in the working directory.
The content of axial.inp must be exactly as provided in the input deck section.
Run CalculiX using either ccx -i axial or ccx axial.
Determine whether the run succeeded by checking axial.sta for 'JOB COMPLETED'.
Write a results.json file in the working directory.
The results.json file must have the schema: {"solver": "calculix", "case_id": "axial", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Record the version string from ccx -v in ccx_version.
Record the exact ccx command used in notes.
If the run failed, include the error message and the file indicating failure in notes.
