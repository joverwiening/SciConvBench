Create a file named beampt.inp in the working directory.
The content of beampt.inp must be exactly as provided in the "Input deck (beampt.inp)" section.
Run CalculiX using the command ccx -i beampt or ccx beampt, whichever works on the system.
Determine the success of the run by checking the beampt.sta file for a successful termination message such as 'JOB COMPLETED'.
Create a results.json file in the working directory.
The results.json file must adhere to the schema: {"solver": "calculix", "case_id": "beampt", "status": "success" | "error", "ccx_version": "...", "artifacts": [], "notes": "..."}.
Populate the "ccx_version" field with the version string obtained from running ccx -v.
Populate the "notes" field with the exact ccx command used for the analysis.
If the CalculiX run failed, the "notes" field must also include the error message and the name of the file that indicated the failure.
