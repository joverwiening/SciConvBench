## 4️⃣ Common “what‑if” scenarios  

| Situation | What to check / tweak |
|-----------|-----------------------|
| **CalculiX complains about `*OUTPUT, JSON`** | Make sure you are using a recent CalculiX version (≥ 2.19). Older releases only support the binary `.frd` output. |
| **No `RF` entries in the JSON** | You only asked for nodal displacements (`U`). Add `*NODE PRINT, NSET=ALL` and `RF` to the output block if you need reaction forces on the constrained nodes. |
| **You have a different geometry** | Keep the two `*STEP` blocks exactly as they are (they define the two pressure steps). Replace the `*NODE`, `*ELEMENT`, `*ELSET`, and `*SURFACE` sections with your own mesh definition. |
| **You want a *strict* node‑to‑element mapping** | In `parse_beamtor.py` replace the “representative element” logic with a proper mapping (e.g. loop over `step["E"]` to collect element connectivity, then assign each node the von Mises of the first element that contains it). |
| **You need a load‑displacement curve** | Add `*STEP` blocks for each load increment, then modify the parser to loop over **all** steps, pull the vertical `RF` of the constrained node and the vertical `U` of a reference node, and plot with `matplotlib`. |
| **You want strain‑energy** | Add `*EL PRINT, ENERGY` to the input deck and extend `extract_globals()` to also read `step["ENERGY"]`. |

## 5️⃣ Quick‑add‑on: Load‑Displacement Curve (optional)

If you ever decide you’d like a classic **P‑U curve**, just drop the following tiny helper script into the same folder and run it after the CalculiX run:

```python
#!/usr/bin/env python3
"""
ld_curve.py – extracts reaction force (RF) and vertical displacement (U)
for every step and plots a load‑displacement curve.
"""

import json, math, sys
from pathlib import Path
import matplotlib.pyplot as plt

def vec_norm(v):
    return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)

def load_json(fp):
    with fp.open() as f:
        return json.load(f)

def main():
    data = load_json(Path("results.json"))
    loads = []   # total vertical RF
    disps = []   # vertical U of node 2 (just an example)

    for i, step in enumerate(data, start=1):
        # sum of vertical reaction forces (assuming Z‑direction is vertical)
        total_rf = sum(node["value"][2] for node in step.get("RF", []))
        loads.append(total_rf)

        # vertical displacement of node 2 (change index if you prefer another node)
        u_node2 = next((n["value"][2] for n in step.get("U", []) if n["node"] == 2), 0.0)
        disps.append(u_node2)

    plt.figure()
    plt.plot(disps, loads, marker='o')
    plt.xlabel('Vertical displacement of node 2 (m)')
    plt.ylabel('Total vertical reaction force (N)')
    plt.title('Load‑Displacement Curve (all steps)')
    plt.grid(True)
    plt.tight_layout()
    plt.show()

if __name__ == "__main__":
    main()
```

*Run it*: `./ld_curve.py` (or `python3 ld_curve.py`).  
It will pop up a Matplotlib window with the curve for **all** steps (including the 1 MPa and 2 MPa cases).
