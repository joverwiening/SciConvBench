Just to recap the **one‑click workflow**:

1. **Install once**  

   ```bash
   pip install pandas numpy matplotlib seaborn openpyxl
   ```

2. **Edit the single line** near the top of the script  

   ```python
   raw_path = pathlib.Path("your_file.txt")   # ← replace with your actual file
   ```

3. **Run**  

   ```bash
   python process_table.py
   ```

   *Two plot windows will appear (scatter → log‑log). Close each to let the script finish.*

4. **Result** – a folder `cleaned_outputs/` next to the script containing  

   * `cleaned.csv` (comma‑separated, with headers)  
   * `cleaned.txt` (whitespace‑delimited, no header – matches the original style)  
   * `cleaned.jsonl` (JSON‑lines)  
   * `cleaned.xlsx` (Excel workbook)

If you run the script **as‑is**, it will auto‑create the tiny `sample.txt` example, process it, and you’ll see console output like:


### Quick “what‑if” tweaks (optional)

| What you might want to change | Where to edit |
|------------------------------|---------------|
| **Different flag rule** (e.g. treat `-1` as missing) | `fix_flag_column()` – replace the lambda. |
| **More numeric columns** (e.g. 5 numeric columns) | `cast_columns()` – add `c4`, `c5`, … to the loop. |
| **Header row present** | Change `header=None` to `header='infer'` (or supply a list) in `read_whitespace_file()`. |
| **Save with column headers** | Set `header=True` (or a list) in the `to_csv()` / `to_excel()` calls inside `write_outputs()`. |
| **Run headless (no plots)** | Comment out `plot_scatter(df)` and `plot_loglog_fit(df)` in `main()`. |
| **Different output folder** | Change `out_dir = pathlib.Path.cwd() / "cleaned_outputs"` to any path you like. |
| **Add extra diagnostics** (summary stats, etc.) | Insert `print(df.describe())` wherever you need it. |
