Use FEniCS legacy (dolfin) Python to solve the 2‑D plane‑stress linear elasticity problem on the rectangle Ω = (0, 1.0) × (0, 0.20) m.  
Create a structured mesh of 80 cells in the x‑direction and 16 cells in the y‑direction covering Ω.  
Define two subdomains with a DG0 cell marker:  
- Ω_Al (top half, y ∈ (0.10, 0.20) m) assigned aluminium with Young’s modulus E = 70 GPa and Poisson’s ratio ν = 0.30.  
- Ω_Steel (bottom half, y ∈ (0.00, 0.10) m) assigned steel with Young’s modulus E = 200 GPa and Poisson’s ratio ν = 0.30.  
For each material compute the plane‑stress constitutive tensor C = E/(1‑ν²) [[1, ν, 0],[ν, 1, 0],[0, 0,(1‑ν)/2]] assuming unit thickness.  
Define the vector function space V = VectorFunctionSpace(mesh, "CG", 1) for the displacement field u = (u_x, u_y).  
Set the strain ε(u) = sym(grad(u)) and the stress σ = C : ε(u) using the material marker to select the appropriate C in each cell.  
Apply Dirichlet boundary conditions u_x = 0, u_y = 0 on the left edge x = 0.  
Apply a uniform downward Neumann traction t = (0, ‑5000) N/m on the right edge x = 1 as a surface integral; the top (y = 0.20) and bottom (y = 0) edges are traction‑free.  
Form the variational problem ∫_Ω σ(u):ε(v) dx = ∫_{Γ_N} t·v ds and assemble the linear system.  
Solve the linear system with a direct linear solver (e.g., PETSc LU).  
Compute the displacement magnitude |u| = sqrt(u_x² + u_y²) and save a colour map as q7_disp.png.  
Save the full displacement field u to an XDMF file named displacement.xdmf.
