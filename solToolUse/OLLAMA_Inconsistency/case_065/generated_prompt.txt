The *CLOAD line that gives the same result as  

```abaqus
*DLOAD, EALL, NEWTON
```  

is

```abaqus
*CLOAD, NSET=EALL, OP=NEW
EALL, 2, -26013.0
```

*Explanation*  

- **NSET=EALL** – the node set must contain exactly the nodes that belong to the element set `EALL`.  
- **OP=NEW** – makes the prescribed nodal forces Newtonian (follower) loads, the counterpart of the `NEWTON` option in *DLOAD.  
- **2** – is the global Y‑direction degree of freedom (U2).  
- **‑26013.0** – is the equivalent nodal force (negative because the original load acts in the –Y direction).  

Insert this line (after the node‑set `EALL` has been defined) into your Abaqus input file and the concentrated nodal loads will reproduce exactly the effect of the original `*DLOAD, EALL, NEWTON` command.
