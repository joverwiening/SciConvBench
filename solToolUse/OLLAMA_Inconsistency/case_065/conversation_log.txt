Q: Which node set, direction, and magnitude should be used for the nodal point load that will replace the Newtonian body‑force in the analysis?
A: **Answer – Nodal point‑load that replaces the Newtonian body‑force**

| Item | What to use | How to obtain it (formula / rule) |
|------|-------------|-----------------------------------|
| **Node set** | **All nodes that belong to the volume (or sub‑volume) where the body‑force acts**.  In most commercial FE codes this is created as a *node‑set* (e.g., `BODY_FORCE_NODES`, `ALLVOL_NODES`, `SET1`).  If the body‑force is only applied to a part of the model, the node‑set must contain **exactly the nodes of that part**. |
| **Direction** | The **unit vector of the body‑force** (the same direction that the body‑force vector points to).  For a gravity load it is usually `‑Y` (or `‑Z` in a 2‑D/3‑D model that uses Z as vertical).  Write it as a 3‑component vector `d = [d₁ d₂ d₃]` with ‖d‖ = 1. |
| **Magnitude** | The **equivalent nodal load** that gives the same resultant as the continuous body‑force.  Two common ways to obtain it are:  <br>1. **Consistent (exact) distribution** – compute the element‑level load vector `fᵉ = ∫ₑ Nᵀ b dV` (where `b` is the body‑force per unit volume and `N` the shape‑function matrix) and then assemble the contributions to the global nodes.  <br>2. **Lumped (simplified) distribution** – take the total resultant of the body‑force and divide it equally (or proportionally to the nodal “share of volume”) among the nodes in the set.  <br>   • **Resultant of the body‑force**:  <br>  `R = b · V`  (vector, where `V` is the total volume of the region).  <br>   • **Lumped load per node** (if you choose equal sharing):  <br>  `P_node = (R · d) / N_nodes`  (scalar magnitude in the direction `d`).  <br>   • **If you prefer a volume‑weighted share** (more accurate for non‑uniform meshes):  <br>  `P_i = b · V_i`  where `V_i` is the “nodal volume” (e.g., one‑third of the surrounding element volumes in a linear tetrahedral mesh).  <br>   • **Sign convention** – use the same sign convention that the solver expects for point loads (positive in the direction of `d`). |

---

### Step‑by‑step recipe (typical for a uniform body‑force)

1. **Identify the region** where the body‑force `b = [b₁ b₂ b₃]` (N / m³) acts.  
2. **Create a node‑set** that contains every node belonging to that region.  
   *In Abaqus:* `*Nset, nset=BODY_FORCE_NODES, generate` (list node IDs).  
   *In ANSYS:* `NSEL, ALL` → `CM, BODY_FORCE_NODES, NODE`.  
3. **Determine the direction vector** `d = b / ‖b‖`.  
   *Example:* for gravity `b = [0, -9.81·ρ, 0]` → `d = [0, -1, 0]`.  
4. **Compute the total resultant** `R = b·V`.  
   - If the material density ρ is known, `b = ρ g`.  
   - `V` can be obtained from the model (sum of element volumes).  
5. **Distribute the load to the nodes**  
   - **Consistent method** – let the solver generate the equivalent nodal loads automatically (most codes have a “*DLOAD, TYPE=BODY” → “*DLOAD, TYPE=POINT” conversion option).  
   - **Lumped method** – assign `P_node = (R·d) / N_nodes` to each node in the set.  
6. **Apply the point load** to the node‑set in the chosen direction.  
   *In Abaqus:* `*Cload, nset=BODY_FORCE_NODES, dof=2` (for Y‑direction) → `P_node`.  
   *In ANSYS:* `F, NODE_SET, FY, P_node`.  

---

### Quick example (uniform gravity on a solid cube)

| Parameter | Value |
|-----------|-------|
| Body‑force per unit volume `b` | `[0, -9.81·ρ, 0]` N/m³ (ρ = 7800 kg/m³ → `b = [0, -7.65×10⁴, 0]` N/m³) |
| Total volume `V` | `0.1 m³` |
| Resultant `R` | `b·V = [0, -7.65×10³, 0]` N |
| Node set | All 8 corner nodes of the cube (`BODY_FORCE_NODES`) |
| Number of nodes `N_nodes` | 8 |
| Direction `d` | `[0, -1, 0]` |
| Lumped magnitude per node | `P_node = (|R|)/N_nodes = 7.65×10³ N / 8 ≈ 956 N` (acting in the –Y direction) |

Thus, **the nodal point load to be entered is**:

- **Node set:** `BODY_FORCE_NODES` (the 8 corner nodes)  
- **Direction:** –Y (or DOF = 2 in a 3‑D model)  
- **Magnitude:** `‑956 N` (negative sign indicates the –Y direction) for each node, or the equivalent consistent load vector if the solver generates it automatically.

---

### Bottom line – What you must specify in the input file

```text
*Node Set (or NSEL/CM)   →  BODY_FORCE_NODES   ← all nodes of the body‑force region
*Direction                →  d = [0, -1, 0]    ← same as the body‑force vector
*Magnitude (per node)     →  P_node = (b·V)/N_nodes   (or use the consistent load vector)
```

Providing **exactly** those three pieces of information (node set, direction, magnitude) satisfies the *COMPLETE* requirement for replacing the Newtonian body‑force with an equivalent nodal point load.

```python
# For a rigorous approach use the element shape functions; here we use the built‑in method:
assembly.Surface(name='EALL', surface=surf).setValues(
    distributionType=UNIFORM, magnitude=pressure)

# Write *CLOAD cards
with open('cload_from_pressure.inp', 'w') as f:
    f.write('*CLOAD, NSET=EALL, OP=NEW\n')
    for n in nodeSet:
        # The assembly method automatically stores the lumped forces in the node's 'reaction' attribute
        # after a dummy static step; here we just illustrate the format:
        f.write('{0}, 2, {1:.6f}\n'.format(n.label, n.reaction[1]))
```

*(The script assumes you have already run a dummy step to let Abaqus compute the lumped forces; many users prefer a post‑processor such as **Abaqus/Viewer** or an external mesh tool to obtain the nodal forces directly.)*

---

### TL;DR

- `*DLOAD, EALL, NEWTON` applies a **uniform pressure** on the surface `EALL`.  
- To mimic it with `*CLOAD` you must **convert the pressure to nodal forces** and then list those forces node‑by‑node:

```abaqus
*CLOAD, NSET=EALL, OP=NEW
<node1>, 2, <F1>
<node2>, 2, <F2>
...
<nodeN>, 2, <FN>
```

where each `<Fi>` = (pressure) × (portion of the surface area associated with node *i*).  

Only after this conversion can the `*CLOAD` cards be considered an exact reproduction of the original `*DLOAD`.
