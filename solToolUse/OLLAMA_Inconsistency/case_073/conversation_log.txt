The message  

```

```  

is Abaqus’ generic way of telling you that it cannot find a *valid* definition for a **load that is supposed to act on a surface**.  
In the input you have

```abaqus

30,P2,-1000.
31,P2,-1000.
32,P2,-1000.
```

and later

```abaqus

```

Instead you are giving element numbers (29‑32) and an element set name (B1).  
Because Abaqus cannot find a surface with that name it falls back to the

has not been compiled.

The same problem exists for the *DFLUX* card – `BFNU` is not a surface; it is
just a label that you have not defined anywhere.

So the error is **not** caused by a missing user element; it is caused by an
incorrect definition of the loads.
