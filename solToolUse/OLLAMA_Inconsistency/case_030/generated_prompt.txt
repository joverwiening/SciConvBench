Use FEniCS legacy (dolfin) to solve a 2D plane‑stress linear elasticity problem on an L‑shaped domain.  
The outer square is 1 m × 1 m; remove a 0.5 m × 0.5 m square from the top‑right corner, i.e. the cutout occupies 0.5 ≤ x ≤ 1 and 0.5 ≤ y ≤ 1, leaving an L‑shaped domain.  
Create a uniform mesh with 64 elements along each outer edge (resulting in a structured mesh that respects the cutout geometry).  

Define the displacement field **u** in a first‑order (P1) vector‑valued finite element space (continuous Lagrange elements).  

Material properties: Young’s modulus E = 70 × 10⁹ Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³ (gravity is omitted).  
Use the reduced plane‑stress constitutive matrix  
\( D = \frac{E}{1-\nu^{2}} \begin{bmatrix} 1 & \nu & 0 \\ \nu & 1 & 0 \\ 0 & 0 & \frac{1-\nu}{2} \end{bmatrix} \).  

Apply boundary conditions:  
- Clamp (Dirichlet u = 0) on the outer left edge (x = 0) and outer bottom edge (y = 0).  
- Also set u = 0 on the two interior faces of the cutout that meet at the re‑entrant corner, i.e. on the line x = 0.5 for 0.5 ≤ y ≤ 1 and on the line y = 0.5 for 0.5 ≤ x ≤ 1.  

Apply a horizontal traction on the outer right edge (x = 1) where the domain exists (0 ≤ y ≤ 0.5):  
\( \mathbf{t} = (2.65\times10^{4},\;0) \) Pa.  

Formulate the weak form of the equilibrium equations with the above Dirichlet and Neumann conditions and solve the resulting linear system using a direct linear solver (e.g., LU factorization).  

Post‑process the solution:  
- Compute the Cauchy stress tensor σ from the strain‑displacement relation and the plane‑stress constitutive law.  
- Calculate the von Mises stress at each point using  
\( \sigma_{vm} = \sqrt{\sigma_{xx}^{2} - \sigma_{xx}\sigma_{yy} + \sigma_{yy}^{2} + 3\sigma_{xy}^{2}} \).  
- Output the displacement vector field and the von Mises stress field to VTK/XDMF files for visualization.  

The simulation provides the displacement patterns and von Mises stress distribution for the specified loading and constraints.
