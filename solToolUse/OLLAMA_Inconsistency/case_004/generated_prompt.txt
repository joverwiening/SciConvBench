Use legacy FEniCS (dolfin) to solve a 2‑D plane‑stress linear elasticity problem.  
Define the domain as an L‑shape: outer square [0,1] × [0,1] with the inner square [0.5,1] × [0.5,1] removed.  
Generate a uniform triangular mesh with 64 elements along each outer edge (≈ 64 × 64 triangles).  
Create a continuous Lagrange vector function space (CG1) for the displacement field u.  
Material parameters: Young’s modulus E = 70e9 Pa, Poisson ratio ν = 0.33, density ρ = 2700 kg/m³.  
Use the reduced plane‑stress constitutive matrix  
C = E/(1‑ν²) [[1, ν, 0],[ν, 1, 0],[0, 0,(1‑ν)/2]].  
Apply a body force f = (0, ‑ρ g) with g = 9.81 m/s² throughout the domain.  
Impose Dirichlet boundary condition u = (0,0) on the left boundary x = 0.  
Apply Neumann traction t(y) = (0, σ_yy(y)) on every exterior facet whose outward normal has a positive x‑component, i.e., the outer right edge x = 1 and the vertical face of the cut‑out.  
The traction magnitude varies linearly: σ_yy(y) = ‑2.65e4 · y Pa for y ∈ [0,1].  
All other external boundaries are traction‑free.  
Formulate the weak form ∫Ω ε(v):C:ε(u) dx = ∫Ω v·f dx + ∫Γ_N v·t ds and solve with a direct linear solver (e.g., LU).  
Compute the Cauchy stress σ = C:ε(u) and the von Mises stress √(σ_xx² ‑ σ_xxσ_yy + σ_yy² + 3σ_xy²).  
Write the displacement vector field and the stress tensor components (σ_xx, σ_yy, σ_xy) to VTK (or XDMF) files.  
Write the scalar von Mises field to a CSV file (including node coordinates and the von Mises value).  
Provide a single Python script named case_004_lshape_elasticity.py that performs mesh generation, problem definition, solution, post‑processing, and output as described.
