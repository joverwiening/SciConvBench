Develop a finite element solution for the small‑strain linear elasticity problem on the square domain Ω = [‑1,1] × [‑1,1] containing a slit from (0,0) to (1,0). Use the legacy FEniCS (dolfin) library and vector Lagrange (P1) elements for the displacement field.

1. Generate a conforming triangular mesh of Ω that includes the slit as an interior line segment. Use a mesh resolution parameter of about 30 (e.g., `Mesh("slit_mesh.xml")` generated with `mshr` or `gmsh` and a characteristic cell size ≈ 2/30).

2. Define the material parameters:
   - First Lamé parameter λ = 0.5444837367825.
   - Shear modulus μ = 1.0 (any positive value; the exact value does not affect the benchmark displacement field).

3. Define the exact displacement field u₀ in polar coordinates (r,θ) measured from the crack tip at the origin:
   - r = sqrt(x² + y²)
   - θ = atan2(y, x)   (θ ∈ (‑π,π))
   - q = 0.5430755788367
   - u₀_r = r**q * cos(q*θ)
   - u₀_θ = r**q * sin(q*θ)

   Convert to Cartesian components:
   - u₀_x = u₀_r * cos(θ) - u₀_θ * sin(θ)
   - u₀_y = u₀_r * sin(θ) + u₀_θ * cos(θ)

4. Create a `Function` `u_exact` in the vector function space and assign it the expressions for u₀_x and u₀_y.

5. Impose Dirichlet boundary conditions:
   - On the outer square boundary (x = ±1 or y = ±1), set u = u_exact.
   - On both faces of the slit (the line segment (0,0)–(1,0) approached from y>0 and y<0), also set u = u_exact. Ensure the slit is treated as a single interior seam so the displacement remains single‑valued.

6. Formulate the variational problem for linear elasticity:
   - Define the strain ε(u) = sym(grad(u)).
   - Define the stress σ(u) = λ*tr(ε(u))*Identity(2) + 2*μ*ε(u).
   - Weak form: find u ∈ V such that
     a(u,v) = ∫_Ω inner(σ(u), ε(v)) dx  for all test functions v ∈ V₀,
     where V₀ is the space of vector functions with homogeneous Dirichlet conditions (zero on the same boundaries where u_exact is prescribed).

7. Assemble the linear system and solve it with an iterative linear solver:
   - Use GMRES as the Krylov solver.
   - Apply an ILU preconditioner (`"ilu"` in PETSc or `PETScPreconditioner("ilu")`).

8. After solving, compute the error norm ‖u – u_exact‖_{L²(Ω)} and optionally the H¹‑seminorm to verify that the numerical solution reproduces the exact benchmark displacement field.

9. Output:
   - The computed displacement field `u`.
   - The error norms.
   - Visualizations of the displacement magnitude and the mesh, showing the slit.

All code must be written for the legacy FEniCS (dolfin) API, using `FunctionSpace`, `TrialFunction`, `TestFunction`, `assemble`, `solve`, and related constructs. Ensure the mesh respects the slit geometry so that the displacement is continuous across the slit faces.
