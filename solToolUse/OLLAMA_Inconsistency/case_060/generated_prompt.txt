
|-----------------------------------|-----------------|
| Displacement of node 7            | Ux = … m, Uy = … m, Uz = … m |
| Reaction forces at node 7         | Fx = … N, Fy = … N, Fz = … N |

### 3️⃣ Verify that the static step converged cleanly  

```bash
# look for the success line
grep -i "completed successfully" axiplane.log

# double‑check that no WARN/ERROR lines are present
grep -iE "warning|error|failed" axiplane.log
```

A line such as  

```
*** STEP 1 COMPLETED SUCCESSFULLY ***
```  

means the analysis finished without warnings.

---

### 4️⃣ Build the final reproducible archive  

```bash
tar -czvf axiplane_results.tar.gz \
    axiplane.dat \
    axiplane.log \
    myplot.png \
    extract.py \
    summary.txt \
    README.txt
```

**`README.txt` (already in the folder) – example content**

```
axiplane – static linear analysis
---------------------------------
Files:
  axiplane.dat   – raw CalculiX results (nodes, elements, stresses …)
  axiplane.log   – solver log (convergence information)
  myplot.png     – quick CGX preview of the deformed shape
  extract.py     – Python post‑processor (run with: python3 extract.py axiplane.dat)
  summary.txt    – human‑readable extraction of node‑7 data & avg von Mises stress
  README.txt     – this file
```

Now `axiplane_results.tar.gz` contains everything a reviewer (or future you) needs to:

* open the raw results,
* confirm convergence,
* visualise the model (quick CGX preview or ParaView via `ccx2vtk`),
* obtain the exact node‑7 displacement, reaction forces, and average von Mises stress,
* reproduce the whole workflow from start to finish.
