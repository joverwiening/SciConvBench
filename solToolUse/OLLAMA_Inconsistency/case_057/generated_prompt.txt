**

*MATERIAL,NAME=Material

1000

*DYNAMIC
0.01,0.1,0,0

U,V

Run CalculiX with the command `ccx -i zerovel`. If that command is not recognized, run `ccx zerovel` instead.

After execution, examine the file `zerovel.sta`. If the file contains a line indicating successful termination such as “JOB COMPLETED”, set the status to `success`; otherwise set it to `error` and record the failure message.
