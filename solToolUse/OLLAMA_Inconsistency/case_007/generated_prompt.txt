Define the 2D stepped polygon domain with eight vertices listed counter‑clockwise: (0.0, 0.0), (0.8, 0.0), (0.8, 0.2), (0.5, 0.2), (0.5, 0.4), (0.3, 0.4), (0.3, 0.6), (0.0, 0.6).  
Treat the domain as a plane‑stress body of unit thickness.  
Use the material properties: Young’s modulus E = 70e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³, gravitational acceleration g = 9.81 m/s².  
Apply the body force vector f = (0, −ρ g) throughout the domain.  
Impose Dirichlet boundary conditions: the entire bottom edge y = 0 is fixed (u = (0, 0)).  
Impose roller (zero normal displacement) conditions on the vertical stem faces at x = 0.3 and x = 0.5 by setting uₓ = 0 on those edges.  
Apply a horizontal traction σₓₓ = 5000 Pa on the horizontal face at y = 0.4 for 0.3 ≤ x ≤ 0.5 (the top of the middle step).  
Use the reduced plane‑stress constitutive matrix C = E/(1−ν²) · [[1, ν, 0], [ν, 1, 0], [0, 0, (1−ν)/2]].  
Formulate the weak form of the small‑strain linear elasticity problem with vector‑valued displacement space (e.g., CG1 elements).  
Generate a conforming triangular mesh of the domain consisting of 72 elements.  
Solve the resulting linear system with a direct linear solver (e.g., LUSolver in legacy FEniCS).  
Compute the Cauchy stress tensor σ = C : ε(u) + body‑force contribution, then evaluate the von Mises stress σ_v = √(σₓₓ² − σₓₓσ_yy + σ_yy² + 3σₓy²) at each mesh point.  
Output the displacement field u(x, y) and the von Mises stress field σ_v(x, y) over the mesh for post‑processing.
