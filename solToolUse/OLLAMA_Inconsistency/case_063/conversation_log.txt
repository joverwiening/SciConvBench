## 1. 关键字的基本语法

| 行号（大致） | 关键字 | 常见错误 | 说明 / 正确写法 |
|--------------|--------|----------|----------------|
| `*BOUNDARY` | `*BOUNDARY` 必须指明 **NSET**（或 **ELSET**）以及 **DOF**，随后每行给出 **node‑id, dof, value**（或 **node‑id, dof‑start, dof‑end, value**）。 | `*BOUNDARY`<br>`CN7, 1`<br>`CN7, 2`<br>`CN7, 3` | 这几行的语法不符合 Abaqus 规范。正确的写法示例：<br>```text<br>*BOUNDARY, NSET=CN7<br>1,1,0.<br>1,2,0.<br>1,3,0.<br>```<br>如果想一次性固定集合中所有节点的 1‑3 方向，可使用：<br>```text<br>*BOUNDARY, NSET=CN7, DOF=1,2,3<br>```<br>（后面不需要再写三行） |
| `*MODAL DAMPING,RAYLEIGH` | 关键字应为 `*DAMPING, TYPE=RAYLEIGH`（或 `*RAYLEIGH DAMPING`），后面只能给 **α**（质量比例）和 **β**（刚度比例）两个数值。 | `*MODAL DAMPING,RAYLEIGH`<br>`,,50.,0.` | 语法错误。改为：<br>```text<br>*DAMPING, TYPE=RAYLEIGH<br>0.,50.<br>```<br>（这里 α=0，β=50） |

| `*DLOAD` | 对于 **SHELL**（S8R）单元，压力载荷的方向必须在 **P**（面内均匀压力）后面给出 **幅值**，而不是 `P,1.`（缺少逗号）。 | `33,P,1.` | 正确写法：<br>```text<br*DLOAD<br>33, P, 1.0```<br>（注意逗号分隔） |

| `*DENSITY` | 该关键字的数值是 **质量密度**（质量/体积），单位必须与材料弹性模量的单位保持一致。 | `7.8E-9` | 如果您使用 **N‑mm** 单位体系，钢的密度应为 `7.8E-9` t/mm³（≈ 7850 kg/m³），这在数值上是合理的。若使用 **SI**（N‑m‑kg），则应写成 `7850.`（kg/m³）。请确认您所选的单位体系。 |

| `*STEP` → `*FREQUENCY` | `*FREQUENCY` 关键字后必须给出 **NMODES**（求解的模态数）和 **INC**（频率增量），两者之间用逗号分隔。 | `10,0.01` | 正确写法（假设您想求 10 个模态，频率增量 0.01 Hz）：<br>```text<br>*FREQUENCY, STORAGE=YES, NMODES=10, INC=0.01<br>```<br>如果不写关键字参数，Abaqus 会把第一个数解释为 **NMODES**，第二个解释为 **INC**，但建议显式写出关键字名称，以免误解。 |

## 2. 结构模型的潜在数值问题

| 项目 | 可能的数值/物理问题 | 建议 |
|------|-------------------|------|
| **单元类型** | 您把 **C3D20R**（20‑节点体单元）和 **S8R**（8‑节点壳单元）混在同一个模型里。若两套单元在同一几何体上相邻，必须保证 **节点共享**（即同一节点在体单元和壳单元中出现），否则会出现 **不连续的网格**，导致求解器报错 “*The mesh is not compatible*”。 | 检查 **节点 25、31、5、6、22、100、98、99、101、102、23、24、21、32** 是否在体单元中已经出现。若没有，请在体单元的节点列表里加入对应节点，或把壳单元改为 **S4R**（四节点）并重新划分。 |
| **壳厚度** | `0.0001`（单位取决于模型）在大多数工程尺度（mm‑m）下非常薄，导致 **刚度矩阵奇异**，尤其在进行 **模态分析** 时会出现极高频率或不收敛。 | 将厚度调大（如 `0.001` m 或 `1.0e-3`），或使用 **SHELL SECTION, OFFSET** 来确保厚度与实际几何相匹配。 |
| **质量密度** | `*DENSITY 7.8E-9` 在 **N‑mm** 单位体系下对应 `7.8·10⁻⁹` t/mm³（≈ 7850 kg/m³），是合理的。但如果您使用 **SI**（N‑m‑kg），则应写成 `7850.`。 | 确认您使用的 **长度单位**（mm 还是 m），并相应修改密度。 |
| **Rayleigh 阻尼** | 您在 **STEADY STATE DYNAMICS** 步中写了 `*MODAL DAMPING,RAYLEIGH ,,50.,0.`，这实际上是 **质量比例 α** 为缺省（0），**刚度比例 β** 为 50。β=50 是非常大的阻尼系数，会把所有模态的阻尼比（ζ）提升到数十甚至上百，导致 **响应被过度衰减**，有时会导致求解器报 “*Damping matrix is singular*”。 | 将 β 调整到更合理的范围（如 `0.02`‑`0.05`），或使用 **α** 与 **β** 的组合（如 `α=0.0, β=0.02`). |
| **加载幅值** | 对壳单元的压力 `P,1.` 施加在 **S8R** 单元上，若厚度非常小（0.0001），实际 **面内力** 会非常大，可能导致 **非线性**（虽然您使用线性求解器）。 | 检查实际的 **压力值** 是否符合模型尺度，必要时把幅值调小或把厚度调大。 |
| **频率范围** | `*STEADY STATE DYNAMICS 13000.,14000.,2` 表示在 **13 kHz‑14 kHz** 区间做稳态动力学分析。若模型的固有频率（由前一步的 *FREQUENCY* 步得到）不在此范围内，求解器会报 “*No frequencies in the specified range*”。 | 在 **FREQUENCY** 步中检查输出的固有频率，确保至少有一个模态落在 13‑14 kHz 区间。如果没有，需要扩大频率范围或重新定义 **模态分析** 步的频率区间。 |
| **节点集 N100** | 您只定义了 `*NSET,NSET=N100 100`，即只包含节点 **100**。随后在 **STEP 2** 中使用 `*NODE PRINT,NSET=N100` 只打印该单点的位移。若您想观察整个结构的响应，建议把感兴趣的节点（如所有壳单元的角点）加入该集合。 | 用 `*NSET, NSET=NALL` 或 `*NSET, NSET=OUTPUT, GENERATE` 把所有外表面节点加入集合，或者在 **OUTPUT** 步中使用 `*ELEMENT OUTPUT, ELSET=EALL` 来输出整体响应。 |

## 4. 检查流程建议

1. **先提交仅包含材料、几何和 *FREQUENCY* 步的模型**（不加任何载荷、阻尼或输出），确认 **模态求解** 能够成功完成并得到一组合理的固有频率。  
2. **检查固有频率**：打开 `.dat` 或 `.odb`，确认至少有一个频率落在您在 *STEADY STATE DYNAMICS* 步中指定的区间（13‑14 kHz）。如果没有，重新设定频率范围或在 *FREQUENCY* 步中扩大搜索区间。  
3. **加入稳态动力学载荷**（压力）并重新提交。若出现 “**singular matrix**” 或 “**no convergence**”，逐步检查：  
   - 壳厚度是否过小；  
   - Rayleigh 阻尼系数是否过大；  
   - 载荷幅值是否导致单元的应力/应变超出线性范围。  
4. **输出检查**：在稳态动力学步中使用 `*Output, field`（或 `*Node Output`）来记录位移、应力、反应力等。  
5. **后处理**：在 Abaqus/Viewer 中绘制 **NOUT**（或您感兴趣的节点集合）位移时，确保 **Result → Frequency** 已经选中对应的频率点。

## 推荐的调试/提交流程（最小化调试步骤）

1. **仅跑模态分析**  
   - 注释掉（或删除）第二个 `*Step`（稳态动力学）段。  
   - 提交作业，检查 `.dat` 中是否出现 `FREQUENCY` 表，`.odb` 中是否有 `FREQUENCY` 章节。  
   - 确认 **至少有一个固有频率落在 13 kHz‑14 kHz** 区间。若没有，可增大 `nModes` 或放宽 `inc` 再次求解。

2. **加入稳态动力学**  
   - 恢复第二个 `*Step`，再次提交。  
   - 检查 `.dat` 中是否出现 `STEADY STATE DYNAMICS`，`.odb` 中是否有 `U` 场。  

3. **收敛性检查**（若出现 “singular matrix” / “no convergence”）  
   - **壳厚度** 是否过薄（建议 ≥ 0.5 mm）。  
   - **Rayleigh 阻尼** 系数是否过大（β ≈ 0.02 为常用范围）。  
   - **载荷幅值** 是否导致单元进入非线性（本例 `nlgeom=NO`，若需要大变形请改为 `YES`）。  
   - **体‑壳节点共享** 是否正确（体单元与壳单元的公共节点必须在同一坐标位置且编号相同）。  

4. **后处理**  
   - 打开 `.odb` → **Result → Deformed Shape** → 选取 `NOUT` → **Create XY‑Data → Frequency** → 选择 `U`（位移幅值），即可得到 **频率响应曲线**。  
   - 如需导出 CSV：**Result → Field Output → Export**，选择 `U`、`S`、`E` 等变量。  

5. **如需进一步分析**（非线性、热‑结构耦合等）  
   - 把 `nlgeom=YES` 放到需要的 `*Step` 中。  
   - 添加相应的材料非线性卡（`*Plastic`、`*Viscoelastic` 等）或热载荷卡（`*Temperature`、`*Heat Transfer`）。

## 常见错误快速定位表

| 错误类型 | 典型报错信息 | 快速定位/解决办法 |
|----------|--------------|-------------------|
| 关键字拼写错误 | `*** Error: Invalid keyword` | 检查关键字是否与 Abaqus 手册完全一致（如 `*Steady State Dynamics` 而非 `*STEADY STATE DYNAMICS`）。 |
| 参数缺失 | `*** Error: Missing parameter` | 所有关键字后面的参数必须使用 `=` 形式显式给出（如 `frequencies=`、`nModes=`）。 |
| 逗号缺失 | `*** Error: Invalid data line`（在 `*Dload` 行） | 检查 `*Dload`、`*Boundary`、`*Dload` 等每行是否用逗号分隔。 |
| 单位不统一 | 结果出现异常的极大/极小频率 | 确认文件开头的 `*Unit` 与材料、厚度、密度数值对应。 |
| 壳厚度过薄 | 求解结束后出现 “singular matrix” | 将 `thickness` 调整至 ≥ 0.5 mm（对应 `0.0005` m）或更大。 |
| 阻尼系数异常 | “Damping matrix is singular” | 使用 `β≈0.02`（或 `α≈0.02, β≈0.0`），避免刚度矩阵失去正定性。 |
| 频率区间不匹配 | “No frequencies in the specified range” | 先跑模态分析，确认目标频率是否出现，再设置稳态动力学的 `frequencies=` 参数。 |
| 节点集合过小 | 只能看到单点位移 | 把感兴趣的全部表面节点或关键点加入 `NSET`（如 `NOUT`），并在 `*Output` 中引用。 |

## Ⅰ. 通过 Python（Abaqus 脚本）一次性导出 **全部节点 / 全部体单元 / 全部壳单元**  

> 把下面的脚本保存为 `export_mesh.py`，在 **Abaqus/CAE** 的 **File → Run Script**（或在命令行 `abaqus cae noGUI=export_mesh.py`）中执行。  
> 脚本会在当前工作目录生成四个文本文件：  
> * `nodes.txt`     → `*Node` 区段的完整内容  
> * `solid_elems.txt` → `*Element, type=C3D20R` 区段的完整内容  
> * `shell_elems.txt` → `*Element, type=S8R` 区段的完整内容  
> * `sets.txt`     → 所有 **Nset** / **Elset**（包括约束节点、监测节点）的定义

```python
# --------------------------------------------------------------
# export_mesh.py
# 适用于 Abaqus/CAE 2020‑2024（Python 2.7 / 3.x 兼容）
# --------------------------------------------------------------
from abaqus import *
from abaqusConstants import *
import mesh
import os

# ------------------- 1️⃣ 读取模型 -------------------
# 假设模型在当前打开的 .cae 文件里，名称为 "Assembly"
assembly = mdb.models['Model-1'].rootAssembly

# ------------------- 2️⃣ 收集所有节点 -------------------
# 这里把 Assembly 里所有 Instance 的节点统一编号（Abaqus 已经保证唯一性）
all_nodes = {}
for instName, inst in assembly.instances.items():
    for n in inst.nodes:
        # n.label 已经是全局唯一编号
        all_nodes[n.label] = n.coordinates

# ------------------- 3️⃣ 收集体单元（C3D20R） -------------------
solid_elems = []   # (elemLabel, [node1,…,node20])
for inst in assembly.instances.values():
    for e in inst.elements:
        if e.type == C3D20R:
            solid_elems.append((e.label, e.connectivity))

# ------------------- 4️⃣ 收集壳单元（S8R） -------------------
shell_elems = []   # (elemLabel, [node1,…,node8])
for inst in assembly.instances.values():
    for e in inst.elements:
        if e.type == S8R:
            shell_elems.append((e.label, e.connectivity))

# ------------------- 5️⃣ 生成 Nset / Elset（示例） -------------------
# 下面给出两类常用集合的自动生成方式，您可以自行修改筛选条件
# ① 固定端（左端 X≈0 的所有节点）
fixed_nodes = [nid for nid, xyz in all_nodes.items() if abs(xyz[0]) < 1e-6]

# ② 监测端（右端 X 最大的 10% 节点）
x_max = max(xyz[0] for xyz in all_nodes.values())
threshold = x_max * 0.9
out_nodes = [nid for nid, xyz in all_nodes.items() if xyz[0] >= threshold]

# ------------------- 6️⃣ 写入文件 -------------------
def write_nodes(fname):
    with open(fname, 'w') as f:
        f.write('*Node\n')
        for nid in sorted(all_nodes):
            x, y, z = all_nodes[nid]
            f.write('{:d}, {:.6f}, {:.6f}, {:.6f}\n'.format(nid, x, y, z))

def write_elements(fname, elems, elem_type):
    with open(fname, 'w') as f:
        f.write('*Element, type={}, elset={}\n'.format(elem_type,
                                                      'SOLID' if elem_type.startswith('C3D') else 'SHELL'))
        for eid, conn in sorted(elems):
            line = ','.join(str(n) for n in conn)
            f.write('{:d}, {}\n'.format(eid, line))

def write_sets(fname):
    with open(fname, 'w') as f:
        # ---- Nset: 固定端 ----
        f.write('*Nset, nset=CN7\n')
        for i, nid in enumerate(sorted(fixed_nodes), 1):
            f.write('{:d}'.format(nid))
            if i % 10 == 0:
                f.write('\n')
            else:
                f.write(', ')
        f.write('\n')
        # ---- Nset: 监测端 ----
        f.write('*Nset, nset=NOUT\n')
        for i, nid in enumerate(sorted(out_nodes), 1):
            f.write('{:d}'.format(nid))
            if i % 10 == 0:
                f.write('\n')
            else:
                f.write(', ')
        f.write('\n')
        # ---- Elset: 体单元 ----
        f.write('*Elset, elset=SOLID, generate\n')
        if solid_elems:
            first = min(e[0] for e in solid_elems)
            last  = max(e[0] for e in solid_elems)
            f.write('{:d}, {:d}, 1\n'.format(first, last))
        # ---- Elset: 壳单元 ----
        f.write('*Elset, elset=SHELL, generate\n')
        if shell_elems:
            first = min(e[0] for e in shell_elems)
            last  = max(e[0] for e in shell_elems)
            f.write('{:d}, {:d}, 1\n'.format(first, last))
        # ---- Elset: ALL ----
        f.write('*Elset, elset=ALL, generate\n')
        if solid_elems or shell_elems:
            all_first = min([first] + [first])
            all_last  = max([last]  + [last])
            f.write('{:d}, {:d}, 1\n'.format(all_first, all_last))

# 调用写入函数
write_nodes('nodes.txt')
write_elements('solid_elems.txt', solid_elems, 'C3D20R')
write_elements('shell_elems.txt', shell_elems, 'S8R')
write_sets('sets.txt')

print('=== 导出完成 ===')
print('  nodes.txt      → *Node 区段')
print('  solid_elems.txt → *Element, type=C3D20R')
print('  shell_elems.txt → *Element, type=S8R')
print('  sets.txt        → *Nset / *Elset')
```

## 2️⃣ `assemble_inp.py`（新脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib

# --------------------------------------------------------------
# 1. 需要您自行修改的路径（相对或绝对均可）
# --------------------------------------------------------------
# 原始模板文件（您在问题里贴出的那段代码，已加入占位符）
template_inp = pathlib.Path('model_template.inp')

# 四个由 export_mesh.py 生成的文件
nodes_file   = pathlib.Path('nodes.txt')
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')

# 输出的完整 *.inp*
output_inp   = pathlib.Path('model_complete.inp')
# --------------------------------------------------------------

def read_file(fp):
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace_placeholder(content, placeholder, replacement):
    """把占位符（包括换行）替换为实际文本"""
    return content.replace(placeholder, replacement)

def main():
    # ----------------------------------------------------------
    # 2. 读取模板
    # ----------------------------------------------------------
    if not template_inp.is_file():
        raise FileNotFoundError(f'找不到模板文件 {template_inp}')
    template = read_file(template_inp)

    # ----------------------------------------------------------
    # 3. 读取四个导出文件的内容
    # ----------------------------------------------------------
    if not nodes_file.is_file():
        raise FileNotFoundError(f'找不到节点文件 {nodes_file}')
    nodes_txt = read_file(nodes_file)

    if not solid_file.is_file():
        raise FileNotFoundError(f'找不到体单元文件 {solid_file}')
    solid_txt = read_file(solid_file)

    if not shell_file.is_file():
        raise FileNotFoundError(f'找不到壳单元文件 {shell_file}')
    shell_txt = read_file(shell_file)

    if not sets_file.is_file():
        raise FileNotFoundError(f'找不到集合文件 {sets_file}')
    sets_txt = read_file(sets_file)

    # ----------------------------------------------------------
    # 4. 替换占位符
    # ----------------------------------------------------------
    # 2. 节点定义
    template = replace_placeholder(template, '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
                                   nodes_txt.rstrip() + '\n')

    # 3. 体单元定义
    template = replace_placeholder(template, '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
                                   solid_txt.rstrip() + '\n')

    # 3. 壳单元定义
    template = replace_placeholder(template, '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
                                   shell_txt.rstrip() + '\n')

    # 4. 集合定义（Elset）
    # 这里我们只保留 *Elset, elset=SOLID, generate 之后的一行
    # sets.txt 中已经包含了完整的 *Elset … generate 行，直接复制整段即可
    # 为了避免重复，我们把整段（包括 *Elset … generate）直接粘进去
    # 先把 sets.txt 中的 *Elset … generate 行提取出来
    # ----------------------------------------------------------
    # 读取 sets.txt 并拆分成块
    # ----------------------------------------------------------
    lines = sets_txt.splitlines()
    # 找到每个块的起始行号
    idx_solid = lines.index('*Elset, elset=SOLID, generate')
    idx_shell = lines.index('*Elset, elset=SHELL, generate')
    idx_all   = lines.index('*Elset, elset=ALL, generate')

    # 取出对应的 “generate” 行（包括后面的 start,end,inc）
    solid_generate = '\n'.join(lines[idx_solid:idx_solid+2])   # 两行：*Elset …\n start,end,inc
    shell_generate = '\n'.join(lines[idx_shell:idx_shell+2])
    all_generate   = '\n'.join(lines[idx_all:idx_all+2])

    # 替换模板中的占位符
    template = replace_placeholder(template,
                                   '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
                                   solid_generate)
    template = replace_placeholder(template,
                                   '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
                                   shell_generate)
    template = replace_placeholder(template,
                                   '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
                                   all_generate)

    # 5. Nset CN7
    # 找到 *Nset, nset=CN7 行以及其后所有节点（直到空行或下一个 * 开头的行）
    start_cn7 = lines.index('*Nset, nset=CN7')
    # 读取直到下一个 * 开头的行（不包括该行）
    cn7_nodes = []
    for ln in lines[start_cn7+1:]:
        if ln.strip().startswith('*'):
            break
        cn7_nodes.append(ln.strip())
    cn7_block = '*Nset, nset=CN7\n' + '\n'.join(cn7_nodes) + '\n'

    # 6. Nset NOUT
    start_nout = lines.index('*Nset, nset=NOUT')
    nout_nodes = []
    for ln in lines[start_nout+1:]:
        if ln.strip().startswith('*'):
            break
        nout_nodes.append(ln.strip())
    nout_block = '*Nset, nset=NOUT\n' + '\n'.join(nout_nodes) + '\n'

    # 替换模板中的 Nset 块
    template = replace_placeholder(template,
                                   '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
                                   cn7_block)
    template = replace_placeholder(template,
                                   '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
                                   nout_block)

    # ----------------------------------------------------------
    # 5. 写出完整的 *.inp*
    # ----------------------------------------------------------
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

## 6️⃣ 常见问题 & 快速定位

| 错误信息 | 可能原因 | 快速定位办法 |
|----------|----------|--------------|
| `*** ERROR: Invalid node label` | 节点编号在 `*Node` 中缺失或重复 | 用文本编辑器搜索缺失的节点号（报错行），检查 `nodes.txt` 是否包含该号。 |
| `*** ERROR: Invalid element label` | 单元编号缺失或不在 `*Elset` 的 `generate` 范围内 | 检查 `*Elset, elset=SOLID, generate` 行的 `start, end` 是否覆盖所有体单元号。 |
| `*** ERROR: Node set CN7 not defined` | `CN7` 集合未在 `*Nset` 中出现 | 打开 `sets.txt`，确认 `*Nset, nset=CN7` 行及其后节点列表完整。 |
| `*** ERROR: Dload references undefined element` | `*Dload` 中的单元号（33、34）在 `shell_elems.txt` 中不存在 | 用 `grep "33"`（或编辑器搜索）确认 33、34 在 `shell_elems.txt` 中出现。 |
| `*** ERROR: Rayleigh damping matrix is singular` | `β` 取值过大导致阻尼矩阵奇异 | 将 `*Damping, type=RAYLEIGH` 中的第二个数调小（如 0.01），重新提交。 |

## 4️⃣ `assemble_inp.py`（完整脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib

# --------------------------------------------------------------
# 1. 需要您自行修改的路径（相对或绝对均可）
# --------------------------------------------------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')
output_inp   = pathlib.Path('model_complete.inp')   # 最终生成的完整 inp
# --------------------------------------------------------------

def read_file(fp):
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace_placeholder(content, placeholder, replacement):
    """把占位符（包括换行）替换为实际文本"""
    return content.replace(placeholder, replacement)

def main():
    # --------------------------------------------------------------
    # 2. 读取模板
    # --------------------------------------------------------------
    if not template_inp.is_file():
        raise FileNotFoundError(f'找不到模板文件 {template_inp}')
    template = read_file(template_inp)

    # --------------------------------------------------------------
    # 3. 读取四个导出文件的内容
    # --------------------------------------------------------------
    for fp in (nodes_file, solid_file, shell_file, sets_file):
        if not fp.is_file():
            raise FileNotFoundError(f'找不到文件 {fp}')
    nodes_txt = read_file(nodes_file)
    solid_txt = read_file(solid_file)
    shell_txt = read_file(shell_file)
    sets_txt  = read_file(sets_file)

    # --------------------------------------------------------------
    # 4. 替换占位符
    # --------------------------------------------------------------
    # 4.1 节点
    template = replace_placeholder(
        template,
        '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
        nodes_txt.rstrip() + '\n'
    )
    # 4.2 体单元
    template = replace_placeholder(
        template,
        '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
        solid_txt.rstrip() + '\n'
    )
    # 4.3 壳单元
    template = replace_placeholder(
        template,
        '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
        shell_txt.rstrip() + '\n'
    )

    # 4.4 Elset（generate 行）
    lines = sets_txt.splitlines()
    # 取出 *Elset, elset=SOLID, generate 以及其后的一行
    idx_solid = lines.index('*Elset, elset=SOLID, generate')
    solid_generate = '\n'.join(lines[idx_solid:idx_solid+2])
    idx_shell = lines.index('*Elset, elset=SHELL, generate')
    shell_generate = '\n'.join(lines[idx_shell:idx_shell+2])
    idx_all   = lines.index('*Elset, elset=ALL, generate')
    all_generate   = '\n'.join(lines[idx_all:idx_all+2])

    template = replace_placeholder(
        template,
        '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
        solid_generate
    )
    template = replace_placeholder(
        template,
        '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
        shell_generate
    )
    template = replace_placeholder(
        template,
        '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
        all_generate
    )

    # 4.5 Nset CN7
    start_cn7 = lines.index('*Nset, nset=CN7')
    cn7_nodes = []
    for ln in lines[start_cn7+1:]:
        if ln.strip().startswith('*'):
            break
        cn7_nodes.append(ln.strip())
    cn7_block = '*Nset, nset=CN7\n' + '\n'.join(cn7_nodes) + '\n'

    # 4.6 Nset NOUT
    start_nout = lines.index('*Nset, nset=NOUT')
    nout_nodes = []
    for ln in lines[start_nout+1:]:
        if ln.strip().startswith('*'):
            break
        nout_nodes.append(ln.strip())
    nout_block = '*Nset, nset=NOUT\n' + '\n'.join(nout_nodes) + '\n'

    template = replace_placeholder(
        template,
        '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
        cn7_block
    )
    template = replace_placeholder(
        template,
        '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
        nout_block
    )

    # --------------------------------------------------------------
    # 5. 写出完整的 *.inp*
    # --------------------------------------------------------------
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

> **脚本说明**  
> - **占位符**：脚本只会替换 `<<--- … --->` 之间的文字，确保模板里没有多余的相同字符串。  
> - **`generate` 行**：脚本自动提取 `*Elset … generate` 以及紧随其后的 `start,end,inc` 行，保证编号范围与实际单元匹配。  
> - **`Nset` 块**：脚本会把 `CN7`、`NOUT` 两个节点集合完整复制进去（包括 `*Nset` 行本身），避免 “集合未定义” 的报错。

## 6️⃣ 常见报错 & 快速定位（简表）

| 报错信息 | 可能原因 | 快速定位办法 |
|----------|----------|--------------|
| `*** ERROR: Invalid node label` | `nodes.txt` 中缺失某个节点号 | 打开 `model_complete.inp`，搜索报错行的节点号，确认 `nodes.txt` 是否包含该号 |
| `*** ERROR: Invalid element label` | `solid_elems.txt` / `shell_elems.txt` 中缺失单元号，或 `*Elset … generate` 范围不覆盖 | 检查 `*Elset, elset=SOLID, generate`（或 SHELL）行的 `start, end` 是否覆盖所有单元号 |
| `*** ERROR: Node set CN7 not defined` | `sets.txt` 中没有 `*Nset, nset=CN7` 或脚本未正确粘贴 | 打开 `sets.txt`，确认 `*Nset, nset=CN7` 行存在且后面有节点列表 |
| `*** ERROR: Dload references undefined element` | `*Dload` 中的单元号（如 33、34）不在 `shell_elems.txt` 中 | 在 `shell_elems.txt` 中搜索对应单元号，若不存在则说明导出时漏掉该单元 |
| `*** ERROR: Rayleigh damping matrix is singular` | `*Damping, type=RAYLEIGH` 中的 `β` 取值过大 | 将第二个系数调小（如 `0.01`），重新提交 |

> **定位技巧**：使用编辑器的 “全局搜索” 功能（Ctrl+F）快速定位报错行对应的编号，然后在相应的 txt 中检查是否存在。

## 4️⃣ `assemble_inp.py`（完整拼接脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib

# -------------------------------------------------
# 1️⃣ 需要您自行修改的路径（相对或绝对均可）
# -------------------------------------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')
output_inp   = pathlib.Path('model_complete.inp')   # 最终生成的完整 inp
# -------------------------------------------------

def read_file(fp):
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace_placeholder(content, placeholder, replacement):
    """把占位符（包括换行）替换为实际文本"""
    return content.replace(placeholder, replacement)

def main():
    # -------------------------------------------------
    # 2️⃣ 读取模板
    # -------------------------------------------------
    if not template_inp.is_file():
        raise FileNotFoundError(f'找不到模板文件 {template_inp}')
    template = read_file(template_inp)

    # -------------------------------------------------
    # 3️⃣ 读取四个导出文件的内容
    # -------------------------------------------------
    for fp in (nodes_file, solid_file, shell_file, sets_file):
        if not fp.is_file():
            raise FileNotFoundError(f'找不到文件 {fp}')
    nodes_txt = read_file(nodes_file)
    solid_txt = read_file(solid_file)
    shell_txt = read_file(shell_file)
    sets_txt  = read_file(sets_file)

    # -------------------------------------------------
    # 4️⃣ 替换占位符
    # -------------------------------------------------
    # 4.1 节点
    template = replace_placeholder(
        template,
        '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
        nodes_txt.rstrip() + '\n'
    )
    # 4.2 体单元
    template = replace_placeholder(
        template,
        '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
        solid_txt.rstrip() + '\n'
    )
    # 4.3 壳单元
    template = replace_placeholder(
        template,
        '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
        shell_txt.rstrip() + '\n'
    )

    # 4.4 Elset（generate 行 + start,end,inc）
    lines = sets_txt.splitlines()
    idx_solid = lines.index('*Elset, elset=SOLID, generate')
    solid_generate = '\n'.join(lines[idx_solid:idx_solid+2])
    idx_shell = lines.index('*Elset, elset=SHELL, generate')
    shell_generate = '\n'.join(lines[idx_shell:idx_shell+2])
    idx_all   = lines.index('*Elset, elset=ALL, generate')
    all_generate   = '\n'.join(lines[idx_all:idx_all+2])

    template = replace_placeholder(
        template,
        '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
        solid_generate
    )
    template = replace_placeholder(
        template,
        '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
        shell_generate
    )
    template = replace_placeholder(
        template,
        '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
        all_generate
    )

    # 4.5 Nset CN7
    start_cn7 = lines.index('*Nset, nset=CN7')
    cn7_nodes = []
    for ln in lines[start_cn7+1:]:
        if ln.strip().startswith('*'):
            break
        cn7_nodes.append(ln.strip())
    cn7_block = '*Nset, nset=CN7\n' + '\n'.join(cn7_nodes) + '\n'

    # 4.6 Nset NOUT
    start_nout = lines.index('*Nset, nset=NOUT')
    nout_nodes = []
    for ln in lines[start_nout+1:]:
        if ln.strip().startswith('*'):
            break
        nout_nodes.append(ln.strip())
    nout_block = '*Nset, nset=NOUT\n' + '\n'.join(nout_nodes) + '\n'

    template = replace_placeholder(
        template,
        '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
        cn7_block
    )
    template = replace_placeholder(
        template,
        '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
        nout_block
    )

    # -------------------------------------------------
    # 5️⃣ 写出完整的 *.inp*
    # -------------------------------------------------
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

**脚本工作原理**  

- 读取模板中的 `<<--- … --->` 占位符并用对应的 txt 内容替换。  
- 自动提取 `*Elset … generate` 行以及其后 `start,end,inc` 行，确保 `generate` 范围覆盖所有实际单元。  
- 把 `CN7`、`NOUT` 两个节点集合完整复制进去（包括 `*Nset` 行本身），避免 “集合未定义” 报错。

```python
        template,
        '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
        nout_block

    main()
```

**脚本工作原理**  

1. 读取 `model_template.inp`，定位所有 `<<--- … --->` 占位符。  
2. 用 `nodes.txt`、`solid_elems.txt`、`shell_elems.txt`、`sets.txt` 中的内容替换对应占位符。  
3. 对于 `*Elset, elset=SOLID, generate`、`*Elset, elset=SHELL, generate`、`*Elset, elset=ALL, generate`，脚本会把 **两行**（`*Elset …` + `start,end,inc`）一起粘进去，确保 `generate` 范围覆盖所有实际单元。

## 3️⃣ `assemble_inp.py`（完整拼接脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib
import sys

# ------------------- 需要自行修改的路径 -------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')
output_inp   = pathlib.Path('model_complete.inp')   # 最终生成的完整 inp
# ---------------------------------------------------------

def read_file(fp: pathlib.Path) -> str:
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace(content: str, placeholder: str, replacement: str) -> str:
    """安全替换占位符，若未找到会抛异常"""
    if placeholder not in content:
        raise ValueError(f'占位符未找到: {placeholder}')
    return content.replace(placeholder, replacement)

def main() -> None:
    # ---------- 检查文件 ----------
    for p in (template_inp, nodes_file, solid_file, shell_file, sets_file):
        if not p.is_file():
            sys.exit(f'❌ 找不到必需文件: {p}')

    # ---------- 读取所有文件 ----------
    template = read_file(template_inp)
    nodes_txt = read_file(nodes_file)
    solid_txt = read_file(solid_file)
    shell_txt = read_file(shell_file)
    sets_txt  = read_file(sets_file)

    # ---------- 替换节点、体单元、壳单元 ----------
    template = replace(template,
                       '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
                       nodes_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
                       solid_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
                       shell_txt.rstrip() + '\n')

    # ---------- 处理 *Elset generate ----------
    lines = sets_txt.splitlines()
    def get_generate_block(elset_name: str) -> str:
        """返回 '*Elset, elset=NAME, generate' + 下一行(start,end,inc)"""
        key = f'*Elset, elset={elset_name}, generate'
        try:
            idx = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 把两行合并为一个块（保留换行）
        return '\n'.join(lines[idx:idx+2])

    solid_generate = get_generate_block('SOLID')
    shell_generate = get_generate_block('SHELL')
    all_generate   = get_generate_block('ALL')

    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
                       solid_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
                       shell_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
                       all_generate)

    # ---------- 处理 *Nset CN7 与 NOUT ----------
    def get_nset_block(nset_name: str) -> str:
        """返回完整的 *Nset 块（包括 *Nset 行本身）"""
        key = f'*Nset, nset={nset_name}'
        try:
            start = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 收集后面的节点行，直到遇到下一条 * 开头的卡片或文件结束
        nodes = []
        for ln in lines[start+1:]:
            if ln.strip().startswith('*') or not ln.strip():
                break
            nodes.append(ln.strip())
        return f'*Nset, nset={nset_name}\n' + '\n'.join(nodes) + '\n'

    cn7_block = get_nset_block('CN7')
    nout_block = get_nset_block('NOUT')

    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
                       cn7_block)
    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
                       nout_block)

    # ---------- 写出完整的 *.inp* ----------
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的 Abaqus 输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

### 脚本工作原理（简要说明）

| 步骤 | 说明 |
|------|------|
| **读取模板** | `model_template.inp` 中的占位符保持原样。 |
| **读取四个 txt** | `nodes.txt`、`solid_elems.txt`、`shell_elems.txt`、`sets.txt` 必须全部存在。 |
| **节点 / 单元** | 直接把对应 txt 的全部内容（保留换行）替换到占位符。 |
| **Elset generate** | 脚本把 `*Elset, elset=XXX, generate` 行 **以及** 紧随其后的 `start,end,inc` 行一起粘进去，确保 `generate` 范围覆盖所有单元。 |
| **Nset CN7 / NOUT** | 把 `*Nset, nset=CN7`（或 NOUT）行本身以及后面的节点列表完整复制进模板。 |
| **写文件** | 生成 `model_complete.inp`，即可直接提交 Abaqus。 |

> **异常提示**：如果占位符、`*Elset`、`*Nset` 在 `sets.txt` 中找不到，脚本会抛出清晰的错误信息，帮助您快速定位问题。

## 3️⃣ `assemble_inp.py`（完整拼接脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib
import sys

# ------------------- 需要自行修改的路径 -------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')
output_inp   = pathlib.Path('model_complete.inp')   # 最终生成的完整 inp
# ---------------------------------------------------------

def read_file(fp: pathlib.Path) -> str:
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace(content: str, placeholder: str, replacement: str) -> str:
    """安全替换占位符，若未找到会抛异常"""
    if placeholder not in content:
        raise ValueError(f'占位符未找到: {placeholder}')
    return content.replace(placeholder, replacement)

def main() -> None:
    # ---------- 检查必需文件 ----------
    for p in (template_inp, nodes_file, solid_file, shell_file, sets_file):
        if not p.is_file():
            sys.exit(f'❌ 找不到必需文件: {p}')

    # ---------- 读取所有文件 ----------
    template = read_file(template_inp)
    nodes_txt = read_file(nodes_file)
    solid_txt = read_file(solid_file)
    shell_txt = read_file(shell_file)
    sets_txt  = read_file(sets_file)

    # ---------- 替换节点、体单元、壳单元 ----------
    template = replace(template,
                       '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
                       nodes_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
                       solid_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
                       shell_txt.rstrip() + '\n')

    # ---------- 处理 *Elset generate ----------
    lines = sets_txt.splitlines()

    def get_generate_block(elset_name: str) -> str:
        """返回 '*Elset, elset=NAME, generate' + 下一行(start,end,inc)"""
        key = f'*Elset, elset={elset_name}, generate'
        try:
            idx = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 两行合并为一个块（保留换行）
        return '\n'.join(lines[idx:idx+2])

    solid_generate = get_generate_block('SOLID')
    shell_generate = get_generate_block('SHELL')
    all_generate   = get_generate_block('ALL')

    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
                       solid_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
                       shell_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
                       all_generate)

    # ---------- 处理 *Nset CN7 与 NOUT ----------
    def get_nset_block(nset_name: str) -> str:
        """返回完整的 *Nset 块（包括 *Nset 行本身）"""
        key = f'*Nset, nset={nset_name}'
        try:
            start = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 收集后面的节点行，直到遇到下一条 * 开头的卡片或文件结束
        nodes = []
        for ln in lines[start+1:]:
            if ln.strip().startswith('*') or not ln.strip():
                break
            nodes.append(ln.strip())
        return f'*Nset, nset={nset_name}\n' + '\n'.join(nodes) + '\n'

    cn7_block  = get_nset_block('CN7')
    nout_block = get_nset_block('NOUT')

    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
                       cn7_block)
    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
                       nout_block)

    # ---------- 写出完整的 *.inp* ----------
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的 Abaqus 输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

### 脚本工作原理（简要说明）

| 步骤 | 说明 |
|------|------|
| **读取模板** | `model_template.inp` 中的占位符保持原样。 |
| **读取四个 txt** | `nodes.txt`、`solid_elems.txt`、`shell_elems.txt`、`sets.txt` 必须全部存在。 |
| **节点 / 单元** | 直接把对应 txt 的全部内容（保留换行）替换到占位符。 |
| **Elset generate** | 脚本把 `*Elset, elset=XXX, generate` 行 **以及** 紧随其后的 `start,end,inc` 行一起粘进去，确保 `generate` 范围覆盖所有单元。 |
| **Nset CN7 / NOUT** | 把 `*Nset, nset=CN7`（或 NOUT）行本身以及后面的节点列表完整复制进模板。 |
| **写文件** | 生成 `model_complete.inp`，即可直接提交 Abaqus。 |

> **异常提示**：如果占位符、`*Elset`、`*Nset` 在 `sets.txt` 中找不到，脚本会抛出清晰的错误信息，帮助您快速定位问题。

## 5️⃣ 常见报错 & 快速定位（简表）

| 报错信息 | 可能原因 | 快速定位办法 |
|----------|----------|--------------|
| `*** ERROR: Invalid node label` | `nodes.txt` 中缺失某个节点号 | 在 `model_complete.inp` 中搜索报错行的节点号，确认 `nodes.txt` 是否包含该号 |
| `*** ERROR: Invalid element label` | `solid_elems.txt` / `shell_elems.txt` 中缺失单元号，或 `*Elset … generate` 范围不覆盖 | 检查 `*Elset, elset=SOLID, generate`（或 SHELL）行的 `start, end, inc` 是否覆盖所有单元号 |
| `*** ERROR: Node set CN7 not defined` | `sets.txt` 中没有 `*Nset, nset=CN7` 或脚本未正确粘贴 | 打开 `sets.txt`，确认 `*Nset, nset=CN7` 行存在且后面有节点列表 |
| `*** ERROR: Dload references undefined element` | `*Dload` 中的单元号（如 33、34）不在 `shell_elems.txt` 中 | 在 `shell_elems.txt` 中搜索对应单元号，若不存在则说明导出时漏掉该单元 |
| `*** ERROR: Rayleigh damping matrix is singular` | `*Damping, type=RAYLEIGH` 中的 `β` 取值过大 | 将第二个系数调小（如 `0.01`），重新提交 |

**定位技巧**：使用编辑器的全局搜索（Ctrl + F）快速定位报错行对应的编号，然后在相应的 txt 中检查是否存在。

## 3️⃣ `assemble_inp.py`（完整拼接脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib
import sys

# ------------------- 需要自行修改的路径 -------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')
output_inp   = pathlib.Path('model_complete.inp')   # 最终生成的完整 inp
# ---------------------------------------------------------

def read_file(fp: pathlib.Path) -> str:
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace(content: str, placeholder: str, replacement: str) -> str:
    """安全替换占位符，若未找到会抛异常"""
    if placeholder not in content:
        raise ValueError(f'占位符未找到: {placeholder}')
    return content.replace(placeholder, replacement)

def main() -> None:
    # ---------- 检查必需文件 ----------
    for p in (template_inp, nodes_file, solid_file, shell_file, sets_file):
        if not p.is_file():
            sys.exit(f'❌ 找不到必需文件: {p}')

    # ---------- 读取所有文件 ----------
    template = read_file(template_inp)
    nodes_txt = read_file(nodes_file)
    solid_txt = read_file(solid_file)
    shell_txt = read_file(shell_file)
    sets_txt  = read_file(sets_file)

    # ---------- 替换节点、体单元、壳单元 ----------
    template = replace(template,
                       '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
                       nodes_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
                       solid_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
                       shell_txt.rstrip() + '\n')

    # ---------- 处理 *Elset generate ----------
    lines = sets_txt.splitlines()

    def get_generate_block(elset_name: str) -> str:
        """返回 '*Elset, elset=NAME, generate' + 下一行(start,end,inc)"""
        key = f'*Elset, elset={elset_name}, generate'
        try:
            idx = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 两行合并为一个块（保留换行）
        return '\n'.join(lines[idx:idx+2])

    solid_generate = get_generate_block('SOLID')
    shell_generate = get_generate_block('SHELL')
    all_generate   = get_generate_block('ALL')

    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
                       solid_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
                       shell_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
                       all_generate)

    # ---------- 处理 *Nset CN7 与 NOUT ----------
    def get_nset_block(nset_name: str) -> str:
        """返回完整的 *Nset 块（包括 *Nset 行本身）"""
        key = f'*Nset, nset={nset_name}'
        try:
            start = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 收集后面的节点行，直到遇到下一条 * 开头的卡片或文件结束
        nodes = []
        for ln in lines[start+1:]:
            if ln.strip().startswith('*') or not ln.strip():
                break
            nodes.append(ln.strip())
        return f'*Nset, nset={nset_name}\n' + '\n'.join(nodes) + '\n'

    cn7_block  = get_nset_block('CN7')
    nout_block = get_nset_block('NOUT')

    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
                       cn7_block)
    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
                       nout_block)

    # ---------- 写出完整的 *.inp* ----------
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的 Abaqus 输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

**脚本工作原理（简要说明）**

| 步骤 | 说明 |
|------|------|
| **读取模板** | `model_template.inp` 中的占位符保持原样。 |
| **读取四个 txt** | `nodes.txt`、`solid_elems.txt`、`shell_elems.txt`、`sets.txt` 必须全部存在。 |
| **节点 / 单元** | 直接把对应 txt 的全部内容（保留换行）替换到占位符。 |
| **Elset generate** | 脚本把 `*Elset, elset=XXX, generate` 行 **以及** 紧随其后的 `start,end,inc` 行一起粘进去，确保 `generate` 范围覆盖所有单元。 |
| **Nset CN7 / NOUT** | 把 `*Nset, nset=CN7`（或 NOUT）行本身以及后面的节点列表完整复制进模板。 |
| **写文件** | 生成 `model_complete.inp`，即可直接提交 Abaqus。 |

> **异常提示**：如果占位符、`*Elset`、`*Nset` 在 `sets.txt` 中找不到，脚本会抛出清晰的错误信息，帮助您快速定位问题。

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib
import sys

# ------------------- 需要自行修改的路径 -------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
```

## 🛠️ 3️⃣ `assemble_inp.py`（完整拼接脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib
import sys

# ------------------- 需要自行修改的路径 -------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')
output_inp   = pathlib.Path('model_complete.inp')   # 最终生成的完整 inp
# ---------------------------------------------------------

def read_file(fp: pathlib.Path) -> str:
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace(content: str, placeholder: str, replacement: str) -> str:
    """安全替换占位符，若未找到会抛异常"""
    if placeholder not in content:
        raise ValueError(f'占位符未找到: {placeholder}')
    return content.replace(placeholder, replacement)

def main() -> None:
    # ---------- 检查必需文件 ----------
    for p in (template_inp, nodes_file, solid_file, shell_file, sets_file):
        if not p.is_file():
            sys.exit(f'❌ 找不到必需文件: {p}')

    # ---------- 读取所有文件 ----------
    template = read_file(template_inp)
    nodes_txt = read_file(nodes_file)
    solid_txt = read_file(solid_file)
    shell_txt = read_file(shell_file)
    sets_txt  = read_file(sets_file)

    # ---------- 替换节点、体单元、壳单元 ----------
    template = replace(template,
                       '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
                       nodes_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
                       solid_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
                       shell_txt.rstrip() + '\n')

    # ---------- 处理 *Elset generate ----------
    lines = sets_txt.splitlines()

    def get_generate_block(elset_name: str) -> str:
        """返回 '*Elset, elset=NAME, generate' + 下一行(start,end,inc)"""
        key = f'*Elset, elset={elset_name}, generate'
        try:
            idx = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 两行合并为一个块（保留换行）
        return '\n'.join(lines[idx:idx+2])

    solid_generate = get_generate_block('SOLID')
    shell_generate = get_generate_block('SHELL')
    all_generate   = get_generate_block('ALL')

    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
                       solid_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
                       shell_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
                       all_generate)

    # ---------- 处理 *Nset CN7 与 NOUT ----------
    def get_nset_block(nset_name: str) -> str:
        """返回完整的 *Nset 块（包括 *Nset 行本身）"""
        key = f'*Nset, nset={nset_name}'
        try:
            start = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        # 收集后面的节点行，直到遇到下一条 * 开头的卡片或文件结束
        nodes = []
        for ln in lines[start+1:]:
            if ln.strip().startswith('*') or not ln.strip():
                break
            nodes.append(ln.strip())
        return f'*Nset, nset={nset_name}\n' + '\n'.join(nodes) + '\n'

    cn7_block  = get_nset_block('CN7')
    nout_block = get_nset_block('NOUT')

    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
                       cn7_block)
    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
                       nout_block)

    # ---------- 写出完整的 *.inp* ----------
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的 Abaqus 输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

### 脚本工作原理（简要说明）

| 步骤 | 说明 |
|------|------|
| **读取模板** | `model_template.inp` 中的占位符保持原样。 |
| **读取四个 txt** | `nodes.txt`、`solid_elems.txt`、`shell_elems.txt`、`sets.txt` 必须全部存在。 |
| **节点 / 单元** | 直接把对应 txt 的全部内容（保留换行）替换到占位符。 |
| **Elset generate** | 脚本把 `*Elset, elset=XXX, generate` 行 **以及** 紧随其后的 `start,end,inc` 行一起粘进去，确保 `generate` 范围覆盖所有单元。 |
| **Nset CN7 / NOUT** | 把 `*Nset, nset=CN7`（或 NOUT）行本身以及后面的节点列表完整复制进模板，避免集合未定义。 |
| **写文件** | 生成 `model_complete.inp`，即可直接提交 Abaqus。 |

> **异常提示**：如果占位符、`*Elset`、`*Nset` 在 `sets.txt` 中找不到，脚本会抛出清晰的错误信息，帮助您快速定位问题。

## 🛑 5️⃣ 常见报错 & 快速定位（简表）

| 报错信息 | 可能原因 | 快速定位办法 |
|----------|----------|--------------|
| `*** ERROR: Invalid node label` | `nodes.txt` 中缺失某个节点号 | 在 `model_complete.inp` 中搜索报错行的节点号，确认 `nodes.txt` 是否包含该号 |
| `*** ERROR: Invalid element label` | `solid_elems.txt` / `shell_elems.txt` 中缺失单元号，或 `*Elset … generate` 范围不覆盖 | 检查 `*Elset, elset=SOLID, generate`（或 SHELL）行的 `start, end, inc` 是否覆盖所有单元号 |
| `*** ERROR: Node set CN7 not defined` | `sets.txt` 中没有 `*Nset, nset=CN7` 或脚本未正确粘贴 | 打开 `sets.txt`，确认 `*Nset, nset=CN7` 行存在且后面有节点列表 |
| `*** ERROR: Dload references undefined element` | `*Dload` 中的单元号（如 33、34）不在 `shell_elems.txt` 中 | 在 `shell_elems.txt` 中搜索对应单元号，若不存在则说明导出时漏掉该单元 |
| `*** ERROR: Rayleigh damping matrix is singular` | `*Damping, type=RAYLEIGH` 中的 `β` 取值过大 | 将第二个系数调小（如 `0.01`），重新提交 |

**定位技巧**：使用编辑器的全局搜索（Ctrl + F）快速定位报错行对应的编号，然后在相应的 txt 中检查是否存在。
