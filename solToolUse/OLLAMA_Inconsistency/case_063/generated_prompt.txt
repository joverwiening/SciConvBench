下面把 **“一键生成完整 *.inp*”** 所需的 **4 个文件**（模板 + 脚本 + 导出结果）以及 **2 次脚本运行** 的完整操作步骤全部写在一起。只要把它们全部放在同一个文件夹里，**一次 `export_mesh.py` → 一次 `assemble_inp.py`**，就会得到 **`model_complete.inp`**，直接提交 Abaqus。

---

## 📂 1️⃣ 文件清单（全部放在同一目录）

| 文件名 | 作用 | 关键内容 |
|--------|------|----------|
| **`export_mesh.py`** | 把 CAE 中的网格、集合等导出为四个 txt（**您已有**的脚本，只要保证输出的文件名和格式与下面示例一致即可） | 生成 `nodes.txt`、`solid_elems.txt`、`shell_elems.txt`、`sets.txt` |
| **`model_template.inp`** | 只保留标题、材料、截面、边界、分析步等 **固定块**，在需要插入节点/单元/集合的地方放 **占位符**（`<<--- … --->`） | 见下文完整示例 |
| **`assemble_inp.py`** | **拼接脚本**：读取四个 txt，替换模板中的占位符，生成 `model_complete.inp` | 见下文完整代码（已加入异常提示、路径可自行修改） |
| **`model_complete.inp`** | **最终生成的完整 Abaqus 输入文件**（由 `assemble_inp.py` 自动写出） | 直接提交 Abaqus |

> **⚠️** `export_mesh.py` 必须在每次网格改动后重新运行一次，以保证四个 txt 为最新内容。  
> `assemble_inp.py` 只需要运行 **一次**（或在 txt 更新后再次运行），不需要手动编辑任何 *.inp*。

## 📄 2️⃣ `model_template.inp`（模板示例）

> **占位符必须保持原样**（包括 `<<--- … --->`），否则脚本找不到替换位置。  
> 把已有的完整 `model.inp` 复制一份改名为 `model_template.inp`，然后把对应位置替换成占位符即可。

```text
*Heading
** Job name: Model
** Generated by: <your_user_name>
*Preprint, echo=NO, model=NO, history=NO, contact=NO
** -------------------------------------------------
*Part, name=PART-1
*Node
<<--- 把 nodes.txt 的全部内容粘在这里 --->

*Element, type=C3D20R
<<--- 把 solid_elems.txt 的全部内容粘在这里 --->

*Element, type=S8R
<<--- 把 shell_elems.txt 的全部内容粘在这里 --->

*Elset, elset=SOLID, generate
<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->

*Elset, elset=SHELL, generate
<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->

*Elset, elset=ALL, generate
<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->

*End Part
*Assembly, name=ASSEMBLY
*Instance, name=PART-1-1, part=PART-1
*End Instance
*End Assembly

*Nset, nset=CN7
<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->

*Nset, nset=NOUT
<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->

*Material, name=MAT1
*Elastic
210000., 0.3

*Solid Section, elset=SOLID, material=MAT1
*Shell Section, elset=SHELL, material=MAT1, thickness=1.0

*Boundary
CN7, 1, 6, 0.

*Step, name=MODAL, nlgeom=NO, inc=1000
*Frequency
10, 20
*End Step

*Step, name=STATIC, nlgeom=NO, inc=1000
*Static
1., 1., 1e-05, 1.
*Dload
SHELL, P, 1.0
*End Step
```

> **重要**：  
> * `*Elset, elset=SOLID, generate`、`*Elset, elset=SHELL, generate`、`*Elset, elset=ALL, generate` 必须保留 **generate** 行（后面紧跟 `start,end,inc`），脚本会把这两行一起粘进去。  
> * `*Nset` 行本身也会被粘进去（脚本会把 `*Nset, nset=CN7` 与后面的节点列表一起写入），避免 “集合未定义” 错误。

## 🛠️ 3️⃣ `assemble_inp.py`（完整拼接脚本）

```python
# -*- coding: utf-8 -*-
"""
assemble_inp.py
----------------
把 export_mesh.py 导出的四个文本文件粘进原始 *.inp* 模板，
生成“一键提交”的完整模型文件 model_complete.inp
"""

import pathlib
import sys

# ------------------- 需要自行修改的路径 -------------------
template_inp = pathlib.Path('model_template.inp')   # 模板文件
nodes_file   = pathlib.Path('nodes.txt')           # export_mesh.py 生成
solid_file   = pathlib.Path('solid_elems.txt')
shell_file   = pathlib.Path('shell_elems.txt')
sets_file    = pathlib.Path('sets.txt')
output_inp   = pathlib.Path('model_complete.inp')   # 最终生成的完整 inp
# -----------------------------------------------------------

def read_file(fp: pathlib.Path) -> str:
    """读取文件全部内容（保留换行）"""
    return fp.read_text(encoding='utf-8')

def replace(content: str, placeholder: str, replacement: str) -> str:
    """安全替换占位符，若未找到会抛异常"""
    if placeholder not in content:
        raise ValueError(f'占位符未找到: {placeholder}')
    return content.replace(placeholder, replacement)

def main() -> None:
    # 检查必需文件是否齐全
    for p in (template_inp, nodes_file, solid_file, shell_file, sets_file):
        if not p.is_file():
            sys.exit(f'❌ 找不到必需文件: {p}')

    # 读取所有文件
    template = read_file(template_inp)
    nodes_txt = read_file(nodes_file)
    solid_txt = read_file(solid_file)
    shell_txt = read_file(shell_file)
    sets_txt  = read_file(sets_file)

    # 替换节点、体单元、壳单元
    template = replace(template,
                       '<<--- 把 nodes.txt 的全部内容粘在这里 --->',
                       nodes_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 solid_elems.txt 的全部内容粘在这里 --->',
                       solid_txt.rstrip() + '\n')
    template = replace(template,
                       '<<--- 把 shell_elems.txt 的全部内容粘在这里 --->',
                       shell_txt.rstrip() + '\n')

    # 处理 *Elset generate
    lines = sets_txt.splitlines()

    def get_generate_block(elset_name: str) -> str:
        """返回 '*Elset, elset=NAME, generate' + 下一行(start,end,inc)"""
        key = f'*Elset, elset={elset_name}, generate'
        try:
            idx = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        return '\n'.join(lines[idx:idx+2])   # 两行一起返回

    solid_generate = get_generate_block('SOLID')
    shell_generate = get_generate_block('SHELL')
    all_generate   = get_generate_block('ALL')

    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SOLID, generate” 之后的那一行 --->',
                       solid_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=SHELL, generate” 之后的那一行 --->',
                       shell_generate)
    template = replace(template,
                       '<<--- 从 sets.txt 复制 “*Elset, elset=ALL, generate” 之后的那一行 --->',
                       all_generate)

    # 处理 *Nset CN7 与 NOUT
    def get_nset_block(nset_name: str) -> str:
        """返回完整的 *Nset 块（包括 *Nset 行本身）"""
        key = f'*Nset, nset={nset_name}'
        try:
            start = lines.index(key)
        except ValueError:
            raise ValueError(f'在 sets.txt 中未找到 {key}')
        nodes = []
        for ln in lines[start+1:]:
            if ln.strip().startswith('*') or not ln.strip():
                break
            nodes.append(ln.strip())
        return f'*Nset, nset={nset_name}\n' + '\n'.join(nodes) + '\n'

    cn7_block  = get_nset_block('CN7')
    nout_block = get_nset_block('NOUT')

    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=CN7” 之后的节点列表粘进来 --->',
                       cn7_block)
    template = replace(template,
                       '<<--- 把 sets.txt 中 “*Nset, nset=NOUT” 之后的节点列表粘进来 --->',
                       nout_block)

    # 写出完整的 *.inp*
    output_inp.write_text(template, encoding='utf-8')
    print(f'✅ 完整的 Abaqus 输入文件已生成 → {output_inp}')

if __name__ == '__main__':
    main()
```

**脚本工作原理简述**

| 步骤 | 说明 |
|------|------|
| 读取模板 | `model_template.inp` 中的占位符保持原样。 |
| 读取四个 txt | `nodes.txt`、`solid_elems.txt`、`shell_elems.txt`、`sets.txt` 必须全部存在。 |
| 替换节点/单元 | 直接把对应 txt 的全部内容（保留换行）替换到占位符。 |
| 处理 `*Elset, generate` | 把 `*Elset, elset=XXX, generate` 行 **以及** 紧随其后的 `start,end,inc` 行一起粘进去，确保 `generate` 范围覆盖所有单元。 |
| 处理 `*Nset` | 把 `*Nset, nset=CN7`（或 NOUT）行本身以及后面的节点列表完整复制进模板。 |
| 写文件 | 生成 `model_complete.inp`，即可直接提交 Abaqus。 |

> **异常提示**：如果占位符、`*Elset`、`*Nset` 在 `sets.txt` 中找不到，脚本会抛出清晰的错误信息，帮助您快速定位问题。

## 🚀 4️⃣ 使用步骤（最简流程）

```bash
# 1️⃣ 先把网格、集合等导出（生成四个 txt）
python export_mesh.py          # 您已有的脚本，只要成功生成四个 txt 即可

# 2️⃣ 拼接生成完整的 .inp
python assemble_inp.py         # 运行后会在同目录得到 model_complete.inp

# 3️⃣ 提交 Abaqus（示例）
abaqus job=model_complete interactive   # 或者您常用的 batch / GUI 提交方式
```

> **如果网格或材料有改动**：只需要重新执行 **① → ②** 两步，**③**（提交）不需要改动。

## 🛑 5️⃣ 常见报错 & 快速定位（简表）

| 报错信息 | 可能原因 | 快速定位办法 |
|----------|----------|--------------|
| `*** ERROR: Invalid node label` | `nodes.txt` 中缺失某个节点号 | 在 `model_complete.inp` 中搜索报错行的节点号，确认 `nodes.txt` 是否包含该号 |
| `*** ERROR: Invalid element label` | `solid_elems.txt` / `shell_elems.txt` 中缺失单元号，或 `*Elset … generate` 范围不覆盖 | 检查 `*Elset, elset=SOLID, generate`（或 SHELL）行的 `start, end, inc` 是否覆盖所有单元号 |
| `*** ERROR: Node set CN7 not defined` | `sets.txt` 中没有 `*Nset, nset=CN7` 或脚本未正确粘贴 | 打开 `sets.txt`，确认 `*Nset, nset=CN7` 行存在且后面有节点列表 |
| `*** ERROR: Dload references undefined element` | `*Dload` 中的单元号（如 33、34）不在 `shell_elems.txt` 中 | 在 `shell_elems.txt` 中搜索对应单元号，若不存在则说明导出时漏掉该单元 |
| `*** ERROR: Rayleigh damping matrix is singular` | `*Damping, type=RAYLEIGH` 中的 `β` 取值过大 | 将第二个系数调小（如 `0.01`），重新提交 |

**定位技巧**：使用编辑器的全局搜索（Ctrl + F）快速定位报错行对应的编号，然后在相应的 txt 中检查是否存在。

## 🔧 6️⃣ 扩展思路（如需更高级功能）

| 需求 | 需要在 `export_mesh.py` 里额外导出 | 在模板中预留占位符 | 脚本改动 |
|------|-----------------------------------|-------------------|----------|
| 接触面 (`*Surface`) | `surfaces.txt`（每行一块） | `<<--- surfaces.txt --->` | 增加 `replace` 调用 |
| 接触对 (`*Contact Pair`) | `contact_pairs.txt` | `<<--- contact_pairs.txt --->` | 同上 |
| 多材料 (`*Material` 块) | `materials.txt` | `<<--- materials.txt --->` | 同上 |
| 非线性材料、显式动力学等 | 对应卡片的 txt | 对应占位符 | 同上 |

只要在模板中留好占位符，`assemble_inp.py` 仍然可以一次性把所有块拼接进去，保持“一键生成” 的便利性。
