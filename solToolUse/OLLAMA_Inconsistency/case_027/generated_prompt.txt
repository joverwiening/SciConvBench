Use the legacy FEniCS (dolfin) library and a direct linear solver to solve a small‑strain linear elasticity problem in 2‑D plane‑stress.  
Create a right‑triangular domain with vertices (0,0), (1,0) and (0,0.5).  
Generate a conforming triangular mesh consisting of 64 elements covering the domain.  
Define a vector‑valued continuous Lagrange function space for the displacement field **u**.  
Use the material parameters: Young’s modulus E = 70 e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³, and gravitational acceleration g = 9.81 m/s².  
Apply a body force **f** = (0, –ρ g) to represent gravity (unit thickness).  
Impose a Dirichlet condition **u** = (0,0) on the base edge y = 0 (clamped boundary).  
Apply a uniform horizontal shear traction **t** = (2000, 0) Pa acting in the global x‑direction on the sloping edge defined by x + 2y = 1 (inward normal direction is not used).  
Use the reduced plane‑stress constitutive law σ = C ε with C derived from E and ν for unit thickness.  
Formulate the variational problem ∫Ω ε(v):C:ε(u) dx = ∫Ω v·f dx + ∫Γt v·t ds for all test functions v.  
Assemble and solve the linear system for the displacement field **u**.  
Compute the Cauchy stress tensor σ from the displacement gradient.  
Calculate the von Mises stress σ_vm = sqrt(σ_xx² – σ_xxσ_yy + σ_yy² + 3σ_xy²) at each integration point.  
Post‑process and output two scalar fields: the displacement magnitude |**u**| and the von Mises stress σ_vm, saved as VTK (or XDMF) files for visualization.
