**Quick cheat‑sheet for `abaqus_dat_extractor.py`**

| ✅ What it does | ✅ How to use |
|----------------|--------------|
| **Extract** the `*NODE PRINT` block that follows a comment containing **`NALL`** and the `*EL PRINT` block that follows a comment containing **`EALL`**. | `./abaqus_dat_extractor.py <your‑file>.dat` – prints CSV to the terminal. |
| **Pair** the *i‑th* node row with the *i‑th* element row (truncating to the shorter list). | `./abaqus_dat_extractor.py <your‑file>.dat out.csv` – writes CSV to *out.csv*. |
| **CSV header**: `node_id,U1,U2,U3,element_id,S11,S22,S33,S12,S13,S23`. | Open the CSV in Excel, pandas (`pd.read_csv`), R, etc. |

---

### One‑line customisations (just edit the line(s) indicated)

| Desired change | Edit |
|----------------|------|
| Add a fourth displacement column (`U4`) | Change `node_cols = [row[:4] …]` → `row[:5]` **and** add `"U4"` to the `header` list. |
| Accept `*NODE FILE` / `*EL FILE` blocks | In `extract_from_dat`: `nodes = _read_block(lines, "*NODE") or _read_block(lines, "*NODE FILE")` (same for `*EL`). |
| Tab‑delimited output | In `pair_and_write`: `delimiter="\t"` instead of `","`. |
| Raise an error if node‑ and element‑counts differ | After extraction: `if len(nodes) != len(elems): raise ValueError("Node and element blocks have different lengths")`. |
| Log to a file instead of `stderr` | Replace `sys.stderr.write(...)` with `logging.error(...)` after configuring a `FileHandler`. |
| Different comment marker (e.g. a single `*`) | No change needed – `_is_comment_containing` already works with any line that starts with `*`. |

Because the whole program is only ~150 lines, any of these tweaks can be made in a few seconds.

---

### TL;DR

```bash
python abaqus_dat_extractor.py <input>.dat [<output>.csv]
```

That’s all you need to turn the two Abaqus `*PRINT` sections into a tidy CSV ready for downstream analysis. Happy extracting!
