Q: Below is a short “check‑list” of the things that have to be in place for a **cyclic‑symmetry Green‑function extraction** and, most importantly, the **exact syntax that Abaqus expects for the output requests**.  
If any one of the items is missing or written with the wrong keyword the *.fil* file will be created but it will contain no mode‑shape data, which is exactly what you are seeing.

---

## 1. What the Green‑function step actually does  

| Command | What it does | What you have to ask for |
|---------|--------------|--------------------------|
| `*GREEN, STORAGE=YES` | Solves the eigenvalue problem for the selected cyclic‑symmetry modes and stores the Green’s functions in the *.fil* file. | Nothing else is required – the eigenvectors are automatically stored, **but you must request them as output**. |
| `*SELECT CYCLIC SYMMETRY MODES, NMIN=2, NMAX=2` | Tells Abaqus to keep only the second cyclic mode (the one you want). | OK – you already have this. |
| `*EL FILE, ELSET=…` | Requests **element‑level** output (stress, strain, etc.) for the Green‑function extraction. | Must refer to an **element set**, not a node set. |
| `*NODE FILE, NSET=…` (or `*EL FILE, … NOE`) | Requests **nodal** output (the eigenvector components). | Must be present if you want the mode shape. |

If you only write `*EL FILE, NSET=Nout` (where *Nout* is a **node set**) Abaqus silently ignores the request – the keyword is syntactically correct, but the set type is wrong, so no data are written.

---

## 2. Define an **element set** for the output  

You already have a small element set (`Edum`) that you use for the tie constraint, but you need a *different* set that contains **all the elements whose mode‑shape you want to write**.  
The easiest way is to create a set that contains *all* solid elements:

```abaqus
*ELSET, ELSET=Eout
1, 2, 3, 4, 5, 6, …   ! (list every element number, or use a range if you generated the mesh with a script)
```

If you do not want to type the numbers by hand, you can reuse the set you already created for the geometry:

```abaqus
*ELSET, ELSET=Eout, GENERATE
1, 662, 1   ! 1‑662 are the element numbers in your model
```

*(Replace 662 by the highest element number in your model.)*

---

## 3. Request **nodal eigenvectors**  

Two ways are possible; both give exactly the same data in the *.fil* file.

### 3.1. Using `*EL FILE` with the special variable **NOE**

```abaqus
*EL FILE, ELSET=Eout
S, NOE
```

* `S`  – stress (optional, you can drop it if you only need the mode shape).  
* `NOE` – **N**odal **O**utput for **E**igenvectors. This is the keyword that tells Abaqus to write the displacement components of the selected cyclic mode for every node belonging to the elements in *Eout*.

> **Important:** `*EL FILE` **must** be followed by an **element set** (`ELSET=`), not a node set. The variable list (`S, NOE`) is placed on the next line(s) exactly as shown above.

### 3.2. Using `*NODE FILE` (often clearer)

```abaqus
*NODE FILE, NSET=Nout
U
```

* `U` – the three displacement components of the eigenvector.  
* `Nout` must be a **node set** that contains the nodes for which you want the mode shape (you already have such a set).

Both approaches are accepted by Abaqus; you can even use them together (the *.fil* file will then contain the eigenvectors twice, which is harmless).

```abaqus
*NODE FILE, NSET=Nout
```

## 6. Common “gotchas” that still produce an empty *.fil*  

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| No `*EL FILE` or `*NODE FILE` at all | Green step creates a *.fil* but without any user‑requested data. | Add one of the two blocks shown above. |

## 2. Why the original short example sometimes produced an empty *.fil* file  

1. **`*EL FILE` must reference an *element* set** (`ELSET=`).  
   If you mistakenly write `*EL FILE, NSET=…` Abaqus silently ignores the request, so no eigen‑vector data are written.  

2. **The variable list must contain `NOE` (or `U`).**  
   Using a different variable name (e.g., `U1`) will not be recognised for the Green‑function step.  

3. **A dummy load (`*CLOAD`) is required** for the syntax of a *GREEN* step, but its magnitude is irrelevant – the eigen‑problem is solved independently of the load.  

4. **The element set must actually contain elements** that belong to the model region you are analysing.  
   An empty or miss‑spelled set leads to no output.

## 3. How to read the eigen‑vector from the *.fil* file  

### 3.1 With Abaqus Viewer (GUI)

1. Open **Abaqus Viewer**.  
2. *File → Open* → select the *.fil* file generated by the job.  
3. In the **Result** tree you will see a block called **GREEN** (or **CYCLIC GREEN**).  
4. Expand it → you will find **Mode 2 – Eigen‑vector** (or similar).  
5. Choose **U** (or **NOE**) as the displayed field; the displacement components for the nodes in `Nout` will be plotted.

### 3.2 With a short Python script (batch extraction)

```python
# --------------------------------------------------------------
# extract mode‑2 eigen‑vector from the .fil file
# --------------------------------------------------------------
from odbAccess import *
from abaqusConstants import *
import re

fil_name = 'job_name.fil'          # <-- change to your job name
mode_to_keep = 2                    # the cyclic mode you selected

# Helper to read the binary .fil file (Abaqus 2021+ uses binary format)
def read_fil_blocks(fil):
    import struct
    while True:
        header = fil.read(4)
        if not header:
            break
        block_len = struct.unpack('i', header)[0]
        block = fil.read(block_len-4)
        yield block

with open(fil_name, 'rb') as f:
    for block in read_fil_blocks(f):
        # The block that contains eigen‑vectors starts with '*GREEN' (ASCII 71)
        if b'*GREEN' in block:
            # Convert to string for easier parsing
            txt = block.decode('utf-8', errors='ignore')
            # Look for the mode number
            if f'  {mode_to_keep} ' in txt:
                # Extract node‑ID and three components (U1,U2,U3)
                pattern = r'\s+(\d+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)'
                for nid, u1, u2, u3 in re.findall(pattern, txt):
                    print(f'Node {nid:>6}:  U1={float(u1): .6e}  U2={float(u2): .6e}  U3={float(u3): .6e}')
                break
```

*The script looks for the `*GREEN` block that contains the eigen‑vector data, filters the block that corresponds to the selected mode (`mode_to_keep = 2`), and prints the three displacement components for every node that appears in the block.*  
You can easily adapt it to write the data to a CSV file or to feed a post‑processing routine.

The script below is a **drop‑in replacement** for the one you posted.  
It

* works with both Windows (`\r\n`) and Unix (`\n`) line endings,
* stops as soon as the requested mode is found,
* writes a tidy **CSV** file (`mode2_vector.csv`) that can be opened in Excel, pandas, etc.

```python
#!/usr/bin/env python3
# --------------------------------------------------------------
# Extract the nodal eigen‑vector of cyclic mode N=2 from an Abaqus *.fil*
# --------------------------------------------------------------

import struct
import re
import csv
import sys
from pathlib import Path

# ------------------------------------------------------------------
# USER INPUT ---------------------------------------------------------
# ------------------------------------------------------------------
fil_name   = Path('job_name.fil')   # <-- change to your job name
mode_keep  = 2                       # the cyclic mode you selected
csv_name   = Path('mode2_vector.csv')
# ------------------------------------------------------------------

def read_fil_blocks(file_obj):
    """Yield each binary block (including its 4‑byte length header)."""
    while True:
        hdr = file_obj.read(4)
        if not hdr:
            break
        block_len = struct.unpack('i', hdr)[0]   # length in bytes, includes the 4‑byte header
        yield file_obj.read(block_len - 4)

def extract_mode(block_bytes, mode):
    """Return a list of (node, u1, u2, u3) for the requested mode, or None."""
    txt = block_bytes.decode('utf-8', errors='ignore')
    # The GREEN block contains a line “…  MODE   2   …”.  Look for that.
    if f'  {mode} ' not in txt:
        return None

    # Regular expression that matches:  nodeID  u1  u2  u3
    pattern = re.compile(r'\s+(\d+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)')
    data = [(int(n), float(u1), float(u2), float(u3))
            for n, u1, u2, u3 in pattern.findall(txt)]
    return data if data else None

def main():
    if not fil_name.is_file():
        sys.exit(f'ERROR: *.fil* file not found: {fil_name}')

    with fil_name.open('rb') as f, csv_name.open('w', newline='') as csvfile:
        writer = csv.writer(csvfile)
        writer.writerow(['NodeID', 'U1', 'U2', 'U3'])

        for blk in read_fil_blocks(f):
            # Only GREEN blocks contain the string '*GREEN' at the start
            if b'*GREEN' in blk[:10]:
                mode_data = extract_mode(blk, mode_keep)
                if mode_data:
                    for row in mode_data:
                        writer.writerow(row)
                    print(f'✅  Mode {mode_keep} written to {csv_name}')
                    break
        else:
            sys.exit('⚠️  GREEN block for the requested mode not found.')

if __name__ == '__main__':
    main()
```

### 3.2 Python script (batch extraction → CSV)

The script below extracts the eigen‑vector of **mode 2** from the *.fil* file and writes a tidy **CSV** (`mode2_vector.csv`).  
It works on Windows and Linux, stops as soon as the requested mode is found, and tolerates both `\r\n` and `\n` line endings.

```python
#!/usr/bin/env python3
# --------------------------------------------------------------
# Extract the nodal eigen‑vector of cyclic mode N=2 from an Abaqus *.fil*
# --------------------------------------------------------------

import struct, re, csv, sys
from pathlib import Path

# ------------------- USER INPUT ------------------------------
fil_name   = Path('job_name.fil')   # <-- change to your job name
mode_keep  = 2                       # the cyclic mode you selected
csv_name   = Path('mode2_vector.csv')
# --------------------------------------------------------------

def read_fil_blocks(fobj):
    """Yield each binary block (excluding its 4‑byte length header)."""
    while True:
        hdr = fobj.read(4)
        if not hdr: break
        block_len = struct.unpack('i', hdr)[0]   # length includes the 4‑byte header
        yield fobj.read(block_len - 4)

def extract_mode(block, mode):
    """Return list of (node, u1, u2, u3) for the requested mode, or None."""
    txt = block.decode('utf-8', errors='ignore')
    if b'*GREEN' not in block[:10]:          # not a GREEN block
        return None
    if f'  {mode} ' not in txt:              # mode not present in this block
        return None
    # match: nodeID  u1  u2  u3
    pat = re.compile(r'\s+(\d+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)')
    data = [(int(n), float(u1), float(u2), float(u3))
            for n, u1, u2, u3 in pat.findall(txt)]
    return data if data else None

def main():
    if not fil_name.is_file():
        sys.exit(f'ERROR: *.fil* file not found: {fil_name}')

    with fil_name.open('rb') as f, csv_name.open('w', newline='') as csvfile:
        writer = csv.writer(csvfile)
        writer.writerow(['NodeID', 'U1', 'U2', 'U3'])

        for blk in read_fil_blocks(f):
            mode_data = extract_mode(blk, mode_keep)
            if mode_data:
                for row in mode_data:
                    writer.writerow(row)
                print(f'✅  Mode {mode_keep} written to {csv_name}')
                break
        else:
            sys.exit('⚠️  GREEN block for the requested mode not found.')

if __name__ == '__main__':
    main()
```

The script below extracts the eigen‑vector of **mode 2** from the *.fil* file and writes a tidy **CSV** (`mode2_vector.csv`).

```python
#!/usr/bin/env python3
# --------------------------------------------------------------
# Extract the nodal eigen‑vector of cyclic mode N=2 from an Abaqus *.fil*
# --------------------------------------------------------------

import struct, re, csv, sys
from pathlib import Path

# ------------------- USER INPUT --------------------------------
fil_name   = Path('job_name.fil')   # <-- change to your job name
mode_keep  = 2                       # the cyclic mode you selected
csv_name   = Path('mode2_vector.csv')

def read_fil_blocks(fobj):
    """Yield each binary block (excluding its 4‑byte length header)."""
    while True:
        hdr = fobj.read(4)
        if not hdr:
            break
        block_len = struct.unpack('i', hdr)[0]   # length includes the 4‑byte header
        yield fobj.read(block_len - 4)

    if f'  {mode} ' not in txt:              # mode not present in this block

    pat = re.compile(r'\s+(\d+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)\s+([-\d.Ee+]+)')
    data = [(int(n), float(u1), float(u2), float(u3))
            for n, u1, u2, u3 in pat.findall(txt)]
    return data if data else None

    if not fil_name.is_file():
        sys.exit(f'ERROR: *.fil* file not found: {fil_name}')

    with fil_name.open('rb') as f, csv_name.open('w', newline='') as csvfile:
        writer = csv.writer(csvfile)
        writer.writerow(['NodeID', 'U1', 'U2', 'U3'])

                print(f'✅  Mode {mode_keep} written to {csv_name}')
                break
        else:
```
