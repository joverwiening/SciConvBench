D = (E/(1‑ν²)) * [[1, ν, 0],

Apply Dirichlet boundary condition u = (0,0) on the left edge x = 0 (clamped).

t(x) = (0, ‑5e3 · sin(π x)) Pa,

∫_Ω ε(v):D:ε(u) dx = ∫_Ω v·f dx + ∫_{Γ_N} v·t ds

Assemble the linear system and solve it with a direct linear solver (e.g., “lu”).  

Compute the Cauchy stress σ = D:ε(u).  

Compute the von Mises stress  

σ_vm = sqrt(σ_xx² - σ_xx·σ_yy + σ_yy² + 3·σ_xy²).
