Use FEniCS legacy (dolfin) to solve a small‑strain linear elasticity problem on a 2‑D right‑triangular domain with plane‑stress assumptions and unit thickness.

Geometry  
- Right triangle with vertices (0, 0), (1, 0) and (0, 0.5).  
- The sloping hypotenuse is the line x + 2y = 1.  

Material properties (plane stress)  
- Young’s modulus E = 70 e9 Pa.  
- Poisson’s ratio ν = 0.33.  
- Density ρ = 2700 kg/m³.  
- Plane‑stress constitutive matrix  
  D = E/(1‑ν²) * [[1, ν, 0], [ν, 1, 0], [0, 0, (1‑ν)/2]].  

Body force (gravity)  
- Apply a body force vector f = (0, ‑ρ g) with g = 9.81 m/s² (downward).  

Boundary conditions  
- Dirichlet: displacement u = (0, 0) on the vertical edge x = 0 (clamped).  
- Neumann: traction t on the sloping edge x + 2y = 1 is a normal traction of magnitude 3000 Pa applied as t = 3000 Pa · n̂, where n̂ is the outward unit normal of the domain (n̂ = (1, 2)/√5).  

Finite‑element discretisation  
- Use a vector‑valued continuous Lagrange space of degree 1 (P1) for the displacement field.  
- Generate a mesh of the triangle consisting of 64 triangular elements (e.g., create a rectangular mesh and retain only cells inside the triangle).  

Variational formulation  
- Define the strain ε(u) = sym(∇u).  
- Define the stress σ(u) = D · ε(u).  
- Weak form: find u ∈ V such that  
  ∫_Ω ε(v) : σ(u) dx = ∫_Ω v · f dx + ∫_{Γ_N} v · t ds ∀ v ∈ V₀,  
  where Γ_N is the sloping boundary and V₀ incorporates the Dirichlet condition on x = 0.  

Solver  
- Assemble the linear system and solve with a direct linear solver (e.g., “lu”).  

Post‑processing  
- Compute the displacement magnitude |u| at each node.  
- Compute the Cauchy stress components σ_xx, σ_yy, σ_xy from σ(u).  
- Compute the von Mises stress σ_vm = sqrt(σ_xx² – σ_xx σ_yy + σ_yy² + 3 σ_xy²) at each integration point or node.  
- Export the displacement magnitude and von Mises stress fields (e.g., to VTK files) for visualization.
