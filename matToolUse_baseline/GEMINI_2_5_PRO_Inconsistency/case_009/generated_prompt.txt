Write a Python function named `compute_defect_properties`.
The function will use the Pymatgen library.
The function calculates the number of chemical potential limits for a defect in Gallium Nitride (GaN).
The function takes no input arguments.
A hardcoded string variable `file_path` will be set to './data_directory/' to represent the base directory for input files.
The bulk host material is GaN.
The valence band maximum (VBM) for the bulk material will be read from the `vasprun.xml.gz` file located in the `bulk_sc` subdirectory.
A list of stable entries will be loaded from the `stable_entries_Mg_Ga_N.json` file located in the base directory.
The defect is an Mg atom substituting a Ga atom.
Defect entries will be created for charge states -2, -1, 0, and 1.
For each charge state `q`, the corresponding `vasprun.xml.gz` and `LOCPOT.gz` files will be read from a subdirectory named `charge_q` within the `Mg_Ga` directory.
No electrostatic correction scheme will be applied when creating the defect entries.
A `FormationEnergyDiagram` will be constructed using the stable entries, the VBM, and the defect entries for charge states -2, -1, 0, and 1.
The function will calculate the `chemical_potential_limits_count`, which is the number of chemical potential limits in the constructed `FormationEnergyDiagram`.
The function will return a dictionary with a single key-value pair.
The key will be the string `chemical_potential_limits_count`.
The value will be the calculated integer count.
The function will include a complete docstring describing its purpose and return value.
The function will include all necessary imports from the Pymatgen library.
