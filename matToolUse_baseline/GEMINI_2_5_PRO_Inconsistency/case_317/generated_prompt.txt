The working directory is data/bandgap/CdTe.
The goal is to compute the electronic band gap of CdTe using VASP.
The workflow consists of a PBE ground-state calculation followed by an HSE calculation.
The input files are POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh.
First, perform a PBE ground-state calculation.
Create an INCAR file for the PBE calculation based on best practices for a structural relaxation.
The PBE INCAR file will contain the following parameters: PREC=Normal, ENCUT=450, IBRION=2, ISIF=3, NSW=100, EDIFF=1E-5, EDIFFG=-0.01, ISMEAR=0, SIGMA=0.05, LREAL=Auto, LWAVE=.TRUE., LCHARG=.TRUE., and ISPIN=1.
Run VASP using the command `bash run_vasp.sh`.
Save the INCAR file from this step by running `cp INCAR INCAR1`.
Second, perform an HSE calculation.
Use the original POSCAR file as the input structure for the HSE calculation.
Create a new INCAR file for the HSE calculation.
The HSE INCAR file will contain the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, and PRECFOCK=Fast.
The parameters NBAND and NELECT will not be specified in the HSE INCAR file.
No magnetic moments will be specified in the HSE INCAR file.
Run VASP again using the command `bash run_vasp.sh`.
Save the INCAR file from this step by running `cp INCAR INCAR2`.
Third, extract the band gap.
Run the post-processing script using the command `python gap.py`.
The final output will be the band-gap value printed by the script.
