Calculate the electronic band gap of ZnO using VASP in the directory `data/bandgap/ZnO`.
Use the provided `POSCAR`, `KPOINTS`, and `POTCAR` files as inputs.
The workflow consists of three steps.
First, perform a PBE ground-state structural relaxation.
Create an INCAR file for the PBE calculation with the following parameters: PREC=Normal, ENCUT=450, IBRION=2, NSW=100, ISIF=3, EDIFF=1E-5, EDIFFG=-1E-2, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., LCHARG=.TRUE., ISPIN=1.
Run VASP for the PBE step by executing the command `bash run_vasp.sh`.
After the PBE calculation, save the INCAR file by running `cp INCAR INCAR1`.
Second, perform an HSE calculation.
Create a new INCAR file for the HSE calculation with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
Run VASP for the HSE step by executing the command `bash run_vasp.sh`.
After the HSE calculation, save the INCAR file by running `cp INCAR INCAR2`.
Third, extract the band gap.
Run the post-processing script by executing the command `python gap.py`.
The final output is the band-gap value printed by the `gap.py` script.
