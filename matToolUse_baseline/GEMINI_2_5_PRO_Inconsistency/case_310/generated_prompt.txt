The working directory is data/bandgap/AlN.
The goal is to compute the electronic band gap of AlN using VASP.
The workflow consists of a PBE ground-state calculation, followed by an HSE calculation, and finally band gap extraction.
The input files are POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh.
For the first step, a PBE ground-state calculation, create an INCAR file using reasonable best-practice parameters.
Run the PBE calculation using the command `bash run_vasp.sh`.
After the PBE calculation, save the INCAR file as INCAR1 using the command `cp INCAR INCAR1`.
For the second step, an HSE calculation, create a new INCAR file.
The parameters for the HSE INCAR are: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
The parameters NBAND and NELECT should not be specified in the HSE INCAR.
Magnetic moments should not be specified in the HSE INCAR.
Run the HSE calculation using the command `bash run_vasp.sh`.
After the HSE calculation, save the INCAR file as INCAR2 using the command `cp INCAR INCAR2`.
For the third step, extract the band gap.
Run the extraction script using the command `python gap.py`.
The final output should be the band-gap value exactly as printed by the gap.py script.
