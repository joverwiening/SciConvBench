Create an INCAR file for a VASP structural relaxation.
The INCAR file must contain the exact parameter block provided in the instructions.
The parameters in the provided block take precedence over the prose description in the task summary.
Run the VASP calculation using the command `bash run_vasp.sh`.
After the VASP run, copy the INCAR file to INCAR1 using the command `cp INCAR INCAR1`.
Extract the optimized total energy using the command `python get_energy.py`.
The final output must be the numerical value of the total energy, exactly as printed by the `get_energy.py` script.
