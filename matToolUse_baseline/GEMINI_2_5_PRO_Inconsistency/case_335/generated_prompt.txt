Compute the adsorption energy of CO on a PtO2 surface using VASP.
The process involves three geometry optimization calculations followed by a post-processing script.
The first calculation is a geometry optimization of a CO molecule.
The second calculation is a geometry optimization of the clean PtO2 surface.
The third calculation is a geometry optimization of the CO-adsorbed PtO2 system.
The fourth step is to run a script that calculates the adsorption energy from the results of the first three steps.
All three geometry optimizations will use a consistent set of INCAR parameters.
The INCAR file will include EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, and SIGMA = 0.2.
The INCAR file will also include NSW = 200, EDIFF = 1E-5, NELM = 100, and LREAL = Auto.
Van der Waals corrections will be included in all calculations via the DFT-D3 method (IVDW = 11).
Dipole corrections (LDIPOL = .TRUE., IDIPOL = 3) will be used for the clean surface and adsorbed system calculations.
The CO molecule optimization will use a Gamma-point only KPOINTS file with a 1x1x1 mesh.
The clean surface and adsorbed system optimizations will use the provided `KPOINTS` file.
The input structure for the CO optimization is `POSCAR-CO`.
The input pseudopotentials for the CO optimization are in `POTCAR-CO`.
The input structure for the clean surface optimization is `POSCAR-PtO2face`.
The input pseudopotentials for the clean surface optimization are in `POTCAR-PtO2face`.
The input structure for the adsorbed system optimization is `POSCAR-PtO2CO`.
The input pseudopotentials for the adsorbed system optimization are in `POTCAR-PtO2CO`.
The optimization calculations will be launched using the `op.py` script.
The final adsorption energy will be calculated by running the `calc_absorption_energy.sh` script.
The required output is the numerical value of the adsorption energy as printed by the `calc_absorption_energy.sh` script.
