Compute the adsorption energy of CO on the provided RhO2 surface using VASP.
The working directory is `data/absorptionE5/RhO2`.
The calculation consists of four steps performed in sequence.
A single INCAR file will be used for the three geometry optimization steps.
The INCAR file will contain the following parameters: EDIFF=1E-5, EDIFFG=-0.05, ENCUT=450, IBRION=1, ISIF=2, ISMEAR=1, ISPIN=1, LREAL=Auto, LWAVE=.FALSE., LCHARG=.FALSE., NSW=200, POTIM=0.2, PREC=Normal, and SIGMA=0.2.
The VASP calculations will be run on 16 cores.
Step 1 is to perform a geometry optimization of the CO molecule.
In Step 1, run the command `python op.py CO POTCAR-CO POSCAR-CO`.
Step 2 is to perform a geometry optimization of the clean RhO2 surface.
In Step 2, run the command `python op.py surface POTCAR-RhO2face POSCAR-RhO2face`.
Step 3 is to perform a geometry optimization of the CO-adsorbed RhO2 system.
In Step 3, run the command `python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO`.
Step 4 is to compute the final adsorption energy from the results of the previous steps.
In Step 4, run the command `bash ./calc_absorption_energy.sh`.
The final output must be the adsorption energy value exactly as printed by the `calc_absorption_energy.sh` script.
