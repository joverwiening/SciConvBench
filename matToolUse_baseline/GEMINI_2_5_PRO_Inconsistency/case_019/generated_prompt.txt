Write a Python function to compute defect properties using Pymatgen.
The function should not require any input arguments.
The function will compute the Shockley-Read-Hall (SRH) coefficient and a runtime error check.
Assume a base directory `file_path` contains the necessary input files.
Read the WSWQ files from the directory `file_path/v_Ga/ccd_0_-1/wswqs`.
Use the WSWQ files to build a `HarmonicDefect` object.
Calculate the SRH coefficient for the defect at temperatures of 300, 600, and 900 Kelvin.
The result for the SRH coefficient should be a list of float values.
Verify that a `RuntimeError` is raised when attempting to calculate the SRH coefficient for an invalid transition from charge state 0 to charge state 0.
The result of this verification should be a boolean value.
The function must return a dictionary.
The dictionary keys should be `SRH_Coefficient` and `RuntimeError_Check`.
The dictionary values should be the corresponding calculated results.
The function implementation must include all necessary imports from the Pymatgen library.
The function must have a complete docstring detailing its purpose and return value.
