Write a Python function named `compute_gan_defect_properties`.
The function will not accept any input arguments.
The function will assume the input files `GaN.vasp` and `stable_entries_Mg_Ga_N.json` are located in the current working directory.
The function will read the bulk crystal structure from the `GaN.vasp` file.
The function will read a list of stable computed entries from the `stable_entries_Mg_Ga_N.json` file.
The function will build a phase diagram for the Mg-Ga-N chemical system using the stable entries.
The function will calculate the reduced chemical formula of the bulk material and assign it to the `bulk_formula` key.
The function will determine the chemical system from all elements in the stable entries file and format it as a hyphen-separated string for the `defect_chemsys` key.
The function will determine the chemical potential limits for the bulk GaN material within the Mg-Ga-N phase diagram.
The function will count the number of these chemical potential limits and assign the integer result to the `chempot_limits_count` key.
The function will return a dictionary containing the keys `chempot_limits_count`, `defect_chemsys`, and `bulk_formula` with their calculated values.
The function must include a complete docstring.
The function must include all necessary imports from the Pymatgen library.
