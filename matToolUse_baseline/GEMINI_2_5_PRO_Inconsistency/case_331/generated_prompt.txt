The working directory is data/bandgap/SnO2.
The goal is to compute the electronic band gap of SnO2 using VASP.
The workflow consists of a PBE ground state calculation followed by an HSE calculation.
The final band gap is obtained by running the gap.py script.
The input files are POSCAR, KPOINTS, POTCAR, gap.py, and run_vasp.sh.
For the first step, a PBE ground-state calculation will be performed.
This PBE calculation will include a full structural relaxation of atomic positions, cell shape, and cell volume.
An INCAR file will be created for the PBE calculation with parameters assumed based on best practices for a structural relaxation.
The PBE calculation will be executed by running the command `bash run_vasp.sh`.
After the PBE calculation, the INCAR file will be saved as INCAR1 using the command `cp INCAR INCAR1`.
For the second step, an HSE calculation will be performed.
A new INCAR file will be created for the HSE calculation.
The HSE INCAR will use the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
The HSE calculation will start from the WAVECAR of the previous PBE step.
The HSE INCAR will not specify magnetic moments, NBAND, or NELECT.
The HSE calculation will be executed by running the command `bash run_vasp.sh`.
After the HSE calculation, the INCAR file will be saved as INCAR2 using the command `cp INCAR INCAR2`.
For the third step, the band gap will be extracted.
The band gap extraction will be performed by running the command `python gap.py`.
The final output will be the band-gap value printed by the gap.py script.
