Compute the adsorption energy of CO on a PdO2 surface using VASP.
The calculation consists of four steps.
First, perform a geometry optimization of the CO molecule using the `POSCAR-CO` and `POTCAR-CO` files.
This first step is executed by running `python op.py CO POTCAR-CO POSCAR-CO`.
Second, perform a geometry optimization of the clean PdO2 surface using the `POSCAR-PdO2face` and `POTCAR-PdO2face` files.
This second step is executed by running `python op.py surface POTCAR-PdO2face POSCAR-PdO2face`.
Third, perform a geometry optimization of the CO-adsorbed PdO2 system using the `POSCAR-PdO2CO` and `POTCAR-PdO2CO` files.
This third step is executed by running `python op.py absorbed POTCAR-PdO2CO POSCAR-PdO2CO`.
Fourth, calculate the adsorption energy from the results of the previous steps.
This fourth step is executed by running `bash ./calc_absorption_energy.sh`.
The final result is the adsorption energy value printed by the `calc_absorption_energy.sh` script.
All VASP calculations will use the provided `KPOINTS` file.
The INCAR file for all three geometry optimizations will contain ENCUT = 450, EDIFFG = -0.05, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, and SIGMA = 0.2.
The INCAR file will also include EDIFF = 1E-5, NSW = 200, PREC = Accurate, ALGO = Normal, and LREAL = Auto.
No van der Waals correction will be used.
A dipole correction will be applied for the surface and adsorbed system calculations.
No dipole correction will be applied for the CO molecule calculation.
