The working directory is data/bandgap/MoS2.
The goal is to compute the electronic band gap of MoS2 using VASP.
The calculation will use the provided POSCAR, KPOINTS, and POTCAR files.
First, perform a PBE ground-state calculation.
Create an INCAR file for the PBE ground-state calculation based on best practices for a standard static calculation.
Run the PBE calculation using the command `bash run_vasp.sh`.
After the PBE calculation, save the INCAR file by running `cp INCAR INCAR1`.
Second, perform an HSE calculation.
Create a new INCAR file for the HSE calculation.
The HSE INCAR will use the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
For the HSE INCAR, set the ICHARG parameter to 0.
The HSE INCAR will not specify magnetic moments.
The HSE INCAR will not specify NBAND or NELECT parameters.
Run the HSE calculation using the command `bash run_vasp.sh`.
After the HSE calculation, save the INCAR file by running `cp INCAR INCAR2`.
Finally, extract the band gap by running the script `gap.py` with the command `python gap.py`.
The final output will be the band-gap value printed by the `gap.py` script.
