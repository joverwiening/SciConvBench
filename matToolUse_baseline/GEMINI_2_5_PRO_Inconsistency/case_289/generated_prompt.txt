Perform a VASP structural relaxation for LiCoO2.
The working directory is `data/relax/LiCoO2`.
Create an INCAR file for the relaxation.
The INCAR file will contain the parameter ALGO = Fast.
The INCAR file will contain the parameter EDIFF = 0.0002.
The INCAR file will contain the parameter ENCUT = 520.0.
The INCAR file will contain the parameter IBRION = 2.
The INCAR file will contain the parameter ISIF = 3.
The INCAR file will contain the parameter ISMEAR = -5.
The INCAR file will contain the parameter ISPIN = 2.
The INCAR file will contain the parameter LASPH = .TRUE..
The INCAR file will contain the parameter LDAU = .TRUE..
The INCAR file will contain the parameter LDAUJ = 0 0 0.
The INCAR file will contain the parameter LDAUL = 0 2 0.
The INCAR file will contain the parameter LDAUPRINT = 1.
The INCAR file will contain the parameter LDAUTYPE = 2.
The INCAR file will contain the parameter LDAUU = 0 3.32 0.
The INCAR file will contain the parameter LMAXMIX = 4.
The INCAR file will contain the parameter LORBIT = 11.
The INCAR file will contain the parameter LREAL = Auto.
The INCAR file will contain the parameter LWAVE = .FALSE..
The INCAR file will contain the parameter MAGMOM = 31*-0.0.
The INCAR file will contain the parameter NELM = 100.
The INCAR file will contain the parameter NSW = 99.
The INCAR file will contain the parameter PREC = Accurate.
The INCAR file will contain the parameter SIGMA = 0.05.
Use the provided POSCAR, KPOINTS, and POTCAR files as inputs for the calculation.
Launch the VASP calculation by executing the command `bash run_vasp.sh`.
After the calculation finishes, preserve the INCAR file by copying it to INCAR1 with the command `cp INCAR INCAR1`.
Extract the final total energy from the output using the provided `get_energy.py` script.
Execute the extraction script with the command `python get_energy.py`.
The final output should be only the numerical value of the optimized total energy printed by the script.
