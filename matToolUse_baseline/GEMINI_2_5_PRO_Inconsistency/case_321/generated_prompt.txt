Compute the electronic band gap of GaN using VASP in the `data/bandgap/GaN` directory.
The workflow involves a PBE ground state calculation followed by an HSE calculation.
The final band gap is extracted by running the `gap.py` script.
Use the provided `POSCAR`, `KPOINTS`, `POTCAR`, `gap.py`, and `run_vasp.sh` files.
First, perform a PBE ground-state calculation.
Create an INCAR file for the PBE step with the following parameters: PREC=Normal, ENCUT=450, NELM=100, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., LCHARG=.TRUE., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1.
Execute VASP for the PBE step by running the command `bash run_vasp.sh`.
After the run, save the INCAR file by executing `cp INCAR INCAR1`.
Second, perform an HSE calculation.
Create a new INCAR file for the HSE step with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=1, ICHARG=1, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
Execute VASP for the HSE step by running the command `bash run_vasp.sh`.
After the run, save the INCAR file by executing `cp INCAR INCAR2`.
Third, extract the band gap.
Run the post-processing script by executing the command `python gap.py`.
The final output must be the exact band-gap value printed by the `gap.py` script.
