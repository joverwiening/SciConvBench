The user wants to compute the electronic band gap of GaAs using VASP in the directory `data/bandgap/GaAs`.
The workflow involves a PBE ground-state calculation, followed by an HSE calculation, and finally band gap extraction.
The input files are `POSCAR`, `KPOINTS`, `POTCAR`, `data.json`, `gap.py`, and `run_vasp.sh`.

The first step is a PBE ground-state calculation.
Create an INCAR file for the PBE calculation.
This INCAR file should specify a structural relaxation (IBRION=2, ISIF=3, NSW=100).
Set the energy cutoff ENCUT to 450 eV.
Set the electronic convergence criterion EDIFF to 1E-6.
Use Gaussian smearing with ISMEAR=0 and SIGMA=0.05.
The calculation is non-spin-polarized (ISPIN=1).
Write the WAVECAR and CHGCAR files by setting LWAVE=.TRUE. and LCHARG=.TRUE..
Execute the PBE calculation by running `bash run_vasp.sh`.
Save the INCAR file for this step by running `cp INCAR INCAR1`.

The second step is an HSE calculation.
Create a new INCAR file for the HSE calculation.
The parameters for this INCAR are PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, and PRECFOCK=Fast.
The ISTART tag must be set to 0.
The ICHARG tag must be set to 0.
Execute the HSE calculation by running `bash run_vasp.sh`.
Save the INCAR file for this step by running `cp INCAR INCAR2`.

The third step is to extract the band gap.
Run the post-processing script by executing `python gap.py`.
The final output should be the band-gap value printed by the script.
