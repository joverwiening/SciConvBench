Calculate the electronic band gap of SiC using VASP in the `data/bandgap/SiC` directory.
The calculation involves a PBE ground-state step followed by an HSE calculation step.
For the first step, create an INCAR file for a PBE ground-state calculation using reasonable best-practice parameters for a structural relaxation.
Run the PBE calculation with the command `bash run_vasp.sh`.
After the PBE calculation finishes, copy the INCAR file to `INCAR1`.
For the second step, create a new INCAR file for the HSE calculation.
The HSE calculation will use the original POSCAR file, not the CONTCAR from the PBE step.
The HSE INCAR file will contain the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
In the HSE INCAR, set ISTART=0.
In the HSE INCAR, set ICHARG=0.
Do not include NBAND, NELECT, or magnetic moment parameters in the HSE INCAR.
Run the HSE calculation with the command `bash run_vasp.sh`.
After the HSE calculation finishes, copy the INCAR file to `INCAR2`.
For the third step, extract the band gap by running `python gap.py`.
The final result is the numerical value printed to standard output by `gap.py`.
