Create the VASP input file named INCAR.
The INCAR file must contain the following key-value pairs:
ALGO = Fast
EDIFF = 0.0001
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 35*2.758
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Run the VASP calculation using the command `bash run_vasp.sh`.
After the calculation, copy the INCAR file to a new file named INCAR1.
Extract the optimized total energy by running the script `python get_energy.py`.
The final output should be the optimized total energy as printed by the `get_energy.py` script.
