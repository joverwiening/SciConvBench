Create an INCAR file for a VASP structural relaxation.
The INCAR file must contain the following parameters: ALGO = Fast, EDIFF = 0.0008, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 4, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 31*0.0, NELM = 100, NSW = 99, PREC = Accurate, and SIGMA = 0.05.
Use the provided POSCAR, KPOINTS, and POTCAR files as inputs for the calculation.
Execute the VASP calculation by running the script `run_vasp.sh`.
After the VASP calculation is complete, create a copy of the INCAR file named INCAR1.
Extract the final total energy from the output by running the script `get_energy.py`.
Return the optimized total energy exactly as printed by the `get_energy.py` script.
