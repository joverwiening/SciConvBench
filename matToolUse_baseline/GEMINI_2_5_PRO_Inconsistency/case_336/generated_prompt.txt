Compute the adsorption energy of CO on the provided Rh surface using VASP.
The calculation consists of four steps: optimizing the CO molecule, optimizing the clean surface, optimizing the adsorbed system, and running a post-processing script.
Use the provided `POSCAR-*`, `POTCAR-*`, and `KPOINTS` files for the corresponding steps.
For the three VASP optimization calculations, use an INCAR file with the following settings.
Set EDIFFG to -0.05.
Set ENCUT to 450.
Set IBRION to 1.
Set ISIF to 2 to keep the unit cell fixed for all calculations.
Set ISMEAR to 1.
Set ISPIN to 1 for no spin polarization in all calculations.
Set POTIM to 0.2.
Set SIGMA to 0.2.
Set values for NSW, EDIFF, LREAL, and dipole corrections based on common best practices.
Run the optimization for the CO molecule using the command `python op.py CO POTCAR-CO POSCAR-CO`.
Run the optimization for the clean Rh surface using the command `python op.py surface POTCAR-Rhface POSCAR-Rhface`.
Run the optimization for the CO-adsorbed Rh system using the command `python op.py absorbed POTCAR-RhCO POSCAR-RhCO`.
After the optimizations are complete, calculate the adsorption energy by running `bash ./calc_absorption_energy.sh`.
The final output will be the adsorption energy value printed by the `calc_absorption_energy.sh` script.
