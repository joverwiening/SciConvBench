The goal is to compute the transition-state energy barrier using a VASP NEB workflow.
All operations will be performed inside the `data/NEB1/AgPdneb1` directory.
The workflow consists of five steps.
Step 1 is to optimize the initial state (IS).
Create an INCAR file for the IS relaxation.
The INCAR file for the IS relaxation must contain the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2.
Use a standard value for the electronic energy convergence criterion (EDIFF) in the IS relaxation INCAR file.
Use a sufficiently large value for the number of ionic steps (NSW) in the IS relaxation INCAR file.
Run the IS relaxation using the command: `python op.py IS POTCARagpd IS1POSCAR`.
Step 2 is to optimize the final state (FS).
Create an INCAR file for the FS relaxation using the same parameters as the IS relaxation.
Run the FS relaxation using the command: `python op.py FS POTCARagpd FS1POSCAR`.
Step 3 is to interpolate the intermediate images.
Four intermediate images should be created between the initial and final states.
Run the interpolation using the command: `python nebmake.py`.
Step 4 is to run the NEB calculation.
Create an INCAR file for the NEB calculation.
The INCAR file for the NEB calculation must contain the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 3, IMAGES = 4, LCLIMB = .TRUE., IOPT = 7, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0, SIGMA = 0.2, SPRING = -5.
Use a standard value for the electronic energy convergence criterion (EDIFF) in the NEB INCAR file.
Use a sufficiently large value for the number of ionic steps (NSW) in the NEB INCAR file.
Run the NEB calculation using the command: `python op2.py ./`.
Step 5 is to extract the energy barrier.
Run the extraction script using the command: `bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'`.
The final output should be the reaction-barrier value produced by the extraction step.
