Compute the electronic band gap of CdS using VASP in the `data/bandgap/CdS` directory.
The workflow has three steps: a PBE ground-state calculation, an HSE calculation, and band gap extraction.
Use the provided `POSCAR`, `KPOINTS`, `POTCAR`, `gap.py`, and `run_vasp.sh` files.
For the first step, create an `INCAR` file for a PBE ground-state relaxation.
The PBE `INCAR` will contain the following parameters: `PREC=Normal`, `ENCUT=450`, `EDIFF=1E-5`, `ISPIN=1`, `ISMEAR=0`, `SIGMA=0.05`, `LWAVE=.TRUE.`, `LCHARG=.TRUE.`, `LREAL=Auto`, `LPLANE=.TRUE.`, `NPAR=1`, `KPAR=4`, `NCORE=1`, `LORBIT=11`, `ALGO=Normal`, `IBRION=2`, `NSW=100`, `ISIF=3`, and `EDIFFG=-0.02`.
Run the PBE calculation with the command `bash run_vasp.sh`.
After the PBE calculation, copy the `INCAR` file to `INCAR1`.
For the second step, create a new `INCAR` file for the HSE calculation.
The HSE `INCAR` will contain the following parameters: `PREC=Normal`, `ENCUT=450`, `NELM=500`, `IBRION=-1`, `ISPIN=1`, `NSW=0`, `ISIF=2`, `EDIFF=1E-5`, `EDIFFG=-5E-3`, `ISTART=0`, `ICHARG=0`, `ISMEAR=0`, `SIGMA=0.05`, `LWAVE=.T.`, `LCHARG=.T.`, `LREAL=Auto`, `LPLANE=.TRUE.`, `NPAR=1`, `KPAR=4`, `NCORE=1`, `LORBIT=11`, `ALGO=All`, `LHFCALC=.TRUE.`, `HSE06=.TRUE.`, `HFSCREEN=0.2`, `TIME=0.4`, `AEXX=0.25`, `AGGAX=0.75`, `LMAXFOCK=4`, `PRECFOCK=Fast`.
Run the HSE calculation with the command `bash run_vasp.sh`.
After the HSE calculation, copy the `INCAR` file to `INCAR2`.
For the third step, extract the band gap by running `python gap.py`.
The final output is the numerical band-gap value printed by the `gap.py` script.
