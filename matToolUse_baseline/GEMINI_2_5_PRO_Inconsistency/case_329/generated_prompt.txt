The goal is to compute the electronic band gap of Si using VASP in the directory `data/bandgap/Si`.
The calculation follows a three-step workflow.
The input files are `POSCAR`, `KPOINTS`, and `POTCAR`.
The first step is a PBE ground-state calculation.
Create an `INCAR` file for the PBE ground-state calculation.
In the PBE `INCAR`, set `LWAVE=.TRUE.` to write the WAVECAR.
In the PBE `INCAR`, set `LCHARG=.TRUE.` to write the CHGCAR.
For all other unspecified PBE `INCAR` parameters, assume reasonable values based on best practices.
Run the PBE calculation with the command `bash run_vasp.sh`.
After the run, save the `INCAR` file by executing `cp INCAR INCAR1`.
The second step is an HSE calculation that starts from the PBE WAVECAR and charge density.
Create a new `INCAR` file for the HSE calculation with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
The HSE `INCAR` file must not specify magnetic moments, `NBAND`, or `NELECT`.
Run the HSE calculation with the command `bash run_vasp.sh`.
After the run, save the `INCAR` file by executing `cp INCAR INCAR2`.
The third step is to extract the band gap.
Run the script `gap.py` with the command `python gap.py`.
The final result is the numerical band-gap value printed by the `gap.py` script.
