The working directory is `data/relax/SnSe`.
Create an `INCAR` file for a VASP structural relaxation.
The `INCAR` file must contain the following lines exactly as written:
ALGO = Fast
EDIFF = 0.0004
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 31*-0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the VASP calculation by running the command `bash run_vasp.sh`.
After the calculation finishes, copy the `INCAR` file to `INCAR1` using the command `cp INCAR INCAR1`.
Extract the final total energy by running the command `python get_energy.py`.
The final output should be the optimized total energy as printed by the `get_energy.py` script.
