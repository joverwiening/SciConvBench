Compute the adsorption energy of CO on the provided IrO2 surface using VASP.
The calculation is performed in the `data/absorptionE6/IrO2` directory.
The process consists of four steps.
Step 1 is to optimize the CO molecule using `POSCAR-CO` and `POTCAR-CO`.
Step 2 is to optimize the clean IrO2 surface using `POSCAR-IrO2face` and `POTCAR-IrO2face`.
Step 3 is to optimize the CO-adsorbed IrO2 system using `POSCAR-IrO2CO` and `POTCAR-IrO2CO`.
Step 4 is to run the `calc_absorption_energy.sh` script to compute the final energy from the results of the first three steps.
Use the provided `KPOINTS` file for all VASP calculations.
Use the `op.py` script to set up and run the VASP calculation for each optimization step.
The INCAR file for the three optimization steps will be created with consistent settings.
The INCAR file will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISMEAR = 1, POTIM = 0.2, SIGMA = 0.2.
Spin polarization will be disabled for all calculations by setting ISPIN = 1.
The unit cell will not be optimized for any calculation by setting ISIF = 2.
Reasonable best-practice values will be assumed for NSW, EDIFF, PREC, and LREAL.
Reasonable best-practice assumptions will be made regarding the inclusion of van der Waals, Hubbard U, and dipole corrections.
The final output is the adsorption energy value printed by the `calc_absorption_energy.sh` script.
