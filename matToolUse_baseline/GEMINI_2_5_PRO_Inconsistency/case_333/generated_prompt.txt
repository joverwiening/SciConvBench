Calculate the electronic band gap of ZnS using VASP in the `data/bandgap/ZnS` directory.
The calculation follows a three-step workflow.
Step 1 is a PBE ground-state calculation.
For Step 1, create an INCAR file using reasonable best-practice parameters for a structural relaxation.
After creating the INCAR, run VASP using the command `bash run_vasp.sh`.
After the VASP run, save the INCAR file as `INCAR1` using the command `cp INCAR INCAR1`.
Step 2 is an HSE calculation.
For Step 2, create a new INCAR file using the specified parameter block.
The INCAR for Step 2 must use `ISTART=0`.
After creating the new INCAR, run VASP again using the command `bash run_vasp.sh`.
After the second VASP run, save the INCAR file as `INCAR2` using the command `cp INCAR INCAR2`.
Step 3 is band gap extraction.
For Step 3, run the post-processing script using the command `python gap.py`.
The final output should be the band-gap value printed by the `gap.py` script.
