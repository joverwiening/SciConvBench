Create an INCAR file for a VASP structural relaxation of Boron Nitride.
The INCAR file must contain the following parameters.
Set ALGO to Fast.
Set EDIFF to 0.0001.
Set ENCUT to 520.0.
Set IBRION to 2.
Set ISIF to 3.
Set ISMEAR to -5.
Set ISPIN to 2.
Set LASPH to .TRUE.
Set LORBIT to 11.
Set LREAL to Auto.
Set LWAVE to .FALSE.
Set MAGMOM to 15*0.0.
Set NELM to 100.
Set NSW to 99.
Set PREC to Accurate.
Set SIGMA to 0.05.
Use the provided POSCAR, KPOINTS, and POTCAR files as inputs.
Run the VASP calculation by executing the command `bash run_vasp.sh`.
After the calculation finishes, create a copy of the INCAR file named INCAR1.
Extract the optimized total energy by running the command `python get_energy.py`.
The final output is the optimized total energy value printed by the script.
