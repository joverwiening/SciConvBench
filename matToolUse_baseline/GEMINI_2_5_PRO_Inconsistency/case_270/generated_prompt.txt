Create an INCAR file for a VASP structural relaxation of AlN.
The INCAR file must contain the following parameters: ALGO = Fast, EDIFF = 0.0002, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 31*0.0, NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.
Use the provided POSCAR, KPOINTS, and POTCAR files as inputs.
Run the VASP calculation using the command `bash run_vasp.sh`.
After the calculation, copy the INCAR file to a new file named INCAR1.
Extract the final total energy by running the script `python get_energy.py`.
The final output should be the optimized total energy as printed by the `get_energy.py` script.
