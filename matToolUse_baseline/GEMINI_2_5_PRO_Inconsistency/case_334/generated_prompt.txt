The goal is to compute the adsorption energy of CO on an Ir surface using VASP.
The calculation will be performed in the `data/absorptionE1/Ir` directory.
The process consists of three VASP geometry optimizations followed by a post-processing script.
A single INCAR file will be created and used for all three VASP calculations.
The INCAR file will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 500, PREC = Accurate, and EDIFF = 1E-5.
The first step is to optimize the CO molecule by running `python op.py CO POTCAR-CO POSCAR-CO`.
The second step is to optimize the clean Ir surface by running `python op.py surface POTCAR-Irface POSCAR-Irface`.
The third step is to optimize the CO-adsorbed Ir system by running `python op.py absorbed POTCAR-IrCO POSCAR-IrCO`.
The provided `KPOINTS` file will be used for all three VASP calculations.
The final step is to calculate the adsorption energy by running `bash ./calc_absorption_energy.sh`.
The final output should be the adsorption energy value exactly as printed by the `calc_absorption_energy.sh` script.
