Perform a VASP structural relaxation for Bi2Te3.
The working directory is `data/relax/Bi2Te3`.
Use the provided `POSCAR`, `KPOINTS`, and `POTCAR` files as inputs.
Create an `INCAR` file with the following parameters:
ALGO = Fast
EDIFF = 0.00025
ENCUT = 520.0
IBRION = 2
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 6
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 19*0.0
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the VASP calculation by running the command `bash run_vasp.sh`.
After the calculation completes, copy the `INCAR` file to `INCAR1` using the command `cp INCAR INCAR1`.
Extract the final total energy by running the command `python get_energy.py`.
Report the final total energy exactly as printed by the `get_energy.py` script.
