Calculate the electronic band gap of Cu2O using VASP.
The calculation uses a PBE ground state step followed by an HSE calculation step.
The input files POSCAR, KPOINTS, and POTCAR are located in the current directory.
For the PBE ground-state calculation, create an INCAR file with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, ISMEAR=0, SIGMA=0.05, ISTART=0, ICHARG=2, LWAVE=.TRUE., LCHARG=.TRUE., LREAL=Auto, LORBIT=11, ALGO=Normal, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1.
Run the PBE calculation using the command 'bash run_vasp.sh'.
After the PBE calculation completes, save its INCAR file with the command 'cp INCAR INCAR1'.
For the HSE calculation, create a new INCAR file with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
Run the HSE calculation using the command 'bash run_vasp.sh'.
After the HSE calculation completes, save its INCAR file with the command 'cp INCAR INCAR2'.
Extract the band gap by running the command 'python gap.py'.
The final result is the numerical value printed by the 'gap.py' script.
