Compute the adsorption energy of CO on the provided Pt surface using VASP.
The calculation involves four steps: optimizing the CO molecule, optimizing the clean surface, optimizing the adsorbed system, and then calculating the final adsorption energy.
For the CO molecule optimization, use the `POSCAR-CO` and `POTCAR-CO` files.
For the clean surface optimization, use the `POSCAR-Ptface` and `POTCAR-Ptface` files.
For the adsorbed system optimization, use the `POSCAR-PtCO` and `POTCAR-PtCO` files.
Use the provided `KPOINTS` file for all VASP calculations.
The INCAR file for all three optimization steps will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, and SIGMA = 0.2.
The unit cell will not be optimized in any calculation.
Spin polarization will not be included in any calculation.
Set the number of ionic steps (NSW) based on best practices.
Set the electronic energy convergence criterion (EDIFF) based on best practices.
Set the precision level (PREC) based on best practices.
Set the real-space projection flag (LREAL) based on best practices.
Do not include van der Waals corrections in the calculations.
Include a dipole correction for the CO-adsorbed Pt surface calculation.
Execute the CO optimization by running `python op.py CO POTCAR-CO POSCAR-CO`.
Execute the clean surface optimization by running `python op.py surface POTCAR-Ptface POSCAR-Ptface`.
Execute the adsorbed system optimization by running `python op.py absorbed POTCAR-PtCO POSCAR-PtCO`.
After the optimizations are complete, run `bash ./calc_absorption_energy.sh` to get the final result.
The required output is the adsorption energy value printed by the `calc_absorption_energy.sh` script.
