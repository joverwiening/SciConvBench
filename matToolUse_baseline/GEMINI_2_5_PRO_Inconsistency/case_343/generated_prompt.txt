Compute the adsorption energy of CO on the provided Pd surface using VASP.
The calculation involves four steps: optimizing the CO molecule, optimizing the clean surface, optimizing the adsorbed system, and then calculating the final adsorption energy.
Use the provided POSCAR-CO, POSCAR-Pdface, and POSCAR-PdCO files for the structures of the three optimization steps, respectively.
Use the provided POTCAR-CO, POTCAR-Pdface, and POTCAR-PdCO files for the pseudopotentials of the three optimization steps, respectively.
Use the provided KPOINTS file for the k-point sampling in all calculations.
For each optimization step, write an INCAR file with the specified parameters.
The INCAR file for all three geometry optimization calculations will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, and SIGMA = 0.2.
Spin polarization will not be included in any calculation.
The unit cell shape and volume will be kept fixed for all calculations.
Set the maximum number of ionic steps, NSW, to 200.
Set the electronic energy convergence criterion, EDIFF, to 1E-5.
Include van der Waals corrections using the DFT-D3 method by setting IVDW = 11.
Run the optimization for the CO molecule using the command `python op.py CO POTCAR-CO POSCAR-CO`.
Run the optimization for the clean surface using the command `python op.py surface POTCAR-Pdface POSCAR-Pdface`.
Run the optimization for the adsorbed system using the command `python op.py absorbed POTCAR-PdCO POSCAR-PdCO`.
After the three optimizations are complete, run the script `bash ./calc_absorption_energy.sh` to compute the final energy.
The final output should be the adsorption energy value exactly as printed by the `calc_absorption_energy.sh` script.
