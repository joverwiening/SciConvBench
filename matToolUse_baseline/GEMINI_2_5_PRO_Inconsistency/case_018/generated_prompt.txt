Create a Python function to compute material properties from simulated WSWQ data.
The function should be written in Python and use the Pymatgen and NumPy libraries.
The function will be named `compute_wswq_slopes`.
The function will not accept any input arguments.
The function must include a complete docstring describing its purpose and the returned dictionary.
The function will generate a list of fake WSWQ data objects.
Each object in the list will have a `.data` attribute containing a NumPy array.
The list will contain three objects, with their `.data` attributes being (3, 5) NumPy arrays of ones, zeros, and ones, respectively.
The function will define a positive-distortion branch with distortion values of `[0.5, 0.0, -0.5]`.
The function will define a negative-distortion branch with distortion values of `[-0.5, 0.0, 0.5]`.
The same ordered list of fake WSWQ data objects will be used for both distortion branches.
The function will calculate a property named `wswq_slope_positive_distortion`.
This property is the slope calculated from the positive-distortion branch data points where the distortion value is non-negative.
The function will calculate a property named `wswq_slope_negative_distortion`.
This property is the slope calculated from the negative-distortion branch data points where the distortion value is non-positive.
The slope calculations will be performed using NumPy.
The function will return a dictionary.
The dictionary keys will be the property names `wswq_slope_positive_distortion` and `wswq_slope_negative_distortion`.
The dictionary values will be the corresponding calculated slope matrices as NumPy arrays.
