Compute the electronic band gap of BN using VASP in the `data/bandgap/BN` directory.
Use the provided `POSCAR`, `KPOINTS`, and `POTCAR` files.
The workflow is a PBE ground-state calculation followed by an HSE calculation.
First, create an `INCAR` file for a PBE ground-state structural relaxation.
Set the PBE `INCAR` parameters `ENCUT`, `ISIF`, `EDIFF`, `EDIFFG`, and `ISMEAR` to reasonable values based on best practices.
Run the PBE calculation with the command `bash run_vasp.sh`.
Save the `INCAR` file used for the PBE step as `INCAR1`.
Second, create a new `INCAR` file for the HSE calculation.
Use the following parameters for the HSE `INCAR`: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
For the HSE step, do not specify `NBAND`, `NELECT`, or magnetic moments.
The `ICHARG` parameter must not be larger than 10 for the HSE step.
Run the HSE calculation with the command `bash run_vasp.sh`.
Save the `INCAR` file used for the HSE step as `INCAR2`.
Third, extract the band gap by running `python gap.py`.
Return the band-gap value exactly as printed by the `gap.py` script.
