The working directory is `data/bandgap/C`.
Perform a PBE ground-state calculation as the first step.
Create an INCAR file for the PBE calculation with the following parameters: PREC=Normal, ENCUT=450, IBRION=2, ISIF=3, NSW=100, EDIFF=1E-6, EDIFFG=-0.01, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., LCHARG=.TRUE..
Run VASP for the PBE step using the command `bash run_vasp.sh`.
Save the INCAR file from the PBE step by running `cp INCAR INCAR1`.
Perform an HSE calculation as the second step.
Create a new INCAR file for the HSE calculation with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.
Run VASP for the HSE step using the command `bash run_vasp.sh`.
Save the INCAR file from the HSE step by running `cp INCAR INCAR2`.
Extract the band gap as the third step.
Run the post-processing script using the command `python gap.py`.
The final output is the band-gap value printed by the `gap.py` script.
