Compute the adsorption energy of CO on a RuO2 surface using VASP.
The calculation consists of four steps: optimizing the CO molecule, optimizing the clean surface, optimizing the adsorbed system, and calculating the adsorption energy.
A single INCAR file will be created and used for the three geometry optimization calculations.
The INCAR file will contain the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, and SIGMA = 0.2.
The INCAR file will also include the following parameters based on standard best practices: NSW = 200, EDIFF = 1E-5, IVDW = 11, and PREC = Normal.
Spin polarization will be disabled for all calculations by setting ISPIN to 1.
The unit cell will not be relaxed for any calculation by setting ISIF to 2.
The provided KPOINTS file will be used for all three VASP calculations.
The first step is to optimize the CO molecule by running `python op.py CO POTCAR-CO POSCAR-CO`.
The second step is to optimize the clean RuO2 surface by running `python op.py surface POTCAR-RuO2face POSCAR-RuO2face`.
The third step is to optimize the CO-adsorbed RuO2 system by running `python op.py absorbed POTCAR-RuO2CO POSCAR-RuO2CO`.
The fourth step is to compute the adsorption energy by running `bash ./calc_absorption_energy.sh`.
The final output will be the adsorption energy value exactly as printed by the `calc_absorption_energy.sh` script.
