Write a Python function named `compute_defect_name_consistency`.
The function will not take any input arguments.
The function will use the Pymatgen library to perform its calculations.
The function will check if all defect entries for the Mg_Ga defect in GaN have the same defect name.
The check will be performed for Mg_Ga defect entries with charge states -2, -1, 0, and +1.
The Ga-vacancy reference entry will not be included in the consistency check.
The function will assume a base directory path of `./data/GaN/`.
The bulk structure file is assumed to be located at `./data/GaN/GaN.vasp`.
The defect entry directories are assumed to follow the naming convention `Mg_Ga/charge_q`, where `q` is the charge state.
The function will load the defect entries from these directories.
The function will calculate a boolean value indicating whether all loaded Mg_Ga defect entries have the same name.
The function will return a dictionary with the key `defect_name_consistency` and the calculated boolean value as the value.
The function must include a complete docstring detailing its purpose, parameters, and return value.
The function must include all necessary Python imports.
