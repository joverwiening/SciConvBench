Q: What INCAR parameters should be used for the ground‑state PBE calculation in Step 1?
A: Use a standard PBE ground‑state INCAR, for example:

```
SYSTEM = AlN PBE ground state
PREC   = Normal
ENCUT  = 450          # same cutoff as the hybrid step
EDIFF  = 1E-5
EDIFFG = -0.02        # optional, for geometry relaxations (set to 0 if static)
ISMEAR = 0
SIGMA  = 0.05
IBRION = -1           # static calculation (no ionic steps)
NSW    = 0
ISIF   = 2            # stress/forces not needed for static run
ISPIN  = 1
LCHARG = .TRUE.
LWAVE  = .TRUE.
LREAL  = Auto
NPAR   = 1
KPAR   = 4
NCORE  = 1
LORBIT = 11
ALGO   = Normal
```

These parameters give a well‑converged PBE electronic ground‑state calculation and are compatible with the subsequent hybrid‑functional step. (If you need a geometry relaxation, adjust `IBRION`, `NSW`, `EDIFFG`, and `ISIF` accordingly.)
