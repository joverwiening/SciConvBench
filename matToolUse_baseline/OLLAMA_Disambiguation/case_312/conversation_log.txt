Q: What parameters should be included in the INCAR file for the ground‑state (PBE) calculation?
A: A reasonable PBE ground‑state INCAR can be built from the standard “best‑practice” settings for a static (self‑consistent) calculation. For example:

```
SYSTEM = BN – PBE ground state
PREC   = Accurate          # high precision
ENCUT  = 400               # plane‑wave cutoff (≥ 1.3× the max POTCAR ENMAX)
EDIFF  = 1E-5              # electronic convergence
ISMEAR = 0                 # Gaussian smearing (insulator)
SIGMA  = 0.05
IBRION = -1                # no ionic relaxation (static SCF)
NSW    = 0                 # no ionic steps
ISIF   = 2                 # stress tensor (optional)
ISPIN  = 1                 # non‑magnetic
LCHARG = .TRUE.            # write CHGCAR
LWAVE  = .TRUE.            # write WAVECAR
LREAL  = Auto
NELM   = 100               # max electronic steps
NELMIN = 4
ALGO   = Normal            # standard algorithm
```

These parameters give a converged PBE charge density and wavefunctions, after which you can copy the file to `INCAR1` and proceed to the hybrid‑functional step. (If you have a different preferred cutoff or convergence criteria, adjust `ENCUT` and `EDIFF` accordingly.)

Q: Should I include any additional parameters (e.g., ICHARG) in the ground‑state INCAR, or use exactly the settings you provided?
A: Use exactly the settings shown in the suggested PBE INCAR. No extra tags (e.g., ICHARG) are required for the ground‑state step.
