Create an INCAR file in the current directory containing the specified parameters: ALGO = Fast, EDIFF = 0.0002, ENCUT = 520.0, IBRION = 2, ISMEAR = -5, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05.  
Run VASP using the provided launch script by executing `bash run_vasp.sh`.  
After the VASP run completes, copy the INCAR file to a backup named `INCAR1` with `cp INCAR INCAR1`.  
Extract the optimized total energy by running `python get_energy.py` and output the printed energy value exactly as produced by the script.
