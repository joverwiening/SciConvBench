Retrieve the primitive corundum Al2O3 structure from any reliable database (e.g., Materials Project, ICSD, COD) and use its lattice parameters as the starting configuration.  
Use the LDA pseudopotential files PseudoDojo/SR_v0.4.1/LDA_standard/al.upf and PseudoDojo/SR_v0.4.1/LDA_standard/o.upf for the calculations.  
Perform the workflow in the following order: (1) variable-cell relaxation (vc‑relax), (2) self‑consistent field calculation (scf), (3) non‑self‑consistent field calculation (nscf), (4) pw.x run with calculation="bands", (5) band post‑processing, and (6) density‑of‑states post‑processing.  
Choose a gamma‑centered k‑point grid dense enough to achieve a strict total‑energy convergence of 1 meV per atom.  
Set the total‑energy convergence threshold (etot_conv_thr) to meet the 1 meV/atom requirement.  
Set the force convergence threshold (forc_conv_thr) appropriately for the vc‑relax step.  
Do not output the band structure; only complete the DOS calculation as specified.
