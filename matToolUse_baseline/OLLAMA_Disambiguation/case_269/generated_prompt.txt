Create a file named INCAR in the current directory containing the following lines:
ALGO = Fast
EDIFF = 5e-05
ENCUT = 520.0
IBRION = 2
ISMEAR = -5
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Run VASP using the provided launch script by executing `bash run_vasp.sh` in the current directory.
After VASP finishes, copy the INCAR file to a new file named INCAR1 by executing `cp INCAR INCAR1`.
Extract the optimized total energy by running `python get_energy.py` and capture the printed value.
Return the optimized total energy exactly as printed by `get_energy.py`.
