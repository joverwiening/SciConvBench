The task is to compute the electronic band gap of BN using VASP in the `data/bandgap/BN` directory.
The workflow involves a ground-state calculation followed by a hybrid-functional calculation.
Input files POSCAR, KPOINTS, and POTCAR are located in the current directory.
First, perform a ground-state calculation.
Create an INCAR file for the ground-state calculation with reasonably assumed parameters suitable for a PBE calculation.
The INCAR for the ground-state calculation should include PREC=Normal, ENCUT=450, NELM=100, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-0.02, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., and LCHARG=.TRUE..
Run VASP with the command `bash run_vasp.sh`.
Save a copy of the INCAR file as INCAR1 using the command `cp INCAR INCAR1`.
Second, perform a hybrid-functional calculation.
Create a new INCAR file for the hybrid-functional calculation with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., TIME=0.4.
Set the ICHARG parameter to a value no greater than 10.
Do not specify magnetic moments, NBAND, or NELECT in the INCAR file.
Run VASP again with the command `bash run_vasp.sh`.
Save a copy of this new INCAR file as INCAR2 using the command `cp INCAR INCAR2`.
Third, extract the band gap.
Run the post-processing script with the command `python gap.py`.
The final result is the band-gap value printed by the `gap.py` script.
