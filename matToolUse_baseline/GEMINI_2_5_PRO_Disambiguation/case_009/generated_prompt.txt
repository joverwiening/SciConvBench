Write a Python function named `compute_chemical_potential_limits`.
The function takes no arguments.
The function will compute the number of chemical potential limits in a defect formation energy diagram.
The base directory for input files, `file_path`, is hardcoded inside the function as `'./data/'`.
The path to the stable entries file is `'./data/stable_entries_Mg_Ga_N.json'`.
The list of stable entries for constructing the chemical potential limits will be loaded from this JSON file.
The path to the bulk host calculation is `'./data/bulk/vasprun.xml.gz'`.
The bulk entry and the host band gap are determined from this bulk `vasprun.xml.gz` file.
The defect calculations are located in the `'./data/Mg_Ga/'` directory.
The function will process defect charge states of -2, -1, 0, and +1.
The subdirectories for each charge state follow the naming convention `charge_X`, where X is the charge (e.g., `charge_-2`, `charge_0`, `charge_+1`).
For each charge state, a `DefectEntry` object will be created by loading the `vasprun.xml.gz` and `LOCPOT.gz` files from its corresponding subdirectory.
A `pymatgen.analysis.defects.core.FormationEnergyDiagram` object will be constructed using the created defect entries and the loaded stable entries.
The function will calculate the `chemical_potential_limits_count` property, which is the number of vertices in the chemical potential phase diagram.
The function will return a dictionary with a single key-value pair: `{'chemical_potential_limits_count': count}`.
The function must include a complete docstring explaining its purpose and return value.
All necessary Pymatgen imports must be included.
