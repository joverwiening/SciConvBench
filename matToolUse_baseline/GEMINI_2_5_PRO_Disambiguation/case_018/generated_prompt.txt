Write a Python function that computes slopes for fake WSWQ data.
The function should be named `compute_wswq_slopes`.
The function takes no input arguments.
The function includes all necessary imports, such as `numpy`.
The function has a complete docstring explaining its purpose, parameters, and the returned dictionary.

Generate a corresponding WSWQ data matrix for the positive branch with a shape of (3, 5), where all elements are 1.
Generate a set of 5 negative distortion values, specifically `[-0.05, -0.04, -0.03, -0.02, -0.01]`.
Generate a corresponding WSWQ data matrix for the negative branch with a shape of (3, 5), where all elements are 1.
For the positive branch, calculate the linear slope for each of the 3 rows of WSWQ data against the 5 positive distortion values.
For the negative branch, calculate the linear slope for each of the 3 rows of WSWQ data against the 5 negative distortion values.
Use `numpy.polyfit` to perform the linear slope calculation.
The function returns a dictionary.
The dictionary contains the key `wswq_slope_positive_distortion` with its value being a numpy array of the 3 calculated slopes for the positive branch.
The dictionary contains the key `wswq_slope_negative_distortion` with its value being a numpy array of the 3 calculated slopes for the negative branch.
