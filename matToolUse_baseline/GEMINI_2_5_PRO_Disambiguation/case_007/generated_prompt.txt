Create a Python function to calculate properties for a Magnesium (Mg) substituting Gallium (Ga) defect using the Pymatgen library.
The function will not accept any input arguments.
The function will perform calculations for defect charge states of -2, -1, 0, and +1.
The function will assume a local directory structure containing the necessary VASP output files for the bulk material and for each defect charge state.
The dielectric constant of the bulk material is 14.
For each charge state, the function will calculate the Freysoldt correction, the potential alignment consistency, and the energy difference between the defect and bulk supercells.
The Freysoldt correction (`freysoldt_correction`) will be a floating-point number.
The potential alignment consistency (`potential_alignment_consistency`) will be a boolean value, determined by checking if the potential alignment correction data is available and can be applied.
The energy difference (`energy_difference`) will be a floating-point number.
The function will return a dictionary.
The keys of the returned dictionary will be the integer charge states: -2, -1, 0, 1.
The value for each key will be another dictionary containing the calculated properties: `freysoldt_correction`, `potential_alignment_consistency`, and `energy_difference`.
The function must include a comprehensive docstring explaining its purpose, the assumed file structure, and the format of the returned dictionary.
The function must include all necessary import statements from Pymatgen.
The function should be named `calculate_mg_ga_defect_properties`.
