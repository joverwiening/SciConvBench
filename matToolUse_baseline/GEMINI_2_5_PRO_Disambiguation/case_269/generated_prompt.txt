The current working directory is `data/relax/Al`.
Perform a VASP structural relaxation for Aluminum.
The initial structure is defined in the `POSCAR` file.
The k-point sampling is defined in the `KPOINTS` file.
The pseudopotential is defined in the `POTCAR` file.
Create a VASP input file named `INCAR`.
The `INCAR` file will contain the following settings:
ALGO = Fast
EDIFF = 5e-05
ENCUT = 520.0
IBRION = 2
ISMEAR = -5
LASPH = .TRUE.
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
NELM = 100
NSW = 99
PREC = Accurate
SIGMA = 0.05
Execute the VASP calculation using the command `bash run_vasp.sh`.
After the calculation completes, copy the `INCAR` file to `INCAR1`.
Extract the optimized total energy by running the command `python get_energy.py`.
Report the final total energy exactly as printed by the `get_energy.py` script.
