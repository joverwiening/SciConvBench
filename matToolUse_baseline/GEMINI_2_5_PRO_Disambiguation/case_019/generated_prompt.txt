Write a Python function to compute defect properties using Pymatgen.
The function should be named `compute_srh_properties` and take no input arguments.
The function will calculate the Shockley-Read-Hall (SRH) coefficient for a range of temperatures from 100K to 500K, inclusive, in steps of 100K.
The function will use a hardcoded relative file path of `v_Ga/ccd_0_-1/wswqs` to read the WSWQ files and construct a `HarmonicDefect` object.
The function will verify that a `RuntimeError` is raised when attempting to calculate the SRH coefficient with an invalid defect state configuration, created by manually instantiating a `HarmonicDefect` with inconsistent charge states.
The function will return a dictionary.
The dictionary will contain the key `SRH_Coefficient` with a list of float values as its value.
The dictionary will also contain the key `RuntimeError_Check` with a boolean as its value, which is True if the expected `RuntimeError` was caught.
The function must include a complete docstring explaining its purpose and return value.
All necessary imports from Pymatgen must be included.
