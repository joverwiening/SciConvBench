Perform a VASP structural relaxation for AlN in the `data/relax/AlN` directory.
Create an INCAR file with the following parameters: ALGO = Fast, EDIFF = 0.0002, ENCUT = 520.0, IBRION = 2, ISMEAR = -5, LASPH = .TRUE., LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., NELM = 100, NSW = 99, PREC = Accurate, SIGMA = 0.05, ISIF = 3, and EDIFFG = -0.01.
Use the provided POSCAR, KPOINTS, and POTCAR files as inputs for the calculation.
Run the VASP calculation by executing the command `bash run_vasp.sh`.
After the calculation completes, copy the generated INCAR file to a new file named INCAR1.
Extract the final optimized total energy by running the script `python get_energy.py`.
The final output should be the single numerical value of the total energy printed by the script.
