Calculate the adsorption energy of CO on the provided Iridium surface using VASP.
The calculation consists of four steps.
Step 1 is the geometry optimization of the CO molecule.
Step 2 is the geometry optimization of the clean Iridium surface.
Step 3 is the geometry optimization of the CO-adsorbed Iridium system.
Step 4 is the calculation of the adsorption energy using the results from the previous three steps.
The provided `KPOINTS` file is to be used for all three VASP calculations.
The INCAR files for the three geometry optimizations will be consistent.
The INCAR files will contain `EDIFFG = -0.05`.
The INCAR files will contain `ENCUT = 450`.
The INCAR files will contain `IBRION = 1`.
The INCAR files will contain `ISMEAR = 1`.
The INCAR files will contain `POTIM = 0.2`.
The INCAR files will contain `SIGMA = 0.2`.
The INCAR files will contain `ISPIN = 1` for non-spin-polarized calculations.
The INCAR files will contain `ISIF = 2` to fix the cell shape and volume.
The INCAR files will contain `NSW = 500` to allow for a sufficient number of ionic steps.
A reasonable value of `EDIFF = 1E-5` will be used for the electronic energy convergence criterion.
The INCAR files will contain `LMAXMIX = 4` because Iridium is a d-block element.
Dipole corrections will be applied along the z-axis for all three optimization steps by setting `LDIPOL = .TRUE.` and `IDIPOL = 3`.
For Step 1, run the command `python op.py CO POTCAR-CO POSCAR-CO`.
For Step 2, run the command `python op.py surface POTCAR-Irface POSCAR-Irface`.
For Step 3, run the command `python op.py absorbed POTCAR-IrCO POSCAR-IrCO`.
For Step 4, run the command `bash ./calc_absorption_energy.sh`.
The final output is the adsorption energy value printed by the `calc_absorption_energy.sh` script.
