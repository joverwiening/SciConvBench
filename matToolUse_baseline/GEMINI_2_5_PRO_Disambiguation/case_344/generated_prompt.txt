Compute the transition-state energy barrier for a reaction using a VASP NEB workflow.
The workflow consists of five steps: initial state relaxation, final state relaxation, image interpolation, NEB calculation, and barrier extraction.
Use the provided `IS1POSCAR` as the initial state and `FS1POSCAR` as the final state.
Use the provided `KPOINTS` file for k-point sampling.
Use the provided `POTCARagpd` file for pseudopotentials.
For the initial and final state relaxations, create an INCAR file with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2.
Use an electronic energy convergence criterion (EDIFF) of 1E-5 for all calculations.
Use a value of 200 for the number of ionic steps (NSW) for the initial and final state relaxations.
Run the initial state relaxation using the command `python op.py IS POTCARagpd IS1POSCAR`.
Run the final state relaxation using the command `python op.py FS POTCARagpd FS1POSCAR`.
Create 4 intermediate images for the NEB path.
Interpolate the intermediate images using the command `python nebmake.py`.
For the NEB calculation, create an INCAR file with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 3, IOPT = 7, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0, SIGMA = 0.2, SPRING = -5.
Set the number of images (IMAGES) to 4 in the NEB INCAR file.
Enable the climbing image method by setting LCLIMB = .TRUE. in the NEB INCAR file.
Use a value of 400 for the number of ionic steps (NSW) for the NEB calculation.
Run the NEB calculation using the command `python op2.py ./`.
Extract the energy barrier using the command `bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'`.
The final output should be the calculated reaction-barrier value.
