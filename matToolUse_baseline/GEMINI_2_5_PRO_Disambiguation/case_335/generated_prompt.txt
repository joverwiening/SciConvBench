Compute the adsorption energy of CO on the provided PtO2 surface using VASP.
The task involves three geometry optimizations and a final calculation step.
Step 1 is the geometry optimization of a CO molecule.
Step 2 is the geometry optimization of a clean PtO2 surface.
Step 3 is the geometry optimization of a CO-adsorbed PtO2 system.
Step 4 is the calculation of the adsorption energy from the results of the previous steps.
All three geometry optimizations will use the following INCAR parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISMEAR = 1, POTIM = 0.2, SIGMA = 0.2.
All three geometry optimizations will also use the following INCAR parameters: NSW = 200, ISPIN = 1, EDIFF = 1.0E-04, ISIF = 2.
Additional standard INCAR parameters to use are PREC = Normal, LREAL = Auto, LWAVE = .FALSE., and LCHARG = .FALSE.
For the clean surface and adsorbed system optimizations, a dipole correction with LDIPOL = .TRUE. and IDIPOL = 3 must be enabled.
The CO molecule optimization will not use a dipole correction.
The CO molecule optimization uses the POSCAR-CO file for the structure and the POTCAR-CO file for pseudopotentials.
The clean surface optimization uses the POSCAR-PtO2face file for the structure and the POTCAR-PtO2face file for pseudopotentials.
The adsorbed system optimization uses the POSCAR-PtO2CO file for the structure and the POTCAR-PtO2CO file for pseudopotentials.
The provided KPOINTS file must be used for all three optimization calculations.
The execution sequence begins by running the CO optimization with `python op.py CO POTCAR-CO POSCAR-CO`.
Next, run the surface optimization with `python op.py surface POTCAR-PtO2face POSCAR-PtO2face`.
Then, run the adsorbed system optimization with `python op.py absorbed POTCAR-PtO2CO POSCAR-PtO2CO`.
Finally, compute the adsorption energy by executing `bash ./calc_absorption_energy.sh`.
The final output must be the adsorption energy value as printed by the script.
