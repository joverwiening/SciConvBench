The user wants to compute the electronic band gap of AlN using VASP.
The working directory is `data/bandgap/AlN`.
The calculation involves a three-step workflow.
The required input files `POSCAR`, `KPOINTS`, `POTCAR`, `gap.py`, and `run_vasp.sh` are present in the working directory.
Step 1 is a ground-state calculation.
Create an `INCAR` file for the ground-state calculation with the following parameters: PREC=Normal, ENCUT=450, IBRION=2, ISIF=3, NSW=100, NELM=100, EDIFF=1E-6, EDIFFG=-1E-2, ISMEAR=0, SIGMA=0.05, LWAVE=.TRUE., LCHARG=.TRUE., ISPIN=1, LREAL=Auto.
Run the VASP calculation with the command `bash run_vasp.sh`.
After the calculation, save the `INCAR` file by running `cp INCAR INCAR1`.
Step 2 is a hybrid-functional calculation.
Create a new `INCAR` file for the hybrid-functional calculation with the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., TIME=0.4.
Do not specify ICHARG, NBAND, or NELECT in the `INCAR` for the hybrid-functional calculation.
Run the VASP calculation again with the command `bash run_vasp.sh`.
After the calculation, save the new `INCAR` file by running `cp INCAR INCAR2`.
Step 3 is to extract the band gap.
Run the post-processing script with the command `python gap.py`.
The final output should be the numerical value printed by the `gap.py` script.
