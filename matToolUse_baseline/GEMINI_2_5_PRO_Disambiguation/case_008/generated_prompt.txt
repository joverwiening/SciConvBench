Write a Python function named `compute_defect_properties` that takes no arguments.
The function will use the Pymatgen library to perform calculations.
The function will read a bulk structure from the file `GaN.vasp`.
The function will read stable entries from the JSON file `stable_entries_Mg_Ga_N.json`.
The function will read defect entries from a JSON file named `defect_entries.json`.
Assume all input files are located in the same directory as the script.
Use a total energy of -16.5 eV for the bulk GaN system.
Use a Valence Band Maximum (VBM) of 1.0 eV for the bulk GaN material.
Use a band gap of 3.2 eV for the bulk GaN material.
The function will construct a `FormationEnergyDiagram` from the provided bulk data, defect entries, and stable entries.
From this diagram, the function will compute three properties.
The first property is `chempot_limits_count`, the integer number of chemical potential limits.
The second property is `defect_chemsys`, a string representing the chemical system of the defects.
The third property is `bulk_formula`, a string representing the chemical formula of the bulk material.
The function will return a dictionary with these three property names as keys and their calculated values.
The function must include a complete docstring describing its purpose and return value.
The function must include all necessary imports from Pymatgen.
