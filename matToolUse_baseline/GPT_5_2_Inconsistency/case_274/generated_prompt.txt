Work inside the directory data/relax/BaTiO3.
Use the existing input files POSCAR, KPOINTS, and POTCAR from that directory.
Create a VASP INCAR file for structural optimization using the provided parameter block, with IBRION set to 2 and NSW set to 99, and all other lines matching the specified block.
Run VASP using bash run_vasp.sh.
After the run, copy the INCAR actually used to a file named INCAR1 using cp INCAR INCAR1.
Extract the optimized total energy by running python get_energy.py, which reads vasprun.xml.
Report the optimized total energy exactly as printed by get_energy.py.
