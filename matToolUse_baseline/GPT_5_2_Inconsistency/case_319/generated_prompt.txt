Compute the electronic band gap for Ga2O3 inside the directory data/bandgap/Ga2O3 using VASP and the workflow described in data.json.
Use the existing input files POSCAR, KPOINTS, and POTCAR in the current directory.
Step 1 must be a PBE ground-state calculation.
Because data.json provides no explicit INCAR block for Step 1, create a reasonable best-practice PBE ground-state INCAR before running VASP.
Run Step 1 using bash run_vasp.sh.
After Step 1 finishes, copy the INCAR used for Step 1 to INCAR1 using cp INCAR INCAR1.
Step 2 must be an HSE calculation using the provided INCAR parameter block from data.json domain_knowledge.
For Step 2, obey the additional notes: when starting a hybrid functional calculation with an existing WAVECAR you still need to calculate the charge density so ICHARG cannot be larger than 10, do not specify magnetic moments, and do not specify NBAND or NELECT.
Run Step 2 using bash run_vasp.sh.
After Step 2 finishes, copy the INCAR used for Step 2 to INCAR2 using cp INCAR INCAR2.
Step 3 must extract the band gap by running python gap.py, which reads vasprun.xml and prints the band gap.
Return the band-gap value exactly as printed by gap.py.
Do not assume any band-gap value; obtain it by actually running the two VASP steps and then gap.py.
The run_vasp.sh script is assumed to launch vasp_std with MPI, but its exact contents, VASP version, MPI rank count, and launch line are not specified.
