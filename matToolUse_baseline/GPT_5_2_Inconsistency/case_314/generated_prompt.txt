Work inside the case directory data/bandgap/C.
Compute the electronic band gap using VASP following the workflow in data.json: a PBE ground-state run followed by an HSE run, then extract the gap with gap.py.
Use POSCAR, KPOINTS, and POTCAR in the current directory as inputs.
Step 1 (PBE ground state): create an INCAR using these settings: PREC=Normal, ENCUT=450, EDIFF=1E-5, NELM=200, IBRION=-1, NSW=0, ISIF=2, ISPIN=1, ISMEAR=0, SIGMA=0.05, LREAL=Auto, LPLANE=.TRUE., LWAVE=.T., LCHARG=.T., and do not set MAGMOM, NBAND, or NELECT.
Step 1 command sequence: run bash run_vasp.sh, then copy cp INCAR INCAR1.
Step 2 (HSE): create a new INCAR using the provided HSE parameter block, but set ICHARG=0 (not 11), keep ISTART=0, do not specify magnetic moments, and do not specify NBAND or NELECT.
Step 2 command sequence: run bash run_vasp.sh, then copy cp INCAR INCAR2.
Step 3 (band gap extraction): run python gap.py.
Return the band-gap value exactly as printed by gap.py.
