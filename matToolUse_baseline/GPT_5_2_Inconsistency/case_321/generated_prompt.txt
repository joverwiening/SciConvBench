Compute the electronic band gap of GaN inside data/bandgap/GaN using VASP with a two-step workflow followed by post-processing with gap.py.
Use the existing input files POSCAR, KPOINTS, and POTCAR from the current directory.
Follow the workflow described by data.json: Step 1 PBE ground state, then Step 2 HSE, then Step 3 band-gap extraction.
For Step 1, create a reasonable best-practice PBE ground-state INCAR because data.json provides no explicit Step 1 INCAR block.
For Step 1, ensure the INCAR sets LWAVE = .TRUE. so that a WAVECAR is written for reuse in Step 2.
Run Step 1 VASP using bash run_vasp.sh.
After Step 1 completes, copy the Step 1 INCAR to INCAR1 using cp INCAR INCAR1.
For Step 2, create a new INCAR for an HSE calculation based on the provided parameter block from data.json domain_knowledge.
For Step 2, obey the additional notes: do not specify magnetic moments, do not specify NBAND, and do not specify NELECT.
For Step 2, ensure the hybrid-functional start still computes charge density and therefore ICHARG must not be larger than 10, despite the provided block listing ICHARG=11.
Run Step 2 VASP using bash run_vasp.sh.
After Step 2 completes, copy the Step 2 INCAR to INCAR2 using cp INCAR INCAR2.
For Step 3, run python gap.py to read vasprun.xml, build the band structure, and print the band gap.
Return the band-gap value exactly as printed by gap.py.
