Work inside the case directory data/relax/Li2S.
Perform a VASP structural relaxation for Li2S and report the optimized total energy as the final total energy after relaxation.
Use the existing input files POSCAR, KPOINTS, and POTCAR from the current directory without pasting their full contents.
Create an INCAR file for structure optimization containing exactly these lines: ALGO = Fast; EDIFF = 0.00015000000000000001; ENCUT = 520.0; IBRION = -1; ISIF = 3; ISMEAR = -5; ISPIN = 2; LASPH = .TRUE.; LORBIT = 11; LREAL = Auto; LWAVE = .FALSE.; MAGMOM = 23*-0.0; NELM = 100; NSW = 0; PREC = Accurate; SIGMA = 0.05.
Run VASP using the provided launcher script by executing bash run_vasp.sh.
After the run, copy the INCAR actually used to a file named INCAR1 by executing cp INCAR INCAR1.
Extract the optimized total energy by running python get_energy.py, which reads vasprun.xml and prints the optimized total energy after relaxation.
Return the optimized total energy exactly as printed by get_energy.py, without assuming any value in advance.
