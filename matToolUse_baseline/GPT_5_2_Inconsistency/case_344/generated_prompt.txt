Compute the transition-state (reaction) energy barrier for the NEB case in data/NEB1/AgPdneb1 using a VASP NEB workflow.
Use the provided inputs in the case directory: IS1POSCAR as the initial-state structure, FS1POSCAR as the final-state structure, KPOINTS for k-point sampling, and POTCARagpd as the pseudopotential source.
Follow the five-step workflow described in data1.json/data2.json/data3.json: relax initial state, relax final state, interpolate images, run NEB, extract barrier.
Enforce these global constraints: no spin polarization (ISPIN=1), no unit-cell optimization (ISIF=2), loose force convergence EDIFFG=-0.05 eV/Å, ENCUT=450 (not too high), and NPAR=1.
Step 1 (IS relaxation): write an INCAR using EDIFFG=-0.05, ENCUT=450, NPAR=1, IBRION=1, ISIF=2, ISMEAR=1, ISPIN=1, POTIM=0.2, SIGMA=0.2, and set NSW=200.
Step 1 execution: run python op.py IS POTCARagpd IS1POSCAR to create the IS directory, copy inputs, and launch run_1.sh.
Step 2 (FS relaxation): write/adjust an INCAR using the same constraints as Step 1 and set NSW=200.
Step 2 execution: run python op.py FS POTCARagpd FS1POSCAR to create the FS directory, copy inputs, and launch run_1.sh.
Step 3 (interpolation): run python nebmake.py to read IS/CONTCAR and FS/CONTCAR, interpolate four intermediate images with ASE, and write POSCAR files into directories 00 through 05.
Step 4 (NEB run): write an INCAR using EDIFFG=-0.05, ENCUT=450, NPAR=1, IBRION=3, IMAGES=4, LCLIMB=.TRUE., IOPT=7, ISIF=2, ISMEAR=1, ISPIN=1, POTIM=0, SIGMA=0.2, SPRING=-5, and set NSW=200.
Step 4 execution: run python op2.py ./ to prepare the NEB run (including copying POTCAR) and launch run.sh in the NEB directory.
Step 5 (barrier extraction): run bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl' to print the NEB energy/force profile and determine the reaction barrier.
