Perform a VASP structural relaxation for Bi2Te3 in the directory data/relax/Bi2Te3.
Use POSCAR, KPOINTS, and POTCAR from the current directory as inputs.
Create an INCAR file for structure optimization containing exactly these lines: ALGO = Fast; EDIFF = 0.00025; ENCUT = 520.0; IBRION = 2; ISIF = 3; ISMEAR = -5; ISPIN = 2; LASPH = .TRUE.; LMAXMIX = 6; LORBIT = 11; LREAL = Auto; LWAVE = .FALSE.; MAGMOM = 19*0.0; NELM = 100; NSW = 99; PREC = Accurate; SIGMA = 0.05.
Run VASP using the launcher script command bash run_vasp.sh.
After the run, copy the INCAR used to a file named INCAR1 using cp INCAR INCAR1.
Extract the optimized total energy by running python get_energy.py, which reads vasprun.xml and prints the final total energy after relaxation.
Report the optimized total energy exactly as printed by get_energy.py.
