Work inside the directory data/relax/Al.
Use the existing input files POSCAR, KPOINTS, and POTCAR from that directory.
Create an INCAR file for structure optimization containing exactly these lines: ALGO = Fast; EDIFF = 5e-05; ENCUT = 520.0; IBRION = -1; ISIF = 3; ISMEAR = -5; ISPIN = 2; LASPH = .TRUE.; LORBIT = 11; LREAL = Auto; LWAVE = .FALSE.; MAGMOM = 26*-0.0; NELM = 100; NSW = 0; PREC = Accurate; SIGMA = 0.05.
Run VASP using the provided launcher script by executing bash run_vasp.sh.
After the run, copy the INCAR used to a file named INCAR1 by executing cp INCAR INCAR1.
Extract the optimized total energy by running python get_energy.py, which reads vasprun.xml and prints the optimized total energy after relaxation.
Report the optimized total energy exactly as printed by get_energy.py.
