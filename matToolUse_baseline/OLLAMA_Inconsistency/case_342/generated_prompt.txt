Write an INCAR file named `INCAR` in the `CO` subdirectory containing the following tags: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, EDIFF = 1E-5, PREC = Accurate, ALGO = Normal, LCHARG = .FALSE., LWAVE = .FALSE..  
Run the CO geometry optimization by executing `python op.py CO POTCAR-CO POSCAR-CO` inside the case directory.  

Write an identical INCAR file (same tags as above) in the `surface` subdirectory.  
Run the clean surface geometry optimization by executing `python op.py surface POTCAR-Ptface POSCAR-Ptface`.  

Write an identical INCAR file (same tags as above) in the `absorbed` subdirectory.  
Run the adsorbed system geometry optimization by executing `python op.py absorbed POTCAR-PtCO POSCAR-PtCO`.  

After all three relaxations have completed, compute the adsorption energy by running `bash ./calc_absorption_energy.sh`.  

The script will read the final total energies from `CO/OSZICAR`, `surface/OSZICAR`, and `absorbed/OSZICAR` and print the adsorption energy, which is the required output.
