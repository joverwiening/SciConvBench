Q: What INCAR parameters should be used for the PBE ground‑state calculation?
A: Use a standard PBE‑GGA INCAR, for example:

```
PREC    = Accurate
ENCUT   = 400        # (or 450 eV if you prefer the same cutoff as the HSE step)
EDIFF   = 1E-5
EDIFFG  = -0.02
ISMEAR  = 0
SIGMA   = 0.05
IBRION  = 2          # ionic relaxation (conjugate‑gradient)
NSW     = 50         # number of ionic steps
ISIF    = 3          # relax ions and cell shape/volume
ISPIN   = 1
LCHARG  = .TRUE.
LWAVE   = .TRUE.
LREAL   = Auto
NPAR    = 1
KPAR    = 1
NCORE   = 1
```

These parameters give a reliable PBE ground‑state calculation and can be written to the file `INCAR` before running `bash run_vasp.sh`. (If you prefer to match the HSE cutoff, set `ENCUT = 450`.)
