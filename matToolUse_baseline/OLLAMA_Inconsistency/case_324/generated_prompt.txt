Use the files POSCAR, KPOINTS, and POTCAR in the current directory as inputs for all VASP calculations.  
Create an INCAR file for the PBE ground‑state calculation containing the following tags: PREC = Accurate, ENCUT = 450, EDIFF = 1E-5, EDIFFG = -0.02, ISMEAR = 0, SIGMA = 0.05, IBRION = 2, NSW = 50, ISIF = 3, ISPIN = 1, LCHARG = .TRUE., LWAVE = .TRUE., LREAL = Auto, NPAR = 1, KPAR = 1, NCORE = 1, and ICHARG = 0.  
Run VASP for the PBE step with the command `bash run_vasp.sh`.  
After the PBE run, copy the INCAR file to `INCAR1` with `cp INCAR INCAR1`.  
Create a new INCAR file for the HSE calculation using the provided parameter block: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast, and do not include NBAND, NELECT, or magnetic moment tags.  
Run VASP for the HSE step with the command `bash run_vasp.sh`.  
After the HSE run, copy the INCAR file to `INCAR2` with `cp INCAR INCAR2`.  
Execute the post‑processing script with `python gap.py`.  
Return the band‑gap value exactly as printed by `gap.py`.
