Use the POSCAR, KPOINTS, and POTCAR files in the current directory as inputs for all VASP runs.  

Step 1 – PBE ground‑state calculation:  
Create an INCAR file containing the following parameters:  
SYSTEM = AlN PBE ground state  
PREC = Accurate  
ENCUT = 500  
EDIFF = 1E-5  
EDIFFG = -0.02  
ISMEAR = 0  
SIGMA = 0.05  
IBRION = 2  
NSW = 100  
ISIF = 3  
ISPIN = 1  
LCHARG = .TRUE.  
LWAVE = .TRUE.  
NELM = 60  
NELMIN = 4  
ALGO = Normal  

Run VASP with `bash run_vasp.sh`.  
Copy the INCAR used in this step to a file named `INCAR1` (`cp INCAR INCAR1`).  

Step 2 – HSE calculation:  
Create a new INCAR file using the parameter block from `data.json` and modify it as follows:  
- Set `ICHARG = 0` (replace the original `ICHARG=11`).  
- Do not include any magnetic moment specifications.  
- Do not include `NBAND` or `NELECT` parameters.  

The full HSE INCAR should contain:  
PREC = Normal  
ENCUT = 450  
NELM = 500  
IBRION = -1  
ISPIN = 1  
NSW = 0  
ISIF = 2  
EDIFF = 1E-5  
EDIFFG = -5E-3  
ISTART = 0  
ICHARG = 0  
ISMEAR = 0  
SIGMA = 0.05  
LWAVE = .T.  
LCHARG = .T.  
LREAL = Auto  
LPLANE = .TRUE.  
NPAR = 1  
KPAR = 4  
NCORE = 1  
LORBIT = 11  
ALGO = All  
LHFCALC = .TRUE.  
HSE06 = .TRUE.  
HFSCREEN = 0.2  
TIME = 0.4  
AEXX = 0.25  
AGGAX = 0.75  
LMAXFOCK = 4  
PRECFOCK = Fast  

Run VASP again with `bash run_vasp.sh`.  
Copy this INCAR to a file named `INCAR2` (`cp INCAR INCAR2`).  

Step 3 – Band‑gap extraction:  
Execute the provided post‑processing script with `python gap.py`.  
The script reads `vasprun.xml`, builds the band structure, and prints the band‑gap value.  

Return the band‑gap value exactly as printed by `gap.py`.
