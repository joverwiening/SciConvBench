Q: What INCAR parameters should be used for the PBE ground‑state calculation?
A: Use a standard PBE ground‑state INCAR, for example:

```
SYSTEM = AlN PBE ground state
PREC   = Accurate
ENCUT  = 500          # eV (or at least the POTCAR recommended cutoff)
EDIFF  = 1E-5
EDIFFG = -0.02
ISMEAR = 0            # Gaussian smearing
SIGMA  = 0.05
IBRION = 2            # Conjugate‑gradient ionic relaxation
NSW    = 100          # Max ionic steps
ISIF   = 3            # Relax ions and cell shape/volume
ISPIN  = 1            # Non‑magnetic
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 60
NELMIN = 4
ALGO   = Normal
```

These settings give a reliable PBE relaxation and are appropriate for the first step. Adjust `ENCUT` if a higher value is required by the POTCAR, but the above is a reasonable default.

Q: Should the `ICHARG` line in the HSE INCAR be changed from `ICHARG=11` to `ICHARG=0`?
