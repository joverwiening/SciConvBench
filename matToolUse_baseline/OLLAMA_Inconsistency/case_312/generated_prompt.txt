Work in the directory `data/bandgap/BN` using the provided `POSCAR`, `KPOINTS`, and `POTCAR` files.  
Create an `INCAR` file for the PBE ground‑state calculation containing the following parameters: `PREC = Accurate`, `ENCUT = 450`, `EDIFF = 1E-5`, `EDIFFG = -0.02`, `IBRION = 2`, `NSW = 100`, `ISMEAR = 0`, `SIGMA = 0.05`, `ISPIN = 1`, `LCHARG = .TRUE.`, `LWAVE = .TRUE.`, `LREAL = Auto`, `NPAR = 1`, `KPAR = 4`, `NCORE = 1`, `LORBIT = 11`, `ALGO = Normal`.  
Run VASP for the PBE step with `bash run_vasp.sh`.  
Copy the used `INCAR` to `INCAR1` with `cp INCAR INCAR1`.  
Create a new `INCAR` for the HSE calculation using the following parameters: `PREC = Normal`, `ENCUT = 450`, `NELM = 500`, `IBRION = -1`, `ISPIN = 1`, `NSW = 0`, `ISIF = 2`, `EDIFF = 1E-5`, `EDIFFG = -5E-3`, `ISTART = 0`, `ICHARG = 0`, `ISMEAR = 0`, `SIGMA = 0.05`, `LWAVE = .T.`, `LCHARG = .T.`, `LREAL = Auto`, `LPLANE = .TRUE.`, `NPAR = 1`, `KPAR = 4`, `NCORE = 1`, `LORBIT = 11`, `ALGO = All`, `LHFCALC = .TRUE.`, `HSE06 = .TRUE.`, `HFSCREEN = 0.2`, `TIME = 0.4`, `AEXX = 0.25`, `AGGAX = 0.75`, `LMAXFOCK = 4`, `PRECFOCK = Fast`.  
Run VASP for the HSE step with `bash run_vasp.sh`.  
Copy the used `INCAR` to `INCAR2` with `cp INCAR INCAR2`.  
Execute the post‑processing script with `python gap.py` to obtain the band gap.  
Return the band‑gap value exactly as printed by `gap.py`.
