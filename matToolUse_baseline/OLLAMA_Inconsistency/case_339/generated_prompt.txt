Write an INCAR file for each of the three geometry‑optimization steps (CO, clean surface, adsorbed system) containing the following parameters:  
EDIFFG = -0.05  
ENCUT = 450  
IBRION = 1  
ISIF = 2  
ISMEAR = 1  
ISPIN = 1  
POTIM = 0.2  
SIGMA = 0.2  
NSW = 200  

Run the CO optimization:  
python op.py CO POTCAR-CO POSCAR-CO  

Run the clean‑surface optimization:  
python op.py surface POTCAR-RhO2face POSCAR-RhO2face  

Run the adsorbed‑system optimization:  
python op.py absorbed POTCAR-RhO2CO POSCAR-RhO2CO  

After the three relaxations finish, compute the adsorption energy by executing:  
bash ./calc_absorption_energy.sh  

The script will read the final total energies from CO/OSZICAR, surface/OSZICAR, and absorbed/OSZICAR and print the adsorption energy. The printed value is the required output.
