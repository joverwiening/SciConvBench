Create an INCAR file in the current directory containing the following lines:
ALGO = Fast
EDIFF = 0.0005
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 39*0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05

Run VASP using the provided launch script with the command:
bash run_vasp.sh

After VASP finishes, copy the used INCAR file to a backup named INCAR1:
cp INCAR INCAR1

Extract the optimized total energy by executing the post‑processing script:
python get_energy.py

Print the optimized total energy exactly as produced by get_energy.py to standard output.
