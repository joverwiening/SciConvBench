Q: What specific INCAR parameters should be used for the PBE ground‑state calculation?
A: A reasonable PBE‑ground‑state INCAR can be the standard “high‑quality” set used for most semiconductors/insulators. For example:

```
PREC    = Accurate
ENCUT   = 400        # (or at least the POTCAR‑recommended value)
EDIFF   = 1E-5
EDIFFG  = -0.02
ISMEAR  = 0
SIGMA   = 0.05
IBRION  = 2          # conjugate‑gradient ionic relaxation
NSW     = 50         # number of ionic steps (adjust as needed)
ISIF    = 3          # relax ions and cell shape/volume
ISPIN   = 1
LCHARG  = .TRUE.
LWAVE   = .TRUE.
NELM    = 100
NELMIN  = 4
LREAL   = Auto
```

These parameters give a reliable PBE ground‑state calculation and can be saved as the `INCAR` for Step 1. (If you have a different ENCUT recommendation from the POTCAR, use that value instead.)
