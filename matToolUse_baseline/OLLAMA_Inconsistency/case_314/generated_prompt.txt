Create an INCAR file for the PBE ground‑state calculation in the `data/bandgap/C` directory using the following parameters: PREC = Accurate, ENCUT = 400 eV (or the POTCAR‑recommended value), EDIFF = 1E-5, EDIFFG = -0.02, ISMEAR = 0, SIGMA = 0.05, IBRION = 2, NSW = 50, ISIF = 3, ISPIN = 1, LCHARG = .TRUE., LWAVE = .TRUE., NELM = 100, NELMIN = 4, LREAL = Auto. Save this file as `INCAR`, run VASP with `bash run_vasp.sh`, and then copy the used INCAR to `INCAR1` with `cp INCAR INCAR1`.

Create a new INCAR file for the HSE calculation using the parameter block provided in `data.json` (PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast) but set ICHARG = 0, and do not include magnetic moment, NBAND, or NELECT specifications. Save this file as `INCAR`, run VASP again with `bash run_vasp.sh`, and copy the used INCAR to `INCAR2` with `cp INCAR INCAR2`.

Finally, execute the post‑processing script with `python gap.py` to read `vasprun.xml` and print the electronic band gap. Output the band‑gap value exactly as printed by `gap.py`.
