Create an INCAR file for the PBE ground‑state calculation in the directory `data/bandgap/CdTe` using the following parameters: PREC = Accurate, ENCUT = 500, EDIFF = 1E-5, EDIFFG = -0.02, ISMEAR = 0, SIGMA = 0.05, IBRION = 2, NSW = 100, ISIF = 3, ISPIN = 1, LCHARG = .TRUE., LWAVE = .TRUE., LREAL = Auto, NELM = 60, NELMIN = 4.  
Run VASP with the command `bash run_vasp.sh`.  
Copy the INCAR used for the PBE step to `INCAR1` using `cp INCAR INCAR1`.  
Create a new INCAR for the HSE calculation using the parameter block from `data.json`, but set ICHARG = 0, and do not include any magnetic moment, NBAND, or NELECT specifications. Keep all other parameters exactly as listed.  
Run VASP again with `bash run_vasp.sh`.  
Copy the INCAR used for the HSE step to `INCAR2` using `cp INCAR INCAR2`.  
Execute the band‑gap extraction script with `python gap.py` and output the band‑gap value printed by the script.
