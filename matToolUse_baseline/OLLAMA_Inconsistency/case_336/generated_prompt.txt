Create an INCAR file containing the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200.  
Place a copy of this INCAR file in each of the three step directories (CO, surface, absorbed) before running any calculations.  
Step 1 – Optimize the CO molecule: run `python op.py CO POTCAR-CO POSCAR-CO`.  
Step 2 – Optimize the clean Rh surface: run `python op.py surface POTCAR-Rhface POSCAR-Rhface`.  
Step 3 – Optimize the CO‑adsorbed Rh slab: run `python op.py absorbed POTCAR-RhCO POSCAR-RhCO`.  
Step 4 – Compute the adsorption energy: run `bash ./calc_absorption_energy.sh` and output the adsorption energy exactly as printed by the script.
