In the directory data/bandgap/CdS, create an INCAR file for the PBE ground‑state calculation with the tags: SYSTEM = CdS PBE ground state, PREC = Accurate, ENCUT = 450, EDIFF = 1E-5, EDIFFG = -0.02, ISMEAR = 0, SIGMA = 0.05, IBRION = 2, NSW = 50, ISIF = 3, ISPIN = 1, LWAVE = .TRUE., LCHARG = .TRUE., LREAL = Auto, NELM = 100, NELMIN = 4, ALGO = Normal, GGA = PE, ICHARG = 2.  
Save this file as INCAR, then run VASP with `bash run_vasp.sh`.  
After the run, copy the INCAR to INCAR1 using `cp INCAR INCAR1`.  
Create a new INCAR file for the HSE calculation containing exactly the following parameters: PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=0, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=All, LHFCALC=.TRUE., HSE06=.TRUE., HFSCREEN=0.2, TIME=0.4, AEXX=0.25, AGGAX=0.75, LMAXFOCK=4, PRECFOCK=Fast.  
Do not add any other tags such as magnetic moments, NBAND, or NELECT.  
Save this file as INCAR, then run VASP again with `bash run_vasp.sh`.  
After the HSE run, copy the INCAR to INCAR2 using `cp INCAR INCAR2`.  
Finally, extract the band gap by executing `python gap.py` and output the band‑gap value printed by the script.
