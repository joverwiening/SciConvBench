Create a file named INCAR in the directory data/relax/LiCoO2 containing the following lines:
ALGO = Fast
EDIFF = 0.0002
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LDAU = .TRUE.
LDAUJ = 0 0 0
LDAUL = 0 2 0
LDAUPRINT = 1
LDAUTYPE = 2
LDAUU = 0 3.32 0
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 31*-0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05
Copy this INCAR file to INCAR1 to preserve the used parameters.
Run VASP using the provided launch script by executing: bash run_vasp.sh.
After VASP finishes, execute the post‑processing script: python get_energy.py.
Return the optimized total energy exactly as printed by get_energy.py.
