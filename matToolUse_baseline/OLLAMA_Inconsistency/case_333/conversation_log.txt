Q: What specific INCAR parameters should be used for the PBE ground‑state calculation?
A: A reasonable PBE‑ground‑state INCAR can be built from standard best‑practice settings, for example:

```
SYSTEM = ZnS PBE ground state
PREC   = Accurate
ENCUT  = 400          # (or the maximum ENMAX from the POTCAR)
EDIFF  = 1E-5
EDIFFG = -0.02
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2            # conjugate‑gradient ionic relaxation
NSW    = 50           # number of ionic steps (adjust as needed)
ISIF   = 3            # relax ions and cell shape/volume
ISPIN  = 1            # non‑magnetic
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 100
NELMIN = 4
LREAL  = Auto
ALGO   = Normal
```

These parameters provide a stable PBE relaxation and generate the WAVECAR/CHGCAR files needed for the subsequent HSE step. Adjust ENCUT to match the POTCAR’s recommended cutoff if a different value is required.
