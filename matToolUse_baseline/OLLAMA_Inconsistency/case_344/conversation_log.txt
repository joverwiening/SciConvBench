Q: What value would you like to set for NSW (the maximum number of ionic steps) in the IS/FS relaxations and the NEB calculation?
A: Use a relatively large number of ionic steps, for example:

- **IS and FS relaxations:** `NSW = 200`  
- **NEB calculation:** `NSW = 300`  

These values satisfy the “larger number of NSW” guideline while remaining practical.
