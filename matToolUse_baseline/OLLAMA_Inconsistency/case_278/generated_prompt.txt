Create an INCAR file in the current directory containing the specified parameters for structural optimization. Run VASP by executing the provided launch script `bash run_vasp.sh`. After VASP finishes, copy the used INCAR file to `INCAR1` to preserve it. Execute `python get_energy.py` to read `vasprun.xml` and print the optimized total energy. Return the optimized total energy exactly as printed by `get_energy.py`.
