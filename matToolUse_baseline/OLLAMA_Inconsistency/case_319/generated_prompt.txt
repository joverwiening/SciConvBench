Create an INCAR file for the PBE ground‑state calculation using the provided parameters, and add `ISTART = 0` and `ICHARG = 0`.  
Run VASP with `bash run_vasp.sh`.  
Copy the INCAR used for the PBE step to `INCAR1` with `cp INCAR INCAR1`.  

Create a new INCAR for the HSE calculation using the parameter block from `data.json`.  
Set `ISTART = 0` and change `ICHARG` to `0`.  
Ensure that the INCAR does **not** contain any magnetic‑moment tags (e.g., `MAGMOM`), nor `NBAND` or `NELECT` entries.  
Run VASP again with `bash run_vasp.sh`.  
Copy the INCAR used for the HSE step to `INCAR2` with `cp INCAR INCAR2`.  

Execute the post‑processing script `python gap.py` to read `vasprun.xml` and print the electronic band gap.  

The final output should be the band‑gap value exactly as printed by `gap.py`.
