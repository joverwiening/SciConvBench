Create a file named INCAR in the data/relax/AlN directory containing exactly the provided INCAR parameter block.  
Run the VASP calculation from the data/relax/AlN directory using the command `bash run_vasp.sh`.  
After VASP finishes, copy the INCAR file to a new file named INCAR1 in the same directory.  
Execute the post‑processing script with `python get_energy.py` from the data/relax/AlN directory.  
Capture the output printed by get_energy.py and write it to a file named total_energy.txt in the data/relax/AlN directory.  
All steps must be performed while the current working directory is data/relax/AlN.
