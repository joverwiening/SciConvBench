Q: What INCAR parameters should be used for the PBE ground‑state calculation?
A: Use a standard PBE‑GGA INCAR such as:

```
SYSTEM = ZnO PBE ground state
PREC   = Accurate
ENCUT  = 520          # (or at least the POTCAR recommended cutoff)
EDIFF  = 1E-5
EDIFFG = -0.02
ISMEAR = 0
SIGMA  = 0.05
IBRION = 2            # conjugate‑gradient ionic relaxation
NSW    = 100
ISIF   = 3            # relax ions and cell shape/volume
ISPIN  = 1
LCHARG = .TRUE.
LWAVE  = .TRUE.
NELM   = 60
NELMIN = 4
LREAL  = Auto
```

These parameters constitute a reasonable PBE ground‑state calculation. If you need to adjust the plane‑wave cutoff, use the maximum ENMAX from the POTCAR (e.g., 520 eV).
