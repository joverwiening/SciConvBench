Use the provided PBE‑GGA INCAR parameters for the ground‑state calculation, with ISTART = 0 and the default ICHARG for a fresh run. After writing this INCAR, run `bash run_vasp.sh` and then copy the INCAR to `INCAR1`.  
Create a new INCAR for the HSE calculation using the parameter block from `data.json`, but set `ICHARG = 0` and do not include any magnetic‑moment, NBAND, or NELECT specifications. After writing this INCAR, run `bash run_vasp.sh` again and copy the INCAR to `INCAR2`.  
Finally, execute `python gap.py` to extract and print the band‑gap value.
