Create an INCAR file for the CO optimization containing: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, PREC = Normal.  
Use the same INCAR file for the surface and adsorbed system optimizations.  
Do not include LCHARG, LWAVE, or any other extra output flags.  
Place the provided KPOINTS file in each calculation directory.  
Run `python op.py CO POTCAR-CO POSCAR-CO` to create the CO subdirectory, copy POSCAR and POTCAR, and execute run.sh.  
Run `python op.py surface POTCAR-Pdface POSCAR-Pdface` to create the surface subdirectory and run the calculation.  
Run `python op.py absorbed POTCAR-PdCO POSCAR-PdCO` to create the absorbed subdirectory and run the calculation.  
After all three relaxations finish, execute `bash ./calc_absorption_energy.sh` to read the final energies from CO/OSZICAR, surface/OSZICAR, and absorbed/OSZICAR and print the adsorption energy.  
The output of the script is the required adsorption energy.
