Calculate the lattice parameter for a metal with the specified properties.
The metal has a Face-Centered Cubic (FCC) crystal structure.
The number of atoms per unit cell is 4.
The atomic weight is 85.15 g/mol.
The theoretical density is 13.931 g/cm^3.
Avogadro's number (N_A) is 6.022×10^23 mol^-1.
Use the formula a = ³√[(n * A) / (ρ * N_A)] to find the lattice parameter 'a'.
The final calculated lattice parameter must be expressed in nanometers (nm).
