Use N-mm-MPa units for all calculations.
The column is a solid circular section.
The column diameter is d = 30 mm.
The column length is L = 1500 mm.
The material is structural steel with Young's Modulus E = 200000 MPa.
The column has an effective length factor K = 2.0.
The analysis is governed by Euler buckling theory.
Calculate the second moment of area using the formula I = (π * d^4) / 64.
Compute the Euler critical load using the formula P_cr = (π^2 * E * I) / (K * L)^2.
Use a factor of safety n = 2.0.
Determine the allowable axial compressive load using the formula P_allow = P_cr / n.
