The simulation will be performed using the laplacianFoam solver.
The goal is to find the steady-state temperature distribution in a solid plate.
The simulation domain is a 1m x 1m square, configured to be one cell thick.
The mesh will consist of 20 cells in the x-direction.
The mesh will consist of 20 cells in the y-direction.
The mesh will consist of 1 cell in the z-direction.
Four side patches will be named left, right, top, and bottom.
The front and back patches will be combined into a single patch named frontAndBack.
The frontAndBack patch type will be set to wall.
The thermal diffusivity of the material is 1.6e-5 m^2/s.
The left wall boundary condition for temperature is a fixedValue of 400 K.
The right wall boundary condition for temperature is a fixedValue of 300 K.
The top wall boundary condition for temperature is zeroGradient.
The bottom wall boundary condition for temperature is zeroGradient.
The frontAndBack wall boundary condition for temperature is zeroGradient.
The numerical scheme for the Laplacian term will be Gauss linear corrected.
The linear solver for the temperature equation will be PCG.
The convergence tolerance for the temperature solver will be 1e-6.
The simulation will run for a maximum of 1000 iterations.
