Calculate the diffraction angle 2θ for X-ray diffraction from a cubic crystal.
The X-ray wavelength is 0.0762 nm.
The cubic crystal has a lattice parameter of 0.5313 nm.
The reflection is from the (111) crystallographic planes, where h=1, k=1, and l=1.
The reflection is first-order, so n=1.
First, calculate the interplanar spacing 'd' for the (111) planes using the formula for a cubic crystal: d = a / sqrt(h^2 + k^2 + l^2).
Then, use Bragg's Law (nλ = 2d sin(θ)) to solve for the angle θ.
Finally, calculate the diffraction angle as 2θ.
The final result for 2θ must be expressed in degrees.
