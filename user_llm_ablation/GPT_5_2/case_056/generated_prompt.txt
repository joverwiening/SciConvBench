Create a file named `membrane3.inp` in the working directory.
The content of `membrane3.inp` must be the exact text provided in the reference input deck.
Run the CalculiX solver on the input file using the command `ccx -i membrane3` or `ccx membrane3`.
Check the `membrane3.sta` file to determine if the simulation completed successfully.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object.
The "solver" key must have the string value "calculix".
The "case_id" key must have the string value "membrane3".
The "status" key must have the string value "success" if the run completed successfully, otherwise it must be "error".
The "ccx_version" key must contain the version string obtained by running `ccx -v`.
The "artifacts" key must have an empty list `[]` as its value.
The "notes" key must contain a string with the exact CalculiX command used.
If the run failed, the "notes" string must also include the error message and the name of the file that indicated the failure.
