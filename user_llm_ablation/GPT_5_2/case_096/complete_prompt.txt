Simulate steady-state 2D Rayleigh-Benard convection at Ra ~ 1e5 using the Boussinesq approximation.

Solver: buoyantBoussinesqSimpleFoam

Geometry: 0.1 m x 0.1 m square cavity, 2D via empty front/back.

Mesh: blockMesh 50 x 50 x 1.

Target Ra:
With H=0.1 m, DeltaT=1 K, beta=3.33e-3, nu=1.5e-5, Pr=0.71 (alpha=nu/Pr),
Ra ~ g*beta*DeltaT*H^3/(nu*alpha) ~ 1e5.

Physical properties (constant/physicalProperties):
- nu = 1.5e-5
- Pr = 0.71
- beta = 3.33e-3
- T0 = 293.5
- rho0 = 1.0
Gravity: g (0 -9.81 0)

Boundary conditions:
- bottomHot: T fixedValue 294.0; U noSlip; p_rgh fixedFluxPressure
- topCold:   T fixedValue 293.0; U noSlip; p_rgh fixedFluxPressure
- sideWalls: T zeroGradient;      U noSlip; p_rgh fixedFluxPressure
- frontAndBack: empty

Initial conditions:
- U=(0 0 0), p_rgh=0, T=293.5 uniform.
To break symmetry, use setFields to add a small temperature perturbation:
- boxToCell (0.045 0.00 -1) to (0.055 0.01 1): set T 293.52

Controls: endTime 5000; deltaT 1; writeInterval 500 (steady solver pseudo-time iterations) and stop based on residualControl in fvSolution.
