Solve the 1D viscous Burgers' equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The solution uses a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The time integration is performed using Strang splitting.
The total number of time steps Nt is calculated by first finding dt0 = 0.4 * dx / 1.0.
Then Nt is the ceiling of T/dt0, where T=1.0.
The final time step is dt = T/Nt.
Each time step dt consists of three sub-steps in sequence: a diffusion half-step, an advection full-step, and a second diffusion half-step.
The first sub-step is a diffusion half-step for a duration of dt/2, solved in Fourier space.
To solve the diffusion sub-step, first compute the FFT of the solution u to get u_hat.
The angular wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Update the Fourier coefficients using the formula u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Compute the IFFT of the updated u_hat and take its real part to get the result of the diffusion sub-step.
The second sub-step is an advection full-step for the inviscid Burgers equation for a duration of dt.
The advection step is solved using a finite-volume method with a Rusanov flux.
The flux function is f(u) = 0.5*u^2.
The numerical flux F at an interface between a left state u_left and a right state u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed alpha is max(abs(u_left), abs(u_right)).
Update the solution in each cell j using the formula u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell, respectively.
The third sub-step is another diffusion half-step, identical to the first one.
Compute the solution u(x,t) at the final time T=1.0.
