Solve the one-dimensional Cahn-Hilliard partial differential equation.
The equation is u_t = -(0.01)^2 * u_xxxx + d^2/dx^2(u^3 - u).
The spatial domain is x in the periodic interval [0, 1).
The time domain is t in [0, 0.05].
The initial condition is u(x, 0) = 0.1 * cos(2 * pi * x) + 0.01 * cos(6 * pi * x).
The parameter epsilon is 0.01.
Use a Fourier pseudo-spectral method for spatial discretization.
Discretize the spatial domain with Nx = 512 equally spaced points.
The grid points are x_j = j / Nx for j from 0 to Nx-1.
The spatial step size is dx = 1 / Nx.
Use a semi-implicit time integration scheme.
The time step is dt = 1e-5.
The total number of time steps is 5000.
The time-stepping formula in Fourier space is û^{n+1} = (û^n + dt * F[d^2/dx^2(u^3)]) / (1 - dt * L(k)).
The linear operator in Fourier space is L(k) = -epsilon^2 * k^4 + k^2.
The nonlinear term d^2/dx^2(u^3) is treated explicitly.
Apply a 2/3 dealiasing rule to the u^3 term.
To dealias, zero out the Fourier modes of u^3 for which the absolute value of the wavenumber index is greater than floor(Nx/3).
Compute the solution u(x, t) at the final time T = 0.05.
Save the solution to a file named "solution_agent_other_02_cahn_hilliard.npz".
The NPZ file must contain the 1D array of grid points 'x', the 1D array of the solution 'u', and the scalar metadata T, dx, and dt.
Save a line plot of the final solution u(x, T) versus x to a file named "solution_agent_other_02_cahn_hilliard.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution u, calculated as sqrt(sum(u^2) * dx).
