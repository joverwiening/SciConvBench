Q: What numerical flux function should be used for the inviscid terms?
A: Use the **Rusanov (local Lax–Friedrichs) numerical flux** for the inviscid (Euler) part:

- \(F_{\text{conv}}(U) = \big[m,\; m^2/\rho + p,\; (E+p)v\big]\), with \(v=m/\rho\).
- Interface wave speed \(a = \max\left(|v_L|+c_L,\; |v_R|+c_R\right)\), where \(c=\sqrt{\Gamma p/\rho}\).
- Numerical flux:
\[
\hat F = \tfrac12\left(F_{\text{conv}}(U_L)+F_{\text{conv}}(U_R)\right) - \tfrac12 a (U_R-U_L).
\]

Q: How should the velocity gradient `v_x` be approximated at a cell interface to compute the viscous stress `sigma`?
A: Compute \(v_x\) **on cell centers** using a **centered difference** on the cell-centered velocities \(v_j\), e.g.
\[
(v_x)_j \approx \frac{v_{j+1}-v_{j-1}}{2\,dx}.
\]
Then compute \(\sigma_j = (\zeta+\tfrac{4}{3}\eta)\,(v_x)_j\). To get the **interface** value used in the viscous flux, **average neighboring cell-centered stresses**:
\[
\sigma_{j+1/2} = \tfrac12(\sigma_j+\sigma_{j+1}).
\]

=== 2026-04-24 12:33:10 ===
Q: How should the term `v*sigma` in the energy flux be computed at the interface `j+1/2`?
A: Compute it using **interface-averaged** velocity and stress:

- First get cell-centered \(\sigma_j = (\zeta+\tfrac{4}{3}\eta)\,(v_x)_j\).
- Interface stress: \(\sigma_{j+1/2} = \tfrac12(\sigma_j+\sigma_{j+1})\).
- Interface velocity: \(v_{j+1/2} = \tfrac12(v_j+v_{j+1})\).

Then in the viscous energy flux use
\[
(v\sigma)_{j+1/2} = v_{j+1/2}\,\sigma_{j+1/2},
\]
so
\[
F^{\text{visc}}_{E,\,j+1/2} = -\, (v\sigma)_{j+1/2}.
\]
