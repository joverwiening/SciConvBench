The 1D compressible Navier-Stokes equations are to be solved.
The conservative state vector is U = [rho, m, E], where rho is density, m is momentum (rho*v), and E is total energy.
The primitive variables are density (rho), velocity (v), and pressure (p).
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The parameter zeta is equal to eta.
The PDE system in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.2].
The final simulation time is T = 0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
Boundary conditions are transmissive (zero-gradient) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho_L = 0.445, v_L = 0.698, p_L = 3.528.
For x >= 0, the initial state is rho_R = 0.5, v_R = 0.0, p_R = 0.571.
The spatial discretization is a uniform finite-volume grid with Nx = 800 cells.
The inviscid fluxes at cell interfaces are computed using the Rusanov (local Lax-Friedrichs) numerical flux.
The interface wave speed for the Rusanov flux is a = max(|v_L|+c_L, |v_R|+c_R), where c = sqrt(Gamma*p/rho).
The numerical flux is F_hat = 0.5*(F(U_L) + F(U_R)) - 0.5*a*(U_R - U_L).
The velocity gradient v_x is first computed at cell centers j using the centered difference (v_{j+1} - v_{j-1}) / (2*dx).
The viscous stress sigma is then computed at cell centers j using the cell-centered v_x.
The viscous stress at a cell interface j+1/2 is the average of the neighboring cell-centered stresses: sigma_{j+1/2} = 0.5*(sigma_j + sigma_{j+1}).
The velocity at a cell interface j+1/2 is the average of the neighboring cell-centered velocities: v_{j+1/2} = 0.5*(v_j + v_{j+1}).
The viscous term v*sigma in the energy flux at interface j+1/2 is computed as v_{j+1/2} * sigma_{j+1/2}.
Time integration is performed using the 2-stage Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step dt is determined by a Courant-Friedrichs-Lewy (CFL) number of 0.5.
The final solution rho(x,T), v(x,T), p(x,T) is computed on the cell centers at T=0.2.
