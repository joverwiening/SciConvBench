Set the unit system to N-mm-MPa.
Define the column diameter d as 25 mm.
Define the column length L as 2000 mm.
Define the Young's modulus E as 200000 MPa.
Define the effective length factor K as 0.7.
Define the applied compressive load P as 25000 N.
Define the material yield strength Sy as 250 MPa.
Calculate the cross-sectional area A using the formula A = π * d^2 / 4.
Calculate the average compressive stress σ_avg using the formula σ_avg = P / A.
Compare the calculated σ_avg to the yield strength Sy.
Calculate the second moment of area I using the formula I = π * d^4 / 64.
Calculate the Euler critical buckling load P_cr using the formula P_cr = (π^2 * E * I) / ((K * L)^2).
Compare the applied load P to the calculated critical load P_cr.
