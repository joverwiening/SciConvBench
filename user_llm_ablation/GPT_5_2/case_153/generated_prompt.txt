Solve the 1D viscous Burgers equation u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 4.0.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j/Nx for j=0, ..., Nx-1.
The spatial step size is dx = 1/Nx.
Calculate the time step dt to exactly reach the final time T=1.0.
First, estimate an initial time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T/dt0).
Finally, set the actual time step dt = T/Nt.
Use Strang splitting for the time integration over each time step dt.
The first substep is a diffusion step of duration dt/2 solved in Fourier space.
The Fourier space update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
The second substep is an advection step of duration dt for the inviscid Burgers equation.
Solve the advection step using a finite-volume method with Rusanov flux.
The flux function is f(u) = 0.5*u^2.
The Rusanov flux at the interface between u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The finite-volume cell update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left cell interfaces, respectively.
The third substep is another diffusion step of duration dt/2, identical to the first substep.
Compute the solution u(x,t) up to the final time T=1.0.
Save the results to a file named "solution_pdebench_burgers_nu4.npz".
The NPZ file must contain the 1D arrays x and u, and the scalar values nu, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_burgers_nu4.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete mean value of the final solution u.
Print the discrete L2 norm of the final solution u, calculated as sqrt(sum(u^2)*dx).
