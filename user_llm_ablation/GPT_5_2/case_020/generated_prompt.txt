The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem to be solved is 2D small-strain linear elasticity.
The model will use a plane-stress constitutive relation.
The geometry is a rectangle defined by the domain Ω = (0, 1.0) x (0, 0.20) meters.
A uniform structured mesh of 40x8 quadrilateral cells will be used.
The vector-valued displacement space will use continuous Lagrange elements of polynomial degree 1.
The material has a Young's modulus E = 200 GPa and a Poisson's ratio ν = 0.30.
The left edge of the domain (x = 0) is fixed, with displacement u = (0, 0).
The top edge of the domain (y = 0.20) is subjected to a uniform traction t = (0, -2000) N/m.
The right edge (x = 1.0) and bottom edge (y = 0) are traction-free.
The variational problem will be solved using a direct linear solver.
The y-component of the displacement field (u_y) will be saved as a color map image named `q2_uy.png`.
The full displacement vector field will be saved in XDMF format to a file named `displacement.xdmf`.
