Create an INCAR file for the CO molecule relaxation with the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200.
Execute the command `python op.py CO POTCAR-CO POSCAR-CO`.
Overwrite the INCAR file for the slab calculations with the following parameters: EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 200, LDIPOL = .TRUE., IDIPOL = 3.
Execute the command `python op.py surface POTCAR-Irface POSCAR-Irface`.
Execute the command `python op.py absorbed POTCAR-IrCO POSCAR-IrCO`.
After the three relaxation calculations are complete, execute the command `bash ./calc_absorption_energy.sh`.
The final output is the adsorption energy value printed by the `calc_absorption_energy.sh` script.
