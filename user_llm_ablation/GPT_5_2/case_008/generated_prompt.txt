The simulation will be implemented using the FEniCS legacy library (dolfin).
The problem to solve is a 2D plane-stress small-strain orthotropic elasticity problem.
The geometry is a rectangle defined by the domain Omega = (0, 1.0) x (0, 0.20) meters.
A structured mesh of 50 elements in the x-direction and 25 elements in the y-direction will be used.
The displacement vector field will be approximated using continuous Lagrange elements of degree 1.
The material is orthotropic with local properties E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
The local material axes are rotated 30 degrees anticlockwise with respect to the global x-y axes.
The bottom edge of the domain (y = 0) is fixed, with displacement components u_x and u_y set to zero.
The top edge of the domain (y = 0.20) is subjected to a uniform downward traction vector of (0, -10 MPa).
The vertical sides of the domain (x = 0 and x = 1.0) are traction-free.
The linear system will be solved using a direct solver.
The x-component of the displacement field will be saved as a color map image named q8_ux.png.
The von Mises stress field will be calculated and saved as a color map image named q8_vm.png.
The displacement and stress fields will be written to an XDMF file named q8_solution.xdmf.
