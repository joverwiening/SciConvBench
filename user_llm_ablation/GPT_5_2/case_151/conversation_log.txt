Q: The specification lists 'Explicit forward Euler' for time integration but then describes a 'Strang splitting' method, which is a different time integration scheme. Which of these two methods should be used?
A: Use the **Strang splitting** method exactly as specified in section 7:

- Diffusion half-step in Fourier space (duration **dt/2**)
- Advection full-step using the **finite-volume Rusanov flux** update (duration **dt**)
- Diffusion half-step again (duration **dt/2**)

Do **not** use a separate global “explicit forward Euler” integrator beyond the explicit finite-volume update in the advection substep.
