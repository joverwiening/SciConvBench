Create a single INCAR file to be used for the three geometry optimization calculations.
The INCAR file must contain the parameter ENCUT = 450.
The INCAR file must contain the parameter EDIFF = 1E-5.
The INCAR file must contain the parameter EDIFFG = -0.05.
The INCAR file must contain the parameter IBRION = 1.
The INCAR file must contain the parameter POTIM = 0.2.
The INCAR file must contain the parameter NSW = 200.
The INCAR file must contain the parameter ISIF = 2.
The INCAR file must contain the parameter ISMEAR = 1.
The INCAR file must contain the parameter SIGMA = 0.2.
The INCAR file must contain the parameter ISPIN = 1.
The INCAR file must contain the parameter LREAL = .FALSE..
The INCAR file must contain the parameter NELM = 100.
Run the geometry optimization for the CO molecule using the command `python op.py CO POTCAR-CO POSCAR-CO`.
Run the geometry optimization for the clean surface using the command `python op.py surface POTCAR-OsO2face POSCAR-OsO2face`.
Run the geometry optimization for the adsorbed system using the command `python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO`.
After the three optimizations are complete, calculate the final result by running the command `bash ./calc_absorption_energy.sh`.
The final output is the adsorption energy value printed by the `calc_absorption_energy.sh` script.
