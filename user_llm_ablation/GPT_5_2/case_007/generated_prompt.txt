Calculate the downstream depth, y2, for a hydraulic jump in a rectangular open channel.
The channel width is 3 meters.
The upstream depth, y1, is 0.4 meters.
The upstream velocity, V1, is 6.0 m/s.
The acceleration due to gravity, g, is 9.81 m/s^2.
Use the momentum equation, specifically the sequent depth relationship for a hydraulic jump in a rectangular channel, to perform the calculation.
First, calculate the upstream Froude number, Fr1, using the formula Fr1 = V1 / sqrt(g * y1).
Then, calculate the downstream depth, y2, using the formula y2 = (y1 / 2) * (sqrt(1 + 8 * Fr1^2) - 1).
