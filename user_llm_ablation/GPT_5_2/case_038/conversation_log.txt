Q: You have specified a simply supported beam but also that the end slopes are zero, which defines a fixed-fixed beam. Which beam type should be used for the analysis?
A: Use a **simply supported beam** for the analysis: boundary conditions are **deflection zero at both supports** ( \(v(0)=0,\ v(L)=0\) ) with **free end rotation** (slopes not constrained).  

Do **not** impose zero end slopes; the symmetry only implies **zero slope at midspan** ( \(v'(L/2)=0\) ), not at the supports.
