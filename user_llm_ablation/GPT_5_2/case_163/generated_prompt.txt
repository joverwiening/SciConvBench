The PDE to be solved is the 1D Compressible Navier-Stokes system without heat conduction.
The unknown primitive fields are density rho(x,t), velocity v(x,t), and pressure p(x,t).
The conservative state vector is U = [rho, m, E], where m is momentum and E is total energy.
Momentum is defined as m = rho*v.
Total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system in conservative form is rho_t + (m)_x = 0.
The second equation is m_t + (m^2/rho + p - sigma)_x = 0.
The third equation is E_t + ((E+p)*v - v*sigma)_x = 0.
The spatial domain is x in [-1, 1].
The simulation runs from t=0 to the final time T=0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
Boundary conditions are transmissive (zero-gradient outflow) at x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho_L = 1.0, v_L = -0.75, p_L = 1.0.
For x >= 0, the initial state is rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Use a uniform finite-volume grid with Nx = 800 cells on the domain [-1, 1].
The cell width is dx = 2/Nx.
The cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The simulation evolves the cell averages of the conservative variables U = [rho, m, E].
Pressure is recovered from the conservative variables using the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below this value.
The convective part of the flux is F_conv(U) = [m, m^2/rho + p, (E+p)*v], with v = m/rho.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective terms.
The Rusanov interface flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho) is the sound speed.
Compute the velocity gradient v_x at cell centers using a second-order centered difference.
The viscous stress at cell centers is sigma = (zeta + 4/3*eta)*v_x.
Approximate sigma at cell interfaces by arithmetically averaging the values from the two neighboring cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The viscous flux at an interface is computed using the interface-averaged sigma and an interface-averaged velocity v.
The total numerical flux at an interface is the sum of the convective and viscous fluxes, F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration of the semi-discrete system.
The CFL number for the time step calculation is 0.5.
The time step dt is the minimum of the convective and viscous time step constraints.
The convective time step constraint is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step constraint is dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Adjust the final time step to ensure the simulation stops exactly at T = 0.2.
Implement the outflow boundary conditions by setting the values in the ghost cells equal to the nearest interior cell.
Compute the solution rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T.
