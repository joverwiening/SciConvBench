The task is to solve a system of ordinary differential equations.
The system of equations is dx/dt = y and dy/dt = -delta*y - alpha*x - beta*x**3.
The independent variable is t, and the dependent variables are x(t) and y(t).
The parameters are alpha = 2, beta = 0.1, and delta = 0.2.
The time domain for the simulation is from t=0.0 to t=50.0.
The initial conditions at t=0.0 are x(0.0) = 1.0 and y(0.0) = 0.0.
Solve the system using the classical 4th-order Runge-Kutta method.
Use a fixed time step of dt = 0.01.
Perform 5000 time steps, resulting in a total of 5001 time points including the initial state.
Compute the state vector [x, y] at all 5001 time points.
Save the results to a compressed NumPy file named "solution_molk_011.npz".
The NPZ file must contain a 1D array 't' of shape (5001,) with the time points.
The NPZ file must contain a 2D array 'Y' of shape (5001, 2) with the state vectors.
The columns of the 'Y' array must be ordered as x, then y.
The NPZ file must also contain the scalar parameters alpha, beta, and delta.
Create a plot showing the evolution of x(t) and y(t) over time on a single set of axes.
Save the plot as a PNG file named "solution_molk_011.png".
The plot should contain two lines, one for x versus t and one for y versus t, with a legend.
Print a report to the console.
The report must include the final values of x and y at t=50.0.
The report must also include the minimum and maximum values of x and y over the entire simulation.
