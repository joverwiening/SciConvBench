The simulation will be implemented in FEniCS legacy (dolfin).
The problem is a 2D small-strain linear elasticity analysis using a plane-stress formulation.
The domain is a right triangle with vertices at (0,0), (1,0), and (0,0.5).
The material has a Young's modulus of 70e9 Pa, a Poisson's ratio of 0.33, and a density of 2700 kg/m^3.
A body force corresponding to gravity is applied, with the gravity vector g = (0, -9.81) m/s^2.
The sloping edge of the triangle, defined by x + 2y = 1, is clamped with a zero-displacement Dirichlet boundary condition.
The vertical edge, defined by x = 0, has a horizontal traction vector t = (4000, 0) Pa applied.
The horizontal edge, defined by y = 0, is a free surface with a zero-traction natural boundary condition.
The triangular mesh will be generated to have approximately 64 cells, using a mesh generator resolution parameter of 8.
The vector-valued displacement function space will use first-order Lagrange elements.
The resulting linear system will be solved using a direct solver.
The simulation will compute and output the displacement field and the von Mises stress distribution.
