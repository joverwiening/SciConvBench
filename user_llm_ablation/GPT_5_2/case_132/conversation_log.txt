Q: For the Rusanov flux calculation, should the states at a cell interface be taken directly from the adjacent cell-centered values, implying a first-order spatial reconstruction?
A: Yes. Use the adjacent cell-centered values directly as the left/right states at each interface (i.e., first-order piecewise-constant reconstruction) for the Rusanov flux.

Q: For the Rusanov flux wave speed `alpha`, should a constant value of 1.0 be used for all interfaces and all time steps?
A: No. Use `alpha = max(|sin(u)|)` computed from the current solution at each time step (a single global value applied to all interfaces for that step), not a constant 1.0—though it will always be ≤ 1.
