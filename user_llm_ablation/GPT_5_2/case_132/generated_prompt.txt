The PDE to be solved is u_t = -q1*∂_x( cos(u) ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
Use a uniform periodic grid with Nx=1024 points.
The grid points are x_j = j/Nx for j=0, ..., Nx-1, with grid spacing dx=1/Nx.
Discretize the PDE using the method of lines.
The convection term -q1*∂_x(cos(u)) is discretized using a conservative finite-volume scheme.
The convective flux at cell j is -(F_{j+1/2} - F_{j-1/2})/dx, where indices are modulo Nx.
The numerical flux F is the Rusanov flux, F(u_L, u_R) = 0.5*(cos(u_L) + cos(u_R)) - 0.5*alpha*(u_R - u_L).
The left and right states for the flux at interface j+1/2 are u_L = u_j and u_R = u_{j+1}.
The Rusanov wave speed alpha is recomputed at each time integration stage as the global maximum value of |sin(u)| over the current solution u.
The diffusion term (q2/pi)*u_xx is discretized using a second-order central difference: (q2/pi)*(u_{j+1} - 2*u_j + u_{j-1})/dx^2.
Integrate the resulting system of ODEs in time using the SSP-RK2 method.
The time step dt is constant for the entire simulation.
Calculate the advective time step constraint as dt_adv = 0.2*dx/1.0.
Calculate the diffusive time step constraint as dt_diff = 0.2*dx^2/(q2/pi).
Set a provisional time step dt_0 = min(dt_adv, dt_diff).
Set the number of steps Nt = ceil(0.5 / dt_0).
Set the final time step dt = 0.5 / Nt.
No closed-form reference solution is required for verification.
