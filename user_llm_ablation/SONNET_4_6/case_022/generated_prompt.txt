Calculate the lattice parameter 'a' for a metal.
The metal has a Face-Centered Cubic (FCC) crystal structure.
The number of atoms per unit cell (n) is 4.
The atomic weight (A) is 85.15 g/mol.
The theoretical density (ρ) is 13.931 g/cm^3.
Use Avogadro's number (N_A) as 6.022×10^23 mol^-1.
Use the formula a = ³√((n * A) / (ρ * N_A)).
Express the final lattice parameter in units of nanometers (nm).
