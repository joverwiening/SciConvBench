The PDE to solve is u_t = -1.0 * ∂_x(cos(u)) + (0.05/pi) * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 0.5].
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=1024 points.
The grid points are x_j = j/1024 for j=0, ..., 1023.
The grid spacing is dx = 1/1024.
The PDE is discretized in space using a finite volume approach on this grid.
The convection term -∂_x(cos(u)) is discretized using a Rusanov numerical flux.
The Rusanov flux at the interface between cell j and cell j+1 is F_{j+1/2} = 0.5 * (cos(u_j) + cos(u_{j+1})) - 0.5 * alpha * (u_{j+1} - u_j).
The wave speed alpha is the global maximum of |sin(u)| over all grid points at the current time.
The semi-discretization of the convection term at grid point j is -(F_{j+1/2} - F_{j-1/2}) / dx.
The diffusion term (0.05/pi)*u_xx is discretized using a second-order central difference: (0.05/pi) * (u_{j+1} - 2*u_j + u_{j-1}) / dx^2.
Time integration is performed using the second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step dt is constant for the entire simulation.
An advective time step limit is calculated as dt_adv = 0.2 * dx / 1.0.
A diffusive time step limit is calculated as dt_diff = 0.2 * dx^2 / (0.05/pi).
A provisional time step is set as dt_prov = min(dt_adv, dt_diff).
The total number of time steps is calculated as Nt = ceil(0.5 / dt_prov).
The final time step is dt = 0.5 / Nt.
The simulation is run for Nt steps.
