The simulation solves a 2D plane-stress linear elasticity problem using FEniCS legacy (dolfin).
The geometry is a rectangle defined by the domain (0, 1.0) x (0, 0.20) meters.
A uniform structured mesh of 40x8 quadrilateral elements is used.
The vector-valued displacement function space uses continuous Lagrange elements of polynomial degree 2.
The material has a Young's modulus of 200 GPa and a Poisson's ratio of 0.30.
The constitutive model is reduced plane-stress with unit thickness.
The left boundary at x=0 is fixed with zero displacement in both x and y directions.
The top boundary at y=0.20 is subjected to a uniform traction of (0, -2000) N/m.
The right boundary at x=1.0 and the bottom boundary at y=0 are traction-free.
The linear system is solved using a direct solver.
The y-component of the displacement field is saved as a color plot to the file q2_uy.png.
The full displacement vector field is saved to an XDMF file named q2_displacement.xdmf.
