The simulation domain is a 2D rectangle defined by the corners (0, 0) and (1.0, 0.2) meters.
The domain is meshed with a 50x25 structured grid of quadrilaterals.
The finite element space for the vector displacement field uses continuous, second-order Lagrange polynomials.
The physical model is linear elastic, orthotropic plane stress.
The material properties in the local orthotropic frame are E1=40 GPa, E2=10 GPa, G12=5 GPa, and nu12=0.25.
The local material frame is rotated 30 degrees counter-clockwise relative to the global coordinate system.
A Dirichlet boundary condition fixes the displacement to (0, 0) on the bottom boundary (y=0).
A Neumann boundary condition applies a uniform traction vector of (0, -10e6) Pascals to the top boundary (y=0.2).
The left (x=0) and right (x=1) boundaries are traction-free.
The resulting linear system of equations is solved using a direct LU decomposition solver.
A PNG image file named q8_ux.png is generated, showing a color plot of the x-component of displacement.
A PNG image file named q8_vm.png is generated, showing a color plot of the von Mises stress.
The full displacement vector field and the Cauchy stress tensor field are saved to a single XDMF file named q8_solution.xdmf.
