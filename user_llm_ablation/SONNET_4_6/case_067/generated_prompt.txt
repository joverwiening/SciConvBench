Solve the one-dimensional Cahn-Hilliard equation numerically.
The partial differential equation is u_t = -(0.01)^2*u_xxxx + ∂^2/∂x^2( u^3 - u ).
The spatial domain is x in [0,1) with periodic boundary conditions.
The time domain is t in [0, 0.05].
The initial condition is u(x,0) = 0.1*cos(2*pi*x) + 0.01*cos(6*pi*x).
Use a Fourier pseudo-spectral method for spatial discretization.
Discretize the spatial domain with Nx=512 equally spaced points.
The grid points are x_j = j/512 for j = 0, 1, ..., 511.
Use a time step of dt = 1e-5.
Integrate in time until T = 0.05.
Use the semi-implicit time-stepping scheme: û^{n+1} = (û^n + dt * 𝔽[∂xx(u^3)]) / (1 - dt*L(k)).
The linear operator in Fourier space is L(k) = -ε^2*k^4 + k^2, with ε = 0.01.
The nonlinear term ∂xx(u^3) is treated explicitly.
Apply 2/3 dealiasing to the u^3 term by zeroing out Fourier modes with wave numbers |k| greater than (2/3) of the maximum wave number on the grid.
Compute the solution u(x, T=0.05).
