Create a file named `membrane3.inp` in the working directory.
The content of `membrane3.inp` must be the exact text provided in the reference input deck.
The element type used in the simulation will be M3D8.
The load will be applied to node 1 in the z-direction (degree of freedom 3) with a magnitude of -0.001.
Run the CalculiX solver on the `membrane3.inp` file using the command `ccx -i membrane3` or `ccx membrane3`.
Determine the version of the CalculiX solver by running `ccx -v`.
Check the `membrane3.sta` file for a successful completion message to determine the run status.
Create a file named `results.json` in the working directory.
The `results.json` file must contain a JSON object with the following keys and values:
`solver`: "calculix"
`case_id`: "membrane3"
`status`: "success" if the run completed successfully, otherwise "error".
`ccx_version`: The version string obtained from the `ccx -v` command.
`artifacts`: An empty list `[]`.
`notes`: A string containing the exact `ccx` command used. If the run failed, this string must also include the error message and the name of the file that indicated the failure.
