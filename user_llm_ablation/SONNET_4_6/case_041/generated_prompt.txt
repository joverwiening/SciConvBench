The simulation is a 2D laminar, incompressible flow past a cylinder.
The goal is to observe the von Kármán vortex street at a Reynolds number of 100.
The domain is a rectangular channel 2.2m long and 0.41m high.
A cylinder with a diameter of 0.1m is centered at (0.2, 0.2) meters.
The kinematic viscosity is 1e-3 m²/s.
The mesh is one cell thick in the z-direction.
The solver is `pimpleFoam`.
The simulation starts at `startTime` 0 and ends at `endTime` 200 seconds.
The initial time step `deltaT` is 1 second.
The time step will be automatically adjusted to maintain a maximum Courant number of 0.9.
Simulation data is written every 10 seconds.
The inlet velocity `U` is a fixed uniform value of (1 0 0) m/s.
The outlet has a zero-gradient condition for velocity `U`.
The cylinder wall has a no-slip boundary condition for velocity `U`.
The top and bottom walls have a no-slip boundary condition for velocity `U`.
The front and back patches are of type `empty` for both pressure `p` and velocity `U`.
The inlet has a zero-gradient condition for pressure `p`.
The outlet pressure `p` is a fixed uniform value of 0.
The cylinder wall has a zero-gradient condition for pressure `p`.
The top and bottom walls have a zero-gradient condition for pressure `p`.
The time derivative is discretized using the `Euler` scheme.
Gradient terms are discretized using the `Gauss linear` scheme.
The velocity convection term is discretized using the `Gauss linearUpwindV grad(U)` scheme.
Laplacian terms are discretized using the `Gauss linear corrected` scheme.
The pressure equation is solved using the `PCG` linear solver with a `DIC` preconditioner, a tolerance of 1e-6, and a relative tolerance of 0.05.
The velocity equation is solved using the `PBiCGStab` linear solver with a `DILU` preconditioner, a tolerance of 1e-8, and a relative tolerance of 0.
The PIMPLE algorithm will use 2 pressure-velocity correctors.
The PIMPLE algorithm will use 0 non-orthogonal correctors.
A pressure reference is set in cell 0 with a value of 0.
