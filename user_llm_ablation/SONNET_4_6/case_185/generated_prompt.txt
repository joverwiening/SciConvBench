The PDE to be solved is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The spatial domain is discretized using a uniform periodic grid with Nx=512 points.
The spatial grid points are x_j = j/Nx for j=0,...,Nx-1.
The spatial step size is dx = 1/Nx.
The time domain is discretized with a fixed time step of dt=0.001.
The total number of time steps is Nt=1000.
The final time T is 1.0.
The numerical method is Strang splitting for each time step dt.
A full time step consists of three sequential operations.
First, solve the diffusion equation u_t = nu * u_xx for a half-step of dt/2 using a pseudo-spectral method.
The diffusion half-step is performed by transforming to Fourier space, multiplying the coefficients u_hat(k) by exp(-nu*k^2*(dt/2)), and transforming back.
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Second, solve the reaction equation du/dt = rho*u*(1-u) for a full-step of dt using its exact analytical solution.
The reaction step updates each grid point value u to (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, solve the diffusion equation u_t = nu * u_xx for another half-step of dt/2 using the same pseudo-spectral method.
