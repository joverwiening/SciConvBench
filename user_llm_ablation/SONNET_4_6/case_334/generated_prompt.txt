A single INCAR file will be used for the three geometry optimization steps.
The INCAR file will contain the following parameters: EDIFF = 1E-5, EDIFFG = -0.05, ENCUT = 450, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, LREAL = .FALSE., NSW = 200, POTIM = 0.2, and SIGMA = 0.2.
The first step is to optimize the CO molecule.
Create the INCAR file with the specified parameters in the root directory.
Run the command `python op.py CO POTCAR-CO POSCAR-CO`.
The second step is to optimize the clean Ir surface.
Run the command `python op.py surface POTCAR-Irface POSCAR-Irface`.
The third step is to optimize the CO-adsorbed Ir system.
Run the command `python op.py absorbed POTCAR-IrCO POSCAR-IrCO`.
The fourth step is to calculate the final adsorption energy.
Run the command `bash ./calc_absorption_energy.sh`.
The final output will be the adsorption energy value printed by the `calc_absorption_energy.sh` script.
