The PDE to be solved is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The final time T is 1.0.
The time step dt is determined by a CFL-based calculation.
First, an initial time step is calculated as dt0 = 0.4 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
The numerical method is Strang splitting for each time step dt.
The first sub-step is a diffusion step for a duration of dt/2, solved exactly in Fourier space.
The Fourier coefficients u_hat(k) are multiplied by exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The second sub-step is an advection step for the inviscid Burgers equation for a duration of dt.
The advection step is solved using a finite-volume method with a Rusanov (local Lax-Friedrichs) flux.
The flux between cells u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The flux function is f(u)=0.5*u^2.
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The cell update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The third sub-step is another diffusion step for a duration of dt/2, identical to the first.
The final solution u(x,T) at T=1.0 is computed.
An NPZ file named "solution_pdebench_burgers_nu1.npz" is saved.
The NPZ file contains the arrays x and u, and the scalars nu, T, dx, dt, Nx, Nt.
A PNG file named "solution_pdebench_burgers_nu1.png" is saved, showing a line plot of the final solution u versus x.
The minimum, maximum, mean, and discrete L2 norm of the final solution u are printed.
