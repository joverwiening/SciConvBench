The PDE to solve is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 4.0.
The boundary condition is periodic.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The numerical method is Strang splitting for each time step dt.
The first substep is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
The Fourier space update for the diffusion half-step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wave numbers for the Fourier transform are k = 2*pi*fftfreq(Nx, d=dx).
The second substep is an advection full-step of duration dt for the inviscid Burgers equation.
The advection step uses a finite-volume method with the Rusanov flux.
The Rusanov flux between states u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u)=0.5*u^2.
The wave speed for the Rusanov flux is alpha = max(abs(u_left), abs(u_right)).
The finite-volume update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of cell j.
The third substep is another diffusion half-step of duration dt/2, identical to the first substep.
The time step dt is determined by setting a CFL number of 0.4 with an estimated maximum speed of 1.0.
An initial time step is calculated as dt0 = 0.4 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0), where the final time T is 1.0.
The final time step used for the simulation is dt = T/Nt.
