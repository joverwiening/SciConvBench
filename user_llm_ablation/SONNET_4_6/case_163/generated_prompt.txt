The PDE to be solved is the 1D compressible Navier-Stokes system.
The conservative state vector is U = [rho, m, E], representing density, momentum, and total energy.
The primitive variables are density (rho), velocity (v), and pressure (p).
The momentum is defined as m = rho * v.
The total energy is defined as E = p/(Gamma-1) + 0.5 * rho * v^2.
The viscous stress is sigma = (zeta + 4/3 * eta) * v_x, where v_x is the velocity gradient.
The PDE system in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The simulation runs from t=0 to the final time T=0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions at x=-1 and x=1 are transmissive (outflow).
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho = 1.0, v = -0.75, and p = 1.0.
For x >= 0, the initial state is rho = 0.125, v = 0.0, and p = 0.1.
The simulation will use a uniform finite-volume grid with Nx=800 cells.
The cell width is dx = 2.0 / 800.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,799.
The conservative variables are evolved as cell-averaged quantities.
The pressure is recovered from the conservative variables using p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p fall below 1e-12 during the simulation, they must be clipped to 1e-12.
The convective part of the flux is calculated using the Rusanov (local Lax-Friedrichs) numerical flux.
The Rusanov flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The physical convective flux is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The interface wave speed is a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma*p/rho).
The velocity gradient v_x in each cell is computed with a centered difference using neighboring cell-centered velocity values.
The viscous stress sigma at cell interfaces is the arithmetic average of the sigma values from the two adjacent cells.
The viscous flux contribution is F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.
The total numerical flux at an interface is the sum of the Rusanov flux and the viscous flux.
Time integration is performed using the 2-stage SSP-RK2 (Heun's) method.
The time step dt is determined at each step by dt = min(dt_conv, dt_visc).
The convective time step limit is dt_conv = CFL * dx / max_j(|v_j| + c_j), with a CFL number of 0.9.
The viscous time step limit is dt_visc = 0.5 * dx^2 / (zeta + 4/3*eta).
The final time step is adjusted to end the simulation exactly at T=0.2.
Outflow boundary conditions are implemented using ghost cells where values are set equal to the nearest interior cell.
