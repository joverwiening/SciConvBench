The PDE to be solved is the 1D compressible Navier-Stokes system for density (rho), velocity (v), and pressure (p).
The conservative variables are U = [rho, m, E], where m = rho*v is momentum and E = p/(Gamma-1) + 0.5*rho*v^2 is total energy.
The flux is F(U) = [m, m^2/rho + p, (E+p)*v].
The viscous flux is F_v(U, U_x) = [0, sigma, v*sigma], where sigma = (zeta + 4/3*eta) * v_x.
The PDE is U_t + (F(U) - F_v(U, U_x))_x = 0.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.2].
The final time is T=0.2.
The parameter Gamma is 1.6666666666666667.
The parameter eta is 1e-08.
The parameter zeta is 1e-08.
Boundary conditions are transmissive (zero-gradient) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=0.445, v=0.698, p=3.528.
For x >= 0, the initial state is rho=0.5, v=0.0, p=0.571.
The simulation uses a cell-centered finite volume method with Nx=800 uniform cells.
The spatial step is dx = 2.0/800.
Cell centers are located at x_i = -1 + (i+0.5)*dx for i=0,...,799.
The time integration scheme is the 2-stage Strong Stability Preserving Runge-Kutta method (SSP-RK2).
The time step dt is calculated at each stage using a CFL number of 0.8.
The formula for the time step is dt = CFL * dx / max(|v| + c) over all cells, where c = sqrt(Gamma*p/rho) is the sound speed.
The convective fluxes at cell interfaces are calculated using the Rusanov (local Lax-Friedrichs) scheme.
The viscous terms are discretized by first computing v_x at cell centers using a second-order centered difference on v.
Ghost cells required for the centered difference are populated using the zero-gradient boundary condition.
The viscous stress sigma is then computed at cell centers.
The viscous stress and velocity at cell interfaces are computed by averaging the values from the two adjacent cell centers.
The total numerical flux at an interface is the sum of the Rusanov flux and the viscous flux F_visc = [0, -sigma, -v*sigma] evaluated with interface-averaged values.
The simulation runs until time t >= 0.2.
At the final time, compute rho, v, and p on the cell centers.
