Create an INCAR file for the initial and final state relaxations with the following parameters: EDIFFG=-0.05, ENCUT=450, NPAR=1, IBRION=1, ISIF=2, ISMEAR=1, ISPIN=1, POTIM=0.2, SIGMA=0.2, and NSW=200.
Run the initial state relaxation with the command: `python op.py IS POTCARagpd IS1POSCAR`.
Run the final state relaxation with the command: `python op.py FS POTCARagpd FS1POSCAR`.
Generate the intermediate images for the NEB path with the command: `python nebmake.py`.
Create an INCAR file for the NEB calculation with the following parameters: EDIFFG=-0.05, ENCUT=450, NPAR=1, IBRION=3, IMAGES=4, LCLIMB=.TRUE., IOPT=7, ISIF=2, ISMEAR=1, ISPIN=1, POTIM=0, SIGMA=0.2, SPRING=-5, and NSW=200.
Run the NEB calculation with the command: `python op2.py ./`.
Extract the final energy barrier with the command: `bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'`.
The final output is the reaction-barrier value produced by the extraction step.
