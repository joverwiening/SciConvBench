Create a Python script to calculate the lift coefficient for a NACA 4412 airfoil.
The calculation will use thin airfoil theory.
The angle of attack is fixed at 5 degrees.
The script will use the standard NACA 4-digit series equations to define the airfoil's camber line.
The numerical calculations will use 100 discretization points along the airfoil chord.
The final calculated lift coefficient will be printed to the standard output console.
