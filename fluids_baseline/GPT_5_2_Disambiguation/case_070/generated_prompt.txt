Compute the drag force acting on a sphere moving through glycerin.
Use a sphere diameter of 5 mm (radius 2.5 mm = 0.0025 m).
Use a sphere speed relative to the glycerin of 0.1 m/s.
Use glycerin dynamic viscosity of 1.5 Pa·s.
Use glycerin density of 1260 kg/m³.
Use a Reynolds-number-dependent drag coefficient model rather than pure Stokes drag.
Compute Reynolds number as Re = ρ v D / μ.
Use the Schiller–Naumann correlation explicitly: Cd = (24/Re) (1 + 0.15 Re^0.687), valid for Re ≲ 1000.
Compute drag force in newtons using Fd = 0.5 ρ v^2 Cd A with A = π D^2 / 4.
Use D = 0.005 m, ρ = 1260 kg/m³, v = 0.1 m/s, and Cd from Schiller–Naumann.
