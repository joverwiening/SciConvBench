Compute the Rayleigh number for natural convection from a vertical plate.
Use surface temperature Ts = 80°C.
Use ambient temperature T∞ = 20°C.
Use characteristic length L = 0.5 m.
Assume the fluid is air at 1 atm.
Use film temperature Tf = (Ts + T∞)/2 = 50°C = 323.15 K.
Use thermal expansion coefficient β = 1/Tf with Tf in Kelvin, so β = 1/323.15 K^-1.
Use gravitational acceleration g = 9.81 m/s^2.
Use temperature difference ΔT = Ts − T∞ = 60 K.
Use air properties at the film temperature: kinematic viscosity ν = 1.8×10^-5 m^2/s.
Use air properties at the film temperature: thermal diffusivity α = 2.6×10^-5 m^2/s.
Compute Ra using Ra = g β ΔT L^3 /(ν α).
Report Ra as a single dimensionless value with a reasonable rounding choice such as 3 significant figures.
