Compute the kinetic-energy correction factor α for fully developed laminar flow of water in a circular pipe with diameter D = 20 mm and mean velocity V̄ = 1.0 m/s.
Use the standard definition α = (1/(A V̄^3)) ∫_A v^3 dA.
Evaluate the integral using the fully developed laminar parabolic velocity profile v(r) = 2 V̄ (1 − (r/R)^2).
Report the resulting value of α, which should be α = 2.
