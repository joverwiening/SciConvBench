Determine the condenser-exit (condensate) state for a Rankine cycle.
Use saturated liquid at 10 kPa to define the condensate state.
Set P = 10 kPa.
Set T = Tsat(10 kPa) ≈ 45.8°C.
Use any standard IAPWS-consistent water/steam saturation table source (e.g., IAPWS-IF97 or NIST WebBook).
Read the saturated-liquid (“f”) properties at P = 10 kPa.
Report hf in kJ/kg.
Report vf in m³/kg.
Report sf in kJ/(kg·K).
Round hf, vf, and sf to 3 significant figures or match the table precision.
