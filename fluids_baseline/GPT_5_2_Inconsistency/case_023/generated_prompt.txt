Calculate the terminal velocity of a spherical raindrop falling through air.
Use diameter D = 2 mm.
Use water density ρ_w = 1000 kg/m³.
Use air density ρ_air = 1.2 kg/m³.
Use gravitational acceleration g = 9.81 m/s².
Assume quadratic aerodynamic drag with drag coefficient C_d = 0.5.
Include buoyancy by using weight minus buoyancy in the force balance.
Compute terminal velocity V_t from (\rho_w-\rho_air) g (π D^3 / 6) = (1/2) ρ_air V_t^2 C_d (π D^2 / 4).
No initial velocity is needed; if required, take v₀ = 0 m/s.
