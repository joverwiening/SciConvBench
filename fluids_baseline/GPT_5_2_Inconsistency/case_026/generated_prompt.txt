Compute the Reynolds number for water flowing in a full circular pipe with diameter D = 0.10 m and mean velocity V = 2.0 m/s.
Use water properties at 20°C with density ρ = 998 kg/m^3 and dynamic viscosity μ = 1.0×10^-3 Pa·s.
Use the standard hydraulic diameter definition Dh = 4A/P, which for a full circular pipe gives Dh = D = 0.10 m.
Compute Reynolds number using Re = (ρ V Dh) / μ.
Note that using Re = (V Dh) / ν is equivalent if ν = μ/ρ.
