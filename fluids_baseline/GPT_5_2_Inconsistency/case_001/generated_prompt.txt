Calculate the stagnation pressure for air flowing in a duct with velocity 250 m/s, static pressure 101.3 kPa, and static temperature 300 K.
Treat air as a compressible ideal gas with γ = 1.4 and R = 287 J/(kg·K).
Compute the speed of sound using a = √(γRT) at T = 300 K.
Compute Mach number as M = v/a.
Compute stagnation pressure using the isentropic relation P0/P = (1 + (γ−1)/2 · M^2)^(γ/(γ−1)).
If a reference static density is needed, compute it from ρ = P/(RT) using P = 101.3 kPa and T = 300 K.
Report the stagnation pressure P0 in kPa.
