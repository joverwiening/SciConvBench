Compute wall shear stress for steady flow of oil between parallel plates using τ = μ (du/dy).
Treat the problem as viscous Couette/Poiseuille flow (despite the word “inviscid”) so τ = μ (du/dy) is valid.
Use oil viscosity μ = 0.1 Pa·s.
Use plates located at y = 0 and y = h.
Use the standard Couette/Poiseuille velocity profile u(y) = U0 + ((U1 − U0)/h) y + (1/(2μ)) (dp/dx) (y^2 − h y).
Compute wall shear stress at both walls, reporting τw(0) and τw(h).
Use the wall gradients du/dy|y=0 = (U1 − U0)/h − (h/(2μ)) (dp/dx) and du/dy|y=h = (U1 − U0)/h + (h/(2μ)) (dp/dx).
If a default is needed, assume pure Couette flow with dp/dx = 0.
If defaults are needed, use U0 = 0 m/s, U1 = 1.0 m/s, and h = 1.0 mm = 1.0×10^-3 m.
Only if the intent is truly inviscid should wall shear stress be set to zero and μ treated as irrelevant.
