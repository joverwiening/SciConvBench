Assume a rectangular open-channel flow in SI units.
Use discharge per unit width q = 1.0 m^2/s.
Use gravitational acceleration g = 9.81 m/s^2.
Compute the critical depth using y_c = (q^2/g)^(1/3).
Report the critical depth in meters.
Round the reported critical depth to 3 significant figures.
The given Froude number Fr = 0.2 is provided as context for the given (subcritical) flow state and is not used in the y_c formula when q is specified.
