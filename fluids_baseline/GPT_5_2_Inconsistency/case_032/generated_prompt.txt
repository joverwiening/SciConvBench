Determine whether lumped-capacitance can be used for a cooling steel sphere in air using the solid Biot number criterion.
Use sphere radius R = 10 mm.
Use convection coefficient h = 80 W/m^2·K.
Use steel thermal conductivity k_steel = 45 W/m·K.
Do not perform any fluid temperature uniformity check.
Use the solid characteristic length for a sphere L_c = V/A = R/3.
Compute the Biot number as Bi = h(R/3)/k_steel.
Base the conclusion solely on the Biot number (no temperatures needed).
