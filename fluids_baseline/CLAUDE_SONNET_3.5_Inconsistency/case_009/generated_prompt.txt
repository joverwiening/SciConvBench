Calculate pressure at point B (pB) for an irrotational, steady, inviscid flow with these parameters:
Point A has pressure pA = 200 kPa, velocity VA = 5 m/s, elevation zA = 0 m
Point B has velocity VB = 8 m/s, elevation zB = 0 m
The fluid density is ρ = 1000 kg/m^3
The flow is irrotational, so the same Bernoulli constant applies between points A and B
Use the Bernoulli equation to solve for pB
