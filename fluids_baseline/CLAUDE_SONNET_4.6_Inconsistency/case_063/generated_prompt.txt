Use g = 9.81 m/s².

Calculate the velocity V from the Froude number relationship: Fr = V / sqrt(g * y), so V = Fr * sqrt(g * y) = 0.2 * sqrt(9.81 * y).
Calculate the discharge per unit width: q = V * y.
Find the critical depth using the formula: yc = (q² / g)^(1/3).
