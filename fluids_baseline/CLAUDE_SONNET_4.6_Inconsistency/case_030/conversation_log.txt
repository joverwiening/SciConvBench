Q: The formula you've written, c = sqrt(g * h), is the shallow-water wave speed approximation, but you've stated this is a deep-water wave. The correct deep-water dispersion relation is c = sqrt(g * λ / (2π)).

Which formula would you like me to use for the calculation: the deep-water formula c = sqrt(g λ / 2π), or the shallow-water formula c = sqrt(g h)?
A: Use the deep-water formula c = sqrt(g λ / (2π)).
