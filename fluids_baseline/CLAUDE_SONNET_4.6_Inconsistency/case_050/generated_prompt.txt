The user wants to compute the transient cooling curve of a solid sphere using the lumped-capacitance method.
The Biot number is Bi = hL/k = 0.05, which is less than 0.1, so the lumped-capacitance method is valid.
Use the lumped-capacitance method (not a spatially resolved model).
The characteristic length L is defined as V/A (volume divided by surface area), which for a solid sphere equals r/3 (one-third of the radius).
Produce the transient cooling curve, i.e., temperature as a function of time, using the standard lumped-capacitance exponential decay formula: (T - T_inf)/(T_i - T_inf) = exp(-t/tau), where tau = rho * V * c_p / (h * A).
