The flow field is steady, inviscid, and incompressible with density rho = 1000 kg/m³.
The flow is rotational (nonzero vorticity), but the problem instructs to apply the Bernoulli equation using the same constant between points A and B as if they share the same Bernoulli constant.
At point A: pA = 200 kPa, VA = 5 m/s, zA = 0 m.
At point B: VB = 8 m/s, zB = 0 m, pB is unknown.
Use the incompressible Bernoulli equation: pA + 0.5*rho*VA² + rho*g*zA = pB + 0.5*rho*VB² + rho*g*zB.
Since zA = zB = 0, the elevation terms cancel.
Calculate pB from the resulting equation.
