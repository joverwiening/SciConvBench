Solve the 1D Viscous Burgers equation with periodic boundary conditions using Strang splitting method.

Specific task details:
Solve the PDE u_t + ∂_x( 0.5*u^2 ) = nu * u_xx on domain x in [0, 1) with periodic boundaries.
Use nu = 0.2.
Initial condition: u(x,0) = sin(2*pi*x).
Solve from t=0 to t=1.0.

Numerical method specifications:
Use a uniform periodic grid with Nx=512 points.
Apply Strang splitting method with three substeps:
1. Diffusion half-step in Fourier space
2. Advection full-step using Rusanov (local Lax-Friedrichs) flux
3. Diffusion half-step in Fourier space

Time-stepping:
Use CFL=0.4 with estimated max speed of 1.0.
Compute dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and adjust dt to hit final time exactly.

Output requirements:
Compute solution at T=1.0.
Save solution to "solution_pdebench_burgers_nu0p2.npz".
