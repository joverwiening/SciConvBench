Solve the ordinary differential equation du/dt = a*sin(exp(-0.5*t)*sin(3*t)) + b*u.
The time domain is t in [0.0, 5.0].
The parameter a is 1.0.
The parameter b is -0.3.
The initial condition is u(0.0) = 0.2.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step dt of 0.001 for Nt=5000 steps.
Compute the solution u(t) at all time points t_n = 0.0 + n*dt for n=0 to 5000.
Save a file named "solution_molk_003.npz".
The NPZ file must contain a 1D array 't' of length 5001 for the time points.
The NPZ file must contain a 1D array 'u' of length 5001 for the solution u(t).
The NPZ file must contain the scalar parameters a and b.
Save a line plot of u(t) versus t as "solution_molk_003.png".

Print the minimum value of u over the time grid.
