Solve the 1D compressible Navier-Stokes equations for density (rho), velocity (v), and pressure (p).
The conservative state variables are rho, momentum (m = rho*v), and total energy (E = p/(Gamma-1) + 0.5*rho*v^2).
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The governing equations in conservative form are:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho = 0.445, v = 0.698, and p = 3.528.
For x >= 0, the initial state is rho = 0.5, v = 0.0, and p = 0.571.
The boundary conditions at x=-1 and x=1 are transmissive (zero-gradient outflow).
Implement the zero-gradient boundary conditions by setting the state in the ghost cells equal to the state in the adjacent interior cell.
Use a cell-centered finite volume method.
The spatial domain is discretized with Nx=800 uniform cells.
The convective terms are discretized using the Rusanov (local Lax-Friedrichs) numerical flux.
The Rusanov flux formula is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c is the sound speed.
The velocity gradient v_x at cell centers is computed using a centered difference on the cell-centered velocity values.
The viscous stress sigma at cell interfaces is computed by averaging the sigma values from the two neighboring cell centers.
The velocity v at cell interfaces, for the viscous flux term v*sigma, is computed by averaging the velocity from the two neighboring cell centers.
The time integration is performed using the 2-stage Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step is determined by a CFL condition with a CFL number of 0.5.
The final time is T=0.2.
Compute the solution rho(x,T), v(x,T), and p(x,T) on the cell centers at the final time.
Save the solution to a file named "solution_pdebench_cns1d_sod6_eta1em8_outflow.npz".
The NPZ file must contain the 1D arrays x, rho, v, p.
The NPZ file must also contain the scalars Gamma, eta, zeta, T, dx, and CFL.
Create a 3-panel plot of rho, v, and p versus x at the final time.
Save the plot as "solution_pdebench_cns1d_sod6_eta1em8_outflow.png".
Print the minimum and maximum values of rho and p at the final time.
Print the mean value of rho over the domain at the final time.
