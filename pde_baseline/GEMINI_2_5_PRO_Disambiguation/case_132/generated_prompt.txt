Solve the partial differential equation u_t = -q1*∂_x( cos(u) ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=1024 points, dx=1/Nx, and x_j = j*dx for j=0,...,Nx-1.
Discretize the convection term ∂_x(cos(u)) using a conservative finite-volume method.
The numerical flux at the interface x_{j+1/2} between cells j and j+1 is the Rusanov flux, using the left state u_j and the right state u_{j+1}.
The wave speed alpha for the Rusanov flux is max|sin(u)| calculated over the entire spatial grid.
The wave speed alpha is re-evaluated at the beginning of each time step and this value is used for all stages of the time integrator within that step.
Discretize the diffusion term u_xx using a second-order central difference scheme.
Integrate in time using the SSP-RK2 method, defined by u_1 = u^n + dt * L(u^n) and u^{n+1} = 0.5*u^n + 0.5*(u_1 + dt * L(u_1)), where L(u) is the spatial discretization of the PDE's right-hand side.
The time step dt is constant for the entire simulation.
The advective time step limit is dt_adv = 0.2 * dx / 1.0.
The diffusive time step limit is dt_diff = 0.2 * dx^2 / (q2/pi).
The time step dt is first calculated as the minimum of dt_adv and dt_diff.
The number of time steps Nt is ceil(T/dt), where T=0.5.
The final time step used is dt = T/Nt to ensure the simulation ends exactly at T=0.5.
