Solve the Van der Pol oscillator system of ordinary differential equations.
The system is defined as dx/dt = y and dy/dt = mu*(1 - x**2)*y - x.
The independent variable is t, and the dependent variables are x(t) and y(t).
The time domain for the simulation is the closed interval [0.0, 20.0].
The parameter mu is equal to 2.0.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 0.0.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt = 0.01.
Perform a total of Nt = 2000 time steps.
Compute the state vector [x, y] at all time points t_n = 0.0 + n*dt for n from 0 to 2000.
Save the results to a file named "solution_molk_007.npz".
The NPZ file must contain a 1D array 't' of time points of length 2001.
The NPZ file must contain a 2D array 'Y' of shape [2001, 2] with the state vector history, with columns ordered as [x, y].
The NPZ file must also contain the scalar parameter 'mu'.
Create a line plot showing x(t) versus t and y(t) versus t.
Save the plot as a PNG file named "solution_molk_007.png".
Print the final state values x(20.0) and y(20.0) to the console.
Print the minimum and maximum values of x(t) over the entire simulation to the console.
Print the minimum and maximum values of y(t) over the entire simulation to the console.
