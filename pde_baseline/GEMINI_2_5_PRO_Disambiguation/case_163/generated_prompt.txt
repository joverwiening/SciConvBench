Solve the 1D compressible Navier-Stokes equations for the unknown fields rho(x,t), v(x,t), and p(x,t).
The conservative variables are rho, m = rho*v, and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time is T=0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
Use transmissive (zero-gradient) outflow boundary conditions at x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=-0.75, p=1.0.
For x >= 0, the initial state is rho=0.125, v=0.0, p=0.1.
Use a uniform finite-volume grid with 800 cells.
The cell width is dx = 2.0 / 800.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,799.
Evolve the cell averages of the conservative variables U = [rho, m, E].
Use the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p fall below 1e-12, clip them to 1e-12.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective part.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], with v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The Rusanov flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x at cell centers using a centered difference.
Compute the viscous stress sigma at cell centers.
Approximate sigma at cell interfaces by averaging the values from the two adjacent cells.
The viscous flux vector is F_visc = [ 0, -sigma, -v*sigma ], using interface-averaged v and sigma.
The total numerical flux at an interface is the sum of the Rusanov flux and the viscous flux.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The time step dt is the minimum of the convective and viscous time step limits.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
Use a CFL number of 0.8.
Adjust the final time step to land exactly at T=0.2.
Implement the outflow boundary conditions by setting the values in the ghost cells equal to the values in the nearest interior cells.
Compute the solution rho(x,T), v(x,T), p(x,T) at the cell centers at T=0.2.
Save the results to a file named "solution_pdebench_cns1d_sod4_eta1em8_outflow.npz".
The npz file must contain the 1D arrays x, rho, v, p.
The npz file must also contain the scalars Gamma, eta, zeta, T, dx, and CFL.
Save a plot of rho, v, and p versus x at T=0.2 to a file named "solution_pdebench_cns1d_sod4_eta1em8_outflow.png".
The plot should contain three panels, one for each variable.
