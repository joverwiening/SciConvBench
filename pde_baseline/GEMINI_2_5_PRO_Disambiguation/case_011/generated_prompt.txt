Solve the Allen-Cahn partial differential equation.
The equation is u_t = (0.02)^2 * (u_xx + u_yy) + u - u^3.
The domain is x in [0,1], y in [0,1], and t in [0,0.1].
The parameter epsilon is 0.02.
The initial condition is u(x,y,0) = tanh((0.25 - r) / (sqrt(2) * 0.02)), where r = sqrt((x-0.5)^2 + (y-0.5)^2).
The spatial domain is discretized on a uniform grid with Nx = 300 intervals in x and Ny = 300 intervals in y.
The spatial discretization uses a 5-point finite difference stencil for the Laplacian.
The time step is dt = 0.0001.
The time integration scheme is semi-implicit: (u^{n+1}-u^n)/dt = (0.02)^2*Δu^{n+1} + u^n - (u^n)^3.
A standard, best-practice method should be used to solve the sparse linear system at each time step.
Dirichlet boundary conditions are u=0 on all boundaries for t > 0.
The boundary conditions are enforced by setting the boundary node values to zero at each time step.
Compute the solution u(x,y,t) up to the final time T=0.1.
Save the numerical solution to a file named "solution_agent_allen_cahn_05.npz".
The npz file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u at the final time.
The shape of the solution array u should be (len(y), len(x)).
The npz file must also contain the metadata scalars T, dx, dy, and dt.
