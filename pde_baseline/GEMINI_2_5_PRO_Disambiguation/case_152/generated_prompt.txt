Solve the 1D viscous Burgers' equation: u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1).
The final time is T = 1.0.
The viscosity parameter is nu = 0.002.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points.
The numerical method is Strang splitting for each time step.
The first substep is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
The second substep is an advection full-step of duration dt, solving the inviscid Burgers' equation using a finite-volume method with Rusanov flux.
The third substep is a diffusion half-step of duration dt/2, identical to the first substep.
The time step dt is determined by a CFL number of 0.4, an estimated maximum speed of 1.0, and the requirement to reach the final time T exactly.
Compute the solution u(x,T) at the final time.
Save the output to a file named "solution_pdebench_burgers_nu2em3.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'nu', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_burgers_nu2em3.png".
The plot title should be "Solution of 1D Burgers Equation at T=1.0".
The plot x-axis should be labeled "x".
The plot y-axis should be labeled "u(x,T)".
