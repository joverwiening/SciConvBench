Solve the partial differential equation u_tt = (1.0)^2 * u_xx.

The time domain for t is [0, 1.0].

The initial condition for the field is u(x,0) = cos(2*pi*x).
The initial condition for the time derivative of the field is u_t(x,0) = 0.
The exact solution for verification is u(x,t) = cos(2*pi*x)*cos(2*pi*1.0*t).
Use a uniform periodic grid with Nx=512 points for the spatial domain [0,1).
The spatial step dx is 1/Nx.

Initialize the time integration using a Taylor start with the periodic Laplacian.
The final time T is 1.0.
Set an initial time step dt0 = 0.9*dx/c.
Calculate the number of time steps Nt = ceil(T/dt0).
Set the final time step dt = T/Nt.
Compute the numerical solution u(x,t) at the final time T=1.0.
