Solve the 1D Compressible Navier-Stokes PDE without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The conservative variables are rho, m = rho*v, and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.2], so the final time T is 0.2.
The parameter Gamma is 1.6666666666666667.
The parameter eta is 1e-08.
The parameter zeta is equal to eta, so zeta is 1e-08.
The boundary conditions are transmissive (outflow) at x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho_L = 1.0, v_L = 0.0, p_L = 1.0.
For x >= 0, the initial state is rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Use a uniform finite-volume grid with 800 cells (Nx=800).
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The cell width is dx = 2.0/Nx.
Evolve the cell averages of the conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if they fall below it.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective part.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x using a centered difference on cell-centered velocity values.
Approximate the viscous stress sigma at interfaces by averaging the sigma values from neighboring cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.
The total interface flux is the sum of the convective and viscous fluxes, F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The time step dt is determined at each step by the minimum of a convective and a viscous constraint.
The convective time step constraint is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step constraint is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The CFL number is 0.8.
The final time step should be adjusted to land exactly at the final time T=0.2.
Implement the outflow boundary conditions by setting ghost cell values equal to the nearest interior cell (zero-gradient).
Compute the solution rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T=0.2.

The NPZ file must also contain the scalars Gamma, eta, zeta, T, dx, and CFL.
