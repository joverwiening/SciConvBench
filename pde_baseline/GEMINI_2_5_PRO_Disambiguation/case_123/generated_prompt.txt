Solve the partial differential equation u_t = q1*u_xx + q2*(u**a)*(1-u).

The time domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 2.0.
The parameter a is 2.0.
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
Use a spatial grid with Nx = 512 points.
Discretize the u_xx term using a second-order central difference scheme.
Use the explicit fourth-order Runge-Kutta (RK4) method for time integration.
Use a time step of dt = 0.0005.
Compute the solution u(x,t) at the final time T = 1.0.
Save the solution to a file named "solution_molk_022.npz".
The NPZ file must contain the 1D arrays x and u, and the scalars T, dx, Nx, q1, q2, and a.
Save a line plot of the final solution u(x, T=1.0) versus x to a file named "solution_molk_022.png".
Print the minimum, maximum, and mean values of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
