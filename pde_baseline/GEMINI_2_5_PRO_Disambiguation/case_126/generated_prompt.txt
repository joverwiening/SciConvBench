Solve the partial differential equation u_t = -k*∂_x( 0.5*u^2 ).
The spatial domain is the periodic interval x in [0, 1).
The time domain is t in [0, 0.2].
The parameter k is 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=1024 cells.
The grid spacing is dx = 1/1024.
The cell centers are located at x_j = (j+0.5)*dx for j=0,...,Nx-1.
Discretize the PDE using a conservative finite-volume method.
Set the initial value in each cell j to the value of the initial condition function at the cell's center, u_j(t=0) = sin(2*pi*x_j).
Use the Rusanov (local Lax-Friedrichs) flux to compute the flux at cell interfaces.
The physical flux function is f(u) = 0.5*u^2.
The local wave speed at the interface between cells j and j+1 is s_{j+1/2} = max(|u_j|, |u_{j+1}|).
Integrate in time using the two-stage Strong Stability Preserving Runge-Kutta method (SSP-RK2).
Use a fixed time step, dt, for the entire simulation.
To calculate dt, first define a preliminary time step dt0 = 0.2 * dx / 1.0, based on a CFL of 0.2 and an estimated maximum wave speed of 1.0.
The total number of time steps is Nt = ceil(0.2 / dt0).
The final time step is dt = 0.2 / Nt.
Run the simulation until the final time T=0.2.
