Solve the 1D Compressible Navier-Stokes equations without heat conduction.
The unknown fields are density rho(x,t), velocity v(x,t), and pressure p(x,t).
The conservative form of the PDE is used.
The momentum is m = rho*v.
The total energy is E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system is rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, and E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions are transmissive (zero-gradient) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=0.0, p=2.0.
For x >= 0, the initial state is rho=0.125, v=0.0, p=0.2.
Use a finite-volume method on a uniform grid with Nx=800 cells.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective terms.
For the viscous terms, compute the velocity gradient v_x with a centered difference.
The viscous stress sigma at cell interfaces is calculated by averaging the sigma values from the two adjacent cells.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
Use a reasonable CFL number based on best practices to determine the time step size.
Compute the solution rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T=0.2.
Save the solution to a file named "solution_pdebench_cns1d_sod5_eta1em8_outflow.npz".
The NPZ file must contain the 1D arrays x, rho, v, and p.
The NPZ file must also contain the scalars Gamma, eta, zeta, T, dx, and the chosen CFL number.
Save a 3-panel line plot of rho, v, and p versus x at T=0.2 to a file named "solution_pdebench_cns1d_sod5_eta1em8_outflow.png".
Print the minimum and maximum values of the final density and pressure fields.
