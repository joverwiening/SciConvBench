Solve the partial differential equation u_tt = q*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter q is 1.0.
The initial condition for u is u(x,0) = sin(2*pi*x).
The initial condition for the time derivative of u is u_t(x,0) = 0.
Use a spatial grid with Nx = 256 points.
Discretize the spatial derivative u_xx using second-order central differences.
Integrate in time using the fourth-order Runge-Kutta (RK4) method on the equivalent first-order system.
Use a time step of dt = 0.0005.
Compute the solution u(x,t) up to the final time T = 1.0.
Save the final solution to a file named "solution_molk_019.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalars 'T', 'dx', 'Nx', and 'q'.
Save a line plot of the final solution u(x, T=1.0) versus x to a file named "solution_molk_019.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u(x, T=1.0).
The exact solution for verification is u(x,t) = cos(2*pi*sqrt(q)*t) * sin(2*pi*x).
