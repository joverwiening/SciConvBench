Solve the FitzHugh-Nagumo ODE system numerically.
The system of equations is dv/dt = v - (v**3)/3 - w + I.
The second equation is dw/dt = (1/tau)*(v + a - b*w).
The unknown functions to solve for are v(t) and w(t).
The time domain is from t=0.0 to t=200.0.
The parameter I is 0.5.
The parameter a is 0.7.
The parameter b is 0.8.
The parameter tau is 12.5.
The initial value for v at t=0 is -1.0.
The initial value for w at t=0 is 1.0.
Use the classical 4th-order Runge-Kutta method for time integration.
Use a fixed time step of dt=0.05 for a total of 4000 steps.
Compute the full state vector [v, w] at all 4001 time points.
Save the results to a file named "solution_molk_009.npz".
The NPZ file must contain a 1D array 't' of time points, a 2D array 'Y' with columns [v, w], and the scalar parameters I, a, b, and tau.
Create a line plot showing v(t) and w(t) versus t.
Save the plot as "solution_molk_009.png".
