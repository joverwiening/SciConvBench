Solve the PDE u_t = -q1*∂_x( sin(u) ) + (q2/pi)*u_xx.

The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The boundary condition is periodic: u(0,t)=u(1,t).
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=1024 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
Discretize the convection term ∂_x(sin(u)) using a conservative finite-volume method with Rusanov flux.
For the Rusanov flux, recompute the wave speed alpha at each time step as the maximum of |cos(u)| over the grid.
Discretize the diffusion term u_xx using second-order central differences.
Integrate in time using the SSP-RK2 method.
Calculate the time step dt based on a CFL of 0.2.
The advection time step limit is dt_adv = 0.2*dx/1.
The diffusion time step limit is dt_diff = 0.2*dx^2/(q2/pi).
Use a preliminary time step of dt_prelim = min(dt_adv, dt_diff).
The final time step dt is calculated by Nt=ceil(T/dt_prelim) and then dt=T/Nt, where T=0.5.
The final output should be the numerical solution u at the final time T=0.5.
Save the output to a file named "solution_molk_029.npz".
