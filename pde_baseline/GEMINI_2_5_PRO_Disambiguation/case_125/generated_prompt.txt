Solve the partial differential equation u_t = -q1*∂_x( 0.5*u^2 ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.1.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j/Nx for j=0,...,Nx-1.
Discretize the convective term using a conservative finite-volume method with the Rusanov numerical flux.
Discretize the diffusion term using a second-order central difference scheme.
Integrate in time using the SSP-RK2 (Heun) method.
Use a fixed time step dt calculated as follows:
First, calculate an initial time step dt0 = min(dt_conv, dt_diff).
The convective time step is dt_conv = 0.4 * dx / max|u(x,0)|, where dx=1/Nx and max|u(x,0)|=1.0.
The diffusive time step is dt_diff = 0.4 * dx^2 / (q2/pi).
The number of time steps is Nt = ceil(T/dt0), where the final time T is 0.5.
The final time step is dt = T/Nt.
Compute the solution u(x,t) at the final time T=0.5.
Save the final solution to a file named "solution_molk_024.npz".
The NPZ file must contain the x-coordinates, the final solution u, the final time T, dx, Nx, q1, and q2.
Use the keys 'x', 'u', 'T', 'dx', 'Nx', 'q1', and 'q2' in the NPZ file.
Create a line plot of the final solution u versus x.
Save the plot to a file named "solution_molk_024.png".
The plot should have a reasonable title.
The plot's x-axis should be labeled 'x'.
The plot's y-axis should be labeled 'u'.
Print the minimum of the final solution to the console.
Print the maximum of the final solution to the console.
Print the mean of the final solution to the console.
Print the discrete L2 norm of the final solution to the console.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
