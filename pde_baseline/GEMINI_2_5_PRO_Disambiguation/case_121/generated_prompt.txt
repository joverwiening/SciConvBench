Solve the PDE u_t = q1*u_xx + q2*u*(1-u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use 512 spatial grid points (Nx=512).
Discretize the spatial derivative u_xx using 2nd-order central differences.
Use the Strang splitting method for time integration.
For the splitting, solve the diffusion part using FFT and the reaction part using the exact solution for the logistic equation.
Use a time step size dt of 0.001.
Compute the solution u(x,t) at the final time T=1.0.
Save a file named "solution_molk_020.npz".
The NPZ file must contain the 1D arrays x and u, and the scalars T, dx, Nx, q1, and q2.
Save a line plot of the solution u(x,T) versus x to a file named "solution_molk_020.png".
Print the minimum, maximum, and mean of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
