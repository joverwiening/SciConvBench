Solve the partial differential equation u_t = -q1*∂_x( (1/3)*u^3 ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The problem is to be solved numerically.
Use a uniform periodic spatial grid with Nx=1024 points, where x_j = j/Nx for j=0,...,Nx-1.
The spatial discretization of the convective term -q1*∂_x( (1/3)*u^3 ) will be a conservative finite-volume scheme using the Rusanov flux.
The local wave speed for the Rusanov flux at the interface between u_i and u_{i+1} will be calculated as max(u_i^2, u_{i+1}^2).
The spatial discretization of the diffusive term (q2/pi)*u_xx will be a second-order central difference scheme.
Time integration will be performed using the SSP-RK2 method.
A single fixed time step dt will be used for the entire simulation.
The time step is determined by first calculating two stability-limited time steps, dt0 and dt_diff.
The convective time step limit is dt0 = CFL*dx/max|f'|, with CFL=0.2, dx=1/Nx, and max|f'| estimated from the initial condition as 0.25.
The diffusive time step limit is dt_diff = 0.2*dx^2/(q2/pi).
A preliminary time step is set as dt_prelim = min(dt0, dt_diff).
The number of time steps is Nt = ceil(0.5/dt_prelim).
The final time step used for the simulation is dt = 0.5/Nt.
No comparison with a closed-form reference solution is required.
