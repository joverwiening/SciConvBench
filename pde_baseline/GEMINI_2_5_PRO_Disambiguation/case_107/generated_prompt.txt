Solve a system of three ordinary differential equations for the state variables E(t), I(t), and H(t).
The ODE system is defined as:
dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t)
dI/dt = delta*E - epsilon*I
dH/dt = theta*I - phi*H
The time domain for the simulation is [0.0, 50.0].
The parameters for the model are: alpha = 1.2, beta = 1.0, gamma = 0.5, delta = 0.8, epsilon = 0.7, theta = 0.9, and phi = 0.4.
The initial conditions at t=0 are E(0) = 0.5, I(0) = 0.2, and H(0) = 0.1.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt = 0.01 for a total of Nt = 5000 steps.
Compute the full state vector [E, I, H] at all time points from t=0 to t=50.
Save the results to a file named "solution_molk_006.npz".
The NPZ file must contain a 1D array 't' of time points, a 2D array 'Y' of shape (5001, 3) containing the state vectors, and all the scalar parameters.
The columns of the 'Y' array must be ordered as [E, I, H].
Save a line plot of each state variable versus time to a file named "solution_molk_006.png".
Print the final state values E(50), I(50), and H(50).
Print the minimum and maximum value of each state variable over the entire simulation time.
All trigonometric functions should be evaluated using radians.
