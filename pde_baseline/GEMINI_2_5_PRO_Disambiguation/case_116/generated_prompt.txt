Solve the partial differential equation u_tt + q*sin(u) = u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
The parameter q is 1.0.
The initial condition for u is u(x,0) = 0.1*sin(2*pi*x).
The initial condition for the time derivative of u is u_t(x,0) = 0.
The number of spatial grid points is Nx = 512.
The number of time steps is Nt = 4000.
Use a 2nd-order central difference scheme for the spatial discretization of u_xx.
Use the 4th-order Runge-Kutta method for time integration on the system derived by setting v = u_t.
Compute the solution u(x,T) at the final time T=2.0.
Save the results to a file named "solution_molk_015.npz".
The npz file must contain the 1D arrays x and u, and the scalar values T, dx, Nx, and q.
Save a line plot of the final solution u(x,T) to a file named "solution_molk_015.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u(x,T).
