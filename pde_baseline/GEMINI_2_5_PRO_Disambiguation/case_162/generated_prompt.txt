Solve the 1D Compressible Navier-Stokes PDE without heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
The conservative variables are U = [rho, m, E], where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE in conservative form is:
rho_t + (m)_x = 0
m_t + (m^2/rho + p - sigma)_x = 0
E_t + ( (E+p)*v - v*sigma )_x = 0
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.2], so the final time is T=0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions are transmissive (zero-gradient) at x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho_L = 1.0, v_L = 0.75, p_L = 1.0.
For x >= 0, the initial state is rho_R = 0.125, v_R = 0.0, p_R = 0.1.
Use a uniform finite-volume grid with Nx=800 cells.
The cell width is dx = 2/Nx.
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
Evolve the cell averages of the conservative variables U = [rho, m, E].
Use the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor value of 1e-12 if they fall below it.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part of the equations.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], with v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x using a centered difference on the cell-centered velocity values.
Approximate the viscous stress sigma at cell interfaces by averaging the values from neighboring cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma], using interface-averaged v and sigma.
The total numerical flux at an interface is the sum of the convective and viscous fluxes.
Use the 2-stage SSP-RK2 method (Heun's method) for time integration.
The time step dt is the minimum of the convective and viscous time step limits.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
Use a CFL number of 0.9.
Adjust the final time step to end exactly at T=0.2.
Implement the outflow boundary conditions by setting ghost cell values equal to the nearest interior cell value.
Compute the solution rho(x,T), v(x,T), and p(x,T) on the cell centers at the final time.
