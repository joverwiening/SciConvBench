Solve the partial differential equation u_t = -k * ∂_x(cos(u)).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5 * sin(2*pi*x).
No closed-form reference solution is required for verification.
Use a uniform periodic spatial grid with Nx=1024 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
Discretize in space using a conservative finite-volume method with the Rusanov flux.
The flux function is f(u) = cos(u).
Use a constant wave speed of alpha=1.0 for the Rusanov flux.
Integrate in time using the second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step should be calculated based on a CFL number of 0.2.
First, calculate a preliminary time step dt0 = CFL * dx / 1.0.
Then, determine the number of time steps as Nt = ceil(T/dt0), where T is the final time 0.2.
The final time step used for integration is dt = T/Nt.
