Solve the partial differential equation u_t = -k*∂_x( sin(u) ).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter k is 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required for verification.
Use a uniform periodic spatial grid with Nx=1024 points.
The grid points are defined as x_j = j/Nx for j=0,...,Nx-1, where dx=1/Nx.
Use a conservative finite-volume Rusanov flux for the spatial discretization of f(u)=sin(u).
The wave speed alpha for the Rusanov flux should be set to the constant value of 1.0.
Use the SSP-RK2 method for time integration.
The time step should be determined by a CFL number of 0.2.
Calculate an initial time step dt0 = 0.2 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0), where T=0.2.
The final time step is dt = T/Nt.
Compute the solution u at the final time T=0.2.
Save the results to a file named "solution_molk_030.npz".
The file must contain the arrays x and u, and the scalars T, dx, Nx, and k.
Create a line plot of the final solution u(x,T) versus x.
The plot should have a title "Solution u(x,T) at T=0.2".
Save the plot as "solution_molk_030.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
