Solve the partial differential equation u_tt + (q**2)*u_xxxx + c*∂_x( u * u_x ) = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The parameter q is 0.05.
The parameter c is 1.0.
The initial condition for u is u(x,0) = 0.1*cos(2*pi*x).
The initial condition for the time derivative of u is u_t(x,0) = 0.
Use a Fourier spectral method for spatial derivatives.
Use the fourth-order Runge-Kutta (RK4) method for time integration.
The number of spatial grid points is Nx = 512.
The time step is dt = 0.0001.
Compute the solution u(x,t) at the final time T = 0.5.
Save the solution to a file named "solution_molk_016.npz".
The npz file must contain the 1D arrays x and u, and the scalars T, dx, Nx, q, and c.
Save a line plot of the final solution u(x, T=0.5) versus x to a file named "solution_molk_016.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
