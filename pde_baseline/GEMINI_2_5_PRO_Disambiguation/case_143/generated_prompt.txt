Solve the 1D viscous Burgers' equation: u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The viscosity parameter nu is 0.01.
The spatial domain for x is the periodic interval [0, 1).
The initial condition is u(x,0) = sin(2*pi*x).
The simulation runs up to the final time T = 1.0.
Use a uniform spatial grid with Nx = 512 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Use the Strang splitting method for time integration.
Each full time step dt consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
The diffusion step u_t = nu * u_xx is solved for a duration of dt/2 in Fourier space.
The Fourier space update for the diffusion step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The advection step u_t + ∂_x(0.5*u^2) = 0 is solved for a duration of dt using a finite-volume method with Rusanov flux.
The Rusanov flux between cells with values u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u) = 0.5*u^2 and alpha = max(abs(u_left), abs(u_right)).
The finite-volume update for a cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), using fluxes at the right and left interfaces respectively.
The time step dt is determined by a CFL number of 0.4, an estimated maximum speed of 1.0, and the final time T.
First, calculate a provisional time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T / dt0).
Finally, set the actual time step to dt = T / Nt.
After the simulation, save the results to a file named "solution_pdebench_burgers_nu0p01.npz".
The NPZ file must contain the 1D arrays x and the final solution u, and the scalar values nu, T, dx, dt, Nx, Nt.
Create a line plot of the final solution u versus x.
Save the plot as "solution_pdebench_burgers_nu0p01.png".
Print the minimum and maximum values of the final solution u.
Print the discrete mean value of the final solution u.
