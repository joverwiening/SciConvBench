Solve the 1D compressible Navier-Stokes equations.
The conservative form of the PDE is rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, and E_t + ( (E+p)*v - v*sigma )_x = 0.
The conserved variables are density (rho), momentum (m), and total energy (E).
The primitive variables are density (rho), velocity (v), and pressure (p).
The momentum is defined as m = rho*v.
The total energy is defined as E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions are transmissive (zero-gradient) at x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho=1.0, v=0.0, p=10.0.
For x >= 0, the initial state is rho=1.0, v=0.0, p=0.1.
The numerical method is a finite-volume method on a uniform grid with 800 cells.
The spatial reconstruction is first-order.
The convective flux is the Rusanov (local Lax-Friedrichs) numerical flux.
The velocity gradient v_x for the viscous terms is computed with a centered difference on cell-centered velocities.
The viscous stress sigma at cell interfaces is approximated by averaging values from neighboring cells.
The v*sigma term in the energy flux is calculated using interface-averaged values for both v and sigma.
The time integration scheme is the 2-stage SSP-RK2 (Heun's method).
The CFL number for determining the time step size is 0.8.
Compute the solution rho(x,T), v(x,T), p(x,T) on the cell centers at the final time T=0.2.
Save the solution to a file named "solution_pdebench_cns1d_sod7_eta1em8_outflow.npz".
The file must contain 1D arrays for x, rho, v, p.
The file must also contain the scalars Gamma, eta, zeta, T, dx, and CFL.
Save a plot of rho, v, and p versus x at the final time T=0.2.
The plot should be saved as "solution_pdebench_cns1d_sod7_eta1em8_outflow.png".
The plot should have 3 panels or be 3 separate plots.
Print the minimum and maximum values of rho and p at the final time.
