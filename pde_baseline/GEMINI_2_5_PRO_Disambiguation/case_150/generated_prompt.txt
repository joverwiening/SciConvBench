Solve the 1D viscous Burgers' equation: u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1).
The boundary conditions are periodic.
The viscosity parameter nu is 0.001.
The initial condition is u(x,0) = sin(2*pi*x).
The simulation runs until a final time T of 1.0.
Use a uniform spatial grid with Nx=512 points.
The numerical method is Strang splitting for each time step.
The first substep is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
The second substep is an advection full-step of duration dt for the inviscid Burgers' equation, solved using a finite-volume method with the Rusanov flux.
The third substep is another diffusion half-step of duration dt/2, identical to the first.
The time step dt is determined by a CFL condition.
First, calculate a provisional time step dt0 = 0.4 * dx / 1.0, where dx is the spatial grid spacing.
Then, calculate the number of time steps Nt = ceil(T/dt0).
Finally, set the actual time step dt = T/Nt.
Compute the solution u(x,T) on the grid at the final time.

The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'nu', 'T', 'dx', 'dt', 'Nx', 'Nt'.
