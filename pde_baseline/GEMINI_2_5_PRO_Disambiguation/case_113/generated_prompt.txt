Solve the partial differential equation u_t = c1 * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The parameter c1 is 0.2.
The initial condition is u(x,0) = sin(2*pi*x).
Use a spatial grid with Nx = 256 points.
Discretize the u_xx term using a 2nd-order central difference scheme on the periodic grid.
Integrate in time using the Crank-Nicolson method.
Use a time step of dt = 0.001.
Compute the solution u(x,t) up to the final time T = 0.5.
Save the results to a file named "solution_molk_012.npz".
The NPZ file must contain the 1D arrays x and u, and the scalar values T, dx, Nx, and c1.
Create a line plot of the final solution u(x, T=0.5) versus x.
Save the plot as "solution_molk_012.png".
At the final time T=0.5, print the minimum, maximum, and mean of the solution u.
At the final time T=0.5, print the discrete L2 norm of the solution, calculated as sqrt(sum(u^2)*dx).
The exact solution is u(x,t) = exp(-c1*(2*pi)^2*t) * sin(2*pi*x).
Evaluate the exact solution on the same spatial grid at the final time T=0.5.
Compute and print the maximum absolute error between the numerical and exact solutions.
Compute and print the L2 error between the numerical and exact solutions.
