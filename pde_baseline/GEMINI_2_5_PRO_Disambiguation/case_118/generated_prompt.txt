Solve the PDE u_t + (q**2)*u_xxx + u*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter q is 0.1.
The initial condition is u(x,0) = cos(2*pi*x).
Use a Fourier spectral method for the spatial derivatives.
Use the fourth-order Runge-Kutta (RK4) method for time integration.
Use Nx=512 grid points for the spatial discretization.
Use a time step of dt=0.0001.
Compute the solution u(x,T) at the final time T=0.2.
Save the results to a file named "solution_molk_017.npz".
The file must contain the 1D arrays x and u, and the scalars T, dx, Nx, and q.
Save a line plot of the final solution u(x,T) versus x as "solution_molk_017.png".
Print the minimum, maximum, mean, and discrete L2 norm of the solution u at the final time.
The discrete L2 norm is defined as sqrt(sum(u^2)*dx).
