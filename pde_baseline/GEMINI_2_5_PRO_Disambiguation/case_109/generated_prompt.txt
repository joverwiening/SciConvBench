Solve the Lotka-Volterra ODE system numerically.
The system of equations is dx/dt = alpha*x - beta*x*y and dy/dt = delta*x*y - gamma*y.
The unknown functions to solve for are x(t) and y(t).
The time domain is from t=0.0 to t=30.0.
The parameter alpha is 1.5.
The parameter beta is 1.0.
The parameter gamma is 3.0.
The parameter delta is 1.0.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 1.0.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt=0.01 for a total of 3000 steps.
Compute the full state vector [x(t), y(t)] at all time points from t=0 to t=30.0.
Save the results to a file named "solution_molk_008.npz".
The NPZ file must contain a 1D array 't' of time points, a 2D array 'Y' with shape [3001, 2] for the state variables, and the scalar parameters alpha, beta, gamma, and delta.
The columns of the 'Y' array should be ordered as [x, y].
Save a line plot of x(t) and y(t) versus time to a file named "solution_molk_008.png".
Print the final state values of x and y at t=30.0.
Print the minimum and maximum values of x(t) and y(t) over the entire time interval.
