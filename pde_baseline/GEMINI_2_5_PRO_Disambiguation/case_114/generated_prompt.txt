Solve the partial differential equation u_t = ∂_xx(u^m).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter m is 2.0.
The initial condition is u(x,0) = 0.5 + 0.2*cos(2*pi*x).
Use a spatial grid with Nx = 256 points.
Use the method of lines for the numerical solution.
Discretize the spatial term ∂_xx(u^m) by first computing w = u^m on the grid, and then approximating ∂_xx(w) using a second-order central finite difference scheme.
Use the explicit fourth-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt = 0.0001.
Compute the solution u(x,T) at the final time T = 0.2.
Save the solution to a file named "solution_molk_013.npz".
The NPZ file must contain the 1D arrays for the grid points 'x' and the solution 'u', and the scalar values for the final time 'T', the spatial step 'dx', the number of grid points 'Nx', and the parameter 'm'.
Create a line plot of the solution u(x,T) versus x at the final time.
Save the plot as "solution_molk_013.png".
