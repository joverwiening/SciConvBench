Solve the partial differential equation u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u ).
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The diffusion coefficient D is 0.01.
The parameter gamma is 1.0.
The potential function is U(x) = cos(2*pi*x).
The derivative of the potential is U'(x) = -2*pi*sin(2*pi*x).
The initial condition is u(x,0) = 1.0 + 0.2*sin(2*pi*x).
The numerical solution should be computed on a uniform periodic grid with Nx=512 points.
The grid spacing is dx=1/Nx and grid points are x_j = j*dx for j=0,...,Nx-1.
The PDE should be treated in conservative form u_t = D*u_xx - ∂_x(F), where the flux is F = (1/gamma)*U'(x)*u.
The diffusion term D*u_xx should be discretized using a second-order central difference scheme.
The advection term -∂_x(F) should be discretized using an upwind finite-volume method.
The velocity at a cell interface x_{j+1/2} is b_{j+1/2} = U'(x_{j+1/2})/gamma.
The upwind flux at the interface x_{j+1/2} is based on the sign of the interface velocity b_{j+1/2}.
The time integration should be performed using the explicit SSP-RK2 method.
The time step dt is determined by the stability criteria.
First, calculate a provisional time step dt_prov = min(0.4*dx/max|b|, 0.2*dx^2/D), where b(x)=U'(x)/gamma.
Then, the number of time steps is Nt = ceil(T/dt_prov), where T=1.0 is the final time.
The final time step used for integration is dt = T/Nt.
No closed-form reference solution is required for verification.
