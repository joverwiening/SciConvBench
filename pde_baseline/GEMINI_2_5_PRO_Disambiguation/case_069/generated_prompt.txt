Solve the Kuramoto-Sivashinsky PDE `u_t + u*u_x + u_xx + u_xxxx = 0`.
The spatial domain is `x` in `[0, 2*pi)` with periodic boundary conditions.
The time domain is `t` in `[0, 1.0]`.
The initial condition is `u(x, 0) = cos(x) + 0.1*cos(2*x)`.
Use a spatial grid with `Nx = 1024` points.
Use a time step of `dt = 1e-4`.
Use a Fourier pseudo-spectral method for spatial derivatives.
Use a semi-implicit time integration scheme in Fourier space.
The update formula for each Fourier mode `k` is `û^{n+1} = (û^n - dt * 𝔽[u*u_x]) / (1 - dt*(-k^2 + k^4))`.
Compute the solution `u(x, T)` at the final time `T = 1.0`.
Save the results to a file named "solution_agent_other_04_kuramoto_sivashinsky.npz".
The NPZ file must contain the 1D arrays `x` and `u`, and the scalars `T`, `dx`, and `dt`.
