Solve the PDE u_t = q1*u_xx + q2*u.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
The parameter q1 is 0.01.
The parameter q2 is -1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The number of spatial grid points is Nx=256.
The spatial discretization for the u_xx term is a 2nd-order central difference scheme.
The time integration method is an operator-splitting method with a time step of dt=0.001.
The first step of the operator splitting is a Crank-Nicolson step for the diffusion term: (I - 0.5*dt*q1*L) u_tilde^{n+1} = (I + 0.5*dt*q1*L) u^n, where L is the periodic 2nd-order Laplacian.
The second step of the operator splitting is an exact integration for the reaction term: u^{n+1} = exp(q2*dt) * u_tilde^{n+1}.
Compute the numerical solution u(x,T) at the final time T=0.5.
Save the solution to a file named "solution_molk_021.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalars 'T', 'dx', 'Nx', 'q1', and 'q2'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_molk_021.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u(x,T).
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
The exact solution for verification is u(x,t) = exp(q2*t) * exp(-q1*(2*pi)^2*t) * sin(2*pi*x).
Compute and print the maximum absolute error and the L2 error between the numerical solution and the exact solution at the final time T.
