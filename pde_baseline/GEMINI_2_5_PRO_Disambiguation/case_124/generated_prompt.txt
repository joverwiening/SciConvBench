Solve the partial differential equation u_t = q1*u_xx + q2*(u**2)*(1-u)**2.

The time domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 2.0.
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
Use a spatial grid with Nx = 512 points.
Discretize the u_xx term using second-order central differences.
Use the explicit fourth-order Runge-Kutta (RK4) method for time integration.
Use a time step of dt = 0.0005.
Compute the solution u(x,t) at the final time T = 1.0.
Save the solution to a file named "solution_molk_023.npz".
The NPZ file must contain the 1D arrays x and u, and the scalar values T, dx, Nx, q1, and q2.
Create a line plot of the final solution u(x, T=1.0) versus x.
Save the plot as "solution_molk_023.png".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u(x, T=1.0).
The L2 norm is defined as sqrt(sum(u^2)*dx).
