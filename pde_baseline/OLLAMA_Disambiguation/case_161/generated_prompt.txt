Use Nx = 800 uniform cells on the spatial domain [-1, 1] with cell centers x_j = -1 + (j+0.5)·dx for j = 0,…,799 and dx = (1 - (-1))/800 = 0.0025.  
Set the final simulation time T = 0.2.  
Use the adiabatic index Gamma = 1.6666666666666667, dynamic viscosity eta = 1e-8, and bulk viscosity zeta = eta.  
Apply transmissive/outflow (zero‑gradient) boundary conditions at x = -1 and x = 1 by copying the nearest interior cell values into ghost cells.  
Initialize the conserved variables with a Riemann shock‑tube condition at x = 0: for x < 0 set rho = 1.0, v = 0.0, p = 1.0; for x ≥ 0 set rho = 0.1, v = 0.0, p = 0.1, and compute momentum m = rho·v and total energy E = p/(Gamma‑1) + 0.5·rho·v².  
Evolve the cell‑averaged conservative variables U = [rho, m, E] using a uniform finite‑volume discretization.  
Compute the convective flux with the Rusanov (local Lax‑Friedrichs) numerical flux:  
F_conv(U) = [m, m²/rho + p, (E + p)·v] with v = m/rho;  
at each interface use wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = √(Gamma·p/rho).  
Compute viscous terms by centered differences of the cell‑centered velocity to obtain v_x, then sigma = (zeta + 4/3·eta)·v_x; average sigma to interfaces and form viscous flux F_visc = [0, ‑sigma, ‑v·sigma] using interface‑averaged v and sigma.  
The total interface flux is F_total = F_hat + F_visc, where F_hat is the Rusanov convective flux.  
Integrate in time with the 2‑stage SSP‑RK2 (Heun’s) method.  
At each stage choose the time step dt as the minimum of the convective and viscous limits:  
dt_conv = CFL·dx / max_j(|v_j| + c_j) with CFL = 0.5;  
dt_visc = 0.5·dx² / max(zeta + 4/3·eta, 1e‑30);  
set dt = min(dt_conv, dt_visc) and reduce the final step so that the simulation ends exactly at T.  
Enforce positivity of density and pressure by clipping rho and p to a floor of 1e‑12 after each update.  
After reaching T, compute primitive variables rho, v = m/rho, and p = (Gamma‑1)·(E ‑ 0.5·m²/rho) at the cell centers.
