Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx with nu = 0.01 on the half‑open periodic domain [0,1) using a uniform grid of Nx = 512 points, dx = (1-0)/512, and grid points x_i = i*dx for i = 0,…,511.  
Use the initial condition u(x,0) = sin(2*pi*x).  
Apply periodic boundary conditions u(0,t) = u(1,t).  
Use Strang splitting with diffusion half‑steps solved exactly in Fourier space and a full advection step using a finite‑volume Rusanov flux.  
Compute the diffusion factor exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx).  
For each advection interface compute flux F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left) with f(u)=0.5*u^2 and alpha = max(|u_left|,|u_right|).  
Update each cell: u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).  
Determine the time step dt from CFL = 0.4 using estimated max speed 1: dt0 = 0.4*dx/1.0, set Nt = ceil(T/dt0), then dt = T/Nt to hit the final time exactly.  
Simulate until final time T = 1.0 with Nt time steps.  
At final time compute and save arrays x and u, and scalars nu, T, dx, dt, Nx, Nt in a file named solution_pdebench_burgers_nu0p01.npz in the current working directory.  
Also save a line plot of u(x,T) as solution_pdebench_burgers_nu0p01.png in the current working directory.  
Print the minimum value of u, the maximum value of u, the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at final time.
