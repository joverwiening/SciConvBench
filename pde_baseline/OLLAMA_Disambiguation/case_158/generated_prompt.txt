Use Nx = 400 uniform cells on the domain [-1, 1].  
Set the CFL number for the time step calculation to approximately 0.5.  
Domain: x in [-1, 1], t in [0, 0.5].  
Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = eta = 1e-08.  
Boundary conditions: periodic at x = -1 and x = 1.  
Initial conditions (pointwise on the grid): rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).  
Grid: uniform finite-volume grid with cell centers x_j = -1 + (j+0.5)*dx for j = 0,...,399, where dx = (1 - (-1))/400 = 0.005.  
Evolve conservative variables U = [rho, m, E] as cell averages, where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.  
Equation of state: p = (Gamma-1) * (E - 0.5*m^2/rho). Clip rho and p to a floor of 1e-12 if needed.  
Convective flux: F_conv(U) = [m, m^2/rho + p, (E+p)*v] with v = m/rho.  
Use the Rusanov (local Lax-Friedrichs) numerical flux: compute wave speed a = max(|v_L| + c_L, |v_R| + c_R) at each interface, where c = sqrt(Gamma*p/rho). Then F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).  
Viscous terms: compute v_x with a centered difference on cell-centered v, then sigma = (zeta + 4/3*eta) * v_x. Approximate sigma at interfaces by averaging neighboring cell-centered sigma values. Add viscous fluxes F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma. Total interface flux: F_total = F_hat + F_visc.  
Time integration: use a 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.  
Time step: compute dt_conv = CFL * dx / max_j(|v_j| + c_j), dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30), then dt = min(dt_conv, dt_visc). Adjust the final step to hit t = 0.5 exactly.  
Ghost cells: implement periodic boundaries by wrapping indices.
