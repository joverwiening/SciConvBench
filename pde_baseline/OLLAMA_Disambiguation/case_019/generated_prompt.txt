Solve the PDE u_t = 0.1 * u_xx + 0.01 * u_yy on the spatial domain [0,1] x [0,1] for time t in [0,0.2].  
Use a uniform grid with Nx = Ny = 60 intervals, so dx = dy = (1-0)/60 and grid points x_i = i*dx, y_j = j*dy for i,j = 0..60.  
Apply Dirichlet boundary conditions u = 0 on all four edges x = 0, x = 1, y = 0, y = 1.  
Set the initial condition u(x,y,0) = sin(pi*x) * sin(pi*y).  
Integrate in time with the implicit Euler method using a time step dt = 0.001 for 200 steps to reach T = 0.2.  
After the final step compute the solution u(x,y,T) on the 2D grid.  
Save a file named "solution_agent_diffusion_03.npz" containing the 1‑D arrays x and y, the 2‑D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T, and the scalar metadata values T, dx, dy, dt.  
Create and save a heatmap or contour plot of u(x,y,T) as "solution_agent_diffusion_03.png".  
Print the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt( sum(u^2) * dx * dy ) at T.  
Compute the exact reference solution u_exact(x,y,T) = exp(-(0.1+0.01)*pi**2*T) * sin(pi*x) * sin(pi*y) on the same grid, then print the maximum absolute error max|u - u_exact| and the L2 error sqrt( sum((u - u_exact)^2) * dx * dy ).
