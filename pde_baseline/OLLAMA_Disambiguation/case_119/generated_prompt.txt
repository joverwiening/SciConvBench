Use Nx = 512 uniform grid points on the periodic domain [0, 1) with dx = 1/512 and x_i = i·dx for i = 0,…,511.  
Set the advection speed q = 1.5.  
Choose the time step dt = 1/1536 (CFL = 0.5) and Nt = 1536 steps so that the final time T = 1.0 is reached.  
Discretize the spatial derivative u_x with a first‑order upwind finite‑difference scheme (backward difference because q > 0): (u_i − u_{i‑1})/dx, applying periodic wrap‑around for i = 0.  
Integrate in time with explicit forward Euler: u^{n+1}_i = u^n_i − q·dt·(u^n_i − u^n_{i‑1})/dx.  
Initialize u(x,0) = sin(2πx) + 0.2·sin(6πx) on the grid.  
After Nt steps compute the numerical solution u(x,T).  
Save a file named “solution_molk_018.npz” containing the arrays x (length Nx) and u (length Nx) and the scalar values T, dx, Nx, q, dt, and Nt.  
Create a line plot of u versus x and save it as “solution_molk_018.png”.  
Print the following diagnostics: min(u), max(u), mean(u), and the discrete L2 norm √(∑ u_i² · dx).
