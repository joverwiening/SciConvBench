Solve the PDE numerically with the following specifications.

PDE: u_tt + (q2**2)*(q1**4)*u = (q1**2)*u_xx (1D linear wave / Klein-Gordon-type equation).
Domain: x in [0, 1) with periodic boundary, t in [0, 1.0].
Parameters: q1 = 1.0, q2 = 0.5.
Boundary conditions: periodic, u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t) for all t.
Initial conditions: u(x,0) = sin(2*pi*x), u_t(x,0) = 0.
Exact solution for verification: u(x,t) = cos(omega*t) * sin(2*pi*x), where omega = sqrt(q2**2 * q1**4 + q1**2 * (2*pi)**2) = 6.303048278758258.
Grid convention: domain is half-open [0,1) with periodicity, so Nx is the number of grid points with no duplicated endpoint; dx = 1.0/Nx and x_i = i*dx for i = 0..Nx-1.
Use Python with '**' for exponentiation.
Treat all trig functions in radians.
