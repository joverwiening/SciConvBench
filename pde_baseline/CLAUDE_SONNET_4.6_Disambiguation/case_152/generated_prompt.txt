Solve the 1D Viscous Burgers PDE numerically with the following specifications.

PDE: u_t + d_x(0.5*u**2) = nu * u_xx
Parameter: nu = 0.002
Boundary condition: Periodic, u(0,t) = u(1,t) for all t
Initial condition: u(x,0) = sin(2*pi*x)
Final time: T = 1.0
Spatial domain: [0,1) with periodicity
Spatial grid: Nx = 512 uniform points, no duplicated endpoint, dx = 1.0/512, x_i = i*dx for i=0..511
Time step: CFL = 0.4, dt0 = CFL*dx/1.0, Nt = ceil(T/dt0), dt = T/Nt so final time is hit exactly
Numerical method: Strang splitting each full time step dt as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), define k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), set u = real(IFFT(u_hat)).
Step B (advection full-step, duration dt): finite-volume update with Rusanov (local Lax-Friedrichs) flux; define f(u) = 0.5*u**2; for each interface between u_left=u[j] and u_right=u[j+1] (periodic indexing), compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left); update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus is the flux at the right interface of cell j and F_minus is the flux at the left interface; replace u with u_new.
Step C (diffusion half-step again): same as Step A.
Compute u at final time T on the grid.
Save file "solution_pdebench_burgers_nu2em3.npz" containing arrays x (length Nx), u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu2em3.png".
Print min(u), max(u), mean(u) (should be approximately conserved), and sqrt(sum(u**2)*dx) at T.
