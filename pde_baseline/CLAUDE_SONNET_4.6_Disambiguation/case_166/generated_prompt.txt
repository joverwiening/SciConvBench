Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically in Python.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use conservative form with m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.
The PDEs are: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.

The spatial domain is x in [-1, 1] and time domain is t in [0, 0.2].
Use Nx = 800 cells (cell-centered finite volume), so dx = 2/800.
Cell centers are at x_i = -1 + (i+0.5)*dx for i = 0..799.

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Boundary conditions are transmissive/outflow (zero-gradient) at both x=-1 and x=1.

Initial condition is a Riemann (shock-tube) discontinuity at x=0.
For x < 0: rho_L = 1.0, v_L = 0.0, p_L = 10.0.
For x >= 0: rho_R = 1.0, v_R = 0.0, p_R = 0.1.

Compute rho(x,T), v(x,T), p(x,T) on the cell centers at T=0.2.

Save a file named "solution_pdebench_cns1d_sod7_eta1em8_outflow.npz" containing arrays x (1D length Nx=800), rho (1D), v (1D), p (1D), and scalars Gamma, eta, zeta, T, dx, CFL.

Save a 3-panel (or 3 separate) line plot(s) of rho, v, p vs x at T=0.2 as "solution_pdebench_cns1d_sod7_eta1em8_outflow.png".

Print min/max of rho and p (positivity check) and the mean of rho over the domain (mass conservation check).

Interpret '^' as exponentiation and use '**' for powers in Python code.
