Solve the 1D Viscous Burgers PDE numerically with the following specifications.

PDE: u_t + d_x(0.5*u**2) = nu * u_xx
Unknown field: u(x,t)
Parameter: nu = 0.001
Spatial domain: [0,1) with periodic boundary conditions, interpreted as half-open with Nx=512 grid points, dx=1.0/512, x_i = i*dx for i=0..511.
Initial condition: u(x,0) = sin(2*pi*x)
Final time: T = 1.0

Numerical method: Strang splitting each full time step dt.

Step A (diffusion half-step, duration dt/2): solve exactly in Fourier space.
Compute u_hat = FFT(u).
Compute k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat = u_hat * exp(-nu*k**2*(dt/2)).
Set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): finite-volume update with Rusanov (local Lax-Friedrichs) flux for inviscid Burgers u_t + d_x(0.5*u**2)=0.
Define f(u)=0.5*u**2.
For each interface between u_left=u[j] and u_right=u[j+1] (periodic indexing):
  alpha = max(abs(u_left), abs(u_right))
  F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left)
For each cell j:
  F_plus = flux between (u[j], u[j+1])
  F_minus = flux between (u[j-1], u[j])
  u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus)
Replace u with u_new.

Step C (diffusion half-step again): same as Step A.

Time step: CFL=0.4, estimated max speed=1.0, dt0=CFL*dx/1.0.
Nt = ceil(T/dt0), then reset dt = T/Nt so the final time T=1.0 is hit exactly.

Output: compute u at final time T on the grid.
Save "solution_pdebench_burgers_nu1em3.npz" containing arrays x (length Nx), u (length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu1em3.png".
Print min(u), max(u), mean(u) (should be approximately conserved), and sqrt(sum(u**2)*dx) at T.
Use Python with ** for exponentiation.
