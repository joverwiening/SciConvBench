Solve the PDE numerically in Python with the following specifications.

The PDE is u_t = -q1 * d/dx((1/3)*u**3) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 0.5].
Parameters are q1 = 1.0 and q2 = 0.05.
The periodic boundary condition is u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required.
Use a uniform periodic grid with Nx=1024 points on [0,1), with x_j = j*dx for j=0,...,1023 and dx=1/1024.
Use a conservative finite-volume Rusanov flux for the convective term d/dx((1/3)*u**3) and 2nd-order central differences for u_xx.
Use SSP-RK2 for time integration.
Compute the time step as follows: estimate max|f'(u)| = max|u**2|; with |u| <= 0.5 initially, max|f'| <= 0.25. Compute dt0 = 0.2*dx/max|f'| and dt_diff = 0.2*dx**2/(q2/pi). Set dt = min(dt0, dt_diff), then Nt = ceil(0.5/dt), and reset dt = 0.5/Nt.
Use '**' for exponentiation in Python code.
Treat all trigonometric functions as operating in radians.
