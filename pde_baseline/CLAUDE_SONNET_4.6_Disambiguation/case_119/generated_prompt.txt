Solve the 1D linear advection PDE numerically using the following full specification.

PDE: u_t + q*u_x = 0
Domain: x in [0, 1) with periodic boundary, t in [0, 1.0]
Parameter: q = 1.5
Initial condition: u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x)
Exact solution: u(x,t) = u0((x - q*t) mod 1), where u0 is the initial condition.

Grid: half-open periodic domain [0,1), so Nx=512 grid points with no duplicated endpoint, dx=1/Nx, x_i = i*dx for i=0..Nx-1.

Numerical method: 1st-order upwind finite difference for spatial discretization, Forward Euler for time integration.
Time stepping: dt0 = 0.5*dx/abs(q), Nt = ceil(T/dt0), dt = T/Nt (so final time is exactly T=1.0).
CFL = 0.5.

Since q > 0, the upwind scheme uses a backward difference: u_x at point i approximated as (u_i - u_{i-1})/dx with periodic indexing.
Update: u_i^{n+1} = u_i^n - q*dt/dx*(u_i^n - u_{i-1}^n)
