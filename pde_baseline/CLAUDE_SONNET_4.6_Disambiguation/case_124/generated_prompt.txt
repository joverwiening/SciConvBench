Solve the PDE numerically according to the full specification below.

PDE is u_t = q1*u_xx + q2*(u**2)*(1-u)**2.

The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
Periodic boundary conditions mean u(0,t) = u(1,t) for all t.
No closed-form reference solution is required; skip the error computation step.
Compute u(x, T=1.0) on the periodic grid.
Save a file named "solution_molk_023.npz" containing arrays x (1D length Nx) and u (1D length Nx), and scalars T, dx, Nx, q1, q2.
