Solve the 1D advection PDE numerically with the following specifications.

PDE: u_t + beta * u_x = 0
Parameter: beta = 0.2
Initial condition: u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)
Boundary conditions: Periodic, u(0,t) = u(1,t) for all t.
Spatial domain: [0,1) with periodicity.
Final time: T = 2.0
Reference solution: u(x,t) = u0((x - beta*t) mod 1), where u0 is the initial condition.

Grid: Uniform grid with Nx=512 points on the half-open domain [0,1). dx = 1/512. x_i = i*dx for i=0..511.
Spatial discretization: 1st-order upwind finite difference for u_x, using the upwind direction determined by the sign of beta (since beta=0.2 > 0, use backward difference).
Time integration: Explicit forward Euler.
Time step: CFL=0.5. dt = CFL * dx / abs(beta). Nt = ceil(T/dt), then reset dt = T/Nt so the final time T=2.0 is hit exactly.

Output:
Save "solution_pdebench_advection_beta0p2.npz" containing arrays x (1D length 512), u (1D length 512), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta0p2.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
Use ** for exponentiation in Python code.
