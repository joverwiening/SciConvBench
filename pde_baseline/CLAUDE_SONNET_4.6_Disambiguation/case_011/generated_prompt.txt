Solve the Allen-Cahn PDE numerically with the following specifications.

Parameter: epsilon = 0.02
Initial condition: r = sqrt((x-0.5)**2 + (y-0.5)**2), u(x,y,0) = tanh((0.25 - r) / (sqrt(2) * 0.02))
Boundary condition: Dirichlet, set boundary nodes to the initial condition values (tanh formula evaluated at boundary points) at every time step.
Grid: Nx = Ny = 300 uniform intervals on [0,1] x [0,1], giving 301 x 301 grid points including both endpoints; dx = dy = 1/300; x_i = i*dx for i=0..300, y_j = j*dy for j=0..300.
Spatial discretization: 5-point Laplacian stencil for u_xx + u_yy.
Time integration: Semi-implicit scheme: (u^{n+1} - u^n)/dt = epsilon**2 * Delta(u^{n+1}) + u^n - (u^n)**3. Solve a sparse linear system at each time step.
Time stepping: dt = 0.0001, total steps = 1000, final time T = 0.1.
Enforce Dirichlet BCs by setting boundary nodes to prescribed values at every time step.
Compute u(x,y,T=0.1) on the full 2D grid.
