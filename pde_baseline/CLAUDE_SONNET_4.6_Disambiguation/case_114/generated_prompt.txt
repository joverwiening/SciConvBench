Solve the 1D porous medium equation numerically with the following specifications.

PDE: u_t = ∂_xx( u^m ), where '^' means exponentiation (use '**' in Python).
Spatial domain: x in [0, 1) with periodic boundary conditions.
Time domain: t in [0, 0.2].
Parameter: m = 2.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.5 + 0.2*cos(2*pi*x).
Nx = 256 (number of grid points on the half-open periodic domain).
dx = (1 - 0)/256 = 1/256.
Grid points: x_i = i*dx for i = 0, 1, ..., 255 (no duplicated endpoint).
Compute u(x, T=0.2) on this periodic grid.
Save "solution_molk_013.npz" containing arrays x (1D length 256), u (1D length 256), and scalars T, dx, Nx, and the parameter m.
Save a line plot of u(x, T) as "solution_molk_013.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.2.
No exact solution is provided, so no error computation is required.
Use radians for all trigonometric functions.
