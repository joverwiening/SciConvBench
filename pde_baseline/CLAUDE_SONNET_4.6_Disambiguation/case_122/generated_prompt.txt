Solve the PDE numerically with the following specifications.

PDE: u_t = q1*u_xx + q2*u

Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = sin(2*pi*x).
Exact solution for verification: u(x,t) = exp(q2*t) * exp(-q1*(2*pi)**2*t) * sin(2*pi*x).
Use Nx = 256 grid points on the half-open periodic domain [0,1).
dx = 1.0/256, x_i = i*dx for i = 0..255 (no duplicated endpoint).
Compute u(x, T=0.5) on this periodic grid.
Use Python with '**' for exponentiation.
Treat all trig functions in radians.
Save "solution_molk_021.npz" containing arrays: x (1D length 256), u (1D length 256), and scalars T, dx, Nx, q1, q2.
Save a line plot of u(x, T) as "solution_molk_021.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.
