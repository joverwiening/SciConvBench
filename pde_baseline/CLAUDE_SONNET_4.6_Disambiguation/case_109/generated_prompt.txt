The initial conditions are: x(0.0) = 1.0, y(0.0) = 1.0.

Use Classical 4th-order Runge–Kutta (RK4) with fixed step size dt = 0.01 and Nt = 3000 steps so the final time t = 30.0 is hit exactly.

Compute the full state vector at all time points t_n = 0.0 + n*0.01 for n = 0..3000.

Save "solution_molk_008.npz" containing arrays: t (1D length 3001), Y (2D array shape [3001, 2]) with columns ordered as [x, y], and the parameter scalars alpha, beta, gamma, delta.

Save line plots of each state (x and y) vs t as "solution_molk_008.png".

Print the final state values of x and y at t = 30.0, and also the min and max of each state over all time points.
