Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the full specification below.

PDE in conservative form with m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Viscous stress sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.
Equations: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.

Spatial domain: x in [-1, 1], periodic boundary conditions.
Time domain: t in [0, 0.5].

Parameters: Gamma = 1.6666666666666667, eta = 0.01, zeta = 0.01.

Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
Cell centers: x_j = -1 + (j + 0.5)*dx for j = 0, ..., 399, with dx = 2/400 = 0.005.
Evolve conservative variables U = [rho, m, E] as cell averages.

Initial conditions (evaluated at cell centers):
rho(x, 0) = 1.0 + 0.2*sin(pi*x).
v(x, 0) = 0.1*cos(pi*x).
p(x, 0) = 1.0 + 0.2*cos(pi*x).
Convert to conservative variables: m = rho*v, E = p/(Gamma-1) + 0.5*rho*v^2.

Equation of state: p = (Gamma-1)*(E - 0.5*m^2/rho). Clip rho and p to floor 1e-12 if needed.

Convective flux uses Rusanov (local Lax-Friedrichs): F_conv = [m, m^2/rho + p, (E+p)*v].
Interface wave speed: a = max(|v_L| + c_L, |v_R| + c_R), c = sqrt(Gamma*p/rho).
Numerical convective flux: F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

Viscous terms: compute v_x with centered differences on cell-centered v values.
Compute sigma = (zeta + 4/3*eta)*v_x at cell centers.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Viscous flux at interfaces: F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Total interface flux: F_total = F_hat + F_visc.

Time integration: 2-stage SSP-RK2 (Heun's method).
Time step each stage: dt_conv = CFL * dx / max_j(|v_j| + c_j), dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30), dt = min(dt_conv, dt_visc).
Use CFL = 0.5 (standard choice unless otherwise specified).
Adjust the last time step to hit T = 0.5 exactly.

Boundary conditions: periodic, implemented via index wrapping for ghost cells.

Output: compute rho(x, T), v(x, T), p(x, T) at all cell centers.
