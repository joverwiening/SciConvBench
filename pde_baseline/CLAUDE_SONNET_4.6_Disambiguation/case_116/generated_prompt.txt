Solve the 1D sine-Gordon PDE numerically with the following specifications.

PDE: u_tt + q*sin(u) = u_xx, where q = 1.0.
Spatial domain: x in [0, 1) with periodic boundary conditions.
Time domain: t in [0, 2.0].
Use Nx as the number of grid points with no duplicated endpoint (half-open periodic domain).
Set dx = 1.0/Nx and x_i = i*dx for i = 0..Nx-1.
Initial condition: u(x,0) = 0.1*sin(2*pi*x).
Initial time derivative: u_t(x,0) = 0.
Boundary conditions: periodic, u(0,t) = u(1,t) and u_x(0,t) = u_x(1,t) for all t.
No closed-form reference solution is required.
Solve the PDE numerically and compute u(x, T=2.0) on the periodic grid.
Save a file named "solution_molk_015.npz" containing arrays x (1D length Nx) and u (1D length Nx), and scalars T, dx, Nx, and q.
Save a line plot of u(x, T) as "solution_molk_015.png".
Print the following diagnostics at T=2.0: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx).
Interpret '^' as exponentiation; use '**' for powers in Python code.
Use radians for all trigonometric functions.
