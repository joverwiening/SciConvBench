Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the specifications below.

The unknown fields are rho(x,t), v(x,t), p(x,t).

Use conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v**2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.

The PDE in conservative form is:
rho_t + (m)_x = 0
m_t + (m**2/rho + p - sigma)_x = 0
E_t + ((E+p)*v - v*sigma)_x = 0

The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.5].

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Boundary conditions are periodic on x = -1 and x = 1.

Initial conditions (pointwise):
rho(x,0) = 1.0 + 0.2*sin(pi*x)
v(x,0) = 0.1*cos(pi*x)
p(x,0) = 1.0 + 0.2*cos(pi*x)

Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1].
Cell centers are x_j = -1 + (j + 0.5)*dx for j = 0, ..., 399, with dx = 2/400 = 0.005.

Evolve the conservative variables U = [rho, m, E] as cell averages.

Use the equation of state p = (Gamma-1) * (E - 0.5*m**2/rho).
Enforce positivity by clipping rho and p to a floor of 1e-12 if needed.

For the convective flux, use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
F_conv(U) = [m, m**2/rho + p, (E+p)*v] with v = m/rho.
Interface wave speed: a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho).
Numerical flux: F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).

For viscous terms, compute v_x with a centered difference on cell-centered v values, then sigma = (zeta + 4/3*eta)*v_x.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Add viscous contributions to momentum and energy fluxes at interfaces: F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Total interface flux: F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.

Choose dt each step by:
dt_conv = CFL * dx / max_j(|v_j| + c_j)
dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30)
dt = min(dt_conv, dt_visc)
Adjust the last step so the final time T = 0.5 is hit exactly.

For periodic boundary conditions, wrap indices.
For outflow boundary conditions, set ghost cell values equal to the nearest interior cell.

Compute rho(x,T), v(x,T), p(x,T) on the cell centers at final time T = 0.5.

Save a 3-panel (or 3 separate) line plot(s) of rho, v, p vs x at T as "solution_pdebench_cns1d_eta1em8_periodic_smooth.png".

Print min/max of rho and p (positivity check) and the mean of rho over the domain (mass conservation check).
