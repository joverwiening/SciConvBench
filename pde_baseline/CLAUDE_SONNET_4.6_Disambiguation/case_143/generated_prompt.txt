Solve the 1D Viscous Burgers PDE numerically with the following specifications.

Task ID is pdebench_burgers_nu0p01.
The PDE is u_t + d_x(0.5*u^2) = nu * u_xx.
The parameter nu = 0.01.
The spatial domain is [0,1) with periodic boundary conditions: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
The final simulation time is T = 1.0.
Use a uniform periodic grid with Nx = 512 points; dx = 1.0/512; x_i = i*dx for i = 0..511.
Use Strang splitting for each full time step dt as follows.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u); compute k = 2*pi*fftfreq(Nx, d=dx); multiply u_hat(k) by exp(-nu*k**2*(dt/2)); set u = real(IFFT(u_hat)).
Step B (advection full-step, duration dt) for inviscid Burgers u_t + d_x(0.5*u^2) = 0: use a finite-volume update with Rusanov (local Lax-Friedrichs) flux. Define f(u) = 0.5*u**2. For each interface between u_left = u[j] and u_right = u[j+1] (periodic indexing): alpha = max(abs(u_left), abs(u_right)); F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left). For each cell j: F_plus = flux between (u[j], u[j+1]); F_minus = flux between (u[j-1], u[j]); u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus). Replace u with u_new after the advection substep.
Step C (diffusion half-step again, same as Step A).
Set dt0 = 0.4 * dx / 1.0 (CFL = 0.4, estimated max speed = 1).
Set Nt = ceil(T / dt0), then reset dt = T / Nt so the final time T = 1.0 is hit exactly.
Treat '^' as exponentiation and use '**' for powers in Python code.
Use radians for all trigonometric functions.
Compute u at the final time T on the grid.
Save a file named "solution_pdebench_burgers_nu0p01.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p01.png".
Print min(u), max(u), the discrete mean value mean(u) (should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
