Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically using the full specification below.

PDE in conservative form with m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
Viscous stress sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.
Equations: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.

Domain: x in [-1, 1], t in [0, 0.5].

Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.

Boundary conditions: transmissive/outflow (zero-gradient) at both x=-1 and x=1.

Initial conditions (pointwise): rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).

Grid: uniform finite-volume grid with Nx = 400 cells on [-1, 1]. Cell centers x_j = -1 + (j+0.5)*dx for j=0,...,399, dx = 2/400 = 0.005.

Evolve conservative variables U = [rho, m, E] as cell averages.

Equation of state: p = (Gamma-1) * (E - 0.5*m^2/rho). Clip rho and p to a floor of 1e-12 for positivity.

Convective flux: use Rusanov (local Lax-Friedrichs) flux. F_conv = [m, m^2/rho + p, (E+p)*v] with v = m/rho. Interface wave speed a = max(|v_L|+c_L, |v_R|+c_R) where c = sqrt(Gamma*p/rho). Numerical flux F_hat = 0.5*(F_conv(U_L)+F_conv(U_R)) - 0.5*a*(U_R - U_L).

Viscous terms: compute v_x with centered differences on cell-centered v values. Compute sigma = (zeta + 4/3*eta)*v_x at cell centers. Approximate sigma at interfaces by averaging neighboring cell-centered sigma values. Viscous flux F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma. Total flux: F_total = F_hat + F_visc.

Time integration: 2-stage SSP-RK2 (Heun's method).

Time step each stage: dt_conv = CFL * dx / max_j(|v_j|+c_j), dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30), dt = min(dt_conv, dt_visc). Adjust the last step to hit T=0.5 exactly.

Use CFL = 0.8 (standard value unless otherwise specified).

Ghost cell BC: for outflow, set ghost cell equal to nearest interior cell (zero-gradient).

Compute rho(x,T), v(x,T), p(x,T) on cell centers at T=0.5.
