Solve the Burgers PDE numerically and save the results as specified.

PDE: u_t + u*u_x = 0.005*u_xx, written in conservative form as u_t + (f(u))_x = nu*u_xx with f(u) = 0.5*u**2.

Domain: x in [0,1) periodic, t in [0, 0.2].

Parameter: nu = 0.005.

Initial condition: u(x,0) = 0.5 + sin(2*pi*x).

Grid: Nx = 1200 points on [0,1) with dx = 1/Nx and x_i = i*dx for i = 0..1199 (half-open, periodic, no duplicated endpoint).

Time stepping: dt = 5e-5, Nt = 4000 steps, so T = 0.2 is hit exactly.

Spatial discretization (convection): Use Rusanov (local Lax-Friedrichs) flux F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i) where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|). Approximate (f(u))_x as (F_{i+1/2} - F_{i-1/2})/dx. Apply periodic boundary indexing.

Spatial discretization (diffusion): 2nd-order central difference u_xx ≈ (u_{i+1} - 2*u_i + u_{i-1})/dx**2 with periodic boundary indexing.

Time integration: 1st-order IMEX — convection treated explicitly, diffusion treated implicitly. Each step solves the linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term, where L is the periodic tridiagonal diffusion operator. Use scipy.sparse.linalg.spsolve each step.

Output: Compute u(x, T=0.2) on the grid.
