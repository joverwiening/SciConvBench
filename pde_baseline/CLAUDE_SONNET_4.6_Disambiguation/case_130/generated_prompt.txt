Solve the PDE numerically in Python with the following specifications.

PDE: u_t = -q1 * d/dx( sin(u) ) + (q2/pi) * u_xx
Spatial domain: x in [0, 1) with periodic boundary conditions, t in [0, 0.5].
Parameters: q1 = 1.0, q2 = 0.05.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.5 * sin(2*pi*x).
No closed-form reference solution is required.

Use a uniform periodic grid with Nx = 1024 points on [0,1).
Set dx = 1/Nx and x_j = j*dx for j = 0, ..., Nx-1.

Discretize d/dx(sin(u)) using a conservative finite-volume Rusanov flux.
The Rusanov wave speed is alpha = max|cos(u)| evaluated locally at each interface.
Discretize u_xx using 2nd-order central differences.

Use SSP-RK2 for time integration.
Compute dt_adv = 0.2 * dx / 1 (since max|cos(u)| <= 1).
Compute dt_diff = 0.2 * dx**2 / (q2 / pi).
Set dt = min(dt_adv, dt_diff).
Set Nt = ceil(T / dt), then recompute dt = T / Nt to exactly reach T = 0.5.
