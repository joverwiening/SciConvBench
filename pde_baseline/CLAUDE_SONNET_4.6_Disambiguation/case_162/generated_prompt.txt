Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically in Python.
The unknown fields are rho(x,t), v(x,t), p(x,t).
Use conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.
The PDEs in conservative form are: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
The spatial domain is x in [-1, 1] and the time domain is t in [0, 0.2].
Parameters: Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.
Boundary conditions are transmissive/outflow (zero-gradient) at both x=-1 and x=1.
Initial condition is a Riemann/shock-tube problem with discontinuity at x=0: for x < 0, rho_L=1.0, v_L=0.75, p_L=1.0; for x >= 0, rho_R=0.125, v_R=0.0, p_R=0.1.
Use a uniform finite-volume grid with Nx=800 cells on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,799, with dx = 2/800.
Evolve cell-average conservative variables U = [rho, m, E].
Use the equation of state p = (Gamma-1)*(E - 0.5*m^2/rho), clipping rho and p to a floor of 1e-12 for positivity.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid part: F_conv = [m, m^2/rho+p, (E+p)*v], interface wave speed a = max(|v_L|+c_L, |v_R|+c_R) with c=sqrt(Gamma*p/rho), and F_hat = 0.5*(F_conv(U_L)+F_conv(U_R)) - 0.5*a*(U_R-U_L).
Compute v_x with centered differences on cell-centered v values, then sigma = (zeta + 4/3*eta)*v_x.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Add viscous flux contributions F_visc = [0, -sigma, -v*sigma] at interfaces using interface-averaged v and sigma.
Total interface flux is F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Choose dt each step as the minimum of dt_conv = CFL * dx / max_j(|v_j|+c_j) and dt_visc = 0.5*dx**2 / max(zeta + 4/3*eta, 1e-30), adjusting the last step to hit T=0.2 exactly.
Implement outflow BCs using ghost cells set equal to the nearest interior cell (zero-gradient).
Use '^' as exponentiation in math and '**' in Python code.
Compute rho(x,T), v(x,T), p(x,T) on the cell centers at final time T=0.2.
