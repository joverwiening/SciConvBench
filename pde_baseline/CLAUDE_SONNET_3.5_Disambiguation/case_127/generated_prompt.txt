Task ID is molk_026.
Solve 1D linear advection-diffusion equation u_t = -q1*∂_x(u) + (q2/pi)*u_xx.
Domain is x in [0,1) with periodic boundary and t in [0,0.5].
Parameters are q1=1.0 and q2=0.05.
Use periodic boundary conditions where u(0,t)=u(1,t).
Initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use Python for implementation.
Use matplotlib for visualization.
Create uniform periodic grid with Nx=512 points on [0,1).
Use x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement 1st-order upwind for ∂_x(u) and 2nd-order central differences for u_xx.
Use IMEX Euler or sufficiently small explicit dt for time integration.
Calculate dt = min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)).
Choose Nt=ceil(T/dt) and reset dt=T/Nt.
