Task ID: molk_010
ODE category: Brusselator chemical oscillator
Solve the ODE system numerically:
dx/dt = A + x^2 * y - (B + 1) * x
dy/dt = B * x - x^2 * y
Time domain is [0.0, 20.0].
Initial conditions are x(0) = 1.0, y(0) = 1.0.
Parameters are A = 1.0, B = 3.0.
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt = 0.01.
Use Nt = 2000 time steps.
Compute the full state vector at all time points.
Save solution_molk_010.npz containing arrays t, Y, and parameter scalars.
Save line plots of states vs t as solution_molk_010.png.
Print final state values at T and min/max of each state over time.
