Task ID: molk_033
PDE category: 1D advection–diffusion with space-dependent drift (periodic)
Unknown field: u(x,t)
The PDE is u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u ), with U(x) = cos(2*pi*x).
The domain is x in [0, 1) with periodic boundary and t in [0, 1.0].
Parameters are D = 0.01, gamma = 1.0.
U(x) = cos(2*pi*x).
U'(x) = -2*pi*sin(2*pi*x).
Periodic boundary conditions: u(0,t)=u(1,t) for all t.
Initial condition is u(x,0) = 1.0 + 0.2*sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Treat drift term in conservative form with flux F = (1/gamma)*U'(x)*u.
Use upwind finite-volume flux for ∂_x(F) based on sign of interface velocity b=U'(x)/gamma.
Use 2nd-order central differences for u_xx.
Implement explicit SSP-RK2 time integration.
Choose dt = min(0.4*dx/max|b|, 0.2*dx^2/D).
Set Nt=ceil(T/dt) and adjust dt=T/Nt.
