Task ID: pdebench_cns1d_sod3_eta1em8_outflow
Solve the 1D Compressible Navier-Stokes equations numerically with the following specifications:
The domain is x in [-1, 1], t in [0, 0.2].
Use Nx = 800 cells in a uniform finite-volume grid.
Use CFL = 0.4 for time step calculation.
The equations are in conservative form for [rho, m, E] with viscous stress sigma = (zeta + 4/3*eta) * v_x.
Parameters are Gamma = 1.6666666666666667, eta = zeta = 1e-08.
Initial conditions are a Riemann problem with left state (rho=1.0, v=0.75, p=1.0) and right state (rho=0.125, v=0.0, p=0.1).
Use transmissive/outflow boundary conditions at both ends.
Implement Rusanov flux for convective terms and centered differences for viscous terms.
Use 2-stage SSP-RK2 time integration.
Compute and save solution arrays in NPZ format.
Generate solution plots in PNG format.
Report min/max of rho and p, and mean of rho.
