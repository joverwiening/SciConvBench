Task ID: molk_020
Solve 1D reaction-diffusion PDE u_t = q1*u_xx + q2*u*(1-u) numerically.
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
Use parameters q1 = 0.01 and q2 = 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use Nx = 512 spatial grid points.
Use dt = 0.001 with Nt = 1000 time steps.
Use either IMEX Euler or Strang splitting with FFT for the numerical method.
Compute u(x,T=1.0) on the periodic grid.
Save solution data in "solution_molk_020.npz" with arrays x, u and scalar values.
Create and save a line plot of u(x,T) as "solution_molk_020.png".
Print min(u), max(u), mean(u), and L2 norm at final time T.
No error computation is required as no exact solution is provided.
