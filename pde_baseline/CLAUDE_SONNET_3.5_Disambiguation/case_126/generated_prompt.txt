Use SSP-RK2 (Heun) time integration.
Set time step using CFL=0.2 with dt0 = CFL*dx/max|u|, Nt=ceil(T/dt0), dt=T/Nt.
Implement in Python using NumPy.
Save solution data in solution_molk_025.npz containing x array, u array, and scalar parameters.
