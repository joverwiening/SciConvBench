Task: Solve Lotka-Volterra predator-prey ODE system numerically.
The ODE system is dx/dt = alpha*x - beta*x*y and dy/dt = delta*x*y - gamma*y.
Time domain is [0.0, 30.0].
Initial conditions are x(0) = 1.0 and y(0) = 1.0.
Parameters are alpha = 1.5, beta = 1.0, gamma = 3.0, delta = 1.0.
Use Classical 4th-order Runge-Kutta (RK4) with fixed time step dt = 0.01.
Use Nt = 3000 time steps.
Compute full state vector at all time points.
Save solution data to solution_molk_008.npz including t, Y arrays and parameters.
Save line plots of states vs time to solution_molk_008.png.
Print final state values and min/max of each state over time.
