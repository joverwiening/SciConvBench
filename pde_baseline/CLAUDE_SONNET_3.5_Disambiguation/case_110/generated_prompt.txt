Task ID: molk_009
Solve FitzHugh-Nagumo ODE system numerically.
The ODE system is dv/dt = v - (v^3)/3 - w + I and dw/dt = (1/tau)*(v + a - b*w).
Time domain is [0.0, 200.0].
Initial conditions are v(0) = -1.0 and w(0) = 1.0.
Parameters are I = 0.5, a = 0.7, b = 0.8, tau = 12.5.
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt = 0.05.
Use Nt = 4000 time steps.
Compute full state vector at all time points.
Save solution to NPZ file named "solution_molk_009.npz" with arrays t and Y, and parameter scalars.
Save line plots of states vs t as "solution_molk_009.png".
Print final state values at T and min/max of each state over time.
