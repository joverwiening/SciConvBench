Task ID is molk_028.
Solve 1D inviscid conservation law with cubic flux: u_t = -k*∂_x((1/3)*u^3).
Domain is x in [0,1) periodic, t in [0,0.2].
Parameter k = 1.0.
Initial condition is u(x,0) = 0.5*sin(2*pi*x).
Use uniform periodic grid with Nx=1024 points.
Use conservative finite-volume method with Rusanov flux for f(u)=(1/3)u^3.
Implement SSP-RK2 time integration.
Use CFL=0.2 for time step calculation.
Save numerical solution arrays to solution_molk_028.npz.
Create plot and save as solution_molk_028.png showing both initial and final states.
Print min, max, mean, and L2 norm of final solution.
Grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Time step is based on max|f'(u)| = max|u^2| ≤ 0.25.
