Task: Solve a diffusion-reaction PDE with the following specifications:
The PDE is u_t = 0.01*u_xx + u*(1-u)*(u-0.25).
The domain is x in [0,1], t in [0,0.5].
The diffusion coefficient D = 0.01.
The reaction parameter a = 0.25.
Dirichlet boundary conditions: u(0,t)=1 and u(1,t)=0.
Initial condition is u(x,0) = 0.5*(1 - tanh((x-0.5)/0.02)).
Use 2nd-order central differences for spatial discretization on a uniform grid with Nx=600.
Use IMEX time integration with dt=0.0002 (2500 steps), implicit diffusion and explicit reaction.
Solve (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) using a sparse direct solver each step.
Save solution data in NPZ format including x, u, T, dx, dt.
Create a line plot of the final solution.
Report minimum, maximum, and L2 norm of the solution at final time.
