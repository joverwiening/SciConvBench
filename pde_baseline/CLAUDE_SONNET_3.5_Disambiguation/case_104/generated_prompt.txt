Task ID: molk_003
Solve scalar ODE du/dt = a*sin(exp(-0.5*t)*sin(3*t)) + b*u numerically.
Time domain is [0.0, 5.0].
Initial condition is u(0.0) = 0.2.
Parameters are a = 1.0 and b = -0.3.
Use Classical 4th-order Runge-Kutta (RK4) method.
Use fixed time step dt = 0.001 with Nt = 5000 steps.
Compute solution u(t) at all time points t_n = t0 + n*dt for n=0..Nt.
Save solution arrays to solution_molk_003.npz containing t, u, and parameters.
Save line plot of u(t) vs t as solution_molk_003.png.
Print final value u(T), minimum u value, and maximum u value.
No exact solution comparison required.
