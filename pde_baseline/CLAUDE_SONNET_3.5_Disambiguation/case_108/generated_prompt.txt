Task ID: molk_007
ODE category: Van der Pol oscillator
Solve the ODE system numerically with the following specifications:
The system is dx/dt = y, dy/dt = mu*(1 - x^2)*y - x.
The time domain is t in [0.0, 20.0].
The parameter mu = 2.0.
Initial conditions are x(0) = 1.0 and y(0) = 0.0.
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt=0.01 and Nt=2000 steps.
Compute the full state vector at all time points t_n = t0 + n*dt for n=0..Nt.
Save solution_molk_007.npz containing arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns [x, y], and parameter scalars.
Save line plots of each state vs t as solution_molk_007.png.
Print the final state values at T and min/max of each state over time.
