Task ID: molk_006
ODE category: 3-state neural dynamics toy model
Solve the ODE system numerically for E, I, H (functions of t).
The ODE system is:
dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t)
dI/dt = delta*E - epsilon*I
dH/dt = theta*I - phi*H
Time domain is t in [0.0, 50.0].
Parameters are alpha=1.2, beta=1.0, gamma=0.5, delta=0.8, epsilon=0.7, theta=0.9, phi=0.4.
Initial conditions are E(0)=0.5, I(0)=0.2, H(0)=0.1.
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt=0.01 and Nt=5000 steps.
Compute full state vector at all time points.
Save solution_molk_006.npz containing arrays t, Y, and parameter scalars.
Save line plots of each state vs t as solution_molk_006.png.
Print final state values at T and min/max of each state over time.
