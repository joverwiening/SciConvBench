Solve the 1D wave equation u_tt = q*u_xx numerically with the following specifications:
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
Use parameter q = 1.0.
Initial condition is u(x,0) = sin(2*pi*x).
Initial velocity is u_t(x,0) = 0.
Use Nx = 256 spatial grid points.
Use dt = 0.0005 with Nt = 2000 time steps.
Compute u(x,T=1.0) on the periodic grid.
Save solution data in solution_molk_019.npz containing arrays x and u, and scalars T, dx, Nx, and parameters.
Save line plot of u(x,T) as solution_molk_019.png.
Print min(u), max(u), mean(u), and discrete L2 norm at final time T.
