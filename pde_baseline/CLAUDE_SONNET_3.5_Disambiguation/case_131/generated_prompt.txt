Task ID: molk_030
Solve 1D inviscid conservation law with sin flux (periodic) for u(x,t).
The PDE is u_t = -k*∂_x(sin(u)) with k = 1.0.
The domain is x in [0, 1) with periodic boundary and t in [0, 0.2].
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
Use a uniform periodic grid with Nx=1024 points on [0,1) with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
Use conservative finite-volume Rusanov flux for f(u)=sin(u) with wave speed alpha=max|cos(u)|.
Use standard 2-stage SSP-RK2 (Heun's method) for time integration.
Set time step using CFL=0.2: dt0 = CFL*dx/1.0, Nt=ceil(T/dt0), dt=T/Nt.
Enforce periodic boundary condition u(0,t)=u(1,t) for all t.
No closed-form reference solution is required.
