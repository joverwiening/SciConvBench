Solve the Allen-Cahn PDE numerically with the following specifications:
The PDE is u_t = (0.02)^2*(u_xx + u_yy) + u - u^3.
The domain is (x,y) in [0,1] x [0,1], t in [0,0.1].
Epsilon parameter is 0.02.
Initial condition is u(x,y,0)=tanh((0.25 - r)/(sqrt(2)*0.02)) where r = sqrt((x-0.5)^2 + (y-0.5)^2).
Use Dirichlet boundary conditions with u=0 on all boundaries.
Use spatial discretization with uniform grid and 5-point Laplacian for u_xx+u_yy.
Use semi-implicit time integration: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
Use Nx=Ny=300 grid points with dt=0.0001 (1000 steps).
Enforce boundary conditions by setting boundary nodes to prescribed values each time step.
Compute u(x,y,T=0.1) on the 2D grid.
Save solution in NPZ file "solution_agent_allen_cahn_05.npz" with arrays x, y, u and metadata scalars.
Save heatmap/contour plot as "solution_agent_allen_cahn_05.png".
Print min(u), max(u), and discrete L2 norm at final time T.
