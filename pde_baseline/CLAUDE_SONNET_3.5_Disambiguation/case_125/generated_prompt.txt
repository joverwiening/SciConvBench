Task: Implement a numerical solver for 1D convection-diffusion PDE in Python with the following specifications:
The PDE is u_t = -q1*∂_x(0.5*u^2) + (q2/pi)*u_xx.
The domain is x in [0, 1) with periodic boundary and t in [0, 0.5].
Parameters are q1 = 1.0 and q2 = 0.1.
Periodic boundary conditions require u(0,t) = u(1,t) for all t.
Initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points on [0,1).
Implement conservative finite-volume/finite-difference with Rusanov flux for nonlinear term.
Use 2nd-order central differences for diffusion term.
Implement SSP-RK2 (Heun) time integration.
Calculate time step based on both convection and diffusion stability conditions.
Use Python with NumPy arrays and '**' operator for powers.
Save results in .npz format.
