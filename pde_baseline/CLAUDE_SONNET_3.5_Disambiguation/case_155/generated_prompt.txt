Task ID: pdebench_cns1d_eta0p01_periodic_smooth
Solve 1D Compressible Navier-Stokes equations numerically with the following specifications:
The domain is x in [-1, 1], t in [0, 0.5].
Use Nx = 400 cells in the spatial grid.
Use CFL = 0.5 for time step calculation.
Parameters are Gamma = 1.6666666666666667, eta = zeta = 0.01.
Initial conditions are rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Use periodic boundary conditions.
Implement Rusanov flux for convective terms.
Implement centered differences for viscous terms.
Use 2-stage SSP-RK2 time integration.
Compute time step as minimum of convective and viscous constraints.
Save solution arrays to solution_pdebench_cns1d_eta0p01_periodic_smooth.npz.
Create visualization plot saved as solution_pdebench_cns1d_eta0p01_periodic_smooth.png.
Print minimum/maximum of rho and p, and mean of rho for diagnostics.
