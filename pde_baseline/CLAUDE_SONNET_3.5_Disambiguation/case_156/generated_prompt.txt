Task ID: pdebench_cns1d_eta0p1_periodic_smooth

Use finite-volume discretization with Rusanov flux for convective terms.
Implement viscous terms using centered differences and interface averaging.
Use 2-stage SSP-RK2 time integration.
Compute adaptive time step based on convective and viscous constraints.
Save solution arrays to solution_pdebench_cns1d_eta0p1_periodic_smooth.npz.
Create visualization plots in solution_pdebench_cns1d_eta0p1_periodic_smooth.png.
