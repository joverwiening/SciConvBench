The task is to solve the 1D Viscous Burgers equation with the following specifications:
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The spatial domain is [0, 1) with periodic boundary conditions.
The viscosity parameter nu = 0.2.
The initial condition is u(x,0) = sin(2*pi*x).
The final time is T = 1.0.
Use Nx = 512 grid points with uniform spacing.
Implement Strang splitting with three substeps: FFT-based diffusion (dt/2), Rusanov flux advection (dt), FFT-based diffusion (dt/2).
Use CFL = 0.4 with estimated max speed of 1.0 to determine time step.
Save solution data in NPZ format including x, u, nu, T, dx, dt, Nx, Nt.
Create a line plot of the final solution u(x,T).
Report min(u), max(u), mean(u), and L2 norm at final time T.
