Task ID: pdebench_cns1d_eta1em8_outflow_smooth
Solve 1D Compressible Navier-Stokes equations numerically with the following specifications:
The domain is x in [-1, 1] and t in [0, 0.5].
Use Nx = 400 cells in the spatial grid.
Use CFL = 0.5 for time step calculation.
Parameters are Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.
Initial conditions are rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Use transmissive/outflow boundary conditions at x = -1 and x = 1.
Implement a finite-volume method with Rusanov flux for convective terms.
Use centered differences for viscous terms.
Integrate in time using 2-stage SSP-RK2 (Heun's method).
Compute time step as minimum of convective and viscous constraints.
Save solution arrays to solution_pdebench_cns1d_eta1em8_outflow_smooth.npz.
Create visualization plot saved as solution_pdebench_cns1d_eta1em8_outflow_smooth.png.
Report min/max of rho and p, and mean of rho for solution verification.
