Task: Solve 1D Advection PDE with the following specifications:
The PDE is u_t + beta * u_x = 0.
The spatial domain is [0, 1) with periodic boundary conditions.
The final time T is 2.0.
beta = 0.2.
Initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Reference solution is u(x,t) = u0((x - beta*t) mod 1).
Use Nx=512 points for spatial discretization.
Use 1st-order upwind finite difference scheme for spatial discretization.
Use explicit forward Euler for time integration.
Use CFL=0.5 to determine dt.
Adjust dt to hit final time T exactly by computing Nt = ceil(T/dt) and then dt = T/Nt.
Save solution data in "solution_pdebench_advection_beta0p2.npz" with arrays x, u and scalars beta, T, dx, dt, Nx, Nt.
Create and save a line plot of u(x,T) as "solution_pdebench_advection_beta0p2.png".
Print min(u), max(u), and discrete L2 norm at final time T.
Compute and print max absolute error and L2 error against reference solution.
