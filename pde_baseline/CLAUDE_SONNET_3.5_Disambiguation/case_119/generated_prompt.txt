Solve 1D linear advection equation u_t + q*u_x = 0 with the following specifications:
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
The advection speed q = 1.5.
Use Nx = 512 grid points.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
Use 1st-order upwind finite difference for spatial discretization.
Use Forward Euler for time integration.
Use CFL = 0.5 to determine the time step size.
Save the solution at T=1.0 in solution_molk_018.npz containing x, u arrays and scalar parameters.
Create a line plot of the final solution and save as solution_molk_018.png.
Print min(u), max(u), mean(u), and L2 norm at final time.
Compute and print max absolute error and L2 error against the exact solution u(x,t) = u0((x - q*t) mod 1).
