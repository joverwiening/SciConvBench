Solve a 2D diffusion PDE u_t = 0.1 * u_xx + 0.01 * u_yy.
The spatial domain is [0,1] x [0,1].
The time domain is [0,0.2].
The diffusion coefficients are Dx = 0.1 and Dy = 0.01.
Use Dirichlet boundary conditions with u=0 on all boundaries.
The initial condition is u(x,y,0) = sin(pi*x)*sin(pi*y).
Use a uniform grid with Nx=Ny=60 intervals.
Use implicit Euler time integration with dt=0.001 (200 steps).
Use standard 5-point Laplacian with scaled x- and y- second derivatives.
The exact solution is u(x,y,t) = exp(-(0.1+0.01)*pi^2*t)*sin(pi*x)*sin(pi*y).
Save solution data to solution_agent_diffusion_03.npz containing x, y, u arrays and T, dx, dy, dt scalars.
Save a heatmap/contour plot of the final solution to solution_agent_diffusion_03.png.
Print minimum, maximum, and L2 norm of the solution at final time.
Compute and print maximum absolute error and L2 error compared to exact solution.
