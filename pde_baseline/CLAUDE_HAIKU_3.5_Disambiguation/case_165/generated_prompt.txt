Solve the 1D Compressible Navier-Stokes PDE with the following specifications:

Numerical Method:
Solve on a uniform finite-volume grid with Nx=800 cells.
Evolve conservative variables U=[rho, m, E].
Use Rusanov flux for convective terms.
Compute viscous terms with centered differences.
Apply 2-stage SSP-RK2 time integration.
Implement zero-gradient (transmissive) boundary conditions.

Viscous Stress Term Calculation:
Compute v_x with centered difference on cell-centered v values.
Calculate sigma = (zeta + 4/3*eta)*v_x.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Add viscous contributions to momentum and energy fluxes at interfaces as [ 0, -sigma, -v*sigma ].

Time Step Calculation:
Use CFL number = 0.5.

Domain and Initial Conditions:
x in [-1, 1], t in [0, 0.2]
Riemann shock-tube initial condition with discontinuity at x=0.
Left state (x < 0): rho_L = 0.445, v_L = 0.698, p_L = 3.528
Right state (x ≥ 0): rho_R = 0.5, v_R = 0.0, p_R = 0.571

Parameters:
Gamma = 1.6666666666666667
eta = 1e-08
zeta = 1e-08

Boundary Conditions:
Transmissive/outflow (zero-gradient) at x=-1 and x=1

Output Requirements:
