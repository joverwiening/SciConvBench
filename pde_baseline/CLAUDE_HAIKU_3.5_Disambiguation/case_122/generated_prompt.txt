Solve the 1D linear reaction-diffusion PDE with the following specifications:

Numerical Method:
Operator-splitting method with Crank-Nicolson for diffusion and exact exponential solution for reaction
Spatial discretization using 2nd-order central differences for u_xx
Uniform periodic grid with Nx=256 points
Time step dt=0.001 with Nt=500 total steps

Programming Environment:
Use Python with NumPy for numerical computations

PDE Details:
Equation: u_t = q1*u_xx + q2*u
Domain: x in [0, 1) periodic, t in [0, 0.5]
Parameters: q1 = 0.01, q2 = -1.0

Initial Condition:
u(x,0) = sin(2*pi*x)

Boundary Conditions:
Periodic: u(0,t) = u(1,t) for all t

Output Requirements:
Compute u(x,T=0.5) on periodic grid
