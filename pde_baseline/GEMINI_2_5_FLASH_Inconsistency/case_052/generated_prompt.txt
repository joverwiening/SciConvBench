The task is to numerically solve the Klein-Gordon PDE.
The unknown field is u(x,y,t).
The PDE is u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0.
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.8].
The parameter c is 1.0.
The parameter m is 1.0.
The boundary conditions are Dirichlet on all boundaries with u=0.
The initial condition for u(x,y,0) is sin(pi*x)*sin(pi*y).
The initial condition for u_t(x,y,0) is 0.
The reference exact solution is u(x,y,t)=cos(sqrt((1.0)^2*(2*pi^2) + (1.0)^2)*t)*sin(pi*x)*sin(pi*y).
The spatial discretization uses a uniform grid with a 5-point Laplacian for u_xx+u_yy.
The time integration uses 2nd-order central in time for u_tt.
The initialization uses a Taylor start using the Laplacian and mass term.
The grid uses Nx=Ny=256 intervals, resulting in Nx+1 by Ny+1 points.
dx and dy are both 1/Nx.
dt0 is calculated as 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Nt is calculated as ceil(T/dt0).
dt is then set to T/Nt to hit the final time exactly.
The final simulation time T is 0.8.
The computation should produce u(x,y,T=0.8) on the 2D grid.
The solution should be saved to "solution_agent_kg_05.npz" containing 1D arrays x, y, and a 2D array u (shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T=0.8) should be saved as "solution_agent_kg_05.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T should be printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same grid should also be computed and printed.
