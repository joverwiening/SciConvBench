The task is to solve the 1D Reaction-Diffusion PDE numerically.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 10.0.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1), where x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
The method is Strang splitting for each full time step dt.
The first step is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
This involves computing u_hat(k) = FFT(u), then updating u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx), and finally computing u = IFFT(u_hat) taking the real part.
The second step is a reaction full-step of duration dt, solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
The exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third step is another diffusion half-step, identical to the first step.
The final solution u(x,T=1.0) on the periodic grid must be computed.
The solution must be saved to "solution_pdebench_reacdiff_nu10_rho10.npz" containing arrays x and u, and scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu10_rho10.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed.
