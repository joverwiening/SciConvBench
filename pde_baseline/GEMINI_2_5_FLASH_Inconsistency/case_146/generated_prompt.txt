The task is to solve the 1D Viscous Burgers equation numerically.
The unknown field is u(x,t).
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.1.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of a diffusion half-step (duration dt/2), an advection full-step (duration dt), and another diffusion half-step (duration dt/2).
The diffusion half-step is solved exactly in Fourier space.
The Fourier transform of u is u_hat(k).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The update for u_hat(k) is u_hat(k) * exp(-nu*k^2*(dt/2)).
The inverse Fourier transform of u_hat is u (take the real part).
The advection full-step for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 uses a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (periodic indexing), alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The update for u_new[j] is u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, u is replaced by u_new.
The time step dt is determined using CFL=0.4 based on an estimated max speed of 1.
dt0 is set to CFL*dx/1.0.
Nt is chosen as ceil(T/dt0).
dt is reset to T/Nt so that the final time T is hit exactly.
The solution u(x,T=1.0) on the periodic grid must be computed.
The solution must be saved to "solution_pdebench_burgers_nu0p1.npz".
The .npz file must contain arrays: x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_burgers_nu0p1.png".
The report must print min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
