The PDE to solve numerically is u_t + (-0.5)*u_x = 0.
The spatial domain is x in [0,1) periodic.
The temporal domain is t in [0,1.0].
The parameter a is -0.5.
The boundary conditions are periodic on x, specifically u(0,t)=u(1,t).
The initial condition is u(x,0)=exp(-100*(x-0.3)^2).
The spatial discretization uses a uniform periodic grid with Nx points.
A 1st-order upwind scheme is required; because a<0, a right-biased (downwind) stencil consistent with negative speed must be used.
Time integration uses Forward Euler.
The time step dt must be chosen such that max|a|*dt/dx <= 0.9 (CFL condition).
Boundary handling requires periodic wrap-around indexing.
The grid uses Nx=1000 points on [0,1) (periodic, no duplicated endpoint).
dx is calculated as 1/Nx.
dt0 is calculated as 0.9*dx/|a|.
Nt is calculated as ceil(T/dt0).
dt is set to T/Nt so the final time T is hit exactly.
The final time for computation and output is T=1.0.
Compute u(x, T=1.0) on the grid.

Report by printing min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Treat all functions exactly as written, using radians for trigonometric functions.
Interpret '^' as exponentiation in math and '**' for powers in Python code.
