The task is to numerically solve a 1D wave equation.
The partial differential equation is u_tt = (1.5)^2 * u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0,0.7].
The wave speed parameter c is 1.5.
The initial condition for u(x,0) is sin(2*pi*x).
The initial condition for u_t(x,0) is cos(2*pi*x).
The spatial discretization uses a uniform periodic grid with Nx=512 points on [0,1).
The spatial step dx is 1/Nx.
Second-order central differences with wrap-around are used for the u_xx term.
The time integration uses a second-order central difference scheme.
The CFL condition is c*dt/dx <= 0.9, where c is 1.5.
The initial time step dt0 is calculated as 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0), where T is 0.7.
The actual time step dt is T/Nt to hit the final time exactly.
The initialization for the first time step uses a Taylor expansion including v0 and the Laplacian of u0.
The solution u(x, T=0.7) on the grid must be computed.
The solution must be saved to a file named "solution_agent_wave_17.npz".
The npz file must contain 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_17.png".
The minimum value of u at T must be printed.
The maximum value of u at T must be printed.
The discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
