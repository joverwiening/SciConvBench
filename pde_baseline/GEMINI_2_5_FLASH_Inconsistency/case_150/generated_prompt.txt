The task is to solve the 1D Viscous Burgers equation numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 0.001.
The initial condition is u(x,0) = sin(2*pi*x).
A uniform periodic grid with Nx=512 points on [0,1) must be used.
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: Diffusion half-step (duration dt/2), Advection full-step (duration dt), and Diffusion half-step (duration dt/2).
The diffusion half-steps are solved exactly in Fourier space.
For the diffusion half-step, compute u_hat(k) = FFT(u).
The Fourier frequencies k are calculated as 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Then compute u = IFFT(u_hat) and take the real part.
The advection full-step solves the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
A finite-volume update with Rusanov (local Lax-Friedrichs) flux must be used for advection.
Define the flux function f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The advection update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
The time step dt is determined using CFL=0.4 based on an estimated max speed of 1.0.
Set dt0 = CFL*dx/1.0.
Choose Nt = ceil(T/dt0) and then reset dt = T/Nt to hit the final time exactly.
Compute u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_burgers_nu1em3.npz".
The npz file must contain arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu1em3.png".
Print min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
All functions must be treated exactly as written, using radians for trigonometric functions.
In code, interpret '^' as exponentiation using '**' for powers.
The grid convention for [a,b) with periodicity means Nx is the number of grid points with no duplicated endpoint, dx=(b-a)/Nx, and x_i=a+i*dx for i=0..Nx-1.
