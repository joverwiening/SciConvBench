The PDE is u_t = ∂/∂x( D(x) * u_x ), where D(x) = 0.01 + 0.09*x^2.
The spatial domain is x in [0,1] and the time domain is t in [0,0.2].
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0)=x*(1-x).
The spatial discretization uses a conservative 2nd-order discretization in flux form for (D(x) u_x)_x on a uniform grid x_i.
D_i is defined as D(x_i).
Face values are defined by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior points i=1..Nx-1, the discrete operator is ( (D u_x)_x )_i ≈ (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
The time integration uses Implicit Euler: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
The sparse linear system is solved at each time step.
The grid uses Nx=400 spatial intervals.
The time step is dt=0.0005, resulting in 480 steps.
The final solution u(x, T=0.2) is computed on the grid.
The solution is saved to "solution_agent_diffusion_02.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_diffusion_02.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
