Task ID: agent_wave_18
The PDE to solve numerically is u_tt = (1.0)^2 * u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The parameter c for the wave equation and CFL condition is 1.0.
The boundary conditions are Dirichlet on x=0 and x=1, with u=0.
The initial condition for u(x,0) is exp(-200*(x-0.5)^2).
The initial condition for u_t(x,0) is 0.
The spatial discretization uses a uniform grid on [0,1] with Nx=800 intervals (Nx+1 points).
The spatial step dx is 1/Nx.
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard 2nd-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen such that CFL = c*dt/dx ≤ 0.9, where c=1.0.
Specifically, dt0 = 0.9*dx/c, Nt = ceil(T/dt0), and dt = T/Nt to hit the final time exactly.
The initialization uses u(x,0)=u0(x).
u(x,dt) is computed using u_t(x,0)=v0(x) via the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value (0) at every time step.
The final time T is 1.0.
The computation requires u(x, T=1.0) on the grid.
The solution is saved to "solution_agent_wave_18.npz" containing arrays: x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_wave_18.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
