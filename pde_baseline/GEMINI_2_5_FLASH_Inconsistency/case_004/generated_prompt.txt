The task is to solve a 2D advection PDE numerically.
The PDE is u_t + (1.0)*u_x + (0.5)*u_y = 0.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions.
The time domain is t in [0,1.0].
The parameters are a = 1.0 and b = 0.5.
The initial condition is u(x,y,0)=sin(2*pi*x)*cos(2*pi*y).
The exact solution for verification is u(x,y,t)=sin(2*pi*(x-(1.0)*t))*cos(2*pi*(y-(0.5)*t)).
The numerical method requires a uniform periodic grid with Nx=Ny=256 points on [0,1) x [0,1).
Spatial discretization uses 1st-order upwind in both x and y directions.
Time integration uses Forward Euler.
The time step dt is determined by CFL condition |a|*dt/dx + |b|*dt/dy ≤ 0.9.
Specifically, dt0 = 0.9 / (|a|/dx + |b|/dy), Nt = ceil(T/dt0), and dt = T/Nt to hit the final time exactly.
Boundary handling uses periodic wrap-around indexing.
The final time for computation and output is T=1.0.
The output requirements include computing u(x,y,T) on the grid.
Save "solution_agent_advection_04.npz" containing 1D arrays x, y, and a 2D array u (shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_advection_04.png".
Report min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute and print the max absolute error and L2 error against the reference solution evaluated on the same grid.
