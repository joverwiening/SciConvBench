The number of steps should be adjusted. Use 500 steps.

The task is to solve the PDE numerically.
The PDE is u_t = 0.1 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.5].
The parameter D is 0.1.
The parameter beta is 1.0.
The boundary condition at x=0 is Robin: u_x(0,t) + 1.0*u(0,t) = 0.
The boundary condition at x=1 is Robin: u_x(1,t) + 1.0*u(1,t) = 0.
The initial condition is u(x,0)=cos(pi*x).
The spatial discretization uses a uniform grid with Nx=300 intervals.
2nd-order central differences are used for u_xx.
Robin boundary conditions are implemented with 2nd-order one-sided differences for u_x at the boundary.
At x=0 (i=0), u_x(0) is approximated by (-3*u0 + 4*u1 - u2)/(2*dx).
The boundary condition at x=0 is enforced as (-3*u0 + 4*u1 - u2)/(2*dx) + beta*u0 = 0.
At x=1 (i=Nx), u_x(1) is approximated by (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx).
The boundary condition at x=1 is enforced as (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx) + beta*uN = 0.
The time integration uses Crank–Nicolson for diffusion (2nd order in time).
The resulting linear system is solved each step using a direct solver.
The time step dt is 0.001.
The number of time steps is 500.
The final time T is 0.5.
The solution u(x, T=0.5) is computed on the grid.
The file "solution_agent_diffusion_05.npz" is saved, containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_diffusion_05.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
