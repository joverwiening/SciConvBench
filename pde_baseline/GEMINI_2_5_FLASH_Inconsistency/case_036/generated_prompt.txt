The task is to numerically solve a 1D heat equation.
The PDE is u_t = 0.1 * u_xx.
The spatial domain is x in [0, 1].
The temporal domain is t in [0, 0.5].
The parameter alpha = 0.1 should be defined in the code but not used in numerical calculations.
The parameter alpha should not be included in the metadata saved to the npz file.
The boundary condition at x=0 is Dirichlet: u(0,t) = sin(2*pi*t).
The boundary condition at x=1 is Dirichlet: u(1,t) = 0.
The initial condition is u(x,0) = 0 for all x in [0,1].
The spatial discretization uses a uniform grid on [0,1] with Nx=200 intervals, resulting in Nx+1 points including both boundaries.
Second-order central differences should be used for u_xx in the interior.
The time integration uses the Crank–Nicolson method for diffusion terms.
Dirichlet boundary conditions should be enforced by fixing boundary nodes at each time step.
The spatial step size is dx = 1/Nx.
The temporal step size is dt = 0.0005.
The total number of time steps is 1200.
The solution u(x, T=0.5) should be computed on the grid.
The solution should be saved to "solution_agent_heat_07.npz".
The npz file should contain arrays x (1D) and u (1D, same length as x), and scalar metadata T, dx, dt.
A line plot of u(x,T) should be saved as "solution_agent_heat_07.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T should be printed.
