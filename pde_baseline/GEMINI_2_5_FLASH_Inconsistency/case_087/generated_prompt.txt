Task ID is agent_wave_06.
The PDE category is Wave equation.
The unknown field is u(x,t).
The PDE to solve numerically is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The parameter c for the PDE is 1.0.
The boundary conditions are Neumann at x=0 and x=1: u_x(0,t)=0, u_x(1,t)=0.
The initial condition for u is u(x,0)=cos(pi*x).
The initial condition for u_t is u_t(x,0)=0.
The reference exact solution is u(x,t)=cos(pi*x)*cos(1.0*pi*t).
The spatial discretization uses a uniform grid on [0,1] with Nx intervals (Nx+1 points).
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard 2nd-order central difference in time (leapfrog / Störmer–Verlet).
For stability, dt is chosen so that CFL = c*dt/dx <= 0.9, where c=1.0.
Initialization uses u(x,0)=u0(x).
u(x,dt) is computed using u_t(x,0)=v0(x) via the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0).
Zero Neumann boundary conditions are implemented using ghost points (mirror values).
The grid uses Nx=400 intervals (Nx+1 points).
dx is 1/Nx.
dt0 is calculated as 0.9*dx/c, where c=1.0.
Nt is ceil(T/dt0).
dt is T/Nt so the final time is hit exactly.
The task requires computing u(x, T=1.0) on the grid.
The solution must be saved to "solution_agent_wave_06.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_06.png".
The report must print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
The report must also compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
