The PDE to solve numerically is u_t = 0.05 * (u_xx + u_yy).
The spatial domain for x is [0,1] with Dirichlet boundary conditions.
The spatial domain for y is [0,1) with periodic boundary conditions.
The temporal domain is t in [0,0.3].
The parameter alpha is 0.05.
The Dirichlet boundary conditions are u(0,y,t)=0 and u(1,y,t)=0.
The periodic boundary conditions in the y direction are u(x,0,t)=u(x,1,t) and u_y matches across y=0 and y=1.
The initial condition is u(x,y,0) = sin(pi*x)*cos(2*pi*y).
The reference exact solution for verification is u(x,y,t) = exp(-0.05*((pi)^2 + (2*pi)^2)*t) * sin(pi*x)*cos(2*pi*y).
The spatial discretization will use a tensor grid.
The x dimension will have Nx intervals including boundaries.
The y dimension will have Ny periodic points on [0,1).
Second-order central differences will be used for spatial discretization.
Periodic wrap will be applied in y and Dirichlet in x.
Implicit Euler will be used for time integration.
The grid will use Nx=60 for the Dirichlet x-dimension.
The grid will use Ny=64 for the periodic y-dimension.
The time step dt will be 0.001.
The simulation will run for 300 time steps.
The task requires computing u(x,y,T=0.3) on the 2D grid.
The solution will be saved to "solution_agent_heat_16.npz".
The .npz file will contain 1D arrays x and y, a 2D array u with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T, and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) will be saved as "solution_agent_heat_16.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed.
The maximum absolute error and L2 error against the reference solution evaluated on the same grid will be computed and printed.
