The PDE to solve is u_t + u*u_x + u_xx + u_xxxx = 0.
The spatial domain is x in [0, 2*pi) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The initial condition is u(x,0) = cos(x) + 0.1*cos(2*x).
The numerical method uses Fourier pseudo-spectral differentiation with Nx=1024 grid points.
Spatial derivatives u_x, u_xx, and u_xxxx are computed via Fast Fourier Transform.
The time integration uses a semi-implicit scheme in Fourier space.
The linear part (u_xx + u_xxxx) is treated implicitly.
The nonlinear part (u*u_x) is treated explicitly.
The time-stepping formula for each Fourier mode k is û^{n+1} = (û^n - dt * 𝔽[u*u_x]) / (1 - dt*( -k^2 + k^4 )).
The time step size is dt=1e-4, for a total of 12000 steps.
The Fourier wavenumbers k are defined as [0, 1, ..., Nx/2-1, -Nx/2, ..., -1] for Nx=1024.
The solution u(x, T=1.0) must be computed on the grid.
The solution must be saved to "solution_agent_other_04_kuramoto_sivashinsky.npz".
The .npz file must contain 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_other_04_kuramoto_sivashinsky.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
