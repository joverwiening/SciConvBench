The task is to numerically solve the 1D wave equation.
The PDE is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1].
The time domain is t in [0,0.8].
The wave speed c is 1.0.
Dirichlet boundary conditions are u=0 at x=0 and x=1.
The initial condition for u is u(x,0)=sin(pi*x) + 0.5*sin(3*pi*x).
The initial condition for u_t is u_t(x,0)=0.
The exact solution for verification is u(x,t)=cos(1.0*pi*t)*sin(pi*x) + 0.5*cos(1.0*3*pi*t)*sin(3*pi*x).
A uniform grid on [0,1] with Nx=600 intervals (Nx+1 points) must be used.
Spatial discretization uses 2nd-order central differences for u_xx in the interior.
Time integration uses the standard 2nd-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt must be chosen such that CFL = c*dt/dx ≤ 0.9.
Specifically, dt0 = 0.9*dx/c. Nt = ceil(T/dt0). dt = T/Nt.
Initialization for the first time step (u^1) uses the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Boundary handling for Dirichlet BC involves setting boundary nodes to the prescribed value (0) at every time step.
The final solution u(x, T=0.8) on the grid must be computed.
The solution must be saved to "solution_agent_wave_03.npz" containing arrays: x (1D), u (1D), and metadata scalars T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_03.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
The maximum absolute error and L2 error versus the reference solution (evaluated on the same x grid) must also be computed and printed.
