The task ID is molk_006.
The ODE category is a 3-state neural dynamics toy model.
The unknown fields are E, I, H, which are functions of t.
The ODE system to solve is dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t), dI/dt = delta*E - epsilon*I, and dH/dt = theta*I - phi*H.
The time domain is t in [0.0, 50.0].
The parameter alpha is 1.2.
The parameter beta is 1.0.
The parameter gamma is 0.5.
The parameter delta is 0.8.
The parameter epsilon is 0.7.
The parameter theta is 0.9.
The parameter phi is 0.4.
The initial condition for E(0.0) is 0.5.
The initial condition for I(0.0) is 0.2.
The initial condition for H(0.0) is 0.1.
The numerical method for time integration is Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step dt is 0.01.
The number of time steps Nt is 5000.
The full state vector at all time points t_n = t0 + n*dt for n=0..Nt must be computed.
The solution must be saved to "solution_molk_006.npz".
The "solution_molk_006.npz" file must contain arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns ordered as [E, I, H], and the parameter scalars.
Line plots of each state vs t must be saved as "solution_molk_006.png".
The final state values at T must be printed.
The minimum and maximum of each state over time must be printed.
