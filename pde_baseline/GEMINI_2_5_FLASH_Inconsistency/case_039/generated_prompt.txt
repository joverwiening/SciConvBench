The task is to numerically solve a 2D heat equation.
The PDE is u_t = 0.2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.2].
The parameter alpha is 0.2.
Dirichlet boundary conditions are applied on all boundary edges, with u=0.
The initial condition is u(x,y,0) = sin(2*pi*x)*sin(pi*y).
The reference exact solution is u(x,y,t) = exp(-0.2*((2*pi)^2 + (pi)^2)*t) * sin(2*pi*x)*sin(pi*y).
The spatial discretization uses a uniform grid on [0,1] x [0,1] with Nx=60 and Ny=60 intervals, resulting in 61x61 grid points.
The 5-point Laplacian (2nd-order) is used for spatial discretization.
Time integration uses Implicit Euler (backward Euler) for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each step.
A sparse linear system is solved for interior nodes.
The time step dt is 0.001.
The simulation runs for 200 time steps until the final time T=0.2.
The final solution u(x,y,T=0.2) is computed on the 2D grid.
The solution is saved to "solution_agent_heat_10.npz".
The .npz file contains 1D arrays x, y, a 2D array u (shape (len(y), len(x)) with u[j,i] = u(x[i], y[j]) at T), and scalar metadata T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) is saved as "solution_agent_heat_10.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T are printed.
The maximum absolute error and L2 error versus the reference solution (evaluated on the same grid) are computed and printed.
