The task ID is agent_wave_12.
The PDE category is Wave equation.
The unknown field is u(x,t).
The PDE to solve numerically is u_tt = (2.0)^2 * u_xx.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.5].
The wave speed parameter c is 2.0.
The boundary conditions are Dirichlet u=0 at x=0 and x=1.
The initial condition for u(x,0) is sin(pi*x).
The initial condition for u_t(x,0) is 0.
The reference exact solution is u(x,t)=cos(2.0*pi*t)*sin(pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx intervals (Nx+1 points).
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard 2nd-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen so that CFL = c*dt/dx is less than or equal to 0.9 for stability.
Initialization uses u(x,0)=u0(x).
u(x,dt) is computed using u_t(x,0)=v0(x) via the Taylor start formula: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value at every time step.
The grid uses Nx=400 intervals (Nx+1 points).
dx is 1/Nx.
dt0 is 0.9*dx/c.
Nt is ceil(T/dt0).
dt is T/Nt so the final time is hit exactly.
The computation should produce u(x, T=0.5) on the grid.
The solution should be saved to "solution_agent_wave_12.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) should be saved as "solution_agent_wave_12.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T should be printed.
