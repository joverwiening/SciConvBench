The task is to solve the 1D Viscous Burgers equation numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.04.
The initial condition is u(x,0) = sin(2*pi*x).
A uniform periodic spatial grid with Nx=512 points on [0,1) must be used, with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: Diffusion half-step (duration dt/2), Advection full-step (duration dt), and Diffusion half-step (duration dt/2).
The diffusion half-steps are solved exactly in Fourier space.
For the diffusion half-step, u_hat(k) is computed using FFT(u), k is 2*pi*fftfreq(Nx, d=dx), u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)), and u is obtained by IFFT(u_hat) taking the real part.
The advection full-step solves the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (periodic indexing), alpha is max(abs(u_left), abs(u_right)), and the flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]), F_minus is the flux between (u[j-1], u[j]), and u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, u is replaced by u_new.
The time step dt is determined using CFL=0.4 based on an estimated max speed ≈ 1 for the initial condition.
dt0 is set to CFL*dx/1.0.
Nt is chosen as ceil(T/dt0), and then dt is reset to T/Nt to hit the final time T exactly.
The solution u(x,T=1.0) must be computed on the periodic grid.
The results must be saved to "solution_pdebench_burgers_nu0p04.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_burgers_nu0p04.png".
The minimum value of u, maximum value of u, the discrete mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
