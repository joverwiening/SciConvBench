The PDE to solve is u_t = 0.1 * u_xx + sin(pi*x)*cos(2*pi*t).
The spatial domain is x in [0, 1].
The time domain is t in [0, 1.0].
The parameter alpha is 0.1.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0) = 0.
The spatial discretization uses a uniform grid on [0,1] with Nx=300 intervals, resulting in Nx+1 points.
Second-order central differences are used for u_xx in the interior.
The time integration uses Crank–Nicolson for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step.
The time step is dt=0.001.
The simulation runs until T=1.0, which means 1000 time steps.
The source term is included at the appropriate time level for Crank–Nicolson, by averaging f^n and f^{n+1}.
The task requires computing u(x, T=1.0) on the grid.
The solution should be saved to "solution_agent_heat_08.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
