The task is to solve a 2D advection Partial Differential Equation numerically.
The unknown field is u(x,y,t).
The PDE is u_t + (-0.7)*u_x + (1.2)*u_y = 0.
The spatial domain is (x,y) in [0,1) x [0,1) with periodic boundary conditions.
The temporal domain is t in [0,0.5].
The parameters are a = -0.7 and b = 1.2.
The initial condition is u(x,y,0)=exp(-80*((x-0.2)^2 + (y-0.6)^2)).
The spatial discretization should use upwind with direction chosen by the sign of a and b (a<0 uses right-biased in x; b>0 uses left-biased in y).
The time integration should use Forward Euler with dt satisfying CFL: |a|*dt/dx + |b|*dt/dy ≤ 0.9.
Boundary handling should use periodic wrap-around indexing in both directions.
The grid should use Nx=Ny=256 points on [0,1) x [0,1) (periodic, no duplicated endpoints).
dx=dy=1/Nx.
dt0 should be calculated as 0.9 / (|a|/dx + |b|/dy).
Nt should be calculated as ceil(T/dt0).
dt should be set to T/Nt so the final time is hit exactly.
The final time T for the simulation, computation, and saving is 0.5.
The solution u(x,y,T=0.5) on the 2D grid must be computed.
The solution must be saved as "solution_agent_advection_05.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_advection_05.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
