The task is to numerically solve the advection PDE u_t + (1.0)*u_x = 0.
The unknown field is u(x,t).
The spatial domain is x in [0,1) with periodic boundary conditions.
The temporal domain is t in [0,1.0].
The parameter 'a' is 1.0.
The initial condition is u(x,0)=sin(2*pi*x).
The exact solution for verification is u(x,t)=sin(2*pi*(x-(1.0)*t)).
A uniform periodic grid with Nx=800 points on [0,1) will be used, with dx=1/Nx.
The spatial derivative u_x will be discretized using 1st-order upwind.
Time integration will use Forward Euler.
The time step dt will be chosen such that max|a|*dt/dx ≤ 0.9.
Specifically, dt0 = 0.9*dx/|a|, Nt = ceil(T/dt0), and dt = T/Nt to hit the final time exactly.
Boundary handling will use periodic wrap-around indexing.
The final time T for the simulation is 1.0.
The computation of u(x,T) should be performed at T=1.0.
The solution u(x, T=1.0) on the grid will be computed.
The arrays x (1D) and u (1D), along with metadata scalars T, dx, dt, will be saved to "solution_agent_advection_01.npz".
A line plot of u(x,T) will be saved as "solution_agent_advection_01.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T will be printed.
The maximum absolute error and L2 error against the reference solution (evaluated on the same x grid) will also be computed and printed.
