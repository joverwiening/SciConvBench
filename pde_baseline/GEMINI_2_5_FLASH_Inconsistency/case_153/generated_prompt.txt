Solve the PDE numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The domain for x is [0, 1) with periodic boundary conditions.
The domain for t is [0, 1.0].
The parameter nu is 4.0.
The boundary conditions are periodic, u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
A closed-form reference solution is not required.
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps: (A) Diffusion half-step, (B) Advection full-step, (C) Diffusion half-step.
For the diffusion half-step (duration dt/2), solve exactly in Fourier space.
Transform u to u_hat using FFT.
Define k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Transform u_hat back to u using IFFT, taking the real part.
For the advection full-step (duration dt), use a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, calculate F_plus as the flux between (u[j], u[j+1]) and F_minus as the flux between (u[j-1], u[j]).
Update u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Replace u with u_new after the advection substep.
The time step is determined using CFL=0.4 based on an estimated max speed of 1 for the initial condition.
Calculate dt0 = CFL*dx/1.0.
Determine Nt = ceil(T/dt0).
Reset dt = T/Nt to hit the final time exactly.
Compute u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_burgers_nu4.npz".
The .npz file must contain arrays: x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu4.png".
Print the minimum value of u, the maximum value of u, the discrete mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T.
