The task is to numerically solve the 1D inviscid Burgers equation.
The PDE is u_t = -k*∂_x( 0.5*u^2 ).
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is uniform and periodic with Nx=1024 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1.
The spatial step size dx is 1/Nx.
The spatial discretization is a conservative finite-volume method.
The flux function is f(u)=0.5*u^2.
The Rusanov (local Lax–Friedrichs) flux is used for the spatial discretization.
The time integration method is SSP-RK2 (Heun).
The time step dt is fixed.
The initial time step estimate dt0 is calculated as CFL*dx/max|u|, with CFL=0.2 and max|u| estimated as 1.
The number of time steps Nt is ceil(T/dt0).
The fixed time step dt is T/Nt.
The final solution u(x,T=0.2) on the periodic grid must be computed.
The solution must be saved to "solution_molk_025.npz".
The .npz file must contain arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, and k.
A line plot of u(x,T) must be saved as "solution_molk_025.png".
The minimum, maximum, mean, and discrete L2 norm (sqrt(sum(u^2)*dx)) of u at T must be printed.
All functions are to be treated exactly as written, using radians for trigonometric functions.
The '^' symbol in math denotes exponentiation.
In Python code, '**' should be used for powers.
