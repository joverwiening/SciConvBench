The task is to solve the 2D wave equation numerically.
The PDE is u_tt = (1.0)^2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.5].
The wave speed parameter c is 1.0.
Dirichlet boundary conditions are applied on all boundaries, with u=0.
The initial condition for u is u(x,y,0)=sin(pi*x)*sin(2*pi*y).
The initial condition for u_t is u_t(x,y,0)=0.
The reference exact solution for verification is u(x,y,t)=cos(1.0*pi*sqrt(5)*t)*sin(pi*x)*sin(2*pi*y).
A uniform grid on [0,1] x [0,1] will be used with Nx=160 and Ny=160 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The spatial discretization will use the 5-point Laplacian for ∇²u.
The time integration will use a 2nd-order central difference for u_tt.
The time step dt will be chosen for stability such that CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9.
Specifically, dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)), Nt = ceil(T/dt0), and dt = T/Nt.
The first time step u(t=dt) will be computed using a Taylor start with the initial velocity.
Boundary nodes will be set to 0 at each time step for Dirichlet BC.
The final solution u(x,y,T=0.5) on the 2D grid will be computed.
The solution will be saved to "solution_agent_wave_15.npz" containing arrays x (1D), y (1D), u (2D array with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T), and metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) will be saved as "solution_agent_wave_15.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T will be printed.
The maximum absolute error and L2 error against the reference solution evaluated on the same grid will also be computed and printed.
