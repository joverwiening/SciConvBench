Solve the PDE numerically.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The domain is x in [0, 1) with periodic boundary, t in [0, 1.0].
The parameters are nu = 10.0 and rho = 2.0.
The boundary conditions are periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
No closed-form reference solution is required.
The time integration uses the detailed Strang splitting method.
The spatial grid is uniform periodic with Nx=512 points on [0,1).
Use x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The time grid uses fixed dt=0.001 with Nt=1000 steps so that T is reached exactly.
The method is Strang splitting each full time step dt:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space: u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- IFFT(u_hat) (take the real part).
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE: du/dt = rho*u*(1-u), Exact update for each grid point: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (same as A).
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_reacdiff_nu10_rho2.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu10_rho2.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
