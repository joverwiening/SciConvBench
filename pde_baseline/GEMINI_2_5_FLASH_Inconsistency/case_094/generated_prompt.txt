The task is to numerically solve the 1D wave equation.
The PDE is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1] and the time domain is t in [0,0.25].
The wave speed c is 1.0.
Dirichlet boundary conditions are u=0 at x=0 and x=1.
The initial condition for u is u(x,0)=sin(4*pi*x).
The initial condition for u_t is u_t(x,0)=0.
The reference exact solution is u(x,t)=cos(1.0*4*pi*t)*sin(4*pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx intervals (Nx+1 points).
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen for stability such that CFL = c*dt/dx <= 0.9, where c is 1.0.
Initialization uses u(x,0)=u0(x).
u(x,dt) is computed using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value at every time step.
The grid uses Nx=800 intervals (Nx+1 points).
dx is 1/Nx.
dt0 is calculated as 0.9*dx/c, where c is 1.0.
Nt is ceil(T/dt0).
dt is T/Nt, ensuring the final time T is hit exactly.
The numerical solution u(x, T=0.25) is to be computed on the grid.
The solution is to be saved to "solution_agent_wave_13.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) is to be saved as "solution_agent_wave_13.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are to be printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same x grid are to be computed and printed.
