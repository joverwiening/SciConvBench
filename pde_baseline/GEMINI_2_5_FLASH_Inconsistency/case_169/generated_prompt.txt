Task ID: pdebench_darcy_beta1.
The PDE category is 2D Darcy flow (elliptic).
The unknown field is u(x,y).
Solve the PDE numerically.
Treat all functions exactly as written (use radians for trig).
Interpret '^' as exponentiation in the math; when writing code in Python, use '**' for powers.
If the spatial domain is written as a closed interval [a,b], interpret Nx (and Ny, Nz) as the number of uniform intervals so there are Nx+1 grid points including both endpoints; dx=(b-a)/Nx and x_i=a+i*dx.
The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The domain is (x,y) in (0,1) x (0,1).
The parameter beta = 2.
The deterministic coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Dirichlet boundary conditions are applied on the entire boundary: u = 0 on ∂((0,1) x (0,1)).
No closed-form reference solution is required.
Verify the solution by checking the discrete residual norm.
Use a uniform Cartesian grid with N=128 intervals in each direction (N+1 points including boundaries).
dx = dy = 1/N.
Use x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Use 2nd-order finite differences with variable coefficient using face-centered harmonic averaging for discretization.
For interior nodes (i=1..N-1, j=1..N-1), discretize: -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
The face coefficients are harmonic means, e.g. a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)) (and similarly for other faces).
Assemble the sparse linear system Au=b for the interior unknowns.
Solve the linear system with conjugate gradient (CG) to tolerance 1e-10 (relative residual).
A simple Jacobi preconditioner may be used.
Compute u(x,y) on the full (N+1) x (N+1) grid (including boundaries).
Save "solution_pdebench_darcy_beta1.npz" containing arrays: x (1D), y (1D), u (2D shape [N+1, N+1]), and scalars beta, N, dx.
Save a heatmap/contour plot of u(x,y) as "solution_pdebench_darcy_beta1.png".
Print min(u), max(u), and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system.
