Solve the 2D Darcy flow PDE numerically.
The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1.
The domain is (x,y) in (0,1) x (0,1).
The parameter beta is 0.1.
The coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Dirichlet boundary conditions are applied, with u = 0 on the entire boundary ∂((0,1) x (0,1)).
No closed-form reference solution is required; verify by checking the discrete residual norm.
Use a uniform Cartesian grid with N=128 intervals in each direction, resulting in N+1 points including boundaries.
The grid spacing is dx = dy = 1/N.
Grid points are x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize using 2nd-order finite differences with variable coefficient using face-centered harmonic averaging.
For interior nodes (i=1..N-1, j=1..N-1), discretize as -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Face coefficients are harmonic means, e.g., a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknowns.
Solve the linear system with conjugate gradient (CG) to a relative residual tolerance of 1e-10.
A simple Jacobi preconditioner may be used.
Compute u(x,y) on the full (N+1) x (N+1) grid, including boundaries.
Save "solution_pdebench_darcy_beta0p1.npz" containing arrays: x (1D), y (1D), u (2D shape [N+1, N+1]), and scalars beta, N, dx.
Save a heatmap/contour plot of u(x,y) as "solution_pdebench_darcy_beta0p1.png".
Print min(u), max(u), and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system.
