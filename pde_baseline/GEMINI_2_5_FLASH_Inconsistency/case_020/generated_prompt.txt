The PDE to solve numerically is u_t = ∇·( D(x,y) ∇u ).
The diffusion coefficient is D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.1].
Dirichlet boundary conditions u=0 are applied on all boundary edges.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y).
The spatial discretization uses a conservative 2nd-order method in flux form on a uniform grid.
Arithmetic face averages are used for the diffusion coefficient: D_{i+1/2,j}=0.5*(D_{i,j}+D_{i+1,j}) and D_{i,j+1/2}=0.5*(D_{i,j}+D_{i,j+1}).
The discrete operator for interior nodes is (∇·(D∇u))_{i,j} ≈ (1/dx^2)[ D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}(u_{i,j}-u_{i-1,j}) ] + (1/dy^2)[ D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}(u_{i,j}-u_{i,j-1}) ].
Time integration uses Implicit Euler: (I - dt*L) u^{n+1} = u^n, where L is the discrete diffusion operator.
The sparse linear system is solved at each time step.
The grid resolution is Nx=80 and Ny=80.
The time step size is dt=0.0005.
The simulation runs for 200 time steps.
The final solution u(x,y,T=0.1) on the 2D grid must be computed.
The solution must be saved to "solution_agent_diffusion_04.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_diffusion_04.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
