The task is to numerically solve the 1D Viscous Burgers PDE.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
Time integration uses Strang splitting for each full time step dt.
The Strang splitting consists of a diffusion half-step, an advection full-step, and another diffusion half-step.
The diffusion half-steps are solved exactly in Fourier space.
For the diffusion half-step, compute u_hat(k) from FFT(u).
The wave numbers k are 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) by multiplying with exp(-nu*k^2*(dt/2)).
Then compute u from IFFT(u_hat) and take the real part.
The advection full-step solves the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
It uses a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
The flux function f(u) is 0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The cell update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The array u is replaced by u_new after the advection substep.
The time step dt is determined using CFL=0.4 based on an estimated max speed of 1.0.
Calculate dt0 = CFL*dx/1.0.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is reset to T/Nt to hit the final time exactly.
The final solution u(x,T=1.0) on the periodic grid must be computed.
Save the solution to "solution_pdebench_burgers_nu1.npz".
The .npz file must contain arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu1.png".
Report min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
All functions must be treated exactly as written, using radians for trigonometric functions.
The '^' symbol in math denotes exponentiation.
The grid convention for [a,b) with periodicity means Nx is the number of grid points with no duplicated endpoint.
dx=(b-a)/Nx and x_i=a+i*dx for i=0..Nx-1.
