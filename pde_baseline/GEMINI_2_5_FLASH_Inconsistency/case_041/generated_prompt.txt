The task is to numerically solve a 2D heat equation.
The PDE is u_t = 0.1 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.2].
The parameter alpha is 0.1.
Neumann boundary conditions (zero-flux, ∂u/∂n = 0) are applied on all boundary edges.
The initial condition is u(x,y,0) = cos(pi*x)*cos(pi*y).
The reference exact solution is u(x,y,t) = exp(-2*0.1*pi^2*t) * cos(pi*x)*cos(pi*y).
The spatial discretization uses a uniform grid with Nx=Ny=60 intervals.
The 5-point Laplacian is used for interior nodes.
Zero Neumann boundary conditions are implemented using ghost nodes (mirror values) for 2nd-order accuracy.
The time integration method is Implicit Euler.
The time step dt is 0.001.
The simulation runs for 200 time steps to reach T=0.2.
The final solution u(x,y,T=0.2) on the 2D grid must be computed.
The solution must be saved to "solution_agent_heat_12.npz".
The .npz file must contain 1D arrays x, y, and a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T.
The .npz file must also contain metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_heat_12.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The maximum absolute error and L2 error against the reference solution evaluated on the same grid must be computed and printed.
