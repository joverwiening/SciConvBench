The task is to numerically solve a 1D Reaction-Diffusion PDE.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
The time integration method is Strang splitting for each full time step dt.
Each Strang splitting step consists of three sub-steps.
The first sub-step is a diffusion half-step of duration dt/2, solved exactly in Fourier space.
For the diffusion half-step, compute u_hat(k) by taking the FFT of u.
The wave numbers k are computed as 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) by multiplying it with exp(-nu*k^2*(dt/2)).
Transform u_hat back to real space by taking the IFFT and keeping the real part.
The second sub-step is a reaction full-step of duration dt, solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u).
For the reaction full-step, update each grid point u using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third sub-step is another diffusion half-step, identical to the first sub-step.
The final solution u(x,T=1.0) on the periodic grid must be computed.
Save the solution to a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz".
The .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu0p5_rho10.png".
Print the minimum value of u at T.
Print the maximum value of u at T.
Print the mean value of u at T.
Print the discrete L2 norm sqrt(sum(u^2)*dx) at T.
