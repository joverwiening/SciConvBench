The PDE to solve numerically is u_tt = (1.0)^2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1] and the time domain is t in [0,1.0].
The wave speed parameter c is 1.0.
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y) and u_t(x,y,0)=0.
The reference exact solution for verification is u(x,y,t)=cos(1.0*sqrt(2)*pi*t)*sin(pi*x)*sin(pi*y).
The spatial discretization uses a uniform grid on [0,1] x [0,1] with Nx=120 and Ny=120 intervals, resulting in Nx+1 by Ny+1 grid points.
The 5-point Laplacian is used for the spatial discretization of ∇²u.
Time integration uses a 2nd-order central difference for u_tt.
The time step dt is chosen such that the CFL condition c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9 is met, with c=1.0.
Specifically, dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)), Nt = ceil(T/dt0), and dt = T/Nt to hit the final time exactly.
The first time step is computed using a Taylor start with the initial velocity.
For Dirichlet boundary conditions, boundary nodes are set at each time step.
The numerical solution u(x,y,T=1.0) on the 2D grid must be computed.
The solution must be saved to "solution_agent_wave_07.npz" containing 1D arrays x, y, and a 2D array u (shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T), along with metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_wave_07.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The maximum absolute error and L2 error against the reference solution evaluated on the same grid must also be computed and printed.
