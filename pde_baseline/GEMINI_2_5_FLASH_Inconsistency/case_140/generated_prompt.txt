The task is to solve the 1D Advection PDE numerically.
The PDE is u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 2.0].
The parameter beta is 2.0.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
The spatial grid is uniform with Nx=512 intervals on [0,1), meaning Nx points.
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization is 1st-order upwind finite difference for u_x, using the upwind direction determined by the sign of beta.
The time integration method is Explicit forward Euler.
The time step is determined by CFL=0.5.
Calculate dt = CFL * dx / abs(beta).
Calculate the number of time steps Nt = ceil(T/dt).
Reset dt = T/Nt to hit the final time exactly.
Compute the numerical solution u(x,T=2.0) on the periodic grid.
Save the solution to "solution_pdebench_advection_beta2.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta2.png".
Report min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
