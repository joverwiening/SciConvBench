The task is to solve the PDE numerically.
The PDE is u_t = (0.02)^2*(u_xx + u_yy) + u - u^3.
The unknown field is u(x,y,t).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.1].
The parameter epsilon is 0.02.
Dirichlet boundary conditions are applied on all boundaries, with u=0.
The initial condition is u(x,y,0)=tanh((0.25 - r)/(sqrt(2)*0.02)), where r = sqrt((x-0.5)^2 + (y-0.5)^2).
The time integration method is semi-implicit: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
A sparse linear system must be solved at each time step.
The spatial discretization uses a uniform grid with a 5-point Laplacian for u_xx+u_yy.
Boundary conditions are enforced by setting boundary nodes to the prescribed values at every time step.
The grid uses Nx=Ny=300.
The time step dt is 0.0001, resulting in 1000 steps.
The final solution u(x,y,T=0.1) on the 2D grid must be computed.
The solution must be saved to "solution_agent_allen_cahn_05.npz".
The .npz file must contain 1D arrays x, y, and a 2D array u (shape (len(y), len(x)) with u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_allen_cahn_05.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The grid convention for a closed interval [a,b] means Nx (and Ny) is the number of uniform intervals, so there are Nx+1 grid points including both endpoints; dx=(b-a)/Nx and x_i=a+i*dx.
All functions must be treated exactly as written, using radians for trigonometric functions.
The '^' symbol in math should be interpreted as exponentiation.
