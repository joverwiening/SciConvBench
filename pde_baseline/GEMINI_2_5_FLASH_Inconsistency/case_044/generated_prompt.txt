The PDE to be solved numerically is u_t = 0.05 * u_xx.
The spatial domain is x in [0,1] and the temporal domain is t in [0,0.2].
The parameter alpha is 0.05.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0) = exp(-200*(x-0.35)^2).
A uniform grid on [0,1] with Nx intervals (Nx+1 points including both boundaries) will be used for spatial discretization.
Second-order central differences will be used for u_xx in the interior.
Crank–Nicolson will be used for time integration of diffusion terms.
Dirichlet boundary conditions will be enforced by fixing boundary nodes at each time step.
The number of spatial intervals Nx is 400.
The time step dt is 0.0005, resulting in 480 steps.
The solution u(x, T=0.2) will be computed on the specified grid.
The solution will be saved to "solution_agent_heat_15.npz" containing arrays: x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
A line plot of u(x,T) will be saved as "solution_agent_heat_15.png".
The minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T will be printed.
