The PDE to be solved numerically is u_tt = (1.0)^2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.8].
The wave speed parameter c to be used in the numerical method and CFL condition is 1.0.
Neumann boundary conditions (∂u/∂n = 0) are applied on all boundaries.
The initial condition for u is u(x,y,0)=cos(pi*x)*cos(pi*y).
The initial condition for u_t is u_t(x,y,0)=0.
The reference exact solution for verification is u(x,y,t)=cos(pi*x)*cos(pi*y)*cos(1.0*sqrt(2)*pi*t).
A uniform grid on [0,1] x [0,1] with Nx=140 and Ny=140 intervals (Nx+1 by Ny+1 points) should be used for spatial discretization.
The 5-point Laplacian should be used for ∇²u.
Second-order central difference in time should be used for u_tt.
The time step dt should be chosen such that CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9, where c=1.0.
The value of dx is 1/Nx and dy is 1/Ny.
The time step dt0 is calculated as 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
The number of time steps Nt is ceil(T/dt0), and the final dt is T/Nt to hit the final time exactly.
u at the first step should be computed using the Taylor start with the initial velocity.
Zero Neumann boundary conditions should be implemented with ghost nodes (mirror values).
The numerical solution u(x,y,T=0.8) on the 2D grid should be computed.
The solution should be saved to "solution_agent_wave_16.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) should be saved as "solution_agent_wave_16.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T should be printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same grid should also be computed and printed.
