The task is to solve the 1D Viscous Burgers PDE numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The initial condition is u(x,0) = sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The time integration uses Strang splitting for each full time step dt.
The Strang splitting consists of three substeps:
First, a diffusion half-step of duration dt/2 is solved exactly in Fourier space.
This involves computing the FFT of u to get u_hat(k), where k = 2*pi*fftfreq(Nx, d=dx).
Then, u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, the inverse FFT of u_hat is computed, and its real part is taken as the new u.
Second, an advection full-step of duration dt is performed for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
This uses a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), alpha is calculated as max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The cell value u_new[j] is updated as u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, u is replaced by u_new.
Third, another diffusion half-step (same as the first) is performed.
The time step dt is determined using CFL=0.4 based on an estimated max speed of 1.
dt0 is set to CFL*dx/1.0.
Nt is chosen as ceil(T/dt0), and then dt is reset to T/Nt to hit the final time exactly.
The final solution u(x,T=1.0) on the periodic grid must be computed.
The results must be saved to "solution_pdebench_burgers_nu2.npz" containing arrays x, u, and scalars nu, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_burgers_nu2.png".
The minimum value of u, maximum value of u, the discrete mean value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
