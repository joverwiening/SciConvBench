The task is to solve a 2D heat equation numerically in Python.
The PDE is u_t = 0.1 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,1.0].
The parameter alpha is 0.1.
Dirichlet boundary conditions are u(x,y,t) = x + y on all boundary edges for all t.
The initial condition is u(x,y,0) = x + y for all interior points.
The reference exact solution is u(x,y,t) = x + y.
The spatial discretization uses a uniform grid on [0,1] x [0,1] with Nx=40 and Ny=40 intervals, resulting in (Nx+1) by (Ny+1) grid points.
The 5-point Laplacian (2nd-order) should be used for spatial discretization.
Time integration uses Implicit Euler (backward Euler) for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step.
A sparse linear system for interior nodes should be solved using a reasonable assumption based on best practices for the solver.
The time step is dt=0.01.
The simulation runs for a final time of T=1.0, which corresponds to 100 time steps.
The solution u(x,y,T=1.0) on the 2D grid should be computed.
The solution should be saved to "solution_agent_heat_18.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) should be saved as "solution_agent_heat_18.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T should be printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same grid should be computed and printed.
