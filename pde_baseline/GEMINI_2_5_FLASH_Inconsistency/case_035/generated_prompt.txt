The partial differential equation to solve is u_t = 0.1 * u_xx.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 0.5].
The diffusion coefficient alpha is 0.1.
Dirichlet boundary conditions are applied at x=0 and x=1 for all t, with u(0,t)=1 and u(1,t)=0.
The initial condition is u(x,0) = 1 - x.
The exact solution for verification is u(x,t) = 1 - x.
A uniform grid on [0,1] with Nx intervals and Nx+1 points including boundaries will be used.
Second-order central differences will be used for u_xx in the interior.
Crank–Nicolson time integration will be used for diffusion terms.
Dirichlet boundary conditions will be enforced by fixing boundary nodes at each time step.
The number of spatial intervals Nx is 200, resulting in dx=1/Nx.
The time step dt is 0.001, leading to 600 time steps.
The numerical solution u(x, T=0.5) will be computed on the specified grid.
The solution will be saved to "solution_agent_heat_06.npz" containing 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) will be saved as "solution_agent_heat_06.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at time T will be printed.
The maximum absolute error and L2 error against the reference solution, evaluated on the same x grid, will be computed and printed.
