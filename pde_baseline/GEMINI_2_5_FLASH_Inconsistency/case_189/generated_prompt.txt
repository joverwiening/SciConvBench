The task is to solve the 1D Reaction-Diffusion PDE numerically.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 5.0.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical method is Strang splitting for each full time step dt.
The spatial grid is uniform periodic with Nx=512 points on [0,1), using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
The Strang splitting method consists of three steps:
(A) Diffusion half-step (duration dt/2) solved exactly in Fourier space: u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- IFFT(u_hat) (take the real part).
(B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u) using the update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
(C) Diffusion half-step again (same as A).
The task requires computing u(x,T=1.0) on the periodic grid.
The task requires saving "solution_pdebench_reacdiff_nu5_rho10.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
The task requires saving a line plot of u(x,T) as "solution_pdebench_reacdiff_nu5_rho10.png".
The task requires printing min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
