The task is to solve the 1D Reaction-Diffusion PDE numerically.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1), where x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
The time integration method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps: (A) Diffusion half-step (duration dt/2) solved exactly in Fourier space, (B) Reaction full-step (duration dt) solved exactly pointwise for the logistic ODE, and (C) another Diffusion half-step (duration dt/2).
For the diffusion half-step, u_hat(k) is computed using FFT(u), k is defined as 2*pi*fftfreq(Nx, d=dx), u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)), and u is obtained by IFFT(u_hat) taking the real part.
For the reaction full-step, the exact update for each grid point is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The task requires computing u(x,T=1.0) on the periodic grid.
The solution must be saved to "solution_pdebench_reacdiff_nu0p5_rho5.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_reacdiff_nu0p5_rho5.png".
The minimum, maximum, mean of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
