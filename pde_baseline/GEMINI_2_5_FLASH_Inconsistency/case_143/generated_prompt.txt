The task is to solve the 1D Viscous Burgers PDE numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter nu is 0.01.
The initial condition is u(x,0) = sin(2*pi*x).
A uniform periodic spatial grid with Nx=512 points on [0,1) must be used, with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
For the diffusion half-step (A and C), the solution is found exactly in Fourier space.
This involves computing the FFT of u to get u_hat(k), where k = 2*pi*fftfreq(Nx, d=dx).
Then, u_hat(k) is updated as u_hat(k) * exp(-nu*k^2*(dt/2)).
Finally, u is obtained by taking the real part of the IFFT of u_hat.
For the advection full-step (B), a finite-volume update with Rusanov (local Lax-Friedrichs) flux must be used for the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
The flux function is f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (using periodic indexing), alpha is defined as max(abs(u_left), abs(u_right)).
The Rusanov flux F is calculated as 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The update rule for u_new[j] is u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, u is replaced by u_new.
The time step dt is determined using a CFL condition.
CFL is 0.4, based on an estimated max speed of 1 for the initial condition.
dt0 is set to CFL*dx/1.0.
Nt is chosen as ceil(T/dt0), and then dt is reset to T/Nt to hit the final time T exactly.
The final simulation time T is 1.0.
The task requires computing u(x,T=1.0) on the periodic grid.
The solution must be saved to "solution_pdebench_burgers_nu0p01.npz" as a NumPy compressed archive.
This .npz file must contain the arrays x (1D length Nx) and u (1D length Nx), and the scalars nu, T, dx, dt, Nx, Nt.
A line plot of u(x,T) must be saved as "solution_pdebench_burgers_nu0p01.png".
The report must print min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
