The task is to numerically solve a 2D wave equation.
The PDE is u_tt = c^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t).
The wave speed parameter c is 1.0.
The spatial domain is [0,1] x [0,1].
The time domain is [0,1.0].
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition for u is u(x,y,0)=0.
The initial condition for u_t is u_t(x,y,0)=0.
A uniform grid is used on [0,1] x [0,1] with Nx=120 and Ny=120 intervals.
This results in Nx+1 by Ny+1 grid points.
The spatial step sizes are dx = 1/Nx and dy = 1/Ny.
The 5-point Laplacian is used for spatial discretization of ∇²u.
Second-order central difference is used for time integration of u_tt.
The time step dt is chosen for stability such that CFL = c*dt*sqrt(1/dx^2+1/dy^2) ≤ 0.9.
Specifically, dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)) is calculated.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt to hit the final time exactly.
u at the first step is computed using the Taylor start with the initial velocity.
Boundary nodes are set to the Dirichlet BC value at each time step.
The solution u(x,y,T=1.0) on the 2D grid must be computed.
The solution must be saved to "solution_agent_wave_11.npz".
The npz file must contain 1D arrays x, y, and a 2D array u with shape (len(y), len(x)) such that u[j,i] = u(x[i], y[j]) at T.
The npz file must also contain metadata scalars T, dx, dy, dt.
A heatmap or contour plot of u(x,y,T) must be saved as "solution_agent_wave_11.png".
The minimum value of u at T must be printed.
The maximum value of u at T must be printed.
The discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
