The task is to solve the 1D Reaction-Diffusion PDE numerically.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical method uses a uniform periodic spatial grid with Nx=512 points on [0,1).
The spatial grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The time grid uses a fixed dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
The time integration method is Strang splitting for each full time step dt.
The Strang splitting consists of three steps: Diffusion half-step (dt/2), Reaction full-step (dt), Diffusion half-step (dt/2).
The diffusion half-step is solved exactly in Fourier space.
For the diffusion half-step, compute u_hat(k) = FFT(u).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) = u_hat(k) * exp(-nu*k^2*(dt/2)).
Then compute u = IFFT(u_hat) and take the real part.
The reaction full-step solves du/dt = rho*u*(1-u) exactly pointwise.
The exact update for each grid point is u = (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The final output requires computing u(x,T=1.0) on the periodic grid.
Save the solution to "solution_pdebench_reacdiff_nu2_rho5.npz".
The npz file must contain arrays: x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu2_rho5.png".
Report by printing min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
