The task is to solve the 1D wave equation numerically.
The PDE is u_tt = c^2 * u_xx + sin(pi*x)*sin(2*pi*t).
The wave speed c is 1.0.
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
Dirichlet boundary conditions are applied at x=0 and x=1, with u=0.
The initial condition for u(x,0) is 0.
The initial condition for u_t(x,0) is 0.
The spatial discretization uses a uniform grid on [0,1] with Nx=400 intervals, resulting in Nx+1 points.
The spatial step size dx is 1/Nx.
Second-order central differences are used for u_xx in the interior.
Time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen for stability such that CFL = c*dt/dx <= 0.9.
Specifically, dt0 = 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt to hit the final time exactly.
Initialization for u(x,dt) uses the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0).
Boundary nodes for Dirichlet BC are set to the prescribed value at every time step.
The simulation computes u(x, T=1.0) on the grid.
The solution is saved to "solution_agent_wave_10.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
A line plot of u(x,T) is saved as "solution_agent_wave_10.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T are printed.
All functions are treated exactly as written, using radians for trigonometric functions.
The symbol '^' denotes exponentiation in mathematical expressions.
