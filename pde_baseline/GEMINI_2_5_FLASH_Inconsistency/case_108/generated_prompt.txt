The task is to numerically solve an ODE system.
The ODE system is dx/dt = y and dy/dt = mu*(1 - x**2)*y - x.
The time domain is from 0.0 to 20.0.
The parameter mu is 4.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 0.0.
The numerical method for time integration is Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step dt is 0.01.
The number of time steps Nt is 2000.
The full state vector at all time points t_n = t0 + n*dt for n=0..Nt must be computed.
The solution must be saved to "solution_molk_007.npz".
The "solution_molk_007.npz" file must contain arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns ordered as [x, y], and the parameter scalars.
Line plots of each state vs t must be saved as "solution_molk_007.png".
The final state values at T must be printed.
The minimum and maximum of each state over time must be printed.
