The task is to numerically solve a 2D wave equation.
The PDE is u_tt = (0.7)^2 * (u_xx + u_yy).
The spatial domain is [0,1] x [0,1].
The time domain is [0,0.8].
Dirichlet boundary conditions u=0 are applied on all boundaries.
The initial condition for u is u(x,y,0)=sin(2*pi*x)*sin(pi*y).
The initial condition for u_t is u_t(x,y,0)=0.
The reference exact solution is u(x,y,t)=cos(0.7*pi*sqrt(5)*t)*sin(2*pi*x)*sin(pi*y).
A uniform grid is used on [0,1] x [0,1] with Nx=140 and Ny=140 intervals.
This results in Nx+1 by Ny+1 grid points.
The spatial step sizes are dx=dy=1/Nx.
The 5-point Laplacian is used for spatial discretization of the second derivatives.
A 2nd-order central difference is used for time integration of u_tt.
The time step dt is chosen such that CFL = c*dt*sqrt(1/dx^2+1/dy^2) <= 0.9, where c=0.7.
Specifically, dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
The number of time steps Nt is ceil(T/dt0), and dt = T/Nt to hit the final time T=0.8 exactly.
The first time step u(t=dt) is computed using a Taylor start with the initial velocity.
Boundary nodes are set to 0 at each time step due to Dirichlet boundary conditions.
The numerical solution u(x,y,T=0.8) on the 2D grid must be computed.
The solution data must be saved to "solution_agent_wave_08.npz".
The .npz file must contain 1D arrays x, y, and a 2D array u with shape (len(y), len(x)) where u[j,i] = u(x[i], y[j]) at T.
The .npz file must also contain metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_wave_08.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The maximum absolute error and L2 error against the reference solution on the same grid must also be computed and printed.
