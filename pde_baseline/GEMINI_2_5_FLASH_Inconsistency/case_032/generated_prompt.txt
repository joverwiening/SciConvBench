The task is to numerically solve the 1D heat equation.
The PDE is u_t = 0.2 * u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1].
The temporal domain is t in [0, 0.3].
The parameter alpha is 0.2.
The boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0 for all t.
The initial condition is u(x,0) = sin(pi*x) + 0.5*sin(3*pi*x).
The reference exact solution is u(x,t) = exp(-0.2*pi^2*t)*sin(pi*x) + 0.5*exp(-0.2*(3*pi)^2*t)*sin(3*pi*x).
The spatial discretization uses a uniform grid on [0,1] with Nx=300 intervals, resulting in Nx+1 grid points.
Second-order central differences are used for u_xx in the interior.
The time integration uses the Crank–Nicolson method for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each time step.
The spatial step size is dx = 1/Nx.
The temporal step size is dt = 0.0005, leading to 720 time steps.
The final solution u(x, T=0.3) must be computed on the grid.
The solution and metadata must be saved to "solution_agent_heat_03.npz".
The saved file must contain 1D arrays x and u, and scalar metadata T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_heat_03.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
The maximum absolute error and L2 error against the reference solution on the same x grid must be computed and printed.
All functions must be treated exactly as written, using radians for trigonometric functions.
Exponentiation in math uses '^', and in Python code, it uses '**'.
