Solve the 2D wave equation numerically with the following specifications.

PDE: u_tt = (1.0)**2 * (u_xx + u_yy), but use c = 2 in the CFL condition.
Spatial domain: (x,y) in [0,1] x [0,1], time domain: t in [0, 1.0].
Parameter: c = 2.
Boundary conditions: Dirichlet u = 0 on all boundaries.
Initial condition: u(x,y,0) = sin(pi*x)*sin(pi*y); u_t(x,y,0) = 0.
Exact solution for verification: u(x,y,t) = cos(1.0*sqrt(2)*pi*t)*sin(pi*x)*sin(pi*y).
Use a uniform grid on [0,1] x [0,1] with Nx = Ny = 120 intervals, giving Nx+1 by Ny+1 = 121 x 121 grid points including both endpoints.
Set dx = dy = 1/Nx.
Use the 5-point Laplacian for the spatial discretization of u_xx + u_yy.
Use 2nd-order central difference in time for u_tt.
Compute dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)).
Set Nt = ceil(T / dt0) and then dt = T / Nt so the final time T = 1.0 is hit exactly.
Verify CFL = c * dt * sqrt(1/dx**2 + 1/dy**2) <= 0.9.
Initialize the first time step using a Taylor expansion start incorporating the initial velocity (u_t = 0).
Set boundary nodes to zero at each time step.
Compute u(x,y,T=1.0) on the full 2D grid.

Save a heatmap or contour plot of u(x,y,T) as "solution_agent_wave_07.png".
