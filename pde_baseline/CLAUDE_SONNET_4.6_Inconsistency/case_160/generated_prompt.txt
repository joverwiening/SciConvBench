Solve the 1D Compressible Navier-Stokes PDE (no heat conduction) numerically in Python and save the results.

The PDE is in conservative form with rho, m=rho*v, and E=p/(Gamma-1)+0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x, with zeta = eta.
The equations are: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.

The spatial domain is x in [-1, 1] and time domain is t in [0, 0.2].
Use Gamma = 1.6666666666666667, eta = 1e-08, zeta = 1e-08.
Apply transmissive/outflow (zero-gradient) boundary conditions at x=-1 and x=1.

Use a Riemann (shock-tube) initial condition with discontinuity at x=0.
For x < 0: rho_L=1.0, v_L=0.0, p_L=1.0.
For x >= 0: rho_R=0.125, v_R=0.0, p_R=0.1.

Use a uniform finite-volume grid with Nx=800 cells on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,799, dx=2/800.
Evolve conservative variables U=[rho, m, E] as cell averages.
Use equation of state p=(Gamma-1)*(E - 0.5*m^2/rho), clipping rho and p to floor 1e-12 for positivity.

Use Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
Convective flux F_conv = [m, m^2/rho+p, (E+p)*v] with v=m/rho.
Interface wave speed a = max(|v_L|+c_L, |v_R|+c_R) where c=sqrt(Gamma*p/rho).
Numerical flux F_hat = 0.5*(F_conv(U_L)+F_conv(U_R)) - 0.5*a*(U_R-U_L).

Compute v_x with centered differences on cell-centered v values, then sigma=(zeta+4/3*eta)*v_x.
Approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Viscous flux contribution F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Total interface flux F_total = F_hat + F_visc.

Use 2-stage SSP-RK2 (Heun's method) for time integration.
Compute dt each step as dt = min(dt_conv, dt_visc) where dt_conv = CFL*dx/max_j(|v_j|+c_j) and dt_visc = 0.5*dx^2/max(zeta+4/3*eta, 1e-30).
Adjust the last step to hit final time T=0.2 exactly.
Use CFL=0.8 (standard value unless otherwise specified).
Implement outflow BCs using ghost cells set equal to the nearest interior cell.

Compute rho(x,T), v(x,T), p(x,T) on cell centers at final time.
