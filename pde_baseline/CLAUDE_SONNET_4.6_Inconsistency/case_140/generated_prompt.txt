Solve the 1D advection PDE numerically with the following specifications.

PDE: u_t + beta * u_x = 0
Domain: x in [0, 1) with periodic boundary, t in [0, 2.0]
Parameter: beta = 2.0
Boundary condition: Periodic, u(0,t) = u(1,t) for all t
Initial condition: u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x)
Reference solution: u(x,t) = u0( (x - beta*t) mod 1 ), where u0 is the initial condition

Spatial grid: Uniform periodic grid with Nx=512 points on [0,1), x_j = j*dx for j=0,...,511, dx=1/512.
Spatial discretization: 1st-order upwind finite difference for u_x, using upwind direction determined by sign of beta.
Time integration: Explicit forward Euler.
Time step: CFL=0.5, dt = CFL * dx / abs(beta). Set Nt = ceil(T/dt), then reset dt = T/Nt so final time T=2.0 is hit exactly.

Compute u(x, T=2.0) on the periodic grid.
Save "solution_pdebench_advection_beta2.npz" containing arrays x (length Nx), u (length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta2.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u**2)*dx) at T.
Compute and print max absolute error and L2 error versus the reference solution evaluated on the same x grid.
Use Python with '**' for exponentiation.
Treat all trig functions in radians.
