Solve the 1D inviscid Burgers equation numerically with the following specifications.

PDE: u_t = -k * d_x(0.5 * u**2), where k = 1.0.
Domain: x in [0, 1) with periodic boundary, t in [0, 0.2].
Initial condition: u(x, 0) = sin(2 * pi * x).
Boundary condition: Periodic, u(0, t) = u(1, t) for all t.
No closed-form reference solution is required.

Spatial grid: Uniform periodic grid with Nx = 1024 points on [0, 1). Use x_j = j * dx for j = 0, ..., Nx-1 with dx = 1 / Nx.
Spatial discretization: Conservative finite-volume method with Rusanov (local Lax-Friedrichs) flux for f(u) = 0.5 * u**2.
Time integration: SSP-RK2 (Heun's method) with fixed dt.
Time step: Use CFL = 0.2. Compute dt0 = CFL * dx / max|u| with max|u| estimated as 1. Set Nt = ceil(T / dt0), then dt = T / Nt.
