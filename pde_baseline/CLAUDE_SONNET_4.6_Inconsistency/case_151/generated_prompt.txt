Solve the 1D Viscous Burgers PDE numerically with the following specifications.

PDE: u_t + d_x(0.5*u**2) = nu * u_xx

Domain: x in [0, 1) with periodic boundary, t in [0, 1.0].

Parameter: nu = 2.0.

Boundary condition: Periodic, u(0,t) = u(1,t) for all t.

Initial condition: u(x,0) = sin(2*pi*x).

Use a uniform periodic spatial grid with Nx=512 points on [0,1). Set x_j = j*dx for j=0,...,511 with dx=1/512.

Set dt0 = CFL*dx/1.0 with CFL=0.4. Set Nt = ceil(T/dt0) and reset dt = T/Nt so the final time T=1.0 is hit exactly.

Use Strang splitting for each full time step dt as follows.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): apply a finite-volume update for u_t + d_x(0.5*u**2)=0 using Rusanov (local Lax-Friedrichs) flux. For each interface between u_left=u[j] and u_right=u[j+1] (periodic indexing), set alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left) where f(u)=0.5*u**2. Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus is the flux at interface (j, j+1) and F_minus is the flux at interface (j-1, j). Replace u with u_new.

Step C (diffusion half-step again): same as Step A.

After reaching T=1.0, save a file named "solution_pdebench_burgers_nu2.npz" containing arrays x (1D, length 512), u (1D, length 512), and scalars nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x, T=1.0) as "solution_pdebench_burgers_nu2.png".

Print min(u), max(u), mean(u) (discrete mean, should be approximately conserved), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.0.

Use Python with ** for exponentiation. Treat all trig arguments in radians.
