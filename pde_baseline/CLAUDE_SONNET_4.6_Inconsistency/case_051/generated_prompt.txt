Solve the Klein-Gordon PDE numerically using the specifications below.

PDE: u_tt - (1.0)**2 * u_xx + (3.0)**2 * u = 0
Unknown field: u(x, t)
Parameters: c = 1.0, m = 3.0

Domain: x in [0, 1) periodic, t in [0, 0.8]

Boundary conditions: Periodic on x; u and u_x are periodic.

Initial conditions: u(x, 0) = cos(2*pi*x), u_t(x, 0) = 0

Exact solution for verification: u(x, t) = cos(2*pi*x) * cos(sqrt((1.0*2*pi)**2 + (3.0)**2) * t)

Grid setup: Use Nx = 512 points on [0, 1) with no duplicated endpoint. dx = 1/Nx. x_i = i*dx for i = 0..Nx-1.

Time step setup: Let dt0 = 0.9 * dx / c. Set Nt = ceil(0.8 / dt0). Then dt = 0.8 / Nt so the final time T = 0.8 is hit exactly. CFL = c * dt / dx must be <= 0.9.

Spatial discretization: Use 2nd-order central differences with wrap-around (periodic) for u_xx.

Time integration: Use leapfrog scheme for u_tt. Include the mass term +m**2 * u evaluated at time step n.

Initialization (first step): Use a Taylor expansion start that includes the -m**2 * u0 term, i.e., u at step 1 = u0 + dt * u_t0 + 0.5 * dt**2 * (c**2 * u_xx0 - m**2 * u0).

Output: Compute u(x, T=0.8) on the grid.

Save file "solution_agent_kg_04.npz" containing: x (1D array), u (1D array, same length as x), and metadata scalars T, dx, dt.

Save a line plot of u(x, T) as "solution_agent_kg_04.png".

Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2) * dx) at T.
