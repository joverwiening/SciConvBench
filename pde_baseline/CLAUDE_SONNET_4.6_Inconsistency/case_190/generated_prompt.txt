Solve the 1D Reaction-Diffusion PDE numerically using the exact specifications below.

PDE: u_t = nu * u_xx + rho * u*(1 - u)
Spatial domain: x in [0, 1) with periodic boundary conditions.
Time domain: t in [0, 1.0].
Parameters: nu = 5.0, rho = 2.0.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = 0.25 + 0.1*sin(2*pi*x).
No closed-form reference solution is required.
Use a uniform periodic spatial grid with Nx=512 points on [0,1), with x_j = j*dx for j=0,...,511 and dx=1/512.
Use fixed dt=0.001 with Nt=1000 time steps so that T=1.0 is reached exactly.
Use Strang splitting for each full time step dt.
Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), set u = real(IFFT(u_hat)).
Step B (reaction full-step, duration dt): apply the exact pointwise logistic ODE update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Step C (diffusion half-step again): same procedure as Step A.
Compute u(x, T=1.0) on the periodic grid.
Save a file named "solution_pdebench_reacdiff_nu5_rho2.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu5_rho2.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
