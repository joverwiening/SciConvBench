PDE: u_t + u*u_x + u_xx + u_xxxx = 0 (Kuramoto-Sivashinsky, periodic)

Spatial domain: x in [0, 2*pi), periodic. Time domain: t in [0, 1.0].

Boundary condition: u is periodic in x.

Initial condition: u(x,0) = cos(x) + 0.1*cos(2*x).

Use Fourier pseudo-spectral differentiation on [0, 2*pi) with Nx=1024 points. Compute u_x, u_xx, and u_xxxx via FFT.

Use a semi-implicit time integration scheme in Fourier space: treat the linear part (u_xx + u_xxxx) implicitly and the nonlinear part (u*u_x) explicitly. For each Fourier mode k: u_hat^{n+1} = (u_hat^n - dt * FFT[u*u_x]) / (1 - dt*(-k**2 + k**4)).

Use dt=1e-4 and run for 12000 steps (reaching T=1.0).

Grid convention: domain is half-open [0, 2*pi) with periodicity, so Nx=1024 points, dx=(2*pi)/Nx, x_i = i*dx for i=0..Nx-1.

Compute u(x, T=1.0) on the grid.
