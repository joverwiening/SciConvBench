Solve the PDE u_t = ∂/∂x( D(x) * u_x ) numerically where D(x) = 0.1*(1 + x).
The spatial domain is x in [0,1] and the time domain is t in [0,0.5].
D(x) = 0.1*(1+x).
Boundary conditions are Dirichlet: u(0,t)=0 and u(1,t)=0.
Initial condition is u(x,0)=sin(pi*x).
Use a conservative 2nd-order discretization in flux form for the spatial operator on a uniform grid.
Define D_i = D(x_i) and face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior i=1..Nx-1: ((D u_x)_x)_i ≈ (1/dx**2) * [ D_{i+1/2}*(u_{i+1}-u_i) - D_{i-1/2}*(u_i-u_{i-1}) ].
Use Implicit Euler time integration: (I - dt*L) u^{n+1} = u^n, solving the sparse linear system each step.
Use Nx=300 uniform intervals so there are 301 grid points including both endpoints; dx=(1-0)/300.
Use dt=0.001 for 600 time steps to reach T=0.5.
Compute u(x, T=0.5) on the full grid.
Save a file named "solution_agent_diffusion_01.npz" containing arrays x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_diffusion_01.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=0.5.
Use Python with ** for exponentiation.
