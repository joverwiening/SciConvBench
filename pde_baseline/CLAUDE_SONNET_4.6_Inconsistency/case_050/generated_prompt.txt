Solve the Klein-Gordon PDE numerically with the following specifications.

PDE: u_tt - (1.0)**2 * u_xx + (0.5)**2 * u = 0
Unknown field: u(x, t)
Parameters: c = 1.0, m = 0.5
Domain: x in [0, 1], t in [0, 1.0]; final output time T = 1.1
Boundary conditions: Neumann on x=0 and x=1, u_x(0,t)=0 and u_x(1,t)=0, enforced via ghost points (mirror values).
Initial conditions: u(x,0) = cos(pi*x), u_t(x,0) = 0
Exact solution for verification: u(x,t) = cos(sqrt((1.0*pi)**2 + (0.5)**2)*t) * cos(pi*x)

Grid: Use Nx=400 uniform intervals on [0,1], giving Nx+1=401 points including both endpoints. dx = 1/Nx. x_i = i*dx for i=0..400.
Time stepping: Leapfrog (2nd-order central difference in time). Compute dt0 = 0.9*dx/c. Set Nt = ceil(T/dt0), then dt = T/Nt so the final time T=1.1 is hit exactly.
Initialization: Taylor start using u0 and v0, including the -m**2*u0 term (and any forcing if present).
The m**2*u term is treated explicitly at time level n in the leapfrog update.

Output:
Compute u(x, T=1.1) on the grid.
Save "solution_agent_kg_03.npz" containing arrays x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_kg_03.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
Compute and print the max absolute error and L2 error versus the exact solution evaluated on the same x grid.

Use Python with ** for exponentiation. Treat all functions in radians.
