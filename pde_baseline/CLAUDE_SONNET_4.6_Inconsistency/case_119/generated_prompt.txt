Solve the PDE numerically with the following specifications.

PDE: u_t + q*u_x = 0 (1D linear advection, periodic).
Unknown field: u(x,t).
Domain: x in [0,1) with periodic boundary, t in [0, 1.0]. Note: T for output is 1.1 (see output requirements).
Parameter: q = 1.5.
Boundary condition: Periodic, u(0,t) = u(1,t) for all t.
Initial condition: u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
Exact solution for verification: u(x,t) = u0((x - q*t) mod 1), where u0 is the initial condition.
Use a uniform periodic grid with Nx=512 points on [0,1). Set x_j = j*dx for j=0,...,511 with dx=1/512.
Use 1st-order upwind finite difference for the spatial derivative u_x.
Use Forward Euler for time integration.
Set CFL=0.5, compute dt0 = CFL*dx/abs(q), set Nt=ceil(T/dt0), then dt=T/Nt, where T=1.1.
Compute u(x, T=1.1) on the periodic grid.
Save "solution_molk_018.npz" containing arrays x (1D length Nx) and u (1D length Nx), and scalars T, dx, Nx, and the parameter q.
Save a line plot of u(x,T) as "solution_molk_018.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T=1.1.
Compute and print the max absolute error and L2 error versus the exact solution evaluated on the same x grid.
