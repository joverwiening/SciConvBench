Solve the ODE system numerically for the Brusselator chemical oscillator with the following specifications.

The unknown fields are x and y, both functions of t.

The ODE system is:
dx/dt = A + x**2 * y - (B + 1) * x
dy/dt = B * x - x**2 * y

The time domain is t in [0.0, 20.0].

Parameters are A = 2 and B = 3.0.

Initial conditions are x(0.0) = 1.0 and y(0.0) = 1.0.

Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt = 0.01 and Nt = 2000 steps so the final time is hit exactly.

Compute the full state vector at all time points t_n = t0 + n*dt for n = 0..Nt.

Save a file named "solution_molk_010.npz" containing arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, 2]) with columns ordered as [x, y], and the parameter scalars A and B.

Save line plots of each state vs t as "solution_molk_010.png".

Print the final state values at T = 20.0 and also the min and max of each state over time.

Use ** for exponentiation in Python code.
