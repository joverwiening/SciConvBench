Solve the 1D Compressible Navier–Stokes PDE (no heat conduction) numerically in Python.
The unknown fields are rho(x,t), v(x,t), p(x,t).
Use conservative variables U = [rho, m, E] where m = rho*v and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x, with zeta = eta = 0.1.
The PDE in conservative form is: rho_t + (m)_x = 0; m_t + (m^2/rho + p - sigma)_x = 0; E_t + ((E+p)*v - v*sigma)_x = 0.
The spatial domain is x in [-1, 1], time domain is t in [0, 0.5].
Parameters: Gamma = 1.6666666666666667, eta = 0.1, zeta = 0.1.
Boundary conditions are periodic on x = -1 and x = 1.
Initial conditions: rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1]; cell centers x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, dx = 2/Nx.
Evolve cell-average conservative variables U = [rho, m, E].
Equation of state: p = (Gamma-1) * (E - 0.5*m**2/rho); clip rho and p to a floor of 1e-12 for positivity.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part: F_conv = [m, m**2/rho + p, (E+p)*v] with v = m/rho; interface wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho); numerical flux F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute v_x with centered differences on cell-centered v values; sigma = (zeta + 4/3*eta)*v_x; approximate sigma at interfaces by averaging neighboring cell-centered sigma values.
Add viscous contributions to momentum and energy fluxes: F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma.
Total interface flux: F_total = F_hat + F_visc.
Use 2-stage SSP-RK2 (Heun's method) for time integration.
Compute dt each step: dt_conv = CFL * dx / max_j(|v_j| + c_j); dt_visc = 0.5 * dx**2 / max(zeta + 4/3*eta, 1e-30); dt = min(dt_conv, dt_visc); adjust the last step to hit T = 0.5 exactly.
Use CFL = 0.5 as a reasonable and conservative default based on best practices for SSP-RK2 with Rusanov flux.
Implement periodic boundary conditions by wrapping indices (ghost cells).
Compute rho(x,T), v(x,T), p(x,T) on cell centers at the final time.
