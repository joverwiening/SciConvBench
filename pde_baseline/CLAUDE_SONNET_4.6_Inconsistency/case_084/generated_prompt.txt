Solve the PDE numerically with the following specifications.

PDE: u_tt = (1.0)**2 * u_xx (wave equation).
Domain: x in [0,1], t in [0,0.8].
Parameter: c = 2.
Boundary conditions: Dirichlet u=0 at x=0 and x=1 at every time step.
Initial condition: u(x,0) = sin(pi*x) + 0.5*sin(3*pi*x); u_t(x,0) = 0.
Exact solution for verification: u(x,t) = cos(1.0*pi*t)*sin(pi*x) + 0.5*cos(1.0*3*pi*t)*sin(3*pi*x).
Use a uniform grid on [0,1] with Nx=600 intervals, giving Nx+1=601 points including both endpoints.
dx = 1/600.
Use 2nd-order central differences for u_xx in the interior.
Use the standard leapfrog (Störmer–Verlet) 2nd-order central difference in time for u_tt.
Choose dt as follows: dt0 = 0.9*dx/c, Nt = ceil(0.8/dt0), dt = 0.8/Nt so the final time T=0.8 is hit exactly.
Initialize u^0 = u(x,0).
Compute u^1 using the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt**2*(c**2 * u_xx^0) where v0 = u_t(x,0) = 0 and there is no forcing term.
Apply Dirichlet BC (u=0) at boundary nodes at every time step.
At T=0.8, compute u(x,T) on the full grid.
Save "solution_agent_wave_03.npz" containing arrays x (1D), u (1D, same length as x), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_03.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx) at T.
Compute and print the max absolute error and L2 error versus the exact solution evaluated on the same x grid.
Treat all functions in radians.
