Solve the 2D Darcy flow PDE numerically with the following specifications.

The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 on the domain (x,y) in (0,1) x (0,1).
The coefficient field is a(x,y) = 1 + 2 * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)), with beta = 2.
Apply Dirichlet boundary conditions u = 0 on the entire boundary.
Use a uniform Cartesian grid with N=128 intervals in each direction, giving N+1 = 129 points including boundaries.
Set dx = dy = 1/N and x_i = i*dx for i=0,...,N, y_j = j*dy for j=0,...,N.
Discretize using 2nd-order finite differences with variable coefficients using face-centered harmonic averaging.
The face coefficient is computed as a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)), and similarly for all other faces.
The interior node discretization is -(1/dx**2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1 for interior nodes i=1..N-1, j=1..N-1.
Assemble the sparse linear system Au=b for the interior unknowns only.
Solve the linear system using conjugate gradient (CG) to a relative residual tolerance of 1e-10.
Optionally use a Jacobi preconditioner.
Compute u(x,y) on the full (N+1) x (N+1) grid including boundary nodes (which are zero).
Save a file named "solution_pdebench_darcy_beta1.npz" containing arrays x (1D), y (1D), u (2D, shape [N+1, N+1]), and scalars beta, N, dx.
Save a heatmap or contour plot of u(x,y) as "solution_pdebench_darcy_beta1.png".
Print min(u), max(u), and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system.
Use Python with ** for exponentiation.
Treat all trigonometric arguments in radians.
