Solve the ODE system numerically for the Lotka–Volterra predator–prey model with the specifications below.

Task ID is molk_008.
ODE category is Lotka–Volterra predator–prey model.
Unknown fields are x and y, both functions of t.

Treat all functions exactly as written and use radians for trig.
In Python code, use ** for exponentiation (^ means exponentiation in the math).

ODE system:
dx/dt = alpha*x - beta*x*y
dy/dt = delta*x*y - gamma*y

Time domain: t in [0.0, 30.0].

Parameters: alpha = 1.5, beta = 2, gamma = 3.0, delta = 1.0.

Initial conditions: x(0.0) = 1.0, y(0.0) = 1.0.

Use Classical 4th-order Runge–Kutta (RK4) with fixed step size.
Use dt = 0.01 with Nt = 3000 steps so the final time is hit exactly.

Compute the full state vector at all time points t_n = t0 + n*dt for n = 0..Nt.
Save "solution_molk_008.npz" containing arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns ordered as [x, y], and the parameter scalars.
Save line plots of each state vs t as "solution_molk_008.png".
Print the final state values at T and also min/max of each state over time.
