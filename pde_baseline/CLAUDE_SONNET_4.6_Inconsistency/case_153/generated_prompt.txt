Solve the 1D Viscous Burgers PDE numerically with the following specifications.

PDE: u_t + d_x(0.5*u**2) = nu * u_xx

Domain: x in [0, 1) with periodic boundary, t in [0, 1.0].

Parameters: nu = 4.0.

Boundary conditions: Periodic, u(0,t) = u(1,t) for all t.

Initial condition: u(x,0) = sin(2*pi*x).

No closed-form reference solution is required.

Use a uniform periodic spatial grid with Nx=512 points on [0,1). Set x_j = j*dx for j=0,...,511 with dx=1/512.

Use Strang splitting for each full time step dt.

Step A (diffusion half-step, duration dt/2): compute u_hat = FFT(u), compute k = 2*pi*fftfreq(Nx, d=dx), multiply u_hat(k) by exp(-nu*k**2*(dt/2)), set u = real(IFFT(u_hat)).

Step B (advection full-step, duration dt): use a finite-volume update with Rusanov (local Lax-Friedrichs) flux. Define f(u) = 0.5*u**2. For each interface between u_left=u[j] and u_right=u[j+1] (periodic indexing), compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right - u_left). Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus is the flux at the right interface of cell j and F_minus is the flux at the left interface. Replace u with u_new.

Step C (diffusion half-step again): same as Step A.

Time step: set CFL=0.4, estimated max speed=1.0, dt0 = CFL*dx/1.0. Set Nt = ceil(T/dt0), then reset dt = T/Nt so the final time T=1.0 is hit exactly.

Compute u(x, T=1.0) on the periodic grid.

Save a file named "solution_pdebench_burgers_nu4.npz" containing arrays x (1D length 512), u (1D length 512), and scalars nu, T, dx, dt, Nx, Nt.

Save a line plot of u(x,T) as "solution_pdebench_burgers_nu4.png".

Print min(u), max(u), discrete mean value mean(u), and discrete L2 norm sqrt(sum(u**2)*dx) at T.

Use Python with ** for exponentiation.
