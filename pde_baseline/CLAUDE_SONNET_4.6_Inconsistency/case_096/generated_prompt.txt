Solve the wave equation PDE numerically using the specifications below.

PDE: u_tt = (1.0)**2 * (u_xx + u_yy)
The parameter c = 2 is used for CFL calculation.
Domain: (x,y) in [0,1] x [0,1], t in [0, 0.5].
Boundary conditions: Dirichlet u=0 on all boundaries.
Initial condition: u(x,y,0) = sin(pi*x)*sin(2*pi*y); u_t(x,y,0) = 0.
Exact solution for verification: u(x,y,t) = cos(1.0*pi*sqrt(5)*t)*sin(pi*x)*sin(2*pi*y).

Use a uniform grid on [0,1] x [0,1] with Nx=Ny=160 intervals, giving Nx+1 by Ny+1 = 161x161 grid points including both endpoints.
dx = dy = 1/160.
Use the 5-point Laplacian for the spatial discretization of the Laplacian operator.
Use 2nd-order central difference in time for u_tt.
Compute dt: let dt0 = 0.9 / (c * sqrt(1/dx**2 + 1/dy**2)), set Nt = ceil(0.5/dt0), then dt = 0.5/Nt so the final time T=0.5 is hit exactly.
Initialize the first time step using a Taylor expansion start incorporating the initial velocity (u_t = 0).
Set boundary nodes to zero at each time step.

Compute u(x,y,T=0.5) on the full 2D grid.
Save "solution_agent_wave_15.npz" containing: x (1D array), y (1D array), u (2D array of shape (len(y), len(x)) so u[j,i] = u(x[i], y[j]) at T), and metadata scalars T, dx, dy, dt.
Save a heatmap or contour plot of u(x,y,T) as "solution_agent_wave_15.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u**2)*dx*dy) at T.
Compute and print the max absolute error and L2 error versus the exact reference solution evaluated on the same grid.
