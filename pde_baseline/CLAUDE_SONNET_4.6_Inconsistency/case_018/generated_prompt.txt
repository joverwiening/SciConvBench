Solve the PDE numerically with the following specifications.

Spatial domain: x in [0,1], closed interval.
Time domain: t in [0, 0.2].
Parameter: D(x) = 0.01 + 0.09*x**2
Boundary conditions: Dirichlet, u(0,t)=0 and u(1,t)=0.
Initial condition: u(x,0) = x*(1-x).
Use a conservative 2nd-order discretization in flux form for the spatial operator on a uniform grid.
Define D_i = D(x_i).
Define face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior i=1..Nx-1: ((D u_x)_x)_i ≈ (1/dx**2) * [ D_{i+1/2}*(u_{i+1}-u_i) - D_{i-1/2}*(u_i-u_{i-1}) ].
Use Implicit Euler time integration: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator.
Solve the sparse linear system at each time step.
