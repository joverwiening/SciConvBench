Create a self-contained Python 3 script named agent_kg_07.py that numerically solves the 1D forced Klein–Gordon equation u_tt - c^2 u_xx + m^2 u = sin(pi*x)*cos(2*t) on x in [0,1] and t in [0,5.0].
Use parameters c=1.0 and m=1.0.
Use a uniform grid with Nx=400 intervals on [0,1], giving Nx+1 grid points including endpoints, with dx=(1-0)/Nx and x_i=i*dx.
Impose homogeneous Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 for all t.
Discretize u_xx with 2nd-order central differences on the uniform grid.
Integrate in time with a 2nd-order central difference (leapfrog) scheme for u_tt.
Handle the +m^2*u term explicitly at time level n in the leapfrog update.
Use dt=0.001 for 5000 steps so that T=5.0 corresponds to n=5000.
Evaluate the forcing term sin(pi*x)*cos(2*t) in radians at the current time level t_n=n*dt and include it in the leapfrog update at time level n.
Use initial conditions u(x,0)=0 and u_t(x,0)=0.
Initialize the first time step using a Taylor start from u0 and v0, including the -m^2*u0 contribution and the forcing term at t=0.
Compute the numerical solution u(x,T) at T=5.0 on the same grid, corresponding to time step n=5000.
Compute and print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=5.0 over all grid points including the boundary points.
Save an NPZ file named solution_agent_kg_07.npz containing arrays x (1D) and u (1D, same length as x) and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as solution_agent_kg_07.png with axis labels x and u(x,T) and a title indicating u(x,T) at T=5.0.
Use NumPy for arrays and Matplotlib for plotting, using np.savez/np.load for NPZ I/O.
Set Matplotlib to use the non-interactive Agg backend so the script runs on headless systems.
Make the script runnable from the command line so that executing it runs the simulation, writes the NPZ and PNG files, and prints the diagnostics.
