Solve the 1D compressible Navier–Stokes system (no heat conduction) in conservative form for rho(x,t), v(x,t), p(x,t) with m=rho*v and E=p/(Gamma-1)+0.5*rho*v^2.
Use Gamma = 1.6666666666666667, eta = 1e-08, zeta = eta, and sigma = (zeta + 4/3*eta) * v_x.
Evolve the conservative variables U = [rho, m, E] as cell averages on a uniform finite-volume grid on x in [-1, 1] with Nx = 400 cells.
Use cell centers x_j = -1 + (j+0.5)*dx for j=0..Nx-1 with dx = 2/Nx.

Use the equation of state p = (Gamma-1) * (E - 0.5*m^2/rho) and enforce positivity by clipping rho and p to a small floor (e.g., 1e-12) if needed.
Compute inviscid fluxes with the Rusanov (local Lax-Friedrichs) numerical flux using F_conv(U) = [m, m^2/rho + p, (E+p)*v] with v=m/rho and wave speed a=max(|v_L|+c_L, |v_R|+c_R) where c=sqrt(Gamma*p/rho).
Compute viscous terms by forming v_x with a centered difference on cell-centered v, sigma=(zeta+4/3*eta)*v_x, and interface sigma by averaging neighboring cell-centered sigma values.
Add viscous contributions to interface fluxes as F_visc = [0, -sigma, -v*sigma] using interface-averaged v and sigma, and set total interface flux F_total = F_hat + F_visc.
Advance in time on t in [0, 0.5] using 2-stage SSP-RK2 (Heun’s method) applied to the semi-discrete finite-volume system.
Choose the adaptive time step each step with CFL = 0.5 using dt_conv = CFL*dx/max_j(|v_j|+c_j), dt_visc = 0.5*dx^2/max(zeta+4/3*eta, 1e-30), dt=min(dt_conv, dt_visc), and adjust the last step to hit T=0.5 exactly.
Compute and save rho(x,T), v(x,T), p(x,T) only at the final time T=0.5 on the cell centers.
