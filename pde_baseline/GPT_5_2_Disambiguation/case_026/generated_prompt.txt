Solve the 1D diffusion-reaction PDE u_t = 0.01*u_xx + u*(1-u)*(u-0.25) for u(x,t).
Use the spatial domain x in [0,1] and time domain t in [0,0.5].
Use parameters D = 0.01 and a = 0.25 as given in the reaction term.
Use Dirichlet boundary conditions u(0,t)=1 and u(1,t)=0 for all t.
Use the initial condition u(x,0)=0.5*(1 - tanh((x-0.5)/0.02)) for x in [0,1].
Use a uniform grid with Nx=600 intervals, so there are Nx+1 grid points including endpoints, with dx=(1-0)/Nx and x_i=0+i*dx.
Discretize the diffusion term with 2nd-order central differences on the uniform grid.
Use deterministic IMEX first-order time stepping: diffusion implicit (backward Euler) and reaction explicit (forward Euler).
At each time step solve (I - dt*D*L) u^{n+1} = u^n + dt*R(u^n), where L is the discrete Laplacian with Dirichlet boundary treatment and R(u)=u*(1-u)*(u-0.25).
Enforce Dirichlet conditions by solving for interior unknowns only and modifying the linear system and RHS accordingly, with boundary values fixed at u(0,t)=1 and u(1,t)=0.
Use dt=0.0002 for 2500 steps to reach T=0.5.
Use Python for implementation, with NumPy and SciPy for arrays and sparse linear algebra, and Matplotlib for plotting.
Use SciPy’s default sparse direct solver scipy.sparse.linalg.spsolve at each time step.
Compute and output u(x,T=0.5) on the grid used.
