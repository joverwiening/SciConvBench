Solve the 1D forced wave equation u_tt = (1.0)^2 u_xx + sin(pi*x)*sin(2*pi*t) for x in [0,1] and t in [0,1.0] with unknown field u(x,t).
Use Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 enforced at every time step by setting boundary nodes to the prescribed value.
Use initial conditions u(x,0)=0 and u_t(x,0)=0.
Use a uniform grid on [0,1] with Nx=400 intervals and Nx+1 points, dx=1/Nx, x_i=i*dx for i=0..Nx.
Discretize u_xx in the interior with 2nd-order central differences.
Integrate in time with the standard 2nd-order central difference for u_tt (leapfrog / Störmer–Verlet).
Choose dt via CFL with c=1.0: set dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that T=1.0 is hit exactly.
Initialize with the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0) using v0(x)=0 and f^0=f(x,0).
Evaluate the forcing term exactly as f(x,t)=sin(pi*x)*sin(2*pi*t) in radians at the current time level t^n in the leapfrog update.
Compute u(x,T=1.0) on the grid.
