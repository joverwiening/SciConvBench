Solve the 1D periodic advection PDE u_t + beta * u_x = 0 for u(x,t).
Use beta = 0.2.
Use spatial domain x in [0, 1) with period 1 and a periodic grid with Nx = 512 points.
Define grid points as x_j = j*dx for j = 0..511 with dx = 1/512.
Use float64 throughout.
Use initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x), with trig in radians.
Use 1st-order upwind finite difference for u_x with upwind direction determined by sign(beta).
For beta > 0, approximate u_x at x_j as (u_j - u_{j-1})/dx with periodic wraparound so u_{-1} = u_{Nx-1}.
Use explicit forward Euler time integration.
Use CFL = 0.5 and set dt = CFL * dx / abs(beta).
Choose Nt = ceil(T/dt) and then reset dt = T/Nt to hit final time exactly.

Compute the numerical solution u(x,T) on the grid.

Compute and print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same grid.
