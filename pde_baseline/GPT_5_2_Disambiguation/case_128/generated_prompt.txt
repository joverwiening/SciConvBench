Implement a numerical solver for Task ID molk_027: 1D nonlinear convection–diffusion with cubic flux on a periodic domain.  
Solve u_t = -q1 * ∂_x((1/3) u^3) + (q2/pi) * u_xx on x in [0,1) (periodic) and t in [0,0.5].  
Use parameters q1 = 1.0 and q2 = 0.05.  
Use a uniform periodic grid with Nx = 1024 points on [0,1) with x_j = j*dx for j=0..Nx-1 and dx = 1/Nx.  
Set the initial condition u(x,0) = 0.5*sin(2*pi*x) evaluated exactly on the grid points with no filtering or dealiasing.  
Discretize the convection term in conservative finite-volume form using a Rusanov (local Lax–Friedrichs) numerical flux for f(u) = (1/3)u^3.  
For the Rusanov flux at interface j+1/2, use wave speed a_{j+1/2} = max(|u_L|^2, |u_R|^2).  
Discretize the diffusion term u_xx using the standard 2nd-order central difference (u_{j+1} - 2u_j + u_{j-1})/dx^2 with periodic wrap-around indexing.  
Integrate in time using SSP-RK2.  
Choose a fixed time step once at the start using CFL=0.2 with max|f'(u)| = max|u^2| and the stated initial bound |u|<=0.5 so max|f'|<=0.25 to form dt0 = CFL*dx/max|f'|.  
Compute dt_diff = 0.2*dx^2/(q2/pi).  
Set dt = min(dt0, dt_diff), then Nt = ceil(T/dt), then reset dt = T/Nt with T=0.5.  
Do not recompute max|u| or update dt during the run.  
Save only the final state at T = 0.5.  
Write a single self-contained Python script (e.g., solve_molk_027.py) using NumPy for computation and Matplotlib for plotting.  
When run, the script writes solution_molk_027.npz to the current working directory containing arrays x (length Nx) and u (length Nx at T), and scalars T, dx, Nx, q1, q2.  
Also save solution_molk_027.png as a line plot of u(x,T) with labeled axes (x and u(x,T)) and a simple title like u(x, T=0.5).  
Print to stdout at final time T=0.5 only min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u**2) * dx).
