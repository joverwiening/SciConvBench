Implement Task ID molk_031 as a single self-contained Python script (e.g., molk_031.py) using NumPy (float64) for computation and Matplotlib for plotting, with no command-line arguments.
Solve the 1D nonlinear convection–diffusion PDE u_t = -q1 * ∂_x(cos(u)) + (q2/pi) * u_xx on x in [0,1) with periodic boundary conditions and t in [0,0.5].
Use parameters q1=1.0 and q2=0.05.
Use the initial condition u(x,0)=0.5*sin(2*pi*x) with trig in radians.
Use a uniform periodic grid with Nx=1024 points on [0,1), with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Discretize the convection term in conservative finite-volume form for ∂_x(cos(u)) using a Rusanov numerical flux with wave speed alpha = max|sin(u)|.
Discretize the diffusion term u_xx using second-order central differences with periodic wrap.
Advance in time using SSP-RK2.
Choose the time step using CFL=0.2 with dt_adv=0.2*dx/1 and dt_diff=0.2*dx^2/(q2/pi), then dt=min(dt_adv,dt_diff), Nt=ceil(T/dt), and reset dt=T/Nt.
Evolve the solution to final time T=0.5 and output only the final-time solution u(x,T) on the periodic grid.
Save solution_molk_031.npz containing arrays x (length Nx) and u (length Nx at T), plus scalars T, dx, Nx, q1, q2.
Save a line plot solution_molk_031.png of u(x,T) using reasonable defaults such as figsize=(8,4) and dpi around 150, with axis labels x and u(x,T) and a title molk_031: u(x,T=0.5).
Print a brief run summary to stdout including Nx, dx, dt, Nt, and at T=0.5 print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Do not set any random seed.
