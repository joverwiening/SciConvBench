Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu=0.5 and rho=5.0.
Use the initial condition u(x,0)=0.25 + 0.1*sin(2*pi*x) with trig in radians.
Use a uniform periodic grid with Nx=512 points on [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Use a fixed time step dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
Use Strang splitting for each full time step dt: diffusion half-step dt/2, reaction full-step dt, diffusion half-step dt/2.
Implement each diffusion half-step exactly in Fourier space using FFT: k = 2*pi*fftfreq(Nx, d=dx), u_hat <- FFT(u), u_hat <- u_hat*exp(-nu*k^2*(dt/2)), u <- real(IFFT(u_hat)).
Implement the reaction step exactly pointwise for the logistic ODE: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Assume Python as the implementation language using NumPy’s np.fft for FFT/IFFT and Matplotlib for plotting.
Use float64 (double precision) for computations and for arrays saved to disk.
Save an NPZ file named solution_pdebench_reacdiff_nu0p5_rho5.npz containing arrays x (length Nx) and u (length Nx) at T=1.0, plus scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_reacdiff_nu0p5_rho5.png at a reasonable best-practice DPI (about 150–300).
Include plot labels x and u(x,T) and a simple title like u(x,T=1.0).
Print diagnostics at T=1.0: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx), formatted with a reasonable best-practice precision (e.g., 6 decimal places or scientific format).
Provide a single self-contained Python script that runs end-to-end, writes the NPZ and PNG files, and prints the diagnostics when executed.
