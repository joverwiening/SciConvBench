Task ID is agent_advection_01.
Solve the 1D linear advection PDE u_t + (1.0)*u_x = 0 for unknown u(x,t).
Use domain x in [0,1) with periodic boundary conditions and t in [0,1.0] for the CFL-based timestep selection.
Use parameter a = 1.0 as the advection speed in the CFL condition.
Impose periodicity in x via wrap-around indexing so u(0,t)=u(1,t).
Use initial condition u(x,0)=sin(2*pi*x) with trig in radians.
Use reference solution u(x,t)=sin(2*pi*(x-(1.0)*t)) for verification on the same grid.
Use a uniform periodic grid with Nx=800 points on [0,1) with no duplicated endpoint, dx=1/Nx, and x_i=i*dx for i=0..Nx-1.
Discretize u_x with 1st-order upwind finite differences appropriate for a=1.0 to avoid spurious oscillations.
Integrate in time with Forward Euler.
Choose dt0 = 0.9*dx/|a|, set Nt = ceil(T/dt0), then set dt = T/Nt so the final time is hit exactly.
Compute the numerical solution u(x,T=1.1) on the same grid.
Save solution_agent_advection_01.npz containing arrays x (1D) and u (1D) plus metadata scalars T, dx, dt.
Save a line plot of u(x,T) as solution_agent_advection_01.png.
Print to standard output min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Also compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid at T.
Implement in Python as a single self-contained script named agent_advection_01.py.
Use only NumPy and Matplotlib as external dependencies.
Save the .npz and .png outputs in the current working directory where the script is run.
