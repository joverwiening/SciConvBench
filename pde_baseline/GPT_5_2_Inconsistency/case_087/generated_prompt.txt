Write a single self-contained Python 3.10+ script using NumPy for computation and Matplotlib for plotting.
Solve the 1D wave equation u_tt = (1.0)^2 * u_xx on x in [0,1] and t in [0,1.0] for the unknown field u(x,t).
Use the parameter c = 2 for the CFL condition and for the Taylor start term c^2*u_xx.
Impose zero Neumann boundary conditions u_x(0,t)=0 and u_x(1,t)=0 using ghost points with mirror values.
Use the initial conditions u(x,0)=cos(pi*x) and u_t(x,0)=0.
Use a uniform grid on [0,1] with Nx=400 intervals and Nx+1 points, with dx=1/Nx and x_i=i*dx.
Discretize u_xx with 2nd-order central differences in the interior.
Integrate in time with the standard 2nd-order central difference in time (leapfrog / Störmer–Verlet) for u_tt.
Initialize with the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0) with v0(x)=0 and no forcing.
Choose dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that the final time T=1.0 is hit exactly.
Compute the numerical solution u(x,T=1.0) on the grid.
Compute the reference solution u_exact(x,t)=cos(pi*x)*cos(1.0*pi*t) on the same x grid at T=1.0 for verification.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Also compute and print the max absolute error and L2 error versus the reference solution at T on the same grid.
Save an NPZ file named solution_agent_wave_06.npz to the current working directory containing arrays x (1D) and u (1D) plus metadata scalars T, dx, dt.
Save a line plot of u(x,T) as solution_agent_wave_06.png to the current working directory.
Do not include any randomness or random seeds.
Hard-code all parameters exactly as specified and do not accept command-line arguments.
Structure the script with a main() function and run it under if __name__ == "__main__": main().
Do not print Nt or the adjusted dt unless you decide it is a best-practice addition beyond the required diagnostics.
