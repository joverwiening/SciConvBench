Solve the 1D forced wave equation u_tt = c^2 u_xx + sin(pi*x)*sin(2*pi*t) for u(x,t).
Use c = 1.0.
Use the domain x in [0,1] and t in [0,1.0] with final time T = 1.0.
Impose Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 at every time step.
Use initial conditions u(x,0)=0 and u_t(x,0)=0.
Use a uniform grid on [0,1] with Nx = 400 intervals and Nx+1 points, dx = 1/Nx, x_i = i*dx for i=0..Nx.
Discretize u_xx with 2nd-order central differences on interior points i=1..Nx-1.
Use 2nd-order central differences in time for u_tt (leapfrog / Störmer–Verlet).
Choose dt via dt0 = 0.9*dx/c, set Nt = ceil(T/dt0), then set dt = T/Nt so that t_Nt = T exactly.
Evaluate the forcing at discrete time levels as f_i^n = sin(pi*x_i)*sin(2*pi*t_n) with t_n = n*dt.
Initialize with the Taylor start u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0) using v0=0 and u^0 from the initial condition, while enforcing Dirichlet boundary values.
Advance in time enforcing Dirichlet boundary nodes at every step.
Compute u(x,T) on the grid at t = T.
