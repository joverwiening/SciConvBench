Create a single self-contained Python 3.10+ script that numerically solves the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu=0.5 and rho=2.0.
Use the initial condition u(x,0)=0.25 + 0.1*sin(2*pi*x) with radians.
Use a uniform periodic grid with Nx=512 points on [0,1) with dx=1/Nx and x_j=j*dx for j=0..Nx-1.
Use a fixed time step dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
Use Strang splitting per time step dt: diffusion half-step, reaction full-step, diffusion half-step.
Implement each diffusion half-step exactly in Fourier space using numpy.fft FFT/IFFT with k = 2*pi*fftfreq(Nx, d=dx) and multiplier exp(-nu*k^2*(dt/2)), taking the real part after IFFT.
Implement the reaction full-step exactly pointwise using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Use float64 throughout for x, u, and intermediate computations.
Compute the final solution u(x,T=1.0) on the periodic grid.
Save an NPZ file named solution_pdebench_reacdiff_nu0p5_rho2.npz in the current working directory containing arrays x (length Nx) and u (length Nx) and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_reacdiff_nu0p5_rho2.png in the current working directory with axis labels x and u(x,T), a title like u(x,T=1.0), and x-axis range set to 0 to 1 (or equivalently rely on the computed x array spanning 0 to 1-dx).
Print only the final diagnostics at T=1.0: min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Do not include any command-line interface.
Do not print any runtime progress during the 1000 steps.
Do not set any random seed.
