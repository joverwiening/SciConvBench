Write a single standalone Python script using NumPy (including numpy.fft) and Matplotlib that runs end-to-end with no CLI arguments and writes outputs to the current working directory.
Solve the 1D reaction–diffusion PDE u_t = nu*u_xx + rho*u*(1-u) on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use parameters nu = 10.0 and rho = 10.0.
Use a uniform periodic grid with Nx = 512 points on [0,1) with dx = 1/Nx and x_j = j*dx for j = 0..Nx-1.
Use a fixed time step dt = 0.001 with Nt = 1000 steps to reach T = 1.0 exactly.
Initialize u(x,0) = 0.25 + 0.1*sin(2*pi*x) using radians.
Advance in time using Strang splitting each full step dt: diffusion half-step, reaction full-step, diffusion half-step.
Implement each diffusion half-step exactly in Fourier space: u_hat = FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat *= exp(-nu*k^2*(dt/2)), u = IFFT(u_hat) and enforce real values via u = (...).real.
Implement the reaction full-step exactly pointwise for du/dt = rho*u*(1-u) using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Use double precision (float64) throughout, including FFT-related arrays.
Compute the final solution u(x,T=1.0) on the periodic grid.
Save an NPZ file named solution_pdebench_reacdiff_nu10_rho10.npz containing arrays x (length Nx) and u (length Nx) and scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_reacdiff_nu10_rho10.png with axis labels x and u(x,T) and a title like Reaction–Diffusion solution at T=1.0.
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T using Python’s default float formatting.
Do not save the full time history, only the final state.
