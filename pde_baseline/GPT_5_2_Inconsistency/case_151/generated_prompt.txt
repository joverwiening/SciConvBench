Write a single self-contained Python script that numerically solves the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx on x in [0,1) with periodic boundary conditions and t in [0,1.0].
Use nu = 2.0.
Use the initial condition u(x,0) = sin(2*pi*x) with radians for trig.
Use a uniform periodic grid with Nx = 512 points on [0,1) with x_j = j*dx for j=0..Nx-1 and dx = 1/Nx.
Use Strang splitting each full time step dt consisting of a diffusion half-step, an advection full-step, and a diffusion half-step.
Implement each diffusion half-step exactly in Fourier space using numpy.fft.fft, numpy.fft.ifft, and numpy.fft.fftfreq with k = 2*pi*fftfreq(Nx, d=dx) and u_hat <- u_hat * exp(-nu*k^2*(dt/2)), then inverse FFT and take the real part.
Implement the advection full-step for inviscid Burgers using a finite-volume update with Rusanov flux where f(u)=0.5*u^2, alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left), and u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.
Use explicit forward Euler for the advection substep as specified by the finite-volume update.
Choose the time step using CFL=0.4 with dt0 = CFL*dx/1.0, set Nt = ceil(T/dt0), then reset dt = T/Nt so the final time T=1.0 is hit exactly.
Avoid randomness entirely.
Use numpy.float64 throughout for real arrays.
Use Python with NumPy for arrays and FFTs and Matplotlib for plotting.
Run silently during time stepping and print only final diagnostics at the end.
At T=1.0, compute and print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx).
Save an NPZ file named solution_pdebench_burgers_nu2.npz in the current working directory containing arrays x (length Nx) and u (length Nx) and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as solution_pdebench_burgers_nu2.png in the current working directory with x-axis label x, y-axis label u(x,T), and a title like Viscous Burgers at T=1.0 (nu=2.0).
Use Matplotlib default figure size and dpi.
Structure the script with a main() function and an if __name__ == "__main__": guard.
