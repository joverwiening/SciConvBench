Implement task molk_011 in Python as a single self-contained script named molk_011.py.
Solve the undriven Duffing oscillator ODE system with state [x(t), y(t)] where dx/dt = y and dy/dt = -delta*y - alpha*x - beta*x**3.
Use parameters alpha = 2, beta = 0.1, delta = 0.2.
Use initial conditions x(0.0) = 1.0 and y(0.0) = 0.0.
Integrate over t in [0.0, 50.0] using classical fixed-step RK4 with dt = 0.01 and Nt = 5000 steps, computing the solution at all t_n for n = 0..Nt.
Use only NumPy and Matplotlib (no SciPy).
Set the Matplotlib backend to Agg to support headless PNG saving.
Save solution_molk_011.npz containing t (1D array length Nt+1), Y (2D array shape [Nt+1, 2] with columns [x, y]), and scalar entries alpha, beta, delta.
Save solution_molk_011.png as a single figure with two subplots: x vs t on the top subplot and y vs t on the bottom subplot.
Print to stdout the final state values at T = 50.0 and the min/max of x and y over the full time series, formatted to 6 decimal places.
Include an if __name__ == "__main__": guard so the module can be imported without running the simulation.
