Solve the Klein-Gordon PDE u_tt - (1.0)^2*u_xx + (1.0)^2*u = 0 numerically.
The spatial domain is x in [0,1] and time domain is t in [0,1.0].
Use parameters c = 1.0 and m = 1.0.
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Set initial conditions u(x,0)=sin(pi*x) and u_t(x,0)=0.
Use uniform spatial grid with Nx=400 intervals (401 points) and 2nd-order central differences for u_xx.
Apply 2nd-order central difference in time (leapfrog) for u_tt with explicit treatment of +m^2*u term.
Set dx=1/Nx, dt0 = 0.9*dx/c, Nt = ceil(T/dt0), and dt = T/Nt for exact final time.
Use Taylor start initialization including the -m^2*u0 term.
Compute u(x, T=1.0) on the grid.
Save "solution_agent_kg_01.npz" with arrays x, u and metadata T, dx, dt.
Save line plot "solution_agent_kg_01.png" of u(x,T).
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
