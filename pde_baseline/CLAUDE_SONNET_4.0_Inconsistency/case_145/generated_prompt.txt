Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use domain x in [0, 1) with periodic boundary and t in [0, 1.0].
Set parameter nu = 0.04.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Create uniform periodic grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement Strang splitting with each full time step dt consisting of: diffusion half-step (dt/2) solved exactly in Fourier space, advection full-step (dt) using finite-volume update with Rusanov flux, then diffusion half-step (dt/2) again.
For diffusion steps: transform to Fourier space, multiply by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then transform back taking real part.
For advection step: use finite-volume update with Rusanov flux where f(u)=0.5*u^2, alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), and u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Set time step using CFL=0.4 with dt0 = CFL*dx/1.0, then Nt = ceil(T/dt0) and dt = T/Nt where T=1.0.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_burgers_nu0p04.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu0p04.png".
Print min(u), max(u), discrete mean value mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T=1.0.
