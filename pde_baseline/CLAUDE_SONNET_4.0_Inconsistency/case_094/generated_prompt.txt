Solve the wave equation PDE numerically with the following specifications:

Create a uniform spatial grid on [0,1] with Nx=800 intervals giving Nx+1=801 points.
Set dx=1/Nx=1/800.

Set Nt = ceil(T/dt0) and then dt = T/Nt to hit the final time T=0.25 exactly.
Initialize using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Set boundary nodes to prescribed Dirichlet values at every time step.
Compute u(x, T=0.25) on the grid.
Save "solution_agent_wave_13.npz" containing arrays x, u, and scalars T, dx, dt.
