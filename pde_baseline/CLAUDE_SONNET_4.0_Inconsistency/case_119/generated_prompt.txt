Solve the 1D linear advection PDE u_t + q*u_x = 0 numerically with the following specifications.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter q = 1.5.
The boundary conditions are periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The exact solution for verification is u(x,t) = u0((x - q*t) mod 1), where u0 is the initial condition.
Use a uniform periodic grid with Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Apply 1st-order upwind finite difference for the spatial discretization of u_x.
Use Forward Euler for time integration.
Set the time step using CFL=0.5: dt0 = CFL*dx/abs(q), then Nt=ceil(T/dt0) and dt=T/Nt where T=1.0.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_018.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_018.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
