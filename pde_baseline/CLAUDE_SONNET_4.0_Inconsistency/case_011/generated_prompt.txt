Solve the Allen-Cahn PDE numerically with the following specifications:
The PDE is u_t = (0.02)^2*(u_xx + u_yy) + u - u^3.
The domain is (x,y) in [0,1] x [0,1], t in [0,0.1].
The parameter epsilon = 0.02.
Apply Dirichlet boundary conditions with u=0 on all boundaries.
Set the initial condition as u(x,y,0)=tanh((0.25 - r)/(sqrt(2)*0.02)) where r = sqrt((x-0.5)^2 + (y-0.5)^2).
Use semi-implicit time integration: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3, solving a sparse linear system each step.
Use uniform spatial discretization with 5-point Laplacian for u_xx+u_yy.
Enforce Dirichlet boundary conditions by setting boundary nodes to prescribed values at every time step.
Use grid parameters Nx=Ny=300 and dt=0.0001 for 1000 time steps.
Compute u(x,y,T=0.1) on the 2D grid.
Save "solution_agent_allen_cahn_05.npz" containing arrays x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_allen_cahn_05.png".
