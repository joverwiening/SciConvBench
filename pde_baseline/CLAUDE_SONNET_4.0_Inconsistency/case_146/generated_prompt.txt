Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions and time domain t in [0, 1.0].
Set parameter nu = 0.1.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Create uniform periodic grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement Strang splitting with each full time step dt consisting of: diffusion half-step (dt/2), advection full-step (dt), diffusion half-step (dt/2).
Solve diffusion half-steps exactly in Fourier space using FFT with u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx).
Solve advection full-step for inviscid Burgers equation using finite-volume update with Rusanov flux.
For Rusanov flux between u_left and u_right: alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left) where f(u)=0.5*u^2.
Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus and F_minus are fluxes at cell interfaces.
Use CFL=0.4 with estimated max speed ≈ 1, set dt0 = CFL*dx/1.0, choose Nt = ceil(T/dt0), then reset dt = T/Nt to hit final time T=1.0 exactly.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_burgers_nu0p1.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu0p1.png".
Print min(u), max(u), discrete mean value mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
