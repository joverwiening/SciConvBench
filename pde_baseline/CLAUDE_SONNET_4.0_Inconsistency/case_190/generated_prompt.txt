Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using Python with numpy.fft for FFT operations.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
Use parameters nu = 5.0 and rho = 2.0.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use fixed time step dt=0.001 with Nt=1000 steps to reach T=1.0 exactly.
Implement Strang splitting for each full time step dt with three substeps.
For diffusion half-steps, solve exactly in Fourier space using u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- real(IFFT(u_hat)).
For the reaction full-step, solve the logistic ODE exactly pointwise using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_reacdiff_nu5_rho2.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, rho, T, dx, dt, Nx, Nt.
