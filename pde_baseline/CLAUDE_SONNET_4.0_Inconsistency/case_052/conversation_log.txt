Q: What value should I use for the final time T? The domain specifies t ∈ [0, 0.8], but the output requirements ask to compute u(x,y,T=0.9) and the grid specification mentions T/dt0 and T/Nt, where T=0.9 would be outside the specified time domain.
A: The final time T should be 0.8, not 0.9. The output requirements should compute u(x,y,T=0.8) to stay within the specified time domain [0,0.8]. Use T=0.8 for all calculations including dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)), Nt = ceil(0.8/dt0), and dt = 0.8/Nt.
