Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use domain x in [0, 1) with periodic boundary and t in [0, 1.0].
Set parameter nu = 1.0.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Use explicit forward Euler time integration.
Use uniform periodic grid with Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement Strang splitting for each full time step dt with three substeps: diffusion half-step (dt/2), advection full-step (dt), diffusion half-step (dt/2).
For diffusion substeps, solve exactly in Fourier space using u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- IFFT(u_hat) taking real part.
For advection substep, use finite-volume update with Rusanov flux where f(u)=0.5*u^2, alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), and u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Use CFL=0.4 to set dt0 = CFL*dx/1.0, choose Nt = ceil(T/dt0), then reset dt = T/Nt to hit final time exactly.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_burgers_nu1.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu1.png".
Print min(u), max(u), discrete mean value mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T.
