Solve the wave equation PDE numerically with the following specifications:
The PDE is u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1] and the time domain is t in [0,1.0].
The parameter c = 1.0.
Apply Neumann boundary conditions with u_x(0,t)=0 and u_x(1,t)=0.
Use initial conditions u(x,0)=cos(pi*x) and u_t(x,0)=0.
The exact solution for verification is u(x,t)=cos(pi*x)*cos(1.0*pi*t).
Use a uniform spatial grid on [0,1] with Nx=400 intervals (401 points total).
Apply 2nd-order central differences for u_xx in the interior.
Use 2nd-order central difference time integration (leapfrog/Störmer-Verlet).
Set dx=1/Nx and choose dt so that CFL = c*dt/dx ≤ 0.9.
Initialize using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0).
Handle zero Neumann boundaries using ghost points with mirror values.
Set dt0 = 0.9*dx/c, Nt = ceil(T/dt0), and dt = T/Nt to hit final time exactly.
Compute u(x, T=1.0) on the grid.
Save "solution_agent_wave_06.npz" containing arrays x, u, and scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_06.png".
