Q: What value should I use for the parameter c in the wave equation? I see c = 2 listed in the parameters section, but the PDE shows u_tt = (1.0)^2 * u_xx and the exact solution uses cos(1.0*pi*t), which suggests c = 1.0 might be intended instead.
A: The parameter c should be 1.0. The PDE coefficient (1.0)^2 and the exact solution cos(1.0*pi*t) both indicate c = 1.0, not c = 2.
