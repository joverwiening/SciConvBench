Solve the 1D advection PDE u_t + beta * u_x = 0 numerically with the following specifications.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 2.0].
The parameter beta = 0.4.
The boundary condition is periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for verification is u(x,t) = u0((x - beta*t) mod 1), where u0(x) is the initial condition.
Use a uniform spatial grid with Nx=512 intervals on [0,1) creating Nx points on the periodic grid.
Set x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Apply 1st-order upwind finite difference for u_x using the upwind direction determined by the sign of beta.
Use explicit forward Euler for time integration.
Set the time step using CFL=0.5 with dt = CFL * dx / abs(beta).
Choose the number of steps Nt = ceil(T/dt) and then reset dt = T/Nt so that the final time T=2.0 is hit exactly.
Compute u(x,T=2.0) on the periodic grid.
Save "solution_pdebench_advection_beta0p4.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars beta, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_advection_beta0p4.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=2.0.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
Interpret '^' as exponentiation in the math and use '**' for powers in Python code.
