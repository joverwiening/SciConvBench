Solve the 1D Viscous Burgers PDE numerically with periodic boundary conditions.
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu = 4.0.
The boundary condition is periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use Strang splitting for each full time step dt with three substeps.
First substep: diffusion half-step (duration dt/2) solved exactly in Fourier space using FFT, where u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- IFFT(u_hat) taking the real part.
Second substep: advection full-step (duration dt) for inviscid Burgers equation using finite-volume update with Rusanov flux, where f(u)=0.5*u^2, alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), and u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Third substep: diffusion half-step again (same as first substep).
Use CFL=0.4 based on estimated max speed ≈ 1, set dt0 = CFL*dx/1.0, choose Nt = ceil(T/dt0), then reset dt = T/Nt.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_burgers_nu4.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu4.png".
Print min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
