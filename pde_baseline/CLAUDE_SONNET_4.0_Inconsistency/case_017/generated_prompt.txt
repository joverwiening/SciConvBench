Solve the PDE numerically with the specifications below.
Treat all functions exactly as written (use radians for trig).
Use '**' for powers in Python code.
The PDE is u_t = ∂/∂x( D(x) * u_x ), where D(x) = 0.1*(1 + x).
The spatial domain is x in [0,1], temporal domain is t in [0,0.5].
D(x) = 0.1*(1+x).
Boundary conditions are Dirichlet on x=0 and x=1: u(0,t)=0, u(1,t)=0.
Initial condition is u(x,0)=sin(pi*x).
Use a conservative 2nd-order discretization in flux form for (D(x) u_x)_x on a uniform grid x_i.
Define D_i = D(x_i).
Define face values by arithmetic averaging: D_{i+1/2} = 0.5*(D_i + D_{i+1}).
For interior i=1..Nx-1: ( (D u_x)_x )_i ≈ (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
Use implicit Euler time integration: (I - dt*L) u^{n+1} = u^n, where L is the discrete variable-coefficient diffusion operator above.
Solve the sparse linear system each step.
Use Nx=300 grid points.
Use dt=0.001 (600 steps).
