Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using Python with numpy.fft for FFT operations.

Set parameters nu = 2.0 and rho = 10.0.

Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Implement a uniform periodic grid with Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use a time grid with fixed dt=0.001 and Nt=1000 steps to reach T=1.0 exactly.
Apply Strang splitting for each full time step dt with three substeps: diffusion half-step (dt/2), reaction full-step (dt), diffusion half-step (dt/2).
For diffusion substeps, solve exactly in Fourier space using u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- real(IFFT(u_hat)).
For reaction substep, solve the logistic ODE exactly pointwise using u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute u(x,T=1.0) on the periodic grid.
