Solve the 1D nonlinear reaction-diffusion PDE u_t = 0.01*u_xx + 2.0*(u**2)*(1-u)**2 numerically.

Use explicit RK4 for time integration.
Set the time step dt = 0.0005.
Use Nt = 2000 time steps so the final time T = 1.0 is hit exactly.
Compute u(x,T=1.0) on the periodic grid.
