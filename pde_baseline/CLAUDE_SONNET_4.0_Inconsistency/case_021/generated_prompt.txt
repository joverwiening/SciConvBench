Solve the PDE u_t = 0.1 * u_xx numerically on domain x in [0,1], t in [0,0.5].
Use parameters D = 0.1 and beta = 1.0.
Apply Robin boundary conditions: u_x(0,t) + 1.0*u(0,t) = 0 at x=0 and u_x(1,t) + 1.0*u(1,t) = 0 at x=1.
Set initial condition u(x,0) = cos(pi*x).
Use uniform spatial grid with Nx=300 intervals and 2nd-order central differences for u_xx.
Implement Robin boundary conditions with 2nd-order one-sided differences: at x=0 use (-3*u0 + 4*u1 - u2)/(2*dx) + beta*u0 = 0, at x=1 use (3*uN - 4*u_{N-1} + u_{N-2})/(2*dx) + beta*uN = 0.
Use Crank-Nicolson time integration with dt=0.001 for 600 time steps to reach T=0.5.
Compute u(x, T=0.5) on the grid.
Save "solution_agent_diffusion_05.npz" containing arrays x, u and metadata T, dx, dt.
Save line plot of u(x,T) as "solution_agent_diffusion_05.png".
