Solve the 2D Darcy flow PDE numerically using Python with scipy.sparse for linear algebra operations.
The PDE is -∇ · ( a(x,y) ∇u(x,y) ) = 1 on domain (0,1) x (0,1).
Use beta = 2 and coefficient field a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Apply Dirichlet boundary conditions u = 0 on the entire boundary.
Use a uniform Cartesian grid with N=128 intervals in each direction (129 points including boundaries).
Set dx = dy = 1/N and x_i = i*dx, y_j = j*dy for i,j = 0,...,N.
Discretize using 2nd-order finite differences with face-centered harmonic averaging for interior nodes.
Use harmonic means for face coefficients: a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for interior unknowns and solve with conjugate gradient to tolerance 1e-10.
Compute u(x,y) on the full (N+1) x (N+1) grid including boundaries.
Save "solution_pdebench_darcy_beta1.npz" containing arrays x (1D), y (1D), u (2D shape [N+1, N+1]), and scalars beta, N, dx.
Save a heatmap plot of u(x,y) as "solution_pdebench_darcy_beta1.png".
Print min(u), max(u), and the discrete residual norm ||Au-b||_2 / ||b||_2 for the interior system.
