Set parameters nu = 10.0 and rho = 5.0.

Implement explicit forward Euler time integration with Strang splitting.
Create uniform periodic grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.

Apply Strang splitting for each time step: diffusion half-step (dt/2) in Fourier space, reaction full-step (dt) using exact logistic ODE solution, then diffusion half-step (dt/2) again.
