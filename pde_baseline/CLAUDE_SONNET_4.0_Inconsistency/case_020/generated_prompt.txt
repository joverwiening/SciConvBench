Solve the 2D diffusion PDE u_t = ∇·(D(x,y)∇u) numerically where D(x,y) = 0.05*(1 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The spatial domain is (x,y) in [0,1] x [0,1] and time domain is t in [0,0.1].
Apply Dirichlet boundary conditions u=0 on all boundary edges.
Use initial condition u(x,y,0)=sin(pi*x)*sin(pi*y).
Use a conservative 2nd-order spatial discretization in flux form on a uniform grid with Nx=Ny=80.
For face averages use D_{i+1/2,j}=0.5*(D_{i,j}+D_{i+1,j}) and D_{i,j+1/2}=0.5*(D_{i,j}+D_{i,j+1}).
For interior nodes the discretization is (∇·(D∇u))_{i,j} ≈ (1/dx^2)[D_{i+1/2,j}(u_{i+1,j}-u_{i,j}) - D_{i-1/2,j}(u_{i,j}-u_{i-1,j})] + (1/dy^2)[D_{i,j+1/2}(u_{i,j+1}-u_{i,j}) - D_{i,j-1/2}(u_{i,j}-u_{i,j-1})].
Use implicit Euler time integration (I - dt*L)u^{n+1} = u^n with dt=0.0005 for 200 steps to reach final time T=0.1.
Solve the sparse linear system at each time step.
Compute u(x,y,T=0.1) on the 2D grid.
Save "solution_agent_diffusion_04.npz" containing arrays x (1D), y (1D), u (2D with shape (len(y), len(x)) so u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
Save a heatmap plot of u(x,y,T) as "solution_agent_diffusion_04.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
