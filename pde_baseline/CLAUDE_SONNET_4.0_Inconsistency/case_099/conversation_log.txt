Q: What value should I use for the wave speed c in the PDE u_tt = c^2 * u_xx? I see that the PDE is written as u_tt = (1.0)^2 * u_xx, but the parameters section lists c = 2.
A: The wave speed c should be 1.0. The PDE is written as u_tt = (1.0)^2 * u_xx, which means c^2 = 1.0, so c = 1.0. Use c = 1.0 for all calculations including the CFL condition.
