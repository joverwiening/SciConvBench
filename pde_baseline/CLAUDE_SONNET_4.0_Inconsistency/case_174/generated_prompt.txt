Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using Python with NumPy/SciPy.

Set parameters nu = 0.5 and rho = 2.0.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Implement explicit forward Euler time integration.
Create uniform periodic grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use fixed time step dt=0.001 with Nt=1000 steps.
Apply Strang splitting for each full time step dt with diffusion half-step (duration dt/2) solved exactly in Fourier space using FFT, reaction full-step (duration dt) solved exactly pointwise for logistic ODE, then diffusion half-step again.

For reaction step use exact update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)) for each grid point.
Use NumPy's FFT functions for Fourier space calculations.
Compute u(x,T=1.0) on the periodic grid.
