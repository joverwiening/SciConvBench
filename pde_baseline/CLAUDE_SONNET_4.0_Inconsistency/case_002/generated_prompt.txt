Solve the PDE u_t + (-0.5)*u_x = 0 numerically on the domain x in [0,1) periodic, t in [0,1.0].
Use parameter a = -0.5.
Apply periodic boundary conditions: u(0,t) = u(1,t).
Set initial condition u(x,0) = exp(-100*(x-0.3)^2).
Use uniform periodic grid with Nx = 1000 points on [0,1) with no duplicated endpoint.
Set dx = 1/Nx.
Apply 1st-order upwind spatial discretization with right-biased (downwind) stencil since a < 0.
Use Forward Euler time integration.
Choose dt0 = 0.9*dx/|a| for CFL condition.
Set Nt = ceil(T/dt0) and then dt = T/Nt so final time T = 1.0 is hit exactly.
Handle boundaries with periodic wrap-around indexing.
Compute u(x, T=1.0) on the grid.
Save "solution_agent_advection_02.npz" containing arrays x (1D), u (1D), plus metadata scalars T, dx, dt.
Save line plot of u(x,T) as "solution_agent_advection_02.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
