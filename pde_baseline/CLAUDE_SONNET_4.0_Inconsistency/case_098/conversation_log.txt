Q: What value should I use for the wave speed c in the PDE u_tt = c^2 * u_xx? The PDE shows (1.5)^2 but the parameters section lists c = 3.
A: The wave speed c should be 1.5. The PDE shows u_tt = (1.5)^2 * u_xx, which means c = 1.5, and the parameters section should list c = 1.5 (not c = 3).
