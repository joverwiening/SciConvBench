Solve the Klein-Gordon PDE numerically with the following specifications:
The PDE is u_tt - (0.8)^2*(u_xx + u_yy) + (0.2)^2*u = 0.
The domain is (x,y) in [0,1] x [0,1], t in [0,1.0].
The parameters are c = 0.8 and m = 0.2.
Apply Dirichlet boundary conditions with u=0 on all boundaries.
Use initial condition u(x,y,0)=sin(2*pi*x)*sin(pi*y) and u_t(x,y,0)=0.
The exact solution for verification is u(x,y,t)=cos(sqrt((0.8)^2*((2*pi)^2 + (pi)^2) + (0.2)^2)*t)*sin(2*pi*x)*sin(pi*y).
Use uniform grid with 5-point Laplacian for spatial discretization of u_xx+u_yy.
Apply 2nd-order central difference in time for u_tt.
Use Taylor start for initialization using Laplacian and mass term.
Set Nx=Ny=160 intervals creating (Nx+1) by (Ny+1) grid points.
Set dx=dy=1/Nx.
Choose dt0 = 0.5*min(dx,dy)/c for CFL=0.5.
Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time T=1.0 is hit exactly.
Compute u(x,y,T=1.0) on the 2D grid.
Save "solution_agent_kg_06.npz" containing arrays x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T=1.0), plus metadata scalars T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T=1.0) as "solution_agent_kg_06.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T=1.0.
