Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use domain x in [0, 1) with periodic boundary and t in [0, 1.0].
Set parameter nu = 0.2.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Create uniform periodic grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement Strang splitting with three substeps per time step dt.
For diffusion half-steps, solve exactly in Fourier space using u_hat(k) <- FFT(u), k = 2*pi*fftfreq(Nx, d=dx), u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), u <- IFFT(u_hat) taking real part.
For advection full-step, use finite-volume update with Rusanov flux for inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
Define f(u)=0.5*u^2 and for each interface compute alpha = max(abs(u_left), abs(u_right)), F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell j using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.
Set time step using CFL=0.4 based on estimated max speed of 1.0, so dt0 = CFL*dx/1.0.
Choose Nt = ceil(T/dt0) and reset dt = T/Nt to hit final time T=1.0 exactly.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_burgers_nu0p2.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
