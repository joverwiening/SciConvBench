Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use domain x in [0,1) with periodic boundary conditions and t in [0,1.0].
Set parameter nu = 0.01.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Create uniform periodic grid with Nx=512 points on [0,1) using x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Implement Strang splitting with three substeps per time step dt.
For diffusion half-steps, solve exactly in Fourier space using numpy.fft.fft and numpy.fft.ifft.
Transform u_hat(k) <- FFT(u), get k = 2*pi*fftfreq(Nx, d=dx), apply u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), then u <- real(IFFT(u_hat)).
For advection full-step, use finite-volume update with Rusanov flux for inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0.
Define f(u)=0.5*u^2 and for each interface compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) where F_plus and F_minus are fluxes at adjacent interfaces.
Calculate time step using CFL=0.4 with estimated max speed = 1.0, so dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and then dt = T/Nt to hit final time T=1.0 exactly.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_pdebench_burgers_nu0p01.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu0p01.png".
Print min(u), max(u), discrete mean value mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
