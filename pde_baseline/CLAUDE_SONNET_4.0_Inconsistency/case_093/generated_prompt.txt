Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Use initial condition u(x,0)=sin(pi*x) and u_t(x,0)=0.

Use uniform spatial grid on [0,1] with Nx=400 intervals (401 points total).
Apply 2nd-order central differences for u_xx in the interior.

Set boundary nodes to prescribed values at every time step.
Use dt0 = 0.9*dx/c, then set Nt = ceil(T/dt0) and dt = T/Nt for exact final time.
Compute u(x, T=0.5) on the grid.
