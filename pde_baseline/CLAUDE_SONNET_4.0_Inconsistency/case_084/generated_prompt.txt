Solve the wave equation PDE numerically with the following specifications:

The PDE is u_tt = (1.0)^2 * u_xx with wave speed c = 1.0.
The spatial domain is x in [0,1] and temporal domain is t in [0,0.8].
Apply Dirichlet boundary conditions u=0 at x=0 and x=1.
Use initial condition u(x,0) = sin(pi*x) + 0.5*sin(3*pi*x) and u_t(x,0) = 0.
The exact solution for verification is u(x,t) = cos(1.0*pi*t)*sin(pi*x) + 0.5*cos(1.0*3*pi*t)*sin(3*pi*x).
Use a uniform spatial grid on [0,1] with Nx=600 intervals (601 points total) and 2nd-order central differences for u_xx.
Apply 2nd-order central difference time integration (leapfrog/Störmer-Verlet) with CFL = c*dt/dx ≤ 0.9.
Set dx = 1/Nx, dt0 = 0.9*dx/c, Nt = ceil(T/dt0), and dt = T/Nt to hit final time exactly.
Initialize using Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*c^2*u_xx^0.
Enforce Dirichlet boundary conditions at every time step.
Compute the solution at final time T=0.8.
Save "solution_agent_wave_03.npz" with arrays x, u and scalars T, dx, dt.
Save line plot "solution_agent_wave_03.png" showing u(x,T).
