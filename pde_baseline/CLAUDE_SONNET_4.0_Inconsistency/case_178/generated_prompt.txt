Solve the 1D Reaction-Diffusion PDE u_t = nu * u_xx + rho * u*(1 - u) numerically using Python with numpy.fft for FFT operations.
Use domain x in [0, 1) with periodic boundary and t in [0, 1.0].
Set parameters nu = 10.0 and rho = 2.0.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Implement spatial discretization with uniform periodic grid using Nx=512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Use time discretization with fixed dt=0.001 and Nt=1000 steps.
Apply Strang splitting method for each time step dt with three substeps: diffusion half-step (dt/2) solved exactly in Fourier space using FFT, reaction full-step (dt) solved exactly pointwise for logistic ODE, and another diffusion half-step (dt/2).
For diffusion substeps: compute u_hat(k) using FFT(u), set k = 2*pi*fftfreq(Nx, d=dx), update u_hat(k) with u_hat(k) * exp(-nu*k^2*(dt/2)), and recover u using real part of IFFT(u_hat).
For reaction substep: update each grid point using exact logistic ODE solution u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute final solution u(x,T=1.0) on the periodic grid.
