The PDE to be solved numerically is u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u ).
The function U(x) is cos(2*pi*x).
The derivative U'(x) is -2*pi*sin(2*pi*x).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter D is 0.01.
The parameter gamma is 1.0.
The initial condition is u(x,0) = 1.0 + 0.2*sin(2*pi*x).
A closed-form reference solution is not required.
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1, where dx=1/Nx.
The drift term is treated in conservative form, with flux F = (1/gamma)*U'(x)*u, so the PDE is u_t = D*u_xx - ∂_x(F).
Spatial discretization uses upwind finite-volume flux for ∂_x(F), based on the sign of the interface velocity b=U'(x)/gamma.
Spatial discretization uses 2nd-order central differences for u_xx.
Time integration uses Explicit SSP-RK2.
The time step dt is chosen as min(0.4*dx/max|b|, 0.2*dx^2/D), where b(x)=U'(x)/gamma.
The number of time steps Nt is ceil(T/dt).
The final time step dt is T/Nt.
