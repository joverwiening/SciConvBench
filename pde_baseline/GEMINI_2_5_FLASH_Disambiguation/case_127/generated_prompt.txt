The task is to solve the 1D linear advection–diffusion PDE numerically.
The PDE is u_t = -q1*∂_x( u ) + (q2/pi)*u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The numerical solution should be verified against a Fourier-mode evolution.
A uniform periodic spatial grid with Nx=512 points on [0,1) should be used.
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Spatial discretization should use 1st-order upwind for ∂_x(u) and 2nd-order central differences for u_xx.
A fully explicit time integration method should be used.
The time step dt should be calculated as min(0.4*dx/|q1|, 0.2*dx^2/(q2/pi)).
The number of time steps Nt should be ceil(T/dt), and dt should be reset to T/Nt.
