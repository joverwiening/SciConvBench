The task is to solve a scalar ordinary differential equation numerically.
The unknown field is u(t).
The ODE is du/dt = a*sin(exp(-0.5*t)*sin(3*t)) + b*u.
The time domain is t in [0.0, 5.0].
The parameter a is 1.0.
The parameter b is -0.3.
The initial condition is u(0.0) = 0.2.
No closed-form reference solution is required.
The numerical method for time integration is Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step is dt=0.001.
The number of time steps is Nt=5000, ensuring the final time is hit exactly.
The solution u(t) must be computed at all time points t_n = t0 + n*dt for n=0..Nt.
The results must be saved to "solution_molk_003.npz" containing arrays: t (1D length Nt+1), u (1D length Nt+1), and the parameter scalars.
A line plot of u(t) vs t must be saved as "solution_molk_003.png".
The values u(T), min(u), and max(u) over the time grid must be printed.
No error computation is required as no exact solution is provided.
