The task ID is pdebench_burgers_nu2em3.
The PDE category is 1D Viscous Burgers (periodic).
The unknown field is u(x,t).
The PDE to solve numerically is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The parameter nu is 0.002.
The boundary conditions are periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
No closed-form reference solution is required.
The spatial domain is x in [0, 1).
The final time T for the simulation is 1.0.
A uniform spatial grid with Nx=512 points must be used.
The numerical method is Strang splitting for each full time step dt.
The Strang splitting consists of three substeps: (A) Diffusion half-step (duration dt/2), (B) Advection full-step (duration dt), and (C) Diffusion half-step (duration dt/2).
Substep (A) and (C) involve solving the diffusion equation exactly in Fourier space.
For the diffusion half-step, compute u_hat(k) = FFT(u).
The wave numbers k are calculated as 2*pi*fftfreq(Nx, d=dx).
Update u_hat(k) as u_hat(k) * exp(-nu*k^2*(dt/2)).
Then, u is obtained by IFFT(u_hat), taking the real part.
Substep (B) involves solving the inviscid Burgers equation u_t + ∂_x(0.5*u^2)=0 using a finite-volume update with Rusanov (local Lax-Friedrichs) flux.
Define f(u)=0.5*u^2.
For each interface between u_left=u[j] and u_right=u[j+1] (with periodic indexing), calculate alpha = max(abs(u_left), abs(u_right)).
The flux F is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
For each cell j, F_plus is the flux between (u[j], u[j+1]) and F_minus is the flux between (u[j-1], u[j]).
The new value u_new[j] is calculated as u[j] - (dt/dx)*(F_plus - F_minus).
After the advection substep, replace u with u_new.
The time step is determined using a CFL condition.
Set dt0 = CFL*dx/1.0, where CFL=0.4 and the estimated max speed is 1.0.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is reset to T/Nt to hit the final time exactly.
The task requires computing u at the final time T on the grid.
Save the solution to "solution_pdebench_burgers_nu2em3.npz".
The .npz file must contain arrays: x (1D length Nx), u (1D length Nx), and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu2em3.png".
Report by printing min(u), max(u), the discrete mean value mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
