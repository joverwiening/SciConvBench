The task is to numerically solve the 1D inviscid Burgers equation.
The PDE is u_t = -k*∂_x( 0.5*u^2 ).
The parameter k is 1.0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.2].
The boundary conditions are periodic, u(0,t)=u(1,t) for all t.
The initial condition is u(x,0) = sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is uniform and periodic with Nx=1024 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization is a conservative finite-volume method.
The Rusanov (local Lax–Friedrichs) flux is used for f(u)=0.5*u^2.
The time integration method is SSP-RK2 (Heun).
The time step is determined using CFL=0.2.
Calculate dt0 = CFL*dx/max|u|, estimating max|u|≈1.
Set Nt=ceil(T/dt0).
The final time step dt is T/Nt.
