The task is to numerically solve the 1D dispersive beam / nonlinear wave PDE.
The PDE is u_tt + (q**2)*u_xxxx + c*∂_x( u * u_x ) = 0.
The unknown field is u(x,t), which is second order in time.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The parameter q is 0.05.
The parameter c is 1.0.
The initial condition for u(x,0) is 0.1*cos(2*pi*x).
The initial condition for u_t(x,0) is 0.
Fourier spectral derivatives should be used for u_x and u_xxxx.
RK4 should be used for time integration on (u,v).
The number of spatial grid points, Nx, is 512.
The time step size, dt, is 0.0001.
The solution u(x,T=0.5) should be computed on the periodic grid.
The solution should be saved to "solution_molk_016.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
A line plot of u(x,T) should be saved as "solution_molk_016.png".
The minimum, maximum, mean, and discrete L2 norm sqrt(sum(u^2)*dx) of u at T should be printed.
