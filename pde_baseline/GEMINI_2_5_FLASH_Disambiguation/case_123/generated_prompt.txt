The task ID is molk_022.
The PDE is a 1D nonlinear reaction–diffusion equation.
The unknown field is u(x,t).
The PDE is u_t = q1*u_xx + q2*(u**a)*(1-u) with a=2.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 2.0.
The parameter a is 2.0.
The boundary conditions are periodic, u(0,t)=u(1,t) for all t.
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
No closed-form reference solution is required.
The spatial discretization method for u_xx is 2nd-order central differences.
The temporal discretization method is Explicit RK4.
The number of spatial grid points (Nx) is 512.
The time step size (dt) is 0.0005.
The numerical solution u(x,T=1.0) on the periodic grid must be computed.
The solution must be saved to "solution_molk_022.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
A line plot of u(x,T) must be saved as "solution_molk_022.png".
The minimum, maximum, mean, and discrete L2 norm sqrt(sum(u^2)*dx) of u at T must be printed.
