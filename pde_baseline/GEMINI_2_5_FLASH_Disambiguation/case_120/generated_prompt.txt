The task is to numerically solve the 1D wave equation u_tt = q*u_xx.
The unknown field is u(x,t), which is second order in time.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q is 1.0.
The initial condition for u(x,0) is sin(2*pi*x).
The initial condition for u_t(x,0) is 0.
The number of spatial grid points (Nx) is 256.
The number of time steps (Nt) is 2000.
The numerical solution u(x,T=1.0) on the periodic grid must be computed.
The solution must be saved to "solution_molk_019.npz" containing arrays x and u, and scalars T, dx, Nx, and the parameter scalars.
A line plot of u(x,T) must be saved as "solution_molk_019.png".
The minimum, maximum, mean, and discrete L2 norm sqrt(sum(u^2)*dx) of u at T must be printed.
