The task is to numerically solve a 1D nonlinear reaction-diffusion PDE.
The PDE is u_t = q1*u_xx + q2*(u**2)*(1-u)**2.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q1 is 0.01.
The parameter q2 is 2.0.
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
The number of spatial grid points Nx is 512.
The time step size dt is 0.0005.
For spatial discretization, use 2nd-order central differences for u_xx.
For time integration, use Explicit RK4.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_023.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_023.png".
Report min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
