The task is to solve the ODE system numerically.
The ODE system is dv/dt = v - (v**3)/3 - w + I and dw/dt = (1/tau)*(v + a - b*w).
The unknown fields are v and w, which are functions of t.
The time domain is t in [0.0, 200.0].
The parameters are I = 0.5, a = 0.7, b = 0.8, and tau = 12.5.
The initial conditions are v(0.0) = -1.0 and w(0.0) = 1.0.
The numerical method for time integration is Classical 4th-order Runge–Kutta (RK4) with a fixed step size.
The time step is dt=0.05 with Nt=4000 steps.
The full state vector at all time points t_n = t0 + n*dt for n=0..Nt must be computed.
The solution must be saved to "solution_molk_009.npz".
The saved file must contain arrays: t (1D length Nt+1), Y (2D array shape [Nt+1, n_state]) with columns ordered as [v, w], and the parameter scalars.
Line plots of each state vs t must be saved as "solution_molk_009.png".
The final state values at T must be printed.
The min/max of each state over time must be printed.
