The task is to numerically solve the 1D convection-diffusion PDE: u_t = -q1*∂_x( 0.5*u^2 ) + (q2/pi)*u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.1.
The initial condition is u(x,0) = sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is uniform and periodic with Nx=512 points on [0,1).
Grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The overall spatial discretization should be implemented using a finite volume method.
The nonlinear flux term f(u)=0.5*u^2 should be discretized using a conservative finite-volume method with the Rusanov (local Lax–Friedrichs) flux.
The `alpha` parameter for the Rusanov flux should be 1.0.
The diffusion term u_xx should be discretized with 2nd-order central differences, incorporated into the finite-volume framework.
Time integration should use SSP-RK2 (Heun) with a fixed dt.
The fixed dt is computed based on both convection and diffusion stability.
D_eff is q2/pi.
dt_conv is CFL * dx / max|u0| with CFL=0.4 and max|u0|=1.
dt_diff is 0.4 * dx^2 / D_eff.
dt0 is min(dt_conv, dt_diff).
Nt is ceil(T/dt0).
The final time step dt is T/Nt, ensuring the final time is hit exactly.
All functions should be treated exactly as written, using radians for trigonometric functions.
Exponentiation in math should be interpreted as '^', and in Python code as '**'.
