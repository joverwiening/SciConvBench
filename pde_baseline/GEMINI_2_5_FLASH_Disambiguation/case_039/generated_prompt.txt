The task is to solve the 2D heat equation numerically.
The PDE is u_t = 0.2 * (u_xx + u_yy).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,0.2].
The parameter alpha is 0.2.
The initial condition is u(x,y,0) = sin(2*pi*x)*sin(pi*y).
The exact solution for verification is u(x,y,t) = exp(-0.2*((2*pi)^2 + (pi)^2)*t) * sin(2*pi*x)*sin(pi*y).
The spatial discretization uses a uniform grid on [0,1] x [0,1] with Nx=60 and Ny=60 intervals, resulting in Nx+1 by Ny+1 points.
The 5-point Laplacian (2nd-order) is used for spatial discretization.
The time integration uses Implicit Euler (backward Euler) for diffusion terms.
Dirichlet boundary conditions are enforced by fixing boundary nodes at each step, and a sparse linear system is solved for interior nodes.
The time step is dt=0.001, for a total of 200 steps to reach T=0.2.
The final solution u(x,y,T=0.2) on the 2D grid must be computed.
The solution must be saved to "solution_agent_heat_10.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_heat_10.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same grid must be computed and printed.
