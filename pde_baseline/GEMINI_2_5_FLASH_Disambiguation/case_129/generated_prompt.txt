The task is to numerically solve the 1D inviscid conservation law with cubic flux.
The PDE is u_t = -k*∂_x( (1/3)*u^3 ).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The numerical solution will use a uniform periodic grid with Nx=1024 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization is a conservative finite-volume method with Rusanov flux for f(u)=(1/3)u^3.
The time integration method is SSP-RK2.
The time step is determined using CFL=0.2.
The maximum absolute value of the flux derivative is estimated as max|f'(u)| = max|u^2|.
With the initial condition, max|u|<=0.5, so max|f'|<=0.25.
The initial time step dt0 is CFL*dx/max|f'|.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt.
The numerical solution should compute u(x,T=0.2) on the periodic grid.
The solution should be saved to "solution_molk_028.npz".
The .npz file should contain arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx, and k.
A line plot of u(x,T) should be saved as "solution_molk_028.png".
The minimum, maximum, mean, and discrete L2 norm sqrt(sum(u^2)*dx) of u at T should be printed.
No error computation is required as no exact solution is provided.
