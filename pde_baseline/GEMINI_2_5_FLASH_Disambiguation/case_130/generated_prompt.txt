The task is to solve a 1D nonlinear convection-diffusion PDE numerically.
The PDE is u_t = -q1*∂_x( sin(u) ) + (q2/pi)*u_xx.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required.
A uniform periodic spatial grid with Nx=1024 points on [0,1) should be used.
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization for the convection term ∂_x(sin(u)) should use a conservative finite-volume flux.
The Rusanov flux should be used for the convection term.
The wave speed alpha for the Rusanov flux should be set to 1.
The diffusion term u_xx should be discretized using 2nd-order central differences.
Time integration should use SSP-RK2.
The time step dt should be determined using a CFL condition.
The CFL number for advection is 0.2.
The CFL number for diffusion is 0.2.
The advective time step dt_adv is 0.2*dx/1.
The diffusive time step dt_diff is 0.2*dx^2/(q2/pi).
The preliminary time step dt is min(dt_adv, dt_diff).
The number of time steps Nt is ceil(T/dt).
The final time step dt is T/Nt to ensure the simulation ends exactly at T.
All functions should be treated exactly as written, using radians for trigonometric functions.
The exponentiation operator '^' in math should be interpreted as '**' in Python code.
