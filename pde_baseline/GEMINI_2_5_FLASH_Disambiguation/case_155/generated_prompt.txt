The CFL number will be assumed to be 0.5.

The task is to solve the 1D Compressible Navier–Stokes PDE numerically.
The PDE category is 1D Compressible Navier–Stokes (no heat conduction).
The unknown fields are rho(x,t), v(x,t), p(x,t).
All functions are to be treated exactly as written, using radians for trig functions.
The '^' symbol in math denotes exponentiation, and '**' should be used for powers in Python code.
The grid convention for a half-open domain [a,b) with periodicity is that Nx is the number of grid points with no duplicated endpoint, dx=(b-a)/Nx, and x_i=a+i*dx for i=0..Nx-1.
The PDE in conservative form is defined with m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
zeta is assumed to be equal to eta.
The PDE equations are: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.5].
The parameter Gamma = 1.6666666666666667.
The parameter eta = 0.01.
The parameter zeta = 0.01.
Boundary conditions are periodic on x=-1 and x=1.
Initial conditions are smooth and defined pointwise on the grid: rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
The numerical method requires a uniform finite-volume grid with Nx=400 cells on [-1,1].
Cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1, and dx = (1 - (-1))/Nx.
Conservative variables U = [rho, m, E] (cell averages) are to be evolved.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Positivity of rho and p must be enforced by clipping to a small floor (e.g., 1e-12) if needed.
For the convective flux, the Rusanov (local Lax-Friedrichs) numerical flux is to be used for the inviscid Euler part.
The convective flux function is F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Viscous terms require computing v_x with a centered difference on the cell-centered v values.
Then sigma = (zeta + 4/3*eta)*v_x.
Sigma at interfaces is approximated by averaging neighboring cell-centered sigma values.
Viscous contributions to the momentum and energy fluxes at interfaces are added as F_visc = [ 0, -sigma, -v*sigma ] (using interface-averaged v and sigma).
The total interface flux is F_total = F_hat + F_visc.
Time integration uses 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.
The time step dt is chosen each step by dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The CFL number is 0.5.
dt = min(dt_conv, dt_visc).
The last step is adjusted so the final time T is hit exactly.
For ghost cells and BC implementation, periodic boundary conditions require wrapping indices.
Outflow boundary conditions (if applicable) require setting ghost cell values equal to the nearest interior cell (zero-gradient).
Output requirements include computing rho(x,T), v(x,T), p(x,T) on the cell centers.
The solution must be saved as "solution_pdebench_cns1d_eta0p01_periodic_smooth.npz" containing arrays: x (1D length Nx), rho (1D), v (1D), p (1D), and scalars Gamma, eta, zeta, T, dx, CFL.
A 3-panel (or 3 separate) line plot(s) of rho, v, p vs x at T must be saved as "solution_pdebench_cns1d_eta0p01_periodic_smooth.png".
A report must be printed including min/max of rho and p (positivity check), and the mean of rho over the domain (mass conservation check).
The deliverables are the numerical solution, the requested files, and the printed scalar diagnostics.
