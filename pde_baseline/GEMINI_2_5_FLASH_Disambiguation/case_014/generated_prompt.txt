The task is to numerically solve the Burgers PDE.
The PDE is u_t + u*u_x = 0.005*u_xx.
The spatial domain is x in [0,1) and the time domain is t in [0,0.2].
The parameter nu is 0.005.
The initial condition is u(x,0)=0.5 + sin(2*pi*x).
The spatial discretization uses a conservative finite-volume / conservative finite-difference method.
The convection term (f(u))_x is discretized using the Rusanov (local Lax–Friedrichs) flux F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|) and f(u)=0.5*u^2.
The diffusion term u_xx is discretized using a 2nd-order central difference.
The time integration uses a 1st-order IMEX scheme, treating convection explicitly and diffusion implicitly.
The resulting linear system (I - dt*nu*L) u^{n+1} = u^n - dt*conv_term must be solved each step.
Periodic boundary conditions are applied on x.
The grid uses Nx=1200 points on [0,1), with dx=1/Nx.
The time step is dt=5e-5, with Nt=4000 steps to reach T=0.2 exactly.
The solution u(x, T=0.2) must be computed.
The solution must be saved to "solution_agent_burgers_02.npz" containing arrays x, u, and metadata scalars T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_burgers_02.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
