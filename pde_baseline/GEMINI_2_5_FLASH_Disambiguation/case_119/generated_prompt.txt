The task is to numerically solve the 1D linear advection PDE u_t + q*u_x = 0.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q is 1.5.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The spatial discretization method is 1st-order upwind finite difference for u_x.
The temporal discretization method is Forward Euler.
The number of spatial grid points is Nx=512.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The reference exact solution is u(x,t) = u0( (x - q*t) mod 1 ), where u0 is the initial condition.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_018.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_018.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
