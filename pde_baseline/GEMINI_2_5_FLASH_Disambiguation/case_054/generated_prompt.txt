The task is to solve the Klein-Gordon PDE numerically.
The unknown field is u(x,t).
The PDE is u_tt - (1.0)^2*u_xx + (1.0)^2*u = sin(pi*x)*cos(2*t).
The spatial domain is x in [0,1].
The temporal domain is t in [0,5.0].
The parameters are c = 1.0 and m = 1.0.
The initial condition for u(x,0) is 0.
The initial condition for u_t(x,0) is 0.
The boundary conditions are Dirichlet u=0 at x=0 and x=1.
The spatial discretization uses a uniform grid on the stated interval with 2nd-order central differences for u_xx.
The time integration uses 2nd-order central difference in time for u_tt (leapfrog).
The +m^2*u term is handled explicitly at time level n in the update.
The time step dt is chosen so that c*dt/dx ≤ 0.9.
The initialization uses a Taylor start from u0 and v0, including the -m^2*u0 (and forcing if present).
The grid uses Nx=400.
The time step dt=0.001, resulting in 5000 steps.
The forcing term is included at time level n in the leapfrog update.
The computation should produce u(x, T=5.0) on the grid used.
The solution should be saved to "solution_agent_kg_07.npz" containing arrays: x (1D), u (1D, same length as x), plus metadata scalars T, dx, dt.
A line plot of u(x,T) should be saved as "solution_agent_kg_07.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T should be printed.
