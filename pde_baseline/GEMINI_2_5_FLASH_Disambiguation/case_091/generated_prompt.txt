The task ID is agent_wave_10.
The PDE category is Wave equation.
The unknown field is u(x,t).
The PDE to solve numerically is u_tt = (1.0)^2 * u_xx + sin(pi*x)*sin(2*pi*t).
The spatial domain is x in [0,1].
The temporal domain is t in [0,1.0].
The boundary conditions are Dirichlet at x=0 and x=1, with u=0.
The initial condition for u(x,0) is 0.
The initial condition for u_t(x,0) is 0.
The spatial discretization uses a uniform grid on [0,1] with Nx intervals, resulting in Nx+1 points.
Second-order central differences are used for u_xx in the interior.
The time integration uses the standard second-order central difference in time (leapfrog / Störmer–Verlet).
The time step dt is chosen for stability such that CFL = c*dt/dx ≤ 0.9.
Initialization uses u(x,0)=u0(x).
u(x,dt) is computed using u_t(x,0)=v0(x) via the Taylor start: u^1 = u^0 + dt*v0 + 0.5*dt^2*(c^2*u_xx^0 + f^0).
For Dirichlet boundary conditions, boundary nodes are set to the prescribed value at every time step.
The grid uses Nx=400 intervals, meaning Nx+1 points.
dx is calculated as 1/Nx.
dt0 is calculated as 0.9*dx/c.
Nt is calculated as ceil(T/dt0).
dt is then set to T/Nt to hit the final time exactly.
The computation requires u(x, T=1.0) on the grid.
The solution must be saved to "solution_agent_wave_10.npz" containing 1D arrays x and u, plus scalar metadata T, dx, and dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_10.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
