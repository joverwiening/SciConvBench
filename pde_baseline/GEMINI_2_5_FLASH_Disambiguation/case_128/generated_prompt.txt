Task ID is molk_027.
The PDE category is 1D nonlinear convection–diffusion with cubic flux (periodic).
The unknown field is u(x,t).
The PDE is u_t = -q1*∂_x( (1/3)*u^3 ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary.
The temporal domain is t in [0, 0.5].
Parameter q1 is 1.0.
Parameter q2 is 0.05.
Boundary conditions are periodic: u(0,t)=u(1,t) for all t.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
Grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Spatial discretization uses a conservative finite-volume flux for ∂_x((1/3)u^3) using the Rusanov scheme with a wave speed alpha of 0.25.
Spatial discretization uses 2nd-order central differences for u_xx.
Time integration uses SSP-RK2.
The time step is determined using CFL=0.2.
Estimate max|f'(u)| = max|u^2|.
With |u|<=0.5 initially, max|f'|<=0.25.
Calculate dt0 = CFL*dx/max|f'|.
Calculate dt_diff=0.2*dx^2/(q2/pi).
Set dt=min(dt0,dt_diff).
Then calculate Nt=ceil(T/dt).
The final time step is dt=T/Nt.
