The task ID is molk_015.
The PDE is the 1D sine-Gordon equation: u_tt + q*sin(u) = u_xx.
The unknown field is u(x,t), which is second order in time.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 2.0].
The parameter q is 1.0.
The boundary conditions are periodic: u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t) for all t.
The initial condition for u is u(x,0) = 0.1*sin(2*pi*x).
The initial condition for u_t is u_t(x,0) = 0.
The desired number of spatial grid points, Nx, is 512.
The desired time step size, dt, is 0.0005.
The spatial discretization method for u_xx is 2nd-order central differences on the periodic grid.
The temporal discretization method is RK4 applied to the system (u, v) where v = u_t.
The task requires computing u(x,T=2.0) on the periodic grid.
The task requires saving "solution_molk_015.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
The task requires saving a line plot of u(x,T) as "solution_molk_015.png".
The task requires printing min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
