The task is to numerically solve the PDE u_tt = c^2 * u_xx.
The spatial domain is x in [0,1) with periodic boundary conditions, and the temporal domain is t in [0,1.0].
The parameter c is 1.0.
The boundary conditions are periodic on x: u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t).
The initial conditions are u(x,0)=cos(2*pi*x) and u_t(x,0)=0.
The reference exact solution is u(x,t)=cos(2*pi*x)*cos(2*pi*1.0*t).
The spatial discretization uses a uniform periodic grid with Nx=512 points on [0,1).
A 2nd-order central difference with periodic wrap-around is used for u_xx.
The time integration uses a 2nd-order central difference in time for u_tt.
The CFL condition c*dt/dx≤0.9 must be satisfied.
The grid spacing is dx=1/Nx.
The initial time step dt0 is calculated as 0.9*dx/c.
The number of time steps Nt is ceil(T/dt0), and the final time step dt is T/Nt to hit the final time T=1.0 exactly.
The initialization uses a Taylor start with the periodic Laplacian.
The computation requires u(x, T=1.0) on the grid.
The solution must be saved to "solution_agent_wave_05.npz" containing arrays x (1D), u (1D), and scalars T, dx, dt.
A line plot of u(x,T) must be saved as "solution_agent_wave_05.png".
The minimum u, maximum u, and the discrete L2 norm sqrt(sum(u^2)*dx) at T must be printed.
The maximum absolute error and L2 error versus the reference solution evaluated on the same x grid must be computed and printed.
