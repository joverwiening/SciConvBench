The PDE to solve numerically is u_t = -k*∂_x( sin(u) ).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required for verification.
The spatial grid is uniform and periodic with Nx=1024 points on [0,1).
Grid points are defined as x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization uses a conservative finite-volume Rusanov flux for f(u)=sin(u).
The wave speed alpha for the Rusanov flux is determined dynamically at each time step as alpha = max|cos(u)|.
The time integration method is SSP-RK2.
The SSP-RK2 method uses the form u^(1) = u^n + dt * L(u^n) and u^(n+1) = 0.5 * u^n + 0.5 * u^(1) + 0.5 * dt * L(u^(1)).
The time step is determined using a CFL number of 0.2.
The initial time step dt0 is calculated as CFL*dx/1.0.
The number of time steps Nt is ceil(T/dt0).
The final time step dt is T/Nt.
All functions are treated exactly as written, using radians for trigonometric functions.
Exponentiation in math uses '^', and in Python code, it uses '**'.
