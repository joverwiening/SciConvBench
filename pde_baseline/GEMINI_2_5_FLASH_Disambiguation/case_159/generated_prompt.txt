The task ID is pdebench_cns1d_shock_eta1em8_outflow.
The PDE category is 1D Compressible Navier–Stokes with no heat conduction.
The unknown fields are rho(x,t), v(x,t), and p(x,t).
All functions should be treated exactly as written, using radians for trigonometric functions.
In mathematical expressions, '^' denotes exponentiation.
The PDE is given in conservative form.
Let m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
Let the viscous stress be sigma = (zeta + 4/3*eta) * v_x.
Assume zeta = eta.
The PDE equations are: rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, and E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The temporal domain is t in [0, 0.2].
The parameter Gamma is 1.6666666666666667.
The parameter eta is 1e-08.
The parameter zeta is 1e-08.
Boundary conditions are transmissive/outflow (zero-gradient) at x=-1 and x=1.
The initial condition is a Riemann (shock-tube) discontinuity at x=0.
For x < 0, rho_L = 1.0, v_L = 0.0, and p_L = 1.0.
For x ≥ 0, rho_R = 0.1, v_R = 0.0, and p_R = 0.01.
The numerical method uses a uniform finite-volume grid with Nx=800 cells on [-1,1].
The cell centers are x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The spatial step dx is 0.0025.
Conservative variables U = [rho, m, E] (cell averages) are evolved.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Positivity of rho and p should be enforced by clipping to a small floor, such as 1e-12.
The convective flux uses the Rusanov (local Lax-Friedrichs) numerical flux for the inviscid Euler part.
F_conv(U) = [ m, m^2/rho + p, (E+p)*v ] with v = m/rho.
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where c = sqrt(Gamma*p/rho).
The numerical flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Viscous terms are computed by finding v_x with a centered difference on cell-centered v values.
Sigma is then calculated as (zeta + 4/3*eta)*v_x.
Sigma at interfaces is approximated by averaging neighboring cell-centered sigma values.
Viscous contributions to the momentum and energy fluxes at interfaces are added as F_visc = [ 0, -sigma, -v*sigma ] using interface-averaged v and sigma.
The total interface flux is F_total = F_hat + F_visc.
Time integration uses 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.
The time step dt is chosen each step by dt_conv = CFL * dx / max_j( |v_j| + c_j ) and dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step dt = min(dt_conv, dt_visc).
The last time step should be adjusted so the final time T is hit exactly.
Ghost cells for outflow boundary conditions are set equal to the nearest interior cell (zero-gradient).
The CFL number for time step calculation is 0.5.
The solution should compute rho(x,T), v(x,T), and p(x,T) on the cell centers.
The solution should be saved as "solution_pdebench_cns1d_shock_eta1em8_outflow.npz".
The .npz file must contain arrays: x (1D length Nx), rho (1D), v (1D), p (1D).
The .npz file must also contain scalars: Gamma, eta, zeta, T, dx, CFL.
A 3-panel line plot of rho, v, p vs x at T should be saved as "solution_pdebench_cns1d_shock_eta1em8_outflow.png".
The report should print the minimum and maximum of rho and p for positivity checks.
The report should also print the mean of rho over the domain for mass conservation checks.
