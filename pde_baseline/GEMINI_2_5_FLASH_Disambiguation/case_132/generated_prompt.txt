The task ID is molk_031.
The PDE category is 1D nonlinear convection–diffusion with cos flux (periodic).
The unknown field is u(x,t).
The PDE to solve is u_t = -q1*∂_x( cos(u) ) + (q2/pi)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary.
The temporal domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The boundary conditions are periodic, meaning u(0,t)=u(1,t) for all t.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
No closed-form reference solution is required.
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
Use x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization for the convection term uses a conservative finite-volume flux for ∂_x(cos(u)) with Rusanov flux.
The Rusanov flux uses a wave speed alpha=max|sin(u)|.
The diffusion term u_xx is discretized using 2nd-order central differences.
The time integration method is SSP-RK2.
The time step uses a CFL number of 0.2.
The advective time step dt_adv is 0.2*dx/1, noting max|sin(u)|<=1.
The diffusive time step dt_diff is 0.2*dx^2/(q2/pi).
The final time step dt is the minimum of dt_adv and dt_diff.
The number of time steps Nt is ceil(T/dt).
The final time step dt is adjusted to T/Nt.
