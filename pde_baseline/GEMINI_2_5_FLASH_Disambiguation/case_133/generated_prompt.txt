The task is to solve the 1D inviscid conservation law u_t = -k*∂_x( cos(u) ) numerically.
The unknown field is u(x,t).
The spatial domain is x in [0, 1) with periodic boundary conditions, and the time domain is t in [0, 0.2].
The parameter k is 1.0.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
A closed-form reference solution is not required.
The numerical method requirements are as follows:
The spatial grid is a uniform periodic grid with Nx=1024 points on [0,1).
The grid points are x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
The spatial discretization uses a conservative finite-volume Rusanov flux for f(u)=cos(u) with a wave speed alpha=max|sin(u)|<=1.
The time integration method is SSP-RK2.
The time step is determined by CFL=0.2, with dt0 = CFL*dx/1.0, Nt=ceil(T/dt0), and dt=T/Nt.
The numerical solution should compute u(x,T=0.2) on the periodic grid.
The solution should be saved to "solution_molk_032.npz" containing arrays: x, u, and scalars T, dx, Nx, and the parameter k.
A line plot of u(x,T) should be saved as "solution_molk_032.png".
The minimum, maximum, mean, and the discrete L2 norm sqrt(sum(u^2)*dx) of u at T should be printed.
No error calculation is required.
