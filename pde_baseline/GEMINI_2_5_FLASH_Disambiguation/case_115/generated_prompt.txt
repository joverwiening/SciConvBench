The task is to solve the 1D linear wave / Klein–Gordon-type equation numerically.
The unknown field is u(x,t), which is second order in time.
The PDE is u_tt + (q2**2)*(q1**4)*u = (q1**2)*u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The parameter q1 is 1.0.
The parameter q2 is 0.5.
The boundary conditions are periodic: u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t) for all t.
The initial condition for u(x,0) is sin(2*pi*x).
The initial condition for u_t(x,0) is 0.
The desired number of spatial grid points (Nx) is 256.
The desired time step (dt) is 0.0005.
The numerical solution u(x,T=1.0) on the periodic grid must be computed.
A file named "solution_molk_014.npz" must be saved, containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
A line plot of u(x,T) must be saved as "solution_molk_014.png".
The minimum, maximum, mean, and the discrete L2 norm sqrt(sum(u^2)*dx) of u at T must be printed.
