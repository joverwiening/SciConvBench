The task is to solve a 2D diffusion-reaction PDE numerically.
The PDE is u_t = 0.01*(u_xx + u_yy) + 2.0*u*(1 - u).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,1.0].
The initial condition is u(x,y,0)=0.2 + 0.05*cos(2*pi*x)*cos(2*pi*y).
The boundary conditions are zero Neumann on all boundary edges (∂u/∂n = 0).
The numerical method uses a uniform grid with Nx=Ny=120 intervals, resulting in Nx+1 by Ny+1 grid points.
The spatial discretization uses a 5-point Laplacian for diffusion.
The boundary conditions are implemented using ghost nodes (mirror values).
The time integration is a 1st order deterministic IMEX scheme, with diffusion treated implicitly (backward Euler) and reaction treated explicitly (forward Euler).
Each time step involves solving (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n), where L is the discrete Laplacian and R(u) is the reaction term.
A sparse direct solver is to be used at each time step.
The time step size is dt=0.001, for a total of Nt=1000 steps.
The final solution u(x,y,T=1.0) on the 2D grid must be computed.
The solution, along with x, y, T, dx, dy, and dt, must be saved to "solution_agent_diffusion_reaction_05.npz".
A heatmap/contour plot of u(x,y,T) must be saved as "solution_agent_diffusion_reaction_05.png".
The minimum value of u, maximum value of u, and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T must be printed.
