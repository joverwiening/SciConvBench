The task is to solve a 2D diffusion PDE numerically.
The PDE is u_t = 0.1 * u_xx + 0.01 * u_yy.
The spatial domain is [0,1] x [0,1].
The time domain is [0,0.2].
The diffusion coefficient for the x-derivative is Dx = 0.1.
The diffusion coefficient for the y-derivative is Dy = 0.01.
The initial condition is u(x,y,0)=sin(pi*x)*sin(pi*y).
The boundary conditions are Dirichlet u=0 on all boundary edges.
The exact solution for verification is u(x,y,t)=exp(-( 0.1+0.01 )*pi^2*t)*sin(pi*x)*sin(pi*y).
The spatial discretization uses a uniform grid with Nx=Ny=60 intervals.
The spatial discretization uses a standard 5-point Laplacian, scaling x-second derivatives by Dx and y-second derivatives by Dy.
The time integration method is Implicit Euler.
The time step is dt=0.001, for a total of 200 steps.
The final time T is 0.2.
Compute u(x,y,T=0.2) on the 2D grid.
Save "solution_agent_diffusion_03.npz" containing arrays: x (1D), y (1D), u (2D array with shape (len(y), len(x)) so that u[j,i] = u(x[i], y[j]) at T), plus metadata scalars T, dx, dy, dt.
Save a heatmap/contour plot of u(x,y,T) as "solution_agent_diffusion_03.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same grid.
