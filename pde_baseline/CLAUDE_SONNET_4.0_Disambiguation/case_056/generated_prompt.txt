Apply Dirichlet boundary conditions u = 0 at both x = 0 and x = 1.
Use uniform spatial grid with Nx = 600 intervals giving Nx+1 = 601 grid points including both endpoints.
Set dx = 1/Nx = 1/600.

Use 2nd-order central difference in time (leapfrog) for time integration of u_tt.

Choose dt so that c*dt/dx ≤ 0.9 by setting dt0 = 0.9*dx/c.
Set Nt = ceil(T/dt0) and then dt = T/Nt so the final time T = 0.7 is hit exactly.
Use Taylor start from initial conditions including the -m^2*u0 term for initialization.
Compute u(x, T=0.7) on the grid.
