Solve the PDE u_t = -k*∂_x(sin(u)) numerically with the following specifications:
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.2].
The parameter k = 1.0.
The boundary condition is periodic: u(0,t) = u(1,t) for all t.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
Use a uniform periodic grid with Nx=1024 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Apply conservative finite-volume Rusanov flux for f(u)=sin(u) with wave speed alpha=max|cos(u)|.
Use SSP-RK2 for time integration.
Set the time step using CFL=0.2: dt0 = CFL*dx/1.0, Nt=ceil(T/dt0), dt=T/Nt.
Compute the final time snapshot u(x,T=0.2) on the periodic grid.
Save an NPZ file "solution_molk_030.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter scalars.
Save a line plot of u(x,T) as "solution_molk_030.png".
Print diagnostics: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
