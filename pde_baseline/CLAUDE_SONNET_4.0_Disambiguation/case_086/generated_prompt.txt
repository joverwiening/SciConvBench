Solve the wave equation u_tt = (1.0)^2 * u_xx numerically on domain x in [0,1) periodic, t in [0,1.0].
Use parameters c = 1.0.
Apply periodic boundary conditions: u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t).
Use initial conditions u(x,0) = cos(2*pi*x) and u_t(x,0) = 0.
The exact solution for verification is u(x,t)=cos(2*pi*x)*cos(2*pi*1.0*t).
Use uniform periodic grid with Nx=512 points on [0,1) with no duplicated endpoint.
Set dx=1/Nx.
Use 2nd-order central difference with periodic wrap-around for spatial discretization of u_xx.
Use 2nd-order central difference in time for u_tt: u_tt = (u^(n+1) - 2u^n + u^(n-1))/dt^2.
Set dt0 = 0.9*dx/c for CFL condition, then Nt = ceil(T/dt0) and dt = T/Nt to hit final time exactly.
Initialize the time stepping using Taylor expansion: u^1 = u^0 + dt*u_t^0 + (dt^2/2)*u_tt^0.
Compute u_tt^0 using the periodic Laplacian on the initial condition u^0 = cos(2*pi*x) with u_t^0 = 0.
Compute the solution u(x, T=1.0) on the grid.
Save "solution_agent_wave_05.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_wave_05.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
