Q: What does "Use Taylor start with the periodic Laplacian" mean specifically for implementing the time stepping scheme?
A: For the second-order central difference time scheme u_tt = (u^(n+1) - 2u^n + u^(n-1))/dt^2, you need u^1 to start the scheme. Use Taylor expansion: u^1 = u^0 + dt*u_t^0 + (dt^2/2)*u_tt^0. Since u_tt = c^2*u_xx, compute u_tt^0 using the periodic Laplacian on the initial condition u^0 = cos(2*pi*x), and u_t^0 = 0.
