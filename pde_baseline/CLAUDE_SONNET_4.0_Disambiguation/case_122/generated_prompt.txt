Solve the 1D linear reaction-diffusion PDE u_t = q1*u_xx + q2*u numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use temporal domain t in [0, 0.5].
Set parameters q1 = 0.01 and q2 = -1.0.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x).
Use Nx = 256 grid points in space with dx = (1-0)/256 = 1/256.
Use dt = 0.001 with Nt = 500 time steps to reach final time T = 0.5.
Discretize spatial derivatives using 2nd-order central differences on the uniform periodic grid.
Use deterministic operator-splitting time integration with two steps per time step.
For diffusion step, solve (I - 0.5*dt*q1*L) u_tilde^{n+1} = (I + 0.5*dt*q1*L) u^n using Crank-Nicolson where L is the periodic 2nd-order Laplacian.
For reaction step, apply u^{n+1} = exp(q2*dt) * u_tilde^{n+1} exactly.
Compute the solution u(x,T=0.5) on the periodic grid.
Save "solution_molk_021.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter scalars q1, q2.
