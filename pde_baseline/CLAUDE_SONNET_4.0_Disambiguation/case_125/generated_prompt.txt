Solve the PDE u_t = -q1*∂_x( 0.5*u^2 ) + (q2/pi)*u_xx numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
Set q1 = 1.0 and q2 = 0.1.
Apply periodic boundary conditions where u(0,t) = u(1,t) for all t.
Use the initial condition u(x,0) = sin(2*pi*x).
Create a uniform periodic grid with Nx = 512 points on [0,1) using x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Discretize the nonlinear flux f(u) = 0.5*u^2 using conservative finite-volume with Rusanov (local Lax-Friedrichs) flux.
Discretize the diffusion term u_xx using 2nd-order central differences.
Use SSP-RK2 (Heun) time integration with fixed time step.
Compute the time step using D_eff = q2/pi, dt_conv = 0.4 * dx / max|u0| with max|u0| = 1, dt_diff = 0.4 * dx^2 / D_eff, and dt0 = min(dt_conv, dt_diff).
Set Nt = ceil(0.5/dt0) and dt = 0.5/Nt to hit the final time exactly.
The final time T is 0.5.
