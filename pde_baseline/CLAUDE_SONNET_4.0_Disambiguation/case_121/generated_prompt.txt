Solve the 1D reaction-diffusion PDE u_t = q1*u_xx + q2*u*(1-u) numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use temporal domain t in [0, 1.0].
Set parameters q1 = 0.01 and q2 = 5.0.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use Nx = 512 grid points in space with dx = (1-0)/512 = 1/512.
Use dt = 0.001 with Nt = 1000 time steps to reach final time T = 1.0.
Use 2nd-order central differences for spatial discretization of u_xx.
Use either IMEX Euler (diffusion implicit, reaction explicit) OR Strang splitting with diffusion via FFT and exact logistic reaction for time integration.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_020.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_020.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
