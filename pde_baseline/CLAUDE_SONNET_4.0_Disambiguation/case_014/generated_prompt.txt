Solve the Burgers PDE u_t + u*u_x = 0.005*u_xx numerically on domain x in [0,1), t in [0,0.2].
Use parameter nu = 0.005.
Apply initial condition u(x,0) = 0.5 + sin(2*pi*x).
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Discretize in conservative form u_t + (f(u))_x = nu*u_xx with f(u) = 0.5*u^2.
Use finite-volume/conservative finite-difference for convection with Rusanov flux: F_{i+1/2} = 0.5*(f(u_i)+f(u_{i+1})) - 0.5*alpha_{i+1/2}*(u_{i+1}-u_i), where alpha_{i+1/2} = max(|u_i|, |u_{i+1}|).
Approximate (f(u))_x as (F_{i+1/2}-F_{i-1/2})/dx.
Use 2nd-order central difference for diffusion: u_xx ≈ (u_{i+1}-2u_i+u_{i-1})/dx^2.
Use 1st-order IMEX time integration with forward Euler for explicit convection and backward Euler for implicit diffusion.
Formulate as (u^{n+1} - u^n)/dt + (F^n_{i+1/2}-F^n_{i-1/2})/dx = nu * (u^{n+1}_{i+1}-2u^{n+1}_i+u^{n+1}_{i-1})/dx^2.

Use dt=5e-5 with Nt=4000 steps to reach T=0.2 exactly.
