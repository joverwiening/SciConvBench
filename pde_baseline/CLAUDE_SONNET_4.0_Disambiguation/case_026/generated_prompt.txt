Solve the PDE u_t = 0.01*u_xx + u*(1-u)*(u-0.25) numerically.
The spatial domain is x in [0,1] and time domain is t in [0,0.5].
The diffusion coefficient D = 0.01 and parameter a = 0.25.
Use Dirichlet boundary conditions: u(0,t) = 1 and u(1,t) = 0.
The initial condition is u(x,0) = 0.5*(1 - tanh((x-0.5)/0.02)).
Use 2nd-order central differences for spatial discretization on a uniform grid.
Use 1st order IMEX time integration: diffusion implicit (backward Euler), reaction explicit (forward Euler).
At each step solve (I - dt*D*L) u^{n+1} = u^n + dt * R(u^n) where L is the discrete Laplacian and R(u) is the reaction term.
Use a sparse direct solver at each time step.
Use Nx = 600 spatial intervals and dt = 0.0002 (2500 time steps).
Compute u(x, T=0.5) on the grid.
Save "solution_agent_diffusion_reaction_04.npz" containing arrays x (1D), u (1D), and metadata scalars T, dx, dt.
Save a line plot of u(x,T) as "solution_agent_diffusion_reaction_04.png".
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
