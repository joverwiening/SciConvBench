Solve the PDE u_tt + (q2**2)*(q1**4)*u = (q1**2)*u_xx numerically using the following specifications.
Use a spatial domain x in [0, 1) with periodic boundary conditions and time domain t in [0, 1.0].
Set parameters q1 = 1.0 and q2 = 0.5.
Apply periodic boundary conditions u(0,t)=u(1,t) and u_x(0,t)=u_x(1,t) for all t.
Use initial conditions u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.
Use Nx=256 grid points for spatial discretization.
Convert the second-order PDE to a first-order system by letting v = u_t, then u_t = v and v_t = (q1**2)*u_xx - (q2**2)*(q1**4)*u.
Use RK4 (4th-order Runge-Kutta) for time integration with dt=0.0005 and Nt=2000 steps.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_014.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_014.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
The exact solution for verification is u(x,t) = cos(omega*t) * sin(2*pi*x), where omega = sqrt(q2^2*q1^4 + q1^2*(2*pi)^2) = 6.303048278758258.
