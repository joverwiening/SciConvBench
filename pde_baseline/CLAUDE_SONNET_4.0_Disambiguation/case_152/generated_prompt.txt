Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
The spatial domain is x ∈ [0, 1) with periodic boundary conditions.
The time domain is t ∈ [0, 1.0] with final time T = 1.0.
Use nu = 0.002 as the viscosity parameter.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = sin(2*pi*x).
Use a uniform spatial grid with Nx = 512 points on the half-open interval [0,1).
Calculate dx = (1-0)/Nx = 1/512 and x_i = 0 + i*dx for i = 0..Nx-1.
Implement Strang splitting for each time step dt with three substeps: diffusion half-step, advection full-step, diffusion half-step.
For diffusion substeps, solve exactly in Fourier space using FFT with k = 2*pi*fftfreq(Nx, d=dx) and u_hat(k) *= exp(-nu*k^2*(dt/2)).
For the advection substep, use finite-volume update with Rusanov flux for the inviscid Burgers equation.
Define f(u) = 0.5*u^2 and for each interface calculate alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus) with periodic indexing.
Set time step using CFL = 0.4 with dt0 = CFL*dx/1.0, then Nt = ceil(T/dt0) and dt = T/Nt.
Compute the solution u at final time T = 1.0.
Save "solution_pdebench_burgers_nu2em3.npz" containing arrays x, u and scalars nu, T, dx, dt, Nx, Nt.
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu2em3.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
