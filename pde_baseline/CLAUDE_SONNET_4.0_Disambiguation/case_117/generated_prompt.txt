Solve the PDE u_tt + (q**2)*u_xxxx + c*∂_x( u * u_x ) = 0 numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.5].
Use parameters q = 0.05 and c = 1.0.
Apply periodic boundary conditions where u and all x-derivatives are periodic on [0,1).
Set initial conditions u(x,0) = 0.1*cos(2*pi*x) and u_t(x,0) = 0.
Use Nx=512 grid points for spatial discretization.
Convert the second-order PDE to first-order system: u_t=v, v_t = -(q**2)*u_xxxx - c*∂_x(u*u_x).
Use RK4 (Runge-Kutta 4th order) time stepping with dt=0.0001 and Nt=5000 steps.
Use Fourier spectral derivatives for computing both u_x and u_xxxx since periodic boundary conditions are applied.
Compute u(x,T=0.5) on the periodic grid.
Save "solution_molk_016.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_016.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
