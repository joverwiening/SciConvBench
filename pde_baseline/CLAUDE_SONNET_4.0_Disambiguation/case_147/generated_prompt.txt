Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 0.2.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0, 1) with Nx = 512 grid points.
Set dx = (1-0)/Nx = 1/512.
Set grid points x_i = 0 + i*dx for i = 0 to Nx-1.
Use Strang splitting for time integration with three substeps per time step.
For diffusion substeps, solve exactly in Fourier space using u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
Set k = 2*pi*fftfreq(Nx, d=dx).
For advection substep, use finite-volume update with Rusanov flux for inviscid Burgers equation.
Define f(u) = 0.5*u^2.
For each interface, compute alpha = max(abs(u_left), abs(u_right)).
Compute flux F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell: u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Use CFL = 0.4 with estimated max speed = 1.0.
Set dt0 = CFL*dx/1.0.
Set Nt = ceil(T/dt0) and dt = T/Nt.
Run simulation to final time T = 1.0.
Save results to "solution_pdebench_burgers_nu0p2.npz" with arrays x, u and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu0p2.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time.
