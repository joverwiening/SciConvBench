Solve the 1D nonlinear convection-diffusion PDE u_t = -q1*∂_x(sin(u)) + (q2/pi)*u_xx numerically.
Use spatial domain x in [0,1) with periodic boundary conditions and temporal domain t in [0,0.5].
Set parameters q1 = 1.0 and q2 = 0.05.
Apply initial condition u(x,0) = 0.5*sin(2*pi*x).
Use uniform periodic grid with Nx=1024 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Discretize the convection term ∂_x(sin(u)) using conservative finite-volume flux with Rusanov flux and wave speed alpha=max|cos(u)|.
Discretize the diffusion term u_xx using 2nd-order central differences.
Use SSP-RK2 for time integration.
Set time step using CFL=0.2 with dt_adv=0.2*dx/1 and dt_diff=0.2*dx^2/(q2/pi), then dt=min(dt_adv,dt_diff), Nt=ceil(T/dt), dt=T/Nt where T=0.5.
Compute u(x,T=0.5) on the periodic grid.
Save "solution_molk_029.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_029.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=0.5.
