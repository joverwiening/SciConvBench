Solve the 1D Viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu * u_xx numerically.
Use nu = 0.001.
Apply periodic boundary conditions: u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = sin(2*pi*x).
Use spatial domain [0,1) with Nx=512 grid points.
Set x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Run simulation until final time T = 1.0.
Use Strang splitting with three substeps per time step dt.
For diffusion half-steps, solve exactly in Fourier space using FFT with k = 2*pi*fftfreq(Nx, d=dx) and u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
For advection full-step, use finite-volume update with Rusanov flux for inviscid Burgers equation.
Define f(u)=0.5*u^2 and for each interface compute alpha = max(abs(u_left), abs(u_right)) and F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
Update each cell j as u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
Use CFL=0.4 with estimated max speed ≈ 1 to set dt0 = CFL*dx/1.0.
Choose Nt = ceil(T/dt0) and reset dt = T/Nt for exact final time.
Save "solution_pdebench_burgers_nu1em3.npz" containing arrays x, u and scalars nu, T, dx, dt, Nx, Nt.
Save line plot of u(x,T) as "solution_pdebench_burgers_nu1em3.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at final time T.
