Solve the 1D compressible Navier-Stokes PDE system numerically using finite volume method.
Use conservative form with rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, E_t + ((E+p)*v - v*sigma)_x = 0.
Define m = rho*v, E = p/(Gamma-1) + 0.5*rho*v^2, sigma = (zeta + 4/3*eta) * v_x.
Set Gamma = 1.6666666666666667, eta = 1e-08, zeta = eta = 1e-08.
Use spatial domain x in [-1, 1] with Nx = 800 cells and cell-centered grid.
Use time domain t in [0, 0.2].
Apply transmissive/outflow boundary conditions at x = -1 and x = 1.
Set Riemann initial condition with discontinuity at x = 0.
For x < 0 use rho_L = 0.445, v_L = 0.698, p_L = 3.528.
For x >= 0 use rho_R = 0.5, v_R = 0.0, p_R = 0.571.
Use Rusanov numerical flux for convective terms.
Use centered differences for viscous terms.
Use 2-stage SSP-RK2 time integration with CFL = 0.4.
Compute time step dynamically using dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
Set dt = min(dt_conv, dt_visc) and adjust final step to hit T = 0.2 exactly.
Compute rho(x,T), v(x,T), p(x,T) on cell centers.
Save solution_pdebench_cns1d_sod6_eta1em8_outflow.npz with arrays x, rho, v, p and scalars Gamma, eta, zeta, T, dx, CFL.
Save 3-panel line plot as solution_pdebench_cns1d_sod6_eta1em8_outflow.png.
Print min/max of rho and p for positivity check and mean of rho for mass conservation check.
