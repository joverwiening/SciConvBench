Solve the 1D diffusion/heat equation u_t = c1 * u_xx numerically using the following specifications.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5].
Use c1 = 0.2 as the diffusion coefficient.
Apply periodic boundary conditions where u(0,t) = u(1,t) for all t.
Set the initial condition as u(x,0) = sin(2*pi*x).
Use Nx = 256 grid points for spatial discretization.
Use the Crank-Nicolson method for temporal discretization.
Use dt = 0.001 for the time step size.
Compute u(x,T=0.5) on the periodic grid.
Save "solution_molk_012.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_012.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compare against the exact solution u(x,t) = exp(-c1*(2*pi)^2*t) * sin(2*pi*x).
Compute and print the max absolute error and L2 error versus the reference solution evaluated on the same x grid.
