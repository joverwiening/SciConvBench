Solve the 1D nonlinear reaction-diffusion PDE u_t = q1*u_xx + q2*(u**2)*(1-u)**2 numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use temporal domain t in [0, 1.0].
Set parameters q1 = 0.01 and q2 = 2.0.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.2 + 0.1*sin(2*pi*x).
Use Nx = 512 grid points in space with dx = (1-0)/512 = 1/512.
Use explicit RK4 time stepping with dt = 0.0005 and Nt = 2000 steps.
Compute the solution u(x,T=1.0) on the periodic grid.
Save "solution_molk_023.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars q1 and q2.
Save a line plot of u(x,T) as "solution_molk_023.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T=1.0.
