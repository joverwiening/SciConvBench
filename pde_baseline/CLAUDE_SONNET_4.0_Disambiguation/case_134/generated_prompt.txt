Solve the 1D advection-diffusion PDE u_t = D*u_xx - (1/gamma)*∂_x( U'(x) * u ) numerically with the following specifications:

The PDE has U(x) = cos(2*pi*x) and U'(x) = -2*pi*sin(2*pi*x).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
Use parameters D = 0.01 and gamma = 1.0.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Set initial condition u(x,0) = 1.0 + 0.2*sin(2*pi*x).
Use a uniform periodic grid with Nx = 512 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx = 1/Nx.
Treat the drift term in conservative form as flux F = (1/gamma)*U'(x)*u so the PDE becomes u_t = D*u_xx - ∂_x(F).
Use upwind finite-volume flux for ∂_x(F) based on the sign of interface velocity b = U'(x)/gamma.
Use 2nd-order central differences for u_xx.
Apply explicit SSP-RK2 time integration.
Choose time step dt = min(0.4*dx/max|b|, 0.2*dx^2/D) where b(x) = U'(x)/gamma, then set Nt = ceil(T/dt) and dt = T/Nt.
Save "solution_molk_033.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
Save a line plot of u(x,T) as "solution_molk_033.png".
Print min(u), max(u), mean(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T = 1.0.
