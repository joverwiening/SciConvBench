Solve the PDE u_t = -q1*∂_x( cos(u) ) + (q2/pi)*u_xx numerically.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 0.5] with final time T = 0.5.
Set q1 = 1.0 and q2 = 0.05.
Apply periodic boundary conditions u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = 0.5*sin(2*pi*x).
Use uniform periodic grid with Nx = 1024 points on [0,1) where x_j = j*dx for j = 0,...,Nx-1 with dx = 1/Nx.
Apply conservative finite-volume flux for ∂_x(cos(u)) using Rusanov flux with wave speed alpha = max|sin(u)|.
Use 2nd-order central differences for u_xx.
Apply SSP-RK2 for time integration.
Set CFL = 0.2 and compute dt_adv = 0.2*dx/1 and dt_diff = 0.2*dx^2/(q2/pi).
Use dt = min(dt_adv, dt_diff), Nt = ceil(T/dt), and dt = T/Nt.
Treat all functions exactly as written using radians for trigonometric functions.
Use ** for exponentiation in Python code.
