Solve the PDE u_t = -k*∂_x( (1/3)*u^3 ) numerically with the following specifications:
Domain is x in [0, 1) with periodic boundary, t in [0, 0.2].
Parameter k = 1.0.
Boundary conditions are periodic: u(0,t)=u(1,t) for all t.
Initial condition is u(x,0) = 0.5*sin(2*pi*x) using the standard mathematical constant π (numpy.pi or math.pi in Python).
Use uniform periodic grid with Nx=1024 points on [0,1) where x_j = j*dx for j=0,...,Nx-1 with dx=1/Nx.
Apply conservative finite-volume method with Rusanov flux for f(u)=(1/3)u^3.
Use SSP-RK2 for time integration.
Set time step using CFL=0.2: estimate max|f'(u)| = max|u^2|; with |u|<=0.5 initially, max|f'|<=0.25; set dt0=CFL*dx/max|f'|, Nt=ceil(T/dt0), dt=T/Nt.
Compute u(x,T=0.2) on the periodic grid.
Save NPZ file "solution_molk_028.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter scalars.
Save plot as line plot of u(x,T) as "solution_molk_028.png".
Print diagnostics: min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T=0.2.
