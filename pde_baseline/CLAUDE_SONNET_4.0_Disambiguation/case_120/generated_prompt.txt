Solve the 1D wave equation u_tt = q*u_xx numerically with the following specifications:
Convert to first-order system with v = u_t: u_t = v, v_t = q*u_xx.

Use Nx = 256 grid points.

Initial conditions are u(x,0) = sin(2*pi*x) and u_t(x,0) = 0.
The exact solution is u(x,t) = cos(2*pi*sqrt(q)*t) * sin(2*pi*x) = cos(6.283185307179586*t)*sin(2*pi*x).
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_019.npz" containing arrays: x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus the parameter scalars.
