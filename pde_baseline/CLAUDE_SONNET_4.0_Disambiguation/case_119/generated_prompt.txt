Solve the 1D linear advection PDE u_t + q*u_x = 0 numerically.
Use spatial domain x in [0, 1) with periodic boundary conditions.
Use time domain t in [0, 1.0].
Set parameter q = 1.5.
Apply periodic boundary condition u(0,t) = u(1,t) for all t.
Use initial condition u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
Use Nx = 512 grid points for spatial discretization.
Use 1st-order upwind finite difference for spatial discretization of u_x.
Use Forward Euler for time integration.
Use CFL = 0.5 to determine time step: dt0 = CFL*dx/abs(q), then set Nt = ceil(T/dt0) and dt = T/Nt.
Compute u(x,T=1.0) on the periodic grid.
Save "solution_molk_018.npz" containing arrays x (1D length Nx), u (1D length Nx), and scalars T, dx, Nx plus parameter scalars.
Save line plot of u(x,T) as "solution_molk_018.png".
Print min(u), max(u), mean(u), and discrete L2 norm sqrt(sum(u^2)*dx) at T.
Compute and print max absolute error and L2 error versus exact solution u(x,t) = u0((x - q*t) mod 1) where u0 is the initial condition.
