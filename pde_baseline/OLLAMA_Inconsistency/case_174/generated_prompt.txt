Solve the PDE u_t = nu * u_xx + rho * u * (1 - u) on the domain x in [0, 1) with periodic boundary conditions and t in [0, 1.0].  
Use the parameters nu = 0.5 and rho = 2.0.  
Set the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).  
Create a uniform periodic grid with Nx = 512 points, dx = 1 / Nx, and x_j = j * dx for j = 0,…,511.  
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
Apply explicit forward Euler time integration with Strang splitting each full time step dt:  
(A) Perform a diffusion half‑step of duration dt/2 solved exactly in Fourier space by taking the FFT of u, multiplying each Fourier mode by exp(-nu * k^2 * dt/2) where k = 2 * pi * fftfreq(Nx, d=dx), and then taking the real part of the inverse FFT.  
(B) Perform a reaction full‑step of duration dt solved exactly pointwise for the logistic ODE using the update u <- (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).  
(C) Perform another diffusion half‑step identical to step (A).  
After completing all Nt steps, compute the solution u(x, T) on the periodic grid.  
Save the results in a file named "solution_pdebench_reacdiff_nu0p5_rho2.npz" containing the arrays x (length Nx) and u (length Nx) and the scalar values nu, rho, T, dx, dt, Nx, and Nt.  
Save a line plot of u(x, T) as "solution_pdebench_reacdiff_nu0p5_rho2.png" without requiring axis labels or a title.  
Print the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2) * dx) at time T.
