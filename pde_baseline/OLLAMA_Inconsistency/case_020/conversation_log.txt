Q: Which linear solver and tolerance would you like to use for solving the implicit Euler linear system at each time step?
A: Use a sparse direct solver (e.g., `scipy.sparse.linalg.spsolve` or the factorized version) to solve the linear system at each Implicit Euler step. No explicit tolerance is needed – the direct solve works to machine precision. If you prefer an iterative method, a Conjugate‑Gradient solver with a relative tolerance of `1e-8` (and a similar absolute tolerance) would be a reasonable choice.
