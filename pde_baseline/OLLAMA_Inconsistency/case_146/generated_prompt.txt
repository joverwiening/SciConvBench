Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.1 on the periodic domain x ∈ [0,1) and time interval t ∈ [0,1.0].  
Use the initial condition u(x,0) = sin(2*pi*x).  
Create a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and x_j = j*dx for j = 0,…,511.  
Apply Strang splitting for each full time step dt: diffusion half-step solved exactly in Fourier space, advection full-step using a finite‑volume Rusanov flux as specified, then another diffusion half-step.  
Determine dt from CFL = 0.4 with estimated max speed ≈ 1: dt0 = CFL*dx, Nt = ceil(T/dt0), then set dt = T/Nt so that the final time T = 1.0 is reached exactly.  
Perform Nt time steps to obtain the solution u(x,T) at T = 1.0.  
Save the results in "solution_pdebench_burgers_nu0p1.npz" containing the arrays x and u and the scalars nu, T, dx, dt, Nx, and Nt.  
Save a line plot of u(x,T) as "solution_pdebench_burgers_nu0p1.png".
