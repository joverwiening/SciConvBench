Solve the PDE u_t = ∂/∂x( D(x) u_x ) with D(x)=0.1*(1+x) on the spatial domain x∈[0,1] and time interval t∈[0,0.5].  
Apply Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 and the initial condition u(x,0)=sin(pi*x).  
Discretize the spatial domain with Nx=300 uniform intervals, compute dx=(1-0)/300, and define grid points x_i = i*dx for i=0,…,300.  
Use a conservative second‑order discretization in flux form for (D u_x)_x: define D_i = D(x_i) and face values D_{i+1/2}=0.5*(D_i+D_{i+1}), then for interior i=1,…,Nx‑1 approximate (D u_x)_x_i ≈ (1/dx^2)[ D_{i+1/2}(u_{i+1}-u_i) – D_{i‑1/2}(u_i‑u_{i‑1}) ].  
Integrate in time with implicit Euler using dt=0.001 for 500 steps to reach T=0.5, forming the linear system (I‑dt*L) u^{n+1}=u^n at each step.  
Solve each linear system with the direct sparse solver scipy.sparse.linalg.spsolve.  
After the final time step compute the solution u(x,T) on the grid.  
Save the arrays x and u and the scalar metadata T, dx, and dt in a file named solution_agent_diffusion_01.npz in the current working directory.  
Create a line plot of u(x,T) and save it as solution_agent_diffusion_01.png in the current working directory, omitting axis labels and title.
