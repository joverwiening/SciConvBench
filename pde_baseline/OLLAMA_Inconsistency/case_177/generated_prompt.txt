Solve the PDE u_t = nu * u_xx + rho * u * (1 - u) on the domain x in [0, 1) with periodic boundary conditions and t in [0, 1.0].  
Use the parameters nu = 10.0 and rho = 10.0.  
Create a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and x_j = j * dx for j = 0,…,511.  
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
Apply Strang splitting for each full time step dt:  
(A) Perform a diffusion half-step of duration dt/2 by transforming u to Fourier space with FFT, multiplying each Fourier coefficient by exp(-nu * k^2 * (dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then inverse transforming with IFFT and taking the real part.  
(B) Perform a reaction full-step of duration dt by updating each grid point exactly for the logistic ODE: u <- (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).  
(C) Perform another diffusion half-step identical to (A).  
Set the initial condition u(x,0) = 0.25 + 0.1 * sin(2 * pi * x) (using radians).  
After completing all time steps, compute u(x, T = 1.0) on the periodic grid.  
Save the arrays x (length Nx) and u (length Nx) together with the scalar values nu, rho, T, dx, dt, Nx, and Nt to a file named "solution_pdebench_reacdiff_nu10_rho10.npz" in the current working directory.  
Create a line plot of u versus x, label the x‑axis as “x”, the y‑axis as “u(x, T)”, and add the title “Solution at T = 1.0”. Save the plot as "solution_pdebench_reacdiff_nu10_rho10.png" in the current working directory.  
Print to the console the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2) * dx) at time T.
