Solve the PDE u_t = nu * u_xx + rho * u * (1 - u) on the spatial domain x ∈ [0, 1) with periodic boundary conditions and time interval t ∈ [0, 1.0].  
Use the parameters nu = 0.5 and rho = 10.0.  
Set the initial condition u(x, 0) = 0.25 + 0.1 * sin(2 * pi * x).  
Create a uniform periodic grid with Nx = 512 points, dx = 1 / Nx, and grid points x_j = j * dx for j = 0,…,511.  
Use a fixed time step dt = 0.001 and Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
Advance the solution using Strang splitting for each full time step dt:  
(A) Perform a diffusion half-step of duration dt/2 by transforming u to Fourier space with FFT, multiplying each Fourier mode by exp(-nu * k^2 * (dt/2)) where k = 2 * pi * fftfreq(Nx, d = dx), then applying the inverse FFT and taking the real part.  
(B) Perform a reaction full-step of duration dt by updating each grid point exactly for the logistic ODE: u ← (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).  
(C) Perform another diffusion half-step identical to step (A).  
After completing all Nt steps, compute the solution u(x, T) on the periodic grid.  
Save the arrays x (1‑D length Nx) and u (1‑D length Nx) together with the scalar values nu, rho, T, dx, dt, Nx, and Nt into a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz" in the current working directory.  
Create a line plot of u(x, T) and save it as "solution_pdebench_reacdiff_nu0p5_rho10.png" in the current working directory; axis labels and a title are optional.  
Print to standard output the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u^2) * dx) at time T.
