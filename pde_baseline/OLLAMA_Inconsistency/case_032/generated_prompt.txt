Solve the PDE u_t = 0.2 * u_xx for x in [0, 1] and t in [0, 0.3] with Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0 and initial condition u(x,0)=sin(pi*x) + 0.5*sin(3*pi*x).  
Use a uniform spatial grid with Nx = 300 intervals, so dx = 1/300 and grid points x_i = i*dx for i = 0 … 300.

Discretize the spatial second derivative with second‑order central differences.  
Integrate in time with the Crank–Nicolson scheme for diffusion terms.  
At each time step, solve the resulting tridiagonal linear system using a direct solver (e.g., numpy.linalg.solve or scipy.linalg.solve_banded).  
Enforce the Dirichlet boundary conditions by fixing the boundary nodes at each time step.  
After the final time step, compute the numerical solution u(x,T) on the grid.
