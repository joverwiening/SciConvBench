Solve -∇·(a(x,y)∇u(x,y)) = 1 on the domain (0,1) × (0,1) with Dirichlet boundary condition u = 0 on the entire boundary.  
Define the coefficient field a(x,y) = 1 + beta * (0.5 + 0.5 * sin(2*pi*x) * sin(2*pi*y)) with beta = 0.1.  
Use a uniform Cartesian grid with N = 128 intervals in each direction, so dx = dy = 1/N, and grid points x_i = i*dx, y_j = j*dy for i, j = 0,…,N.  
Discretize the PDE with second‑order finite differences using variable coefficients and face‑centered harmonic averaging: for interior nodes (i=1..N‑1, j=1..N‑1) apply the formula  
-(1/dx^2)[ a(i+½,j)*(u(i+1,j)-u(i,j)) - a(i‑½,j)*(u(i,j)-u(i‑1,j)) + a(i,j+½)*(u(i,j+1)-u(i,j)) - a(i,j‑½)*(u(i,j)-u(i,j‑1)) ] = 1,  
where face coefficients are harmonic means, e.g. a(i+½,j) = 2*a(i,j)*a(i+1,j)/(a(i,j)+a(i+1,j)).  
Assemble the sparse linear system Au = b for the interior unknowns and solve it with the conjugate gradient method to a relative residual tolerance of 1e‑10, optionally using a Jacobi preconditioner.  
After solving, set the boundary values of u to zero and obtain the full (N+1) × (N+1) solution array.
