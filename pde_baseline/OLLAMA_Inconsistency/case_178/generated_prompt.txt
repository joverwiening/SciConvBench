Use the task ID pdebench_reacdiff_nu10_rho2.  
Solve the PDE u_t = nu * u_xx + rho * u*(1 - u) on the periodic domain x in [0,1) and t in [0,1.0] with nu = 10.0 and rho = 2.0.  
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).  
Create a uniform periodic grid with Nx = 512 points, x_j = j*dx for j = 0,…,511 where dx = 1/Nx.  
Use a fixed time step dt = 0.001 for Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
Advance the solution with explicit forward Euler time integration using Strang splitting each full time step dt:  
(A) Perform a diffusion half-step of duration dt/2 by transforming u to Fourier space with np.fft.fft, multiplying each Fourier coefficient by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), and transforming back with np.fft.ifft, taking the real part.  
(B) Perform a reaction full-step of duration dt by applying the exact logistic update pointwise: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).  
(C) Perform another diffusion half-step identical to (A).  
After completing all Nt steps, compute u(x,T) on the grid.  
Save the results in the current working directory as a NumPy .npz file named "solution_pdebench_reacdiff_nu10_rho2.npz" containing the arrays x and u and the scalar values nu, rho, T, dx, dt, Nx, and Nt.  
Create a line plot of u(x,T) and save it as "solution_pdebench_reacdiff_nu10_rho2.png" in the current working directory, labeling the x‑axis as “x”, the y‑axis as “u(x,T)”, adding a simple title, and using a standard figure size.  
Print to the console the minimum value of u, the maximum value of u, the mean value of u, and the discrete L2 norm sqrt(sum(u**2)*dx) at the final time.  
Use NumPy’s default FFT implementation (np.fft.fft and np.fft.ifft) with no explicit normalization on the forward transform and the automatic 1/N factor on the inverse transform.
