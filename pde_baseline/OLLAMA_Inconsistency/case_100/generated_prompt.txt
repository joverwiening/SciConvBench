Set the final time T = 0.5.  
Compute dt0 = 0.9 / (c * sqrt(1/dx² + 1/dy²)).  
Set Nt = ceil(T / dt0) and then dt = T / Nt so that the final time is reached exactly.  
Discretize the spatial Laplacian with second‑order central differences using wrap‑around indexing for periodicity.  
Integrate in time with a second‑order central‑difference scheme; obtain the first time step by a Taylor expansion using the periodic Laplacian.  
Initial condition: u(x,y,0) = cos(2πx) cos(2πy), u_t(x,y,0) = 0.  
Evolve the solution to time T = 0.5.
