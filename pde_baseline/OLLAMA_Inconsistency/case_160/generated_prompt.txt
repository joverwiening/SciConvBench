Use Gamma = 1.6666666666666667.  
Set eta = 1e-8 and zeta = eta.  
Define the spatial domain x ∈ [‑1, 1] and the temporal domain t ∈ [0, 0.2].  
Create a uniform finite‑volume grid with Nx = 800 cells, cell centers x_j = ‑1 + (j+0.5)·dx for j = 0,…,799, and dx = 2/800.  
Evolve the conservative variables U = [rho, m, E] as cell averages.  
Use the equation of state p = (Gamma‑1)·(E ‑ 0.5·m²/rho) and clip rho and p to a floor of 1e‑12 if needed.  
Compute the convective flux with the Rusanov (local Lax‑Friedrichs) flux: F_conv = [m, m²/rho + p, (E+p)·v] where v = m/rho; compute the local wave speed a = max(|v_L|+c_L, |v_R|+c_R) with c = sqrt(Gamma·p/rho); set the numerical flux F_hat = 0.5·(F_conv(U_L)+F_conv(U_R)) ‑ 0.5·a·(U_R‑U_L).  
Compute viscous terms by evaluating v_x with a centered difference on cell‑centered v, set sigma = (zeta + 4/3·eta)·v_x, approximate sigma at interfaces by averaging neighboring sigma values, and form the viscous flux F_visc = [0, ‑sigma, ‑v·sigma] using interface‑averaged v and sigma; the total interface flux is F_total = F_hat + F_visc.  
Integrate in time with a 2‑stage SSP‑RK2 (Heun’s method).  
Choose the time step each step as dt = min(CFL·dx / max_j(|v_j|+c_j), 0.5·dx² / max(zeta+4/3·eta, 1e‑30)) with CFL = 0.5, and adjust the final step to reach T exactly.  
Apply transmissive/outflow (zero‑gradient) boundary conditions at x = ‑1 and x = 1 by setting ghost‑cell values equal to the nearest interior cell.  
Initialize with a Riemann shock‑tube: for x < 0 set rho = 1.0, v = 0.0, p = 1.0; for x ≥ 0 set rho = 0.125, v = 0.0, p = 0.1.  
Compute the solution at final time T = 0.2 and obtain rho(x,T), v(x,T), and p(x,T) at the cell centers.
