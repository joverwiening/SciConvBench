Write a Python script named kdv_solver.py. 
The script uses NumPy for array operations and FFTs, and Matplotlib for plotting. 
Define the spatial domain x in the half‑open interval [0,1) with periodic boundary conditions, using Nx = 1024 uniform grid points, so dx = (1‑0)/1024 and x_i = i*dx for i = 0,…,1023. 
Set the time step dt = 1e‑5 and integrate for 12000 steps to reach the final time T = 0.1. 
Initialize the solution with u(x,0) = 0.5*cos(2*pi*x), using radians for the trigonometric function. 
Compute spatial derivatives u_x and u_xxx with a Fourier pseudo‑spectral method: take the FFT of u, multiply by (i*k) for the first derivative and by (i*k)^3 for the third derivative, then inverse FFT back to physical space. 
Integrate the KdV equation u_t + 6*u*u_x + u_xxx = 0 in time using an explicit fourth‑order Runge‑Kutta (RK4) scheme, evaluating the nonlinear term 6*u*u_x in physical space at each sub‑step. 
After the final time step, compute u(x,T) on the same grid. 
Save the arrays x and u, together with the scalar metadata T, dx, and dt, into a file named solution_agent_other_03_kdv.npz in the current working directory. 
Create a line plot of u versus x, label the x‑axis as “x”, the y‑axis as “u(x, T)”, and set the title to “KdV solution at T = 0.1”, then save the figure as solution_agent_other_03_kdv.png in the current working directory. 
Print to the console the minimum value of u, the maximum value of u, and the discrete L2 norm sqrt(sum(u**2)*dx) at time T.
