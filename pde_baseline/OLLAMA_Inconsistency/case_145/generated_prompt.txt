Solve the 1D viscous Burgers equation u_t + ∂_x(0.5*u^2) = nu*u_xx with nu = 0.04 on the periodic domain x ∈ [0,1) for time t ∈ [0,1.0].  
Use a uniform periodic grid with Nx = 512 points, dx = 1/512, and grid points x_j = j*dx for j = 0,…,511.  
Set the initial condition u(x,0) = sin(2*pi*x).  
Apply Strang splitting each full time step dt: first a diffusion half-step solved exactly in Fourier space, then a full advection step for the inviscid Burgers equation using a finite‑volume Rusanov flux, and finally another diffusion half-step identical to the first.  
Compute Fourier wave numbers k = 2*pi*fftfreq(Nx, d=dx) and update the diffusion step by multiplying the Fourier coefficients by exp(-nu*k^2*(dt/2)).  
For the advection step, use flux F = 0.5*(f(u_left)+f(u_right)) - 0.5*alpha*(u_right-u_left) with f(u)=0.5*u^2 and alpha = max(|u_left|,|u_right|), and update each cell by u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).  
Determine the time step from CFL = 0.4 with estimated max speed ≈ 1: dt0 = CFL*dx, Nt = ceil(T/dt0) = 1280, and set dt = T/Nt = 0.00078125 so that the final time T = 1.0 is reached exactly.  
Perform Nt time steps to obtain the solution u(x,T) at T = 1.0.  
Save the arrays x and u and the scalars nu, T, dx, dt, Nx, and Nt to the file "solution_pdebench_burgers_nu0p04.npz".
