Solve the PDE u_t + (-0.5) u_x = 0 on the periodic spatial domain x ∈ [0,1) and time interval t ∈ [0,1.0].  
Use a uniform periodic grid with Nx = 1000 points, dx = 1/Nx, and grid points x_i = i*dx for i = 0,…,Nx‑1.  
Apply a first‑order upwind spatial discretization; because the advection speed a = -0.5 is negative, use a right‑biased (downwind) stencil.  
Integrate in time with the forward Euler method, choosing dt so that |a|*dt/dx ≤ 0.9. Compute dt0 = 0.9*dx/|a|, set Nt = ceil(T/dt0) with T = 1.0, then set dt = T/Nt.  
Handle the periodic boundary by wrap‑around indexing.  
Set the initial condition u(x,0) = exp(-100*(x-0.3)^2).  
Compute the solution u(x,T) at the final time T = 1.0.
