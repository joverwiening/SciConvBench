Solve the PDE u_t = nu*u_xx + rho*u*(1 - u) on the spatial domain x in [0,1) with periodic boundary conditions and the time interval t in [0,1.0].  
Use the parameters nu = 2.0 and rho = 10.0.  
Set the initial condition u(x,0) = 0.25 + 0.1*sin(2*pi*x).  
Create a uniform periodic grid with Nx = 512 points, dx = 1/Nx, and grid points x_j = j*dx for j = 0,…,511.  
Use a fixed time step dt = 0.001 for Nt = 1000 steps so that the final time T = 1.0 is reached exactly.  
Integrate in time with explicit forward Euler using Strang splitting each full time step dt:  
(A) Perform a diffusion half-step of duration dt/2 solved exactly in Fourier space by computing the FFT of u, multiplying each Fourier mode by exp(-nu*k^2*(dt/2)) where k = 2*pi*fftfreq(Nx, d=dx), then taking the inverse FFT and retaining the real part.  
(B) Perform a reaction full-step of duration dt solved exactly pointwise for the logistic ODE du/dt = rho*u*(1-u) using the update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).  
(C) Perform another diffusion half-step identical to step (A).  
After completing all Nt steps, compute the solution u(x,T) on the periodic grid.  
Save the arrays x (1‑D length Nx) and u (1‑D length Nx) together with the scalar values nu, rho, T, dx, dt, Nx, and Nt to a file named "solution_pdebench_reacdiff_nu2_rho10.npz".  
Save a line plot of u(x,T) as "solution_pdebench_reacdiff_nu2_rho10.png".  
Print the minimum, maximum, mean, and discrete L2 norm sqrt(sum(u^2)*dx) of u at T, formatting each value with at least six decimal places.
