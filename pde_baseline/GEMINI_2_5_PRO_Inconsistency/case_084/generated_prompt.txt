Solve the PDE u_tt = (1.0)^2 * u_xx.
The spatial domain is x in [0,1].
The time domain is t in [0,0.8].
The wave speed c is 1.0.
The boundary condition at x=0 is u=0 (Dirichlet).
The boundary condition at x=1 is u=0 (Dirichlet).
The initial condition for the field is u(x,0)=sin(pi*x) + 0.5*sin(3*pi*x).
The initial condition for the time derivative of the field is u_t(x,0)=0.
Use a uniform grid with Nx=600 intervals, which means there are 601 grid points.
The spatial step size is dx=1/Nx.
Discretize the u_xx term using second-order central differences.
Integrate in time using the second-order central difference leapfrog method.
The time step dt should be calculated to exactly hit the final time T=0.8.
First, calculate a provisional time step dt0 = 0.9*dx/c.
Then, calculate the number of time steps Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
Initialize the solution at the first time step using the Taylor start method: u^1 = u^0 + dt*u_t(x,0) + 0.5*dt^2*(c^2*u_xx^0).
The term u_xx^0 should be computed from u^0 using the same second-order central difference scheme.
Enforce the Dirichlet boundary conditions at every time step.
Compute the numerical solution u(x,t) up to the final time T=0.8.
