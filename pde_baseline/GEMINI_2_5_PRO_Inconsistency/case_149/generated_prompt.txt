Solve the 1D viscous Burgers' equation numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0], so the final time T is 1.0.
The viscosity parameter nu is 1.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
Use the Strang splitting scheme for time integration.
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
Each full time step dt consists of a diffusion half-step (dt/2), an advection full-step (dt), and another diffusion half-step (dt/2).
The diffusion steps are solved exactly in Fourier space using the formula: u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wave numbers for the Fourier step are k = 2*pi*fftfreq(Nx, d=dx).
The advection step for u_t + ∂_x(0.5*u^2)=0 is solved with a finite-volume method using the Rusanov flux.
The Rusanov flux F between states u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u)=0.5*u^2.
The local wave speed for the Rusanov flux is alpha = max(abs(u_left), abs(u_right)).
The finite-volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The time step dt is determined based on a CFL number of 0.4 and an estimated maximum speed of 1.0.
First, calculate an initial time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of steps Nt = ceil(T/dt0).
Finally, use the adjusted time step dt = T/Nt for the simulation.
Compute the solution u(x,T) at the final time T=1.0.

The NPZ file must contain the 1D arrays 'x' and 'u'.
The NPZ file must also contain the scalar values 'nu', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
