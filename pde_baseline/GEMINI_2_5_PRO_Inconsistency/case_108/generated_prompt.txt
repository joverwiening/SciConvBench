Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step dt=0.01 for Nt=2000 steps.

The NPZ file will contain a 2D array 'Y' of shape [2001, 2] with columns for x and y.
The NPZ file will also contain the scalar parameter 'mu'.
