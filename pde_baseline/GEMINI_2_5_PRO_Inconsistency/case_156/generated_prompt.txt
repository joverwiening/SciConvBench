Solve the 1D Compressible Navier-Stokes equations numerically.
The PDE is given in conservative form for rho, m, and E.
The state variables are density rho(x,t), velocity v(x,t), and pressure p(x,t).
The conservative variables are rho, m = rho*v, and E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The PDE system is rho_t + (m)_x = 0.
The PDE system is m_t + (m^2/rho + p - sigma)_x = 0.
The PDE system is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.5].
The final time T is 0.5.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 0.1.
The bulk viscosity zeta is equal to eta, so zeta is 0.1.
Boundary conditions are periodic on x=-1 and x=1.
The initial condition for density is rho(x,0) = 1.0 + 0.2*sin(pi*x).
The initial condition for velocity is v(x,0) = 0.1*cos(pi*x).
The initial condition for pressure is p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx=400 cells.
The domain is [-1, 1], so the cell width is dx = 2/Nx.
Cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
Evolve the cell-averaged conservative variables U = [rho, m, E].
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor value of 1e-12 if they fall below it.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective part of the PDE.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ).
The speed of sound is c = sqrt(Gamma*p/rho).
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x using a centered difference on cell-centered velocity values.
The viscous stress sigma = (zeta + 4/3*eta)*v_x is computed at cell centers.
Approximate sigma at cell interfaces by taking the arithmetic mean of the values in the two adjacent cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The velocity v used in the energy component of the viscous flux at an interface is the arithmetic mean of the velocities in the two adjacent cells.
The total numerical flux at an interface is F_total = F_hat + F_visc.
Use the 2-stage SSP-RK2 (Heun's method) for time integration.
The time step dt is calculated at each step.
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step is dt = min(dt_conv, dt_visc).
Use a CFL number of 0.8.
Adjust the final time step to land exactly at T = 0.5.
Implement periodic boundary conditions by wrapping around the grid indices.
Compute the solution rho(x,T), v(x,T), p(x,T) at the cell centers at the final time T.

The npz file must contain the 1D arrays x, rho, v, and p.
The npz file must also contain the scalars Gamma, eta, zeta, T, dx, and CFL.
