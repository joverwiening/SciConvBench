The grid spacing is dx = 1/160 and dy = 1/160.
The Laplacian is approximated using the standard 5-point finite difference stencil.

The time step dt is determined by setting a CFL number of 0.5, calculating an initial dt0 = 0.5*dx/c, finding the number of steps Nt = ceil(1.0/dt0), and then setting dt = 1.0/Nt.
The time-stepping scheme is initialized using a Taylor series expansion to find u at the first time step.
