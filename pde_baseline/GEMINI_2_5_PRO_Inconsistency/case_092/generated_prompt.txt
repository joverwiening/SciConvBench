Solve the 2D wave equation u_tt = c^2 * (u_xx + u_yy) + sin(pi*x)*sin(pi*y)*cos(2*pi*t).
The spatial domain is (x,y) in [0,1] x [0,1].
The time domain is t in [0,1.0].
The wave speed is c = 1.0.
The boundary conditions are Dirichlet with u=0 on all boundaries.
The initial condition for u is u(x,y,0) = 0.
The initial condition for u_t is u_t(x,y,0) = 0.
Discretize the spatial domain with a uniform grid using Nx=120 and Ny=120 intervals.
Use the standard 5-point finite difference stencil for the Laplacian operator.
Discretize the second-order time derivative u_tt using a 2nd-order central difference.
Use a Taylor series expansion to compute the solution at the first time step.
Set the time step dt based on a CFL number of 0.9.
Specifically, calculate an initial time step dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Then, determine the number of time steps Nt = ceil(T/dt0), where T=1.0.
Finally, set the actual time step to dt = T/Nt.
Compute the numerical solution u(x,y,t) up to the final time T=1.0.
Save the final solution to a file named "solution_agent_wave_11.npz".
The NPZ file must contain the 1D grid arrays 'x' and 'y', the 2D solution array 'u' with shape (Ny+1, Nx+1), and the scalar metadata T, dx, dy, and dt.
