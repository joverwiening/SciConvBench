Solve the partial differential equation u_t = ∂/∂x( D(x) * u_x ).
The diffusion coefficient is D(x) = 0.1*(1 + x).
The spatial domain is the interval [0,1].
The time domain is the interval [0,0.5].
The boundary condition at x=0 is u(0,t)=0.
The boundary condition at x=1 is u(1,t)=0.
The initial condition is u(x,0)=sin(pi*x).
Use a uniform spatial grid with Nx=300 intervals.
Discretize the spatial operator (D(x) u_x)_x at interior grid points x_i using the second-order conservative formula (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
Define the face-centered diffusion coefficients D_{i+1/2} by arithmetic averaging of the node-centered values: D_{i+1/2} = 0.5*(D(x_i) + D(x_{i+1})).
Integrate in time using the Implicit Euler method.
Use a time step of dt=0.001.
Perform 500 time steps to reach the final time T=0.5.
Solve the sparse linear system that arises at each time step.
Compute the numerical solution u(x) at the final time T=0.5.
Save the results to a file named "solution_agent_diffusion_01.npz".
The NPZ file must contain the 1D array of grid coordinates named 'x', the 1D array of the solution named 'u', the final time as a scalar named 'T', the spatial step size as a scalar named 'dx', and the time step size as a scalar named 'dt'.
Create a line plot of the final solution.
Save the plot to a file named "solution_agent_diffusion_01.png".
The plot title should be "Numerical Solution at T=0.5".
The plot's x-axis should be labeled "x".
The plot's y-axis should be labeled "u(x, T)".
Print the minimum value of the final solution array u to the console.
Print the maximum value of the final solution array u to the console.
Print the discrete L2 norm of the final solution to the console, calculated using the formula sqrt(sum(u^2)*dx).
