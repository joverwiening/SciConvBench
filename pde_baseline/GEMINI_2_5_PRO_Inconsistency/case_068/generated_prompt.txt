Solve the Korteweg-de Vries (KdV) equation numerically.
The PDE is u_t + 6*u*u_x + u_xxx = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 0.1].
The initial condition is u(x,0) = 0.5*cos(2*pi*x).
Use a Fourier pseudo-spectral method for the spatial derivatives.
Compute the spatial derivatives u_x and u_xxx in Fourier space by multiplying the FFT of u by (ik) and (ik)^3 respectively.
Compute the nonlinear term 6*u*u_x in physical space.
Apply the 2/3 rule for de-aliasing when computing the nonlinear term.
Use a grid with Nx=1024 points.
Integrate in time using the explicit fourth-order Runge-Kutta (RK4) method.
Use a fixed time step of dt = 1e-5.
The total number of time steps is 10000.
The final time is T = 0.1.
Compute the solution u(x, T) at the final time.
Save the solution to a file named "solution_agent_other_03_kdv.npz".
The NPZ file must contain the 1D grid coordinates 'x', the 1D solution array 'u', and the scalars 'T', 'dx', and 'dt'.
Save a line plot of the final solution u(x, T) to a file named "solution_agent_other_03_kdv.png".
The plot should have a descriptive title.
The plot should have labels for the x and y axes.
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
