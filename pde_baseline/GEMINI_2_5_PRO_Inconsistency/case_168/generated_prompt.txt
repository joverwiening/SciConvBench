Task ID is pdebench_darcy_beta0p1.
Solve the 2D Darcy flow PDE: -∇ · ( a(x,y) ∇u(x,y) ) = 1 for the unknown field u(x,y).
The domain is (x,y) in (0,1) x (0,1).
The coefficient field is a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
The parameter beta is 0.1.
Trigonometric functions should be evaluated using radians.
In any code, use '**' for exponentiation, not '^'.
Apply Dirichlet boundary conditions, u = 0, on the entire boundary of the domain.
Use a uniform Cartesian grid with N=128 intervals in each direction, creating (N+1)x(N+1) grid points.
The grid spacing is dx = dy = 1/N.
Grid points are defined as x_i = i*dx for i=0,...,N and y_j = j*dy for j=0,...,N.
Discretize the PDE using a 2nd-order finite difference scheme.
Use face-centered harmonic averaging for the variable coefficient.
The discretization for an interior node (i,j) is -(1/dx^2) * [ a(i+1/2,j)*(u(i+1,j)-u(i,j)) - a(i-1/2,j)*(u(i,j)-u(i-1,j)) + a(i,j+1/2)*(u(i,j+1)-u(i,j)) - a(i,j-1/2)*(u(i,j)-u(i,j-1)) ] = 1.
Face coefficients are harmonic means, for example, a(i+1/2,j) = 2*a(i,j)*a(i+1,j) / (a(i,j)+a(i+1,j)).
Assemble the sparse linear system Au=b for the interior unknowns.
Solve the linear system using the conjugate gradient method.
The solver should terminate when the relative residual norm, ||Au-b||_2 / ||b||_2, is less than 1e-10.
A simple Jacobi preconditioner may be used at the implementer's discretion.
The final solution u(x,y) should be computed on the full (N+1) x (N+1) grid, including the boundaries.
Save the results to a file named "solution_pdebench_darcy_beta0p1.npz".
The npz file must contain the 1D arrays 'x' and 'y', the 2D array 'u' with shape (N+1, N+1), and the scalars 'beta', 'N', and 'dx'.
Create a visualization of the solution u(x,y) and save it as "solution_pdebench_darcy_beta0p1.png".
The visualization should be a heatmap or a contour plot, as determined by the implementer's judgment of best practices.
Print the minimum value of the solution u to the console.
Print the maximum value of the solution u to the console.
Print the final relative residual norm of the interior system to the console.
