Solve the 2D wave equation u_tt = c^2 * (u_xx + u_yy) numerically.
The wave speed is c = 1.0.
The spatial domain is the unit square [0,1] x [0,1].
The time domain is [0, 1.0].
The boundary conditions are Dirichlet with u=0 on all boundaries.
The initial condition for the field is u(x,y,0) = sin(pi*x)*sin(pi*y).
The initial condition for the time derivative of the field is u_t(x,y,0) = 0.
Discretize the spatial domain using a uniform grid with Nx = 120 intervals in the x-direction and Ny = 120 intervals in the y-direction.
This results in (Nx+1) by (Ny+1) grid points.
The spatial step sizes are dx = 1/Nx and dy = 1/Ny.
Use the standard 5-point finite difference stencil for the Laplacian operator.
Discretize the time derivative u_tt using a 2nd-order central difference.
Initialize the solution at the first time step using a Taylor series expansion incorporating the initial velocity.
Set the time step based on a CFL condition.
The CFL number, defined as c*dt*sqrt(1/dx^2 + 1/dy^2), must be less than or equal to 0.9.
First, calculate a preliminary time step dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Then, determine the number of time steps Nt as the ceiling of T/dt0, where T=1.0.
The final time step is dt = T/Nt to ensure the final time is reached exactly.
At each time step, enforce the Dirichlet boundary conditions by setting the values at the boundary nodes to zero.
Compute the numerical solution u(x,y,t) up to the final time T=1.0.
Save the final solution to a file named "solution_agent_wave_07.npz".
The npz file must contain the 1D x-coordinate array, the 1D y-coordinate array, and the 2D solution array u at T=1.0.
The shape of the u array should be (Ny+1, Nx+1) such that u[j,i] corresponds to u(x[i], y[j]).
The npz file must also contain the scalar metadata T, dx, dy, and dt.
Create a heatmap or contour plot of the final solution u(x,y,T=1.0) and save it as "solution_agent_wave_07.png".
Print the minimum and maximum values of the final solution u to the console.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx*dy), to the console.
The exact solution for verification is u(x,y,t) = cos(1.0*sqrt(2)*pi*t)*sin(pi*x)*sin(pi*y).
