Solve the partial differential equation u_t = ∂/∂x( D(x) * u_x ).
The diffusion coefficient is D(x) = 0.01 + 0.09*x^2.
The spatial domain is x in [0,1].
The temporal domain is t in [0,0.2].
The boundary condition at x=0 is u(0,t)=0.
The boundary condition at x=1 is u(1,t)=0.
The initial condition is u(x,0)=x*(1-x).
Use a uniform spatial grid with Nx=400 intervals.
Use a time step of dt=0.0005.
The final time is T=0.2, which corresponds to 400 time steps.
Discretize the spatial term (D(x) u_x)_x using a conservative second-order finite difference scheme.
The discrete operator at interior grid point i is (1/dx^2) * [ D_{i+1/2}(u_{i+1}-u_i) - D_{i-1/2}(u_i-u_{i-1}) ].
The face values of the diffusion coefficient D are calculated by arithmetic averaging: D_{i+1/2} = 0.5*(D(x_i) + D(x_{i+1})).
Use the Implicit Euler method for time integration.
Compute the solution u(x,T) at the final time T=0.2.
Save the results to a file named "solution_agent_diffusion_02.npz".
The NPZ file must contain the 1D grid coordinates as an array named 'x'.
The NPZ file must contain the 1D solution array at the final time, named 'u'.
The NPZ file must contain the scalar values T, dx, and dt as metadata.
Create a line plot of the solution u versus x at the final time.
Save the plot to a file named "solution_agent_diffusion_02.png".
The plot should have a reasonable title.
Print the minimum value of the final solution u(x,T).
Print the maximum value of the final solution u(x,T).
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
