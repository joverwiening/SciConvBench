Solve the partial differential equation u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 0.5.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The numerical solution will be computed on a uniform periodic spatial grid with Nx = 512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx = 1/Nx.
The time integration will use a fixed time step dt = 0.001 for Nt = 1000 steps to reach the final time T = 1.0.
The time integration method is Strang splitting.
Each time step dt consists of three sub-steps: a half-step of diffusion, a full-step of reaction, and another half-step of diffusion.
The diffusion half-step u_t = nu * u_xx for a duration of dt/2 is solved exactly in Fourier space.
The Fourier-space update for the diffusion step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
The reaction full-step du/dt = rho*u*(1-u) for a duration of dt is solved exactly for each grid point.
The exact update for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Compute the final solution u(x, T=1.0).
Save the results to a file named "solution_pdebench_reacdiff_nu0p5_rho10.npz".
The NPZ file must contain the 1D arrays x and u, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x, T=1.0) to a file named "solution_pdebench_reacdiff_nu0p5_rho10.png".
The plot's x-axis label will be "x".
The plot's y-axis label will be "u(x, T=1.0)".
The plot's title will be "Solution of 1D Reaction-Diffusion Equation at T=1.0".
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
