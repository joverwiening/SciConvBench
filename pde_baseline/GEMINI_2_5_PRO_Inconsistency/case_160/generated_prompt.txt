Solve the 1D compressible Navier-Stokes equations in conservative form.
The conservative variables are density (rho), momentum (m), and total energy (E).
The momentum is defined as m = rho * v.
The total energy is defined as E = p/(Gamma-1) + 0.5 * rho * v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The parameter zeta is equal to eta.
The PDE system is rho_t + (m)_x = 0.
The PDE system is m_t + (m^2/rho + p - sigma)_x = 0.
The PDE system is E_t + ( (E+p)*v - v*sigma )_x = 0.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time T is 0.2.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is 1e-08.
The boundary conditions are transmissive (outflow) at both x=-1 and x=1.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial density is 1.0, velocity is 0.0, and pressure is 1.0.
For x >= 0, the initial density is 0.125, velocity is 0.0, and pressure is 0.1.
Use a uniform finite-volume grid with Nx=800 cells.
The cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,Nx-1.
The cell width is dx = 2/Nx.
Evolve the cell-averaged conservative variables U = [rho, m, E].
The pressure is calculated from the conservative variables using p = (Gamma-1) * (E - 0.5*m^2/rho).
Enforce positivity by clipping rho and p to a floor value of 1e-12.
Apply the positivity clipping after each stage of the time integrator.
Use the Rusanov (local Lax-Friedrichs) numerical flux for the convective terms.
The convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The interface wave speed for the Rusanov flux is a = max( |v_L| + c_L, |v_R| + c_R ).
The speed of sound is c = sqrt(Gamma*p/rho).
The numerical convective flux is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute the velocity gradient v_x at cell centers using a centered difference on the cell-centered velocity values.
Calculate the viscous stress sigma at cell centers using the computed v_x.
Approximate sigma at cell interfaces by taking the arithmetic mean of the sigma values from the two neighboring cells.
The viscous flux vector is F_visc = [0, -sigma, -v*sigma].
The value of v used in the viscous energy flux at an interface is the arithmetic mean of the velocities in the neighboring cells.
The total numerical flux at an interface is the sum of the convective and viscous fluxes, F_total = F_hat + F_visc.
Integrate in time using the 2-stage SSP-RK2 (Heun's method).
The time step dt is determined at each step by the minimum of a convective and a viscous constraint.
The convective time step constraint is dt_conv = CFL * dx / max_j( |v_j| + c_j ).
The CFL number is 0.5.
The viscous time step constraint is dt_visc = 0.5 * dx^2 / max( zeta + 4/3*eta, 1e-30 ).
The time step is dt = min(dt_conv, dt_visc).
Adjust the final time step to land exactly at T=0.2.
Implement the outflow boundary conditions using ghost cells.
Set the values in the ghost cells to be equal to the values in the nearest interior cell.
Apply the centered difference formula for v_x at boundary-adjacent cells using the ghost cell values.
Compute the solution rho(x,T), v(x,T), and p(x,T) on the cell centers at the final time T=0.2.
Save the results to a file named "solution_pdebench_cns1d_sod1_eta1em8_outflow.npz".
The NPZ file must contain the 1D arrays x, rho, v, and p.
The NPZ file must also contain the scalars Gamma, eta, zeta, T, dx, and CFL.
Save a plot of rho, v, and p versus x at the final time T.
The plot should be saved as "solution_pdebench_cns1d_sod1_eta1em8_outflow.png".
The plot can be a single 3-panel plot or three separate plots.
Print the minimum and maximum values of rho and p at the final time.
