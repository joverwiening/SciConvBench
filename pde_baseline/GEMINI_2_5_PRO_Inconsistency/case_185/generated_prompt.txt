Solve the PDE u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j/Nx for j=0,...,Nx-1.
The spatial step size dx is 1/Nx.
Use a fixed time step dt=0.001.
Perform Nt=1000 time steps to reach the final time T=1.0.
Use a Strang splitting method for time integration.
Each time step dt consists of three sub-steps.
First, perform a diffusion half-step of duration dt/2 solved exactly in Fourier space.
The diffusion step updates the Fourier coefficients u_hat(k) by multiplying with exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
Second, perform a reaction full-step of duration dt solved exactly pointwise.
The exact update for the reaction step is u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Third, perform another diffusion half-step of duration dt/2, identical to the first.
Compute the solution u(x, T=1.0).
Save the results to a file named "solution_pdebench_reacdiff_nu2_rho10.npz".
The NPZ file must contain the arrays x and u, and the scalars nu, rho, T, dx, dt, Nx, Nt.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_reacdiff_nu2_rho10.png".
The plot title should be "Solution u(x) at T=1.0".
The plot's x-axis should be labeled "x".
The plot's y-axis should be labeled "u(x, T)".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the mean value of the final solution u.
Print the discrete L2 norm of the final solution u, calculated as sqrt(sum(u^2)*dx).
