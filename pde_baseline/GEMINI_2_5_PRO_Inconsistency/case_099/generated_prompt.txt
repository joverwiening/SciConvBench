Solve the partial differential equation u_tt = c^2 * u_xx.
The wave speed is c = 1.0.
The spatial domain is x in [0, 1].
The time domain is t in [0, 1.0], with a final time T = 1.0.
The boundary condition at x=0 is u=0 for all t.
The boundary condition at x=1 is u=0 for all t.
The initial condition for the field is u(x,0) = exp(-200*(x-0.5)^2).
The initial condition for the time derivative of the field is u_t(x,0) = 0.
Set the initial values at the boundary points x=0 and x=1 to zero to be consistent with the boundary conditions.
Discretize the spatial domain with Nx=800 uniform intervals, creating Nx+1 grid points.
The spatial step size is dx = 1/Nx.
Use a second-order central difference for the spatial derivative u_xx.
Use the second-order central difference in time (leapfrog/Störmer–Verlet) for time integration.
Calculate the time step dt by first setting dt0 = 0.9 * dx / c.
Then, calculate the number of time steps Nt = ceil(T / dt0).
Finally, set the time step as dt = T / Nt.
Initialize the solution at the first time step u(x, dt) using the Taylor series expansion u^1 = u^0 + dt*u_t(x,0) + 0.5*dt^2*(c^2*u_xx^0).
Compute the numerical solution u(x,t) up to the final time T=1.0.
Save the results in an NPZ file named "solution_agent_wave_18.npz".
The NPZ file must contain the 1D array of grid point coordinates 'x', the 1D array of the final solution 'u', and the scalar values 'T', 'dx', and 'dt'.
Save a line plot of the final solution u(x, T) versus x as "solution_agent_wave_18.png".
The plot should have a descriptive title and labels for the x and y axes.
Print the minimum value of the final solution array u.
Print the maximum value of the final solution array u.
