Solve the partial differential equation u_tt = c^2 * u_xx.
The wave speed c is 1.0.
The spatial domain is x in [0, 1].
The time domain is t in [0, 0.25], so the final time T is 0.25.
The boundary condition at x=0 is u=0.
The boundary condition at x=1 is u=0.
The initial condition for the field is u(x,0) = sin(4*pi*x).
The initial condition for the time derivative of the field is u_t(x,0) = 0.
The exact solution for verification is u(x,t) = cos(1.0*4*pi*t)*sin(4*pi*x).
Use a uniform spatial grid on [0,1] with Nx=800 intervals, which means there are 801 grid points.
The spatial step size is dx = 1/Nx.
Discretize the spatial derivative u_xx using a second-order central difference scheme for all interior grid points.
Integrate in time using the second-order central difference in time (leapfrog / Störmer–Verlet method).
Initialize the solution at the first time step u(x, dt) using a second-order Taylor series expansion.
The time step dt is determined by first setting dt0 = 0.9 * dx / c, then Nt = ceil(T / dt0), and finally dt = T / Nt.
Enforce the Dirichlet boundary conditions at every time step.
Compute the numerical solution u(x,T) at the final time T=0.25.
Save the results to a file named "solution_agent_wave_13.npz".
The saved file must contain the x-coordinates array, the solution array u(x,T), and the scalars T, dx, and dt.
