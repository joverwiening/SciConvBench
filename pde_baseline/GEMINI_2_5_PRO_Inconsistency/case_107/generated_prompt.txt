Solve the given 3-state neural dynamics ODE system numerically.
The ODE system is defined as:
dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t)
dI/dt = delta*E - epsilon*I
dH/dt = theta*I - phi*H
The time domain for the simulation is [0.0, 50.0].
The parameters for the ODE system are:
alpha = 1.2
beta = 1.0
gamma = 0.5
delta = 0.8
epsilon = 0.7
theta = 0.9
phi = 0.4
The initial conditions at t=0.0 are:
E(0.0) = 0.5
I(0.0) = 0.2
H(0.0) = 0.1
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt=0.01 for a total of Nt=5000 steps.
Compute the full state vector [E, I, H] at all time points t_n = n*dt for n=0 to Nt.
Save the results to a file named "solution_molk_006.npz".
The NPZ file must contain a 1D array 't' for the time points, a 2D array 'Y' of shape [Nt+1, 3] for the state vectors with columns ordered as [E, I, H], and all the scalar parameters.
Save line plots of each state variable versus time to a single image file named "solution_molk_006.png".
Print the final state values E(50.0), I(50.0), and H(50.0).
Print the minimum and maximum values of each state variable over the entire simulation time.
Interpret trigonometric functions as using radians.
