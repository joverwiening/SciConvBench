Solve the partial differential equation u_tt = c^2 * u_xx + f(x,t) numerically.

The time domain is t in the closed interval [0, 1.0].
The boundary condition at x=0 is u(0,t) = 0.
The boundary condition at x=1 is u(1,t) = 0.
The initial condition for the field is u(x,0) = 0.
The initial condition for the time derivative of the field is u_t(x,0) = 0.

The spatial step size is dx = 1/Nx.

The time step dt should be determined as follows: first calculate a reference time step dt0 = 0.9 * dx / c.
Then, calculate the number of time steps Nt = ceil(T / dt0).
Finally, set the actual time step to dt = T / Nt.
Initialize the simulation at t=0 with u^0_i = u(x_i, 0).
Compute the solution at the first time step t=dt using the Taylor series expansion: u^1 = u^0 + dt*u_t(x,0) + 0.5*dt^2*(c^2*u_xx^0 + f(x,0)).
In the Taylor expansion, u_xx^0 is the second-order central difference approximation of the second derivative of u^0.
At every time step, enforce the Dirichlet boundary conditions by setting the values at the boundary nodes.
Compute the numerical solution u(x,t) up to the final time T=1.0.
