Solve the 1D reaction-diffusion PDE: u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The diffusion coefficient is nu = 0.5.
The reaction rate is rho = 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points, where x_j = j/Nx for j=0,...,Nx-1.
Use a fixed time step of dt=0.001 for Nt=1000 steps to reach the final time T=1.0.
Use the Strang splitting method for time integration over each time step dt.
The Strang splitting consists of a half-step of diffusion, a full step of reaction, and another half-step of diffusion.
Solve the diffusion half-step (duration dt/2) exactly in Fourier space using the formula: u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=1/Nx).
The Fourier and inverse Fourier transforms should be implemented using a standard library's convention for normalization (e.g., orthonormal).
Take the real part of the solution after each inverse Fourier transform.
Solve the reaction full-step (duration dt) exactly for the logistic ODE at each grid point using the formula: u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
Use 64-bit (double) floating-point precision for all calculations and stored arrays.
Compute the final solution u(x, T=1.0).
