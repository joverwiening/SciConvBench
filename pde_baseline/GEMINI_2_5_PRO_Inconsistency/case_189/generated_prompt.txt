Solve the 1D reaction-diffusion equation u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The diffusion coefficient is nu = 5.0.
The reaction coefficient is rho = 10.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The solution must be advanced in time using the specified Strang splitting method.
Each time step dt consists of a half-step of diffusion, a full step of reaction, and another half-step of diffusion.
The diffusion step of duration dt/2 is solved exactly in Fourier space using the formula u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wave numbers are defined as k = 2*pi*fftfreq(Nx, d=dx).
The reaction step of duration dt is solved exactly for the logistic ODE using the formula u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
The time step is fixed at dt=0.001.
The simulation runs for Nt=1000 steps to reach the final time T=1.0.
Compute the final solution u(x, T=1.0).
Save the results to a file named "solution_pdebench_reacdiff_nu5_rho10.npz".
The npz file must contain the arrays 'x' and 'u', and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u versus x to a file named "solution_pdebench_reacdiff_nu5_rho10.png".
The plot should have a descriptive title.
The plot's x-axis should be labeled.
The plot's y-axis should be labeled.
Print the minimum, maximum, mean, and discrete L2 norm of the final solution at T=1.0.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
