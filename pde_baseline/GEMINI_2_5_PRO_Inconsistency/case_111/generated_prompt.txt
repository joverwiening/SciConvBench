Solve the Brusselator ODE system numerically.
The ODE system is dx/dt = A + x**2 * y - (B + 1) * x and dy/dt = B * x - x**2 * y.
The unknown functions to solve for are x(t) and y(t).
The time domain is from t=0.0 to t=20.0.
The value for parameter A is 2.
The value for parameter B is 3.0.
The initial condition is x(0.0) = 1.0 and y(0.0) = 1.0.
Use the classical 4th-order Runge-Kutta (RK4) method with a fixed time step.
The time step dt is 0.01 for a total of Nt=2000 steps.
Compute the full state vector [x, y] at all Nt+1 time points.
Save the results to a file named "solution_molk_010.npz".
The NPZ file must contain the time array under the key 't'.
The NPZ file must contain the solution array under the key 'Y', with shape [2001, 2] and columns ordered as [x, y].
The NPZ file must contain the parameter A under the key 'A'.
The NPZ file must contain the parameter B under the key 'B'.
Save a line plot of the solution to a file named "solution_molk_010.png".
The plot will show the time series for x(t) and y(t) in separate subplots on a single figure.
Print the final state values x(20.0) and y(20.0) to the console.
Print the minimum and maximum values of x(t) and y(t) over the time domain to the console.
