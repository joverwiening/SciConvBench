Solve the specified ODE system numerically.
The ODE system is for an undriven Duffing oscillator.
The unknown functions to be solved for are x(t) and y(t).
The system of equations is dx/dt = y and dy/dt = -delta*y - alpha*x - beta*x**3.
The time domain for the simulation is the closed interval [0.0, 50.0].
The value of the parameter alpha is 2.
The value of the parameter beta is 0.1.
The value of the parameter delta is 0.2.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 0.0.
The time integration method is the classical 4th-order Runge-Kutta (RK4) with a fixed step size.
The time step dt is 0.01.
The number of time steps Nt is 5000.
The full state vector [x(t), y(t)] will be computed at all 5001 time points from t=0.0 to t=50.0.
A file named "solution_molk_011.npz" will be created to store the output.
The NPZ file will contain a 1D array named 't' with the time points.
The NPZ file will contain a 2D array named 'Y' of shape (5001, 2) with the state vector history.
The columns of the 'Y' array will correspond to x and y, in that order.
The NPZ file will also store the scalar parameters alpha, beta, and delta using their names as keys.
A plot will be generated and saved as "solution_molk_011.png".
The plot will show the time series of x(t) and y(t) versus time.
The time series for x(t) and y(t) will be displayed in separate subplots within the same figure.
A report will be printed to the console.
The report will state the final values of x and y at t=50.0.
The report will also state the minimum and maximum values of x(t) and y(t) observed during the simulation.
