Solve the partial differential equation u_t + (-0.5)*u_x = 0.
The spatial domain is the interval [0, 1) with periodic boundary conditions.
The time domain is the interval [0, 1.0].
The initial condition is u(x,0) = exp(-100*(x-0.3)^2).
Use a uniform periodic grid with Nx=1000 points for the spatial domain.
Discretize the spatial derivative using a 1st-order upwind scheme, which for the negative velocity a=-0.5 corresponds to a right-biased stencil.
Integrate in time using the Forward Euler method.
Set the final time T to 1.0.
Calculate the time step dt by first setting a CFL-limited step dt0 = 0.9*dx/|a|, then finding the number of steps Nt = ceil(T/dt0), and finally setting dt = T/Nt.
Compute the numerical solution u(x,T) at the final time T=1.0.
Save the solution to a file named "solution_agent_advection_02.npz".
The saved file must contain the 1D arrays for the grid coordinates 'x' and the solution 'u', and the scalar values for the final time 'T', the spatial step 'dx', and the time step 'dt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_agent_advection_02.png".
Print the minimum value of the final solution array u.
Print the maximum value of the final solution array u.
Print the discrete L2 norm of the final solution array u, defined as sqrt(sum(u^2)*dx).
