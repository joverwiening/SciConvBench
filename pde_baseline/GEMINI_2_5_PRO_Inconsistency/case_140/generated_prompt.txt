Solve the partial differential equation u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 2.0].
The final time for the simulation is T=2.0.
The parameter beta is 2.0.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use a uniform spatial grid with Nx=512 points.
The grid spacing is dx=1/Nx and grid points are x_j = j*dx for j=0,...,Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
Integrate in time using the explicit forward Euler method.
Set the Courant-Friedrichs-Lewy number CFL to 0.5.
Calculate an initial time step dt_est = CFL * dx / abs(beta).
Set the number of time steps Nt = ceil(T/dt_est).
Recalculate the time step as dt = T/Nt to ensure the final time is reached exactly.
Compute the numerical solution u(x,T) at the final time T=2.0.
Save the results to a file named "solution_pdebench_advection_beta2.npz".
The saved file must contain the 1D arrays x and u.
The saved file must also contain the scalars beta, T, dx, dt, Nx, and Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_advection_beta2.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
The reference solution is u_ref(x,t) = u( (x - beta*t) mod 1, 0).
Compute the error between the numerical solution and the reference solution at the final time.
Print the maximum absolute error.
Print the L2 error norm.
