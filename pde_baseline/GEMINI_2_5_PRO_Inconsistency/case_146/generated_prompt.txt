Solve the 1D viscous Burgers equation numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The final time for the simulation is T=1.0.
The viscosity parameter is nu = 0.1.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
No closed-form reference solution is required for comparison.
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
Use Strang splitting for the time integration.
Each full time step dt consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
The diffusion step of duration dt/2 is solved exactly in Fourier space.
The Fourier transform of the solution u_hat(k) is updated by multiplying with exp(-nu*k^2*(dt/2)).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The advection step for u_t + ∂_x(0.5*u^2)=0 is solved for a duration dt.
Use a finite-volume method with the Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u)=0.5*u^2.
The numerical flux F between states u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The cell update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of cell j.
The time step dt is determined by a CFL condition.
Use a CFL number of 0.4 and an estimated maximum speed of 1.0.
First, calculate a provisional time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T/dt0).
Finally, set the actual time step to dt = T/Nt to reach the final time exactly.
Compute the solution u(x,T) at the final time T=1.0.
Save the output to a file named "solution_pdebench_burgers_nu0p1.npz".
The npz file should contain the 1D arrays x and u.
The npz file should also contain the scalars nu, T, dx, dt, Nx, and Nt.
