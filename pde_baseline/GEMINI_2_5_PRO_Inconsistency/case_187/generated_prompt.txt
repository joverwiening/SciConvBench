Solve the partial differential equation u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The parameter nu is 2.0.
The parameter rho is 5.0.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
The problem will be solved numerically using the Strang splitting method.
Use a uniform periodic spatial grid with Nx=512 points.
The spatial grid points are x_j = j/Nx for j=0,...,Nx-1.
The spatial step size is dx = 1/Nx.
Use a fixed time step of dt=0.001.
Perform Nt=1000 time steps to reach the final time T=1.0.
Each time step consists of a half-step of diffusion, a full step of reaction, and another half-step of diffusion.
The diffusion half-step for duration dt/2 is solved exactly in Fourier space by multiplying the Fourier coefficients by exp(-nu*k^2*(dt/2)), where k = 2*pi*fftfreq(Nx, d=dx).
After the inverse Fourier transform for the diffusion step, take the real part of the result.
The reaction full-step for duration dt is solved exactly for each grid point using the formula u_new = (u_old*exp(rho*dt)) / (1 + u_old*(exp(rho*dt) - 1)).
Compute the final solution u(x,T=1.0).
Save the results to a file named "solution_pdebench_reacdiff_nu2_rho5.npz".
The NPZ file must contain the 1D array 'x' of grid point locations, the 1D array 'u' of the final solution, and the scalars 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Create a line plot of the final solution u versus x.
Save the plot as "solution_pdebench_reacdiff_nu2_rho5.png".
Use a reasonable and descriptive label for the x-axis and y-axis of the plot.
Print the minimum, maximum, mean, and discrete L2 norm of the final solution u.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
Use a reasonable and clear format for printing the four scalar diagnostic values.
