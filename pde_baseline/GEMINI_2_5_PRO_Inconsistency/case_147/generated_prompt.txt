Solve the PDE u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
Simulate the PDE from t=0 to the final time T=1.0.
The viscosity parameter nu is 0.2.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
A closed-form reference solution is not required for verification.
Use a uniform periodic spatial grid on [0,1) with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
Use the Strang splitting method for time integration.
Each time step dt consists of a half-step of diffusion, a full-step of advection, and another half-step of diffusion.
Solve the diffusion half-step of duration dt/2 in Fourier space.
The update rule in Fourier space for a diffusion step is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wavenumbers are k = 2*pi*fftfreq(Nx, d=dx).
Solve the advection full-step for u_t + ∂_x(0.5*u^2)=0 using a finite-volume method with a Rusanov flux.
The flux function is f(u) = 0.5*u^2.
The Rusanov flux between cell-face values u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed estimate for the Rusanov flux is alpha = max(abs(u_left), abs(u_right)).
The finite volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell.
The time step dt is determined based on a CFL number of 0.4 and a maximum wave speed of 1.0.
First, calculate a provisional time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T/dt0).
Finally, set the actual time step to dt = T/Nt to reach the final time exactly.
Compute the solution u(x,T) at the final time T=1.0.

The NPZ file must contain the 1D arrays 'x' and 'u'.
The NPZ file must also contain the scalar values 'nu', 'T', 'dx', 'dt', 'Nx', and 'Nt'.
Save a line plot of the final solution u(x,T) to a file named "solution_pdebench_burgers_nu0p2.png".
The plot should have a descriptive title and labels for the x and y axes.
At the final time, print the minimum value of u, the maximum value of u, the discrete mean value of u, and the discrete L2 norm of u.
The discrete mean is the simple average of the grid point values.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
