Solve the partial differential equation u_t + beta * u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 2.0].
The final time for the simulation is T=2.0.
The parameter beta is 0.4.
The initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
The reference solution for verification is u(x,t) = u0( (x - beta*t) mod 1 ), where u0(x) is the initial condition.
Use a uniform spatial grid with Nx=512 points, defined as x_j = j/Nx for j=0,...,Nx-1.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
Integrate in time using the explicit forward Euler method.
Set the CFL number to 0.5.
Calculate the number of time steps Nt as ceil(T / (CFL * dx / abs(beta))), where dx=1/Nx.
Set the time step dt as T/Nt.
Compute the numerical solution u(x,T) at the final time T=2.0.
Save the results to a file named "solution_pdebench_advection_beta0p4.npz".
The NPZ file must contain the 1D arrays 'x' and 'u' (the final solution), and the scalar values 'beta', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final numerical solution u(x,T) to a file named "solution_pdebench_advection_beta0p4.png".
The plot should not include the exact solution for comparison.
The plot should have a descriptive title, an x-axis label, and a y-axis label.
Print the minimum value of the final solution array u.
Print the maximum value of the final solution array u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
Compute the error against the reference solution evaluated on the grid at T=2.0.
Print the maximum absolute error between the numerical and reference solutions.
Print the L2 error norm between the numerical and reference solutions.
