Solve the 1D viscous Burgers' equation numerically.
The PDE is u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 1.0].
The final time for the simulation is T=1.0.
The viscosity parameter nu is 0.001.
The boundary conditions are periodic.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial grid is a uniform periodic grid with Nx=512 points.
The grid spacing is dx=1/Nx.
The grid points are x_j = j*dx for j=0,...,Nx-1.
The numerical method is Strang splitting for each time step dt.
A full time step consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
The diffusion step of duration dt_sub is solved in Fourier space.
The Fourier space update is u_hat(k) <- u_hat(k) * exp(-nu*k^2*dt_sub).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The advection step for u_t + ∂_x(0.5*u^2)=0 is solved using a finite-volume method with a Rusanov flux.
The flux between cells with values u_left and u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u) is 0.5*u^2.
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The finite volume update is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of cell j.
The time step dt is determined by a CFL condition.
The CFL number is 0.4.
The maximum wave speed is estimated as 1.0.
An initial time step is calculated as dt0 = 0.4 * dx / 1.0.
The number of time steps is Nt = ceil(T/dt0).
The final time step is dt = T/Nt.
The solution u(x,T) at the final time T=1.0 should be computed.
An NPZ file named "solution_pdebench_burgers_nu1em3.npz" must be saved.
The NPZ file must contain the 1D arrays x and u, and the scalars nu, T, dx, dt, Nx, and Nt.
A PNG file named "solution_pdebench_burgers_nu1em3.png" must be saved.
The PNG file must be a line plot of the final solution u against x.
The plot should have a descriptive title and axis labels, following best practices.
The minimum and maximum values of the final solution u must be printed.
The discrete mean value of the final solution u must be printed.
The discrete L2 norm of the final solution u, calculated as sqrt(sum(u^2)*dx), must be printed.
