Solve the partial differential equation -∇ · ( a(x,y) ∇u(x,y) ) = 1 for the unknown field u(x,y).
The spatial domain is the unit square, (x,y) in (0,1) x (0,1).
The parameter beta is set to 2.
The variable coefficient field is defined as a(x,y) = 1 + beta * (0.5 + 0.5*sin(2*pi*x)*sin(2*pi*y)).
Impose a Dirichlet boundary condition of u = 0 on the entire boundary of the domain.
The problem shall be solved on a uniform Cartesian grid with N=128 intervals in both the x and y directions.
This results in a grid of (N+1)x(N+1) points with grid spacing dx = dy = 1/N.
Use a second-order finite difference method to discretize the PDE.
The variable coefficient `a` should be handled using face-centered harmonic averaging.
Assemble the resulting sparse linear system Au=b for the interior grid points.
Solve this linear system using the conjugate gradient method.
Use a Jacobi preconditioner to accelerate the conjugate gradient solver.
The solver should iterate until the relative residual norm, ||Au-b||_2 / ||b||_2, is less than 1e-10.
The final solution u should be represented on the full (N+1)x(N+1) grid, including the boundary values.
Save the numerical results to a compressed NumPy file named 'solution_pdebench_darcy_beta1.npz'.
This file must contain the 1D coordinate arrays 'x' and 'y', the 2D solution array 'u', and the scalar parameters 'beta', 'N', and 'dx'.
Generate a visualization of the solution and save it as 'solution_pdebench_darcy_beta1.png'.
The visualization should be a heatmap of the solution field u(x,y).
The plot must include a title, labels for the x and y axes, and a colorbar.
Use a standard perceptually uniform colormap, such as 'viridis', for the heatmap.
Print the minimum value of the final solution u to the console.
Print the maximum value of the final solution u to the console.
Print the final relative residual norm of the linear system solution to the console.
