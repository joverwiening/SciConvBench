Solve the partial differential equation u_t + q*u_x = 0.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The final time for the simulation is T=1.0.
The advection coefficient is q = 1.5.
The initial condition is u(x,0) = sin(2*pi*x) + 0.2*sin(6*pi*x).
The exact solution for verification is u(x,t) = u0((x - q*t) mod 1), where u0 is the initial condition function.
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j/Nx for j=0,...,Nx-1, with grid spacing dx=1/Nx.
Discretize the spatial derivative u_x using a 1st-order upwind finite difference scheme.
Integrate in time using the Forward Euler method.
The time step dt should be determined by a CFL number of 0.5.
First, calculate a reference time step dt0 = CFL*dx/abs(q).
Then, determine the number of time steps as Nt = ceil(T/dt0).
Finally, set the actual time step to dt = T/Nt.
Compute the numerical solution u(x,T) at the final time T=1.0.
Save the solution to a file named "solution_molk_018.npz".
The NPZ file should contain the 1D arrays for the grid points 'x' and the solution 'u'.
The NPZ file should also contain the scalars T, dx, Nx, and q.
Create a line plot of the numerical solution u(x,T) versus x.
The plot should not include the exact solution.
The plot should have a reasonable title and axis labels.
Save the plot as "solution_molk_018.png".
Print the minimum, maximum, and mean values of the final numerical solution u(x,T).
Also, print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
Compute the error between the numerical solution and the exact solution evaluated on the same grid.
Print the maximum absolute error.
Print the L2 error norm.
