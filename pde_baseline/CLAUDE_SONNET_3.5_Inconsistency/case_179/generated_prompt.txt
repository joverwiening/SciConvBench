Task: Solve 1D Reaction-Diffusion PDE using Python with NumPy and Matplotlib.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The domain is x in [0, 1) periodic and t in [0, 1.0].
Parameters are nu = 10.0 and rho = 5.0.
Initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use periodic boundary conditions where u(0,t) = u(1,t).
Use Nx=512 spatial points with uniform grid spacing dx=1/Nx.
Use Nt=1000 time steps with fixed dt=0.001.
Implement Strang splitting with three steps per time step: diffusion (dt/2), reaction (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space using FFT.
Solve reaction step exactly using the analytical solution of the logistic ODE.
Save solution data to solution_pdebench_reacdiff_nu10_rho5.npz including x, u, nu, rho, T, dx, dt, Nx, Nt.
Create and save a line plot of the final solution as solution_pdebench_reacdiff_nu10_rho5.png.
Print the minimum, maximum, mean, and L2 norm of the final solution.
