Task ID: agent_advection_01
Solve 1D advection equation u_t + u_x = 0 numerically with the following specifications:
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,1.0].
The advection speed a = 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The exact solution is u(x,t) = sin(2*pi*(x-t)).
Use Nx=800 points for spatial discretization.
Use first-order upwind scheme for spatial derivative.
Use Forward Euler time integration.
Set dt based on CFL condition max|a|*dt/dx ≤ 0.9.
Calculate dt by first computing dt0 = 0.9*dx/|a|, then Nt = ceil(T/dt0), then dt = T/Nt.
Save solution data in NPZ file with x, u arrays and T, dx, dt metadata.
Create line plot of solution at final time.
Report min(u), max(u), and L2 norm at final time.
Compare with exact solution using max absolute error and L2 error.
