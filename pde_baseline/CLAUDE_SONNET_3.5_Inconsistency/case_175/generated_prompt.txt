Task: Solve 1D Reaction-Diffusion PDE numerically with the following specifications:
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The domain is x in [0, 1) periodic and t in [0, 1.0].
Parameters are nu = 0.5 and rho = 5.0.
Initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use periodic boundary conditions where u(0,t) = u(1,t).
Use Nx=512 points on a uniform periodic grid with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
Use fixed dt=0.001 with Nt=1000 time steps.
Implement Strang splitting with three substeps: diffusion (dt/2), reaction (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space using FFT.
Solve reaction step exactly using the analytical solution of the logistic ODE.
Save solution data to solution_pdebench_reacdiff_nu0p5_rho5.npz containing x, u, and scalar parameters.
Create and save a line plot of the final solution to solution_pdebench_reacdiff_nu0p5_rho5.png.
Print min(u), max(u), mean(u), and L2 norm of the solution at final time.
