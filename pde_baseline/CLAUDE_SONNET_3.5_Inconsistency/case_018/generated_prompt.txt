Task ID: agent_diffusion_02
Solve a variable-coefficient diffusion PDE u_t = (D(x)u_x)_x where D(x) = 0.01 + 0.09*x^2.
The spatial domain is [0,1].
The time domain is [0,0.2].
Use Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0.
The initial condition is u(x,0)=x*(1-x).
Use a conservative 2nd-order spatial discretization in flux form with arithmetic-averaged face values.
Use Implicit Euler time integration.
Set Nx=400 grid intervals.
Set dt=0.0005 for 480 time steps.
Compute the solution u(x,T) at final time T=0.2.
Save the solution arrays x and u plus metadata T, dx, dt to solution_agent_diffusion_02.npz.
Create and save a line plot of u(x,T) to solution_agent_diffusion_02.png.
Print the minimum value, maximum value, and discrete L2 norm of the final solution.
