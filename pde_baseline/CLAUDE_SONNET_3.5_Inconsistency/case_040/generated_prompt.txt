Use a uniform periodic grid with 64x64 points.
Use Crank-Nicolson time integration with dt=0.0025 (240 steps).
Use 2nd-order central differences with periodic wrap-around for spatial discretization.
Solve the linear system (I - 0.5*dt*alpha*L) u^{n+1} = (I + 0.5*dt*alpha*L) u^n using a sparse direct solver.
Save solution data in solution_agent_heat_11.npz containing x, y, u arrays and metadata.
