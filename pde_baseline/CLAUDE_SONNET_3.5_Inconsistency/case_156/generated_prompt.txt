Task ID: pdebench_cns1d_eta0p1_periodic_smooth
Solve 1D Compressible Navier-Stokes equations numerically.
The domain is x in [-1, 1] and t in [0, 0.5] with T = 0.5.
Use Gamma = 1.6666666666666667.
Use eta = zeta = 0.1.
Apply periodic boundary conditions at x = -1 and x = 1.
Initial conditions are rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), p(x,0) = 1.0 + 0.2*cos(pi*x).
Use uniform finite-volume grid with Nx=400 cells.
Evolve conservative variables U = [rho, m, E].
Use Rusanov flux for convective terms.
Implement viscous terms with centered differences.
Use 2-stage SSP-RK2 time integration.
Compute time step using both convective and viscous constraints.
Save solution arrays to solution_pdebench_cns1d_eta0p1_periodic_smooth.npz.
Create and save plots to solution_pdebench_cns1d_eta0p1_periodic_smooth.png.
Print min/max of rho and p, and mean of rho.
