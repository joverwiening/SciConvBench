Task ID: agent_heat_15
Solve a heat equation PDE numerically using Python and NumPy.
The PDE is u_t = 0.05 * u_xx on domain x in [0,1], t in [0,0.2].
Use Dirichlet boundary conditions u(0,t)=0 and u(1,t)=0.
Initial condition is u(x,0) = exp(-200*(x-0.35)^2).
Use Nx=400 intervals for spatial discretization with 2nd-order central differences.
Use dt=0.0005 for time stepping with Crank-Nicolson method.
Compute solution until T=0.2 (480 time steps).
Save solution arrays (x, u) and metadata (T, dx, dt) to solution_agent_heat_15.npz.
Create and save a line plot of final solution to solution_agent_heat_15.png.
Print minimum value, maximum value, and discrete L2 norm of final solution.
