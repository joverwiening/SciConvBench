Task ID is molk_008.
Solve a Lotka-Volterra predator-prey ODE system using Python.
Use NumPy for numerical computations.
Use Matplotlib for plotting.
The ODE system is dx/dt = alpha*x - beta*x*y and dy/dt = delta*x*y - gamma*y.
Time domain is [0.0, 30.0].
Parameters are alpha=1.5, beta=2, gamma=3.0, delta=1.0.
Initial conditions are x(0.0)=1.0 and y(0.0)=1.0.
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt=0.01.
Use Nt=3000 time steps.
Compute solution at all time points t_n = t0 + n*dt for n=0..Nt.
Save solution to "solution_molk_008.npz" with arrays t, Y, and parameters.
Create line plots of states vs time in "solution_molk_008.png".
Print final state values and min/max of each state over time.
