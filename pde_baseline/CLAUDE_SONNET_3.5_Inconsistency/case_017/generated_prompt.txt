Task ID: agent_diffusion_01
Solve a variable-coefficient diffusion PDE using Python with NumPy/SciPy libraries.
The PDE is u_t = d/dx(D(x)*u_x) with D(x) = 0.1*(1+x).
The domain is x in [0,1], t in [0,0.5].
Dirichlet boundary conditions: u(0,t)=0, u(1,t)=0.
Initial condition: u(x,0)=sin(pi*x).
Use Nx=300 uniform intervals for spatial discretization.
Use dt=0.001 for time integration (600 steps).
Use conservative 2nd-order spatial discretization with arithmetic-averaged face values.
Use Implicit Euler time integration, solving a sparse linear system each step.
Save solution data to solution_agent_diffusion_01.npz containing x, u, T, dx, dt.
Create and save a line plot of the final solution as solution_agent_diffusion_01.png.
Print min(u), max(u), and discrete L2 norm at final time T=0.5.
