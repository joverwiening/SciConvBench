Given the scientific computing nature of the task and the `.npz` file format requirement which is specific to NumPy, Python should be used with NumPy, SciPy, and Matplotlib libraries.


Solve a 2D heat equation PDE numerically with the following specifications:
The PDE is u_t = 0.1 * (u_xx + u_yy).
The domain is (x,y) in [0,1] x [0,1], t in [0,1.0].
The diffusion coefficient alpha is 0.1.
Dirichlet boundary conditions: u(x,y,t) = x + y on all boundaries for all t.
Initial condition: u(x,y,0) = x + y for all points.
Use Python with NumPy, SciPy, and Matplotlib for implementation.
Use a uniform grid with Nx=Ny=40 intervals (41x41 points).
Use implicit Euler time integration with dt=0.01 (120 steps).
Use 5-point Laplacian stencil for spatial discretization.
Solve sparse linear system for interior nodes at each time step.
Save solution data in solution_agent_heat_18.npz with arrays x, y, u and scalars T, dx, dy, dt.
Create and save a heatmap plot as solution_agent_heat_18.png.
Print minimum, maximum, and L2 norm of the solution at T=1.0.
Compute and print max absolute error and L2 error against exact solution u(x,y,t) = x + y.
