Given the scientific computing nature of the task and the mention of NumPy's .npz format, Python should be used with NumPy and matplotlib libraries.


Solve the Korteweg-de Vries (KdV) equation using Python.
The PDE is u_t + 6*u*u_x + u_xxx = 0 with periodic boundary conditions.
The spatial domain is [0,1) with periodicity.
The temporal domain is [0,0.1].
The initial condition is u(x,0) = 0.5*cos(2*pi*x).
Use a Fourier pseudo-spectral method for spatial derivatives.
Use explicit RK4 time integration with dt=1e-5.
Use Nx=1024 grid points.
Compute nonlinear term 6*u*u_x in physical space.
Save solution at T=0.1 in solution_agent_other_03_kdv.npz with arrays x, u and metadata T, dx, dt.
Create and save a line plot of the final solution as solution_agent_other_03_kdv.png.
Print the minimum value, maximum value, and discrete L2 norm of the solution at final time.
