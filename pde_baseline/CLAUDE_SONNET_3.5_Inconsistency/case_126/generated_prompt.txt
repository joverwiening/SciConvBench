Task: Solve 1D inviscid Burgers equation numerically with the following specifications:
The PDE is u_t = -k*∂_x(0.5*u^2) with k = 1.0.
The domain is x in [0, 1) periodic and t in [0, 0.2].
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=1024 points.
Use a conservative finite-volume method with Rusanov flux for f(u)=0.5*u^2.
Implement SSP-RK2 (Heun) time integration.
Set time step using CFL=0.2 with dt0 = CFL*dx/max|u|, estimating max|u|≈1.
Compute final solution at T=0.2.
Save solution data in solution_molk_025.npz including x, u arrays and scalar parameters.
Create and save a line plot of the solution as solution_molk_025.png.
Print minimum, maximum, mean, and L2 norm of the final solution.
Use Python with NumPy for implementation.
