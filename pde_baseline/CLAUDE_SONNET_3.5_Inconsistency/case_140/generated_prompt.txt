Task ID: pdebench_advection_beta2
Solve 1D Advection PDE u_t + beta * u_x = 0 using Python with NumPy and Matplotlib.
The domain is x in [0,1) periodic and t in [0,2.0].
Use beta = 2.0.
Apply periodic boundary conditions u(0,t) = u(1,t).
Set initial condition u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use Nx=512 points on a uniform periodic grid with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
Implement 1st-order upwind finite difference for spatial discretization.
Use explicit forward Euler time integration.
Set time step using CFL=0.5 with dt = CFL * dx / abs(beta), then adjust to hit final time T=2.0 exactly.
Compute solution at T=2.0.
Save solution data to solution_pdebench_advection_beta2.npz including x, u, beta, T, dx, dt, Nx, Nt.
Create and save line plot of solution to solution_pdebench_advection_beta2.png.
Print minimum, maximum, and L2 norm of solution at final time.
Compute and print max absolute error and L2 error against reference solution.
