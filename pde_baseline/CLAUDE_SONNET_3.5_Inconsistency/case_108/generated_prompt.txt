Task ID is molk_007.
Solve Van der Pol oscillator ODE system numerically.
The ODE system is dx/dt = y and dy/dt = mu*(1 - x^2)*y - x.
Time domain is [0.0, 20.0].
Parameter mu = 4.
Initial conditions are x(0.0) = 1.0 and y(0.0) = 0.0.
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt=0.01.
Use Nt=2000 time steps.
Compute full state vector at all time points.
Save solution to "solution_molk_007.npz" with arrays t and Y, including parameter values.
Create line plots of states vs time in "solution_molk_007.png" using standard figure size.
Print final state values at T=20.0 and min/max of each state over time.
Use Python with standard scientific computing libraries.
Use matplotlib for plotting.
