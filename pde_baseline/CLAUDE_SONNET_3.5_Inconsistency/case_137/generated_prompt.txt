Task ID: pdebench_advection_beta0p4
Solve 1D Advection equation u_t + beta * u_x = 0 numerically.
The domain is x in [0, 1) with periodic boundary and t in [0, 2.0].
Use beta = 0.4.
Apply periodic boundary conditions: u(0,t) = u(1,t).
Initial condition is u(x,0) = sin(2*pi*x) + 0.5*sin(4*pi*x).
Use a uniform grid with Nx=512 points on [0,1).
Use 1st-order upwind finite difference for spatial discretization.
Use explicit forward Euler for time integration.
Set CFL=0.5 and calculate dt = CFL * dx / abs(beta).
Adjust dt to hit final time T=2.0 exactly by computing Nt = ceil(T/dt) and resetting dt = T/Nt.
Compute solution at T=2.0.
Save solution data to "solution_pdebench_advection_beta0p4.npz" with arrays x, u and scalars beta, T, dx, dt, Nx, Nt.
Create a line plot of the solution and save as "solution_pdebench_advection_beta0p4.png" with appropriate axis labels and title.
Print minimum value, maximum value, and L2 norm of the solution at final time.
Compute and print maximum absolute error and L2 error compared to reference solution.
