PDE category: Klein-Gordon
Unknown field: u(x,y,t)

Solve the Klein-Gordon PDE numerically with the following specifications:
The PDE is u_tt - (1.0)^2*(u_xx + u_yy) + (1.0)^2*u = 0.
The domain is (x,y) in [0,1] x [0,1], t in [0,0.8].
Wave speed parameter c = 1.0.
Mass parameter m = 1.0.
Dirichlet boundary conditions u=0 on all boundaries.
Initial condition u(x,y,0)=sin(pi*x)*sin(pi*y) and u_t(x,y,0)=0.
Exact solution is u(x,y,t)=cos(sqrt((1.0)^2*(2*pi^2) + (1.0)^2)*t)*sin(pi*x)*sin(pi*y).
Use uniform grid with 5-point Laplacian for spatial discretization.
Use 2nd-order central difference in time for u_tt.
Initialize using Taylor start with Laplacian and mass term.
Use Nx=Ny=256 intervals with dx=dy=1/Nx.
Set dt0 = 0.9 / (c*sqrt(1/dx^2 + 1/dy^2)).
Set Nt = ceil(T/dt0) and then dt = T/Nt.
Compute solution at T=0.9.
Save solution in NPZ file with specified arrays and metadata.
Create and save heatmap/contour plot.
Report minimum, maximum, and L2 norm of solution.
Compute and report max absolute error and L2 error against reference solution.
Implementation can use any suitable numerical computing environment following best practices.
