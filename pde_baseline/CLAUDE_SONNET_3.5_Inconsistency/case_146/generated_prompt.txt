Task ID: pdebench_burgers_nu0p1
Solve 1D Viscous Burgers equation with periodic boundary conditions.
Use Python with NumPy/SciPy for numerical computations.
Use Matplotlib for plotting.
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The domain is x in [0, 1) periodic and t in [0, 1.0].
Set nu = 0.1.
Use periodic boundary conditions u(0,t) = u(1,t).
Set initial condition u(x,0) = sin(2*pi*x).
Use Nx=512 points on a uniform periodic grid with x_j = j*dx for j=0,...,Nx-1 and dx=1/Nx.
Implement Strang splitting with exact Fourier diffusion solve and Rusanov flux for advection.
Use CFL=0.4 with estimated max speed of 1.0 to determine time step.
Compute solution until T=1.1.
Save solution data to solution_pdebench_burgers_nu0p1.npz.
Create line plot saved as solution_pdebench_burgers_nu0p1.png.
Print min(u), max(u), mean(u), and L2 norm at final time.
