Task ID: pdebench_reacdiff_nu5_rho2
Solve a 1D Reaction-Diffusion PDE with logistic reaction term and periodic boundary conditions.
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is [0, 1) with periodic boundary conditions.
The time domain is [0, 1.0].
Parameters are nu = 5.0 and rho = 2.0.
Initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use Nx=512 spatial points with uniform spacing.
Use Nt=1000 time steps with dt=0.001.
Implement Strang splitting with Fourier-based diffusion and exact logistic ODE solution.
Save solution data to solution_pdebench_reacdiff_nu5_rho2.npz.
Create a line plot saved as solution_pdebench_reacdiff_nu5_rho2.png.
Print min, max, mean, and L2 norm of final solution.
Use standard scientific computing libraries for implementation.
