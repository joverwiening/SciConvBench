The exact solution is u(x,t) = exp(-0.5*(2*pi)^2*t) * sin(2*pi*x).
Use a uniform spatial grid with Nx=200 intervals (201 points including boundaries).
Use 2nd-order central differences for spatial discretization of u_xx.
Implement Crank-Nicolson time integration for diffusion terms.
Use time step dt=0.0005 (480 time steps).
Compute the solution until T=0.2.
Save solution data in solution_agent_heat_02.npz containing x, u arrays and T, dx, dt scalars.
Create and save a line plot of u(x,T) as solution_agent_heat_02.png.
Print minimum and maximum values of u, and its discrete L2 norm at T=0.2.
Compute and print the maximum absolute error and L2 error compared to the exact solution.
Use Python with NumPy/SciPy for computations and Matplotlib for plotting.
