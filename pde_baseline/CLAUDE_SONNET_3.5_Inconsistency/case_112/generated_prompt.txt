Initial conditions are x(0.0) = 1.0 and y(0.0) = 0.0.
Use Classical 4th-order Runge-Kutta (RK4) method with fixed time step dt = 0.01.
Use Nt = 5000 time steps.
Compute full state vector at all time points.
Save solution to "solution_molk_011.npz" with arrays t and Y, and parameter scalars.
Create line plots of states vs time and save as "solution_molk_011.png".
