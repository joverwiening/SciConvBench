Task ID is molk_006.
Solve a 3-state neural dynamics ODE system for E, I, H functions of t.
The ODE system is dE/dt = 1.2*E - E*I - 0.5*E + 0.01*sin(t), dI/dt = 0.8*E - 0.7*I, dH/dt = 0.9*I - 0.4*H.
Time domain is [0.0, 50.0].
Parameters are alpha=1.2, beta=1.0, gamma=0.5, delta=0.8, epsilon=0.7, theta=0.9, phi=0.4.
Initial conditions are E(0)=0.5, I(0)=0.2, H(0)=0.1.
Use Classical 4th-order Runge-Kutta (RK4) with fixed step size dt=0.01 for Nt=5000 steps.
Compute full state vector at all time points.
Save solution data to solution_molk_006.npz containing t array, Y array [E,I,H], and parameters.
Create and save line plot of states vs time to solution_molk_006.png using reasonable formatting.
Print final state values and min/max of each state over time.
