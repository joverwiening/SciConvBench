Task: Solve 1D Viscous Burgers equation numerically with the following specifications:
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The domain is x in [0,1) periodic and t in [0,1.0].
The viscosity parameter nu is 0.001.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points.
Implement Strang splitting with exact Fourier diffusion solve and Rusanov flux for advection.
Use CFL=0.4 for time stepping.
Compute solution until T=1.1.
Save solution data in NPZ format including x, u, nu, T, dx, dt, Nx, Nt.
Create a line plot of the final solution.
Print min(u), max(u), mean(u), and L2 norm at final time.
Use Python with standard scientific computing libraries.
Use scientific notation for scalar diagnostic output.
Save results as solution_pdebench_burgers_nu1em3.npz and solution_pdebench_burgers_nu1em3.png.
