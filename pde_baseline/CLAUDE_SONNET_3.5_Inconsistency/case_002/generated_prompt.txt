Task ID: agent_advection_02
PDE category: Advection
Unknown field: u(x,t)

Solve the advection equation u_t + (-0.5)*u_x = 0.
The spatial domain is [0,1) with periodic boundary conditions.
The time domain is [0,1.0].
The advection speed is a = -0.5.
The initial condition is u(x,0) = exp(-100*(x-0.3)^2).
Use Nx=1000 points on [0,1) with periodic boundary conditions.
Use first-order upwind scheme with right-biased (downwind) stencil due to negative speed.
Use Forward Euler time integration.
Set dx = 1/Nx.
Set dt0 = 0.9*dx/|a|.
Set Nt = ceil(T/dt0) and then dt = T/Nt.
Compute the solution u(x,T=1.0).
Save solution data to solution_agent_advection_02.npz containing x, u, T, dx, and dt.
Create and save a line plot of u(x,T) as solution_agent_advection_02.png.
Print min(u), max(u), and the discrete L2 norm sqrt(sum(u^2)*dx) at T.
