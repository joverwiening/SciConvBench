Task ID: agent_diffusion_05
Solve a 1D diffusion PDE using Python with NumPy/SciPy for numerical computations and Matplotlib for plotting.
The PDE is u_t = 0.1 * u_xx on domain x in [0,1], t in [0,0.5].
Use diffusion coefficient D = 0.1 and beta = 1.0.
Apply Robin boundary conditions: u_x(0,t) + 1.0*u(0,t) = 0 and u_x(1,t) + 1.0*u(1,t) = 0.
Initial condition is u(x,0) = cos(pi*x).
Use Nx=300 intervals for spatial discretization with 2nd-order central differences.
Implement Robin BCs using 2nd-order one-sided differences as specified.
Use Crank-Nicolson time integration with dt=0.001 (600 steps).
Save solution data to solution_agent_diffusion_05.npz containing x, u, T, dx, dt.
Create and save a line plot of the final solution as solution_agent_diffusion_05.png.
Print min(u), max(u), and discrete L2 norm at final time T=0.5.
