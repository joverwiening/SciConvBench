Task ID: agent_advection_05
PDE category: Advection
Unknown field: u(x,y,t)
Solve the PDE u_t + (-0.7)*u_x + (1.2)*u_y = 0.
The domain is (x,y) in [0,1) x [0,1) periodic, t in [0,0.5].
The parameters are a = -0.7 and b = 1.2.
Use periodic boundary conditions on x and y.
The initial condition is u(x,y,0)=exp(-80*((x-0.2)^2 + (y-0.6)^2)).
Use upwind spatial discretization with direction based on sign of a and b.
Use Forward Euler time integration with CFL condition |a|*dt/dx + |b|*dt/dy ≤ 0.9.
Use periodic wrap-around indexing in both directions.
Use Nx=Ny=256 points on [0,1) x [0,1).
Set dx=dy=1/Nx.
Calculate dt0 = 0.9 / (|a|/dx + |b|/dy).
Set Nt = ceil(T/dt0) and then dt = T/Nt.
Compute u(x,y,T=0.5) on the 2D grid.
Save solution_agent_advection_05.npz with arrays x, y, u and metadata T, dx, dy, dt.
Save heatmap/contour plot as solution_agent_advection_05.png.
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
