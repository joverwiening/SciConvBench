Solve the wave equation PDE numerically with these specifications:
The PDE is u_tt = (1.0)^2 * (u_xx + u_yy).

The exact solution is u(x,y,t)=cos(1.0*sqrt(2)*pi*t)*sin(pi*x)*sin(pi*y).

Set Nt = ceil(T/dt0) and dt = T/Nt.
Initialize first time step using Taylor start with initial velocity.
Apply Dirichlet BC at each time step.
