Task ID: agent_allen_cahn_05
PDE category: Allen-Cahn
Unknown field: u(x,y,t)
Solve the Allen-Cahn equation u_t = (0.02)^2*(u_xx + u_yy) + u - u^3 numerically.
The domain is (x,y) in [0,1] x [0,1], t in [0,0.1].
The parameter epsilon is 0.02.
Apply Dirichlet boundary conditions u=0 on all boundaries.
Initial condition is u(x,y,0)=tanh((0.25 - r)/(sqrt(2)*0.02)) where r = sqrt((x-0.5)^2 + (y-0.5)^2).
Use semi-implicit time integration: (u^{n+1}-u^n)/dt = ε^2*Δu^{n+1} + u^n - (u^n)^3.
Use uniform grid with 5-point Laplacian for spatial discretization.
Set Nx=Ny=300 grid points.
Use dt=0.0001 (1000 steps).
Enforce Dirichlet BC by setting boundary nodes to prescribed values each time step.
Compute u(x,y,T=0.1) on the 2D grid.
Save solution data to "solution_agent_allen_cahn_05.npz" with arrays x, y, u and metadata T, dx, dy, dt.
Save heatmap/contour plot of u(x,y,T) as "solution_agent_allen_cahn_05.png".
Print min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
