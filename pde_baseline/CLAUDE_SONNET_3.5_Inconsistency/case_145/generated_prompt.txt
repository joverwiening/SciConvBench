Task: Solve 1D Viscous Burgers equation numerically with the following specifications:
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The spatial domain is [0, 1) with periodic boundary conditions.
The temporal domain is [0, 1.0].
The viscosity parameter nu is 0.04.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points.
Implement Strang splitting with three substeps: diffusion (dt/2), advection (dt), diffusion (dt/2).
Solve diffusion steps exactly in Fourier space.
Use Rusanov flux for the advection step.
Set time step using CFL=0.4 with estimated max speed of 1.0.
Compute solution until T=1.1.
Save solution data in NPZ format including x, u, nu, T, dx, dt, Nx, Nt.
Create and save a line plot of the final solution.
Print minimum, maximum, mean, and L2 norm of the final solution.
Use Python with appropriate scientific computing and plotting libraries.
