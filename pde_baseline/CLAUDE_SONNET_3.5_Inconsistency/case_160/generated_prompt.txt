Domain is x in [-1,1], t in [0,0.2].
Parameters are Gamma = 1.6666666666666667, eta = zeta = 1e-08.
Boundary conditions are transmissive/outflow at both ends.
Initial condition is a Riemann problem with left state (rho=1.0, v=0.0, p=1.0) and right state (rho=0.125, v=0.0, p=0.1).
Use finite-volume method with Nx=800 cells.
Evolve conservative variables U = [rho, m, E].
Use Rusanov flux for convective terms.
Implement viscous terms with centered differences.
Use 2-stage SSP-RK2 time integration.
Compute time step using both convective and viscous constraints.
Use CFL = 0.5 as a standard safe choice for this type of problem.
Implement outflow boundary conditions using zero-gradient in ghost cells.
Save solution arrays in NPZ format.
Create visualization plot of rho, v, p vs x.
Report min/max of rho and p, and mean of rho.
Save results as specified filenames.
