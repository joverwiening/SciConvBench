Task: Solve 1D Viscous Burgers equation numerically with the following specifications:
The PDE is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The spatial domain is [0, 1) with periodic boundary conditions.
The temporal domain is [0, 1.0].
The viscosity parameter nu is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
Use Python with appropriate scientific computing libraries.
Use Nx=512 points for the uniform periodic spatial grid.
Implement Strang splitting with three substeps: FFT-based diffusion (dt/2), Rusanov flux advection (dt), FFT-based diffusion (dt/2).
Use CFL=0.4 with estimated max speed of 1.0 for time stepping.
Save the solution data in NPZ format including x, u, nu, T, dx, dt, Nx, and Nt.
Create a line plot of the final solution u(x,T) and save as PNG.
Print the minimum, maximum, mean, and L2 norm of the final solution.
Use standard plotting defaults for the visualization.
