Task ID: molk_023
Solve a 1D nonlinear reaction-diffusion PDE using Python.
The PDE is u_t = 0.01*u_xx + 2.0*(u**2)*(1-u)**2.
The domain is x in [0,1) with periodic boundary conditions and t in [0,1.0].
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
Use a uniform periodic grid with Nx=512 points.
Use 2nd-order central differences for spatial discretization.
Use explicit RK4 for time integration.
Use dt=0.0005 with Nt=2000 time steps.
Save the solution at T=1.0 in solution_molk_023.npz with arrays x and u, and scalar parameters.
Create a line plot of the final solution as solution_molk_023.png.
Print min(u), max(u), mean(u), and L2 norm at final time.
No error computation is needed as no exact solution is provided.
