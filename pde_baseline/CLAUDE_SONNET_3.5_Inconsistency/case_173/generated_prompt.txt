Task: Solve 1D Reaction-Diffusion PDE numerically with the following specifications:
The PDE is u_t = nu * u_xx + rho * u*(1 - u).
The domain is x in [0, 1) periodic and t in [0, 1.0].
Parameters are nu = 0.5 and rho = 10.0.
Initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use periodic boundary conditions where u(0,t) = u(1,t).
Use Nx=512 spatial points with uniform grid spacing.
Use Nt=1000 time steps with fixed dt=0.001.
Implement Strang splitting with FFT-based diffusion solver and exact logistic ODE solver.
Save solution data in solution_pdebench_reacdiff_nu0p5_rho10.npz file.
Create line plot of final solution in solution_pdebench_reacdiff_nu0p5_rho10.png.
Print minimum, maximum, mean, and L2 norm of final solution.
