Solve the 1D viscous Burgers' equation: u_t + d/dx(0.5 * u^2) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The viscosity parameter nu is 1.0.
The initial condition is u(x, 0) = sin(2 * pi * x).
Discretize the spatial domain using a uniform periodic grid with Nx = 512 points.
The grid points are defined as x_j = j * dx for j = 0, ..., Nx-1, where dx = 1 / Nx.
The final time T is 1.0.
Calculate the time step size based on a CFL number of 0.4 and a maximum wave speed of 1.0.
First, calculate a preliminary time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of time steps Nt = ceil(T / dt0).
Finally, set the actual time step dt = T / Nt to ensure the final time is reached exactly.
Integrate in time using a Strang splitting method for each time step dt.
The first substep is to solve the diffusion equation u_t = nu * u_xx for a duration of dt/2.
Solve the diffusion substep in Fourier space.
Compute the forward FFT of the solution u to get u_hat.
Define the wavenumbers k = 2 * pi * fftfreq(Nx, d=dx).
Update the Fourier coefficients: u_hat(k) = u_hat(k) * exp(-nu * k^2 * (dt/2)).
Compute the inverse FFT of the updated u_hat and take its real part to get the result of the first substep.
The second substep is to solve the advection equation u_t + d/dx(0.5 * u^2) = 0 for a duration of dt.
Solve the advection substep using a finite-volume method with a Rusanov (local Lax-Friedrichs) flux.
The flux function is f(u) = 0.5 * u^2.
For each interface between cells j and j+1 (with periodic indexing), the numerical flux F is calculated.
Let u_left = u[j] and u_right = u[j+1].
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The Rusanov flux is F = 0.5 * (f(u_left) + f(u_right)) - 0.5 * alpha * (u_right - u_left).
Update the solution in each cell j using the conservative formula: u_new[j] = u[j] - (dt/dx) * (F_plus - F_minus).
F_plus is the flux at the interface between cells j and j+1.
F_minus is the flux at the interface between cells j-1 and j.
The third substep is to solve the diffusion equation u_t = nu * u_xx again for a duration of dt/2, using the same Fourier method as the first substep.
Compute the solution u(x, T) at the final time T=1.0.
