Solve the one-dimensional Cahn-Hilliard equation.
The partial differential equation is u_t = -ε^2 * u_xxxx + ∂^2/∂x^2(u^3 - u).
The parameter ε is 0.01.
The spatial domain is x ∈ [0, 1) with periodic boundary conditions.
The time domain is t ∈ [0, 0.05].
The initial condition is u(x,0) = 0.1*cos(2*pi*x) + 0.01*cos(6*pi*x).
Discretize the spatial domain with Nx=512 equally spaced points.
The grid points are x_j = j/Nx for j = 0, ..., Nx-1.
The spatial step size is dx = 1/Nx.
Use a constant time step of dt = 1e-5.
Solve the equation using a Fourier pseudo-spectral method.
Use a semi-implicit time integration scheme where the linear part is treated implicitly and the nonlinear part is treated explicitly.
The linear operator in Fourier space is L(k) = k^2 - ε^2*k^4, where k are the wavenumbers.
The nonlinear term in real space is N(u) = ∂^2/∂x^2(u^3).
The time-stepping formula in Fourier space is û^{n+1} = (û^n + dt * 𝔽[N(u^n)]) / (1 - dt*L(k)).
Apply a 2/3 dealiasing rule when computing the nonlinear term.
To dealias, after computing the FFT of u^3, set to zero all Fourier modes for which the absolute value of the wavenumber exceeds 2/3 of the maximum wavenumber.
Run the simulation up to the final time T = 0.05.

The NPZ file must contain the 1D grid coordinates as 'x', the 1D solution array as 'u', and the scalars 'T', 'dx', and 'dt'.
At T = 0.05, create a line plot of the solution u as a function of x.
