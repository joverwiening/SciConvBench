Perform a 2D steady-state heat conduction simulation using the laplacianFoam solver in OpenFOAM.
The simulation domain is a 1m x 1m square plate, one cell thick.
The mesh resolution will be 20 cells in the x-direction and 20 cells in the y-direction.
In the blockMeshDict file, define five patches: left, right, top, bottom, and frontAndBack.
Set the frontAndBack patch type to empty.
The thermal diffusivity (DT) of the material is set to 1.5e-5 m^2/s.
In the 0/T file, set the initial internal field temperature to a uniform value of 300 K.
The boundary condition for the left patch is fixedValue with a uniform value of 400 K.
The boundary condition for the right patch is fixedValue with a uniform value of 300 K.
The boundary conditions for the top and bottom patches are zeroGradient.
The boundary condition for the frontAndBack patch is empty.
The simulation will run until a steady-state solution is reached, with the endTime in controlDict set to 1000 to ensure convergence.
