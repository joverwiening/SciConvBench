Use the FEniCS legacy library (dolfin) to solve a 2D small-strain linear elasticity problem.
The geometry is a rectangular plate defined by the domain Ω = (0, 1.0) x (0, 0.20) meters.
Create a uniform structured mesh of the rectangle with 40 subdivisions in the x-direction and 8 subdivisions in the y-direction.
The model is based on the plane-stress assumption.
The material is linear elastic with Young's modulus E = 200e9 Pa and Poisson's ratio ν = 0.30.
Define a vector-valued function space for the displacement field using continuous Lagrange elements of polynomial degree 2.
Apply a Dirichlet boundary condition on the left edge (x=0) to fix the displacement to u = (0, 0).
Apply a traction vector t = (0, -2000) N/m on the top edge (y=0.20).
The right edge (x=1.0) and bottom edge (y=0) are traction-free.
Solve the linear variational problem using a direct solver.
Save a color plot of the y-component of the displacement field to a file named `q2_uy.png`.
Save the full displacement vector field to an XDMF file named `q2_displacement.xdmf`.
