Solve the 1D compressible Navier-Stokes equations for density rho(x,t), velocity v(x,t), and pressure p(x,t).
The conservative variables are U = [rho, m, E], where m = rho*v is the momentum and E = p/(Gamma-1) + 0.5*rho*v^2 is the total energy.
The governing equations in conservative form are:
d(rho)/dt + d(m)/dx = 0
d(m)/dt + d(m^2/rho + p - sigma)/dx = 0
d(E)/dt + d((E+p)*v - v*sigma)/dx = 0
The viscous stress is sigma = (zeta + 4/3*eta) * d(v)/dx.
The spatial domain is x in [-1, 1].
The time domain is t in [0, 0.2].
The final time is T = 0.2.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The boundary conditions at x=-1 and x=1 are transmissive (outflow), implemented with a zero-gradient condition.
The initial condition is a Riemann problem with a discontinuity at x=0.
For x < 0, the initial state is rho_L = 1.0, v_L = -0.75, and p_L = 1.0.
For x >= 0, the initial state is rho_R = 0.125, v_R = 0.0, and p_R = 0.1.
The problem is solved on a uniform finite-volume grid with Nx = 800 cells.
The cell width is dx = 2.0 / 800.
The cell centers are located at x_j = -1 + (j+0.5)*dx for j=0,...,799.
The conservative variables U = [rho, m, E] are evolved as cell averages.
The equation of state is p = (Gamma-1) * (E - 0.5*m^2/rho).
If rho or p become non-positive during the simulation, they are clipped to a floor value of 1e-12.
The convective flux is F_conv(U) = [m, m^2/rho + p, (E+p)*v], where v = m/rho.
The convective part of the PDE is discretized using the Rusanov (local Lax-Friedrichs) numerical flux.
The Rusanov flux at an interface between states U_L and U_R is F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
The interface wave speed is a = max( |v_L| + c_L, |v_R| + c_R ), where the speed of sound is c = sqrt(Gamma*p/rho).
The velocity gradient v_x at cell centers is computed using a second-order centered difference on the cell-centered velocity values.
The viscous stress sigma = (zeta + 4/3*eta)*v_x is computed at cell centers.
The viscous stress at cell interfaces is approximated by averaging the values from the two adjacent cell centers.
The viscous flux is F_visc = [0, -sigma, -v*sigma].
The velocity v and stress sigma used in the viscous flux at an interface are averages of the neighboring cell-centered values.
The total numerical flux at an interface is F_total = F_hat + F_visc.
The semi-discrete system is integrated in time using the 2-stage Strong Stability Preserving Runge-Kutta method (SSP-RK2).
The time step dt is chosen at each step according to dt = min(dt_conv, dt_visc).
The convective time step limit is dt_conv = CFL * dx / max_j( |v_j| + c_j ), with a CFL number of 0.5.
The viscous time step limit is dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30).
The final time step is adjusted to ensure the simulation stops exactly at T = 0.2.
Outflow boundary conditions are implemented by setting the values in the ghost cells equal to the values in the nearest interior cells.
