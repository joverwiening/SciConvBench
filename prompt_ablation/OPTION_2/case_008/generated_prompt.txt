Use the FEniCS legacy library (dolfin) to solve a 2D small-strain orthotropic plane-stress elasticity problem.
The simulation domain is a rectangle defined by the corners (0, 0) and (1.0, 0.20) in meters.
Mesh the domain with a 50x25 structured quadrilateral mesh.
The material is orthotropic with local properties: E1 = 40 GPa, E2 = 10 GPa, G12 = 5 GPa, and nu12 = 0.25.
The local material axes are rotated 30 degrees anticlockwise with respect to the global x-y axes.
Construct the plane-stress reduced stiffness matrix in the local frame and rotate it to the global frame for the simulation.
Apply a fixed boundary condition (u_x = 0, u_y = 0) on the bottom edge (y = 0).
Apply a uniform downward traction vector t = (0, -10e6) N/m^2 on the top edge (y = 0.20).
The vertical sides (x = 0 and x = 1) are traction-free.
Solve the resulting linear system using a direct solver.
Post-process the solution to calculate the von Mises stress.
Save a color plot of the x-component of displacement (u_x) to a file named `q8_ux.png`.
Save a color plot of the von Mises stress to a file named `q8_vm.png`.
Save the displacement and stress fields to a file named `q8_solution.xdmf`.
