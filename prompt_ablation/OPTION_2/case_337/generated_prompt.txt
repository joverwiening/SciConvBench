The goal is to compute the adsorption energy of CO on an OsO2 surface.
This task involves three VASP geometry optimizations followed by a post-processing script.
The same INCAR file will be used for all three VASP calculations.

First, create a file named `INCAR` with the following content:
```
# General Parameters
PREC = Normal
LREAL = Auto
LWAVE = .TRUE.
LCHARG = .TRUE.
ENCUT = 450

# Electronic Relaxation
NELM = 60
EDIFF = 1E-5
ALGO = Normal
ISMEAR = 1
SIGMA = 0.2

# Ionic Relaxation
NSW = 400
IBRION = 1
ISIF = 2
POTIM = 0.2
EDIFFG = -0.05

# Spin
ISPIN = 1
```

Execute the following four steps in order.

Step 1: Optimize the CO molecule.
Run the command: `python op.py CO POTCAR-CO POSCAR-CO`.

Step 2: Optimize the clean OsO2 surface.
Run the command: `python op.py surface POTCAR-OsO2face POSCAR-OsO2face`.

Step 3: Optimize the CO-adsorbed OsO2 system.
Run the command: `python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO`.

Step 4: Calculate the final adsorption energy.
Run the command: `bash ./calc_absorption_energy.sh`.

The final output will be the adsorption energy value printed by the `calc_absorption_energy.sh` script.
