Solve the Kuramoto-Sivashinsky partial differential equation u_t + u*u_x + u_xx + u_xxxx = 0.
The spatial domain is x in [0, 2*pi) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The initial condition is u(x,0) = cos(x) + 0.1*cos(2*x).
Use a Fourier pseudo-spectral method for spatial derivatives.
The spatial grid has Nx=1024 points.
The grid spacing is dx = 2*pi/Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Use a semi-implicit time integration scheme.
The time step is dt = 1e-4.
The simulation runs for 10,000 steps to reach the final time T=1.0.
The time-stepping formula for each Fourier mode k is û^{n+1} = (û^n - dt * F[u^n * (u_x)^n]) / (1 - dt*(-k^2 + k^4)).
The nonlinear term u*u_x is computed in real space at each time step and then transformed to Fourier space.
The final solution u(x, T=1.0) should be computed.
Save the solution to a file named "solution_agent_other_04_kuramoto_sivashinsky.npz".
The NPZ file must contain the 1D array of grid points 'x', the 1D array of the solution 'u', and the scalars 'T', 'dx', and 'dt'.
Save a line plot of the final solution u(x, T=1.0) to a file named "solution_agent_other_04_kuramoto_sivashinsky.png".
Print the minimum value of the final solution u.
Print the maximum value of the final solution u.
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
