Solve the PDE u_t + ∂_x( 0.5*u^2 ) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The final time T is 1.0.
The viscosity parameter nu is 4.0.
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points.
The grid points are x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
Use Strang splitting for time integration.
Each full time step dt consists of a half-step of diffusion, a full step of advection, and another half-step of diffusion.
The diffusion half-step of duration dt/2 is solved exactly in Fourier space.
The update rule in Fourier space is u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
The advection full-step of duration dt solves the inviscid Burgers equation using a finite-volume method with a Rusanov flux.
The flux function is f(u) = 0.5*u^2.
The Rusanov flux F between a left state u_left and a right state u_right is F = 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left).
The local wave speed is alpha = max(abs(u_left), abs(u_right)).
The finite volume update for cell j is u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus), where F_plus and F_minus are the fluxes at the right and left interfaces of the cell.
The time step dt is determined by a CFL number of 0.4 and an estimated maximum speed of 1.0.
First, calculate an initial time step dt0 = 0.4 * dx / 1.0.
Then, determine the number of steps Nt = ceil(T/dt0).
Finally, set the time step to dt = T/Nt to reach the final time exactly.
Compute the solution u(x,T) at the final time T=1.0.
Save the output to a file named "solution_pdebench_burgers_nu4.npz".
The output file must contain the 1D arrays x and u, and the scalar values nu, T, dx, dt, Nx, and Nt.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_burgers_nu4.png".
Print the minimum, maximum, discrete mean value, and discrete L2 norm of the final solution u(x,T).
