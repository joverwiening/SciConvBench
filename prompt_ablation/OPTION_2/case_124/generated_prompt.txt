Solve the partial differential equation u_t = q1*u_xx + q2*(u^2)*(1-u)^2.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The time domain is t in [0, 1.0].
The PDE parameters are q1 = 0.01 and q2 = 2.0.
The initial condition is u(x,0) = 0.2 + 0.1*sin(2*pi*x).
Discretize the spatial domain with Nx = 512 grid points.
The grid spacing is dx = 1.0/Nx.
The grid points are x_i = i*dx for i = 0, ..., Nx-1.
Discretize the second spatial derivative, u_xx, using a second-order central difference scheme.
Integrate in time using the explicit fourth-order Runge-Kutta (RK4) method.
Use a time step of dt = 0.0005.
The final time is T = 1.0.
Compute the solution u(x,T) on the grid.
Save a file named "solution_molk_023.npz".
The NPZ file will contain the 1D array 'x' of grid point locations, the 1D array 'u' of the solution at T, and the scalar values T, dx, Nx, q1, and q2.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_molk_023.png".
At the final time T, print the minimum, maximum, mean, and discrete L2 norm of the solution u.
The discrete L2 norm is calculated as sqrt(sum(u^2)*dx).
