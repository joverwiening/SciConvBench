Solve the partial differential equation u_t = nu * u_xx + rho * u*(1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 1.0].
The diffusion coefficient is nu = 2.0.
The reaction coefficient is rho = 10.0.
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.25 + 0.1*sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=512 points, where x_j = j/Nx for j=0,...,Nx-1.
Use a fixed time step of dt=0.001 for Nt=1000 steps to reach the final time T=1.0.
Use a Strang splitting method for the time integration over each time step dt.
The first sub-step is to advance the diffusion term for a half-step of dt/2.
Solve the diffusion step exactly in Fourier space using the update u_hat(k) <- u_hat(k) * exp(-nu*k^2*(dt/2)).
The second sub-step is to advance the reaction term for a full-step of dt.
Solve the reaction step exactly at each grid point using the update u <- (u*exp(rho*dt)) / (1 + u*(exp(rho*dt) - 1)).
The third sub-step is to advance the diffusion term for another half-step of dt/2 using the same Fourier space method as the first sub-step.
Compute the final solution u(x,T) at T=1.0.
Save the output to a file named "solution_pdebench_reacdiff_nu2_rho10.npz".
The NPZ file must contain the 1D arrays 'x' and 'u', and the scalar values 'nu', 'rho', 'T', 'dx', 'dt', 'Nx', 'Nt'.
Save a line plot of the final solution u(x,T) versus x to a file named "solution_pdebench_reacdiff_nu2_rho10.png".
Print the minimum, maximum, and mean of the final solution u(x,T).
Print the discrete L2 norm of the final solution, calculated as sqrt(sum(u^2)*dx).
