Solve the partial differential equation u_t = -q1 * ∂_x(cos(u)) + (q2/pi) * u_xx for the unknown field u(x,t).
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 0.5].
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The boundary conditions are periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The solution is to be found numerically.
Use a uniform periodic spatial grid on [0,1) with Nx=1024 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1, with dx=1/Nx.
Discretize the convective term, -q1*∂_x(cos(u)), using a conservative finite-volume method.
The numerical flux between cells j and j+1 is calculated using the Rusanov flux scheme.
The physical flux function is f(u) = q1*cos(u).
The wave speed alpha for the Rusanov flux is a constant value of 1.0.
Discretize the diffusion term, (q2/pi)*u_xx, using a second-order central difference stencil: (u_{j+1} - 2*u_j + u_{j-1}) / dx^2.
Integrate in time using the second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The time step dt is constant throughout the simulation.
First, calculate candidate time steps based on advection (dt_adv) and diffusion (dt_diff).
Set dt_adv = 0.2 * dx / 1.0.
Set dt_diff = 0.2 * dx^2 / (q2/pi).
The preliminary time step is the minimum of dt_adv and dt_diff.
The final number of time steps is Nt = ceil(T/dt), where the final time T is 0.5.
The actual time step used for the simulation is dt = T/Nt.
