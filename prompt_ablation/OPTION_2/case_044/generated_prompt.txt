Run a turbulent buoyant cavity simulation.
The simulation uses the k-epsilon turbulence model.
The geometry is a 2D square cavity with a height of 0.10 meters and a width of 0.10 meters.
The 2D simulation is achieved by using empty patches for the front and back boundaries.
The fluid has a kinematic viscosity of 1.523e-5 m^2/s.
The fluid has a Prandtl number of 0.71.
The fluid has a thermal expansion coefficient of 3.33e-3 1/K.
The fluid has a reference density of 1.0 kg/m^3.
These properties result in a target Rayleigh number of 1.0e6.
Gravitational acceleration is -9.81 m/s^2 in the y-direction.
All walls have a noSlip boundary condition for velocity.
The left vertical wall has a fixed temperature of 303 K.
The right vertical wall has a fixed temperature of 293 K.
The top and bottom horizontal walls have a zeroGradient temperature boundary condition.
