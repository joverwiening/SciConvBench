Create a file named `INCAR` with the following content.
This file will be used for all three geometry optimization steps.
```
EDIFFG = -0.05
ENCUT = 450
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 500
EDIFF = 1E-5
NELM = 100
LREAL = Auto
LWAVE = .FALSE.
LCHARG = .FALSE.
```
Execute the following commands in order in the `data/absorptionE1/Ir` directory.
First, run the geometry optimization for the CO molecule.
`python op.py CO POTCAR-CO POSCAR-CO`
Second, run the geometry optimization for the clean Iridium surface.
`python op.py surface POTCAR-Irface POSCAR-Irface`
Third, run the geometry optimization for the CO-adsorbed Iridium system.
`python op.py absorbed POTCAR-IrCO POSCAR-IrCO`
Finally, calculate the adsorption energy using the results from the previous steps.
`bash ./calc_absorption_energy.sh`
The final output is the numerical value printed to standard output by the `calc_absorption_energy.sh` script.
