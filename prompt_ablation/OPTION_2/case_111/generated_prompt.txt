Solve the Brusselator system of ordinary differential equations numerically.
The system is defined by dx/dt = A + x**2 * y - (B + 1) * x and dy/dt = B * x - x**2 * y.
The independent variable is time t.
The dependent variables are x(t) and y(t).
The simulation time domain is the closed interval [0.0, 20.0].
The parameter A is 1.0.
The parameter B is 3.0.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 1.0.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step dt of 0.01.
Perform a total of 2000 steps, resulting in a final time of 20.0.
Compute the state vector [x(t), y(t)] at every time step from t=0.0 to t=20.0, inclusive.
Save the results to a compressed NumPy file named "solution_molk_010.npz".
The NPZ file must contain a 1D array 't' of time points of length 2001.
The NPZ file must contain a 2D array 'Y' of shape (2001, 2) representing the state variables over time.
The columns of the 'Y' array must be ordered as [x, y].
The NPZ file must also contain the scalar parameters A and B.
Create a line plot showing x(t) versus t and y(t) versus t on the same axes.
Save the plot as a PNG file named "solution_molk_010.png".
Print the final state values x(20.0) and y(20.0) to standard output.
Print the minimum and maximum values attained by x(t) over the entire simulation to standard output.
Print the minimum and maximum values attained by y(t) over the entire simulation to standard output.
