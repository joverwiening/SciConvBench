Create an `INCAR` file in the current directory for the single-point relaxations with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 1, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0.2, SIGMA = 0.2, NSW = 400, LREAL = Auto, LWAVE = .FALSE., and LCHARG = .FALSE.
Execute the command `python op.py IS POTCARagpd IS1POSCAR` to run the initial state relaxation.
Execute the command `python op.py FS POTCARagpd FS1POSCAR` to run the final state relaxation.
Execute the command `python nebmake.py` to generate the intermediate images for the NEB path.
Overwrite the `INCAR` file in the current directory for the Nudged Elastic Band (NEB) calculation with the following parameters: EDIFFG = -0.05, ENCUT = 450, NPAR = 1, IBRION = 3, IMAGES = 4, LCLIMB = .TRUE., IOPT = 7, ISIF = 2, ISMEAR = 1, ISPIN = 1, POTIM = 0, SIGMA = 0.2, SPRING = -5, NSW = 400, LREAL = Auto, LWAVE = .FALSE., and LCHARG = .FALSE.
Execute the command `python op2.py ./` to run the NEB calculation.
After the NEB calculation is complete, execute the command `bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'`.
