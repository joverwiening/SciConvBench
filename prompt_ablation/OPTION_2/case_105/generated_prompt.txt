Solve the ordinary differential equation du/dt = a*t*sin(u) for the unknown field u(t).

The initial condition is u(0.0) = 0.5.
The parameter is a = 0.8.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step of dt = 0.001 for Nt = 5000 steps.
The trigonometric function sin(u) should be evaluated using radians.
Compute the solution u(t) at all time points t_n = n*dt for n=0 to Nt.
Save a file named "solution_molk_004.npz".
The NPZ file must contain a 1D array 't' of length Nt+1 for the time points, a 1D array 'u' of length Nt+1 for the solution, and the scalar parameter 'a'.
Save a line plot of u(t) versus t to a file named "solution_molk_004.png".
