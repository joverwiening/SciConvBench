Solve the partial differential equation u_t = -k*∂_x( 0.5*u^2 ).
The spatial domain is x in [0, 1) with periodic boundaries.
The time domain is t in [0, 0.2].
The parameter k is 1.0.
The boundary condition is periodic, such that u(0,t) = u(1,t).
The initial condition is u(x,0) = sin(2*pi*x).
Use a uniform periodic spatial grid with Nx=1024 points.
The grid points are defined as x_j = j*dx for j=0,...,Nx-1.
The grid spacing is dx = 1/Nx.
Discretize the spatial term using a conservative finite-volume method.
Use the Rusanov (local Lax–Friedrichs) numerical flux to approximate the flux at cell interfaces.
The physical flux is F(u) = k * 0.5 * u^2.
Integrate in time using the SSP-RK2 (Heun) method.
Use a fixed time step dt.
To determine the time step, first calculate a preliminary step dt0 = CFL*dx/max_speed.
Use a CFL number of 0.2.
Estimate the maximum wave speed, max_speed, as 1.0.
Calculate the number of time steps as Nt = ceil(T/dt0), where T=0.2 is the final time.
The final time step is dt = T/Nt.
Compute the solution u(x,T) at the final time T=0.2.
Save the output to a file named "solution_molk_025.npz".
The output file must contain the 1D arrays 'x' and 'u', each of length Nx.
The output file must also contain the scalars T, dx, Nx, and k.
