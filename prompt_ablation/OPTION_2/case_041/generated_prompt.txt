Simulate 2D laminar, incompressible flow past a cylinder to observe the von Kármán vortex street.
The simulation domain is a rectangular channel 2.2m long and 0.41m high.
A cylinder with a diameter of 0.1m is centered at (0.2, 0.2, 0).
The mesh is one cell thick in the z-direction with empty front and back patches.
The cell size on the surface of the cylinder shall be 0.005m.
The far-field cell size shall be 0.02m.
The mesh should have a growth rate of 1.1 from the cylinder to the far-field.
The kinematic viscosity of the fluid is 1e-3 m²/s.
The inlet velocity is a uniform 1 m/s, corresponding to a Reynolds number of 100.
The simulation will be run using the `pimpleFoam` solver.
In `system/controlDict`, set `startTime` to 0 and `endTime` to 200.
Set the initial `deltaT` to 0.005.
Enable `adjustTimeStep` and set `maxCo` to 0.9.
Set `writeControl` to `runTime` and `writeInterval` to 0.1.
In `system/fvSolution`, set `nCorrectors` to 2.
In `system/fvSchemes`, use `backward` for the time discretization scheme (`ddtSchemes`).
Use `Gauss linearUpwindV grad(U)` for the divergence scheme (`div(phi,U)`).
Use `Gauss linear corrected` for the Laplacian schemes.
For the velocity field `U`, apply the following boundary conditions in the `0/` directory.
The `inlet` patch is a `fixedValue` of `uniform (1 0 0)`.
The `outlet` patch is `zeroGradient`.
The `cylinderWall` patch is `noSlip`.
The `topAndBottom` patches are `noSlip`.
The `frontAndBack` patches are `empty`.
For the pressure field `p`, apply the following boundary conditions in the `0/` directory.
The `inlet` patch is `zeroGradient`.
The `outlet` patch is a `fixedValue` of `uniform 0`.
The `cylinderWall` patch is `zeroGradient`.
The `topAndBottom` patches are `zeroGradient`.
The `frontAndBack` patches are `empty`.
