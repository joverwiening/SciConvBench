Numerically solve a system of ordinary differential equations for x(t) and y(t).
The system is the undriven Duffing oscillator.
The first equation is dx/dt = y.
The second equation is dy/dt = -delta*y - alpha*x - beta*x**3.
The time domain is from t=0.0 to t=50.0.
The parameter alpha is 2.
The parameter beta is 0.1.
The parameter delta is 0.2.
The initial condition at t=0.0 is x(0.0) = 1.0.
The initial condition at t=0.0 is y(0.0) = 0.0.
Use the classical 4th-order Runge-Kutta (RK4) method for time integration.
Use a fixed time step, dt, of 0.01.
Perform 5000 time steps, resulting in a final time of 50.0.
Compute the full state vector [x, y] at all time points t_n = 0.0 + n*dt for n=0 to 5000.
Save the results to a compressed NumPy file named "solution_molk_011.npz".
The NPZ file must contain a 1D array 't' of length 5001 holding the time points.
The NPZ file must contain a 2D array 'Y' of shape (5001, 2) holding the state vector at each time point.
The columns of the 'Y' array must be ordered as [x, y].
The NPZ file must also contain the scalar parameters alpha, beta, and delta.
Create a line plot of x versus t and y versus t.
Save the plot as a PNG file named "solution_molk_011.png".
Print the final state values x(50.0) and y(50.0) to standard output.
Print the minimum and maximum values of x(t) and y(t) over the entire time domain to standard output.
