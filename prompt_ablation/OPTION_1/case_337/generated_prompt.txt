Create a file named INCAR with the following content:
```
# Electronic Relaxation
ENCUT  = 450
EDIFF  = 1E-05
ISMEAR = 1
SIGMA  = 0.2
NELM   = 100
LREAL  = Auto

# Ionic Relaxation
IBRION = 1
ISIF   = 2
NSW    = 200
EDIFFG = -0.05
POTIM  = 0.2

# Spin
ISPIN  = 1

# vdW Correction
IVDW   = 11

# Output Control
LWAVE  = .FALSE.
LCHARG = .FALSE.
```
Execute the command `python op.py CO POTCAR-CO POSCAR-CO`.
Execute the command `python op.py surface POTCAR-OsO2face POSCAR-OsO2face`.
Execute the command `python op.py absorbed POTCAR-OsO2CO POSCAR-OsO2CO`.
Execute the command `bash ./calc_absorption_energy.sh`.
The final output is the numerical value printed to standard output by the `calc_absorption_energy.sh` script.
