The partial differential equation is u_t + k * d/dx(0.5 * u^2) = 0.
The spatial domain is the interval [0, 1).
The temporal domain is the interval [0, 0.2].
The parameter k is 1.0.
The initial condition at t=0 is u(x, 0) = sin(2*pi*x).
The spatial boundary conditions are periodic.
The spatial grid is a uniform periodic grid.
The number of grid points Nx is 1024.
The grid spacing dx is 1/Nx.
The grid points are x_j = j*dx for j = 0, 1, ..., Nx-1.
The spatial discretization is a conservative finite-volume method.
The physical flux function is f(u) = 0.5 * u^2.
The numerical flux at the interface j+1/2 is the Rusanov flux.
The Rusanov flux is defined as F(u_L, u_R) = 0.5 * (f(u_L) + f(u_R)) - 0.5 * c * (u_R - u_L).
The states at the interface j+1/2 are u_L = u_j and u_R = u_{j+1}.
The local wave speed c at the interface j+1/2 is max(|u_j|, |u_{j+1}|).
The semi-discretization updates each cell average u_j according to du_j/dt = -k * (F_{j+1/2} - F_{j-1/2}) / dx.
The time integration scheme is the second-order Strong Stability Preserving Runge-Kutta method (SSP-RK2).
The final time T is 0.2.
The Courant-Friedrichs-Lewy number is 0.2.
A preliminary time step dt0 is calculated as CFL * dx / max|u(x,0)|.
The maximum of the initial velocity magnitude, max|u(x,0)|, is estimated as 1.0 for this calculation.
The number of time steps Nt is ceil(T / dt0).
The time step dt is T / Nt.
The simulation runs from t=0 to t=T.
