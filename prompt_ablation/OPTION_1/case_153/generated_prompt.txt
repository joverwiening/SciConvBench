The governing equation is u_t + d/dx(0.5 * u^2) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 1.0].
The final simulation time T is 1.0.
The viscosity nu is 4.0.
The initial condition is u(x, 0) = sin(2 * pi * x).
The spatial grid is a uniform periodic grid with Nx = 512 points.
The grid spacing is dx = 1.0 / Nx.
The grid points are x_j = j * dx for j = 0, ..., Nx-1.
The time step dt is determined by a CFL condition.
The CFL number is 0.4.
The characteristic speed for the CFL calculation is 1.0.
An initial time step is calculated as dt0 = (CFL * dx) / 1.0.
The number of time steps is Nt = ceil(T / dt0).
The final time step is dt = T / Nt.
The time integration uses Strang splitting.
Each time step dt consists of a half-step of diffusion, a full-step of advection, and a second half-step of diffusion.
The diffusion equation u_t = nu * u_xx is solved for a duration of dt/2 using a spectral method in Fourier space.
The Fourier space update for a diffusion step of duration tau is u_hat(k) <- u_hat(k) * exp(-nu * k^2 * tau).
The wavenumbers are k = 2 * pi * fftfreq(Nx, d=dx).
The advection equation u_t + d/dx(0.5 * u^2) = 0 is solved for a duration of dt using a finite volume method.
The finite volume method uses the Rusanov (local Lax-Friedrichs) flux.
The flux F at the interface between cells with values u_L and u_R is F = 0.5 * (f(u_L) + f(u_R)) - 0.5 * alpha * (u_R - u_L), where f(u) = 0.5 * u^2.
The local wave speed is alpha = max(|u_L|, |u_R|).
The cell update formula is u_new[j] = u[j] - (dt/dx) * (F_plus - F_minus), where F_plus is the flux at the right interface and F_minus is the flux at the left interface.
