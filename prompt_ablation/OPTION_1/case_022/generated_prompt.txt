The task is to calculate the lattice parameter of a metal.
The crystal structure is Face-Centered Cubic (FCC).
The number of atoms per unit cell (n) for an FCC structure is 4.
The atomic weight (A) is 85.15 g/mol.
The theoretical density (ρ) is 13.931 g/cm^3.
Avogadro's number (N_A) is 6.022×10^23 atoms/mol.
Use the formula a = [(n * A) / (ρ * N_A)]^(1/3) to find the lattice parameter 'a'.
Calculate the value of 'a' in centimeters.
Convert the final result for 'a' from centimeters to nanometers.
The final result must be expressed in nanometers.
