The partial differential equation to be solved is the Kuramoto-Sivashinsky equation: u_t + u*u_x + u_xx + u_xxxx = 0.
The spatial domain is x in [0, 2*pi) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The initial condition at t=0 is u(x,0) = cos(x) + 0.1*cos(2*x).
The spatial domain is discretized using Nx=1024 grid points.
The time step is dt = 1e-4.
The simulation runs for 10000 time steps to reach the final time T=1.0.
Spatial derivatives are computed using a Fourier pseudo-spectral method.
Time integration is performed using a semi-implicit scheme in Fourier space.
