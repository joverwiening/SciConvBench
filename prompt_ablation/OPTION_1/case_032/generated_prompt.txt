The simulation is performed using the FEniCS legacy library (dolfin).
The problem is a 2D static linear elasticity analysis under the plane stress assumption.
The domain is a right triangle defined by the vertices (0, 0), (1, 0), and (0, 0.5).
A triangular mesh is generated for the domain with a resolution resulting in approximately 64 elements.
The material has a Young's modulus of 70e9 Pa and a Poisson's ratio of 0.33.
The material has a density of 2700 kg/m^3.
A gravitational body force acts in the negative y-direction, with g = 9.81 m/s^2.
The vector function space for displacement is defined using continuous Lagrange elements of the second degree.
A Dirichlet boundary condition clamps the sloping edge defined by the line x + 2y = 1, setting displacement to (0, 0).
A Neumann boundary condition applies a normal traction vector of (4000, 0) Pa on the vertical edge at x = 0.
The horizontal edge at y = 0 is a free surface with a zero-traction Neumann boundary condition.
The linear variational problem is formulated for the displacement field.
The resulting linear system is solved using a direct solver.
The displacement field is computed and stored.
The in-plane Cauchy stress tensor is computed from the displacement field.
The von Mises stress is computed from the Cauchy stress tensor.
