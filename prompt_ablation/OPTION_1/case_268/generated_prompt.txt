Retrieve the primitive crystallographic structure for Na3Bi with space group P6_3/mmc.
Perform a variable-cell relaxation calculation followed by a self-consistent field calculation.
Use the LDA exchange-correlation functional.
Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/na.upf for Na.
Use the pseudopotential file PseudoDojo/SR_v0.4.1/LDA_standard/bi.upf for Bi.
Include spin-orbit coupling in the calculation.
Set the kinetic energy cutoff for wavefunctions (ecutwfc) to 80 Rydberg.
Set the kinetic energy cutoff for charge density (ecutrho) to 320 Rydberg.
Use a 10x10x6 Monkhorst-Pack k-point grid.
The k-point grid is gamma-centered.
The k-point grid uses a half shift.
Use Marzari-Vanderbilt smearing for occupations.
Set the smearing width (degauss) to 0.01 Rydberg.
Set the total energy convergence threshold (etot_conv_thr) to 1.0e-8 Rydberg.
Set the force convergence threshold (forc_conv_thr) to 1.0e-7 Rydberg/Bohr.
Set the self-consistency convergence threshold (conv_thr) to 1.0e-8 Rydberg.
The final outputs are the fully relaxed structure and the total energy from the final self-consistent field calculation.
