The PDE to be solved is u_t + ∂_x(0.5*u^2) = nu * u_xx.
The spatial domain is x in [0, 1) with periodic boundary conditions.
The temporal domain is t in [0, 1.0].
The viscosity parameter nu is 1.0.
The initial condition is u(x,0) = sin(2*pi*x).
The spatial domain is discretized with a uniform grid of Nx = 512 points.
The grid spacing dx is 1.0 / Nx.
The grid points are x_j = j*dx for j from 0 to Nx-1.
The total simulation time T is 1.0.
An initial time step dt0 is calculated as 0.4 * dx / 1.0.
The number of time steps Nt is the ceiling of T / dt0.
The final time step dt is T / Nt, ensuring the simulation ends exactly at T.
The time integration scheme is Strang splitting.
Each full time step is composed of a half-step of diffusion, a full-step of advection, and a final half-step of diffusion.
The diffusion step of duration dt_sub is solved in Fourier space.
The solution u is transformed using a forward Fast Fourier Transform (FFT).
The FFT and its inverse use a standard library convention with a 1/N normalization factor on the inverse transform.
The wave numbers are k = 2*pi*fftfreq(Nx, d=dx).
Each Fourier coefficient u_hat(k) is multiplied by exp(-nu*k^2*dt_sub).
The solution is transformed back to physical space using an inverse FFT, and the real part is taken.
The advection step solves u_t + ∂_x(0.5*u^2) = 0 for a duration dt using a finite volume method.
The numerical flux between cells is the Rusanov flux.
The Rusanov flux between u_left and u_right is 0.5*(f(u_left) + f(u_right)) - 0.5*alpha*(u_right - u_left), where f(u)=0.5*u^2.
The local wave speed alpha is max(abs(u_left), abs(u_right)).
The solution in each cell j is updated using u_new[j] = u[j] - (dt/dx)*(F_plus - F_minus).
The final solution u(x,T) is computed after Nt full time steps.
An NPZ file named "solution_pdebench_burgers_nu1.npz" is saved.
The NPZ file contains the arrays x and u, and the scalars nu, T, dx, dt, Nx, Nt.
A PNG file named "solution_pdebench_burgers_nu1.png" is saved.
The PNG file is a line plot of the final solution u versus x.
The plot title is "Solution of 1D Viscous Burgers' Equation at T=1.0".
The x-axis is labeled "x".
The y-axis is labeled "u(x, T=1.0)".
