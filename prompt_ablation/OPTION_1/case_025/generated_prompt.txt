The simulation is performed using the FEniCS legacy library, dolfin.
The problem is a 2D small-strain linear elasticity analysis under a plane stress assumption.
The domain is a 2D polygon defined by 8 vertices with coordinates in meters: (0.0, 0.0), (1.0, 0.0), (1.0, 0.2), (0.8, 0.2), (0.8, 0.5), (0.2, 0.5), (0.2, 0.2), (0.0, 0.2).
The domain is meshed with approximately 72 triangular elements.
The vector-valued displacement function space is defined using continuous Lagrange elements of polynomial degree 2.
The material's Young's modulus is 70e9 Pa.
The material's Poisson's ratio is 0.33.
The material's density is 2700 kg/m^3.
A body force representing gravity acts in the negative y-direction, with g = 9.81 m/s^2.
A vertical traction of -10e3 Pa is applied to the full top boundary, defined by y = 0.5.
The bottom boundary, defined by y = 0, is fixed with a zero-displacement Dirichlet condition.
The linear variational problem is solved using a direct solver with LU decomposition.
The displacement magnitude is computed from the solution vector.
The in-plane Cauchy stress tensor is computed from the displacement solution.
The von Mises stress is computed from the Cauchy stress tensor.
The displacement magnitude and von Mises stress fields are saved to files for visualization.
