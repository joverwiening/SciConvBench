Create a file named `INCAR.relax` with the following content:
SYSTEM = AgPd_Relax
PREC = Normal
EDIFFG = -0.05
ENCUT = 450
NPAR = 1
IBRION = 1
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0.2
SIGMA = 0.2
NSW = 400
LWAVE = .FALSE.
LCHARG = .FALSE.

Copy the file `INCAR.relax` to `INCAR`.
Execute the command: `python op.py IS POTCARagpd IS1POSCAR`
Copy the file `INCAR.relax` to `INCAR`.
Execute the command: `python op.py FS POTCARagpd FS1POSCAR`
Execute the command: `python nebmake.py`
Create a file named `INCAR.neb` with the following content:
SYSTEM = AgPd_NEB
PREC = Normal
EDIFFG = -0.05
ENCUT = 450
NPAR = 1
IBRION = 3
IMAGES = 4
LCLIMB = .TRUE.
IOPT = 7
ISIF = 2
ISMEAR = 1
ISPIN = 1
POTIM = 0
SIGMA = 0.2
SPRING = -5
NSW = 400
LWAVE = .FALSE.
LCHARG = .FALSE.

Copy the file `INCAR.neb` to `INCAR`.
Execute the command: `python op2.py ./`
Execute the command: `bash -c 'cp IS/OUTCAR 00/ && cp FS/OUTCAR 05/ && perl nebef.pl'`
The final output is the numerical value for the energy barrier reported by the last command.
