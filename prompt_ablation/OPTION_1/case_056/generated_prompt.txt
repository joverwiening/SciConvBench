Create a file named `membrane3.inp` in the working directory.
The content of `membrane3.inp` must be the exact text provided in the user's reference input deck.
Execute the command `ccx -v` and store its complete standard output as the `ccx_version_string`.
Execute the command `ccx -i membrane3` to run the analysis.
Capture all standard output and standard error generated by the `ccx -i membrane3` command.
After the command completes, check if the file `membrane3.sta` contains the exact string 'JOB COMPLETED'.
If the string 'JOB COMPLETED' is found in `membrane3.sta`, the run status is "success".
If the string 'JOB COMPLETED' is not found in `membrane3.sta`, the run status is "error".
Create a file named `results.json` in the working directory.
The `results.json` file contains a single JSON object with six keys: `solver`, `case_id`, `status`, `ccx_version`, `artifacts`, and `notes`.
The value for the `solver` key is the string "calculix".
The value for the `case_id` key is the string "membrane3".
The value for the `status` key is the run status determined in the previous steps.
The value for the `ccx_version` key is the `ccx_version_string`.
The value for the `artifacts` key is an empty list.
If the run status is "success", the value for the `notes` key is the string "ccx -i membrane3".
If the run status is "error", the value for the `notes` key is a single string containing the command "ccx -i membrane3", followed by the captured standard output and standard error.
