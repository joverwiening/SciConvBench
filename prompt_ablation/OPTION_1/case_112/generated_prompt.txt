The task is to solve a system of ordinary differential equations.
The system of equations is dx/dt = y.
The system of equations is dy/dt = -delta*y - alpha*x - beta*x**3.
The independent variable is t, representing time.
The dependent variables are x(t) and y(t).
The time domain for the simulation is the closed interval [0.0, 50.0].
The parameter alpha is 2.
The parameter beta is 0.1.
The parameter delta is 0.2.
The initial condition for x at t=0.0 is 1.0.
The initial condition for y at t=0.0 is 0.0.
The numerical integration method is the classical 4th-order Runge-Kutta scheme.
The time step, dt, is fixed at 0.01.
The number of time steps, Nt, is 5000.
The state vector, consisting of x and y, must be computed at every time step from t=0 to t=50.0.
The results must be saved to a compressed NumPy file named "solution_molk_011.npz".
The NPZ file must contain a 1D array named 't' of length Nt+1, storing the time points.
The NPZ file must contain a 2D array named 'Y' of shape [Nt+1, 2], storing the state vectors.
The columns of the 'Y' array must be ordered as [x, y].
The NPZ file must also store the scalar parameters alpha, beta, and delta.
A plot must be saved as "solution_molk_011.png".
The plot will contain two line graphs on the same axes: x versus t and y versus t.
The final state values, x(50.0) and y(50.0), must be printed to the console.
The minimum and maximum values of x(t) over the entire simulation must be printed to the console.
The minimum and maximum values of y(t) over the entire simulation must be printed to the console.
