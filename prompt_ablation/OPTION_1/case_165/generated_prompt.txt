The PDE to be solved is the 1D compressible Navier-Stokes system in conservative form.
The conserved variables are density (rho), momentum (m), and total energy (E).
The governing equations are rho_t + (m)_x = 0, m_t + (m^2/rho + p - sigma)_x = 0, and E_t + ((E+p)*v - v*sigma)_x = 0.
The pressure p is defined by the ideal gas equation of state E = p/(Gamma-1) + 0.5*rho*v^2.
The viscous stress is sigma = (zeta + 4/3*eta) * v_x.
The ratio of specific heats is Gamma = 1.6666666666666667.
The dynamic viscosity is eta = 1e-08.
The bulk viscosity is zeta = 1e-08.
The spatial domain is x in [-1, 1].
The simulation time interval is t in [0, 0.2].
A uniform cell-centered finite volume grid with 800 cells is used.
The cell width is dx = 2.0 / 800.
The center of cell j is located at x_j = -1.0 + (j + 0.5) * dx for j = 0, ..., 799.
The initial condition is a Riemann problem with a discontinuity at x=0.
For cell centers with x < 0, the initial state is rho = 0.445, v = 0.698, p = 3.528.
For cell centers with x >= 0, the initial state is rho = 0.5, v = 0.0, p = 0.571.
Transmissive (zero-gradient) boundary conditions are applied at x=-1 and x=1.
Two ghost cells are used on each side of the domain.
The values of the conserved variables in the ghost cells are set equal to the values in the nearest interior cell.
The system is advanced in time using the 2-stage Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The convective flux is approximated using the Rusanov numerical flux.
The velocity gradient v_x is computed at each cell center using a centered difference.
The viscous stress sigma is computed at each cell center using the cell-centered v_x.
The viscous stress at a cell interface is the average of the sigma values from the two adjacent cell centers.
The time step dt is calculated at each stage using a Courant-Friedrichs-Lewy (CFL) number of 0.5.
The simulation runs until the final time T=0.2.
A file named "solution_pdebench_cns1d_sod6_eta1em8_outflow.npz" is saved.
The NPZ file contains the 1D arrays 'x', 'rho', 'v', 'p' at the final time.
The NPZ file also contains the scalars 'Gamma', 'eta', 'zeta', 'T', 'dx', 'CFL'.
A plot named "solution_pdebench_cns1d_sod6_eta1em8_outflow.png" is saved, showing rho, v, and p versus x at the final time.
The minimum and maximum values of rho and p at the final time are printed to the console.
The mean value of rho over the domain at the final time is printed to the console.
