The partial differential equation to solve is u_t = nu * u_xx + rho * u * (1 - u).
The spatial domain is x in [0, 1) with periodic boundaries.
The temporal domain is t in [0, 1.0].
The diffusion coefficient nu is 2.0.
The reaction coefficient rho is 10.0.
The initial condition at t=0 is u(x,0) = 0.25 + 0.1 * sin(2 * pi * x).
Define a uniform spatial grid with Nx = 512 points.
The grid points are x_j = j * dx for j = 0, ..., Nx-1.
The spatial step size is dx = 1.0 / Nx.
Define a uniform temporal grid with a time step dt = 0.001.
The number of time steps is Nt = 1000.
The final time is T = 1.0.
The numerical method is Strang splitting.
Each time step from t to t+dt consists of three sequential operations.
First, advance the diffusion term u_t = nu * u_xx for a duration of dt/2.
This diffusion half-step is solved exactly in Fourier space.
The Fourier space update for each wavenumber k is u_hat(k) <- u_hat(k) * exp(-nu * k^2 * (dt/2)).
The wavenumbers are k = 2 * pi * fftfreq(Nx, d=dx).
Second, advance the reaction term u_t = rho * u * (1 - u) for a duration of dt.
This reaction step is solved exactly for each grid point.
The pointwise update for the reaction step is u <- (u * exp(rho * dt)) / (1 + u * (exp(rho * dt) - 1)).
Third, advance the diffusion term u_t = nu * u_xx for a second duration of dt/2 using the same Fourier space method as the first step.
