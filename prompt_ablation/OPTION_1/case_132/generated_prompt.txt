The partial differential equation to be solved is u_t = -q1*∂_x(cos(u)) + (q2/pi)*u_xx.
The parameter q1 is 1.0.
The parameter q2 is 0.05.
The spatial domain is the interval [0, 1).
The temporal domain is the interval [0, 0.5].
The boundary conditions are periodic.
The initial condition is u(x,0) = 0.5*sin(2*pi*x).
The spatial domain is discretized using a uniform periodic grid with Nx=1024 points.
The grid spacing is dx = 1/Nx.
The grid points are x_j = j*dx for j=0, ..., Nx-1.
The time step dt is constant for the entire simulation.
An advective time step constraint is calculated as dt_adv = 0.2 * dx / 1.0.
A diffusive time step constraint is calculated as dt_diff = 0.2 * dx**2 / (q2/pi).
A preliminary time step is set to the minimum of dt_adv and dt_diff.
The number of time steps is Nt = ceil(0.5 / preliminary_dt).
The final time step is dt = 0.5 / Nt.
The PDE is advanced in time using the second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The spatial operator is a sum of discretizations for the convective and diffusive terms.
The diffusive term u_xx is discretized using a second-order central difference stencil.
The convective term -∂_x(cos(u)) is discretized using a conservative finite-volume method.
The numerical flux at the interface between cell j and j+1 is the Rusanov flux.
The Rusanov flux is F_{j+1/2} = 0.5*(cos(u_j) + cos(u_{j+1})) - 0.5*alpha*(u_{j+1} - u_j).
The wave speed alpha is recomputed at each stage of the SSP-RK2 integrator.
The value of alpha for a given stage is the maximum of |sin(u)| over all grid points for the solution u at that stage.
