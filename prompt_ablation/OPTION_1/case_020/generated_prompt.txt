The simulation will be performed using the FEniCS legacy library (dolfin).
The simulation domain is a 2D rectangle spanning from (0, 0) to (1.0, 0.20).
A uniform structured mesh of 40 by 8 cells will be generated for the domain.
The mesh elements will be triangles.
The governing equations are for 2D small-strain linear elasticity under the plane stress assumption.
The material's Young's modulus is 200 GPa.
The material's Poisson's ratio is 0.3.
The vector-valued displacement function space will be discretized using continuous Lagrange elements of polynomial degree 2.
A Dirichlet boundary condition will be applied to the left edge (x=0), fixing the displacement vector to (0, 0).
A Neumann boundary condition will be applied to the top edge (y=0.20), representing a uniform traction vector of (0, -2000).
The right edge (x=1.0) and the bottom edge (y=0) are traction-free.
The linear system will be solved using a direct solver.
The y-component of the resulting displacement field will be saved as a color plot to the file `q2_uy.png`.
The complete displacement vector field will be saved in XDMF format to the file `q2_displacement.xdmf`.
