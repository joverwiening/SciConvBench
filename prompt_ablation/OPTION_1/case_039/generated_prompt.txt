The simulation environment is FEniCS legacy (dolfin).
The analysis type is 2D plane stress linear elasticity.
The domain is a rectangle defined by corners (0, 0) and (1.0, 0.5).
A circular hole with a radius of 0.1 is removed from the domain.
The center of the circular hole is at (0.5, 0.25).
An unstructured 2D triangular mesh is generated for the domain.
The characteristic mesh element size is approximately 0.015625.
The function space for the displacement vector is the space of continuous Galerkin, vector-valued, second-degree Lagrange polynomials.
The Young's modulus is 70e9 Pa.
The Poisson's ratio is 0.33.
The material density is 2700 kg/m^3.
The plane stress constitutive relation is used.
A body force vector f = (0, -26487) N/m^3 is applied to the domain, using g=9.81 m/s^2.
A uniform traction vector T = (0, -2500) N/m^2 is applied to the top boundary at y=0.5.
A uniform traction vector T = (0, 2500) N/m^2 is applied to the bottom boundary at y=0.0.
The circular hole boundary is traction-free.
A Dirichlet boundary condition restricts vertical displacement to zero on the left boundary at x=0.
A Dirichlet boundary condition restricts horizontal displacement to zero on the right boundary at x=1.
The linear variational problem is solved using a direct solver.
The von Mises stress is computed from the resulting in-plane Cauchy stress tensor.
