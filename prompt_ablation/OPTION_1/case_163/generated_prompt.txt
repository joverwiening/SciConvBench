The system of equations to be solved is the 1D compressible Navier-Stokes equations in conservative form.
The conservative state vector is U = [rho, m, E].
rho is the density.
m is the momentum density, defined as m = rho * v.
v is the velocity.
E is the total energy density.
p is the pressure.
The total energy density is related to pressure by E = p / (Gamma - 1) + 0.5 * rho * v^2.
The viscous stress is sigma = (zeta + 4/3 * eta) * d(v)/dx.
The governing equations are:
d(rho)/dt + d(m)/dx = 0.
d(m)/dt + d(m^2/rho + p - sigma)/dx = 0.
d(E)/dt + d((E + p) * v - v * sigma)/dx = 0.
The spatial domain is x from -1 to 1.
The temporal domain is t from 0 to 0.2.
The ratio of specific heats Gamma is 1.6666666666666667.
The dynamic viscosity eta is 1e-08.
The bulk viscosity zeta is 1e-08.
The initial condition is a Riemann problem with a discontinuity at x = 0.
For x < 0, the initial density rho is 1.0.
For x < 0, the initial velocity v is -0.75.
For x < 0, the initial pressure p is 1.0.
For x >= 0, the initial density rho is 0.125.
For x >= 0, the initial velocity v is 0.0.
For x >= 0, the initial pressure p is 0.1.
Transmissive (outflow) boundary conditions are applied at x = -1.
Transmissive (outflow) boundary conditions are applied at x = 1.
A uniform finite-volume grid with 800 cells is used.
The cell width, dx, is 0.0025.
Cell centers are located at x_j = -1 + (j + 0.5) * dx for j = 0 to 799.
The conservative variables rho, m, and E are evolved as cell averages.
The pressure is calculated from the conservative variables using the equation of state p = (Gamma - 1) * (E - 0.5 * m^2 / rho).
If rho or p become non-positive during the simulation, they are clipped to a floor value of 1e-12.
The total numerical flux at cell interfaces is the sum of a convective flux and a viscous flux.
The convective flux is computed using the Rusanov (local Lax-Friedrichs) scheme.
The physical convective flux vector is F_conv(U) = [m, m^2/rho + p, (E+p)*v].
The interface wave speed for the Rusanov flux is a = max(|v_L| + c_L, |v_R| + c_R), where c = sqrt(Gamma*p/rho).
The Rusanov numerical flux is F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L).
The velocity gradient d(v)/dx at cell centers is computed using a second-order centered difference on the cell-centered velocity values.
The viscous stress sigma is computed at cell centers.
The viscous stress at cell interfaces is computed by averaging the values from the two adjacent cell centers.
The velocity at cell interfaces is computed by averaging the values from the two adjacent cell centers.
The numerical viscous flux at an interface is calculated using the interface-averaged v and sigma in the expression F_visc = [0, -sigma, -v*sigma].
The total numerical flux at an interface is F_total = F_hat + F_visc.
The semi-discrete system is integrated in time using the two-stage, second-order Strong Stability Preserving Runge-Kutta (SSP-RK2) method.
The Courant-Friedrichs-Lewy (CFL) number is 0.5.
The convective time step limit is dt_conv = CFL * dx / max_j(|v_j| + c_j).
The viscous time step limit is dt_visc = 0.5 * dx^2 / max(zeta + 4/3 * eta, 1e-30).
The time step used is dt = min(dt_conv, dt_visc).
The final time step is adjusted to ensure the simulation stops exactly at T = 0.2.
One ghost cell is used on each side of the domain.
For the outflow boundary conditions, the values in the ghost cells are set equal to the values in the nearest interior cell.
The simulation will compute the primitive variables rho(x,t), v(x,t), and p(x,t) at the final time T = 0.2.
The results will be saved to a file named "solution_pdebench_cns1d_sod4_eta1em8_outflow.npz".
The NPZ file will contain the 1D array of cell center coordinates 'x'.
The NPZ file will contain the 1D array of final density 'rho'.
The NPZ file will contain the 1D array of final velocity 'v'.
The NPZ file will contain the 1D array of final pressure 'p'.
The NPZ file will contain the scalar value of Gamma.
The NPZ file will contain the scalar value of eta.
The NPZ file will contain the scalar value of zeta.
The NPZ file will contain the final time T.
The NPZ file will contain the cell width dx.
The NPZ file will contain the CFL number.
A three-panel plot of the final density, velocity, and pressure versus x will be saved as "solution_pdebench_cns1d_sod4_eta1em8_outflow.png".
The minimum and maximum values of the final density rho will be printed to the console.
The minimum and maximum values of the final pressure p will be printed to the console.
The mean value of the final density rho over the spatial domain will be printed to the console.
