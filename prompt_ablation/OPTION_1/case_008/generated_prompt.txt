The simulation environment is FEniCS legacy (dolfin).
The problem to be solved is 2D small-strain orthotropic elasticity under plane stress conditions.
The computational domain is a rectangle defined by x in [0, 1.0] and y in [0, 0.2].
The domain is meshed with a 50 by 25 structured grid of triangular elements.
A vector function space of continuous Lagrange elements of degree 1 is used for the displacement field.
The material is orthotropic with the following properties in its local coordinate system.
The Young's modulus along the first principal axis E1 is 40 GPa.
The Young's modulus along the second principal axis E2 is 10 GPa.
The in-plane shear modulus G12 is 5 GPa.
The major Poisson's ratio nu12 is 0.25.
The minor Poisson's ratio nu21 is calculated as 0.0625.
The local material axes are rotated 30 degrees counter-clockwise with respect to the global Cartesian axes.
The plane stress stiffness matrix is first constructed in the local material frame and then rotated to the global frame.
The bottom boundary (y=0) is fixed, with displacement components u_x and u_y set to zero.
A uniform traction vector of (0, -10e6) N/m is applied to the top boundary (y=0.2).
The vertical boundaries (x=0 and x=1) are traction-free.
The linear variational problem is solved for the displacement field.
A direct solver is used to solve the resulting linear system of equations.
The x-component of the displacement field is saved as a PNG image named q8_ux.png.
The von Mises stress field is computed and saved as a PNG image named q8_vm.png.
The displacement and stress fields are written to an XDMF file named q8_solution.xdmf.
