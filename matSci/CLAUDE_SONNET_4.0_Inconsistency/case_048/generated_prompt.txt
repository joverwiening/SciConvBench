Calculate the phase fractions for a binary A-B alloy system using the lever rule.
The alloy has an overall composition of C_0 = 10 wt% B.
At the analysis temperature, the α phase has composition C_α = 25 wt% B.
At the analysis temperature, the β phase has composition C_β = 70 wt% B.
The temperature is within the α+β two-phase field where these tie line compositions are valid.
Use the lever rule formula: fraction of β phase = (C_0 - C_α)/(C_β - C_α).
Use the lever rule formula: fraction of α phase = (C_β - C_0)/(C_β - C_α).
Calculate both phase fractions and express as percentages.
Verify that the sum of phase fractions equals 100%.
