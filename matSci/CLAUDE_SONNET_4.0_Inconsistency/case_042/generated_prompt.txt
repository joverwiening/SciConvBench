Calculate the diffusion flux J using Fick's first law: J = -D(dC/dx).
Use the given diffusion coefficient D = 3.0×10^-11 m²/s.
Use the concentration gradient from C₁ = 0.12 mol/m³ at x = 0 to C₂ = 0.02 mol/m³ at x = L.
Use L = 0.001 m for the membrane thickness.
Calculate the concentration gradient as dC/dx = (C₂ - C₁)/(L - 0) = (0.02 - 0.12)/(0.001 - 0) = -100 mol/m⁴.
Substitute into Fick's law: J = -D(dC/dx) = -(3.0×10^-11)(-100) = 3.0×10^-9 mol/(m²·s).
The positive result confirms the flux is in the +x direction, which contradicts the stated -x direction.
