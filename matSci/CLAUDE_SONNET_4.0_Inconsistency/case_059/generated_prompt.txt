Calculate the rupture life using the Larson-Miller parameter equation P = T(C + log10 t_r).
Use T = 973 K (corresponding to 700°C).
Use C = 20.
Use P = 23,500.
Solve for t_r in hours by rearranging the equation to: log10 t_r = (P/T) - C.
Substitute the values: log10 t_r = (23,500/973) - 20.
Calculate the result and convert from log10 to get t_r in hours.
