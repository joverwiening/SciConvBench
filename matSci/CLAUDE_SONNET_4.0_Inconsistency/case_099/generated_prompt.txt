The correct electron count for the reaction FePO₄ + Li⁺ + e⁻ → LiFePO₄ is n = 1 electron per formula unit.
The iron oxidation state changes from +3 in FePO₄ to +2 in LiFePO₄, which is a one-electron reduction.
The balanced equation shows that exactly one electron is required per formula unit of FePO₄.
Using n = 2 electrons per formula unit in theoretical specific capacity calculations is incorrect for this reaction.
