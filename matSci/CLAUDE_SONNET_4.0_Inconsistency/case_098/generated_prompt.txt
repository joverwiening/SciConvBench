The statement contains an error in the definition of a Frenkel defect.
A Frenkel defect consists of a cation vacancy paired with the same cation occupying an interstitial site.
The described defect pair of one cation vacancy and one anion vacancy is called a Schottky defect.
Assume a typical ionic crystal with moderate size ratio between cation and anion where both defect types can occur.
The correct identification is that the given description matches a Schottky defect, not a Frenkel defect.
