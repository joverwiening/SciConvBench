Calculate the degree of crystallinity using the formula χc = (ρ - ρa)/(ρc - ρa).
Use the measured density ρ = 1.42 g/cm³.
Use the amorphous density ρa = 1.05 g/cm³.
Use the crystalline density ρc = 1.30 g/cm³.
Substitute the values into the formula: χc = (1.42 - 1.05)/(1.30 - 1.05).
Calculate the numerator: 1.42 - 1.05 = 0.37 g/cm³.
Calculate the denominator: 1.30 - 1.05 = 0.25 g/cm³.
Divide to get the degree of crystallinity: χc = 0.37/0.25 = 1.48.
Convert to percentage by multiplying by 100: 1.48 × 100 = 148%.
Note that this result exceeds 100%, which indicates an error in the given density values since the measured density cannot be higher than the crystalline density in this model.
