Calculate the first-order Bragg diffraction angle for X-rays with wavelength 0.30 nm incident on crystal planes with spacing 0.12 nm.
Use Bragg's law: nλ = 2d sin θ, where n = 1 for first-order diffraction.
Substitute the given values: λ = 0.30 nm, d = 0.12 nm, n = 1.
Solve for the Bragg angle θ: sin θ = nλ/(2d) = (1)(0.30)/(2)(0.12) = 1.25.
Since sin θ cannot exceed 1, conclude that first-order Bragg reflection is not possible for these parameters.
