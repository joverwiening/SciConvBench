Calculate the transverse modulus E_T for a composite material using the rule of mixtures formula E_T = V_f E_f + V_m E_m.
Use a carbon fiber-epoxy composite system as the standard assumption.
Set the fiber volume fraction V_f = 0.6 (60%).
Set the matrix volume fraction V_m = 0.4 (40%).
Use carbon fiber transverse modulus E_f = 15 GPa.
Use epoxy matrix modulus E_m = 3.5 GPa.
Verify that V_f + V_m = 1.0.
Substitute the values into the formula E_T = V_f E_f + V_m E_m.
Calculate E_T = (0.6)(15) + (0.4)(3.5) = 9.0 + 1.4 = 10.4 GPa.
Report the final result as E_T = 10.4 GPa.
Note that this represents the transverse modulus using the rule of mixtures approximation for a unidirectional carbon fiber-epoxy composite.
