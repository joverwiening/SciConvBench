Calculate the steady‑state heat‑transfer rate through the composite wall as follows.

1. Convert the layer thicknesses to metres:  
   L₁ = 9.74 mm = 0.00974 m, L₂ = 13.27 mm = 0.01327 m.

2. Compute the thermal resistance of each layer using R = L / (k A):  
   R₁ = 0.00974 / (12.31 × 0.0725) = 0.01091 K / W,  
   R₂ = 0.01327 / (107.49 × 0.0725) = 0.001702 K / W.

3. Sum the resistances for series conduction:  
   R_total = R₁ + R₂ = 0.01091 + 0.001702 = 0.012612 K / W.

4. Determine the temperature difference between the outer surfaces:  
   ΔT = 198.1 °C – (‑25.4 °C) = 223.5 K.

5. Compute the heat‑transfer rate:  
   Q = ΔT / R_total = 223.5 / 0.012612 = 1.77 × 10⁴ W (≈ 17 730 W).
