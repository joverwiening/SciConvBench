Use the cubic interplanar spacing formula d_hkl = a / √(h² + k² + l²).  
For the (100) planes, √(1²+0²+0²) = 1, so a simple cubic lattice would give d_(100) = a = 0.360 nm.  
The reported spacing is d_(100) = 0.180 nm, which is exactly a/2.  
In a face‑centered cubic (FCC) lattice, the (100) planes are spaced by a/2 because lattice points exist on each face, halving the plane separation compared with a simple cubic cell.  
Since the measured d matches a/2, the crystal is consistent with an FCC structure rather than a simple cubic one.
