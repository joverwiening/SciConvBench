Calculate the interplanar spacing for the (111) planes using d = a / √(h² + k² + l²) = 0.5313 nm / √3 ≈ 0.3067 nm.  
Apply Bragg’s law with n = 2: 2 λ = 2 d sinθ, where λ = 0.0762 nm.  
Solve for sinθ: sinθ = (2 λ) / (2 d) = (0.1524 nm) / (0.6134 nm) ≈ 0.2486.  
Find θ: θ = arcsin(0.2486) ≈ 14.4°.  
The diffraction angle is 2θ = 2 × 14.4° ≈ 28.8°.
