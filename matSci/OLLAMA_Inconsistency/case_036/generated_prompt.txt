Use the Cu Kα wavelength λ = 1.5406 Å.  
Convert the measured 2θ value to θ: θ = 43.5° / 2 = 21.75°.  
Apply Bragg’s law for first‑order diffraction (n = 1): λ = 2 d sin θ.  
For the (100) reflection of an FCC lattice, the interplanar spacing d₁₀₀ equals the lattice parameter a.  
Solve for a: a = λ / (2 sin θ).  
Calculate sin θ = sin(21.75°) ≈ 0.371.  
Compute a = 1.5406 Å / (2 × 0.371) ≈ 2.08 Å.  
Report the lattice parameter as a ≈ 2.08 Å.
