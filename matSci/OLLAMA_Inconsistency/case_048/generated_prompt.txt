Use the lever rule with Cα = 25 wt% B, Cβ = 70 wt% B, and alloy composition C₀ = 40 wt% B.  
Calculate the α‑phase fraction as (Cβ − C₀) / (Cβ − Cα) = (70 − 40) / (70 − 25) = 30 / 45 = 0.667 (≈66.7 %).  
Calculate the β‑phase fraction as (C₀ − Cα) / (Cβ − Cα) = (40 − 25) / (70 − 25) = 15 / 45 = 0.333 (≈33.3 %).
