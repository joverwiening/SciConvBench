Use the semi-infinite, constant-surface-concentration diffusion model for carburizing.
Assume the steel is fully austenitic at the carburizing temperature so carbon diffuses in γ-Fe.
Set the carburizing temperature to 925 °C (1198 K).
Use the diffusivity relation D = D0 exp(-Q/RT) with D0 = 2.0×10^-5 m^2/s and Q = 142 kJ/mol.
Use R = 8.314 J/mol·K.
Compute D at 1198 K, or use the provided value D = 1.3×10^-11 m^2/s.
Define initial carbon content C0 = 0.20 wt% C.
Define constant surface carbon content Cs = 0.90 wt% C.
Define target carbon content at depth x as Cx = 1.10 wt% C.
Define depth x = 0.6 mm = 6.0×10^-4 m.
Use the semi-infinite solution C(x,t) = Cs + (C0 − Cs) erf(x / (2√(Dt))).
Rearrange to erf(x / (2√(Dt))) = (Cx − Cs) / (C0 − Cs).
Evaluate the right-hand side as (1.10 − 0.90) / (0.20 − 0.90) = 0.20 / (−0.70) = −0.285714.
Compute the inverse error function argument η = erf^-1(−0.285714) ≈ −0.258.
Use x / (2√(Dt)) = η and solve for time t = x^2 / (4 D η^2).
Compute t = (6.0×10^-4 m)^2 / (4 (1.3×10^-11 m^2/s) (0.258^2)) ≈ 1.0×10^5 s.
Report the estimated carburizing time as approximately 1.0×10^5 s ≈ 28 hours.
