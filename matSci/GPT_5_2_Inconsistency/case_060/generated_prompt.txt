Treat the test as a standard Vickers hardness test with a 136° diamond pyramid indenter.
Use the Vickers hardness formula HV = 1.8544 F / d^2, with F in kgf and d in mm.
Set F = 0.500 kgf.
Set d = 0.42 mm.
Compute HV = 1.8544 × 0.500 / (0.42)^2 = 5.26.
Report the Vickers hardness as HV ≈ 5.26 kgf/mm^2 (≈ 5.3 HV).
