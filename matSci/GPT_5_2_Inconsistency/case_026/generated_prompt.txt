Use the density relation ρ = nA/(N_A a^3).
Set n = 2 for a BCC unit cell.
Use A = 186.76 g/mol.
Use ρ = 14.274 g/cm^3.
Use N_A = 6.022×10^23 mol^-1.
Solve for a = (nA/(ρ N_A))^(1/3).
Compute a^3 = (2×186.76)/(14.274×6.022×10^23) cm^3 = 4.336×10^-23 cm^3.
Compute a = (4.336×10^-23)^(1/3) cm = 3.513×10^-8 cm.
Convert to nm using 1 cm = 10^7 nm.
Report lattice parameter a = 0.351 nm.
