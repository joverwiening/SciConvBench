Use the density relation ρ = nA/(N_A a^3).
Use n = 2 atoms per unit cell.
Use A = 96.98 g/mol.
Use ρ = 5.414 g/cm^3.
Use N_A = 6.022×10^23 mol^-1.
Solve for a^3 = nA/(ρ N_A) with units consistent in g and cm^3.
Compute a^3 = (2×96.98)/(5.414×6.022×10^23) cm^3 = 5.946×10^-23 cm^3.
Compute a = (5.946×10^-23)^(1/3) cm = 3.904×10^-8 cm.
