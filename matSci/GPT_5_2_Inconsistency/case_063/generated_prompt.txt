The test geometry is a standard simply supported three-point bend with a single central point load P applied at midspan over span L.
For this geometry, the maximum bending moment occurs at midspan and equals M_max = P L / 4.
For a rectangular cross-section with width b and thickness d (d is the dimension in the bending direction), the second moment of area is I = b d^3 / 12 and the outer-fiber distance is c = d/2.
The maximum outer-fiber bending stress is σ_max = M_max c / I = (P L / 4)(d/2)/(b d^3 / 12) = 3 P L / (2 b d^2).
Therefore the provided formula σ_f = 3 P L / (4 b d^2) is a factor of 2 too low for the stated three-point bending geometry with P as the total midspan load.
The provided formula would only match if P were interpreted as half the total load (i.e., P = total load / 2), which contradicts the stated definition of P.
Using the correct three-point bend formula with P = 120 N, L = 40 mm, b = 4 mm, d = 3 mm gives σ_max = 3·120·40 / (2·4·3^2) = 200 MPa (with N/mm² = MPa).
