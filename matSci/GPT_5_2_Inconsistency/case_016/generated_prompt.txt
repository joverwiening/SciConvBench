Use the theoretical density relation ρ = ZM/(N_A a^3).
Use Z = 8 formula units per cubic unit cell.
Use M = 139.63 g/mol (molar mass per formula unit).
Use N_A = 6.022×10^23 mol^-1.
Convert the lattice parameter to centimeters before cubing: a = 0.6067 nm = 6.067×10^-8 cm.
Compute a^3 = (6.067×10^-8 cm)^3 = 2.233×10^-22 cm^3.
Compute the denominator N_A a^3 = (6.022×10^23)(2.233×10^-22) = 134.5 cm^3/mol.
Compute the numerator ZM = 8×139.63 = 1117.04 g/mol.
Compute the density ρ = 1117.04 / 134.5 = 8.31 g/cm^3.
