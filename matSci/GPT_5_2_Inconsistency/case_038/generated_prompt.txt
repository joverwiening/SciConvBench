Use the hexagonal interplanar-spacing relation: 1/d_hkl^2 = (4/3)(h^2 + hk + k^2)/a^2 + l^2/c^2.
Set (h k l) = (1 0 0), so (h^2 + hk + k^2) = 1 and l = 0.
Compute 1/d_100^2 = (4/3)(1/a^2).
Solve for d_100: d_100 = a·(√3/2).
Substitute a = 0.321 nm: d_100 = 0.321×0.866025 ≈ 0.278 nm.
