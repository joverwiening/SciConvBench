Use the density relation ρ = nA/(N_A a^3).
Use n = 2 atoms per unit cell.
Use A = 129.68 g/mol.
Use ρ = 14.368 g/cm^3.
Use N_A = 6.022 × 10^23 mol^-1.
Solve for a^3 = nA/(ρ N_A).
Compute a^3 = (2 × 129.68) / (14.368 × 6.022 × 10^23) cm^3 = 2.996 × 10^-23 cm^3.
Compute a = (2.996 × 10^-23)^(1/3) cm = 3.105 × 10^-8 cm.
Convert to nm using 1 cm = 10^7 nm.
Report the cubic lattice parameter a = 0.3105 nm.
