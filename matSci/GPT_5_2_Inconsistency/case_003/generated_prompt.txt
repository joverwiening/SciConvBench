Use X-ray wavelength λ = 0.1172 nm.
Use a cubic crystal lattice parameter a = 0.4045 nm.
Use the (311) planes with interplanar spacing d = a / sqrt(h^2 + k^2 + l^2) = a / sqrt(3^2 + 1^2 + 1^2) = a / sqrt(11).
Compute d = 0.4045 / sqrt(11) = 0.12198 nm.
Treat the reflection as first order, so use Bragg’s law with n = 1: λ = 2 d sin θ.
Compute sin θ = λ / (2d) = 0.1172 / (2 × 0.12198) = 0.48041.
Compute θ = arcsin(0.48041) = 28.72 degrees.
Compute the diffraction angle 2θ = 57.44 degrees.
