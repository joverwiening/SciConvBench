Use the density relation ρ = nA/(N_A a^3).
Use n = 2 atoms per unit cell (BCC).
Use A = 183.72 g/mol.
Use ρ = 16.416 g/cm^3.
Use N_A = 6.02214076×10^23 mol^-1.
Solve for a^3 = nA/(ρ N_A).
Compute a = (nA/(ρ N_A))^(1/3) in cm.
Convert a from cm to nm using 1 cm = 1.0×10^7 nm.
Report a in nm to 4 significant figures.

Numerical result:
a^3 = (2×183.72)/(16.416×6.02214076×10^23) cm^3 = 3.716×10^-23 cm^3.
a = (3.716×10^-23)^(1/3) cm = 3.336×10^-8 cm.
a = 3.336×10^-8 cm × 1.0×10^7 nm/cm = 0.3336 nm.
