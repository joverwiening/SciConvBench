Use X-ray wavelength λ = 0.0762 nm.
Use a cubic crystal lattice parameter a = 0.5313 nm.
Use the (111) planes.
Compute the interplanar spacing for cubic crystals as d111 = a / sqrt(1^2 + 1^2 + 1^2) = a / sqrt(3).
Use Bragg’s law nλ = 2 d sin θ with n = 1 (first-order reflection).
Solve for θ via sin θ = λ / (2 d111).
Compute the diffraction angle as 2θ in degrees.
Numerical result: d111 = 0.5313 / sqrt(3) = 0.3067 nm, sin θ = 0.0762 / (2 × 0.3067) = 0.1242, θ = 7.13°, so 2θ = 14.26°.
