Use the density method for a two-phase (amorphous + crystalline) semicrystalline polymer with no voids.
Use measured bulk density ρ = 1.22 g/cm³.
Use amorphous density ρa = 1.05 g/cm³.
Use crystalline density ρc = 1.30 g/cm³.
Compute weight fraction crystallinity Xc,w using Xc,w = (ρc(ρ − ρa)) / (ρ(ρc − ρa)).
Substitute values: Xc,w = (1.30(1.22 − 1.05)) / (1.22(1.30 − 1.05)) = (1.30·0.17) / (1.22·0.25) = 0.221 / 0.305 ≈ 0.725.
Report degree of crystallinity ≈ 72.5 wt% (about 73 wt%).
