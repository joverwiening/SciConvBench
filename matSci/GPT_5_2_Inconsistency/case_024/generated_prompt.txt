Use the density relation ρ = nA/(N_A a^3).
Set n = 4 atoms/unit cell for FCC.
Use A = 85.15 g/mol.
Use ρ = 13.931 g/cm^3 directly with no corrections.
Use N_A = 6.022×10^23 mol^-1.
Solve for a^3 = nA/(ρ N_A).
Compute a^3 = (4×85.15)/(13.931×6.022×10^23) cm^3 = 4.056×10^-23 cm^3.
Compute a = (4.056×10^-23)^(1/3) cm = 3.437×10^-8 cm.
Convert to nm using 1 cm = 10^7 nm.
Report lattice parameter a = 0.3437 nm (≈ 0.344 nm).
