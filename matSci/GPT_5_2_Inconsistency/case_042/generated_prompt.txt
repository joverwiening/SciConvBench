Use Fick’s first law in 1D: J = −D(dC/dx).
Assume a linear concentration profile between x = 0 and x = L.
Use C(0) = 0.12 mol/m^3 and C(L) = 0.02 mol/m^3.
Use L = 1 mm = 1×10^-3 m.
Compute the gradient as dC/dx = (0.02 − 0.12)/(1×10^-3) = −100 mol/m^4.
Use D = 3.0×10^-11 m^2/s.
Compute J = −(3.0×10^-11)(−100) = +3.0×10^-9 mol/(m^2·s).
Report J as positive in the +x direction per the stated sign convention.
