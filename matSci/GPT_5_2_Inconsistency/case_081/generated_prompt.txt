Estimate the band gap using the simple photon-energy relation Eg ≈ hc/λ, ignoring exciton binding and temperature effects.
Use hc = 1239.84 eV·nm.
Use λ = 900 nm as the absorption edge wavelength.
Compute Eg = 1239.84 / 900 eV.
Report Eg ≈ 1.38 eV (≈ 1.3776 eV).
Optionally note that this estimate conflicts with the separately stated 2.8 eV band gap.
