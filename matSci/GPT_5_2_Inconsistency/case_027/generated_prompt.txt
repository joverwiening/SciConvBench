Use a = 0.5499 nm and λ = 0.0537 nm.
Treat the lattice as generic cubic so the interplanar spacing is d211 = a / sqrt(2^2 + 1^2 + 1^2) = a / sqrt(6).
Compute d211 = 0.5499 / sqrt(6) = 0.22445 nm.
Use Bragg’s law nλ = 2 d sin θ with n = 2.
Compute sin θ = (nλ) / (2d) = (2·0.0537) / (2·0.22445) = 0.23922.
Compute θ = arcsin(0.23922) = 13.84°.
Compute 2θ = 27.68°.
Report 2θ = 27.68°.
