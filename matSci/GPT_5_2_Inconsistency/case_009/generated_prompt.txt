Use the Avrami equation X = 1 − exp(−k t^n).
Treat t in seconds to match k = 7.83×10^-3 s^-n.
Set X = 0.274 and solve for t: t = [−ln(1 − X)/k]^(1/n).
Compute −ln(1 − 0.274) = 0.320243.
Compute (0.320243 / 7.83×10^-3) = 40.899.
Compute t = (40.899)^(1/2.81) = 3.75 s.
Report the required holding time as 3.75 seconds.
