Use V_f = 0.60 and V_m = 0.40.
Use ρ_f = 1.8 g/cm^3 and ρ_m = 1.2 g/cm^3.
Compute fiber weight fraction from volumes and densities as w_f = (V_f ρ_f) / (V_f ρ_f + V_m ρ_m).
Compute V_f ρ_f = 0.60 × 1.8 = 1.08.
Compute V_m ρ_m = 0.40 × 1.2 = 0.48.
Compute w_f = 1.08 / (1.08 + 0.48) = 1.08 / 1.56 = 0.6923.
Report w_f ≈ 0.692 (about 69.2 wt% fiber), which does not match the reported 0.40.
