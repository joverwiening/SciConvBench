The X-ray wavelength is λ = 0.0537 nm.

Use Bragg's Law: nλ = 2d sin(θ).
For a cubic crystal, the interplanar spacing for the (100) planes is d = a = 0.5499 nm.
Calculate θ using sin(θ) = nλ / (2d) = (1 × 0.0537) / (2 × 0.5499) = 0.04883.
θ = arcsin(0.04883) = 2.799 degrees.
