The user wants to determine the fiber volume fraction V_f for a composite material.

Given information:
- Fiber mass fraction (fiber fraction) = 0.361
- Fiber density ρ_f = 4.277 g/cm³
- Matrix density ρ_m = 2.035 g/cm³

The relationship between mass fraction and volume fraction for a composite is:

V_f = (w_f / ρ_f) / (w_f / ρ_f + w_m / ρ_m)

Where:
- w_f = fiber mass fraction = 0.361
- w_m = matrix mass fraction = 1 - w_f = 0.639

Calculation:
- w_f / ρ_f = 0.361 / 4.277 = 0.084405 g/cm³
- w_m / ρ_m = 0.639 / 2.035 = 0.314005 g/cm³
- Total specific volume = 0.084405 + 0.314005 = 0.398410 cm³/g

V_f = 0.084405 / 0.398410 = 0.2119

The fiber volume fraction V_f is approximately 0.212 or 21.2%.
