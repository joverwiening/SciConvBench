The X-rays have wavelength λ = 0.1172 nm.
The cubic crystal has lattice parameter a = 0.4045 nm.
The reflection order is n = 1 (first-order).
The diffraction angle 2θ must be calculated in degrees.

Apply Bragg's Law: nλ = 2d sin(θ).

For a cubic crystal, the interplanar spacing d for the (100) planes equals the lattice parameter: d = a = 0.4045 nm.

Solve for θ: sin(θ) = nλ / (2d) = (1 × 0.1172 nm) / (2 × 0.4045 nm) = 0.1172 / 0.809 = 0.14487.

Calculate θ: θ = arcsin(0.14487) = 8.329 degrees.

Calculate the diffraction angle: 2θ = 2 × 8.329 degrees = 16.658 degrees.

Round to appropriate significant figures: 2θ = 16.7 degrees.
