The ferromagnetic metal has a saturation magnetization M_s = 1.45×10^6 A/m.

The magnetic moment per atom in Bohr magnetons is determined using the relationship between saturation magnetization and atomic magnetic moment.

The number density of atoms n is calculated from the material density and atomic mass.

For iron (Fe), which is the most common ferromagnetic metal matching this saturation magnetization value: density ρ = 7870 kg/m³, atomic mass A = 55.85 g/mol, and atomic number Z = 26.

The number density is n = (ρ × N_A) / A = (7870 kg/m³ × 6.022×10^23 mol^-1) / (0.05585 kg/mol) = 8.49×10^28 atoms/m³.

The magnetic moment per atom is μ_atom = M_s / n = (1.45×10^6 A/m) / (8.49×10^28 m^-3) = 1.71×10^-23 A·m² = 1.71×10^-23 J/T.

One Bohr magneton is μ_B = 9.274×10^-24 J/T.

The magnetic moment in Bohr magnetons per atom is μ_atom / μ_B = (1.71×10^-23 J/T) / (9.274×10^-24 J/T) = 1.84 ≈ 1.85 μ_B/atom.

Alternatively, using the common approximation for iron with M_s = 1.45×10^6 A/m, the accepted value is approximately 1.85 Bohr magnetons per atom, or roughly 2.2 μ_B/atom if using slightly different material parameters.
