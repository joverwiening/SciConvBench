Calculate the number of atomic sites per unit volume using the formula N = (ρ × N_A) / A, where ρ is density, N_A is Avogadro's number, and A is atomic weight.
Convert the density from g/cm³ to appropriate units: ρ = 3.380 g/cm³ = 3.380 × 10^6 g/m³ = 3380 kg/m³, or keep in g/cm³ and convert N_A accordingly.
Calculate N = (3.380 g/cm³ × 6.022×10^23 mol^-1) / (169.90 g/mol) = 1.197×10^22 atoms/cm³.
Convert the vacancy formation energy to consistent units: Q_v = 87.6 kJ/mol = 87600 J/mol.
Calculate the equilibrium vacancy fraction using the Boltzmann factor: N_v/N = exp(-Q_v / RT).
Compute the exponent: -Q_v / RT = -87600 / (8.314 × 1443) = -87600 / 11997.1 = -7.302.
Calculate the vacancy fraction: exp(-7.302) = 6.72×10^-4.
Calculate the equilibrium number of vacancies per unit volume: N_v = N × exp(-Q_v / RT) = 1.197×10^22 × 6.72×10^-4 = 8.04×10^18 vacancies/cm³.
