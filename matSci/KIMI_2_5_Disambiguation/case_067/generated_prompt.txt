Calculate the atomic radius for BCC using the relationship a = 4r/√3, where a = 0.286 nm.
The atomic radius r = a√3/4 = (0.286 nm)(1.732)/4 = 0.124 nm.
Identify the [111] direction as the close-packed direction in BCC.
Determine the length of the [111] direction vector: L = a√3 = (0.286 nm)(1.732) = 0.495 nm.
Count the number of atoms centered along the [111] direction within one unit cell: 2 atoms (one corner atom at each end, each shared by 8 cells, but the body-centered atom lies fully on this diagonal).
Calculate the total length of atoms along [111]: 2 atoms × 2r = 4r = 4(0.124 nm) = 0.496 nm.
Compute linear density as the number of atoms divided by the length of the direction vector: LD = 2 atoms / (a√3) = 2 / (0.495 nm) = 4.04 atoms/nm.
Alternatively express as LD = 1/(2r) = 1/(0.248 nm) = 4.03 atoms/nm.
