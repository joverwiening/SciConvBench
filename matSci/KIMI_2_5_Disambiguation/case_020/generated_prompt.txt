The fiber volume fraction V_f is calculated using the relationship between mass fraction and volume fraction in composite materials.

The mass fraction of fibers W_f is 0.360.
The fiber density ρ_f is 5.456 g/cm³.
The matrix density ρ_m is 1.774 g/cm³.

First calculate the mass fraction of matrix W_m = 1 - W_f = 0.640.

Calculate the fiber volume fraction using the formula:
V_f = (W_f / ρ_f) / [(W_f / ρ_f) + (W_m / ρ_m)]

Calculate W_f / ρ_f = 0.360 / 5.456 = 0.065982 g⁻¹·cm³

Calculate W_m / ρ_m = 0.640 / 1.774 = 0.360766 g⁻¹·cm³

Calculate the denominator: 0.065982 + 0.360766 = 0.426748 g⁻¹·cm³

Calculate V_f = 0.065982 / 0.426748 = 0.1546

The fiber volume fraction V_f is 0.155 or 15.5%.
