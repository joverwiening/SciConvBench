The X-rays have wavelength λ = 0.0762 nm.
The cubic crystal has lattice parameter a = 0.5313 nm.
The reflection order is n = 1 (first-order).
Use Bragg's Law: nλ = 2d sin(θ).
For a cubic crystal, the interplanar spacing for the (100) planes is d = a = 0.5313 nm.
Solve for θ: sin(θ) = nλ / (2d) = (1 × 0.0762) / (2 × 0.5313) = 0.07171.
Calculate θ = arcsin(0.07171) = 4.113 degrees.
The diffraction angle 2θ = 2 × 4.113 = 8.23 degrees.
