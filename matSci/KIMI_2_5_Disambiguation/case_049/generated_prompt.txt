Use the density values provided: ρ_s = 1.0383 g/cm^3 (sample density), ρ_a = 1.0015 g/cm^3 (amorphous phase density), and ρ_c = 1.2157 g/cm^3 (crystalline phase density).

Apply the two-phase model equation for mass fraction crystallinity: w_c = (ρ_c / ρ_s) * ((ρ_s - ρ_a) / (ρ_c - ρ_a)).

Calculate the crystallinity using the given values: w_c = (1.2157 / 1.0383) * ((1.0383 - 1.0015) / (1.2157 - 1.0015)).

Perform the calculation: w_c = (1.2157 / 1.0383) * (0.0368 / 0.2142) = 1.1709 * 0.1718 = 0.2012.
