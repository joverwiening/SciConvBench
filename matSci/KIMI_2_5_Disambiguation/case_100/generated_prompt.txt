The crystal is cubic, so all lattice parameters are equal (a = b = c).
The wavelength of Cu Kα radiation is 0.15406 nm.
The observed diffraction peak occurs at 2θ = 44.7°.
Apply Bragg's Law: nλ = 2d sin(θ), using first order diffraction (n = 1).
Calculate θ = 44.7° / 2 = 22.35°.
Calculate d = λ / (2 sin(θ)) = 0.15406 nm / (2 × sin(22.35°)) = 0.15406 nm / (2 × 0.3805) = 0.15406 nm / 0.7610 = 0.2024 nm.
For a cubic crystal, the interplanar spacing relates to lattice parameter by d = a / √(h² + k² + l²).
The lattice parameter a equals d multiplied by √(h² + k² + l²).
Without knowing the specific (hkl) indices of the diffraction peak, the lattice parameter cannot be uniquely determined.
The most common first peak in a cubic crystal is typically from the (111) plane for FCC or (110) for BCC.
Assuming the (111) reflection: a = 0.2024 nm × √3 = 0.2024 nm × 1.732 = 0.3506 nm.
Assuming the (110) reflection: a = 0.2024 nm × √2 = 0.2024 nm × 1.414 = 0.2862 nm.
The lattice parameter is approximately 0.351 nm if FCC (111), or 0.286 nm if BCC (110).
