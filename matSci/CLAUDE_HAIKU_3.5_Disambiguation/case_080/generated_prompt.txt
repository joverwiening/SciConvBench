The task is to calculate the ionic conductivity of a solid electrolyte using the Nernst-Einstein relation.
Use the following parameters: 
Mobile-ion number density n = 4.0 × 10^27 m^-3
Diffusivity D = 1.2 × 10^-11 m^2/s
Temperature T = 800 K
Mobile ion charge z = 1
Elementary charge e = 1.602 × 10^-19 C
Calculate the ionic conductivity σ using the Nernst-Einstein equation: σ = n × z^2 × e^2 × D / (k_B × T)
Where k_B is the Boltzmann constant (1.380649 × 10^-23 J/K)
Report the final result in units of S/m (Siemens per meter)
