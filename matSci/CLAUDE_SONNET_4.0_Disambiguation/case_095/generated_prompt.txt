Calculate the magnetic moment per atom in Bohr magnetons for iron metal.
Use saturation magnetization M_s = 1.45×10^6 A/m.
Use density = 7.87 g/cm³.
Use atomic weight = 55.85 g/mol.
Assume body-centered cubic crystal structure for iron.
First calculate the number density of atoms using density, atomic weight, and Avogadro's number.
Then calculate magnetic moment per atom by dividing saturation magnetization by number density.
Convert the result from A⋅m² to Bohr magnetons using the conversion factor 1 Bohr magneton = 9.274×10^-24 A⋅m².
Present the final answer as the number of Bohr magnetons per atom.
