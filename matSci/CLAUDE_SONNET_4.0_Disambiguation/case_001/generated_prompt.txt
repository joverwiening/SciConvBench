Calculate the cubic lattice parameter for a crystalline metal with the following properties.
The metal has a body-centered cubic (BCC) structure.
The atomic weight is 129.68 g/mol.
The theoretical density is 14.368 g/cm³.
Use Avogadro's number N_A = 6.022×10²³ mol⁻¹.
For BCC structure, there are 2 atoms per unit cell.
Use the density formula: density = (number of atoms per unit cell × atomic weight) / (lattice parameter³ × N_A).
Solve for the lattice parameter and express the result in nanometers.
