Calculate the magnitude of the Burgers vector for a perfect dislocation in an FCC metal.
The lattice parameter is a = 0.404 nm.
The Burgers vector is b = a/2 <110>.
Use the formula |b| = (a/2) × √(1² + 1² + 0²) = (a/2) × √2.
Substitute a = 0.404 nm to get |b| = (0.404/2) × √2 = 0.202 × 1.414 = 0.286 nm.
The magnitude of the Burgers vector is 0.286 nm.
