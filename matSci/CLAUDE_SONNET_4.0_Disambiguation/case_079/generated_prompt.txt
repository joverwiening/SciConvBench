Calculate the atomic fraction of component B in a substitutional binary alloy using Vegard's law.
The alloy has a lattice parameter of 0.389 nm.
Pure component A has a lattice parameter of 0.404 nm.
Pure component B has a lattice parameter of 0.361 nm.
Apply Vegard's law which states that the lattice parameter varies linearly with composition: a_alloy = x_A * a_A + x_B * a_B.
Use the constraint that x_A + x_B = 1 for a binary system.
Solve for the atomic fraction of component B (x_B).
Express the final answer as both a decimal and percentage.
