Calculate the critical field H_c(T) at T = 4.2 K for a type-I superconductor.
Use the formula H_c(T) = H_c(0)[1 - (T/T_c)^2].
Set H_c(0) = 0.080 T.
Set T_c = 7.20 K.
Set T = 4.2 K.
Substitute the values into the formula to get H_c(4.2 K) = 0.080 T × [1 - (4.2 K / 7.20 K)^2].
Calculate (4.2/7.20)^2 = 0.3403.
Calculate 1 - 0.3403 = 0.6597.
Calculate the final result: H_c(4.2 K) = 0.080 T × 0.6597 = 0.0528 T.
Express the answer to appropriate significant figures as 0.053 T.
