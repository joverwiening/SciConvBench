Calculate the crystallite size using the Scherrer equation: D = Kλ/(β cos θ).
Use the shape factor K = 0.90.
Use the X-ray wavelength λ = 0.15406 nm (Cu Kα radiation).
Use the diffraction peak at 2θ = 38.2°, so θ = 19.1°.
Use the full width at half maximum β = 0.24°.
Convert the FWHM from degrees to radians by multiplying by π/180.
Calculate cos(19.1°) for the denominator.
The final result will give the crystallite size D in nanometers.
