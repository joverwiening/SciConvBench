Use the given values of Young's modulus E = 210 GPa and Poisson's ratio ν = 0.30.  
Calculate the theoretical shear modulus G using the formula G = E / (2(1 + ν)).  
Substitute the values to obtain G = 210 / (2(1 + 0.30)) = 210 / 2.6 ≈ 80.77 GPa.  
Compare the calculated G (≈80.77 GPa) with the given value of G = 60 GPa.  
Determine that the given elastic constants are not mutually consistent because 80.77 GPa ≠ 60 GPa.
