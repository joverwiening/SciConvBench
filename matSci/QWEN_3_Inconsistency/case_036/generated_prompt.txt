The first peak in the powder diffraction pattern is indexed as (100) and occurs at 2θ = 43.5°.  
Convert 2θ to θ by dividing by 2, giving θ = 21.75°.  
Apply Bragg's law: nλ = 2d sinθ, using n = 1 and λ = 1.5406 Å.  
Calculate the interplanar spacing d using d = λ / (2 sinθ).  
For an FCC lattice, the (100) plane has a relationship between d and the lattice parameter a given by d = a / √(h² + k² + l²), where h, k, l are the Miller indices (1,0,0).  
Thus, d = a / √1, so a = d × √1.
