Use Fick's first law: J = -D * (dc/dx).  
Assume a linear concentration gradient across the membrane.  
Calculate the concentration gradient: dc/dx = (0.02 - 0.12) / (0.001 - 0) = -100 mol/m⁴.  
Substitute D = 3.0×10⁻¹¹ m²/s into the equation.  
Compute J = - (3.0×10⁻¹¹) * (-100) = 3.0×10⁻⁹ mol/(m²·s).  
The diffusion flux J is in the -x direction as stated.  
Report J = 3.0×10⁻⁹ mol/(m²·s) with direction implied by sign convention.
