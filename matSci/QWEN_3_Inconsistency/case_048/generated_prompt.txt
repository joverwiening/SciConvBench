Use the lever rule to calculate the fraction of phase α.  
The fraction of phase α is given by (C_β - C₀) / (C_β - C_α).  
Substitute C₀ = 40 wt% B, C_α = 25 wt% B, and C_β = 70 wt% B.  
Calculate (70 - 40) / (70 - 25) = 30 / 45 = 0.6667.  
The fraction of phase α is 0.6667 (or 66.67%).  
The temperature is assumed to be within the α+β two-phase region where the tie line is valid.
