Use monochromatic X-rays with wavelength λ = 0.1172 nm incident on a cubic crystal with lattice parameter a = 0.4045 nm.  
Perform a first-order reflection (n = 1) from the (311) planes.  
Apply Bragg's law: nλ = 2d sinθ, with n = 1.  
Calculate the interplanar spacing d for the (311) planes using the formula d = a / √(h² + k² + l²), where h = 3, k = 1, l = 1.  
Compute d = 0.4045 / √11 ≈ 0.1219 nm.  
Compute sinθ = λ / (2d) = 0.1172 / (2 × 0.1219) ≈ 0.4807.  
Calculate θ = arcsin(0.4807) ≈ 28.73°.  
Report the diffraction angle 2θ ≈ 57.46°.
