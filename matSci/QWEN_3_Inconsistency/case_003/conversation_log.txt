Q: Use monochromatic X-rays with wavelength λ = 0.1172 nm incident on a cubic crystal with lattice parameter a = 0.4045 nm.  
Perform a first-order reflection (n = 1) from the (311) planes.  
Apply Bragg's law: nλ = 2d sinθ, with n = 1.  
Calculate the interplanar spacing d for the (311) planes using the cubic crystal lattice parameter a.  
Compute the diffraction angle 2θ in degrees.  
Report the final angle value with appropriate precision.
A: Use λ = 0.1172 nm, a = 0.4045 nm, and (hkl) = (311).  
For cubic crystals, d = a / √(h² + k² + l²) = 0.4045 / √(3² + 1² + 1²) = 0.4045 / √11 ≈ 0.1219 nm.  
Apply Bragg's law: nλ = 2d sinθ, with n = 1.  
sinθ = λ / (2d) = 0.1172 / (2 × 0.1219) ≈ 0.4807.  
θ = arcsin(0.4807) ≈ 28.73°.  
2θ ≈ 57.46°.  

Final answer: 57.46°.
