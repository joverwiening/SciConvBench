Calculate the weight-average molecular weight using the formula M_w = Σ(N_i M_i) / ΣN_i.  
Use the given values: N1 = 93, M1 = 21640 g/mol.  
Use the given values: N2 = 40, M2 = 74810 g/mol.  
Use the given values: N3 = 170, M3 = 135292 g/mol.  
Use the given values: N4 = 48, M4 = 141802 g/mol.  
Multiply each N_i by its corresponding M_i and sum the products for the numerator.  
Sum all N_i values for the denominator.  
Divide the total sum of N_i M_i by the sum of N_i to obtain M_w.  
Report M_w in g/mol.
