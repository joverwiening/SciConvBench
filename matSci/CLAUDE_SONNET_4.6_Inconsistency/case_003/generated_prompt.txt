Use Bragg's law in the form nλ = 2d·sin(θ), with n = 1.
The X-ray wavelength is λ = 0.1172 nm.
The crystal is cubic with lattice parameter a = 0.4045 nm.
The reflecting planes are (311).
Calculate the interplanar spacing d for the (311) planes using d = a / sqrt(h² + k² + l²), where h = 3, k = 1, l = 1.
Compute sqrt(3² + 1² + 1²) = sqrt(11) ≈ 3.3166.
Compute d = 0.4045 / 3.3166 ≈ 0.12196 nm.
Apply Bragg's law: sin(θ) = nλ / (2d) = (1 × 0.1172) / (2 × 0.12196).
Compute sin(θ) = 0.1172 / 0.24392 ≈ 0.4805.
Compute θ = arcsin(0.4805) ≈ 28.71 degrees.
Compute the diffraction angle 2θ = 2 × 28.71 ≈ 57.42 degrees.
Report the final answer as 2θ ≈ 57.42 degrees.
