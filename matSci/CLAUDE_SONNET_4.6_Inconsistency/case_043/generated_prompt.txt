Use the semi-infinite solid diffusion solution: C(x,t) = Cs - (Cs - C0) * erf(x / (2 * sqrt(D*t))).

Treat this as a likely transcription error in the problem: the desired carbon content at 0.6 mm depth is most likely 0.40 wt% C (a common textbook value), not 1.10 wt% C.
Use C(x,t) = 0.40 wt% C at x = 0.0006 m as the corrected target.

Compute the dimensionless concentration ratio: (Cs - C(x,t)) / (Cs - C0) = (0.90 - 0.40) / (0.90 - 0.20) = 0.50 / 0.70 = 0.7143.
Set erf(z) = 0.7143, where z = x / (2 * sqrt(D*t)).
Find z from the inverse error function: erf(0.755) ≈ 0.7143, so z ≈ 0.755.

Solve for t: sqrt(D*t) = x / (2 * 0.755) = 0.0006 / 1.510 = 3.974 x 10^-4 m.

Divide by D: t = 1.579 x 10^-7 / 1.28 x 10^-11 = 12,336 seconds.
Convert to hours: t ≈ 12,336 / 3600 ≈ 3.43 hours.
