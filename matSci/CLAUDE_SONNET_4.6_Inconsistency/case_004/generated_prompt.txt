The material has atomic weight 169.90 g/mol and density 3.380 g/cm^3.
The vacancy formation energy Q_v is 87.6 kJ/mol, which equals 87600 J/mol.
The temperature T is 1443 K.
Use the formula n_v = N * exp(-Q_v / (k_B * T)).
Compute N, the number of atomic sites per unit volume, using N = (N_A * density) / atomic weight.
Convert density from g/cm^3 to g/m^3: 3.380 g/cm^3 = 3.380e6 g/m^3.
Compute N = (6.022e23 mol^-1 * 3.380e6 g/m^3) / 169.90 g/mol.
Compute numerator: 6.022e23 * 3.380e6 = 2.03544e30.
Compute N = 2.03544e30 / 169.90 = 1.1980e28 atoms/m^3.
For the exponential argument, use the per-atom form of Q_v by dividing by N_A: Q_v per atom = 87600 / 6.022e23 = 1.4548e-19 J/atom.
Use k_B = 1.3806e-23 J/K.
Compute k_B * T = 1.3806e-23 * 1443 = 1.9922e-20 J.
Compute Q_v / (k_B * T) = 1.4548e-19 / 1.9922e-20 = 7.302.
Compute exp(-7.302) = 6.72e-4.
Alternatively, use the molar form: Q_v / (R * T) = 87600 / (8.314 * 1443) = 87600 / 11997.0 = 7.302, confirming the same exponent.
Compute n_v = 1.1980e28 * 6.72e-4.
Compute n_v = 1.1980e28 * 6.72e-4 = 8.05e24 vacancies/m^3.
The equilibrium number of vacancies per m^3 at 1443 K is approximately 8.05e24 vacancies/m^3.
