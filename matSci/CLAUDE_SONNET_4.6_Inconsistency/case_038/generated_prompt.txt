The crystal system is HCP (hexagonal close-packed) magnesium.

The lattice parameters are a = 0.321 nm and c = 0.521 nm.

The plane of interest is (100), so h = 1, k = 0, l = 0.

Use the correct hexagonal interplanar spacing formula: 1/d²_hkl = (4/3)·((h² + hk + k²)/a²) + l²/c².

Substitute h = 1, k = 0, l = 0 into the formula.

Calculate h² + hk + k² = 1² + (1)(0) + 0² = 1.

Calculate (4/3)·(1/a²) = (4/3)·(1/(0.321)²).

Calculate (0.321)² = 0.103041 nm².

Calculate (4/3)/0.103041 = 1.3333/0.103041 = 12.940 nm⁻².

The l²/c² term = 0²/(0.521)² = 0.

Therefore 1/d²_100 = 12.940 nm⁻².
