The system is a two-component polymer blend.
Polymer A has a weight fraction of 0.65 and a glass-transition temperature T_g,A = 370 K.
Polymer B has a weight fraction of 0.35 and a glass-transition temperature T_g,B = 250 K.
The two weight fractions sum to 1.00, confirming a valid two-component blend.
Apply the Fox equation: 1/T_g,blend = (w_A / T_g,A) + (w_B / T_g,B).
Substitute the values: 1/T_g,blend = (0.65 / 370) + (0.35 / 250).
Calculate each term: 0.65 / 370 = 0.0017568 K⁻¹ and 0.35 / 250 = 0.0014000 K⁻¹.
Sum the terms: 1/T_g,blend = 0.0017568 + 0.0014000 = 0.0031568 K⁻¹.
Take the reciprocal to find T_g,blend: T_g,blend = 1 / 0.0031568 ≈ 316.8 K.
Report the estimated blend glass-transition temperature as approximately 317 K.
