Use Bragg's law: nλ = 2d·sin(θ), with n = 1.
The crystal is cubic with lattice parameter a = 0.5499 nm.
The X-ray wavelength is λ = 0.0537 nm.
The reflecting planes are (211).
Calculate the interplanar spacing d for the (211) planes using d = a / sqrt(h² + k² + l²), where h=2, k=1, l=1.
Compute sqrt(2² + 1² + 1²) = sqrt(6).
Compute d = 0.5499 / sqrt(6).
Substitute n = 1, λ = 0.0537 nm, and the computed d into Bragg's law: sin(θ) = λ / (2d).
Solve for θ = arcsin(λ / (2d)).
Compute the final answer as 2θ in degrees.
