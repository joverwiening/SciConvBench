The grain growth equation to use is D^n - D_0^n = K * t, with n = 3 as specified in the problem.
The initial grain size D_0 is 12 μm.
The final grain size D is 30 μm.
The time t is 1 hour.
Substitute the values into the equation: K = (D^3 - D_0^3) / t.
Calculate D^3: 30^3 = 27000 μm^3.
Calculate D_0^3: 12^3 = 1728 μm^3.
Calculate the difference: 27000 - 1728 = 25272 μm^3.
Divide by t = 1 h: K = 25272 / 1 = 25272 μm^3/h.
The value of K is 25272 μm^3/h.
Note that the problem uses n = 3 instead of the classical n = 2, which represents a deviation from ideal normal grain growth, often attributed to solute drag or other retarding mechanisms.
