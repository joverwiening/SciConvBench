The problem involves a central crack in a material under Mode I loading.
The total crack length is 2a = 4.0 mm, so the correct half-crack length is a = 2.0 mm = 0.002 m.
The fracture toughness is K_Ic = 35 MPa√m.
The geometry correction factor is Y = 1.0.
The fracture mechanics equation is K_I = Y * σ * √(π * a).
At the critical condition, set K_I equal to K_Ic: K_Ic = Y * σ_c * √(π * a).
Rearrange to solve for critical stress: σ_c = K_Ic / (Y * √(π * a)).
Substitute the values: σ_c = 35 / (1.0 * √(π * 0.002)).
Compute the term inside the square root: π * 0.002 = 0.006283.
Compute the square root: √(0.006283) = 0.07927 m^(1/2).
Compute the critical stress: σ_c = 35 / 0.07927 = approximately 441.5 MPa.
Report the final answer as σ_c ≈ 441.5 MPa.
Note that using the incorrect value a = 4.0 mm would overestimate the crack size and yield a lower, non-conservative critical stress of approximately 312.2 MPa, which is the error introduced by substituting the full crack length instead of the half-crack length.
