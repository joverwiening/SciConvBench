Use the cubic interplanar spacing formula d = a / sqrt(h² + k² + l²).
Given a = 0.5313 nm and (hkl) = (111), compute d = 0.5313 / sqrt(1² + 1² + 1²) = 0.5313 / sqrt(3) = 0.3067 nm.
Use Bragg's law: n·λ = 2·d·sin(θ), with n = 2 and λ = 0.0762 nm.
Substitute: 2 × 0.0762 = 2 × 0.3067 × sin(θ).
Simplify: 0.1524 = 0.6134 × sin(θ).
Solve for sin(θ): sin(θ) = 0.1524 / 0.6134 = 0.2484.
Compute θ = arcsin(0.2484) = 14.38 degrees.
The diffraction angle 2θ = 2 × 14.38 = 28.76 degrees.
Report the final answer as 2θ ≈ 28.76°.
