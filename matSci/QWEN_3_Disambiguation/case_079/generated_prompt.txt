Use Vegard's law to estimate the atomic fraction of component B in the binary alloy.  
The lattice parameter of the alloy is 0.389 nm.  
The lattice parameter of pure component A is 0.404 nm.  
The lattice parameter of pure component B is 0.361 nm.  
Assume a linear relationship between lattice parameter and composition according to Vegard's law.  
Calculate the atomic fraction of component B using the formula:  
x_B = (a_alloy - a_A) / (a_B - a_A), where a_alloy = 0.389 nm, a_A = 0.404 nm, and a_B = 0.361 nm.  
Report the atomic fraction of component B as the result.
