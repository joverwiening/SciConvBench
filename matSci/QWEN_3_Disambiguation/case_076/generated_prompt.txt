Use the Larson–Miller parameter equation P = T(C + log10 t_r).  
Set P = 23,500.  
Set T = 700°C, which is 973 K (convert by adding 273).  
Set C = 20.  
Substitute into the equation: 23,500 = 973(20 + log10 t_r).  
Solve for log10 t_r: log10 t_r = (23,500 / 973) - 20.  
Calculate log10 t_r ≈ 24.15 - 20 = 4.15.  
Compute t_r = 10^4.15.  
The rupture life t_r is approximately 14,125 hours.
