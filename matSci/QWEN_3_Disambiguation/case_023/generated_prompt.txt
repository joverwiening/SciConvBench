Use Bragg's Law: nλ = 2d sinθ, where n = 1 (first-order diffraction), λ = 0.0537 nm, and d is the interplanar spacing.  
For a cubic crystal, d = a / √(h² + k² + l²), where a = 0.5499 nm is the lattice parameter.  
Assume the diffraction occurs from the (100) plane, so h = 1, k = 0, l = 0, giving d = 0.5499 nm.  
Calculate θ using sinθ = (nλ) / (2d).  
Then calculate 2θ in degrees.  
The value of 2θ is approximately 11.18 degrees.
