Calculate the d-spacing for the (100) plane in HCP magnesium using the hexagonal crystal system formula.

Use the HCP d-spacing formula: d_hkl = 1 / √[(4/3)((h² + hk + k²)/a²) + (l²/c²)].

Substitute h = 1, k = 0, l = 0 for the (100) plane.

Substitute a = 0.321 nm and c = 0.521 nm.

Calculate the term (h² + hk + k²) = (1² + 1×0 + 0²) = 1.

Calculate (4/3) × (1 / a²) = (4/3) × (1 / 0.321²) = (4/3) × (1 / 0.103041) = (4/3) × 9.7048 = 12.9397 nm⁻².

Calculate l²/c² = 0² / 0.521² = 0.

Sum the terms: 12.9397 + 0 = 12.9397 nm⁻².

Take the square root: √12.9397 = 3.5972 nm⁻¹.

Take the reciprocal: d_100 = 1 / 3.5972 = 0.2780 nm.

Report the final answer as d_(100) = 0.278 nm (or 2.78 Å).
