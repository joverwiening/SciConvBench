The critical applied stress for fracture is calculated using the fracture toughness criterion K_I = K_Ic at failure.

The stress intensity factor relation is K_I = Yσ√(πa).

Set K_I = K_Ic and solve for critical stress σ_c:

σ_c = K_Ic / (Y√(πa))

Given values:
- K_Ic = 105.8 MPa·√m
- Y = 0.98
- The crack size parameter a = 2.968 mm = 0.002968 m (used in the formula)
- The visible through-crack length 2a = 2.968 mm confirms the crack depth a = 1.484 mm, but the problem explicitly states to use a = 2.968 mm as the crack size parameter in the relation

Calculation:
σ_c = 105.8 / (0.98 × √(π × 0.002968))
σ_c = 105.8 / (0.98 × √0.009321)
σ_c = 105.8 / (0.98 × 0.09654)
σ_c = 105.8 / 0.09461
σ_c = 1118.3 MPa

The critical applied stress for fracture is 1118 MPa (or approximately 1118.3 MPa).
