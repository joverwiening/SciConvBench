Calculate the interplanar spacing d for the (211) planes in a cubic crystal using the formula d = a / sqrt(h² + k² + l²), where a = 0.5499 nm and (hkl) = (211).

Substitute the values: d = 0.5499 nm / sqrt(2² + 1² + 1²) = 0.5499 nm / sqrt(6) = 0.2245 nm.

Apply Bragg's law: nλ = 2d sin(θ), with n = 1 (first-order), λ = 0.0537 nm, and d = 0.2245 nm.

Solve for θ: sin(θ) = nλ / (2d) = (1 × 0.0537 nm) / (2 × 0.2245 nm) = 0.1196.

Calculate θ = arcsin(0.1196) = 6.87°.

Determine 2θ = 2 × 6.87° = 13.74°.
