The diffusion couple consists of two semi-infinite regions joined at an initial interface located at the geometric center of the specimen. The left region initially contains 20 at% B and the right region initially contains 80 at% B. After annealing, the concentration profile evolves according to Fick's second law with constant interdiffusion coefficient. The solution for the composition as a function of position and time is given by the error function solution: C(x,t) = C_avg + (ΔC/2) * erf(x / (2√(Dt))), where C_avg = 50 at% B and ΔC = 60 at% B. The profile width is defined as the distance between positions where the concentration equals 20 at% B and 80 at% B. Using the error function solution, the position where C = 20 at% B corresponds to erf(η) = -1, and where C = 80 at% B corresponds to erf(η) = +1, where η = x / (2√(Dt)). Since erf(η) = ±1 occurs at approximately η = ±0.906, the profile width equals 2 × 0.906 × 2√(Dt) = 3.624√(Dt). For a typical metallic system such as Cu-Ni, a reasonable interdiffusion coefficient at an elevated annealing temperature of 1000°C is approximately D = 10^(-12) m²/s. For a typical annealing time of 10 hours (36000 seconds), the interdiffusion distance √Dt = √(3.6 × 10^(-8) m²) = 1.9 × 10^(-4) m = 190 μm. The profile width is then estimated as 3.624 × 190 μm ≈ 690 μm, or approximately 0.7 mm. The total specimen length is assumed to be much larger than this profile width (e.g., 10 mm), ensuring the semi-infinite boundary condition remains valid.
