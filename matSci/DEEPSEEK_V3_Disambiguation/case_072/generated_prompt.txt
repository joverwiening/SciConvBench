This is a diffusion problem requiring the application of Fick's second law.
The boundary condition is a constant surface concentration (C_s = 0.95 wt% C).
The initial concentration is uniform (C_0 = 0.20 wt% C).
The target concentration is C(x,t) = 0.40 wt% C at depth x = 0.80 mm.
The diffusion coefficient is D = 1.6×10^-11 m^2/s.
The solution uses the error function: (C(x,t) - C_0) / (C_s - C_0) = 1 - erf( x / (2√(Dt) ) ).
Calculate the left-hand side: (0.40 - 0.20) / (0.95 - 0.20) = 0.20 / 0.75 = 0.2667.
Solve 0.2667 = 1 - erf( z ), where z = x / (2√(Dt)).
Therefore, erf(z) = 1 - 0.2667 = 0.7333.
Find the argument z corresponding to erf(z) = 0.7333 from error function tables or an approximation.
The value z is approximately 0.78.
Set z = x / (2√(Dt)) = 0.78.
Solve for t: t = x^2 / (4 * D * z^2).
Convert depth x to meters: x = 0.80 mm = 8.0×10^-4 m.
Substitute values: t = (8.0×10^-4 m)^2 / (4 * 1.6×10^-11 m^2/s * (0.78)^2).
Calculate the time t.
The estimated time is approximately 8.2 × 10^3 seconds.
