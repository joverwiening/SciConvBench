Use Bragg’s law n λ = 2 d sinθ with n = 1.  
Calculate the interplanar spacing for the (311) planes: d = a / √(h² + k² + l²) = 0.4045 nm / √11 ≈ 0.1219 nm.  
Compute sinθ: sinθ = λ / (2 d) = 0.1172 nm / (2 × 0.1219 nm) ≈ 0.4806.  
Find θ: θ = arcsin(0.4806) ≈ 28.7°.  
Thus the diffraction angle is 2θ ≈ 57.4°.
