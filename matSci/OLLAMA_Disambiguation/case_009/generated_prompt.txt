Calculate the steady‑state heat‑transfer rate through the composite wall as follows:

1. Convert the layer thicknesses from millimetres to metres:  
   - Layer 1 thickness = 9.74 mm = 0.00974 m  
   - Layer 2 thickness = 13.27 mm = 0.01327 m  

2. Compute the thermal resistance of each layer using \(R = \dfrac{L}{k\,A}\):  
   - \(R_1 = \dfrac{0.00974}{12.31 \times 0.0725}\) K/W  
   - \(R_2 = \dfrac{0.01327}{107.49 \times 0.0725}\) K/W  

3. Sum the resistances to obtain the total resistance:  
   - \(R_{\text{total}} = R_1 + R_2\) K/W  

4. Determine the temperature difference between the outer surfaces:  
   - \(\Delta T = 198.1^\circ\text{C} - (-25.4^\circ\text{C}) = 223.5\ \text{K}\)  

5. Calculate the steady heat‑transfer rate using Fourier’s law for series conduction:  
   - \(Q = \dfrac{\Delta T}{R_{\text{total}}}\) W  

6. Report the resulting heat‑transfer rate in watts.
