Assume the tensile loading axis is aligned with the crystal [100] direction.  
Use the FCC slip system with slip plane {111} and slip direction <110>, for example the (111)[‑110] system, as the active slip system because it provides the maximum Schmid factor for this loading orientation.  
Calculate the direction cosines: cos φ (angle between loading axis and slip‑plane normal) = 1/√3 ≈ 0.577, and cos λ (angle between loading axis and slip direction) = 1/√2 ≈ 0.707.  
Compute the Schmid factor m = cos φ · cos λ = 0.577 × 0.707 ≈ 0.408.  
Determine the resolved shear stress τ = σ · m = 65 MPa × 0.408 ≈ 26.5 MPa.
