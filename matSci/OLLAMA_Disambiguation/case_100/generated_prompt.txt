Determine the lattice parameter of the cubic crystal using the following steps.

Use Cu Kα radiation with wavelength λ = 1.5406 Å.  
Assume first‑order diffraction (n = 1).  
Calculate the Bragg angle θ = 2θ / 2 = 44.7° / 2 = 22.35°.  
Apply Bragg’s law: d = λ / (2 sin θ).  
For the (1 1 0) reflection in a cubic lattice, the interplanar spacing is d = a / √(h² + k² + l²) = a / √2.  
Solve for the lattice parameter: a = d × √2.  

The resulting lattice parameter is a ≈ 2.87 Å.
