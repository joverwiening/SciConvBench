Calculate the interplanar spacing for the (111) planes using d = a / √(h² + k² + l²) = 0.5313 nm / √3 ≈ 0.3067 nm.  
Apply Bragg’s law for first‑order reflection (n = 1): sin θ = λ / (2d) = 0.0762 nm / (2 × 0.3067 nm) ≈ 0.1242.  
Determine θ = arcsin(0.1242) ≈ 7.13°.  
Compute the diffraction angle 2θ = 2 × θ ≈ 14.3°.  
Thus the diffraction angle 2θ is approximately 14.3 degrees.
