Use the one‑dimensional semi‑infinite diffusion solution with a constant surface concentration:  

C(x,t)=Cs−(Cs−C0)·erf( x / (2√(D t)) ).  

Set Cs = 0.95 wt% C, C0 = 0.20 wt% C, target C = 0.40 wt% C, x = 0.80 mm = 8.0×10⁻⁴ m, and D = 1.6×10⁻¹¹ m²/s.  

Solve the equation 0.40 = 0.95 − (0.95−0.20)·erf( x / (2√(D t)) ) for t.  

Compute the argument of the error function:  

erf⁻¹[ (0.95−0.40)/(0.95−0.20) ] = erf⁻¹(0.55/0.75) = erf⁻¹(0.7333…).  

Evaluate erf⁻¹(0.7333…) ≈ 0.732.  

Set 0.732 = x / (2√(D t)).  

Rearrange to obtain t = [ x / (2·0.732) ]² / D.  

Substitute x = 8.0×10⁻⁴ m and D = 1.6×10⁻¹¹ m²/s:  

t = [ (8.0×10⁻⁴) / (1.464) ]² / (1.6×10⁻¹¹) ≈ (5.47×10⁻⁴)² / (1.6×10⁻¹¹) ≈ 2.99×10⁻⁷ / 1.6×10⁻¹¹ ≈ 1.87×10⁴ s.  

Convert to hours: 1.87×10⁴ s / 3600 ≈ 5.2 h.  

Therefore, the estimated time required for the carbon content to reach 0.40 wt% at a depth of 0.80 mm is approximately 1.9×10⁴ seconds, or about 5.2 hours.
