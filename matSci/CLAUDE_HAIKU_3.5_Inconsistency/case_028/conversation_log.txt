Q: What is the value of the lattice spacing (d) for the (111) planes in this cubic crystal?
A: To calculate the lattice spacing (d) for the (111) planes in a cubic crystal, use the formula:

d = a / √(h² + k² + l²)

Where:
a = lattice parameter = 0.5313 nm
h = 1, k = 1, l = 1 (for the (111) planes)

d = 0.5313 / √(1² + 1² + 1²)
d = 0.5313 / √3
d = 0.3067 nm
