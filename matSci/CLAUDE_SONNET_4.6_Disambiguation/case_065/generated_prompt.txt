The metal is FCC with lattice parameter a = 0.404 nm.
A perfect (full) dislocation in an FCC crystal has a Burgers vector of the type a/2 <110>.
Calculate the magnitude of the Burgers vector using the formula |b| = a/√2.
Substitute a = 0.404 nm into the formula: |b| = 0.404 / √2.
Compute √2 = 1.41421356.
Divide: |b| = 0.404 / 1.41421356 = 0.2856 nm.
Round the result to four significant figures: |b| ≈ 0.2856 nm.
State the final answer: the Burgers vector magnitude of a perfect dislocation in this FCC metal is approximately 0.2856 nm (or 2.856 Å).
