The crystal is cubic with a lattice parameter a = 0.5499 nm.
The X-ray wavelength used is λ = 0.0537 nm.
The reflecting plane has Miller indices (h, k, l) = (2, 1, 1).
The diffraction order is n = 1 (first-order).
Calculate the interplanar spacing d using the cubic formula: d = a / sqrt(h² + k² + l²).
Compute d = 0.5499 / sqrt(4 + 1 + 1) = 0.5499 / sqrt(6).
Apply Bragg's law: nλ = 2d sinθ, solving for sinθ = nλ / (2d).
Calculate θ = arcsin(nλ / (2d)) in degrees.
The final answer required is 2θ in degrees.
