Model a substitutional binary alloy using Vegard's law.
The alloy lattice parameter is a = 0.389 nm.
The lattice parameter of pure component A is a_A = 0.404 nm.
The lattice parameter of pure component B is a_B = 0.361 nm.
Apply Vegard's law: a = x_A * a_A + x_B * a_B, where x_A + x_B = 1.
Substitute x_A = 1 - x_B into the equation to get a = (1 - x_B) * a_A + x_B * a_B.
Rearrange to solve for x_B: x_B = (a_A - a) / (a_A - a_B).
Compute the numerator: a_A - a = 0.404 - 0.389 = 0.015 nm.
Compute the denominator: a_A - a_B = 0.404 - 0.361 = 0.043 nm.
Calculate x_B = 0.015 / 0.043 ≈ 0.349.
Calculate x_A = 1 - x_B ≈ 0.651.
Report the atomic fraction of component B as approximately 0.349 (34.9%) and component A as approximately 0.651 (65.1%).
