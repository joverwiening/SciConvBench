The material has a saturation magnetization M_s = 1.45×10^6 A/m.
The density is 7.87 g/cm³ (7870 kg/m³) and the atomic weight is 55.85 g/mol.
Use Avogadro's number N_A = 6.022×10^23 atoms/mol to calculate the number of atoms per unit volume: N = (density × N_A) / atomic weight.
Convert density to kg/m³ (7870 kg/m³) and atomic weight to kg/mol (0.05585 kg/mol) for consistent SI units.
Calculate N = (7870 × 6.022×10^23) / 0.05585, giving approximately 8.48×10^28 atoms/m³.
The magnetic moment per atom in A·m² is obtained by dividing M_s by N: m = M_s / N = 1.45×10^6 / 8.48×10^28.
This gives m ≈ 1.71×10^-23 A·m² per atom.
Convert to Bohr magnetons using 1 Bohr magneton μ_B = 9.274×10^-24 A·m².
Divide: number of Bohr magnetons per atom = 1.71×10^-23 / 9.274×10^-24 ≈ 1.84 μ_B per atom.
Report the final answer as approximately 1.84 Bohr magnetons per atom.
