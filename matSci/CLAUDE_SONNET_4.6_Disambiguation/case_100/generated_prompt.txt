Use Cu Kα radiation with wavelength λ = 1.5406 Å.
The diffraction peak occurs at 2θ = 44.7°, so θ = 22.35°.
Apply Bragg's law: nλ = 2d sinθ, with n = 1.
Calculate the interplanar spacing d = λ / (2 sinθ).
Compute sin(22.35°) = 0.3800 (approximately).
Calculate d = 1.5406 / (2 × 0.3800) = 2.027 Å.
The reflecting plane has Miller indices (hkl) = (110).
For a cubic crystal, the interplanar spacing is given by d = a / sqrt(h² + k² + l²).
For (110), sqrt(h² + k² + l²) = sqrt(1 + 1 + 0) = sqrt(2) = 1.4142.
Calculate the lattice parameter a = d × sqrt(2) = 2.027 × 1.4142 = 2.867 Å.
Report the lattice parameter as a ≈ 2.87 Å.
Note that this value is consistent with the known lattice parameter of body-centered cubic iron (α-Fe), which is approximately 2.87 Å.
