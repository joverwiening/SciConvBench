Use Bragg's law: nλ = 2d sin θ.
Set the order n to 1.
Set the wavelength λ to 0.20 nm.
Set the interplanar spacing d to 0.12 nm.
Solve for the angle θ: sin θ = (nλ) / (2d) = (1 * 0.20 nm) / (2 * 0.12 nm).
Calculate sin θ = 0.20 / 0.24 = 5/6.
Compute θ = arcsin(5/6).
