The X-ray wavelength is 0.0762 nm.
The crystal is cubic with a lattice parameter of 0.5313 nm.
The reflection is from the (111) family of planes.
The order of reflection, n, is 2.
Calculate the interplanar spacing, d, for the (111) planes using the formula for a cubic crystal: d = a / sqrt(h² + k² + l²), where a is the lattice parameter.
Substitute the values: d = 0.5313 nm / sqrt(1² + 1² + 1²) = 0.5313 nm / sqrt(3).
Compute the value of d.
Apply Bragg's Law: nλ = 2d sin θ, with n=2 and λ=0.0762 nm.
Solve for sin θ.
Calculate the Bragg angle, θ, in degrees.
Calculate the diffraction angle, 2θ, in degrees.
Report the final value of 2θ.
