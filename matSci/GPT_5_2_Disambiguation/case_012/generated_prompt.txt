Compute the number-average molecular weight using \(M_n=\frac{\sum_i N_i M_i}{\sum_i N_i}\).
Use the given pairs \((M_i, N_i)\): (56526, 96), (92809, 131), (115856, 153), (126029, 146), with \(M_i\) in g/mol.
Calculate \(\sum_i N_i = 96+131+153+146 = 526\).
Calculate \(\sum_i N_i M_i = 96\cdot56526 + 131\cdot92809 + 153\cdot115856 + 146\cdot126029 = 53,391,967\) g/mol.
Compute \(M_n = 53,391,967 / 526 = 101,505.64\) g/mol.
Report \(M_n \approx 1.015\times 10^5\) g/mol (about 101,506 g/mol).
