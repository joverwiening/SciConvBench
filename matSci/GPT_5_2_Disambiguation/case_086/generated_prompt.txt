Use the half-reaction Cu2+ + 2 e− ⇌ Cu(s) at 25°C.
Use the Nernst equation E = E° − (RT/nF) ln(Q).
Set n = 2.
Set Q = a(Cu)/a(Cu2+) = 1/a(Cu2+) because a(Cu(s)) = 1 for a pure solid.
Use E° = +0.340 V vs SHE.
Use a(Cu2+) = 0.010.
At 25°C, use (RT/F) = 0.025693 V so (RT/nF) = 0.0128465 V.
Compute E = 0.340 − 0.0128465 ln(1/0.010).
Compute ln(1/0.010) = ln(100) = 4.60517.
Compute E = 0.340 − 0.0128465 × 4.60517 = 0.2808 V.
Report the equilibrium potential as E ≈ +0.281 V vs SHE at 25°C for a(Cu2+) = 0.010.
