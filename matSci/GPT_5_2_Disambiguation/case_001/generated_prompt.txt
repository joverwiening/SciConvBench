Assume a body-centered cubic (BCC) structure with n = 2 atoms per unit cell.
Use the theoretical density relation ρ = (n A) / (N_A a^3).
Rearrange to solve for the lattice parameter: a = ((n A) / (ρ N_A))^(1/3).
Substitute n = 2, A = 129.68 g/mol, ρ = 14.368 g/cm^3, N_A = 6.022×10^23 mol^-1.
Compute a^3 = (2×129.68) / (14.368×6.022×10^23) cm^3 = 2.996×10^-23 cm^3.
Compute a = (2.996×10^-23)^(1/3) cm = 3.105×10^-8 cm.
Convert to nm using 1 cm = 10^7 nm to get a = 0.3105 nm.
