Assume the crystal structure is FCC.
Compute the number of atomic sites per unit volume using N = (density/atomic weight)·N_A.
Use density = 9.434 g/cm^3, atomic weight = 191.53 g/mol, and N_A = 6.022×10^23 mol^-1 to get N in sites/cm^3.
Convert vacancy formation energy to per-mole-of-vacancies in joules: Q_v = 121.4 kJ/mol = 121400 J/mol.
Compute the equilibrium vacancy fraction using n_v/N = exp(−Q_v/(R·T)).
Use R = 8.314 J/mol·K and T = 985 K.
Compute the equilibrium number of vacancies per cm^3 as n_v = N·exp(−Q_v/(R·T)).
Report the final estimate for n_v (vacancies/cm^3) and optionally the vacancy fraction n_v/N.
