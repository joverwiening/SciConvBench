Assume a semi-infinite steel solid with one-dimensional diffusion in the x-direction from the surface at x = 0.
Use constant surface concentration boundary condition C(0,t) = Cs = 0.95 wt% C for all t > 0.
Use initial condition C(x,0) = C0 = 0.20 wt% C for all x > 0.
Use the constant-surface-concentration error-function solution: (C(x,t) − Cs)/(C0 − Cs) = erf(x/(2√(Dt))).
Set the target condition C(x,t) = 0.40 wt% C at depth x = 0.80 mm = 8.0×10^-4 m.
Compute the normalized concentration ratio: (0.40 − 0.95)/(0.20 − 0.95) = 0.733333….
Solve erf(η) = 0.733333… for η, giving η ≈ 0.77 (since erf(0.77) ≈ 0.733).
Use η = x/(2√(Dt)) to solve for time: t = (x/(2η))^2 / D.
Substitute x = 8.0×10^-4 m, η ≈ 0.77, D = 1.6×10^-11 m^2/s to get t ≈ (8.0×10^-4/(2×0.77))^2 /(1.6×10^-11) ≈ 1.7×10^4 s.
Report the estimated carburizing time as t ≈ 1.7×10^4 s ≈ 4.7 h.
