Compute the linear density of atoms along the BCC close-packed [111] direction for a metal with lattice parameter a = 0.286 nm.
Use the definition linear density = (number of atom centers lying on the direction segment within one repeat distance) / (length of that segment).
Use the [111] direction segment across one unit cell from (0,0,0) to (1,1,1), whose length is a√3.
Count atom centers on this segment in BCC: one corner atom at each end contributes 1/2 + 1/2 = 1 atom total, and the body-centered atom at (1/2,1/2,1/2) contributes 1 atom, giving 2 atoms on the segment.
Compute linear density = 2 / (a√3).
Substitute a = 0.286 nm to obtain linear density = 2 / (0.286√3) nm⁻¹ ≈ 4.04 nm⁻¹.
Report the result as approximately 4.04 × 10^9 atoms/m if expressed in SI units.
