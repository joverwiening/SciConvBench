Assume a face-centered cubic (FCC) crystal structure with n = 4 atoms per unit cell.
Use the density relation ρ = (n A) / (N_A a^3).
Rearrange to a = ((n A) / (ρ N_A))^(1/3).
Use A = 85.15 g/mol, ρ = 13.931 g/cm^3, and N_A = 6.022×10^23 mol^-1.
Compute a^3 = (4 × 85.15) / (13.931 × 6.022×10^23) cm^3 = 4.061×10^-23 cm^3.
Compute a = (4.061×10^-23)^(1/3) cm = 3.437×10^-8 cm.
Convert to nm using 1 cm = 10^7 nm to get a = 0.3437 nm.
