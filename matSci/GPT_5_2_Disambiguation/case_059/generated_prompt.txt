Compute the critical fiber length for a short reinforcing fiber using the shear-lag relation \(l_c = \sigma_f d / (2\tau_c)\).
Use the given fiber tensile strength \(\sigma_f = 3926.6\) MPa directly, interpreted as the fiber ultimate tensile strength if needed.
Use the given fiber diameter \(d = 5.91\,\mu\text{m}\).
Use the given interfacial shear strength \(\tau_c = 14.22\) MPa.
Keep units consistent by using MPa for stresses and \(\mu\text{m}\) for diameter so the resulting \(l_c\) is in \(\mu\text{m}\).
Calculate \(l_c = (3926.6 \times 5.91) / (2 \times 14.22)\,\mu\text{m} = 816.2\,\mu\text{m}\) (approximately).
Report the final critical length as \(l_c \approx 8.16 \times 10^2\,\mu\text{m} \approx 0.816\,\text{mm}\).
