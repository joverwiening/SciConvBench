Use the model X = 1 − exp(−k t^n).
Set X = 0.848, k = 9.27×10^-5 s^-n, and n = 3.60.
Rearrange to exp(−k t^n) = 1 − X = 0.152.
Take natural logs to get −k t^n = ln(0.152), so t^n = −ln(0.152)/k.
Compute −ln(0.152) = 1.883874759.
Compute t^n = 1.883874759 / (9.27×10^-5) = 20322.16568.
Compute t = (20322.16568)^(1/3.60) = 15.74 s.
Report the required time as 15.74 seconds.
