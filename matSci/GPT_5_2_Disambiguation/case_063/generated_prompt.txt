Use the Hall–Petch relation σ_y = σ_0 + k_y d^(-1/2).
Set σ_y = 420 MPa, σ_0 = 120 MPa, and k_y = 0.74 MPa·m^(1/2).
Compute Δσ = σ_y − σ_0 = 300 MPa.
Solve for d^(-1/2) = Δσ / k_y = 300 / 0.74 = 405.405 m^(-1/2).
Invert to get d^(1/2) = 1 / 405.405 = 0.0024667 m^(1/2).
Square to get d = (0.0024667)^2 = 6.084×10^-6 m.
Convert to micrometers: d = 6.084×10^-6 m × 10^6 μm/m = 6.08 μm.
Report the estimated average grain diameter as d ≈ 6.1 μm.
