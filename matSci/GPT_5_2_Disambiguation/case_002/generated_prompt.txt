Use Bragg’s law for first order: nλ = 2 d sin θ with n = 1.
Compute the interplanar spacing for a cubic crystal: d = a / sqrt(h^2 + k^2 + l^2).
Use h = 3, k = 1, l = 1 so d = 0.4045 nm / sqrt(11) = 0.12197 nm.
Compute sin θ = λ / (2d) = 0.1172 / (2 × 0.12197) = 0.48045.
Compute θ = arcsin(0.48045) = 28.72°.
Report the diffraction angle 2θ = 57.44°.
