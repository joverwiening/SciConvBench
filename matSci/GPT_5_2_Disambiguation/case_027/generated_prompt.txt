Assume Arrhenius behavior: D = D0 exp(−Q/RT).
Use the two-point form: ln(D2/D1) = −Q/R (1/T2 − 1/T1).
Set D1 = 4.27×10^-15 m^2/s at T1 = 771 K.
Set D2 = 1.13×10^-11 m^2/s at T2 = 1233 K.
Compute ln(D2/D1) = ln(1.13×10^-11 / 4.27×10^-15) = ln(2646.37) = 7.881.
Compute (1/T2 − 1/T1) = (1/1233 − 1/771) = −4.864×10^-4 K^-1.
Solve Q = R ln(D2/D1) / (1/T1 − 1/T2) = 8.314×7.881 / (4.864×10^-4) = 1.346×10^5 J/mol.
Report the activation energy as Q ≈ 135 kJ/mol.
