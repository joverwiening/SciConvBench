Use saturation magnetization M_s = 1.45×10^6 A/m.
Use atomic number density n = 8.49×10^28 atoms/m^3.
Compute magnetic moment per atom as μ_atom = M_s / n in A·m^2 per atom.
Calculate μ_atom = (1.45×10^6) / (8.49×10^28) = 1.71×10^-23 A·m^2 per atom.
Use Bohr magneton μ_B = 9.274×10^-24 A·m^2.
Compute magnetic moment in Bohr magnetons per atom as μ_atom/μ_B.
Calculate μ_atom/μ_B = (1.71×10^-23) / (9.274×10^-24) = 1.85 μ_B per atom.
