Use Griffith fracture criterion for a central through-crack in an infinite plate: σ_f = sqrt((2Eγ_s)/(πa)).
Rearrange to solve for the half-crack length parameter: a = (2Eγ_s)/(πσ_f^2).
Use E = 240.3 GPa = 240.3×10^9 Pa.
Use γ_s = 2.576 J/m^2.
Use σ_f = 529.7 MPa = 529.7×10^6 Pa.
Compute a = (2×240.3×10^9×2.576)/(π×(529.7×10^6)^2) m = 1.403×10^-6 m.
Report the critical flaw size parameter as a = 1.403 μm.
