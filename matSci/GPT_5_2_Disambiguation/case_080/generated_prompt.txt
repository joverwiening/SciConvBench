Use the Nernst–Einstein relation σ = n z^2 e^2 D / (kB T).
Set n = 4.0×10^27 m^-3.
Set z = 1.
Use e = 1.602×10^-19 C.
Set D = 1.2×10^-11 m^2/s.
Use kB = 1.381×10^-23 J/K.
Set T = 800 K.
Compute σ = (4.0×10^27)(1^2)(1.602×10^-19)^2(1.2×10^-11)/((1.381×10^-23)(800)).
Report σ ≈ 1.11 S/m (≈ 0.0111 S/cm).
