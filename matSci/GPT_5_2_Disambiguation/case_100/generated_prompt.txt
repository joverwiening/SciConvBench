Use Cu Kα radiation wavelength λ = 1.5406 Å.
Use the measured diffraction angle 2θ = 44.7°.
Compute θ = 44.7° / 2.
Assume the peak is from the (110) reflection.
Assume the crystal is cubic and treat it as BCC for best practice consistency with (110) being the first allowed reflection.
Use Bragg’s law for first order diffraction: nλ = 2 d sin θ with n = 1.
Solve for interplanar spacing: d = λ / (2 sin θ).
Use the cubic d-spacing relation: d(hkl) = a / sqrt(h^2 + k^2 + l^2).
For (110), use sqrt(h^2 + k^2 + l^2) = sqrt(1^2 + 1^2 + 0^2) = sqrt(2).
Solve for lattice parameter: a = d sqrt(2).
Report the lattice parameter numerically as a ≈ 2.87 Å (≈ 0.287 nm).
