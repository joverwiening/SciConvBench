Use the theoretical density relation for cubic crystals: ρ = (n A) / (N_A a^3).
Use n = 4 for an FCC unit cell.
Use A = 197.35 g/mol, ρ = 7.754 g/cm^3, and N_A = 6.022×10^23 mol^-1.
Solve for a: a = ((n A) / (ρ N_A))^(1/3).
Compute a^3 = (4×197.35) / (7.754×6.022×10^23) cm^3 = 1.685×10^-22 cm^3.
Compute a = (1.685×10^-22)^(1/3) cm = 5.523×10^-8 cm.
Convert to nm using 1 cm = 10^7 nm.
Report a = 0.5523 nm.
