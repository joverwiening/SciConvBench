Estimate the effective thermal conductivity along the fibers using the rule of mixtures for a unidirectional composite in the longitudinal direction.
Use fiber volume fraction Vf = 0.55 and matrix volume fraction Vm = 0.45.
Use fiber thermal conductivity kf = 18 W/m·K.
Use matrix thermal conductivity km = 0.25 W/m·K.
Compute k_eff,‖ = Vf·kf + Vm·km.
Report the numerical result k_eff,‖ = 0.55·18 + 0.45·0.25 = 10.0125 W/m·K (≈ 10.01 W/m·K).
