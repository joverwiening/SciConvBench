Use X-ray wavelength λ = 0.0762 nm.
Use cubic lattice parameter a = 0.5313 nm.
Use the (111) lattice planes.
Compute the interplanar spacing for cubic crystals as d111 = a / sqrt(1^2 + 1^2 + 1^2) = a / sqrt(3).
Use first-order Bragg diffraction with n = 1.
Apply Bragg’s law nλ = 2 d111 sin θ, without any structure-factor selection rules.
Solve for θ = arcsin(λ / (2 d111)).
Report the diffraction angle as 2θ in degrees.
Numerically, d111 = 0.5313 / sqrt(3) = 0.3067 nm (approx).
Numerically, sin θ = 0.0762 / (2 × 0.3067) = 0.1242 (approx).
Numerically, θ = 7.13° (approx).
Numerically, 2θ = 14.26° (approx).
