Use Bragg’s law for first-order diffraction: nλ = 2d sin θ with n = 1.
Use the cubic interplanar spacing formula: d(hkl) = a / sqrt(h^2 + k^2 + l^2).
Set a = 0.5499 nm, λ = 0.0537 nm, and (hkl) = (211).
Compute sqrt(h^2 + k^2 + l^2) = sqrt(2^2 + 1^2 + 1^2) = sqrt(6).
Compute d = 0.5499 / sqrt(6) = 0.22445 nm.
Compute sin θ = λ / (2d) = 0.0537 / (2 × 0.22445) = 0.11962.
Compute θ = arcsin(0.11962) = 6.869°.
Report 2θ = 13.74°.
