The program receives a single English sentence as input.  
The program determines whether the sentence contains at least one common noun (a noun that is not a proper noun).  
If the sentence contains a common noun, the program outputs the character X.  
If the sentence does not contain any common noun, the program outputs the character Y.  
The program should perform case‑insensitive analysis and may use a part‑of‑speech tagger or a lexical list to identify common nouns.  
The output must be exactly a single character (X or Y) followed by a newline.
