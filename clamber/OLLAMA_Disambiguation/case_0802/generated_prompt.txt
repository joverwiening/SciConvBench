The program receives a single English sentence as input.  
It determines whether the sentence contains at least one proper noun.  
A proper noun is identified using a standard NLP library (e.g., spaCy) with part‑of‑speech tagging, falling back to a simple capitalization rule that treats any capitalized word not at the beginning of a sentence as a proper noun.  
If the sentence contains one or more proper nouns, the program outputs the single character X.  
If the sentence contains no proper nouns, the program outputs the single character Y.  
The output must consist of only the character X or Y followed by a newline.
