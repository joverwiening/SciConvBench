The task is to classify a given sentence as “X” if it contains at least one male pronoun and as “Y” if it does not.

Male pronouns to be considered are: he, him, his, himself. The detection is case‑insensitive and matches whole words only (e.g., “he” matches but “the” does not).

For each input sentence:
- Scan the sentence for any occurrence of the listed male pronouns.
- If any male pronoun is found, output “X”.
- If none are found, output “Y”.
