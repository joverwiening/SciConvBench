The program receives three input sentences: the first example sentence, the second example sentence, and the target sentence to evaluate.  
Each sentence follows the pattern “The <noun> is in the <phrase>.”  
The possible word categories are “outdoor location” and “animal”.  
The program must determine which single category is present in both example sentences.  
After identifying the shared category, the program checks the target sentence for any word that belongs to that category.  
If the target sentence contains at least one word from the identified category, output the single character X.  
If the target sentence does not contain any word from the identified category, output the single character Y.  
The output must be exactly one character (X or Y) with no additional text, spaces, or newline characters.
