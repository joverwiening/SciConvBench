The simulation will model steady-state, developing, laminar pipe flow.
The OpenFOAM solver to be used is simpleFoam.
The geometry is a 2D axisymmetric wedge with a 5-degree angle.
The pipe length is 1 meter.
The pipe radius is 0.01 meters.
The mesh will consist of 100 cells in the axial direction.
The mesh will consist of 20 cells in the radial direction.
The mesh grading in the radial direction is uniform.
The fluid's kinematic viscosity is 1e-6 m^2/s.
The inlet velocity boundary condition is a uniform fixed value of 0.1 m/s.
The outlet pressure boundary condition is a fixed value of 0.
The pipe wall velocity boundary condition is noSlip.
The wedge faces will use the wedge boundary condition.
The axis will use the empty boundary condition.
