The simulation domain is a square cavity with dimensions of 1 unit in x, 1 unit in y, and 0.1 units in z.
The simulation is transient, running from time 0 to 10 units.
The time step is 0.005 units.
Simulation results are written every 100 time steps.
The solver is pisoFoam.
The kinematic viscosity is constant at 1e-05 m^2/s.
The turbulence model is k-epsilon.
The velocity boundary condition for the top wall is a fixed value of (1 0 0) m/s.
The velocity boundary condition for the left, right, and bottom walls is a no-slip condition with a fixed value of (0 0 0) m/s.
The pressure boundary condition for all walls is fixedFluxPressure.
The boundary condition for the front and back patches is empty.
The initial value for turbulent kinetic energy (k) is 1.5e-4 m^2/s^2 uniformly throughout the domain.
The initial value for turbulent dissipation rate (epsilon) is 1.4e-4 m^2/s^3 uniformly throughout the domain.
The initial value for turbulent viscosity (nut) is 0 m^2/s uniformly throughout the domain.
The wall function for k is kqRWallFunction on all walls.
The wall function for epsilon is epsilonWallFunction on all walls.
The wall function for nut is nutkWallFunction on all walls.
The convection scheme for velocity is Gauss limitedLinearV 1.
The convection scheme for k is Gauss limitedLinear 1.
The convection scheme for epsilon is Gauss limitedLinear 1.
The viscous term scheme is Gauss linear.
