Simulate transient 3D turbulent Rayleigh-Benard convection at Ra = 1e8 (Boussinesq), using periodic lateral boundaries.

Solver: buoyantBoussinesqPimpleFoam

Geometry: 3D box with aspect ratio 4:4:1:
- Lx = 0.40 m
- Ly = 0.40 m
- H  = 0.10 m
Gravity in -z: g (0 0 -9.81)

Mesh: blockMesh (80 80 40) uniform. Patches:
- bottomHot (z=0)
- topCold (z=H)
- xMin cyclic <-> xMax cyclic
- yMin cyclic <-> yMax cyclic

Periodic pairing: define cyclic neighbourPatch pairs for xMin/xMax and yMin/yMax in the blockMesh boundary.

Target Ra:
Ra = g*beta*DeltaT*H^3/(nu*alpha).
Use water-like reference properties:
- nu = 1.0e-6 m^2/s
- alpha = 1.4e-7 m^2/s
- beta = 2.1e-4 1/K
With H=0.1 m, Ra=1e8 implies DeltaT ~ Ra*nu*alpha/(g*beta*H^3) ~ 6.8 K.
Set T_bottom = 300.0 K, T_top = 293.2 K, and T0 = 296.6 K.

Physical properties (constant/physicalProperties):
- nu = 1.0e-6
- Pr = nu/alpha ~ 7.14
- beta = 2.1e-4
- T0 = 296.6
- rho0 = 1000

Turbulence: RAS kOmegaSST in constant/momentumTransport (or LES if desired). Use wall functions on plates; cyclic on lateral boundaries.

Initial conditions:
- U = (0 0 0)
- p_rgh = 0
- T = linear interpolation between plates (or uniform T0).
Add a small perturbation using setFields (standard OpenFOAM), e.g., a small warm spot near the bottom center:
  boxToCell (0.19 0.19 0.00) to (0.21 0.21 0.01): set T (T0+0.05)

Boundary conditions:
- bottomHot: U noSlip; T fixedValue 300.0; p_rgh fixedFluxPressure
- topCold:   U noSlip; T fixedValue 293.2; p_rgh fixedFluxPressure
- x/y cyclic patches: cyclic for all fields

Time controls: endTime 30; deltaT 1e-3; adjustTimeStep yes; maxCo 0.9; writeInterval 0.5.
PIMPLE: nOuterCorrectors 2; nCorrectors 2; nNonOrthogonalCorrectors 0.
