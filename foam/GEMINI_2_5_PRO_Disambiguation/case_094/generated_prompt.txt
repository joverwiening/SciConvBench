The starting point is the OpenFOAM tutorial case located at `tutorials/heatTransfer/buoyantPimpleFoam/buoyantCavity`.
In the `constant/thermophysicalProperties` file, the thermal expansion coefficient `beta` is set to 2.9e-2 1/K.
In the `constant/momentumTransport` file, the `simulationType` is set to `RAS`.
In the `constant/momentumTransport` file, within the `RAS` sub-dictionary, the `RASModel` is set to `kOmegaSST`.
The initial condition file for turbulent kinetic energy, `0/k`, is created.
The internal field for `k` is set to `uniform 1e-6`.
The boundary condition for `k` on all wall patches is `kqRWallFunction` with a value of `uniform 1e-6`.
The initial condition file for specific dissipation rate, `0/omega`, is created.
The internal field for `omega` is set to `uniform 1`.
The boundary condition for `omega` on all wall patches is `omegaWallFunction` with a value of `uniform 1`.
The initial condition file for turbulent viscosity, `0/nut`, is created.
The internal field for `nut` is set to `uniform 0`.
The boundary condition for `nut` on all wall patches is `nutkWallFunction` with a value of `uniform 0`.
