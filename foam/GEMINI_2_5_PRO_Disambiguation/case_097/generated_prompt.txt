The simulation models 2D natural convection in a square cavity.
The fluid is air, modeled using the Boussinesq approximation.
The side length of the cavity is 1 meter.
The simulation is performed on a 3D mesh that is one cell thick in the z-direction.
The Rayleigh number is 1e5.
The Prandtl number is 0.71.
The thermal expansion coefficient is 0.00333 1/K, corresponding to a reference temperature of 300 K.
The kinematic viscosity is set to 0.002155 m^2/s to achieve the target Rayleigh number.
The thermal diffusivity is set to 0.003035 m^2/s to achieve the target Rayleigh number.
The gravitational acceleration vector is (0, -9.81, 0) m/s^2.
The left wall is a no-slip boundary with a fixed temperature of 310 K.
The right wall is a no-slip boundary with a fixed temperature of 290 K.
The top wall is a no-slip, adiabatic boundary.
The bottom wall is a no-slip, adiabatic boundary.
The front and back patches are of type 'empty' to enforce 2D flow.
The initial velocity field within the domain is zero.
The initial temperature field within the domain is 300 K.
The simulation should be run until a steady-state solution is reached.
