The simulation uses the pisoFoam solver.
The case is based on the standard cavity tutorial.
The target Reynolds number is 5000.
The lid velocity is set to 1 m/s.
The characteristic length of the domain is 1 meter.
The kinematic viscosity is set to 2e-4 m^2/s.
The RAS kEpsilon turbulence model is enabled.
The mesh is configured to achieve a target y+ value between 30 and 100.
The base mesh resolution is 100x100x1 cells.
The simulation runs until an end time of 50 seconds.
The maximum Courant number is set to 0.8.
