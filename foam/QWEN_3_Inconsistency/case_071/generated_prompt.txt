Use a mesh resolution of 120 cells in the x-direction and 80 cells in the y-direction.  
The domain length is 0.6 m, so the cell size in x will be 0.005 m.  
The domain height is 0.4 m, so the cell size in y will be 0.005 m.  
The simulation uses interFoam with a single block in blockMesh.  
The initial water column is defined in setFieldsDict for x < 0.15 m and y < 0.3 m.  
The rest of the domain is initialized as air.  
Phase properties for water and air are defined in transportProperties with standard values.  
Gravity is set to (0 0 -9.81) m/s² in the g file.  
Boundary conditions for U: noSlip on walls, pressureInletOutletVelocity on atmosphere, empty on front and back.  
Boundary conditions for p_rgh: fixedFluxPressure on walls, totalPressure on atmosphere, empty on front and back.  
Boundary conditions for alpha.water: zeroGradient on walls, inletOutlet on atmosphere, empty on front and back.  
The simulation runs for 2 seconds.
