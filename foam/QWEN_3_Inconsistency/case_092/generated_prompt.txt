Use the `rhoPimpleFoam` solver for the simulation.
Simulate the compressible, supersonic flow of air over a 10-degree wedge to form an oblique shock.
Set the freestream Mach number to 2.0.
Treat air as a perfect gas.
Use a 2D mesh extruded one cell in the z-direction with `frontAndBack` boundary condition set to `empty`.
Set freestream/inlet conditions: `U = (686 0 0) m/s`, `T = 293 K`, `p = 101325 Pa`.
In `constant/thermophysicalProperties`, use `hePsiThermo`, `equationOfState perfectGas`, and `transport sutherland`.
Set inlet boundary condition: fixed values for `U`, `p`, and `T`.
Set outlet boundary condition: `waveTransmissive` for `p` and `T`, and `zeroGradient` for `U`.
Set wedge surface and top boundary as slip walls.
Set `frontAndBack` boundaries to `empty`.
In `system/controlDict`, set the application to `rhoPimpleFoam`.
