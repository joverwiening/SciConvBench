Set up a 2D dam-break simulation with a water column collapsing into air with a sharp free surface.
Use a 2D mesh extruded by one cell in the spanwise direction.
Set the front and back patches to type `empty`.
Track the interface between water and air using the VOF field `alpha.water`.
Initialize the water column using `setFields` to set `alpha.water = 1` inside the initial column and `alpha.water = 0` elsewhere.
Set gravity to `(0 -9.81 0)`.
Apply no-slip boundary condition for velocity `U` on tank walls.
Apply zero gradient boundary condition for `p_rgh` on tank walls.
Apply zero gradient boundary condition for `alpha.water` on tank walls.
Apply pressureInletOutletVelocity boundary condition for `U` on the open top.
Apply totalPressure or fixedValue (0) boundary condition for `p_rgh` on the open top.
Apply inletOutlet boundary condition for `alpha.water` on the open top with inletValue set to uniform 0.
Set the application in `system/controlDict` to `interFoam`.
