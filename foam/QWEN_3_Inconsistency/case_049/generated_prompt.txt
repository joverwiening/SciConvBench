Set up a 2D simulation of incompressible, laminar flow over an airfoil using `simpleFoam`.
Extrude the mesh one cell in the z-direction.
Use the patch name `frontAndBack` for the out-of-plane faces.
In `constant/polyMesh/boundary`, set the `frontAndBack` patch type to wall.
In `0/U`, set the `frontAndBack` boundary condition type to slip.
Use velocityInlet for the inlet boundary condition in `0/U`.
Use zeroGradient for the outlet boundary condition in `0/U`.
Use noSlip for the airfoil surface boundary condition in `0/U`.
