Assume the initial height of the water column is 0.5 meters, which is a common choice for dam break simulations to allow sufficient space for the wave propagation and splashing.

 
Set up a 2D dam break simulation using the interFoam solver for a two-phase (water-air) system.
The domain is 2 meters long and 1 meter high, with a single cell in the z-direction.
Gravity is defined in 'constant/g' as (0 -9.81 0).
In 'blockMeshDict', the front and back patches are defined as 'frontAndBack' with type wall.
In the '0' directory, for all fields (U, p_rgh, alpha.water), the 'frontAndBack' patches are assigned the 'noSlip' boundary condition for velocity and 'zeroGradient' for scalars.
The initial water column is defined using setFieldsDict with a height of 0.5 meters.
The water is initially located in the leftmost 0.5 meters of the domain.
The simulation uses a structured mesh with sufficient resolution to capture the interface dynamics.
The interface between water and air is captured using the Volume of Fluid (VOF) method implemented in interFoam.
Initial conditions are set with zero velocity throughout the domain.
The top boundary is set as a pressure outlet with atmospheric pressure for p_rgh and zeroGradient for alpha.water.
The left and right vertical walls are treated as no-slip walls for velocity and wall-adhesive for alpha.water.
The bottom boundary is a no-slip wall for velocity and zeroGradient for p_rgh and alpha.water.
