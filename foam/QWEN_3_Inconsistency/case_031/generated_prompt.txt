Set up a 2D incompressible laminar flow simulation using the icoFoam solver.  
Define the channel geometry as 0.5 m long in the x-direction and 0.1 m high in the y-direction.  
Make the domain one cell thick in the z-direction within blockMeshDict.  
Define patches in blockMeshDict: inlet, outlet, topWall, bottomWall, and frontAndBack.  
Set the frontAndBack patches to type wall.  
Model Poiseuille flow by applying a parabolic velocity profile at the inlet.  
Set the maximum inlet velocity to 1 m/s at the centerline of the inlet.  
Use zeroGradient boundary condition for velocity at the outlet.  
Apply noSlip boundary condition for velocity on topWall and bottomWall.  
Apply noSlip boundary condition for velocity on frontAndBack patches.  
In the 0/p file, set fixedValue 0 for pressure at the outlet.  
Set zeroGradient boundary condition for pressure on all other patches, including inlet, topWall, bottomWall, and frontAndBack.
