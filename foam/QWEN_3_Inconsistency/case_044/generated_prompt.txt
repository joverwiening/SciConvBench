Use a uniform grid with 200 cells in the x-direction and 200 cells in the y-direction.  
Set the domain length to 1 meter in both x and y directions.  
Initialize a water column in the region 0 < x < 0.2 and 0 < y < 0.5 with alpha.water = 1.  
Set alpha.water = 0 in the remaining domain.  
Apply gravity as g (0 -9.81 0) in the constant/g file.  
Set the top boundary as pressureInletOutletVelocity for both velocity and pressure.  
Set all side and bottom boundaries as noSlip walls.  
Use the interFoam solver to simulate the 2D dam break.  
Use setFieldsDict to initialize the alpha.water field according to the specified water column.
