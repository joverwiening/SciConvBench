Set up a steady-state simulation for laminar, incompressible flow over a backward-facing step using the simpleFoam solver.
The domain has an inlet on the left and an outlet on the right.
The fluid enters the domain at the 'inlet' patch and exits at the 'outlet' patch.
All wall boundaries (stepWall and topWall) are assigned a no-slip condition.
The front and back patches are of type 'empty' to enforce 2D simulation.
The velocity at the inlet is set to fixedValue uniform (0.5 0 0).
The velocity at the outlet is set to fixedValue uniform (0.5 0 0).
The velocity boundary condition for stepWall and topWall is noSlip.
The velocity boundary condition for frontAndBack is empty.
The pressure at the inlet is set to fixedValue uniform 0.
The pressure at the outlet is set to fixedValue uniform 0.
The pressure at stepWall, topWall, and frontAndBack is set to zeroGradient.
The simulation uses the simpleFoam solver for steady-state incompressible flow.
