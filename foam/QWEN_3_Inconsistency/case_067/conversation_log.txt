Q: What should the velocity value be at the inlet boundary, since "zeroGradient" alone is not sufficient to define the inlet flow velocity?
A: The inlet boundary condition should be fixedValue with a velocity of uniform (0.5 0 0).

Q: What should the boundary condition be for pressure at the inlet and outlet patches?
A: For pressure (p):

inlet  
{  
    type            fixedValue;  
    value           uniform 0;  
}  
outlet  
{  
    type            fixedValue;  
    value           uniform 0;  
}  

All other boundaries (stepWall, topWall, frontAndBack) should be zeroGradient.
