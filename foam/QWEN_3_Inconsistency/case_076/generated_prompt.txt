Set up a 2D square cavity for a steady-state natural convection simulation.  
Use the `buoyantBoussinesqSimpleFoam` solver.  
Define the left wall as hot with a temperature of 310 K.  
Define the right wall as cold with a temperature of 290 K.  
Set the top and bottom walls as adiabatic.  
Apply gravity in the -y direction with g = (0 -9.81 0).  
Use air as the working fluid.  
In `constant/thermophysicalProperties`, set `thermoType` to `heRhoThermo`.  
Set `mixture` to `pureMixture`.  
Set `transport` to `const`.  
Set `thermo` to `hConst`.  
Set `equationOfState` to `perfectGas`.  
Set `specie` to `hConst`.  
Set `energy` to `sensibleEnthalpy`.  
Set molecular weight to 28.9 g/mol.  
In `constant/transportProperties`, set dynamic viscosity `mu` to 1.8e-5 Pa·s.  
Set Prandtl number `Pr` to 0.7.  
In the `0/T` file, set the left wall boundary condition to `fixedValue uniform 310`.  
In the `0/T` file, set the right wall boundary condition to `fixedValue uniform 290`.  
In the `0/T` file, set the top and bottom walls to `zeroGradient`.  
In the `0/U` file, apply `noSlip` boundary condition on all walls.  
In the `0/p_rgh` file, apply `fixedFluxPressure` boundary condition on all walls.
