Use the `buoyantPimpleFoam` solver for a 2D simulation of heat transfer in a channel with a heated block.
The fluid is air and the flow is laminar.
The channel walls are adiabatic and must be modeled with a `zeroGradient` boundary condition for temperature.
The inlet has a fixed velocity and a fixed temperature of 300 K.
The outlet has a zeroGradient boundary condition for temperature.
The heated block is maintained at a constant temperature of 400 K.
In the `0/T` file, set `inlet { type fixedValue; value uniform 300; }`.
In the `0/T` file, set `outlet { type zeroGradient; }`.
In the `0/T` file, set `block { type fixedValue; value uniform 400; }`.
In the `0/T` file, set `walls { type zeroGradient; }`.
