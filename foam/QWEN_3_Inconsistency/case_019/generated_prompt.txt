Set up a 2-D opposed-jet laminar counter-flow diffusion flame in a rectangular domain from x = 0 to 0.02 m, y = -0.01 to 0.01 m, and z = -0.01 to 0.01 m.  
Discretize the domain with 100 cells in the x-direction, 40 cells in the y-direction, and 1 cell in the z-direction.  
Name the boundary at x = 0 as fuel and the boundary at x = 0.02 as air.  
Name the top and bottom boundaries as outlet, and set the front and back boundaries as empty.  
Inject pure methane (CH4) at the fuel inlet with a mass fraction of CH4 equal to 1.0.  
Set the fuel inlet temperature to 293 K and the fuel inlet velocity to 0.1 m/s.  
Supply air at the air inlet with a mass fraction of O2 equal to 0.23 and N2 equal to 0.77.  
Set the air inlet temperature to 293 K and the air inlet velocity to -0.1 m/s.  
Initialize the entire domain with a uniform temperature of 2000 K at time zero.  
Use incompressible finite-rate chemistry with the thermophysical model heRhoThermo.  
Select the mixture model as coefficientWilkeMultiComponentMixture.  
Use Sutherland transport model for viscosity.  
Use JANAF thermodynamics for species properties.  
Set the chemistry solver to EulerImplicit with the ODE solver Rosenbrock43.  
Model combustion using laminar finite-rate kinetics with no turbulence.  
Neglect momentum transport effects other than laminar diffusion.  
Use the reactingFoam solver for transient simulation.  
Set the time step to 1e-4 seconds.  
Run the simulation until the end time of 0.5 seconds.  
Write simulation results every 0.05 seconds.  
Apply second-order central differencing for pressure and temperature fields.  
Apply second-order upwind schemes for velocity and species concentration fields.
