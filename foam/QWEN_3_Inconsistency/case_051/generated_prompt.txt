Use a 2D rectangular domain with a length of 1.0 m and a diameter of 0.1 m.  
Mesh the domain using blockMesh with 100 cells in the axial (x) direction and 20 cells in the radial (y) direction.  
Set the front and back patches to type empty.  
Set the inlet boundary condition to a fixed velocity of (0.1 0 0) m/s.  
Set the outlet boundary condition to zeroGradient for velocity and fixed pressure of 0.  
Apply noSlip boundary conditions on the wall.  
Use the icoFoam solver for transient simulation.  
Run the simulation from t=0 to t=5 s.  
Define the fluid as a Bingham plastic in constant/transportProperties.  
Set transportModel to BinghamPlastic.  
Set rho to 1000 kg/m³.  
Set tau0 to 10 Pa.  
Set mu0 to 0.1 Pa·s.  
Set muInf to 0.01 Pa·s.
