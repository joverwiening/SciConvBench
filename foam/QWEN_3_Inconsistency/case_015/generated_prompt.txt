Run a 2D inviscid laminar oblique-shock simulation in a rectangular channel extruded one cell in the z-direction.  
The domain extends from (0, 0, 0) to (4.1, 1, 0.1).  
Use a mesh with 60 cells in the x-direction, 30 cells in the y-direction, and 1 cell in the z-direction.  
Set the front and back patches to empty.  
Define the boundaries as follows: left face as inlet, right face as outlet, top face as wall, and bottom face as symmetryPlane.  
Use the simpleFoam solver.  
Set the momentum transport model to laminar with inviscid properties: viscosity = 0, Prandtl number = 1.  
Use an ideal gas model with molecular weight = 11640.3, Cp = 2.5, and heat of formation Hf = 0.  
Initialize the velocity field U to (2.9 0 0), pressure p to 1, and temperature T to 1 throughout the domain.  
At the inlet, set U = (2.9 0 0), p = 1, and T = 1.  
At the top wall, set the velocity to (2.61933 -0.50632 0) and temperature T = 1.25853.  
Set the time step deltaT to 0.0025.  
Run the simulation until endTime = 10.  
Set writeInterval to 1 to output results every 1 simulation time unit.  
The oblique shock is generated by the prescribed tangential and normal velocity components at the top wall, not by wall inclination.  
The top wall is horizontal and aligned with the x-axis.
