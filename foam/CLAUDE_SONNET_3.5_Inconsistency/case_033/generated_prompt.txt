The domain is 1m x 1m x 0.01m with 50 cells in both x and y directions, and 1 cell in z direction.
Create a blockMeshDict with six patches: left, right, top, bottom, and frontAndBack (front and back faces).
Set frontAndBack patches to type wall.
In 0/T file, set left wall temperature to fixedValue of 400 K.
In 0/T file, set right wall temperature to fixedValue of 300 K.
In 0/T file, set top and bottom walls to zeroGradient.
In 0/T file, set frontAndBack patches to zeroGradient.
Set maximum simulation time to 1000 seconds to ensure steady-state.
Set writeInterval to 100 seconds for result output.
Use laplacianFoam solver for the simulation.
Set initial internal field temperature to 300 K.
Use SIMPLE algorithm for pressure-velocity coupling.
Set convergence criteria to 1e-6 for temperature residuals.
