The simulation uses simpleFoam solver for steady-state, laminar, incompressible flow over a backward-facing step.
The step height H is 0.01 meters.
The computational domain extends 20H (0.2 meters) upstream and 40H (0.4 meters) downstream of the step.
The channel height is 2H (0.02 meters) above the step.
The inlet velocity is uniform (0.5 0 0) m/s.
The kinematic viscosity is set to 1e-5 m²/s to achieve a Reynolds number of 500 based on step height.
The simulation runs until convergence, typically 1000 seconds.
The boundary conditions for velocity (0/U) are:
inlet: type fixedValue, value uniform (0.5 0 0)
outlet: type zeroGradient
stepWall: type noSlip
topWall: type noSlip
frontAndBack: type empty
The pressure boundary conditions (0/p) are:
inlet: type zeroGradient
outlet: type fixedValue, value uniform 0
stepWall: type zeroGradient
topWall: type zeroGradient
frontAndBack: type empty
