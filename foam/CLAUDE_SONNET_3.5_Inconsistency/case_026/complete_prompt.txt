Set up a steady-state, incompressible, turbulent flow simulation for the Pitz and Daily combustor case using the simpleFoam solver. The geometry is 2D. The turbulence modeling approach will be Reynolds-Averaged Navier-Stokes (RANS) using the standard k-Epsilon model. The turbulence properties are defined in `constant/turbulenceProperties` as follows:

```
simulationType RAS;

RAS
{
    RASModel        kEpsilon;
    turbulence      on;
    printCoeffs     on;
}
```

Boundary conditions for velocity `U` are a fixed inlet velocity of (10 0 0) m/s at the `inlet`, a zero-gradient condition at the `outlet`, and no-slip walls for `upperWall` and `lowerWall`. The front and back patches are of type `empty`. The pressure `p` is set to `zeroGradient` at the inlet and walls, and a fixed value of 0 at the outlet. The simulation should run for 500 iterations.
