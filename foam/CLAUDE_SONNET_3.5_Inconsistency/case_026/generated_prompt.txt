The simulation will use air at standard conditions with kinematic viscosity of 1.5e-5 m²/s.
The inlet height is set to 0.01 m as a typical laboratory-scale combustor dimension.
The inlet turbulence intensity is set to 5% (moderate turbulence level).
The inlet turbulent length scale is set to 7% of the inlet height (0.0007 m).
The mesh consists of 100,000 hexahedral cells with refinement near walls to achieve y+ < 30.
The simulation uses the simpleFoam solver for steady-state, incompressible, turbulent flow.
The turbulence model is k-epsilon RAS with coefficients set to OpenFOAM defaults.
The inlet velocity is fixed at (10 0 0) m/s.
The outlet has zero-gradient velocity condition.
The walls have no-slip velocity condition.
The pressure is zero at outlet and zero-gradient at inlet and walls.
Front and back patches are set to empty type for 2D simulation.
Solution tolerances are set to 1e-4 for U, k, and epsilon, and 1e-5 for p.
The simulation runs for 500 iterations.
The results are considered converged when residuals fall below specified tolerances.
Monitor points will be set up at key locations to track convergence.
All solution variables are initialized with reasonable values to promote stability.
The SIMPLE algorithm parameters (relaxation factors) are set to default OpenFOAM values.
