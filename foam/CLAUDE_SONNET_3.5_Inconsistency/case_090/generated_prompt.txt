The domain is a rectangular channel 40D x 20D (40m x 20m), with the cylinder center located at (10m, 10m).
The mesh consists of 200 cells across the cylinder diameter with grading toward the cylinder surface.
Use blockMesh to create the base mesh and snappyHexMesh to refine around the cylinder.
The kinematic viscosity is 0.01 m^2/s.
The inlet velocity is uniform at (1 0 0) m/s.
The cylinder diameter is 1 m.
The inlet boundary uses fixedValue for velocity.
The outlet boundary uses zeroGradient for velocity and fixedValue (0) for pressure.
The top and bottom boundaries use slip conditions.
The cylinder surface uses no-slip conditions.
The front and back boundaries use empty conditions for 2D simulation.
Initialize the velocity field to (1 0 0) m/s and pressure to 0.
Use the simpleFoam solver with PIMPLE algorithm for transient simulation.
Set the time step to 0.1 seconds.
Run the simulation from t=0 to t=200 seconds.
Write output every 1 second for post-processing.
Monitor force coefficients on the cylinder for Strouhal number calculation.
Use second-order discretization schemes for spatial and temporal terms.
Set convergence criteria of 1e-6 for all equations.
Enable runtime calculation of force coefficients using forceCoeffs function object.
