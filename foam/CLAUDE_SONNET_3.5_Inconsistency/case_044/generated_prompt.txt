The domain is 1m x 1m with a 100 x 100 uniform mesh resolution.
The simulation runs for 2 seconds total time.
Initialize a water column in region 0 < x < 0.2 and 0 < y < 0.5 using setFieldsDict.
Set alpha.water to 1 in the water column region and 0 elsewhere.
Set acceleration due to gravity as g (0 0 -9.81) in constant/g file.
Use interFoam solver for two-phase flow simulation.
Apply pressureInletOutletVelocity boundary condition on the top boundary.
Apply noSlip boundary condition on all other boundaries (bottom, left, right).
The simulation models water column collapse under gravity.
Write results at 0.1 second intervals for post-processing.
