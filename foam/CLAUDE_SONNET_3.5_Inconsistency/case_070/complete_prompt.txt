Set up a 2D simulation of natural convection in a tall, sealed cavity, where the left wall is hot and the right wall is cold. The top and bottom walls are adiabatic. Use the buoyantBoussinesqSimpleFoam solver. Gravity acts in the negative y-direction. The fluid is air.

Boundary conditions for temperature 'T' should be:

leftWall
{
    type            fixedValue;
    value           uniform 350;
}
rightWall
{
    type            fixedValue;
    value           uniform 300;
}
topWall
{
    // This wall is adiabatic
    type            zeroGradient;
}
bottomWall
{
    // This wall is also adiabatic
    type            zeroGradient;
}
