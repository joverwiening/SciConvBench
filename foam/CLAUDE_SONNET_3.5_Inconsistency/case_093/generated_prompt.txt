The domain is 0.6m wide by 0.4m high.
The initial water column is 0.2m wide by 0.3m high, positioned at the left side of the domain.
Create a uniform hexahedral mesh with cell size of 0.005m (resulting in 9600 cells).
Set initial time step deltaT to 0.001s.
Set maxCo to 0.5 in the controlDict.
Set endTime to 5s in the controlDict.
Use the pimpleFoam solver.
Set gravity to (0 -9.81 0) m/s².
Use setFields to initialize alpha.water = 1 in the region x < 0.2m and y < 0.3m.
Set alpha.water = 0 in the remaining domain for air.
In transportProperties, set water properties: density = 998 kg/m³, kinematic viscosity = 1e-6 m²/s.
In transportProperties, set air properties: density = 1.2 kg/m³, kinematic viscosity = 1.48e-5 m²/s.
Enable adjustable time step with adjustTimeStep yes in controlDict.
Write output every 0.1s using writeInterval 0.1.
