Simulate buoyancy-driven heat transfer in a 2D channel using `buoyantPimpleFoam`. The bottom wall is heated to 400 K (`fixedValue`), and the top wall is adiabatic (zero heat flux). Initialize the air at 300 K. Gravity acts in the negative y-direction.

In `0/T`, set:
```foam
bottomWall
{
    type            fixedValue;
    value           uniform 400;
}

topWall
{
    type            zeroGradient;
}
```
