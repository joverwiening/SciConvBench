The channel has dimensions of 0.1 m width and 0.5 m height.
The initial velocity field is set to 0 m/s in all directions.
The operating pressure is set to 101325 Pa (atmospheric pressure).
The bottom wall temperature is fixed at 400 K using fixedValue boundary condition.
The top wall uses zeroGradient boundary condition for temperature.
The side walls use empty boundary condition for all fields.
The initial temperature field is uniform 300 K.
Gravity is set to -9.81 m/s² in the y-direction.
The simulation runs for 30 seconds to achieve steady-state natural convection.
Air properties are calculated using the incompressible ideal gas law for buoyancy.
The PIMPLE algorithm is used for pressure-velocity coupling.
The time step is automatically adjusted to maintain a maximum Courant number of 1.0.
