The right wall temperature is fixed at 290 K.
The top and bottom walls are adiabatic (zeroGradient).
Gravity acts in the negative y-direction: g = (0 -9.81 0) m/s².
The fluid medium is air.

Set transport to const.
Set thermo to hConst.
Set equationOfState to perfectGas.
Set specie to hConst.
Set energy to sensibleEnthalpy.
Set molecular weight to 28.9 g/mol.
Set kinematic viscosity (mu) to 1.8e-5 m²/s in constant/transportProperties.
