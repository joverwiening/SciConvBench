The simulation will use the following specifications:
The geometry is a NACA 0012 airfoil in a 2D configuration with 1 meter chord length.
The angle of attack is set to 5 degrees.
The freestream velocity is set to 50 m/s.
The Reynolds number is set to 1 million, typical for subsonic airfoil analysis.
The simulation uses the steady-state simpleFoam solver.
The turbulence model is k-omega SST.
The domain is quasi-2D with a single cell layer in the z-direction.
The frontAndBack patches are set to wall type in constant/polyMesh/boundary.
The frontAndBack boundary conditions are noSlip for velocity (U) and zeroGradient for pressure (p).
The flow is incompressible.
The kinematic viscosity is set to 5e-5 m²/s to match the Reynolds number.
The inlet turbulence intensity is set to 1%.
The inlet turbulent viscosity ratio is set to 10.
