The computational domain extends 1m upstream and 5m downstream of the nozzle exit, with a height of 3m.
The inlet nozzle has a height of 0.2m.
The mesh contains approximately 100,000 cells with refinement near the nozzle exit and in the shear layer regions.
The simulation uses a RANS approach with the k-omega SST turbulence model.
The simulation runs for 0.1 seconds with a time step of 1e-6 seconds to ensure CFL < 1.
Wall boundaries use the slip condition for an inviscid approximation.
The inlet conditions are: U = (686 0 0) m/s, T = 300 K, p = 101325 Pa.
Far-field/outlet conditions use waveTransmissive for p and T, zeroGradient for U.
The thermophysical model uses hePsiThermo with perfectGas equation of state and sutherland transport model.
The solver application is pimpleFoam.
The mesh is 2D with one cell thickness in z-direction using frontAndBack empty boundary conditions.
Local mesh refinement is applied in regions of high velocity gradients and shock waves.
The simulation uses second-order discretization schemes for spatial terms.
The pressure-velocity coupling uses the PIMPLE algorithm with 2 outer correctors.
