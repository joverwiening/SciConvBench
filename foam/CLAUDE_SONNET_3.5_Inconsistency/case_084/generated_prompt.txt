Set up a two-phase Euler-Euler gas-solid riser simulation using twoPhaseEulerFoam solver.
The riser geometry is cylindrical with height 10 m and diameter 0.2 m.
Use air as the continuous phase and catalyst particles as the dispersed phase.
Set catalyst particle diameter to 100 microns (0.0001 m).
Set catalyst particle density to 1500 kg/m³.
Set inlet air velocity to 5 m/s.
Set inlet catalyst volume fraction (alpha.catalyst) to 0.01.
Set inlet air volume fraction (alpha.air) to 0.99 to ensure phase fractions sum to 1.
Use pressureInletOutletVelocity boundary condition at the outlet.
Apply k-epsilon turbulence model for both phases.
Run the simulation for 10 seconds of flow time.
Initialize the domain with zero velocity and alpha.catalyst = 0.
Initialize the domain with alpha.air = 1 everywhere except at the inlet.
Set gravity to -9.81 m/s² in the vertical direction.
Use first-order implicit time discretization for stability.
Enable phase-coupled SIMPLE (PIMPLE) algorithm for pressure-velocity coupling.
