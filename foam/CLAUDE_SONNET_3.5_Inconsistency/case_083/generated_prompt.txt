Create initial field files in the 0/ directory for a three-phase settling tank simulation.
Set uniform initial volume fraction of 0.5 in alpha.sediment, alpha.water, and alpha.oil files.
Set wall boundary conditions to zeroGradient for all volume fraction fields.
Set inlet and outlet boundary conditions to fixedValue for volume fractions.
Create a rectangular settling tank with dimensions 5m length x 2m width x 3m height.
Configure the stratified layers with sediment 0-0.5m, water 0.5-2.0m, and oil 2.0-3.0m from bottom.
Set the internalField uniform 0.5 in each alpha file as a starting condition.
Create setFieldsDict to establish the stratified layers.
The sum of volume fractions must equal 1.0 at every point in the domain.
Apply phase ordering based on density: sediment at bottom, water in middle, oil at top.
