The cylinder diameter D is set to 0.1 meters.
The inlet velocity U is set to 1.5 m/s.
The kinematic viscosity ν is set to 0.001 m²/s to achieve Re = 150.
The domain extends 8D upstream, 25D downstream, and 8D to each side of the cylinder.
The mesh is structured with refinement near the cylinder.
The boundary conditions are: inlet (fixed velocity), outlet (zero gradient), top/bottom (symmetry), cylinder (no-slip wall).
The simulation uses PIMPLE algorithm for pressure-velocity coupling.
The time step is adaptive with maximum Courant number of 0.9.
The simulation runs for 200 seconds with results written every 1 second.
The expected Strouhal number at Re = 150 is approximately 0.18.
Monitor points should be placed in the wake region to capture vortex shedding frequency.
Use second-order discretization schemes for momentum equations.
Use linear-upwind schemes for divergence terms.
The pressure equation uses the GAMG solver with DIC smoother.
The velocity equations use the smoothSolver with symGaussSeidel smoother.
