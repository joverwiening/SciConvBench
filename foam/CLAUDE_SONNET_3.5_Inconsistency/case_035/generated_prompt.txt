The inlet velocity is set to 1 m/s in the positive x direction.
The cylinder diameter is set to 0.1 meters.
The kinematic viscosity is set to 0.001 m²/s to achieve a Reynolds number of 100.
The simulation domain extends 8 diameters upstream, 20 diameters downstream, and 8 diameters to each side of the cylinder.
The frontAndBack patches must be changed to type 'empty' in constant/polyMesh/boundary.
The frontAndBack boundary condition in 0/U must be changed to type 'empty'.
The inlet boundary uses fixedValue with uniform (1 0 0).
The outlet boundary uses zeroGradient.
The cylinderWall uses noSlip condition with uniform (0 0 0).
The simulation uses PIMPLE algorithm with nOuterCorrectors 1 and nCorrectors 2.
The simulation runs from t = 0 to t = 100 seconds with adjustable timestep and maxCo = 0.5.
Initial conditions are set to uniform (1 0 0) for velocity and uniform 0 for pressure.
