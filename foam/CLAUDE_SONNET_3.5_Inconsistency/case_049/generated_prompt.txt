Use a NACA 0012 airfoil profile for the simulation.
Set the chord length to 1 meter.
Set the angle of attack to 5 degrees.
Set the inlet velocity to 1 m/s in the x-direction.
Use air as the working fluid (kinematic viscosity = 1.5e-5 m²/s).
The resulting Reynolds number is 66,667.
Create a C-type mesh with domain extending 10 chord lengths upstream and downstream.
Set the domain height to 20 chord lengths.
Extrude the 2D mesh one cell (0.1 meters) in the z-direction.
Apply slip boundary condition on frontAndBack patches.
Set inlet boundary with fixed velocity of 1 m/s.
Set outlet boundary with zero gradient pressure condition.
Set no-slip condition on the airfoil surface.
Initialize the flow field with uniform velocity of 1 m/s.
Set reference pressure to 0 at the outlet.
Use SIMPLE algorithm for pressure-velocity coupling.
Set first-order upwind discretization for initial solution.
Run simulation until residuals drop below 1e-4.
