The simulation uses buoyantSimpleFoam solver for a steady-state buoyant flow in a solar chimney.
The chimney dimensions are 10 meters in height and 2 meters in diameter, following typical research-scale dimensions.
The bottom surface is heated to 350K, representing moderate solar heating.
Air properties are defined using the Boussinesq approximation with TRef = 300K, beta = 0.00333, and rhoRef = 1.176 kg/m³.
The specific heat capacity (Cp) is 1005 J/kgK.
The dynamic viscosity (mu) is 1.8e-05 kg/ms.
The Prandtl number (Pr) is 0.7.
Gravity effects are included via the constant/g file.
The molecular weight of air is set to 28.9 g/mol.
The thermodynamic model uses hePsiThermo with Boussinesq equation of state.
The reference enthalpy of formation (Hf) is set to 0 J/kg.
