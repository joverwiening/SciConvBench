Set reference temperature T0 to 300K in constant/transportProperties.
Set kinematic viscosity nu to 1.5e-5 m²/s in constant/transportProperties.
Set gravity vector to (-9.81 0 0) in constant/g.
Apply fixedValue T=310K boundary condition on bottom wall (z=0).
Apply fixedValue T=300K boundary condition on top wall (z=0.1m).
Set periodic boundary conditions on all side walls.
Apply noSlip boundary condition for velocity U on top and bottom walls.
Initialize temperature field with linear gradient from 310K at bottom to 300K at top.
Run simulation for 100 seconds to allow proper development of convection cells.
