The simulation domain is 1.0 m × 0.1 m × 0.1 m aluminum block.
Material properties are E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m^3.
Create a structured hexahedral mesh with element size of 0.005 m (approximately 20 elements per smallest domain dimension).
Initialize displacement field D with (1e-6 0 0) m in a thin region near x = 0, and (0 0 0) elsewhere using setFields.
Apply traction-free boundary conditions on all external faces using tractionDisplacement with zero traction and pressure.

Set time step size (deltaT) to 1e-6 s to ensure numerical stability.
Use pimpleFoam solver as specified.
Write output every 1e-5 s (writeInterval = 100) for visualization.
