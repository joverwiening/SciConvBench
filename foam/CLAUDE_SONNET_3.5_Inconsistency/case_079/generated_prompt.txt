The domain is a 2D rectangle with width 0.1 m and height 0.1 m.
The total simulation time is 300 seconds to allow full development of convection cells.
The mesh consists of 100 cells in both x and y directions (10,000 total cells) for adequate resolution.
The bottom wall temperature is fixed at 305 K.
The top wall temperature is fixed at 295 K.
The side walls are adiabatic.
All walls use no-slip boundary conditions for velocity.
The fluid is water with properties at 300 K reference temperature.
Use buoyantPimpleFoam solver.
Set thermoType hePsiThermo in constant/thermophysicalProperties.
Set equationOfState Boussinesq in constant/thermophysicalProperties.
Use div(phi,T) Gauss linear for temperature divergence scheme.
Use div(rhoPhi,U) Gauss upwind for velocity divergence scheme.
Initial conditions are fluid at rest (U = 0) at 300 K uniform temperature.
The simulation uses PIMPLE algorithm with 2 outer correctors and 1 inner corrector.
The time step is 0.1 seconds with adjustable timestep based on max Courant number of 0.5.
Write output every 1 second for post-processing.
