Create a 2D fluid-structure interaction simulation of a flexible flap in a channel with the following specifications:

Set inlet boundary condition to fixedValue with uniform velocity (1 0 0) m/s.
Set outlet boundary condition to fixedValue with pressure p = 0.
Apply noSlip condition on channel walls.
The flap material is linear elastic with Young's modulus 1e6 Pa, Poisson ratio 0.45, and density 1200 kg/m³.
Fix the displacement at the flap base.
Use coupled interface boundary condition on the flap surface.
Use pimpleFoam as a single solver for both fluid and solid domains on a combined mesh.
Run the simulation for 10 seconds to allow for flow development and flap oscillation stabilization.
