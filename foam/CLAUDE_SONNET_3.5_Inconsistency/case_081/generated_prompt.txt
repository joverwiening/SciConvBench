The domain is a 2D rectangle with dimensions 0.5 m width x 2.0 m height.
The mesh resolution is 100 x 400 cells (50,000 total cells).
The solver used is twoPhaseEulerFoam.
The simulation runs for 30 seconds of physical time.
Results are saved every 0.1 seconds.
The two phases are air and water.
The inlet boundary conditions for air are: volume fraction = 0.8, velocity = (0 0.2 0) m/s.
The inlet boundary conditions for water are: volume fraction = 0.2, velocity = (0 0.01 0) m/s.
The top boundary is an outlet.
The side boundaries are no-slip walls.
The alpha.air file specifies fixedValue type with uniform value 0.8 at inlet.
The alpha.water file specifies fixedValue type with uniform value 0.2 at inlet.
The simulation is transient (time-dependent).
