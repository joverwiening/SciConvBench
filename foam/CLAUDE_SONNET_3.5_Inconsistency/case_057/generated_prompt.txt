The simulation domain is a 2D bubble column with dimensions 0.5m x 2m.
Use twoPhaseEulerFoam solver for the simulation.
The continuous phase is water and the dispersed phase is air.
Set the mesh resolution to 50 cells in x-direction and 200 cells in y-direction for adequate accuracy.
Set the air inlet velocity at the bottom boundary to 0.1 m/s, which is typical for bubble column operations.
Initialize the domain using setFieldsDict with two regions.
The bottom 1.5m region contains a mixture of 40% air and 70% water volume fractions.
The top 0.5m region contains a mixture of 90% air and 10% water volume fractions.
The simulation uses the provided setFieldsDict configuration file without modifications.
Note: The volume fractions in the bottom region sum to 110%, which is physically impossible but will be normalized by the solver.
