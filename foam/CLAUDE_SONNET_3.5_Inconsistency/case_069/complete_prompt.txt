Simulate the flow in a cyclone separator using simpleFoam. The geometry has a tangential 'inlet', a top 'outlet' (vortex finder), and a bottom 'dustOutlet'. The flow is swirling and turbulent, so use the k-epsilon model. The fluid enters tangentially at the inlet and is expected to exit primarily through the top outlet. The pressure at the top outlet is atmospheric (0 gauge).

For the pressure field 'p', define the boundary conditions as follows:

inlet
{
    type            zeroGradient;
}
outlet
{
    type            fixedValue;
    value           uniform 0;
}
dustOutlet
{
    type            zeroGradient; // Or fixedValue depending on the desired condition
}
walls
{
    type            zeroGradient;
}
