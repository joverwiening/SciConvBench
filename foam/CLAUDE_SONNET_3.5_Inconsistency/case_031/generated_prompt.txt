Create a case directory with standard OpenFOAM structure (0, constant, system folders).
Use blockMesh to create a rectangular channel mesh with dimensions 0.5 m × 0.1 m × 0.01 m.
Set the number of cells to 100 in x-direction and 40 in y-direction for adequate resolution.
Set the mesh thickness to 1 cell (0.01 m) in z-direction.
Define patches in blockMeshDict: inlet, outlet, topWall, bottomWall, and frontAndBack.
Set frontAndBack patches as type wall.
Use icoFoam solver for incompressible laminar flow simulation.
Set kinematic viscosity (nu) to 1e-6 m²/s in constant/transportProperties.
In 0/U file, specify:
Inlet: parabolic velocity profile with maximum 1 m/s at centerline
Outlet: zeroGradient
TopWall: noSlip condition
BottomWall: noSlip condition
FrontAndBack: noSlip condition
In 0/p file, specify:
Inlet: zeroGradient
Outlet: fixedValue uniform 0
TopWall: zeroGradient
BottomWall: zeroGradient
FrontAndBack: zeroGradient
