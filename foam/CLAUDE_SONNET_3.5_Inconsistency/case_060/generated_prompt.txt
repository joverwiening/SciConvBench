Create a 2D dam break simulation with the following specifications:
Set up a rectangular domain of 0.6m width by 0.4m height.
Create an initial water column of 0.2m width by 0.2m height in the left side of the domain.
Use a uniform mesh with cell size of 0.005m (resulting in 120x80 cells).
Set the domain depth (z-direction) to one cell thickness of 0.005m.
Apply empty boundary condition on front and back patches.
Set simulation end time to 1.0 seconds.
Use twoPhaseEulerFoam as the solver application.
Initialize alpha.water as 1 in the water column region and 0 elsewhere using setFields.
Set gravity to -9.81 m/s² in the y-direction.
Use water properties: density = 1000 kg/m³, kinematic viscosity = 1e-6 m²/s.
Use air properties: density = 1.225 kg/m³, kinematic viscosity = 1.48e-5 m²/s.
Apply wall boundary conditions on bottom and sides.
Apply atmosphere boundary condition at the top.
