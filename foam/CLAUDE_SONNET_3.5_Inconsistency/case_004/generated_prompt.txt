The simulation uses a 2D gas-liquid bubble column with multiphaseEulerFoam in OpenFOAM.
The domain is rectangular with dimensions 0.15 m × 1.00 m × 0.10 m, oriented with height along +y direction.
The mesh is structured hexahedral with 25 × 75 × 1 cells using simpleGrading (1 1 1).
The domain has inlet, outlet, walls, and frontAndBack boundary patches.
The frontAndBack faces in z direction are set as wall boundary.
The continuous liquid phase (water) uses heRhoThermo with rPolynomial equation of state.
Water properties: C coefficients (0.001278 -2.1055e-06 3.9689e-09 4.3772e-13 -2.0225e-16), MW 18, Cv 4195, viscosity 3.645e-4 Pa·s, Pr 2.289.
The dispersed gas phase (air) uses heRhoThermo with perfectGas equation of state.
Air properties: MW 28.9, Cp 1007, viscosity 1.84e-05 Pa·s, Pr 0.7.
Gravity is set to (0 -9.81 0) m/s².
Bubble size models: isothermal diameter 3e-3 m for air, constant diameter 1e-4 m for water.
Both phases use laminar momentum transport.
Phases are defined as (air water) with water as reference phase and residualAlpha 1e-6.
Blending uses linear scheme with minFullyContinuousAlpha 0.7 and minPartlyContinuousAlpha 0.3 (0.5 for drag).
Surface tension coefficient is 0.07.
Drag model uses SchillerNaumann for all configurations.
Virtual mass uses constantCoefficient with Cvm 0.5 for both directions.
Heat transfer uses RanzMarshall model with residualAlpha 1e-4 for both directions.
Initial conditions at t=0: water velocity (0 0 0), air velocity (0 0.1 0), water volume fraction 1, p_rgh 1e5, air temperature 300, water temperature 350.
Phase distribution uses default values (air=1, water=0) except in box (0 0 0) to (0.15 0.701 0.1) where air=0, water=1.
Inlet boundary conditions: air velocity (0 0.1 0), water velocity (0 0 0), air fraction 0.5, water fraction 0.5, air temperature 300, water temperature 350.
Wall boundary conditions: both velocities (0 0 0), both volume fractions zeroGradient, p_rgh fixedFluxPressure, both temperatures zeroGradient.
Outlet boundary conditions: both velocities inletOutlet, both volume fractions inletOutlet, p_rgh fixedValue 1e5, both temperatures inletOutlet.
Time controls: startTime 0, endTime 20 s, deltaT 0.005 s, adjustTimeStep no, maxCo 0.5, maxDeltaT 1, writeInterval 1 s.
