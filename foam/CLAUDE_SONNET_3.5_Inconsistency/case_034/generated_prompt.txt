Create a 2D dam break simulation with the following specifications:
The domain is 2m long and 1m high with a single cell thickness in z-direction.
Set gravity as (0 -9.81 0) in constant/g.
Use blockMesh to create a mesh with 100 cells in x-direction and 50 cells in y-direction.
Define front and back patches as 'frontAndBack' with type wall in blockMeshDict.
Set initial water column dimensions as 0.5m wide by 0.5m high, positioned at the left side of the domain.
In the 0 directory, set boundary conditions for U, p_rgh, and alpha.water fields:
Set frontAndBack patches to noSlip for velocity.
Set frontAndBack patches to zeroGradient for scalar fields.
Use setFieldsDict to initialize the water column in the specified dimensions.
Use interFoam solver for the two-phase simulation.
Set remaining domain space as air phase.
Set left and right sides of domain as walls with standard wall boundary conditions.
Set top and bottom of domain as walls with standard wall boundary conditions.
