The simulation setup is a 2D, steady-state, incompressible, turbulent flow over a NACA0012 airfoil.
The chord length is set to 1 meter as a reference length.
The freestream velocity is 10 m/s in the x-direction.
The kinematic viscosity is set to 1.5e-5 m²/s (standard air at room temperature).
This gives a Reynolds number of approximately 6.67e5, which is appropriate for turbulent airfoil flow.
Use the simpleFoam solver for incompressible, turbulent flow.
Implement the k-omega SST turbulence model.
Create a C-grid type domain, one cell thick in the z-direction.
The mesh is defined in constant/polyMesh.
Set boundary conditions for inlet patch: U = fixedValue uniform (10 0 0), k and omega calculated from 1% turbulence intensity and viscosity ratio 10, p = zeroGradient.
Set boundary conditions for outlet patch: U = inletOutlet, k = inletOutlet, omega = inletOutlet, p = fixedValue uniform 0.
Set boundary conditions for airfoil patch: U = noSlip, k = kqRWallFunction, omega = omegaWallFunction, p = zeroGradient.
Set boundary conditions for frontAndBack patches: type = wall, U = noSlip, p = zeroGradient, k = zeroGradient, omega = zeroGradient.
Set the angle of attack to 5 degrees.
