The simulation will use a horizontal gravity separator with the following specifications:
The separator vessel dimensions are 2.0 m length, 0.5 m width, and 0.5 m height.
The fluid properties are set as follows: water (density=998 kg/m³, viscosity=0.001 Pa·s), oil (density=850 kg/m³, viscosity=0.02 Pa·s), gas (density=1.225 kg/m³, viscosity=1.84e-5 Pa·s).
The solver is set to interFoam in controlDict.
The simulation time is set to 30 seconds to ensure complete phase separation.
Gravity is set to (0 -9.81 0) m/s².
The initial condition is a stratified mixture defined in setFieldsDict.
The phases are tracked using the VOF method with alpha.water representing water volume fraction.
The domain is initialized with three regions of equal height (gas at top, oil in middle, water at bottom).
The time step is automatically adjusted to maintain a maximum Courant number of 0.5.
The simulation uses second-order spatial discretization schemes.
The pressure-velocity coupling uses the PIMPLE algorithm.
The results are written every 0.1 seconds for post-processing.
The boundary conditions are set to no-slip walls with zero gradient for pressure.
