The cylinder diameter is set to 0.1 m (standard benchmark size).
The computational domain extends 10D upstream, 20D downstream, and 10D laterally from the cylinder center.
The mesh is structured O-grid type with refinement near the cylinder wall.
The first cell height achieves y+ ≈ 1 for wall-resolved LES.
The simulation runs for 1 second of flow time.
The initial time step is set to 1e-5 seconds to maintain CFL < 1.
The inlet boundary uses fixedValue for velocity (10 m/s), temperature (300 K), and turbulence properties.
The outlet boundary uses zeroGradient for velocity and temperature, fixedValue for pressure (101325 Pa).
The cylinder surface uses noSlip for velocity, fixedValue for temperature (500 K), and zeroGradient for pressure.
The k-omega SST model is used with standard model coefficients.
The fluid is air modeled as a perfect gas using hePsiThermo thermophysical model.
Sutherland's law is used for transport properties.
The Boussinesq approximation coefficients are set with TRef=300 K, beta=0.00333, and rhoRef=1.225 kg/m³.
The PIMPLE algorithm uses 2 outer correctors and 1 inner corrector.
The simulation uses second-order schemes for spatial and temporal discretization.
