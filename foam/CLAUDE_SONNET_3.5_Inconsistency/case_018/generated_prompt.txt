The domain is a 2D opposed-jet configuration with the following specifications:
Domain dimensions are x: [0, 0.02] m, y: [-0.01, 0.01] m, z: [-0.01, 0.01] m.
Mesh consists of 100 cells in x, 40 cells in y, and 1 cell in z direction.
FrontAndBack patches are set to empty boundary condition.
Left patch (x=0) is fuel inlet with methane at 293 K.
Right patch (x=0.02) is air inlet with O2/N2 mixture at 293 K (Y_O2 = 0.23, balance N2).
Top and bottom patches are outlets with fixed pressure of 101325 Pa.
Fuel inlet velocity is 0.1 m/s in +x direction.
Air inlet velocity is 0.1 m/s in +x direction.
Initial temperature field is set to 2000 K throughout the domain.
Initial pressure field is set to 101325 Pa throughout the domain.
Inlet patches use fixed total pressure of 101325 Pa.
Chemistry solver is set to EulerImplicit with Rosenbrock43 ODE solver.
Flow is laminar with momentum transport.
Thermophysical model uses hePsiThermo with coefficientWilkeMultiComponentMixture.
Transport properties use Sutherland model.
Thermodynamic properties use JANAF tables.
Time step is set to 1e-4 seconds.
End time is 0.5 seconds.
Results are written every 0.05 seconds.
