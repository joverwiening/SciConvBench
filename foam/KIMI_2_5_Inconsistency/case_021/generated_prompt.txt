The simulation is a 2D, incompressible, steady-state airflow over a symmetric airfoil using the simpleFoam solver.

The domain topology is a C-grid around the airfoil.

The mesh has a thickness of exactly one cell in the z-direction.

In the system/blockMeshDict file, the frontAndBack patch is defined as a wall type with the specified face connectivity.

The frontAndBack patch uses the wall type to enforce 2D behavior.

In the 0/U file, the inlet boundary condition is a fixedValue uniform (10 0 0) m/s.

In the 0/U file, the outlet boundary condition is zeroGradient.

In the 0/U file, the airfoil surface boundary condition is noSlip.

In the 0/U file, the frontAndBack patches use noSlip boundary conditions.

In the 0/p file, the inlet boundary condition is zeroGradient.

In the 0/p file, the airfoil surface boundary condition is zeroGradient.

In the 0/p file, the outlet boundary condition is fixedValue uniform 0.

In the 0/p file, the frontAndBack patches use zeroGradient boundary conditions.
