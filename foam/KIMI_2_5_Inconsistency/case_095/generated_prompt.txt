Set up a 2D, steady-state, incompressible, turbulent simulation of airflow over a NACA0012 airfoil at a 5-degree angle of attack.
Use the simpleFoam solver with the k-omega SST turbulence model.
The domain should be a C-grid type, one cell thick in the z-direction.
The mesh is defined in `constant/polyMesh`.
The boundary patches are `inlet`, `outlet`, `airfoil`, and `frontAndBack`.
The `inlet` patch has velocity `U` set to `fixedValue` uniform (10 0 0).
The `inlet` patch has turbulent kinetic energy `k` calculated from turbulence intensity 1% and viscosity ratio 10.
The `inlet` patch has specific dissipation rate `omega` calculated from turbulence intensity 1% and viscosity ratio 10.
The `inlet` patch has pressure `p` set to `zeroGradient`.
The `outlet` patch has velocity `U` set to `inletOutlet`.
The `outlet` patch has turbulent kinetic energy `k` set to `inletOutlet`.
The `outlet` patch has specific dissipation rate `omega` set to `inletOutlet`.
The `outlet` patch has pressure `p` set to `fixedValue` uniform 0.
The `airfoil` patch has velocity `U` set to `noSlip`.
The `airfoil` patch has turbulent kinetic energy `k` set to `kqRWallFunction`.
The `airfoil` patch has specific dissipation rate `omega` set to `omegaWallFunction`.
The `airfoil` patch has pressure `p` set to `zeroGradient`.
The `frontAndBack` patches have their type set to `wall` in `constant/polyMesh/boundary`.
The `frontAndBack` patches have velocity `U` set to `noSlip`.
The `frontAndBack` patches have pressure `p` set to `zeroGradient`.
The `frontAndBack` patches have turbulent kinetic energy `k` set to `zeroGradient`.
The `frontAndBack` patches have specific dissipation rate `omega` set to `zeroGradient`.
