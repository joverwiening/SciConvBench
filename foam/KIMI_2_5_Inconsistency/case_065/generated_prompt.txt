Simulate transient elastic wave propagation in a solid aluminum block using solidDisplacementFoam.

The domain is a rectangular block with dimensions 1.0 m × 0.1 m × 0.1 m.

The material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, and density rho = 2700 kg/m^3.

Initialize the displacement field D using setFields with a small pulse: set D = (1e-6 0 0) m in a thin region 0.0 m ≤ x ≤ 0.05 m near the left boundary, and D = (0 0 0) m elsewhere in the domain.

Apply traction-free boundary conditions on all six external faces using tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0.

Use solidDisplacementFoam as the application in system/controlDict.

Set the endTime to 2.0e-3 seconds to capture multiple wave reflections across the domain.

Set deltaT to 1.0e-6 seconds to satisfy the CFL condition based on the longitudinal wave speed.

Assume a characteristic pulse wavelength of 0.1 m based on the smallest domain dimension, which corresponds to a frequency of approximately 50 kHz for the longitudinal wave mode.

Use a mesh with at least 20 elements per wavelength in the propagation direction (x-direction), resulting in a uniform hexahedral mesh with 200 × 20 × 20 cells.

Set writeControl to adjustableRunTime and writeInterval to 2.0e-5 seconds to capture the wave propagation with adequate temporal resolution.

Set the numerical scheme for d2dt2 to Euler implicit and for grad(D) to Gauss linear.

Set the linear solver for D to GAMG with tolerance 1e-7 and relTol 0.01 for efficient solution of the sparse system.
