Set up a laminar counter-flow diffusion flame simulation using reactingFoam in a 2-D opposed-jet configuration.

The domain spans x = 0 to 0.02 m, y = -0.01 to 0.01 m, and z = -0.01 to 0.01 m.

Use a mesh with 100 grid points in x, 40 in y, and 1 cell in z.

The left boundary at x = 0 is named fuel.

The right boundary at x = 0.02 m is named air.

The top and bottom boundaries at y = -0.01 m and y = 0.01 m are named outlet.

The frontAndBack faces in z are empty.

At the fuel inlet, set velocity to 0.1 m/s in the positive x-direction, temperature to 293 K, and mass fractions to Y_CH4 = 1.0, Y_O2 = 0.0, Y_N2 = 0.0.

At the air inlet, set velocity to -0.1 m/s in the negative x-direction, temperature to 293 K, and mass fractions to Y_O2 = 0.23, Y_N2 = 0.77, Y_CH4 = 0.0.

At the outlet boundaries, use zeroGradient for velocity and pressure, and zeroGradient for temperature and mass fractions.

Initialize the domain at time 0 with temperature T = 2000 K throughout.

Initialize the domain at time 0 with pressure p = 101325 Pa (1 atm) uniformly throughout.

Initialize the domain at time 0 with velocity field U = 0 m/s (stagnant) throughout.

Initialize the domain at time 0 with mass fractions Y_CH4 = 0.0, Y_O2 = 0.23, Y_N2 = 0.77 throughout (air composition).

Use chemistry type EulerImplicit.

Use ODE solver Rosenbrock43 for chemistry integration.

Use combustion model laminar.

Use momentum transport laminar (no turbulence model).

Use thermophysical model hePsiThermo.

Use mixture model coefficientWilkeMultiComponentMixture.

Use transport model Sutherland.

Use thermodynamics model JANAF.

Set dynamic viscosity mu = 0 Pa·s everywhere to represent an inviscid flame.

Use the reactingFoam solver.

Set timestep deltaT = 1e-4 s.

Set endTime = 0.5 s.

Set writeInterval = 0.05 s for results output.

Use chemical mechanism GRI-Mech 3.0 for methane-air combustion kinetics.

Set reference pressure pRef = 101325 Pa.

Set gravitational acceleration g = (0, 0, 0) m/s² (neglect gravity).
