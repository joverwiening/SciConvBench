Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity in OpenFOAM.

The beam geometry is 1 m long, 0.1 m high, and 0.1 m wide (depth).

One end named `fixed` is clamped with boundary condition `fixedValue uniform (0 0 0)`.

The free end named `loaded` has a downward traction load with boundary condition `tractionDisplacement` using `traction uniform (0 -1000 0)` and `pressure uniform 0`.

All other faces use `zeroGradient` boundary condition.

Material properties in `constant/mechanicalProperties` are steel with Young's modulus `E = 200e9` Pa and Poisson ratio `nu = 0.3`.

The mesh resolution is 100 cells in the length direction, 10 cells in the height direction, and 10 cells in the width direction, creating a structured hexahedral mesh with 10000 total cells.

In `system/controlDict`, set `application` to `solidDisplacementFoam` (corrected from `pimpleFoam` for linear elasticity), `endTime` to 1, and `deltaT` to 0.01 for quasi-static simulation with 100 time steps.

Use first-order Euler implicit time integration scheme.

Write the simulation case files including `constant/mechanicalProperties`, `0/D`, `system/controlDict`, `system/fvSchemes`, `system/fvSolution`, and `constant/polyMesh/blockMeshDict`.

Run the simulation and extract the vertical displacement at the free end (`loaded` patch).

Compare the numerical result against the analytical Euler-Bernoulli beam theory prediction for maximum deflection at the free end.
