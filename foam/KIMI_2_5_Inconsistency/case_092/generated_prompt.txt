Simulate compressible, supersonic flow of air over a 10-degree wedge to form an oblique shock using rhoPimpleFoam.

Freestream conditions: Mach number 2.0, U = (686 0 0) m/s, T = 293 K, p = 101325 Pa.

Treat air as a perfect gas with thermophysical properties configured in constant/thermophysicalProperties using hePsiThermo, equationOfState perfectGas, and transport sutherland.

Use a 2D mesh extruded one cell in z-direction with frontAndBack boundaries set to empty.

Set application to rhoPimpleFoam in system/controlDict.

Configure boundary conditions as follows: inlet uses fixedValue for U, p, and T; outlet uses waveTransmissive for p and T with zeroGradient for U; wedge surface and top boundary use slip wall; frontAndBack uses empty.

Use laminar turbulence model (no turbulence model) as the simulation involves a sharp oblique shock where laminar assumption is standard for validation cases and the shock structure is primarily inviscid.
