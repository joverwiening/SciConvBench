The simulation models 2D developing laminar flow in a channel using the bottom half of the geometry with a symmetry plane at the centerline.

The domain geometry uses a channel half-height of 0.005 m and a length of 0.5 m, giving an aspect ratio of 100 to ensure fully developed flow is captured.

The working fluid is air with kinematic viscosity nu = 1.5e-5 m^2/s.

The Reynolds number based on full channel height is Re = 100, corresponding to a mean inlet velocity of 0.3 m/s.

The mesh is generated with blockMesh using the blockMeshDict file.

The centerline patch uses type symmetry in blockMeshDict.

The frontAndBack patches use type empty in blockMeshDict.

The inlet patch uses a fixedValue boundary condition for velocity with uniform value (0.3 0 0) m/s and zeroGradient for pressure.

The outlet patch uses a zeroGradient boundary condition for velocity and fixedValue for pressure with uniform value 0 Pa.

The bottomWall patch uses a noSlip boundary condition for velocity and zeroGradient for pressure.

The centerline patch uses a symmetry boundary condition for velocity and symmetry for pressure in the 0/U and 0/p files.

The simpleFoam solver is used for steady-state incompressible flow.

The simulation is run until residuals fall below 1e-6 or convergence stalls.
