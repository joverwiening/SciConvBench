Simulate the transient start-up flow of a Bingham plastic fluid in a 2D pipe using the nonNewtonianIcoFoam solver.

The domain is a rectangle with length 1.0m and height 0.1m (representing pipe diameter).

Generate the mesh using blockMesh with 100 cells in the axial (x) direction and 20 cells in the radial (y) direction.

Set the front and back patches to type empty to enforce a 2D simulation.

Apply the following boundary conditions: inlet with fixed velocity (0.1 0 0) m/s, outlet with zeroGradient for velocity and fixed pressure 0, and noSlip walls.

Configure the simulation to run from t=0 to t=5s with appropriate time step control for stability.

In constant/transportProperties, set the transport model to BinghamPlastic with rho 1000, tau0 10, mu0 0.1, and muInf 0.01.

Do not specify a constant kinematic viscosity nu; instead rely on the BinghamPlastic model to compute effective viscosity dynamically from the strain rate-dependent relationship.

Use nonNewtonianIcoFoam as the solver, not icoFoam, since icoFoam does not support non-Newtonian viscosity models.
