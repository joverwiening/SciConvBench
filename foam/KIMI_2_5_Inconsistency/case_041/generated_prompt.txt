Set up a 2D laminar, incompressible flow simulation past a cylinder at Reynolds number 100 to capture the time-dependent von Kármán vortex street using OpenFOAM.

Use `pimpleFoam` as the solver in `system/controlDict`.

Set the simulation time parameters: `startTime` to 0, `endTime` to 8, `deltaT` to 0.005, `writeInterval` to 0.1, enable `adjustTimeStep` to yes, and set `maxCo` to 0.9.

Define the computational domain as a rectangular channel with length 2.2 m and height 0.41 m, with the cylinder of diameter 0.1 m centered at coordinates (0.2, 0.2).

Set the fluid properties with kinematic viscosity of 1e-3 m²/s and uniform inlet velocity U = (1 0 0) m/s, which yields the target Reynolds number of 100 based on cylinder diameter.

Create a 2D mesh that is one cell thick in the z-direction.

Configure velocity boundary conditions in the `0/U` file: set `inlet` to `fixedValue uniform (1 0 0)`, `outlet` to `zeroGradient`, `cylinderWall` to `noSlip`, `topAndBottom` to `noSlip`, and `frontAndBack` to `empty`.

Configure pressure boundary conditions in the `0/p` file: set `inlet` to `zeroGradient`, `outlet` to `fixedValue uniform 0`, `cylinderWall` to `zeroGradient`, `topAndBottom` to `zeroGradient`, and `frontAndBack` to `empty`.

Run the simulation to capture the time-dependent vortex shedding phenomenon and obtain the unsteady flow field showing the von Kármán vortex street.
