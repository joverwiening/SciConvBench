The simulation models a high-speed compressible supersonic jet using OpenFOAM with the following specifications.

The domain geometry extends 20 nozzle diameters downstream (1.0 m) and 10 nozzle diameters radially (0.5 m) from the nozzle centerline, with the nozzle exit located at the origin. The nozzle exit diameter is 0.05 m (50 mm). The mesh is 2D extruded one cell in the z-direction with frontAndBack boundaries set to empty. The mesh uses structured hexahedral cells with refinement near the nozzle lip and shear layer, with cell sizes approximately D/50 near the nozzle exit (1 mm) and gradual coarsening to D/10 (5 mm) at far-field boundaries.

The working fluid is air treated as a perfect gas with thermophysical properties configured in constant/thermophysicalProperties using hePsiThermo, equationOfState perfectGas, and transport sutherland with standard coefficients.

Boundary conditions are specified as follows. The nozzle inlet uses fixedValue for U = (686 0 0) m/s, fixedValue for p = 101325 Pa, and fixedValue for T = 300 K representing supersonic inflow. The far-field and outlet boundaries use waveTransmissive for p and T with zeroGradient for U to allow acoustic wave passage. Solid walls use noSlip for viscous simulations or slip for inviscid approximation.

The solver application in system/controlDict is set to rhoPimpleFoam (compressible transient solver) rather than pimpleFoam, as pimpleFoam is incompressible and inappropriate for Mach 2.0 flow. The simulation uses adjustable time step with maximum CFL = 0.8. The initial time step is 5e-7 s. The total simulation duration is 3 ms with writeInterval set to capture 100-200 time steps for post-processing. The endTime is 0.003 s.

Initial conditions set the entire domain to quiescent flow with U = (0 0 0), p = 101325 Pa, and T = 300 K, allowing the jet to develop naturally from startup.
