Set up a 2D dam-break simulation using the interFoam solver with the following specifications.

Create a 2D mesh extruded one cell in the z-direction with frontAndBack patches set to empty.

Define the computational domain as a tank with overall dimensions 0.6 m width by 0.45 m height. Initialize a water column with dimensions 0.146 m width by 0.292 m height positioned at the left wall of the tank.

Set gravity to (0 -9.81 0) m/s^2 in the constant/g file.

Configure the VOF field alpha.water to track the air-water interface. Initialize alpha.water to 1 inside the water column region (x < 0.146 m and y < 0.292 m) and 0 elsewhere using the setFields utility with an appropriate setFieldsDict.

Apply the following boundary conditions:

For the tank bottom and side walls (left, right walls):
- U: noSlip
- p_rgh: zeroGradient
- alpha.water: zeroGradient

For the open top boundary:
- U: pressureInletOutletVelocity with inletValue uniform (0 0 0) and value uniform (0 0 0)
- p_rgh: totalPressure with p0 uniform 0, or alternatively fixedValue uniform 0
- alpha.water: inletOutlet with inletValue uniform 0 and value uniform 0

Set the initial time step to 0.001 seconds with adjustableTimeStep enabled. Limit the maximum Courant number to 0.5 for stability, with a maximum time step of 0.05 seconds.

Set the simulation end time to 2.0 seconds to capture the initial collapse and sloshing phases of the dam-break.

Configure system/controlDict with application interFoam, startFrom startTime, startTime 0, stopAt endTime, endTime 2.0, deltaT 0.001, and writeControl adjustableRunTime with writeInterval 0.05.

Use the standard interFoam solver settings with PIMPLE algorithm, appropriate relaxation factors, and interface compression for sharp interface capturing.
