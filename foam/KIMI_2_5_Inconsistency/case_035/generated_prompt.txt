Configure a 2D simulation of flow past a cylinder using pimpleFoam for a transient, incompressible, laminar case.

The mesh is one cell thick in the z-direction.

In constant/polyMesh/boundary, set the frontAndBack patches to type empty.

In 0/U, set the frontAndBack patches to type empty.

Set the inlet boundary condition to type fixedValue with value uniform (U_inf 0 0), where U_inf is the freestream velocity magnitude.

Set the outlet boundary condition to type zeroGradient for velocity.

Set the cylinderWall boundary condition to type noSlip.

Set the top and bottom boundaries to type slip or zeroGradient as appropriate for the domain extent.

Set the initial internal field for velocity to uniform (0 0 0) or uniform (U_inf 0 0).

In 0/p, set frontAndBack to type empty.

Set inlet to type zeroGradient for pressure.

Set outlet to type fixedValue with value uniform 0 for pressure.

Set cylinderWall to type zeroGradient for pressure.

Set top and bottom boundaries to type zeroGradient for pressure.

In system/controlDict, set application to pimpleFoam.

Set startFrom to startTime with startTime 0.

Set stopAt to endTime with an appropriate endTime for vortex shedding to develop.

Set deltaT small enough for stability, typically based on the Courant number.

Set writeControl to adjustableRunTime or timeStep with appropriate writeInterval.

In system/fvSchemes, use schemes appropriate for transient incompressible laminar flow, such as Euler or CrankNicolson for ddt, and linear or linearUpwind for convection.

In system/fvSolution, configure PIMPLE algorithm settings with appropriate nOuterCorrectors, nCorrectors, and nNonOrthogonalCorrectors for transient stability.

Set the turbulence model to laminar in constant/turbulenceProperties.

Set the transport model to Newtonian in constant/transportProperties with the desired kinematic viscosity nu.
