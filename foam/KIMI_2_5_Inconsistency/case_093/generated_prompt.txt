Set up a 2D dam break simulation using the pimpleFoam solver with the following specifications:

The domain is a rectangular box with dimensions 2.0 m in length (x-direction) and 1.0 m in height (y-direction).

The water column has a width of 0.4 m and a height of 0.6 m, positioned with its left edge flush against the left wall of the domain (x = 0 to x = 0.4 m, y = 0 to y = 0.6 m).

The mesh uses a uniform grid with 200 cells in the x-direction and 100 cells in the y-direction, resulting in a cell size of 0.01 m x 0.01 m.

In the controlDict, set endTime to 5 seconds, deltaT to 0.001 seconds, and writeInterval to 0.05 seconds.

Use setFields to initialize the water column region with alpha.water = 1 and the remainder of the domain with alpha.water = 0.

Set gravity to g = (0 -9.81 0) m/s^2 in the g constant.

In transportProperties, define two phases: water with density 1000 kg/m^3 and kinematic viscosity 1e-6 m^2/s, and air with density 1.225 kg/m^3 and kinematic viscosity 1.48e-5 m^2/s.

The simulation runs in 2D with empty front and back patches.

Use the interFoam or pimpleFoam solver with multiphase capabilities enabled for interface capturing.

Set the initial velocity field to uniform (0 0 0) throughout the domain.

Set the initial pressure field to uniform 0 (hydrostatic pressure will develop automatically).

Use zeroGradient boundary conditions for alpha.water on all walls.

Use noSlip boundary conditions for velocity on all walls.

Use fixedFluxPressure or zeroGradient for pressure on all walls.

Enable automatic time step adjustment based on the Courant number with a maximum Co of 0.5 if desired, or use the fixed deltaT specified above.
