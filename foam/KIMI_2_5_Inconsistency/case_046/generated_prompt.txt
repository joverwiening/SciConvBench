Set up a transient simulation of turbulent flow over a 2D cylinder in a channel using pimpleFoam with LES turbulence modeling.

Use the Smagorinsky LES model with cubeRootVol delta function in the constant/turbulenceProperties file.

Set the simulationType to LES in constant/turbulenceProperties. Do not include any RAS sub-dictionary.

Use standard air properties for an incompressible fluid with kinematic viscosity nu = 1.5e-5 m²/s.

Set the inlet velocity to 10 m/s using a fixedValue boundary condition with uniform value (10 0 0).

Set the cylinder diameter to 0.1 m based on best practices for canonical cylinder flow simulations.

Set the channel height to 0.4 m (4 times the cylinder diameter) to minimize wall blockage effects.

Set the channel length to 2.0 m (20 times the cylinder diameter) with the cylinder positioned 0.5 m (5 diameters) downstream of the inlet to allow flow development.

Apply noSlip boundary conditions on the cylinder surface and channel walls (top and bottom).

Apply a zeroGradient boundary condition for velocity at the outlet.

Apply a fixedValue boundary condition for pressure at the outlet with uniform value 0.

Apply a zeroGradient boundary condition for pressure at the inlet and walls.

Set the maximum Courant number to 1.0 and enable adjustable time step in system/controlDict.

Set the initial time step to 1e-4 seconds to satisfy the Courant number constraint during startup.

Set the end time to 0.5 seconds to capture approximately 25 vortex shedding cycles based on expected Strouhal number of 0.2.

Set the write interval to 0.002 seconds (every 20 time steps on average) to resolve vortex shedding dynamics.

Use a structured O-grid or C-grid mesh with approximately 100 cells around the cylinder circumference.

Use wall-resolved LES with y+ < 1 at the cylinder surface, requiring 30-40 cells in the wall-normal direction within the boundary layer.

Refine the mesh in the wake region extending 10 diameters downstream with cell size comparable to the cylinder surface resolution.

Use second-order schemes for all terms: Gauss linear for divergence, Gauss linear corrected for Laplacian, and linear for interpolation.

Use the CrankNicolson ddt scheme with blend factor 0.9 for time integration to balance accuracy and stability.

Enable pimpleFoam with 2-3 outer corrector iterations and 1 inner corrector iteration per time step.

Enable momentumPredictor for improved velocity-pressure coupling.

Enable turbOnFinalIterOnly to compute turbulence model only on the final PIMPLE iteration for efficiency.

Initialize the velocity field with uniform value (10 0 0) and pressure with uniform value 0.

Set the initial turbulent kinetic energy k to 0.375 m²/s² (5% turbulence intensity) and epsilon to 14.06 m²/s³ based on inlet conditions.

Use the vanDriest damping function for the Smagorinsky model to improve near-wall behavior.

Set the Smagorinsky constant Cs to 0.1 for wall-bounded flows.
