Set up a Rayleigh-Bénard convection case using the buoyantBoussinesqPimpleFoam solver.

The domain is a 3D box with dimensions 1m x 1m x 0.1m, with the height oriented along the Z-axis.

In constant/transportProperties, set the following properties: beta=0.00341, T0=300, nu=1.5e-5, and Pr=0.71.

In constant/g, define the gravity vector as `g (-9.81 0 0);`.

In the 0/T file, apply boundary conditions as follows: the bottom wall (z=0) has a fixed temperature T=310K using the `fixedValue` type, the top wall (z=0.1) has T=300K using the `fixedValue` type, and the side walls (x and y directions) are periodic using `cyclic` boundary conditions.

In the 0/U file, apply `noSlip` boundary conditions on the top and bottom walls, and `cyclic` boundary conditions on the side walls.

Configure the simulation as transient to capture the formation of convection cells.

The temperature difference of 10K (310K - 300K) and the given beta value of 0.00341 define the buoyancy forcing for the simulation.
