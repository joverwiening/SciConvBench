Simulate incompressible water flow in a 2D channel with prescribed peristaltic wall motion using dynamic mesh in OpenFOAM.

Solver: Use `pimpleFoam` in `system/controlDict`.

Geometry and mesh: Create a 2D rectangular channel mesh extruded one cell in the z-direction with `frontAndBack` patches defined as `empty` type.

Water properties: Set kinematic viscosity `nu = 1e-6 m^2/s` in `constant/transportProperties`.

Dynamic mesh configuration: Create `constant/dynamicMeshDict` with `dynamicMotionSolverFvMesh` as the dynamicFvMesh type and `displacementLaplacian` as the motion solver with `diffusivity quadratic inverseDistance (movingWall)`.

Wall motion specification: In `0/pointDisplacement`, apply `oscillatingDisplacement` boundary condition on the `movingWall` patch with amplitude `0.001 m` (1 mm) and frequency `2 Hz` (period 0.5 s), representing a physiologically reasonable peristaltic wave. Set all other boundary patches to `fixedValue uniform (0 0 0)`.

Velocity boundary conditions in `0/U`: Set inlet to `fixedValue uniform (0.01 0 0)` m/s (1 cm/s mean flow), outlet to `zeroGradient`, stationary walls to `noSlip`, and `movingWall` to `movingWallVelocity` with `value uniform (0 0 0)`.

Pressure boundary conditions in `0/p`: Set outlet to `fixedValue uniform 0`, and inlet, stationary walls, and `movingWall` to `zeroGradient`.

Numerical settings: Use `system/fvSchemes` with second-order schemes for spatial discretization and `system/fvSolution` with appropriate relaxation factors and linear solver settings for PIMPLE algorithm with 2-3 outer corrector loops.

Time control: Set adjustable time step with maximum Courant number of 1.0, total simulation time of 5 seconds (10 periods) to reach quasi-periodic state, and write interval every 0.1 seconds.
