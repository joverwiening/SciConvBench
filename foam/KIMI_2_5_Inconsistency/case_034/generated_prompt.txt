Set up a 2D dam break simulation using the interFoam solver for a two-phase water-air system.
The domain is 2 meters long in the x-direction and 1 meter high in the y-direction, with a single cell in the z-direction.
Gravity is defined in constant/g as the vector (0 -9.81 0).
In blockMeshDict, the front and back patches are named frontAndBack with type wall.
In the 0 directory, for all fields U, p_rgh, and alpha.water, the frontAndBack patches use noSlip boundary condition for velocity and zeroGradient for scalars.
The initial water column is defined using setFieldsDict with a 0.4 meter high water column positioned on the left side of the domain extending from x=0 to x=0.4m.
The mesh resolution is 200 cells in the x-direction and 100 cells in the y-direction, giving a uniform cell size of 0.01m by 0.01m.
The total simulation duration is 2 seconds.
Adaptive time stepping is enabled with a maximum Courant number of 1.0 and maximum cell Courant number of 0.5, with a maximum time step of 0.001 seconds.
In constant/transportProperties, the water phase has density 1000 kg/m3 and kinematic viscosity 1e-6 m2/s.
The air phase has density 1.225 kg/m3 and kinematic viscosity 1.48e-5 m2/s.
Surface tension between water and air is set to 0.07 N/m.
The interface compression coefficient cAlpha is set to 1.0 in fvSolution.
