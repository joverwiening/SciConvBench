Run a 2D inviscid laminar oblique-shock simulation on a rectangular domain with corner points (0, 0, 0) and (4.1, 1, 0.1) extruded one cell in the z-direction.

Use a mesh of 60 cells in x, 30 cells in y, and 1 cell in z.

Set the frontAndBack patch type to empty.

Configure boundaries as follows: left patch is inlet, right patch is outlet, top patch is wall, bottom patch is symmetryPlane.

Use the rhoCentralFoam solver for compressible flow.

Set momentum transport to laminar.

Use ideal-gas thermophysical properties with Cp=2.5, Prandtl number=1, and dynamic viscosity=1e-5.

Initialize the entire domain with velocity U=(2.9 0 0), pressure p=1, and temperature T=1.

Set inlet boundary conditions to fixedValue velocity (2.9 0 0), fixedValue pressure 1, and fixedValue temperature 1.

Set top wall boundary conditions to fixedValue velocity (2.61933 -0.50632 0) and fixedValue temperature 1.25853.

Set the molecular weight to 11640.3 and heat of formation Hf to 0.

Set the time step deltaT to 0.0025, endTime to 10, and writeInterval to 1.
