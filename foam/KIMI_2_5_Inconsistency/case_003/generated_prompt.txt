Run a two-dimensional Rayleigh-Benard convection simulation using the buoyantFoam solver with the following specifications:

The computational domain is a rectangular cavity with dimensions 9 units in x, 1 unit in y, and 1 cell in z, extruded to enforce 2D flow with front and back patches treated as walls.

The mesh consists of 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.

Gravity acts in the negative y-direction.

The reference state uses air-like properties: density 1.0 kg/m^3, reference temperature 300 K, thermal expansion coefficient 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, and thermal diffusivity 2.1e-5 m^2/s (Prandtl number 0.7).

Boundary conditions for temperature: bottom wall fixed at 305 K, top wall fixed at 295 K, vertical side walls adiabatic (zeroGradient), and front/back walls use noSlip.

Boundary conditions for velocity: no-slip on all solid walls and noSlip on front/back patches.

Initial conditions: flow at rest with uniform temperature 300 K everywhere.

Time stepping uses a fixed timestep of 1 second with adjustTimeStep disabled, no maxCo, and no maxDeltaT.

The simulation runs for 1000 seconds of physical time.

Results are written every 50 timesteps.

The turbulence model is RAS k-epsilon with turbulence on and printCoeffs on.

In constant/momentumTransport, set simulationType to RAS, model to kEpsilon, turbulence to on, and printCoeffs to on.

In constant/physicalProperties, use heRhoThermo with equationOfState Boussinesq, molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.

In 0/k, set internalField to uniform 1e-5 with kqRWallFunction on walls and noSlip on front/back.

In 0/epsilon, set internalField to uniform 1e-5 with epsilonWallFunction on walls and noSlip on front/back.

In 0/nut, set internalField to uniform 0 with nutkWallFunction on walls and noSlip on front/back.

In 0/alphat, set internalField to uniform 0 with compressible::alphatJayatillekeWallFunction on walls, Prt 0.85, and noSlip on front/back.

In 0/U, set internalField to uniform (0 0 0) with noSlip on all solid walls and noSlip on front/back.

In 0/T, set internalField to uniform 300, bottom to fixedValue 305, top to fixedValue 295, sides to zeroGradient, and front/back to noSlip.

In 0/p, set internalField to uniform 0 with walls calculated and front/back noSlip.

In 0/p_rgh, set internalField to uniform 0 with walls fixedFluxPressure and front/back noSlip.

In system/fvSolution, set solvers for p_rgh and (U|e|k|epsilon) to tolerance 1e-8 and relTol 0.01, and set the corresponding *Final entries to relTol 0.
