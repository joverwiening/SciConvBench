Simulate steady-state, incompressible, turbulent swirling flow in an industrial cyclone separator using the simpleFoam solver with the standard k-epsilon turbulence model.

The computational domain represents a reverse-flow cyclone separator with cylindrical body, conical lower section, tangential inlet duct, top axial outlet (vortex finder), and bottom dust outlet.

Define the boundary conditions for the pressure field 'p' as follows:

inlet
{
    type            zeroGradient;
}

outlet
{
    type            fixedValue;
    value           uniform 0;
}

dustOutlet
{
    type            zeroGradient;
}

walls
{
    type            zeroGradient;
}

Define the boundary conditions for the velocity field 'U' as follows:

inlet
{
    type            fixedValue;
    value           uniform (0 -15 0);
}

outlet
{
    type            inletOutlet;
    inletValue      uniform (0 0 0);
    value           uniform (0 0 0);
}

dustOutlet
{
    type            inletOutlet;
    inletValue      uniform (0 0 0);
    value           uniform (0 0 0);
}

walls
{
    type            noSlip;
}

Define the boundary conditions for the turbulent kinetic energy 'k' as follows:

inlet
{
    type            fixedValue;
    value           uniform 0.84375;
}

outlet
{
    type            inletOutlet;
    inletValue      uniform 0.84375;
    value           uniform 0.84375;
}

dustOutlet
{
    type            inletOutlet;
    inletValue      uniform 0.84375;
    value           uniform 0.84375;
}

walls
{
    type            kqRWallFunction;
    value           uniform 0.84375;
}

Define the boundary conditions for the turbulent dissipation rate 'epsilon' as follows:

inlet
{
    type            fixedValue;
    value           uniform 0.061523;
}

outlet
{
    type            inletOutlet;
    inletValue      uniform 0.061523;
    value           uniform 0.061523;
}

dustOutlet
{
    type            inletOutlet;
    inletValue      uniform 0.061523;
    value           uniform 0.061523;
}

walls
{
    type            epsilonWallFunction;
    value           uniform 0.061523;
}

Define the boundary conditions for the turbulent viscosity 'nut' as follows:

inlet
{
    type            calculated;
    value           uniform 0;
}

outlet
{
    type            calculated;
    value           uniform 0;
}

dustOutlet
{
    type            calculated;
    value           uniform 0;
}

walls
{
    type            nutkWallFunction;
    value           uniform 0;
}

Set the inlet velocity magnitude to 15 m/s directed tangentially to establish strong swirling flow typical for cyclone operation.

Set the inlet turbulence intensity to 5 percent characteristic of industrial duct flow with moderate disturbances.

Set the inlet hydraulic diameter to 0.15 m representing a standard rectangular or circular inlet duct for small-to-medium industrial cyclones.

Set the cyclone body diameter to 0.3 m and total height to 1.2 m giving a height-to-diameter ratio of 4:1 consistent with high-efficiency Stairmand or Lapple cyclone designs.

Set the kinematic viscosity to 1.5e-5 m²/s corresponding to air at approximately 20°C and 1 atm.

Set the reference pressure to 0 Pa (gauge) at the top outlet with atmospheric pressure boundary condition.

Configure the fvSchemes file to use second-order schemes for convection terms: Gauss linearUpwind for velocity and Gauss upwind for turbulence quantities, with Gauss linear for diffusion terms.

Configure the fvSolution file to use the GAMG solver for pressure with tolerance 1e-7, and smoothSolver for velocity and turbulence with tolerance 1e-8, with 2 non-orthogonal correctors and relaxation factors of 0.3 for pressure and 0.7 for velocity.

Initialize the internal field with uniform velocity (0 0 0), pressure 0, k 0.84375, and epsilon 0.061523.

Run the simulation until residuals drop below 1e-6 or for 2000 iterations, monitoring for convergence of pressure drop and swirl velocity profiles.
