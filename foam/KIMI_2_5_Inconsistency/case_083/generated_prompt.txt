The initial conditions for a three-phase settling tank simulation using the `multiphaseEulerFoam` solver shall be configured as follows.

Create three volume fraction field files in the `0/` directory named `alpha.sediment`, `alpha.water`, and `alpha.oil`.

Set the `internalField` entry in each of the three files to `uniform 0.5`.

Set the `boundaryField` entries in each file to `type zeroGradient` for all patch names, as this is the standard default for multiphase volume fraction fields before specific boundary conditions are applied.

Use OpenFOAM version 9 or OpenFOAM v2212 (OpenFOAM Foundation or OpenCFD/ESI versions respectively), as these are stable releases with well-documented `multiphaseEulerFoam` solver support.

Ensure the `0/` directory also contains the mandatory field files `U` (velocity), `p` (pressure), and `Theta` (granular temperature) as required by `multiphaseEulerFoam`, with `internalField uniform (0 0 0)` for velocity, `internalField uniform 1e5` for pressure, and `internalField uniform 1e-8` for granular temperature as reasonable initial defaults.

The `setFieldsDict` in the `system/` directory will later override these uniform initial conditions to create the desired stratified layer configuration.
