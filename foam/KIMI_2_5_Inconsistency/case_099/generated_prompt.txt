The simulation models 2D laminar, transient flow past a square cylinder using icoFoam.

The computational domain measures 2.2m in length, 0.41m in height, and one cell thickness of 0.01m.

A square cylinder of 0.1m by 0.1m is placed in the flow path.

The kinematic viscosity nu is set to 0.001 m^2/s.

The Reynolds number based on cylinder diameter and mean inlet velocity is 100.

The mean inlet velocity is calculated as 1.0 m/s from the parabolic profile with maximum value 1.5 m/s.

The time step size is 0.005 seconds.

The maximum Courant number is limited to 0.5 for numerical stability.

The total simulation duration is 10 seconds.

The spatial discretization scheme for the convection term in the momentum equation is Gauss linear.

The spatial discretization scheme for the Laplacian term is Gauss linear corrected.

The temporal discretization scheme is CrankNicolson with a blending factor of 0.5.

The pressure-velocity coupling uses the PISO algorithm with 2 correctors.

The gradient scheme is Gauss linear.

The interpolation scheme is linear.

The wall distance calculation uses the meshWave method.

Boundary conditions for velocity field U are as follows.

The inlet patch uses a parabolic velocity profile with maximum value (1.5 0 0) m/s.

The outlet patch uses zeroGradient.

The topAndBottomWalls patch uses noSlip.

The cylinder patch uses noSlip.

The frontAndBack patches use noSlip.

Boundary conditions for pressure field p are as follows.

The inlet patch uses zeroGradient.

The outlet patch uses fixedValue with uniform value 0.

The topAndBottomWalls patch uses zeroGradient.

The cylinder patch uses zeroGradient.

The frontAndBack patches use zeroGradient.

In constant/polyMesh/boundary, the frontAndBack patches are defined with type wall.

The initial velocity field is uniform (0 0 0).

The initial pressure field is uniform 0.

The solver tolerance for U is 1e-6.

The solver tolerance for p is 1e-6.

The solver relative tolerance for U is 0.1.

The solver relative tolerance for p is 0.1.

The linear solver for U uses smoothSolver with symGaussSeidel smoother.

The linear solver for p uses GAMG with GaussSeidel smoother.

The nNonOrthogonalCorrectors is set to 0.

The momentumPredictor is set to yes.

The fluxRequired for p is set to yes.

The writeControl is set to adjustableRunTime.

The writeInterval is 0.1 seconds.

The purgeWrite is set to 0.

The writeFormat is ascii.

The writePrecision is 6.

The writeCompression is off.

The timeFormat is general.

The timePrecision is 6.

The runTimeModifiable is set to true.

The adjustTimeStep is set to yes.

The maxCo is 0.5.

The maxDeltaT is 0.01 seconds.
