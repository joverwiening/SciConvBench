Simulate a 2D bubble column using `twoPhaseEulerFoam`. The column is 0.5m wide and 2m high. The continuous phase is water, and the dispersed phase is air. Initialize the domain using `setFieldsDict`. The bottom 1.5m of the column should be filled with a mixture of water and air, while the top 0.5m is pure air. Use the following `setFieldsDict` configuration:

```
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      setFieldsDict;
}

defaultFieldValues
(
    volScalarFieldValue alpha.air 1.0
    volScalarFieldValue alpha.water 0.0
);

regions
(
    boxToCell
    {
        box (0 0 -0.1) (0.5 1.5 0.1);
        fieldValues
        (
            volScalarFieldValue alpha.air 0.4
            volScalarFieldValue alpha.water 0.6
        );
    }
);
```
