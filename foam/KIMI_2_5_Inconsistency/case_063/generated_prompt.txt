Simulate the transient von Kármán vortex street behind a cylinder in a 2D channel using `pimpleFoam`.

Use a 2D mesh extruded one cell in z with `frontAndBack` as `empty`.

Set the kinematic viscosity to `nu = 1e-3 m^2/s`.

Boundary conditions for `0/U`:
Set inlet to `fixedValue uniform (0.1 0 0)`.
Set outlet to `zeroGradient`.
Set cylinder to `noSlip`.
Set top and bottom to `slip`.
Set frontAndBack to `empty`.

Boundary conditions for `0/p`:
Set inlet to `zeroGradient`.
Set outlet to `fixedValue uniform 0`.
Set cylinder, top, and bottom to `zeroGradient`.
Set frontAndBack to `empty`.

In `system/controlDict`, set `application` to `pimpleFoam`.
