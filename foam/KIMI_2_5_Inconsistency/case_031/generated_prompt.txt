The simulation shall use the icoFoam solver for 2D incompressible laminar flow.

The computational domain is a rectangular channel with length 0.5 m in the x-direction and height 0.1 m in the y-direction.

The mesh shall be one cell thick in the z-direction.

In blockMeshDict, define the geometry with vertices spanning from (0 0 0) to (0.5 0.1 0) in the xy-plane with a single cell thickness in z.

In blockMeshDict, define five patches: inlet, outlet, topWall, bottomWall, and frontAndBack.

For the frontAndBack patches in blockMeshDict, set type to wall.

The simulation shall model Poiseuille flow driven by a pressure gradient.

In the 0/U file, set the inlet boundary condition to a fixedValue with a parabolic velocity profile: Ux = 1.0 * (1.0 - ((y - 0.05)/0.05)^2), Uy = 0, Uz = 0, yielding a maximum velocity of 1 m/s at the channel centerline (y = 0.05 m).

In the 0/U file, set the outlet boundary condition to zeroGradient.

In the 0/U file, set topWall and bottomWall boundary conditions to noSlip.

In the 0/U file, set frontAndBack boundary conditions to noSlip.

In the 0/p file, set the outlet boundary condition to fixedValue with value 0.

In the 0/p file, set inlet, topWall, bottomWall, and frontAndBack boundary conditions to zeroGradient.

The transportProperties file shall define kinematic viscosity nu appropriate for the desired Reynolds number based on the characteristic length (channel height 0.1 m) and maximum velocity (1 m/s).

The controlDict shall specify appropriate time step, end time, and write interval for convergence of the laminar solution.
