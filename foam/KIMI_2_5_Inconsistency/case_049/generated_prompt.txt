Set up a 2D simulation of incompressible, laminar flow over an airfoil using `simpleFoam`.

The mesh is extruded one cell in the z-direction with the patch name `frontAndBack` for the out-of-plane faces.

In `constant/polyMesh/boundary`, set the `frontAndBack` patch type to `wall`.

In `0/U`, set the `frontAndBack` patch type to `slip`.

Assume the domain has four patches: `inlet`, `outlet`, `airfoil`, and `frontAndBack`.

In `0/U`, set the `inlet` patch to `fixedValue` with uniform velocity `(10 0 0)` m/s.

In `0/U`, set the `outlet` patch to `zeroGradient`.

In `0/U`, set the `airfoil` patch to `noSlip`.

In `0/p`, set the `inlet` patch to `zeroGradient`.

In `0/p`, set the `outlet` patch to `fixedValue` with uniform value `0`.

In `0/p`, set the `airfoil` patch to `zeroGradient`.

In `0/p`, set the `frontAndBack` patch to `slip`.

In `constant/transportProperties`, set `nu` to `1.5e-05` m²/s for air at standard conditions.

Use the `laminar` RAS model in `constant/turbulenceProperties`.

Set the airfoil geometry to NACA 0012 at 0 degrees angle of attack.

Set the Reynolds number to approximately 100,000 based on chord length and inlet velocity.

Use a C-grid or O-grid domain with the inlet located 10 chord lengths upstream, outlet 15 chord lengths downstream, and far-field boundaries 10 chord lengths above and below the airfoil.

Ensure the mesh has sufficient resolution near the airfoil surface with y+ less than 1 for laminar flow resolution.
