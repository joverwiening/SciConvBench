The simulation models steady-state heat conduction through a 2D square solid plate using the OpenFOAM solver laplacianFoam.

The computational domain is a square plate with dimensions 1 meter by 1 meter and a thickness of one cell.

The blockMeshDict file defines six boundary patches: left, right, top, bottom, front, and back. The frontAndBack patches are assigned the type wall.

The mesh is generated using blockMesh with a structured grid appropriate for resolving the temperature gradient across the domain.

The initial temperature field in the 0/T file is set to a uniform value of 350 K for the internal field.

The left patch boundary condition in 0/T is set to type fixedValue with a value of 400 K.

The right patch boundary condition in 0/T is set to type fixedValue with a value of 300 K.

The top patch boundary condition in 0/T is set to type zeroGradient.

The bottom patch boundary condition in 0/T is set to type zeroGradient.

The frontAndBack patches boundary condition in 0/T is set to type zeroGradient to simulate thermal insulation and enforce a 2D solution.

The transportProperties file in the constant directory defines the thermal diffusivity DT for the solid material.

The laplacianFoam solver is executed to compute the steady-state temperature distribution.

The simulation runs until convergence criteria are met or the end time specified in controlDict is reached.

The output includes the steady-state temperature field written to the final time directory.
