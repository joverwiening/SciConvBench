Simulate buoyancy-driven heat transfer in a 2D channel using `buoyantPimpleFoam`.

The computational domain is a 2D rectangular channel with height 0.1 m, width 0.01 m (unit depth in z-direction), and length 1.0 m.

The mesh consists of 100 cells in the x-direction (length) and 50 cells in the y-direction (height), with grading towards the walls for boundary layer resolution.

Gravity acts in the negative y-direction with magnitude 9.81 m/s².

The fluid is air with the following properties: kinematic viscosity 1.5e-5 m²/s, thermal expansion coefficient 0.00333 K⁻¹ (1/300 K), Prandtl number 0.71, and reference density 1.0 kg/m³.

Initial conditions: pressure 1e5 Pa, velocity (0 0 0) m/s, temperature 300 K uniform throughout the domain.

Boundary conditions for velocity: inlet and outlet use `pressureInletOutletVelocity`, bottomWall and topWall use `noSlip`.

Boundary conditions for pressure: inlet and outlet use `totalPressure`, bottomWall and topWall use `fixedFluxPressure`.

Boundary conditions for temperature: bottomWall uses `fixedValue` with uniform 400 K, topWall uses `zeroGradient` (adiabatic), inlet uses `inletOutlet` with 300 K, outlet uses `inletOutlet` with 300 K.

The simulation uses the PIMPLE algorithm with 2 outer correctors, 1 inner corrector, and no non-orthogonal correctors.

Time step size is 0.001 s with adjustable time step enabled and maximum Courant number 1.0.

Total end time is 50 s with write interval every 0.5 s.

Turbulence is modeled as laminar.

The `thermophysicalProperties` file uses `hePsiThermo` with `pureMixture` and `const` transport and thermo models.
