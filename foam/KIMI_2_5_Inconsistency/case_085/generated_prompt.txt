Set up a 2D steady-state simulation of Rayleigh-Bénard convection in a square cavity of 1m x 1m.

Use the `buoyantBoussinesqSimpleFoam` solver.

The fluid is air modeled with the incompressible Boussinesq approximation.

Gravity acts in the negative y-direction with g = 9.81 m/s².

The bottom wall is heated to 310 K.

The top wall is cooled to 290 K.

The side walls are adiabatic.

In `constant/thermophysicalProperties`, use the following configuration:

thermoType
{
    type            heRhoThermo;
    mixture         pureMixture;
    transport       const;
    thermo          hConst;
    equationOfState Boussinesq;
    specie          specie;
    energy          sensibleEnthalpy;
}

mixture
{
    specie
    {
        molWeight   28.9;
    }
    thermodynamics
    {
        Cp          1005;
        Hf          0;
    }
    transport
    {
        mu          1.8e-05;
        Pr          0.7;
    }
    equationOfState
    {
        rhoRef      1.176;
        TRef        300;
        beta        0.00333;
    }
}

In `constant/transportProperties`, set:

transportModel  Newtonian;

nu              1.531e-05;

beta            0.00333;

TRef            300;

Pr              0.7;

For boundary conditions on temperature: set T_bottom to fixedValue 310 K, T_top to fixedValue 290 K, T_sides to zeroGradient.

For boundary conditions on velocity: set all walls to noSlip.

For boundary conditions on p_rgh: set all boundaries to fixedFluxPressure.
