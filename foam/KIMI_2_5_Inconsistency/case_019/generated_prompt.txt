Set up a laminar counter-flow diffusion flame simulation using reactingFoam in OpenFOAM with the following specifications:

The computational domain is a rectangular region spanning x = 0 to 0.02 m, y = -0.01 to 0.01 m, and z = -0.01 to 0.01 m.

Create a mesh with 100 cells in the x-direction, 40 cells in the y-direction, and 1 cell in the z-direction.

Name the left boundary at x = 0 as "fuel" and the right boundary at x = 0.02 m as "air".

Name the top and bottom boundaries as "outlet".

Set the frontAndBack faces as empty patches for 2-D simulation.

Configure the fuel inlet boundary to inject methane (CH4) at a temperature of 293 K with a velocity of 0.1 m/s in the positive x-direction.

Configure the air inlet boundary to supply oxidizer as air (O2/N2) at 293 K with mass fraction Y_O2 = 0.23 and Y_N2 = 0.77, with a velocity of -0.1 m/s in the negative x-direction.

Initialize the entire domain with a uniform temperature of 2000 K at time 0.

Set the chemistry type to EulerImplicit in the chemistryProperties dictionary.

Set the ODE solver to Rosenbrock43 in the chemistryProperties dictionary.

Use laminar combustion model for the combustion properties.

Use laminar momentum transport for the turbulence properties.

Configure the thermophysical model as heRhoThermo with incompressible finite-rate chemistry.

Set the mixture model to coefficientWilkeMultiComponentMixture.

Set the transport model to Sutherland.

Set the thermodynamics model to JANAF.

Use the reactingFoam solver for the simulation.

Set the timestep to 1e-4 seconds in the controlDict.

Set the end time to 0.5 seconds in the controlDict.

Set the write interval to 0.05 seconds in the controlDict.
