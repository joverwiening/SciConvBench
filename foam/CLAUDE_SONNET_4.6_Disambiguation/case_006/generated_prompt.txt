Final Specification:

The simulation is a 2D Rayleigh-Benard convection cell in a rectangular cavity.
The domain is 9 units wide (x), 1 unit tall (y), and 1 cell thick in the spanwise (z) direction.
Generate the mesh using blockMesh with a block spanning (0 0 0) to (9 1 1).
Use a cell count of 90 cells in x, 10 cells in y, and 1 cell in z, with uniform grading (simpleGrading 1 1 1).
Name the patches: bottom (y=0), top (y=1), left (x=0), right (x=9), front (z=1), back (z=0).
Set front and back patch types to empty in the blockMeshDict to enforce 2D.

Use the buoyantFoam solver.
Set gravity in constant/g as (0 -9.81 0) m/s^2.

Create constant/physicalProperties with thermoType using heRhoThermo, rhoThermo, pureMixture, const transport, sensibleInternalEnergy thermo, hConst, and Boussinesq equationOfState.
Set molWeight to 29 in the mixture specie entry.
Set rho0 to 1.0, T0 to 300, beta to 3.3e-3 in the equationOfState entry.
Set Cv to 714.3 and Hf to 0 in the thermodynamics entry.
Set mu to 1.5e-5 and Pr to 0.714 in the transport entry.

Create constant/momentumTransport with simulationType set to RAS.
Set the RAS model to kEpsilon.
Set turbulence to on.
Set printCoeffs to on.
Do not use laminar anywhere in the momentumTransport file.

Create 0/U with internalField uniform (0 0 0).
Set type noSlip on bottom, top, left, and right patches.
Set type empty on front and back patches.

Create 0/T with internalField uniform 300.
Set type fixedValue with value uniform 305 on the bottom patch.
Set type fixedValue with value uniform 295 on the top patch.
Set type zeroGradient on left and right patches.
Set type empty on front and back patches.

Create 0/p with internalField uniform 0.
Set type calculated on bottom, top, left, and right patches.
Set type empty on front and back patches.

Create 0/p_rgh with internalField uniform 0.
Set type fixedFluxPressure with value uniform 0 on bottom, top, left, and right patches.
Set type empty on front and back patches.

Create 0/k with internalField uniform 1e-5.
Set type kqRWallFunction with value uniform 1e-5 on bottom, top, left, and right patches.
Set type empty on front and back patches.

Create 0/epsilon with internalField uniform 1e-5.
Set type epsilonWallFunction with value uniform 1e-5 on bottom, top, left, and right patches.
Set type empty on front and back patches.

Create 0/nut with internalField uniform 0.
Set type nutkWallFunction with value uniform 0 on bottom, top, left, and right patches.
Set type empty on front and back patches.

Create 0/alphat with internalField uniform 0.
Set type compressible::alphatJayatillekeWallFunction with Prt 0.85 and value uniform 0 on bottom, top, left, and right patches.
Set type empty on front and back patches.

Create system/controlDict with application buoyantFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 1000.
Set deltaT to 1.
Set adjustTimeStep to no.
Do not set maxCo or maxDeltaT in controlDict.
Set writeControl to timeStep.
Set writeInterval to 50.
Set purgeWrite to 0.
Set writeFormat to ascii.
Set writePrecision to 8.
Set runTimeModifiable to yes.

Create system/fvSchemes.
Set ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear.
Set divSchemes for div(phi,U) to Gauss linearUpwind grad(U), for div(phi,e) to Gauss linearUpwind grad(e), for div(phi,k) to Gauss linearUpwind grad(k), for div(phi,epsilon) to Gauss linearUpwind grad(epsilon), and for div((muEff*dev(T(grad(U))))) to Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.

Create system/fvSolution.
Under solvers, define p_rgh using a PCG solver with DIC preconditioner, tolerance 1e-8, and relTol 0.01.
Define p_rghFinal using the same PCG solver with DIC preconditioner, tolerance 1e-8, and relTol 0.
Define a solver entry matching (U|e|k|epsilon) using a PBiCGStab solver with DILU preconditioner, tolerance 1e-8, and relTol 0.01.
Define a solver entry matching (U|e|k|epsilon)Final using the same PBiCGStab solver with DILU preconditioner, tolerance 1e-8, and relTol 0.
Under PIMPLE, set nOuterCorrectors to 2, nCorrectors to 2, and nNonOrthogonalCorrectors to 1.
Set momentumPredictor to yes under PIMPLE.
