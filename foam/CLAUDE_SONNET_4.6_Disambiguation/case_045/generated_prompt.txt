Set up an OpenFOAM case using buoyantBoussinesqPimpleFoam, targeting OpenFOAM v2212 (ESI release) as a reasonable modern stable version.
The domain is a 2D square cavity, 1 meter wide and 1 meter tall.
Use a structured mesh of 50 cells in the x-direction and 50 cells in the y-direction, with 1 cell in the z-direction (2D slice).
Set the cell depth in the z-direction to 0.1 m with empty boundary conditions on the front and back faces.
The fluid is air modeled with the Boussinesq approximation.
Use the following fluid properties: kinematic viscosity nu = 1.5e-5 m^2/s, thermal diffusivity alphaEff via Prandtl number Pr = 0.71, reference density rho0 = 1.2 kg/m^3, thermal expansion coefficient beta = 3.43e-3 1/K (1/Tref), reference temperature Tref = 295 K, specific heat Cp = 1005 J/kg/K, thermal conductivity lambda = 0.0257 W/m/K.
Set gravitational acceleration to g = (0, -9.81, 0) m/s^2 in the constant/g file.
The bottom wall is a fixed temperature boundary at 300 K (hot wall).
The top wall is a fixed temperature boundary at 290 K (cold wall).
The left and right walls are no-slip, adiabatic (zero gradient for temperature).
Initialize the entire domain with T = 295 K, p_rgh = 0 Pa, and U = (0, 0, 0) m/s.
Use the PIMPLE algorithm with nOuterCorrectors = 1, nCorrectors = 2, nNonOrthogonalCorrectors = 1.
Set the time step deltaT = 0.01 s.
Set endTime = 200 s to allow the flow to reach a statistically steady state.
Write results every 10 s (writeInterval = 10).
Use Gauss linear schemes for gradient and divergence terms, and Gauss linear corrected for the Laplacian.
Use GAMG solver for p_rgh and smoothSolver for U and T.
Create the standard OpenFOAM case directory structure: 0/, constant/, and system/.
Place boundary condition files for T, U, p_rgh, and alphat in the 0/ directory.
Place transportProperties and turbulenceProperties (set to laminar) in constant/.
Place blockMeshDict, controlDict, fvSchemes, fvSolution in system/.
Run blockMesh to generate the mesh, then run buoyantBoussinesqPimpleFoam to execute the simulation.
