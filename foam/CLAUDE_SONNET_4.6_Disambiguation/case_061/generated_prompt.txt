Create an OpenFOAM case using pimpleFoam for turbulent channel flow driven by a body force.

The channel dimensions are: length Lx = 2.0 m (streamwise, x), height H = 0.10 m (wall-normal, y), width Lz = 0.10 m (spanwise, z).

The bulk velocity target is Ubar = (1 0 0) m/s and kinematic viscosity nu = 1.5e-5 m²/s, giving a bulk Reynolds number Re = Ubar * H / nu = 6667.

Use blockMesh to generate the mesh with 100 cells in x, 50 cells in y, and 50 cells in z.

Apply wall-normal grading in y to refine near both the bottom and top walls, using a symmetric expansion ratio so that the first cell height is small enough to resolve the near-wall region for kOmegaSST (target y+ on the order of 1).

Use a single block in blockMeshDict spanning (0 0 0) to (2.0 0.10 0.10).

Set the x-direction (streamwise) faces as cyclic patch pair named inlet and outlet.

Set the z-direction (spanwise) faces as cyclic patch pair named front and back.

Set the bottom face (y = 0) as a wall patch named bottomWall.

Set the top face (y = H) as a wall patch named topWall.

Use RAS turbulence modeling with the kOmegaSST model.

In turbulenceProperties, set simulationType to RAS and model to kOmegaSST.

Initialize U to (1 0 0) m/s uniformly across the domain.

Set p initial field to zero uniform.

Initialize k using k = 0.005 * Ubar^2 = 0.005 m²/s² uniformly.

Initialize omega using omega = sqrt(k) / (Cmu^0.25 * 0.07 * H) where Cmu = 0.09, giving approximately omega = 47 s⁻¹ uniformly.

Apply cyclic boundary conditions for U, p, k, and omega on the inlet/outlet and front/back patch pairs.

Apply noSlip for U on bottomWall and topWall.

Apply kqRWallFunction for k on bottomWall and topWall.

Apply omegaWallFunction for omega on bottomWall and topWall.

Apply zeroGradient for p on bottomWall and topWall.

Apply nutWallFunction for nut on bottomWall and topWall.

In fvOptions, use the meanVelocityForce function object to drive the flow to the target bulk velocity Ubar = (1 0 0) m/s.

Set the meanVelocityForce selectionMode to all and Ubar to (1 0 0).

In fvSchemes, use Gauss linear for gradient schemes, Gauss linearUpwind grad(U) for the divergence of U, Gauss linear corrected for Laplacian schemes, and linear interpolation.

In fvSolution, use GAMG solver for p with tolerance 1e-6 and relative tolerance 0.01, and smoothSolver with GaussSeidel for U, k, and omega with tolerance 1e-8.

Use the PIMPLE algorithm with nOuterCorrectors = 2, nCorrectors = 2, and nNonOrthogonalCorrectors = 1.

Set endTime = 5 s.

Set deltaT = 0.001 s as the initial time step.

Set adjustTimeStep to yes with maxCo = 1.0.

Set writeInterval = 0.1 s using runTime write control.

Set writeFormat to binary and purgeWrite to 0 to keep all time directories.
