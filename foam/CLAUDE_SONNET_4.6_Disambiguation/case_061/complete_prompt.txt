Simulate transient turbulent incompressible flow in a straight channel, driven by a constant mean pressure gradient (implemented as a mean-velocity forcing).

Solver: pimpleFoam

Geometry: 3D channel (periodic box)
- Length Lx = 2.0 m
- Height H = 0.10 m
- Width Lz = 0.10 m
Walls at y=0 and y=H. Periodic in x and z.

Mesh: blockMesh (100 50 50) (refine near walls if needed). Patches:
- xMin (cyclic) <-> xMax (cyclic)
- zMin (cyclic) <-> zMax (cyclic)
- lowerWall (y=0), upperWall (y=H)

Physical properties: incompressible air-like nu = 1.5e-5 m^2/s (constant/transportProperties).

Turbulence: RAS kOmegaSST (constant/momentumTransport). Use wall functions on the walls (kqRWallFunction, omegaWallFunction, nutkWallFunction).

Flow driving (system/fvOptions): use meanVelocityForce to maintain a target bulk velocity, e.g. Ubar = (1 0 0).
Example:
meanU
{
  type                meanVelocityForce;
  active              yes;
  selectionMode       all;
  meanVelocityForceCoeffs
  {
    Ubar              (1 0 0);
    relaxation        0.1;
  }
}

Initial conditions (0/):
- U internalField uniform (1 0 0)
- p internalField uniform 0
- k, omega initialized uniformly from turbulence intensity I=1%:
  k = 1.5*(I*|U|)^2 = 1.5*(0.01*1)^2 = 1.5e-4
  omega = k^0.5/(Cmu^0.25*L) with L=0.01 m (or set omega=10 as a reasonable start)

Boundary conditions:
- xMin/xMax and zMin/zMax: cyclic for all fields
- lowerWall/upperWall:
  - U noSlip
  - p zeroGradient
  - k kqRWallFunction
  - omega omegaWallFunction

Time controls (controlDict): startTime 0; endTime 5; deltaT 0.001; adjustTimeStep yes; maxCo 1.0; writeInterval 0.1.
PIMPLE (fvSolution): nOuterCorrectors 1-2; nCorrectors 2; nNonOrthogonalCorrectors 0.
