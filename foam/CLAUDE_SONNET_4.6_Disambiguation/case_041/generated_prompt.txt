Simulate a 2D buoyant cavity (natural convection) using OpenFOAM with the buoyantBoussinesqSimpleFoam solver.
The cavity is square with dimensions 1m x 1m (aspect ratio 1:1).
The working fluid is air, modeled under the Boussinesq approximation.
Target a Rayleigh number of 1e6, which is a well-established benchmark case for laminar natural convection in a square cavity.
Derive the temperature difference between the hot and cold walls from the Rayleigh number definition using air properties at 300K (rho=1.177 kg/m3, nu=1.589e-5 m2/s, alpha=2.257e-5 m2/s, beta=1/300 K-1, g=9.81 m/s2), giving a wall temperature difference of approximately 30K.
Set the hot left wall temperature to 315K and the cold right wall temperature to 285K.
Apply no-slip velocity condition (U = noSlip) on all four walls.
Apply a fixed temperature of 315K on the left wall and 285K on the right wall for the thermal boundary condition.
Apply zeroGradient for temperature (T) on the top and bottom walls (adiabatic/insulated).
Apply fixedFluxPressure for p_rgh on all walls.
Use a structured, uniform 2D mesh of 50x50 cells in the x and y directions respectively.
Set the mesh depth (z-direction) to one cell thick (0.01m) with empty boundary conditions on the front and back faces to enforce 2D behavior.
Use the SIMPLE algorithm for pressure-velocity coupling as provided by buoyantBoussinesqSimpleFoam.
Set residual convergence tolerances to 1e-6 for pressure (p_rgh) and 1e-5 for velocity (U) and temperature (T).
Set the relaxation factors to 0.7 for U, 0.3 for p_rgh, and 0.5 for T following standard best practices for buoyancy-driven flows.
Use the linearUpwind scheme for divergence terms and Gauss linear corrected for Laplacian terms.
Run the simulation until all residuals fall below the specified convergence tolerances or for a maximum of 5000 iterations.
Use the k-epsilon or laminar turbulence model; since Ra=1e6 is within the laminar regime, set the simulationType to laminar in turbulenceProperties.
Set gravitational acceleration to g = (0, -9.81, 0) m/s2 in the constant/g file.
Set the reference pressure to 0 Pa at a reference point inside the domain.
Output field data (U, T, p_rgh) every 500 iterations for post-processing.
Validate results against the De Vahl Davis (1983) benchmark data for Nu (average Nusselt number on the hot wall should be approximately 8.8 for Ra=1e6).
