Set up a supersonic flow simulation over a forward-facing step using rhoCentralFoam in OpenFOAM.

The computational domain is 3 m in the x-direction and 1 m in the y-direction (2D).
A forward-facing step of height 0.2 m begins at x = 0.6 m and extends to the outlet, reducing the channel height to 0.8 m downstream of x = 0.6 m.
The flow is inviscid (Euler equations only; no viscosity model).

Use a structured mesh with approximately 150 cells in the x-direction and 50 cells in the y-direction for the base resolution.
Apply mesh refinement near the step corner and along expected shock propagation paths.
The mesh upstream of the step (x = 0 to 0.6 m) spans the full 1 m height; downstream (x = 0.6 m to 3 m) spans 0.8 m height.

The inlet boundary condition is a fixed supersonic inflow at Mach 3.
Set inlet static pressure to 101325 Pa.
Set inlet static temperature to 300 K.
Set inlet velocity to U = (1020.6, 0, 0) m/s.

The outlet boundary uses waveTransmissive for pressure with pInf = 101325 Pa.
The outlet boundary uses zeroGradient (or waveTransmissive) for velocity and temperature.

The top wall uses a slip boundary condition for all flow variables.
The bottom wall and all step faces (bottom face, vertical riser face) use slip boundary conditions for all flow variables.

Use the hePsiThermo thermophysical model with perfectGas equation of state and hConst transport/thermo.
Set Cp = 1005 J/kg/K.
Set molecular weight (molWeight) = 28.9 kg/kmol.
Derive gamma as 1.4 (consistent with Cp and molWeight for ideal air).

Set the thermodynamicType in thermophysicalProperties to hePsiThermo, pureMixture, hConst, perfectGas, specie, sensibleEnthalpy.

In fvSchemes, use Gauss linear or Gauss vanLeer for divergence schemes appropriate for rhoCentralFoam.
Set the flux scheme to Kurganov in fvSolution or rhoCentralFoam control dictionaries.

Set the initial conditions throughout the domain to match the inlet values: p = 101325 Pa, T = 300 K, U = (1020.6, 0, 0) m/s.

Run the simulation until a steady or quasi-steady shock structure is established, monitoring residuals and flow field for convergence.
Write solution output at regular intervals to allow visualization of the shock system, including the detached bow shock ahead of the step and any reflected shocks.
