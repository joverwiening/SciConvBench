Simulate a 2D lid-driven cavity flow using OpenFOAM's icoFoam solver.
The cavity is a square domain with side length 0.1 m.
Use a 20x20x1 computational mesh (20 cells in x, 20 cells in y, 1 cell in z).
The domain is a unit square scaled to 0.1 m x 0.1 m x one-cell-thick in z (treat as 2D using empty boundary conditions on front and back faces).
Set kinematic viscosity nu = 0.01 m²/s in the transportProperties file.
The top wall (y = 0.1 m) moves with a velocity of 1 m/s in the x-direction.
Set the top wall boundary condition to fixedValue with U = (1 0 0) m/s.
Set the bottom wall (y = 0 m) and side walls (x = 0 m and x = 0.1 m) as no-slip walls with fixedValue U = (0 0 0) m/s.
Set pressure boundary conditions on all walls to zeroGradient.
Set the front and back faces (z-direction) to empty boundary type for 2D treatment.
Initialize the internal field for velocity U = (0 0 0) m/s and pressure p = 0 Pa.
Use a fixed time step deltaT = 0.005 s.
Set the simulation start time to 0 s and end time to 0.5 s.
Write output results at a suitable write interval (e.g., every 0.05 s) using the controlDict.
Use the icoFoam solver to run the simulation.
Set the solver tolerances for p and U in fvSolution to standard icoFoam defaults (e.g., p tolerance 1e-6, U tolerance 1e-5).
Use standard icoFoam fvSchemes with Gauss linear interpolation and Euler time scheme.
