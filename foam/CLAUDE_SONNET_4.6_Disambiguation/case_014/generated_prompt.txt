Set up a laminar counter-flow diffusion flame simulation using the reactingFoam solver in OpenFOAM.

The domain is rectangular spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Use 100 cells in the x direction, 40 cells in the y direction, and 1 cell in the z direction.
Use a uniform mesh with no grading in any direction.

Name the boundary at x=0 as "fuel".
Name the boundary at x=0.02 as "air".
Name the boundaries at y=-0.01 and y=0.01 as "outlet".
Name the z-normal boundaries as "frontAndBack" and set them as empty type.

Set the fuel boundary as a fixedValue inlet with velocity (0.1, 0, 0) m/s.
Set the air boundary as a fixedValue inlet with velocity (-0.1, 0, 0) m/s.
Set the outlet boundaries as zeroGradient for velocity.

Initialize the entire domain at time 0 with a temperature of 2000 K.
Set pressure to 101325 Pa throughout the domain.

At the fuel boundary, set the mass fraction of CH4 to 1.0 and all other species to 0.
At the air boundary, set the mass fraction of O2 to 0.233, N2 to 0.767, and all other species to 0.
Initialize the domain with a mixed composition: CH4=0.5 on the fuel side blending to O2=0.233 and N2=0.767 on the air side, or use a uniform initial composition of N2=1.0 as inert fill with temperature 2000 K.

Use the following species: CH4, O2, N2, CO2, H2O, CO, H2, OH.
Use a simplified 4-step or skeletal methane-air mechanism based on the Jones-Lindstedt reduced mechanism as a best-practice assumption for these species.
Define reactions including: CH4 partial oxidation to CO and H2, CO oxidation to CO2, H2 oxidation to H2O, and OH radical participation.
Write the reactions and Arrhenius coefficients consistent with the Jones-Lindstedt 4-step methane mechanism.

Use reactingFoam as the solver.
Use compressible finite-rate chemistry formulation.
Use hePsiThermo as the thermodynamic model.
Use coefficientWilkeMultiComponentMixture as the mixture model.
Use Sutherland transport model.
Use JANAF thermodynamic data for all species.
Use laminar as the combustion model.
Use laminar as the momentum transport model.

Use EulerImplicit as the chemistry type.
Use Rosenbrock43 as the ODE solver for chemistry integration.
Set the chemistry ODE solver absolute tolerance to 1e-9 and relative tolerance to 1e-6 as best-practice defaults.

Set the simulation timestep (deltaT) to 1e-4 s.
Set the end time to 0.5 s.
Set the write interval to 0.05 s.
Use adjustTimeStep no so the fixed timestep is maintained.

For pressure boundary conditions, use fixedValue at fuel and air inlets set to 101325 Pa, and zeroGradient at outlet.
For temperature boundary conditions, set fixedValue of 300 K at the fuel boundary, fixedValue of 300 K at the air boundary, and zeroGradient at outlet.
For species boundary conditions, use fixedValue at fuel and air inlets as specified, and zeroGradient at outlet.

Use fvSchemes with Gauss linear interpolation for gradient schemes, Gauss limitedLinear for divergence of velocity, Gauss limitedLinear for divergence of species and enthalpy, and Euler for time discretization.
Use PIMPLE algorithm with nOuterCorrectors 1, nCorrectors 2, and nNonOrthogonalCorrectors 0 in fvSolution.
