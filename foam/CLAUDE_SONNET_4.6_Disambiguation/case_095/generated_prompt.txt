The simulation uses buoyantBoussinesqSimpleFoam to find the steady-state solution for a 2D square cavity of 1m x 1m.
The mesh is 50 cells in the x-direction and 50 cells in the y-direction, created using blockMesh.
The domain is 2D (one cell deep in the z-direction with empty boundary conditions on front and back faces).
Gravity is set to (0, -9.81, 0) m/s² in the constant/g file.
The fluid is air at approximately 300K with the following properties.
Kinematic viscosity nu = 1.5e-5 m²/s.
Prandtl number Pr = 0.71.
Thermal expansion coefficient beta = 3.33e-3 1/K.
Reference temperature T0 = 300 K.
Reference density rho0 = 1.0 kg/m³.
Thermal diffusivity alphaEff is derived from nu and Pr as alpha = nu/Pr = 2.113e-5 m²/s.
The left wall has a fixed temperature boundary condition of 310 K.
The right wall has a fixed temperature boundary condition of 290 K.
The top and bottom walls are insulated, meaning a zeroGradient boundary condition is applied to temperature on those faces.
All four walls have a no-slip boundary condition for velocity (fixedValue uniform (0 0 0)).
Pressure p_rgh uses fixedFluxPressure on all walls.
The initial internal field for temperature is set to 300 K (uniform).
The initial internal field for velocity is set to (0 0 0) (uniform).
The initial internal field for p_rgh is set to 0 (uniform).
Use the SIMPLE algorithm for pressure-velocity coupling.
Set the number of SIMPLE corrector iterations to 1.
Use Gauss linear corrected schemes for Laplacian terms.
Use Gauss linear for gradient schemes.
Use Gauss linearUpwind for divergence schemes on velocity and temperature.
Set relaxation factors: p_rgh = 0.3, U = 0.7, T = 0.7.
Run the simulation for 2000 iterations or until residuals drop below 1e-6 for all fields.
Write results every 500 iterations.
Use residualControl in the SIMPLE dict to stop when all residuals are below 1e-6.
The transportModel entry in transportProperties is set to Newtonian.
The turbulence model is set to laminar in turbulenceProperties.
