The simulation uses OpenFOAM with the rhoReactingFoam solver.
The domain is a rectangular tube 0.5 m long, 0.01 m wide, and 0.01 m high.
Model the geometry as a 3D rectangular box with the length along the x-axis.
Use a structured hexahedral mesh generated with blockMesh.
Choose a mesh resolution sufficient to resolve the flame front, recommended at least 500 cells in the x-direction and 10 cells each in the y and z directions (500 x 10 x 10).
All six walls are no-slip (U = fixedValue uniform (0 0 0)) and adiabatic (T = zeroGradient, p = zeroGradient).
The closed-tube condition means all walls, including both ends (x=0 and x=0.5 m), are treated as solid walls with no inlet or outlet.
Use a 9-species, 19-reaction detailed hydrogen-air chemical mechanism.
Convert the mechanism from CHEMKIN format to OpenFOAM format using the chemkinToFoam utility.
Place the resulting reactions file and thermo data in the constant directory.
Species included in the mechanism are H2, O2, H2O, H, O, OH, HO2, H2O2, and N2.
Set the turbulence model to laminar (no turbulence modeling) in constant/turbulenceProperties.
Set the initial conditions for the entire domain to T=300 K, p=101325 Pa, and velocity U=(0 0 0).
Set the initial mass fractions for the unburned mixture as H2=0.028, O2=0.225, N2=0.747, and all other species to zero.
Use setFieldsDict to define a high-temperature ignition patch from x=0 to x=0.01 m (the first 2% of the domain).
In the ignition patch, set T=2000 K and keep pressure and composition the same as the rest of the domain.
Run setFields before starting the simulation to apply the ignition patch.
Use the PIMPLE algorithm for pressure-velocity coupling as configured by default in rhoReactingFoam.
Set the maximum Courant number (maxCo) to 0.3 in controlDict to ensure numerical stability.
Set deltaT to adjustable with automatic time-step control enabled.
Set the simulation end time to 0.005 s to capture full flame propagation across the 0.5 m tube.
Write output every 1e-4 s for post-processing.
Use linear interpolation schemes and Gauss limitedLinear for divergence schemes in fvSchemes to balance accuracy and stability.
Set solver tolerances for p, U, T, and species to 1e-6 in fvSolution.
Post-process results using ParaView to visualize temperature, pressure, and species mass fraction fields over time.
Monitor the flame front position by tracking the location of maximum heat release rate or the T=1500 K isosurface along the x-axis.
