Final Specification for Sod Shock Tube Simulation using rhoCentralFoam:

The simulation is a 1D Sod shock tube problem solved with the rhoCentralFoam solver in OpenFOAM.

GEOMETRY AND MESH

The domain runs from (0 0 0) to (1 0.1 0.1) meters.
Use blockMesh with a single block divided into 400 1 1 cells in the x, y, z directions respectively.
The left, right, front, back, top, and bottom patches are all set to type empty to enforce 1D behavior.
The inlet patch corresponds to the x=0 face and the outlet patch corresponds to the x=1 face.

BOUNDARY CONDITIONS

Set both the inlet (x=0) and outlet (x=1) patches to zeroGradient for p, T, U, and all other fields.
Set all remaining patches (top, bottom, front, back) to type empty.

INITIAL CONDITIONS

For x < 0.5: set p = 100000 Pa, T = 348.4 K, U = (0 0 0).
For x >= 0.5: set p = 10000 Pa, T = 278.7 K, U = (0 0 0).
Use the setFields utility with a fieldBoxValues entry targeting the right half of the domain to set the right-state values after initializing the entire field with left-state values.
Density is not set directly; it is derived automatically from the perfect-gas equation of state.

THERMOPHYSICAL MODEL

Use thermoType: hePsiThermo, pureMixture, const transport, hConst thermodynamics, perfectGas equation of state, specie, sensibleEnthalpy energy.
Set molWeight = 28.9 kg/kmol.
Set Cp = 1005 J/kg/K.
Set Hf = 0 J/kg.
Set dynamic viscosity mu = 1.8e-5 Pa·s (standard air value).
Set Prandtl number Pr = 0.713 (standard air value).

TIME CONTROL

Set startTime = 0.
Set endTime = 0.007 s.
Set deltaT = 1e-6 s as the initial time step.
Enable adjustable time-stepping by setting adjustTimeStep = yes.
Set maxCo = 0.5.
Set writeControl to adjustableRunTime.
Set writeInterval = 0.0005 s.

NUMERICAL SCHEMES (system/fvSchemes)

Set the default fluxScheme to Kurganov (suitable for rhoCentralFoam).
Set ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes for reconstruct(rho), reconstruct(U), and reconstruct(T) all to vanLeer.
Set snGradSchemes default to corrected.

SOLUTION SETTINGS (system/fvSolution)

Use default solver settings compatible with rhoCentralFoam; no iterative pressure-velocity coupling is needed as rhoCentralFoam is density-based.
Set solver for rho, rhoU, and rhoE to diagonal (explicit update).
Set solver for p and e to PBiCGStab with DILU preconditioner, tolerance 1e-8, relTol 0.

EXECUTION STEPS

Run blockMesh to generate the mesh.
Run setFields to apply the right-state initial conditions to the region x >= 0.5.
Run rhoCentralFoam to execute the simulation.
Post-process results using sample or foamToVTK to extract the 1D profiles of p, T, U, and rho along the x-axis at desired write times.
