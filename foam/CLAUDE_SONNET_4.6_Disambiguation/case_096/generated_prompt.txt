The simulation domain is a 2D square cavity of 0.1 m × 0.1 m (aspect ratio 1:1) with a 1-cell depth in the z-direction.
Use OpenFOAM solver buoyantBoussinesqSimpleFoam (steady-state, finite volume, Boussinesq approximation).
Generate the mesh using blockMesh with a 50 × 50 × 1 grid, giving uniform cell spacing of 0.002 m in x and y.
The fluid is air with kinematic viscosity nu = 1.5e-5 m²/s, Prandtl number Pr = 0.71, thermal expansion coefficient beta = 3.33e-3 1/K, reference temperature T0 = 293.5 K, and reference density rho0 = 1.0 kg/m³.
Set gravitational acceleration to g = (0, -9.81, 0) m/s².
The bottom wall (bottomHot) is a no-slip wall held at a fixed temperature of 294.0 K.
The top wall (topCold) is a no-slip wall held at a fixed temperature of 293.0 K.
The temperature difference across the cavity is ΔT = 1 K.
Both side walls (left and right) have U set to no-slip (fixedValue, uniform (0 0 0)).
Both side walls have T set to zeroGradient (adiabatic).
Both side walls have p_rgh set to fixedFluxPressure.
The front and back faces (z-direction) are set to empty to enforce 2D simulation.
For the bottom and top walls, set p_rgh to fixedFluxPressure.
Set the initial internal field for U to uniform (0 0 0), for T to uniform 293.5 K, and for p_rgh to uniform 0.
Use the SIMPLE algorithm in fvSolution with residualControl to terminate the run.
Set residualControl tolerances to 1e-5 for U, p_rgh, and T.
Use default relaxation factors appropriate for buoyantBoussinesqSimpleFoam: U = 0.7, p_rgh = 0.3, T = 0.5, rho = 1.0, h = 0.5.
Set endTime to 5000 with deltaT = 1 (each iteration counts as one time step in SIMPLE).
Set writeInterval to 500 so solution fields are saved at every 500 iterations.
Use Gauss linear schemes for gradient and divergence terms, and Gauss linear corrected for Laplacian terms in fvSchemes.
Use GAMG solver for p_rgh and smoothSolver for U and T in fvSolution.
The Rayleigh number for this configuration is Ra = g * beta * ΔT * H³ / (nu * alpha), where alpha = nu / Pr, which gives Ra ≈ 2870, placing the simulation in the weakly convective regime above the critical Ra of 1708.
Output fields to be written include U, T, p_rgh, and p at each write interval.
