The simulation models incompressible turbulent flow through a thin porous screen in a 2D planar channel using OpenFOAM with the simpleFoam solver.

The channel is 1.0 m long and 0.1 m high, with a depth of one cell (2D simulation in the x-y plane).
The mesh is structured and Cartesian, with the single-cell depth in the z-direction.
Use approximately 200 cells in the x-direction and 40 cells in the y-direction, with uniform cell spacing.
The porous baffle (screen) is located at x = 0.5 m, spanning the full height of the channel from y = 0.0 m to y = 0.1 m.

Model the porous screen as a cyclic ACMi (arbitrary coupled mesh interface) baffle using the porousBafflePressure boundary condition in OpenFOAM.
Define the baffle as an internal faceZone at x = 0.5 m created during mesh generation using blockMesh or snappyHexMesh.
Apply the porousBafflePressure condition with Darcy coefficient D = 1e7 and Inertial coefficient I = 0.0.
Set the length of the porous medium (thickness) to 1e-3 m to represent a thin screen.

Use the k-omega SST turbulence model.
At the inlet, apply a fixedValue velocity boundary condition of uniform (5 0 0) m/s.
Calculate inlet turbulent kinetic energy k using k = 1.5 * (U * Ti)^2, where turbulent intensity Ti = 0.05 (5%) and U = 5 m/s, giving k = 0.09375 m^2/s^2.
Calculate inlet specific dissipation rate omega using omega = k^0.5 / (Cmu^0.25 * L), where Cmu = 0.09 and mixing length L = 0.07 * 0.1 m (7% of channel height), giving omega approximately 1109 s^-1.
Apply zeroGradient for velocity at the outlet.
Apply fixedValue uniform 0 for pressure at the outlet.
Apply zeroGradient for pressure at the inlet.
Apply noSlip for velocity on the top and bottom walls.
Apply kqRWallFunction for k on walls, omegaWallFunction for omega on walls, and nutkWallFunction for turbulent viscosity on walls.
Apply empty boundary conditions on the front and back faces (z-direction) for the 2D treatment.

Use air as the fluid with kinematic viscosity nu = 1.5e-5 m^2/s and density rho = 1.0 kg/m^3 (incompressible, so density is absorbed into the pressure definition).
Set the pressure field p to represent kinematic pressure (p/rho) with units m^2/s^2.

In fvSolution, use SIMPLE algorithm with consistent yes for improved stability.
Set relaxation factors: 0.7 for U, 0.3 for p, 0.5 for k and omega.
In fvSchemes, use Gauss linear for gradient schemes, Gauss linearUpwind grad(U) for divergence of U, Gauss upwind for divergence of turbulence quantities, and linear corrected for Laplacian schemes.
Run the simulation for a maximum of 2000 iterations or until all residuals drop below 1e-5.
Write results every 500 iterations.

The expected output is a converged steady-state solution showing a clear pressure drop across the porous baffle at x = 0.5 m, with a uniform velocity profile recovering downstream of the screen.
