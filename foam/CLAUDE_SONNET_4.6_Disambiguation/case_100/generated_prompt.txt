Perform a 3D turbulent Rayleigh-Benard convection simulation using OpenFOAM with the buoyantBoussinesqPimpleFoam solver.

The domain is a rectangular box with Lx = 0.40 m, Ly = 0.40 m, H = 0.10 m (aspect ratio 4:4:1).

Generate the mesh using blockMesh with a uniform grid of 80 x 80 x 40 cells, giving a total of 256,000 cells with no wall refinement.

The working fluid is water under the Boussinesq approximation.

Use the following thermophysical properties for water: kinematic viscosity nu = 1e-6 m²/s, thermal diffusivity alpha = 1.43e-7 m²/s, thermal expansion coefficient beta = 2.07e-4 K⁻¹, reference temperature Tref = 296.6 K, reference density rho0 = 998.0 kg/m³, and gravitational acceleration g = (0 0 -9.81) m/s².

These properties correspond to a Rayleigh number of approximately 1e8 based on the temperature difference delta_T = 6.8 K and height H = 0.10 m.

Use RANS turbulence modeling with the kOmegaSST model, configured in constant/momentumTransport with simulationType RAS.

Apply the following boundary conditions on the bottom wall (bottomHot): T = 300.0 K as fixedValue, U = (0 0 0) as noSlip, p_rgh as fixedFluxPressure, and wall function conditions for k and omega.

Apply the following boundary conditions on the top wall (topCold): T = 293.2 K as fixedValue, U = (0 0 0) as noSlip, p_rgh as fixedFluxPressure, and wall function conditions for k and omega.

Apply cyclic (periodic) boundary conditions on all four lateral side walls (in x and y directions) for all fields: U, T, p_rgh, k, and omega.

Initialize the flow with U = (0 0 0) everywhere, p_rgh = 0 everywhere, and T either uniform at T0 = 296.6 K or linearly interpolated between the bottom (300.0 K) and top (293.2 K) plates.

Use setFields to add a warm perturbation in the box region from (0.19 0.19 0.00) to (0.21 0.21 0.01), setting T = 296.65 K (T0 + 0.05 K) in that region to trigger convection.

Initialize k = 1e-6 m²/s² and omega = 1.0 s⁻¹ uniformly as reasonable low-turbulence starting values.

Set endTime = 30 s.

Set the initial deltaT = 1e-3 s with adjustTimeStep yes and maxCo = 0.9 so the time step adjusts automatically to maintain numerical stability.

Write simulation data to disk every writeInterval = 0.5 s.

Use the PIMPLE algorithm for pressure-velocity coupling with appropriate nOuterCorrectors, nCorrectors, and nNonOrthogonalCorrectors settings (e.g., 2, 2, 1 respectively) suitable for buoyancy-driven flow.

Use Gauss linear schemes for gradient and divergence terms, and Gauss linear corrected for Laplacian terms in fvSchemes.

Use GAMG solver for p_rgh and smoothSolver for U, T, k, and omega in fvSolution.

Output the fields U, T, p_rgh, k, and omega at each write interval for post-processing.
