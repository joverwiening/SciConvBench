Run the pisoFoam cavity tutorial in OpenFOAM with the following configuration.

Use the standard lid-driven cavity geometry: 1m x 1m x 1 cell (unit cavity).
Set the mesh resolution to 100 x 100 x 1 cells using blockMesh.
Set the lid (top boundary) velocity to U = (1 0 0) m/s (moving wall).
Set all other boundary conditions as in the standard cavity tutorial (no-slip walls, empty front and back).
Set kinematic viscosity nu = 2e-4 m²/s in transportProperties to achieve Re = 5000.
Set endTime = 50 in controlDict.
Set deltaT = 0.005 in controlDict as the initial time step.
Set adjustTimeStep to yes in controlDict.
Set maxCo = 0.5 in controlDict.
Set writeInterval to an appropriate value, such as 1 (write every 1 second of simulation time).
Use the pisoFoam solver.
In fvSolution under the PISO sub-dictionary, set nCorrectors to 3.
Set nNonOrthogonalCorrectors to 0.
Set nOuterCorrectors to 1 (standard PISO, no outer loops).
Use the standard fvSchemes settings from the cavity tutorial (Gauss linear for gradients and divergence, Euler for time discretisation).
Use GAMG or PCG solvers for pressure and smoothSolver for velocity as in the standard cavity fvSolution.
Run blockMesh to generate the mesh, then run pisoFoam to execute the simulation.
