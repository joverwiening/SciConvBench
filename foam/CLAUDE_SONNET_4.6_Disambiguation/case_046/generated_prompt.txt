Simulate a 2D lid-driven cavity flow using OpenFOAM's icoFoam solver.
The fluid is incompressible and the flow is laminar.
The cavity is a square domain with side length L = 0.1 m.
The kinematic viscosity nu is 0.001 m²/s.
The top wall moves to the right at U = 1 m/s.
The bottom wall, left wall, and right wall are stationary no-slip boundaries.
The resulting Reynolds number is Re = 100.
Use a structured mesh of 20x20 cells in the X and Y directions.
Set the simulation end time to endTime = 0.5 s.
Set the time step size to deltaT = 0.002 s.
Use standard icoFoam case structure with 0/, constant/, and system/ directories.
In the 0/ directory, define boundary conditions for U and p fields.
Set the top wall velocity to (1 0 0) m/s using a fixedValue boundary condition.
Set all other walls to a fixedValue velocity of (0 0 0) m/s.
Set pressure p to zeroGradient on all walls.
In constant/transportProperties, set nu to 0.001 m²/s.
In constant/polyMesh, generate the mesh using blockMesh with 20 cells in each direction.
In system/controlDict, set application to icoFoam, startTime to 0, endTime to 0.5, and deltaT to 0.002.
In system/fvSchemes, use standard first or second order schemes appropriate for laminar incompressible flow.
In system/fvSolution, configure solvers for p and U with appropriate tolerances (e.g., tolerance 1e-6).
Run blockMesh to generate the mesh, then run icoFoam to execute the simulation.
