Simulate external aerodynamics on a 3D Ahmed body using OpenFOAM with the simpleFoam solver (steady-state, incompressible, turbulent RANS).

Geometry: Use the standard Ahmed body dimensions: length L = 1.044 m, width = 0.389 m, height = 0.288 m, with a rear slant angle of 25 degrees.

Domain extents: Place the inlet 4L upstream of the body nose, the outlet 10L downstream of the body base, 3L to each lateral side from the body centerline, and 3L above the body roof.

Include a ground plane at the bottom of the domain (z = 0), coinciding with the underside of the Ahmed body supports.

Use simpleFoam as the steady-state incompressible Navier-Stokes solver.

Apply the k-omega SST (kOmegaSST) turbulence model with wall functions on all solid surfaces.

Set the inlet velocity to U = (11 0 0) m/s in the streamwise direction.

The Reynolds number is Re_L = 7.68e5 based on body length L = 1.044 m.

Compute kinematic viscosity as nu = U * L / Re_L (approximately 1.496e-5 m^2/s).

Boundary conditions: Set the inlet as a fixedValue velocity inlet with U = (11 0 0) m/s, turbulent kinetic energy k and specific dissipation rate omega estimated from turbulence intensity (use 1% intensity and turbulent length scale 0.07 times the inlet hydraulic diameter as defaults).

Set the outlet as a zeroGradient condition for velocity and a fixedValue of 0 for pressure.

Set the ground plane as a no-slip wall (fixedValue U = (0 0 0)) to represent a stationary ground.

Set the top and two lateral side boundaries as slip walls (symmetryPlane or slip condition).

Set all Ahmed body surfaces as no-slip walls with wall functions for k and omega (kqRWallFunction for k, omegaWallFunction for omega, nutkWallFunction for turbulent viscosity).

Set pressure to zeroGradient at all walls and inlet.

Generate a hex-dominant mesh using snappyHexMesh with refinement levels on the Ahmed body surface and in the wake region behind the slant.

Target a y+ value in the range 30 to 100 on the body surfaces to be consistent with wall function usage.

Apply at least two levels of volumetric refinement in the near-wake region behind the rear slant and one level in the far wake.

Run simpleFoam until residuals for U, p, k, and omega drop below 1e-5 or until the drag coefficient Cd stabilizes.

Calculate the drag force on the Ahmed body by integrating pressure and viscous stress forces on all body patches in the streamwise (x) direction.

Compute the drag coefficient as Cd = F_drag / (0.5 * rho * U^2 * A_ref), where A_ref is the frontal area of the Ahmed body (width times height = 0.389 m * 0.288 m) and rho = 1.225 kg/m^3.

Output the drag coefficient Cd as the primary result.

Use the forceCoeffs function object in OpenFOAM to monitor and report Cd at each iteration.
