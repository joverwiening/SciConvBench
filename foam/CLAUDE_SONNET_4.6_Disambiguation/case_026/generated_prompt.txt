Run a transient laminar two-phase VOF simulation of a dam-break with an internal obstacle using OpenFOAM's interFoam solver.

Use blockMesh to generate the mesh entirely from scratch with no external geometry files.

Define the domain as a cube from (0,0,0) to (1,1,1).

Divide the domain into a uniform 32x32x32 grid as the base block.

Represent the obstacle as a solid rectangular block from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) by defining it as a separate block in blockMeshDict with zero cells (0 0 0) so it is excluded from the fluid mesh.

Define the blockMeshDict with the fluid region as the full cube minus the obstacle block, using appropriate block topology to carve out the obstacle region.

Set gravity as g = (0 0 -9.81) m/s^2 in the constant/g file.

Use the VOF method via interFoam to model two phases: water and air.

Define water with density = 1000 kg/m^3 and kinematic viscosity = 1.0e-6 m^2/s.

Define air with density = 1 kg/m^3 and kinematic viscosity = 1.48e-5 m^2/s.

Set surface tension between water and air to 0.07 N/m.

Assign the top face of the domain (z = 1) as a patch named atmosphere with boundary type patch and set it as an open atmosphere boundary (totalPressure for p_rgh, inletOutlet for U, inletOutlet for alpha.water).

Assign all remaining five faces (x=0, x=1, y=0, y=1, z=0) and the obstacle surfaces as wall boundary conditions with no-slip velocity.

Set the turbulence model to laminar.

Initialize alpha.water = 1 inside the rectangular prism from (0,0,0) to (0.6, 0.1875, 0.75) and alpha.water = 0 everywhere else using setFields with a fieldBoxToCell source.

Set deltaT = 1e-3 s in the controlDict.

Set endTime = 0.1 s in the controlDict.

Set writeInterval = 0.02 s in the controlDict.

Use adjustableRunTime for write control.

Use Euler time scheme for time integration.

Use Gauss linear for gradient schemes and Gauss linearUpwind for divergence of velocity.

Use MULES for alpha.water advection.

Use PIMPLE loop with nOuterCorrectors = 1, nCorrectors = 3, and nNonOrthogonalCorrectors = 0.
