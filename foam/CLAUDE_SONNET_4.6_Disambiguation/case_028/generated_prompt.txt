Use OpenFOAM's interFoam solver to run a transient two-phase laminar dam-break simulation with an obstacle.

The computational domain is a cube from (0,0,0) to (1,1,1).
Discretize the domain uniformly with a 32 x 32 x 32 hexahedral mesh using blockMesh.
Define a rectangular box-shaped obstacle (a wall patch or refinement region) occupying (0.375, 0.375, 0) to (0.625, 0.625, 0.25) inside the domain.
Treat the obstacle surfaces as no-slip walls.

Set gravity as g = (0, 0, -9.81) m/s² in the constant/g file.

Use the following fluid properties in constant/transportProperties.
Water phase: rho = 1000 kg/m³, nu = 1e-6 m²/s.
Air phase: rho = 1 kg/m³, nu = 1.48e-5 m²/s.
Set the surface tension coefficient sigma = 0.07 N/m between water and air.

Set the turbulence model to laminar in constant/turbulenceProperties.

Initialize the alpha.water field so that alpha.water = 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75) and alpha.water = 0 everywhere else.
Use the setFields utility with a fieldBoxValues entry to apply this initialization.

Apply the following boundary conditions to all outer domain faces (six sides of the cube): no-slip wall condition (fixedValue zero) for velocity U, zeroGradient for pressure p_rgh, and zeroGradient for alpha.water.
Apply no-slip wall boundary conditions on all obstacle surfaces.

Set deltaT = 1e-3 s in system/controlDict.
Set startTime = 0 s.
Set endTime = 0.1 s.
Set writeInterval = 0.02 s.
Set writeControl to timeStep or runTime consistent with the writeInterval of 0.02 s.

Use the MULES scheme for alpha.water advection as configured by default in interFoam.
Use Gauss linear schemes for gradient and divergence terms as appropriate for a laminar interFoam case.
Use PIMPLE or PISO loop settings as per standard interFoam defaults in system/fvSolution and system/fvSchemes.
