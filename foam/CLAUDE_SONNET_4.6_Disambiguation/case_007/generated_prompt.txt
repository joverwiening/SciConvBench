Final Specification:

The simulation is an incompressible lid-driven cavity flow using OpenFOAM.
Use the pisoFoam solver.
Create a 3D block mesh with 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.
The domain represents a 2D flow problem using the empty condition on front and back faces.
The top wall boundary is named 'movingWall' and moves in the x-direction with a uniform velocity of (1 0 0) m/s.
The remaining walls are named 'fixedWalls' and have a no-slip boundary condition with velocity (0 0 0) m/s.
The front and back faces are named 'frontAndBack' and are designated as 'empty' type for both velocity and pressure.
Set the pressure field p with zeroGradient on movingWall and fixedWalls, and empty on frontAndBack.
Initialize the entire velocity field U to (0 0 0) m/s at time 0.
Initialize the pressure field p to 0 uniformly at time 0.
The simulation starts at time 0 and ends at time 10.
The time step deltaT is 0.005.
Write output results every 100 time steps, meaning set writeControl to timeStep and writeInterval to 100.
Use a constant kinematic viscosity nu with a value of 1e-05 m^2/s in the transportProperties file.
Set the transportModel to Newtonian.
Use the k-epsilon turbulence model by setting RASModel to kEpsilon in the turbulenceProperties or RASProperties file.
Set turbulence to on and printCoeffs to on in the turbulence properties file.
Initialize the turbulent kinetic energy field k to 1.5e-4 uniformly throughout the domain at time 0.
Apply kqRWallFunction boundary condition for k on movingWall and fixedWalls.
Apply empty boundary condition for k on frontAndBack.
Initialize the turbulent dissipation rate field epsilon to 1.4e-4 uniformly throughout the domain at time 0.
Apply epsilonWallFunction boundary condition for epsilon on movingWall and fixedWalls.
Apply empty boundary condition for epsilon on frontAndBack.
Initialize the turbulent viscosity field nut to 0 uniformly throughout the domain at time 0.
Apply nutkWallFunction boundary condition for nut on movingWall and fixedWalls.
Apply empty boundary condition for nut on frontAndBack.
In the fvSchemes file, set the time scheme ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear.
Set the convection scheme div(phi,U) to Gauss limitedLinearV 1.
Set the convection scheme div(phi,k) to Gauss limitedLinear 1.
Set the convection scheme div(phi,epsilon) to Gauss limitedLinear 1.
Set the viscous term scheme div((nuEff*dev2(T(grad(U))))) to Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.
In the fvSolution file, use a linear solver for p such as PCG with DIC preconditioner, with tolerance 1e-06 and relTol 0.05.
Use a linear solver for U, k, and epsilon such as PBiCG with DILU preconditioner, with tolerance 1e-05 and relTol 0.1.
Use the PISO algorithm with nCorrectors set to 2 and nNonOrthogonalCorrectors set to 0.
Set nOuterCorrectors to 1 if required by the solver settings.
The mesh is a unit cube or appropriately scaled cavity; define the block vertices to form a square cavity of side 1 m in x and y, and a small thickness (e.g., 0.1 m) in z.
Use uniform cell spacing with simpleGrading (1 1 1).
