The simulation uses chtMultiRegionFoam with two regions: "fluid" and "solid".

The fluid cavity is 1.0 m wide, 1.0 m tall, and 0.01 m deep (one cell deep in z for 2D).
The solid block is 0.4 m wide and 0.4 m tall, centered at (0.5, 0.5, 0.005) in the cavity.
The fluid region occupies the cavity volume minus the solid block volume.

Generate the mesh using blockMesh and snappyHexMesh, or use blockMesh with multi-block to define the fluid region as the cavity with the central block removed, and the solid region as the central block.
Use a structured mesh with approximately 50x50 cells in the fluid region and 20x20 cells in the solid block.
Apply one cell in the z-direction with empty boundary conditions on front and back faces for 2D treatment.

The fluid region uses chtMultiRegionFoam's compressible solver with heRhoThermo thermophysical model.
Set the equation of state to perfectGas.
Set transport model to sutherland for the fluid.
Set Cp to 1005 J/kg/K for the fluid.
Set molWeight to 28.9 kg/kmol for the fluid.
Set Pr to 0.71 for the fluid (used internally by Sutherland transport).
Set Sutherland coefficients As=1.458e-6 and Ts=110.4 for air.

The solid region uses heRhoThermo with rhoConst equation of state.
Set solid density rho to 8960 kg/m3.
Set solid Cp to 385 J/kg/K.
Set solid thermal conductivity kappa to 401 W/m/K.
Set solid transport model to constIso.

Apply a fixed temperature boundary condition of 310 K on the left wall of the fluid cavity.
Apply a fixed temperature boundary condition of 290 K on the right wall of the fluid cavity.
Apply adiabatic (zeroGradient) boundary conditions for temperature on the top and bottom walls of the fluid cavity.
Apply no-slip (fixedValue U=0) on all fluid solid walls.
Apply zeroGradient for p_rgh on all walls except use fixedFluxPressure where appropriate.
Apply coupled boundary conditions (turbulentTemperatureCoupledBaffleMixed) at the fluid-solid interface for temperature in both regions.
Apply empty boundary conditions on front and back patches in both regions.

Set initial fluid temperature to 300 K throughout the fluid domain.
Set initial fluid velocity to (0 0 0) throughout the fluid domain.
Set initial fluid p_rgh to 0 Pa (gauge) throughout the fluid domain.
Set initial solid temperature to 300 K throughout the solid domain.

Use laminar flow modeling in the fluid region (set simulationType to laminar in turbulenceProperties).

Set gravity to (0 -9.81 0) in the constant/g file.

Set endTime to 50 s.
Set deltaT to 0.01 s.
Set adjustTimeStep to yes.
Set maxCo to 0.5.
Set writeInterval to 1 s.
Set writeFormat to ascii.
Set runTimeModifiable to yes.

Use PIMPLE algorithm settings in fvSolution for the fluid region with nOuterCorrectors 2, nCorrectors 2, nNonOrthogonalCorrectors 1.
Use standard fvSchemes with Gauss linear for gradient schemes, Gauss linearUpwind for divergence of velocity and enthalpy, and Euler for time discretization.

Create a system/decomposeParDict if parallel running is desired, otherwise run serially.
Run the case using the command: chtMultiRegionFoam.
Initialize the case using setFields or direct field files for each region placed under 0/fluid/ and 0/solid/ directories.
Place thermophysical properties in constant/fluid/thermophysicalProperties and constant/solid/thermophysicalProperties.
Place region mesh data in constant/fluid/polyMesh and constant/solid/polyMesh.
