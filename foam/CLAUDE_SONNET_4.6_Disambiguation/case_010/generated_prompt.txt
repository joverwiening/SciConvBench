Final Specification:

The simulation is an incompressible lid-driven cavity flow using OpenFOAM.

The cavity geometry is a square domain with dimensions 1 unit in x, 1 unit in y, and 0.1 units in z.

Generate a structured hexahedral mesh using blockMesh with 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.

Use a uniform cell grading of 1 in all directions (no grading).

Define the following boundary patches in blockMeshDict: movingWall (top face, y = 1), fixedWalls (bottom face y = 0, left face x = 0, right face x = 1), and empty (front and back faces in z-direction).

The solver is pisoFoam.

The fluid is incompressible with a constant kinematic viscosity nu = 1e-05 m^2/s defined in transportProperties.

Use the k-epsilon turbulence model defined in turbulenceProperties (or RASProperties), with RAS model set to kEpsilon and turbulence set to on.

Set the initial condition for velocity U to uniform (0 0 0) throughout the internal field at the start of the simulation.

Set the boundary condition for U on movingWall to fixedValue with uniform value (1 0 0).
Set the boundary condition for U on fixedWalls to fixedValue with uniform value (0 0 0) (no-slip).
Set the boundary condition for U on front and back faces to empty.

Set the initial condition for pressure p to uniform 0 throughout the internal field.
Set the boundary condition for p on movingWall to zeroGradient.
Set the boundary condition for p on fixedWalls to zeroGradient.
Set the boundary condition for p on front and back faces to empty.

Set the initial condition for k to uniform 1.5e-4 throughout the internal field.
Set the boundary condition for k on movingWall to kqRWallFunction with uniform value 1.5e-4.
Set the boundary condition for k on fixedWalls to kqRWallFunction with uniform value 1.5e-4.
Set the boundary condition for k on front and back faces to empty.

Set the initial condition for epsilon to uniform 1.4e-4 throughout the internal field.
Set the boundary condition for epsilon on movingWall to epsilonWallFunction with uniform value 1.4e-4.
Set the boundary condition for epsilon on fixedWalls to epsilonWallFunction with uniform value 1.4e-4.
Set the boundary condition for epsilon on front and back faces to empty.

Set the initial condition for nut to uniform 0 throughout the internal field.
Set the boundary condition for nut on movingWall to nutkWallFunction with uniform value 0.
Set the boundary condition for nut on fixedWalls to nutkWallFunction with uniform value 0.
Set the boundary condition for nut on front and back faces to empty.

In fvSchemes, set the ddtSchemes default to Euler.
Set the gradSchemes default to Gauss linear.
Set div(phi,U) to Gauss limitedLinearV 1.
Set div(phi,k) to Gauss limitedLinear 1.
Set div(phi,epsilon) to Gauss limitedLinear 1.
Set div((nuEff*dev2(T(grad(U))))) to Gauss linear.
Set the laplacianSchemes default to Gauss linear corrected.
Set the interpolationSchemes default to linear.
Set the snGradSchemes default to corrected.
Set the fluxRequired fields to p.

In fvSolution, use PCG solver with DIC preconditioner for p, with tolerance 1e-6 and relTol 0.05.
Use PBiCG solver with DILU preconditioner for U, k, and epsilon, with tolerance 1e-5 and relTol 0.1.
Set the PISO dictionary with nCorrectors 2 and nNonOrthogonalCorrectors 0.
