Build a 2D planar de Laval nozzle simulation using OpenFOAM with the following specification.

Use the rhoCentralFoam or rhoPimpleFoam steady-state compressible solver suitable for transonic and supersonic flows.

Model air as a perfect (ideal) gas with the following thermophysical properties: use the hePsiThermo thermodynamic model, perfectGas equation of state, and Sutherland transport model for dynamic viscosity.

Use standard Sutherland coefficients for air: As = 1.458e-6 kg/(m·s·K^0.5) and Ts = 110.4 K.

Set the specific heat at constant pressure Cp = 1005 J/(kg·K) and molecular weight Mw = 28.97 g/mol.

The geometry is a 2D planar nozzle, 1 metre long in the x-direction.

The inlet is at x = 0 with a full height of 0.2 m (half-height 0.1 m if symmetry is used, but model the full height as planar).

The throat is located at x = 0.5 m with a height of 0.1 m.

The outlet is at x = 1.0 m with a height of 0.3 m.

Define the nozzle wall profile as two smooth curves (top and bottom walls) connecting inlet, throat, and outlet heights; use a cosine or piecewise-quadratic interpolation to define the wall y-coordinates as a function of x.

The domain depth in the z-direction is one cell thick (0.01 m) to represent a 2D case in OpenFOAM.

Generate the mesh using blockMesh with a structured hexahedral grid.

Use approximately 200 cells along the x-direction and 60 cells across the full height of the nozzle.

Apply grading in the x-direction to refine cells near the throat region (x = 0.4 m to x = 0.6 m), using a grading ratio that clusters at least 40 percent of the x-cells within that 0.2 m throat region.

Apply uniform cell distribution in the y-direction, or mild grading toward the walls if a boundary layer is resolved.

Set the inlet boundary condition as a stagnation inlet: total pressure p0 = 200000 Pa and total temperature T0 = 300 K, using the totalPressure and totalTemperature boundary condition types in OpenFOAM.

Set the inlet velocity using the pressureInletVelocity boundary condition.

Set the outlet static pressure to 101325 Pa using either fixedValue or waveTransmissive boundary condition for pressure.

Set the outlet velocity using the inletOutlet or zeroGradient boundary condition.

Set the outlet temperature using zeroGradient.

Set the top and bottom nozzle walls as no-slip adiabatic walls: fixedValue U = (0 0 0), zeroGradient p, and zeroGradient T.

Set the front and back faces (z-direction) as empty boundary condition to enforce 2D behaviour.

Initialize the flow field with a uniform pressure of 101325 Pa, temperature of 300 K, and a low subsonic velocity of (10 0 0) m/s throughout the domain to aid convergence.

Run the simulation in steady-state mode; if using rhoCentralFoam (which is inherently transient), run it to a sufficiently large time until residuals and flow field reach a steady state.

Set the maximum Courant number to 0.5 for stability during the transient ramp-up to steady state.

Monitor residuals for p, U, T, and rho at every time step.

Monitor the Mach number profile along the nozzle centreline (y = 0) to confirm subsonic flow at the inlet, Mach 1 at the throat, and supersonic flow at the outlet.

Write output every 500 time steps for field visualisation in ParaView.

The simulation is considered converged when residuals drop below 1e-5 and the centreline Mach number profile is stable between successive write intervals.
