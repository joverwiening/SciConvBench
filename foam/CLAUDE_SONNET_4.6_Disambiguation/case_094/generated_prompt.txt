Start from the standard OpenFOAM buoyantCavity tutorial case without changing any file except where explicitly stated below.

Use the solver buoyantSimpleFoam (or buoyantPimpleFoam if the base tutorial uses a transient solver) as found in the base tutorial.

Keep all geometry, mesh, and boundary condition files (blockMeshDict, boundary, etc.) exactly as in the base tutorial.

Keep all thermal boundary conditions (hot wall, cold wall temperatures) exactly as in the base tutorial.

In the thermophysicalProperties (or transportProperties) file, change beta from 2.9e-3 to 2.9e-2 1/K and leave all other transport and thermophysical properties unchanged.

Replace the laminar turbulence model with the k-omega SST model.

In the turbulenceProperties (or momentumTransport) file, set simulationType to RAS and the RAS model to kOmegaSST.

Add initial and boundary condition files for k and omega in the time directory (typically 0/).

Set the initial internal field for k to a low turbulence intensity value consistent with natural convection, for example k = 1e-6 m2/s2.

Set the initial internal field for omega using the relation omega = C_mu^0.25 * k^0.5 / l, where l is a small length scale representative of the cavity (e.g., 1% of the cavity height), giving a value on the order of 1e-3 to 1e-1 s-1 depending on cavity size.

On all solid walls, apply the kLowReWallFunction boundary condition for k and the omegaWallFunction boundary condition for omega.

On all solid walls, set the value of k to 0 (no-slip turbulent kinetic energy) as the wall function initial value.

In the fvSchemes file, add discretisation schemes for the k and omega transport equations, using the same scheme style (e.g., Gauss linearUpwind or Gauss upwind) as used for other transported scalars in the base tutorial.

In the fvSolution file, add solvers and relaxation factors for k and omega, using settings consistent with the other scalar equations (e.g., smoothSolver with symGaussSeidel, tolerance 1e-7, relTol 0.1, relaxation factor 0.5).

Do not change the number of cells, the SIMPLE or PIMPLE control settings, or the end time from the base tutorial.

Verify that the Rayleigh number Ra = g * beta * deltaT * L^3 / (nu * alpha) equals 1e6 using the updated beta = 2.9e-2 1/K and the unchanged values of g, deltaT, L, nu, and alpha from the base tutorial.
