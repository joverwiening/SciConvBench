The simulation domain is rectangular, spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Use 100 grid points in the x direction, 40 grid points in the y direction, and 1 cell in the z direction.
Name the left boundary (x=0) "fuel", the right boundary (x=0.02) "air", the top and bottom boundaries "outlet", and the front and back faces "frontAndBack".
Set the frontAndBack patch type to empty (2D simulation).
Use the reactingFoam solver.
Use compressible finite-rate chemistry with hePsiThermo thermodynamic model.
Use coefficientWilkeMultiComponentMixture for mixture transport properties.
Use Sutherland transport model.
Use JANAF thermodynamics.
Use EulerImplicit chemistry type with Rosenbrock43 ODE solver.
Use laminar combustion model and laminar momentum transport.
Use a single-step global reaction mechanism: CH4 + 2 O2 → CO2 + 2 H2O.
Include species CH4, O2, CO2, H2O, and N2.
Use JANAF thermodynamic coefficients for all five species taken from standard NASA polynomial databases.
Use Sutherland transport coefficients for all species based on standard literature values.
Set the timestep to 1e-4 s and the end time to 0.5 s.
Write results at an interval of 0.05 s.
Set the initial pressure throughout the domain to 101325 Pa.
Set the initial temperature throughout the domain to 2000 K.
Set the initial velocity throughout the domain to (0, 0, 0) m/s.
Set the initial species mass fractions throughout the domain to Y_O2 = 0.23, Y_N2 = 0.77, and all other species to 0.
At the fuel inlet boundary (x=0), set a fixed velocity of (0.1, 0, 0) m/s.
At the fuel inlet boundary, set a fixed temperature of 293 K.
At the fuel inlet boundary, set fixed species mass fractions of Y_CH4 = 1 and all other species to 0.
At the fuel inlet boundary, set pressure to zero-gradient (zeroGradient).
At the air inlet boundary (x=0.02), set a fixed velocity of (-0.1, 0, 0) m/s.
At the air inlet boundary, set a fixed temperature of 293 K.
At the air inlet boundary, set fixed species mass fractions of Y_O2 = 0.23, Y_N2 = 0.77, and all other species to 0.
At the air inlet boundary, set pressure to zero-gradient (zeroGradient).
At the outlet boundaries (top and bottom), set pressure to a fixed value of 101325 Pa (totalPressure or fixedValue).
At the outlet boundaries, set velocity to inletOutlet with zero reference velocity.
At the outlet boundaries, set temperature and species to zero-gradient (zeroGradient).
Use standard OpenFOAM blockMeshDict to generate the mesh based on the above domain and grid specifications.
Use standard fvSchemes and fvSolution settings appropriate for reactingFoam with laminar compressible reacting flow.
