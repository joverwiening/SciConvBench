The simulation domain is a 3D rectangular box extending from x = -5 m to x = 5 m (streamwise), y = -1.5 m to y = 2.5 m (cross-stream), and z = -1 m to z = 1 m (spanwise).
A cylinder of diameter 2 m (radius 1 m) is centered at the origin (x = 0, y = 0) and spans the full z extent.
The mesh is treated as 2D by assigning empty boundary conditions to the front and back faces (z = -1 m and z = 1 m).
Use OpenFOAM's blockMesh or snappyHexMesh to generate the mesh with the cylinder subtracted from the domain.
The solver is pimpleFoam for incompressible unsteady (transient) flow.
Set startTime = 0 s, endTime = 0.5 s, and deltaT = 0.0025 s in controlDict.
Write results every 0.05 s using writeInterval = 0.05 in controlDict.
The flow is laminar; set simulationType to laminar in turbulenceProperties (or momentumTransport).
Use a generalizedNewtonian viscosity model within the laminar framework.
Set the viscosity model to crossPowerLaw in the transport properties file.
Set the crossPowerLaw parameter nu0 = 0.01 m²/s.
Set the crossPowerLaw parameter nuInf = 10 m²/s.
Set the crossPowerLaw parameter m = 0.4.
Set the crossPowerLaw parameter n = 3.
The fluid density is not explicitly specified; assume incompressible formulation where kinematic quantities are used throughout (no explicit rho needed).
Apply the inlet boundary condition on the left face (x = -5 m): U = (1 0 0) m/s (fixedValue), p = zeroGradient.
Apply the outlet boundary condition on the right face (x = 5 m): U = zeroGradient, p = 0 Pa (fixedValue, uniform 0).
Apply noSlip (U = (0 0 0)) and p = zeroGradient on the top wall (y = 2.5 m) and bottom wall (y = -1.5 m).
Apply noSlip (U = (0 0 0)) and p = zeroGradient on the cylinder wall surface.
Apply empty boundary conditions to the front face (z = 1 m) and back face (z = -1 m) for both U and p.
Initialize the internal field with a quiescent fluid: U = (0 0 0) m/s and p = 0 Pa uniformly throughout the domain at t = 0 s.
