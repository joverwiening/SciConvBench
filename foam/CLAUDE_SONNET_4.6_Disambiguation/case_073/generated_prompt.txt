Set up a steady-state pipe flow simulation using OpenFOAM with the simpleFoam solver.

The pipe is 2 meters long and has a diameter of 0.04 meters (radius 0.02 meters).

The fluid is air with a kinematic viscosity (nu) of 1.5e-5 m²/s and a density of 1.225 kg/m³ (standard sea-level air, assumed as best practice).

The Reynolds number is approximately 26,667, confirming turbulent flow.

Use the k-omega SST turbulence model.

Generate the mesh using blockMesh with an O-grid topology.

Use a 5-degree wedge geometry with 1 cell in the azimuthal (wedge) direction.

Discretize the mesh with 200 cells in the axial direction and 25 cells in the radial direction.

Apply wall-normal grading in the radial direction to refine cells near the pipe wall, targeting a grading ratio sufficient to achieve y+ in the range of 30 to 300 for wall functions, or y+ near 1 if low-Reynolds wall treatment is used.

Set the inlet boundary condition as a fixed velocity U = (10 0 0) m/s in the axial direction.

Set the inlet turbulent kinetic energy k using the formula k = 1.5 * (U * I)² where turbulence intensity I = 0.05 (5%), giving k ≈ 0.1875 m²/s².

Set the inlet specific dissipation rate omega using omega = k^0.5 / (Cmu^0.25 * L) where L = 0.07 * D = 0.0028 m and Cmu = 0.09, giving omega ≈ 14,000 rad/s (compute precisely from these values).

Set the outlet boundary condition as a fixed pressure p = 0 Pa (gauge) with zero-gradient for all other variables.

Apply no-slip wall boundary condition for velocity on the pipe wall.

Apply standard wall functions for k, omega, and nut on the pipe wall boundary.

Set the wedge faces as wedge boundary conditions in OpenFOAM.

Use the SIMPLE algorithm as implemented in simpleFoam for pressure-velocity coupling.

Set relaxation factors for U to 0.7 and for p to 0.3, and for turbulence quantities to 0.5, as standard best-practice starting values.

Use Gauss linear schemes for gradient terms, Gauss linearUpwind for divergence terms, and Gauss linear corrected for Laplacian terms in fvSchemes.

Run the simulation until residuals for all variables drop below 1e-5 or for a minimum of 1000 iterations, whichever comes later.

Monitor residuals for U, p, k, and omega each iteration to confirm convergence.
