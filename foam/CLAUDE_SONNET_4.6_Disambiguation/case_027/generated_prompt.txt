Run a transient laminar two-phase dam-break simulation with obstacles using the interFoam solver in OpenFOAM.

The computational domain is a cube from (0,0,0) to (1,1,1).
Discretize the domain with a uniform structured mesh of 32 x 32 x 32 cells.

Carve out a rectangular box obstacle occupying the region from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) by marking those cells as a wall boundary (or using topoSet and refineMesh/subsetMesh as appropriate).

Assign the top face (z = 1) as an atmosphere patch using the boundary type "patch" with atmospheric pressure conditions.
Assign all remaining five faces (x=0, x=1, y=0, y=1, z=0) and the obstacle surfaces as wall boundaries with no-slip velocity conditions.

Model the two phases using Volume of Fluid (VOF) via the interFoam framework.
Define the water phase with density = 1000 kg/m^3 and kinematic viscosity = 1.0e-6 m^2/s.
Define the air phase with density = 1 kg/m^3 and kinematic viscosity = 1.48e-5 m^2/s.
Set the surface tension coefficient between water and air to 0.07 N/m.

Set the turbulence modelling to laminar (no turbulence model).

Initialize alpha.water = 1 inside the rectangular prism from (0,0,0) to (0.6, 0.1875, 0.75) and alpha.water = 0 everywhere else.
Initialize the velocity field U = (0, 0, 0) everywhere.
Initialize the pressure field p_rgh = 0 everywhere.

Set deltaT = 1e-3 s.
Set endTime = 0.1 s.
Set writeInterval = 0.02 s, producing output at t = 0.02, 0.04, 0.06, 0.08, and 0.10 s.

Use the MULES scheme for alpha advection with interface compression.
Use PIMPLE or PISO loop as appropriate for the interFoam solver with standard numerical schemes for divergence, gradient, and Laplacian terms suitable for a laminar VOF simulation.

Write alpha.water, U, and p_rgh fields at each write interval.
