The simulation is a 2D transient two-phase flow through a porous dam using OpenFOAM's interFoam solver.

The domain is 2D with dimensions 5 m in x, 2 m in y, and 0.1 m in z-thickness.
The front and back boundaries are set as empty patches to enforce 2D simulation.
The porous dam zone occupies x=2 m to x=3 m across the full height of the domain (y=0 to y=2 m).

Use the interFoam solver (VOF-based two-phase incompressible flow).

Water properties: kinematic viscosity nu=1e-6 m²/s, density rho=1000 kg/m³.
Air properties: kinematic viscosity nu=1.48e-5 m²/s, density rho=1 kg/m³.
Surface tension sigma=0.07 N/m between water and air.

Define the porous dam zone using OpenFOAM's DarcyForchheimer porosity model.
Set Darcy coefficient d=(1e6 1e6 0) and Forchheimer coefficient f=(100 100 0).
No separate porosity scalar is defined; the resistance coefficients fully characterize the porous zone.

Initial condition for alpha.water: set alpha.water=1 inside the box from (0 0 -1) to (1 1.5 1), and alpha.water=0 everywhere else.
Initial condition for velocity U: set U=(0 0 0) everywhere.
Initial condition for p_rgh: set p_rgh=0 everywhere.

Boundary condition for leftWall, rightWall, and bottomWall: no-slip (U=fixedValue (0 0 0)), fixedFluxPressure for p_rgh, zeroGradient for alpha.water.
Boundary condition for the top (atmosphere) patch: pressureInletOutletVelocity for U with inletValue=(0 0 0), totalPressure for p_rgh with p0=0, inletOutlet for alpha.water with inletValue=0.
Boundary condition for frontAndBack: empty.

Set endTime=10 s.
Set initial deltaT=0.001 s.
Enable adjustable time stepping with adjustTimeStep=yes.
Set maximum Courant number maxCo=0.5.
Set writeInterval=0.1 s to output results every 0.1 seconds.

The simulation captures the transient advance of the water front from the initial left-side water column through the porous dam zone into the dry right-side region over 10 seconds.
