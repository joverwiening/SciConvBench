Run a transient laminar two-phase dam-break simulation with an obstacle using the interFoam solver in OpenFOAM.

The computational domain is a cube from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 cells in each direction (32 x 32 x 32 hex mesh).
Use blockMesh to generate the mesh.

Define a rectangular box obstacle occupying the region from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Treat the obstacle as a wall boundary embedded in the domain using topoSet and refineMesh or represent it as a wall patch via blockMesh multi-block definition.
Apply no-slip wall boundary conditions on all obstacle faces.

Apply no-slip wall boundary conditions (U = (0,0,0)) on all six outer domain faces.
Apply zeroGradient for pressure p_rgh on all walls.
Apply zeroGradient for alpha.water on all walls.

Set gravity to g = (0, 0, -9.81) m/s² in the constant/g file.

Use the following fluid properties in constant/transportProperties:
Water phase: rho = 1000 kg/m³, nu = 1e-6 m²/s.
Air phase: rho = 1 kg/m³, nu = 1.48e-5 m²/s.
Surface tension sigma = 0.07 N/m.

Use laminar flow; set simulationType to laminar in constant/turbulenceProperties (or constant/momentumTransport).

Initialize alpha.water = 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75) and alpha.water = 0 everywhere else.
Use setFields with a fieldBoxValues entry to set this initial condition.

Initialize U = (0, 0, 0) everywhere in the domain.
Initialize p_rgh = 0 everywhere in the domain.

Set deltaT = 1e-3 s in system/controlDict.
Set endTime = 0.1 s in system/controlDict.
Set writeInterval = 0.02 s in system/controlDict.
Set writeControl to runTime in system/controlDict.
Set startFrom to startTime with startTime = 0 in system/controlDict.

Use adjustTimeStep no so the time step remains fixed at 1e-3 s.

Use the MULES-based interFoam solver for the alpha equation.
Use PIMPLE or PISO loop as default for interFoam (standard interFoam settings).

Use the following fvSchemes: ddtSchemes Euler, gradSchemes Gauss linear, divSchemes Gauss linear for div(phi,U) and Gauss vanLeer for div(phi,alpha), laplacianSchemes Gauss linear corrected, interpolationSchemes linear, snGradSchemes corrected.

Use the following fvSolution settings: GAMG solver for p_rgh with tolerance 1e-7, smoothSolver for U and alpha with tolerance 1e-8, nAlphaCorr 2, nAlphaSubCycles 1, cAlpha 1.
