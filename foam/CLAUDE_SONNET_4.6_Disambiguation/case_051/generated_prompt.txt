The simulation is a 1D shock tube problem solved using OpenFOAM's rhoCentralFoam solver.

The domain is a 3D box of dimensions 1 m x 0.1 m x 0.1 m, representing a 1D tube.
Use blockMesh with a single block and 400 1 1 cells in the x, y, z directions respectively.
The diaphragm is located at x = 0.5 m.

Set initial conditions using pressure and temperature fields so density is derived via the ideal gas equation of state.
Left state (x < 0.5 m): p = 100000 Pa, T = 348.4 K, U = (0 0 0).
Right state (x > 0.5 m): p = 10000 Pa, T = 278.7 K, U = (0 0 0).
Use a perfect gas thermodynamic model with air properties: R = 287 J/(kg·K), gamma = 1.4.
Set Cp = 1005 J/(kg·K) and mu = 0 (inviscid) or a negligibly small viscosity consistent with inviscid flow.

Use rhoCentralFoam as the solver.
For numerical scheme settings, use the van Leer limiter for the flux interpolation (vanLeerV for vector fields, vanLeer for scalar fields), which is best practice for rhoCentralFoam shock-capturing.
Use Gauss linear for gradient schemes and linear for interpolation schemes where not overridden.

Use a fixed time step of 1e-6 s.
Do not use adjustable time stepping.
Set the end time to 0.007 s.
Write output (write interval) every 0.0005 s, giving 14 output time directories.

Apply the following boundary conditions at both the left wall (x = 0) and right wall (x = 1 m):
U: slip
p: zeroGradient
T: zeroGradient
rho: zeroGradient (derived from p and T via equation of state)

Apply empty boundary conditions on all four side faces (the y and z faces) to enforce 1D behavior in OpenFOAM.

Set the case up with the standard rhoCentralFoam directory structure: constant/thermophysicalProperties, constant/turbulenceProperties (set to laminar), system/fvSchemes, system/fvSolution, system/controlDict, system/blockMeshDict, and 0/ directory containing p, T, and U fields.
Set turbulenceProperties to simulationType laminar.
