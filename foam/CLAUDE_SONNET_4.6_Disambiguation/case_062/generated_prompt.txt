The simulation is a 2D CFD simulation of flow over a cylinder using OpenFOAM.
The fluid is water with kinematic viscosity nu = 1e-6 m^2/s.
The Reynolds number is Re = 3900.
The inlet velocity is U = (3.9, 0, 0) m/s.
The cylinder diameter is D = 1 m.
The computational domain is a rectangle spanning from (-10D, -10D, 0) to (30D, 10D, 0.1D), which is 40 m long, 20 m wide, and 0.1 m deep.
The cylinder is centered at the origin (0, 0).
The domain has one cell in the Z direction (depth = 0.1D = 0.1 m).
The front and back faces (Z-direction faces) are set as empty boundary condition to enforce a 2D simulation in OpenFOAM.
The inlet boundary (left face, x = -10D) uses a fixedValue condition with U = (3.9, 0, 0) m/s.
The outlet boundary (right face, x = 30D) uses a zeroGradient condition for velocity and a fixedValue condition of p = 0 for pressure.
The top and bottom boundaries (y = -10D and y = 10D) use a slip or symmetryPlane boundary condition.
The cylinder surface uses a no-slip wall boundary condition (fixedValue U = (0, 0, 0)).
Use the icoFoam or pimpleFoam solver to capture unsteady vortex shedding.
The simulation is transient and must run long enough to observe periodic vortex shedding (Karman vortex street).
The mesh must be refined near the cylinder surface to resolve the boundary layer and wake region.
Output fields include velocity U and pressure p at regular time intervals for post-processing and visualization of vortex shedding.
