Use OpenFOAM's interFoam solver to simulate gravity-driven sloshing in a rectangular tank.

The tank dimensions are 1.0 m in x, 0.6 m in y, and 0.1 m in z.

Run the case in 2D using a single cell layer in z with empty boundary conditions on the front and back patches.

Use a structured block mesh with 200 cells in x, 120 cells in y, and 1 cell in z.

Set all cell expansion ratios to 1 (uniform mesh) in all directions.

Use interFoam as the solver with a transient, two-phase, incompressible, laminar flow setup.

Set gravity to (0 -9.81 0) m/s² in the constant/g file.

Define the water phase with density 1000 kg/m³ and kinematic viscosity 1e-6 m²/s.

Define the air phase with density 1.0 kg/m³ and kinematic viscosity 1.48e-5 m²/s.

Set surface tension between water and air to 0.07 N/m.

Initialize the alpha.water field so that the free surface is a tilted plane: water depth varies linearly from 0.25 m at x=0 to 0.35 m at x=1.0 m.

Implement the initial alpha.water field using a setFieldsDict with a boxToCell or a codedFixedValue, or use funkySetFields / setExprFields to assign alpha=1 where y is less than the local linear water height (0.25 + 0.10*x/1.0) and alpha=0 elsewhere.

Set the initial velocity field U to uniform (0 0 0) everywhere.

Set the initial pressure field p_rgh to uniform 0.

Apply no-slip wall boundary conditions (U = fixedValue (0 0 0)) on all four tank walls: left (x=0), right (x=1), bottom (y=0), and top (y=0.6).

Apply zeroGradient for alpha.water on all walls.

Apply zeroGradient for p_rgh on all walls except the top; set the top boundary as totalPressure with p0=0.

Apply inletOutlet for U on the top boundary to allow air to move freely.

Set the front and back patches (z-normal) to empty type for all fields.

Set endTime to 10 s.

Set deltaT to 1e-3 s.

Set adjustTimeStep to yes.

Set maxCo to 0.5.

Set maxAlphaCo to 0.5.

Set writeControl to adjustableRunTime with writeInterval of 0.1 s.

Use the MULES-based alpha advection scheme; set nAlphaCorr 2 and nAlphaSubCycles 1 in fvSolution.

Use the PIMPLE algorithm with nOuterCorrectors 1, nCorrectors 3, and nNonOrthogonalCorrectors 0.

Use Gauss linearUpwind for div(phi,U), Gauss vanLeer for div(phi,alpha), and Gauss linear for all gradient schemes.

Use linear interpolation and Gauss linear for Laplacian schemes with explicit non-orthogonal correction set to corrected.

Set the simulation to run as a single-region, single-processor case unless the user chooses to decompose for parallel execution.

Do not apply any turbulence model; use laminar flow throughout.
