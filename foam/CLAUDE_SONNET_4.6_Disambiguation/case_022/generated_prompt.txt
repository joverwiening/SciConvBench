The simulation is 2D flow past a circular cylinder using OpenFOAM.
The domain is rectangular: x from -5 m to 5 m (streamwise), y from -1.5 m to 2.5 m (cross-stream), z from -1 m to 1 m.
A circular cylinder of diameter 2 m is centered at the origin (x = 0 m, y = 0 m).
The solver is pimpleFoam for incompressible unsteady flow.
Set startTime = 0 s, endTime = 0.5 s, deltaT = 0.0025 s.
Write results every 0.05 s.
The initial condition is a quiescent fluid: U = (0 0 0) m/s and p = 0 Pa everywhere.
The flow is laminar.
Use the laminar turbulence model with a generalised Newtonian viscosity approach.
The viscosity model is crossPowerLaw.
Set the crossPowerLaw coefficient nuInf = 10 m²/s.
Set the crossPowerLaw coefficient m = 0.4 s.
Set the crossPowerLaw coefficient n = 3 (dimensionless).
Set nu0 = 1000 m²/s as a reasonable high-viscosity plateau value following best practice (nu0 >> nuInf to represent the zero-shear-rate plateau).
The mesh is 2D (one cell thick in the z-direction) with an unstructured or block-structured mesh resolving the cylinder surface.
Apply a no-slip boundary condition (U = (0 0 0)) on the cylinder wall.
Apply a zeroGradient condition for p on the cylinder wall.
Apply an empty boundary condition on the front and back patches (z-direction faces) to enforce 2D behaviour.
Apply a fixedValue condition for U = (0 0 0) at the inlet (x = -5 m face) consistent with the quiescent initial condition.
Apply zeroGradient for U and fixedValue p = 0 at the outlet (x = 5 m face).
Apply a slip or symmetry boundary condition on the top (y = 2.5 m) and bottom (y = -1.5 m) patches.
Use SI units throughout.
