The case is a 2D dam break simulation using OpenFOAM's interFoam solver.

The tank domain is 0.584m in x (length), 0.584m in y (height), and 0.01m in z (depth).

Use a uniform structured mesh of 58 cells in x, 58 cells in y, and 1 cell in z, giving a total of 58x58x1 cells.

The front and back patches (z-faces) use the empty boundary condition to enforce 2D behavior.

The simulation is laminar with no turbulence model.

Two phases are defined: water with rho=1000 kg/m³ and nu=1e-6 m²/s, and air with rho=1 kg/m³ and nu=1.48e-5 m²/s.

Surface tension sigma is set to 0.07 N/m.

The water column occupies the region x in [0, 0.146m] and y in [0, 0.292m], positioned in the bottom-left corner of the tank.

Initialize the alpha.water field to 1 inside the water column region and 0 elsewhere using setFields.

The left and bottom walls of the water column coincide with the tank walls.

All tank walls (left, right, bottom, top) use a no-slip wall boundary condition for velocity (fixedValue uniform (0 0 0)).

Apply zeroGradient for pressure (p_rgh) on all walls.

Apply zeroGradient for alpha.water on all walls.

The top boundary is a wall (closed tank) unless otherwise needed; treat it as a wall with no-slip.

Use adjustable time stepping controlled by Courant number.

Set maxCo to 0.5 and maxAlphaCo to 0.5.

Set the initial deltaT to a small value such as 0.001s.

Set the simulation end time to 2.0 seconds.

Write output results at every 0.05 seconds (writeInterval 0.05s) using adjustableRunTime write control.

Use the MULES scheme for alpha.water advection as is default in interFoam.

Use Gauss linear for gradient schemes and Gauss linearUpwind or linear for divergence schemes as appropriate for interFoam defaults.

Use PCG solver for p_rgh and PBiCGStab or smoothSolver for velocity as per standard interFoam setup.

Gravity is set to (0 -9.81 0) m/s² in the g file.

The case directory structure follows standard OpenFOAM layout: 0/, constant/, and system/ directories.
