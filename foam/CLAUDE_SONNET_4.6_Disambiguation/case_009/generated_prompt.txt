The simulation is a 2D lid-driven cavity using OpenFOAM with pisoFoam solver.

The cavity domain is a square of 1 unit in x and 1 unit in y, with a z-depth of 0.1 units, making it effectively 2D.

The simulation runs from time 0 to 10 seconds with a time step of 0.005 seconds.

Write results to disk every 100 time steps.

Use a constant kinematic viscosity nu = 1e-05 m^2/s.

Use the k-epsilon turbulence model.

Set the initial condition for U as (0, 0, 0) uniformly throughout the domain.

Set the initial condition for p as 0 uniformly throughout the domain.

Initialize k = 1.5e-4 uniformly throughout the domain.

Apply kqRWallFunction boundary condition for k on all solid walls (movingWall and fixedWalls).

Apply empty boundary condition for k on the front and back patches.

Initialize epsilon = 1.4e-4 uniformly throughout the domain.

Apply epsilonWallFunction boundary condition for epsilon on all solid walls (movingWall and fixedWalls).

Apply empty boundary condition for epsilon on the front and back patches.

Initialize nut = 0 uniformly throughout the domain.

Apply nutkWallFunction boundary condition for nut on all solid walls (movingWall and fixedWalls).

Apply empty boundary condition for nut on the front and back patches.

Set the boundary condition for U on movingWall (top lid) as fixedValue uniform (1 0 0) m/s.

Set the boundary condition for U on fixedWalls as fixedValue uniform (0 0 0) (no-slip).

Set the boundary condition for U on front and back patches as empty.

Set the boundary condition for p on movingWall as zeroGradient.

Set the boundary condition for p on fixedWalls as zeroGradient.

Set the boundary condition for p on front and back patches as empty.

Specify the convection scheme for div(phi,U) as Gauss limitedLinearV 1.

Specify the convection scheme for div(phi,k) as Gauss limitedLinear 1.

Specify the convection scheme for div(phi,epsilon) as Gauss limitedLinear 1.

Specify the viscous term scheme for div((nuEff*dev2(T(grad(U))))) as Gauss linear.
