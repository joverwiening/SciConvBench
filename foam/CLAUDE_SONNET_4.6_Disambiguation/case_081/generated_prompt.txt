Simulate a premixed methane-air flame in a 2D channel using the reactingFoam solver in OpenFOAM.

The channel is 0.1 m long and 0.02 m high.
Orient the channel so the flow travels in the x-direction, with the inlet at x=0 and the outlet at x=0.1 m.
Use a 2D planar mesh (one cell thick in the z-direction with empty boundary conditions on the front and back faces).
Choose a mesh resolution appropriate for a laminar premixed flame, for example 200 cells in x and 40 cells in y.

The flow is laminar; do not use any turbulence model (set simulationType to laminar).

Set the inlet boundary condition for velocity to a uniform fixed value of (0.5 0 0) m/s.
Set the outlet boundary condition for velocity to zeroGradient.
Set the wall boundary conditions for velocity to noSlip on the top and bottom walls.

Set the inlet temperature to a fixed value of 300 K.
Set the outlet temperature to zeroGradient.
Set the wall boundary conditions for temperature to zeroGradient (adiabatic walls).

Set the initial and inlet pressure to 101325 Pa.
Use the pressureInletOutletVelocity or fixedValue condition for pressure as appropriate for reactingFoam (p_rgh formulation).

Define four species: CH4, O2, CO2, H2O, and N2.
Set the inlet species mass fractions to CH4=0.055, O2=0.220, N2=0.725, CO2=0.0, H2O=0.0.
Set the outlet and wall species boundary conditions to zeroGradient.
Initialize the entire domain with the inlet species mass fractions and temperature of 300 K, except seed a small high-temperature ignition region near the inlet to initiate combustion.

Use a single one-step irreversible reaction: CH4 + 2O2 -> CO2 + 2H2O.
Define the Arrhenius rate coefficients as pre-exponential factor A=2.119e11, temperature exponent beta=0, and activation temperature Ta=2.027e8 K.
Use the Arrhenius reaction rate type in the reactions dictionary.

Use the janaf thermodynamic model for all species.
Provide standard JANAF polynomial coefficients for CH4, O2, CO2, H2O, and N2 in the thermophysicalProperties or thermo.compressibleGas dictionary.
Use sutherland or polynomial transport models for viscosity and thermal conductivity of each species.

Set the thermophysical model to reactingMixture with a compressible, multi-species formulation compatible with reactingFoam.
Use the PsiReactionThermo or hePsiThermo thermodynamic framework as required by reactingFoam.

Set the simulation end time and time step to values appropriate for the flame to reach steady state, for example endTime=0.05 s and deltaT=1e-6 s.
Use adjustable time stepping with a maximum Courant number of 0.5 if desired.
Write output every 0.005 s.

Use PIMPLE or PISO algorithm settings consistent with reactingFoam defaults.
Set solver tolerances for p, U, T, and species to 1e-6 with residual control.
