Simulate a thermal plume rising from a hot strip on the floor of a 2D cross-section room using OpenFOAM with buoyantPimpleFoam and the kOmegaSST RAS turbulence model.

Assume a recent stable OpenFOAM version (e.g., OpenFOAM v2306 or OpenFOAM 10) following best practices for buoyantPimpleFoam.

The simulation domain is 2.0 m wide (x), 2.0 m tall (y), and 0.01 m deep (z), representing a 2D cross-section with one cell in the z-direction.

The mesh resolution is 160 cells in x, 160 cells in y, and 1 cell in z, giving approximately 160×160×1 total cells.

Use blockMesh to generate the mesh.

The hot strip is located on the floor, centered at x = 1.0 m, spanning x ∈ [0.9, 1.1] m (0.2 m wide).

The floor is divided into two patches: hotStrip (x ∈ [0.9, 1.1] m) and coolFloor (the remainder of the floor).

The front and back z-faces are set as empty patches to enforce 2D behavior.

Set the fluid to air with Boussinesq-appropriate thermophysical properties: use hePsiThermo or heRhoThermo with a suitable air mixture, Cp = 1005 J/(kg·K), dynamic viscosity mu = 1.8e-5 Pa·s, Prandtl number Pr = 0.71, and reference density rho = 1.2 kg/m³.

Use the buoyantPimpleFoam solver with gravity g = (0, -9.81, 0) m/s².

Apply the kOmegaSST RAS turbulence model with standard model coefficients.

Initial conditions throughout the interior at t=0 are: U = (0, 0, 0) m/s, T = 300 K, p_rgh = 0 Pa (gauge), k = 0.001 m²/s², omega = 1 s⁻¹.

For the hotStrip patch, apply: fixedValue U = (0,0,0) (noSlip), fixedValue T = 400 K, fixedFluxPressure for p_rgh, kqRWallFunction for k, omegaWallFunction for omega.

For the coolFloor patch, apply: fixedValue U = (0,0,0) (noSlip), fixedValue T = 300 K, fixedFluxPressure for p_rgh, kqRWallFunction for k, omegaWallFunction for omega.

For the sideWalls (left and right) patches, apply: fixedValue U = (0,0,0) (noSlip), fixedValue T = 300 K, fixedFluxPressure for p_rgh, kqRWallFunction for k, omegaWallFunction for omega.

For the outlet (top) patch, apply: pressureInletOutletVelocity for U with inletValue (0,0,0), totalPressure for p_rgh with p0 = 0 Pa, inletOutlet for T with inletValue 300 K, inletOutlet for k with inletValue 0.001 m²/s², inletOutlet for omega with inletValue 1 s⁻¹.

Set endTime to 200 s.

Set initial deltaT to 0.01 s.

Enable adjustable time stepping (adjustTimeStep yes) with maxCo = 0.5.

Set maxDeltaT to 0.05 s to cap the time step size.

Write results every 5 s (writeInterval 5).

Use PIMPLE loop settings appropriate for buoyant flow: nOuterCorrectors 2, nCorrectors 2, nNonOrthogonalCorrectors 1.

Use Gauss linear schemes for gradient and divergence terms, and Gauss linear corrected for Laplacian terms, consistent with second-order accuracy.

Use GAMG solver for p_rgh and smoothSolver for U, T, k, and omega.

The simulation starts from rest and allows the thermal plume to develop naturally due to buoyancy over the 200 s run time.
