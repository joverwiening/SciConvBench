Simulate a steady-state turbulent channel flow using OpenFOAM's simpleFoam solver with the standard k-epsilon turbulence model.

The channel has length L = 1 m in x, height H = 0.1 m in y, and width W = 0.2 m in z.
The fluid has kinematic viscosity nu = 1e-5 m²/s.
Assume incompressible flow; density is not required explicitly as the solver operates on kinematic quantities.
The bulk Reynolds number based on H and target velocity is Re = 0.5 * 0.1 / 1e-5 = 5000, confirming turbulent regime.

Create the mesh using blockMesh with 100 cells in x, 20 cells in y, and 10 cells in z.
Use uniform cell spacing in all directions (no grading required unless wall y+ demands it, but with wall functions uniform grading is acceptable).

Apply the meanVelocityForce fvOption to drive the flow, targeting a bulk mean velocity of 0.5 m/s in the x-direction.
Set the meanVelocityForce in the fvOptions file with Ubar = (0.5 0 0) and fields = (U).

Use cyclic boundary conditions on the inlet (x = 0) and outlet (x = 1 m) patches for both U, p, k, and epsilon to simulate fully developed channel flow.
Use cyclic boundary conditions on the front (z = 0) and back (z = 0.2 m) patches for all fields.
Apply no-slip wall boundary condition (fixedValue U = (0 0 0)) on the top and bottom walls (y = 0 and y = 0.1 m).
Apply wall functions on the top and bottom walls for turbulence quantities: use epsilonWallFunction for epsilon and kqRWallFunction for k.
Apply zeroGradient for p on all walls.
Apply cyclic for p on inlet/outlet and front/back patches.

Initialize the flow field with U = (0.5 0 0) uniformly.
Estimate initial turbulence intensity I = 0.05 (5%) and turbulent length scale l = 0.07 * H = 0.007 m.
Compute initial k = 1.5 * (U * I)^2 = 1.5 * (0.5 * 0.05)^2 = 9.375e-4 m²/s².
Compute initial epsilon = Cmu^0.75 * k^1.5 / l, where Cmu = 0.09, giving epsilon ≈ 0.09^0.75 * (9.375e-4)^1.5 / 0.007 ≈ 1.03e-4 m²/s³.
Set initial p = 0 uniformly.

Set endTime = 1000 and deltaT = 1 in the controlDict.
Set writeInterval = 100 to save results every 100 iterations.
Use SIMPLE algorithm settings in fvSolution with nNonOrthogonalCorrectors = 0.
Set relaxation factors: U = 0.7, p = 0.3, k = 0.5, epsilon = 0.5 in fvSolution.
Use Gauss linear schemes for gradient and divergence terms in fvSchemes.
Use Gauss linearUpwind for div(phi,U) and div(phi,k) and div(phi,epsilon).
Use linear interpolation and corrected surface normal gradient schemes.

Use the standard k-epsilon model coefficients: Cmu = 0.09, C1 = 1.44, C2 = 1.92, sigmaK = 1.0, sigmaEps = 1.3.
Specify turbulenceProperties with simulationType = RAS and RAS model = kEpsilon with turbulence = on and printCoeffs = on.

Monitor convergence by checking residuals for U, p, k, and epsilon each iteration.
Consider the simulation converged when all residuals drop below 1e-5 or remain stable over successive iterations.
Post-process by extracting the mean streamwise velocity profile U(y) at x = 0.5 m to verify the expected turbulent log-law profile.
