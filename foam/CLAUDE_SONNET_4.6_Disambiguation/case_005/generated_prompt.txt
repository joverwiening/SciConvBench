Run a two-dimensional Rayleigh-Benard convection simulation using OpenFOAM with the buoyantFoam solver.

Create the case directory structure with folders: 0, constant, and system.

The computational domain is a rectangular box 9 units wide (x), 1 unit tall (y), and 1 cell thick in z (spanwise depth of 1 unit).

Use 90 cells in the x direction, 10 cells in the y direction, and 1 cell in the z direction, with no grading.

Define six patches: bottom (y=0), top (y=1), left (x=0), right (x=9), front and back (z faces).

Treat front and back patches as type empty to enforce 2D behavior.

In constant/polyMesh/blockMeshDict, define the block with vertices at the eight corners of the box and assign the patches accordingly.

Set gravity in constant/g to (0 -9.81 0) m/s^2.

In constant/physicalProperties, use thermoType with class heRhoThermo, type rhoThermo, mixture pureMixture, transport const, thermo hConst, equationOfState Boussinesq.

Set specie molWeight to 29.

Set equationOfState coefficients: rho0 1.0, T0 300, beta 3.3e-3.

Set thermodynamic coefficients: Cv 714.3, Hf 0.

Set transport coefficients: mu 1.5e-5, Pr 0.714.

In constant/turbulenceProperties, set simulationType to RAS and model to kEpsilon with turbulence on and printCoeffs on.

Create the 0/U file with internalField uniform (0 0 0), noSlip condition on bottom, top, left, and right patches, and empty on front and back.

Create the 0/T file with internalField uniform 300, fixedValue 305 on the bottom patch, fixedValue 295 on the top patch, zeroGradient on left and right patches, and empty on front and back.

Create the 0/p file with internalField uniform 0, calculated condition on bottom, top, left, and right patches, and empty on front and back.

Create the 0/p_rgh file with internalField uniform 0, fixedFluxPressure condition on bottom, top, left, and right patches, and empty on front and back.

Create the 0/k file with internalField uniform 1e-5, kqRWallFunction on bottom, top, left, and right patches, and empty on front and back.

Create the 0/epsilon file with internalField uniform 1e-5, epsilonWallFunction on bottom, top, left, and right patches, and empty on front and back.

Create the 0/nut file with internalField uniform 0, nutkWallFunction on bottom, top, left, and right patches, and empty on front and back.

Create the 0/alphat file with internalField uniform 0, compressible::alphatJayatillekeWallFunction with Prt 0.85 on bottom, top, left, and right patches, and empty on front and back.

In system/controlDict, set application to buoyantFoam, startFrom startTime, startTime 0, stopAt endTime, endTime 1000, deltaT 1, writeControl timeStep, writeInterval 50, purgeWrite 0, writeFormat ascii, writePrecision 8, runTimeModifiable yes.

In system/fvSchemes, set ddtSchemes default to Euler, gradSchemes default to Gauss linear, divSchemes for div(phi,U) to Gauss linearUpwind grad(U), for div(phi,e) to Gauss linearUpwind grad(e), for div(phi,k) and div(phi,epsilon) to Gauss upwind, for div(((rho*nuEff)*dev2(T(grad(U))))) to Gauss linear, set laplacianSchemes default to Gauss linear corrected, interpolationSchemes default to linear, snGradSchemes default to corrected.

In system/fvSolution, define a solver for p_rgh using GAMG with smoother GaussSeidel, tolerance 1e-8, relTol 0.01.

Define a solver for p_rghFinal using GAMG with smoother GaussSeidel, tolerance 1e-8, relTol 0.

Define solvers for U, e, k, and epsilon using PBiCGStab with preconditioner DILU, tolerance 1e-8, relTol 0.01.

Define solvers for UFinal, eFinal, kFinal, and epsilonFinal using PBiCGStab with preconditioner DILU, tolerance 1e-8, relTol 0.

In system/fvSolution under PIMPLE, set nOuterCorrectors 2, nCorrectors 2, nNonOrthogonalCorrectors 1, momentumPredictor yes.

Set the reference pressure cell to 0 and reference pressure value to 0 in the PIMPLE or p_rgh solver settings.

Initialize the flow field at rest with uniform temperature 300 K throughout the domain.

The simulation runs from t=0 to t=1000 s with a fixed time step of 1 s and no adaptive time-stepping.
