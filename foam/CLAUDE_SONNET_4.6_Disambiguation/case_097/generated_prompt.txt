The simulation models natural convection in a differentially heated square cavity using OpenFOAM with the buoyantPimpleFoam solver.

The cavity is 1 m x 1 m in the x-y plane with a depth of 1 cell in the z-direction (2D simulation).

Use a uniform structured mesh of 50 x 50 x 1 cells with no grading or refinement.

The left wall is the hot wall with a fixed temperature of 310 K.

The right wall is the cold wall with a fixed temperature of 290 K.

The top and bottom walls are adiabatic, using zeroGradient for temperature.

All four walls use no-slip boundary conditions: fixedValue uniform (0 0 0) for U.

The front and back faces (z-direction) use empty boundary conditions as required for 2D OpenFOAM cases.

The working fluid is air with the following properties: dynamic viscosity mu = 1.8e-5 Pa·s, Prandtl number Pr = 0.71, specific heat Cp = 1005 J/(kg·K).

Compute thermal conductivity as k = mu * Cp / Pr, giving k = 0.02549 W/(m·K).

Use the Boussinesq approximation for buoyancy with a reference temperature of 300 K.

Set the coefficient of thermal expansion beta = 1/300 K^-1 (ideal gas approximation at 300 K).

The resulting Rayleigh number is Ra = (rho^2 * g * beta * DeltaT * L^3 * Cp) / (mu * k), which evaluates to approximately 1.7e8 using standard air density rho = 1.177 kg/m^3.

Initialize the velocity field U to (0 0 0) uniformly throughout the domain.

Initialize the temperature field T to 300 K uniformly throughout the domain.

Initialize p_rgh to 0 uniformly throughout the domain.

Run the simulation from t = 0 s to t = 500 s as a fixed-duration run.

Use an adjustable time step with a maximum Courant number (maxCo) of 0.7 and an initial deltaT of 0.01 s.

Write simulation results to disk every 10 seconds.

Configure the buoyantPimpleFoam solver with standard PIMPLE settings appropriate for buoyancy-driven flow at this Rayleigh number.

Use OpenFOAM's standard thermophysicalProperties dictionary to define the air properties as a hConstThermo or similar constant-property model consistent with the values above.

Gravity is set to (0 -9.81 0) m/s^2 in the g file, acting in the negative y-direction.
