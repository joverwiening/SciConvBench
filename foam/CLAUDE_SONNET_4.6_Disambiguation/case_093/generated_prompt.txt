The simulation is a 2D buoyant compressible turbulent plume in OpenFOAM using buoyantPimpleFoam.

The domain is 2 m wide (x) by 4 m tall (y) with a nominal depth of 1 cell in z using empty front and back patches.

Create the mesh using blockMesh with 100 cells in x graded towards the center and 200 cells in y graded towards the bottom.

Define the following named patches: heatSource (center 0.2 m of the bottom boundary), floorSides (remaining bottom boundary), leftWall, rightWall, top, frontAndBack (empty).

Use buoyantPimpleFoam as the solver.

Model air as a compressible perfect gas using hePsiThermo with the perfectGas equation of state and janafThermo or hConst thermodynamic model using standard air property defaults for viscosity, thermal conductivity, molecular weight, and specific heat.

Use the standard k-epsilon turbulence model with default model coefficients.

Set the initial condition for T to 300 K uniformly throughout the domain.

Set the initial condition for p_rgh to uniform 0 throughout the domain.

Set the initial condition for U to uniform (0 0 0) throughout the domain.

Set the initial condition for k to uniform 1e-5 throughout the domain.

Set the initial condition for epsilon to uniform 1e-5 throughout the domain.

Apply a fixed temperature boundary condition of 400 K on the heatSource patch.

Apply zeroGradient for T on the floorSides patch.

Apply zeroGradient for T on leftWall and rightWall patches.

Apply inletOutlet for T on the top patch with inletValue of 300 K and value of 300 K.

Apply noSlip for U on heatSource and floorSides patches.

Apply slip for U on leftWall and rightWall patches.

Apply pressureInletOutletVelocity for U on the top patch with value uniform (0 0 0).

Apply totalPressure for p_rgh on the top patch with p0 uniform 0.

Apply fixedFluxPressure or zeroGradient for p_rgh on heatSource and floorSides patches.

Apply zeroGradient for p_rgh on leftWall and rightWall patches.

Apply kqRWallFunction for k on heatSource, floorSides, leftWall, and rightWall patches with value uniform 1e-5.

Apply epsilonWallFunction for epsilon on heatSource, floorSides, leftWall, and rightWall patches with value uniform 1e-5.

Apply nutkWallFunction for nut on heatSource, floorSides, leftWall, and rightWall patches with value uniform 0.

Apply inletOutlet for k on the top patch with inletValue uniform 1e-5 and value uniform 1e-5.

Apply inletOutlet for epsilon on the top patch with inletValue uniform 1e-5 and value uniform 1e-5.

Apply calculated for nut on the top patch with value uniform 0.

Apply empty conditions to all fields on the frontAndBack patches.

Set the simulation end time to 100 seconds.

Set the initial deltaT to 0.01 seconds.

Enable adjustable time stepping with maxCo of 0.8.

Write results every 5 seconds of simulated time.

Enable gravity as (0 -9.81 0) in the g file.

Use PIMPLE loop settings appropriate for buoyantPimpleFoam, such as nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1 as a starting point.
