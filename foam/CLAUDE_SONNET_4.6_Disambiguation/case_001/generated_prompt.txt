Run a two-dimensional Rayleigh-Benard convection cell simulation using OpenFOAM.

Use the buoyantFoam solver.

Set gravity to (0 -9.81 0) in constant/g.

The domain is a 2D rectangle 9 m wide and 1 m tall.

Use 90 cells in the x-direction and 10 cells in the y-direction.

Set the mesh depth (z-direction) to a single cell with empty front and back patches to enforce 2D.

In constant/physicalProperties, use thermoType with class heRhoThermo, type rhoThermo, mixture pureMixture, transport const, thermo hConst, equationOfState Boussinesq, specie specie, and energy sensibleInternalEnergy.

Set specie molWeight to 29.

Set equationOfState parameters: rho0 1.0, T0 300, beta 3.3e-3.

Set thermodynamic parameters: Cv 714.3, Hf 0.

Set transport parameters: mu 1.5e-5, Pr 0.714.

In constant/momentumTransport, set simulationType to RAS.

Set RAS model to kEpsilon, turbulence on, and printCoeffs on.

Do not use laminar anywhere.

In 0/U, set internalField to uniform (0 0 0).

Apply noSlip boundary condition on all solid walls (top, bottom, left, right).

Apply empty on front and back patches.

In 0/T, set internalField to uniform 300.

Set bottom wall to fixedValue 305.

Set top wall to fixedValue 295.

Set left and right (side) walls to zeroGradient.

Set front and back to empty.

In 0/p, set internalField to uniform 0.

Set all solid walls to calculated.

Set front and back to empty.

In 0/p_rgh, set internalField to uniform 0.

Set all solid walls to fixedFluxPressure.

Set front and back to empty.

In 0/k, set internalField to uniform 1e-5.

Apply kqRWallFunction on all solid walls.

Set front and back to empty.

In 0/epsilon, set internalField to uniform 1e-5.

Apply epsilonWallFunction on all solid walls.

Set front and back to empty.

In 0/nut, set internalField to uniform 0.

Apply nutkWallFunction on all solid walls.

Set front and back to empty.

In 0/alphat, set internalField to uniform 0.

Apply compressible::alphatJayatillekeWallFunction on all solid walls with Prt 0.85.

Set front and back to empty.

In system/fvSolution, configure the p_rgh solver with tolerance 1e-8 and relTol 0.01.

Configure the p_rghFinal solver with tolerance 1e-8 and relTol 0.

Configure solvers for U, e, k, and epsilon each with tolerance 1e-8 and relTol 0.01.

Configure the corresponding Final solvers (UFinal, eFinal, kFinal, epsilonFinal) each with tolerance 1e-8 and relTol 0.

Initialize the flow field at rest with uniform temperature 300 K throughout the domain.

The reference state uses air-like properties: density 1.0 kg/m^3, reference temperature 300 K, thermal expansion coefficient 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, and thermal diffusivity 2.1e-5 m^2/s giving Prandtl number approximately 0.7.
