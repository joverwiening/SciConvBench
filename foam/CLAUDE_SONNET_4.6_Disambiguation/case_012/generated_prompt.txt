The simulation is an incompressible lid-driven cavity flow using OpenFOAM with the pisoFoam solver.

The cavity geometry is a square with x and y dimensions normalized to 1 unit each and a z-dimension of 0.1 units to make it effectively 2D.

Generate a blockMesh with 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction, with uniform cell spacing in all directions.

The simulation start time is 0, the end time is 10, the time step (deltaT) is 0.005, and results are written every 100 time steps (writeInterval 100).

Use the pisoFoam solver for transient incompressible flow.

Apply the k-epsilon turbulence model.

Set kinematic viscosity nu to 1e-05 m^2/s in the transportProperties file.

The top wall is named movingWall and has a fixed velocity of (1 0 0) m/s (uniform, x-direction).

All other walls (bottom, left, right) are named fixedWalls and have a no-slip condition with velocity (0 0 0).

The front and back faces (z-normal faces) use the empty boundary condition, consistent with 2D treatment.

Initialize the entire domain with velocity (0 0 0) at time 0.

Initialize pressure p to 0 uniformly across the domain at time 0.

Set the pressure boundary condition to zeroGradient on all walls and empty on front and back.

Initialize k to 1.5e-4 uniformly in the domain.

Apply kqRWallFunction on all wall patches (movingWall and fixedWalls) for k.

Apply empty on front and back patches for k.

Initialize epsilon to 1.4e-4 uniformly in the domain.

Apply epsilonWallFunction on all wall patches (movingWall and fixedWalls) for epsilon.

Apply empty on front and back patches for epsilon.

Initialize nut to 0 uniformly in the domain.

Apply nutkWallFunction on all wall patches (movingWall and fixedWalls) for nut.

Apply empty on front and back patches for nut.

Set the convection scheme for div(phi,U) to Gauss limitedLinearV 1.

Set the convection scheme for div(phi,k) to Gauss limitedLinear 1.

Set the convection scheme for div(phi,epsilon) to Gauss limitedLinear 1.

Set the viscous term scheme div((nuEff*dev2(T(grad(U))))) to Gauss linear.

Use default or standard OpenFOAM settings for all other numerical schemes (e.g., Gauss linear for gradient schemes, linear interpolation, and corrected surface-normal gradients).

Use PISO algorithm settings appropriate for pisoFoam (nCorrectors 2, nNonOrthogonalCorrectors 1 as standard defaults).
