Run a transient laminar two-phase dam-break simulation with obstacles using the interFoam solver in OpenFOAM.

The computational domain is a cube spanning from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 cells in each direction (32 x 32 x 32), giving 32768 hexahedral cells total.

Define a rectangular box obstacle as a topoSet or STL-based cellZone occupying the region from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Treat the obstacle as a solid wall by assigning no-slip wall boundary conditions on all faces of the obstacle.

Set gravitational acceleration as g = (0, 0, -9.81) m/s² in the constant/g file.

Define the following boundary patches:
The top face (z = 1) is an atmosphere patch of type patch, with a totalPressure condition for pressure (p_rgh), inletOutlet for velocity U, and inletOutlet for alpha.water.
The remaining five faces (x=0, x=1, y=0, y=1, z=0) are wall patches of type wall with no-slip conditions for U, zeroGradient for p_rgh, and zeroGradient for alpha.water.

Initialize the phase fraction field alpha.water using setFields.
Set alpha.water = 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
Set alpha.water = 0 everywhere else.
Initialize U = (0, 0, 0) everywhere.
Initialize p_rgh = 0 everywhere.

Use the following fluid properties in constant/transportProperties:
Water: density (rho) = 1000 kg/m³, kinematic viscosity (nu) = 1.0e-6 m²/s.
Air: density (rho) = 1 kg/m³, kinematic viscosity (nu) = 1.48e-5 m²/s.
Surface tension (sigma) = 0.07 N/m.

Set the turbulence model to laminar in constant/turbulenceProperties.

Use the following time control settings in system/controlDict:
Set application to interFoam.
Set startTime = 0.
Set endTime = 0.1 s.
Set deltaT = 1e-3 s.
Set writeInterval = 0.02 s.
Set writeControl to runTime.
Set adjustTimeStep to no.

Use the PIMPLE algorithm for pressure-velocity coupling in system/fvSolution.
Use Gauss linearUpwind for divergence schemes on U and Gauss vanLeer for alpha.water in system/fvSchemes.
Use Gauss linear corrected for Laplacian schemes.
Use Euler for the time scheme (ddtSchemes).
