Simulate a 2D buoyant cavity (differentially heated square box) using OpenFOAM's buoyantBoussinesqSimpleFoam solver for a steady-state solution.

The domain is a unit square (1 m x 1 m) in 2D (one cell thick in the z-direction, with empty boundary conditions on the front and back faces).

The left wall is the hot wall with a fixed temperature of 310 K.
The right wall is the cold wall with a fixed temperature of 290 K.
The top and bottom walls are adiabatic (zero gradient for temperature).
All four walls use no-slip boundary conditions for velocity.

The fluid is air-like with the following properties:
Kinematic viscosity (nu) is 1.5e-5 m^2/s.
Thermal diffusivity (alpha) is 2.1e-5 m^2/s (Prandtl number approximately 0.71).
Thermal expansion coefficient (beta) is 3.33e-3 1/K (based on Boussinesq approximation at a reference temperature of 300 K).
Reference temperature (Tref) is 300 K.
Gravitational acceleration is 9.81 m/s^2 in the negative y-direction.

These properties yield a Rayleigh number of approximately 1e5, which is a well-studied benchmark case for this configuration.

Use the Boussinesq approximation for buoyancy; density is treated as constant except in the buoyancy term.
Set the reference pressure to 0 Pa (gauge).

The mesh is a structured 50x50 hexahedral grid generated using blockMesh.

Use the SIMPLE algorithm for pressure-velocity coupling.
Set relaxation factors to 0.7 for velocity, 0.3 for pressure, and 0.9 for temperature.
Run the simulation for a maximum of 2000 iterations or until all residuals drop below 1e-5, whichever comes first.

Use the following numerical schemes:
div(phi,U): Gauss linearUpwind grad(U)
div(phi,T): Gauss linearUpwind grad(T)
Laplacian schemes: Gauss linear corrected
Gradient schemes: Gauss linear

Initialize the velocity field to zero everywhere.
Initialize the temperature field to 300 K everywhere.
Initialize the pressure field to 0 Pa everywhere.

Output the fields (U, T, p_rgh) at the final converged time step.
Post-process by plotting temperature and velocity contours, and extract the Nusselt number along the hot wall to validate against published benchmark data (e.g., de Vahl Davis 1983).
