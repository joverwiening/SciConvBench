Create an OpenFOAM case for a laminar counter-flow diffusion flame using the reactingFoam solver.

The domain is 2-D rectangular spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Use 100 uniformly distributed cells in the x-direction, 40 uniformly distributed cells in the y-direction, and 1 cell in the z-direction.
Generate the mesh using blockMesh with a single block covering the full domain.

Name the boundary at x=0 as "fuel" and set it as a patch type.
Name the boundary at x=0.02 as "air" and set it as a patch type.
Name the boundaries at y=-0.01 and y=0.01 as "outlet" and set them as patch type.
Name the z-normal boundaries as "frontAndBack" and set them as empty type.

At the fuel inlet (x=0), set velocity as fixedValue (0.1 0 0) m/s.
At the fuel inlet, set temperature as fixedValue 293 K.
At the fuel inlet, set species mass fractions as fixedValue with Y_CH4 = 1.0 and all other species = 0.
At the fuel inlet, set pressure as zeroGradient.

At the air inlet (x=0.02), set velocity as fixedValue (-0.1 0 0) m/s.
At the air inlet, set temperature as fixedValue 293 K.
At the air inlet, set species mass fractions as fixedValue with Y_O2 = 0.23 and Y_N2 = 0.77 and all other species = 0.
At the air inlet, set pressure as zeroGradient.

At the outlet boundaries (top and bottom), set velocity as zeroGradient.
At the outlet boundaries, set pressure as fixedValue 101325 Pa (totalPressure or fixedValue as appropriate).
At the outlet boundaries, set temperature as zeroGradient.
At the outlet boundaries, set species as zeroGradient.

At frontAndBack, set all fields as empty.

Use reactingFoam as the solver.
Use compressible finite-rate chemistry formulation.
Use hePsiThermo as the thermodynamic model.
Use coefficientWilkeMultiComponentMixture as the mixture model.
Use Sutherland transport model.
Use JANAF thermodynamics.
Use a laminar combustion model (laminar in combustionProperties).
Use laminar momentum transport (laminar in momentumTransport or turbulenceProperties).

In chemistryProperties, set chemistryType as EulerImplicit.
Use Rosenbrock43 as the ODE solver for chemistry integration.
Enable chemistry with chemistry on.

Use a GRI-Mech or compatible reduced methane-air chemical mechanism (e.g., GRI 3.0 or a compatible mechanism provided in the constant/chemkin or constant directory) with species including at minimum CH4, O2, N2, CO2, H2O, CO, H2, OH, H, O, CH3, CH2O, HO2, H2O2, and other relevant intermediates.

Set deltaT to 1e-4 s in controlDict.
Set endTime to 0.5 s in controlDict.
Set writeInterval to 0.05 s in controlDict (writeControl set to runTime).
Set startFrom to startTime with startTime 0.

Initialize the internal field for velocity to (0 0 0).
Initialize the internal field for temperature to 293 K.
Initialize the internal field for pressure to 101325 Pa.
Initialize the internal field for species mass fractions uniformly: Y_N2 = 0.77, Y_O2 = 0.23, all others = 0.

Set fvSchemes to use Euler for time discretization, Gauss linear for gradient schemes, Gauss linearUpwind for divergence of velocity and species, and Gauss linear corrected for Laplacian schemes.
Set fvSolution to use GAMG or PCG solvers for pressure and smoothSolver or PBiCGStab for velocity and species fields with appropriate tolerances (p: 1e-6, U and species: 1e-8).
