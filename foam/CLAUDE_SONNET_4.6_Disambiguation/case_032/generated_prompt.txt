The simulation is a transient 2D Rayleigh-Benard convection case using buoyantBoussinesqPimpleFoam with the Boussinesq approximation.

The domain is a rectangle with width L = 0.40 m and height H = 0.10 m, giving a 4:1 aspect ratio.

The mesh has 160 cells in x, 40 cells in y, and 1 cell in z, all uniform.

The spanwise depth in z is 0.01 m (one cell, effectively 2D).

Use the following fluid properties: kinematic viscosity nu = 1.5e-5 m²/s, Prandtl number Pr = 0.71, thermal diffusivity alpha = nu/Pr = 2.1127e-5 m²/s, thermal expansion coefficient beta = 3.33e-3 1/K, reference density rho0 = 1.0 kg/m³, reference temperature T0 = 299.5 K.

The gravitational acceleration is g = 9.81 m/s² acting in the negative y direction.

The Rayleigh number Ra = g * beta * DeltaT * H^3 / (nu * alpha) = 9.81 * 3.33e-3 * 1.0 * (0.10)^3 / (1.5e-5 * 2.1127e-5) ≈ 1e5, confirming consistency.

The bottom wall (y = 0) is set to a fixed temperature of 300 K (heated).

The top wall (y = H) is set to a fixed temperature of 299 K (cooled).

The left and right boundaries (x = 0 and x = L) are cyclic (periodic) for all fields.

The front and back boundaries (z faces) are set to empty to enforce 2D behavior.

The initial temperature field is set to T0 = 299.5 K uniformly throughout the domain with a small random perturbation (magnitude 0.01 K) added to trigger convection onset.

The initial velocity field U is set to zero everywhere.

The initial pressure field p_rgh is set to zero everywhere.

Set startTime to 0, endTime to 50 s, initial deltaT to 0.01 s, adjustTimeStep to yes, and maxCo to 0.5.

Write results every 1 s (writeInterval 1).

Use the PIMPLE algorithm with nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1.

In the transportProperties dictionary, set nu = 1.5e-5 m²/s.

In the thermophysicalProperties or transportProperties, set DT (thermal diffusivity) = 2.1127e-5 m²/s.

In the g file, set the gravitational vector to (0 -9.81 0) m/s².

In the turbulenceProperties file, set simulationType to laminar.

In the fvSchemes file, use Euler for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for the divergence of U, Gauss linear corrected for laplacianSchemes, and linear for interpolationSchemes.

In the fvSolution file, use PCG with DIC preconditioner for p_rgh, and PBiCGStab with DILU preconditioner for U and T.

Set the reference pressure level pRefCell to 0 and pRefValue to 0.

The Boussinesq buoyancy term uses rho0, beta, T0, and g as defined above, consistent with buoyantBoussinesqPimpleFoam conventions.
