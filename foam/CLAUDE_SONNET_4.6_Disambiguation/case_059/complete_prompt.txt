Simulate steady-state laminar flow in a straight circular pipe using an axisymmetric wedge mesh.

Solver: simpleFoam (run in laminar mode)

Geometry: Pipe length L = 1.0 m, radius R = 0.01 m (diameter 0.02 m). Model as a 5 deg wedge (axisymmetric approximation).

Mesh (blockMesh): structured wedge mesh with (100 axial) x (20 radial) x (1 circumferential) cells.
Patches:
- inlet (x=0)
- outlet (x=L)
- pipeWall (r=R)
- axis (r=0)  -> set patch type to symmetryAxis
- wedgeFront and wedgeBack -> set patch type to wedge

Physical properties (constant/transportProperties): kinematic viscosity nu = 1e-6 m^2/s.

Boundary conditions:
- U:
  - inlet fixedValue uniform (0.1 0 0)
  - outlet zeroGradient
  - pipeWall noSlip
  - axis symmetryAxis
  - wedgeFront/wedgeBack wedge
- p:
  - inlet zeroGradient
  - outlet fixedValue uniform 0
  - pipeWall zeroGradient
  - axis symmetryAxis
  - wedgeFront/wedgeBack wedge

Initial conditions: U uniform (0.1 0 0); p uniform 0.

Controls: endTime 1000; deltaT 1; writeInterval 100 (steady solver pseudo-time iterations).
