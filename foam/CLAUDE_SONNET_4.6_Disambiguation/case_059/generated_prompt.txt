Create a steady-state developing pipe flow simulation using simpleFoam in OpenFOAM.

The pipe is a cylinder 1 meter long with a diameter of 0.02 m (radius 0.01 m).
The flow is in the axial x-direction.

Geometry and Mesh:
Use blockMesh to create a cylindrical pipe geometry aligned along the x-axis.
The pipe runs from x = 0 to x = 1 m.
Use 100 cells in the axial (x) direction.
Use 20 cells in the radial direction.
Apply a grading in the radial direction to cluster cells near the wall for better boundary layer resolution.
Use wedge boundary conditions if a 2D axisymmetric approach is taken, or a full 3D cylinder mesh otherwise.

Fluid Properties (constant/transportProperties):
Set the transport model to Newtonian.
Set kinematic viscosity nu = 1e-6 m²/s.

Turbulence Modelling (constant/turbulenceProperties):
Set simulationType to laminar, since Re = (0.1 * 0.02) / 1e-6 = 2000, which is at the laminar-transitional boundary but treated as laminar.

Boundary Conditions (0/ directory):
At the inlet (x = 0), set U to fixedValue uniform (0.1 0 0).
At the inlet, set p to zeroGradient.
At the outlet (x = 1), set U to zeroGradient.
At the outlet, set p to fixedValue uniform 0.
At the pipe wall, set U to noSlip (fixedValue uniform (0 0 0)).
At the pipe wall, set p to zeroGradient.

Solver Settings (system/fvSolution):
Use simpleFoam as the solver.
Use GAMG solver for pressure with a tolerance of 1e-6.
Use smoothSolver with symGaussSeidel for velocity with a tolerance of 1e-6.
Set nNonOrthogonalCorrectors to 1.
Set relaxation factors: 0.7 for U and 0.3 for p.

Numerical Schemes (system/fvSchemes):
Use Gauss linear for gradient schemes.
Use Gauss linearUpwind for divergence schemes on U.
Use Gauss linear corrected for Laplacian schemes.

Run Control (system/controlDict):
Set application to simpleFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 1000 (steady-state iterations).
Set deltaT to 1.
Set writeInterval to 100.

Run blockMesh to generate the mesh, then run simpleFoam to execute the simulation.
Check convergence by monitoring residuals for U and p dropping below 1e-5.
