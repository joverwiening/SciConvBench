Set up a counter-flow diffusion flame simulation using OpenFOAM's reactingFoam solver.

GEOMETRY AND MESH

The domain is a 2D axisymmetric wedge geometry representing a cylinder with radius 0.02 m and height 0.02 m.
Orient the axis of symmetry along the y-axis (axial direction).
Use a wedge angle of 5 degrees in the z-direction to create the axisymmetric wedge geometry.
The wedge spans one cell in the azimuthal direction.
Use blockMesh to generate the mesh.
Apply 40 cells in the radial (x) direction and 40 cells in the axial (y) direction.
Grade the mesh in the axial direction so that cells are refined toward the midplane at y = 0.01 m where the flame is expected, using a grading ratio that compresses cells toward the center (e.g., split the axial blocks at y = 0.01 m with grading ratio 4 toward the center from both top and bottom).
Apply uniform cell spacing in the radial direction.

BOUNDARY CONDITIONS

Name the boundaries: fuelInlet (top, y = 0.02 m), airInlet (bottom, y = 0.0 m), axis (centerline, x = 0), wedge1 and wedge2 (the two azimuthal faces), and outerWall (radial boundary, x = 0.02 m).
Set the fuelInlet boundary type as patch.
Set the airInlet boundary type as patch.
Set the axis boundary type as symmetryPlane (or axis type for axisymmetric cases).
Set wedge1 and wedge2 boundary types as wedge.
Set outerWall boundary type as wall.

At fuelInlet: U = (0 -0.5 0) m/s (flow directed downward), T = 300 K, p = zeroGradient, CH4 mass fraction = 1.0, all other species = 0.
At airInlet: U = (0 0.5 0) m/s (flow directed upward), T = 300 K, p = zeroGradient, O2 mass fraction = 0.233, N2 mass fraction = 0.767, all other species = 0.
At outerWall: U = noSlip, T = zeroGradient, p = zeroGradient, species = zeroGradient.
At axis: apply symmetryPlane conditions for all fields.
At wedge1 and wedge2: apply wedge conditions for all fields.
Set the initial internal field to p = 101325 Pa, U = (0 0 0) m/s, T = 300 K, with air composition (O2 = 0.233, N2 = 0.767).

REACTION MECHANISM

Use GRI-Mech 3.0 as the detailed reaction mechanism.
Convert the GRI-Mech 3.0 files chem.inp and therm.dat to OpenFOAM format using the chemkinToFoam utility with the command: chemkinToFoam chem.inp therm.dat transport.dat constant/chemkin/reactions constant/chemkin/thermo.
Place the resulting reactions and thermo files in the constant/chemkin directory.
Set the chemistry format to chemkin in the chemistryProperties dictionary.

THERMOPHYSICAL AND CHEMISTRY PROPERTIES

In constant/thermophysicalProperties, set the thermophysical model to reactingMixture.
Use janaf for thermodynamic data and sutherland for transport properties as provided by GRI-Mech 3.0.
In constant/chemistryProperties, enable chemistry (chemistry on).
Use the EulerImplicit chemistry ODE solver with an initial chemical time step of 1e-7 s.
Set the maximum chemistry time step (maxChemicalTimeStep) to 1e-6 s.
Use the ode solver SIBS or seulex for stiff chemistry integration.

TURBULENCE

Set the turbulence model to laminar in constant/turbulenceProperties (simulationType laminar).

SOLVER SETTINGS

Use the PIMPLE algorithm in fvSolution.
Set nOuterCorrectors to 3, nCorrectors to 2, and nNonOrthogonalCorrectors to 1.
Use a GAMG solver for pressure with a tolerance of 1e-6 and relative tolerance of 1e-4.
Use a PBiCGStab solver with DILU preconditioner for velocity and species equations, with tolerance 1e-6 and relative tolerance 1e-4.
Use a PBiCGStab solver with DILU preconditioner for energy (h or T), with tolerance 1e-6 and relative tolerance 1e-4.

NUMERICAL SCHEMES

In fvSchemes, set the time discretization (ddtSchemes) to Euler (first-order implicit).
Set the gradient scheme (gradSchemes) to Gauss linear.
Set the divergence scheme for U (div(phi,U)) to Gauss linearUpwind grad(U).
Set the divergence scheme for species (div(phi,Yi_h)) to Gauss limitedLinear 1.
Set the divergence scheme for enthalpy to Gauss limitedLinear 1.
Set the Laplacian schemes to Gauss linear corrected.
Set the interpolation scheme to linear.
Set the snGradScheme to corrected.

TIME CONTROL

Set the start time to 0, end time to 0.5 s, and write interval to 0.01 s in controlDict.
Set deltaT to 1e-6 s initially.
Enable adjustTimeStep with maxCo = 0.5 and maxDeltaT = 1e-5 s to allow adaptive time-stepping.
Set the application to reactingFoam in controlDict.

EXECUTION

Run blockMesh to generate the mesh.
Run chemkinToFoam to convert the mechanism files.
Run reactingFoam to execute the simulation.
Monitor convergence by checking residuals and the temperature field to confirm flame stabilization near the midplane y = 0.01 m.
