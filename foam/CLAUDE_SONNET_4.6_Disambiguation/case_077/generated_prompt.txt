The simulation is a fully 3D bubble column using OpenFOAM's twoPhaseEulerFoam solver.
The domain dimensions are 0.2 m (x) x 1.0 m (y) x 0.2 m (z).
Use a structured mesh of 40 x 200 x 40 cells in x, y, and z respectively.
The continuous phase is water (liquid) and the dispersed phase is air (gas).
Use the Euler-Euler two-fluid approach as implemented in twoPhaseEulerFoam.
Set the constant bubble diameter for the air phase to 2 mm (0.002 m).
Use the Schiller-Naumann drag model for interphase momentum exchange.
The sparger inlet is a small rectangular patch centered at the bottom face (z = 0 plane in y-direction, i.e., the bottom wall).
Place the sparger patch centered at (x=0.1 m, z=0.1 m) on the bottom face, spanning 0.04 m x 0.04 m (4 cells x 4 cells), which is a reasonable best-practice assumption for a centered sparger.
At the sparger inlet patch, set the air velocity to (0 0.2 0) m/s (upward) and the air volume fraction alpha.air to 0.05.
At the sparger inlet patch, set the water velocity to (0 0 0) m/s and alpha.water to 0.95.
The remainder of the bottom face (outside the sparger patch) is a no-slip wall for both phases.
The top face of the column is an outlet (pressure outlet), set to atmospheric pressure (totalPressure or fixedValue 0 Pa gauge).
All four side walls are no-slip wall boundaries for both phases.
Initialize the column with water at rest: alpha.water = 1.0, alpha.air = 0.0 everywhere in the domain.
Set the simulation end time to 20 s.
Set the initial time step deltaT to 1e-3 s.
Enable adjustable time stepping with a maximum Courant number (maxCo) of 0.5.
Write output data every 0.2 s (writeInterval = 0.2 s).
Use standard physical properties: water density 1000 kg/m3, water dynamic viscosity 1e-3 Pa·s; air density 1.225 kg/m3, air dynamic viscosity 1.8e-5 Pa·s.
Include gravity as (0 -9.81 0) m/s2.
Use standard turbulence modeling appropriate for twoPhaseEulerFoam (e.g., mixture k-epsilon or per-phase k-epsilon); if not specified further, apply the dispersed k-epsilon turbulence model for the liquid phase.
Use GAMG or PCG solvers for pressure and smoothSolver for velocity fields as typical for twoPhaseEulerFoam.
Apply standard fvSchemes for twoPhaseEulerFoam: Euler time scheme, Gauss limitedLinear or van Leer for divergence schemes, and Gauss linear for gradient schemes.
