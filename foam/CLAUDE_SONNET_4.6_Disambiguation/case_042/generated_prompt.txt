Use OpenFOAM with the buoyantBoussinesqPimpleFoam solver.

The domain is a 2D rectangle, 2 m wide and 1 m tall.

Use a structured mesh appropriate for the domain (e.g., blockMesh with sufficient resolution to capture convection cells, such as 64 cells in x and 32 cells in z/y).

Work in dimensional form throughout.

Set kinematic viscosity nu = 0.00928 m²/s.

Set thermal diffusivity alpha (alphaEff or DT) = 0.01307 m²/s.

Set thermal expansion coefficient beta = 0.0034 1/K.

Set the temperature difference deltaT = 1 K across the domain height.

Set the reference temperature Tref = 299.5 K.

Set gravitational acceleration g = (0 -9.81 0) m/s².

The bottom wall (y = 0) has a fixed temperature boundary condition with T = 300 K and a no-slip velocity condition (U = (0 0 0)).

The top wall (y = 1 m) has a fixed temperature boundary condition with T = 299 K and a no-slip velocity condition (U = (0 0 0)).

Both the bottom and top walls use a zeroGradient condition for p_rgh.

The left and right walls use cyclic (periodic) boundary conditions for all fields: U, T, and p_rgh.

The front and back faces (z-direction) are set as empty to enforce 2D simulation.

Initialize U = (0 0 0) everywhere.

Initialize p_rgh = 0 everywhere.

Initialize temperature as T(x, y) = (300 - y) + 0.1 * sin(pi * x), where y is the vertical coordinate and x is the horizontal coordinate.

Set endTime = 500 s.

Set deltaT = 0.1 s as the initial time step.

Enable adjustTimeStep = yes with maxCo = 0.5.

Set writeInterval = 10 s.

In the thermophysicalProperties file, define the fluid using the Boussinesq approximation with the specified nu, alpha, beta, and Tref values.

In the g file, set gravitational acceleration to (0 -9.81 0) m/s².

Use the PIMPLE algorithm settings appropriate for buoyantBoussinesqPimpleFoam (e.g., nOuterCorrectors = 2, nCorrectors = 2, nNonOrthogonalCorrectors = 1).

The resulting Rayleigh number Ra = g * beta * deltaT * H³ / (nu * alpha) should be approximately 2500, consistent with the provided fluid properties and domain height H = 1 m.
