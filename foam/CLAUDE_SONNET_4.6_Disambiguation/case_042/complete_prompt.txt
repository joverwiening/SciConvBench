Simulate transient 2D Rayleigh-Benard convection in a fluid layer heated from below, targeting a Rayleigh number of Ra=2500.

Solver: buoyantBoussinesqPimpleFoam

Geometry & Mesh: A 2D rectangular domain with an aspect ratio of 2:1 (2m wide x 1m high). Use blockMesh to create a 80x40 cell mesh. Patches are 'bottomHot', 'topCold', 'leftWall', 'rightWall', and 'frontAndBack'.

Physical Properties (transportProperties dictionary): To achieve Ra = (g*beta*deltaT*H^3)/(nu*alpha) = 2500, with H=1m, deltaT=1K, g=9.81, beta=0.0034 1/K, and Pr=0.71, we set nu=0.00928 m^2/s and thermal diffusivity alpha = nu/Pr = 0.01307 m^2/s. Set Tref = 299.5 K.

Initial Conditions (0/ directory): The fluid is initially at rest (U = (0 0 0) m/s). To trigger convection, the temperature field is initialized to a linear profile T(y) = 300 - y, plus a small sinusoidal perturbation: T(x,y) = (300 - y) + 0.1*sin(pi*x). The initial p_rgh is uniform at 0.

Boundary Conditions (0/ directory):
- bottomHot: U = noSlip; T = fixedValue, value 300 K; p_rgh = fixedFluxPressure.
- topCold: U = noSlip; T = fixedValue, value 299 K; p_rgh = fixedFluxPressure.
- leftWall & rightWall: Use periodic boundary conditions (type cyclic) for all fields (U, T, p_rgh).
- frontAndBack: type empty.

Time Controls (controlDict): startTime = 0; endTime = 500; deltaT = 0.1; writeInterval = 10; maxCo = 0.5; adjustTimeStep = yes.
