The simulation is a 2D transient flow over a circular cylinder using OpenFOAM with the pimpleFoam solver.

The cylinder diameter is D = 0.1 m, centered at the origin (0, 0).

The computational domain extends from x = -1.0 m to x = +2.5 m and y = -1.0 m to y = +1.0 m (i.e., -10D to +25D in x, -10D to +10D in y).

The flow is 2D, so the domain has a depth of one cell in the z-direction with empty boundary conditions on the front and back faces.

The fluid kinematic viscosity is nu = 1e-3 m²/s, giving Reynolds number Re = U * D / nu = 1.5 * 0.1 / 1e-3 = 150.

The inlet velocity is U = 1.5 m/s in the x-direction.

Create the mesh using blockMesh and snappyHexMesh.

Define a background structured block mesh covering the full domain with a base cell size of approximately 0.05 m (0.5D).

Use snappyHexMesh to carve out the cylinder geometry and apply an O-grid-like refinement around the cylinder surface.

Apply at least 3 levels of refinement around the cylinder surface, targeting a cell size of approximately 0.005 m (0.05D) at the cylinder wall.

Define a wake refinement box from x = 0 to x = 2.5 m and y = -0.3 m to y = +0.3 m with 2 levels of refinement, targeting a cell size of approximately 0.01 m (0.1D).

Add at least 5 boundary layer expansion layers on the cylinder surface using snappyHexMesh addLayers, with an expansion ratio of 1.2 and a first layer thickness of approximately 0.001 m.

Set the inlet boundary condition to fixedValue with U = (1.5 0 0) m/s.

Set the outlet boundary condition to zeroGradient for velocity and fixedValue 0 for pressure.

Set the top and bottom boundaries to slip (symmetryPlane) boundary conditions.

Set the cylinder wall boundary condition to noSlip for velocity and zeroGradient for pressure.

Use the pimpleFoam solver with the PIMPLE algorithm.

Set nOuterCorrectors = 2, nCorrectors = 2, and nNonOrthogonalCorrectors = 1 in fvSolution.

Enable adjustable time stepping with adjustTimeStep set to yes and maxCo = 0.5.

Set the initial time step deltaT = 1e-3 s.

Set endTime = 20 s.

Set writeInterval = 0.2 s using the runTime write control.

Use the Gauss linear scheme for gradient and divergence terms, and Gauss linear corrected for the Laplacian scheme in fvSchemes.

Initialize the entire domain with uniform velocity U = (1.5 0 0) m/s and pressure p = 0 Pa.

Add a small perturbation to the initial y-velocity field (e.g., 0.01 m/s) near the cylinder to trigger vortex shedding onset.

Monitor the drag coefficient (Cd) and lift coefficient (Cl) on the cylinder surface at every time step using the OpenFOAM forceCoeffs function object.

Set the reference values for forceCoeffs as: liftDir = (0 1 0), dragDir = (1 0 0), pitchAxis = (0 0 1), magUInf = 1.5, lRef = 0.1, Aref = 0.1 (per unit depth).

Write forceCoeffs output to the postProcessing directory.

The expected Strouhal number for Re = 150 is approximately St = 0.185, corresponding to a vortex shedding frequency of approximately f = St * U / D = 2.775 Hz, which can be used to validate the simulation results.
