Use OpenFOAM with the pimpleFoam solver to run a Large Eddy Simulation of flow over periodic hills.

GEOMETRY AND DOMAIN
The hill height is H = 0.028 m.
Use the standard Mellen et al. periodic hills geometry.
The streamwise domain length is Lx = 9H = 0.252 m.
The wall-normal domain height is Ly = 3.036H = 0.08501 m.
The spanwise domain width is Lz = 4.5H = 0.126 m.

FLOW CONDITIONS
The Reynolds number is Re_H = 10595, based on hill height H and bulk velocity Ub.
Compute Ub = Re_H * nu / H, using kinematic viscosity nu = 1.516e-5 m²/s (air at ~20°C) unless a different fluid is implied, giving Ub ≈ 5.72 m/s.
Apply a streamwise pressure gradient or mass-flow-rate forcing to maintain the target bulk velocity Ub throughout the simulation.

MESH
Target a total cell count of approximately 1.5 million cells.
Distribute cells as approximately 200 cells in x, 100 cells in y, and 75 cells in z as a starting point, adjusted to hit the target count.
Use wall-normal mesh grading near all solid surfaces (hill surface and top and bottom walls) to achieve y+ ~ 1–2 on the hill surface.
Use a structured or block-structured hex mesh generated with blockMesh, with the hill surface profile defined analytically using the standard periodic hills polynomial.
Ensure smooth cell-to-cell expansion ratios, keeping the ratio below 1.2 near walls.

BOUNDARY CONDITIONS
Apply periodic boundary conditions in the streamwise direction (x) between the inlet and outlet patches.
Apply periodic boundary conditions in the spanwise direction (z) between the two side patches.
Apply no-slip boundary conditions on the hill surface and the flat bottom wall.
Apply a slip or symmetry boundary condition on the top wall, consistent with standard periodic hills reference cases.
Initialize the velocity field with the bulk velocity Ub in the streamwise direction plus a small random perturbation (e.g., 5% of Ub) to trigger turbulence.

SGS MODEL
Use the WALE sub-grid scale model as the primary choice.
Smagorinsky is acceptable as an alternative if WALE is unavailable or inconvenient.
Set the WALE model coefficient Cw = 0.325 (standard value).

NUMERICAL SCHEMES
Use the linear (pure central differencing) scheme for the convective term in the momentum equation, consistent with best-practice LES in OpenFOAM.
Use the Gauss linear scheme for gradient terms.
Use the Gauss linear corrected scheme for Laplacian terms.
Use linear interpolation for face interpolations.
Use the Gauss linear scheme for divergence of the SGS stress tensor.

TIME STEPPING AND SIMULATION DURATION
Use adjustable time stepping controlled by a maximum Courant number of maxCo = 1.0.
Set the initial deltaT to 1e-4 s.
Allow deltaT to adjust automatically within the range 1e-4 s to 5e-4 s.
Set endTime = 5.0 s, corresponding to approximately 20 flow-through times based on Lx and Ub.
Write solution fields every 0.05 s (writeInterval = 0.05 s).

STATISTICS COLLECTION
Discard the first 2.0 s (approximately 8 flow-through times) as the flow development or spin-up period.
Begin collecting time-averaged statistics at t = 2.0 s.
Collect statistics from t = 2.0 s to t = 5.0 s, giving approximately 3.0 s (roughly 12 flow-through times) of averaging time.
Use the fieldAverage function object in OpenFOAM to compute time-averaged mean velocity components (UMean) and Reynolds stress components (UPrime2Mean) during the statistics window.

PIMPLEFOAM SETTINGS
Use the PIMPLE algorithm with nOuterCorrectors = 2, nCorrectors = 2, and nNonOrthogonalCorrectors = 1.
Set the pressure solver tolerance to 1e-6 and the velocity solver tolerance to 1e-7.
Use a GAMG solver for pressure and a smoothSolver with GaussSeidel smoother for velocity.

OUTPUT AND POST-PROCESSING
Write all primitive fields (U, p) at each write interval.
Write the SGS viscosity field (nut) at each write interval for diagnostic purposes.
After the simulation, extract time-averaged streamwise velocity profiles at the standard x/H stations (x/H = 0.05, 0.5, 1, 2, 3, 4, 5, 6, 7, 8) for comparison against the Breuer et al. (2009) reference DNS and LES data at Re_H = 10595.
