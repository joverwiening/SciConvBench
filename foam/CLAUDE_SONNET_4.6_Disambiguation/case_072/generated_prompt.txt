Run a pimpleFoam simulation of a 2D backward-facing step flow using water as the fluid.

Geometry and Mesh:
The domain is a 2D backward-facing step channel with an out-of-plane thickness of 0.01 m.
The total streamwise length is 1.0 m.
The upstream section spans from x = 0.0 m to x = 0.2 m with a channel height of 0.02 m.
The step is located at x = 0.2 m with a step height of 0.02 m.
The downstream section spans from x = 0.2 m to x = 1.0 m with a channel height of 0.04 m.
The front and back patches are set as empty to enforce 2D behavior.
Use blockMesh to construct the mesh with appropriate block decomposition to represent the step geometry.
Use a structured hex mesh with sufficient resolution near walls to support wall functions (y+ target in the range 30 to 300).

Fluid Properties:
Use water with kinematic viscosity nu = 1e-6 m²/s and density rho = 1000 kg/m³.

Turbulence Modeling:
Use RAS turbulence modeling with the kEpsilon model.
Apply standard wall functions on all no-slip wall patches for k, epsilon, and nut.

Boundary Conditions:
At the inlet, set velocity to fixedValue uniform (0.5 0 0) m/s.
At the inlet, set pressure to zeroGradient.
At the inlet, set k to fixedValue uniform 9.375e-4 m²/s².
At the inlet, set epsilon to fixedValue uniform 5.5e-3 m²/s³.
At the inlet, set nut to calculated or zeroGradient.
At the outlet, set pressure to fixedValue uniform 0 Pa.
At the outlet, set velocity to zeroGradient.
At the outlet, set k and epsilon to zeroGradient.
At all wall patches (top wall, bottom wall upstream, bottom wall downstream, and step face), set velocity to fixedValue uniform (0 0 0).
At all wall patches, apply kqRWallFunction for k, epsilonWallFunction for epsilon, and nutkWallFunction for nut.
At the front and back patches, set all fields to empty.

Solver and Numerical Settings:
Use pimpleFoam as the solver.
Set deltaT to 1.0 s.
Set endTime to 2000 s.
Set writeInterval to 100 s.
Use Gauss linearUpwind or linearUpwindV schemes for divergence terms involving velocity.
Use Gauss linear corrected for Laplacian schemes.
Set PIMPLE nOuterCorrectors to 2, nCorrectors to 2, and nNonOrthogonalCorrectors to 1.
Set residual tolerances for p to 1e-6 and for U, k, epsilon to 1e-5.

Initial Conditions:
Initialize the entire domain with velocity (0.5 0 0) m/s.
Initialize k uniformly to 9.375e-4 m²/s².
Initialize epsilon uniformly to 5.5e-3 m²/s³.
Initialize p uniformly to 0 Pa.
