Use OpenFOAM with the pimpleFoam solver for an incompressible, unsteady, laminar simulation with a generalised Newtonian viscosity model.

The 3D domain extends from x = -5 m to x = 5 m (streamwise), y = -1.5 m to y = 2.5 m (cross-stream), and z = -1 m to z = 1 m (spanwise).

A circular cylinder of diameter 2 m is centered at the origin (x = 0, y = 0) and spans the full z-extent of the domain.

The mesh must be a 2D mesh with a single cell layer in the z-direction, using empty boundary conditions on the front and back faces.

Generate the mesh using blockMesh and snappyHexMesh (or blockMesh alone with a suitable O-grid or background mesh), resolving the cylinder surface adequately.

Set startTime = 0 s, endTime = 0.5 s, deltaT = 0.0025 s, and writeInterval = 0.05 s in controlDict.

Set the writeFormat to ascii and the application to pimpleFoam in controlDict.

Use default PIMPLE settings with at least 2 outer corrector loops and 1 inner corrector loop.

The initial condition for the entire domain is U = (0 0 0) m/s and p = 0 Pa.

The inlet boundary (left face, x = -5 m) uses a fixedValue condition with U = (1 0 0) m/s and a zeroGradient condition for p.

The outlet boundary (right face, x = 5 m) uses a zeroGradient condition for U and a fixedValue condition with p = 0 Pa.

The top boundary (y = 2.5 m) and bottom boundary (y = -1.5 m) use noSlip for U and zeroGradient for p.

The cylinder wall uses noSlip for U and zeroGradient for p.

The front and back faces (z = -1 m and z = 1 m) use the empty boundary condition for both U and p.

Set the viscosity model to CrossPowerLaw in the transportProperties file (or constant/transportProperties in OpenFOAM v9+ directory structure).

Set the CrossPowerLaw parameters as follows: nu0 = 0.01 m²/s (zero-shear-rate viscosity), nuInf = 10 m²/s (infinite-shear-rate viscosity), m = 0.4 s (consistency index / time constant), n = 3 (power-law exponent).

Set tauStar = 0 Pa as the critical stress parameter, which reduces the Cross model to its standard shear-rate-dependent form without a yield-stress offset.

Set the simulationType to laminar in the turbulenceProperties (or momentumTransport) file.

Use the Gauss linear scheme for gradient and divergence terms, and Gauss linear corrected for the Laplacian scheme in fvSchemes.

Use a GAMG solver for p and a smoothSolver with symGaussSeidel for U in fvSolution.

Set the PIMPLE residual tolerances to 1e-6 for p and 1e-5 for U.

Output the fields U and p at each write interval.
