Set up the pitzDaily OpenFOAM case, which is a backward-facing step geometry.
Use the simpleFoam solver, which is appropriate for steady-state incompressible turbulent flow.
Use the standard k-epsilon RAS turbulence model.
Set the inlet boundary condition for velocity to uniform (10 0 0) m/s (x-direction only).
Set the outlet boundary condition for velocity to zeroGradient.
Set all wall boundary conditions for velocity to noSlip.
Set the inlet pressure boundary condition to zeroGradient.
Set the outlet pressure boundary condition to fixedValue uniform 0.
Set the kinematic viscosity nu to 1e-5 m²/s in the transportProperties file.
Use the transportModel Newtonian in the transportProperties file.
Set the inlet boundary condition for k (turbulent kinetic energy) to a fixedValue; calculate the inlet k value using k = 1.5*(I*U)^2 where I is turbulence intensity (assume I = 0.05) and U = 10 m/s, giving k = 0.375 m²/s².
Set the inlet boundary condition for epsilon (turbulent dissipation rate) to a fixedValue; calculate epsilon using epsilon = C_mu^0.75 * k^1.5 / L where C_mu = 0.09 and L is a representative length scale (assume L = 0.01 m based on pitzDaily geometry), giving epsilon approximately 101.5 m²/s³.
Set wall boundary conditions for k to kqRWallFunction.
Set wall boundary conditions for epsilon to epsilonWallFunction.
Set the inlet boundary condition for nut (turbulent viscosity) to calculated.
Set wall boundary conditions for nut to nutkWallFunction.
Use the standard pitzDaily mesh provided with OpenFOAM (blockMeshDict already defined in the case).
Run blockMesh to generate the mesh before running simpleFoam.
Set the number of iterations in controlDict to at least 500 with writeInterval 100.
Set deltaT to 1 in controlDict (pseudo-time step for steady-state).
Use SIMPLE algorithm settings in fvSolution with standard relaxation factors: 0.3 for pressure and 0.7 for velocity, k, and epsilon.
