Use OpenFOAM with the pimpleFoam solver for a transient, incompressible flow simulation over a cylinder at Reynolds number 100.

The fluid is water with density rho = 998.2 kg/m³ and kinematic viscosity nu = 1.004e-6 m²/s.

The mean inlet velocity is U = 0.001 m/s and the cylinder diameter is D = 0.1 m, giving Re = U*D/nu = 100.

The 2D computational domain is rectangular: 2.2 m in the x-direction and 0.41 m in the y-direction.

The cylinder center is located at (0.2, 0.2, 0.0) with diameter D = 0.1 m (radius = 0.05 m).

The domain is treated as 2D by using a single cell layer in the z-direction with empty boundary conditions on the front and back patches.

Generate the mesh using blockMesh combined with snappyHexMesh, or use blockMesh with a refined structured region around the cylinder.

Use a background mesh of approximately 110 cells in x and 41 cells in y (cell size approximately 0.02 m in the far field).

Refine the mesh near the cylinder surface to achieve a minimum cell size of approximately 0.002 m (D/50) in the region within 2D of the cylinder center.

Place at least 60 cells around the cylinder circumference.

Set the inlet boundary condition for U to fixedValue (0.001 0 0).
Set the outlet boundary condition for U to zeroGradient.
Set the top and bottom boundary conditions for U to slip.
Set the cylinder wall boundary condition for U to noSlip.
Set the front and back boundary conditions for U to empty.

Set the inlet boundary condition for p to zeroGradient.
Set the outlet boundary condition for p to fixedValue 0.
Set the top and bottom boundary conditions for p to zeroGradient.
Set the cylinder wall boundary condition for p to zeroGradient.
Set the front and back boundary conditions for p to empty.

Set startTime to 0 and endTime to 200 seconds.

Use adjustable time stepping with maxCo 1.0 and maxDeltaT 0.01 s.

Set deltaT to 0.001 s as the initial time step.

In fvSchemes, use Euler for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for the divergence of U, and Gauss linear corrected for laplacianSchemes.

In fvSolution, use GAMG solver for p with tolerance 1e-6 and relTol 0.01, and smoothSolver with symGaussSeidel for U with tolerance 1e-7 and relTol 0.1.

Set nOuterCorrectors to 2, nCorrectors to 2, and nNonOrthogonalCorrectors to 1 in the PIMPLE dictionary.

Write output every 1 second of simulation time (writeInterval 1).

Use writeFormat ascii and writePrecision 6.

Monitor and record the drag coefficient (Cd) and lift coefficient (Cl) on the cylinder surface throughout the simulation using the forces function object, with rhoInf = 998.2, liftDir (0 1 0), dragDir (1 0 0), CofR (0.2 0.2 0), and pitchAxis (0 0 1).

Use a reference length of D = 0.1 m and reference area (per unit span) of 0.1 m² for force coefficient normalization.

Expect periodic vortex shedding (Karman vortex street) to develop after an initial transient; the Strouhal number is expected to be approximately 0.165 at Re = 100.
