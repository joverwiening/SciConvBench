Use the buoyantFoam solver for this simulation.
Set gravity to (0 -9.81 0) in constant/g.
The computational domain is 9 m wide × 1 m tall × 1 cell deep in the spanwise direction.
Use a mesh of 90 cells in x, 10 cells in y, and 1 cell in z.
The domain depth in z should be set to a small thickness (e.g., 0.1 m) to represent a 2D case with one cell.

Create the blockMeshDict in system/ to define this box geometry with the above cell counts.
Label the patches: bottom (y=0), top (y=1), left and right as sides (x=0 and x=9), and front and back (z faces) as empty patches.

In constant/physicalProperties, use thermoType with class heRhoThermo, type rhoThermo, mixture pureMixture, transport const, thermo hConst, equationOfState Boussinesq.
Set mixture specie molWeight to 29.
Set equationOfState coefficients: rho0 1.0, T0 300, beta 3.3e-3.
Set thermodynamics coefficients: Cv 714.3, Hf 0.
Set transport coefficients: mu 1.5e-5, Pr 0.714.

In constant/turbulenceProperties, set simulationType to RAS and use the kEpsilon model.

In constant/g, set the gravitational acceleration value to (0 -9.81 0).

In 0/U, set internalField to uniform (0 0 0).
Apply noSlip boundary condition on bottom, top, left, and right walls.
Apply empty boundary condition on front and back patches.

In 0/T, set internalField to uniform 300.
Set bottom wall to fixedValue 305.
Set top wall to fixedValue 295.
Set left and right side walls to zeroGradient.
Set front and back patches to empty.

In 0/p, set internalField to uniform 0.
Set all solid walls (bottom, top, left, right) to calculated.
Set front and back patches to empty.

In 0/p_rgh, set internalField to uniform 0.
Set all solid walls to fixedFluxPressure.
Set front and back patches to empty.

In 0/k, set internalField to uniform 1e-5.
Apply kqRWallFunction on bottom, top, left, and right walls.
Apply empty on front and back patches.

In 0/epsilon, set internalField to uniform 1e-5.
Apply epsilonWallFunction on bottom, top, left, and right walls.
Apply empty on front and back patches.

Apply nutkWallFunction on bottom, top, left, and right walls.

Apply compressible::alphatJayatillekeWallFunction with Prt 0.85 on bottom, top, left, and right walls.

In system/controlDict, set application to buoyantFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 1000.
Set deltaT to 1.
Do not enable adjustTimeStep, do not set maxCo, and do not set maxDeltaT.
Set writeControl to timeStep and writeInterval to 50.

In system/fvSchemes, use Gauss linear for gradient schemes, Gauss linear corrected for Laplacian schemes, and Gauss linearUpwind grad(U) for the divergence of U.
Use Gauss linear for other divergence terms.
Use linear interpolation and corrected surface normal gradients.

In system/fvSolution, configure the p_rgh solver to use GAMG with tolerance 1e-8 and relTol 0.01.
Configure solvers for U, e, k, and epsilon using smoothSolver or PBiCGStab with tolerance 1e-8 and relTol 0.01.
Set the corresponding Final solvers (p_rghFinal, UFinal, eFinal, kFinal, epsilonFinal) with the same settings but relTol 0.
Set PIMPLE settings with nOuterCorrectors 1, nCorrectors 2, and nNonOrthogonalCorrectors 0.
