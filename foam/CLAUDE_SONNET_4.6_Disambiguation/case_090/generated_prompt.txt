The simulation is a steady-state, incompressible, turbulent 2D flow in a wedge-shaped diffuser using OpenFOAM's simpleFoam solver.

The 2D diffuser geometry is defined by the following vertices:
Inlet bottom: (0, 0)
Inlet top: (0, 0.10)
Outlet bottom: (1, 0)
Outlet top: (1, 0.20)
The bottom wall is flat along y = 0 from x = 0 to x = 1.
The top wall diverges linearly from (0, 0.10) to (1, 0.20).
The domain is extruded one cell in the z-direction with a small thickness (e.g., 0.01 m) to create a valid 3D OpenFOAM mesh with empty front and back patches.

Use blockMesh to generate the mesh with sufficient resolution to capture the turbulent boundary layer and flow separation if present (e.g., 100 cells in x, 40 cells in y, 1 cell in z, with grading toward the walls in y).

The turbulence model is kOmegaSST.

The inlet boundary condition for velocity is U = (5 0 0) m/s (uniform, fixed value).
The inlet boundary condition for pressure p is zeroGradient.
The outlet boundary condition for p is fixedValue with p = 0 Pa (gauge).
The outlet boundary condition for U is zeroGradient.
The top and bottom walls use noSlip for U and zeroGradient for p.
The front and back patches are set to empty.

Derive inlet turbulence quantities using the following standard formulas:
Turbulence intensity I = 0.05 (5%).
Characteristic length scale L = 0.10 m (inlet height).
k = 1.5 * (U * I)^2 = 1.5 * (5 * 0.05)^2 = 0.09375 m^2/s^2.
Turbulent length scale l = 0.07 * L = 0.007 m.
omega = k^0.5 / (Cmu^0.25 * l), where Cmu = 0.09, giving omega = 0.09375^0.5 / (0.09^0.25 * 0.007) = 0.3062 / (0.5477 * 0.007) ≈ 79.8 rad/s.
Use fixedValue for k and omega at the inlet with the values above.
Use kqRWallFunction for k and omegaWallFunction for omega on wall patches.

The kinematic viscosity nu is set to 1e-5 m^2/s (approximate air, giving Re = U*L/nu = 5 * 0.10 / 1e-5 = 50000).

Use the simpleFoam solver with standard relaxation factors (e.g., 0.3 for p, 0.7 for U, k, omega).
Set convergence residual tolerance to 1e-5 for all fields.
Run for a sufficient number of iterations (e.g., 500 to 1000) to reach a converged steady-state solution.

Use paraFoam or ParaView to visualize the velocity magnitude, pressure field, turbulent kinetic energy, and streamlines in the diffuser.
