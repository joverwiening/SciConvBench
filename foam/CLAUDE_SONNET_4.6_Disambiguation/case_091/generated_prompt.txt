Simulate natural convection in a 2D square cavity using OpenFOAM with buoyantPimpleFoam.

The cavity dimensions are 0.1 m x 0.1 m.
Use a 2D mesh (one cell thick in the z-direction with empty boundary conditions on front and back patches).

The left wall is a fixed temperature hot wall at 313.15 K with no-slip velocity (U = 0 0 0) and zeroGradient for pressure.
The right wall is a fixed temperature cold wall at 293.15 K with no-slip velocity (U = 0 0 0) and zeroGradient for pressure.
The top and bottom walls are adiabatic (zeroGradient for T), no-slip (U = 0 0 0), and zeroGradient for pressure.

Set the initial internal field for U to (0 0 0), for T to 303.15 K (mean temperature), and for p_rgh to 0.

Use buoyantPimpleFoam as the solver.
Set the simulation end time to 200 seconds.
Set the initial deltaT to 0.005 s.
Enable adjustable time stepping with maxCo of 0.5.
Write results every 20 seconds.

Set simulationType to laminar in constant/momentumTransport.

Use air as an ideal gas in constant/thermophysicalProperties.
Set the equation of state to perfectGas.
Set the thermodynamics model to janaf with standard JANAF coefficients for air.
Set the transport model to sutherland with standard Sutherland coefficients for air.
Set molWeight to 28.9 kg/kmol.
Set the mixture to a single-component air mixture.

Use the PIMPLE algorithm in fvSolution with at least 2 outer corrector loops, 1 inner corrector loop, and 2 non-orthogonal correctors.
Use Gauss linear schemes for gradient and divergence terms in fvSchemes.
Use Gauss linear corrected for the Laplacian scheme.
Use linear interpolation.
Set ddtSchemes to Euler.

Include gravity as (0 -9.81 0) m/s2 in constant/g.
Set the reference pressure level (pRef) to 101325 Pa.
