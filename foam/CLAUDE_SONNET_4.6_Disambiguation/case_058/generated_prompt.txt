The simulation is a 2D laminar pimpleFoam case of flow past a cylinder at Reynolds number 100.

The fluid kinematic viscosity nu is 1e-3 m²/s.
The inlet velocity is 1 m/s in the x-direction, giving Re = U*D/nu = 100.

The computational domain is 2.2 m long (x), 0.41 m tall (y), and 0.01 m deep (z).
The cylinder diameter D is 0.1 m and its center is located at (0.2, 0.2, 0).

Generate the blockMesh geometry using an O-grid topology around the cylinder.
The O-grid inner block is a square of side 0.2 m centered on the cylinder at (0.2, 0.2, 0), with the cylinder inscribed within it.
Use approximately 50 cells around the cylinder circumference and 20 cells in the radial direction of the O-grid, graded toward the cylinder surface with an expansion ratio of approximately 4.
Use approximately 100 cells in the streamwise direction and 40 cells in the cross-stream direction for the outer background blocks.
Use 1 cell in the z (spanwise) direction since this is a 2D simulation.

The boundary patch named "inlet" is the left face (x = 0).
The boundary patch named "outlet" is the right face (x = 2.2).
The boundary patch named "topAndBottom" covers the top (y = 0.41) and bottom (y = 0) faces.
The boundary patch named "cylinderWall" is the cylinder surface.
The boundary patch named "frontAndBack" covers the front (z = 0.01) and back (z = 0) faces.

Set the inlet boundary condition for U to fixedValue (1 0 0).
Set the inlet boundary condition for p to zeroGradient.
Set the outlet boundary condition for U to inletOutlet with inletValue (1 0 0) and value (1 0 0).
Set the outlet boundary condition for p to fixedValue 0.
Set the cylinderWall boundary condition for U to noSlip.
Set the cylinderWall boundary condition for p to zeroGradient.
Set the topAndBottom boundary condition for U to slip.
Set the topAndBottom boundary condition for p to zeroGradient.
Set the frontAndBack boundary condition for both U and p to empty.

Use the laminar transport model with no turbulence modelling.
Set the transportModel to Newtonian in constant/transportProperties.
Set nu to 1e-3 m²/s.

In fvSolution, use GAMG solver for p with tolerance 1e-6 and relTol 0.01.
Use smoothSolver with symGaussSeidel smoother for U with tolerance 1e-8 and relTol 0.1.
Set nCorrectors to 2 in the PIMPLE dictionary.
Set nNonOrthogonalCorrectors to 0 in the PIMPLE dictionary.
Set nOuterCorrectors to 1 in the PIMPLE dictionary.

In fvSchemes, use Euler for ddtSchemes.
Use Gauss linear for gradSchemes.
Use Gauss linearUpwind grad(U) for the divergence scheme on div(phi,U).
Use Gauss linear corrected for laplacianSchemes.
Use linear interpolation for interpolationSchemes.
Use corrected for snGradSchemes.

In controlDict, set application to pimpleFoam.
Set startFrom to startTime with startTime 0.
Set endTime to 8.0.
Set adjustTimeStep to yes.
Set maxCo to 1.0.
Set deltaT to 1e-3 as the initial time step.
Set writeControl to adjustableRunTime.
Set writeInterval to 0.1.
Set purgeWrite to 0.
Set writeFormat to ascii.
Set runTimeModifiable to yes.
