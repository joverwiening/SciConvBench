Simulate 2D incompressible, laminar flow past a cylinder at Re=100 using the pimpleFoam solver.
GEOMETRY: The domain is a channel of size 2.2m x 0.41m x 0.01m. A cylinder with a diameter D=0.1m is centered at (0.2, 0.2, 0).
MESH: Use blockMesh to create a background mesh with an O-grid around the cylinder location. Patches are 'inlet', 'outlet', 'cylinderWall', 'topAndBottom', and 'frontAndBack'.
PHYSICAL PROPERTIES: To achieve Re = U*D/nu = 100, set kinematic viscosity 'nu' to 1e-3 m^2/s in 'constant/transportProperties'. This requires an inlet velocity of 1 m/s.
INITIAL CONDITIONS: Initialize U to (1 0 0) and p to 0.
BOUNDARY CONDITIONS:
- inlet: U fixedValue (1 0 0); p zeroGradient.
- outlet: U inletOutlet with inletValue (1 0 0); p fixedValue 0.
- cylinderWall: U noSlip (0 0 0); p zeroGradient.
- topAndBottom: type 'slip' for U; zeroGradient for p.
- frontAndBack: type 'empty' for U and p.
TIME CONTROLS: In 'system/controlDict', use adjustable time step with maxCo 1.0. Set endTime to 8.0 seconds to capture vortex shedding. Set writeInterval to 0.1.
SOLVER SETTINGS: In 'system/fvSolution', for the PIMPLE loop, set nCorrectors to 2 and nNonOrthogonalCorrectors to 0.
