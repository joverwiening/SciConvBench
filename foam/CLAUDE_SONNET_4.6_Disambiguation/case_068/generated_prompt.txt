The simulation is a 2D steady-state compressible laminar flow of air through a heated porous block using OpenFOAM (rhoSimpleFoam or equivalent compressible steady solver).

The computational domain is a 2D channel 0.2 m long and 0.05 m high, with 1 cell in the depth (z) direction.

The mesh resolves the channel in the x-y plane with the z-direction collapsed to a single cell using empty boundary conditions on the front and back faces.

The porous block occupies the region from x = 0.08 m to x = 0.12 m and spans the full channel height from y = 0 m to y = 0.05 m.

Use the rhoSimpleFoam solver for steady-state compressible flow.

Set the flow model to laminar; do not include any turbulence model.

Use air as the working fluid modeled as a perfect gas with standard thermodynamic properties (Cp = 1005 J/kg/K, gamma = 1.4, molecular weight = 28.97 g/mol).

Apply a fixedTotalPressure (or totalPressure) boundary condition at the inlet with total pressure p0 = 101325 Pa.

Apply a fixedValue total temperature boundary condition at the inlet with T0 = 300 K.

Apply a fixedValue static pressure boundary condition at the outlet with p = 100000 Pa.

Apply a zeroGradient condition for temperature at the outlet.

Apply a zeroGradient condition for velocity at the outlet.

Apply no-slip (fixedValue zero) velocity boundary conditions on the top and bottom channel walls.

Apply zeroGradient pressure and temperature conditions on the top and bottom walls.

Apply empty boundary conditions on the front and back faces (z-direction) for all fields.

Define the porous block region using a cellZone named porousBlock covering x = 0.08 m to x = 0.12 m, y = 0 m to y = 0.05 m.

Apply a DarcyForchheimerCoeff model to the porousBlock cellZone in fvOptions with d = (1e9, 1e9, 1e11) and f = (0, 0, 0) in the principal coordinate directions (x, y, z).

Apply a scalarSemiImplicitSource fvOption to the porousBlock cellZone injecting volumetric energy at a rate of 1e6 W/m³ into the enthalpy field h.

Set the scalarSemiImplicitSource to use absolute volume mode so the total power scales with the cell volume.

Use standard SIMPLE algorithm settings with relaxation factors appropriate for compressible flow (e.g., p = 0.3, U = 0.7, h = 0.7, rho = 0.05).

Run the simulation to steady-state convergence, targeting residuals below 1e-5 for all fields.

Output fields include pressure p, velocity U, temperature T, and density rho.
