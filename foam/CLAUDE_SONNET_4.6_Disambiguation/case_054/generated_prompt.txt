Simulate an oblique shock wave for a supersonic flow impinging on a wedge.

The working fluid is air modeled as a calorically perfect gas with a specific heat ratio γ = 1.4.
The freestream Mach number upstream of the shock is M1 = 2.0.
The wedge half-angle (flow deflection angle) is θ = 10 degrees.
Assume steady, inviscid, two-dimensional flow.
Use the oblique shock relations derived from the Rankine-Hugoniot conditions for a calorically perfect gas.

Step 1: Solve the θ-β-M relation to find the shock wave angle β for the weak shock solution.
The θ-β-M relation is: tan(θ) = 2 cot(β) × [M1² sin²(β) − 1] / [M1² (γ + cos(2β)) + 2].
Solve this equation numerically (e.g., via bisection or Newton-Raphson) for β given θ = 10° and M1 = 2.0.
Use the weak shock solution (the smaller value of β).

Step 2: Compute the normal component of the upstream Mach number as Mn1 = M1 × sin(β).

Step 3: Apply the normal shock relations using Mn1 to compute the following downstream quantities.
Compute the static pressure ratio: P2/P1 = 1 + 2γ/(γ+1) × (Mn1² − 1).
Compute the static density ratio: ρ2/ρ1 = (γ+1) × Mn1² / [(γ−1) × Mn1² + 2].
Compute the static temperature ratio: T2/T1 = (P2/P1) × (ρ1/ρ2).
Compute the normal component of the downstream Mach number: Mn2² = [(γ−1) × Mn1² + 2] / [2γ × Mn1² − (γ−1)].
Compute the total downstream Mach number: M2 = Mn2 / sin(β − θ).

Step 4: Report the following output values.
Report the shock wave angle β in degrees.
Report the downstream Mach number M2.
Report the static pressure ratio P2/P1.
Report the static density ratio ρ2/ρ1.
Report the static temperature ratio T2/T1.
Report the flow deflection angle θ = 10° as a confirmation.

Assume the shock is attached to the wedge tip (valid since θ is less than the maximum deflection angle for M1 = 2.0).
Do not model the expansion fan or boundary layer; only the oblique shock solution is required.
