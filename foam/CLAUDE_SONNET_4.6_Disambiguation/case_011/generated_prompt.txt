The simulation is an incompressible lid-driven cavity flow using OpenFOAM.
Use the pisoFoam solver.
The computational domain is a 3D box representing a 2D cavity, discretized with a 20x20 grid in the x and y directions and 1 cell in the z-direction.
The top wall boundary is named 'movingWall' and moves in the x-direction with a uniform velocity of 1 m/s.
The remaining walls are named 'fixedWalls' and have a no-slip boundary condition with velocity equal to zero.
The front and back faces are designated as 'empty' boundary type to enforce 2D flow behavior.
The fluid is incompressible with a constant kinematic viscosity (nu) of 1e-05 m^2/s.
Use the k-epsilon RANS turbulence model.
Set the convection scheme for div(phi,U) as Gauss limitedLinearV 1.
Set the convection scheme for div(phi,k) as Gauss limitedLinear 1.
Set the convection scheme for div(phi,epsilon) as Gauss limitedLinear 1.
Set the viscous term scheme for div((nuEff*dev2(T(grad(U))))) as Gauss linear.
