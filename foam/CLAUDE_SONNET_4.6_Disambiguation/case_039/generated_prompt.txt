Use OpenFOAM solver chtMultiRegionSimpleFoam for this conjugate heat transfer simulation with a porous fluid region inside a solid block.

GEOMETRY AND MESH

Create two mesh regions: one named "solid" and one named "fluid".
The overall solid block dimensions are 0.2 m x 0.2 m x 0.5 m.
The fluid channel is 0.1 m x 0.1 m in cross-section and runs along the full 0.5 m length through the center of the solid block.
Use blockMesh to define both regions, ensuring the fluid channel is centered within the solid block.
Define the shared interface between the fluid and solid regions as a coupled patch pair for conjugate heat transfer.
Name the fluid inlet patch "inlet" on the face at x = 0.
Name the fluid outlet patch "outlet" on the face at x = 0.5 m.
Name the outer solid boundary patches "externalWall".

REGION DIRECTORY STRUCTURE

Create the directory structure constant/fluid, constant/solid, 0/fluid, and 0/solid.
Place fluid thermophysical and turbulence properties in constant/fluid.
Place solid thermophysical properties in constant/solid.

FLUID THERMOPHYSICAL PROPERTIES

In constant/fluid/thermophysicalProperties, use the hePsiThermo or heRhoThermo model appropriate for incompressible liquid; use heRhoThermo with rhoConst and hConst.
Set fluid density rho = 1000 kg/m³.
Set fluid dynamic viscosity mu = 8.9e-4 Pa·s.
Set fluid specific heat Cp = 4186 J/(kg·K).
Set fluid thermal conductivity kappa = 0.6 W/(m·K).
Set the fluid turbulence model to laminar in constant/fluid/turbulenceProperties.

SOLID THERMOPHYSICAL PROPERTIES

In constant/solid/thermophysicalProperties, use the solidThermo model.
Set solid density rho = 2700 kg/m³.
Set solid specific heat Cp = 900 J/(kg·K).
Set solid thermal conductivity kappa = 237 W/(m·K).

POROUS MEDIA

In constant/fluid/fvOptions, define a porosity model of type DarcyForchheimer.
Apply the porosity model to the entire fluid region (cellZone covering all fluid cells).
Set Darcy coefficients d = (1e6 1e6 1e6) 1/m².
Set Forchheimer coefficients f = (100 100 100) 1/m.

FLUID BOUNDARY CONDITIONS (0/fluid)

For U at inlet, use fixedValue with value (0.05 0 0) m/s.
For U at outlet, use zeroGradient.
For U at the fluid-solid interface patch, use fixedValue (0 0 0) (no-slip wall).
For p at inlet, use zeroGradient.
For p at outlet, use fixedValue with value 0 Pa.
For p at the fluid-solid interface patch, use zeroGradient.
For T at inlet, use fixedValue with value 353.15 K.
For T at outlet, use zeroGradient.
For T at the fluid-solid interface patch, use compressible::turbulentTemperatureCoupledBaffleMixed with neighbourFieldName T, kappa fluidThermo, and kappaName none.

SOLID BOUNDARY CONDITIONS (0/solid)

For T at the fluid-solid interface patch on the solid side, use compressible::turbulentTemperatureCoupledBaffleMixed with neighbourFieldName T, kappa solidThermo, and kappaName none.
For T at externalWall, use mixed boundary condition with refValue 293.15 K, refGradient 0, and valueFraction computed from h = 10 W/(m²·K) using the relation valueFraction = h / (h + kappa/delta), or use externalWallHeatFluxTemperature with h = 10 W/(m²·K) and Ta = 293.15 K.

NUMERICAL SCHEMES AND SOLVERS

In system/fluid/fvSchemes, use steadyState for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for divSchemes on U, Gauss linear corrected for laplacianSchemes.
In system/solid/fvSchemes, use steadyState for ddtSchemes and Gauss linear corrected for laplacianSchemes.
In system/fluid/fvSolution, use SIMPLE algorithm with nNonOrthogonalCorrectors 1.
Use PCG solver with DIC preconditioner for p.
Use PBiCGStab solver with DILU preconditioner for U and T.
In system/solid/fvSolution, use PCG solver with DIC preconditioner for T.
Set residual convergence tolerance to 1e-6 for all fields.

SIMULATION CONTROL

In system/controlDict, set application to chtMultiRegionSimpleFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 1000 (steady-state iterations).
Set deltaT to 1.
Set writeInterval to 100.
Set runTimeModifiable to true.

EXECUTION

Run blockMesh to generate the combined mesh, then use splitMeshRegions -cellZones -overwrite to split into fluid and solid regions.
Run chtMultiRegionSimpleFoam to execute the simulation.
Monitor residuals for U, p, and T in both regions to confirm convergence.
