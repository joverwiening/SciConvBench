Use OpenFOAM's buoyantPimpleFoam solver for a 2D transient natural convection simulation in a closed room.

The domain is 4 m wide and 3 m tall with one cell in the depth (z) direction (2D simulation using empty patches on front and back).

Set the mesh to resolve the room with a structured block mesh, for example 80 cells in x and 60 cells in y, with grading to refine near walls if desired.

The floor is split into three sections: a left floor patch from x=0 to x=1.5 m, a floorHeater patch from x=1.5 m to x=2.5 m (1 m wide, centered), and a right floor patch from x=2.5 m to x=4 m.

Set the floorHeater boundary condition for T to fixedValue 323 K.

Set all other solid boundaries (leftWall, rightWall, ceiling, leftFloor, rightFloor) to zeroGradient for T (adiabatic).

Set all solid boundaries (walls, floor sections, ceiling) to fixedValue 0 for U (no-slip).

Set the front and back patches to empty type for both U, T, and p_rgh (2D treatment).

Initialize the entire domain with T = 293 K and U = (0 0 0).

Set p_rgh initial value to 0 and use zeroGradient on all walls and fixedFluxPressure on the floor and ceiling patches.

Use hePsiThermo for the thermophysical model with the pureMixture specie model.

Set the equation of state to perfectGas.

Set the transport model to sutherland with As = 1.479e-06 and Ts = 110.4 K.

Set MolWeight = 28.9 kg/kmol and Cp = 1005 J/(kg·K).

Set Pr is derived from sutherland transport; no explicit Pr entry is needed since sutherland provides mu(T) and kappa(T) directly.

Set the thermodynamic model to hConst with Hf = 0.

Enable gravity by setting g = (0 -9.81 0) in the constant/g file.

Set startTime = 0, endTime = 120 s, deltaT = 0.02 s in controlDict.

Enable adjustTimeStep = yes with maxCo = 0.7 in controlDict.

Set writeInterval = 2 s and writeControl = runTime in controlDict.

Use PIMPLE settings with nOuterCorrectors = 2, nCorrectors = 2, nNonOrthogonalCorrectors = 1.

Set the turbulence model to laminar (no turbulence) since natural convection at this scale is expected to be laminar.

Use Gauss linear schemes for gradient and divergence terms, and Gauss linear corrected for the Laplacian scheme in fvSchemes.

Use GAMG solver for p_rgh and smoothSolver for U and T in fvSolution.

Set the reference pressure to 101325 Pa using pRef in the thermophysical properties or via the buoyantPimpleFoam pRefCell/pRefValue settings (pRefCell = 0, pRefValue = 0 for p_rgh).

Output fields U, T, p_rgh, and alphat at each write interval.
