Create an OpenFOAM case for 2D laminar flow past a circular cylinder using the icoFoam or similar incompressible laminar solver.

The domain is a rectangular box from x = -5 m to x = 5 m (streamwise), y = -1.5 m to y = 2.5 m (cross-stream), and z = -1 m to z = 1 m (spanwise, for 2D empty condition).

The cylinder has a diameter of 2 m and is centered at the origin (x = 0, y = 0).

Use blockMesh or snappyHexMesh to generate the mesh with the cylinder cut out from the domain.

Label the patches as: inlet (left face, x = -5), outlet (right face, x = 5), top (y = 2.5), bottom (y = -1.5), cylinder (curved wall), front (z = 1), back (z = -1).

Set the front and back patches to type empty to enforce 2D simulation.

For the inlet boundary condition, set U = (1 0 0) m/s (fixedValue) and p = zeroGradient.

For the outlet boundary condition, set U = zeroGradient and p = 0 Pa (fixedValue, uniform 0).

For the top and bottom walls, set U = noSlip (fixedValue uniform (0 0 0)) and p = zeroGradient.

For the cylinder wall, set U = noSlip (fixedValue uniform (0 0 0)) and p = zeroGradient.

For the front and back patches, set both U and p to type empty.

Set the initial conditions in the 0/ directory: U = (0 0 0) uniform throughout the internal field, p = 0 uniform throughout the internal field.

Use the nonNewtonianIcoFoam solver (or icoFoam with generalised Newtonian support) to handle the laminar generalised Newtonian viscosity model.

In constant/transportProperties, set the transport model to generalizedNewtonian.

Set the viscosity model to crossPowerLaw within the generalizedNewtonian framework.

Set the crossPowerLaw coefficients as follows: nu0 = 0.1 m^2/s (assumed as a reasonable upper bound, approximately 10 times nuInf, following best practice for Cross model where nu0 >> nuInf), nuInf = 10 m^2/s, m = 0.4, n = 3.

Set the kinematic viscosity nu = 0.01 m^2/s as the reference or characteristic viscosity for Reynolds number purposes.

Set the simulation as laminar in constant/turbulenceProperties or constant/momentumTransport: set simulationType to laminar.

In system/controlDict, set the application to nonNewtonianIcoFoam.

Set deltaT, endTime, and writeInterval to appropriate values for resolving the flow (for example, deltaT = 0.01 s, endTime = 50 s, writeInterval = 1 s).

Set writeFormat to ascii and writePrecision to 6.

In system/fvSchemes, use Euler for ddtSchemes, Gauss linear for gradSchemes, Gauss linear corrected for laplacianSchemes, and Gauss linearUpwind grad(U) for divSchemes on div(phi,U).

In system/fvSolution, use PCG with DIC preconditioner for the pressure solver and PBiCGStab with DILU preconditioner for the velocity solver.

Use the PISO or PIMPLE algorithm for pressure-velocity coupling with at least 2 corrector steps.
