Use OpenFOAM's chtMultiRegionSimpleFoam solver for a steady-state conjugate heat transfer simulation with pseudo-time stepping.

The overall computational domain is 0.5 m x 0.1 m x 0.01 m, treated as two-dimensional (one cell thick in the z-direction).
The domain contains two regions: a fluid region and a solid region named "fluid" and "solid" respectively.
The solid porous block is 0.1 m x 0.05 m x 0.01 m, centered at (0.25 m, 0.05 m, 0.005 m) within the domain.
The fluid region occupies the remainder of the domain surrounding the solid block.

Generate a multi-region mesh using blockMesh and topoSet (or equivalent) to define the two regions.
Use a single-cell layer in the z-direction to enforce 2D behavior with empty front and back patches.

Model the fluid as a compressible perfect gas using heRhoThermo with the perfectGas equation of state.
Use Sutherland's law for dynamic viscosity in the fluid region.
Set fluid Cp to 1005 J/kg/K and molecular weight to 28.9 g/mol.
Density and viscosity in the fluid region are computed from the equation of state and Sutherland transport model, not set as fixed constants.
Use laminar flow modeling in the fluid region (no turbulence model).

Set solid region thermophysical properties as follows: rho = 500 kg/m3, Cp = 900 J/kg/K, kappa = 10 W/m/K.
Model the solid using heSolidThermo with constSolidThermo or equivalent solid thermo type in OpenFOAM.

Set the initial temperature to 300 K in both the fluid and solid regions.

Apply the following boundary conditions at the fluid inlet: U = (1 0 0) m/s as fixedValue, T = 400 K as fixedValue, p_rgh as fixedFluxPressure.
Apply the following boundary conditions at the fluid outlet: p_rgh = 0 as fixedValue, U as zeroGradient, T as inletOutlet with inletValue 300 K and value 300 K.
Apply the following boundary conditions at the top and bottom fluid walls: U as noSlip, T as zeroGradient (adiabatic), p_rgh as fixedFluxPressure.
Apply coupled boundary conditions at the fluid-solid interface for both T and p_rgh using compressible::turbulentTemperatureCoupledBaffleMixed or the standard chtMultiRegionSimpleFoam coupled patch type.
Apply empty boundary conditions on the front and back patches of both regions.

Set deltaT to 1, endTime to 2000, and writeInterval to 200 in the controlDict.
Set the application field in controlDict to chtMultiRegionSimpleFoam.

Use SIMPLE algorithm settings in fvSolution for both regions.
Set relaxation factors appropriate for compressible conjugate heat transfer, for example: U = 0.7, p_rgh = 0.3, h or T = 0.5, rho = 1.0.
Use Gauss linear or Gauss linearUpwind schemes for divergence terms in fvSchemes.
Use Gauss linear corrected for Laplacian schemes.

Set convergence residual tolerances to 1e-6 for all fields or use the default chtMultiRegionSimpleFoam recommended values.

Run the case using: chtMultiRegionSimpleFoam > log.solver 2>&1.
