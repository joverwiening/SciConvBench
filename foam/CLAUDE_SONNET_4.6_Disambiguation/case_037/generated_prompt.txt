Use OpenFOAM with the rhoPorousSimpleFoam solver for compressible, steady-state, turbulent flow through a porous filter in a duct.

GEOMETRY AND MESH

The duct is 2D with dimensions 0.5m (x) x 0.1m (y) x 0.01m (z).
Use blockMesh to generate the mesh with 250 cells in x, 50 cells in y, and 1 cell in z.
Define patches named: inlet (x=0 face), outlet (x=0.5m face), topAndBottomWalls (y=0 and y=0.1m faces), frontAndBack (z=0 and z=0.01m faces).
Define a cellZone named porousFilter covering the region from x=0.2m to x=0.25m across the full y and z extent.

FLUID PROPERTIES

Use air as a compressible ideal gas.
Set thermodynamic properties consistent with air: Cp = 1005 J/(kg·K), gamma = 1.4, molecular weight = 28.97 g/mol.
Use Sutherland's law for dynamic viscosity.

BOUNDARY CONDITIONS — INLET

Apply the supersonicFreestream boundary type to the inlet patch.
Set inlet velocity U = (700 0 0) m/s.
Set inlet static pressure p = 101325 Pa.
Set inlet static temperature T = 300 K.
Set inlet turbulent kinetic energy k = 0.003 m²/s².
Set inlet specific dissipation rate omega = 10 s⁻¹.

BOUNDARY CONDITIONS — OUTLET

Apply the waveTransmissive boundary type to the outlet patch for pressure and velocity.
Set outlet reference static pressure p = 101325 Pa.
Set outlet temperature T = 300 K using waveTransmissive or zeroGradient as appropriate for the solver.
Set k and omega to zeroGradient at the outlet.

BOUNDARY CONDITIONS — WALLS

Apply noSlip to U on the topAndBottomWalls patch.
Apply zeroGradient to p on the topAndBottomWalls patch.
Apply zeroGradient to T on the topAndBottomWalls patch (adiabatic walls).
Apply kqRWallFunction to k on the topAndBottomWalls patch.
Apply omegaWallFunction to omega on the topAndBottomWalls patch.
Apply nutkWallFunction to the turbulent viscosity nut on the topAndBottomWalls patch.

BOUNDARY CONDITIONS — FRONT AND BACK

Apply empty boundary type to the frontAndBack patch for all fields to enforce 2D simulation.

TURBULENCE MODEL

Use RAS turbulence modelling with the kOmegaSST model.
Use default kOmegaSST model coefficients as provided by OpenFOAM.
Set the initial internal field values to k = 0.003 m²/s² and omega = 10 s⁻¹.

POROUS MEDIA

Define the porosity model in system/fvOptions using the DarcyForchheimer model applied to the cellZone named porousFilter.
Set the Darcy coefficient d = (5e7 5e7 0) m⁻² for the porousFilter zone.
Set the Forchheimer coefficient f = (500 500 0) m⁻¹ for the porousFilter zone.
The z-component coefficients are zero to reflect the 2D nature of the simulation.

SOLVER SETTINGS

Use the rhoPorousSimpleFoam solver.
Set the SIMPLE algorithm with appropriate relaxation factors for a compressible supersonic case: suggest U = 0.7, p = 0.3, T = 0.7, k = 0.5, omega = 0.5.
Use Gauss linearUpwind or linearUpwindV schemes for divergence terms to handle the supersonic flow and shock robustly.
Use Gauss linear for gradient schemes and linear corrected for Laplacian schemes.
Run the simulation for a sufficient number of iterations (suggest at least 5000) and monitor residuals for convergence to below 1e-5 for all fields.

OUTPUT

Write field data every 500 iterations.
Monitor residuals for U, p, T, k, and omega throughout the run.
Inspect the solution for a normal shock upstream of or within the porous filter zone, consistent with the supersonic inlet condition.
