The simulation domain is a 1m x 1m square (2D lid-driven cavity).
The mesh is 40x40 cells.
The solver is pimpleFoam.
The top wall moves at 1 m/s in the x-direction (lid velocity).
All other walls are stationary no-slip walls.
The kinematic viscosity (nu) is 1e-4 m^2/s.
The simulation runs from t=0 to t=5s.
Use an adjustable time step with adjustTimeStep yes.
Set maxCo to 1.0.
Set maxDeltaT to 0.05.
The initial conditions are zero velocity and zero pressure throughout the domain.
Write results at every 0.1s interval (writeInterval 0.1) using a fixed write interval, unless otherwise specified.
Use the default PIMPLE settings (nOuterCorrectors 1, nCorrectors 2, nNonOrthogonalCorrectors 0) appropriate for this case.
The case is 2D, so use empty boundary conditions on the front and back patches.
The domain is a single block structured mesh generated with blockMesh.
