The simulation is a two-dimensional Rayleigh-Benard convection cell using OpenFOAM.

Use the buoyantFoam solver.

Create a rectangular cavity mesh that is 9 units wide (x), 1 unit tall (y), and 1 cell deep (z, with a small thickness such as 0.1 units).

Use 90 cells in the x direction, 10 cells in the y direction, and 1 cell in the z direction.

Set the front and back patches (spanwise faces) as type empty in all field files and in the boundary definition to enforce 2D behavior.

Set gravity in constant/g to (0 -9.81 0) (negative y direction).

In constant/physicalProperties, use thermoType with class heRhoThermo, type rhoThermo, mixture pureMixture, transport const, thermo hConst, equationOfState Boussinesq.

Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, Pr 0.714 in the mixture specie and transport entries.

In constant/momentumTransport, set simulationType RAS, model kEpsilon, turbulence on, printCoeffs on.

Do not use laminar anywhere in the turbulence or momentumTransport configuration.

In 0/T, set internalField uniform 300.

Set the bottom wall (y=0) temperature as fixedValue 305 K.

Set the top wall (y=1) temperature as fixedValue 295 K.

Set the left and right vertical side walls temperature as zeroGradient.

Set front and back patches in 0/T as empty.

In 0/U, set internalField uniform (0 0 0).

Apply noSlip boundary condition on all solid walls (top, bottom, left, right) in 0/U.

Set front and back patches in 0/U as empty.

In 0/p, set internalField uniform 0, all solid walls as calculated, and front and back as empty.

In 0/p_rgh, set internalField uniform 0, all solid walls as fixedFluxPressure, and front and back as empty.

In 0/k, set internalField uniform 1e-5, apply kqRWallFunction on all solid walls, and set front and back as empty.

In 0/epsilon, set internalField uniform 1e-5, apply epsilonWallFunction on all solid walls, and set front and back as empty.

In 0/nut, set internalField uniform 0, apply nutkWallFunction on all solid walls, and set front and back as empty.

In 0/alphat, set internalField uniform 0, apply compressible::alphatJayatillekeWallFunction on all solid walls with Prt 0.85, and set front and back as empty.

In system/controlDict, set application buoyantFoam, startFrom startTime, startTime 0, stopAt endTime, endTime 1000, deltaT 1, writeControl timeStep, writeInterval 50.

In system/fvSolution, configure the p_rgh solver with tolerance 1e-8 and relTol 0.01.

Configure solvers for U, e, k, and epsilon each with tolerance 1e-8 and relTol 0.01.

Configure the corresponding Final solvers (p_rghFinal, UFinal, eFinal, kFinal, epsilonFinal) with the same tolerance 1e-8 and relTol 0.

In system/fvSchemes, use Gauss linear for gradient schemes, Gauss linear corrected for Laplacian schemes, and Gauss linearUpwind grad(U) for divergence schemes on U, k, and epsilon.

Use Euler for the time scheme (ddtSchemes default Euler).

Initialize the flow at rest with no initial perturbation; the temperature difference between bottom (305 K) and top (295 K) will drive convection naturally.
