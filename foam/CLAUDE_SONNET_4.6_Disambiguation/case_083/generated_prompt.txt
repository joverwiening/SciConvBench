Use OpenFOAM with the reactingParcelFoam solver for a spray combustion simulation of liquid dodecane injected into hot air.

Geometry and Mesh
Model a cylindrical combustion chamber that is 0.2 m long and 0.1 m in diameter.
Set up the case as 2D axisymmetric using a wedge mesh with a small wedge angle (e.g., 5 degrees).
The wedge front and back patches use the wedge boundary condition.
The axis patch uses the axis boundary condition.

Continuous Phase — Gas Inlet Boundary Condition
Apply a fixedValue velocity of U = (10 0 0) m/s at the inlet.
Set inlet temperature to 800 K as a fixedValue.
Set inlet pressure to 101325 Pa as a totalPressure condition.
Set inlet gas composition by mass fraction: O2 = 0.233, N2 = 0.767.

Continuous Phase — Outlet Boundary Condition
Apply totalPressure for p at the outlet.
Apply zeroGradient for all other fields at the outlet.

Continuous Phase — Wall Boundary Condition
Apply no-slip (fixedValue U = 0) at the chamber wall.
Set wall temperature to a fixedValue of 400 K.

Turbulence Model
Use the standard k-epsilon turbulence model (RAS, kEpsilon).
Set reasonable inlet turbulence values, for example k = 1 m2/s2 and epsilon = 150 m2/s3, consistent with the inlet velocity.

Dispersed Phase — Spray Injection
Inject liquid dodecane at the center of the inlet face using a cone injection model.
Set the injection mass flow rate to 0.002 kg/s.
Set the injected droplet temperature to 300 K.
Use a Rosin-Rammler droplet size distribution with a mean diameter of 50e-6 m, spread parameter n = 3.5, and min/max diameters of 10e-6 m and 150e-6 m respectively.
Use a cone half-angle of 15 degrees as the spray cone angle.
Use the liquidEvaporation or liquidEvaporationBoil evaporation model for the droplets.
Use dodecane liquid properties (C12H26) for the dispersed phase.

Combustion Chemistry
Use a two-step global reaction mechanism for dodecane (C12H26).
Step 1: C12H26 + 12.5 O2 → 12 CO + 13 H2O
Step 2: CO + 0.5 O2 → CO2
Define these reactions in constant/reactionSchemes (or reactions sub-dictionary).
Use the PaSR (Partially Stirred Reactor) or EDC combustion model as appropriate for reactingParcelFoam with turbulent combustion.
Use JANAF thermodynamic data for all species: C12H26, O2, N2, CO, CO2, H2O.
Define all species thermodynamic coefficients in constant/thermophysicalProperties using the janaf format.

Thermophysical Model
Use the reactingMixture thermophysical model.
Use sutherland transport properties for the gas mixture.

Time Control
Set startTime = 0 and endTime = 0.05 s.
Use an adjustable time step with maxCo = 0.7.
Set an initial deltaT of 1e-6 s.
Write results every 0.001 s (writeInterval = 0.001 s, writeControl = adjustableRunTime).

Numerical Schemes
Use Euler implicit time integration (ddtSchemes: Euler).
Use Gauss linear or Gauss limitedLinear schemes for divergence terms.
Use Gauss linear corrected for Laplacian schemes.
Use linear interpolation.

Solvers
Use PIMPLE algorithm (nOuterCorrectors = 2, nCorrectors = 2, nNonOrthogonalCorrectors = 1).

Output
Write fields: U, p, T, Yi (all species mass fractions), k, epsilon, and Lagrangian parcel data including position, diameter, temperature, and velocity.
