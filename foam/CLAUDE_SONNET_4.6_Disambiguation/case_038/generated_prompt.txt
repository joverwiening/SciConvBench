The simulation uses OpenFOAM with the buoyantBoussinesqSimpleFoam solver.
The domain is a 2D porous block of dimensions 0.10 m (x) x 0.10 m (y) x 0.01 m (z).
The mesh has 40 cells in x, 40 cells in y, and 1 cell in z.
The front and back patches (z-direction faces) are set as empty boundary conditions.
The fluid is air modeled under the Boussinesq approximation.
No turbulence model is used; the flow is laminar.
The bottom wall is a fixed-temperature hot wall at 310 K.
The top wall is a fixed-temperature cold wall at 290 K.
The left and right walls are adiabatic (zero heat flux) with no-slip velocity conditions.
The reference temperature for the Boussinesq approximation is 300 K (the mean of 310 K and 290 K).
Use standard air properties at 300 K: kinematic viscosity nu = 1.589e-5 m^2/s, thermal diffusivity alphaEff consistent with Pr = 0.713, thermal expansion coefficient beta = 1.0/300 K^-1, and density rho = 1.177 kg/m^3.
The porous resistance is applied using the Darcy-Forchheimer model via fvOptions.
The Darcy coefficient d is set to (1e7 1e7 1e7) in all three directions.
The Forchheimer coefficient f is set to (0 0 0) — no Forchheimer term.
The porous zone covers the entire domain.
The simulation is steady-state (SIMPLE algorithm).
Use the following SIMPLE relaxation factors: p_rgh = 0.3, U = 0.7, T = 0.5.
Run the simulation for 2000 iterations or until residuals drop below 1e-6 for all fields.
Gravity is set to (0 -9.81 0) m/s^2, acting in the negative y-direction.
The pressure field uses a fixedFluxPressure condition on all walls and a buoyantPressure or fixedValue condition as appropriate for the buoyantBoussinesqSimpleFoam solver.
Initialize the velocity field to (0 0 0) m/s and the temperature field to 300 K throughout the domain.
Output the fields U, T, p_rgh, and phi at the end of the run.
