Final Specification:

The solver is buoyantBoussinesqSimpleFoam (steady-state, incompressible, Boussinesq buoyancy).
The computational domain is a 2D rectangle: 0.2 m wide (x), 0.4 m tall (y), 0.01 m thick (z).
The mesh is one cell thick in the z-direction (2D simulation).
The porous medium fills the entire domain with no separate fluid subdomain.
Gravity acts in the negative y-direction: g = (0 -9.81 0) m/s².

Fluid properties are defined as follows.
Kinematic viscosity: nu = 1e-6 m²/s.
Prandtl number: Pr = 7.0.
Thermal diffusivity: alphaEff = nu/Pr = 1.4286e-7 m²/s.
Thermal expansion coefficient: beta = 2.1e-4 1/K.
Reference temperature: T0 = 298 K.
Reference density: rho0 = 1000 kg/m³.

The Darcy-Forchheimer porous resistance is applied as an fvOptions source over the entire domain.
The Darcy coefficient vector is d = (1e8 1e8 1e8) m⁻².
The Forchheimer coefficient vector is f = (0 0 0) m⁻¹ (purely Darcy flow).

Boundary conditions for velocity (U) are as follows.
Left wall (hot): noSlip.
Right wall (cold): noSlip.
Top wall: noSlip.
Bottom wall: noSlip.
Front and back faces (z-direction): empty (2D).

Boundary conditions for pressure (p_rgh) are as follows.
All walls: fixedFluxPressure.
Front and back faces: empty.

Boundary conditions for temperature (T) are as follows.
Left wall: fixedValue 303 K.
Right wall: fixedValue 293 K.
Top wall: zeroGradient.
Bottom wall: zeroGradient.
Front and back faces: empty.

Use SIMPLE algorithm for pressure-velocity coupling.
Set relaxation factors: U = 0.7, p_rgh = 0.3, T = 0.5.
Run the simulation until residuals for U, p_rgh, and T all drop below 1e-6.
Use linear interpolation schemes and Gauss linear gradients throughout.
The turbulence model is set to laminar (no turbulence modelling).

The transportProperties file defines nu = 1e-6 m²/s and Pr = 7.0.
The thermophysicalProperties or transportProperties file defines beta = 2.1e-4 1/K, T0 = 298 K, and rho0 = 1000 kg/m³.
The fvOptions file defines a DarcyForchheimer (or explicitPorositySource) model applied to the cellZone covering the entire mesh with d = (1e8 1e8 1e8) and f = (0 0 0).
