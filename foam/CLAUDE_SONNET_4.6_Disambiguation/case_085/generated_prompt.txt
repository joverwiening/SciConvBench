Use OpenFOAM's coalChemistryFoam solver for the simulation.

Model a 2D rectangular furnace geometry that is 2 m high and 0.5 m wide.
Represent the 2D domain using a single-cell-thick 3D mesh with empty boundary conditions on the front and back faces.

Use the standard k-epsilon RAS turbulence model for the gas phase.
Apply standard wall functions for all turbulence quantities at the walls.

Use the P1 radiation model for thermal radiation.
Include the absorptivity and emissivity of the gas mixture consistent with coal combustion products (CO2, H2O) using appropriate P1 model coefficients.

Define one inlet at the bottom of the furnace for primary air and coal particle injection.
Set the primary air inlet velocity to (0 20 0) m/s.
Set the primary air inlet temperature to 400 K.
Set the primary air inlet composition to O2 mass fraction 0.233 and N2 mass fraction 0.767.

Inject coal particles at the same inlet location as the primary air.
Use a Rosin-Rammler particle size distribution with a mean diameter of 100 microns.
Set the Rosin-Rammler spread parameter n to 3.0 as a standard assumption for pulverized coal.
Set the minimum particle diameter to 10 microns and the maximum to 300 microns.
Set the coal particle mass flow rate to 0.1 kg/s.
Set the particle injection velocity to (0 20 0) m/s to match the primary air inlet.

Use the following proximate analysis for a typical high-volatile bituminous coal: moisture 5%, ash 8%, volatile matter 35%, fixed carbon 52% (all by mass, as-received basis).
Use the following ultimate analysis (dry, ash-free basis): C 80%, H 5.5%, O 8.5%, N 1.5%, S 1.5% by mass.

Model coal particle combustion using the standard coalChemistryFoam sub-models: single kinetic rate devolatilization model, diffusion-limited surface reaction model for char combustion, and species transport for the gas phase.
Use a single-step devolatilization model releasing volatiles as a mixture of CH4 and CO as representative surrogate species, consistent with OpenFOAM coalChemistryFoam defaults.
Model char combustion as a surface reaction with O2: C + O2 -> CO2.

Set wall boundary conditions as follows: no-slip velocity (U = (0 0 0)), fixed temperature T = 1200 K, zero-gradient pressure, and wall functions for k and epsilon.
Set the outlet boundary condition at the top of the furnace as a totalPressure boundary with p0 = 101325 Pa.
Set zero-gradient conditions for temperature, species, k, and epsilon at the outlet.

Set the initial conditions in the domain to T = 1200 K, U = (0 0 0) m/s, and air composition (O2 = 0.233, N2 = 0.767) to aid ignition and convergence.

Use a time step that satisfies a Courant number below 0.5 for stability.
Run the simulation until a statistically steady state is reached, assessed by monitoring outlet temperature and species mass fractions.
Write solution fields every 0.05 s of simulation time.

Monitor residuals for U, p, T, k, epsilon, and all species; target residuals below 1e-4 for convergence assessment.
