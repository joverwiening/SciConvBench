Set up a transient incompressible turbulent backward-facing step channel-flow case in OpenFOAM using pimpleFoam with water properties.
Assume OpenFOAM Foundation v10 as the target version.
Model as 2D using a finite z-thickness of 0.01 m with frontAndBack patches set to empty.
Use a rectangular domain of total length 1.0 m in x.
Use an upstream channel height of 0.02 m and a downstream channel height of 0.04 m created by a backward-facing step of height 0.02 m.
Place the backward-facing step at x = 0.2 m from the inlet.
Define the geometry so that for 0 ≤ x < 0.2 m the fluid region spans y = 0 to 0.02 m, and for 0.2 m ≤ x ≤ 1.0 m the fluid region spans y = 0 to 0.04 m, with the step vertical face at x = 0.2 m spanning y = 0.02 to 0.04 m.
Use boundary patches: inlet at x = 0, outlet at x = 1.0, bottomWall at y = 0, topWallUpstream at y = 0.02 for x < 0.2, topWallDownstream at y = 0.04 for x ≥ 0.2, stepWall as the vertical wall at x = 0.2 for y ∈ [0.02, 0.04], and frontAndBack as empty.
Set inlet velocity as a uniform fixedValue U = (0.5 0 0) m/s.
Set outlet pressure as fixedValue p = 0 (kinematic pressure) and use zeroGradient for U at the outlet.
Apply noSlip for U on all wall patches (bottomWall, topWallUpstream, topWallDownstream, stepWall).
Use RANS turbulence with the kEpsilon model and enable turbulence on.
Use wall functions: kqRWallFunction for k, epsilonWallFunction for epsilon, and nutkWallFunction for nut on all wall patches.
Set inlet turbulence quantities using a reasonable internal-flow estimate: set k at inlet to 0.00375 m2/s2 and epsilon at inlet to 0.056 m2/s3, with fixedValue at inlet and appropriate outlet zeroGradient.
Set p to zeroGradient on all walls and inlet, and fixedValue at outlet.
Use water kinematic viscosity nu = 1.0e-6 m2/s.
Create the mesh with blockMesh using at least two blocks to represent the step expansion, ensuring matching cell faces at the step interface.
Choose a mesh resolution sufficient for a RANS wall-function approach with y+ in the wall-function range, using near-wall grading toward walls.
Use PIMPLE settings suitable for transient RANS: second-order time discretization, bounded second-order convection schemes for U, k, epsilon, and appropriate relaxation factors.
Select a time step to keep max Courant number below 1, and run until statistically steady behavior is reached, with writeInterval set to capture flow development downstream of the step.
Post-process to obtain velocity profiles and reattachment length downstream of the step using sampled lines and wall shear sign change.
