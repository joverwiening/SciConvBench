Simulate LES of flow over periodic hills (ERCOFTAC-style) at Reynolds number Re_H = 10595.

Solver: pimpleFoam (incompressible transient)

Geometry:
- Use the standard periodic-hill bottom surface shape and a flat top wall.
- Set hill height H = 0.028 m. Domain extents:
  - streamwise length Lx = 9H = 0.252 m (periodic)
  - spanwise width Lz = 4.5H = 0.126 m (periodic)
  - channel height Ly = 3.036H ~ 0.0850 m (top wall at y=Ly)
- Bottom: periodic hill wall; Top: flat wall.

Mesh: Use snappyHexMesh from an STL of the periodic hill surface and a base blockMesh.
Target ~1.5 million cells; ensure near-wall resolution appropriate for LES (e.g., y+ ~ 1-2 on the hill).
Patches:
- xMin/xMax cyclic (periodic in x)
- zMin/zMax cyclic (periodic in z)
- bottomWall (hill surface)
- topWall (flat wall)

Physical properties: choose bulk velocity Ub = 1.0 m/s.
Set kinematic viscosity to match Re_H = Ub*H/nu:
- nu = Ub*H/Re_H = 1.0*0.028/10595 ~ 2.64e-6 m^2/s (constant/transportProperties).

Turbulence (LES): constant/momentumTransport
- simulationType LES
- LESModel WALE (or Smagorinsky)
- Set delta using cubeRootVol and appropriate coefficients.

Flow driving (system/fvOptions): use meanVelocityForce to maintain Ub in x:
- Ubar (1 0 0); relaxation 0.1; selectionMode all.

Initial conditions:
- U uniform (1 0 0)
- p uniform 0
- nut uniform 0 (LES will develop)
Optionally add a small perturbation (setFields) near the hill crest to accelerate transition.

Boundary conditions:
- bottomWall/topWall: U noSlip; p zeroGradient.
- cyclic patches: cyclic for all fields.

Time controls: startTime 0; endTime 5 s (~20 flow-through times since Lx/Ub~0.252 s); deltaT 1e-4-5e-4 (use adjustTimeStep, maxCo~1); writeInterval 0.05 s.
