Use OpenFOAM Foundation (latest stable at time of setup, e.g., v11) on Ubuntu 22.04 LTS.
Model a 2D planar converging–diverging de Laval nozzle and simulate compressible inviscid flow with rhoCentralFoam to obtain a normal shock in the diverging section.
Use a calorically perfect gas with gamma 1.4 and gas constant R 287 J/kg/K.
Use constant transport properties (set a constant dynamic viscosity value suitable for numerical stability, since walls are slip and viscous effects are not modeled).
Set inlet total pressure p0 = 5.0e5 Pa and inlet total temperature T0 = 600 K.
Set outlet static pressure (back pressure) p = 3.5e5 Pa with a fixedValue pressure boundary at the nozzle exit.
Use nozzle length 0.3 m with throat at x = 0.10 m.
Use inlet height 0.10 m, throat height 0.05 m, and outlet height 0.08 m.
Create a smooth nozzle contour using arc edges in blockMeshDict to smoothly connect the inlet, throat, and outlet heights.
Generate a structured 2D mesh with 300 cells in x and 50 cells in y.
Apply axial grading to cluster cells near the throat around x = 0.10 m.
Use inviscid slip walls on the top and bottom boundaries with U slip, p zeroGradient, and T zeroGradient.
Use an inlet boundary at x = 0 that imposes total conditions with a specified flow direction aligned with +x.
Set inlet pressure using totalPressure with p0 = 5.0e5 Pa.
Set inlet temperature using totalTemperature with T0 = 600 K.
Set inlet velocity using a direction-based condition compatible with rhoCentralFoam (e.g., pressureInletOutletVelocity or a fixed direction with magnitude determined by the solver from total conditions), with flow direction (1 0 0).
Use an outlet boundary at x = 0.3 m with p fixedValue 3.5e5 Pa and appropriate outlet conditions for U and T (e.g., zeroGradient for U and T, or inletOutlet variants to allow weak backflow handling).
Initialize the domain with a low-Mach uniform field consistent with subsonic inflow (e.g., p = 3.5e5 Pa, T = 600 K, U = (10 0 0) m/s) to aid startup.
Run transient with adjustable time step to maintain a target Courant number <= 0.5.
Use second-order spatial schemes suitable for shocks (rhoCentralFoam default central-upwind with appropriate limiters).
Run until the shock location in the diverging section becomes steady in time (monitor mass flow, exit pressure, and centerline Mach number).
Post-process centerline distributions of Mach number, static pressure, and static temperature to confirm choking at the throat and a normal shock in the diverging section.
Output fields frequently enough to capture shock stabilization (e.g., 200–500 writes over the run) and include residual/continuity monitoring.
