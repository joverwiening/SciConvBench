Create a 2D natural-convection (buoyant) cavity simulation in OpenFOAM using buoyantBoussinesqSimpleFoam for air with the Boussinesq approximation.
Use a square cavity domain of 1 m × 1 m in the x–y plane.
Use a 2D mesh with a frontAndBack patch set to empty.
Define gravity as g = (0 -9.81 0) m/s^2.
Set the left wall patch name to hotWall and apply a fixedValue temperature T = 303 K.
Set the right wall patch name to coldWall and apply a fixedValue temperature T = 293 K.
Set the top wall patch name to insulatedTop and apply a zeroGradient temperature boundary condition.
Set the bottom wall patch name to insulatedBottom and apply a zeroGradient temperature boundary condition.
Set the initial internal field for temperature T at time 0 to a uniform value of 293 K.
Apply noSlip velocity boundary condition for U on hotWall.
Apply noSlip velocity boundary condition for U on coldWall.
Apply noSlip velocity boundary condition for U on insulatedTop.
Apply noSlip velocity boundary condition for U on insulatedBottom.
Apply fixedFluxPressure boundary condition for p_rgh on hotWall.
Apply fixedFluxPressure boundary condition for p_rgh on coldWall.
Apply fixedFluxPressure boundary condition for p_rgh on insulatedTop.
Apply fixedFluxPressure boundary condition for p_rgh on insulatedBottom.
Set the frontAndBack patch to empty for all relevant fields (at minimum U, T, and p_rgh).
