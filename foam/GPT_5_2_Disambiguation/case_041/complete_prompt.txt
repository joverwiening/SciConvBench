Simulate a 2D differentially heated square cavity using the Boussinesq approximation for steady-state natural convection.

Solver: buoyantBoussinesqSimpleFoam

Geometry & Mesh: A 2D square domain of 1m x 1m. Use blockMesh to create a uniform 40x40 cell mesh. The patches will be 'hotWall' (left), 'coldWall' (right), 'insulatedTop' (top), 'insulatedBottom' (bottom), and 'frontAndBack' (empty for 2D).

Physical Properties (transportProperties dictionary): Use the Boussinesq model. Kinematic viscosity nu = 1e-5 m^2/s. Thermal expansion coefficient beta = 0.00333 1/K. Prandtl number Pr = 0.71. Reference temperature Tref = 293 K. Gravity g = (0 -9.81 0) m/s^2.

Initial Conditions (0/ directory): The fluid is initially at rest (U = (0 0 0) m/s) and at a uniform temperature of T = 293 K. The initial pressure field p_rgh is uniform at 0.

Boundary Conditions (0/ directory):
- hotWall: U = noSlip; T = fixedValue, value 303 K; p_rgh = fixedFluxPressure.
- coldWall: U = noSlip; T = fixedValue, value 293 K; p_rgh = fixedFluxPressure.
- insulatedTop & insulatedBottom: U = noSlip; T = zeroGradient; p_rgh = fixedFluxPressure.
- frontAndBack: type empty.

Time Controls (controlDict): This is a steady-state simulation. startTime = 0; endTime = 2000; deltaT = 1; writeInterval = 100. Use the SIMPLE algorithm for pressure-velocity coupling.
