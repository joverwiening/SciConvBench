Create a 2D Rayleigh–Bénard convection case using buoyantFoam in a rectangular cavity of size 9 (x) by 1 (y) by 1 cell (z).

Extrude a single cell in the spanwise (z) direction and set the front and back patches to type empty to enforce 2D.

Assume a standard Linux environment for case setup and run commands.
Set gravity to act downward in the negative y direction.
Use the buoyantFoam solver.
Run with a fixed time step of 1 s by setting deltaT = 1 and do not enable adjustTimeStep, maxCo, or maxDeltaT.
Simulate from time 0 s to 1000 s physical time.
Write results every 50 time steps.

Apply no-slip velocity conditions on all solid walls.
Set the bottom wall temperature to fixedValue 305 K.
Set the top wall temperature to fixedValue 295 K.
Set the vertical side walls temperature to zeroGradient (adiabatic).
Set front and back temperature boundary conditions to empty.
Initialize 0/U internalField to uniform (0 0 0).
Set 0/U boundary conditions to noSlip on all solid walls and empty on front/back.
Initialize 0/T internalField to uniform 300.
Initialize 0/p_rgh internalField to uniform 0.
Set 0/p_rgh boundary conditions to fixedFluxPressure on walls and empty on front/back.
Set 0/p boundary conditions to calculated on walls and empty on front/back.
