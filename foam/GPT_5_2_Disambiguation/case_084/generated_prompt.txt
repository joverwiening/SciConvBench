Create an OpenFOAM CFD case to simulate premixed flame propagation in a closed tube filled with a stoichiometric hydrogen–air mixture, ignited at one end.
Assume OpenFOAM Foundation distribution, version v10, as the target platform.
Use the solver rhoReactingFoam for compressible reacting flow with detailed chemistry.
Model the tube as a 3D rectangular duct aligned with the x-axis.
Set tube length to 0.5 m.
Set tube cross-section to 0.01 m × 0.01 m (width × height).
Create a hexahedral mesh of the full 3D domain (no symmetry assumptions).
Treat the mixture as stoichiometric hydrogen–air premixed throughout the tube at t = 0.
Set initial pressure p = 101325 Pa everywhere.
Set initial temperature T = 300 K everywhere except the ignition region.
Define the ignition region as 0 ≤ x ≤ 0.01 m across the full cross-section.
Set initial temperature in the ignition region to T = 2000 K.
Initialize velocity U = (0 0 0) m/s everywhere.
Use a detailed hydrogen–air reaction mechanism with approximately 9 species and 19 reactions.
Provide the chemistry in CHEMKIN format and convert it to OpenFOAM chemistry/thermo files.
Place the converted chemistry and thermophysical property files under the constant/ directory in the case.
Configure thermodynamics for a compressible reacting mixture suitable for hydrogen–air combustion with detailed chemistry (e.g., ideal gas, JANAF/NASA polynomials as required by the mechanism).
Set all four side walls (y-min, y-max, z-min, z-max) as adiabatic no-slip walls.
Set both tube ends (x = 0 and x = 0.5 m) as closed solid walls with the same wall treatment.
Apply boundary conditions on all wall patches as follows.
Set U to noSlip.
Set T to zeroGradient.
Set p to fixedFluxPressure.
Set all species mass fractions to zeroGradient.
Run the simulation as a transient compressible reacting flow until the flame has clearly propagated away from the ignition region and pressure waves have evolved within the closed tube.
Output fields at a time resolution sufficient to capture flame propagation and pressure wave dynamics (including at least p, T, U, and all species mass fractions).
Include function objects or post-processing steps to extract flame position versus time (e.g., based on a temperature or OH/H2O mass-fraction iso-surface) and to record pressure histories at multiple x-locations along the tube.
