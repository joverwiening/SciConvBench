Set up a 2D Rayleigh–Bénard convection case in OpenFOAM using buoyantBoussinesqSimpleFoam.  
Model an air-like Boussinesq fluid with constant properties: nu = 1.5e-5 m^2/s, Pr = 0.71, alpha = nu/Pr, beta = 3.33e-3 1/K, T0 = 293.5 K, rho0 = 1.0 kg/m^3.  
Use a box domain with Lx = 0.1 m, Ly = 0.1 m, Lz = 0.1 m.  
Run the case as 2D by setting front and back patches to empty and using a 50×50×1 mesh.  
Use gravity g = (0 -9.81 0) m/s^2.  
Initialize U uniformly to (0 0 0).  
Initialize T uniformly to 293.5 K.

Apply no-slip adiabatic side walls with U = noSlip, T = zeroGradient, p_rgh = fixedFluxPressure.  
Apply fixed temperature boundaries with bottomHot T = fixedValue 294.0 K and topCold T = fixedValue 293.0 K.
