Create an OpenFOAM incompressible lid-driven cavity case using pisoFoam with a k-epsilon RANS turbulence model.
Use a square cavity domain with x in [0,1], y in [0,1], and z in [0,0.1].

Set the lid (top wall at y=1) to move with a uniform tangential velocity U = (1 0 0) m/s.
Set the other walls (bottom and side walls) to no-slip velocity U = (0 0 0).
Set the kinematic viscosity to a constant nu = 1e-05 m^2/s.
Use the incompressible RANS k-epsilon turbulence model with turbulence on.
Initialize velocity U to (0 0 0) everywhere at time 0.
Initialize pressure p (or p_rgh if used) to a uniform value consistent with incompressible pisoFoam (e.g., 0) at time 0.
Initialize k to 1.5e-4 uniformly in the domain.
Apply kqRWallFunction for k on all non-empty walls.

Apply epsilonWallFunction for epsilon on all non-empty walls.
Initialize nut to 0 uniformly in the domain.
Apply nutkWallFunction for nut on all non-empty walls.
Set startTime to 0.
Set endTime to 10.
Set deltaT to 0.005.
Write results every 100 time steps (writeInterval = 100 when writeControl is timeStep).

Set the convection discretization schemes to div(phi,k) Gauss limitedLinear 1.
Set the convection discretization schemes to div(phi,epsilon) Gauss limitedLinear 1.
Set the viscous term discretization to div((nuEff*dev2(T(grad(U))))) Gauss linear.
Keep all other discretization, linear solver, and relaxation settings consistent with a stable transient pisoFoam RANS run for Re = 1e5 unless explicitly overridden by the above requirements.
