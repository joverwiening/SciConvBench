Create an OpenFOAM case for a 2D lid-driven cavity with compressible turbulent flow using rhoPimpleFoam.
Use air as a perfect gas with hePsiThermo and Sutherland viscosity using pureMixture / sutherland / hConst / perfectGas / specie / sensibleEnthalpy.
Set the cavity geometry to a square 1 m × 1 m in the x–y plane with a thickness of 0.01 m in z.
Model the case as 2D by setting the front and back patches to type empty and using 1 cell in the z direction.
Generate a uniform structured mesh with 100 cells in x, 100 cells in y, and 1 cell in z.
Set the lid (top wall) to move at 100 m/s tangentially along the x direction.
Set the side walls and bottom wall to no-slip.
Set the initial fields uniformly to p = 101325 Pa and T = 300 K throughout the domain.
Use RANS turbulence with the kOmegaSST model configured in constant/momentumTransport.
Apply compressible wall functions for k and omega on solid walls.
Set thermal boundary conditions to isothermal walls with T fixedValue 300 K on the top lid, side walls, and bottom wall.
Use transient time integration with rhoPimpleFoam and PIMPLE coupling.
Enable adjustable time stepping with adjustTimeStep yes.
Set initial deltaT to 1e-6 s.
Limit the time step using maxCo = 0.7.
Run the simulation transiently until a statistically steady state is reached, and if an endTime is required but not specified, set endTime = 0.1 s as a default stopping time.
Write results at a reasonable interval for transient analysis, and if not specified, set writeControl to adjustableRunTime with writeInterval = 1e-3 s.
