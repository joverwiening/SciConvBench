Use OpenFOAM to model 2D Rayleigh–Bénard convection of an air-like Boussinesq fluid with gravity pointing in the negative y direction.
Use solver buoyantBoussinesqPimpleFoam with the Boussinesq approximation and constant properties in constant/physicalProperties.
Create a 2D rectangular domain of size 0.4 m (x) by 0.1 m (y) with front and back patches set to empty and a single cell in z.
Generate the mesh with blockMesh using 160 cells in x, 40 cells in y, and 1 cell in z.
Set gravity to g = (0 -9.81 0) m/s^2.
Set thermophysical/transport properties to nu = 1.5e-5 m^2/s, Pr = 0.71, alpha = nu/Pr = 2.11e-5 m^2/s, beta = 3.33e-3 1/K.
Set temperature boundary conditions: bottom wall (y=0) T fixedValue 305 K, top wall (y=0.1) T fixedValue 295 K.
Set side wall boundary conditions: U noSlip, T zeroGradient, p_rgh fixedFluxPressure.
Set bottom and top wall velocity boundary conditions to noSlip.
Set p_rgh boundary conditions on all solid walls to fixedFluxPressure.
Set initial fields: U uniform (0 0 0) everywhere, and initialize T uniformly to 300 K everywhere.
Use setFields to add a small temperature perturbation by setting T = 300.05 K in the boxToCell region from (0.19 0.00 -1) to (0.21 0.01 1).
Use adjustable time stepping with initial deltaT = 0.01 s, adjustTimeStep yes, and maxCo 0.7.
Run the transient simulation from startTime 0 to endTime 50 s.
Set a pressure reference for the Boussinesq formulation by constraining p_rgh at the top wall to fixedValue 0 Pa.
