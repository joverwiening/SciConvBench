Use OpenFOAM with the steady-state incompressible RANS solver simpleFoam.
Simulate fully developed turbulent channel flow in a 3D rectangular domain driven by a uniform streamwise forcing (meanVelocityForce) equivalent to a constant mean pressure gradient.
Set the domain size to Lx = 1.0 m, Ly = 0.1 m, Lz = 0.2 m, with y as the wall-normal direction and walls at y = 0 and y = 0.1 m (channel half-height H = 0.05 m).
Use cyclic (periodic) boundary conditions in the streamwise x direction.
Use cyclic (periodic) boundary conditions in the spanwise z direction.
Use no-slip walls on topWall and bottomWall.
Use the standard k-epsilon turbulence model with standard wall functions.
Set kinematic viscosity to nu = 1e-5 m^2/s.
Assume an incompressible Newtonian fluid with constant properties consistent with the specified nu.
Drive the flow using meanVelocityForce to achieve a target bulk (cross-section averaged) streamwise velocity Ub = 0.5 m/s.
Initialize the flow field with a uniform velocity in the x direction close to the target bulk velocity to aid convergence.
Set wall boundary conditions on topWall and bottomWall as follows: U = noSlip.
Set wall boundary conditions on topWall and bottomWall as follows: k = kqRWallFunction.
Set wall boundary conditions on topWall and bottomWall as follows: epsilon = epsilonWallFunction.
Set wall boundary conditions on topWall and bottomWall as follows: nut = nutkWallFunction.
Design the near-wall mesh for standard wall-function usage with target y+ in the range 30–100, aiming for approximately y+ ≈ 30.
Use a hexahedral-dominant mesh aligned with the flow, with refinement toward both walls to meet the y+ target.
Use steady-state SIMPLE algorithm settings appropriate for RANS, with under-relaxation factors chosen for stable convergence.
Run until residuals for U, p, k, and epsilon are reduced to typical steady-state tolerances and monitored integral quantities are steady.
Monitor and report the achieved bulk velocity, the required meanVelocityForce (equivalent pressure gradient), and the wall shear stress.
Post-process and report mean velocity profile U(y) across the channel height and compare qualitatively to expected turbulent channel behavior for a wall-function k-epsilon RANS solution.
