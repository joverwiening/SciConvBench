Use OpenFOAM interFoam to run a transient, laminar, incompressible, isothermal two-phase (air/water) VOF dam-break simulation with gravity.
Create a cubic domain from (0 0 0) to (1 1 1) in meters.
Discretize the domain with a uniform structured mesh of 32 x 32 x 32 cells.
Set gravity to g = (0 0 -9.81) m/s^2.
Include a rectangular obstacle (solid region) spanning from (0.375 0.375 0) to (0.625 0.625 0.25) meters.
Treat the obstacle surfaces as wall boundaries for the flow (no-slip for velocity).
Define the six outer boundary patches of the cube as follows.
Set the top face at z = 1 as an open atmosphere boundary patch.
Set the other five outer faces (x = 0, x = 1, y = 0, y = 1, z = 0) as no-slip wall boundary patches.
Initialize the volume fraction field so that alpha.water = 1 inside the rectangular prism from (0 0 0) to (0.6 0.1875 0.75) meters.
Initialize alpha.water = 0 everywhere outside that prism.
Run with a fixed time step deltaT = 1e-3 s.
Set endTime = 0.1 s.
Write results every 0.02 s (writeInterval = 0.02 s).
