Create an OpenFOAM case for a 2D Rayleigh–Bénard convection simulation using buoyantFoam.
Assume OpenFOAM v10 case-file syntax and dictionary locations as the target version.
Model a rectangular cavity of size 9 (x) by 1 (y) by 1 cell thick in z, with 2D enforced via empty front/back patches.
Generate a structured mesh with 90 cells in x, 10 cells in y, and 1 cell in z.
Name boundary patches bottom, top, left, right, front, back.
Set front and back patch types to empty in the mesh boundary and in all field boundary conditions.
Use gravity g = (0 -9.81 0) m/s^2 in constant/g.
Use buoyantFoam as the solver.
Use a Boussinesq buoyancy model via heRhoThermo with equationOfState Boussinesq in constant/physicalProperties.
Set molWeight 29 in constant/physicalProperties.
Set rho0 1.0 in constant/physicalProperties.
Set T0 300 in constant/physicalProperties.
Set beta 3.3e-3 in constant/physicalProperties.
Set Cv 714.3 in constant/physicalProperties.
Set Hf 0 in constant/physicalProperties.
Set mu 1.5e-5 in constant/physicalProperties.
Set Pr 0.714 in constant/physicalProperties.
Use RAS turbulence with kEpsilon, turbulence on, and printCoeffs on in constant/momentumTransport.
Do not configure any laminar simulationType anywhere.
Initialize U internalField to uniform (0 0 0).
Apply noSlip for U on bottom, top, left, and right.
Set U to empty on front and back.
Initialize T internalField to uniform 300.
Set T fixedValue 305 on bottom.
Set T fixedValue 295 on top.
Set T zeroGradient on left and right.
Set T empty on front and back.
Initialize k internalField to uniform 1e-5.
Set k to kqRWallFunction on bottom, top, left, and right.
Set k to empty on front and back.
Initialize epsilon internalField to uniform 1e-5.
Set epsilon to epsilonWallFunction on bottom, top, left, and right.
Set epsilon to empty on front and back.
Initialize nut internalField to uniform 0.
Set nut to nutkWallFunction on bottom, top, left, and right.
Set nut to empty on front and back.
Initialize alphat internalField to uniform 0.
Set alphat to compressible::alphatJayatillekeWallFunction on bottom, top, left, and right.
Set Prt 0.85 for the alphat wall function.
Set alphat to empty on front and back.
Initialize p internalField to uniform 0.
Set p to calculated on bottom, top, left, and right.
Set p to empty on front and back.
Initialize p_rgh internalField to uniform 0.
Set p_rgh to fixedFluxPressure on bottom, top, left, and right.
Set p_rgh to empty on front and back.
Run the simulation from startTime 0 to endTime 1000 seconds.
Use a fixed deltaT of 1 second.
Disable adjustTimeStep, maxCo, and maxDeltaT.
Write results using writeControl timeStep with writeInterval 50.
In system/fvSolution, set solvers for p_rgh and for (U|e|k|epsilon) to tolerance 1e-8 and relTol 0.01.
In system/fvSolution, set the corresponding Final solvers to relTol 0.
In system/fvSolution, set pRefValue 0.
In system/fvSolution, set pRefCell to a convenient internal cell near the domain center.
