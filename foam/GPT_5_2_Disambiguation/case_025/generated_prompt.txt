Use OpenFOAM Foundation v10 as the assumed version for best-practice compatibility with interFoam.
Create a transient, incompressible, isothermal, laminar two-phase VOF case using interFoam.
Set the computational domain to a cube from (0 0 0) to (1 1 1) in meters.
Generate a uniform hexahedral mesh with 32 x 32 x 32 cells.
Create a solid obstacle region occupying (0.375 0.375 0) to (0.625 0.625 0.25) meters and exclude it from the fluid region using a cellZone-to-baffle/porosity-free solid treatment via snappyHexMesh castellated refinement with the obstacle as a refinement surface and cell removal (i.e., the obstacle is an internal wall/solid, not a porous region).
Apply gravity g = (0 0 -9.81) m/s^2.
Define boundary patches so that the top face at z=1 is an open atmosphere patch.
Define the remaining five outer faces (x=0, x=1, y=0, y=1, z=0) as no-slip walls.
Treat the obstacle surfaces as no-slip walls.
Use two phases: water and air.
Set water properties to rho = 1000 kg/m^3 and nu = 1.0e-6 m^2/s.
Set air properties to rho = 1 kg/m^3 and nu = 1.48e-5 m^2/s.
Set surface tension sigma = 0.07 N/m for the water–air interface.
Use laminar flow with no turbulence model (turbulence off in turbulenceProperties).
Initialize alpha.water = 1 inside the rectangular prism from (0 0 0) to (0.6 0.1875 0.75) and alpha.water = 0 elsewhere.
Initialize velocity U = (0 0 0) everywhere.
Initialize pressure as p_rgh consistent with hydrostatics under gravity with the free surface implied by alpha.water, using a uniform reference of 0 at the atmosphere patch.
Set the top atmosphere patch boundary conditions to: p_rgh = totalPressure with p0 = 0, U = pressureInletOutletVelocity with inletValue (0 0 0), and alpha.water = inletOutlet with inletValue 0.
Set all wall patches (including obstacle walls) to: U = noSlip, p_rgh = fixedFluxPressure, and alpha.water = zeroGradient.
Use time step deltaT = 1e-3 s with adjustable time stepping disabled (fixed deltaT).
Run the simulation from startTime = 0 to endTime = 0.1 s.
Write results every 0.02 s (writeInterval = 0.02 with writeControl = runTime).
Use standard interFoam numerics suitable for dam-break VOF: Gauss linear for gradients, bounded Gauss upwind/linearUpwind for div(U), and a compressive interface scheme for div(phi,alpha) (e.g., Gauss vanLeer or interfaceCompression with cAlpha enabled).
Use PIMPLE (or PISO) settings appropriate for interFoam transient VOF with sufficient correctors to maintain stability at deltaT = 1e-3 s.
Ensure the case includes the required dictionaries: system/blockMeshDict (or snappyHexMeshDict if used for obstacle), system/controlDict, system/fvSchemes, system/fvSolution, constant/g, constant/transportProperties, constant/turbulenceProperties, and 0/alpha.water, 0/U, 0/p_rgh.
