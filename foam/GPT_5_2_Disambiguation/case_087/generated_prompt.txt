Set up a 2D inviscid compressible simulation of supersonic flow over a forward-facing step using OpenFOAM rhoCentralFoam.
Use ideal air with hePsiThermo, perfectGas, hConst.
Set Cp = 1005 J/kg/K.
Set molar mass = 28.9 kg/kmol (R derived by OpenFOAM from molar mass).
Model viscosity as inviscid by setting transportProperties to inviscid (mu = 0) and disable turbulence (simulationType laminar).
Use a rectangular channel domain of length 3.0 m and height 1.0 m.
Use a forward-facing step of height 0.2 m starting at x = 0.6 m on the bottom wall, reducing the downstream flow passage height to 0.8 m.
Use a 2D setup with spanwise depth 1.0 m and set front and back patches to empty.
Apply no-slip is not used; use slip walls for inviscid flow on all solid boundaries (top wall, bottom wall, and step faces) via slip or symmetry-type wall treatment consistent with rhoCentralFoam.
Set inlet boundary as supersonic inflow with fixed values corresponding to Mach 3 at static p = 101325 Pa and static T = 300 K.
Compute inlet velocity magnitude from Mach 3 using a = sqrt(gamma*R*T) with gamma derived from Cp and R, and set U accordingly in the streamwise direction.
Set inlet p = 101325 Pa and inlet T = 300 K as fixedValue.
Set outlet boundary as non-reflecting for pressure using waveTransmissive with pInf = 101325 Pa.
Set outlet U and T to zeroGradient (or waveTransmissive if implemented consistently), matching the stated preference.
Initialize the field with the inlet conditions throughout the domain.
Create a base mesh of approximately 150 cells in x over 3.0 m and 50 cells in y over 1.0 m.
Apply local refinement near the step corner and in regions expected to contain shocks immediately downstream of the step, using snappyHexMesh or topoSet/refineMesh to achieve finer cells in those zones.
Use rhoCentralFoam with a central-upwind scheme suitable for shocks.
Use spatial discretization schemes appropriate for shock-capturing (e.g., limited linear for gradients and a TVD/limited scheme for div(phi,U), div(phi,e), div(phi,K)).
Run as a transient simulation with time step controlled by a maximum Courant number maxCo = 0.5.
Set endTime = 0.01 s.
Use adjustableTimeStep yes and set an initial deltaT small enough to satisfy maxCo at startup (e.g., 1e-7 s).
Write results frequently enough to capture shock development (e.g., writeInterval corresponding to every 1e-4 s).
Monitor residuals and key probes (e.g., pressure at points upstream and downstream of the step) to confirm convergence to a quasi-steady shock structure.
Post-process Mach number, pressure contours, and density gradients to visualize shocks and expansion features around the forward-facing step.
