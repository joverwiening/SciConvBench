Use OpenFOAM incompressible RANS with simpleFoam to model steady turbulent flow through a 2D channel containing a zero-thickness porous screen that causes a pressure drop.
Create a 2D channel domain of length 1.0 m and height 0.1 m with a single cell in the out-of-plane direction (z), representing unit thickness.
Place the porous screen at x = 0.5 m from the inlet as an internal baffle created from the interface between two mesh blocks.
Generate a uniform hexahedral mesh of 100 x-cells by 20 y-cells by 1 z-cell using blockMesh with two blocks: block 1 spanning x = 0 to 0.5 m and block 2 spanning x = 0.5 to 1.0 m.
Convert the internal interface at x = 0.5 m into a faceZone named porousBaffleZone using topoSet.
Create a baffle patch named porousBaffle from the faceZone so the interface behaves as a zero-thickness porous screen.
Set the inlet boundary condition for velocity U to fixedValue uniform (5 0 0) m/s.
Set the outlet boundary condition for pressure p to fixedValue uniform 0.
Set the top and bottom wall boundary condition for U to noSlip.
Set the top and bottom wall boundary condition for p to zeroGradient.
Use the k-omega SST turbulence model with simulationType RAS and model kOmegaSST.
Apply standard wall functions for k, omega, and nut on the top and bottom walls.
Define the porous screen using a porous baffle pressure-drop boundary condition on patch porousBaffle with type porousBafflePressure.
Link the porous baffle to faceZone porousBaffleZone.
Use Darcy–Forchheimer pressure-drop coefficients on the porous baffle with Darcy coefficient D = 1e7 and inertial coefficient I = 0.
Run the case as steady-state incompressible turbulent flow using simpleFoam until residuals and monitored pressure drop across the baffle converge.
Post-process the pressure field to report the pressure drop across the porous screen by sampling p immediately upstream and downstream of x = 0.5 m along the channel centerline.
