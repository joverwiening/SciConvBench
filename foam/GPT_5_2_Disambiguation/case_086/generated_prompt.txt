Assume OpenFOAM Foundation v11 on Ubuntu 22.04 LTS.
Create a new case directory named sodShockTube_rhoCentralFoam using the standard OpenFOAM case structure: 0, constant, system.
Use solver rhoCentralFoam.
Model a 1D shock tube in a thin 3D mesh with x from 0 to 1.0 m, y from 0 to 0.01 m, and z from 0 to 0.01 m.
Generate the mesh with blockMesh using 400 cells in x and 1 cell in y and z (400 1 1).
Set the diaphragm (initial discontinuity) at x = 0.5 m, applying the left state for x < 0.5 and the right state for x ≥ 0.5.
Use a perfect-gas equation of state with gamma = 1.4 and molWeight = 28.9 g/mol.
Set the left state initial conditions for x < 0.5 m to p = 100000 Pa, T = 348.4 K, and U = (0 0 0) m/s.
Set the right state initial conditions for x ≥ 0.5 m to p = 10000 Pa, T = 278.7 K, and U = (0 0 0) m/s.
Do not hardcode rho in the initial conditions; compute it from p and T via the perfect-gas EOS.
Set boundary conditions to approximate 1D flow: use slip (or symmetry) on the y and z side patches, and use wall or symmetry-type conditions that do not inject disturbances.
Set the x-min and x-max boundaries as non-reflecting where available; otherwise use zeroGradient for p, T, and rho and zeroGradient for U to minimize reflections over the short run time.
Set startTime = 0 and endTime = 0.007 s.
Choose an adjustable time step with a target maxCo suitable for rhoCentralFoam (e.g., maxCo 0.2) to maintain stability.
Write results frequently enough to resolve wave motion (e.g., writeInterval corresponding to 50–200 time writes over 0.007 s).
Use a second-order spatial scheme appropriate for rhoCentralFoam (e.g., linearUpwind or limitedLinear for convective terms) and a stable flux scheme supported by the solver.
Run blockMesh, then run rhoCentralFoam.
Post-process by sampling along the centerline from x = 0 to 1 at y = 0.005, z = 0.005 to extract p, rho, T, and U versus x at selected times.
Validate qualitatively against the Sod shock tube structure (left rarefaction, contact discontinuity, right shock) at t = 0.007 s.
