Set up a laminar counter-flow diffusion flame case using the reactingFoam solver in a 2-D opposed-jet configuration.
Create a rectangular domain with x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Generate a structured mesh with 100 cells in x, 40 cells in y, and 1 cell in z.
Name the boundary at x=0 as fuel.
Name the boundary at x=0.02 as air.
Name the boundaries at y=-0.01 and y=0.01 as outlet.
Set the boundaries at z=-0.01 and z=0.01 as empty (frontAndBack).
Use laminar momentum transport.
Use a laminar combustion model.
Use compressible finite-rate chemistry.
Use the hePsiThermo thermophysical model.
Use coefficientWilkeMultiComponentMixture for mixing.
Use Sutherland transport.
Use JANAF thermodynamics.
Set the chemistry type to EulerImplicit.
Set the ODE solver to Rosenbrock43.
At the fuel inlet boundary, set a uniform velocity of +0.1 m/s in the +x direction.
At the fuel inlet boundary, set the inlet temperature to 293 K.
At the fuel inlet boundary, set the inlet composition to methane (CH4).
At the air inlet boundary, set a uniform velocity of -0.1 m/s in the x direction (into the domain from x=0.02).
At the air inlet boundary, set the inlet temperature to 293 K.
At the air inlet boundary, set the inlet composition to Y_O2 = 0.23 with the balance as N2.
Set the time step to 1e-4 s.
Set the end time to 0.5 s.
Write results every 0.05 s.
