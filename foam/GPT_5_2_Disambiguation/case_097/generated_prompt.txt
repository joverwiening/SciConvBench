Model 2D natural convection of air in a differentially heated square cavity using OpenFOAM buoyantPimpleFoam with a compressible perfect-gas formulation.
Use a square domain of size 1 m × 1 m with a single-cell thickness in the third direction (1 m × 1 m × 1 cell).
Generate a uniform structured mesh of 50 × 50 × 1 cells using blockMesh.
Set gravity to g (0 -9.81 0) m/s^2.
Set the left wall temperature to fixedValue 310 K.
Set the right wall temperature to fixedValue 290 K.
Set the top and bottom walls to adiabatic temperature boundary condition T zeroGradient.
Set all walls to no-slip velocity boundary condition U fixedValue uniform (0 0 0).
Set p_rgh boundary condition on top and bottom walls to fixedFluxPressure with value 0.
Use laminar flow with constant/turbulenceProperties set to simulationType laminar.
Use a compressible air model in constant/thermophysicalProperties with thermoType hePsiThermo, equationOfState perfectGas, and transport const.
Set air properties to molWeight 28.9, Cp 1005 J/kg/K, mu 1.8e-5 Pa·s, and Pr 0.71.
Initialize the flow field at t=0 with U uniform (0 0 0) and T uniform 300 K.
Initialize p_rgh at t=0 as uniform 0 as a best-practice default.
Run the simulation as a transient case until a steady or statistically steady natural-convection circulation is reached, using standard buoyantPimpleFoam time-step control and convergence monitoring.
