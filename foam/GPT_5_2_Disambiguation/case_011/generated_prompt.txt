Set up an incompressible lid-driven cavity case using the pisoFoam solver.
Use a 3D mesh with 20 cells in x, 20 cells in y, and 1 cell in z.
Set the domain size to Lx = 1 m, Ly = 1 m, Lz = 0.1 m.
Name the top boundary patch movingWall.
Apply a fixedValue velocity boundary condition on movingWall with U = (1 0 0) m/s.
Name the remaining side and bottom wall patches fixedWalls.
Apply a fixedValue velocity boundary condition on fixedWalls with U = (0 0 0) m/s.
Set the front and back patches to type empty for all fields to enforce 2D behavior.
Use kinematic viscosity nu as a constant value of 1e-05 m^2/s.
Run the transient simulation from time 0 s to endTime = 10 s.
Use a fixed time step deltaT = 0.005 s.
Apply pressure boundary condition p = zeroGradient on movingWall.
Apply pressure boundary condition p = zeroGradient on fixedWalls.
Apply empty type on p for the front and back patches.
In fvSchemes, set div(phi,U) to Gauss limitedLinearV 1.
In fvSchemes, set div(phi,k) to Gauss limitedLinear 1.
In fvSchemes, set div(phi,epsilon) to Gauss limitedLinear 1.
In fvSchemes, set div((nuEff*dev2(T(grad(U))))) to Gauss linear.
