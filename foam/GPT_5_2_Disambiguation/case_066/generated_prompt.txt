Set up a steady-state incompressible laminar porous-media flow simulation in OpenFOAM using the porousSimpleFoam solver.
Use a 2D rectangular channel domain of length 0.5 m in x and height 0.1 m in y with single-cell thickness in z.
Define a porous region as a rectangular zone spanning x = 0.2 m to x = 0.3 m across the full channel height.
Apply the Darcy–Forchheimer porous-medium model in the porous region using constant/fvOptions with type DarcyForchheimer.
Set the Darcy (viscous) resistance coefficient d to (1e8 1e8 1e10) with units 1/m^2.
Set the Forchheimer (inertial) resistance coefficient f to (0 0 0) with units 1/m.
Use water as the working fluid with incompressible properties.
Set inlet boundary at x = 0 m with U fixedValue uniform (1 0 0).
Set inlet boundary at x = 0 m with p zeroGradient.
Set outlet boundary at x = 0.5 m with p fixedValue uniform 0.
Set outlet boundary at x = 0.5 m with U zeroGradient.
Set top wall at y = 0.1 m with U noSlip.
Set bottom wall at y = 0 m with U noSlip.
Set pressure p on the top and bottom wall patches to zeroGradient.
