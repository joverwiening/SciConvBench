Assume a closed cavity with no fixed pressure boundary, and anchor pressure using a referenceCell/referenceValue in system/fvSolution for p_rgh (referenceValue 0).  
Target OpenFOAM Foundation distribution, version v11, on Ubuntu Linux.  
Create a 2D Rayleigh–Bénard convection case using buoyantFoam in a rectangular cavity 9 m wide (x) and 1 m tall (y), extruded 1 cell in z with front/back patches set to empty.  
Generate the mesh with blockMesh using a single hex block from (0 0 0) to (9 1 1) with 90 cells in x, 10 in y, and 1 in z.  
Define patches as bottom (y=0), top (y=1), left (x=0), right (x=9), front (z=0), back (z=1).  
Set front and back patch types to empty in constant/polyMesh/boundary via blockMeshDict.  
Use gravity g = (0 -9.81 0) in constant/g.  
Use transient simulation with buoyantFoam, deltaT 1 s, endTime 1000 s, and writeInterval 50 (steps) in system/controlDict.  
Initialize the flow at rest with uniform U = (0 0 0) and uniform T = 300 K.  
Use RAS kEpsilon turbulence modeling with simulationType RAS and turbulence on in constant/momentumTransport.  
Use heRhoThermo with equationOfState Boussinesq in constant/physicalProperties.  
Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714 in constant/physicalProperties consistent with buoyantFoam Boussinesq setup.  
Set bottom wall temperature to fixedValue 305 K in 0/T.  
Set top wall temperature to fixedValue 295 K in 0/T.  
Set left and right wall temperature to zeroGradient in 0/T.  
Set front/back temperature to empty in 0/T.  
Set no-slip velocity on bottom, top, left, and right walls in 0/U.  
Set front/back velocity to empty in 0/U.  
Set 0/p internalField uniform 0, wall patches to calculated, and front/back to empty.  
Set 0/p_rgh internalField uniform 0, wall patches to fixedFluxPressure, and front/back to empty.  
Set 0/k internalField uniform 1e-5, wall patches to kqRWallFunction, and front/back to empty.  
Set 0/epsilon internalField uniform 1e-5, wall patches to epsilonWallFunction, and front/back to empty.  
Set 0/nut internalField uniform 0, wall patches to nutkWallFunction, and front/back to empty.  
Set 0/alphat internalField uniform 0, wall patches to compressible::alphatJayatillekeWallFunction with Prt 0.85, and front/back to empty.  
In system/fvSolution, set linear solvers for p_rgh and for (U|e|k|epsilon) to tolerance 1e-8 and relTol 0.01, and set corresponding *Final solvers to relTol 0.  
In system/fvSolution, set PIMPLE/PISO settings appropriate for buoyantFoam transient operation, and include p_rgh referenceCell and referenceValue 0 to anchor pressure.  
Run blockMesh, then run buoyantFoam.
