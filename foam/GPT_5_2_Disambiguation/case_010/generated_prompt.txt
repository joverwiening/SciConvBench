Target Foundation OpenFOAM v11.
Create a 3D mesh representing an effectively 2D lid-driven cavity with dimensions Lx=1, Ly=1, Lz=0.1.

Name boundary patches as movingWall (top), fixedWalls (remaining side and bottom walls), and frontAndBack (front and back faces).
Set frontAndBack patch type to empty.
Use pisoFoam as the solver for an incompressible transient simulation.
Set kEpsilon as the RANS turbulence model and enable turbulence.
Set transportProperties nu to 1e-05 m^2/s (constant).
Initialize the domain velocity U to uniform (0 0 0).
Set movingWall velocity boundary condition for U to a fixedValue of (1 0 0).
Set fixedWalls velocity boundary condition for U to noSlip (fixedValue (0 0 0)).
Set frontAndBack velocity boundary condition for U to empty.
Use p as kinematic pressure.
Set p boundary condition on movingWall to zeroGradient.
Set p boundary condition on fixedWalls to zeroGradient.
Set p boundary condition on frontAndBack to empty.
Initialize k to uniform 1.5e-4 in the domain.
Set k boundary condition on movingWall to kqRWallFunction.
Set k boundary condition on fixedWalls to kqRWallFunction.
Set k boundary condition on frontAndBack to empty.
Initialize epsilon to uniform 1.4e-4 in the domain.
Set epsilon boundary condition on movingWall to epsilonWallFunction.
Set epsilon boundary condition on fixedWalls to epsilonWallFunction.
Set epsilon boundary condition on frontAndBack to empty.
Initialize nut to uniform 0 in the domain.
Set nut boundary condition on movingWall to nutkWallFunction.
Set nut boundary condition on fixedWalls to nutkWallFunction.
Set nut boundary condition on frontAndBack to empty.
Run the simulation from startTime 0 to endTime 10 seconds.
Use deltaT 0.005 seconds.
Write results every 0.5 seconds.

In fvSchemes, set div(phi,k) to Gauss limitedLinear 1.
In fvSchemes, set div(phi,epsilon) to Gauss limitedLinear 1.
In fvSchemes, set div((nuEff*dev2(T(grad(U))))) to Gauss linear.
In fvSchemes, set the pressure laplacian discretization to laplacian(1,p) Gauss linear corrected.

In fvSolution, use for U: solver smoothSolver, smoother symGaussSeidel, tolerance 1e-6, relTol 0.1.
In fvSolution, use for k: solver smoothSolver, smoother symGaussSeidel, tolerance 1e-6, relTol 0.1.
In fvSolution, use for epsilon: solver smoothSolver, smoother symGaussSeidel, tolerance 1e-6, relTol 0.1.
