Model 2D Rayleigh–Bénard convection in OpenFOAM using buoyantBoussinesqPimpleFoam with incompressible Navier–Stokes under the Boussinesq approximation coupled to a temperature advection–diffusion equation and buoyancy term g*beta*(T - Tref).
Use a rectangular domain 2 m wide in x and 1 m high in y (aspect ratio 2:1).
Use gravity g = 9.81 m/s^2 acting in the negative y-direction.
Use kinematic viscosity nu = 0.00928 m^2/s.
Use thermal diffusivity alpha = 0.01307 m^2/s (Pr = 0.71).
Use thermal expansion coefficient beta = 0.0034 1/K.
Target Rayleigh number Ra ≈ 2500 using H = 1 m and DeltaT = 1 K.
Set bottom wall patch name to bottomHot and top wall patch name to topCold.
Set side wall patch names to leftWall and rightWall.
Apply temperature boundary condition on bottomHot as fixedValue with uniform T = 300 K.
Apply temperature boundary condition on topCold as fixedValue with uniform T = 299 K.
Apply velocity boundary condition on bottomHot as noSlip.
Apply velocity boundary condition on topCold as noSlip.
Apply velocity boundary condition on leftWall as cyclic.
Apply velocity boundary condition on rightWall as cyclic.
Apply pressure field p_rgh boundary condition on leftWall as cyclic.
Apply pressure field p_rgh boundary condition on rightWall as cyclic.
Apply pressure field p_rgh boundary condition on bottomHot as fixedFluxPressure.
