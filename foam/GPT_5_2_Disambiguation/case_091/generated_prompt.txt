Simulate 2D natural convection of air in a closed square cavity using OpenFOAM buoyantPimpleFoam.
Use a cavity of width 0.1 m in x and height 0.1 m in y.
Use a 2D setup by using a single cell in z and applying empty boundary conditions on the front and back planes.
Set gravity to g (0 -9.81 0) m/s^2.
Use laminar flow with simulationType laminar in constant/momentumTransport.
Use air thermophysics with hePsiThermo, pureMixture, sutherland transport, janaf thermo, and perfectGas equation of state.
Set molWeight to 28.9 kg/kmol in constant/thermophysicalProperties.
Use operating/reference pressure pRef = 100000 Pa.
Apply no-slip velocity on all four cavity walls with U fixedValue uniform (0 0 0).
Set the left wall temperature to fixedValue uniform 313.15 K.
Set the right wall temperature to fixedValue uniform 293.15 K.
Set the top wall temperature boundary condition to zeroGradient (adiabatic).
Set the bottom wall temperature boundary condition to zeroGradient (adiabatic).
Initialize the internal temperature field uniformly to 303.15 K.
Initialize the internal velocity field to uniform (0 0 0).
Use buoyantPimpleFoam as the solver for the transient buoyant flow.
