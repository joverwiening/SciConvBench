Create an OpenFOAM case for a 2D lid-driven cavity using pisoFoam with the k-epsilon turbulence model.
Use a square cavity domain with x in [0,1], y in [0,1], and z thickness 0.1.
Make the case effectively 2D by setting the front and back patches to type empty.
Run the simulation from time 0 to 10.
Use a time step deltaT of 0.005.
Write results every 100 time steps.
Set the kinematic viscosity nu as a constant 1e-05 m^2/s.
Enable RANS turbulence with the k-epsilon model.
Initialize k uniformly to 1.5e-4 in the domain.
Initialize epsilon uniformly to 1.4e-4 in the domain.
Initialize nut uniformly to 0 in the domain.
Set U boundary conditions as follows: movingWall (top) fixedValue uniform (1 0 0); fixedWalls (bottom, left, right) noSlip.
Set p boundary conditions as follows: movingWall (top) zeroGradient; fixedWalls (bottom, left, right) zeroGradient; front/back empty.
Set k boundary conditions as follows: all walls use kqRWallFunction; front/back use empty.
Set epsilon boundary conditions as follows: all walls use epsilonWallFunction; front/back use empty.
Set nut boundary conditions as follows: all walls use nutkWallFunction; front/back use empty.
Set convection schemes as follows: div(phi,U) Gauss limitedLinearV 1; div(phi,k) Gauss limitedLinear 1; div(phi,epsilon) Gauss limitedLinear 1.
Set the viscous term scheme as follows: div((nuEff*dev2(T(grad(U))))) Gauss linear.
