Use Foundation OpenFOAM v11 case structure and dictionary syntax.

Model a 1 m x 1 m square domain in the x-y plane.

Make the case 2D by extruding one cell in the z-direction with thickness 1 m and setting the front and back patches to type empty.

Create a structured mesh with 40 cells in x, 40 cells in y, and 1 cell in z.

Use blockMesh to generate the mesh.

Define patches as follows: topWall (moving wall), fixedWalls (left, right, bottom), frontAndBack (front and back).

Run an incompressible, transient, laminar simulation using pimpleFoam.

Set kinematic viscosity nu to 1e-4 m^2/s in constant/transportProperties.

Set initial velocity U to uniform (0 0 0) in 0/U.

Set initial kinematic pressure p to uniform 0 in 0/p.

Apply boundary conditions for U: topWall uses movingWallVelocity with value uniform (1 0 0); fixedWalls use noSlip; frontAndBack use empty.

Apply boundary conditions for p: topWall uses zeroGradient; fixedWalls use zeroGradient; frontAndBack use empty.

Set system/controlDict to start from startTime 0 and end at endTime 5.

Enable adjustable time stepping with adjustTimeStep yes, maxCo 1.0, and maxDeltaT 0.05.

Set an initial deltaT of 0.01 s.

Write results every 0.1 s using writeControl timeStep with writeInterval chosen to match 0.1 s based on the current deltaT, or use writeControl adjustableRunTime with writeInterval 0.1.

Use PIMPLE settings in system/fvSolution with nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 0.

Use linear solvers in system/fvSolution: for p use GAMG with tolerance 1e-7 and relTol 0.01; for U use smoothSolver with tolerance 1e-8 and relTol 0.1.

Use PIMPLE relaxation factors: fields p 0.3; equations U 0.7.

Use system/fvSchemes with second-order schemes: ddtSchemes backward; gradSchemes Gauss linear; divSchemes div(phi,U) Gauss linear; laplacianSchemes Gauss linear corrected; interpolationSchemes linear; snGradSchemes corrected.

Set pressure reference in fvSolution using pRefCell 0 and pRefValue 0.

Run the case with blockMesh then pimpleFoam.

Ensure the case runs without turbulence model files beyond turbulenceProperties set to simulationType laminar.
