Set up an OpenFOAM transient URANS simulation of incompressible flow over a circular cylinder in water to observe vortex shedding.  
Use pimpleFoam as the solver.  
Use the k-omega SST RAS turbulence model in URANS mode.  
Use water kinematic viscosity nu = 1e-6 m^2/s.  
Use cylinder diameter D = 1 m.  
Set the target Reynolds number to Re = 3900 based on Re = U·D/nu.  
Set inlet bulk velocity to U = (3.9 0 0) m/s.  

Create a 2D (effectively infinite) cylinder case by extruding a 2D mesh to a thickness of 0.1D with one cell in the z direction.  
Set the front and back patches to type empty for all fields.  
Place the cylinder center at (0, 0).  

Use a rectangular domain with x in [-10, 30] m and y in [-10, 10] m.  
Generate a C-grid mesh around the cylinder with approximately 40,000 cells total.  
Refine the mesh near the cylinder surface and in the wake region downstream of the cylinder.  
Use wall-function-appropriate near-wall resolution targeting y+ in the range 30 to 100 on the cylinder surface.  
Choose a reasonable first-layer height and number of prism layers to achieve the y+ target and smooth growth away from the wall.  

Apply inlet boundary conditions as follows.  
Set U to fixedValue (3.9 0 0) m/s at the inlet.  
Set p to zeroGradient at the inlet.  
Set k to fixedValue 5.7e-3 at the inlet.  
Set omega to fixedValue 3.6 at the inlet.  

Apply outlet boundary conditions as follows.  
Set U to zeroGradient at the outlet.  
Set p to fixedValue 0 at the outlet.  
Set k to zeroGradient at the outlet.  
Set omega to zeroGradient at the outlet.  

Apply cylinder wall boundary conditions as follows.  
Set U to noSlip on the cylinder.  
Set p to zeroGradient on the cylinder.  
Set k to kqRWallFunction on the cylinder.  
Set omega to omegaWallFunction on the cylinder.  

Apply lateral boundary conditions on the top and bottom boundaries as symmetry for all fields.  
Set U to symmetry on topAndBottom.  
Set p to symmetry on topAndBottom.  
Set k to symmetry on topAndBottom.  
Set omega to symmetry on topAndBottom.  

Run the transient simulation from t = 0 s to t = 100 s.  
Use an adjustable time step controlled by a maximum Courant number.  
Set maxCo = 0.5 and maxDeltaT = 0.01 s.  
Write results at a fixed physical interval of 0.1 s.  

Initialize the domain with uniform U = (3.9 0 0) m/s and p = 0 Pa, and initialize k and omega consistent with the inlet values.  
Monitor and record force coefficients (Cd and Cl) on the cylinder versus time.  
Compute and report the vortex shedding frequency and Strouhal number from the lift coefficient time history after initial transients.  
Visualize vortex shedding using vorticity magnitude and velocity contours in the wake.
