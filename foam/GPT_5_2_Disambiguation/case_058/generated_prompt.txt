Place the outlet at x = 2.2 m.

Define downstream length as 2.0 m (20D) from cylinder center to outlet.
Define cross-stream height as 0.41 m (4.1D).

Set cylinderWall boundary condition for U to noSlip (equivalently fixedValue uniform (0 0 0)).

Run the case with pimpleFoam using appropriate time step control to maintain numerical stability (e.g., by limiting Courant number).
