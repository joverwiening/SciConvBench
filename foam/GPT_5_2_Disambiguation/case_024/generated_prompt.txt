Simulate an incompressible laminar 2D flow past a circular cylinder using a 3D domain with z-thickness and no z-variation in the setup.
Use a rectangular domain with x from -5 m to 5 m, y from -1.5 m to 2.5 m, and z from -1 m to 1 m.
Place a circular cylinder of diameter 2 m centered at (x, y) = (0 m, 0 m) and spanning the full z extent.
Use startTime = 0 s.
Use endTime = 0.5 s.
Use deltaT = 0.0025 s.
Write results every 0.05 s.
Initialize the velocity field as U = (0 0 0).
Initialize the pressure field as p = 0.
Apply a uniform inlet velocity at x = -5 m with U = (1 0 0) m/s.
At the outlet boundary x = 5 m, set pressure p to fixedValue 0.
At the outlet boundary x = 5 m, set velocity U to zeroGradient.
On the cylinder surface, set velocity U to fixedValue (0 0 0) (no-slip).
On the cylinder surface, set pressure p to zeroGradient.
On the top boundary y = 2.5 m, set velocity U to fixedValue (0 0 0) (no-slip wall).
On the bottom boundary y = -1.5 m, set velocity U to fixedValue (0 0 0) (no-slip wall).
Model viscosity using the generalisedNewtonian laminar model with the CrossPowerLaw viscosity model.
Set CrossPowerLaw parameters to nuInf = 10, m = 0.4, n = 3.
Do not use a constant-ν Newtonian viscosity model.
Use an incompressible laminar flow model with no turbulence model.
