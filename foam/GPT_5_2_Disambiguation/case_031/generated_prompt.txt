Target OpenFOAM Foundation v10 (or later) and use buoyantBoussinesqSimpleFoam.

Create a 2D rectangular cavity domain of size 1.0 m in x by 0.25 m in y with out-of-plane thickness 0.01 m in z.

Generate the mesh with blockMesh using a single block and set the front and back patches to type empty.

Name patches as bottomHot (y=0), topCold (y=0.25), sideWalls (x=0 and x=1), and frontAndBack (z=0 and z=0.01).

Set gravity in constant/g to g (0 -9.81 0) m/s^2.

Use laminar flow (no RAS and no LES) in constant/turbulenceProperties.

Use the Boussinesq model with constant properties in constant/physicalProperties with nu 1e-6 m^2/s, Pr 7.0, beta 2.0e-4 1/K, T0 300 K, rho0 1000 kg/m^3.

Set initial fields in 0/U, 0/T, and 0/p_rgh with internalField uniform (0 0 0), uniform 300, and uniform 0 respectively.

Apply boundary conditions for U: noSlip on bottomHot, topCold, and sideWalls; empty on frontAndBack.

Apply boundary conditions for T: fixedValue 310 K on bottomHot; fixedValue 290 K on topCold; zeroGradient on sideWalls; empty on frontAndBack.

Apply boundary conditions for p_rgh: fixedFluxPressure on bottomHot, topCold, and sideWalls; empty on frontAndBack.

Configure system/controlDict for a steady-state SIMPLE run using buoyantBoussinesqSimpleFoam and write fields at a reasonable interval until convergence.

Configure system/fvSchemes with second-order schemes where stable (e.g., linear for gradients, limited linear for div terms) suitable for steady buoyant flow.

Configure system/fvSolution with SIMPLE settings, appropriate relaxation factors, and solvers for U, T, and p_rgh to achieve steady convergence.

Use convergence criteria based on residual reduction and stable integral quantities (e.g., heat flux through bottomHot and topCold) to declare the solution converged.

Post-process to report temperature and velocity fields and compute heat transfer (wall heat flux) at bottomHot and topCold.
