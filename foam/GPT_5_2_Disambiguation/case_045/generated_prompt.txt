Set the domain extents to x ∈ [0, 1], y ∈ [0, 1], z ∈ [0, 0.01].

Run laminar (no turbulence) by setting simulationType laminar in constant/turbulenceProperties.
Initialize fields at time 0 with U uniform (0 0 0), T uniform 295, and p_rgh uniform 0.
Apply a temperature perturbation using setFields: set T to 295.1 in the box from (0.45 0.00 -1) to (0.55 0.05 1).
Set boundary conditions for U: bottomWall fixedValue (0 0 0), topWall fixedValue (0 0 0), sideWalls noSlip, frontAndBack empty.
Set boundary conditions for T: bottomWall fixedValue 300, topWall fixedValue 290, sideWalls zeroGradient, frontAndBack empty.
Set boundary conditions for p_rgh: bottomWall fixedFluxPressure, topWall fixedFluxPressure, sideWalls fixedFluxPressure, frontAndBack empty.

Configure system/fvSchemes with second-order spatial schemes suitable for buoyant transient flow (e.g., Gauss linear for gradients, Gauss linearUpwind for div(phi,U), Gauss upwind or linearUpwind for div(phi,T), and Gauss linear for laplacians).
Configure system/fvSolution with a PIMPLE setup appropriate for buoyantBoussinesqPimpleFoam, including solvers for p_rgh, U, and T, and set nCorrectors and nNonOrthogonalCorrectors appropriate for an orthogonal mesh (e.g., nNonOrthogonalCorrectors 0).
Generate the mesh with blockMesh.
Apply initial perturbation with setFields.
