Set up the OpenFOAM pitzDaily backward-facing step case using the standard tutorial structure and files.
Target OpenFOAM Foundation v11 as the assumed platform.
Use the steady-state incompressible solver simpleFoam.
Use RAS turbulence modeling with kEpsilon.
Enable turbulence in constant/turbulenceProperties and set RASModel to kEpsilon.
Use the tutorial’s default mesh definition by running blockMesh with the provided system/blockMeshDict unchanged.
Set the inlet velocity boundary condition in 0/U to fixedValue uniform (10 0 0) at the inlet patch.
Set the kinematic viscosity in constant/transportProperties to nu [0 2 -1 0 0 0 0] 1e-5.
Use standard incompressible SIMPLE settings consistent with the pitzDaily tutorial for fvSchemes and fvSolution unless otherwise required for stability.
Set the outlet pressure boundary condition in 0/p to fixedValue uniform 0 at the outlet patch.
Use zeroGradient for velocity at the outlet patch.
Use noSlip for velocity at wall patches.
Use wall functions appropriate for kEpsilon at walls: kqRWallFunction for k and epsilonWallFunction for epsilon, with nut using nutkWallFunction.
Set controlDict to run until convergence with an endTime of 1000 and a writeInterval of 100.
Define convergence as residuals for U, p, k, and epsilon dropping at least three orders of magnitude and key monitored quantities (e.g., pressure drop between inlet and outlet and/or forces on the step wall) reaching a steady plateau.
Run the case in this order: blockMesh, then simpleFoam.
Post-process using the tutorial’s standard approach (e.g., paraFoam) to visualize velocity, pressure, and recirculation region downstream of the step.
