Use OpenFOAM reactingFoam to simulate a laminar counter-flow diffusion flame in a 2-D opposed-jet configuration.
Create a rectangular domain with x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Generate a structured mesh with 100 cells in x, 40 cells in y, and 1 cell in z.
Name the boundary patch at x=0 as fuel.
Name the boundary patch at x=0.02 as air.
Name the boundary patches at y=-0.01 and y=0.01 as outlet.
Set the front and back patches (z=-0.01 and z=0.01) to empty to enforce 2-D.
Initialize the entire domain at time 0 with temperature T = 2000 K.
Set the fuel boundary velocity to +0.1 m/s in the x-direction.
Set the air boundary velocity to -0.1 m/s in the x-direction.
Impose fuel composition at the fuel patch as pure methane with mass fraction Y_CH4 = 1.0 and all other species mass fractions 0.
Impose oxidizer composition at the air patch as air with mass fractions Y_O2 = 0.23 and Y_N2 = 0.77 and all other species mass fractions 0.
Use operating pressure p = 101325 Pa (1 atm).
Use laminar momentum transport.
Use a laminar combustion model with compressible finite-rate chemistry.
Use hePsiThermo thermodynamics.
Use coefficientWilkeMultiComponentMixture for mixing rules.
Use Sutherland transport.
Use JANAF thermodynamics.
Set chemistryType to EulerImplicit.
Set the ODE solver to Rosenbrock43.
Run with a fixed timestep of 1e-4 s.
Set endTime to 0.5 s.
Write results at intervals of 0.05 s.
