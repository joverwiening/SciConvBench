Use OpenFOAM Foundation v10 as the assumed version for best-practice compatibility with interFoam tutorials and boundary condition syntax.
Create a transient, incompressible, laminar, two-phase VOF dam-break simulation using interFoam.
Use a 3D Cartesian domain from (0 0 0) to (1 1 1) in meters.
Generate a uniform base mesh of 32×32×32 hexahedral cells over the full domain using blockMesh.
Represent one internal obstacle as an axis-aligned rectangular block from (0.375 0.375 0) to (0.625 0.625 0.25) meters and include it as wall boundary faces in the mesh.
Define boundary patches so that the top face at z=1 is a single patch named atmosphere.
Define the remaining five outer faces (x=0, x=1, y=0, y=1, z=0) as wall patches.
Treat all obstacle faces as wall patches.
Model phases as water and air using VOF with alpha.water as the volume fraction field.
Set water properties to rho=1000 kg/m^3 and kinematic viscosity nu=1.0e-6 m^2/s.
Set air properties to rho=1 kg/m^3 and kinematic viscosity nu=1.48e-5 m^2/s.
Set surface tension sigma=0.07 N/m.
Set gravity to g=(0 0 -9.81) m/s^2.
Initialize alpha.water to 1 inside the rectangular prism from (0 0 0) to (0.6 0.1875 0.75) and 0 elsewhere.
Initialize velocity U uniformly to (0 0 0) m/s at t=0.
Run the simulation from startTime=0 to endTime=0.1 s.
Use a fixed time step deltaT=1e-3 s.
Set the top atmosphere boundary condition for p_rgh to totalPressure with p0=uniform 0, U=U, phi=phi, rho=rho, psi=none, gamma=1.
Set p_rgh on all wall patches (all five outer walls plus obstacle walls) to fixedFluxPressure.
Set the top atmosphere boundary condition for U to pressureInletOutletVelocity with value uniform (0 0 0).
Set U on all wall patches (all five outer walls plus obstacle walls) to noSlip.
Set the top atmosphere boundary condition for alpha.water to inletOutlet with inletValue uniform 0 and value uniform 0.
Set alpha.water on all wall patches (all five outer walls plus obstacle walls) to zeroGradient.
Use laminar transport and disable turbulence modeling (RASModel=laminar).
Write fields at a reasonable interval such as writeInterval=0.01 s.
