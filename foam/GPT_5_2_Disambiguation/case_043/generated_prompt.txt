Use a 2D closed-room natural convection case in OpenFOAM using buoyantPimpleFoam.
Model a rectangular domain 4.0 m wide (x) by 3.0 m high (y).
Treat the case as 2D by setting the front and back patches to type empty.
Assume an out-of-plane thickness of 1.0 m for any extensive quantities, while still using empty front/back.
Create the mesh with blockMesh using 80 cells in x and 60 cells in y.
Apply non-uniform mesh grading with refinement near the floor, the side walls, and around the heater region.
Use a three-block decomposition in x to refine around the centered heater strip.
Set x-direction blocks as: left block 0.0–1.5 m with 25 cells, middle block 1.5–2.5 m with 30 cells, right block 2.5–4.0 m with 25 cells.
Use simpleGrading in x to cluster cells toward the heater edges by applying grading 2.0 in the left block (toward x=1.5), grading 1.0 in the middle block, and grading 2.0 in the right block (toward x=2.5).
Use a two-block decomposition in y to refine near the floor.
Set y-direction blocks as: bottom block 0.0–0.5 m with 20 cells, top block 0.5–3.0 m with 40 cells.
Use simpleGrading in y to cluster cells toward the floor by applying grading 4.0 in the bottom block (toward y=0) and grading 1.5 in the top block (toward y=0.5).
Define boundary patches: floorHeater, floorInsulated, leftWall, rightWall, ceiling, front, back.
Define floorHeater as a 1.0 m wide strip centered on the floor spanning x=1.5–2.5 m at y=0.
Define floorInsulated as the remaining floor area spanning x=0.0–1.5 m and x=2.5–4.0 m at y=0.
Set leftWall at x=0.0, rightWall at x=4.0, and ceiling at y=3.0.
Set front and back patches to empty.
Use air as the working fluid with full compressible thermodynamics.
Use thermoType with hePsiThermo, perfectGas equationOfState, sutherland transport, and sensibleEnthalpy energy.
Set operating/initial pressure to 101325 Pa.
Initialize fields at time 0 with uniform U = (0 0 0), T = 293 K, and p = 101325 Pa.
Use laminar flow by setting simulationType laminar in turbulenceProperties.
Run buoyantPimpleFoam transiently to endTime 120 s.
Use noSlip velocity on all solid walls: floorHeater, floorInsulated, leftWall, rightWall, ceiling.
Set temperature boundary conditions as: floorHeater T fixedValue 323 K; all other walls T zeroGradient.
Set p_rgh boundary conditions as fixedFluxPressure on all solid walls.
Set front and back boundary conditions for U, T, and p_rgh to empty.
Use a closed room with no inlet or outlet boundaries.
Choose a time step controlled by maxCo to maintain stability, with adjustable time stepping enabled.
Write results at a regular interval suitable for transient visualization (e.g., every 1 s).
Include function objects to compute and write min/max of T and U, and optionally wall heat flux on floorHeater for monitoring.
