Assume OpenFOAM v8 (or an equivalent “classic” OpenFOAM release where reactingFoam uses the standard thermophysical/chemistry dictionaries and boundary condition names as in v7–v9).
Create a 2D reactingFoam case for a premixed methane–air flame in a straight channel.
Use a rectangular channel domain of length 0.1 m in x and height 0.02 m in y.
Use a single cell in z with front and back patches set to empty to enforce 2D.
Define patches named inlet, outlet, walls, front, and back.
Set the flow regime to laminar.
In constant/turbulenceProperties set simulationType laminar.
Use reactingFoam with finite-rate chemistry enabled.
Use a one-step irreversible global methane mechanism: CH4 + 2 O2 -> CO2 + 2 H2O.
In constant/combustionProperties set the reaction identifier to methaneAir.
Use Arrhenius kinetics with A = 2.119e11, beta = 0, Ta = 2.027e8 for the global reaction.
Use janaf thermodynamics for species properties.
Include species CH4, O2, N2, CO2, and H2O in the thermophysical/chemistry setup.
Set inlet mixture to stoichiometric premixed methane–air using the provided mass fractions: Y_CH4 = 0.055, Y_O2 = 0.22, Y_N2 = 0.725.
Set inlet temperature to 300 K.
Set inlet velocity to a uniform U = (0.5 0 0) m/s.
Set walls to noSlip for velocity.
Set walls to adiabatic for temperature using a zeroGradient temperature boundary condition.
Set outlet pressure using totalPressure with p0 = 101325 Pa.
Set outlet velocity U to zeroGradient.
Set outlet temperature T to zeroGradient.
Set species mass fraction boundary conditions at inlet to fixedValue using the specified inlet mass fractions for CH4, O2, and N2, and set CO2 and H2O to fixedValue 0 at the inlet.
Set species mass fraction boundary conditions at outlet to zeroGradient for all species.
Set species mass fraction boundary conditions at walls to zeroGradient for all species.
Set front and back patches to empty for all fields (U, p, T, and all species).
Use a mesh resolution suitable for a laminar flame in a 0.02 m channel height, with refinement in y to resolve the flame thickness, and ensure near-wall resolution is adequate for laminar boundary layers.
Use a transient time step controlled to keep stable chemistry integration and maintain a reasonable maximum Courant number (e.g., maxCo ≤ 0.5).
Run until a statistically steady flame position/structure is obtained or until a specified physical time sufficient for the flame to establish in the channel.
