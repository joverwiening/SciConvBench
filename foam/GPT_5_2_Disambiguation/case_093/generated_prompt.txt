Set up a 2D turbulent buoyant plume simulation in OpenFOAM using buoyantPimpleFoam.
Use a rectangular domain 2 m wide (x) by 4 m high (y).
Make the case 2D by using front and back patches of type empty.
Create boundary patches named atmosphere (top), sideWalls (left and right), heatSource (central 0.2 m of the bottom), floorSides (remaining bottom), front, and back.
Place the heatSource patch centered on the bottom boundary spanning x = 0.9 m to x = 1.1 m.
Use buoyantPimpleFoam with gravity acting downward in y (e.g., g = (0 -9.81 0)).
Use a RANS kEpsilon turbulence model by setting simulationType RAS and RASModel kEpsilon in constant/momentumTransport.
Set the bottom boundary velocity to noSlip on both heatSource and floorSides.
Set the sideWalls velocity boundary condition to slip.
Set the atmosphere velocity boundary condition to pressureInletOutletVelocity with value uniform (0 0 0).
Set the atmosphere pressure boundary condition for p_rgh to totalPressure with value uniform 0.
Set the atmosphere temperature boundary condition to inletOutlet with inletValue uniform 300 and value uniform 300.
Set the heatSource temperature boundary condition to fixedValue with value uniform 400.
Set the floorSides temperature boundary condition to zeroGradient.
Set the sideWalls temperature boundary condition to zeroGradient.
Set front and back boundary conditions to empty for all fields.
Initialize the domain temperature to 300 K and velocity to (0 0 0).
Run the simulation as transient with buoyantPimpleFoam until a statistically steady plume is established.
Output fields including U, p_rgh, T, k, and epsilon for post-processing of plume rise and turbulence quantities.
