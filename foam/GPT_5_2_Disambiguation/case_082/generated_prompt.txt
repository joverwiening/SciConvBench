Set up an OpenFOAM reactingFoam case for a counter-flow diffusion flame in a 2D axisymmetric cylindrical domain with the axis along the y-axis.
Use a domain of radius R = 0.02 m (x from 0 to 0.02 m) and height H = 0.02 m (y from 0 to 0.02 m).
Create boundary patches named fuelInlet at y = 0.02 m, oxidizerInlet at y = 0 m, outlet at x = 0.02 m, and axis at x = 0.
Model each nozzle as a circular inlet region centered on the axis with diameter D = 0.01 m (10 mm) on both the top (fuelInlet) and bottom (oxidizerInlet) boundaries.
Treat the remaining area of the top and bottom boundaries outside the circular nozzle regions as open/outlet boundaries that allow entrainment and pressure adjustment consistent with the overall pressure treatment.
Generate the mesh with blockMesh using 40 cells in the radial direction and 40 cells in the axial direction.
Apply mesh grading toward the center plane y = 0.01 m to better resolve the expected flame location.
Use reactingFoam with a detailed chemistry mechanism.
Use GRI-Mech 3.0 as the chemical mechanism, sourced from standard Chemkin files (chem.inp, therm.dat) converted with chemkinToFoam.
Place the converted chemistry and thermodynamics files in the constant/ directory in the format required by reactingFoam.
Set the fuel inlet composition on the fuelInlet nozzle region to pure methane with mass fraction Y.CH4 = 1.0 and all other species mass fractions equal to 0.
Set the oxidizer inlet composition on the oxidizerInlet nozzle region to air with mass fractions Y.O2 = 0.233 and Y.N2 = 0.767 and all other species mass fractions equal to 0.
Set the fuelInlet nozzle velocity boundary condition to uniform U = (0 -0.5 0) m/s.
Set the oxidizerInlet nozzle velocity boundary condition to uniform U = (0 0.5 0) m/s.
Set the temperature boundary condition on both inlet nozzle regions to T = 300 K.
Do not prescribe static pressure at the inlet nozzle regions and handle pressure through the domain pressure setup.
Set the outlet pressure treatment using totalPressure with p0 = 101325 Pa.
Apply an axisymmetric boundary condition on the axis patch at x = 0.
Run the case as a counter-flow diffusion flame with opposing methane and air streams meeting near y = 0.01 m.
