Set up a buoyant thermal plume CFD case in OpenFOAM using buoyantPimpleFoam with RANS kOmegaSST specified in constant/momentumTransport.
Use a 2D domain represented as a thin 3D slab with empty front/back patches.
Set the domain size to 2.0 m in x, 2.0 m in y, and 0.01 m in z.
Align gravity to act in the negative y direction.
Create boundary patches named hotSource, coolFloor, sideWalls, outlet, front, and back.
Define the floor at y=0 as two patches: hotSource and coolFloor.
Define hotSource as the floor segment with x in [0.9, 1.1] m spanning the full z thickness.
Define coolFloor as the remainder of the floor at y=0 excluding hotSource.
Define sideWalls to include the vertical walls at x=0, x=2, and y=2 excluding the top opening.
Define outlet as the top boundary at y=2 over the full x extent and full z thickness.
Set front and back patches (z-normal faces) to type empty for all fields.
Set U on hotSource to noSlip.
Set U on coolFloor to noSlip.
Set U on sideWalls to noSlip.
Set U on outlet to pressureInletOutletVelocity with inletValue (0 0 0).
Set p_rgh on hotSource to fixedFluxPressure.
Set p_rgh on coolFloor to fixedFluxPressure.
Set p_rgh on sideWalls to fixedFluxPressure.
Set p_rgh on outlet to totalPressure with p0 uniform 0 (gauge).
Set T on hotSource to fixedValue uniform 400.
Set T on coolFloor to fixedValue uniform 300.
Set T on outlet to inletOutlet with inletValue uniform 300 and value uniform 300.
Set T on sideWalls to a wall temperature boundary condition consistent with solid walls and the ambient reference of 300 K.
Initialize the internal field temperature to 300 K.
Run the simulation transiently with buoyantPimpleFoam using PIMPLE settings appropriate for buoyant, turbulent flow.
Use kOmegaSST wall functions and near-wall treatment consistent with the chosen mesh resolution.
Ensure the case produces a turbulent buoyant plume rising from the hotSource strip into the open outlet at the top.
