The simulation models incompressible lid-driven cavity flow using pisoFoam solver with the following specifications:

The computational domain is a square cavity with dimensions 1 unit in x and y directions and 0.1 units in z-direction, discretized with a 20x20x1 grid.

The fluid kinematic viscosity is 1e-05 m^2/s.

The top wall (lid) moves at 1 m/s in the x-direction while all other walls are stationary with no-slip conditions.

The simulation runs from time 0 to 10 seconds with a fixed time step of 0.005 seconds, writing results every 100 time steps (every 0.5 seconds of simulation time).

The k-epsilon turbulence model is employed with the following initial and boundary conditions: turbulent kinetic energy k is initialized uniformly at 1.5e-4 m^2/s^2 with kqRWallFunction on all walls (front/back patches set to empty); turbulent dissipation epsilon is initialized uniformly at 1.4e-4 m^2/s^3 with epsilonWallFunction on all walls (front/back patches set to empty); turbulent viscosity nut is initialized uniformly at 0 m^2/s with nutkWallFunction on all walls (front/back patches set to empty).

The velocity field is initialized to zero throughout the domain at time zero.

Pressure boundary conditions use zeroGradient on all walls.

The following convection schemes are specified: div(phi,U) uses Gauss limitedLinearV 1; div(phi,k) uses Gauss limitedLinear 1; div(phi,epsilon) uses Gauss limitedLinear 1; the viscous term div((nuEff*dev2(T(grad(U))))) uses Gauss linear.

Laplacian schemes use Gauss linear corrected for all terms.

Gradient schemes use Gauss linear for all fields.

Interpolation schemes use linear for all fields.

SnGrad schemes use corrected for all fields.
