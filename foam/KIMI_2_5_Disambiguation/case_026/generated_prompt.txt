Run a transient laminar two-phase dam-break simulation with obstacles using the Volume of Fluid (VOF) method.

Set gravity to g = (0 0 -9.81) m/s^2.

Define the computational domain as a cube with bounding box from (0, 0, 0) to (1, 1, 1), giving dimensions of 1m × 1m × 1m.

Assign boundary conditions as follows: the top face at z=1 is the open atmosphere patch, and the remaining five faces (x=0, x=1, y=0, y=1, z=0) are walls.

Model two phases using VOF: water with density = 1000 kg/m^3 and kinematic viscosity = 1.0e-6 m^2/s, and air with density = 1 kg/m^3 and kinematic viscosity = 1.48e-5 m^2/s. Set surface tension between phases to 0.07 N/m.

Initialize the water phase as a rectangular prism where alpha.water = 1 inside the box from (0, 0, 0) to (0.6, 0.1875, 0.75) and alpha.water = 0 elsewhere.

Place a single obstacle in the domain: a rectangular prism spanning from (0.375, 0.375, 0) to (0.625, 0.625, 0.25). Treat this obstacle as a wall boundary condition.

Set the simulation time step to deltaT = 1e-3 s, end time to endTime = 0.1 s, and write interval to writeInterval = 0.02 s.
