Set up a steady-state developing pipe flow case using simpleFoam solver.
The pipe geometry is 1 meter in length with 0.02 meter diameter (0.01 meter radius).
Use axisymmetric (2D axisymmetric) geometry with a 5-degree wedge mesh.
The mesh resolution is 100 cells in axial direction, 20 cells in radial direction, and 1 cell in circumferential direction.
Set the inlet velocity to 0.1 m/s uniform profile.
Set the kinematic viscosity to 1e-6 m²/s.
Assume fluid density of 1000 kg/m³ (water) as a reasonable default for liquid pipe flow simulations.
The Reynolds number is 2000, indicating laminar flow regime.
Apply no-slip wall boundary condition on the pipe wall.
Apply zero gradient pressure boundary condition at the inlet.
Set fixed value pressure boundary condition at the outlet (reference pressure 0 Pa).
Use standard simpleFoam solver settings with laminar turbulence model (laminar RAS model or no turbulence model).
Run the simulation until residuals converge below 1e-6 or steady-state is achieved.
