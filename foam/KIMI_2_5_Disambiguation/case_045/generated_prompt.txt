Set up a buoyant flow simulation in a 2D square domain with dimensions 1 meter by 1 meter.

Discretize the domain using a uniform Cartesian grid with 50 cells in the x-direction and 50 cells in the y-direction, resulting in a cell size of 0.02 meters in each direction.

Apply thermal boundary conditions as follows: set the bottom wall temperature to 300 Kelvin (hot), and set the top wall temperature to 290 Kelvin (cold).

Treat the left and right walls as adiabatic (zero heat flux) and no-slip for velocity.

Use air as the working fluid with the following physical properties: kinematic viscosity nu = 1.0e-5 square meters per second, Prandtl number Pr = 0.71, thermal expansion coefficient beta = 3.4e-3 per Kelvin, and reference density rho0 = 1.0 kilogram per cubic meter.

Assume the Boussinesq approximation for buoyancy, where density variations are neglected except in the gravitational body force term.

Set the gravitational acceleration to 9.81 meters per square second acting in the negative y-direction (downward).

Initialize the flow field with zero velocity and a linear temperature profile between the hot bottom and cold top walls, or with the mean temperature of 295 Kelvin throughout the domain.

Run the simulation until a steady-state or statistically steady natural convection pattern is achieved, or for a specified physical time sufficient to observe the development of buoyant plumes and circulation patterns.
