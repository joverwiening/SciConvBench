Set up a counter-flow diffusion flame simulation using reactingFoam with the following specifications:

Use the GRI-Mech 3.0 detailed reaction mechanism for methane combustion.

Configure the domain as a 2D axisymmetric cylinder with radius 0.02 m and height 0.02 m, with the axis of symmetry along the y-axis.

Generate the mesh using blockMesh with 40 cells in the radial (x) direction and 40 cells in the axial (y) direction, applying grading towards the center plane at y=0.01 m where the flame is expected to stabilize.

Position the fuel nozzle at the top boundary (y=0.02 m) with pure methane (Y_CH4 = 1.0) entering at velocity U = (0 -0.5 0) m/s (0.5 m/s downward) and temperature T = 300 K.

Position the air nozzle at the bottom boundary (y=0 m) with composition Y_O2 = 0.233 and Y_N2 = 0.767 entering at velocity U = (0 0.5 0) m/s (0.5 m/s upward) and temperature T = 300 K.

Set the nozzle separation distance to 0.02 m based on the domain height, which with 0.5 m/s opposing velocities gives a nominal strain rate of approximately 50 s^-1.

Apply the axis boundary condition type to the patch named 'axis' along the centerline.

Set the radial boundary (outlet) to zeroGradient for all variables except pressure, which uses totalPressure with p0 = 101325 Pa.

Set the reference pressure to 101325 Pa throughout the domain.

Do not include wall boundaries in the domain geometry.
