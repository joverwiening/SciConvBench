Simulate turbulent channel flow using the k-epsilon turbulence model with a pressure gradient driving force.

Assume a target friction Reynolds number Re_tau = 395, which is a well-documented benchmark case for DNS and LES validation studies.

Use periodic boundary conditions in the streamwise and spanwise directions.

Apply no-slip wall boundary conditions at the top and bottom channel walls.

Set the channel half-height h as the reference length scale.

Set the friction velocity u_tau as the reference velocity scale.

Compute the pressure gradient to maintain the target Re_tau based on the relationship Re_tau = u_tau * h / nu, where nu is the kinematic viscosity.

Use standard wall functions for the k-epsilon model at the near-wall cells.

Initialize the flow field with a logarithmic velocity profile superimposed with random fluctuations.

Run the simulation until statistical stationarity is achieved, then collect statistics for at least 10 flow-through times.
