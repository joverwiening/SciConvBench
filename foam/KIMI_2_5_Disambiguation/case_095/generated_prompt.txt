The simulation solves steady-state natural convection in a 2D buoyant cavity using buoyantBoussinesqSimpleFoam.

The domain is a square cavity with dimensions 1m x 1m in the x-y plane.

The mesh consists of 50 cells in the x-direction and 50 cells in the y-direction, creating a uniform structured grid.

The left wall boundary condition is fixed temperature at 310 K.

The right wall boundary condition is fixed temperature at 290 K.

The top wall boundary condition is zeroGradient (insulated).

The bottom wall boundary condition is zeroGradient (insulated).

The gravity vector is (0, -9.81, 0) m/s^2.

The reference temperature TRef for the Boussinesq approximation is 300 K.

The kinematic viscosity nu is 1.5e-5 m^2/s.

The thermal expansion coefficient beta is 3.33e-3 1/K.

The Prandtl number Pr is 0.71.

The thermal diffusivity alpha is calculated as nu / Pr = 2.1127e-5 m^2/s.

The solver requires appropriate boundary conditions for pressure (p_rgh), velocity (U), and temperature (T) fields.

The case setup includes constant/transportProperties with nu, beta, TRef, and Pr specified.

The case setup includes constant/g with the gravity vector specified.

The case setup includes system/fvSchemes and system/fvSolution configured for steady-state buoyant flow.

Initial conditions should be set with uniform temperature of 300 K and zero velocity.

The simulation runs until convergence criteria are met for all fields.
