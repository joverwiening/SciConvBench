The simulation is an incompressible lid driven cavity flow using the pisoFoam solver.

The computational domain is a square cavity with dimensions 1 unit in the x-direction, 1 unit in the y-direction, and 0.1 units in the z-direction.

The mesh consists of 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.

The top wall boundary is named 'movingWall' and has a fixed velocity of (1 0 0) m/s.

The remaining three walls are named 'fixedWalls' and have a no-slip boundary condition with velocity (0 0 0) m/s.

The front and back faces in the z-direction are designated as 'empty' boundary type to enforce 2D flow behavior.

The kinematic viscosity nu is set to a constant value of 1e-05 m^2/s.

The turbulence model is k-epsilon with the following wall function specifications.

The turbulent kinetic energy field k is initialized uniformly to 1.5e-04 m^2/s^2 throughout the domain.

The k field uses kqRWallFunction on all walls, with front and back faces left empty.

The turbulent dissipation rate field epsilon is initialized uniformly to 1.4e-04 m^2/s^3 throughout the domain.

The epsilon field uses epsilonWallFunction on all walls, with front and back faces left empty.

The turbulent viscosity field nut is initialized uniformly to 0 m^2/s throughout the domain.

The nut field uses nutkWallFunction on all walls, with front and back faces left empty.

The velocity field U is initialized to (0 0 0) m/s uniformly throughout the domain at time zero.

The pressure field p is initialized to a uniform value of 0 Pa.

The divergence scheme for div(phi,U) uses Gauss limitedLinearV with a coefficient of 1.

The divergence scheme for div(phi,k) uses Gauss limitedLinear with a coefficient of 1.

The divergence scheme for div(phi,epsilon) uses Gauss limitedLinear with a coefficient of 1.

The divergence scheme for the viscous term div((nuEff*dev2(T(grad(U))))) uses Gauss linear.

The gradient scheme for all fields uses Gauss linear.

The Laplacian scheme for all fields uses Gauss linear corrected.

The interpolation scheme for all fields uses linear.

The snGrad scheme for all fields uses corrected.

The time integration uses first order implicit Euler scheme for all time derivatives.

The solver for p uses GAMG with a tolerance of 1e-06 and relTol of 0.01.

The solver for U, k, and epsilon uses smoothSolver with a tolerance of 1e-07 and relTol of 0.1.

The PISO algorithm uses 2 correctors.

The simulation runs with adjustable time step based on a maximum Courant number of 1.

The write interval is set to output results every 0.1 seconds of simulation time.

The end time for the simulation is 10 seconds.
