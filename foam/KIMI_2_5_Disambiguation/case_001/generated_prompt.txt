Run a two-dimensional Rayleigh-Benard convection cell simulation using the buoyantFoam solver with gravity acting downward in the negative y direction.

The reference state shall be air-like with density 1.0 kg/m^3, reference temperature 300 K, thermal expansion coefficient 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, and thermal diffusivity 2.1e-5 m^2/s (Pr ~ 0.7).

The temperature of the bottom wall shall be fixed at 305 K and the top wall at 295 K, while the vertical side walls shall be adiabatic.

Apply no-slip velocity conditions on all solid walls, and initialize the flow at rest with a uniform temperature field of 300 K.

Use the k-epsilon turbulence model with RAS simulation type.

In constant/momentumTransport, set simulationType to RAS with model kEpsilon, turbulence on, and printCoeffs on.

In constant/physicalProperties, use heRhoThermo with equationOfState Boussinesq; set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.

In 0/k, set internalField to uniform 1e-5 with kqRWallFunction on walls and empty on front/back.

In 0/epsilon, set internalField to uniform 1e-5 with epsilonWallFunction on walls and empty on front/back.

In 0/nut, set internalField to uniform 0 with nutkWallFunction on walls and empty on front/back.

In 0/alphat, set internalField to uniform 0 with compressible::alphatJayatillekeWallFunction on walls with Prt 0.85, and empty on front/back.

In 0/U, set internalField to uniform (0 0 0) with noSlip on all solid walls and empty on front/back.

In 0/T, set internalField to uniform 300, bottom fixedValue 305, top fixedValue 295, sides zeroGradient, and front/back empty.

In 0/p, set internalField to uniform 0 with walls calculated and front/back empty.

In 0/p_rgh, set internalField to uniform 0 with walls fixedFluxPressure and front/back empty.

In system/fvSolution, set p_rgh and (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01, and set the corresponding *Final solvers to relTol 0.
