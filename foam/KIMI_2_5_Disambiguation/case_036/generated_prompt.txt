Simulate steady-state incompressible water flow through a porous block inside a channel using the Darcy-Forchheimer model for porous media.

The channel has dimensions 1.0m (length) x 0.2m (height) x 0.01m (width).

The porous block has dimensions 0.2m (length) x 0.2m (height) x 0.01m (width), spanning the entire channel height and width, positioned from x=0.4m to x=0.6m (centered in the channel).

The inlet boundary condition is a fixed velocity of 0.1 m/s in the x-direction.

The outlet boundary condition is a fixed pressure of 0 Pa (fixedValue uniform 0).

The porous block uses the Darcy-Forchheimer model with d = (1e8 1e8 1e8) and f = (0 0 0).

The porosity of the porous block is assumed to be 0.5 based on typical values for packed beds and foam structures in engineering applications.

The fluid is incompressible water with standard properties: density 1000 kg/m³ and dynamic viscosity 1e-3 Pa·s.

The simulation solves for steady-state velocity and pressure fields using the incompressible Navier-Stokes equations with the Darcy-Forchheimer momentum source term in the porous region.

All wall boundaries use no-slip velocity boundary conditions.

The flow is laminar based on the low inlet velocity and small characteristic length scale.
