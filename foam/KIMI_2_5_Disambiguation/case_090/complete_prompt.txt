Simulate steady incompressible turbulent flow in a 2D wedge-shaped diffuser using simpleFoam.

Solver: simpleFoam

Geometry: 2D planar diffuser of length 1.0 m with a linearly expanding half-height:
- inlet full height = 0.10 m (y = 0..0.10)
- outlet full height = 0.20 m (y = 0..0.20)
The bottom wall is y=0; the top wall is a straight line from (x=0, y=0.10) to (x=1, y=0.20).
Out-of-plane thickness 0.01 m, front/back empty.

Mesh: blockMesh with a single hex block using the actual wedge vertices:
- vertices include (0 0 0), (1 0 0), (1 0.20 0), (0 0.10 0) and the corresponding z=0.01 points.
Use ~200 cells in x and ~40 in y with grading near walls.

Physical properties: air-like nu = 1.5e-5 m^2/s.

Turbulence: RAS kOmegaSST (constant/momentumTransport) with wall functions.

Boundary conditions:
- inlet: U fixedValue (5 0 0); p zeroGradient; turbulence from I=5%.
- outlet: p fixedValue 0; U zeroGradient.
- walls: U noSlip; p zeroGradient; wall functions for turbulence.
- frontAndBack: empty

Controls: endTime 2000; deltaT 1; writeInterval 200.
