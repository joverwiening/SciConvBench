Simulate a 2D flow past a circular cylinder using the following specifications.

The computational domain is a rectangular region extending from x = -5 m to x = 5 m in the streamwise direction, y = -1.5 m to y = 2.5 m in the cross-stream direction, and z = -1 m to z = 1 m in the spanwise direction.

The cylinder has a diameter of 2 m and is centered at the origin (x = 0 m, y = 0 m).

Apply the following boundary conditions: at the inlet (left boundary), set velocity U = (1 0 0) m/s; at the outlet (right boundary), apply zeroGradient for velocity and set pressure p = 0 Pa as the reference value; at the top and bottom walls, apply noSlip for velocity and zeroGradient for pressure; at the cylinder wall, apply noSlip for velocity and zeroGradient for pressure; the default back and front faces are set to empty to enforce a 2D simulation.

Initialize the flow field with quiescent fluid conditions: velocity U = (0 0 0) m/s and pressure p = 0 Pa everywhere.

The flow is laminar and uses the generalisedNewtonian viscosity model with the crosspowerlaw formulation.

The crosspowerlaw parameters are: nuinf = 10 m²/s (limiting high-shear-rate kinematic viscosity), m = 0.4 (consistency index), and n = 3 (power-law index).
