Set up the pitzDaily backward-facing step simulation case using OpenFOAM.

Use the standard k-epsilon RAS turbulence model.

Set the inlet velocity to uniform (10 0 0) m/s.

Set the kinematic viscosity nu to 1e-5 m²/s.

Set the step height to 0.028 m, giving a Reynolds number based on step height of 28,000.

Use the blockMeshDict provided in the OpenFOAM pitzDaily tutorial for mesh generation.

Run the simulation for 3000 iterations to ensure adequate convergence for this flow configuration.

Set the residual convergence criteria to 1e-6 for velocity U and turbulence kinetic energy k, and 1e-7 for turbulence dissipation rate epsilon.

Run the simulation until the specified residual criteria are met or the maximum iteration count is reached, whichever occurs first.
