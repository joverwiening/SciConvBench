The simulation shall be based on the standard buoyantCavity tutorial from OpenFOAM with the following modifications.

The turbulence model shall be set to k-omega SST.

The Rayleigh number shall be set to 1e6.

The Prandtl number shall remain unchanged from the original buoyantCavity tutorial value.

The kinematic viscosity nu shall remain unchanged from the original buoyantCavity tutorial value.

The thermal expansion coefficient beta shall be adjusted to achieve the target Rayleigh number of 1e6 while keeping nu and Pr constant.

The mesh resolution shall be set to 100 cells in each direction (x, y, z) to adequately resolve turbulent structures for this Rayleigh number.

The simulation shall be run as a transient simulation using the buoyantPimpleFoam solver.

The maximum Courant number maxCo shall be set to 0.5 for numerical stability.

The endTime shall be set to 100 seconds.

The writeInterval shall be set to 10 seconds to capture the turbulent flow evolution.
