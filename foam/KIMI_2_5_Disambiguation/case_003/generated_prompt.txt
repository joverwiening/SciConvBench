The simulation shall be configured as a 2D buoyancy-driven flow in a rectangular cavity using OpenFOAM's buoyantFoam solver.

The domain geometry shall be a rectangular cavity 9 units wide in the x-direction and 1 unit tall in the y-direction, extruded a single cell in the z-direction with front and back patches treated as empty to enforce two-dimensionality.

The mesh shall consist of 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.

The solver shall be buoyantFoam with gravity acting in the negative y-direction.

The reference thermophysical state shall use air-like properties with density 1.0 kg/m^3, reference temperature 300 K, thermal expansion coefficient 3.3e-3 1/K, kinematic viscosity 1.5e-5 m^2/s, and thermal diffusivity 2.1e-5 m^2/s.

The boundary conditions for temperature shall fix the bottom wall at 305 K, the top wall at 295 K, and apply zeroGradient adiabatic conditions on the vertical side walls.

The velocity boundary conditions shall apply no-slip on all solid walls.

The initial conditions shall set the flow at rest with uniform velocity (0 0 0) and uniform temperature 300 K throughout the domain.

The time discretization shall use a fixed timestep of 1 second with adjustTimeStep disabled, no maxCo limit, and no maxDeltaT constraint.

The simulation shall run for 1000 seconds of physical time.

The write control shall output results every 50 timesteps.

The turbulence modeling shall use RAS k-epsilon with simulationType RAS, model kEpsilon, turbulence on, and printCoeffs on in constant/momentumTransport.

The thermophysical properties in constant/physicalProperties shall use heRhoThermo with Boussinesq equation of state, molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.

The 0/k file shall set internalField uniform 1e-5 with kqRWallFunction on walls and empty on front/back patches.

The 0/epsilon file shall set internalField uniform 1e-5 with epsilonWallFunction on walls and empty on front/back patches.

The 0/nut file shall set internalField uniform 0 with nutkWallFunction on walls and empty on front/back patches.

The 0/alphat file shall set internalField uniform 0 with compressible::alphatJayatillekeWallFunction on walls with Prt 0.85, and empty on front/back patches.

The 0/U file shall set internalField uniform (0 0 0) with noSlip on all solid walls and empty on front/back patches.

The 0/T file shall set internalField uniform 300, bottom wall fixedValue 305, top wall fixedValue 295, side walls zeroGradient, and front/back empty.

The 0/p file shall set internalField uniform 0 with walls calculated and front/back empty.

The 0/p_rgh file shall set internalField uniform 0 with walls fixedFluxPressure and front/back empty.

The system/fvSolution file shall set p_rgh and (U|e|k|epsilon) solver tolerances to 1e-8 with relTol 0.01, and set the corresponding *Final solvers to relTol 0.
