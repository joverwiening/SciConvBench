The simulation is a 2D transient lid-driven cavity flow using pimpleFoam with the following specifications:

The domain is a 1m x 1m square with a 40x40 mesh.

The initial velocity field is uniform (0 0 0) throughout the domain.

The top wall uses a fixedValue boundary condition with uniform velocity (1 0 0) m/s.

The bottom wall uses a noSlip boundary condition.

The left and right walls use noSlip boundary conditions.

The front and back boundaries use empty boundary conditions to enforce 2D simulation.

The kinematic viscosity is 1e-4 m^2/s.

The simulation runs until t=5s.

The time step is adjustable with adjustTimeStep set to yes, maxCo set to 1.0, and maxDeltaT set to 0.05 in controlDict, allowing deltaT to vary based on the Courant number constraint.
