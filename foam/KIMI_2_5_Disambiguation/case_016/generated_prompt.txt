Set up a laminar counter-flow diffusion flame simulation using reactingFoam in OpenFOAM with the following specifications:

The computational domain is a rectangular geometry spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.

The mesh consists of 100 grid points in the x-direction, 40 grid points in the y-direction, and 1 cell in the z-direction.

The left boundary at x=0 is named "fuel" and serves as the fuel inlet.

The right boundary at x=0.02 m is named "air" and serves as the oxidizer inlet.

The top and bottom boundaries are named "outlet".

The frontAndBack faces are set to empty to enforce a 2-D simulation.

At the fuel inlet boundary, inject methane (CH4) with a temperature of approximately 293 K.

At the air inlet boundary, supply oxidizer as air (O2/N2 mixture) at 293 K with mass fraction Y_O2 = 0.23 and the remainder as N2.

Use EulerImplicit as the chemistry integration type.

Use Rosenbrock43 as the ODE solver for chemistry.

Set the combustion model to laminar.

Set the momentum transport to laminar.

Use compressible finite-rate chemistry thermophysical modeling.

Use hePsiThermo for the thermophysical model.

Use coefficientWilkeMultiComponentMixture for the mixture model.

Use Sutherland for transport properties.

Use JANAF for thermodynamic properties.

Use the reactingFoam solver.

Set the time step to 1e-4 seconds.

Set the end time to 0.5 seconds.

Set the write interval to 0.05 seconds for result output.
