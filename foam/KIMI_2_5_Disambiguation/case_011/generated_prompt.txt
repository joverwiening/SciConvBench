The simulation is an incompressible lid driven cavity flow using the pisoFoam solver.

The computational domain uses a structured grid with 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction to enforce 2D flow characteristics.

The top boundary patch named 'movingWall' has a fixed velocity boundary condition with uniform velocity (1, 0, 0) m/s in the x-direction.

The remaining side boundary patches named 'fixedWalls' have fixed velocity boundary conditions with uniform velocity (0, 0, 0) m/s representing no-slip conditions.

The front and back boundary patches are designated as 'empty' to indicate 2D simulation.

The kinematic viscosity nu is set to a constant value of 1e-05 m^2/s in the transportProperties dictionary.

The convection scheme for div(phi,U) is set to Gauss limitedLinearV 1.

The convection scheme for div(phi,k) is set to Gauss limitedLinear 1.

The convection scheme for div(phi,epsilon) is set to Gauss limitedLinear 1.

The viscous term div((nuEff*dev2(T(grad(U))))) uses the Gauss linear scheme.
