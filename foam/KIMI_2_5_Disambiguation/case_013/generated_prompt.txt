Set up a laminar counter-flow diffusion flame simulation using reactingFoam in OpenFOAM with a 2-D opposed-jet configuration.

The computational domain is a rectangular box spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.

The mesh consists of 100 cells in the x-direction, 40 cells in the y-direction, and 1 cell in the z-direction.

The left boundary at x=0 is named "fuel" and represents the fuel inlet.

The right boundary at x=0.02 m is named "air" and represents the oxidizer inlet.

The top and bottom boundaries at y=±0.01 m are named "outlet" and act as zero-gradient outflow boundaries.

The front and back boundaries in the z-direction are set to "empty" to enforce 2-D simulation.

At the fuel inlet boundary, set the velocity to 0.1 m/s in the positive x-direction.

At the fuel inlet, set the mass fraction of methane (CH4) to 1.0 (pure methane).

At the fuel inlet, set the temperature to 293 K.

At the air inlet boundary, set the velocity to -0.1 m/s in the negative x-direction.

At the air inlet, set the mass fraction of O2 to 0.23 and N2 to 0.77.

At the air inlet, set the temperature to 293 K.

Initialize the entire domain with a uniform temperature of 2000 K at time zero to assist ignition.

Set the initial pressure throughout the domain to 101325 Pa (1 atm).

Use the reactingFoam solver for compressible reacting flow with finite-rate chemistry.

Set the combustion model to laminar.

Set the momentum transport to laminar (no turbulence model).

Use hePsiThermo for the thermophysical model with compressible flow.

Use coefficientWilkeMultiComponentMixture for the mixture model.

Use Sutherland for the transport properties.

Use JANAF for the thermodynamic properties.

Set the chemistry type to EulerImplicit.

Set the ODE solver for chemistry integration to Rosenbrock43.

The nozzle separation distance is 0.02 m, corresponding to the full x-domain length.

The global strain rate for this configuration is 10 s^-1, calculated as 2 × |U| / L = 2 × 0.1 / 0.02.
