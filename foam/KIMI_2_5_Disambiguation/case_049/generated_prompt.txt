The dam break simulation is configured as follows.

The computational domain is a rectangular tank with dimensions 0.584m in length (x-direction) and 0.584m in height (y-direction).

The water column is initially positioned in the bottom-left corner of the tank with width 0.146m and height 0.292m.

The simulation is 2D with the z-direction depth set to 1m, bounded by front and back patches of type 'empty'.

The mesh consists of a uniform 58x58 grid generated using blockMesh.

The fluid properties use water and air with standard density and viscosity values appropriate for a dam break case.

The simulation employs the interFoam solver for two-phase incompressible flow with volume of fluid interface capturing.

Time stepping uses adjustable time step control with maximum Courant number 0.5 and maximum interface Courant number 0.5.

The simulation starts at time 0 and runs until 2 seconds.

Results are written every 20 time steps.

Gravity acts in the negative y-direction with magnitude 9.81 m/s².

Initial conditions set the water phase to alpha=1 within the column region defined by box (0 0 -1) to (0.146 0.292 1) and alpha=0 elsewhere.

Boundary conditions consist of no-slip walls for velocity on all non-empty patches, zero gradient for pressure, and fixed value for alpha on walls.
