The simulation models Rayleigh-Benard convection in a 2D rectangular domain with the following specifications:

The domain dimensions are 2 meters in width and 1 meter in height, giving an aspect ratio of 2:1.

The bottom boundary is heated to a temperature of 300 K.

The top boundary is cooled to a temperature of 299 K.

The temperature difference between bottom and top boundaries is 1 K.

The side walls (left and right boundaries) use periodic boundary conditions (type cyclic) for all fields including velocity U, temperature T, and pressure p_rgh.

The Rayleigh number is set to approximately 2500.

The working fluid properties correspond to air-like behavior with Prandtl number Pr = 0.71 and thermal expansion coefficient beta = 0.0034 1/K.

The reference temperature for property evaluation is Tref = 299.5 K.

The kinematic viscosity at the reference temperature is nu = 0.00928 m²/s.
