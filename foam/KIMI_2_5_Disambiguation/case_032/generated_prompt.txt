The simulation uses buoyantBoussinesqPimpleFoam to solve transient 2D Rayleigh-Benard convection.

The Rayleigh number is Ra = 1e5.

The Prandtl number is Pr = 0.71.

The domain is 2D with width L = 0.40 m and height H = 0.10 m, giving an aspect ratio of 4:1.

The boundary conditions are: bottom wall heated, top wall cooled, and side walls periodic in the horizontal direction.

The temperature difference between bottom and top walls is DeltaT = 1 K.

The kinematic viscosity is nu = 1.5e-5 m^2/s.

The thermal expansion coefficient is beta = 3.33e-3 1/K.

The initial temperature field is set using setFields: uniform mean temperature T = 299.5 K everywhere, with a small hot spot perturbation T = 299.55 K in a box region from (0.18 0 -1) to (0.22 0.01 1) to break symmetry.

The gravitational acceleration g = 9.81 m/s^2 acts in the negative y-direction (vertical).

The reference temperature TRef = 299.5 K is used for the Boussinesq approximation.

The thermal diffusivity alpha is calculated from nu and Pr as alpha = nu / Pr = 2.1127e-5 m^2/s.
