The simulation uses the pisoFoam solver for an incompressible lid-driven cavity flow with k-epsilon turbulence modeling.

The domain is a square cavity with dimensions 1 unit in x, 1 unit in y, and 0.1 units in z.

The mesh consists of 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.

The top boundary is named movingWall and moves in the x-direction with a uniform velocity of 1 m/s (U = (1 0 0)).

The remaining walls (left, right, bottom) are grouped as fixedWalls with a no-slip boundary condition (U = (0 0 0)).

The front and back faces are designated as empty to enforce 2D flow behavior.

The pressure field p is initialized to 0 uniformly throughout the domain.

The pressure boundary condition on fixedWalls is zeroGradient.

The pressure boundary condition on movingWall is zeroGradient.

The pressure boundary condition on front and back faces is empty.

An internal reference pressure is set using pRefCell 0 and pRefValue 0.

The velocity field U is initialized to (0 0 0) uniformly throughout the domain.

The velocity boundary condition on movingWall is fixedValue with value (1 0 0).

The velocity boundary condition on fixedWalls is noSlip.

The velocity boundary condition on front and back faces is empty.

The kinematic viscosity nu is constant with a value of 1e-05 m^2/s.

The turbulence model is kEpsilon using the RAS framework.

The turbulent kinetic energy k is initialized uniformly to 1.5e-4.

The k boundary condition on movingWall is kqRWallFunction with value 1.5e-4.

The k boundary condition on fixedWalls is kqRWallFunction with value 1.5e-4.

The k boundary condition on front and back faces is empty.

The turbulent dissipation rate epsilon is initialized uniformly to 1.4e-4.

The epsilon boundary condition on movingWall is epsilonWallFunction with value 1.4e-4.

The epsilon boundary condition on fixedWalls is epsilonWallFunction with value 1.4e-4.

The epsilon boundary condition on front and back faces is empty.

The turbulent viscosity nut is initialized uniformly to 0.

The nut boundary condition on movingWall is nutkWallFunction with value 0.

The nut boundary condition on fixedWalls is nutkWallFunction with value 0.

The nut boundary condition on front and back faces is empty.

The simulation runs from time 0 to time 10.

The time step deltaT is 0.005.

Results are written every 100 time steps, corresponding to a writeInterval of 100 with writeControl set to timeStep.

The divergence scheme for div(phi,U) is Gauss limitedLinearV 1.

The divergence scheme for div(phi,k) is Gauss limitedLinear 1.

The divergence scheme for div(phi,epsilon) is Gauss limitedLinear 1.

The divergence scheme for div((nuEff*dev2(T(grad(U))))) is Gauss linear.

The gradient scheme default is Gauss linear.

The Laplacian scheme default is Gauss linear corrected.

The interpolation scheme default is linear.

The snGrad scheme default is corrected.

The time scheme (ddtSchemes default) is Euler.

The pressure linear solver uses GAMG with GaussSeidel smoother, tolerance 1e-06, and relTol 0.01.

The velocity linear solver uses smoothSolver with GaussSeidel smoother, tolerance 1e-06, and relTol 0.1.

The k linear solver uses smoothSolver with GaussSeidel smoother, tolerance 1e-06, and relTol 0.1.

The epsilon linear solver uses smoothSolver with GaussSeidel smoother, tolerance 1e-06, and relTol 0.1.

The PISO algorithm uses nCorrectors 2 and nNonOrthogonalCorrectors 0.
