The simulation domain is a square lid-driven cavity with dimensions 1 x 1 x 0.1 units (x, y, z), making it effectively 2D.
The mesh is a uniform structured grid of 20 cells in x, 20 cells in y, and 1 cell in z.
The solver is pisoFoam.
The turbulence model is k-epsilon.

Boundary definitions:
The top wall patch is named "movingWall" and is of type "wall".
The bottom, left, and right wall patches are grouped under "fixedWalls" and are of type "wall".
The front and back faces are named "frontAndBack" and are of type "empty".

Velocity (U) boundary conditions:
movingWall: fixedValue, uniform (1 0 0) m/s.
fixedWalls: noSlip (fixedValue, uniform (0 0 0)).
frontAndBack: empty.

Pressure (p) boundary conditions:
movingWall: zeroGradient.
fixedWalls: zeroGradient.
frontAndBack: empty.

Turbulent kinetic energy (k) boundary conditions:
movingWall: kqRWallFunction, value uniform 1.5e-4.
fixedWalls: kqRWallFunction, value uniform 1.5e-4.
frontAndBack: empty.

Turbulent dissipation rate (epsilon) boundary conditions:
movingWall: epsilonWallFunction, value uniform 1.4e-4.
fixedWalls: epsilonWallFunction, value uniform 1.4e-4.
frontAndBack: empty.

Turbulent viscosity (nut) boundary conditions:
movingWall: nutkWallFunction, value uniform 0.
fixedWalls: nutkWallFunction, value uniform 0.
frontAndBack: empty.

Initial conditions at time 0:
U: uniform (0 0 0).
p: uniform 0.
k: uniform 1.5e-4.
epsilon: uniform 1.4e-4.
nut: uniform 0.

Transport properties:
The transport model is Newtonian.
nu is constant with a value of 1e-05 m^2/s.

Turbulence properties:
simulationType is RAS.
The RAS model is kEpsilon.
turbulence is on.
printCoeffs is on.

Time control (controlDict):
startFrom is startTime.
startTime is 0.
stopAt is endTime.
endTime is 10.
deltaT is 0.005.
writeControl is timeStep.
writeInterval is 100.
purgeWrite is 0.
writeFormat is ascii.
writePrecision is 6.
writeCompression is uncompressed.
timeFormat is general.
timePrecision is 6.
runTimeModifiable is true.

fvSchemes:
ddtSchemes default is Euler.
gradSchemes default is Gauss linear.
divSchemes: div(phi,U) is Gauss limitedLinearV 1.
divSchemes: div(phi,k) is Gauss limitedLinear 1.
divSchemes: div(phi,epsilon) is Gauss limitedLinear 1.
divSchemes: div((nuEff*dev2(T(grad(U))))) is Gauss linear.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.

fvSolution:
Solver for p: GAMG, smoother GaussSeidel, tolerance 1e-06, relTol 0.01.
Solver for U: smoothSolver, smoother symGaussSeidel, tolerance 1e-06, relTol 0.1.
Solver for k: smoothSolver, smoother symGaussSeidel, tolerance 1e-06, relTol 0.1.
Solver for epsilon: smoothSolver, smoother symGaussSeidel, tolerance 1e-06, relTol 0.1.
PISO settings: nCorrectors is 2, nNonOrthogonalCorrectors is 0, pRefCell is 0, pRefValue is 0.
