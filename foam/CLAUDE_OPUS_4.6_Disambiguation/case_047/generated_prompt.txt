Use OpenFOAM with the simpleFoam solver to simulate turbulent channel flow driven by a pressure gradient, using the k-epsilon turbulence model.

The channel dimensions are 1 m (length, x-direction) by 0.1 m (height, y-direction) by 0.2 m (width, z-direction).

The bulk velocity is 0.5 m/s and the kinematic viscosity is 1e-5 m²/s.

The pressure gradient is enforced via fvOptions using a meanVelocityForce source term to drive the bulk velocity to 0.5 m/s in the x-direction.

Create the mesh using blockMesh with a resolution of 100 cells in x, 20 cells in y, and 10 cells in z, using uniform spacing with no grading or wall refinement.

The top and bottom boundaries (topWall, bottomWall) use no-slip (fixedValue uniform (0 0 0)) for U, zeroGradient for p, kqRWallFunction for k with value uniform 0.000375, epsilonWallFunction for epsilon with value uniform 1.875e-4, and nutkWallFunction for nut with value uniform 0.

The inlet and outlet boundaries in the streamwise x-direction use cyclic (periodic) boundary conditions for all fields (U, p, k, epsilon, nut).

The frontAndBack boundaries in the spanwise z-direction use cyclic (periodic) boundary conditions for all fields (U, p, k, epsilon, nut).

Initialize U to uniform (0.1 0 0) in the internal field.
Initialize p to uniform 0 in the internal field.
Initialize k to uniform 0.000375 in the internal field.
Initialize epsilon to uniform 1.875e-4 in the internal field.
Initialize nut to uniform 0 in the internal field.

Set the kinematic viscosity to 1e-5 m²/s in constant/transportProperties using the Newtonian transport model.

Select the kEpsilon turbulence model in constant/turbulenceProperties with RAS simulation type and turbulence enabled.

Set startTime to 0, endTime to 1000, and deltaT to 1 in system/controlDict, with writeInterval chosen at a reasonable frequency (e.g., every 100 steps).

In system/fvSolution, use the GAMG solver for p with tolerance 1e-6 and relTol 0.1, and the smoothSolver (with symGaussSeidel smoother) for U, k, and epsilon with tolerance 1e-5 and relTol 0.1. Use the SIMPLE algorithm for pressure-velocity coupling. Set under-relaxation factors to 0.7 for U, 0.3 for p, 0.7 for k, and 0.7 for epsilon. Set residual control targets to 1e-4 for p and 1e-4 for U, k, and epsilon.

In system/fvSchemes, use steadyState for ddtSchemes, Gauss linearUpwind grad(U) for div(phi,U), Gauss upwind for div(phi,k) and div(phi,epsilon), Gauss linear corrected for laplacianSchemes, Gauss linear for gradSchemes, and linear for interpolationSchemes. Set snGradSchemes to corrected.

In system/fvOptions, configure a meanVelocityForce source applied to all cells, acting on the U field, with the Ubar set to (0.5 0 0) to enforce the target bulk velocity in the streamwise direction.
