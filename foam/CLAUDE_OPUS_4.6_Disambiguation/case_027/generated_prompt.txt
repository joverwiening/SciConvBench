The solver is interFoam, running a transient laminar two-phase VOF dam-break simulation with one rectangular obstacle.

The computational domain is a cube spanning from (0, 0, 0) to (1, 1, 1).

The mesh is generated with blockMesh at a uniform resolution of 32 x 32 x 32 cells.

There is one rectangular obstacle defined as a box from (0.375, 0.375, 0) to (0.625, 0.625, 0.25). Use topoSet to select the obstacle cells as a cellSet, then use subsetMesh to remove those cells from the domain. The exposed obstacle faces become a wall patch.

The top face at z = 1 is assigned as an open atmosphere patch. The remaining five outer faces (x = 0, x = 1, y = 0, y = 1, z = 0) are assigned as wall patches. The obstacle surfaces are also assigned as wall patches, consistent with the other solid boundaries.

The two phases are water and air, modeled using the VOF method. Water has density 1000 kg/m^3 and kinematic viscosity 1.0e-6 m^2/s. Air has density 1 kg/m^3 and kinematic viscosity 1.48e-5 m^2/s. Surface tension between the phases is 0.07 N/m.

The initial condition for alpha.water is 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75) and 0 everywhere else.

Gravity is set to (0, 0, -9.81) m/s^2.

The simulation uses a fixed time step of deltaT = 1e-3 s. The end time is 0.1 s.

Results are written every 0.02 s (writeInterval = 0.02).

The turbulence modeling is set to purely laminar (simulationType laminar in turbulenceProperties).

Time integration uses the Euler scheme. Gradient schemes use Gauss linear. The alpha field divergence scheme uses Gauss vanLeer. Interface compression uses MULES. The pressure-velocity coupling uses the PIMPLE algorithm with nOuterCorrectors = 1, nCorrectors = 3, and nNonOrthogonalCorrectors = 0. All other fvSchemes and fvSolution settings use standard interFoam defaults.
