The simulation is a transient laminar two-phase dam-break with one obstacle, solved using OpenFOAM's interFoam solver with the VOF method.

The computational domain is a cube spanning from (0, 0, 0) to (1, 1, 1).

The mesh is a uniform structured grid of 32 x 32 x 32 cells.

There is one obstacle defined as a rectangular block from (0.375, 0.375, 0) to (0.625, 0.625, 0.25). This obstacle is created using snappyHexMesh or topoSet/subsetMesh to remove cells or define a wall region within the domain.

Gravity is set to (0 0 -9.81) m/s^2.

The top face at z = 1 is assigned as the atmosphere patch. The remaining five outer faces (xMin, xMax, yMin, yMax, zMin) are assigned as wall patches. The obstacle surfaces are also assigned as wall patches.

Two phases are modeled using VOF. Water has density 1000 kg/m^3 and kinematic viscosity 1.0e-6 m^2/s. Air has density 1 kg/m^3 and kinematic viscosity 1.48e-5 m^2/s. Surface tension between the phases is 0.07 N/m.

The water column is initialized as a rectangular prism where alpha.water = 1 inside the box from (0, 0, 0) to (0.6, 0.1875, 0.75) and alpha.water = 0 elsewhere.

The time step deltaT is 1e-3 s. The end time is 0.1 s. The write interval is 0.02 s.

The solver is interFoam.

Turbulence modeling is explicitly set to laminar (simulationType laminar in turbulenceProperties).

The PIMPLE algorithm is used for pressure-velocity coupling with nCorrectors 3, nNonOrthogonalCorrectors 1, and nOuterCorrectors 1.

The atmosphere patch uses totalPressure with p_rgh set to a total pressure value of 0 Pa, U set to pressureInletOutletVelocity with a uniform value of (0 0 0), and alpha.water set to inletOutlet with inletValue 0 and value 0.

All wall patches (outer walls and obstacle surfaces) use fixedFluxPressure for p_rgh, noSlip for U, and zeroGradient for alpha.water.

Time discretization uses Euler (first-order implicit).

Gradient schemes use Gauss linear.

Divergence schemes use Gauss vanLeer for div(phi,alpha) and Gauss linearUpwindV grad(U) for div(rhoPhi,U).

Laplacian schemes use Gauss linear corrected.

Interpolation schemes use linear.

Surface normal gradient schemes use corrected.

The maxAlphaCo is set to 0.5 and the maxCo is set to 0.5 with adjustTimeStep set to no since a fixed time step of 1e-3 s is specified.
