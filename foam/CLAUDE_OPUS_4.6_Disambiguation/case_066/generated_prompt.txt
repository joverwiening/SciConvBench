The simulation uses OpenFOAM with the porousSimpleFoam solver.
The case is steady-state, incompressible, laminar flow through a porous medium.
The fluid is water with kinematic viscosity 1e-06 m^2/s and density 1000 kg/m^3.
The computational domain is a 2D rectangular channel 0.5 m long and 0.1 m high.
The mesh is created using blockMesh with a uniform Cartesian grid of 100 cells in x, 20 cells in y, and 1 cell in z.
The vertices define a box from (0 0 0) to (0.5 0.1 0.01) with one cell thickness in z.
Front and back patches are set to empty type for the 2D simulation.
The inlet is the left face at x=0.
The inlet velocity boundary condition is fixedValue uniform (1 0 0) m/s.
The inlet pressure boundary condition is zeroGradient.
The outlet is the right face at x=0.5.
The outlet pressure boundary condition is fixedValue uniform 0.
The outlet velocity boundary condition is zeroGradient.
The top and bottom faces are no-slip walls.
The wall velocity boundary condition is noSlip.
The wall pressure boundary condition is zeroGradient.
A porous zone is defined in the central region from x=0.2 to x=0.3, spanning the full height and depth of the domain.
The porous zone is specified in constant/fvOptions using a porosity source term.
The porosity model is DarcyForchheimer.
The Darcy coefficient d is (1e8 1e8 1e10).
The Forchheimer coefficient f is (0 0 0).
The porous zone cell selection uses a cellZone, which must be defined in the mesh (e.g., via topoSet or blockMesh with multiple blocks).
The solver is porousSimpleFoam, set as the application in system/controlDict.
startFrom is startTime.
startTime is 0.
stopAt is endTime.
endTime is 500.
deltaT is 1.
The simulation is steady-state so endTime represents the number of SIMPLE iterations.
Numerical schemes in fvSchemes use reasonable defaults for steady-state SIMPLE: steadyState for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for divSchemes div(phi,U), Gauss linear corrected for laplacianSchemes, and linear for interpolationSchemes.
fvSolution uses the SIMPLE algorithm with p solver GAMG and U solver smoothSolver (GaussSeidel smoother).
Residual convergence tolerances are 1e-06 for p and 1e-05 for U.
SIMPLE relaxation factors are 0.3 for p and 0.7 for U.
Write control outputs results at a suitable interval such as every 100 iterations.
The turbulence model is set to laminar in constant/momentumTransport (or constant/turbulenceProperties depending on version).
