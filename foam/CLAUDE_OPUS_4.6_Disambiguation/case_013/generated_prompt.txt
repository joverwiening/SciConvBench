The simulation uses the reactingFoam solver from OpenFOAM for a 2-D laminar counter-flow diffusion flame in an opposed-jet configuration.

The domain is a rectangular box spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
The mesh has 100 cells in the x direction, 40 cells in the y direction, and 1 cell in the z direction, using uniform spacing (blockMesh).

The left boundary at x=0 is named "fuel".
The right boundary at x=0.02 is named "air".
The top boundary at y=0.01 and bottom boundary at y=-0.01 are both named "outlet".
The front and back boundaries in the z direction are named "frontAndBack" and use the empty boundary condition for 2-D simulation.

At the fuel boundary, velocity is set as a fixedValue of (0.1 0 0) m/s.
At the fuel boundary, temperature is set as a fixedValue of 293 K.
At the fuel boundary, species mass fractions are fixedValue with Y_CH4 = 1.0 and all other species set to 0.
At the fuel boundary, pressure is set as zeroGradient.

At the air boundary, velocity is set as a fixedValue of (-0.1 0 0) m/s.
At the air boundary, temperature is set as a fixedValue of 293 K.
At the air boundary, species mass fractions are fixedValue with Y_O2 = 0.23, Y_N2 = 0.77, and all other species set to 0.
At the air boundary, pressure is set as zeroGradient.

At the outlet boundaries, pressure is set as a fixedValue of 101325 Pa (1 atm).
At the outlet boundaries, velocity is set as pressureInletOutletVelocity (or inletOutlet with zero inletValue).
At the outlet boundaries, temperature is set as inletOutlet with inletValue 293 K.
At the outlet boundaries, species mass fractions are set as inletOutlet with inletValue of 0 for each species (zeroGradient behavior on outflow).

The domain is initialized at time 0 with a uniform temperature of 2000 K.
The domain is initialized with uniform velocity of (0 0 0) m/s.
The domain is initialized with uniform pressure of 101325 Pa.
The domain is initialized with uniform species composition Y_O2 = 0.23, Y_N2 = 0.77, and all other species 0.

The operating pressure is 1 atm (101325 Pa).

The chemical mechanism is GRI-Mech 3.0 (or its OpenFOAM-compatible subset, typically provided as the GRI-3.0 mechanism in chemkin format with corresponding thermodynamic and transport data files).

The thermophysical model uses hePsiThermo as the thermo type.
The mixture model is coefficientWilkeMultiComponentMixture.
The transport model is Sutherland.
The thermodynamics model is JANAF (janaf polynomial coefficients for each species).
The equation of state is perfectGas.
The energy formulation is sensibleEnthalpy.
The specie sub-type is specie (with molecular weight).

The chemistry solver type is EulerImplicit.
The ODE solver is Rosenbrock43.
The combustion model is laminar (finite-rate chemistry, no turbulence-chemistry interaction model).
The turbulence model is laminar (no turbulence modeling).

The simulation uses a fixed time step of 1e-4 seconds.
The end time is 0.5 seconds.
Results are written every 0.05 seconds (writeInterval of 0.05 with writeControl set to adjustableRunTime or runTime).

The temporal discretization scheme is Euler (first-order implicit).
The gradient scheme is Gauss linear.
The divergence schemes use Gauss limitedLinear 1 for species and energy, and Gauss linear for momentum terms; div(phi,U) uses Gauss limitedLinearV 1; div(phi,Yi_h) uses Gauss limitedLinear 1; div(phi,K) uses Gauss linear; div(phid,p) uses Gauss linear.
The Laplacian schemes use Gauss linear corrected.
The interpolation scheme is linear.
The snGrad scheme is corrected.

The pressure-velocity coupling uses the PIMPLE algorithm with 2 outer correctors and 1 inner corrector (nCorrectors 1, nOuterCorrectors 2).
The pressure equation solver is GAMG with DIC smoother and tolerance 1e-6, relTol 0.01.
The velocity, species, and energy equation solvers use PBiCGStab with DILU preconditioner, tolerance 1e-6, relTol 0.1.
Final solver tolerances (within PIMPLE final iteration) use relTol 0.
