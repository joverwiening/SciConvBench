The simulation is a 2D incompressible unsteady flow past a circular cylinder using OpenFOAM.

The solver is pimpleFoam.

The domain is a rectangular box extending from x = -5 m to x = 5 m, y = -1.5 m to y = 2.5 m, and z = -1 m to z = 1 m.

A circular cylinder of diameter 2 m (radius 1 m) is centered at the origin (x = 0 m, y = 0 m).

The simulation is treated as 2D by using the empty condition on the front and back (z = -1 and z = 1) patches, with one cell in the z-direction.

The start time is 0 s, the end time is 0.5 s, the time step is 0.0025 s, and results are written every 0.05 s (writeInterval = 20 time steps).

The initial velocity field is U = (0 0 0) m/s everywhere.

The initial pressure field is p = 0 everywhere.

The flow is laminar using the generalisedNewtonian viscosity model with the CrossPowerLaw viscosity law.

The CrossPowerLaw parameters are nu0 = 0.01 m²/s, nuInf = 10 m²/s, m = 0.4, and n = 3.

The velocity boundary conditions are as follows.
Inlet (x = -5): fixedValue, U = (1 0 0) m/s.
Outlet (x = 5): zeroGradient.
Top (y = 2.5): noSlip.
Bottom (y = -1.5): noSlip.
Cylinder surface: noSlip.
Front and back (z = -1 and z = 1): empty.

The pressure boundary conditions are as follows.
Inlet (x = -5): zeroGradient.
Outlet (x = 5): fixedValue, p = 0.
Top (y = 2.5): zeroGradient.
Bottom (y = -1.5): zeroGradient.
Cylinder surface: zeroGradient.
Front and back (z = -1 and z = 1): empty.

The mesh is generated using blockMesh with an O-grid topology around the cylinder.

The cylinder surface is discretized with approximately 120 cells around its circumference.

The first cell height near the cylinder wall is approximately 0.01 m to resolve the boundary layer.

A geometric grading ratio of approximately 1.1 is used to expand cells radially away from the cylinder surface.

The outer rectangular block regions use approximately 80 cells in the streamwise direction and 60 cells in the cross-stream direction, with mild grading toward the cylinder region.

The z-direction has exactly 1 cell to enforce the 2D (empty) condition.

The time derivative scheme (ddtSchemes) uses Euler (first-order implicit).

The gradient scheme (gradSchemes) uses Gauss linear.

The divergence scheme (divSchemes) for div(phi,U) uses Gauss linearUpwind grad(U).

The Laplacian scheme (laplacianSchemes) uses Gauss linear corrected.

The interpolation scheme (interpolationSchemes) uses linear.

The surface normal gradient scheme (snGradSchemes) uses corrected.

The pressure equation is solved using GAMG with a GaussSeidel smoother, tolerance of 1e-06, and relative tolerance of 0.01.

The velocity equation is solved using smoothSolver with a GaussSeidel smoother, tolerance of 1e-06, and relative tolerance of 0.1.

The PIMPLE algorithm uses 2 outer correctors, 1 non-orthogonal corrector, and 2 correctors (pressure correction loops).
