Simulate turbulent natural convection (thermal plume) from a hot vertical plate in a large air-filled enclosure.

Solver: buoyantPimpleFoam (transient compressible buoyant solver)

Geometry: 2D enclosure, width 2.0 m x height 3.0 m, thickness 0.01 m (front/back empty).
A hot plate is a 1.0 m tall segment on the left wall spanning y=1.0 m to y=2.0 m.

Mesh (blockMesh): Use a multi-block mesh to create a separate boundary patch for the plate segment.
Example: split the domain into 3 blocks stacked in y (0-1, 1-2, 2-3). The left boundary of the middle block is patch 'hotPlate', while the left boundary of the lower+upper blocks is patch 'leftWall'.
Target resolution ~ (80 120 1) overall (refine near the hotPlate if desired).
Patches:
- hotPlate (left wall, y=1-2)
- leftWall (left wall remainder, adiabatic)
- floor (bottom wall)
- openBoundary (top wall + right wall, treated as open to ambient)
- frontAndBack (empty)

Thermophysical properties (constant/thermophysicalProperties): Air as perfect gas with Sutherland viscosity.
Use heRhoThermo / perfectGas / sensibleEnthalpy. Set Cp ~ 1005 J/kg/K, molWeight ~ 28.9 kg/kmol.

Turbulence (constant/momentumTransport): RAS, kOmegaSST with appropriate wall functions.

Gravity (constant/g): (0 -9.81 0)

Initial conditions (0/):
- U internalField (0 0 0)
- T internalField 300 K
- p_rgh internalField 0 (gauge)
- k, omega: small uniform values (e.g., k=1e-4, omega=10) or derived from low turbulence intensity.

Boundary conditions:
- hotPlate:
  - U noSlip
  - T fixedValue 350 K
  - p_rgh fixedFluxPressure
  - k kqRWallFunction; omega omegaWallFunction; nut nutkWallFunction
- leftWall and floor (adiabatic walls):
  - U noSlip
  - T zeroGradient
  - p_rgh fixedFluxPressure
  - wall functions for turbulence
- openBoundary (top + right):
  - U pressureInletOutletVelocity (inletValue (0 0 0))
  - p_rgh totalPressure with p0 uniform 0
  - T inletOutlet (inletValue 300; value 300)
  - k, omega inletOutlet (inletValue small; value small)

Time controls (system/controlDict): startTime 0; endTime 200; deltaT 0.01; adjustTimeStep yes; maxCo 0.5; writeInterval 5.
PIMPLE controls (system/fvSolution): nOuterCorrectors 2; nCorrectors 2; nNonOrthogonalCorrectors 0; under-relax p_rgh/U/T if needed for stability.
