The simulation uses OpenFOAM with the rhoCentralFoam solver to model an oblique shock wave from a Mach 2 supersonic flow hitting a 10-degree wedge.
The gas is air modeled as a perfect gas with specific heat ratio γ = 1.4.
The free-stream static temperature is T = 300 K.
The free-stream static pressure is p = 101325 Pa.
The free-stream velocity is U = (694.5 0 0) m/s, corresponding to Mach 2.
The simulation is inviscid.
The computational domain is a 2D rectangle of 1.0 m in the x-direction and 0.5 m in the y-direction.
The wedge tip is located at point (0.2, 0).
The bottom boundary follows a flat section from (0, 0) to (0.2, 0), then an angled wedge surface from (0.2, 0) to (1.0, 0.141) where 0.141 m equals 0.8 times tan(10 degrees).
The top boundary runs from (0, 0.5) to (1.0, 0.5).
The mesh is a uniform structured mesh of 200 cells in the x-direction and 100 cells in the y-direction, created with blockMeshDict.
The mesh is split into two blocks to accommodate the wedge geometry: one block for the flat upstream section from x = 0 to x = 0.2 with 40 cells in x, and one block for the wedge section from x = 0.2 to x = 1.0 with 160 cells in x, both having 100 cells in the y-direction, maintaining approximately uniform cell sizing.
The inlet boundary uses fixedValue for U = (694.5 0 0) m/s, p = 101325 Pa, and T = 300 K.
The outlet boundary uses zeroGradient for all variables (supersonic outflow).
The bottomWall boundary (flat section plus wedge surface) is a single patch with a slip condition.
The topWall boundary uses a slip condition (far-field).
The frontAndBack boundaries use the empty condition for a 2D simulation.
The simulation end time is 0.005 s.
The time step deltaT is 5e-7 s.
The write interval is 0.001 s, producing results at 0.001, 0.002, 0.003, 0.004, and 0.005 s.
The simulation should produce a full 2D flow field suitable for visualization in ParaView, showing pressure, temperature, density, and Mach number across the domain to reveal the oblique shock structure.
