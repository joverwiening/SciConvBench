Use OpenFOAM's icoFoam solver, which is a finite volume method solver for incompressible laminar Newtonian flow.
The simulation is a 2D lid-driven cavity flow.
The square cavity has dimensions 0.1 m x 0.1 m.
The domain is 2D, so the z-direction thickness is a single cell (e.g., 0.01 m or similar small value) with empty boundary conditions on the front and back patches.
Use a 20x20 uniform Cartesian mesh generated with blockMesh.
The top wall (lid) moves with a velocity of (1 0 0) m/s, i.e., 1 m/s in the positive x-direction.
The bottom, left, and right walls are stationary no-slip walls with velocity (0 0 0) m/s.
The fluid is incompressible with a kinematic viscosity nu of 0.001 m^2/s.
This gives a Reynolds number of Re = U * L / nu = 1 * 0.1 / 0.001 = 100.
The pressure field p has dimensions of kinematic pressure (m^2/s^2) as used by icoFoam.
Set a zero-gradient boundary condition for pressure on all walls, and fix the pressure value at one reference point or cell to zero to ensure a unique pressure solution.
The total simulation time (endTime) is 0.5 seconds.
The time step (deltaT) is 0.002 seconds.
In system/controlDict, set writeControl to timeStep and writeInterval to 20.
The initial conditions are zero velocity and zero pressure throughout the domain.
Use default icoFoam numerical schemes (e.g., Gauss linear for gradient, Gauss linear corrected for Laplacian, Euler for time).
Use default linear solvers (e.g., PCG with DIC preconditioner for pressure, PBiCG with DILU preconditioner for velocity) as typically set up for icoFoam.
