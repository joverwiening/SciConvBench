Simulate supersonic flow over a forward-facing step using OpenFOAM.

The computational domain is a 2D channel 0.5 m long and 0.1 m tall.
A forward-facing step 0.02 m high is located at x = 0.1 m from the inlet.
The step spans the full width of the bottom wall.

The working fluid is standard air modeled as a perfect gas with gamma = 1.4 and R = 287 J/(kg·K).
The freestream static temperature is 293 K.
The freestream static pressure is 101325 Pa.
The inlet Mach number is 3.
The viscosity is computed using the Sutherland transport model.

The turbulence model is k-omega SST using the RAS framework.

Use blockMeshDict to create a structured mesh with approximately 20,000 cells total.
Refine the mesh near the step corner and where the shock is expected to impinge on the bottom wall.

The simulation is 2D, so the frontAndBack patches use the empty condition.

The solver is rhoPimpleFoam run as a transient simulation.
The end time is 0.01 s.
The initial time step is 1e-8 s.
Adaptive time stepping is enabled with a maximum Courant number of 0.5.
The write interval is 0.001 s.

Inlet boundary conditions: fixedValue for U = (1020.5 0 0), fixedValue for T = 293 K, fixedValue for k = 3.8, fixedValue for omega = 4.5e5, and zeroGradient for p.

Outlet boundary conditions: waveTransmissive for p, and zeroGradient for U, T, k, and omega.

Upper wall boundary condition: slip for all fields.

Bottom wall boundary conditions (including all step faces): noSlip for U, zeroGradient for p, fixedValue for T = 293 K, kqRWallFunction for k, omegaWallFunction for omega, and nutkWallFunction for nut.

frontAndBack boundary condition: empty.

For numerical schemes, use Euler for the time derivative (ddt).
Use Gauss linearUpwind for divergence schemes (div) to achieve second-order accuracy in space.
Use Gauss linear corrected for Laplacian schemes.
Use Gauss linear for gradient schemes.
Use linear for interpolation schemes.
Use Gauss linear corrected for the snGrad schemes.

Standard field output (p, U, T, k, omega, nut, etc.) is sufficient for post-processing.
No additional visualization or post-processing steps are required.
