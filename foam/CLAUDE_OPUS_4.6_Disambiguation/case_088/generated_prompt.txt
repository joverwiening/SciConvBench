The simulation models a de Laval nozzle with subsonic flow at the inlet transitioning to supersonic flow at the outlet, solved in pseudo-steady mode using OpenFOAM.

Solver: rhoPimpleFoam in pseudo-steady mode.

Geometry: 2D planar de Laval nozzle with a total length of 1 m.
Inlet height is 0.2 m.
Throat height is 0.1 m, located at x = 0.5 m.
Outlet height is 0.3 m.
The nozzle wall contour is defined using splines or polynomials in blockMeshDict to smoothly connect inlet, throat, and outlet heights.
The front and back patches are set to empty for a 2D planar simulation.

Mesh: Structured mesh generated with blockMeshDict.
Approximately 200 cells along the x-direction.
Approximately 60 cells across the full height.
Mesh refinement is applied near the throat region.
Wall-normal refinement targets y+ of approximately 30–100, consistent with wall-function usage for kOmegaSST.

Working fluid: Air modeled as a perfect gas.
Thermophysics type is hePsiThermo with perfectGas equation of state.
Transport model is Sutherland viscosity.
Specific heat capacity Cp is 1005 J/(kg·K).
Molecular weight is 28.9 g/mol.

Turbulence model: kOmegaSST configured under constant/momentumTransport as a RAS model for compressible flow.

Inlet boundary conditions:
p uses totalPressure with p0 = 200,000 Pa.
T uses totalTemperature with T0 = 300 K.
U uses pressureInletOutletVelocity with an initial guess of (10 0 0) m/s.
k is estimated from a turbulence intensity of 1% and the inlet velocity.
omega is estimated from the turbulent length scale Lt = 0.01 m and the computed k.

Outlet boundary conditions:
p uses waveTransmissive with a reference static pressure pInf = 101,325 Pa (fixedValue at 101,325 Pa is an acceptable alternative).
T uses waveTransmissive (zeroGradient is an acceptable alternative).
U uses pressureInletOutletVelocity.
k and omega use appropriate outlet conditions such as inletOutlet or zeroGradient.

Nozzle wall boundary conditions:
U is noSlip.
p is zeroGradient.
T is zeroGradient (adiabatic wall).
k uses compressibleKqRWallFunction (or kqRWallFunction).
omega uses compressible omegaWallFunction.

Time and solution controls:
ddtSchemes uses steadyState.
endTime is 2000.
deltaT is 1.
writeInterval is 200.
PIMPLE dictionary uses nOuterCorrectors set to 50–100.
Under-relaxation is applied to pressure, velocity, energy, k, and omega fields to promote steady-state convergence.

Numerical schemes:
Gradient schemes use Gauss linear.
Divergence schemes use bounded Gauss upwind or bounded Gauss linearUpwind for stability in transonic/supersonic flow.
Laplacian schemes use Gauss linear corrected.
Interpolation schemes use linear.
snGrad schemes use corrected.
