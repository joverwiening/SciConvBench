The simulation is an incompressible lid-driven cavity flow using OpenFOAM's pisoFoam solver.

The geometry is a square cavity with dimensions 1 unit in x, 1 unit in y, and 0.1 units in z, making it effectively 2D.

The mesh is 20 cells in x, 20 cells in y, and 1 cell in z.

The boundary named movingWall is the top wall, moving in the x-direction with a uniform velocity of 1 m/s.

The boundary named fixedWalls comprises the bottom, left, and right walls with a no-slip condition (velocity equal to zero).

The front and back faces are designated as empty to enforce 2D behavior.

For the velocity field U, initialize the entire domain to (0 0 0). Set movingWall to fixedValue (1 0 0). Set fixedWalls to fixedValue (0 0 0). Set frontAndBack to empty.

For the pressure field p, initialize the entire domain to 0. Set movingWall to zeroGradient. Set fixedWalls to zeroGradient. Set frontAndBack to empty.

The kinematic viscosity nu is constant with a value of 1e-05 m^2/s.

The turbulence model is kEpsilon using a RAS simulation type.

For the turbulent kinetic energy field k, initialize uniformly to 1.5e-4. Set movingWall to kqRWallFunction with value 1.5e-4. Set fixedWalls to kqRWallFunction with value 1.5e-4. Set frontAndBack to empty.

For the turbulent dissipation rate field epsilon, initialize uniformly to 1.4e-4. Set movingWall to epsilonWallFunction with value 1.4e-4. Set fixedWalls to epsilonWallFunction with value 1.4e-4. Set frontAndBack to empty.

For the turbulent viscosity field nut, initialize uniformly to 0. Set movingWall to nutkWallFunction with value 0. Set fixedWalls to nutkWallFunction with value 0. Set frontAndBack to empty.

The time step deltaT is 0.005.

The end time is 10.

The write control is timeStep with a write interval of 100.

The ddt scheme is Euler.

The gradient schemes default to Gauss linear.

The divergence schemes are as follows: div(phi,U) is Gauss limitedLinearV 1; div(phi,k) is Gauss limitedLinear 1; div(phi,epsilon) is Gauss limitedLinear 1; div((nuEff*dev2(T(grad(U))))) is Gauss linear.

The Laplacian schemes default to Gauss linear corrected.

The interpolation schemes default to linear.

The snGrad schemes default to corrected.

The linear solver for p uses GAMG with a tolerance of 1e-06, relative tolerance of 0.01, smoother GaussSeidel, and nPreSweeps 0, nPostSweeps 2, nFinestSweeps 2, cacheAgglomeration true.

The linear solver for U, k, and epsilon uses smoothSolver with smoother symGaussSeidel, tolerance 1e-06, and relative tolerance 0.1.

The PISO settings are nCorrectors 2, nNonOrthogonalCorrectors 0, pRefCell 0, and pRefValue 0.
