The simulation uses the interFoam solver from OpenFOAM for a transient, laminar, two-phase (water-air) dam-break with an obstacle in a unit cube domain.

The domain is a cube spanning from (0, 0, 0) to (1, 1, 1).
The mesh is generated using blockMesh with a uniform resolution of 32 cells in each direction (32 x 32 x 32).
An obstacle is modeled as a solid block occupying the region from (0.375, 0.375, 0) to (0.625, 0.625, 0.25), defined as a separate region in the blockMesh dictionary with its exposed faces assigned wall boundary conditions.

Gravity is set to g = (0, 0, -9.81) m/s^2 in the constant/g file.

Water properties: density = 1000 kg/m^3, kinematic viscosity = 1.0e-6 m^2/s.
Air properties: density = 1 kg/m^3, kinematic viscosity = 1.48e-5 m^2/s.
Surface tension between water and air sigma = 0.07 N/m.
These are specified in constant/transportProperties using the appropriate interFoam format (phases water and air, each with nu and rho entries, and sigma between them).

The turbulenceProperties file uses simulationType laminar with no turbulence model.

The initial condition for alpha.water is 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75) and 0 elsewhere, set using the setFieldsDict utility with a boxToCell source.
The initial velocity field U is uniform (0, 0, 0) m/s.
The initial pressure field p_rgh is uniform 0 Pa.

The bottom face (z=0), front face (y=0), back face (y=1), left face (x=0), and right face (x=1) are all wall boundaries.
For wall patches: U uses a fixedValue condition set to (0, 0, 0); p_rgh uses a fixedFluxPressure condition with value 0; alpha.water uses a zeroGradient condition.
The top face (z=1) is an open atmosphere patch.
For the atmosphere patch: p_rgh uses a totalPressure condition with p0 = 0 Pa and value 0 Pa; U uses a pressureInletOutletVelocity condition with value (0, 0, 0); alpha.water uses an inletOutlet condition with inletValue 0 and value 0.
The obstacle faces exposed to the fluid domain use the same wall boundary conditions as the outer walls.

Time control in system/controlDict: deltaT = 1e-3 s, endTime = 0.1 s, writeInterval = 0.02 s, writeControl timeStep is not used — instead writeControl is set to adjustable or runTime with writeInterval = 0.02 s. Specifically, writeControl is runTime and writeInterval is 0.02.
The time stepping is fixed (no adjustableRunTime), with deltaT = 1e-3 s.
maxCo is set to 0.5 and maxAlphaCo is set to 0.5 as safety values, but adjustTimeStep is off.

Numerical schemes in system/fvSchemes: ddtSchemes default is Euler; gradSchemes default is Gauss linear; divSchemes uses Gauss vanLeer for div(phi,alpha) and div(phirb,alpha), Gauss linearUpwind grad(U) for div(rhoPhi,U), and Gauss linear for other divergence terms; laplacianSchemes default is Gauss linear corrected; interpolationSchemes default is linear; snGradSchemes default is corrected.

Solution controls in system/fvSolution use the PIMPLE algorithm with nOuterCorrectors = 1, nCorrectors = 2, and nNonOrthogonalCorrectors = 1.
The p_rgh solver uses GAMG with DICGaussSeidel smoother, tolerance 1e-8, and relTol 0.01 for the predictor and 0 for the final corrector.
The U and alpha.water solvers use smoothSolver with GaussSeidel smoother, tolerance 1e-8, and relTol 0.
The MULES settings for alpha use nAlphaCorr = 2, nAlphaSubCycles = 1, and cAlpha = 1.
