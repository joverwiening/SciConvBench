Simulate a lid-driven cavity flow using OpenFOAM's icoFoam solver.

The cavity geometry is 0.1m x 0.1m x 0.01m, where the 0.01m depth is in the z-direction for a quasi-2D setup.

The mesh is a 20 x 20 x 1 uniform Cartesian mesh created with blockMesh.

The kinematic viscosity nu is 0.01 m²/s, set in constant/transportProperties.

The top wall patch is named movingWall and moves at (1 0 0) m/s.
The remaining walls (bottom, left, right) are grouped into a patch named fixedWalls.
The front and back faces are grouped into a patch named frontAndBack.

Boundary conditions for velocity U are as follows.
movingWall: fixedValue, uniform (1 0 0).
fixedWalls: fixedValue, uniform (0 0 0).
frontAndBack: empty.

Boundary conditions for pressure p are as follows.
movingWall: zeroGradient.
fixedWalls: zeroGradient.
frontAndBack: empty.

The initial internal field for p is uniform 0.
The initial internal field for U is uniform (0 0 0).

The end time is 0.5 s.
The time step deltaT is 0.0005 s.
writeControl is set to timeStep.
writeInterval is set to 20.

In fvSolution, use standard icoFoam defaults.
The pressure solver is PCG with a DIC preconditioner, tolerance 1e-06, and relTol 0.
The velocity solver is PBiCG (or PBiCGStab) with a DILU preconditioner, tolerance 1e-05, and relTol 0.
The PISO sub-dictionary has nCorrectors set to 2 and nNonOrthogonalCorrectors set to 0.

In fvSchemes, use standard icoFoam defaults.
ddtSchemes default is Euler.
gradSchemes default is Gauss linear.
divSchemes div(phi,U) is Gauss linear.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.
