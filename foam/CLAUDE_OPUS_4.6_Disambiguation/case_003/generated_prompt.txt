The simulation domain is a rectangular cavity spanning from (0, 0, 0) to (9, 1, 0.1).
The mesh has 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.
The front and back patches (z-normal faces) are of type empty to enforce a 2D simulation.
The bottom wall is the patch at y=0, the top wall is the patch at y=1, and the left and right side walls are the patches at x=0 and x=9.

The solver is buoyantFoam.

The file constant/g sets gravity to (0 -9.81 0).

The file constant/momentumTransport sets simulationType to RAS, with the RAS sub-dictionary specifying model kEpsilon, turbulence on, and printCoeffs on. Do not use laminar anywhere.

The file constant/physicalProperties uses thermoType with type heRhoThermo, mixture pureMixture, transport const, thermo eConst, equationOfState Boussinesq, specie specie, and energy sensibleInternalEnergy.
The mixture sub-dictionary contains a specie sub-dictionary with molWeight 29.
The equationOfState sub-dictionary contains rho0 1.0, T0 300, and beta 3.3e-3.
The thermodynamics sub-dictionary contains Cv 714.3 and Hf 0.
The transport sub-dictionary contains mu 1.5e-5 and Pr 0.714.
