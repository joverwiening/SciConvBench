The simulation models a 2D de Laval nozzle with a normal shock in the diverging section using OpenFOAM.

The solver is rhoCentralFoam.
The flow is compressible and inviscid (Euler equations, no turbulence model).
The working fluid is a perfect (ideal) gas with constant properties: gamma = 1.4, R = 287 J/(kg·K).

The nozzle geometry is 2D with the following dimensions:
Inlet height is 0.1 m, located at x = 0.
Throat height is 0.05 m, located at x = 0.1 m.
Outlet height is 0.08 m, located at x = 0.3 m.
Total nozzle length is 0.3 m.
The converging-diverging wall profile uses arc edges in blockMeshDict for a smooth shape.

The mesh has 300 cells in the axial direction and 50 cells in the transverse direction.
The mesh is graded to be finer near the throat region.

The inlet total pressure is 5e5 Pa.
The inlet total temperature is 600 K.
The outlet static pressure is 3.5e5 Pa, applied as a fixedValue boundary condition.

The domain is initialized with quiescent conditions consistent with the inlet stagnation state: p = 5e5 Pa, T = 600 K, U = (0 0 0).
The solution develops transiently until steady state is reached.

The time step is fixed at 1e-7 s.
The end time is 0.05 s.
The write interval is 0.005 s.

The front and back patches are set to empty for the 2D simulation.
The nozzle walls are slip boundaries (consistent with the inviscid assumption).
