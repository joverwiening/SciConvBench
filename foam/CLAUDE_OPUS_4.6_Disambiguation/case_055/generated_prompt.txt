The final specification is as follows:

Simulate a lid-driven cavity case for compressible, high-speed, turbulent flow using OpenFOAM.

The solver is rhoPimpleFoam, a transient compressible solver.

The domain is a 1 m x 1 m square cavity with a thickness of 0.01 m in the z-direction, treated as a 2D case using empty boundary conditions on the front and back patches.

The mesh is a uniform 100 x 100 x 1 hexahedral mesh with no grading or wall refinement.

The fluid is air modeled as a perfect gas (calorically perfect) with Cp = 1005 J/(kg·K) and molecular weight = 28.9 kg/kmol.

The viscosity model is Sutherland.

Initial conditions are uniform throughout the domain: pressure = 101325 Pa, temperature = 300 K, and velocity = (0 0 0) m/s.

The turbulence model is kOmegaSST under the RAS framework with compressibility corrections enabled.

The top lid boundary conditions are: U = fixedValue (100 0 0) m/s, p = zeroGradient, T = fixedValue 300 K, k = compressible wall function (kqRWallFunction), omega = compressible wall function (omegaWallFunction).

The bottom, left, and right wall boundary conditions are: U = noSlip, p = zeroGradient, T = fixedValue 300 K, k = compressible wall function (kqRWallFunction), omega = compressible wall function (omegaWallFunction).

The front and back patches are set to empty for the 2D treatment.

The end time is 0.2 s.

The time step is adjustable with an initial deltaT of 1e-6 s and a maximum Courant number of 0.7.

The write interval is 0.02 s, producing 10 output time directories.

Temporal discretization uses the backward scheme (second-order implicit).

Divergence schemes use Gauss linearUpwind for velocity, enthalpy, and kinetic energy terms, and Gauss upwind for turbulence quantities (k and omega) for stability.

Gradient schemes use Gauss linear.

Laplacian schemes use Gauss linear corrected.

Interpolation schemes use linear.

Surface normal gradient schemes use corrected.

Initial turbulence quantities should be estimated from a turbulence intensity of approximately 5% and a mixing length of approximately 0.07 m (7% of cavity side length), giving initial k approximately 3.75 m^2/s^2 and initial omega estimated accordingly from k and the mixing length using omega = sqrt(k) / (Cmu^0.25 * l), with Cmu = 0.09.

The PIMPLE algorithm settings should use 2 outer correctors, 1 non-orthogonal corrector, and 2 pressure correctors per outer loop.

Linear solvers should use a smoothSolver with GaussSeidel smoother for U, k, omega, and h (or e), and GAMG with GaussSeidel smoother for pressure.
