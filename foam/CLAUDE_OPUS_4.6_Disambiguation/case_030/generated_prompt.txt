The simulation framework is OpenFOAM using the interFoam solver.
The simulation is transient, laminar, two-phase (VOF) dam-break with an obstacle.
The domain is a cube spanning from (0, 0, 0) to (1, 1, 1).
There is a rectangular obstacle (solid block to be subtracted from the mesh) from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Gravity is set to g = (0, 0, -9.81) m/s^2.
The top face (z = 1) is assigned as an open atmosphere patch.
The remaining five outer faces (x = 0, x = 1, y = 0, y = 1, z = 0) are assigned as wall patches.
The obstacle surfaces exposed to the fluid are also wall patches.
Two phases are modeled via VOF: water and air.
Water has density = 1000 kg/m^3 and kinematic viscosity = 1.0e-6 m^2/s.
Air has density = 1 kg/m^3 and kinematic viscosity = 1.48e-5 m^2/s.
Surface tension between water and air is 0.07 N/m.
The flow is laminar; no turbulence model is used.
The initial water column is defined by alpha.water = 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
alpha.water = 0 everywhere else in the domain (air).
The mesh is uniform with 32 cells in the x-direction, 32 cells in the y-direction, and 32 cells in the z-direction.
The obstacle is created using snappyHexMesh or an equivalent mesh subtraction method from the base blockMesh.
The time step is fixed at deltaT = 1e-3 s.
The simulation end time is endTime = 0.1 s.
The write interval is 0.02 s (writing results at t = 0.02, 0.04, 0.06, 0.08, and 0.1 s).
Time integration uses the Euler scheme.
Gradient schemes use Gauss linear.
Divergence schemes use Gauss vanLeer for alpha and Gauss linearUpwind for velocity.
Laplacian schemes use Gauss linear corrected.
Interpolation schemes use linear.
Surface normal gradient schemes use corrected.
The PIMPLE algorithm is used for pressure-velocity coupling with default settings (nOuterCorrectors = 1, nCorrectors = 3, nNonOrthogonalCorrectors = 0).
