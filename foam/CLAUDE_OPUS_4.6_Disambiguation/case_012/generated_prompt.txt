The simulation is an incompressible lid-driven cavity flow using OpenFOAM's pisoFoam solver.

The domain is a square cavity with dimensions 1 unit in x, 1 unit in y, and 0.1 units in z.
The mesh has 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.

The simulation runs from time 0 to time 10 with a time step of 0.005.
Results are written every 100 time steps.

The fluid kinematic viscosity nu is constant at 1e-05 m²/s.
The transport model is Newtonian.

The turbulence model is kEpsilon (RAS).

The top wall is named movingWall and has a fixedValue velocity boundary condition of (1 0 0) m/s.
All other walls (bottom and two sides) are named fixedWalls and have a fixedValue velocity boundary condition of (0 0 0).
The front and back patches are of type empty.

For pressure, all walls (movingWall and fixedWalls) use zeroGradient.
The front and back patches use empty for pressure.
Pressure is set with a fixedValue of 0 at one reference point or the pressure field uses a fixedValue of 0 on one wall; specifically, use zeroGradient on movingWall and fixedWalls, and empty on front and back, with a pressure reference point set in fvSolution (pRefCell 0, pRefValue 0).

The velocity field is initialized uniformly to (0 0 0) throughout the domain.
The pressure field is initialized uniformly to 0 throughout the domain.

The turbulent kinetic energy k is initialized uniformly to 1.5e-4.
On movingWall and fixedWalls, k uses kqRWallFunction with value 1.5e-4.
On front and back, k uses empty.

The turbulent dissipation rate epsilon is initialized uniformly to 1.4e-4.
On movingWall and fixedWalls, epsilon uses epsilonWallFunction with value 1.4e-4.
On front and back, epsilon uses empty.

The turbulent viscosity nut is initialized uniformly to 0.
On movingWall and fixedWalls, nut uses nutkWallFunction with value 0.
On front and back, nut uses empty.

The time discretization scheme (ddt) is Euler.

The gradient schemes default to Gauss linear.

The divergence schemes are as follows:
div(phi,U) uses Gauss limitedLinearV 1.
div(phi,k) uses Gauss limitedLinear 1.
div(phi,epsilon) uses Gauss limitedLinear 1.
div((nuEff*dev2(T(grad(U))))) uses Gauss linear.

The Laplacian schemes default to Gauss linear corrected.

The interpolation schemes default to linear.

The snGrad schemes default to corrected.

For the linear solvers in fvSolution:
The pressure solver (p) uses GAMG with a GaussSeidel smoother, tolerance 1e-06, and relTol 0.01.
The velocity solver (U) uses smoothSolver with a GaussSeidel smoother, tolerance 1e-06, and relTol 0.1.
The k solver uses smoothSolver with a GaussSeidel smoother, tolerance 1e-06, and relTol 0.1.
The epsilon solver uses smoothSolver with a GaussSeidel smoother, tolerance 1e-06, and relTol 0.1.

The PISO algorithm settings are nCorrectors 2 and nNonOrthogonalCorrectors 0.
The pressure reference cell is pRefCell 0 and pRefValue 0.
