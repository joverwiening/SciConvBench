What PIMPLE/PISO algorithm settings should be used in system/fvSolution (e.g., number of outer correctors, correctors, non-orthogonal correctors)?
User: Use PIMPLE with nOuterCorrectors 1, nCorrectors 2, and nNonOrthogonalCorrectors 1.



The simulation is a two-dimensional Rayleigh-Benard convection cell using OpenFOAM's buoyantFoam solver.

The computational domain is a rectangular cavity 9 units wide (x), 1 unit tall (y), and 0.1 units deep (z).
The mesh has 90 cells in x, 10 cells in y, and 1 cell in z.
The front and back z-normal patches are type empty to enforce two-dimensionality.
The boundary patches are: bottom (y=0 wall), top (y=1 wall), left (x=0 wall), right (x=9 wall), front (z=0.05 empty), back (z=-0.05 empty).

Gravity is set in constant/g as (0 -9.81 0) m/s².

In constant/physicalProperties (or constant/thermophysicalProperties), use thermoType with type heRhoThermo, mixture pureMixture, transport const, thermo hConst, equationOfState Boussinesq, specie specie, energy sensibleInternalEnergy.
Under mixture, set specie with molWeight 29.
Under equationOfState, set rho0 1.0, T0 300, beta 3.3e-3.
Under thermodynamics, set Cv 714.3 and Hf 0.
Under transport, set mu 1.5e-5 and Pr 0.714.

In constant/momentumTransport (or constant/turbulenceProperties), set simulationType to RAS.
Under RAS, set model to kEpsilon, turbulence on, and printCoeffs on.
Do not use laminar anywhere.

In 0/U, set internalField to uniform (0 0 0), bottom noSlip, top noSlip, left noSlip, right noSlip, front empty, back empty.

In 0/T, set internalField to uniform 300, bottom fixedValue uniform 305, top fixedValue uniform 295, left zeroGradient, right zeroGradient, front empty, back empty.

In 0/p, set internalField to uniform 0, bottom calculated, top calculated, left calculated, right calculated, front empty, back empty.

In 0/p_rgh, set internalField to uniform 0, bottom fixedFluxPressure with value uniform 0, top fixedFluxPressure with value uniform 0, left fixedFluxPressure with value uniform 0, right fixedFluxPressure with value uniform 0, front empty, back empty.

In 0/k, set internalField to uniform 1e-5, bottom kqRWallFunction with value uniform 1e-5, top kqRWallFunction with value uniform 1e-5, left kqRWallFunction with value uniform 1e-5, right kqRWallFunction with value uniform 1e-5, front empty, back empty.

In 0/epsilon, set internalField to uniform 1e-5, bottom epsilonWallFunction with value uniform 1e-5, top epsilonWallFunction with value uniform 1e-5, left epsilonWallFunction with value uniform 1e-5, right epsilonWallFunction with value uniform 1e-5, front empty, back empty.

In 0/nut, set internalField to uniform 0, bottom nutkWallFunction with value uniform 0, top nutkWallFunction with value uniform 0, left nutkWallFunction with value uniform 0, right nutkWallFunction with value uniform 0, front empty, back empty.

In 0/alphat, set internalField to uniform 0, bottom compressible::alphatJayatillekeWallFunction with value uniform 0 and Prt 0.85, top compressible::alphatJayatillekeWallFunction with value uniform 0 and Prt 0.85, left compressible::alphatJayatillekeWallFunction with value uniform 0 and Prt 0.85, right compressible::alphatJayatillekeWallFunction with value uniform 0 and Prt 0.85, front empty, back empty.

In system/controlDict, set application to buoyantFoam, startFrom startTime, startTime 0, stopAt endTime, endTime 1000, deltaT 1, writeControl timeStep, writeInterval 50, purgeWrite 0, writeFormat ascii, writePrecision 6, writeCompression uncompressed, timeFormat general, timePrecision 6, runTimeModifiable true.
Do not set adjustTimeStep, maxCo, or maxDeltaT.

In system/fvSchemes, set ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear.
Set divSchemes default to none, div(phi,U) to Gauss linearUpwind grad(U), div(phi,e) to Gauss linearUpwind default, div(phi,k) to Gauss upwind, div(phi,epsilon) to Gauss upwind, div(phi,K) to Gauss linear, div(meshPhi,p) to Gauss linear, div((phi|interpolate(rho)),p) to Gauss linear, div(((rho*nuEff)*dev2(T(grad(U))))) to Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.

In system/fvSolution, set solvers for p_rgh with solver PCG, preconditioner DIC, tolerance 1e-8, relTol 0.01.
Set solvers for p_rghFinal with solver PCG, preconditioner DIC, tolerance 1e-8, relTol 0.
Set solvers for "(U|e|k|epsilon)" with solver PBiCGStab, preconditioner DILU, tolerance 1e-8, relTol 0.01.
Set solvers for "(U|e|k|epsilon)Final" with solver PBiCGStab, preconditioner DILU, tolerance 1e-8, relTol 0.
Under PIMPLE, set nOuterCorrectors 1, nCorrectors 2, nNonOrthogonalCorrectors 1.
