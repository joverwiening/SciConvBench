The simulation uses buoyantBoussinesqSimpleFoam to solve for the steady-state natural convection in a 2D square cavity.

The domain is a 1m x 1m square cavity meshed with a uniform 50x50 grid.
The mesh is generated using blockMesh with one cell in the z-direction (2D case) and empty boundary conditions on the front and back patches.
The geometry vertices span from (0, 0, 0) to (1, 1, 0.02) or a similarly thin z-extent.

The fluid is air at a reference temperature of 300 K.
The kinematic viscosity nu is 1.5e-5 m²/s.
The Prandtl number Pr is 0.71.
The thermal expansion coefficient beta is 3.33e-3 1/K.
The reference temperature TRef is 300 K.
The reference density rho0 is 1.0 kg/m³.

Gravity is set to (0, -9.81, 0) in the constant/g file.

The turbulence model is laminar (no turbulence modeling).

The boundary patches are named leftWall, rightWall, topWall, bottomWall, frontAndBack.

The temperature boundary conditions are as follows.
leftWall: fixedValue uniform 310 K.
rightWall: fixedValue uniform 290 K.
topWall: zeroGradient (insulated).
bottomWall: zeroGradient (insulated).
frontAndBack: empty.
The internalField for T is uniform 300 K.

The velocity boundary conditions are as follows.
leftWall: noSlip.
rightWall: noSlip.
topWall: noSlip.
bottomWall: noSlip.
frontAndBack: empty.
The internalField for U is uniform (0 0 0).

The p_rgh boundary conditions are as follows.
leftWall: fixedFluxPressure with value uniform 0.
rightWall: fixedFluxPressure with value uniform 0.
topWall: fixedFluxPressure with value uniform 0.
bottomWall: fixedFluxPressure with value uniform 0.
frontAndBack: empty.
The internalField for p_rgh is uniform 0.

The time scheme (ddtSchemes) is steadyState.
The gradient scheme (gradSchemes) is Gauss linear.
The divergence scheme (divSchemes) for div(phi,U), div(phi,T), and other div(phi,*) terms is Gauss upwind.
The Laplacian scheme (laplacianSchemes) is Gauss linear corrected.
The interpolation scheme is linear.
The snGrad scheme is corrected.

The linear solver for p_rgh is GAMG.
The linear solver for U is smoothSolver.
The linear solver for T is smoothSolver.

The SIMPLE algorithm is used with nNonOrthogonalCorrectors set to 0.
The residual control thresholds are p_rgh 1e-6, U 1e-6, T 1e-6.

The relaxation factor for p_rgh is 0.3.
The relaxation factor for U is 0.7.
The relaxation factor for T is 0.7.

The endTime is 2000.
The deltaT is 1.
The writeInterval is 200.
The writeFormat is ascii.
The writeCompression is uncompressed.
The timeFormat is general.
The timePrecision is 6.
The runTimeModifiable is true.
