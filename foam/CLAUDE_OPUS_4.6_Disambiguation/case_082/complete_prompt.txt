Simulate a 2D axisymmetric counter-flow diffusion flame using the reactingFoam solver.
GEOMETRY: The domain is a cylinder with a radius of 0.02 m and a height of 0.02 m. The simulation is axisymmetric, with the axis of symmetry along the y-axis.
 MESH: Use blockMesh to create a mesh of 40 cells in the radial (x) direction and 40 cells in the axial (y) direction. The mesh should be graded towards the center (y=0.01 m) where the flame is expected.
FUEL INLET (patch 'fuelInlet', top boundary): Pure methane (CH4) enters at a uniform velocity of U = (0 -0.5 0) m/s and T = 300 K. Mass fraction Y.CH4 = 1.0.
OXIDIZER INLET (patch 'oxidizerInlet', bottom boundary): Air enters at a uniform velocity of U = (0 0.5 0) m/s and T = 300 K. Mass fractions are O2=0.233, N2=0.767.
OUTLET (patch 'outlet', radial boundary): Use a zeroGradient condition for all variables except pressure, which is set to totalPressure with p0=101325 Pa.
AXIS (patch 'axis'): Use the 'axis' boundary condition type.
INITIAL CONDITIONS: The domain is initialized with N2 at T=300 K, p=101325 Pa, and U=(0 0 0) m/s.
COMBUSTION PROPERTIES: Use the GRI-Mech 3.0 mechanism. The mechanism files (e.g., chem.inp, therm.dat) must be converted to OpenFOAM format using the 'chemkinToFoam' utility and placed in the constant directory. Set thermodynamics to 'janaf'.
TIME CONTROLS: Run the simulation until endTime=0.05 s. Use an adjustable time step with an initial deltaT of 1e-7 s and a maximum Courant number (maxCo) of 0.3. Write results every 0.002 s.
