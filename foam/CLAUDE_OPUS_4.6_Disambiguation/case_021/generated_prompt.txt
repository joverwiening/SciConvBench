The simulation domain is a rectangular box extending from x = -5 m to x = 5 m, y = -1.5 m to y = 2.5 m, and z = -1 m to z = 1 m.
A circular cylinder of diameter 2 m is centered at the origin (x = 0 m, y = 0 m).
The simulation is 2D, enforced by using the "empty" boundary condition on the front and back z-direction faces.
The solver is pimpleFoam for incompressible unsteady flow.
The start time is 0 s, the end time is 0.5 s, the time step deltaT is 0.0025 s, and results are written every 0.05 s (writeInterval of 20 time steps using timeStep write control).
The write format is ASCII.
The initial velocity field is U = (0 0 0) m/s everywhere.
The initial pressure field is p = 0 everywhere.
The inlet boundary (x = -5) has a fixed value velocity U = (1 0 0) m/s and zeroGradient for pressure.
The outlet boundary (x = 5) has zeroGradient for velocity and a fixed value pressure p = 0.
The top boundary (y = 2.5) has noSlip for velocity and zeroGradient for pressure.
The bottom boundary (y = -1.5) has noSlip for velocity and zeroGradient for pressure.
The cylinder wall has noSlip for velocity and zeroGradient for pressure.
The front and back faces (z-direction) use the empty boundary condition.
The turbulence model is laminar using the generalisedNewtonian viscosity approach.
The viscosity model is CrossPowerLaw with nu0 = 0.01, nuInf = 10, m = 0.4, and n = 3.
The base kinematic viscosity nu in transportProperties is 0.01 m²/s.
The mesh should have approximately 50,000 to 80,000 cells with refinement near the cylinder surface to resolve boundary layer gradients, targeting a first cell height near the cylinder of approximately 0.01 m with a growth ratio of about 1.2.
The time integration scheme is Euler (first-order implicit).
The gradient scheme is Gauss linear.
The divergence scheme for velocity convection is Gauss linearUpwind grad(U).
The divergence scheme for other terms is Gauss linear.
The Laplacian scheme is Gauss linear corrected.
The interpolation scheme is linear.
The surface normal gradient scheme is corrected.
The pressure equation is solved using GAMG with a DICGaussSeidel smoother, tolerance of 1e-06, and relative tolerance of 0.01.
The velocity equation is solved using smoothSolver with a symGaussSeidel smoother, tolerance of 1e-06, and relative tolerance of 0.1.
The PIMPLE algorithm uses 2 outer correctors, 1 non-orthogonal corrector, and 2 correctors.
