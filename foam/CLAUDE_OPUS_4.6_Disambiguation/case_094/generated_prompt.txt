Start from the standard buoyantCavity tutorial case and apply the following modifications to make it turbulent using k-omega SST at Ra = 1e6.

In constant/transportProperties, change the thermal expansion coefficient beta from 2.9e-3 to 2.9e-2 1/K. All other fluid properties (nu, Pr, etc.) remain unchanged.

In constant/momentumTransport, change simulationType from laminar to RAS. Add the entry RASModel kOmegaSST. Turbulence is on by default and no explicit turbulence on entry is required.

Keep the mesh identical to the original tutorial with no modifications.

Create a new file 0/k with internalField uniform 1e-6. On all wall patches, use kqRWallFunction with value uniform 1e-6. On the frontAndBack patch, set the type to empty.

Create a new file 0/omega with internalField uniform 1. On all wall patches, use omegaWallFunction with value uniform 1. On the frontAndBack patch, set the type to empty.

Create a new file 0/nut with internalField uniform 0. On all wall patches, use nutkWallFunction with value uniform 0. On the frontAndBack patch, set the type to empty.

In system/fvSolution, add solver entries for k and omega. For k, use solver PBiCGStab, preconditioner DILU, tolerance 1e-08, relTol 0.1. For omega, use solver PBiCGStab, preconditioner DILU, tolerance 1e-08, relTol 0.1. Keep all other fvSolution entries as-is.

In system/fvSchemes, add div(phi,k) Gauss linearUpwindV grad(k) and div(phi,omega) Gauss linearUpwindV grad(omega) to the divSchemes sub-dictionary. Keep all other fvSchemes entries as-is.

In system/controlDict, reduce maxCo from 0.9 to 0.5. Set endTime to 100. Set writeInterval to 10. Keep all other controlDict entries as-is.
