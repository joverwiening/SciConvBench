Problem: Simulate steady-state, laminar, incompressible flow of water through a porous baffle in a 2D channel.
Solver: porousSimpleFoam
Geometry: A 2D channel of dimensions 1.0m (L) x 0.2m (H) x 0.01m (W). A porous zone is located from x=0.4m to x=0.6m across the entire channel height.
Mesh: Use blockMesh to create a structured mesh with 100 cells in x, 20 in y, and 1 in z. Patches are 'inlet', 'outlet', 'walls', and 'frontAndBack'.
Fluid Properties (constant/transportProperties): Water at 20C. Set nu to 1e-6 m^2/s.
Porous Properties (system/fvOptions): Use a 'porosity' source term. Define a cellZone named 'porousZone' using topoSet. Set the Darcy-Forchheimer model with d = (1e8 1e8 1e8) and f = (0 0 0).
Turbulence: The flow is laminar. Set simulationType to laminar in constant/momentumTransport.
Initial Conditions (0/): Initialize U as uniform (0 0 0) and p as uniform 0.
Boundary Conditions (0/U and 0/p):
- inlet: U fixedValue uniform (0.1 0 0); p zeroGradient.
- outlet: U zeroGradient; p fixedValue uniform 0.
- walls: U noSlip; p zeroGradient.
- frontAndBack: empty.
Time Controls (system/controlDict): This is a steady-state simulation. Set startFrom latestTime; startTime 0; stopAt endTime; endTime 500; deltaT 1; writeControl timeStep; writeInterval 100.
