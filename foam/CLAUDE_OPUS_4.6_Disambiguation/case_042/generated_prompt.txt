The simulation models Rayleigh-Benard convection using OpenFOAM.

The solver is buoyantBoussinesqPimpleFoam (transient).

The domain is a 2D rectangle, 2 m wide and 1 m high (aspect ratio 2:1).

The mesh is generated with blockMesh using 80 cells in the x-direction and 40 cells in the y-direction (80x40 uniform grid).

The simulation is 2D, so the z-direction has 1 cell with empty boundary conditions on the front and back patches.

The bottom wall is a no-slip wall held at a fixed temperature of 300 K.

The top wall is a no-slip wall held at a fixed temperature of 299 K.

The left and right boundaries use periodic (cyclic) boundary conditions for all fields (U, T, and p_rgh).

The fluid uses the Boussinesq approximation with the following properties: g = 9.81 m/s² (acting in the negative y-direction), beta (thermal expansion coefficient) = 0.0034 1/K, Prandtl number Pr = 0.71, kinematic viscosity nu = 0.00928 m²/s, thermal diffusivity alpha = nu/Pr = 0.01307 m²/s, and reference temperature Tref = 299.5 K.

These properties yield a Rayleigh number Ra = (g * beta * deltaT * H^3) / (nu * alpha) of approximately 2500, with H = 1 m and deltaT = 1 K.

The turbulence model is set to laminar, as Ra = 2500 is far below the turbulent transition threshold.

The initial velocity field is uniform at U = (0 0 0) m/s.

The initial temperature field is T(x, y) = (300 - y) + 0.1 * sin(pi * x), which is a linear gradient from 300 K at the bottom to 299 K at the top plus a 0.1 K sinusoidal perturbation to trigger convection onset.

The initial p_rgh field is uniform at 0.

The simulation starts at time 0 and ends at time 500.

The initial time step deltaT is 0.1.

Adaptive time stepping is enabled with adjustTimeStep set to yes and maxCo set to 0.5.

The write interval is every 10 time units (writeControl is adjustableRunTime with writeInterval = 10).
