The simulation is the standard OpenFOAM pisoFoam lid-driven cavity tutorial, modified for Re = 5000 on a unit square domain.

Domain and Mesh:
The cavity is a unit square with side length L = 1 m and depth of one cell in the z-direction (quasi-2D).
The mesh is 100 x 100 x 1 uniform hexahedral cells generated with blockMesh.

Boundary Conditions:
The top wall (movingWall) has a fixed velocity of U = (1, 0, 0) m/s.
All other walls (fixedWalls) have a no-slip condition, U = (0, 0, 0) m/s.
The front and back planes are set to the empty type for a 2D simulation.
Pressure p is zeroGradient on all walls except one reference point or patch set to fixedValue 0.

Fluid Properties:
The kinematic viscosity nu is 2e-4 m²/s, set in constant/transportProperties.

Turbulence Modelling:
The simulation uses RAS with the kEpsilon turbulence model, configured in constant/momentumTransport (simulationType RAS, RAS model kEpsilon, turbulence on, printCoeffs on).
Wall functions are used for near-wall treatment.
nut uses nutkWallFunction on all walls, with uniform initial value 0.
k uses kqRWallFunction on all walls, with uniform initial value 1e-4.
epsilon uses epsilonWallFunction on all walls, with uniform initial value 1e-4.
Internal field initial conditions are k = 1e-4 and epsilon = 1e-4 (uniform).

Time Control:
The end time is 50 s.
The initial time step deltaT is 0.005 s.
Adaptive time stepping is enabled with adjustTimeStep yes and maxCo 0.5.
The write control is adjustableRunTime with a write interval of 0.5 s.

PISO Algorithm Settings:
nCorrectors is 2.
nNonOrthogonalCorrectors is 0.

Linear Solvers:
Pressure p uses GAMG with GaussSeidel smoother, tolerance 1e-06, relTol 0.01.
Velocity U, k, and epsilon use smoothSolver with symGaussSeidel smoother, tolerance 1e-06, relTol 0.1.

Numerical Schemes:
ddtSchemes default is Euler.
gradSchemes default is Gauss linear.
divSchemes: div(phi,U) uses Gauss linearUpwind grad(U) for stability at Re 5000.
divSchemes: div(phi,k) uses Gauss upwind.
divSchemes: div(phi,epsilon) uses Gauss upwind.
divSchemes: div((nuEff*dev2(T(grad(U))))) uses Gauss linear.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.
