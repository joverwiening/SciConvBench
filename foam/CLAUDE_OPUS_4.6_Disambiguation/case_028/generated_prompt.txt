The solver is interFoam (OpenFOAM VOF two-phase solver).
The simulation is transient and three-dimensional.
The domain is a cube from (0, 0, 0) to (1, 1, 1).
The mesh is a uniform structured hexahedral grid with 32 cells in each direction (32 x 32 x 32).
An obstacle (solid block) occupies the region from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
The obstacle surfaces exposed to the fluid are treated as no-slip walls.
Gravity is set to g = (0, 0, -9.81) m/s².
The water phase is initialized with alpha.water = 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
The water phase is initialized with alpha.water = 0 everywhere else (air fills the remainder).
Water density is 1000 kg/m³.
Water kinematic viscosity is 1.0e-6 m²/s.
Air density is 1 kg/m³.
Air kinematic viscosity is 1.48e-5 m²/s.
Surface tension between water and air is 0.07 N/m.
Turbulence modeling is laminar (no turbulence model).
The top face at z = 1 is an open atmosphere patch.
The remaining five faces (bottom z = 0, front y = 0, back y = 1, left x = 0, right x = 1) are no-slip wall patches.
On the atmosphere patch, pressure (p_rgh) uses a totalPressure condition with a reference value of 0.
On the atmosphere patch, velocity (U) uses a pressureInletOutletVelocity condition.
On the atmosphere patch, alpha.water uses an inletOutlet condition with an inlet value of 0 (air enters if there is inflow).
On wall patches, pressure (p_rgh) uses a fixedFluxPressure condition.
On wall patches, velocity (U) uses a noSlip condition.
On wall patches, alpha.water uses a zeroGradient condition.
The time step deltaT is 1.0e-3 s.
The end time is 0.1 s.
The write interval is 0.02 s.
