The simulation uses the interFoam solver from OpenFOAM for a transient, laminar, two-phase (water-air) dam-break with an obstacle.

The computational domain is a cube spanning from (0, 0, 0) to (1, 1, 1).

A rectangular obstacle occupies the region from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) and is carved out of the mesh directly in the blockMesh topology so that no fluid cells exist inside the obstacle volume.

The mesh is uniform with 32 cells in each direction (32 x 32 x 32) for the full cube, with the obstacle region removed by decomposing the domain into multiple blocks in blockMesh.

Gravity is set to g = (0, 0, -9.81) m/s².

The top face at z = 1 is assigned as an open atmosphere patch (totalPressure for p_rgh, pressureInletOutletVelocity for U, inletOutlet for alpha.water).

The remaining five outer faces (x = 0, x = 1, y = 0, y = 1, z = 0) are assigned as wall patches with no-slip boundary conditions (fixedValue uniform (0 0 0) for U, fixedFluxPressure for p_rgh, zeroGradient for alpha.water).

The obstacle surfaces exposed to the fluid are also wall patches with the same wall boundary conditions as above.

Water properties are density = 1000 kg/m³ and kinematic viscosity = 1.0e-6 m²/s.

Air properties are density = 1 kg/m³ and kinematic viscosity = 1.48e-5 m²/s.

Surface tension between water and air is 0.07 N/m.

The simulation runs as laminar with no turbulence model (simulationType laminar in momentumTransport or turbulenceProperties).

The initial condition for alpha.water is 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75) and 0 elsewhere, set using setFields with a boxToCell source.

The initial velocity field U is uniform (0 0 0).

The initial pressure field p_rgh is uniform 0.

The time step deltaT is 1e-3 s.

The end time is 0.1 s.

The write interval is 0.02 s.

The time stepping is fixed (adjustTimeStep is not enabled).

The solution algorithm is PIMPLE with nOuterCorrectors = 1 (effectively PISO mode), nCorrectors = 3, and nNonOrthogonalCorrectors = 1.

The alpha.water sub-cycling uses nAlphaCorr = 2, nAlphaSubCycles = 1, and cAlpha = 1.

Time schemes use Euler (first-order implicit).

Gradient schemes use Gauss linear.

Divergence schemes use Gauss vanLeer for div(phi,alpha), Gauss linearUpwind grad(U) for div(rhoPhi,U), and Gauss linear for other divergence terms.

Laplacian schemes use Gauss linear corrected.

Interpolation schemes use linear.

Surface normal gradient schemes use corrected.

The pressure equation (p_rgh) is solved using GAMG with DIC smoother and tolerance 1e-8, relative tolerance 0.01, with a final solve tolerance of 1e-8 and relative tolerance 0.

The velocity equation (U) is solved using smoothSolver with GaussSeidel smoother, tolerance 1e-6, and relative tolerance 0.

The alpha.water equation uses smoothSolver with GaussSeidel smoother, tolerance 1e-8, and relative tolerance 0.

The write format is ascii.

The write precision is 6.

The time format is general.

The run format is general with time precision 6.
