Use standard numerical schemes appropriate for interFoam VOF simulations, selecting robust and accurate defaults.

The simulation domain is quasi-2D with dimensions 0.05 m (x) x 0.2 m (y) x 0.01 m (z).
The mesh is a uniform Cartesian grid with 50 cells in x, 200 cells in y, and 1 cell in z.
The solver is interFoam from OpenFOAM.
The simulation models a single air bubble rising in quiescent water using the Volume of Fluid (VOF) method.

Water properties: density = 1000 kg/m³, kinematic viscosity = 1e-6 m²/s.
Air properties: density = 1.2 kg/m³, kinematic viscosity = 1.5e-5 m²/s.
Surface tension coefficient sigma = 0.072 N/m.
Gravity vector is (0, -9.81, 0) m/s².

The bubble has an initial diameter of 0.01 m.
The bubble is initialized using sphereToCell in setFieldsDict with center at (0.025, 0.025, 0.005).
The default field value for alpha.water is 1 (water everywhere), and the sphereToCell region sets alpha.water to 0 (air inside the bubble).

The bottom boundary is a noSlip wall for velocity U, zeroGradient for p_rgh, and zeroGradient for alpha.water.
The top boundary uses inletOutlet for U, p_rgh, and alpha.water to allow fluid to exit.
The left and right side walls are noSlip walls for U, zeroGradient for p_rgh, and zeroGradient for alpha.water.
The front and back z-normal faces use the empty boundary condition for quasi-2D simulation.

The turbulence model is laminar (no turbulence model).

The simulation start time is 0 s.
The simulation end time is 2.0 s.
The initial time step deltaT is 1e-4 s.
Adaptive time-stepping is enabled with a maximum Courant number maxCo of 0.4.
Write control is by timeStep with a write interval of 100.

Use Euler for the time discretization scheme (ddt).
Use Gauss linear for gradient schemes (grad).
Use Gauss linear corrected for Laplacian schemes.
Use Gauss vanLeer for divergence of alpha.water (div(phi,alpha)).
Use Gauss linearUpwind grad(U) for the divergence of velocity (div(rhoPhi,U)).
Use linear for interpolation schemes.
Use corrected for surface normal gradient schemes (snGrad).
Use MULES for the VOF interface compression as handled by interFoam defaults.

The velocity field U is initialized to (0 0 0) everywhere.
The pressure field p_rgh is initialized to 0.
