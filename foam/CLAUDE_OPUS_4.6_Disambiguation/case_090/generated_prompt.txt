The simulation uses simpleFoam for steady incompressible turbulent flow in a 2D planar diffuser.

The solver is simpleFoam.

The domain is a 2D planar diffuser of length 1.0 m.
The inlet is at x=0 with a full height of 0.10 m (y = 0 to 0.10).
The outlet is at x=1 with a full height of 0.20 m (y = 0 to 0.20).
The bottom wall is flat at y = 0 from x=0 to x=1.
The top wall is a straight line from (0, 0.10) to (1, 0.20).
The out-of-plane thickness is 0.01 m in the z-direction.

The block vertices are (0, 0, 0), (1, 0, 0), (1, 0.20, 0), (0, 0.10, 0), (0, 0, 0.01), (1, 0, 0.01), (1, 0.20, 0.01), (0, 0.10, 0.01).
The geometry is a single hex block.

The mesh has 200 cells in the x-direction, 40 cells in the y-direction, and 1 cell in the z-direction.
Double-sided grading is applied in the y-direction to cluster cells near both the bottom and top walls, using an expansion ratio of approximately 4 (cells at the center are about 4 times larger than cells at the walls, achieved via a simpleGrading entry such as ((0.5 0.5 0.25)(0.5 0.5 4)) or equivalent).

The front and back boundaries (z=0 and z=0.01 faces) are type empty.
The bottom wall (y=0) is type wall.
The top wall (sloped surface) is type wall.
The inlet (x=0) is type patch.
The outlet (x=1) is type patch.

The fluid has a kinematic viscosity nu of 1.5e-5 m^2/s, set in constant/transportProperties.

The turbulence model is kOmegaSST configured as a RAS model in constant/momentumTransport.

Inlet boundary conditions are as follows.
U is fixedValue uniform (5 0 0).
p is zeroGradient.
k is fixedValue uniform 0.09375 (computed from k = 1.5*(U*I)^2 = 1.5*(5*0.05)^2).
omega is fixedValue uniform approximately 44.3 (computed assuming a turbulent viscosity ratio of nu_t/nu = 10, giving omega = k / (nu_t) = 0.09375 / (10 * 1.5e-5) = 625; alternatively using the hydraulic diameter approach with L_mix = 0.07 * 0.10 = 0.007 m, giving omega = sqrt(k) / (0.09 * L_mix) = sqrt(0.09375) / (0.09 * 0.007) ≈ 486). Use the hydraulic diameter approach: set omega at the inlet to approximately 486 s^-1 with a mixing length scale of 0.07 times the inlet height (0.10 m).

Outlet boundary conditions are as follows.
U is zeroGradient.
p is fixedValue uniform 0.
k is zeroGradient.
omega is zeroGradient.

Wall boundary conditions (bottom and top walls) are as follows.
U is noSlip (fixedValue uniform (0 0 0)).
p is zeroGradient.
k uses kqRWallFunction with value uniform 0.09375.
omega uses omegaWallFunction with value uniform 486.
nut uses nutkWallFunction with value uniform 0.

Internal field initial values are U = (5 0 0), p = 0, k = 0.09375, omega = 486, nut = 0.

The controlDict settings are as follows.
application is simpleFoam.
startFrom is startTime.
startTime is 0.
stopAt is endTime.
endTime is 2000.
deltaT is 1.
writeControl is timeStep.
writeInterval is 200.
writeFormat is ascii.
purgeWrite is 0.
writePrecision is 6.
timeFormat is general.
timePrecision is 6.
runTimeModifiable is true.

The fvSchemes use standard simpleFoam defaults: steadyState for ddtSchemes, Gauss linearUpwind grad(U) for divSchemes of U, Gauss linear for laplacianSchemes and gradSchemes, and corrected for snGradSchemes.

The fvSolution uses SIMPLE algorithm with residual tolerances of 1e-6 for p and 1e-5 for U, k, and omega. Relaxation factors are 0.3 for p and 0.7 for U, k, and omega. The pressure solver is GAMG with GaussSeidel smoother. The velocity and turbulence solvers are smoothSolver with GaussSeidel smoother.
