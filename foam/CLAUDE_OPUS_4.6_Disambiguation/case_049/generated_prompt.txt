This is a 2D dam break simulation using OpenFOAM's interFoam solver, modeling a water column collapsing under gravity in a tank of air.

The tank domain is 0.584m wide and 0.584m tall.
The water column is 0.146m wide and 0.292m tall, located in the bottom-left corner of the tank.
The simulation is 2D.

The mesh is a uniform 58x58 grid created using blockMesh.
The mesh has one cell in the z-direction to enforce the 2D condition.

The solver is interFoam.
The turbulence model is laminar.

Gravity acts in the negative y-direction at 9.81 m/s².

Water properties: density (rho) = 1000 kg/m³, kinematic viscosity (nu) = 1e-6 m²/s.
Air properties: density (rho) = 1 kg/m³, kinematic viscosity (nu) = 1.48e-5 m²/s.
Surface tension (sigma) between water and air is 0.07 N/m.

The transport model for both phases is Newtonian.

The start time is 0 and the end time is 2.
Use adjustable time stepping with adjustTimeStep yes, maxCo 0.5, and maxAlphaCo 0.5.
Set writeControl to timeStep and writeInterval to 20.

The boundary patches are: leftWall, rightWall, lowerWall, atmosphere, and frontAndBack.
The leftWall patch is on the left side of the tank (x = 0).
The rightWall patch is on the right side of the tank (x = 0.584).
The lowerWall patch is on the bottom of the tank (y = 0).
The atmosphere patch is on the top of the tank (y = 0.584).
The frontAndBack patch covers the front and back faces and is of type empty.

Boundary conditions for velocity (U):
The atmosphere patch uses pressureInletOutletVelocity with a value of uniform (0 0 0).
The leftWall, rightWall, and lowerWall patches use noSlip.
The frontAndBack patch uses empty.

Boundary conditions for pressure (p_rgh):
The atmosphere patch uses totalPressure with p0 uniform 0.
The leftWall, rightWall, and lowerWall patches use fixedFluxPressure.
The frontAndBack patch uses empty.

Boundary conditions for alpha.water:
The atmosphere patch uses inletOutlet with inletValue uniform 0 and value uniform 0.
The leftWall, rightWall, and lowerWall patches use zeroGradient.
The frontAndBack patch uses empty.

The initial condition for alpha.water is set using setFields.
The default field value for alpha.water is 0 (air everywhere).
A boxToCell region from (0 0 -1) to (0.146 0.292 1) sets alpha.water to 1 (water in the bottom-left corner).

The initial velocity field U is uniform (0 0 0).
The initial pressure field p_rgh is uniform 0.
