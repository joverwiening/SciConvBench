The simulation is a 2D Rayleigh-Bénard convection problem in a rectangular cavity using OpenFOAM.

Solver: buoyantBoussinesqSimpleFoam (steady-state).

Geometry: rectangular cavity, 1 m wide, 0.25 m tall, 0.01 m out-of-plane thickness.

Mesh: 80 cells in the width direction, 20 cells in the height direction, 1 cell in the out-of-plane direction, uniform grading (simpleGrading (1 1 1)).

Patches: bottomHot (bottom wall), topCold (top wall), sideWalls (left and right walls), frontAndBack (front and back planes).

Turbulence model: laminar.

Gravity: (0 -9.81 0).

Fluid properties (water-like):
Kinematic viscosity (nu): 1e-6 m²/s.
Prandtl number (Pr): 7.0.
Thermal expansion coefficient (beta): 2.0e-4 1/K.
Reference temperature (TRef): 300 K.
Reference density (rho0): 1000 kg/m³.
Thermal diffusivity is derived as nu/Pr = 1.4286e-7 m²/s.

Boundary conditions for temperature (T):
bottomHot: fixedValue uniform 310 K.
topCold: fixedValue uniform 290 K.
sideWalls: zeroGradient.
frontAndBack: empty.

Boundary conditions for velocity (U):
bottomHot: fixedValue uniform (0 0 0).
topCold: fixedValue uniform (0 0 0).
sideWalls: fixedValue uniform (0 0 0).
frontAndBack: empty.

Boundary conditions for p_rgh:
bottomHot: fixedFluxPressure, value uniform 0.
topCold: fixedFluxPressure, value uniform 0.
sideWalls: fixedFluxPressure, value uniform 0.
frontAndBack: empty.

Initial conditions:
U: uniform (0 0 0).
T: uniform 300 K.
p_rgh: uniform 0.

Time control:
endTime: 1000.
deltaT: 1.
writeInterval: 100.
writeControl: timeStep.

SIMPLE controls:
nNonOrthogonalCorrectors: 0.
Residual control: p_rgh 1e-6, U 1e-6, T 1e-6.

Relaxation factors:
p_rgh: 0.3.
U: 0.7.
T: 0.7.

Linear solvers:
p_rgh: GAMG.
U: smoothSolver.
T: smoothSolver.

Numerical schemes:
ddtSchemes: steadyState.
gradSchemes: Gauss linear.
divSchemes: div(phi,U) bounded Gauss upwind, div(phi,T) bounded Gauss upwind.
laplacianSchemes: Gauss linear corrected.
