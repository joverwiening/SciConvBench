Set up a steady-state incompressible pipe flow case using simpleFoam in OpenFOAM.
The pipe is 1 meter long with a diameter of 0.02 m (radius R = 0.01 m).
The simulation is laminar with no turbulence model.
The kinematic viscosity is nu = 1e-6 m^2/s, set in constant/transportProperties.
Use blockMesh to create a structured axisymmetric 5-degree wedge mesh.
The mesh has 100 cells in the axial direction, 20 cells in the radial direction, and 1 cell in the circumferential direction.
The blockMesh patches are: inlet at x = 0, outlet at x = L, pipeWall at r = R, axis at r = 0 with patch type symmetryAxis, and wedgeFront and wedgeBack with patch type wedge.
The inlet boundary condition for U is fixedValue uniform (0.1 0 0).
The inlet boundary condition for p is zeroGradient.
The outlet boundary condition for U is zeroGradient.
The outlet boundary condition for p is fixedValue uniform 0.
The pipeWall boundary condition for U is noSlip.
The pipeWall boundary condition for p is zeroGradient.
The wedgeFront and wedgeBack boundary conditions for both U and p are type wedge.
The axis boundary condition for both U and p is type symmetryAxis.
The endTime is 1000.
The deltaT is 1.
The writeInterval is 100.
The writeControl is timeStep.
Use GAMG solver for p with tolerance 1e-6, relTol 0.01, and smoother GaussSeidel.
Use smoothSolver for U with tolerance 1e-6, relTol 0.1, and smoother symGaussSeidel.
Use relaxation factor 0.3 for p.
Use relaxation factor 0.7 for U.
Use residual control convergence criteria of 1e-5 for both p and U in the SIMPLE dictionary.
Set nNonOrthogonalCorrectors to 1 in the SIMPLE dictionary.
Use Gauss linear for gradient schemes.
Use Gauss linearUpwind grad(U) for the divergence scheme of div(phi,U).
Use Gauss linear corrected for Laplacian schemes.
Use linear for interpolation schemes.
Use corrected for snGrad schemes.
