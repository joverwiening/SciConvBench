The simulation is a classic Sod shock tube problem using rhoCentralFoam in OpenFOAM.

The domain is a 3D box from (0 0 0) to (1 0.1 0.1), representing a 1 m long tube.
Use blockMesh to generate the mesh with 400 cells in x, 1 cell in y, and 1 cell in z (400 × 1 × 1).

The diaphragm is located at x = 0.5 m.
Left state (x < 0.5): p = 100000 Pa, T = 348.4 K, U = (0 0 0).
Right state (x >= 0.5): p = 10000 Pa, T = 278.7 K, U = (0 0 0).
Density is not set directly; it follows from the perfect gas equation of state using the specified p and T.
Use setFields to initialize the left and right states.

Boundary conditions for leftEnd (x = 0) and rightEnd (x = 1) are wall (reflecting).
U is set to slip on both ends.
p is set to zeroGradient on both ends.
T is set to zeroGradient on both ends.
All lateral faces (top, bottom, front, back) are set to empty to enforce 1D behavior.

The gas is ideal air with molecular weight 28.9 kg/kmol and Cp = 1005 J/(kg·K).
The ratio of specific heats gamma = 1.4 follows from Cp and the specific gas constant.
The thermophysical model uses hePsiThermo with perfectGas EOS, hConst for enthalpy, and const for transport.
Viscosity mu = 0 (inviscid simulation).
Prandtl number Pr = 0.71.

The end time is 0.007 s.
The initial time step deltaT is 1e-6 s.
The write interval is 0.0005 s.
Time step adjustment is enabled with maxCo = 0.5.

Time integration uses the Euler scheme.
Divergence schemes use Gauss vanLeer (standard rhoCentralFoam practice).
Gradient schemes use Gauss linear.
Laplacian schemes use Gauss linear corrected.
Interpolation schemes use linear.
Surface normal gradient schemes use corrected.
