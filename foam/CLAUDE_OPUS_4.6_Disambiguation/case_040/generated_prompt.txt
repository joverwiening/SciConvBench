The simulation uses OpenFOAM's interFoam solver to model transient two-phase (water-air) flow through a porous dam in 2D.

The computational domain is 5 m (x) by 2 m (y) by 0.1 m (z, single cell depth for 2D simulation).

The mesh is generated with blockMesh using 250 cells in x, 100 cells in y, and 1 cell in z.

A cellZone named porousDam is defined covering the region from x = 2 m to x = 3 m over the full height y = 0 m to y = 2 m.

The porous dam is modeled using an explicitPorositySource in fvOptions applied to the porousDam cellZone with Darcy-Forchheimer coefficients: d = (1e6 1e6 0) and f = (100 100 0).

The initial condition for alpha.water is 1 (water) inside the box from (0, 0, -1) to (1, 1.5, 1), meaning water occupies x = 0 to 1 m and y = 0 to 1.5 m.

Everywhere else alpha.water is initialized to 0 (air).

Gravity is set to (0 -9.81 0) m/s².

Water properties are density 998 kg/m³ and kinematic viscosity 1e-06 m²/s.

Air properties are density 1 kg/m³ and kinematic viscosity 1.48e-05 m²/s.

Surface tension between water and air is 0.07 N/m.

The simulation is laminar (no turbulence model).

The leftWall, rightWall, and bottomWall patches are solid walls with U set to noSlip, p_rgh set to fixedFluxPressure, and alpha.water set to zeroGradient.

The atmosphere patch (top boundary) has U set to pressureInletOutletVelocity with inletValue uniform (0 0 0), p_rgh set to totalPressure with p0 uniform 0, and alpha.water set to inletOutlet with inletValue uniform 0 and value uniform 0.

The frontAndBack patches (z-normal faces) use the empty boundary condition for all fields.

The simulation end time is 10 s.

The initial time step deltaT is 0.001 s.

Adaptive time stepping is enabled with adjustTimeStep yes and maxCo 0.5.
