Use blockMesh to generate a uniform 50 x 50 x 1 mesh.

The Prandtl number is 0.71, giving thermal diffusivity alpha = nu / Pr.
The thermal expansion coefficient beta is 3.33e-3 1/K.
The reference temperature T0 is 293.5 K.
The reference density rho0 is 1.0 kg/m^3.
Gravity is (0, -9.81, 0) m/s^2.
The target Rayleigh number is approximately 1e5.
The bottom wall temperature is fixed at 294.0 K.
The top wall temperature is fixed at 293.0 K.
The temperature difference deltaT is 1 K.
The left and right side walls use zeroGradient for temperature (adiabatic).
All four walls (bottom, top, left, right) use no-slip for velocity, U = (0 0 0).
All four walls use fixedFluxPressure for p_rgh.
The front and back faces use the empty boundary condition for all fields.
The solver runs in steady-state mode with deltaT = 1.
The end time is 5000 iterations.
The write interval is 500.
