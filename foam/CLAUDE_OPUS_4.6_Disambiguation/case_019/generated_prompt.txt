The simulation is a 2D incompressible unsteady laminar flow past a circular cylinder using OpenFOAM.

The domain is a rectangular box extending from x = -5 m to x = 5 m in the streamwise direction, y = -1.5 m to y = 2.5 m in the cross-stream direction, and z = -1 m to z = 1 m in the spanwise direction.

A circular cylinder of diameter 2 m is centered at the origin (x = 0 m, y = 0 m).

The solver is pimpleFoam.

The simulation start time is 0 s.

The simulation end time is 0.5 s.

The time step deltaT is 0.0025 s.

The write interval is 0.05 s.

The time integration scheme is backward (second-order implicit).

The gradient schemes use Gauss linear.

The divergence schemes use Gauss linearUpwind for velocity convection and Gauss linear for other terms.

The Laplacian schemes use Gauss linear corrected.

The interpolation schemes use linear.

The snGrad schemes use corrected.

The inlet boundary (left face at x = -5 m) has a fixed velocity U = (1 0 0) m/s and zeroGradient for pressure.

The outlet boundary (right face at x = 5 m) has zeroGradient for velocity and fixedValue p = 0 for pressure.

The top boundary (face at y = 2.5 m) has noSlip for velocity and zeroGradient for pressure.

The bottom boundary (face at y = -1.5 m) has noSlip for velocity and zeroGradient for pressure.

The cylinder wall has noSlip for velocity and zeroGradient for pressure.

The front and back faces (z = -1 m and z = 1 m) are set to empty for a 2D simulation.

The initial velocity field is uniform U = (0 0 0) m/s.

The initial pressure field is uniform p = 0.

The flow is laminar using the generalisedNewtonian viscosity model.

The viscosity model is CrossPowerLaw with nu0 = 0.01 m^2/s, nuInf = 10 m^2/s, m = 0.4, and n = 3.

The mesh resolution uses approximately 50 cells per cylinder diameter near the cylinder surface, with grading to coarsen away from the cylinder, resulting in roughly 20000 to 30000 cells total.

The mesh is generated using blockMesh with an O-grid topology around the cylinder for good cell quality.
