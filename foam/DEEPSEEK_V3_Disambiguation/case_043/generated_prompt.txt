Simulate natural convection in a closed room using the buoyantPimpleFoam solver.
The room is a closed rectangular cavity.
Place a heat source on the floor.
Set the heat source temperature to a fixed value of 323 K.
Set the boundary condition for the walls and ceiling to adiabatic (zeroGradient) for temperature.
Set the initial temperature of the air inside the room to a uniform 293 K.
Use air as the working fluid with its standard properties.
Assume the Boussinesq approximation is valid for buoyancy.
Use appropriate initial and boundary conditions for pressure and velocity fields (e.g., no-slip for velocity, fixedFluxPressure for pressure on walls).
Run the simulation until a steady-state or statistically steady condition is reached.
