Simulate transient, compressible, natural convection from a heat source in a 2D sealed room using buoyantPimpleFoam.

Solver: buoyantPimpleFoam

Geometry & Mesh: A 2D room of 4m width x 3m height. A 1m wide heat source is centered on the floor. Use blockMesh to create a non-uniform mesh of 80x60 cells, refined near the heat source and walls. Patches are 'floorHeater', 'floorInsulated', 'walls', 'ceiling', and 'frontAndBack'.

Thermophysical Properties (thermophysicalProperties dictionary): The fluid is air. Use 'hePsiThermo' with the 'perfectGas' equation of state and 'sutherland' transport model. MolWeight = 28.9 kg/kmol; Cp = 1005 J/(kg*K); Sutherland coeffs: As=1.479e-06, Ts=110.4 K.

Initial Conditions (0/ directory): The room is initially quiescent (U = (0 0 0) m/s) at standard atmospheric pressure (p = 101325 Pa) and uniform temperature (T = 293 K).

Boundary Conditions (0/ directory):
- floorHeater: U = noSlip; T = fixedValue, value 323 K; p_rgh = fixedFluxPressure.
- floorInsulated, walls, ceiling: U = noSlip; T = zeroGradient (adiabatic); p_rgh = fixedFluxPressure.
- frontAndBack: type empty.

Gravity: Set g = (0 -9.81 0) m/s^2 in the 'g' file.

Time Controls (controlDict): startTime = 0; endTime = 120; deltaT = 0.02; writeInterval = 2; maxCo = 0.7; adjustTimeStep = yes.
