Set up a steady-state incompressible turbulent pipe flow simulation using the simpleFoam solver.
The pipe geometry is a straight cylinder with a length of 1 meter and a diameter of 0.02 meters.
Use a blockMeshDict to generate a hexahedral mesh for the pipe geometry.
Apply a fixedValue boundary condition for velocity at the inlet, set to uniform (0.1 0 0) m/s.
Apply a zeroGradient boundary condition for pressure at the inlet.
Apply a fixedValue boundary condition for pressure at the outlet, set to uniform 0 Pa.
Apply a zeroGradient boundary condition for velocity at the outlet.
Apply a no-slip wall boundary condition (fixedValue (0 0 0)) for velocity on the pipe walls.
Apply a zeroGradient boundary condition for pressure on the pipe walls.
Set the kinematic viscosity (transportProperties) to 1e-6 m²/s.
Select and configure a turbulence model (e.g., k-epsilon, k-omega SST) in the turbulenceProperties dictionary.
Initialize the flow field with the inlet velocity.
Run the simpleFoam solver until the flow field reaches a steady-state convergence.
