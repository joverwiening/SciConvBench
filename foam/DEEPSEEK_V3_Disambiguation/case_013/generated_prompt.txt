Set up a laminar counter-flow diffusion flame simulation using the reactingFoam solver.
Use a 2-D opposed-jet configuration.
The domain is a rectangular box.
The x-coordinate spans from 0 to 0.02 meters.
The y-coordinate spans from -0.01 to 0.01 meters.
The z-coordinate spans from -0.01 to 0.01 meters.
Use a structured mesh with 100 cells in the x-direction.
Use 40 cells in the y-direction.
Use 1 cell in the z-direction.
Name the left boundary (x=0) as "fuel".
Name the right boundary (x=0.02) as "air".
Name the top and bottom boundaries as "outlet".
Set the frontAndBack boundary type to "empty".
At the fuel inlet, inject a pure methane (CH4) stream.
Set the methane mass fraction (Y_CH4) at the fuel inlet to 1.0.
Set the fuel inlet temperature to 293 Kelvin.
At the air inlet, supply an oxidizer stream of air.
Set the oxygen mass fraction (Y_O2) at the air inlet to 0.23.
Set the nitrogen mass fraction (Y_N2) at the air inlet to 0.77.
Set the air inlet temperature to 293 Kelvin.
Initialize the entire domain with a uniform temperature of 2000 Kelvin at time zero.
Set the velocity at the fuel boundary to 0.1 meters per second in the positive x-direction.
Set the velocity at the air boundary to -0.1 meters per second in the x-direction.
Use the "EulerImplicit" chemistry type.
Use the "Rosenbrock43" ODE solver.
Use a laminar combustion model.
Use laminar momentum transport.
Use the compressible finite-rate chemistry formulation.
Use the "hePsiThermo" thermodynamic class.
Use the "coefficientWilkeMultiComponentMixture" for mixture properties.
