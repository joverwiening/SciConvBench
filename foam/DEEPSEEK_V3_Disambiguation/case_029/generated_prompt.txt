Run a transient laminar two-phase dam-break simulation using the interFoam solver.
The domain is a cube from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 cells in each direction (32 x 32 x 32).
Place a rectangular obstacle spanning from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set the acceleration due to gravity vector to (0, 0, -9.81).
Initialize the water phase (alpha.water) as 1.0 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
Initialize the water phase (alpha.water) as 0.0 everywhere else in the domain.
Set the time step (deltaT) to 0.001 seconds.
Set the simulation end time to 0.1 seconds.
Set the output write interval to 0.02 seconds.
Use water as the first fluid with a density of 1000 kg/m³ and a kinematic viscosity of 1.0e-6 m²/s.
Use air as the second fluid with a density of 1 kg/m³ and a kinematic viscosity of 1.48e-5 m²/s.
