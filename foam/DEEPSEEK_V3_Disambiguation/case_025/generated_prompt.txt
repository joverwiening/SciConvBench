Use the interFoam solver for a transient laminar two-phase dam-break simulation.
The simulation domain is a cube from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 cells in the x, y, and z directions.
Define an obstacle region as a rectangular prism from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set the acceleration due to gravity vector g to (0, 0, -9.81).
Assign the top face (z=1) as a patch named "open" with a boundary condition type for an open atmosphere.
Assign the remaining five faces (all faces except z=1) as patches named "walls" with wall boundary conditions.
Assign the obstacle faces as a patch named "obstacle" with wall boundary conditions.
Initialize the water phase (alpha.water) with a value of 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
Initialize the water phase (alpha.water) with a value of 0 everywhere else in the domain.
Set the simulation time step deltaT to 0.001 seconds.
Set the simulation end time endTime to 0.1 seconds.
Set the output write interval writeInterval to 0.02 seconds.
