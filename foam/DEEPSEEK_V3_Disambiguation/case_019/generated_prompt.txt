Simulate a 2D laminar flow past a circular cylinder.
The computational domain is a rectangular box.
The domain extends from x = -5 m to x = 5 m in the streamwise direction.
The domain extends from y = -1.5 m to y = 2.5 m in the cross-stream direction.
The domain extends from z = -1 m to z = 1 m, with the front and back faces treated as empty for a 2D simulation.
Place a circular cylinder with a diameter of 2 m.
Center the cylinder at the origin (x = 0 m, y = 0 m).
Apply an inlet boundary condition at the left face (x = -5 m).
Set the inlet velocity U to (1, 0, 0) m/s.
Apply an outlet boundary condition at the right face (x = 5 m).
Set the outlet velocity to a zeroGradient condition.
Set the outlet pressure p to 0 Pa as a reference.
Apply wall boundary conditions at the top (y = 2.5 m) and bottom (y = -1.5 m) faces.
Set the wall velocity U to a noSlip condition.
Set the wall pressure p to a zeroGradient condition.
Apply a wall boundary condition on the cylinder surface.
Set the cylinder wall velocity U to a noSlip condition.
Set the cylinder wall pressure p to a zeroGradient condition.
Initialize the flow field as quiescent.
Set the initial velocity field U to (0, 0, 0) m/s.
Set the initial pressure field p to 0 Pa.
Use a laminar flow model.
Use the generalisedNewtonian viscosity model.
Use the crosspowerlaw model within the generalisedNewtonian framework.
Set the crosspowerlaw parameter nuInf to 10.
Set the crosspowerlaw parameter m to 0.4.
Set the crosspowerlaw parameter n to 3.
Set the kinematic viscosity to 0.01 m^2/s.
