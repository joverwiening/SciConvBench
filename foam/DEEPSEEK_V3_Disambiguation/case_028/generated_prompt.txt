Run a transient two-phase dam-break simulation.
The simulation domain is a cube from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 cells in each direction (32 x 32 x 32).
Place a rectangular obstacle from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set the gravitational acceleration vector to (0, 0, -9.81).
Initialize the water phase as a rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
Set the water volume fraction (alpha.water) to 1 inside the water column and 0 elsewhere.
Use a time step (deltaT) of 0.001 seconds.
Set the simulation end time (endTime) to 0.1 seconds.
Set the output write interval (writeInterval) to 0.02 seconds.
Set the water density to 1000 kg/m³.
Set the water kinematic viscosity to 1.0e-6 m²/s.
Set the air density to 1 kg/m³.
Set the air kinematic viscosity to 1.48e-5 m²/s.
Set the surface tension coefficient between water and air to 0.07 N/m.
Set the contact angle for the water-air interface on the obstacle surfaces to 90 degrees.
