Problem: 2D incompressible laminar lid-driven cavity flow.
Solver: icoFoam
Geometry: A square cavity of size 0.1m x 0.1m. The case is 2D, so the z-dimension is one cell thick with 'empty' boundary conditions.
Mesh: Use blockMesh to create a uniform Cartesian mesh of 20x20 cells. The blockMeshDict should define vertices at (0 0 0), (0.1 0 0), (0.1 0.1 0), (0 0.1 0) and extrude by 0.01m in z. Patches should be 'movingWall' (top, y=0.1), 'fixedWalls' (left, right, bottom), and 'frontAndBack' (z faces).
Physical Properties: In constant/transportProperties, set kinematic viscosity 'nu' to 0.001 m^2/s.
Initial Conditions: In the 0/ directory, initialize velocity 'U' to uniform (0 0 0) and pressure 'p' to uniform 0.
Boundary Conditions:
- For U (in 0/U): 'movingWall' is fixedValue uniform (1 0 0); 'fixedWalls' is noSlip; 'frontAndBack' is empty.
- For p (in 0/p): 'movingWall' and 'fixedWalls' are zeroGradient; 'frontAndBack' is empty.
Time Controls: In system/controlDict, set startTime to 0, endTime to 0.5, deltaT to 0.002, writeControl to timeStep, and writeInterval to 20.
