Problem: Sod shock tube (ideal gas) with a diaphragm at x=0.5 m; run until the right-going shock reflects from the end wall.

Solver: rhoCentralFoam (density-based shock-capturing compressible solver)

Geometry: 1 m long tube; use a very thin 3D box to model 1D:
- x: 0 -> 1 m
- y: 0 -> 0.1 m
- z: 0 -> 0.1 m

Mesh: blockMesh (400 1 1). Patches:
- leftEnd (x=0)
- rightEnd (x=1)
- sidePatches (all faces in y and z directions) set to empty to enforce 1D.

Thermophysical properties (constant/thermophysicalProperties): ideal air
- thermoType: hePsiThermo; mixture pureMixture; transport const; thermo hConst; equationOfState perfectGas; specie specie; energy sensibleInternalEnergy
- set Cp ~ 1005 J/kg/K; molWeight ~ 28.9 kg/kmol (gamma follows from Cp and R)

Initial conditions (system/setFieldsDict) using p and T (so rho is consistent via perfectGas):
- Region x < 0.5:
  - p = 100000 Pa
  - T = 348.4 K   (so rho ~ p/(R*T) ~ 1.0 kg/m^3 with R ~ 287)
  - U = (0 0 0)
- Region x > 0.5:
  - p = 10000 Pa
  - T = 278.7 K   (so rho ~ 0.125 kg/m^3)
  - U = (0 0 0)

Boundary conditions:
- leftEnd and rightEnd: wall with slip velocity (to mimic inviscid reflection)
  - U slip
  - p zeroGradient
  - T zeroGradient
- sidePatches: empty

Time controls: startTime 0; endTime 0.007 s; deltaT 1e-6 s; writeControl runTime; writeInterval 0.0005 s.
