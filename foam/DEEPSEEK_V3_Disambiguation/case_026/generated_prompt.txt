Run a transient laminar two-phase dam-break simulation.
Use the Volume of Fluid (VOF) method to model the phases.
The domain is a cubic box from coordinates (0, 0, 0) to (1, 1, 1).
Set the acceleration due to gravity vector g to (0, 0, -9.81).
Define the top face, where z=1, as an open atmosphere boundary patch.
Define the remaining five faces of the cube as wall boundaries.
Define the first fluid phase as water.
Set the density of water to 1000 kg/m^3.
Set the kinematic viscosity of water to 1.0e-6 m^2/s.
Define the second fluid phase as air.
Set the density of air to 1 kg/m^3.
Set the kinematic viscosity of air to 1.48e-5 m^2/s.
Set the surface tension coefficient between the phases to 0.07 N/m.
Initialize the water column as a rectangular prism.
Set the volume fraction of water (alpha.water) to 1 inside the box from (0, 0, 0) to (0.6, 0.1875, 0.75).
Set the volume fraction of water to 0 everywhere else in the domain.
Place one rectangular prism obstacle within the domain.
The obstacle spans from coordinates (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set the simulation time step (deltaT) to 0.001 seconds.
Set the simulation end time (endTime) to 0.1 seconds.
Set the output write interval (writeInterval) to 0.02 seconds.
