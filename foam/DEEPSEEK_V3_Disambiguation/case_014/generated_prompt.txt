Set up a laminar counter-flow diffusion flame simulation using the reactingFoam solver.
The simulation uses a 2-D opposed-jet configuration.
The computational domain is a rectangular box.
The x-dimension spans from 0 to 0.02 meters.
The y-dimension spans from -0.01 to 0.01 meters.
The z-dimension spans from -0.01 to 0.01 meters.
The mesh uses 100 cells in the x-direction.
The mesh uses 40 cells in the y-direction.
The mesh uses 1 cell in the z-direction.
The left boundary at x=0 is named "fuel".
The right boundary at x=0.02 is named "air".
The top and bottom boundaries are named "outlet".
The front and back boundaries are of type "empty".
Initialize the entire domain with a uniform temperature of 2000 Kelvin at time zero.
Set the velocity at the fuel boundary to 0.1 m/s in the positive x-direction.
Set the velocity at the air boundary to -0.1 m/s in the x-direction.
Use the EulerImplicit chemistry type.
Use the Rosenbrock43 ODE solver.
Use a laminar combustion model.
Use laminar momentum transport.
Use compressible finite-rate chemistry.
Use the hePsiThermo thermo model.
Use the coefficientWilkeMultiComponentMixture for mixture properties.
Use the Sutherland model for transport properties.
Use JANAF for thermodynamics.
Use a fixed time step of 1e-4 seconds.
Set the simulation end time to 0.5 seconds.
Write result fields at an interval of every 0.05 seconds.
