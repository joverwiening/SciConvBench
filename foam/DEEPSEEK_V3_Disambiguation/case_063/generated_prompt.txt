Set up the pitzDaily case as a backward-facing step simulation.
Use the standard k-epsilon RAS turbulence model.
Set the inlet velocity boundary condition to a uniform value of (10 0 0) m/s.
Set the kinematic viscosity (nu) of the fluid to 1e-5 m²/s.
Set the outlet pressure boundary condition to type fixedValue with a uniform value of 0.
Set the inlet turbulence kinetic energy (k) boundary condition to a uniform value of 0.0375.
Set the inlet turbulence dissipation rate (epsilon) boundary condition to a uniform value of 0.875.
