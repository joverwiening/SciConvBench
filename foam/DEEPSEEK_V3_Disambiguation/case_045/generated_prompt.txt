Set up a buoyant flow simulation in a 1x1 meter box.
Use a computational grid of 50 cells in the x-direction and 50 cells in the y-direction.
Set the bottom wall boundary condition to a constant temperature of 300 Kelvin.
Set the top wall boundary condition to a constant temperature of 290 Kelvin.
Use a fluid with a kinematic viscosity (nu) of 1e-5 square meters per second.
Use a fluid with a Prandtl number (Pr) of 0.71.
Apply a gravitational acceleration of 9.81 meters per second squared in the negative y-direction.
Initialize the fluid temperature uniformly at 295 Kelvin.
Use a thermal expansion coefficient (beta) of 3.4e-3 per Kelvin for the fluid.
Run the simulation.
