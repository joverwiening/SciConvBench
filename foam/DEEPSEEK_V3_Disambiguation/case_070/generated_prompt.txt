Model a flow through a thin porous screen in a channel.
The flow is incompressible and turbulent.
Use a fluid with a kinematic viscosity of 1e-5 m²/s.
Assume a fluid density of 1.225 kg/m³.
The channel is 1.0 m long and 0.1 m high.
The simulation uses a 2D geometry.
Set the inlet velocity boundary condition to a fixedValue of uniform (5 0 0) m/s.
Model the porous screen using the 'porousBafflePressure' boundary condition.
Set the porousBafflePressure coefficients to D = 1e7 and I = 0.
The solver calculates the resulting pressure drop based on the defined coefficients and flow.
