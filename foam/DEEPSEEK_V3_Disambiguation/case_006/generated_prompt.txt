Run a two-dimensional Rayleigh-Benard convection simulation in a rectangular cavity.
The cavity dimensions are 9 units wide and 1 unit tall.
Extrude the domain a single cell in the spanwise direction.
Treat the front and back patches as empty to enforce a 2D simulation.
Use the buoyantFoam solver.
Set gravity to act downward in the negative y direction.
Use a Boussinesq approximation for buoyancy.
Set the reference density to 1.0 kg/m^3.
Set the reference temperature to 300 K.
Set the thermal expansion coefficient to 3.3e-3 1/K.
Set the kinematic viscosity to 1.5e-5 m^2/s.
Set the thermal diffusivity to 2.1e-5 m^2/s.
Set the Prandtl number to approximately 0.7.
Fix the temperature of the bottom wall at 305 K.
Fix the temperature of the top wall at 295 K.
Set the vertical side walls to be adiabatic with a zeroGradient condition.
Apply no-slip velocity conditions on all solid walls.
Use the k-epsilon turbulence model.
Set the simulation type to RAS with the kEpsilon model.
Enable turbulence and print coefficients.
Set the thermodynamic model to heRhoThermo with the Boussinesq equation of state.
Set the molecular weight to 29.
Set the specific heat at constant volume to 714.3.
Set the formation enthalpy to 0.
Set the dynamic viscosity to 1.5e-5.
Set the turbulent Prandtl number to 0.85.
Initialize the velocity field uniformly at rest (0 0 0).
Initialize the temperature field uniformly at 300 K.
Initialize the pressure field p uniformly to 0.
Initialize the pressure field p_rgh uniformly to 0.
Initialize the turbulent kinetic energy field k uniformly to 1e-5.
Initialize the turbulent dissipation rate field epsilon uniformly to 1e-5.
Initialize the turbulent viscosity field nut uniformly to 0.
Initialize the turbulent thermal diffusivity field alphat uniformly to 0.
Set boundary conditions for k to kqRWallFunction on walls and empty on front/back.
Set boundary conditions for epsilon to epsilonWallFunction on walls and empty on front/back.
Set boundary conditions for nut to nutkWallFunction on walls and empty on front/back.
Set boundary conditions for alphat to compressible::alphatJayatillekeWallFunction on walls and empty on front/back.
Set boundary conditions for U to noSlip on walls and empty on front/back.
Set boundary conditions for T to fixedValue 305 on bottom, fixedValue 295 on top, zeroGradient on sides, and empty on front/back.
Set boundary conditions for p to calculated on walls and empty on front/back.
Set boundary conditions for p_rgh to fixedFluxPressure on walls and empty on front/back.
Use a fixed timestep of 1 second.
Do not enable adjustTimeStep.
Do not set maxCo or maxDeltaT.
Simulate up to 1000 seconds of physical time.
Write result files every 50 timesteps.
Set solver tolerances for p_rgh, U, e, k, and epsilon to 1e-8.
Set solver relative tolerances for p_rgh, U, e, k, and epsilon to 0.01.
Set the corresponding *Final solvers to a relative tolerance of 0.
