The simulation is a 2D pimpleFoam case for flow past a cylinder at Re=100.
The domain is a 2D channel with dimensions 2.2m (x) x 0.41m (y) x 0.01m (z).
A cylinder of diameter 0.1m is centered at coordinates (0.2, 0.2, 0).
Use a kinematic viscosity (nu) of 1e-3 m^2/s.
Set the inlet boundary condition for velocity U to fixedValue (1 0 0).
Set the outlet boundary condition for velocity U to inletOutlet with inletValue (1 0 0).
Set the outlet boundary condition for pressure p to fixedValue 0.
Set the cylinder wall boundary condition for velocity U to noSlip (0 0 0).
Set the cylinder wall boundary condition for pressure p to zeroGradient.
Set the top and bottom channel wall boundary condition for velocity U to type 'slip'.
Set the top and bottom channel wall boundary condition for pressure p to zeroGradient.
