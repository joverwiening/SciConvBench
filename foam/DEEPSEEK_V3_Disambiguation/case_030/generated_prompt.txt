The simulation domain is a cube spanning from coordinates (0, 0, 0) to (1, 1, 1).
An obstacle is placed within the domain, spanning from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set the acceleration due to gravity vector g = (0, 0, -9.81).
Assign the top face of the cube, where z = 1, as an open atmosphere boundary patch.
Assign the remaining five faces of the cube as wall boundary patches.
Model the phases using the Volume of Fluid (VOF) method.
Define the first phase as water with a density of 1000 kg/m^3 and a kinematic viscosity of 1.0e-6 m^2/s.
Define the second phase as air with a density of 1 kg/m^3 and a kinematic viscosity of 1.48e-5 m^2/s.
Set the surface tension coefficient between the phases to 0.07 N/m.
Initialize the water phase by setting the volume fraction alpha.water = 1 inside the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
Initialize the water phase by setting the volume fraction alpha.water = 0 everywhere else in the domain.
Set the total simulation end time to 0.1 seconds.
Set the simulation time step size (deltaT) to 0.001 seconds.
