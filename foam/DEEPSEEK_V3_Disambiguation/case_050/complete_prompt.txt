Problem: 2D transient incompressible lid-driven cavity flow.
Solver: pimpleFoam
Geometry: A square cavity of size 1m x 1m. The case is 2D, with front and back patches of type 'empty'.
Mesh: A uniform Cartesian mesh of 40x40 cells, created with blockMesh. Patches are 'movingWall' (top), 'fixedWalls' (left, right, bottom), and 'frontAndBack'.
Physical Properties: In constant/transportProperties, set kinematic viscosity 'nu' to 1e-4 m^2/s.
Initial Conditions: In the 0/ directory, initialize velocity 'U' to uniform (0 0 0) and kinematic pressure 'p' to uniform 0.
Boundary Conditions:
- For U (in 0/U): 'movingWall' is fixedValue uniform (1 0 0); 'fixedWalls' is noSlip; 'frontAndBack' is empty.
- For p (in 0/p): 'movingWall' and 'fixedWalls' are fixedFluxPressure with value uniform 0; 'frontAndBack' is empty.
Time Controls: In system/controlDict, set startTime to 0, endTime to 5. Use an adjustable time step by setting 'adjustTimeStep yes', 'maxCo 1.0', and 'maxDeltaT 0.05'. Set writeControl to 'runTime' and writeInterval to 0.5.
