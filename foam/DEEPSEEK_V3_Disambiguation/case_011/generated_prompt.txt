Use a fluid density of 1 kg/m³.
The simulation is a 2D incompressible lid-driven cavity flow.
Use a computational grid of 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.
The top wall boundary is named 'movingWall' and has a uniform velocity of (1 0 0) m/s.
All other walls are named 'fixedWalls' and have a no-slip boundary condition with zero velocity.
The front and back boundary faces are designated as 'empty'.
Set the kinematic viscosity (nu) to a constant value of 1e-05 m²/s.
Use the pisoFoam solver.
Set the convection scheme for the velocity term to 'div(phi,U) Gauss limitedLinearV 1'.
Set the convection scheme for the turbulent kinetic energy term to 'div(phi,k) Gauss limitedLinear 1'.
Set the convection scheme for the dissipation rate term to 'div(phi,epsilon) Gauss limitedLinear 1'.
Set the viscous term scheme to 'div((nuEff*dev2(T(grad(U))))) Gauss linear'.
