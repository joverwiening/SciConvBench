Run a transient laminar two-phase dam-break simulation using the interFoam solver.
Model the phases as water and air using the Volume of Fluid (VOF) method.
Set the water properties to a density of 1000 kg/m^3 and a kinematic viscosity of 1.0e-6 m^2/s.
Set the air properties to a density of 1 kg/m^3 and a kinematic viscosity of 1.48e-5 m^2/s.
Apply a surface tension coefficient of 0.07 N/m between the phases.
Initialize the water column as a rectangular prism where the alpha.water field equals 1.
Define the water column's region as the box from coordinates (0, 0, 0) to (0.6, 0.1875, 0.75).
Set alpha.water to 0 everywhere outside the defined water column region.
Include one rectangular prism obstacle within the domain.
Define the obstacle's region as the box from coordinates (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set the boundary condition for the top face at z=1 to use the patch named 'atmosphere'.
Treat the 'atmosphere' patch as an open boundary to the atmosphere.
Set the boundary condition for the remaining five domain faces as walls.
Set the total simulation end time to 0.1 seconds.
Set the simulation time step (deltaT) to 0.001 seconds.
