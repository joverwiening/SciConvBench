The cavity is a square with dimensions normalized to 1 unit in x and y and 0.1 units in z.
The simulation runs from time 0 to 10 with a time step of 0.005.
Results are output every 100 time steps.
The fluid viscosity (nu) is constant at 1e-05 m^2/s.
Use the k-epsilon turbulence model.
Initialize the velocity field to zero everywhere.
Initialize the turbulence kinetic energy (k) uniformly to 1.5e-4.
Initialize the turbulence dissipation rate (epsilon) uniformly to 1.4e-4.
Initialize the turbulent viscosity (nut) uniformly to 0.
Use the pisoFoam solver.
For the top wall ('movingWall'), set the velocity boundary condition to a uniform fixed value of (1 0 0) m/s.
For the bottom and side walls ('fixedWalls'), set the velocity boundary condition to a no-slip (fixedValue of (0 0 0)).
For all walls, set the pressure boundary condition to a zero gradient.
For all walls, set the boundary condition for k to kqRWallFunction.
For all walls, set the boundary condition for epsilon to epsilonWallFunction.
For all walls, set the boundary condition for nut to nutkWallFunction.
The front and back boundary patches are empty.
Use the convection scheme div(phi,U) Gauss limitedLinearV 1.
Use the convection scheme div(phi,k) Gauss limitedLinear 1.
Use the convection scheme div(phi,epsilon) Gauss limitedLinear 1.
Use the scheme div((nuEff*dev2(T(grad(U))))) Gauss linear for the viscous term.
