The simulation models compressible air flow through a porous filter in a duct.
The duct is 0.5 meters long and 0.1 meters high.
The porous filter is a zone from x=0.2 meters to x=0.25 meters, with a thickness of 0.05 meters.
The filter porosity is modeled using Darcy-Forchheimer coefficients: d = (5e7 5e7 0); f = (500 500 0).
The inlet boundary condition is supersonic with a Mach number of 2.
The inlet static pressure is 101325 Pa.
The inlet static temperature is 300 K.
The inlet turbulence intensity is assumed to be 5%.
The inlet turbulent viscosity ratio is assumed to be 10.
The k-omega SST turbulence model is used.
The outlet boundary condition is waveTransmissive with pressure 101325 Pa and temperature 300 K.
