The simulation uses a rectangular cavity domain that is 9 units wide and 1 unit tall, extruded a single cell in the spanwise direction.
The front and back patches are treated as empty to enforce a 2D simulation.
The mesh uses 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.
Use the buoyantFoam solver.
Set the gravitational acceleration to 9.81 m/s² acting downward in the negative y-direction.
The reference state uses air-like properties.
Set the reference density (rho0) to 1.0 kg/m³.
Set the reference temperature (T0) to 300 K.
Set the thermal expansion coefficient (beta) to 3.3e-3 1/K.
Set the kinematic viscosity (nu) to 1.5e-5 m²/s.
Set the thermal diffusivity (alpha) to 2.1e-5 m²/s, resulting in a Prandtl number (Pr) of approximately 0.7.
Set the bottom wall temperature to a fixed value of 305 K.
Set the top wall temperature to a fixed value of 295 K.
Set the vertical side walls to be adiabatic (zeroGradient for temperature).
Apply no-slip velocity conditions on all solid walls.
Initialize the flow at rest with a uniform velocity field of (0 0 0) m/s.
Initialize the temperature field uniformly at 300 K.
Use a fixed timestep (deltaT) of 1 s.
Do not enable adjustTimeStep.
Do not set maxCo or maxDeltaT.
Simulate up to 1000 s of physical time.
Write result fields every 50 timesteps.
Use the k-epsilon turbulence model.
In constant/momentumTransport, set simulationType to RAS.
In constant/momentumTransport, set RASModel to kEpsilon.
In constant/momentumTransport, set turbulence to on.
In constant/momentumTransport, set printCoeffs to on.
Do not use laminar settings.
In constant/physicalProperties, use the heRhoThermo thermophysical model.
In constant/physicalProperties, set the equationOfState to Boussinesq.
In constant/physicalProperties, set the molecular weight (molWeight) to 29.
In constant/physicalProperties, set the reference density (rho0) to 1.0.
In constant/physicalProperties, set the reference temperature (T0) to 300.
In constant/physicalProperties, set the thermal expansion coefficient (beta) to 3.3e-3.
In constant/physicalProperties, set the specific heat at constant volume (Cv) to 714.3.
In constant/physicalProperties, set the heat of formation (Hf) to 0.
In constant/physicalProperties, set the dynamic viscosity (mu) to 1.5e-5.
In constant/physicalProperties, set the Prandtl number (Pr) to 0.714.
In the 0/k file, set the internalField to a uniform value of 1e-5.
In the 0/k file, apply the kqRWallFunction boundary condition on all solid walls.
In the 0/k file, apply the empty condition on the front and back patches.
In the 0/epsilon file, set the internalField to a uniform value of 1e-5.
In the 0/epsilon file, apply the epsilonWallFunction boundary condition on all solid walls.
In the 0/epsilon file, apply the empty condition on the front and back patches.
In the 0/nut file, set the internalField to a uniform value of 0.
In the 0/nut file, apply the nutkWallFunction boundary condition on all solid walls.
In the 0/nut file, apply the empty condition on the front and back patches.
In the 0/alphat file, set the internalField to a uniform value of 0.
In the 0/alphat file, apply the compressible::alphatJayatillekeWallFunction boundary condition on all solid walls.
In the 0/alphat file, set the turbulent Prandtl number (Prt) to 0.85.
In the 0/alphat file, apply the empty condition on the front and back patches.
In the 0/U file, set the internalField to a uniform value of (0 0 0).
In the 0/U file, apply the noSlip boundary condition on all solid walls.
In the 0/U file, apply the empty condition on the front and back patches.
In the 0/T file, set the internalField to a uniform value of 300.
