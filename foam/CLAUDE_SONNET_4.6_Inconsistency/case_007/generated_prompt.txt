Run a 2D gas-liquid bubble column simulation using multiphaseEulerFoam (Euler-Euler approach).

DOMAIN AND MESH
The rectangular domain spans x in [0, 0.15] m, y in [0, 1.00] m, z in [0, 0.10] m with height along the +y direction and thin in the z direction.
Use a structured hex mesh with 25 x 75 x 1 cells and simpleGrading (1 1 1).
Define the following patches in blockMeshDict: inlet (bottom face, y=0), outlet (top face, y=1.00), walls (left and right faces in x), and empty faces in the z direction for 2D treatment.

GRAVITY
Set gravity to (0 -9.81 0) m/s² in the constant/g file.

CONTINUOUS PHASE: WATER
Use heRhoThermo thermophysical model for water.
Use rPolynomial equation of state for water with C coefficients (0.001278 -2.1055e-06 3.9689e-09 4.3772e-13 -2.0225e-16).
Set molecular weight of water to 18.
Set specific heat capacity Cv of water to 4195 J/(kg·K).
Set dynamic viscosity of water to 3.645e-4 Pa·s.
Set Prandtl number of water to 2.289.

DISPERSED PHASE: AIR
Use heRhoThermo thermophysical model for air.
Use perfectGas equation of state for air.
Set molecular weight of air to 28.9.
Set specific heat capacity Cp of air to 1007 J/(kg·K).
Set dynamic viscosity of air to 1.84e-05 Pa·s.
Set Prandtl number of air to 0.7.

BUBBLE SIZE MODELS
Use isothermal diameter model for air with d0 = 3e-3 m.
Use constant diameter model for water with d = 1e-4 m.

MOMENTUM TRANSPORT
Set simulationType to laminar in the momentumTransport file for both air and water phases.

PHASE PROPERTIES
Define phases as (air water) with water as the reference phase.
Set residualAlpha to 1e-6 for both air and water.

BLENDING
Use linear blending scheme.
Set minFullyContinuousAlpha to 0.7 and minPartlyContinuousAlpha to 0.3 for the default blending.
Set minFullyContinuousAlpha to 0.5 and minPartlyContinuousAlpha to 0.5 for drag blending (i.e., minPartlyContinuousAlpha 0.5 for drag).

INTERFACIAL MODELS
Set surface tension between air and water to constant with sigma = 0.07 N/m.
Use SchillerNaumann drag model for air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water configurations.
Use constantCoefficient virtual mass model with Cvm = 0.5 for both air-in-water and water-in-air directions.
Use RanzMarshall heat transfer model for both directions with residualAlpha = 1e-4.

INITIAL CONDITIONS (t = 0)
Set U.water to uniform (0 0 0).
Set U.air to uniform (0 0.1 0).
Set alpha.water to uniform 1.
Set p_rgh to uniform 1e5.
Set T.air to uniform 300 K.
Set T.water to uniform 350 K.
Use setFieldsDict to define phase distribution: set default field values with alpha.air = 1 and alpha.water = 0 everywhere, then override the box region from (0 0 0) to (0.15 0.701 0.1) with alpha.air = 0 and alpha.water = 1.

BOUNDARY CONDITIONS AT INLET (bottom face, y=0)
Set U.air to fixedValue (0 0.1 0).
Set U.water to fixedValue (0 0 0).
Set alpha.air to fixedValue 0.5.
Set alpha.water to fixedValue 0.5.
Set T.air to fixedValue 300 K.
Set T.water to fixedValue 350 K.
Set p_rgh to fixedFluxPressure.

BOUNDARY CONDITIONS AT OUTLET (top face, y=1.00)
Set U.air to fixedValue (0 0.1 0).
Set U.water to fixedValue (0 0 0).
Set alpha.air to fixedValue 0.5.
Set alpha.water to fixedValue 0.5.
Set T.air to fixedValue 300 K.
Set T.water to fixedValue 350 K.

BOUNDARY CONDITIONS AT WALLS (left and right faces in x)
Set U.air to fixedValue (0 0 0).
Set U.water to fixedValue (0 0 0).
Set alpha.air to zeroGradient.
Set alpha.water to zeroGradient.
Set p_rgh to fixedFluxPressure.
Set T.air to zeroGradient.
Set T.water to zeroGradient.

BOUNDARY CONDITIONS AT EMPTY FACES (z-normal faces)
Set all fields to empty type for 2D treatment.

TIME CONTROLS
Set startTime to 0 s.
Set endTime to 20 s.
Set deltaT to 0.005 s.
Set adjustTimeStep to no.
Set maxCo to 0.5.
Set maxDeltaT to 1.
Set writeInterval to 1 s.
