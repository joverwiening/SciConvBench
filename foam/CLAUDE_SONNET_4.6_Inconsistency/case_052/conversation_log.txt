Q: The `nonNewtonianIcoFoam` solver is specifically designed for non-Newtonian fluids, but the transport properties you provided define a Newtonian fluid with a constant kinematic viscosity. These two choices contradict each other.

Which non-Newtonian viscosity model do you want to use for the shear-thinning fluid (for example, powerLaw, BirdCarreau, HerschelBulkley, or Casson)?
A: Use the Power Law model with these properties:

```
transportModel  PowerLaw;
nuMax           1;
nuMin           1e-6;
k               0.1;
n               0.5;
```
