Set up a 2D lid-driven cavity simulation using the nonNewtonianIcoFoam solver in OpenFOAM.
The cavity geometry is a 1m x 1m square domain.
The simulation is transient (time-dependent).
The mesh is 2D (one cell thick in the z-direction, with empty boundary conditions on the front and back faces).
The top wall (lid) moves with a velocity of (1 0 0) m/s using a fixedValue boundary condition.
All other walls (bottom, left, right) are stationary using the noSlip boundary condition.
In the constant/transportProperties file, set transportModel to PowerLaw.
Set nuMax to 1 (units: m^2/s) with dimensional array [0 2 -1 0 0 0 0].
Set nuMin to 1e-6 (units: m^2/s) with dimensional array [0 2 -1 0 0 0 0].
Set k to 0.1 with dimensional array [0 2 -1 0 0 0 0].
Set n to 0.5 (dimensionless) with dimensional array [0 0 0 0 0 0 0].
The density is not explicitly used by nonNewtonianIcoFoam (it solves in kinematic form), so no rho entry is required in transportProperties.
In the 0/U file, set the internal field to uniform (0 0 0).
In the 0/U file, set the lid (top wall) boundary to fixedValue with value uniform (1 0 0).
In the 0/U file, set all other wall boundaries to noSlip.
In the 0/p file, set the internal field to uniform 0.
In the 0/p file, set all wall boundaries to zeroGradient.
In the 0/p file, set at least one reference point or use a fixedValue on one boundary patch to pin the pressure if needed.
In the system/controlDict file, set the application to nonNewtonianIcoFoam.
Set the start time to 0, the end time to a suitable transient duration (e.g., 10 seconds), and the time step deltaT to a small value consistent with the mesh and flow (e.g., 0.001 s).
Set writeInterval to write results at regular intervals (e.g., every 0.1 s).
In the system/fvSchemes file, use a first-order or second-order time scheme (e.g., Euler for ddtSchemes) and appropriate gradient, divergence, and Laplacian schemes for incompressible laminar flow.
In the system/fvSolution file, configure solvers for p (e.g., PCG with DIC preconditioner) and U (e.g., PBiCGStab with DILU preconditioner), and use the PISO or PIMPLE algorithm for pressure-velocity coupling.
The simulation is laminar; no turbulence model is used.
