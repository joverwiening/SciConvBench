Simulate the static deflection of a 2D cantilever beam under a downward traction load using linear elasticity in OpenFOAM with solidDisplacementFoam.

The beam geometry is 1.0 m long and 0.1 m high.

Use a structured mesh of 100 cells in the x-direction and 10 cells in the y-direction, generated with blockMesh.

The domain is 2D, so set the mesh to one cell thick in the z-direction with empty boundary conditions on the front and back faces.

The material is aluminum with Young's modulus E = 70e9 Pa and Poisson's ratio nu = 0.33.

Define these material properties in constant/mechanicalProperties using the entries rho, E, and nu appropriate for solidDisplacementFoam.

Set the solver to plane stress or plane strain as appropriate; use planeStress off (plane strain) unless otherwise specified.

In 0/D, set the boundary condition for the patch named fixedEnd (at x=0) to fixedValue uniform (0 0 0).

In 0/D, set the boundary condition for the patch named loadEnd (at x=1) to tractionDisplacement with traction uniform (0 -10000 0) and pressure uniform 0.

In 0/D, set the boundary conditions for the top and bottom patches to tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0, which represents a traction-free surface.

In 0/D, set the boundary conditions for the front and back patches to empty.

In system/controlDict, set application to solidDisplacementFoam.

Set the simulation as steady-state by setting startTime to 0, endTime to 1, deltaT to 1, and maxCo to a large value so it runs a single step.

In system/fvSolution, configure the linear solver for D (displacement) using a suitable iterative solver such as GAMG with tolerance 1e-6 and relTol 0.01.

In system/fvSchemes, set d2dt2Schemes default to steadyState and gradSchemes and divSchemes to Gauss linear.

Run blockMesh to generate the mesh, then run solidDisplacementFoam to compute the displacement field D.

Post-process the results using paraFoam or foamToVTK to visualize the displacement field and verify the maximum downward deflection at the free end (x=1).
