Use simpleFoam as the steady-state incompressible flow solver.
Use the kOmegaSST RANS turbulence model.
The geometry is a backward-facing step.
Set the inlet freestream velocity to 20 m/s as a fixedValue uniform boundary condition in 0/U.
Set the outlet for U to zeroGradient.
Set all walls for U to noSlip.
Assume fully turbulent inflow with turbulence intensity 5% and turbulent mixing length 0.005 m.
Compute the inlet turbulent kinetic energy as k = 1.5 * (U * I)^2 = 1.5 * (20 * 0.05)^2 = 1.5 Pa^2/s^2, giving k = 1.5 m^2/s^2.
Compute the inlet specific dissipation rate as omega = sqrt(k) / (Cmu^0.25 * L) = sqrt(1.5) / (0.09^0.25 * 0.005) = 447.2 s^-1.
In 0/k, set the inlet boundary condition to type fixedValue with value uniform 1.5.
In 0/k, set the outlet boundary condition to zeroGradient.
In 0/k, set all wall boundary conditions to kqRWallFunction with value uniform 1.5.
In 0/omega, set the inlet boundary condition to type fixedValue with value uniform 447.2.
In 0/omega, set the outlet boundary condition to zeroGradient.
In 0/omega, set all wall boundary conditions to omegaWallFunction with value uniform 447.2.
In 0/nut, set the inlet boundary condition to calculated with value uniform 0.
In 0/nut, set the outlet boundary condition to calculated with value uniform 0.
In 0/nut, set all wall boundary conditions to nutkWallFunction with value uniform 0.
Use standard wall functions on all wall patches for turbulence variables (kqRWallFunction for k, omegaWallFunction for omega, nutkWallFunction for nut).
Do not set k or omega to uniform 0 at any boundary; use the physically computed values above.
In constant/turbulenceProperties, set simulationType to RAS, model to kOmegaSST, and turbulence to on.
In constant/transportProperties, set the kinematic viscosity nu appropriate for air at standard conditions (nu = 1.5e-5 m^2/s).
Use a structured or block-structured mesh appropriate for a backward-facing step geometry, with sufficient near-wall refinement to support wall function usage (y+ in the range 30 to 300 on walls).
Set solver convergence tolerances for U, p, k, and omega to 1e-6 in fvSolution.
Use SIMPLE algorithm settings in fvSolution with nNonOrthogonalCorrectors set to at least 1.
Run the simulation until all residuals converge below 1e-5 or for a sufficient number of iterations (at least 1000) to reach steady state.
