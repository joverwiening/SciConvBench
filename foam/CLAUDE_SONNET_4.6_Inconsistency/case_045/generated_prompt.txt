Perform a steady-state, incompressible 2D NACA 0012 airfoil simulation using OpenFOAM's simpleFoam solver.

Use a freestream velocity of U = 50 m/s in the x-direction (horizontal).
Use a kinematic viscosity of nu = 1.5e-5 m^2/s (air at standard conditions), giving a chord-based Reynolds number of approximately 3.33 million with a chord length of 1 m.
Set the angle of attack to 5 degrees by decomposing the inlet velocity into components: Ux = 50*cos(5°) ≈ 49.81 m/s, Uy = 50*sin(5°) ≈ 4.36 m/s, Uz = 0.

Set the chord length of the NACA 0012 airfoil to 1 m.
Place the airfoil leading edge at the origin.
Use a C-type or O-type structured mesh extending at least 20 chord lengths from the airfoil in all far-field directions.
Create the mesh as a single cell layer in the z-direction with a depth of 0.1 m.

In constant/polyMesh/boundary, define the thin-direction patches as frontAndBack with type wall.
In 0/U, set the frontAndBack boundary condition to noSlip.
In 0/p, set the frontAndBack boundary condition to zeroGradient.

Define the following boundary patches: inlet (far-field inflow), outlet (far-field outflow or wake exit), and airfoil (no-slip wall).
At the inlet, set U to a fixedValue of (49.81 4.36 0).
At the inlet, set p to zeroGradient.
At the outlet, set U to zeroGradient.
At the outlet, set p to fixedValue uniform 0.
At the airfoil, set U to noSlip.
At the airfoil, set p to zeroGradient.

Use the k-omega SST turbulence model.
Set turbulence intensity at the inlet to 0.1% (I = 0.001).
Compute inlet k as k = 1.5*(I*U_mag)^2 = 1.5*(0.001*50)^2 = 0.00375 m^2/s^2.
Compute inlet omega as omega = k^0.5 / (Cmu^0.25 * L) where L = 1 m and Cmu = 0.09, giving omega ≈ 0.0612 / (0.5477 * 1) ≈ 0.112 s^-1; use omega = 1.0 s^-1 as a conservative far-field value following best practices.
Set nut at the inlet to fixedValue uniform 0.
Set nut at the airfoil to fixedValue uniform 0 (wall condition).

In constant/turbulenceProperties, set simulationType to RAS and model to kOmegaSST.
In constant/transportProperties, set nu to 1.5e-5 m^2/s.

In system/fvSchemes, use Gauss linear for gradient schemes, Gauss linearUpwind grad(U) for the divergence of U, Gauss linear corrected for Laplacian schemes, and linear interpolation.
In system/fvSolution, use SIMPLE algorithm with consistent yes.
Set relaxation factors: U = 0.7, p = 0.3, k = 0.5, omega = 0.5, nut = 0.5.
Use GAMG solver for p with tolerance 1e-6 and relative tolerance 0.01.
Use smoothSolver with symGaussSeidel for U, k, and omega with tolerance 1e-7 and relative tolerance 0.1.

Run the simulation for 3000 steady-state iterations or until all residuals drop below 1e-5.
Write results every 500 iterations.
