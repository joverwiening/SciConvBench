The simulation uses OpenFOAM with the solver buoyantPimpleFoam.

The domain is a 2D sealed room of 5 m (x) by 3 m (y), extruded one cell in z (0.1 m depth).

The mesh is generated with blockMesh. Use a uniform block with 50 cells in x, 30 cells in y, and 1 cell in z.

The front and back patches are set to type empty for 2D treatment.

A hot block occupies the region from (2.25, 0, 0) to (2.75, 0.5, 0.1), representing a 0.5 m x 0.5 m block centered horizontally at the floor.

The block is represented as a fixed-temperature wall patch at 400 K, not as a solid region. Its six faces are defined as separate patches in blockMesh named blockWalls.

All other room walls (left, right, top, bottom excluding block faces) are named roomWalls.

Gravity is set to (0 -9.81 0) in constant/g.

In constant/thermophysicalProperties, set the following:
thermoType { type hePsiThermo; mixture pureMixture; transport sutherland; thermo janaf; equationOfState perfectGas; specie specie; energy sensibleEnthalpy; }

Use the following specie entry for air:
specie { nMoles 1; molWeight 28.9640; }

Use the following JANAF thermo coefficients for air (two-range NASA 7-coefficient polynomial, standard OpenFOAM tutorial values):
thermodynamics { Tlow 200; Thigh 6000; Tcommon 1000; highCpCoeffs ( 3.57304 -4.23e-04 6.1e-09 0 0 -1047.54 3.12 ); lowCpCoeffs ( 3.09589 1.22835e-03 -4.14267e-07 6.56910e-11 -3.87021e-15 -983.191 5.34161 ); }

Use the following Sutherland transport coefficients for air:
transport { As 1.458e-06; Ts 110.4; }

Initialize the entire domain temperature field T to 300 K in 0/T.

Set the block patch (blockWalls) boundary condition for T to fixedValue 400 K.

Set all roomWalls boundary condition for T to zeroGradient (adiabatic).

Set front and back patches for T to empty.

Initialize pressure p to 101325 Pa uniform across the domain in 0/p.

Set all wall patches for p to zeroGradient.

Set front and back patches for p to empty.

Initialize velocity U to (0 0 0) uniform across the domain in 0/U.

Set all wall patches (roomWalls and blockWalls) for U to noSlip.

Set front and back patches for U to empty.

In 0/p_rgh, initialize to 101325 Pa. Set roomWalls and blockWalls to fixedFluxPressure. Set front and back to empty.

In fvSchemes, use Euler for ddtSchemes. Use Gauss linear for gradSchemes. Use Gauss linearUpwind grad(U) for div(phi,U). Use Gauss linearUpwind grad(h) for div(phi,h). Use Gauss linear corrected for laplacianSchemes. Use linear for interpolationSchemes. Use corrected for snGradSchemes.

In fvSolution, use PIMPLE with nOuterCorrectors 2, nCorrectors 2, nNonOrthogonalCorrectors 1. Use PCG with DIC preconditioner for p_rgh. Use PBiCGStab with DILU preconditioner for U and h.

Set the time step deltaT to 0.01 s.

Set endTime to 300 s (5 minutes of physical time).

Set writeInterval to 10 s.

Set maxCo to 0.5 in controlDict and use adjustTimeStep yes to allow adaptive time stepping.

Set runTimeModifiable to yes in controlDict.

The simulation captures transient natural convection driven by the temperature difference between the hot block at 400 K and the surrounding air at 300 K in the sealed room.
