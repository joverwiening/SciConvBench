Use `laplacianFoam` as the solver.

The domain is a 1 m × 1 m square plate extruded one cell in the z-direction with a thickness of 0.01 m.

Set thermal diffusivity `DT = 1e-5 m^2/s` in `constant/transportProperties`.

Set the initial condition for `T` to uniform 300 K in `0/T`.

In `constant/polyMesh/boundary`, set the `frontAndBack` patch type to `empty`.

In `0/T`, set the `frontAndBack` boundary condition to type `empty`.

Apply boundary conditions on the four side patches (left, right, top, bottom) of the plate as needed by the physical problem; since no specific side boundary conditions were provided, apply `zeroGradient` on all four side patches as a default (no-flux condition).

Set the initial time directory to `0`.

Configure `system/controlDict` with a suitable `startTime` of 0, an `endTime` sufficient to observe transient diffusion (for example 10000 s), a `deltaT` time step that satisfies the diffusion stability criterion (for example 1 s), and `writeInterval` set to a reasonable output frequency (for example every 100 s).

Configure `system/fvSchemes` with an Euler time scheme for `ddtSchemes` and a Gauss linear corrected scheme for `laplacianSchemes`.

Configure `system/fvSolution` with a PCG solver with DIC preconditioner for `T`, a tolerance of `1e-6`, and a relative tolerance of `0`.

The mesh is generated using `blockMesh` with a single block, with the z-direction having exactly one cell of size 0.01 m.
