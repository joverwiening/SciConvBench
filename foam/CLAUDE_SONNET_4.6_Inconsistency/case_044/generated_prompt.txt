Use the interFoam solver for a 2D dam break simulation.
Set the domain to 1 meter long (x-direction) and 1 meter high (y-direction).
Use a mesh of 100 cells in the x-direction and 100 cells in the y-direction, giving a uniform cell size of 0.01m x 0.01m.
Set the domain depth (z-direction) to 0.01m with 1 cell and empty boundary conditions on the front and back faces to enforce 2D behavior.
Create the mesh using blockMesh with a single block spanning (0 0 0) to (1 1 0.01).
In the constant/g file, define gravity as: dimensions [0 1 -2 0 0 0 0]; value (0 -9.81 0); so that gravity acts in the negative y-direction.
Do not use g (0 0 -9.81) since the 2D domain lies in the x-y plane and the z-axis is the empty direction; gravity must point in the negative y-direction.
Initialize the alpha.water field to 1 in the region 0 < x < 0.2 and 0 < y < 0.5, and 0 elsewhere.
Use setFieldsDict to perform this initialization with a boxToCell selection using box (0 0 0) (0.2 0.5 0.01).
Set the initial alpha.water field to 0 everywhere as the default in 0/alpha.water, then override with setFields.
Set the initial velocity field U to (0 0 0) everywhere in 0/U.
Set the initial pressure field p_rgh to 0 everywhere in 0/p_rgh.
Apply noSlip boundary condition for U on the left, right, and bottom boundaries.
Apply pressureInletOutletVelocity boundary condition for U on the top boundary.
Apply zeroGradient for alpha.water on the left, right, and bottom boundaries.
Apply inletOutlet with inletValue 0 for alpha.water on the top boundary.
Apply fixedFluxPressure for p_rgh on the left, right, and bottom boundaries.
Apply totalPressure with p0 = 0 for p_rgh on the top boundary.
In constant/transportProperties, define water with kinematic viscosity nu = 1e-6 m2/s and density rho = 1000 kg/m3.
Define air with kinematic viscosity nu = 1.48e-5 m2/s and density rho = 1 kg/m3.
Set the surface tension coefficient sigma to 0.07 N/m.
Use a MULES-based scheme for alpha.water with nAlphaCorr 2 and nAlphaSubCycles 1 in fvSolution.
Set the end time to 1 second in controlDict.
Set deltaT to 0.001 seconds in controlDict.
Set maxCo to 0.5 and adjust the time step with adjustTimeStep yes in controlDict.
Set writeInterval to 0.05 seconds to capture the collapse progression.
Use Euler time scheme in fvSchemes.
Use Gauss linear schemes for gradient and divergence terms appropriate for interFoam.
Run setFields before executing interFoam to initialize the water column.
