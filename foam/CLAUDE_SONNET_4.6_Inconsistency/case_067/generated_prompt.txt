Set up a steady-state simulation for laminar, incompressible flow over a backward-facing step using the simpleFoam solver.
The domain is 2D with an inlet on the left side and an outlet on the right side.
All other boundaries are walls except the front and back patches which are treated as empty for 2D simulation.
Create the '0/U' file with the following boundary conditions.
The 'inlet' patch uses type fixedValue with value uniform (0.5 0 0).
The 'outlet' patch uses type zeroGradient.
The 'stepWall' patch uses type noSlip.
The 'topWall' patch uses type noSlip.
The 'frontAndBack' patch uses type empty.
The internal field for U is initialized to uniform (0 0 0).
Use simpleFoam as the solver, which is appropriate for steady-state incompressible laminar or turbulent flow.
The flow is incompressible, so the fluid density is constant and no energy equation is solved.
The flow is laminar, so no turbulence model is required.
