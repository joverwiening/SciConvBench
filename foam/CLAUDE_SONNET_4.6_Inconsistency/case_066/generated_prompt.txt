Simulate steady-state, incompressible, turbulent flow and heat transfer in a 2D heated pipe using the simpleFoam solver.
The pipe has a diameter of 0.1 m and a length of 2 m.
Use the k-epsilon turbulence model.
The fluid is air with standard properties (density 1.225 kg/m³, kinematic viscosity 1.5e-5 m²/s, specific heat Cp 1005 J/kg·K, thermal conductivity 0.0257 W/m·K).
The simulation is 2D; the mesh must have exactly one cell in the z-direction, and the front and back patches must be of type empty.
The inlet boundary condition for velocity (U) is a uniform fixedValue of (1 0 0) m/s.
The inlet boundary condition for pressure (p) is zeroGradient.
The inlet boundary condition for temperature (T) is fixedValue uniform 300 K.
The inlet boundary conditions for k and epsilon must be derived from turbulence intensity of 5% and a mixing length of 0.07 times the pipe diameter.
The outlet boundary condition for pressure (p) is fixedValue uniform 0 Pa (gauge).
The outlet boundary condition for velocity (U) is zeroGradient.
The outlet boundary condition for temperature (T) is zeroGradient.
The outlet boundary conditions for k and epsilon are zeroGradient.
The wall boundary condition for velocity (U) is noSlip.
The wall boundary condition for pressure (p) is zeroGradient.
The wall boundary condition for temperature (T) is zeroGradient (adiabatic, zero heat flux).
The wall boundary conditions for k and epsilon must use standard wall functions (kqRWallFunction and epsilonWallFunction respectively).
The front and back patches have type empty for all fields.
Use the SIMPLE algorithm as implemented in simpleFoam for pressure-velocity coupling.
Set the number of non-orthogonal correctors to 1 in fvSolution.
Use Gauss linear schemes for gradient and divergence terms, and Gauss linear corrected for the Laplacian scheme in fvSchemes.
Set relaxation factors of 0.7 for U, 0.3 for p, 0.5 for k, 0.5 for epsilon, and 0.5 for T in fvSolution.
Run the simulation for a maximum of 1000 iterations or until all residuals drop below 1e-5, whichever comes first.
Include the energy equation by enabling it in the thermophysical or transport properties configuration appropriate for simpleFoam with a passive scalar or buoyantSimpleFoam approach; use the appropriate solver that supports both turbulence and energy transport for incompressible flow.
Set the turbulence model to kEpsilon in the turbulenceProperties file with RAS modelling.
