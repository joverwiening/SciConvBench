The simulation uses the reactingFoam solver in OpenFOAM.

The domain is a 3-D rectangular block with x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.

Use 100 cells in the x-direction, 40 cells in the y-direction, and 1 cell in the z-direction, with uniform cell spacing in all directions.

Name the boundary patch at x = 0 "fuel", the patch at x = 0.02 m "air", the patches at y = -0.01 m and y = 0.01 m both "outlet", and the patches at z = -0.01 m and z = 0.01 m "frontAndBack".

Set the frontAndBack patch type to empty to enforce a 2-D simulation.

Set the outlet patches to zeroGradient for all transported variables and to fixedValue 0 Pa for pressure.

Use the 4-step reduced methane mechanism by Jones and Lindstedt (1988) as the chemical mechanism, which includes the species CH4, O2, N2, H2O, CO2, CO, H2, and OH.

This mechanism is a well-established best-practice choice for laminar diffusion flame simulations balancing accuracy and computational cost.

Define all thermodynamic and transport properties for each species using JANAF polynomial coefficients and Sutherland transport coefficients respectively.

Use heRhoThermo as the thermophysical model.

Set the mixture model to coefficientWilkeMultiComponentMixture.

Set the transport model to Sutherland.

Set the thermodynamics model to janaf.

Set the combustion model to laminar with finite-rate chemistry.

Set the turbulence and momentum transport model to laminar.

Use EulerImplicit as the chemistry solver type.

Use Rosenbrock43 as the ODE solver within the chemistry integrator.

Set the fuel inlet boundary condition: patch type fixedValue, velocity U = (0.1, 0, 0) m/s, temperature T = 293 K, species mass fractions Y_CH4 = 1.0 and all other species = 0.0, pressure gradient zeroGradient.

Set the air inlet boundary condition: patch type fixedValue, velocity U = (-0.1, 0, 0) m/s, temperature T = 293 K, species mass fractions Y_O2 = 0.23 and Y_N2 = 0.77 and all other species = 0.0, pressure gradient zeroGradient.

Initialize the entire domain at time 0 with temperature T = 2000 K to promote ignition.

Initialize the domain velocity to (0, 0, 0) m/s.

Initialize the domain pressure to 101325 Pa.

Initialize species mass fractions in the domain by linearly interpolating between fuel and air inlet values along the x-direction, with Y_CH4 = 1.0 at x = 0 and Y_O2 = 0.23, Y_N2 = 0.77 at x = 0.02 m.

Set the fixed timestep deltaT to 1e-4 s.

Set the end time to 0.5 s.

Set writeInterval to 0.05 s using adjustableRunTime write control.

Set writeFormat to ascii and writePrecision to 8.

Use PIMPLE as the pressure-velocity coupling algorithm with at least 2 outer corrector loops and 1 inner pressure corrector loop.

Set the linear solver for pressure to PCG with DIC preconditioner and tolerance 1e-6.

Set the linear solver for velocity and species to PBiCGStab with DILU preconditioner and tolerance 1e-7.

Set divSchemes for div(phi,U) to Gauss linearUpwind grad(U), for div(phi,Yi) to Gauss limitedLinear01 1, and for div(phi,h) to Gauss limitedLinear 1.

Set gradSchemes to Gauss linear and laplacianSchemes to Gauss linear corrected.

Set the interpolationSchemes to linear and snGradSchemes to corrected.
