The geometry is a 2D backward-facing step channel created using `blockMesh`.

The inlet channel height is 0.1 m (upstream section).

The step height is 0.05 m, so the downstream channel height is 0.15 m.

The upstream length (before the step) is 0.2 m.

The downstream length (after the step) is 0.8 m.

The domain depth in the z-direction is 0.01 m (one cell thick for 2D simulation).

Define the geometry in `system/blockMeshDict` using three blocks: the upstream channel block, the step solid region (excluded), and the downstream channel block.

The upstream block spans x from 0 to 0.2, y from 0.05 to 0.15.

The downstream block spans x from 0.2 to 1.0, y from 0 to 0.15.

Use 40 cells in x for the upstream block, 160 cells in x for the downstream block, and 20 cells in y for the upstream block and 30 cells in y for the downstream block.

Use 1 cell in the z-direction for all blocks.

The inlet boundary is the left face of the upstream block.

The outlet boundary is the right face of the downstream block.

The top wall spans the full length of the domain at y = 0.15.

The bottom wall consists of the bottom face of the upstream block (y = 0.05, x = 0 to 0.2), the vertical step face (x = 0.2, y = 0 to 0.05), and the bottom face of the downstream block (y = 0, x = 0.2 to 1.0).
