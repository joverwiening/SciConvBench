Set up a 2D axisymmetric simpleFoam simulation of swirling flow in a pipe using a wedge mesh of 5 degrees created with blockMeshDict.

Pipe geometry: radius = 0.05 m, length = 0.5 m.

The wedge is centered on the x-axis (axial direction), spanning 2.5 degrees on each side of the x-z plane, giving a total wedge angle of 5 degrees.

Use blockMeshDict to create the wedge mesh with approximately 100 cells in the axial direction and 20 cells in the radial direction, with grading of 1 in both directions.

In constant/polyMesh/boundary, define the patches exactly as follows:
inlet { type patch; }
outlet { type patch; }
wall { type wall; }
front { type wedge; }
back { type wedge; }

Note: the front and back patches must be of type wedge (not symmetryPlane) in the boundary file for a proper OpenFOAM wedge geometry, even though the user specified symmetryPlane; wedge is the physically correct type for axisymmetric simpleFoam simulations.

Use standard air properties at room temperature: kinematic viscosity nu = 1.5e-5 m^2/s, density rho = 1.225 kg/m^3 (incompressible, so density is not explicitly set in simpleFoam).

Use the k-omega SST turbulence model (RAS).

In constant/turbulenceProperties, set simulationType to RAS and model to kOmegaSST.

For the velocity field U in 0/U:
Apply a fixedValue inlet condition with a uniform velocity of (1.0 0.0 0.0) in Cartesian components, then add swirl using the swirlFlowRateInletVelocity or cylindricalInletVelocity condition: use cylindricalInletVelocity with axial velocity = 1.0 m/s, radial velocity = 0.0 m/s, and tangential (swirl) velocity = 0.5 m/s, with the axis along the x-direction and origin at (0 0 0).
Apply noSlip on wall.
Apply zeroGradient on outlet.
Apply wedge on front and back.

For the pressure field p in 0/p:
Apply zeroGradient on inlet.
Apply fixedValue uniform 0 on outlet.
Apply zeroGradient on wall.
Apply wedge on front and back.

For turbulence fields k and omega in 0/k and 0/omega:
At inlet, apply fixedValue: k = 0.00375 m^2/s^2 (based on 5% turbulence intensity at 1 m/s), omega = 100 s^-1.
At outlet, apply zeroGradient for both k and omega.
At wall, apply kqRWallFunction for k and omegaWallFunction for omega.
Apply wedge on front and back.

In system/fvSchemes, use steadyState for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for div(phi,U), Gauss upwind for div(phi,k) and div(phi,omega), and corrected for laplacianSchemes.

In system/fvSolution, use SIMPLE algorithm with nNonOrthogonalCorrectors 1, and set residual convergence tolerances to 1e-5 for all fields.

In system/controlDict, set application to simpleFoam, startTime to 0, endTime to 1000, deltaT to 1, writeInterval to 100, and writeFormat to ascii.
