Run a 2D inviscid oblique-shock simulation using rhoCentralFoam in OpenFOAM.

The domain is a rectangular box extending from (0, 0, 0) to (4.1, 1, 0.1).

Use 60 cells in x, 30 cells in y, and 1 cell in z in the blockMeshDict.

Set the frontAndBack patches to type empty to enforce 2D behavior.

Define the following boundary patches: inlet on the left face (x=0), outlet on the right face (x=4.1), top on the upper face (y=1), and bottom on the lower face (y=0).

Set the inlet patch type to inlet (fixedValue for all fields).

Set the outlet patch type to outlet (zeroGradient for all fields).

Set the top patch to a wall boundary condition.

Set the bottom patch to a symmetryPlane boundary condition.

Use laminar momentumTransport model.

Use ideal-gas thermodynamics with the following properties: molecular weight = 11640.3, Cp = 2.5, Pr = 1, dynamic viscosity = 0, heat of formation Hf = 0.

Set transport model to const with mu = 0 and Pr = 1.

Initialize the internal field with U = (2.9 0 0), p = 1, T = 1.

At the inlet boundary, set U = (2.9 0 0), p = 1, T = 1 as fixedValue.

At the top wall boundary, set U = (2.61933 -0.50632 0) as fixedValue, set T = 1.25853 as fixedValue, and set p to zeroGradient.

At the outlet boundary, set U, p, and T all to zeroGradient.

At the bottom symmetryPlane boundary, apply symmetryPlane condition to all fields.

At the frontAndBack patches, apply empty condition to all fields.

Set deltaT = 0.0025 in the controlDict.

Set endTime = 10 in the controlDict.

Set writeInterval = 1 in the controlDict.

Set the application field in controlDict to rhoCentralFoam.

Use the flux scheme settings appropriate for rhoCentralFoam, including Kurganov scheme for flux interpolation in fvSchemes.
