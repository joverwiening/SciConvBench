Use simpleFoam as the steady-state incompressible flow solver.
Use the k-epsilon RANS turbulence model.
The fluid is water with a kinematic viscosity of 1e-6 m²/s.
The pipe diameter is 0.1 m.
The inlet velocity is 1 m/s, giving a Reynolds number of approximately 100,000.

In the 0/k file, set internalField to uniform 0.00375.
In the 0/epsilon file, set internalField to uniform 0.001.
These values are derived from 5% turbulence intensity and a turbulent length scale of 0.07 times the pipe diameter.

For the inlet boundary condition in 0/k, use a fixedValue of uniform 0.00375.
For the inlet boundary condition in 0/epsilon, use a fixedValue of uniform 0.001.
For the outlet boundary condition in 0/k, use zeroGradient.
For the outlet boundary condition in 0/epsilon, use zeroGradient.
For the pipe wall boundary condition in 0/k, use the kqRWallFunction wall function.
For the pipe wall boundary condition in 0/epsilon, use the epsilonWallFunction wall function.

In the 0/U file, set the inlet boundary condition to fixedValue uniform (1 0 0).
In the 0/U file, set the outlet boundary condition to zeroGradient.
In the 0/U file, set the pipe wall boundary condition to noSlip.

In the 0/p file, set the inlet boundary condition to zeroGradient.
In the 0/p file, set the outlet boundary condition to fixedValue uniform 0.
In the 0/p file, set the pipe wall boundary condition to zeroGradient.

In constant/turbulenceProperties, set simulationType to RAS, model to kEpsilon, and turbulence to on.
In constant/transportProperties, set the kinematic viscosity nu to 1e-6 m²/s.

In system/fvSchemes, use Gauss linear for gradient schemes, Gauss linearUpwind grad(U) for the divergence of U, Gauss linear corrected for Laplacian schemes, and linear interpolation.
In system/fvSolution, use SIMPLE algorithm with nNonOrthogonalCorrectors set to 1.
Set relaxation factors for U to 0.7, for p to 0.3, and for k and epsilon to 0.5.
Set convergence residual tolerance to 1e-5 for all fields.
Run the simulation until residuals for all fields drop below 1e-5 or for a maximum of 1000 iterations.
