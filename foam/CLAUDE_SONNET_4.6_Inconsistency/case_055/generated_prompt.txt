Create an OpenFOAM case for compressible air flow through a 2D converging-diverging nozzle using rhoCentralFoam.

GEOMETRY
The nozzle is 2D (unit depth in z, one cell thick).
The nozzle length is 1.0 m total: 0.5 m converging section and 0.5 m diverging section.
The inlet height is 0.2 m.
The throat height is 0.1 m.
The outlet height is 0.2 m.
The nozzle wall profile follows a smooth cosine-based contraction and expansion between these heights.

MESH
Generate the mesh using blockMesh.
Use 200 cells in the streamwise (x) direction and 40 cells in the cross-stream (y) direction.
Use one cell in the z direction (empty direction for 2D).
Apply grading to cluster cells near the throat and near the nozzle wall.
Define boundary patches: inlet (left face), outlet (right face), nozzleWall (top curved wall), symmetry (bottom centerline, type symmetryPlane), frontAndBack (z-faces, type empty).

THERMOPHYSICAL PROPERTIES (constant/thermophysicalProperties)
Use thermoType: hePsiThermo, pureMixture, sutherland, janaf (or sensibleEnthalpy), perfectGas, specie.
Set the fluid as air with molecular weight 28.96 g/mol.
Use Sutherland transport model with As = 1.458e-6 kg/(m s K^0.5) and Ts = 110.4 K.
Set Cp = 1005 J/(kg K) and Pr = 0.71 (used as reference; Sutherland handles mu).

SOLVER
Use rhoCentralFoam as the application in system/controlDict.
Do NOT use nonNewtonianIcoFoam; override the example given in the prompt.

INLET BOUNDARY CONDITIONS (patch: inlet)
Use totalPressure boundary condition for p with p0 = 300000 Pa (3 bar stagnation pressure).
Use totalTemperature boundary condition for T with T0 = 500 K (stagnation temperature).
Set U to pressureInletVelocity (derived from flux).
Set rho to rhoThermo (derived).
Set e or h to totalEnthalpy or equivalent consistent with rhoCentralFoam.

OUTLET BOUNDARY CONDITIONS (patch: outlet)
Set p to waveTransmissive or fixedValue at 101325 Pa to allow supersonic outflow to develop naturally.
If supersonic flow reaches the outlet, use zeroGradient for p to avoid reflecting shocks.
Set U to zeroGradient.
Set T to zeroGradient.

NOZZLE WALL BOUNDARY CONDITIONS (patch: nozzleWall)
Set U to noSlip (adiabatic viscous wall).
Set T to zeroGradient (adiabatic condition).
Set p to zeroGradient.

SYMMETRY BOUNDARY CONDITIONS (patch: symmetry)
Apply symmetryPlane type to all fields.

FRONT AND BACK (patch: frontAndBack)
Set type empty for all fields (2D simulation).

TURBULENCE
Use laminar flow model (no turbulence) for this inviscid-like supersonic nozzle case.
Set simulationType laminar in constant/turbulenceProperties.

NUMERICAL SCHEMES (system/fvSchemes)
Use Kurganov-Tadmor (KT) flux scheme as required by rhoCentralFoam.
Set divSchemes to use linearUpwind or van Leer limiter for robustness.
Use Gauss linear for gradSchemes.
Use Gauss linear corrected for laplacianSchemes.

SOLUTION CONTROLS (system/fvSolution)
Use default rhoCentralFoam solver settings (no iterative pressure loop needed; density-based explicit time-stepping).

TIME CONTROL (system/controlDict)
Set application to rhoCentralFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 0.01 s.
Set deltaT to 1e-7 s (small enough for CFL < 1 at supersonic conditions).
Set maxCo to 0.5.
Set adjustTimeStep to yes.
Set writeInterval to 0.001 s.
Set writeFormat to ascii.

INITIAL CONDITIONS (0/ directory)
Initialize the entire domain with p = 101325 Pa, T = 300 K, U = (1 0 0) m/s (small non-zero to aid startup).
Compute rho from perfect gas: rho = p / (R_specific * T) where R_specific = 287 J/(kg K).

EXPECTED RESULT
The simulation should develop a choked (Mach 1) condition at the throat and supersonic flow (Mach > 1) in the diverging section, consistent with isentropic nozzle theory for the given area ratio of 2 (outlet area / throat area).
