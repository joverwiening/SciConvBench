The simulation is a thermo-elastic deformation of a solid aluminum block using OpenFOAM's solidDisplacementFoam solver.

Assume a block geometry of 0.1 m x 0.1 m x 0.1 m (a unit-scale cube appropriate for structural thermal studies).

Use a mesh of 10 x 10 x 10 cells (blockMesh), which is sufficient for a first-order thermo-elastic solution and consistent with best practices for demonstration cases.

The block is meshed using blockMesh with uniform cell distribution in all three directions.

Label the face at x=0 as fixedFace and the face at x=0.1 as heatedFace. All remaining faces are free (no mechanical constraint, zeroGradient for displacement).

Create the file constant/mechanicalProperties with the following aluminum properties: E = 69e9 Pa, nu = 0.33, rho = 2700 kg/m^3.

Create the file constant/thermalProperties with: alpha = 2.3e-5 1/K, T0 = 300 K.

Create the file 0/D (displacement field) with dimensions [0 1 0 0 0 0 0], internalField uniform (0 0 0), fixedFace as fixedValue uniform (0 0 0), and all other faces as zeroGradient.

Create the file 0/T (temperature field) with dimensions [0 0 0 1 0 0 0], internalField uniform 300, heatedFace as fixedValue uniform 400, fixedFace as zeroGradient, and all other faces as zeroGradient.

In system/controlDict, set application to solidDisplacementFoam (not buoyantPimpleFoam, which is incorrect for this case and must be overridden).

Set startTime to 0, endTime to 1, deltaT to 1, and writeInterval to 1 in controlDict, since this is a steady-state structural solve.

In system/fvSchemes, use default Gauss linear for gradient and Gauss linear corrected for Laplacian schemes.

In system/fvSolution, use PCG solver with DIC preconditioner for the displacement field D, with tolerance 1e-6 and relTol 0.01.

solidDisplacementFoam will solve for displacement field D and derive stress field sigma from the constitutive relation including thermal strain: epsilon_thermal = alpha * (T - T0) * I.

After the run, post-process using paraFoam or foamToVTK to visualize displacement magnitude and von Mises stress across the block.

The expected physical result is expansion in the x-direction (toward the heated face) with maximum displacement at the heatedFace and zero displacement at the fixedFace, and compressive stress near the fixed boundary.
