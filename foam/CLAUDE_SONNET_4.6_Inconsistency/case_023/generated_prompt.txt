The simulation is a 2D developing flow in a channel using simpleFoam.
Only the bottom half of the channel is meshed to reduce computational cost.
The channel centerline is treated as a symmetry plane.
In system/blockMeshDict, change the centerline patch type from wall to symmetry.
The corrected centerline patch block in blockMeshDict should read: centerline { type symmetry; faces ( (3 7 6 2) ); }
In 0/U, change the boundary condition for the centerline patch from noSlip to symmetry.
The corrected centerline entry in 0/U should read: centerline { type symmetry; }
The inlet, outlet, and bottomWall patches remain unchanged in both blockMeshDict and 0/U.
The frontAndBack patches remain set to type empty in blockMeshDict and use the corresponding empty boundary condition in 0/U.
No other files require changes to implement the symmetry plane correction.
