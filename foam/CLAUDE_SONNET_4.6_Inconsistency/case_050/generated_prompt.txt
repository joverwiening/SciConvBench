Simulate a 2D supersonic jet using OpenFOAM with the domain extruded one cell in the z-direction and frontAndBack patches set to empty.

Use rhoPimpleFoam as the solver, not pimpleFoam, because the flow is compressible and high-speed. Update application in system/controlDict to rhoPimpleFoam.

Treat air as a calorically perfect gas using hePsiThermo with pureMixture, perfectGas equation of state, janaf or sensibleEnthalpy thermodynamics, and sutherland transport.

Set the molecular weight of air to 28.96 kg/kmol, mu0 (reference viscosity) to 1.716e-05 kg/m/s, Tref to 273.15 K, and Sref to 110.4 K for Sutherland transport.

Set Cp to 1005 J/kg/K and Pr to 0.71.

Geometry: define a rectangular nozzle inlet of height 0.01 m (10 mm) centered on the x-axis at x = 0. The nozzle duct extends from x = -0.05 m to x = 0 m. The discharge domain extends from x = 0 to x = 0.5 m in the streamwise direction and from y = -0.1 m to y = 0.1 m in the transverse direction. This gives a domain that is 50 nozzle diameters long and 20 nozzle diameters wide, consistent with best practices for supersonic jet simulations.

Use a structured quad mesh. Cluster cells near the jet shear layer and near the nozzle lip. Use a cell size of approximately 0.0005 m near the jet centerline and nozzle exit, grading outward to coarser cells at the far-field boundaries.

Inlet Mach number is 2.0. Set inlet boundary conditions as fixedValue: U = (686 0 0) m/s, T = 300 K, p = 101325 Pa. These correspond to a Mach 2 flow in air at 300 K.

Use RANS turbulence modeling with the k-omega SST model, as this is the best-practice choice for free shear flows and shock-boundary-layer interactions at supersonic speeds.

Set turbulent inlet conditions: turbulence intensity of 1% and turbulent length scale of 0.001 m. Compute k and omega from these values at the inlet as fixedValue.

Far-field top and bottom boundaries: use waveTransmissive for p and T, and zeroGradient for U, k, and omega.

Outlet (right boundary, x = 0.5 m): use waveTransmissive for p and T, zeroGradient for U, k, and omega.

Nozzle walls and any solid surfaces: use noSlip for U, zeroGradient for p, zeroGradient for T (adiabatic wall), and standard wall functions for k and omega (kqRWallFunction and omegaWallFunction).

In system/controlDict, set startTime to 0, endTime to 0.005 s, and deltaT to 1e-7 s. This gives an initial CFL well below 1 given the domain size and inlet velocity.

Enable adjustableRunTime with maxCo set to 0.5 so the solver adjusts the time step to maintain CFL below 0.5 throughout the run.

Set writeInterval to 0.0005 s to capture 10 solution snapshots.

In system/fvSchemes, use Gauss limitedLinear or Gauss vanLeer for divergence schemes to handle shocks without spurious oscillations. Use Gauss linear for gradient schemes and linear corrected for Laplacian schemes.

In system/fvSolution, use PIMPLE with nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1. Set pRefCell and pRefValue only if no pressure boundary is fully fixed; since waveTransmissive is used, no additional reference is needed.

Enable residual convergence criteria: set convergence tolerance to 1e-6 for all fields within each PIMPLE loop.

Run the simulation to capture transient shock structure and shear layer development. The end time of 0.005 s allows the jet to establish across the full domain length at the given inlet velocity.
