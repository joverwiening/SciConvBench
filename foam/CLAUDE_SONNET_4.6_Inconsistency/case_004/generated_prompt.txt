Run a 2D gas-liquid bubble column simulation using multiphaseEulerFoam (Euler-Euler approach) in OpenFOAM.

DOMAIN AND MESH
The rectangular domain spans x in [0, 0.15] m, y in [0, 1.00] m, z in [0, 0.10] m with height along the +y direction and thin in the z direction.
Use a structured hex mesh with 25 x 75 x 1 cells and simpleGrading (1 1 1).
Define four boundary patches in blockMeshDict: inlet (bottom face, y=0), outlet (top face, y=1), walls (side faces at x=0 and x=0.15), and frontAndBack (z-normal faces treated as wall boundary type).

BLOCK MESH DICT
The blockMeshDict vertices define the eight corners of the box.
The single block uses hex connectivity with 25 75 1 cells and simpleGrading (1 1 1).
The inlet patch is the face at y=0 (bottom).
The outlet patch is the face at y=1.00 (top).
The walls patch groups the two faces at x=0 and x=0.15.
The frontAndBack patch groups the two faces at z=0 and z=0.10 and is of type wall.

PHASES
Define two phases: air (dispersed) and water (continuous, reference phase).
Set residualAlpha to 1e-6 for both phases.

WATER PHASE THERMOPHYSICAL PROPERTIES
Use heRhoThermo with rPolynomial equation of state for water.
Set rPolynomial C coefficients to (0.001278 -2.1055e-06 3.9689e-09 4.3772e-13 -2.0225e-16).
Set molecular weight of water to 18 kg/kmol.
Set Cv of water to 4195 J/(kg·K).
Set dynamic viscosity of water to 3.645e-4 Pa·s.
Set Prandtl number of water to 2.289.
Use specie, equationOfState, thermo, and transport sub-dictionaries consistent with heRhoThermo rPolynomial hConst const thermophysics.

AIR PHASE THERMOPHYSICAL PROPERTIES
Use heRhoThermo with perfectGas equation of state for air.
Set molecular weight of air to 28.9 kg/kmol.
Set Cp of air to 1007 J/(kg·K).
Set dynamic viscosity of air to 1.84e-05 Pa·s.
Set Prandtl number of air to 0.7.
Use specie, equationOfState, thermo, and transport sub-dictionaries consistent with heRhoThermo perfectGas hConst const thermophysics.

GRAVITY
Set g to (0 -9.81 0) m/s² in the constant/g file.

BUBBLE SIZE MODELS
Use isothermal diameter model for air with d0 = 3e-3 m.
Use constant diameter model for water with d = 1e-4 m.

MOMENTUM TRANSPORT
Set simulationType to laminar in the momentumTransport file for both air and water phases.

PHASE INTERACTION MODELS (phaseProperties)
Define phases as (air water) with water as the referencePhase.
Use linear blending with minFullyContinuousAlpha 0.7 and minPartlyContinuousAlpha 0.3 as the default blending parameters.
Use linear blending with minFullyContinuousAlpha 0.5 and minPartlyContinuousAlpha 0.3 for drag blending.
Set surface tension between air and water to constant with sigma = 0.07 N/m.
Use SchillerNaumann drag model for air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water configurations.
Use constantCoefficient virtual mass model with Cvm = 0.5 for both air-in-water and water-in-air directions.
Use RanzMarshall heat transfer model for both directions with residualAlpha = 1e-4.

INITIAL CONDITIONS (0/ directory)
Set U.water to uniform (0 0 0).
Set U.air to uniform (0 0.1 0).
Set alpha.water to uniform 1.
Set alpha.air to uniform 0 as the default field value, except in the box region from (0 0 0) to (0.15 0.701 0.1) where alpha.air is 0 and alpha.water is 1.
Set p_rgh to uniform 1e5 Pa.
Set T.air to uniform 300 K.
Set T.water to uniform 350 K.
Use setFieldsDict to apply the box region override: set alpha.air to 0 and alpha.water to 1 in the box from (0 0 0) to (0.15 0.701 0.1).
The default field values outside the box set alpha.air to 1 and alpha.water to 0.

BOUNDARY CONDITIONS
At the inlet patch:
Set U.air to fixedValue (0 0.1 0).
Set U.water to fixedValue (0 0 0).
Set alpha.air to fixedValue 0.5.
Set alpha.water to fixedValue 0.5.
Set T.air to fixedValue 300 K.
Set T.water to fixedValue 350 K.
Set p_rgh to fixedFluxPressure.

At the outlet patch:
Set U.air and U.water to pressureInletOutletVelocity with value uniform (0 0 0).
Set alpha.air and alpha.water to zeroGradient.
Set T.air and T.water to zeroGradient.
Set p_rgh to totalPressure with p0 uniform 1e5.

At the walls patch and frontAndBack patch:
Set U.air to fixedValue (0 0 0).
Set U.water to fixedValue (0 0 0).
Set alpha.air to zeroGradient.
Set alpha.water to zeroGradient.
Set p_rgh to fixedFluxPressure.
Set T.air to zeroGradient.
Set T.water to zeroGradient.

TIME CONTROLS (controlDict)
Set application to multiphaseEulerFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 20 s.
Set deltaT to 0.005 s.
Set adjustTimeStep to no.
Set maxCo to 0.5.
Set maxDeltaT to 1.
Set writeControl to runTime with writeInterval 1 s.
Set writeFormat to ascii and writePrecision to 6.
Set runTimeModifiable to yes.

FV SCHEMES (fvSchemes)
Set ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear.
Set divSchemes for div(phi.air,U.air) to Gauss limitedLinearV 1.
Set divSchemes for div(phi.water,U.water) to Gauss limitedLinearV 1.
Set divSchemes for div(phi.air,alpha.air) and div(phi.water,alpha.water) to Gauss vanLeer.
Set divSchemes for div(phi.air,T.air) and div(phi.water,T.water) to Gauss limitedLinear 1.
Set divSchemes for div(phi.air,p) and div(phi.water,p) to Gauss limitedLinear 1.
Set divSchemes default to Gauss linear for any remaining divergence terms.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.

FV SOLUTION (fvSolution)
Use a PIMPLE outer-loop with nOuterCorrectors 3, nCorrectors 2, and nNonOrthogonalCorrectors 1.
Set momentumPredictor to yes.
For the p_rgh solver use GAMG with smoother DICGaussSeidel, tolerance 1e-8, relTol 0.01, and agglomerator faceAreaPair.
For U.air and U.water solvers use PBiCGStab with preconditioner DILU, tolerance 1e-8, and relTol 0.001.
For alpha.air and alpha.water solvers use PBiCGStab with preconditioner DILU, tolerance 1e-10, and relTol 0.
For T.air and T.water solvers use PBiCGStab with preconditioner DILU, tolerance 1e-8, and relTol 0.001.
Set relaxation factors for p_rgh to 0.3, for U.air and U.water to 0.7, and for T.air and T.water to 0.7 within the PIMPLE loop.
