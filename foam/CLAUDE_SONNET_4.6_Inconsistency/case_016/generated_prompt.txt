Final Specification:

Create an OpenFOAM case for a 2D inviscid laminar oblique-shock simulation.

Use blockMesh to generate a rectangular domain from (0, 0, 0) to (4.1, 1, 0.1).
Extrude the domain one cell in the z-direction to enforce 2D behavior.
Use 60 cells in x, 30 cells in y, and 1 cell in z.
Set simpleGrading to (1 1 1) with no grading.

Assign the patch named "inlet" to the left face (x=0).
Assign the patch named "outlet" to the right face (x=4.1).
Assign the patch named "top" to the top face (y=1).
Assign the patch named "bottom" to the bottom face (y=0).
Assign the patch named "frontAndBack" to the z-normal faces and set its type to empty.

Use rhoCentralFoam as the solver.

In constant/thermophysicalProperties, use the hePsiThermo model with pureMixture.
Use the perfectGas equation of state.
Use sensibleInternalEnergy as the thermo type.
Set Cp to 2.5.
Set Pr to 1.
Set dynamic viscosity mu to 1e-5.
Set molecular weight (molWeight) to 11640.3.
Set heat of formation Hf to 0.

In constant/momentumTransport (or turbulenceProperties), set the simulation type to laminar.

In the 0/U file, set the internal field to uniform (2.9 0 0).
Set the inlet boundary condition for U to fixedValue uniform (2.9 0 0).
Set the outlet boundary condition for U to zeroGradient.
Set the top boundary condition for U to fixedValue uniform (2.61933 -0.50632 0).
Set the bottom boundary condition for U to symmetryPlane.
Set frontAndBack for U to empty.

In the 0/p file, set the internal field to uniform 1.
Set the inlet boundary condition for p to fixedValue uniform 1.
Set the outlet boundary condition for p to zeroGradient.
Set the top boundary condition for p to zeroGradient.
Set the bottom boundary condition for p to symmetryPlane.
Set frontAndBack for p to empty.

In the 0/T file, set the internal field to uniform 1.
Set the inlet boundary condition for T to fixedValue uniform 1.
Set the outlet boundary condition for T to zeroGradient.
Set the top boundary condition for T to fixedValue uniform 1.25853.
Set the bottom boundary condition for T to symmetryPlane.
Set frontAndBack for T to empty.

In system/controlDict, set the application to rhoCentralFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 10.
Set deltaT to 0.0025.
Set writeControl to timeStep.
Set writeInterval to 1.
Set writeFormat to ascii.
Set runTimeModifiable to true.

In system/fvSchemes, use Kurganov-Tadmor (KT) or equivalent flux schemes appropriate for rhoCentralFoam.
Use linear interpolation schemes where appropriate.
Use Gauss linear for gradient schemes.
Use linear corrected or equivalent for Laplacian schemes.

In system/fvSolution, set solver tolerances appropriate for rhoCentralFoam density-based solving.
No PISO or SIMPLE loops are required since rhoCentralFoam is a density-based transient solver.

Ensure the case directory structure contains: constant/, system/, and 0/ folders with all required files.
Run blockMesh before executing rhoCentralFoam.
