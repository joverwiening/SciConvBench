Perform a multiphase sludge settling simulation using the driftFluxFoam solver in OpenFOAM.

Use RAS turbulence modeling with the buoyantKEpsilon model.

The domain is a 2D rectangular channel with dimensions 8.65 m in x, 1 m in y, and 0.2 m in z (z from -0.1 to 0.1).

The mesh has two blocks: a lower block (0 1 2 3 6 7 8 9) with 200x4x1 cells from y=0 to y=0.1, and an upper block (3 2 4 5 9 8 10 11) with 200x36x1 cells from y=0.1 to y=1.

All simpleGrading ratios are (1 1 1).

Set the initial condition for velocity (U) as uniform (0.0191 0 0) m/s throughout the domain.

Set the initial condition for alpha.sludge as uniform 0.001 throughout the domain.

Set the initial condition for turbulent kinetic energy k as uniform 0.00015 m2/s2.

Set the initial condition for turbulent dissipation rate epsilon as uniform 1.50919e-06 m2/s3.

Set the initial condition for pressure p_rgh as uniform 0.

For the inlet boundary, apply fixedValue velocity of (0.0191 0 0) m/s.

For the inlet boundary, apply fixedValue alpha.sludge of 0.001.

For the inlet boundary, apply fixedValue k of 0.00015 m2/s2.

For the inlet boundary, apply fixedValue epsilon of 1.50919e-06 m2/s3.

For the outlet boundary, apply zeroGradient for alpha.sludge.

For the outlet boundary, apply pressureInletOutletVelocity for U.

For the outlet boundary, apply fixedValue p_rgh of 0 (zero gauge pressure).

For the outlet boundary, apply zeroGradient for k and epsilon.

For bottomWall and endWall boundaries, apply noSlip for U.

For bottomWall and endWall boundaries, apply kqRWallFunction for k.

For bottomWall and endWall boundaries, apply epsilonWallFunction for epsilon.

For bottomWall and endWall boundaries, apply nutkWallFunction for nut.

For bottomWall and endWall boundaries, apply zeroGradient for alpha.sludge.

For the top boundary, apply slip for U.

For the top boundary, apply zeroGradient for alpha.sludge, k, epsilon, and p_rgh.

For frontAndBack, apply empty type for all fields.

Define the sludge phase with density rho = 1996 kg/m3.

Define the sludge viscosity model as BinghamPlastic with plastic viscosity coefficients coeff = 0.00023143 and exponent = 179.26.

Use a Newtonian nu of 1e-06 m2/s for the sludge phase as the base (solvent) viscosity in the BinghamPlastic model.

Define the water phase with constant kinematic viscosity nu = 1.7871e-06 m2/s and density rho = 996 kg/m3.

Set gravity as (0 -9.81 0) m/s2 in the g file.

Define the relative velocity model as simple drift flux with Vc = 2.241e-4 m/s.

In transportProperties, name the two phases as sludge and water.

Use the PIMPLE algorithm with nCorrectors = 3.

Enable adjustable time stepping with adjustTimeStep yes.

Set the initial deltaT to 0.1 s.

Set maxCo (maximum Courant number) to 5.

Set the simulation start time to 0 s and end time to 6400 s.

Set writeInterval to 50 time units.

Set writeControl to timeStep or runTime such that results are written every 50 time units.

Use writeFormat ascii.

Set runTimeModifiable to yes.

Create the system/fvSchemes file with ddtSchemes using Euler, gradSchemes using Gauss linear, divSchemes using Gauss linearUpwind for div(phi,U) and Gauss vanLeer for div(phi,alpha), laplacianSchemes using Gauss linear corrected, and interpolationSchemes as linear.

Create the system/fvSolution file with PIMPLE settings: nCorrectors 3, nNonOrthogonalCorrectors 1, and appropriate solvers for p_rgh (PCG with DIC preconditioner), U (PBiCGStab with DILU), alpha (PBiCGStab with DILU), k and epsilon (PBiCGStab with DILU).
