Set up a 2D steady-state simulation of natural convection in a tall, sealed cavity using OpenFOAM.

Use the buoyantBoussinesqSimpleFoam solver.

The fluid is air with Boussinesq approximation properties appropriate for air.

Gravity acts in the negative y-direction, set g to (0 -9.81 0) m/s².

The cavity is 2D, meaning it is one cell thick in the z-direction with empty boundary conditions on the front and back faces.

The left wall is the hot wall with a fixed temperature of 350 K.

The right wall is the cold wall with a fixed temperature of 300 K.

The top wall is adiabatic; use zeroGradient for temperature on the top wall.

The bottom wall is adiabatic; use zeroGradient for temperature on the bottom wall.

The boundary condition for temperature T is as follows.

For leftWall: type fixedValue, value uniform 350.

For rightWall: type fixedValue, value uniform 300.

For topWall: type zeroGradient.

For bottomWall: type zeroGradient.

For the front and back faces: type empty.

Set the reference temperature Tref to 325 K (the mean of hot and cold wall temperatures) for the Boussinesq buoyancy term.

Apply no-slip boundary conditions for velocity U on all four walls (leftWall, rightWall, topWall, bottomWall).

Set the initial internal field for temperature T to uniform 325 K.

Set the initial internal field for velocity U to uniform (0 0 0).

Set the initial internal field for pressure p_rgh to uniform 0.

Apply zeroGradient for p_rgh on all four walls.

Use buoyantPressure type for p_rgh on all four walls if required by the solver.

Configure the turbulence model as laminar, as natural convection in a cavity is typically solved in the laminar regime unless otherwise specified.

Set up the transportProperties dictionary with air properties: kinematic viscosity nu = 1.516e-5 m²/s, thermal expansion coefficient beta = 3.43e-3 1/K (appropriate for air at 325 K), Prandtl number Pr = 0.707, and thermal diffusivity DT derived accordingly.

Set up the thermophysicalProperties dictionary consistent with buoyantBoussinesqSimpleFoam requirements for air.

Configure fvSolution and fvSchemes appropriate for a steady-state buoyancy-driven flow using SIMPLE algorithm.

Set up the controlDict to run the simulation for a sufficient number of iterations (e.g., 1000 iterations) with writeInterval of 100.
