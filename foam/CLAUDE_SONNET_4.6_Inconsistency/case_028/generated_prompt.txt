Create a 2D laminar incompressible flow simulation through a channel using the icoFoam solver in OpenFOAM.
The simulation domain is 1m long (x), 0.1m high (y), and 0.01m deep (z).
Generate the mesh using blockMesh with one cell thick in the z-direction to enforce the 2D condition.
Use a mesh resolution of 100 cells in x, 20 cells in y, and 1 cell in z.
Define the blockMeshDict vertices as (0 0 0), (1 0 0), (1 0.1 0), (0 0.1 0), (0 0 0.01), (1 0 0.01), (1 0.1 0.01), (0 0.1 0.01).
Define the block with hex notation covering all 8 vertices with 100 20 1 cells and simpleGrading (1 1 1).
Define the following boundaries in blockMeshDict: inlet, outlet, topWall, bottomWall, and frontAndBack.
Set the inlet patch type to patch, covering the left face of the domain.
Set the outlet patch type to patch, covering the right face of the domain.
Set the topWall patch type to wall, covering the top face of the domain.
Set the bottomWall patch type to wall, covering the bottom face of the domain.
Set the frontAndBack patch type to empty, covering the front face (0 4 7 3) and back face (1 2 6 5).
In the U (velocity) field initial conditions file, set the internal field to uniform (0 0 0).
Set the inlet boundary condition for U to fixedValue uniform (0.01 0 0), giving a mean inlet velocity of 0.01 m/s in the x-direction.
Set the outlet boundary condition for U to zeroGradient.
Set the topWall boundary condition for U to fixedValue uniform (0 0 0) to enforce no-slip.
Set the bottomWall boundary condition for U to fixedValue uniform (0 0 0) to enforce no-slip.
Set the frontAndBack boundary condition for U to empty.
In the p (pressure) field initial conditions file, set the internal field to uniform 0.
Set the inlet boundary condition for p to zeroGradient.
Set the outlet boundary condition for p to fixedValue uniform 0.
Set the topWall boundary condition for p to zeroGradient.
Set the bottomWall boundary condition for p to zeroGradient.
Set the frontAndBack boundary condition for p to empty.
In the transportProperties file, set the kinematic viscosity nu to 1e-4 m2/s.
This gives a Reynolds number of approximately 10 (Re = U*H/nu = 0.01 * 0.1 / 1e-4), confirming laminar flow.
In the controlDict file, set the application to icoFoam.
Set startTime to 0.
Set endTime to 10.
Set deltaT (time step) to 0.005, giving a Courant number well below 1.
Set writeInterval to 0.5 to save results every 0.5 seconds.
Set writeFormat to ascii.
Set runTimeModifiable to true.
In the fvSchemes file, use Euler for ddtSchemes, Gauss linear for gradSchemes, Gauss linear corrected for laplacianSchemes, and linear interpolation for interpolationSchemes.
In the fvSolution file, use PCG solver with DIC preconditioner for p, and PBiCG solver with DILU preconditioner for U.
Set the PISO dictionary with nCorrectors 2 and nNonOrthogonalCorrectors 0.
Run blockMesh to generate the mesh, then run icoFoam to execute the simulation.
The expected result is a fully developed parabolic (Poiseuille) velocity profile at the outlet after sufficient simulation time.
