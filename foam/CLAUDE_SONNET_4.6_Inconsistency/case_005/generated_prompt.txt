Run a twoPhaseEulerFoam (Euler–Euler) simulation of a 2D gas–liquid bubble column in OpenFOAM.

DOMAIN AND MESH
The rectangular domain spans x in [0, 0.15] m, y in [0, 1.00] m, z in [0, 0.10] m with height along the +y direction and one cell thick in z.
Define the blockMeshDict with vertices at the eight corners of this box.
Use a structured hex mesh with 25 cells in x, 75 cells in y, and 1 cell in z, with simpleGrading (1 1 1).
Define the following patches in blockMeshDict: inlet (bottom face, y=0), outlet (top face, y=1.00), walls (left and right faces in x), and frontAndBack (z-normal faces) typed as empty for 2D treatment.

THERMOPHYSICAL PROPERTIES — WATER (CONTINUOUS LIQUID PHASE)
The liquid phase is named water and uses heRhoThermo with rPolynomial equation of state.
Set the rPolynomial C coefficients to (0.001278 -2.1055e-06 3.9689e-09 4.3772e-13 -2.0225e-16).
Set molecular weight to 18 kg/kmol.
Set Cv to 4195 J/(kg·K).
Set dynamic viscosity mu to 3.645e-4 Pa·s.
Set Prandtl number Pr to 2.289.
Use hConst or eConst transport consistent with Cv specification.

THERMOPHYSICAL PROPERTIES — AIR (DISPERSED GAS PHASE)
The gas phase is named air and uses heRhoThermo with perfectGas equation of state.
Set molecular weight to 28.9 kg/kmol.
Set Cp to 1007 J/(kg·K).
Set dynamic viscosity mu to 1.84e-05 Pa·s.
Set Prandtl number Pr to 0.7.

GRAVITY
Set g to (0 -9.81 0) m/s² in the constant/g file.

BUBBLE SIZE MODELS
For air, use isothermalDiameter with d0 = 3e-3 m.
For water, use constantDiameter with d = 1e-4 m.

MOMENTUM TRANSPORT
Set simulationType to laminar in the momentumTransport file for both air and water phases.

PHASE PROPERTIES (phaseProperties)
Define phases as (air water) with water as the reference phase.
Set residualAlpha to 1e-6 for both air and water.
Use linear blending with minFullyContinuousAlpha 0.7 and minPartlyContinuousAlpha 0.3 as the default blending parameters.
For drag blending, use minFullyContinuousAlpha 0.5 and minPartlyContinuousAlpha 0.3.
Set surface tension between air and water to constant with sigma = 0.07 N/m.
Use SchillerNaumann drag model for air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water configurations.
Use constantCoefficient virtual mass model with Cvm = 0.5 for both air-in-water and water-in-air directions.
Use RanzMarshall heat transfer model for both directions with residualAlpha = 1e-4.

INITIAL CONDITIONS (t=0)
Set water velocity U.water to uniform (0 0 0).
Set air velocity U.air to uniform (0 0.1 0).
Set water volume fraction alpha.water to uniform 1.
Set air volume fraction alpha.air to uniform 0 as the field default.
Set p_rgh to uniform 1e5 Pa.
Set T.air to uniform 300 K.
Set T.water to uniform 350 K.
Use setFieldsDict to define a box region from (0 0 0) to (0.15 0.701 0.1) where alpha.water is set to 1 and alpha.air is set to 0, with default field values outside this region being alpha.air = 1 and alpha.water = 0.

BOUNDARY CONDITIONS
At the inlet patch:
Set U.air to fixedValue (0 0.1 0).
Set U.water to fixedValue (0 0 0).
Set alpha.air to fixedValue 0.5.
Set alpha.water to fixedValue 0.5.
Set T.air to fixedValue 300 K.
Set T.water to fixedValue 350 K.
Set p_rgh at inlet to zeroGradient.

At the outlet patch:
Set U.air and U.water to pressureInletOutletVelocity with value uniform (0 0 0).
Set alpha.air and alpha.water to zeroGradient.
Set T.air and T.water to zeroGradient.
Set p_rgh at outlet to totalPressure with p0 uniform 1e5 Pa.

At the walls patch:
Set U.air to fixedValue (0 0 0).
Set U.water to fixedValue (0 0 0).
Set alpha.air to zeroGradient.
Set alpha.water to zeroGradient.
Set p_rgh to fixedFluxPressure.
Set T.air to zeroGradient.
Set T.water to zeroGradient.

At the frontAndBack patch:
Set all fields to empty type.

TIME CONTROLS (controlDict)
Set application to twoPhaseEulerFoam.
Set startFrom to startTime with startTime 0.
Set endTime to 20 s.
Set deltaT to 0.005 s.
Set adjustTimeStep to no.
Set maxCo to 0.5.
Set maxDeltaT to 1.
Set writeControl to runTime with writeInterval 1 s.
Set writeFormat to ascii and writePrecision to 6.
Set runTimeModifiable to yes.

NUMERICAL SCHEMES (fvSchemes)
Set ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear.
Set divSchemes as follows: use Gauss limitedLinear 1 for div(phi.air, U.air) and div(phi.water, U.water); use Gauss vanLeer for div(phir, alpha.air) and div(phir, alpha.water); use Gauss linear for div(phi.air, T.air), div(phi.water, T.water), div(phi.air, e.air), and div(phi.water, e.water); use Gauss linear for div(((rho*nuEff)*dev2(T(grad(U))))) terms.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.
Set fluxRequired fields to p_rgh, alpha.air, alpha.water.

LINEAR SOLVERS (fvSolution)
For p_rgh, use GAMG solver with GaussSeidel smoother, tolerance 1e-8, relTol 0.01, nPreSweeps 0, nPostSweeps 2, cacheAgglomeration on, agglomerator faceAreaPair, nCellsInCoarsestLevel 10, mergeLevels 1.
For U.air and U.water, use PBiCGStab solver with DILU preconditioner, tolerance 1e-7, relTol 0.
For alpha.air and alpha.water, use PBiCGStab solver with DILU preconditioner, tolerance 1e-8, relTol 0.
For T.air, T.water, e.air, and e.water, use PBiCGStab solver with DILU preconditioner, tolerance 1e-7, relTol 0.
For the PIMPLE loop, set nOuterCorrectors to 3, nCorrectors to 2, nNonOrthogonalCorrectors to 0, and pRefCell 0 with pRefValue 1e5.
Set momentumPredictor to yes.
