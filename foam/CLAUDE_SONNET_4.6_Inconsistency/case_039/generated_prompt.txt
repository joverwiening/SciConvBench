Set up a classic 2D dam-break simulation using OpenFOAM with the interFoam solver.

Use `interFoam` as the application in `system/controlDict`.

Create a 2D mesh that is extruded exactly one cell in the spanwise (z) direction.

Set the `frontAndBack` patch type to `empty` in the mesh and in all field boundary condition files to enforce 2D behaviour.

Track the free surface using the VOF field `alpha.water`.

Initialize the water column by running `setFields`: set `alpha.water = 1` inside the initial water column region and `alpha.water = 0` everywhere else (air).

Set gravity to `(0 -9.81 0)` in `constant/g`.

Apply the following boundary conditions on all tank wall patches (bottom and side walls):
- `U`: `noSlip`
- `p_rgh`: `zeroGradient`
- `alpha.water`: `zeroGradient`

Apply the following boundary conditions on the open top patch:
- `U`: `pressureInletOutletVelocity` with `value uniform (0 0 0)`
- `p_rgh`: `totalPressure` with a fixed reference value of 0 (or `fixedValue uniform 0`)
- `alpha.water`: `inletOutlet` with `inletValue uniform 0` and `value uniform 0`

Apply `empty` boundary conditions on the `frontAndBack` patch for all fields (`U`, `p_rgh`, `alpha.water`).

In `system/controlDict`, set `application interFoam`.

Use `system/setFieldsDict` to define the rectangular region corresponding to the initial water column and assign `alpha.water = 1` within it.

Include `transportProperties` in the `constant` directory defining the two phases (water and air) with appropriate kinematic viscosities and densities.

Include `turbulenceProperties` in the `constant` directory; set the simulation to laminar unless otherwise specified.
