The simulation is a 2D dam break problem in OpenFOAM.
Use the interFoam solver (not pimpleFoam, as interFoam is the correct VOF multiphase solver for free-surface dam break problems; pimpleFoam is single-phase and cannot handle alpha.water transport).
The rectangular domain is 4 m long and 2 m tall (in the x and y directions respectively).
The domain has a depth of 0.1 m in the z-direction (one cell thick for 2D).
The water column is 1 m wide and 1 m tall, positioned at the left side of the domain (x from 0 to 1, y from 0 to 1).
The remaining domain is initialized with air (alpha.water = 0).
Use a structured mesh with 400 cells in x, 200 cells in y, and 1 cell in z.
Set the mesh using blockMesh.
Use setFields to initialize alpha.water = 1 inside the water column region (box from (0 0 0) to (1 1 0.1)) and alpha.water = 0 everywhere else.
In controlDict, set application to interFoam.
In controlDict, set startTime to 0.
In controlDict, set endTime to 5.
In controlDict, set deltaT to 0.001.
In controlDict, set writeControl to adjustableRunTime.
In controlDict, set writeInterval to 0.1.
In controlDict, set maxCo to 0.5.
In controlDict, set adjustTimeStep to yes.
Gravity is defined in the g file as (0 -9.81 0) m/s^2.
In transportProperties, define two phases: water and air.
For water, set nu (kinematic viscosity) to 1e-6 m^2/s and rho (density) to 1000 kg/m^3.
For air, set nu to 1.48e-5 m^2/s and rho to 1 kg/m^3.
Use the standard turbulence model setting of laminar for this simulation.
Boundary conditions: set the bottom and side walls (left, right, bottom) as no-slip walls (fixedValue U = (0 0 0), zeroGradient p_rgh, zeroGradient alpha.water).
Set the top boundary as an atmosphere (totalPressure for p_rgh, pressureInletOutletVelocity for U, inletOutletValue for alpha.water = 0).
Set the front and back patches as empty (2D simulation).
Use the MULES scheme for alpha.water with nAlphaCorr 2 and nAlphaSubCycles 1.
Use the fvSolution settings standard for interFoam: GAMG solver for p_rgh, smoothSolver for U and alpha.water.
Use linear schemes for gradient and interpolation in fvSchemes.
Use Gauss limitedLinear01 for the div(phi,alpha) scheme.
