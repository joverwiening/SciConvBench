Simulate 2D steady-state turbulent incompressible flow over a NACA 0012 airfoil at a 5-degree angle of attack using OpenFOAM's simpleFoam solver.

Assume a chord length of 1.0 meter.
Assume a freestream velocity magnitude of 10 m/s in the x-direction (inlet U = (10 0 0) m/s, not (10 0 0.1); the z-component is zeroed since this is a 2D simulation with symmetry in z).
Assume air kinematic viscosity nu = 1.5e-5 m^2/s, giving a Reynolds number of approximately 6.67e5.
Use the k-omega SST turbulence model.

Geometry and Mesh:
Generate a NACA 0012 airfoil profile with chord length 1.0 m, rotated to a 5-degree angle of attack.
Use a C-grid topology for the mesh around the airfoil.
Extrude the mesh one cell in the z-direction with a thickness of 0.1 m to create the quasi-2D domain.
The far-field boundary should extend at least 20 chord lengths from the airfoil in all directions.
In blockMeshDict, name the front and back patches 'frontAndBack' and set their type to 'symmetry'.

Boundary Conditions in the 0 directory:
For U: set inlet to fixedValue with uniform (10 0 0), outlet to zeroGradient, airfoil surface to noSlip, frontAndBack to symmetry.
For p: set inlet to zeroGradient, outlet to fixedValue with uniform 0, airfoil surface to zeroGradient, frontAndBack to symmetry.
For k: compute inlet turbulence intensity at 1% (I = 0.01), giving k_inlet = 1.5*(U*I)^2 = 1.5*(10*0.01)^2 = 0.015 m^2/s^2, set inlet to fixedValue uniform 0.015, outlet to zeroGradient, airfoil surface to kqRWallFunction with uniform 0, frontAndBack to symmetry.
For omega: compute inlet omega using omega = k^0.5 / (Cmu^0.25 * L) where L = 0.07 * chord = 0.07 m, giving omega_inlet approximately 111 s^-1, set inlet to fixedValue uniform 111, outlet to zeroGradient, airfoil surface to omegaWallFunction, frontAndBack to symmetry.
For nut: set inlet to calculated with uniform 0, outlet to calculated, airfoil surface to nutkWallFunction with uniform 0, frontAndBack to symmetry.

Solver Settings in system/fvSolution:
Use GAMG solver for p with tolerance 1e-6 and relTol 0.1.
Use smoothSolver with GaussSeidel for U, k, and omega with tolerance 1e-8 and relTol 0.1.
Set relaxation factors: U = 0.7, p = 0.3, k = 0.5, omega = 0.5.

Solver Settings in system/fvSchemes:
Use Gauss linear for gradSchemes.
Use Gauss linearUpwind grad(U) for divSchemes for U, and Gauss upwind for k and omega.
Use Gauss linear corrected for laplacianSchemes.

Run Control in system/controlDict:
Set application to simpleFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 3000 iterations.
Set deltaT to 1.
Set writeInterval to 500.

Post-processing:
Add a forceCoeffs function object in controlDict to compute lift and drag coefficients.
Set the reference velocity Uref = 10 m/s, reference area Aref = 1.0 m^2 (chord times unit span of 0.1 m times 10 to normalize, or use Aref = chord * span = 1.0 * 0.1 = 0.1 m^2 with appropriate liftDir and dragDir).
Set liftDir to (-sin(5deg) cos(5deg) 0) = (-0.08716 0.99619 0) to account for the angle of attack.
Set dragDir to (cos(5deg) sin(5deg) 0) = (0.99619 0.08716 0) to account for the angle of attack.
Set pitchAxis to (0 0 1).
Set magUInf = 10, rhoInf = 1.225, Aref = 0.1, lRef = 1.0.
The airfoil patch in forceCoeffs should be named 'airfoil'.
Run simpleFoam and monitor residuals and force coefficients for convergence.
Extract the final Cl and Cd values from the forceCoeffs output file.
