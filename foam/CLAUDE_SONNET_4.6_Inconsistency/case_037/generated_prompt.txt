Simulate steady, incompressible, laminar flow of water through a 2D channel containing a rigid, stationary obstacle.

Use a 2D mesh extruded one cell in the spanwise direction.
Set the `frontAndBack` patch type to `empty` to enforce the 2D condition.

Set the kinematic viscosity of water to `nu = 1e-6 m^2/s` in `constant/transportProperties`.

In `system/controlDict`, set `application` to `simpleFoam`.

For `0/U`, set the inlet patch to `fixedValue uniform (0.1 0 0)`.
For `0/U`, set the outlet patch to `zeroGradient`.
For `0/U`, set the walls and obstacle patches to `noSlip`.
For `0/U`, set the frontAndBack patch to `empty`.

For `0/p`, set the inlet patch to `zeroGradient`.
For `0/p`, set the outlet patch to `fixedValue uniform 0`.
For `0/p`, set the walls and obstacle patches to `zeroGradient`.
For `0/p`, set the frontAndBack patch to `empty`.

The obstacle is rigid and stationary, so no mesh motion or fluid-structure interaction is required.
The flow regime is laminar, so no turbulence model is needed; set the `simulationType` to `laminar` in `constant/momentumTransport` (or `constant/turbulenceProperties` depending on OpenFOAM version).
Use `simpleFoam` to run the steady-state simulation to convergence.
