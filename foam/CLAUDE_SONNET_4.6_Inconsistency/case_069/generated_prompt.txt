Simulate steady-state incompressible turbulent flow in a cyclone separator using the simpleFoam solver.
The geometry contains four boundary patches: inlet, outlet, dustOutlet, and walls.
The fluid enters tangentially through the inlet patch.
The primary exit is through the top outlet patch (vortex finder).
The bottom dustOutlet patch is a secondary exit for separated particles/dust-laden flow.
Use the k-epsilon turbulence model for closure.
The flow is treated as incompressible and steady-state.

Define the pressure field (p) boundary conditions as follows.
For the inlet patch, use type zeroGradient.
For the outlet patch, use type fixedValue with value uniform 0 (gauge atmospheric pressure).
For the dustOutlet patch, use type zeroGradient.
For the walls patch, use type zeroGradient.

The p boundary condition block must be written as:

inlet
{
    type            zeroGradient;
}
outlet
{
    type            fixedValue;
    value           uniform 0;
}
dustOutlet
{
    type            zeroGradient;
}
walls
{
    type            zeroGradient;
}
