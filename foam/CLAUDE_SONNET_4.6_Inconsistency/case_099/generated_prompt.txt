Use icoFoam as the solver for 2D laminar transient incompressible flow.

The domain is a rectangular channel 2.2m long, 0.41m high, and 0.01m thick (one cell in the z-direction).

A 0.1m x 0.1m square cylinder obstacle is placed in the flow path, centered at x=0.2m, y=0.2m from the bottom-left corner of the domain (following the DFG benchmark geometry).

The mesh has one cell in the z-direction (thickness 0.01m) to enforce 2D behavior.

Set kinematic viscosity nu to 0.001 m^2/s in constant/transportProperties.

In constant/polyMesh/boundary, define the following patches:
- inlet: type patch
- outlet: type patch
- topAndBottomWalls: type wall
- cylinder: type wall
- frontAndBack: type empty

In 0/U, set the following boundary conditions:
- inlet: type groovyBC or codedFixedValue implementing a parabolic inflow profile with maxValue (1.5 0 0), using the expression 1.5 * 4 * y * (0.41 - y) / (0.41^2) in the x-component, and 0 for y and z components
- outlet: type zeroGradient
- topAndBottomWalls: type noSlip
- cylinder: type noSlip
- frontAndBack: type empty
- Set internalField to uniform (0 0 0)

In 0/p, set the following boundary conditions:
- inlet: type zeroGradient
- outlet: type fixedValue, uniform 0
- topAndBottomWalls: type zeroGradient
- cylinder: type zeroGradient
- frontAndBack: type empty
- Set internalField to uniform 0

In system/controlDict, set the following:
- application: icoFoam
- startFrom: startTime
- startTime: 0
- stopAt: endTime
- endTime: 8
- deltaT: 0.001
- writeControl: timeStep
- writeInterval: 100
- purgeWrite: 0
- writeFormat: ascii
- writePrecision: 6
- runTimeModifiable: true

In system/fvSchemes, use the following:
- ddtSchemes default: Euler
- gradSchemes default: Gauss linear
- divSchemes div(phi,U): Gauss linearUpwind grad(U)
- laplacianSchemes default: Gauss linear corrected
- interpolationSchemes default: linear
- snGradSchemes default: corrected

In system/fvSolution, use the following:
- For p solver: PCG with DIC preconditioner, tolerance 1e-6, relTol 0.01
- For U solver: PBiCG with DILU preconditioner, tolerance 1e-5, relTol 0
- PISO: nCorrectors 2, nNonOrthogonalCorrectors 1

The parabolic inlet profile ensures a maximum velocity of 1.5 m/s at the channel centerline (y=0.205m), giving a mean velocity of approximately 1.0 m/s.

The Reynolds number based on the cylinder diameter (0.1m) and mean velocity (1.0 m/s) is Re=100, which produces a transient von Karman vortex street, justifying the transient solver and an end time of 8s to allow full vortex shedding development.

The time step deltaT of 0.001s gives a maximum Courant number well below 1 for stability with icoFoam.
