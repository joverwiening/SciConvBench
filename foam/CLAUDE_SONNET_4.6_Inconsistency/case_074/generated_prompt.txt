Model a steady-state, buoyancy-driven natural convection flow in a vertical heated pipe using the buoyantSimpleFoam solver.
The pipe is aligned with the Z-axis, has a length of 2 meters, and a diameter of 0.1 meters.
The computational domain is a cylindrical pipe from z=0 (bottom/inlet) to z=2 (top/outlet).
Use a structured or unstructured mesh appropriate for a cylindrical pipe geometry.
In the constant/g dictionary, set gravity to `g (0 0 -9.81);` to enable buoyancy-driven flow along the Z-axis.
Use air as the working fluid with thermophysical properties defined using the perfectGas equation of state.
Set up the thermophysicalProperties dictionary for air using the hePsiThermo or heRhoThermo thermo model compatible with buoyantSimpleFoam.
Use standard air transport properties (dynamic viscosity and thermal conductivity appropriate for air around 300-350K).
Run the simulation in steady-state mode using the SIMPLE algorithm as implemented in buoyantSimpleFoam.
At the inlet boundary (z=0), set the velocity boundary condition to pressureInletOutletVelocity.
At the inlet boundary (z=0), set the temperature boundary condition to fixedValue with a value of 300 K.
At the inlet boundary (z=0), set the pressure boundary condition to a zeroGradient or appropriate inlet pressure condition consistent with buoyantSimpleFoam (using p_rgh).
At the outlet boundary (z=2), set the velocity boundary condition to zeroGradient.
At the outlet boundary (z=2), set the temperature boundary condition to zeroGradient.
At the outlet boundary (z=2), set the pressure (p_rgh) boundary condition to a fixed value (e.g., fixedValue 0 as gauge pressure).
At the pipe wall, set the velocity boundary condition to noSlip.
At the pipe wall, set the temperature boundary condition to fixedValue with a value of 350 K.
At the pipe wall, set the pressure boundary condition to fixedFluxPressure.
Initialize the internal field for temperature to 300 K, velocity to zero, and pressure to zero (gauge).
The goal of the simulation is to observe the natural convection velocity profile and temperature distribution established due to density differences caused by wall heating.
Use relaxation factors appropriate for buoyantSimpleFoam steady-state convergence (e.g., 0.7 for U, 0.3 for p_rgh, 0.5 for h or T).
Run the simulation until residuals converge to at least 1e-5 for all solved quantities.
