Set up a 2D lid-driven cavity flow simulation using OpenFOAM with the icoFoam solver.

Use a square domain of 1 m × 1 m extruded one cell in the z-direction.

Define the patch named `frontAndBack` as type `empty` to enforce the 2D condition.

Generate a uniform structured mesh of 40 × 40 × 1 cells using blockMesh.

Use an incompressible Newtonian fluid with kinematic viscosity `nu = 0.01 m^2/s` defined in `constant/transportProperties`.

In `system/controlDict`, set `application` to `icoFoam`.

Choose `startTime`, `endTime`, and `deltaT` in `system/controlDict` such that the simulation runs transiently until a steady solution is reached (for example, endTime 20 s with deltaT 0.005 s is appropriate for Re=100).

Set `writeInterval` to save results at regular intervals (for example, every 1 s).

In `0/U`, set the `movingLid` patch (top wall) to `fixedValue uniform (1 0 0)`.

In `0/U`, set the `fixedWalls` patch (left, right, and bottom walls) to `noSlip`.

In `0/U`, set the `frontAndBack` patch to `empty`.

In `0/p`, set all wall patches (`movingLid` and `fixedWalls`) to `zeroGradient`.

In `0/p`, set the `frontAndBack` patch to `empty`.

Set the pressure reference in `system/fvSolution` using `pRefCell 0` and `pRefValue 0` inside the PISO or solution block.

In `system/fvSchemes`, use appropriate schemes for a transient incompressible laminar flow (for example, Euler for `ddtSchemes`, Gauss linear for `gradSchemes`, Gauss linear corrected for `laplacianSchemes`, and linear interpolation for `interpolationSchemes`).

In `system/fvSolution`, use the PISO algorithm with at least 2 corrector steps.
