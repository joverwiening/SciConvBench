The simulation is a 3D dam break problem with three phases: water, air, and a light oil.
The domain is a rectangular tank with dimensions 1m (x) x 0.6m (y) x 0.4m (z).
Use the `twoPhaseEulerFoam` solver, which supports multiphase Eulerian frameworks.
Gravity is defined as (0, -9.81, 0) m/s² in the `constant/g` file.
The three phases are named `air`, `water`, and `oil`, defined in `constant/transportProperties`.

Define the following physical properties in `transportProperties`:
Water density is 1000 kg/m³ and dynamic viscosity is 1e-3 Pa·s.
Oil density is 800 kg/m³ and dynamic viscosity is 5e-3 Pa·s.
Air density is 1.225 kg/m³ and dynamic viscosity is 1.8e-5 Pa·s.

The mesh is a structured hexahedral mesh created with `blockMesh`.
Use a resolution of 50 x 30 x 20 cells in x, y, and z respectively.
Define the block in `blockMeshDict` spanning from (0 0 0) to (1 0.6 0.4).

Initial conditions are set using the `setFields` utility via `system/setFieldsDict`.
The default field values set `alpha.air` to 1, `alpha.water` to 0, and `alpha.oil` to 0 everywhere.
A box region from (0 0 0) to (0.2 0.2 0.4) sets `alpha.water` to 1 and `alpha.air` to 0.
A box region from (0 0.2 0) to (0.2 0.25 0.4) sets `alpha.oil` to 1 and `alpha.air` to 0.
All three phase fractions must sum to 1 everywhere in the domain.

Boundary conditions are applied as follows:
All wall patches (left, right, front, back, bottom) use no-slip conditions for velocity (fixedValue uniform (0 0 0)).
All wall patches use `zeroGradient` for pressure.
All wall patches use `zeroGradient` for all phase fraction fields.
The top boundary is named `atmosphere` and uses `pressureInletOutletVelocity` for velocity.
The top boundary uses `totalPressure` with p0 = 0 (gauge) for pressure.
The top boundary uses `inletOutlet` with `inletValue uniform 0` for `alpha.water` and `alpha.oil`.
The top boundary uses `inletOutlet` with `inletValue uniform 1` for `alpha.air`.

Use adaptive time-stepping controlled by a maximum Courant number of 0.5.
Set `adjustTimeStep yes` and `maxCo 0.5` in `controlDict`.
Set the initial time step `deltaT` to 0.001 s.
Set `maxDeltaT` to 0.01 s.
Set the simulation start time to 0 s and end time to 1 s.
Write results every 0.05 s by setting `writeControl timeStep` with `writeInterval` adjusted accordingly, or use `writeControl adjustableRunTime` with `writeInterval 0.05`.

Use the `MULES` scheme for phase fraction transport.
Use `Gauss linearUpwind` or `Gauss vanLeer` for divergence schemes of velocity.
Use `Gauss linear corrected` for Laplacian schemes.
Use `linear` interpolation scheme.
Set `snGradSchemes` to `corrected`.

Use `PIMPLE` algorithm with `nOuterCorrectors 3`, `nCorrectors 2`, and `nNonOrthogonalCorrectors 1` in `fvSolution`.

Create the following directory structure: `constant/`, `system/`, `0/`.
Place `transportProperties` and `g` in `constant/`.
Place `blockMeshDict`, `controlDict`, `fvSchemes`, `fvSolution`, and `setFieldsDict` in `system/`.
Place initial condition files `alpha.air`, `alpha.water`, `alpha.oil`, `U`, and `p_rgh` in `0/`.

Run the case by first executing `blockMesh`, then `setFields`, then `twoPhaseEulerFoam`.
