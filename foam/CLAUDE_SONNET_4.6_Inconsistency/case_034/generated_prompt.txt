Set up a 2D dam break simulation using the interFoam solver for a two-phase water-air system.
The domain is 2 meters long (x-direction) and 1 meter high (y-direction) with a single cell in the z-direction (thickness 0.1 m).
Use blockMeshDict to define the mesh with 200 cells in x, 100 cells in y, and 1 cell in z, giving a uniform cell size of 0.01 m.
Define the front and back patches in blockMeshDict as a single patch named frontAndBack with type empty (standard 2D OpenFOAM practice for the z-normal faces).
Define gravity in constant/g as (0 -9.81 0) m/s².
The fluid system is water and air; define their properties in constant/transportProperties using standard interFoam two-phase format.
Set water kinematic viscosity to 1e-6 m²/s and density to 1000 kg/m³.
Set air kinematic viscosity to 1.48e-5 m²/s and density to 1 kg/m³.
Set surface tension sigma to 0.07 N/m.
In the 0 directory, create the fields U, p_rgh, and alpha.water.
For U, set the internalField to uniform (0 0 0).
For U, assign type noSlip to the bottom, left, and right wall patches.
For U, assign type slip to the top patch to allow free surface venting.
For U, assign type empty to the frontAndBack patch.
For p_rgh, set the internalField to uniform 0.
For p_rgh, assign type fixedFluxPressure with value uniform 0 to all wall patches (bottom, left, right).
For p_rgh, assign type totalPressure with p0 uniform 0 to the top patch.
For p_rgh, assign type empty to the frontAndBack patch.
For alpha.water, set the internalField to uniform 0 (air everywhere initially).
For alpha.water, assign type zeroGradient to all wall patches and the top patch.
For alpha.water, assign type empty to the frontAndBack patch.
Use setFieldsDict to define the initial water column as a box region from (0 0 0) to (0.4 1 0.1), setting alpha.water to 1 inside this region.
This places a water column 0.4 m wide and 1 m tall (full height) on the left side of the domain, representing a classic dam break configuration.
Run setFields before starting the solver to initialize alpha.water.
Use the interFoam solver for the transient simulation.
In system/controlDict, set the application to interFoam, startTime to 0, endTime to 1, deltaT to 0.001, and writeInterval to 0.05.
In system/fvSolution, use PIMPLE with nOuterCorrectors 1, nCorrectors 3, and nNonOrthogonalCorrectors 0.
In system/fvSchemes, use Euler for time discretization and Gauss linear for gradient and divergence schemes, with interfaceCompression for the alpha.water convection scheme.
