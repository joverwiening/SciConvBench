Use the `interFoam` solver for a 2D tank simulation involving two fluid phases: water and sludge.
Name the two phases `water` and `sludge` in the `phases` entry of the `transportProperties` file.
Define the `water` phase with `transportModel Newtonian`, kinematic viscosity `nu = 1e-6`, and density `rho = 1000`.
Define the `sludge` phase with `transportModel BinghamPlastic`.
Set the sludge Bingham plastic parameter `tau0` (yield stress) to 15.
Set the sludge Bingham plastic parameter `mu0` (plastic viscosity) to 0.1.
Set the sludge Bingham plastic parameter `muInf` to 0.01.
Do not include a regularization parameter (such as `BinghamCoeff`) in the sludge sub-dictionary.
Set the sludge density `rho` to 1500.
Set the surface tension coefficient `sigma` to 0.07.
The simulation is 2D; configure the mesh and boundary conditions accordingly for a tank geometry.
Do not change any other solver settings beyond what is specified above.
