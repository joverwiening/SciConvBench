Set up a 2D laminar incompressible flow simulation past a cylinder to observe the von Kármán vortex street using OpenFOAM.

Use the `pimpleFoam` transient incompressible solver.

The domain is a rectangular channel 2.2 m long and 0.41 m high.

Place a cylinder of diameter 0.1 m centered at (0.2, 0.2) in the channel.

The mesh is one cell thick in the z-direction to enforce a 2D simulation.

Use a kinematic viscosity of 1e-3 m²/s.

The Reynolds number for this configuration is 100.

In `system/controlDict`, set the solver to `pimpleFoam`.

In `system/controlDict`, set `startTime` to 0.

In `system/controlDict`, set `endTime` to 200.

In `system/controlDict`, set `deltaT` to 1.

In `system/controlDict`, set `writeInterval` to 10.

In `0/U`, set the `inlet` boundary condition to `fixedValue uniform (1 0 0)`.

In `0/U`, set the `outlet` boundary condition to `zeroGradient`.

In `0/U`, set the `cylinderWall` boundary condition to `noSlip`.

In `0/U`, set the `topAndBottom` boundary condition to `noSlip`.

In `0/U`, set the `frontAndBack` boundary condition to `empty`.

In `0/p`, set the `inlet` boundary condition to `zeroGradient`.

In `0/p`, set the `outlet` boundary condition to `fixedValue uniform 0`.

In `0/p`, set the `cylinderWall` boundary condition to `zeroGradient`.

In `0/p`, set the `topAndBottom` boundary condition to `zeroGradient`.

In `0/p`, set the `frontAndBack` boundary condition to `empty`.

Run the simulation from time 0 to time 200 to capture the development of the transient periodic vortex shedding in the wake of the cylinder.

Write flow field results every 10 time steps for post-processing and analysis of the von Kármán vortex street.
