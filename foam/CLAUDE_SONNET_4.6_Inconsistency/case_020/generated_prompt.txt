Use the reactingFoam solver in OpenFOAM for a laminar counter-flow diffusion flame simulation.

Domain and Mesh
The domain spans x = 0 to 0.02 m, y = -0.01 to 0.01 m, z = -0.01 to 0.01 m.
Use 100 uniformly spaced cells in the x-direction, 40 in the y-direction, and 1 cell in the z-direction.
The mesh is generated using blockMesh.

Boundaries
Name the patch at x = 0 "fuel" with type patch.
Name the patch at x = 0.02 m "air" with type patch.
Name the patches at y = -0.01 and y = 0.01 "outlet" with type patch.
Name the patches at z = -0.01 and z = 0.01 "frontAndBack" with type empty.

Chemical Mechanism
Use the 2-step Westbrook-Dryer reduced mechanism for methane combustion as a best-practice compromise between accuracy and computational cost.
Include the following species: CH4, O2, N2, CO2, H2O, CO.
Define the two reactions as: CH4 + 1.5 O2 -> CO + 2 H2O, and CO + 0.5 O2 -> CO2.
Place the mechanism files (reactions and thermo data) in the constant/chemkin or constant directory as required by OpenFOAM's JANAF/chemkin format.

Thermophysical Model
Use hePsiThermo for the thermodynamic model.
Use coefficientWilkeMultiComponentMixture for species mixing.
Use Sutherland transport model for viscosity and thermal conductivity.
Use JANAF thermodynamic data for all species.
Set the combustion model to laminar (finite-rate chemistry, no turbulence-chemistry interaction).

Chemistry Solver
Set chemistryType to EulerImplicit.
Use the Rosenbrock43 ODE solver for stiff chemistry integration.
Place chemistry solver settings in constant/chemistryProperties.

Initial Conditions (t = 0)
Initialize temperature T = 2000 K throughout the entire domain.
Initialize pressure p = 101325 Pa throughout the domain.
Initialize velocity U = (0 0 0) m/s throughout the domain.
Initialize species mass fractions: set Y_CH4 = 1.0 at the fuel side and Y_O2 = 0.23, Y_N2 = 0.77 at the air side; initialize the interior domain with Y_N2 = 1.0 and all other species at 0 as a cold-start approximation.

Boundary Conditions — Fuel Inlet (x = 0, patch "fuel")
Set U = (0.1 0 0) m/s (fixedValue, flow in +x direction).
Set T = 293 K (fixedValue).
Set p to zeroGradient.
Set Y_CH4 = 1.0 (fixedValue).
Set Y_O2 = 0, Y_N2 = 0, Y_CO2 = 0, Y_H2O = 0, Y_CO = 0 (fixedValue).

Boundary Conditions — Air Inlet (x = 0.02 m, patch "air")
Set U = (-0.1 0 0) m/s (fixedValue, flow in -x direction).
Set T = 293 K (fixedValue).
Set p to zeroGradient.
Set Y_O2 = 0.23 (fixedValue).
Set Y_N2 = 0.77 (fixedValue).
Set Y_CH4 = 0, Y_CO2 = 0, Y_H2O = 0, Y_CO = 0 (fixedValue).

Boundary Conditions — Outlet (top and bottom, patch "outlet")
Set U to inletOutlet with inletValue (0 0 0).
Set T to inletOutlet with inletValue 293 K.
Set p to totalPressure or fixedValue at 101325 Pa.
Set all species mass fractions to inletOutlet with inletValue 0.

Boundary Conditions — FrontAndBack
Set all fields to empty type.

Viscosity
Set the dynamic viscosity to 0 everywhere to represent an inviscid flame configuration.
Override the Sutherland transport result by setting nu or mu to fixedValue 0 in the relevant transport dictionary entry, or set the Sutherland coefficients to produce zero viscosity.

Momentum Transport
Set the simulationType to laminar in constant/momentumTransport (or constant/turbulenceProperties depending on OpenFOAM version).

Time Control (system/controlDict)
Set application to reactingFoam.
Set startTime to 0.
Set endTime to 0.5 s.
Set deltaT to 1e-4 s.
Set writeInterval to 0.05 s.
Set writeControl to runTime.

Numerical Schemes (system/fvSchemes)
Use Euler implicit time integration for ddtSchemes.
Use Gauss linear for gradient and divergence schemes appropriate for laminar low-speed reacting flow.
Use linear interpolation for laplacian schemes.

Solvers (system/fvSolution)
Use PIMPLE or PISO loop appropriate for reactingFoam.
Use PCG or GAMG for pressure solve.
Use PBiCGStab for velocity and species solves.
