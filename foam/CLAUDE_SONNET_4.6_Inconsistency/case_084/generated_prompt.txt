Set up a transient two-phase Euler–Euler gas–solid riser simulation using twoPhaseEulerFoam.
Define two phases: air (gas) and catalyst (solid).
In 0/alpha.catalyst, set the inlet boundary condition to type fixedValue with value uniform 0.01.
In 0/alpha.air, set the inlet boundary condition to type fixedValue with value uniform 0.99.
Ensure the phase volume fractions at the inlet sum to 1 (0.01 + 0.99 = 1.0), satisfying the phase fraction constraint.
Apply a dilute solids loading at the inlet with alpha.catalyst = 0.01 representing the solid catalyst phase.
Apply the complementary gas volume fraction at the inlet with alpha.air = 0.99 representing the air phase.
Use transient (time-dependent) solver settings appropriate for twoPhaseEulerFoam.
Configure the simulation as a riser geometry with the inlet at the bottom and outlet at the top.
