Set up a steady-state 2D natural convection simulation in a square cavity using OpenFOAM.

Use the buoyantBoussinesqSimpleFoam solver.

The cavity has a side length of 1.0 m (a standard benchmark configuration).

Use a uniform structured mesh of 40 x 40 cells in the x and y directions respectively, which is a well-established resolution for this benchmark problem.

The domain is 2D; set the mesh to one cell thick in the z-direction with empty boundary conditions on the front and back faces.

Gravity is defined as g = (0 -9.81 0) m/s^2 in the constant/g file.

The fluid is air modeled using the Boussinesq approximation.

In constant/thermophysicalProperties, set thermoType to heRhoThermo.

Set mixture to pureMixture.

Set transport to const.

Set thermo to hConst.

Set equationOfState to perfectGas.

Set specie to specie (the keyword for the specie sub-dictionary).

Set energy to sensibleEnthalpy.

In the specie sub-dictionary, set molWeight to 28.9 g/mol.

In the thermodynamics sub-dictionary, set Cp to 1005 J/(kg·K) and Hf to 0.

In the transport sub-dictionary, set mu to 1.8e-5 kg/(m·s) and Pr to 0.7.

In constant/transportProperties, set nu to 1.5e-5 m^2/s (consistent with mu/rho at reference conditions) and Pr to 0.7.

Set the reference temperature Tref to 300 K (the mean of 310 K and 290 K) for the Boussinesq approximation.

Set the thermal expansion coefficient beta to 1/Tref = 3.33e-3 1/K in constant/transportProperties.

In 0/T, set the internal field to uniform 300 K.

In 0/T, set the left wall (named leftWall) boundary condition to fixedValue uniform 310.

In 0/T, set the right wall (named rightWall) boundary condition to fixedValue uniform 290.

In 0/T, set the top wall (named topWall) and bottom wall (named bottomWall) boundary conditions to zeroGradient.

In 0/U, set the internal field to uniform (0 0 0).

In 0/U, set all walls (leftWall, rightWall, topWall, bottomWall) to noSlip.

In 0/p_rgh, set the internal field to uniform 0.

In 0/p_rgh, set all walls to fixedFluxPressure with value uniform 0.

In system/fvSchemes, use steadyState for ddtSchemes.

Use Gauss linear for gradSchemes.

Use Gauss linearUpwind grad(U) for the divergence of U, and Gauss linear for divergence of other fields including temperature.

Use Gauss linear corrected for laplacianSchemes.

In system/fvSolution, use SIMPLE as the solution algorithm.

Set nNonOrthogonalCorrectors to 0 in the SIMPLE sub-dictionary.

Set residual convergence tolerance to 1e-6 for all fields (U, p_rgh, T).

Use PBiCGStab with DILU preconditioner for U and T solvers.

Use GAMG with GaussSeidel smoother for the p_rgh solver.

Set relaxation factors to 0.7 for U, 0.3 for p_rgh, and 0.7 for T in fvSolution relaxationFactors.

Run the simulation for a maximum of 2000 iterations or until all residuals drop below 1e-6.
