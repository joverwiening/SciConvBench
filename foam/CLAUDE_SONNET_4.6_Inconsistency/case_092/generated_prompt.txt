Simulate compressible supersonic flow of air over a 10-degree wedge using OpenFOAM with rhoPimpleFoam.

The domain is 2D, extruded one cell in the z-direction with a depth of 0.01 m.

The domain length in x is 1.0 m and the height in y is 0.5 m.

The wedge starts at x = 0.2 m from the inlet and runs to the outlet along the bottom boundary, rising at 10 degrees.

The mesh is generated using blockMesh with approximately 200 cells in x and 100 cells in y, graded toward the wedge surface.

Use rhoPimpleFoam as the solver in system/controlDict.

Set application to rhoPimpleFoam in system/controlDict.

Set deltaT to 1e-7 s and endTime to 5e-3 s in system/controlDict.

Set writeInterval to 5e-4 s so that 10 solution snapshots are saved.

Set adjustTimeStep to no and maxCo to 0.5 as a reference.

Treat air as a perfect gas using hePsiThermo with pureMixture, equationOfState perfectGas, thermo janaf (or hConst with Cp = 1005 J/kg/K), and transport sutherland in constant/thermophysicalProperties.

Set molecular weight to 28.96 g/mol, mu0 (Sutherland reference viscosity) to 1.716e-5 Pa·s, T0 to 273.11 K, and Ts (Sutherland constant) to 110.4 K.

Set the freestream inlet velocity U to (686 0 0) m/s.

Set the freestream static temperature T to 293 K at the inlet.

Set the freestream static pressure p to 101325 Pa at the inlet.

The inlet boundary (x = 0 face) uses fixedValue for U, p, and T with the freestream values above.

The outlet boundary (x = 1.0 m face) uses waveTransmissive for p and T, and zeroGradient for U.

The wedge surface (bottom boundary from x = 0.2 m onward) uses slip boundary condition for U and zeroGradient for p and T.

The top boundary uses slip for U and zeroGradient for p and T.

The bottom boundary upstream of the wedge (x = 0 to 0.2 m) uses slip for U and zeroGradient for p and T.

The frontAndBack boundaries are set to empty for all fields.

In system/fvSchemes, set ddtSchemes default to Euler.

Set gradSchemes default to Gauss linear.

Set divSchemes for div(phi,U) to Gauss linearUpwind grad(U), for div(phi,e) and div(phi,h) to Gauss linearUpwind default, and for div(phi,K) to Gauss linear.

Set laplacianSchemes default to Gauss linear corrected.

Set interpolationSchemes default to linear.

Set snGradSchemes default to corrected.

In system/fvSolution, use PBiCGStab with DILU preconditioner for U and e, and GAMG with GaussSeidel smoother for p.

Set nOuterCorrectors to 2, nCorrectors to 1, and nNonOrthogonalCorrectors to 0 in the PIMPLE dictionary.

Set residualControl for p and U to 1e-5.

Initialize all internal fields with the freestream values: U = (686 0 0), p = 101325, T = 293.

Compute initial density as rho = p / (R_specific * T) = 101325 / (287 * 293) ≈ 1.205 kg/m³ and set it as the initial condition for rho if required.

The expected result is an attached oblique shock emanating from the wedge leading edge at approximately 30.2 degrees from the freestream direction, consistent with the analytical solution for M=2.0 and a 10-degree wedge half-angle.
