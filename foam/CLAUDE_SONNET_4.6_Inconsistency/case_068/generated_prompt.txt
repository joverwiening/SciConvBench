Perform a conjugate heat transfer (CHT) simulation of an electronics component cooled by forced air convection.
Use the chtMultiRegionSimpleFoam solver.
The setup consists of two regions: a solid region named "solid" (silicon chip) and a fluid region named "air".
The silicon chip generates heat, specified via fvOptions in the solid region.
The entire assembly is enclosed in a housing.
The fluid air region has an inlet and an outlet.
In the file 0/air/T, set the inlet boundary condition to fixedValue with a uniform temperature of 293 K.
In the file 0/air/T, set the outlet boundary condition to zeroGradient.
In the file 0/solid/T, set the outerCasing boundary condition to zeroGradient to represent a perfectly insulated (zero heat flux) wall, as shown below:

outerCasing
{
    type            zeroGradient;
}

Do not use fixedValue for the outerCasing boundary in 0/solid/T.
The interface between the solid and fluid regions uses a coupled boundary condition to allow heat transfer between the chip and the air.
Air enters the fluid region at 293 K.
The simulation is steady-state, consistent with the SimpleFoam-based solver.
