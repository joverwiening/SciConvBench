Simulate incompressible water flow in a 2D channel with a prescribed moving wall to model simplified peristaltic pumping using a dynamic mesh in OpenFOAM with pimpleFoam.

Geometry and Mesh:
Use a 2D rectangular channel mesh extruded exactly one cell in the spanwise (z) direction.
Set the front and back boundary patches to type empty to enforce 2D behavior.
Define at least four boundary patches: inlet, outlet, stationaryWall (or walls), and movingWall.

Fluid Properties (constant/transportProperties):
Set the kinematic viscosity nu to 1e-6 m^2/s.
Use the Newtonian transport model.

Dynamic Mesh (constant/dynamicMeshDict):
Set dynamicFvMesh to dynamicMotionSolverFvMesh.
Set the motionSolver to displacementLaplacian.
Set diffusivity to uniform 1 (or a suitable uniform value) for the Laplacian smoother.

Point Displacement (0/pointDisplacement):
Set the field dimensions to [0 1 0 0 0 0 0] (meters).
Set the internal field to uniform (0 0 0).
On the movingWall patch, prescribe an oscillatingDisplacement boundary condition with a sinusoidal amplitude in the wall-normal direction (e.g., amplitude (0 0.05 0) and omega 6.2832 rad/s as representative values, adjustable by the user).
On all other patches (inlet, outlet, stationaryWall, frontAndBack), set fixedValue uniform (0 0 0).

Velocity Field (0/U):
Set dimensions to [0 1 -1 0 0 0 0].
Set internal field to uniform (0 0 0).
On the inlet patch, set type fixedValue with a uniform inlet velocity, e.g., uniform (0.01 0 0).
On the outlet patch, set type zeroGradient.
On the stationaryWall patch, set type noSlip.
On the movingWall patch, set type movingWallVelocity with value uniform (0 0 0).
On frontAndBack patches, set type empty.

Pressure Field (0/p):
Set dimensions to [0 2 -2 0 0 0 0].
Set internal field to uniform 0.
On the outlet patch, set type fixedValue uniform 0.
On the inlet patch, set type zeroGradient.
On all wall patches (stationaryWall, movingWall), set type zeroGradient.
On frontAndBack patches, set type empty.

System/controlDict:
Set application to pimpleFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 1.0 (adjustable).
Set deltaT to 0.001.
Set writeControl to timeStep and writeInterval to 50.
Enable adjustTimeStep no (or yes with maxCo 0.5 if desired).

System/fvSchemes:
Use Euler for ddtSchemes default.
Use Gauss linear for gradSchemes default.
Use Gauss linearUpwind grad(U) for divSchemes div(phi,U).
Use Gauss linear corrected for laplacianSchemes default.
Use linear for interpolationSchemes default.
Use corrected for snGradSchemes default.

System/fvSolution:
Use GAMG solver for p with tolerance 1e-6 and relTol 0.01.
Use smoothSolver with symGaussSeidel for U with tolerance 1e-8 and relTol 0.1.
Configure the PIMPLE block with nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1.
