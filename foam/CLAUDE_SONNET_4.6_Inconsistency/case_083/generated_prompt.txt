Set up initial condition files for a three-phase settling tank using the multiphaseEulerFoam solver.

Create three files in the 0/ directory: alpha.sediment, alpha.water, and alpha.oil.

Each file follows the standard OpenFOAM field file format with a FoamFile header block.

In the FoamFile header of alpha.sediment, set version to 2.0, format to ascii, class to volScalarField, location to "0", and object to alpha.sediment.

In the FoamFile header of alpha.water, set version to 2.0, format to ascii, class to volScalarField, location to "0", and object to alpha.water.

In the FoamFile header of alpha.oil, set version to 2.0, format to ascii, class to volScalarField, location to "0", and object to alpha.oil.

Set the dimensions field to [ 0 0 0 0 0 0 0 ] in all three files, indicating a dimensionless scalar quantity.

Set internalField to uniform 0.5 in all three files.

Define a boundaryField block in each file to handle all boundary patches.

For all boundary patches in all three files, set the boundary condition type to zeroGradient, as no flux of volume fraction is expected through the walls, inlet, or outlet at this initial stage.

Include a comment in each file or in a README noting that the internalField value of 0.5 is a placeholder and will be overwritten by setFields using the configuration in system/setFieldsDict to produce physically stratified layers with sediment at the bottom, water in the middle, and oil at the top.

Do not set the sum of the three internalField values to 1 at this stage, since setFields will enforce the correct phase distribution after initialization.
