Set up a 2D steady-state Rayleigh-Bénard convection simulation in OpenFOAM using the buoyantBoussinesqSimpleFoam solver.

The domain is a square cavity of 1 m x 1 m in the x-y plane.

Use a structured mesh of 50 x 50 cells (2500 cells total) with uniform spacing in both x and y directions, generated via blockMesh. This resolution is standard for laminar Rayleigh-Bénard convection at moderate Rayleigh numbers.

Use laminar flow modeling, as Rayleigh-Bénard convection in air with a 20 K temperature difference across 1 m is well within the laminar regime (Ra ~ 10^7, below the turbulent transition threshold of ~10^8 for this geometry).

Gravity is defined in constant/g as (0 -9.81 0) m/s^2.

In constant/thermophysicalProperties, use the thermoType and mixture blocks exactly as specified by the user, with hePsiThermo, perfectGas equation of state, const transport, hConst thermodynamics, molWeight 28.9, Cp 1005, Hf 0, mu 1.8e-05, and Pr 0.7.

In constant/transportProperties, set the reference temperature T0 to 300 K (mean of 310 K and 290 K) and beta (thermal expansion coefficient) to 1/T0 = 3.33e-03 1/K, consistent with the Boussinesq approximation.

Set the initial internal field for T to 300 K (uniform), for U to (0 0 0), and for p_rgh to 0 Pa uniform.

Apply the following boundary conditions for T: bottom wall fixedValue 310 K, top wall fixedValue 290 K, left and right side walls zeroGradient.

Apply noSlip boundary condition for U on all four walls.

Apply fixedFluxPressure boundary condition for p_rgh on all four walls.

In system/fvSolution, use the SIMPLE algorithm. Set the number of non-orthogonal correctors to 0 (mesh is orthogonal). Use GAMG solver for p_rgh with tolerance 1e-06 and relTol 0.01. Use smoothSolver with symGaussSeidel for U and T with tolerance 1e-06 and relTol 0.1.

In system/fvSchemes, use Gauss linear for gradient schemes, Gauss linear corrected for Laplacian schemes, and Gauss linearUpwind grad(U) for divergence of U and Gauss linear for divergence of other fields.

Set relaxation factors in fvSolution to 0.7 for U, 0.3 for p_rgh, and 0.5 for T and h.

Run the simulation for 2000 steady-state iterations or until all residuals drop below 1e-05, whichever comes first.

The simulation is 2D, so the mesh has one cell in the z-direction with empty boundary conditions on the front and back faces.
