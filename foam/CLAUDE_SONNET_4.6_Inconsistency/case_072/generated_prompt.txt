Set up a Rayleigh-Bénard convection simulation using the buoyantBoussinesqPimpleFoam solver in OpenFOAM.

The domain is a 3D rectangular box with dimensions 1m (x) x 1m (y) x 0.1m (z), where the Z-axis is the wall-normal (height) direction.

Create the blockMeshDict to generate a structured mesh for this box domain.
Use a mesh resolution of 40 x 40 x 20 cells in the x, y, and z directions respectively as a starting point suitable for capturing convection cells.

Define the bottom boundary at z=0 as a wall named "bottomWall".
Define the top boundary at z=0.1 as a wall named "topWall".
Define the four side boundaries (x=0, x=1, y=0, y=1) as periodic patch pairs: one pair in the x-direction and one pair in the y-direction.

In constant/g, set the gravity vector as: g (0 0 -9.81);

In constant/transportProperties, use the Boussinesq approximation with the following values:
nu = 1.5e-5;
Pr = 0.71;
beta = 0.00341;
TRef = 300;

In constant/turbulenceProperties, set the simulation as laminar (simulationType laminar).

In the 0/T file, set the bottom wall (z=0) to a fixedValue of 310K.
Set the top wall (z=0.1) to a fixedValue of 300K.
Set the side patches to cyclic boundary conditions.
Set the internal field to a linear profile varying from 310K at z=0 to 300K at z=0.1, superimposed with a small random perturbation of amplitude 0.1K to trigger convection cell formation.

In the 0/U file, set the bottom wall and top wall to noSlip boundary conditions.
Set the side patches to cyclic boundary conditions.
Set the internal field to uniform (0 0 0).

In the 0/p_rgh file, set the top and bottom walls to fixedFluxPressure boundary conditions.
Set the side patches to cyclic boundary conditions.
Set the internal field to uniform 0.

In system/fvSchemes, use Euler for the time derivative (ddtSchemes), Gauss linear for gradient schemes, Gauss linearUpwind for divergence of U, and Gauss linear corrected for Laplacian schemes.

In system/fvSolution, use GAMG solver for p_rgh and smoothSolver for U and T.
Use the PIMPLE algorithm with nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1.

In system/controlDict, set the application to buoyantBoussinesqPimpleFoam.
Set startTime to 0, endTime to 200 seconds, deltaT to 0.05 seconds, and writeInterval to 10 seconds.
Enable adjustTimeStep as no and set maxCo to 0.5 as a reference.

The simulation is transient and aims to capture the formation and evolution of Rayleigh-Bénard convection cells driven by the temperature difference of 10K between the bottom and top walls.
