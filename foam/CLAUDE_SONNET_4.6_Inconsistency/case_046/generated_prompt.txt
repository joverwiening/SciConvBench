Set up a transient pimpleFoam simulation of turbulent flow over a 2D cylinder in a rectangular channel.
Use a cylinder diameter D = 0.1 m, which gives a Reynolds number of approximately 68,000 based on inlet velocity 10 m/s and standard air properties, consistent with turbulent flow benchmarks.
The domain is 2D, meaning one cell thick in the spanwise (z) direction with empty boundary conditions on the front and back patches.
The channel length is 20D (2.0 m) in the streamwise direction and 8D (0.8 m) in the cross-stream direction.
Place the cylinder center at 4D (0.4 m) downstream from the inlet and centered vertically in the channel.
Use standard incompressible air properties: kinematic viscosity nu = 1.5e-5 m^2/s, density rho = 1.225 kg/m^3 (density is not needed directly in incompressible solvers but noted for reference).
Set the inlet velocity to 10 m/s in the x-direction (U = (10 0 0)).
Apply a zeroGradient boundary condition for pressure at the inlet.
Apply a fixedValue boundary condition for pressure at the outlet set to 0 Pa (gauge).
Apply a zeroGradient boundary condition for velocity at the outlet.
Apply noSlip boundary conditions on the cylinder surface and all channel walls.
In constant/turbulenceProperties, set simulationType to LES.
Include an LES sub-dictionary specifying LESModel as Smagorinsky and delta as cubeRootVol.
Include a RAS sub-dictionary specifying RASModel as kOmegaSST, turbulence as on, and printCoeffs as on.
The active turbulence model used by pimpleFoam will be LES as specified by simulationType; the RAS sub-dictionary is present in the file as required but will not be active simultaneously.
Use a structured mesh generated with blockMesh with refinement around the cylinder using snappyHexMesh to resolve the boundary layer.
Target a maximum Courant number of 0.5 in the pimpleFoam settings.
Set the time step deltaT to 1e-4 s as an initial value, with adjustable time stepping enabled to maintain the target Courant number.
Set the simulation end time to 5.0 s to allow flow to develop and statistics to be gathered.
Write results every 0.1 s.
Use the PIMPLE algorithm with nOuterCorrectors = 2, nCorrectors = 2, and nNonOrthogonalCorrectors = 1.
Use linear interpolation schemes and Gauss linear divergence schemes appropriate for LES.
Set initial conditions for U to (10 0 0) throughout the domain and p to 0 throughout the domain.
Set initial k and omega fields consistent with low turbulence intensity of 5 percent at the inlet for the kOmegaSST model boundary conditions, even though LES is the active model.
