Simulate heat transfer in a 2D channel with a heated block. The fluid is air, and the flow is laminar. Use the `buoyantPimpleFoam` solver. The channel walls are specified as being perfectly insulated (adiabatic). The inlet has a fixed velocity and a temperature of 300 K. The block is maintained at a constant temperature of 400 K. In the `0/T` file, set the boundary conditions as follows: `inlet { type fixedValue; value uniform 300; }`, `outlet { type zeroGradient; }`, `block { type fixedValue; value uniform 400; }`, and for the adiabatic channel walls, `walls { type zeroGradient; }`.
