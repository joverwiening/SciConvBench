Simulate heat transfer in a 2D channel with a heated block using OpenFOAM.
The fluid is air and the flow is laminar.
Use the `buoyantPimpleFoam` solver.
The geometry is a 2D channel with a solid block inside it.
The inlet boundary condition for velocity is a fixed velocity value.
The inlet boundary condition for temperature is a fixed value of 300 K.
The outlet boundary condition for temperature uses `zeroGradient`.
The block is maintained at a constant temperature of 400 K using a `fixedValue` boundary condition.
The channel walls are perfectly insulated (adiabatic) and use a `zeroGradient` boundary condition for temperature.
In the `0/T` file, set the boundary conditions as follows:
`inlet { type fixedValue; value uniform 300; }`
`outlet { type zeroGradient; }`
`block { type fixedValue; value uniform 400; }`
`walls { type zeroGradient; }`
