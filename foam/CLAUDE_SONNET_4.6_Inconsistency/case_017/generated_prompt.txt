Run a 2D inviscid laminar oblique-shock simulation using OpenFOAM with the rhoCentralFoam solver.

The domain is a rectangular box from (0, 0, 0) to (4.1, 1, 0.1).

The mesh has 60 cells in x, 30 cells in y, and 1 cell in z.

Set the frontAndBack patches to the empty type to enforce 2D behavior.

Define the following boundary patches: inlet on the left face (x=0), outlet on the right face (x=4.1), top on the upper face (y=1), bottom on the lower face (y=0).

Set the bottom patch type to symmetryPlane.

Set the top patch type to wall.

Use the rhoCentralFoam compressible flow solver.

Set momentum transport model to laminar.

Use an ideal gas thermodynamic model.

Set Cp to 2.5 J/(kg·K).

Set Prandtl number Pr to 1.

Set dynamic viscosity mu to 0 (inviscid).

Set molecular weight to 11640.3 g/mol.

Set heat of formation Hf to 0.

Initialize the internal field for velocity U to (2.9 0 0) m/s.

Initialize the internal field for pressure p to 1 Pa.

Initialize the internal field for temperature T to 1 K.

Set the inlet boundary condition for U to fixedValue (2.9 0 0).

Set the inlet boundary condition for p to fixedValue 1.

Set the inlet boundary condition for T to fixedValue 1.

Set the outlet boundary condition for U to zeroGradient.

Set the outlet boundary condition for p to zeroGradient.

Set the outlet boundary condition for T to zeroGradient.

Set the top wall boundary condition for U to noSlip.

Set the top wall boundary condition for p to zeroGradient.

Set the top wall boundary condition for T to zeroGradient.

Set deltaT to 0.0025.

Set endTime to 10.

Set writeInterval to 1.
