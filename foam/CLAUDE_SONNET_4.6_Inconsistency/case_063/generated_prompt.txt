Simulate a transient von Kármán vortex street behind a cylinder in a 2D channel using OpenFOAM.

Use a 2D mesh extruded one cell in the z-direction.
Assign the front and back patches the type `empty` to enforce 2D behavior.

Set the kinematic viscosity to `nu = 1e-3 m^2/s` in `constant/transportProperties`.

In `0/U`, apply the following boundary conditions:
- inlet: `fixedValue uniform (0.1 0 0)`
- outlet: `zeroGradient`
- cylinder: `noSlip`
- top and bottom walls: `slip`
- frontAndBack: `empty`

In `0/p`, apply the following boundary conditions:
- inlet: `zeroGradient`
- outlet: `fixedValue uniform 0`
- cylinder: `zeroGradient`
- top and bottom walls: `zeroGradient`
- frontAndBack: `empty`

In `system/controlDict`, set `application` to `pimpleFoam`.
Set `startFrom` to `startTime` with `startTime 0`.
Set `stopAt` to `endTime` and choose an `endTime` long enough to develop vortex shedding (e.g., `10` seconds).
Set `deltaT` to a small enough value to resolve the flow (e.g., `0.005` seconds).
Set `writeControl` to `timeStep` or `runTime` and write results at regular intervals.

Use `pimpleFoam` as the solver, which handles transient incompressible flow with the PIMPLE algorithm.
Configure `system/fvSchemes` with a `ddtSchemes` entry using `Euler` for time discretization and standard `Gauss linear` schemes for gradient, divergence, and Laplacian terms.
Configure `system/fvSolution` with a `PIMPLE` sub-dictionary specifying the number of outer correctors (`nOuterCorrectors`), pressure correctors (`nCorrectors`), and non-orthogonal correctors (`nNonOrthogonalCorrectors`) appropriate for the mesh quality.
