Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity with OpenFOAM.

The beam geometry is 1 m long, 0.1 m high, and 0.1 m wide.

One end is named `fixed` and is fully clamped; the other end is named `loaded` and has a downward traction applied.

In `constant/mechanicalProperties`, set Young's modulus `E = 200e9` Pa and Poisson's ratio `nu = 0.3` using steel properties.

In `0/D`, set the `fixed` patch to `fixedValue uniform (0 0 0)`.

In `0/D`, set the `loaded` patch to `tractionDisplacement` with `traction uniform (0 -1000 0)` and `pressure uniform 0`.

In `0/D`, set all remaining faces (e.g., top, bottom, front, back) to `zeroGradient`.

In `system/controlDict`, set `application` to `solidDisplacementFoam`.

In `system/controlDict`, set `endTime` to `1`.

In `system/controlDict`, set `deltaT` to `1` to perform a single quasi-static load step.

In `system/controlDict`, set `startTime` to `0` and `startFrom` to `startTime`.

In `system/controlDict`, set `stopAt` to `endTime`.

In `system/controlDict`, set `writeControl` to `timeStep` and `writeInterval` to `1` so results are written at the end of the step.

Use a structured hexahedral mesh generated via `blockMesh` that discretizes the beam domain into a suitable number of cells along each axis (e.g., 10 cells along the length, 1 cell along height, 1 cell along width as a minimum, or finer as needed).

Define the `blockMeshDict` in `system/` with vertices corresponding to the eight corners of the rectangular beam, one block spanning the full geometry, and patch names `fixed`, `loaded`, and appropriate names for the four side faces.

Run the simulation using `solidDisplacementFoam` and post-process displacement field `D` to inspect the deflection at the loaded end.
