Run a two-dimensional Rayleigh-Benard convection simulation using OpenFOAM with the buoyantFoam solver.

The domain is a rectangular cavity 9 units wide and 1 unit tall, extruded 1 cell in the spanwise (z) direction with a small thickness.

Use 90 cells in x, 10 cells in y, and 1 cell in z.

Gravity acts in the negative y direction with magnitude 9.81 m/s².

Set the front and back patches as empty to enforce 2D behavior.

Use a fixed timestep of 1 s. Do not enable adjustTimeStep, do not set maxCo, and do not set maxDeltaT.

Simulate up to 1000 s of physical time.

Write results every 50 time steps.

Use RAS k-epsilon turbulence. In constant/momentumTransport set simulationType to RAS, model to kEpsilon, turbulence on, and printCoeffs on. Do not use laminar anywhere.

In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq. Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.

In 0/T set internalField uniform 300. Set the bottom wall to fixedValue 305. Set the top wall to fixedValue 295. Set the left and right vertical side walls to zeroGradient. Set front and back to empty.

In 0/U set internalField uniform (0 0 0). Apply noSlip on all solid walls (top, bottom, left, right). Set front and back to empty.

In 0/p set internalField uniform 0. Set all solid walls to calculated. Set front and back to empty.

In 0/p_rgh set internalField uniform 0. Set all solid walls to fixedFluxPressure. Set front and back to empty.

In 0/k set internalField uniform 1e-5. Apply kqRWallFunction on all solid walls. Set front and back to empty.

In 0/epsilon set internalField uniform 1e-5. Apply epsilonWallFunction on all solid walls. Set front and back to empty.

In 0/nut set internalField uniform 0. Apply nutkWallFunction on all solid walls. Set front and back to empty.

In 0/alphat set internalField uniform 0. Apply compressible::alphatJayatillekeWallFunction on all solid walls with Prt 0.85. Set front and back to empty.

In system/fvSolution set the p_rgh solver to tolerance 1e-8 and relTol 0.01. Set solvers for U, e, k, and epsilon each to tolerance 1e-8 and relTol 0.01. Set the corresponding Final solvers (p_rghFinal, UFinal, eFinal, kFinal, epsilonFinal) to the same tolerance 1e-8 and relTol 0.
