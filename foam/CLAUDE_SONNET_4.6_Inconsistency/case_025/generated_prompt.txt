Simulate 3D incompressible turbulent flow around a surface-mounted cube in a channel using OpenFOAM's simpleFoam solver.

Use the RANS kEpsilon turbulence model for closure.

The geometry consists of a rectangular channel with a cube mounted on the floor.

Define the cube side length as H. Set the channel dimensions as: length 14H in the streamwise (x) direction, height 2H in the wall-normal (y) direction, and width 4H in the spanwise (z) direction.

Position the cube with its upstream face at x = 4H from the inlet, centered in the spanwise direction, sitting on the floor at y = 0.

Create the mesh using blockMeshDict with a fully 3D block-structured mesh having more than one cell in the spanwise direction.

Use at least 10 cells in the spanwise direction to ensure the mesh is genuinely 3D.

Apply grading to refine cells near all solid walls (floor, cube faces, top wall) in the wall-normal direction.

Define the following named patches in blockMeshDict: inlet, outlet, floor, top, cube, left, right.

In blockMeshDict, define the left and right side patches with type symmetryPlane.

In the 0/ directory, set the following boundary conditions.

For the inlet patch: set U to fixedValue with a uniform streamwise velocity U0 (e.g., 1 m/s), set p to zeroGradient, set k to fixedValue computed as k = 1.5*(I*U0)^2 with turbulence intensity I = 0.05, set epsilon to fixedValue computed as epsilon = C_mu^0.75 * k^1.5 / (0.07*H) with C_mu = 0.09.

For the outlet patch: set p to fixedValue uniform 0, set U to zeroGradient, set k to zeroGradient, set epsilon to zeroGradient.

For all solid wall patches (floor, top, cube): set U to noSlip, set p to zeroGradient, set k to kqRWallFunction, set epsilon to epsilonWallFunction.

For the left and right patches: set the type to symmetryPlane for all fields (U, p, k, epsilon).

In constant/transportProperties, set the kinematic viscosity nu to give a Reynolds number Re = U0*H/nu of at least 10000 (e.g., nu = 1e-5 m^2/s with U0 = 1 m/s and H = 0.1 m).

In constant/turbulenceProperties, set simulationType to RAS, the RAS model to kEpsilon, and set turbulence to on.

In system/fvSchemes, use steadyState for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for the divergence of U, Gauss linear corrected for laplacianSchemes, and corrected for snGradSchemes.

In system/fvSolution, use SIMPLE algorithm. Set nNonOrthogonalCorrectors to 2. Set residual convergence tolerances to 1e-5 for p and 1e-6 for U, k, and epsilon. Set relaxation factors to 0.3 for p and 0.7 for U, k, and epsilon.

In system/controlDict, set application to simpleFoam, startFrom to startTime with startTime 0, stopAt to endTime with endTime 500, deltaT to 1, writeControl to timeStep, writeInterval to 50, and writeFormat to ascii.

Run the case with simpleFoam.
