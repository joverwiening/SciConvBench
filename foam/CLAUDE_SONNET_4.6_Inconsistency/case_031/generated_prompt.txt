Set up a 2D incompressible laminar flow simulation in a rectangular channel using the icoFoam solver.

The channel is 0.5 m long in the x-direction and 0.1 m high in the y-direction.

The mesh is one cell thick in the z-direction to enforce the 2D assumption.

In blockMeshDict, define the block vertices for a rectangular domain spanning x: 0 to 0.5, y: 0 to 0.1, z: 0 to one cell thickness (e.g., 0 to 0.01).

In blockMeshDict, define five patches: inlet, outlet, topWall, bottomWall, and frontAndBack.

Set the patch type for inlet as patch, outlet as patch, topWall as wall, bottomWall as wall, and frontAndBack as empty in blockMeshDict.

Choose a mesh resolution appropriate for laminar channel flow, for example 50 cells in x, 20 cells in y, and 1 cell in z.

The simulation models Poiseuille flow driven by a parabolic inlet velocity profile.

In 0/U, set the inlet boundary condition to fixedValue with a parabolic profile in the y-direction having a maximum velocity of 1 m/s at the channel centerline, following U = 1.5 * Umax * (1 - ((y - H/2)/(H/2))^2) where H is 0.1 m.

In 0/U, set the outlet boundary condition to zeroGradient.

In 0/U, set topWall and bottomWall boundary conditions to noSlip.

In 0/U, set the frontAndBack boundary condition to type empty.

In 0/p, set the outlet boundary condition to fixedValue with a value of 0.

In 0/p, set the inlet, topWall, and bottomWall boundary conditions to zeroGradient.

In 0/p, set the frontAndBack boundary condition to type empty.

In transportProperties, set the kinematic viscosity nu to a value consistent with laminar flow, for example 0.001 m^2/s, giving a Reynolds number of approximately 100.

In fvSchemes, use Euler for time discretization, Gauss linear for gradient and divergence schemes, and Gauss linear corrected for the Laplacian scheme.

In fvSolution, use PCG with DIC preconditioner for the pressure solver and PBiCG with DILU preconditioner for the velocity solver.

Use the PISO algorithm as implemented by icoFoam with at least 2 corrector steps.

Set the time step deltaT to 0.001 s, the end time to 10 s, and write output every 1 s.
