Simulate a 2D bubble column using twoPhaseEulerFoam.
The column geometry is 0.5m wide and 2m high.
The continuous phase is water and the dispersed phase is air.
Initialize the domain fields using setFieldsDict.
The default field values (top 0.5m pure air region) set alpha.air to 0.9 and alpha.water to 0.1.
The boxToCell region covers the bottom 1.5m of the column, defined by the box (0 0 -0.1) to (0.5 1.5 0.1).
In the boxToCell region, set alpha.air to 0.4 and alpha.water to 0.6.
The two phase fractions in every region must sum to exactly 1.0.
Use the following corrected setFieldsDict configuration:

FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      setFieldsDict;
}

defaultFieldValues
(
    volScalarFieldValue alpha.air 0.9
    volScalarFieldValue alpha.water 0.1
);

regions
(
    boxToCell
    {
        box (0 0 -0.1) (0.5 1.5 0.1);
        fieldValues
        (
            volScalarFieldValue alpha.air 0.4
            volScalarFieldValue alpha.water 0.6
        );
    }
);

The solver to use is twoPhaseEulerFoam.
The simulation domain is 2D (one cell thick in the z-direction, with empty boundary conditions on the front and back faces).
The continuous phase is water and the dispersed phase is air throughout the simulation.
