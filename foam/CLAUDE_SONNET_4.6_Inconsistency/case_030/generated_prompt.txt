Set up a 2D natural convection simulation in a square cavity using buoyantBoussinesqPimpleFoam.
The left wall is hot with a fixed temperature of 310 K using a fixedValue boundary condition.
The right wall is cold with a fixed temperature of 290 K using a fixedValue boundary condition.
The top wall is adiabatic using a zeroGradient boundary condition for temperature.
The bottom wall is adiabatic using a zeroGradient boundary condition for temperature.
Initialize the temperature field T uniformly at 300 K across the entire domain.
Initialize the velocity field U at rest, meaning uniform (0 0 0) across the entire domain.
In 0/T, set the bottomWall patch to type zeroGradient (not fixedValue).
In 0/T, set the topWall patch to type zeroGradient.
In 0/T, set the leftWall patch to type fixedValue with value uniform 310.
In 0/T, set the rightWall patch to type fixedValue with value uniform 290.
In 0/T, set the internal field to uniform 300.
In 0/U, set all wall patches to type fixedValue with value uniform (0 0 0) to enforce no-slip conditions.
In 0/U, set the internal field to uniform (0 0 0).
The simulation domain is a square cavity in 2D, so the front and back patches must be set to empty type to enforce the 2D assumption in OpenFOAM.
