The simulation is for a three-phase immiscible fluid separation (oil, water, gas) in a horizontal gravity separator using the VOF method in OpenFOAM.

The solver specified in controlDict is interFoam.

The domain is a 3D horizontal box with dimensions 2.0 m (length) x 1.0 m (height) x 0.1 m (width), representing a typical lab-scale horizontal separator.

The mesh resolution is 200 cells in the x-direction, 100 cells in the y-direction, and 1 cell in the z-direction, giving a 2D planar simulation with unit depth.

The mesh is generated using blockMesh with uniform cell distribution.

Gravity is set to (0 -9.81 0) in the constant/g file, acting in the negative y-direction.

The phases are defined in constant/transportProperties using a three-phase VOF framework compatible with interFoam (or multiphaseInterFoam if three-phase VOF is required; use multiphaseInterFoam as the solver since interFoam natively handles only two phases, but the user specified interFoam, so treat water and oil as the two primary VOF phases and gas as the third phase represented implicitly as 1 - alpha.water - alpha.oil).

The solver in controlDict is set to multiphaseInterFoam to correctly handle three immiscible phases with VOF, as interFoam only supports two phases; this resolves the implicit contradiction in the user request.

Water density is 1000 kg/m³ and dynamic viscosity is 1e-3 Pa·s.

Oil density is 800 kg/m³ and dynamic viscosity is 5e-3 Pa·s.

Gas density is 1.2 kg/m³ and dynamic viscosity is 1.8e-5 Pa·s.

The phases are defined in constant/transportProperties with entries for water, oil, and gas including their respective nu (kinematic viscosity) values computed as mu/rho.

The initial stratified configuration is set using setFieldsDict with three horizontal layers based on height fractions of the domain.

The bottom 40% of the domain height (0.0 to 0.4 m) is initialized as water, so alpha.water = 1 in that region.

The middle 40% of the domain height (0.4 to 0.8 m) is initialized as oil, so alpha.oil = 1 in that region.

The top 20% of the domain height (0.8 to 1.0 m) is initialized as gas, so alpha.gas = 1 in that region.

All alpha fields are initialized to 0 everywhere before applying the setFieldsDict regions.

The simulation start time is 0 s.

The end time is 20 s, which is sufficient to observe gravitational stratification and interface development.

The time step deltaT is set to 0.001 s with adjustable time stepping enabled.

The maximum Courant number maxCo is set to 0.5 to maintain numerical stability at the interface.

The write interval is set to 1 s so that 20 output time directories are saved.

The writeControl is set to adjustableRunTime.

The numerical schemes in fvSchemes use Gauss vanLeer for divergence of alpha fields to maintain sharp interfaces.

The MULES (Multidimensional Universal Limiter with Explicit Solution) algorithm is used for interface compression, with nAlphaCorr set to 2 and nAlphaSubCycles set to 1 in fvSolution.

The pressure-velocity coupling uses the PIMPLE algorithm with nOuterCorrectors 1, nCorrectors 3, and nNonOrthogonalCorrectors 1.

Boundary conditions on the left and right faces (inlet/outlet) are set to zeroGradient for all alpha fields and velocity, with fixedValue 0 for pressure.

The top and bottom walls use noSlip boundary condition for velocity and zeroGradient for pressure and alpha fields.

The front and back faces (z-direction) use empty boundary condition for the 2D simulation.

The initial velocity field U is set to uniform (0 0 0) everywhere, representing a static initial condition.

The initial pressure field p_rgh is set to uniform 0 with hydrostatic pressure handled by the solver.
