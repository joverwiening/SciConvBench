The simulation is a 2D dam break case using the interFoam solver in OpenFOAM.

The domain is a rectangle 0.6m in the X-direction and 0.4m in the Y-direction.
Use blockMesh to define the geometry as a single block.
Set the mesh resolution to 60 cells in the X-direction and 40 cells in the Y-direction, giving a uniform cell size of 0.01m, which is a standard best-practice resolution for this benchmark case.
Set the number of cells in the Z-direction to 1 for a 2D simulation.
The front and back boundary patches are of type empty to enforce 2D behavior.

Define two phases in constant/transportProperties named water and air.
Use the following properties for water: kinematic viscosity nu = 1e-6 m2/s, density rho = 1000 kg/m3.
Use the following properties for air: kinematic viscosity nu = 1.48e-5 m2/s, density rho = 1 kg/m3.
Set the surface tension coefficient sigma = 0.07 N/m.

Set the gravity vector in constant/g to (0 0 -9.81) m/s2.

Define the initial water column in system/setFieldsDict as the region where x < 0.15m and y < 0.3m.
Set alpha.water = 1 inside this region and alpha.water = 0 everywhere else.

For the U field in 0/U: apply noSlip on all wall patches, apply pressureInletOutletVelocity with a uniform value of (0 0 0) on the atmosphere patch.
For the p_rgh field in 0/p_rgh: apply fixedFluxPressure on all wall patches, apply totalPressure with p0 = 0 on the atmosphere patch.
For the alpha.water field in 0/alpha.water: apply zeroGradient on all wall patches, apply inletOutlet with inletValue = 0 and value = 0 on the atmosphere patch.

The top boundary is named atmosphere and is of type patch.
The remaining boundaries (left, right, bottom) are named walls and are of type wall.

In system/controlDict, set the application to interFoam.
Set startTime to 0, endTime to 2 seconds.
Set deltaT to 0.001 seconds as the initial time step.
Enable adjustTimeStep with maxCo = 0.5 and maxAlphaCo = 0.5 to ensure numerical stability.
Set writeInterval to 0.05 seconds to capture sufficient output frames.

In system/fvSolution, use PIMPLE with nOuterCorrectors = 1, nCorrectors = 3, and nNonOrthogonalCorrectors = 0.
Use PBiCGStab with DILU preconditioner for velocity and alpha solvers.
Use GAMG with DIC preconditioner for pressure.

In system/fvSchemes, use Euler for time discretization (ddtSchemes).
Use Gauss linear for gradSchemes.
Use Gauss vanLeer for the div(phi,alpha) scheme to ensure boundedness of the phase fraction.
Use Gauss linear corrected for laplacianSchemes.
