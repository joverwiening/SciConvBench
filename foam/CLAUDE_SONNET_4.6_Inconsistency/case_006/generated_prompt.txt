Run a 2D gas-liquid bubble column simulation using multiphaseEulerFoam (Euler-Euler approach) in OpenFOAM.

Domain and Mesh
The rectangular domain spans x in [0, 0.15] m, y in [0, 1.00] m, z in [0, 0.10] m with height along the +y direction and the domain thin in the z direction.
Use a structured hex mesh with 25 x 75 x 1 cells and simpleGrading (1 1 1).
Define the blockMeshDict with an inlet patch at the bottom (y = 0), an outlet patch at the top (y = 1.00), wall patches on the left and right sides (x = 0 and x = 0.15), and empty patches on the front and back faces (z = 0 and z = 0.10) for 2D treatment.

Gravity
Set gravity to (0 -9.81 0) m/s² so it acts in the -y direction, aligned with the column height axis.

Continuous Phase: Water
Use heRhoThermo thermodynamic model for water.
Use rPolynomial equation of state for water with C coefficients (0.001278 -2.1055e-06 3.9689e-09 4.3772e-13 -2.0225e-16).
Set molecular weight of water to 18.
Set specific heat capacity Cv of water to 4195 J/(kg·K).
Set dynamic viscosity of water to 3.645e-4 Pa·s.
Set Prandtl number of water to 2.289.
Water is the reference (continuous) phase.

Dispersed Phase: Air
Use heRhoThermo thermodynamic model for air.
Use perfectGas equation of state for air.
Set molecular weight of air to 28.9.
Set specific heat capacity Cp of air to 1007 J/(kg·K).
Set dynamic viscosity of air to 1.84e-05 Pa·s.
Set Prandtl number of air to 0.7.

Bubble Size Models
Use isothermal diameter model for air with d0 = 3e-3 m.
Use constant diameter model for water with d = 1e-4 m.

Momentum Transport
Set simulationType to laminar in the momentumTransport file for both the air phase and the water phase.

Phase Properties and Blending
Define phases as (air water) in phaseProperties with water as the reference phase.
Set residualAlpha to 1e-6 for both air and water.
Use linear blending scheme with minFullyContinuousAlpha 0.7 and minPartlyContinuousAlpha 0.3 as the default blending parameters.
Use minFullyContinuousAlpha 0.5 and minPartlyContinuousAlpha 0.3 for the drag blending parameters.

Interfacial Models
Set surface tension between air and water to constant with sigma = 0.07 N/m.
Use SchillerNaumann drag model for air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water configurations.
Use constantCoefficient virtual mass model with Cvm = 0.5 for both air-in-water and water-in-air directions.
Use RanzMarshall heat transfer model for both directions with residualAlpha = 1e-4.

Initial Conditions at t = 0
Set velocity of water to uniform (0 0 0).
Set velocity of air to uniform (0 0.1 0).
Set volume fraction of water to uniform 1.
Set pressure p_rgh to uniform 1e5 Pa.
Set temperature of air to uniform 300 K.
Set temperature of water to uniform 350 K.
Use setFieldsDict to define default field values where volume fraction of air is 1 and volume fraction of water is 0 everywhere, then override the box region from (0 0 0) to (0.15 0.701 0.1) to set volume fraction of air to 0 and volume fraction of water to 1.

Boundary Conditions at Inlet (y = 0)
Set velocity of air to fixedValue (0 0.1 0).
Set velocity of water to fixedValue (0 0 0).
Set volume fraction of air to fixedValue 0.5.
Set volume fraction of water to fixedValue 0.5.
Set temperature of air to fixedValue 300 K.
Set temperature of water to fixedValue 350 K.
Set p_rgh at inlet to zeroGradient.

Boundary Conditions at Outlet (y = 1.00)
Set p_rgh at outlet to totalPressure or fixedValue 1e5 Pa.
Set velocity of air and water at outlet to zeroGradient or inletOutlet as appropriate for an outflow boundary.
Set volume fraction of air and water at outlet to zeroGradient.
Set temperature of air and water at outlet to zeroGradient.

Boundary Conditions at Walls (x = 0 and x = 0.15)
Set velocity of air to fixedValue (0 0 0).
Set velocity of water to fixedValue (0 0 0).
Set volume fraction of air to zeroGradient.
Set volume fraction of water to zeroGradient.
Set p_rgh at walls to fixedFluxPressure.
Set temperature of air to zeroGradient.
Set temperature of water to zeroGradient.

Boundary Conditions at Empty Faces (z = 0 and z = 0.10)
Set all fields on the front and back faces to empty type for 2D treatment.

Time Controls
Set startTime to 0 s.
Set endTime to 20 s.
Set deltaT to 0.005 s.
Set adjustTimeStep to no.
Set maxCo to 0.5.
Set maxDeltaT to 1.
Set writeInterval to 1 s.
