Final Specification:

The simulation is a 2D steady-state Rayleigh-Benard convection cell in a rectangular cavity.
The domain is 9 units wide (x), 1 unit tall (y), and 1 cell thick (z, spanwise extrusion).
Use 90 cells in x, 10 cells in y, and 1 cell in z.
The front and back patches are of type empty to enforce 2D behavior.
Use the buoyantSimpleFoam solver (steady-state, buoyancy-driven, compressible-compatible).
Gravity acts in the negative y direction: g = (0 -9.81 0) m/s².

Mesh and Geometry:
Create the blockMesh with vertices spanning (0 0 0) to (9 1 1) with the z-thickness set to 1 unit (single cell).
Define blocks with hex notation using 90 10 1 cells and simpleGrading (1 1 1).
Name the patches: bottom (y=0), top (y=1), left (x=0), right (x=9), frontAndBack (z=0 and z=1).
Set frontAndBack patch type to empty.
Set bottom, top, left, right patch types to wall.

Solver:
Use buoyantSimpleFoam for steady-state buoyancy-driven flow.
Set deltaT 1 in system/controlDict.
Do not enable adjustTimeStep, maxCo, or maxDeltaT.
Set endTime to 1000 in system/controlDict.
Set writeInterval to 50 in system/controlDict.
Set writeControl to timeStep in system/controlDict.
Set startFrom to startTime with startTime 0.

Turbulence Model:
In constant/momentumTransport set simulationType to RAS.
Set model to kEpsilon.
Set turbulence to on.
Set printCoeffs to on.
Do not use laminar anywhere.

Thermophysical Properties:
In constant/physicalProperties use thermoType with class heRhoThermo, type rhoThermo, mixture pureMixture, transport const, thermo hConst, equationOfState Boussinesq, specie specie, energy sensibleEnthalpy.
Set molWeight to 29.
Set rho0 to 1.0.
Set T0 to 300.
Set beta to 3.3e-3.
Set Cv to 714.3.
Set Hf to 0.
Set mu to 1.5e-5.

Set thermal expansion coefficient beta to 3.3e-3 1/K.
Set kinematic viscosity to 1.5e-5 m²/s (mu = rho * nu = 1.5e-5 Pa·s since rho=1).
