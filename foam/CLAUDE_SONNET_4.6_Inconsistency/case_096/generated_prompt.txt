The simulation uses the interFoam solver for a 2D dam break problem with water and air as two incompressible, immiscible fluids.

The domain is a rectangular tank 0.5m in x, 0.5m in y, and 0.01m in z.

Use blockMesh to generate the mesh with 50 cells in the x-direction, 50 cells in the y-direction, and 1 cell in the z-direction, giving a uniform cell size of 0.01m x 0.01m x 0.01m.

Define the eight vertices of the block in blockMeshDict as (0 0 0), (0.5 0 0), (0.5 0.5 0), (0 0.5 0), (0 0 0.01), (0.5 0 0.01), (0.5 0.5 0.01), (0 0.5 0.01).

Use a single hex block with simpleGrading (1 1 1) for uniform cell distribution.

Assign the following boundary patches in blockMeshDict: leftWall as the face at x=0, rightWall as the face at x=0.5, lowerWall as the face at y=0, atmosphere as the face at y=0.5, frontAndBack as the two faces at z=0 and z=0.01.

In constant/polyMesh/boundary, set leftWall, rightWall, and lowerWall to type wall.

In constant/polyMesh/boundary, set atmosphere to type patch.

In constant/polyMesh/boundary, set frontAndBack to type symmetryPlane.

Set gravity in constant/g as (0 -9.81 0) m/s^2.

Define water properties in constant/transportProperties: nu = 1e-06 m^2/s, rho = 1000 kg/m^3.

Define air properties in constant/transportProperties: nu = 1.48e-05 m^2/s, rho = 1 kg/m^3.

Set the surface tension sigma between water and air to 0.07 N/m in constant/transportProperties.

Use constant/turbulenceProperties to set simulationType to laminar.

Create the 0/alpha.water field with internalField uniform 0.

Set the alpha.water boundary condition on leftWall, rightWall, and lowerWall to zeroGradient.

Set the alpha.water boundary condition on frontAndBack to symmetry.

Set the alpha.water boundary condition on atmosphere to inletOutlet with inletValue uniform 0 and value uniform 0.

Create the 0/U field with internalField uniform (0 0 0).

Set the U boundary condition on leftWall, rightWall, and lowerWall to noSlip.

Set the U boundary condition on frontAndBack to symmetry.

Set the U boundary condition on atmosphere to pressureInletOutletVelocity with value uniform (0 0 0).

Create the 0/p_rgh field with internalField uniform 0.

Set the p_rgh boundary condition on leftWall, rightWall, and lowerWall to fixedFluxPressure with value uniform 0.

Set the p_rgh boundary condition on frontAndBack to fixedFluxPressure with value uniform 0.

Set the p_rgh boundary condition on atmosphere to totalPressure with p0 uniform 0 and value uniform 0.

Use system/setFieldsDict to initialize alpha.water.

In setFieldsDict, set the defaultFieldValues to alpha.water = 0.

In setFieldsDict, define one region using boxToCell with box (0 0 0) (0.15 0.5 0.01) and set alpha.water = 1 within this region.

Run setFields before running interFoam to initialize the water column.

In system/controlDict, set application to interFoam.

Set startFrom to startTime with startTime 0.

Set stopAt to endTime with endTime 1.0 seconds.

Set deltaT to 0.001 seconds.

Set adjustTimeStep to yes.

Set maxCo to 0.5.

Set maxAlphaCo to 0.5.

Set maxDeltaT to 0.01 seconds.

Set writeControl to adjustableRunTime with writeInterval 0.05 seconds.

Set writeFormat to ascii.

Set runTimeModifiable to yes.

In system/fvSchemes, set ddtSchemes default to Euler.

Set gradSchemes default to Gauss linear.

Set divSchemes for div(rhoPhi,U) to Gauss linearUpwind grad(U).

Set divSchemes for div(phi,alpha) to Gauss vanLeer.

Set divSchemes for div(phirb,alpha) to Gauss linear.

Set laplacianSchemes default to Gauss linear corrected.

Set interpolationSchemes default to linear.

Set snGradSchemes default to corrected.

In system/fvSolution, set the PIMPLE solver with nOuterCorrectors 1, nCorrectors 3, and nNonOrthogonalCorrectors 0.

Set the solver for alpha.water to smoothSolver with smoother symGaussSeidel, tolerance 1e-8, and relTol 0.

Set the solver for pcorr and p_rgh to PCG with DIC preconditioner, tolerance 1e-7, and relTol 0.05.

Set the solver for U to smoothSolver with smoother symGaussSeidel, tolerance 1e-7, and relTol 0.
