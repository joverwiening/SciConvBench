Use the twoPhaseEulerFoam solver in OpenFOAM for a 2D transient gas-liquid bubble column simulation.
The two phases are air (gas) and water (liquid).
The computational domain is a 2D rectangle of 0.5 m width and 2 m height.
Create a blockMesh dictionary that defines this rectangular domain with a suitable 2D mesh (one cell thick in the z-direction).
The simulation is transient.
The bottom boundary is named "inlet".
The top boundary is named "outlet".
The left and right boundaries are named "walls" and are treated as no-slip walls.
The front and back boundaries are set as "empty" type for 2D simulation.
In the file 0/alpha.air, set the inlet patch boundary condition to: type fixedValue; value uniform 0.8;
In the file 0/alpha.water, set the inlet patch boundary condition to: type fixedValue; value uniform 0.2;
The inlet volume fractions sum to 1.0 (0.8 air + 0.2 water).
In the file 0/U.air, set the inlet patch velocity boundary condition to: type fixedValue; value uniform (0 0.2 0);
In the file 0/U.water, set the inlet patch velocity boundary condition to: type fixedValue; value uniform (0 0.01 0);
At the outlet (top boundary), use a pressureInletOutletVelocity condition for velocity and a fixedValue or totalPressure condition for pressure.
At the walls (sides), apply noSlip or fixedValue (0 0 0) velocity boundary conditions for both phases.
Set the initial condition for alpha.air in the domain interior to 0 (domain initially filled with water).
Set the initial condition for alpha.water in the domain interior to 1.
Use the constant/phaseProperties dictionary to define air and water as the two phases with appropriate physical properties (density of air ~1.225 kg/m³, density of water ~1000 kg/m³, dynamic viscosity of air ~1.8e-5 Pa·s, dynamic viscosity of water ~1e-3 Pa·s).
Use the constant/turbulenceProperties or constant/momentumTransport file to define the turbulence model (laminar or a suitable RANS model such as kEpsilon).
Set gravitational acceleration to (0 -9.81 0) m/s² in the constant/g file.
Use the system/controlDict to define the start time as 0, an appropriate end time (e.g., 10 s), and a time step (e.g., deltaT = 0.001 s).
Use the system/fvSchemes and system/fvSolution files with settings appropriate for twoPhaseEulerFoam.
The simulation uses SI units throughout.
