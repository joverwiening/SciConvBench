Set up an axisymmetric simpleFoam simulation of swirling flow inside a pipe using a 2D wedge geometry.

Use a pipe radius of 0.05 m and an axial length of 0.5 m.
Use 20 cells in the radial direction and 100 cells in the axial direction.
The wedge angle is 5 degrees in the tangential direction, one cell thick.

Create the file system/blockMeshDict to define the wedge mesh.
Place the axis of symmetry along the x-axis (axial direction).
Define 8 vertices: 4 on the front plane and 4 on the back plane of the wedge, at z = +/- r*sin(2.5 deg) offset.
The front plane is at +2.5 degrees from the x-z reference plane and the back plane is at -2.5 degrees.

Define the following patches in blockMeshDict:
Name the inlet patch "inlet" at x = 0, covering the radial face from axis to wall.
Name the outlet patch "outlet" at x = 0.5, covering the radial face from axis to wall.
Name the pipe wall patch "wall" at r = 0.05, type wall.
Name the axial patch "axis" at r = 0, type empty (the axis line).
Name the front patch "front" with type empty, using faces ((0 3 2 1)).
Name the back patch "back" with type empty, using faces ((4 5 6 7)).

Create the file constant/transportProperties and set the kinematic viscosity nu to 1e-05 m^2/s.
Create the file constant/turbulenceProperties and set simulationType to laminar.

Create the file 0/U to define the velocity field.
Set the internal field to uniform (0 0 0).
Set the inlet boundary condition for U to fixedValue with a uniform axial velocity of (1 0 0) m/s and a swirl component; use a combined axial and tangential velocity of (1 0 0.5) in (Ux Uy Uz) mapped to the wedge, or use a swirlFlowRateInletVelocity boundary condition with axialVelocity 1.0 m/s and rpm 500.
Set the outlet boundary condition for U to zeroGradient.
Set the wall boundary condition for U to noSlip.
Set the axis boundary condition for U to empty.
Set the front and back boundary conditions for U to empty.

Create the file 0/p to define the pressure field.
Set the internal field to uniform 0.
Set the inlet boundary condition for p to zeroGradient.
Set the outlet boundary condition for p to fixedValue uniform 0.
Set the wall boundary condition for p to zeroGradient.
Set the axis boundary condition for p to empty.
Set the front and back boundary conditions for p to empty.

Create the file system/fvSchemes.
Set ddtSchemes default to steadyState.
Set gradSchemes default to Gauss linear.
Set divSchemes for div(phi,U) to Gauss linearUpwind grad(U).
Set div(phi,p) to Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.

Create the file system/fvSolution.
Use the SIMPLE algorithm block with nNonOrthogonalCorrectors 1.
Set the solver for p to PCG with DIC preconditioner, tolerance 1e-6, relTol 0.01.
Set the solver for U to PBiCGStab with DILU preconditioner, tolerance 1e-7, relTol 0.01.
Set relaxationFactors for U to 0.7 and for p to 0.3.

Create the file system/controlDict.
Set application to simpleFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 500.
Set deltaT to 1.
Set writeControl to timeStep with writeInterval 50.
Set runTimeModifiable to true.

Run blockMesh to generate the mesh before running simpleFoam.
Run checkMesh after blockMesh to verify mesh quality.
Run simpleFoam to execute the steady-state simulation.
