Simulate a 2D supersonic flow of air at Mach 2 over a 10-degree wedge (oblique shock) using OpenFOAM.

Use rhoCentralFoam as the solver application.

Set the application field in system/controlDict to rhoCentralFoam.

Treat air as a perfect gas (calorically perfect, constant specific heats).

In constant/thermophysicalProperties, use hePsiThermo as the thermoType model, pureMixture as the mixture, perfectGas as the equationOfState, hConst as the thermo model, and constTransport for transport properties.

Set molecular weight to 28.96 g/mol, Cp to 1005 J/(kg·K), dynamic viscosity mu to 1.8e-5 Pa·s, and Prandtl number Pr to 0.713.

Use a 2D mesh that represents the wedge geometry in the x-y plane and is extruded exactly one cell in the z-direction.

Set the wedge half-angle to 10 degrees so the lower boundary rises at 10 degrees from the inlet.

Set the frontAndBack patches to the empty boundary condition type on all relevant fields.

Define freestream/inlet conditions as: U = (686 0 0) m/s, p = 101325 Pa, T = 300 K.

These inlet conditions correspond to Mach 2 flow (speed of sound approximately 347 m/s in air at 300 K).

For the inlet boundary, apply fixedValue for U set to (686 0 0), fixedValue for p set to 101325 Pa, and fixedValue for T set to 300 K.

For the outlet boundary, apply zeroGradient for U, waveTransmissive (or zeroGradient) for p, and zeroGradient for T.

For the wedge surface and the top boundary, apply slip wall conditions (slip for U, zeroGradient for p and T).

For the frontAndBack boundaries, apply empty to all fields (U, p, T, and any other solved fields).

In system/fvSchemes, use Kurganov-Tadmor (KT) or similar shock-capturing schemes appropriate for rhoCentralFoam, such as vanLeer or Minmod limiters for the flux interpolation.

In system/fvSolution, configure the solver settings appropriate for rhoCentralFoam (e.g., diagonal or PCG solvers for the relevant fields).

Set the Courant number (maxCo) to no greater than 0.5 in system/controlDict to ensure numerical stability for the explicit time-stepping in rhoCentralFoam.

Use adjustTimeStep yes with maxCo 0.5 in system/controlDict.

Run the simulation until a steady oblique shock is established, observable as a straight shock wave emanating from the leading edge of the wedge at the theoretically predicted shock angle (approximately 39.3 degrees for Mach 2 over a 10-degree wedge using the theta-beta-Mach relation).
