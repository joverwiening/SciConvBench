Set up a transient 2D vortex shedding simulation behind a circular cylinder at Reynolds number 100 using OpenFOAM.

Use the pimpleFoam solver for transient, incompressible, laminar flow.

The fluid is incompressible with kinematic viscosity nu = 0.01 m^2/s.

The cylinder diameter D is 1 m.

The inlet velocity is U = (1 0 0) m/s, giving Re = U*D/nu = 100.

The domain is a rectangular channel in 2D (one cell thick in the z-direction).

Place the circular cylinder offset slightly from the horizontal centerline of the channel to help trigger asymmetric vortex shedding (a vertical offset of 5-10% of the channel height is acceptable).

The recommended domain size is: length 40D in the x-direction (e.g., inlet 10D upstream of cylinder center, outlet 30D downstream), and height 20D in the y-direction.

Create the geometry and mesh using OpenFOAM's blockMesh and snappyHexMesh utilities, or use blockMesh with a cylindrical cutout.

Use a single cell in the z-direction (thickness 0.1 m) to enforce 2D behavior via empty boundary conditions on the front and back patches.

Define the following boundary conditions:

For the inlet patch: fixedValue with U = (1 0 0) m/s, and zeroGradient for pressure p.

For the outlet patch: zeroGradient for U, and fixedValue p = 0 Pa.

For the topAndBottom patches: slip condition for U, and zeroGradient for p.

For the cylinder patch: noSlip (fixedValue U = (0 0 0)), and zeroGradient for p.

For the frontAndBack patches: empty type for both U and p to enforce 2D simulation.

Set the simulation start time to 0 s and end time to 200 s.

Set deltaT to 0.1 s.

Set the write interval to every 1 s (writeInterval 1) to save flow field data for post-processing.

Use the PIMPLE algorithm with nOuterCorrectors = 2, nCorrectors = 2, and nNonOrthogonalCorrectors = 1.

Set the numerical schemes to: Gauss linear for gradient schemes, Gauss linear corrected for Laplacian schemes, and Gauss linearUpwind grad(U) for the divergence scheme of U.

Use GAMG solver for pressure and smoothSolver with GaussSeidel for velocity.

Set the flow to laminar (no turbulence model).

After the simulation, extract the time history of the lift force (Cy) on the cylinder using the OpenFOAM forces function object or by sampling pressure on the cylinder patch.

Calculate the Strouhal number as St = f*D/U, where f is the dominant vortex shedding frequency obtained from a Fast Fourier Transform (FFT) of the lift coefficient time series.

The expected Strouhal number for Re=100 is approximately 0.164.

Visualize the vorticity field and velocity magnitude in ParaView to confirm the von Kármán vortex street pattern.
