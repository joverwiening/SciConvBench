The solver is `buoyantSimpleFoam`, used for steady-state buoyant compressible flow in a solar chimney.

Air is heated at the bottom of the chimney and rises due to density changes driven by temperature.

Gravity is defined in the `constant/g` file.

The thermophysical model uses a compressible perfect gas approach, not the Boussinesq approximation.

The `constant/thermophysicalProperties` file uses the older-style flat keyword format.

Set `thermoType` to `hePsiThermo`.

Set `mixture` to `perfectGas`.

Set `transport` to `const`.

Set `thermo` to `hConst`.

Set `equationOfState` to `perfectGas`.

Set `specie` to `specie`.

Set `energy` to `sensibleEnthalpy`.

The `specie` sub-dictionary contains `molWeight 28.9` (air).

The `thermodynamics` sub-dictionary contains `Cp 1005` and `Hf 0`.

The `transport` sub-dictionary contains `mu 1.8e-05` and `Pr 0.7`.

Remove all Boussinesq-related entries, including `BoussinesqCoeffs`, `TRef`, `beta`, and `rhoRef`, from the `thermophysicalProperties` file.

The final `constant/thermophysicalProperties` file reads as follows:

FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      thermophysicalProperties;
}

thermoType      hePsiThermo;
mixture         perfectGas;
transport       const;
thermo          hConst;
equationOfState perfectGas;
specie          specie;
energy          sensibleEnthalpy;

specie
{
    molWeight   28.9;
}

thermodynamics
{
    Cp          1005;
    Hf          0;
}

transport
{
    mu          1.8e-05;
    Pr          0.7;
}
