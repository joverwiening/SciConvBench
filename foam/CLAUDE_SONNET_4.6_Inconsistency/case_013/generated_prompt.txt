Use the denseParticleFoam solver with Lagrangian particle tracking for a dense fluidization simulation.

The domain is a rectangular column with convertToMeters factor of 0.001.
Vertices are defined as (-7.5 -75 0), (7.5 -75 0), (7.5 75 0), (-7.5 75 0), (-7.5 -75 450), (7.5 -75 450), (7.5 75 450), (-7.5 75 450) in millimeter units.
Use a structured hex mesh of 2x30x90 cells in x, y, z directions with simpleGrading (1 1 1).

The blockMeshDict file content is exactly as provided by the user, with the following boundary definitions:
Top patch has type wall with face (4 5 6 7).
Bottom patch has type wall with face (0 1 2 3).
Walls patch has type wall with faces (0 1 5 4) and (2 3 7 6).
FrontAndBack patch has type wall with faces (1 2 6 5) and (3 0 4 7).

Override the boundary condition types at the solver level as follows despite the blockMeshDict wall types:
Bottom patch uses interstitialInletVelocity of (0 0 1.875) m/s for velocity and fixedFluxPressure for pressure.
Top patch uses pressureInletOutletVelocity for velocity and fixedValue pressure of 0 Pa.
Walls patch uses noSlip for velocity and fixedFluxPressure for pressure.
FrontAndBack patch uses symmetry condition for both velocity and pressure.

The continuous phase is air with density 1.2 kg/m³ and kinematic viscosity 1e-05 m²/s.
Use laminar flow model for the continuous phase (no turbulence).

Particle cloud properties are as follows:
Particle density is 2526 kg/m³.
Particle diameter is 0.0025 m.
Injection method is manualInjection reading positions from a file named cloudPositions.
Assume particle positions are distributed in a regular grid pattern near the bottom of the column in the region x from -7.5 mm to 7.5 mm, y from -75 mm to 75 mm, and z from 5 mm to 50 mm (converted to meters: x from -0.0075 to 0.0075, y from -0.075 to 0.075, z from 0.005 to 0.05), with approximately 60 particles arranged in a 2x5x6 grid at equal spacing, giving positions at x in {-0.00375, 0.00375}, y in {-0.06, -0.03, 0, 0.03, 0.06}, z in {0.005, 0.014, 0.023, 0.032, 0.041, 0.05}.
Initial particle velocity is (0 0 0) m/s.
Wall interaction uses rebound model with coefficient of restitution 0.97 and friction coefficient 0.09.

Use ErgunWenYuDrag force model for particle-fluid interaction.
Use pairCollision model for particle-particle collisions.
Include gravity as (0 0 -9.81) m/s² applied in the z-direction.

Use the PIMPLE algorithm with 1 outer corrector (nOuterCorrectors 1) and 2 pressure correctors (nCorrectors 2).
Use Euler time integration scheme for time discretization.
Use Gauss linear schemes for gradient and divergence terms as appropriate for this solver.

Set startTime to 0, endTime to 0.02 seconds, deltaT to 2e-5 seconds.
Set write interval to 0.01 seconds using adjustableRunTime or fixed write control.
Set writeFormat to ascii.

Create the following directory and file structure:
0/ directory containing U, p, and cloud (particle) initial condition files.
constant/ directory containing blockMeshDict, transportProperties, turbulenceProperties, kinematicCloudProperties, and g files.
constant/polyMesh/ will be generated by blockMesh from blockMeshDict.
system/ directory containing controlDict, fvSchemes, fvSolution, and decomposeParDict files.
constant/cloudPositions file containing the 60 particle position vectors in OpenFOAM list format.

The cloudPositions file must be formatted as a valid OpenFOAM file with FoamFile header, class vectorField, and the list of 60 position vectors corresponding to the 2x5x6 grid described above.
