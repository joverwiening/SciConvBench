The simulation uses twoPhaseEulerFoam as the solver.
The domain is 2D with a width of 0.5m in the X-direction and a height of 2m in the Y-direction.
The depth in the Z-direction is a single cell thick to enforce 2D behavior.
The column is initially filled with water (alpha.air = 0, alpha.water = 1 everywhere at t=0).
The dispersed phase is air and the continuous phase is water.
The gravity vector in constant/g is set to g (0 -9.81 0).
Air is injected from a sparger patch located at the bottom center of the column.
The bottom boundary is an inlet patch representing the sparger.
On the inlet patch, alpha.air is set to fixedValue 1.
On the inlet patch, U.air is set to fixedValue (0 0.1 0).
On the inlet patch, U.water is set to fixedValue (0 0 0).
On the inlet patch, alpha.water is set to fixedValue 0.
The top boundary is an outlet patch.
On the outlet patch, use a pressureInletOutletVelocity condition for both phase velocities.
On the outlet patch, use a totalPressure or fixedValue pressure condition to allow outflow.
On the outlet patch, alpha.air and alpha.water use inletOutlet conditions.
The left and right side walls use noSlip boundary conditions for both phases.
The front and back patches are set to empty to enforce the 2D planar assumption.
The mesh is generated using blockMesh with a structured rectangular grid.
The mesh resolution is at least 50 cells in the X-direction and 200 cells in the Y-direction.
The sparger inlet patch spans only the center portion of the bottom face, not the full width.
The simulation runs for a physically meaningful time period sufficient to observe bubble rise, recommended at least 10 seconds of simulation time.
Use appropriate turbulence or drag models consistent with twoPhaseEulerFoam for air-water bubbly flow.
