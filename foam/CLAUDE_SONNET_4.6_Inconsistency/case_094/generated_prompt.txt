Final Specification:

The simulation models steady-state, compressible flow of natural gas through a cylindrical pipe containing a porous baffle.

Use the porousSimpleFoam solver from OpenFOAM.

Model the gas as a perfect gas by setting the equation of state to perfectGas in the thermophysicalProperties dictionary.

Define the gas as natural gas, approximated as methane, with the following thermophysical properties: molecular weight 16.04 g/mol, Cp 2222 J/kg/K, dynamic viscosity 1.1e-5 Pa·s, Prandtl number 0.74.

Define kinematic viscosity nu in the transportProperties dictionary as 1.5e-5 m²/s.

Use the k-omega SST turbulence model as the RANS closure, as it is best practice for internal flows with adverse pressure gradients.

Create the geometry and mesh using the blockMesh utility.

Model the pipe as a 3D rectangular channel approximating a pipe: length 1.0 m, cross-section 0.1 m x 0.1 m.

Place the porous baffle as a thin zone of thickness 0.05 m centered at x = 0.5 m along the pipe length.

Divide the mesh into three blocks along the pipe axis: upstream block from x=0 to x=0.475 m, porous block from x=0.475 m to x=0.525 m, downstream block from x=0.525 m to x=1.0 m.

Use 50 cells in the upstream block, 5 cells in the porous block, and 50 cells in the downstream block along the x-axis.

Use 20 cells in each of the y and z directions across the cross-section.

Apply a grading of 1 (uniform) throughout all blocks.

Set the inlet boundary condition as a totalPressure boundary with p0 = 2e5 Pa for total pressure.

Set the inlet velocity boundary condition to pressureInletVelocity.

Set the outlet boundary condition as fixedValue with static pressure = 1e5 Pa.

Set the outlet velocity boundary condition to zeroGradient.

Apply no-slip wall boundary conditions on all four side walls.

Set the initial internal field pressure to 1.5e5 Pa and velocity to uniform (0 0 0).

Set initial k to 0.1 m²/s² and omega to 1000 1/s throughout the domain.

Define the porous zone in the fvOptions dictionary using the DarcyForchheimerCoeff model applied to the porous baffle cell zone.

Use Darcy coefficient d = (1e7 1e7 1e7) 1/m² and Forchheimer coefficient f = (0 0 0) 1/m as best-practice values for a moderately resistive porous medium.

Set the cellZone name for the porous region to porousBaffle in both fvOptions and the blockMeshDict.

Use SIMPLE algorithm settings in fvSolution with residual tolerances of 1e-5 for p, U, k, and omega.

Set relaxation factors to 0.3 for p, 0.7 for U, k, and omega in fvSolution.

Run the simulation for 1000 iterations or until all residuals drop below 1e-5.

Set the writeInterval to 100 in controlDict.

Set deltaT to 1 and endTime to 1000 in controlDict, consistent with steady-state SIMPLE iteration control.
