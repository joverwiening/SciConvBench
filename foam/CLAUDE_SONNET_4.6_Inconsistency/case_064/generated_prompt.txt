The simulation is a 2D partitioned FSI case (one cell thick in z, frontAndBack patches set to empty).

The channel is 1.0 m long and 0.2 m tall.

The fluid domain occupies the full channel volume excluding the solid flap region.

The solid flap is 0.05 m tall (in y), 0.005 m thick (in x), and is attached to the bottom wall with its base centered at x = 0.4 m.

Use solids4foam as the coupling framework, employing its built-in partitioned FSI solver to manage both the fluid and solid regions and their interface exchange without requiring preCICE.

The fluid region is solved with pimpleFoam (incompressible, transient).

The solid region is solved with solidDisplacementFoam (linear elastic, transient).

At each time step, the interface coupling exchanges traction (from fluid to solid) and displacement (from solid to fluid) in a two-way iterative loop until convergence before advancing to the next time step.

The fluid is incompressible water with kinematic viscosity nu = 1e-6 m^2/s.

The fluid inlet boundary condition is fixedValue with U = (1 0 0) m/s.

The fluid outlet boundary condition is fixedValue with p = 0 Pa.

The top and bottom channel walls (excluding the flap base footprint) use noSlip for velocity and zeroGradient for pressure.

The fluid mesh deforms using dynamic mesh motion (e.g., displacementLaplacian) to accommodate flap deflection, with the fluid-side interface patch following the solid displacement.

The solid flap material is linear elastic with Young's modulus E = 1e6 Pa, Poisson's ratio nu = 0.45, and density rho = 1200 kg/m^3.

The flap base patch (bottom edge, attached to the channel floor) has a fixedDisplacement boundary condition set to zero (clamped).

The flap surface patches that contact the fluid are designated as the FSI interface and receive traction from the fluid and return displacement to the fluid mesh mover.

The flap tip (top edge) is a free surface with zero traction.

The frontAndBack patches in both fluid and solid regions are set to empty to enforce the 2D assumption.

Use a structured quad mesh for the fluid channel and a structured quad mesh for the solid flap, with the interface patch nodes matching in position to avoid interpolation error.

Recommended mesh resolution: approximately 200 cells in x and 40 cells in y for the fluid domain, and 10 cells in x (through thickness) and 50 cells in y (along flap height) for the solid domain.

Use a time step of dt = 1e-4 s and run the simulation to t = 2.0 s to allow the flap to reach a statistically steady deflected state.

Set the maximum Courant number to 0.5 for the fluid solver.

Use a fixed-point (Gauss-Seidel) FSI coupling loop per time step with a convergence tolerance of 1e-6 on interface displacement and a maximum of 50 FSI iterations per time step.

Apply Aitken adaptive under-relaxation on the displacement field at the FSI interface to stabilise the coupling iterations.

Write output every 0.05 s for both fluid and solid fields.

Monitor flap tip displacement in x and y as a time series output for validation.
