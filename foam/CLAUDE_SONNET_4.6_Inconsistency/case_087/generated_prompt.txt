Use rhoPimpleFoam as the solver for a transient, compressible, turbulent, heat-transfer simulation of flow over a 2D cylinder.

The domain is two-dimensional. Model the cylinder as a circle. The spanwise direction uses an empty boundary condition to enforce 2D behaviour.

The fluid is air modelled as a perfect gas.

Define the thermophysical model in constant/thermophysicalProperties as follows.

Set thermoType/type to hePsiThermo.
Set thermoType/mixture to pureMixture.
Set thermoType/transport to sutherland.
Set thermoType/thermo to janaf.
Set thermoType/equationOfState to perfectGas.
Set thermoType/specie to specie.
Set thermoType/energy to sensibleEnthalpy.

Under mixture/specie, set molWeight to 28.9.
Under mixture/thermodynamics, set Cp to 1005 J/(kg·K) and Hf to 0.
Under mixture/transport, set As to 1.458e-06 and Ts to 110.4 using the Sutherland viscosity law.
Do not include any BoussinesqCoeffs block anywhere in the file.

Set the freestream velocity to 10 m/s in the x-direction.
Set the freestream static temperature to 300 K.
Set the freestream static pressure to 101325 Pa.
Compute the freestream density from the perfect gas law using these values, which gives approximately 1.177 kg/m³.

Apply a constant wall temperature of 500 K on the cylinder surface using a fixedValue boundary condition for T.
Apply a no-slip condition on the cylinder surface for U.
Apply a zeroGradient condition on the cylinder surface for p.

Use the k-omega SST turbulence model.
Set the turbulence model in constant/turbulenceProperties with simulationType set to RAS and model set to kOmegaSST.
Estimate freestream turbulence intensity at 1 percent and a turbulent length scale appropriate for the cylinder diameter to initialise k and omega at the inlet.

Use PIMPLE algorithm settings in system/fvSolution. Set nOuterCorrectors to at least 2, nCorrectors to 1, and nNonOrthogonalCorrectors to 1.

In system/fvSchemes, use Euler for ddtSchemes. Use Gauss linearUpwind or Gauss linear for divSchemes appropriate for compressible flow. Use Gauss linear corrected for laplacianSchemes.

Set the time step such that the maximum Courant number stays below 0.5. Use adjustTimeStep yes in system/controlDict with maxCo 0.5.

Write results at regular intervals sufficient to resolve the vortex shedding cycle if it develops.

Do not include gravity or buoyancy source terms. The density variation due to temperature is handled entirely by the compressible equation of state and the continuity equation.
