The simulation is a 2D Rayleigh-Benard convection cell using OpenFOAM's buoyantFoam solver.

The domain is a rectangular cavity 9 units wide, 1 unit tall, and 1 cell deep in the spanwise (z) direction.
The mesh has 90 cells in x, 10 cells in y, and 1 cell in z.
The front and back patches are treated as empty or cyclic-type walls to enforce 2D behavior; use the "empty" type for front and back in the mesh and boundary conditions since this is a 2D case extruded one cell.

Use the buoyantFoam solver.
Gravity acts in the negative y direction: g = (0 -9.81 0) m/s^2.

Create constant/physicalProperties using heRhoThermo thermodynamic model.
Set thermoType: type heRhoThermo, mixture pureMixture, transport const, thermo hConst, equationOfState Boussinesq, specie specie, energy sensibleEnthalpy.
Set specie: molWeight 29.
Set equationOfState: rho0 1.0, T0 300, beta 3.3e-3.
Set thermodynamics: Cv 714.3, Hf 0.
Set transport: mu 1.5e-5, Pr 0.714.

Create constant/momentumTransport with simulationType RAS.
Set RAS model to kEpsilon, turbulence on, printCoeffs on.
Do not use laminar anywhere.

Create constant/g with value (0 -9.81 0) m/s^2.

Create the blockMeshDict to produce the described mesh with patches: bottom (wall), top (wall), left (wall), right (wall), front (empty), back (empty).

In 0/U set internalField uniform (0 0 0).
Set noSlip on bottom, top, left, and right patches.
Set empty on front and back patches.

In 0/T set internalField uniform 300.
Set fixedValue uniform 305 on the bottom patch.
Set fixedValue uniform 295 on the top patch.
Set zeroGradient on left and right patches.
Set empty on front and back patches.

In 0/p set internalField uniform 0.
Set calculated on bottom, top, left, and right patches.
Set empty on front and back patches.

In 0/p_rgh set internalField uniform 0.
Set fixedFluxPressure with value uniform 0 on bottom, top, left, and right patches.
Set empty on front and back patches.

In 0/k set internalField uniform 1e-5.
Set kqRWallFunction with value uniform 1e-5 on bottom, top, left, and right patches.
Set empty on front and back patches.

In 0/epsilon set internalField uniform 1e-5.
Set epsilonWallFunction with value uniform 1e-5 on bottom, top, left, and right patches.
Set empty on front and back patches.

In 0/nut set internalField uniform 0.
Set nutkWallFunction with value uniform 0 on bottom, top, left, and right patches.
Set empty on front and back patches.

In 0/alphat set internalField uniform 0.
Set compressible::alphatJayatillekeWallFunction with Prt 0.85 and value uniform 0 on bottom, top, left, and right patches.
Set empty on front and back patches.

In system/controlDict set application buoyantFoam.
Set startFrom startTime, startTime 0.
Set stopAt endTime, endTime 1000.
Set deltaT 1.
Set adjustTimeStep no.
Do not set maxCo or maxDeltaT.
Set writeControl timeStep, writeInterval 50.
Set purgeWrite 0, writeFormat ascii, writePrecision 8.

In system/fvSolution configure the PIMPLE block with nOuterCorrectors 2, nCorrectors 2, nNonOrthogonalCorrectors 1.
This uses PIMPLE mode with 2 outer loops, which is a best-practice balance between stability and cost for buoyancy-driven flows.

In system/fvSolution set the p_rgh solver to use GAMG with smoother GaussSeidel, tolerance 1e-8, relTol 0.01.
Set the p_rghFinal solver the same but with relTol 0.
Set solvers for U, e, k, and epsilon to use PBiCGStab with preconditioner DILU, tolerance 1e-8, relTol 0.01.
Set the corresponding Final solvers (UFinal, eFinal, kFinal, epsilonFinal) the same but with relTol 0.

In system/fvSchemes set ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear.
Set divSchemes: div(phi,U) Gauss linearUpwind grad(U), div(phi,e) Gauss linearUpwind grad(e), div(phi,k) Gauss upwind, div(phi,epsilon) Gauss upwind, div(((rho*nuEff)*dev2(T(grad(U))))) Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.
Set fluxRequired fields: p_rgh, p, e, U.
