Set up a 2D, steady-state, incompressible, turbulent simulation of airflow over a NACA0012 airfoil at a 5-degree angle of attack.

Use the simpleFoam solver.

Use the k-omega SST turbulence model.

The domain is a C-grid type, one cell thick in the z-direction.

The mesh is defined in constant/polyMesh.

The boundary patches are inlet, outlet, airfoil, and frontAndBack.

Compute turbulent kinetic energy k from: k = 1.5 * (U * TI)^2, where U = 10 m/s and TI = 0.01 (1%), giving k = 0.0015 m^2/s^2.

Compute specific dissipation rate omega from: omega = rho * k / (mu * viscosity_ratio), using viscosity ratio = 10 and kinematic viscosity nu = 1.5e-5 m^2/s (standard air), giving omega = k / (nu * 10) = 10.0 s^-1.

For the inlet patch, set U to fixedValue uniform (10 0 0).

For the inlet patch, set p to zeroGradient.

For the inlet patch, set k to fixedValue uniform 0.0015.

For the inlet patch, set omega to fixedValue uniform 10.0.

For the outlet patch, set U to inletOutlet with inletValue uniform (0 0 0) and value uniform (10 0 0).

For the outlet patch, set p to fixedValue uniform 0.

For the outlet patch, set k to inletOutlet with inletValue uniform 0.0015 and value uniform 0.0015.

For the outlet patch, set omega to inletOutlet with inletValue uniform 10.0 and value uniform 10.0.

For the airfoil patch, set U to noSlip.

For the airfoil patch, set p to zeroGradient.

For the airfoil patch, set k to kqRWallFunction with value uniform 0.0015.

For the airfoil patch, set omega to omegaWallFunction with value uniform 10.0.

For the frontAndBack patch, set the type to empty in constant/polyMesh/boundary.

For the frontAndBack patch, set U, p, k, and omega all to type empty in their respective field files.

In constant/polyMesh/boundary, set inlet type to patch, outlet type to patch, airfoil type to wall, and frontAndBack type to empty.

In constant/turbulenceProperties, set simulationType to RAS, model to kOmegaSST, and turbulence to on.

In constant/transportProperties, set the kinematic viscosity nu to 1.5e-5 m^2/s.

In system/fvSchemes, use Gauss linear for gradient schemes, Gauss linearUpwind grad(U) for the divergence of U, Gauss linear corrected for Laplacian schemes, and linear interpolation.

In system/fvSolution, configure the simpleFoam SIMPLE algorithm with nNonOrthogonalCorrectors 1, and set residual tolerances for U, p, k, and omega to 1e-6.

In system/controlDict, set application to simpleFoam, startFrom to startTime with startTime 0, stopAt to endTime, endTime to 1000, deltaT to 1, and writeInterval to 100.
