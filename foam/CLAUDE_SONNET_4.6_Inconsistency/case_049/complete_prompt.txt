Set up a 2D simulation of incompressible, laminar flow over an airfoil using `simpleFoam`. The mesh is extruded one cell in the z-direction. Use the patch name `frontAndBack` for the out-of-plane faces.

In `constant/polyMesh/boundary`, set:
```foam
frontAndBack
{
    type            empty;
    // ...
}
```

In `0/U`, set:
```foam
frontAndBack
{
    type            empty;
}
```
