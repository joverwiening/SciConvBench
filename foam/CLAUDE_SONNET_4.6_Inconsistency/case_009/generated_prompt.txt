Use the rhoCentralFoam solver for a compressible inviscid supersonic flow simulation over a 15-degree wedge obstacle.
Use the Kurganov flux scheme within rhoCentralFoam.
The domain is a 2D rectangular channel in the x-y plane, extruded from z=-0.005m to z=0.005m.
Set convertToMeters to 1 in blockMeshDict.
Define the mesh using two blocks as specified in the provided blockMeshDict.
Use the exact blockMeshDict content provided by the user, reproduced verbatim in the case directory under constant/polyMesh/blockMeshDict.
The first block spans x=-0.15242m to x=0m, y=0 to y=0.1524m, with 40x40x1 cells and simple grading of 1 1 1.
The second block spans x=0m to x=0.3048m, y=0 (rising to y=0.081670913853m at the bottom due to the wedge) to y=0.1524m, with 80x40x1 cells and simple grading of 1 1 1.
The wedge obstacle starts at x=0 on the bottom boundary and rises at 15 degrees, reaching y=0.081670913853m at x=0.3048m.
Define the following boundary patches in blockMeshDict: inlet (type patch), outlet (type patch), bottom (type symmetryPlane), top (type symmetryPlane), obstacle (type patch), and defaultFaces (type empty).
The inlet patch covers the left face of the first block: faces (0 6 9 3).
The outlet patch covers the right face of the second block: faces (2 5 11 8).
The bottom patch covers the bottom face of the first block: faces (0 1 7 6).
The top patch covers the top faces of both blocks: faces (3 9 10 4) and (4 10 11 5).
The obstacle patch covers the bottom face of the second block (the wedge surface): faces (1 2 8 7).
The defaultPatch type is empty to enforce 2D simulation.
Set the inlet boundary condition for velocity (U) to fixedValue with value (5 0 0) m/s.
Set the inlet boundary condition for pressure (p) to fixedValue with value 1 Pa.
Set the inlet boundary condition for temperature (T) to fixedValue with value 1 K.
Set the outlet boundary conditions for U, p, and T all to zeroGradient.
Set the bottom and top boundary conditions for U, p, and T to symmetryPlane.
Set the obstacle boundary condition for U to slip.
Set the obstacle boundary conditions for p and T to zeroGradient.
Set the defaultFaces boundary condition to empty for U, p, and T.
Use the perfect gas equation of state (perfectGas) in thermophysical properties.
Set the molecular weight (molWeight) to 11640.3.
Set the specific heat at constant pressure (Cp) to 2.5 J/(kg·K).
Set the Prandtl number (Pr) to 1.
Enable Sutherland viscosity model with muRef = 1.7894e-5 Pa·s and TRef = 300 K.
Use the hePsiThermo thermo model with pureMixture, constTransport, sensibleEnthalpy, hConst, and perfectGas.
Set the simulation start time to 0 seconds and end time to 0.2 seconds in controlDict.
Use a fixed time step (deltaT) of 0.0001 seconds.
Set writeInterval to 0.02 seconds with writeControl set to runTime.
Set the application field in controlDict to rhoCentralFoam.
Use vanLeer reconstruction scheme for rho, U, and T in the fvSchemes file under the interpolationSchemes or fluxSchemes section as appropriate for rhoCentralFoam.
Use Euler scheme for time discretization (ddtSchemes default Euler).
Use Gauss linear scheme for gradient calculations (gradSchemes default Gauss linear).
Use Gauss linear corrected or Gauss linear for Laplacian schemes.
Set the flux scheme in rhoCentralFoam to Kurganov by setting fluxScheme to Kurganov in the constant/thermophysicalProperties or system/fvSolution as appropriate (set in constant/thermophysicalProperties under the solver settings or in fvSolution).
Initialize the flow field with uniform conditions: U = (5 0 0) m/s, p = 1 Pa, T = 1 K.
Run blockMesh to generate the mesh from the provided blockMeshDict before running the solver.
