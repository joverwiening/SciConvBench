The simulation is a 2D mixed convection lid-driven cavity using buoyantPimpleFoam in OpenFOAM.
The cavity is a unit square with dimensions 1 m (width) × 1 m (height) × 0.01 m (depth in Z, one cell thick for 2D).
The mesh resolution is 50 cells in X, 50 cells in Y, and 1 cell in Z, with uniform cell spacing.
The top lid (y = 1 m) moves in the positive X direction at 0.1 m/s and is held at a fixed temperature of 350 K.
The bottom wall (y = 0 m) is stationary and held at a fixed temperature of 300 K.
The left wall (x = 0 m) and right wall (x = 1 m) are stationary and adiabatic (zero gradient for temperature).
The front and back patches are set to empty boundary condition for 2D treatment.
Gravity is defined as (0, -9.81, 0) m/s² in constant/g.
The fluid is air with molecular weight 28.9 kg/kmol, Cp 1005 J/(kg·K), dynamic viscosity mu 1.8e-5 Pa·s, and Prandtl number 0.7.
The thermal conductivity is derived from mu and Pr as lambda = mu × Cp / Pr.
The thermoType block in constant/thermophysicalProperties uses type hePsiThermo, mixture pureMixture, transport const, thermo hConst, equationOfState perfectGas, specie specie, and energy sensibleEnthalpy.
The equationOfState is perfectGas, which provides the incompressiblePerfectGas-like density variation rho = p/(R×T) where R = Runi/molWeight.
The BoussinesqCoeffs block is included inside the mixture subdictionary with TRef 325 K and beta 0.00307 1/K as a backup buoyancy reference.
The Hf (heat of formation) is set to 0 J/kg.
The operating pressure p_rgh reference value is set to 0 Pa at a reference point, and the absolute pressure p is reconstructed from p_rgh + rho×g×h.
The initial conditions are: U = (0, 0, 0) m/s everywhere, T = 325 K everywhere (midpoint between hot and cold), p_rgh = 0 Pa everywhere.
The boundary condition for p_rgh on all walls is fixedFluxPressure.
The boundary condition for p_rgh on the top and bottom walls is fixedFluxPressure with value 0.
The PIMPLE algorithm is used with nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1.
The time step is set to 0.001 s with a maximum Courant number of 0.5.
The simulation runs for a total time of 100 s to allow steady-state development, with results written every 10 s.
The turbulence model is set to laminar in constant/turbulenceProperties, as the flow is expected to be laminar at these conditions.

The fvSolution uses GAMG solver for p_rgh with tolerance 1e-7 and relTol 0.01, and smoothSolver with symGaussSeidel for U and T with tolerance 1e-8 and relTol 0.1.
