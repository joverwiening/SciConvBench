Set up a classic 2D dam-break problem in OpenFOAM using the interFoam solver.

Use a 2D rectangular domain meshed with blockMesh, extruded one cell in the z-direction.

Set the front and back boundary patches to type empty in the mesh and all field files to enforce 2D behavior.

In system/controlDict, set application to interFoam.

Use the VOF phase field alpha.water to represent the water phase, where alpha.water = 1 is pure water and alpha.water = 0 is pure air.

Define the initial water column as a rectangular region on one side of the domain using system/setFieldsDict.

In system/setFieldsDict, set the defaultFieldValues to alpha.water = 0 for the entire domain, then use a boxToCell topoSetSource to select the cells inside the water column region and set alpha.water = 1 there.

Run setFields before interFoam to initialize the alpha.water field.

Define two phases in constant/transportProperties: water and air, each with their respective kinematic viscosity (nu) and density (rho).

Set the surface tension coefficient (sigma) between water and air in constant/transportProperties.

Enable gravity by setting the gravitational acceleration vector in constant/g to point in the negative y-direction with magnitude 9.81 m/s^2.

In the 0/ directory, provide initial and boundary condition files for alpha.water, U, p_rgh, and p.

Set initial velocity U to zero everywhere.

Set p_rgh to zero gradient at all walls and at the top (atmosphere) boundary use a totalPressure or fixedValue condition as appropriate.

Use a Gauss linearUpwind or MULES-based scheme for alpha.water advection as configured in system/fvSchemes.

Set the simulation end time, write interval, and time step (or maximum Courant number for adjustable time stepping) in system/controlDict.

Use adjustable time stepping with maxCo set to 0.5 to maintain numerical stability.
