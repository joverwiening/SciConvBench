Set up a 2D, incompressible, steady-state simulation of airflow over a symmetric airfoil using the simpleFoam solver in OpenFOAM.

Use a NACA 0012 airfoil profile with a chord length of 1 m and an angle of attack of 5 degrees, which is a standard low-angle attached-flow case for validation.

Use the k-omega SST turbulence model, as it is the industry best-practice model for external aerodynamic flows with adverse pressure gradients.

The domain uses a C-grid topology. Extend the domain 15 chord lengths upstream and radially from the airfoil leading edge, and 20 chord lengths downstream from the trailing edge. These dimensions minimize blockage and boundary interference effects.

The mesh is one cell thick in the z-direction (a single layer of cells with unit thickness of 0.1 m in z).

In `system/blockMeshDict`, define the `frontAndBack` patch with `type empty`.

In `0/U`, set the inlet to `type fixedValue; value uniform (10 0 0);` corresponding to a freestream velocity of 10 m/s aligned with the x-axis before rotation for angle of attack.

In `0/U`, set the outlet to `type zeroGradient`.

In `0/U`, set the airfoil surface to `type noSlip`.

In `0/U`, set the `frontAndBack` patches to `type empty`.

In `0/p`, set the inlet to `type zeroGradient`.

In `0/p`, set the outlet to `type fixedValue; value uniform 0;`.

In `0/p`, set the airfoil surface to `type zeroGradient`.

In `0/p`, set the `frontAndBack` patches to `type empty`.

For the k-omega SST model, create a `0/k` file with `type fixedValue; value uniform 0.00015;` at the inlet (based on 1% turbulence intensity at 10 m/s), `zeroGradient` at the outlet, `kqRWallFunction` on the airfoil wall, and `empty` on `frontAndBack`.

For the k-omega SST model, create a `0/omega` file with `type fixedValue; value uniform 2.0;` at the inlet, `zeroGradient` at the outlet, `omegaWallFunction` on the airfoil wall, and `empty` on `frontAndBack`.

In `constant/turbulenceProperties`, set `simulationType RAS` and `RASModel kOmegaSST`.

In `constant/transportProperties`, set kinematic viscosity `nu` to `1.5e-05` m^2/s, giving a chord Reynolds number of approximately 667,000.

In `system/fvSchemes`, use `Gauss linear` for gradient schemes, `Gauss linearUpwind grad(U)` for the divergence of U, `Gauss linear corrected` for Laplacian schemes, and `linear` for interpolation schemes.

In `system/fvSolution`, use the SIMPLE algorithm with `nNonOrthogonalCorrectors 1`. Set under-relaxation factors of 0.7 for U, 0.3 for p, and 0.5 for k and omega.

Run the simulation for 2000 steady-state iterations or until all residuals drop below 1e-5.

Apply a structured boundary layer mesh on the airfoil surface with a first cell height of approximately 1e-5 m to achieve y+ near 1, suitable for the k-omega SST model in low-Reynolds-number (resolved wall) mode. Use at least 30 layers in the boundary layer region with an expansion ratio of 1.2.
