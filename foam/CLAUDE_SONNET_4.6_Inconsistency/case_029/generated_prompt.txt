Simulate the transient von Kármán vortex street for 2D flow past a circular cylinder at Reynolds number Re = 150 using OpenFOAM.

Use pimpleFoam as the transient incompressible solver.

In system/controlDict, set application to pimpleFoam.

Set startFrom to startTime with startTime 0.

Set stopAt to endTime with endTime 200.

Set deltaT to 0.005 as the initial time step.

Set adjustTimeStep to yes with maxCo 0.9 so the solver adjusts the time step to maintain a Courant number below 0.9.

Set writeControl to runTime and writeInterval to 1 so results are written every 1 second of simulation time.

Create a 2D rectangular domain with the cylinder centered in the domain; use a domain extent of approximately 20 diameters upstream, 40 diameters downstream, and 20 diameters in the cross-stream direction to minimize blockage and outlet effects.

Set the cylinder diameter D = 1 m and the inlet velocity U = 1 m/s.

Set the kinematic viscosity nu = U * D / Re = 1/150 so that Re = 150.

Apply a uniform inlet velocity boundary condition U = (1 0 0) m/s on the inlet patch.

Apply a zero-gradient outlet boundary condition for U and a fixed-value zero pressure condition on the outlet patch.

Apply a no-slip boundary condition on the cylinder wall.

Apply symmetry or slip boundary conditions on the top and bottom patches.

Apply empty boundary conditions on the front and back patches to enforce 2D flow.

Use a structured or unstructured mesh with sufficient refinement around the cylinder surface and in the wake region to resolve the boundary layer and vortex shedding; target a minimum cell size of approximately 0.02D near the cylinder wall.

Set the empty direction (z-direction) to one cell thick to enforce 2D simulation.

In system/fvSchemes, use a second-order time scheme (Euler or CrankNicolson with blending coefficient 0.9) and second-order spatial schemes (linear or linearUpwind) for divergence terms.

In system/fvSolution, configure the PIMPLE algorithm with at least 2 outer corrector loops (nOuterCorrectors 2) and 2 inner pressure corrector loops (nCorrectors 2).

Run the simulation for the full endTime of 200 time units to allow the initial transient to decay and capture multiple shedding cycles.

Post-process the results to extract the lift coefficient (Cy) on the cylinder as a function of time to confirm periodic vortex shedding and compute the Strouhal number St = f * D / U, which should be approximately 0.18 for Re = 150.
