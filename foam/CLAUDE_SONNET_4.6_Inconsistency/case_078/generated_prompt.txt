Set up a steady-state OpenFOAM simulation of buoyancy-driven airflow in a ventilated room using the solver buoyantSimpleFoam.

Assume a rectangular room of dimensions 5 m (length) x 3 m (width) x 2.5 m (height).
Place the inlet patch as a 0.5 m x 0.5 m opening centered on the lower portion of one of the 3 m x 2.5 m end walls, with its center at 0.5 m height from the floor.
Place the outlet patch as a 0.5 m x 0.5 m opening centered on the upper portion of the opposite 3 m x 2.5 m end wall, with its center at 2.0 m height from the floor.
Place the heater patch on the floor of the room, occupying a 1 m x 1 m area centered in the middle of the floor.
All remaining surfaces (remaining floor area, ceiling, side walls) are treated as no-slip, adiabatic walls.

Create the mesh using blockMesh with a structured hexahedral grid.
Divide the domain into 50 x 30 x 25 cells in the x, y, and z directions respectively.
Define all patches in blockMeshDict: inlet, outlet, heater, and walls.

In constant/thermophysicalProperties, set thermoType to heRhoThermo.
Set the equation of state to Boussinesq with T0 293, beta 0.00341, and rho0 1.2.
Set the transport model to const with mu 1.8e-5 and Pr 0.71.
Set the thermodynamics type to hConst with Cp 1005 and Hf 0.
Set the mixture to pureMixture with a molecular weight of 28.9 g/mol.

In constant/turbulenceProperties, set the simulation to laminar flow, as natural convection at this scale may remain in the laminar regime.

In constant/g, set gravitational acceleration to (0 0 -9.81) m/s^2.

In 0/T, set the inlet patch to fixedValue uniform 293 K.
Set the heater patch to fixedValue uniform 320 K.
Set the outlet patch to zeroGradient.
Set all other wall patches to zeroGradient.
Set the internal field to uniform 293 K.

In 0/U, set the inlet patch to fixedValue uniform (0.5 0 0) m/s, representing a low-velocity supply of 0.5 m/s in the x-direction.
Set the outlet patch to zeroGradient.
Set all wall patches including the heater to noSlip.
Set the internal field to uniform (0 0 0) m/s.

In 0/p_rgh, set the inlet patch to zeroGradient.
Set the outlet patch to fixedValue uniform 0 Pa.
Set all wall patches to fixedFluxPressure.
Set the internal field to uniform 0 Pa.

In system/fvSolution, use SIMPLE algorithm settings.
Set the number of non-orthogonal correctors to 1.
Use smoothSolver with symGaussSeidel smoother for U and T.
Use GAMG solver for p_rgh.
Set residual tolerances to 1e-6 for all fields.
Set relaxation factors to 0.7 for U, 0.7 for T, and 0.3 for p_rgh.

In system/fvSchemes, use steadyState for ddtSchemes.
Use Gauss linear for gradSchemes.
Use Gauss linearUpwind grad(U) for the divergence of U.
Use Gauss linearUpwind grad(T) for the divergence of T.
Use Gauss linear corrected for laplacianSchemes.

In system/controlDict, set the application to buoyantSimpleFoam.
Set startFrom to startTime with startTime 0.
Set stopAt to endTime with endTime 1000.
Set deltaT to 1.
Set writeControl to timeStep with writeInterval 100.
