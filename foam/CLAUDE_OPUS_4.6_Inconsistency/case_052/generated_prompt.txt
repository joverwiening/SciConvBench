The simulation is a 2D lid-driven cavity using the nonNewtonianIcoFoam solver in OpenFOAM.

The domain is a 1m x 1m square cavity.
The mesh is one cell thick in the z-direction (e.g., from z=0 to z=0.1).
The mesh resolution is 50 cells in the x-direction and 50 cells in the y-direction, with 1 cell in the z-direction.
The mesh is generated using blockMesh with a single block and uniform grading.

The solver is nonNewtonianIcoFoam.
The simulation is transient.

The time step deltaT is 0.005 s.
The end time is 10 s.
The write interval is 0.5 s.

The constant/transportProperties file defines the following:
transportModel PowerLaw;
PowerLawCoeffs with nuMax 1 (dimensions 0 2 -1 0 0 0 0), nuMin 1e-6 (dimensions 0 2 -1 0 0 0 0), k 0.1 (dimensions 0 2 -1 0 0 0 0), and n 0.5 (dimensions 0 0 0 0 0 0 0).

The velocity boundary conditions are as follows:
The top wall (lid) has a fixedValue of (1 0 0) m/s.
The bottom wall has a noSlip condition (fixedValue of (0 0 0)).
The left wall has a noSlip condition (fixedValue of (0 0 0)).
The right wall has a noSlip condition (fixedValue of (0 0 0)).
The front and back patches use the empty boundary condition type.
The initial internal field for velocity is uniform (0 0 0).

The pressure boundary conditions are as follows:
The top wall uses zeroGradient.
The bottom wall uses fixedValue of 0.
The left wall uses zeroGradient.
The right wall uses zeroGradient.
The front and back patches use the empty boundary condition type.
The initial internal field for pressure is uniform 0.

The fvSchemes file uses Euler for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for divSchemes (div(phi,U)), Gauss linear corrected for laplacianSchemes, and linear for interpolationSchemes, with corrected for snGradSchemes.

The fvSolution file uses PISO with nCorrectors set to 2 and nNonOrthogonalCorrectors set to 0.
The p solver uses PCG with DIC preconditioner, tolerance 1e-06, and relTol 0.
The U solver uses PBiCGStab with DILU preconditioner, tolerance 1e-06, and relTol 0.
