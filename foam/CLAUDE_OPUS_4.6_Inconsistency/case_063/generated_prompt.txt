Simulate the transient von Kármán vortex street behind a cylinder in a 2D channel using OpenFOAM with the pimpleFoam solver.

The domain is a 2D rectangular channel 2.2 m long and 0.41 m high.
A cylinder of diameter 0.1 m is placed at coordinates (0.2, 0.2) which is slightly off-center vertically in the channel.
The mesh is 2D, extruded one cell in the z-direction, with frontAndBack patches set to the empty type.

The Reynolds number is approximately 10 based on U=0.1 m/s, D=0.1 m, and nu=1e-3 m^2/s.
The kinematic viscosity is set to nu = 1e-3 m^2/s in constant/transportProperties using the Newtonian transport model.

Boundary conditions for 0/U are as follows.
Inlet is fixedValue uniform (0.1 0 0).
Outlet is zeroGradient.
Cylinder is noSlip.
Top and bottom walls are slip.
frontAndBack is empty.

Boundary conditions for 0/p are as follows.
Inlet is zeroGradient.
Outlet is fixedValue uniform 0.
Cylinder is zeroGradient.
Top and bottom walls are zeroGradient.
frontAndBack is empty.

In system/controlDict, set application to pimpleFoam.
Set deltaT to 0.005 s.
Set endTime to 50 s to allow full development of vortex shedding.
Set writeInterval to 0.5 s (every 100 time steps).
Set writeFormat to ascii.
Set writeCompression to uncompressed.
Set timeFormat to general.
Set timePrecision to 6.
Set runTimeModifiable to true.

The mesh is generated using blockMesh with an O-grid or structured approach around the cylinder.
Use approximately 200 cells along the channel length, 60 cells across the channel height, and approximately 64 cells around the cylinder circumference.
Apply mesh grading near the cylinder wall to resolve the boundary layer, with a first cell height yielding adequate near-wall resolution for this low-Re flow.
The mesh is one cell deep in z with a thickness of 0.01 m.

In system/fvSchemes, use the following.
ddtSchemes default is Euler (first-order implicit time integration).
gradSchemes default is Gauss linear.
divSchemes div(phi,U) is Gauss linearUpwind grad(U).
divSchemes div((nuEff*dev2(T(grad(U))))) is Gauss linear.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.

In system/fvSolution, use the following.
The pressure solver is GAMG with a GaussSeidel smoother, tolerance 1e-6, and relTol 0.01.
The velocity solver is smoothSolver with a GaussSeidel smoother, tolerance 1e-7, and relTol 0.01.
Under the PIMPLE dictionary, set nOuterCorrectors to 2, nCorrectors to 2, and nNonOrthogonalCorrectors to 1.

The turbulence model is laminar, set in constant/turbulenceProperties with simulationType as laminar.
