The simulation is a 2D natural convection problem in a tall sealed cavity using OpenFOAM.

Use the buoyantBoussinesqSimpleFoam solver.

The cavity has a height of 0.8 m and a width of 0.1 m, giving an aspect ratio of 8:1.

The geometry is 2D, so the depth direction (z) uses a single cell layer with empty boundary conditions on the front and back patches.

Gravity acts in the negative y-direction with a value of (0, -9.81, 0) m/s^2.

The fluid is air with the following properties: kinematic viscosity nu = 1.568e-5 m^2/s, thermal expansion coefficient beta = 3.077e-3 1/K (calculated as 1/T_ref where T_ref = 325 K), Prandtl number Pr = 0.71, reference temperature T_ref = 325 K, and laminar transport properties corresponding to air at 325 K.

The flow is assumed to be laminar. The turbulence model is set to laminar in the momentumTransport or turbulenceProperties dictionary.

The mesh resolution is 30 cells in the x-direction and 240 cells in the y-direction, giving uniform cells with an aspect ratio close to 1.

Boundary conditions for temperature T are as follows.
leftWall: type fixedValue, value uniform 350.
rightWall: type fixedValue, value uniform 300.
topWall: type zeroGradient.
bottomWall: type zeroGradient.

Boundary conditions for velocity U are as follows.
leftWall: type noSlip.
rightWall: type noSlip.
topWall: type noSlip.
bottomWall: type noSlip.

Boundary conditions for pressure p_rgh are as follows.
leftWall: type fixedFluxPressure, value uniform 0.
rightWall: type fixedFluxPressure, value uniform 0.
topWall: type fixedFluxPressure, value uniform 0.
bottomWall: type fixedFluxPressure, value uniform 0.

The front and back patches use the empty boundary condition type for all fields.

Initial conditions are as follows.
T is initialized to a uniform value of 325 K.
U is initialized to a uniform value of (0, 0, 0) m/s.
p_rgh is initialized to a uniform value of 0.

The SIMPLE algorithm convergence residual tolerances are 1e-6 for p_rgh, 1e-6 for U, and 1e-6 for T.

The number of SIMPLE iterations (outer loops) is set to 5000 to allow the steady-state solution to converge.

Under-relaxation factors are 0.3 for p_rgh, 0.7 for U, and 0.7 for T.

The fvSchemes use second-order discretization: Gauss linear for gradient schemes, Gauss linearUpwind for divergence schemes, and Gauss linear corrected for Laplacian schemes.

The fvSolution uses GAMG solver for p_rgh and smoothSolver (with GaussSeidel smoother) for U and T.
