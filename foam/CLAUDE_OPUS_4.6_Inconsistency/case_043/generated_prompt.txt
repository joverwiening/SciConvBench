The simulation uses the buoyantPimpleFoam solver in OpenFOAM to model laminar, buoyancy-driven heat transfer of air flowing over a heated block in a 2D channel.

The channel is 0.5 m long and 0.1 m tall.
The heated block is a square with side length 0.02 m, centered at (0.15 m, 0.05 m) within the channel.
The simulation is 2D, achieved by using a single-cell thickness in the z-direction with empty boundary conditions on the front and back patches.

The fluid is air with properties evaluated near 300 K (density computed via the ideal gas law, kinematic viscosity approximately 1.5e-5 m^2/s, thermal conductivity approximately 0.026 W/(m·K), specific heat Cp approximately 1005 J/(kg·K), Prandtl number approximately 0.71, and thermal expansion coefficient approximately 0.0033 1/K).

The operating pressure is 101325 Pa.

The inlet velocity is fixed at 0.1 m/s in the x-direction (uniform), giving a Reynolds number of approximately 670 based on channel height, ensuring laminar flow.

The 0/T file boundary conditions are as follows.
inlet: type fixedValue; value uniform 300.
outlet: type zeroGradient.
block: type fixedValue; value uniform 400.
walls: type zeroGradient.

The 0/U file boundary conditions are as follows.
inlet: type fixedValue; value uniform (0.1 0 0).
outlet: type zeroGradient.
block: type noSlip.
walls: type noSlip.

The 0/p_rgh file boundary conditions are as follows.
inlet: type zeroGradient.
outlet: type fixedValue; value uniform 0.
block: type zeroGradient.
walls: type zeroGradient.

The 0/p file boundary conditions are as follows.
inlet: type calculated; value uniform 101325.
outlet: type calculated; value uniform 101325.
block: type calculated; value uniform 101325.
walls: type calculated; value uniform 101325.

The thermophysical model uses the Boussinesq approximation or ideal gas equation of state as appropriate for buoyantPimpleFoam, with hePsiThermo or heRhoThermo and a pureMixture of air.

The turbulence model is set to laminar in the constant/momentumTransport (or turbulenceProperties) file.

The gravity vector is (0, -9.81, 0) m/s^2, specified in the constant/g file.

The simulation end time is 5 seconds.
The time step is 0.001 seconds with a maximum Courant number of 0.5 for adaptive time-stepping via adjustTimeStep.

The fvSchemes use second-order schemes: Gauss linearUpwind for divergence terms, Gauss linear corrected for Laplacian terms, and Euler for time discretization.

The fvSolution uses PIMPLE with 2 outer correctors and 1 non-orthogonal corrector. The pressure solver uses GAMG with a DIC preconditioner and tolerance of 1e-6. The velocity and temperature solvers use PBiCGStab with a DILU preconditioner and tolerance of 1e-7.

Write results every 0.1 seconds.
