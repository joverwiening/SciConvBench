The simulation uses rhoCentralFoam to solve compressible air flow through a 2D converging-diverging nozzle with a perfect gas equation of state.

Geometry of the nozzle:
The total nozzle length is 0.6 m, divided into a 0.2 m converging section, a short 0.02 m throat region, and a 0.38 m diverging section.
The inlet half-height is 0.05 m (full height 0.1 m).
The throat half-height is 0.025 m (full height 0.05 m).
The outlet half-height is 0.075 m (full height 0.15 m).
The nozzle area ratio (outlet area / throat area) is 3.0.
The nozzle contour is smooth, using a spline or arc profile to avoid abrupt geometry changes.
The domain is one cell thick in the z-direction (e.g., 0.001 m) for the 2D simulation.

Mesh:
The mesh is block-structured using blockMesh.
The approximate resolution is 300 cells along the length and 60 cells across the half-height, giving roughly 18000 cells total.
Grading is applied near the walls to resolve the boundary layer, with a cell expansion ratio of approximately 5 toward the wall.
Boundary patches are named inlet, outlet, nozzleWall, and frontAndBack.
The frontAndBack patch type is empty.

Thermophysical properties (constant/thermophysicalProperties):
The thermophysical model type is hePsiThermo.
The mixture is pureMixture.
The transport model is sutherland with As = 1.458e-06 and Ts = 110.4.
The thermodynamics model is hConst with Cp = 1005 J/(kg·K) and Hf = 0.
The equation of state is perfectGas.
The specie is air with molecular weight 28.97 g/mol.
The energy formulation is sensibleInternalEnergy.

Inlet boundary conditions:
The inlet total pressure is 300000 Pa applied using the totalPressure boundary condition.
The inlet total temperature is 600 K applied using the totalTemperature boundary condition.
The inlet velocity is set to pressureInletOutletVelocity.

Outlet boundary conditions:
The outlet static pressure is fixed at 101325 Pa using fixedValue.
The outlet temperature is set to zeroGradient.
The outlet velocity is set to zeroGradient.
If supersonic outflow develops, the outlet conditions are effectively overridden by the interior solution, which rhoCentralFoam handles via its Riemann-solver-based flux scheme.

Wall boundary conditions (nozzleWall):
The velocity is fixedValue with a value of (0 0 0) enforcing no-slip.
The pressure is zeroGradient.
The temperature is zeroGradient enforcing an adiabatic wall.

frontAndBack boundary conditions:
All fields use the empty type on the frontAndBack patch.

Numerical schemes (system/fvSchemes):
The time derivative scheme is Euler.
The gradient scheme is Gauss linear.
The divergence schemes use Gauss vanLeer for convective terms appropriate for compressible flow with shocks.
The Laplacian schemes are Gauss linear corrected.
The interpolation scheme is linear.
The surface normal gradient scheme is corrected.

Solution settings (system/fvSolution):
The solver for all fields is smoothSolver with smoother GaussSeidel.
The tolerance is 1e-06 and relTol is 0.

Control settings (system/controlDict):
The application is rhoCentralFoam.
The simulation is transient.
The start time is 0.
The end time is 0.005 s, which is sufficient for the flow to reach a quasi-steady state in this nozzle geometry.
The time step is 1e-07 s to maintain a Courant number below 0.5 for stability.
The write interval is 5e-04 s.
The adjustTimeStep option is off (fixed time step).
The maxCo is 0.5.

Initial conditions (time 0 directory):
The initial pressure is 101325 Pa throughout the domain.
The initial temperature is 300 K throughout the domain.
The initial velocity is (0 0 0) throughout the domain.

The simulation is expected to develop a converging subsonic region, sonic flow at the throat, and a supersonic region in the diverging section with a normal shock whose position depends on the pressure ratio between inlet stagnation pressure and outlet back pressure.
