The simulation uses the compressible transient solver buoyantPimpleFoam in OpenFOAM.
The domain is a 2D sealed room of dimensions 5 m (x) by 3 m (y).
The 2D setup is achieved by extruding one cell in the z-direction, with frontAndBack patches set to type empty.
The z-direction extrusion thickness is 0.1 m (from z = 0 to z = 0.1).
The mesh resolution is 100 cells in the x-direction and 60 cells in the y-direction (uniform spacing, dx = dy = 0.05 m).
A single cell is used in the z-direction.
Use blockMesh to generate the mesh.

A 0.5 m x 0.5 m hot block region is centered in the room, spanning from (2.25, 1.25, 0) to (2.75, 1.75, 0.1).
The hot block is a fluid region (air), not a solid. It is initialized to 400 K using setFields (with a boxToCell source).
The surrounding air is initialized to 300 K.

Gravity is set to (0 -9.81 0) in constant/g.

The thermophysical properties in constant/thermophysicalProperties use the following thermoType:
type hePsiThermo;
mixture pureMixture;
transport sutherland;
thermo janaf;
equationOfState perfectGas;
specie specie;
energy sensibleEnthalpy.
The mixture coefficients are for air (molecular weight 28.96 kg/kmol, Sutherland coefficients As = 1.4792e-06, Ts = 116, JANAF coefficients for air valid over 200-6000 K range).

The initial and boundary conditions for pressure (p) use a uniform value of 101325 Pa.
The field p_rgh is initialized consistently (p_rgh = p - rho*g*h).
All walls use fixedFluxPressure for p_rgh.

The initial and boundary conditions for velocity (U) use a uniform value of (0 0 0).
All walls use noSlip for U.

The initial and boundary conditions for temperature (T) use a uniform value of 300 K, then setFields overrides the hot block region to 400 K.
All walls use zeroGradient for T (adiabatic walls).

The frontAndBack patch uses type empty for all fields.

The simulation end time is 300 s.
Adaptive time-stepping is enabled with maxCo = 0.5.
The initial time step (deltaT) is 0.01 s.
maxDeltaT is set to 1.0 s.

The time discretization uses backward (second-order implicit) for ddt schemes.
The divergence schemes use Gauss linearUpwind for velocity and Gauss upwind for energy/scalar fields.
The Laplacian schemes use Gauss linear corrected.
The interpolation schemes use linear.
The snGrad schemes use corrected.

The PIMPLE algorithm uses 2 outer correctors, 1 corrector, and 1 non-orthogonal corrector.
Turbulence is modeled as laminar (set in constant/momentumTransport or constant/turbulenceProperties with simulationType laminar).

Write results every 5 s (writeInterval 5, writeControl adjustableRunTime).
The run is serial (no domain decomposition required).
