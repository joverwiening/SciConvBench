Simulate natural convection in a 2D square cavity using the de Vahl Davis benchmark configuration in OpenFOAM.

The solver is buoyantBoussinesqPimpleFoam (transient).

The cavity is a square with side length L = 0.1 m.

The cavity is filled with air at a reference temperature of T_ref = 295 K.

Use the Boussinesq approximation for buoyancy.

Air properties at 295 K are as follows: kinematic viscosity nu = 1.516e-05 m^2/s, thermal expansion coefficient beta = 3.39e-03 1/K, Prandtl number Pr = 0.71, laminar thermal diffusivity (nu/Pr) approximately 2.135e-05 m^2/s.

Gravity acts in the negative y-direction: g = (0 -9.81 0) m/s^2.

The left wall (hot wall) has a fixed temperature T = 300 K.

The right wall (cold wall) has a fixed temperature T = 290 K.

The top and bottom walls are adiabatic, using zeroGradient for temperature.

All four walls use noSlip (fixedValue uniform (0 0 0)) for velocity.

Pressure uses fixedFluxPressure on all walls.

The mesh is a uniform 80x80 grid in 2D (single cell in the z-direction with empty front and back patches).

The domain extends from (0 0 0) to (0.1 0.1 0.005) with 80 cells in x, 80 cells in y, and 1 cell in z.

The front and back patches are of type empty to enforce a 2D simulation.

The simulation end time is 100 s.

The time step is 0.01 s.

The maximum Courant number is 0.5.

Write output data every 1 s (writeInterval = 1 s).

Turbulence modeling is set to laminar (no turbulence model) since the resulting Rayleigh number is approximately 7.1e+05, which is in the laminar regime.

Use fvSchemes appropriate for transient buoyant flow: Euler for time discretization, Gauss linear for gradient schemes, Gauss linear corrected for Laplacian schemes, and Gauss linearUpwind for divergence schemes.

The PIMPLE algorithm settings use 2 outer correctors, 1 corrector, and 1 non-orthogonal corrector.
