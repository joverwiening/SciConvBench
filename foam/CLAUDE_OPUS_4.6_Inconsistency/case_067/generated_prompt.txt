The simulation uses the simpleFoam solver for steady-state, laminar, incompressible flow over a 2D backward-facing step.

The geometry of the backward-facing step has a step height of 0.1 m, an expansion ratio of 2:1 (inlet channel height 0.1 m, downstream channel height 0.2 m), an upstream length of 0.3 m (3 step heights), and a downstream length of 2.0 m (20 step heights). The domain depth in the z-direction is one cell thick (e.g., 0.1 m) to represent a 2D simulation.

The mesh is generated using blockMesh with sufficient resolution to capture the laminar recirculation zone (e.g., approximately 20 cells per step height).

The 0/U file specifies the following boundary conditions:
inlet has type fixedValue with value uniform (0.5 0 0).
outlet has type zeroGradient.
stepWall has type noSlip.
topWall has type noSlip.
frontAndBack has type empty.

The 0/p file specifies the following boundary conditions:
inlet has type zeroGradient.
outlet has type fixedValue with value uniform 0.
stepWall has type zeroGradient.
topWall has type zeroGradient.
frontAndBack has type empty.

The transportProperties file uses the Newtonian transport model with kinematic viscosity nu equal to 1e-03 m^2/s.

The turbulenceProperties file specifies laminar simulation type (simulationType laminar).

The fvSchemes file uses the following:
ddtSchemes default is steadyState.
gradSchemes default is Gauss linear.
divSchemes div(phi,U) is bounded Gauss linearUpwind grad(U), and default is none.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.

The fvSolution file uses the following:
p is solved using GAMG with tolerance 1e-06, relTol 0.01, and smoother GaussSeidel.
U is solved using smoothSolver with smoother GaussSeidel, tolerance 1e-07, and relTol 0.1.
The SIMPLE algorithm is used with nNonOrthogonalCorrectors set to 0 and residualControl for p at 1e-04 and U at 1e-04.
Relaxation factors are 0.3 for p and 0.7 for U.

The controlDict file uses the following:
application is simpleFoam.
startFrom is startTime.
startTime is 0.
stopAt is endTime.
endTime is 1000.
deltaT is 1.
writeControl is timeStep.
writeInterval is 100.
purgeWrite is 0.
writeFormat is ascii.
writePrecision is 6.
writeCompression is off.
timeFormat is general.
timePrecision is 6.
runTimeModifiable is true.
