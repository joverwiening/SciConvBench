Use OpenFOAM's laplacianFoam solver to perform a 2D transient heat conduction simulation on a 1 m x 1 m square plate.

Generate the mesh using blockMesh with 50 cells in the x-direction and 50 cells in the y-direction, and 1 cell in the z-direction with a thickness of 0.01 m.

Define the following patches in the blockMeshDict: left (x = 0), right (x = 1), top (y = 1), bottom (y = 0), and frontAndBack (the two z-normal faces).

In constant/polyMesh/boundary, set the frontAndBack patch type to empty.

In the 0/T field file, set the frontAndBack patch type to empty.

Set the thermal diffusivity DT to 1e-5 m^2/s in constant/transportProperties.

Set the initial internal field temperature T to a uniform value of 300 K.

For the in-plane boundary conditions on T, use the following sensible demonstration setup: left face fixed at 400 K (fixedValue, uniform 400), right face fixed at 300 K (fixedValue, uniform 300), top face insulated (zeroGradient), bottom face insulated (zeroGradient).

Set the simulation end time to 10000 s.

Set the time step deltaT to 1 s.

Set the write interval to 500 s (writeControl set to timeStep, writeInterval set to 500).

Use Gauss linear for the Laplacian discretization scheme with explicit non-orthogonal correction (corrected).

Use PBiCGStab with DILU preconditioner as the linear solver for T, with tolerance 1e-06 and relative tolerance 1e-03.

Set nNonOrthogonalCorrectors to 0 in the SIMPLE (fvSolution) dictionary since the mesh is orthogonal.

The time scheme (ddtSchemes) should be Euler.

The interpolation scheme (interpolationSchemes) should be linear.
