The simulation uses buoyantFoam solver with LES Smagorinsky turbulence model and Boussinesq approximation. The domain is a 3D rectangular room of dimensions 4m (x) by 3m (y) by 1.6m (z). The convertToMeters factor is 1. The mesh is structured with 40x20x60 cells in x, y, and z directions respectively with uniform grading. The blockMeshDict contents are as follows:

FoamFile
{
    format      ascii;
    class       dictionary;
    object      blockMeshDict;
}

convertToMeters 1;

vertices
(
    (0 0 0)
    (0 0 1.6)
    (0 3 1.6)
    (0 3 0)
    (4 0 0)
    (4 0 1.6)
    (4 3 1.6)
    (4 3 0)
);

blocks
(
    hex (0 3 2 1 4 7 6 5)
    (40 20 60)
    simpleGrading (1 1 1)
);

defaultPatch
{
    name walls;
    type wall;
}

boundary
();

The inlet patch is on the x=0 face covering y-range 0.25 to 0.75 and z-range 1.1 to 1.3. The inlet has a fixed velocity of (0.2 0 0) m/s, a fixed temperature of 290 K, turbulent intensity of 14%, and mixing length of 0.0168 m. From these inlet conditions, k is calculated as 1.5 times (0.14 times 0.2) squared, giving k = 0.001176 m2/s2. Epsilon is calculated as Cmu^0.75 times k^1.5 divided by the mixing length, where Cmu = 0.09, giving epsilon approximately 0.000054 m2/s3. These calculated values of k and epsilon are used for both the inlet boundary condition and the uniform internal field initialization.

The outlet patch is on the x=4 face covering y-range 1.75 to 2.25 and z-range 0.3 to 0.5. The outlet uses pressureInletOutletVelocity for velocity and zeroGradient for temperature.

All remaining walls use no-slip (fixedValue uniform (0 0 0)) velocity boundary condition and fixed temperature of 302 K.

The turbulence model is LES with Smagorinsky subgrid-scale model.

The Boussinesq approximation is used with the following transport properties: reference density (rhoRef) of 1 kg/m3, reference temperature (TRef) of 300 K, thermal expansion coefficient (beta) of 3e-03 K-1, dynamic viscosity (nu) of 1e-05 m2/s (kinematic viscosity), Prandtl number (Pr) of 0.7, and specific heat capacity (Cp) of 712 J/(kg·K). Do not use compressible perfectGas or temperature-dependent density.

The simulation runs as steady-state using the PIMPLE algorithm with buoyantFoam. The time step (deltaT) is 1 s. The simulation runs for 3000 iterations (endTime = 3000). Results are written every 100 time steps (writeInterval = 100).

Pressure is set to a suitable reference value for the Boussinesq formulation. Gravity is (0 -9.81 0) m/s2.

Include an age function object to compute the mean age of air.

Include a comfort function object with clothing factor (clothingFactor) of 0.5, metabolic rate (metabolicRate) of 1.2, relative humidity (relHumidity) of 60%, and external air velocity derived from the simulation flow field.

Both k and epsilon fields are included in the setup even though LES Smagorinsky is the active turbulence model, as explicitly required.

The inlet and outlet patches must be created by splitting the defaultPatch walls using topoSet and createPatchDict (or equivalent face-set-based approach) since the blockMeshDict boundary list is empty and all faces default to the walls patch.
