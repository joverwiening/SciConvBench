The simulation uses the interFoam solver from OpenFOAM to model a 2D dam break.

The domain spans x: 0 to 1 m, y: 0 to 1 m, z: 0 to 0.01 m.
The z-direction is the empty direction with a single cell layer of thickness 0.01 m.
The front and back patches (z-normal faces) use the empty boundary condition.

The mesh resolution is 100 cells in the x-direction and 100 cells in the y-direction, giving uniform cells of 0.01 m x 0.01 m.
There is 1 cell in the z-direction.
The mesh is generated using blockMesh with a single hex block and simpleGrading (1 1 1).

The gravity vector is defined in constant/g as g (0 -9.81 0).

The water column is initialized using setFieldsDict.
The alpha.water field is set to 1 in the box region with min point (0 0 0) and max point (0.2 0.5 0.01).
The alpha.water field is set to 0 everywhere else (default value).

Water properties at room temperature are used: density 998.2 kg/m3, kinematic viscosity 1.0e-06 m2/s.
Air properties at room temperature are used: density 1.2 kg/m3, kinematic viscosity 1.48e-05 m2/s.
The surface tension coefficient sigma between water and air is 0.07 N/m.
These are specified in constant/transportProperties using the transportModel Newtonian for both phases.

The turbulence model is laminar, specified in constant/turbulenceProperties with simulationType set to laminar.

The top boundary (y = 1 m) is an open atmosphere patch of type patch.
The top boundary uses pressureInletOutletVelocity for U, totalPressure for p_rgh, and inletOutlet for alpha.water with inletValue uniform 0.
All other boundaries (bottom at y = 0, left at x = 0, right at x = 1) are walls.
Wall boundaries use noSlip (fixedValue uniform (0 0 0)) for U, fixedFluxPressure for p_rgh, and zeroGradient for alpha.water.

The simulation end time is 1.0 s.
Adjustable time stepping is enabled with adjustTimeStep set to yes.
The maximum Courant number maxCo is 0.5.
The maximum alpha Courant number maxAlphaCo is 0.5.
The initial deltaT is 0.001 s.
The maximum deltaT maxDeltaT is 0.01 s.
The write interval is 0.02 s using adjustableRunTime write control.

The time discretization scheme ddtSchemes uses Euler.
The gradient schemes gradSchemes use Gauss linear.
The divergence schemes divSchemes use Gauss vanLeer for div(phi,alpha.water), Gauss linearUpwindV grad(U) for div(rhoPhi,U), and Gauss linear for others.
The laplacian schemes laplacianSchemes use Gauss linear corrected.
The interpolation schemes interpolationSchemes use linear.
The surface normal gradient schemes snGradSchemes use corrected.

The linear solver for p_rgh uses GAMG with tolerance 1e-08 and relTol 0.01, with DIC smoother.
The linear solver for U, alpha.water, and other fields uses smoothSolver with GaussSeidel smoother, tolerance 1e-06, and relTol 0.
The PIMPLE algorithm is used with nOuterCorrectors 1, nCorrectors 2, and nNonOrthogonalCorrectors 1.

The output format is ascii.
The output precision is 6.
