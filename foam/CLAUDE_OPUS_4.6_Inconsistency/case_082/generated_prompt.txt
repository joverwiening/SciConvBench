The simulation uses the VOF (Volume of Fluid) method in OpenFOAM to model the gravity-driven separation of three immiscible fluids (oil, water, and gas) in a horizontal gravity separator.

The solver is interFoam, specified in the system/controlDict file.

The horizontal gravity separator has dimensions of 4.0 m (length) x 1.0 m (height) x 0.5 m (width), which is a reasonable geometry for a horizontal gravity separator.

The mesh resolution is 200 cells in the x-direction (length), 50 cells in the y-direction (height), and 25 cells in the z-direction (width), giving a total of 250,000 cells, which is sufficient to capture the interfaces between three phases.

Three phases are defined in the constant/transportProperties file.
Water has a density of 998 kg/m³ and a kinematic viscosity of 1.0e-06 m²/s.
Oil has a density of 850 kg/m³ and a kinematic viscosity of 5.0e-05 m²/s.
Gas has a density of 1.2 kg/m³ and a kinematic viscosity of 1.48e-05 m²/s.

Surface tension coefficients are defined between each pair of phases.
The surface tension between water and oil is 0.03 N/m.
The surface tension between water and gas is 0.072 N/m.
The surface tension between oil and gas is 0.025 N/m.

Gravity is set to (0 -9.81 0) in the constant/g file.

The volume fraction fields are alpha.water, alpha.oil, and alpha.gas.

The initial condition is a partially stratified state defined using system/setFieldsDict.
Water occupies the bottom third of the separator (y from 0 to 0.333 m), with alpha.water = 1, alpha.oil = 0, alpha.gas = 0.
Oil occupies the middle third of the separator (y from 0.333 m to 0.666 m), with alpha.water = 0, alpha.oil = 1, alpha.gas = 0.
Gas occupies the top third of the separator (y from 0.666 m to 1.0 m), with alpha.water = 0, alpha.oil = 0, alpha.gas = 1.

The default field values (before setFields regions are applied) are alpha.water = 0, alpha.oil = 0, alpha.gas = 1.

All six boundaries (top, bottom, front, back, left, right) are walls with no-slip velocity conditions, making this a closed vessel with no inlet or outlet.
Pressure on walls uses fixedFluxPressure.
Alpha fields on walls use zeroGradient.

The flow is laminar, so no turbulence model is used. The simulationType in constant/momentumTransport (or turbulenceProperties) is set to laminar.

The simulation end time is 60 seconds, which is sufficient to observe meaningful gravity-driven phase separation.
The time step is controlled by an adjustable time step with an initial deltaT of 0.001 s.
The maximum Courant number is 0.5.
The maximum alpha Courant number is 0.25.
The maximum deltaT is 0.05 s.

Write interval is set to 0.5 seconds, resulting in 120 saved time steps for post-processing.
Write format is ascii.
Write precision is 8.

The pressure-velocity coupling uses the PIMPLE algorithm.
The number of outer correctors is 1.
The number of correctors is 3.
The number of non-orthogonal correctors is 1.

The discretization schemes in system/fvSchemes use the following.
Time discretization (ddtSchemes) uses Euler.
Gradient schemes (gradSchemes) use Gauss linear.
Divergence schemes (divSchemes) use Gauss vanLeer for alpha fields and Gauss linearUpwind grad(U) for velocity.
Laplacian schemes use Gauss linear corrected.
Interpolation schemes use linear.
Surface normal gradient schemes use corrected.

The linear solvers in system/fvSolution use the following.
The pressure field (p_rgh) uses GAMG with a DIC smoother and tolerance of 1e-08.
The velocity field uses smoothSolver with a GaussSeidel smoother and tolerance of 1e-06.
The alpha fields use smoothSolver with a GaussSeidel smoother and tolerance of 1e-08.
