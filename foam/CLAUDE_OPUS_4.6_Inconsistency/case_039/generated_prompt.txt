The simulation is a classic 2D dam-break problem solved with OpenFOAM's interFoam VOF solver.

Domain and Geometry:
The tank dimensions are 0.584 m in the x-direction and 0.584 m in the y-direction.
The domain is extruded 0.01 m in the z-direction (one cell deep) to create a quasi-2D setup.
The initial water column occupies the region from (0, 0, 0) to (0.1461, 0.292, 0.01).

Mesh:
The mesh is a structured block mesh with approximately 46 cells in the x-direction and 46 cells in the y-direction and 1 cell in the z-direction, giving a uniform cell size of roughly 0.0127 m.
The mesh is generated using blockMesh.

Patches and Boundary Conditions:
The front and back z-normal faces are a single patch named frontAndBack with type empty.
The bottom wall (y = 0), left wall (x = 0), and right wall (x = 0.584) are grouped or individually defined as wall patches.
The top boundary (y = 0.584) is a patch named atmosphere.

For U: walls use noSlip (fixedValue uniform (0 0 0)), atmosphere uses pressureInletOutletVelocity with value uniform (0 0 0), frontAndBack uses empty.
For p_rgh: walls use zeroGradient (fixedFluxPressure), atmosphere uses totalPressure with p0 uniform 0 and value uniform 0, frontAndBack uses empty.
For alpha.water: walls use zeroGradient, atmosphere uses inletOutlet with inletValue uniform 0 and value uniform 0, frontAndBack uses empty.

Field Initialization:
alpha.water is initialized to 0 everywhere via the 0/alpha.water file.
setFields is used with a boxToCell source selecting the region (0, 0, 0) to (0.1461, 0.292, 0.01) and setting alpha.water to 1 inside that region.

Gravity:
Gravity is set in constant/g as (0 -9.81 0) with dimensions [0 1 -2 0 0 0 0].

Fluid Properties:
Water density is 1000 kg/m³.
Air density is 1 kg/m³.
Water kinematic viscosity is 1e-06 m²/s.
Air kinematic viscosity is 1.48e-05 m²/s.
Surface tension between water and air is 0.07 N/m.
These are specified in constant/transportProperties using the transportModel Newtonian for both phases.

Turbulence:
The simulation is laminar, set via constant/momentumTransport (or constant/turbulenceProperties) with simulationType laminar.

Solver and Numerical Schemes:
The application in system/controlDict is interFoam.
The end time is 1.0 s.
Adjustable time stepping is enabled with maxCo 0.5, maxAlphaCo 0.5, and an initial deltaT of 0.001 s.
The write interval is 0.05 s.
The run format is adjustableRunTime for writeControl.

The system/fvSchemes file uses Euler for ddtSchemes, Gauss linear for gradSchemes, Gauss vanLeer for div(rho*phi,U) and div(phi,alpha), Gauss linear corrected for laplacianSchemes, and linear for interpolationSchemes.

The system/fvSolution file uses GAMG with DIC smoother for p_rgh, smoothSolver with GaussSeidel for U and alpha.water, and the PIMPLE algorithm with nOuterCorrectors 1, nCorrectors 3, and nNonOrthogonalCorrectors 1.
