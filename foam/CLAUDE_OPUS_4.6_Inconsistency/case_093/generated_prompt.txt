The simulation is a 2D dam break using OpenFOAM with the interFoam solver.

The solver is interFoam.

The domain is a rectangle 0.584 m wide and 0.584 m tall.
The domain depth in the z-direction is 0.01 m (one cell thick) to enforce 2D behavior.

The water column is initially 0.146 m wide and 0.292 m tall, positioned at the bottom-left corner of the domain.

The mesh is generated using blockMesh with 46 cells in the x-direction, 46 cells in the y-direction, and 1 cell in the z-direction, giving approximately uniform cells.

Gravity is set to g = (0 -9.81 0) in the constant/g file.

The transportProperties dictionary defines two phases, water and air.
Water has density rho = 1000 kg/m^3 and kinematic viscosity nu = 1e-06 m^2/s.
Air has density rho = 1 kg/m^3 and kinematic viscosity nu = 1.48e-05 m^2/s.
The surface tension between water and air is sigma = 0.07 N/m.

The field alpha.water is initialized using setFields.
The default value of alpha.water is 0 (air everywhere).
A boxToCell region from (0 0 0) to (0.146 0.292 0.01) sets alpha.water = 1 (water column).

The controlDict settings are as follows.
The endTime is 5 s.
The initial deltaT is 0.001 s.
adjustTimeStep is set to yes.
maxCo is set to 0.5.
maxAlphaCo is set to 0.5.
maxDeltaT is set to 0.01 s.
The writeControl is adjustableRunTime.
The writeInterval is 0.05 s.

The boundary conditions for the bottom, left, and right patches are no-slip walls.
For velocity U, the walls use a fixedValue condition set to (0 0 0).
For pressure p_rgh, the walls use a fixedFluxPressure condition.
For alpha.water, the walls use a zeroGradient condition.

The top patch is open to the atmosphere.
For velocity U, the top uses pressureInletOutletVelocity with a value of (0 0 0).
For pressure p_rgh, the top uses totalPressure with p0 = 0.
For alpha.water, the top uses inletOutlet with an inletValue of 0 and a value of 0.

The front and back patches use the empty boundary condition for all fields to enforce the 2D simulation.

The turbulence modeling approach is laminar, specified by setting simulationType to laminar in the constant/turbulenceProperties file.

The fvSchemes file uses Gauss linear for gradient schemes, Gauss vanLeer for the divergence of alpha.water, Gauss linearUpwind grad(U) for the divergence of velocity, Gauss linear corrected for Laplacian schemes, and linear for interpolation schemes.

The fvSolution file uses the GAMG solver for p_rgh with a tolerance of 1e-08 and a relative tolerance of 0.01, smoothSolver with symGaussSeidel for U and alpha.water, and the PIMPLE algorithm with nOuterCorrectors set to 1, nCorrectors set to 2, and nNonOrthogonalCorrectors set to 1.
