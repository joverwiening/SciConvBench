Simulate the 2D transient von Kármán vortex street past a circular cylinder at Re = 150 using OpenFOAM.

The solver is pimpleFoam.

The cylinder diameter D = 1 m.
The freestream velocity U = 1 m/s.
The kinematic viscosity nu = U*D/Re = 1/150 = 0.006667 m^2/s.

The flow is laminar. Set simulationType to laminar in constant/turbulenceProperties. No turbulence model is used.

The computational domain is rectangular.
The cylinder center is at the origin (0, 0, 0).
The inlet is 15D upstream of the cylinder center (x = -15).
The outlet is 30D downstream of the cylinder center (x = 30).
The top boundary is 15D above the cylinder center (y = 15).
The bottom boundary is 15D below the cylinder center (y = -15).
The domain is one cell thick in the z-direction (z = 0 to z = 0.5), with empty front and back patches for 2D simulation.

The mesh is generated using blockMesh with an O-grid or structured approach around the cylinder, or alternatively using snappyHexMesh or gmsh.
The total cell count is approximately 50,000 to 80,000 cells.
The first cell height at the cylinder wall gives y+ < 1, approximately 0.005D.
There are at least 200 cells around the cylinder circumference.
The mesh is refined in the wake region extending at least 10D downstream.
Growth ratio from the cylinder wall outward does not exceed 1.1.

In system/controlDict, set the following:
application pimpleFoam;
startFrom startTime;
startTime 0;
stopAt endTime;
endTime 200;
deltaT 0.005;
adjustTimeStep yes;
maxCo 0.9;
writeControl runTime;
writeInterval 1;
purgeWrite 0;
writeFormat ascii;
writePrecision 8;
writeCompression uncompressed;
timeFormat general;
timePrecision 6;
runTimeModifiable true;

In system/fvSchemes, set the following:
ddtSchemes default is backward (second-order implicit time integration).
gradSchemes default is Gauss linear.
divSchemes div(phi,U) is Gauss linearUpwind grad(U).
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.

In system/fvSolution, set the following:
The pressure solver is GAMG with tolerance 1e-6, relTol 0.01, smoother GaussSeidel, and nPreSweeps 0, nPostSweeps 2, cacheAgglomeration true.
The velocity solver is smoothSolver with smoother symGaussSeidel, tolerance 1e-7, relTol 0.01.
The final pressure solver (pFinal) uses tolerance 1e-7 and relTol 0.
The final velocity solver (UFinal) uses tolerance 1e-8 and relTol 0.
Under PIMPLE, set nOuterCorrectors 2, nCorrectors 2, nNonOrthogonalCorrectors 1.
Under relaxationFactors equations, set U to 0.7 and p to 0.3 for intermediate outer iterations, and UFinal to 1.0 and pFinal to 1.0 for the final outer iteration.

Boundary conditions for velocity (0/U):
Inlet is fixedValue uniform (1 0 0).
Outlet is zeroGradient.
Top boundary is slip.
Bottom boundary is slip.
Cylinder surface is noSlip (fixedValue uniform (0 0 0)).
Front and back patches are empty.

Boundary conditions for pressure (0/p):
Inlet is zeroGradient.
Outlet is fixedValue uniform 0.
Top boundary is slip.
Bottom boundary is slip.
Cylinder surface is zeroGradient.
Front and back patches are empty.

In constant/transportProperties, set transportModel to Newtonian and nu to 0.006667 m^2/s.

The simulation runs from t = 0 to t = 200 seconds, which corresponds to approximately 30 or more vortex shedding cycles at the expected Strouhal number of approximately 0.18.
Results are written every 1 second of simulation time, providing roughly 5 to 6 snapshots per shedding cycle, which is sufficient to resolve the shedding.

Optionally include a forces function object in controlDict to monitor lift and drag on the cylinder, writing every time step, to extract the shedding frequency and force coefficients.
