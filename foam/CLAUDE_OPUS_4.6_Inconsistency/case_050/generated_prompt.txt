The simulation uses rhoCentralFoam to model a 2D compressible supersonic jet at Mach 2.0 discharging into a quiescent larger domain.

Air is treated as a perfect gas using hePsiThermo with perfectGas equation of state and sutherland transport in constant/thermophysicalProperties.

The application line in system/controlDict is set to rhoCentralFoam.

The mesh is 2D, extruded one cell in the z-direction, with frontAndBack patches set to empty.

Domain dimensions are assumed as follows based on best practices for underexpanded/supersonic jet simulations. The nozzle exit height is 1D where D = 0.01 m. The domain extends 30D downstream of the nozzle exit, 10D upstream of the nozzle exit, and 15D in the transverse direction above and below the jet centerline. The nozzle channel length upstream of the exit is 5D.

Inlet boundary conditions at the nozzle inlet are fixedValue for U = (686 0 0) m/s, fixedValue for T = 300 K, and fixedValue for p = 101325 Pa. This is a supersonic inflow so all variables are fixed.

Far-field and outlet boundary conditions use waveTransmissive for p and T, and zeroGradient for U, as specified. If rhoCentralFoam encounters compatibility issues with waveTransmissive, replace with zeroGradient for p and T at the outlet, and use inletOutlet with inletValue set to the far-field ambient values for U, p, and T on lateral far-field boundaries. The far-field ambient conditions are p = 101325 Pa, T = 300 K, and U = (0 0 0) m/s.

Solid walls use noSlip for U, zeroGradient for p, and zeroGradient for T.

Turbulence modeling uses kOmegaSST via the constant/turbulenceProperties file set to RAS. Inlet values for k and omega are estimated from a turbulence intensity of 1% and a turbulent viscosity ratio of 10. Wall functions (kqRWallFunction for k, omegaWallFunction for omega, nutkWallFunction for nut) are applied at wall boundaries.

Time stepping uses adjustableRunTime with a maximum Courant number of 0.5, which is appropriate for the explicit density-based central-upwind scheme in rhoCentralFoam. The initial deltaT is 1e-8 s. The end time is 0.005 s, which allows the jet to develop and traverse the domain multiple times.

Standard field data (U, p, T, rho, k, omega, nut, phi) are written at regular intervals with a writeInterval corresponding to every 0.0005 s, giving approximately 10 output time directories over the simulation.

The system/fvSchemes file uses Gauss linear for gradient schemes, bounded Gauss upwind or vanLeer for divergence schemes as appropriate for rhoCentralFoam, and Gauss linear corrected for laplacian schemes. Time discretization uses Euler (first-order implicit for the outer time loop, consistent with rhoCentralFoam usage).

The system/fvSolution file includes settings compatible with rhoCentralFoam. Smoothers use GaussSeidel. Tolerances for all fields are set to 1e-6 with relTol 0.
