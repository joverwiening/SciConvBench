Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity with the OpenFOAM solver solidDisplacementFoam.

The beam geometry is 1 m long (x-direction), 0.1 m high (y-direction), and 0.1 m wide (z-direction).
The beam origin is at (0 0 0) and extends to (1 0.1 0.1).

Use blockMesh with a single block to mesh the domain.
Use 40 cells along the length (x), 4 cells along the height (y), and 4 cells along the width (z).
The grading is uniform (simpleGrading (1 1 1)).

Define six boundary patches in blockMeshDict: fixed (the face at x=0), loaded (the face at x=1), top (the face at y=0.1), bottom (the face at y=0), front (the face at z=0.1), and back (the face at z=0).
All six patches are of type patch, except fixed which is of type wall.

In constant/mechanicalProperties, set planeStress to no.
Set rho with type uniform and value 7800 (density is defined but gravity is not active, so it has no effect).
Set E with type uniform and value 200e9.
Set nu with type uniform and value 0.3.

Gravity is not enabled. There is no g file or gravity body force applied.

In 0/D, the displacement field D is a volVectorField with dimensions [0 1 0 0 0 0 0] and internalField uniform (0 0 0).
The fixed patch boundary condition is fixedValue with value uniform (0 0 0).
The loaded patch boundary condition is tractionDisplacement with traction uniform (0 -1000 0) and pressure uniform 0 and value uniform (0 0 0).
The top patch boundary condition is tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0 and value uniform (0 0 0).
The bottom patch boundary condition is tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0 and value uniform (0 0 0).
The front patch boundary condition is tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0 and value uniform (0 0 0).
The back patch boundary condition is tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0 and value uniform (0 0 0).

In system/controlDict, set application to solidDisplacementFoam.
Set startFrom to startTime.
Set startTime to 0.
Set stopAt to endTime.
Set endTime to 1.
Set deltaT to 1.
Set writeControl to timeStep.
Set writeInterval to 1.
Set purgeWrite to 0.
Set writeFormat to ascii.
Set writePrecision to 6.
Set writeCompression to uncompressed.
Set timeFormat to general.
Set timePrecision to 6.
Set runTimeModifiable to true.

In system/fvSchemes, set d2dt2Schemes default to steadyState.
Set gradSchemes default to leastSquares.
Set divSchemes default to Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.

In system/fvSolution, set the solver for D to GAMG with tolerance 1e-06, relTol 0.01, smoother GaussSeidel, and nCellsInCoarsestLevel 20.
Set the stressAnalysis sub-dictionary with compactNormalStress yes, nCorrectors 1, and D tolerance 1e-06.
