Simulate turbulent airflow over a backward-facing step using the steady-state solver simpleFoam with the kOmegaSST RANS turbulence model.

The fluid is air at standard conditions with kinematic viscosity 1.5e-5 m2/s and density 1.225 kg/m3.

The geometry is a 2D backward-facing step with a step height H = 0.01 m.
The upstream channel height is 0.01 m (1H above the step surface).
The downstream channel height is 0.02 m (step height plus upstream channel height).
The domain extends 5H (0.05 m) upstream of the step.
The domain extends 30H (0.3 m) downstream of the step.
The domain is one cell thick in the spanwise direction for a 2D simulation using the empty boundary condition on front and back patches.

The mesh uses approximately 200 cells in the streamwise direction and 100 cells in the cross-stream direction.
The mesh is graded near all walls so that the first cell center satisfies y+ in the range of 30 to 100, appropriate for standard wall functions.

The inlet freestream velocity is 20 m/s in the streamwise direction.

In 0/U, the inlet boundary condition is type fixedValue with value uniform (20 0 0).
In 0/U, the walls boundary condition is type noSlip.
In 0/U, the outlet boundary condition is type zeroGradient.
In 0/U, the frontAndBack boundary condition is type empty.

In 0/p, the inlet boundary condition is type zeroGradient.
In 0/p, the walls boundary condition is type zeroGradient.
In 0/p, the outlet boundary condition is type fixedValue with value uniform 0.
In 0/p, the frontAndBack boundary condition is type empty.

In 0/k, the inlet boundary condition is type fixedValue with value uniform 1.5.
In 0/k, the walls boundary condition is type kqRWallFunction with value uniform 1.5.
In 0/k, the outlet boundary condition is type zeroGradient.
In 0/k, the frontAndBack boundary condition is type empty.

In 0/omega, the inlet boundary condition is type fixedValue with value uniform 447.2.
In 0/omega, the walls boundary condition is type omegaWallFunction with value uniform 447.2.
In 0/omega, the outlet boundary condition is type zeroGradient.
In 0/omega, the frontAndBack boundary condition is type empty.

In 0/nut, the inlet boundary condition is type calculated with value uniform 0.
In 0/nut, the walls boundary condition is type nutkWallFunction with value uniform 0.
In 0/nut, the outlet boundary condition is type calculated with value uniform 0.
In 0/nut, the frontAndBack boundary condition is type empty.

The turbulence intensity at the inlet is 5% (I = 0.05).
The turbulent mixing length at the inlet is 0.005 m.
The inlet k value is computed as 1.5 * (U * I)^2 = 1.5 * (20 * 0.05)^2 = 1.5 m2/s2.
The inlet omega value is computed as sqrt(k) / (Cmu^0.25 * L) = sqrt(1.5) / (0.09^0.25 * 0.005) = 447.2 rad/s.

In constant/transportProperties, set nu to 1.5e-5 m2/s.

In constant/turbulenceProperties, set simulationType to RAS and RASModel to kOmegaSST with turbulence on and printCoeffs on.

In system/controlDict, set the application to simpleFoam, startFrom to startTime, startTime to 0, endTime to 2000, deltaT to 1, writeInterval to 100, and writeFormat to ascii.

In system/fvSchemes, use Gauss linearUpwind for div(phi,U), Gauss upwind for div(phi,k) and div(phi,omega), Gauss linear for laplacian schemes, and steadyState for ddtSchemes.

In system/fvSolution, use the SIMPLE algorithm, smoothSolver with GaussSeidel smoother for U, k, and omega, and GAMG for p, with residual convergence tolerances of 1e-6 for p and 1e-5 for U, k, and omega, and relaxation factors of 0.7 for U, 0.3 for p, and 0.7 for k and omega.
