The simulation is a 2D, steady-state, incompressible, turbulent airflow over a NACA0012 airfoil at a 5-degree angle of attack using OpenFOAM.

The solver is simpleFoam.

The turbulence model is k-omega SST.

The domain is a C-grid type, one cell thick in the z-direction, making it a true 2D simulation.

The mesh is pre-defined and located in constant/polyMesh.

The boundary patches are inlet, outlet, airfoil, and frontAndBack.

The frontAndBack patches are set to type empty in constant/polyMesh/boundary.

The freestream velocity is 10 m/s in the x-direction, giving a vector of (10 0 0).

The kinematic viscosity nu is 1.5e-05 m/s squared.

The turbulence intensity at the inlet is 1%.

The turbulent viscosity ratio (nut/nu) at the inlet is 10.

The inlet turbulent kinetic energy k is calculated as 1.5 * (U * I)^2 = 1.5 * (10 * 0.01)^2 = 0.015 m^2/s^2.

The inlet specific dissipation rate omega is calculated as k / (nu * viscosityRatio) = 0.015 / (1.5e-05 * 10) = 100 rad/s.

The inlet turbulent viscosity nut is the viscosity ratio times nu = 10 * 1.5e-05 = 1.5e-04 m^2/s.

Boundary conditions for the inlet patch are as follows. U is fixedValue uniform (10 0 0). p is zeroGradient. k is fixedValue uniform 0.015. omega is fixedValue uniform 100. nut is calculated.

Boundary conditions for the outlet patch are as follows. U is inletOutlet with inletValue uniform (0 0 0) and value uniform (10 0 0). p is fixedValue uniform 0. k is inletOutlet with inletValue uniform 0.015 and value uniform 0.015. omega is inletOutlet with inletValue uniform 100 and value uniform 100. nut is calculated.

Boundary conditions for the airfoil patch are as follows. U is noSlip. p is zeroGradient. k is kqRWallFunction with value uniform 0.015. omega is omegaWallFunction with value uniform 100. nut is nutkWallFunction with value uniform 0.

Boundary conditions for the frontAndBack patch are as follows. U is empty. p is empty. k is empty. omega is empty. nut is empty.

The turbulence properties file specifies simulationType as RAS. The RAS model is kOmegaSST. turbulence is on. printCoeffs is on.

The transport model is Newtonian with nu set to 1.5e-05 m^2/s.

The fvSchemes file uses the following. ddtSchemes default is steadyState. gradSchemes default is Gauss linear. divSchemes div(phi,U) is bounded Gauss linearUpwind grad(U). divSchemes div(phi,k) is bounded Gauss upwind. divSchemes div(phi,omega) is bounded Gauss upwind. divSchemes div((nuEff*dev2(T(grad(U))))) is Gauss linear. laplacianSchemes default is Gauss linear corrected. interpolationSchemes default is linear. snGradSchemes default is corrected.

The fvSolution file uses the following. The p solver is GAMG with tolerance 1e-06, relTol 0.01, smoother GaussSeidel, and nPreSweeps 0, nPostSweeps 2, cacheAgglomeration on. The U solver is smoothSolver with smoother GaussSeidel, tolerance 1e-07, relTol 0.1, nSweeps 1. The k solver is smoothSolver with smoother GaussSeidel, tolerance 1e-07, relTol 0.1, nSweeps 1. The omega solver is smoothSolver with smoother GaussSeidel, tolerance 1e-07, relTol 0.1, nSweeps 1. The SIMPLE algorithm settings are nNonOrthogonalCorrectors 1 and consistent yes. Relaxation factors for fields p is 0.3. Relaxation factors for equations U is 0.7, k is 0.7, and omega is 0.7. The residualControl is p 1e-05, U 1e-05, k 1e-05, and omega 1e-05.

The controlDict file sets application to simpleFoam. startFrom is startTime. startTime is 0. stopAt is endTime. endTime is 2000. deltaT is 1. writeControl is timeStep. writeInterval is 100. purgeWrite is 3. writeFormat is ascii. writePrecision is 8. writeCompression is off. timeFormat is general. timePrecision is 6. runTimeModifiable is true.

The simulation includes function objects to compute force coefficients on the airfoil patch. The liftDir is (-0.08716 0.99619 0). The dragDir is (0.99619 0.08716 0). The magUInf is 10. The lRef is 1 (chord length). The Aref is 1 (chord length times unit span).
