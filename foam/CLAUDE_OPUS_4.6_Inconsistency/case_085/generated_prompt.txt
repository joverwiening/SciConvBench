The simulation is a 2D steady-state Rayleigh-Bénard convection problem in a square cavity using OpenFOAM.

Solver: buoyantBoussinesqSimpleFoam.

Geometry: A 2D square cavity of 1 m x 1 m. The domain is one cell thick in the z-direction (e.g., 0 to 0.01 m) with empty boundary conditions on the front and back patches to enforce 2D behavior.

Mesh: Use blockMesh with 80 cells in the x-direction and 80 cells in the y-direction, uniform spacing. One cell in the z-direction. This gives 6400 cells, which is a reasonable resolution for this Rayleigh number (~70,000).

Gravity: Set g = (0, -9.81, 0) m/s^2 in constant/g.

Thermophysical properties in constant/thermophysicalProperties:
thermoType: type heRhoThermo; mixture Boussinesq; transport const; thermo hConst; equationOfState Boussinesq; specie specie; energy sensibleEnthalpy.
mixture/specie: molWeight 28.9.
mixture/thermodynamics: Cp 1005; Hf 0.
mixture/transport: mu 1.8e-05; Pr 0.7.
mixture/BoussinesqCoeffs: TRef 300; beta 0.00333; rhoRef 1.176.

Turbulence modeling: Run as laminar. Set simulationType to laminar in constant/turbulenceProperties. The Rayleigh number for this configuration is approximately Ra = (rhoRef * g * beta * deltaT * L^3) / (mu / rhoRef) * (1 / alpha) which is around 70,000, well below the turbulent transition threshold of ~1e9 for this configuration.

Boundary conditions for temperature T: bottom wall fixedValue uniform 310; top wall fixedValue uniform 290; left and right side walls zeroGradient; front and back patches empty.

Boundary conditions for velocity U: all four walls noSlip (fixedValue uniform (0 0 0)); front and back patches empty.

Boundary conditions for pressure p_rgh: all four walls fixedFluxPressure with value uniform 0; front and back patches empty.

Boundary conditions for pressure p: all four walls calculated with value uniform 0; front and back patches empty.

Initial conditions: T uniform 300 (the reference temperature); U uniform (0 0 0); p_rgh uniform 0; p uniform 0.

Numerical schemes in system/fvSchemes:
ddtSchemes: steadyState.
gradSchemes: default Gauss linear.
divSchemes: div(phi,U) bounded Gauss linearUpwind grad(U); div(phi,T) bounded Gauss linearUpwind grad(T); div((nuEff*dev2(T(grad(U))))) Gauss linear.
laplacianSchemes: default Gauss linear corrected.
interpolationSchemes: default linear.
snGradSchemes: default corrected.

Solution controls in system/fvSolution:
Solver for p_rgh: GAMG with tolerance 1e-06, relTol 0.01, smoother GaussSeidel.
Solver for U and T: smoothSolver with smoother GaussSeidel, tolerance 1e-06, relTol 0.1.
SIMPLE: nNonOrthogonalCorrectors 0; residualControl with p_rgh tolerance 1e-05, U tolerance 1e-05, T tolerance 1e-05.
Relaxation factors: p_rgh 0.3; U 0.7; T 0.7.

Run control in system/controlDict: startFrom startTime; startTime 0; stopAt endTime; endTime 2000 (iterations); deltaT 1; writeControl timeStep; writeInterval 500; purgeWrite 2; writeFormat ascii; writePrecision 8; writeCompression uncompressed; timeFormat general; timePrecision 6; runTimeModifiable true.

The simulation should converge to a steady-state solution showing convective rolls in the cavity driven by the temperature difference between the hot bottom wall and the cold top wall.
