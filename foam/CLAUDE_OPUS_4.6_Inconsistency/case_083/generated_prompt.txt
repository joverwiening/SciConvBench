Set up the initial conditions for a three-phase settling tank using the multiphaseEulerFoam solver.
The initial field files are located in the 0/ directory.
There are three phases: sediment, water, and oil.
Each phase has a corresponding volume fraction file: alpha.sediment, alpha.water, and alpha.oil.
In the file 0/alpha.sediment, set the internalField to: internalField uniform 0.5;
In the file 0/alpha.water, set the internalField to: internalField uniform 0.5;
In the file 0/alpha.oil, set the internalField to: internalField uniform 0.5;
These default uniform values will be later overwritten by setFieldsDict to create stratified layers in the settling tank.
The solver used is multiphaseEulerFoam.
