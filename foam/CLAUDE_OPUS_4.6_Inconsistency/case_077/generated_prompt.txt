The solver is buoyantPimpleFoam.
The simulation is a 2D transient thermal plume of hot air rising due to buoyancy with large density variations.
Gravity is set to (0 -9.81 0) in constant/g.

The computational domain is 1 m wide and 2 m tall, centered so that x ranges from 0 to 1 and y ranges from 0 to 2.
The domain is one cell thick in the z-direction (e.g., 0 to 0.01 m) with empty boundary conditions on the front and back faces to enforce 2D behavior.

The mesh is generated with blockMesh using 100 cells in the x-direction and 200 cells in the y-direction and 1 cell in the z-direction, giving uniform 0.01 m cell spacing.

The bottom boundary is split into two patches: a hot patch named "hotPatch" spanning the central 10% of the bottom width (x from 0.45 to 0.55, y = 0), and the remaining bottom boundary named "bottomWall".
The top boundary is a patch named "top".
The left boundary is a patch named "left".
The right boundary is a patch named "right".
The front and back boundaries are of type empty.

The thermoType in constant/thermophysicalProperties is configured as follows: type heRhoThermo; mixture pureMixture; transport sutherland; thermo hConst; equationOfState perfectGas; specie specie; energy sensibleEnthalpy.
The Boussinesq equation of state is not used and no BoussinesqCoeffs block is present.

The mixture subdictionary contains a specie sub-block with molWeight 28.9.
The thermodynamics sub-block has Cp 1005 and Hf 0.
The transport sub-block uses the Sutherland model with As 1.4792e-06 and Ts 116.

The turbulence model is laminar, configured in constant/momentumTransport (or constant/turbulenceProperties depending on the OpenFOAM version) with simulationType laminar.

The initial temperature field T is uniform 300 K with dimensions [0 0 0 0 1 0 0].
The hotPatch boundary condition for T is fixedValue uniform 500.
The bottomWall boundary condition for T is zeroGradient.
The top, left, and right boundary conditions for T are inletOutlet with inletValue uniform 300 and value uniform 300.
The front and back boundary conditions for T are empty.

The initial velocity field U is uniform (0 0 0) with dimensions [0 1 -1 0 0 0 0].
The hotPatch and bottomWall boundary conditions for U are fixedValue uniform (0 0 0).
The top, left, and right boundary conditions for U are pressureInletOutletVelocity with value uniform (0 0 0).
The front and back boundary conditions for U are empty.

The initial pressure field p_rgh is uniform 0 with dimensions [1 -1 -2 0 0 0 0].
The hotPatch and bottomWall boundary conditions for p_rgh are fixedFluxPressure with value uniform 0.
The top, left, and right boundary conditions for p_rgh are totalPressure with p0 uniform 0 and value uniform 0.
The front and back boundary conditions for p_rgh are empty.

The initial pressure field p is uniform 101325 with dimensions [1 -1 -2 0 0 0 0].
The hotPatch and bottomWall boundary conditions for p are calculated with value uniform 101325.
The top, left, and right boundary conditions for p are calculated with value uniform 101325.
The front and back boundary conditions for p are empty.

The simulation end time is 5 seconds.
The time step is controlled by adjustableRunTime with an initial deltaT of 0.001 s and a maximum Courant number of 0.5.
The maxDeltaT is 0.01 s.
The write interval is 0.1 s using adjustableRunTime write control.

The fvSchemes file uses Euler for ddtSchemes, Gauss linear for gradSchemes, Gauss linearUpwind grad(U) for div(phi,U), Gauss linearUpwind grad(T) for div(phi,h) and div(phi,K), Gauss linear corrected for laplacianSchemes, and linear for interpolationSchemes.

The fvSolution file uses PIMPLE with nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1.
The p_rgh solver is GAMG with tolerance 1e-6 and relTol 0.01.
The U and h solvers are PBiCGStab with DILU preconditioner, tolerance 1e-6, and relTol 0.1.
