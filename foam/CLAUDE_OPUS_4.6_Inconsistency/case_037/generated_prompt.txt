Simulate steady, incompressible, laminar flow of water through a 2D channel with a rigid, stationary obstacle using OpenFOAM.

Use the simpleFoam solver (steady-state, incompressible).

The channel dimensions are 2.2 m long and 0.41 m tall, consistent with the standard Schaefer-Turek 2D benchmark.

The obstacle is a circular cylinder with a diameter of 0.1 m, centered at (0.2, 0.2) from the bottom-left corner of the channel.

The mesh is 2D, extruded one cell deep in the spanwise (z) direction, with frontAndBack patches set to empty type.

Use blockMesh or snappyHexMesh to generate the mesh with approximately 200 cells along the channel length and 80 cells across the channel height, with local refinement around the cylinder surface to resolve the boundary layer (smallest cell size near the cylinder approximately 0.001 m).

Water kinematic viscosity nu is 1e-6 m2/s, specified in constant/transportProperties using the Newtonian transport model.

The Reynolds number based on cylinder diameter and inlet velocity is Re = U * D / nu = 0.1 * 0.1 / 1e-6 = 10000. Since this exceeds the laminar regime, the simulation proceeds as specified by the user (laminar, no turbulence model), acknowledging that the user has explicitly requested laminar flow. Set simulationType to laminar in constant/turbulenceProperties.

Boundary conditions for 0/U are as follows.
Inlet is fixedValue uniform (0.1 0 0).
Outlet is zeroGradient.
Top and bottom walls are noSlip (fixedValue uniform (0 0 0)).
Obstacle surface is noSlip (fixedValue uniform (0 0 0)).
frontAndBack is empty.

Boundary conditions for 0/p are as follows.
Inlet is zeroGradient.
Outlet is fixedValue uniform 0.
Top and bottom walls are zeroGradient.
Obstacle surface is zeroGradient.
frontAndBack is empty.

In system/controlDict, set application to simpleFoam.
Set startFrom to startTime and startTime to 0.
Set endTime to 1000.
Set deltaT to 1.
Set writeInterval to 100.
Set writeFormat to ascii.
Set writeCompression to off.
Set purgeWrite to 0.
Set runTimeModifiable to true.

In system/fvSchemes, use steadyState for ddtSchemes.
Use Gauss linear for gradSchemes.
Use bounded Gauss linearUpwind grad(U) for div(phi,U) and bounded Gauss linear for div((nuEff*dev2(T(grad(U))))).
Use Gauss linear corrected for laplacianSchemes.
Use linear for interpolationSchemes.
Use corrected for snGradSchemes.

In system/fvSolution, use the SIMPLE algorithm.
For p, use GAMG solver with GaussSeidel smoother, tolerance 1e-6, relTol 0.01.
For U, use smoothSolver with GaussSeidel smoother, tolerance 1e-7, relTol 0.01.
Set SIMPLE residualControl so that p converges to 1e-4 and U converges to 1e-4.
Set relaxationFactors for fields p to 0.3 and for equations U to 0.7.
