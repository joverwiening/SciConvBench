The simulation uses the multiphaseEulerFoam solver in OpenFOAM.
The PIMPLE algorithm is used with 3 outer correctors, 1 corrector, 0 non-orthogonal correctors, and 2 energy correctors.
The domain is a rectangular channel with dimensions 0.15m (x) by 1.0m (y) by 0.1m (z).
The convertToMeters factor is 1.
The mesh is a structured 25x75x1 grid with uniform grading.
The simulation is treated as 2D with empty boundary conditions on the front and back faces.
All field files include empty patch entries for the defaultFaces patch.

The blockMeshDict contents are as follows:
FoamFile { format ascii; class dictionary; object blockMeshDict; }
convertToMeters 1;
vertices ( (0 0 0) (0.15 0 0) (0.15 1 0) (0 1 0) (0 0 0.1) (0.15 0 0.1) (0.15 1 0.1) (0 1 0.1) );
blocks ( hex (0 1 2 3 4 5 6 7) (25 75 1) simpleGrading (1 1 1) );
defaultPatch { type empty; }
boundary ( inlet { type patch; faces ( (1 5 4 0) ); } outlet { type patch; faces ( (3 7 6 2) ); } walls { type wall; faces ( (0 4 7 3) (2 6 5 1) ); } );

Two phases are defined: water (continuous) and steam (dispersed).
The initial internal field for water temperature (T.water) is 360K.
The initial internal field for water velocity (U.water) is (0, 0.1, 0) m/s.
The initial internal field for alpha.water is 0.6.
The initial internal field for alpha.steam is 0.
The initial internal field for steam temperature (T.steam) is 372.76K (saturation temperature).
The initial internal field for steam velocity (U.steam) is (0, 0.1, 0) m/s.
The initial internal field for pressure (p_rgh) is 1e5 Pa.
The initial internal field for pressure (p) is 1e5 Pa.

The inlet patch boundary conditions are as follows:
U.water is fixedValue with value (0, 0.1, 0) m/s.
U.steam is fixedValue with value (0, 0.1, 0) m/s.
T.water is fixedValue with value 360K.
T.steam is fixedValue with value 372.76K.
alpha.water is fixedValue with value 1.
alpha.steam is fixedValue with value 0.
p_rgh is fixedFluxPressure with value 1e5 Pa.
p is calculated.

The outlet patch boundary conditions are as follows:
U.water is pressureInletOutletVelocity with value (0, 0, 0) m/s.
U.steam is pressureInletOutletVelocity with value (0, 0, 0) m/s.
T.water is inletOutlet with inletValue 360K and value 360K.
T.steam is inletOutlet with inletValue 372.76K and value 372.76K.
alpha.water is inletOutlet with inletValue 1 and value 0.6.
alpha.steam is inletOutlet with inletValue 0 and value 0.
p_rgh is fixedValue with value 1e5 Pa.
p is calculated.

The walls patch boundary conditions are as follows:
U.water is noSlip.
U.steam is noSlip.
T.water is fixedValue with value 360K.
T.steam is zeroGradient.
alpha.water is zeroGradient.
alpha.steam is zeroGradient.
p_rgh is fixedFluxPressure with value 1e5 Pa.
p is calculated.

The defaultFaces patch boundary conditions are empty for all fields.

Water thermophysical properties use the following:
The thermophysical model type is heRhoThermo.
The mixture type is pureMixture.
The transport model is const.
The dynamic viscosity (mu) is 2.8291e-4 Pa.s.
The Prandtl number (Pr) is approximately 1.77 (derived from mu*Cp/kappa = 2.8291e-4 * 4195 / 0.67).
The thermo model is hConst.
The specific heat capacity (Cp) is 4195 J/kg/K.
The enthalpy of formation (Hf) is 0.
The equation of state is rPolynomial.
The rPolynomial coefficients are chosen for liquid water near 360K and 1 bar: rhoCoeffs are approximately (0.001027, -5.0e-7, 0, 0, 0, 0) corresponding to a density of approximately 967 kg/m3 at reference conditions.
The specie molecular weight is 18.0153 g/mol.
The thermal conductivity (kappa) is approximately 0.67 W/m/K.
The energy type is sensibleEnthalpy.

Steam thermophysical properties use the following:
The thermophysical model type is heRhoThermo.
The mixture type is pureMixture.
The transport model is const.
The dynamic viscosity (mu) is 1.2256e-5 Pa.s.
The Prandtl number (Pr) is approximately 1.02 (derived from mu*Cp/kappa = 1.2256e-5 * 2078.4 / 0.025).
The thermo model is hConst.
The specific heat capacity (Cp) is 2078.4 J/kg/K.
The enthalpy of formation (Hf) is 0.
The equation of state is perfectGas.
The specie molecular weight is 18.0153 g/mol.
The thermal conductivity (kappa) is approximately 0.025 W/m/K.
The energy type is sensibleEnthalpy.

The phase properties dictionary (phaseProperties) defines water as the continuous phase and steam as the dispersed phase.
The dispersed phase (steam) uses a constant diameter model with a default diameter of 1e-3 m.
The residual alpha for both phases is 1e-6.

The SchillerNaumann drag model is used for the steam-water pair.
The surface tension between steam and water is constant at 0.07 N/m.
No virtual mass, lift, wall lubrication, or turbulent dispersion forces are included.

Phase change is modeled using a thermal phase change model (e.g., thermalPhaseChangeTwoPhaseEuler or equivalent).
The saturation model is constant with saturation pressure 1e5 Pa and saturation temperature 372.76K.
The phase change coefficients use reasonable default values for condensation and evaporation.

Steam injection is implemented via fvOptions using a semi-implicit source applied to a cellSet.
The cellSet is defined using topoSet with a sphereToCell or nearestToCell selection at point (0.075, 0.2, 0.05).
The injection mass flow rate for the steam phase is 1e-3 kg/s.
The injection velocity for the steam phase is (0, 10, 0) m/s.
The injection specific enthalpy for the steam phase is 3.7e6 J/kg.
The injection is active from t=1s to t=10s (timeStart 1, duration 9).

Both phases use a laminar flow model (simulationType laminar).
Each phase has its own momentumTransport dictionary (e.g., momentumTransport.water and momentumTransport.steam) set to laminar.

The simulation runs from time 0 to 10 seconds.
The initial time step is 1e-3 seconds.
The maximum time step is 1e-2 seconds.
Adaptive time stepping is enabled with maxCo 0.25.
The write interval is 0.1 seconds.
The write control is adjustableRunTime.
The time format is general with time precision 6.

The fvSchemes dictionary uses appropriate schemes for multiphaseEulerFoam.
The time scheme (ddtSchemes) is Euler.
The gradient schemes (gradSchemes) default to Gauss linear.
The divergence schemes (divSchemes) default to Gauss linear for standard terms and Gauss linearUpwind or Gauss vanLeer for phase fraction and velocity transport.
The Laplacian schemes (laplacianSchemes) default to Gauss linear corrected.
The interpolation schemes (interpolationSchemes) default to linear.
The snGrad schemes (snGradSchemes) default to corrected.

The fvSolution dictionary uses the PIMPLE algorithm as specified.
The pressure equation (p_rgh) uses the GAMG solver with DIC smoother and tolerance 1e-8 with relTol 0.01.
The final pressure solve uses tolerance 1e-8 with relTol 0.
The velocity, temperature, and alpha equations use the smoothSolver with symGaussSeidel smoother and tolerance 1e-8 with relTol 0.
