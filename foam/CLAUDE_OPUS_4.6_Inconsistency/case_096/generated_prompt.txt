Simulate a 2D dam break problem using the interFoam solver from OpenFOAM for two incompressible, immiscible fluids (water and air).

The computational domain is a rectangular tank 0.5m long (x-direction) and 0.5m high (y-direction), extruded by 0.01m in the z-direction to create a single layer of cells.

The mesh is generated using blockMeshDict with 50 cells in the x-direction, 50 cells in the y-direction, and 1 cell in the z-direction, giving uniform cubic cells of 0.01m edge length.

The boundary patches defined in constant/polyMesh/boundary are as follows:
leftWall is type wall.
rightWall is type wall.
lowerWall is type wall.
atmosphere is type patch.
frontAndBack is type symmetry.

Gravity acts in the negative y-direction with the vector g = (0 -9.81 0), specified in constant/g.

The transport model is Newtonian for both phases, specified in constant/transportProperties.
Water (phase1) has density rho = 998.2 kg/m³ and kinematic viscosity nu = 1.004e-06 m²/s.
Air (phase2) has density rho = 1.2 kg/m³ and kinematic viscosity nu = 1.48e-05 m²/s.
Surface tension between water and air is sigma = 0.07 N/m.

The turbulence modeling approach is laminar, specified in constant/turbulenceProperties.

The initial condition for alpha.water is set using setFieldsDict.
The default field value for alpha.water is 0 (air everywhere).
A boxToCell region is used to set alpha.water = 1 for all cells with x < 0.15m (i.e., the box spans from (0 0 0) to (0.15 0.5 0.01)).

Boundary conditions for the U field in the 0/ directory:
leftWall, rightWall, and lowerWall use noSlip.
atmosphere uses pressureInletOutletVelocity with a value of uniform (0 0 0).
frontAndBack uses symmetry.
The internal field for U is uniform (0 0 0).

Boundary conditions for the p_rgh field in the 0/ directory:
leftWall, rightWall, and lowerWall use fixedFluxPressure with a value of uniform 0.
frontAndBack uses fixedFluxPressure with a value of uniform 0.
atmosphere uses totalPressure with p0 = uniform 0, U field U, phi field phi, rho field rho, psi field none, gamma 1, and value uniform 0.
The internal field for p_rgh is uniform 0.

Boundary conditions for the alpha.water field in the 0/ directory:
leftWall, rightWall, and lowerWall use zeroGradient.
frontAndBack uses zeroGradient.
atmosphere uses inletOutlet with inletValue uniform 0 and value uniform 0.
The internal field for alpha.water is uniform 0 (will be overwritten by setFields).

The simulation control is specified in system/controlDict.
The application is interFoam.
The start time is 0.
The end time is 1 second.
The deltaT (initial time step) is 0.001 seconds.
Adjustable time stepping is enabled with maxCo = 1, maxAlphaCo = 1, and maxDeltaT = 0.01.
The write control is adjustableRunTime with a write interval of 0.05 seconds.
The write format is ascii.
The write precision is 6.
The time precision is 6.
The purgeWrite value is 0 (keep all time steps).

The numerical schemes in system/fvSchemes use the following:
ddtSchemes default is Euler.
gradSchemes default is Gauss linear.
divSchemes uses Gauss vanLeer for div(phi,alpha), Gauss linearUpwindV grad(U) for div(phi,U), and Gauss linear for div(rhoPhi,U) and others as needed.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.

The linear solvers in system/fvSolution use the following:
alpha.water uses smoothSolver with smoother symGaussSeidel, tolerance 1e-8, and relTol 0.
p_rgh uses GAMG with smoother GaussSeidel, tolerance 1e-7, and relTol 0.01.
p_rghFinal uses GAMG with smoother GaussSeidel, tolerance 1e-7, and relTol 0.
U uses smoothSolver with smoother symGaussSeidel, tolerance 1e-6, and relTol 0.
The PIMPLE algorithm is used with nOuterCorrectors 1, nCorrectors 3, and nNonOrthogonalCorrectors 0.

The execution order is: run blockMesh to generate the mesh, run setFields to initialize the water column, then run interFoam to perform the simulation.
