The simulation uses the multiphaseEulerFoam solver in OpenFOAM for a 3D transient dam break with three phases: water, air, and oil.

The computational domain is a rectangular tank of size 1.0 m (x) x 0.6 m (y) x 0.4 m (z).

Gravity acts in the -y direction at 9.81 m/s².

The water column is initially placed in one corner of the domain, occupying the region from (0, 0, 0) to (0.2, 0.6, 0.2).

The oil layer sits on top of the water column, occupying the region from (0, 0, 0.2) to (0.2, 0.6, 0.25).

The remainder of the domain is filled with air.

The three phases are defined in transportProperties as air, water, and oil.

Water has a density of 1000 kg/m³ and a kinematic viscosity of 1e-06 m²/s.

Air has a density of 1.225 kg/m³ and a kinematic viscosity of 1.48e-05 m²/s.

Oil (light oil) has a density of 800 kg/m³ and a kinematic viscosity of 1e-06 m²/s.

Surface tension coefficients are set as follows: water-air is 0.07 N/m, oil-air is 0.03 N/m, and water-oil is 0.03 N/m.

The setFieldsDict utility is used to initialize the phase fraction fields alpha.water, alpha.oil, and alpha.air in their respective regions using boxToCell entries.

In the water region, alpha.water is set to 1, alpha.oil is set to 0, and alpha.air is set to 0.

In the oil region, alpha.oil is set to 1, alpha.water is set to 0, and alpha.air is set to 0.

The default field values are alpha.air equal to 1, alpha.water equal to 0, and alpha.oil equal to 0.

All wall boundaries (bottom, front, back, left, right) use no-slip conditions with fixedValue uniform (0 0 0) for velocity and zeroGradient for pressure and phase fractions.

The top boundary is an atmospheric inlet/outlet using totalPressure for pressure (p_rgh with a reference value of 0), pressureInletOutletVelocity for velocity, and inletOutlet for the phase fractions with air as the inlet value (alpha.air = 1, alpha.water = 0, alpha.oil = 0).

The turbulence model is set to laminar for all phases.

The simulation end time is 1.0 s.

Adaptive time-stepping is enabled with a maximum Courant number of 0.5.

The initial time step is 1e-04 s.

The maximum time step is 1e-03 s.

The write interval is 0.05 s, using adjustableRunTime write control.

The time discretization scheme is first-order Euler implicit.

The gradient schemes use Gauss linear.

The divergence schemes use Gauss linear or Gauss upwind as appropriate for multiphaseEulerFoam.

The Laplacian schemes use Gauss linear corrected.

The PIMPLE algorithm is used for pressure-velocity coupling with 3 outer correctors and 1 non-orthogonal corrector.
