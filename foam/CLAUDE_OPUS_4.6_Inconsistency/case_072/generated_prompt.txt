The solver is buoyantBoussinesqPimpleFoam.
The domain is a 3D box with dimensions 1m (X) x 1m (Y) x 0.1m (Z), with height oriented along the Z-axis.
The mesh is generated using blockMesh with a uniform resolution of 100 cells in X, 100 cells in Y, and 20 cells in Z, giving cell aspect ratios close to unity.
The blockMeshDict defines the domain from (0 0 0) to (1 1 0.1).
The boundary patches are: bottomWall (z=0 face), topWall (z=0.1 face), and two cyclic pairs — xPeriodic (x=0 paired with x=1) and yPeriodic (y=0 paired with y=1).
The cyclic pairs use the OpenFOAM cyclic boundary type, and the blockMeshDict must define matching face pairs with the cyclicPolyPatch type using neighbourPatch entries.

The file constant/g defines the gravity vector as g (0 0 -9.81).

The file constant/transportProperties uses the Boussinesq approximation with the following entries: beta = 0.00341 (thermal expansion coefficient in 1/K), TRef = 300 (reference temperature in K), nu = 1.5e-5 (kinematic viscosity in m^2/s), Pr = 0.71 (Prandtl number), and Prt = 0.85 (turbulent Prandtl number).

The Rayleigh number for this configuration is approximately Ra = g * beta * deltaT * H^3 / (nu * alpha) where deltaT=10K, H=0.1m, alpha=nu/Pr, giving Ra ~ 1.4e6, which is above the critical value but moderate.
The turbulence model is set to laminar in constant/momentumTransport (or constant/turbulenceProperties depending on OpenFOAM version), since Ra is moderate and the goal is to capture laminar convection cells.

Boundary conditions in the 0/ directory for temperature T: bottomWall is fixedValue uniform 310, topWall is fixedValue uniform 300, xPeriodic and yPeriodic are cyclic.
Boundary conditions in the 0/ directory for velocity U: bottomWall is noSlip, topWall is noSlip, xPeriodic and yPeriodic are cyclic.
Boundary conditions in the 0/ directory for pressure p_rgh: bottomWall is fixedFluxPressure with a value of uniform 0, topWall is fixedValue uniform 0, xPeriodic and yPeriodic are cyclic.
Boundary conditions in the 0/ directory for pressure p: bottomWall is calculated with a value of uniform 0, topWall is calculated with a value of uniform 0, xPeriodic and yPeriodic are cyclic.

The initial condition for U is uniform (0 0 0).
The initial condition for p_rgh is uniform 0.
The initial condition for p is uniform 0.
The initial condition for T is a linear profile from 310K at z=0 to 300K at z=0.1, with a small random perturbation of amplitude ~0.1K added to the interior cells using the setFields utility or a coded function object, to break symmetry and trigger the onset of convection cells.

The simulation is transient.
The system/controlDict sets the end time to 200 seconds to allow full development of convection cells.
The time step uses adjustable time stepping with adjustTimeStep yes, maxCo 0.5, and an initial deltaT of 0.01 seconds.
The write interval is set to write data every 5 seconds (or equivalent writeControl setting).

The system/fvSchemes uses second-order schemes: Gauss linear for gradient schemes, Gauss linearUpwind for divergence schemes (div(phi,U) and div(phi,T)), Gauss linear corrected for Laplacian schemes, and linear for interpolation schemes. The ddt scheme is Euler (first-order in time) or backward (second-order in time); use backward for better temporal accuracy.

The system/fvSolution configures the PIMPLE algorithm with nOuterCorrectors 2, nCorrectors 1, and nNonOrthogonalCorrectors 0. The pressure solver uses GAMG with a DIC smoother and tolerance 1e-6 with relTol 0.01. The velocity and temperature solvers use PBiCGStab with DILU preconditioner, tolerance 1e-6, and relTol 0.01.
