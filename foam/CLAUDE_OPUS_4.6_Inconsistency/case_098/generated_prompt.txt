This is a 2D axisymmetric simulation of swirling flow in a pipe using OpenFOAM with the simpleFoam solver and a 5-degree wedge mesh.

Pipe dimensions: length 1.0 m, radius 0.05 m (L/D ratio of 10, a standard benchmark proportion).

The mesh is generated using blockMeshDict as a 5-degree wedge about the x-axis (axial direction), with one cell in the circumferential direction.

The working fluid is air at standard conditions with kinematic viscosity nu = 1.5e-05 m^2/s, defined in constant/transportProperties.

The turbulence model is k-omega SST, defined in constant/turbulenceProperties with RAS enabled and printCoeffs on.

The patches in constant/polyMesh/boundary are defined as follows:
inlet has type patch.
outlet has type patch.
wall has type wall.
front has type symmetryPlane.
back has type symmetryPlane.

The velocity field U (dimensions 0 0 -1 0 0 0 0) boundary conditions are:
inlet is fixedValue with a uniform swirling velocity of (1 0 0.5), representing 1 m/s axial and 0.5 m/s tangential (swirl number approximately 0.5), decomposed into the wedge coordinate components as (1 <y-component> <z-component>) where the tangential velocity of 0.5 m/s is decomposed using the wedge half-angle of 2.5 degrees as y-component = 0.5*cos(2.5 deg) and z-component = 0.5*sin(2.5 deg). On the front wedge face the z-component is positive and on the back wedge face it is negative.
outlet is zeroGradient.
wall is noSlip.
front is symmetryPlane.
back is symmetryPlane.

The pressure field p (dimensions 0 2 -2 0 0 0 0) boundary conditions are:
inlet is zeroGradient.
outlet is fixedValue uniform 0.
wall is zeroGradient.
front is symmetryPlane.
back is symmetryPlane.

The turbulent kinetic energy k (dimensions 0 2 -2 0 0 0 0) boundary conditions are:
inlet is fixedValue uniform 0.015 (based on 5% turbulence intensity with U_bulk approximately 1 m/s, k = 1.5*(TI*U)^2).
outlet is zeroGradient.
wall is kqRWallFunction with value uniform 0.015.
front is symmetryPlane.
back is symmetryPlane.

The specific dissipation rate omega (dimensions 0 0 -1 0 0 0 0) boundary conditions are:
inlet is fixedValue uniform 44.7 (estimated from omega = k^0.5 / (Cmu^0.25 * l), with mixing length l = 0.07*D).
outlet is zeroGradient.
wall is omegaWallFunction with value uniform 44.7.
front is symmetryPlane.
back is symmetryPlane.

The turbulent viscosity nut (dimensions 0 2 -1 0 0 0 0) boundary conditions are:
inlet is calculated with value uniform 0.
outlet is calculated with value uniform 0.
wall is nutkWallFunction with value uniform 0.
front is symmetryPlane.
back is symmetryPlane.

In system/fvSchemes:
ddtSchemes default is steadyState.
gradSchemes default is Gauss linear.
divSchemes default is none.
divSchemes div(phi,U) is bounded Gauss linearUpwind grad(U).
divSchemes div(phi,k) is bounded Gauss upwind.
divSchemes div(phi,omega) is bounded Gauss upwind.
divSchemes div((nuEff*dev2(T(grad(U))))) is Gauss linear.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.

In system/fvSolution:
The SIMPLE algorithm is used.
Solver for p is GAMG with tolerance 1e-06, relTol 0.01, smoother GaussSeidel.
Solver for U, k, and omega is smoothSolver with smoother symGaussSeidel, tolerance 1e-06, relTol 0.1.
Relaxation factors for fields: p is 0.3.
Relaxation factors for equations: U is 0.7, k is 0.7, omega is 0.7.
Residual control: p 1e-04, U 1e-04, k 1e-04, omega 1e-04.

In system/controlDict:
application is simpleFoam.
startFrom is startTime.
startTime is 0.
stopAt is endTime.
endTime is 1000.
deltaT is 1.
writeControl is timeStep.
writeInterval is 100.
purgeWrite is 3.
writeFormat is ascii.
writePrecision is 8.
writeCompression is off.
timeFormat is general.
timePrecision is 6.
runTimeModifiable is true.
