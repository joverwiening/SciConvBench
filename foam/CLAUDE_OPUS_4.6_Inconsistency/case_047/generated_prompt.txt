The simulation uses the simpleFoam solver for steady-state, incompressible, turbulent flow.
The RANS turbulence model is k-epsilon (kEpsilon).
The fluid is water with a kinematic viscosity of 1e-6 m²/s.
The pipe has a diameter of 0.1 m.
The pipe length is assumed to be 1.0 m (10 diameters), which is a reasonable length for developing turbulent pipe flow.
The mesh is a structured hexahedral mesh generated with blockMesh, with approximately 20 cells across the radial direction, 40 cells around the circumference, and 100 cells along the axial length, with grading near the wall to resolve the boundary layer.
The inlet velocity is 1 m/s, applied as a uniform profile in the axial direction.
The turbulence intensity for initial and inlet conditions is 5%.

The 0/U file sets internalField to uniform (0 0 1), assuming flow in the z-direction along the pipe axis.
The inlet boundary condition for U is fixedValue with value uniform (0 0 1).
The outlet boundary condition for U is zeroGradient.
The wall boundary condition for U is noSlip.

The 0/p file sets internalField to uniform 0.
The inlet boundary condition for p is zeroGradient.
The outlet boundary condition for p is fixedValue with value uniform 0.
The wall boundary condition for p is zeroGradient.

The 0/k file sets internalField to uniform 0.00375.
The inlet boundary condition for k is fixedValue with value uniform 0.00375.
The outlet boundary condition for k is zeroGradient.
The wall boundary condition for k is kqRWallFunction with value uniform 0.00375.

The 0/epsilon file sets internalField to uniform 0.001.
The inlet boundary condition for epsilon is fixedValue with value uniform 0.001.
The outlet boundary condition for epsilon is zeroGradient.
The wall boundary condition for epsilon is epsilonWallFunction with value uniform 0.001.

The constant/transportProperties file specifies nu as 1e-6 m²/s.
The constant/turbulenceProperties file specifies the simulation type as RAS, the RAS model as kEpsilon, and turbulence is set to on.

The system/controlDict file sets the application to simpleFoam, startFrom to startTime, startTime to 0, stopAt to endTime, endTime to 1000, deltaT to 1, writeControl to timeStep, writeInterval to 100, and purgeWrite to 0.

The system/fvSchemes file uses steadyState for ddtSchemes, Gauss linearUpwind grad(U) for divSchemes on div(phi,U), Gauss upwind for divSchemes on div(phi,k) and div(phi,epsilon), Gauss linear corrected for laplacianSchemes, and linear for interpolationSchemes.

The system/fvSolution file uses the SIMPLE algorithm.
The solver for p is GAMG with tolerance 1e-6 and relTol 0.01.
The solver for U is smoothSolver with smoother symGaussSeidel, tolerance 1e-6, and relTol 0.1.
The solvers for k and epsilon are smoothSolver with smoother symGaussSeidel, tolerance 1e-6, and relTol 0.1.
The SIMPLE relaxation factors are 0.3 for p, 0.7 for U, 0.7 for k, and 0.7 for epsilon.
The SIMPLE residualControl sets convergence thresholds of 1e-4 for p, U, k, and epsilon.
The SIMPLE nNonOrthogonalCorrectors is set to 1.
