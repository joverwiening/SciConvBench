The simulation is a 2D, incompressible, steady-state airflow over a NACA 0012 airfoil at 0 degrees angle of attack using OpenFOAM's simpleFoam solver.

The airfoil has a chord length of 1 m.

The freestream velocity is (10 0 0) m/s.

Standard sea-level air properties are used, with kinematic viscosity nu = 1.5e-5 m²/s, giving a Reynolds number of approximately 6.67e5.

The turbulence model is k-omega SST, which is a standard and robust choice for external aerodynamic flows at this Reynolds number.

The domain uses a C-grid topology around the airfoil.

The mesh is one cell thick in the z-direction to enforce a true 2D simulation.

In the system/blockMeshDict file, the frontAndBack patches are defined with type empty in the boundary entry.

In the 0/U file, the inlet boundary condition is fixedValue uniform (10 0 0).
In the 0/U file, the outlet boundary condition is zeroGradient.
In the 0/U file, the airfoil surface boundary condition is noSlip.
In the 0/U file, the frontAndBack boundary condition is empty.

In the 0/p file, the inlet boundary condition is zeroGradient.
In the 0/p file, the outlet boundary condition is fixedValue uniform 0.
In the 0/p file, the airfoil surface boundary condition is zeroGradient.
In the 0/p file, the frontAndBack boundary condition is empty.

Turbulence fields (k, omega, nut) are set up consistently with the k-omega SST model using standard inlet values estimated from a turbulence intensity of approximately 1% and a turbulent viscosity ratio of 10.

The system/controlDict file specifies the simpleFoam solver application.

The system/fvSchemes file uses standard second-order discretization schemes suitable for steady-state RANS simulations.

The system/fvSolution file uses standard solver settings and SIMPLE algorithm relaxation factors appropriate for simpleFoam.

The constant/transportProperties file specifies nu as 1.5e-5 m²/s.

The constant/turbulenceProperties file specifies the RAS turbulence model type with the kOmegaSST model.
