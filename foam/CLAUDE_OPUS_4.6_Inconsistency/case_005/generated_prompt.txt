The simulation uses multiphaseEulerFoam (Euler–Euler) for a 2D gas–liquid bubble column.

The computational domain is a rectangular box spanning x from 0 to 0.15 m, y from 0 to 1.00 m, z from 0 to 0.10 m, with height along the +y direction.

The mesh is structured hexahedral with 25 cells in x, 75 cells in y, and 1 cell in z, using simpleGrading (1 1 1).

The blockMeshDict defines an inlet patch on the bottom face (y = 0), an outlet patch on the top face (y = 1.0), walls patches on the four side faces (x = 0, x = 0.15, y-side faces), and frontAndBack empty patches on the two z-normal faces (z = 0 and z = 0.10) for 2D treatment.

The inlet patch type is patch.
The outlet patch type is patch.
The walls patch type is wall.
The frontAndBack patch type is empty.

Gravity is set to (0 -9.81 0) m/s² in the constant/g file.

The phases are defined as (air water) in phaseProperties, with water as the continuous phase and air as the dispersed phase.

The residualAlpha is 1e-6 for both air and water phases.

Blending uses the linear scheme with minFullyContinuousAlpha.water 0.7 and minPartlyContinuousAlpha.water 0.3 for the default blending, and minFullyContinuousAlpha.water 0.5 and minPartlyContinuousAlpha.water 0.5 for drag blending.

Surface tension between air and water is constant with sigma = 0.07.

Drag model is SchillerNaumann for air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water configurations.

Virtual mass uses constantCoefficient with Cvm = 0.5 for air_dispersedIn_water and water_dispersedIn_air.

Heat transfer uses RanzMarshall model for air_dispersedIn_water and water_dispersedIn_air with residualAlpha 1e-4.

The water phase thermophysical model uses heRhoThermo with type heRhoThermo, mixture pureMixture, transport const with mu 3.645e-4 and Pr 2.289, thermo eConst with Cv 4195 and Hf 0, equationOfState rPolynomial with C coefficients (0.001278 -2.1055e-06 3.9689e-09 4.3772e-13 -2.0225e-16), specie with molWeight 18, and energy sensibleInternalEnergy.

The air phase thermophysical model uses heRhoThermo with type heRhoThermo, mixture pureMixture, transport const with mu 1.84e-05 and Pr 0.7, thermo hConst with Cp 1007 and Hf 0, equationOfState perfectGas, specie with molWeight 28.9, and energy sensibleEnthalpy.

Bubble diameter for air uses isothermalDiameter with d0 = 3e-3 m.
Bubble diameter for water uses constantDiameter with d = 1e-4 m.

Momentum transport is laminar for both phases, with simulationType laminar in the respective constant/momentumTransport.air and constant/momentumTransport.water files.
