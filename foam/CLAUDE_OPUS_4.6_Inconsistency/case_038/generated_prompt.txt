The simulation uses OpenFOAM with the solidDisplacementFoam solver to compute displacement and stress in a solid aluminum block undergoing thermo-elastic deformation.

The geometry is a rectangular block with dimensions 0.1 m x 0.01 m x 0.01 m (length along x, width along y, height along z).

The mesh is generated using blockMesh with 40 cells in the x-direction, 4 cells in the y-direction, and 4 cells in the z-direction, using simple grading of 1 in all directions.

The block has six faces named as follows: fixedFace at x = 0, heatedFace at x = 0.1, top at z = 0.01, bottom at z = 0, left at y = 0, right at y = 0.01.

Material properties for aluminum are specified in constant/mechanicalProperties or equivalent dictionaries as follows: E = 69e9 Pa, nu = 0.33, rho = 2700 kg/m^3, alpha = 2.3e-5 1/K.

The reference temperature T0 is 300 K and is specified in the thermalProperties or equivalent dictionary.

Thermal strains are enabled by setting thermalStress to yes in the constant/thermalProperties dictionary.

The planeStress entry in constant/mechanicalProperties is set to no, since this is a full 3D simulation.

The boundary condition for the displacement field D in 0/D is as follows: fixedFace is fixedValue uniform (0 0 0); heatedFace is zeroGradient; top is zeroGradient; bottom is zeroGradient; left is zeroGradient; right is zeroGradient.

The internal field for D in 0/D is uniform (0 0 0).

The boundary condition for the temperature field T in 0/T is as follows: heatedFace is fixedValue uniform 400; fixedFace is zeroGradient; top is zeroGradient; bottom is zeroGradient; left is zeroGradient; right is zeroGradient.

The internal field for T in 0/T is uniform 300.

The simulation is run as a steady-state analysis using a single large time step.

In system/controlDict, the application is solidDisplacementFoam.
In system/controlDict, startFrom is startTime and startTime is 0.
In system/controlDict, stopAt is endTime and endTime is 1.
In system/controlDict, deltaT is 1.
In system/controlDict, writeControl is timeStep and writeInterval is 1.

In system/fvSchemes, the d2dt2 schemes are set to steadyState.
In system/fvSchemes, the gradient schemes default to Gauss linear.
In system/fvSchemes, the divergence schemes default to Gauss linear.
In system/fvSchemes, the laplacian schemes default to Gauss linear corrected.
In system/fvSchemes, the interpolation schemes default to linear.
In system/fvSchemes, the snGrad schemes default to corrected.

In system/fvSolution, the solver for D uses GAMG with tolerance 1e-06 and relTol 0.01, using GaussSeidel as the smoother with nCellsInCoarsestLevel set to 20.
In system/fvSolution, the number of correctors (nCorrectors) is set to 1.
In system/fvSolution, the convergence tolerance for D is 1e-06.

The outputs of interest are the displacement field D and the stress field sigmaEq (von Mises equivalent stress), which solidDisplacementFoam writes automatically.

The temperature field T is prescribed (not solved by solidDisplacementFoam) and drives the thermal strain computation via the thermal expansion coefficient alpha and the reference temperature T0.
