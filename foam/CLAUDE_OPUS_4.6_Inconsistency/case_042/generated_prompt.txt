The simulation is a 2D supersonic flow of air at Mach 2 over a 10-degree half-wedge, producing an oblique shock. Air is treated as a calorically perfect gas. The solver is rhoCentralFoam (density-based, transient, compressible). The simulation is run as inviscid (Euler) to cleanly capture the shock without viscous effects.

Domain geometry:
The domain is 2D, extruded one cell in the z-direction.
The wedge tip is located at x = 0, y = 0.
Upstream of the wedge tip, the bottom wall is flat (y = 0) extending from x = -1.0 m to x = 0.
Downstream of the wedge tip, the bottom wall is a 10-degree ramp extending from x = 0 to x = 3.0 m, so the ramp surface goes from (0, 0) to (3.0, 3.0*tan(10 degrees)) which is approximately (3.0, 0.529).
The top boundary is flat at y = 1.5 m, extending from x = -1.0 m to x = 3.0 m.
The inlet is at x = -1.0 m from y = 0 to y = 1.5 m.
The outlet is at x = 3.0 m from y = 3.0*tan(10 degrees) to y = 1.5 m.
The z-direction extrusion is from z = 0 to z = 0.1 m, one cell thick.

Mesh resolution:
The mesh is generated using blockMesh.
Use approximately 200 cells in the x-direction and 100 cells in the y-direction, with 1 cell in the z-direction.
The mesh consists of two blocks: one upstream block from x = -1.0 to x = 0 (rectangular), and one downstream block from x = 0 to x = 3.0 where the bottom boundary follows the 10-degree ramp.
The upstream block uses approximately 50 cells in x and 100 cells in y.
The downstream block uses approximately 150 cells in x and 100 cells in y.
Grading is uniform (no stretching).

Freestream and inlet conditions:
p = 101325 Pa.
T = 300 K.
U = (686 0 0) m/s.

Thermophysical properties (constant/thermophysicalProperties):
Use hePsiThermo with mixture pureMixture.
The transport model is const (mu = 0, Pr = 1, since inviscid).
The thermodynamics model is hConst with Cp = 1004.5 J/(kg·K) and Hf = 0.
The equation of state is perfectGas.
The specie is air with molecular weight 28.96 kg/kmol.
The energy entry is sensibleEnthalpy.

Turbulence modeling:
In constant/momentumTransport (or constant/turbulenceProperties), set simulationType to laminar. Since viscosity is zero, this effectively gives an Euler (inviscid) simulation.

Boundary conditions:
Inlet (x = -1.0 m face): fixedValue for U = (686 0 0), fixedValue for p = 101325, fixedValue for T = 300.
Outlet (x = 3.0 m face): zeroGradient for U, waveTransmissive for p (gamma = 1.4, fieldInf = 101325, lInf = 3.0), zeroGradient for T.
Top boundary (y = 1.5 m face): slip for U, zeroGradient for p, zeroGradient for T.
Bottom wall upstream (flat, y = 0 from x = -1.0 to x = 0): slip for U, zeroGradient for p, zeroGradient for T.
Wedge ramp surface (10-degree ramp from x = 0 to x = 3.0): slip for U, zeroGradient for p, zeroGradient for T.
frontAndBack (z = 0 and z = 0.1 faces): empty for all fields.

system/controlDict:
application is rhoCentralFoam.
startFrom is startTime.
startTime is 0.
stopAt is endTime.
endTime is 0.01 s.
deltaT is 1e-06 s.
adjustTimeStep is yes.
maxCo is 0.5.
maxDeltaT is 1e-04 s.
writeControl is adjustableRunTime.
writeInterval is 0.001 s.
purgeWrite is 0.
writeFormat is ascii.
writePrecision is 10.
writeCompression is off.
timeFormat is general.
timePrecision is 6.
runTimeModifiable is true.

system/fvSchemes:
ddtSchemes default is Euler.
gradSchemes default is Gauss linear.
divSchemes default is none.
divSchemes div(phi,U) is Gauss vanLeerV.
divSchemes div(phid,p) is Gauss vanLeer.
divSchemes div(phi,e) is Gauss vanLeer.
divSchemes div(phi,K) is Gauss vanLeer.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
interpolationSchemes reconstruct(rho) is vanLeer.
interpolationSchemes reconstruct(U) is vanLeerV.
interpolationSchemes reconstruct(T) is vanLeer.
snGradSchemes default is corrected.

system/fvSolution:
No linear solver or PISO/SIMPLE settings are needed for rhoCentralFoam as it is an explicit density-based solver.

Expected result:
An oblique shock originating at the wedge tip at approximately 39.3 degrees shock angle (from analytical oblique shock relations for M = 2, deflection = 10 degrees, gamma = 1.4). Downstream of the shock, the flow deflects by 10 degrees and the Mach number, pressure, temperature, and density change according to the oblique shock relations.
