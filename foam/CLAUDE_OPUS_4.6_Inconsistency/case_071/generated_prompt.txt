Simulate a 2D dam break case using the interFoam solver in OpenFOAM.

The computational domain is a rectangle with dimensions 0.6m in the X-direction (length) and 0.4m in the Y-direction (height).
The domain extends 0.01m in the Z-direction to accommodate a single-cell layer for the 2D simulation.
The geometry is created using blockMesh with a single block.
The mesh resolution is 120 cells in X, 80 cells in Y, and 1 cell in Z, giving uniform cells of approximately 0.005m edge length in the X-Y plane.
The block vertices span from (0 0 0) to (0.6 0.4 0.01).

The front and back patches (Z-normal faces) are of type empty to enforce a 2D simulation.
The bottom (y=0), left (x=0), and right (x=0.6) patches are grouped as walls.
The top (y=0.4) patch is named atmosphere.

The gravity vector in constant/g is set to (0 -9.81 0).

The two phases are defined in transportProperties as water and air.
Water has kinematic viscosity nu = 1e-06 m^2/s and density rho = 1000 kg/m^3.
Air has kinematic viscosity nu = 1.48e-05 m^2/s and density rho = 1 kg/m^3.
Surface tension between the phases sigma is 0.07 N/m.

The initial condition is defined using setFieldsDict.
The default field value for alpha.water is 0 (air everywhere).
A boxToCell region from (0 0 0) to (0.15 0.3 0.01) sets alpha.water to 1 (water column occupying x < 0.15m and y < 0.3m).

Boundary conditions in the 0/ directory for U: noSlip on walls, pressureInletOutletVelocity with value uniform (0 0 0) on atmosphere, empty on front and back.
Boundary conditions for p_rgh: fixedFluxPressure with value uniform 0 on walls, totalPressure with p0 uniform 0 on atmosphere, empty on front and back.
Boundary conditions for alpha.water: zeroGradient on walls, inletOutlet with inletValue uniform 0 and value uniform 0 on atmosphere, empty on front and back.

The internal field for U is uniform (0 0 0).
The internal field for p_rgh is uniform 0.
The internal field for alpha.water is uniform 0 (overridden by setFields).

The turbulence modeling approach is laminar, specified in constant/turbulenceProperties by setting simulationType to laminar.

The simulation runs from startTime 0 to endTime 2 seconds.
Adaptive time stepping is enabled by setting adjustTimeStep to yes in controlDict.
The maximum Courant number maxCo is 0.5.
The maximum alpha Courant number maxAlphaCo is 0.5.
The maximum allowed time step maxDeltaT is 0.001.
The initial time step deltaT is 0.0001.

The write control is set to adjustableRunTime with a write interval of 0.05 seconds.
The write format is ascii.
The write precision is 6.
The time precision is 6.
The purgeWrite value is 0 (keep all time directories).

The fvSchemes file uses Euler for ddtSchemes (time discretization).
The gradSchemes default is Gauss linear.
The divSchemes use Gauss vanLeer for div(phi,alpha) and div(phirb,alpha), and Gauss linearUpwind grad for div(rhoPhi,U).
The div((muEff*dev(T(grad(U))))) scheme is Gauss linear.
The laplacianSchemes default is Gauss linear corrected.
The interpolationSchemes default is linear.
The snGradSchemes default is corrected.

The fvSolution file uses the GAMG solver with DIC smoother for p_rgh, smoothSolver with GaussSeidel smoother for U, and smoothSolver with GaussSeidel smoother for alpha.water.
The PIMPLE algorithm is used with nOuterCorrectors 1, nCorrectors 2, and nNonOrthogonalCorrectors 1.

The run sequence is: blockMesh, then setFields, then interFoam.
