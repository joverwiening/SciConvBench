The simulation uses OpenFOAM's solidDisplacementFoam solver to compute the static deflection of a 2D cantilever beam under a downward traction load, assuming linear elasticity.

The beam geometry is 1.0 m long (x-direction), 0.1 m high (y-direction), and 0.01 m deep (z-direction, single cell layer for 2D).

The structured mesh has 100 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction, created using blockMesh.

The material is aluminum with Young's modulus E = 70e9 Pa and Poisson's ratio nu = 0.33.

The formulation is plane stress, which is set in the mechanicalProperties dictionary.

The displacement field D is the primary solved variable.

Boundary condition for the fixedEnd patch (x = 0 face): fixedValue with uniform (0 0 0) in 0/D.

Boundary condition for the loadEnd patch (x = 1 face): tractionDisplacement with traction uniform (0 -10000 0) and pressure uniform 0 in 0/D.

Boundary conditions for the top patch (y = 0.1 face) and bottom patch (y = 0 face): tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0 in 0/D, representing traction-free surfaces.

Boundary conditions for the frontAndBack patches (z = 0 and z = 0.01 faces): empty in 0/D.

In system/controlDict, set application to solidDisplacementFoam.

In system/controlDict, set startFrom to startTime, startTime to 0, endTime to 1, deltaT to 1, so the simulation runs a single time step for the static solution.

In system/controlDict, set writeControl to timeStep and writeInterval to 1.

In constant/mechanicalProperties, set planeStress to yes, rho with dimensions [1 -3 0 0 0 0 0] and value 2700, nu with dimensions [0 0 0 0 0 0 0] and value 0.33, and E with dimensions [1 -1 -2 0 0 0 0] and value 70e9.

In system/fvSchemes, use appropriate settings for solidDisplacementFoam: laplacian schemes use Gauss linear corrected, gradient schemes use Gauss linear, and divergence schemes use Gauss linear.

In system/fvSolution, solve for D using GAMG or PCG with a tolerance of 1e-06 and relTol of 0.01.
