The simulation is a 2D fluid-structure interaction of a flexible flap in a channel, using OpenFOAM with the preCICE coupling library.

GEOMETRY
The domain is 2D, extruded one cell in the z-direction, with frontAndBack patches set to empty.
The fluid channel is 1.0 m long and 0.2 m tall.
A solid flap is 0.05 m long (extending upward from the bottom wall) and 0.005 m thick.
The flap is attached to the bottom wall with its center at x = 0.4 m.
The fluid and solid are separate regions (multi-region setup) sharing a common interface at the flap surface.

FLUID DOMAIN
The fluid solver is pimpleFoam.
The fluid is incompressible water with kinematic viscosity nu = 1e-6 m^2/s and density rho = 1000 kg/m^3.
The inlet boundary condition is fixedValue with U = (1 0 0) m/s.
The outlet boundary condition is fixedValue with p = 0 Pa.
The top and bottom channel walls (excluding the flap interface) use noSlip for velocity and zeroGradient for pressure.
The flap interface on the fluid side receives displacement from the solid solver and applies a moving-wall velocity condition consistent with the interface motion.
Turbulence is modeled using RANS with the k-omega SST model.
Inlet turbulence quantities are set to reasonable values: k = 0.015 m^2/s^2 (turbulence intensity ~10%), omega = 100 1/s.
Wall functions (kqRWallFunction, omegaWallFunction, nutkWallFunction) are used on all wall boundaries.

SOLID DOMAIN
The solid solver is solidDisplacementFoam run as a separate region.
The solid flap material is linear elastic with Young's modulus E = 1e6 Pa, Poisson's ratio nu = 0.45, and density rho = 1200 kg/m^3.
The flap base (bottom edge attached to the channel wall) has a fixedDisplacement (zero displacement) boundary condition.
The flap surface (interface with the fluid) receives traction from the fluid solver and sends displacement back to the fluid solver.
The top edge of the flap (tip) is traction-free.

FSI COUPLING
The coupling framework is preCICE with the OpenFOAM-preCICE adapter.
Coupling is two-way (partitioned) and implicit, performed every time step.
At each time step, fluid traction (pressure and viscous stress) is transferred from the fluid interface to the solid interface, and solid displacement is transferred from the solid interface to the fluid interface.
The fluid mesh at the interface is deformed according to the received displacement using a diffusion-based mesh motion solver (displacementLaplacian with diffusivity set to inverseDistance).
An implicit fixed-point (Aitken under-relaxation) coupling scheme is used within each time step.
The FSI coupling convergence criterion is a relative displacement residual tolerance of 1e-4.
The maximum number of coupling iterations per time step is 50.

MESH RESOLUTION
The fluid domain uses approximately 200 cells along the channel length and 40 cells along the channel height, with refinement near the flap and walls so that the first cell height gives y+ of approximately 1 near the flap (cell size near walls approximately 0.0005 m).
The solid domain uses approximately 10 cells along the flap length and 4 cells across the flap thickness.
Both meshes are generated using blockMesh.

TIME CONTROL
The time step size is 1e-4 s, giving a maximum Courant number of approximately 0.2.
The total simulation time is 1.0 s, which is sufficient for the flow to develop and the flap to reach a quasi-steady oscillatory or deflected state.
Results are written every 0.01 s (every 100 time steps).

PIMPLE SETTINGS FOR FLUID
The number of outer correctors (PIMPLE loops) is 2.
The number of pressure correctors is 1.
The number of non-orthogonal correctors is 1.
Residual tolerances for pressure and velocity are 1e-6.

SOLID SOLVER SETTINGS
The number of correctors for solidDisplacementFoam is 200.
The displacement convergence tolerance is 1e-6.

NUMERICAL SCHEMES
Time discretization uses backward (second-order implicit) for both fluid and solid.
Gradient schemes use Gauss linear.
Divergence schemes use Gauss linearUpwind for convective terms in the fluid.
Laplacian schemes use Gauss linear corrected.
