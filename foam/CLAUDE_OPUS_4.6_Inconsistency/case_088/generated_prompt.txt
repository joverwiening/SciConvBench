The simulation uses the buoyantSimpleFoam solver for steady-state buoyant flow in a solar chimney.
The constant/thermophysicalProperties file uses the following top-level entries for thermo type selection, not grouped as a sub-dictionary.
thermoType is set to hePsiThermo.
mixture is set to perfectGas.
transport is set to const.
thermo is set to hConst.
equationOfState is set to perfectGas.
specie is set to specie.
energy is set to sensibleEnthalpy.
The mixture block contains three sub-dictionaries: specie, thermodynamics, and transport.
The specie sub-dictionary sets molWeight to 28.9.
The thermodynamics sub-dictionary sets Cp to 1005 and Hf to 0.
The transport sub-dictionary sets mu to 1.8e-05 and Pr to 0.7.
There is no BoussinesqCoeffs block in the file.
The constant/g file defines gravitational acceleration as (0 -9.81 0), assuming y is the vertical direction pointing upward.
The file uses the standard OpenFOAM FoamFile header with version 2.0, ascii format, class uniformDimensionedVectorField, and object g.
The dimensions entry in the g file is [0 1 -2 0 0 0 0].
The scope of this specification covers only the constant/thermophysicalProperties and constant/g files.
No geometry, mesh, boundary condition, or other case setup files are included in this specification.
