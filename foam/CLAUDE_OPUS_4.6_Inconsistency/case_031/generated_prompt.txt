Use the icoFoam solver for a 2D incompressible laminar Poiseuille flow simulation in a rectangular channel.
The channel is 0.5 m long in the x-direction and 0.1 m high in the y-direction.
The mesh is one cell thick in the z-direction, spanning from z = 0 to z = 0.01 m.
The kinematic viscosity is 1e-3 m^2/s, set in constant/transportProperties as nu = 1e-3.
The mesh resolution is 200 cells in the x-direction and 40 cells in the y-direction, with 1 cell in the z-direction.
Use a uniform grading of 1 in all directions in blockMeshDict.
Define the following patches in blockMeshDict: inlet (type patch), outlet (type patch), topWall (type wall), bottomWall (type wall), and frontAndBack (type empty).
The inlet patch is the face at x = 0.
The outlet patch is the face at x = 0.5.
The topWall patch is the face at y = 0.1.
The bottomWall patch is the face at y = 0.
The frontAndBack patches are the faces at z = 0 and z = 0.01.
In the 0/U file, set the inlet boundary condition to a parabolic velocity profile using codedFixedValue or groovyBC with Ux = 4 * Umax * y * (H - y) / (H * H), where Umax = 1 m/s and H = 0.1 m, with Uy = 0 and Uz = 0.
In the 0/U file, set the outlet boundary condition to zeroGradient.
In the 0/U file, set the topWall boundary condition to noSlip.
In the 0/U file, set the bottomWall boundary condition to noSlip.
In the 0/U file, set the frontAndBack boundary condition to empty.
The internal field for U is uniform (0 0 0).
In the 0/p file, set the outlet boundary condition to fixedValue with a value of uniform 0.
In the 0/p file, set the inlet boundary condition to zeroGradient.
In the 0/p file, set the topWall boundary condition to zeroGradient.
In the 0/p file, set the bottomWall boundary condition to zeroGradient.
In the 0/p file, set the frontAndBack boundary condition to empty.
The internal field for p is uniform 0.
The simulation end time is 1 s.
The time step deltaT is 1e-4 s.
The write interval is 0.05 s.
Use the PISO algorithm settings with nCorrectors set to 2 and nNonOrthogonalCorrectors set to 0 in system/fvSolution.
In system/fvSchemes, use Gauss linear for gradient schemes, Gauss linear corrected for laplacian schemes, Gauss linear for divergence schemes, and Euler for the time scheme.
