The simulation uses the driftFluxFoam solver for a multiphase sludge settling problem in OpenFOAM.

The domain is a 2D rectangular channel with dimensions 8.65 m in the x-direction, 1 m in the y-direction, and 0.2 m in the z-direction (from -0.1 to 0.1).
The convertToMeters factor is 1.

The mesh uses two blocks: a lower section with 200x4x1 cells from y=0 to y=0.1, and an upper section with 200x36x1 cells from y=0.1 to y=1.
Simple grading of (1 1 1) is used in both blocks.

Boundary patches are: inlet, outlet, bottomWall, endWall, top, and frontAndBack.

Turbulence modeling uses RAS with the buoyantKEpsilon model.
Turbulence is enabled (RAS on, printCoeffs on).

Initial conditions (internal field) are as follows:
Velocity U is uniform (0.0191 0 0) m/s.
Sludge volume fraction alpha.sludge is uniform 0.001.
Turbulent kinetic energy k is uniform 0.00015 m2/s2.
Turbulent dissipation rate epsilon is uniform 1.50919e-06 m2/s3.
Pressure p_rgh is uniform 0.

Boundary conditions for U:
inlet uses fixedValue with value uniform (0.0191 0 0).
outlet uses pressureInletOutletVelocity with value uniform (0 0 0).
bottomWall uses noSlip.
endWall uses noSlip.
top uses slip.
frontAndBack uses empty.

Boundary conditions for p_rgh:
inlet uses fixedFluxPressure with value uniform 0.
outlet uses fixedValue with value uniform 0.
bottomWall uses fixedFluxPressure with value uniform 0.
endWall uses fixedFluxPressure with value uniform 0.
top uses fixedFluxPressure with value uniform 0.
frontAndBack uses empty.

inlet uses fixedValue with value uniform 0.001.

endWall uses zeroGradient.

frontAndBack uses empty.

Boundary conditions for k:

The continuous phase is water with a Newtonian transport model, constant kinematic viscosity nu = 1.7871e-06 m2/s, and density rho = 996 kg/m3.

The dispersed phase is sludge with density rho = 1996 kg/m3.
The sludge does not use a Newtonian viscosity model; it uses only the BinghamPlastic mixture viscosity model.

The mixture viscosity model is BinghamPlastic with the following parameters:
coeff is 0.00023143.
exponent is 179.26.
BinghamCoeff is 0.0005.
BinghamExponent is 179.26.
BinghamOffset is 0.
muMax is 0.1.

The relative velocity model is simple with V0 = (0 -2.241e-4 0) and residualAlpha = 0.

Gravity is (0 -9.81 0) m/s2.

The solution algorithm is PIMPLE with 3 correctors (nCorrectors 3).
nNonOrthogonalCorrectors is set to 1.
nOuterCorrectors is set to 1.

Time stepping is adjustable with initial deltaT = 0.1 s.
Maximum Courant number is 5.
Maximum alphaCourant number is 5.
The simulation runs from startTime 0 to endTime 6400 seconds.
Results are written every 50 time units using writeControl timeStep is not used; writeControl is set to adjustableRunTime and writeInterval is 50.

Numerical schemes are as follows:
ddtSchemes default uses Euler.
gradSchemes default uses Gauss linear.
divSchemes div(phi,alpha.sludge) uses Gauss vanLeer.
divSchemes div(phirb,alpha.sludge) uses Gauss vanLeer.
divSchemes div(phi,U) uses Gauss linearUpwindV grad(U).
divSchemes div(phi,k) uses Gauss upwind.
divSchemes div(phi,epsilon) uses Gauss upwind.
divSchemes div(((rho*nuEff)*dev2(T(grad(U))))) uses Gauss linear.
laplacianSchemes default uses Gauss linear corrected.
interpolationSchemes default uses linear.
snGradSchemes default uses corrected.

The fvSolution file uses solvers as follows:
alpha.sludge uses smoothSolver with smoother symGaussSeidel, tolerance 1e-8, relTol 0.
p_rgh uses GAMG with smoother GaussSeidel, tolerance 1e-8, relTol 0.01.
p_rghFinal uses GAMG with smoother GaussSeidel, tolerance 1e-8, relTol 0.
U uses smoothSolver with smoother symGaussSeidel, tolerance 1e-6, relTol 0.1.
UFinal uses smoothSolver with smoother symGaussSeidel, tolerance 1e-6, relTol 0.
k uses smoothSolver with smoother symGaussSeidel, tolerance 1e-6, relTol 0.1.
kFinal uses smoothSolver with smoother symGaussSeidel, tolerance 1e-6, relTol 0.
epsilon uses smoothSolver with smoother symGaussSeidel, tolerance 1e-6, relTol 0.1.
epsilonFinal uses smoothSolver with smoother symGaussSeidel, tolerance 1e-6, relTol 0.
