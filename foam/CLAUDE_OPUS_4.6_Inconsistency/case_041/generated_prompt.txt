Set up a 2D transient simulation of laminar, incompressible flow past a cylinder using OpenFOAM to capture the von Kármán vortex street.

The domain is a rectangular channel 2.2 m long and 0.41 m high.
A cylinder of diameter 0.1 m is centered at (0.2, 0.2).
The mesh is one cell thick in the z-direction.
The Reynolds number is 100.
The kinematic viscosity is 1e-3 m²/s.
The uniform inlet velocity is U = (1 0 0) m/s.

In system/controlDict, set the solver (application) to pimpleFoam.
Set startTime to 0.
Set endTime to 8.
Set deltaT to 0.005.
Set writeControl to adjustableRunTime.
Set writeInterval to 0.1.
Enable adjustTimeStep by setting it to yes.
Set maxCo to 0.9.
Set maxDeltaT to 0.01 as a reasonable upper bound to prevent excessively large time steps.

In the 0/ directory, configure boundary conditions for U as follows.
Set inlet to fixedValue uniform (1 0 0).
Set outlet to zeroGradient.
Set cylinderWall to noSlip.
Set topAndBottom to noSlip.
Set frontAndBack to empty.

In the 0/ directory, configure boundary conditions for p as follows.
Set inlet to zeroGradient.
Set outlet to fixedValue uniform 0.
Set cylinderWall to zeroGradient.
Set topAndBottom to zeroGradient.
Set frontAndBack to empty.

Run the simulation as a transient case to capture periodic vortex shedding behind the cylinder.
The final result is the time-evolving flow field over the 8-second duration, written every 0.1 seconds of physical time.
