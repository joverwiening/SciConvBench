The simulation is a 2D dam break case using the interFoam solver for a two-phase water-air system.

The domain is 2m long (x-direction), 1m high (y-direction), and one cell thick in the z-direction (e.g., 0 to 0.01m).

In blockMeshDict, the mesh resolution is 100 cells in x and 50 cells in y, with 1 cell in z.

In blockMeshDict, the patches are defined as follows: leftWall is type wall, rightWall is type wall, bottomWall (floor) is type wall, topBoundary (atmosphere) is type patch, and frontAndBack is type empty.

Gravity is defined in constant/g as (0 -9.81 0).

For the velocity field U in the 0 directory: leftWall, rightWall, and bottomWall use noSlip. topBoundary uses pressureInletOutletVelocity with a uniform value of (0 0 0). frontAndBack uses empty. The internal field is uniform (0 0 0).

For the pressure field p_rgh in the 0 directory: leftWall, rightWall, and bottomWall use fixedFluxPressure with a value of uniform 0. topBoundary uses totalPressure with p0 uniform 0. frontAndBack uses empty. The internal field is uniform 0.

For the phase fraction field alpha.water in the 0 directory: leftWall, rightWall, and bottomWall use zeroGradient. topBoundary uses inletOutlet with inletValue uniform 0 and value uniform 0. frontAndBack uses empty. The internal field is uniform 0.

The initial water column is defined using setFieldsDict. The default field value for alpha.water is 0 (air everywhere). A boxToCell region from (0 0 0) to (0.5 0.5 0.01) sets alpha.water to 1 (water). This represents a water column 0.5m wide and 0.5m high at the left side of the domain.

In transportProperties, water (phase1) has density 1000 kg/m3 and kinematic viscosity 1e-06 m2/s. Air (phase2) has density 1 kg/m3 and kinematic viscosity 1.48e-05 m2/s. The surface tension between the phases is 0.07 N/m.

In controlDict, the end time is 1 second. Adjustable time stepping is enabled with an initial deltaT of 0.001s, a maxDeltaT of 1, a maxCo of 1, and a maxAlphaCo of 1. The write interval is 0.05 seconds. The run time modifiable flag is set to yes.

The turbulence model is laminar.

The solver is interFoam.

The numerical schemes in fvSchemes follow the standard interFoam dam break tutorial defaults: Euler for ddtSchemes, Gauss linear for gradSchemes, and appropriate divergence schemes for the phase fraction and velocity (Gauss vanLeer for alpha and Gauss limitedLinearV 1 for velocity).

The fvSolution file uses GAMG for pressure and smoothSolver with symGaussSeidel for velocity and alpha, following the standard PIMPLE algorithm settings with nOuterCorrectors 1, nCorrectors 3, and nNonOrthogonalCorrectors 0.
