The simulation uses solidDisplacementFoam to model transient elastic wave propagation in a solid aluminum block.

The domain is a rectangular block of dimensions 1.0 m x 0.1 m x 0.1 m.

The material properties are: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, density rho = 2700 kg/m^3.

The simulation runs as a full 3D case with no plane strain or plane stress simplification, since the geometry is a three-dimensional block.

The mesh is generated using blockMesh with 500 cells in the x-direction, 5 cells in the y-direction, and 5 cells in the z-direction, giving a uniform cell size of 0.002 m in x and 0.02 m in y and z. This resolution is chosen to adequately resolve the propagating wavefront along the long axis.

The longitudinal (P-wave) speed in aluminum with these properties is approximately 6198 m/s. The transverse (S-wave) speed is approximately 3122 m/s.

The total simulation end time is 2e-4 s, which is sufficient for the P-wave to traverse the full 1.0 m domain.

The time step is 2e-7 s, chosen so that the Courant number based on the P-wave speed and the 0.002 m cell size is approximately 0.62, which is below 1.0 for stability.

The time integration scheme is Euler (first-order implicit) specified in system/fvSchemes under ddtSchemes.

The initial displacement field D is set using setFields. A thin region from x = 0 to x = 0.01 m (5 cells thick) is initialized with D = (1e-6 0 0). The rest of the domain is initialized with D = (0 0 0).

In system/setFieldsDict, the region is defined using a boxToCell source selecting cells with coordinates from (0 0 0) to (0.01 0.1 0.1).

The boundary condition for D on all six external faces is tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0, representing traction-free surfaces.

In system/controlDict, the application is solidDisplacementFoam.

In system/controlDict, deltaT is 2e-7, endTime is 2e-4, writeControl is timeStep, and writeInterval is 100, resulting in output approximately every 2e-5 s and roughly 10 output frames over the simulation.

The writeFormat is ascii. The writePrecision is 6. The writeCompression is uncompressed.

In constant/mechanicalProperties, the mechanical properties are specified as: rho with dimensions [1 -3 0 0 0 0 0] and value 2700, E with dimensions [1 -1 -2 0 0 0 0] and value 70e9, and nu with dimensions [0 0 0 0 0 0 0] and value 0.33. The planeStress entry is set to no.

In system/fvSchemes, ddtSchemes default is Euler, gradSchemes default is leastSquares, divSchemes default is none, laplacianSchemes default is Gauss linear corrected, and interpolationSchemes default is linear. snGradSchemes default is corrected.

In system/fvSolution, the solver for D uses GAMG with tolerance 1e-06 and relTol 0.01.

The velocity field is not solved; solidDisplacementFoam solves only for the displacement field D.
