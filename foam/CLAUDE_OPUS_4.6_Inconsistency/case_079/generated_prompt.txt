Perform a transient simulation of Rayleigh-Bénard convection using the buoyantPimpleFoam solver in OpenFOAM.

The domain is a 2D rectangle with width 0.1 m and height 0.025 m, giving an aspect ratio of 4:1.
The domain is one cell deep in the z-direction to enforce 2D behavior, with empty boundary conditions on the front and back patches.

The mesh resolution is 200 cells in the x-direction and 50 cells in the y-direction (uniform spacing), with 1 cell in the z-direction.

The bottom wall is held at a fixed temperature of 305 K.
The top wall is held at a fixed temperature of 295 K.
The left and right side walls are adiabatic (zeroGradient for temperature).
All four walls (top, bottom, left, right) use no-slip conditions for velocity (fixedValue uniform (0 0 0)).
Pressure uses fixedFluxPressure on all walls.
The front and back patches use the empty boundary condition for all fields.

The initial temperature field is set to a linear gradient from 305 K at the bottom to 295 K at the top, with a small random perturbation of magnitude 0.1 K added to seed the onset of convection.
The initial velocity field is uniform at (0 0 0).
The initial pressure field is uniform at 1e5 Pa.

The fluid is water with the following thermophysical properties set in constant/thermophysicalProperties.
The thermoType uses hePsiThermo as the base type.
The equationOfState is Boussinesq.
The Boussinesq reference temperature T0 is 300 K.
The Boussinesq thermal expansion coefficient beta is 2.07e-4 1/K.
The reference density rho0 is 998.0 kg/m3.
The specific heat capacity Cp is 4182 J/(kg·K).
The dynamic viscosity mu is 1.003e-3 Pa·s.
The thermal conductivity kappa is 0.598 W/(m·K).
The Prandtl number is approximately 7.0.

The turbulence model is set to laminar in constant/momentumTransport (or constant/turbulenceProperties), as the Rayleigh number for this configuration is moderate and the flow is expected to be in the laminar convection regime.

In system/fvSchemes, the time derivative scheme is Gauss Euler implicit (ddt default Euler).
The gradient scheme is Gauss linear.
The divergence scheme for velocity is div(phi,U) Gauss upwind.
The divergence scheme for temperature is div(phi,T) Gauss linear.
All other required divergence terms use Gauss upwind as a safe default.
The Laplacian schemes use Gauss linear corrected.
The interpolation scheme is linear.
The snGrad scheme is corrected.

In system/fvSolution, the PIMPLE algorithm is used with 2 outer correctors and 1 non-orthogonal corrector.
The pressure equation is solved using GAMG with a GaussSeidel smoother and tolerance of 1e-6.
The velocity and temperature equations are solved using PBiCGStab with DILU preconditioner and tolerance of 1e-7.

The simulation uses adjustable time stepping with a maximum Courant number of 0.5.
The initial time step is 0.001 s.
The maximum time step is 0.1 s.
The simulation end time is 200 s, which is sufficient for the convection cells to develop and reach a statistically steady state.
Data is written every 1 s of simulation time.
