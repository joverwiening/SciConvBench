The solver is rhoCentralFoam, a density-based compressible transient solver.

The domain is a 3D rectangular box from (0, 0, 0) to (4.1, 1, 0.1).

The mesh has 60 cells in x, 30 cells in y, and 1 cell in z, created with blockMesh as a single hex block with uniform grading.

The front and back patches (z-normal faces) are of type empty.

The left patch (x=0) is named inlet.
The right patch (x=4.1) is named outlet.
The top patch (y=1) is named top and is a wall.
The bottom patch (y=0) is named bottom and is a symmetryPlane.

The momentum transport model is laminar (no turbulence model).

The thermophysical model uses the hePsiThermo type with a pureMixture, perfectGas equation of state, hConst transport, and sensibleInternalEnergy energy form.

The molecular weight is 11640.3 kg/kmol.
Cp is 2.5 J/(kg·K).
Hf is 0.
Cv is derived from Cv = Cp - R/M, where R = 8314.46 J/(kmol·K), giving Cv = 2.5 - 8314.46/11640.3 = 2.5 - 0.71426 = 1.78574 J/(kg·K).
The Prandtl number Pr is 1.
The dynamic viscosity mu is 0.

Initial conditions for all internal fields: U = (2.9 0 0), p = 1, T = 1.

Inlet boundary conditions: U is fixedValue (2.9 0 0), p is fixedValue 1, T is fixedValue 1.

Top wall boundary conditions: U is fixedValue (2.61933 -0.50632 0), p is zeroGradient, T is fixedValue 1.25853.

Outlet boundary conditions: U is zeroGradient, p is zeroGradient, T is zeroGradient.

Bottom symmetryPlane boundary conditions: U is symmetryPlane, p is symmetryPlane, T is symmetryPlane.

Front and back boundary conditions: U is empty, p is empty, T is empty.

The time step deltaT is 0.0025.
The end time is 10.
The write control is writeControl adjustableRunTime with writeInterval 1 (writing solution every 1 second of simulation time).

The time discretization scheme (ddtSchemes default) is Euler.
The gradient schemes (gradSchemes default) are Gauss linear.
The divergence schemes use Gauss vanLeer for div(phi,U), div(phi,e), and div(phi,K), and Gauss linear for div(phid,p). The default divSchemes entry is none.
The Laplacian schemes (laplacianSchemes default) are Gauss linear corrected.
The interpolation schemes (interpolationSchemes default) are linear.
The surface normal gradient schemes (snGradSchemes default) are corrected.
The flux calculation is yes for fluxRequired with p.

The linear solver for p uses smoothSolver with symGaussSeidel smoother, tolerance 1e-06, and relTol 0.
The linear solvers for U, e, and h use smoothSolver with symGaussSeidel smoother, tolerance 1e-06, and relTol 0.
