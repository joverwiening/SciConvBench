Simulate the mixing of a non-Newtonian sludge with water in a 2D tank using the `interFoam` solver. The two phases are 'water' and 'sludge'. The sludge is a Bingham plastic. The simulation setup requires a `transportProperties` file that defines the properties for both phases. The dictionary should be configured as follows to correctly model the Bingham plastic sludge:

phases (water sludge);

water
{
    transportModel Newtonian;
    nu              1e-6;
    rho             1000;
}

sludge
{
    transportModel BinghamPlastic;
    rho             1500;
    tau0            15;
    mu0             0.1;
    muInf           0.01;
}

sigma 0.07;
