The simulation is a transient, compressible, turbulent flow over a heated 2D cylinder using OpenFOAM.

SOLVER
Use rhoPimpleFoam as the solver.

GEOMETRY
The cylinder diameter is 0.01 m (10 mm).
The domain is 2D, enforced using the empty boundary condition on the front and back patches.
The outer domain extends 20 diameters (0.2 m) from the cylinder center in all directions.
The domain shape is a rectangular outer boundary surrounding the cylinder.

MESH
Use blockMesh with an O-grid topology around the cylinder.
The first cell height at the cylinder wall gives y+ of approximately 1 to resolve the boundary layer for the k-omega SST model without wall functions.
Use approximately 200 cells around the cylinder circumference.
Use approximately 100 cells in the radial direction with a grading ratio that clusters cells near the wall.
The mesh is one cell thick in the spanwise (z) direction for the 2D setup.

TURBULENCE MODEL
Use the k-omega SST model specified in constant/turbulenceProperties.
Set RAS model type to kOmegaSST.
Set turbulence on and printCoeffs on.

THERMOPHYSICAL PROPERTIES (constant/thermophysicalProperties)
thermoType uses type hePsiThermo, mixture pureMixture, transport sutherland, thermo janaf, equationOfState perfectGas, specie specie, energy sensibleEnthalpy.
The mixture dictionary contains three sub-dictionaries only: specie, thermodynamics, and transport.
specie contains molWeight 28.9.
thermodynamics contains Cp 1005 and Hf 0.
transport contains As 1.458e-06 and Ts 110.4.
No BoussinesqCoeffs block is included.

BOUNDARY CONDITIONS
The inlet patch is set to fixedValue for velocity at (10 0 0) m/s, fixedValue for temperature at 300 K, fixedValue for pressure at 101325 Pa, and appropriate turbulent inlet values for k and omega estimated from 1% turbulence intensity and a turbulent length scale of 0.0007 m (7% of diameter).
The outlet patch uses waveTransmissive or advective conditions for pressure, and inletOutlet for velocity, temperature, k, and omega.
The cylinder wall patch uses fixedValue for temperature at 500 K, noSlip for velocity, zeroGradient for pressure, fixedValue of 0 for k (or kLowReWallFunction), and omegaWallFunction for omega.
The top and bottom far-field boundaries use the same conditions as the inlet or use freestream conditions.
The front and back patches use the empty boundary condition for the 2D simulation.

INITIAL CONDITIONS
Initialize velocity to (10 0 0) m/s throughout the domain.
Initialize temperature to 300 K throughout the domain.
Initialize pressure to 101325 Pa throughout the domain.
Initialize k and omega consistent with the inlet turbulence values.

TIME CONTROL (system/controlDict)
The time step is 1e-06 s, chosen to keep the maximum Courant number below 1.
The end time is 0.05 s, providing sufficient flow-through times for transient development (approximately 50 flow-through times based on domain length and freestream velocity).
Use adjustable time stepping with a maximum Courant number of 0.9.
Write interval is set to output approximately 100 time snapshots over the simulation.

NUMERICAL SCHEMES (system/fvSchemes)
Time discretization uses backward (second-order implicit).
Gradient schemes use Gauss linear.
Divergence schemes use Gauss linearUpwind for velocity, energy, k, and omega (second-order with upwind blending for stability).
Laplacian schemes use Gauss linear corrected.
Interpolation schemes use linear.
Surface normal gradient schemes use corrected.

SOLUTION CONTROLS (system/fvSolution)
Use the PIMPLE algorithm with 2 outer correctors and 1 non-orthogonal corrector.
Use 2 pressure corrector steps per outer loop.
Pressure solver uses GAMG with GaussSeidel smoother and tolerance 1e-06.
Velocity, energy, k, and omega solvers use smoothSolver with GaussSeidel smoother and tolerance 1e-08.
Relaxation factors for intermediate PIMPLE iterations are 0.7 for velocity and turbulence quantities and 0.3 for pressure, with final iteration relaxation factors of 1.0.
