The solver is buoyantPimpleFoam for buoyancy-driven heat transfer in a 2D channel.

The channel dimensions are 1.0 m in length (x-direction) and 0.5 m in height (y-direction), which is a reasonable aspect ratio for natural convection studies.

The mesh resolution is 100 cells in the x-direction and 50 cells in the y-direction, with grading near the bottom and top walls to resolve thermal boundary layers (e.g., simpleGrading with a ratio of 4 toward both walls in the y-direction).

The geometry is defined in blockMeshDict as a single block with vertices spanning from (0 0 0) to (1 0.5 0.01), with one cell in the z-direction for the 2D setup.

The front and back patches are set to type empty for the 2D simulation.

The left and right boundaries are set to cyclic (periodic) boundary conditions for all fields, representing a horizontally periodic domain.

Gravity is set to (0 -9.81 0) in the constant/g file.

The working fluid is air, initialized at 300 K and 1 atm (101325 Pa), using thermophysical properties from the standard buoyantPimpleFoam air setup (perfectGas equation of state, hConst thermodynamics, const transport with Cp = 1005 J/(kg·K), mu = 1.831e-5 Pa·s, Pr = 0.705).

The turbulence model is laminar, as the Rayleigh number for this configuration (approximately 1e8 or below) is in the laminar-to-transitional regime and laminar is a standard starting assumption.

In 0/T, the bottomWall boundary condition is fixedValue uniform 400.
In 0/T, the topWall boundary condition is zeroGradient.
In 0/T, the left and right boundaries are cyclic.
In 0/T, the front and back boundaries are empty.
In 0/T, the internalField is uniform 300.

In 0/U, the bottomWall boundary condition is fixedValue uniform (0 0 0) for no-slip.
In 0/U, the topWall boundary condition is fixedValue uniform (0 0 0) for no-slip.
In 0/U, the left and right boundaries are cyclic.
In 0/U, the front and back boundaries are empty.
In 0/U, the internalField is uniform (0 0 0).

In 0/p_rgh, the bottomWall boundary condition is fixedFluxPressure with value uniform 0.
In 0/p_rgh, the topWall boundary condition is fixedFluxPressure with value uniform 0.
In 0/p_rgh, the left and right boundaries are cyclic.
In 0/p_rgh, the front and back boundaries are empty.
In 0/p_rgh, the internalField is uniform 0.

In 0/p, the bottomWall boundary condition is calculated with value uniform 101325.
In 0/p, the topWall boundary condition is calculated with value uniform 101325.
In 0/p, the left and right boundaries are cyclic.
In 0/p, the front and back boundaries are empty.
In 0/p, the internalField is uniform 101325.

The simulation end time is 20 seconds.
The time step is adjustable with an initial deltaT of 0.001 s.
The maximum Courant number is 0.5.
The maximum deltaT is 0.1 s.

The fvSchemes use Gauss linear for gradient schemes, Gauss linearUpwind for divergence schemes, Gauss linear corrected for Laplacian schemes, and linear for interpolation schemes.

The fvSolution uses GAMG solver for p_rgh and smoothSolver (GaussSeidel) for U, T, and other fields, with PIMPLE settings of nOuterCorrectors 2, nCorrectors 2, and nNonOrthogonalCorrectors 1.

Write results every 0.5 seconds using writeInterval in controlDict.
