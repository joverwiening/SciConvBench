The simulation is a steady-state, incompressible, turbulent flow simulation of the Pitz and Daily backward-facing step combustor geometry using the simpleFoam solver in OpenFOAM.

The geometry is 2D.

Use the standard Pitz-Daily tutorial mesh provided with OpenFOAM (blockMeshDict from the tutorials/incompressible/simpleFoam/pitzDaily case).

The turbulence modeling approach is RAS using the kEpsilon model.

The file constant/turbulenceProperties contains only the following:
simulationType RAS;
RAS block with RASModel set to kEpsilon, turbulence set to on, and printCoeffs set to on.
There is no LES block in this file.

Boundary conditions for velocity U:
inlet is a fixedValue with a uniform value of (10 0 0) m/s.
outlet is zeroGradient.
upperWall is a fixedValue with a uniform value of (0 0 0) (no-slip).
lowerWall is a fixedValue with a uniform value of (0 0 0) (no-slip).
frontAndBack patches are of type empty.

Boundary conditions for pressure p:
inlet is zeroGradient.
outlet is a fixedValue with a uniform value of 0.
upperWall is zeroGradient.
lowerWall is zeroGradient.
frontAndBack patches are of type empty.

Boundary conditions and initial values for turbulent kinetic energy k:
The internal field value is 0.375 m2/s2, estimated assuming a turbulence intensity of 5% at the inlet (k = 1.5 * (U * I)^2 = 1.5 * (10 * 0.05)^2 = 0.375).
inlet is a fixedValue with a uniform value of 0.375 m2/s2.
outlet is zeroGradient.
upperWall uses kqRWallFunction with a uniform value of 0.375 m2/s2.
lowerWall uses kqRWallFunction with a uniform value of 0.375 m2/s2.
frontAndBack patches are of type empty.

Boundary conditions and initial values for turbulent dissipation rate epsilon:
The internal field value is 14.855 m2/s3, estimated assuming a turbulent length scale of approximately 10% of the inlet step height (l = 0.00635 m, giving epsilon = Cmu^0.75 * k^1.5 / l, where Cmu = 0.09).
inlet is a fixedValue with a uniform value of 14.855 m2/s3.
outlet is zeroGradient.
upperWall uses epsilonWallFunction with a uniform value of 14.855 m2/s3.
lowerWall uses epsilonWallFunction with a uniform value of 14.855 m2/s3.
frontAndBack patches are of type empty.

Boundary conditions for turbulent viscosity nut:
The internal field value is calculated.
inlet is calculated with a uniform value of 0.
outlet is calculated with a uniform value of 0.
upperWall uses nutkWallFunction with a uniform value of 0.
lowerWall uses nutkWallFunction with a uniform value of 0.
frontAndBack patches are of type empty.

Numerical schemes in fvSchemes use standard settings consistent with the OpenFOAM simpleFoam Pitz-Daily tutorial:
ddtSchemes default is steadyState.
gradSchemes default is Gauss linear.
divSchemes div(phi,U) is bounded Gauss linearUpwind grad(U).
divSchemes div(phi,k) is bounded Gauss upwind.
divSchemes div(phi,epsilon) is bounded Gauss upwind.
divSchemes div(phi,R) is bounded Gauss upwind.
divSchemes div(R) is Gauss linear.
divSchemes div((nuEff*dev2(T(grad(U))))) is Gauss linear.
laplacianSchemes default is Gauss linear corrected.
interpolationSchemes default is linear.
snGradSchemes default is corrected.

Solution settings in fvSolution use standard settings consistent with the OpenFOAM simpleFoam Pitz-Daily tutorial:
p solver is GAMG with tolerance 1e-06, relTol 0.1, smoother GaussSeidel.
U, k, and epsilon solvers are smoothSolver with smoother symGaussSeidel, tolerance 1e-05, relTol 0.1.
SIMPLE block has nNonOrthogonalCorrectors set to 0 and residualControl with p at 1e-04 and U, k, and epsilon at 1e-04.
Relaxation factors are 0.3 for p and 0.7 for U, k, and epsilon.

The simulation runs for 500 iterations, set via endTime 500 and deltaT 1 in the controlDict, with startFrom startTime and startTime 0, writeControl timeStep, and a reasonable writeInterval such as 100.
