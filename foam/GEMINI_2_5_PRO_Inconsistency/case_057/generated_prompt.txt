The simulation is a 2D bubble column.
The solver is `twoPhaseEulerFoam`.
The column dimensions are 0.5m width and 2.0m height.
The continuous phase is water.
The dispersed phase is air.
The domain is initialized using `setFieldsDict`.
The default volume fraction for air (`alpha.air`) is 1.0.
The default volume fraction for water (`alpha.water`) is 0.0.
A box region from (0, 0, -0.1) to (0.5, 1.5, 0.1) is defined.
Inside this box region, the volume fraction for air (`alpha.air`) is set to 0.4.
Inside this box region, the volume fraction for water (`alpha.water`) is set to 0.6.
