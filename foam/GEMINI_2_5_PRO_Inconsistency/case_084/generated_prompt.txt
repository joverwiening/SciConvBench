The simulation is a transient two-phase Euler-Euler gas-solid riser simulation.
The solver to be used is twoPhaseEulerFoam.
The phases are defined as air for the gas phase and catalyst for the solid phase.
The riser geometry is a 2D rectangle with a height of 10 meters and a width of 0.1 meters.
The inlet boundary condition for the air volume fraction is a fixed value of 0.99.
The inlet boundary condition for the catalyst volume fraction is a fixed value of 0.01.
The inlet velocity for the air phase is a fixed value of 5.0 m/s in the vertical direction.
The inlet velocity for the catalyst phase is a fixed value of 5.0 m/s in the vertical direction.
The outlet boundary condition for pressure is a fixed value corresponding to atmospheric pressure (101325 Pa).
The wall boundary condition for both phase velocities is no-slip.
The density of the catalyst particles is 1500 kg/m^3.
The diameter of the catalyst particles is 75 micrometers.
The Gidaspow drag model will be used for the interphase momentum exchange.
