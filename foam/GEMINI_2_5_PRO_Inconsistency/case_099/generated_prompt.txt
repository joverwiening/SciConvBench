The simulation is a 2D, laminar, transient flow past a square cylinder in a channel.
The solver to be used is icoFoam.
The domain is 2.2m long and 0.41m high.
A 0.1m x 0.1m square cylinder is placed with its center at coordinates (0.2, 0.205).
The kinematic viscosity of the fluid is 0.001 m^2/s.
The mesh consists of 440 cells in the x-direction and 82 cells in the y-direction.
The simulation runs for a total of 8.0 seconds.
The time step deltaT is 0.002 seconds.
Simulation results are written to disk every 0.04 seconds.
The 'inlet' velocity boundary condition is a parabolic inflow profile with a maximum value of (1.5 0 0).
The 'inlet' pressure boundary condition is zeroGradient.
The 'outlet' velocity boundary condition is zeroGradient.
The 'outlet' pressure boundary condition is a fixedValue of 0.
The 'topAndBottomWalls' velocity boundary condition is noSlip.
The 'topAndBottomWalls' pressure boundary condition is zeroGradient.
The 'cylinder' velocity boundary condition is noSlip.
The 'cylinder' pressure boundary condition is zeroGradient.
The 'frontAndBack' patch type in the boundary file is set to empty.
The 'frontAndBack' boundary condition for all fields is set to empty.
