The simulation is a 2D, steady-state, incompressible, turbulent flow analysis.
The solver to be used is simpleFoam.
The turbulence model is k-omega SST.
The geometry is a NACA0012 airfoil at a 5-degree angle of attack.
The airfoil geometry is pre-rotated in the mesh file.
The mesh is a C-grid type, located in `constant/polyMesh`.
The mesh is one cell thick in the z-direction.
The kinematic viscosity of the fluid is 1.5e-5 m^2/s.
The simulation will run for 1000 iterations.
The boundary patch named `inlet` has a fixedValue velocity of (10 0 0).
The `inlet` patch has a zeroGradient pressure boundary condition.
The `inlet` patch turbulence kinetic energy `k` is calculated from a turbulence intensity of 1%.
The `inlet` patch specific dissipation rate `omega` is calculated from a viscosity ratio of 10.
The boundary patch named `outlet` has a fixedValue pressure of 0.
The `outlet` patch has an inletOutlet boundary condition for velocity `U`.
The `outlet` patch has an inletOutlet boundary condition for `k` and `omega`.
The boundary patch named `airfoil` has a noSlip boundary condition for velocity `U`.
The `airfoil` patch has a zeroGradient boundary condition for pressure `p`.
The `airfoil` patch uses the kqRWallFunction for `k`.
The `airfoil` patch uses the omegaWallFunction for `omega`.
The boundary patches named `frontAndBack` are of type `empty` in the `constant/polyMesh/boundary` file.
The field files for `U`, `p`, `k`, and `omega` have the `frontAndBack` patch boundary condition set to `empty`.
Standard second-order discretization schemes will be used in `system/fvSchemes`.
Standard solver settings and relaxation factors for simpleFoam will be used in `system/fvSolution`.
The simulation results will be written to disk every 100 iterations.
