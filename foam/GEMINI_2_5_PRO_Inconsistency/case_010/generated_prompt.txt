Perform a buoyant natural convection heat transfer simulation.
Use the buoyantFoam solver.
The simulation is transient.
Use the PIMPLE algorithm for the solution.
The turbulence model is Large Eddy Simulation (LES) with the Smagorinsky subgrid scale model.
The domain is a rectangular room with dimensions 4m in length (x), 3m in height (y), and 1.6m in width (z).
The convertToMeters factor is 1.
A structured mesh of 40 cells in x, 20 cells in y, and 60 cells in z is used.
The mesh is generated to define distinct patches for the inlet, outlet, and walls.
The inlet is located on the front face (x=0) spanning 0.25≤y≤0.75 and 1.1≤z≤1.3.
The outlet is located on the top face (y=3) spanning 1.75≤x≤2.25 and 0.3≤z≤0.5.
All other boundary faces are defined as walls.
The inlet velocity is a fixed value of (0.2 0 0) m/s.
The inlet temperature is a fixed value of 290K.
The outlet velocity condition is `pressureInletOutletVelocity`.
The outlet temperature condition is `zeroGradient`.
All wall boundaries have a no-slip velocity condition.
All wall boundaries have a fixed temperature of 302K.
The thermophysical model uses the Boussinesq approximation.
The reference density is 1 kg/m³.
The reference temperature is 300K.
The thermal expansion coefficient is 0.003 K⁻¹.
The dynamic viscosity is 1e-05 Pa·s.
The Prandtl number is 0.7.
The specific heat at constant pressure is 712 J/kg·K.
The gravitational acceleration vector is (0 -9.81 0) m/s².
The initial velocity field inside the domain is (0 0 0) m/s.
The initial temperature field inside the domain is 300K.
The simulation runs for a total time of 3000 seconds.
The time step is 1 second.
Results are written to file every 100 time steps.
