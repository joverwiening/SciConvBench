The simulation is a 2D steady-state analysis of natural convection.
The solver to be used is buoyantBoussinesqSimpleFoam.
The fluid is air.
Gravity is 9.81 m/s^2 and acts in the negative y-direction.
The cavity height is 0.4 meters.
The cavity width is 0.1 meters.
The mesh will have 40 cells in the x-direction.
The mesh will have 160 cells in the y-direction.
The target Rayleigh number is 1e5.
The Prandtl number is 0.71.
The kinematic viscosity is set to 1.035e-4 m^2/s to achieve the target Rayleigh number.
The temperature boundary condition for the left wall is a fixed value of 350 K.
The temperature boundary condition for the right wall is a fixed value of 300 K.
The temperature boundary condition for the top wall is zeroGradient.
The temperature boundary condition for the bottom wall is zeroGradient.
The velocity boundary condition for all walls is noSlip.
The pressure (p_rgh) boundary condition for all walls is fixedFluxPressure.
The initial condition for velocity is zero everywhere.
The initial condition for temperature is a uniform 325 K.
