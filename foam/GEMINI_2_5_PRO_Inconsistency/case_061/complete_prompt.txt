Set up a 2D lid-driven cavity flow in a 1 m × 1 m square domain, extruded one cell in z with `frontAndBack` as `empty`. Use a uniform mesh of 40 × 40 × 1 cells. Use an incompressible Newtonian fluid with `nu = 0.01 m^2/s` and run transient until a steady solution is reached.

Boundary conditions:
- `movingLid` (top): `0/U` is `fixedValue uniform (1 0 0)`
- `fixedWalls` (left, right, bottom): `0/U` is `noSlip`
- `0/p`: `zeroGradient` on all walls (set the pressure reference using `pRefCell` and `pRefValue` in `system/fvSolution`)
- `frontAndBack`: `empty`

In `system/controlDict`, set:
```foam
application     icoFoam;
```
