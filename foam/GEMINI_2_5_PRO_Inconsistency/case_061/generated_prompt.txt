The simulation domain is a 1 m by 1 m square, extruded one cell thick in the z-direction.
The mesh is a uniform 40 by 40 by 1 grid.
The fluid is incompressible and Newtonian.
The kinematic viscosity is 0.01 m^2/s.
The solver application is `icoFoam`.
The simulation is transient.
The simulation end time is 200 seconds.
The time step `deltaT` is 0.005 seconds.
Data is written every 10 seconds of simulation time.
The top boundary is named `movingLid`.
The velocity on the `movingLid` boundary is a fixed value of (1 0 0) m/s.
The left, right, and bottom boundaries are named `fixedWalls`.
The velocity on the `fixedWalls` boundaries is `noSlip`.
The front and back boundaries are of type `empty`.
The pressure boundary condition on all wall boundaries is `zeroGradient`.
The pressure reference cell `pRefCell` is 0.
The pressure reference value `pRefValue` is 0.
The time discretization scheme is `Euler`.
The gradient discretization scheme is `Gauss linear`.
The divergence discretization scheme is `Gauss linear`.
The Laplacian discretization scheme is `Gauss linear corrected`.
The interpolation scheme is `linear`.
The pressure field is solved with the PCG solver using a DIC preconditioner.
The pressure solver tolerance is 1e-6 and the relative tolerance is 0.05.
The velocity field is solved with the `smoothSolver` using a `symGaussSeidel` smoother.
The velocity solver tolerance is 1e-5 and the relative tolerance is 0.
