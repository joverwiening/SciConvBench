The simulation solver is pimpleFoam.
The simulation is transient, incompressible, and laminar.
The mesh is 2D, represented as a one-cell-thick 3D mesh.
The 'frontAndBack' patches in 'constant/polyMesh/boundary' are defined with 'type empty'.
The kinematic viscosity of the fluid is 0.001 m^2/s.
The cylinder diameter is 0.1 m.
The simulation end time is 10 seconds.
The time step is controlled automatically to maintain a maximum Courant number of 0.5.
Simulation results are written every 0.1 seconds.
The velocity boundary condition for the 'inlet' patch is a uniform fixed value of (1 0 0) m/s.
The velocity boundary condition for the 'outlet' patch is zero-gradient.
The velocity boundary condition for the 'cylinderWall' patch is no-slip.
The velocity boundary condition for the 'frontAndBack' patches is 'type empty'.
The pressure boundary condition for the 'inlet' patch is zero-gradient.
The pressure boundary condition for the 'outlet' patch is a uniform fixed value of 0.
The pressure boundary condition for the 'cylinderWall' patch is zero-gradient.
The pressure boundary condition for the 'frontAndBack' patches is 'type empty'.
The PIMPLE algorithm uses 2 outer correctors and 1 inner corrector.
The time derivative scheme is Euler.
Gradient and divergence schemes are second-order accurate.
