The simulation is a 2D steady-state analysis of Rayleigh-Bénard convection.
The solver to be used is `buoyantBoussinesqSimpleFoam`.
The geometry is a square cavity of 1 meter by 1 meter.
A uniform structured mesh of 100 cells in the x-direction and 100 cells in the y-direction will be used.
Gravity is enabled and set to 9.81 m/s^2 in the negative y-direction.
The k-omega SST turbulence model is enabled.
The fluid is air, modeled using the Boussinesq approximation.
The thermophysical properties are defined using `heRhoThermo`.
The reference density `rhoRef` is 1.176 kg/m^3.
The reference temperature `TRef` is 300 K.
The thermal expansion coefficient `beta` is 0.00333 1/K.
The dynamic viscosity `mu` is 1.8e-05 Pa.s.
The Prandtl number `Pr` is 0.7.
The bottom wall has a fixed temperature of 310 K.
The top wall has a fixed temperature of 290 K.
The side walls are adiabatic (zeroGradient temperature).
All walls have a no-slip boundary condition for velocity.
All boundaries use the `fixedFluxPressure` condition for `p_rgh`.
All walls use `kqRWallFunction` for `k` and `omegaWallFunction` for `omega`.
The simulation will run for 2000 iterations.
Standard second-order numerical schemes with upwinding for divergence terms will be used.
Standard solver settings and relaxation factors for steady-state RANS will be used.
