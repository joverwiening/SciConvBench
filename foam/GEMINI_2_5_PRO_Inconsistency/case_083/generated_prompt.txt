The simulation uses the `multiphaseEulerFoam` solver.
Initial field files are located in the `0/` directory.
The file `0/alpha.sediment` will have its `internalField` set to `uniform 0;`.
The file `0/alpha.water` will have its `internalField` set to `uniform 1;`.
The file `0/alpha.oil` will have its `internalField` set to `uniform 0;`.
These settings represent the default field conditions before the `setFields` utility is applied.
