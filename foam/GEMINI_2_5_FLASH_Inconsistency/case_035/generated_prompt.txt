The simulation will be configured as a 2D transient, incompressible, laminar flow past a cylinder using the pimpleFoam solver.
The mesh will be one cell thick.
The 'frontAndBack' patches in 'constant/polyMesh/boundary' will be defined with 'type symmetryPlane'.
In the '0/U' file, the boundary condition for 'frontAndBack' will be 'type empty;'.
In the '0/U' file, the boundary condition for 'inlet' will be 'type fixedValue; value uniform (1 0 0);'.
In the '0/U' file, the boundary condition for 'outlet' will be 'type zeroGradient;'.
In the '0/U' file, the boundary condition for 'cylinderWall' will be 'type fixedValue; value uniform (0 0 0);'.
In the '0/p' file, the boundary condition for 'frontAndBack' will be 'type empty;'.
In the '0/p' file, the boundary condition for 'inlet' will be 'type zeroGradient;'.
In the '0/p' file, the boundary condition for 'outlet' will be 'type fixedValue; value uniform 0;'.
In the '0/p' file, the boundary condition for 'cylinderWall' will be 'type zeroGradient;'.
The kinematic viscosity (nu) in the 'transportProperties' file will be set to 1e-5 m^2/s.
