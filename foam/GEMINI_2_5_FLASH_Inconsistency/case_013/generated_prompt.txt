Perform a dense particle fluidization simulation using the denseParticleFoam solver with Lagrangian particle tracking.
The computational domain is a rectangular column with dimensions 15 mm in the x-direction (from -7.5 mm to 7.5 mm), 150 mm in the y-direction (from -75 mm to 75 mm), and 450 mm in the z-direction (from 0 mm to 450 mm).
The convertToMeters factor for the domain definition is 0.001.
A structured mesh of 2 cells in the x-direction, 30 cells in the y-direction, and 90 cells in the z-direction will be used.
The blockMeshDict configuration is as follows:
FoamFile
{
    format      ascii;
    class       dictionary;
    object      blockMeshDict;
}
convertToMeters 0.001;
vertices
(
    (-7.5 -75   0)
    ( 7.5 -75   0)
    ( 7.5  75   0)
    (-7.5  75   0)
    (-7.5 -75 450)
    ( 7.5 -75 450)
    ( 7.5  75 450)
    (-7.5  75 450)
);
blocks
(
    hex (0 1 2 3 4 5 6 7) (2 30 90) simpleGrading (1 1 1)
);
boundary
(
    top
    {
        type wall;
        faces
        (
            (4 5 6 7)
        );
    }
    bottom
    {
        type wall;
        faces
        (
            (0 1 2 3)
        );
    }
    walls
    {
        type wall;
        faces
        (
            (0 1 5 4)
            (2 3 7 6)
        );
    }
    frontAndBack
    {
        type symmetry;
        faces
        (
            (1 2 6 5)
            (3 0 4 7)
        );
    }
);
Boundary conditions are set as follows: the 'bottom' patch has an interstitialInletVelocity of (0 0 1.875) m/s and fixedFluxPressure.
The 'top' patch has pressureInletOutletVelocity and a fixedValue pressure of 0 Pa.
The 'walls' patches have noSlip velocity and fixedFluxPressure.
The 'frontAndBack' patches are configured as symmetry.
Air phase properties include a density of 1.2 kg/m³ and a kinematic viscosity of 1e-05 m²/s, with laminar flow conditions.
Particles are initialized with a density of 2526 kg/m³ and a diameter of 0.0025 m.
Particles are injected manually from a cloudPositions file.
Particle wall interactions are modeled with rebound, using a coefficient of restitution of 0.97 and a friction coefficient of 0.09.
The PIMPLE algorithm is used with 1 outer corrector and 2 pressure correctors.
The Euler time integration scheme is employed.
The simulation runs from 0 to 0.02 seconds with a timestep of 2e-5 seconds.
Output data is generated at intervals of 0.01 seconds.
Gravity acceleration of -9.81 m/s² is included in the z-direction.
The ErgunWenYuDrag force model is used for particle-fluid interaction.
The pairCollision model is used for particle-particle collisions.
