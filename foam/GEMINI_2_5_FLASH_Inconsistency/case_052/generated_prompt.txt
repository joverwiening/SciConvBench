A 2D lid-driven cavity simulation will be set up using the `nonNewtonianIcoFoam` solver.
The cavity is a 1m x 1m square.
The top wall (lid) moves with a velocity of `(1 0 0)` m/s.
All other walls are stationary (`noSlip`).
The simulation is transient.
The fluid is a non-Newtonian, shear-thinning fluid.
The Power Law model will be used for the fluid properties.
The power-law index (n) is 0.5.
The consistency index (K) is 0.1.
In the `constant/transportProperties` file, `transportModel` will be set to `nonNewtonianPowerLaw`.
The mesh resolution will be 100 cells in the x-direction and 100 cells in the y-direction.
The initial time step (`deltaT`) for the transient simulation will be 0.005 seconds.
The end time for the transient simulation will be 10 seconds.
