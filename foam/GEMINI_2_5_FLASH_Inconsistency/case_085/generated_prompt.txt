A 2D steady-state simulation of Rayleigh-Bénard convection will be set up.
The computational domain is a square cavity of 1 meter by 1 meter.
The fluid is air.
The `buoyantBoussinesqSimpleFoam` solver will be used.
Gravity acts in the negative y-direction with a magnitude of 9.81 m/s^2.
The Boussinesq approximation will be used for density variations.
The reference temperature for the Boussinesq approximation is 300 K.
The reference density for the Boussinesq approximation is 1.176 kg/m^3.
The `thermoType` configuration in `constant/thermophysicalProperties` will be set as follows: `type heRhoThermo; mixture Boussinesq; transport const; thermo hConst; equationOfState Boussinesq; specie specie; energy sensibleEnthalpy;`.
The `mixture` configuration in `constant/thermophysicalProperties` will be set as follows: `specie { molWeight 28.9; } thermodynamics { Cp 1005; Hf 0; } transport { mu 1.8e-05; Pr 0.7; }`.
The bottom wall temperature is fixed at 310 K.
The top wall temperature is fixed at 290 K.
The side walls are adiabatic, with a zeroGradient boundary condition for temperature.
All walls have a noSlip boundary condition for velocity.
All boundaries have a fixedFluxPressure boundary condition for pressure p_rgh.
A laminar turbulence model will be used.
The initial velocity field will be set to (0 0 0) m/s.
The initial temperature field will be set to a uniform value of 300 K.
The mesh resolution for the square cavity will be 100 cells by 100 cells.
