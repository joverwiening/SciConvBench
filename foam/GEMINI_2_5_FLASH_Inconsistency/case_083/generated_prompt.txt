The simulation will use the `multiphaseEulerFoam` solver.
Initial field files are located in the `0/` directory.
For the default field condition, the `alpha.sediment` file will have `internalField uniform 0;`.
For the default field condition, the `alpha.water` file will have `internalField uniform 1;`.
For the default field condition, the `alpha.oil` file will have `internalField uniform 0;`.
The initial velocity field `U` will have `internalField uniform (0 0 0);`.
The initial pressure field `p_rgh` will have `internalField uniform 0;`.
These initial conditions represent the state before `setFields` is applied to create stratified layers.
