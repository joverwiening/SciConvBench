Simulate compressible air flow through a 2D converging–diverging nozzle.
The gas is a perfect gas.
Create a nozzle mesh with boundary patches named inlet, outlet, and nozzleWall.
The frontAndBack patches should be set as empty for 2D simulation.
Use constant/thermophysicalProperties with equationOfState perfectGas.
Use a temperature-dependent transport model, such as Sutherland.
The simulation will use the rhoCentralFoam solver.
The inlet boundary condition will specify a stagnation state.
The inlet total pressure will be 500000 Pa.
The inlet total temperature will be 300 K.
The outlet boundary condition will set the back pressure to 101325 Pa.
The outlet boundary condition will allow supersonic outflow if it develops.
The nozzle wall boundary condition will be an adiabatic no-slip wall.
The system/controlDict application will be rhoCentralFoam.
