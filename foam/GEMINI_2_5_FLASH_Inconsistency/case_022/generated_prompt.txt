Simulate a 2D lid-driven cavity flow.
Use the icoFoam solver.
The flow is transient, incompressible, and laminar.
The computational domain is a unit square, one cell thick in the z-direction.
The frontAndBack patches in the blockMeshDict file are defined with type empty.
The frontAndBack patches in the 0/U initial condition file are set to empty.
The top wall, named 'movingWall', moves at 1 m/s in the x-direction.
The other three walls, named 'fixedWalls', are stationary.
The mesh resolution is 100 cells in the x-direction.
The mesh resolution is 100 cells in the y-direction.
The simulation end time is 10 seconds.
The simulation time step size is 0.005 seconds.
