Simulate transient elastic wave propagation in a solid aluminum block.
The computational domain is 1.0 m in the x-direction, 0.1 m in the y-direction, and 0.1 m in the z-direction.
The material properties for aluminum are Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, and density rho = 2700 kg/m^3.
The simulation will use the `solidDisplacementFoam` solver.
The total simulation duration (endTime) is 0.001 seconds.
The maximum simulation time step (deltaT) is 2e-7 seconds.
The characteristic cell size (dx) for the mesh is 0.0025 m.
An initial displacement pulse is set using `setFields` by applying a displacement D = (1e-6 0 0) in a thin region near x = 0.
The initial displacement D is (0 0 0) elsewhere in the domain.
All external faces of the block have traction-free boundary conditions, implemented using `tractionDisplacement` with `traction uniform (0 0 0)` and `pressure uniform 0`.
