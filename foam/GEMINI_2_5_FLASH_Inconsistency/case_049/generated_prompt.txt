A 2D simulation of incompressible, laminar flow over an airfoil will be set up using the `simpleFoam` solver.
The mesh is extruded one cell in the z-direction.
The out-of-plane faces are named `frontAndBack`.
The airfoil surface is named `airfoil`.
The inlet boundary is named `inlet`.
The outlet boundary is named `outlet`.
The top and bottom boundaries of the computational domain are named `topAndBottom`.
In `constant/polyMesh/boundary`, the `frontAndBack` patch type is `empty`.
In `constant/polyMesh/boundary`, the `airfoil` patch type is `wall`.
In `constant/polyMesh/boundary`, the `inlet` patch type is `patch`.
In `constant/polyMesh/boundary`, the `outlet` patch type is `patch`.
In `constant/polyMesh/boundary`, the `topAndBottom` patch type is `patch`.
In `0/U`, the `frontAndBack` patch type is `empty`.
In `0/U`, the `airfoil` patch has a `noSlip` boundary condition.
In `0/U`, the `inlet` patch has a `fixedValue` boundary condition.
In `0/U`, the `outlet` patch has a `zeroGradient` boundary condition.
In `0/U`, the `topAndBottom` patch has a `slip` boundary condition.
In `0/p`, the `frontAndBack` patch type is `empty`.
In `0/p`, the `airfoil` patch has a `zeroGradient` boundary condition.
In `0/p`, the `inlet` patch has a `zeroGradient` boundary condition.
In `0/p`, the `outlet` patch has a `fixedValue` boundary condition.
In `0/p`, the `topAndBottom` patch has a `zeroGradient` boundary condition.
