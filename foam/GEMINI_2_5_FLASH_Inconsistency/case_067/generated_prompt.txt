Set up a steady-state simulation for laminar, incompressible flow over a backward-facing step using the simpleFoam solver.
The simulation is 2D, with front and back patches of type 'empty'.
The domain has an inlet on the left and an outlet on the right.
The fluid enters the domain at the 'inlet' patch and exits at the 'outlet' patch.
All other boundaries are walls with a no-slip condition.
The '0/U' file specifies the following boundary conditions:
The 'inlet' patch has a type of 'fixedValue' with a value of 'uniform (0.5 0 0)'.
The 'outlet' patch has a type of 'zeroGradient'.
The 'stepWall' patch has a type of 'noSlip'.
The 'topWall' patch has a type of 'noSlip'.
The 'frontAndBack' patch has a type of 'empty'.
The '0/p' file specifies the following boundary conditions:
The 'inlet' patch has a type of 'zeroGradient'.
The 'outlet' patch has a type of 'fixedValue' with a value of 'uniform 0'.
The 'stepWall' patch has a type of 'zeroGradient'.
The 'topWall' patch has a type of 'zeroGradient'.
The 'frontAndBack' patch has a type of 'empty'.
