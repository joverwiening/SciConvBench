Set up the classic 2D dam-break problem (water column collapsing into air with a sharp free surface). Use a 2D mesh extruded one cell in the spanwise direction with `frontAndBack` set to `empty`. Track the interface with the VOF field `alpha.water` and initialize the water column using `setFields` (e.g., set `alpha.water = 1` inside the initial column and `0` elsewhere). Set gravity to `(0 -9.81 0)`.

Use typical dam-break boundaries:
- tank walls: `noSlip` for `U`, `zeroGradient` for `p_rgh`, `zeroGradient` for `alpha.water`
- open top: `pressureInletOutletVelocity` for `U`, `totalPressure`/`fixedValue` (0) for `p_rgh`, and `inletOutlet` for `alpha.water` with `inletValue uniform 0`

In `system/controlDict`, set:
```foam
application     interFoam;
```
