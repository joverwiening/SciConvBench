The simulation models a classic 2D dam-break problem.
The solver used is interFoam.
The computational domain is 4 meters in length (x-direction), 2 meters in height (y-direction), and 0.1 meters in depth (z-direction).
The mesh is a 2D mesh extruded one cell in the spanwise (z) direction.
The frontAndBack boundary condition is set to empty.
The initial water column has a width of 1 meter (x-direction) and a height of 1 meter (y-direction).
The initial water column is located from x=0 to x=1 and y=0 to y=1.
The water column is initialized using setFields, setting alpha.water = 1 inside the column and 0 elsewhere.
The interface is tracked using the VOF field alpha.water.
Gravity is set to (0 -9.81 0).
For the tank walls (bottom, left, right boundaries), U uses noSlip, p_rgh uses zeroGradient, and alpha.water uses zeroGradient.
For the open top boundary, U uses pressureInletOutletVelocity, p_rgh uses totalPressure with a fixedValue of 0, and alpha.water uses inletOutlet with an inletValue uniform 0.
In system/controlDict, the application is set to interFoam.
