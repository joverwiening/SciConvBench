The simulation will use the icoFoam solver.
The mesh will be generated using blockMesh.
The simulation domain is 1 meter long, 0.1 meters high, and 0.01 meters deep.
The mesh will consist of 200 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.
The fluid density is 1 kg/m^3.
The fluid kinematic viscosity is 1e-6 m^2/s.
The inlet boundary condition for velocity is a uniform fixed value of (0.01 0 0) m/s.
The inlet boundary condition for pressure is zero gradient.
The outlet boundary condition for velocity is zero gradient.
The outlet boundary condition for pressure is a fixed value of 0 Pa gauge pressure.
The topWall boundary condition for velocity is a fixed value of (0 0 0) m/s (no-slip).
The topWall boundary condition for pressure is zero gradient.
The bottomWall boundary condition for velocity is a fixed value of (0 0 0) m/s (no-slip).
The bottomWall boundary condition for pressure is zero gradient.
The frontAndBack boundary condition for velocity is a fixed value of (0 0 0) m/s (no-slip).
The frontAndBack boundary condition for pressure is zero gradient.
The frontAndBack patches are defined as wall type in blockMeshDict.
The simulation models 2D laminar, incompressible flow.
