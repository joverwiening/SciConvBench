The simulation will set up a 2D lid-driven cavity flow.
The domain is a 1 m x 1 m square, extruded one cell in the z-direction.
The `frontAndBack` boundary condition is `empty`.
A uniform mesh of 40 x 40 x 1 cells will be used.
The fluid is an incompressible Newtonian fluid with a kinematic viscosity `nu = 0.01 m^2/s`.
The OpenFOAM solver `icoFoam` will be used.
The simulation will run transiently until a steady solution is reached.
A steady solution is defined as when the residuals for U and p drop below 1e-5, or when a maximum simulation time of 1000 seconds is reached.
The boundary condition for `0/U` on the `movingLid` (top) is `fixedValue uniform (1 0 0)`.
The boundary condition for `0/U` on the `fixedWalls` (left, right, bottom) is `noSlip`.
The boundary condition for `0/U` on `frontAndBack` is `empty`.
The boundary condition for `0/p` on all walls is `zeroGradient`.
The pressure reference is set using `pRefCell = 0` and `pRefValue = 0` in `system/fvSolution`.
The `application` in `system/controlDict` is `icoFoam`.
