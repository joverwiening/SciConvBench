Run a two-dimensional Rayleigh-Benard convection cell simulation using the buoyantFoam solver.
The simulation domain is 9 units wide and 1 unit tall.
The mesh resolution is 90 cells in the x direction, 10 cells in the y direction, and 1 cell in the z direction.
Gravity acts downward in the negative y direction with a magnitude of 9.81 m/s^2.
The reference state is air-like with a density of 1.0 kg/m^3, a reference temperature of 300 K, a thermal expansion coefficient of 3.3e-3 1/K, a kinematic viscosity of 1.5e-5 m^2/s, and a thermal diffusivity of 2.1e-5 m^2/s.
The temperature of the bottom wall is fixed at 305 K, and the top wall is fixed at 295 K.
The vertical side walls are adiabatic.
Apply no-slip velocity conditions on all solid walls.
Initialize the flow at rest with a uniform temperature field of 300 K.
Use the k-epsilon turbulence model.
Set constant/momentumTransport to simulationType RAS with model kEpsilon, turbulence on, and printCoeffs on.
In constant/physicalProperties, use heRhoThermo with equationOfState Boussinesq.
Set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714 in constant/physicalProperties.
In 0/k, set internalField uniform 1e-5 with kqRWallFunction on walls and empty front/back.
In 0/epsilon, set internalField uniform 1e-5 with epsilonWallFunction on walls and empty front/back.
In 0/nut, set internalField uniform 0 with nutkWallFunction on walls and empty front/back.
In 0/alphat, set internalField uniform 0 with compressible::alphatJayatillekeWallFunction on walls, Prt 0.85, and empty front/back.
In 0/U, set internalField uniform (0 0 0) with noSlip on all solid walls and empty on front/back.
In 0/T, set internalField uniform 300, bottom fixedValue 305, top fixedValue 295, sides zeroGradient, and front/back empty.
In 0/p, set internalField uniform 0 with walls calculated and front/back empty.
In 0/p_rgh, set internalField uniform 0 with walls fixedFluxPressure and front/back empty.
In system/fvSolution, set p_rgh and (U|e|k|epsilon) solvers to tolerance 1e-8 and relTol 0.01.
Set the corresponding *Final solvers to relTol 0 in system/fvSolution.
The simulation will run up to 1000 s of physical time.
Use a fixed timestep of 1 s.
