Run the pisoFoam cavity tutorial.
Set the Reynolds number to 5000.
Achieve the Reynolds number of 5000 by setting kinematic viscosity (nu) to 2e-4 m^2/s, characteristic length (L) to 1 m, and lid velocity (U_lid) to 1 m/s.
The simulation is 2D.
The cavity is a unit square domain with side length L=1m.
Use the RAS kEpsilon turbulence model.
Set the boundary condition for turbulent kinetic energy (k) on the moving lid (topWall) to kqRWallFunction.
Set the boundary condition for turbulent kinetic energy (k) on other walls to kqRWallFunction.
Set the boundary condition for turbulent kinetic energy (k) on frontAndBack to empty.
Set the boundary condition for turbulent dissipation rate (epsilon) on the moving lid (topWall) to epsilonWallFunction.
Set the boundary condition for turbulent dissipation rate (epsilon) on other walls to epsilonWallFunction.
Set the boundary condition for turbulent dissipation rate (epsilon) on frontAndBack to empty.
Set the initial condition for turbulent kinetic energy (k) to 1e-4.
Set the initial condition for turbulent dissipation rate (epsilon) to 1e-4.
Use a mesh resolution of 100x100x1 cells.
