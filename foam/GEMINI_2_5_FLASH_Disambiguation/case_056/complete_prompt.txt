Simulate a 2D incompressible laminar lid-driven cavity flow using the icoFoam solver.
GEOMETRY: The domain is a square cavity of size 0.1m x 0.1m x 0.01m.
MESH: Use blockMesh to create a uniform Cartesian mesh of 20x20x1 cells. The patches should be named 'movingWall' (top), 'fixedWalls' (left, bottom, right), and 'frontAndBack' (front and back).
PHYSICAL PROPERTIES: Set the kinematic viscosity 'nu' to 0.01 m^2/s in 'constant/transportProperties'.
INITIAL CONDITIONS (in '0' directory): Initialize the pressure 'p' field to uniform 0. Initialize the velocity 'U' field to uniform (0 0 0).
BOUNDARY CONDITIONS (in '0/U' and '0/p'):
- movingWall: U is fixedValue uniform (1 0 0); p is zeroGradient.
- fixedWalls: U is fixedValue uniform (0 0 0); p is zeroGradient.
- frontAndBack: type 'empty' for both U and p.
TIME CONTROLS (in 'system/controlDict'):
- solver: icoFoam
- startTime: 0
- endTime: 0.5
- deltaT: 0.0005
- writeControl: timeStep
- writeInterval: 20
