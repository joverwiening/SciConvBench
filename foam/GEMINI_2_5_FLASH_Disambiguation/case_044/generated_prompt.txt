The simulation is a 2D turbulent buoyant cavity simulation.
The k-epsilon turbulence model is used.
The Rayleigh number is approximately 1e6.
The cavity dimensions are 0.10 m by 0.10 m.
Gravity acts in the (0 -9.81 0) direction.
The fluid properties are kinematic viscosity (nu) = 1.5e-5 m^2/s, Prandtl number (Pr) = 0.71, thermal expansion coefficient (beta) = 3.33e-3 1/K, reference temperature (T0) = 298 K, and reference density (rho0) = 1.0 kg/m^3.
The thermal boundary condition for the hotWall is a fixed temperature of 303 K.
The thermal boundary condition for the coldWall is a fixed temperature of 293 K.
The thermal boundary condition for the topWall is a zeroGradient.
The thermal boundary condition for the bottomWall is a zeroGradient.
The velocity boundary condition for the hotWall is noSlip.
The velocity boundary condition for the coldWall is noSlip.
The velocity boundary condition for the topWall is noSlip.
The velocity boundary condition for the bottomWall is noSlip.
