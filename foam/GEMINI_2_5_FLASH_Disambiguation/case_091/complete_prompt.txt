Problem: 2D natural convection in a differentially heated square cavity (Lid-driven cavity setup adapted for buoyancy).
Solver: buoyantPimpleFoam
Geometry: A square domain of 0.1m x 0.1m. The simulation is 2D, enforced by using a single cell in the z-direction with 'empty' boundary conditions on the front and back patches.
Mesh: A uniform Cartesian mesh of 40x40 cells created with blockMesh. (vertices: (0 0 0), (0.1 0 0), (0.1 0.1 0), (0 0.1 0)).
Turbulence Model: Laminar flow. In constant/momentumTransport, set 'simulationType laminar;'.
Physical Properties: The fluid is air, treated as an ideal gas. In constant/thermophysicalProperties, use 'thermoType hePsiThermo;', 'mixture pureMixture;', 'transport sutherland;', 'thermo janaf;', 'equationOfState perfectGas;'. Set molWeight to 28.9 kg/kmol.
Gravity: Standard earth gravity acting in the negative y-direction, specified in constant/g as 'g (0 -9.81 0);'.
Boundary Conditions:
- leftWall (hot): T = fixedValue 313.15 K (40 C); U = noSlip (0 0 0).
- rightWall (cold): T = fixedValue 293.15 K (20 C); U = noSlip (0 0 0).
- topWall & bottomWall (adiabatic): T = zeroGradient; U = noSlip (0 0 0).
- p_rgh: fixedFluxPressure with value uniform 0 on all walls.
Initial Conditions: The entire domain is initialized with a quiescent fluid (U = (0 0 0)) at the average temperature (T = 303.15 K) and uniform pressure (p_rgh = 0).
Time Controls: Run a transient simulation for 200 seconds. Use an adjustable time step with an initial deltaT of 0.005s and a maximum Courant number (maxCo) of 0.5. Write results every 20 seconds.
