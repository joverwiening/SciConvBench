Set up a 2D lid-driven cavity simulation for a non-Newtonian, shear-thinning fluid using the nonNewtonianIcoFoam solver.
The cavity is a 1m x 1m square domain.
The top wall (lid) moves with a velocity of (1 0 0) m/s.
All other walls are stationary with noSlip boundary conditions.
The simulation is transient.
Use a mesh resolution of 100x100 cells for adequate resolution of boundary layers and flow features.
In the constant/transportProperties file, define the fluid properties with transportModel PowerLaw.
Set nuMax to 1 m²/s.
Set nuMin to 1e-6 m²/s.
Set k to 0.1.
Set n to 0.5.
The Power Law model will provide shear-thinning behavior where viscosity decreases with increasing shear rate.
Use appropriate initial conditions with zero velocity throughout the domain.
Set up proper boundary conditions for pressure with zeroGradient on walls and fixedValue or zeroGradient on one boundary for pressure reference.
