Simulate transient cooling of a hot block in a 2D sealed room using the compressible solver buoyantPimpleFoam.
Create a 5 m × 3 m room geometry extruded one cell in the z-direction with frontAndBack boundary condition set to empty.
Position a 0.5 m × 0.5 m hot block at the bottom center of the room (centered horizontally at x = 2.5 m, positioned at the bottom with its base at y = 0).
Initialize the hot block temperature to 400 K.
Initialize the surrounding air temperature to 300 K.
Set all walls to adiabatic boundary conditions using zeroGradient for temperature T.
Set all walls to noSlip boundary condition for velocity U.
Set gravity vector to (0 -9.81 0).
Configure thermophysicalProperties with thermoType using hePsiThermo type, pureMixture mixture, sutherland transport, janaf thermo, Boussinesq equationOfState, specie specie, and sensibleEnthalpy energy.
Run the transient simulation to observe natural convection cooling of the hot block.
