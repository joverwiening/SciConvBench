Run a 2D inviscid laminar oblique-shock simulation using OpenFOAM.
Create a rectangular domain from (0, 0, 0) to (4.1, 1, 0.1) extruded one cell in the z-direction.
Use a mesh with 60x30x1 cells.
Set frontAndBack patches as empty boundary type.
Apply inlet boundary condition to the left face.
Apply outlet boundary condition to the right face.
Apply wall boundary condition to the top face.
Apply symmetryPlane boundary condition to the bottom face.
Use rhoCentralFoam solver for the simulation.
Set momentum transport model to laminar.
Use ideal gas properties with Cp=2.5, Pr=1, and viscosity=1e-5.
Set molecular weight to 11640.3 and heat of formation Hf=0.
Initialize the flow field with velocity U=(2.9 0 0), pressure p=1, and temperature T=1.
Set inlet boundary conditions as velocity (2.9 0 0), pressure 1, and temperature T=1.
Set top wall boundary conditions as velocity (2.61933 -0.50632 0) and temperature T=1.25853.
Use deltaT=0.0025 for time stepping.
Run simulation until endTime=10.
Write results every writeInterval=1 time units.
Assume the simulation represents flow over a wedge with the oblique shock angle determined by the given top wall velocity components, creating an approximate 11-degree deflection angle based on the velocity ratio.
