Simulate turbulent airflow over a backward-facing step using simpleFoam with the kOmegaSST RANS model.
Set the inlet freestream velocity to 20 m/s.
The inflow is fully turbulent with turbulence intensity 5% and turbulent mixing length 0.005 m.
Use standard wall functions on walls and zeroGradient at the outlet for turbulence variables.
Set the computational domain dimensions to 20H x 10H where H is the step height.
Set the backward-facing step height H to 0.1 m.
Position the step at 5H downstream from the inlet.
Set the inlet boundary condition for k to fixedValue with uniform value 1.5.
Set the inlet boundary condition for omega to fixedValue with uniform value 447.2.
Use fixedValue uniform (20 0 0) for velocity at the inlet.
Use zeroGradient boundary conditions at the outlet for velocity, k, and omega.
Apply noSlip boundary condition on all wall surfaces.
Use nutUSpaldingWallFunction for nut on walls.
Use kqRWallFunction for k on walls.
Use omegaWallFunction for omega on walls.
Set the pressure outlet to fixedValue uniform 0.
Set the pressure inlet to zeroGradient.
