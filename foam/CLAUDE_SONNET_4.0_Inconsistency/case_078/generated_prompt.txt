Set up a simulation of airflow in a ventilated room with a heater using the steady-state solver buoyantSimpleFoam.
The room dimensions are 4 meters length, 3 meters width, and 2.5 meters height.
The heater is a rectangular wall patch of 1 meter width by 0.5 meter height, located on one wall at 0.5 meters above the floor, centered horizontally.
The inlet is a rectangular opening of 0.3 meters width by 0.2 meters height, located on the wall opposite to the heater, positioned 2 meters above the floor.
The outlet is a rectangular opening of 0.3 meters width by 0.2 meters height, located on the same wall as the heater, positioned 0.2 meters below the ceiling.
The heater wall patch uses fixedValue temperature boundary condition set to 320 K.
The inlet uses pressureInletVelocity boundary condition with inlet air temperature at 293 K.
The outlet uses zeroGradient boundary condition for velocity and fixedValue boundary condition for pressure.
All other walls use noSlip boundary condition for velocity and zeroGradient for temperature.
The simulation models natural convection driven by the heater.
In constant/thermophysicalProperties, specify thermoType heRhoThermo.
Set the equation of state as equationOfState Boussinesq with T0 293, beta 0.00341, and rho0 1.2.
Use transport model const with mu 1.8e-5 and Pr 0.71.
