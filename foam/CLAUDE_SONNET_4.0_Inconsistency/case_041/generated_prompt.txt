Set up a 2D laminar, incompressible flow simulation past a cylinder using OpenFOAM.
The domain is a rectangular channel 2.2m long and 0.41m high.
Place a cylinder with diameter 0.1m centered at coordinates (0.2, 0.2).
Target Reynolds number is 100 to observe the von Kármán vortex street.
Use kinematic viscosity of 1e-3 m²/s.
Set uniform inlet velocity to U = (1 0 0) m/s.
Create the mesh one cell thick in the z-direction using blockMesh with snappyHexMesh for cylinder geometry.
Use approximately 200 cells along the channel length and 80 cells along the height.
Refine the mesh around the cylinder with at least 40 cells around the circumference.
Set the solver as simpleFoam in system/controlDict.
Set startTime to 0.
Set endTime to 200.
Set deltaT to 1.
Set writeInterval to 10.
Configure boundary conditions in the 0/ directory for velocity U: inlet as fixedValue uniform (1 0 0), outlet as zeroGradient, cylinderWall as noSlip, topAndBottom walls as noSlip, frontAndBack patches as empty.
Configure boundary conditions for pressure p: inlet and cylinderWall as zeroGradient, outlet as fixedValue uniform 0, topAndBottom as zeroGradient, frontAndBack as empty.
Run the simulation to obtain the final steady-state flow field.
