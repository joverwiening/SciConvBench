Configure a 2D simulation of flow past a cylinder using pimpleFoam for a transient, incompressible, laminar case.
The mesh is one cell thick in the z-direction.
The Reynolds number is 100 based on cylinder diameter and inlet velocity.
The cylinder diameter is 1.0 meters.
The inlet velocity magnitude is 1.0 m/s in the x-direction.
The computational domain extends 10 diameters upstream of the cylinder, 20 diameters downstream, and 10 diameters in the cross-flow direction on each side.
The frontAndBack patches in constant/polyMesh/boundary are defined with type symmetryPlane.
In the 0/U file, the boundary condition for frontAndBack is specified as type wall with value uniform (0 0 0).
The inlet boundary condition uses type fixedValue with uniform velocity (1 0 0).
The outlet boundary condition uses type zeroGradient.
The cylinderWall boundary condition uses type noSlip with uniform velocity (0 0 0).
The kinematic viscosity is set to 0.01 m²/s to achieve the target Reynolds number.
The simulation end time is 200 seconds to capture multiple vortex shedding cycles.
The time step size is 0.01 seconds with adjustable time stepping disabled.
Use PIMPLE algorithm settings appropriate for laminar flow with 2 outer correctors and 1 pressure corrector.
