Simulate steady-state, incompressible, turbulent flow and heat transfer in a 2D heated pipe using the simpleFoam solver.
The pipe has a diameter of 0.1m and a length of 2m.
Use the k-epsilon turbulence model.
The fluid is air with standard properties.
The inlet velocity is uniform at 1 m/s in the x-direction.
The inlet temperature is 300 K.
The outlet is at a fixed gauge pressure of 0 Pa.
The pipe wall is adiabatic (perfectly insulated).
The simulation is 2D, so the front and back patches should be of type 'empty'.
The inlet boundary condition for temperature uses fixedValue type with uniform 300 K.
The outlet boundary condition for temperature uses zeroGradient type.
The wall boundary condition for temperature uses zeroGradient type for adiabatic conditions.
The frontAndBack boundary condition for temperature uses empty type.
