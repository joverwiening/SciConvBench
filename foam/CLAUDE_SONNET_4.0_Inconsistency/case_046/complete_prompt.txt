Set up a transient simulation of turbulent flow over a 2D cylinder in a channel using pimpleFoam. The simulation should be configured to use Large Eddy Simulation (LES) to resolve the large turbulent scales. In the `constant/turbulenceProperties` dictionary, specify the simulation type as LES and configure the appropriate sub-grid scale model. The file should look like this:

`simulationType LES;

LES
{
    LESModel        Smagorinsky;
    delta           cubeRootVol;
}`

Use standard air properties for an incompressible fluid. The inlet velocity is 10 m/s. The cylinder and channel walls should have noSlip boundary conditions.
