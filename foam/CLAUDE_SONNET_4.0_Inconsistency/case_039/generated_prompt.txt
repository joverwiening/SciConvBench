Set up the classic 2D dam-break problem with water column collapsing into air with a sharp free surface.
Use a 2D mesh extruded one cell in the spanwise direction with frontAndBack set to empty.
Track the interface with the VOF field alpha.water.
Initialize the water column using setFields with alpha.water = 1 inside the initial column and 0 elsewhere.
Set gravity to (0 -9.81 0).
Use water column dimensions of 0.6 m height and 0.146 m width positioned at the left side of the tank.
Use total tank dimensions of 1.0 m length and 0.6 m height.
Apply tank wall boundaries with noSlip for U, zeroGradient for p_rgh, and zeroGradient for alpha.water.
Apply open top boundaries with pressureInletOutletVelocity for U, totalPressure/fixedValue (0) for p_rgh, and inletOutlet for alpha.water with inletValue uniform 0.
Set application to solidDisplacementFoam in system/controlDict.
