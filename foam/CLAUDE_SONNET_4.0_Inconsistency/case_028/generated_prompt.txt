Create a 2D simulation of laminar, incompressible flow through a simple channel using the icoFoam solver.
Generate the mesh using blockMesh with the following specifications.
The simulation domain is 1m long, 0.1m high, and 0.01m deep.
The mesh is one cell thick in the z-direction to model the 2D case.
Use a mesh resolution of 100 cells in the x-direction and 20 cells in the y-direction.
The blockMeshDict defines boundaries as inlet, outlet, topWall, bottomWall, and frontAndBack.
The frontAndBack patches are defined as wall type with faces (0 4 7 3) and (1 2 6 5).
Set the kinematic viscosity to 1e-6 m²/s (water at room temperature).
Apply a uniform inlet velocity of 0.1 m/s in the x-direction, giving a Reynolds number of approximately 10000.
Set no-slip boundary condition (0 0 0) velocity at all walls including frontAndBack.
Set zero gradient pressure condition at the inlet.
Set fixed pressure value of 0 at the outlet.
Set zero gradient pressure condition at all walls.
The frontAndBack patches should be treated as empty type for 2D simulation instead of wall type.
Use first-order upwind schemes for convection terms.
Set the simulation end time to 10 seconds with a time step of 0.001 seconds.
