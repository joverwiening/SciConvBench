Simulate the compressible, supersonic flow of air over a 10-degree wedge to form an oblique shock.
Set the freestream Mach number to 2.0.
Treat air as a perfect gas.
Use a 2D mesh extruded one cell in the z-direction with frontAndBack boundaries set to empty.
Set freestream conditions: U = (686 0 0) m/s, T = 293 K, p = 101325 Pa.
Configure constant/thermophysicalProperties with hePsiThermo, perfectGas equation of state, and Sutherland transport model.
Set inlet boundary conditions to fixed values for U, p, and T.
Set outlet boundary conditions to waveTransmissive for p and T, and zeroGradient for U.
Set wedge surface and top boundary to slip wall conditions.
Set frontAndBack boundaries to empty.
Use rhoPimpleFoam as the solver in system/controlDict.
Set the time step to 1e-7 seconds for numerical stability.
Set the total simulation time to 0.01 seconds to capture steady-state development.
Use adjustable time stepping with maxCo = 0.5 for Courant number control.
