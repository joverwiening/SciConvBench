Create a 2D heat conduction simulation using laplacianFoam with the following specifications:

Domain is a 1m x 1m square plate, one cell thick in the z-direction.
Use a 50x50x1 mesh resolution (50 cells in x-direction, 50 cells in y-direction, 1 cell in z-direction).
In blockMeshDict, define four side patches named left, right, top, and bottom.
Define frontAndBack patches in blockMeshDict.
Set frontAndBack patches to type wall in blockMeshDict.
In the 0/T file, set left wall boundary condition to fixedValue 400 K.
In the 0/T file, set right wall boundary condition to fixedValue 300 K.
In the 0/T file, set top wall boundary condition to zeroGradient.
In the 0/T file, set bottom wall boundary condition to zeroGradient.
In the 0/T file, set frontAndBack patches boundary condition to zeroGradient.
Run the simulation to steady-state convergence.
The simulation will find the steady-state temperature distribution across the plate.
