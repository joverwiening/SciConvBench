Simulate natural convection in a 2D square cavity using the de Vahl Davis benchmark case.
The cavity dimensions are 1.0 m x 1.0 m (length x height).
The cavity is filled with air with properties at 295 K reference temperature.
The left wall temperature is fixed at 300 K (hot wall).
The right wall temperature is fixed at 290 K (cold wall).
The top and bottom walls are adiabatic with zero gradient boundary conditions for temperature.
All walls have no-slip boundary conditions for velocity (fixedValue with zero velocity).
Gravity acts downwards in the negative y-direction with magnitude 9.81 m/s².
Use the Boussinesq approximation for buoyancy effects.
Target Rayleigh number is approximately 10^4 (Ra = 10,000).
Use a uniform mesh resolution of 100x100 cells.
The solver to be used is buoyantBoussinesqPimpleFoam (not laplacianFoam, as laplacianFoam is for steady-state diffusion only).
Air properties: kinematic viscosity = 1.5e-5 m²/s, thermal diffusivity = 2.0e-5 m²/s, thermal expansion coefficient = 3.4e-3 K⁻¹.
Initialize the temperature field with a linear distribution between the hot and cold walls.
Initialize velocity field to zero everywhere.
Run the simulation until steady state is reached (typically when residuals drop below 1e-6).
