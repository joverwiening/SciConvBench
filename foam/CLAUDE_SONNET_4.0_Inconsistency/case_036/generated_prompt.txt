Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity.
The beam geometry is 1 m long, 0.1 m high, and 0.1 m wide.
One end (fixed) is clamped and the free end (loaded) has a downward traction load of 1000 Pa.
Use a mesh with approximately 20 elements along the length, 4 elements along the height, and 4 elements along the width for adequate resolution.
In constant/mechanicalProperties, set Young's modulus E = 200e9 Pa and Poisson ratio nu = 0.3 for steel properties.
In 0/D, apply fixedValue uniform (0 0 0) boundary condition to the fixed end.
In 0/D, apply tractionDisplacement boundary condition to the loaded end with traction uniform (0 -1000 0) and pressure uniform 0.
In 0/D, apply zeroGradient boundary condition to all other faces.
In system/controlDict, set application to solidDisplacementFoam.
In system/controlDict, set endTime to 1.
Use linear elasticity material model for the structural analysis.
The simulation solves for displacement field under the applied loading conditions.
