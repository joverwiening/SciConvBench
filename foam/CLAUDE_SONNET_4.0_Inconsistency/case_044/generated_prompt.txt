Set up a 2D dam break simulation using the interFoam solver in OpenFOAM.
Create a rectangular domain that is 1m long (x-direction) and 1m high (y-direction).
Use a mesh resolution of 200 cells in the x-direction and 200 cells in the y-direction for adequate resolution of the water-air interface.
Initialize a water column in the region where 0 < x < 0.2 and 0 < y < 0.5.
Fill the rest of the domain with air.
Set the acceleration due to gravity in the constant/g file as g (0 0 -9.81).
Use setFieldsDict to initialize the alpha.water field to 1 in the water column region and 0 elsewhere.
Apply pressureInletOutletVelocity boundary condition with zero gradient for velocity at the top boundary to simulate open atmosphere.
Apply noSlip boundary condition (zero velocity) to all other boundaries (left, right, and bottom walls).
Use an adaptive time step with initial deltaT of 0.001 seconds and maxCo of 0.5 for Courant number control.
Run the simulation for a total time of 2.0 seconds to capture the complete dam break dynamics.
The simulation models the collapse of the water column under gravity using the volume of fluid method.
