Set up a 2D, steady-state, incompressible, turbulent simulation of airflow over a NACA0012 airfoil at a 5-degree angle of attack.
Use the simpleFoam solver with the k-omega SST turbulence model.
The domain should be a C-grid type, one cell thick in the z-direction.
The mesh is defined in constant/polyMesh.
The boundary patches are inlet, outlet, airfoil, and frontAndBack.
Use kinematic viscosity nu = 1.5e-05 m²/s (standard air at sea level conditions).
Set inlet velocity U to fixedValue uniform (10 0 0).
Calculate inlet k from turbulence intensity 1% as k = 1.5 * (I * U)² = 1.5 * (0.01 * 10)² = 0.015 m²/s².
Calculate inlet omega from viscosity ratio 10 as omega = k / (nu_t) where nu_t = 10 * nu, so omega = 0.015 / (10 * 1.5e-05) = 100 s⁻¹.
Set inlet k to fixedValue uniform 0.015.
Set inlet omega to fixedValue uniform 100.
Set inlet pressure p to zeroGradient.
Set outlet velocity U to inletOutlet with inletValue uniform (10 0 0) and value uniform (10 0 0).
Set outlet k to inletOutlet with inletValue uniform 0.015 and value uniform 0.015.
Set outlet omega to inletOutlet with inletValue uniform 100 and value uniform 100.
Set outlet pressure p to fixedValue uniform 0.
Set airfoil velocity U to noSlip.
Set airfoil k to kqRWallFunction with value uniform 0.015.
Set airfoil omega to omegaWallFunction with value uniform 100.
Set airfoil pressure p to zeroGradient.
Set frontAndBack patches type to wall in constant/polyMesh/boundary.
Set frontAndBack velocity U to noSlip.
Set frontAndBack pressure p to zeroGradient.
Set frontAndBack k to zeroGradient.
Set frontAndBack omega to zeroGradient.
