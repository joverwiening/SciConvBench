Simulate the transient von Kármán vortex street behind a cylinder in a 2D channel. Use a 2D mesh extruded one cell in z with `frontAndBack` as `empty`. Set the kinematic viscosity to `nu = 1e-3 m^2/s`.

Boundary conditions:
- `0/U`: inlet `fixedValue uniform (0.1 0 0)`, outlet `zeroGradient`, cylinder `noSlip`, top/bottom `slip`, frontAndBack `empty`
- `0/p`: inlet `zeroGradient`, outlet `fixedValue uniform 0`, cylinder/top/bottom `zeroGradient`, frontAndBack `empty`

In `system/controlDict`, set:
```foam
application     pimpleFoam;
```
