Simulate the transient von Kármán vortex street behind a cylinder in a 2D channel.
Use a 2D mesh extruded one cell in z with frontAndBack as empty.
Set the kinematic viscosity to nu = 1e-3 m^2/s.
Set the cylinder diameter to 0.1 m.
Set the channel length to 2.2 m with the cylinder positioned 0.2 m from the inlet.
Set the channel width to 0.41 m with the cylinder centered vertically.
Set the simulation end time to 20 seconds.
Set the time step size to 0.005 seconds.
Use application icoFoam in system/controlDict.
Set boundary conditions for 0/U: inlet fixedValue uniform (0.1 0 0), outlet zeroGradient, cylinder noSlip, top/bottom slip, frontAndBack empty.
Set boundary conditions for 0/p: inlet zeroGradient, outlet fixedValue uniform 0, cylinder/top/bottom zeroGradient, frontAndBack empty.
Configure writeControl as timeStep and writeInterval as 20 in system/controlDict.
Set adjustTimeStep to no and maxCo to 0.5 in system/controlDict.
