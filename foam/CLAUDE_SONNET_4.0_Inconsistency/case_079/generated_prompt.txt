Perform a transient simulation of a Rayleigh-Bénard convection cell using buoyantPimpleFoam.
The domain is a 2D rectangle with width 0.02 m and height 0.01 m (aspect ratio 2:1).
Heat the bottom boundary at 305 K and cool the top boundary at 295 K.
The fluid is water.
Use the Boussinesq approximation for this problem.
In constant/thermophysicalProperties, set thermoType hePsiThermo and equationOfState Boussinesq with appropriate coefficients for water.
In system/fvSchemes, for the divergence of temperature, use div(phi,T) Gauss linear.
For the divergence of velocity, use the density-weighted scheme div(rhoPhi,U) Gauss upwind.
Run the transient simulation for a total duration of 100 seconds.
Use a time step size of 0.01 seconds.
