Simulate heat transfer in a 2D channel with a heated block using OpenFOAM.
The fluid is air and the flow is laminar.
Use the buoyantPimpleFoam solver.
The channel walls are adiabatic (perfectly insulated).
The inlet has a fixed velocity of 0.1 m/s and a temperature of 300 K.
The heated block is maintained at a constant temperature of 400 K.
In the 0/T file, set the inlet boundary condition as: inlet { type fixedValue; value uniform 300; }.
Set the outlet boundary condition as: outlet { type zeroGradient; }.
Set the block boundary condition as: block { type fixedValue; value uniform 400; }.
Set the adiabatic channel walls boundary condition as: walls { type zeroGradient; }.
The inlet velocity should be set to 0.1 m/s which provides a reasonable Reynolds number for laminar flow in typical channel geometries.
