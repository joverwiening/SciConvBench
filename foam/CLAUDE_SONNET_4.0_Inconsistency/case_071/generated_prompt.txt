Create a 2D dam break simulation using the interFoam solver in OpenFOAM.
Set up a rectangular domain with dimensions 0.6m length (x-direction) by 0.4m height (y-direction).
Use blockMesh to create the geometry with a single block and a mesh resolution of 120 cells in x-direction and 80 cells in y-direction for a cell size of approximately 0.005m.
Define the initial water column in setFieldsDict occupying the region where x < 0.15m and y < 0.3m.
Fill the rest of the domain with air as the second phase.
Configure transportProperties with standard water and air properties.
Set gravity vector in constant/g to g (0 0 -9.81).
Apply noSlip boundary condition for velocity U on all walls.
Apply pressureInletOutletVelocity boundary condition for velocity U on the top atmosphere patch.
Apply fixedFluxPressure boundary condition for p_rgh on all walls.
Apply totalPressure boundary condition for p_rgh on the atmosphere patch.
Apply zeroGradient boundary condition for alpha.water on all walls.
Apply inletOutlet boundary condition for alpha.water on the atmosphere patch.
Set front and back patches as empty type for 2D simulation.
Run the simulation for 2 seconds total time.
