Channel dimensions: 2 meters length, 0.4 meters height.
Obstacle: circular cylinder with 0.05 meters diameter, positioned at x = 0.5 meters from inlet, centered vertically in the channel.
Boundary conditions for 0/U: inlet fixedValue uniform (0.1 0 0), outlet zeroGradient, walls+obstacle noSlip, frontAndBack empty.
Boundary conditions for 0/p: inlet zeroGradient, outlet fixedValue uniform 0, walls+obstacle zeroGradient, frontAndBack empty.
In system/controlDict, set application simpleFoam.
Use appropriate mesh resolution with refinement around the obstacle for accurate flow capture.
