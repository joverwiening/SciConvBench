Simulate a 2D lid-driven cavity flow using the icoFoam solver for transient, incompressible, laminar flow.
The domain is a unit square (1m x 1m), one cell thick in the z-direction.
The system/blockMeshDict defines the frontAndBack patches with type empty.
The top wall (movingWall) moves at 1 m/s in the x-direction.
The other three walls (fixedWalls) are stationary with no-slip boundary conditions.
In the 0/U initial condition file, set the frontAndBack patches to type empty to match the mesh definition.
Set the movingWall boundary condition to type fixedValue with value uniform (1 0 0).
Set the fixedWalls boundary condition to type noSlip.
Set the internalField to uniform (0 0 0) for initial conditions.
Use a kinematic viscosity of 1e-3 m²/s in the transportProperties file to achieve a Reynolds number of 1000.
The Reynolds number is calculated as Re = UL/ν where U = 1 m/s, L = 1 m, and ν = 1e-3 m²/s.
Run the simulation as a transient case to capture the flow development from rest to steady state.
