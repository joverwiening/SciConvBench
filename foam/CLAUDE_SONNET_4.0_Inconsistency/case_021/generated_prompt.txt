Set up a 2D, incompressible, steady-state simulation of airflow over a NACA 0012 symmetric airfoil.
Use the simpleFoam solver in OpenFOAM.
The airfoil has a chord length of 1.0 meter.
Set the angle of attack to 0 degrees (aligned with the flow).
The domain uses a C-grid topology around the airfoil.
The mesh is one cell thick in the z-direction.
Apply a uniform inlet velocity of (10 0 0) m/s.
Set the kinematic viscosity to 1.5e-05 m²/s (corresponding to air at standard conditions, giving a Reynolds number of approximately 667,000).
In the system/blockMeshDict file, define the front and back patches as walls in the boundary entry using the specified format with frontAndBack patch type wall and the given face definitions.
For boundary conditions in the 0/U file, apply uniform inlet velocity (10 0 0) m/s, zero-gradient outlet, noSlip condition on the airfoil surface, and noSlip on the frontAndBack patches.
For pressure in 0/p, use zeroGradient for the inlet and airfoil, fixedValue uniform 0 at the outlet, and zeroGradient on the frontAndBack patches.
The simulation operates at steady-state conditions with incompressible flow assumptions.
