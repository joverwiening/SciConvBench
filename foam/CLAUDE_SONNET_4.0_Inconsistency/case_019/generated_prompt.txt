Set up a laminar counter-flow diffusion flame simulation using reactingFoam solver in OpenFOAM.
Create a 2-D opposed-jet configuration with a rectangular domain spanning x = 0 to 0.02 m, y = -0.01 to 0.01 m, and z = -0.01 to 0.01 m.
Use a mesh with 100 cells in x-direction, 40 cells in y-direction, and 1 cell in z-direction.
Name the left boundary (x = 0) as fuel and the right boundary (x = 0.02) as air.
Set the top and bottom boundaries as outlet type.
Configure frontAndBack faces as empty boundary type.
At the fuel inlet boundary, inject methane (CH4) at 293 K temperature with velocity of 0.1 m/s in positive x-direction.
At the air inlet boundary, supply air with Y_O2 = 0.23 and balance N2 at 293 K temperature with velocity of -0.1 m/s.
Initialize the entire domain temperature to 2000 K at time zero.
Use a simplified global reaction mechanism with species CH4, O2, N2, CO2, and H2O following the reaction CH4 + 2O2 → CO2 + 2H2O.
Configure chemistry solver with type EulerImplicit and ODE solver Rosenbrock43.
Set combustion model to laminar and momentum transport to laminar.
Use incompressible finite-rate chemistry with heRhoThermo thermophysical model.
Configure mixture type as coefficientWilkeMultiComponentMixture.
Set transport model to Sutherland and thermodynamics to JANAF.
Use a timestep of 1e-4 seconds with end time of 0.5 seconds.
Write simulation results every 0.05 seconds.
