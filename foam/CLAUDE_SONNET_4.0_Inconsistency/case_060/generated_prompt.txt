Set up a classic 2D dam-break problem using OpenFOAM with the following specifications:

Use twoPhaseEulerFoam as the solver application.
Create a 2D computational domain with dimensions 4 meters wide by 2 meters tall.
Extrude the mesh one cell thick in the z-direction.
Set the front and back patches to empty boundary condition type.
Initialize a water column with height 1 meter and width 1 meter positioned at the left side of the domain.
Use setFields utility to initialize the phase fraction field alpha.water to 1.0 inside the water column region.
Set alpha.water to 0.0 in all other regions representing air.
The water column should be positioned with its bottom at y=0 and left edge at x=0.
Configure the mesh resolution to be fine enough to capture the free surface dynamics accurately.
Set appropriate boundary conditions with walls at the bottom and sides, and atmosphere at the top.
The simulation should model the gravitational collapse of the water column into the surrounding air phase.
