Set up a steady-state 2D natural convection simulation in a square cavity with dimensions 1.0 m x 1.0 m.
The left wall is hot at 310 K and the right wall is cold at 290 K.
The top and bottom walls are adiabatic.
Use the buoyantBoussinesqSimpleFoam solver.
Gravity acts in the -y direction with g = (0 -9.81 0).
The fluid is air.
Use a uniform mesh with 100 cells in both x and y directions for adequate resolution.
In constant/thermophysicalProperties, set thermoType heRhoThermo with mixture pureMixture, transport const, thermo hConst, equationOfState perfectGas, specie hConst, and energy sensibleEnthalpy.
Set molecular weight to 28.9 g/mol.
In constant/transportProperties, set mu 1.8e-5 and Pr 0.7.
Set reference temperature T0 to 300 K in the BoussinesqCoeffs sub-dictionary.
In the 0/T file, set the left wall to fixedValue uniform 310, the right wall to fixedValue uniform 290, and top/bottom walls to zeroGradient.
For velocity 0/U, use noSlip on all walls.
For pressure 0/p_rgh, use fixedFluxPressure on all walls.
Set convergence criteria with residual tolerances of 1e-6 for p_rgh, 1e-6 for U, and 1e-6 for T.
Set maximum number of iterations to 1000 for the SIMPLE algorithm.
