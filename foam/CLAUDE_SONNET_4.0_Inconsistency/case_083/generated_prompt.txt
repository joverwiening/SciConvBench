Set up initial conditions for a three-phase settling tank using multiphaseEulerFoam solver.
Create a rectangular tank with dimensions 2.0m length, 1.0m width, and 1.5m height.
Place the tank geometry with the bottom at z=0 and top at z=1.5m.
In the 0/ directory, create three alpha field files: alpha.sediment, alpha.water, and alpha.oil.
Set the internalField in all three alpha files to uniform 0.5 as the default condition.
Configure setFieldsDict to create stratified layers with sediment at bottom (z=0 to z=0.5m), water in middle (z=0.5m to z=1.0m), and oil at top (z=1.0m to z=1.5m).
Set alpha.sediment to 1.0 in the bottom region and 0.0 elsewhere.
Set alpha.water to 1.0 in the middle region and 0.0 elsewhere.
Set alpha.oil to 1.0 in the top region and 0.0 elsewhere.
Ensure the sum of all alpha fields equals 1.0 at every cell location.
Apply appropriate boundary conditions for all alpha fields on tank walls, inlet, and outlet patches.
