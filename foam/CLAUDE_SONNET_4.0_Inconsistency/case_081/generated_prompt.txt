Create a 2D gas-liquid bubble column simulation using the twoPhaseEulerFoam solver.
The computational domain is a rectangle with 0.5 m width and 2 m height.
The two phases are air and water.
The simulation is transient.
Use a mesh resolution of 50 cells in the width direction and 200 cells in the height direction.
At the bottom inlet boundary, introduce both air and water.
Set the boundary condition in 0/alpha.air file for the inlet patch as type fixedValue with value uniform 0.8.
Set the boundary condition in 0/alpha.water file for the inlet patch as type fixedValue with value uniform 0.3.
Set the air velocity at the inlet to (0 0.2 0) m/s.
Set the water velocity at the inlet to (0 0.01 0) m/s.
Configure the top boundary as an outlet.
Configure the side boundaries as no-slip walls.
Set the total simulation time to 10 seconds.
Use a time step size of 0.001 seconds.
