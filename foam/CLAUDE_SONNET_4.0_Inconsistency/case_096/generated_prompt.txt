Create a 2D dam break simulation using the interFoam solver for two incompressible, immiscible fluids (water and air).
Set up a rectangular tank domain that is 0.5m long and 0.5m high, extruded by 0.01m in the z-direction to create a single layer of cells.
Use a mesh resolution of 100 cells in the x-direction and 100 cells in the y-direction for adequate resolution of the interface.
Apply gravity in the negative y-direction with g = (0 -9.81 0).
Initialize a column of water (alpha.water=1) in the region x < 0.15m using setFieldsDict.
Set the rest of the domain as air (alpha.water=0).
Configure boundary types in constant/polyMesh/boundary as leftWall, rightWall, and lowerWall with type wall.
Set atmosphere boundary as type patch.
Set frontAndBack boundaries as type symmetry.
Apply noSlip boundary condition for U field on all walls.
Use pressureInletOutletVelocity boundary condition for U field on atmosphere.
Apply symmetry boundary condition for U field on frontAndBack.
Set fixedFluxPressure boundary condition for p_rgh field on walls and frontAndBack.
Use totalPressure boundary condition for p_rgh field on atmosphere.
Apply zeroGradient boundary condition for alpha.water field on walls and frontAndBack.
Set inletOutlet boundary condition for alpha.water field on atmosphere.
