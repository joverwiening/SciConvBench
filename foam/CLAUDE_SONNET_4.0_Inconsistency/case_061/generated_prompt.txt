Set up a 2D lid-driven cavity flow simulation using OpenFOAM.
Create a 1 m × 1 m square domain extruded one cell in the z-direction.
Use a uniform mesh of 40 × 40 × 1 cells.
Set the fluid as incompressible Newtonian with kinematic viscosity nu = 0.01 m²/s.
Run the simulation as transient until steady state is reached.
Set the application in system/controlDict to icoFoam.
Use a time step of 0.005 seconds based on CFL considerations for the given mesh and velocity.
Configure the movingLid boundary (top wall) with fixedValue uniform velocity (1 0 0) m/s for 0/U.
Configure fixedWalls boundaries (left, right, bottom walls) with noSlip condition for 0/U.
Set all wall boundaries to zeroGradient for 0/p.
Configure frontAndBack boundaries as empty type.
Set pressure reference using pRefCell and pRefValue in system/fvSolution.
Run the simulation until the solution reaches steady state.
