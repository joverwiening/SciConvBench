Set up an axisymmetric simulation of swirling flow inside a pipe using simpleFoam.
Use a pipe diameter of 0.1 meters (100mm).
Use a pipe length of 0.5 meters (5 times the diameter for flow development).
Create a 2D wedge geometry mesh with 5 degrees in the tangential direction.
Make the mesh one cell thick in the tangential direction.
Use 50 cells in the axial direction and 20 cells in the radial direction.
Define the axial patches as axis type.
Define the pipe surface as wall type.
Define the inlet patch with fixed velocity boundary condition.
Define the outlet patch with zero gradient pressure boundary condition.
Define the front and back planes of the wedge as empty type boundary conditions.
Set inlet axial velocity to 2.0 m/s.
Set inlet tangential velocity to 1.0 m/s to create swirl.
Set inlet radial velocity to 0.0 m/s.
Use kinematic viscosity of 1e-05 m²/s for air at standard conditions.
Set initial pressure field to zero gauge pressure.
Configure the blockMeshDict to create vertices from centerline (r=0) to pipe wall (r=0.05m).
Use grading of 1 (uniform spacing) in all directions.
Set wall boundary condition as no-slip for velocity.
Set axis boundary condition as symmetry for velocity and pressure.
