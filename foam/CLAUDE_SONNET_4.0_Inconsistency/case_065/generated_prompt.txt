Simulate transient elastic wave propagation in a solid aluminum block.
Create a rectangular domain with dimensions 1.0 m × 0.1 m × 0.1 m.
Use aluminum material properties: E = 70e9 Pa, nu = 0.33, rho = 2700 kg/m³.
Generate a structured hexahedral mesh with 200 cells in x-direction, 20 cells in y-direction, and 20 cells in z-direction.
Initialize displacement field using setFields with D = (1e-6 0 0) in a thin region from x = 0 to x = 0.005 m, and D = (0 0 0) elsewhere.
Apply traction-free boundary conditions on all external faces using tractionDisplacement with traction uniform (0 0 0) and pressure uniform 0.
Set application to solidDisplacementFoam in system/controlDict.
Use a time step of 1e-7 seconds.
Run the simulation for a total time of 1e-3 seconds.
Configure appropriate solver settings for transient elastic analysis.
Output displacement and stress fields at regular intervals for visualization.
