Simulate a 2D supersonic flow of air at Mach 2 over a 10-degree wedge using oblique shock theory.
Treat air as a perfect gas with gamma = 1.4 and R = 287 J/kg-K.
Create a 2D mesh extruded one cell in the z-direction with frontAndBack boundaries set to empty.
Set the computational domain to 2 meters length by 0.5 meters height.
Position the wedge starting at x = 0.5 meters from the inlet, with the wedge tip at y = 0 and extending 1 meter in length.
The wedge deflects the flow upward by 10 degrees from the horizontal.
Set freestream conditions at the inlet with pressure p = 101325 Pa, temperature T = 300 K, and velocity U = (686 0 0) m/s.
Use hePsiThermo with perfectGas equation of state in constant/thermophysicalProperties.
Apply fixed value boundary conditions at the inlet for U, p, and T using the freestream values.
Apply waveTransmissive boundary conditions at the outlet for p and T, and zeroGradient for U.
Set the wedge surface and top boundary as slip walls with zeroGradient for p and T, and slip condition for U.
Set frontAndBack boundaries to empty type.
Use simpleFoam as the application solver in system/controlDict.
Configure the mesh with appropriate refinement near the wedge leading edge to capture the oblique shock accurately.
