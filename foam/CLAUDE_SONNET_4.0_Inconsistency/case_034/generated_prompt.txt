Set up a 2D dam break simulation using the interFoam solver for a two-phase (water-air) system.
The domain is 2m long and 1m high, with a single cell in the z-direction.
Gravity is defined in 'constant/g' as (0 -9.81 0).
In 'blockMeshDict', the front and back patches are defined as 'frontAndBack' with 'type wall'.
In the '0' directory, for all fields (U, p_rgh, alpha.water), the 'frontAndBack' patches are assigned the 'noSlip' boundary condition for velocity and 'zeroGradient' for scalars.
The initial water column has dimensions of 0.6m width and 0.6m height, positioned at the left side of the domain.
The mesh resolution is 200 cells in the x-direction and 100 cells in the y-direction.
The left, right, and bottom walls use 'noSlip' boundary condition for velocity and 'zeroGradient' for pressure and alpha.water.
The top wall uses 'pressureInletOutletVelocity' for velocity, 'totalPressure' for pressure, and 'inletOutlet' for alpha.water to allow air flow.
The initial water column is defined using setFieldsDict with a box region from (0 0 -1) to (0.6 0.6 1).
