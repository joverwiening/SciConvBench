Fluid-Structure Interaction Simulation Specification:

Geometry:
- Create a 2D channel extruded one cell in z-direction
- Channel length is 1.0 m
- Channel height is 0.2 m
- Flap length is 0.05 m
- Flap thickness is 0.005 m
- Flap attached to bottom wall at x = 0.4 m

Fluid Properties:
- Fluid is incompressible water
- Kinematic viscosity (nu) = 1e-6 m²/s
- Reynolds number = 20,000 (based on inlet velocity, channel height, and viscosity)

Boundary Conditions:
- Inlet: Velocity (U) = (1 0 0) m/s (fixed value)
- Outlet: Pressure (p) = 0 Pa (fixed value)
- Channel walls: No-slip condition

Solid Flap Properties:
- Material: Linear elastic
- Young's modulus (E) = 1e6 Pa
- Poisson's ratio (nu) = 0.45
- Density (rho) = 1200 kg/m³

Fluid-Structure Interaction:
- Coupling library: solids4foam
- Two-way coupling method: Dynamic displacement and traction exchange
- Flap base: Fixed displacement
- Interface: Dynamically coupled boundary

Simulation Parameters:
- Fluid solver: pimpleFoam
- Total simulation time: 10 seconds
- Time step size: 0.01 seconds

Solver Configuration:
- Single-region setup with combined mesh
- External coupling library for FSI interaction
