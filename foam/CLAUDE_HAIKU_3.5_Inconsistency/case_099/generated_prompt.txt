Create a 2D laminar, transient flow simulation of a square cylinder in a channel using OpenFOAM's `icoFoam`.

Simulation Domain Specifications:
Domain length is 2.2 meters.
Domain height is 0.41 meters.
Domain thickness is one cell of 0.01 meters.
Square cylinder is 0.1m x 0.1m, placed in the flow path.
Kinematic viscosity (nu) is 0.001 m^2/s.

Velocity Boundary Conditions (`0/U`):
Inlet uses a parabolic velocity profile with maximum velocity of (1.5 0 0) m/s.
Outlet uses `zeroGradient` boundary condition.
Top and bottom walls use `noSlip` boundary condition.
Cylinder surface uses `noSlip` boundary condition.
Front and back surfaces use `noSlip` boundary condition.

Pressure Boundary Conditions (`0/p`):
Inlet uses `zeroGradient` boundary condition.
Outlet uses `fixedValue` uniform 0 pressure.
Top and bottom walls use `zeroGradient` boundary condition.
Cylinder surface uses `zeroGradient` boundary condition.
Front and back surfaces use `zeroGradient` boundary condition.

Mesh Boundary Configuration:
Front and back patches in `constant/polyMesh/boundary` are defined with `type wall`.
