Perform a 2D steady-state incompressible simulation of airflow over a NACA 0012 airfoil using OpenFOAM.
Use the `simpleFoam` solver for the simulation.
Apply the k-omega SST turbulence model.
Create a computational mesh with a single layer of cells in the z-direction.
Configure `constant/polyMesh/boundary` file with `frontAndBack` patches of type `wall`.
Set `frontAndBack` boundary condition in `0/U` file to `noSlip`.
Set `frontAndBack` boundary condition in `0/p` file to `zeroGradient`.
Simulate the airfoil at a low angle of attack.
Ensure the simulation is incompressible and steady-state.
