Simulate mixing of water and Bingham plastic sludge in a 2D tank using OpenFOAM's `interFoam` solver.
Use the following `transportProperties` configuration:

phases (water sludge);

water
{
    transportModel Newtonian;
    nu              1e-6;
    rho             1000;
}

sludge
{
    transportModel BinghamPlastic;
    nu0             0.1;
    rho             1500;
    yieldStress     15;
}

sigma 0.07;

Implement the simulation with the following key characteristics:
The sludge is modeled as a Bingham plastic with a yield stress of 15 Pa.
The plastic viscosity (μp) is 0.1 Pa·s.
Use a 2D tank geometry for the mixing simulation.
Utilize the `interFoam` solver for two-phase flow modeling.
Ensure accurate representation of non-Newtonian sludge behavior during mixing with water.
