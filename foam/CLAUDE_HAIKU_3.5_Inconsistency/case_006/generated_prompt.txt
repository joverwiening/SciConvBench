Simulation Specification for 2D Gas-Liquid Bubble Column using multiphaseEulerFoam:

Domain Geometry:
- Domain dimensions are x: [0, 0.15] m, y: [0, 1.00] m, z: [0, 0.10] m.
- Height is along +y direction, domain is thin in z direction.
- Mesh is structured hexahedral with 25 × 75 × 1 cells.
- Use simpleGrading (1 1 1).
- blockMeshDict defines inlet, outlet, and wall patches.
- Use 2D treatment with empty faces in z direction.

Fluid Phases:
Liquid Phase (Water):
- Use heRhoThermo with rPolynomial equation of state.
- Coefficients: [0.001278, -2.1055e-06, 3.9689e-09, 4.3772e-13, -2.0225e-16]
- Molecular weight: 18
- Specific heat capacity (Cv): 4195
- Dynamic viscosity: 3.645e-4 Pa·s
- Prandtl number: 2.289
- Initial diameter: 1e-4 m
- Initial velocity: uniform (0 0 0)
- Initial volume fraction: uniform 1, except in specified box region
- Initial temperature: uniform 350 K

Gas Phase (Air):
- Use heRhoThermo with perfectGas equation of state
- Molecular weight: 28.9
- Specific heat capacity (Cp): 1007
- Dynamic viscosity: 1.84e-05 Pa·s
- Prandtl number: 0.7
- Initial diameter: 3e-3 m
- Initial velocity: uniform (0 0.1 0)
- Initial volume fraction: 1, except in specified box region
- Initial temperature: uniform 300 K

Simulation Parameters:
- Gravity: (0 0 -9.81) m/s²
- Momentum transport: Laminar for both phases
- Multiphase interaction:
  - Phases: (air water)
  - Reference phase: water
  - Residual alpha: 1e-6
- Blending:
  - Scheme: linear
  - minFullyContinuousAlpha: 0.7
  - minPartlyContinuousAlpha: 0.3 (default), 0.5 (drag)
- Surface tension: constant, sigma = 0.07
- Drag model: SchillerNaumann for all configurations
- Virtual mass: constantCoefficient, Cvm = 0.5
- Heat transfer: RanzMarshall model
  - Residual alpha: 1e-4

Boundary Conditions:
Inlet:
- Air velocity: fixedValue (0 0.1 0)
- Water velocity: fixedValue (0 0 0)
- Air volume fraction: fixedValue 0.5
- Water volume fraction: fixedValue 0.5
- Air temperature: fixedValue 300 K
- Water temperature: fixedValue 350 K

Walls:
- Air velocity: fixedValue (0 0 0)
- Water velocity: fixedValue (0 0 0)
- Air volume fraction: zeroGradient
- Water volume fraction: zeroGradient
- Pressure (p_rgh): fixedFluxPressure
- Air temperature: zeroGradient
- Water temperature: zeroGradient

Time Controls:
- Start time: 0 s
- End time: 20 s
- Time step (deltaT): 0.005 s
- Adjust time step: no
- Maximum Courant number: 0.5
- Maximum time step: 1 s
- Write interval: 1 s
