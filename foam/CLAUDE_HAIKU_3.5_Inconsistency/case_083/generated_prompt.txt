I recommend using a standard room temperature of 20°C (293.15 K) as the initial temperature for all phases in the three-phase settling tank simulation. This is a common default temperature for laboratory or industrial environment simulations when no specific temperature is specified.


Set up initial conditions for a three-phase settling tank using `multiphaseEulerFoam` solver.
Place initial field files in the `0/` directory.
Set `internalField` for `alpha.sediment`, `alpha.water`, and `alpha.oil` to `uniform 0.5`.
Set initial temperature for all phases to 20°C (293.15 K).
Prepare for later modification of volume fractions using `setFieldsDict` to create stratified layers.
