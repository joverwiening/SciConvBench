Set up a steady-state, incompressible, turbulent flow simulation for the Pitz and Daily combustor case using the simpleFoam solver.
The simulation geometry is 2D.
Use the Reynolds-Averaged Simulation (RAS) approach with the standard k-Epsilon turbulence model.
Configure turbulence properties in `constant/turbulenceProperties` with RAS model set to kEpsilon.
Set boundary conditions for velocity `U`:
- Fixed inlet velocity of (10 0 0) m/s at the `inlet`
- Zero-gradient condition at the `outlet`
- No-slip walls for `upperWall` and `lowerWall`
- Front and back patches of type `empty`
Set boundary conditions for pressure `p`:
- `zeroGradient` at the inlet and walls
- Fixed value of 0 at the outlet
Run the simulation for 500 iterations.
