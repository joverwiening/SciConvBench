Create a 2D dam break simulation using OpenFOAM interFoam solver with the following specifications:

Geometry:
Create a rectangular domain using blockMesh with dimensions 0.6m x 0.4m.
Orientation of height is along Y-axis.
Use a single block for mesh generation.

Initial Conditions:
Define water column in setFieldsDict occupying region x < 0.15m and y < 0.3m.
Remaining domain filled with air.

Fluid Properties (transportProperties):
Define two phases: water and air with standard physical properties.

Gravity:
Set gravity vector to (0 0 -9.81) in constant/g.

Boundary Conditions:
Velocity (U):
- Walls: noSlip
- Top atmosphere patch: pressureInletOutletVelocity

Pressure (p_rgh):
- Walls: fixedFluxPressure
- Atmosphere: totalPressure

Volume Fraction (alpha.water):
- Walls: zeroGradient
- Atmosphere: inletOutlet

Additional Conditions:
Front and back patches set to type 'empty' for 2D simulation.

Simulation Parameters:
Total simulation time: 2 seconds.
Solver: interFoam
