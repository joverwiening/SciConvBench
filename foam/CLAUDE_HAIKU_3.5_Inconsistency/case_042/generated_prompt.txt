Simulation Specification for 2D Supersonic Air Flow over a Wedge:

Simulation Domain: 2D supersonic flow over a 10-degree wedge
Flow Conditions:
- Mach number: 2
- Air treated as a perfect gas
- Mesh configuration: 2D mesh extruded one cell in z-direction
- Mesh z-boundaries: `frontAndBack` set to `empty`

Freestream/Inlet Conditions:
- Pressure: 101325 Pa
- Temperature: 300 K
- Velocity: (686 0 0) m/s

Thermophysical Properties:
- Thermo model: `hePsiThermo`
- Equation of state: `perfectGas`

Numerical Solver: `rhoCentralFoam`

Boundary Conditions:
- Inlet: Fixed values for velocity, pressure, and temperature
- Outlet: `waveTransmissive` for pressure and temperature, `zeroGradient` for velocity
- Wedge and top boundary: Slip wall
- Front and back boundaries: `empty`

Mesh Configuration:
- 2D mesh
- Single cell thickness in z-direction
- `frontAndBack` boundaries set to `empty`
