Set up a 2D, steady-state, incompressible, turbulent simulation of airflow over a NACA0012 airfoil using OpenFOAM.

Solver Configuration:
Use the simpleFoam solver with the k-omega SST turbulence model.

Computational Domain:
Create a C-grid type domain with one cell thick in the z-direction.
Define the mesh in `constant/polyMesh`.

Boundary Patches:
Define four boundary patches: `inlet`, `outlet`, `airfoil`, and `frontAndBack`.

Inlet Boundary Conditions:
Set velocity `U` as `fixedValue` uniform (10 0 0).
Calculate `k` and `omega` using turbulence intensity of 1% and viscosity ratio of 10.
Set pressure `p` as `zeroGradient`.

Outlet Boundary Conditions:
Set velocity `U` as `inletOutlet`.
Set `k` and `omega` as `inletOutlet`.
Set pressure `p` as `fixedValue` uniform 0.

Airfoil Boundary Conditions:
Set velocity `U` as `noSlip`.
Set `k` as `kqRWallFunction`.
Set `omega` as `omegaWallFunction`.
Set pressure `p` as `zeroGradient`.

Front and Back Boundary Conditions:
Set patch type to `wall` in `constant/polyMesh/boundary`.
Set velocity `U` as `noSlip`.
Set pressure `p`, `k`, and `omega` as `zeroGradient`.

Simulation Parameters:
Angle of attack: 5 degrees.
