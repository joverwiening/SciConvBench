Simulate 3D incompressible turbulent flow around a cube on a channel floor using OpenFOAM.

Solver: Use `simpleFoam` with `kEpsilon` RANS turbulence model.

Mesh Requirements:
Create a fully 3D mesh with multiple cells in the spanwise direction.
Configure spanwise side patches (`left` and `right`) as symmetry boundaries.

Boundary Conditions:
Set `noSlip` boundary condition on:
- Floor
- Cube surfaces
- Top wall

Set fixed inlet velocity boundary condition on `inlet`.
Set fixed outlet pressure boundary condition on `outlet`.

Mesh Configuration in `system/blockMeshDict`:
Define `left` and `right` patches with `type empty`.
Ensure symmetry boundary conditions are correctly implemented for spanwise patches.

Simulation Objectives:
Analyze flow characteristics around the cube.
Capture turbulent flow behavior using RANS `kEpsilon` model.
Represent channel flow with symmetry side boundaries to emulate infinite width.
