Set up a 2D laminar, incompressible flow simulation past a cylinder using OpenFOAM.
Simulation domain is a rectangular channel 2.2m long and 0.41m high.
Place a cylinder with 0.1m diameter centered at coordinates (0.2, 0.2).
Use kinematic viscosity of 1e-3 m²/s.
Apply uniform inlet velocity of (1 0 0) m/s.
Create a mesh one cell thick in the z-direction.
Use `simpleFoam` solver in `system/controlDict`.
Set simulation parameters in `system/controlDict`:
- `startTime`: 0
- `endTime`: 200
- `deltaT`: 1
- `writeInterval`: 10
Set boundary conditions in `0/U`:
- `inlet`: `fixedValue uniform (1 0 0)`
- `outlet`: `zeroGradient`
- `cylinderWall`: `noSlip`
- `topAndBottom`: `noSlip`
- `frontAndBack`: `empty`
Set boundary conditions in `0/p`:
- `inlet`: `zeroGradient`
- `cylinderWall`: `zeroGradient`
- `outlet`: `fixedValue uniform 0`
- `topAndBottom`: `zeroGradient`
- `frontAndBack`: `empty`
Run simulation to obtain final steady-state flow field.
Reynolds number is 100.
