Create a 2D lid-driven cavity flow simulation with the following specifications:

Use OpenFOAM solver `icoFoam` for incompressible fluid flow.
Create a computational domain of 1 m × 1 m square.
Extrude the domain one cell in z-direction with `frontAndBack` set to `empty`.
Generate a uniform mesh of 40 × 40 × 1 cells.
Use an incompressible Newtonian fluid with kinematic viscosity `nu = 0.01 m^2/s`.
Run the simulation transiently until a steady solution is reached.

Boundary conditions:
Set top boundary (`movingLid`) velocity to `fixedValue uniform (1 0 0)`.
Set left, right, and bottom boundaries (`fixedWalls`) to `noSlip`.
Apply `zeroGradient` for pressure on all walls.
Set pressure reference using `pRefCell` and `pRefValue` in `system/fvSolution`.
Configure `frontAndBack` boundaries as `empty`.

Simulation will continue until steady-state conditions are achieved.
