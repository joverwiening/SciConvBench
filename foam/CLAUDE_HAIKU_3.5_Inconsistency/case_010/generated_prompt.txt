Simulation Specification for Buoyant Natural Convection Heat Transfer:

Solver Configuration:
Use buoyantFoam solver with RAS k-epsilon turbulence model and LES Smagorinsky subgrid model.

Domain Geometry:
Create a 3D rectangular room with dimensions 4m x 3m x 1.6m (length x height x width).
Use convertToMeters factor of 1.
Generate a structured mesh of 40x20x60 cells in x, y, and z directions respectively.

Boundary Conditions:
Inlet (lower front wall, 0.25≤y≤0.75, 1.1≤z≤1.3):
Set fixed velocity of 0.2 m/s in x-direction.
Set fixed temperature of 290K.
Set turbulent intensity of 14%.
Set mixing length of 0.0168m.
Initialize k=0 and ε=0 uniformly in the domain.

Outlet (upper back wall, 1.75≤x≤2.25, 0.3≤z≤0.5):
Apply pressure inlet-outlet velocity.
Use zero gradient temperature.

Wall Boundary Conditions:
Apply no-slip wall conditions.
Set fixed wall temperature of 302K for all remaining walls.

Thermophysical Properties:
Use Boussinesq approximation.
Set reference density of 1 kg/m³.
Set reference temperature of 300K.
Use thermal expansion coefficient of 3e-03 K⁻¹.
Set dynamic viscosity of 1e-05 Pa·s.
Use Prandtl number of 0.7.
Set specific heat to 712 J/kg·K.
Use compressible perfectGas thermophysical model with temperature-dependent density.

Simulation Parameters:
Run steady-state simulation.
Use PIMPLE algorithm.
Set time step of 1s.
Run for 3000 iterations.
Output results every 100 time steps.

Additional Function Objects:
Include age and comfort function objects.
Set clothing factor to 0.5.
Set metabolic rate to 1.2.
Set relative humidity to 60%.

blockMeshDict Configuration:
Use the provided blockMeshDict with convertToMeters 1.
Define 8 vertices for the 3D rectangular domain.
Create a single hex block with (40 20 60) cells.
Use simpleGrading of (1 1 1).
Set default patch name to "walls" with type "wall".
