Specification for Two-Dimensional Rayleigh-Benard Convection Simulation:

Geometry Configuration:
The simulation domain is a rectangular cavity 9 units wide and 1 unit tall.
Discretize the domain with 90 cells in x direction, 10 cells in y direction, and 1 cell in z direction.
Treat front and back patches as empty to enforce 2D simulation.

Solver and Numerical Setup:
Use simpleFoam solver for steady-state simulation.
Set fixed timestep of 1 second.
Simulate up to 1000 seconds of physical time.
Write simulation results every 50 time steps.

Physical Properties:
Use Boussinesq approximation for buoyancy-driven flow.
Reference density: 1.0 kg/m³
Reference temperature: 300 K
Thermal expansion coefficient: 3.3e-3 1/K
Kinematic viscosity: 1.5e-5 m²/s
Thermal diffusivity: 2.1e-5 m²/s
Molecular weight: 29 kg/kmol
Specific heat capacity: 714.3 J/kg·K

Boundary Conditions:
Bottom wall temperature: 305 K (fixed)
Top wall temperature: 295 K (fixed)
Vertical side walls: Adiabatic
All solid walls: No-slip velocity condition

Turbulence Modeling:
Use RAS k-epsilon turbulence model
Initialize k: 1e-5
Initialize epsilon: 1e-5
Initialize turbulent viscosity (nut): 0
Initialize turbulent thermal diffusivity (alphat): 0

Initial Conditions:
Initial velocity field: Uniform zero velocity (0 0 0)
Initial temperature field: Uniform 300 K
Gravity acting downward in negative y direction

Solver Tolerances:
Set solver tolerances for p_rgh and (U|e|k|epsilon) to 1e-8
Set relative tolerance to 0.01 for final iterations
