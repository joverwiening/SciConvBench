Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity.

Beam Geometry:
Length is 1 m.
Height is 0.1 m.
Width is 0.1 m.

Material Properties:
Use steel with Young's modulus of 200e9 Pa.
Use steel with Poisson's ratio of 0.3.

Boundary Conditions:
One end (fixed) is clamped with displacement `(0 0 0)`.
Free end (loaded) has a traction load of `(0 -1000 0)` Pa.
All other faces have `zeroGradient` boundary condition.

Simulation Settings:
Use `pimpleFoam` application.
Set simulation end time to 1 second.

Solve for the beam's quasi-static deflection using linear elasticity theory.
