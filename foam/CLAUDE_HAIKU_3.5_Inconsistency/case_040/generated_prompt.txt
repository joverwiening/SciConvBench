Simulation of Incompressible Water Flow in Peristaltic Channel

Simulation Domain:
- Channel length: 0.1 m
- 2D mesh extruded one cell in spanwise direction
- Mesh type: Dynamic mesh using `dynamicMotionSolverFvMesh`

Fluid Properties:
- Fluid: Water
- Kinematic viscosity (nu): 1e-6 m^2/s

Mesh Motion:
- Wall motion: Sinusoidal displacement
- Wavelength: 0.5 times channel length (0.05 m)
- Amplitude: 0.005 m (5 mm)
- Frequency: 1 Hz (one complete wave cycle per second)

Boundary Conditions:
- Inlet: `fixedValue` velocity
- Outlet: `zeroGradient` velocity, `fixedValue uniform 0` pressure
- Stationary walls: `noSlip` velocity
- Moving wall: `movingWallVelocity` with sinusoidal displacement

Solver Configuration:
- Application: `solidDisplacementFoam`
- Mesh handling: `dynamicMotionSolverFvMesh`
- Displacement method: `displacementLaplacian`

Mesh Boundary Treatment:
- Spanwise boundaries: `frontAndBack` set to `empty`
