Create a steady-state turbulent pipe flow simulation using OpenFOAM's simpleFoam solver with the k-epsilon RANS turbulence model.
Use water as the fluid with a kinematic viscosity of 1e-6 m²/s.
Set the pipe diameter to 0.1 m.
Set the inlet velocity to 1 m/s.
Initialize turbulent kinetic energy (k) to zero in the `0/k` file with `internalField uniform 0;`.
Initialize turbulent dissipation rate (epsilon) to zero in the `0/epsilon` file with `internalField uniform 0;`.
Apply `kqRWallFunction` boundary condition for k on the pipe wall.
Apply `epsilonWallFunction` boundary condition for epsilon on the pipe wall.
Use standard k-epsilon RANS turbulence model in the simulation setup.
