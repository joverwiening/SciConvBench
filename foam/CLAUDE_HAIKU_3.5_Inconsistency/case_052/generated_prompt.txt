Lid-Driven Cavity Simulation Specification:

Simulation Domain:
The simulation will be a 2D lid-driven cavity with dimensions 1m x 1m.

Solver:
Use `nonNewtonianIcoFoam` solver for non-Newtonian fluid simulation.

Boundary Conditions:
Top wall (lid) moves with velocity (1 0 0) m/s.
All other walls are stationary with no-slip condition.

Fluid Properties:
Use Power-Law non-Newtonian fluid model with the following parameters:
- Maximum kinematic viscosity (nuMax): 1 m²/s
- Minimum kinematic viscosity (nuMin): 1e-6 m²/s
- Consistency index (k): 0.1 Pa·s^n
- Power-law index (n): 0.5

Simulation Type:
Transient simulation.

Configuration Files:
In `constant/transportProperties`:
- Set transportModel to Power-Law
- Define viscosity parameters as specified above.

Numerical Setup:
Prepare 2D computational mesh for the 1m x 1m cavity.
Configure time-stepping and discretization schemes appropriate for transient non-Newtonian flow.
