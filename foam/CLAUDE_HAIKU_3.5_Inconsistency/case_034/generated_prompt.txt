Set up a 2D dam break simulation using OpenFOAM's interFoam solver for a water-air system.
Create a computational domain that is 2m long and 1m high.
Use a single cell in the z-direction for 2D simulation.
Define gravity in 'constant/g' as (0 -9.81 0).
Configure 'blockMeshDict' with front and back patches as 'frontAndBack' with 'type wall'.
In the '0' directory, set 'frontAndBack' patches to:
- Velocity (U): 'noSlip' boundary condition
- Scalar fields (p_rgh, alpha.water): 'zeroGradient' boundary condition
Place the initial water column on the left side of the domain.
Set the initial water column geometry to:
- Width: 1m (50% of domain width)
- Height: 0.5m (half of domain height)
- Position: Starting from the left domain boundary, centered vertically
Use setFieldsDict to define the initial water column volume fraction.
