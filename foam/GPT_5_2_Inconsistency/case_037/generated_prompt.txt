Assume OpenFOAM Foundation, OpenFOAM 11.

Model steady, incompressible, laminar flow of water in a 2D channel with a rigid, stationary obstacle using simpleFoam.

Use a 3D mesh extruded one cell in the spanwise (z) direction to emulate 2D.

Set the frontAndBack patches to type empty for all fields.

Set kinematic viscosity nu = 1e-6 m^2/s.

Use a rectangular channel domain of length 2.2 m in x and height 0.41 m in y.

Extrude in z with thickness 0.01 m and 1 cell.

Place a circular cylinder obstacle of diameter 0.1 m centered at (0.2 m, 0.2 m) in the channel.

Name boundary patches inlet, outlet, walls, obstacle, frontAndBack.

Set 0/U inlet to fixedValue uniform (0.1 0 0).

Set 0/U outlet to zeroGradient.

Set 0/U walls and obstacle to noSlip.

Set 0/U frontAndBack to empty.

Set 0/p inlet to zeroGradient.

Set 0/p outlet to fixedValue uniform 0.

Set 0/p walls and obstacle to zeroGradient.

Set 0/p frontAndBack to empty.

Set system/controlDict application to simpleFoam.

Use a steady-state SIMPLE setup suitable for laminar flow.

Use fvSchemes with bounded second-order convection for U and standard Laplacian/gradient schemes appropriate for simpleFoam.

Use fvSolution with a pressure reference at the outlet and standard SIMPLE relaxation factors for stable convergence.

Run until residuals for U and p drop at least 3 orders of magnitude and monitored forces on the obstacle reach steady values.

Post-process velocity and pressure fields and report drag coefficient on the cylinder.
