Assume OpenFOAM Foundation v10 and use interFoam (two-phase VOF) as the closest standard solver, modeling oil+gas as a single “light” phase and water as the “heavy” phase, because stock interFoam cannot natively track three immiscible phases.

Create a closed, initially filled horizontal gravity separator case with no inlets and no outlets.

Use a 2D approximation as a thin slice: one cell in the z-direction with empty boundary conditions on front/back.

Set gravity to g (0 -9.81 0).

Use a rectangular domain representing the separator cross-section and length: L = 2.0 m, H = 0.5 m, W = 0.01 m (thin slice).

Generate a structured mesh with blockMesh: Nx = 400 along x, Ny = 100 along y, Nz = 1 along z.

Set boundary patches: leftWall, rightWall, bottomWall, topWall as wall; frontAndBack as empty.

Set velocity boundary conditions U: noSlip on all walls; empty on front/back.

Set pressure boundary conditions p_rgh: fixedFluxPressure on all walls; empty on front/back.

Define phases in constant/transportProperties for a two-phase interFoam case: phases (water oilGas).

Use water properties: rho = 1000 kg/m3, nu = 1.0e-6 m2/s.

Use oilGas properties (representing a light immiscible phase): rho = 50 kg/m3, nu = 1.5e-5 m2/s.

Set surface tension sigma = 0.03 N/m between water and oilGas.

Initialize a stratified mixture using system/setFieldsDict by setting alpha.water = 1 in the bottom region and alpha.water = 0 in the top region with a horizontal interface at y = 0.25 m, with a small smoothing band of 0.01 m.

Use alpha.water as the tracked volume fraction field; interpret alpha.oilGas = 1 - alpha.water.

Set alpha.water boundary conditions: zeroGradient on all walls; empty on front/back.

Set contact angle at walls using alphaContactAngle on bottomWall and side walls with theta = 60 degrees; use zeroGradient on topWall; empty on front/back.

Configure system/controlDict: application interFoam; startFrom startTime; startTime 0; endTime 20; deltaT 1e-4 with adjustable time step; maxCo 0.5; writeControl timeStep; writeInterval 200; purgeWrite 0; writeFormat ascii; writePrecision 8.

Configure system/fvSchemes with bounded, interface-compressive schemes: div(phi,alpha) using Gauss vanLeer; div(phirb,alpha) using Gauss interfaceCompression; div(phi,U) using Gauss linearUpwind grad(U); laplacian using Gauss linear corrected; grad using Gauss linear; interpolation linear; snGrad corrected.

Configure system/fvSolution with PIMPLE settings suitable for interFoam: nOuterCorrectors 2; nCorrectors 2; nNonOrthogonalCorrectors 0; set solvers for p_rgh (PCG/GAMG) and U/alpha (smoothSolver) with tight tolerances; enable MULES for alpha.

Run workflow: blockMesh; setFields; interFoam.

Post-process by writing and visualizing alpha.water iso-surfaces and contours over time to observe separation and interface evolution under gravity.
