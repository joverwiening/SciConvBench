Build a 2D mesh using blockMesh extruded one cell in z from z = 0 to z = 0.01 m and set the frontAndBack patches to type empty.
Define the wedge apex at (0, 0).
Define the 10-degree ramp from (0, 0) to (1.0, 0.17632698).
Define the inlet plane at x = -0.5 m.
Define the outlet plane at x = 2.0 m.
Define the top farfield boundary at y = 1.0 m.
Define the bottom boundary as y = 0 from x = -0.5 to x = 0, then the ramp from (0, 0) to (1.0, 0.17632698), then y = 0.17632698 from x = 1.0 to x = 2.0.
Use a uniform base mesh resolution of Nx = 500 cells in x from -0.5 to 2.0, Ny = 200 cells in y from 0 to 1.0, and Nz = 1 cell in z from 0 to 0.01.
Use simpleGrading (1 1 1) for the blockMesh.
Set inlet boundary conditions as fixedValue for U, p, and T using the specified freestream values.
Set outlet boundary conditions as waveTransmissive (or zeroGradient) for p and T and zeroGradient for U.
Set the wedge wall and the top boundary as slip walls.
Set frontAndBack to empty for all fields.
Initialize the domain fields consistently with the freestream values for U, p, and T.
Run rhoCentralFoam to steady state or until the shock structure is stationary, using appropriate time step control for stability (Courant number control) in system/controlDict.
