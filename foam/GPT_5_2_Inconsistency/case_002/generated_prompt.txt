Set up an OpenFOAM Foundation v10 case for 2D Rayleigh–Bénard convection in a 9 m × 1 m rectangular cavity extruded 1 cell in z, with gravity (0 -9.81 0) m/s².
Use buoyantFoam with Boussinesq buoyancy and solve for internal energy e (not h).
Create the mesh with blockMesh as a single hex block from (0 0 0) to (9 1 0.1) with 90×10×1 cells, and set front and back patches to type empty to enforce 2D.
Define patches: bottom (y=0), top (y=1), left (x=0), right (x=9), front/back (z-normal) as empty.
In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq and set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.
In constant/momentumTransport set simulationType RAS, RAS model kEpsilon, turbulence on, and printCoeffs on.
In constant/g set value (0 -9.81 0).
Initialize 0/U with internalField uniform (0 0 0), noSlip on bottom/top/left/right, and empty on front/back.
Initialize 0/T with internalField uniform 300, bottom fixedValue 305, top fixedValue 295, left/right zeroGradient (adiabatic), and empty on front/back.
Initialize 0/p with internalField uniform 0, bottom/top/left/right calculated, and empty on front/back.
Initialize 0/p_rgh with internalField uniform 0, bottom/top/left/right fixedFluxPressure, and empty on front/back.
Initialize 0/k with internalField uniform 1e-5, kqRWallFunction on bottom/top/left/right, and empty on front/back.
Initialize 0/epsilon with internalField uniform 1e-5, epsilonWallFunction on bottom/top/left/right, and empty on front/back.
Initialize 0/nut with internalField uniform 0, nutkWallFunction on bottom/top/left/right, and empty on front/back.
Initialize 0/alphat with internalField uniform 0, compressible::alphatJayatillekeWallFunction on bottom/top/left/right with Prt 0.85, and empty on front/back.
Create 0/e and set internalField uniform e0 corresponding to T=300 K using e = Cv*(T - T0) with Cv=714.3 and T0=300 so e0=0.
In 0/e set bottom fixedValue with eBottom = Cv*(305-300)=3571.5, top fixedValue with eTop = Cv*(295-300)=-3571.5, left/right zeroGradient, and front/back empty.
In system/controlDict set application buoyantFoam, startFrom startTime, startTime 0, stopAt endTime, endTime 1000, deltaT 1, adjustTimeStep no, writeControl timeStep, writeInterval 50, and set appropriate purgeWrite/writeFormat/writePrecision as defaults.
In system/fvSchemes use standard second-order schemes suitable for buoyantFoam (e.g., Gauss linear for gradients, Gauss linearUpwind/limitedLinear for div terms, and Gauss linear corrected for laplacians) without enabling any time-step adjustment controls.
In system/fvSolution set solvers for p_rgh and for U, e, k, epsilon to tolerance 1e-8 and relTol 0.01, and set the corresponding Final solvers to relTol 0.
In system/fvSolution anchor pressure using referenceCell and referenceValue 0 (choose a convenient cell near the domain center).
Run blockMesh, then run buoyantFoam for 0–1000 s and write results every 50 s-equivalent steps.
