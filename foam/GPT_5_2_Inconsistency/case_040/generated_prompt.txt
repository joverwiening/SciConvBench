Assume OpenFOAM Foundation v11.

Use an incompressible transient moving-mesh solver suitable for dynamic mesh motion with PIMPLE, and set application pimpleFoam in system/controlDict.

Model a 2D channel as a 3D mesh extruded one cell in the spanwise direction, and set the spanwise patches to type empty (frontAndBack).

Use water kinematic viscosity nu 1e-6 m^2/s in constant/transportProperties.

Create a rectangular channel geometry with length 0.10 m and height 0.01 m.

Extrude in the spanwise direction with thickness 0.001 m and 1 cell.

Name boundary patches inlet, outlet, stationaryWalls, movingWall, frontAndBack.

Use dynamicMotionSolverFvMesh in constant/dynamicMeshDict.

Use displacementLaplacian (or equivalent Laplacian-based motion solver) for mesh motion, with appropriate diffusivity to maintain mesh quality.

Prescribe movingWall motion via 0/pointDisplacement using oscillatingDisplacement.

Use a sinusoidal wall-normal displacement on movingWall with amplitude 0.001 m and frequency 2 Hz.

Set pointDisplacement fixedValue uniform (0 0 0) on all non-moving boundaries.

Set 0/U inlet to fixedValue uniform (0.10 0 0).

Set 0/U outlet to zeroGradient.

Set 0/U stationaryWalls to noSlip.

Set 0/U movingWall to movingWallVelocity.

Set 0/p outlet to fixedValue uniform 0.

Set 0/p inlet to zeroGradient.

Set 0/p all walls to zeroGradient.

Use PIMPLE settings in system/fvSolution appropriate for transient incompressible flow with moving mesh, including at least 2 outer correctors and non-orthogonal correctors as needed.

Use second-order spatial discretization schemes in system/fvSchemes where stable, and a bounded scheme for convection of U.

Choose a time step to keep max Courant number below 0.5, and enable adjustableTimeStep in system/controlDict.

Run long enough to capture multiple wall oscillation periods, and write results at a cadence that resolves the oscillation (e.g., at least 50 time samples per period).

Enable mesh motion output fields as needed to post-process deformation and wall kinematics.
