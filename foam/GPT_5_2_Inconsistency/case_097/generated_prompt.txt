Use OpenFOAM laplacianFoam to run a transient 2D heat conduction case on a 1 m × 1 m plate.
Create a 3D mesh by extruding the 2D plate one cell in the z-direction to a thickness of 0.01 m.
Define the two out-of-plane faces as a patch named frontAndBack.
In constant/polyMesh/boundary, set frontAndBack type to wall.
In 0/T, set frontAndBack to type zeroGradient.
Set the four in-plane edges (left, right, bottom, top) to zeroGradient for T to represent adiabatic boundaries.
Set thermal diffusivity DT to 1e-5 m^2/s in the transport properties for laplacianFoam.
Initialize T uniformly to 300 K in the entire domain.
Choose simulation controls (time step and end time) such that the run is stable and completes, while expecting no temperature change because the initial condition is uniform and all boundaries are zeroGradient.
Verify that T remains 300 K everywhere for all saved time directories within numerical tolerance.
