Set up a 2D, incompressible, steady-state RANS simulation of airflow over a symmetric airfoil using OpenFOAM simpleFoam.
Assume 0° angle of attack, meaning the inlet velocity vector is aligned with the airfoil chord and equals (10 0 0) m/s.
Use a C-grid topology computational domain around the airfoil.
Create a mesh that is one cell thick in the z-direction to represent a 2D case.
In system/blockMeshDict, define the frontAndBack patch in the boundary entry with type wall.
In system/blockMeshDict, include the frontAndBack faces list starting with (0 4 7 3) and (1 2 6 5) and include all remaining z-normal faces that close the single-cell thickness as part of this same frontAndBack patch.
In 0/U, set the inlet boundary condition to fixedValue uniform (10 0 0).
In 0/U, set the outlet boundary condition to zeroGradient.
In 0/U, set the airfoil surface boundary condition to noSlip.
In 0/U, set the frontAndBack boundary condition to noSlip.
In 0/p, set the inlet boundary condition to zeroGradient.
In 0/p, set the outlet boundary condition to fixedValue uniform 0.
In 0/p, set the airfoil surface boundary condition to zeroGradient.
In 0/p, set the frontAndBack boundary condition to zeroGradient.
