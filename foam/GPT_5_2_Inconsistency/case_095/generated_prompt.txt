Use OpenFOAM simpleFoam for a 2D, steady-state, incompressible RANS simulation of airflow over a NACA0012 airfoil at 5 degrees angle of attack.
Use the k-omega SST turbulence model.
Use a C-grid computational domain with a mesh that is one cell thick in the z-direction.
Use the existing mesh located in constant/polyMesh.
Ensure the boundary patches are named inlet, outlet, airfoil, and frontAndBack.
In constant/polyMesh/boundary, set the frontAndBack patch type to wall.
In 0/U, set inlet to fixedValue uniform (10 0 0).
In 0/p, set inlet to zeroGradient.
In 0/k, set inlet to a fixedValue computed from turbulence intensity 1% and viscosity ratio 10.
In 0/omega, set inlet to a fixedValue computed from turbulence intensity 1% and viscosity ratio 10.
In 0/U, set outlet to inletOutlet with inletValue uniform (10 0 0) and value uniform (10 0 0).
In 0/p, set outlet to fixedValue uniform 0.
In 0/k, set outlet to inletOutlet with inletValue equal to the inlet k value and value equal to the inlet k value.
In 0/omega, set outlet to inletOutlet with inletValue equal to the inlet omega value and value equal to the inlet omega value.
In 0/U, set airfoil to noSlip.
In 0/p, set airfoil to zeroGradient.
In 0/k, set airfoil to kqRWallFunction with an appropriate initial value.
In 0/omega, set airfoil to omegaWallFunction with an appropriate initial value.
In 0/U, set frontAndBack to noSlip.
In 0/p, set frontAndBack to zeroGradient.
In 0/k, set frontAndBack to zeroGradient.
In 0/omega, set frontAndBack to zeroGradient.
In constant/transportProperties, set the kinematic viscosity nu to 1.5e-05 m^2/s to represent standard sea-level air at 15°C.
Initialize internal fields for U, p, k, and omega consistently with the inlet conditions and a reasonable freestream guess.
Run the case to steady convergence using simpleFoam with appropriate relaxation factors and residual controls for stable convergence.
