Use OpenFOAM Foundation distribution, version v11, and set up a steady-state buoyancy-driven natural-convection case using buoyantSimpleFoam.  
Model a vertical circular pipe aligned with the Z-axis with length 2.0 m and diameter 0.1 m.  
Create three boundary patches named inlet (z=0), outlet (z=2), and wall (cylindrical surface).  
Enable gravity in constant/g as g (0 0 -9.81);.  
Use air thermophysical properties with equationOfState perfectGas and operating/reference pressure pRef = 101325 Pa.  
Solve in terms of p_rgh as used by buoyantSimpleFoam.  
Assume a turbulent RANS model as best practice for buoyancy-driven internal flow in this geometry, using RAS kOmegaSST with wall functions.  
Set the inlet velocity boundary condition U to pressureInletOutletVelocity with inletValue uniform (0 0 0).  
Set the inlet temperature T to fixedValue uniform 300.  
Set the outlet pressure p_rgh to fixedValue uniform 0 to represent an opening to ambient.  
Set the outlet U to zeroGradient.  
Set the outlet T to zeroGradient.  
Set the wall velocity U to noSlip.  
Set the wall temperature T to fixedValue uniform 350.  
Generate a mesh targeting 200k–500k cells total.  
Use near-wall inflation layers on the wall patch with 10–15 layers, growth ratio about 1.2, and first-layer thickness chosen to target y+ in the 30–100 range consistent with wall functions.  
Use second-order spatial discretization schemes suitable for steady buoyant RANS (bounded where appropriate).  
Use SIMPLE settings appropriate for buoyantSimpleFoam with under-relaxation factors suitable for stable convergence of coupled buoyancy and turbulence.  
Initialize fields with quiescent flow (U = 0) and uniform temperature 300 K, and initialize turbulence fields consistent with low inlet velocity (small but nonzero k and omega) to aid convergence.  
Run buoyantSimpleFoam to steady convergence using residual targets and monitoring of mass balance and outlet mass flow rate.  
Post-process to report the established buoyancy-driven flow rate, axial velocity profile, and temperature distribution along the pipe.
