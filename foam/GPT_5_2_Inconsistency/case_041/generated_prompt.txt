Assume OpenFOAM Foundation distribution, version v11.

Create a new case directory based on $FOAM_TUTORIALS/incompressible/pimpleFoam/laminar/pitzDaily (or an equivalent pimpleFoam incompressible laminar tutorial) and replace geometry, mesh, and boundary conditions as specified below.

Model a 2D laminar incompressible flow past a cylinder in a rectangular channel of length 2.2 m and height 0.41 m.

Place a circular cylinder of diameter 0.1 m with center at (x,y) = (0.2, 0.2).

Use a 2D extruded mesh with one cell in the z-direction and set the frontAndBack patches to empty.

Use kinematic viscosity nu = 1e-3 m^2/s in constant/transportProperties.

Use a uniform inlet velocity U = (1 0 0) m/s.

Use pimpleFoam as the solver in system/controlDict.

Set system/controlDict startTime 0.

Set system/controlDict endTime 200.

Set system/controlDict deltaT 1.

Set system/controlDict writeInterval 10.

Set system/controlDict application pimpleFoam.

Set system/controlDict to write fields U and p.

Set constant/turbulenceProperties simulationType laminar.

Generate the mesh using a blockMesh + snappyHexMesh workflow.

Create a background blockMesh for a box spanning x=[0,2.2], y=[0,0.41], z=[0,0.01] with one cell in z.

Define blockMesh boundary patches named inlet (x=0), outlet (x=2.2), topAndBottom (y=0 and y=0.41), and frontAndBack (z=0 and z=0.01).

Create a cylinder surface for snappyHexMesh as a searchable geometry (e.g., searchableCylinder) aligned with the z-axis, centered at (0.2,0.2), with radius 0.05, spanning the full z thickness.

Use snappyHexMesh to castellate and snap the mesh to the cylinder surface and create a boundary patch named cylinderWall.

Add boundary layer refinement on cylinderWall sufficient to resolve laminar separation (use at least 5 prism layers with a modest expansion ratio).

Refine the mesh in a wake region downstream of the cylinder (e.g., a refinement box from x=0.2 to x=2.2 and y=0 to y=0.41) to capture vortex shedding.

Run checkMesh and ensure the mesh is valid and the frontAndBack patches are of type empty.

In 0/U, set internalField uniform (1 0 0).

In 0/U, set inlet type fixedValue with value uniform (1 0 0).

In 0/U, set outlet type zeroGradient.

In 0/U, set cylinderWall type noSlip.

In 0/U, set topAndBottom type noSlip.

In 0/U, set frontAndBack type empty.

In 0/p, set internalField uniform 0.

In 0/p, set inlet type zeroGradient.

In 0/p, set outlet type fixedValue with value uniform 0.

In 0/p, set cylinderWall type zeroGradient.

In 0/p, set topAndBottom type zeroGradient.

In 0/p, set frontAndBack type empty.

In system/fvSchemes, use second-order spatial schemes suitable for transient incompressible flow (e.g., linear for grad, linearUpwind or limitedLinear for div(phi,U), and linear for laplacian with corrected).

In system/fvSchemes, use a transient time scheme suitable for vortex shedding (e.g., backward).

In system/fvSolution, configure PIMPLE settings for transient incompressible flow with at least 2 correctors and 1 non-orthogonal corrector, and set appropriate tolerances for p and U.

In system/fvSolution, use GAMG for p and a smoothSolver (e.g., smoothSolver with symGaussSeidel) for U.

In system/controlDict, enable adjustable time stepping if needed to keep Courant number below 1, otherwise keep deltaT=1 as specified.

Initialize the case with potentialFoam (optional) or start directly from the uniform initial fields.

Run blockMesh.

Run snappyHexMesh with overwrite enabled.

Run checkMesh.

Run pimpleFoam until endTime 200.

Post-process to observe von Kármán vortex shedding by visualizing vorticity (curl of U) and time-dependent velocity/pressure fields in ParaView.

Confirm vortex shedding by monitoring lift/drag coefficients on the cylinder (e.g., using functionObjects forces) and verifying periodic oscillations after initial transients.
