Use OpenFOAM Foundation v2312.
Model 2D Rayleigh–Bénard convection in a rectangular cavity using buoyantPimpleFoam with the Boussinesq approximation.
Set the domain size to width 1.0 m and height 0.1 m.
Make the case 2D by using a single cell in the z direction and applying empty boundary conditions on the front and back patches.
Use water properties with constant reference properties suitable for Boussinesq modeling around 300 K.
Set the bottom wall temperature to 305 K.
Set the top wall temperature to 295 K.
Set the side walls to adiabatic with zeroGradient for T.
Use no-slip velocity (fixedValue uniform (0 0 0)) on all four walls.
Use fixedFluxPressure on all walls for p_rgh (or p as appropriate for the solver setup).
Use laminar flow (no turbulence model).
Choose a target Rayleigh number in the convective regime by using the above geometry and ΔT, and set Boussinesq coefficients for water accordingly (rho0, beta, T0, Cp, mu, kappa/Pr) at 300 K.
Set constant/thermophysicalProperties thermoType to hePsiThermo.
Set constant/thermophysicalProperties equationOfState to Boussinesq.
In system/fvSchemes, set div(phi,T) to Gauss linear.
In system/fvSchemes, set div(rhoPhi,U) to Gauss upwind.
Use a structured mesh with 200 cells in x and 100 cells in y.
Set the transient simulation end time to 200 s.
Select a time step controlled by a maximum Courant number of 0.5 using adjustable time stepping.
Initialize the velocity field to zero everywhere.
Initialize the temperature field to a linear profile from 305 K at the bottom to 295 K at the top (or uniform 300 K if a linear initialization is not desired).
Run until a statistically steady convective pattern is established and save fields frequently enough to resolve transient plume dynamics (e.g., writeInterval corresponding to 0.5–1.0 s).
