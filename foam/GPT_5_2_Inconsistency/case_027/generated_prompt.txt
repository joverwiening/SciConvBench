Use standard wall functions, so design the mesh for yPlus in the 30–100 range, targeting yPlus ≈ 50 on the walls.

Assume the working fluid is air at 20°C.
Set kinematic viscosity nu = 1.5e-5 m^2/s in constant/transportProperties.
Use incompressible simpleFoam with kOmegaSST RANS.

Set operating pressure as kinematic pressure with pRef = 0 and p at outlet fixedValue uniform 0.

Use a backward-facing step with step height H = 0.01 m.
Use expansion ratio ER = 2.0, so upstream channel height = 0.01 m and downstream channel height = 0.02 m.
Use upstream length (inlet to step) = 0.10 m (10H).
Use downstream length (step to outlet) = 0.30 m (30H).
Use spanwise thickness = 0.01 m and apply empty boundary condition on front/back to make the case 2D.

Set inlet freestream velocity to 20 m/s with a fixedValue uniform (20 0 0).
Set outlet velocity to zeroGradient.
Set walls to noSlip.

Compute inlet turbulence from turbulence intensity I = 0.05 and mixing length L = 0.005 m.
Set inlet k = 1.5*(U*I)^2 = 1.5 m^2/s^2 and apply fixedValue uniform 1.5 in 0/k at inlet.
Set inlet omega = sqrt(k)/(Cmu^0.25*L) with Cmu = 0.09, giving omega = 447.2 1/s, and apply fixedValue uniform 447.2 in 0/omega at inlet.

Use standard wall functions on walls for turbulence variables.
Set k on walls to kqRWallFunction.
Set omega on walls to omegaWallFunction.
Set nut on walls to nutkWallFunction.

Set outlet boundary conditions for turbulence variables to zeroGradient for k and omega.
Set inlet nut to calculated and outlet nut to calculated with zeroGradient where appropriate.

Use SIMPLE algorithm with steady-state settings suitable for simpleFoam.
Use second-order schemes for convection (e.g., linearUpwind for U, k, omega) and bounded schemes for stability.
Run until residuals are converged and monitor reattachment length downstream of the step.
