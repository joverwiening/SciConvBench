Use OpenFOAM version v10 as the reasonable best-practice assumption.
Simulate 2D laminar transient incompressible flow past a square cylinder in a channel using icoFoam.
Set the domain size to 2.2 m in x, 0.41 m in y, and 0.01 m in z (one cell thick).
Place a 0.1 m × 0.1 m square cylinder with its center at (x, y) = (0.2, 0.205) m.
Set kinematic viscosity nu = 0.001 m^2/s.
Use an inlet parabolic velocity profile with Umax = 1.5 m/s in the x-direction.
Use inlet bulk velocity Umean = (2/3)Umax = 1.0 m/s as the reference mean velocity implied by the parabolic profile.
In 0/U, set inlet to a parabolic inflow profile with maxValue (1.5 0 0).
In 0/U, set outlet to zeroGradient.
In 0/U, set topAndBottomWalls to noSlip.
In 0/U, set cylinder to noSlip.
In 0/U, set frontAndBack to empty.
In 0/p, set inlet to zeroGradient.
In 0/p, set outlet to fixedValue uniform 0.
In 0/p, set topAndBottomWalls to zeroGradient.
In 0/p, set cylinder to zeroGradient.
In 0/p, set frontAndBack to empty.
In constant/polyMesh/boundary, define frontAndBack patches with type empty.
Run the transient simulation to endTime = 10 s.
