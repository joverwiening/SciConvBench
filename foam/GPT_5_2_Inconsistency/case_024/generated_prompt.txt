Use OpenFOAM Foundation v11 as the target version.
Create a steady-state incompressible RANS case using simpleFoam for swirling flow in a straight circular pipe represented by a 2D axisymmetric wedge.
Use a 2D wedge mesh with a wedge angle of 5 degrees in the circumferential direction and one cell in the circumferential direction.
Use a pipe inner radius of 0.05 m.
Use a pipe axial length of 1.0 m.
Set the mesh resolution to 200 cells in the axial direction and 50 cells in the radial direction, with 1 cell in the circumferential direction.
Generate the mesh with blockMesh using a single hex block spanning r=0 to r=R and x=0 to x=L, with the two wedge planes at ±2.5 degrees.
Define boundary patches in system/blockMeshDict as inlet, outlet, wall, axis, front, and back.
Set the pipe surface patch type to wall.
Set the inlet patch type to patch.
Set the outlet patch type to patch.
Set the axis patch type to symmetry (axis) and place it on the r=0 line.
Set the wedge planes to type wedge using the provided front/back patch definitions with faces (0 3 2 1) and (4 5 6 7).
In 0/U, impose swirl at the inlet by prescribing both axial and tangential velocity components.
Use an inlet axial bulk velocity of 1.0 m/s.
Use an inlet tangential velocity profile of solid-body rotation, Utheta(r)=Omega*r, with Omega chosen so that Utheta at the wall equals 0.5 m/s.
Set outlet U to zeroGradient.
Set wall U to noSlip.
In 0/p, set inlet to zeroGradient and outlet to fixedValue uniform 0.
Use the kOmegaSST turbulence model.
In 0/k, 0/omega, set inlet turbulence using a turbulence intensity of 5% and a turbulent length scale of 0.07*D.
Set outlet k and omega to zeroGradient.
Set wall k to kqRWallFunction and omega to omegaWallFunction.
In constant/transportProperties, set nu to 1.5e-5 m^2/s (air-like).
In constant/turbulenceProperties, enable RAS and select kOmegaSST.
In system/fvSchemes, use bounded second-order schemes suitable for simpleFoam (e.g., bounded Gauss linearUpwind for div(phi,U) and Gauss linear for gradients and laplacians).
In system/fvSolution, use SIMPLE with consistent on, set appropriate relaxation factors (e.g., p 0.3, U 0.7, turbulence 0.7), and use GAMG for p and smoothSolver for U, k, omega.
Add functionObjects to compute and write axial pressure drop and area-averaged outlet swirl (e.g., patchAverage of U on outlet and wall shear stress).
Run blockMesh, then simpleFoam until residuals drop at least 3 orders of magnitude and monitored integral quantities reach steady values.
