Use OpenFOAM v10 as the assumed version.
Create a new case based on the standard laplacianFoam tutorial structure.
Model a 1 m × 1 m square plate in x–y with thickness 1 cell in z to enforce a 2D simulation.
Set the plate extents to x ∈ [0, 1], y ∈ [0, 1], z ∈ [0, 0.01].
Use a structured mesh with 100 cells in x, 100 cells in y, and 1 cell in z.
In system/blockMeshDict, define 6 patches named left, right, top, bottom, frontAndBack.
In system/blockMeshDict, set left, right, top, bottom to type wall.
In system/blockMeshDict, set frontAndBack to type empty.
In 0/T, set internalField to uniform 300 K.
In 0/T, set left to fixedValue uniform 400 K.
In 0/T, set right to fixedValue uniform 300 K.
In 0/T, set top to zeroGradient.
In 0/T, set bottom to zeroGradient.
In 0/T, set frontAndBack to empty.
In constant/transportProperties, set a constant thermal diffusivity alpha to 1.0e-5 m2/s.
In system/fvSchemes, use Gauss linear for laplacian schemes and Gauss linear for grad schemes.
In system/fvSolution, use a PCG solver with DIC preconditioner for T.
In system/fvSolution, set solver tolerance to 1e-10 and relTol to 0 for T.
In system/controlDict, run laplacianFoam in steady-state mode using SIMPLE.
In system/controlDict, set writeControl to timeStep and writeInterval to 100.
In system/controlDict, set endTime to 5000 iterations.
In system/fvSolution, set SIMPLE residualControl for T to 1e-6 to declare steady state and stop iterating when achieved.
Run blockMesh, then run laplacianFoam.
Post-process the steady-state temperature field T to obtain the 2D temperature distribution over the plate.
