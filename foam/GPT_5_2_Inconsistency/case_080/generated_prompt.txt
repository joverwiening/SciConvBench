Use OpenFOAM v10 (or the closest available ESI OpenFOAM release) and base the case on the multiphaseEulerFoam tutorial structure.
Use solver multiphaseEulerFoam (not twoPhaseEulerFoam) to model a true three-Eulerian-phase system.
Define phases in constant/phaseProperties as (air water sand).
Set gravity in constant/g as (0 -9.81 0).
Create a 3D cylindrical column domain with diameter 0.1 m and height 1.0 m, with y as the vertical axis.
Generate a hexa-dominant mesh with a target cell size of ~5 mm (about 20 cells across the diameter and 200 cells over the height), using blockMesh plus a cylinder mapping approach or snappyHexMesh around a cylinder.
Create boundary patches named bottomInlet (y=0), topOutlet (y=1), and wall (cylindrical side wall).
Run a transient simulation from t=0 to t=10 s.
Use adjustable time stepping with maxCo ~0.3 and initial deltaT ~1e-4 s.
Model air as a perfect gas with rho = rho(p,T) using a standard perfectGas equation of state.
Model water as incompressible with constant density 1000 kg/m3.
Model sand as a granular Eulerian phase with constant density 2650 kg/m3 and particle diameter 500e-6 m.
Enable interphase momentum exchange using a standard drag model suitable for gas-liquid-solid, using Gidaspow-type drag where applicable for gas-solid and an appropriate dispersed drag for gas-liquid and liquid-solid consistent with multiphaseEulerFoam capabilities.
Enable granular temperature / kinetic theory of granular flow (KTGF) for the sand phase with standard closures (restitution coefficient ~0.9, specularity ~0.1, friction angle ~30 deg) unless the chosen OpenFOAM release requires different defaults.
Use RAS turbulence with k-epsilon for the continuous phases (air and water) and standard dispersed-phase turbulence treatment for sand as supported by the solver.
Set initial volume fractions in 0/alpha.air, 0/alpha.water, 0/alpha.sand such that alpha.sand=0.6 and alpha.water=0.4 for 0 <= y <= 0.2 m, alpha.water=1 and alpha.sand=0 for 0.2 < y <= 1.0 m, and alpha.air=0 everywhere initially.
Set initial velocities in 0/U.air, 0/U.water, 0/U.sand to (0 0 0) everywhere.
Set initial pressure field p_rgh (or p depending on solver setup) consistent with hydrostatic water column and 0 Pa gauge at the top outlet reference.
At bottomInlet, set U.air to fixedValue (0 0.5 0).
At bottomInlet, set U.water to fixedValue (0 0 0).
At bottomInlet, set U.sand to fixedValue (0 0 0).
At topOutlet, set pressure to fixedValue 0 Pa gauge (use p or p_rgh consistent with the solver formulation).
At topOutlet, set U.air, U.water, and U.sand to zeroGradient (or pressureInletOutletVelocity if required for stability by the chosen OpenFOAM release).
At wall, set noSlip for U.water and U.sand, and noSlip for U.air (or slip for U.air only if required by the intended physics), and apply appropriate wall functions for turbulence if RAS is used.
At wall, set zeroGradient for volume fractions and enforce alpha summation to 1 via the solver’s phase-fraction handling.
At topOutlet, set alpha.air to inletOutlet with inletValue 0 and value 0, and set alpha.water and alpha.sand to inletOutlet with inletValue 1 for water and 0 for sand, consistent with allowing outflow and preventing unphysical inflow.
At bottomInlet, set alpha.air to fixedValue 1 to represent pure air injection at the inlet.
At bottomInlet, set alpha.water to fixedValue 0.
At bottomInlet, set alpha.sand to fixedValue 0.
Configure fvSchemes with bounded, conservative schemes for alpha transport (e.g., upwind or limitedLinear for div(phi,alpha)) and second-order schemes for momentum where stable.
Configure fvSolution with PIMPLE (or PISO/PIMPLE hybrid) suitable for transient multiphase Euler simulations, using under-relaxation factors for stability.
Write results every 0.1 s.
Include function objects to compute bed height (from alpha.sand iso-surface), phase-averaged velocities, and pressure drop between y=0.05 m and y=0.95 m.
Validate that alpha.air+alpha.water+alpha.sand remains 1 within numerical tolerance throughout the run.
Ensure the case runs without phase fraction negativity by using bounded solvers and limiters for alpha fields.
