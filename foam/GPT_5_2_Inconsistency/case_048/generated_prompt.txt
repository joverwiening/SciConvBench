Simulate buoyancy-driven heat transfer in a 2D channel using OpenFOAM buoyantPimpleFoam.
Use air initialized at 300 K in the internal field for T.
Apply gravity in the negative y-direction in constant/g (e.g., value (0 -9.81 0)).
Use mesh patch names bottomWall, topWall, inlet, outlet.

In 0/T, set internalField uniform 300.
In 0/T, set bottomWall to type fixedValue with value uniform 400.
In 0/T, set topWall to type zeroGradient (adiabatic, zero heat flux).
In 0/T, set inlet to type zeroGradient.
In 0/T, set outlet to type zeroGradient.

In 0/U, set solid walls bottomWall and topWall to no-slip using type fixedValue with value uniform (0 0 0).
In 0/U, set inlet to type slip.
In 0/U, set outlet to type slip.

In 0/p_rgh, set bottomWall to type fixedFluxPressure with value uniform 0.
In 0/p_rgh, set topWall to type fixedFluxPressure with value uniform 0.
In 0/p_rgh, set inlet to type fixedFluxPressure with value uniform 0.
In 0/p_rgh, set outlet to type fixedFluxPressure with value uniform 0.
