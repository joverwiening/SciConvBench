Use OpenFOAM v10 (or later) case structure and dictionaries.

Model a 2D, steady-state, incompressible RANS simulation of external flow over a NACA 0012 airfoil using simpleFoam.

Use the k-omega SST turbulence model.

Set the airfoil chord length to c = 1.0 m.

Set the angle of attack to α = 2 degrees.

Target Reynolds number based on chord to Re_c = 1.0e6.

Use air kinematic viscosity nu = 1.5e-5 m^2/s.

Compute freestream speed as Uinf = Re_c * nu / c = 15.0 m/s.

Create a 2D mesh as a single cell layer in the z-direction.

Set the thin-direction patches named frontAndBack to be 2D by using type empty in constant/polyMesh/boundary.

Set frontAndBack boundary condition to type empty in 0/U.

Set frontAndBack boundary condition to type empty in 0/p.

Use a far-field outer boundary as a single patch named farField.

Apply freestream-type boundary conditions on farField.

Set 0/U farField to freestreamVelocity with freestreamValue uniform (Uinf*cosα Uinf*sinα 0).

Set 0/p farField to freestreamPressure with freestreamValue uniform 0.

Set the airfoil wall patch named airfoil to noSlip in 0/U.

Set the airfoil wall patch named airfoil to zeroGradient in 0/p.

Use turbulence intensity at inlet/freestream of 1%.

Use inlet turbulence length scale L = 0.07c.

Derive k from intensity as k = 1.5*(Uinf*I)^2 with I = 0.01.

Derive omega from length scale as omega = sqrt(k) / (Cmu^0.25 * L) with Cmu = 0.09.

Set 0/k farField to freestream with freestreamValue uniform k.

Set 0/omega farField to freestream with freestreamValue uniform omega.

Set 0/k airfoil to kqRWallFunction with value uniform 0.

Set 0/omega airfoil to omegaWallFunction with value uniform 1.

Set 0/nut airfoil to nutkWallFunction with value uniform 0.

Set 0/nut farField to calculated with value uniform 0.

Use SIMPLE algorithm with steady-state settings suitable for external aerodynamics.

Use second-order discretization for convection terms (e.g., linearUpwind or limitedLinear for U, k, omega).

Run until residuals for U, p, k, omega are reduced at least 3 orders of magnitude and force coefficients are statistically steady.

Compute and report lift and drag coefficients referenced to chord c and unit span (2D).
