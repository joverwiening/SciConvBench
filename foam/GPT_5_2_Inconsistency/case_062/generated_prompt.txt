Target OpenFOAM distribution is OpenFOAM Foundation v10.
Use solids4foam to provide solidDisplacementFoam.
Model a 2D cantilever beam in the x-y plane with plane-stress linear elasticity.
Assume out-of-plane thickness is 1.0 m.
Set beam geometry to length 1.0 m in x and height 0.1 m in y.
Create a structured mesh with 100 cells along x and 10 cells along y.
Use aluminum material properties with E = 70e9 Pa and nu = 0.33.
Run a static solution using a pseudo-time approach in solidDisplacementFoam.
Set system/controlDict application to solidDisplacementFoam.
Set endTime to 1.
Set deltaT to 1 to perform a single pseudo-time step.
Apply boundary condition at x=0 patch fixedEnd as fixedValue uniform (0 0 0) for displacement.
Apply boundary condition at x=1 patch loadEnd as tractionDisplacement with traction uniform (0 -10000 0) and pressure uniform 0.
Apply boundary condition on the top and bottom patches as zeroGradient for displacement.
Solve the displacement equation to an absolute residual tolerance of 1e-8 with relative tolerance 0.
Report the primary result as the maximum downward vertical displacement at the free end, computed as min(Dy) on the loadEnd patch.
