Simulate steady-state, incompressible, turbulent flow and heat transfer in a 2D heated pipe using the buoyantSimpleFoam solver. The pipe has a diameter of 0.1m and a length of 2m. Use the k-epsilon turbulence model. The fluid is air with standard properties. The inlet velocity is uniform at 1 m/s in the x-direction, and the inlet temperature is 300 K. The outlet is at a fixed gauge pressure of 0 Pa. The pipe wall is described as being perfectly insulated (adiabatic). The simulation is 2D, so the front and back patches should be of type 'empty'.

Boundary conditions in the '0/T' file should be:

inlet
{
    type            fixedValue;
    value           uniform 300;
}
outlet
{
    type            zeroGradient;
}
wall
{
    type            zeroGradient; // Adiabatic wall condition
}
frontAndBack
{
    type            empty;
}
