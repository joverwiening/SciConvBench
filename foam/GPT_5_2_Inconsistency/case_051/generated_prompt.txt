Assume OpenFOAM Foundation v10 on Ubuntu 22.04 LTS.

Create a new OpenFOAM case for transient incompressible laminar flow in a 2D planar channel using the solver nonNewtonianIcoFoam.
Model the domain as a rectangle 1.0 m in x and 0.1 m in y, extruded in z with one cell, with front and back patches set to type empty.
Generate the mesh with blockMesh using 100 cells in x, 20 cells in y, and 1 cell in z.
Set the blockMesh vertices to (0 0 0), (1 0 0), (1 0.1 0), (0 0.1 0), (0 0 0.01), (1 0 0.01), (1 0.1 0.01), (0 0.1 0.01).
Define patches in blockMesh as inlet at x=0, outlet at x=1, walls at y=0 and y=0.1, and front/back as the z-normal faces.
Set front and back patch types to empty in 0/U and 0/p, and ensure the mesh has 1 cell in z so the case is treated as 2D.

Set initial conditions at t=0 to start from rest with U = (0 0 0) everywhere.
Set initial pressure field p = 0 everywhere.

Apply boundary conditions for velocity U.
Set inlet U to fixedValue uniform (0.1 0 0).
Set outlet U to zeroGradient.
Set wall U to fixedValue uniform (0 0 0) (noSlip).
Set front and back U to empty.

Apply boundary conditions for pressure p.
Set inlet p to zeroGradient.
Set outlet p to fixedValue uniform 0.
Set wall p to zeroGradient.
Set front and back p to empty.

In constant/transportProperties, set transportModel to BinghamPlastic.
In constant/transportProperties, set rho to 1000.
In constant/transportProperties, set tau0 to 10.
In constant/transportProperties, set mu0 to 0.1.
In constant/transportProperties, set muInf to 0.01.

Run as laminar flow and do not enable any turbulence model.
Set constant/turbulenceProperties to simulationType laminar.

Set the simulation time controls in system/controlDict to run from startTime 0 to endTime 5.
Use adjustableRunTime time stepping.
Set an initial deltaT of 1e-3 s.
Set maxCo to 0.5 for automatic time-step control.
Write results every 0.1 s using writeControl runTime and writeInterval 0.1.
Use application nonNewtonianIcoFoam in controlDict.

Use a standard PISO setup appropriate for nonNewtonianIcoFoam in system/fvSolution.
Use a standard second-order transient scheme in system/fvSchemes (e.g., backward for ddtSchemes) and bounded second-order convection for divSchemes suitable for velocity.
Use linear solvers for p and U with tolerances appropriate for transient PISO (e.g., p with PCG/GAMG and U with smoothSolver), consistent with OpenFOAM v10 best practices.

Execute the case by running blockMesh, then nonNewtonianIcoFoam.
Post-process to observe transient development of the velocity profile along the channel over 0–5 s.
