Set up a steady-state buoyant airflow simulation in a ventilated room with a heater using buoyantSimpleFoam.
Assume OpenFOAM Foundation v10 case structure and dictionary syntax as the target version.
Create a fully 3D room domain.
Use a rectangular room geometry of 5 m (x) × 3 m (y) × 2.5 m (z).
Define gravity as g (0 -9.81 0) with y as the vertical direction.
Place an inlet patch on the left wall (x=0) as a vertical rectangle centered in height with size 0.5 m (width in z) × 0.5 m (height in y).
Place an outlet patch on the right wall (x=5) as a vertical rectangle centered in height with size 0.5 m (width in z) × 0.5 m (height in y).
Define a heater patch as a wall patch on the floor (y=0) near the center of the room with footprint 1.0 m (x) × 0.5 m (z).
Set all remaining boundaries as no-slip walls with adiabatic thermal condition unless otherwise specified.
Use the Boussinesq approximation with reference temperature 293 K to model buoyancy-driven natural convection.
In constant/thermophysicalProperties, set thermoType to heRhoThermo.
In constant/thermophysicalProperties, set equationOfState to Boussinesq with T0 293, beta 0.00341, rho0 1.2.
In constant/thermophysicalProperties, set transport to const with mu 1.8e-5 and Pr 0.71.
Use a laminar flow model in constant/turbulenceProperties (simulationType laminar).
Use p_rgh as the pressure variable and include buoyancy via p_rgh formulation consistent with buoyantSimpleFoam.
Set the inlet velocity boundary condition as a uniform fixedValue with magnitude 0.1 m/s directed into the room along +x.
Set the inlet temperature boundary condition to fixedValue uniform 293 K.
Set the outlet pressure boundary condition for p_rgh to fixedValue uniform 0 (gauge) on the outlet patch.
Set the outlet velocity boundary condition to zeroGradient.
Set the outlet temperature boundary condition to zeroGradient.
Set the heater wall temperature boundary condition to fixedValue uniform 320 K on the heater patch.
Set the heater wall velocity boundary condition to noSlip.
Set temperature on all non-heater walls to zeroGradient (adiabatic).
Set velocity on all non-inlet/outlet walls to noSlip.
Initialize the internal field temperature to 293 K.
Initialize the internal field velocity to uniform (0 0 0).
Initialize the internal field p_rgh to uniform 0.
Use SIMPLE-based steady-state controls appropriate for buoyantSimpleFoam in system/fvSolution.
Use second-order spatial discretization schemes suitable for steady-state buoyant flow in system/fvSchemes (e.g., linear for gradients, limited linear for div terms).
Run until residuals for U, T, and p_rgh are reduced at least 3 orders of magnitude and monitored integral quantities (e.g., outlet mass flow, average room temperature) are steady.
Post-process to visualize velocity vectors, temperature contours, and buoyant plume structure from the heater to confirm natural convection behavior.
