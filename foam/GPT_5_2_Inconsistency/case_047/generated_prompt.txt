Assume Foundation OpenFOAM v11 case file syntax and dictionaries.
Configure a steady-state incompressible turbulent pipe flow case using simpleFoam.
Use the RANS k-epsilon turbulence model.
Set the fluid to water with kinematic viscosity nu = 1e-6 m^2/s.
Use a pipe diameter of 0.1 m.
Use an inlet bulk velocity of 1 m/s.
In the 0/k file, set internalField to uniform 0.00375.
In the 0/epsilon file, set internalField to uniform 0.001.
For the inlet patch in 0/k, use type fixedValue with value uniform 0.00375.
For the inlet patch in 0/epsilon, use type fixedValue with value uniform 0.001.
For the pipe wall patch in 0/k, use type kqRWallFunction with an appropriate value entry (e.g., uniform 0.00375).
For the pipe wall patch in 0/epsilon, use type epsilonWallFunction with an appropriate value entry (e.g., uniform 0.001).
Use wall-function-compatible near-wall treatment consistent with k-epsilon RANS in simpleFoam.
