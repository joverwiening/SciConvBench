Use OpenFOAM Foundation v10 case structure and dictionaries for an interFoam 2D dam-break tutorial-style setup.
Create a 1 m × 1 m rectangular domain in x–y with a thin z thickness of 0.01 m.
Mesh the domain with 200 cells in x and 200 cells in y, and 1 cell in z.
Define patches named left, right, bottom, top, front, back.
Set front and back patches to type empty to enforce 2D.
Set left, right, and bottom patches as walls.
Set top patch as an open atmosphere boundary.

Use interFoam as the solver in system/controlDict.
Set application interFoam.
Set startFrom startTime and startTime 0.
Set endTime 2.
Set deltaT 0.001 with adjustable time stepping enabled.
Set maxCo 0.5 and maxAlphaCo 0.5.
Write results every 0.02 s using writeControl timeStep or runTime (choose runTime) with writeInterval 0.02.
Use purgeWrite 0 (no purging) unless disk space is a concern.
Set stopAt endTime.

In constant/g, set dimensions [0 1 -2 0 0 0 0] and value g (0 0 -9.81);.
In constant/transportProperties, use two incompressible Newtonian phases with water and air properties suitable for dam-break benchmarks (water rho 1000, nu 1e-6; air rho 1, nu 1.48e-5; sigma 0.072).
In constant/turbulenceProperties, set simulationType laminar;.

In system/fvSchemes, use standard interFoam schemes (Gauss linear for gradients, limitedLinearV 1 for div(phi,U), vanLeer for div(phi,alpha), interfaceCompression for div(phirb,alpha), and appropriate laplacian and interpolation schemes).
In system/fvSolution, use PIMPLE settings appropriate for interFoam with 2–3 correctors, 1–2 non-orthogonal correctors, and standard solvers for p_rgh, U, and alpha.water with MULES.

In 0/U, set internalField uniform (0 0 0).
In 0/U, set top patch to pressureInletOutletVelocity with value uniform (0 0 0).
In 0/U, set left, right, and bottom wall patches to noSlip.
In 0/U, set front and back to empty.

In 0/p_rgh, set internalField uniform 0.
In 0/p_rgh, set top patch to totalPressure with p0 uniform 0 and value uniform 0.
In 0/p_rgh, set left, right, and bottom wall patches to fixedFluxPressure with value uniform 0.
In 0/p_rgh, set front and back to empty.

In 0/alpha.water, set internalField uniform 0.
In 0/alpha.water, set top patch to inletOutlet with inletValue uniform 0 and value uniform 0.
In 0/alpha.water, set left, right, and bottom wall patches to zeroGradient.
In 0/alpha.water, set front and back to empty.

In 0/alpha.air, either omit and let it be derived, or include it consistent with alpha.air = 1 - alpha.water if required by the chosen OpenFOAM version setup.

In system/blockMeshDict, define vertices for a block from (0 0 0) to (1 1 0.01).
In system/blockMeshDict, define a single hex block with grading 1 1 1 and cell counts (200 200 1).
In system/blockMeshDict, assign boundary faces to left (x=0), right (x=1), bottom (y=0), top (y=1), front (z=0), back (z=0.01).

In system/setFieldsDict, set defaultFieldValues for volScalarFieldValue alpha.water 0.
In system/setFieldsDict, add a boxToCell region from (0 0 0) to (0.2 0.5 0.01) and set volScalarFieldValue alpha.water 1 inside it.

Run blockMesh.
Run setFields.
Run interFoam.

Post-process by viewing alpha.water and U in ParaView to observe the collapse and propagation of the water column under gravity.
