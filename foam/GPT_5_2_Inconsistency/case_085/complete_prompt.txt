Set up a 2D steady-state simulation of Rayleigh-Bénard convection in a square cavity of 1m x 1m. The fluid is air. The bottom wall is heated to 310 K, the top wall is cooled to 290 K, and the side walls are adiabatic. Gravity acts in the negative y-direction with g = 9.81 m/s^2. Use the `buoyantBoussinesqSimpleFoam` solver. For thermophysical properties, use the Boussinesq approximation. In `constant/thermophysicalProperties`, set the following:

thermoType
{
    type            heRhoThermo;
    mixture         Boussinesq;
    transport       const;
    thermo          hConst;
    equationOfState Boussinesq;
    specie          specie;
    energy          sensibleEnthalpy;
}

mixture
{
    specie
    {
        molWeight   28.9;
    }
    thermodynamics
    {
        Cp          1005;
        Hf          0;
    }
    transport
    {
        mu          1.8e-05;
        Pr          0.7;
    }
    BoussinesqCoeffs
    {
        TRef        300;
        beta        0.00333; // 1/TRef for ideal gas
        rhoRef      1.176;   // rho at TRef
    }
}

Boundary conditions are: T_bottom = 310 K (fixedValue), T_top = 290 K (fixedValue), T_sides = zeroGradient. For velocity, all walls are noSlip. For pressure p_rgh, all boundaries are fixedFluxPressure.
