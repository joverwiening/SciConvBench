Assume OpenFOAM Foundation release v11 case format and dictionaries.
Create a 2D incompressible laminar channel-flow case solved with icoFoam.
Use a rectangular domain of length 0.5 m in x and height 0.1 m in y.
Use one cell in the z direction with a small thickness (e.g., 0.01 m) to make the mesh one cell thick.
Generate the mesh with blockMesh using Nx=200, Ny=40, Nz=1 with simpleGrading (1 1 1).
Define vertices for a single hex block spanning (0,0,0) to (0.5,0.1,0.01).
Define patches in blockMeshDict named inlet, outlet, topWall, bottomWall, and frontAndBack.
Assign inlet to the x=0 face.
Assign outlet to the x=0.5 face.
Assign bottomWall to the y=0 face.
Assign topWall to the y=0.1 face.
Assign frontAndBack to the z=0 and z=0.01 faces.
Set the frontAndBack patch physical type in blockMeshDict to “type wall;”.
Model Poiseuille flow driven by an imposed inlet velocity profile and outlet pressure reference.
In 0/U, set inlet to a parabolic fixedValue profile with Umax=1 m/s and Uy=Uz=0.
In 0/U, implement the parabolic inlet profile using a codedFixedValue boundary condition.
In 0/U, define the inlet profile as Ux(y)=4*Umax*(y/H)*(1 - y/H) with H=0.1 m and y measured from the bottom wall.
In 0/U, set outlet to zeroGradient.
In 0/U, set topWall to noSlip.
In 0/U, set bottomWall to noSlip.
In 0/U, set frontAndBack to noSlip.
In 0/p, set outlet to fixedValue uniform 0.
In 0/p, set inlet to zeroGradient.
In 0/p, set topWall to zeroGradient.
In 0/p, set bottomWall to zeroGradient.
In 0/p, set frontAndBack to zeroGradient.
Use laminar transport with a single constant kinematic viscosity nu.
Set nu to 1e-6 m2/s as a reasonable default for an incompressible Newtonian fluid.
Use standard icoFoam numerics suitable for laminar transient flow (second-order where stable) in system/fvSchemes and system/fvSolution.
Run transient until the solution is steady based on a stopping criterion rather than a fixed endTime.
Define steady-state detection as max over the domain of |U(t)-U(t-Δt)| < 1e-6 m/s for 200 consecutive time steps.
Implement automatic stopping using a functionObject-based convergence check that terminates the run when the criterion is met.
Choose a time step controlled by a target max Courant number (e.g., maxCo 0.5) using adjustable time stepping.
Write fields at a reasonable interval (e.g., every 0.1 s of simulated time) while running to steady state.
Verify Poiseuille behavior by comparing the final centerline velocity to approximately 1 m/s and the final profile shape to the imposed parabola.
