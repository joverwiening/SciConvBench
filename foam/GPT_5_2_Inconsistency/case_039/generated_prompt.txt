Set up an OpenFOAM two-phase incompressible VOF dam-break case using interFoam.
Set system/controlDict so application is interFoam.
Model the case as 2D by using a 3D mesh extruded one cell in the spanwise direction.
Set the frontAndBack patches to type empty.
Use the VOF phase fraction field named alpha.water.
Initialize the water column using setFields such that alpha.water = 1 inside the initial column and alpha.water = 0 elsewhere with a sharp interface.
Set gravity in constant/g to value (0 -9.81 0).
Apply tank wall boundary conditions on all non-open-top walls: U noSlip, p_rgh zeroGradient, alpha.water zeroGradient.
Apply open-top boundary conditions: U pressureInletOutletVelocity, p_rgh totalPressure with p0 uniform 0 (or fixedValue uniform 0 if required by the setup), alpha.water inletOutlet with inletValue uniform 0.
Assume any missing domain dimensions, initial column dimensions/position, mesh resolution, and time-step/Courant control values using common dam-break best practices suitable for interFoam and VOF stability.
