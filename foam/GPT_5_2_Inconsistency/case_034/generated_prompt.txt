Use OpenFOAM Foundation distribution, version v10, and the interFoam solver.
Model a 2D dam-break in the x–y plane with one cell in z and frontAndBack treated as 2D.
Set the domain size to 2.0 m in x, 1.0 m in y, and 0.01 m in z.
Create the mesh with blockMesh using Nx=400, Ny=200, Nz=1 (uniform grading).
Define gravity in constant/g as (0 -9.81 0).
Set frontAndBack patches to type empty in system/blockMeshDict.
Set frontAndBack boundary type to empty for 0/U, 0/p_rgh, and 0/alpha.water.
Use laminar flow in constant/turbulenceProperties.
Use adjustable time stepping with maxCo = 0.5 in system/controlDict.
Set the initial fields with setFields so that water occupies a rectangular column from x=0 to x=0.4 m and y=0 to y=0.6 m, and air fills the rest.
Define patches as left, right, bottom, top, frontAndBack.
Set left and right patches as solid walls with U noSlip, and p_rgh and alpha.water zeroGradient.
Set the top patch as atmosphere with p_rgh fixedValue uniform 0, U pressureInletOutletVelocity, and alpha.water inletOutlet with inletValue uniform 0.
Set the bottom patch as a solid wall with U noSlip.
Set the bottom patch p_rgh to zeroGradient.
Set the bottom patch alpha.water to zeroGradient.
Use standard interFoam two-phase properties for water and air in constant/transportProperties (water rho 1000, nu 1e-6; air rho 1, nu 1.5e-5) and surface tension sigma 0.072.
Initialize p_rgh consistent with hydrostatic pressure by setting p_rgh uniform 0 and allowing it to adjust during the transient.
Run blockMesh, then setFields, then interFoam.
