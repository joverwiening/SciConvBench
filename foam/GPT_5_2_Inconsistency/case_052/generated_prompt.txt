Set up a 2D transient lid-driven cavity case in OpenFOAM using the nonNewtonianIcoFoam solver.
Assume OpenFOAM Foundation v11 conventions and file formats.
Use a 1 m x 1 m square cavity domain with the third direction treated as empty to enforce 2D behavior.
Create the mesh with blockMesh as a single block spanning x in [0,1], y in [0,1], z in [0,0.1] (or another small thickness), and set front and back patches to type empty.
Define boundary patches named lid, bottom, left, right, front, back.
Set the lid boundary condition to a fixedValue velocity of (1 0 0) m/s.
Set bottom, left, and right boundary conditions to noSlip (equivalently fixedValue (0 0 0)) for velocity.
Set front and back velocity boundary conditions to empty.
Set pressure boundary conditions to zeroGradient on lid, bottom, left, and right.
Set pressure boundary conditions to empty on front and back.
Use a transient incompressible formulation with kinematic viscosity defined by a shear-thinning non-Newtonian model.
In constant/transportProperties, use the PowerLaw transport model with the following entries: transportModel PowerLaw; nuMax 1; nuMin 1e-6; k 0.1; n 0.5.
Do not use the Newtonian nu entry when transportModel is PowerLaw.
Set initial conditions in 0/U to uniform (0 0 0) and in 0/p to uniform 0.
Use system/controlDict to run a transient simulation with appropriate startTime, endTime, deltaT, and writeInterval for lid-driven cavity evolution.
Use system/fvSchemes with second-order (or stable bounded) spatial discretization for div terms and an appropriate time scheme for transient incompressible flow.
Use system/fvSolution with PISO (or the solver’s required algorithm settings) suitable for transient incompressible flow and set tolerances for p and U.
Run blockMesh, then run nonNewtonianIcoFoam, and post-process velocity and pressure fields to verify the primary vortex structure typical of lid-driven cavity flow.
