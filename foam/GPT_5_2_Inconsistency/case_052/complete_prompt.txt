Set up a 2D lid-driven cavity simulation for a non-Newtonian, shear-thinning fluid using the `nonNewtonianIcoFoam` solver. The cavity is a 1m x 1m square. The top wall (lid) moves with a velocity of `(1 0 0)` m/s, while all other walls are stationary (`noSlip`). The simulation is transient. In the `constant/transportProperties` file, define the fluid properties using a suitable shear-thinning model, for example, the Power Law model:

transportModel  PowerLaw;
nuMax           1;
nuMin           1e-6;
k               0.1;
n               0.5;
