Set up a 2D lid-driven cavity flow OpenFOAM case using icoFoam for an incompressible Newtonian fluid.
Target OpenFOAM Foundation v12 conventions and file syntax.
Prepare the case as a complete runnable case directory containing 0/, constant/, system/, plus Allrun and Allclean bash scripts for Linux.
Create a 1 m × 1 m square domain in x-y, extruded one cell in z, with frontAndBack patches set to empty.
Generate a uniform mesh of 40 × 40 × 1 cells using blockMesh.
Define patches named movingLid (top), fixedWalls (left, right, bottom), and frontAndBack (front and back).
Set kinematic viscosity in constant/transportProperties to nu [0 2 -1 0 0 0 0] 0.01.
Set initial conditions in 0/U to uniform (0 0 0) and in 0/p to uniform 0.
Set boundary conditions for 0/U so that movingLid is fixedValue uniform (1 0 0).
Set boundary conditions for 0/U so that fixedWalls is noSlip.
Set boundary conditions for 0/U so that frontAndBack is empty.
Set boundary conditions for 0/p so that movingLid is zeroGradient.
Set boundary conditions for 0/p so that fixedWalls is zeroGradient.
Set boundary conditions for 0/p so that frontAndBack is empty.
Set the pressure reference in system/fvSolution using pRefCell and pRefValue (use pRefValue 0 and choose a valid internal pRefCell index).
Set system/controlDict application to icoFoam.
Run transient until a steady solution is reached, with an upper stop time endTime = 50 s.
Use adjustable time stepping with adjustTimeStep yes.
Set the initial time step deltaT = 0.005 s.
Enforce a maximum Courant number maxCo = 0.5 for time-step control.
Write results every 0.5 s using writeControl runTime and writeInterval 0.5.
Use second-order time discretization with ddtSchemes set to backward for default.
Use Gauss linear schemes for gradients and Laplacians with laplacianSchemes using Gauss linear corrected.
Use a bounded second-order convection scheme for div(phi,U) as Gauss linearUpwind grad(U).
Use linear interpolation for interpolationSchemes.
Use a PISO setup in system/fvSolution appropriate for icoFoam with nCorrectors = 2 and nNonOrthogonalCorrectors = 0.
Use solvers in system/fvSolution with PCG for p (with DIC preconditioner) and smoothSolver for U (with symGaussSeidel).
Set solver tolerances so that p has tolerance 1e-7 and relTol 0, and U has tolerance 1e-8 and relTol 0.
Define “steady solution is reached” as both conditions being satisfied: the final residuals for U and p remain below 1e-6 for at least 5 consecutive write intervals, and the change in domain-averaged kinetic energy between consecutive write times is less than 1e-6 (in SI units) for at least 5 consecutive write intervals.
Implement kinetic-energy monitoring via a function object in system/controlDict that computes and logs domain-averaged magSqr(U) (or equivalent) each write time.
Stop the run manually when the steady criteria are met, or automatically at endTime if not met earlier.
Provide Allrun to execute blockMesh then icoFoam, and Allclean to remove processor directories and time directories except 0 and constant.
