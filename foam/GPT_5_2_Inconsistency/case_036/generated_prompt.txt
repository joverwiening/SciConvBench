Create an OpenFOAM solid mechanics case to simulate quasi-static linear-elastic deflection of a 3D steel cantilever beam.
Use the solver solidDisplacementFoam.
Model a rectangular beam of length 1.0 m, height 0.1 m, and width 0.1 m.
Orient the beam so the length is along global X, the height is along global Y, and the width is along global Z.
Create a hexahedral mesh with 100 cells along X, 10 cells along Y, and 10 cells along Z.
Name the x-min face patch fixed and the x-max face patch loaded.
Set all remaining faces as a single patch (e.g., sides) for zeroGradient displacement.
In constant/mechanicalProperties, set linear elastic isotropic steel properties with E 200e9 and nu 0.3.
In 0/D, set the fixed patch to fixedValue uniform (0 0 0).
In 0/D, set the loaded patch to tractionDisplacement with traction uniform (0 -1000 0) and pressure uniform 0.
In 0/D, set all other patches to zeroGradient.
In system/controlDict, set application pimpleFoam, endTime 1, and write displacement results to time directories.
Run the case as quasi-static by using sufficiently small time step and/or solver settings so inertial effects are negligible.
Validate by reporting the Y-component displacement at the beam tip (e.g., at the center of the loaded face) at endTime and by writing the full displacement field D for post-processing.
