Model a steady-state buoyant flow in a solar chimney using OpenFOAM Foundation v11.
Use the buoyantSimpleFoam solver with a compressible thermodynamics setup.
Use the perfectGas equation of state and do not use the Boussinesq approximation.
Set operating/reference pressure pRef to 101325 Pa.
Set the initial/reference air temperature to 300 K.
Use a steady RANS turbulence model with RAS kOmegaSST.
Define gravity in constant/g and ensure it is enabled for buoyancy.
Set the bottom heated surface temperature boundary condition to fixedValue with T = 350 K.
Set all other walls to an adiabatic temperature boundary condition using zeroGradient for T unless a different wall heat transfer is explicitly specified.
Set the chimney outlet temperature boundary condition to inletOutlet for T with inletValue uniform 300 K and value uniform 300 K.
Set the chimney outlet pressure boundary condition to fixedValue with p = 101325 Pa.
Set the chimney outlet velocity boundary condition to pressureInletOutletVelocity with value uniform (0 0 0).
Set the inlet (if present) pressure boundary condition to totalPressure with p0 = 101325 Pa.
Set the inlet (if present) temperature boundary condition to totalTemperature with T0 = 300 K.
Set the inlet (if present) velocity boundary condition to fixedValue with a small uniform inflow (0 0 0) if driven purely by buoyancy, otherwise specify the intended inflow velocity.
Use noSlip for velocity on all solid walls.
Use appropriate wall functions for k, omega, and nut consistent with kOmegaSST (e.g., kqRWallFunction, omegaWallFunction, nutkWallFunction) on solid walls.
Set thermophysicalProperties to use hePsiThermo with a perfectGas mixture and constant Cp and mu consistent with air at 300 K (Cp = 1005 J/kg/K, mu = 1.8e-05 Pa·s, Pr = 0.7).
Initialize fields with p = 101325 Pa, T = 300 K, U = (0 0 0), and turbulence quantities consistent with low-speed indoor/outdoor air (use standard kOmegaSST initialization).
Run until residuals for U, p, and T reach steady convergence criteria suitable for buoyantSimpleFoam (e.g., 1e-6 for U and T, 1e-5 for p) and monitor mass flow at the outlet for steady behavior.
