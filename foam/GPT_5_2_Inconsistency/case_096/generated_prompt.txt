Set up a 2D dam-break interFoam case in OpenFOAM Foundation v10 for two incompressible, immiscible phases (water and air) in a rectangular tank.
Use a domain of 0.5 m in x, 0.5 m in y, and 0.01 m in z (single cell thick in z).
Use a uniform mesh of 100 cells in x, 100 cells in y, and 1 cell in z (Δx = Δy = 0.005 m).
Create the mesh with blockMesh using vertices spanning (0 0 0) to (0.5 0.5 0.01).
Define boundary patches in constant/polyMesh/boundary as leftWall, rightWall, lowerWall of type wall, atmosphere of type patch (top boundary), and frontAndBack of type symmetry (z-normal faces).
Set gravity in constant/g as g (0 -9.81 0).
Use laminar flow (no turbulence model) in constant/turbulenceProperties.
Set phase properties in constant/transportProperties with water rho 1000, nu 1e-6, air rho 1.0, nu 1.5e-5, and surface tension sigma 0.072.
Initialize the phase fraction using system/setFieldsDict with default alpha.water = 0 everywhere.
In system/setFieldsDict, set alpha.water = 1 in the region x < 0.15 m for the full water column height from y = 0 to y = 0.5 m.
Set initial fields in 0/ with U = (0 0 0), p_rgh = 0, and alpha.water according to setFields.
Apply U boundary conditions: noSlip on leftWall, rightWall, lowerWall; pressureInletOutletVelocity on atmosphere; symmetry on frontAndBack.
Apply p_rgh boundary conditions: fixedFluxPressure on leftWall, rightWall, lowerWall, and frontAndBack; totalPressure on atmosphere.
Apply alpha.water boundary conditions: zeroGradient on leftWall, rightWall, lowerWall, and frontAndBack; inletOutlet on atmosphere.
Configure system/controlDict to run interFoam from startTime 0 to endTime 2.0 s.
Use adjustable time stepping with initial deltaT 1e-4 s.
Set maxCo = 0.5 and maxAlphaCo = 0.5 for time-step control.
Use standard interFoam discretization schemes and solvers appropriate for OpenFOAM v10 in system/fvSchemes and system/fvSolution.
Run blockMesh, then setFields, then interFoam.
