Use the multiphaseEulerFoam solver case structure with initial fields stored in the 0/ directory.
Create the volume-fraction field file 0/alpha.sediment for the sediment phase.
Create the volume-fraction field file 0/alpha.water for the water phase.
Create the volume-fraction field file 0/alpha.oil for the oil phase.
In 0/alpha.sediment, set internalField uniform 0.5; as the default pre-setFields condition.
In 0/alpha.water, set internalField uniform 0.5; as the default pre-setFields condition.
In 0/alpha.oil, set internalField uniform 0.5; as the default pre-setFields condition.
Leave the stratification to be applied later by setFields using setFieldsDict, which will overwrite these uniform internalField values to create layered initial conditions.
