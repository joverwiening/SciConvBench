Target OpenFOAM Foundation v11.
Model transient incompressible flow past a circular cylinder in a 2D channel producing a von Kármán vortex street.
Use solver pimpleFoam by setting application pimpleFoam; in system/controlDict.
Use a 2D mesh extruded one cell in z with frontAndBack patches set to empty.
Set kinematic viscosity nu = 1e-3 m^2/s in constant/transportProperties.
Use inlet velocity magnitude 0.1 m/s as specified.
Choose cylinder diameter D = 1.0 m to target Reynolds number Re = U*D/nu = 0.1*1.0/1e-3 = 100, which is in the vortex-shedding laminar regime.
Use a laminar model by setting simulationType laminar in constant/turbulenceProperties.
Set channel height H = 10D = 10 m to reduce blockage effects with slip walls.
Set channel length L = 25D = 25 m to provide upstream development and downstream wake resolution.
Place the cylinder center at (x,y) = (5D, H/2) = (5 m, 5 m).
Use blockMesh to create a background hexahedral mesh for a 2D channel domain and use snappyHexMesh to create a curved cylinder boundary.
Define a circular cylinder geometry for snappyHexMesh using a searchableCylinder aligned with the z-axis with radius D/2 and spanning the full z thickness.
Extrude the domain thickness in z to one cell with thickness 0.1D = 0.1 m and set frontAndBack to empty.
Create boundary patches named inlet, outlet, top, bottom, cylinder, frontAndBack.
In 0/U set inlet fixedValue uniform (0.1 0 0).
In 0/U set outlet zeroGradient.
In 0/U set cylinder noSlip.
In 0/U set top slip.
In 0/U set bottom slip.
In 0/U set frontAndBack empty.
In 0/p set inlet zeroGradient.
In 0/p set outlet fixedValue uniform 0.
In 0/p set cylinder zeroGradient.
In 0/p set top zeroGradient.
In 0/p set bottom zeroGradient.
In 0/p set frontAndBack empty.
Use a mesh resolution sufficient for Re=100 shedding with near-cylinder refinement to achieve y+ < 1 and at least 40 cells around the cylinder circumference.
Use snappyHexMesh refinement regions to refine the wake for at least 10D downstream of the cylinder with gradually coarsening cells.
Set time step to satisfy max Courant number Co <= 0.5 using adjustableTimeStep yes and maxCo 0.5 in system/controlDict.
Run the simulation long enough to reach periodic shedding and collect statistics, using endTime corresponding to at least 200 convective time units (t*U/D >= 200).
Write fields frequently enough to resolve shedding, using writeInterval corresponding to at most 0.1 convective time units.
Use second-order temporal and spatial discretization schemes suitable for transient vortex shedding in system/fvSchemes.
Use PIMPLE settings in system/fvSolution with at least 2 outer correctors and 2 pressure correctors, and enable momentumPredictor yes.
Initialize the flow with uniform U = (0.1 0 0) and p = 0 in the domain.
Post-process to visualize vorticity and velocity magnitude in the wake and to extract lift and drag coefficients on the cylinder over time.
