Assume OpenFOAM Foundation v10 and use nonNewtonianIcoFoam for an incompressible, laminar, isothermal, single-phase Power Law fluid over a 2D backward-facing step.

Model a planar channel with an upstream height Hu = 0.010 m, a step height h = 0.005 m, and a downstream height Hd = 0.015 m (expansion ratio Hd/Hu = 1.5).

Use an upstream inlet length Lin = 0.050 m (5·Hu) and a downstream outlet length Lout = 0.300 m (20·Hd) to allow recirculation development and reattachment.

Extrude the 2D mesh with a thickness of 0.001 m and use empty boundary conditions on the front and back patches.

Define boundary patches named inlet, outlet, topWall, bottomWall, and stepWall (or a single combined walls patch) such that the bottom boundary includes the step.

Set velocity boundary conditions in 0/U as follows: inlet fixedValue with a uniform velocity (U 0 0), outlet zeroGradient, and all solid walls (topWall, bottomWall, stepWall or combined walls) type noSlip.

Set pressure boundary conditions in 0/p as follows: inlet zeroGradient, outlet fixedValue uniform 0, and all walls zeroGradient.

Use a laminar flow assumption and do not enable turbulence modeling.

Set the inlet mean velocity to U = 0.10 m/s.

Use the step height h as the characteristic length for reporting purposes.

Target a moderate laminar Reynolds number based on Newtonian-equivalent viscosity to avoid transition, aiming for Re_h on the order of 50–200.

In constant/transportProperties, set transportModel PowerLaw.

Use a shear-thickening index n = 1.4.

Set the Power Law consistency index K = 0.50 Pa·s^n.

Ensure the kinematic form used by the solver is consistent with OpenFOAM’s PowerLaw implementation (i.e., parameters provided in transportProperties match the solver’s expected nu/nu0 formulation if applicable).

Initialize the field with U = (0 0 0) and p = 0 everywhere.

Use a transient run to steady state with adjustable time step to keep max Courant number ≤ 0.5.

Run until residuals for U and p plateau and integral quantities (e.g., pressure drop, reattachment length) become time-invariant.

Post-process to extract the reattachment length along the bottom wall by locating the streamwise position where wall shear stress changes sign from negative to positive.

Report centerline velocity profiles and pressure distribution upstream and downstream of the step.

Verify mesh independence by repeating with at least one refined mesh, refining near the step corner and walls to resolve high shear regions.
