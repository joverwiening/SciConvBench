The simulation domain is a cube spanning from (0, 0, 0) to (1, 1, 1) with a uniform mesh resolution of 32 × 32 × 32 cells.  
An obstacle is present in the domain, defined by the box from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).  
Gravity is set to (0, 0, -9.81) m/s².  
The initial water phase is defined by alpha.water = 1 within the rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75), and alpha.water = 0 elsewhere.  
The fluid properties for water are density = 1000 kg/m³ and dynamic viscosity = 1.0e-6 Pa·s.  
The fluid properties for air are density = 1 kg/m³ and dynamic viscosity = 1.48e-5 Pa·s.  
The simulation is transient using the interFoam solver with laminar flow assumptions.  
The time step deltaT is set to 1e-3 seconds.  
The simulation runs until endTime = 0.1 seconds.  
Field data is written at every writeInterval = 0.02 seconds.
