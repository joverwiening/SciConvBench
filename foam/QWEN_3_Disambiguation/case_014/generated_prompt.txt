Set up a 2-D opposed-jet laminar counter-flow diffusion flame simulation using reactingFoam.
Use a rectangular domain spanning x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Discretize the domain with 100 grid points in the x-direction and 40 in the y-direction, and 1 cell in the z-direction.
Name the left boundary (x=0) as fuel and the right boundary (x=0.02) as air.
Designate the top and bottom boundaries as outlet.
Set the front and back faces as empty.
Initialize the entire domain with a temperature of 2000 K at time zero.
Set the velocity at the fuel boundary to 0.1 m/s in the positive x-direction.
Set the velocity at the air boundary to -0.1 m/s in the negative x-direction.
Use pure methane (CH4) as the fuel species at the fuel boundary with no other components.
Use air at the air boundary with a mass fraction of O2 equal to 0.23 and N2 equal to 0.77.
Use EulerImplicit chemistry type with Rosenbrock43 ODE solver.
Model combustion using compressible finite-rate chemistry.
Use hePsiThermo thermophysical model.
Use coefficientWilkeMultiComponentMixture for species transport.
Use Sutherland transport model for viscosity.
Use JANAF thermodynamics for thermal properties.
Assume laminar flow with no turbulence model.
Use reactingFoam solver for the simulation.
Set the time step to 1e-4 seconds.
Run the simulation until the end time of 0.5 seconds.
Write results at an output interval of 0.05 seconds.
