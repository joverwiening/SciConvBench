Use the standard k-epsilon RAS turbulence model.
Set turbulence to on in turbulenceProperties.
Set the inlet velocity to 10 m/s in the x-direction, specified as uniform (10 0 0) in the boundary conditions for U.
Use a kinematic viscosity (nu) of 1e-5 m²/s.
Assume a fluid density of 1 kg/m³, as it is not specified and incompressible solvers in OpenFOAM typically use this value.
Use the blockMeshDict from the OpenFOAM pitzDaily tutorial for domain size and mesh resolution.
Set the step height to 0.028 m as defined in the tutorial.
