Use pisoFoam to simulate turbulent flow in a 2D channel.  
Set the channel length to 2 meters and the channel height to 0.1 meters.  
Use a uniform inlet velocity of (1 0 0) m/s as a fixedValue boundary condition.  
Apply the k-epsilon turbulence model for turbulence closure.  
Set the kinematic viscosity to 1e-5 m²/s.  
Use a time step size of 0.001 seconds.  
Run the simulation for a total time of 5.0 seconds.  
Do not assume a fully developed velocity profile at the inlet.  
Ensure the simulation is set up in 2D with appropriate front and back boundary conditions for planar flow.
