Use a square cavity domain with a length and height of 1 meter each and a depth of 0.1 meters in the z-direction.
Discretize the domain using a 20x20x1 computational grid in the x, y, and z directions respectively.
Set the top wall (movingWall) to move with a uniform velocity of 1 m/s in the x-direction.
Apply no-slip boundary conditions (zero velocity) to all other walls (fixedWalls).
Designate the front and back faces as 'empty' to enforce 2D flow behavior.
Set the kinematic viscosity (nu) to 1e-05 m²/s as a constant.
Use the pisoFoam solver for incompressible flow simulations.
Set the end time of the simulation to 10 seconds.
Use the convection scheme div(phi,U) Gauss limitedLinearV 1 for momentum.
Use the convection scheme div(phi,k) Gauss limitedLinear 1 for turbulent kinetic energy.
Use the convection scheme div(phi,epsilon) Gauss limitedLinear 1 for turbulent dissipation rate.
Use the viscous term scheme div((nuEff*dev2(T(grad(U))))) Gauss linear.
