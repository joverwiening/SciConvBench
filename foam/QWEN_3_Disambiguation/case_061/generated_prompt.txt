Define the simulation domain with blockMesh using a grid size of 100×50×50 corresponding to dimensions (Lx, H, Lz) = (2.0 m, 0.10 m, 0.10 m).
Apply grid refinement near walls if necessary to ensure proper resolution for wall functions.
