Simulate a gas-solid fluidized bed using an Euler-Euler model.

Solver: twoPhaseEulerFoam (or multiphaseEulerFoam if using more phases)

Geometry: 3D bed 0.1 m x 0.5 m x 0.1 m. Gas enters from the bottom distributor; outlet at the top.
Mesh: blockMesh 50 x 250 x 50.

Phases:
- phase1: air (continuous gas)
- phase2: solid particles (granular phase), diameter d_p = 200 microns, rho_s = 2500 kg/m^3
Gas properties: rho_g = 1.2 kg/m^3, nu_g = 1.5e-5 m^2/s.

Models/closures (constant/phaseProperties etc):
- drag: SchillerNaumann (or Gidaspow if desired)
- solids stress: kineticTheory (granular temperature), with appropriate restitution coefficient (e=0.9) and frictional stress model if dense
- turbulence: RAS kEpsilon in the gas phase (optional) or laminar if low
- wall friction for solids: JohnsonJackson (if available) or standard granular wall BCs

Initial conditions:
- Set initial packed bed: alpha.solid = 0.55 in bottom 0.2 m; alpha.solid = 0 above; alpha.air = 1 - alpha.solid.
- U.air = (0 0 0); U.solid = (0 0 0); p_rgh = 0.

Boundary conditions:
- bottom inlet:
  - U.air fixedValue upward such that superficial velocity exceeds minimum fluidization (e.g., 0.2 m/s)
  - alpha.solid zeroGradient (no solids inflow)
- top outlet:
  - p_rgh totalPressure p0 0
  - U.air pressureInletOutletVelocity
  - alpha.solid inletOutlet (inletValue 0; value 0) to allow solids to leave (or set to zeroGradient if you want no entrainment)
- walls:
  - U.air noSlip
  - U.solid partialSlip / granular wall condition
  - alpha gradients zero

Time controls: endTime 5; deltaT 1e-4-5e-4 with adjustTimeStep and maxCo 0.3; writeInterval 0.05.
