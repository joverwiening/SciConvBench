Discretize the domain uniformly with 32 x 32 x 32 cells.

Set surface tension coefficient to 0.07 N/m.
Set gravity vector to (0 0 -9.81) m/s^2.
Apply wall boundary conditions to all faces except the top.
Set the top face (z=1) as open atmosphere boundary.
Place a rectangular obstacle from (0.375 0.375 0) to (0.625 0.625 0.25).
Initialize water column (alpha.water = 1) in region (0 0 0) to (0.6 0.1875 0.75).
Set initial air fraction (alpha.air = 1) in remaining domain.
Set simulation time parameters: deltaT = 0.001 s, endTime = 0.1 s.
Set writeInterval = 0.02 s for output data.
Use laminar flow model for the simulation.
