The simulation shall use pisoFoam solver for incompressible lid-driven cavity flow.
The cavity dimensions are 1x1x0.1 units in x, y, and z directions respectively.
Use a mesh of 20x20x1 cells in x, y, and z directions.
The simulation runs from t=0 to t=10 with a time step of 0.005 units.
Output results every 100 time steps.
Use k-epsilon turbulence model.
Set kinematic viscosity (nu) to 1e-05 m^2/s.
Initialize velocity field to zero everywhere.
Set top wall ('movingWall') velocity to 1 m/s in x-direction.
Set other walls to no-slip condition (U = 0).
Initialize k = 1.5e-4 uniformly in the domain.
Initialize epsilon = 1.4e-4 uniformly in the domain.
Initialize nut = 0 uniformly in the domain.
Apply kqRWallFunction for k on all walls (front/back empty).
Apply epsilonWallFunction for epsilon on all walls (front/back empty).
Apply nutkWallFunction for nut on all walls (front/back empty).
Set pressure boundary condition to zeroGradient on all walls except fixed value of 0 at one cell.
Initialize pressure field to 0 uniformly.
Use convection scheme div(phi,U) Gauss limitedLinearV 1.
Use convection scheme div(phi,k) Gauss limitedLinear 1.
Use convection scheme div(phi,epsilon) Gauss limitedLinear 1.
Use div((nuEff*dev2(T(grad(U))))) Gauss linear for viscous term.
Set front and back patches to empty type.
