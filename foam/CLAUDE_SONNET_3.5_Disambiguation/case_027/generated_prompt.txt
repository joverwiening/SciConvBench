The computational domain is a 1m x 1m x 1m cube from (0,0,0) to (1,1,1).
Use interFoam solver for transient laminar two-phase flow simulation.
Discretize the domain uniformly with 32 x 32 x 32 cells.
Set time step size (deltaT) to 1e-3 seconds.
Run the simulation until end time of 0.1 seconds.
Define phase properties: water (density = 1000 kg/m^3, viscosity = 1.0e-6 m^2/s) and air (density = 1 kg/m^3, viscosity = 1.48e-5 m^2/s).
Set surface tension coefficient to 0.07 N/m.
Initialize water column as rectangular prism with alpha.water = 1 in region (0,0,0) to (0.6,0.1875,0.75), and alpha.water = 0 elsewhere.
Place rectangular obstacle block from (0.375,0.375,0) to (0.625,0.625,0.25).
Set boundary conditions: atmosphere patch at top face (z=1), walls at remaining five faces.
Use Volume of Fluid (VOF) method for interface tracking between phases.
