Problem: 2D multiphase simulation of a dam break using the Volume of Fluid (VOF) method.
Solver: interFoam
Geometry: A rectangular tank of size 0.584m (length) x 0.584m (height). The initial water column is 0.146m wide and 0.292m high, located in the bottom-left corner. The case is 2D, with front and back patches of type 'empty'.
Mesh: Use blockMesh to create a uniform 58x58 grid. Patches are 'leftWall', 'rightWall', 'lowerWall', 'atmosphere' (top), and 'frontAndBack'.
Physical Properties: In constant/transportProperties, define two phases: 'water' and 'air'.
- water: rho=1000 kg/m^3, nu=1e-6 m^2/s.
- air: rho=1 kg/m^3, nu=1.48e-5 m^2/s.
- Set surface tension sigma to 0.07 N/m.
Gravity: In the constant/ directory, create a file 'g' with the content: dimensions [0 1 -2 0 0 0 0]; value (0 -9.81 0);
Initial Conditions: In the 0/ directory, initialize U to uniform (0 0 0) and p_rgh to uniform 0. The phase fraction 'alpha.water' is initialized using the 'setFields' utility. The system/setFieldsDict should define a boxToCell from (0 0 -1) to (0.146 0.292 1) with fieldValue 1, and a defaultFieldValue of 0.
Boundary Conditions:
- U: 'atmosphere' is pressureInletOutletVelocity; all walls are noSlip; 'frontAndBack' is empty.
- p_rgh: 'atmosphere' is totalPressure with p0 uniform 0; all walls are fixedFluxPressure; 'frontAndBack' is empty.
- alpha.water: 'atmosphere' is inletOutlet with inletValue 0; all walls are zeroGradient; 'frontAndBack' is empty.
Time Controls: In system/controlDict, use adjustable time step with 'adjustTimeStep yes', 'maxCo 0.5', and 'maxAlphaCo 0.5'. Set startTime to 0, endTime to 2, writeControl to timeStep, and writeInterval to 20.
