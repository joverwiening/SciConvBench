The domain is a 1m x 1m square with a 40x40 mesh.
The simulation uses pimpleFoam solver for transient flow.
The kinematic viscosity is set to 1e-4 m^2/s.
The simulation runs until t=5s.
The top wall moves with velocity (1 0 0) m/s.
Time stepping is adjustable with maxCo=1.0 and maxDeltaT=0.05.
Initial velocity field is set to uniform (0 0 0).
Bottom and side walls use noSlip condition for velocity and fixedFluxPressure with uniform 0 for pressure.
Top wall uses fixedFluxPressure with uniform 0 for pressure.
The velocity boundary condition for the top wall is a moving wall with velocity (1 0 0) m/s.
