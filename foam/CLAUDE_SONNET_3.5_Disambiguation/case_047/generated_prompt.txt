The channel flow simulation shall use the following specifications:
Channel dimensions are 1m (length) x 0.1m (height) x 0.2m (width).
Reynolds number is 5000 based on channel height, bulk velocity, and kinematic viscosity.
Use k-epsilon turbulence model.
Drive the flow using meanVelocityForce to maintain 0.5 m/s bulk velocity.
Apply wall boundary conditions: noSlip for velocity, zeroGradient for pressure, wall functions for k/epsilon/nut.
Set initial conditions: U = (0.1 0 0) m/s, p = 0, k = 0.000375, epsilon = 1.875e-4.
Use SIMPLE algorithm for pressure-velocity coupling.
Use GAMG solver for pressure with 1e-6 tolerance.
Use smoothSolver for velocity, k, and epsilon with 1e-5 tolerance.
Set kinematic viscosity to 1e-5 m²/s.
Apply kqRWallFunction for k with value 0.000375.
Apply epsilonWallFunction for epsilon with value 1.875e-4.
Apply nutkWallFunction for nut with value 0.
