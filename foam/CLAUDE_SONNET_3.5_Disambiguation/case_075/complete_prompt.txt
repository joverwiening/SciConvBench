Simulate the 2D lid-driven cavity at Reynolds number Re=5000.

Solver: pisoFoam (transient incompressible)

Geometry: Use the standard cavity tutorial geometry (unit square) as 2D with empty front/back.

Mesh: Use the standard cavity mesh (e.g., 100x100x1) or refine as needed.

Physical properties: set nu so that Re = U_lid*L/nu = 5000.
With L=1 m and U_lid=1 m/s, use nu = 2e-4 m^2/s (constant/transportProperties).

Turbulence: RAS kEpsilon (constant/momentumTransport). Use wall functions; target y+ in the wall-function range (~30-100) if using wall functions.

Initial conditions:
- U = (0 0 0)
- p = 0
- k and epsilon small uniform values (e.g., k=1e-4, epsilon=1e-4)

Boundary conditions:
- moving lid (topWall):
  - U fixedValue (1 0 0)
  - p zeroGradient
  - k kqRWallFunction
  - epsilon epsilonWallFunction
  - nut nutkWallFunction
- other walls:
  - U noSlip
  - p zeroGradient
  - k kqRWallFunction
  - epsilon epsilonWallFunction
  - nut nutkWallFunction
- frontAndBack: empty

Time controls: endTime 50; deltaT 0.005; adjustTimeStep yes; maxCo 0.5; writeInterval 0.5.
PISO controls (fvSolution): nCorrectors 2-3; nNonOrthogonalCorrectors 0.
