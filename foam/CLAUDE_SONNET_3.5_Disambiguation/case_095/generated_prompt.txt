The simulation domain is a 2D square cavity of size 1m x 1m.
Use buoyantBoussinesqSimpleFoam solver for steady-state solution.
Create a uniform 50x50 mesh.
Set left wall temperature to 310K.
Set right wall temperature to 290K.
Set top and bottom walls as thermally insulated.
Set gravity vector to (0, -9.81, 0) m/s^2.
Set initial and reference temperature to 300K.
Set kinematic viscosity to 1.5e-5 m^2/s.
Set thermal expansion coefficient (beta) to 3.33e-3 1/K.
Set thermal diffusivity (alpha) to 2.11e-5 m^2/s (calculated from Pr = 0.71).
Use laminar flow (no turbulence model).
Set convergence criteria: p_rgh residual < 1e-6.
Set convergence criteria: U residual < 1e-6.
Set convergence criteria: T residual < 1e-6.
Apply Boussinesq approximation for buoyancy effects.
Set no-slip boundary conditions on all walls.
