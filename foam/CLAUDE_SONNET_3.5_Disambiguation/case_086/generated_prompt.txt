The shock tube simulation should be set up as follows:
The domain is a rectangular box from (0 0 0) to (1 0.1 0.1) meters.
Use rhoCentralFoam solver for the simulation.
Initial conditions for x < 0.5 m: pressure = 100000 Pa, temperature = 348.4 K, velocity = (0 0 0) m/s.
Initial conditions for x >= 0.5 m: pressure = 10000 Pa, temperature = 278.7 K, velocity = (0 0 0) m/s.
Set endTime to 0.007 seconds.
Set initial deltaT to 1e-6 seconds.
Enable adjustableTimeStep with maxCo = 0.5.
Set writeInterval to 0.0005 seconds.
Use air as the working fluid with standard properties.
Create a 3D structured mesh with appropriate refinement near the discontinuity.
Apply zeroGradient boundary conditions for all variables at all boundaries.
Initialize the internal field using setFields utility to create the discontinuity at x = 0.5 m.
