The domain is a 2m wide x 1m high rectangular enclosure.
The simulation models Rayleigh-Benard convection with Ra = 2500.
Set bottom wall temperature to 300 K.
Set top wall temperature to 299 K.
Apply periodic (cyclic) boundary conditions on left and right walls for all fields (U, T, p_rgh).
Set kinematic viscosity to 0.00928 m²/s.
Set thermal diffusivity to 0.01307 m²/s.
Set gravitational acceleration to 9.81 m/s² in the negative y-direction.
Initialize temperature field as T(x,y) = (300 - y) + 0.1*sin(π*x).
Set simulation end time to 500 seconds.
Use adaptive time stepping with initial deltaT = 0.1s and maxCo = 0.5.
Use second-order central differencing for spatial discretization of velocity.
Use second-order central differencing with van Leer limiter for temperature.
Use second-order backward differencing for temporal discretization.
