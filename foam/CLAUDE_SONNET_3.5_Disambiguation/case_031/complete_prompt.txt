Simulate steady-state 2D Rayleigh-Benard convection in a rectangular cavity using the Boussinesq approximation.

Solver: buoyantBoussinesqSimpleFoam (steady-state SIMPLE-based solver for buoyant incompressible flow)

Geometry: 2D cavity of size 1 m (width) x 0.25 m (height) with a small out-of-plane thickness 0.01 m. Use front/back patches of type empty.

Mesh: blockMesh with (80 20 1) uniform cells. Patches: bottomHot, topCold, sideWalls (left+right), frontAndBack.

Physical properties (constant/physicalProperties, Boussinesq):
- nu = 1e-6 m^2/s
- Pr = 7.0  (water-like)
- beta = 2.0e-4 1/K
- T0 = 300 K (reference/mean temperature)
- rho0 = 1000 kg/m^3
Gravity (constant/g): (0 -9.81 0)

Boundary conditions (0/):
- T: bottomHot fixedValue 310; topCold fixedValue 290; sideWalls zeroGradient; frontAndBack empty.
- U: noSlip on bottomHot, topCold, sideWalls; frontAndBack empty.
- p_rgh: fixedFluxPressure on bottomHot, topCold, sideWalls; frontAndBack empty.
Initial fields: U=(0 0 0), T=300 K, p_rgh=0 everywhere.

Numerics:
- system/fvSchemes: steadyState ddtSchemes; second-order (linear) gradients; bounded upwind for div(phi,U) and div(phi,T); laplacian Gauss linear corrected.
- system/fvSolution:
  - linear solvers: GAMG for p_rgh; smoothSolver for U and T.
  - SIMPLE controls: nNonOrthogonalCorrectors 0; residualControl { p_rgh 1e-6; U 1e-6; T 1e-6; }.
  - relaxationFactors: p_rgh 0.3; U 0.7; T 0.7.

Run control (system/controlDict): endTime 1000; deltaT 1; writeInterval 100 (pseudo-time iterations for the steady solver).
