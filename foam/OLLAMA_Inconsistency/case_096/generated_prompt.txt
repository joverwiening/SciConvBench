Initialize the volume fraction field alpha.water using setFieldsDict so that alpha.water = 1 for all cells where x < 0.15 m (water column) and alpha.water = 0 elsewhere (air).

Configure system/controlDict with startTime 0, endTime 1.5 s, deltaT 0 (adjustable), adjustTimeStep yes, maxCo 0.2, writeInterval 0.05, and use the default time‑stepping and solver settings recommended for interFoam.
