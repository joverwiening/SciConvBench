Set up an axisymmetric steady‑state simulation of swirling flow inside a circular pipe using the incompressible solver `simpleFoam`.  
Use a 2‑D wedge mesh that spans a 5‑degree sector in the circumferential direction and is one cell thick in that direction.  
Assume a pipe inner radius of 0.05 m (diameter = 0.10 m) and a pipe length of 1.0 m, which corresponds to ten pipe diameters and provides a good aspect ratio for the flow development.  
Create the mesh with `blockMesh` using the following block definition:  

```
vertices
(
    (0 0 0)                     // 0: centre line, inlet
    (0.05 0 0)                  // 1: pipe wall, inlet
    (0 0 1.0)                   // 2: centre line, outlet
    (0.05 0 1.0)                // 3: pipe wall, outlet
    (0 0 0)                     // 4: duplicate of 0 for back face (empty)
    (0.05 0 0)                  // 5: duplicate of 1 for back face (empty)
    (0 0 1.0)                   // 6: duplicate of 2 for back face (empty)
    (0.05 0 1.0)                // 7: duplicate of 3 for back face (empty)
);

blocks
(
    hex (0 1 3 2 4 5 7 6) 200 20 1 simpleGrading (1 1 1)
);

edges
(
);

boundary
(
    axis
    {
        type            empty;
        faces
        (
            (0 2 6 4)
        );
    }
    wall
    {
        type            wall;
        faces
        (
            (1 3 7 5)
        );
    }
    inlet
    {
        type            patch;
        faces
        (
            (0 1 5 4)
        );
    }
    outlet
    {
        type            patch;
        faces
        (
            (2 3 7 6)
        );
    }
    front
    {
        type            empty;
        faces
        (
            (0 3 2 1)
        );
    }
    back
    {
        type            empty;
        faces
        (
            (4 5 6 7)
        );
    }
);
```

Set the wedge angle to 5 degrees by adding the line `convertToMeters 1;` and the `mergePatchPairs` entry is not required because the front and back faces are `empty`.  

Define the `system/controlDict` for a steady simulation:  

```
application     simpleFoam;
startFrom       startTime;
startTime       0;
stopAt          endTime;
endTime         1000;
deltaT          1;
writeControl    timeStep;
writeInterval   100;
purgeWrite      0;
```

Use standard second‑order schemes in `system/fvSchemes` and a SIMPLE algorithm with under‑relaxation factors in `system/fvSolution`.  

Create the initial fields in `0/U`, `0/p`, and turbulence fields (`0/k`, `0/epsilon`) with the following boundary conditions:  

- `U` at `inlet`: fixedValue ( (Uaxial 0 0) ) where `Uaxial` is a reasonable mean axial velocity, e.g., 5 m s⁻¹, and a tangential component to impose swirl, e.g., 2 m s⁻¹.  
- `U` at `outlet`: zeroGradient.  
- `U` at `wall`: noSlip.  
- `U` at `axis`, `front`, `back`: empty.  

- `p` at `inlet`: zeroGradient.  
- `p` at `outlet`: fixedValue 0.  
- `p` at `wall`, `axis`, `front`, `back`: zeroGradient.  

- Turbulence fields (`k`, `epsilon`) use standard `kEpsilon` model with appropriate inlet values (e.g., `k` = 0.01 m² s⁻², `epsilon` = 0.001 m² s⁻³) and zeroGradient at outlet, wall functions at `wall`, and empty at `axis`, `front`, `back`.  

Run `blockMesh` to generate the mesh, then execute `simpleFoam`.  
Post‑process the results with `paraFoam` to examine axial velocity profiles, swirl distribution, and pressure drop along the pipe.
