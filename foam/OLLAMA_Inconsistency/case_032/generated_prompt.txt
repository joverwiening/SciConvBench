Simulate a 2D steady‑state, turbulent, incompressible flow over a NACA 0012 airfoil at a 5° angle of attack using OpenFOAM’s simpleFoam solver with the k‑omega SST turbulence model.  
Assume a chord length of 1.0 m; use this as the reference length for lift and drag coefficient calculations.  
Assume standard atmospheric conditions: density ρ = 1.225 kg m⁻³ and dynamic viscosity μ = 1.8 × 10⁻⁵ Pa·s.  
Create a C‑grid mesh with blockMesh; extrude the 2‑D mesh by one cell in the z‑direction to obtain a single‑cell thickness domain.  
Define the front and back patches in blockMeshDict as type “symmetry” and name them “frontAndBack”.  
Set the following boundary conditions in the “0” directory:  

- **U**:  
  - inlet: fixedValue (10 0 0.1) m s⁻¹  
  - outlet: zeroGradient  
  - airfoil: fixedValue (0 0 0) m s⁻¹ (no‑slip wall)  
  - frontAndBack: symmetryPlane  

- **p**:  
  - inlet: zeroGradient  
  - outlet: fixedValue 0  
  - airfoil: zeroGradient (wall)  
  - frontAndBack: symmetryPlane  

- **k** (turbulent kinetic energy):  
  - inlet: fixedValue calculated from a turbulence intensity of 5 %: k = 1.5 · (I·U)² ≈ 0.01875 m² s⁻²  
  - outlet: zeroGradient  
  - airfoil: zeroGradient (wall)  
  - frontAndBack: symmetryPlane  

- **omega** (specific dissipation rate):  
  - inlet: fixedValue using a turbulent length scale of 0.07 · chord: ω = √k / (C_μ^0.25 · l) ≈ 5.0 s⁻¹ (use C_μ = 0.09)  
  - outlet: zeroGradient  
  - airfoil: zeroGradient (wall)  
  - frontAndBack: symmetryPlane  

Configure simpleFoam with appropriate relaxation factors and second‑order discretisation schemes (e.g., Gauss linear for gradients, Gauss linearUpwind for convection).  
Add a “forceCoeffs” function object in controlDict to compute lift and drag coefficients using the airfoil surface as the reference patch, reference area = chord × unit depth (1.0 m²), and reference pressure = 0.  
Run the simulation until residuals fall below 1 × 10⁻⁶ and the lift/drag coefficients converge.  
Post‑process the results to report the steady‑state lift coefficient (C_L) and drag coefficient (C_D).
