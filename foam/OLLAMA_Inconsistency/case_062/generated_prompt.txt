Create a new OpenFOAM case for a 2‑D cantilever beam with the following geometry: length 1.0 m in the x‑direction and height 0.1 m in the y‑direction. Generate a structured mesh of 100 cells along x and 10 cells along y using blockMesh.

In the blockMeshDict define the vertices (0 0 0, 1 0 0, 1 0.1 0, 0 0.1 0) and a single hexahedral block with grading (100 10 1). Set the default cell type to hex and use simpleGrading (1 1 1).

Create a mechanicalProperties dictionary in the constant directory with:
```
materialModel  linearElastic;
E              70e9;
nu             0.33;
planeStrain    true;
```

In the 0 directory define the displacement field “U” with initial value uniform (0 0 0). Apply the following boundary conditions:
- fixedEnd (patch at x = 0): type fixedValue; value uniform (0 0 0)
- loadEnd (patch at x = 1): type tractionDisplacement; traction uniform (0 -10000 0); pressure uniform 0
- top and bottom (patches at y = 0 and y = 0.1): type zeroGradient

Create an empty pressure field “p” (or use the default zero field) with zeroGradient on all boundaries, as required by solidDisplacementFoam.

In system/controlDict set:
```
application     solidDisplacementFoam;
startTime       0;
endTime         1;
deltaT          1;
writeControl    timeStep;
writeInterval   1;
```

In system/fvSolution configure a simple linear solver for static analysis, e.g.:
```
solvers
{
    U
    {
        solver          PCG;
        preconditioner  DIC;
        tolerance       1e-08;
        relTol          0;
    }
}
```

In system/fvSchemes use default schemes appropriate for solid mechanics (e.g., linearGrad, Gauss linear).

Run the case:
1. blockMesh
2. solidDisplacementFoam

The simulation will compute the static deflection of the cantilever beam under the specified downward traction load using linear elasticity in a plane‑strain formulation.
