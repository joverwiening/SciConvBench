Set up a 2D natural convection simulation of a square cavity using the OpenFOAM solver `buoyantBoussinesqPimpleFoam`.  
Assume the cavity dimensions are 1 m × 1 m.  

Create the geometry with `blockMesh` using a single block that spans from (0 0 0) to (1 1 0.01) and discretize it with a uniform grid of 50 cells in the X direction and 50 cells in the Y direction (the third dimension is a single cell of thickness 0.01 m to keep the case 2‑D).  

Define the fluid as incompressible air with Boussinesq approximation:  
- Kinematic viscosity ν = 1.5e‑5 m²/s (corresponding to Pr ≈ 0.71 at 300 K).  
- Thermal diffusivity α = ν / Pr.  
- Thermal expansion coefficient β = 1/300 K⁻¹.  
- Reference temperature TRef = 300 K.  
- Gravity vector g = (0 -9.81 0) m/s² acting in the negative Y direction.  

Boundary conditions:  

- **leftWall** (hot): `type fixedValue; value uniform 310;` for temperature T, `type zeroGradient;` for velocity U.  
- **rightWall** (cold): `type fixedValue; value uniform 290;` for temperature T, `type zeroGradient;` for velocity U.  
- **topWall** (adiabatic): `type zeroGradient;` for temperature T, `type zeroGradient;` for velocity U.  
- **bottomWall** (adiabatic): `type zeroGradient;` for temperature T, `type zeroGradient;` for velocity U.  
- **frontAndBack** (symmetry planes): `type empty;` for both T and U to enforce 2‑D behavior.  

Initial fields (in the `0` directory):  

- `T`: `internalField uniform 300;` with the boundary conditions listed above.  
- `U`: `internalField uniform (0 0 0);` with the same boundary conditions as above.  
- `p`: `internalField uniform 0;` with `type zeroGradient;` on all walls and `type fixedFluxPressure;` on the outlet (choose any wall as reference).  

Set up the `controlDict` to run the simulation for a physical time of 500 s, with a time step automatically adjusted by the Courant number (maxCo = 0.5). Write results every 10 s.  

Create the `fvSchemes` and `fvSolution` files using standard settings for buoyant Boussinesq flows:  
- Use second‑order Gauss linear schemes for divergence and gradient terms.  
- Use the PIMPLE algorithm with `nOuterCorrectors 2`, `nCorrectors 2`, and `nNonOrthogonalCorrectors 0`.  

After generating the mesh with `blockMesh`, run the case with:  

```
buoyantBoussinesqPimpleFoam > log.run 2>&1
```  

Post‑process temperature and velocity fields using `paraFoam` or `sample` to extract vertical temperature profiles and streamlines.
