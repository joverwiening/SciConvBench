Perform a 2D steady-state incompressible flow simulation of developing flow in a rectangular channel using the simpleFoam solver.  
Mesh only the bottom half of the channel; the channel centreline is represented by a symmetry plane.  
Define the patches in system/blockMeshDict as inlet, outlet, bottomWall, centerline, and frontAndBack (type empty).  

Boundary conditions:  
- inlet: fixedValue uniform velocity (1 0 0) m s⁻¹ in 0/U.  
- outlet: zeroGradient for velocity in 0/U and fixedValue zero pressure (0) in 0/p.  
- bottomWall: noSlip (fixedValue (0 0 0)) for velocity in 0/U and zeroGradient for pressure in 0/p.  
- centreline: symmetryPlane type; zeroGradient for velocity normal component and slip for tangential components in 0/U, and zeroGradient for pressure in 0/p.  
- frontAndBack: empty type for all fields.  

Initial fields:  
- Set uniform initial velocity (0.1 0 0) m s⁻¹ in 0/U.  
- Set uniform initial pressure (0) Pa in 0/p.  

Turbulence model: use the standard k‑epsilon model (RASProperties set to kEpsilon).  
- Initialise k and epsilon with typical turbulent intensity of 5 % and length scale equal to 0.07 × hydraulic height.  

Physical properties (constant/transportProperties):  
- Density ρ = 1000 kg m⁻³.  
- Kinematic viscosity ν = 1e‑6 m² s⁻¹ (dynamic viscosity μ = 1e‑3 Pa·s).  

Solver settings (system/fvSolution and fvSchemes): use default SIMPLE algorithm settings for steady incompressible flow, with under‑relaxation factors 0.3 for pressure and 0.7 for velocity.  

Run the simulation until residuals for all equations fall below 1e‑5.  

Post‑process velocity and pressure fields to examine development length and wall shear stress on the bottomWall.
