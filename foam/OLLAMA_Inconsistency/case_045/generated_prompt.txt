Perform a steady‑state, incompressible 2‑D simulation of airflow over a NACA 0012 airfoil using the simpleFoam solver with the k‑omega SST turbulence model.  
Assume a free‑stream velocity of 30 m s⁻¹ and an angle of attack of 5° (positive nose‑up).  
Use air at standard conditions (ρ = 1.225 kg m⁻³, ν = 1.5 × 10⁻⁵ m² s⁻¹).  
Create a rectangular computational domain extending 20 chord lengths upstream, 30 chord lengths downstream, and 20 chord lengths above and below the airfoil.  
Generate a structured C‑grid mesh with a single cell layer in the z‑direction; set the first cell height near the airfoil surface to achieve y⁺ ≈ 1 for the k‑omega SST model.  
Define boundary patches as follows:  
- inlet: type fixedValue, U = (30 cos 5°, 30 sin 5°, 0) m s⁻¹, p = zeroGradient.  
- outlet: type zeroGradient for U, fixedValue p = 0 Pa.  
- top and bottom: type symmetryPlane.  
- frontAndBack: type wall, U = noSlip, p = zeroGradient.  
- airfoil surface: type wall, U = noSlip, p = zeroGradient.  
Set turbulence initial fields consistent with the k‑omega SST model (e.g., k = 1.5 × 10⁻³ m² s⁻², ω = 5 s⁻¹).  
Use SIMPLE algorithm with standard under‑relaxation factors (e.g., 0.3 for pressure, 0.7 for velocity, 0.7 for k, 0.7 for ω).  
Run until residuals drop below 1 × 10⁻⁵ for all equations and monitor lift and drag coefficients for convergence.  
Post‑process lift, drag, pressure coefficient distribution, and velocity field on the airfoil surface.
