The mesh consists of 55 cells in the streamwise direction (15 inlet + 20 porous + 20 outlet) and 20 cells in each transverse direction, giving a total of 55 × 20 × 20 cells.

The constant directory contains the following files:

thermophysicalProperties defines air as an ideal gas with γ = 1.4, R = 287 J kg⁻¹ K⁻¹, and reference temperature 300 K.

turbulenceProperties selects the k‑epsilon model.

porousProperties (applied to the “porosity” cell zone) specifies DarcyCoeff = 1e5 1/m and ForchCoeff = 1e3 1/m.

controlDict sets startTime = 0, endTime = 1000, deltaT = 1, writeInterval = 100, and uses the SIMPLE algorithm.

fvSchemes uses bounded Gauss upwind for all convective terms and Gauss linear corrected for all diffusive terms.

fvSolution configures:
- pressure solver GAMG with tolerance 1e‑8, relTol 0.05;
- velocity and turbulence solvers smoothSolver with GaussSeidel smoother, tolerance 1e‑6 for velocity and 1e‑7 for k‑epsilon;
- relaxation factors 0.3 for pressure, 0.7 for velocity, and 0.9 for turbulence quantities.

Boundary conditions are defined as follows:

Inlet patch:
- velocity U fixedValue uniform (1 0 0) m s⁻¹;
- pressure p fixedValue uniform 101325 Pa;
- temperature T fixedValue uniform 300 K;
- turbulent kinetic energy k fixedValue uniform 0.01 m² s⁻²;
- turbulent dissipation rate epsilon fixedValue uniform 0.001 m² s⁻³.

Outlet patch:
- velocity U zeroGradient;
- pressure p fixedValue uniform 101325 Pa;
- temperature T fixedValue uniform 300 K;
- k zeroGradient;
- epsilon zeroGradient.

PorosityWall (wall type):
- velocity U fixedValue uniform (0 0 0) (no‑slip);
- pressure p zeroGradient;
- temperature T zeroGradient;
- k zeroGradient;
- epsilon zeroGradient.

All remaining wall patches use the default wall type with no‑slip velocity and zeroGradient for pressure, temperature, k, and epsilon.

Initial fields (0/U, 0/p, 0/T, 0/k, 0/epsilon) are set to the same uniform values as the inlet conditions.

The case is ready to be run with blockMesh, followed by rhoPorousSimpleFoam.
