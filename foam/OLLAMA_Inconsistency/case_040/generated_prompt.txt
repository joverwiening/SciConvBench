Simulate incompressible water flow in a 2‑D channel using OpenFOAM with a dynamic mesh that implements a simplified peristaltic pump.  
Use a 2‑D mesh extruded one cell in the spanwise direction with `frontAndBack` set to `empty`.  
Set water kinematic viscosity `nu = 1e-6 m^2/s`.  

Mesh motion:  
- Use `dynamicMotionSolverFvMesh` with the `displacementLaplacian` solver defined in `constant/dynamicMeshDict`.  
- Prescribe the wall motion on the patch named `movingWall` via `0/pointDisplacement` using the `oscillatingDisplacement` type.  
- All other boundaries have `fixedValue uniform (0 0 0)` displacement.  

Moving‑wall displacement:  
- Amplitude = 0.05 m (5 % of the channel height).  
- Period = 1 s (frequency = 1 Hz).  
- The displacement field is `oscillatingDisplacement` with `amplitude (0.05 0 0)` and `period 1`.  

Moving‑wall velocity:  
- The velocity on `movingWall` is obtained from the time derivative of the prescribed displacement and applied as `movingWallVelocity` in the `0/U` file.  

Flow boundary conditions (`0/U`):  
- Inlet patch: `fixedValue uniform (Uinlet 0 0)` (choose a suitable inlet velocity, e.g., `Uinlet = 0.1 m/s`).  
- Outlet patch: `zeroGradient`.  
- Stationary wall patches: `noSlip`.  
- `movingWall` patch: `movingWallVelocity`.  

Flow boundary conditions (`0/p`):  
- Outlet patch: `fixedValue uniform 0`.  
- Inlet and all wall patches: `zeroGradient`.  

Solver:  
- Set `application solidDisplacementFoam;` in `system/controlDict`.  

Time settings:  
- Simulate for 5 s (five complete peristaltic cycles).  
- Use a constant time step `deltaT = 0.001 s` (ensuring Courant number < 0.5).  
- Write results every `0.01 s`.  

Numerical schemes and solvers:  
- Use second‑order accurate schemes for divergence, gradient, and Laplacian terms.  
- Use a pressure‑velocity coupling algorithm appropriate for incompressible flow (e.g., PIMPLE).  

Post‑processing:  
- Export velocity, pressure, and wall shear stress fields for each time step.  
- Compute volumetric flow rate at the inlet and outlet to assess pumping performance.
