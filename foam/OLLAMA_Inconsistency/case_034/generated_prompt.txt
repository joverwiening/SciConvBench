Set up a 2‑D dam‑break case using the interFoam solver for a water‑air two‑phase system.  
Define the computational domain as a rectangular box 2 m long in the x‑direction, 1 m high in the y‑direction, and one cell thick in the z‑direction (single‑cell depth).  
Create the mesh with blockMesh using a uniform grid of 200 cells in x, 100 cells in y, and 1 cell in z.  
Specify gravity in constant/g as (0 -9.81 0).  
Define the front and back patches in blockMeshDict as a single patch named frontAndBack with type wall.  
In the 0 directory, set the following boundary conditions for all patches:  
- For the frontAndBack patch, assign U a fixedValue (noSlip) condition, and assign p_rgh and alpha.water zeroGradient conditions.  
- For the inlet (left) and outlet (right) patches, assign U a zeroGradient condition, p_rgh a zeroGradient condition, and alpha.water a zeroGradient condition.  
- For the top (air) patch, assign U a slip condition (zeroGradient), p_rgh a zeroGradient condition, and alpha.water a zeroGradient condition.  
- For the bottom (wall) patch, assign U a fixedValue (noSlip) condition, p_rgh a zeroGradient condition, and alpha.water a zeroGradient condition.  
Define the initial water column using setFieldsDict: place water (alpha.water = 1) in the region 0 ≤ x ≤ 0.5 m and 0 ≤ y ≤ 0.5 m, and air (alpha.water = 0) elsewhere.  
Initialize the velocity field U to (0 0 0) everywhere.  
Initialize the pressure field p_rgh to 0 Pa everywhere.  
Set the simulation time parameters in controlDict: startTime 0, endTime 5, deltaT 0.001, writeInterval 0.05.  
Configure the interFoam solver settings in fvSolution: use the PIMPLE algorithm with a maximum of 2 outer correctors, 1 pressure corrector, and 2 velocity correctors; set the linear solvers for pressure (PCG preconditioned with DIC) and for velocity (smoothSolver with GaussSeidel).  
Set the discretisation schemes in fvSchemes: use second‑order Gauss linear for gradient and divergence terms, limitedLinearV for the convection of alpha.water, and Gauss linear for Laplacian terms.  
Run the case with blockMesh, setFields, and then interFoam.  
Post‑process the results using paraFoam to visualize the water surface evolution and velocity field.
