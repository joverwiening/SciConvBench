Simulate the quasi-static deflection of a 3D steel cantilever beam using linear elasticity.  
The beam dimensions are 1 m long, 0.1 m high, and 0.1 m wide.  
Use the solidDisplacementFoam solver.  
In system/controlDict set application to solidDisplacementFoam and endTime to 1.  
In constant/mechanicalProperties define Young’s modulus E = 200e9 Pa and Poisson ratio ν = 0.3.  
Apply a fixedValue uniform (0 0 0) condition on the clamped end named “fixed”.  
Apply a tractionDisplacement condition on the free end named “loaded” with traction uniform (0 -1000 0) and pressure uniform 0.  
Apply zeroGradient on all remaining faces.  
Run the case as a quasi‑static analysis with no inertial terms.
