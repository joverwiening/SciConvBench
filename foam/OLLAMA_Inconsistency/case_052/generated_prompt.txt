Set up a 2D lid-driven cavity case using the `nonNewtonianIcoFoam` solver.  
Define the computational domain as a 1 m × 1 m square with a uniform mesh (e.g., 100 × 100 cells).  
Apply the following boundary conditions:  
- Top wall (lid): fixed velocity `U (1 0 0)` m/s.  
- All other walls: `noSlip` condition (zero velocity).  
Create the `constant/transportProperties` file with the Power‑Law model:  

```
transportModel  PowerLaw;
nuMax           1;
nuMin           1e-6;
k               0.1;
n               0.5;
```  

Set the simulation control parameters in `system/controlDict` as follows:  
- `startTime` 0.  
- `endTime` 10.   (reasonable total simulation time for a transient lid‑driven cavity)  
- `deltaT` 0.01.  
- `writeInterval` 1.0.  
- `adjustTimeStep` true.  
- `maxCo` 0.5.  

Use default `fvSchemes` and `fvSolution` settings appropriate for `nonNewtonianIcoFoam`, ensuring second‑order spatial discretisation for momentum and appropriate solvers for pressure‑velocity coupling.  

Run the case with `nonNewtonianIcoFoam` and post‑process the velocity and pressure fields to analyze the shear‑thinning behavior.
