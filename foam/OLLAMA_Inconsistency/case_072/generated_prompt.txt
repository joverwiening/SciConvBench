Create a new OpenFOAM case directory with the standard sub‑folders constant, system and 0.  
Use the buoyantBoussinesqPimpleFoam solver for the simulation.  
Generate a hexahedral mesh for a rectangular box of size 1 m × 1 m × 0.1 m with 100 cells in the x‑direction, 100 cells in the y‑direction, and 20 cells in the z‑direction.  
In constant/transportProperties set the Boussinesq approximation with beta 0.00341, reference temperature T0 300 K, kinematic viscosity nu 1.5e‑5 m²/s, and Prandtl number Pr 0.71.  
In constant/g define the gravity vector as g (0 0 -9.81).  
In the 0 directory set the initial fields: uniform temperature T 300 K and velocity U (0 0 0).  
Apply the following boundary conditions:  
- Bottom wall (z = 0): fixedValue temperature T 310 K and noSlip velocity.  
- Top wall (z = 0.1 m): fixedValue temperature T 300 K and noSlip velocity.  
- All four side walls: periodic (cyclic) for both temperature and velocity.  
Configure the PIMPLE algorithm in system/fvSolution with typical under‑relaxation factors (e.g., 0.7 for pressure, 0.7 for velocity) and a maximum of 2 outer correctors per time step.  
Set the time control in system/controlDict with deltaT 0.001 s, endTime 10 s, writeInterval 0.1 s, and adjust the Courant number to 0.5.  
Run the case transiently to capture the development of Rayleigh‑Bénard convection cells.
