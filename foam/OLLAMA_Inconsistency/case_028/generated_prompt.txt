Use the laminar, incompressible solver icoFoam.  
Generate the mesh with blockMesh for a rectangular channel that is 1 m long in the x‑direction, 0.1 m high in the y‑direction, and 0.01 m deep in the z‑direction.  
Create a single cell in the z‑direction to represent a 2‑D case; use 100 cells in the x‑direction and 10 cells in the y‑direction (blockMeshDict block (100 10 1) 1).  
Define the following boundary patches in blockMeshDict:  
inlet at x = 0, type fixedValue, uniform velocity (1 0 0) m s⁻¹.  
outlet at x = 1, type zeroGradient for velocity and fixedValue pressure 0 Pa.  
topWall at y = 0.1, type wall, no‑slip (0 0 0).  
bottomWall at y = 0, type wall, no‑slip (0 0 0).  
frontAndBack at z = 0 and z = 0.01, type wall, no‑slip (0 0 0).  
Set the initial fields U and p to uniform values matching the inlet (U = (1 0 0), p = 0).  
Specify fluid properties in transportProperties as water: rho = 1000 kg m⁻³, nu = 1e‑6 m² s⁻¹.  
In controlDict set startTime = 0, endTime = 5, deltaT = 0.001, writeInterval = 0.5, and use default solver tolerances for laminar flow.  
Run icoFoam until the solution reaches a steady state (residuals below 1e‑6).  
Post‑process by sampling the velocity profile at several x‑locations across the channel height and visualising the results with paraFoam or a similar tool.
