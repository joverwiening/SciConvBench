Set up a 2D lid‑driven cavity case in a 1 m × 1 m square domain extruded one cell in the z‑direction, using `frontAndBack` as `empty`.  
Create a uniform mesh of 40 × 40 × 1 cells.  
Use the incompressible Newtonian fluid with kinematic viscosity `nu = 0.01 m^2/s`.  
Select the solver `icoFoam` by setting `application icoFoam;` in `system/controlDict`.  

Boundary conditions:  
- Top wall (`movingLid`): `U` fixedValue uniform (1 0 0).  
- Left, right, and bottom walls (`fixedWalls`): `U` noSlip.  
- All walls: pressure `p` zeroGradient; set a pressure reference using `pRefCell 0;` and `pRefValue 0;` in `system/fvSolution`.  
- Front and back patches: `empty`.  

Initial conditions:  
- Velocity field `U` uniform (0 0 0) at time 0.  
- Pressure field `p` uniform 0 at time 0.  

Time‑stepping parameters in `system/controlDict`:  
- `startTime 0;`  
- `deltaT 0.001;`   // chosen to keep Courant number ≤ 0.5 for lid velocity = 1 m s⁻¹  
- `endTime 10;`      // maximum simulated physical time  
- `writeInterval 0.1;`  

Convergence criteria:  
- In `system/fvSolution`, set the momentum and pressure residual tolerances to `1e-6`.  
- Stop the simulation when both residuals fall below this tolerance **or** when `endTime` (10 s) is reached.  

Run the case transiently until the flow field no longer changes appreciably, indicating a steady‑state solution.
