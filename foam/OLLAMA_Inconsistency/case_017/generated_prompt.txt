Run a 2D inviscid laminar oblique‑shock simulation using the rhoCentralFoam solver on a rectangular channel extruded one cell in the z‑direction.  
The computational domain extends from (0, 0, 0) to (4.1, 1, 0.1) and is discretised with 60 cells in the x‑direction, 30 cells in the y‑direction and 1 cell in the z‑direction.  
Set the front and back patches to type empty.  
Define the following patches: inlet at the left face, outlet at the right face, top wall at the upper y‑face, bottom symmetryPlane at the lower y‑face.  
Use an ideal‑gas thermodynamic model with Cp = 2.5, Pr = 1, molecular weight = 11640.3, heat of formation Hf = 0, and zero viscosity (inviscid).  
Use laminar momentum transport (no turbulence model).  
Initialise the fields uniformly with U = (2.9 0 0), p = 1, T = 1.  
Inlet boundary conditions: fixedValue U = (2.9 0 0), fixedValue p = 1, fixedValue T = 1.  
Outlet boundary conditions: zeroGradient for U, p and T.  
Top wall boundary conditions: fixedValue U = (0 0 0) (noSlip), zeroGradient for p, zeroGradient for T.  
Bottom symmetryPlane boundary conditions: symmetryPlane for U, zeroGradient for p, zeroGradient for T.  
Time control: deltaT = 0.0025, endTime = 10, writeInterval = 1.
