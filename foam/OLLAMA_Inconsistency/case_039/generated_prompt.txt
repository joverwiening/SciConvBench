Create a rectangular tank 2 m long (x‑direction) and 1 m high (y‑direction) with a single cell extrusion in the spanwise (z) direction and set the frontAndBack patches to empty.  
Define the mesh in system/blockMeshDict with vertices at (0 0 0), (2 0 0), (2 1 0), (0 1 0), (0 0 1), (2 0 1), (2 1 1), (0 1 1), a single hex block (200 100 1) cells, and simple grading of (1 1 1).  
Specify the boundary patches: walls (type wall) on the left, right, bottom, and side walls; top (type patch) as the open top; frontAndBack (type empty) for the extruded direction.  
Set gravity in constant/g to dimensions [0 1 -2 0 0 0 0] and value (0 -9.81 0).  
In system/controlDict set the application to interFoam.  
Create 0/U with internalField uniform (0 0 0); walls noSlip; top pressureInletOutletVelocity with phi phi and value uniform (0 0 0); frontAndBack empty.  
Create 0/p_rgh with internalField uniform 0; walls zeroGradient; top totalPressure with p0 uniform 0; frontAndBack empty.  
Create 0/alpha.water with internalField uniform 0; walls zeroGradient; top inletOutlet with inletValue uniform 0 and value uniform 0; frontAndBack empty.  
Define system/setFieldsDict to set alpha.water to 1 inside the box from (0 0 -0.5) to (0.5 0.5 0.5) and to 0 elsewhere.  
Run the workflow: execute blockMesh, then setFields, then interFoam to start the VOF dam‑break simulation.
