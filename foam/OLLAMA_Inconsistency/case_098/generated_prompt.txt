Set up a 2‑D axisymmetric simulation of swirling flow in a circular pipe using the simpleFoam solver.  
Assume the pipe inner radius is 0.05 m and the pipe length is 1.0 m (20 × diameter) to allow flow development.  
Create a 5‑degree wedge mesh with blockMeshDict: use one cell in the angular direction, 20 cells radially from the centre to the wall, and 100 cells along the pipe length.  
Define the following boundary patches in constant/polyMesh/boundary:  
inlet – type patch;  
outlet – type patch;  
wall – type wall;  
front – type symmetryPlane;  
back – type symmetryPlane.  
Apply velocity boundary conditions (U) as follows:  
- inlet: fixedValue with a swirling profile, e.g. U = (Uaxial(r), 0, Utheta(r)) where Uaxial(r) = Umax·(1‑(r/R)²) and Utheta(r) = ω·r (solid‑body rotation).  
- wall: fixedValue (0 0 0) (noSlip).  
- outlet: zeroGradient.  
- front and back: symmetryPlane (zeroGradient for all fields).  
Set pressure boundary conditions (p) as:  
- inlet: zeroGradient.  
- outlet: fixedValue 0.  
- wall, front, back: zeroGradient.  
Use standard simpleFoam turbulence settings (k‑epsilon model) with default transportProperties for a Newtonian fluid (density 1 kg/m³, viscosity 1e‑5 m²/s).  
Configure the fvSolution and fvSchemes files with standard SIMPLE settings and appropriate under‑relaxation factors for steady‑state convergence.  
Run blockMesh to generate the mesh, then simpleFoam to solve the steady swirling flow.  
Post‑process results (velocity magnitude, swirl intensity, pressure drop) using paraFoam or other visualization tools.
