Simulate a steady, incompressible, laminar flow of water through a two‑dimensional channel that contains a rigid, stationary obstacle.  
Create a two‑dimensional mesh and extrude it by one cell in the spanwise direction, setting the `frontAndBack` patches to `empty`.  
Set the kinematic viscosity of water to `nu = 1e-6 m^2/s`.  
Use the `simpleFoam` solver for the simulation.  
In `system/controlDict`, set `application     simpleFoam;`.  
Configure the SIMPLE algorithm to stop when all residuals fall below `1e-6` or after a maximum of `1000` SIMPLE cycles.  
Apply the following boundary conditions:  
- For velocity field `0/U`: inlet patch `fixedValue uniform (0.1 0 0)`, outlet patch `zeroGradient`, wall and obstacle patches `noSlip`, `frontAndBack` patch `empty`.  
- For pressure field `0/p`: inlet patch `zeroGradient`, outlet patch `fixedValue uniform 0`, wall and obstacle patches `zeroGradient`, `frontAndBack` patch `empty`.  
Run the simulation until convergence criteria are met, then post‑process velocity and pressure fields as needed.
