Set up a 2D sealed cavity with a height of 1 m and a width of 0.2 m (aspect ratio 5:1).  
Use air as the working fluid with standard properties at 300 K (density ≈1.177 kg/m³, kinematic viscosity ≈1.5 × 10⁻⁵ m²/s, thermal diffusivity ≈2.2 × 10⁻⁵ m²/s).  
Apply gravity in the negative y‑direction with magnitude 9.81 m/s².  
Use the buoyantBoussinesqSimpleFoam solver.  
Create a structured mesh with 100 cells in the vertical (y) direction and 20 cells in the horizontal (x) direction, giving a uniform cell size of 0.01 m × 0.01 m.  
Set temperature boundary conditions:  
- leftWall: type fixedValue, value uniform 350 K.  
- rightWall: type fixedValue, value uniform 300 K.  
- topWall: type zeroGradient (adiabatic).  
- bottomWall: type zeroGradient (adiabatic).  
Set velocity boundary conditions: all walls use type zeroGradient (no‑slip for the Boussinesq approximation).  
Set pressure boundary condition: type zeroGradient on all walls (sealed cavity).  
Initialize the field with a uniform temperature of 325 K and zero velocity.  
Run the simulation until the residuals drop below 1e‑5 for continuity, momentum, and energy, or until a steady‑state solution is reached.  
Post‑process temperature and velocity fields to visualize natural convection rolls within the cavity.
