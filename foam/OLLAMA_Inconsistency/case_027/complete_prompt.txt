Simulate turbulent airflow over a backward-facing step using `simpleFoam` with the `kOmegaSST` RANS model. Set the inlet freestream velocity to 20 m/s and assume the inflow is fully turbulent with turbulence intensity 5% and turbulent mixing length 0.005 m. Use standard wall functions on walls and `zeroGradient` at the outlet for turbulence variables.

In `0/k`, set the inlet boundary condition to:
```foam
inlet
{
    type            fixedValue;
    value           uniform 1.5;   // k = 1.5*(U*I)^2 with U=20, I=0.05
}
```

In `0/omega`, set the inlet boundary condition to:
```foam
inlet
{
    type            fixedValue;
    value           uniform 447.2; // omega ≈ sqrt(k)/(Cmu^0.25*L) with Cmu=0.09, L=0.005
}
```
