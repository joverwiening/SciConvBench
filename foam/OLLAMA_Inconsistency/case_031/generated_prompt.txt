Set up a 2D incompressible laminar flow case for icoFoam in a rectangular channel that is 0.5 m long in the x‑direction and 0.1 m high in the y‑direction, with a single cell thickness in the z‑direction.  
Create the mesh with blockMesh using 100 cells along x, 20 cells along y, and 1 cell along z, giving a uniform cell size of 0.005 m in x and 0.005 m in y.  
In blockMeshDict define the vertices for the rectangular block, and create the following patches: inlet (type patch), outlet (type patch), topWall (type wall), bottomWall (type wall), and frontAndBack (type wall).  
Set the frontAndBack patches to type wall in the blockMeshDict.  
In the 0/U file assign a parabolic inlet velocity profile Ux = 4 Umax (y (0.1 – y))/0.1² with Umax = 1 m s⁻¹, zeroGradient for the outlet, and noSlip (fixedValue (0 0 0)) for topWall, bottomWall, and both frontAndBack patches.  
In the 0/p file set fixedValue 0 at the outlet and zeroGradient on inlet, topWall, bottomWall, and frontAndBack.  
In constant/transportProperties set the kinematic viscosity ν = 1e‑6 m² s⁻¹ (typical value for water at 20 °C) and density ρ = 1 kg m⁻³.  
Use laminarTransport model in transportProperties.  
In system/controlDict set application icoFoam, startTime 0, endTime 5, deltaT 0.001, writeInterval 0.5, and appropriate solver settings.  
Use default fvSchemes for laminar incompressible flow (e.g., Gauss linear for divergence, Gauss linear for gradient, Gauss upwind for convection).  
Use default fvSolution with SIMPLE algorithm, tolerance 1e‑6 for velocity and pressure, and appropriate relaxation factors (e.g., 0.7 for U, 0.3 for p).  
Run blockMesh to generate the mesh, then execute icoFoam to obtain the Poiseuille flow solution.  
Post‑process the velocity field to verify the parabolic profile and pressure drop consistent with the analytical solution for laminar flow in a rectangular channel.
