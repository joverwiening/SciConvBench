Use the interFoam solver for a two‑dimensional dam break simulation.  
Create a rectangular domain 1 m long (x‑direction) and 1 m high (y‑direction) with a 2‑D mesh.  
Set the constant/g file to `g (0 0 -9.81);`.  
Define the initial phase field with `setFieldsDict` so that `alpha.water = 1` in the region `0 < x < 0.2` and `0 < y < 0.5`, and `alpha.water = 0` elsewhere (air).  
Apply a `pressureInletOutletVelocity` boundary condition on the top boundary for velocity and a zero‑gradient condition for pressure, representing an open atmosphere.  
Apply `noSlip` wall boundary conditions on the left, right, and bottom boundaries for velocity and appropriate zero‑gradient or fixedValue conditions for pressure and phase fields.  
Configure `controlDict` with `startTime 0`, `endTime 2` (seconds), an initial `deltaT 0.001`, `adjustableTimeStep true`, `maxCo 0.5`, and `writeInterval 0.02`.  
Run the simulation to model the collapse of the water column under gravity.
