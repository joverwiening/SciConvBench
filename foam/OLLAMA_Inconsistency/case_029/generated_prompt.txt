Use the pimpleFoam solver for the transient simulation.  
Set the cylinder diameter D to 1 m.  
Set the inlet velocity magnitude U∞ to 0.15 m s⁻¹, which together with a kinematic viscosity ν of 1 × 10⁻³ m² s⁻¹ yields a Reynolds number Re = U∞ D/ν = 150.  
Define the computational domain as a rectangular box that extends 10 D (10 m) upstream of the cylinder centre, 20 D (20 m) downstream, and 5 D (5 m) above and below the cylinder centre, giving a total height of 10 D (10 m).  
Place the cylinder at the centre of the domain at (x = 10 D, y = 0).  
Generate a mesh with a fine region around the cylinder: cell size near the cylinder surface of approximately 0.02 D (0.02 m) and gradual coarsening to a maximum cell size of about 0.5 D (0.5 m) in the far field.  
Use laminar flow (no turbulence model) and specify the transportProperties file with ν = 1e-3.  
Set the initial fields to a uniform flow: U = (0.15 0 0) m s⁻¹ and p = 0 Pa throughout the domain.  
Apply boundary conditions:  
- inlet (patch “inlet”): fixedValue U = (0.15 0 0), zeroGradient p;  
- outlet (patch “outlet”): zeroGradient U, fixedValue p = 0;  
- cylinder wall (patch “cylinder”): noSlip (U = (0 0 0)), zeroGradient p;  
- top and bottom (patches “top” and “bottom”): slip (zeroGradient U), zeroGradient p.  
In system/controlDict, use the provided settings but change the application entry to pimpleFoam:  
application     pimpleFoam;  
startFrom       startTime;  
startTime       0;  
stopAt          endTime;  
endTime         200;  
deltaT          0.005;  
adjustTimeStep  yes;  
maxCo           0.9;  
writeControl    runTime;  
writeInterval   1;  
Configure system/fvSchemes and system/fvSolution for a transient PIMPLE algorithm with appropriate under‑relaxation factors (e.g., nOuterCorrectors = 2, nCorrectors = 2, nNonOrthogonalCorrectors = 0).  
Run the simulation for 200 s of physical time, writing results every 1 s to resolve the vortex shedding.  
Post‑process the velocity and pressure fields to visualize the von Kármán vortex street and compute the Strouhal number from the lift coefficient time series.
