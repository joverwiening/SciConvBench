Create a 2‑D converging–diverging nozzle mesh with the following dimensions: inlet height 0.020 m, throat height 0.010 m, outlet height 0.020 m, and overall length 0.100 m. Generate a structured rectangular mesh that refines the throat region (minimum cell size 0.0005 m) and uses `empty` boundary type for the front and back faces to enforce 2‑D behavior. Define four boundary patches: `inlet`, `outlet`, `nozzleWall`, and `frontAndBack`.

In `constant/thermophysicalProperties` set:
- `equationOfState` to `perfectGas`.
- `transportModel` to `sutherland`.
- Reference temperature 300 K, reference viscosity 1.78e‑5 Pa·s, Sutherland constant 110 K.

Apply the following boundary conditions:
- `inlet`: total (stagnation) pressure 200 kPa and total temperature 300 K using `totalPressure` and `totalTemperature` (or equivalently fixed supersonic values for `U`, `p`, `T` if preferred).
- `outlet`: static pressure 101325 Pa; allow supersonic outflow by using a zeroGradient condition for velocity and temperature.
- `nozzleWall`: adiabatic no‑slip wall (`U` = (0 0 0), `p` = zeroGradient, `T` = zeroGradient) or slip wall (`U` = slip) if inviscid behavior is desired.
- `frontAndBack`: `empty` type for all fields.

In `system/controlDict` set:
```
application     nonNewtonianIcoFoam;
```
Configure time stepping, solver tolerances, and output controls appropriate for compressible flow (e.g., Courant number ≤ 0.5, residual tolerance 1e‑6 for pressure and velocity).

Run the simulation, monitor convergence of pressure, velocity, and temperature fields, and post‑process the results to obtain Mach number distribution, pressure ratio, and temperature variation along the nozzle centreline.
