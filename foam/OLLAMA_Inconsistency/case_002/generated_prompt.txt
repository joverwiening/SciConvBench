Run a buoyantFoam simulation of two‑dimensional Rayleigh‑Bénard convection in a rectangular cavity that is 9 units wide (x), 1 unit tall (y) and 1 unit thick (z).  
Create the mesh with blockMesh using the origin at (0 0 0) and the opposite corner at (9 1 1), with 90 cells in the x‑direction, 10 cells in the y‑direction and 1 cell in the z‑direction.  
Define six boundary patches with the standard names: front, back, left, right, top, bottom.  
Set the front and back patches to type empty.  
Set the left and right patches to type wall with a zeroGradient condition for temperature (adiabatic) and noSlip for velocity.  
Set the bottom patch to type wall with fixedValue temperature 305 K and noSlip for velocity.  
Set the top patch to type wall with fixedValue temperature 295 K and noSlip for velocity.  

Use the heRhoThermo thermophysical model with equationOfState Boussinesq; set molWeight 29, rho0 1.0 kg m⁻³, T0 300 K, beta 3.3e‑3 K⁻¹, Cv 714.3 J kg⁻¹ K⁻¹, Hf 0, mu 1.5e‑5 m² s⁻¹, and Pr 0.714.  

Apply a gravity vector (0 -9.81 0) m s⁻² (negative y‑direction).  

Enable the RAS k‑epsilon turbulence model: set constant/momentumTransport simulationType to RAS, model to kEpsilon, turbulence on, and printCoeffs on.  

Initial fields:  
- U uniform (0 0 0) m s⁻¹ with noSlip on all solid walls and empty on front/back.  
- T uniform 300 K with bottom fixedValue 305 K, top fixedValue 295 K, left and right zeroGradient, and empty on front/back.  
- k uniform 1e‑5 m² s⁻² with kqRWallFunction on walls and empty on front/back.  
- epsilon uniform 1e‑5 m² s⁻³ with epsilonWallFunction on walls and empty on front/back.  
- nut uniform 0 with nutkWallFunction on walls and empty on front/back.  
- alphat uniform 0 with compressible::alphatJayatillekeWallFunction on walls, Prt 0.85, and empty on front/back.  
- p uniform 0 Pa with calculated wall condition and empty on front/back.  
- p_rgh uniform 0 Pa with fixedFluxPressure on walls and empty on front/back.  

Set the simulation time step deltaT to 1 s, do not enable adjustTimeStep, maxCo, or maxDeltaT.  
Run the simulation for a total physical time of 1000 s and write results every 50 time steps.  

In system/fvSolution, set the solvers for p_rgh and the coupled (U, e, k, epsilon) fields to tolerance 1e‑8 and relative tolerance 0.01, and set the corresponding *Final solvers to relative tolerance 0.  

Use the buoyantFoam solver with the above settings to perform the simulation.
