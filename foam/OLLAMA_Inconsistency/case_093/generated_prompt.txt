Set up a 2‑D dam break simulation using the pimpleFoam solver.  
Create a rectangular domain with length 2 m, height 1 m, and a unit width of 0.01 m.  
Apply a uniform gravity vector g = (0 -9.81 0) m s⁻².  
In the controlDict, set endTime to 5 s.  
Use setFields to initialise a water region (alpha.water = 1) that occupies the left side of the domain from x = 0 m to x = 0.5 m and from y = 0 m to y = 0.5 m; set alpha.water = 0 (air) elsewhere.  
Define transportProperties with two phases:  
- water: density ρ = 1000 kg m⁻³, dynamic viscosity μ = 1 × 10⁻³ Pa·s.  
- air: density ρ = 1.2 kg m⁻³, dynamic viscosity μ = 1.8 × 10⁻⁵ Pa·s.  
Ensure the mesh resolves the domain adequately for a 2‑D simulation with the specified width.  
Run the simulation and observe the collapse of the water column under gravity.
