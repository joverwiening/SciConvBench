Simulate steady‑state, incompressible, turbulent flow and heat transfer in a 2‑D heated pipe using the simpleFoam solver.  
The pipe has a length of 2 m and an internal diameter of 0.1 m; the geometry is 2‑D, so the front and back patches are of type “empty”.  

Create a structured mesh with approximately 200 cells in the axial (x) direction and 45 cells across the pipe diameter (radial direction), giving a cell size of about 0.01 m axially and 0.0022 m radially. Refine the mesh near the wall if needed to keep y⁺ in an acceptable range for the k‑ε model.  

Use air at standard conditions (≈ 1.177 kg m⁻³ density, ≈ 1.85 × 10⁻⁵ Pa·s dynamic viscosity, ideal‑gas properties).  

Apply the standard k‑ε turbulence model with wall functions.  

Set the following boundary conditions for all fields:

- **Inlet patch**  
  - Velocity U: fixedValue uniform (1 0 0) m s⁻¹  
  - Temperature T: fixedValue uniform 300 K  
  - Turbulent kinetic energy k: fixedValue uniform 3.8e‑03 m² s⁻²  
  - Turbulent dissipation rate ε: fixedValue uniform 5e‑03 m² s⁻³  
  - Pressure p: zeroGradient  

- **Outlet patch**  
  - Velocity U: zeroGradient  
  - Temperature T: zeroGradient  
  - k: zeroGradient  
  - ε: zeroGradient  
  - Pressure p: fixedValue uniform 0 Pa (gauge)  

- **Wall patch**  
  - Velocity U: noSlip (fixedValue uniform (0 0 0))  
  - Temperature T: zeroGradient (adiabatic)  
  - k: kWallFunction  
  - ε: epsilonWallFunction  

- **FrontAndBack patches** (empty)  
  - All fields: type empty  

Configure the case controlDict for a steady‑state run: startTime 0, endTime 1000 (or a sufficiently large number), deltaT 1 (pseudo‑time step), writeInterval 100, and set residual tolerances to 1e‑5 for U, p, k, ε, and T. Use typical SIMPLE under‑relaxation factors (e.g., 0.7 for U, 0.3 for p, 0.3 for k, 0.7 for ε, 0.7 for T).  

Use standard second‑order discretisation schemes in fvSchemes and default solver settings in fvSolution appropriate for simpleFoam.  

Run simpleFoam until the residuals meet the specified tolerances, then post‑process velocity, temperature, and turbulence fields as needed.
