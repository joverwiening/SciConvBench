Set up a 2D steady incompressible laminar flow simulation over a NACA 0012 airfoil using the simpleFoam solver.  
Create a 3‑D mesh by extruding the 2‑D airfoil geometry one cell in the z‑direction; assign the out‑of‑plane faces to a patch named `frontAndBack`.  
In `constant/polyMesh/boundary`, define the `frontAndBack` patch as a wall:  
```
frontAndBack
{
    type            wall;
    // other wall parameters as needed
}
```  
In the velocity initial and boundary condition file `0/U`, set the `frontAndBack` patch to slip:  
```
frontAndBack
{
    type            slip;
}
```  
Define the computational domain to extend at least 10 chord lengths upstream, 20 chord lengths downstream, and 10 chord lengths above and below the airfoil.  
Use the following patch names and boundary conditions:  
- `inlet`: fixedValue for velocity (U = (Uinf 0 0) with Uinf = 1 m s⁻¹) and zeroGradient for pressure.  
- `outlet`: zeroGradient for velocity and fixedValue for pressure (p = 0).  
- `top` and `bottom`: slip (zero normal velocity, zeroGradient for pressure).  
- `frontAndBack`: wall in the mesh definition and slip in the velocity field as specified above.  

Set the free‑stream velocity in `0/U` for the `inlet` patch to 1 m s⁻¹, giving a Reynolds number based on a 1 m chord of approximately 6.7 × 10⁴, which is within the laminar regime for best‑practice low‑speed airfoil studies.  

In `constant/transportProperties`, set the kinematic viscosity ν to 1.5 × 10⁻⁵ m² s⁻¹ (air at standard conditions).  

In `constant/turbulenceProperties`, select laminar flow:  
```
simulationType laminar;
```  

Configure `system/fvSchemes` and `system/fvSolution` with standard simpleFoam settings for laminar flow (e.g., Gauss linear for divergence, smoothSolver for pressure, GAMG for velocity).  

Run `simpleFoam` until residuals drop below 1e‑6 for velocity and pressure, then post‑process velocity, pressure, and wall shear stress on the airfoil surface.
