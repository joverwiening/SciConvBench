Create a 2‑D structured mesh using blockMesh with the provided blockMeshDict, which defines two hexahedral blocks (40 × 40 × 1 cells upstream and 80 × 40 × 1 cells downstream) and the vertices that form a 15‑degree wedge obstacle from x = 0 to x = 0.3048 m, reaching y = 0.081670913853 m at the outlet. Use convertToMeters = 1 and set the default patch type to empty for the spanwise direction.

Set the solver to rhoCentralFoam and select the Kurganov flux scheme in the fvSchemes file.

Define the following fvSchemes:
- timeSchemes: default Euler;
- gradSchemes: default Gauss linear;
- divSchemes: use Kurganov for the convective terms (e.g., “div(rho*phi,U) Kurganov”);
- interpolationSchemes: vanLeer for density, velocity, and temperature (e.g., “interpolationScheme rho vanLeer”, “interpolationScheme U vanLeer”, “interpolationScheme T vanLeer”).

Define the following fvSolution entries:
- solver for rho, U, and T set to smoothSolver or appropriate rhoCentralFoam solvers;
- tolerance and relTol values appropriate for compressible inviscid flow (e.g., 1e‑6);
- relaxation factors set to 1 (no under‑relaxation).

Create thermophysicalProperties for a perfect gas with:
- molecularWeight 11640.3;
- Cp 2.5;
- Pr 1;
- equationOfState perfectGas.

Create transportProperties to enable Sutherland viscosity:
- muRef 1.7894e‑5;
- TRef 300;
- Sutherland constant set automatically by the Sutherland model.

Set initial fields (U, p, T) to uniform values equal to the inlet conditions: U = (5 0 0) m/s, p = 1 Pa, T = 1 K.

Specify boundary conditions in the 0 folder:
- inlet: type fixedValue for U (5 0 0), p (1 Pa), and T (1 K);
- outlet: type zeroGradient for U, p, and T;
- bottom and top: type symmetryPlane for all variables;
- obstacle: type slip for U, zeroGradient for p and T;
- defaultFaces (spanwise direction): type empty (already defined in defaultPatch).

Configure controlDict to run from startTime = 0 to endTime = 0.2 s with deltaT = 0.0001 s, writeControl set to timeStep, writeInterval = 200 (which corresponds to output every 0.02 s), and adjust writeFormat, writePrecision, and purgeWrite as needed.

Run blockMesh to generate the mesh, then execute rhoCentralFoam to perform the compressible inviscid supersonic flow simulation over the wedge obstacle with the specified settings.
