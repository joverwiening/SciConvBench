Use the compressible solver rhoPimpleFoam for the simulation.  
Set the computational domain to extend 0.5 m upstream of the inlet, 1.0 m downstream of the wedge tip, and 0.2 m vertically from the wedge surface to the top slip wall.  
Place the wedge base at x = 0 m, the wedge tip at x = 0.1 m, and give the wedge a 10‑degree angle.  
Generate a 2‑D mesh with 200 cells in the x‑direction and 50 cells in the y‑direction, then extrude one cell in the z‑direction and assign the frontAndBack patches the empty type.  
Apply the following boundary conditions:  
- inlet: fixedValue for velocity U = (686 0 0) m/s, temperature T = 293 K, and pressure p = 101325 Pa;  
- outlet: waveTransmissive for pressure and temperature, zeroGradient for velocity;  
- wedge surface and top boundary: slipWall;  
- frontAndBack: empty.  
In constant/thermophysicalProperties configure a perfect‑gas model using hePsiThermo, equationOfState perfectGas, and transport model sutherland.  
In system/controlDict set application rhoPimpleFoam and choose appropriate time‑stepping, writeInterval, and endTime values for a steady‑state run.  
Initialize all fields (U, p, T, rho, etc.) to the freestream values specified for the inlet.  
Employ a compressible turbulence model, specifically the SST k‑omega model, to capture shock‑induced turbulence effects.  
Use standard rhoPimpleFoam relaxation factors and solver settings suitable for supersonic, compressible flow with an oblique shock.
