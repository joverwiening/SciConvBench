Run a transient compressible simulation using the rhoCentralFoam solver on a rectangular channel extruded one cell in the z‑direction.  
Create a mesh that spans from (0, 0, 0) to (4.1, 1, 0.1) with 60 cells in the x‑direction, 30 cells in the y‑direction, and 1 cell in the z‑direction.  
Define the following boundary patches: inlet (left), outlet (right), top (wall), bottom (symmetryPlane), and leave the frontAndBack patches empty.  
Set the thermophysical model to an ideal gas with molecular weight 11640.3, specific heat at constant pressure Cp = 2.5, Prandtl number Pr = 1, dynamic viscosity = 0, and heat of formation Hf = 0.  
Initialize the fields in the entire domain: velocity U = (2.9 0 0), pressure p = 1, temperature T = 1.  
Apply inlet boundary conditions: fixedValue for U = (2.9 0 0), fixedValue for p = 1, fixedValue for T = 1.  
Apply outlet boundary conditions: zeroGradient for U, zeroGradient for p, zeroGradient for T.  
Apply top wall boundary conditions: fixedValue for velocity U = (2.61933 -0.50632 0), fixedValue for temperature T = 1.25853, zeroGradient for pressure.  
Apply bottom boundary conditions: symmetryPlane for velocity, zeroGradient for pressure, zeroGradient for temperature.  
Set the simulation control parameters: time step deltaT = 0.0025, end time = 10, write interval = 1.  
Use a laminar momentum transport model (no turbulence model).  
Run the case until the end time, writing results at each write interval.
