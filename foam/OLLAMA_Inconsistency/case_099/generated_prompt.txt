Simulate a 2‑D laminar, transient flow past a square cylinder using the icoFoam solver.

- topAndBottomWalls: noSlip

- outlet: fixedValue uniform 0

- cylinder: zeroGradient

In constant/polyMesh/boundary, define the frontAndBack patches as type wall.
