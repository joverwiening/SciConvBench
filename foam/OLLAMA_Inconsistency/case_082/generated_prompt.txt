Configure a horizontal gravity separator simulation using the VOF method with the solver `interFoam`.  
Set the gravity vector in `constant/g` to (0 -9.81 0).  

In `system/controlDict` specify:
- `application` = interFoam  
- appropriate time step controls, startTime, endTime, writeInterval, and solver tolerances for the pressure and velocity fields.  

In `constant/transportProperties` define the three phases with the following densities (kg m‑3) and dynamic viscosities (Pa·s):
- oil: rho = 850; mu = 0.05  
- water: rho = 998; mu = 0.001  
- gas (air): rho = 1.225; mu = 1.8e‑5  

Create a `constant/phasesProperties` (or equivalent) file that lists the phase names `oil`, `water`, and `gas` and assigns each a unique `alpha` field (`alpha.oil`, `alpha.water`, `alpha.gas`).  

In `system/setFieldsDict` initialise a stratified mixture:
- Define three horizontal layers in the domain: the top layer filled with gas (`alpha.gas` = 1), the middle layer with oil (`alpha.oil` = 1), and the bottom layer with water (`alpha.water` = 1).  
- Use `setFields` to assign the appropriate volume fractions to each region, ensuring that the sum of the three `alpha` fields equals 1 everywhere.  

In `0/alpha.water`, `0/alpha.oil`, and `0/alpha.gas` set the initial volume‑fraction fields to match the stratified configuration defined in `setFieldsDict`.  

In `0/U` set the initial velocity field to zero (U = (0 0 0)).  

In `0/p` set the initial pressure field to hydrostatic pressure based on the defined gravity and fluid densities, or use a uniform initial pressure if hydrostatic initialization is not required.  

Configure the VOF scheme in `system/fvSchemes`:
- Use a compressive interface‑capturing scheme for the `alpha` fields, such as `MULES` with a high compression factor.  
- Choose appropriate discretisation for divergence, gradient, and Laplacian terms (e.g., `Gauss linear` for most fields, `Gauss upwind` for convective terms).  

Configure the linear solvers in `system/fvSolution`:
- Use a suitable pressure‑velocity coupling algorithm (e.g., `PIMPLE` or `PISO`).  
- Set solver tolerances for `p`, `U`, and the `alpha` fields consistent with VOF simulations (e.g., `1e-6` for pressure, `1e-5` for velocity, `1e-8` for volume fractions).  

Run `setFields` to apply the initial stratified mixture, then execute `interFoam` to simulate the separation.  
Monitor the evolution of `alpha.water`, `alpha.oil`, and `alpha.gas` to track the interfaces between the three immiscible fluids over time.
