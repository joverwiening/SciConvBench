Use the interFoam solver to simulate the mixing of water and a Bingham plastic sludge in a two‑dimensional rectangular tank.  
Define the two phases in the case dictionary as “water” and “sludge”.  
Create a `transportProperties` file in the constant directory with the following content:

```
phases (water sludge);

water
{
    transportModel Newtonian;
    nu              1e-6;
    rho             1000;
}

sludge
{
    transportModel BinghamPlastic;
    rho             1500;
    yieldStress     15;      // τ₀ in Pa
    plasticViscosity 0.1;    // μ₀ in Pa·s
    nu              0.1;     // optional: kinematic viscosity for reference
}
sigma 0.07;
```

Set the surface tension coefficient `sigma` to 0.07 N/m as shown.  
Configure the remaining case files (`controlDict`, `fvSchemes`, `fvSolution`, `initialConditions`, etc.) with standard interFoam settings for a 2‑D tank, appropriate time step, simulation end time, and boundary conditions (no‑slip walls, pressure outlet at the top, etc.).  
Run the case with `interFoam` and post‑process the phase fraction field to visualize the mixing of water and sludge.
