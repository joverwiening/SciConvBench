Set up a transient, compressible, turbulent flow simulation of air over a heated 2‑D cylinder using rhoPimpleFoam with the k‑omega SST turbulence model.  
Define the fluid as a perfect gas in constant/thermophysicalProperties with the Boussinesq coefficients as shown.  

Geometry and domain  
- Cylinder diameter D = 0.10 m; cylinder axis is out of the 2‑D plane (unit depth).  
- Computational domain is a rectangular box extending 5 D upstream, 15 D downstream, and 10 D above and below the cylinder centre.  

Mesh  
- Use a structured C‑grid around the cylinder.  
- Minimum cell size in the near‑wall region ≈ 0.0025 D to achieve y⁺ ≈ 1 with wall functions.  
- Gradually coarsen the mesh away from the cylinder, keeping the total cell count around 200 000.  

Boundary conditions  
- inlet (patch “inlet”): fixedValue velocity (10 m s⁻¹ in the streamwise direction), fixedValue temperature (300 K), fixedValue pressure (101325 Pa), turbulence: fixedValue k = 1.5 (U I)² with turbulence intensity I = 0.05, fixedValue ω = √k/(C_μ^0.25 l) where l = 0.07 D.  
- outlet (patch “outlet”): zeroGradient for velocity, fixedValue pressure (0 Pa gauge), zeroGradient for temperature, zeroGradient for turbulence variables.  
- side walls (patch “symmetry”): slip (zeroGradient) for velocity, zeroGradient for pressure and temperature, zeroGradient for turbulence.  
- cylinder surface (patch “cylinder”): fixedValue temperature (500 K), noSlip (fixedValue velocity = (0 0 0)), turbulence wall functions (k = 0, ω = ω_wall).  

Thermophysical model (constant/thermophysicalProperties)  
```
thermoType
{
    type            hePsiThermo;
    mixture         perfectGas;
    transport       sutherland;
    thermo          janaf;
    equationOfState perfectGas;
    specie          specie;
    energy          sensibleEnthalpy;
}
mixture
{
    specie { molWeight 28.9; }
    thermodynamics { Cp 1005; Hf 0; }
    transport { As 1.458e-06; Ts 110.4; }
    BoussinesqCoeffs
    {
        TRef        300;
        beta        0.00333;
        rhoRef      1.225;
    }
}
```  

Solver settings (system/controlDict)  
- startTime 0; endTime 5 s (approximately two flow‑through times).  
- deltaT 1e‑4 s (CFL < 0.5).  
- writeInterval 0.01 s.  
- adjustTimeStep yes; maxCo 0.5.  

PIMPLE algorithm (system/pimpleProperties)  
- nOuterCorrectors 2  
- nCorrectors 2  
- nNonOrthogonalCorrectors 0  
- residualControl: U 1e‑5, p 1e‑5, T 1e‑5, k 1e‑5, omega 1e‑5  

Post‑processing  
- Compute drag coefficient Cd on the cylinder from the pressure and viscous forces.  
- Compute surface-averaged Nusselt number based on the temperature difference between the cylinder wall (500 K) and the freestream (300 K).  
- Export fields U, p, T, k, omega, and wall shear stress for visualization.
