Simulate a steady‑state, two‑phase (oil–water) flow in a horizontal pipe using the OpenFOAM solver `twoPhaseEulerFoam`.  
Impose at the inlet a fixed mixture velocity of 1 m s⁻¹ and a fixed water volume fraction `alpha.water = 0.3`.  
Apply a `noSlip` boundary condition on all pipe wall surfaces.  
In the `0/alpha.water` file, set the outlet boundary condition as:  

```
outlet
{
    type            fixedValue;
    value           uniform 0.3;
}
``` 

Use appropriate pressure and turbulence boundary conditions for a steady‑state simulation (e.g., `fixedValue` inlet pressure, `zeroGradient` outlet pressure, and standard `kEpsilon` or `kOmega` wall functions).  
Run the case until residuals converge to steady‑state criteria (e.g., 1e‑6 for all fields).
