Create a 2‑D rectangular pipe geometry of length 1.0 m and height 0.1 m using blockMesh with 100 cells in the x‑direction and 20 cells in the y‑direction. Define the following patches: inlet (type fixedValue, U = (0.1 0 0) m/s), outlet (type zeroGradient for U and fixedValue p = 0 Pa), walls (type noSlip), front (type empty), and back (type empty). Set the fluid properties in constant/transportProperties to a Bingham plastic: transportModel BinghamPlastic; rho 1000; tau0 10; mu0 0.1; muInf 0.01. Initialise the fields in 0/U and 0/p with U = (0 0 0) m/s and p = 0 Pa everywhere. Use the icoFoam solver for a transient laminar simulation. In system/controlDict set startTime 0, endTime 5, deltaT 0.001, writeInterval 0.1 (or another suitable interval). Use default fvSchemes and fvSolution appropriate for icoFoam. Run the simulation from t = 0 s to t = 5 s and post‑process the transient start‑up flow of the Bingham plastic fluid.
