Set up a 2D, incompressible, steady-state simulation of airflow over a symmetric airfoil using the simpleFoam solver.  
Create a C‑grid topology around the airfoil with a mesh that is one cell thick in the z‑direction.  
In `system/blockMeshDict`, define the front and back patches as walls with the entry:

```
frontAndBack
{
    type            wall;
    faces
    (
        (0 4 7 3)
        (1 2 6 5)
        // ... other faces for this patch
    );
}
```

Name the inlet patch `inlet`, the outlet patch `outlet`, and the airfoil surface patch `airfoil`.  

In the `0/U` file, set the following boundary conditions:  
- `inlet`: uniform velocity (10 0 0) m/s.  
- `outlet`: zeroGradient.  
- `airfoil`: noSlip.  
- `frontAndBack`: noSlip.  

In the `0/p` file, set the following boundary conditions:  
- `inlet`: zeroGradient.  
- `outlet`: fixedValue uniform 0.  
- `airfoil`: zeroGradient.  
- `frontAndBack`: zeroGradient.  

Use the k‑omega SST turbulence model for the simulation, with its standard default coefficients.  

Run the simulation with simpleFoam until convergence is achieved.
