Create a rectangular 2‑D domain 9 units wide (x) and 1 unit tall (y) with a single cell in the spanwise (z) direction; extrude the mesh so that the front and back patches are empty to enforce two‑dimensionality. Use 90 cells in the x direction, 10 cells in the y direction and 1 cell in the z direction.

Set the gravity vector to (0 -9.81 0) m s⁻².

Define the reference state in constant/physicalProperties using a heRhoThermo Boussinesq model with molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.

Set the transport properties in constant/transportProperties: nu 1.5e-5 m² s⁻¹ and alpha 2.1e-5 m² s⁻¹.

Configure turbulence in constant/RASProperties: simulationType RAS, RASModel kEpsilon, turbulence on, printCoeffs on.

Use the simpleFoam solver for a steady‑state simulation.

In system/controlDict set startTime 0, endTime 1000, deltaT 1, writeControl step, writeInterval 50, adjustTimeStep false, and do not define maxCo or maxDeltaT.

In system/fvSolution set solvers for p_rgh, U, k and epsilon to have tolerance 1e-8 and relTol 0.01; set the corresponding *Final solvers to relTol 0.

Use the fvSchemes provided by the user for divSchemes, gradSchemes, laplacianSchemes, interpolationSchemes, snGradSchemes and ddtSchemes.

Define the following boundary patches: bottom (patch name “bottom”), top (patch name “top”), side walls (patch name “walls”), front (patch name “front”), and back (patch name “back”).

Set the initial and boundary conditions as follows:

- 0/U: internalField uniform (0 0 0); type fixedValue (noSlip) on bottom, top and walls; type empty on front and back.
- 0/T: internalField uniform 300; bottom fixedValue 305, top fixedValue 295, walls zeroGradient, front and back empty.
- 0/p: internalField uniform 0; type calculated on bottom, top and walls, empty on front and back.
- 0/p_rgh: internalField uniform 0; type fixedFluxPressure on bottom, top and walls, empty on front and back.
- 0/k: internalField uniform 1e-5; type kqRWallFunction on bottom, top and walls, empty on front and back.
- 0/epsilon: internalField uniform 1e-5; type epsilonWallFunction on bottom, top and walls, empty on front and back.
- 0/nut: internalField uniform 0; type nutkWallFunction on bottom, top and walls, empty on front and back.
- 0/alphat: internalField uniform 0; type compressible::alphatJayatillekeWallFunction on bottom, top and walls with Prt 0.85, empty on front and back.

Initialize the flow at rest with a uniform temperature field of 300 K throughout the domain.

Run the simulation for 1000 s of physical time, writing results every 50 timesteps, using the k‑ε turbulence model and the specified boundary and material settings.
