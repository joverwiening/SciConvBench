Q: Which discretization schemes should be used in the system/fvSchemes file?
A: Make a reasonable assumption based on best practices. For a buoyantFoam simulation with k‑ε turbulence you can use the following typical fvSchemes settings:

```foam
// Interpolation schemes
divSchemes
{
    default         none;
    div(phi,U)      Gauss linearUpwind grad(U);
    div(phi,k)      Gauss linearUpwind grad(k);
    div(phi,epsilon) Gauss linearUpwind grad(epsilon);
    div(phi,T)      Gauss linearUpwind grad(T);
    div(phi,p)      Gauss linear;
    div(phi,R)      Gauss linear;
}

// Gradient schemes
gradSchemes
{
    default         Gauss linear;
}

// Laplacian schemes
laplacianSchemes
{
    default         Gauss linear corrected;
}

// Interpolation of face values
interpolationSchemes
{
    default         linear;
}

// Surface normal gradient schemes
snGradSchemes
{
    default         limited;
}

// Time derivative schemes (steady‑state not needed, but for completeness)
ddtSchemes
{
    default         steadyState;
}
```
