Create a rectangular 2‑D cavity with length 1 m in the x‑direction and height 1 m in the y‑direction; treat the third dimension as unit depth for a quasi‑2‑D simulation.  
Generate a uniform hexahedral mesh of 100 cells in the x‑direction and 100 cells in the y‑direction (total 10 000 cells).  
Set the fluid to use the `incompressiblePerfectGas` model with the thermophysicalProperties file exactly as provided, including the BoussinesqCoeffs block.  
Apply a gravity vector of (0 -9.81 0) m s⁻² acting downwards.  
Define the top wall (y = 1 m) as a moving wall with a fixed velocity of (0.1 0 0) m s⁻¹ and a fixed temperature of 350 K.  
Define the bottom wall (y = 0) as a stationary wall with a fixed temperature of 300 K.  
Define the left and right side walls (x = 0 and x = 1 m) as stationary no‑slip walls with zero‑gradient (adiabatic) temperature condition.  
Set the initial velocity field to zero everywhere and the initial temperature field to the reference temperature 325 K throughout the domain.  
Use `buoyantPimpleFoam` as the solver, with a time step of 0.001 s, a maximum Courant number of 0.5, and run the simulation for a physical time of 10 s or until the residuals for velocity, pressure, and temperature fall below 1e‑6.

In `system/fvSolution`, configure the PIMPLE algorithm with `nOuterCorrectors 2; nCorrectors 2; nNonOrthogonalCorrectors 0;` and set solver tolerances of 1e‑6 for pressure and velocity and 1e‑6 for temperature.  
Add a reference pressure point at the bottom‑left corner (0 0 0) to fix the pressure level.  
Enable the Boussinesq backup model by setting `buoyancyModel Boussinesq;` in `constant/thermophysicalProperties` (the provided `beta` value will be used if the density variation model fails).
