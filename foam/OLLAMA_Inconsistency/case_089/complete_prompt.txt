Simulate a mixed convection lid-driven cavity problem using `buoyantPimpleFoam`. The top lid moves at 0.1 m/s and is held at a hot temperature of 350 K. The bottom wall is cold at 300 K. Gravity acts downwards. Use the `incompressiblePerfectGas` model to account for density variations with temperature. The `constant/thermophysicalProperties` file should be configured as follows:

thermoType
{
    type            hePsiThermo;
    mixture         incompressiblePerfectGas;
    transport       const;
    thermo          hConst;
    equationOfState perfectGas;
    specie          specie;
    energy          sensibleEnthalpy;
}

mixture
{
    specie { molWeight 28.9; }
    thermodynamics { Cp 1005; Hf 0; }
    transport { mu 1.8e-5; Pr 0.7; }
}
