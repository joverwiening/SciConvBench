Use the rhoCentralFoam solver for the compressible supersonic simulation.  
Set the freestream conditions to pressure 101325 Pa, temperature 300 K, and velocity vector (686 0 0) m s⁻¹, corresponding to Mach 2 at sea‑level conditions.  
Define the wedge geometry with a length of 0.10 m and a wedge angle of 10°, giving a wedge height of 0.0176 m.  
Create a rectangular computational domain that extends 0.50 m upstream of the wedge leading edge (5 × wedge length), 1.00 m downstream of the wedge trailing edge (10 × wedge length), and 0.04 m in the vertical direction (at least twice the wedge height).  
Generate the mesh with a uniform cell size of 0.001 m (1 mm) in all directions, resulting in 1600 cells in the streamwise direction (500 upstream, 100 wedge region, 1000 downstream) and 40 cells in the vertical direction, with a single cell in the z‑direction extruded and the frontAndBack patches set to empty.  
Specify thermophysicalProperties using a perfect‑gas model: select hePsiThermo, equationOfState perfectGas, set gamma = 1.4 and gas constant R = 287 J kg⁻¹ K⁻¹.  
Apply the following boundary conditions:  
- inlet: fixedValue for velocity U, pressure p, and temperature T using the freestream values;  
- outlet: zeroGradient for U, p, and T (or waveTransmissive for p and T if preferred);  
- wedge surface and top boundary: slipWall (zero normal velocity, zeroGradient for pressure and temperature);  
- frontAndBack: empty.  
In the system/controlDict, set application to rhoCentralFoam, startTime to 0, endTime to 0.001 s, deltaT to 1e‑6 s (CFL ≈ 0.5 based on the 1 mm cell size and 686 m s⁻¹ flow speed), writeInterval to 0.0001 s, and use default numerical schemes appropriate for rhoCentralFoam.  
Initialize the fields (U, p, T) with the freestream values throughout the domain.  
Run the simulation until the solution reaches a steady oblique shock pattern over the wedge.
