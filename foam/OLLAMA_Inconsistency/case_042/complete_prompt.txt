Simulate a 2D supersonic flow of air at Mach 2 over a 10-degree wedge (oblique shock). Treat air as a perfect gas. Use a 2D mesh extruded one cell in z with `frontAndBack` set to `empty`.

Freestream/inlet example: `p = 101325 Pa`, `T = 300 K`, `U = (686 0 0) m/s`.

In `constant/thermophysicalProperties`, use a perfect-gas setup (e.g., `hePsiThermo` + `equationOfState perfectGas`).

Boundary conditions (typical for supersonic inflow/outflow):
- inlet: fixed values for `U`, `p`, and `T`
- outlet: `waveTransmissive` (or `zeroGradient`) for `p` and `T`, `zeroGradient` for `U`
- wedge + top boundary: slip wall
- frontAndBack: `empty`

In `system/controlDict`, set:
```foam
application     rhoCentralFoam;
```
