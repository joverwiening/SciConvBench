Set up a 2‑dimensional steady‑state laminar incompressible case using the simpleFoam solver for flow over a backward‑facing step.  
Define the geometry so that the inlet patch is on the left side, the outlet patch on the right side, the step wall and top wall are solid walls, and the front and back patches are of type empty to enforce 2‑D.  
In the file 0/U assign the following boundary conditions:  
- inlet: type zeroGradient;  
- outlet: type fixedValue with value uniform (0.5 0 0);  
- stepWall: type noSlip;  
- topWall: type noSlip;  
- frontAndBack: type empty.  
In the file 0/p assign the pressure boundary conditions:  
- inlet: type zeroGradient;  
- outlet: type fixedValue with value uniform 0.  
Create constant/transportProperties with density 1 kg m‑3 and kinematic viscosity nu 1e‑6 m² s‑1.  
Create constant/turbulenceProperties and set simulationType laminar.  
Use the default simpleFoam fvSchemes and fvSolution settings appropriate for a laminar, incompressible flow.  
Run simpleFoam until residuals converge to the desired tolerance.
