Create a rectangular block of size 1 m × 1 m in the x‑y plane and extrude it one cell in the z‑direction to a thickness of 0.01 m.  
Generate the mesh with blockMesh, using a reasonable cell count (e.g., 20 cells in x, 20 cells in y, and 1 cell in z).  
Define the two out‑of‑plane faces as the patch named **frontAndBack** and the four side edges as separate wall patches (e.g., **left**, **right**, **front**, **back**).  

In **constant/polyMesh/boundary** set:  
```
frontAndBack
{
    type            wall;
}
left
{
    type            wall;
}
right
{
    type            wall;
}
front
{
    type            wall;
}
back
{
    type            wall;
}
```  

In **0/T** set the temperature field:  
```
dimensions      [0 0 0 1 0 0 0];
internalField   uniform 300;
frontAndBack
{
    type            zeroGradient;
}
left
{
    type            zeroGradient;
}
right
{
    type            zeroGradient;
}
front
{
    type            zeroGradient;
}
back
{
    type            zeroGradient;
}
```  

In **constant/transportProperties** set the thermal diffusivity:  
```
DT              1e-5;
```  

Configure the transient run in **system/controlDict** (using laplacianFoam):  
```
application     laplacianFoam;
startTime       0;
endTime         10;
deltaT          0.1;
writeInterval   1;
```  

Use default numerical schemes in **system/fvSchemes** and default solver tolerances in **system/fvSolution**.  

Run laplacianFoam to simulate transient heat conduction on the plate with insulated side edges (zeroGradient) and insulated out‑of‑plane faces (zeroGradient), starting from a uniform temperature of 300 K.
