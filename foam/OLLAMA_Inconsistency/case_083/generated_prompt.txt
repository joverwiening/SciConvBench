Set up the case directory for the three‑phase settling tank using the `multiphaseEulerFoam` solver.  
In the `0/` folder, locate the three volume‑fraction field files: `alpha.sediment`, `alpha.water`, and `alpha.oil`.  
Edit each file so that the `internalField` entry reads: `internalField uniform 0.5;`.  
Leave all other entries in the files unchanged.  
These uniform volume‑fraction values will serve as the default field condition before the `setFields` utility is run with a `setFieldsDict` to create the desired stratified layers.
