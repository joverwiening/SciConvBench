Run a two‑phase Euler–Euler simulation of a gas–liquid bubble column using twoPhaseEulerFoam in a rectangular domain that spans x = 0 to 0.15 m, y = 0 to 1.00 m, and z = 0 to 0.10 m, with the height oriented in the +y direction and a thin dimension in z.  
Create a structured hexahedral mesh with 25 cells in the x direction, 75 cells in the y direction, and 1 cell in the z direction, using simpleGrading (1 1 1).  
Define the blockMeshDict patches as follows: the face at x = 0 is the inlet patch, the face at x = 0.15 m is the outlet patch, the faces at y = 0, y = 1 m, and the side walls are wall patches, and the two faces normal to the z direction are empty patches for 2‑D treatment.  
Use the heRhoThermo model for the continuous liquid phase (water) with a polynomial equation of state rPolynomial and coefficients C = (0.001278 -2.1055e‑06 3.9689e‑09 4.3772e‑13 -2.0225e‑16), molecular weight 18, specific heat capacity Cv = 4195 J kg‑1 K‑1, dynamic viscosity μ = 3.645e‑4 Pa·s, and Prandtl number Pr = 2.289.  
Use the heRhoThermo model for the dispersed gas phase (air) with a perfectGas equation of state, molecular weight 28.9, specific heat capacity Cp = 1007 J kg‑1 K‑1, dynamic viscosity μ = 1.84e‑05 Pa·s, and Prandtl number Pr = 0.7.  
Set gravity to (0 -9.81 0) m s‑2.  
Apply bubble size models: an isothermal diameter d0 = 3e‑3 m for air and a constant diameter d = 1e‑4 m for water.  
Configure momentum transport as laminar for both phases by setting simulationType = laminar in the respective momentumTransport files.  
In phaseProperties, list the phases as (air water) with water as the reference phase and set residualAlpha = 1e‑6 for both phases.  
Use a linear blending scheme with minFullyContinuousAlpha = 0.7 and minPartlyContinuousAlpha = 0.3 for the default blending and 0.5 for the drag blending.  
Set the surface tension between air and water to a constant sigma = 0.07 N m‑1.  
Select the Schiller‑Naumann drag model for the configurations air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water.  
Use a constant virtual‑mass coefficient Cvm = 0.5 for both directions.  
Employ the Ranz‑Marshall heat‑transfer model for both directions with residualAlpha = 1e‑4.  
Initialize the fields at t = 0 as follows: water velocity uniform (0 0 0), air velocity uniform (0 0.1 0), water volume fraction α_water = 1 and air volume fraction α_air = 0 inside the box region from (0 0 0) to (0.15 0.701 0.1); everywhere else use the default fields (α_air = 1, α_water = 0); pressure p_rgh uniform 1e5 Pa; air temperature uniform 300 K; water temperature uniform 350 K.  
Apply inlet boundary conditions: air velocity fixedValue (0 0.1 0), water velocity fixedValue (0 0 0), α_air fixedValue 0.5, α_water fixedValue 0.5, air temperature fixedValue 300 K, water temperature fixedValue 350 K.  
Apply wall boundary conditions: air velocity fixedValue (0 0 0), water velocity fixedValue (0 0 0), α_air zeroGradient, α_water zeroGradient, pressure p_rgh fixedFluxPressure, air temperature zeroGradient, water temperature zeroGradient.  
Set the outlet patch to use zeroGradient for velocities, zeroGradient for volume fractions, and fixedFluxPressure for p_rgh, with zeroGradient for temperatures.  
Configure the time controls: startTime = 0 s, endTime = 20 s, deltaT = 0.005 s, adjustTimeStep = no, maxCo = 0.5, maxDeltaT = 1 s, writeInterval = 1 s.
