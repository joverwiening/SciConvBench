Run a 2D gas–liquid bubble column simulation using multiphaseEulerFoam (Euler–Euler) in a rectangular domain spanning x = [0, 0.15] m, y = [0, 1.00] m, z = [0, 0.10] m with the height along the +y direction and a thin dimension in z.  
Create a structured hexahedral mesh with 25 cells in x, 75 cells in y, and 1 cell in z, using simpleGrading (1 1 1).  
Define the blockMeshDict patches as follows: the face at y = 0 m is the inlet patch, the face at y = 1.00 m is the outlet patch, the faces at x = 0 m, x = 0.15 m, and y = 0 m (excluding the inlet) are wall patches, and the two faces in the z direction (frontAndBack) are empty patches for the 2‑D case.  
Use heRhoThermo for the continuous liquid phase (water) with a polynomial equation of state (rPolynomial) using C coefficients (0.001278 -2.1055e‑06 3.9689e‑09 4.3772e‑13 -2.0225e‑16), molecular weight 18, specific heat capacity Cv = 4195 J kg⁻¹ K⁻¹, dynamic viscosity μ = 3.645e‑4 Pa·s, and Prandtl number Pr = 2.289.  
Use heRhoThermo for the dispersed gas phase (air) with a perfectGas equation of state, molecular weight 28.9, specific heat capacity Cp = 1007 J kg⁻¹ K⁻¹, dynamic viscosity μ = 1.84e‑05 Pa·s, and Prandtl number Pr = 0.7.  
Set gravity to (0 -9.81 0) m s⁻².  
Apply bubble size models: isothermal diameter d₀ = 3e‑3 m for air and constant diameter d = 1e‑4 m for water.  
Configure momentum transport as laminar for both phases by setting simulationType = laminar in the respective momentumTransport files.  
In phaseProperties, define the phases as (air water) with water as the reference phase and residualAlpha = 1e‑6 for both phases.  
Use linear blending with minFullyContinuousAlpha = 0.7 and minPartlyContinuousAlpha = 0.3 for the default scheme and 0.5 for the drag scheme.  
Set surface tension between air and water to a constant σ = 0.07 N m⁻¹.  
Select the Schiller‑Naumann drag model for the configurations air_dispersedIn_water, water_dispersedIn_air, and air_segregatedWith_water.  
Use a constant virtual mass coefficient Cvm = 0.5 for both directions.  
Employ the Ranz‑Marshall heat‑transfer model for both directions with residualAlpha = 1e‑4.  
Initialize the fields at t = 0 s as follows: water velocity uniform (0 0 0), air velocity uniform (0 0.1 0), water volume fraction α_water = 1, pressure p_rgh = 1e5 Pa, air temperature = 300 K, water temperature = 350 K.  
Set the initial phase distribution so that α_air = 1 and α_water = 0 everywhere except in the box region from (0 0 0) to (0.15 0.701 0.1) where α_air = 0 and α_water = 1.  
Apply inlet boundary conditions: air velocity fixedValue (0 0.1 0), water velocity fixedValue (0 0 0), α_air fixedValue 0.5, α_water fixedValue 0.5, air temperature fixedValue 300 K, water temperature fixedValue 350 K.  
Apply wall boundary conditions (including side walls and front/back empty patches treated as walls): air velocity fixedValue (0 0 0), water velocity fixedValue (0 0 0), α_air zeroGradient, α_water zeroGradient, pressure p_rgh fixedFluxPressure, air temperature zeroGradient, water temperature zeroGradient.  
Apply outlet boundary conditions: air velocity zeroGradient, water velocity zeroGradient, α_air zeroGradient, α_water zeroGradient, pressure p_rgh fixedFluxPressure, air temperature zeroGradient, water temperature zeroGradient.  
Set time control parameters: startTime = 0 s, endTime = 20 s, deltaT = 0.005 s, adjustTimeStep = no, maxCo = 0.5, maxDeltaT = 1 s, writeInterval = 1 s.
