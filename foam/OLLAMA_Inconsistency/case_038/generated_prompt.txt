Assume the aluminum block is a cube with side length 0.1 m (length = 0.1 m, width = 0.1 m, height = 0.1 m).  
Create a structured hexahedral mesh covering the cube with a uniform cell size of 0.005 m (resulting in 20 cells along each axis).  
Assign the material properties: Young’s modulus E = 69e9 Pa, Poisson’s ratio ν = 0.33, density ρ = 2700 kg/m³, thermal expansion coefficient α = 2.3e-5 1/K, reference temperature T0 = 300 K.  
Prescribe the temperature field T on the domain (either imported from a prior conduction solve or defined analytically) and use it to compute the thermal strain ε_th = α (T − T0).  
Apply boundary conditions:  
- On the face designated as fixedFace (e.g., x = 0), set displacement fixedValue uniform (0 0 0) for the displacement field (0/D) and zeroGradient for the temperature field (0/T).  
- On the opposite face (heatedFace, e.g., x = 0.1 m), set temperature fixedValue uniform 400 K for the temperature field (0/T) and zeroGradient for the displacement field (0/D).  
- All remaining faces have zeroGradient for both displacement and temperature fields.  
In system/controlDict, set the solver application to buoyantPimpleFoam.  
Configure the thermo‑elastic solver to include the thermal strain term in the momentum equation and to solve for displacement and stress fields.  
Run the simulation until a steady state is reached, then post‑process to obtain the displacement vector field and the Cauchy stress tensor throughout the block.
