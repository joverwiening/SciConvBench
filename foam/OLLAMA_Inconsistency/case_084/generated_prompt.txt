Create a new OpenFOAM case directory named “riserTwoPhase”.  
Use the solver twoPhaseEulerFoam for the simulation.  
Define two phases: “air” as the continuous phase and “catalyst” as the dispersed solid phase.  
Set the riser geometry to a vertical cylinder with a length of 10 m and an internal diameter of 0.20 m.  
Generate the mesh with blockMesh using hexahedral cells, a uniform axial cell size of 0.02 m and a radial cell size of 0.01 m, resulting in a structured mesh that resolves the diameter with at least 20 cells across.  
Create three boundary patches: “inlet”, “outlet”, and “wall”.  
At the inlet, set alpha.catalyst to a fixedValue of uniform 0.01 and alpha.air to a fixedValue of uniform 0.99.  
Prescribe a uniform axial velocity of 5 m s⁻¹ for the air phase at the inlet and apply the same velocity to the catalyst phase (fixedValue).  
At the outlet, set alpha.catalyst and alpha.air to zeroGradient, velocity to zeroGradient, and pressure to zeroGradient.  
On the wall, apply a noSlip condition for velocity and zeroGradient for pressure, alpha.catalyst, and alpha.air.  
Initialize the fields with alpha.catalyst = uniform 0.01, alpha.air = uniform 0.99, velocity = uniform (0 0 5) m s⁻¹, and pressure = uniform 0 Pa throughout the domain.  
Select the k‑epsilon turbulence model for the continuous phase and use the Syamlal‑O’Brien drag model for interphase momentum exchange.  
Set the simulation time parameters: startTime = 0 s, endTime = 5 s, deltaT = 0.001 s, and writeInterval = 0.1 s.  
Configure the solver controls to use an adjustable time step with a maximum Courant number of 0.5, a residual tolerance of 1e‑5 for all fields, and a maximum of 2 outer correctors per time step.  
Enable post‑processing by adding a sample utility that extracts axial profiles of velocity, pressure, and phase fractions along the riser centreline at every write interval.
