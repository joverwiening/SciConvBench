Simulate a 1D Sod shock tube using rhoCentralFoam.

Geometry: 1 m long tube, modeled as a thin 3D box:
- (0 0 0) to (1 0.1 0.1)

Mesh: blockMesh (400 1 1).
Patches:
- leftEnd (x=0) and rightEnd (x=1): wall (reflecting ends)
- all other faces: empty (to enforce 1D)

Thermophysical properties (constant/thermophysicalProperties): ideal air
- hePsiThermo / perfectGas / hConst / const transport
- Cp ~ 1005 J/kg/K; molWeight ~ 28.9 kg/kmol (gamma follows from Cp and R)

Initial conditions (setFields):
Use p and T so the density is consistent with the perfect-gas EOS:
- x < 0.5: p=100000 Pa, T=348.4 K, U=(0 0 0)
- x >= 0.5: p=10000 Pa,  T=278.7 K, U=(0 0 0)

Boundary conditions:
- leftEnd/rightEnd: U slip; p zeroGradient; T zeroGradient.
- empty faces: empty.

Time controls: endTime 0.007 s; deltaT 1e-6 s; writeInterval 0.0005 s; adjustTimeStep optional with maxCo 0.5.
