Run a transient laminar two-phase dam-break simulation with obstacles.
Set gravity g = (0 0 -9.81).
The computational domain is a cube spanning from (0,0,0) to (1,1,1).
Assign the top face (z=1) as the open atmosphere patch.
Assign the remaining five faces as walls.
Model phases via VOF method.
Water phase has density = 1000 kg/m^3 and viscosity = 1.0e-6 m^2/s.
Air phase has density = 1 kg/m^3 and viscosity = 1.48e-5 m^2/s.
Surface tension = 0.07 N/m.
Initialize water column as a rectangular prism where alpha.water = 1 inside the box (0, 0, 0) to (0.6, 0.1875, 0.75) and 0 elsewhere.
Include one obstacle as a rectangular box from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Use deltaT = 1e-3 s.
Use endTime = 0.1 s.
Use writeInterval = 0.02 s.
