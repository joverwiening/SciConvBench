Create an incompressible lid-driven cavity flow simulation using OpenFOAM.
Set up a computational grid with 20x20 cells in x and y directions and 1 cell in z-direction.
Use a square cavity domain with dimensions 1 meter x 1 meter x 0.1 meter.
Configure the top wall as 'movingWall' with uniform velocity of 1 m/s in the x-direction.
Set all other walls as 'fixedWalls' with no-slip boundary condition (zero velocity).
Designate front and back faces as 'empty' boundary type.
Run the simulation from time 0 to 10 seconds with a time step of 0.005 seconds.
Output results every 100 time steps.
Set kinematic viscosity (nu) as constant with value 1e-05 m²/s.
Use k-epsilon turbulence model.
Initialize turbulent kinetic energy (k) uniformly at 1.5e-4 m²/s² throughout the domain.
Apply kqRWallFunction boundary condition for k on all walls except front/back faces which remain empty.
Initialize turbulent dissipation rate (epsilon) uniformly at 1.4e-4 m²/s³ throughout the domain.
Apply epsilonWallFunction boundary condition for epsilon on all walls except front/back faces which remain empty.
Initialize turbulent viscosity (nut) uniformly at 0 m²/s throughout the domain.
Apply nutkWallFunction boundary condition for nut on all walls except front/back faces which remain empty.
Use pisoFoam solver for the simulation.
Initialize the velocity field to zero throughout the domain at the beginning of the simulation.
Set convection scheme for velocity as div(phi,U) Gauss limitedLinearV 1.
Set convection scheme for turbulent kinetic energy as div(phi,k) Gauss limitedLinear 1.
Set convection scheme for turbulent dissipation rate as div(phi,epsilon) Gauss limitedLinear 1.
Set viscous term scheme as div((nuEff*dev2(T(grad(U))))) Gauss linear.
