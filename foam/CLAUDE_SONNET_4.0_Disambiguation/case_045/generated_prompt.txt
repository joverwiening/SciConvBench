Set up a buoyant flow simulation in OpenFOAM using the buoyantPimpleFoam solver.
Create a 1x1 meter square domain with 50x50 uniform cells.
Use air as the working fluid with standard properties at atmospheric conditions.
Set the bottom wall boundary condition to fixed temperature at 300K.
Set the top wall boundary condition to fixed temperature at 290K.
Set the left and right walls to adiabatic boundary conditions using zeroGradient for temperature.
Initialize the temperature field uniformly at 295K throughout the domain.
Use setFields to create a symmetry-breaking perturbation by setting a warm spot from coordinates (0.45 0.00 -1) to (0.55 0.05 1) at 295.1K.
Configure gravity to act in the negative y-direction.
Set up appropriate turbulence modeling for the buoyant flow.
Configure the solver settings for transient simulation.
Run the simulation to capture the development of Rayleigh-Benard convection patterns.
