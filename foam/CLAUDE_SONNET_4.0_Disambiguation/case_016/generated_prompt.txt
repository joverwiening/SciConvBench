Set up a laminar counter-flow diffusion flame simulation using reactingFoam solver in OpenFOAM.
Create a 2-D rectangular domain with x from 0 to 0.02 m, y from -0.01 to 0.01 m, and z from -0.01 to 0.01 m.
Use a mesh with 100 grid points in x direction, 40 grid points in y direction, and 1 cell in z direction.
Name the left boundary (x=0) as fuel and the right boundary (x=0.02) as air.
Name the top and bottom boundaries as outlet.
Set the frontAndBack faces as empty boundary type.
At the fuel inlet boundary, inject methane (CH4) with inlet velocity of 0.1 m/s and temperature of 293 K.
At the air inlet boundary, supply air with inlet velocity of -0.1 m/s and temperature of 293 K.
Set the air composition with Y_O2 = 0.23 and balance N2.
Set inlet pressure at both fuel and air boundaries to 101325 Pa (atmospheric pressure).
Use EulerImplicit chemistry type with Rosenbrock43 ODE solver.
Configure laminar combustion model and laminar momentum transport.
Use compressible finite-rate chemistry with hePsiThermo thermodynamics.
Use coefficientWilkeMultiComponentMixture for mixing model.
Use Sutherland transport model and JANAF thermodynamics.
Set timestep to 1e-4 seconds with end time of 0.5 seconds.
Write results at intervals of 0.05 seconds.
