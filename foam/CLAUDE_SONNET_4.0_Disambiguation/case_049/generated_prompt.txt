Create a 2D dam break simulation using OpenFOAM with the interFoam solver.
Set up a water column with width 0.146m and height 0.292m positioned in the bottom-left corner of an air tank.
The air tank has dimensions of 0.584m length by 0.584m height.
Use blockMesh to create a uniform 58x58 grid for the computational domain.
Set front and back patches to 'empty' type to enforce 2D simulation.
Apply noSlip boundary condition for velocity on all walls (leftWall, rightWall, lowerWall).
Apply fixedFluxPressure boundary condition for p_rgh on all walls.
Apply zeroGradient boundary condition for alpha.water on all walls.
Set the top boundary (atmosphere) with pressureInletOutletVelocity for velocity.
Set the top boundary with totalPressure boundary condition for p_rgh with p0 uniform 0.
Set the top boundary with inletOutlet boundary condition for alpha.water with inletValue 0.
Configure adjustable time stepping with adjustTimeStep yes.
Set maxCo 0.5 and maxAlphaCo 0.5 for Courant number control.
Run the simulation for 2 seconds total time starting from time 0.
Use writeControl timeStep with writeInterval 20 for output frequency.
Initialize the water column in the bottom-left corner with alpha.water = 1 and the rest of the domain with alpha.water = 0 for air.
