Simulate natural convection in a square cavity using a buoyant solver for air.

Use a uniform 40x40 mesh with 40 cells in both x and y directions.
Apply 'empty' boundary conditions on the front and back patches for 2D simulation.

Set the right wall temperature to 293.15 K (20°C) with no-slip velocity condition.
Apply adiabatic conditions to top and bottom walls with zeroGradient temperature.
Apply no-slip velocity conditions (0 0 0) to top and bottom walls.
Apply fixedFluxPressure boundary condition with uniform 0 value for p_rgh on all walls.
Use air as the working fluid with appropriate thermophysical properties.
Set initial time step to 0.005 seconds with adjustable time stepping enabled.

Run simulation for total time of 200 seconds.
