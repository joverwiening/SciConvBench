Model turbulent flow in a porous pipe using the k-epsilon turbulence model.
The pipe has a length of 2 m and a diameter of 0.1 m (radius of 0.05 m).
The pipe is completely filled with porous material.
Use a porosity value of 0.4 (typical for packed beds or granular materials).
Use a permeability value of 1e-9 m^2 (typical for medium porosity materials).
The fluid is air with kinematic viscosity nu = 1.5e-5 m^2/s.
The inlet velocity boundary condition is fixedValue uniform (10 0 0) m/s.
The outlet velocity boundary condition is inletOutlet with inletValue uniform (0 0 0).
The outlet pressure boundary condition is fixedValue uniform 0.
The pipe wall velocity boundary condition is noSlip.
The pipe wall pressure boundary condition is zeroGradient.
The pipe wall k boundary condition is kqRWallFunction.
The pipe wall epsilon boundary condition is epsilonWallFunction.
The pipe wall nut boundary condition is nutkWallFunction.
The inlet k boundary condition is fixedValue uniform 0.375.
The inlet epsilon boundary condition is fixedValue uniform 0.23.
Use initial conditions of velocity (1 0 0) m/s, pressure 0 Pa, k 0.375 m^2/s^2, and epsilon 0.23 m^2/s^3 throughout the domain interior.
