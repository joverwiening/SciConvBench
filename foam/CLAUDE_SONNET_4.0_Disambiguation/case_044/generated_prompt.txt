Run a turbulent buoyant cavity simulation using the k-epsilon turbulence model.
The cavity is a 2D square with dimensions 0.10 m x 0.10 m x 0.01 m (length x width x height).
The thin dimension (0.01 m) is in the z-direction.
The Rayleigh number is approximately 1e6.
Use the Boussinesq approximation for buoyancy effects.
Set the left wall (hotWall) to fixed temperature 303 K with no-slip velocity boundary condition.
Set the right wall (coldWall) to fixed temperature 293 K with no-slip velocity boundary condition.
Set the top wall to zero gradient temperature with no-slip velocity boundary condition.
Set the bottom wall to zero gradient temperature with no-slip velocity boundary condition.
Use kinematic viscosity of 1.5e-5 m²/s.
Use Prandtl number of 0.71.
Use thermal expansion coefficient of 3.33e-3 1/K.
Set reference temperature to 298 K.
Set reference density to 1.0 kg/m³.
Initialize the temperature uniformly at 298 K throughout the cavity.
Run the simulation for 5000 pseudo-time iterations.
Use a time step (deltaT) of 1 for the steady-state solver.
