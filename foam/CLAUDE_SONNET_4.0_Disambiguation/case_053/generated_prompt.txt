Model a 2D de Laval nozzle with the following specifications.
Use air as the working fluid modeled as a perfect gas with gamma = 1.4 and molecular weight = 28.97 kg/kmol.
Set inlet total pressure to 5 bar (500,000 Pa).
Set inlet total temperature to 600 K.
Set back pressure (exit pressure) to 3.5e5 Pa (350,000 Pa) to force a normal shock in the diverging section.
Create a 2D nozzle geometry with total length of 0.3m from inlet to outlet.
Set inlet height to 0.1m.
Set throat height to 0.05m located at axial position x = 0.1m from the inlet.
Set outlet height to 0.08m.
The nozzle converges from inlet to throat (x = 0 to x = 0.1m) and diverges from throat to outlet (x = 0.1m to x = 0.3m).
Configure the simulation to capture the normal shock wave that will form in the diverging section due to the specified back pressure.
Use appropriate boundary conditions with total pressure and temperature at inlet and static pressure at outlet.
