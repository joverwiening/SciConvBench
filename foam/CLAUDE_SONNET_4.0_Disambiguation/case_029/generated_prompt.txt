Run a transient laminar two-phase dam-break simulation using interFoam solver.
The computational domain is a cube spanning from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 x 32 x 32 cells.
Place a rectangular obstacle in the domain from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set gravity vector to g = (0, 0, -9.81) m/s².
Initialize the water column as a rectangular prism where alpha.water = 1 inside the box from (0, 0, 0) to (0.6, 0.1875, 0.75) and alpha.water = 0 elsewhere.
Apply atmospheric pressure boundary condition to the top face (z=1).
Apply no-slip wall boundary conditions to the remaining five faces (bottom and four sides).
Set time step deltaT = 1e-3 seconds.
Set simulation end time to 0.1 seconds.
Set output write interval to 0.02 seconds.
Use laminar flow model for both phases.
