Simulate a 1D shock tube problem using rhoCentralFoam solver.
The shock tube is 1 meter long extending from x=0 to x=1.
The diaphragm is located at x=0.5 separating high and low pressure regions.
Left side initial conditions (x < 0.5): pressure 100000 Pa, density 1.0 kg/m³, temperature 348.4 K.
Right side initial conditions (x > 0.5): pressure 10000 Pa, density 0.125 kg/m³, temperature 278.7 K.
Use ideal air gas properties with Cp = 1005 J/kg/K, molecular weight = 28.9 kg/kmol, R = 287 J/kg/K.
Calculate gamma from the relation γ = Cp/(Cp - R).
Apply wall boundary conditions with slip at both ends (x=0 and x=1).
Set velocity boundary condition to slip at both walls.
Set pressure boundary condition to zeroGradient at both walls.
Set temperature boundary condition to zeroGradient at both walls.
Create mesh using blockMesh with 400 cells in x-direction and 1 cell each in y and z directions.
Set startTime to 0 and endTime to 0.007 seconds.
Use fixed deltaT of 1e-6 seconds.
Set writeControl to runTime with writeInterval of 0.0005 seconds.
Run the simulation until the shock reflects off the end wall.
