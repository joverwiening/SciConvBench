Create a lid-driven cavity flow simulation with the following specifications.
The cavity has dimensions 0.1m x 0.1m x 0.01m (length x width x height).
Set the kinematic viscosity to 0.01 m^2/s in the transportProperties file.
Assume water as the fluid with density 1000 kg/m^3.
The top wall moves at 1 m/s in the horizontal direction.
Apply no-slip boundary conditions to the bottom, left, and right walls with fixedValue uniform (0 0 0) for velocity.
Apply empty boundary conditions to the front and back walls for 2D simulation.
Use a uniform Cartesian mesh of 20x20x1 cells.
Use the icoFoam solver for the simulation.
Set endTime to 0.5 seconds.
Set deltaT to 0.0005 seconds.
Set writeInterval to 20 time steps.
