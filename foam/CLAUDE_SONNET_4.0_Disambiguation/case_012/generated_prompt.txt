The simulation is an incompressible lid-driven cavity flow using OpenFOAM.
The cavity is a square with dimensions 1 unit x 1 unit x 0.1 unit, making it effectively 2D.
Use a computational grid of 20x20x1 cells (20 cells in x-direction, 20 cells in y-direction, 1 cell in z-direction).
The simulation runs from time 0 to 10 time units with a time step of 0.005 units.
Output results every 100 time steps.
Use the k-epsilon turbulence model.
Initialize the velocity field to zero throughout the domain.
Initialize the turbulent kinetic energy k = 1.5e-4 uniformly in the domain.
Initialize the turbulent dissipation rate epsilon = 1.4e-4 uniformly in the domain.
Initialize the turbulent viscosity nut = 0 uniformly in the domain.
Apply kqRWallFunction boundary condition for k on all walls except front and back faces.
Apply epsilonWallFunction boundary condition for epsilon on all walls except front and back faces.
Apply nutkWallFunction boundary condition for nut on all walls except front and back faces.
Set front and back faces as empty boundary conditions.
The top wall (movingWall) moves in the x-direction with uniform velocity of 1 m/s.
The left, right, and bottom walls (fixedWalls) have no-slip boundary conditions with zero velocity.
Use pisoFoam solver.
Set convection scheme for velocity as div(phi,U) Gauss limitedLinearV 1.
Set convection scheme for turbulent kinetic energy as div(phi,k) Gauss limitedLinear 1.
Set convection scheme for turbulent dissipation rate as div(phi,epsilon) Gauss limitedLinear 1.
Set viscous term scheme as div((nuEff*dev2(T(grad(U))))) Gauss linear.
