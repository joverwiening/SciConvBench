Run a transient laminar two-phase dam-break simulation using interFoam solver.
Set up a cubic computational domain from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 x 32 x 32 cells.
Assign the top face (z=1) as an open atmosphere patch.
Assign the remaining five faces (x=0, x=1, y=0, y=1, z=0) as wall boundary conditions.
Include one rectangular obstacle from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Model two phases using Volume of Fluid (VOF) method.
Set water properties as density = 1000 kg/m³ and kinematic viscosity = 1.0e-6 m²/s.
Set air properties as density = 1 kg/m³ and kinematic viscosity = 1.48e-5 m²/s.
Set surface tension coefficient = 0.07 N/m between water and air.
Initialize water column as a rectangular prism from (0, 0, 0) to (0.6, 0.1875, 0.75).
Set alpha.water = 1 inside the water column and alpha.water = 0 elsewhere.
Run the simulation for 0.1 seconds total time.
