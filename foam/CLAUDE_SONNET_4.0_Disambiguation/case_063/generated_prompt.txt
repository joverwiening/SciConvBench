Set up the pitzDaily backward-facing step case using OpenFOAM.
Use the standard k-epsilon RAS turbulence model.
Use the blockMeshDict provided in the OpenFOAM pitzDaily tutorial for mesh generation.
Apply inlet boundary conditions with U fixedValue uniform (10 0 0) m/s, p zeroGradient, k fixedValue uniform 0.0375 m²/s², and epsilon fixedValue uniform 0.875 m²/s³.
Apply outlet boundary conditions with U zeroGradient, p fixedValue uniform 0, k zeroGradient, and epsilon zeroGradient.
Apply wall boundary conditions with U noSlip for both upperWall and lowerWall, p zeroGradient for both walls, k kqRWallFunction for both walls, epsilon epsilonWallFunction for both walls, and nut nutkWallFunction for both walls.
Use the simpleFoam solver for steady-state incompressible flow.
Set convergence criteria with residual tolerances of 1e-6 for U, 1e-6 for p, 1e-6 for k, and 1e-6 for epsilon.
Configure the simulation to run until convergence is achieved based on these residual tolerances.
