Set up the standard pitzDaily backward-facing step tutorial case for a steady-state solution.
Solver: Use the steady-state incompressible solver simpleFoam.
Geometry and Mesh: Use the blockMeshDict provided in the OpenFOAM pitzDaily tutorial. The step height is 0.028 m.
Fluid Properties: In transportProperties, set nu to 1e-5 m^2/s.
Turbulence Model: Use the standard k-epsilon RAS model. Set turbulence on in turbulenceProperties.
Boundary Conditions (in 0/ directory):
- U: inlet has type fixedValue with value uniform (10 0 0); outlet has type zeroGradient; upperWall and lowerWall have type noSlip.
- p: inlet has type zeroGradient; outlet has type fixedValue with value uniform 0; upperWall and lowerWall have type zeroGradient.
- k: inlet has type fixedValue with value uniform 0.0375; outlet has type zeroGradient; upperWall and lowerWall have type kqRWallFunction.
- epsilon: inlet has type fixedValue with value uniform 0.875; outlet has type zeroGradient; upperWall and lowerWall have type epsilonWallFunction.
- nut: upperWall and lowerWall have type nutkWallFunction.
Solver Settings: In fvSolution, use GAMG for pressure and smoothSolver for U, k, and epsilon. Set relaxationFactors for a stable convergence (e.g., p=0.3, U=0.7, k/epsilon=0.7). In fvSchemes, use Gauss upwind for divergence schemes.
