Simulate a 2D lid-driven cavity flow using icoFoam solver.
The cavity is a square with dimensions 0.1m x 0.1m.
The top wall moves with a velocity of (1 0 0) m/s.
The three stationary walls (left, right, and bottom) have noSlip boundary conditions with fixedValue uniform (0 0 0) for velocity.

The simulation runs for a total time of 0.5 seconds.
Use a fixed time step of 0.005 seconds.
