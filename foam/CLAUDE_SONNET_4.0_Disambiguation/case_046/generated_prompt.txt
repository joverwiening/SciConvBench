Simulate a 2D lid-driven cavity flow with the following specifications.
The cavity has dimensions of 0.1m width by 0.1m height.
The fluid is incompressible with kinematic viscosity of 0.001 m²/s and density of 1000 kg/m³.
The top wall moves to the right at 1 m/s with velocity vector (1 0 0).
The left, right, and bottom walls have noSlip boundary conditions for velocity and zeroGradient boundary conditions for pressure.
The top wall has zeroGradient boundary conditions for pressure.
Initialize the velocity field to uniform (0 0 0) throughout the domain.
Initialize the pressure field to uniform 0 throughout the domain.
Use the icoFoam solver for the simulation.
Use second-order accurate discretization schemes for spatial derivatives.
Use backward Euler scheme for time integration.
Set the time step to 0.002 seconds.
Run the simulation for a total time of 0.5 seconds.
The Reynolds number for this configuration is 100.
