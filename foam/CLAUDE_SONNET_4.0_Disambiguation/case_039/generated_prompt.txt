Set up a multi-region conjugate heat transfer simulation with a solid block containing a porous channel.

Create a rectangular solid block with dimensions 0.2m x 0.2m x 0.5m.

Create a rectangular porous channel with dimensions 0.1m x 0.1m x 0.5m running through the center of the solid block.

Use water as the fluid flowing through the porous channel.

Define porous properties using Darcy coefficients in fvOptions file with d=(1e6 1e6 1e6) and f=(100 100 100).

Set inlet boundary conditions for water flow as velocity U = (0.05 0 0) m/s, temperature T = 353.15 K, and pressure p = zeroGradient.

Set outlet boundary conditions for water flow as velocity U = zeroGradient, temperature T = zeroGradient, and pressure p = fixedValue 0.

Define aluminum material properties for the solid block in constant/solid/thermophysicalProperties with density 2700 kg/m³, specific heat capacity 900 J/kg·K, and thermal conductivity 237 W/m·K.

Set external solid wall boundary conditions as convective heat transfer using type mixed with reference temperature 293.15 K and heat transfer coefficient 10 W/m²·K.

Define water material properties with viscosity 8.9e-4 Pa·s in constant/fluid/transportProperties.

Define water thermal properties in constant/fluid/thermophysicalProperties with density 1000 kg/m³, specific heat capacity 4186 J/kg·K, and thermal conductivity 0.6 W/m·K.

Configure conjugate heat transfer between the solid block and fluid in the porous channel.
