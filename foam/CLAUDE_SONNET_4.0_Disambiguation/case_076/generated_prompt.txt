Create a dam break simulation using OpenFOAM's interFoam solver for two incompressible, immiscible fluids.
Set up a rectangular tank with dimensions 0.5715 m length, 0.4 m height, and 0.01 m thickness.
Position a water column at the left side starting from x=0 with dimensions 0.1461 m length, 0.2922 m height, and 0.01 m thickness.
Fill the remaining tank volume with air.
Use a mesh with 114 cells in x-direction, 80 cells in y-direction, and 1 cell in z-direction.
Set water properties to density 1000 kg/m³ and kinematic viscosity 1e-6 m²/s.
Set air properties to density 1 kg/m³ and kinematic viscosity 1.48e-5 m²/s.
Set surface tension coefficient to 0.07 N/m between water and air.
Apply noSlip velocity boundary condition to left, right, and bottom walls.
Apply fixedFluxPressure boundary condition to left, right, and bottom walls for p_rgh.
Apply zeroGradient boundary condition to left, right, and bottom walls for alpha.water.
Apply pressureInletOutletVelocity with inletValue (0 0 0) to top wall for velocity.
Apply totalPressure with p0 uniform 0 to top wall for p_rgh.
Apply inletOutlet with inletValue 0 and value 0 to top wall for alpha.water.
Set front and back boundaries as empty for 2D simulation.
Run simulation for 1.0 seconds total duration.
Use initial time step of 0.001 seconds with adjustTimeStep enabled.
Set maximum Courant number to 1.0 for adaptive time stepping.
Initialize water column as alpha.water = 1 and air region as alpha.water = 0.
