Create an incompressible lid-driven cavity flow simulation using OpenFOAM.
Use the pisoFoam solver for this transient simulation.
Set up a rectangular domain with dimensions 1 meter × 1 meter × 0.1 meter.
Create a structured grid with 20×20×1 cells in the x, y, and z directions respectively.
Set the kinematic viscosity (nu) to a constant value of 1e-05 m²/s.
Configure the top wall boundary as 'movingWall' with uniform velocity of 1 m/s in the x-direction and zero velocity in y and z directions.
Set all other walls as 'fixedWalls' with no-slip boundary condition (zero velocity in all directions).
Designate the front and back faces as 'empty' boundary type for 2D flow treatment.
Run the simulation from time 0 to 10 seconds with a time step of 0.005 seconds.
Use the convection scheme div(phi,U) Gauss limitedLinearV 1 for momentum transport.
Use the convection scheme div(phi,k) Gauss limitedLinear 1 for turbulent kinetic energy transport.
Use the convection scheme div(phi,epsilon) Gauss limitedLinear 1 for turbulent dissipation rate transport.
Use the viscous term scheme div((nuEff*dev2(T(grad(U))))) Gauss linear for viscous stress calculation.
