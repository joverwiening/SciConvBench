Create a 2D buoyant cavity simulation using buoyantBoussinesqSimpleFoam.
Set up a 1m x 1m square cavity geometry.
Apply a hot wall boundary condition of 310K on the left wall.
Apply a cold wall boundary condition of 290K on the right wall.
Apply insulated (zero gradient) boundary conditions on the top and bottom walls.
Set gravity vector to (0, -9.81, 0) m/s².
Use a 50x50 uniform mesh.
Set the Prandtl number to 0.71.
Set the reference temperature T0 to 300K for the Boussinesq approximation.
Set the thermal expansion coefficient beta to 3.33e-3 1/K.
Run the simulation to steady-state convergence.
