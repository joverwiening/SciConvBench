Run a transient laminar two-phase dam-break simulation with obstacles using interFoam.
The computational domain is a cube spanning from (0,0,0) to (1,1,1).
Discretize the domain uniformly with 32 x 32 x 32 cells.
Place a rectangular obstacle in the domain from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set gravity vector g = (0, 0, -9.81) m/s².
Assign the top face (z=1) as an open atmosphere patch.
Assign the remaining five faces (bottom and four sides) as wall boundary conditions.
Initialize the water column as a rectangular prism where alpha.water = 1 inside the box from (0, 0, 0) to (0.6, 0.1875, 0.75).
Set alpha.water = 0 everywhere else in the domain.
Use no turbulence model since the simulation is laminar.
Set time step deltaT = 1e-3 seconds.
Set end time endTime = 0.1 seconds.
Set write interval writeInterval = 0.02 seconds.
