Run a transient two-phase dam-break simulation using the interFoam solver.
The computational domain is a cube spanning from (0,0,0) to (1,1,1).
Discretize the domain uniformly with a 32 x 32 x 32 grid.
Place a rectangular obstacle in the domain from (0.375, 0.375, 0) to (0.625, 0.625, 0.25).
Set gravity vector to g = (0, 0, -9.81) m/s².
Initialize the water phase with alpha.water = 1 inside the rectangular region from (0, 0, 0) to (0.6, 0.1875, 0.75).
Initialize alpha.water = 0 everywhere else in the domain.
Apply atmospheric pressure boundary condition to the top face at z = 1.
Apply no-slip wall boundary conditions to the remaining five faces (x = 0, x = 1, y = 0, y = 1, z = 0).
Apply no-slip wall boundary conditions to all surfaces of the obstacle.
Set the time step deltaT = 1e-3 seconds.
Run the simulation until endTime = 0.1 seconds.
Write output data every writeInterval = 0.02 seconds.
