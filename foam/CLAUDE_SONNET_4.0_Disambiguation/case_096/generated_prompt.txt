Simulate 2D Rayleigh-Benard convection in a square cavity.
The cavity dimensions are 0.1 m x 0.1 m x single cell depth.
Use a 50 x 50 x 1 mesh generated with blockMesh.
Set the bottom surface temperature to 294.0 K (heated).
Set the top surface temperature to 293.0 K (cooled).
Apply no-slip boundary conditions to the left and right walls.
Apply adiabatic (zero gradient) temperature boundary conditions to the left and right walls.
Apply empty boundary conditions to the front and back faces for 2D simulation.
Use kinematic viscosity of 1.5e-5 m²/s.
Use Prandtl number of 0.71.
Use thermal expansion coefficient of 3.33e-3 K⁻¹.
Use reference temperature of 293.5 K.
Use reference density of 1.0 kg/m³.
Set deltaT to 1 for pseudo-time stepping.
Set endTime to 5000 iterations.
Use a steady-state solver approach.
The simulation will show convection cell formation due to buoyancy-driven flow.
