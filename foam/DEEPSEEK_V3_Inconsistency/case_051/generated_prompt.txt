Create a 2D rectangular domain with a length of 1.0m and a height of 0.1m.
Use the `blockMesh` utility to generate a structured mesh.
The mesh must have 100 cells in the axial (x) direction.
The mesh must have 20 cells in the radial (y) direction.
Define the front and back patches as type `empty`.
Name the inlet boundary patch "inlet".
Apply a fixed velocity of (0.1 0 0) m/s at the inlet.
Name the outlet boundary patch "outlet".
Apply a `zeroGradient` condition for velocity at the outlet.
Apply a fixed pressure of 0 at the outlet.
Name the top wall boundary patch "top".
Name the bottom wall boundary patch "bottom".
Apply a `noSlip` condition for velocity at the top and bottom walls.
Use the `icoFoam` solver for the simulation.
Set the simulation start time to 0 seconds.
Set the simulation end time to 5 seconds.
In the `constant/transportProperties` dictionary, set the `transportModel` to `BinghamPlastic`.
In the `constant/transportProperties` dictionary, set the density `rho` to 1000.
In the `constant/transportProperties` dictionary, set the yield stress `tau0` to 10.
In the `constant/transportProperties` dictionary, set the plastic viscosity `mu0` to 0.1.
In the `constant/transportProperties` dictionary, set the infinite shear viscosity `muInf` to 0.01.
