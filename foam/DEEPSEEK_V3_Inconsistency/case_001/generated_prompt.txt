Run a two-dimensional Rayleigh-Benard convection simulation in a rectangular cavity.
The cavity dimensions are 9 units wide (x) and 1 unit tall (y), extruded a single cell in the spanwise (z) direction.
Use a computational grid with 90 cells in the x-direction, 10 cells in the y-direction, and 1 cell in the z-direction.
Treat the front and back patches as empty to enforce two-dimensionality.
Use the simpleFoam solver for a steady-state simulation.
Apply gravity acting downward in the negative y-direction.
Use a reference state for air-like fluid with a density of 1.0 kg/m³.
Set the reference temperature to 300 K.
Set the thermal expansion coefficient to 3.3e-3 1/K.
Set the kinematic viscosity to 1.5e-5 m²/s.
Set the thermal diffusivity to 2.1e-5 m²/s, resulting in a Prandtl number of approximately 0.7.
Fix the temperature of the bottom wall at 305 K.
Fix the temperature of the top wall at 295 K.
Set the vertical side walls to adiabatic (zeroGradient) thermal conditions.
Apply no-slip velocity conditions on all solid walls.
Initialize the velocity field uniformly at rest (0 0 0).
Initialize the temperature field uniformly at 300 K.
Use a fixed time step of 1 second.
Set deltaT to 1 s in the controlDict.
Do not enable adjustTimeStep.
Do not set maxCo or maxDeltaT.
Simulate up to 1000 seconds of physical time.
Write result files every 50 time steps.
Use the RANS k-epsilon turbulence model.
In constant/momentumTransport, set simulationType to RAS.
In constant/momentumTransport, set the RAS model to kEpsilon.
In constant/momentumTransport, set turbulence to on.
In constant/momentumTransport, set printCoeffs to on.
Do not use a laminar specification.
In constant/physicalProperties, use the heRhoThermo thermophysical model.
In constant/physicalProperties, set the equationOfState to Boussinesq.
In constant/physicalProperties, set the molecular weight to 29.
In constant/physicalProperties, set rho0 to 1.0.
In constant/physicalProperties, set T0 to 300.
In constant/physicalProperties, set beta to 3.3e-3.
In constant/physicalProperties, set Cv to 714.3.
In constant/physicalProperties, set Hf to 0.
In constant/physicalProperties, set mu to 1.5e-5.
In constant/physicalProperties, set Pr to 0.714.
In the initial condition file 0/k, set the internal field uniformly to 1e-5.
Apply the kqRWallFunction boundary condition on all solid walls.
Apply the empty condition on the front and back patches.
In the initial condition file 0/epsilon, set the internal field uniformly to 1e-5.
Apply the epsilonWallFunction boundary condition on all solid walls.
Apply the empty condition on the front and back patches.
In the initial condition file 0/nut, set the internal field uniformly to 0.
Apply the nutkWallFunction boundary condition on all solid walls.
Apply the empty condition on the front and back patches.
In the initial condition file 0/alphat, set the internal field uniformly to 0.
Apply the compressible::alphatJayatillekeWallFunction on all solid walls.
Set the turbulent Prandtl number (Prt) to 0.85 in the alphat boundary condition.
Apply the empty condition on the front and back patches for alphat.
In the initial condition file 0/U, set the internal field uniformly to (0 0 0).
Apply the noSlip condition on all solid walls.
Apply the empty condition on the front and back patches.
In the initial condition file 0/T, set the internal field uniformly to 300.
Apply a fixedValue condition of 305 K on the bottom wall.
Apply a fixedValue condition of 295 K on the top wall.
Apply a zeroGradient condition on the vertical side walls.
Apply the empty condition on the front and back patches.
In the initial condition file 0/p, set the internal field uniformly to 0.
Apply the calculated condition on all solid walls.
Apply the empty condition on the front and back patches.
In the initial condition file 0/p_rgh, set the internal field uniformly to 0.
Apply the fixedFluxPressure condition on all solid walls.
Apply the empty condition on the front and back patches.
In system/fvSolution, set the solver for p_rgh to a tolerance of 1e-8 and a relative tolerance of 0.01.
In system/fvSolution, set the solver for U to a tolerance of 1e-8 and a relative tolerance of 0.01.
In system/fvSolution, set the solver for epsilon to a tolerance of 1e-8 and a relative tolerance of 0.01.
In system/fvSolution, set the solver for k to a tolerance of 1e-8 and a relative tolerance of 0.01.
In system/fvSolution, set the corresponding *Final solvers for p_rgh, U, epsilon, and k to a relative tolerance of 0.
