Configure a 2D simulation of flow past a cylinder using pimpleFoam for a transient, incompressible, laminar case.
Use a mesh that is one cell thick.
Define the 'frontAndBack' patches in 'constant/polyMesh/boundary' with 'type symmetryPlane'.
In the '0/U' file, set the boundary condition for 'frontAndBack' to 'type wall; value uniform (0 0 0);'.
Set all other boundary conditions (inlet, outlet, cylinderWall) appropriately for a flow-past-cylinder case.
