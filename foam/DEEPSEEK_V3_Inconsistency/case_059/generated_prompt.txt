Simulate a steady-state, two-phase oil-water flow in a horizontal pipe using the twoPhaseEulerFoam solver.
Use a pipe diameter of 0.05 meters.
Use a pipe length of 2 meters.
Set the inlet mixture velocity to 1.0 m/s.
Target a fully turbulent flow regime with a Reynolds number in the order of 10^5.
Set the operating fluid temperature to 293.15 K (20°C).
Set the oil phase density to 800 kg/m³.
Set the water phase density to 1000 kg/m³.
Set the oil phase dynamic viscosity to 0.001 Pa·s.
Set the water phase dynamic viscosity to 0.00089 Pa·s.
Set the surface tension coefficient to 0.07 N/m.
At the inlet, impose a fixed mixture velocity boundary condition.
At the inlet, impose a fixed water volume fraction (alpha.water) of 0.3.
Apply a no-slip boundary condition on all pipe walls.
In the 0/alpha.water file, set the outlet boundary condition to fixedValue with a uniform value of 0.3.
Use appropriate turbulence modeling for a fully turbulent regime (e.g., k-epsilon or k-omega SST).
Initialize the domain with a uniform water volume fraction of 0.3.
Run the simulation to a steady state as determined by monitoring residuals and field values.
