Simulate transient elastic wave propagation in a solid aluminum block.
The domain dimensions are 1.0 m in length, 0.1 m in width, and 0.1 m in height.
Use the material properties: Young's modulus E = 70e9 Pa, Poisson's ratio nu = 0.33, and density rho = 2700 kg/m^3.
Initialize a small displacement pulse using setFields by setting the displacement vector D = (1e-6 0 0) m in a thin region near x = 0.
Set the displacement vector D = (0 0 0) m elsewhere in the domain.
Apply traction-free boundary conditions on all external faces using the tractionDisplacement boundary condition with traction uniform (0 0 0) and pressure uniform 0.
Set the application in system/controlDict to pimpleFoam.
Set the total simulation time to 0.001 seconds to capture the initial wave propagation.
Measure the displacement field as the primary output quantity.
Use a structured hexahedral mesh for spatial discretization.
Set the approximate cell size to 0.01 m.
Set the time step size (deltaT) to 1e-7 seconds to satisfy the Courant condition for numerical stability.
