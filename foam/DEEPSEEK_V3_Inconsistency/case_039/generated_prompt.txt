The simulation is a 2D dam-break of a water column collapsing into air.
The domain is a rectangular tank with a length of 3.0 m in the x-direction and a height of 2.0 m in the y-direction.
The mesh is a 2D grid extruded one cell in the spanwise (z) direction with a length of 0.1 m.
The mesh cell size is 0.02 m in both the x and y directions.
The initial water column is a rectangle with a width of 0.5 m and a height of 1.0 m.
The water column is positioned with its left edge at x = 0.0 m and its bottom edge at y = 0.0 m.
The interface is tracked using the VOF field alpha.water.
The alpha.water field is initialized to 1 inside the initial water column and 0 elsewhere using setFields.
Gravity is set to (0 -9.81 0).
The tank walls use noSlip for U, zeroGradient for p_rgh, and zeroGradient for alpha.water.
The open top boundary uses pressureInletOutletVelocity for U, totalPressure with a fixedValue of 0 for p_rgh, and inletOutlet for alpha.water with an inletValue uniform 0.
The application in system/controlDict is set to solidDisplacementFoam.
The simulation runs for 2.0 seconds.
