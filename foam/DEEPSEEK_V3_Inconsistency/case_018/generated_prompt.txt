Set up a laminar counter-flow diffusion flame simulation using reactingFoam in a 2-D opposed-jet configuration.
The computational domain spans x in [0, 0.02] m, y in [-0.01, 0.01] m, and z in [-0.01, 0.01] m.
Use a structured hexahedral mesh with 100 cells in the x-direction, 40 cells in the y-direction, and 1 cell in the z-direction.
Set the boundary condition for the frontAndBack patches to "empty".
Define the left boundary patch (x=0) as the fuel inlet.
Define the right boundary patch (x=0.02) as the air inlet.
Define the top boundary patch as an outlet.
Define the bottom boundary patch as an outlet.
Set the fuel inlet composition to pure methane (CH4) with a mass fraction of 1.0.
Set the fuel inlet temperature to 293 K.
Set the fuel inlet velocity to +0.1 m/s in the +x direction.
Set the air inlet composition to a mass fraction of 0.23 for O2 and 0.77 for N2.
Set the air inlet temperature to 293 K.
Set the air inlet velocity to -0.1 m/s in the -x direction.
Initialize the temperature field in the entire domain to 2000 K.
Use the EulerImplicit scheme for chemistry integration.
Use the Rosenbrock43 ODE solver for chemistry.
Use the laminar combustion model.
Use the laminar momentum transport model.
Use the hePsiThermo thermodynamic package.
Use the coefficientWilkeMultiComponentMixture for mixture properties.
Use the Sutherland model for transport properties.
Use the JANAF format for thermodynamic data.
Set the simulation time step (deltaT) to 1e-4 seconds.
Set the simulation endTime to 0.5 seconds.
Set the data writeInterval to 0.05 seconds.
