Use the OpenFOAM steady-state solver `buoyantSimpleFoam` to simulate airflow in a ventilated room.
The room geometry must include an inlet boundary patch named `inlet`.
The room geometry must include an outlet boundary patch named `outlet`.
The room geometry must include a wall patch for the heater, named `heater`.
All other walls of the room must be defined as a single patch named `walls`.
Apply a `fixedValue` temperature boundary condition of 320 K to the `heater` patch.
Apply a `fixedValue` temperature boundary condition of 293 K to the `inlet` patch.
In the `constant/thermophysicalProperties` dictionary, set the `thermoType` to `heRhoThermo`.
In the `constant/thermophysicalProperties` dictionary, use the `Boussinesq` equation of state.
Set the Boussinesq reference temperature `T0` to 293.
Set the Boussinesq thermal expansion coefficient `beta` to 0.00341.
Set the Boussinesq reference density `rho0` to 1.2.
Use a constant transport model.
Set the constant dynamic viscosity `mu` to 1.8e-05.
Set the constant Prandtl number `Pr` to 0.71.
The simulation must model natural convection driven by the heated wall.
