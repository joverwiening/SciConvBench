Run a 2D inviscid laminar oblique-shock simulation on a rectangular channel extruded one cell in z.
The domain extends from (0, 0, 0) to (4.1, 1, 0.1).
Use a grid of 60 cells in x, 30 cells in y, and 1 cell in z.
Set the frontAndBack patches to the empty type.
Set the left patch as inlet.
Set the right patch as outlet.
Set the top patch as wall.
Set the bottom patch as symmetryPlane.
Use the rhoCentralFoam solver.
Set momentum transport to laminar.
Use ideal gas thermodynamics.
Set the inviscid model with Cp=2.5, Pr=1, and viscosity=0.
Initialize the velocity field U to (2.9 0 0).
Initialize the pressure field p to 1.
Initialize the temperature field T to 1.
Set the inlet boundary condition for U to fixedValue (2.9 0 0).
Set the inlet boundary condition for p to fixedValue 1.
Set the inlet boundary condition for T to fixedValue 1.
Apply the noSlip velocity boundary condition on the top wall patch.
Set the molecular weight to 11640.3.
Set the formation enthalpy Hf to 0.
Calculate the specific gas constant R as 8314.462618 / 11640.3.
Set the outlet boundary condition for all fields to zeroGradient.
Set the time step deltaT to 0.0025.
Set the simulation endTime to 10.
Set the writeInterval to 1.
