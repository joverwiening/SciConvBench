Perform a steady-state, incompressible simulation of airflow over a NACA 0012 airfoil.
The simulation is 2D.
The mesh is created as a single layer of cells in the z-direction.
In the `constant/polyMesh/boundary` file, the patches for the thin dimension are named `frontAndBack` and are defined with `type wall;`.
In the `0/U` file, the boundary condition for `frontAndBack` is set to `noSlip`.
In the `0/p` file, the boundary condition for `frontAndBack` is set to `zeroGradient`.
Use the `simpleFoam` solver.
Use the k-omega SST turbulence model.
Set the Reynolds number to 6 million based on chord length.
Set the freestream velocity to 10 m/s.
Set the chord length of the NACA 0012 airfoil to 1 meter.
Set the angle of attack to 2 degrees.
Set the domain size to a C-grid with a farfield distance of 20 chord lengths from the airfoil in all directions.
