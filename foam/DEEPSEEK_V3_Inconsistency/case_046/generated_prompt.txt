Set up a transient simulation of turbulent flow over a 2D cylinder in a channel using pimpleFoam.
Use the incompressible solver.
Set the fluid properties to those of standard air at 20°C: kinematic viscosity (nu) to 1.5e-05 m²/s and density (rho) to 1.2 kg/m³.
Set the inlet velocity to a uniform 10 m/s in the streamwise direction.
Set the cylinder diameter to 0.1 m.
Set the channel height to 0.4 m.
Set the channel length in the flow direction to 2.0 m.
Place the cylinder center at a position 0.5 m downstream from the inlet boundary.
Place the cylinder center at a position 1.5 m upstream from the outlet boundary.
Apply a no-slip boundary condition to the cylinder surface.
Apply no-slip boundary conditions to the top and bottom channel walls.
Configure the `constant/turbulenceProperties` dictionary with the specified hybrid LES/RAS setup.
Set the simulation type to LES.
In the LES sub-dictionary, set the LESModel to Smagorinsky and the delta to cubeRootVol.
In the RAS sub-dictionary, set the RASModel to kOmegaSST, turbulence to on, and printCoeffs to on.
Generate a 2D mesh with a structured background and a refined O-grid around the cylinder.
Set the base cell size in the far field to 0.02 m.
Set the first cell height at the cylinder wall to achieve a y+ of approximately 1.
Set the circumferential resolution around the cylinder to 200 cells.
Set the radial expansion ratio in the O-grid to 1.1.
Set the time step (deltaT) to 1e-04 seconds to maintain a Courant number below 1.
Set the total simulation time (endTime) to 1.0 second.
Use the PIMPLE algorithm for pressure-velocity coupling with standard pimpleFoam settings.
Set the maximum number of outer correctors to 2.
Set the maximum number of inner correctors for pressure to 3.
Set the write interval for results to 0.01 seconds.
