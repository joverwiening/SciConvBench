The domain is a rectangle with width 2.0 m and height 1.0 m.
The water column is initially on the left side, with a length of 0.5 m and a height of 0.5 m.
The mesh is generated with a uniform cell size of 0.01 m, resulting in a 200x100 cell grid.
Use the pimpleFoam solver for the simulation.
In the controlDict, set the endTime to 5 s.
Use the setFields utility to initialize the water column.
Set alpha.water to 1 in the region defined by x from 0 to 0.5 m and y from 0 to 0.5 m.
Set alpha.water to 0 everywhere else in the domain.
Set the gravitational acceleration g to (0 -9.81 0) in the constant/g file.
In the transportProperties dictionary, define two phases: 'water' and 'air'.
Set the kinematic viscosity for water to 1e-06 m^2/s.
Set the kinematic viscosity for air to 1.5e-05 m^2/s.
Set the density for water to 1000 kg/m^3.
Set the density for air to 1 kg/m^3.
