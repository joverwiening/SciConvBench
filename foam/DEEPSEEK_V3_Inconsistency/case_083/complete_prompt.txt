Set up the initial conditions for a three-phase settling tank containing sediment, water, and oil using the `multiphaseEulerFoam` solver. The initial field files are located in the `0/` directory. For the default field condition (before `setFields` is applied), the volume fraction for each phase should be specified in its corresponding file (`alpha.sediment`, `alpha.water`, `alpha.oil`). To represent a tank initially full of water, set the `internalField` as follows: `alpha.water` should be `internalField uniform 1;`, while `alpha.sediment` and `alpha.oil` should both be `internalField uniform 0;`. This initial state can then be modified by `setFieldsDict` to create stratified layers.
