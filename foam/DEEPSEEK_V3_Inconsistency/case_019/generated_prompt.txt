Set up a laminar counter-flow diffusion flame simulation using the reactingFoam solver in OpenFOAM.
The domain is a 2-D opposed-jet configuration in a rectangular region.
The x-coordinate spans from 0 to 0.02 meters.
The y-coordinate spans from -0.01 to 0.01 meters.
The z-coordinate spans from -0.01 to 0.01 meters.
Use a mesh with 100 cells in the x-direction.
Use 40 cells in the y-direction.
Use 1 cell in the z-direction.
Name the left boundary at x=0 as "fuel".
Name the right boundary at x=0.02 as "air".
Name the top and bottom boundaries as "outlet".
Set the frontAndBack boundary condition type to "empty".
At the fuel inlet, inject pure methane (CH4).
Set the mass fraction of CH4 at the fuel inlet to 1.0.
Set the mass fraction of N2 at the fuel inlet to 0.0.
Set the fuel inlet temperature to 293 K.
At the air inlet, supply oxidizer as air.
Set the mass fraction of O2 at the air inlet to 0.23.
Set the mass fraction of N2 at the air inlet to 0.77.
Set the air inlet temperature to 293 K.
Initialize the entire domain with a temperature of 2000 K at time 0.
Set the velocity at the fuel boundary to 0.1 m/s.
Set the velocity at the air boundary to -0.1 m/s.
Apply a "fixedValue" boundary condition for velocity at the fuel and air inlets.
Apply a "zeroGradient" boundary condition for pressure at the fuel and air inlets.
Use a chemistry type = EulerImplicit.
Use an ODE solver = Rosenbrock43.
Use a laminar combustion model.
Use laminar momentum transport.
Use an incompressible finite-rate chemistry formulation.
Use the heRhoThermo thermodynamics package.
Use the coefficientWilkeMultiComponentMixture for the mixture.
Use the Sutherland model for transport.
Use the JANAF model for thermodynamics.
Use a simulation timestep of 1e-4 seconds.
Set the simulation end time to 0.5 seconds.
Write simulation results every 0.05 seconds.
