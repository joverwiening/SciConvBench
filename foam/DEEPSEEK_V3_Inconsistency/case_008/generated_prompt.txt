Conduct a compressible flow simulation through a 45-degree angled porous duct using the porousSimpleFoam solver with the SIMPLE algorithm.

Use the provided blockMeshDict to generate the mesh.

Set all remaining surfaces to default wall conditions.
The simulation is steady-state, running from time 0 to 1000 with a timestep of 1 and output every 100 timesteps.
Use the GAMG solver for pressure with a tolerance of 1e-08 and a relative tolerance of 0.05.
Use the smoothSolver with a GaussSeidel smoother for velocity and turbulence quantities.

Set the k-epsilon turbulence model solver tolerance to 1e-07.
