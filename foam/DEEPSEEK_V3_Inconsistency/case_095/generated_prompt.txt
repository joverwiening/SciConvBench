Set up a 2D, steady-state, incompressible, turbulent simulation of airflow over a NACA0012 airfoil at a 5-degree angle of attack.
Use the simpleFoam solver with the k-omega SST turbulence model.
The domain is a C-grid type, one cell thick in the z-direction.
The mesh is defined in `constant/polyMesh`.
The boundary patches are `inlet`, `outlet`, `airfoil`, and `frontAndBack`.
Assume a chord length of 1 meter for the NACA0012 airfoil.
Assume a freestream velocity magnitude of 10 meters per second.
Assume a kinematic viscosity of air of 1.5e-05 m²/s, resulting in a Reynolds number of approximately 666,667.
Set the `inlet` boundary condition for velocity `U` to `fixedValue` uniform (10 0 0).
Set the `inlet` boundary condition for `k` and `omega` based on a turbulence intensity of 1% and a viscosity ratio of 10.
Set the `inlet` boundary condition for pressure `p` to `zeroGradient`.
Set the `outlet` boundary condition for velocity `U` to `inletOutlet`.
Set the `outlet` boundary condition for `k` and `omega` to `inletOutlet`.
Set the `outlet` boundary condition for pressure `p` to `fixedValue` uniform 0.
Set the `airfoil` boundary condition for velocity `U` to `noSlip`.
Set the `airfoil` boundary condition for `k` to `kqRWallFunction`.
Set the `airfoil` boundary condition for `omega` to `omegaWallFunction`.
Set the `airfoil` boundary condition for pressure `p` to `zeroGradient`.
Set the `frontAndBack` patches to type `wall` in `constant/polyMesh/boundary`.
Set the `frontAndBack` boundary condition for velocity `U` to `noSlip`.
Set the `frontAndBack` boundary condition for pressure `p` to `zeroGradient`.
Set the `frontAndBack` boundary condition for `k` to `zeroGradient`.
Set the `frontAndBack` boundary condition for `omega` to `zeroGradient`.
