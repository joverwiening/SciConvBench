Set up a 2D steady-state simulation of Rayleigh-Bénard convection in a square cavity of 1m x 1m.
Use the `buoyantBoussinesqSimpleFoam` solver.
The fluid is air.
The bottom wall is heated to 310 K with a fixedValue boundary condition.
The top wall is cooled to 290 K with a fixedValue boundary condition.
The side walls are adiabatic with a zeroGradient boundary condition for temperature.
All walls have a noSlip boundary condition for velocity.
All boundaries have a fixedFluxPressure boundary condition for pressure p_rgh.
Gravity acts in the negative y-direction with g = 9.81 m/s^2.
Use a compressible model to capture density changes.
In `constant/thermophysicalProperties`, set the thermoType to hePsiThermo.
In `constant/thermophysicalProperties`, set the mixture to perfectGas.
In `constant/thermophysicalProperties`, set the transport model to const.
In `constant/thermophysicalProperties`, set the thermo model to hConst.
In `constant/thermophysicalProperties`, set the equationOfState to perfectGas.
In `constant/thermophysicalProperties`, set the specie to specie.
In `constant/thermophysicalProperties`, set the energy to sensibleEnthalpy.
In `constant/thermophysicalProperties`, set the mixture.specie.molWeight to 28.9.
In `constant/thermophysicalProperties`, set the mixture.thermodynamics.Cp to 1005.
In `constant/thermophysicalProperties`, set the mixture.thermodynamics.Hf to 0.
In `constant/thermophysicalProperties`, set the mixture.transport.mu to 1.8e-05.
In `constant/thermophysicalProperties`, set the mixture.transport.Pr to 0.7.
Set the initial temperature field to 300 K uniformly.
Set the initial pressure field to 0 Pa (gauge pressure) uniformly.
Set the initial velocity field to (0 0) m/s uniformly.
