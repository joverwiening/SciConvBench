Perform a 2D transient heat conduction simulation on a 1 m x 1 m plate.
Use the OpenFOAM solver `laplacianFoam`.
Extrude the mesh one cell in the z-direction to a thickness of 0.01 m.
Treat the out-of-plane faces as a single patch named `frontAndBack`.
Set the thermal diffusivity `DT` to 1e-5 m²/s in the transport properties.
Set the initial temperature field `T` to a uniform value of 300 K.
In the file `constant/polyMesh/boundary`, define the `frontAndBack` patch with type `wall`.
In the initial condition file `0/T`, set the boundary condition for the `frontAndBack` patch to type `zeroGradient`.
