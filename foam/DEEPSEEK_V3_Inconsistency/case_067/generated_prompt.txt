Set up a steady-state simulation for laminar, incompressible flow over a backward-facing step using the simpleFoam solver.
The domain has an inlet on the left and an outlet on the right.
The fluid enters the domain at the 'inlet' patch and exits at the 'outlet' patch.
All other boundaries are walls with a no-slip condition.
The simulation is 2D, so front and back patches are of type 'empty'.
Use a Reynolds number of 100, based on the step height, for a laminar flow regime.
Specify the following boundary conditions in the '0/U' file.
For the inlet patch, use a fixedValue condition with a uniform parabolic velocity profile.
The maximum inlet velocity is set to achieve the target Reynolds number of 100.
For the outlet patch, use a zeroGradient condition.
For the stepWall patch, use a noSlip condition.
For the topWall patch, use a noSlip condition.
For the frontAndBack patches, use an empty condition.
Set the kinematic viscosity in the transportProperties dictionary to achieve the specified Reynolds number.
Initialize the velocity field with a uniform value of (0 0 0).
