Simulate incompressible water flow in a 2D channel with a prescribed moving wall using a dynamic mesh.
Use a 2D mesh extruded one cell in the spanwise direction with `frontAndBack` boundary types set to `empty`.
Use water properties with kinematic viscosity `nu = 1e-6 m^2/s`.
The channel has a length of 1.0 m and a cross-sectional height of 0.1 m.
Use the `dynamicMotionSolverFvMesh` solver with `displacementLaplacian` specified in `constant/dynamicMeshDict`.
Prescribe the motion on the `movingWall` boundary using an `oscillatingDisplacement` condition in the `0/pointDisplacement` field.
Set the amplitude of the oscillating displacement for the moving wall to 0.01 m.
Set the frequency of the oscillating displacement for the moving wall to 1.0 Hz.
Set the direction of the oscillating displacement for the moving wall to be normal to the wall surface.
Set all other boundaries in the `0/pointDisplacement` field to `fixedValue` with a `uniform` value of `(0 0 0)`.
For the `0/U` field, set the inlet boundary condition to `fixedValue`.
For the `0/U` field, set the outlet boundary condition to `zeroGradient`.
For the `0/U` field, set stationary wall boundaries to `noSlip`.
For the `0/U` field, set the `movingWall` boundary to `movingWallVelocity`.
For the `0/p` field, set the outlet boundary condition to `fixedValue` with a `uniform` value of 0.
For the `0/p` field, set the inlet and wall boundaries to `zeroGradient`.
In the `system/controlDict` file, set the `application` to `solidDisplacementFoam`.
