Set up a 2D incompressible laminar flow simulation in a rectangular channel using the icoFoam solver.
The channel is 0.5 m long in the x-direction and 0.1 m high in the y-direction.
The mesh is one cell thick in the z-direction.
In the blockMeshDict file, define the geometry and patches named inlet, outlet, topWall, bottomWall, and frontAndBack.
For the frontAndBack patches, specify the type as 'wall'.
In the transportProperties dictionary, set the kinematic viscosity (nu) to 0.0001 m^2/s.
In the transportProperties dictionary, set the fluid density (rho) to 1 kg/m^3.
In the '0/U' file, set a parabolic inlet velocity profile with a maximum of 1 m/s.
In the '0/U' file, set the outlet boundary condition to zeroGradient.
In the '0/U' file, set the boundary condition for topWall and bottomWall to noSlip.
In the '0/U' file, set the boundary condition for the frontAndBack patches to noSlip.
In the '0/p' file, set the outlet boundary condition to fixedValue with a value of 0.
In the '0/p' file, set the boundary condition for the inlet, topWall, bottomWall, and frontAndBack patches to zeroGradient.
The simulation models Poiseuille flow with a Reynolds number of 1000, based on a characteristic length of 0.1 m, a maximum velocity of 1 m/s, and the specified kinematic viscosity.
