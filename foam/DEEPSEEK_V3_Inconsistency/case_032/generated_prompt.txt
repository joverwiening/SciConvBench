Simulate the 2D steady-state, turbulent, incompressible flow over a NACA 0012 airfoil at a 5-degree angle of attack.
Use the simpleFoam solver.
Use the k-omega SST turbulence model.
Use a C-grid mesh extruded one cell in the z-direction to create the 2D domain.
In blockMeshDict, name the front and back patches 'frontAndBack' and set their type to 'symmetry'.
Set the boundary conditions in the '0' directory.
For the velocity field U, set the inlet to a fixed value of (10 0 0.1) m/s.
For the velocity field U, set the outlet to zeroGradient.
For the velocity field U, set the airfoil surface to a no-slip wall condition.
For the velocity field U, set the 'frontAndBack' patches to the 'symmetry' condition.
For the pressure field p, set the inlet to zeroGradient.
For the pressure field p, set the outlet to a fixed value of 0.
For the pressure field p, set the airfoil surface to zeroGradient.
For the pressure field p, set the 'frontAndBack' patches to the 'symmetry' condition.
For the turbulent kinetic energy field k, set the inlet using a freestream turbulence intensity of 5%.
For the turbulent kinetic energy field k, set the outlet to zeroGradient.
For the turbulent kinetic energy field k, set the airfoil surface to 'kqRWallFunction'.
For the turbulent kinetic energy field k, set the 'frontAndBack' patches to the 'symmetry' condition.
For the specific dissipation rate field omega, set the inlet using the freestream turbulence intensity and a turbulent viscosity ratio of 10.
For the specific dissipation rate field omega, set the outlet to zeroGradient.
For the specific dissipation rate field omega, set the airfoil surface to 'omegaWallFunction'.
For the specific dissipation rate field omega, set the 'frontAndBack' patches to the 'symmetry' condition.
Assume a chord length of 1 meter for the NACA 0012 airfoil.
Assume a kinematic viscosity of 1.5e-05 m²/s for air at standard conditions.
Assume a span of 0.1 meters for the extruded 2D domain.
Calculate the lift and drag coefficients from the simulation results.
