Simulate the 3D, incompressible, turbulent flow around a cube mounted on the floor of a channel using `simpleFoam` with a RANS `kEpsilon` turbulence model.
Use a fully 3D mesh with more than one cell in the spanwise direction.
Define the spanwise side patches `left` and `right` as symmetry boundaries of type `empty` in `system/blockMeshDict`.
Apply a `noSlip` boundary condition on all solid walls: the floor, the cube, and the top wall.
Apply a fixed inlet velocity on the `inlet` patch.
Apply a fixed outlet pressure on the `outlet` patch.
Set the Reynolds number based on the cube height to 40,000.
Set the cube height (H) to 0.1 meters.
Set the channel height to 3H (0.3 meters).
Set the spanwise width of the domain to 3H (0.3 meters).
Set the length of the channel upstream of the cube to 5H (0.5 meters).
Set the length of the channel downstream of the cube to 15H (1.5 meters).
Set the inlet velocity magnitude to 1.0 m/s.
Set the fluid kinematic viscosity to 2.5e-6 m²/s to achieve the target Reynolds number.
