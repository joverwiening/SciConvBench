Perform a transient simulation of Rayleigh-Bénard convection using buoyantPimpleFoam.
The domain is a 2D rectangle with a width of 0.1 m and a height of 0.01 m.
The aspect ratio (width/height) is 10.
The bottom wall is a fixed temperature boundary at 305 K.
The top wall is a fixed temperature boundary at 295 K.
The side walls are adiabatic (zero gradient) for temperature.
All walls use a no-slip boundary condition for velocity.
The fluid is water, using the Boussinesq approximation.
In constant/thermophysicalProperties, set thermoType to hePsiThermo.
In constant/thermophysicalProperties, set equationOfState to Boussinesq.
Set the reference density (rho0) to 1000 kg/m³.
Set the reference temperature (T0) to 300 K.
Set the thermal expansion coefficient (beta) to 0.000207 K⁻¹.
Set the kinematic viscosity (nu) to 1.0e-6 m²/s.
Set the thermal diffusivity (alpha) to 1.43e-7 m²/s.
This yields a Prandtl number (Pr) of approximately 7.0.
This yields a Rayleigh number (Ra) of approximately 1.4e4.
In system/fvSchemes, for the divergence of temperature, use div(phi,T) Gauss linear.
In system/fvSchemes, for the divergence of velocity, use div(rhoPhi,U) Gauss upwind.
Initialize the temperature field to a linear conductive profile from 305 K (bottom) to 295 K (top).
Initialize the velocity field to zero everywhere.
Set the initial pressure field to the hydrostatic pressure distribution.
Run the simulation for a sufficient duration to capture the transient development of convection rolls.
