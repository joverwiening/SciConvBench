Perform a 2D simulation of heat conduction through a square solid plate using the laplacianFoam solver.
The domain is a 1m x 1m square, one cell thick.
In the blockMeshDict file, define four side patches named 'left', 'right', 'top', and 'bottom'.
In the blockMeshDict file, define the 'frontAndBack' patches.
Set the 'frontAndBack' patches to 'type wall' in blockMeshDict.
In the '0/T' boundary condition file, set the 'left' patch to a fixedValue of 400 K.
In the '0/T' boundary condition file, set the 'right' patch to a fixedValue of 300 K.
In the '0/T' boundary condition file, set the 'top' patch to a zeroGradient boundary condition.
In the '0/T' boundary condition file, set the 'bottom' patch to a zeroGradient boundary condition.
In the '0/T' boundary condition file, set the 'frontAndBack' patches to a zeroGradient boundary condition.
In the '0/T' file, set the internalField to a uniform value of 350 K.
Run the simulation to find the steady-state temperature distribution.
