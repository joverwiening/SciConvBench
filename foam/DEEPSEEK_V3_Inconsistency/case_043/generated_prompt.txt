Simulate heat transfer in a 2D channel with a heated block.
The fluid is air.
The flow is laminar.
Use the `buoyantPimpleFoam` solver.
The channel walls are perfectly insulated (adiabatic).
The inlet has a fixed velocity and a fixed temperature of 300 K.
The block is maintained at a constant temperature of 400 K.
In the `0/T` file, set the boundary condition for `inlet` to `fixedValue` with a `uniform` value of 300.
In the `0/T` file, set the boundary condition for `outlet` to `zeroGradient`.
In the `0/T` file, set the boundary condition for `block` to `fixedValue` with a `uniform` value of 400.
In the `0/T` file, set the boundary condition for `walls` to `zeroGradient`.
