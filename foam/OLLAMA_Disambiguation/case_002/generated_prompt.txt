Create a blockMeshDict with the following geometry: vertices at (0 0 0), (9 0 0), (9 1 0), (0 1 0), (0 0 1), (9 0 1), (9 1 1), (0 1 1); a single hexahedral block using these vertices with cell counts (90 10 1) and simpleGrading (1 1 1). Define six boundary patches: bottom, top, left, and right as type wall; front and back as type empty.

Set the controlDict parameters: startTime 0, endTime 1000, deltaT 1 (fixed, no adjustTimeStep), writeInterval 50, and writeControl timeStep.

Use the buoyantFoam solver with gravity vector (0 -9.81 0) acting in the negative y direction.

In constant/physicalProperties, use heRhoThermo with equationOfState Boussinesq; set molWeight 29, rho0 1.0, T0 300, beta 3.3e-3, Cv 714.3, Hf 0, mu 1.5e-5, and Pr 0.714.

In constant/momentumTransport, set simulationType RAS, RASModel kEpsilon, turbulence on, and printCoeffs on; do not use any laminar settings.

In the 0 folder, define the following fields:
- U: internalField uniform (0 0 0); boundary condition noSlip on all wall patches and empty on front and back.
- T: internalField uniform 300; bottom fixedValue 305, top fixedValue 295, left and right zeroGradient, front and back empty.
- k: internalField uniform 1e-5; kqRWallFunction on wall patches, empty on front and back.
- epsilon: internalField uniform 1e-5; epsilonWallFunction on wall patches, empty on front and back.
- nut: internalField uniform 0; nutkWallFunction on wall patches, empty on front and back.
- alphat: internalField uniform 0; compressible::alphatJayatillekeWallFunction on wall patches with Prt 0.85, empty on front and back.
- p: internalField uniform 0; calculated on wall patches, empty on front and back.
- p_rgh: internalField uniform 0; fixedFluxPressure on wall patches, empty on front and back.

Initialize the flow at rest with the uniform temperature field of 300 K.

In system/fvSolution, set solvers for p_rgh, U, k, and epsilon to have tolerance 1e-8 and relTol 0.01; set the corresponding finalSolvers to have relTol 0. Ensure the same tolerance and relTol are used for any coupled solvers (e.g., (U|e|k|epsilon)).
