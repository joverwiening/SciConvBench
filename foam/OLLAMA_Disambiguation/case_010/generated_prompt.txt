Create a square cavity with dimensions 1 unit in x, 1 unit in y, and 0.1 unit in z.  
Generate a structured mesh with 20 cells in the x‑direction, 20 cells in the y‑direction, and 1 cell in the z‑direction.  
Assign the top wall as “movingWall” with a uniform velocity U = (1 m/s, 0, 0).  
Assign the left, right, and bottom walls as “fixedWalls” with a no‑slip condition U = (0, 0, 0).  
Set the front and back faces as “empty”.  
Use incompressible flow with constant kinematic viscosity ν = 1e‑5 m²/s.  
Select the k‑epsilon turbulence model.  
Initialize the turbulence fields:  
‑ k = 1.5e‑4 uniformly in the domain and apply kqRWallFunction on all physical walls (excluding empty faces).  
‑ ε = 1.4e‑4 uniformly in the domain and apply epsilonWallFunction on all physical walls (excluding empty faces).  
‑ νₜ (nut) = 0 uniformly in the domain and apply nutkWallFunction on all physical walls (excluding empty faces).  
Use the pisoFoam solver.  
Initialize the velocity field U = (0, 0, 0) everywhere at the start of the simulation.  
Set the transient control: startTime = 0, endTime = 10, timeStep = 0.005, resulting in 2000 steps; write results every 100 steps (writeInterval = 0.5).  
Specify the convection and diffusion discretisation schemes:  
‑ div(phi,U) = Gauss limitedLinearV 1  
‑ div(phi,k) = Gauss limitedLinear 1  
‑ div(phi,ε) = Gauss limitedLinear 1  
‑ div((nuEff*dev2(T(grad(U))))) = Gauss linear.  
Use default solver relaxation factors and other OpenFOAM settings unless otherwise required.
