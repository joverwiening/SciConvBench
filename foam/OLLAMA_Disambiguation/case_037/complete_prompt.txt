Problem: Simulate steady-state, turbulent, compressible, supersonic (~ Mach 2) air flow through a porous filter in a 2D duct.
Solver: rhoPorousSimpleFoam
Geometry: A 2D duct of dimensions 0.5m (L) x 0.1m (H) x 0.01m (W). The porous filter is a zone from x=0.2m to x=0.25m.
Mesh: Use blockMesh with 250 cells in x, 50 in y, and 1 in z. Patches: 'inlet', 'outlet', 'topAndBottomWalls', 'frontAndBack'.
Porous Properties (system/fvOptions): Use a 'porosity' source term applied to a cellZone 'porousFilter'. Set Darcy-Forchheimer coefficients: d = (5e7 5e7 0); f = (500 500 0).
Thermodynamic Properties (constant/thermophysicalProperties): Use 'hePsiThermo' with a 'perfectGas' equation of state and 'sutherland' transport for viscosity. MolWeight=28.9, Cp=1005, R=287.
Turbulence (constant/momentumTransport): Use RAS with the k-omega SST model.
Initial Conditions (0/): Initialize with p=101325, T=300, U=(0 0 0), k=0.003, omega=10.
Boundary Conditions (0/U, p, T, k, omega):
- inlet: type supersonicFreestream; U (700 0 0); p 101325; T 300. Use freestream values for k and omega.
- outlet: type waveTransmissive; p 101325; T 300.
- topAndBottomWalls: U noSlip; T zeroGradient (adiabatic); k kqRWallFunction; omega omegaWallFunction.
- frontAndBack: empty.
Time Controls (system/controlDict): Steady-state. stopAt endTime; endTime 1000; deltaT 1; writeInterval 100.
