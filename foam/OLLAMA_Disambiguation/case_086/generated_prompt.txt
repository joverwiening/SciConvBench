Set up a 3‑D case for rhoCentralFoam with the computational domain spanning from (0 0 0) to (1 0.1 0.1) m.  
Create a hexahedral mesh with 400 cells in the x‑direction and 1 cell in each of the y‑ and z‑directions.  
Assign the left half of the domain (x < 0.5 m) an initial density of 1.0 kg m⁻³, pressure of 100 000 Pa, and velocity (0 0 0) m s⁻¹.  
Assign the right half of the domain (x ≥ 0.5 m) an initial density of 0.125 kg m⁻³, pressure of 10 000 Pa, and velocity (0 0 0) m s⁻¹.  
Define the fluid as an ideal gas with Cp = 1005 J kg⁻¹ K⁻¹, γ = 1.4, giving Cv ≈ 718 J kg⁻¹ K⁻¹ and gas constant R ≈ 287 J kg⁻¹ K⁻¹; compute the initial temperature from p = ρ R T.  
Apply slip wall boundary conditions on the left (x = 0 m) and right (x = 1 m) patches, using zero‑gradient for pressure and temperature and zero normal velocity for the slip condition.  
Set the simulation end time to 0.007 s and use rhoCentralFoam with its default time‑step control (CFL‑based) unless otherwise specified.  
Write the case files (system/controlDict, fvSchemes, fvSolution, constant/thermophysicalProperties, 0/U, 0/p, 0/T) accordingly and run the solver.
