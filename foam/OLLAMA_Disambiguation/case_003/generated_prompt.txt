Create a rectangular cavity domain 9 units wide (x-direction) and 1 unit tall (y-direction) with a single cell extruded in the spanwise (z) direction; treat the front and back patches as empty to enforce two-dimensionality.
Generate a mesh with 90 cells in the x direction, 10 cells in the y direction, and 1 cell in the z direction.
Assign gravity acting downward in the negative y direction.
Use the buoyantFoam solver.
Define the reference state as air-like with density 1.0 kg/m³, reference temperature 300 K, thermal expansion coefficient 3.3e-3 1/K, kinematic viscosity 1.5e-5 m²/s, and thermal diffusivity 2.1e-5 m²/s (Pr ≈ 0.7).
Set the bottom wall patch name to “bottom”, the top wall patch name to “top”, and the two vertical side wall patches to “sideWalls”.
Apply a fixed temperature of 305 K on the bottom wall, a fixed temperature of 295 K on the top wall, and adiabatic (zeroGradient) condition on the sideWalls.
Apply no-slip velocity condition on all solid walls (bottom, top, sideWalls).
Initialize the velocity field U with uniform (0 0 0) and the temperature field T with uniform 300 K throughout the domain.
Use a fixed time step deltaT = 1 s; do not enable adjustTimeStep, maxCo, or maxDeltaT.
Simulate for a total physical time of 1000 s and write results every 50 time steps.
Employ the RAS k‑epsilon turbulence model; set constant/momentumTransport to simulationType RAS with model kEpsilon, turbulence on, and printCoeffs on; do not use any laminar settings.
In constant/physicalProperties use heRhoThermo with equationOfState Boussinesq; set molWeight = 29, rho0 = 1.0, T0 = 300, beta = 3.3e-3, Cv = 714.3, Hf = 0, mu = 1.5e-5, and Pr = 0.714.
In 0/k set internalField uniform 1e-5, apply kqRWallFunction on bottom, top, and sideWalls, and set front and back patches to empty.
In 0/epsilon set internalField uniform 1e-5, apply epsilonWallFunction on bottom, top, and sideWalls, and set front and back patches to empty.
In 0/nut set internalField uniform 0, apply nutkWallFunction on bottom, top, and sideWalls, and set front and back patches to empty.
In 0/alphat set internalField uniform 0, apply compressible::alphatJayatillekeWallFunction on bottom, top, and sideWalls, set Prt = 0.85, and set front and back patches to empty.
In 0/U set internalField uniform (0 0 0), apply noSlip on bottom, top, and sideWalls, and set front and back patches to empty.
In 0/T set internalField uniform 300, apply fixedValue 305 on bottom, fixedValue 295 on top, zeroGradient on sideWalls, and set front and back patches to empty.
In 0/p set internalField uniform 0, calculate wall values, and set front and back patches to empty.
In 0/p_rgh set internalField uniform 0, apply fixedFluxPressure on bottom, top, and sideWalls, and set front and back patches to empty.
In system/fvSolution set the solvers for p_rgh and the coupled (U|e|k|epsilon) fields to tolerance 1e-8 and relative tolerance 0.01; set the corresponding *Final solvers to relative tolerance 0.
