Problem: 3D incompressible turbulent channel flow using a RANS model.
Solver: simpleFoam (for a steady-state solution).
Turbulence Model: In constant/momentumTransport, set simulationType to RAS and the RASModel to kEpsilon.
Geometry: A channel with dimensions 1m (length, x) x 0.1m (height, y) x 0.2m (width, z).
Mesh: Use blockMesh to create a 100x20x10 mesh. Patches are 'inlet', 'outlet', 'bottomWall', 'topWall', and 'frontAndBack'. The frontAndBack patches should be of type 'cyclic'.
Physical Properties: In constant/transportProperties, set kinematic viscosity 'nu' to 1e-5 m^2/s.
Initial Conditions: In the 0/ directory, initialize U to uniform (0.1 0 0), p to uniform 0, k to uniform 0.000375, and epsilon to uniform 1.875e-4.
Boundary Conditions:
- U: inlet/outlet are cyclic; topWall/bottomWall are noSlip.
- p: inlet/outlet are cyclic; topWall/bottomWall are zeroGradient. The pressure gradient is enforced via fvOptions by adding a meanVelocityForce source to drive the bulk velocity to 0.5 m/s.
- k: inlet/outlet are cyclic; topWall/bottomWall use kqRWallFunction with value uniform 0.000375.
- epsilon: inlet/outlet are cyclic; topWall/bottomWall use epsilonWallFunction with value uniform 1.875e-4.
- nut: inlet/outlet are cyclic; topWall/bottomWall use nutkWallFunction with value uniform 0.
Time Controls: In system/controlDict, set application to simpleFoam, startTime to 0, endTime to 1000, deltaT to 1. The simulation will stop when residuals fall below the tolerance specified in fvSolution.
Solution Control: In system/fvSolution, use GAMG for p with tolerance 1e-6, and smoothSolver for U, k, epsilon with tolerance 1e-5. Use the SIMPLE algorithm for pressure-velocity coupling.
