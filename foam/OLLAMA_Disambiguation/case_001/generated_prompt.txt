Create a case directory with the standard OpenFOAM folder structure (constant, 0, system).  
Use the buoyantFoam solver and set gravity to (0 -9.81 0) m s⁻².  

In constant/physicalProperties define a heRhoThermo model with equationOfState Boussinesq; set molWeight 29, rho0 1.0 kg m⁻³, T0 300 K, beta 3.3e-3 K⁻¹, Cv 714.3 J kg⁻¹ K⁻¹, Hf 0, mu 1.5e-5 m² s⁻¹, and Pr 0.714.  

In constant/turbulenceProperties set simulationType RAS, RASModel kEpsilon, turbulence on, printCoeffs on, and do not include any laminar settings.  

In constant/transportProperties set kinematic viscosity nu 1.5e-5 m² s⁻¹ and thermal diffusivity alphat 2.1e-5 m² s⁻¹ (Pr ≈ 0.7).  

Generate the mesh with blockMesh: domain size 9 units in the x‑direction, 1 unit in the y‑direction, and 1 unit in the z‑direction; use 90 cells in x, 10 cells in y, and 1 cell in z.  

In the 0 folder set the following fields:  

- 0/U: internalField uniform (0 0 0); boundary condition noSlip on all solid walls; empty on front and back.  
- 0/T: internalField uniform 300 K; bottom wall fixedValue 305 K, top wall fixedValue 295 K, side walls zeroGradient; empty on front and back.  
- 0/p: internalField uniform 0; boundary condition calculated on all walls; empty on front and back.  
- 0/p_rgh: internalField uniform 0; boundary condition fixedFluxPressure on all walls; empty on front and back.  
- 0/k: internalField uniform 1e-5; kqRWallFunction on walls; empty on front and back.  
- 0/epsilon: internalField uniform 1e-5; epsilonWallFunction on walls; empty on front and back.  
- 0/nut: internalField uniform 0; nutkWallFunction on walls; empty on front and back.  
- 0/alphat: internalField uniform 0; compressible::alphatJayatillekeWallFunction on walls with Prt 0.85; empty on front and back.  

In system/controlDict set startTime 0, endTime 1000, deltaT 1, writeInterval 50, and use the default timeScheme settings.  

In system/fvSolution define solvers for p_rgh, U, e, k, and epsilon with tolerance 1e-8 and relTol 0.01; set the corresponding finalSolvers with relTol 0.  

Use default fvSchemes unless specific schemes are required.  

Run the case with buoyantFoam; the simulation will advance 1000 time steps of 1 s each, writing results every 50 steps.
