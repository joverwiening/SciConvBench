Create a 1 m × 1 m square domain and generate a 40 × 40 uniform hexahedral mesh.  
Use the solver **pimpleFoam** for a transient incompressible laminar flow simulation.  
Set the kinematic viscosity **nu** to 1e‑4 m² s⁻¹ in `constant/transportProperties`.  
Define the following patches in `0/U` and `0/p`:  

- **fixedWalls** (left, right, bottom):  
  - Velocity `U` = `fixedValue` uniform (0 0 0) m s⁻¹ (no‑slip).  
  - Pressure `p` = `fixedFluxPressure` uniform 0 Pa.  

- **movingWall** (top):  
  - Velocity `U` = `fixedValue` uniform (1 0 0) m s⁻¹.  
  - Pressure `p` = `fixedFluxPressure` uniform 0 Pa.  

Set the initial fields in the `0` directory:  

- Velocity `U` = uniform (0 0 0) m s⁻¹.  
- Pressure `p` = uniform 0 Pa.  

Configure the time‑stepping in `system/controlDict` as:  

```
startTime       0;
endTime         5;
adjustTimeStep  yes;
maxCo           1.0;
maxDeltaT       0.05;
writeInterval   0.1   // optional, adjust as needed
```

Use default `pimpleProperties` for a laminar run (no turbulence model).  
Run the case with `pimpleFoam` until the simulation time reaches **t = 5 s**.
