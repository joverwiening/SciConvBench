Simulate a 2D lid‑driven cavity flow using icoFoam.  
Set the cavity domain to a square of side length 0.1 m (0 ≤ x ≤ 0.1, 0 ≤ y ≤ 0.1).  
Create a uniform Cartesian mesh with 20 cells in the x‑direction and 20 cells in the y‑direction (cell size 0.005 m).  
Define three boundary patches:  
- movingWall (top lid, y = 0.1 m)  
- fixedWalls (left, right, and bottom walls)  
- frontAndBack (z‑faces) as empty for a 2D case.  
Set the fluid kinematic viscosity ν = 0.001 m²/s in constant/transportProperties.  
Apply the following velocity (U) boundary conditions:  
- movingWall: fixedValue uniform (1 0 0) m s⁻¹  
- fixedWalls: noSlip  
- frontAndBack: empty  
Apply the following pressure (p) boundary conditions:  
- movingWall and fixedWalls: zeroGradient  
- frontAndBack: empty  
Initialize the fields at time 0:  
- U uniform (0 0 0) m s⁻¹  
- p uniform 0 Pa (relative pressure).  
In system/controlDict set:  
- startTime 0  
- endTime 0.5  
- deltaT 0.002  
- writeInterval 20  
- adjustTimeStep no  
- maxCo 0.5 (or appropriate Courant number).  
Use the default icoFoam solver settings (PISO algorithm) for a transient incompressible simulation.  
Run the case with blockMesh, then icoFoam, and post‑process the results saved every 20 time steps.
