Set up a 2‑D rectangular domain of size 1 m × 1 m discretized with 50 cells in the x‑direction and 50 cells in the y‑direction. Use air with reference density ρ₀ = 1 kg m⁻³, kinematic viscosity ν = 1 × 10⁻⁵ m² s⁻¹, Prandtl number Pr = 0.71, and thermal expansion coefficient β = 3.4 × 10⁻³ K⁻¹. Apply a gravitational acceleration of 9.81 m s⁻² in the negative y‑direction. Impose no‑slip velocity on all walls. Set the bottom wall temperature to a fixed value of 300 K and the top wall temperature to a fixed value of 290 K; side walls have zero‑gradient temperature. Use fixedFluxPressure for pressure on all walls. Initialise the temperature field uniformly at 295 K and add a small perturbation of 0.1 K in a thin box region (0.45 ≤ x ≤ 0.55, 0 ≤ y ≤ 0.05). Run the case as a transient laminar simulation with a constant time step of 0.05 s, enable adjustTimeStep with maxCo = 0.8, and simulate from startTime = 0 s to endTime = 200 s. Use the transient buoyant Boussinesq solver buoyantBoussinesqPimpleFoam.
