Set up a two‑dimensional inviscid (Euler) simulation of supersonic flow over a forward‑facing step.  
Define a rectangular channel 1 m high and 3 m long in the x‑direction.  
Place a forward‑facing step of height 0.2 m (20 % of the channel height) at x = 0.6 m; the inlet section extends 0.6 m upstream of the step and the outlet section extends 2.4 m downstream, ending at x = 3 m.  
Create a mesh with approximately 150 cells in the streamwise (x) direction and 50 cells in the vertical (y) direction, giving an average cell size of about 0.02 m; apply local refinement near the step corner and anticipated shock paths.  
Set the front and back faces to *empty* to enforce a 2‑D model.  
Apply the following boundary conditions:  
- Inlet (x = 0): Mach 3 inflow with static pressure 101 325 Pa and static temperature 300 K.  
- Outlet (x = 3 m): waveTransmissive condition with fixed static pressure pInf = 101 325 Pa.  
- Top and bottom walls and the step surface: slip (zero normal velocity, zero shear stress) to represent inviscid flow.  
Configure the solver for a transient (time‑dependent) case using the compressible Euler equations.  
Enable an adjustable time step (`adjustTimeStep yes`) and limit the Courant number to maxCo = 0.7; the solver will compute Δt automatically (approximately 1 × 10⁻⁶ s for the given mesh).  
Run the simulation until the physical time reaches 0.005 s (`endTime 0.005`).  
Use default residual tolerances for the Euler solver; the simulation stops when the specified end time is reached.
