Simulate steady‑state, incompressible, laminar flow of water (ρ = 1000 kg m⁻³, μ = 0.001 Pa·s) through a porous medium using a Darcy‑Forchheimer model.  
The computational domain is rectangular with length 0.5 m (streamwise), height 0.1 m (vertical), and depth 1 m (spanwise) for a 2‑D representation.  
Apply a fixed inlet velocity of 1 m s⁻¹ uniform in the streamwise direction (U = (1 0 0) m s⁻¹) on the left boundary.  
Set the outlet (right boundary) pressure to a fixed value of 0 Pa (fixedValue uniform 0) and use a zeroGradient condition for velocity.  
Use no‑slip (zeroVelocity) on the top and bottom walls.  
Define the permeability tensor of the porous zone as k = diag(1e‑8, 1e‑8, 1e‑10) m².  
Set the linear Darcy resistance coefficients d = (1e⁸, 1e⁸, 1e¹⁰) m⁻², which are the inverses of the permeability components.  
Set the quadratic Forchheimer resistance coefficient f = (0, 0, 0) (pure Darcy flow).  
Assume the porous medium occupies the entire domain.  
Use a steady‑state incompressible solver (e.g., simpleFoam) with laminar flow settings and include the Darcy‑Forchheimer source term based on the specified d and f values.  
Generate a structured mesh fine enough to resolve the flow, for example 100 cells along the length and 20 cells along the height, with unit depth.  
Run the simulation until residuals drop below 1e‑6 for continuity and momentum.
