Simulate steady-state, incompressible, laminar flow through a porous medium using the porousSimpleFoam solver.
GEOMETRY: The domain is a 2D channel, 0.5 m long and 0.1 m high. A porous zone is defined in the central region, from x=0.2 to x=0.3.
MESH: Use blockMesh to create a uniform Cartesian mesh of (100 x 20 x 1) cells.
PHYSICAL PROPERTIES: The fluid is water with a kinematic viscosity nu = 1e-6 m^2/s, defined in 'constant/transportProperties'.
POROUS MEDIA: The porous zone is defined in 'constant/fvOptions' using a 'porosity' source term. The model is 'DarcyForchheimer' with coefficients d = (1e8 1e8 1e10) and f = (0 0 0).
INITIAL & BOUNDARY CONDITIONS (in '0/' directory):
- U: inlet (left patch) is fixedValue uniform (1 0 0); outlet (right patch) is zeroGradient; top and bottom patches are noSlip walls; front and back patches are empty.
- p: inlet is zeroGradient; outlet is fixedValue uniform 0; walls are zeroGradient; front and back are empty.
TIME CONTROLS: In 'system/controlDict', set application = porousSimpleFoam, startFrom = startTime, startTime = 0, stopAt = endTime, endTime = 500, deltaT = 1. The simulation is steady-state, so endTime is the number of iterations.
