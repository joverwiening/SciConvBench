The computational domain is a rectangular box 0.5 m long, 0.1 m high, and 0.01 m deep (effectively 2‑D).  
A solid porous block is centered in the domain with dimensions 0.1 m long, 0.05 m high, and 0.01 m deep; the fluid region occupies the remainder of the box.  
The fluid is air modeled as a compressible perfect gas using heRhoThermo + perfectGas + Sutherland with standard air properties (Cp ≈ 1005 J kg⁻¹ K⁻¹, molWeight ≈ 28.9 kg kmol⁻¹, etc.).  
At the inlet (x = 0) a uniform velocity U = (1 0 0) m s⁻¹ and a fixed temperature T = 400 K are imposed.  
At the outlet (x = 0.5 m) the pressure p_rgh is fixed to 0, the velocity U has a zeroGradient condition, and the temperature T uses an inletOutlet condition with inletValue = 300 K and value = 300 K.  
The solid porous block is modeled as an effective homogeneous solid using heSolidThermo with density ρ = 500 kg m⁻³, specific heat Cp = 900 J kg⁻¹ K⁻¹, and thermal conductivity kappa = 10 W m⁻¹ K⁻¹; no momentum equations are solved in the solid.  
The porosity of the solid porous block is assumed to be 0.85 (a typical value for aluminum‑foam).  
The case is solved as a steady‑state simulation using the solver chtMultiRegionSimpleFoam.  
All thermophysicalProperties files are set accordingly for the fluid and solid regions.
