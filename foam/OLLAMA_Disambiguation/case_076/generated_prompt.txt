Set up a two‑dimensional dam‑break case using the interFoam solver for two incompressible, immiscible fluids (water and air).  
Create a rectangular tank with length 0.5715 m in the x‑direction, width 0.01 m in the y‑direction (empty direction), and height 0.4 m in the z‑direction.  
Place an initial water column that occupies the region from the left wall (x = 0) to x = 0.1461 m and from the bottom (z = 0) up to z = 0.2922 m; set the water volume fraction α.water = 1 in this region and α.water = 0 elsewhere (air).  
Assign fluid properties: water density 1000 kg m⁻³, dynamic viscosity 0.001 Pa·s; air density 1 kg m⁻³, dynamic viscosity 1.48 × 10⁻⁵ Pa·s.  
Use gravity vector g = (0 ‑9.81 0) acting in the negative y‑direction, with the y‑axis defined as vertical.  
Generate the mesh with blockMesh using 114 cells in the x‑direction, 80 cells in the y‑direction, and 1 cell in the z‑direction.  
Set the simulation time from startTime = 0 to endTime = 1.0 s.  
Enable adaptive time stepping with adjustTimeStep yes, initial deltaT = 0.001 s, and a maximum Courant number of 1.0.  
Apply boundary conditions:  
- lowerWall, leftWall, rightWall (solid walls): velocity U = noSlip, pressure p_rgh = fixedFluxPressure, α.water = zeroGradient.  
- top (atmosphere): velocity U = pressureInletOutletVelocity with inletValue (0 0 0), pressure p_rgh = totalPressure with reference pressure p0 = 0, α.water = inletOutlet with inletValue 0 and value 0.  
- frontAndBack (empty direction): U, p_rgh, and α.water set to empty.  
Initialize the velocity field U to zero everywhere.  
Run the case with the default interFoam numerical schemes and solver tolerances unless otherwise required.
