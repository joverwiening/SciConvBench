Simulate a compressible, high‑speed lid‑driven cavity flow in a square cavity 1 m long and 1 m high.  
Model the fluid as air using the perfect‑gas equation of state with Sutherland viscosity, reference temperature 300 K and reference pressure 101 325 Pa.  
Set the lid to move horizontally at a constant velocity of 100 m/s.  
Apply isothermal wall boundary conditions at 300 K on all stationary walls (no‑slip) and on the moving lid (no‑slip with the specified velocity).  
Use the RANS k‑omega SST turbulence model.  
Run the transient simulation with the compressible solver rhoPimpleFoam.  
Integrate for a total physical time of 0.2 s.  
Start with an initial time step Δt = 1 × 10⁻⁶ s, enable adjustTimeStep, and limit the Courant number to a maximum of 0.7.  
Generate a mesh covering the cavity domain; the mesh resolution must be sufficient to resolve the boundary layers and turbulent structures for the chosen turbulence model (user to define the specific cell count or target cell size).
