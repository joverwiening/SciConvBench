Run interFoam for a transient laminar two‑phase dam‑break simulation in a cubic domain from (0 0 0) to (1 1 1).

Place a solid rectangular obstacle occupying the region from (0.375 0.375 0) to (0.625 0.625 0.25) and treat it as a stationary no‑slip wall using a cell zone and an fvOption.  
Set gravity to (0 0 -9.81) m s⁻².  
Define the two phases in transportProperties: water density = 1000 kg m⁻³, kinematic viscosity = 1.0e‑6 m² s⁻¹; air density = 1 kg m⁻³, kinematic viscosity = 1.48e‑5 m² s⁻¹.  
Use a laminar flow model (no turbulence model).  
Initialize the volume fraction field alpha.water to 1 inside the rectangular water column from (0 0 0) to (0.6 0.1875 0.75) and to 0 elsewhere.  
Set the initial velocity field U to (0 0 0) everywhere at time 0.  
Apply boundary conditions:  
- Top face (z = 1) – open atmosphere: U = zeroGradient, p_rgh = fixedValue 0, alpha.water = zeroGradient.  
- All other faces (x = 0, x = 1, y = 0, y = 1, z = 0) – walls: U = fixedValue (0 0 0), p_rgh = zeroGradient, alpha.water = zeroGradient.  
Set the time step deltaT to 1e‑3 s, final simulation time endTime to 0.1 s, and write results every 0.02 s (writeInterval = 0.02).  
Configure the controlDict, fvSchemes, and fvSolution with standard second‑order spatial discretization and implicit time integration suitable for interFoam.  
Run the case and post‑process the results to observe the dam‑break wave interaction with the internal obstacle.
