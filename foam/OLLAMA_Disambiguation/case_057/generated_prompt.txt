Create a new OpenFOAM case for a 2‑D turbulent channel flow using pisoFoam and the k‑epsilon turbulence model.

Define the geometry with blockMesh:
- Channel length = 2 m, height = 0.1 m, depth = 0.01 m.
- Mesh: 200 cells in the streamwise (x) direction, 20 cells in the vertical (y) direction, 1 cell in the depth (z) direction, giving Δx = 0.01 m, Δy = 0.005 m, Δz = 0.01 m.
- Use a single‑cell thickness in z to keep the case effectively 2‑D.

Set fluid properties in constant/transportProperties:
- Density ρ = 1000 kg m⁻³.
- Kinematic viscosity ν = 1 × 10⁻⁵ m² s⁻¹.

Configure turbulence model in constant/turbulenceProperties:
- Choose the kEpsilon model.

Specify initial and boundary conditions in the 0 folder:

U:
- inlet (patch “inlet”): fixedValue (1 0 0) m s⁻¹.
- outlet (patch “outlet”): zeroGradient.
- topWall and bottomWall: noSlip.

p:
- inlet: zeroGradient.
- outlet: fixedValue 0 (zero gauge pressure).
- walls: zeroGradient.

k:
- inlet: fixedValue 3.75e-3.
- outlet: zeroGradient.
- topWall and bottomWall: kqRWallFunction.

epsilon:
- inlet: fixedValue 0.017.
- outlet: zeroGradient.
- topWall and bottomWall: epsilonWallFunction.

nut (optional):
- walls: nutkWallFunction.
- other patches: zeroGradient.

Set simulation control parameters in system/controlDict:
- startTime 0.
- endTime 5.
- deltaT 0.001.
- writeInterval 0.1 (or another suitable interval).
- solver pisoFoam.

Define discretisation schemes in system/fvSchemes appropriate for transient, convection, diffusion, and turbulence terms (e.g., Euler for time, Gauss linear for gradients, limitedLinear for convection).

Define solver settings and relaxation factors in system/fvSolution for p, U, k, epsilon, and nut (use standard pisoFoam defaults or typical values).

Run the case:
1. blockMesh to generate the mesh.
2. pisoFoam to perform the transient simulation for the specified 5 s with Δt = 0.001 s.

Post‑process results (velocity, pressure, turbulent kinetic energy, and dissipation) using paraFoam or other visualization tools.
