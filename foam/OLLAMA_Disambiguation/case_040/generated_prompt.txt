Create a rectangular computational domain 5 m (x) × 2 m (y) × 0.1 m (z) and generate a mesh that resolves the domain (e.g., uniform cells of 0.01 m in x and y).  
Define a cell zone named “porousDam” that occupies the block from x = 2 m to x = 3 m, y = 0 m to y = 2 m, and the full z‑thickness.  
Add an fvOptions entry for the porous dam using a Darcy‑Forchheimer source:  
```
explicitPorositySourceCoeffs
{
    type DarcyForchheimer;
    d (1e6 1e6 0);
    f (100 100 0);
}
```  
Set the fluid properties in constant/transportProperties: density ρ = 1000 kg m⁻³, dynamic viscosity μ = 0.001 Pa·s.  
Use the interFoam solver (two‑phase VOF water–air).  
Initialize the fields at time 0: velocity U = (0 0 0) everywhere, pressure p_rgh = 0 Pa everywhere, and phase fraction alpha.water = 1 in the rectangular water column defined by x = 0 m to 1 m, y = 0 m to 1.5 m (full z‑thickness) and alpha.water = 0 elsewhere. Implement this initialization with system/setFieldsDict.  
Apply the following boundary conditions on all six domain faces:  
- leftWall, rightWall, bottomWall (solid walls): U = noSlip, p_rgh = fixedFluxPressure, alpha.water = zeroGradient.  
- atmosphere (top open boundary): U = pressureInletOutletVelocity with inletValue (0 0 0), p_rgh = totalPressure with p0 uniform 0, alpha.water = inletOutlet with inletValue 0 and value 0.  
- frontAndBack (empty direction): U = empty, p_rgh = empty, alpha.water = empty.  
Set the simulation control in system/controlDict: startTime = 0, endTime = 10 s, appropriate timeStep (e.g., 0.001 s) and writeInterval (e.g., every 0.1 s).  
Run interFoam for the transient simulation and post‑process the evolution of the water front through the porous dam.
