Run a two-dimensional Rayleigh‑Benard convection simulation in a rectangular cavity that is 9 units wide (x‑direction) and 1 unit tall (y‑direction) with a spanwise (z‑direction) length of 1 unit to represent a single extruded cell.  
Create a structured mesh with 90 cells in the x‑direction, 10 cells in the y‑direction, and 1 cell in the z‑direction.  
Use the buoyantFoam solver with gravity acting in the negative y‑direction.  
Define the reference state as air‑like: density ρ₀ = 1.0 kg m⁻³, reference temperature T₀ = 300 K, thermal expansion coefficient β = 3.3e‑3 K⁻¹, kinematic viscosity ν = 1.5e‑5 m² s⁻¹, thermal diffusivity α = 2.1e‑5 m² s⁻¹ (Pr ≈ 0.7).  

In constant/physicalProperties set the thermophysical model to heRhoThermo with equationOfState Boussinesq and specify: molWeight = 29, rho0 = 1.0, T0 = 300, beta = 3.3e‑3, Cv = 714.3, Hf = 0, mu = 1.5e‑5, Pr = 0.714.  

Boundary and initial fields:  

- 0/k: internalField uniform 1e‑5; apply kqRWallFunction on all solid walls; front and back patches are empty.  
- 0/epsilon: internalField uniform 1e‑5; apply epsilonWallFunction on all solid walls; front and back patches are empty.  
- 0/nut: internalField uniform 0; apply nutkWallFunction on all solid walls; front and back patches are empty.  
- 0/alphat: internalField uniform 0; apply compressible::alphatJayatillekeWallFunction on all solid walls, set Prt = 0.85; front and back patches are empty.  
- 0/U: internalField uniform (0 0 0); impose noSlip on all solid walls; front and back patches are empty.  
- 0/T: internalField uniform 300 K; bottom wall fixedValue 305 K, top wall fixedValue 295 K, vertical side walls zeroGradient; front and back patches are empty.  
- 0/p: internalField uniform 0; walls calculated; front and back patches are empty.  
- 0/p_rgh: internalField uniform 0; walls fixedFluxPressure; front and back patches are empty.  

Initialize the flow at rest with a uniform temperature field of 300 K throughout the domain.  

In system/fvSolution set the solvers for p_rgh and the coupled fields (U, e, k, epsilon) to have tolerance 1e‑8 and relative tolerance 0.01; set the corresponding *Final solvers to relative tolerance 0.  

Time control: use a fixed time step Δt = 1 s and run the simulation for a total physical time of 1000 s.
