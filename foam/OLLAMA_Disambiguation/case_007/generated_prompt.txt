Create a 3‑D blockMesh for a unit square cavity (length 1 m in x and y) with a single cell in the z‑direction, resulting in a 20 × 20 × 1 uniform mesh (cell size 0.05 m in x and y). Define the following boundary patches: top wall named “movingWall”, bottom, left and right walls grouped as “fixedWalls”, and the front and back faces named “front” and “back” respectively. Set the front and back patches as type empty.

Assign velocity boundary conditions: “movingWall” – fixedValue (1 0 0) m s⁻¹; “fixedWalls” – fixedValue (0 0 0) m s⁻¹ (no‑slip); “front” and “back” – empty (zeroGradient). Initialise the velocity field U to (0 0 0) everywhere at time 0.

Set fluid properties: incompressible constant density (ρ = 1 kg m⁻³) and kinematic viscosity ν = 1e‑5 m² s⁻¹.

Use the k‑epsilon turbulence model. Initialise turbulence fields at time 0 as follows:
- k – uniform 1.5e‑4 m² s⁻² with kqRWallFunction on all wall patches (including front and back empty patches).
- ε – uniform 1.4e‑4 m² s⁻³ with epsilonWallFunction on all wall patches (including front and back empty patches).
- nut – uniform 0 m² s⁻¹ with nutkWallFunction on all wall patches (including front and back empty patches).

Select the solver pisoFoam. Configure the PISO algorithm with default settings (e.g., nCorrectors = 2, nNonOrthogonalCorrectors = 0).

Define the discretisation schemes in fvSchemes:
- div(phi,U) Gauss limitedLinearV 1
- div(phi,k) Gauss limitedLinear 1
- div(phi,epsilon) Gauss limitedLinear 1
- div((nuEff*dev2(T(grad(U))))) Gauss linear

Use default interpolation and gradient schemes unless otherwise required.

Set the time control in controlDict:
- startTime 0
- endTime 10
- deltaT 0.005 (constant time step)
- writeControl timeStep
- writeInterval 100 (output every 100 steps, i.e., every 0.5 s)
- purgeWrite 0
- adjustTimeStep no
- maxCo 0.5 (or appropriate Courant number)

Run the simulation from t = 0 to t = 10, writing results every 0.5 s. The simulation will capture the incompressible lid‑driven cavity flow with the specified turbulence model and boundary conditions.
