All walls are no‑slip, adiabatic, and have zeroGradient conditions for species and pressure.  
The outlet uses zeroGradient for all variables and a fixedValue pressure of 101 325 Pa.  
Use laminar flow (no turbulence model) with the default compressible laminar transport properties.  
Employ the simple one‑step irreversible methane‑air reaction defined in constant/combustionProperties (reaction “methaneAir” with Arrhenius parameters A = 2.119 × 10¹¹, β = 0, Ta = 2.027 × 10⁸ K) and the janaf thermodynamic database.  
Initialize the entire domain with the inlet conditions (U = 0.5 m s⁻¹, T = 300 K, p = 101 325 Pa, stoichiometric species fractions).  
Run reactingFoam from t = 0 s to endTime = 0.1 s with an adaptive time step starting at Δt = 1 × 10⁻⁶ s and a maximum Courant number of 0.5.  
Output fields (velocity, pressure, temperature, species) at appropriate intervals for post‑processing.
