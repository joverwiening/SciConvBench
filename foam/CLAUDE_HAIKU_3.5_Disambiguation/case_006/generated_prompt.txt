Specification for Rayleigh-Benard Convection Cell Simulation:

Geometry Configuration:
Create a rectangular cavity 9 units wide and 1 unit tall.
Extrude the domain a single cell in spanwise direction.
Treat front and back patches as empty to enforce 2D simulation.

Solver and Physics:
Use buoyantFoam solver.
Apply gravity in negative y direction.

Fluid Properties:
Use air-like reference state with following parameters:
Density: 1.0 kg/m^3
Reference temperature: 300 K
Thermal expansion coefficient: 3.3e-3 1/K
Kinematic viscosity: 1.5e-5 m^2/s
Thermal diffusivity: 2.1e-5 m^2/s
Prandtl number: ~0.7

Boundary Conditions:
Bottom wall temperature: Fixed at 305 K
Top wall temperature: Fixed at 295 K
Vertical side walls: Adiabatic
All solid walls: No-slip velocity conditions

Simulation Parameters:
Fixed timestep: 1 s
Total simulation time: 1000 s
Result writing interval: Every 50 steps

Turbulence Modeling:
Use RAS k-epsilon turbulence model
Enable turbulence
Print turbulence coefficients

Detailed Configuration:
Use heRhoThermo with Boussinesq equation of state
Set molecular weight: 29
Set reference density: 1.0 kg/m^3
Set reference temperature: 300 K
Set thermal expansion coefficient: 3.3e-3 1/K
Set specific heat capacity: 714.3
Set formation enthalpy: 0
Set dynamic viscosity: 1.5e-5
Set Prandtl number: 0.714

Turbulence Field Initialization:
k field: Uniform 1e-5
epsilon field: Uniform 1e-5
nut field: Uniform 0
alphat field: Uniform 0

Solver Tolerances:
Set p_rgh and (U|e|k|epsilon) solvers tolerance to 1e-8
Set relative tolerance to 0.01
