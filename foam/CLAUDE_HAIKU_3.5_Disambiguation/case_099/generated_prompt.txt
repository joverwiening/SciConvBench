Simulation Specification for Steady Buoyant Flow through Porous Medium:

Solver: buoyantBoussinesqSimpleFoam

Geometry:
The porous block is a 2D rectangular domain with dimensions 0.2 m (width) x 0.4 m (height) x 0.01 m (thickness).
Front and back boundaries are set to empty.
Mesh will be created using blockMesh with 20 x 40 x 1 cells.

Boundary Conditions:
Left wall temperature: Fixed at 303 K
Right wall temperature: Fixed at 293 K
Top and bottom walls temperature: zeroGradient
All walls velocity: noSlip

Fluid Properties (Boussinesq Model):
Reference temperature (T0): 298 K
Reference density (rho0): 1000 kg/m^3
Kinematic viscosity (nu): 1e-6 m^2/s
Prandtl number (Pr): 7.0
Thermal expansion coefficient (beta): 2.1e-4 1/K

Porous Medium Resistance:
Darcy-Forchheimer source coefficients:
d (laminar resistance): [1e8, 1e8, 1e8]
f (turbulent resistance): [0, 0, 0]

Simulation Type: Steady-state buoyancy-driven flow through porous medium
