Simulate 2D transient, laminar, incompressible flow over a cylinder using the pimpleFoam solver in OpenFOAM.
The computational domain is from -1m to +2.5m horizontally and -1m to +1m vertically.
Cylinder diameter is 0.1m, positioned at the center of the domain (0,0).
Reynolds number is 150.
Boundary conditions:
Inlet: Velocity set to uniform (1.5 0 0); pressure with zeroGradient.
Outlet: Velocity with zeroGradient; pressure fixed at uniform 0 Pa.
Cylinder walls: No-slip boundary condition.
Top and bottom boundaries: Slip boundary condition.
Initial conditions: Uniform zero velocity (0 0 0) and uniform 0 Pa pressure.
Use adjustable time step with maxCo = 0.5.
Simulation total time is 20 seconds.
Results to be written every 0.2 seconds.
