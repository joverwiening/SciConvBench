Simulate Rayleigh-Benard convection in a 0.1 m x 0.1 m square cavity.
Use buoyantBoussinesqSimpleFoam solver for the simulation.
Create a computational mesh with 50 x 50 x 1 grid points.
Set physical properties as follows:
Kinematic viscosity (nu) = 1.5e-5 m²/s
Prandtl number (Pr) = 0.71
Thermal expansion coefficient (beta) = 3.33e-3 1/K
Reference temperature (T0) = 293.5 K
Reference density (rho0) = 1.0 kg/m³
Set boundary conditions:
Bottom boundary temperature = 294.0 K (hot)
Top boundary temperature = 293.0 K (cold)
Initial uniform temperature = 293.5 K
Run the simulation for 5000 pseudo-time iterations.
Use a time step size of 1 for each iteration.
