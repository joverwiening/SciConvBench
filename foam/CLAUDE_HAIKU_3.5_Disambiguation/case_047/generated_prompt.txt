Simulate turbulent channel flow using the k-epsilon model with the following specifications:

Flow Characteristics:
Reynolds number is 5,000.
Flow is driven by a pressure gradient.

Computational Domain:
Domain dimensions are 1m (length) x 0.1m (height) x 0.2m (width).
Mesh resolution is 100x20x10 using blockMesh.

Boundary Conditions:
Velocity (U):
Inlet and outlet use cyclic boundary conditions.
Top and bottom walls use noSlip boundary conditions.

Turbulent Kinetic Energy (k):
Inlet and outlet use cyclic boundary conditions.
Top and bottom walls use kqRWallFunction with uniform value of 0.000375.

Turbulent Dissipation Rate (epsilon):
Inlet and outlet use cyclic boundary conditions.
Top and bottom walls use epsilonWallFunction with uniform value of 1.875e-4.

Turbulent Viscosity (nut):
Inlet and outlet use cyclic boundary conditions.
Top and bottom walls use nutkWallFunction with uniform value of 0.

Fluid Properties:
Kinematic viscosity (ν) = 1e-5 m^2/s
Bulk velocity = 0.5 m/s
