Simulate a 2D buoyant cavity flow using OpenFOAM.
Use a square domain with dimensions 1m x 1m.
Set the left wall temperature to 303 K (hot wall).
Set the right wall temperature to 293 K (cold wall).
Apply a temperature difference of 10 K between walls.
Use Rayleigh number Ra = 10^4.
Use buoyantBoussinesqSimpleFoam solver for steady-state simulation.
Apply no-slip boundary condition for velocity (U) on all walls.
Apply zero gradient temperature boundary condition on top and bottom walls.
Apply fixed flux pressure boundary condition (p_rgh) on top and bottom walls.
Model the fluid as air using the Boussinesq approximation.
Solve for natural convection heat transfer in the cavity.
