Simulation Specification for Conjugate Heat Transfer:

Fluid Properties:
Air will be modeled as a compressible perfect gas.
Molecular weight is approximately 28.9.
Specific heat capacity is 1005 J/kg/K.
Modeling approach uses heRhoThermo and perfectGas models.

Geometry:
Overall domain dimensions are 0.5 m x 0.1 m x 0.01 m (2D configuration via empty front/back).
Solid porous block region is 0.1 m x 0.05 m x 0.01 m, centered in the domain.
Domain will be created using blockMesh.
Regions will be defined using topoSet with cellZones for 'fluid' and 'solid'.
Mesh will be split using splitMeshRegions.

Initial Conditions:
Initial temperature of the entire domain is 300 K.

Boundary Conditions:
Fluid inlet temperature is 400 K.
Fluid inlet velocity is 1 m/s in the x-direction (1 0 0).

Simulation Type:
Conjugate heat transfer simulation between solid porous block and flowing air.
