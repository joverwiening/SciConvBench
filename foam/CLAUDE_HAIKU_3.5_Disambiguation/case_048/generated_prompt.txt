Transient Flow Over Cylinder Simulation Specification:

Physical Parameters:
The simulation will model water flow over a cylinder.
Reynolds number is 100.

Computational Domain:
Domain size is 2.2 m (x) x 0.41 m (y).
Cylinder diameter is 0.1 m.
Cylinder is centered at coordinates (0.2, 0.2).

Boundary Conditions:
Velocity (U):
Inlet boundary condition is fixedValue (0.001 0 0).
Outlet boundary condition is zeroGradient.
Top and bottom boundaries use slip condition.
Cylinder wall uses noSlip condition.
Front and back boundaries are set to empty.

Pressure (p):
Inlet boundary condition is zeroGradient.
Outlet boundary condition is fixedValue 0.
Top and bottom boundaries use zeroGradient.
Cylinder wall uses zeroGradient.
Front and back boundaries are set to empty.

Solver and Discretization:
Use pimpleFoam solver.
Use standard second-order discretization schemes.

Time Controls:
Start time is 0.
End time is 200.
Time step adjustment is enabled.
Maximum Courant number is 1.0.
Maximum time step is 0.01.
Write control is set to timeStep.
Write interval is 100 time steps.
