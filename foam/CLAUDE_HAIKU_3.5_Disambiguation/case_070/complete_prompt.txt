Simulate steady-state, incompressible, turbulent flow through a porous baffle using the simpleFoam solver.
GEOMETRY: The domain is a 2D channel, 1.0 m long and 0.1 m high. The porous baffle is a zero-thickness screen located at x=0.5 m.
MESH: Use blockMesh to create two blocks, one from x=0 to x=0.5 and the second from x=0.5 to x=1.0. The interface between them will be the baffle. The mesh resolution is (100 x 20 x 1) cells total. Use 'topoSet' to create a 'faceZone' named 'porousBaffleZone' at the interface.
TURBULENCE: Use the standard k-omega SST RAS model. Set 'simulationType RAS' in 'constant/turbulenceProperties' and 'model kOmegaSST' in 'constant/RASProperties'.
PHYSICAL PROPERTIES: In 'constant/transportProperties', set kinematic viscosity nu = 1e-5 m^2/s.
POROUS BAFFLE MODEL: This is not a porous zone via fvOptions, but a boundary condition. In '0/p', create a patch for the baffle named 'porousBaffle'. Set its type to 'porousBafflePressure'. This requires a 'faceZone' entry pointing to 'porousBaffleZone' and coefficients for the pressure drop model: D (Darcy) = 1e7 and I (Inertial/Forchheimer) = 0.
INITIAL & BOUNDARY CONDITIONS:
- U: inlet is fixedValue uniform (5 0 0); outlet is zeroGradient; walls are noSlip.
- p: inlet is zeroGradient; outlet is fixedValue uniform 0; walls are zeroGradient. The 'porousBaffle' patch is of type 'porousBafflePressure'.
- k, omega, nut: Use standard wall functions on walls and appropriate inlet/outlet conditions.
TIME CONTROLS: In 'system/controlDict', set application = simpleFoam, stopAt = endTime, endTime = 1000, deltaT = 1.
