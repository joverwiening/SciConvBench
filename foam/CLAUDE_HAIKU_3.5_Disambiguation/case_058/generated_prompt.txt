Simulation Specification for Flow Past a Cylinder using pimpleFoam:

Computational Domain:
- Domain size is 2.2m x 0.41m x 0.01m
- Cylinder diameter is 0.1m
- Cylinder center located at coordinates (0.2, 0.2, 0)

Fluid Properties:
- Reynolds number: 100
- Kinematic viscosity: 1e-3 m²/s
- Inlet velocity: 1 m/s

Boundary Conditions:
- Inlet: Velocity (1 0 0), Pressure zeroGradient
- Outlet: Velocity inletOutlet with inletValue (1 0 0), Pressure fixed at 0
- Cylinder Wall: Velocity no-slip (0 0 0), Pressure zeroGradient
- Top and Bottom Walls: Velocity slip, Pressure zeroGradient
- Front and Back Planes: Velocity and Pressure type 'empty'

Mesh Generation:
- Use blockMesh with O-grid topology around the cylinder
- Mesh resolution based on standard OpenFOAM best practices for flow past cylinder simulations

Solver:
- Use pimpleFoam transient solver
