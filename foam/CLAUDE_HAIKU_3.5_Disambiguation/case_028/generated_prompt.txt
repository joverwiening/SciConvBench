Run a transient laminar two-phase dam-break simulation using interFoam.
Use a cubic computational domain spanning from (0,0,0) to (1,1,1) meters.
Discretize the domain uniformly with a 32 x 32 x 32 grid resolution.
Place an obstacle in the domain from (0.375, 0.375, 0) to (0.625, 0.625, 0.25) meters.
Set gravitational acceleration to g = (0, 0, -9.81) m/s².
Initialize water volume fraction (alpha.water) as 1 inside the box from (0, 0, 0) to (0.6, 0.1875, 0.75) meters.
Set water volume fraction to 0 elsewhere in the domain (air phase).
Set simulation time step (deltaT) to 0.001 seconds.
Set total simulation end time to 0.1 seconds.
Set data writing interval to 0.02 seconds.
Apply wall boundary conditions to left, right, bottom, front, and back domain faces.
Apply open atmosphere boundary condition to the top domain face (z=1).
