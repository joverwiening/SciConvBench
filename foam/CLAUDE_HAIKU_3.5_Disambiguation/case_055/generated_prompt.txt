Simulation of a Compressible, High-Speed Lid-Driven Cavity Flow

Fluid Dynamics Configuration:
The simulation will model a compressible, high-speed lid-driven cavity flow.

Turbulence Modeling:
Use RAS k-Omega SST turbulence model with compressible wall functions.

Boundary Conditions:
Top Lid (Moving Wall):
Velocity set to (100 0 0) m/s using fixedValue.
Pressure boundary condition is zeroGradient.
Temperature fixed at 300 K.
k and omega use wall functions.

Side and Bottom Walls (Fixed Walls):
Velocity boundary condition is noSlip.
Pressure boundary condition is zeroGradient.
Temperature fixed at 300 K.
k and omega use wall functions.

Front and Back Boundaries:
Set as empty boundary condition.

Simulation Parameters:
Perform a compressible flow simulation with the specified turbulence and boundary conditions.
